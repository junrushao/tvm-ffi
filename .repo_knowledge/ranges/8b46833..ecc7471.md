## Overview

This range represents a major evolution of TVM-FFI from v0.1.6 through v0.1.8+,
spanning container system expansion, object model hardening, error handling
completeness, reflection extensions, CUDA/ROCm maturation, and a comprehensive
documentation overhaul.

### Key Highlights

- **Mutable containers**: `List<T>` and `Dict<K,V>` introduced alongside
  existing immutable `Array<T>` and `Map<K,V>`, with full cross-subsystem
  integration (serialization, structural hash/equal, deep copy, repr)
- **Object model**: `__slots__=()` enforcement, copy/deepcopy/replace
  semantics, `CObject`/`Object` split
- **Error handling**: Generalized CHECK macros with custom error kinds,
  `Expected<T>` for exception-free paths, error cause chaining
- **Reflection**: Function overloading, `DefaultFactory`, `kw_only` init,
  unified DFS-based repr, `__repr__` generation
- **CUDA/ROCm**: Cubin launcher refactor with unified CUDA API, ROCm DLPack
  stream fix, AMD HIP C++ extension support
- **Documentation**: 8 new concept/guide RST docs, complete packaging docs,
  developer manuals
- **Rust**: `Array<T>` binding with `AnyCompatible` trait
