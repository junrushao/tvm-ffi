# 3b4a532 — [CMAKE] Allow explicit turning threads off (#400)

## TL;DR
- Adds a new CMake option `TVM_FFI_USE_THREADS` (default ON) to explicitly control thread library linkage.
- Changes `find_package(Threads)` from optional-at-top-level to required-when-enabled, gated behind the new option.

## Why (intent / motivation)
- On some cross-compilation platforms, the Threads library may not be found or is not needed. This change provides an explicit knob to disable thread linkage instead of relying on `find_package(Threads)` silently succeeding or failing.

## What changed (facts from diff)
- Added `option(TVM_FFI_USE_THREADS "Link against threads in shared lib" ON)` near the top of CMakeLists.txt.
- Replaced the previous `find_package(Threads)` / `if (Threads_FOUND)` pattern with `if (TVM_FFI_USE_THREADS)` / `find_package(Threads REQUIRED)`.
- When `TVM_FFI_USE_THREADS` is ON, Threads is now REQUIRED (CMake will error if not found). When OFF, Threads is not searched for at all.

## Public surface changes (if any)

## Tests & verification

- CI impact: none (default is ON, existing behavior preserved)
