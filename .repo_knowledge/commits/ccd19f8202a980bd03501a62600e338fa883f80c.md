# ccd19f8 — feat(cmake): Introduce `tvm_ffi_configure_target` and `tvm_ffi_install` (#351)

## TL;DR
- Adds two new CMake functions `tvm_ffi_configure_target()` and `tvm_ffi_install()` to simplify integration with TVM-FFI
- `tvm_ffi_configure_target` replaces manual calls to link headers/shared libs, prefix map, dsymutil, MSVC flags, and stubgen
- `tvm_ffi_install` handles platform-specific debug symbol installation (dSYM on Apple)
- Simplifies the packaging example CMakeLists from ~50 lines to ~5 lines

## Why (intent / motivation)
- Users integrating TVM-FFI via CMake had to manually call multiple utility functions (link, prefix map, dsymutil, MSVC flags, stubgen)
- Similar to `pybind11_add_module` and `nanobind_add_module`, a single high-level function reduces boilerplate and errors
- The packaging example's CMakeLists was overly complex for a simple extension

## What changed (facts from diff)
- `cmake/Utils/Library.cmake`: added `tvm_ffi_configure_target()` function (~120 lines) with keyword args: `LINK_SHARED`, `LINK_HEADER`, `DEBUG_SYMBOL`, `MSVC_FLAGS`, `STUB_INIT`, `STUB_DIR`, `STUB_PKG`, `STUB_PREFIX`
- `cmake/Utils/Library.cmake`: added `tvm_ffi_install()` function (~50 lines) with `DESTINATION` keyword arg for dSYM installation
- `cmake/Utils/Library.cmake`: changed `tvm_ffi_add_apple_dsymutil` to always run on Apple (removed `TVM_FFI_USE_LIBBACKTRACE` guard)
- `examples/packaging/CMakeLists.txt`: replaced ~50 lines of manual setup with `tvm_ffi_configure_target(my_ffi_extension STUB_DIR "./python" STUB_INIT ON)` and `tvm_ffi_install(my_ffi_extension)`
- `examples/packaging/python/my_ffi_extension/_ffi_api.py`: fixed library loader package name from `"my-ffi-extension"` to `"my_ffi_extension"`

## Public surface changes (if any)
- API: new CMake functions `tvm_ffi_configure_target()` and `tvm_ffi_install()`
- Flags/config: new keyword arguments control linking, debug symbols, MSVC flags, and stub generation
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: none (tested via existing CI example workflows)
- How to verify manually: `cd examples/packaging && uv pip install --verbose . --no-build-isolation && python run_example.py`
- CI impact: the packaging example CI job exercises the new CMake functions

## Risk & rollout notes
- Risk level: medium — new public CMake API; the `tvm_ffi_add_apple_dsymutil` behavior change (removing libbacktrace guard) could affect existing users
- Rollout/migration: existing users can migrate from manual calls to `tvm_ffi_configure_target`; old manual pattern still works
- Follow-ups: none
