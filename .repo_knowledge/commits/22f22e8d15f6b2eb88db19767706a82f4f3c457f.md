# 22f22e8 -- fix(lint): Suppress latest clang-tidy warnings (#361)

## TL;DR
- Adds `NOLINTNEXTLINE(bugprone-unchecked-optional-access)` suppression in `overload.h` for an intentionally unchecked `std::optional` dereference.
- Adds a missing Doxygen comment for the `Super` type alias.

## Why (intent / motivation)
- Introduced by PR #286, the `CaptureTuple` type (a tuple of `std::optional<T>...`) has its optionals dereferenced without explicit checks. This is intentional by design (the optionals are guaranteed to have values at the call site), but newer clang-tidy flags it as `bugprone-unchecked-optional-access`.
- The `Super` alias lacked documentation.

## What changed (facts from diff)
- `include/tvm/ffi/reflection/overload.h` line 167: Added `// NOLINTNEXTLINE(bugprone-unchecked-optional-access)` before the star-dereference of optional tuple elements.
- `include/tvm/ffi/reflection/overload.h` line 276: Added `/*! \brief The super class */` Doxygen comment for `using Super = ObjectDef<Class>`.
