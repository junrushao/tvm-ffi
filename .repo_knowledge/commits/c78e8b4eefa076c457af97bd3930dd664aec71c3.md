# c78e8b4 — doc: abi overview (#402)

## TL;DR
- Rewrites the ABI overview doc from Markdown (`abi_overview.md`) to reStructuredText (`abi_overview.rst`) with significant content expansion
- Adds a new standalone C example file (`examples/abi_overview/example_code.c`, ~292 lines) illustrating low-level ABI usage
- Streamlines other concept docs (`any.rst`, `func_module.rst`, `object_and_class.rst`, `tensor.rst`) by removing duplicated content now covered in the overview
- Adds `TVM_FFI_VERSION_CODE` and `TVM_FFI_VERSION` convenience macros to `c_api.h`

## Why (intent / motivation)
- The existing Markdown ABI overview was less integrated with the Sphinx RST doc system
- Content was duplicated across multiple concept pages
- A comprehensive, single-source ABI overview with runnable C example code improves developer onboarding
