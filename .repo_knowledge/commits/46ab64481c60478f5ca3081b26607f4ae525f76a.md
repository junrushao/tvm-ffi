# 46ab644 — feat: add __bool__ support for Array and Map (#380)

## TL;DR
- Added `__bool__` to `Array` and `Map` so empty containers evaluate to `False` (matching Python `list`/`dict` semantics).
- Added parametrized pytest tests for both container types.

## Why (intent / motivation)
- Python built-in `list` and `dict` return `False` when empty. `Array` and `Map` did not implement `__bool__`, so `bool(Array([]))` and `bool(Map({}))` unexpectedly returned `True` (default object truthiness).

## What changed (facts from diff)
- `Array.__bool__` returns `len(self) > 0`.
- `Map.__bool__` returns `len(self) > 0`.
- New parametrized tests (`test_array_bool`, `test_map_bool`) verify truthy/falsy behavior for empty and non-empty instances.

## Public surface changes (if any)
- API: `Array.__bool__` and `Map.__bool__` are now defined (previously inherited default `True`).
- Flags/config: none
- Data formats/schemas: none
