# 395db3c -- Add Support for NVIDIA Ampere GPUs in _get_cuda_target (#440)

## TL;DR
- Adds a fallback GPU name-based lookup for CUDA compute capability when `nvidia-smi` does not support `compute_cap` query (common on older Ampere drivers).
- Maps known Ampere GPU names (A100, A10) to their compute capabilities (8.0, 8.6).
- Raises `RuntimeError` with a clear message instead of silently defaulting to compute_70.

## Why (intent / motivation)
- Older NVIDIA drivers on Ampere GPUs (A10, A100) do not support the `compute_cap` query field in `nvidia-smi`. This caused `_get_cuda_target` to fail or silently fall back to `compute_70`, which is incorrect for Ampere hardware. The fix provides a fallback that queries the GPU name and maps it to the correct compute capability.

## What changed (facts from diff)
- `python/tvm_ffi/cpp/extension.py`: In `_get_cuda_target()`, replaced the blanket fallback to `compute_70` with:
  1. A secondary try/except that queries `nvidia-smi --query-gpu=name` and looks up the GPU name in an `ampere_arch_map` dict (`A100` -> 8.0, `A10` -> 8.6).
  2. If both detection methods fail, raises `RuntimeError` suggesting the user set `TVM_FFI_CUDA_ARCH_LIST` environment variable.

## Public surface changes (if any)
- API: none (internal helper function)
- Flags/config: Error message now references `TVM_FFI_CUDA_ARCH_LIST` environment variable.
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: none
- How to verify manually: Run on an Ampere GPU with an older driver that lacks `compute_cap` support.
- CI impact: none

## Risk & rollout notes
- Risk level: low -- Fallback only triggers when primary detection fails. The `ampere_arch_map` is conservative (only 2 entries). The previous silent fallback to compute_70 was arguably more risky.
- Rollout/migration: Users who previously relied on the silent compute_70 fallback will now get a `RuntimeError` if their GPU is not in the map. They can set `TVM_FFI_CUDA_ARCH_LIST` to resolve.
- Follow-ups: The `ampere_arch_map` could be extended with more GPU models (A30, A40, etc.).
