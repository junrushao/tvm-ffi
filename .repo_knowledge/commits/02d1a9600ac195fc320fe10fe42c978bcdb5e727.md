# 02d1a96 -- feat: add starts_with and ends_with to String (#388)

## TL;DR
- Adds `starts_with()` and `ends_with()` methods to the `String` class in C++ with multiple overloads (String, string_view, const char*, const char* + length).
- Comprehensive GoogleTest coverage for both methods including edge cases (empty strings, single char, prefix longer than string).

## Why (intent / motivation)
- Users lacked efficient prefix/suffix checking methods on the TVM-FFI `String` class, requiring conversion to `std::string` for basic pattern matching operations commonly needed in compiler infrastructure.

## What changed (facts from diff)
- Added 4 overloads of `starts_with()` to `String`: accepting `const String&`, `std::string_view`, `const char*`, and `const char* + size_t count`.
- Added 4 overloads of `ends_with()` to `String` with the same overload variants.
- Core implementation uses `std::memcmp` with bounds checking (`count > size()` returns false).
- Added `TEST(String, StartsWith)` and `TEST(String, EndsWith)` test cases.

## Public surface changes (if any)
- API: New public methods `String::starts_with(...)` and `String::ends_with(...)` with 4 overloads each.
- Flags/config: none
- Data formats/schemas: none
