# 3b26a09 -- doc: Properly document `field_static_type_index` and add more tests (#456)

## TL;DR
- Rewrites documentation for `field_static_type_index` in `TVMFFIFieldInfo` (C API) to clarify compile-time vs runtime semantics.
- Restores `TypeToFieldStaticTypeIndex` / `TypeToRuntimeTypeIndex` templates and POD field inlining in serialization.
- Adds 40 new C++ serialization tests and 58 new Python serialization tests.
- Adds serialization-oriented test objects (`TestSerializationObj`, `TestSerializationAllFieldsObj`, etc.) in testing_object.h.

## Why (intent / motivation)
- The `field_static_type_index` field in `TVMFFIFieldInfo` was poorly documented and its usage for POD field inlining in serialization was incomplete. This commit restores full usage and provides thorough documentation explaining the compile-time static type semantics versus runtime type.

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: Rewrote the documentation block for `field_static_type_index` with warnings about compile-time vs runtime type mismatch, explicit value semantics for all type index values.
- `include/tvm/ffi/type_traits.h`: Removed one blank line (minor cleanup).
- `rust/tvm-ffi-sys/src/c_api.rs`: Updated doc comment for `field_static_type_index` to match new C API docs.
- `tests/cpp/extra/test_serialization.cc`: Added 364 lines of new C++ serialization tests covering all field types, round-trip serialization, nested objects, containers, optional fields, and edge cases.
- `tests/cpp/test_reflection.cc`: Added 2 lines checking `field_static_type_index` values in reflection tests.
- `tests/cpp/testing_object.h`: Added 96 lines of new test object definitions (`TestSerializationObj`, `TestSerializationAllFieldsObj`, etc.) with full reflection registration.
- `tests/python/test_serialization.py`: Added 515 lines of Python serialization tests (58 tests) covering round-trip for all primitive types, containers, nested objects, and edge cases.
