# a754afe — chore: Run examples on `main` commits (#353)

## TL;DR
- Adds a new CI job (`examples`) to `ci_mainline_only.yml` that builds and runs all three example projects on every mainline commit
- Adds Windows `.bat` scripts for quickstart and stable_c_abi examples
- Fixes multi-config generator output directory issues in CMakeLists via `set_flat_output_dirs` helper
- Updates example READMEs and `run_example.py` to be self-contained and run all examples sequentially

## Why (intent / motivation)
- Examples were not being tested in CI, meaning they could break silently on mainline
- Windows support needed batch scripts to run the same examples that Linux/macOS use shell scripts for
- Multi-config CMake generators (MSVC) placed build outputs in config subdirectories, breaking scripts that expected flat output

## What changed (facts from diff)
- `ci_mainline_only.yml`: added `examples` job matrix (ubuntu-latest/py3.14, macos-14/py3.13, windows-latest/py3.12) running quickstart, stable_c_abi, and packaging examples
- `examples/quickstart/CMakeLists.txt`: added `set_flat_output_dirs()` function; replaced manual `LIBRARY_OUTPUT_DIRECTORY` with it
- `examples/quickstart/run_all_cpu.bat`: new Windows batch script
- `examples/quickstart/README.md`: added "Run everything" section with bash/bat instructions
- `examples/stable_c_abi/CMakeLists.txt`: added same `set_flat_output_dirs()` function
- `examples/stable_c_abi/run_all.bat`: new Windows batch script
- `examples/stable_c_abi/README.md`: added "Run everything" section
- `examples/stable_c_abi/src/add_one_cpu.c`: changed `TVM_FFI_DLL` to `TVM_FFI_DLL_EXPORT`
- `examples/packaging/pyproject.toml`: fixed typo `RelWithDebugInfo` -> `RelWithDebInfo`
- `examples/packaging/README.md`: simplified usage, replaced CLI arg dispatch with single `python run_example.py`
- `examples/packaging/run_example.py`: runs all three flows (add_one, raise_error, int_pair) sequentially; catches errors in raise_error demo
