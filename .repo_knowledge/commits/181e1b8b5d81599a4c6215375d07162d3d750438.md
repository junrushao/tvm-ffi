# 181e1b8 -- ci: add clang-tidy to ci_test (#389)

## TL;DR
- Adds a `clang-tidy` job to the PR CI workflow (`ci_test.yml`) so C++ lint failures are caught before merge, not only on main.
- Detects changed C++ files and conditionally runs clang-tidy only when relevant files are modified.

## Why (intent / motivation)
- Previously, clang-tidy ran only on the main branch (in `ci_mainline_only.yml`). PRs could pass CI but then break main after merge due to undetected clang-tidy violations.

## What changed (facts from diff)
- Added a `Get changed C++ files` step in the `prepare` job that diffs against `origin/${{ github.base_ref }}` for `*.c`, `*.cc`, `*.cpp`, `*.cxx` files.
- New outputs `cpp_changed` and `cpp_files` from the prepare job.
- Added a new `clang-tidy` job that runs conditionally (`if: needs.prepare.outputs.cpp_changed == 'true'`) using `uv run --no-project --with "clang-tidy==21.1.1"` and the `clang_tidy_precommit.py` script.
