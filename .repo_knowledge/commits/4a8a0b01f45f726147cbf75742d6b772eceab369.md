# 4a8a0b0 -- chore: replace C-style cast with static_cast in String::substr (#386)

## TL;DR
- Replaces `size_t(-1)` with `npos` in `String::substr` default parameter to fix a clang-tidy `google-readability-casting` error.

## Why (intent / motivation)
- clang-tidy on CI failed with a `google-readability-casting` error because `String::substr` used a C-style cast `size_t(-1)` in its default parameter instead of `npos` (which is already `static_cast<size_t>(-1)`).

## What changed (facts from diff)
- Changed default parameter of `String::substr` from `size_t count = size_t(-1)` to `size_t count = npos`.

## Public surface changes (if any)
- API: none (behavior identical; `npos` is `static_cast<size_t>(-1)`)
- Flags/config: none
