# dcd07cf — [CMAKE] Allow explcitly turning dl off (#401)

## TL;DR
- Adds a new CMake option `TVM_FFI_USE_DL_LIBS` (default ON) to control linking against `dl` libs.
- The dl library linkage now requires both `TVM_FFI_USE_EXTRA_CXX_API`, `CMAKE_DL_LIBS`, and the new `TVM_FFI_USE_DL_LIBS` to all be truthy.

## Why (intent / motivation)
- Certain cross-compilation scenarios require explicitly disabling the `dl` (dynamic loading) library linkage, as it may not be available or desired on the target platform.

## What changed (facts from diff)
- Added `option(TVM_FFI_USE_DL_LIBS "Link against dl libs in shared lib" ON)` to CMakeLists.txt.
- The conditional that links `${CMAKE_DL_LIBS}` to `tvm_ffi_shared` and `tvm_ffi_static` now additionally checks `TVM_FFI_USE_DL_LIBS`.

## Public surface changes (if any)
- API: none
- Flags/config: New CMake option `TVM_FFI_USE_DL_LIBS` (default ON, backward compatible)
- Data formats/schemas: none

## Tests & verification

- How to verify manually: `cmake . -B build -DTVM_FFI_USE_DL_LIBS=OFF` and confirm `dl` is not linked.
- CI impact: none (default is ON, existing behavior preserved)
