# 5bc7fcd — feat: add array __contains__ support (#377)

## TL;DR
- Added `ffi.ArrayContains` C++ FFI function using `AnyEqual` and `std::any_of`.
- Implemented `Array.__contains__` in Python, enabling `value in array` syntax.
- Added C++ and Python tests and updated type stubs.

## Why (intent / motivation)
- Python `Array` lacked native `in` operator support, requiring manual iteration to check membership. This is a standard Python `Sequence` protocol method.

## What changed (facts from diff)
- `src/ffi/container.cc`: Registered `ffi.ArrayContains` lambda that uses `AnyEqual` with `std::any_of` to search the array.
- `python/tvm_ffi/container.py`: Added `Array.__contains__` method delegating to `_ffi_api.ArrayContains`.
- `python/tvm_ffi/_ffi_api.py`: Added `ArrayContains` stub signature and `__all__` entry.
- `tests/cpp/test_array.cc`: Added `TEST(Array, Contains)` covering int and string arrays, including empty arrays.
- `tests/python/test_container.py`: Added parametrized `test_array_contains` with 9 test cases. Also added `from __future__ import annotations` import.
