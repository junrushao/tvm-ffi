# a1cb746 -- build: Rename Import Targets (#354)

## TL;DR
- Renames CMake imported targets from `tvm_ffi_shared`/`tvm_ffi_header` to `tvm_ffi::shared`/`tvm_ffi::header` in `tvm_ffi-config.cmake`.
- Updates all CMake consumers (Library.cmake, EmbedCubin.cmake, examples, docs) to use the new namespaced target names.
- Avoids name conflicts between imported and locally defined CMake targets.

## Why (intent / motivation)
- The old target names `tvm_ffi_shared` and `tvm_ffi_header` conflicted with targets defined in the project's own `CMakeLists.txt`. CMake's `::` namespace convention for imported targets prevents this ambiguity and is the standard modern CMake practice.

## What changed (facts from diff)
- **`cmake/tvm_ffi-config.cmake`**: `add_library(tvm_ffi_header INTERFACE)` changed to `add_library(tvm_ffi::header INTERFACE IMPORTED)`. `add_library(tvm_ffi_shared SHARED IMPORTED)` changed to `add_library(tvm_ffi::shared SHARED IMPORTED)`. All `set_target_properties` and `target_*` calls updated accordingly.
- **`cmake/Utils/Library.cmake`**: `tvm_ffi_configure_target` now links against `tvm_ffi::header` and `tvm_ffi::shared` instead of the old names. Documentation comments updated.
- **`cmake/Utils/EmbedCubin.cmake`**: Added fallback logic to check for both `tvm_ffi::header` (preferred) and `tvm_ffi_header` (legacy) targets.
- **`examples/quickstart/CMakeLists.txt`**: Updated `target_link_libraries` to use `tvm_ffi::header tvm_ffi::shared`.
- **`examples/stable_c_abi/CMakeLists.txt`**: Same update.
- **`examples/cubin_launcher/dynamic_cubin/CMakeLists.txt`**: Same update.
- **`examples/cubin_launcher/embedded_cubin/CMakeLists.txt`**: Same update.
- **`docs/get_started/quickstart.rst`**: Documentation updated to reference `tvm_ffi::header` and `tvm_ffi::shared`.

## Public surface changes (if any)
- API: CMake imported target names changed from `tvm_ffi_shared`/`tvm_ffi_header` to `tvm_ffi::shared`/`tvm_ffi::header`. This is a breaking change for downstream CMake users.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: none
- How to verify manually: Build any example that uses `find_package(tvm_ffi)` and verify the new target names resolve correctly.
- CI impact: CI example builds will validate the new target names.

## Risk & rollout notes
- Risk level: medium -- breaking change for downstream projects that directly reference `tvm_ffi_shared` or `tvm_ffi_header` in their CMakeLists. The `EmbedCubin.cmake` has a fallback for `tvm_ffi_header`, but `Library.cmake` does not.
- Rollout/migration: Downstream CMake users must update `target_link_libraries` calls from `tvm_ffi_shared`/`tvm_ffi_header` to `tvm_ffi::shared`/`tvm_ffi::header`.
- Follow-ups: none
