# 0f45528 -- fix: Suppress GCC warning for array bounds in String class (#439)

## TL;DR
- Adds `#pragma GCC diagnostic ignored "-Warray-bounds"` to suppress a false-positive GCC warning in `String::Concat`.

## Why (intent / motivation)
- GCC (non-Clang) emits a spurious `-Warray-bounds` warning for the `memcpy` call in `String::Concat` when the function is inlined in certain contexts (e.g., `operator+(const String&, const char*)`). The warning claims an out-of-bounds offset, but it is a false positive caused by GCC's analysis of inlined code paths. The existing pragma block already suppressed `-Wstringop-overflow` and `-Wrestrict`; this adds the missing `-Warray-bounds` suppression.

## What changed (facts from diff)
- `include/tvm/ffi/string.h`: Added `#pragma GCC diagnostic ignored "-Warray-bounds"` inside the existing `#if (__GNUC__) && !(__clang__)` pragma block, before the `Concat` function body.
