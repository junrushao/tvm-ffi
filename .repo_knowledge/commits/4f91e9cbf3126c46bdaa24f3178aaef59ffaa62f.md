# 4f91e9c -- [TEST] Addback missing test for init once (#452)

## TL;DR
- Adds back a missing C++ test file for the `TVMFFIHandleInitOnce` / `TVMFFIHandleDeinitOnce` C API.
- Includes single-threaded tests covering success, error, idempotency, and lifecycle scenarios.
- Includes multi-threaded tests verifying exactly-once semantics under concurrent access.

## Why (intent / motivation)
- A C++ test for the `TVMFFIHandleInitDeinitOnce` API was previously missing from the test suite. This commit restores it to ensure the init-once / deinit-once thread-safe handle management is properly tested.

## What changed (facts from diff)
- `tests/cpp/test_init_once.cc`: New 313-line test file with two test cases:
  - `TVMFFIHandleInitDeinitOnce`: 9 sub-tests covering successful init, idempotent re-init, successful deinit, idempotent re-deinit, init error (returns error code), init returning null, deinit error, full lifecycle, and re-init after deinit.
  - `TVMFFIHandleInitDeinitOnceMultithreaded`: Tests with 4 threads racing on init (verifies init called exactly once) and 4 threads racing on deinit (verifies deinit called exactly once).
