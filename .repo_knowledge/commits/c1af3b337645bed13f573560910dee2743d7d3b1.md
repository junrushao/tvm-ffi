# c1af3b3 -- [FEAT] Introduce mutable Dict (#463)

## TL;DR
- Introduced `Dict<K, V>` as a mutable map container with shared-reference semantics (all handles see mutations immediately)
- Added `kTVMFFIDict = 76` type index in the C ABI
- Full Python bindings as `tvm_ffi.Dict` implementing `MutableMapping`
- Complete support in serialization, deep copy, structural equal/hash, repr, and JSON writer

## Why (intent / motivation)
- The existing `Map` container uses copy-on-write (immutable) semantics, which is not suitable for all use cases
- A mutable dictionary is needed for scenarios where multiple handles should share and observe mutations (e.g., building up state progressively)
- `Dict` shares the same `MapBaseObj` base class as `Map`, enabling potential future freeze-to-immutable operations

## What changed (facts from diff)
- New C++ header `include/tvm/ffi/container/dict.h`: `DictObj` (extends `MapBaseObj`) and `Dict<K, V>` template with full iterator, Set/Get/erase/pop/count/clear/update APIs
- `include/tvm/ffi/c_api.h`: Added `kTVMFFIDict = 76` type index
- `include/tvm/ffi/container/map_base.h`: Added `clean()` helper, `Empty<>()` factory, `CreateFromRange<>()` factory to `MapBaseObj`; extracted shared logic from `Map` to support `Dict`
- `include/tvm/ffi/object.h`: Added `kTVMFFIDict` to `TypeIndex` enum
- `python/tvm_ffi/container.py`: New `Dict` class (+148 lines) implementing `MutableMapping` with `__setitem__`, `__delitem__`, `pop`, `clear`, `update`, `setdefault`
- `python/tvm_ffi/__init__.py`: Exports `Dict`
- `python/tvm_ffi/cython/type_info.pxi`: Added Dict to type info mapping
- `src/ffi/container.cc`: Registered `ffi.Dict` constructor and `ffi.DictSize`, `ffi.DictGetItem`, `ffi.DictSetItem`, `ffi.DictDeleteItem`, `ffi.DictClear`, `ffi.DictKeys`, `ffi.DictValues`, `ffi.DictItems`
- `src/ffi/extra/deep_copy.cc`: Added Dict deep copy support
- `src/ffi/extra/json_writer.cc`: Added Dict JSON serialization
- `src/ffi/extra/repr_print.cc`: Added Dict repr support
- `src/ffi/extra/serialization.cc`: Added Dict serialization/deserialization
- `src/ffi/extra/structural_equal.cc`: Added Dict structural equality
- `src/ffi/extra/structural_hash.cc`: Added Dict structural hashing
- Extensive C++ tests (`tests/cpp/test_dict.cc`, 229 lines) and Python tests (`tests/python/test_container.py`, +219 lines)
