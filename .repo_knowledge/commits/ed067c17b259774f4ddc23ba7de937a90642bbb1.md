# ed067c1 — Update the logic of checking `#embed` (#418)

## TL;DR
- Adds a compile-time check for C++26 `#embed` support in the CUBIN launcher example
- Fails early with a clear error message if the compiler does not support `__cpp_pp_embed`

## Why (intent / motivation)
- The embedded CUBIN example requires C++26 `#embed` preprocessor directive
- Without an explicit check, builds would fail with cryptic errors on older compilers
- Moving the check after `set(CMAKE_CXX_STANDARD 26)` ensures the feature test macro is properly defined

## What changed (facts from diff)
- `examples/cubin_launcher/embedded_cubin/cpp_embed/CMakeLists.txt`: Added `CheckCXXSymbolExists` for `__cpp_pp_embed` macro after setting C++26 standard; emits `FATAL_ERROR` with guidance to use GCC 15+ or Clang 19+ if not supported
