# e08dd68 — chore: Run ty in dev environment (#441)

## TL;DR
- Migrates dependency management from `[project.optional-dependencies]` to `[dependency-groups]` for `test` and `torch` groups
- Pins `ty` to version 0.0.15 with `--error-on-warning` flag, reorders pre-commit hooks
- Adds `ty: ignore[...]` comments to suppress known false positives across Python files
- Adds `ml_dtypes` version guard in tests

## Why (intent / motivation)
- Aligns with modern Python packaging practices by using dependency-groups instead of optional-dependencies for dev/test tooling
- Pins `ty` to a specific version for reproducibility and enables `--error-on-warning` for stricter type checking
- Ensures all `ty` warnings are addressed to keep the codebase clean
