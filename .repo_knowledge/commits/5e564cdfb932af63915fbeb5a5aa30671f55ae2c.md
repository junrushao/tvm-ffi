# 5e564cd -- feat: add `DefaultFactory` support to field reflection (#446)

## TL;DR
- Adds `DefaultFactory` trait to the reflection system, allowing mutable defaults (Array, Map) to be produced by a callable factory `() -> Any` rather than a shared static value.
- Renames `TVMFFIFieldInfo::default_value` to `default_value_or_factory` across C API, Cython, and Rust bindings.
- Adds `kTVMFFIFieldFlagBitMaskDefaultFromFactory` (1 << 5) flag bit.
- Introduces `reflection::SetFieldToDefault` helper used by creator, reflection_extra, and serialization.

## Why (intent / motivation)
- `DefaultValue` stores a single static default shared across all instances created via reflection. For mutable defaults (Array, Map, etc.) this causes aliasing: every object receives the same underlying container. `DefaultFactory` fixes this by storing a callable that produces a fresh value per instance, mirroring Python dataclass `default_factory`.
