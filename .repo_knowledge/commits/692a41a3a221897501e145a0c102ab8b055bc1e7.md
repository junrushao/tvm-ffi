# 692a41a — fix: add unified_api.h include to device_guard.h (#405)

## TL;DR
- Fixes missing `#include <tvm/ffi/extra/cuda/internal/unified_api.h>` in `device_guard.h` which caused `TVM_FFI_CHECK_CUDA_ERROR` to be undefined
- One-line change: replaces `#include <tvm/ffi/extra/cuda/base.h>` with `#include <tvm/ffi/extra/cuda/internal/unified_api.h>`
