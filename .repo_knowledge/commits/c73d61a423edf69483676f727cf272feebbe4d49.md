# c73d61a -- feat: add `__copy__`, `__deepcopy__`, and `__replace__` for FFI objects (#438)

## TL;DR
- Adds first-class `copy.copy`, `copy.deepcopy`, and dataclass-style `__replace__` support for TVM-FFI objects.
- Implements memoized graph-based deep copy in C++ (`ffi.DeepCopy`) preserving shared references and cycles.
- Auto-registers `__ffi_shallow_copy__` for copy-constructible reflected object types via `ObjectDef`.
- Wires Python class registration to install `__copy__`, `__deepcopy__`, and `__replace__` for supported types.

## Why (intent / motivation)
- TVM-FFI objects previously had no standard copy support. Users needed deep copy for immutable-style programming and shallow copy for quick cloning. This commit provides both, with proper handling of shared references, cycles, and non-copyable types.

## What changed (facts from diff)
- `CMakeLists.txt`: Added `src/ffi/extra/deep_copy.cc` to build.
- `include/tvm/ffi/extra/deep_copy.h`: New header declaring `DeepCopy(Any value) -> Any`.
