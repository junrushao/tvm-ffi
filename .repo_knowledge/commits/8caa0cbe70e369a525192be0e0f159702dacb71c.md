# 8caa0cb — feat: Introduce `<tvm/ffi/tvm_ffi.h>` (#369)

## TL;DR
- Added a new umbrella header `include/tvm/ffi/tvm_ffi.h` that includes all core TVM-FFI C++ headers in one shot.
- Updated all examples to use `#include <tvm/ffi/tvm_ffi.h>` instead of individual headers.
- Updated documentation and `pyproject.toml` example with improved formatting and references.

## Why (intent / motivation)
- Analogous to `nanobind/nanobind.h` and `pybind11/pybind11.h`, having a single umbrella header simplifies onboarding and reduces boilerplate `#include` directives for users.

## What changed (facts from diff)
- New file `include/tvm/ffi/tvm_ffi.h`: includes all core headers (any, cast, containers, dtype, error, function, memory, object, optional, reflection, rvalue_ref, string, type_traits, etc.).
- `examples/python_packaging/src/extension.cc`: replaced 3 individual includes with `tvm_ffi.h`.
- `examples/quickstart/compile/add_one_cpu.cc`: replaced 2 includes with `tvm_ffi.h`.
- `examples/quickstart/compile/add_one_cuda.cu`: replaced 2 includes with `tvm_ffi.h` + extra header.
- `examples/quickstart/load/load_cpp.cc` and `load_cuda.cc`: replaced container include with `tvm_ffi.h`.
- `docs/get_started/quickstart.rst`: added hint about umbrella header, fixed indentation.
- `docs/packaging/python_packaging.rst`: added umbrella header reference.
- `examples/python_packaging/pyproject.toml`: cleaned up scikit-build-core configuration.
