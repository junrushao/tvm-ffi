# 89cb606 — fix(build): Broken Wheel Testing (#444)

## TL;DR
- Fixes broken wheel testing caused by PR #441 which moved `test` from optional-dependency to dependency-group
- Changes `test-extras = ["test"]` to `test-groups = ["test"]` in cibuildwheel config

## Why (intent / motivation)
- PR #441 moved test dependencies from `[project.optional-dependencies]` to `[dependency-groups]`, but the cibuildwheel configuration still referenced the old `test-extras` key
- This caused wheel testing in CI to fail because cibuildwheel could not find the test dependencies

## What changed (facts from diff)
- `pyproject.toml`: Changed `test-extras = ["test"]` to `test-groups = ["test"]` under `[tool.cibuildwheel]` section to match the new dependency-group approach
