# b17709a — doc: Update Kernel Library Guide (#431)

## TL;DR
- Rewrites the kernel library guide (`docs/guides/kernel_library_guide.rst`) with clearer structure and expanded content
- Adds new example files: a CUDA scale kernel, a Python loader script, and a utility header for kernel libraries
- Cleans up Doxygen exclusion patterns in `docs/conf.py` to expose more symbols in the C++ API reference

## Why (intent / motivation)
- The existing kernel library guide was incomplete and did not provide concrete, runnable examples
- Developers shipping CUDA/C++ kernel libraries via TVM FFI needed an end-to-end walkthrough with actual source code

## What changed (facts from diff)
- `docs/guides/kernel_library_guide.rst` (+248/-120): Complete rewrite covering Tensor, DLPack, the `__tvm_ffi_<name>` export convention, shared library modules, kernel compilation, and integration with Python; restructured into clear sections with code examples
- `examples/kernel_library/scale_kernel.cu` (+66): New CUDA example implementing a scale kernel with TVM FFI function export using `TVM_FFI_EXPORT_FUNCTION`
- `examples/kernel_library/load_scale.py` (+34): New Python script demonstrating how to load and call the compiled CUDA kernel via `tvm_ffi.module.load_module`
- `examples/kernel_library/tvm_ffi_utils.h` (+75): New utility header providing `TVM_FFI_EXPORT_FUNCTION` macro and `AnyViewToTensor` helper for kernel libraries that want minimal TVM FFI dependency
- `docs/conf.py` (+3/-6): Cleaned up Doxygen `EXCLUDE_SYMBOLS` and `EXCLUDE_PATTERNS` — removed overly broad exclusions to expose more C++ API symbols in the reference docs
- `include/tvm/ffi/base_details.h` (+10/-6): Moved `TVM_FFI_DLL_EXPORT` and related macros outside of the `#ifndef TVM_FFI_BASE_DETAILS_H_` guard or adjusted their placement to be usable from the new `tvm_ffi_utils.h` standalone header
