# 39d9b2b -- [CORE] Enable customized AnyHash/Equal in Object Type attr (#451)

## TL;DR
- Extends `AnyHash` and `AnyEqual` to support custom hash/equal implementations registered via type attribute columns (`__any_hash__`, `__any_equal__`).
- Custom hash/equal can be registered as raw function pointers (fast path) or as `ffi.Function` objects.
- Moves `MoveFromSafeCallRaised` and `SetSafeCallRaised` from `function_details.h` to `error.h` for broader availability.
- Adds test objects (`TInt`, `TFloat`) with custom hash/equal registrations, plus new test cases.

## Why (intent / motivation)
- To allow object types to customize their hash and equality semantics when used as keys in containers like `Map<Any, Any>`. This is a prerequisite for `StructuralKey` and other types that need structural (not identity-based) hashing/equality.

## What changed (facts from diff)
- `include/tvm/ffi/any.h`: Extended `AnyHash::operator()` and `AnyEqual::operator()` with lookup into `__any_hash__` / `__any_equal__` type attribute columns. Supports both `OpaquePtr` (raw function pointer, fast path) and `Function` (FFI function object) callbacks. Added private helper methods `GetAnyHashTypeAttrColumn`, `CallCustomAnyHash`, `GetAnyEqualTypeAttrColumn`, `CallCustomAnyEqual`.
- `include/tvm/ffi/error.h`: Added `MoveFromSafeCallRaised()` and `SetSafeCallRaised()` helper functions (moved from `function_details.h`).
- `include/tvm/ffi/function_details.h`: Removed duplicate definitions of `MoveFromSafeCallRaised` and `SetSafeCallRaised`.
- `include/tvm/ffi/endian.h`: Minor whitespace cleanup (removed leading blank line).
- `src/ffi/container.cc`: Ensures `__any_hash__` and `__any_equal__` type attribute columns exist at init.
- `tests/cpp/testing_object.h`: Added `CustomAnyHash`/`CustomAnyEqual` static methods to `TInt` and `TFloat`. Registered them as `__any_hash__`/`__any_equal__` type attributes. Moved `TFloatObj::RegisterReflection` out-of-line to add type attr registration.
- `tests/cpp/test_any.cc`: Added `CustomAnyHash` and `CustomAnyEqual` test cases covering both OpaquePtr and Function branches.

## Public surface changes (if any)
- API: New extension point -- object types can now register `__any_hash__` and `__any_equal__` type attributes to customize `AnyHash`/`AnyEqual` behavior.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/cpp/test_any.cc` (2 new tests), `tests/cpp/testing_object.h` (updated test objects)
- How to verify manually: Build with `-DTVM_FFI_BUILD_TESTS=ON` and run ctest
- CI impact: none beyond new tests

## Risk & rollout notes
- Risk level: medium -- Changes core hash/equal logic in `AnyHash`/`AnyEqual` which is used by all container operations. The lookup is guarded by type index checks and only triggers for registered object types.
- Rollout/migration: none
- Follow-ups: Used by StructuralKey in a subsequent commit.
