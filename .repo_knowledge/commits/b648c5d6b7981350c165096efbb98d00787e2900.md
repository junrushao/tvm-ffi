# b648c5d -- feat: add DFS-based ffi.ReprPrint for unified object repr (#454)

## TL;DR
- New C++ `ffi.ReprPrint` function produces human-readable repr for any TVM FFI value using DFS traversal
- DAG deduplication via 3-state tracking (NotVisited/InProgress/Done); cycles shown as `...`
- All Python `__repr__` methods on containers and objects now delegate to this single C++ function
- Removed the old Python-side `method_repr` code generator from dataclasses

## Why (intent / motivation)
- Previously, each container type and user object class had its own `__repr__` implementation, leading to inconsistent formatting
- The old Python `method_repr` used `exec()` to generate repr methods, which was fragile and hard to maintain
- A unified C++ repr function handles all types consistently, including proper DAG/cycle detection

## What changed (facts from diff)
- New C++ file `src/ffi/extra/repr_print.cc` (+390 lines): DFS-based repr with 3-state tracking; built-in formatters for primitives, String, Bytes, Tensor, Shape, Array, List, Map; reflection-based repr for user objects; cycle detection showing `...`; optional address display via `TVM_FFI_REPR_WITH_ADDR=1` env var
- `CMakeLists.txt`: Added `repr_print.cc` to build
- `include/tvm/ffi/c_api.h`: Added `kTVMFFIFieldFlagBitMaskReprOff = 1 << 6` flag for excluding fields from repr
- `include/tvm/ffi/reflection/registry.h`: Added `Repr` InfoTrait class for per-field repr control; added `type_attr::kRepr = "__ffi_repr__"` for custom repr methods
- `python/tvm_ffi/cython/object.pxi`: `__object_repr__` now lazy-loads and calls `ffi.ReprPrint`; falls back to address-based repr on error
- `python/tvm_ffi/container.py`: `Array.__repr__`, `List.__repr__`, `Map.__repr__` all delegate to `core.__object_repr__`
- `python/tvm_ffi/dataclasses/_utils.py`: Removed `method_repr` function (40 lines of exec-based code generation)
- `python/tvm_ffi/dataclasses/c_class.py`: Removed `method_repr` usage; repr is now handled by the C++ repr function
- `python/tvm_ffi/dataclasses/field.py`: Added `Repr` to `FIELD_INFO_TRAIT_MAP` for `repr` field option
- `python/tvm_ffi/_ffi_api.py`: Added `ReprPrint` stub
- `tests/python/test_repr.py` (+581 lines): Comprehensive tests for primitives, containers, user objects, DAGs, cycles, `TVM_FFI_REPR_WITH_ADDR`

## Public surface changes (if any)
- API: New `ffi.ReprPrint` global function; new `Repr(bool)` InfoTrait; new `kTVMFFIFieldFlagBitMaskReprOff` flag; removed `method_repr` from dataclasses

- Data formats/schemas: Repr output format changed for Array (parenthesized tuples), List (brackets), Map (braces)
