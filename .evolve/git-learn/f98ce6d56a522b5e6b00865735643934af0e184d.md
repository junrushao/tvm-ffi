# Skill /git-learn - Self-Evolution
- **Grouping parameters**: MAX_LOC_PER_GROUP=5000 was slightly tight for this repo -- 3 exception groups (15328, 6204, 6650 LOC) needed single-commit isolation. MAX_COMMITS_PER_GROUP=100 was never hit. MAX_TIME_SPAN_SECONDS was the binding constraint for later groups. Parameters were appropriate overall.
- **Pipeline bottleneck**: Commit-distill was the slowest phase (~10-17 min per group), especially for large groups (30+ commits) where it reads many ledger files. Commit-ledger fan-out was efficient with worktree isolation.
- **Cross-skill patterns**: Batch ledger agents (processing 10-18 commits sequentially in one agent) were effective for reducing agent spawn overhead. Combining small adjacent groups for distill (G29+G30, G31+G32) saved time without quality loss.
- **Distillation coverage**: Coverage looks complete. All 22 design docs, 27 ADRs, and 14 API indexes were created/updated across 32 distill runs. No design fell through the cracks.
- **Suggested skill changes**: None.
