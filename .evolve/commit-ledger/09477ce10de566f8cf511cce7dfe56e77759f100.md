# Skill /commit-ledger - Self-Evolution
- **Procedure friction**: The large-bringup path says "skip file-by-file narration" and use "(a) consumed, (b) produced, (c) divergences" -- this worked well for this 42-file commit. However, the Key Exports section template does not differentiate between sub-crates in a multi-crate workspace, making it harder to structure the output. Had to improvise sub-headings by crate.
- **Template gap**: No section for "crate/package architecture" -- for multi-crate workspaces the dependency graph between crates is important design information that does not fit cleanly into Key Exports or Design Elements.
- **Wasted effort**: None -- large-bringup shape matched well.
- **Suggested skill change**: Add an optional "Package Architecture" subsection under Key Exports for large-bringup commits that introduce new packages/crates/modules, to capture inter-package dependency graphs.
