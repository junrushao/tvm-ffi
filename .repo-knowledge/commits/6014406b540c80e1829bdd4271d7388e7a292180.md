# 6014406 — [FFI] AudoDLPack compatible with torch stream context (#18217)

## TL;DR
- Updates the `benchmark_dlpack.py` script to benchmark auto-DLPack conversion under a non-default CUDA stream context.
- Adds a JIT-compiled C++ extension (`load_torch_get_current_cuda_stream`) to efficiently query the current CUDA stream from torch, bypassing Python overhead.
- Benchmarks both default-stream and non-default-stream paths for the torch stream query.

## Why (intent / motivation)
- FFI functions need to be compatible with stream-based executions. The benchmark demonstrates the overhead of querying torch's current CUDA stream via Python vs. a native C++ extension path.
- First-load may be slow due to JIT compilation; subsequent invocations use cached modules.

## What changed (facts from diff)
- `scripts/benchmark_dlpack.py`: Added `stream=True` parameter to `tvm_ffi_nop_autodlpack_from_torch`; added `load_torch_get_current_cuda_stream()` (torch cpp_extension JIT), `torch_get_cuda_stream_native()`, and `bench_torch_get_current_stream()`; added benchmark invocations for both default and non-default streams.
