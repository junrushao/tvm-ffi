# 639cc63 — chore(ci): Run wheel testing per-mainline-commit (#337)

## TL;DR
- Extracts the wheel-building logic into a reusable composite action `.github/actions/build-wheel-for-publish/action.yml`.
- Adds a `build-wheels` job to `ci_mainline_only.yml` that runs on every mainline commit.
- Removes the nightly cron trigger from `publish_wheel.yml`; publish workflow now only triggers on manual `workflow_dispatch` with an explicit `tag` input.
- Consolidates the separate `build_sdist` job into the `build_wheels` matrix.

## Why (intent / motivation)
- The nightly cron was wasteful on days without new commits and missed days with multiple commits. Per-commit wheel tests catch breakage sooner.

## What changed (facts from diff)
- `.github/actions/build-wheel-for-publish/action.yml` (new): Composite action that installs Python 3.8 (macOS arm64), checks out source, runs C++ tests, builds wheels, and optionally builds an sdist.
- `.github/workflows/ci_mainline_only.yml`: Adds `build-wheels` matrix job for all supported platforms using the new composite action.
- `.github/workflows/publish_wheel.yml`: Removes nightly cron, renames `branch` input to `tag`, removes standalone `build_sdist` job (now inline in the matrix), refactors to use the composite action.
- `.gitignore`: Allows `.github/actions/build-wheel-for-publish/` to bypass the `build-*` ignore pattern.
