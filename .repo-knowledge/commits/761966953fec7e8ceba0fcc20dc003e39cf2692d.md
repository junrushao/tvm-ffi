# 7619669 — chore: Switch from mypy to ty (#432)

## TL;DR
- Replaces `mypy` with `ty` (Astral's new type checker) as the pre-commit type-checking hook
- Updates `pyproject.toml` to use `ty` configuration instead of mypy settings
- Adds `uv sync` step to CI before pre-commit so that `ty` runs in the project's own environment
- Touches many Python source files to fix type annotations that `ty` is stricter about

## Why (intent / motivation)
- `ty` is significantly faster than `mypy` and integrated with the Astral toolchain (`uv`, `ruff`)
- More accurate type inference catches issues that mypy was missing

## What changed (facts from diff)
- `.pre-commit-config.yaml`: Replaces `mirrors-mypy` hook with a local `ty check` hook using `uvx`; also removes `yamllint` and `taplo-format` hooks
- `.github/workflows/ci_test.yml`: Adds `uv sync --group dev` step before pre-commit to set up environment
- `CONTRIBUTING.md`: Updates "type checking" note from mypy to ty
- `pyproject.toml`: Replaces mypy config section with `[tool.ty]` configuration (+28/-23)
- Many Python files (`__init__.py`, `_convert.py`, `_tensor.py`, `container.py`, `error.py`, etc.): Minor type annotation adjustments to satisfy `ty`'s stricter checks
- Test files similarly updated
