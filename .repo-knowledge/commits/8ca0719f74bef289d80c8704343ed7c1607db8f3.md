# 8ca0719 — [ABI] Introduce ShapeView Minimize TensorObj exposure (#67)

## TL;DR
- Introduces `ffi::ShapeView`, a lightweight non-owning view over a shape array (mirrors `ShapeObj` but without heap allocation).
- Converts `Tensor::shape()` and `Tensor::strides()` to return `ShapeView` instead of `Shape`, eliminating redundant allocations.
- Adds `Tensor::data_ptr()`, `Tensor::ndim()`, and `Tensor::numel()` convenience helpers.
- Minimizes `TensorObj` ABI exposure: removes `shape_data_` / `strides_data_` / `cached_dl_managed_tensor_versioned_` fields; shape/strides stored inline after the object in memory.

## Why (intent / motivation)
- Reducing `TensorObj` fields makes future ABI changes more stable; inlining shape/strides eliminates a secondary heap allocation per tensor; `ShapeView` avoids managed copy overhead when only read access is needed.

## What changed (facts from diff)
- `ShapeView` class added to `include/tvm/ffi/container/shape.h` with `data()`, `size()`, `operator[]`, `at()`, `begin/end`, `front/back`, `empty`, `Product()`.
- `Shape::operator ShapeView()` implicit conversion added; `Shape(ShapeView)` constructor added.
- `Shape::StridesFromShape` signature changed from `(const int64_t*, int64_t)` to `(ShapeView)`.
- `details::MakeStridesFromShape` and new `details::FillStridesFromShape` helper added.
- `TensorObj`: removed `shape_data_`, `strides_data_`, `cached_dl_managed_tensor_versioned_` member fields and associated destructor logic.
- `TensorObjFromNDAlloc`: shape/strides now inlined after struct via `make_inplace_array_object`.
- `TensorObjFromDLPack`: extra strides stored at tail when source lacks strides.
- `Tensor::shape()` and `Tensor::strides()` return `ShapeView`; `ToDLPackVersioned` simplified (no CAS cache).
- Version bumped to `0.1.0b10`.

## Public surface changes (if any)
- API: `Tensor::shape()` and `Tensor::strides()` now return `ShapeView` (not `Shape`). `Tensor::data_ptr()`, `Tensor::ndim()`, `Tensor::numel()` added. `Shape::StridesFromShape(ShapeView)` signature changed.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification

- How to verify manually: `cmake . -B build_test -DTVM_FFI_BUILD_TESTS=ON && cmake --build build_test && ctest --test-dir build_test`
- CI impact: none

## Risk & rollout notes
- Risk level: medium — changes `Tensor::shape()` return type (source-breaking if callers expect `Shape`); TensorObj internal layout changed.
- Rollout/migration: Callers that assigned `Tensor::shape()` to `Shape` will need updating if they call `Shape`-only methods; `ShapeView` is implicitly convertible to `Shape`.
- Follow-ups: none
