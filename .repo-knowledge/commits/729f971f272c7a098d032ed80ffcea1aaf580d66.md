# 729f971 — [Docs] Add Rust Docs (#160)

## TL;DR
- Adds a comprehensive Rust guide (`docs/guides/rust_guide.md`) covering installation, basic usage, advanced topics, and examples.
- Adds a new `docs/reference/rust/index.rst` landing page for Rust API reference.
- Extends `docs/conf.py` to optionally build Rust docs via `cargo doc` when `BUILD_RUST_DOCS=1`.
- Updates `rust/tvm-ffi-sys/build.rs` to gracefully skip linking when building docs (rustdoc build).

## Why (intent / motivation)
- The Rust bindings lacked any documentation or tutorials; this PR closes that gap with a complete guide and hooks for API reference generation.

## What changed (facts from diff)
- New `docs/guides/rust_guide.md` (217 lines) covering prerequisites, Cargo.toml setup, loading modules, working with tensors, calling functions, global functions, type-erased functions, and error handling.
- New `docs/reference/rust/index.rst` listing all three crates (`tvm-ffi`, `tvm-ffi-sys`, `tvm-ffi-macros`).
- `docs/conf.py` gains `_build_rust_docs()` function that runs `cargo doc --no-deps --workspace` and copies output; detects `sphinx-autobuild` to allow incremental rebuilds.
- `docs/README.md` extended with instructions for `BUILD_RUST_DOCS=1` usage.
- `rust/tvm-ffi-sys/build.rs` now detects rustdoc builds (`RUSTDOC`/`CARGO_CFG_DOC` env vars) and returns early instead of panicking when `tvm-ffi-config` is unavailable.
