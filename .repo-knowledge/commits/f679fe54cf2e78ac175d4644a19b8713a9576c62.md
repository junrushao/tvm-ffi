# f679fe5 — [ABI] Refactor the TVMFFIEnvTensorAllocator to align with DLPack (#131)

## TL;DR
- Renames `TVMFFIEnvSetTensorAllocator` -> `TVMFFIEnvSetDLPackManagedTensorAllocator` and `TVMFFIEnvGetTensorAllocator` -> `TVMFFIEnvGetDLPackManagedTensorAllocator`.
- Introduces new `TVMFFIEnvTensorAlloc(DLTensor*, TVMFFIObjectHandle*)` C API that allocates a `ffi::Tensor` directly and keeps metadata allocation in `libtvm_ffi`.
- Replaces `Tensor::FromDLPackAlloc(allocator, shape, dtype, device)` with `Tensor::FromEnvAlloc(TVMFFIEnvTensorAlloc, shape, dtype, device)`.
- Bumps version to 0.1.0b19.

## Why (intent / motivation)
- Aligning function names with DLPack conventions improves interoperability. The new `TVMFFIEnvTensorAlloc` keeps tensor object metadata allocated inside `libtvm_ffi` rather than the caller's library, avoiding the module unloading order problem (object deleter in unloaded library).

## What changed (facts from diff)
- `include/tvm/ffi/extra/c_env_api.h`: New `TVMFFIEnvTensorAlloc` declaration; renamed set/get allocator functions.
- `include/tvm/ffi/container/tensor.h`: `FromDLPackAlloc` replaced by `FromEnvAlloc(int (*env_alloc)(DLTensor*, TVMFFIObjectHandle*), ...)` with simplified implementation.
- `src/ffi/extra/env_context.cc`: Implements `TVMFFIEnvTensorAlloc`; renamed other functions.
- `pyproject.toml`: Version bumped to 0.1.0b19; `torch` dependency excludes Windows.
- `python/tvm_ffi/cython/tvm_ffi_python_helpers.h`: Updated calls to use renamed function.
- `rust/tvm-ffi-sys/src/c_env_api.rs`: Renamed bindings.
- `tests/cpp/extra/test_c_env_api.cc`: New test file for `TVMFFIEnvTensorAlloc`.
- `tests/cpp/test_tensor.cc`, `tests/python/test_load_inline.py`: Updated to use new API.

## Risk & rollout notes
- Risk level: high — breaking ABI rename across C, C++, Python, and Rust; any code using old names will fail to compile/link.
- Rollout/migration: Replace `TVMFFIEnvSetTensorAllocator` -> `TVMFFIEnvSetDLPackManagedTensorAllocator`; `TVMFFIEnvGetTensorAllocator` -> `TVMFFIEnvGetDLPackManagedTensorAllocator`; `Tensor::FromDLPackAlloc` -> `Tensor::FromEnvAlloc`.
- Follow-ups: Freeze API before formal release.
