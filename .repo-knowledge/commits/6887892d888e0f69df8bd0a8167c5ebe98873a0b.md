# 6887892 — chore: Use `importlib.metadata` to locate DSOs (#306)

## TL;DR
- Rewrites `python/tvm_ffi/libinfo.py` to use `importlib.metadata` (via the package `RECORD` file) as the primary DSO discovery mechanism, with a fallback to env-variable-based path search.
- Introduces `tvm_ffi.libinfo.load_lib_ctypes(package, target_name, mode)` as a reusable helper for downstream libraries.
- Deletes `python/tvm_ffi/base.py`; library loading is now triggered directly in `__init__.py` via `libinfo.load_lib_ctypes`.
- Adds `test_libinfo.py` with 9 new test cases covering all `tvm-ffi-config` flags.

## Why (intent / motivation)
- Fixes issue #250: old path-guessing approach was unreliable in certain wheel installations.
- `importlib.metadata` RECORD lookup is the canonical, packaging-standard way to locate installed files.

## What changed (facts from diff)
- `python/tvm_ffi/libinfo.py`: completely reworked; primary search via `im.distribution(package).read_text("RECORD")`; fallback searches `build/lib`, `lib`, and PATH-related env vars; adds `load_lib_ctypes`, `find_windows_implib`, updated `find_source_path`, `find_cmake_path`, `find_include_path`, `find_dlpack_include_path`, `find_python_helper_include_path`.
- `python/tvm_ffi/base.py`: deleted.
- `python/tvm_ffi/__init__.py`: directly calls `libinfo.load_lib_ctypes("apache-tvm-ffi", "tvm_ffi", "RTLD_GLOBAL")`; exports `LIB`.
- `python/tvm_ffi/config.py`: internal `find_windows_implib` moved to `libinfo`; uses `_find_libdir()` helper.
- `tests/python/test_libinfo.py` (new): comprehensive test for all config CLI flags.

## Public surface changes (if any)
- API: `tvm_ffi.LIB` (new public export); `tvm_ffi.libinfo.load_lib_ctypes` (new); `tvm_ffi.libinfo.find_windows_implib` (moved from `config.py`); `tvm_ffi.base` module removed
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/python/test_libinfo.py` (new, 119 lines)
- How to verify manually: `uv run pytest -vvs tests/python/test_libinfo.py`
- CI impact: new test file added to Python suite

## Risk & rollout notes
- Risk level: medium — changes library loading path; if `importlib.metadata` RECORD is missing or malformed, fallback is used
- Rollout/migration: code importing `tvm_ffi.base` must switch to `tvm_ffi.libinfo`
- Follow-ups: `find_source_path` now checks for `src/` directory instead of `cmake/` (fixed in next commit #319)
