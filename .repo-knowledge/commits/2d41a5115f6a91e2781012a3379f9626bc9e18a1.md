# 2d41a51 — [FFI][REFACTOR] Establish tvm_ffi python module (#18226)

## TL;DR
- Establishes `tvm_ffi` as a standalone, installable Python package with Cython bindings (`python/tvm_ffi/`).
- Adds `pyproject.toml` using scikit-build-core for Python packaging with Cython support.
- Adds `examples/get_started/` with a minimal CPU/CUDA example showing end-to-end FFI usage.
- Adds a comprehensive Python test suite (`tests/python/`).
- Adds `libbacktrace` as a git submodule (`3rdparty/libbacktrace`) and integrates it into the build.
- Improves traceback setup in `src/ffi/error.cc` / `traceback.cc`.

## Why (intent / motivation)
- Decouples `tvm_ffi` from the main TVM compiler, allowing lightweight ML library plugins to depend only on `tvm_ffi` without the full TVM runtime/compiler stack.
- Enables `pip install ./ffi` workflow for users and downstream packages.
