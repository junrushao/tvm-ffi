## TL;DR

Rewrites the Python FFI call mechanism for performance by introducing a C++ header `tvm_ffi_python_helpers.h` with a `TVMFFIPyCallManager` thread-local dispatch cache, a `TVMFFIPyArgSetter` function pointer struct, and a `TVMFFIPyArgSetterFactory` type-dispatch mechanism. Adds the `__dlpack_c_exporter__` attribute protocol for C-level fast-path DLPack export. Refactors `function.pxi` to use individual per-type `TVMFFIPyArgSetterXXX_` Cython functions dispatched through the factory.

## Why

The previous Python-to-C FFI call path used a single large `make_args` function with per-argument type dispatch via Python isinstance checks. For high-frequency calls with tensor arguments, the repeated Python-level dispatch was a significant overhead. The new design caches the dispatch function pointer per Python type in a thread-local `std::unordered_map`, amortizing the dispatch cost across calls with the same argument types.

## What changed

- `python/tvm_ffi/cython/tvm_ffi_python_helpers.h` (new, 447 lines): C++ header defining:
  - `TVMFFIPyCallContext`: holds `packed_args`, device, stream, and temporary objects.
  - `TVMFFIPyArgSetter`: struct with function pointer `setter` + optional DLPack exporter pointer.
  - `TVMFFIPyCallManager`: thread-local manager with `std::unordered_map<PyTypeObject*, TVMFFIPyArgSetter>` dispatch table.
  - `TVMFFIPyArgSetterFactory`: function dispatching to the correct setter based on Python type.
- `python/tvm_ffi/cython/function.pxi`: Refactored to use per-type `TVMFFIPyArgSetterXXX_` Cython setter functions dispatched via `TVMFFIPyArgSetterFactory_` lookup.
- `python/tvm_ffi/cython/base.pxi`: Added C declarations for new helper types.
- `python/tvm_ffi/cython/tensor.pxi`: Added `__dlpack_c_exporter__` attribute support for C-level fast-path export.
- `include/tvm/ffi/container/tensor.h`: Minor additions to support C exporter protocol.
- `src/ffi/extra/testing.cc`: `testing.nop` function no longer echoes first argument as return value.
- `CMakeLists.txt`: Updated to include new header.
- `scripts/benchmark_dlpack.py`: Updated to exercise new call path.

## Public surface changes

- New `__dlpack_c_exporter__` attribute protocol: tensor-like objects can expose this to enable C-level fast DLPack export.
- `testing.nop` behavior changed: no longer returns first argument.
- New C++ types in Cython headers: `TVMFFIPyCallManager`, `TVMFFIPyArgSetter`, `TVMFFIPyArgSetterFactory` (internal).

## Tests & verification

Existing tests updated where `testing.nop` behavior changed. Benchmark script updated to exercise new dispatch path.

## Risk & rollout notes

Medium risk. Major internal refactor of the Python call mechanism. Behavior should be identical for all existing call patterns; only internal dispatch strategy changes. The `testing.nop` behavior change may break tests that relied on it returning its first argument.
