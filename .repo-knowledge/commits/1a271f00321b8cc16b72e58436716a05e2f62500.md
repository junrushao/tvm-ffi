# 1a271f0 — [FFI] Make JSON Parser/Write fastmath safe (#18212)

## TL;DR
- Adds fallback implementations for NaN/Infinity detection and creation in the JSON parser and writer that work correctly under `-ffast-math` (where `std::isnan`, `std::isinf`, and `std::numeric_limits<double>::infinity()` may be optimized away).
- Uses static helper methods `FastMathSafePosInf()`, `FastMathSafeNegInf()`, `FastMathSafeNaN()` in the parser and `FastMathSafeIsNaN()`, `FastMathSafeIsInf()` in the writer.
- Updates JSON parser tests to use the same fast-math-safe helpers.

## Why (intent / motivation)
- When compiling with `-ffast-math`, the compiler may treat NaN/Inf as non-existent, breaking JSON round-trips for these special values. Adding `#ifdef __FAST_MATH__` guards with bit-level implementations ensures correctness regardless of the optimization flag.

## What changed (facts from diff)
- `src/ffi/extra/json_parser.cc`: Replaced direct `std::numeric_limits<double>::infinity()` and `std::numeric_limits<double>::quiet_NaN()` calls with `FastMathSafe*()` helpers; added three `static` helper methods using bit-cast via pointers.
- `src/ffi/extra/json_writer.cc`: Replaced `std::isnan(value)` and `std::isinf(value)` with `FastMathSafeIsNaN(value)` and `FastMathSafeIsInf(value)`; added two static helper methods with bit-level IEEE 754 checks under `__FAST_MATH__`.
- `tests/cpp/extra/test_json_parser.cc`: Added free helper functions `FastMathSafeIsNaN` / `FastMathSafeIsInf`; replaced `std::isnan`/`std::isinf` in test assertions.
