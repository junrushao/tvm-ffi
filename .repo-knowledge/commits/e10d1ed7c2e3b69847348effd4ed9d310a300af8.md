# e10d1ed — doc: Migrate `.pyi` docstrings into Cython (#175)

## TL;DR
- Moves docstrings from `.pyi` stub files into the corresponding Cython `.pxi` source files so Sphinx autodoc can pick them up.
- Trims `python/tvm_ffi/core.pyi` from ~530+ lines to ~46 lines.
- Updates `docs/conf.py` and `docs/reference/python/index.rst` to properly expose the Cython classes.

## Why (intent / motivation)
- Sphinx autodoc does not read `.pyi` files; all docstrings must live in the actual source (`.pyx`/`.pxi`). The large `core.pyi` was the authoritative docstring source, which meant docs were never generated.

## What changed (facts from diff)
- `python/tvm_ffi/cython/device.pxi`, `dtype.pxi`, `error.pxi`, `function.pxi`, `object.pxi`, `string.pxi`, `tensor.pxi`, `type_info.pxi`: Docstrings added/migrated to classes, methods, and properties.
- `python/tvm_ffi/core.pyi`: Reduced to minimal type-annotation stubs (~46 lines); docstrings removed.
- `python/tvm_ffi/__init__.py`: Minor adjustments to expose classes for autodoc.
- `docs/conf.py`: Updated to correctly configure autodoc for Cython-generated modules.
- `docs/reference/python/index.rst`: Updated automodule directives.
