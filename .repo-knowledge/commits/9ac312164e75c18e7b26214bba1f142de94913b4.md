# 9ac3121 — [CPP] Remove static line based object reg in favor of ObjectDef (#116)

## TL;DR
- Removes the `static inline int32_t _register_type_index = _GetOrAllocRuntimeTypeIndex()` auto-registration from `TVM_FFI_DECLARE_OBJECT_INFO_STATIC` and the dynamic variant.
- Static built-in types are now explicitly reserved at runtime startup via `ReserveDepthOneObjectTypeIndex`.
- Dynamic types must now be explicitly registered via `reflection::ObjectDef<T>()` or `T::_GetOrAllocRuntimeTypeIndex()`.
- Adds `StaticTypeKey::kTVMFFIError` constant.

## Why (intent / motivation)
- Auto-registration triggered from every DLL that includes the header caused unnecessary binary size overhead.
- Explicit registration through `ObjectDef` is cleaner and predictable; types that don't need dynamic casting don't need registration.

## What changed (facts from diff)
- `include/tvm/ffi/object.h`: `TVM_FFI_DECLARE_OBJECT_INFO_STATIC` macro now uses `[[maybe_unused]]` on `tindex` and returns the static `_type_index` instead of the dynamically registered value; the `static inline _register_type_index` line is removed. The dynamic `TVM_FFI_DECLARE_OBJECT_INFO` also has its `static inline _type_index` self-init removed.
- `src/ffi/object.cc`: Startup now explicitly calls `ReserveDepthOneObjectTypeIndex` for all depth-1 static types (Str, Bytes, Error, Function, Shape, Tensor, Array, Map, Module, OpaquePyObject).
- `src/ffi/container.cc`: Removed `#include <tvm/ffi/container/shape.h>`.
- `tests/cpp/test_object.cc`, `test_reflection.cc`: Updated to use `RuntimeTypeIndex()` instead of `_type_index`.

## Public surface changes (if any)
- API: `_type_index` static member no longer auto-registers type; callers must explicitly register via `ObjectDef` or `_GetOrAllocRuntimeTypeIndex()`.
- Flags/config: none
- Data formats/schemas: none

## Risk & rollout notes
- Risk level: medium — any downstream code that declares objects without registering through `ObjectDef` will lose dynamic casting; must explicitly register.
- Rollout/migration: Add `reflection::ObjectDef<T>()` registration for all custom objects that need dynamic casting.
