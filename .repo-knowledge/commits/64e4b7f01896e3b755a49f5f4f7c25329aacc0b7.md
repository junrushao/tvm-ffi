# 64e4b7f — chore: Modernize pre-commit hooks (#19)

## TL;DR
- Introduces a comprehensive set of pre-commit hooks replacing the old `task_lint.sh`-based lint approach.
- Adds hooks for `ruff-check`, `ruff-format`, `clang-format`, `cython-lint`, `shfmt`, `shellcheck`, ASF header and filetype checks.
- Updates CI to use native pre-commit hooks in the lint stage, and makes the test stage depend on lint.
- Applies broad code formatting changes across Python, Cython, C++ headers, docs, and scripts.

## Why (intent / motivation)
- The old shell-script-based linting was difficult to maintain and run consistently across developer machines and CI. Migrating to pre-commit hooks standardizes the process and enables per-hook control.
