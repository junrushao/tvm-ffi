# 9c0b869 — doc(python): Add example coverage to docstrings (#206)

## TL;DR
- Adds copy-pastable `Examples` blocks to nearly every public Python API (`dtype`, `convert`, `Array`, `Map`, `AccessPath`, `registry`, `module`, `serialization`, `stream`, `lockfile`, and Cython Pyx classes)
- Polishes wording and fixes typos across all touched docstrings
- Adds `get_raw_stream` and individual `serialization`/`access_path` members to the Sphinx reference index
- Registers `testing.add_one` as a system-lib symbol in C++ testing code to support the new `system_lib` example

## Why (intent / motivation)
- Public API surface had little or no example code, making it difficult for new users to learn usage patterns
- Some existing examples were not import-complete and could not be copy-pasted directly

## What changed (facts from diff)
- `_convert.py`: `convert()` docstring gains a full set of type-conversion examples
- `_dtype.py`: `dtype`, `dtype.from_dlpack_data_type`, `dtype.with_lanes`, `.itemsize`, `.type_code`, `.bits`, `.lanes` all gain `Examples` and `See Also` sections
- `_tensor.py`: `Shape` and `device()` docstrings gain `import tvm_ffi` line
- `access_path.py`: `AccessPath` class and `AccessPath.root()` gain full docstrings with examples
- `container.py`: `Array` and `Map` examples updated to use direct constructors instead of `tvm_ffi.convert`
- `cython/device.pxi`: `DLDeviceType` gets a proper hyperlink reference; `Device` example gains `import tvm_ffi`
- `cython/function.pxi`: `Function` See Also uses proper Sphinx `:py:func:` cross-references
- `cython/object.pxi`: Object examples add `import tvm_ffi.testing`
- `cython/tensor.pxi`: `from_dlpack` and `Tensor` examples add `import tvm_ffi`
- `error.py`: `register_error` example updated to use `tvm_ffi` API and demonstrate round-trip
- `module.py`: `system_lib()` docstring completely rewritten with C++ and Python code examples; `load_module` gains `import` lines; `implements_function` note fixed
- `registry.py`: `get_global_func`, `remove_global_func`, `get_global_func_metadata` gain examples
- `serialization.py`: module docstring and `to_json_graph_str`/`from_json_graph_str` gain examples

- `docs/reference/python/index.rst`: adds `get_raw_stream`, `serialization.from_json_graph_str`, `serialization.to_json_graph_str`, `access_path.AccessKind`, `access_path.AccessPath`, `access_path.AccessStep`
