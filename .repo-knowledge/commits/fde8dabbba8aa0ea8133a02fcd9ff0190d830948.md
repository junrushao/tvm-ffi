# fde8dab — [CYTHON] Fix stream passing bug (#68)

## TL;DR
- Fixes a bug in Cython DLPack argument setter where `ctx.device_id` was checked instead of `ctx.device_type` to determine if device had been queried.
- Adds a regression test in `test_load_inline_cuda` that verifies the stream passed via DLPack matches the actual CUDA stream.

## Why (intent / motivation)
- The wrong field check caused stream passing to be skipped even when the device had not yet been queried, breaking expected CUDA stream forwarding behavior.

## What changed (facts from diff)
- `function.pxi`: condition changed from `if ctx.device_id != -1` to `if ctx.device_type != -1` in `TVMFFIPyArgSetterDLPackCExporter_`.
- `tests/python/test_load_inline.py`: test function `test_load_inline_cuda` updated to pass `raw_stream` as extra int64 argument; C++ source asserts `TVMFFIEnvGetStream(...)` equals `raw_stream`; test now also exercises a `torch.cuda.Stream` context manager path.
- Version bumped to `0.1.0b11`.
