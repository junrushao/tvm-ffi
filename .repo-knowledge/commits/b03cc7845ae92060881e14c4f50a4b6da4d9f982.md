# b03cc78 — [TORCH] robustify torch jit module support for earlier ver (#53)

## TL;DR
- Guards `kDLFloat4_e2m1fn` handling in the torch DLPack extension behind `TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` to avoid compile errors on earlier torch versions
- Bumps package version from `0.1.0b6` to `0.1.0b7`

## Why (intent / motivation)
- The `Float4_e2m1fn` scalar type was introduced in PyTorch 2.8; earlier versions do not have this type and would fail to compile when the extension is included

## What changed (facts from diff)
- `python/tvm_ffi/_optional_torch_c_dlpack.py`: `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` guard added around `kDLFloat4_e2m1fn` case blocks (both in `getDLDataTypeForDLPackv1` and `toScalarTypeForDLPackv1`)
- `pyproject.toml`: version bumped to `0.1.0b7`
