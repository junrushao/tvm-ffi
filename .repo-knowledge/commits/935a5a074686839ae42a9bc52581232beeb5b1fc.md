# 935a5a0 — [ABI] Stablize doc and metadata for functions (#79)

## TL;DR
- Renames `type_schema` to `metadata` in `TVMFFIFieldInfo` and `TVMFFIMethodInfo` C ABI structs.
- Adds `GetFunctionDoc` virtual method to `ModuleObj` (separate unstructured docstring from structured metadata).
- Exposes `ffi.ModuleGetFunctionDoc` global function.

## Why (intent / motivation)
- Separating docstring (`doc`) from structured metadata clarifies their purpose: docstrings are unstructured and potentially large; metadata stores focused structured JSON. Renaming `type_schema` to `metadata` reflects that it can hold arbitrary JSON, not only type schemas.

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: `TVMFFIFieldInfo.type_schema` → `metadata`; `TVMFFIMethodInfo.type_schema` → `metadata`; added rationale comment.
- `include/tvm/ffi/extra/module.h`: added `virtual Optional<String> GetFunctionDoc(const String& name)` and `GetFunctionDoc(name, query_imports)` to `ModuleObj`.
- `include/tvm/ffi/reflection/registry.h`: `info.type_schema` → `info.metadata` in `GlobalDef` and `ObjectDef` builders.
- `python/tvm_ffi/cython/base.pxi`: `TVMFFIFieldInfo.type_schema` → `metadata`; `TVMFFIMethodInfo.type_schema` → `metadata`.
- `src/ffi/function.cc`: `type_schema_data` → `metadata_data` in `GlobalFunctionTable::Entry`.
- `src/ffi/object.cc`: `TypeTable` field/method copy updated.
- `src/ffi/extra/module.cc`: `GetFunctionDoc` implementation added; `ffi.ModuleGetFunctionDoc` registered.

## Public surface changes (if any)
- API: `TVMFFIFieldInfo.metadata` (was `type_schema`), `TVMFFIMethodInfo.metadata` (was `type_schema`) — ABI-breaking rename. `ModuleObj::GetFunctionDoc` new virtual method.

- Rollout/migration: Rename all `type_schema` field accesses to `metadata`.
