# c1af3b3 — [FEAT] Introduce mutable Dict (#463)

## TL;DR
- Introduces `Dict`, a mutable map container sharing the same base class (`MapObj` from `map_base.h`) as the immutable `Map`.
- Adds Python `tvm_ffi.Dict` class with full `MutableMapping` interface, mirroring the `List` vs `Array` relationship.
- Registers `kTVMFFIDict` type index in the C ABI.
- Exposes Dict operations as global functions: `DictSetItem`, `DictDelItem`, `DictClear`, `DictPopItem`, `DictUpdate`.

## Why (intent / motivation)
- `Map` is immutable (copy-on-write). A mutable map was needed for cases where shared-reference mutation semantics are desirable, completing the mutable-container story alongside `List`.

- New header `include/tvm/ffi/container/dict.h` (+374 lines): `DictObj` and `Dict` ref wrapper with mutating operations (`Set`, `Del`, `Clear`, `PopItem`, `Update`).
