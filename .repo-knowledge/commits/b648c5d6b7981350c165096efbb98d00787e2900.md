# b648c5d — feat: add DFS-based ffi.ReprPrint for unified object repr (#454)

## TL;DR
- Introduces a single C++ `ffi.ReprPrint` function producing human-readable repr for any TVM FFI value, with DFS cycle detection and DAG memoization.
- All Python `__repr__` methods delegate to this function (Array, List, Map, Object).
- Per-field `Repr(false)` InfoTrait excludes fields from repr output.
- Array repr format changes from `[1, 2, 3]` to `(1, 2, 3)` (tuple-style); Map string keys now use double quotes.
- Optional address display via `TVM_FFI_REPR_WITH_ADDR=1` env var.

## Why (intent / motivation)
- Repr was inconsistently implemented across Python classes (each had its own `__repr__`). Moving the logic to C++ ensures consistency, handles cycles/DAGs, and makes the format customizable per type via `__ffi_repr__` type attributes.

## What changed (facts from diff)
- New file `src/ffi/extra/repr_print.cc` (+390 lines): `ReprPrinter` class with 3-state DFS (NotVisited/InProgress/Done); built-in `__ffi_repr__` functions for String, Bytes, Tensor, Shape, Array, List, Map; `ffi.ReprPrint` global registration.
- `CMakeLists.txt`: adds `repr_print.cc` to build.
- `include/tvm/ffi/c_api.h`: new `kTVMFFIFieldFlagBitMaskReprOff = 1 << 6`.
- `include/tvm/ffi/reflection/registry.h`: new `Repr` InfoTrait and `type_attr::kRepr` constant.
- `python/tvm_ffi/cython/object.pxi`: `__object_repr__` now calls `ffi.ReprPrint` via lazy-loaded global; falls back to address repr on error.
- `python/tvm_ffi/container.py`: `Array.__repr__`, `List.__repr__`, `Map.__repr__` all delegate to `core.__object_repr__`.
- `python/tvm_ffi/dataclasses/_utils.py`: removes 40-line `method_repr` code-gen function.
- `python/tvm_ffi/dataclasses/c_class.py`: removes `repr` parameter; `fn_repr` no longer generated.
- `python/tvm_ffi/dataclasses/field.py`: removes `repr` parameter from `Field` and `field()`.
- `src/ffi/testing/testing.cc`: `TestCxxClassBase` fields `v_i64` and `v_i32` now use `Repr(false)`.
- `tests/python/test_container.py`: Array repr assertions updated from `[...]` to `(...)`.
- `tests/python/test_dataclasses_c_class.py`: 3 repr tests removed (superseded by `test_repr.py`).
- New `tests/python/test_repr.py` (+581 lines): 55 tests for primitives, containers, user objects, DAGs, cycles, `TVM_FFI_REPR_WITH_ADDR`.
