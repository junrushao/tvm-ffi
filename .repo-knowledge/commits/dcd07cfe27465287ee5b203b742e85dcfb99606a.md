# dcd07cf — [CMAKE] Allow explicitly turning dl off (#401)

## TL;DR
- Adds a new CMake option `TVM_FFI_USE_DL_LIBS` (default `ON`) to explicitly control whether `libdl` is linked
- When `OFF`, the `CMAKE_DL_LIBS` linkage for shared/static targets is skipped even if available
- Complements `TVM_FFI_USE_THREADS` from the previous commit for full cross-compilation control

## Why (intent / motivation)
- On certain embedded or cross-compilation targets `libdl` is unavailable; building without it previously required patching CMakeLists; an explicit opt-out flag is cleaner

## What changed (facts from diff)
- `CMakeLists.txt`: Added `option(TVM_FFI_USE_DL_LIBS ...)` near the top; updated the `if(TVM_FFI_USE_EXTRA_CXX_API AND CMAKE_DL_LIBS)` guard to also require `TVM_FFI_USE_DL_LIBS`

## Public surface changes (if any)
- API: none
- Flags/config: New CMake option `TVM_FFI_USE_DL_LIBS` (default `ON`)
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: none
- How to verify manually: `cmake . -DTVM_FFI_USE_DL_LIBS=OFF -B build_no_dl && cmake --build build_no_dl`
- CI impact: none for default builds

## Risk & rollout notes
- Risk level: low — default is `ON`; no change for existing build configurations
- Rollout/migration: Cross-compilation users without `libdl` should set `-DTVM_FFI_USE_DL_LIBS=OFF`
- Follow-ups: none
