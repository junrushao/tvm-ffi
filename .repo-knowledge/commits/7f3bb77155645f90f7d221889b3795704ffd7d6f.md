# 7f3bb77 — [DLPACK] Upgrade DLPack Exchange API to pass by capsule (#288)

## TL;DR
- Changes the `__c_dlpack_exchange_api__` attribute from an integer pointer to a PyCapsule, with backward compatibility for the integer form
- Adds `_get_dlpack_exchange_api()` Cython helper that accepts both int and PyCapsule
- Eagerly upgrades integer-form attributes to PyCapsule when loading the torch extension
- Updates tests to handle both forms

## Why (intent / motivation)
- Using a PyCapsule wrapping the pointer is safer and more Pythonic than passing raw integer pointers; backward compatibility is maintained while upgrading the exchange API

## What changed (facts from diff)
- `python/tvm_ffi/cython/tensor.pxi`: Added `_get_dlpack_exchange_api()` function that accepts both `int` and PyCapsule; used throughout
- `python/tvm_ffi/cython/function.pxi`: Changed `TVMFFIPyArgSetterFactory_` to use `_get_dlpack_exchange_api()` instead of direct int cast
- `python/tvm_ffi/_optional_torch_c_dlpack.py`: Added `_create_dlpack_exchange_api_capsule()` helper; on load, integer attributes are upgraded to PyCapsule; new installs set PyCapsule directly
- `addons/torch_c_dlpack_ext/torch_c_dlpack_ext/core.py`: Keeps integer assignment for backward compatibility; upgrade happens on tvm-ffi side
- `tests/python/test_cubin_launcher.py`: Added `_is_cuda_version_greater_than_13()` check and skip markers
- `tests/python/test_dlpack_exchange_api.py`: Updated to handle both PyCapsule and integer forms

## Public surface changes (if any)
- API: `torch.Tensor.__c_dlpack_exchange_api__` is now set to a PyCapsule (was integer); integer form still accepted
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/python/test_dlpack_exchange_api.py` (updated), `tests/python/test_cubin_launcher.py` (skip condition added)
- How to verify manually: `uv run pytest -vvs tests/python/test_dlpack_exchange_api.py`
- CI impact: Cubin launcher tests now skip unless CUDA > 13

## Risk & rollout notes
- Risk level: medium — changes the type of a class attribute used internally; backward compatibility maintained via fallback
- Rollout/migration: Code that reads `torch.Tensor.__c_dlpack_exchange_api__` as int needs updating (now PyCapsule); tvm-ffi handles both
- Follow-ups: Eventually remove integer fallback once all dependencies are updated
