# 9829dec — chore: cleanup old DLPack related defs (#129)

## TL;DR
- Removes obsolete `DLPackTensorAllocator` typedef and related forward declarations that are no longer needed after the migration to the latest DLPack standard.
- Renames all remaining uses to `DLPackManagedTensorAllocator` consistently across C++, Python/Cython, and Rust.

## Why (intent / motivation)
- The old `DLPackTensorAllocator` typedef was a temporary compatibility shim predating the final DLPack naming; removing it cleans up the API surface.

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: Removed `DLManagedTensorVersioned` forward declaration and `DLPackTensorAllocator` typedef.
- `include/tvm/ffi/container/tensor.h`: Renamed parameter type in `FromDLPackAlloc` from `DLPackTensorAllocator` to `DLPackManagedTensorAllocator`.
- `include/tvm/ffi/extra/c_env_api.h`: Renamed `TVMFFIEnvSetTensorAllocator`/`TVMFFIEnvGetTensorAllocator` signatures.
- `python/tvm_ffi/cython/base.pxi`: Removed old Cython typedef declarations for `DLPackFromPyObject`, `DLPackToPyObject`, `DLPackTensorAllocator`.
- `python/tvm_ffi/cython/tvm_ffi_python_helpers.h`: Removed old typedefs; updated internal variable type.
- `rust/tvm-ffi-macros/src/utils.rs`: Fixed unused variable warning.
- `rust/tvm-ffi-sys/src/c_env_api.rs`: Renamed `DLPackTensorAllocator` to `DLPackManagedTensorAllocator`.
- `src/ffi/extra/env_context.cc`: Renamed all internal uses.
- `tests/cpp/test_tensor.cc`: Renamed test allocator functions.
