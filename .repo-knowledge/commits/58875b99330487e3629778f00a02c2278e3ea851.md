# 58875b9 — [CMAKE] Fix Cmake when building as subdir (#112)

## TL;DR
- Changes one `${CMAKE_SOURCE_DIR}` reference to `${CMAKE_CURRENT_LIST_DIR}` in `CMakeLists.txt` so that `DetectTargetTriple.cmake` is found correctly when `tvm-ffi` is included as a CMake subdirectory of another project.

## Why (intent / motivation)
- `CMAKE_SOURCE_DIR` always refers to the top-level project's source directory; when `tvm-ffi` is embedded as a `add_subdirectory(...)` target, `CMAKE_SOURCE_DIR` points to the parent project root instead of `tvm-ffi`'s own root. Using `CMAKE_CURRENT_LIST_DIR` fixes this.

## What changed (facts from diff)
- `CMakeLists.txt`: `include(${CMAKE_SOURCE_DIR}/cmake/Utils/DetectTargetTriple.cmake)` → `include(${CMAKE_CURRENT_LIST_DIR}/cmake/Utils/DetectTargetTriple.cmake)`.
