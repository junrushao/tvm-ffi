# fc2630f — feat: Add a method to define initializer (#127)

## TL;DR
- Introduces `refl::init<Args...>` struct and a `ObjectDef::def(init<Args...>())` overload to register an `__ffi_init__` constructor method.
- Replaces the previous pattern of `def_static("__ffi_init__", refl::init<T, Args...>)`.
- Removes the old free-function `refl::init<T, Args...>(args...)` from the header.
- All testing objects and reflection tests updated to use the new pattern.

## Why (intent / motivation)
- Aligns the constructor registration API with nanobind/pybind11's `.def(py::init<Args...>())` convention, improving consistency and discoverability.

## What changed (facts from diff)
- `include/tvm/ffi/reflection/registry.h`: Added `struct init<Args...>` with private `execute<Class>(args...)` static method; added `ObjectDef::def(init<Args...>, Extra...)` overload that registers `__ffi_init__`; removed old free-function `init<T, Args...>`.
- `src/ffi/testing/testing.cc`: All `.def_static("__ffi_init__", refl::init<...>)` replaced with `.def(refl::init<...>())`.
- `tests/cpp/test_reflection.cc`: Same pattern update.
- `tests/cpp/CMakeLists.txt`: Removed `EXCLUDE_FROM_ALL` from test executable.
- `docs/guides/cpp_guide.md`, `docs/guides/python_guide.md`: Updated code examples.

## Public surface changes (if any)
- API: `refl::init<T, Args...>` free function removed (breaking); new `refl::init<Args...>` struct and `ObjectDef::def(init<Args...>())` method added.
