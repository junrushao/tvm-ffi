# 0f45528 — fix: Suppress GCC warning for array bounds in String class (#439)

## TL;DR
- Adds `#pragma GCC diagnostic ignored "-Warray-bounds"` to the `String::Concat` method in `string.h`.
- Suppresses a false-positive GCC `-Warray-bounds` warning triggered when `String::Concat` is inlined and the `memcpy` offset looks out of bounds to the GCC analyzer.
- No behavioral change; purely a compiler warning suppression.

## Why (intent / motivation)
- Downstream projects (e.g., `tvm/src/relax/transform/meta_schedule.cc`) hit this GCC warning when inlining `String::Concat` via `operator+`. The warning is a false positive caused by GCC's inter-procedural alias analysis, not an actual out-of-bounds access.

## What changed (facts from diff)
- One new pragma line added inside the existing `#pragma GCC diagnostic push` block in `string.h:Concat`: `#pragma GCC diagnostic ignored "-Warray-bounds"`.
