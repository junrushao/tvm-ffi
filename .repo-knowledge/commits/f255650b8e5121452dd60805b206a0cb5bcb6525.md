# f255650 — feat: Introduce `tvm_ffi.libinfo.load_lib_module` (#336)

## TL;DR
- Adds `tvm_ffi.libinfo.load_lib_module(package, target_name, keep_module_alive=True)` which finds and loads a downstream shared library as a TVM-FFI `Module` object.
- Simplifies the packaging example's `base.py` from ~30 lines to a single call.
- Also removes the `PREFIX ""` property from `examples/packaging/CMakeLists.txt` so the library gets the normal OS-specific prefix (e.g., `libmy_ffi_extension.so`).

## Why (intent / motivation)
- Downstream packages had to duplicate a fragile `_load_lib()` pattern for every new library. `load_lib_module` encapsulates `_find_library_by_basename` + Windows DLL directory setup + `load_module` into a single well-tested utility.

## What changed (facts from diff)
- `python/tvm_ffi/libinfo.py`: Adds `load_lib_module(package, target_name, keep_module_alive=True) -> Module` function.
- `examples/packaging/python/my_ffi_extension/base.py`: Reduces to `_LIB = tvm_ffi.libinfo.load_lib_module("my-ffi-extension", "my_ffi_extension")`.
- `examples/packaging/CMakeLists.txt`: Removes `set_target_properties(... PREFIX "")`.
