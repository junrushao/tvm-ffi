# da570b0 — Add torch c dlpack release workflow (#220)

## TL;DR
- Adds `.github/workflows/torch_c_dlpack.yml` — a 218-line GitHub Actions workflow for building and publishing `torch_c_dlpack_ext` wheels to PyPI
- Covers torch 2.4–2.9, Python cp39–cp313, x86_64 and aarch64, with CUDA support

## Why (intent / motivation)
- The `torch_c_dlpack_ext` addon package introduced in #189 needed a CI/CD release pipeline to publish AOT-compiled wheels to PyPI

## What changed (facts from diff)
- New workflow file `.github/workflows/torch_c_dlpack.yml` with three jobs:
  - `build_libs`: Builds `.so` files for each torch version/arch/Python combination inside manylinux_2_28 Docker containers with CUDA 13.0 toolkit; uploads as artifacts
  - `build_wheels`: Downloads lib artifacts, runs `auditwheel repair` to produce manylinux-compatible wheels; uploads as artifacts
  - `build_source`: Builds the source distribution (`.tar.gz`)
  - `upload_pypi`: Downloads all artifacts and publishes to PyPI using OIDC attestation
- Workflow triggered manually via `workflow_dispatch` with branch/tag input
