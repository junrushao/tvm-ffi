# 395db3c — Add Support for NVIDIA Ampere GPUs in _get_cuda_target (#440)

## TL;DR
- Adds a fallback path in `_get_cuda_target()` when older NVIDIA drivers do not support the `compute_cap` query field in `nvidia-smi`.
- Falls back to querying GPU name via `nvidia-smi --query-gpu=name` and maps known Ampere GPU names (A100, A10) to their compute capabilities.
- Raises `RuntimeError` with actionable message if auto-detection still fails, instead of silently returning a wrong default (`sm_70`).

## Why (intent / motivation)
- Older NVIDIA drivers deployed on Ampere-generation systems (A10, A100) do not support `compute_cap` in `nvidia-smi`. Previously this caused an exception that was caught and fell back to `sm_70`, which is incorrect for Ampere GPUs (sm_80 / sm_86).

## What changed (facts from diff)
- In `_get_cuda_target()`, the broad exception handler now attempts a secondary query: `nvidia-smi --query-gpu=name --format=csv,noheader`.
- Maps known Ampere GPU names to correct compute capabilities: A100 -> (8, 0), A10 -> (8, 6).
- If name-based lookup also fails, raises `RuntimeError` directing the user to set `TVM_FFI_CUDA_ARCH_LIST`.
- The old silent fallback to `sm_70` is removed.

## Public surface changes (if any)
- API: `_get_cuda_target()` now raises `RuntimeError` instead of silently returning `sm_70` on fully undetectable systems
- Flags/config: `TVM_FFI_CUDA_ARCH_LIST` environment variable (already existed) is now referenced in the error message
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: none
- How to verify manually: Run on an A10/A100 machine with an old NVIDIA driver; check that the function returns the correct target
- CI impact: none

## Risk & rollout notes
- Risk level: low — additive fallback path; only affects systems where `compute_cap` query fails
- Rollout/migration: Callers that were accidentally relying on the `sm_70` fallback will now get an error; they should set `TVM_FFI_CUDA_ARCH_LIST`
- Follow-ups: Consider expanding the Ampere map to cover more GPU models
