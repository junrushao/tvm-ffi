# ccd19f8 — feat(cmake): Introduce `tvm_ffi_configure_target` and `tvm_ffi_install` (#351)

## TL;DR
- Adds two high-level CMake helper functions to `cmake/Utils/Library.cmake`: `tvm_ffi_configure_target` and `tvm_ffi_install`.
- Similar in spirit to `pybind11_add_module` / `nanobind_add_module`, these functions consolidate linking, debug symbol generation, MSVC flags, prefix map, and optional stub generation into a single call.
- Simplifies `examples/packaging/CMakeLists.txt` from ~62 lines to 3 lines.
- Changes `tvm_ffi_add_apple_dsymutil` to run on all Apple builds regardless of `TVM_FFI_USE_LIBBACKTRACE`.

## Why (intent / motivation)
- Downstream CMake consumers had to manually replicate several boilerplate calls (link_libraries, prefix_map, dsymutil, msvc_flags, stub post-build command). `tvm_ffi_configure_target` packages these into one idiomatic call.

## What changed (facts from diff)
- `cmake/Utils/Library.cmake`: Adds `tvm_ffi_configure_target(target [LINK_SHARED ON|OFF] [LINK_HEADER ON|OFF] [DEBUG_SYMBOL ON|OFF] [MSVC_FLAGS ON|OFF] [STUB_INIT ON|OFF] [STUB_DIR <dir>] [STUB_PKG <pkg>] [STUB_PREFIX <prefix>])` and `tvm_ffi_install(target [DESTINATION <dir>])`. Updates `tvm_ffi_add_apple_dsymutil` condition to `if (APPLE)` (was `if (APPLE AND TVM_FFI_USE_LIBBACKTRACE)`).
- `examples/packaging/CMakeLists.txt`: Reduces from complex option-guarded block to `find_package(tvm_ffi CONFIG REQUIRED)` + `add_library(my_ffi_extension SHARED src/extension.cc)` + `tvm_ffi_configure_target(my_ffi_extension STUB_DIR "./python" STUB_INIT ON)`.
- `examples/packaging/python/my_ffi_extension/_ffi_api.py`: Corrects `_FFI_LOAD_LIB` call from `"my-ffi-extension"` to `"my_ffi_extension"` package name.
