# ed067c1 — Update the logic of checking `#embed` (#418)

## TL;DR
- Adds an early compile-time check for C++26 `#embed` support to the cubin launcher CMake build
- Fails fast with a clear error message if the compiler lacks `#embed` (requires GCC 15+ or Clang 19+)
- Uses `CheckCXXSymbolExists(__cpp_pp_embed)` after the C++ standard is set so GCC correctly defines the feature macro

## Why (intent / motivation)
- Previously the build would fail with a confusing linker or compilation error if `#embed` was unsupported
- The check must occur after `set(CMAKE_CXX_STANDARD 26)` because GCC does not define `__cpp_pp_embed` without the standard being set first

## What changed (facts from diff)
- `examples/cubin_launcher/embedded_cubin/cpp_embed/CMakeLists.txt`: Added `include(CheckCXXSymbolExists)`, `check_cxx_symbol_exists(__cpp_pp_embed "" HAVE_EMBED)`, and a `FATAL_ERROR` message if not found (+10 lines)
