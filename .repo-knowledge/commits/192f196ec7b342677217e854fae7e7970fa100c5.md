# 192f196 — [REFACTOR][FFI] Cleanup PackedFunc redirections (#18022)

## TL;DR
- Exposes `tvm::ffi::Any` and `tvm::ffi::AnyView` into the `tvm::` namespace via `using` declarations.
- Adds `TVM_FFI_DLL_EXPORT` macro alongside `TVM_FFI_DLL` for all platforms (Emscripten, MSVC, GCC/Clang).
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro for exporting typed functions as `SafeCallType` symbols.
- Adds comment clarifying `TVM_FFI_DLL` vs `TVM_FFI_DLL_EXPORT` semantics.

## Why (intent / motivation)
- Completes the namespace cleanup started in #17929: `Any`/`AnyView` are now accessible as `tvm::Any`, `tvm::AnyView` without namespace qualification.
- `TVM_FFI_DLL_EXPORT` is needed to distinguish always-export from context-dependent import/export, which is required for module library export utilities.

## What changed (facts from diff)
- `include/tvm/ffi/any.h`: added `using tvm::ffi::Any; using tvm::ffi::AnyView;` in `tvm` namespace.
- `include/tvm/ffi/c_api.h`: added `TVM_FFI_DLL_EXPORT` macro for Emscripten, MSVC, and GCC/Clang; added clarifying comment for `TVM_FFI_DLL` vs `TVM_FFI_DLL_EXPORT`.
- `include/tvm/ffi/function.h`: added `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro (+48 lines) — allows exporting a typed C++ function as a `TVMFFISafeCallType` symbol.

## Public surface changes (if any)
- API: `tvm::Any`, `tvm::AnyView` now available; `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro added.
- Flags/config: `TVM_FFI_DLL_EXPORT` macro added for all platforms.
