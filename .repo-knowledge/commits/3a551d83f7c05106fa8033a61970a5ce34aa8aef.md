## TL;DR

Global rename of `NDArray` to `Tensor` across the entire codebase: C++ class `NDArray`/`NDArrayObj` becomes `Tensor`/`TensorObj`, the header `ndarray.h` becomes `tensor.h`, the Cython file `ndarray.pxi` becomes `tensor.pxi`, the Python module `ndarray.py` becomes `tensor.py`, and the test file `test_ndarray.cc` becomes `test_tensor.cc`. This is an ABI-breaking rename touching approximately 30 files.

## Why

The name `NDArray` (N-dimensional array) is the internal DLPack representation name. `Tensor` is a more standard and recognizable name for machine learning frameworks. Renaming aligns the TVM FFI API with broader ecosystem conventions and avoids confusion with DLPack's own `DLTensor` type.

## What changed

Approximately 30 files renamed or modified, including:
- `include/tvm/ffi/container/ndarray.h` -> `include/tvm/ffi/container/tensor.h`
- C++ class `NDArray` -> `Tensor`, `NDArrayObj` -> `TensorObj`
- `python/tvm_ffi/cython/ndarray.pxi` -> `python/tvm_ffi/cython/tensor.pxi`
- `python/tvm_ffi/ndarray.py` -> `python/tvm_ffi/tensor.py` (or `_tensor.py`)
- `tests/cpp/test_ndarray.cc` -> `tests/cpp/test_tensor.cc`
- All include paths, type aliases, forward declarations, and docstring references updated throughout `include/`, `src/`, `python/`, `tests/`, `docs/`, and `examples/`.

## Public surface changes

**ABI breaking**: `tvm::ffi::NDArray` renamed to `tvm::ffi::Tensor`. `NDArrayObj` renamed to `TensorObj`. Header path changed. All C++ consumers must update includes and type names. Python: `tvm_ffi.NDArray` renamed to `tvm_ffi.Tensor`.

## Tests & verification

Existing test suite renamed from `test_ndarray.cc` to `test_tensor.cc` and updated to use new type names. All existing tests continue to exercise the same functionality.

## Risk & rollout notes

High risk: ABI and API breaking change touching the entire codebase. Requires coordinated update of all downstream consumers. Intentional as part of pre-1.0 API stabilization.

## Evidence

- ~30 files modified/renamed across `include/`, `src/`, `python/`, `tests/`, `docs/`, `examples/`
- Key renames: `ndarray.h` -> `tensor.h`, `NDArray` -> `Tensor`, `NDArrayObj` -> `TensorObj`
