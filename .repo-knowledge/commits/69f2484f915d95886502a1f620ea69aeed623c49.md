# 69f2484 — [FFI] Provide Field Visit bridge so we can do gradual transition (#18091)

## TL;DR
- Adds `ForEachFieldInfoWithEarlyStop` to `reflection.h` — a new variant of `ForEachFieldInfo` that supports early-stop semantics via a boolean-returning callback.
- Adds a `static_assert` to the existing `ForEachFieldInfo` to enforce that callbacks return `void`.
- These helpers form a bridge enabling gradual migration of `VisitAttrs` to the new reflection mechanism.

## Why (intent / motivation)
- Old-style `VisitAttrs` reflection used a "search and stop" pattern; the new `ForEachFieldInfo` only supports void callbacks.
- `ForEachFieldInfoWithEarlyStop` allows migrated code to stop iteration early (e.g., when a field is found), which is needed to implement `VisitAttrs` search semantics on top of the new reflection.
- The `static_assert` prevents accidental misuse of `ForEachFieldInfo` with non-void callbacks.

## What changed (facts from diff)
- `include/tvm/ffi/reflection/reflection.h` (+30/-0):
  - `ForEachFieldInfo`: added `static_assert` that callback returns `void`.
  - `ForEachFieldInfoWithEarlyStop` (new function): iterates ancestors and fields; calls `callback(field_ptr)` which returns `bool`; stops and returns `true` if callback returns `true`.
