# 8888eb4 — [TENSOR] Add API to create strided view (#335)

## TL;DR
- Adds `Tensor::as_strided(shape, strides, element_offset)` method that creates a ref-counted view sharing the source tensor's data memory.
- Adds `TensorView::as_strided(shape, strides, element_offset)` for the lightweight non-owning variant.
- Adds `Tensor::FromNDAllocStrided` static factory for creating tensors with custom strides from an NDAllocator.
- Exposes `TVMFFITensorCreateUnsafeView` C API function.

## Why (intent / motivation)
- Certain ML runtime scenarios require strided (non-contiguous) tensor views (e.g., column-major layout, sub-tensor slices) without copying data.

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: Declares `TVMFFITensorCreateUnsafeView(source, prototype, out)`.
- `include/tvm/ffi/container/tensor.h`: Adds `TensorObjFromNDAlloc` prototype-based constructor; `Tensor::as_strided`; `Tensor::FromNDAllocStrided`; `TensorView::as_strided`; removes `inline` from `dim()`, `sizes()`, `is_contiguous()`.
- `src/ffi/tensor.cc`: Implements `TVMFFITensorCreateUnsafeView` using a local `ViewNDAlloc` functor that keeps the source alive via `ObjectPtr`.
- `tests/cpp/test_tensor.cc`: Adds `EmptyStrided` helper and `TEST(Tensor, TensorViewAsStrided)`, `TEST(Tensor, AsStrided)` with byte-offset validation.
- `docs/guides/kernel_library_guide.rst`: Adds `FromNDAllocStrided` documentation entry.

## Public surface changes (if any)
- API: `TVMFFITensorCreateUnsafeView` (C API); `Tensor::as_strided`, `Tensor::FromNDAllocStrided`, `TensorView::as_strided` (C++ API)
- Flags/config: none
