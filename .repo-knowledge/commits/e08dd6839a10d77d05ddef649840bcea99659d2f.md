# e08dd68 — chore: Run ty in dev environment (#441)

## TL;DR
- Changes `ty` to run in the project's own dev environment (`uvx ty@<version>`) rather than a standalone invocation
- Moves `test`, `torch`, and other groups from `[project.optional-dependencies]` to `[dependency-groups]` in `pyproject.toml`
- Updates CI workflows to use `--group test` and `--group torch` instead of `.[test]` and `.[torch]` extras syntax
- Removes `yamllint` and `taplo-format` from pre-commit; pins `ty` version in the hook
- Touches many test and example files for minor type annotation fixes required by pinned `ty`

## Why (intent / motivation)
- Running `ty` via `uvx` without the project's environment meant it lacked access to type stubs for project dependencies
- Migrating to `[dependency-groups]` in `pyproject.toml` follows PEP 735 and is the modern `uv`-idiomatic approach
- Pinning `ty` version ensures reproducible linting

## What changed (facts from diff)
- `.github/workflows/ci_test.yml`: `.[test]` → `--group test`
