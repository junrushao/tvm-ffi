# cdfd041 — Add cuda DeviceGuard (#287)

## TL;DR
- Adds `include/tvm/ffi/extra/cuda/device_guard.h` with `CUDADeviceGuard` RAII struct, analogous to `c10::cuda::CUDAGuard` in PyTorch
- Extracts `TVM_FFI_CHECK_CUDA_ERROR` macro into a new shared `include/tvm/ffi/extra/cuda/base.h` header
- Cleans up `cubin_launcher.h` by removing the now-duplicate macro

## Why (intent / motivation)
- Kernel libraries need a reliable way to set the current CUDA device when launching kernels on a specific device index and restore it afterward

## What changed (facts from diff)
- New `include/tvm/ffi/extra/cuda/base.h` with `TVM_FFI_CHECK_CUDA_ERROR` macro
- New `include/tvm/ffi/extra/cuda/device_guard.h` with `CUDADeviceGuard` struct: constructor saves original device, sets target; destructor restores original device
- `include/tvm/ffi/extra/cuda/cubin_launcher.h`: removed duplicate `TVM_FFI_CHECK_CUDA_ERROR`; updated header guard name; includes `base.h`

## Public surface changes (if any)
- API: New `tvm::ffi::CUDADeviceGuard` RAII guard; new `TVM_FFI_CHECK_CUDA_ERROR` macro in `cuda/base.h`
- Flags/config: none
