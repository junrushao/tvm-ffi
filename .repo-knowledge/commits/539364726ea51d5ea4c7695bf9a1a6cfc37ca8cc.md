# 5393647 — [DLPack] Further compatibility (#315)

## TL;DR
- Renames the DLPack exchange API attribute from `__c_dlpack_exchange_api__` to `__dlpack_c_exchange_api__` across the Python layer to track a future DLPack naming standard.
- Adds backward-compatibility shim: when only `__c_dlpack_exchange_api__` is present, it is automatically upgraded and mirrored to `__dlpack_c_exchange_api__`.
- `DLTensorTestWrapper` now stores a PyCapsule directly instead of a raw integer pointer.

## Why (intent / motivation)
- DLPack may standardize the attribute name as `__dlpack_c_exchange_api__`; this PR aligns TVM-FFI with the expected future name while keeping backward compatibility with the old one.

## What changed (facts from diff)
- `addons/torch_c_dlpack_ext/core.py`: Now sets both `__c_dlpack_exchange_api__` and `__dlpack_c_exchange_api__` on `torch.Tensor`, the latter as a PyCapsule.
- `python/tvm_ffi/_optional_torch_c_dlpack.py`: Introduces `_check_and_update_dlpack_c_exchange_api` helper that upgrades the legacy integer attribute to a PyCapsule under the new name.
- `python/tvm_ffi/cython/function.pxi`, `tensor.pxi`, `base.pxi`, `tvm_ffi_python_helpers.h`: All struct field and attribute references renamed from `c_dlpack_exchange_api` to `dlpack_c_exchange_api`.
- Environment variable `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` renamed to `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API`.
- Tests updated to check for `__dlpack_c_exchange_api__` and removed the dual integer/capsule handling path since the new API is always a PyCapsule.

## Public surface changes (if any)
- API: `DLTensorTestWrapper.__c_dlpack_exchange_api__` -> `__dlpack_c_exchange_api__`; environment variable renamed
- Flags/config: `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API` replaces `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API`
- Data formats/schemas: DLPack exchange pointer now always carried as a PyCapsule

## Tests & verification
- Added/updated tests: `tests/python/test_dlpack_exchange_api.py`, `tests/python/test_load_inline.py`
- How to verify manually: `uv run pytest -vvs tests/python/test_dlpack_exchange_api.py tests/python/test_load_inline.py`
- CI impact: none beyond the renamed env var

## Risk & rollout notes
- Risk level: low — backward compat shim provided; old attribute still set by the extension loader
- Rollout/migration: consumers using `__c_dlpack_exchange_api__` or `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` should migrate to the new names
- Follow-ups: none
