# eda2b71 — [FFI][LLVM] Fix compilation errors with clang20 (#17954)

## TL;DR
- One-line fix in `include/tvm/ffi/string.h`: `nullptr_t` → `std::nullptr_t`.
- Resolves a compilation error introduced by stricter type checking in Clang 20.

## Why (intent / motivation)
- Clang 20 no longer accepts the unqualified `nullptr_t` as a type name in some contexts where `std::nullptr_t` (from `<cstddef>`) is required.
- This is a portability fix to maintain compatibility with the latest compiler toolchains.

## What changed (facts from diff)
- `include/tvm/ffi/string.h`: `String(nullptr_t) = delete;` → `String(std::nullptr_t) = delete;`
