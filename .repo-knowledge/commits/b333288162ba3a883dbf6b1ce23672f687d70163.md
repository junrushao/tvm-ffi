# b333288 — [FFI] Introduce GlobalDef for function registration (#18111)

## TL;DR
- Adds a new `reflection::GlobalDef` class in `reflection.h` that mirrors the `ObjectDef` API for registering global functions.
- Migrates all existing `TVM_FFI_REGISTER_GLOBAL` usages in `container.cc`, `function.cc`, `ndarray.cc`, `object.cc`, and `testing.cc` to use `GlobalDef` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- Improves `GetMethod` to correctly dispatch whether the target class is `Object`-derived or `ObjectRef`-derived.

## Why (intent / motivation)
- Aligns global function registration with the new reflection-style API (`ObjectDef`, `def`, `def_packed`, `def_method`).
- Prepares for phasing out the `TVM_FFI_REGISTER_GLOBAL` macro.

## What changed (facts from diff)
- `reflection.h`: new `GlobalDef` class with `def`, `def_packed`, `def_method`, and private `RegisterFunc`; improved `GetMethod` overloads for both `Object` and `ObjectRef` class types.
- `container.cc`, `function.cc`, `ndarray.cc`, `object.cc`, `testing.cc`: all global registrations moved from `TVM_FFI_REGISTER_GLOBAL(...).set_body_*` pattern to `GlobalDef().def(...)` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- `test_function.cc`: updated expected type string for `ffi.Function`; removed `TVM_FFI_REGISTER_GLOBAL`-based `testing.Int_GetValue` test.
- `test_reflection.cc`: added `GlobalDef().def_method(...)` test for `testing.Int_GetValue`.

## Public surface changes (if any)
- API: `reflection::GlobalDef` is a new public class in `tvm/ffi/reflection/reflection.h`.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/cpp/test_reflection.cc` — new `Reflection::FuncRegister` test.
- How to verify manually: `cmake --build build_test && ctest -V --test-dir build_test`
- CI impact: none expected; existing behavior preserved

## Risk & rollout notes
- Risk level: medium — replaces existing macro-based registration across multiple files; functional parity maintained but registration timing changes slightly (now in `TVM_FFI_STATIC_INIT_BLOCK`).
- Rollout/migration: Downstream callers using `TVM_FFI_REGISTER_GLOBAL` should migrate to `GlobalDef` in follow-up PRs.
- Follow-ups: Phase out `TVM_FFI_REGISTER_GLOBAL` macro entirely.
