# 78d3c42 — chore: Upgrade Python dependency (#135)

## TL;DR
- Adds `torch` back to Windows test dependencies and constrains it to the latest version.
- Adds a new `dev` dependency group with common developer tools (ruff, mypy, clang-format, ipdb, pre-commit, etc.).
- Enforces Ninja as the build generator (disables Makefile fallback).
- Adds `ninja` to `build-system.requires`.
- Adds a workaround torch import to avoid symbol conflict on Windows Python 3.12.

## Why (intent / motivation)
- Windows CI was missing torch; developer tooling was previously not listed in `pyproject.toml`; Ninja is preferred for its speed and parallel builds.

## What changed (facts from diff)
- `pyproject.toml`: `test` dependency restored to include `torch` for all platforms; new `[dependency-groups.dev]` section; `ninja.version` and `ninja.make-fallback = false` added to scikit-build; `ninja` added to build-system requires; `docs` group requires Python >= 3.13.
- `python/tvm_ffi/__init__.py`: Added early `try: import torch` hack to work around symbol conflict on Windows GitHub Actions Python 3.12 + torch 2.9.0.
