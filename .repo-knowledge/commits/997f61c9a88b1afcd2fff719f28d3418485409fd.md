# 997f61c — [Docs][Examples] Add CUDA C++ loading example and improve development documentation (#209)

## TL;DR
- Adds a new C++ CUDA loading example (`examples/quickstart/load/load_cuda.cc`) demonstrating custom CUDA memory allocators and tensor operations
- Adds a new guide `docs/guides/cpp_packaging.md` documenting glibc ABI compatibility and the manylinux approach for kernel distribution
- Expands `CONTRIBUTING.md` with a comprehensive "Setting Up Pre-commit Hooks" section
- Upgrades pip in the development Docker container

## Why (intent / motivation)
- No pure C++ CUDA example existed; existing examples only covered Python CUDA or CPU C++
- Contributors were encountering glibc compatibility issues when distributing compiled kernels
- Pre-commit version conflicts (2.17.0 vs 2.18.0+) were causing contributor friction

## What changed (facts from diff)
- `examples/quickstart/load/load_cuda.cc`: New 112-line C++ example using `ffi::Module::LoadFromFile`, custom `CUDANDAlloc` allocator, `cudaMalloc`/`cudaFree`, and `Tensor::FromNDAlloc`
- `examples/quickstart/raw_compile.sh`: Adds Example 4 (commented out) showing CUDA build flags with `nvcc`/`g++`
- `docs/guides/cpp_packaging.md`: New 90-line guide covering ABI challenge, manylinux solution, practical guidance for kernel distributors, and verification commands
- `docs/index.rst`: Adds `cpp_packaging.md` to guides toctree
- `CONTRIBUTING.md`: Adds ~80 lines on pre-commit installation, hook configuration, troubleshooting, and updates Docker workflow instructions
- `docs/guides/build_from_source.md`: Minor flag fix (`--reinstall` -> `--force-reinstall`)
- `tests/docker/Dockerfile`: Adds `RUN python3 -m pip install --upgrade pip`
