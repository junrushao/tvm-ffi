# 369ff23 — doc: Stable C ABI (#191)

## TL;DR
- Adds a comprehensive new documentation page `docs/get_started/stable_c_abi.rst` explaining the TVM FFI stable C ABI layout and calling convention.
- Creates `examples/stable_c_abi/` with a pure-C kernel (`add_one_cpu.c`) and C loader (`load.c`) that serve as codegen reference implementations.
- Moves the Stable C ABI guide from `docs/guides/stable_c_abi.md` (deleted) to `docs/get_started/stable_c_abi.rst` (new).

## Why (intent / motivation)
- DSL and ML compiler codegens targeting the ABI needed a complete reference for both callee and caller sides in pure C. The old guide was a stub; this replaces it with a full reference page with figures and working examples.

## What changed (facts from diff)
- New `docs/get_started/stable_c_abi.rst` (254 lines): Explains `TVMFFIAny` 128-bit layout, calling convention, stability/cross-language/cross-framework properties; includes C callee and caller examples via `literalinclude`.
- New `examples/stable_c_abi/src/add_one_cpu.c`: Pure C11 kernel following the C ABI (`__tvm_ffi_add_one_cpu`).
- New `examples/stable_c_abi/src/load.c`: Pure C11 loader using `TVMFFIFunctionCall` to load a module and call `add_one_cpu`.
- New `examples/stable_c_abi/CMakeLists.txt`, `raw_compile.sh`, `run_all.sh`, `README.md`.
- Deleted `docs/guides/stable_c_abi.md`.
- `docs/index.rst`: Moved stable_c_abi from guides to get_started toctree.
- `examples/quickstart/load/load_cpp.cc`: Refactored region markers to `[main.begin/end]` and `[aux.begin/end]`.
