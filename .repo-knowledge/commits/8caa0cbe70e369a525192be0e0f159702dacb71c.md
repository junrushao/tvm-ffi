# 8caa0cb — feat: Introduce `<tvm/ffi/tvm_ffi.h>` (#369)

## TL;DR
- Added new umbrella header `include/tvm/ffi/tvm_ffi.h` (58 lines) that includes all core TVM FFI C++ headers in one include
- Updated examples and docs to use the single `#include <tvm/ffi/tvm_ffi.h>` instead of multiple individual includes
- Updated `examples/python_packaging/pyproject.toml` for package configuration changes

## Why (intent / motivation)
- Following the convention of popular C++ binding libraries (nanobind, pybind11) that provide a single umbrella header, TVM FFI needed `tvm_ffi.h` to reduce boilerplate for users
- Previously users had to know which individual headers to include (`function.h`, `container/tensor.h`, etc.)

## What changed (facts from diff)
- `include/tvm/ffi/tvm_ffi.h`: new file including `any.h`, `base_details.h`, `c_api.h`, `error.h`, `function.h`, `object.h`, and key container headers
- `examples/quickstart/compile/add_one_cpu.cc`, `add_one_cuda.cu`, `load_cpp.cc`, `load_cuda.cc`: multiple individual includes replaced with single `#include <tvm/ffi/tvm_ffi.h>`
- `examples/python_packaging/src/extension.cc`: individual includes replaced
- `docs/get_started/quickstart.rst`: added hint box explaining the umbrella header; emphasis line numbers adjusted; code block indentation cleaned up (+30/-23)
