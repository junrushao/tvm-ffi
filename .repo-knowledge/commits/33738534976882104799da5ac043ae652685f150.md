# 3373853 — [DLPACK] Skip Loading DLPack if available (#156)

## TL;DR
- `load_torch_c_dlpack_extension()` now checks if `torch.Tensor.__c_dlpack_exchange_api__` already exists before loading the JIT extension.
- If PyTorch natively ships this attribute (newer versions), the JIT compilation step is entirely skipped.

## Why (intent / motivation)
- The JIT compilation of the DLPack C extension is slow on first use; newer PyTorch versions already provide the required API natively, so the extension is unnecessary.
- Avoids redundant compilation and potential conflicts.

## What changed (facts from diff)
- `python/tvm_ffi/_optional_torch_c_dlpack.py`: added an early-return guard at the top of `load_torch_c_dlpack_extension()` that imports `torch`, checks `hasattr(torch.Tensor, "__c_dlpack_exchange_api__")`, and returns `None` if the attribute exists; also returns `None` if `torch` is not installed.

## Public surface changes (if any)
- API: `load_torch_c_dlpack_extension()` may now return `None` without building the extension.
- Flags/config: none.
- Data formats/schemas: none.
