# 5a6b211 — [REACTOR] Cleanup and improve map array containers (#462)

## TL;DR
- Removes `InplaceArrayBase` from `container_details.h` as it is no longer useful.
- Extracts `MapObj` into a new `map_base.h` header to enable future subclasses and variants.
- Reorganizes `SmallBaseMapObj` after `DenseMapObj` in the file.
- Adds helper methods such as `clear` to the map container.

## Why (intent / motivation)
- Preparing the container internals for the upcoming mutable `Dict` type, which needs to share the same base class as the immutable `Map`.

## What changed (facts from diff)
- `include/tvm/ffi/container/container_details.h`: removes `InplaceArrayBase` (-128 lines).
- `include/tvm/ffi/container/map.h`: -1332 lines moved to `map_base.h`; +11 lines for includes and minor updates.
- `include/tvm/ffi/container/map_base.h`: new file (+1444 lines) containing `MapObj`, `DenseMapObj`, `SmallBaseMapObj` and helper methods.
- `include/tvm/ffi/container/array.h`: removes `InplaceArrayBase` usage (+2/-15).
- `include/tvm/ffi/extra/stl.h`: minor updates (+3/-3).
