# 573d76f — API Alias Redirect for torch aten tensor (#167)

## TL;DR
- Adds ATen-style API aliases to both `Tensor` and `TensorView` classes in `include/tvm/ffi/container/tensor.h`.
- New aliases: `dim()` -> `ndim()`, `sizes()` -> `shape()`, `is_contiguous()` -> `IsContiguous()`.
- Also changes `size(size_t idx)` and `stride(size_t idx)` to accept `int64_t idx` and support negative indexing (Python-style).
- Adds corresponding C++ tests for negative-index `size()` and `stride()`.

## Why (intent / motivation)
- Code ported from PyTorch (which uses ATen naming) can now interop with TVM FFI tensors without method name adapters.
- Negative index support mirrors Python/NumPy convention for convenience.

## What changed (facts from diff)
- `include/tvm/ffi/container/tensor.h`:
  - `Tensor::size(size_t)` changed to `size(int64_t)` with `idx >= 0 ? idx : ndim + idx` logic (same for `stride`).
  - `TensorView::size(size_t)` and `stride(size_t)` similarly changed.
  - Added `inline int32_t dim()`, `inline ShapeView sizes() const`, `inline bool is_contiguous() const` to both `Tensor` and `TensorView`.
- `tests/cpp/test_tensor.cc`: added 8 new assertions testing negative index access for `size()` and `stride()`.

## Public surface changes (if any)
- API: New methods `dim()`, `sizes()`, `is_contiguous()` on `tvm::ffi::Tensor` and `TensorView`; `size()` and `stride()` now accept `int64_t` and support negative indices.
- Flags/config: none.
- Data formats/schemas: none.
