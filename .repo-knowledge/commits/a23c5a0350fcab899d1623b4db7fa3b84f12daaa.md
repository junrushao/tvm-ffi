# a23c5a0 — [Minor] Fix missing function ref in type traits (#186)

## TL;DR
- Adds a template specialization `FunctionInfo<R(&)(Args...), void>` so that function references (e.g., `(SomeFunc)` with extra parentheses, or `constexpr auto& func = ...`) are handled correctly by `TVM_FFI_DLL_EXPORT_TYPED_FUNC`.
- Without this fix, such usages caused a crash because the function type was resolved as a reference type, which was not matched by any specialization.

## Why (intent / motivation)
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC(name, (Func))` and `TVM_FFI_DLL_EXPORT_TYPED_FUNC(name, ref_func)` (where `ref_func` is a reference) would silently produce broken code because `FunctionInfo` lacked a specialization for lvalue-reference function types.

## What changed (facts from diff)
- `include/tvm/ffi/function_details.h`: Added `template <typename R, typename... Args> struct FunctionInfo<R (&)(Args...), void> : FuncFunctorImpl<R, Args...> {};` after the existing function-pointer specialization.

## Public surface changes (if any)
- API: `TVM_FFI_DLL_EXPORT_TYPED_FUNC` now correctly handles function references in addition to function pointers and plain function types.
- Flags/config: none
- Data formats/schemas: none
