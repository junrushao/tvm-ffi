# af25838 — doc: split installation section (#144)

## TL;DR
- Removes `docs/get_started/install.md` and splits its content into the homepage (`docs/index.rst`) and a new `docs/guides/build_from_source.md`.
- Adds a "Build from Source" guide covering Python package and C++-only build workflows.
- Fixes `CMakeLists.txt` to guard `tvm_ffi_testing` and `tvm_ffi_static` install targets with `if (TARGET ...)` + `OPTIONAL` so they don't fail when not built.

## Why (intent / motivation)
- The old single "Installation" page conflated quick PyPI install with full source-build instructions.
- Separating them makes the docs hierarchy clearer and avoids confusing first-time users.

## What changed (facts from diff)
