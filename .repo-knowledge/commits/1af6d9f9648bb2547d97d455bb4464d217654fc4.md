# 1af6d9f — feat(stubgen): Refactor into staged pipeline, Introduce directive `import` (#259)

## TL;DR
- Rebuilt `tvm-ffi-stubgen` into a modular staged pipeline with separate modules for parsing (`file_utils.py`), constants (`consts.py`), code generation (`codegen.py`), analysis (`analysis.py`), utilities (`utils.py`), and CLI (`cli.py`).
- Introduced new `import` directive: placing `# tvm-ffi-stubgen(begin): import` markers causes the tool to auto-generate necessary import blocks.
- Adopted new directives across `_ffi_api.py`, `access_path.py`, `module.py`, and `testing.py`.
- Deleted the old monolithic `stubgen.py` (528 lines) and `test_stubgen.py`.

## Why (intent / motivation)
- The old monolithic `stubgen.py` was hard to test and extend.
- A staged pipeline enables dry-run mode, verbose mode, tree-wide scanning, and file-level `ty-map` directive support.
- The `import` directive enables auto-inference and generation of required imports for stubs.
