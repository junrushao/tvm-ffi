# 59c91c1 — [TEST] Add testcase about subclassing an ffi.Function (#140)

## TL;DR
- Adds a test demonstrating that `tvm_ffi.Function` can be subclassed and mixed with other Python classes.
- Verifies that `__call__` must be explicitly re-assigned on the subclass due to Cython cdef class inheritance behavior.
- Tests the `__move_handle_from__` mechanism for transferring the C handle between function instances.
- Confirms that echoed function references maintain handle identity.

## Why (intent / motivation)
- It is useful to subclass `tvm_ffi.Function` to attach metadata (e.g., for a JIT function wrapper).
- The testcase documents the expected workaround pattern for Cython cdef class special method inheritance.
