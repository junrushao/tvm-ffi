## TL;DR

Adds a `strides()` member function to `ffi::Tensor` that returns the strides as a `tvm::ffi::Shape`. Also fixes a field name typo `stride_data_` -> `strides_data_` that was introduced during the NDArray-to-Tensor rename, and updates examples to use `ffi::Tensor` directly.

## Why

After the NDArray-to-Tensor rename, the `Tensor` class lacked a public `strides()` accessor. Users need access to stride information to determine memory layout. Additionally, the field name typo from the rename needed to be fixed.

## What changed

- `include/tvm/ffi/container/tensor.h`:
  - Added `Shape strides() const` member function returning `tvm::ffi::Shape` built from `TensorObj::strides_data_`.
  - Fixed typo: `stride_data_` -> `strides_data_` (internal field name).
- `examples/packaging/src/extension.cc`: Updated to use `ffi::Tensor` type directly.
- `examples/quick_start/src/add_one_cpu.cc`: Updated to use `ffi::Tensor`.
- `examples/quick_start/src/add_one_cuda.cu`: Updated to use `ffi::Tensor`.
- `tests/cpp/test_tensor.cc`: Added tests for `Tensor::strides()`.

## Public surface changes

- New public method: `tvm::ffi::Tensor::strides()` returning `tvm::ffi::Shape`.

## Tests & verification

New C++ tests in `tests/cpp/test_tensor.cc` verifying that `strides()` returns the correct values for allocated tensors.

## Risk & rollout notes

Low risk. Purely additive (new method). The field name fix (`stride_data_` -> `strides_data_`) corrects a regression from the immediately preceding rename commit.

## Evidence

- `include/tvm/ffi/container/tensor.h` (modified)
- `examples/packaging/src/extension.cc`, `examples/quick_start/src/add_one_cpu.cc`, `examples/quick_start/src/add_one_cuda.cu` (modified)
- `tests/cpp/test_tensor.cc` (modified)
