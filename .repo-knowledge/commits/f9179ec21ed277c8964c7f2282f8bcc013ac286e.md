# f9179ec — [MEMORY] Explicitly set padding to 0 (#77)

## TL;DR
- Explicitly zeros the `__padding` field in `TVMFFIObject` during object allocation.
- Ensures deterministic memory content even for the unused padding bytes.

## Why (intent / motivation)
- Although `__padding` is currently unused, leaving it uninitialized can cause non-deterministic behavior in memory comparisons, serialization, or future uses of the field.

## What changed (facts from diff)
- `include/tvm/ffi/memory.h`: added `ffi_ptr->__padding = 0;` in both `ObjAllocatorBase::make` (for regular objects) and `ObjAllocatorBase::make_inplace_array` (for array objects).
