# 79894c3 — chore(test): Fix segfaults (#313)

## TL;DR
- Adds explicit `gc.collect()` and `del mod` after the STL test to prevent segfaults.
- Objects created from a dynamically loaded module hold deleters inside that module's code; if the module is unloaded before those objects are GC'd, the destructor calls an invalid address.

## Why (intent / motivation)
- Test was intermittently segfaulting because Python's GC did not immediately free objects referencing code from the unloaded library.
- Forcing a GC pass before releasing the module reference ensures all such objects are destroyed while the library is still mapped.

## What changed (facts from diff)
- `tests/python/test_stl.py`: Added `import gc`, `gc.collect()`, and `del mod` at the end of `test_stl`.
