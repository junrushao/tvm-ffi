# ae06434 — [ERROR] Place ErrorKind second in error handling (#70)

## TL;DR
- Swaps the argument order of `TVM_FFI_CHECK` from `(ErrorKind, cond)` to `(cond, ErrorKind)` to better align with the convention "check condition, then specify error kind".
- Updates all call sites in the test file to match the new order.

## Why (intent / motivation)
- The original order from #69 placed `ErrorKind` before `cond`, which is less ergonomic; condition-first matches patterns like `assert(cond, msg)` and `TVM_FFI_ICHECK(cond)`.

## What changed (facts from diff)
- `include/tvm/ffi/error.h`: macro redefined as `TVM_FFI_CHECK(cond, ErrorKind)`.
- `tests/cpp/test_error.cc`: all three `TVM_FFI_CHECK` usages updated to new argument order.

## Public surface changes (if any)
- API: `TVM_FFI_CHECK(cond, ErrorKind)` — argument order changed (breaking if callers already used the old form from #69, but that was added in the same release cycle).
