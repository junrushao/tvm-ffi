# d6845f7 — [DOCS] Fix py:func format hyperlink (#16)

## TL;DR
- Fixes incorrect Sphinx cross-reference syntax in `container.py` docstrings.
- Replaces `{py:func}` (MyST syntax) with `:py:func:` (reStructuredText syntax).
- Affects `Array` and `Map` class docstrings.

## Why (intent / motivation)
- Sphinx was not rendering hyperlinks correctly because MyST-style `{py:func}` syntax was used inside plain RST docstrings. Switching to `:py:func:` makes the cross-references render properly in the generated HTML docs.

## What changed (facts from diff)
- Four occurrences in `python/tvm_ffi/container.py` changed from `{py:func}` to `:py:func:` format.
