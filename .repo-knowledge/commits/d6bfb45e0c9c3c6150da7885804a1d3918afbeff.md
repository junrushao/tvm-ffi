# d6bfb45 — [ADDON] Add torch c dlpack for macos (#256)

## TL;DR
- Added macOS arm64 AOT wheel build job to the `torch_c_dlpack.yml` CI workflow.
- Extended `build_aot_wheels.sh` to support both Linux and macOS, using `delocate` on macOS instead of `auditwheel` for wheel repair.
- Fixed `build_backend.py` to no longer treat `.dylib` as a prebuilt extension marker on macOS (since macOS builds use `.so`).

## Why (intent / motivation)
- macOS arm64 users had no AOT-compiled wheel available and had to rely on JIT compilation or the Python fallback path.

## What changed (facts from diff)
- `.github/workflows/torch_c_dlpack.yml`: Added `build_wheels_macos` job targeting `macos-14` (arm64); updated `upload_pypi` to depend on it.
- `addons/torch_c_dlpack_ext/build_aot_wheels.sh`: Added OS detection (`Linux`/`Darwin`); conditional torch install URL (Linux uses CUDA index, macOS uses default); conditional CUDA build (Linux only); uses `delocate-wheel` on macOS, `auditwheel` on Linux; sets platform tag `macosx_11_0_arm64`.
- `addons/torch_c_dlpack_ext/build_backend.py`: Removed `darwin` -> `dylib` extension branch (macOS uses `.so`).
