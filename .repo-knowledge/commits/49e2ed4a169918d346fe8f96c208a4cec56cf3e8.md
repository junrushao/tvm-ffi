# 49e2ed4 — [FFI] Introduce small string/bytes (#18185)

## TL;DR
- Introduces `kTVMFFISmallStr` and `kTVMFFISmallBytes` type indices in the C ABI for inline (stack-allocated) small string/bytes values stored directly in `TVMFFIAny`.
- Updates `AnyView`, `Any`, type traits, cast machinery, and all consumers to handle the new type indices.
- Adds a `zero_padding` field in the ABI union to keep padding zeroed for correctness.

## Why (intent / motivation)
- Short strings (e.g., field names, type keys) are very common; avoiding heap allocation for small strings reduces memory pressure and improves cache locality.

## What changed (facts from diff)
- `c_api.h`: adds `kTVMFFISmallStr` and `kTVMFFISmallBytes` enum values; adds `zero_padding` field to `TVMFFIAny` union.
- `any.h`: `AnyView` and `Any` constructors and `reset()` initialize `zero_padding`; small-string type indices handled in type checks.
- `string.h`, `type_traits.h`, `cast.h`, `object.h`, `optional.h`, `rvalue_ref.h`, `container/variant.h`: updated to handle `kTVMFFISmallStr`/`kTVMFFISmallBytes` alongside `kTVMFFIStr`/`kTVMFFIBytes`.
- `src/ffi/dtype.cc`, `object.cc`: small-string handling in DType and object code.
- `src/ffi/extra/structural_equal.cc`, `structural_hash.cc`, `reflection/accessor.h`: small-string cases added.
- Tests: `test_any.cc`, `test_dtype.cc`, `test_optional.cc`, `test_reflection_accessor.cc`, `test_rvalue_ref.cc`, `test_string.cc`, `test_variant.cc` all updated.

## Public surface changes (if any)
- API: new `TypeIndex::kTVMFFISmallStr` and `kTVMFFISmallBytes` in C ABI; new `zero_padding` field in `TVMFFIAny`; ABI layout change.
- Flags/config: none
- Data formats/schemas: ABI binary change — any pre-compiled binaries must be recompiled.

## Tests & verification
- Added/updated tests: 7 test files updated to cover small-string scenarios.
- How to verify manually: `uv pip install --force-reinstall -e . && uv run pytest -vvs tests/python && cmake --build build_test && ctest -V --test-dir build_test`
- CI impact: ABI change requires recompile of all dependent libraries.

## Risk & rollout notes
- Risk level: high — C ABI extension (`TVMFFIAny` union change, new type indices); requires full recompile.
- Rollout/migration: Recompile all code using `TVMFFIAny`; update type index checks from `== kTVMFFIStr` to `== kTVMFFIStr || == kTVMFFISmallStr`.
- Follow-ups: none
