# fc0f5f5 — Add Docker support and C++ CUDA example (#29)

## TL;DR
- Adds `tests/docker/Dockerfile` based on `nvidia/cuda:12.6.3-devel-ubuntu22.04` for GPU-capable development containers.
- Adds a C++ CUDA example (`examples/quick_start/src/run_example_cuda.cc`) demonstrating FFI usage with CUDA kernel dispatch.
- Updates `examples/quick_start/CMakeLists.txt` to build `run_example_cuda` when CUDA is found, using `CUDAToolkit` (modern CMake) instead of the deprecated `CUDA` find module.
- Improves the quick-start build script (`run_example.sh`) to prefer Ninja and run the CUDA example when available.
- Updates `CONTRIBUTING.md` with Docker development workflow.

## Why (intent / motivation)
- Provides contributors with a reproducible development environment with GPU support, and demonstrates an end-to-end C++ CUDA use case for the quick-start guide.

## What changed (facts from diff)
- `tests/docker/Dockerfile` added (72 lines): Ubuntu 22.04 + CUDA 12.6.3, installs clang, cmake, ninja, Python, doxygen, etc.
- `examples/quick_start/src/run_example_cuda.cc` added (94 lines): C++ driver that allocates CUDA tensors, calls `add_one_cuda` via FFI, copies result back to host.
- `examples/quick_start/CMakeLists.txt`: `find_package(CUDA)` → `find_package(CUDAToolkit)`; added `run_example_cuda` executable target linked against `CUDA::cudart`.
- `examples/quick_start/run_example.sh`: Added Ninja detection, `--parallel` flag, pip install from `requirements.txt`, conditional `run_example_cuda` run.
- `CONTRIBUTING.md`: Added "Development with Docker" section.
- `.pre-commit-config.yaml`: Changed ASF header and file-type check hooks to `language: python` (more portable than `system`).
- `tests/lint/check_file_type.py`: Added `"Dockerfile"` to allowed file names.
