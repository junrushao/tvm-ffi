# 5a82940 — [TEST] Further fix potential use after free issue (#298)

## TL;DR
- Restructures `test_stl.py` to ensure all temp variables are out of scope before the module is unloaded
- Wraps all test assertions in a `run_check(mod)` sub-function so local variables are garbage collected before `mod` goes out of scope

## Why (intent / motivation)
- Some objects returned by STL-typed functions contain deleters pointing into the loaded module; if the module is unloaded first, the deleter calls an invalid address, causing a segfault
