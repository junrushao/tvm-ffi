# ecc7471 — feat: Add `tvm_ffi.Function.__init__` (#28)

## TL;DR
- Enables creating a `tvm_ffi.Function` object directly from a Python callable or an existing `Function` instance via its constructor (`tvm_ffi.Function(add)`).
- Adds type stub annotation for `Function.__init__`.
- Adds 27 new test lines covering construction from callables and identity passthrough.

## Why (intent / motivation)
- Previously `tvm_ffi.Function` could only be obtained via global registry lookups or C++ return values. Providing a constructor makes it convenient to wrap Python callables into FFI Function objects directly.

## What changed (facts from diff)
- `python/tvm_ffi/cython/function.pxi` (+23/-0): implements `Function.__init__` that accepts either a Python callable (wraps via `_convert_to_function`) or an existing `Function` (identity/passthrough).
- `python/tvm_ffi/core.pyi` (+1/-0): adds `__init__` stub.
- `tests/python/test_function.py` (+27/-0): new tests for `Function(callable)` and `Function(function)` construction.
