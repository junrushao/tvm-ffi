# 997a366 — chore(release): Publish both manylinux2014 and 2_28 (#155)

## TL;DR
- Expands the wheel build matrix to produce both `manylinux2014` and `manylinux_2_28` Linux wheels for x86_64 and aarch64.
- Removes the hard-coded `manylinux-x86_64-image` / `manylinux-aarch64-image` from `pyproject.toml`; image selection is now per matrix row via `CIBW_MANYLINUX_X86_64_IMAGE` / `CIBW_MANYLINUX_AARCH64_IMAGE` env vars.
- manylinux2014 builds are gated to `workflow_dispatch` only (manual release trigger); manylinux_2_28 builds run on all triggers.

## Why (intent / motivation)
- Distributing only one manylinux flavor limits compatibility; providing both covers old (RHEL 7+) and modern (RHEL 8+) Linux environments.

## What changed (facts from diff)
- `.github/workflows/publish_wheel.yml`: matrix now has 6 entries (x86_64×2, aarch64×2, Windows, macOS); each Linux row carries a `linux_image` field; `CIBW_MANYLINUX_*_IMAGE` set from `matrix.linux_image`; build job conditionally skips manylinux2014 on non-dispatch events.
- `pyproject.toml`: removed `manylinux-x86_64-image` and `manylinux-aarch64-image` lines.
