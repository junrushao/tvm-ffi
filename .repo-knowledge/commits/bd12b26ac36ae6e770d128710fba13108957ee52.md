# bd12b26 — feat: add find and substr methods to String (#383)

## TL;DR
- Adds `find()` method to `tvm::ffi::String` with three overloads: `String`, `const char*`, and `const char* + count`
- Adds `substr()` method to extract substrings with bounds checking
- Adds `String::npos` sentinel value (analogous to `std::string::npos`)
- Covers the new methods with C++ GoogleTest and Python pytest tests

## Why (intent / motivation)
- The `String` class lacked standard library equivalents for substring search and extraction
- Users were forced to convert to `std::string` just to do basic operations like looking for a substring or slicing

## What changed (facts from diff)
- `include/tvm/ffi/string.h`: +44 lines — added `npos`, three `find()` overloads delegating to `std::string_view::find`, and `substr()` with `std::out_of_range` on out-of-bounds `pos`
- `tests/cpp/test_string.cc`: +37 lines — `TEST(String, Find)` and `TEST(String, Substr)` covering normal, boundary, and error cases
- `tests/python/test_string.py`: +18 lines — `test_string_find_substr()` validating Python-side behaviour (note: `find` returning `-1` for not-found matches Python `str.find` convention; slicing uses existing `__getitem__`)

## Public surface changes (if any)
- API: Added `String::npos`, `String::find(String, size_t=0)`, `String::find(const char*, size_t=0)`, `String::find(const char*, size_t, size_t)`, `String::substr(size_t=0, size_t=npos)` to `include/tvm/ffi/string.h`
- Flags/config: none
- Data formats/schemas: none

## Tests & verification

- How to verify manually: `ctest -V --test-dir build_test -R String` and `uv run pytest -vvs tests/python/test_string.py::test_string_find_substr`
