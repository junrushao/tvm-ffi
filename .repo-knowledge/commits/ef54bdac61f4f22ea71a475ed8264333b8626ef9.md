# ef54bda — [fix] Change Py_DECREF to Py_DecRef and make function static members (#138)

## TL;DR
- Refactors `TorchDLPackExchangeAPI` in `_optional_torch_c_dlpack.py`: converts five free-function callbacks into `private static` member methods of the struct.
- Replaces `Py_DECREF` macro with `Py_DecRef` function in test inline C++ snippets to avoid potential issues with the macro form.
- Fixes `CurrentWorkStream` to always set `*out_stream = nullptr` for non-CUDA devices.

## Why (intent / motivation)
- `Py_DECREF` is a macro that may have issues in certain contexts (e.g., when used as a function pointer); `Py_DecRef` is the proper function call. Making the DLPack callbacks static members of the struct is cleaner and avoids polluting the anonymous namespace.

## What changed (facts from diff)
- `python/tvm_ffi/_optional_torch_c_dlpack.py`: Moved five free functions (`TorchDLPackDLTensorFromPyObjectNoSync`, etc.) inside `TorchDLPackExchangeAPI` as `private static` methods; restructured class to set function pointers in constructor using member names; added `*out_stream = nullptr` for non-CUDA in `CurrentWorkStream`.
- `tests/python/test_dlpack_exchange_api.py`: Replaced `Py_DECREF` with `Py_DecRef` in four unique_ptr constructors.
