# 88d5130 — fix: Use-after-move when handling std::tuple (#293)

## TL;DR
- Fixes a use-after-move bug in `TypeTraits<ListTemplate>::CopyToTupleImpl` introduced with the STL support PR
- Also fixes a signed/unsigned comparison warning in `TypeTraits<std::vector<T>>`

## Why (intent / motivation)
- The original `CopyToTupleImpl` used a fold expression that called `std::get<Is>(std::forward<Tuple>(src))` multiple times which could access a moved-from object; replaced with `std::apply` which safely moves each element once

## What changed (facts from diff)
- `include/tvm/ffi/extra/stl.h`: Replaced the fold expression in `CopyToTupleImpl` with a `std::apply` lambda to avoid UB from accessing moved elements
- Changed `auto length = array->size_` from `auto` (unsigned) to `int64_t` in vector TryCast to match the signed loop index
