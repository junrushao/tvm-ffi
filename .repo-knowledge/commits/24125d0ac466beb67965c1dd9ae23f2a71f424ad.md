## TL;DR

Adds the initial C++ API reference documentation using Sphinx with Breathe and Exhale extensions. Adds a new `docs/reference/cpp/index.rst` page. Improves Doxygen comments across many C++ headers throughout `include/tvm/ffi/`.

## Why

The C++ API lacked structured API documentation. Adding Breathe/Exhale integration enables auto-generation of C++ API docs from Doxygen comments directly into the Sphinx documentation site, making the API discoverable without reading headers.

## What changed

- `docs/reference/cpp/index.rst` (new, 107 lines): Sphinx RST page configuring the C++ API reference via Exhale/Breathe.
- `docs/requirements.txt`: Added `breathe` and `exhale` packages.
- `docs/conf.py`: Extended Sphinx config to enable Breathe (Doxygen XML input) and Exhale (API tree generation) extensions.
- ~25 C++ headers in `include/tvm/ffi/` (e.g., `any.h`, `function.h`, `object.h`, `error.h`, `container/*.h`): Improved Doxygen comment coverage with `/*! \brief ... */` doc comments.

## Public surface changes

Documentation only. No code behavior changes.

## Tests & verification

No code tests added. Docs build verifiable via `make html` in `docs/`.

## Risk & rollout notes

Low risk. Documentation-only change. Breathe/Exhale added to `docs/requirements.txt` but not to the main package dependencies.

- `docs/requirements.txt` (modified)
