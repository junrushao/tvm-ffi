# 9186b44 — [CPP] Introduce InvokeExternC (#117)

## TL;DR
- Adds `Function::InvokeExternC(handle, safe_call, args...)` static method to directly invoke an exported C symbol in SafeCall convention.
- Eliminates the need to construct a full `ffi::Function` object just to call an already-exported symbol.
- Adds a corresponding C++ test.

## Why (intent / motivation)
- Downstream users may have an exported C symbol (`extern "C"` function following `TVMFFISafeCallType`) and want to invoke it as a typed function without going through the object registry; `InvokeExternC` provides a lightweight typed wrapper.

## What changed (facts from diff)
- `include/tvm/ffi/function.h`: Added `Function::InvokeExternC<Args...>(void* handle, TVMFFISafeCallType safe_call, Args&&... args) -> Any`; packs arguments into `AnyView` array and calls the function pointer directly.
- `tests/cpp/test_function.cc`: Added `invoke_testing_add1` helper and `TEST(Func, InvokeExternC)`.
