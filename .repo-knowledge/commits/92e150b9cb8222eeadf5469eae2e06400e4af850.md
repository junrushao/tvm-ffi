# 92e150b — feat(stubgen): Generate `__all__` for proper exporting (#268)

## TL;DR
- Added `__all__` stub generation to `tvm-ffi-stubgen`: placing `# tvm-ffi-stubgen(begin): __all__` inside an `__all__` list causes the tool to populate it with all auto-generated global functions and classes.
- Populated `python/tvm_ffi/_ffi_api.py` with a full `__all__` list (38 entries) generated by the tool.
- Added comprehensive unit tests for the stubgen pipeline in a new `tests/python/test_stubgen.py` (361 lines).
- Refactored `codegen.py` and `utils.py` to be testable without CLI invocation.

## Why (intent / motivation)
- Without `__all__`, wildcard imports and IDE introspection do not enumerate all generated FFI bindings.
- This is the last component needed before whole-package stub generation can be enabled.
