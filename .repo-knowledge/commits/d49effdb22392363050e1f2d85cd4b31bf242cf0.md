# d49effd — [Feature] Add cubin launcher utility as an extra header (#283)

## TL;DR
- Adds `include/tvm/ffi/extra/cuda/cubin_launcher.h`, a header-only CUDA kernel launcher that loads CUBIN from byte buffers or files
- Adds Python `tvm_ffi.cpp.nvrtc` module for NVRTC-based CUBIN compilation
- Adds Python `tvm_ffi.utils.embed_cubin` utility and CMake support for embedding CUBINs
- Adds comprehensive examples and a full guide (`docs/guides/cubin_launcher.rst`)
- Benchmarks show 2.41x lower launch overhead vs Triton for an empty kernel

## Why (intent / motivation)
- Provides a complete, framework-agnostic CUDA kernel execution pipeline from CUBIN bytes to kernel launch, with support for multi-GPU contexts, embedded CUBINs, and CUDA driver API-level launching

## What changed (facts from diff)
- New header `include/tvm/ffi/extra/cuda/cubin_launcher.h` with `CubinModule`, `CubinKernel`, `dim3`, `TVM_FFI_EMBED_CUBIN`, `TVM_FFI_EMBED_CUBIN_GET_KERNEL` and `TVM_FFI_CHECK_CUDA_DRIVER_ERROR` macro
- New `cmake/Utils/EmbedCubin.cmake` for embedding CUBIN bytes into C++ sources
- New `python/tvm_ffi/cpp/nvrtc.py` providing `nvrtc_compile()`
- New `python/tvm_ffi/utils/embed_cubin.py`
- `python/tvm_ffi/cpp/extension.py` updated to support `embed_cubin` parameter in `build_inline`/`load_inline`
- New `tests/python/test_cubin_launcher.py`
- New `examples/cubin_launcher/` with embedded and dynamic cubin examples and benchmarks
- `docs/guides/cubin_launcher.rst` added (422 lines)

## Public surface changes (if any)
- API: New `tvm_ffi.cpp.nvrtc.nvrtc_compile()`; new `embed_cubin` parameter in `tvm_ffi.cpp.load_inline`/`build_inline`; new `include/tvm/ffi/extra/cuda/cubin_launcher.h`
- Flags/config: New `cmake/Utils/EmbedCubin.cmake` utility
- Data formats/schemas: none

## Tests & verification
