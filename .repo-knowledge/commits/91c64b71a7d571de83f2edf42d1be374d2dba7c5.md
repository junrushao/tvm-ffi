# 91c64b7 — [Fix] Fix missing int8 for torch<2.6.0 (#323)

## TL;DR
- Fixes a preprocessor condition that caused `ScalarType::Char` (int8) to be excluded from DLPack type mapping on PyTorch versions before 2.6.0.
- Also consolidates duplicate `kDLInt` and `kDLFloat` switch cases to reduce code repetition.

## Why (intent / motivation)
- The original condition `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6` is incorrect: for `TORCH_VERSION_MAJOR > 2` the minor check was also evaluated, which would be wrong for future major versions. Additionally, `Char` was inside the guarded block, so torch < 2.6 could not map int8.

## What changed (facts from diff)
- `python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py`: Changed `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6` to `#if (TORCH_VERSION_MAJOR > 2) || (TORCH_VERSION_MAJOR == 2 && TORCH_VERSION_MINOR >= 6)`. Moved `ScalarType::Char`, `Short`, `Int`, `Long` outside the conditional block. Merged `kDLFloat` cases for `Half`, `Float`, `Double`.
