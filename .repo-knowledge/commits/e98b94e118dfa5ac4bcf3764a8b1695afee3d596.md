# e98b94e — feat: Introduce Experimental `tvm_ffi.dataclasses.c_class` (#8)

## TL;DR
- Introduces the `@c_class(type_key)` decorator in a new `python/tvm_ffi/dataclasses/` package.
- Allows Python classes to mirror C++ FFI types with dataclass-like syntax: annotated fields become properties backed by the C++ object, and an `__init__` is auto-generated from the reflected constructor signature.
- Supports inheritance (up to three levels tested), default values via `field(default=...)` / `field(default_factory=...)`, and `__post_init__` hook.
- Adds `Object.__ffi_init__` method to Cython for constructor invocation.
- Registers `TestCxxClassBase`, `TestCxxClassDerived`, `TestCxxClassDerivedDerived` in `testing.cc` as test fixtures.

## Why (intent / motivation)
- The existing `@register_object` + manual `__init__` pattern is boilerplate-heavy. `@c_class` lets users write one concise Python class body that mirrors the C++ definition, with reflection driving the property generation and constructor synthesis.
