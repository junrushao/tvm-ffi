# 8873700 — [CYTHON][REFACTOR] __tvm_ffi_object__ protocol (#115)

## TL;DR
- Renames `PyNativeObject.__tvm_ffi_object__` attribute to `_tvm_ffi_cached_object` (internal cached handle).
- Renames the `__tvm_ffi_tensor__` protocol method to `__tvm_ffi_object__` to generalize beyond tensors.
- Renames `__init_tvm_ffi_object_by_constructor__` to `__init_cached_object_by_constructor__`.
- Bumps package version from 0.1.0b17 to 0.1.0b18.

## Why (intent / motivation)
- The dunder convention is normally used for methods, not attributes; renaming the cached attribute to `_tvm_ffi_cached_object` follows Python naming conventions.
- Generalizing `__tvm_ffi_tensor__` to `__tvm_ffi_object__` allows any FFI object (not just Tensor) to be passed across the protocol boundary, enabling richer interoperability.

## What changed (facts from diff)
- All references to `__tvm_ffi_object__` as an attribute replaced with `_tvm_ffi_cached_object` in Cython, Python, and test code.
- `TVMFFIPyArgSetterFFITensorCompatible_` Cython setter renamed to `TVMFFIPyArgSetterFFIObjectCompatible_`; now calls `arg.__tvm_ffi_object__()` as a method and sets `type_index` from `TVMFFIObjectGetTypeIndex` instead of hardcoded `kTVMFFITensor`.
- `PyNativeObject.__init_tvm_ffi_object_by_constructor__` renamed to `__init_cached_object_by_constructor__`.
- `String` and `Bytes` `__slots__` entries updated accordingly.
- New test `test_object_protocol` in `test_object.py` verifies the `__tvm_ffi_object__` method protocol works for arbitrary objects.
- `test_tensor.py` updated to use `__tvm_ffi_object__` as a method protocol name.

## Public surface changes (if any)
- API: `__tvm_ffi_tensor__` protocol method replaced by `__tvm_ffi_object__` (breaking rename for any code implementing the tensor protocol); `_tvm_ffi_cached_object` replaces `__tvm_ffi_object__` attribute.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/python/test_object.py::test_object_protocol`, `tests/python/test_tensor.py`, `tests/python/test_function.py`
- How to verify manually: `uv run pytest -vvs tests/python/test_object.py tests/python/test_tensor.py tests/python/test_function.py`
- CI impact: none

## Risk & rollout notes
- Risk level: medium — breaking rename for any downstream code using `__tvm_ffi_tensor__` or `__tvm_ffi_object__` as an attribute; mitigated by pre-release status.
- Rollout/migration: Code using `__tvm_ffi_tensor__` protocol must rename method to `__tvm_ffi_object__`; code accessing `__tvm_ffi_object__` attribute must switch to `_tvm_ffi_cached_object`.
- Follow-ups: Freeze protocol before formal release.
