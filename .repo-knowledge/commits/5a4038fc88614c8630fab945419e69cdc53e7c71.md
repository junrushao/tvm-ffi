# 5a4038f — [FFI] Replace `Arg2Str` with a more powerful `for_each` (#18117)

## TL;DR
- Extends `for_each_dispatcher` to support three invocation signatures: `F(size_t, Arg)`, `F(Arg)`, and `F(std::integral_constant<size_t,I>, Arg)` (constexpr index form).
- Uses the enhanced `for_each` to replace `Arg2Str` in `function_details.h`, enabling compile-time index checks with `if constexpr`.
- Note: this commit was subsequently reverted by `9a1d41a`.

## Why (intent / motivation)
- The constexpr-index form allows `if constexpr (i() != 0)` in lambdas passed to `for_each`, which would otherwise require the older `Arg2Str` machinery.
- Reduces boilerplate while enabling more expressive compile-time iteration.

## What changed (facts from diff)
- `base_details.h`: `for_each_dispatcher::run` now dispatches via three `if constexpr` branches depending on invocability; adds `always_false<T>` helper for static_assert fallback.
- `function_details.h`: `Arg2Str<T>` struct removed; `FuncFunctorImpl::Sig()` now uses `for_each` with a capturing lambda that uses `i()` as constexpr index.

## Public surface changes (if any)
- API: `for_each` accepts three invocation forms — minor internal API extension.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification

## Risk & rollout notes
