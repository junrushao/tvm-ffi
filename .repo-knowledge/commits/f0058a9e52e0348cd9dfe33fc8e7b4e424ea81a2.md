# f0058a9 — [VERSION] Add Version Query API (#171)

## TL;DR
- Adds `TVMFFIVersion` struct and `TVMFFIGetVersion()` C ABI function so consumers can query the runtime version.
- Adds compile-time version macros `TVM_FFI_VERSION_MAJOR/MINOR/PATCH` to `c_api.h`.
- Adds a C++ GoogleTest covering the version API.
- Updates `README.md` with RFC stage and versioning policy.

## Why (intent / motivation)
- Libraries need to detect the ABI version at runtime to ensure compatibility, especially important as TVM-FFI enters the RFC/evolution phase.

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: New `TVMFFIVersion` struct (major/minor/patch uint32), macros `TVM_FFI_VERSION_MAJOR 0`, `TVM_FFI_VERSION_MINOR 1`, `TVM_FFI_VERSION_PATCH 0`, and `TVMFFIGetVersion(TVMFFIVersion*)` declaration.
- `src/ffi/object.cc`: Implementation of `TVMFFIGetVersion` fills the struct from the macros.
- `tests/cpp/test_base.cc` (new): GoogleTest `Base.Version` verifying the function returns values matching the macros.
- `README.md`: Adds versioning policy section describing RFC stage, `0.X.Y` semantics, and future semantic versioning.

## Public surface changes (if any)
- API: New C ABI symbol `TVMFFIGetVersion(TVMFFIVersion*)` — guaranteed stable across all ABI versions.
- Flags/config: New macros `TVM_FFI_VERSION_MAJOR`, `TVM_FFI_VERSION_MINOR`, `TVM_FFI_VERSION_PATCH`.
- Data formats/schemas: New `TVMFFIVersion` struct.

## Tests & verification
- Added/updated tests: `tests/cpp/test_base.cc` — `TEST(Base, Version)`
- How to verify manually: `cmake . -B build_test -DTVM_FFI_BUILD_TESTS=ON && cmake --build build_test && ctest --test-dir build_test`
- CI impact: New test file included in the C++ test suite.
