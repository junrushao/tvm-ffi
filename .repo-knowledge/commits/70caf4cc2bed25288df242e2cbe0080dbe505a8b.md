# 70caf4c — [CYTHON] Fix type annotation (#123)

## TL;DR
- Changes DLPack-related Cython function pointer declarations from `noexcept` to `except -1` to properly propagate Python exceptions.
- Refactors `TorchDLPackToPyObjectFallback_` to not silently swallow exceptions.
- Fixes a type annotation in `make_tensor_from_chandle`: changes `cdef Tensor` to `cdef object` so non-Tensor FFI objects can be handled correctly.

## Why (intent / motivation)
- Using `noexcept` on function pointers that can raise Python exceptions prevents proper error propagation; `except -1` is the Cython convention for returning an integer error code.
- Silently catching and returning `-1` in `TorchDLPackToPyObjectFallback_` hides real exceptions; removing the try-except lets exceptions propagate normally through Cython's `except -1` convention.

## What changed (facts from diff)
- `python/tvm_ffi/cython/base.pxi`: Changed four `ctypedef` function pointer declarations from `noexcept` to `except -1`.
- `python/tvm_ffi/cython/function.pxi`: Removed try-except from `TorchDLPackToPyObjectFallback_`; changed declaration from `noexcept` to `except -1`.
- `python/tvm_ffi/cython/tensor.pxi`: Changed `cdef Tensor tensor` to `cdef object tensor` in `make_tensor_from_chandle` and fixed cast from `<Tensor>` to `<object>`.
