# 8377011 — [CYTHON] Expose Tensor.strides (#102)

## TL;DR
- Adds `Tensor.strides` property to the Python API, exposing the DLTensor strides as a tuple of integers.
- When `DLTensor.strides` is NULL (C-contiguous), computes strides from the shape.
- Bumps `3rdparty/dlpack` submodule to v1.2.
- Bumps package version to `0.1.0b16`.

## Why (intent / motivation)
- Strides are needed for non-contiguous tensor support and interoperability with frameworks that expose them.
- DLPack v1.2 provides updated definitions.

## What changed (facts from diff)
- `python/tvm_ffi/cython/tensor.pxi`: adds `_make_strides_from_shape(tuple shape)` helper and `Tensor.strides` property.
