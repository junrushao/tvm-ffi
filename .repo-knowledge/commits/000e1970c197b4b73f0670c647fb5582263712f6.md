# 000e197 — [CYTHON] Add always inline hint to python helpers (#59)

## TL;DR
- Adds `TVM_FFI_INLINE` (mapped to `[[gnu::always_inline]] inline` or `[[msvc::forceinline]] inline`) to all key C++ helper functions in `tvm_ffi_python_helpers.h`
- Corrects the default stack size from an erroneous `32 * 2 = 64` entries to a 4KB page-aligned `4096 / sizeof(TVMFFIAny)` entries

## Why (intent / motivation)
- The helpers take multiple parameters and without forced inlining, register passing overhead can occur (particularly in debug/O1 builds)
- Explicit `always_inline` guarantees the compiler inlines these even at lower optimisation levels

## What changed (facts from diff)
- `tvm_ffi_python_helpers.h`: `TVM_FFI_INLINE` macro defined locally if not already defined; applied to `TVMFFIPyArgSetter::operator()`, `TVMFFIPyCallManager::FuncCall`, `ConstructorCall`, `SetField`, `SetArgument`; free functions `TVMFFIPyFuncCall`, `TVMFFIPyConstructorCall`, `TVMFFIPyCallFieldSetter`, `TVMFFIPyPyObjectToFFIAny`, `TVMFFIPyGetDispatchMapSize`, `TVMFFIPyPushTempFFIObject`, `TVMFFIPyPushTempPyObject`
- Default stack size corrected: `kDefaultStackSize = 4096` and `temp_stack_.resize(kDefaultStackSize / sizeof(TVMFFIAny))`
