# a754afe — chore: Run examples on `main` commits (#353)

## TL;DR
- Adds an `examples` job to `ci_mainline_only.yml` that builds and runs all three example directories (quickstart, stable_c_abi, packaging) on Linux, macOS, and Windows after every mainline commit.
- Adds Windows batch scripts `run_all_cpu.bat` and `run_all.bat` for the quickstart and stable_c_abi examples.
- Refactors CMakeLists in examples to use `set_flat_output_dirs` helper for multi-config generator compatibility.
- Simplifies `run_example.py` to always run all three flows instead of requiring a CLI argument.

## Why (intent / motivation)
- Examples were not tested in CI, leaving them prone to silent breakage. Running them on every mainline commit ensures the packaging and quickstart guides stay working across all three OSes.

## What changed (facts from diff)
- `.github/workflows/ci_mainline_only.yml`: Adds `examples` job matrix (ubuntu-latest, macos-14, windows-latest) with per-OS install and run steps for all three examples.
- `examples/quickstart/CMakeLists.txt`: Adds `set_flat_output_dirs` helper; removes hardcoded `LIBRARY_OUTPUT_DIRECTORY` and `PREFIX ""`/`SUFFIX ""` properties; uses `set_flat_output_dirs` for all targets.
- `examples/stable_c_abi/CMakeLists.txt`: Same `set_flat_output_dirs` pattern.
- `examples/quickstart/run_all_cpu.bat` (new): Windows batch equivalent of `run_all_cpu.sh`.
- `examples/stable_c_abi/run_all.bat` (new): Windows batch equivalent of `run_all.sh`.
- `examples/packaging/run_example.py`: Removes `sys.argv` dispatch; always runs all three examples (`run_add_one`, `run_raise_error`, `run_int_pair`) with section headers.
- `examples/packaging/pyproject.toml`: Fixes typo `RelWithDebugInfo` -> `RelWithDebInfo`.
- READMEs updated with "Run everything" sections and corrected commands.
- `examples/stable_c_abi/src/add_one_cpu.c`: Replaces `TVM_FFI_DLL` with `TVM_FFI_DLL_EXPORT`.
