# ca9c3d1 — [FFI][ABI] Introduce weak rc support (#18259)

## TL;DR
- Adds a weak reference counter to the FFI object system, enabling weak references that do not prevent object destruction.
- When strong RC reaches zero: destructor is called but memory is not freed. When both strong and weak RC reach zero: memory is freed.
- Extends the C ABI, `object.h`, `memory.h`, and `type_traits.h` accordingly.
- Adds extensive C++ tests for weak ref behavior.

## Why (intent / motivation)
- Weak references are needed to break cyclic dependencies in object graphs (e.g., between parent and child nodes). The two-phase destruction (strong-zero → destructor, both-zero → free) is the standard weak_ptr semantics for ref-counted objects.
