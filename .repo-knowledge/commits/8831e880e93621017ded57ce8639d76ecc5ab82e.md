# 8831e88 — chore(build): Properly skip macOS cp38 (#152)

## TL;DR
- Moves the macOS arm64 cp38 skip from the GitHub Actions workflow environment variable to `pyproject.toml`'s `[tool.cibuildwheel] skip` list.
- Removes `CIBW_SKIP` env var from workflow (reverts approach from d87502a).
- This ensures the skip is enforced for all invocations of cibuildwheel, not just the CI run.

## Why (intent / motivation)
- The previous approach relied on a CI env var, which is easy to accidentally omit. Encoding it in `pyproject.toml` is the canonical cibuildwheel location.

## What changed (facts from diff)
- `.github/workflows/publish_wheel.yml`: removed `CIBW_SKIP: "cp38-macosx_*"` line.
- `pyproject.toml`: `skip` line changed from `["*musllinux*"]` to `["*musllinux*", "cp38-macosx_*"]`.
