# 5bc7fcd — feat: add array __contains__ support (#377)

## TL;DR
- Added `ffi.ArrayContains` C++ global function that checks if an element exists in an `ArrayObj` using `AnyEqual`
- Implemented `Array.__contains__` in Python binding delegating to the new FFI function
- Added type stub and tests for both C++ and Python

## Why (intent / motivation)
- Python's `in` operator was not supported on `tvm_ffi.Array`, requiring users to manually iterate; this aligns `Array` with standard Python sequence behavior

## What changed (facts from diff)
- `src/ffi/container.cc`: new `ffi.ArrayContains` lambda registered via `GlobalDef`, iterating `ArrayObj` elements using `AnyEqual` and `std::any_of`
- `python/tvm_ffi/container.py`: `Array.__contains__(self, value)` added calling `_ffi_api.ArrayContains(self, value)`
- `python/tvm_ffi/_ffi_api.py`: `ArrayContains` stub added to type stubs and `__all__`
- `tests/cpp/test_array.cc`: `TEST(Array, Contains)` added (+20 lines)
- `tests/python/test_container.py`: parametrized `test_array_contains` test added (+21 lines)
