# bc2f408 — [Fix] Keep a reference to loaded patch lib (#200)

## TL;DR
- Fixes a potential use-after-free bug introduced in PR #192: the `ctypes.CDLL` handle returned by `load_torch_c_dlpack_extension()` was not stored anywhere, so the library could be garbage-collected while its function pointer was still in use.
- Stores the return value in module-level `_LIB` to keep it alive.

## Why (intent / motivation)
- Python's garbage collector can unload a `ctypes.CDLL` if no Python reference is kept alive, causing a segfault when the function pointer stored in `torch.Tensor.__c_dlpack_exchange_api__` is later invoked.

## What changed (facts from diff)
- `python/tvm_ffi/_optional_torch_c_dlpack.py`: `load_torch_c_dlpack_extension()` now returns `lib`; at call site, the result is stored as `_LIB = load_torch_c_dlpack_extension()` instead of being discarded.
