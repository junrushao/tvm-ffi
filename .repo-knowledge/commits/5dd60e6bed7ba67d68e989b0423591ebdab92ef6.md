# 5dd60e6 — [CMAKE] Fix tvm_ffi_testing in wheel packaging (#122)

## TL;DR
- Sets `INSTALL_RPATH` on `tvm_ffi_testing` to use `@loader_path` (macOS) or `$ORIGIN` (Linux) so it can find `libtvm_ffi` after wheel installation.
- Also fixes the `tvm_ffi_cython` RPATH condition from `LINUX` to `UNIX AND NOT APPLE` for broader portability.

## Why (intent / motivation)
- Without a relative RPATH, `libtvm_ffi_testing.so` cannot find `libtvm_ffi.so` at runtime after wheel installation where the two libraries live in the same directory.

## What changed (facts from diff)
- `CMakeLists.txt`: Added RPATH configuration block for `tvm_ffi_testing` (macOS: `@loader_path`, Linux/Unix: `$ORIGIN`); fixed cython RPATH condition to `UNIX AND NOT APPLE`.
