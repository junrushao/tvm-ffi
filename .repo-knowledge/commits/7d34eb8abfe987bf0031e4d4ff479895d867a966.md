# 7d34eb8 — [REFACTOR] Introduce and modernize FFI system (#17920)

## TL;DR
- Initial commit establishing the entire TVM FFI codebase as a standalone, modernized FFI system.
- Introduces the core C++ abstractions: `Any`/`AnyView`, `Object`/`ObjectRef`, `Function`, and a full container library.
- Adds a stable C ABI (`c_api.h`) plus a CMake build system, C++ test suite, and utility scripts.
- All files are newly added; this is the foundational commit for the repository.

## Why (intent / motivation)
- Modernize TVM's FFI foundation by extracting it into a minimal, lightweight, standalone module with clean abstractions.
- Eliminate legacy PackedFunc/TVMArgs complexity and replace with type-erased `Any`/`AnyView` and typed `Function`.
- Provide a stable C ABI for cross-language (Python, Rust, WebAssembly) interoperability.

## What changed (facts from diff)
- Added all public C++ headers under `include/tvm/ffi/`: `any.h`, `base_details.h`, `c_api.h`, `cast.h`, object system, container library (array, map, ndarray, shape, tuple, variant), dtype, error, function, memory, optional, reflection, rvalue_ref, string, type_traits.
- Added implementation sources under `src/ffi/`: container, dtype, error, function, ndarray, object, testing, traceback (Linux + Windows).
- Added CMake build system: `CMakeLists.txt` and `cmake/Utils/` (AddGoogleTest, AddLibbacktrace, CxxWarning, Library, Sanitizer).
- Added C++ GoogleTest tests for every major subsystem under `tests/cpp/`.
- Vendored `dlpack` submodule under `3rdparty/dlpack`.
- Added `scripts/run_tests.sh` helper.

## Public surface changes (if any)
- API: Entire new public API — `tvm::ffi::Any`, `tvm::ffi::AnyView`, `tvm::ffi::Object`, `tvm::ffi::ObjectRef`, `tvm::ffi::Function`, containers, dtype, error, cast.
- Flags/config: `TVM_FFI_BUILD_TESTS`, `TVM_FFI_BUILD_REGISTRY`, `TVM_FFI_USE_LIBBACKTRACE`, `TVM_FFI_BACKTRACE_ON_SEGFAULT` CMake options.
- Data formats/schemas: C ABI structs defined in `c_api.h` (`TVMFFIAny`, `TVMFFIObject`, `TVMFFIFunction`, etc.).

## Tests & verification
- Added/updated tests: `tests/cpp/test_any.cc`, `test_array.cc`, `test_c_ffi_abi.cc`, `test_dtype.cc`, `test_error.cc`, `test_function.cc`, `test_map.cc`, `test_ndarray.cc`, `test_object.cc`, `test_optional.cc`, `test_reflection.cc`, `test_rvalue_ref.cc`, `test_shape.cc`, `test_string.cc`, `test_tuple.cc`, `test_variant.cc`
- How to verify manually: `cmake . -B build_test -DTVM_FFI_BUILD_TESTS=ON && cmake --build build_test && ctest -V --test-dir build_test`
- CI impact: Establishes the test baseline for all subsequent CI runs.
