# b1611e0 — [Error] Unify EnvErrorAlreadySet to error.kind (#425)

## TL;DR
- Removes the special `-2` error code path for `EnvErrorAlreadySet` from the C ABI; it is now carried as an error `kind` field instead
- Error handling is simplified: callers only need to handle return code `-1` and check `error.kind` for `EnvErrorAlreadySet`
- Documentation, C header, C++ headers, and Cython bindings all updated to reflect the unified model

## Why (intent / motivation)
- The separate `-2` return code path was an outlier that complicated error handling for every language binding
- Carrying the interrupt signal as `error.kind` on a normal `-1` return path makes the contract simpler and more consistent

- `include/tvm/ffi/c_api.h`: Removed the `-2` error code documentation (-1 line)

- `include/tvm/ffi/function.h`: Removed special-case `-2` propagation logic (-6 lines)
