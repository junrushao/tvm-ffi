# f5633e9 — chore: Test Various Python Versions in GitHub Action CI (#41)

## TL;DR
- Extends CI matrix to test four different Python versions across platforms instead of always using 3.13
- ubuntu-latest tests Python 3.13, ubuntu-24.04-arm tests 3.9, windows-latest tests 3.12, macos-14 tests 3.10
- Switches from `actions/setup-python` to `astral-sh/setup-uv` for Python setup and uses `uv pip install` instead of bare `pip install`

## Why (intent / motivation)
- Previously all CI runs used Python 3.13 only, leaving older versions untested
- Broader version coverage catches compatibility regressions for Python 3.9+ users (the minimum supported version)

## What changed (facts from diff)
- CI matrix entries gain a `python_version` field per OS
- `actions/setup-python@v6` step is removed; replaced by `astral-sh/setup-uv` with per-matrix `python-version`
- Install command changes from `pip install -v ".[test]"` to `uv pip install --reinstall --verbose -e ".[test]"`
- Step ordering is reorganised: checkout and env detection happen before Python setup

## Public surface changes (if any)
- API: none
- Flags/config: CI matrix now parameterises `python_version`
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: none (CI workflow change only)

- CI impact: broader Python version coverage; build time unchanged per runner
