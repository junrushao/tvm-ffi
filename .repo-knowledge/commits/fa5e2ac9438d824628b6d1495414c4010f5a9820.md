# fa5e2ac — [FFI] Replace `__attribute__` with C++ standard attributes (#18114)

## TL;DR
- Replaces GCC/Clang-specific `__attribute__((...))`  annotations across 16 header files with their C++17 standard attribute equivalents.
- Pure mechanical substitution with no behavioral change.

## Why (intent / motivation)
- Improve portability and standards compliance; `__attribute__` is a GNU extension whereas C++ standard attributes (`[[nodiscard]]`, `[[maybe_unused]]`, etc.) are portable across all C++17-conforming compilers including MSVC.

## What changed (facts from diff)
- `include/tvm/ffi/any.h`, `base_details.h`, container headers, `dtype.h`, `function.h`, `function_details.h`, `object.h`, `reflection/reflection.h`, `rvalue_ref.h`, `string.h`, `type_traits.h`, `tests/cpp/testing_object.h`: `__attribute__` forms replaced with C++ standard equivalents (e.g., `TVM_FFI_INLINE` macro usage adjusted, `[[maybe_unused]]`, etc.).
