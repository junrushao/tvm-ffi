# af898a2 — feat: Enhance load_module to accept PathLike objects (#187)

## TL;DR
- Updates `tvm_ffi.load_module()` to accept both `str` and `os.PathLike` (e.g., `pathlib.Path`) arguments.
- Calls `os.fspath()` to convert `PathLike` to string before passing to the C backend.

## Why (intent / motivation)
- Users frequently work with `pathlib.Path` objects; the previous `str`-only signature required explicit string conversion, which was an unnecessary friction point (issue #158).

## What changed (facts from diff)
- `python/tvm_ffi/module.py`: Changed `load_module(path: str)` signature to `load_module(path: str | PathLike)`; added `from os import PathLike, fspath` import; calls `path = fspath(path)` before `_ffi_api.ModuleLoadFromFile(path)`.
- Updated docstring example to demonstrate `pathlib.Path` usage.

## Public surface changes (if any)
- API: `tvm_ffi.load_module()` now accepts `os.PathLike` in addition to `str`.
