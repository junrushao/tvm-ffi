# 162d600 — [FFI][REFACTOR] Introduce TypeAttr in reflection (#18160)

## TL;DR
- Introduces `TypeAttrDef<Class>` in `registry.h` for registering per-type function and constant attributes.
- Adds `TypeAttrColumn` accessor class in `accessor.h` for runtime lookup of type attributes by type index.
- Renames `TVMFFITypeExtraInfo` → `TVMFFITypeMetadata` in C ABI and adds new `TVMFFITypeAttrColumn` struct plus `TVMFFITypeRegisterAttr`/`TVMFFIGetTypeAttrColumn` C APIs.
- Renames `TypeExtraInfo` to `TypeMetadata` internally in `object.cc`.

## Why (intent / motivation)
- `TypeAttrDef` allows attaching arbitrary per-type metadata (functions, constants) in a unified column-store pattern, enabling extensible type traits beyond the fixed `TVMFFITypeMetadata` fields.
- Cleaner naming: `TypeMetadata` is more precise than `TypeExtraInfo`.

## What changed (facts from diff)
- `c_api.h`: adds `TVMFFITypeAttrColumn` struct; renames `TVMFFITypeExtraInfo` → `TVMFFITypeMetadata`; adds `TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`; renames `TVMFFITypeRegisterExtraInfo` → `TVMFFITypeRegisterMetadata`.
- `accessor.h`: adds `TypeAttrColumn` class.
- `registry.h`: adds `TypeAttrDef<Class>` class with `def` and `attr` methods; adds `EnsureTypeAttrColumn`.
- `src/ffi/object.cc`: adds `TypeAttrColumnData` store and `RegisterTypeAttr`/`GetTypeAttrColumn`; renames metadata fields throughout.
- `src/ffi/reflection/structural_equal.cc`, `structural_hash.cc`: update `extra_info` → `metadata` references.
- `tests/cpp/test_reflection_accessor.cc`: new `Reflection::TypeAttrColumn` test.
- `tests/cpp/testing_object.h`: registers `test.GetValue` and `test.size` via `TypeAttrDef<TIntObj>`.

## Public surface changes (if any)
- API: `TVMFFITypeRegisterExtraInfo` renamed to `TVMFFITypeRegisterMetadata`; `TVMFFITypeExtraInfo` renamed to `TVMFFITypeMetadata`; new functions `TVMFFITypeRegisterAttr`/`TVMFFIGetTypeAttrColumn`.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/cpp/test_reflection_accessor.cc` — `Reflection::TypeAttrColumn` test.
- How to verify manually: `cmake --build build_test && ctest -V --test-dir build_test`
- CI impact: C ABI rename is breaking.

## Risk & rollout notes
- Risk level: medium — C ABI rename affects ABI-stable boundary; recompile required.
- Rollout/migration: Update all `TVMFFITypeExtraInfo` / `extra_info` references to `TVMFFITypeMetadata` / `metadata`.
- Follow-ups: Enable custom s_hash/equal via TypeAttr.
