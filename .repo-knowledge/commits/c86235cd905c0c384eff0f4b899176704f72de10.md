# c86235c — refactor: Remove Unused `OBJECT_INDEX` from Cython (#28)

## TL;DR
- Removes the `OBJECT_INDEX` dict (type-class → type-index mapping) from Cython's `object.pxi`.
- The dict was populated but never read; the corresponding `OBJECT_INDEX[cls] = index` assignment is also removed.

## Why (intent / motivation)
- Dead code removal. The `OBJECT_INDEX` reverse mapping was superseded by the `TYPE_INDEX_TO_INFO`/`TYPE_KEY_TO_INFO` infrastructure introduced subsequently. Removing it reduces memory use and eliminates a potential source of confusion.

## What changed (facts from diff)
- `python/tvm_ffi/cython/object.pxi`: Removed `cdef dict OBJECT_INDEX = {}` declaration and `OBJECT_INDEX[cls] = index` assignment in `_register_object_by_index`.
