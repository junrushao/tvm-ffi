# 929effa — [DLPACK] Update dlpack conversion to enable f4 (#22)

## TL;DR
- Adds full bidirectional DLPack-to-ATen conversion for `Float4_e2m1fn_x2` (f4) data type.
- Fixes the existing `getDLDataTypeForDLPackv1` function to correctly set `lanes=2` and `bits=4` for this type.
- Introduces a new comprehensive `toScalarTypeForDLPackv1` function replacing the old `toScalarType` call.
- Moves the `tvm_ffi_python_helpers.h` install location to be under the Python build step.
- Bumps version to `0.1.0b4`.

## Why (intent / motivation)
- The Float4_e2m1fn_x2 type was partially supported (export only) and had a bug in the DLPack dtype fields. This completes the round-trip so tensors of this type can be exchanged between PyTorch and TVM via DLPack.

## What changed (facts from diff)
- `python/tvm_ffi/_optional_torch_c_dlpack.py`: Added `dtype.lanes = 2; dtype.bits = 4` for Float4_e2m1fn_x2 in `getDLDataTypeForDLPackv1`; added full `toScalarTypeForDLPackv1` function covering all DLPack dtype codes; changed `fromDLPackImpl` to call `toScalarTypeForDLPackv1` instead of `toScalarType`.
- `CMakeLists.txt`: Moved `tvm_ffi_python_helpers.h` install from the general section into the Python module section.
- `pyproject.toml`: Version `0.1.0b3` → `0.1.0b4`.

## Public surface changes (if any)
