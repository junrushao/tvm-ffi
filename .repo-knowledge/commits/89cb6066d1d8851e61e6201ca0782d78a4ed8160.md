# 89cb606 — fix(build): Broken Wheel Testing (#444)

## TL;DR
- Fixes a regression introduced by PR #441 that broke cibuildwheel's wheel testing
- Changes `test-extras = ["test"]` to `test-groups = ["test"]` in the `[tool.cibuildwheel]` section of `pyproject.toml`
- One-line fix following the migration from `optional-dependencies` to `dependency-groups`

## Why (intent / motivation)
- PR #441 moved `test` from `[project.optional-dependencies]` to `[dependency-groups]`, but the `cibuildwheel` config still used `test-extras` which references optional-dependencies
- This caused wheel testing to install without the test dependencies, silently skipping tests

## What changed (facts from diff)
- `pyproject.toml`: `test-extras = ["test"]` → `test-groups = ["test"]` in `[tool.cibuildwheel]` section (+1/-1)
