# 4147ba7 — [FIX] Fixes from_dlpack issue fallback (#301)

## TL;DR
- Fixes `_from_dlpack_universal` in `tensor.pxi` to use the new `_get_dlpack_exchange_api()` helper instead of direct integer cast
- Adds test `test_from_dlpack_torch` covering the dlpack universal fallback path

## Why (intent / motivation)
- After the PyCapsule migration (#288), `_from_dlpack_universal` still used the old direct integer cast `<long long>(ext_tensor.__c_dlpack_exchange_api__)`, breaking `tvm_ffi.from_dlpack(torch_tensor)` when the attribute is a PyCapsule

## What changed (facts from diff)
- `python/tvm_ffi/cython/tensor.pxi`: In `_from_dlpack_universal`, declared a `const DLPackExchangeAPI* exchange_api = NULL` local variable; replaced direct integer cast with `_get_dlpack_exchange_api()` call; changed `DLPackExchangeAPI*` parameter to `const DLPackExchangeAPI*` in `_from_dlpack_exchange_api`
- `tests/python/test_dlpack_exchange_api.py`: Added `test_from_dlpack_torch()` to cover the fix
