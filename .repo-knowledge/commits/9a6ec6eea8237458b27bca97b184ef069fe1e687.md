# 9a6ec6e — [Docs] Fix Rust Docs (#172)

## TL;DR
- Fixes Rust docs build by using the Sphinx `build-finished` hook to copy the generated docs to the correct output directory.
- Removes incorrect pre-build copy that targeted the source tree instead of the output.
- Adds `_copy_rust_docs_to_output()` callback connected via `app.connect("build-finished", ...)`.

## Why (intent / motivation)
- The previous approach copied generated Rust docs to `docs/reference/rust/generated` in the source tree, which is the wrong location for the Sphinx output; this caused the docs to not appear in the built site.

## What changed (facts from diff)
- `docs/conf.py`: Removed `_RUST_OUTPUT_DIR` path constant and the `shutil.copytree(target_doc, _RUST_OUTPUT_DIR)` call from `_build_rust_docs()`.
- New `_copy_rust_docs_to_output(app, exception)` function registered with `build-finished` event; copies from `rust/target/doc` to `{outdir}/reference/rust/generated` after a successful build.
- Added `from __future__ import annotations` import.
