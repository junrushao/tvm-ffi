# 9432896 — [CMAKE] Fix packaging 3rdparty (#18)

## TL;DR
- Fixes CMake `install` directory paths for `3rdparty/dlpack` and `3rdparty/libbacktrace` by adding trailing slashes.
- Bumps the Python package version from `0.1.0b2` to `0.1.0b3`.

## Why (intent / motivation)
- CMake's `install(DIRECTORY ...)` command has different behavior with and without trailing slashes: a trailing slash copies only the directory contents, while omitting it copies the directory itself. The fix ensures headers are installed at the correct paths.

## What changed (facts from diff)
- `CMakeLists.txt`: Added trailing `/` to both the source and destination of dlpack and libbacktrace install directives.
- `pyproject.toml`: Version bumped to `0.1.0b3`.
