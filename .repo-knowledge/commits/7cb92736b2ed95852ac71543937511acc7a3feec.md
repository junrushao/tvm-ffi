# 7cb9273 — [FFI][REFACTOR] Migrate the Save/Load JSON to the new reflection (#18188)

## TL;DR
- Adds `include/tvm/ffi/reflection/creator.h` with `reflection::ObjectCreator`, a helper that creates objects from their type key and a `Map<String, Any>` of fields using the reflection registry.
- Updates `serialization.cc` to use `ObjectCreator` during deserialization and to handle `Shape` as a primitive type.
- Renames `tests/cpp/test_reflection_accessor.cc` to `tests/cpp/test_reflection.cc`.

## Why (intent / motivation)
- The deserializer previously relied on ad hoc `getattr`-style attribute setting; using `ObjectCreator` through the reflection registry is cleaner, type-safe, and consistent with the new reflection API.
- Centralizing object construction logic in `ObjectCreator` allows deserialization to benefit from default-value handling and proper error reporting for missing/extra fields.

## What changed (facts from diff)
- `include/tvm/ffi/reflection/creator.h` (new, 112 lines): `ObjectCreator` class constructed from `type_key` or `TVMFFITypeInfo*`; `operator()(Map<String, Any>)` calls `metadata->creator`, iterates fields via `ForEachFieldInfo`, applies setters, handles defaults, and reports errors for missing/extra fields.
- `src/ffi/extra/serialization.cc` (+13/-2): deserializer updated to use `ObjectCreator`; `Shape` recognized as a primitive type (stored directly, not as a node reference); allows `data_to_json` to return `json::Value` (not just `json::Object`).
- `tests/cpp/extra/test_serialization.cc` (+18/-0): additional tests for `Shape` serialization and new deserialization paths.
- `tests/cpp/{test_reflection_accessor.cc => test_reflection.cc}` (+6/-0): file renamed; minor test additions.
- `tests/cpp/testing_object.h` (+1/-0): minor addition to support new test cases.

## Public surface changes (if any)
- API: new header `include/tvm/ffi/reflection/creator.h`; new class `reflection::ObjectCreator`.
- Flags/config: none.
- Data formats/schemas: `Shape` fields now stored as primitives in JSONGraph (may change serialized form for objects with `Shape` fields).

## Tests & verification
- Added/updated tests: `tests/cpp/extra/test_serialization.cc` (+18 lines), `tests/cpp/test_reflection.cc` (renamed, +6 lines).
- How to verify manually: `cmake --build build_test && ctest -V --test-dir build_test --tests-regex serialization`
- CI impact: test file rename requires CMakeLists update if test is listed by name; minor.

## Risk & rollout notes
- Risk level: low — additive; `ObjectCreator` is new public API with no existing callers.
- Rollout/migration: Replace ad hoc object construction via attribute setting with `reflection::ObjectCreator(type_key)(fields_map)`.
- Follow-ups: Phase out remaining getattr-based attribute handling.
