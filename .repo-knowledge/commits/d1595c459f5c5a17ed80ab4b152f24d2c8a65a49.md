# d1595c4 — [ADDON] Add torch c dlpack ext wheels for windows (#252)

## TL;DR
- Added a new Windows CI workflow (`.github/workflows/torch_c_dlpack_windows.yml`) to build and publish `torch-c-dlpack-ext` AOT wheels for Windows AMD64.
- Added `addons/torch_c_dlpack_ext/build_aot_wheels.bat` batch script supporting torch versions 2.4–2.9 and Python 3.9–3.14.
- Fixed include path handling to support paths with spaces on Windows.
- Added CUDA `.lib` file linking for Windows CUDA builds.

## Why (intent / motivation)
- Windows users were previously unable to install AOT-compiled `torch-c-dlpack-ext` wheels, requiring JIT compilation which may not succeed in all environments.

## What changed (facts from diff)
- `.github/workflows/torch_c_dlpack.yml`: Renamed `build_wheels` job to `build_wheels_linux`; updated artifact names and `upload_pypi` dependencies.
- `.github/workflows/torch_c_dlpack_windows.yml`: New workflow running on `windows-latest` with CUDA toolkit, building across arch/python matrix.
- `addons/torch_c_dlpack_ext/build_aot_wheels.bat`: Full batch script: creates venvs, installs torch, builds CPU and CUDA variants, tags wheels for `win_amd64`.
- `python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py`: Fixed include path quoting for spaces; added `torch_cuda.lib`/`c10_cuda.lib` to Windows CUDA linker flags.
