# 7786133 — feat(stub): use distinct container type origins in type schema and stub generation (#469)

## TL;DR
- TypeSchema now emits `Array`, `List`, `Map`, `Dict` as distinct container origins instead of collapsing all to `list` / `dict`.
- Generated stubs use `MutableSequence`/`MutableMapping` for `List`/`Dict` and `Sequence`/`Mapping` for `Array`/`Map`.
- Adds a new `docs/concepts/containers.rst` page documenting all five container types, their mutability semantics, thread safety, and usage guidance.
- Updates C++ and Python language guides with `List` and `Dict` sections.
- `CLAUDE.md` updated with Dict/List mentions.

## Why (intent / motivation)
- Collapsing immutable (`Array`, `Map`) and mutable (`List`, `Dict`) containers to the same Python ABC in stubs lost the semantic distinction. Downstream type checkers could not distinguish the two, making incorrect mutations invisible at the type level.
