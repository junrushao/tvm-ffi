# d87502a — chore(build): Skip Python 3.8 on arm64 macOS (#150)

## TL;DR
- Adds `CIBW_SKIP: "cp38-macosx_*"` to the wheel publish workflow to skip building Python 3.8 wheels on arm64 macOS.
- ARM64 macOS does not have a native Python 3.8 build, making cp38 wheels pointless on that platform.

## Why (intent / motivation)
- Apple Silicon (arm64) Macs do not have an ARM64-native Python 3.8, so building cp38 wheels there is wasteful and prone to failure.

## What changed (facts from diff)
- `.github/workflows/publish_wheel.yml`: added `CIBW_SKIP: "cp38-macosx_*"` environment variable.
