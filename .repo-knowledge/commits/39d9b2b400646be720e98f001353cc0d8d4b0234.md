# 39d9b2b — [CORE] Enable customized AnyHash/Equal in Object Type attr (#451)

## TL;DR
- Extends `AnyHash` and `AnyEqual` functors to consult per-type-attribute columns (`__any_hash__`, `__any_equal__`) when hashing or comparing object-typed `Any` values.
- Supports both raw function pointer (fast path) and `ffi::Function` object dispatch.
- Moves `MoveFromSafeCallRaised` and `SetSafeCallRaised` from `function_details.h` to `error.h` (now accessible without depending on `function.h`).
- Adds tests for `CustomAnyHash` and `CustomAnyEqual` on two test types (`TInt` via opaque ptr, `TFloat` via ffi::Function).

## Why (intent / motivation)
- Allows objects to override the default pointer-based hash and equality with structural or value-based logic, enabling use in `AnyHash`-keyed containers without manual conversion.

## What changed (facts from diff)
- `include/tvm/ffi/any.h`: `AnyHash` and `AnyEqual` gain private `GetAnyHashTypeAttrColumn()`/`GetAnyEqualTypeAttrColumn()` and `CallCustomAnyHash()`/`CallCustomAnyEqual()` methods; lookup uses static `TVMFFITypeAttrColumn*`.
- `include/tvm/ffi/error.h`: `MoveFromSafeCallRaised()` and `SetSafeCallRaised()` moved here (+19 lines).
- `include/tvm/ffi/function_details.h`: same functions removed (-20 lines).
- `src/ffi/container.cc`: calls `EnsureTypeAttrColumn("__any_hash__")` and `EnsureTypeAttrColumn("__any_equal__")` in the static init block.
- `tests/cpp/testing_object.h`: `TInt` and `TFloat` register `__any_hash__` and `__any_equal__` type attributes; `TIntObj::RegisterReflection` updated accordingly.
- `tests/cpp/test_any.cc`: new tests `CustomAnyHash` and `CustomAnyEqual`.

## Public surface changes (if any)
- API: `__any_hash__` and `__any_equal__` type attribute names are now consulted by `AnyHash`/`AnyEqual`; must be registered via `TypeAttrDef`
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/cpp/test_any.cc` +30 lines, 2 new tests
- How to verify manually: `ctest -V --test-dir build_test -R Any`
- CI impact: none

## Risk & rollout notes
- Risk level: medium — modifies core hash/equal functors that are on the hot path for container operations
- Rollout/migration: Existing types without `__any_hash__`/`__any_equal__` attrs continue to use pointer-based defaults
