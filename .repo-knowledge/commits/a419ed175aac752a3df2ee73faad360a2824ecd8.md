# a419ed1 — [FFI][REFACTOR] Update registry to have complete meta-data (#18062)

## TL;DR
- Removes the `TVM_FFI_BUILD_REGISTRY` CMake option (now always included in the build).
- Adds `TVM_FFI_STATIC_INIT_BLOCK` / `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` macros for registration-time initialization.
- Extends `TVMFFITypeInfo` and `TVMFFITypeExtraInfo` with new metadata fields (`total_size`, `creator`, `doc`).
- Adds `TVMFFITypeRegisterExtraInfo` C API function and `TypeTable::RegisterTypeExtraInfo`.
- Updates `src/ffi/function.cc` to register module info via `TVM_FFI_STATIC_INIT_BLOCK`.

## Why (intent / motivation)
- The registry now needs to carry complete metadata (size, creator, doc string) to support Python reflection binding without requiring separate registration passes.
- Removing the `BUILD_REGISTRY` toggle simplifies the build model — the registry is always present.

- `CMakeLists.txt` (+0/-10): removed `TVM_FFI_BUILD_REGISTRY` option block.
- `include/tvm/ffi/base_details.h` (+7/-0): added `TVM_FFI_STATIC_INIT_BLOCK` and `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` macros.
- `include/tvm/ffi/c_api.h` (+79/-20): added `TVMFFITypeExtraInfo` struct (`total_size`, `creator`, `doc`); added `TVMFFITypeRegisterExtraInfo` function declaration.

- `src/ffi/object.cc` (+33/-13): implemented `TypeTable::RegisterTypeExtraInfo`; registers `Object` base type extra info at startup.
