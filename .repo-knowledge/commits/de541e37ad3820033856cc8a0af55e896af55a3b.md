# de541e3 — [FFI] Lightweight json parser/writer (#18186)

## TL;DR
- Adds a minimalistic JSON parser (`src/ffi/extra/json_parser.cc`) and writer (`src/ffi/extra/json_writer.cc`) to the `extra` subsystem.
- Introduces `include/tvm/ffi/extra/json.h` with type aliases `json::Value = Any`, `json::Object = Map<Any,Any>`, `json::Array = Array<Any>` and two public functions `json::Parse` and `json::Stringify`.
- Registers global functions `ffi.json.Parse` and `ffi.json.Stringify` via `GlobalDef`.

## Why (intent / motivation)
- The upcoming JSONGraph serialization needs a lightweight JSON layer that integrates directly with the `Any`/`Map`/`Array` type system, avoiding a heavy third-party dependency.
- Reusing `ffi::Any` as `json::Value` keeps the parser output immediately usable by all FFI consumers without conversion.

## What changed (facts from diff)
- `include/tvm/ffi/extra/json.h` (new, 84 lines): defines `json::Value`, `json::Object`, `json::Array` aliases; declares `json::Parse(String, String*)` and `json::Stringify(json::Value, Optional<int>)`; guarded by `TVM_FFI_EXTRA_CXX_API`.
- `src/ffi/extra/json_parser.cc` (new, 692 lines): `JSONParserContext` class with `Peek`/`SkipNextAssumeNoSpace`/`SkipSpaces` helpers; recursive descent parser supporting null/bool/int64/double/string/array/object; supports JavaScript-style `Infinity`/`NaN`; registers `ffi.json.Parse` global.
- `src/ffi/extra/json_writer.cc` (new, 266 lines): serializes `Any` back to JSON string with optional indent; registers `ffi.json.Stringify` global.
- `CMakeLists.txt` (+2): adds `json_parser.cc` and `json_writer.cc` to `tvm_ffi_objs_sources` under `TVM_FFI_USE_EXTRA_CXX_API`.
- `tests/cpp/extra/test_json_parser.cc` (new, 363 lines): comprehensive parser tests for all JSON types, error paths, int64 precision, Infinity/NaN.
- `tests/cpp/extra/test_json_writer.cc` (new, 241 lines): writer tests for roundtrip correctness and indent formatting.

## Public surface changes (if any)
- API: new header `include/tvm/ffi/extra/json.h`; new public functions `json::Parse` and `json::Stringify` in `tvm::ffi::json` namespace; new global functions `ffi.json.Parse` / `ffi.json.Stringify`.
- Flags/config: requires `TVM_FFI_USE_EXTRA_CXX_API=ON` to compile the parser/writer sources.
- Data formats/schemas: none (standard JSON, with int64 and Infinity/NaN extensions).

## Tests & verification
- Added/updated tests: `tests/cpp/extra/test_json_parser.cc` (363 lines) and `tests/cpp/extra/test_json_writer.cc` (241 lines).
- How to verify manually: `cmake --build build_test && ctest -V --test-dir build_test --tests-regex json`
- CI impact: none beyond added test targets.

## Risk & rollout notes
- Risk level: medium — adds new compiled sources behind the `TVM_FFI_USE_EXTRA_CXX_API` flag; no changes to existing code.
- Rollout/migration: Include `<tvm/ffi/extra/json.h>` and build with `TVM_FFI_USE_EXTRA_CXX_API=ON`.
- Follow-ups: JSONGraph serialization built on top of this layer.
