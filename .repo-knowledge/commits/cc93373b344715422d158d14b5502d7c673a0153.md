# cc93373 — refactor: Prefer `bytearray_to_str|bytes` to raw Python API (#6)

## TL;DR
- Adds a new `bytearray_to_bytes` Cython inline helper in `base.pxi` (symmetric to existing `bytearray_to_str`).
- Replaces all raw `py_str(PyBytes_FromStringAndSize(...))` and bare `PyBytes_FromStringAndSize(...)` calls throughout the Cython code with the cleaner `bytearray_to_str(&x)` / `bytearray_to_bytes(&x)` helpers.

## Why (intent / motivation)
- Reduces code duplication, improves readability, and centralizes the byte-array-to-Python-object conversion logic.

## What changed (facts from diff)
- `python/tvm_ffi/cython/base.pxi`: Added `bytearray_to_bytes` inline.
- `python/tvm_ffi/cython/dtype.pxi`: Two `DataType.__str__` usages updated.
- `python/tvm_ffi/cython/function.pxi`: `make_ret_small_str`, `make_ret_small_bytes`, and field/method name extraction in `_add_class_attrs_by_reflection` updated.
- `python/tvm_ffi/cython/object.pxi`: `_type_index_to_key` updated.
- `python/tvm_ffi/cython/string.pxi`: `_string_obj_get_py_str` and `_bytes_obj_get_py_bytes` updated.
