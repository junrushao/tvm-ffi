# 3115b23 — [FEAT] kwargs wrapping utility (#309)

## TL;DR
- Adds `python/tvm_ffi/utils/kwargs_wrapper.py` with `make_kwargs_wrapper()` and `make_kwargs_wrapper_from_signature()` for wrapping positional-only callables with kwargs support via code generation
- Uses `exec()` with controlled generated code (no untrusted input in generated string) following the pattern used by `dataclasses` and `pydantic`
- Special-cases `None` and `bool` defaults for direct embedding; all other defaults use a MISSING sentinel

## Why (intent / motivation)
- Provides a high-performance way to add keyword argument support to positional-only FFI functions without per-call `**kwargs` overhead; useful for wrapping exported C++ functions with Python-friendly call signatures
