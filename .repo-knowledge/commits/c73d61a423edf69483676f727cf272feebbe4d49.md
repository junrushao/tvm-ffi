# c73d61a — feat: add `__copy__`, `__deepcopy__`, and `__replace__` for FFI objects (#438)

## TL;DR
- Adds first-class Python `copy.copy`, `copy.deepcopy`, and dataclass-style `__replace__` support to all TVM-FFI objects.
- Introduces a new C++ `ffi.DeepCopy` global function with memoized graph copy preserving shared references and handling cycles.
- Auto-registers shallow copy for any copy-constructible reflected object type via `__ffi_shallow_copy__`.
- Adds `TestNonCopyable` test object to verify that non-copy-constructible types raise `TypeError`.

## Why (intent / motivation)
- Python's `copy` module had no support for FFI objects. Deep copy was especially important for correctness: mutable fields containing containers needed per-instance copies, not shared references.

## What changed (facts from diff)
- New C++ file `src/ffi/extra/deep_copy.cc` (+163 lines): `ObjectDeepCopier` class with memoization, iterative queue, handles `Array`, `List`, `Map`, and general objects via `ShallowCopy`.
- New header `include/tvm/ffi/extra/deep_copy.h` (+48 lines): declares `DeepCopy(const Any&)`.
- `include/tvm/ffi/reflection/registry.h`: new `type_attr::kShallowCopy` constant; `AutoRegisterCopy()` in `ObjectDef` constructor registers `__ffi_shallow_copy__` for copy-constructible types.
- `python/tvm_ffi/registry.py`: `_setup_copy_methods()` installs `__copy__`, `__deepcopy__`, `__replace__`; `_deepcopy_supported` calls `ffi.DeepCopy`.
- `python/tvm_ffi/dataclasses/c_class.py`: calls `_setup_copy_methods` after class creation.
- `python/tvm_ffi/dataclasses/_utils.py`: refactors method attachment to use `method.as_callable` directly.
- Testing: `src/ffi/testing/testing.cc` adds `TestDeepCopyEdgesObj` and `TestNonCopyable`; `TestObjectDerived` fields changed from `def_ro` to `def_rw`.
- New test file `tests/python/test_copy.py` (+690 lines): 50+ tests covering shallow copy, deep copy, shared references, cycles, non-copyable types.
- `CMakeLists.txt` registers `deep_copy.cc`.

## Public surface changes (if any)
- API: All reflected copy-constructible objects gain `__copy__`, `__deepcopy__`, `__replace__`; non-copyable types get raising stubs; new global `ffi.DeepCopy`
