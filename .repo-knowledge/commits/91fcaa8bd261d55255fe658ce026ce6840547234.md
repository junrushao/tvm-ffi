# 91fcaa8 — Revert "feat: Add `tvm_ffi.Function.__init__`" (#406)

## TL;DR
- Reverts commit `8786670` (PR #395) that added `tvm_ffi.Function.__init__(callable)`
- The constructor broke a downstream use-case that relied on the previous behavior of `Function` not accepting plain callables in its constructor
- Restores `function.pxi`, `core.pyi`, `test_function.py`, and `base_details.h` to pre-#395 state

## Why (intent / motivation)
- The `Function.__init__` constructor was reverted because a downstream codebase incorrectly depended on the previous behavior; the API design needs further discussion before re-introduction

- `python/tvm_ffi/cython/function.pxi`: Removed `__init__(self, func: Callable[..., Any])` method
