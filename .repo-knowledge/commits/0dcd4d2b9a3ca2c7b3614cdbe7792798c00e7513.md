# 0dcd4d2 — [CPP] Make Tensor/TensorView API to method-based (#121)

## TL;DR
- Replaces `operator->()` access on `Tensor` and `TensorView` with named accessor methods (`ndim()`, `dtype()`, `device()`, `data_ptr()`, `size(idx)`, `stride(idx)`, `byte_offset()`).
- Removes `operator->()` from `TensorView`; adds `GetDLTensorPtr()` to `Tensor` for raw pointer access.
- Propagates the change through all examples, docs, tests, and inline documentation in Python.

## Why (intent / motivation)
- Using `operator->()` to get `DLTensor*` is error-prone and obscures intent; method-based API is clearer and safer, and aligns with the project's ergonomic goals.

## What changed (facts from diff)
- `include/tvm/ffi/container/tensor.h`: Added `data_ptr()`, `device()`, `ndim()`, `dtype()`, `size(idx)`, `stride(idx)`, `byte_offset()`, `numel()` to both `Tensor` and `TensorView`; removed `operator->()` from `TensorView`; added `GetDLTensorPtr()` to `Tensor`; added `GetDataSize(Tensor)` and `GetDataSize(TensorView)` free functions.
- All call sites in examples (`add_one_cpu.cc`, `add_one_cuda.cu`, `extension.cc`, `run_example.cc`, etc.), docs, Python inline tests, and Rust scripts updated to use the new methods.
- `examples/packaging/python/my_ffi_extension/base.py`: Improved library search to scan multiple candidate directories.

## Public surface changes (if any)
- API: `Tensor::operator->()` removed (breaking); replaced by `GetDLTensorPtr()`. `TensorView::operator->()` removed (breaking). All named accessors are new additions.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/cpp/test_tensor.cc`, `tests/python/test_build_inline.py`, `tests/python/test_load_inline.py`
- How to verify manually: Build and run C++ tests; `uv run pytest -vvs tests/python/test_load_inline.py`
- CI impact: none

## Risk & rollout notes
- Risk level: medium — removes `operator->()` which is a breaking API change for any existing callers; mitigated by comprehensive update of all known call sites.
- Rollout/migration: Replace `tensor->field` with `tensor.field()` and `tensor->data` with `tensor.data_ptr()` etc.
- Follow-ups: none
