# 8eaefe0 — [FFI][EXTRA] Serialization To/From JSONGraph (#18187)

## TL;DR
- Introduces object-graph-aware JSON serialization: `ToJSONGraph` serializes an `Any` value into a JSON structure with a `nodes` array that preserves shared references; `FromJSONGraph` deserializes back.
- Adds `include/tvm/ffi/extra/serialization.h`, `src/ffi/extra/serialization.cc`, `include/tvm/ffi/extra/base64.h`, and a comprehensive test suite.
- Registers global functions `ffi.ToJSONGraph` and `ffi.FromJSONGraph`.

## Why (intent / motivation)
- A flat JSON representation cannot represent shared object references; the JSONGraph format (nodes array + root_index) preserves the full object graph topology required for correct round-trip serialization of TVM IR.
- Base64 encoding is needed to serialize `Bytes` fields within the JSON representation.

## What changed (facts from diff)
- `include/tvm/ffi/extra/serialization.h` (new, 72 lines): declares `ToJSONGraph(Any, Any metadata)` and `FromJSONGraph(json::Value)`; documents the JSON schema `{"root_index": int, "nodes": [...], "metadata": ...}` with each node as `{"type": "<type_key>", "data": <data>}`.
- `include/tvm/ffi/extra/base64.h` (new, 142 lines): header-only `Base64Encode(TVMFFIByteArray)` and `Base64Decode(TVMFFIByteArray)` utilities.
- `src/ffi/extra/serialization.cc` (new, 408 lines): `ObjectGraphSerializer` and `ObjectGraphDeserializer` classes; handles Object, String, Bytes (base64), primitives, Array, Map; uses `TypeAttrColumn` for `__data_to_json__` / `__data_from_json__` custom hooks; registers globals.
- `include/tvm/ffi/extra/json.h` (+1/-1): minor fix.
- `tests/cpp/extra/test_serialization.cc` (new, 354 lines): tests roundtrip for primitives, strings, bytes, objects with fields, nested objects, shared references.
- `tests/cpp/extra/test_structural_equal_hash.cc` (+3/-3): minor test updates.
- `tests/cpp/testing_object.h` (+17/-3): adds test object types with `__data_to_json__` / `__data_from_json__` registration to support serialization tests.
- `CMakeLists.txt` (+1): adds `serialization.cc` to `tvm_ffi_objs_sources`.

## Public surface changes (if any)
- API: new headers `include/tvm/ffi/extra/serialization.h` and `include/tvm/ffi/extra/base64.h`; new global functions `ffi.ToJSONGraph` / `ffi.FromJSONGraph`.
- Flags/config: requires `TVM_FFI_USE_EXTRA_CXX_API=ON`.
- Data formats/schemas: new JSONGraph format — `{"root_index": int, "nodes": [{"type": str, "data": ...}], "metadata": ...}`.

## Tests & verification
- Added/updated tests: `tests/cpp/extra/test_serialization.cc` (354 lines).
- How to verify manually: `cmake --build build_test && ctest -V --test-dir build_test --tests-regex serialization`
- CI impact: none beyond added test targets.

## Risk & rollout notes
- Risk level: medium — new compiled source behind `TVM_FFI_USE_EXTRA_CXX_API`; relies on `TypeAttrColumn` extension points for custom hooks.
- Rollout/migration: Include `<tvm/ffi/extra/serialization.h>` and build with `TVM_FFI_USE_EXTRA_CXX_API=ON`; implement `__data_to_json__` / `__data_from_json__` type attributes for custom object types.
- Follow-ups: Migrate existing Save/Load JSON to use new reflection-based creator.
