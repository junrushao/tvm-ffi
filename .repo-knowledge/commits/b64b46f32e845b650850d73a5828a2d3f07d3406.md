# b64b46f — [BUILD] Enable free threaded python build (#98)

## TL;DR
- Adds support for free-threaded Python (nogil / PEP 703) builds, targeting CPython 3.14t.
- Introduces `TVMFFIPyWithGILIfNotFreeThreaded` and `TVMFFIPyObjectDeleter` in `tvm_ffi_python_helpers.h` to handle GIL acquisition conditionally.
- Fixes `OpaquePyObject` not being recognized as an `Object` subtype by registering it with proper parent type index.
- CI adds Python 3.14t as a test matrix entry; wheels now include `cp314t-*`.

## Why (intent / motivation)
- Free-threaded Python removes the GIL and requires Cython modules to annotate themselves as `freethreading_compatible`. Python object deletion callbacks must work without explicitly acquiring the GIL when running in nogil mode.
- `OpaquePyObject` was incorrectly registered with `ReserveBuiltinTypeIndex` which does not set the parent, causing `isinstance` checks to fail.

## What changed (facts from diff)
- `python/tvm_ffi/cython/core.pyx`: adds `# cython: freethreading_compatible = True` directive.
- `python/tvm_ffi/cython/function.pxi`: removes `tvm_ffi_pyobject_deleter` (with-gil variant); uses shared `TVMFFIPyObjectDeleter`.
- `python/tvm_ffi/cython/tvm_ffi_python_helpers.h`: adds `TVMFFIPyWithGILIfNotFreeThreaded` RAII guard and `TVMFFIPyObjectDeleter` extern C function.
- `python/tvm_ffi/cython/base.pxi`: exposes `TVMFFIPyObjectDeleter` and corrects `deleter` field signature.
- `src/ffi/object.cc`: `OpaquePyObject` registered via `GetOrAllocTypeIndex` with `parent_type_index = kTVMFFIObject`.
- `CMakeLists.txt`: detects free-threaded Python; disables `USE_SABI` for 3.14t builds.
- `pyproject.toml`: excludes `torch` for Python >= 3.14; adds `cp314t-*` to wheel build matrix.
- CI: replaces Python 3.13 (x86_64) with 3.14t; macOS moves from 3.10 to 3.13.
- `tests/python/test_object.py`: uses relative ref-count offsets instead of absolute values.

## Public surface changes (if any)
- API: `TVMFFIPyObjectDeleter` exposed as C extern; `OpaquePyObject` now correctly `isinstance`-checks as `Object`.
- Flags/config: `cp314t-*` added to cibuildwheel build list.
- Data formats/schemas: none

## Tests & verification

- How to verify manually: Build with Python 3.14t; run `uv run pytest -vvs tests/python/test_object.py`
- CI impact: New matrix entry for Python 3.14t on Linux x86_64.
