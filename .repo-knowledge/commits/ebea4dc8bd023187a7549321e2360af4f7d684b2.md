# ebea4dc — [VERSION] Expose version (#62)

## TL;DR
- Exposes `__version__` string in the `tvm_ffi` Python package (`0.1.0b9`).
- Adds `pyproject.toml` as the single source of truth for version numbers.
- Adds a `check_version` pre-commit hook (`tests/lint/check_version.py`) that keeps `__init__.py` in sync with `pyproject.toml`.

## Why (intent / motivation)
- Version needs to be communicated across releases; rather than fully automating version management, this PR establishes a manual-but-enforced workflow using `pyproject.toml` as source of truth.

## What changed (facts from diff)
- `python/tvm_ffi/__init__.py` now defines and exports `__version__ = "0.1.0b9"`.
- New lint script `tests/lint/check_version.py` reads both `pyproject.toml` and `__init__.py`, fails if they differ, and auto-updates `__init__.py` to match `pyproject.toml`.
- `.pre-commit-config.yaml` registers the new `check-version` hook using `tomli` as an additional dependency.
- `pyproject.toml` version bumped from `0.1.0b8` to `0.1.0b9`.

## Public surface changes (if any)
- API: `tvm_ffi.__version__` is now a public attribute.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/lint/check_version.py` (lint-time check, not pytest).
- How to verify manually: `python tests/lint/check_version.py` from repo root; bump version in `pyproject.toml` only and run `pre-commit run check-version --all-files` to confirm auto-fix.
- CI impact: pre-commit hook will now enforce version consistency on every commit.
