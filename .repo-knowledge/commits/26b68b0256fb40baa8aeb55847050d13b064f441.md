# 26b68b0 — [FFI][REFACTOR] Phase out TVM_FFI_REGISTER_GLOBAL in favor of GlobalDef (#18148)

## TL;DR
- Removes the `Function::Registry` class and the `TVM_FFI_REGISTER_GLOBAL` macro from `function.h` (144 lines deleted).
- All global function registration is now done through `reflection::GlobalDef` (introduced in b333288).

## Why (intent / motivation)
- With all sites migrated to `GlobalDef`, the legacy macro and `Registry` class become dead code.
- Removing them enforces the new registration convention and reduces the public API surface.

## What changed (facts from diff)
- `include/tvm/ffi/function.h`: deleted `Function::Registry` class (including `set_body_packed`, `set_body_typed`, `set_body_method` methods), and deleted the `TVM_FFI_FUNC_REG_VAR_DEF` and `TVM_FFI_REGISTER_GLOBAL` macro definitions.

## Public surface changes (if any)
- API: `TVM_FFI_REGISTER_GLOBAL` macro and `Function::Registry` class are removed. Downstream code using `TVM_FFI_REGISTER_GLOBAL(...).set_body_typed(...)` must be migrated to `GlobalDef().def(...)`.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: none
- How to verify manually: `cmake --build build_test && ctest -V --test-dir build_test`
- CI impact: any downstream code using `TVM_FFI_REGISTER_GLOBAL` will fail to compile.

## Risk & rollout notes
- Risk level: medium — breaking change for any code using the macro.
- Rollout/migration: Replace `TVM_FFI_REGISTER_GLOBAL("name").set_body_typed(f)` with `TVM_FFI_STATIC_INIT_BLOCK({ refl::GlobalDef().def("name", f); })`.
- Follow-ups: none
