# 327e8cc — [ERROR] TVM_FFI_CHECK throw error condition (#69)

## TL;DR
- Adds a new `TVM_FFI_CHECK(ErrorKind, cond)` macro to `error.h` that throws a user-specified error kind (e.g., `ValueError`, `IndexError`) instead of always `InternalError`.
- Adds tests covering `ValueError`, `IndexError`, and passing-condition cases.

## Why (intent / motivation)
- `TVM_FFI_ICHECK` always throws `InternalError`; many situations require throwing typed errors (e.g., `ValueError`, `IndexError`) to surface meaningful error kinds across the FFI boundary.

## What changed (facts from diff)
- `include/tvm/ffi/error.h`: added `#define TVM_FFI_CHECK(ErrorKind, cond)` macro.
- `tests/cpp/test_error.cc`: added `TEST(CheckError, ValueError)`, `TEST(CheckError, IndexError)`, `TEST(CheckError, PassingCondition)` test cases.
