## TL;DR

Large commit that introduces `DLPackPyObjectExporter`, `DLPackPyObjectImporter`, and `DLPackTensorAllocator` C-level function pointer APIs for high-speed DLPack tensor exchange. Renames `TVMFFIEnvSetCurrentStream` -> `TVMFFIEnvSetStream`. Adds `func.release_gil` boolean option on Python `Function` objects. `TensorObj::ToDLPackVersioned()` now atomically caches the `DLManagedTensorVersioned*`. Adds PyTorch license attributions. Deletes `stream_context.cc`, replaced by `env_context.cc`.

## Why

DLPack tensor exchange between Python and C++ was going through Python-level object protocol overhead on every call. By exposing C-level function pointers (`DLPackPyObjectExporter`, `DLPackPyObjectImporter`) and a tensor allocator, the hot path for tensor passing can bypass Python object protocol entirely. The atomic caching in `TensorObj` eliminates repeated allocations when the same tensor is exported to DLPack multiple times.

## What changed

- `include/tvm/ffi/c_api.h`: Added `DLPackPyObjectExporter`, `DLPackPyObjectImporter`, `DLPackTensorAllocator` function pointer typedefs and their registration C API.
- `include/tvm/ffi/container/tensor.h`: `TensorObj` now atomically caches `DLManagedTensorVersioned*` via `std::atomic<DLManagedTensorVersioned*>`. Added `ToDLPackVersioned()` method with atomic cache check.
- `include/tvm/ffi/extra/c_env_api.h`: Renamed `TVMFFIEnvSetCurrentStream` -> `TVMFFIEnvSetStream`.
- `python/tvm_ffi/cython/function.pxi`: Added `func.release_gil` boolean attribute. Updated to use `TVMFFIEnvSetStream`.
- `python/tvm_ffi/cython/tvm_ffi_python_helpers.h`: Updated to use new exporter/importer APIs.
- `src/ffi/extra/env_context.cc` (new): Replaces `stream_context.cc`. Implements `TVMFFIEnvSetStream` and the new exporter/importer/allocator registration.
- `src/ffi/extra/stream_context.cc` (deleted): Superseded by `env_context.cc`.
- PyTorch license files added to `3rdparty/` or `addons/` for code adapted from PyTorch.
- `pyproject.toml`: Version bump.
- Tests updated.

## Public surface changes

**ABI breaking**:
- `TVMFFIEnvSetCurrentStream` renamed to `TVMFFIEnvSetStream`.
- New C API: `DLPackPyObjectExporter`, `DLPackPyObjectImporter`, `DLPackTensorAllocator` function pointer registration APIs.
- New Python option: `func.release_gil = True` to release the GIL during C function dispatch.
- `TensorObj` layout change: new `std::atomic` field added (binary incompatible with previous layout).

## Tests & verification

Existing tests updated for the renamed stream API. New tests exercise `release_gil` behavior and the exporter/importer paths.

## Risk & rollout notes

High risk: ABI breaking changes in `TensorObj` layout and `TVMFFIEnvSetStream` rename. All compiled TVM FFI modules must be recompiled. The `DLManagedTensorVersioned*` atomic cache adds a pointer-sized field to every `TensorObj` instance.
