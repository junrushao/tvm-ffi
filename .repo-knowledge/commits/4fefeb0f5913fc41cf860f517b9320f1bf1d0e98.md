# 4fefeb0 — [TENSOR] Allow strides to be null for zerodim case (#82)

## TL;DR
- Relaxes the `strides != nullptr` assertion in `Tensor::strides()`, `TensorView::strides()`, and the three `FromDLPack*` factories to allow null strides when `ndim == 0`.
- Fixes a crash on zero-dimensional tensors imported via DLPack.

## Why (intent / motivation)
- Zero-dimensional tensors (scalars) may have `strides == nullptr` per DLPack spec; the previous unconditional `ICHECK(strides != nullptr)` caused a spurious error for this valid case.

## What changed (facts from diff)
- `include/tvm/ffi/container/tensor.h`:
  - `Tensor::strides()`: condition changed to `TVM_FFI_ICHECK(obj->strides != nullptr || obj->ndim == 0)`.
  - `TensorView::strides()`: same condition added.
  - `Tensor::FromDLPackVersioned(DLManagedTensorVersioned*)` (two overloads) and `Tensor::FromDLPack(DLManagedTensor*)`: strides-at-tail branch condition changed from `strides != nullptr` to `strides != nullptr || ndim == 0`.
