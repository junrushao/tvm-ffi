# c100338 — [DOCS] Add C example (#15)

## TL;DR
- Adds `examples/quick_start/src/add_one_c.c` — a minimal, pure-C implementation of a TVM FFI-compatible function demonstrating the raw ABI.
- Expands `docs/get_started/quick_start.md` with a new "Advanced: Minimal C ABI demonstration" section (69 lines) showing the C code and `tvm-ffi-config` build command.
- Refines the C code example in `docs/guides/compiler_integration.md` to fix a bug (`DLTensor*` vs `DLTensor**` in `ReadDLTensorPtr`).
- Adds `--cflags` flag to the `tvm-ffi-config` CLI tool for C (not C++) compilation.
- Bumps version `0.1.0b1` → `0.1.0b2`; increases `TEST_DISCOVERY_TIMEOUT` to 600s.
- Moves `DLManagedTensorVersioned` forward declaration inside `extern "C"` guard in `c_api.h`; removes `v_char32` from `TVMFFIAny` union.

## Why (intent / motivation)
- Compiler codegen authors need a runnable, minimal C example showing exactly how to implement and expose a function following the TVM FFI ABI without any C++ machinery.
