# 7092774 — [CYTHON] Fix memory leak when tensor alloc returns to python (#87)

## TL;DR
- Fixes a memory leak where a `Tensor` allocated inside an FFI function and returned to Python would not properly release the C object handle.
- When DLPack conversion succeeds, `TVMFFIObjectDecRef` is now called on the original `chandle`; when it fails, the `dlpack.deleter` is called to free the managed tensor.

## Why (intent / motivation)
- The ownership count for the `Tensor` was transferred to `DLManagedTensor` on successful conversion, but the original `chandle` was not decremented, causing the object to never be freed.

## What changed (facts from diff)
- `python/tvm_ffi/cython/tensor.pxi`: in `make_tensor_from_chandle`, after a successful `c_dlpack_to_pyobject` conversion, `TVMFFIObjectDecRef(chandle)` is now called. On exception, `dlpack.deleter(dlpack)` is called before passing through.
- `tests/python/test_load_inline.py`: added `test_cuda_memory_alloc_noleak` (CUDA-only) that allocates and discards a tensor in a loop and asserts memory growth stays bounded.
- Version bumped to `0.1.0b15`.
