# 5e564cd — feat: add `DefaultFactory` support to field reflection (#446)

## TL;DR
- Introduces `reflection::DefaultFactory` as a callable `() -> Any` alternative to `DefaultValue`, to prevent aliasing of mutable defaults (e.g., `Array`, `Map`) across object instances.
- Renames `TVMFFIFieldInfo::default_value` to `default_value_or_factory` throughout all layers.
- Adds `kTVMFFIFieldFlagBitMaskDefaultFromFactory` (1 << 5) to distinguish factory from value.
- Centralizes default-setting logic in `SetFieldToDefault()` helper.

## Why (intent / motivation)
- `DefaultValue` stored a single static default shared across instances, causing aliasing bugs for mutable container defaults. `DefaultFactory` calls a function per instantiation to produce a fresh value each time, mirroring Python's `dataclasses.field(default_factory=...)`.

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: new `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5`; `default_value` field renamed to `default_value_or_factory` with expanded documentation.
- `include/tvm/ffi/reflection/accessor.h`: new `SetFieldToDefault()` helper that calls factory when the flag is set.
- `include/tvm/ffi/reflection/registry.h`: new `DefaultFactory` class, symmetric to `DefaultValue`.
- `include/tvm/ffi/reflection/creator.h`, `src/ffi/extra/reflection_extra.cc`, `src/ffi/extra/serialization.cc`: all use `SetFieldToDefault()` instead of direct `field_info->default_value` setter.
- `src/ffi/object.cc`: field storage updated to use `default_value_or_factory`.
- `python/tvm_ffi/cython/base.pxi`: new `kTVMFFIFieldFlagBitMaskDefaultFromFactory` constant; `default_value` renamed to `default_value_or_factory`.
- `rust/tvm-ffi-sys/src/c_api.rs`: field renamed with updated docs.
- `tests/cpp/test_reflection.cc`: new `TestObjWithFactory` struct; three new tests (`DefaultFactoryFlag`, `DefaultFactoryCreation`, `DefaultFactoryNotCalledWhenProvided`).

## Public surface changes (if any)
- API: `DefaultFactory` C++ trait, new in `registry.h`; `SetFieldToDefault()` helper; `kTVMFFIFieldFlagBitMaskDefaultFromFactory` in C ABI
- Flags/config: new flag bit `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5`
