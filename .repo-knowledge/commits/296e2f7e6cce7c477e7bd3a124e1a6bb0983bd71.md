# 296e2f7 — [FFI] Variant specialize for all ObjectRef (#17943)

## TL;DR
- Extends `Variant<T...>` to support all `ObjectRef` types as members via specialized type traits.
- Adds `AnyUnsafe::MoveFromAnyStorageAfterCheck` helper for zero-copy extraction from `Any`.
- Fixes a macro expansion bug in `TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY` where pointer operands lacked parentheses.
- Adds `all_any_compatible_v` concept to `container_details.h`.

## Why (intent / motivation)
- Previously `Variant` only supported a limited set of types stored in `Any`; this change generalizes it to accept any `ObjectRef` subtype, making the variant system fully composable with the object hierarchy.
- The macro fix prevents C macro expansion issues when the result argument is an expression.

## What changed (facts from diff)
- `include/tvm/ffi/any.h`: added `AnyUnsafe::MoveFromAnyStorageAfterCheck<T>` static method.
- `include/tvm/ffi/base_details.h`: fixed `TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY` macro to wrap `result` in parentheses.
- `include/tvm/ffi/container/container_details.h`: added `all_any_compatible_v<T...>` compile-time check.
- `include/tvm/ffi/container/variant.h`: major expansion (+78/-20) — specialized `TypeTraits<Variant<T...>>` to handle all ObjectRef members; added `TryConvertElements`, `MoveFromAnyStorageAfterCheck` dispatch.
- `tests/cpp/test_any.cc`: added 1 test.
- `tests/cpp/test_map.cc`: 1 line update.
- `tests/cpp/test_variant.cc`: added 27 lines of new test coverage for ObjectRef variants.
