# 11a4a02 — [REFACTOR][FFI] Update symbol name for library module (#18042)

## TL;DR
- Renames the `self` parameter to `handle` in two C API typedefs: `TVMFFISafeCallType` function pointer declaration and its doc comment.
- Minor doc fix: corrects `TVMFFIErrorSetRaisedByCStr` reference to `TVMFFIErrorSetRaisedFromCStr`.

## Why (intent / motivation)
- The parameter name `self` is semantically tied to OOP "this-pointer" conventions, while `handle` is more accurate for an opaque C function pointer context where the first argument is an opaque handle.
- Stabilizing the symbol name/semantics is a prerequisite for bringing the module system to the FFI layer.
