# 8786670 — feat: Add `tvm_ffi.Function.__init__` (#395)

## TL;DR
- Adds a `__init__` constructor to the Cython `Function` class, allowing `tvm_ffi.Function(callable)` to create a `tvm_ffi.Function` directly from any Python callable
- Updates the `.pyi` stub accordingly
- NOTE: This commit was later reverted in commit `91fcaa8` (#406) due to a downstream breakage

## Why (intent / motivation)
- Previously users had to use `tvm_ffi.convert(fn)` to wrap a Python callable; a direct `Function(fn)` constructor is more ergonomic and familiar

## What changed (facts from diff)
- `python/tvm_ffi/cython/function.pxi`: Added `__init__(self, func: Callable[..., Any])` method to `Function`; validates callability; if `func` is already a `Function`, increments the ref count and reuses the handle; otherwise calls `_convert_to_ffi_func_handle`
- `python/tvm_ffi/core.pyi`: Added `def __init__(self, func: Callable[..., Any]) -> None: ...` stub
- `include/tvm/ffi/base_details.h`: Minor Doxygen comment fixes (moved `/// \\endcond` tags, added `/*!` documentation for `TVM_FFI_STATIC_INIT_BLOCK`)
- `tests/python/test_function.py`: Added `test_pyfunc_init` verifying `tvm_ffi.Function(add)` produces a callable `Function` instance

## Public surface changes (if any)
- API: `tvm_ffi.Function.__init__(func: Callable[..., Any])` — NEW (reverted in #406)
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/python/test_function.py` (test_pyfunc_init)
- How to verify manually: `uv run pytest -vvs tests/python/test_function.py::test_pyfunc_init`
- CI impact: test was later removed with the revert

## Risk & rollout notes
- Risk level: medium — this commit was reverted; the constructor broke a downstream use-case
- Rollout/migration: See revert commit 91fcaa8 — the `Function.__init__` API was not released
- Follow-ups: The constructor may be re-introduced with a different approach that handles the problematic downstream pattern
