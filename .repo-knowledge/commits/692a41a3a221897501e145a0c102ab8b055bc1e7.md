# 692a41a — fix: add unified_api.h include to device_guard.h (#405)

## TL;DR
- Fixes a broken include in `include/tvm/ffi/extra/cuda/device_guard.h` introduced by refactoring in PR #300
- Replaces the stale `#include <tvm/ffi/extra/cuda/base.h>` with the correct `#include <tvm/ffi/extra/cuda/internal/unified_api.h>` needed to resolve `TVM_FFI_CHECK_CUDA_ERROR`
- NOTE: This include was subsequently reverted to `base.h` in commit `10cb004` when the unified API was isolated to only the cubin launcher

## Why (intent / motivation)
- After PR #300 moved `TVM_FFI_CHECK_CUDA_ERROR` to `unified_api.h`, `device_guard.h` still included the old `base.h` which no longer provided the macro, causing undefined symbol errors when compiling with CUDA

## What changed (facts from diff)
- `include/tvm/ffi/extra/cuda/device_guard.h`: Changed `#include <tvm/ffi/extra/cuda/base.h>` to `#include <tvm/ffi/extra/cuda/internal/unified_api.h>`
