# c22e10e — chore: fix compiler warnings (#378)

## TL;DR
- Removed trailing semicolons after `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro calls across multiple source files (the macro already expands to a statement ending with `}`)
- Added `[[maybe_unused]]` attribute to `num_args` parameter in `GetMismatchMessageAux` in `overload.h`

## Why (intent / motivation)
- Trailing semicolons after macro calls that expand to function definitions cause `-Wextra` / `-Wpedantic` "extra `;`" warnings on some compilers
- Unused `num_args` parameter in a template function triggered `-Wunused-parameter`

## What changed (facts from diff)
- Trailing `;` removed after `TVM_FFI_DLL_EXPORT_TYPED_FUNC(...)` in: `examples/cubin_launcher/dynamic_cubin/src/lib_dynamic.cc`, `examples/cubin_launcher/embedded_cubin/cpp_embed/src/lib_embedded.cc`, `examples/cubin_launcher/embedded_cubin/embed_with_tvm_ffi/src/lib_embedded.cc`, `examples/cubin_launcher/embedded_cubin/include_bin2c/src/lib_embedded.cc`, `examples/python_packaging/src/extension.cc`, `examples/quickstart/compile/add_one_cpu.cc`
