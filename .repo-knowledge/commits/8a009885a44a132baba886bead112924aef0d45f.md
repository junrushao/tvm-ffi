# 8a00988 — [REFACTOR][FFI] Phase out legacy C API (#18010)

## TL;DR
- Introduces `TVM_FFI_WEAK` macro for platform-portable weak symbol linking (`__declspec(selectany)` on MSVC, `__attribute__((weak))` on GCC/Clang).
- Updates `TVM_REGISTER_GLOBAL` documentation reference to `TVM_FFI_REGISTER_GLOBAL`.
- Part of the broader effort to remove legacy C API scaffolding.

## Why (intent / motivation)
- Weak linking support is needed to allow shared-library functions to be optionally overridden by addons or downstream users without causing linker errors.
- Phasing out `TVM_REGISTER_GLOBAL` in favor of `TVM_FFI_REGISTER_GLOBAL` completes the naming migration from old TVM API to the new FFI API.

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: added `TVM_FFI_WEAK` macro (MSVC: `__declspec(selectany)`, others: `__attribute__((weak))`).
- `include/tvm/ffi/function.h`: updated doc comment from `TVM_REGISTER_GLOBAL` to `TVM_FFI_REGISTER_GLOBAL`.
