## TL;DR

Introduces a `__tvm_ffi_env_stream__()` protocol for non-torch tensors to communicate their associated compute stream to TVM FFI. Renames `TVMFFIEnvSetStream` to `TVMFFIEnvSetCurrentStream`. Adds `DLTensorTestWrapper` Cython class implementing the protocol. Adds `kDLMAIA` and `kDLTrn` device type constants from newer DLPack.

## Why

Previously, TVM FFI could only retrieve the current compute stream from PyTorch tensors via `torch._C._cuda_getCurrentRawStream`. Non-torch tensors (e.g., from other frameworks or test code) had no way to communicate their stream context. The `__tvm_ffi_env_stream__()` protocol provides a generic mechanism: any tensor object that defines this method can communicate its stream to TVM FFI during function dispatch.

## What changed

- `include/tvm/ffi/extra/c_env_api.h`: Renamed `TVMFFIEnvSetStream` -> `TVMFFIEnvSetCurrentStream`. Added declaration for stream exchange protocol handling.
- `src/ffi/extra/stream_context.cc`: Updated to use `TVMFFIEnvSetCurrentStream`. Added logic to call `__tvm_ffi_env_stream__()` on tensor arguments during dispatch.
- `python/tvm_ffi/cython/base.pxi`: Added `kDLMAIA` and `kDLTrn` device type constants. Moved DLPack `cdef extern` block before TVM C API block for correct include ordering.
- `python/tvm_ffi/cython/function.pxi`: Updated to check for `__tvm_ffi_env_stream__` attribute on tensor arguments and call it to get the stream handle.
- `python/tvm_ffi/cython/tensor.pxi`: Added `DLTensorTestWrapper` Cython class that implements the `__tvm_ffi_env_stream__()` protocol for testing.
- `scripts/benchmark_dlpack.py`: Updated to use renamed API.

## Public surface changes

- **ABI breaking**: `TVMFFIEnvSetStream` renamed to `TVMFFIEnvSetCurrentStream` in `c_env_api.h`.
- New protocol: objects can implement `__tvm_ffi_env_stream__()` to provide stream context.
- New DLPack device constants: `kDLMAIA`, `kDLTrn`.
- New Python test utility: `DLTensorTestWrapper`.

## Tests & verification

`DLTensorTestWrapper` implements the protocol for use in tests. Stream exchange behavior tested via the wrapper class.

## Risk & rollout notes

Medium risk. `TVMFFIEnvSetCurrentStream` rename is ABI-breaking for C code using the old name. The stream protocol is new and additive for Python. New device type constants are purely additive.
