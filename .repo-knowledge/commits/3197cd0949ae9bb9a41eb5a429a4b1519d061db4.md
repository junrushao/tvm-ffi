# 3197cd0 — Add stream context (#5)

## TL;DR
- Introduces `StreamContext`, `use_raw_stream`, and `use_torch_stream` to the Python API.
- Exposes `_env_set_current_stream` via Cython to allow Python to set the FFI environment stream.
- Supports wrapping raw stream handles, PyTorch stream contexts, and CUDA graph contexts.
- Adds comprehensive tests covering all three use cases.

## Why (intent / motivation)
- Enables Python code to inform the TVM FFI environment which stream is currently active, which is essential for correct GPU kernel scheduling when running alongside PyTorch or other frameworks that manage their own CUDA streams.

## What changed (facts from diff)
- New file `python/tvm_ffi/stream.py` adds `StreamContext`, `TorchStreamContext`, `use_torch_stream`, and `use_raw_stream`.
- `python/tvm_ffi/cython/base.pxi` gains `_env_set_current_stream` Cython function wrapping `TVMFFIEnvSetStream`.
- `python/tvm_ffi/__init__.py` re-exports the new symbols.
- `docs/reference/python/index.rst` adds a "Stream Context" section to the API reference.
- New test file `tests/python/test_stream.py` with four test functions.

## Public surface changes (if any)
- API: `tvm_ffi.StreamContext`, `tvm_ffi.use_raw_stream(device, stream)`, `tvm_ffi.use_torch_stream(context=None)` added as new public symbols.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
