# 02d1a96 — feat: add starts_with and ends_with to String (#388)

## TL;DR
- Adds `starts_with()` and `ends_with()` methods to `tvm::ffi::String`, each with four overloads: `String`, `std::string_view`, `const char*`, and `const char* + count`
- Implements using `std::memcmp` with a short-circuit length check
- Covers both methods with comprehensive C++ GoogleTest cases

## Why (intent / motivation)
- Prefix/suffix checking is essential for validation and parsing in compiler infrastructure but required manual conversion to `std::string` or `std::string_view`

## What changed (facts from diff)
- `include/tvm/ffi/string.h`: +70 lines — added `starts_with(String)`, `starts_with(string_view)`, `starts_with(const char*)`, `starts_with(const char*, size_t)`, and four symmetric `ends_with` overloads; all delegate to the `(const char*, size_t)` base using `memcmp`
- `tests/cpp/test_string.cc`: +46 lines — `TEST(String, StartsWith)` and `TEST(String, EndsWith)` covering normal, empty, single-char, and too-long prefix/suffix cases
