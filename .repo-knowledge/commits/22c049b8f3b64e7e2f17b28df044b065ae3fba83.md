# 22c049b — Expose get stream method (#97)

## TL;DR
- Adds `get_raw_stream(device)` to the Python public API, exposing the current FFI stream handle for a given device.
- Implements `_env_get_current_stream(device_type, device_id)` in the Cython layer by calling `TVMFFIEnvGetStream`.
- Exports `get_raw_stream` from `tvm_ffi.__init__`.
- Adds three assertions in `test_stream.py` verifying stream values under nested `use_raw_stream` contexts.

## Why (intent / motivation)
- Follow-up to PR #5 which set the stream; now callers can also query the current stream for a device, useful for coordinating with external runtimes.
