# df04392 — [CMake] Enable automatic cmake config discovery (#124)

## TL;DR
- Relocates installed CMake config files from `cmake/` to `share/cmake/tvm_ffi/` matching CMake's standard search pattern.
- Enables `find_package(tvm_ffi CONFIG REQUIRED)` to work automatically after `pip install` without setting `tvm_ffi_ROOT` manually.
- Removes the `execute_process` boilerplate from example `CMakeLists.txt` files.
- Disables editable install rebuild to avoid redundant recompilation.

## Why (intent / motivation)
- CMake's standard install path is `<prefix>/<name>/share/cmake/<name>/`; placing the config file there allows automatic discovery when `find_package(Python)` is called, similar to pybind11's approach.

## What changed (facts from diff)
- `CMakeLists.txt`: Install config to `share/cmake/tvm_ffi/` and Utils to `share/cmake/tvm_ffi/Utils/`.
- `python/tvm_ffi/libinfo.py`: Updated `find_cmake_path()` to check standard install path first.
- `examples/packaging/CMakeLists.txt`, `examples/quick_start/CMakeLists.txt`: Removed `execute_process` calling `tvm_ffi.config --cmakedir`; now just `find_package(tvm_ffi CONFIG REQUIRED)`.
- `pyproject.toml`: Added `editable.rebuild = false`.
- `docs/guides/packaging.md`: Removed `execute_process` snippet.
- Example READMEs: Added `cd examples/...` step.
