# 3cfc5c5 — fix(config): `tvm-ffi-config --sourcedir` broken in wheels (#319)

## TL;DR
- Changes `find_source_path()` condition from checking for a `cmake/` subdirectory to checking for a `src/` subdirectory.
- Fixes `tvm-ffi-config --sourcedir` being broken in installed wheels because the `cmake/` directory lives at a different relative path than expected.

## Why (intent / motivation)
- Bug introduced in #306 (6887892): the new `find_source_path` checked for `${guess}/cmake` which does not exist at the expected location in installed wheels; `${guess}/src` is always present in the same relative position.

## What changed (facts from diff)
- `python/tvm_ffi/libinfo.py`: `cond=lambda p: (p / "cmake").is_dir()` -> `cond=lambda p: (p / "src").is_dir()`.

## Public surface changes (if any)
- API: `find_source_path()` now uses `src/` as the discriminant
