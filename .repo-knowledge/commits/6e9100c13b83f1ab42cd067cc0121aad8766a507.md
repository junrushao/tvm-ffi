# 6e9100c — MSVC compiler fix (#159)

## TL;DR
- Adds a forward declaration `class Tensor;` inside `namespace tvm::ffi` in `include/tvm/ffi/container/tensor.h`.
- Prevents MSVC compile errors caused by the class being referenced before it is fully defined.

## Why (intent / motivation)
- MSVC is stricter than GCC/Clang about forward references within the same header; the missing declaration caused build failures on Windows.

## What changed (facts from diff)
- `include/tvm/ffi/container/tensor.h`: added `class Tensor;` forward declaration at line 40 (namespace scope, before the first helper function that references `Tensor`).
