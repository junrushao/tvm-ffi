## TL;DR

Major cleanup of the `tvm_ffi` Python public API: renames several functions and properties, removes convenience device shortcut functions, renames internal modules, adds a `DLDeviceType` enum, and improves docstrings throughout. Approximately 25 files are touched.

## Why

The Python API had accumulated inconsistencies with the C++ API naming conventions and with Python best practices. This cleanup pass aligns naming (`register_func` -> `register_global_func`, `_init_api` -> `init_ffi_api`), removes ad-hoc device shortcut functions in favor of the `Device` constructor, and renames internal modules with underscore prefix to mark them as private.

## What changed

- `python/tvm_ffi/__init__.py`: Updated exports to reflect renamed symbols.
- `python/tvm_ffi/registry.py`: `register_func` -> `register_global_func`, `_init_api` -> `init_ffi_api`.
- `python/tvm_ffi/cython/device.pxi`: `device_id` property -> `index`; `device_type` property replaced by `dlpack_device_type()` method + `type` property returning `DLDeviceType` enum; shortcut functions `cpu()`, `cuda()`, etc. removed.
- `python/tvm_ffi/convert.py` -> `python/tvm_ffi/_convert.py` (marked private).
- `python/tvm_ffi/dtype.py` -> `python/tvm_ffi/_dtype.py` (marked private).
- `python/tvm_ffi/_tensor.py` (new): Python-side tensor utilities.
- Added `DLDeviceType` `IntEnum` exposing DLPack device type constants.
- `docs/reference/python/index.rst` (new): Python API reference RST page.
- Various docstring improvements across `Array`, `Map`, `Module`, `register_global_func`, etc.
- Tests and examples updated to use new API names.

## Public surface changes

**Breaking changes**:
- `tvm_ffi.register_func` -> `tvm_ffi.register_global_func`
- `tvm_ffi._init_api` -> `tvm_ffi.init_ffi_api`
- `Device.device_id` -> `Device.index`
- `Device.device_type` -> `Device.type` (returns `DLDeviceType` enum) / `Device.dlpack_device_type()` (returns int)
- Device shortcut functions (`tvm_ffi.cpu()`, `tvm_ffi.cuda()`, etc.) removed
- Internal modules renamed: `convert` -> `_convert`, `dtype` -> `_dtype`
- New: `tvm_ffi.DLDeviceType` enum, `tvm_ffi._tensor` module

## Tests & verification

All existing tests updated to use the new API names. No new test scenarios added. `tests/python/test_device.py` updated extensively.

## Risk & rollout notes

High risk: multiple breaking API changes. Downstream code using old names must be updated. Intentional as part of pre-1.0 API stabilization.

## Evidence

- ~25 files modified across `python/tvm_ffi/`, `docs/`, `tests/python/`, `examples/`
- Key renames: `register_func` -> `register_global_func`, `device_id` -> `index`, shortcut functions removed
