# 5cfd705 — chore: Revamp mypy config and publish typing metadata (#51)

## TL;DR
- Consolidates four separate mypy pre-commit hooks into a single project-wide hook (`pass_filenames: false`)
- Moves all mypy settings from per-hook args into `[tool.mypy]` in `pyproject.toml`, enabling argument-free `mypy` invocation from the repo root
- Adds `py.typed` marker file to enable PEP 561 typed-package consumption
- Pins mypy to v1.18.2 and sets `typing-extensions>=4.5` as minimum in `dependencies`

## Why (intent / motivation)
- Multiple redundant mypy hook definitions in pre-commit were hard to maintain and slow
- Downstream consumers of `apache-tvm-ffi` should be able to benefit from inline type annotations without manual stub installation (PEP 561)

## What changed (facts from diff)
- `.pre-commit-config.yaml`: four `mypy` hook entries replaced with one entry using `pass_filenames: false` and pinned to v1.18.2
- `pyproject.toml`: `[tool.mypy]` section expanded with `python_version`, `show_error_codes`, `mypy_path`, `files`, `namespace_packages`, `explicit_package_bases`, `exclude`; `[[tool.mypy.overrides]]` for `torch` and example modules
- `pyproject.toml`: `setuptools<81` in sdist include; `py.typed` included in wheels
- `python/tvm_ffi/py.typed`: new empty PEP 561 marker file
- `python/tvm_ffi/dataclasses/c_class.py`: removed fallback `try/except ImportError` for `dataclass_transform`, now always imports from `typing_extensions`
- `tests/lint/check_file_type.py`: `"py.typed"` added to `ALLOW_FILE_NAME`
