# 3fc0391 — [FFI][REFACTOR] Isolate out extra API (#18177)

## TL;DR
- Moves `StructuralEqual` and `StructuralHash` from `include/tvm/ffi/reflection/` to `include/tvm/ffi/extra/`.
- Moves corresponding source files from `src/ffi/reflection/` to `src/ffi/extra/`.
- Removes both classes from the `reflection` namespace (now directly in `ffi` namespace).
- Adds `include/tvm/ffi/extra/base.h` to house the `TVM_FFI_EXTRA_CXX_API` macro, removed from `c_api.h`.
- Renames `AccessKind` enum values: `kArrayIndex` → `kArrayItem`, `kMapKey` → `kMapItem`, etc.
- Renames global function `ffi.reflection.GetFirstStructuralMismatch` → `ffi.GetFirstStructuralMismatch` and `ffi.reflection.StructuralHash` → `ffi.StructuralHash`.

## Why (intent / motivation)
- Structural equal/hash are not part of the core reflection registry; they are "extra" functionality. Separating them reduces the public reflection API surface and makes the core/extra boundary explicit.
- Moving `TVM_FFI_EXTRA_CXX_API` to `extra/base.h` keeps `c_api.h` focused on C-only definitions.

## What changed (facts from diff)
- `include/tvm/ffi/extra/base.h` (new): `TVM_FFI_EXTRA_CXX_API` macro definition.
- `include/tvm/ffi/extra/structural_equal.h` (from `reflection/`): removed `reflection` namespace; `GetFirstMismatch` return type uses `reflection::AccessPathPair`.
- `include/tvm/ffi/extra/structural_hash.h` (from `reflection/`): similar namespace change.
- `include/tvm/ffi/reflection/access_path.h`: `AccessKind` values renamed (`kArrayIndex`→`kArrayItem`, `kMapKey`→`kMapItem`, missing variants similarly renamed); `AccessStep` factory methods renamed.
- `src/ffi/extra/structural_equal.cc`, `structural_hash.cc` (moved from `reflection/`): namespace references updated; global function names changed.
- `tests/cpp/extra/test_structural_equal_hash.cc` (renamed from `test_reflection_structural_equal_hash.cc`): uses `StructuralEqual`/`StructuralHash` directly (no `refl::` prefix); updated `AccessKind` enum names.
