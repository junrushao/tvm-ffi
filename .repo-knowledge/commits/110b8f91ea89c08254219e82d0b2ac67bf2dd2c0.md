# 110b8f9 — [REFACTOR][FFI] Cleanup PackedFunc related redirection (#17923)

## TL;DR
- Renames `Function::FromUnpacked` to `Function::FromTyped` to better reflect its purpose.
- Updates doc comments throughout `function.h` to replace legacy "PackedFunc" terminology with `ffi::Function`.
- Aligns test code to use the renamed API.

## Why (intent / motivation)
- Remove residual `PackedFunc` naming from the new FFI codebase, which uses `ffi::Function` as the canonical name.
- `FromUnpacked` was a confusing name; `FromTyped` clearly indicates that this creates a Function from a typed (non-packed) callable.

## What changed (facts from diff)
- `Function::FromUnpacked` renamed to `Function::FromTyped` in `function.h` and `function_details.h`.
- Doc comments updated: "PackedFunc" → "ffi::Function", "packed format" → "packed format via AnyView".
- `rvalue_ref.h`: minor comment cleanup.
- `src/ffi/container.cc` and `src/ffi/function.cc`: one-line updates to use new name.
- Tests (`test_array.cc`, `test_function.cc`, `test_map.cc`, `test_rvalue_ref.cc`, `test_tuple.cc`, `test_variant.cc`): updated call sites to use `FromTyped`.

## Public surface changes (if any)
- API: `Function::FromUnpacked` renamed to `Function::FromTyped` — breaking rename for any caller using `FromUnpacked`.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification

- How to verify manually: `cmake --build build_test && ctest -V --test-dir build_test`

## Risk & rollout notes
- Risk level: low — Pure rename; logic is unchanged. Any downstream code using `FromUnpacked` must update to `FromTyped`.
- Rollout/migration: Update all `FromUnpacked` call sites to `FromTyped`.
