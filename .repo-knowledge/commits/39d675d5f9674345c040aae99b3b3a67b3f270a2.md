# 39d675d — chore(release): Test wheels nightly (#157)

## TL;DR
- Replaces the `push: branches: [main]` trigger with a daily `schedule: cron: '0 9 * * *'` trigger in `publish_wheel.yml`.
- Removes the conditional `if:` check that prevented manylinux2014 builds on non-dispatch events.
- Publishing remains exclusively on `workflow_dispatch`.

## Why (intent / motivation)
- Building on every `main` commit can be noisy and consume too many CI minutes; a daily nightly build is a better balance.
- Nightly builds still catch regressions before manual releases.
