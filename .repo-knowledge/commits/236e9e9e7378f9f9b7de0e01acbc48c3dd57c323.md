## TL;DR

Marks all `load_inline` tests as `xfail` on non-Linux platforms (macOS, Windows) until cross-platform support is robustified. Adds `ninja` to the optional dependency groups in `pyproject.toml`.

## Why

The `load_inline` feature was initially implemented and verified only on Linux. Running the tests on macOS and Windows CI was causing failures that needed to be addressed separately. Using `pytest.mark.xfail` allows CI to continue without blocking while platform-specific issues are fixed.

## What changed

- `tests/python/test_load_inline.py`: Added `@pytest.mark.xfail(not sys.platform.startswith("linux"), reason="needs to robustify non-linux support")` decorator to all `load_inline` test functions.
- `pyproject.toml`: Added `ninja` to `[project.optional-dependencies]` groups `torch`, `cpp`, and `test`.

## Public surface changes

None. Test-only and build dependency change.

## Tests & verification

All `load_inline` tests are now marked `xfail` on non-Linux platforms, allowing CI to proceed without hard failures.

## Risk & rollout notes

Low risk. Temporary measure; subsequent commits address macOS and Windows support specifically.

## Evidence

- `pyproject.toml` (modified, ninja dependency added)
- `tests/python/test_load_inline.py` (modified, xfail markers added)
