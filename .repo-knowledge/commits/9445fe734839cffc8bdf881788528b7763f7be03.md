# 9445fe7 — [FFI] Structural equal and hash based on reflection (#18156)

## TL;DR
- Adds `StructuralEqual` and `StructuralHash` implementations driven by the reflection system, with new files in `src/ffi/reflection/`.
- Introduces `reflection::AccessPath` and `AccessStep` for structured mismatch reporting.
- Adds `TVMFFITypeAttrColumn` to the C ABI for column-indexed per-type attribute lookup, with `TVMFFITypeRegisterAttr` and `TVMFFIGetTypeAttrColumn`.
- Renames `TVMFFITypeExtraInfo` to `TVMFFITypeMetadata` and `TVMFFITypeRegisterExtraInfo` to `TVMFFITypeRegisterMetadata`.

## Why (intent / motivation)
- Unify structural equality/hash registration with the reflection system so types need only one registration point.
- Enable structured error paths (AccessPath) that report exactly which field differs.
- `TypeAttrColumn` supports a general per-type extensible attribute store (column-array pattern).

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: adds `TVMFFITypeAttrColumn`, `TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`; renames `TVMFFITypeExtraInfo` → `TVMFFITypeMetadata`; adds `TVMFFITypeRegisterMetadata`.
- `include/tvm/ffi/reflection/access_path.h` (new): `AccessKind`, `AccessStep`, `AccessPath`, `AccessPathPair`.
- `include/tvm/ffi/reflection/registry.h`: adds `TypeAttrDef` class for registering function or constant per-type attributes; adds `EnsureTypeAttrColumn`.
- `include/tvm/ffi/reflection/structural_equal.h` (new): `StructuralEqual` class.
- `include/tvm/ffi/reflection/structural_hash.h` (new): `StructuralHash` class.
- `src/ffi/object.cc`: adds `TypeAttrColumnData`, `RegisterTypeAttr`, `GetTypeAttrColumn` to `TypeTable`; renames `extra_info` → `metadata`.
- `src/ffi/reflection/access_path.cc`, `structural_equal.cc`, `structural_hash.cc` (new source files).
- `tests/cpp/test_reflection_structural_equal_hash.cc` (new): tests for Array, Map, nested containers, FreeVar, FuncDef+IgnoreField.
- `tests/cpp/testing_object.h`: adds `TypeAttrDef<TIntObj>` with test attrs.

## Public surface changes (if any)
- API: new C API functions `TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`; renamed `TVMFFITypeRegisterExtraInfo` → `TVMFFITypeRegisterMetadata`; `TVMFFITypeExtraInfo` → `TVMFFITypeMetadata`. Breaking ABI change on the `extra_info` field of `TVMFFITypeInfo` (now `metadata`).
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: `tests/cpp/test_reflection_structural_equal_hash.cc`; `tests/cpp/test_reflection_accessor.cc` (TypeAttrColumn test).
- How to verify manually: `cmake -DTVM_FFI_BUILD_TESTS=ON --build build_test && ctest -V --test-dir build_test`
- CI impact: C ABI rename is breaking for existing compiled code.

## Risk & rollout notes
- Risk level: high — C ABI rename (`TVMFFITypeExtraInfo` → `TVMFFITypeMetadata`); all pre-compiled binaries must be recompiled.
- Rollout/migration: Update all `TVMFFITypeExtraInfo`, `TVMFFITypeRegisterExtraInfo`, and `extra_info` references to new names.
- Follow-ups: Further migration of StructuralEqual/Hash call sites.
