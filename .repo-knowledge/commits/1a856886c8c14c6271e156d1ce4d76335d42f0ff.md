# 1a85688 — [FFI][REFACTOR] Enhance reflection (#18059)

## TL;DR
- Enhances the C ABI reflection structs with rich field metadata: `doc`, `flags` bitmask, `byte_offset`, `default_value`, and explicit getter/setter fields.
- Introduces `TVMFFIFieldFlagBitMask` enum with `Writable`, `HasDefault`, `IsStaticMethod` bits.
- Refactors `ObjectDef` in `reflection.h` to support nanobind/pybind-style definitions including static methods.
- Adds `def_method` and `def_static_method` registration.

## Why (intent / motivation)
- The existing reflection struct was minimal (name + type index only); to support Python property/method binding, serialization, and default values, full field metadata is required.
- Aligning reflection with nanobind/pybind conventions makes Python binding generation straightforward.
