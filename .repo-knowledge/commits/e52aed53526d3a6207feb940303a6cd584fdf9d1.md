# e52aed5 — [REFACTOR][FFI] Phase out SEqualReduce/SHashReduce (#18172)

## TL;DR
- Removes `_type_has_method_sequal_reduce` and `_type_has_method_shash_reduce` static fields from the `Object` base class.
- Removes two debug `std::cout` statements from `TCustomFuncObj::SEqual` in test helpers.

## Why (intent / motivation)
- The old `SEqualReduce`/`SHashReduce` virtual-method mechanism is fully replaced by the new `TypeAttrDef`-based `__s_equal__`/`__s_hash__` registration.
- Removing the flags eliminates dead code and clarifies that the new mechanism is the only supported path.

## What changed (facts from diff)
- `include/tvm/ffi/object.h`: deleted `_type_has_method_sequal_reduce = false` and `_type_has_method_shash_reduce = false` from `Object` base.
- `tests/cpp/testing_object.h`: removed two `std::cout` debug prints from `TCustomFuncObj::SEqual`.

## Public surface changes (if any)
- API: `Object::_type_has_method_sequal_reduce` and `Object::_type_has_method_shash_reduce` removed. Downstream code specializing on these static fields will fail to compile.
- Flags/config: none
- Data formats/schemas: none

## Tests & verification
