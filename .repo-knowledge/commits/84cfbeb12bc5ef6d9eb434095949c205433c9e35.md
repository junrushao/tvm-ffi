# 84cfbeb — [FFI] Use fold expression to simplify for_each (#18116)

## TL;DR
- Rewrites the `for_each_dispatcher` helper in `base_details.h` using C++17 fold expressions and `std::index_sequence`, eliminating the recursive template specialization approach.
- Reduces the implementation from ~10 lines with two template specializations to ~5 lines.

## Why (intent / motivation)
- Simplify the implementation of `for_each` by leveraging C++17 fold expressions instead of the more verbose recursive template specialization pattern.

## What changed (facts from diff)
- `include/tvm/ffi/base_details.h`: `for_each_dispatcher` is no longer a template taking `<bool stop, size_t I, typename F>`; instead it is a plain struct with a single `run` method using `std::index_sequence` parameter pack and fold expression `(f(I, ...), ...)`.
- The `for_each` wrapper now calls `for_each_dispatcher::run(std::index_sequence_for<Args...>{}, f, ...)`.
