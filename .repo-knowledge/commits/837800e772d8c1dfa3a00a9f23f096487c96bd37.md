# 837800e — [FFI] Update typeinfo to speedup parent reflection (#18083)

## TL;DR
- Changes `TVMFFITypeInfo::type_acenstors` from `const int32_t*` (array of type indices) to `const TVMFFITypeInfo**` (array of pointers to type info structs), enabling direct parent type metadata lookup without a second table lookup.
- Adds `ForEachFieldInfo` overloads to `reflection.h` that iterate parent types directly.
- Optimizes `if constexpr` chains in `IsObjectInstance<T>()` to use explicit `else` branches to reduce compilation overhead.
- Adds `String` literal helpers.

## Why (intent / motivation)
- The old `type_acenstors` stored integer indices requiring a table lookup per ancestor to get field info.
- Storing `TVMFFITypeInfo*` directly allows O(1) ancestor field iteration without extra indirection.
- `if constexpr` without `else` can prevent early compilation path elimination; adding `else` branches makes the intent explicit and helps compilers.

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h` (+2/-2): `TVMFFITypeInfo` struct — `type_acenstors` type changed from `const int32_t*` to `const struct TVMFFITypeInfo**`; struct gets a tag name for forward declaration.
- `include/tvm/ffi/object.h` (+28/-24): updated `IsObjectInstance<T>()` with explicit `else` branches; updated internal ancestor array type.
- `include/tvm/ffi/reflection/reflection.h` (+25/-0): added `ForEachFieldInfo` overloads using pointer-based parent iteration.
- `include/tvm/ffi/string.h` (+9/-0): added String literal helpers.
- `include/tvm/ffi/container/tuple.h` (+2/-1): minor if-constexpr fix.
- `src/ffi/object.cc` (+5/-6): updated type table to store `TVMFFITypeInfo*` in ancestors array.
- Tests: `test_reflection.cc` (+26/-4), `testing_object.h` (+10/-0), `test_object.cc` (+2/-2).
