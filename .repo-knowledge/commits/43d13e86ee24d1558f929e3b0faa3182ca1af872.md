# 43d13e8 — [CORE] Update logic to use combined ref count (#58)

## TL;DR
- Merges the two separate `uint32_t strong_ref_count` and `uint32_t weak_ref_count` fields into a single `uint64_t combined_ref_count` in `TVMFFIObject`
- Strong ref count occupies the lower 32 bits; weak ref count occupies the upper 32 bits
- All atomic operations on strong/weak counters now operate on a single 64-bit atomic, avoiding a separate weak-counter read during deletion (the common case)
- Bumps version to `0.1.0b8`

## Why (intent / motivation)
- The separate counters required two atomic operations (read strong, read weak) in the `DecRef` hot path to detect the common case of both going to zero
- Packing into a single `uint64_t` allows detecting the common case with a single atomic fetch-subtract (if result was `kCombinedRefCountBothOne` before subtraction, both go to zero)
- Inspired by a similar recent optimisation in PyTorch's `intrusive_ptr`

## What changed (facts from diff)
- `include/tvm/ffi/c_api.h`: `TVMFFIObject` changes `strong_ref_count` + `weak_ref_count` to `combined_ref_count: uint64_t`; doc comments explain bit packing
- `include/tvm/ffi/object.h`: constants `kCombinedRefCountWeakOne`, `kCombinedRefCountStrongOne`, `kCombinedRefCountBothOne`, `kCombinedRefCountMaskUInt32` introduced; `Object::use_count()` returns `uint64_t`; `IncRef`, `DecRef`, `IncWeakRef`, `DecWeakRef`, `TryPromoteWeakPtr` all updated; `DecRef` gains fast path for `count_before_sub == kCombinedRefCountBothOne`
- `include/tvm/ffi/memory.h`: object init sets `combined_ref_count = kCombinedRefCountBothOne`
- `python/tvm_ffi/cython/base.pxi`: struct declaration updated to `uint64_t combined_ref_count`
- `docs/concepts/abi_overview.md`: ABI overview updated to describe combined counter encoding
- `pyproject.toml`: version bumped to `0.1.0b8`

## Public surface changes (if any)
- API: `Object::use_count()` return type changes from `int32_t` to `uint64_t` (but returns only the lower 32 bits via mask)
- Flags/config: none
- Data formats/schemas: `TVMFFIObject` layout change — **ABI-breaking**: `combined_ref_count` at offset 0 replaces the previous two `uint32_t` fields
