# 17ff30b — doc: Auto-extract type annotations from function definition (#106)

## TL;DR
- Adds `sphinx-autodoc-typehints` to the docs dependency group and Sphinx extensions, enabling automatic type annotation extraction from Python function signatures.
- Removes redundant type names from docstring `Parameters` / `Returns` sections (keeping only the variable names per DRY principle).
- Configures `autodoc_preserve_defaults`, `typehints_defaults`, `always_document_param_types`, and `napoleon_use_rtype` in `docs/conf.py`.

## Why (intent / motivation)
- Avoids duplicating type annotations in both the function signature and the docstring, which leads to inconsistency over time.
