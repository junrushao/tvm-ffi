# 03e8a6b — [FFI][REFACTOR] Update Map ABI to enable flexible smallMap switch (#18200)

## TL;DR
- Introduces a MSB tag in the `slots_` field of `MapObj` to distinguish `SmallMapObj` from `DenseMapObj` at runtime, replacing the previous size-threshold comparison.
- Adds `IsSmallMap()`, `NumSlots()`, `SetSlotsAndSmallLayoutTag()`, and `SetSlotsAndDenseLayoutTag()` to encapsulate the tagged-slot logic.
- Updates `TVM_FFI_DISPATCH_MAP` macros to use `IsSmallMap()` instead of a direct `slots_ <= kMaxSize` check.

## Why (intent / motivation)
- The old dispatch used `slots_ <= SmallMapObj::kMaxSize` to identify small maps. Using MSB as a tag bit allows the small/dense boundary to be changed in the future without breaking dispatch logic or the ABI check.

## What changed (facts from diff)
- `MapObj`: added `kSmallTagMask = (1ULL << 63)` and `IsSmallMap()` method.
- `SmallMapObj`: added `NumSlots()` (masks off the tag), `SetSlotsAndSmallLayoutTag()` (sets MSB); all internal uses of `slots_` now go through `NumSlots()`.
- `DenseMapObj`: added `NumSlots()` (identity, MSB clear), `SetSlotsAndDenseLayoutTag()` (asserts MSB clear); all internal slot usages updated.
- `TVM_FFI_DISPATCH_MAP` / `TVM_FFI_DISPATCH_MAP_CONST`: now uses `base->IsSmallMap()`.
- `MapObj::CopyFrom`, `MapObj::InsertMaybeReHash`: updated to use `IsSmallMap()` and `NumSlots()`.

## Public surface changes (if any)
- API: `MapObj::slots_` is now a tagged field; direct access is discouraged. The new `IsSmallMap()` / `NumSlots()` accessors should be used instead.
- Flags/config: none
- Data formats/schemas: ABI change — serialized maps that store raw `slots_` values will differ (MSB set for SmallMapObj).

## Tests & verification
- Added/updated tests: none (no test file changes)
- How to verify manually: Run existing Map tests (`uv run pytest -vvs tests/python` or C++ `ctest --test-dir build_test`).
- CI impact: ABI-level change; any code that reads `slots_` directly on a `SmallMapObj` will see the MSB tag.

## Risk & rollout notes
- Risk level: medium — ABI change to `MapObj::slots_` field semantics; affects any code that directly inspects the field.
- Rollout/migration: Use `IsSmallMap()` and `NumSlots()` accessor methods instead of comparing `slots_` directly.
- Follow-ups: Future work may adjust `kMaxSize` boundary for small maps without requiring dispatch logic changes.
