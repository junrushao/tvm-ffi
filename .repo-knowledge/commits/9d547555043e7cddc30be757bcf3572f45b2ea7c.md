# 9d54755 — chore(release): Test wheel building on every `main` commit (#149)

## TL;DR
- Adds a `push: branches: [main]` trigger to `publish_wheel.yml` so wheels are built (but not published) on every commit to `main`.
- Publishing remains gated to `workflow_dispatch` only.
- Fixes the checkout `ref` to use `inputs.branch` only for manual runs and falls back to `github.ref` for push events.

## Why (intent / motivation)
- Ensures wheel building is exercised continuously and regressions are caught before manual release.
