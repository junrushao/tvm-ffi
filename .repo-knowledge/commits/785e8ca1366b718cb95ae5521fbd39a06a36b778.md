# 785e8ca — feat: Add typestubs for Cython generated code (#24)

## TL;DR
- Introduces `python/tvm_ffi/core.pyi` — a 227-line type stub file for the Cython-compiled `core` module.
- Provides complete type signatures for `Object`, `Function`, `Device`, `Tensor`, `DataType`, `DLDeviceType`, `Error`, `String`, `Bytes`, `PyNativeObject`, and associated helper functions.
- Updates `_tensor.py` to import names directly from `core` instead of `core.*` to satisfy mypy.
- Adds `.pyi` to the ASF header check allowlist.

## Why (intent / motivation)
- Without a stub file, IDEs and type checkers cannot introspect the Cython-generated `core` module. Adding `core.pyi` enables Pylance/mypy to understand the public surface of the low-level C extension.

## What changed (facts from diff)
- `python/tvm_ffi/core.pyi` added (227 lines, full type stubs for all public Cython classes and functions).
- `python/tvm_ffi/_tensor.py`: Changed to import `_CLASS_DEVICE`, `PyNativeObject`, `_shape_obj_get_py_tuple` etc. directly from `.core` instead of via `core.` attribute access.
- `tests/lint/check_asf_header.py`: Added `"pyi"` extension to `FMT_MAP`.

## Public surface changes (if any)
