# f4a65cd — [DLPack] completely remove normalization (#72)

## TL;DR
- Removes stride normalization in the Torch-to-DLPack C export path (`_optional_torch_c_dlpack.py`).
- Previously, a special case normalized strides for 1-D size-1 tensors; this is now dropped entirely.

## Why (intent / motivation)
- The normalization (rewriting strides for 1-D size-1 tensors, gh-83069 workaround) is no longer needed with the updated TVM FFI tensor handling and adds unnecessary complexity.
