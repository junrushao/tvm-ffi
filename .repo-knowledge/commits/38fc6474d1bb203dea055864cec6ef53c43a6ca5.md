# 38fc647 — fix: Error message when numpy is missing (#332)

## TL;DR
- Fixes a typo in the fallback definition of `_convert_numpy_dtype_to_ffi_dtype` when numpy is not installed: the function was incorrectly named `_convert_torch_dtype_to_ffi_dtype`.

## Why (intent / motivation)
- When numpy is not available the error fallback defined the wrong function name, meaning callers of `_convert_numpy_dtype_to_ffi_dtype` would get a `NameError` instead of a helpful `ValueError: "numpy not found"`.

## What changed (facts from diff)
- `python/tvm_ffi/cython/dtype.pxi`: `def _convert_torch_dtype_to_ffi_dtype(torch_dtype)` -> `def _convert_numpy_dtype_to_ffi_dtype(numpy_dtype)`.
