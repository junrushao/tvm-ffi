# a1cb746 — build: Rename Import Targets (#354)

## TL;DR
- Renamed CMake imported targets from `tvm_ffi_shared`/`tvm_ffi_header` to `tvm_ffi::shared`/`tvm_ffi::header` (namespaced form)
- Added backward compatibility in `EmbedCubin.cmake` that falls back to old names if new targets are not found
- Updated all examples and docs to use new target names

## Why (intent / motivation)
- Flat target names (`tvm_ffi_shared`, `tvm_ffi_header`) could conflict with targets defined in user `CMakeLists.txt` files
- CMake convention for imported targets from packages uses the `Package::Target` namespaced form to avoid collisions

## What changed (facts from diff)
- `cmake/tvm_ffi-config.cmake`: `add_library(tvm_ffi_shared ...)` → `add_library(tvm_ffi::shared ...)`; same for `tvm_ffi_header`
- `cmake/Utils/Library.cmake`: all references to `tvm_ffi_header`/`tvm_ffi_shared` updated to `tvm_ffi::header`/`tvm_ffi::shared`
- `cmake/Utils/EmbedCubin.cmake`: added compatibility probe (`if(TARGET tvm_ffi::header) ... elseif(TARGET tvm_ffi_header)`) to support both old and new target names
- Examples updated: `examples/cubin_launcher/*/CMakeLists.txt`, `examples/quickstart/CMakeLists.txt`, `examples/stable_c_abi/CMakeLists.txt`
- `docs/get_started/quickstart.rst` updated — comment changed from `set tvm_ffi_DIR` to `set tvm_ffi_ROOT`

## Public surface changes (if any)
- API: **breaking for CMake consumers** — `tvm_ffi_shared` and `tvm_ffi_header` are deprecated; use `tvm_ffi::shared` and `tvm_ffi::header`
- Flags/config: `tvm_ffi-config.cmake` exported target names changed
- Data formats/schemas: none

## Tests & verification
- Added/updated tests: none (build-system change; tested via existing CI example builds)
- How to verify manually: `cmake . -B build && cmake --build build` in any example that uses `find_package(tvm_ffi)`
- CI impact: examples CI step exercises the renamed targets

## Risk & rollout notes
- Risk level: medium — downstream CMake consumers using old target names (`tvm_ffi_shared`, `tvm_ffi_header`) will get build errors after upgrade; backward compatibility provided only in `EmbedCubin.cmake`, not in `Library.cmake`
- Rollout/migration: update `target_link_libraries(... tvm_ffi_shared)` → `target_link_libraries(... tvm_ffi::shared)` and same for `tvm_ffi_header` → `tvm_ffi::header`
- Follow-ups: none
