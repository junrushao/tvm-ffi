# 7a355c7 — [TORCH] Remove ninja dep on non-windows when JIT optional torch-c-dlpack (#272)

## TL;DR
- Made `ninja` an optional build tool on non-Windows platforms: the JIT build now uses `make` as a fallback if `ninja` is not available.
- Improved subprocess error reporting: capture stdout/stderr and surface them in the warning message on failure.
- Added a `logging.info` call when JIT compilation is triggered.
- Refactored build script to use more structured argument and include-path handling.

## Why (intent / motivation)
- On Linux/macOS, requiring `ninja` as a hard dependency was unnecessary since `make` is universally available.
- Silent JIT build failures made it hard to diagnose issues; surfacing stdout/stderr helps.

## What changed (facts from diff)
- `python/tvm_ffi/_optional_torch_c_dlpack.py`:
  - Added `logging` import and module-level logger.
  - Log at INFO level before JIT build starts.
  - Switched from `subprocess.run(check=True)` to `check=False` with explicit error message building from stdout/stderr.
  - Improved warning message when JIT build fails.
- `python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py`:
  - Refactored to make `ninja` optional on non-Windows.
  - Various include-path and argument handling improvements (96 additions, 48 deletions).
