# 53b2e00 — feat: Introduce Python-side TypeInfo Metadata (#30)

## TL;DR
- Introduces `TypeInfo`, `TypeField`, and `TypeMethod` Python dataclasses backed by Cython, making C++ type reflection data accessible as pure Python objects.
- Moves `FieldGetter`/`FieldSetter` Cython classes and the field-attachment logic from `function.pxi` to a new `type_info.pxi` file.
- Replaces the `OBJECT_TYPE` list with `TYPE_INDEX_TO_INFO` and `TYPE_KEY_TO_INFO` dicts keyed by `TypeInfo`.
- Changes `_register_object_by_index` to return a `TypeInfo` instead of `None`.
- Adds `_lookup_type_info_from_type_key` to look up type info without requiring a Python class.
- Moves class attribute attachment logic from Cython `_add_class_attrs_by_reflection` to a new Python-side `_add_class_attrs` in `registry.py`.

## Why (intent / motivation)
- Previously, `TypeInfo` was a C-struct accessible only via Cython. Surfacing it as a Python-accessible dataclass enables downstream Python code (e.g., the upcoming `c_class` decorator) to introspect reflection metadata without requiring Cython changes.

## What changed (facts from diff)
- New `python/tvm_ffi/cython/type_info.pxi`: defines `FieldGetter`, `FieldSetter`, `TypeField`, `TypeMethod`, `TypeInfo` as Cython/Python dataclasses.
- `python/tvm_ffi/cython/object.pxi`: replaces `OBJECT_TYPE` list with `TYPE_INDEX_TO_INFO`/`TYPE_KEY_TO_INFO`; new `_type_info_create_from_type_key`, `_register_object_by_index`, `_lookup_type_info_from_type_key` functions.
- `python/tvm_ffi/cython/function.pxi`: removes 103 lines (FieldGetter/FieldSetter/`_add_class_attrs_by_reflection`).
- `python/tvm_ffi/registry.py`: adds Python-side `_add_class_attrs` and `_member_method_wrapper`; updates `register_object` to use them.
- `python/tvm_ffi/core.pyi`: updated signatures for `_register_object_by_index` and new `_lookup_type_info_from_type_key`; adds `TypeField`, `TypeMethod`, `TypeInfo` stubs.

## Public surface changes (if any)
- API: `_register_object_by_index` now returns `TypeInfo`; `_lookup_type_info_from_type_key` added; `_add_class_attrs_by_reflection` removed from public Cython interface.
