## Architectural changes
- - The old dispatch used `slots_ <= SmallMapObj::kMaxSize` to identify small maps. Using MSB as a tag bit allows the small/dense boundary to be changed in the future without breaking dispatch logic or the ABI check. (.repo-knowledge/commits/03e8a6b8c995259d379358ab50ad81609a99083e.md)
- - Follow-ups: Future work may adjust `kMaxSize` boundary for small maps without requiring dispatch logic changes. (.repo-knowledge/commits/03e8a6b8c995259d379358ab50ad81609a99083e.md)
- - Introduces `ffi::Module` / `ffi::ModuleObj` as a formalized extra API for dynamic module loading, replacing ad-hoc runtime::Module usage. (.repo-knowledge/commits/538bef49b4daa91970f0f9cea137acdcb696562a.md)
- - Adds `Library` base class and concrete implementations: `LibraryModuleObj` (DSO/system-lib wrapper), `DSOLibrary`, `SystemLibrary`. (.repo-knowledge/commits/538bef49b4daa91970f0f9cea137acdcb696562a.md)
- - Exposes `ffi.ModuleLoadFromFile`, `ffi.ModuleGetFunction`, `ffi.ModuleImportModule`, etc. as global functions. (.repo-knowledge/commits/538bef49b4daa91970f0f9cea137acdcb696562a.md)
- - Adds `BufferInStream` helper for reading module binary blobs embedded in library files. (.repo-knowledge/commits/538bef49b4daa91970f0f9cea137acdcb696562a.md)
- - Formalizes the module system within the FFI layer so that library plugins can use a stable, minimal API for loading and invoking packed functions from shared libraries. (.repo-knowledge/commits/538bef49b4daa91970f0f9cea137acdcb696562a.md)

## Synthesized analysis

### Thematic threads

This range represents a concentrated month (2025-08-04 to 2025-08-31) of work to establish `tvm_ffi` as a standalone, self-contained FFI layer. The 24 commits group into five coherent threads:

**1. ABI evolution: small string/bytes and Map tagging (49e2ed4, 03e8a6b, 777cf8d)**
The C ABI (`TVMFFIAny`) was extended with `kTVMFFISmallStr`/`kTVMFFISmallBytes` type indices for inline small strings, a `zero_padding` field for correctness, and MSB-tagged `MapObj::slots_` to decouple small/dense map dispatch from the size threshold. Late in the month (777cf8d), the ABI type ordering was adjusted before freeze, reordering simple C-ABI objects before complex C++-dependent ones, and a `GetFunctionMetadata` virtual method stub was added to `ModuleObj`.

**2. Serialization stack: JSON + JSONGraph (de541e3, 8eaefe0, 7cb9273, 55edee0, 1a271f0, 3f4f4f1)**
A three-layer serialization stack was built: (a) lightweight JSON parser/writer (`json::Parse`, `json::Stringify`), (b) graph-aware JSONGraph serialization (`ToJSONGraph`/`FromJSONGraph`) preserving shared object references, and (c) reflection-based `ObjectCreator` for type-safe deserialization. Fast-math safety was added (1a271f0, 3f4f4f1) to handle NaN/Infinity under `-ffast-math`. String convenience wrappers (`ToJSONGraphString`/`FromJSONGraphString`) were added for Python consumption.

**3. Reflection and AccessPath refactor (f4ede98, ed56a5e, 55edee0, 4be1af7)**
`AccessPath` was refactored from a flat `Array<AccessStep>` to a parent-pointing tree for space-efficient path sharing. `ObjectPath` was deprecated in favor of `AccessPath`. `Downcast` was removed from the FFI layer (replaced by `Any::cast<T>()`). Namespace aliases (`tvm::Tuple`, `tvm::Downcast`) were cleaned up.

**4. Module system and environment APIs (538bef4, 0daaffe, 6014406, 023ea44)**
`ffi::Module`/`ffi::ModuleObj` was formalized with `Library`, `DSOLibrary`, and `SystemLibrary` implementations. A thread-local `StreamContext` was added for per-device stream management. The env C API symbols were renamed and relocated from `function.cc` to `src/ffi/extra/env_c_api.cc` to keep the core minimal.

**5. Python packaging and standalone tvm_ffi (2d41a51, 2cf211f, 7358796, ad8e5d2, 4523a83, b245f1f, 7d09d6a, 3702e50)**
The `tvm_ffi` Python package was established with Cython bindings, `pyproject.toml` (scikit-build-core), full test suite, examples, and packaging documentation. Build issues on Windows were fixed. libbacktrace was added as a git submodule with a fallback download URL. The last commit (3702e50) fixed migration issues.

### Key design decisions

1. **Small strings stored inline in TVMFFIAny**: Short strings avoid heap allocation by storing data directly in the 8-byte `v_handle`/`v_int64` union slot, identified by a new type index. This is an ABI-breaking change requiring full recompile.

2. **MSB tagging for Map layout dispatch**: Instead of comparing `slots_ <= kMaxSize`, the MSB of `slots_` distinguishes `SmallMapObj` from `DenseMapObj`. This decouples the dispatch from the size threshold, allowing future boundary changes without ABI breaks.

3. **JSONGraph format for object-graph serialization**: A `{"root_index", "nodes", "metadata"}` schema preserves shared references across the object graph, enabling round-trip serialization of TVM IR. Custom types participate via `__data_to_json__`/`__data_from_json__` hooks.

4. **Reflection-based ObjectCreator**: Rather than ad-hoc attribute setting, deserialization uses `ObjectCreator(type_key)(fields_map)` which goes through the reflection registry for type-safe construction with default values.

5. **AccessPath as parent-pointing tree**: Replaces flat `Array<AccessStep>`, yielding compact representation when multiple paths share a common prefix (structural equality reporting).

6. **Standalone tvm_ffi Python package**: Decoupled from the main TVM compiler, allowing lightweight ML library plugins to depend on `tvm_ffi` alone.
