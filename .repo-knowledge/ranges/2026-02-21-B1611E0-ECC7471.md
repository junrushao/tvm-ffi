## Architectural changes

### Mutable container hierarchy (List and Dict)
- Introduced `List<T>` as a mutable sequence alongside the immutable `Array<T>`. Extracted `SeqBaseObj` as shared base class for `ArrayObj` and `ListObj`, removing ~300 lines of duplication from `array.h`. (`9513c2f`, `include/tvm/ffi/container/list.h`, `include/tvm/ffi/container/seq_base.h`)
- Reorganized map internals: extracted `MapObj` into `map_base.h` (+1694 lines) from `map.h` (-1415 lines), removed `InplaceArrayBase` from `container_details.h` (-128 lines). This prepared the shared base for `Dict`. (`5a6b211`, `include/tvm/ffi/container/map_base.h`)
- Introduced `Dict<K,V>` as a mutable map container sharing `MapObj` base with the immutable `Map`. Registered `kTVMFFIDict` type index in C ABI. (`c1af3b3`, `include/tvm/ffi/container/dict.h`)
- New `docs/concepts/containers.rst` (+208 lines) documents all container types, mutability, thread safety. (`7786133`)

### Customizable AnyHash/AnyEqual via type attributes
- Extended `AnyHash` and `AnyEqual` functors to consult per-type `__any_hash__` and `__any_equal__` type attribute columns, enabling structural or value-based hashing/equality for objects in containers. (`39d9b2b`, `include/tvm/ffi/any.h`)
- `StructuralKey` leverages this to cache structural hash and dispatch structural equality via type attributes. (`6adc8df`, `include/tvm/ffi/extra/structural_key.h`)

### Unified repr system
- Introduced DFS-based `ffi.ReprPrint` as the single repr entry point for all FFI values. All Python `__repr__` methods now delegate to this C++ function. Cycle detection and DAG memoization built in. (`b648c5d`, `src/ffi/extra/repr_print.cc`)
- Removed per-class Python repr code-gen from `dataclasses/_utils.py` (-40 lines) and `c_class.py`. Per-field `Repr(false)` InfoTrait controls field exclusion. (`b648c5d`)

### Deep copy infrastructure
- New C++ `ObjectDeepCopier` with memoized graph copy preserving shared references and handling cycles across `Array`, `List`, `Map`, and reflected objects. (`c73d61a`, `src/ffi/extra/deep_copy.cc`, `include/tvm/ffi/extra/deep_copy.h`)
- Auto-registers `__ffi_shallow_copy__` for copy-constructible types via `AutoRegisterCopy()` in `ObjectDef`. Python `__copy__`, `__deepcopy__`, `__replace__` installed for all reflected types. (`c73d61a`)

### Reflection enhancements
- `DefaultFactory` as callable `() -> Any` alternative to `DefaultValue` prevents aliasing bugs for mutable container defaults. Renamed `TVMFFIFieldInfo::default_value` to `default_value_or_factory`. New flag `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5`. (`5e564cd`, `include/tvm/ffi/c_api.h`, `include/tvm/ffi/reflection/registry.h`)
- `MISSING` sentinel moved from `container.py` to `core.pyx` for earlier availability; renamed `ffi.MapGetMissingObject` to `ffi.GetInvalidObject`. (`86c4042`)

### Python object model hardening
- Enforced `__slots__ = ()` on all Cython-defined FFI object subclasses to prevent accidental Python attribute mutation on C++-backed objects. (`83daf69`, all `.pxi` files)
- Added `Function.__init__` constructor accepting Python callables or existing `Function` objects. (`ecc7471`)

### Error handling

## Design decisions

- **Mutable vs immutable containers as separate types**: `List<T>` and `Dict<K,V>` were introduced as distinct mutable types rather than adding mutation methods to `Array<T>` and `Map<K,V>`. This preserves the copy-on-write invariant of existing containers while providing shared-reference mutation semantics where needed. (`9513c2f`, `c1af3b3`)
- **SeqBaseObj extraction**: Rather than using composition, `SeqBaseObj` was extracted as a shared inheritance base for `ArrayObj` and `ListObj`. This avoids duplicating iterator/accessor code and enables generic algorithms. (`9513c2f`)
- **MapObj shared base for Map and Dict**: The `MapObj` base was extracted into `map_base.h` before introducing `Dict`, ensuring both share identical storage and lookup internals. (`5a6b211`, `c1af3b3`)
- **DefaultFactory over mutable defaults**: The `DefaultFactory` approach mirrors Python's `dataclasses.field(default_factory=...)` to avoid aliasing bugs when mutable containers are used as default field values. (`5e564cd`)
- **Type-attribute-based AnyHash/AnyEqual dispatch**: Per-type hash/equal customization uses type attribute columns (`__any_hash__`, `__any_equal__`) rather than virtual methods, keeping the hot path as a function pointer dispatch without vtable overhead. (`39d9b2b`)
- **DFS-based repr with cycle detection**: `ReprPrint` uses 3-state DFS (NotVisited/InProgress/Done) to handle arbitrary object graphs. Array repr format changed from `[...]` to `(...)` to distinguish from Python lists. (`b648c5d`)
- **Expected<T> for exception-free FFI calls**: Modeled after C++23 `std::expected` and Rust `Result<T,E>`, enabling value-based error handling for embedded/perf-critical callers. (`0a9d4b6`)
- **Slots enforcement on FFI objects**: `__slots__ = ()` prevents silent Python-side attribute creation on C++-backed objects. This is a behavioral restriction that aligns Python attribute access with C++ field semantics. (`83daf69`)
- **Stub type origins for mutable/immutable containers**: TypeSchema now emits `Array`/`List`/`Map`/`Dict` as distinct origins instead of collapsing to `list`/`dict`, enabling downstream type checkers to distinguish mutability. (`7786133`)

## New APIs and breaking changes

### New C++ APIs
- `ffi::Expected<T>`, `ffi::Unexpected<E>`: exception-free error containers (`0a9d4b6`, `include/tvm/ffi/expected.h`)
- `Function::CallExpected<T>()`: call FFI functions returning `Expected<T>` (`0a9d4b6`, `include/tvm/ffi/function.h`)
- `List<T>`, `ListObj`, `SeqBaseObj`: mutable sequence container and shared base (`9513c2f`, `include/tvm/ffi/container/list.h`, `seq_base.h`)
- `Dict<K,V>`, `DictObj`: mutable map container (`c1af3b3`, `include/tvm/ffi/container/dict.h`)
- `StructuralKey`, `StructuralKeyObj`: structural hash/equality wrapper (`6adc8df`, `include/tvm/ffi/extra/structural_key.h`)
- `DeepCopy(const Any&)`: memoized deep copy engine (`c73d61a`, `include/tvm/ffi/extra/deep_copy.h`)
- `DefaultFactory` reflection trait: callable default for mutable fields (`5e564cd`, `include/tvm/ffi/reflection/registry.h`)
- `Repr` InfoTrait and `kTVMFFIFieldFlagBitMaskReprOff`: per-field repr exclusion (`b648c5d`)
- `DCHECK`, `DCHECK_EQ`, typed `CHECK_EQ`: complete check macro suite (`35cbc32`, `include/tvm/ffi/error.h`)

### New C ABI type indices / flags
- `kTVMFFIList`: new type index for `ListObj` (`9513c2f`, `include/tvm/ffi/c_api.h`)
- `kTVMFFIDict`: new type index for `DictObj` (`c1af3b3`, `include/tvm/ffi/c_api.h`)
- `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5`: default-factory flag (`5e564cd`)
- `kTVMFFIFieldFlagBitMaskReprOff = 1 << 6`: repr exclusion flag (`b648c5d`)

### New Python APIs
- `tvm_ffi.List`: mutable sequence class (`9513c2f`)
- `tvm_ffi.Dict`: mutable mapping class (`c1af3b3`)
- `tvm_ffi.StructuralKey`, `tvm_ffi.structural_equal`, `tvm_ffi.structural_hash`, `tvm_ffi.get_first_structural_mismatch`: structural comparison utilities (`6adc8df`)
- `__copy__`, `__deepcopy__`, `__replace__` on all reflected FFI objects (`c73d61a`)
- `Function.__init__(callable_or_function)`: direct construction from Python callable (`ecc7471`)
- `ffi.ReprPrint`: unified repr global function (`b648c5d`)
- `ffi.DeepCopy`: deep copy global function (`c73d61a`)
- `ffi.GetInvalidObject`: renamed from `ffi.MapGetMissingObject` (`86c4042`)
- `DictSetItem`, `DictDelItem`, `DictClear`, `DictPopItem`, `DictUpdate`: dict mutation globals (`c1af3b3`)

### New global function parameters
- `backend: str | None` parameter added to `build_inline`, `load_inline`, `build`, `load` in `tvm_ffi.cpp.extension` (`65b5e90`)

### New environment variables
- `TVM_FFI_GPU_BACKEND`: override GPU backend detection (cuda/hip) (`65b5e90`)
- `TVM_FFI_ROCM_ARCH_LIST`: fallback ROCm architecture list (`65b5e90`)
- `TVM_FFI_REPR_WITH_ADDR=1`: show object addresses in repr output (`b648c5d`)

### Breaking changes
- `TVMFFIFieldInfo::default_value` renamed to `default_value_or_factory` (C ABI field rename; all consumers must rebuild) (`5e564cd`)
- `InplaceArrayBase` removed from `container_details.h` (`5a6b211`)
- Array repr format changed from `[1, 2, 3]` to `(1, 2, 3)` (affects any code parsing repr strings) (`b648c5d`)
- `field()` and `c_class()` no longer accept `repr` parameter (superseded by `Repr` InfoTrait) (`b648c5d`)
- `ffi.MapGetMissingObject` renamed to `ffi.GetInvalidObject` (`86c4042`)
- FFI object subclasses now have `__slots__ = ()` by default; setting arbitrary Python attributes raises `AttributeError` (`83daf69`)
