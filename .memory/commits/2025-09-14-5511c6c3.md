## Design Elements
Design elements this commit consumes:
- `TVM_FFI_STATIC_INIT_BLOCK()` macro for registering global functions at startup
- `TVMFFIGetGlobalFunction` / `GetGlobalRequired` for cross-language state access

Design elements this commit produces:
- Documented pattern for compiler-specific runtime state management: singleton + global function registration + package distribution
- Distinction between common FFI-managed state (streams, allocators) and compiler-specific state
## Reflection
- The recommended pattern (register a global function returning a void* to a singleton) keeps the FFI layer decoupled from compiler-specific state
