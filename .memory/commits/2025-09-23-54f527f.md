# feat: Support Array Concat in Python (#45)
## TL;DR
- Adds `__add__` and `__radd__` methods to `Array`, enabling `array1 + array2` and `list + array` syntax.
- Broadens `Array.__init__` to accept any `Iterable[T]` instead of only `Sequence[T]`, enabling construction from itertools chains and generators.
- Adds 67 lines of tests covering Array/List concat with lists, tuples, and other Array instances.

## Impact
- API: `Array.__init__` now accepts `Iterable[T]` (broader than `Sequence[T]`). New `__add__`/`__radd__` operators.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `itertools.chain` for lazy concatenation without intermediate list allocation

Design elements this commit produces:
- Pattern: Array supports Pythonic `+` concatenation, returning a new Array of the same subtype via `type(self)(...)`.

## Reflection
- Using `itertools.chain` avoids materializing an intermediate list, though the FFI constructor ultimately unpacks all elements anyway via `*input_list`.
- `__radd__` enables `[1, 2] + tvm_array` to work, matching Python list semantics.
