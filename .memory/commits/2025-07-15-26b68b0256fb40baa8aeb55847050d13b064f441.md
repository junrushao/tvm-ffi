# Remove TVM_FFI_REGISTER_GLOBAL macro and Function::Registry class in favor of GlobalDef
## TL;DR
- Deletes the entire `Function::Registry` class (~120 lines) from `include/tvm/ffi/function.h`, which provided `set_body_packed`, `set_body_typed`, and `set_body_method` chaining APIs for global function registration.
- Deletes the `TVM_FFI_REGISTER_GLOBAL` macro and its helper `TVM_FFI_FUNC_REG_VAR_DEF`, which were the primary C++ entry point for registering global functions.
- This is a pure deletion (0 additions, 144 deletions in a single file), completing the migration to the `GlobalDef` mechanism.
## Impact
- API: **Breaking** -- any downstream C++ code using `TVM_FFI_REGISTER_GLOBAL("name").set_body_typed(...)` or `Function::Registry` must migrate to the `GlobalDef` pattern. This affects all C++ callers that register global functions.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- The `GlobalDef` mechanism (introduced in prior commits) which replaces the removed macro-based registration pattern.
- `Function::FromTyped` and `Function::FromPacked` static methods remain available; only the `Registry` wrapper and macro are removed.

Design elements this commit produces:
- Establishes `GlobalDef` as the sole C++ mechanism for global function registration, eliminating the dual-path ambiguity.
## Reflection
- The removed `Function::Registry` class used a builder pattern (`Registry(name).set_body_typed(f)`) for registration. The replacement `GlobalDef` pattern consolidates this with the reflection/definition system used elsewhere in the codebase.
- The commit is part of PR #18148, indicating it was done in the upstream TVM repo before being synced here.
- The 0-addition, 144-deletion profile confirms this is a cleanup commit with no replacement code needed in this file -- the `GlobalDef` infrastructure already existed elsewhere.
