# [FFI][DOCS] Initial bringup of cpp docs (#18279)
## TL;DR
- Added `docs/reference/cpp/index.rst` with Breathe/Doxygen-generated C++ API reference, organized by header folder with a key-classes quick reference table.
- Bulk-added or improved Doxygen doc comments across nearly all public C++ headers (`any.h`, `object.h`, `function.h`, `memory.h`, `string.h`, containers, reflection, extras).
- Updated Makefile to clean/ignore generated C++ docs; added `breathe` and `exhale` to `docs/requirements.txt`.
## Impact
- API: none (doc-only, no behavioral changes)
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- All public C++ header files under `include/tvm/ffi/`
- Sphinx doc infrastructure in `docs/`
Design elements this commit produces:
- `docs/reference/cpp/index.rst` with header organization table, key-classes table, and full API index
- Comprehensive Doxygen comments on constructors, operators, and methods of `AnyView`, `Any`, `Object`, `ObjectRef`, `Function`, `String`, containers, reflection classes
## Reflection
- This is foundational for auto-generated API docs. The key-classes table in the RST gives users a quick overview without needing to navigate the full Doxygen tree.
- Many previously undocumented constructors and operators now have proper `\brief` / `\param` / `\tparam` annotations, which helps both human readers and tooling.
