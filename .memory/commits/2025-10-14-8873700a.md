# [CYTHON][REFACTOR] __tvm_ffi_object__ protocol (#115)
## TL;DR
- Renames internal attribute `PyNativeObject.__tvm_ffi_object__` to `_tvm_ffi_cached_object` (attributes should not use dunder convention).
- Generalizes the `__tvm_ffi_tensor__` protocol to `__tvm_ffi_object__` so it works for any FFI object, not just tensors.
- Updates all Cython dispatch code, type stubs, and tests.
## Impact
- API: Renames `__tvm_ffi_tensor__` -> `__tvm_ffi_object__` (not yet in a formal release, low external impact). Internal attribute renamed.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `__tvm_ffi_tensor__` protocol from commit 4bc89254
Design elements this commit produces:
- `__tvm_ffi_object__` protocol -- generalized for any FFI object type
## Reflection
- Good consolidation: a single protocol for all object types rather than tensor-specific.
