# Initial commit: introduce the TVM FFI system with stable C ABI, C++ API, type-erased Any/Object/Function, and container library

## TL;DR
- Establishes the entire TVM FFI codebase from scratch (59 files, 15,328 LOC): a stable C ABI (`c_api.h`), C++17 API (`any.h`, `object.h`, `function.h`, `type_traits.h`), container library (Array, Map, String, Shape, Tuple, Variant, NDArray), error system, reflection system, memory management, and CMake build.
- Implements the [Unified Packed and Object RFC](https://github.com/apache/tvm-rfcs/blob/main/rfcs/0097-unify-packed-and-object.md) that unifies packed function calls and the object system under a single type-erased `Any`/`AnyView` value representation.
- Includes a full GoogleTest C++ test suite (18 test files, ~2,700 LOC) covering every major subsystem.

## Impact
- API: This commit defines the entire public API surface. All C ABI functions (`TVMFFI*` in `c_api.h`), all C++ classes (`Any`, `AnyView`, `Object`, `ObjectRef`, `ObjectPtr`, `Function`, `Error`, `String`, `Bytes`, `Array`, `Map`, `Shape`, `Tuple`, `Variant`, `Optional`, `Tensor`), and all macros (`TVM_FFI_DECLARE_OBJECT_INFO`, `TVM_FFI_DEFINE_OBJECT_REF_METHODS`, `TVM_FFI_REGISTER_GLOBAL`, `TVM_FFI_THROW`, etc.) are introduced here. No prior callers exist.
- Flags/config: CMake options `TVM_FFI_USE_LIBBACKTRACE`, `TVM_FFI_USE_EXTRA_CXX_API`, `TVM_FFI_USE_THREADS`, `TVM_FFI_USE_DL_LIBS`, `TVM_FFI_BACKTRACE_ON_SEGFAULT`, `TVM_FFI_BUILD_TESTS`. Compile-time macros `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA`, `TVM_FFI_USE_LIBBACKTRACE`, `TVM_FFI_BACKTRACE_ON_SEGFAULT`, `TVM_FFI_ALWAYS_LOG_BEFORE_THROW`.
- Data formats/schemas: Defines the on-wire ABI layout of `TVMFFIAny` (16-byte tagged union: 4-byte `type_index` + 4-byte padding/small-string-len + 8-byte value union), `TVMFFIObject` (8-byte combined ref count + 4-byte type index + 4-byte padding + 8-byte deleter), `TVMFFIByteArray`, `TVMFFIShapeCell`, `TVMFFISeqCell`, `TVMFFIErrorCell`, `TVMFFIFunctionCell`, `TVMFFITypeInfo`. Version: 0.1.9.

## Design Elements

Design elements this commit consumes:
- **DLPack** (`3rdparty/dlpack`): The tensor exchange protocol. `DLTensor`, `DLDataType`, `DLDevice`, `DLManagedTensor` are used as the tensor ABI.
- **Unified Packed and Object RFC** (tvm-rfcs/0097): The architectural blueprint that this commit implements.

Design elements this commit produces:

- **C ABI (`c_api.h`, 718 LOC)**: The stable C boundary layer. Key structs: `TVMFFIAny` (tagged union for all values), `TVMFFIObject` (ref-counted object header with combined strong/weak refcount packed into u64), `TVMFFIByteArray`, `TVMFFIShapeCell`, `TVMFFISeqCell`, `TVMFFIErrorCell`, `TVMFFIFunctionCell`. Key enums: `TVMFFITypeIndex` with static range [0, 64) for POD types and [64, 128) for builtin objects, and [128, +inf) for dynamic types. Key functions: `TVMFFIObjectIncRef`/`DecRef`, `TVMFFIFunctionCreate`/`Call`/`GetGlobal`, `TVMFFIErrorCreate`/`SetRaised`/`MoveFromRaised`, `TVMFFITensorFromDLPack`/`ToDLPack`, `TVMFFITypeKeyToIndex`, `TVMFFIAnyViewToOwnedAny`. The safe-call convention: `int (*TVMFFISafeCallType)(void*, const TVMFFIAny*, int32_t, TVMFFIAny*)` returns 0 on success, -1 with TLS error on failure.
- **Type-erased value system (`any.h`, 492 LOC)**: `AnyView` (non-owning 16-byte tagged view) and `Any` (owning, ref-count-managing). POD types (int, float, bool, DataType, Device) stored inline. Object types stored as `TVMFFIObject*` with ref-count management. Small-string optimization: strings up to 7 bytes stored inline in `v_bytes` with `small_str_len`. `AnyView` can hold `kTVMFFIRawStr` (non-owning `const char*`) but `Any` cannot (invariant: `Any::type_index` is never `kTVMFFIRawStr`).
- **Object system (`object.h`, 798 LOC)**: `Object` base class with `TVMFFIObject` header. `ObjectPtr<T>` intrusive smart pointer (strong ref). `ObjectRef` wrapper around `ObjectPtr<Object>`. Patterns: `FooObj` (data class, inherits Object) + `Foo` (ref wrapper, inherits ObjectRef). Macros: `TVM_FFI_DECLARE_OBJECT_INFO(key, Self, Parent)` / `TVM_FFI_DECLARE_OBJECT_INFO_FINAL` for type registration, `TVM_FFI_DEFINE_OBJECT_REF_METHODS(Ref, ParentRef, Obj)` for ref class boilerplate. Runtime type checking via `IsInstance<T>()` with fast-path slot-range check and fallback ancestor-table walk. `UnsafeInit` tag for deferred field initialization.
- **TypeTraits system (`type_traits.h`, 683 LOC)**: Template specialization framework `TypeTraits<T>` governing how each C++ type converts to/from `Any`/`AnyView`. Key operations: `CopyToAnyView`, `MoveToAny`, `CheckAnyStrict`, `CopyFromAnyViewAfterCheck`, `MoveFromAnyAfterCheck`, `TryCastFromAnyView`, `TypeStr`. `TypeTraitsNoCR<T>` strips const/ref. `field_static_type_index` maps types to their static type index for container element checking.
- **Function system (`function.h`, 914 LOC)**: `FunctionObj` inherits `Object` + `TVMFFIFunctionCell`, providing dual dispatch: `cpp_call` (direct C++ with exception propagation) and `safe_call` (C ABI with error code). `FunctionObjImpl<TCallable>` wraps arbitrary C++ callables. `ExternCFunctionObjImpl` wraps C-style callbacks. `Function` ref class with `operator()` variadic call. `TypedFunction<R(Args...)>` for typed wrappers. Global registry via `TVM_FFI_REGISTER_GLOBAL("name")` / `register_global_func` / `get_global_func`.
- **Memory management (`memory.h`, 209 LOC)**: `make_object<T>(args...)` allocates and constructs objects with correct deleter/type_index. `make_inplace_array_object<ArrayType, ElemType>(num_elem, args...)` for inline-storage arrays. `AlignedAlloc<align>` for platform-portable aligned allocation.
- **Error system (`error.h`, 294 LOC)**: `ErrorObj` inherits `Object` + `TVMFFIErrorCell` with `kind`, `message`, `backtrace`, `cause_chain`, `extra_context`. `Error` ref class thrown as C++ exception. `TVM_FFI_THROW(ErrorType) << "msg"` macro for stream-style error construction. TLS-based error propagation across C ABI boundaries via `TVMFFIErrorSetRaised`/`MoveFromRaised`. Traceback support via libbacktrace (`src/ffi/traceback.cc`/`.h`) with platform-specific Windows variant.
- **String/Bytes (`string.h`, 662 LOC)**: `StringObj`/`BytesObj` use `InplaceArrayBase` for inline storage (object header + `TVMFFIByteArray` + trailing chars). `String`/`Bytes` ref wrappers with `std::string_view`-like API. `String(nullptr_t) = delete` enforces non-null invariant. Comparison, hashing, concatenation, and `std::ostream` integration.
- **Containers**: `Array<T>` (`array.h`, 1035 LOC, immutable with COW), `Map<K,V>` (`map.h`, 1606 LOC, immutable ordered map preserving insertion order), `Shape` (`shape.h`, 219 LOC, inline int64 dimensions), `Tuple` (`tuple.h`, 279 LOC, heterogeneous fixed-size), `Variant<T...>` (`variant.h`, 198 LOC, tagged union over ObjectRef types), `NDArray`/`Tensor` (`ndarray.h`, 337 LOC, DLPack-backed tensor), `Optional<T>` (`optional.h`, 299 LOC). All containers use `SeqBaseObj` / `TVMFFISeqCell` as the sequence base with `data`, `size`, `capacity`, and optional `data_deleter`.
- **Reflection (`reflection/reflection.h` + 5 more headers)**: `ObjectDef<T>` builder with `def_field`/`def_method` for registering type metadata. Accessor and creator patterns for field access/object construction via the registry.
- **Type registration runtime (`src/ffi/object.cc`)**: `TypeTable` singleton manages type index allocation, type key-to-index mapping, ancestor arrays for `IsInstance` checks, and field/method metadata. Static types [0, 128) are pre-allocated; dynamic types start at 128 with child-slot reservation for fast subtype checks.
- **Global function registry (`src/ffi/function.cc`)**: `GlobalFunctionTable` stores `Entry` objects (name, function, metadata) in a `Map` keyed by name. Registration via `TVMFFIFunctionGetGlobal`/`TVMFFIFunctionSetGlobal`.
- **Build system**: CMake project `tvm_ffi` with targets `tvm_ffi_header` (header-only interface), `tvm_ffi_shared` (shared library), `tvm_ffi_static`, `tvm_ffi_tests`. GoogleTest integration via `AddGoogleTest.cmake`. Libbacktrace integration via `AddLibbacktrace.cmake`. Sanitizer support.

## Reflection

- This is the genesis commit of the repository, extracted from the Apache TVM monorepo (PR #17920). The commit message references legacy ABI translation (`LegacyTVMArgValueToFFIAny`) and plans for further refactoring (phasing out legacy redirections, reflection improvements, Python/Rust bindings). Those are not present in this commit -- only the C++/C core and tests.
- The combined strong/weak ref-count in a single `uint64_t` (`TVMFFIObject::combined_ref_count`) is a notable ABI design choice: strong in lower 32 bits, weak in upper 32 bits, allowing atomic increment/decrement of strong refs with plain +1/-1 while enabling a single atomic read to check both counters during deletion.
- The `TVMFFIAny` layout is 16 bytes: `{int32_t type_index, uint32_t zero_padding, union{int64_t, double, void*, ...}}`. The small-string optimization reuses `zero_padding` as `small_str_len` and `v_bytes[8]` for up to 7 bytes of inline string data.
- The type index space is partitioned into three ranges: POD/special [0, 64), static objects [64, 128), and dynamic objects [128, +inf). This enables fast `IsInstance` checks via slot-range comparison before falling back to ancestor table lookup.
- No Python, Rust, or Cython bindings are included in this commit. Those are introduced in later commits.
