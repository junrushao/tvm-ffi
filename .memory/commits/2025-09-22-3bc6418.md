# doc: Enable Doxygen Build Checks in CI (#42)
## TL;DR
- Enables Doxygen in the CI doc job (`sudo apt install doxygen` + `BUILD_CPP_DOCS=1`).
- Adds `WARN_AS_ERROR` to Doxygen config and `TVM_FFI_DOXYGEN_MODE` preprocessor define to hide anonymous unions from Doxygen (which cannot parse them).
- Fixes Doxygen warnings: adds `\brief` comments to `TVMFFIAny` union fields, suppresses `make_object<MapObj>` deletion specialization with `\cond`, removes stray `\endcond`, fixes `\return` on constructors, adds missing `\endcode`.
- Adds `cpp_id_attributes` and `c_id_attributes` lists in `docs/conf.py` for Sphinx C/C++ domain to recognize TVM FFI macros.
## Impact
- API: No runtime changes. `TVM_FFI_DOXYGEN_MODE` preprocessor guard added around anonymous unions in `TVMFFIObject` and `TVMFFIAny`.
- Flags/config: `BUILD_CPP_DOCS=1` env var now required for full doc build in CI.
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- Exhale/Breathe Doxygen integration in Sphinx.
Design elements this commit produces:
- `TVM_FFI_DOXYGEN_MODE` guard pattern for hiding C constructs (anonymous unions) that Doxygen cannot parse.
- Clean Doxygen build with warnings-as-errors.

- The `#if !defined(TVM_FFI_DOXYGEN_MODE)` pattern around anonymous unions is a common workaround for Doxygen's limited C11/C++ parser.
