# [MEMORY] Use raw alloc for memory (#66)
## TL;DR
- Replaced `new StorageType` / `new StorageType[]` with `AlignedAlloc<align>(size)` / `AlignedFree()` in `SimpleObjAllocator`, removing the `StorageType` wrappers entirely.
- For inplace arrays, allocation size is now `sizeof(ArrayType) + sizeof(ElemType) * num_elems` rounded up to alignment, instead of being rounded up to multiples of `StorageType` (which could waste memory).
- Added `AlignedAlloc<align>()` and `AlignedFree()` helper functions using `posix_memalign` / `_aligned_malloc`.
## Impact
- API: none (internal allocator change)
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `SimpleObjAllocator` pattern with `ObjAllocatorBase` CRTP

Design elements this commit produces:
- `details::AlignedAlloc<align>()` and `details::AlignedFree()` utilities
- More precise inplace array allocation sizing
## Reflection
- Moves the `static_assert` for element alignment from class-level to function-level inside `ArrayHandler::New`.
