# [FFI][ABI] ABI Updates to for future metadata and complex ordering (#18254)
## TL;DR
- Reorders static object type indices in `c_api.h`: Shape=69, NDArray=70, Array=71, Map=72 (previously Array=69, Map=70, Shape=71, NDArray=72) to group simple C-ABI objects before more complex C++ ones
- Adds `ModuleObj::GetFunctionMetadata` virtual method returning `Optional<String>` (JSON format) and a query-imports overload, plus a registered FFI method `ffi.ModuleGetFunctionMetadata`
- Adds `tvm_ffi_metadata_prefix` symbol constant (`__tvm_ffi_metadata_`)
- Renames `override` parameter to `allow_override` in `TVMFFIFunctionSetGlobal` and `TVMFFIFunctionSetGlobalFromMethodInfo` signatures
- Bumps version to `0.1.0a3`; updates Cython `base.pxi` to match new enum values; changes test build type to `RelWithDebugInfo`

## Impact
- API: **ABI-breaking** -- type index values for Array, Map, Shape, NDArray are renumbered; any code that hardcodes these values must be updated
- API: `override` -> `allow_override` parameter rename in two C API functions (source-level rename, ABI-compatible since it is just a parameter name)
- API: new virtual method `GetFunctionMetadata` on `ModuleObj` (additive)
- Flags/config: test build type changed from `Release` to `RelWithDebugInfo`
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: none

Design elements this commit produces:
- Ordering convention: simple C-ABI static objects (String, Bytes, Error, Function, Shape, NDArray) come before complex C++ objects (Array, Map, Module)
- Module metadata API pattern: `GetFunctionMetadata(name)` returns JSON string, with import-chain query support
- `__tvm_ffi_metadata_` symbol prefix convention for library modules

## Reflection
- This is a deliberate ABI break done before the ABI freeze, grouping objects by complexity to allow future C-only consumers to handle the simple subset without C++ dependencies
- The metadata API enables introspection of function signatures/attributes from dynamically loaded modules, useful for code generation and tooling
