# [CYTHON] Enable ffi function creation from MLIR Packed function (#100)
## TL;DR
- Adds `Function.__from_mlir_packed_safe_call__(mlir_packed_symbol, *, keep_alive_object=None)` static method for constructing FFI Functions from MLIR execution engine packed function pointers
- Introduces `TVMFFIPyMLIRPackedSafeCall` C++ helper class that adapts MLIR's `void(void**)` packed calling convention to TVM FFI's `int(void*, TVMFFIAny*, int32_t, TVMFFIAny*)` safe call convention
- The adapter unpacks the `void**` array into `{handle, args, num_args, rv, ret_code}` and routes through the MLIR function
- Also makes `keep_alive_object` keyword-only in `__from_extern_c__` (from #99) and improves its docstrings
- Adds test using `testing.get_mlir_packed_add_one_c_symbol` helper

## Impact
- API: New static method `Function.__from_mlir_packed_safe_call__(mlir_packed_symbol: int, *, keep_alive_object=None) -> Function`. `__from_extern_c__` parameter `keep_alive_object` changed to keyword-only.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVMFFIFunctionCreate` C API
- `TVMFFIPyObjectDeleter` and `TVMFFIPyWithGILIfNotFreeThreaded` from #98
- `__from_extern_c__` pattern from #99

Design elements this commit produces:
- `TVMFFIPyMLIRPackedSafeCall` adapter class translating MLIR packed convention to TVM FFI safe call convention
- Pattern: `TVMFFIPyMLIRPackedSafeCallCreate`/`Invoke`/`Deleter` triple for lifecycle management

## Reflection
- MLIR execution engine generates functions with `void(void**)` signature where arguments are passed as an array of pointers. This adapter bridges that to the TVM FFI packed convention.
- Kept in Python helper layer (not core C++) since MLIR execution engine may eventually support direct extern C function pointer exposure
