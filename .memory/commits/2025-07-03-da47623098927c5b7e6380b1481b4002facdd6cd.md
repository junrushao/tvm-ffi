# [REFACTOR][FFI] Phase out old VisitAttrs mechanism (#18106)
## TL;DR
- Removes `static constexpr const bool _type_has_method_visit_attrs = true;` from `Object` base class in `include/tvm/ffi/object.h`.
- This phases out the legacy `VisitAttrs` introspection flag; the new reflection system (`ObjectDef<T>`) replaces it.
## Impact
- API: Downstream subclasses that check `_type_has_method_visit_attrs` at compile time will no longer find it on the `Object` base. In practice this flag was vestigial in tvm-ffi since the reflection rewrite.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- The new `ObjectDef<T>` reflection builder (`def_field`/`def_method`) already provides attribute visiting, making the old boolean flag redundant.

Design elements this commit produces:
- Establishes that `Object` no longer carries any `visit_attrs` compile-time marker; future reflection is solely through the `ObjectDef` registry.
## Reflection
- One-line deletion, but signals a clean break from the legacy TVM `VisitAttrs` pattern toward the `ObjectDef` reflection API.
