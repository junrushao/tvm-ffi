# Introduce dtype protocol (#178)
## TL;DR
- Added `dtype.from_dlpack_data_type()` static factory method accepting `(type_code, bits, lanes)` tuples
- Added `TVMFFIPyArgSetterDLPackDataTypeProtocol_` in Cython to auto-convert args with `__dlpack_data_type__` attribute
- Renamed internal slot `__tvm_ffi_dtype__` to `_tvm_ffi_dtype` for consistency
## Impact
- API: new `dtype.from_dlpack_data_type()` method; objects with `__dlpack_data_type__` are now auto-converted in FFI calls

- Data formats/schemas: none
