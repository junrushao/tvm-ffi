# [Minor] Fix missing function ref in type traits (#186)
## TL;DR
- Added `FunctionInfo<R (&)(Args...), void>` specialization to handle function reference types
- Fixes crash when `TVM_FFI_DLL_EXPORT_TYPED_FUNC` is used with extra parentheses or `constexpr auto&` references to functions, which `decltype` resolves as reference types
## Impact
- API: fixes a crash in `TVM_FFI_DLL_EXPORT_TYPED_FUNC` with reference-typed function arguments; no API surface change
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `FunctionInfo` type traits system in `function_details.h`
Design elements this commit produces:
- Function reference type support (`R(&)(Args...)`) in `FunctionInfo`
## Reflection
- Two-line fix but prevents subtle UB/crash in a common macro usage pattern
