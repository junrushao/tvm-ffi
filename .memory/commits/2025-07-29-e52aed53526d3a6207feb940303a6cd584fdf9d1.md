# [REFACTOR][FFI] Phase out SEqualReduce/SHashReduce (#18172)
## TL;DR
- Removes two unused static constexpr bools (`_type_has_method_sequal_reduce`, `_type_has_method_shash_reduce`) from the `Object` base class, completing the migration to the new reflection-based equality/hashing mechanism.
- Removes debug `std::cout` prints from `TCustomFuncObj::SEqual` in test helper.
## Impact
- API: Removes two compile-time trait flags from `Object`. Any downstream code inspecting `_type_has_method_sequal_reduce` or `_type_has_method_shash_reduce` will fail to compile. These flags were legacy from the old SEqualReduce/SHashReduce visitor pattern, now replaced by reflection-based `__ffi_eq__`/`__ffi_hash__`.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- The new reflection-based structural equality/hash mechanism (`ffi/reflection`, `__ffi_eq__`, `__ffi_hash__`) that replaces the old `SEqualReduce`/`SHashReduce` visitor pattern.

Design elements this commit produces:
- Cleaner `Object` base class without legacy boolean trait flags, reducing surface area for the object type system.
## Reflection
- This is a cleanup commit: the two removed bools were dead code after the reflection-based hash/eq system was introduced. The `std::cout` removals in the test are incidental cleanup of debug prints.
