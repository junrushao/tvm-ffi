# [CYTHON] Support cuda stream protocol (#109)
## TL;DR
- Adds `TVMFFIPyArgSetterCUDAStream_` setter that extracts a CUDA stream handle via the `__cuda_stream__()` protocol and passes it as an opaque pointer.
- Checks for `__cuda_stream__` on the argument class during arg setter factory dispatch.
- Also fixes `__dlpack__` check to use `arg_class` (class-level) instead of `arg` (instance-level).
## Impact
- API: Objects implementing `__cuda_stream__()` (NVIDIA's cuda-python interop protocol) are now automatically handled in FFI calls.
- Flags/config: none
- Data formats/schemas: Streams are passed as `void*` (opaque pointer).
## Design Elements
Design elements this commit consumes:
- NVIDIA's CUDA stream protocol: https://nvidia.github.io/cuda-python/cuda-core/latest/interoperability.html#cuda-stream-protocol
Design elements this commit produces:
- CUDA stream interop in the Cython FFI arg dispatch path
## Reflection
- Enables seamless stream passing from cuda-python/torch to TVM FFI without manual conversion.
