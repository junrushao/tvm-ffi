# [FFI] Update torch stream getter to use native torch c api (#18266)
## TL;DR
- Removes the `load_torch_get_current_cuda_stream()` helper that compiled a custom C++ extension via `torch.utils.cpp_extension.load_inline` to obtain the current CUDA stream.
- Replaces it with a single call to `torch._C._cuda_getCurrentRawStream(device_id)`, the same native C API used by PyTorch dynamo.
## Impact
- API: none (internal implementation change only)
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- PyTorch internal C API (`torch._C._cuda_getCurrentRawStream`)
- TVM FFI Cython function call path for CUDA tensor arguments
Design elements this commit produces: none
## Reflection
- This eliminates an expensive JIT compilation step at import/first-call time that previously required a working CUDA compiler toolchain on the host, making the CUDA stream integration simpler and more reliable.
