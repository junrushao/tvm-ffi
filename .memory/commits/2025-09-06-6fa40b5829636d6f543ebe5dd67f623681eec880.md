# [FFI] Add ffi::Tensor.strides() (#18276)
## TL;DR
- Added `Tensor::strides()` method returning a `Shape` with lazy caching (mirrors existing `Tensor::shape()`).
- Renamed internal field `stride_data_` to `strides_data_` for consistency.
- Updated examples to use `ffi::Tensor` parameter type instead of raw `DLTensor*`.
## Impact
- API: New `Tensor::strides()` C++ method. No breaking changes.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `TensorObj` internal layout with `Optional<Shape>` backing fields for shape/strides
- `Shape` container type
Design elements this commit produces:
- `Tensor::strides()` accessor with lazy materialization pattern identical to `shape()`
- Idiomatic example code using `ffi::Tensor` instead of raw `DLTensor*`
## Reflection
- The lazy caching pattern (`if (!strides_data_.has_value()) { ... }`) is consistent with `shape()` and avoids allocating a `Shape` object until explicitly requested.
- Switching examples from `DLTensor*` to `ffi::Tensor` promotes the higher-level type-safe API.
