# Replace Arg2Str helper with a more flexible for_each dispatcher
## TL;DR
- Removes the `Arg2Str` template struct from `function_details.h` (19 lines deleted).
- Enhances `for_each_dispatcher::run` in `base_details.h` to accept three callable signatures: `F(integral_constant<size_t,I>, Arg)`, `F(size_t, Arg)`, or `F(Arg)`, with a `static_assert` fallback.
- Rewrites `FuncFunctorImpl::Sig()` to use the improved `for_each` instead of `Arg2Str`, leveraging `integral_constant` for constexpr index access in the lambda.

## Impact
- API: Internal-only change. `Arg2Str` was a private detail in `namespace tvm::ffi::details`; no public API affected.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Existing `for_each` / `for_each_dispatcher` utility in `base_details.h` (fold-expression over index sequence).
- `Type2Str` trait used for generating human-readable type signatures.

Design elements this commit produces:
- `always_false<T>` dependent-false helper for `static_assert` in `if constexpr` branches (`base_details.h`).
- Three-overload dispatch in `for_each_dispatcher::run`: enables callers to receive compile-time index (`integral_constant`), runtime index (`size_t`), or no index at all.

## Reflection
- The `integral_constant` overload is the key addition: it allows `if constexpr (i() != 0)` inside lambdas, which the old `size_t` overload could not support. The `Sig()` rewrite demonstrates this directly (conditionally emitting the comma separator at compile time).
- `always_false<T>` is a standard C++ idiom to make `static_assert(false)` dependent and avoid ill-formed-no-diagnostic-required in `if constexpr` else branches.
