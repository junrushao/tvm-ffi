# [C-API] TVMFFIErrorSetRaisedFromCStrParts (#107)
## TL;DR
- Adds new C API `TVMFFIErrorSetRaisedFromCStrParts(kind, message_parts, num_parts)` that constructs an error message by concatenating multiple C string parts.
- Motivating use case: DSL compilers can store reusable message fragments (e.g., function signatures) separately to reduce binary size.
- Includes C++ test coverage.
## Impact
- API: New public C ABI function `TVMFFIErrorSetRaisedFromCStrParts`. Additive, non-breaking.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- Existing `SafeCallContext` TLS error mechanism
Design elements this commit produces:
- `TVMFFIErrorSetRaisedFromCStrParts` -- composable error message construction for minimal runtimes
## Reflection
- Useful optimization for compiler-generated code where error messages share common substrings. The API is minimal (concatenation only) which keeps the runtime footprint small.
