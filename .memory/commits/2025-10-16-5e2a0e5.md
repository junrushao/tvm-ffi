# Enable py38 build (#145)
## TL;DR
- Lowered `requires-python` from `>=3.9` to `>=3.8` in pyproject.toml.
- Added `from __future__ import annotations` to files that were missing it (e.g., `_dtype.py`, `stream.py`, lint scripts).
- Added `"FA"` (flake8-future-annotations) to ruff lint rules.
- Added `cp38-*` to cibuildwheel build list and updated ruff/mypy target versions to py38.
- Added `wheelhouse/` to `.gitignore`.
## Impact
- API: none (wider Python version support)
- Flags/config: `requires-python` lowered to 3.8, ruff target changed to py38
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- Python 3.8 compatibility baseline
## Reflection
- The `from __future__ import annotations` additions are required for 3.8 compatibility since PEP 604 union syntax and other typing features need deferred evaluation.
