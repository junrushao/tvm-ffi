# [CMAKE] Hide symbols from libbacktrace (#139)
## TL;DR
- Added `-fvisibility=hidden -fvisibility-inlines-hidden` to CFLAGS when compiling libbacktrace on GCC/Clang/AppleClang.
- This prevents libbacktrace symbols from leaking into the shared library's public symbol table.
## Impact
- API: none
- Flags/config: build-time only change to libbacktrace compilation flags
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- Pattern: hide third-party library symbols via visibility flags in ExternalProject
## Reflection
- Important for avoiding symbol collisions when multiple libraries in the same process each bundle their own libbacktrace.
