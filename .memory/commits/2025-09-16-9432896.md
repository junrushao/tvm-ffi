# [CMAKE] Fix packaging 3rdparty (#18)
## TL;DR
- Appended trailing slashes to `DIRECTORY` source paths in CMake `install()` calls for `dlpack` and `libbacktrace`, so CMake copies the directory *contents* rather than nesting the directory itself inside the destination.
- Bumped Python package version from `0.1.0b2` to `0.1.0b3`.
## Impact
- API: none
- Flags/config: none
- Data formats/schemas: installed wheel layout changes -- `3rdparty/dlpack/include/` and `3rdparty/libbacktrace/` now contain flat contents instead of an extra nested directory.
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces: none
## Reflection
- Classic CMake `install(DIRECTORY)` gotcha: without the trailing `/`, CMake copies the directory itself into the destination rather than its contents.
