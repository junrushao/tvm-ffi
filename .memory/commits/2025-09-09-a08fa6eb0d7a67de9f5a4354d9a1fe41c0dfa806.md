# Streamline Object declaration macros: consolidate 6 macros into 4 with consistent naming
## TL;DR
- Renames and consolidates the Object declaration macros:
  - `TVM_FFI_DECLARE_BASE_OBJECT_INFO` -> `TVM_FFI_DECLARE_OBJECT_INFO` (now takes `TypeKey` as first arg, folding in `_type_key` definition)
  - `TVM_FFI_DECLARE_FINAL_OBJECT_INFO` -> `TVM_FFI_DECLARE_OBJECT_INFO_FINAL` (same TypeKey argument addition)
  - `TVM_FFI_DECLARE_STATIC_OBJECT_INFO` -> `TVM_FFI_DECLARE_OBJECT_INFO_STATIC` (same)
  - New intermediate: `TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY` for classes that define `_type_key` separately.
- Consolidates 4 ObjectRef method macros into 2:
  - `TVM_FFI_DEFINE_OBJECT_REF_METHODS` + `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS` -> `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` (auto-detects mutability via `_type_mutable`)
  - `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS` + `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS` -> `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE` (same auto-detection)
- The `__PtrType` alias uses `std::conditional_t<ObjectName::_type_mutable, ObjectName*, const ObjectName*>` to automatically select mutable vs const pointer, eliminating the mutable/immutable macro split.
## Impact
- API: **Breaking** for all C++ code using any of the old macro names. All Object/ObjectRef declarations must be updated to the new naming convention.
- The `_type_key` is now embedded in the declare macro call, removing the need for a separate `static constexpr const char* _type_key = ...` line.
- `_type_is_nullable` is now always explicitly set: `true` in the nullable macro, `false` in the non-nullable macro.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- [Object system and reference counting](/.memory/designs/0002-object-system-and-reference-counting.md): The entire macro infrastructure for declaring object types and ref wrappers.

Design elements this commit produces:
- **Consolidated macro set**: The new canonical set is `TVM_FFI_DECLARE_OBJECT_INFO[_FINAL|_STATIC]` + `TVM_FFI_DEFINE_OBJECT_REF_METHODS_[NULLABLE|NOTNULLABLE]`. The naming follows `VERB_ADJECTIVE` suffix pattern (e.g., `_FINAL`, `_NULLABLE`).
- **Auto-mutable pointer detection**: `std::conditional_t<ObjectName::_type_mutable, ...>` eliminates the need for separate mutable/immutable macro variants. The `_type_mutable` field on the Obj class drives whether `operator->` returns `const T*` or `T*`.
- **TypeKey-in-macro pattern**: `_type_key` is now always defined inside the declare macro, reducing boilerplate and ensuring every declared type has a key.
