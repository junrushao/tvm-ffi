# Add Docker support and C++ CUDA example (#29)
## TL;DR
- Adds `tests/docker/Dockerfile` (CUDA 12.6.3 / Ubuntu 22.04) with the full build toolchain (CMake, Ninja, clang, Doxygen, Python 3).
- Adds `examples/quick_start/src/run_example_cuda.cc`, a C++ driver that allocates CUDA tensors, calls `add_one_cuda` via FFI, and copies results back to host.
- Updates `CMakeLists.txt` in the quick-start example to use `CUDAToolkit` (modern CMake) and build `run_example_cuda` when CUDA is found.
- Enhances `run_example.sh` with Ninja auto-detection and conditional CUDA execution.
- Adds Docker development instructions to `CONTRIBUTING.md`.
- Updates pre-commit hooks to use `language: python` instead of `language: system` for portability.
