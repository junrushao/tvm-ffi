# [TENSOR] Allow strides to be null for zerodim case (#82)
## TL;DR
- Fixes edge case where `strides()` accessor would assert-fail on zero-ndim tensors with null strides pointer
- Changes 5 checks from `strides != nullptr` to `strides != nullptr || ndim == 0` across `Tensor::strides()`, `TensorView::strides()`, and `FromDLPack*` methods

## Impact
- API: none (bugfix to existing behavior)
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: none
Design elements this commit produces: none

## Reflection
- Scalar (0-dim) tensors are a common edge case in ML frameworks; DLPack spec allows null strides when ndim==0
