# chore(release): Re-enable Python 3.8 Wheel on macOS (#162)
## TL;DR
- Added `actions/setup-python@v5` step to install arm64 Python 3.8 on macOS (since `astral-sh/setup-uv` provides x86_64 instead).
- Pinned `astral-sh/setup-uv` to a specific commit hash and skipped it on macOS arm64.
- Removed `cp38-macosx_*` from the pyproject.toml skip list to re-enable the build.
