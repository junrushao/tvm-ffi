# [DLPack] completely remove normalization (#72)
## TL;DR
- Removed the stride normalization workaround in `_optional_torch_c_dlpack.py` that created a new tensor view via `as_strided` for 1-element 1D tensors with non-unit stride. The source tensor's sizes and strides are now passed through directly.
## Impact
- API: none
- Flags/config: none
- Data formats/schemas: none (DLPack tensor strides are no longer normalized)
## Design Elements
Design elements this commit consumes:
- Torch C DLPack extension `toDLPackImpl`

Design elements this commit produces: none
## Reflection
- The normalization was a workaround for gh-83069 in PyTorch. Removing it suggests TVM-FFI now handles non-unit strides correctly on the receiving side (likely via the inline strides storage from #67).
