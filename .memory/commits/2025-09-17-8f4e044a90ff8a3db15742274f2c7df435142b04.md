# Commit: 8f4e044a — chore: Enforce type annotation on public APIs (#21)

- **Date**: 2025-09-17
- **Author**: Junru Shao
- **Scope**: `pyproject.toml`, across 37 files (Python source, tests, examples)

## Summary
Enables the `ANN` (flake8-annotations) Ruff rule, requiring type annotations on all
public function parameters, return types, and method signatures. This is the final
commit in the three-part lint modernization series.

## Key Changes

### Configuration
- Uncomments `"ANN"` in `[tool.ruff.lint] select` (was commented out in commit 0bc968d1).
- Retains `ANN401` ignore (allowing `Any` type annotations).

### Code Changes (37 files)
- Adds return type annotations to all public functions and methods across `python/tvm_ffi/`.
- Adds parameter type annotations where missing.
- Test files updated with annotations for test helper functions.
- Example files updated with annotations.

## Architectural Impact
- **Medium**: Enforces type safety documentation across the public Python API. Combined
  with the existing `from __future__ import annotations` requirement, the codebase now
  has consistent type annotations suitable for static analysis tools (mypy, pyright).
