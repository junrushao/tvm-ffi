# [CMAKE] Detect endian when possible (#153)
## TL;DR
- Added CMake endianness detection using `CMAKE_CXX_BYTE_ORDER` to define `TVM_FFI_CMAKE_LITTLE_ENDIAN` compile definition.
- Added `__MUSL__` to the list of platforms that include `<endian.h>` in `include/tvm/ffi/endian.h`.
## Impact
- API: none
- Flags/config: new compile definition `TVM_FFI_CMAKE_LITTLE_ENDIAN` when CMake can detect byte order
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- CMake-based endianness detection as a complement to the preprocessor-based detection
## Reflection
- Useful for cross-compilation scenarios where preprocessor macros may not correctly detect the target endianness.
