# [TORCH] robustify torch jit module support for earlier ver (#53)
## TL;DR
- Wraps `kDLFloat4_e2m1fn` and `kDLFloat4_e2m1fn` case blocks in the JIT'd torch C DLPack extension with `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` guards.
- Bumps package version from `0.1.0b6` to `0.1.0b7`.

## Impact
- API: none
- Flags/config: Package version bumped to `0.1.0b7`.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TORCH_VERSION_MAJOR`/`TORCH_VERSION_MINOR` preprocessor macros for conditional compilation in JIT code

Design elements this commit produces:
- Pattern: version-gated dtype support in the inline torch C++ extension for backward compatibility

## Reflection
- The JIT'd C++ extension is compiled at runtime using torch headers, so version guards are essential to avoid compilation errors on older torch versions that lack newer scalar types.
- This is a minimal, targeted fix -- only the new float4/float8 types are gated.
