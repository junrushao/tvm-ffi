# Fix `load_inline` on macOS by linking libtvm_ffi.dylib
## TL;DR
- Fixes `tvm_ffi.cpp.load_inline` on macOS by adding `-L<path> -ltvm_ffi` to the linker flags for non-Windows platforms, ensuring the compiled module links against `libtvm_ffi.dylib`.
- Moves `find_libtvm_ffi()` call and path extraction before the platform-specific branch so it is shared across Windows and Unix.
- Removes `xfail` markers from 4 test functions in `test_load_inline.py` that previously skipped non-Linux/Windows platforms.

- API: none
- Flags/config: none (linker flags are internal to the ninja build generator)
- Data formats/schemas: none
