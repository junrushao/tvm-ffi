# [CPP] Introduce InvokeExternC (#117)
## TL;DR
- Adds `Function::InvokeExternC(handle, safe_call, args...)` static method that directly invokes an `extern "C"` symbol following the TVM FFI SafeCall convention, without constructing an `ffi::Function` object.
- Enables turning already-exported symbols into typed C++ function calls with minimal overhead.
## Impact
- API: New public static method `Function::InvokeExternC`. Additive, non-breaking.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `TVMFFISafeCallType` calling convention
- `PackedArgs::Fill` for argument packing
Design elements this commit produces:
- `Function::InvokeExternC` -- lightweight typed wrapper for extern "C" SafeCall symbols
## Reflection
- Useful for performance-sensitive paths where constructing an `ffi::Function` is unnecessary overhead. The handle is typically `nullptr` for exported symbols.
