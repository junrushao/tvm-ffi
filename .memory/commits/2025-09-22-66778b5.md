# doc: Enable Sphinx Build Checks in CI (#38)
## TL;DR
- Adds a `doc` CI job that runs `sphinx-build -W --keep-going` to catch doc warnings as errors.
- Adds a stub `docs/_stubs/cpp_index.rst` that is copied to `reference/cpp/generated/index.rst` when Doxygen output is absent, preventing Sphinx `toctree` errors.
- Uses `ifconfig:: build_exhale` directive to conditionally include the C++ generated index only when Exhale/Doxygen ran.
- Adds `setup()` function to `docs/conf.py` for custom Sphinx config registration and stub preparation.
- Fixes docstring formatting (Google-style) in `_tensor.py` and `module.py`.
## Impact
- API: none
- Flags/config: New `build_exhale` Sphinx config value. `setuptools<81` pinned in docs deps.
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- Exhale/Breathe Sphinx extensions for C++ API docs.
Design elements this commit produces:
- Graceful degradation pattern: stub RST files fill in for missing generated content so CI passes without Doxygen.
- `_prepare_stub_files()` hook in `docs/conf.py`.
## Reflection
- The `-W` flag (warnings as errors) with `--keep-going` catches all warnings before failing, which is helpful for batch-fixing.
