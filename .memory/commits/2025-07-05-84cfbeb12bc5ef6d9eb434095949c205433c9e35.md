# [FFI] Use fold expression to simplify for_each (#18116)
## TL;DR
- Replaces the recursive template `for_each_dispatcher` (two specializations, recursive `run` calls) with a single struct using a C++17 fold expression `(f(I, std::forward<Args>(args)), ...)`
- Removes the `stop=true` partial specialization (base case) since the fold expression handles empty packs naturally
- Uses `std::index_sequence_for<Args...>` to generate indices instead of manual `I+1` tracking

## Impact
- API: none -- `details::for_each` keeps the same signature and behavior; all internal callers (packed function dispatch, etc.) are unaffected
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- C++17 fold expressions and `std::index_sequence` utilities, already available given the project's C++17 baseline

Design elements this commit produces:
- none (pure simplification, no new abstractions)

## Reflection
- Net -7 lines; straightforward modernization of a utility template that previously needed two class specializations to iterate a parameter pack
