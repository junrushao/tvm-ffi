# feat: Metadata and JSON-based type schemas for fields, methods and global funcs (#36)
## TL;DR
- Introduces `TypeSchema<T>` C++ trait that generates JSON type schema strings for all FFI types (primitives, containers, functions, optionals, variants, tuples)
- Adds `Metadata` class (key-value pairs of `String -> Any`) attachable to fields, methods, and global functions via reflection `def`/`def_field`/`def_method`
- Builds `FieldInfoBuilder`/`MethodInfoBuilder` structs that extend `TVMFFIFieldInfo`/`TVMFFIMethodInfo` with temporary metadata storage, serialized to JSON before C API registration
- On Python side: `TypeSchema` class parses JSON schemas into structured objects with `repr()` output (e.g. `Callable[[int], int]`); `TypeField.metadata` and `TypeMethod.metadata` dicts exposed; new `get_global_func_metadata()` API
- Adds `EscapeString` utility in `string.h` for proper JSON string escaping

## Impact
- API: New public types -- `reflection::Metadata`, `reflection::FieldInfoBuilder`, `reflection::MethodInfoBuilder`; renamed `FieldInfoTrait` to `InfoTrait`; `GlobalDef::def`/`def_method` now automatically attach `type_schema` metadata. Python: new `TypeSchema` class, `get_global_func_metadata()` function.
- Flags/config: none
- Data formats/schemas: New JSON schema format for type information (e.g. `{"type":"ffi.Function","args":[{"type":"int"},{"type":"int"}]}`)

## Design Elements
Design elements this commit consumes:
- Reflection registry pattern (`ObjectDef<T>`, `GlobalDef`)
- `TVMFFIFieldInfo` / `TVMFFIMethodInfo` C structs and their `metadata` byte array field

Design elements this commit produces:
- `TypeSchema<T>` trait pattern for generating JSON type descriptors from C++ types
- `Metadata` class for attaching arbitrary key-value metadata to reflection entries
- Python `TypeSchema` structured schema representation with `from_json_str` parser
- `_TYPE_SCHEMA_ORIGIN_CONVERTER` mapping table in Cython for C++ to Python type name translation

## Reflection
- The `FieldInfoTrait` -> `InfoTrait` rename is a breaking change for any downstream code that subclasses `FieldInfoTrait`
- Type schema generation is fully static (compile-time type information), enabling tooling and IDE support
