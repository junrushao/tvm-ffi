# [Python] Complete Python packaging with scikit-build-core (#18251)
## TL;DR
- Removes `BUILD_WITH_INSTALL_RPATH ON` from the Cython target's RPATH configuration on both macOS and Linux, letting CMake handle build vs install RPATH distinction properly

## Impact
- API: none
- Flags/config: none -- the `INSTALL_RPATH` values (`@loader_path/lib`, `$ORIGIN/lib`) remain the same
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- RPATH setup pattern introduced in #18233

Design elements this commit produces:
- Corrected RPATH configuration that works with scikit-build-core's install step (no `BUILD_WITH_INSTALL_RPATH` override)

## Reflection
- `BUILD_WITH_INSTALL_RPATH ON` bakes the install RPATH into the build tree, which can break local development; removing it lets CMake use the build RPATH during development and switch to the install RPATH on `cmake --install`
