# [DLPACK] Skip Loading DLPack if available (#156)
## TL;DR
- Added an early return in `load_torch_c_dlpack_extension()` if `torch.Tensor` already has a `__c_dlpack_exchange_api__` attribute, avoiding redundant extension compilation.
- Also returns `None` early if torch is not installed.
## Impact
- API: none (optimization of internal loading path)
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `__c_dlpack_exchange_api__` attribute on torch.Tensor as a feature-detection signal
Design elements this commit produces: none
## Reflection
- Forward-looking: newer PyTorch versions will natively support the DLPack exchange API, making the custom extension unnecessary.
