# Add ForEachFieldInfoWithEarlyStop and static_assert on ForEachFieldInfo callback
## TL;DR
- Adds `ForEachFieldInfoWithEarlyStop` template function that iterates field infos (parent-to-child) and returns `true` on first callback that signals early stop.
- Adds a `static_assert` to existing `ForEachFieldInfo` enforcing that its callback must return `void`, preventing accidental misuse.
## Impact
- API: New public C++ template `ForEachFieldInfoWithEarlyStop` in `include/tvm/ffi/reflection/reflection.h`. Existing `ForEachFieldInfo` gains a compile-time check; callers returning non-void from the callback will now fail to compile.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `TypeInfo` / `TVMFFITypeInfo` ancestor-chain iteration pattern already used in `ForEachFieldInfo`
- Field-visit bridge concept for gradual VisitAttrs-to-reflection migration (PR #18091)

Design elements this commit produces:
- `ForEachFieldInfoWithEarlyStop`: enables search-style field traversal (e.g., find a field by name) without scanning every field
- Stricter `ForEachFieldInfo` contract via `static_assert`
## Reflection
- The new helper is part of the VisitAttrs-to-reflection migration path described in the commit message; downstream PRs will use it to adapt old visitor-based code.
- The `static_assert` is a defensive measure to catch silent bugs where a callback return value would be ignored.
