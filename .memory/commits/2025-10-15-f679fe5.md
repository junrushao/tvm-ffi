# [ABI] Refactor the TVMFFIEnvTensorAllocator to align with DLPack (#131)
## TL;DR
- Renamed C API functions: `TVMFFIEnvSetTensorAllocator` -> `TVMFFIEnvSetDLPackManagedTensorAllocator`, `TVMFFIEnvGetTensorAllocator` -> `TVMFFIEnvGetDLPackManagedTensorAllocator`.
- Added new `TVMFFIEnvTensorAlloc` C API that wraps the DLPack allocator and returns a `TVMFFIObjectHandle` (Tensor), moving error handling out of the C++ `Tensor::FromDLPackAlloc`.
- Replaced `Tensor::FromDLPackAlloc` with `Tensor::FromEnvAlloc` that takes the new C function pointer, simplifying the C++ side significantly.
- Added 86 lines of new C++ tests in `tests/cpp/extra/test_c_env_api.cc`.
## Impact
- API: Breaking C ABI change -- three functions renamed/replaced. `Tensor::FromDLPackAlloc` renamed to `Tensor::FromEnvAlloc` with a different signature.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- DLPack v1 `DLPackManagedTensorAllocator` callback protocol
Design elements this commit produces:
- `TVMFFIEnvTensorAlloc` as a single C ABI entry point for tensor allocation from env context
- `Tensor::FromEnvAlloc` as the simplified C++ wrapper
## Reflection
- The refactoring moves error-context boilerplate from the C++ header into the C implementation, making the header-level API simpler and more aligned with the C ABI pattern of returning `int` error codes.
