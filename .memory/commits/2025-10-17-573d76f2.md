# API Alias Redirect for torch aten tensor (#167)
## TL;DR
- Added ATen-compatible aliases on `Tensor` and `TensorView`: `dim()` -> `ndim()`, `sizes()` -> `shape()`, `is_contiguous()` -> `IsContiguous()`
- Changed `size(idx)` and `stride(idx)` to accept `int64_t` (was `size_t`) and support negative indexing
- Added C++ tests for the new aliases
## Impact
- API: new convenience methods `dim()`, `sizes()`, `is_contiguous()` on Tensor/TensorView; `size`/`stride` parameter type changed from `size_t` to `int64_t` (potentially breaking for callers using unsigned)
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- ATen-compatible tensor interface for easier PyTorch interop
## Reflection
- Negative indexing on `size()`/`stride()` matches PyTorch semantics and is a usability improvement
