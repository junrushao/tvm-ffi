# [CI] Setup initial CI

## TL;DR
- Adds GitHub Actions CI workflow (`ci_test.yml`) with prepare/lint/test jobs across Linux x86_64/aarch64, macOS arm64, and Windows AMD64.
- Adds pre-commit config (`.pre-commit-config.yaml`) with standard hooks (trailing whitespace, large files, merge conflict, etc.).
- Adds lint infrastructure: ASF header checker, file type checker, `git-clang-format` wrapper, and `task_lint.sh` orchestrator.
- Adds `publish_wheel.yml` for wheel publishing workflow.

## Impact
- API: none
- Flags/config: `pyproject.toml` gains extended `[tool.black]` exclude patterns (`.venv`, `build`, `docs`, `dist`, `3rdparty`).
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Existing C++ test targets (`tvm_ffi_tests`) and Python test suite (`tests/python`)

Design elements this commit produces:
- CI workflow with skip-ci detection (commit message `[skip ci]` and docs-only changes)
- Lint pipeline: ASF header check, file type check, black formatting, clang-format
- Pre-commit hook configuration for local developer use
- `detect-env-vars` and `detect-skip-ci` reusable GitHub Actions

## Reflection
- The lint job installs `black pylint ruff` via pip but `task_lint.sh` only invokes `black` and `clang-format` at this stage; ruff/pylint are not yet wired in.
- Pre-commit config is minimal (standard hooks only); language-specific linters (ruff, clang-format) are not yet integrated as pre-commit hooks.
