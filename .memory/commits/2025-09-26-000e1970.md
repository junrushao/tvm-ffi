# [CYTHON] Add always inline hint to python helpers (#59)
## TL;DR
- Replaced `inline` with `TVM_FFI_INLINE` (`[[gnu::always_inline]]` / `[[msvc::forceinline]]`) on all public helper functions in `tvm_ffi_python_helpers.h` to ensure inlining regardless of optimization level.
- Increased default temp stack size from 32 slots to 4096 bytes (page-aligned).
## Impact
- API: none (internal helpers only)
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces: none
## Reflection
- The `TVM_FFI_INLINE` macro is re-defined locally in the helper header to avoid pulling in non-C headers, keeping the Cython helpers self-contained.
