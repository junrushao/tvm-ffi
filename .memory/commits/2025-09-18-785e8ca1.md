# feat: Add typestubs for Cython generated code (#24)
## TL;DR
- Introduces `python/tvm_ffi/core.pyi` with full type annotations for all Cython-defined classes (`Object`, `Function`, `Tensor`, `DataType`, `Device`, `Error`, `String`, `Bytes`, etc.) and module-level functions.
- Refactors `_tensor.py` to import symbols directly from `core` instead of going through the `core` module object, improving IDE resolution.
- Adds `.pyi` to the ASF header lint so stub files are checked.
## Impact
- API: No runtime API change; purely a developer-experience improvement (IDE autocompletion, type checking).
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- Cython `.pxi` definitions in `python/tvm_ffi/cython/`

Design elements this commit produces:
- `python/tvm_ffi/core.pyi`: authoritative stub for the Cython extension module
## Reflection
- The stub file is hand-written rather than auto-generated; future Cython changes will need manual stub updates until an automated stub-gen pipeline is in place.
