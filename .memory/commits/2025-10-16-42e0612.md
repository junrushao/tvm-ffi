# Introduce opaque ptr protocol (#147)
## TL;DR
- Added `TVMFFIPyArgSetterFFIOpaquePtrCompatible_` in Cython to handle objects implementing `__tvm_ffi_opaque_ptr__()`.
- The arg setter factory checks for the `__tvm_ffi_opaque_ptr__` attribute and converts the return value to `kTVMFFIOpaquePtr`.
- Added test `test_function_with_opaque_ptr_protocol()` demonstrating the protocol.
- Bumped version from 0.1.0b19 to next (in pyproject.toml and `__init__.py`).
## Impact
- API: New Python protocol `__tvm_ffi_opaque_ptr__()` for custom objects to be passed as opaque pointers through FFI.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `kTVMFFIOpaquePtr` type index
- Cython arg setter factory dispatch pattern
Design elements this commit produces:
- `__tvm_ffi_opaque_ptr__` protocol -- any Python object implementing this method can be passed as an opaque pointer through FFI calls
## Reflection
- Follows the existing pattern of protocol-based type dispatch (like `__dlpack__`, `__tvm_ffi_object__`).
