# Introduce reflection::GlobalDef for fluent global function registration
## TL;DR
- Adds `reflection::GlobalDef` class in `reflection.h` with `def`, `def_packed`, and `def_method` methods that provide a fluent builder API for registering global functions, replacing the `TVM_FFI_REGISTER_GLOBAL("name").set_body_*()` macro pattern.
- Migrates all existing `TVM_FFI_REGISTER_GLOBAL` call sites in `src/ffi/` and `tests/cpp/` to use `GlobalDef` inside `TVM_FFI_STATIC_INIT_BLOCK` blocks.
- Enhances `GetMethod` in `ReflectionDefBase` to handle both `ObjectRef`-derived and `Object`-derived class method pointers with proper dispatch (by-value for ObjectRef, by-pointer for Object).

## Impact
- API: Introduces `reflection::GlobalDef` as the new preferred way to register global functions. The old `TVM_FFI_REGISTER_GLOBAL` macro is not removed but all in-tree usages are migrated away from it. Downstream code using `TVM_FFI_REGISTER_GLOBAL` is still valid but is expected to migrate.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- [.memory/designs/0003-packed-function-and-global-registry.md](.memory/designs/0003-packed-function-and-global-registry.md): GlobalFunctionTable, `TVMFFIFunctionSetGlobalFromMethodInfo`, and `TVMFFIMethodInfo` are the underlying mechanisms that `GlobalDef::RegisterFunc` delegates to.

Design elements this commit produces:
- `reflection::GlobalDef` builder class: a new entry in the reflection subsystem that unifies global function registration with the same fluent API style as `ObjectDef<T>`. Key methods: `def(name, func, extra...)` for typed functions, `def_packed(name, func, extra...)` for packed-args functions, `def_method(name, member_ptr, extra...)` for class member functions exposed as globals.
- Pattern: multiple related functions are grouped into a single `TVM_FFI_STATIC_INIT_BLOCK` containing one chained `GlobalDef()` builder call, replacing scattered `TVM_FFI_REGISTER_GLOBAL` macros that each created separate static variables.

## Reflection
- The `GetMethod` enhancement adds `static_assert` guards and `if constexpr` branching to distinguish `ObjectRef` subclasses (passed by value) from `Object` subclasses (passed by pointer). This fixes method registration for ref-wrapper types where the method is defined on the ref class rather than the underlying object.
- The migration from `TVM_FFI_REGISTER_GLOBAL` to `GlobalDef` within `TVM_FFI_STATIC_INIT_BLOCK` consolidates multiple static-init registrations into fewer translation-unit-level init blocks, which may marginally improve static initialization ordering predictability.
- One test error message changed from `object.Function` to `ffi.Function`, suggesting a concurrent or bundled rename of the Function type key (visible in `test_function.cc` diff).
- The test for `TVM_FFI_REGISTER_GLOBAL("testing.Int_GetValue").set_body_method(...)` was moved from `test_function.cc` to `test_reflection.cc` and rewritten to use `GlobalDef().def_method(...)`, confirming `def_method` as the replacement for `set_body_method`.
