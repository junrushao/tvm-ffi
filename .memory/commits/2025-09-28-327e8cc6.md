# [ERROR] TVM_FFI_CHECK throw error condition (#69)
## TL;DR
- Added `TVM_FFI_CHECK(ErrorKind, cond)` macro that throws a specified error kind (e.g., `ValueError`, `IndexError`) when the condition fails, complementing the existing `TVM_FFI_ICHECK` which always throws `InternalError`.
- Added comprehensive tests for `ValueError`, `IndexError`, and passing conditions.
## Impact
- API: new public macro `TVM_FFI_CHECK(ErrorKind, cond)`
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `TVM_FFI_THROW(ErrorKind)` error throwing pattern

Design elements this commit produces:
- `TVM_FFI_CHECK(ErrorKind, cond)` macro
## Reflection
- Note: the argument order was `(ErrorKind, cond)` in this commit, then swapped to `(cond, ErrorKind)` in the immediately following commit #70.
