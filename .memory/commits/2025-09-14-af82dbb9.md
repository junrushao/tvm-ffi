# fix: Always specify `method_pyfunc.__name__` (#7)

## TL;DR
- Fixes a bug in `_add_class_attrs_by_reflection` where `method_pyfunc.__name__` was only set when the method had a docstring (inside the `if doc is not None` block). Now `__name__` is always set unconditionally.

## Impact
- API: none -- fixes incorrect behavior, no interface change.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Cython reflection system (`_add_class_attrs_by_reflection` in `function.pxi`) that populates Python class attributes from C++ type info

Design elements this commit produces: none

## Reflection
- One-line indentation fix with significant behavioral impact: without `__name__`, reflected methods without docstrings would have incorrect or missing names, breaking introspection, error messages, and debugging.
- The bug was caused by `method_pyfunc.__name__ = name` being indented inside the `if doc is not None:` guard. The fix de-indents it to the outer scope.
