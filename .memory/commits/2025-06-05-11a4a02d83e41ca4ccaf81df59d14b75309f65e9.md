# Rename TVMFFISafeCallType parameter from `self` to `handle`
## TL;DR
- Renames the first parameter of the `TVMFFISafeCallType` function pointer typedef from `self` to `handle` in `include/tvm/ffi/c_api.h`.
- Updates the corresponding Doxygen `\param` comment to match.
## Impact
- API: Cosmetic rename of a parameter name in a typedef; no ABI or behavioral change. Callers are unaffected since C function pointer parameter names have no linkage significance.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- Establishes `handle` as the canonical parameter name for opaque function pointers in the C ABI, aligning with the library-module stabilization effort mentioned in the commit message.
## Reflection
- Pure documentation/naming cleanup in preparation for stabilizing the module system at the FFI layer. The rename from `self` to `handle` avoids implying object-oriented dispatch semantics for what is a plain C function pointer.
