# Relax default alignment and contiguity requirements in DLPack import
## TL;DR
- Changes `from_dlpack()` defaults from `require_alignment=8, require_contiguous=True` to `require_alignment=0, require_contiguous=False`, making tensor import more permissive by default.
- Renames parameter names from `required_alignment`/`required_contiguous` to `require_alignment`/`require_contiguous` throughout Cython bindings.
- Extracts `IsDirectAddressDevice()` as a public utility in `tensor.h` and adds `Tensor::IsAligned()` member method.
- Removes the global `__dlpack_auto_import_required_alignment__` constant; all auto-import call sites (`_convert.py`, `function.pxi`) now rely on relaxed defaults.
## Impact
- API: **Breaking** for Python callers of `from_dlpack()` that relied on keyword argument names `required_alignment`/`required_contiguous` (renamed to `require_*`). Default behavior change: tensors that would have been rejected (non-contiguous, alignment < 8) are now accepted.
- C++ API: New public functions `IsDirectAddressDevice()` and `Tensor::IsAligned()` in `tensor.h`.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- [Container library](/.memory/designs/0004-container-library.md): `Tensor`, `DLTensor`, and the DLPack import path.
- [Cython binding layer](/.memory/designs/0011-cython-binding-layer.md): `tensor.pxi` and `function.pxi` for Python-side tensor marshaling.
- [C ABI boundary layer](/.memory/designs/0005-c-abi-boundary-layer.md): `TVMFFITensorFromDLPack` C API called with alignment/contiguity flags.

Design elements this commit produces:
- **`IsDirectAddressDevice()`**: New public utility function for determining whether a device uses direct memory addressing (CPU, CUDA, ROCm families), extracted from inline logic in `IsAligned`.
- **`Tensor::IsAligned()`**: New member method on the `Tensor` ref class, exposing alignment checks to C++ callers without going through the free function.
- **Relaxed import defaults**: Establishes the convention that DLPack import is permissive by default; callers opt-in to strict checks.
