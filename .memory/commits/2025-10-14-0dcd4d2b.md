# [CPP] Make Tensor/TensorView API to method-based (#121)
## TL;DR
- Replaces `tensor->data`, `tensor->ndim`, `tensor->dtype`, `tensor->device` with method-based accessors: `tensor.data_ptr()`, `tensor.ndim()`, `tensor.dtype()`, `tensor.device()`.
- Adds new accessors: `size(idx)`, `stride(idx)`, `byte_offset()`, `GetDLTensorPtr()`.
- `TensorView` gets the same method-based API, removing `operator->()`.
- Updates all downstream usage in examples, docs, and tests (16 files).
## Impact
- API: Breaking -- removes `operator->()` on `Tensor` (returns `DLTensor*`), replaces with explicit methods. `TensorView::operator->()` also removed.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- Method-based Tensor/TensorView API surface (data_ptr, ndim, dtype, device, size, stride, byte_offset, GetDLTensorPtr)
## Reflection
- Removes the error-prone `operator->()` pattern which exposed raw DLTensor internals. The method-based API is safer and more discoverable.
- Wide-reaching change (16 files) but purely mechanical find-and-replace in downstream code.
