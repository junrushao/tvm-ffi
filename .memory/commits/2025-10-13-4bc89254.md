# [CYTHON] Introduce __tvm_ffi_tensor__ protocol (#108)
## TL;DR
- Adds `__tvm_ffi_tensor__()` protocol: any Python object implementing this method can be passed to FFI calls and will be fast-converted to a `Tensor` argument.
- Adds `TVMFFIPyArgSetterFFITensorCompatible_` setter in Cython arg dispatch, checked before DLPack fallback.
- Includes benchmark script for DLPack performance comparison.
## Impact
- API: New protocol `__tvm_ffi_tensor__()` that third-party tensor wrappers can implement.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- `__tvm_ffi_tensor__` protocol (later renamed to `__tvm_ffi_object__` in commit 8873700)
## Reflection
- Enables wrapping classes that hold an `ffi.Tensor` as a member to participate in fast FFI calls without going through the DLPack round-trip.
- Note: This protocol was short-lived; it was generalized to `__tvm_ffi_object__` in a subsequent commit.
