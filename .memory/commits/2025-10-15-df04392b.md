# [CMake] Enable automatic cmake config discovery (#124)
## TL;DR
- Relocates CMake config files from `cmake/` to `share/cmake/tvm_ffi/` to match CMake's standard `<prefix>/<name>*/share/cmake/<name>*/` search pattern.
- Enables `find_package(tvm_ffi CONFIG REQUIRED)` to work automatically without manually setting `tvm_ffi_ROOT`.
- Simplifies example `CMakeLists.txt` files to use direct `find_package()`.
- Adds `pyproject.toml` config to avoid unnecessary rebuilds in editable mode.
## Impact
- API: none
- Flags/config: CMake config install path changed from `cmake/` to `share/cmake/tvm_ffi/`. Downstream CMake projects using the old path need updating.
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- Standard CMake config discovery pattern (aligns with pybind11 convention)
## Reflection
- Follows established conventions (pybind11) for CMake config placement. Good DX improvement for downstream C++ projects.
