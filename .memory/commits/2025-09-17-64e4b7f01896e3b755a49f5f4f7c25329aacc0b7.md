# Commit: 64e4b7f0 — chore: Modernize pre-commit hooks (#19)

- **Date**: 2025-09-17
- **Author**: Junru Shao
- **Scope**: `.pre-commit-config.yaml`, `.github/workflows/ci_test.yml`, `pyproject.toml`, across 45 files

## Summary
Replaces the monolithic `tests/scripts/task_lint.sh` shell script with a comprehensive
set of pre-commit hooks, modernizing the lint infrastructure. CI now runs pre-commit
natively via the official GitHub Action, and the test stage depends on lint passing.

## Key Changes

### Pre-commit Configuration (`.pre-commit-config.yaml`)
New hooks added:
- **check-yaml**, **check-toml**: Syntax validation for config files.
- **ruff-check** + **ruff-format**: Python linting and formatting (replaces black + isort).
- **clang-format** (v20.1.8): C/C++ formatting (Google style, 100-col).
- **cython-lint** (v0.16.7): Cython linting (120-col max).
- **shfmt** + **shellcheck**: Shell script formatting and static analysis.
- **check-asf-header**: ASF license header check (migrated from `task_lint.sh`).
- **check-file-type**: File type validation (migrated from `task_lint.sh`).

### CI Workflow Changes
- Lint job simplified to `uses: pre-commit/action@v3.0.1` (replaces manual pip install
  of black/pylint/ruff/clang-format-15 and `task_lint.sh` invocation).
- `test` stage now has `needs: [lint, prepare]` (was just `prepare`), enforcing lint
  as a gate before tests run.

### Removed / Deprecated
- `black` and `isort` configs removed from `pyproject.toml` (now handled by ruff).
- `tests/scripts/task_lint.sh` significantly slimmed (header/filetype checks migrated
  to pre-commit local hooks).

### Code Fixes (to pass new linters)
- Added `from __future__ import annotations` to several Python files.
- Minor reformatting in Cython `.pxi` files, shell scripts, C headers.
- `config.py`: Improved path handling with `pathlib`.

## Architectural Impact
- **High**: This is a foundational infrastructure change that defines how code quality
  is enforced across all languages in the repo. Moving from a single shell script to
  composable pre-commit hooks enables per-hook CI caching, local developer feedback
  (via `pre-commit install`), and easier addition of new linters.

## Invariants
- All linting now runs via `pre-commit run --all-files`. The old `task_lint.sh` is
  retained only for clang-tidy (which is too expensive for pre-commit).
- CI test jobs cannot start until lint passes.
