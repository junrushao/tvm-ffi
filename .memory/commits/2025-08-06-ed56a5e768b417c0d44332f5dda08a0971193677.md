# [FFI] Phase out ObjectPath in favor of AccessPath (#18192)
## TL;DR
- Removes the `using ffi::Tuple;` re-export from `namespace tvm`, so `Tuple` is no longer directly available as `tvm::Tuple`.
- Part of a broader effort to phase out ObjectPath in favor of AccessPath; this commit cleans up a namespace convenience alias that is no longer desired.
## Impact
- API: `tvm::Tuple` no longer resolves; callers must use `tvm::ffi::Tuple`. Any downstream C++ code using `tvm::Tuple` will fail to compile.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- Establishes the pattern that `ffi::` types should not be re-exported into the `tvm` root namespace, tightening namespace hygiene.
## Reflection
- The commit message references phasing out ObjectPath in favor of AccessPath, but the actual change in this commit is limited to removing a `using` declaration for `Tuple`. The Tuple cleanup is likely one small piece of a larger multi-commit PR.
