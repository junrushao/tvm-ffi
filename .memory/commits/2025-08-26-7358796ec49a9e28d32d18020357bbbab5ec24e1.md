# [FFI] Misc fixup for windows (#18234)
## TL;DR
- Replaces `FetchContent_Populate` + manual `add_subdirectory` with `FetchContent_MakeAvailable` for GoogleTest (fixes Windows CMake issues)
- Changes `std::remove_cv_t` to `std::decay_t` in Tuple variadic constructor SFINAE to handle MSVC edge cases
- Replaces en-dash characters (`U+2013`) with ASCII hyphens in `json_parser.cc` comments to avoid Windows encoding issues
- Removes `MSVC_RUNTIME_LIBRARY` property and changes test binary output to `lib/` directory

## Impact
- API: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: none

Design elements this commit produces:
- `std::decay_t` instead of `std::remove_cv_t` for SFINAE in variadic template constructors (MSVC compatibility pattern)

## Reflection
- The `std::decay_t` vs `std::remove_cv_t` difference matters because `std::decay_t` also strips references, which MSVC needs when deducing forwarding reference parameter packs
- Non-ASCII characters in source comments can cause MSVC compilation warnings/errors depending on codepage settings
