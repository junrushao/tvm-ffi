# feat: Introduce flexible `TypeSchema.repr(ty_map)` (#94)
## TL;DR
- Adds `TypeSchema.repr(ty_map=...)` method allowing downstream applications to override string representation of types (e.g. `list` -> `Sequence`, `dict` -> `Mapping`)
- Major expansion of `core.pyi` (+458/-56 lines) with detailed docstrings for `Object`, `Function`, `Error`, `TypeSchema`, and other core classes
- Adds test for custom `ty_map` rendering

## Impact
- API: New `ty_map` parameter on `TypeSchema.repr()` and `TypeSchema.__repr_inner__()`. Extensive new docstrings in `core.pyi`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TypeSchema` class from #36

Design elements this commit produces:
- `ty_map` override pattern for schema rendering -- useful for stub generation where different type aliases are needed

## Reflection
- The large `.pyi` diff is mostly docstring additions, not functional changes
- `ty_map` is a callable `(TypeSchema) -> str | None`; returning `None` falls back to default rendering
