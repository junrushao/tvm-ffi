# [MEMORY] Explicitly set padding to 0 (#77)
## TL;DR
- Added `ffi_ptr->__padding = 0` in both `ObjAllocatorBase::make` and `ObjAllocatorBase::make_inplace_array` to ensure deterministic memory for the padding field in `TVMFFIObject`.
## Impact
- API: none
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `TVMFFIObject.__padding` field from the combined ref count ABI (#58)

Design elements this commit produces: none
## Reflection
- Defensive programming: although the padding is unused, zeroing it avoids undefined values in memory dumps and improves debuggability.
