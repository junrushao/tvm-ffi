# chore: cleanup old DLPack related defs (#129)
## TL;DR
- Removed the custom `DLPackTensorAllocator` typedef from `c_api.h` (18 lines deleted), replacing all usages with the upstream `DLPackManagedTensorAllocator` from dlpack.
- Renamed internal references across C++, Python/Cython, and Rust to match the new type name.
- Updated C++ tests for tensor allocation accordingly.
## Impact
- API: C ABI type `DLPackTensorAllocator` removed; callers must use `DLPackManagedTensorAllocator` from dlpack headers instead. Affects `TVMFFIEnvSetTensorAllocator`/`TVMFFIEnvGetTensorAllocator` signatures.
- Flags/config: none
- Data formats/schemas: none
