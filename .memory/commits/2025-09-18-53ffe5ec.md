# [Fix] Restrict stride normalization to 1D tensors on export (#23)
## TL;DR
- Replaces the multi-dimensional stride normalization loop in `toDLPackImpl` with a simple check: only normalize strides for 1D tensors where `size(0)==1 && stride(0)!=1`.
- Simplifies the normalization body to a single `as_strided(shape, {1}, ...)` call.
## Impact
- API: none (internal behavior change for DLPack export)
- Flags/config: none
- Data formats/schemas: Fixes edge-case stride values in exported DLPack tensors; previously multi-dimensional tensors with size-1 dims could have their strides silently rewritten.
## Design Elements
Design elements this commit consumes:
- PyTorch `toDLPackImpl` template used by the torch C DLPack extension

Design elements this commit produces:
- Narrower, safer stride normalization policy (1D only)
## Reflection
- The original code tried to normalize strides for any dimension with size 1, which could mask real stride information in higher-rank tensors. The fix is more conservative and correct.
