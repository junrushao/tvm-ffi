# [FFI] Log and throw in function dup registration (#18149)
## TL;DR
- Replaced `TVM_FFI_THROW` with `TVM_FFI_LOG_AND_THROW` for duplicate global function registration in `GlobalFunctionTable::Register`
- Added a multi-line error message listing possible causes (duplicate `GlobalDef().def` registrations) and suggesting to remove the duplicate
## Impact
- API: none -- error path only, same exception type (`RuntimeError`)
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `TVM_FFI_LOG_AND_THROW` macro (logs before throwing, aids debugging when exceptions are swallowed)
- `GlobalFunctionTable` singleton registry in `src/ffi/function.cc`

Design elements this commit produces:
- Pattern: actionable multi-line error messages with "possible causes" list for registration conflicts
## Reflection
- Tiny 3-line change (net +3). The key insight is that duplicate registration errors are hard to diagnose because the exception may be caught silently; `LOG_AND_THROW` ensures the message reaches stderr regardless.
