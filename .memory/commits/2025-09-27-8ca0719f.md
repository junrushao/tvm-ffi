# [ABI] Introduce ShapeView Minimize TensorObj exposure (#67)
## TL;DR
- Added `ShapeView` as a lightweight non-owning view over shape data (pointer + size), reducing need for managed `Shape` allocations.
- Removed `shape_data_`, `strides_data_`, and `cached_dl_managed_tensor_versioned_` fields from `TensorObj`, significantly reducing TensorObj's ABI surface.
- Shape and strides are now stored inline (as trailing data after the object struct) via `make_inplace_array_object`, eliminating separate heap allocations.
- `Tensor::shape()` and `Tensor::strides()` now return `ShapeView` instead of `Shape`.
- Added helper methods `data_ptr()`, `ndim()`, `numel()` to `Tensor`.
- `ToDLPackVersioned()` simplified: removed atomic caching, now always allocates a new `DLManagedTensorVersioned`.
- Version bumped to 0.1.0b10.
## Impact
- API: `Tensor::shape()` and `Tensor::strides()` return `ShapeView` instead of `Shape` (source-compatible in most cases via implicit conversion). `TensorObj` protected fields removed (ABI break for C++ subclasses).
- Flags/config: none
- Data formats/schemas: `TensorObj` layout changed (removed cached fields, shape/strides now inline).
## Design Elements
Design elements this commit consumes:
- `make_inplace_array_object` for trailing data allocation
- `FillStridesFromShape` utility

Design elements this commit produces:
- `ShapeView` non-owning view class
- Inline shape/strides storage pattern for TensorObj
- `Shape::StridesFromShape(ShapeView)` API
## Reflection
- The removal of the atomic `cached_dl_managed_tensor_versioned_` simplifies TensorObj considerably. The caching was complex (CAS-based) and the overhead of always allocating a new `DLManagedTensorVersioned` is likely negligible.
