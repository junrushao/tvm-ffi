# refactor: Prefer `bytearray_to_str|bytes` to raw Python API (#6)
## TL;DR
- Adds `bytearray_to_bytes` helper in `base.pxi` alongside existing `bytearray_to_str`
- Replaces raw `PyBytes_FromStringAndSize` + `py_str` calls in `function.pxi` with the new helpers
- Touches 5 `.pxi` files; net reduction of ~7 lines in `function.pxi`
## Impact
- API: none -- internal Cython helpers only, no public API change
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- Existing `bytearray_to_str` helper pattern in `base.pxi`
- TVMFFIByteArray C struct for passing byte arrays across FFI boundary

Design elements this commit produces:
- `bytearray_to_bytes` helper for converting FFI byte arrays to Python `bytes` without UTF-8 decode
- Consistent convention: all TVMFFIByteArray-to-Python conversions go through `bytearray_to_str` or `bytearray_to_bytes`
## Reflection
- Reduces duplication and makes the conversion path easier to audit (single place to change if ABI evolves)
