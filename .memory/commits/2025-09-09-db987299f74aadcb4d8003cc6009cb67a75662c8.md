# Introduce `__tvm_ffi_env_stream__` protocol for generic tensor stream exchange
## TL;DR
- Adds `__tvm_ffi_env_stream__` protocol: when a non-CPU tensor argument to an FFI function has this dunder method, the Cython marshaling layer calls it to obtain the source framework's current stream and passes it via `TVMFFIEnvSetCurrentStream` before the function call.
- Renames C API `TVMFFIEnvSetStream` -> `TVMFFIEnvSetCurrentStream` for clarity (both in header and implementation).
- Adds `DLTensorTestWrapper` Cython class in `tensor.pxi` that wraps a Tensor and implements `__tvm_ffi_env_stream__`, `__dlpack__`, `__dlpack_device__` for testing.
- Restructures `base.pxi` to declare DLPack device type constants (`kDLCPU`, `kDLCUDA`, etc.) from `dlpack/dlpack.h` before the FFI C API declarations, enabling device-type checks in `function.pxi`.
- Updates `benchmark_dlpack.py` with `DLTensorTestWrapper` benchmarks and fixes the `tvm_ffi_nop` benchmark body.
## Impact
- API: **Breaking** C API rename `TVMFFIEnvSetStream` -> `TVMFFIEnvSetCurrentStream`. Any C/C++ code calling the old name must update.
- Python: New `__tvm_ffi_env_stream__` protocol for framework-agnostic stream exchange. Non-breaking for existing code (opt-in protocol).
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- [C ABI boundary layer](/.memory/designs/0005-c-abi-boundary-layer.md): `TVMFFIEnvSetCurrentStream`, `TVMFFIEnvGetCurrentStream`, and the stream context management in `stream_context.cc`.
- [Cython binding layer](/.memory/designs/0011-cython-binding-layer.md): `make_args` in `function.pxi` for argument marshaling, and the auto-dlpack path for tensor arguments.
- [Container library](/.memory/designs/0004-container-library.md): `Tensor` and DLPack protocol (`__dlpack__`, `__dlpack_device__`).

Design elements this commit produces:
- **`__tvm_ffi_env_stream__` protocol**: A Python-level duck-typing protocol. Objects that have `__dlpack__` and also implement `__tvm_ffi_env_stream__()` can communicate the active GPU stream to TVM FFI's stream context. The method returns an integer (stream handle cast to `long long`). This enables cross-framework stream synchronization without requiring frameworks to directly call `TVMFFIEnvSetCurrentStream`.
- **DLPack device type constants in Cython**: `base.pxi` now declares `kDLCPU`, `kDLCUDA`, `kDLROCM`, etc. from `dlpack.h`, enabling device-type branching in Cython code.
