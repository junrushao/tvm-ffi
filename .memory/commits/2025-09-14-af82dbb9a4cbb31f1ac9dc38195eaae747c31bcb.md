# Commit: af82dbb9 — fix: Always specify `method_pyfunc.__name__`

- **Date**: 2025-09-14
- **Author**: Junru Shao
- **Scope**: `python/tvm_ffi/cython/function.pxi`

## Summary
Fixes a bug where reflected methods without a docstring would not have their `__name__`
attribute set. Previously, `method_pyfunc.__name__ = name` was inside the `if doc is not
None:` block, so methods without docstrings were missing their name attribute.

## Key Changes
- Dedent `method_pyfunc.__name__ = name` out of the `if doc is not None:` conditional in
  `_add_class_attrs_by_reflection()`.

## Before
```python
if doc is not None:
    method_pyfunc.__doc__ = doc
    method_pyfunc.__name__ = name
```

## After
```python
if doc is not None:
    method_pyfunc.__doc__ = doc
method_pyfunc.__name__ = name
```

## Architectural Impact
- **Low**: Bugfix in the reflection system. Methods without docstrings now correctly report
  their name, which matters for debugging, repr, and introspection.
