# feat: support `ml_dtypes<0.5` (#198)
## TL;DR
- Moved ml_dtypes types that only exist in >= 0.5.0 (`int2`, `uint2`, `float8_e3m4`, `float8_e4m3`, `float8_e8m0fnu`, `float6_e2m3fn`, `float6_e3m2fn`, `float4_e2m1fn`) behind a `hasattr(ml_dtypes, "int2")` guard
- Base types available in ml_dtypes 0.4.x remain unconditionally registered
