# [FFI] Temp skip load_inline tests nonlinux (#18278)
## TL;DR
- Added `@pytest.mark.xfail` to four `test_load_inline_cpp*` tests on non-Linux platforms (macOS, Windows) since the inline compilation path is not yet fully supported there.
- Added `ninja` to `[torch]`, `[cpp]`, and `[test]` optional dependency groups in `pyproject.toml`.
## Impact
- API: none
- Flags/config: new `[cpp]` optional dependency group with `ninja`
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `load_inline` test suite from commit 825aeb9
Design elements this commit produces:
- Platform-conditional test gating pattern using `sys.platform`
## Reflection
- This is a temporary workaround; the `xfail` markers signal known gaps in cross-platform support for `load_inline` that need to be addressed later.
