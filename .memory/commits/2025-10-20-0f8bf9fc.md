# Introduce Device Protocol (#179)
## TL;DR
- Added `TVMFFIPyArgSetterDLPackDeviceProtocol_` in Cython to auto-convert args with `__dlpack_device__` (but not `__dlpack__`) into Device values
- The setter calls `arg.__dlpack_device__()` to get `(device_type, device_id)` tuple and converts to `TVMFFIDevice`
- Added Python tests for the new protocol
## Impact
- API: objects with `__dlpack_device__` protocol are now auto-converted to Device in FFI calls
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- DLPack device protocol (`__dlpack_device__`)
Design elements this commit produces:
- Automatic device argument conversion via DLPack protocol in the FFI arg setter factory
## Reflection
- Complements #178 (dtype protocol); together they enable seamless DLPack interop for both dtype and device
