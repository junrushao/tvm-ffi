# fix: Use `tvm_ffi.dtype` instead of `DataType` in schema (#93)
## TL;DR
- Adds `"DataType": "dtype"` mapping to `_TYPE_SCHEMA_ORIGIN_CONVERTER` so that type schemas display `dtype` instead of `DataType` in Python
- Updates test expectations from `DataType` to `dtype`

## Impact
- API: Schema `repr()` output for `DLDataType` fields/args now shows `dtype` instead of `DataType`
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `_TYPE_SCHEMA_ORIGIN_CONVERTER` mapping from #36

Design elements this commit produces: none

## Reflection
- `tvm_ffi.dtype` is the public Python interface; `tvm_ffi.core.DataType` is internal. The schema should reflect the user-facing name.
