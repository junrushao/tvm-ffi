# [DLL] Explicit link libtvm_ffi_testing from cython (#132)
## TL;DR
- Added `target_link_libraries(tvm_ffi_cython PRIVATE tvm_ffi_testing)` in CMakeLists.txt to ensure correct unloading order (cython first, then testing).
- Added a `TVMFFITestingDummyTarget()` declaration and call in Cython init to force the link dependency.
- Removed the dynamic `load_module` of `tvm_ffi_testing` from `python/tvm_ffi/testing.py`, replacing it with static linking.
## Impact
- API: none (internal build change)
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- Pattern of using dummy symbols to enforce DLL link/unload ordering
## Reflection
- Fixes DLL unloading issues on Windows where the testing library could be unloaded before the Cython module was done referencing it.
