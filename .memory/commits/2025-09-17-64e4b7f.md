# chore: Modernize pre-commit hooks (#19)
## TL;DR
- Replaced the ad-hoc CI lint job (pip install black/pylint/ruff + `task_lint.sh`) with the official `pre-commit/action` GitHub Action, running all hooks declaratively.
- Extended `.pre-commit-config.yaml` with: `ruff-check` + `ruff-format` (replacing black/isort), `clang-format` (v20, replacing clang-format-15 script), `cython-lint`, `shfmt`, `shellcheck`, `check-yaml`, `check-toml`, and two local hooks (`check-asf-header`, `check-file-type`).
- Reformatted all Python files to ruff-format style (100-col, double quotes, trailing commas); reformatted shell scripts via shfmt (tab indent); reformatted C headers to clang-format v20.
- CI `test` job now depends on `lint` (was only `prepare`), ensuring lint passes before tests run.
