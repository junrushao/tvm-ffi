# chore(build): Split `src/ffi/extra/testing.cc` into `libtvm_ffi_testing.so` (#114)
## TL;DR
- Moves `src/ffi/extra/testing.cc` to `src/ffi/testing/testing.cc` and builds it as a separate shared library `libtvm_ffi_testing.so`.
- Testing functions are no longer bundled into `libtvm_ffi.so`, reducing the main library size.
- Adds `find_library_by_basename()` utility in `libinfo.py` for locating any platform-specific shared library.
- Updates Rust bindings to link against the testing library when needed.
## Impact
- API: Testing FFI functions now require loading `libtvm_ffi_testing.so` separately.
- Flags/config: New CMake target `tvm_ffi_testing`.
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- `find_library_by_basename()` in `libinfo.py` -- generic library finder
- Separate `tvm_ffi_testing` CMake target and shared library
## Reflection
- Clean separation of test-only code from the production library. The `find_library_by_basename` utility is a reusable improvement.
