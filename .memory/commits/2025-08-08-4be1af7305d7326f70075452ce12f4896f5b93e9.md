# [FFI][REFACTOR] Move Downcast out of ffi for now (#18198)
## TL;DR
- Removes all `Downcast<T>()` overloads (for `ObjectRef`, `Any`, `Any&&`, `std::optional<Any>`) from `include/tvm/ffi/cast.h`, shrinking the file from ~90 template lines to just `GetRef` and `GetObjectPtr`.
- Updates the sole in-tree caller in `tests/cpp/test_string.cc` to use `r.cast<String>()` instead of `Downcast<String>(r)`.
- Removes the `using ffi::Downcast;` namespace alias from `tvm`, retaining only `using ffi::GetRef;` and adding `using ffi::GetObjectPtr;`.

## Impact
- API: **Breaking** -- any downstream C++ code calling `tvm::Downcast<T>(...)` or `tvm::ffi::Downcast<T>(...)` will fail to compile. Callers must migrate to `Any::cast<T>()` for Any values or `any_value.cast<T>()` for ObjectRef downcasts.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- ADR-0005 `as`/`cast`/`try_cast` semantic split ([.memory/ADRs/0005-as-vs-cast-semantic-split.md](.memory/ADRs/0005-as-vs-cast-semantic-split.md)): `Downcast` was a legacy convenience wrapper that predated the `cast<T>()` method. After ADR-0005 introduced `Any::cast<T>()`, `Downcast` became redundant.
- ADR-0009 extra API isolation ([.memory/ADRs/0009-extra-api-isolation.md](.memory/ADRs/0009-extra-api-isolation.md)): aligns with the principle of minimizing the core FFI surface by removing duplicated functionality.

Design elements this commit produces:
- `cast.h` is now a minimal header containing only `GetRef<RefType>(ptr)` and `GetObjectPtr<BaseType>(ptr)` -- pointer-to-ref and pointer-to-ObjectPtr conversions with no conversion semantics.
- Minor cleanup: `TVM_FFI_INLINE` on `GetRef` replaced with plain `inline`; unnecessary includes (`dtype.h`, `error.h`, `<utility>`) removed.

## Reflection
- The `Downcast` family of functions (4 overloads) duplicated `Any::cast<T>()` behavior that was formalized in ADR-0005. This commit is the natural follow-through: once `cast<T>()` exists as the canonical converting accessor, the legacy wrapper is dead code.
- The commit message says "move out of ffi to node for now," implying `Downcast` may reappear in a higher-level TVM layer. The FFI layer itself no longer carries the symbol.
- Only one in-tree test used `Downcast` directly, confirming minimal in-tree usage and suggesting most call sites had already migrated to `cast<T>()`.
