# [CORE] Use new for singleton to prevent de-alloc order issues (#133)
## TL;DR
- Changed `TypeTable::Global()` from a stack-allocated static local to a heap-allocated `new TypeTable()` that intentionally leaks.
- This prevents use-after-destroy issues during program shutdown when other statics still reference the type table.
## Impact
- API: none
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes: none
Design elements this commit produces:
- Pattern: deliberate leak of singleton via `static T* inst = new T()` for shutdown-order safety
## Reflection
- Classic C++ lifetime-of-statics problem. The heap allocation ensures the table outlives all users during shutdown, with the OS reclaiming memory at exit.
