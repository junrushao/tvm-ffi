# Modularize reflection into registry.h (definition) and accessor.h (read-time helpers)

## TL;DR
- Splits the monolithic `reflection/reflection.h` into two focused headers: `reflection/registry.h` (type/field/method registration via `ObjectDef`, `GlobalDef`, `ReflectionDefBase`) and `reflection/accessor.h` (read-time helpers: `FieldGetter`, `FieldSetter`, `GetMethod`, `ForEachFieldInfo`).
- All `.cc` files that only register reflection metadata now include `registry.h` instead of the old umbrella header; only `test_reflection.cc` (which also reads fields) includes both.
- Net code addition of ~36 lines: the accessor.h (198 lines) is new; registry.h retains 414 lines (was 576 as reflection.h, losing the accessor portion).

## Impact
- API: Header path changes from `tvm/ffi/reflection/reflection.h` to `tvm/ffi/reflection/registry.h` (and optionally `accessor.h`). All downstream C++ code that included the old header must update its `#include`. Within this repo, all 5 `src/ffi/*.cc` files and `tests/cpp/testing_object.h` are migrated.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- [Design 0002 - Object System and Reference Counting](../designs/0002-object-system-and-reference-counting.md): `ObjectDef`, `FieldGetter`, `FieldSetter` all operate on the `Object`/`ObjectRef` hierarchy.

Design elements this commit produces:
- Establishes a two-header reflection architecture: **registry.h** for compile-time registration (heavy template machinery) and **accessor.h** for runtime field/method access (lighter, no registration templates). This separation means translation units that only _define_ types no longer pay the compile cost of accessor utilities.

## Reflection
- The split follows the principle of separating "write path" (registration at static-init time) from "read path" (field access at runtime). This is a clean SRP decomposition.
- `ForEachFieldInfo` and `ForEachFieldInfoWithEarlyStop` in accessor.h walk the ancestor chain (parent-to-child), which is consistent with the type-depth/ancestor array design in the C ABI `TVMFFITypeInfo`.
- The rename from `reflection.h` to `registry.h` is a breaking change for any out-of-tree code, but the old header is simply removed (no compatibility shim). This is acceptable at the current maturity stage.
