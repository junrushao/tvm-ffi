# Add stream context (#5)
## TL;DR
- New `StreamContext` class wrapping `TVMFFIEnvSetStream` C API; saves/restores the previous stream on enter/exit.
- `use_raw_stream(device, stream)` for raw handles, `use_torch_stream(context)` for Torch CUDA streams and graphs.
- Cython helper `_env_set_current_stream` added to call `TVMFFIEnvSetStream` and return the previous stream handle.
- Tests cover nested raw streams, Torch stream switching, Torch current-stream passthrough, and Torch CUDA graph contexts.
## Impact
- API: new public symbols `StreamContext`, `use_raw_stream`, `use_torch_stream` exported from `tvm_ffi.__init__`.
- Flags/config: none
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `TVMFFIEnvSetStream` / `TVMFFIEnvGetStream` from `tvm/ffi/extra/c_env_api.h`
- `tvm_ffi.cpp.load_inline` for in-test C++ compilation
Design elements this commit produces:
- `StreamContext` context-manager pattern (save-on-enter, restore-on-exit)
- Torch interop layer with optional `torch` import guard
## Reflection
- The Torch fallback path raises `ImportError` at call time rather than import time, keeping `tvm_ffi` importable without Torch.
