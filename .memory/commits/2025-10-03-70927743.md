# [CYTHON] Fix memory leak when tensor alloc returns to python (#87)
## TL;DR
- Fixes a memory leak in `make_tensor_from_chandle`: after successful DLPack conversion to a Python tensor, the original `chandle` reference was not decremented, leaking one reference count
- Adds `TVMFFIObjectDecRef(chandle)` after successful DLPack-to-Python conversion since the `DLManagedTensor` already holds its own reference
- On conversion failure, calls `dlpack.deleter(dlpack)` to free the DLPack allocation before falling back to the default path
- Adds CUDA memory leak regression test that verifies GPU memory does not grow across repeated tensor allocations

## Impact
- API: none (bugfix)
- Flags/config: none
- Data formats/schemas: none

Design elements this commit consumes: none
Design elements this commit produces: none

## Reflection
- Root cause: ownership was duplicated -- both `chandle` and `DLManagedTensor` held references, but `chandle` was never released on the Python side
- The regression test uses `torch.cuda.memory_allocated()` to detect leaks, which is a practical pattern for CUDA memory leak testing
