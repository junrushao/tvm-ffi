# Rename FromUnpacked to FromTyped and replace legacy PackedFunc references in docs/comments

## TL;DR
- Renamed `Function::FromUnpacked` to `Function::FromTyped` across headers, sources, and tests (pure mechanical rename, no behavioral change).
- Updated all Doxygen comments and code comments to replace legacy `PackedFunc`/`PackedFuncObj` terminology with `ffi::Function`/`ffi::FunctionObj`, and `TVMRetValue` with `ffi::Any`.
- No changes to function signatures, semantics, or ABI.

## Impact
- API: `Function::FromUnpacked` is renamed to `Function::FromTyped`. All in-tree callers (headers, src, tests) are updated in this commit. Any out-of-tree C++ code calling `Function::FromUnpacked` will fail to compile and must be updated.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- [.memory/designs/0003-packed-function-and-global-registry.md](../designs/0003-packed-function-and-global-registry.md): The `Function` API, `TypedFunction`, and `Function::Registry::set_body_typed` all route through the renamed method.

Design elements this commit produces:
- Establishes `FromTyped` as the canonical name for converting a C++ callable with a concrete signature into a type-erased `ffi::Function`. The new name better describes the operation: the input is a *typed* callable, the output is a packed function. The old name `FromUnpacked` described the input as "unpacked" which was less clear.
- Completes the terminology migration away from the legacy `PackedFunc` name toward `ffi::Function` in all C++ doc comments.

## Reflection
- This is a naming cleanup commit that improves readability but has no functional effect. The rename from `FromUnpacked` to `FromTyped` is a better description of the API's intent: the user provides a typed callable, and the framework wraps it into the packed convention.
- The commit also systematically removes references to `PackedFunc` (the old TVM name) from comments in `function.h`, `function_details.h`, and `rvalue_ref.h`. This aligns the codebase with the `tvm::ffi` namespace naming convention.
- One test name `TEST(Map, PackedFuncGetItem)` was renamed to `TEST(Map, ffi::FunctionGetItem)` which includes `::` in the test name -- an unusual GoogleTest naming choice that may cause issues with test filtering.
- Design doc [0003](../designs/0003-packed-function-and-global-registry.md) still refers to `FunctionObjImpl` and the packed calling convention concepts, which remain accurate. The doc's reference to "TypedFunction" wrappers is consistent with the new `FromTyped` name.
