# Commit: 3197cd09 — Add stream context (#5)

- **Date**: 2025-09-15
- **Author**: Yaxing Cai
- **Scope**: `python/tvm_ffi/stream.py`, `python/tvm_ffi/cython/base.pxi`, `python/tvm_ffi/__init__.py`, `tests/python/test_stream.py`, `docs/reference/python/index.rst`

## Summary
Adds the Python-level `StreamContext` API for managing GPU stream contexts in TVM FFI.
This provides a higher-level Python `with`-statement-based interface on top of the
existing C-level `TVMFFIEnvSetStream` API. Includes both a raw stream API
(`use_raw_stream`) and a PyTorch integration (`use_torch_stream`).

## Key Changes

### New Module: `python/tvm_ffi/stream.py` (148 lines)
- **`StreamContext`** class: Context manager that saves/restores the FFI environment
  stream. On `__enter__`, caches the current stream and sets the new one via
  `core._env_set_current_stream()`. On `__exit__`, restores the previous stream.
- **`TorchStreamContext`** class (conditionally defined if `torch` is importable):
  Wraps a PyTorch stream/graph context and creates a `StreamContext` for the
  corresponding device and CUDA stream handle.
- **`use_torch_stream(context=None)`**: Factory function returning `TorchStreamContext`.
  Supports torch streams (`torch.cuda.stream(s)`), CUDA graphs (`torch.cuda.graph(g)`),
  or the current default stream (when `context=None`).
- **`use_raw_stream(device, stream)`**: Factory returning `StreamContext` from a raw
  device and stream handle (int or ctypes.c_void_p).

### Cython Integration (`base.pxi`)
- New `_env_set_current_stream(device_type, device_id, stream)` function wrapping
  `TVMFFIEnvSetStream()`. Returns the previous stream handle as `uint64_t`.

### Public API
- `StreamContext`, `use_raw_stream`, `use_torch_stream` exported from `tvm_ffi.__init__`.

## Architectural Impact
- **High**: This is the user-facing Python stream management API. It complements the
  existing `__tvm_ffi_env_stream__` duck-typing protocol (design 0014) with an explicit
  context manager approach. The two mechanisms serve different use cases:
  - `__tvm_ffi_env_stream__`: Automatic, per-argument stream detection during FFI calls.
  - `StreamContext`/`use_torch_stream`: Explicit, scope-based stream management by the user.

## Usage Patterns
```python
# Explicit torch stream context
with tvm_ffi.use_torch_stream(torch.cuda.stream(s)):
    kernel(x, y)

# Raw stream handle
with tvm_ffi.use_raw_stream(device, stream_handle):
    kernel(x, y)
```
