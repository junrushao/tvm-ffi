# chore: Test Various Python Versions in GitHub Action CI (#41)
## TL;DR
- Updates CI test matrix to use different Python versions per OS: 3.13 (Ubuntu x86_64), 3.9 (Ubuntu aarch64), 3.12 (Windows), 3.10 (macOS arm64).
- Switches from `actions/setup-python` + `pip install` to `astral-sh/setup-uv` + `uv pip install --reinstall`, matching the project's uv-based workflow.
- Reorders CI steps: checkout first, then detect env vars, then C++ tests, then Python setup and tests.
## Impact
- API: none
- Flags/config: CI now tests Python 3.9, 3.10, 3.12, 3.13 across platforms.
- Data formats/schemas: none
## Design Elements
Design elements this commit consumes:
- `astral-sh/setup-uv` GitHub Action for uv-based Python environment setup.
Design elements this commit produces:
- Multi-version Python CI coverage ensuring compatibility from 3.9 to 3.13.
## Reflection
- Testing the minimum supported version (3.9) on aarch64 is a good choice since that platform is less commonly tested locally.
