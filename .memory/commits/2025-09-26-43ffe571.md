# fix: Only attach docstring when it's defined (#60)
## TL;DR
- Changed `TypeField.as_property()` and `TypeMethod.as_callable()` to only set `__doc__` when the C++ reflection provides a non-empty docstring, leaving it as `None` otherwise.
- Reverts the default docstring generation introduced in #49 which conflicted with Sphinx doc generation.
- Added explicit `doc` strings to `TestIntPairObj` fields `a` and `b` in testing code for regression testing.
