# chore: Add linters for `.rst`, `.md` and `.yaml` (#46)
## TL;DR
- Adds three new pre-commit hooks: `markdownlint-cli2` (Markdown), `yamllint` (YAML), and `rstcheck` (reStructuredText).
- Creates config files `.markdownlint-cli2.yaml` (disables MD013 line-length), `.yamllint.yaml` (120-col warning, truthy values), and `docs/.rstcheck.cfg` (ignores Sphinx-specific directives/roles).
- Fixes existing lint violations across docs (`*.md`, `*.rst`) and YAML files (`.asf.yaml`, CI workflow).

## Impact
- API: none
- Flags/config: Three new linter config files; all contributors must now pass these checks.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: none

Design elements this commit produces:
- Linter configs for markdown, YAML, and RST that future docs/config changes must satisfy

## Reflection
- The `.rstcheck.cfg` ignores Sphinx-specific directives (`automodule`, `toctree`, etc.) so it can run outside of a full Sphinx build.
- `yamllint` truthy rule is relaxed to allow `on`/`off`/`yes`/`no` in addition to `true`/`false`, accommodating GitHub Actions syntax.
