# Design Index

Lookup index for all design records in `.knowledge/design-records/`.
Each entry summarizes one design record. Regenerated by `/commit-distill` after every run.

---

### 0001-c-abi
- **Status**: active
- **Scope**: C ABI, wire types, DLL exports
The stable, language-agnostic boundary between TVM FFI and all language bindings (Python, Rust, C). `TVMFFIObject` header is **24 bytes**: `combined_ref_count` (uint64, offset 0, lower 32 bits = strong, upper 32 bits = weak) + `type_index` (int32, offset 8) + `__padding` (uint32, offset 12) + `deleter(void*, int flags)` (offset 16). `TVMFFIFieldInfo.default_value` renamed to `default_value_or_factory` (commit 5e564cdf); `kTVMFFIFieldFlagBitMaskDefaultFromFactory=1<<5` added. 5 new flag bits (commits 6b39efbf): `ReprOff=1<<6`, `CompareOff=1<<7`, `HashOff=1<<8`, `InitOff=1<<9`, `KwOnly=1<<10`. `kTVMFFIList=75`, `kTVMFFIDict=76` added. `TVMFFISeqCell` struct (shared Array/List layout). `TVMFFITypeAttrColumn.begin_index: int32_t` added (commit c85fd42d). Connects to every other design record.

### 0002-object-system
- **Status**: active
- **Scope**: object system, ref-counting, type hierarchy, UnsafeInit
The three-layer pattern (`FooObj` / `ObjectPtr<T>` / `Foo`) for all heap-allocated TVM FFI objects. `TVMFFIObject` header is **24 bytes**. Memory allocated via `AlignedAlloc<alignof(T)>(sizeof(T))`; freed via `AlignedFree`. `WeakObjectPtr<T>` with `TryPromoteWeakPtr` CAS protocol. `TypeTable::Global()` uses immortal-singleton pattern. Connects to 0001-c-abi, 0003-any-anyview, 0006-reflection.

### 0003-any-anyview
- **Status**: active
- **Scope**: Any, AnyView, type-erased values
The 16-byte type-erased value containers. `AnyView` is non-owning; `Any` extends it with ref-counting and raw-string promotion. Key API split: `as<T>()` is strict non-coercing; `try_cast<T>()`/`cast<T>()` are coercing. `AnyHash`/`AnyEqual` support per-type custom dispatch via `__any_hash__`/`__any_equal__` TypeAttr columns (commit 39d9b2b4). Connects to 0001-c-abi, 0008-type-traits, 0002-object-system.

### 0004-function-system
- **Status**: active
- **Scope**: packed calling convention, global function registry, extern-C / MLIR interop, DLL export macros
`Function` (ObjectRef over `FunctionObj`) is the universal callable. Factory paths: `FromPacked`, `FromTyped`, `TVMFFIFunctionCreate`, `FromExternC`. `InvokeExternC` is zero-allocation one-shot call path. Registration via `reflection::GlobalDef().def(name, fn)`. Connects to 0001-c-abi, 0003-any-anyview, 0005-error-system, 0008-type-traits, 0011-module-system, 0023-cubin-launcher.

### 0005-error-system
- **Status**: active
- **Scope**: structured errors, TLS error slot, cross-language propagation, EnvErrorAlreadySet, error chaining
`ErrorObj` stores `{kind, message, backtrace, cause_chain, extra_context}`. `EnvErrorAlreadySet` changed from standalone `std::exception` subclass to `Error(kind="EnvErrorAlreadySet")`. TLS error slot bridges C++ exceptions and C ABI. Connects to 0001-c-abi, 0002-object-system, 0004-function-system, 0028-expected-type.

### 0006-reflection
- **Status**: active
- **Scope**: reflection, field/method/global/TypeAttr registration
Three-builder pattern: `ObjectDef<Class>` (fields + methods), `GlobalDef` (global functions), `TypeAttrDef<Class>` (per-type attributes). `RegisterField` stores `info.metadata = extract_metadata(extra)`. `refl::init<Args...>` struct with `ObjectDef::def(init<Args...>())` overload. New lowercase InfoTraits: `repr`, `compare`, `hash`, `kw_only`, `init(bool)`, `default_value`, `default_factory`. `ObjectDef<T>` destructor auto-generates `__ffi_init__` via `RegisterAutoInit`/`MakeInit`. `SetFieldToDefault` consolidates factory vs static dispatch. `TVMFFITypeAttrColumn.begin_index` for sparse storage. Connects to 0001-c-abi, 0002-object-system, 0008-type-traits, 0009-structural-eq-hash, 0010-json-serialization, 0017-c-class-dataclasses, 0031-dataclass-ops.

### 0007-containers
- **Status**: active
- **Scope**: Array, List, Map, Dict, String, Bytes, Shape, ShapeView, Tensor, TensorView, Tuple, Variant, MISSING sentinel, KWARGS sentinel
Ten container types plus `TensorView`. `SeqBaseObj` (commit 9513c2f8) is the shared C++ base for `ArrayObj`/`ListObj`; both share `TVMFFISeqCell` C ABI layout. `MapBaseObj` (commit 5a6b2116) holds all hash-map implementation; `MapObj`/`DictObj` are thin final subclasses. `List<T>` (kTVMFFIList=75) is mutable; `Dict<K,V>` (kTVMFFIDict=76) is mutable with `InplaceSwitchTo`. `ffi.GetInvalidObject` (MISSING sentinel) moved to core.pyx. Connects to 0001-c-abi, 0002-object-system, 0008-type-traits, 0011-module-system, 0014-opaque-pyobject.

### 0008-type-traits
- **Status**: active
- **Scope**: TypeTraits customization point, type conversion protocol, storage_enabled/convert_enabled flags, STL bridge
`TypeTraits<T>` is the customization-point struct for type conversion. Key methods: `CheckAnyStrict`, `TryCastFromAnyView`, `MoveFromAnyAfterCheck`. STL bridge adds specializations for `std::vector`, `std::array`, `std::tuple`, `std::optional`, `std::variant`, `std::map`, etc. Connects to 0003-any-anyview, 0004-function-system, 0006-reflection, 0007-containers.

### 0009-structural-eq-hash
- **Status**: active
- **Scope**: StructuralEqual, StructuralHash, AccessPath, StructuralKey, extra/ subsystem
IR-oriented reflection-driven recursive comparison/hashing with alpha-equivalence, free-variable binding, and DAG memoization. `AccessPath` is a proper `ObjectRef` with parent-pointer tree. `StructuralKey` caches structural hash for `Map<Any,Any>` key use. Python API: `structural_equal`, `structural_hash`, `get_first_structural_mismatch`. Distinct from `RecursiveEq`/`RecursiveHash` (see 0031-dataclass-ops) which is a simpler field-by-field system for data containers. Connects to 0006-reflection, 0001-c-abi, 0002-object-system, 0029-py-class, 0031-dataclass-ops.

### 0010-json-serialization
- **Status**: active
- **Scope**: JSON codec, object-graph serialization, ObjectCreator
`json::Parse`/`json::Stringify` handle primitives. `ToJSONGraph`/`FromJSONGraph` serialize any `ffi::Any` preserving DAG sharing. `ObjectCreator` constructs objects from named-field maps. Connects to 0003-any-anyview, 0007-containers, 0006-reflection, 0001-c-abi.

### 0011-module-system
- **Status**: active
- **Scope**: ffi.Module, dynamic libraries, kernel loading, symbol prefix, metadata/doc query, ModuleGlobals
`ffi::Module` (`ModuleObj`/`Module`, type index 73) abstracts over DSOs, system libs, and custom backends. `ModuleGlobals` singleton prevents premature `dlclose`. Module lifetime invariant: Module must outlive objects whose deleters reside in the loaded `.so`. Connects to 0001-c-abi, 0002-object-system, 0004-function-system, 0012-env-api, 0015-load-inline, 0021-build-packaging, 0023-cubin-launcher.

### 0012-env-api
- **Status**: active
- **Scope**: stream context, tensor allocator, Python env callbacks, extra/ C env API
`c_env_api.h` consolidates environment-side C ABI. `TVMFFIEnvSetStream`/`TVMFFIEnvGetStream` manage thread-local stream context. Python API: `StreamContext`, `TorchStreamContext`. Connects to 0001-c-abi, 0005-error-system, 0011-module-system, 0013-python-package, 0016-py-ffi-call-dispatch.

### 0013-python-package
- **Status**: active
- **Scope**: Python package, Cython bindings, library loading, extension packaging, TypeInfo, config-mode guard
Standalone `tvm_ffi` pip package with `scikit-build-core` + Cython. Cython `Object` renamed to `CObject`; new Python `Object(CObject, metaclass=_ObjectSlotsMeta)`. `_install_init` distinguishes `auto_init=True` path (`_make_init` + KWARGS sentinel) from legacy `__ffi_init__` forwarding. `TypeField` gains `c_init`, `c_kw_only`, `c_has_default` boolean flags. `core.KWARGS` singleton for packed kw-arg encoding. `_add_class_attrs` always overrides `__c_ffi_init__` per type. Connects to 0001-c-abi, 0002-object-system, 0004-function-system, 0011-module-system, 0012-env-api, 0014-opaque-pyobject, 0015-load-inline, 0016-py-ffi-call-dispatch, 0017-c-class-dataclasses, 0021-build-packaging, 0029-py-class, 0031-dataclass-ops.

### 0014-opaque-pyobject
- **Status**: active
- **Scope**: OpaquePyObject, cross-language lifecycle bridge, free-threaded Python
`kTVMFFIOpaquePyObject = 74` wraps arbitrary Python objects into ref-counted `Object` instances with identity-preserving round-trip. Connects to 0001-c-abi, 0002-object-system, 0004-function-system, 0013-python-package.

### 0015-load-inline
- **Status**: active
- **Scope**: JIT compilation, inline C++/CUDA, tvm_ffi.cpp, FileLock
`tvm_ffi.cpp.load_inline()` JIT-compiles inline C++/CUDA source strings via Ninja and loads as `Module`. Content-hash caching under `~/.cache/tvm-ffi`. Connects to 0011-module-system, 0004-function-system, 0013-python-package, 0021-build-packaging.

### 0016-py-ffi-call-dispatch
- **Status**: active
- **Scope**: Python FFI call dispatch, TVMFFIPyCallManager, DLPackExchangeAPI, protocols, PyCapsule registration
C++-backed dispatch layer for Python to FFI argument conversion. `TVMFFIPyCallManager` (TLS singleton). DLPackExchangeAPI attribute rename. Connects to 0001-c-abi, 0012-env-api, 0013-python-package, 0007-containers, 0022-torch-dlpack-addon.

### 0017-c-class-dataclasses
- **Status**: active
- **Scope**: Python dataclass proxy, @c_class decorator, field() protocol, structural dunders
`@c_class(type_key)` is now a thin alias for `register_object(type_key)` (commit b97ff1ae). `field()`, `Field`, `KW_ONLY`, `method_init`, `type_info_to_cls` all deleted. `_add_class_attrs` always overrides `__c_ffi_init__` per type. `_install_init` supports `auto_init=True` path via `_make_init`/KWARGS sentinel. Connects to 0006-reflection, 0013-python-package, 0002-object-system, 0029-py-class, 0030-repr-print, 0031-dataclass-ops.

### 0018-rust-binding
- **Status**: active
- **Scope**: Rust language bindings, tvm-ffi-sys, tvm-ffi, tvm-ffi-macros, AnyCompatible, Array<T>
Three-crate Rust workspace. `AnyCompatible` unsafe trait is the Rust analog of C++ `TypeTraits<T>`. `Array<T>` with full mutation API. Soundness fixes (commit 8255069): `data_as_slice_mut(&mut self)`, `with_stream` and `from_extern_c` now `unsafe fn`. Connects to 0001-c-abi, 0002-object-system, 0003-any-anyview, 0004-function-system, 0005-error-system, 0007-containers, 0008-type-traits, 0011-module-system, 0021-build-packaging.

### 0019-type-schema
- **Status**: active
- **Scope**: type schema, metadata, field/method metadata extraction, TypeSchema converter, CAny, __ffi_convert__
Field and method metadata pipeline with Python-side type conversion. `TypeSchema.convert()` returns `CAny` (owned `TVMFFIAny`). `_TYPE_SCHEMA_ORIGIN_CONVERTER` now emits "Array"/"List"/"Map"/"Dict" distinct origins (commit 778613316) instead of collapsing to "list"/"dict". `TY_MAP_DEFAULTS` maps these to `Sequence`/`MutableSequence`/`Mapping`/`MutableMapping`. `__ffi_convert__` TypeAttr protocol. Connects to 0006-reflection, 0020-stub-gen, 0029-py-class.

### 0020-stub-gen
- **Status**: active
- **Scope**: Python stub generation, tvm-ffi-stubgen, inline .pyi blocks, staged pipeline, FuncInfo/ObjectInfo IR, --init-* bootstrap
`tvm-ffi-stubgen python` regenerates inline stub blocks inside `.py` files. Seven-module staged pipeline. `ObjectInfo.gen_init()` emits typed `__init__` stubs. Connects to 0006-reflection, 0019-type-schema, 0013-python-package.

### 0021-build-packaging
- **Status**: active
- **Scope**: build system, CMake packaging, CI, wheel distribution, testing library, convenience integration functions
Two-library split: `libtvm_ffi_shared` (production) and `libtvm_ffi_testing` (testing-only). `tvm_ffi_configure_target` one-call CMake helper. CMake ALIAS targets `tvm_ffi::header/shared/static` now available in both `find_package` and source-dependency (`FetchContent`/`add_subdirectory`) builds (commit ac80ea39). Umbrella header `<tvm/ffi/tvm_ffi.h>`. Dynamic versioning via `setuptools_scm`. Connects to 0011-module-system, 0013-python-package, 0015-load-inline, 0018-rust-binding, 0020-stub-gen, 0022-torch-dlpack-addon.

### 0022-torch-dlpack-addon
- **Status**: active
- **Scope**: standalone torch C DLPack addon, JIT/AOT build, platform-split build, PyCapsule registration
Standalone build script compiles addon to patch older PyTorch with `DLPackExchangeAPI` support. Two-tier loading: AOT wheel probe then JIT subprocess fallback. Connects to 0016-py-ffi-call-dispatch, 0015-load-inline, 0021-build-packaging, 0012-env-api.

### 0023-cubin-launcher
- **Status**: active
- **Scope**: CUDA kernel launching, CubinModule, CUDADeviceGuard, unified API layer, NVRTC Python helper
Header-only CUDA kernel launching infrastructure. Four headers. `tvm::ffi::dim3` removed — use CUDA-native `dim3`. `CubinKernel::LaunchEx` + `cuda_api::ConstructLaunchConfig` added (commit adac5ebd) for SM90+ cluster-dimension launches. Connects to 0005-error-system, 0004-function-system, 0011-module-system, 0012-env-api, 0015-load-inline, 0021-build-packaging.

### 0024-kwargs-wrapper
- **Status**: active
- **Scope**: Python kwargs_wrapper, positional-only callable wrapping, MISSING sentinel
`make_kwargs_wrapper` wraps positional-only callables with keyword-argument support via `exec()`-based code generation. `MISSING` sentinel for exception-free `Map.get`. Connects to 0013-python-package, 0007-containers.

### 0025-handle-lifecycle
- **Status**: active
- **Scope**: thread-safe static handle init/deinit, TVMFFIHandleInitOnce, TVMFFIHandleDeinitOnce
C-ABI-compatible alternative to `std::call_once` for DSL runtimes. Double-checked lock pattern with shared process-global mutex. Connects to 0001-c-abi, 0005-error-system.

### 0026-overload-system
- **Status**: active
- **Scope**: function overloading, OverloadBase, TypedOverload, OverloadedFunction, OverloadObjectDef
Python-style method overloading via `OverloadedFunction<Callable>` with fallback dispatch chain. `Function::FromPackedInplace` ties callable lifetime to Function object. Connects to 0004-function-system, 0006-reflection, 0008-type-traits.

### 0027-dtype-trait
- **Status**: active
- **Scope**: compile-time DLDataType mapping, dtype_trait, CUDA/HIP type support
`tvm_ffi::dtype_trait<T>` maps C++ primitive and GPU types to `DLDataType` values. Python: `tvm_ffi.cpp.dtype.DType` wraps `DLDataType`. Connects to 0008-type-traits, 0007-containers, 0012-env-api, 0013-python-package.

### 0028-expected-type
- **Status**: active
- **Scope**: Expected<T>, Unexpected<E>, exception-free error handling, Function::CallExpected
`Expected<T>` holds success value `T` or `Error`. Uses `Any` as internal storage. `Function::CallExpected<T>()` provides exception-free FFI call path. Connects to 0005-error-system, 0004-function-system, 0003-any-anyview, 0008-type-traits.

### 0029-py-class
- **Status**: active
- **Scope**: Python-defined FFI types, @py_class decorator, field(), two-phase registration, structural eq/hash
`@py_class` enables defining FFI-registered types entirely in Python without C++ `ObjectDef<T>`. Two-phase registration handles forward references. Supports `structure=` param for structural eq/hash control, `field()` with tri-state hash, and auto-registration of `__ffi_*` dunder methods. Connects to 0017-c-class-dataclasses, 0006-reflection, 0009-structural-eq-hash, 0019-type-schema, 0013-python-package, 0030-repr-print.

### 0030-repr-print
- **Status**: active
- **Scope**: unified repr system, ffi.ReprPrint, DFS cycle/DAG tracking, __ffi_repr__ TypeAttr, repr InfoTrait
`ffi.ReprPrint(value)` is a C++ global function producing human-readable repr. As of commit 6b39efbf, backed by `ObjectGraphDFS<ReprTraversal>` (shared DFS engine in `dataclass.cc`). `refl::repr(false)` excludes fields via `kTVMFFIFieldFlagBitMaskReprOff`. Custom repr via `__ffi_repr__` TypeAttr; `@py_class` auto-registers. Connects to 0006-reflection, 0001-c-abi, 0017-c-class-dataclasses, 0029-py-class, 0031-dataclass-ops.

### 0031-dataclass-ops
- **Status**: active
- **Scope**: ObjectGraphDFS CRTP engine, RecursiveHash/Eq/Lt/Le/Gt/Ge, DeepCopy, auto-init (MakeInit/RegisterAutoInit)
`ObjectGraphDFS<Derived, FrameT, ResultT>` CRTP iterative DFS engine (commit 6b39efbf) shared by four operations: `ReprTraversal`, `DeepCopyTraversal`, `HashTraversal`, `CompareTraversal`. Public API: `DeepCopy`, `ReprPrint`, `RecursiveHash`, `RecursiveEq`, `RecursiveLt/Le/Gt/Ge` registered as global functions. `MakeInit`/`RegisterAutoInit` auto-generate `__ffi_init__` from `ObjectDef<T>` destructor. `_make_init`/`_make_init_signature` in Python build typed `__init__` via KWARGS sentinel. Connects to 0006-reflection, 0001-c-abi, 0009-structural-eq-hash, 0013-python-package, 0017-c-class-dataclasses, 0030-repr-print.
