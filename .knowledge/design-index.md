# Design Index

Lookup index for all design records in `.knowledge/design-records/`.
Each entry summarizes one design record. Regenerated by `/commit-distill` after every run.

### 0001-any-anyview-value-system
- **Status**: active
- **Scope**: ffi/any
- 16-byte tagged union (`TVMFFIAny`) serving as the universal wire format for all FFI values. `AnyView` is non-owning (zero-cost for function arguments), `Any` is owning (manages ref-counts for objects). Three-tier conversion model: `as` (strict, no conversion), `cast` (permissive, throws), `try_cast` (permissive, returns optional). Type index partitions values into POD `[0,64)` (including SmallStr=11, SmallBytes=12 for SSO), static objects `[64,128)` (reordered: Shape=69, Tensor=70, Array=71, Map=72, OpaquePyObject=74), and dynamic objects `[128,+inf)`. `zero_padding`/`small_str_len` union at offset 4 activates inline small-string storage. `Any.cast<T>()` is the canonical downcast path (legacy `Downcast` removed). Static object type indices (64-128 range) must be registered via `ReserveBuiltinTypeIndex` to avoid abort on type mismatch errors (e.g., `OpaquePyObject`, `bdad218`). Connects to the Object system (0002), TypeTraits (0005), Containers (0006).

### 0002-object-system
- **Status**: active
- **Scope**: ffi/object, ffi/memory
- Intrusive ref-counted heap objects with single-inheritance type hierarchy. Three-layer pattern: `Object` (data + 24-byte header with `uint64 combined_ref_count` packing strong (lower 32) and weak (upper 32) counters, `type_index` at offset 8, `__padding` at offset 12 (explicitly zeroed), `deleter` at offset 16; `43d13e8`), `ObjectPtr<T>` (strong smart pointer), `ObjectRef` (user-facing wrapper). Note: `TVMFFIObject.type_index` is NOT at offset 0 -- there is no layout aliasing with `TVMFFIAny` (`13436f0`). `WeakObjectPtr<T>` provides weak references with CAS-based promotion via `lock()`. Flag-based deleter protocol (`TVMFFIObjectDeleterFlagBitMask`) separates destruction (kStrong) from memory freeing (kWeak); deleter takes `void*` (not `TVMFFIObject*`). Single-atomic deletion fast path: `DecRef` detects `combined_ref_count == kCombinedRefCountBothOne` with one fetch-sub. `AlignedAlloc`/`AlignedFree` replace `StorageType` wrappers (`6fb42a7`). `TypeTable::Global()` returns a deliberately-leaked heap-allocated singleton to outlive all other static destructors (`4206f16`). Macros: `TVM_FFI_DECLARE_OBJECT_INFO_FINAL`, `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE`; mutable/immutable pointer dispatch auto-derived from `_type_mutable` via `std::conditional_t`. Since `9ac3121`, static inline auto-registration removed from macros; dynamic types MUST explicitly call `ObjectDef<T>()` for type index registration. `ReserveDepthOneObjectTypeIndex` centralizes static (depth-1) type pre-registration. `StaticTypeKey::kTVMFFIError = "ffi.Error"`. `UnsafeInit` tag type, `IsInstance` child-slot optimization, type keys use `ffi.*` namespace. Connects to Any (0001), Function (0003), Reflection (0008).

### 0003-function-system
- **Status**: active
- **Scope**: ffi/function
- Packed callable objects with dual-path calling convention: C-ABI `safe_call` (exception-catching) and optional C++ `cpp_call` (`void*` field in `TVMFFIFunctionCell`; `4fe8b2b`). `CallPacked` uses `cpp_call` when non-null, falls back to `safe_call` via `CppCallDedirectToSafeCall`. `Function::FromTyped` auto-converts typed arguments via TypeTraits. `Function::FromExternC` supports null handle/deleter for raw function pointers via `ExternCFunctionObjNullHandleImpl`. `Function::InvokeExternC` directly invokes a C-ABI safe_call pointer without creating a Function object (zero heap allocation, `9186b44`). Removed: `ImportFromExternDLL`, `ImportedFunctionObjImpl`, `RedirectCallToSafeCall`. Global function registration uses `reflection::GlobalDef`. `TVM_FFI_DLL_EXPORT_TYPED_FUNC` exports typed C++ functions as C-ABI-safe DLL symbols with `__tvm_ffi_` prefix (args now `const TVMFFIAny*`); optionally exports companion `__tvm_ffi__metadata_<name>` (JSON type schema) and `__tvm_ffi__doc_<name>` symbols when `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1` (`ac7bf68`). `FunctionInfo<T>` SFINAE dispatch hierarchy: separate specializations for Object-derived (pointer semantics, `368af82`) and ObjectRef-derived (value semantics, `7b57a46`) member pointers; function reference `R(&)(Args...)` specialization (`a23c5a0`). `FuncFunctorImpl` handles all C++ arg qualifications (`T`, `const T`, `T&`, `const T&`, `T&&`, `const T&&`) via `std::decay_t`/`std::remove_cv_t` normalization (`583e4b7`). `FuncFunctorImpl::TypeSchema()` generates JSON schema for function signatures (`28fe3cc`). `TVM_FFI_STATIC_INIT_BLOCK() { body }` syntax (function-definition style, `7b813f8`). Connects to Error (0004), TypeTraits (0005), Reflection (0008), Module (0011).

### 0004-error-propagation
- **Status**: active
- **Scope**: ffi/error
- Object-based errors (`ErrorObj` with kind/message/backtrace) propagated across C ABI boundaries via TLS. `TVM_FFI_THROW(Kind)` is a stream-based macro with `ErrorBuilder` destructor throw pattern. `TVM_FFI_CHECK(cond, ErrorKind)` macro for user-facing checks with configurable error kind (`327e8cc`, `ae06434`). Renamed from `traceback` to `backtrace` throughout (`6f020c1`): `TVMFFITraceback` -> `TVMFFIBacktrace`, `TVMFFIErrorCell.traceback` -> `.backtrace`, `Error.traceback()` -> `.backtrace()`. Backtraces stored in most-recent-call-first order; `Error::TracebackMostRecentCallLast()` reverses for Python-style display. `TVMFFIBacktraceUpdateMode` enum with Replace/Append modes. `TVMFFIErrorCreate` now returns `int` with output parameter (was direct return). New C API: `TVMFFIErrorSetRaisedFromCStrParts` creates and sets error from kind + multiple message C string parts concatenated (`550e92f`). `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` flag enables stderr logging. `DetectFFIBoundary` matches Python ABI symbols. Error cause chaining: `TVMFFIErrorCell` gains `cause_chain`/`extra_context` handles (`4c712ca`); `TVMFFIErrorCreateWithCauseAndExtraContext` C API. `EnvErrorAlreadySet` unified into Error kind (`b1611e0`), removes error code -2. `Expected<T>` for exception-free error handling (`0a9d4b6`): `Unexpected<E>`, `Function::CallExpected<T>()`. `Error::what()` returns message-only (conforming to `std::exception::what()` no-throw requirement); `Error::FullMessage()` returns full message with backtrace and kind (`4bccb3e`). Connects to Function (0003) and C ABI (0007).

### 0005-type-traits-protocol
- **Status**: active
- **Scope**: ffi/type-traits
- Compile-time specialization interface (`TypeTraits<T>`) with 9 static methods (9th: `TypeSchema()` for JSON schema generation, `28fe3cc`). Three-tier conversion: `CheckAnyStrict` (strict, for containers) vs `TryCastFromAnyView` (permissive, for function args). Generic enum TypeTraits via SFINAE covers all `enum class` types automatically (uses two-phase `is_integeral_enum_v` helper for GCC 8.x compatibility, `5fba9e8`). `TypeTraits<TensorView>` specialization with `storage_enabled=false` and cross-type `TryCastFromAnyView` (`1ec6236`). Built-in specializations for POD types, ObjectRef subtypes, Optional, TypedFunction. `TypeTraits<String>`/`TypeTraits<Bytes>` are standalone specializations handling dual small/large representation. Connects to Any (0001), Containers (0006), Function (0003).

### 0006-containers
- **Status**: active
- **Scope**: ffi/containers
- Collection types storing elements as inline `Any` values. `ArrayObj` uses inplace array pattern. `MapObj` is insertion-ordered with MSB tag protocol; all `at`/`At` methods throw `KeyError` (not `IndexError`) for missing keys (`c88110e`). `String` and `Bytes` are value types backed by `BytesBaseCell` with SSO; `String::starts_with()`/`ends_with()` convenience methods (`02d1a96`). `ShapeView` is a lightweight non-owning view over shape data (`8ca0719`). `TensorObj`/`Tensor` (renamed from NDArray) is DLPack-compatible with inplace shape/strides storage (removed cached `DLManagedTensorVersioned` and `shape_data_`/`strides_data_` fields; `8ca0719`). `TensorView` is a non-owning view over `DLTensor` with `TypeTraits` specialization (`storage_enabled=false`, `TryCastFromAnyView` accepts both `kTVMFFIDLTensorPtr` and `kTVMFFITensor`; `1ec6236`). Strides null-check relaxed: `strides != nullptr || ndim == 0` for zero-dim tensors (`4fefeb0`). Since `0dcd4d2`, Tensor/TensorView expose full method-based API: `device()`, `dtype()`, `size(idx: int64)`, `stride(idx: int64)` (int64 with negative indexing, `573d76f`), `byte_offset()`, `GetDLTensorPtr()`; ATen-style aliases `dim()`, `sizes()`, `is_contiguous()` (`573d76f`); `operator->()` removed. `GetDataSize` free function overloads for both Tensor and TensorView. DLPack `_no_sync` convention for all conversions (`22a78943`). `Tensor::FromDLPackAlloc` allocates via environment tensor allocator. `from_dlpack()` defaults relaxed. `Variant<V...>` uses dual-storage. Type keys use `ffi.*` namespace. Python `Array[T]` is generic (`Sequence[T]`), supports `+` concatenation (`__add__`/`__radd__`), constructor widened to `Iterable[T]` (`54f527f`). Array slicing returns `list[T]` (not `Array[T]`, `90dba57`). Python `Map[K, V]` is generic (`Mapping[K, V]`) with typed views (`df58a05`). `Tuple<Types...>` supports C++17 structured bindings via ADL-friendly `get<I>()` free functions and `std::tuple_size`/`std::tuple_element` specializations; move-qualified `get() &&` overload moves out elements when unique (`5569e44`). `IterAdapter`/`ReverseIterAdapter` conform to InputIterator: `reference = const T`, `operator*` returns by value (`14f3c82`). `List<Any>` mutable sequence container (`9513c2f`): `ListObj` with `kTVMFFIList` type index; `SeqBaseObj`/`SeqBase<T>` shared base with Array; Python `List` as `MutableSequence`. `Dict` mutable dictionary container (`c1af3b3`): `DictObj` with `kTVMFFIDict` type index; Python `Dict` as `MutableMapping`; shares hash-table infrastructure with Map. Map/Array internals refactored into `map_base.h` (`5a6b211`). Connects to Any (0001), Object (0002), TypeTraits (0005), C ABI (0007).

### 0008-reflection
- **Status**: active
- **Scope**: ffi/reflection

### 0009-structural-eq-hash

- Experimental Rust bindings via three crates: `tvm-ffi-sys` (raw C ABI bindings, `build.rs` discovers `libtvm_ffi` via `tvm-ffi-config --libdir`), `tvm-ffi` (safe wrappers: `AnyView<'a>`/`Any`, `ObjectArc<T>`, `Function`, `Error`, `Tensor`, `String`, `Array<T>` (`d0d0e2f`)), and `tvm-ffi-macros` (proc-macros `#[derive(Object)]` and `#[derive(ObjectRef)]` generating `ObjectCore`, `ObjectRefCore`, and `AnyCompatible` implementations). `unsafe trait AnyCompatible` mirrors C++ `TypeTraits<T>` with 7 methods. `ObjectArc<T>` implements native Rust `inc_ref`/`dec_ref` with matching atomic semantics (same 3-path deletion as C++). `CallbackFunctionObjImpl<F>` extends `FunctionObj` with a Rust closure via prefix-cast pattern. Error macros: `check_safe_call!`, `bail!`, `ensure!`, `tvm_ffi_dll_export_typed_func!`, `into_typed_fn!`. Known limitation: `try_cast_from_any_view` uses exact type_index match (no `IsInstance` subtype check). Requires Python editable install first (`09477ce1`). Connects to all core C ABI design records (0001-0008, 0011) as a consumer layer.

### 0015-cuda-utilities
- **Status**: active
- **Scope**: ffi/extra/cuda
- Header-only CUDA utilities for kernel launching and device management. `CubinModule`/`CubinKernel` wraps CUDA Driver API for loading cubin from memory and launching kernels with cached function lookup. `DeviceGuard` provides PyTorch-style RAII device context switching via `cuCtxSetCurrent`. `TVM_FFI_EMBED_CUBIN`/`TVM_FFI_EMBED_CUBIN_GET_KERNEL` macros enable embedding compiled cubin blobs in C++ sources (generated by `EmbedCubin.cmake` or `embed_cubin.py`). Python `tvm_ffi.cpp.nvrtc` wraps NVRTC for runtime CUDA compilation to cubin. `load_inline()` extended with `embed_cubin` parameter (`d49effdb`). Error-checking macros `TVM_FFI_CHECK_CUDA_DRIVER_ERROR`/`TVM_FFI_CHECK_CUDA_RUNTIME_ERROR` in shared `base.h` (`cdfd0410`). Connects to Function (0003), Error (0004), Module (0011), Load Inline (0013).
