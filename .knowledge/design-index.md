# Design Index

Lookup index for all design records in `.knowledge/design-records/`.
Each entry summarizes one design record. Regenerated by `/commit-distill` after every run.

---

### 0001-c-abi
- **Status**: active
- **Scope**: ffi/c-api
- Defines the binary-stable C ABI surface (`c_api.h`): the 16-byte `TVMFFIAny` value layout (with `zero_padding`/`small_str_len` union for small-string optimization), 24-byte `TVMFFIObject` heap header (with `combined_ref_count: uint64` packing strong in lower 32 bits and weak in upper 32 bits, `type_index: int32`, `__padding: uint32`, then `deleter`). `TVMFFITypeIndex` enum covers POD range [0,64), static object range [64,128), and dynamic range [128,+inf). `kTVMFFIDict = 76` (c1af3b33) added for mutable Dict container. `TVMFFITypeAttrColumn` gains `begin_index: int32_t` for offset-based access and `size` narrowed to `int32_t` (c85fd42d). `kDLMAIA = 17` added; `kDLTrn` renumbered 17->18 (49a5d71a). Version bump to patch 10 (577b2949).

### 0002-any-value-system
- **Status**: active
- **Scope**: ffi/any, ffi/type-traits
- C++ type-erased value system: `AnyView` (non-owning 16-byte view) and `Any` (owning, ref-counted). Conversion driven by `TypeTraits<T>` protocol with `CheckAnyStrict`, `TryCastFromAnyView`, `CopyFromAnyViewAfterCheck`, `MoveFromAnyAfterCheck`. Small-string optimization implemented. Semantic split: `as()` is strict, `try_cast()` allows implicit conversion, `cast()` throws on failure. uint64_t overflow check (86bbddfd): unsigned 64-bit values exceeding `INT64_MAX` throw `OverflowError` in `CopyToAnyView`. Per-type `__any_hash__`/`__any_equal__` dispatch via TypeAttr columns (39d9b2b4) enables value-semantic hashing/equality for custom object types.

### 0003-object-system
- **Status**: active
- **Scope**: ffi/object, ffi/memory
- The `Object`/`ObjectRef`/`ObjectPtr<T>`/`WeakObjectPtr<T>` quad: intrusive ref-counted heap objects with a 24-byte `TVMFFIObject` header. `combined_ref_count: uint64` packs strong (lower 32) and weak (upper 32) ref counts, enabling single-atomic `DecRef` fast path. `_type_mutable` flag gates writable field registration. Runtime `IsInstance` via ancestor table. `SimpleObjAllocator` uses `AlignedAlloc`/`AlignedFree`.

### 0004-function-system
- **Status**: active
- **Scope**: ffi/function
- `FunctionObj` with `safe_call` (C ABI entry) and `cpp_call` (C++ fast-path). Perfect forwarding across all construction paths with SFINAE self-type guards. `Function::FromTyped` for typed callable wrapping. `Function::FromPackedInplace` (84c5bdbc) returns `(Function, TCallable*)` for post-construction mutation (used by `OverloadObjectDef`). `Function::CallExpected<T>()` (0a9d4b6) for exception-free calling via `safe_call` path. `Function::InvokeExternC` for zero-allocation direct invocation. `FunctionInfo` SFINAE dispatch. `FunctionObjImpl` variadic forwarding constructor with `GetCallable()` accessor. Python construction: `Function.__from_extern_c__` and `Function.__from_mlir_packed_safe_call__`. Global registration via `refl::GlobalDef`. `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro for embedding documentation. `ArgValueWithContext<Type>` template.

### 0005-error-protocol
- **Status**: active
- **Scope**: ffi/error
- Object-based error handling: `ErrorObj` with kind/message/backtrace/cause_chain/extra_context (4c712ca), `Error` ref that inherits `std::exception`. Backtraces in most-recent-call-first order. TLS error propagation (return code -1 only; -2 removed, b1611e0). Three-tier CHECK macro family (35cbc327): `TVM_FFI_CHECK_*(x, y, ErrorKind)` for generic checks, `TVM_FFI_ICHECK_*` for InternalError aliases, `TVM_FFI_DCHECK_*` for debug-only checks (stripped when NDEBUG). `Expected<T>` for exception-free error handling with `Function::CallExpected<T>()` (0a9d4b6). Python-side cycle-free backtrace injection via `_with_append_backtrace` (6ccbdb6b).

### 0006-containers
- **Status**: active
- **Scope**: ffi/containers
- Ref-counted containers: `Array<T>`, `List<T>` (mutable, 9513c2f8), `Map<K,V>`, `Dict<K,V>` (mutable, c1af3b33), `Shape`, `Tensor`/`TensorView`, `Tuple`, `Variant<T...>`, `Optional<T>`. `String` and `Bytes` backed by `BytesBaseCell`. `Dict<K,V>` shares `MapBaseObj` with `Map` but provides shared-reference (no COW) mutation semantics via `InplaceSwitchTo`. `kTVMFFIDict = 76`. Map hierarchy refactored (5a6b211): `MapBaseObj` extracted to `map_base.h` with templatized factory methods. Container repr via `ffi.ReprPrint` (b648c5d6).

### 0007-reflection
- **Status**: active
- **Scope**: ffi/reflection
- Cross-language field/method access via `ObjectDef<T>` builder with bitmask flags, defaults, docstrings, and metadata. `OverloadObjectDef<T>` (84c5bdbc) extends `ObjectDef` with runtime method overloading. `TVMFFITypeAttrColumn` updated with `begin_index: int32_t` for offset-based access and `size` narrowed to `int32_t` (c85fd42d). `TypeAttrDef<T>` + `TypeAttrColumn` for extensible per-type attributes. `DefaultFactory` (5e564cdf) for per-instance mutable defaults. Auto-registered `__ffi_shallow_copy__` (c73d61a4). Auto-generated `__ffi_init__` from reflected fields when no explicit `init<Args...>` (6b39efbf). Lowercase reflection traits: `repr`, `compare`, `hash`, `kw_only`, `init`, `default_`, `default_factory` (6b39efbf). Field flag bits 7-10 for compare/hash/init/kw_only control. Python `_make_init`/`_make_init_signature` wires C++ auto-init to Python `__init__` with KWARGS protocol (b1abaeac).

### 0008-object-macros
- **Status**: active
- **Scope**: ffi/object
- Five declaration macros: `TVM_FFI_DECLARE_OBJECT_INFO`, `_FINAL`, `_STATIC`, `_PREDEFINED_TYPE_KEY`. Two ref macros: `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` and `NOTNULLABLE`, which auto-derive pointer constness from `_type_mutable` via `std::conditional_t`.

### 0009-structural-eq-hash
- **Status**: active
- **Scope**: ffi/extra, ffi/reflection
- `StructuralEqual` and `StructuralHash` compare/hash `Any` values by walking reflection-registered fields. Dispatch via `TVMFFISEqHashKind` enum. Custom `__s_equal__`/`__s_hash__` via `TypeAttrDef` column registration. `__s_hash__` callback signature changed from `uint64_t` to `int64_t` (bitcast, 86bbddfd). `StructuralKey` (6adc8df7) wraps any value with a cached structural hash for dict/map key use, registering `__any_hash__`/`__any_equal__` TypeAttr overrides. Python `tvm_ffi.structural` module with `structural_equal`, `structural_hash`, `get_first_structural_mismatch`.

### 0010-json-serialization
- **Status**: active
- **Scope**: ffi/extra, ffi/reflection
- Two-layer JSON serialization: `json::Parse`/`Stringify` for lightweight JSON round-tripping, `ToJSONGraph`/`FromJSONGraph` for reflection-driven object graph serialization with node deduplication. POD field inlining for five specific type indices (None, Bool, Int, Float, DataType); `kTVMFFIAny`-declared fields always go through node-graph path (3b26a09). `List<T>` support with cycle detection (9513c2f8). JSON parser fix for non-ASCII UTF-8 on signed-char platforms (d3b5532f).

### 0011-module-system
- **Status**: active
- **Scope**: ffi/module, ffi/extra, ffi/c-env-api
- `ModuleObj`/`Module` for dynamic module loading with virtual function lookup, import hierarchy with cyclic detection, and serialization. `Library` interface with prefixed-then-unprefixed fallback. `LibraryModuleObj` implements `GetFunctionMetadata`/`GetFunctionDoc`. C env API: `EnvContext` manages per-thread streams. `ModuleGlobals` singleton (8dcaec1f) pins modules globally via `keep_module_alive=True` default. Metadata string allocation uses `TVMFFIStringFromByteArray` to avoid use-after-unload (dcacb98d).

### 0012-python-package
- **Status**: active
- **Scope**: python/ffi-bindings, python/packaging
- The `tvm_ffi` standalone Python package with Cython bindings. `CObject` (Cython extension type) + `Object` (Python, with `_ObjectSlotsMeta` enforcing `__slots__=()` on all subclasses, 49a5d71a; broken `__instancecheck__`/`__subclasscheck__` removed in 721d878). `register_object` now universally wires `__init__` via `_install_init` (6973d22). Library loading via `libinfo.load_lib_ctypes()` using `importlib.metadata` RECORD-based discovery (6887892d). `TVMFFIPyCallManager` C++ dispatcher with cached per-type setter dispatch. `TVMFFIPyCallStack` and `TVMFFIPyCallContext` (3dd7a817). `__tvm_ffi_value__` generic value protocol. `__dlpack_c_exchange_api__` (renamed from `__c_dlpack_exchange_api__`, 539364726). Protocol-based arg dispatch.

### 0022-deep-copy
- **Status**: active
- **Scope**: ffi/extra, ffi/reflection, python/ffi-bindings
- `ffi::DeepCopy` provides memoized graph-copy of `Any` values preserving shared references and handling cycles. Now accessed via `dataclass.h` (consolidated from `deep_copy.h` in 6b39efbf). `ObjectDef<T>` auto-registers `__ffi_shallow_copy__` for copy-constructible types (c73d61a4). Python `_setup_copy_methods()` installs `__copy__`/`__deepcopy__`/`__replace__` on FFI class proxies.

### 0023-repr-print
- **Status**: active
- **Scope**: ffi/extra, ffi/reflection, python/ffi-bindings
- `ffi.ReprPrint` is a single C++ global function that produces human-readable repr for any `Any` value using DFS with 3-state cycle/DAG tracking. Now in `dataclass.cc` (consolidated from `repr_print.cc` in 6b39efbf). Extensible via `__ffi_repr__` TypeAttr column. `repr(false)` InfoTrait (renamed from `Repr`) and `kTVMFFIFieldFlagBitMaskReprOff = 1<<6` for per-field exclusion. Python `__repr__` delegates to `ffi.ReprPrint` via `__object_repr__`.

### 0024-dataclass-ops
- **Status**: active
- **Scope**: ffi/extra, ffi/reflection, ffi/c-api, python/ffi-bindings, python/dataclasses
- Unified `dataclass.h` public header consolidating DeepCopy, ReprPrint, RecursiveHash, RecursiveEq, RecursiveLt/Le/Gt/Ge into a shared `ObjectGraphDFS` CRTP engine. New recursive comparison/hashing family with per-field opt-out via `compare(false)`/`hash(false)` traits and custom `__ffi_eq__`/`__ffi_compare__`/`__ffi_hash__` TypeAttr hooks. Auto-generated `__ffi_init__` from `ObjectDef<T>` destructor with KWARGS protocol. Python `_make_init`/`_make_init_signature` wires to proper `__init__` with `inspect.Signature`. Connects to [0007](0007-reflection.md) (reflection traits), [0009](0009-structural-eq-hash.md) (parallel comparison system), [0016](0016-python-dataclasses.md) (Python dataclass init), [0022](0022-deep-copy.md) and [0023](0023-repr-print.md) (consolidated operations).

### 0025-py-class
- **Status**: active
- **Scope**: python/dataclasses, python/ffi-bindings, ffi/reflection
- `@py_class` decorator for Python-defined FFI dataclasses without C++ type definitions. Two-phase registration (type index allocation then field resolution with deferred forward references). `field()` helper with `default`, `default_factory`, `init`, `repr`, `hash`, `compare`, `kw_only`, `structure`; `KW_ONLY` sentinel; `__post_init__` support. `structure=` parameter maps to `TVMFFISEqHashKind` for structural eq/hash (84f46d4). Auto-registers `__ffi_*` dunder methods (`__ffi_repr__`, `__s_equal__`, `__data_to_json__`, etc.) as `TypeMethod` callable from C++ (5735098). Uses `__ffi_new__` TypeAttr for `CreateEmptyObject` fallback. Full FFI integration: serialization, deep copy, repr, structural eq/hash. Connects to [0016](0016-python-dataclasses.md), [0024](0024-dataclass-ops.md), [0007](0007-reflection.md), [0009](0009-structural-eq-hash.md).
