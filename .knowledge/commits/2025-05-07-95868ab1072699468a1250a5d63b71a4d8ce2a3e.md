# Add DLPack FFI overhead benchmark script for AutoDLPack feature
## TL;DR
- Adds `scripts/benchmark_dlpack.py`, a standalone benchmark measuring Python FFI call overhead for various DLPack conversion paths (torch, numpy, cupy, tvm native).
- Benchmarks the new "AutoDLPack" implicit conversion path (passing `torch.Tensor`/`numpy.ndarray` directly to FFI functions) against explicit `from_dlpack` conversion.
- **Diff-message discrepancy**: The commit message describes the full AutoDLPack feature, but this commit only contains the benchmark script (345 LOC). The core AutoDLPack implementation resides in other commits of PR #17927.

## Design Elements
Design elements this commit consumes:
- **Global function registry** (`tvm_ffi.get_global_func("testing.nop")`) -- looks up a C++-registered NOP function to isolate FFI call overhead. See [0004-function-system.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0004-function-system.md).
- **DLPack interop** (`tvm_ffi.from_dlpack()`) -- converts external tensors (torch, numpy) to TVM NDArray via DLPack protocol. See [0008-containers.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0008-containers.md), NDArray section.
- **AutoDLPack implicit conversion** -- the benchmark's `bench_tvm_ffi_nop_autodlpack` functions pass `torch.Tensor`/`numpy.ndarray` directly to `nop()` without explicit `from_dlpack`, exercising the new auto-conversion path. This design element is not yet documented.
- **`__dlpack__` protocol** (DLPack spec) -- benchmarks `__dlpack__()` and `__dlpack__(max_version=(1,1))` on torch, numpy, and tvm tensors.
