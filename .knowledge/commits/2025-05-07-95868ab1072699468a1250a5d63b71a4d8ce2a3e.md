# Add DLPack FFI overhead benchmark script

## TL;DR
- Adds `scripts/benchmark_dlpack.py` (345 LOC), a benchmark measuring Python FFI call overhead for DLPack-based tensor passing: baseline numpy/torch/cupy add, `tvm.ffi.nop` with manual `from_dlpack`, and `autodlpack` (auto-conversion) paths.

## Design Elements
Design elements this commit consumes:
- **Function system / global registry**: The benchmark calls `tvm_ffi.get_global_func("testing.nop")` to obtain a no-op packed function, exercising the global function registry and packed calling convention. See [0004-function-system.md](../designs/0004-function-system.md).
- **NDArray / DLPack interop**: The benchmark calls `tvm_ffi.from_dlpack(tensor)` to convert torch/numpy/cupy tensors into TVM NDArrays via the DLPack protocol. See [0007-containers.md](../designs/0007-containers.md).
- **AutoDLPack path** (referenced in commit message): The `bench_tvm_ffi_nop_autodlpack` functions pass external tensors (torch.Tensor, numpy.ndarray) directly to `nop()` without explicit `from_dlpack`, relying on automatic DLPack conversion in the FFI layer. This feature is not visible in the diff but is exercised by the script.
