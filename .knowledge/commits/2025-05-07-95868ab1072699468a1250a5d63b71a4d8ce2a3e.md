# Add DLPack FFI overhead benchmark script for torch/numpy/cupy interop

## TL;DR
- Adds `scripts/benchmark_dlpack.py` (345 lines), a microbenchmark measuring Python FFI call overhead for DLPack tensor interop across torch, numpy, cupy, and TVM's autodlpack paths.
- Benchmarks three categories: `f(x,y,z)` overhead (baseline add vs FFI nop with various conversion paths), `__dlpack__` export overhead, and `__dlpack__(max_version=...)` versioned export overhead.
- **Diff-message discrepancy**: commit message describes introducing the AutoDLPack *feature*, but the actual diff only contains this benchmark script. The feature implementation is not in this diff.

## Design Elements
Design elements this commit consumes:
- **Function system / global registry** (0003): `tvm_ffi.get_global_func("testing.nop")` to obtain a no-op packed function for measuring call overhead.
- **NDArray DLPack interop** (0006, 0007): `tvm_ffi.from_dlpack(x)` for explicit DLPack conversion from torch/numpy tensors to TVM NDArray.
- **AutoDLPack implicit conversion**: Passing `torch.Tensor` and `numpy.ndarray` directly to FFI functions (e.g., `nop(x, y, z)` where x/y/z are torch tensors), relying on automatic DLPack import in the FFI argument path.

## Usage Examples
The benchmark script itself serves as a usage example for AutoDLPack. The key pattern is:

```python
import torch
from tvm import ffi as tvm_ffi

nop = tvm_ffi.get_global_func("testing.nop")

# Explicit DLPack conversion (baseline)
x = tvm_ffi.from_dlpack(torch.arange(1))
nop(x, x, x)

# AutoDLPack: pass torch.Tensor directly to FFI function
t = torch.arange(1, device="cuda")
nop(t, t, t)  # implicit DLPack import, no manual from_dlpack needed
```
