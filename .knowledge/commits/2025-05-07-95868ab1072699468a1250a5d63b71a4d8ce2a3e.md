# Add DLPack FFI overhead benchmark script for autodlpack feature
## TL;DR
- Adds `scripts/benchmark_dlpack.py` (345 LOC), a comprehensive microbenchmark measuring Python FFI call overhead for DLPack tensor argument passing.
- Benchmarks compare autodlpack (direct torch/numpy tensor args), explicit `from_dlpack` conversion, and baseline `torch.add`/`numpy.add`/`cupy.add` overhead.
- **Diff-message discrepancy**: commit message describes the "AutoDLPack" feature itself, but the diff only contains the benchmark script. The core autodlpack implementation must reside in a prior commit.

## Key Exports
None -- this commit adds only a benchmark script with no public API surface.

The script exercises these existing APIs:

```python
# Consumed APIs (not introduced by this commit):
tvm_ffi.get_global_func("testing.nop")  # -> Function
# Interacts with: global PackedFunc registry (0004-ffi-function-system)

tvm_ffi.from_dlpack(tensor)  # -> NDArray
# Interacts with: NDArray::FromDLPack, DLPack protocol (__dlpack__)
# Interacts with: 0006-ffi-containers (NDArray), 0001-ffi-c-abi (TVMFFINDArrayFromDLPack)

# AutoDLPack: pass torch.Tensor/np.ndarray directly to PackedFunc
nop = tvm_ffi.get_global_func("testing.nop")
nop(torch_tensor, torch_tensor, torch_tensor)  # auto-converts via __dlpack__
# Interacts with: PackedFunc argument conversion, DLPack protocol
# Invariant: input tensor must be contiguous and meet alignment requirements
```

## Design Elements
Design elements this commit consumes:
- **PackedFunc / global registry** (`0004-ffi-function-system`): uses `tvm_ffi.get_global_func("testing.nop")` to obtain a C++-defined NOP function for overhead measurement.
- **NDArray / DLPack interop** (`0006-ffi-containers`): uses `tvm_ffi.from_dlpack()` to convert torch/numpy tensors to TVM NDArrays.
- **AutoDLPack conversion** (not yet documented): the benchmark's main contribution is exercising the autodlpack path where `torch.Tensor` / `np.ndarray` are passed directly to a `PackedFunc` without explicit `from_dlpack`. The FFI runtime auto-detects `__dlpack__` protocol and converts inline.
- **DLPack protocol** (`__dlpack__`, `__dlpack_device__`): benchmarks the overhead of the DLPack capsule export from torch, numpy, cupy, and TVM tensors, including versioned API `__dlpack__(max_version=(1,1))`.

Design elements this commit produces:
- None -- purely a consumer of existing APIs.

## Usage Examples
The benchmark script itself serves as a usage reference for autodlpack. Key pattern:

```python
import torch
from tvm import ffi as tvm_ffi

# AutoDLPack: pass torch tensors directly to a TVM PackedFunc
nop = tvm_ffi.get_global_func("testing.nop")
x = torch.arange(1, device="cuda")
y = torch.arange(1, device="cuda")
z = torch.arange(1, device="cuda")
nop(x, y, z)  # auto-converted via __dlpack__ protocol, no explicit from_dlpack needed

# Explicit DLPack path (for comparison):
tx = tvm_ffi.from_dlpack(x)
nop(tx, tvm_ffi.from_dlpack(y), tvm_ffi.from_dlpack(z))
```
