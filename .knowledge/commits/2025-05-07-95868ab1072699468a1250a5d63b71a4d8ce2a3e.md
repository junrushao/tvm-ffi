## Usage Examples

The benchmark script documents the AutoDLPack calling pattern. Compared to explicit `from_dlpack`:

```python
# Explicit DLPack conversion (pre-AutoDLPack)
nop = tvm_ffi.get_global_func("testing.nop")
tx = tvm_ffi.from_dlpack(x)   # manual conversion required
ty = tvm_ffi.from_dlpack(y)
tz = tvm_ffi.from_dlpack(z)
nop(tx, ty, tz)

# AutoDLPack — pass torch.Tensor or numpy.ndarray directly
nop = tvm_ffi.get_global_func("testing.nop")
nop(x, y, z)  # FFI layer calls x.__dlpack__() automatically
```

Key benchmarks measured:
- `numpy.add`: ~0.36 µs/call (Python baseline)
- `torch.add[cuda]`: ~3.7 µs/call (GPU eager baseline)
- `tvm.ffi.nop+from_dlpack(torch)`: explicit conversion path overhead
- `tvm.ffi.nop.autodlpack(torch[cpu/cuda])`: AutoDLPack path overhead
- `x.__dlpack__()` and `x.__dlpack__(max_version=(1,1))`: raw protocol overhead for torch, numpy, tvm
