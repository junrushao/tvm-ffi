# Add DLPack FFI overhead benchmark script for AutoDLPack feature
## TL;DR
- Adds `scripts/benchmark_dlpack.py` (345 lines, new file), a microbenchmark measuring Python FFI call overhead across multiple DLPack conversion paths: explicit `tvm_ffi.from_dlpack()`, legacy `torch.utils.dlpack.to_dlpack()`, and the AutoDLPack path where external tensors (torch, numpy) are passed directly to TVM FFI functions.
- No functional code changes -- this commit is benchmark/tooling only. The AutoDLPack feature itself (automatic DLPack import when an FFI function receives a non-TVM tensor argument) is implemented elsewhere in the Cython binding layer (`python/tvm_ffi/cython/function.pxi`).
- The benchmark uses `testing.nop` (a registered global function that does nothing) to isolate FFI call overhead from compute, measuring `f(x, y, z)` with length-1 tensors.

## Design Elements

Design elements this commit **consumes**:
- **Function system / GlobalFunctionTable** ([`.knowledge/designs/0004-function-system.md`](../designs/0004-function-system.md)): The benchmark retrieves the `testing.nop` function via `tvm_ffi.get_global_func("testing.nop")` and calls it with the packed calling convention. This exercises the cross-language function dispatch path (Python -> Cython -> C safe_call -> FunctionObj::call).
- **NDArray / DLPack interop** ([`.knowledge/designs/0005-containers.md`](../designs/0005-containers.md)): The benchmark exercises `tvm_ffi.from_dlpack()` which wraps `TVMFFINDArrayFromDLPack` C API. It tests multiple DLPack exchange paths: `__dlpack__()` protocol (PEP 3118 / DLPack 1.0+), legacy `torch.utils.dlpack.to_dlpack()`, and versioned `__dlpack__(max_version=(1,1))`.
- **AutoDLPack / Cython arg setter** (not yet documented in `.knowledge/designs/`): The `bench_tvm_ffi_nop_autodlpack` benchmarks pass `torch.Tensor` / `numpy.ndarray` directly to `nop(x, y, z)` without explicit `from_dlpack()`. This exercises the automatic DLPack conversion in the Cython `TVMFFIPyArgSetterDLPack_` / `TVMFFIPyArgSetterTorchFallback_` code paths in `python/tvm_ffi/cython/function.pxi`.
- **Testing infrastructure** (`src/ffi/testing/testing.cc:515`): The `testing.nop` function is registered as a no-op packed function `[](PackedArgs args, Any* ret) {}` and serves as the baseline for measuring pure FFI overhead.

Design elements this commit **produces**:
- None -- this is a benchmark script, not a functional change. It does not introduce new abstractions, APIs, or invariants.
