# Establish tvm_ffi as a standalone Python package with Cython bindings and improved traceback

## TL;DR
- Introduces the `tvm_ffi` Python package as a standalone, minimal-dependency pip-installable module (49 new files, ~5800 LOC added). The package wraps all core FFI abstractions: Object, Function, NDArray, Array, Map, Shape, Module, error handling, serialization, and testing.
- Adds `pyproject.toml` with scikit-build-core backend, Cython compilation pipeline, `tvm-ffi-config` CLI entry point, and CI wheel build config (cibuildwheel).
- Improves C++ traceback system: adds `cross_ffi_boundary` parameter to `TVMFFITraceback`, frame skipping, symbol-first exclusion matching, FFI boundary detection for Python ABI symbols, and MSVC tail-call workaround in `TVMFFIFunctionCall`.

## Impact
- API: `TVMFFITraceback` gains a 4th parameter `cross_ffi_boundary` (int). All existing callers (via `TVM_FFI_THROW`/`TVM_FFI_LOG_AND_THROW` macros) are updated inline to pass `0`. External C callers of `TVMFFITraceback` must add the parameter.
- Behavioral: Traceback frame filtering now prioritizes symbol-based matching over filename-based matching. `ShouldStopTraceback` renamed to `DetectFFIBoundary`. New boundary detection for Python ABI symbols (`slot_tp_call`, `PyObject*`). Frame skipping added when filename/func are provided (skips 2 frames for `TVMFFITraceback` + caller). `TVMFFIFunctionCall` on MSVC avoids tail-call optimization to keep the frame visible for boundary detection.
- Flags/config: New CMake option `TVM_FFI_BUILD_PYTHON_MODULE` (used by scikit-build). Minimum CMake version bumped 3.14 to 3.18. `TVM_FFI_DECLARE_FINAL_OBJECT_INFO` adds `[[maybe_unused]]` attribute. MSVC `#pragma` typo fixed (`disagnostic` -> `warning`).
- Data formats/schemas: `pyproject.toml` defines package metadata, build system (scikit-build-core + Cython), wheel targets, and sdist inclusion rules.

## Usage Examples

**Registering and using an FFI object from Python (end-to-end):**
```python
import tvm_ffi

@tvm_ffi.register_object("testing.TestObjectBase")
class TestObjectBase(tvm_ffi.Object):
    pass

# Create via reflection
obj = tvm_ffi.testing.create_object("testing.TestObjectBase", x=1, y="hello")

# Register and call a global function
@tvm_ffi.register_func("my.add")
def my_add(a, b):
    return a + b

f = tvm_ffi.get_global_func("my.add")
assert f(1, 2) == 3
```

**Using containers and module loading:**
```python
import tvm_ffi

arr = tvm_ffi.Array([1, 2, 3])
assert len(arr) == 3

m = tvm_ffi.Map({"key": "value"})
assert m["key"] == "value"

shape = tvm_ffi.Shape([3, 224, 224])
assert shape[0] == 3

mod = tvm_ffi.load_module("path/to/module.so")
func = mod.get_function("my_kernel")
```

**Traceback with FFI boundary control (C++ side):**
```cpp
// Stop at FFI boundary (default for TVM_FFI_THROW):
TVMFFITraceback(__FILE__, __LINE__, TVM_FFI_FUNC_SIG, 0);

// Cross FFI boundary (segfault handler):
TVMFFITraceback(nullptr, 0, nullptr, 1);
```
