# Enable free-threaded Python (3.14t) build and fix OpaqueObject type hierarchy
## TL;DR
- Adds full build and CI support for free-threaded Python 3.14t (nogil), including CMake detection, Cython directive, GIL-aware deleter helper, and stable ABI bypass.
- Fixes OpaqueObject type registration to use proper Object hierarchy (type_depth=1, parent=Object) instead of flat reservation, making it recognized as an Object type in isinstance checks.
- Simplifies callback return code handling and hardens opaque object test for free-threaded ref count semantics.

## Key Exports
```python
# New C helper (tvm_ffi_python_helpers.h):
# TVMFFIPyWithGILIfNotFreeThreaded — RAII GIL guard
#   When Py_GIL_DISABLED: no-op (default constructor only)
#   When GIL enabled: PyGILState_Ensure/Release pair
# Invariant: Used by TVMFFIPyObjectDeleter to safely decref across threads

# extern "C" void TVMFFIPyObjectDeleter(void* py_obj) noexcept
#   Replaces old Cython `tvm_ffi_pyobject_deleter` (which used `with gil`)
#   Now in C helper header, uses TVMFFIPyWithGILIfNotFreeThreaded guard
#   Interacts with: TVMFFIFunctionCreate, TVMFFIObjectCreateOpaque

# Cython module directive (core.pyx):
# cython: freethreading_compatible = True
# Declares the extension module safe for free-threaded Python

# CMake detection (CMakeLists.txt):
# PYTHON_IS_FREE_THREADED variable — set by checking sysconfig.Py_GIL_DISABLED
# When true: skips USE_SABI (stable ABI incompatible with free-threaded builds)

# C++ type registration fix (object.cc):
# OpaquePyObject now registered via GetOrAllocTypeIndex with:
#   type_depth=1, parent_type_index=kTVMFFIObject
# Old: ReserveBuiltinTypeIndex (type_depth=0, no parent)
# Invariant: OpaquePyObject is now a proper child of Object in type hierarchy

# Packaging (pyproject.toml):
# cibuildwheel: cp314t-* added to build targets
# torch dependency: conditional on python_version < '3.14' (torch not yet on 3.14t)
```

## Impact
- API: None (no public API signature changes)
- Behavioral: OpaqueObject now passes isinstance(obj, Object) checks that use the type hierarchy (child-slot optimization); previously would fail type_depth checks.
- Flags/config: New CMake variable `PYTHON_IS_FREE_THREADED` controls stable ABI usage; `cython: freethreading_compatible = True` directive added.
- Data formats/schemas: None

## Usage Examples
Before (OpaqueObject not recognized as Object):
```python
# OpaquePyObject was registered with ReserveBuiltinTypeIndex (type_depth=0)
# This meant isinstance checks via child-slot optimization could fail
obj = tvm_ffi.convert(some_python_obj)
# ref_count = tvm_ffi.get_global_func("testing.object_use_count")
# ref_count(obj)  # could fail: OpaqueObject not in Object hierarchy
```

After (OpaqueObject properly in hierarchy):
```python
obj = tvm_ffi.convert(some_python_obj)
ref_count = tvm_ffi.get_global_func("testing.object_use_count")
assert ref_count(obj) == 1  # works: OpaqueObject is child of Object
assert isinstance(obj, tvm_ffi.core.OpaquePyObject)
```

Free-threaded Python deleter pattern (C helper):
```cpp
// tvm_ffi_python_helpers.h
#if defined(Py_GIL_DISABLED)
// No-op guard for nogil Python
class TVMFFIPyWithGILIfNotFreeThreaded { /* default ctor only */ };
#else
// Acquires/releases GIL for traditional Python
class TVMFFIPyWithGILIfNotFreeThreaded {
  TVMFFIPyWithGILIfNotFreeThreaded() noexcept { gstate_ = PyGILState_Ensure(); }
  ~TVMFFIPyWithGILIfNotFreeThreaded() { PyGILState_Release(gstate_); }
};
#endif

extern "C" void TVMFFIPyObjectDeleter(void* py_obj) noexcept {
  TVMFFIPyWithGILIfNotFreeThreaded gil_state;
  Py_DecRef(static_cast<PyObject*>(py_obj));
}
```
