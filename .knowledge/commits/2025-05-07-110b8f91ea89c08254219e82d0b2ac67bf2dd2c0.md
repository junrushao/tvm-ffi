# Rename Function::FromUnpacked to Function::FromTyped and clean up legacy PackedFunc terminology
## TL;DR
- Renames `Function::FromUnpacked` to `Function::FromTyped` across the entire C++ codebase (header, implementation, tests).
- Updates Doxygen comments to replace legacy `PackedFunc` with `ffi::Function`, `TVMRetValue` with `ffi::Any`, and `PackedFuncObj` with `ffi::FunctionObj`.
- All call sites updated consistently: 11 files, ~54 lines changed, additions equal deletions.

### Rename Mapping

| Old Name | New Name | Location |
|---|---|---|
| `Function::FromUnpacked` | `Function::FromTyped` | `include/tvm/ffi/function.h` (definition + all internal call sites) |
| `Function::FromUnpacked` (usage) | `Function::FromTyped` | `src/ffi/container.cc`, `src/ffi/function.cc` |
| `Function::FromUnpacked` (usage) | `Function::FromTyped` | `tests/cpp/test_*.cc` (6 test files) |
| `PackedFunc` (in comments) | `ffi::Function` | `include/tvm/ffi/function.h` |
| `TVMRetValue` (in comments) | `ffi::Any` | `include/tvm/ffi/function.h` |
| `PackedFuncObj` (in comments) | `ffi::FunctionObj` | `include/tvm/ffi/function.h` |
| `TypedPackedFunc` (in comments) | "typed function" | `include/tvm/ffi/function_details.h` |
| Test `FromUnpacked` (test names) | Test `FromTyped` | `test_function.cc`, `test_tuple.cc`, `test_variant.cc` |
| Test `PackedFuncGetItem` | Test `ffi::FunctionGetItem` | `test_map.cc` |

## Impact
- API: `Function::FromUnpacked` renamed to `Function::FromTyped`. All C++ callers must update. No ABI change (this is a static method name, not a symbol in the C ABI).
- Behavioral: none -- pure rename, no semantic change.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Function system** (`0003-function-system`): `Function::FromTyped` (formerly `FromUnpacked`), `Function::FromPacked`, `TypedFunction`, `FunctionObjImpl`, `Function::Registry::set_body_typed`, `Function::Registry::set_body_method`
- **TypeTraits protocol** (`0005-type-traits-protocol`): argument auto-conversion in the `FromTyped` wrapper via `details::unpack_call`

Design elements this commit produces:
- None new -- this is a rename of an existing element. `Function::FromTyped` replaces `Function::FromUnpacked` with identical semantics.
