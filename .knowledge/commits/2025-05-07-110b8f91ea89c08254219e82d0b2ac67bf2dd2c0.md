# Rename Function::FromUnpacked to Function::FromTyped and clean up legacy PackedFunc references

## TL;DR
- Renames `Function::FromUnpacked` to `Function::FromTyped` across headers, source, and all C++ tests.
- Updates Doxygen comments and code examples to replace legacy `PackedFunc` / `TVMRetValue` terminology with the canonical `ffi::Function` / `ffi::Any` names.
- No behavioral or signature changes; purely a naming cleanup.

### Rename Mapping

| Before | After | Scope |
|--------|-------|-------|
| `Function::FromUnpacked(callable)` | `Function::FromTyped(callable)` | Public API method (2 overloads) |
| `Function::FromUnpacked(callable, name)` | `Function::FromTyped(callable, name)` | Public API method (named overload) |
| `PackedFunc` (in comments/docs) | `ffi::Function` | Documentation only |
| `PackedFuncObj` (in comments) | `ffi::FunctionObj` | Documentation only |
| `TVMRetValue` (in comments) | `ffi::Any` | Documentation only |
| `TypedPackedFunc` (in comments) | typed function | Documentation only |
| `TEST(Func, FromUnpacked)` | `TEST(Func, FromTyped)` | Test name |
| `TEST(Tuple, FromUnpacked)` | `TEST(Tuple, FromTyped)` | Test name |
| `TEST(Variant, FromUnpacked)` | `TEST(Variant, FromTyped)` | Test name |
| `TEST(Map, PackedFuncGetItem)` | `TEST(Map, ffi::FunctionGetItem)` | Test name |

## Impact
- API: `Function::FromUnpacked` is renamed to `Function::FromTyped`. All call sites within this repo are updated. External callers using `FromUnpacked` will get a compile error.
- Behavioral: none -- identical runtime behavior.
- Flags/config: none.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- **Function system** (`.knowledge/designs/0004-function-system.md`): The packed calling convention, `FunctionObj`, `TypedFunction`, `Function::Registry`, `details::unpack_call`.
- **Object system** (`.knowledge/designs/0002-object-system.md`): `ObjectRef` pattern used by `Function`.

Design elements this commit produces:
- None new. This is a pure rename of an existing API method (`FromUnpacked` -> `FromTyped`). The name `FromTyped` better reflects that this method wraps a *typed* callable (as opposed to a packed-signature callable wrapped by `FromPacked`).

## Usage Examples

Before (old name):
```cpp
Function f = Function::FromUnpacked([](int a, int b) -> int { return a + b; });
```

After (new name):
```cpp
Function f = Function::FromTyped([](int a, int b) -> int { return a + b; });
```

The semantics are identical. The rename clarifies the naming contrast: `FromPacked` wraps a packed-convention callable, `FromTyped` wraps a typed callable.
