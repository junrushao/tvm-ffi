# Rename Function::FromUnpacked to Function::FromTyped across C++ headers, source, and tests

## TL;DR
- `Function::FromUnpacked` is renamed to `Function::FromTyped` in all call sites across headers, source files, and tests (54 additions, 54 deletions, 11 files).
- Doc comments updated throughout `function.h` to replace legacy `PackedFunc` / `TVMRetValue` / `TypedPackedFunc` references with `ffi::Function` / `ffi::Any` terminology.
- Test names updated to match: e.g. `TEST(Func, FromUnpacked)` → `TEST(Func, FromTyped)`, `TEST(Tuple, FromUnpacked)` → `TEST(Tuple, FromTyped)`.

| Old name | New name | Location |
|---|---|---|
| `Function::FromUnpacked(callable)` | `Function::FromTyped(callable)` | `include/tvm/ffi/function.h` |
| `Function::FromUnpacked(callable, name)` | `Function::FromTyped(callable, name)` | `include/tvm/ffi/function.h` |
| `ffi::Function::FromUnpacked(...)` | `ffi::Function::FromTyped(...)` | `src/ffi/container.cc`, `src/ffi/function.cc` |
| `TEST(Func, FromUnpacked)` | `TEST(Func, FromTyped)` | `tests/cpp/test_function.cc` |
| `TEST(Map, PackedFuncGetItem)` | `TEST(Map, ffi::FunctionGetItem)` | `tests/cpp/test_map.cc` |
| `TEST(Tuple, FromUnpacked)` | `TEST(Tuple, FromTyped)` | `tests/cpp/test_tuple.cc` |
| `TEST(Variant, FromUnpacked)` | `TEST(Variant, FromTyped)` | `tests/cpp/test_variant.cc` |
| comment: `via FromUnpacked` | `via FromTyped` | `include/tvm/ffi/function_details.h` |
| example: `Function::FromUnpacked(...)` | `Function::FromTyped(...)` | `include/tvm/ffi/rvalue_ref.h` |

## Key Exports

```python
# Function::FromTyped — typed lambda → ffi::Function factory (renamed from FromUnpacked)
# Accepts any lambda whose parameter and return types are TypeTraits-registered.
# Generates a packed wrapper: (const AnyView* args, int32_t num_args, Any* rv) -> void
# using details::unpack_call<RetType>(callable, args, num_args, rv).
# Interacts with: details::FunctionInfo<TCallable> (arg type deduction),
#                 TypeTraits<T> (arg unpacking via TryConvertFromAnyView),
#                 Function::Registry::set_body_typed (calls FromTyped internally),
#                 TypedFunction<R(Args...)> constructor (delegates to FromTyped)
# Invariant: callable's arg types must all satisfy TypeTraits<T>::convert_enabled.

class Function:
    @staticmethod
    def FromTyped(callable: TCallable) -> "Function": ...
    # old: Function::FromUnpacked(callable)

    @staticmethod
    def FromTyped(callable: TCallable, name: str) -> "Function": ...
    # old: Function::FromUnpacked(callable, name)

    # FromPacked (manual packed signature) remains unchanged.
```

## Impact
- API: `Function::FromUnpacked` is removed; all callers must use `Function::FromTyped`. This is a breaking rename for any downstream C++ code using `FromUnpacked` directly.
- Behavioral: None — purely mechanical rename, no logic changed.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `Function` / `FunctionObj` factory pattern (`0004-function-system`) — specifically the `FromUnpacked` factory path being renamed.
- `TypeTraits<T>` unpacking machinery (`0008-type-traits`) — unchanged, but all callsites renaming their factory entry point.
- `TypedFunction<R(Args...)>` — delegates to `FromTyped` in constructors and assignment operators.

Design elements this commit produces:
- Updated factory name: `Function::FromTyped` replaces `Function::FromUnpacked` as the canonical typed-lambda factory in `0004-function-system`.

## Usage Examples

Before:
```cpp
Function fadd1 = Function::FromUnpacked([](const int32_t& a) -> int { return a + 1; });
```

After:
```cpp
Function fadd1 = Function::FromTyped([](const int32_t& a) -> int { return a + 1; });
```

The factory semantics are identical — only the name changed.
