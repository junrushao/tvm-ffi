# Rename Function::FromUnpacked to Function::FromTyped and clean up legacy PackedFunc references in comments

## TL;DR
- Renames `Function::FromUnpacked` to `Function::FromTyped` across headers, source, and tests (API-breaking for C++ callers).
- Updates all Doxygen comments replacing legacy names (`PackedFunc`, `PackedFuncObj`, `TVMRetValue`) with modern equivalents (`ffi::Function`, `ffi::FunctionObj`, `ffi::Any`).
- No behavioral change; all function signatures and semantics are preserved.

| Before | After |
|--------|-------|
| `Function::FromUnpacked(callable)` | `Function::FromTyped(callable)` |
| `Function::FromUnpacked(callable, name)` | `Function::FromTyped(callable, name)` |

Doc-comment-only renames:

| Before (comment text) | After (comment text) |
|------------------------|----------------------|
| `PackedFunc` | `ffi::Function` |
| `PackedFuncObj` | `ffi::FunctionObj` |
| `TVMRetValue` | `ffi::Any` |
| `TypedPackedFunc` | "typed function signature" |

## Key Exports

**Renames** (public static method on `Function`):

| Old name | New name | Signature |
|----------|----------|-----------|
| `Function::FromUnpacked<TCallable>(TCallable)` | `Function::FromTyped<TCallable>(TCallable)` | `template<typename TCallable> static Function FromTyped(TCallable callable)` |
| `Function::FromUnpacked<TCallable>(TCallable, std::string)` | `Function::FromTyped<TCallable>(TCallable, std::string)` | `template<typename TCallable> static Function FromTyped(TCallable callable, std::string name)` |

## Impact
- API: **Breaking** -- all C++ call sites using `Function::FromUnpacked` must migrate to `Function::FromTyped`. Affected internally: `TypedFunction` constructors, `Function::Registry::set_body_typed`, `Function::Registry::set_body_method`, `container.cc`, `function.cc`, and 6 test files.
- Behavioral: None -- the function body is unchanged.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `Function` type-erased callable handle (`.knowledge/designs/0004-function-system.md`)
- `TypedFunction<R(Args...)>` compile-time typed wrapper (`.knowledge/designs/0004-function-system.md`)
- `Function::Registry` builder for global function registration (`.knowledge/designs/0004-function-system.md`)
- Packed calling convention (`AnyView[]` + `Any*` return) (`.knowledge/designs/0004-function-system.md`)

Design elements this commit mutates:
- `Function::FromUnpacked` -> `Function::FromTyped`: public static factory method on `Function` that wraps a typed C++ callable into the packed calling convention. The rename better reflects that the input is a "typed" callable being adapted, not that the arguments are being "unpacked" (which is an implementation detail).

## Usage Examples

Before/after for the rename:
```cpp
// Before (no longer compiles after this commit):
Function f = Function::FromUnpacked([](int a, int b) -> int { return a + b; });
Function f2 = Function::FromUnpacked([](int a) -> int { return a + 1; }, "add_one");

// After:
Function f = Function::FromTyped([](int a, int b) -> int { return a + b; });
Function f2 = Function::FromTyped([](int a) -> int { return a + 1; }, "add_one");
```

Callers via `set_body_typed` and `set_body_method` are unaffected (they call `FromTyped` internally now).
