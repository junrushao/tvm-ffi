# Rename Function::FromUnpacked to Function::FromTyped and clean up legacy PackedFunc references
## TL;DR
- Renames `Function::FromUnpacked` to `Function::FromTyped` across all C++ headers, sources, and tests, making the naming symmetric with `Function::FromPacked`.
- Updates Doxygen comments to replace legacy names (`PackedFunc` -> `ffi::Function`, `TVMRetValue` -> `ffi::Any`, `PackedFuncObj` -> `ffi::FunctionObj`, `TypedPackedFunc` -> typed function description).
- Test names updated to match (`TEST(Func, FromUnpacked)` -> `TEST(Func, FromTyped)`, `TEST(Map, PackedFuncGetItem)` -> `TEST(Map, ffi::FunctionGetItem)`, etc.).

### Rename mapping

| Before | After | Location |
|--------|-------|----------|
| `Function::FromUnpacked(callable)` | `Function::FromTyped(callable)` | `include/tvm/ffi/function.h` (declaration + 2 overloads) |
| `Function::FromUnpacked(callable, name)` | `Function::FromTyped(callable, name)` | `include/tvm/ffi/function.h` (named overload) |
| `PackedFunc` (in comments) | `ffi::Function` | `include/tvm/ffi/function.h`, `include/tvm/ffi/function_details.h` |
| `PackedFuncObj` (in comments) | `ffi::FunctionObj` | `include/tvm/ffi/function.h` |
| `TVMRetValue` (in comments) | `ffi::Any` | `include/tvm/ffi/function.h` |
| `TypedPackedFunc` (in comments) | typed function description | `include/tvm/ffi/function_details.h` |
| `FromUnpacked` (in doc example) | `FromTyped` | `include/tvm/ffi/rvalue_ref.h` |

## Impact
- API: `Function::FromUnpacked` is removed; all callers must use `Function::FromTyped`. This is a breaking rename for any downstream C++ code using `FromUnpacked` directly.
- Behavioral: none -- semantics are identical, only the name changed.
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces (mutates):
- **`Function::FromTyped`** (renamed from `Function::FromUnpacked`) -- the public API for wrapping typed C++ callables into packed format. This is the primary construction path used by `set_body_typed`, `TypedFunction` constructors, and direct user code.

## Usage Examples
Before/after showing the rename:
```cpp
// Before (no longer compiles after this commit):
Function f = Function::FromUnpacked([](int a, int b) -> int { return a + b; });

// After:
Function f = Function::FromTyped([](int a, int b) -> int { return a + b; });

// Named variant:
Function f = Function::FromTyped([](int a) -> int { return a + 1; }, "add_one");

// No change to registration macro usage (set_body_typed delegates internally):
TVM_FFI_REGISTER_GLOBAL("MyAdd").set_body_typed([](int a, int b) -> int { return a + b; });
```
