# Rename Function::FromUnpacked to Function::FromTyped across codebase
## TL;DR
- Renames `Function::FromUnpacked` to `Function::FromTyped` in `include/tvm/ffi/function.h` (the two overloads: with and without `name` parameter), and updates all call sites in implementation files (`src/ffi/function.cc`, `src/ffi/container.cc`) and tests.
- Replaces stale references to `PackedFunc`/`PackedFuncObj`/`TVMRetValue` in Doxygen comments with the current names `ffi::Function`/`ffi::FunctionObj`/`ffi::Any`.
- No functional change: the method signature, body, and behavior are identical; this is a pure rename + doc comment cleanup.

## Impact
- API: **rename only**. `Function::FromUnpacked` no longer exists; all callers must use `Function::FromTyped`. Downstream C++ code that calls `FromUnpacked` will fail to compile until updated. The method remains in the same header (`include/tvm/ffi/function.h`) with the same template signature and semantics.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit **consumes**:
- **Function System** ([`.knowledge/designs/0004-function-system.md`](../designs/0004-function-system.md)): The renamed method is `Function::FromTyped` (formerly `FromUnpacked`), which wraps a typed C++ callable into the packed calling convention `(const AnyView*, int32_t, Any*)`. The internal mechanism is unchanged: `FunctionInfo<TCallable>` extracts the function signature, then `unpack_call` generates a lambda that converts packed `AnyView` arguments to typed parameters.
- **Function::Registry** ([`.knowledge/designs/0004-function-system.md`](../designs/0004-function-system.md)): `Registry::set_body_typed` and `Registry::set_body_method` both delegate to `Function::FromTyped` (6 call sites updated in `function.h`).
- **Containers** ([`.knowledge/designs/0005-containers.md`](../designs/0005-containers.md)): `src/ffi/container.cc` updates one call site where `MapForwardIterFunctor` is wrapped via `FromTyped`.
- **RValueRef** (`include/tvm/ffi/rvalue_ref.h`): Documentation example updated to use `FromTyped`.

Design elements this commit **produces**:
- **`Function::FromTyped` naming convention**: Establishes `FromTyped` as the canonical name for converting typed C++ callables to `ffi::Function`. The old name `FromUnpacked` was a legacy carryover from the pre-unification era when the system distinguished "packed" (type-erased) and "unpacked" (typed) calling conventions. The new name `FromTyped` more clearly expresses intent: "create a Function from a typed callable."
- **Comment modernization**: Replaces all remaining `PackedFunc`/`PackedFuncObj`/`TVMRetValue` references in `function.h` with `ffi::Function`/`ffi::FunctionObj`/`ffi::Any`, completing the naming alignment with the unified object system established in [`.knowledge/ADRs/0001-unified-packed-and-object.md`](../ADRs/0001-unified-packed-and-object.md).
