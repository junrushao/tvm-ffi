# Add string-level wrappers for JSON graph serialization API (ToJSONGraphString / FromJSONGraphString)

## TL;DR
- Adds two new C++ functions `ToJSONGraphString(Any, Any) -> String` and `FromJSONGraphString(String) -> Any` as thin wrappers around `ToJSONGraph`/`FromJSONGraph` + `json::Stringify`/`json::Parse`.
- Registers all four JSON graph functions (`ffi.ToJSONGraph`, `ffi.ToJSONGraphString`, `ffi.FromJSONGraph`, `ffi.FromJSONGraphString`) in the global function registry via `refl::GlobalDef()` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- The commit message describes the broader strategic goal ("phase out getattr based attribute handling"), but the diff is narrowly scoped: this string API is a prerequisite that allows Python callers to round-trip objects through a string without going through the `json::Value` intermediate type (which required getattr-style field access).

## Impact
- API: Two new global functions `ffi.ToJSONGraphString` and `ffi.FromJSONGraphString` are added to the global registry. No existing function signatures changed.
- Behavioral: None — the existing `ffi.ToJSONGraph`/`ffi.FromJSONGraph` behavior is unchanged.
- Flags/config: None.
- Data formats/schemas: None — the JSON graph schema is unchanged; `ToJSONGraphString` produces the same JSON as `json::Stringify(ToJSONGraph(...))`.

## Design Elements
Design elements this commit consumes:
- **Global function registry** (`0004-function-system`): uses `refl::GlobalDef().def(name, fn)` inside `TVM_FFI_STATIC_INIT_BLOCK` to register the new functions — the canonical registration idiom.
- **`json::Parse` / `json::Stringify`** (`include/tvm/ffi/extra/json.h`): thin wrappers delegate to these for string↔json::Value conversion.
- **`ToJSONGraph` / `FromJSONGraph`** (`src/ffi/extra/serialization.cc`, introduced in `8eaefe0`): the underlying json::Value-level API being wrapped.
- **`EnsureTypeAttrColumn`** (`0006-reflection`): pre-allocates `"__data_to_json__"` and `"__data_from_json__"` columns (retained from prior commit, unchanged here).

Design elements this commit produces:
- **`ffi.ToJSONGraphString` global function**: new string-level serialization entry point callable from any language via the packed-function ABI.
- **`ffi.FromJSONGraphString` global function**: new string-level deserialization entry point callable from any language via the packed-function ABI.

## Usage Examples

Cross-layer call trace (C++ definition → packed-function ABI → Python call):

```cpp
// C++ (src/ffi/extra/serialization.cc) — defined and registered:
String ToJSONGraphString(const Any& value, const Any& metadata) {
  return json::Stringify(ToJSONGraph(value, metadata));
}
Any FromJSONGraphString(const String& value) {
  return FromJSONGraph(json::Parse(value));
}
// Registered as "ffi.ToJSONGraphString" and "ffi.FromJSONGraphString"
```

```python
# Python (hypothetical caller after phasing out getattr-based paths):
import tvm_ffi
```
