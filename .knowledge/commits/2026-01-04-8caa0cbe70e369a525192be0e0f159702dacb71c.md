# Introduce tvm/ffi/tvm_ffi.h umbrella header for core C++ APIs
## TL;DR
- Adds `<tvm/ffi/tvm_ffi.h>` as an umbrella header including all core TVM-FFI C++ headers (excluding `tvm/ffi/extra/`), analogous to `nanobind/nanobind.h` or `pybind11/pybind11.h`.
- Updates docs and examples to use the single include.

## Key Exports

**`<tvm/ffi/tvm_ffi.h>`** -- umbrella header including: `any.h`, `c_api.h`, `cast.h`, `container/*.h` (array, map, shape, tensor, tuple, variant), `dtype.h`, `error.h`, `function.h`, `memory.h`, `object.h`, `optional.h`, `reflection/*.h` (access_path, accessor, creator, overload, registry), `rvalue_ref.h`, `string.h`, `type_traits.h`, and supporting detail headers.

## Impact
- API: New convenience header. No behavioral change.
- Behavioral: None
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes: All core C++ API headers.

Design elements this commit produces:
- **Umbrella header** (`tvm/ffi/tvm_ffi.h`): Single-include entry point for extension writers.

## Usage Examples
```cpp
#include <tvm/ffi/tvm_ffi.h>
// All core TVM-FFI APIs available
```
