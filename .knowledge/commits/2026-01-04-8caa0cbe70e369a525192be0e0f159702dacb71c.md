# Introduce <tvm/ffi/tvm_ffi.h> umbrella header
## TL;DR
- Adds `tvm/ffi/tvm_ffi.h` as a single-include umbrella header that pulls in all core C++ APIs.
- Updates quickstart docs and examples to use the umbrella header.
- Simplifies the getting-started experience for C++ users.

## Key Exports

**C++ Header:**
- `#include <tvm/ffi/tvm_ffi.h>` -- Umbrella header including any.h, function.h, all containers, string.h, error.h, memory.h, object.h, optional.h, type_traits.h.
