# Introduce umbrella header `<tvm/ffi/tvm_ffi.h>` aggregating all core C++ APIs
## TL;DR
- Adds `include/tvm/ffi/tvm_ffi.h`, a single umbrella header that includes all core TVM-FFI C++ headers (any, object, function, containers, reflection, etc.), excluding `tvm/ffi/extra/`.
- Updates all quickstart examples and the packaging example to use `#include <tvm/ffi/tvm_ffi.h>` instead of individual header includes.
- Updates quickstart and packaging docs to recommend the umbrella header as the primary entry point, analogous to `nanobind/nanobind.h` and `pybind11/pybind11.h`.

## Key Exports

```python
# --- Umbrella header (include/tvm/ffi/tvm_ffi.h) ---
# A single #include that transitively provides all core TVM-FFI C++ APIs.
# Excludes tvm/ffi/extra/ headers (module loading, c_env_api, cuda utilities).
#
# Aggregates:
#   tvm/ffi/any.h, tvm/ffi/base_details.h, tvm/ffi/c_api.h, tvm/ffi/cast.h,
#   tvm/ffi/container/{array,container_details,map,shape,tensor,tuple,variant}.h,
#   tvm/ffi/dtype.h, tvm/ffi/endian.h, tvm/ffi/error.h,
#   tvm/ffi/function.h, tvm/ffi/function_details.h,
#   tvm/ffi/memory.h, tvm/ffi/object.h, tvm/ffi/optional.h,
#   tvm/ffi/reflection/{access_path,accessor,creator,overload,registry}.h,
#   tvm/ffi/rvalue_ref.h, tvm/ffi/string.h, tvm/ffi/type_traits.h
#
# Interacts with: every core TVM-FFI C++ API (by transitive inclusion)
# Invariant: must NOT include tvm/ffi/extra/* headers (those require additional deps)
# Extension: when new core headers are added, they should be added to this umbrella
```

## Impact
- API: None -- purely additive. All individual headers remain valid includes; existing code is unaffected.
- Behavioral: None -- no runtime behavior changes.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- All core C++ headers under `include/tvm/ffi/` (the umbrella simply re-exports them). See `.knowledge/designs/0002-object-system.md`, `.knowledge/designs/0003-any-system.md`, `.knowledge/designs/0004-function-system.md`, `.knowledge/designs/0007-containers.md`, `.knowledge/designs/0008-reflection.md`.
- Extension packaging pattern (`examples/python_packaging/`). See `.knowledge/designs/0013-packaging.md`.

Design elements this commit produces:
- **Umbrella header convention**: `<tvm/ffi/tvm_ffi.h>` as the recommended single include for downstream C++ consumers. Analogous to `nanobind/nanobind.h` and `pybind11/pybind11.h`.

## Usage Examples
Before (multiple individual includes):
```cpp
#include <tvm/ffi/function.h>
#include <tvm/ffi/object.h>
#include <tvm/ffi/reflection/registry.h>
```

After (single umbrella include):
```cpp
#include <tvm/ffi/tvm_ffi.h>
```

Both forms remain valid. The umbrella header is the new recommended entry point for extension authors who need access to the full core API surface.
