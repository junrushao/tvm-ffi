# feat: Introduce <tvm/ffi/tvm_ffi.h> umbrella header aggregating all core TVM-FFI C++ APIs

## TL;DR
- New `include/tvm/ffi/tvm_ffi.h` (58 lines): single-include umbrella header aggregating all core TVM-FFI headers (any, base_details, c_api, cast, containers, dtype, error, function, memory, object, optional, reflection, string, type_traits) except `tvm/ffi/extra/`
- Updated `docs/get_started/quickstart.rst`, example `pyproject.toml`, and example source files to use `#include <tvm/ffi/tvm_ffi.h>`

## Key Exports

```python
# include/tvm/ffi/tvm_ffi.h — umbrella header
# Includes: any.h, base_details.h, c_api.h, cast.h, container/array.h,
#   container/container_details.h, container/map.h, container/shape.h,
#   container/tensor.h, container/tuple.h, container/variant.h, dtype.h,
#   endian.h, error.h, function.h, function_details.h, memory.h, object.h,
#   optional.h, reflection/access_path.h, reflection/accessor.h,
#   reflection/creator.h, reflection/overload.h, reflection/registry.h,
#   rvalue_ref.h, string.h, type_traits.h
# Does NOT include: tvm/ffi/extra/ (platform-specific extensions)
# Interacts with: all core API consumers
```

## Impact
- API: Additive — `<tvm/ffi/tvm_ffi.h>` is a new convenience header; no existing includes broken
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none
