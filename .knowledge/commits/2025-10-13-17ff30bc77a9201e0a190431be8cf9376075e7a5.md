# Add sphinx-autodoc-typehints plugin and remove redundant type annotations from docstrings
## TL;DR
- Adds the `sphinx-autodoc-typehints` Sphinx extension so that parameter and return types are auto-extracted from Python function signatures, following DRY principles.
- Configures several related Sphinx/Napoleon options (`autodoc_preserve_defaults`, `typehints_defaults`, `always_document_param_types`, `napoleon_use_rtype`).
- Removes redundant `: type` annotations from NumPy-style docstring parameter/return sections across 14 Python source files in `python/tvm_ffi/`, leaving only the parameter name and description.
