# Add sphinx-autodoc-typehints to auto-extract type annotations from function definitions
## TL;DR
- Adds `sphinx-autodoc-typehints` Sphinx extension to `docs/conf.py` and `pyproject.toml` (docs dependency group) so Sphinx auto-extracts type annotations from Python function signatures into rendered documentation.
- Removes redundant `: TypeName` type labels from all `Parameters` and `Returns` docstring sections across 14 Python source files in `python/tvm_ffi/`, applying DRY — types are now declared once (in the Python type annotation) rather than repeated in the docstring.
- No functional code changes; purely a documentation infrastructure and docstring cleanup.

- Behavioral: none — changes are documentation-only.
