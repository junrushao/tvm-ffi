# Fix PyTorch Tensor API call in DLPack interop: ndim() -> dim()
## TL;DR
- Fixes incorrect PyTorch `Tensor.ndim()` method call to the correct `Tensor.dim()` in the embedded C++ source for the torch C DLPack extension (`_optional_torch_c_dlpack.py`).
