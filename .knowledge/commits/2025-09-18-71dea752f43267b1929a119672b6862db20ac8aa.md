# Fix PyTorch API call from ndim() to dim() in DLPack C extension source
## TL;DR
- Fixed a one-line bug in the embedded PyTorch C++ source within `_optional_torch_c_dlpack.py`: changed `src.ndim()` to `src.dim()` to match the PyTorch `at::Tensor` API.

## Key Exports
None

## Impact
- API: none
- ABI: none
- Behavioral: Fixes stride normalization check for 1-element 1D PyTorch tensors. Before this fix, `ndim()` would fail to compile or resolve against the PyTorch `at::Tensor` API (which exposes `dim()`, not `ndim()`). The stride normalization guard (`need_normalize_strides`) now correctly evaluates for tensors where `dim() == 1 && size(0) == 1 && stride(0) != 1`.
- Flags/config: none
- Data formats/schemas: none
