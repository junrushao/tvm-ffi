# fix: Add negative index bounds check in ArrayObj operator[] and SetItem

## TL;DR
- `ArrayObj::operator[](i)` and `ArrayObj::SetItem(i, item)` previously only checked `i >= size_` (missing negative index check); now also checks `i < 0`
- Added 31 C++ test cases for negative index edge cases

## Key Exports

```python
class ArrayObj:
    def __getitem__(self, i: int) -> Any:
        # Invariant: 0 <= i < size_; throws IndexError if i < 0 OR i >= size_
        # Interacts with: TVM_FFI_THROW(IndexError)
    def SetItem(self, i: int, item: Any) -> None:
        # Same invariant as __getitem__
```

## Impact
- API: Behavioral change — negative indices to `ArrayObj::operator[]` now throw `IndexError` instead of causing UB; Python `Array.__getitem__` with negative indices already handled Python-side (converted to positive before reaching C++)
- Behavioral: Previously `array[-1]` in C++ would silently access invalid memory; now throws
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cpp
// Before fix: UB for negative index
```
