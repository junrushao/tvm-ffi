# Add negative index bounds check in ArrayObj
## TL;DR
- Adds `i < 0` check to `ArrayObj::operator[]` and `ArrayObj::SetItem` to reject negative indices with IndexError.
- Previously negative indices caused undefined behavior by accessing memory before the array data.
