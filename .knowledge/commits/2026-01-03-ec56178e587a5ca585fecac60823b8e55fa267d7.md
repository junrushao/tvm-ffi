# Add negative index bounds check to ArrayObj::operator[] and ArrayObj::SetItem

## TL;DR
- `ArrayObj::operator[]` and `ArrayObj::SetItem` only checked `i >= size_`, missing `i < 0`, which allowed negative indices to cause undefined behavior (out-of-bounds memory access).
- Fix adds `i < 0 ||` to both bounds checks, throwing `IndexError` for negative indices.
- The `Array<T>` wrapper class already handled negative indices at the Python/template level; this fix closes the gap at the `ArrayObj` (C++ object) layer.

## Key Exports

```python
class ArrayObj(Object):
    """Immutable array backed by contiguous Any elements."""
    # Changed methods:

    def __getitem__(self, i: int64) -> Any:
        # OLD: if i >= size_: raise IndexError
        # NEW: if i < 0 or i >= size_: raise IndexError
        ...
    # Invariant: i must be in [0, size_). Negative indices are NOT auto-wrapped; they raise IndexError.
    # Interacts with: Array<T> wrapper (which may normalize negative indices before delegating)

    def SetItem(self, i: int64, item: Any) -> None:
        # OLD: if i >= size_: raise IndexError
        # NEW: if i < 0 or i >= size_: raise IndexError
        ...
    # Invariant: i must be in [0, size_). Negative indices raise IndexError.
```

## Impact
- API: none -- only behavioral tightening of existing bounds check
- Behavioral: negative index values now raise `IndexError` instead of causing undefined behavior (silent out-of-bounds read/write). This is a correctness fix, not a breaking change, since the prior behavior was UB.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**Before (buggy):** Negative index silently accessed memory before the array data pointer.
```cpp
Array<int> arr = {1, 2, 3};
ArrayObj* obj = arr.GetArrayObj();
// BUG: no bounds check for negative index, UB
const Any& val = obj->at(-1);  // silent out-of-bounds read
obj->SetItem(-1, Any(42));     // silent out-of-bounds write
```

**After (fixed):** Negative index properly raises IndexError.
```cpp
Array<int> arr = {1, 2, 3};
ArrayObj* obj = arr.GetArrayObj();
// FIXED: throws IndexError for negative index
try {
  const Any& val = obj->at(-1);
} catch (const Error& e) {
  // e.kind() == "IndexError"
  // e.message() contains "Index -1 out of bounds 3"
}
```
