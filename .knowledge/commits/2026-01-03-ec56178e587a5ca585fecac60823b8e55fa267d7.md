# Fix missing negative index bounds check in ArrayObj::operator[] and SetItem
## TL;DR
- Adds `i < 0` check to `ArrayObj::operator[]` and `ArrayObj::SetItem` bounds validation, fixing UB when accessing with negative indices.

**Invariant violated**: Negative indices bypassed the bounds check (only `i >= size_` was tested).
**Invariant restored**: Both methods now check `i < 0 || i >= size_`.
