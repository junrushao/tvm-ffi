# Fix missing int8 dtype mapping for torch<2.6.0 in getDLDataTypeForDLPackv1

## TL;DR
- The preprocessor guard `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6` was logically incorrect — it fails for torch 3.x (major>2) and also incorrectly placed `ScalarType::Char` (int8) inside the guard, making int8 unavailable on torch<2.6.
- Fixed to `(TORCH_VERSION_MAJOR > 2) || (TORCH_VERSION_MAJOR == 2 && TORCH_VERSION_MINOR >= 6)`.
- `ScalarType::Char` moved outside the version guard into the unconditional `kDLInt` case group; `Short`, `Float`, `Double` cases consolidated into grouped fallthrough chains.

## Key Exports

```python
# Embedded C++ in _build_optional_torch_c_dlpack.py (getDLDataTypeForDLPackv1 function)
# Before (broken):
#   #if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6
#     case ScalarType::Int1: ... case ScalarType::Int7:
#     case ScalarType::Char:          # <-- BUG: int8 absent on torch<2.6
#       dtype.code = kDLInt; break;
#   #endif
#   case ScalarType::Int: ... kDLInt
#   case ScalarType::Short: ... kDLInt (separate block)
#   case ScalarType::Double: ... kDLFloat (separate block)
#   case ScalarType::Float: ... kDLFloat (separate block)
#
# After (fixed):
#   #if (TORCH_VERSION_MAJOR > 2) || (TORCH_VERSION_MAJOR == 2 && TORCH_VERSION_MINOR >= 6)
#     case ScalarType::Int1: ... case ScalarType::Int7:
#   #endif
#   case ScalarType::Char:  # always present
#   case ScalarType::Short:
#   case ScalarType::Int:
#   case ScalarType::Long:
#     dtype.code = kDLInt; break;
#   case ScalarType::Half:
#   case ScalarType::Float:
#   case ScalarType::Double:
#     dtype.code = kDLFloat; break;
#
# Invariant: ScalarType::Char (int8) must always map to kDLInt regardless of torch version.
# Invariant: Version guard is for sub-byte int types (Int1–Int7), not standard int8.
# Interacts with: DLPackExchangeAPI, toDLPack/fromDLPack bridge, libtorch_c_dlpack_addon.so
```

## Usage Examples

Before (incorrect behavior on torch<2.6.0):
```python
# With torch==2.5.x:
import torch, tvm_ffi
t = torch.tensor([1, 2, 3], dtype=torch.int8)
# Attempting DLPack conversion would silently fail or produce incorrect dtype
# because ScalarType::Char was inside the #if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6
# guard, and the guard evaluates false for 2.5 (minor 5 < 6).
```

After (correct behavior):
```python
# With torch==2.5.x:
import torch, tvm_ffi
t = torch.tensor([1, 2, 3], dtype=torch.int8)
# ScalarType::Char is now in the unconditional branch, always maps to kDLInt.
# DLPack exchange works correctly for int8 on all torch versions.
```
