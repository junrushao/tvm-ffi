# Refactor tensor allocator API to align with DLPack naming and add TVMFFIEnvTensorAlloc
## TL;DR
- Renames `TVMFFIEnvSetTensorAllocator` -> `TVMFFIEnvSetDLPackManagedTensorAllocator` and `TVMFFIEnvGetTensorAllocator` -> `TVMFFIEnvGetDLPackManagedTensorAllocator` to match DLPack standard naming.
- Introduces `TVMFFIEnvTensorAlloc(prototype, out)` C API for direct tensor allocation from a DLTensor prototype, simplifying DSL compiler integration.
- Simplifies `Tensor::FromDLPackAlloc` by removing the old metadata allocation path. Version bump to 0.1.0b19.

## Impact
- API: Breaking rename of allocator getter/setter C APIs. New `TVMFFIEnvTensorAlloc` C API.
- Flags/config: Version bump.
- Data formats/schemas: None.
