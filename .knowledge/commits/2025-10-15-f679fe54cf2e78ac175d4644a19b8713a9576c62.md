# Refactor tensor allocator C API to align with DLPack naming and introduce TVMFFIEnvTensorAlloc
## TL;DR
- Renames `TVMFFIEnvSetTensorAllocator` -> `TVMFFIEnvSetDLPackManagedTensorAllocator` and `TVMFFIEnvGetTensorAllocator` -> `TVMFFIEnvGetDLPackManagedTensorAllocator` to align with DLPack naming standard.
- Replaces `Tensor::FromDLPackAlloc` with `Tensor::FromEnvAlloc`, which takes a simpler function pointer `int (*)(DLTensor*, TVMFFIObjectHandle*)` instead of the full `DLPackManagedTensorAllocator` callback.
- Introduces `TVMFFIEnvTensorAlloc` as a new C env API function that encapsulates the DLPack allocator invocation, error handling, and TensorObj wrapping -- moving this logic from the header-only `Tensor::FromDLPackAlloc` into `libtvm_ffi` to avoid module unloading order problems.

| Old name | New name |
|----------|----------|
| `TVMFFIEnvSetTensorAllocator` | `TVMFFIEnvSetDLPackManagedTensorAllocator` |
| `TVMFFIEnvGetTensorAllocator` | `TVMFFIEnvGetDLPackManagedTensorAllocator` |
| `Tensor::FromDLPackAlloc` | `Tensor::FromEnvAlloc` |
| (new) | `TVMFFIEnvTensorAlloc` |

## Key Exports

```python
# --- C Env API: include/tvm/ffi/extra/c_env_api.h ---

# Renamed: was TVMFFIEnvSetTensorAllocator
def TVMFFIEnvSetDLPackManagedTensorAllocator(
    allocator: DLPackManagedTensorAllocator,
    write_to_global_context: int,
    opt_out_original_allocator: Ptr[DLPackManagedTensorAllocator],
) -> int: ...
    # Interacts with: EnvContext.SetDLPackManagedTensorAllocator()
    # Invariant: TLS allocator takes priority over global; global is fallback

# Renamed: was TVMFFIEnvGetTensorAllocator
def TVMFFIEnvGetDLPackManagedTensorAllocator() -> DLPackManagedTensorAllocator: ...
    # Interacts with: EnvContext.GetDLPackManagedTensorAllocator()

# NEW: high-level tensor allocation through env context
def TVMFFIEnvTensorAlloc(prototype: Ptr[DLTensor], out: Ptr[TVMFFIObjectHandle]) -> int: ...
    # Interacts with: TVMFFIEnvGetDLPackManagedTensorAllocator() (fetches allocator from TLS/global)
    # Interacts with: TensorObjFromDLPack (wraps allocated DLManagedTensorVersioned into TensorObj)
    # Invariant: allocator must have been set via TVMFFIEnvSetDLPackManagedTensorAllocator
    #            Returns -1 with TVMFFIErrorSetRaisedFromCStr("RuntimeError", ...) if nullptr
    # Invariant: prototype.dtype, prototype.ndim, prototype.shape, prototype.device used;
    #            other fields ignored (data, strides, byte_offset)
    # Invariant: error from underlying DLPackManagedTensorAllocator propagated via
    #            TVMFFIEnvTensorAllocSetError -> TVMFFIErrorSetRaisedFromCStr
    # Extension: future allocator backends can be added by extending the allocator dispatch

# --- C++ API: include/tvm/ffi/container/tensor.h ---

class Tensor(ObjectRef):
    # Renamed: was FromDLPackAlloc. Signature simplified.
    @staticmethod
    def FromEnvAlloc(
        env_alloc: Callable[[Ptr[DLTensor], Ptr[TVMFFIObjectHandle]], int],
        shape: ShapeView, dtype: DLDataType, device: DLDevice,
    ) -> Tensor: ...
        # Interacts with: TVMFFIEnvTensorAlloc (canonical env_alloc argument)
        # Interacts with: TVM_FFI_CHECK_SAFE_CALL (error propagation)
        # Interacts with: ObjectUnsafe.ObjectPtrFromOwned (unwrap TVMFFIObjectHandle -> Tensor)
        # Invariant: env_alloc must return 0 on success, nonzero on failure
        # Extension: pass any function matching the signature, not just TVMFFIEnvTensorAlloc
```

## Impact
- API: Breaking rename of 3 public C/C++ symbols. All callers of `TVMFFIEnvSetTensorAllocator`, `TVMFFIEnvGetTensorAllocator`, and `Tensor::FromDLPackAlloc` must update. Affected layers: C++ (`tensor.h`, `c_env_api.h`), Python/Cython (`tvm_ffi_python_helpers.h`), Rust (`c_env_api.rs`), inline C++ in Python tests (`test_load_inline.py`).
- Behavioral: `Tensor::FromEnvAlloc` no longer handles DLPack wrapping internally -- that logic moved into `TVMFFIEnvTensorAlloc` inside `libtvm_ffi`. This means metadata allocation happens in the shared library, avoiding module unloading order issues where a DSO's allocator callback outlives the DSO itself.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **DLPackManagedTensorAllocator** typedef (`c_api.h`) -- the underlying allocator callback type is unchanged, only the env API names wrapping it changed.
- **EnvContext** TLS context (`src/ffi/extra/env_context.cc`) -- the internal `SetDLPackManagedTensorAllocator`/`GetDLPackManagedTensorAllocator` methods are unchanged. See [0011-ffi-module-system](../design-records/0011-ffi-module-system.md).
- **TensorObjFromDLPack** internal template (`tensor.h`) -- reused in `TVMFFIEnvTensorAlloc` to wrap allocated `DLManagedTensorVersioned` into `TensorObj`.
- **TVM_FFI_SAFE_CALL/TVM_FFI_CHECK_SAFE_CALL** error macros. See [0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md).
- **ObjectUnsafe** (`object.h`) -- `ObjectPtrFromOwned` and `MoveObjectPtrToTVMFFIObjectPtr` used to convert between `TVMFFIObjectHandle` and typed C++ refs.

Design elements this commit produces:
- **TVMFFIEnvTensorAlloc** -- new C env API function that centralizes tensor allocation from env context. This is the canonical way for DSL compilers to allocate output tensors.
- **Tensor::FromEnvAlloc** -- simplified C++ factory that takes a generic `int (*)(DLTensor*, TVMFFIObjectHandle*)` function pointer instead of the DLPack-specific allocator. The function pointer indirection maintains explicit dependency on `extra/c_env_api.h`.

## Usage Examples

Allocating a tensor via the environment allocator (C++ kernel library):
```cpp
#include <tvm/ffi/container/tensor.h>
#include <tvm/ffi/extra/c_env_api.h>

ffi::Tensor allocate_output(ffi::TensorView x) {
  DLDataType f32_dtype{kDLFloat, 32, 1};
  // TVMFFIEnvTensorAlloc is passed as function pointer (explicit dep on c_env_api.h)
  return ffi::Tensor::FromEnvAlloc(
    TVMFFIEnvTensorAlloc, ffi::Shape({x.size(0)}), f32_dtype, x.device());
}
```

Before/after calling pattern:
```cpp
// BEFORE (removed):
ffi::Tensor y = ffi::Tensor::FromDLPackAlloc(
    TVMFFIEnvGetTensorAllocator(), shape, dtype, device);

// AFTER:
ffi::Tensor y = ffi::Tensor::FromEnvAlloc(
    TVMFFIEnvTensorAlloc, shape, dtype, device);
```
