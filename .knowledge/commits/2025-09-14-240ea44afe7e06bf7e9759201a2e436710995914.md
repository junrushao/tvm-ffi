# Add compiler integration guide documenting FFI ABI conventions for kernel and graph compilers

## TL;DR
- New `docs/guides/compiler_integration.md` documenting how kernel language compilers, graph compilers, and custom modules integrate with the TVM FFI ABI.
- Improved Doxygen on `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro: removed stale examples, added `\note` clarifying the `__tvm_ffi_<ExportName>` symbol naming.
- Minor comment clarification in `library_module.cc` binary layout documentation and a lint message path fix.

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro — documented as the primary mechanism for kernel compilers to expose C++ host functions (design record `0013-ffi-packaging-and-distribution`)
- `__tvm_ffi_` symbol prefix — now explicitly noted in Doxygen and guide as the ABI convention (design record `0011-ffi-module-system`)
- `ModuleObj` / `Module` subclassing — guide documents `kind`, `GetPropertyMask`, `GetFunction`, `SaveToBytes` virtual interface (design record `0011-ffi-module-system`)
- `__tvm_ffi__library_bin` binary layout — guide documents the CSR import-tree + key/val serialization format (design record `0011-ffi-module-system`)
- `TVMFFIEnvGetStream` — guide shows stream acquisition for device-synchronized kernel execution (design record `0011-ffi-module-system`)
- `TVMFFIErrorSetRaisedFromCStr` — guide documents error propagation pattern in C codegen (design record `0005-ffi-error-protocol`)
- `load_module` / `ffi.Module.load_from_bytes.<kind>` — guide documents Python-side loading flow (design record `0011-ffi-module-system`)

## Usage Examples
The guide itself serves as the usage example. Key C code pattern for kernel compiler integration (`docs/guides/compiler_integration.md`):

```c
#include <tvm/ffi/c_api.h>
#include <tvm/ffi/extra/c_env_api.h>

int __tvm_ffi_add_one(
  void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
) {
  DLTensor *a, *b, *c;
  if (ReadDLTensorPtr(&args[0], &a) == -1) return -1;
  if (ReadDLTensorPtr(&args[1], &b) == -1) return -1;
  if (ReadDLTensorPtr(&args[2], &c) == -1) return -1;
  void* stream = TVMFFIEnvGetStream(a->device.device_type, a->device.device_id);
  // ... computation ...
  return 0;
}
```
