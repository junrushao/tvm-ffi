# Add compiler integration guide covering kernel DSL, graph compiler, and custom module patterns

## TL;DR
- Adds `docs/guides/compiler_integration.md` (140 lines) documenting three integration patterns: kernel language compilers (symbol ABI), graph compilers (call_tvm_ffi + module API), and custom `ModuleObj` subclassing with binary serialization.
- Fixes a doc comment in `include/tvm/ffi/function.h` adding a `\note` that `TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Fn)` produces the symbol `__tvm_ffi_<ExportName>`, removing outdated "compilation error" warnings.
- Clarifies `__tvm_ffi__library_bin` binary layout comment in `src/ffi/extra/library_module.cc` to mark `val` as optional (`[val0: bytes]`) and explain its content for custom modules.

## Usage Examples

Context: the guide provides a C code snippet showing the minimum an external code generator needs to emit to be FFI-compatible (`__tvm_ffi_add_one` function), demonstrating the `__tvm_ffi_` symbol prefix, `TVMFFIEnvGetStream` for device streams, and `TVMFFIErrorSetRaisedFromCStr` for error propagation. This is the most authoritative example of the C ABI from a consumer perspective.

```c
// From docs/guides/compiler_integration.md — minimum FFI-compliant kernel symbol
int __tvm_ffi_add_one(
  void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
) {
  DLTensor *a, *b, *c;
  ReadDLTensorPtr(&args[0], &a);  // kTVMFFIDLTensorPtr or kTVMFFITensor
  ReadDLTensorPtr(&args[1], &b);
  ReadDLTensorPtr(&args[2], &c);
  void* stream = TVMFFIEnvGetStream(a->device.device_type, a->device.device_id);
  // ... computation on a, b -> c ...
  return 0;  // -1 + TVMFFIErrorSetRaisedFromCStr on error
}
```

Context: custom `ModuleObj` subclass protocol (pseudocode from guide):

```python
class MyCustomModuleObj(ModuleObj):
    kind: str = "my_custom"
    # Override GetPropertyMask → kRunnable | kBinarySerializable
    # Override GetFunction(name) → ffi::Function
    # Override SaveToBytes() → bytes
    # Register: GlobalDef().def("ffi.Module.load_from_bytes.my_custom", load_fn)
```
