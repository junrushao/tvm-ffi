# Add compiler integration guide documenting FFI ABI conventions for kernel and graph compilers
## TL;DR
- New guide `docs/guides/compiler_integration.md` documenting how kernel language compilers (Triton, TileLang, Mojo, etc.) and graph compilers integrate with TVM FFI via the `__tvm_ffi_` symbol prefix convention, `TVM_FFI_DLL_EXPORT_TYPED_FUNC`, and the `__tvm_ffi__library_bin` embedded binary format.
- Improved `TVM_FFI_DLL_EXPORT_TYPED_FUNC` Doxygen in `function.h`: clarified it exports a "SafeCallType symbol that follows the FFI ABI" and added a `\note` documenting the final symbol name `__tvm_ffi_<ExportName>`.
- Minor comment fixes in `library_module.cc` (binary layout brackets) and `check_asf_header.py` (full script path in error message).

## Design Elements
Design elements this commit consumes:
- **C ABI calling convention** ([0001-c-abi-layer](../.knowledge/designs/0001-c-abi-layer.md)): The guide's C code example uses `TVMFFIAny`, `TVMFFISafeCallType` signature (`void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result`), and `TVMFFIErrorSetRaisedFromCStr` for error propagation.
- **`__tvm_ffi_` symbol prefix convention** ([0013-module-system](../.knowledge/designs/0013-module-system.md)): The guide formalizes the two-tier symbol namespace (`__tvm_ffi_<name>` for user exports, `__tvm_ffi__<name>` for internal symbols) as the integration contract for external compilers.
- **`TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro** ([0004-function-system](../.knowledge/designs/0004-function-system.md)): Documented as the primary mechanism for C++ host code generators to expose FFI-compatible symbols.
- **`TVMFFIEnvGetStream`** ([0013-env-api-naming-convention](../.knowledge/ADRs/0013-env-api-naming-convention.md)): Referenced in the guide's C code example for device stream acquisition.
- **`ModuleObj` interface and custom module workflow** ([0013-module-system](../.knowledge/designs/0013-module-system.md)): The "Advanced: Custom Modules" section documents `kind()`, `GetPropertyMask()`, `GetFunction()`, `SaveToBytes()`, and `ffi.Module.load_from_bytes.<kind>` registration.
- **`__tvm_ffi__library_bin` binary embedded format** ([0013-module-system](../.knowledge/designs/0013-module-system.md)): The guide documents the CSR import tree + serialized sub-module binary layout for compiler authors to emit.

```c
// FFI function implementing add_one operation
int __tvm_ffi_add_one(
  void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
) {
  DLTensor *a, *b, *c;
  if (ReadDLTensorPtr(&args[0], &a) == -1) return -1;
  if (ReadDLTensorPtr(&args[1], &b) == -1) return -1;
  if (ReadDLTensorPtr(&args[2], &c) == -1) return -1;
  void* stream = TVMFFIEnvGetStream(a->device.device_type, a->device.device_id);
  // computation here
  return 0;
}
```
