## Design Elements
Design elements this commit consumes:
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro (0003-function-system) -- documented as the primary export mechanism for kernel compilers generating C++ host code
- `__tvm_ffi_` symbol prefix (0003, 0011) -- documented as the required ABI convention for exported function symbols
- `TVMFFIEnvGetStream` (0011-module-system) -- documented for CUDA/device stream retrieval in generated kernel functions
- `TVMFFIErrorSetRaisedFromCStr` (0004-error-propagation) -- used in the C code example for error reporting
- `ModuleObj` interface and `GetFunction`/`GetPropertyMask`/`SaveToBytes` (0011-module-system) -- documented for custom module subclassing
- `__tvm_ffi__library_bin` binary format (0011-module-system) -- documented with byte-level layout for module serialization/export
- `c_api.h` and `extra/c_env_api.h` headers (0007-c-abi) -- referenced in code examples

Design elements this commit produces: None -- purely documents existing patterns.

## Usage Examples

```c
// Kernel compiler integration: export a function following the FFI ABI
#include <tvm/ffi/c_api.h>
#include <tvm/ffi/extra/c_env_api.h>

int __tvm_ffi_add_one(
  void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
) {
  DLTensor *a, *b, *c;
  if (ReadDLTensorPtr(&args[0], &a) == -1) return -1;
  void* stream = TVMFFIEnvGetStream(a->device.device_type, a->device.device_id);
  // ... kernel launch with stream ...
  return 0;
}
```
