# Fix torch_c_dlpack_ext import and build-time circular loading

## TL;DR
- Fix relative import in `torch_c_dlpack_ext/__init__.py` (`import core` -> `from . import core`) so the package works when installed as a proper Python package.
- Add `TVM_FFI_DISABLE_TORCH_C_DLPACK=1` env var during `build_wheel` to prevent circular loading of the torch_c_dlpack extension while building it.
- After importing `torch_c_dlpack_ext`, verify `__c_dlpack_exchange_api__` is actually set before returning early (the prebuilt package may have loaded without successfully patching torch).
- Version bump `torch_c_dlpack_ext` from 0.1.0 to 0.1.1.

## Key Exports

None -- this is a bugfix with no new public API surface.

## Impact
- API: none
- Behavioral: `torch_c_dlpack_ext` can now be properly imported as an installed package (relative import fix). Build-time circular import prevented by environment variable guard. Post-import validation tightened.
- Flags/config: `TVM_FFI_DISABLE_TORCH_C_DLPACK` env var now set during addon wheel build to disable the extension auto-load in `_optional_torch_c_dlpack.py` (consumed at line 130 of that file).
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **DLPack exchange protocol** (`__c_dlpack_exchange_api__` class attribute on `torch.Tensor`): the commit verifies this attribute is set after importing the prebuilt extension, rather than assuming a successful import means the patch was applied. See `0012-ffi-python-package` for the `DLPackExchangeAPI` design.
- **`TVM_FFI_DISABLE_TORCH_C_DLPACK` env var guard** (already present at `_optional_torch_c_dlpack.py:130`): the build backend now sets this variable to prevent self-referential loading during wheel compilation.

Design elements this commit produces: none

## Usage Examples

Before (broken):
```python
# torch_c_dlpack_ext/__init__.py
import core  # Fails with ModuleNotFoundError when installed as a package
```

After (fixed):
```python
# torch_c_dlpack_ext/__init__.py
from . import core  # Correct relative import
```

Before (build-time circular load):
```python
# build_backend.py: build_wheel() calls subprocess to build the addon,
# which imports tvm_ffi, which imports _optional_torch_c_dlpack,
# which tries to load the very extension being built -> circular failure
```

After (guarded):
```python
# build_backend.py: subprocess launched with TVM_FFI_DISABLE_TORCH_C_DLPACK=1
subprocess.run([...], env={**os.environ, "TVM_FFI_DISABLE_TORCH_C_DLPACK": "1"})
# _optional_torch_c_dlpack.py skips loading when this env var is "1" (line 130)
```
