# Simplify internal for_each helper in base_details.h using C++17 fold expression.
## TL;DR
- Replaces the recursive-specialization template pattern for `details::for_each` with a C++17 fold expression `(f(I, ...), ...)`.
- Eliminates the base-case specialization `for_each_dispatcher<true, I, F>` and reduces the implementation from ~15 lines to ~5.
- Public signature of `for_each(f, args...)` is unchanged; no caller impact.
