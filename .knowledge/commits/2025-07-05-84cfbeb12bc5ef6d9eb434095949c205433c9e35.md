# Simplify for_each_dispatcher using C++17 fold expression
## TL;DR
- Replaces the recursive template `for_each_dispatcher` (two struct specializations with head/tail recursion) with a single non-template struct using a C++17 fold expression `(f(I, std::forward<Args>(args)), ...)` plus `std::index_sequence`.
- Net result is -11 lines, +4 lines in `include/tvm/ffi/base_details.h`. No behavioral change; purely a code simplification.

## Impact
- API: none. `details::for_each` is an internal utility; its public interface (function signature) is unchanged.
- Flags/config: none.
- Data formats/schemas: none.
