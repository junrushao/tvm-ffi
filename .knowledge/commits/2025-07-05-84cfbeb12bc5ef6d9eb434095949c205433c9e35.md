# Replace recursive for_each_dispatcher template with C++17 fold expression
## TL;DR
- Simplifies `details::for_each_dispatcher` from a recursive two-struct template (with partial specialization base case) into a single non-template struct using a C++17 fold expression over a comma operator.
- Reduces template instantiation depth and code size with no change to the public `details::for_each` interface.

## Key Exports
No public API surface change. Internal implementation simplified:

**Before** (removed):
```cpp
// Recursive template with stop-condition partial specialization
template <bool stop, std::size_t I, typename F>
struct for_each_dispatcher {
  template <typename T, typename... Args>
  static void run(const F& f, T&& value, Args&&... args);
};
template <std::size_t I, typename F>
struct for_each_dispatcher<true, I, F> {
  static void run(const F&) {}
};
```

**After** (introduced):
```cpp
struct for_each_dispatcher {
  template <typename F, typename... Args, size_t... I>
  static void run(std::index_sequence<I...>, const F& f, Args&&... args) {
    (f(I, std::forward<Args>(args)), ...);
  }
};
```

Public entry point `details::for_each` signature unchanged:
```cpp
template <typename F, typename... Args>
void for_each(const F& f, Args&&... args);
```

## Impact
- API: None. `details::for_each` is an internal utility in `tvm::ffi::details` namespace; its signature and semantics are unchanged.
- Behavioral: None. Evaluation order preserved (comma operator fold is left-to-right).
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **C++17 fold expressions** (`(expr, ...)`) and **`std::index_sequence`/`std::index_sequence_for`** from the standard library -- used to replace the recursive template pattern.
- **Packed function calling convention** (`.knowledge/designs/0004-function-system.md`) -- `for_each` is called by `Function::operator()` via `PackedArgsSetter` to pack variadic arguments into `TVMFFIAny` arrays (`include/tvm/ffi/function.h:283`).

Design elements this commit produces:
- None. This is a pure refactor of an existing internal utility.

## Usage Examples
None -- no new API introduced. Existing call site unchanged:

```cpp
// include/tvm/ffi/function.h:283 (unchanged)
details::for_each(details::PackedArgsSetter(data), std::forward<Args>(args)...);
```
