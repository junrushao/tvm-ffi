# Replace recursive template for_each with C++17 fold expression
## TL;DR
- Replaced the recursive `for_each_dispatcher` template specialization (with a `bool stop` base-case partial specialization) with a single non-template struct using a C++17 fold expression `(f(I, std::forward<Args>(args)), ...)`.
- Uses `std::index_sequence_for<Args...>` to generate compile-time indices, eliminating the manual `I` counter and recursion termination.
- Net -7 LOC, no behavioral change.

## Key Exports
None -- internal implementation detail only. The public API (`details::for_each(f, args...)`) is unchanged.

## Impact
- API: none -- `details::for_each` signature and behavior are unchanged
- Behavioral: none -- identical runtime semantics
- Flags/config: none
- Data formats/schemas: none
