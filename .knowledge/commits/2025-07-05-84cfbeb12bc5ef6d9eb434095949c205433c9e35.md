# Replace recursive for_each_dispatcher with C++17 fold expression

## TL;DR
- Replaces the recursive template `for_each_dispatcher` (two specializations, one for the recursive case and one for the base case) with a single non-template struct using a C++17 fold expression `(f(I, std::forward<Args>(args)), ...)`.
- The `details::for_each` free function signature is unchanged; only the internal dispatch mechanism is simplified.
- Net effect: -11 lines, +4 lines in `include/tvm/ffi/base_details.h`. No behavioral change.

## Key Exports

None. The public interface (`details::for_each(f, args...)`) is unchanged. The internal `for_each_dispatcher` struct is simplified but remains an implementation detail not consumed outside `base_details.h`.

**Before:**
```cpp
// Two template specializations with recursive instantiation
template <bool stop, std::size_t I, typename F>
struct for_each_dispatcher {
  template <typename T, typename... Args>
  static void run(const F& f, T&& value, Args&&... args);
};
template <std::size_t I, typename F>
struct for_each_dispatcher<true, I, F> {
  static void run(const F&) {}
};
```

**After:**
```cpp
// Single struct with fold expression
struct for_each_dispatcher {
  template <typename F, typename... Args, size_t... I>
  static void run(std::index_sequence<I...>, const F& f, Args&&... args) {
    (f(I, std::forward<Args>(args)), ...);
  }
};
```

## Impact
- API: None. `details::for_each` signature unchanged.
- ABI: None. Header-only template; no compiled symbol changes.
- Behavioral: None. Identical runtime behavior.
- Flags/config: None.
- Data formats/schemas: None.
