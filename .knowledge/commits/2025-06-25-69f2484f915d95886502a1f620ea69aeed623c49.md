# Add ForEachFieldInfoWithEarlyStop for gradual VisitAttrs-to-reflection migration
## TL;DR
- Introduces `ForEachFieldInfoWithEarlyStop`, a field-visitor template that accepts a `bool`-returning callback, enabling early termination during field traversal (useful for search-by-name patterns).
- Hardens existing `ForEachFieldInfo` with a `static_assert` enforcing that its callback must return `void`, disambiguating the two overloads at compile time.
- Part of the migration strategy from old `VisitAttrs`-based reflection to the new `ReflectionDef` mechanism.

## Key Exports

**Functions**:
```cpp
// New: early-stop field visitor
template <typename Callback>
inline bool ForEachFieldInfoWithEarlyStop(
    const TypeInfo* type_info,
    Callback callback_with_early_stop);
// callback_with_early_stop: (const TVMFFIFieldInfo*) -> bool
// Returns true if any callback invocation returned true (early stop triggered).
```

**Behavioral change to existing function**:
```cpp
// Modified: added static_assert
template <typename Callback>
inline void ForEachFieldInfo(const TypeInfo* type_info, Callback callback);
// Now enforces: static_assert(std::is_same_v<decltype(callback(ptr)), void>)
// Callbacks that return non-void will fail to compile.
```

## Impact
- API: Adds one new public function template `ForEachFieldInfoWithEarlyStop` in `tvm::ffi::reflection`. The `static_assert` on `ForEachFieldInfo` is a minor breaking change -- callers whose callbacks accidentally returned non-void will now get a compile error, but this enforces the intended contract.
- Behavioral: None for existing correct callers. The new function enables search patterns (find-field-by-name) that previously required full traversal.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **TypeInfo / TVMFFITypeInfo**: The type hierarchy traversal pattern (`type_depth`, `type_acenstors`, `num_fields`, `fields`) — see [0009-reflection.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0009-reflection.md)
- **ForEachFieldInfo traversal pattern**: Parent-to-child ancestor iteration, skipping root object (index 0), then own fields — the new function mirrors this exactly.

Design elements this commit produces:
- **ForEachFieldInfoWithEarlyStop**: A new traversal primitive for the reflection system that supports short-circuit evaluation. Bridges the gap between old `VisitAttrs` (which supported early-stop via `AttrVisitor`) and the new `ForEachFieldInfo` (which did not).
- **Callback return-type contract enforcement**: The `static_assert` on `ForEachFieldInfo` formalizes the invariant that void-returning and bool-returning visitors are distinct APIs.

## Usage Examples
**Context**: Searching for a specific field by name using the new early-stop visitor.
```cpp
#include <tvm/ffi/reflection/reflection.h>

using namespace tvm::ffi::reflection;

// Find a field by name, returning its info pointer (or nullptr)
const TVMFFIFieldInfo* FindFieldByName(const TypeInfo* type_info,
                                        std::string_view target_name) {
  const TVMFFIFieldInfo* result = nullptr;
  ForEachFieldInfoWithEarlyStop(type_info, [&](const TVMFFIFieldInfo* field) -> bool {
    if (std::string_view(field->name.data, field->name.size) == target_name) {
      result = field;
      return true;  // early stop
    }
    return false;  // continue
  });
  return result;
}
```
