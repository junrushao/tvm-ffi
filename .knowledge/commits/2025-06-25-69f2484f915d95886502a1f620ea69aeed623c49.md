# Add ForEachFieldInfoWithEarlyStop and static_assert on ForEachFieldInfo callback
## TL;DR
- Adds `ForEachFieldInfoWithEarlyStop`, a new reflection field-iteration helper that accepts a `bool`-returning callback, allowing callers to terminate iteration early (e.g., when searching for a specific field by name).
- Adds a `static_assert` to the existing `ForEachFieldInfo` to enforce that its callback returns `void`, preventing accidental misuse where a caller intends early-stop semantics but silently discards the return value.
- Part of the "Field Visit bridge" for gradual migration from the legacy `VisitAttrs` reflection mechanism to the new `ReflectionDef`-based system.

## Impact
- API: Adds one new public template function `reflection::ForEachFieldInfoWithEarlyStop(const TypeInfo*, Callback)` in `include/tvm/ffi/reflection/reflection.h`. Tightens the existing `ForEachFieldInfo` contract with a compile-time check. No breaking changes.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit **consumes**:

- **Reflection system** ([`.knowledge/designs/0006-reflection.md`](../designs/0006-reflection.md)): Uses `TypeInfo`, `TVMFFITypeInfo`, `TVMFFIFieldInfo`, `type_depth`, `type_acenstors`, `fields`, and `num_fields` -- the core reflection data structures for field enumeration. The new function follows the same ancestor-to-child iteration order as `ForEachFieldInfo`.
- **Object system type hierarchy** ([`.knowledge/designs/0003-object-system.md`](../designs/0003-object-system.md)): The `type_acenstors` array (depth-indexed ancestor pointers) and `type_depth` field are part of the `TypeTable::Entry` / `TVMFFITypeInfo` structure. The iteration skips index 0 (always the root `Object`) and walks from parent to child, which is the standard traversal invariant for reflection field access.

Design elements this commit **produces**:

- **`ForEachFieldInfoWithEarlyStop`** (`include/tvm/ffi/reflection/reflection.h`): A template function that iterates over all `TVMFFIFieldInfo` entries for a type (including inherited fields from ancestors) and calls a `bool`-returning callback. Returns `true` if any callback invocation returned `true` (early stop triggered), `false` otherwise. This is a building block for field-search operations like name lookup, structural equality comparison, and object creation validation.
- **Compile-time callback-type enforcement on `ForEachFieldInfo`**: The `static_assert(std::is_same_v<ResultType, void>)` prevents callers from accidentally using `ForEachFieldInfo` when they need early-stop semantics, catching the mistake at compile time rather than silently ignoring the return value.
