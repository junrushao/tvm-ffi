# Add ForEachFieldInfoWithEarlyStop and tighten ForEachFieldInfo callback contract

## TL;DR
- Adds `ForEachFieldInfoWithEarlyStop`, a new field-iteration utility that accepts a `bool`-returning callback for search-style early termination.
- Tightens `ForEachFieldInfo` with a `static_assert` enforcing that its callback must return `void`, steering callers who need early-stop to the new function.
- Part of a gradual migration from legacy `VisitAttrs` reflection to the new `TVMFFITypeInfo`-based mechanism.

## Impact
- API: Adds one new public function template in `tvm::ffi::reflection`. Existing `ForEachFieldInfo` callers with non-void callbacks will fail to compile (intentional, guiding migration).
- Behavioral: None for callers with void callbacks.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `TypeInfo` / `TVMFFITypeInfo`: ancestor array traversal pattern (`type_depth`, `type_acenstors`, `num_fields`, `fields`). See [0007-ffi-reflection](../design-records/0007-ffi-reflection.md).
- `TVMFFIFieldInfo`: per-field metadata struct with byte_offset, getter/setter. See [0007-ffi-reflection](../design-records/0007-ffi-reflection.md).

Design elements this commit produces:
- `ForEachFieldInfoWithEarlyStop`: new field-iteration utility with early-termination support, enabling search-style operations over the type hierarchy's registered fields.
- `static_assert` contract on `ForEachFieldInfo`: compile-time enforcement that void-callback and bool-callback use cases are channeled to the correct function.

## Usage Examples

**Searching for a field by name using the new early-stop variant:**
```cpp
// Find a specific field in the type hierarchy
const TVMFFIFieldInfo* found = nullptr;
bool exists = reflection::ForEachFieldInfoWithEarlyStop(
    type_info, [&](const TVMFFIFieldInfo* field) -> bool {
      if (std::string_view(field->name.data, field->name.size) == "target_field") {
        found = field;
        return true;  // early stop
      }
      return false;
    });
// exists == true if field was found, found points to the TVMFFIFieldInfo
```

**VisitAttrs bridge (the stated motivation):**
```cpp
// Old: VisitAttrs pattern (virtual, per-type)
void MyNodeObj::VisitAttrs(AttrVisitor* v) {
  v->Visit("name", &name);
  v->Visit("value", &value);
}

// New: static reflection registration + ForEachFieldInfo iteration
TVM_FFI_REFLECTION_DEF(MyNodeObj)
  .def_readonly("name", &MyNodeObj::name)
  .def_readwrite("value", &MyNodeObj::value);
// Adapter iterates fields via ForEachFieldInfo[WithEarlyStop]
```
