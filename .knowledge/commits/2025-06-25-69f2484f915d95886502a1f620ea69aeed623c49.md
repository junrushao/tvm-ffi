# Add ForEachFieldInfoWithEarlyStop and harden ForEachFieldInfo with static_assert
## TL;DR
- Adds `ForEachFieldInfoWithEarlyStop`, a bool-returning variant of `ForEachFieldInfo` that supports early termination during field traversal -- a bridge utility for gradual transition from legacy `VisitAttrs` reflection to the new reflection mechanism.
- Adds a `static_assert` to the existing `ForEachFieldInfo` enforcing that the callback must return `void`, preventing accidental misuse with bool-returning callbacks.

## Key Exports
**Functions**:

```cpp
// New: early-stop field visitor (header-only template)
template <typename Callback>
inline bool ForEachFieldInfoWithEarlyStop(
    const TypeInfo* type_info,
    Callback callback_with_early_stop    // (const TVMFFIFieldInfo*) -> bool
) -> bool;  // returns true if any callback returned true (early stop triggered)
```

**Hardened existing function** (not a new export, but contract change):

```cpp
// Existing: now enforces void return via static_assert
template <typename Callback>
inline void ForEachFieldInfo(
    const TypeInfo* type_info,
    Callback callback                    // (const TVMFFIFieldInfo*) -> void  [enforced]
);
```

## Impact
- API: New `ForEachFieldInfoWithEarlyStop` function template in `tvm::ffi::reflection`. Existing `ForEachFieldInfo` gains a `static_assert` that will reject callbacks returning non-void -- this is a source-breaking change for any caller that previously passed a bool-returning callback (though no such callers exist in this codebase at the time of the commit).
- ABI: none -- both functions are header-only templates, no symbol table changes.
- Behavioral: none for existing correct callers. Callers that accidentally return non-void from a `ForEachFieldInfo` callback will now get a compile error.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeInfo / TVMFFITypeInfo hierarchy traversal** (`type_depth`, `type_acenstors`, `num_fields`, `fields`): The new function replicates the same parent-to-child iteration pattern as `ForEachFieldInfo`, walking ancestor types before the leaf type. See `.knowledge/designs/reflection.md` and `.knowledge/designs/object-system.md`.
- **TVMFFIFieldInfo** field descriptor struct: used as the callback argument type.

Design elements this commit produces:
- **ForEachFieldInfoWithEarlyStop**: A new search-oriented field visitor. The commit message describes this as part of a "gradual transition" bridge from legacy `VisitAttrs` to the new reflection mechanism. The bool-returning callback pattern enables field-name lookup, existence checks, and other search operations that do not need to visit every field.
- **static_assert guard on ForEachFieldInfo**: Enforces the void-return contract at compile time, making the two visitor variants (`void` vs `bool`) unambiguous.

## Usage Examples
Search for a field by name using early stop:

```cpp
#include <tvm/ffi/reflection/reflection.h>
using namespace tvm::ffi;

const TypeInfo* info = TVMFFIGetTypeInfo(MyObj::RuntimeTypeIndex());
const TVMFFIFieldInfo* found = nullptr;

bool exists = reflection::ForEachFieldInfoWithEarlyStop(
    info, [&](const TVMFFIFieldInfo* field) -> bool {
      if (std::strncmp(field->name.data, "target_field", field->name.size) == 0) {
        found = field;
        return true;   // early stop
      }
      return false;    // continue
    });
```
