# Add ForEachFieldInfoWithEarlyStop for field traversal with short-circuit and static_assert on existing ForEachFieldInfo
## TL;DR
- Adds `ForEachFieldInfoWithEarlyStop`, a new template function in `reflection.h` that traverses all fields of a type hierarchy (parent-to-child) and supports early termination via a bool-returning callback.
- Adds a `static_assert` to the existing `ForEachFieldInfo` enforcing that its callback must return void, preventing accidental misuse with bool-returning callbacks.
- This is a bridge utility to support the gradual transition from the legacy `VisitAttrs` reflection mechanism to the new `ReflectionDef`-based system.

## Impact
- API: Additive — new `ForEachFieldInfoWithEarlyStop` function in `tvm::ffi::reflection` namespace. The `static_assert` on `ForEachFieldInfo` is a compile-time breaking change for callers with non-void-returning callbacks (unlikely in practice since the return was always discarded).
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TypeInfo` / `TVMFFITypeInfo` — type hierarchy metadata with `type_depth`, `type_acenstors[]`, `fields[]`, `num_fields` (see [0008-reflection.md](../designs/0008-reflection.md))
- `TVMFFIFieldInfo` — per-field metadata struct (see [0001-c-abi.md](../designs/0001-c-abi.md))
- Parent-to-child traversal convention — skip `type_acenstors[0]` (root Object), iterate indices 1..type_depth-1 for ancestors, then own fields

Design elements this commit produces:
- `ForEachFieldInfoWithEarlyStop` — a search-oriented field traversal that short-circuits on first callback returning `true`. This is the search counterpart to the iteration-oriented `ForEachFieldInfo`.
- Callback return-type enforcement on `ForEachFieldInfo` via `static_assert` — ensures callers pick the correct variant (void-returning vs bool-returning).

## Usage Examples

**Searching for a field by name using the new early-stop traversal:**
```cpp
// Find a field named "target" in PointObj's type hierarchy
const TypeInfo* info = GetTypeInfo("my.Point");
const TVMFFIFieldInfo* found = nullptr;
bool hit = ForEachFieldInfoWithEarlyStop(info, [&](const TVMFFIFieldInfo* field) -> bool {
  if (std::string_view(field->name.data, field->name.size) == "target") {
    found = field;
    return true;   // early stop
  }
  return false;     // continue
});
// hit == true if "target" was found, found points to its TVMFFIFieldInfo
```

**Contrast with ForEachFieldInfo (exhaustive iteration):**
```cpp
// Collect all field names -- must use void-returning callback
std::vector<std::string> names;
ForEachFieldInfo(info, [&](const TVMFFIFieldInfo* field) {
  names.emplace_back(field->name.data, field->name.size);
});
```
