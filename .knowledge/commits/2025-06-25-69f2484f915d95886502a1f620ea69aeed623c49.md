# Add ForEachFieldInfoWithEarlyStop and enforce void-callback constraint on ForEachFieldInfo

## TL;DR
- Adds `ForEachFieldInfoWithEarlyStop` to `tvm::ffi::reflection`: a new field traversal helper that accepts a `bool`-returning callback and short-circuits on the first `true` return, enabling efficient field search without visiting all ancestors.
- Tightens `ForEachFieldInfo` with a `static_assert` ensuring callbacks return `void`, making the two traversal APIs' contracts explicit and mutually exclusive.
- Part of a multi-PR gradual migration from `VisitAttrs`-based reflection to the new `ReflectionDef`/`RegisterReflection` mechanism; this bridge function is the utility layer that makes field lookup usable during the transition.

## Key Exports

```python
# tvm::ffi::reflection namespace (include/tvm/ffi/reflection/reflection.h)

def ForEachFieldInfo(type_info: TypeInfo, callback: Callable[[TVMFFIFieldInfo*], None]) -> None:
    """Visit all registered field infos (parent-to-child order) for a type; callback must return void."""
    # Invariant: callback MUST return void (enforced by static_assert on ResultType).
    # Traversal order: ancestors[1..depth-1] in index order, then type's own fields.
    # Invariant: ancestors[0] is always the root Object — skipped.
    # Interacts with: TypeInfo.type_acenstors[], TypeInfo.num_fields, TVMFFIFieldInfo

def ForEachFieldInfoWithEarlyStop(
    type_info: TypeInfo,
    callback_with_early_stop: Callable[[TVMFFIFieldInfo*], bool]
) -> bool:
    """Visit field infos (parent-to-child order) with early stop on first True return.
    Returns True if any callback triggered early stop, False if all fields visited."""
    # Invariant: callback must return bool; True = stop, False = continue.
    # Traversal order: same as ForEachFieldInfo (ancestors[1..], then own fields).
    # Extension: used to implement field-by-name lookup during VisitAttrs bridge.
    # Interacts with: TypeInfo.type_acenstors[], TypeInfo.num_fields, TVMFFIFieldInfo
    # Interacts with: ForEachFieldInfo (sibling; same traversal; different return semantics)
```

## Impact
- API: **Additive only.** `ForEachFieldInfoWithEarlyStop` is a new public header function in `tvm::ffi::reflection`. No existing callers affected.
- Behavioral: The `static_assert` added to `ForEachFieldInfo` will cause a compile error if any existing or future caller passes a non-void-returning callback. This is a tightening of an implicit contract, not a runtime behavior change (no existing callers pass non-void callbacks per the diff).
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Searching for a field by name during `VisitAttrs`-to-`ReflectionDef` bridge (illustrative pseudocode based on commit message):

```cpp
// Find a field by name for a bridge between VisitAttrs and ReflectionDef.
const TVMFFIFieldInfo* FindField(const TypeInfo* type_info, std::string_view name) {
  const TVMFFIFieldInfo* result = nullptr;
  tvm::ffi::reflection::ForEachFieldInfoWithEarlyStop(
      type_info, [&](const TVMFFIFieldInfo* field) -> bool {
        if (field->name == name) {
          result = field;
          return true;  // early stop
        }
        return false;
      });
  return result;
}
```
