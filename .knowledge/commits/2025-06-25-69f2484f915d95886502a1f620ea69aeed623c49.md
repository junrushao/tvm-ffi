# Add ForEachFieldInfoWithEarlyStop and static_assert on ForEachFieldInfo callback return type

## TL;DR
- Adds `ForEachFieldInfoWithEarlyStop`, a new field-visitor that accepts a `bool`-returning callback for short-circuit search over a type's field hierarchy.
- Hardens `ForEachFieldInfo` with a `static_assert` requiring the callback to return `void`, preventing accidental use of a bool-returning callback in the wrong overload.
- Both functions serve as bridge utilities enabling gradual migration from the legacy `VisitAttrs` reflection pattern to the new `ReflectionDef` mechanism (described in the commit message for the broader TVM repo).

```python
    type_info: TypeInfo,
    callback_with_early_stop: Callable[[TVMFFIFieldInfo_ptr], bool]
) -> bool:
    """Visit each field info; return True on first callback returning True."""
    # Invariant: traverses parent-to-child order (type_acenstors[1..depth], then own fields)
    # Invariant: returns False if no callback triggered early stop
    # Interacts with: TypeInfo.type_acenstors[], TypeInfo.fields, TVMFFIFieldInfo
    # Extension: enables field-name lookup, search-by-predicate over reflected fields
    ...
```

## Impact
- API: Additive -- new `ForEachFieldInfoWithEarlyStop` template in `tvm::ffi::reflection` namespace. Existing `ForEachFieldInfo` gains a `static_assert` that may break callers whose callback accidentally returned a non-void value.
- Behavioral: None for existing correct callers. The `static_assert` surfaces a compile error for previously-silent misuse of `ForEachFieldInfo` with a bool-returning callback.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- `TypeInfo` / `TVMFFITypeInfo` -- type hierarchy metadata including `type_depth`, `type_acenstors`, `num_fields`, `fields` (see `0008-reflection.md`, `0007-c-abi.md`)
- `TVMFFIFieldInfo` -- per-field metadata struct (see `0008-reflection.md`)

Design elements this commit produces:
- `ForEachFieldInfoWithEarlyStop` -- new search-oriented field visitor in `tvm::ffi::reflection`. Mirrors `ForEachFieldInfo` but accepts a `bool`-returning callback for early termination. Located in `include/tvm/ffi/reflection/reflection.h`.

## Usage Examples

Searching for a field by name using `ForEachFieldInfoWithEarlyStop`:

```cpp
#include <tvm/ffi/reflection/reflection.h>

// Find a specific field by name in a type's full hierarchy
const TVMFFIFieldInfo* FindField(const reflection::TypeInfo* info,
                                 const char* target_name) {
  const TVMFFIFieldInfo* result = nullptr;
  reflection::ForEachFieldInfoWithEarlyStop(
      info, [&](const TVMFFIFieldInfo* field) -> bool {
        if (std::strcmp(field->name, target_name) == 0) {
          result = field;
          return true;  // early stop
        }
        return false;
      });
  return result;
}
```
