# Add ffi::Expected<T> for exception-free error handling
## TL;DR
- Adds `Expected<T>` (analogous to Rust `Result<T, Error>` / C++23 `std::expected`) as a new value type that holds either a success `T` or an `Error`.
- Adds `Unexpected<E>` wrapper for explicit error construction.
- Adds `Function::CallExpected<T>()` method for exception-free packed function calls via the `safe_call` ABI path.
- Full `TypeTraits<Expected<T>>` specialization enables round-tripping through `Any`.

## Key Exports

```python
class Unexpected(Generic[E]):
    """Wrapper to explicitly construct an Expected in the error state."""
    # Invariant: E must derive from Error (static_assert enforced)
    error_: E

    def __init__(self, error: E): ...
    def error(self) -> E: ...
    # Interacts with: Expected<T> (implicit conversion from Unexpected<E>)

class Expected(Generic[T]):
    """Exception-free error handling container: holds either T or Error."""
    # Invariant: T cannot be Error (static_assert: "Expected<Error> is not allowed")
    data_: Any  # holds either T or Error internally

    def __init__(self, value: T): ...       # implicit, success path
    def __init__(self, error: Error): ...   # implicit, error path
    def __init__(self, unexpected: Unexpected[E]): ...  # from Unexpected wrapper

    def is_ok(self) -> bool: ...
        # Interacts with: Any.as<Error>() — checks error first to handle T being a base of Error
        # Invariant: checks for Error before T to correctly classify Expected<ObjectRef>

    def is_err(self) -> bool: ...
    def has_value(self) -> bool: ...  # alias for is_ok()

    def value(self) -> T: ...
        # Invariant: throws the contained Error if is_err()
        # Interacts with: Any.cast<T>(), Any.cast<Error>()

    def error(self) -> Error: ...
        # Invariant: throws RuntimeError("Bad expected access") if is_ok()
        # Interacts with: TVM_FFI_THROW(RuntimeError)

    def value_or(self, default_value: T) -> T: ...
        # Returns contained value or default if error

# TypeTraits specialization for Expected<T>:
# - CopyToAnyView/MoveToAny: unwraps to inner T or Error (transparent to ABI)
# - CheckAnyStrict: true if inner is T or Error
# - TryCastFromAnyView: reconstructs Expected from Any holding T or Error
# - TypeStr: "Expected<{T}>"
# - TypeSchema: {"type":"Expected","args":[{T_schema},{"type":"ffi.Error"}]}
# Interacts with: TypeTraits<T>, TypeTraits<Error>
# Extension: specialize TypeTraits<Expected<T>> is automatic via the template

# New method on Function:
class Function:
    def CallExpected(self, T=Any, *args) -> Expected[T]:
        """Call function without throwing; returns Expected<T>."""
        # Uses safe_call (C ABI path) instead of cpp_call
        # On ret_code==0: try_cast result to T, then to Error
        # On ret_code!=0: wraps error from MoveFromSafeCallRaised()
        # Interacts with: FunctionObj.safe_call, details::MoveFromSafeCallRaised()
        # Interacts with: Any.try_cast<T>(), Any.try_cast<Error>()
        # Invariant: never throws (all exceptions caught by safe_call boundary)
        ...
```

## Impact
- API: Additive only. New public header `tvm/ffi/expected.h`, new method `Function::CallExpected<T>()`. No existing signatures changed.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: New TypeSchema format `{"type":"Expected","args":[...]}` for reflection.

## Design Elements
Design elements this commit consumes:
- **Any/AnyView value system** ([0002-ffi-any-value-system](../design-records/0002-ffi-any-value-system.md)): `Expected<T>` stores its value/error in an `Any`. Uses `Any.as<Error>()`, `Any.cast<T>()`, `Any.try_cast<T>()` for discrimination and extraction.
- **TypeTraits protocol** ([0002-ffi-any-value-system](../design-records/0002-ffi-any-value-system.md)): Full `TypeTraits<Expected<T>>` specialization following the 8-method protocol (`CopyToAnyView`, `MoveToAny`, `CheckAnyStrict`, `TryCastFromAnyView`, `CopyFromAnyViewAfterCheck`, `MoveFromAnyAfterCheck`, `TypeStr`, `TypeSchema`).
- **Error protocol** ([0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md)): `Error` as the error type inside `Expected`. Uses `TVM_FFI_THROW(RuntimeError)` for bad access.
- **Function safe_call** ([0004-ffi-function-system](../design-records/0004-ffi-function-system.md)): `CallExpected` uses `FunctionObj::safe_call` (C ABI boundary) to catch exceptions, then `details::MoveFromSafeCallRaised()` to recover the error.

Design elements this commit produces:
- **Expected<T> container**: New type-erased result type at `include/tvm/ffi/expected.h`. Holds either success `T` or `Error` in a single `Any`.
- **Unexpected<E> wrapper**: Explicit error construction wrapper with CTAD deduction guide.
- **Function::CallExpected<T>()**: Exception-free function call path returning `Expected<T>`.
- **TypeTraits<Expected<T>>**: Transparent ABI integration — `Expected` unwraps to its inner value when crossing the C ABI (no new type index needed).

## Usage Examples

Exception-free function calling (from `tests/cpp/test_expected.cc`):
```cpp
// Define a function that may fail
auto throwing_func = [](int a) -> int {
  if (a < 0) {
    TVM_FFI_THROW(ValueError) << "Negative value not allowed";
  }
  return a * 2;
};
Function func = Function::FromTyped(throwing_func);

// Exception-free call via CallExpected
Expected<int> result_ok = func.CallExpected<int>(5);
assert(result_ok.is_ok());     // true
assert(result_ok.value() == 10);

Expected<int> result_err = func.CallExpected<int>(-1);
assert(result_err.is_err());   // true
assert(result_err.error().kind() == "ValueError");
```

Returning Expected from registered functions:
```cpp
auto safe_divide = [](int a, int b) -> Expected<int> {
  if (b == 0) return Error("ValueError", "Division by zero", "");
  return a / b;
};
Function::SetGlobal("test.safe_divide", Function::FromTyped(safe_divide));

Function func = Function::GetGlobalRequired("test.safe_divide");
// Normal call path: throws on error
int val = func(10, 2).cast<int>();  // val == 5
// Exception-free path:
Expected<int> result = func.CallExpected<int>(10, 0);
assert(result.is_err());
assert(result.error().message() == "Division by zero");
```
