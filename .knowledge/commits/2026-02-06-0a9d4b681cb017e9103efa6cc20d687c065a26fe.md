# Add ffi::Expected<T> for exception-free error handling
## TL;DR
- Adds `Expected<T>` class in new header `include/tvm/ffi/expected.h`, analogous to Rust's `Result<T, Error>` or C++23's `std::expected`.
- Adds `Unexpected<E>` wrapper for explicit error construction.
- Adds `Function::CallExpected<T>()` for exception-free function invocation.
- Full `TypeTraits` integration enabling `Expected<T>` <-> `Any` roundtrip.
- Comprehensive test suite in `tests/cpp/test_expected.cc` (345 lines).

    """Exception-free error handling container: holds either T or Error."""
    # Invariant: T cannot be Error (use Error directly)
    # Interacts with: Any type system via TypeTraits<Expected<T>>

    def __init__(self, value: T) -> None: ...            # implicit from success value
    def __init__(self, error: Error) -> None: ...         # implicit from Error
    def __init__(self, unexpected: Unexpected[E]) -> None: ...  # from Unexpected wrapper

    def is_err(self) -> bool: ...

    def error(self) -> Error: ...

    def value_or(self, default: T) -> T: ...

## Usage Examples

```cpp
// Direct usage:
Expected<int> divide(int a, int b) {
    if (b == 0) return Error("ValueError", "Division by zero", "");
    return a / b;
}
auto result = divide(10, 2);
if (result.is_ok()) {
    int value = result.value();  // 5
}

// Via Function::CallExpected:
Function func = Function::GetGlobal("risky_function");
Expected<int> result = func.CallExpected<int>(arg1, arg2);
if (result.is_err()) {
    Error err = result.error();
}
```
