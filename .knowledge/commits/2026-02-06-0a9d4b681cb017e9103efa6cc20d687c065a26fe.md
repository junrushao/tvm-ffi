# Add Expected<T> for exception-free error handling and Function::CallExpected
## TL;DR
- Introduces `Expected<T>` class (`expected.h`) holding either a success value `T` or an `Error`, analogous to Rust's `Result<T, Error>` or C++23's `std::expected`.
- Adds `Unexpected<E>` wrapper for explicit error construction, with CTAD guide.
- Adds `Function::CallExpected<T>(args...)` method that calls via `safe_call` path, catching exceptions and returning them as `Expected<T>` instead of throwing.
- Full `TypeTraits<Expected<T>>` specialization enables `Expected<T>` to participate in the Any type system (can be a function return type).

## Key Exports

**Types/Classes**:
```cpp
// expected.h
template <typename E = Error>
class Unexpected {
    explicit Unexpected(E error);
    const E& error() const& noexcept;
    E&& error() && noexcept;
};
template <typename E> Unexpected(E) -> Unexpected<E>;  // CTAD

template <typename T>
class Expected {
    Expected(T value);              // implicit from success value
    Expected(Error error);          // implicit from error
    Expected(Unexpected<E> unexpected); // from Unexpected wrapper
    bool is_ok() const;
    bool is_err() const;
    bool has_value() const;         // alias for is_ok()
    T value() const&;               // throws contained Error if is_err()
    T value() &&;
    Error error() const&;           // throws RuntimeError if is_ok()
    Error error() &&;
    T value_or(U&& default_value) const;
private:
    Any data_;                      // holds either T or Error
};
```

**Functions**:
```cpp
// function.h - new method on Function
template <typename T = Any, typename... Args>
Expected<T> Function::CallExpected(Args&&... args) const;
```

**Traits**:
```cpp
// TypeTraits<Expected<T>> specialization with:
//   CopyToAnyView, MoveToAny, CheckAnyStrict, CopyFromAnyViewAfterCheck,
//   MoveFromAnyAfterCheck, TryCastFromAnyView, TypeStr, TypeSchema
// CheckAnyStrict returns true if src matches T OR Error
```

## Impact
- API: New public header `expected.h`, included from `function.h` and `tvm_ffi.h`. New `Function::CallExpected<T>()` method.
- Behavioral: No changes to existing code paths. `CallExpected` uses the `safe_call` function pointer (same as C ABI path), catching exceptions without propagating them.
- Flags/config: none
- Data formats/schemas: TypeSchema for `Expected<T>` is `{"type":"Expected","args":[<T_schema>,{"type":"ffi.Error"}]}`

## Design Elements
Design elements this commit consumes:
- **Any/AnyView value system** (`.knowledge/designs/0002-any-value-system.md`): `Expected<T>` stores its state as `Any data_`, leveraging `Any::try_cast<T>()` and `Any::cast<Error>()` for discrimination.
- **Type traits** (`.knowledge/designs/0005-type-traits.md`): Full `TypeTraits<Expected<T>>` specialization enabling Any interop.
- **Function system** (`.knowledge/designs/0004-function-system.md`): `CallExpected` uses `FunctionObj::safe_call` (the C ABI safe-call function pointer) and `details::MoveFromSafeCallRaised()` for TLS error retrieval.
- **Error handling** (`.knowledge/designs/0006-error-handling.md`): `Error` as the error type in the Expected variant.

Design elements this commit produces:
- **Expected<T> result type**: Exception-free error handling primitive for C++ FFI usage. Stored as `Any` internally, discriminated by `Any::as<Error>()` check.
- **Function::CallExpected<T>**: Exception-free function call path using safe_call.

## Usage Examples

```cpp
#include <tvm/ffi/expected.h>

// Returning Expected from a function
Expected<int> divide(int a, int b) {
    if (b == 0) return Error("ValueError", "Division by zero");
    return a / b;
}

auto result = divide(10, 2);
assert(result.is_ok());
assert(result.value() == 5);
assert(divide(1, 0).is_err());

// Exception-free FFI function call
Function func = Function::GetGlobal("risky_function");
Expected<int> r = func.CallExpected<int>(arg1, arg2);
if (r.is_ok()) {
    use(r.value());
} else {
    log(r.error().what());
}

// Using value_or for defaults
int val = divide(1, 0).value_or(42);  // returns 42
```
