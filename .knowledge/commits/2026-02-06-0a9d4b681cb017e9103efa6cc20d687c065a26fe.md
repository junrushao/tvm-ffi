# Add ffi::Expected<T> for exception-free error handling
## TL;DR
- Introduces `Expected<T>` type (similar to Rust `Result<T, Error>` or C++23 `std::expected`) for exception-free error handling
- Adds `Unexpected<E>` wrapper for explicit error construction
- Provides `TypeTraits<Expected<T>>` specialization for FFI interop
- Adds `Function::CallExpected<T>()` method to call FFI functions returning `Expected<T>` without exceptions
- Includes 345-line test suite covering all usage patterns

## Key Exports
```python
class Unexpected[E: Error]:
    """Wrapper for explicit error construction in Expected."""
    def __init__(self, error: E) -> None: ...
    def error(self) -> E: ...

class Expected[T]:
    """Exception-free error handling container (like Rust Result<T, Error>)."""
    # Invariant: T cannot be Error
    def __init__(self, value: T) -> None: ...        # success path
    def __init__(self, error: Error) -> None: ...     # error path
    def __init__(self, unexpected: Unexpected[E]) -> None: ...  # explicit error
    def is_ok(self) -> bool: ...
    def is_err(self) -> bool: ...
    def has_value(self) -> bool: ...  # alias for is_ok()
    def value(self) -> T: ...         # throws contained error if is_err()
    def error(self) -> Error: ...     # throws RuntimeError if is_ok()
    def value_or(self, default: T) -> T: ...
    # Interacts with: Any (stores T or Error internally), TypeTraits<Expected<T>>
    # Extension: combine with Function::CallExpected for exception-free FFI calls

class Function:
    def call_expected(self, *args) -> Expected[T]: ...
    # Interacts with: safe_call convention, Expected<T> return type
    # Invariant: catches errors from safe_call and wraps in Expected instead of throwing

# TypeTraits<Expected<T>>: maps to/from Any by storing either T or Error
# CopyToAnyView delegates to TypeTraits<T> or TypeTraits<Error>
# TryCastFromAnyView: tries Error first, then T (handles T=ObjectRef hierarchy correctly)
```

## Usage Examples
```cpp
// Function returning Expected instead of throwing:
Expected<int> divide(int a, int b) {
  if (b == 0) return Unexpected(Error("ValueError", "Division by zero"));
  return a / b;
}

auto result = divide(10, 2);
if (result.is_ok()) {
  int value = result.value();  // 5
} else {
  Error err = result.error();
}

// Exception-free FFI call:
Function f = get_global_func("some_func");
Expected<int> result = f.CallExpected<int>(arg1, arg2);
int value = result.value_or(-1);  // default on error
```
