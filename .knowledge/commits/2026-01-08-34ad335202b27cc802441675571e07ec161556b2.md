# Add comprehensive Any/AnyView concept doc and cross-link from existing guides
## TL;DR
- Adds `docs/concepts/any.rst`, a 436-line tutorial covering `Any`/`AnyView` usage patterns, ownership semantics, ABI boundary rules, memory layout (tagged union, atomic types, heap objects), and small string optimization.
