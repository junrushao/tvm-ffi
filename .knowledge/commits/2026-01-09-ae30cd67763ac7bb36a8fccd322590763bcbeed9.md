# Fix out-of-bounds read in dtype string parsing with non-null-terminated string_view
## TL;DR
- Replaces `strtoul()` with bounds-respecting manual digit parsing in `StringViewToDLDataType_` to prevent OOB reads on non-null-terminated `string_view` inputs.
- Adds comprehensive test `TEST(DType, NonNullTerminatedStringView)` covering garbage-after-bounds, lane parsing, and scalable vector dtype cases.

## Usage Examples
Before (buggy): `strtoul()` reads past `string_view` bounds into garbage memory, parsing `"float16"` from `"float16999888777"` as bits=16999888777.

After (fixed): manual digit parser respects `str.data() + str.length()` boundary, correctly parsing bits=16.
