# Fix out-of-bounds read in StringViewToDLDataType_ with non-null-terminated strings
## TL;DR
- Replaces `strtoul()` calls in `StringViewToDLDataType_` with bounded manual digit parsing, fixing an out-of-bounds read when `std::string_view` is not null-terminated (e.g., in Electron/Chromium environments with aggressive allocator reuse).
- Extracts `parse_digits` and `parse_lanes` helper lambdas that respect `string_view` length boundaries and add overflow checks for bits (`uint8_t`), lanes (`uint16_t`), and intermediate values (`uint32_t`).
- Adds comprehensive test `TEST(DType, NonNullTerminatedStringView)` with 10 cases covering digit garbage after bounds, lane specifications outside bounds, scalable vectors, and truly non-null-terminated buffers.

## Key Exports

**Functions** (internal, in `src/ffi/dtype.cc`):

| Symbol | Signature | Notes |
|--------|-----------|-------|
| `parse_digits` | `(const char** ptr, const char* end) -> uint32_t` | Lambda; parses decimal digits within `[*ptr, end)`, advances `*ptr`, throws on `> UINT32_MAX` |
| `parse_lanes` | `(const char** ptr, const char* end, string_view dtype_str, bool allow_scalable) -> uint16_t` | Lambda; parses `x<N>` or `xvscalex<N>` lane spec, returns 1 if absent, negative for scalable vectors |

**Mutated function**: `StringViewToDLDataType_(std::string_view str) -> DLDataType` — now safe for non-null-terminated input.

## Impact
- API: none (internal function, C API `TVMFFIDataTypeFromString` unchanged)
- Behavioral: `StringViewToDLDataType_` no longer reads past `str.data() + str.length()`. Previously, `strtoul` could read garbage digits past the view boundary, producing incorrect bits/lanes values or crashing.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
**Before** (bug): `strtoul` reads past `string_view` bounds.
```cpp
// buffer contains "float16999888777", view is length 7 ("float16")
std::string_view sv(buffer, 7);
DLDataType dt = StringViewToDLDataType_(sv);
// BEFORE: dt.bits == garbage (strtoul parsed "16999888777")
```

**After** (fix): bounded parsing stops at view end.
```cpp
// Same input
std::string_view sv(buffer, 7);
DLDataType dt = StringViewToDLDataType_(sv);
// AFTER: dt.bits == 16, dt.lanes == 1 (correct)
```
