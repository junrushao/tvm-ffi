# Add CI job to run examples on main-branch commits with Windows batch-script and CMake flat-output-dir support

## TL;DR

- Adds a new `examples` CI job in `ci_mainline_only.yml` that runs all three example directories (`quickstart`, `stable_c_abi`, `packaging`) on Ubuntu, macOS, and Windows after every merge to `main`.
- Adds `run_all_cpu.bat` (quickstart) and `run_all.bat` (stable_c_abi) Windows batch scripts mirroring the existing `*.sh` POSIX counterparts; both use `setlocal enabledelayedexpansion` and dynamically discover `TVM_FFI_LIBDIR` from `tvm_ffi.libinfo`.
- Introduces a shared `set_flat_output_dirs(target)` CMake helper in both `examples/quickstart/CMakeLists.txt` and `examples/stable_c_abi/CMakeLists.txt` to force all multi-config generators (MSVC) to emit outputs into a flat `${CMAKE_BINARY_DIR}` rather than per-config subdirectories.

## Impact

- API: none — no public headers or Python APIs changed.
- Behavioral: `examples/packaging/run_example.py` no longer accepts CLI arguments; it always runs `run_add_one()`, `run_raise_error()`, and `run_int_pair()` sequentially. The `raise_error` flow now catches `RuntimeError` and prints the traceback rather than letting it propagate.
- Flags/config: `cmake.build-type` in `examples/packaging/pyproject.toml` corrected from `"RelWithDebugInfo"` (invalid) to `"RelWithDebInfo"`.

## Design Elements

Design elements this commit consumes:
- `0021-build-packaging` — CI job follows the existing `ci_mainline_only.yml` job pattern (`needs: [prepare]`, `matrix`, `uv pip install`).
- `0011-module-system` — `run_all_cpu.bat` and `run_all.bat` use `tvm_ffi.libinfo.find_libtvm_ffi()` to locate `libtvm_ffi` and prepend it to `PATH` for the `load_cpp.exe` / `load.exe` step; this is the documented Windows DLL-search-path convention for the module system.
- `0004-function-system` — `TVM_FFI_DLL` macro in `examples/stable_c_abi/src/add_one_cpu.c` corrected to `TVM_FFI_DLL_EXPORT`, aligning with the macro name used throughout `include/tvm/ffi/` public headers.
