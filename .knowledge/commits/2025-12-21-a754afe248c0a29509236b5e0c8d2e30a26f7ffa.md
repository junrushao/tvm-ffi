# Add CI job to run examples on main commits; add Windows .bat scripts and fix example build issues
## TL;DR
- Adds an `examples` CI job in `ci_mainline_only.yml` that runs all three example suites (quickstart, stable_c_abi, packaging) on Linux, macOS, and Windows with Python 3.12-3.14.
- Introduces Windows `.bat` runner scripts and a `set_flat_output_dirs` CMake helper to normalize MSVC multi-config output directories.
- Fixes minor issues: `TVM_FFI_DLL` -> `TVM_FFI_DLL_EXPORT` in the stable_c_abi example, `RelWithDebugInfo` -> `RelWithDebInfo` typo in packaging `pyproject.toml`, and simplifies `run_example.py` to run all demos sequentially.
