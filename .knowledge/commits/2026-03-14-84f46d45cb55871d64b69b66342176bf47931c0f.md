# Add structural equality/hashing support (structure= param) to py_class and field

## TL;DR
- `@py_class` gains `structure=` parameter: maps to `TVMFFISEqHashKind` enum (`"tree"`, `"var"`, `"dag"`, `"const-tree"`, `"singleton"`, `None`).
- `field()` gains `structure=` parameter: `"def"` (default contribution) or `"ignore"` (excluded from structural eq/hash).
- Cython `type_info.pxi` maps these to C flags and calls `TVMFFITypeRegisterMetadata`.
- Adds 361 test lines mirroring C++ structural eq/hash tests, and full `docs/concepts/structural_eq_hash.rst` documentation.

## Key Exports

```python
# python/tvm_ffi/dataclasses/py_class.py
@py_class(
    structure: str | None = None,  # NEW: "tree"|"var"|"dag"|"const-tree"|"singleton"|None
    ...
)
# Maps to TVMFFISEqHashKind:
# None -> kTVMFFISEqHashKindUnsupported (0, default)
# "tree" -> kTVMFFISEqHashKindTreeNode (1) - content-based
# "var" -> kTVMFFISEqHashKindFreeVar (2) - binding position
# "dag" -> kTVMFFISEqHashKindDAGNode (3)
# "const-tree" -> kTVMFFISEqHashKindConstTreeNode (4)
# "singleton" -> kTVMFFISEqHashKindUniqueInstance (5)

# python/tvm_ffi/dataclasses/field.py
def field(..., structure: str | None = None):
    # "def" (default) = included in structural eq/hash
    # "ignore" = excluded from structural eq/hash
    # Interacts with: TVMFFIFieldFlagBitMask
```

## Impact
- API: Additive. New `structure=` parameter on `@py_class` and `field()`.
- Behavioral: `@py_class` types can now participate in `StructuralEqual`/`StructuralHash` with proper tree/DAG/var semantics.
- Flags/config: none
- Data formats/schemas: none
