# Add structural equality/hashing support to py_class and field

## TL;DR
- `@py_class` gains `structure=` parameter for type-level structural eq/hash kind ("tree", "leaf", "none").
- `field()` gains `structure=` parameter for field-level annotations ("def", "ignore").
- Cython `type_info.pxi` maps Python structure annotations to C flags and calls `TVMFFITypeRegisterMetadata`.
- New RST documentation for structural equality/hashing concepts; 361-line test suite.

## Key Exports

```python
@py_class("my.Node", structure="tree")
class Node(Object):
    name: str
    comment: str = field(structure="ignore")  # excluded from structural eq/hash
    params: Array = field(structure="def")    # enters def region for free-var mapping

# structure= parameter on @py_class:
#   "tree" -> TVMFFISEqHashKind.TreeNode
#   "leaf" -> TVMFFISEqHashKind.UniqueInstance
#   "none" -> TVMFFISEqHashKind.Unsupported (default)
# Interacts with: TVMFFITypeRegisterMetadata, 0009-structural-eq-hash

# structure= parameter on field():
#   "def" -> kTVMFFIFieldFlagBitMaskSEqHashDef
#   "ignore" -> kTVMFFIFieldFlagBitMaskSEqHashIgnore
```

## Impact
- API: `@py_class` and `field()` gain `structure=` parameter.
- Behavioral: Python-defined types can now participate in structural equality/hashing.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

```python
from tvm_ffi.dataclasses import py_class, field
from tvm_ffi import StructuralEqual

@py_class("test.MyNode", structure="tree", eq=True, unsafe_hash=True)
class MyNode(Object):
    name: str
    comment: str = field(structure="ignore")

a = MyNode("hello", "draft")
b = MyNode("hello", "final")
assert StructuralEqual()(a, b)  # comment ignored
```
