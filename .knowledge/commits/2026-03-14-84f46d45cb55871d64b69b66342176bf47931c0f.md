# Add structural equality/hashing support to @py_class and field()

## TL;DR
- New `structure=` param on `@py_class`: maps to `TVMFFISEqHashKind` enum (`"tree"`, `"var"`, `"dag"`, `"const-tree"`, `"singleton"`, `None`); passed to `TypeInfo._register_fields(own_fields, structure_kind)`.
- New `structure=` param on `field()`: `None` (participates normally), `"ignore"` (excluded from eq/hash), `"def"` (definition region introducing variable bindings); mapped to C flags via `type_info.pxi`.
- New RST doc `docs/concepts/structural_eq_hash.rst` (715 lines) with Mermaid diagrams.

## Key Exports

```python
# python/tvm_ffi/dataclasses/py_class.py

_STRUCTURE_KIND_MAP: dict[str | None, int] = {
    None: 0,       # kTVMFFISEqHashKindUnsupported
    "tree": 1,     # kTVMFFISEqHashKindTreeNode
    "var": 2,      # kTVMFFISEqHashKindFreeVar
    "dag": 3,      # kTVMFFISEqHashKindDAGNode
    "const-tree": 4,  # kTVMFFISEqHashKindConstTreeNode
    "singleton": 5,   # kTVMFFISEqHashKindUniqueInstance
}

@dataclass_transform(eq_default=False, order_default=False)
def py_class(
    type_key: str | None = None,
    *,
    # ... existing params ...
    structure: str | None = None,  # NEW: structural eq/hash kind
) -> Callable[[type], type]: ...

# python/tvm_ffi/dataclasses/field.py

class Field:
    structure: str | None    # NEW: None, "ignore", or "def"
    _VALID_STRUCTURE_VALUES: ClassVar[frozenset] = frozenset({None, "ignore", "def"})

def field(
    *,
    # ... existing params ...
    structure: str | None = None,  # NEW
) -> Any: ...
# Interacts with: TypeInfo._register_fields (Cython), TVMFFITypeRegisterMetadata
# Invariant: structure="ignore" → field excluded from structural eq/hash
# Invariant: structure="def" → field is definition region (alpha-equiv)
```

## Impact
- API: `@py_class` gains `structure=` keyword arg. `field()` gains `structure=` keyword arg. `Field` class gains `structure` slot. Backward-compatible (defaults to `None`).
- Behavioral: Python-defined types can now participate in `StructuralEqual`/`StructuralHash` with the same semantics as C++ types. Invalid `structure=` values raise `ValueError`.
- Flags/config: `structure="tree"` is the safe default for most IR nodes; `"var"` for variable binding nodes; `"singleton"` for singletons.
- Data formats/schemas: `TVMFFISEqHashKind` enum values 0-5 now surfaced in Python.

## Design Elements
Design elements this commit consumes:
- `0009-structural-eq-hash`: `TVMFFISEqHashKind` enum, `StructuralEqual`/`Hash` reflection protocol
- `0013-python-package`: `TypeInfo._register_fields`, `TVMFFITypeRegisterMetadata` Cython call

Design elements this commit produces:
- `structure=` param on `@py_class`: type-level structural eq/hash kind control
- `structure=` param on `field()`: field-level structural eq/hash annotation (`"ignore"`, `"def"`)
- `_STRUCTURE_KIND_MAP`: Python→C enum mapping for structural kind
- `Field._VALID_STRUCTURE_VALUES`: validation set for field-level structure annotations

## Usage Examples

```python
from tvm_ffi.core import Object
from tvm_ffi.dataclasses import py_class, field

@py_class("myir.Func", structure="tree")
class Func(Object):
    params: list = field(structure="def")  # definition region: introduces variable bindings
    body: object                            # participates in structural eq/hash normally
    span: object = field(structure="ignore")  # excluded from structural eq/hash

@py_class("myir.Var", structure="var")
class Var(Object):
    name: str

# StructuralEqual/Hash now work for Python-defined py_class types
from tvm_ffi import structural_equal, structural_hash
f1 = Func(params=[], body=Var(name="x"), span=None)
f2 = Func(params=[], body=Var(name="x"), span=None)
assert structural_equal(f1, f2)  # True: span ignored, var compared by binding position
```
