# Add structural equality/hashing support to py_class and field
## TL;DR
- Adds `eq` parameter to `field()` controlling whether a field participates in structural equality/hashing.
- Implements `__s_equal__` and `__s_hash__` hooks in `py_class` using the existing `TypeAttrColumn` mechanism.
- Adds `docs/concepts/structural_eq_hash.rst` documentation.
- Adds 361-line `test_structural_py_class.py` test suite.

## Usage Examples
```python
from tvm_ffi.dataclasses import py_class, field

@py_class("mylib.CachedResult")
class CachedResult:
    key: str
    value: int
    cache_id: int = field(eq=False)  # excluded from equality

r1 = CachedResult(key="a", value=1, cache_id=100)
r2 = CachedResult(key="a", value=1, cache_id=200)
assert tvm_ffi.structural_equal(r1, r2)  # True, cache_id ignored
```
