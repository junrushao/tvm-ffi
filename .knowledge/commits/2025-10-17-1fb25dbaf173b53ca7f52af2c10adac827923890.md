# Polish quickstart docs: rename examples, fix CMake config, add JAX/bundle snippets
## TL;DR
- Renames generic `libmain.so`/`main.cc`/`main.cu` to descriptive `add_one_cpu.so`/`add_one_cpu.cc`/`add_one_cuda.cu` throughout the quickstart guide, aligning docs with the actual example source filenames.
- Fixes CMake snippets in both `docs/get_started/quickstart.rst` and `examples/quick_start/CMakeLists.txt` to use `python -m tvm_ffi.config --cmakedir` (module form) instead of bare `tvm-ffi-config --cmakedir`.
- Adds new JAX usage example via `jax-tvm-ffi`, a C++ bundling hint (`Function::FromExternC`/`InvokeExternC`), an expanded C++ `run_example.cc` snippet, and a note about Python ABI version independence.
