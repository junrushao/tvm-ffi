# Polish quickstart docs with improved examples, naming, and JAX/bundle snippets
## TL;DR
- Rewrites quickstart guide (`docs/get_started/quickstart.rst`) to use distinct library names (`add_one_cpu.so`, `add_one_cuda.so`) instead of a single generic `libmain.so`, making per-device examples self-contained and unambiguous.
- Adds JAX integration example (via `jax-tvm-ffi`), a C++ bundle example (`Function::InvokeExternC`), and a Rust `into_typed_fn!` example; expands C++ driver example to a complete `main()` with tensor allocation.
- Fixes the CMake `execute_process` command in both the docs and `examples/quick_start/CMakeLists.txt` to use the correct `python -m tvm_ffi.config --cmakedir` instead of the incorrect `python -m tvm-ffi-config --cmakedir`.

Design elements this commit produces:
- **JAX integration pattern**: First documented example of using `jax-tvm-ffi` to register a TVM FFI function as a JAX custom call target via `jax_tvm_ffi.register_ffi_target` and `jax.ffi.ffi_call`.
- **C++ bundle pattern**: First documented example of `Function::InvokeExternC` for statically linking a TVM FFI exported function into the same binary (bypassing dynamic module loading).
- **Distinct per-device naming convention**: The quickstart now uses `add_one_cpu`/`add_one_cuda` as both the exported function name and the `.so` filename, establishing a clear naming pattern for multi-device libraries.

## Usage Examples
### Loading a per-device module in Python (PyTorch)
```python
import tvm_ffi
import torch

mod = tvm_ffi.load_module("add_one_cuda.so")
device = "cuda"
x = torch.tensor([1, 2, 3, 4, 5], dtype=torch.float32, device=device)
y = torch.empty_like(x)
mod.add_one_cuda(x, y)
print(y)
```

### JAX integration via jax-tvm-ffi
```python
import jax
import jax.numpy as jnp
import jax_tvm_ffi
import tvm_ffi

mod = tvm_ffi.load_module("add_one_cuda.so")
jax_tvm_ffi.register_ffi_target("add_one_cuda", mod.add_one_cuda, platform="cuda")
x = jnp.array([1.0, 2.0, 3.0], dtype=jnp.float32)
y = jax.ffi.ffi_call(
    "add_one_cuda",
    jax.ShapeDtypeStruct(x.shape, x.dtype),
    vmap_method="broadcast_all",
)(x)
```

### C++ bundle pattern (static linking, no dynamic module load)
```cpp
// declare reference to the exported symbol
extern "C" int __tvm_ffi_add_one(void*, const TVMFFIAny*, int32_t, TVMFFIAny*);

namespace ffi = tvm::ffi;

int bundle_add_one(ffi::TensorView x, ffi::TensorView y) {
    void* closure_handle = nullptr;
    ffi::Function::InvokeExternC(closure_handle, __tvm_ffi_add_one, x, y);
    return 0;
}
```
