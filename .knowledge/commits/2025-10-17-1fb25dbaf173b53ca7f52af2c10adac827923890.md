# Polish quickstart guide: rename example files, fix tvm_ffi.config invocation, add C++ bundle example
## TL;DR
- Renames example source filenames in docs from generic `main.cc`/`main.cu` to descriptive `add_one_cpu.cc`/`add_one_cuda.cc`, and exported symbol names from `add_one` to `add_one_cpu`/`add_one_cuda`.
- Fixes CMake config discovery: `tvm-ffi-config --cmakedir` (CLI) corrected to `tvm_ffi.config --cmakedir` (Python module invocation) in both docs and `examples/quick_start/CMakeLists.txt`.
- Adds a new "Bundle into a C++ Binary" section demonstrating static linking of the add_one library into a standalone C++ executable.
