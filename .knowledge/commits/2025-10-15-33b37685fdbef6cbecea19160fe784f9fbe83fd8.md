# Hide libbacktrace symbols via -fvisibility=hidden in CMake build
## TL;DR
- Adds `-fvisibility=hidden -fvisibility-inlines-hidden` to libbacktrace's CFLAGS in the CMake ExternalProject build, preventing internal symbols from leaking into the tvm_ffi shared library's public symbol table.
- Compiler-guarded for GCC, Clang, and AppleClang only.

## Key Exports
N/A — infrastructure.

## Impact
- API: none
- Behavioral: libbacktrace symbols are no longer exported from the tvm_ffi shared library, preventing potential symbol collisions with other libraries that also vendor libbacktrace
- Flags/config: new `symbol_hiding_flags` CMake variable in `_libbacktrace_compile()` function
- Data formats/schemas: none
