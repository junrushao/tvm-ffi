# Support vanilla C++ STL containers in FFI
## TL;DR
- Adds `TypeTraits` specializations for `std::vector<T>`, `std::tuple<T...>`, `std::pair<K,V>`, `std::unordered_map<K,V>`, and `std::map<K,V>` enabling automatic conversion to/from FFI containers (Array, Tuple, Map).
- Adds comprehensive tests for STL container round-trips through packed functions.

## Key Exports

**TypeTraits Specializations (C++):**
- `TypeTraits<std::vector<T>>` -- Converts to/from `Array<T>`.
- `TypeTraits<std::tuple<T...>>` -- Converts to/from `Tuple<T...>`.
- `TypeTraits<std::pair<K,V>>` -- Converts to/from `Tuple<K,V>`.
- `TypeTraits<std::unordered_map<K,V>>` -- Converts to/from `Map<K,V>`.
- `TypeTraits<std::map<K,V>>` -- Converts to/from `Map<K,V>`.

## Impact
- API: STL containers can now be used directly as packed function arguments and return types.
- ABI: none
- Behavioral: Automatic bidirectional conversion between STL and FFI containers.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:

Design elements this commit produces:

## Usage Examples
```cpp
TVM_FFI_REGISTER_GLOBAL("test.vec")
    .set_body_typed([](std::vector<int> v) -> int { return v.size(); });
// Python: f([1, 2, 3]) returns 3
```
