# Add STL container TypeTraits bridge (stl.h) for transparent std::vector/array/tuple/optional/variant/map/function in FFI exports
## TL;DR
- Introduces `tvm/ffi/extra/stl.h`, a header-only bridge that provides `TypeTraits<T>` specializations for 8 C++ STL types: `std::array`, `std::vector`, `std::optional`, `std::variant`, `std::tuple`, `std::map`, `std::unordered_map`, and `std::function`.
- STL types are transparently converted to/from native FFI containers (`Array`, `Map`, `Function`) when crossing the FFI boundary -- users write vanilla C++ signatures and the conversion is automatic.
- Adds a `TypeTraits` friend declaration to `MapObj` to enable `CreateFromRange` access from the STL map specializations.

## Key Exports

```python
# --- Internal base classes (not directly used by consumers) ---

class STLTypeMismatch(Exception):
    """Sentinel exception used internally to signal type mismatch during STL<->FFI conversion."""
    # Invariant: caught internally by TryCastFromAnyView; never propagates to user code
    # Interacts with: every TryCastFromAnyView in stl.h catches this to return nullopt

class STLTypeTrait:
    """Base class for STL TypeTraits specializations. Disables direct storage in Any."""
    storage_enabled: bool = False  # STL types cannot be stored directly in TVMFFIAny
    # Invariant: STL types always round-trip through an intermediate FFI Object (Array/Map)
    # Interacts with: TypeTraitsBase (parent), ArrayObj, MapObj, ObjectPtr

# --- List-like types: all convert through ArrayObj ---

class TypeTraits_std_array(Generic[T, Nm]):
    """TypeTraits<std::array<T, Nm>>. Converts to/from Array with length check."""
    field_static_type_index = TypeIndex.kTVMFFIArray
    # Invariant: Nm > 0 (static_assert). Array length must equal Nm on read-back.
    # Interacts with: ArrayObj.Empty, ArrayObj.MutableBegin

class TypeTraits_std_vector(Generic[T]):
    """TypeTraits<std::vector<T>>. Converts to/from Array."""
    field_static_type_index = TypeIndex.kTVMFFIArray
    # Interacts with: ArrayObj.Empty, ArrayObj.MutableBegin

class TypeTraits_std_tuple(Generic[*Args]):
    """TypeTraits<std::tuple<Args...>>. Converts to/from Array with length + element type check."""
    field_static_type_index = TypeIndex.kTVMFFIArray
    # Invariant: Nm > 0 (static_assert). Array length must equal sizeof...(Args).
    # Interacts with: ArrayObj.Empty, ArrayObj.MutableBegin

# --- Optional: delegates to inner TypeTraits ---

class TypeTraits_std_optional(Generic[T]):
    """TypeTraits<std::optional<T>>. None maps to kTVMFFINone, value delegates to TypeTraits<T>."""
    # Invariant: TryCastFromAnyView returns optional<optional<T>> -- outer nullopt = cast failure,
    #            inner nullopt = the value is legitimately None
    # Interacts with: TypeTraits<T> (all methods delegated), TypeTraits<nullptr_t>

# --- Variant: tries alternatives in declaration order ---

class TypeTraits_std_variant(Generic[*Args]):
    """TypeTraits<std::variant<Args...>>. First matching alternative wins on read-back."""
    # Invariant: alternatives are tried in declaration order; first CheckAnyStrict match wins
    # Extension: order alternatives from most specific to least specific to avoid mis-dispatch
    # Interacts with: TypeTraits<Arg>::CheckAnyStrict for each alternative

# --- Map types: convert through MapObj ---

class TypeTraits_std_map(Generic[K, V]):
    """TypeTraits<std::map<K, V>>. Converts to/from Map."""
    field_static_type_index = TypeIndex.kTVMFFIMap
    # Interacts with: MapObj.CreateFromRange (friend access required)

class TypeTraits_std_unordered_map(Generic[K, V]):
    """TypeTraits<std::unordered_map<K, V>>. Converts to/from Map. Uses reserve()."""
    field_static_type_index = TypeIndex.kTVMFFIMap
    # Interacts with: MapObj.CreateFromRange (friend access required)

# --- Function: wraps through TypedFunction ---

class TypeTraits_std_function(Generic[Ret, *Args]):
    """TypeTraits<std::function<Ret(Args...)>>. Wraps to/from TypedFunction."""
    field_static_type_index = TypeIndex.kTVMFFIFunction
    storage_enabled: bool = False
    # Interacts with: TypeTraits<TypedFunction<Ret(Args...)>> (proxied entirely)
```

## Impact
- API: Additive only -- new header `include/tvm/ffi/extra/stl.h`. Users opt in by including it.
- Behavioral: None -- existing code is unaffected. The only change to existing files is a friend declaration in `map.h`.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **TypeTraits protocol** ([0002-ffi-any-value-system](../../.knowledge/design-records/0002-ffi-any-value-system.md)): extends the protocol with 8 new specializations. Uses `TypeTraitsBase`, `CopyToAnyView`/`MoveToAny`/`TryCastFromAnyView` contract.
- **ArrayObj** ([0006-ffi-containers](../../.knowledge/design-records/0006-ffi-containers.md)): used as the intermediate representation for all list-like STL types (`vector`, `array`, `tuple`). Uses `ArrayObj::Empty()` and `ArrayObj::MutableBegin()`.
- **MapObj** ([0006-ffi-containers](../../.knowledge/design-records/0006-ffi-containers.md)): used as intermediate for `std::map`/`std::unordered_map`. Uses `MapObj::CreateFromRange()` (requires new friend declaration).
- **TypedFunction** ([0004-ffi-function-system](../../.knowledge/design-records/0004-ffi-function-system.md)): `std::function` TypeTraits delegates entirely to `TypeTraits<TypedFunction<Sig>>`.
- **Module system** ([0011-ffi-module-system](../../.knowledge/design-records/0011-ffi-module-system.md)): tests exercise the `load_module` + `TVM_FFI_DLL_EXPORT_TYPED_FUNC` pattern.

Design elements this commit produces:
- **STL-FFI bridge layer** (`tvm/ffi/extra/stl.h`): an opt-in header that enables vanilla C++ STL types in FFI-exported function signatures. Establishes the pattern: STL types are always copied into/out of FFI objects (never stored directly in `TVMFFIAny`), mediated by `STLTypeTrait` base class.
- **`STLTypeMismatch` exception protocol**: internal sentinel exception for graceful fallback in nested STL type conversion (caught by `TryCastFromAnyView`, never propagates to user code).
- **`ListTemplate` / `MapTemplate` tag types**: internal dispatch tags enabling shared conversion logic for list-like and map-like STL types respectively.

## Usage Examples

**C++ side**: Define functions using STL types; the FFI bridge converts automatically.
```cpp
#include <tvm/ffi/extra/stl.h>
#include <tvm/ffi/function.h>

auto sum_row(std::optional<std::vector<std::array<int, 2>>> arg)
    -> std::tuple<bool, std::vector<int>> {
  if (arg) {
    std::vector<int> result;
    for (const auto& row : *arg)
      result.push_back(row[0] + row[1]);
    return {true, result};
  }
  return {false, {}};
}
TVM_FFI_DLL_EXPORT_TYPED_FUNC(sum_row, sum_row);
```

**Python side**: Call with native Python types; conversion is transparent.
```python
import tvm_ffi
mod = tvm_ffi.load_module("path/to/lib.so")
ok, sums = mod.sum_row([[1, 2], [3, 4]])   # -> (True, [3, 7])
result = mod.sum_row(None)                   # -> None
```
