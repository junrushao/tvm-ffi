# Add stl.h for transparent C++ STL container support in FFI exported functions
## TL;DR
- Introduces `include/tvm/ffi/extra/stl.h`, a new header providing `TypeTraits` specializations for `std::array`, `std::vector`, `std::optional`, `std::variant`, `std::tuple`, `std::map`, `std::unordered_map`, and `std::function`, enabling these types as parameters and return types in FFI-exported C++ functions.
- Conversion strategy: STL types are always marshalled through existing TVM FFI containers (`ArrayObj` for sequences/tuples, `MapObj` for maps, `Function` for callables) at the ABI boundary. No new wire types are introduced.
- Adds `friend struct TypeTraits` to `MapObj` to allow the STL map traits to access `MapObj::CreateFromRange`.

## Key Exports

```python
# === New base types (internal, in tvm::ffi::details) ===

class STLTypeMismatch(Exception):
    """Sentinel exception for soft-failure during nested STL type conversion.
    Caught internally by TryCastFromAnyView to return nullopt instead of propagating."""
    # Interacts with: every STL TypeTraits::TryCastFromAnyView
    # Invariant: never escapes to user code -- always caught at the TryCast boundary

class STLTypeTrait:
    """Base for all STL TypeTraits specializations. Provides shared helpers."""
    storage_enabled: bool = False  # STL types cannot be stored directly in containers
    # Invariant: STL types are always copied into/from TVM FFI objects at the boundary
    # Extension: derive from this to add new STL type support

    @staticmethod
    def MoveToAnyImpl(src: ObjectPtr[T], result: Ptr[TVMFFIAny]) -> None: ...
        # Moves an ObjectPtr into a TVMFFIAny slot (transfers ownership)
        # Interacts with: ObjectUnsafe.MoveObjectPtrToTVMFFIObjectPtr

    @staticmethod
    def CopyFromAnyImpl(src: Ptr[TVMFFIAny]) -> ObjectPtr[T]: ...
        # Extracts non-owning ObjectPtr from a TVMFFIAny slot
        # Interacts with: ObjectUnsafe.ObjectPtrFromUnowned

    @staticmethod
    def ConstructFromAny(value: Any) -> T: ...
        # Converts Any to T via TryCastFromAnyView; raises STLTypeMismatch on failure
        # Invariant: soft-failure path (exception, not hard error) for composability

# Sentinel tag types for CRTP base selection:
class ListTemplate: ...   # Tag for sequence-like STL types (array, vector, tuple)
class MapTemplate: ...    # Tag for map-like STL types (map, unordered_map)

# === TypeTraits specializations (all in tvm::ffi) ===

class TypeTraits_ListTemplate:
    """CRTP base for sequence-like STL types. Provides CopyToArray/MoveToArray/CopyToTuple/MoveToTuple."""
    field_static_type_index: int = kTVMFFIArray
    # Interacts with: ArrayObj.Empty, ArrayObj.MutableBegin

class TypeTraits_MapTemplate:
    """CRTP base for map-like STL types. Provides CopyToMap/MoveToMap/ConstructMap."""
    field_static_type_index: int = kTVMFFIMap
    # Interacts with: MapObj.CreateFromRange, MapObj iterator

# --- Concrete specializations ---

class TypeTraits_std_array(Generic[T, Nm]):
    """TypeTraits<std::array<T, Nm>>"""
    # CopyToAnyView/MoveToAny: converts to ArrayObj of size Nm
    # TryCastFromAnyView: checks type_index==kTVMFFIArray AND size==Nm, then element-wise ConstructFromAny
    # Invariant: Nm > 0 (zero-length array rejected by static_assert)

class TypeTraits_std_vector(Generic[T]):
    """TypeTraits<std::vector<T>>"""
    # CopyToAnyView/MoveToAny: converts to ArrayObj
    # TryCastFromAnyView: checks type_index==kTVMFFIArray, then element-wise ConstructFromAny

class TypeTraits_std_optional(Generic[T]):
    """TypeTraits<std::optional<T>>"""
    # CopyToAnyView/MoveToAny: delegates to TypeTraits<T> if has_value, else writes kTVMFFINone
    # TryCastFromAnyView: kTVMFFINone -> nullopt, else delegates to TypeTraits<T>
    # Invariant: mirrors Optional<T> FFI semantics (None maps to nullopt)

class TypeTraits_std_variant(Generic[*Args]):
    """TypeTraits<std::variant<Args...>>"""
    # CopyToAnyView/MoveToAny: std::visit, delegates to active alternative's TypeTraits
    # TryCastFromAnyView: tries each alternative in declaration order, returns first match
    # Invariant: first-match semantics -- order of variant alternatives matters for ambiguous types
    # Interacts with: TypeTraits<T>::CheckAnyStrict for each alternative

class TypeTraits_std_tuple(Generic[*Args]):
    """TypeTraits<std::tuple<Args...>>"""
    # CopyToAnyView/MoveToAny: converts to ArrayObj of size sizeof...(Args)
    # TryCastFromAnyView: checks type_index==kTVMFFIArray AND size==sizeof...(Args), then per-element ConstructFromAny
    # Invariant: sizeof...(Args) > 0 (zero-length tuple rejected by static_assert)

class TypeTraits_std_map(Generic[K, V]):
    """TypeTraits<std::map<K, V>>"""
    # CopyToAnyView/MoveToAny: converts to MapObj via CreateFromRange
    # TryCastFromAnyView: checks type_index==kTVMFFIMap, then per-entry ConstructFromAny
    # Interacts with: MapObj iterator (key-value pairs)

class TypeTraits_std_unordered_map(Generic[K, V]):
    """TypeTraits<std::unordered_map<K, V>>"""
    # Same as std_map but with CanReserve=True for pre-allocation

class TypeTraits_std_function(Generic[Ret, *Args]):
    """TypeTraits<std::function<Ret(Args...)>>"""
    # CopyToAnyView/MoveToAny: wraps in TypedFunction, delegates to its TypeTraits
    # TryCastFromAnyView: extracts TypedFunction, wraps in std::function lambda
    # Interacts with: TypedFunction<Ret(Args...)>, TypeTraits<TypedFunction>
```

## Impact
- API: Additive only. Users can now use STL types in `TVM_FFI_DLL_EXPORT_TYPED_FUNC` signatures. No existing APIs changed.
- Behavioral: None -- existing code paths unaffected unless `stl.h` is included.
- Flags/config: None.
- Data formats/schemas: TypeSchema() strings added for all new specializations (e.g., `{"type":"std::vector","args":[...]}`), extending the schema vocabulary.

## Design Elements
Design elements this commit consumes:
- **TypeTraits protocol** ([0006-type-traits.md](../designs/0006-type-traits.md)): All STL specializations implement the full `TypeTraits<T>` interface (`CopyToAnyView`, `MoveToAny`, `TryCastFromAnyView`, `TypeStr`, `TypeSchema`).
- **ArrayObj** ([0007-containers.md](../designs/0007-containers.md)): Used as the wire format for `std::array`, `std::vector`, `std::tuple`. Uses `ArrayObj::Empty()` and `ArrayObj::MutableBegin()`.
- **MapObj** ([0007-containers.md](../designs/0007-containers.md)): Used as the wire format for `std::map`, `std::unordered_map`. Uses `MapObj::CreateFromRange` (required `friend struct TypeTraits` addition).
- **TypedFunction** ([0004-function-system.md](../designs/0004-function-system.md)): Used as proxy for `std::function` conversion.
- **ObjectUnsafe** ([0002-object-system.md](../designs/0002-object-system.md)): `MoveObjectPtrToTVMFFIObjectPtr`, `ObjectPtrFromUnowned` used in `STLTypeTrait` base.
- **Module system** ([0011-module-system.md](../designs/0011-module-system.md)): Tests use `load_module` to exercise cross-language round-trip.

Design elements this commit produces:
- **STL-to-FFI bridging layer** (`stl.h`): A new optional extension header that bridges C++ STL types to TVM FFI containers. Not a core component -- explicitly marked as "extra" and documented as second-choice to native FFI containers.
- **STLTypeTrait base class**: Internal CRTP base providing shared conversion helpers (`MoveToAnyImpl`, `CopyFromAnyImpl`, `ConstructFromAny`).
- **STLTypeMismatch sentinel exception**: Internal soft-failure mechanism enabling composable nested type conversion with graceful fallback to `std::nullopt`.

## Usage Examples

**Context**: Defining a C++ function using STL types and calling it from Python via the module system.

C++ side (`test_stl.cc`):
```cpp
#include <tvm/ffi/extra/stl.h>
#include <tvm/ffi/function.h>

auto test_vector(std::optional<std::vector<std::array<int, 2>>> arg)
    -> std::optional<std::vector<int>> {
  if (arg) {
    auto result = std::vector<int>{};
    result.reserve(arg->size());
    for (const auto& row : *arg) {
      result.push_back(std::accumulate(row.begin(), row.end(), 0));
    }
    return result;
  } else {
    return std::nullopt;
  }
}
TVM_FFI_DLL_EXPORT_TYPED_FUNC(test_vector, test_vector);
```

Python side:
```python
import tvm_ffi
mod = tvm_ffi.load_module(output_lib_path)
mod.test_vector([[1, 2], [3, 4]])  # returns [3, 7] (Array -> vector<array<int,2>> -> vector<int> -> Array)
mod.test_vector(None)              # returns None (kTVMFFINone -> nullopt -> nullopt -> kTVMFFINone)
```
