# Add stl.h header for vanilla C++ STL support in FFI
## TL;DR
- Adds `include/tvm/ffi/extra/stl.h` (649 lines): enables automatic conversion between C++ STL types (`std::vector`, `std::array`, `std::tuple`, `std::optional`, `std::variant`) and TVM FFI types in exported functions.
- Users can write functions using standard C++ types and export them via `TVM_FFI_DLL_EXPORT_TYPED_FUNC` with automatic marshalling.
- Adds `Map::keys()` method to `container/map.h`.
- Includes test files (`test_stl.cc`, `test_stl.py`).

## Impact
- API: New header `tvm/ffi/extra/stl.h` with STL <-> FFI conversion traits
- Flags/config: None
- Data formats/schemas: None
