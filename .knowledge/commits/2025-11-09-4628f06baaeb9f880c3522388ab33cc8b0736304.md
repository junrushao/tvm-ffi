# Replace runtime __module__ patching with --module-name Cython build flag for correct class module paths

## TL;DR
- Removes `__module__` patching logic in `python/tvm_ffi/__init__.py` (14 lines deleted) introduced in PR #177.
- Adds `--module-name tvm_ffi.core` build-time flag to the Cython compilation in `CMakeLists.txt` and `pyproject.toml`, which sets the correct module name at build time — more reliable and works in older Python/Cython.
- Updates import paths in `_dtype.py`, `access_path.py`, `container.py`, `cpp/extension.py`, and Cython files accordingly.

## Key Exports

```python
# Before: __init__.py patched __module__ at runtime (unreliable in older Cython/Python)
# After: Cython compiled with --module-name=tvm_ffi.core — works at all versions
# The _CYTHON_MODULE_NAME variable set accordingly at build time
```

## Impact
- API: none (internal module naming)
- Behavioral: Cython class `__module__` is now correctly `tvm_ffi.core` on all Python/Cython versions.
- Flags/config: CMake/pyproject.toml build flags gain `--module-name`.
- Data formats/schemas: none
