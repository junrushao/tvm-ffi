# Specify --module-name for Cython builds, remove runtime __module__ patching
## TL;DR
- Adds `--module-name` flag when building Cython extensions so that generated classes have correct `__module__` attributes at compile time.
- Removes runtime `__module__` patching logic from `python/tvm_ffi/__init__.py` that was a workaround for the missing compile-time module name.

None (build system cleanup)

## Impact
- API: none
- ABI: none
- Behavioral: Cython class `__module__` attributes are now set correctly at compile time rather than being patched at runtime.
- Flags/config: `--module-name tvm_ffi.cython.core` passed to Cython compiler.
