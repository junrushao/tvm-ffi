# Use --module-name in Cython build; remove _update_module hack; doc/build cleanups
## TL;DR
- Adds `--module-name "tvm_ffi.core"` to the Cython build command in `CMakeLists.txt`, so generated classes report the correct `__module__` attribute natively.
- Removes the `_update_module()` workaround from `python/tvm_ffi/__init__.py` that manually patched `__module__` after import.
- Pins `cython>=3.0` in both dev dependencies and build-system requires.
- Various docstring fixes replacing `` ``...`` `` with `:class:`, `:py:meth:`, `:c:macro:` Sphinx roles for proper cross-referencing.
