# Specify --module-name for Cython build, remove _update_module workaround, fix docstrings
## TL;DR
- Adds `--module-name "tvm_ffi.core"` to the Cython compilation command in CMakeLists.txt so Cython-generated classes natively report `tvm_ffi.core` as their `__module__`, eliminating the need for a runtime workaround.
- Removes the `_update_module()` function from `python/tvm_ffi/__init__.py` which previously iterated `__all__` to patch `__module__` attributes post-import (did not work on older Python/Cython versions).
- Bumps Cython minimum version to `>=3.0` in both `[build-system].requires` and `[dependency-groups].dev`.
- Converts docstrings across several Python and Cython files from double-backtick literals to proper Sphinx cross-references (`:py:class:`, `:py:meth:`, `:c:macro:`, external URLs).
