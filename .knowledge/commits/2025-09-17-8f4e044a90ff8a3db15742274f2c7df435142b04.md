# Enable ruff ANN rule and annotate all public Python APIs

## TL;DR

- Enables `ANN` (flake8-annotations) in `pyproject.toml` ruff config, enforcing type annotations on all Python function signatures project-wide.
- Adds return types, parameter types, and appropriate `from typing import ...` imports to every public module in `python/tvm_ffi/`, all test files, examples, and lint scripts.
- Fixes a latent bug in `StreamContext.__enter__` and `TorchStreamContext.__enter__`: neither returned `self`, making the `as` clause in `with use_raw_stream(...) as ctx:` silently yield `None`.

## Impact

- API: None — all signatures are source-compatible. Annotations are additive at runtime.
- Behavioral: `StreamContext.__enter__` and `TorchStreamContext.__enter__` now correctly return `self`, fixing the `with ... as ctx:` pattern for consumers who capture the context manager result.
- Flags/config: `pyproject.toml` — `ANN` rule uncommented in `[tool.ruff.lint] select`; all subsequent Python commits in this repo must include type annotations.

## Usage Examples

Bugfix pattern — `StreamContext.__enter__` return value:

```python
# BEFORE (broken): ctx is None because __enter__ returned nothing
with tvm_ffi.use_raw_stream(device, stream) as ctx:
    assert ctx is None  # bug: ctx is None, not the StreamContext

# AFTER (fixed): ctx is the StreamContext instance
with tvm_ffi.use_raw_stream(device, stream) as ctx:
    assert isinstance(ctx, tvm_ffi.stream.StreamContext)
```
