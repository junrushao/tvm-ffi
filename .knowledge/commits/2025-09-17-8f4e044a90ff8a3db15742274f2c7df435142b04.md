# Enable flake8-annotations (ANN) ruff rule and add type annotations to all public Python APIs
## TL;DR
- Uncomments `"ANN"` in `pyproject.toml` `[tool.ruff.lint] select`, enabling flake8-annotations enforcement across the Python codebase.
- Adds return type annotations and parameter type hints to every public function and method across 36 files (`python/tvm_ffi/`, `tests/`, `examples/`, `docs/`, `tests/scripts/`).
- Fixes a behavioral bug: `StreamContext.__enter__` and `TorchStreamContext.__enter__` now return `self`, restoring correct context manager protocol (previously returned `None`).

## Key Exports
None -- this commit does not introduce new public APIs. It annotates existing APIs with type hints.

The only behavioral change is the `return self` fix in `stream.py`:

```python
# Before (broken context manager protocol):
class StreamContext:
    def __enter__(self):
        self.prev_stream = core._env_set_current_stream(...)
        # implicitly returns None

# After (correct):
class StreamContext:
    def __enter__(self) -> "StreamContext":
        self.prev_stream = core._env_set_current_stream(...)
        return self  # <-- fixes `with use_raw_stream(...) as ctx:`
```

## Impact
- API: None -- no signatures changed, only annotations added.
- Behavioral: `StreamContext.__enter__` and `TorchStreamContext.__enter__` now return `self`. Code using `with use_raw_stream(dev, s) as ctx:` previously got `ctx=None`; now gets the `StreamContext` instance. Same for `TorchStreamContext`.
- Flags/config: `pyproject.toml` `[tool.ruff.lint] select` now includes `"ANN"` -- all future Python code must have type annotations on public functions or ruff will reject it.
- Data formats/schemas: None.
