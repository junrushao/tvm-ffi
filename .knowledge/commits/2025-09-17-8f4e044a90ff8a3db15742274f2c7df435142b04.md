# Enable ANN (flake8-annotations) Ruff rule and add type annotations across codebase
## TL;DR
- Uncomments the `"ANN"` (flake8-annotations) rule in `pyproject.toml` Ruff lint config, enforcing type annotations on public API functions and methods.
- Adds type annotations across ~35 Python files in `python/tvm_ffi/`, `tests/python/`, `examples/`, and `tests/lint/` to satisfy the new rule, including return types, parameter types, and `self`/`cls` annotations.

## Impact
- API: none (type annotations are documentation-only, no runtime behavioral change)
- Flags/config: `"ANN"` rule now active in `[tool.ruff.lint]` select list, enforcing annotations on all public APIs.
- Data formats/schemas: none
