# Enable flake8-annotations (ANN) ruff rule and add type annotations to all public Python APIs
## TL;DR
- Uncomments the `"ANN"` rule in `pyproject.toml` `[tool.ruff.lint]` select list, enabling flake8-annotations enforcement across the Python codebase.
- Adds return type annotations and parameter type annotations to every public function, method, and test function across 36 files (library code, examples, tests, lint scripts, benchmarks).
- Fixes two latent bugs where `StreamContext.__enter__` and `TorchStreamContext.__enter__` were missing `return self`, causing `with ... as ctx` bindings to receive `None`.

## Key Exports
None. This commit does not introduce new public API surface. It annotates existing signatures.

Notable annotation patterns applied:

| Module | Representative signature change |
|---|---|
| `registry.py` | `register_global_func(func_name: str \| Callable[..., Any], f: Optional[Callable[..., Any]] = None, override: bool = False) -> Any` |
| `registry.py` | `get_global_func(name: str, allow_missing: bool = False) -> Optional[core.Function]` |
| `container.py` | `Map.get(self, key: Any, default: Any \| None = None) -> Any` |
| `module.py` | `Module.get_function(self, name: str, query_imports: bool = False) -> core.Function` |
| `_tensor.py` | `device(device_type: Union[str, int, DLDeviceType], index: Optional[int] = None) -> Device` |
| `stream.py` | `StreamContext.__enter__(self) -> "StreamContext"` (+ added missing `return self`) |

## Impact
- API: None. Annotations are additive and do not change runtime behavior.
- Behavioral: Two bug fixes in `python/tvm_ffi/stream.py` -- `StreamContext.__enter__` and `TorchStreamContext.__enter__` now return `self` so `with use_raw_stream(...) as ctx:` and `with use_torch_stream(...) as ctx:` correctly bind the context variable.
- Flags/config: `pyproject.toml` lint configuration changed -- `"ANN"` rule is now enforced. All future Python code must include type annotations on public function parameters and return types.
- Data formats/schemas: None.

## Usage Examples
None. This is a chore/convention commit. The behavioral fix in `stream.py` is best illustrated by:

```python
# Before (broken): ctx was None
with use_raw_stream(device, stream_handle) as ctx:
    assert ctx is None  # bug

# After (fixed): ctx is the StreamContext instance
with use_raw_stream(device, stream_handle) as ctx:
    assert isinstance(ctx, StreamContext)
```
