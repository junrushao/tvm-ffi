# Enable ruff ANN rule and add return/parameter type annotations across all Python code
## TL;DR
- Enables the `ANN` (flake8-annotations) rule set in `pyproject.toml` `[tool.ruff.lint]`, enforcing type annotations on all public Python APIs going forward.
- Adds parameter and return type annotations to every public function/method across `python/tvm_ffi/`, `tests/python/`, `tests/lint/`, `examples/`, `tests/scripts/`, and `docs/conf.py` (37 files, ~294 insertions / ~236 deletions).
- Fixes a latent bug in `StreamContext.__enter__` and `TorchStreamContext.__enter__` which did not `return self`, making `with ... as ctx:` bind `ctx` to `None`.

## Impact
- API: None -- no signatures changed at runtime; annotations are metadata only.
- ABI: None.
- Behavioral: `StreamContext.__enter__` and `TorchStreamContext.__enter__` now return `self`, fixing `with ... as ctx:` usage. Previously `ctx` would have been `None`.
- Flags/config: The `ANN` ruff rule set is now enforced. All future Python code must include type annotations on public API parameters and return types.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Python binding layer** (`.knowledge/designs/0014-python-bindings.md`): The pure-Python wrapper modules (`registry.py`, `container.py`, `module.py`, `error.py`, `stream.py`, etc.) that provide idiomatic Python APIs atop the Cython core.
- **Ruff lint configuration** (`pyproject.toml`): The project's lint rule set that governs Python code style, extended here with the `ANN` rule family.

Design elements this commit produces:
- **Type annotation convention (enforcement)**: The `ANN` rule set in ruff is now enabled, establishing an enforced project-wide convention that all public Python functions must have parameter and return type annotations. This is a linting convention, not a new design element per se, but it establishes a quality gate for all future Python contributions.

## Usage Examples
None -- this commit adds annotations to existing code rather than introducing new APIs. The `StreamContext.__enter__` fix enables correct usage of the `as` clause:

```python
# Before (broken): ctx was None
with StreamContext(device, stream) as ctx:
    assert ctx is None  # bug

# After (fixed): ctx is the StreamContext instance
with StreamContext(device, stream) as ctx:
    assert isinstance(ctx, StreamContext)
```
