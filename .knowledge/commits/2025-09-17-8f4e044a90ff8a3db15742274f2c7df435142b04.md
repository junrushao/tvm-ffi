# Enable ruff ANN rules and add type annotations to all Python public APIs

## TL;DR
- Uncomments the `ANN` (flake8-annotations) rule in `pyproject.toml` to enforce return-type and parameter-type annotations on all Python code.
- Adds explicit type annotations (return types, parameter types) to every public function, method, and property across `python/tvm_ffi/`, `tests/python/`, `examples/`, `docs/conf.py`, and `tests/lint/`.
- Fixes two minor bugs in `stream.py`: `StreamContext.__enter__` and `TorchStreamContext.__enter__` now correctly `return self`, enabling `as` clauses in `with` statements.

## Key Exports

None -- this commit does not introduce new public API symbols. It adds type annotations to existing symbols. The two `return self` fixes in `stream.py` are behavioral corrections rather than new exports.

## Impact
- API: None -- all signatures are unchanged; only annotations are added.
- Behavioral: `StreamContext.__enter__` and `TorchStreamContext.__enter__` now return `self`, enabling `with use_raw_stream(...) as ctx:` usage. Previously the return value was `None`.
- Flags/config: `ANN` ruff rule is now enforced project-wide. All future Python code must include type annotations on public APIs.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- Python bindings layer (0012-python-bindings): All annotated functions belong to the `tvm_ffi` Python package.
- Container system (0006-containers): `Array`, `Map`, `KeysView`, `ValuesView`, `ItemsView` in `container.py` gain annotations.
- Module system (0011-module-system): `Module` class methods in `module.py` gain annotations.
- Function system (0003-function-system): `register_global_func`, `get_global_func` in `registry.py` gain annotations.
- Error propagation (0004-error-propagation): `register_error`, `TracebackManager` methods in `error.py` gain annotations.
- Load-inline (0013-load-inline): `_run_command_in_dev_prompt` in `load_inline.py` gains annotations.

Design elements this commit produces:
- Lint enforcement convention: `ANN` ruff rule is now active -- all Python files must have type annotations on functions and methods.

## Usage Examples

Before (StreamContext):
```python
# Bug: __enter__ returned None, so `ctx` was None
with use_raw_stream(dev, stream) as ctx:
    assert ctx is None  # broken
```

After (StreamContext):
```python
# Fixed: __enter__ returns self
with use_raw_stream(dev, stream) as ctx:
    assert isinstance(ctx, StreamContext)  # works
```
