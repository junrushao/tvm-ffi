# Fix Cython None-arg packing: zero-initialize v_int64 in make_args for kTVMFFINone

## TL;DR
- In the Cython `make_args` function (`function.pxi`), the `None` branch only set `type_index = kTVMFFINone` but left `v_int64` uninitialized, violating the ABI invariant that None-valued `TVMFFIAny` slots must have `v_int64 = 0`.
- Added `out[i].v_int64 = 0` after setting the type index, aligning Cython behavior with the C++ `AnyView` default constructor and `reset()` method.

## Key Exports
None -- no new API surface. Single-line bugfix to existing internal function.

## Impact
- API: none
- Behavioral: `None` arguments passed from Python through the Cython FFI bridge now have deterministic `v_int64 = 0` instead of whatever garbage resided in the stack-allocated `TVMFFIAny` array. This prevents potential misinterpretation by C++ callers that inspect the value union of a `kTVMFFINone`-typed `TVMFFIAny`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TVMFFIAny layout** ([.knowledge/designs/0001-c-abi.md](../designs/0001-c-abi.md)): The 16-byte `{type_index, zero_padding, v_int64}` struct. The invariant that `v_int64 = 0` when `type_index = kTVMFFINone` is documented in C++ (`any.h` lines 60-64) but was not enforced in the Cython `make_args` path.
- **Any/AnyView reset invariant** ([.knowledge/designs/0003-any-system.md](../designs/0003-any-system.md)): C++ `AnyView()` constructor and `AnyView::reset()` both set `type_index = kTVMFFINone`, `zero_padding = 0`, `v_int64 = 0`. This commit brings the Cython `None` handling into alignment.
- **Cython packed-function calling convention** (`python/tvm_ffi/cython/function.pxi`): `make_args` converts a Python tuple of arguments into a `TVMFFIAny*` array for the packed calling convention.

Design elements this commit produces:
- None -- purely corrective.

## Usage Examples
**Before** (incorrect -- left `v_int64` with stale stack data):
```python
# In Cython make_args, the None branch was:
elif arg is None:
    out[i].type_index = kTVMFFINone
    # v_int64 NOT zeroed -- contains whatever was in the stack-allocated TVMFFIAny
```

**After** (correct -- deterministic zero):
```python
elif arg is None:
    out[i].type_index = kTVMFFINone
    out[i].v_int64 = 0  # matches C++ AnyView() / reset() invariant
```
