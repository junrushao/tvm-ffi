# Fix uninitialized value union in Cython make_args for None arguments
## TL;DR
- Zeroes `v_int64` when packing `None` into a `TVMFFIAny` slot in the Cython `make_args` function, restoring the zero-padding invariant required by `same_as()` and hashing.
- Without this fix, stale data from a previous use of the `out[i]` slot could persist in the 8-byte value union, causing non-deterministic comparisons or hash values for None-typed arguments.

## Key Exports
None — no new API surface. One-line bugfix to existing internal Cython function.

## Impact
- API: none
- Behavioral: `None` arguments passed through the Cython FFI bridge now have deterministic `same_as()` and hashing behavior. Previously, stale union bytes could cause two `None` values to compare unequal or hash differently.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TVMFFIAny 16-byte layout and zero-padding invariant** (design record `0001-any-anyview-value-system`): The invariant that non-small-string types must have `zero_padding = 0` and `v_int64 = 0` when `type_index = kTVMFFINone`. The C++ `AnyView::reset()` and `Any::reset()` enforce this, but the Cython `make_args` path was missing the `v_int64 = 0` assignment.
- **kTVMFFINone type index** (`include/tvm/ffi/c_api.h`): The sentinel type index indicating no value.
- **make_args Cython function** (`python/tvm_ffi/cython/function.pxi`): The argument packing function that converts Python values into `TVMFFIAny` slots for FFI calls.

Design elements this commit produces: none — purely restorative fix.

## Usage Examples
Before (broken): `None` packed with stale union bytes:
```python
# In make_args, when arg is None:
out[i].type_index = kTVMFFINone
# v_int64 still contains whatever was in out[i] from a previous iteration
# -> same_as() may fail when comparing two None values
```

After (fixed): `None` packed with zeroed union:
```python
# In make_args, when arg is None:
out[i].type_index = kTVMFFINone
out[i].v_int64 = 0  # Satisfies zero-padding invariant
# -> same_as() and hashing are now well-defined for None
```
