# Fix uninitialized v_int64 when packing None in Cython make_args
## TL;DR
- In the Cython `make_args` function (`function.pxi`), the `None` branch set `type_index = kTVMFFINone` but left `v_int64` uninitialized, violating the `TVMFFIAny` zero-padding invariant.
- Added `out[i].v_int64 = 0` after setting `type_index` for `None` arguments, ensuring the 8-byte value union and the 4-byte `zero_padding` field are both zeroed.

## Key Exports
None -- no new API surface; single-line fix inside existing `make_args` helper.

## Impact
- API: none
- Behavioral: `None` arguments passed from Python via Cython now have deterministic zero bits in the value union. Before this fix, stale stack data could leak into `v_int64`/`zero_padding`, causing incorrect `same_as()` or `AnyEqual` comparisons and non-deterministic structural hashing.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TVMFFIAny layout** (`c_api.h` L188-217, `.knowledge/design-records/0001-ffi-c-abi.md`): the 16-byte `{type_index, zero_padding|small_str_len, value-union}` struct. The invariant that `zero_padding` must be 0 for all non-small-string types is documented in `c_api.h` L195 and design record 0001.
- **kTVMFFINone type index** (`.knowledge/design-records/0001-ffi-c-abi.md`): type index 0 representing null/None.
- **Any value comparison semantics** (`.knowledge/design-records/0002-ffi-any-value-system.md`): `same_as()` and `AnyEqual` compare `type_index` + `v_int64` bitwise -- stale bits in the value union cause false negatives.

Design elements this commit produces:
- None -- purely restores an existing invariant.

## Usage Examples
Before (bug): passing `None` from Python left `v_int64` with stack garbage:
```python
# Cython make_args, before fix:
elif arg is None:
    out[i].type_index = kTVMFFINone
    # v_int64 is UNINITIALIZED -- stale stack data
    # -> same_as() may fail when comparing two "None" AnyView values
```

After (fix): `v_int64 = 0` ensures deterministic zero bits:
```python
# Cython make_args, after fix:
elif arg is None:
    out[i].type_index = kTVMFFINone
    out[i].v_int64 = 0  # zeroes both zero_padding and value union
```
