# Consolidate torch_c_dlpack CI workflows into single unified file
## TL;DR
- Merged the standalone Windows build workflow (`.github/workflows/torch_c_dlpack_windows.yml`) into the unified `.github/workflows/torch_c_dlpack.yml`.
- Deleted the now-redundant `torch_c_dlpack_windows.yml` file.
- Updated the `upload_pypi` job dependency list to include `build_wheels_windows`, ensuring all three platforms (Linux, Windows, macOS) complete before publishing to PyPI.

## Key Exports
N/A -- infrastructure

## Impact
- API: none
- Behavioral: The `upload_pypi` job now gates on `build_wheels_windows` in addition to `build_wheels_linux`, `build_wheels_macos`, and `build_source`. Previously the Windows wheels were published by a separate workflow's own `upload_pypi` job; now all platforms share a single publish step.
- Flags/config: none
- Data formats/schemas: none
