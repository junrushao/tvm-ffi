# Introduce __tvm_ffi_env_stream__ protocol and rename TVMFFIEnvSetStream to TVMFFIEnvSetCurrentStream
## TL;DR
- Adds a `__tvm_ffi_env_stream__` dunder protocol allowing external tensor-like objects to provide a stream handle for automatic stream context exchange when passed to TVM FFI functions.
- Renames `TVMFFIEnvSetStream` to `TVMFFIEnvSetCurrentStream` across C header, C++ implementation, and Cython bindings (breaking C ABI change).
- Adds DLPack device type enum declarations to Cython `base.pxi` to enable device-type checks in the new protocol path.

| Old name | New name |
|----------|----------|
| `TVMFFIEnvSetStream` | `TVMFFIEnvSetCurrentStream` |

## Key Exports

**Protocols**:
- `__tvm_ffi_env_stream__(self) -> int`: A dunder method that tensor-like objects implement to return the raw stream handle (as an integer) for the device context. Called by the Cython `make_args` function during FFI argument marshalling when the object also implements `__dlpack__` and the device is non-CPU.

**Functions (renamed)**:
- `TVMFFIEnvSetCurrentStream(int32_t device_type, int32_t device_id, TVMFFIStreamHandle stream, TVMFFIStreamHandle* opt_out_original_stream) -> int`: Renamed from `TVMFFIEnvSetStream`. Sets the thread-local current stream for a device. Returns 0 on success.

**Types/Classes (test-only)**:
- `DLTensorTestWrapper` (Cython cdef class in `tensor.pxi`): Wraps a `Tensor`, exposes `__tvm_ffi_env_stream__()` (returns current stream for the tensor's device), `__dlpack__()`, and `__dlpack_device__()`. Test-only utility.

**Constants (newly declared in Cython)**:
- DLPack device type enum values (`kDLCPU=1`, `kDLCUDA=2`, ..., `kDLTrn=18`) from `dlpack/dlpack.h`, declared in `base.pxi` for use in `make_args` device-type comparison.

## Impact
- API: **Breaking C ABI rename** — `TVMFFIEnvSetStream` -> `TVMFFIEnvSetCurrentStream`. All direct C callers of the old symbol must update. Impact is limited to the TVM toolchain (generated code, Cython bindings) since end users do not call this C function directly.
- Behavioral: When a `__dlpack__`-compatible argument also implements `__tvm_ffi_env_stream__`, the Cython function calling path now automatically captures and sets the stream context before the FFI call, and restores it afterward. Previously, only `torch.Tensor` with `__cuda_stream__` was handled; now any framework can participate via the generic protocol.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Stream context API** (`TVMFFIEnvSetCurrentStream`/`TVMFFIEnvGetCurrentStream` in `extra/c_env_api.h`): The Cython call path uses these to save/restore streams around FFI calls. See [ADR 0010](../ADRs/0010-extra-api-isolation.md).
- **DLPack protocol** (`__dlpack__`, `__dlpack_device__`): The `make_args` function already converts `__dlpack__`-implementing objects; this commit extends that path with stream capture.
- **`TVMFFITensorGetDLTensorPtr`**: Used to inspect device type/id from the converted tensor to decide whether stream capture is needed.
- **Env API naming convention** ([ADR 0013](../ADRs/0013-env-api-naming-convention.md)): The rename aligns with the "Current" infix convention used by `TVMFFIEnvGetCurrentStream`.

Design elements this commit produces:
- **`__tvm_ffi_env_stream__` protocol**: A new cross-framework convention for stream exchange. Any tensor-like object that implements `__dlpack__` and `__tvm_ffi_env_stream__` can participate in automatic stream context propagation through TVM FFI calls. This is a new extension point documented in the Cython code comments.

## Usage Examples

**Implementing the `__tvm_ffi_env_stream__` protocol on a custom tensor class:**
```python
class MyFrameworkTensor:
    """A tensor from an external framework that exposes DLPack + stream."""

    def __dlpack__(self, *, stream=None):
        # Return DLPack capsule
        return self._internal_dlpack(stream=stream)

    def __dlpack_device__(self):
        return (self.device_type, self.device_id)

    def __tvm_ffi_env_stream__(self):
        # Return the raw stream handle as an integer
        # This stream will be set via TVMFFIEnvSetCurrentStream
        # before the TVM FFI function executes
        return int(self._get_current_stream())

# When passed to a TVM FFI function, the stream is automatically exchanged:
# tvm_func(my_tensor)  # stream captured and set before call, restored after
```

**End-to-end flow in Cython `make_args` (pseudocode):**
```python
# In make_args, for each arg with __dlpack__:
ffi_arg = from_dlpack(arg)
dltensor = get_dltensor_ptr(ffi_arg)
if dltensor.device.device_type != kDLCPU and no_stream_yet:
    if hasattr(arg, "__tvm_ffi_env_stream__"):
        ctx_dev_type = dltensor.device.device_type
        ctx_dev_id = dltensor.device.device_id
        ctx_stream = arg.__tvm_ffi_env_stream__()
# Later in FuncCall3:
# TVMFFIEnvSetCurrentStream(ctx_dev_type, ctx_dev_id, ctx_stream, &prev_stream)
# ... call function ...
# TVMFFIEnvSetCurrentStream(ctx_dev_type, ctx_dev_id, prev_stream, NULL)  # restore
```
