# Introduce __tvm_ffi_env_stream__ protocol for generic tensor stream exchange
## TL;DR
- Adds a `__tvm_ffi_env_stream__` dunder protocol so non-TVM tensors (e.g., from external frameworks) can supply the device stream to use when calling TVM FFI functions via the auto-DLPack path.
- Renames `TVMFFIEnvSetStream` to `TVMFFIEnvSetCurrentStream` in C header, C++ implementation, and all Cython call sites.
- Adds `DLTensorTestWrapper` Cython class and benchmark entries for testing the new protocol.

| Old name | New name |
|---|---|
| `TVMFFIEnvSetStream` | `TVMFFIEnvSetCurrentStream` |

## Key Exports

```python
# --- New protocol (duck-typed dunder method on any object passed to FFI) ---

# Any object that implements __dlpack__ can also implement this:
def __tvm_ffi_env_stream__(self) -> int:
    """Return the device stream handle (as an integer) that TVM FFI should
    set via TVMFFIEnvSetCurrentStream before calling the packed function.
    # Interacts with: TVMFFIEnvSetCurrentStream (C ABI), make_args (Cython),
    #   FuncCall3/FuncCall (stream save/restore around FFI call)
    # Invariant: only consulted for non-CPU devices when no prior stream
    #   context has been set (ctx_dev_type[0] == -1)
    # Extension: any framework tensor class can implement this to participate
    #   in automatic stream forwarding
    """
    ...

# --- Renamed C ABI function ---

# Was: TVMFFIEnvSetStream
def TVMFFIEnvSetCurrentStream(
    device_type: int32,
    device_id: int32,
    stream: TVMFFIStreamHandle,      # opaque void*
    opt_out_original_stream: ptr[TVMFFIStreamHandle] | None,
) -> int:
    """Set the current stream for a device; returns 0 on success.
    # Interacts with: StreamContext (thread-local), FuncCall3/FuncCall (Cython)
    # Invariant: stream is a weak reference owned/cached by the module
    """
    ...

# --- Test helper (Cython class, not public API) ---

class DLTensorTestWrapper:
    """Wraps a Tensor to expose DLPack + __tvm_ffi_env_stream__ for testing."""
    tensor: Tensor

    def __tvm_ffi_env_stream__(self) -> int: ...
    def __dlpack_device__(self) -> tuple[int, int]: ...
    def __dlpack__(self, **kwargs) -> PyCapsule: ...
    # Interacts with: TVMFFIEnvGetCurrentStream (reads current stream for device)
```

## Impact
- API: `TVMFFIEnvSetStream` renamed to `TVMFFIEnvSetCurrentStream` in `include/tvm/ffi/extra/c_env_api.h` and `src/ffi/extra/stream_context.cc`. Any C/C++ caller using the old name will fail to link.
- Behavioral: Objects implementing `__dlpack__` that also implement `__tvm_ffi_env_stream__` now automatically have their stream forwarded to TVM FFI calls. Previously only `torch.Tensor` with `__tvm_ffi_stream__` was handled.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Stream context** (0011-module-system, 0007-c-abi): thread-local `StreamContext` for per-device stream tracking, `TVMFFIEnvGetCurrentStream`.
- **DLPack protocol** (0006-containers, 0012-python-bindings): `__dlpack__`/`__dlpack_device__` used for tensor exchange in the auto-convert path of `make_args`.
- **Packed function calling convention** (0003-function-system): `FuncCall3`/`FuncCall` save/restore stream around `TVMFFIFunctionCall`.
- **DLDevice type constants** (dlpack.h): `kDLCPU`, `kDLCUDA`, etc., now declared in Cython `base.pxi` for device-type comparison.

Design elements this commit produces:
- **`__tvm_ffi_env_stream__` protocol**: a new duck-typed dunder method for generic tensor objects to supply a device stream to TVM FFI. Not yet documented in any design record.
- **DLDevice enum in Cython**: moves `kDLCPU`..`kDLTrn` device type constants from dlpack.h into `base.pxi` extern declarations, enabling device-type comparison in Cython without C++ casts.

## Usage Examples

Using `DLTensorTestWrapper` to test the stream protocol (from `benchmark_dlpack.py` and `tensor.pxi`):

```python
import tvm_ffi

# Wrap a TVM tensor so it goes through the __dlpack__ + __tvm_ffi_env_stream__ path
x = tvm_ffi.from_dlpack(torch.arange(1, device="cuda"))
wrapper = tvm_ffi.core.DLTensorTestWrapper(x)

# When wrapper is passed to a TVM FFI packed function, the calling convention:
#   1. Calls wrapper.__dlpack__() to get a DLTensor
#   2. Checks wrapper.__tvm_ffi_env_stream__() for the current stream
#   3. Calls TVMFFIEnvSetCurrentStream with that stream before the function body
#   4. Restores the original stream after the call
nop = tvm_ffi.get_global_func("testing.nop")
nop(wrapper, wrapper, wrapper)  # stream auto-forwarded
```

Custom framework integration pattern:

```python
class MyFrameworkTensor:
    """A tensor from another ML framework that participates in TVM stream exchange."""

    def __dlpack__(self, **kwargs):
        return self._internal_dlpack(**kwargs)

    def __dlpack_device__(self):
        return (self.device_type, self.device_id)

    def __tvm_ffi_env_stream__(self) -> int:
        # Return the framework's current CUDA stream as an integer handle
        return int(my_framework.current_stream(self.device_id).cuda_stream)
```
