# Introduce __tvm_ffi_env_stream__ protocol and rename TVMFFIEnvSetStream to TVMFFIEnvSetCurrentStream

## TL;DR
- Renames `TVMFFIEnvSetStream` → `TVMFFIEnvSetCurrentStream` in C ABI, Cython bindings, and `stream_context.cc`.
- Adds `__tvm_ffi_env_stream__` protocol: any object passed to an FFI function that has a `__dlpack__` method and defines `__tvm_ffi_env_stream__()` can push its device stream into the TVM FFI stream context without needing direct `torch` / framework dependency.
- Adds `DLTensorTestWrapper` Cython class that implements `__tvm_ffi_env_stream__()` for testing the new protocol.

## Key Exports

```python
# C ABI rename
# Old: int TVMFFIEnvSetStream(device_type, device_id, stream, opt_out_original_stream)
# New: int TVMFFIEnvSetCurrentStream(device_type, device_id, stream, opt_out_original_stream)
# Interacts with: StreamContext::SetStream, FuncCall / FuncCall3 in function.pxi

# Protocol: __tvm_ffi_env_stream__
# Any Python object with __dlpack__ may also define:
#   def __tvm_ffi_env_stream__(self) -> int:
#       """Returns current environment stream handle as integer."""
# When detected during make_args(), sets ctx_dev_type/ctx_dev_id/ctx_stream
# before calling TVMFFIFunctionCall.
# Invariant: only consulted for non-CPU devices; only first such arg wins (ctx_dev_type == -1 guard).
# Interacts with: FuncCall / FuncCall3, TVMFFIEnvSetCurrentStream, TVMFFIEnvGetCurrentStream

class DLTensorTestWrapper:
    """Test-only wrapper that exposes __tvm_ffi_env_stream__ via DLTensorTestWrapper.
    Interacts with: TVMFFIEnvGetCurrentStream (c_env_api.h), __dlpack__, __dlpack_device__.
    """
    tensor: Tensor  # wrapped tvm_ffi.Tensor

    def __tvm_ffi_env_stream__(self) -> int: ...
    # Returns current stream for tensor's device as an integer (void* cast to long long).

    def __dlpack__(self, **kwargs) -> ...: ...
    def __dlpack_device__(self) -> ...: ...
```

## Impact
- API: Breaking ABI rename: `TVMFFIEnvSetStream` → `TVMFFIEnvSetCurrentStream`. All callers (C++, Cython, any downstream binding) must update the call site.
- Behavioral: `__tvm_ffi_env_stream__` protocol allows non-torch tensors to inject their stream. Previously only objects with `__tvm_ffi_device__` attr or explicit device propagation were recognized.
- Flags/config: None.
- Data formats/schemas: None.
