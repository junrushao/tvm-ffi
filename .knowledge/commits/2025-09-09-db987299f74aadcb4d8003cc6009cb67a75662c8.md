# Introduce __tvm_ffi_env_stream__ protocol for generic DLPack stream exchange

## TL;DR
- Adds a `__tvm_ffi_env_stream__` dunder protocol so any object implementing `__dlpack__` can participate in automatic stream context exchange when passed to TVM FFI functions (previously only `torch.Tensor` got CUDA stream propagation).
- Renames the C ABI function `TVMFFIEnvSetStream` to `TVMFFIEnvSetCurrentStream` across the C header, Cython bindings, and C++ implementation for naming clarity.
- Adds a `DLTensorTestWrapper` Cython class and benchmark coverage for testing the new protocol.

| Old name | New name |
|---|---|
| `TVMFFIEnvSetStream` | `TVMFFIEnvSetCurrentStream` |

## Impact
- API: `TVMFFIEnvSetStream` renamed to `TVMFFIEnvSetCurrentStream` in C header (`c_env_api.h`) — any C/C++ caller of the old name will fail to compile/link. Purely additive new Python protocol (`__tvm_ffi_env_stream__`).
- Behavioral: `make_args` now checks `__tvm_ffi_env_stream__` on any `__dlpack__` object for non-CPU devices, enabling automatic stream propagation beyond torch.Tensor. A minor variable rename inside the `__dlpack__` branch (`arg` -> `ffi_arg`) fixes a shadowing issue where the converted tensor was stored in the same variable as the original argument, preventing access to the original's `__tvm_ffi_env_stream__`.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

A framework (e.g., CuPy, JAX) wraps its tensor with the stream protocol for TVM FFI:

```python
class MyFrameworkTensor:
    """Example: a tensor from another framework that wants TVM FFI stream propagation."""
    def __init__(self, data, stream_handle):
        self._data = data
        self._stream = stream_handle

    def __dlpack__(self, **kwargs):
        return self._data.__dlpack__(**kwargs)

    def __dlpack_device__(self):
        return self._data.__dlpack_device__()

    def __tvm_ffi_env_stream__(self):
        # Return the integer stream handle for TVM FFI to install
        return self._stream

# When passed to a TVM FFI function, make_args will:
# 1. Call from_dlpack(my_tensor) to get a TVM Tensor
# 2. Check device_type != kDLCPU
# 3. Call my_tensor.__tvm_ffi_env_stream__() to get the stream
# 4. Call TVMFFIEnvSetCurrentStream(device_type, device_id, stream, &prev)
# 5. Execute the FFI function
# 6. Restore prev stream if it differs
tvm_func(my_tensor)
```
