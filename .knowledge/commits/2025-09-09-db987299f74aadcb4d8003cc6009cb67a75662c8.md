# Introduce __tvm_ffi_env_stream__ protocol for generic tensor stream exchange and rename TVMFFIEnvSetStream to TVMFFIEnvSetCurrentStream
## TL;DR
- Adds `__tvm_ffi_env_stream__` dunder protocol: objects implementing `__dlpack__` can also expose their framework's current stream via this method, enabling automatic stream context exchange when passing non-TVM tensors to FFI functions.
- Renames `TVMFFIEnvSetStream` to `TVMFFIEnvSetCurrentStream` across C header, C++ implementation, and Cython bindings for naming clarity.
- Adds `DLTensorTestWrapper` Cython class for testing the new stream protocol, and extends the DLPack benchmark script with wrapper-based benchmarks.

**Rename mapping:**

| Old name | New name | Files |
|----------|----------|-------|
| `TVMFFIEnvSetStream` | `TVMFFIEnvSetCurrentStream` | `c_env_api.h`, `stream_context.cc`, `base.pxi`, `function.pxi` |

## Impact
- API: Renames `TVMFFIEnvSetStream` to `TVMFFIEnvSetCurrentStream` in C header and Cython bindings. This is a **breaking change** for any direct C callers of `TVMFFIEnvSetStream`.
- Behavioral: Auto-DLPack path in `make_args()` now probes `__tvm_ffi_env_stream__` on non-CPU tensors, automatically setting stream context before FFI function call. Previously only `__tvm_ffi_ctx_stream__` (on the function/object side) could set stream context.
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces:
- **`__tvm_ffi_env_stream__` protocol** -- a new dunder method convention for generic tensor objects to expose their framework's current device stream to TVM FFI. Called during `make_args()` auto-DLPack path.
- **`DLTensorTestWrapper`** -- test-only Cython class demonstrating the protocol.
- **DLDevice enum imports in base.pxi** -- moved DLPack device type constants (`kDLCPU`, `kDLCUDA`, etc.) from implicit availability to explicit Cython `cdef extern` block, and reordered `base.pxi` to place `dlpack.h` declarations before `c_api.h` declarations.

## Usage Examples
Stream exchange protocol usage (from `scripts/benchmark_dlpack.py`):
```python
import tvm_ffi

# Wrap a TVM tensor in a DLTensorTestWrapper that exposes __tvm_ffi_env_stream__
x = tvm_ffi.from_dlpack(torch.arange(1, device="cuda"))
wrapper = tvm_ffi.core.DLTensorTestWrapper(x)

# When wrapper is passed to an FFI function, make_args() detects:
# 1. wrapper has __dlpack__ -> converts to Tensor via from_dlpack
# 2. wrapper has __tvm_ffi_env_stream__ AND device is non-CPU
#    -> calls wrapper.__tvm_ffi_env_stream__() to get stream handle
#    -> sets ctx_dev_type/ctx_dev_id/ctx_stream for the FFI call
# 3. FuncCall/FuncCall3 calls TVMFFIEnvSetCurrentStream before dispatch
nop = tvm_ffi.get_global_func("testing.nop")
nop(wrapper)  # stream context automatically exchanged
```
