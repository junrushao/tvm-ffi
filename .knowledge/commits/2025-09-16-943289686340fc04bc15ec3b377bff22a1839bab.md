# Fix CMake install DIRECTORY trailing-slash for 3rdparty packaging and bump to 0.1.0b3
## TL;DR
- Fixed CMake `install(DIRECTORY ...)` paths for `3rdparty/dlpack` and `3rdparty/libbacktrace` by appending trailing slashes, ensuring only directory *contents* (not the directory itself) are installed to the destination.
- Bumped package version from `0.1.0b2` to `0.1.0b3` in `pyproject.toml`.

## Key Exports
None

## Impact
- API: none
- Behavioral: Fixes the installed layout of `3rdparty/dlpack/include` and `3rdparty/libbacktrace` in Python wheels. Without the trailing slash, CMake's `install(DIRECTORY src DESTINATION dst)` copies the directory *including* its last path component, creating a nested `dst/include/include` or `dst/libbacktrace/libbacktrace` layout. The trailing slash (`src/` -> `dst/`) copies only the contents.
- Flags/config: none
- Data formats/schemas: none
