# Fix CMake 3rdparty install paths and bump version to 0.1.0b3
## TL;DR
- Add trailing slashes to CMake `install(DIRECTORY ...)` source paths for `3rdparty/dlpack` and `3rdparty/libbacktrace`, fixing the install layout so directory *contents* are copied rather than the directory itself being nested.
- Bump package version from `0.1.0b2` to `0.1.0b3` in `pyproject.toml`.

None

## Impact
- API: none
- Behavioral: Corrects the installed directory structure for 3rdparty dependencies in the Python wheel. Before, `3rdparty/dlpack/include` was installed as `3rdparty/dlpack/include/include/` (extra nesting); after, the contents land at the intended `3rdparty/dlpack/include/`.
