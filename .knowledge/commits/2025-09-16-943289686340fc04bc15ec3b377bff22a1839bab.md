# Fix CMake install paths for 3rdparty directories and bump version to 0.1.0b3
## TL;DR
- Fixed CMake `install(DIRECTORY ...)` paths for `dlpack` and `libbacktrace` by appending trailing slashes, which changes CMake behavior from copying the directory itself to copying its *contents* into the destination.
- Bumped package version from `0.1.0b2` to `0.1.0b3` in `pyproject.toml`.

## Key Exports
None

## Impact
- API: none
- Behavioral: The trailing-slash fix in `CMakeLists.txt` changes what gets installed: without the slash, CMake copies the source directory *as a subdirectory* of the destination (creating a nested `include/include/` or `libbacktrace/libbacktrace/`); with the slash, it copies the *contents* into the destination directly. This fixes the installed directory layout for downstream consumers building from the sdist/wheel.
- Flags/config: none
- Data formats/schemas: none
