# Fix CMake install paths for 3rdparty directories and bump version to 0.1.0b3
## TL;DR
- Fixes CMake `install(DIRECTORY ...)` rules for `3rdparty/dlpack/include` and `3rdparty/libbacktrace` by appending trailing slashes, so that the *contents* of those directories are installed rather than nesting the directory itself inside the destination.
- Bumps package version from `0.1.0b2` to `0.1.0b3`.

## Key Exports
None

## Impact
- API: none
- ABI: none
- Behavioral: The trailing-slash fix changes what ends up in the wheel. Without the slash, CMake's `install(DIRECTORY src/foo DESTINATION bar)` copies `foo/` *as a subdirectory* of `bar/`, producing `bar/foo/...`. With the slash (`src/foo/`), CMake copies the *contents* of `foo/` directly into `bar/`, producing `bar/...`. This means the dlpack headers and libbacktrace source are now installed at the correct paths inside the wheel instead of being double-nested.
- Flags/config: none
- Data formats/schemas: none
