# Fix copy-paste error in numpy-missing fallback dtype converter
## TL;DR
- Renamed the fallback function defined when numpy is not installed from `_convert_torch_dtype_to_ffi_dtype(torch_dtype)` to `_convert_numpy_dtype_to_ffi_dtype(numpy_dtype)`, fixing a copy-paste error.
- The bug would have caused a `NameError` at call time (wrong function name in the module namespace) when trying to convert a numpy dtype without numpy installed.
