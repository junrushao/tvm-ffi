# Fix fallback function name from _convert_torch to _convert_numpy when numpy is missing
## TL;DR
- Fixes a copy-paste error in `dtype.pxi`: the numpy-missing fallback stub was named `_convert_torch_dtype_to_ffi_dtype` instead of `_convert_numpy_dtype_to_ffi_dtype`, causing a `NameError` at runtime when numpy was not installed.

None

## Impact
- API: none
- Behavioral: When numpy is not installed, calling code that tries to convert a numpy dtype now correctly raises `ValueError("numpy not found")` instead of failing with `NameError`.
- Flags/config: none
- Data formats/schemas: none
