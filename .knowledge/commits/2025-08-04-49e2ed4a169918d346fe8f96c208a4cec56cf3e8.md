# [FFI] Introduce small string/bytes (#18185)

## TL;DR
- Strings and bytes <= 7 characters are now stored inline within the 16-byte `TVMFFIAny` struct (using new type indices `kTVMFFISmallStr=11` and `kTVMFFISmallBytes=12`), eliminating heap allocation for short strings.
- `String` and `Bytes` no longer inherit from `ObjectRef`; they are now standalone value types backed by `details::BytesBaseCell`, which wraps a `TVMFFIAny` internally and dispatches between inline storage and heap-allocated object storage.
- `AnyHash`/`AnyEqual`, `StructuralHash`/`StructuralEqual`, and all `TypeTraits` specializations are updated to treat small and large string/bytes as semantically equivalent.

## Key Exports

**Constants/Enums** (new type indices in `TVMFFITypeIndex`):
| Name | Value | Purpose |
|------|-------|---------|
| `kTVMFFISmallStr` | 11 | On-stack small string (<=7 bytes) |
| `kTVMFFISmallBytes` | 12 | On-stack small bytes (<=7 bytes) |

**Struct field change** in `TVMFFIAny` (`c_api.h`):
```c
// Before:
int32_t small_len;  // reserved, unused

// After:
union {
  uint32_t zero_padding;    // MUST be 0 for non-small-string types
  uint32_t small_str_len;   // length of small string (max 7)
};
```
The `v_bytes` union member (existing `char[8]`) stores the small string content. Max small string length = `sizeof(int64_t) - 1` = 7.

**Class `details::BytesBaseCell`** (`string.h`) -- internal backing cell for String and Bytes:
```cpp
class BytesBaseCell {
public:
  BytesBaseCell();
  explicit BytesBaseCell(std::nullopt_t);
  // copy/move/assign/destructor with refcount management
  bool operator==(std::nullopt_t) const;
  bool operator!=(std::nullopt_t) const;
  void swap(BytesBaseCell& other);
  const char* data() const noexcept;   // dispatches small vs large
  size_t size() const noexcept;        // dispatches small vs large
  template <typename LargeObj> void InitFromStd(std::string&&, int32_t large_type_index);
  template <typename LargeObj> char* InitSpaceForSize(size_t, int32_t small_type_index, int32_t large_type_index);
  void MoveToAny(TVMFFIAny* result);
  TVMFFIAny CopyToTVMFFIAny() const;
  static BytesBaseCell CopyFromAnyView(const TVMFFIAny* src);
  static BytesBaseCell MoveFromAny(TVMFFIAny* src);
private:
  TVMFFIAny data_;
};
```

**Class `String`** (`string.h`) -- no longer inherits `ObjectRef`:
```cpp
class String {  // was: class String : public ObjectRef
public:
  String();                              // default: empty small string
  String(const char* other);
  String(const char* other, size_t size);
  String(const std::string& other);
  String(std::string&& other);
  explicit String(TVMFFIByteArray other);
  String(std::nullptr_t) = delete;
  const char* data() const noexcept;
  const char* c_str() const noexcept;
  size_t size() const noexcept;
  // comparison, concat operators unchanged
  operator std::string() const;
private:
  details::BytesBaseCell data_;          // was: ObjectRef data_
};
```

**Class `Bytes`** (`string.h`) -- no longer inherits `ObjectRef`:
```cpp
class Bytes {  // was: class Bytes : public ObjectRef
public:
  Bytes();                               // default: empty small bytes
  Bytes(const char* data, size_t size);
  Bytes(TVMFFIByteArray bytes);
  Bytes(const std::string& other);
  Bytes(std::string&& other);
  const char* data() const;
  size_t size() const;
  operator std::string() const;
private:
  details::BytesBaseCell data_;          // was: ObjectRef data_
};
```

**`TypeTraits<String>`** and **`TypeTraits<Bytes>`** (`string.h`) -- fully rewritten:
- No longer extend `ObjectRefWithFallbackTraitsBase`. Now extend `TypeTraitsBase` directly.
- `field_static_type_index = TypeIndex::kTVMFFIAny` (was `kTVMFFIStr`/`kTVMFFIBytes`), because the value can be either a small inline type or a heap object.
- `CheckAnyStrict` checks for both small and large type indices.
- `TryCastFromAnyView` handles `kTVMFFIRawStr` -> `String` and `kTVMFFIByteArrayPtr` -> `Bytes` fallback conversions.

**`Optional<String>` and `Optional<Bytes>`** (`optional.h`) -- new specialization:
- Uses `BytesBaseCell(std::nullopt)` as the null sentinel instead of `std::optional` wrapping.
- `sizeof(Optional<String>) == sizeof(String)` (16 bytes, no overhead).

**C API function signature change** (`c_api.h`):
```c
// Before:
int TVMFFIDataTypeToString(const DLDataType* dtype, TVMFFIObjectHandle* out);
// After:
int TVMFFIDataTypeToString(const DLDataType* dtype, TVMFFIAny* out);
```

**New C API inline** (`c_api.h`):
```c
inline TVMFFIByteArray TVMFFISmallBytesGetContentByteArray(const TVMFFIAny* value);
```

**`StableHashSmallStrBytes`** (`base_details.h`):
```cpp
uint64_t StableHashSmallStrBytes(const TVMFFIAny* data);
```

**`Bytes::memequal` signature change** (`string.h`):
```cpp
// Before: static bool memequal(const char* lhs, const char* rhs, ...);
// After:  static bool memequal(const void* lhs, const void* rhs, ...);
```

**Deleted comparison operators** (`string.h`): All comparison operators (`<`, `>`, `<=`, `>=`, `==`, `!=`) between `String` and `std::nullptr_t` are now `= delete`.

## Impact
- API: **Breaking**. `String` and `Bytes` no longer inherit `ObjectRef`. Code that assigns `String` to `ObjectRef`, calls `.get()`, `.defined()`, `.use_count()`, or relies on `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS` macros on String/Bytes will fail. `TVMFFIDataTypeToString` C API signature changed. Callers must use `TypeTraits<String>::MoveFromAnyAfterCheck` instead of casting the output to an object pointer.
- Behavioral: Short strings (<=7 bytes) are now stored on-stack. `Any a = "hello"` yields `type_index == kTVMFFISmallStr` (was `kTVMFFIStr`). `AnyHash`/`AnyEqual` normalize small/large strings to compare equal and hash identically.
- Flags/config: None.
- Data formats/schemas: `TVMFFIAny` field `small_len` renamed to `zero_padding`/`small_str_len` union. All `TypeTraits::CopyToAnyView` and `MoveToAny` methods now explicitly set `zero_padding = 0`. `Any::same_as` now compares `zero_padding` in addition to `type_index` and `v_int64`.

## Design Elements

Design elements this commit consumes:
- **TVMFFIAny 16-byte struct** (`0001-c-abi-layer.md`): Repurposes the reserved `small_len` field as `zero_padding`/`small_str_len` union and the `v_bytes` union member for inline string storage.
- **TypeTraits protocol** (`0005-type-traits.md`): Rewrites `TypeTraits<String>` and `TypeTraits<Bytes>` to handle dual type indices.
- **Type index partitioning** (`0004-type-index-layout.md`): Allocates two new POD-range indices (11, 12) for small string/bytes.
- **Object system** (`0003-object-system.md`): `BytesObjBase`, `BytesObj`, `StringObj` remain for heap-allocated strings.
- **AnyHash/AnyEqual** (`0002-any-value-system.md`): Extended to normalize small/large string comparison.
- **Structural equality/hash** (`structural_equal.cc`, `structural_hash.cc`): Extended for cross-type-index string comparison.

Design elements this commit produces:
- **Small string optimization (SSO) for FFI**: Strings <= 7 bytes avoid heap allocation entirely, stored inline in the `TVMFFIAny` value slot. This is a new core design element.
- **`BytesBaseCell` dual-representation cell**: Internal class that dispatches between inline storage (`type_index < kTVMFFIStaticObjectBegin`) and heap-allocated object storage, with proper refcount management.
- **`zero_padding` invariant**: All non-small-string `TVMFFIAny` values must have `zero_padding == 0`. This is enforced across all `TypeTraits` specializations and enables `same_as` to use full 16-byte comparison.
- **String/Bytes as non-ObjectRef value types**: `String` and `Bytes` are no longer `ObjectRef` subtypes. They are self-contained value types that manage their own storage.
- **`Optional<String>`/`Optional<Bytes>` specialization**: Uses `kTVMFFINone` as the null sentinel, achieving zero-overhead optionality.

## Usage Examples

**Small string on-stack storage (from test_any.cc):**
```cpp
// Short string (<= 7 bytes) stored inline in TVMFFIAny
Any a = "a1";
EXPECT_EQ(a.type_index(), TypeIndex::kTVMFFISmallStr);

// Long string heap-allocated as before
Any b = String(std::string("a1"));
EXPECT_EQ(b.type_index(), TypeIndex::kTVMFFIStr);

// Small and large representations compare equal and hash equal
EXPECT_TRUE(AnyEqual()(a, b));
EXPECT_EQ(AnyHash()(a), AnyHash()(b));
```

**Optional<String> with zero overhead (from test_optional.cc):**
```cpp
Optional<String> opt_str;
EXPECT_TRUE(!opt_str.has_value());
EXPECT_EQ(opt_str.value_or("default"), "default");

opt_str = "hello";
EXPECT_TRUE(opt_str.has_value());
EXPECT_EQ(opt_str.value(), "hello");
static_assert(sizeof(Optional<String>) == sizeof(String));  // 16 bytes, no overhead
```
