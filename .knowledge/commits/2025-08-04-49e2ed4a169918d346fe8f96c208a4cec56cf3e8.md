# Introduce small string/bytes optimization, changing String and Bytes from ObjectRef wrappers to value types backed by BytesBaseCell

## TL;DR
- String and Bytes are no longer `ObjectRef` subclasses. They are now standalone value types backed by `details::BytesBaseCell`, which stores a `TVMFFIAny` internally and uses the small string optimization (SSO) for strings up to 7 bytes.
- Two new type indices added to the C ABI: `kTVMFFISmallStr=11` and `kTVMFFISmallBytes=12`. The `TVMFFIAny::small_len` field is replaced by a `zero_padding`/`small_str_len` union, activating the previously reserved small-string slot.
- `TypeTraits<String>` and `TypeTraits<Bytes>` are rewritten from `ObjectRefWithFallbackTraitsBase` to standalone specializations that handle the dual representation (small on-stack vs. large heap-allocated object). All equality, hashing, and structural comparison functions updated to handle cross-representation comparisons (small vs. large).

## Impact
- API: **Breaking** -- `String` and `Bytes` no longer inherit from `ObjectRef`. Code using `ObjectRef` methods on String/Bytes (e.g., `use_count()`, `get()`, `defined()`) will not compile. `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS` removed from both classes.
- API: **Breaking** -- `TVMFFIDataTypeToString` output parameter changed from `TVMFFIObjectHandle*` to `TVMFFIAny*`.
- API: **Breaking** -- `TypeTraits<String>::field_static_type_index` changed from `kTVMFFIStr` to `kTVMFFIAny`, and `TypeTraits<Bytes>::field_static_type_index` changed from `kTVMFFIBytes` to `kTVMFFIAny`.
- Behavioral: `Any::same_as()` now also compares `zero_padding` field (required for small string length differentiation). All `zero_padding` initialization added throughout type traits.
- Behavioral: `std::hash<String>` and `std::hash<Bytes>` switched from `StableHashBytes` to `std::hash<std::string_view>`.
- Flags/config: none
- Data formats/schemas: `TVMFFIAny` layout changed -- `small_len` replaced by `zero_padding`/`small_str_len` union. Two new `TVMFFITypeIndex` values (11, 12).

## Design Elements
Design elements this commit consumes:
- **TVMFFIAny 16-byte layout** (0001, 0007): Reuses the existing `v_bytes` union member and the second 4-byte slot for `small_str_len`, activating the previously reserved small-string capability.
- **Object system** (0002): `BytesObjStdImpl<T>` and `make_inplace_array_object` still used for large strings.
- **TypeTraits protocol** (0005): Provides new standalone `TypeTraits<String>` and `TypeTraits<Bytes>` specializations following the 8-method protocol.
- **Structural equality/hash** (0009): Extends `StructEqualHandler` and `StructuralHashHandler` with small string cases.

Design elements this commit produces:
- **`BytesBaseCell` internal cell type** (new, `include/tvm/ffi/string.h`): Core abstraction that makes String/Bytes value types with dual small/large representation. Manages ref-counting for large strings, inline storage for small ones.
- **`kTVMFFISmallStr` / `kTVMFFISmallBytes` type indices** (new, `include/tvm/ffi/c_api.h`): Extend the type index enum with two new on-stack types.
- **`zero_padding` / `small_str_len` union** (new, `include/tvm/ffi/c_api.h`): Replaces the `small_len` reserved field in `TVMFFIAny`, activating the small-string data path.
- **`StableHashSmallStrBytes`** (new, `include/tvm/ffi/base_details.h`): Fast-path hash for on-stack small strings.
- **`TVMFFISmallBytesGetContentByteArray`** (new, `include/tvm/ffi/c_api.h`): C API accessor for small string content.
- **`Optional<String>` / `Optional<Bytes>` specialization** (new, `include/tvm/ffi/optional.h`): Zero-overhead optional using BytesBaseCell null state.

## Usage Examples

**Small string creation and Any interop (from test_string.cc):**
```cpp
// Short strings (<= 7 bytes) are stored inline in TVMFFIAny
String s{"hello"};
Any a = s;
assert(a.type_index() == TypeIndex::kTVMFFISmallStr);
assert(a.as<String>().value() == "hello");

// Long strings are heap-allocated as before
Any c = "long string very long";
assert(c.type_index() == TypeIndex::kTVMFFIStr);
```

**Cross-representation equality (from test_any.cc):**
```cpp
// Small string and heap string compare equal in AnyEqual/AnyHash
Any a = "a1";                          // kTVMFFISmallStr
Any b = String(std::string("a1"));     // kTVMFFIStr (forced heap via std::string&&)
assert(AnyEqual()(a, b));              // true
assert(AnyHash()(a) == AnyHash()(b));  // same hash
```

**Optional<String> zero-overhead nullable (from test_optional.cc):**
```cpp
Optional<String> opt_str;
assert(!opt_str.has_value());
opt_str = "hello";
assert(opt_str.value() == "hello");
static_assert(sizeof(Optional<String>) == sizeof(String));  // no extra flag byte
```
