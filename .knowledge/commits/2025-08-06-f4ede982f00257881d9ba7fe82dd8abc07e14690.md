# Refactor AccessPath from Array<AccessStep> alias to parent-pointing tree object for compact prefix-sharing representation

## TL;DR
- **AccessPath** is promoted from a simple type alias (`Array<AccessStep>`) to a full object class (`AccessPathObj`/`AccessPath`) with a parent-pointing tree structure, enabling compact memory sharing among paths with common prefixes.
- **AccessKind::kObjectField** is renamed to **kAttr**, a new **kAttrMissing** variant is added, and **AccessStepObj::_type_key** changes from `"tvm.ffi.reflection.AccessStep"` to `"ffi.reflection.AccessStep"`.
- `MakeObjectFromPackedArgs` and `AccessStep`/`AccessPath` reflection registration are relocated from core (`object.cc`, `access_path.cc`) to `extra/reflection_extra.cc`, and the template parameter `Class` is removed from `ReflectionDefBase::GetMethod`.

## Key Exports

**Classes (new)**:

`AccessPathObj` -- parent-pointing tree node for access paths:
```cpp
class AccessPathObj : public Object {
  Optional<ObjectRef> parent;   // empty for root
  Optional<AccessStep> step;    // empty for root
  int32_t depth;                // 0 for root
  Optional<AccessPath> GetParent() const;
  AccessPath Extend(AccessStep step) const;
  AccessPath Attr(String field_name) const;
  AccessPath AttrMissing(String field_name) const;
  AccessPath ArrayItem(int64_t index) const;
  AccessPath ArrayItemMissing(int64_t index) const;
  AccessPath MapItem(Any key) const;
  AccessPath MapItemMissing(Any key) const;
  Array<AccessStep> ToSteps() const;
  bool PathEqual(const AccessPath& other) const;
  bool IsPrefixOf(const AccessPath& other) const;
  static constexpr const char* _type_key = "ffi.reflection.AccessPath";
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindConstTreeNode;
};
```

`AccessPath` -- ref wrapper:
```cpp
class AccessPath : public ObjectRef {
  static AccessPath Root();
  static AccessPath FromSteps(Array<AccessStep> steps);
  template<typename Iter>
  static AccessPath FromSteps(Iter begin, Iter end);
};
```

## Impact
- API: **Breaking**. `AccessPath` changes from `Array<AccessStep>` to a distinct `ObjectRef` type. All callers that constructed `AccessPath` as an `Array` must use `AccessPath::Root()` + chained `->Extend()`/`->Attr()`/etc., or `AccessPath::FromSteps(array)`. `AccessStep::ObjectField` renamed to `AccessStep::Attr`. Callers using `AccessKind::kArrayItemMissing` (=3) or `kMapItemMissing` (=4) must update to new values (4 and 5).
- Behavioral: `AccessPath` now shares memory among paths with common prefixes via parent pointers. `IsPrefixOf` and `PathEqual` enable efficient path comparison without materializing full arrays.
- Flags/config: `reflection_extra.cc` added to `TVM_FFI_USE_EXTRA_CXX_API` CMake sources; `access_path.cc` removed from core sources.
- Data formats/schemas: `AccessStepObj::_type_key` changes from `"tvm.ffi.reflection.AccessStep"` to `"ffi.reflection.AccessStep"` (serialization impact).

## Design Elements
Design elements this commit consumes:
- **Object system** (`0003-object-system.md`): `AccessPathObj` follows the `FooObj`/`Foo` pattern with `TVM_FFI_DECLARE_FINAL_OBJECT_INFO`/`TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS`.
- **Reflection registration** (`0009-reflection.md`): `ObjectDef<AccessPathObj>` registers fields and methods; `GlobalDef` registers `ffi.MakeObjectFromPackedArgs`.
- **Any/AnyView** (`0002-any-value-system.md`): `AnyEqual()` used in `StepEqual` for deep key comparison.
- **Containers** (`0008-containers.md`): `Array<AccessStep>`, `Optional<T>`, `Tuple<T...>` used in the new structure.

Design elements this commit produces:
- **AccessPath tree structure**: A parent-pointing tree (`AccessPathObj`) that replaces the flat `Array<AccessStep>` alias, enabling O(depth) prefix sharing and O(depth) prefix-of checks.
- **AccessStep::Attr / kAttr nomenclature**: Renames "ObjectField" to "Attr" for consistency with attribute-access semantics across layers.
- **Extra reflection isolation**: Moves `MakeObjectFromPackedArgs` and `AccessStep`/`AccessPath` reflection to `extra/`, aligning with the `extra/` module boundary (`0010-extra-api-isolation.md`).

## Usage Examples

### Constructing and querying an AccessPath (from test)
```cpp
namespace refl = tvm::ffi::reflection;

// Build a path: root -> .body -> [1]
refl::AccessPath path = refl::AccessPath::Root()->Attr("body")->ArrayItem(1);

// Convert to flat steps for inspection
auto steps = path->ToSteps();  // Array<AccessStep> of size 2
// steps[0]->kind == kAttr, steps[0]->key == "body"
// steps[1]->kind == kArrayItem, steps[1]->key == 1

// Prefix checking
refl::AccessPath longer = path->Attr("value");
path->IsPrefixOf(longer);   // true
longer->IsPrefixOf(path);   // false

// Deep equality
refl::AccessPath path2 = refl::AccessPath::Root()->Attr("body")->ArrayItem(1);
path->PathEqual(path2);     // true

// Reconstruct from flat steps (migration path from old API)
refl::AccessPath from_flat = refl::AccessPath::FromSteps({
    refl::AccessStep::Attr("body"),
    refl::AccessStep::ArrayItem(1),
});
path->PathEqual(from_flat); // true
```
