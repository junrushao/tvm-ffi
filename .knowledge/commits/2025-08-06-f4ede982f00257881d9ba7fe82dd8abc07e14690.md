# Refactor AccessPath from flat array alias to parent-pointing tree object, rename kObjectField to kAttr

## TL;DR
- Replaces `using AccessPath = Array<AccessStep>` with a proper `AccessPathObj`/`AccessPath` Object using a parent-pointing tree structure, enabling compact shared-prefix representation of multiple paths.
- Renames `AccessKind::kObjectField` to `kAttr` and `AccessStep::ObjectField()` to `Attr()`, adding new `kAttrMissing` variant; renumbers enum values.
- Moves `MakeObjectFromPackedArgs` and reflection registrations from `src/ffi/object.cc` to `src/ffi/extra/reflection_extra.cc`; fixes a Cython method export bug by removing redundant `GetMethod_` overloads in `GlobalDef`.

## Impact
- API: `AccessStep::ObjectField()` renamed to `AccessStep::Attr()`. `AccessPath` is no longer a type alias for `Array<AccessStep>` but a proper Object type. All callers constructing `AccessPath` via `Array<AccessStep>{...}` must switch to `AccessPath::Root()->...` chain or `AccessPath::FromSteps(...)`. `AccessKind` enum values renumbered (kAttrMissing inserted at 3, bumping kArrayItemMissing and kMapItemMissing).
- Behavioral: `GetFirstMismatch` now returns `AccessPath` objects (parent-pointing tree) instead of `Array<AccessStep>`. Callers must call `->ToSteps()` to get flat representation.
- Flags/config: `access_path.cc` removed from always-compiled sources; reflection registration moved to `reflection_extra.cc` under `TVM_FFI_USE_EXTRA_CXX_API` gate.
- Data formats/schemas: `AccessStepObj._type_key` changed from `"tvm.ffi.reflection.AccessStep"` to `"ffi.reflection.AccessStep"`.

## Usage Examples
Building and querying access paths (from `tests/cpp/test_reflection.cc`):
```cpp
// Build a path via chained calls
AccessPath path = AccessPath::Root()->Attr("body")->ArrayItem(1);
auto steps = path->ToSteps();
// steps[0]->kind == kAttr, steps[0]->key == "body"
// steps[1]->kind == kArrayItem, steps[1]->key == 1

// Compare paths
AccessPath path2 = AccessPath::Root()->Attr("body")->ArrayItem(1);
path->PathEqual(path2);  // true

// Check prefix relationship
AccessPath longer = path->Attr("name");
path->IsPrefixOf(longer);  // true

// Reconstruct from flat steps (round-trip)
AccessPath reconstructed = AccessPath::FromSteps(path->ToSteps());
path->PathEqual(reconstructed);  // true
```

Using in structural equality mismatch diagnostics (from `tests/cpp/extra/test_structural_equal_hash.cc`):
```cpp
// Old style (before this commit):
// AccessPath({AccessStep::ObjectField("body"), AccessStep::ArrayItem(1)})

// New style (after this commit):
AccessPath::Root()->Attr("body")->ArrayItem(1)
// or:
AccessPath::FromSteps({AccessStep::Attr("body"), AccessStep::ArrayItem(1)})
```
