# Refactor AccessPath from Array<AccessStep> alias to parent-pointing tree object

## TL;DR
- `AccessPath` promoted from a type alias (`Array<AccessStep>`) to a full Object (`AccessPathObj`/`AccessPath`) with parent-pointing tree representation, enabling memory-efficient prefix sharing when multiple paths share a common prefix.
- `AccessKind::kObjectField` renamed to `kAttr`; new `kAttrMissing` kind added; `AccessStep::ObjectField()` renamed to `AccessStep::Attr()`. Type keys shortened from `tvm.ffi.reflection.*` to `ffi.reflection.*`.
- `MakeObjectFromPackedArgs` and reflection registrations for `AccessStepObj`/`AccessPathObj` moved from `src/ffi/object.cc` and `src/ffi/reflection/access_path.cc` into new `src/ffi/extra/reflection_extra.cc` (behind `TVM_FFI_USE_EXTRA_CXX_API` flag). `GlobalDef::GetMethod_` template overload removed in favor of the base-class `GetMethod`.

| Old name | New name |
|---|---|
| `AccessKind::kObjectField` | `AccessKind::kAttr` |
| (none) | `AccessKind::kAttrMissing` (new, value 3) |
| `AccessKind::kArrayItemMissing` | value 3 -> 4 |
| `AccessKind::kMapItemMissing` | value 4 -> 5 |
| `AccessStep::ObjectField(name)` | `AccessStep::Attr(name)` |
| (none) | `AccessStep::AttrMissing(name)` (new) |
| `using AccessPath = Array<AccessStep>` | `class AccessPathObj : public Object` / `class AccessPath : public ObjectRef` |
| `AccessStepObj::_type_key = "tvm.ffi.reflection.AccessStep"` | `"ffi.reflection.AccessStep"` |
| (none) | `AccessPathObj::_type_key = "ffi.reflection.AccessPath"` (new) |

## Impact
- API: `AccessStep::ObjectField` renamed to `AccessStep::Attr`. `AccessPath` changed from `Array<AccessStep>` to a first-class ObjectRef. All callers building or consuming AccessPaths must update. `AccessKind` enum values renumbered (kArrayItemMissing 3->4, kMapItemMissing 4->5).
- Behavioral: `GetFirstMismatch` now returns `AccessPath` objects instead of `Array<AccessStep>`. Call `path->ToSteps()` to get the equivalent array.
- Flags/config: `MakeObjectFromPackedArgs` and reflection registrations now require `TVM_FFI_USE_EXTRA_CXX_API` CMake flag (moved to `extra/` build group).
- Data formats/schemas: `AccessStepObj._type_key` changed from `tvm.ffi.reflection.AccessStep` to `ffi.reflection.AccessStep`. Serialized data using the old key will not deserialize correctly.

## Design Elements
Design elements this commit consumes:
- **Object system** (0002): `AccessPathObj` / `AccessStepObj` follow `FooObj` + `Foo` ObjectRef pattern with `TVM_FFI_DECLARE_FINAL_OBJECT_INFO` / `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS`.
- **Reflection system** (0008): `ObjectDef<AccessStepObj>` and `ObjectDef<AccessPathObj>` register field/method reflection. `GlobalDef` registers `MakeObjectFromPackedArgs`.
- **Structural equal/hash** (0009): `kTVMFFISEqHashKindConstTreeNode` applied to both `AccessStepObj` and `AccessPathObj`. Mismatch path construction in `StructEqualHandler` updated to use `AccessStep::Attr`.

Design elements this commit produces:
- **AccessPathObj/AccessPath** (new object type): Parent-pointing tree representation replacing the flat `Array<AccessStep>` alias. Enables memory-efficient prefix sharing when representing multiple related paths (e.g., all mismatch paths in a large tree comparison share common prefix nodes).
- **AccessStep::Attr/AttrMissing** (renamed + new): Replaces `ObjectField` with more generic `Attr` naming. Adds `AttrMissing` for asymmetric mismatch reporting where one side lacks an attribute.

## Usage Examples

Building and querying an AccessPath (from the new test in `tests/cpp/test_reflection.cc`):
```cpp
namespace refl = tvm::ffi::reflection;
// Build path via fluent chaining from Root
refl::AccessPath path = refl::AccessPath::Root()->Attr("body")->ArrayItem(1);
auto steps = path->ToSteps();  // Array<AccessStep> of length 2

// Prefix checking
refl::AccessPath longer = path->Extend(refl::AccessStep::MapItem("key"));
EXPECT_TRUE(path->IsPrefixOf(longer));    // true
EXPECT_FALSE(longer->IsPrefixOf(path));   // false

// Round-trip: path -> steps -> path
refl::AccessPath reconstructed = refl::AccessPath::FromSteps(path->ToSteps());
EXPECT_TRUE(path->PathEqual(reconstructed));

// StructuralEqual mismatch uses the new builder API:
auto expected = refl::AccessPathPair(
    refl::AccessPath::Root()->MapItem("b")->ArrayItem(1),
    refl::AccessPath::Root()->MapItem("b")->ArrayItem(1));
```
