# Refactor AccessPath from Array<AccessStep> alias to a parent-pointer tree ObjectRef, and migrate MakeObjectFromPackedArgs to extra/

## TL;DR
- `AccessPath` is no longer a `using` alias for `Array<AccessStep>`; it is now a proper `ObjectRef`/`Object` pair (`AccessPath`/`AccessPathObj`) backed by a parent-pointer tree structure. Paths are built incrementally with `.Attr()`, `.ArrayItem()`, `.MapItem()`, etc.; `ToSteps()` linearizes on demand.
- `AccessKind::kObjectField` is renamed to `kAttr`; `kAttrMissing` (value 3) is added; `kArrayItemMissing` shifts from 3→4 and `kMapItemMissing` from 4→5.
- `MakeObjectFromPackedArgs` and all `AccessStep`/`AccessPath` reflection registrations are moved from the always-compiled core (`src/ffi/object.cc`, `src/ffi/reflection/access_path.cc`) into a new `src/ffi/extra/reflection_extra.cc`, gating them under `TVM_FFI_USE_EXTRA_CXX_API`.

class AccessKind(IntEnum):
    """Discriminator for one traversal step. Header: include/tvm/ffi/reflection/access_path.h"""

    kArrayItem        = 1
    kMapItem          = 2

    key: Any  # str for kAttr/kAttrMissing, int64 for kArrayItem/kArrayItemMissing, Any for kMap*

    def StepEqual(self, other: AccessStep) -> bool: ...
    # Invariant: kTVMFFISEqHashKindConstTreeNode — steps are structurally comparable

    """Ref wrapper. Factory methods:"""
    @staticmethod
    def Attr(name: str) -> AccessStep: ...          # was: ObjectField()
    @staticmethod
    def AttrMissing(name: str) -> AccessStep: ...   # NEW

    @staticmethod

    @staticmethod

    @staticmethod
    def MapItemMissing(key: Any = None) -> AccessStep: ...

class AccessPathObj(Object):
    """Parent-pointer tree node for an access path.
    _type_key = "ffi.reflection.AccessPath"
    _type_s_eq_hash_kind = kTVMFFISEqHashKindConstTreeNode
    """
    parent: Optional[ObjectRef]   # None at root; cast to AccessPath to traverse
    step:   Optional[AccessStep]  # None at root
    depth:  int32_t               # 0 at root; = parent.depth + 1

    def GetParent(self) -> Optional[AccessPath]: ...
    def Extend(self, step: AccessStep) -> AccessPath: ...
    def Attr(self, name: str) -> AccessPath: ...
    def AttrMissing(self, name: str) -> AccessPath: ...
    def ArrayItem(self, index: int64) -> AccessPath: ...
    def ArrayItemMissing(self, index: int64) -> AccessPath: ...
    def MapItem(self, key: Any) -> AccessPath: ...
    def MapItemMissing(self, key: Any) -> AccessPath: ...
    def ToSteps(self) -> Array[AccessStep]: ...
    # Walks parent chain backwards, collects into vector, reverses → O(depth)
    def PathEqual(self, other: AccessPath) -> bool: ...
    # Fast path: pointer equality; depth guard; then step-by-step traversal up parent chain
    def IsPrefixOf(self, other: AccessPath) -> bool: ...
    # Walks other up until depths match, then calls PathEqual
    # Invariant: empty parent <=> root (depth == 0)
    # Interacts with: StructuralEqual.GetFirstMismatch (builds paths via Attr/ArrayItem/MapItem)


class AccessPath(ObjectRef):
    """Ref wrapper for AccessPathObj. Replaces old `using AccessPath = Array<AccessStep>`."""
    @staticmethod
    def Root() -> AccessPath: ...
    # Creates root node: parent=None, step=None, depth=0

    @staticmethod
    def FromSteps(steps: Array[AccessStep]) -> AccessPath: ...  # also: FromSteps(Iter begin, Iter end)
    # Builds by repeatedly calling Root()->Extend() for each step
    # Invariant: round-trip: FromSteps(path->ToSteps()) produces PathEqual path
    # Interacts with: StructuralEqual.GetFirstMismatch (constructs return value)

AccessPathPair = Tuple[AccessPath, AccessPath]  # unchanged

## Impact
- API: **Breaking.** `AccessPath` is no longer `Array<AccessStep>`; callers that construct paths with `AccessPath({step1, step2})` must migrate to `AccessPath::FromSteps({...})` or the fluent builder style `AccessPath::Root()->Attr("x")->ArrayItem(0)`. `AccessStep::ObjectField()` is removed; use `Attr()`. Enum values `kArrayItemMissing` and `kMapItemMissing` shifted by 1 — any serialized integer values are stale.
- Behavioral: `GetFirstMismatch` still returns an `AccessPathPair`, but the elements are now `AccessPath` objects (parent-pointer trees) instead of `Array<AccessStep>`. Consumers must call `->ToSteps()` or use the `PathEqual`/`IsPrefixOf` methods directly.
- Flags/config: `MakeObjectFromPackedArgs` is now compiled only when `TVM_FFI_USE_EXTRA_CXX_API` is ON (default ON, but not guaranteed in stripped builds). Previously it was always compiled.
- Data formats/schemas: `AccessStepObj._type_key` is unchanged (`"ffi.reflection.AccessStep"`). `AccessPathObj._type_key = "ffi.reflection.AccessPath"` is new (was no separate Object type before). Serialized `AccessPath` data will differ in format.

## Usage Examples

**Fluent path builder style (new):**
```cpp
namespace refl = tvm::ffi::reflection;

// Old (no longer valid):
// refl::AccessPath path = {refl::AccessStep::ObjectField("body"), refl::AccessStep::ArrayItem(1)};

// New — fluent builder:
refl::AccessPath path = refl::AccessPath::Root()->Attr("body")->ArrayItem(1);

// Or equivalently, via FromSteps:
refl::AccessPath path2 = refl::AccessPath::FromSteps({
    refl::AccessStep::Attr("body"),
    refl::AccessStep::ArrayItem(1),
});

assert(path->PathEqual(path2));    // deep equality
assert(path->depth == 2);

// Prefix check:
refl::AccessPath prefix = refl::AccessPath::Root()->Attr("body");
assert(prefix->IsPrefixOf(path)); // true

// Linearize:
auto steps = path->ToSteps();
assert(steps[0]->kind == refl::AccessKind::kAttr);
assert(steps[0]->key.cast<String>() == "body");
```

**GetFirstMismatch with new AccessPath API:**
```cpp
Array<int> a = {1, 2, 3};
Array<int> d = {1, 2};
auto diff = refl::StructuralEqual::GetFirstMismatch(a, d);
// diff.get<0>() and diff.get<1>() are now AccessPath objects
auto lhs_steps = diff->get<0>()->ToSteps();
// lhs_steps[0]->kind == AccessKind::kArrayItem, key == 2
```
