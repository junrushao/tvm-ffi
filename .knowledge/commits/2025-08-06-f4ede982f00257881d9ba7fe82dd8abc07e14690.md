# Refactor AccessPath from Array type alias to parent-pointer tree Object for compact shared-prefix representation

## TL;DR
- `AccessPath` is promoted from a simple `Array<AccessStep>` type alias to a full Object class (`AccessPathObj`/`AccessPath`) using a parent-pointer tree structure, enabling compact memory when multiple paths share a common prefix.
- `AccessKind::kObjectField` is renamed to `kAttr`, and a new `kAttrMissing` variant is added (shifting missing-variant enum values by +1). `AccessStep::ObjectField()` becomes `AccessStep::Attr()`.
- The `GetMethod` template in `ReflectionDefBase` drops the `<Class>` template parameter, fixing a Cython method export bug where `GlobalDef::GetMethod_` overloads were not correctly dispatching.
- Reflection registration for `AccessStepObj` and `AccessPathObj` moves from `access_path.cc` (core) and `object.cc` to a new `reflection_extra.cc` (extra module), along with `MakeObjectFromPackedArgs`.

    """Parent-pointer tree node representing an access path.
    More space efficient than Array when many paths share a prefix."""
    parent: Optional[ObjectRef]    # Empty for root
    step: Optional[AccessStep]     # Empty for root
    depth: int                     # 0 for root
    # Invariant: depth == number of steps from root to this node
    # Invariant: parent chain always terminates at a root node (depth=0, parent=None)

    def GetParent(self) -> Optional[AccessPath]: ...
    def Extend(self, step: AccessStep) -> AccessPath: ...
        # Creates new node with self as parent, depth+1
        # Interacts with: make_object<AccessPathObj>
    def Attr(self, field_name: str) -> AccessPath: ...
    def AttrMissing(self, field_name: str) -> AccessPath: ...
    def ArrayItem(self, index: int) -> AccessPath: ...
    def ArrayItemMissing(self, index: int) -> AccessPath: ...
    def MapItem(self, key: Any) -> AccessPath: ...
    def MapItemMissing(self, key: Any) -> AccessPath: ...
    def ToSteps(self) -> Array[AccessStep]: ...
        # Walks parent chain, collects steps in reverse, returns in root-to-leaf order
    def PathEqual(self, other: AccessPath) -> bool: ...
        # Fast path: pointer equality. Then depth check. Then step-by-step via StepEqual.
        # Interacts with: AccessStepObj.StepEqual
    def IsPrefixOf(self, other: AccessPath) -> bool: ...
        # Walks other's parent chain to match self's depth, then PathEqual
        # Invariant: root is prefix of every path

    _type_key = "ffi.reflection.AccessPath"
    _type_s_eq_hash_kind = kTVMFFISEqHashKindConstTreeNode

class AccessPath(ObjectRef):
    """Ref wrapper for AccessPathObj."""
    @staticmethod
    def Root() -> AccessPath: ...
        # Creates root node (parent=None, step=None, depth=0)
    @staticmethod
    def FromSteps(steps: Union[Array[AccessStep], Iterator[AccessStep]]) -> AccessPath: ...

## Impact
- API: `AccessKind::kObjectField` renamed to `kAttr`; `AccessStep::ObjectField()` renamed to `Attr()`. New `kAttrMissing` and `AccessStep::AttrMissing()`. `AccessPath` is no longer `Array<AccessStep>` -- callers must use `AccessPath::Root()`, `->Extend()`, `->ToSteps()`. All existing test call sites updated in this commit.
- Behavioral: `AccessPath` now stores paths as parent-pointer chains rather than flat arrays. `ToSteps()` converts to the old flat representation. `PathEqual()` and `IsPrefixOf()` provide structural comparison.
- Flags/config: `reflection_extra.cc` added to `TVM_FFI_USE_EXTRA_CXX_API` build set; `access_path.cc` removed from core sources.
- Data formats/schemas: `AccessStepObj._type_key` shortened from `"tvm.ffi.reflection.AccessStep"` to `"ffi.reflection.AccessStep"`. Affects serialized type keys.

## Design Elements
Design elements this commit consumes:
- **Object system** (`0002-object-system.md`): AccessPathObj/AccessPath follow the standard Obj+Ref pattern with `TVM_FFI_DECLARE_FINAL_OBJECT_INFO` / `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS`.
- **Reflection system** (`0008-reflection.md`): `ObjectDef<AccessStepObj>`, `ObjectDef<AccessPathObj>` register fields and methods. `GlobalDef` registers `ffi.MakeObjectFromPackedArgs`.
- **Any/AnyView** (`0003-any-system.md`): `AnyEqual` used in `StepEqual` for key comparison.
- **Structural equality** (`0009-structural-equal-hash.md`): `StructuralEqual::GetFirstMismatch` is the primary consumer of `AccessPath`. Updated to use `AccessPath::FromSteps()` instead of `Array<AccessStep>` constructor.

Design elements this commit produces:
- **AccessPathObj/AccessPath** (new Object): parent-pointer tree representation for access paths, replacing the `Array<AccessStep>` alias. Provides `Extend`, `ToSteps`, `PathEqual`, `IsPrefixOf`.
- **AccessStep::Attr/AttrMissing** (renamed + new): replaces `ObjectField` with `Attr` naming, adds missing-attribute variant.
- **reflection_extra.cc** (new file): consolidates reflection registrations for AccessStep, AccessPath, and MakeObjectFromPackedArgs into the extra module.

## Usage Examples

Constructing and querying access paths (from `tests/cpp/test_reflection.cc`):

```cpp
namespace refl = tvm::ffi::reflection;

// Build a path: root -> .body -> [1]
refl::AccessPath path = refl::AccessPath::Root()->Attr("body")->ArrayItem(1);
auto steps = path->ToSteps();
// steps.size() == 2, steps[0]->kind == kAttr, steps[1]->kind == kArrayItem

// Prefix checking
refl::AccessPath longer = path->Extend(refl::AccessStep::Attr("x"));
path->IsPrefixOf(longer);  // true
longer->IsPrefixOf(path);  // false

// Round-trip: path -> steps -> path
refl::AccessPath roundtrip = refl::AccessPath::FromSteps(path->ToSteps());
path->PathEqual(roundtrip);  // true

// Fluent construction for mismatch reporting (from test_structural_equal_hash.cc)
auto expected = refl::AccessPathPair(
    refl::AccessPath::Root()->MapItem("b")->ArrayItem(1),
    refl::AccessPath::Root()->MapItem("b")->ArrayItem(1));
```
