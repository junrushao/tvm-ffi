# Introduce UnsafeInit tag and tighten ObjectRef constructor safety across the object system

## TL;DR
- Adds `ffi::UnsafeInit` tag struct; all four `TVM_FFI_DEFINE_*_OBJECT_REF_METHODS` macros now expose `explicit TypeName(UnsafeInit)` and tighten the `ObjectPtr<Object>` constructor to `ObjectPtr<ContainerType>`, removing the unchecked base-object overload from non-nullable ref types entirely.
- Introduces `ObjectUnsafe::ObjectRefFromObjectPtr<T>()` as the canonical factory for constructing any `ObjectRef` subtype from an `ObjectPtr<Object>`; replaces all direct `T(ObjectPtr<Object>)` call sites across cast.h, optional.h, type_traits.h, function_details.h, rvalue_ref.h, and tensor.cc.
- `ObjectCreatorUnsafeInit<T>` is added to `ReflectionDefBase` so that objects which lack a default constructor but have `explicit T(UnsafeInit)` still get a usable `creator` callback for named-field construction during JSON deserialization.

struct UnsafeInit:
    """Tag for explicitly unsafe null-init of any ObjectRef subtype.
    # Invariant: Only pass to constructors in controlled teardown/init paths.
    # Interacts with: ObjectRef(UnsafeInit), all TVM_FFI_DEFINE_*_OBJECT_REF_METHODS macros,
    #                 ObjectCreatorUnsafeInit<T> (reflection/registry.h).

class ObjectRef:
    data_: ObjectPtr[Object]

    def __init__(self, tag: UnsafeInit) -> None:
        self.data_ = nullptr
        # Invariant: caller must assign data_ before first use.

    def as_(self, ObjectRefType: type) -> Optional[ObjectRefType]:
        # CHANGED: no longer calls ObjectRefType(data_) directly.
        # Now: ref = ObjectRefType(UnsafeInit{}); ref.data_ = data_; return ref
        # Invariant: requires ObjectRefType to have UnsafeInit constructor.
        ...

# New helper on ObjectUnsafe — ffi/object.h
class ObjectUnsafe:
    @staticmethod
    def ObjectRefFromObjectPtr(T: type, ptr: ObjectPtr[Object]) -> T:
        """Construct T (any ObjectRef subtype) from a raw ObjectPtr without
        calling T(ObjectPtr<Object>) — bypasses the now-removed public ctor.
        # Invariant: ptr's runtime type_index must be compatible with T::ContainerType.
        # Interacts with: all callers that previously called T(ObjectPtr<Object>) directly,
        #                 ObjectUnsafe::ObjectRefFromObjectPtr (rvalue overload for move).
        """
        ref = T(UnsafeInit{})
        ref.data_ = ptr
        return ref

    @staticmethod
    def ObjectRefFromObjectPtr_move(T: type, ptr: ObjectPtr[Object]) -> T:
        ref = T(UnsafeInit{})
        ref.data_ = std.move(ptr)
        return ref

## Impact
- API: **Breaking for downstream code that called `T(ObjectPtr<Object>)` directly** on any non-nullable `ObjectRef` subtype. The non-nullable macros no longer generate that constructor. Code that was doing `return MyRef(some_object_ptr)` must migrate to `details::ObjectUnsafe::ObjectRefFromObjectPtr<MyRef>(some_object_ptr)` or add an explicit typed constructor. Nullable refs still have `TypeName(ObjectPtr<ContainerType>)`.
- Behavioral: `ObjectPtr<Object>` upcasting constructor removed from non-nullable refs; `ObjectPtr<ContainerType>` typed constructor retained for nullable refs (more type-safe). `ObjectRef::as<T>()` no longer calls `T(data_)` — uses `UnsafeInit` + `data_` assignment (functionally equivalent, but does not require a public `ObjectPtr<Object>` ctor on `T`).
- Flags/config: none
- Data formats/schemas: `MakeStridesFromShape` parameter order changed from `(ndim, shape*)` to `(data*, ndim)`. Only called internally (`TensorObjFromNDAlloc`, `TensorObjFromDLPack`); no public schema change.

## Design Elements
Design elements this commit consumes:
- **0002-object-system**: `ObjectRef`, `ObjectPtr<T>`, `TVM_FFI_DEFINE_OBJECT_REF_METHODS`, `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS`, `ObjectUnsafe` (friend struct in `details::`)
- **0008-type-traits**: `ObjectRefTypeTraitsBase` (uses `T(ObjectPtr<Object>)` for `CopyFromAnyViewAfterCheck`, `MoveFromAnyAfterCheck`, `TryCastFromAnyView` — all migrated)
- **0006-reflection**: `ObjectDef<Class>` init — `creator` selection logic updated
- **0007-containers**: `Array`, `Map`, `Tuple`, `Shape`, `Optional<T>` — UnsafeInit constructors added; `Optional::value()`, `operator*`, `value_or()` migrated to `ObjectRefFromObjectPtr<T>`
- **0011-module-system**: `Module` — gains explicit typed `ObjectPtr<ModuleObj>` ctor with null check

Design elements this commit produces:
- **`ffi::UnsafeInit` tag struct** — new design element in `include/tvm/ffi/object.h`. Enables null-init pattern for `ObjectRef` subclasses that lack a default constructor, used by reflection's `ObjectCreatorUnsafeInit<T>`.
- **`ObjectUnsafe::ObjectRefFromObjectPtr<T>()`** — new static template method on `ObjectUnsafe`. Becomes the sole canonical path for constructing any `ObjectRef` subtype from a raw `ObjectPtr<Object>`. Both const-ref and rvalue overloads provided.
- **`ObjectCreatorUnsafeInit<T>`** — new static method on `ReflectionDefBase`. Fills `TVMFFIFieldInfo.creator` for types with `UnsafeInit` constructor but no default constructor.

## Usage Examples

**Using `UnsafeInit` in a custom ObjectRef (C++)**

```cpp
// Before: ObjectRef subclass constructor accepting ObjectPtr<Object>
class MyRef : public ObjectRef {
 public:
  // Old macro generated: explicit MyRef(ObjectPtr<Object> n) : ObjectRef(n) {}
  TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS(MyRef, ObjectRef, MyObj);
};

// After: ObjectPtr<Object> ctor removed from non-nullable refs; UnsafeInit added
// Direct construction via ObjectUnsafe:
auto ptr = details::ObjectUnsafe::ObjectPtrFromOwned<Object>(handle);
MyRef ref = details::ObjectUnsafe::ObjectRefFromObjectPtr<MyRef>(std::move(ptr));

// UnsafeInit pattern for init-then-fill (e.g. in reflection):
MyRef ref2(ffi::UnsafeInit{});
ref2.data_ = some_ptr;  // data_ must be assigned before any dereference
```

**Updated ObjectCreator chain for objects without default constructor (C++)**

```cpp
// Obj without default constructor — only UnsafeInit is accepted
class TVarObj : public Object {
 public:
  std::string name;
  explicit TVarObj(UnsafeInit) {}  // replaces: TVarObj() = default;
  TVarObj(std::string name) : name(name) {}
  // ...
};

// Reflection registration (unchanged call site):
ObjectDef<TVarObj>()
    .def_field("name", &TVarObj::name);
// ObjectDef::init() now detects is_constructible<TVarObj, UnsafeInit> and registers
// ObjectCreatorUnsafeInit<TVarObj> as the creator — used by JSON deserialization.
```
