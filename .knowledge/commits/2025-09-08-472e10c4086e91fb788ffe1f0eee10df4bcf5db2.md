# Introduce UnsafeInit tag and tighten ObjectRef constructor type safety
## TL;DR
- Introduces `ffi::UnsafeInit` tag struct as the sole mechanism for initializing ObjectRef types to null, replacing the previous `ObjectPtr<Object>` constructor that allowed implicit type-erased construction from any object pointer.
- All four `TVM_FFI_DEFINE_*_OBJECT_REF_METHODS` macros now generate typed `ObjectPtr<ContainerType>` constructors (instead of `ObjectPtr<Object>`), and non-nullable macros replace their `ObjectPtr<Object>` constructor entirely with `UnsafeInit`.
- Adds `ObjectUnsafe::ObjectRefFromObjectPtr<T>` factory methods to route all internal unsafe ObjectRef construction through a single controlled path, eliminating scattered `RefType(ObjectPtr<Object>)` calls throughout type_traits.h, cast.h, optional.h, rvalue_ref.h, and container headers.

## Key Exports

**Types/Classes**:
```cpp
struct UnsafeInit {};
// Tag type for unsafe initialization. Constructing an ObjectRefType with
// UnsafeInit{} sets data_ to nullptr. Only for controlled internal scenarios.
```

**Functions (ObjectUnsafe methods)**:
```cpp
template <typename T>
static T ObjectUnsafe::ObjectRefFromObjectPtr(const ObjectPtr<Object>& ptr);
// Creates T (an ObjectRef subtype) from a const-ref ObjectPtr via UnsafeInit + data_ assignment.

template <typename T>
static T ObjectUnsafe::ObjectRefFromObjectPtr(ObjectPtr<Object>&& ptr);
// Creates T from an rvalue ObjectPtr via UnsafeInit + data_ move.
```

**Functions (ReflectionDefBase)**:
```cpp
template <typename T>
static int ReflectionDefBase::ObjectCreatorUnsafeInit(TVMFFIObjectHandle* result);
// Creates an object via make_object<T>(UnsafeInit{}) for types that have an
// UnsafeInit constructor but no default constructor.
```

**Static method (Shape)**:
```cpp
static Shape Shape::StridesFromShape(const int64_t* data, int64_t ndim);
// Public factory to create row-major contiguous strides from shape data.
// Replaces direct calls to details::MakeStridesFromShape (which also changed signature).
```

**Macros (changed)**:

| Macro | Before | After |
|-------|--------|-------|
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS` | `TypeName(ObjectPtr<Object>)` | `TypeName(ObjectPtr<ContainerType>)` + `TypeName(UnsafeInit)` |
| `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS` | `TypeName(ObjectPtr<Object>)` | `TypeName(UnsafeInit)` only |
| `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS` | `TypeName(ObjectPtr<runtime::Object>)` | `TypeName(ObjectPtr<ContainerType>)` + `TypeName(UnsafeInit)` |
| `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS` | `TypeName(ObjectPtr<Object>)` | `TypeName(UnsafeInit)` only |

**Signature changes**:

| Symbol | Before | After |
|--------|--------|-------|
| `details::MakeStridesFromShape` | `(int64_t ndim, int64_t* shape)` | `(const int64_t* data, int64_t ndim)` |
| `Optional<T>::Optional(ObjectPtr<Object>)` | present | removed; replaced by `Optional(UnsafeInit)` |
| `Tuple<...>::Tuple(ObjectPtr<Object>)` | present | removed; replaced by `Tuple(UnsafeInit)` |
| `VariantBase<true>::VariantBase(ObjectPtr<Object>)` | present | replaced by `VariantBase(UnsafeInit)` |
| `Module` | no typed constructor | added `Module(ObjectPtr<ModuleObj>)` with null-check |

## Impact
- API: **Breaking** -- Any code constructing ObjectRef subtypes via `RefType(ObjectPtr<Object>)` must switch to either (a) the typed `RefType(ObjectPtr<ContainerType>)` for nullable types, or (b) `ObjectUnsafe::ObjectRefFromObjectPtr<RefType>(ptr)` for internal code. Non-nullable types lose the `ObjectPtr<Object>` constructor entirely.
- Behavioral: `ObjectRef::as<T>()` now uses UnsafeInit + data_ assignment instead of direct `T(data_)` construction, which is semantically equivalent but avoids the now-removed type-erased constructor.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system macros** (`TVM_FFI_DEFINE_*_OBJECT_REF_METHODS`) -- all four macros are mutated, see [0003-object-system.md](../designs/0003-object-system.md)
- **ObjectUnsafe** utility class -- extended with new factory methods, see [0003-object-system.md](../designs/0003-object-system.md)
- **ObjectRefTypeTraitsBase** -- updated to use `ObjectRefFromObjectPtr` for all ObjectRef construction from AnyView, see [0005-type-traits.md](../designs/0005-type-traits.md)
- **Reflection creator** -- `ObjectDef` constructor now falls back to `ObjectCreatorUnsafeInit` when a type has `UnsafeInit` constructor but no default constructor, see [0009-reflection.md](../designs/0009-reflection.md)
- **Containers** (Array, Map, Tuple, Shape, Variant) -- all gain `UnsafeInit` constructor, see [0008-containers.md](../designs/0008-containers.md)

Design elements this commit produces:
- **`UnsafeInit` tag struct** -- new sentinel type in `include/tvm/ffi/object.h` that marks intentional null initialization. Every ObjectRef subtype must provide a constructor taking `UnsafeInit`.
- **`ObjectUnsafe::ObjectRefFromObjectPtr<T>`** -- new canonical factory for constructing ObjectRef subtypes from raw `ObjectPtr` without going through the (now typed) public constructors.
- **`ReflectionDefBase::ObjectCreatorUnsafeInit<T>`** -- new reflection creator for non-default-constructible types that have an `UnsafeInit` constructor.
- **`Shape::StridesFromShape`** -- new public static factory method encapsulating stride computation.

## Usage Examples

**Constructing an ObjectRef subtype from ObjectPtr (internal code)**:
```cpp
// Before (now fails to compile for non-nullable types):
Shape s(some_object_ptr);

// After: Use ObjectUnsafe factory
Shape s = details::ObjectUnsafe::ObjectRefFromObjectPtr<Shape>(some_object_ptr);

// Or for types with a typed ObjectPtr constructor (nullable types only):
Array<int> a(ObjectPtr<ArrayObj>(some_typed_ptr));
```

**Defining an object type with UnsafeInit (for non-default-constructible types)**:
```cpp
class TVarObj : public Object {
public:
  std::string name;
  TVarObj(std::string name) : name(name) {}
  explicit TVarObj(UnsafeInit) {}  // replaces default constructor
  // ... reflection registration will use ObjectCreatorUnsafeInit<TVarObj>
};
```

**Test demonstrating UnsafeInit behavior**:
```cpp
TEST(ObjectRef, UnsafeInit) {
  ObjectRef a(UnsafeInit{});
  EXPECT_TRUE(a.get() == nullptr);

  TInt b(UnsafeInit{});
  EXPECT_TRUE(b.get() == nullptr);
}
```
