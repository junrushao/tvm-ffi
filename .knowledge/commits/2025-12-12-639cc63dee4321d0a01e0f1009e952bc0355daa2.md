# Move wheel build+test from nightly cron to per-commit on mainline via composite action

## TL;DR
- Extracts wheel-building logic from `publish_wheel.yml` into a reusable composite action `.github/actions/build-wheel-for-publish/action.yml`.
- Adds a `build-wheels` job to `ci_mainline_only.yml` that runs on every push to `main`, replacing the nightly `schedule.cron` trigger in `publish_wheel.yml`.
- Simplifies `publish_wheel.yml` to be dispatch-only (tag-based publish), removing the cron schedule, the separate `build_sdist` job, and inlining sdist into the matrix. Renames the `branch` input to `tag`.

## Key Exports
N/A -- infrastructure.

## Impact
- API: None.
- Behavioral: Wheel validation (C++ tests + cibuildwheel build) now runs on every mainline commit instead of once per day. This catches packaging regressions sooner but increases CI minutes. The `publish_wheel.yml` workflow no longer runs on a cron schedule -- it is now manual dispatch only, accepting a `tag` input instead of `branch`.
- Flags/config: `publish_wheel.yml` trigger changed from `schedule.cron: '0 9 * * *'` + `workflow_dispatch(branch)` to `workflow_dispatch(tag)` only. New `build-wheels` job in `ci_mainline_only.yml`. `.gitignore` updated to allow `.github/actions/build-wheel-for-publish/`.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **cibuildwheel matrix** ([0013-packaging.md](../designs/0013-packaging.md)): The composite action reuses the same platform matrix (manylinux2014, manylinux_2_28, macOS arm64, Windows AMD64) and cibuildwheel v3.1.4 configuration documented in the packaging design doc.
- **Mainline-only CI pattern** (`ci_mainline_only.yml`): Extends the existing per-commit mainline workflow (introduced in 0899b5d for clang-tidy) with wheel validation.
- **C++ test invocation pattern**: The composite action includes `cmake + ctest` C++ test steps matching the documented test commands in CLAUDE.md.

Design elements this commit produces:
- **Composite action `build-wheel-for-publish`** (`.github/actions/build-wheel-for-publish/action.yml`): A reusable GitHub Actions composite action that encapsulates checkout, C++ tests, wheel build (cibuildwheel), and optional sdist build. Parameterized by `os`, `arch`, `linux_image`, `checkout_ref`, `build_wheels`, and `build_sdist`. Consumed by both `ci_mainline_only.yml` and `publish_wheel.yml`.
- **Tag-only publish convention**: `publish_wheel.yml` now exclusively uses `workflow_dispatch` with a `tag` input, formalizing the pattern that mainline validation and release publishing are separate concerns.
