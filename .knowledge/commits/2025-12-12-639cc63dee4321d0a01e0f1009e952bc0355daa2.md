# Move wheel build testing from nightly cron to per-mainline-commit and extract reusable composite action
## TL;DR
- Extract wheel-build logic into a reusable composite GitHub Action at `.github/actions/build-wheel-for-publish/action.yml`, consolidating checkout, C++ tests, cibuildwheel, and sdist steps.
- Add a `build-wheels` job to `ci_mainline_only.yml` so wheel builds run on every mainline push instead of a nightly cron.
- Refactor `publish_wheel.yml` to consume the new composite action, remove the nightly cron trigger (keep only `workflow_dispatch` with renamed input `tag`), and merge the separate `build_sdist` job into the matrix.

N/A -- infrastructure

## Impact
- API: none
- Behavioral: Wheel build validation now runs per-commit on mainline, providing faster feedback on wheel breakage. The publish workflow is now manual-only (`workflow_dispatch`) with a `tag` input replacing the old `branch` input. The separate `build_sdist` job is eliminated; sdist building is folded into the first matrix entry (`build_sdist: "true"`).
- Flags/config: `.gitignore` updated with exclusion rules (`!.github/actions/build-wheel-for-publish/`) to prevent the `build-*` glob from hiding the new composite action.
- Data formats/schemas: none
