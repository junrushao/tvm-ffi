# Move mainline wheel testing from nightly schedule to per-commit trigger

## TL;DR
- Extracts a reusable composite action `.github/actions/build-wheel-for-publish/action.yml` that encapsulates the full wheel build+test sequence (cpp tests, cibuildwheel, optional sdist).
- Adds a `build-wheels` job to `ci_mainline_only.yml` so that every mainline commit triggers wheel building across all six matrix targets (Linux x86_64/aarch64 × manylinux2014/manylinux_2_28, Windows AMD64, macOS arm64).
- Refactors `publish_wheel.yml` to delegate to the same composite action (removes the duplicated inline steps and the standalone `build_sdist` job); drops the nightly `schedule` trigger and tightens the manual-dispatch input from `branch` to `tag`.

## Impact
- API: none
- Behavioral: Wheel testing now runs on every push to mainline instead of nightly. The publish workflow no longer has a `schedule` trigger; publish is exclusively manual (`workflow_dispatch`) with a `tag` input rather than a `branch` input.
- Flags/config: New composite action inputs: `os`, `arch`, `linux_image`, `checkout_ref`, `build_wheels` (default `"true"`), `build_sdist` (default `"false"`). Matrix adds `build_sdist` column; the manylinux2014 x86_64 variant is the sole sdist builder.
