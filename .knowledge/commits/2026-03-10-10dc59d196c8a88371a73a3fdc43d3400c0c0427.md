# Extend TVMFFIFieldInfo setter to support FunctionObj dispatch

## TL;DR
- Adds `kTVMFFIFieldFlagBitSetterIsFunctionObj` (bit 11) to `TVMFFIFieldFlags`. When set, the `setter` member of `TVMFFIFieldInfo` holds a `TVMFFIObjectHandle` pointing to a `FunctionObj` (invoked with `(field_addr_as_OpaquePtr, value_as_AnyView)`), rather than a raw `TVMFFIFieldSetter` function pointer.
- Enables runtime-defined setter logic (e.g., Python-side `__ffi_convert__` wrapped in a `FunctionObj`).
- Updates all layers: C++ headers, Cython bindings, Rust FFI bindings.

## Key Exports

**New constant (`c_api.h`):**
- `kTVMFFIFieldFlagBitSetterIsFunctionObj = 1 << 11`

**Behavioral change in `FieldAccessor`** (`reflection/accessor.h`):
- `SetField` now checks bit 11: if set, interprets `setter` as `FunctionObj*` and invokes it; otherwise uses raw `TVMFFIFieldSetter` function pointer as before.

## Impact
- API: Breaking ABI change -- new flag bit in `TVMFFIFieldFlags` enum.
- Behavioral: Backward compatible for existing fields (bit 11 is off by default).
- Flags/config: none
- Data formats/schemas: none
