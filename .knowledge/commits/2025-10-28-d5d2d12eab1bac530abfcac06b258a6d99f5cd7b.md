# Fix clang-tidy warnings across core headers and testing code
## TL;DR
- Added NOLINT annotations to suppress false-positive clang-tidy warnings in core headers (`base_details.h`, `c_api.h`, `array.h`, `access_path.h`) and testing code (`testing.cc`).
- Fixed one genuine `performance-unnecessary-value-param` warning in `registry.h` by changing `const Class target` to `const Class& target` in a method-wrapping lambda.
- Prepares codebase for per-commit clang-tidy CI enforcement (PR #95).

None

## Impact
- API: none -- the `const Class` to `const Class&` change in `registry.h` is internal to a lambda in `ReflectionDefBase` and does not affect any public API signature.
- Behavioral: none -- all changes are lint annotations or a micro-optimization (pass-by-reference instead of by-value).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `StableHashBytes` (`base_details.h`) -- suppressed `clang-analyzer-security.ArrayBound` false positives in aligned/unaligned read paths. See [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md), [0009-ffi-structural-eq-hash](../design-records/0009-ffi-structural-eq-hash.md).
- `TVM_FFI_VERSION_*` macros (`c_api.h`) -- suppressed `modernize-macro-to-enum` since these must remain as C preprocessor macros for ABI stability. See [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md).
- `Array` iterator constructor/assign (`array.h`) -- suppressed `performance-unnecessary-value-param` false positive on template iterator parameters. See [0006-ffi-containers](../design-records/0006-ffi-containers.md).
- `AccessPath::FromSteps` (`access_path.h`) -- same suppression for template iterators. See [0007-ffi-reflection](../design-records/0007-ffi-reflection.md).
- `ReflectionDefBase` method wrapping (`registry.h`) -- fixed genuine by-value ObjectRef copy in lambda. See [0007-ffi-reflection](../design-records/0007-ffi-reflection.md).
- `__add_one_c_symbol` and pointer casts (`testing.cc`) -- suppressed `bugprone-reserved-identifier` and `bugprone-casting-through-void` in test helpers. See [0004-ffi-function-system](../design-records/0004-ffi-function-system.md).
