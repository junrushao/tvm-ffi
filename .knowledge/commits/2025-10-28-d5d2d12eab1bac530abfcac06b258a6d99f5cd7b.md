# Suppress clang-tidy warnings across headers and testing code

## TL;DR
- Adds NOLINT/NOLINTBEGIN/NOLINTEND annotations to suppress six categories of clang-tidy false positives across C++ headers and test code.
- Fixes one genuine issue: changes `const Class target` (by-value) to `const Class& target` in `ReflectionDefBase::def_method` wrapper lambda.
- Prepares the codebase for per-commit clang-tidy CI enforcement (PR #95).

## Key Exports
None (no new public API surface). One minor signature fix:

- **`ReflectionDefBase::def_method` internal lambda**: `const Class target` changed to `const Class& target` (avoids unnecessary copy of ObjectRef wrapper in method dispatch lambda).

## Impact
- API: none — the by-value vs by-reference change is internal to a lambda inside `def_method`; callers are unaffected.
- ABI: none — template instantiations are header-only and inline; no shared-library symbol changes.
- Behavioral: negligible — the `const Class&` fix avoids one redundant ref-count increment/decrement per reflected method call, but this was already a trivial cost.
- Flags/config: none
- Data formats/schemas: none

## Appendix: Suppressed Warnings by Category

| Warning ID | File(s) | Rationale |
|---|---|---|
| `clang-analyzer-security.ArrayBound` | `base_details.h` (StableHashBytes) | False positive on pointer arithmetic that is guarded by explicit bounds checks (`it + 8 <= end`). Converted two per-line NOLINTNEXTLINE to a single NOLINTBEGIN/END block. |
| `modernize-macro-to-enum` | `c_api.h` (version macros) | Version macros must remain `#define` for C compatibility and preprocessor consumption; cannot be converted to enum. |
| `performance-unnecessary-value-param` | `array.h`, `access_path.h` | Template iterator parameters (`IterType`, `Iter`) are typically lightweight (pointers/integers); clang-tidy cannot reason about template instantiations and incorrectly flags them. |
| `bugprone-reserved-identifier` | `testing.cc` (`__add_one_c_symbol`) | Double-underscore prefix is intentional — simulates a C module export symbol for testing the module loader. |
| `bugprone-casting-through-void` | `testing.cc` | Function-pointer-to-integer casts via `void*` are required for the C ABI function pointer handoff pattern in testing. |
