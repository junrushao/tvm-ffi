# Fix clang-tidy warnings with NOLINT annotations and a const-ref fix in reflection registry
## TL;DR
- Adds NOLINT annotations across headers and test code to suppress false-positive clang-tidy warnings (ArrayBound, modernize-macro-to-enum, performance-unnecessary-value-param, bugprone-reserved-identifier, bugprone-casting-through-void).
- Consolidates per-line NOLINTNEXTLINE into region-scoped NOLINTBEGIN/NOLINTEND where multiple suppressions share the same category.
- Fixes an actual code issue in `ReflectionDefBase`: method wrapper lambda now takes `const Class&` instead of `const Class` to avoid unnecessary ObjectRef copy.
