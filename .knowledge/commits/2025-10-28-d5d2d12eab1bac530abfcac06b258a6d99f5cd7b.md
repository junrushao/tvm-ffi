# Suppress clang-tidy warnings with NOLINT annotations and fix const-ref in ReflectionDefBase
## TL;DR
- Added NOLINT/NOLINTBEGIN/NOLINTEND comments across 6 files to suppress false-positive clang-tidy warnings (clang-analyzer-security.ArrayBound, modernize-macro-to-enum, performance-unnecessary-value-param, bugprone-reserved-identifier, bugprone-casting-through-void).
- Changed `const Class target` to `const Class& target` in `ReflectionDefBase::def_method` lambda wrapper to avoid unnecessary copy of ObjectRef wrapper (the only semantically meaningful change).

## Key Exports
None

## Impact
- API: none
- Behavioral: The `const Class&` change in `ReflectionDefBase` eliminates a copy of the ObjectRef wrapper when calling reflected methods. This is a micro-optimization; callers see no behavioral difference since ObjectRef is a lightweight ref-counted handle.
- Flags/config: none
- Data formats/schemas: none
