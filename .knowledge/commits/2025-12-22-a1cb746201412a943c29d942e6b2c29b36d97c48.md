# Rename CMake import targets to tvm_ffi::shared and tvm_ffi::header
## TL;DR
- Renames CMake imported targets: `tvm_ffi_shared` -> `tvm_ffi::shared`, `tvm_ffi_header` -> `tvm_ffi::header` to avoid name conflicts with locally defined targets.
- Updates all downstream references in examples, cubin launcher, and `tvm_ffi-config.cmake`.

## Impact
- API: Breaking change for downstream CMake consumers using the old target names `tvm_ffi_shared`/`tvm_ffi_header`.
- Flags/config: None.
- Data formats/schemas: None.
