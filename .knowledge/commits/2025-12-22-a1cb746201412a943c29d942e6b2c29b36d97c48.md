# Rename CMake imported targets from tvm_ffi_{shared,header} to tvm_ffi::{shared,header}
## TL;DR
- Renames CMake imported targets in `tvm_ffi-config.cmake` to use namespace syntax, avoiding name conflicts with build-tree targets defined in `CMakeLists.txt`.
- Updates all internal consumers (`Library.cmake`, `EmbedCubin.cmake`, examples, docs) to use the new names.

| Old name | New name |
|----------|----------|
| `tvm_ffi_shared` | `tvm_ffi::shared` |
| `tvm_ffi_header` | `tvm_ffi::header` |

Additionally, `tvm_ffi::header` is now declared as `INTERFACE IMPORTED` (was just `INTERFACE`), matching the `IMPORTED` qualifier already used by `tvm_ffi::shared`.

## Key Exports

**CMake targets** (in `cmake/tvm_ffi-config.cmake`):
- `tvm_ffi::header` -- `INTERFACE IMPORTED` library; provides include dirs + C++17 (renamed from `tvm_ffi_header`).
- `tvm_ffi::shared` -- `SHARED IMPORTED` library; provides include dirs + linked `libtvm_ffi` (renamed from `tvm_ffi_shared`).

## Impact
- API: **Breaking** for downstream CMake consumers using `find_package(tvm_ffi)`. Any `target_link_libraries(... tvm_ffi_shared)` or `target_link_libraries(... tvm_ffi_header)` must be updated to `tvm_ffi::shared` / `tvm_ffi::header`. Internal consumers (`tvm_ffi_configure_target`) are already updated.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

- **Namespaced CMake target convention**: Uses `tvm_ffi::` namespace prefix for imported targets, following CMake best practices (consistent with pybind11, nanobind patterns).

## Usage Examples

**Before** (broken after this commit):
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
target_link_libraries(my_ext PRIVATE tvm_ffi_header tvm_ffi_shared)
```

**After**:
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
target_link_libraries(my_ext PRIVATE tvm_ffi::header tvm_ffi::shared)
# Or use tvm_ffi_configure_target which handles this automatically:
tvm_ffi_configure_target(my_ext)
```
