# Rename CMake import targets tvm_ffi_shared/tvm_ffi_header to tvm_ffi::shared/tvm_ffi::header

## TL;DR
- `tvm_ffi-config.cmake` renamed import targets from flat names (`tvm_ffi_shared`, `tvm_ffi_header`) to CMake namespaced form (`tvm_ffi::shared`, `tvm_ffi::header`) to avoid conflicts with same-named targets in downstream `CMakeLists.txt`.
- `tvm_ffi::header` is now correctly declared as `INTERFACE IMPORTED` (was `INTERFACE` without `IMPORTED`); `tvm_ffi::shared` remains `SHARED IMPORTED`.
- `EmbedCubin.cmake` added a compatibility fallback that accepts either name, softening the breaking change for callers not using `tvm_ffi_configure_target`.

| Old name | New name |
|---|---|
| `tvm_ffi_header` | `tvm_ffi::header` |
| `tvm_ffi_shared` | `tvm_ffi::shared` |

## Key Exports

```python
# cmake/tvm_ffi-config.cmake — imported target declarations (pseudocode)
# add_library(tvm_ffi::header INTERFACE IMPORTED)
#   target_compile_features: cxx_std_17
#   target_include_directories: tvm_ffi_INCLUDE_DIR, tvm_ffi_DLPACK_INCLUDE_DIR
#   Interacts with: tvm_ffi_configure_target (LINK_HEADER), tvm_ffi_embed_cubin
#   Invariant: Must be declared before any call to tvm_ffi_configure_target

# add_library(tvm_ffi::shared SHARED IMPORTED)
#   target_compile_features: cxx_std_17
#   IMPORTED_LOCATION / IMPORTED_IMPLIB set from tvm_ffi_LIB_FILES
#   INTERFACE_INCLUDE_DIRECTORIES = tvm_ffi_INCLUDE_DIR + tvm_ffi_DLPACK_INCLUDE_DIR
#   Interacts with: tvm_ffi_configure_target (LINK_SHARED)

# cmake/Utils/EmbedCubin.cmake — compatibility shim added
# if (TARGET tvm_ffi::header): TVM_FFI_HEADER_TARGET = tvm_ffi::header
# elseif (TARGET tvm_ffi_header): TVM_FFI_HEADER_TARGET = tvm_ffi_header  # legacy fallback
# else: FATAL_ERROR
# Invariant: exactly one of the two names must exist at call time
```

## Impact
- API: **Breaking** for downstream CMake consumers that reference `tvm_ffi_header` or `tvm_ffi_shared` directly via `target_link_libraries`. They must switch to `tvm_ffi::header` / `tvm_ffi::shared`. Callers using `tvm_ffi_configure_target` are unaffected (that helper was updated). `tvm_ffi_embed_cubin` callers are unaffected (fallback shim added).
- Behavioral: None — purely a rename; no runtime behavior changes.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

After upgrade, downstream `CMakeLists.txt` must use the new names:

```cmake
# Before (now breaks unless going through tvm_ffi_configure_target)
target_link_libraries(my_target PRIVATE tvm_ffi_header tvm_ffi_shared)

# After
target_link_libraries(my_target PRIVATE tvm_ffi::header tvm_ffi::shared)

# Or use the helper (unchanged call, handles new names internally)
tvm_ffi_configure_target(my_target)
```
