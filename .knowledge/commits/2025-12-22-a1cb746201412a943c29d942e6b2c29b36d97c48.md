# Rename CMake imported targets from tvm_ffi_header/tvm_ffi_shared to tvm_ffi::header/tvm_ffi::shared
## TL;DR
- Renames CMake imported targets in `tvm_ffi-config.cmake` from `tvm_ffi_header` -> `tvm_ffi::header` and `tvm_ffi_shared` -> `tvm_ffi::shared` to avoid name conflicts with targets defined in the project's own `CMakeLists.txt`.
- Updates all downstream consumers: `Library.cmake`, `EmbedCubin.cmake`, example CMakeLists, and quickstart docs.
- `EmbedCubin.cmake` adds backward-compatible fallback: checks for `tvm_ffi::header` first, falls back to `tvm_ffi_header`.

| Old name | New name |
|---|---|
| `tvm_ffi_header` (imported INTERFACE) | `tvm_ffi::header` (imported INTERFACE IMPORTED) |
| `tvm_ffi_shared` (imported SHARED) | `tvm_ffi::shared` (imported SHARED IMPORTED) |

## Key Exports

```python
# === cmake/tvm_ffi-config.cmake ===
# Imported targets created by find_package(tvm_ffi):
#   OLD: tvm_ffi_header (INTERFACE), tvm_ffi_shared (SHARED IMPORTED)
#   NEW: tvm_ffi::header (INTERFACE IMPORTED), tvm_ffi::shared (SHARED IMPORTED)
# Interacts with: cmake/Utils/Library.cmake (tvm_ffi_configure_target links these)
# Interacts with: cmake/Utils/EmbedCubin.cmake (queries INTERFACE_INCLUDE_DIRECTORIES)
# Invariant: downstream find_package(tvm_ffi) consumers must use tvm_ffi::header / tvm_ffi::shared

# === cmake/Utils/EmbedCubin.cmake (backward compat addition) ===
# tvm_ffi_embed_cubin() now resolves header target dynamically:
#   if TARGET tvm_ffi::header -> use it
#   elif TARGET tvm_ffi_header -> use it (legacy fallback)
#   else -> FATAL_ERROR
# Interacts with: tvm_ffi-config.cmake (provides the target)
```

## Impact
- API: CMake imported target names changed. Any downstream `CMakeLists.txt` using `tvm_ffi_header` or `tvm_ffi_shared` directly (not via `tvm_ffi_configure_target`) must update to `tvm_ffi::header` / `tvm_ffi::shared`. The `tvm_ffi_configure_target()` wrapper handles this transparently.
- Behavioral: `tvm_ffi-config.cmake` now marks targets as `IMPORTED` (e.g., `add_library(tvm_ffi::header INTERFACE IMPORTED)` instead of just `INTERFACE`), which is the correct CMake idiom for config-file packages. Also removes `cmake-lint: disable=C0307` suppression.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **CMake config module** (`cmake/tvm_ffi-config.cmake`): the `find_package(tvm_ffi)` entry point that creates imported targets. Documented in [0013-packaging.md](../designs/0013-packaging.md).
- **CMake convenience functions** (`cmake/Utils/Library.cmake`): `tvm_ffi_configure_target()` which wraps target linking. Documented in [0013-packaging.md](../designs/0013-packaging.md).
- **CUBIN embedding utility** (`cmake/Utils/EmbedCubin.cmake`): `tvm_ffi_embed_cubin()` which queries header include dirs. Documented in [0018-cuda-extra-utilities.md](../designs/0018-cuda-extra-utilities.md).

Design elements this commit produces:
- No new design elements. This is a rename of existing CMake targets to follow the `namespace::target` convention standard in modern CMake.

## Usage Examples

Before (old target names):
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
add_library(my_ext SHARED src/extension.cc)
target_link_libraries(my_ext PRIVATE tvm_ffi_header)
target_link_libraries(my_ext PRIVATE tvm_ffi_shared)
```

After (new target names):
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
add_library(my_ext SHARED src/extension.cc)
target_link_libraries(my_ext PRIVATE tvm_ffi::header tvm_ffi::shared)
```

Or via the convenience wrapper (unchanged):
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
add_library(my_ext SHARED src/extension.cc)
tvm_ffi_configure_target(my_ext)
```
