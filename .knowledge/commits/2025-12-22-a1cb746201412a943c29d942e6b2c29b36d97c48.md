# build: Rename CMake import targets from tvm_ffi_header/tvm_ffi_shared to tvm_ffi::header/tvm_ffi::shared

## TL;DR
- Renamed CMake IMPORTED targets from `tvm_ffi_header` / `tvm_ffi_shared` to `tvm_ffi::header` / `tvm_ffi::shared` (namespaced form, standard CMake convention)
- Updated all callers: `cmake/Utils/Library.cmake`, `cmake/tvm_ffi-config.cmake`, all example `CMakeLists.txt` files
- Updated docs `get_started/quickstart.rst` to reference new target names

## Rename Mapping

| Old name | New name |
|---|---|
| `tvm_ffi_header` | `tvm_ffi::header` |
| `tvm_ffi_shared` | `tvm_ffi::shared` |

## Key Exports

```python
# cmake find_package targets (after this commit):
# tvm_ffi::header — INTERFACE IMPORTED, provides include dirs + cxx_std_17
# tvm_ffi::shared — SHARED IMPORTED, provides the .so/.dylib/.dll + cxx_std_17
# Interacts with: tvm_ffi_configure_target(), all downstream CMakeLists.txt
```

## Impact
- API: Breaking for any downstream CMake project that references `tvm_ffi_header` or `tvm_ffi_shared` directly — must update to namespaced form
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cmake
# Before:
find_package(tvm_ffi REQUIRED)

# After:

target_link_libraries(my_ext PRIVATE tvm_ffi::shared)

# Or use the helper (recommended):
tvm_ffi_configure_target(my_ext LINK_SHARED ON)
```
