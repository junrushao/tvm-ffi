# Fix test_stl segfault by enforcing module-object lifetime ordering
## TL;DR
- Adds `gc.collect()` + `del mod` to `test_stl.py` to force garbage collection of module-created objects before the module is unloaded.
- Prevents segfaults caused by calling destructors in an already-unloaded shared library.

## Design Elements
Design elements this commit consumes:
- **Module-object lifetime invariant** ([0011-ffi-module-system](../design-records/0011-ffi-module-system.md), "Library lifetime" contract): objects returned by module-loaded functions may have deleters residing in the library code; the Module must remain loaded until all such objects are destroyed. This commit enforces that invariant in the `test_stl` test by explicitly triggering GC and deleting the module reference after the nested `run_check()` scope returns.
