# Fix missing unified_api.h include in device_guard.h after CUDA API unification
## TL;DR
- `device_guard.h` included `cuda/base.h` but after PR #300 (b16f11f6) moved `TVM_FFI_CHECK_CUDA_ERROR` to `cuda/internal/unified_api.h`, causing an undefined-macro compilation error.
- Fix: replace `#include <tvm/ffi/extra/cuda/base.h>` with `#include <tvm/ffi/extra/cuda/internal/unified_api.h>`.
