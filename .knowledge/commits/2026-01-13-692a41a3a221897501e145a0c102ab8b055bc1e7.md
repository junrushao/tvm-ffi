# Fix missing unified_api.h include in device_guard.h causing TVM_FFI_CHECK_CUDA_ERROR undefined

## TL;DR
- `include/tvm/ffi/extra/cuda/device_guard.h` previously included `base.h` which defines `TVM_FFI_CHECK_CUDA_ERROR`.
- After PR #300 (commit 10cb004) isolated `unified_api.h`, `device_guard.h` needed `unified_api.h` instead of `base.h` for `TVM_FFI_CHECK_CUDA_ERROR`.
- Fix: change `#include <tvm/ffi/extra/cuda/base.h>` → `#include <tvm/ffi/extra/cuda/internal/unified_api.h>`.

None — single include change, no API surface change.

## Impact

- Behavioral: fixes compile error when `device_guard.h` is included standalone (after #300).
