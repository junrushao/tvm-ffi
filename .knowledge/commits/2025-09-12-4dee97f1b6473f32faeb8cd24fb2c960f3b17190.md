# Rename DLPack speed converter typedefs and functions for clarity
## TL;DR
- Renamed DLPack speed converter typedefs and functions: `DLPackPyObjectExporter` -> `DLPackFromPyObject`, `DLPackPyObjectImporter` -> `DLPackToPyObject`, and all derived names throughout Cython bindings, torch C DLPack extension, and the C helper header.
- Renamed Python dunder attributes on tensor classes: `__c_dlpack_exporter__` -> `__c_dlpack_from_pyobject__`, `__c_dlpack_importer__` -> `__c_dlpack_to_pyobject__`.
- Version bump `0.1.0a11` -> `0.1.0a12`. Minor: added `#if TORCH_VERSION` guard around `Float4_e2m1fn_x2` DLDataType case.

| Old Name | New Name | Layer |
|----------|----------|-------|
| `DLPackPyObjectExporter` | `DLPackFromPyObject` | C typedef (`tvm_ffi_python_helpers.h`) |
| `DLPackPyObjectImporter` | `DLPackToPyObject` | C typedef (`tvm_ffi_python_helpers.h`) |
| `TorchDLPackPyObjectExporter` | `TorchDLPackFromPyObject` | C function (`_optional_torch_c_dlpack.py`) |
| `TorchDLPackPyObjectImporter` | `TorchDLPackToPyObject` | C function (`_optional_torch_c_dlpack.py`) |
| `TorchDLPackPyObjectExporterPtr` | `TorchDLPackFromPyObjectPtr` | C function (`_optional_torch_c_dlpack.py`) |
| `TorchDLPackPyObjectImporterPtr` | `TorchDLPackToPyObjectPtr` | C function (`_optional_torch_c_dlpack.py`) |
| `c_dlpack_exporter` | `c_dlpack_from_pyobject` | struct field (`TVMFFIPyArgSetter`) |
| `c_dlpack_importer` | `c_dlpack_to_pyobject` | struct field (`TVMFFIPyCallContext`, `TVMFFIPyArgSetter`) |
| `__c_dlpack_exporter__` | `__c_dlpack_from_pyobject__` | Python dunder attribute |
| `__c_dlpack_importer__` | `__c_dlpack_to_pyobject__` | Python dunder attribute |
| `TorchDLPackPyObjectImporterFallback_` | `TorchDLPackToPyObjectFallback_` | Cython function (`function.pxi`) |
| `_dltensor_test_wrapper_c_dlpack_exporter` | `_dltensor_test_wrapper_c_dlpack_from_pyobject` | Cython function (`tensor.pxi`) |
| `_dltensor_test_wrapper_c_dlpack_exporter_as_intptr` | `_dltensor_test_wrapper_c_dlpack_from_pyobject_as_intptr` | Cython function (`tensor.pxi`) |
| `TVM_FFI_SKIP_C_DLPACK_EXPORTER` | `TVM_FFI_SKIP_c_dlpack_from_pyobject` | env var (`function.pxi`) |

## Key Exports

The rename clarifies directionality: "FromPyObject" = extract DLPack from a Python tensor, "ToPyObject" = wrap DLPack as a Python tensor. No behavioral change.

```python
# C typedef (tvm_ffi_python_helpers.h)
# Old: DLPackPyObjectExporter -> New: DLPackFromPyObject
DLPackFromPyObject = Callable[[void_ptr, DLManagedTensorVersioned_ptr_ptr, void_ptr_ptr], int]
# Interacts with: TVMFFIPyArgSetter.c_dlpack_from_pyobject, torch C extension

# Old: DLPackPyObjectImporter -> New: DLPackToPyObject
DLPackToPyObject = Callable[[DLManagedTensorVersioned_ptr, void_ptr_ptr], int]
# Interacts with: TVMFFIPyCallContext.c_dlpack_to_pyobject, make_tensor_from_chandle()

# Struct fields (tvm_ffi_python_helpers.h)
class TVMFFIPyArgSetter:
    c_dlpack_from_pyobject: DLPackFromPyObject  # was: c_dlpack_exporter
    c_dlpack_to_pyobject: DLPackToPyObject       # was: c_dlpack_importer
    c_dlpack_tensor_allocator: DLPackTensorAllocator

class TVMFFIPyCallContext:
    c_dlpack_to_pyobject: DLPackToPyObject  # was: c_dlpack_importer
    c_dlpack_tensor_allocator: DLPackTensorAllocator

# Python dunder protocol on tensor classes (e.g. torch.Tensor)
# __c_dlpack_from_pyobject__: int  # was: __c_dlpack_exporter__
# __c_dlpack_to_pyobject__: int    # was: __c_dlpack_importer__
```

## Impact
- API: Breaking rename of Python dunder attributes (`__c_dlpack_exporter__` -> `__c_dlpack_from_pyobject__`, `__c_dlpack_importer__` -> `__c_dlpack_to_pyobject__`). Any external code that sets these attributes on custom tensor types must update. Also renames the env var `TVM_FFI_SKIP_C_DLPACK_EXPORTER` -> `TVM_FFI_SKIP_c_dlpack_from_pyobject`.
- Behavioral: none -- pure rename, identical semantics.
- Flags/config: Env var renamed `TVM_FFI_SKIP_C_DLPACK_EXPORTER` -> `TVM_FFI_SKIP_c_dlpack_from_pyobject`.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- DLPack speed converter protocol (C function pointer typedefs for fast PyObject<->DLManagedTensorVersioned conversion, used in Cython FFI call path). See `.knowledge/design-records/0012-ffi-python-package.md`.
- `TVMFFIPyArgSetter` / `TVMFFIPyCallContext` structs in `tvm_ffi_python_helpers.h` that carry DLPack converter function pointers through the packed-function call pipeline.

Design elements this commit produces:
- None -- pure rename, no new design elements introduced.

## Usage Examples

Before/after for external tensor types implementing the DLPack speed converter protocol:

```python
# Before (0.1.0a11):
torch.Tensor.__c_dlpack_exporter__ = mod.TorchDLPackPyObjectExporterPtr()
torch.Tensor.__c_dlpack_importer__ = mod.TorchDLPackPyObjectImporterPtr()

# After (0.1.0a12):
torch.Tensor.__c_dlpack_from_pyobject__ = mod.TorchDLPackFromPyObjectPtr()
torch.Tensor.__c_dlpack_to_pyobject__ = mod.TorchDLPackToPyObjectPtr()
```
