# Rename DLPack speed converter typedefs and attributes for clarity
## TL;DR
- Renames DLPack "speed converter" function-pointer typedefs and struct fields from `Exporter`/`Importer` terminology to `FromPyObject`/`ToPyObject`, making data-flow direction explicit.
- Renames corresponding Python dunder attributes (`__c_dlpack_exporter__` -> `__c_dlpack_from_pyobject__`, etc.) and the Torch JIT-compiled function entry points.
- Bumps package version from `0.1.0a11` to `0.1.0a12`. Adds a `#if TORCH_VERSION` guard for `Float4_e2m1fn_x2` scalar type (Torch >=2.8 only).

| Old name | New name | Layer |
|---|---|---|
| `DLPackPyObjectExporter` (typedef) | `DLPackFromPyObject` | C header (`tvm_ffi_python_helpers.h`) |
| `DLPackPyObjectImporter` (typedef) | `DLPackToPyObject` | C header |
| `TVMFFIPyArgSetter.c_dlpack_exporter` | `TVMFFIPyArgSetter.c_dlpack_from_pyobject` | C struct field |
| `TVMFFIPyArgSetter.c_dlpack_importer` | `TVMFFIPyArgSetter.c_dlpack_to_pyobject` | C struct field |
| `TVMFFIPyCallContext.c_dlpack_importer` | `TVMFFIPyCallContext.c_dlpack_to_pyobject` | C struct field |
| `TorchDLPackPyObjectExporter` | `TorchDLPackFromPyObject` | Torch addon (Python/C++) |
| `TorchDLPackPyObjectImporter` | `TorchDLPackToPyObject` | Torch addon (Python/C++) |
| `TorchDLPackPyObjectExporterPtr` | `TorchDLPackFromPyObjectPtr` | Torch addon (JIT export) |
| `TorchDLPackPyObjectImporterPtr` | `TorchDLPackToPyObjectPtr` | Torch addon (JIT export) |
| `TorchDLPackPyObjectImporterFallback_` | `TorchDLPackToPyObjectFallback_` | Cython (function.pxi) |
| `__c_dlpack_exporter__` (dunder attr) | `__c_dlpack_from_pyobject__` | Python protocol attribute |
| `__c_dlpack_importer__` (dunder attr) | `__c_dlpack_to_pyobject__` | Python protocol attribute |
| `_dltensor_test_wrapper_c_dlpack_exporter` | `_dltensor_test_wrapper_c_dlpack_from_pyobject` | Cython test helper |
| `_dltensor_test_wrapper_c_dlpack_exporter_as_intptr` | `_dltensor_test_wrapper_c_dlpack_from_pyobject_as_intptr` | Cython test helper |
| `TVM_FFI_SKIP_C_DLPACK_EXPORTER` (env var) | `TVM_FFI_SKIP_c_dlpack_from_pyobject` | Environment variable |

## Key Exports

```python
# C-style function pointer typedefs (from tvm_ffi_python_helpers.h)
# Old: DLPackPyObjectExporter -> New: DLPackFromPyObject
DLPackFromPyObject = Callable[[void_ptr, Ptr[DLManagedTensorVersioned], Ptr[void_ptr]], int]
# Interacts with: TVMFFIPyArgSetter.c_dlpack_from_pyobject, Torch JIT extension
# Invariant: returns 0 on success, -1 on error (Python exception protocol)

# Old: DLPackPyObjectImporter -> New: DLPackToPyObject
DLPackToPyObject = Callable[[Ptr[DLManagedTensorVersioned], Ptr[void_ptr]], int]
# Interacts with: TVMFFIPyCallContext.c_dlpack_to_pyobject, make_tensor_from_chandle()
# Invariant: returns 0 on success; py_obj_out holds a new reference on success

class TVMFFIPyArgSetter:
    """Setter struct populated by factory for each Python argument."""
    func: Callable[..., int]
    c_dlpack_from_pyobject: DLPackFromPyObject  # was: c_dlpack_exporter
    c_dlpack_to_pyobject: DLPackToPyObject       # was: c_dlpack_importer
    c_dlpack_tensor_allocator: DLPackTensorAllocator

class TVMFFIPyCallContext:
    """Per-call context threaded through argument setting."""
    c_dlpack_to_pyobject: DLPackToPyObject  # was: c_dlpack_importer
    c_dlpack_tensor_allocator: DLPackTensorAllocator
    # Interacts with: TVMFFIPyCallManager.Call(), make_ret(), make_tensor_from_any()

# Python dunder protocol attributes (set on torch.Tensor by Torch addon):
# torch.Tensor.__c_dlpack_from_pyobject__ : int  (was __c_dlpack_exporter__)
# torch.Tensor.__c_dlpack_to_pyobject__   : int  (was __c_dlpack_importer__)
# torch.Tensor.__c_dlpack_tensor_allocator__ : int  (unchanged)
```

## Impact
- API: Renames C typedefs, struct fields, and Python dunder attributes. Any out-of-tree code using `DLPackPyObjectExporter`, `DLPackPyObjectImporter`, `__c_dlpack_exporter__`, or `__c_dlpack_importer__` must update. The old `TVM_FFI_SKIP_C_DLPACK_EXPORTER` env var is replaced by `TVM_FFI_SKIP_c_dlpack_from_pyobject`.
- Behavioral: None -- pure rename, no semantic change.
- Flags/config: Environment variable `TVM_FFI_SKIP_C_DLPACK_EXPORTER` renamed to `TVM_FFI_SKIP_c_dlpack_from_pyobject`.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **DLPack speed converter protocol**: The C-function-pointer-based fast path for converting between Python tensor objects and `DLManagedTensorVersioned`, bypassing the generic FFI packed-function call. This protocol is consumed by `TVMFFIPyArgSetter` (arg conversion) and `TVMFFIPyCallManager` (return value conversion). See [0012-python-bindings.md](../designs/0012-python-bindings.md).
- **Torch C DLPack addon**: The optional JIT-compiled Torch extension (`_optional_torch_c_dlpack.py`) that registers speed converter pointers on `torch.Tensor`.

Design elements this commit produces:
- None (rename only -- no new design elements introduced).

## Usage Examples
Before (old naming):
```python
# Torch addon sets old dunder attributes
torch.Tensor.__c_dlpack_exporter__ = mod.TorchDLPackPyObjectExporterPtr()
torch.Tensor.__c_dlpack_importer__ = mod.TorchDLPackPyObjectImporterPtr()

# Cython checks for old attribute
if hasattr(arg, "__c_dlpack_exporter__"):
    temp_ptr = arg.__c_dlpack_exporter__
```

After (new naming):
```python
# Torch addon sets new dunder attributes
torch.Tensor.__c_dlpack_from_pyobject__ = mod.TorchDLPackFromPyObjectPtr()
torch.Tensor.__c_dlpack_to_pyobject__ = mod.TorchDLPackToPyObjectPtr()

# Cython checks for new attribute
if hasattr(arg, "__c_dlpack_from_pyobject__"):
    temp_ptr = arg.__c_dlpack_from_pyobject__
```
