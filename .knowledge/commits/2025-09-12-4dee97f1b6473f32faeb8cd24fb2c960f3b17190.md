# Rename DLPack speed converter symbols from Exporter/Importer to FromPyObject/ToPyObject
## TL;DR
- Renames all DLPack speed-converter typedefs, functions, struct fields, and dunder attributes from `Exporter`/`Importer` naming to `FromPyObject`/`ToPyObject` naming to clarify data-flow direction.
- Version bump to `0.1.0a12`.
- Adds `#if TORCH_VERSION` guard around `Float4_e2m1fn_x2` in the torch DLPack extension for backward compatibility.

## Key Exports

```python
# C-style function pointer typedefs (in tvm_ffi_python_helpers.h)
# Old: DLPackPyObjectExporter -> New: DLPackFromPyObject
DLPackFromPyObject = Callable[[void_ptr, DLManagedTensorVersioned_pp, void_pp], int]
# Interacts with: TVMFFIPyArgSetter.c_dlpack_from_pyobject, torch C DLPack extension
# Invariant: returns 0 on success, -1 on error

# Old: DLPackPyObjectImporter -> New: DLPackToPyObject
DLPackToPyObject = Callable[[DLManagedTensorVersioned_ptr, void_pp], int]
# Interacts with: TVMFFIPyCallContext.c_dlpack_to_pyobject, make_tensor_from_chandle()
# Invariant: returns 0 on success, -1 on error; py_obj_out holds new reference

class TVMFFIPyArgSetter:
    """Per-argument conversion context for packed function calls."""
    func: Callable  # setter function
    c_dlpack_from_pyobject: DLPackFromPyObject   # was: c_dlpack_exporter
    c_dlpack_to_pyobject: DLPackToPyObject        # was: c_dlpack_importer
    c_dlpack_tensor_allocator: DLPackTensorAllocator

class TVMFFIPyCallContext:
    """Call-scoped context carrying device/stream and converter state."""
    c_dlpack_to_pyobject: DLPackToPyObject  # was: c_dlpack_importer
    c_dlpack_tensor_allocator: DLPackTensorAllocator

# Dunder protocol attributes set on torch.Tensor:
# torch.Tensor.__c_dlpack_from_pyobject__  (was __c_dlpack_exporter__)
# torch.Tensor.__c_dlpack_to_pyobject__    (was __c_dlpack_importer__)
# torch.Tensor.__c_dlpack_tensor_allocator__  (unchanged)
```

## Impact
- API: Renames dunder attributes (`__c_dlpack_exporter__` -> `__c_dlpack_from_pyobject__`, `__c_dlpack_importer__` -> `__c_dlpack_to_pyobject__`) on `torch.Tensor`. Any external code checking for or setting these attributes must update. Also renames env var `TVM_FFI_SKIP_C_DLPACK_EXPORTER` to `TVM_FFI_SKIP_c_dlpack_from_pyobject`.
- Behavioral: None -- pure rename, no functional change.
- Flags/config: Env var `TVM_FFI_SKIP_C_DLPACK_EXPORTER` renamed to `TVM_FFI_SKIP_c_dlpack_from_pyobject`.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- DLPack speed converter protocol (typedef function pointers + dunder attrs on tensor types) from 0012-python-bindings and 0006-containers (Tensor/DLPack interop).
- `TVMFFIPyCallManager` call machinery from `tvm_ffi_python_helpers.h`.

Design elements this commit produces:
- None new -- this is a pure rename with no new contracts or protocols.

## Usage Examples
Before/after for any external tensor type implementing the DLPack speed protocol:

```python
# Before (old naming)
class MyTensor:
    __c_dlpack_exporter__ = my_exporter_func_ptr()
    __c_dlpack_importer__ = my_importer_func_ptr()
    __c_dlpack_tensor_allocator__ = my_allocator_func_ptr()

# After (new naming)
class MyTensor:
    __c_dlpack_from_pyobject__ = my_from_pyobject_func_ptr()
    __c_dlpack_to_pyobject__ = my_to_pyobject_func_ptr()
    __c_dlpack_tensor_allocator__ = my_allocator_func_ptr()  # unchanged
```
