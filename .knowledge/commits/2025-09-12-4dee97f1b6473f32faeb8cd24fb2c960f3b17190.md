# Rename DLPack speed converter typedefs and attributes from Exporter/Importer to FromPyObject/ToPyObject
## TL;DR
- Renames all DLPack "speed converter" C typedefs, struct fields, Python dunder attributes, Cython wrapper names, and torch addon functions from the `Exporter`/`Importer` naming to `FromPyObject`/`ToPyObject` naming to clarify data-flow direction.
- Adds `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` guard around `Float4_e2m1fn_x2` in the torch C DLPack addon.
- Bumps package version from `0.1.0a11` to `0.1.0a12`.

## Key Exports

**Typedefs** (in `python/tvm_ffi/cython/tvm_ffi_python_helpers.h`):
- `DLPackFromPyObject`: `int (*)(void* py_obj, DLManagedTensorVersioned** out, void** env_stream)` -- converts a PyObject tensor to a DLPack versioned tensor.
- `DLPackToPyObject`: `int (*)(DLManagedTensorVersioned* tensor, void** py_obj_out)` -- converts a DLPack versioned tensor back to a PyObject tensor.

**Struct fields** (same header):
- `TVMFFIPyArgSetter.c_dlpack_from_pyobject` (`DLPackFromPyObject`) -- optional converter attached to arg setters for DLPack-compatible external tensors.
- `TVMFFIPyArgSetter.c_dlpack_to_pyobject` (`DLPackToPyObject`) -- optional reverse converter.
- `TVMFFIPyCallContext.c_dlpack_to_pyobject` (`DLPackToPyObject`) -- per-call context converter used by `make_ret` to convert result tensors back to framework objects.

**Python dunder protocol** (on `torch.Tensor` or any DLPack-compatible type):
- `__c_dlpack_from_pyobject__`: `int64_t` -- function pointer (as int) for PyObject-to-DLPack conversion.
- `__c_dlpack_to_pyobject__`: `int64_t` -- function pointer (as int) for DLPack-to-PyObject conversion.
- `__c_dlpack_tensor_allocator__`: unchanged.

**Environment variable**:
- `TVM_FFI_SKIP_c_dlpack_from_pyobject` (was `TVM_FFI_SKIP_C_DLPACK_EXPORTER`) -- set to `"1"` to bypass the C DLPack fast path.

## Impact
- API: The Python dunder attributes `__c_dlpack_exporter__` and `__c_dlpack_importer__` are renamed to `__c_dlpack_from_pyobject__` and `__c_dlpack_to_pyobject__`. Any external code that sets these attributes on custom tensor types must update. The environment variable `TVM_FFI_SKIP_C_DLPACK_EXPORTER` is renamed to `TVM_FFI_SKIP_c_dlpack_from_pyobject`.
- ABI: The C typedefs `DLPackPyObjectExporter` and `DLPackPyObjectImporter` are renamed, and the struct fields in `TVMFFIPyArgSetter` and `TVMFFIPyCallContext` are renamed. The torch addon's exported C function names change. Any external code linking against these symbols must update.
- Behavioral: No semantic changes to existing functions. The `Float4_e2m1fn_x2` case now has a torch version guard (`>= 2.8`), preventing compilation errors on older torch versions.
- Flags/config: Environment variable renamed (see above). Note the new name uses mixed case, which is unconventional for env vars.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **DLPack speed converter protocol** (`tvm_ffi_python_helpers.h`): The C-level fast-path mechanism that bypasses Python's `__dlpack__` protocol by using direct C function pointers stored as Python class attributes. See `.knowledge/designs/0014-python-bindings.md` lines ~98-99 for DLPack argument dispatch.
- **Cython arg setter factory** (`function.pxi`): The `TVMFFIPyArgSetterFactory_` isinstance chain that detects `__c_dlpack_from_pyobject__` (formerly `__c_dlpack_exporter__`) on argument types and selects the DLPack C exporter fast path.
- **`make_ret` tensor conversion** (`function.pxi`, `tensor.pxi`): The return-value conversion path that uses the call context's DLPack-to-PyObject converter to return framework-native tensor objects.

Design elements this commit produces:
- None new. This is a pure rename of existing design elements.

## Usage Examples
None -- pure rename, no new functionality. External consumers of the dunder protocol must update attribute names:

```python
# Before
torch.Tensor.__c_dlpack_exporter__ = my_exporter_ptr
torch.Tensor.__c_dlpack_importer__ = my_importer_ptr

# After
torch.Tensor.__c_dlpack_from_pyobject__ = my_exporter_ptr
torch.Tensor.__c_dlpack_to_pyobject__ = my_importer_ptr
```
