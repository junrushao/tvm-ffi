# Build Python __init__ from C++ field reflection at runtime using KWARGS sentinel protocol

## TL;DR
- `_make_init()` and `_make_init_signature()` in `registry.py` build a Python `__init__` that unpacks keyword args through the KWARGS sentinel protocol into `__ffi_init__`, using `TypeField.c_init/c_kw_only/c_has_default` flags read from C++ reflection metadata.
- `_install_init()` now distinguishes `auto_init=True` methods (use new `_make_init` path) from non-auto-init `__ffi_init__` (forward directly, preserving prior behavior).
- Two new C++ field bitmask flags (`kTVMFFIFieldFlagBitMaskInitOff = 1 << 9`, `kTVMFFIFieldFlagBitMaskKwOnly = 1 << 10`) are decoded into `TypeField.c_init`, `TypeField.c_kw_only`, and `TypeField.c_has_default` on the Python Cython side.
- `core.KWARGS` singleton exposes the C++ kwargs sentinel object needed by `__ffi_init__` when invoked from Python.

## Key Exports

```python
# python/tvm_ffi/registry.py

def _make_init(type_cls: type, type_info: TypeInfo) -> Callable[..., None]:
    """Build a Python __init__ delegating to __ffi_init__ via KWARGS sentinel protocol.
    # Interacts with: core.KWARGS, TypeField.c_init/c_kw_only/c_has_default
    # Invariant: __init__ signature is derived from TypeInfo.fields filtered by c_init=True
    # Invariant: sets __signature__, __qualname__, __module__ on the synthesized __init__
    # Invariant: called only when __ffi_init__.metadata['auto_init'] is True
    """
    kwargs_obj = core.KWARGS

    def __init__(self: Any, *args: Any, **kwargs: Any) -> None:
        ffi_args: list[Any] = list(args)
        ffi_args.append(kwargs_obj)        # kwargs sentinel marks start of kw section
        for key, val in kwargs.items():
            ffi_args.append(key)           # alternating key/value pairs
            ffi_args.append(val)
        self.__ffi_init__(*ffi_args)

    __init__.__signature__ = _make_init_signature(type_info)
    return __init__
```

## Impact
- API: `register_object`-decorated classes with C++ `refl::init()` + `auto_init=True` metadata now automatically get a typed Python `__init__` with correct positional/kw-only/default parameter structure, without needing `@c_class`. The prior `__c_ffi_init__` forwarding path (for non-auto-init `__ffi_init__`) is preserved.
- Behavioral: `_add_class_attrs` now always overrides `__c_ffi_init__` (no `has_c_init` guard), and `__tvm_ffi_type_info__` is assigned *before* `_add_class_attrs` runs (ordering swap from prior code). The error message for missing `__ffi_init__` is now a `TypeError` with actionable guidance, not a `RuntimeError`.
- Flags/config: ruff rule `D107` (undocumented public `__init__`) is now suppressed in `pyproject.toml`.
- Data formats/schemas: `TypeField` gains three new boolean fields (`c_init`, `c_kw_only`, `c_has_default`) parsed from C++ field flag bitmasks.

Design elements this commit produces:
- `_make_init()` + `_make_init_signature()`: new internal API that synthesizes a runtime Python `__init__` from C++ reflection metadata via the KWARGS sentinel protocol.
- `core.KWARGS` sentinel: module-level object bridging Python kwargs dispatch to C++ `__ffi_init__` packed-call convention.
- New `TypeField` boolean fields `c_init`, `c_kw_only`, `c_has_default`: runtime-readable auto-init control flags derived from C++ `TVMFFIFieldInfo.flags`.
- Seven new `_TestCxxAutoInit*` test fixture classes in `tvm_ffi.testing` covering all combinations of init/kw-only/default/inheritance.

## Usage Examples

**End-to-end: C++ ObjectDef → Python `_TestCxxAutoInitSimple(1, 2)`**

```python
# C++ side (in libtvm_ffi_testing):
#   ObjectDef<TestCxxAutoInitSimpleObj>()
#       .def_ro("x", &Obj::x)
#       .def_ro("y", &Obj::y)
#       .def(refl::init<int64_t, int64_t>())  # → __ffi_init__ with auto_init=True

# Python side (auto-wired by _install_init via _make_init):
@register_object("testing.TestCxxAutoInitSimple")
class _TestCxxAutoInitSimple(Object):
    x: int
    y: int
    # __init__(self, x: int, y: int) synthesized automatically at class registration time

obj = _TestCxxAutoInitSimple(10, 20)
assert obj.x == 10 and obj.y == 20

# Low-level: _make_init translates kwargs to __ffi_init__ KWARGS protocol:
#   obj.__ffi_init__(10, 20)             # positional call, no KWARGS sentinel
#   obj.__ffi_init__(10, core.KWARGS, "y", 20)  # keyword call with sentinel
```

**Inheritance auto-init:**

```python
# _TestCxxAutoInitChild.__init__ signature includes parent fields first:
# __init__(self, parent_required: int, child_required: int, parent_default: int = ..., *, child_kw_only: int)
child = _TestCxxAutoInitChild(parent_required=1, child_required=2, child_kw_only=3)
assert child.parent_required == 1
```
