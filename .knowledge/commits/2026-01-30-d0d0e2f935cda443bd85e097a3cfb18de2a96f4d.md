# Add Rust binding for Array<T> container with mutation, AnyCompatible, and iterator support

## TL;DR
- Introduces `rust/tvm-ffi/src/collections/array.rs` (341 lines): `ArrayObj` (`#[repr(C)]`) and `Array<T>` with full mutation API (`push`, `pop`, `insert`, `remove`, `clear`) plus `AnyCompatible` impl for roundtrip through `Any`/`AnyView`.
- Fixes `Any::into_raw_ffi_any` to wrap `self` in `ManuallyDrop` before reading `data` to prevent double-drop.
- `Array<T>` implements `ObjectRefCore`, `FromIterator<T>`, `Extend<T>`, `Index<usize>`.

## Key Exports

```rust
// rust/tvm-ffi/src/collections/array.rs

#[repr(C)]
#[derive(Object)]
#[type_key = "ffi.Array"]
#[type_index(TypeIndex::kTVMFFIArray)]
pub struct ArrayObj {
    pub object: Object,
    pub data: *mut c_void,   // Pointer to element buffer (AddressOf(0))
    pub size: i64,
    pub capacity: i64,
    pub data_deleter: Option<unsafe extern "C" fn(*mut c_void)>,
}
// Invariant: elements stored inline after ArrayObj header (ObjectCoreWithExtraItems<ExtraItem=TVMFFIAny>)
// Interacts with: ObjectArc::new_with_extra_items, C++ Array<T> layout

pub struct Array<T: AnyCompatible + Clone> {
    data: ObjectArc<ArrayObj>,
    _marker: PhantomData<T>,
}
// Invariant: T must be AnyCompatible + Clone; ref-counts managed on get/push/remove
// Interacts with: AnyCompatible::inc_ref/dec_ref, ObjectRefCore

impl<T: AnyCompatible + Clone> Array<T> {
    pub fn new(items: Vec<T>) -> Self: ...
    pub fn len(&self) -> usize: ...
    pub fn is_empty(&self) -> bool: ...
    pub fn get(&self, idx: usize) -> Option<T>: ...  # calls inc_ref
    pub fn push(&mut self, item: T): ...             # may reallocate
    pub fn pop(&mut self) -> Option<T>: ...          # calls dec_ref
    pub fn insert(&mut self, idx: usize, item: T): ...
    pub fn remove(&mut self, idx: usize) -> T: ...
    pub fn clear(&mut self): ...                     # calls dec_ref on all elements
    // Extension: implement AnyCompatible for new element types to use as Array<NewType>
}

// AnyCompatible roundtrip
impl<T: AnyCompatible + Clone> AnyCompatible for Array<T>: ...
// Interacts with: Any, AnyView, TryFromTemp

// Bug fix in any.rs:
// Any::into_raw_ffi_any now wraps self in ManuallyDrop to prevent double-drop
pub unsafe fn into_raw_ffi_any(this: Self) -> TVMFFIAny {
    let this = std::mem::ManuallyDrop::new(this);
    this.data  // Safe: ownership transferred to caller
}
```

## Impact
- API: New `Array<T>` type in `rust/tvm-ffi/src/collections/`. `mod.rs` exports `Array`.
- Behavioral: `Any::into_raw_ffi_any` previously could double-drop; now fixed with `ManuallyDrop`.
- Flags/config: none
- Data formats/schemas: `ArrayObj` layout must match C++ `ffi::ArrayObj` exactly (enforced by `#[repr(C)]` + `type_index(kTVMFFIArray)`).

## Usage Examples

```rust
use tvm_ffi::collections::Array;
use tvm_ffi::Any;

// Create and mutate
let mut arr: Array<i64> = Array::new(vec![1, 2, 3]);
arr.push(4);
arr.insert(0, 0);
assert_eq!(arr.len(), 5);
assert_eq!(arr.get(0), Some(0i64));

// Roundtrip through Any
let any = Any::from(arr);
let arr2: Array<i64> = any.try_into().unwrap();

// FromIterator
let arr3: Array<i64> = (0..5i64).collect();
```
