# Add Rust binding for Array<T>
## TL;DR
- Adds `Array<T>` generic container type to the Rust `tvm-ffi` crate, mirroring the C++ `Array<T>`
- Implements `ArrayObj` with `#[derive(Object)]` and `ObjectCoreWithExtraItems` for inplace element storage
- Provides `Array<T>::new()`, indexing, iteration, `get()`, `push()` (CoW), and `From<Vec<T>>` conversions
- Fixes `Any::into_raw_ffi_any` to use `ManuallyDrop` to prevent double-free

## Key Exports
```python
# Rust: tvm-ffi/src/collections/array.rs
class ArrayObj:
    """C-compatible layout matching C++ ArrayObj."""
    object: Object
    data: *mut c_void     # pointer to element buffer
    size: i64
    capacity: i64
    data_deleter: Optional[extern "C" fn(*mut c_void)]
    # Invariant: elements stored inline after ArrayObj via ObjectCoreWithExtraItems

class Array[T: AnyCompatible + Clone]:
    """Generic typed array wrapping ObjectArc<ArrayObj>."""
    def new(items: Vec[T]) -> Array[T]: ...
    def len(self) -> usize: ...
    def get(self, index: usize) -> Option[T]: ...
    def push(self, item: T) -> Array[T]: ...  # CoW: creates new array
    # Interacts with: ObjectArc<ArrayObj>, AnyCompatible trait, TVMFFIAny inline storage
    # Extension: implement new container types using ObjectCoreWithExtraItems pattern

# Fix: Any::into_raw_ffi_any now uses ManuallyDrop to prevent double-free
```

## Usage Examples
```rust
use tvm_ffi::collections::Array;
let arr = Array::new(vec![1i64, 2, 3]);
assert_eq!(arr.len(), 3);
assert_eq!(arr.get(0), Some(1i64));
let arr2 = arr.push(4);  // CoW semantics
assert_eq!(arr2.len(), 4);
```
