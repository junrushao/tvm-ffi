# Add Rust binding for Array<T> container with full FFI integration
## TL;DR
- Implements `Array<T>` in Rust (`rust/tvm-ffi/src/collections/array.rs`) with FFI-compatible memory layout matching C++ `ArrayObj`.
- Supports `new`, `get`, `len`, `iter`, `Index`, `FromIterator`, and `AnyCompatible` trait for `Any`/`AnyView` roundtrip.
- Fixes `Any::into_raw_ffi_any` double-free by wrapping with `ManuallyDrop`.
- Adds comprehensive test suite in `rust/tvm-ffi/tests/test_array.rs`.

## Key Exports

```python
class ArrayObj:
    """FFI-compatible array object layout (Rust repr(C))."""
    object: Object
    data: Pointer[c_void]          # Pointer to element buffer (TVMFFIAny[])
    size: int64
    capacity: int64
    data_deleter: Optional[FnPtr]  # Optional custom deleter
    # Invariant: data points to inline extra_items allocation
    # Interacts with: ObjectArc ref-counting, ObjectCoreWithExtraItems

class Array(Generic[T]):
    """Typed array container for Rust FFI."""
    # Invariant: T must implement AnyCompatible + Clone

    def new(items: List[T]) -> "Array[T]": ...
    def len(self) -> int: ...
    def is_empty(self) -> bool: ...
    def get(self, index: int) -> Result[T, Error]: ...
        # Invariant: raises IndexError if out of bounds
    def iter(self) -> ArrayIterator[T]: ...
    # Interacts with: AnyCompatible trait for type checking and conversion
    # Interacts with: ObjectArc for ref-counted ownership
    # Extension: implement FromIterator<T> and Index<usize>

# AnyCompatible impl for Array<T>:
# - check_any_strict: verifies type_index == kTVMFFIArray, then checks each element
# - copy_to_any_view / move_to_any: standard ObjectRef pattern
# - try_cast_from_any_view: fast path (strict check) + slow path (element-by-element conversion)
```

## Usage Examples

```rust
use tvm_ffi::Array;

let array = Array::new(vec![Shape::from(vec![1, 2]), Shape::from(vec![3])]);
assert_eq!(array.len(), 2);
assert_eq!(array.get(0).unwrap().as_slice(), &[1, 2, 3]);

// Any roundtrip
let any = Any::from(array);
let back: Array<Shape> = Array::try_from(any).unwrap();
```
