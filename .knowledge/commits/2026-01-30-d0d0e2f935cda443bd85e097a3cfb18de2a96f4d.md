# Add Rust binding for Array<T> container with full AnyCompatible integration
## TL;DR
- Introduces `Array<T>` in the Rust `tvm-ffi` crate, mirroring the C++ `Array<T>` container with `#[repr(C)]` layout compatibility (`ArrayObj` with data/size/capacity/data_deleter fields).
- Implements `AnyCompatible` for `Array<T>` with recursive element-type checking (`check_any_strict` iterates elements), enabling type-safe roundtrips through `Any`/`AnyView`.
- Fixes `Any::into_raw_ffi_any` to use `ManuallyDrop` to prevent double-free when extracting the raw `TVMFFIAny`.

## Key Exports

**Types/Classes**:

```rust
#[repr(C)]
#[derive(Object)]
#[type_key = "ffi.Array"]
#[type_index(TypeIndex::kTVMFFIArray)]
pub struct ArrayObj {
    pub object: Object,
    pub data: *mut core::ffi::c_void,
    pub size: i64,
    pub capacity: i64,
    pub data_deleter: Option<unsafe extern "C" fn(*mut core::ffi::c_void)>,
}

#[repr(C)]
pub struct Array<T: AnyCompatible + Clone> {
    data: ObjectArc<ArrayObj>,
    _marker: PhantomData<T>,
}
```

**Key methods on `Array<T>`**:
- `pub fn new(items: Vec<T>) -> Self` -- create from vector
- `pub fn len(&self) -> usize`
- `pub fn is_empty(&self) -> bool`
- `pub fn get(&self, index: usize) -> Result<T, Error>` -- bounds-checked retrieval with inc_ref
- `pub fn iter(&self) -> ArrayIterator<T>` -- typed iterator
- `Index<usize>` returning `&AnyView<'static>` -- raw element access

**Traits implemented**:
- `unsafe impl ObjectCoreWithExtraItems for ArrayObj` (ExtraItem = TVMFFIAny)
- `unsafe impl ObjectRefCore for Array<T>` (ContainerType = ArrayObj)
- `unsafe impl AnyCompatible for Array<T>` -- recursive type checking and Any/AnyView conversions
- `FromIterator<T> for Array<T>`
- `IntoIterator for &Array<T>`
- `TryFrom<Any> for Array<T>` and `TryFrom<AnyView> for Array<T>`
- `Default`, `Clone`, `Debug`

**Bugfix**:
```rust
// Any::into_raw_ffi_any now wraps in ManuallyDrop to prevent double-free
pub unsafe fn into_raw_ffi_any(this: Self) -> TVMFFIAny {
    let this = std::mem::ManuallyDrop::new(this);  // NEW
    this.data
}
```

## Impact
- API: First Rust container binding. `Array` is now re-exported from `tvm_ffi::Array`. The non-goal statement in 0019-rust-bindings.md ("Rust implementations of containers... not covered") is now partially fulfilled.
- Behavioral: `Any::into_raw_ffi_any` previously dropped the `Any` after extracting `data`, potentially causing use-after-free for object-typed values. Now uses `ManuallyDrop` to transfer ownership correctly.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Creating an `Array<Tensor>` and round-tripping through `Any`:
```rust
use tvm_ffi::*;

// Create array from vector
let array = Array::new(vec![tensor1, tensor2]);
assert_eq!(array.len(), 2);

// Typed iteration
for t in &array {
    println!("ndim: {}", t.ndim());
}

// Roundtrip through Any
let any = Any::from(array);
let back: Array<Tensor> = Array::try_from(any).unwrap();

// Recursive type checking prevents miscast
let shape_arr = Array::new(vec![Shape::from(vec![1, 2])]);
let any_val = Any::from(shape_arr);
assert!(Array::<Tensor>::try_from(any_val.clone()).is_err()); // type mismatch
assert!(Array::<Shape>::try_from(any_val).is_ok());           // correct type
```
