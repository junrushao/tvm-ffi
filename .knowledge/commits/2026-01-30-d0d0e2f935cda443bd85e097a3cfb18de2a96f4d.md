# Add Rust binding for Array<T> container with full FFI type system integration
## TL;DR
- Adds `Array<T>` and `ArrayObj` to the Rust `tvm-ffi` crate, implementing the same C-ABI-compatible memory layout as the C++ `ArrayObj` (data pointer, size, capacity, data_deleter, trailing `TVMFFIAny` elements).
- Implements `AnyCompatible` for `Array<T>` with recursive element type checking (strict fast path + element-by-element slow path), plus `FromIterator`, `Index`, and iterator support.
- Fixes `Any::into_raw_ffi_any` to wrap `self` in `ManuallyDrop` before extracting the raw `TVMFFIAny`, preventing a double-free when the `Any` held an object-typed value.

## Key Exports

```python
class ArrayObj:
    """#[repr(C)] FFI object mirroring C++ ArrayObj layout. Trailing TVMFFIAny elements."""
    object: Object
    data: *mut c_void          # Pointer to start of element buffer (AddressOf(0))
    size: i64
    capacity: i64
    data_deleter: Optional[extern "C" fn(*mut c_void)]
    # Invariant: data == address of trailing TVMFFIAny items after allocation
    # Invariant: ExtraItem = TVMFFIAny, extra_items_count = size
    # Interacts with: ObjectCoreWithExtraItems (trailing item allocation)
    # Interacts with: ObjectArc::new_with_extra_items (allocation with trailing data)

class Array(Generic[T]):  # T: AnyCompatible + Clone
    """Rust generic array ref wrapping ArrayObj. Mirrors C++ Array<T>."""
    data: ObjectArc[ArrayObj]
    _marker: PhantomData[T]
    # Interacts with: ObjectRefCore (data/into_data/from_data pattern)
    # Interacts with: AnyCompatible (Any/AnyView round-trip via type_index kTVMFFIArray)
    # Invariant: elements stored as raw TVMFFIAny in trailing items; typed access via T::try_cast_from_any_view
    # Extension: implement new container types following this ObjectCoreWithExtraItems + ObjectRefCore pattern

    def new(items: Vec[T]) -> Array[T]: ...
    def len(self) -> usize: ...
    def is_empty(self) -> bool: ...
    def get(self, index: usize) -> Result[T, Error]: ...
        # Invariant: bounds-checked, returns IndexError on OOB
        # Interacts with: T::try_cast_from_any_view (element conversion)
    def iter(self) -> ArrayIterator[T]: ...
    def __index__(self, index: usize) -> AnyView: ...
        # Invariant: panics on OOB (not Result-based)

# AnyCompatible impl for Array<T>:
#   check_any_strict: type_index == kTVMFFIArray AND (T == Any OR all elements pass T::check_any_strict)
#   try_cast_from_any_view: fast path (strict check + copy ref) OR slow path (element-by-element conversion)
#   Interacts with: Any, AnyView, TryFrom<Any>, TryFrom<AnyView>

# Bugfix in Any::into_raw_ffi_any:
#   Old: let raw = this.data;  // this is dropped, decrementing refcount -> double-free
#   New: let this = ManuallyDrop::new(this); let raw = this.data;  // ownership transferred, no drop
#   Interacts with: ArrayObj construction (into_raw_ffi_any used to write elements into trailing slots)
```

## Impact
- API: Adds `Array<T>` to Rust public API (`pub use crate::collections::array::Array`). No breaking changes to existing APIs.
- Behavioral: Fixes `Any::into_raw_ffi_any` double-free bug that affected any caller extracting raw `TVMFFIAny` from an object-typed `Any` value.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
Creating and iterating over a Rust `Array<Tensor>`, then round-tripping through `Any` (from test_array.rs):
```rust
use tvm_ffi::*;

// Create typed array
let t1 = create_tensor(10.0, &[1, 2]);
let t2 = create_tensor(20.0, &[3, 4, 5]);
let array = Array::new(vec![t1, t2]);

// Typed access
assert_eq!(array.len(), 2);
let first: Tensor = array.get(0).unwrap();

// Iteration
let vals: Vec<f32> = array.iter().map(|t| get_val(&t)).collect();

// Any round-trip
let any = Any::from(array);
let back: Array<Tensor> = Array::try_from(any).expect("round-trip");

// Recursive type checking prevents invalid casts
let shape_array = Array::new(vec![Shape::from(vec![1, 2])]);
let any_val = Any::from(shape_array);
assert!(Array::<Tensor>::try_from(any_val.clone()).is_err());  // wrong element type
assert!(Array::<Shape>::try_from(any_val).is_ok());            // correct type
```
