# Add Rust binding for Array<T>
## TL;DR
- Implements a generic `Array<T>` Rust type backed by `ArrayObj` (`#[repr(C)]`, type key `ffi.Array`) that is ABI-compatible with the C++ `Array<T>` container.
- Full `AnyCompatible` implementation with recursive element-level type checking: `check_any_strict` validates each element matches `T`, and `try_cast_from_any_view` supports a slow-path element-by-element conversion.
- Supports `FromIterator`, `IntoIterator`, `Index<usize>`, `Clone`, `Default`, and `Debug` traits.
- Also fixes `Any::into_raw_ffi_any` to use `ManuallyDrop` to prevent double-free when converting to raw FFI representation.

## Impact
- API: New public type `tvm_ffi::Array<T>` with `new`, `get`, `len`, `is_empty`, `iter` methods.
- Rust object system: `ArrayObj` implements `ObjectCoreWithExtraItems` (extra items are `TVMFFIAny` elements stored inline after the header).
- Bug fix: `Any::into_raw_ffi_any` now wraps in `ManuallyDrop` before extracting the inner data, fixing a potential double-free.
