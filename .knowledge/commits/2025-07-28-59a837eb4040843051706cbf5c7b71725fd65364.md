# Migrate StructuralEqual/Hash dispatch from enum-gated to reflection TypeAttrColumn lookup
## TL;DR
- Removes `kTVMFFISEqHashKindCustomTreeNode` (value 6) from the `TVMFFISEqHashKind` C ABI enum; custom equal/hash is now dispatched by checking whether a `__s_equal__`/`__s_hash__` TypeAttrColumn entry exists for the type, rather than by enum tag.
- Adds NaN-safe handling in both structural equal and hash: all NaN float representations are treated as equal and hash to the same value (`quiet_NaN` canonical form).
- Changes `__s_hash__` callback signature from `(AnyView, bool) -> uint64_t` to `(AnyView, uint64_t init_hash, bool) -> uint64_t`, moving hash combining into the callback itself.
- Tightens error handling: missing metadata or unsupported `_type_s_eq_hash_kind` now throws `TypeError` instead of silently falling back to pointer comparison/hash.

## Impact
- API: **Breaking** -- `kTVMFFISEqHashKindCustomTreeNode` removed from `c_api.h`. Any type using `_type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode` must change to `kTVMFFISEqHashKindTreeNode` and ensure `__s_equal__`/`__s_hash__` TypeAttrColumn entries are registered. `__s_hash__` callback signature changed (added `init_hash` parameter).
- Behavioral: Types without metadata now throw `TypeError` instead of falling back to pointer comparison (equal) or pointer hash (hash). NaN floats now compare equal and hash identically regardless of bit representation.
- Flags/config: none
- Data formats/schemas: none

- **Mutated**: Structural equal/hash dispatch protocol -- custom handlers are detected via `TypeAttrColumn` null-check instead of enum value, unifying the registration path with normal reflection.
- **Mutated**: `__s_hash__` callback signature -- `(AnyView, bool) -> uint64_t` becomes `(AnyView, uint64_t, bool) -> uint64_t` with hash combining moved inside the callback.

## Usage Examples
Before/after for custom structural hash (from `tests/cpp/testing_object.h`):
```cpp
// BEFORE: hash combining done by caller, callback returns raw hash
uint64_t SHash(uint64_t type_key_hash,
               TypedFunction<uint64_t(AnyView, bool)> hash) const {
    uint64_t hash_value = type_key_hash;
    hash_value = StableHashCombine(hash_value, hash(params, true));
    hash_value = StableHashCombine(hash_value, hash(body, false));
    return hash_value;
}
static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode;

// AFTER: callback takes init_hash and does combining internally
uint64_t SHash(uint64_t init_hash,
               TypedFunction<uint64_t(AnyView, uint64_t, bool)> hash) const {
    uint64_t hash_value = init_hash;
    hash_value = hash(params, hash_value, true);
    hash_value = hash(body, hash_value, false);
    return hash_value;
}
static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
```
