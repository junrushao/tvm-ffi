# Migrate StructuralEqual/Hash to new reflection-based custom dispatch and harden error handling
## TL;DR
- Removes the `kTVMFFISEqHashKindCustomTreeNode` enum value (was `= 6`) from the C ABI enum `TVMFFISEqHashKind`, replacing the dedicated dispatch kind with a runtime check on the `__s_equal__` / `__s_hash__` TypeAttrColumn -- custom structural equal/hash functions are now triggered by their presence in the type attribute registry rather than by a special enum variant.
- Changes error behavior when type metadata or `_type_s_eq_hash_kind` is missing: both `StructEqualHandler::CompareObject` and `StructuralHashHandler::HashObject` now throw `TypeError` instead of silently falling back to pointer equality/hash.
- Adds NaN normalization: `CompareAny` treats all NaN float values as structurally equal; `HashAny` canonicalizes NaN to `quiet_NaN()` before hashing so all NaN representations produce the same hash.
- Updates the custom `__s_hash__` callback signature from `(AnyView, bool) -> uint64_t` to `(AnyView, uint64_t init_hash, bool) -> uint64_t`, threading the accumulator through the callback so custom hash functions compose via `StableHashCombine` internally.

## Key Exports

**Removed C ABI enum value:**
```c
// REMOVED from TVMFFISEqHashKind in include/tvm/ffi/c_api.h:
kTVMFFISEqHashKindCustomTreeNode = 6
```

**Changed internal signatures (not public API, but affects custom `__s_hash__` implementations):**

Old `__s_hash__` callback type:
```cpp
TypedFunction<uint64_t(AnyView val, bool def_region)>
```

New `__s_hash__` callback type:
```cpp
TypedFunction<uint64_t(AnyView val, uint64_t init_hash, bool def_region)>
```

The callback now returns `StableHashCombine(init_hash, HashAny(val))` instead of the raw hash, so the caller no longer needs to combine manually.

## Impact
- API: `kTVMFFISEqHashKindCustomTreeNode` is removed. Types that previously used this enum value must switch to `kTVMFFISEqHashKindTreeNode` and register `__s_equal__` / `__s_hash__` via `TypeAttrDef`. The test object `TCustomFuncObj` demonstrates this migration.
- ABI: Breaking -- the enum value `6` is removed from `TVMFFISEqHashKind`. Any binary compiled against the old header that references `kTVMFFISEqHashKindCustomTreeNode` will fail to compile.
- Behavioral:
  - Missing metadata now throws `TypeError` rather than falling back to pointer comparison. This catches configuration errors where a type declares `_type_s_eq_hash_kind` but fails to register reflection metadata.
  - NaN float values are now structurally equal to each other (previously compared as unequal via bitwise `v_int64` comparison, since NaN != NaN at the bitwise level for different NaN encodings). All NaN values hash to the same bucket.
  - Custom `__s_hash__` implementations receive and must return a running hash accumulator (`init_hash`) instead of computing an isolated hash. The `SHash` method on `TCustomFuncObj` shows the new pattern: `hash_value = hash(field, hash_value, def_region)`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeAttrColumn** (`reflection::TypeAttrColumn`): Runtime per-type-index attribute lookup. The commit moves `custom_s_equal` / `custom_s_hash` TypeAttrColumn construction to `static` local variables and uses `column[type_index] == nullptr` as the dispatch predicate instead of checking the enum kind.
- **ForEachFieldInfo / ForEachFieldInfoWithEarlyStop**: Field visitor utilities used to iterate reflection fields for the default (non-custom) structural comparison/hashing path. Documented in `.knowledge/designs/reflection.md`.
- **StableHashCombine**: Deterministic hash combiner from `tvm::ffi::details`. Used in the new `__s_hash__` callback to fold field hashes into the accumulator.
- **TVMFFISEqHashKind enum**: The remaining valid values (0-5) continue to control structural equal/hash behavior; this commit removes value 6.

Design elements this commit produces:
- **Presence-based custom dispatch for StructuralEqual/Hash**: Instead of requiring a dedicated `kTVMFFISEqHashKindCustomTreeNode` enum variant, custom structural equal/hash is now triggered purely by the presence of `__s_equal__` / `__s_hash__` attributes in the TypeAttrColumn for a given type. This means any type with `_type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode` (or other non-custom kinds) can additionally register custom functions that will take priority over the default reflection-based traversal.
- **NaN canonicalization in StructuralEqual/Hash**: Float NaN values are treated as a single equivalence class for both equality and hashing. Equality uses `std::isnan` on both sides; hashing canonicalizes to `std::numeric_limits<double>::quiet_NaN()` before computing the hash.
- **Accumulator-threaded custom hash callback**: The `__s_hash__` callback signature now carries `init_hash` through the call chain, making composition cleaner -- custom hash functions no longer need to manually call `StableHashCombine` on the result.

## Usage Examples

### Defining a custom structural equal/hash type (new pattern)

```cpp
class TCustomFuncObj : public Object {
 public:
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;

  bool SEqual(const TCustomFuncObj* other,
              TypedFunction<bool(AnyView, AnyView, bool, AnyView)> cmp) const {
    if (!cmp(params, other->params, true, "params")) return false;
    if (!cmp(body, other->body, false, "body")) return false;
    return true;
  }

  // New signature: receives init_hash, returns combined hash
  uint64_t SHash(uint64_t init_hash,
                 TypedFunction<uint64_t(AnyView, uint64_t, bool)> hash) const {
    uint64_t hash_value = init_hash;
    hash_value = hash(params, hash_value, true);   // callback combines internally
    hash_value = hash(body, hash_value, false);
    return hash_value;
  }

  static void RegisterReflection() {
    namespace refl = tvm::ffi::reflection;
    refl::ObjectDef<TCustomFuncObj>()
        .def_ro("params", &TCustomFuncObj::params)
        .def_ro("body", &TCustomFuncObj::body)
        .def_ro("comment", &TCustomFuncObj::comment);
    // Register custom functions via TypeAttrDef (no special enum needed)
    refl::TypeAttrDef<TCustomFuncObj>()
        .def("__s_equal__", &TCustomFuncObj::SEqual)
        .def("__s_hash__", &TCustomFuncObj::SHash);
  }

  static constexpr const char* _type_key = "test.CustomFunc";
  // Use kTVMFFISEqHashKindTreeNode, NOT the removed kTVMFFISEqHashKindCustomTreeNode
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TCustomFuncObj, Object);
};
```
