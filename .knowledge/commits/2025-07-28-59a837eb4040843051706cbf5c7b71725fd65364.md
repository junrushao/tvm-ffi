# Migrate StructuralEqual/Hash to reflection-based custom dispatch, remove kTVMFFISEqHashKindCustomTreeNode

## TL;DR
- Removes the `kTVMFFISEqHashKindCustomTreeNode` enum value (was 6) from the C ABI enum `TVMFFISEqHashKind`, replacing its dispatch role with a runtime `TypeAttrColumn` lookup for `__s_equal__`/`__s_hash__` attributes.
- Adds NaN-aware comparison and hashing for float values: all NaN representations are treated as structurally equal and hash to the same value (`quiet_NaN()`).
- Tightens error handling: missing type metadata or unsupported `_type_s_eq_hash_kind` now throws `TypeError` instead of silently falling back to pointer comparison/hash.

## Key Exports

**Constants/Enums (removed)**:
- `kTVMFFISEqHashKindCustomTreeNode = 6` — removed from `TVMFFISEqHashKind` in `c_api.h`. Types that previously used this value should now use `kTVMFFISEqHashKindTreeNode` (value 1) and register `__s_equal__`/`__s_hash__` via `TypeAttrColumn`.

**Callbacks (signature changed)**:
- `__s_hash__` callback: `(AnyView val, bool def_region) -> uint64_t` changed to `(AnyView val, uint64_t init_hash, bool def_region) -> uint64_t`. The callback now incorporates `StableHashCombine` internally rather than requiring callers to combine.

## Impact
- API: **Breaking ABI change** — `kTVMFFISEqHashKindCustomTreeNode` removed from the public C ABI enum. Any downstream code referencing this enum value will fail to compile. Types using it must switch to `kTVMFFISEqHashKindTreeNode` + `TypeAttrColumn` registration.
- Behavioral: (1) NaN float values are now structurally equal to each other and hash identically. Previously, bitwise comparison of NaN would produce false/inconsistent hashes. (2) Missing metadata now throws `TypeError` instead of silently using pointer equality/hash — this surfaces misconfigured types.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- **`TVMFFISEqHashKind` enum** (`c_api.h`) — the SEqHash dispatch enum that controls structural comparison strategy per type. Ref: `.knowledge/designs/0001-c-abi-layer.md` (not explicitly documented there yet).
- **`TypeAttrColumn`** (`reflection/accessor.h`) — runtime column lookup for per-type attributes like `__s_equal__` and `__s_hash__`. Ref: `.knowledge/designs/0009-reflection.md`.
- **`ForEachFieldInfo` / `ForEachFieldInfoWithEarlyStop`** — field traversal utilities for reflection-based comparison. Ref: `.knowledge/designs/0009-reflection.md`.
- **`details::StableHashCombine`** — deterministic hash combiner.
- **`TypeIndex::kTVMFFIFloat`** — type index for float POD values. Ref: `.knowledge/ADRs/0004-type-index-layout.md`.

Design elements this commit produces:
- **Reflection-based custom SEqHash dispatch pattern**: Custom `__s_equal__`/`__s_hash__` functions are now discovered via `TypeAttrColumn` lookup (null check) rather than through a dedicated enum kind. This unifies registration with the normal reflection attribute system.
- **NaN canonicalization invariant**: Structural equal/hash now canonicalizes NaN representations, ensuring `NaN == NaN` structurally and all NaN bit patterns hash to `quiet_NaN()`.

## Usage Examples

**Migrating a type from `kTVMFFISEqHashKindCustomTreeNode` to the new pattern**:
```cpp
// BEFORE (removed):
class MyObj : public Object {
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode;
  uint64_t SHash(uint64_t type_key_hash, TypedFunction<uint64_t(AnyView, bool)> hash) const {
    uint64_t h = type_key_hash;
    h = StableHashCombine(h, hash(field, true));
    return h;
  }
};

// AFTER:
class MyObj : public Object {
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
  // SHash callback now takes (AnyView, uint64_t init_hash, bool def_region) -> uint64_t
  // and folds StableHashCombine internally
  uint64_t SHash(uint64_t init_hash, TypedFunction<uint64_t(AnyView, uint64_t, bool)> hash) const {
    uint64_t h = init_hash;
    h = hash(field, h, true);  // hash() now returns combined value directly
    return h;
  }
};
// Register __s_hash__ via TypeAttrColumn (reflection system handles dispatch)
```
