# Allocate metadata strings via TVMFFIStringFromByteArray to avoid delete-after-module-unload
## TL;DR
- Changes `TVM_FFI_DLL_EXPORT_TYPED_FUNC` and `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macros to allocate metadata strings via `TVMFFIStringFromByteArray` (C API in libtvm_ffi) instead of constructing `tvm::ffi::String` objects locally in the module's code.
- This ensures the returned String object's memory is allocated in the main libtvm_ffi shared library, not in the loaded module's address space, preventing use-after-free when the module is unloaded before the metadata string is destroyed.

## Key Exports
None (no new API surface; internal macro implementation change only).

## Impact
- API: None. The exported C symbol signatures (`__tvm_ffi__metadata_*`, `__tvm_ffi__doc_*`) are unchanged.
- Behavioral: Metadata strings now survive module unloading because their memory lives in libtvm_ffi's heap. Previously, the `String` object's deleter code lived in the module's `.so` and would become invalid after `dlclose`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Function metadata macros** ([0004-function-system.md](../designs/0004-function-system.md)): `TVM_FFI_DLL_EXPORT_TYPED_FUNC` and `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macros that export function type schema and documentation strings.
- **C ABI string creation** ([0001-c-abi-layer.md](../designs/0001-c-abi-layer.md)): `TVMFFIStringFromByteArray` C API function that allocates a String in the main library's heap.
- **Module system lifetime** ([0013-module-system.md](../designs/0013-module-system.md)): The module unloading problem where objects with deleters in the loaded library become dangling after `dlclose`.

Design elements this commit produces:
- None (bug fix establishing a new invariant for metadata allocation).

## Usage Examples
**Before** (buggy): metadata string allocated in module's code space:
```cpp
::tvm::ffi::String str(os.str());
::tvm::ffi::TypeTraits<::tvm::ffi::String>::MoveToAny(std::move(str), result);
```

**After** (fixed): metadata string allocated via C API in main library:
```cpp
std::string data = os.str();
TVMFFIByteArray data_array{data.data(), data.size()};
return TVMFFIStringFromByteArray(&data_array, result);
```
