# Expose core ffi container types and utilities into tvm namespace via using-declarations
## TL;DR
- Adds `using ffi::X` declarations in the `tvm` namespace for 10 commonly-used symbols: `Array`, `Map`, `String`, `Bytes`, `Tuple`, `Variant`, `Optional`, `Downcast`, `GetRef`, `make_object`.
- Enables callers to write `tvm::Array` instead of `tvm::ffi::Array`, reducing verbosity for unambiguous types.
- Minor doc fix: `NullOpt` -> `std::nullopt` in `Map::Get` return comment.

### Namespace alias mapping

| `tvm::ffi::` symbol | Header | Now also available as `tvm::` |
|---|---|---|
| `Downcast` | `ffi/cast.h` | `tvm::Downcast` |
| `GetRef` | `ffi/cast.h` | `tvm::GetRef` |
| `Array` | `ffi/container/array.h` | `tvm::Array` |
| `Map` | `ffi/container/map.h` | `tvm::Map` |
| `Tuple` | `ffi/container/tuple.h` | `tvm::Tuple` |
| `Variant` | `ffi/container/variant.h` | `tvm::Variant` |
| `make_object` | `ffi/memory.h` | `tvm::make_object` |
| `Optional` | `ffi/optional.h` | `tvm::Optional` |
| `Bytes` | `ffi/string.h` | `tvm::Bytes` |
| `String` | `ffi/string.h` | `tvm::String` |

## Impact
- API: Additive only. `tvm::Array` etc. now resolve; `tvm::ffi::Array` continues to work.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **0006-containers** (`Array`, `Map`, `String`, `Bytes`, `Tuple`, `Variant`, `Optional`) -- re-exports these into the parent namespace.
- **0002-object-system** (`Downcast`, `GetRef`, `make_object`) -- re-exports cast/allocation utilities into the parent namespace.

Design elements this commit produces:
- None. No new types, functions, or protocols are introduced. The using-declarations create namespace aliases, not new design elements.

## Usage Examples

After this commit, downstream C++ code can use shorter qualified names:

```cpp
// Before: fully qualified
tvm::ffi::Array<tvm::ffi::String> names = ...;
auto node = tvm::ffi::make_object<MyNodeObj>();
auto ref = tvm::ffi::Downcast<MyNode>(obj);

// After: shorter aliases available
tvm::Array<tvm::String> names = ...;
auto node = tvm::make_object<MyNodeObj>();
auto ref = tvm::Downcast<MyNode>(obj);
```
