# Expose commonly-used tvm::ffi types into tvm namespace via using declarations

## TL;DR
- Adds `using ffi::X` declarations at the end of 9 public headers to lift `Array`, `Map`, `Tuple`, `Variant`, `Optional`, `String`, `Bytes`, `Downcast`, `GetRef`, and `make_object` from `tvm::ffi` into the `tvm` namespace.
- Fixes a doc comment in `Map::Get` (`NullOpt` -> `std::nullopt`).
- Part of a broader header redirection cleanup (PR #17929) that points legacy `runtime/` paths to new `ffi/` headers.

## Key Exports

**Namespace aliases** (new `using` declarations in `namespace tvm`):

| Header | Symbols exposed to `tvm::` |
|--------|---------------------------|
| `ffi/cast.h` | `Downcast`, `GetRef` |
| `ffi/container/array.h` | `Array` |
| `ffi/container/map.h` | `Map` |
| `ffi/container/tuple.h` | `Tuple` |
| `ffi/container/variant.h` | `Variant` |
| `ffi/memory.h` | `make_object` |
| `ffi/optional.h` | `Optional` |
| `ffi/string.h` | `String`, `Bytes` |

After this commit, callers can write `tvm::Array<int>` instead of `tvm::ffi::Array<int>`. The `tvm::ffi::` qualified form remains valid.

## Impact
- API: Additive only -- existing `tvm::ffi::X` qualified names remain valid. Code using `tvm::X` (e.g. from legacy `tvm::runtime::` aliases) now resolves through `using ffi::X` instead of through redirect headers.
- Behavioral: None. Pure namespace aliasing.
- Flags/config: None.
- Data formats/schemas: None.

Design elements this commit produces:
- **Namespace aliasing convention**: A pattern where `tvm::ffi` types that are "commonly used and have no ambiguity" are lifted into `tvm::` via `using` declarations placed between the closing `}  // namespace ffi` and `}  // namespace tvm` braces. This establishes a convention for which symbols are considered first-class `tvm::` API.

## Usage Examples

After this commit, user code can use shorter qualified names:

```cpp
// Before: required full qualification
tvm::ffi::Array<int> arr = {1, 2, 3};
auto ptr = tvm::ffi::make_object<MyObj>(42);
tvm::ffi::String s = "hello";

// After: tvm:: namespace suffices
tvm::Array<int> arr = {1, 2, 3};
auto ptr = tvm::make_object<MyObj>(42);
tvm::String s = "hello";
```
