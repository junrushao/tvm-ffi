# Isolate extra C++ API into `extra/` directory, rename AccessKind enums, move StructuralEqual/Hash to `ffi` namespace

## TL;DR
- Moves `StructuralEqual` and `StructuralHash` from `tvm::ffi::reflection` namespace to `tvm::ffi` namespace, and relocates their headers/sources from `reflection/` to `extra/`.
- Renames `AccessKind` enum values: `kArrayIndex` -> `kArrayItem`, `kMapKey` -> `kMapItem` (and their `Missing` variants).
- Extracts `TVM_FFI_EXTRA_CXX_API` macro from `c_api.h` into a new `extra/base.h` header, formalizing the "extra API" as a distinct directory.
- Promotes `access_path.cc` from optional extra build to always-compiled core sources.

## Key Exports

```python
# --- extra/base.h (new) ---
# TVM_FFI_EXTRA_CXX_API macro: marks non-core C++ APIs with DLL visibility.
# Moved from c_api.h to formalize extra API isolation.
# Previously: defined in c_api.h alongside core ABI definitions
# Now: defined in extra/base.h, the base header for all extra API headers
# Interacts with: TVM_FFI_DLL (resolves to dllexport/visibility)

# --- AccessKind enum (renamed values, still in reflection namespace) ---
class AccessKind(IntEnum):
    kObjectField = 0
    kArrayItem = 1       # was: kArrayIndex
    kMapItem = 2         # was: kMapKey
    kArrayItemMissing = 3  # was: kArrayIndexMissing
    kMapItemMissing = 4    # was: kMapKeyMissing
    # Interacts with: AccessStep factory methods, StructuralEqual mismatch paths
    # Invariant: values 0-4 are stable; used in switch statements and serialized mismatch reports

# --- AccessStep factory methods (renamed, still in reflection namespace) ---
class AccessStep(ObjectRef):
    @staticmethod
    def ArrayItem(index: int64) -> AccessStep: ...    # was: ArrayIndex
    @staticmethod
    def ArrayItemMissing(index: int64) -> AccessStep: ...  # was: ArrayIndexMissing
    @staticmethod
    def MapItem(key: Any) -> AccessStep: ...           # was: MapKey
    @staticmethod
    def MapItemMissing(key: Any) -> AccessStep: ...    # was: MapKeyMissing
    # Interacts with: StructuralEqual.GetFirstMismatch (builds mismatch paths)

# --- StructuralEqual (moved from reflection to ffi namespace) ---
class StructuralEqual:
    """Deep structural equality for Any values using reflection field traversal."""
    @staticmethod
    def Equal(lhs: Any, rhs: Any, map_free_vars: bool = False,
              skip_ndarray_content: bool = False) -> bool: ...
    @staticmethod
    def GetFirstMismatch(lhs: Any, rhs: Any, map_free_vars: bool = False,
                         skip_ndarray_content: bool = False) -> Optional[reflection.AccessPathPair]: ...
    def __call__(self, lhs: Any, rhs: Any) -> bool: ...
    # Interacts with: reflection::ForEachFieldInfoWithEarlyStop, reflection::FieldGetter
    # Interacts with: reflection::AccessStep/AccessPath for mismatch reporting
    # Invariant: traverses all registered fields except those with kTVMFFIFieldFlagBitMaskSEqHashIgnore
    # Extension: custom_s_equal per-type callbacks for overriding default field comparison

# --- StructuralHash (moved from reflection to ffi namespace) ---
class StructuralHash:
    """Structural hash for Any values using reflection field traversal."""
    @staticmethod
    def Hash(value: Any, map_free_vars: bool = False,
             skip_ndarray_content: bool = False) -> uint64: ...
    def __call__(self, value: Any) -> uint64: ...
    # Interacts with: reflection::ForEachFieldInfo, reflection::FieldGetter
    # Invariant: Hash(a) == Hash(b) whenever StructuralEqual(a, b) is true

# Global function registry renames:
# "ffi.GetFirstStructuralMismatch" -> StructuralEqual.GetFirstMismatch  (was: "ffi.reflection.GetFirstStructuralMismatch")
# "ffi.StructuralHash" -> StructuralHash.Hash  (was: "ffi.reflection.StructuralHash")
```

## Impact
- API: **Breaking** -- `StructuralEqual` and `StructuralHash` are no longer in `tvm::ffi::reflection` namespace; callers must use `tvm::ffi::StructuralEqual` / `tvm::ffi::StructuralHash`. All `AccessStep::ArrayIndex/MapKey` factory methods renamed to `ArrayItem/MapItem`. Include paths changed from `tvm/ffi/reflection/structural_*.h` to `tvm/ffi/extra/structural_*.h`. Global function names changed: `ffi.reflection.GetFirstStructuralMismatch` -> `ffi.GetFirstStructuralMismatch`, `ffi.reflection.StructuralHash` -> `ffi.StructuralHash`.
- Behavioral: none -- same logic, different names/locations
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` CMake flag now controls the new `src/ffi/extra/` sources instead of `src/ffi/reflection/structural_*.cc`. `access_path.cc` is now always compiled (moved from extra to core sources).
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Reflection field traversal** (`0007-ffi-reflection`): `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`, `FieldGetter` -- all still in `reflection` namespace, now qualified as `reflection::` from the `ffi` namespace context.
- **Object system** (`0003-ffi-object-system`): `ObjectRef`, type hierarchy, intrusive refcount.
- **Global function registry** (`0004-ffi-function-system`): `TVM_FFI_STATIC_INIT_BLOCK` + `GlobalDef().def(...)` for registering structural equal/hash as global packed functions.

Design elements this commit produces/mutates:
- **Extra API directory convention** (new): formalizes `include/tvm/ffi/extra/` and `src/ffi/extra/` as the home for non-core C++ APIs. `extra/base.h` is the base header that provides `TVM_FFI_EXTRA_CXX_API` visibility macro.
- **AccessKind enum rename** (mutates `0007-ffi-reflection`): `kArrayIndex` -> `kArrayItem`, `kMapKey` -> `kMapItem` and their `Missing` variants. Naming now emphasizes "item" (container element) over "index"/"key" (access mechanism).
- **StructuralEqual/Hash namespace promotion** (mutates): moved from `tvm::ffi::reflection` to `tvm::ffi`, signaling these are user-facing APIs rather than reflection internals.
- **access_path.cc build promotion**: moved from optional `TVM_FFI_USE_EXTRA_CXX_API` gate to always-compiled core sources, indicating `AccessPath`/`AccessStep` are now considered core infrastructure.

## Usage Examples

Before/after calling pattern for StructuralEqual (C++):
```cpp
// BEFORE:
#include <tvm/ffi/reflection/structural_equal.h>
namespace refl = tvm::ffi::reflection;
bool eq = refl::StructuralEqual()(a, b);
auto mismatch = refl::StructuralEqual::GetFirstMismatch(a, b);
// mismatch path used: refl::AccessStep::ArrayIndex(i)

// AFTER:
#include <tvm/ffi/extra/structural_equal.h>
using tvm::ffi::StructuralEqual;
bool eq = StructuralEqual()(a, b);
auto mismatch = StructuralEqual::GetFirstMismatch(a, b);
// mismatch path used: tvm::ffi::reflection::AccessStep::ArrayItem(i)
```
