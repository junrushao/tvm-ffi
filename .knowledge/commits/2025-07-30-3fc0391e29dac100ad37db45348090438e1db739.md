# Isolate extra API into dedicated include/tvm/ffi/extra/ directory, move structural equal/hash out of reflection namespace
## TL;DR
- Creates a new `include/tvm/ffi/extra/` directory with `base.h` that owns the `TVM_FFI_EXTRA_CXX_API` macro (previously in `c_api.h`).
- Moves `StructuralEqual` and `StructuralHash` from `tvm::ffi::reflection` namespace to `tvm::ffi` namespace, and from `include/tvm/ffi/reflection/` to `include/tvm/ffi/extra/`.
- Renames `AccessKind` enum values: `kArrayIndex` -> `kArrayItem`, `kMapKey` -> `kMapItem` (plus corresponding `*Missing` variants and `AccessStep` factory methods).
- Promotes `access_path.cc` from conditional (`TVM_FFI_USE_EXTRA_CXX_API`) to always-compiled core source.
- Renames global functions: `ffi.reflection.GetFirstStructuralMismatch` -> `ffi.GetFirstStructuralMismatch`, `ffi.reflection.StructuralHash` -> `ffi.StructuralHash`.

## Impact
- API: Callers using `tvm::ffi::reflection::StructuralEqual` or `tvm::ffi::reflection::StructuralHash` must change to `tvm::ffi::StructuralEqual` / `tvm::ffi::StructuralHash`. Include paths change from `tvm/ffi/reflection/structural_*.h` to `tvm/ffi/extra/structural_*.h`. All callers of the renamed `AccessStep` factory methods and `AccessKind` enum values must update.
- ABI: none -- `TVM_FFI_EXTRA_CXX_API` macro value unchanged; global function names changed (string-level, not binary ABI).
- Behavioral: none -- all implementations are unchanged.
- Flags/config: `access_path.cc` is now always compiled (no longer gated by `TVM_FFI_USE_EXTRA_CXX_API`). This means `AccessStepObj`, `AccessPath`, and `AccessPathPair` types are part of the core build, not extra.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`.knowledge/designs/reflection.md`) -- `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`, `FieldGetter`, `AccessStep`, `AccessPath`, `AccessPathPair`, `GlobalDef`, `ObjectDef<T>` are all used by the moved structural equal/hash implementations.
- **Object system** (`.knowledge/designs/object-system.md`) -- `Object`, `ObjectRef`, `make_object`, dual-class pattern for `AccessStepObj`/`AccessStep`.
- **C ABI** (`.knowledge/designs/c-abi.md`) -- `TVM_FFI_DLL`, `TVMFFIFieldInfo`, `kTVMFFIFieldFlagBitMaskSEqHashIgnore`, `kTVMFFIFieldFlagBitMaskSEqHashDef`.

Design elements this commit produces:
- **Extra API directory convention** -- new `include/tvm/ffi/extra/` directory with `base.h` defining `TVM_FFI_EXTRA_CXX_API`. Establishes the pattern that non-core C++ APIs live under `extra/` with their own base header, rather than polluting `c_api.h` with C++-only macros.
- **Core/Extra boundary for access_path** -- `access_path.cc` promoted to core (always compiled), establishing that the `AccessStep`/`AccessPath` types are core infrastructure, while structural equal/hash are extra features that consume them.

## Usage Examples
After this commit, C++ callers write:
```cpp
// Before
#include <tvm/ffi/reflection/structural_equal.h>
tvm::ffi::reflection::StructuralEqual seq;
bool eq = seq(a, b);

// After
#include <tvm/ffi/extra/structural_equal.h>
tvm::ffi::StructuralEqual seq;
bool eq = seq(a, b);
```

AccessStep factory methods:
```cpp
// Before
reflection::AccessStep::ArrayIndex(i)
reflection::AccessStep::MapKey(key)

// After
reflection::AccessStep::ArrayItem(i)
reflection::AccessStep::MapItem(key)
```
