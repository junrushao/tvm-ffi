# Isolate structural equal/hash into extra/ module, rename AccessKind enum values

## TL;DR
- Moves `StructuralEqual` and `StructuralHash` classes from `tvm::ffi::reflection` namespace (under `include/tvm/ffi/reflection/`) to `tvm::ffi` namespace (under `include/tvm/ffi/extra/`), formalizing the "extra API" tier.
- Introduces `include/tvm/ffi/extra/base.h` as the foundation header for the extra API layer, relocating the `TVM_FFI_EXTRA_CXX_API` visibility macro from `c_api.h`.
- Renames `AccessKind` enum values: `kArrayIndex` -> `kArrayItem`, `kMapKey` -> `kMapItem` (and corresponding `Missing` variants); renames the factory methods on `AccessStep` accordingly.
- Promotes `access_path.cc` from extra-only to core build (always compiled), while structural_equal/hash remain behind `TVM_FFI_USE_EXTRA_CXX_API`.

## Key Exports

```python
# New header: include/tvm/ffi/extra/base.h
# Defines TVM_FFI_EXTRA_CXX_API macro (relocated from c_api.h)
# TVM_FFI_EXTRA_CXX_API = TVM_FFI_DLL  (unless overridden)
# Interacts with: c_api.h (TVM_FFI_DLL), all extra/ headers

class StructuralEqual:
    """Deep structural equality for Any values. Now in tvm::ffi namespace (was tvm::ffi::reflection)."""
    # Interacts with: reflection::AccessPath (for mismatch reporting), reflection::FieldGetter,
    #   TypeAttrColumn("__s_equal__") for custom comparators, TVMFFIFieldInfo flags

    @staticmethod
    def Equal(lhs: Any, rhs: Any, map_free_vars: bool = False,
              skip_ndarray_content: bool = False) -> bool: ...

    @staticmethod
    def GetFirstMismatch(lhs: Any, rhs: Any, map_free_vars: bool = False,
                         skip_ndarray_content: bool = False) -> Optional[AccessPathPair]: ...

    def __call__(self, lhs: Any, rhs: Any) -> bool:
        return self.Equal(lhs, rhs, False, True)

class StructuralHash:
    """Deep structural hash for Any values. Now in tvm::ffi namespace (was tvm::ffi::reflection)."""
    # Interacts with: reflection::FieldGetter, TypeAttrColumn("__s_hash__"),
    #   details::StableHashCombine, details::StableHashBytes

    @staticmethod
    def Hash(value: Any, map_free_vars: bool = False,
             skip_ndarray_content: bool = False) -> int: ...

    def __call__(self, value: Any) -> int:
        return self.Hash(value)

class AccessKind(IntEnum):
    """Enum for access step kinds in structural comparison paths (renamed values)."""
    kObjectField = 0
    kArrayItem = 1       # was: kArrayIndex
    kMapItem = 2         # was: kMapKey
    kArrayItemMissing = 3  # was: kArrayIndexMissing
    kMapItemMissing = 4    # was: kMapKeyMissing

class AccessStep:
    """Factory methods renamed to match new AccessKind values."""
    @staticmethod
    def ArrayItem(index: int) -> AccessStep: ...       # was: ArrayIndex
    @staticmethod
    def ArrayItemMissing(index: int) -> AccessStep: ...  # was: ArrayIndexMissing
    @staticmethod
    def MapItem(key: Any) -> AccessStep: ...            # was: MapKey
    @staticmethod
    def MapItemMissing(key: Any) -> AccessStep: ...      # was: MapKeyMissing
```

## Impact
- API: **Breaking** -- `StructuralEqual`/`StructuralHash` move from `tvm::ffi::reflection` to `tvm::ffi` namespace. Include paths change from `tvm/ffi/reflection/structural_*.h` to `tvm/ffi/extra/structural_*.h`. `AccessKind` enum values renamed. All callers must update includes and qualified names.
- Behavioral: None -- no semantic changes to the equality/hash algorithms themselves.
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` CMake flag now also controls the new `extra/` directory. `access_path.cc` is now always compiled (moved out of the extra guard).
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`.knowledge/designs/0008-reflection.md`) -- `StructuralEqual`/`StructuralHash` use `reflection::FieldGetter`, `reflection::ForEachFieldInfo`, `reflection::TypeAttrColumn`, and `TVMFFIFieldInfo` flags (`kTVMFFIFieldFlagBitMaskSEqHashIgnore`, `kTVMFFIFieldFlagBitMaskSEqHashDef`).
- **Object system** (`.knowledge/designs/0002-object-system.md`) -- `TVMFFITypeInfo`, `structural_eq_hash_kind` metadata, type registration.
- **Any system** (`.knowledge/designs/0003-any-system.md`) -- `Any`/`AnyView` for type-erased field access and comparison.
- **Containers** (`.knowledge/designs/0007-containers.md`) -- `Array`, `Map`, `Shape`, `NDArray` have specialized comparison/hashing paths.
- **C ABI** (`.knowledge/designs/0001-c-abi.md`) -- `TVM_FFI_DLL` visibility macro, `TVMFFIAny` layout.

Design elements this commit produces:
- **Extra API layer** (`include/tvm/ffi/extra/`) -- A new directory tier for C++ APIs that are useful but not required for core FFI functionality. Governed by `TVM_FFI_USE_EXTRA_CXX_API` CMake flag and `TVM_FFI_EXTRA_CXX_API` visibility macro.
- **`extra/base.h`** -- Foundation header for the extra API layer, defining the `TVM_FFI_EXTRA_CXX_API` macro.
