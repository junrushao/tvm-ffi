# Isolate structural equal/hash into new extra/ module, rename AccessKind enum values

## TL;DR
- Moves `StructuralEqual` and `StructuralHash` from `include/tvm/ffi/reflection/` and `src/ffi/reflection/` to a new `include/tvm/ffi/extra/` and `src/ffi/extra/` directory, formalizing the "extra API" boundary.
- Introduces `include/tvm/ffi/extra/base.h` as the base header for the extra API, relocating the `TVM_FFI_EXTRA_CXX_API` macro from `c_api.h`.
- Renames `AccessKind` enum values and `AccessStep` factory methods: `kArrayIndex` -> `kArrayItem`, `kMapKey` -> `kMapItem` (and their `Missing` variants).

### Rename mapping

| Before | After |
|--------|-------|
| `include/tvm/ffi/reflection/structural_equal.h` | `include/tvm/ffi/extra/structural_equal.h` |

| `src/ffi/reflection/structural_equal.cc` | `src/ffi/extra/structural_equal.cc` |
| `src/ffi/reflection/structural_hash.cc` | `src/ffi/extra/structural_hash.cc` |

| `AccessKind::kArrayIndex` | `AccessKind::kArrayItem` |
| `AccessKind::kMapKey` | `AccessKind::kMapItem` |
| `AccessKind::kArrayIndexMissing` | `AccessKind::kArrayItemMissing` |
| `AccessKind::kMapKeyMissing` | `AccessKind::kMapItemMissing` |

## Key Exports

**New header**: `include/tvm/ffi/extra/base.h`
- Defines `TVM_FFI_EXTRA_CXX_API` macro (previously in `c_api.h`). Marks functions as extra C++ API implemented in `.cc` files, using `TVM_FFI_DLL` visibility.

**Relocated classes** (same API surface, new include path):
- `tvm::ffi::StructuralEqual` -- now at `<tvm/ffi/extra/structural_equal.h>` (was `<tvm/ffi/reflection/structural_equal.h>`)
- `tvm::ffi::StructuralHash` -- now at `<tvm/ffi/extra/structural_hash.h>` (was `<tvm/ffi/reflection/structural_hash.h>`)

**Renamed enum values** in `AccessKind` (`reflection/access_path.h`):
```cpp
enum class AccessKind : int32_t {
  kObjectField = 0,
  kArrayItem = 1,       // was kArrayIndex
  kMapItem = 2,         // was kMapKey
  kArrayItemMissing = 3, // was kArrayIndexMissing
  kMapItemMissing = 4,   // was kMapKeyMissing
};
```

**Renamed static factory methods** on `AccessStep`:
```cpp
static AccessStep ArrayItem(int64_t index);       // was ArrayIndex
static AccessStep ArrayItemMissing(int64_t index); // was ArrayIndexMissing
static AccessStep MapItem(Any key);                // was MapKey
static AccessStep MapItemMissing(Any key);         // was MapKeyMissing
```

**Build change**: `access_path.cc` moved from `TVM_FFI_USE_EXTRA_CXX_API`-conditional to unconditional core sources in `CMakeLists.txt`. `structural_equal.cc` and `structural_hash.cc` remain conditional under `TVM_FFI_USE_EXTRA_CXX_API`.

## Impact
- API: Breaking for any downstream code including `<tvm/ffi/reflection/structural_equal.h>` or `<tvm/ffi/reflection/structural_hash.h>` -- must update to `<tvm/ffi/extra/...>`. Callers using `AccessKind::kArrayIndex`, `kMapKey`, `ArrayIndex()`, `MapKey()` must update to `kArrayItem`/`kMapItem`/`ArrayItem()`/`MapItem()`.
- Behavioral: None -- no functional change.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`reflection/accessor.h`, `reflection/access_path.h`) -- `StructuralEqual`/`StructuralHash` use `FieldGetter`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`, `TypeAttrColumn`, `AccessStep`, `AccessPath`, `AccessPathPair` from the reflection layer.
- **Object system** (`object.h`) -- `ObjectRef`, `ObjectPtrHash`, `ObjectPtrEqual` for memoization in equality/hash handlers.
- **Container types** (`Array`, `Map`, `Shape`, `NDArray`, `String`, `Bytes`) -- dispatched by `TypeIndex` in structural comparison/hash.
- **`TVM_FFI_DLL` / `TVM_FFI_DLL_EXPORT`** visibility macros from `c_api.h`.
- **`TVM_FFI_STATIC_INIT_BLOCK`** for global function registration (`ffi.GetFirstStructuralMismatch`, `ffi.StructuralHash`).

Design elements this commit produces:
- **`extra/` module boundary** -- new directory `include/tvm/ffi/extra/` with `base.h` establishing the convention for extra (non-core) C++ APIs. This formalizes the separation between core FFI functionality and optional features.
- **`TVM_FFI_EXTRA_CXX_API` relocated** -- now lives in `extra/base.h` rather than `c_api.h`, keeping the C API header free of C++-only concerns.
- **`kArrayItem`/`kMapItem` naming convention** -- renames `Index`/`Key` to `Item`, normalizing the vocabulary for container element access.

Design elements this commit mutates:
- **`AccessKind` enum** -- values renamed from `Index`/`Key` to `Item` terminology.
- **`AccessStep` factory API** -- method names updated to match new `AccessKind` values.
- **`access_path.cc` build classification** -- promoted from extra-only to core (always compiled).

## Usage Examples
After this commit, include paths and factory method names change:

```cpp
// Before
#include <tvm/ffi/reflection/structural_equal.h>
auto diff = StructuralEqual::GetFirstMismatch(a, c);
// (*diff).get<0>()[0]->kind == refl::AccessKind::kArrayIndex
auto step = refl::AccessStep::ArrayIndex(2);
auto kstep = refl::AccessStep::MapKey("b");

// After
#include <tvm/ffi/extra/structural_equal.h>
auto diff = StructuralEqual::GetFirstMismatch(a, c);
// (*diff).get<0>()[0]->kind == refl::AccessKind::kArrayItem
auto step = refl::AccessStep::ArrayItem(2);
auto kstep = refl::AccessStep::MapItem("b");
```
