# Formalize the extra API subsystem by relocating structural-equal/hash from reflection/ to extra/ and renaming AccessKind enum variants

## TL;DR
- Introduces `include/tvm/ffi/extra/base.h` as the dedicated home for the `TVM_FFI_EXTRA_CXX_API` DLL-export macro, removing it from `c_api.h`. Structural-equal and structural-hash headers/sources move from `reflection/` to `extra/`.
- `access_path.cc` is promoted from conditionally-compiled (under `TVM_FFI_USE_EXTRA_CXX_API`) to unconditionally compiled core, so reflection-based error reporting is always available.
- `AccessKind` enum variants are renamed for consistency: `kArrayIndex` → `kArrayItem`, `kArrayIndexMissing` → `kArrayItemMissing`, `kMapKey` → `kMapItem`, `kMapKeyMissing` → `kMapItemMissing`; corresponding `AccessStep` factory statics are renamed to match.

| Old name | New name |
|---|---|
| `include/tvm/ffi/reflection/structural_equal.h` | `include/tvm/ffi/extra/structural_equal.h` |
| `include/tvm/ffi/reflection/structural_hash.h` | `include/tvm/ffi/extra/structural_hash.h` |
| `src/ffi/reflection/structural_equal.cc` | `src/ffi/extra/structural_equal.cc` |
| `src/ffi/reflection/structural_hash.cc` | `src/ffi/extra/structural_hash.cc` |
| `tests/cpp/extra/test_reflection_structural_equal_hash.cc` | `tests/cpp/extra/test_structural_equal_hash.cc` |
| `c_api.h` — `TVM_FFI_EXTRA_CXX_API` macro | `extra/base.h` — `TVM_FFI_EXTRA_CXX_API` macro |
| `AccessKind::kArrayIndex` | `AccessKind::kArrayItem` |
| `AccessKind::kArrayIndexMissing` | `AccessKind::kArrayItemMissing` |
| `AccessKind::kMapKey` | `AccessKind::kMapItem` |
| `AccessKind::kMapKeyMissing` | `AccessKind::kMapItemMissing` |
| `AccessStep::ArrayIndex(i)` | `AccessStep::ArrayItem(i)` |

| `AccessStep::MapKeyMissing(k)` | `AccessStep::MapItemMissing(k)` |

## Key Exports

```python
# NEW: include/tvm/ffi/extra/base.h — previously in c_api.h
# TVM_FFI_EXTRA_CXX_API: DLL-visibility macro for extra C++ APIs implemented in .cc files
# Interacts with: StructuralEqual, StructuralHash (annotate their static methods)
# Invariant: expands to TVM_FFI_DLL (visibility("default") / dllexport)

class StructuralEqual:
    """Structural equality comparator for Any values. Header: extra/structural_equal.h"""
    # Old include: tvm/ffi/reflection/structural_equal.h
    # New include: tvm/ffi/extra/structural_equal.h

    @staticmethod
    def Equal(lhs: Any, rhs: Any,
              map_free_vars: bool = False,
              skip_ndarray_content: bool = False) -> bool: ...
    # Interacts with: StructEqualHandler (internal), reflection::TypeAttrColumn("__s_equal__"),
    #                 TVMFFITypeInfo.metadata.structural_eq_hash_kind
    # Invariant: throws TypeError if type has no metadata or kTVMFFISEqHashKindUnsupported

    @staticmethod
    def GetFirstMismatch(lhs: Any, rhs: Any,
                         map_free_vars: bool = False,
                         skip_ndarray_content: bool = False) -> Optional[reflection.AccessPathPair]: ...
    # Interacts with: AccessPath, AccessStep (uses renamed variants kArrayItem, kMapItem)

    def __call__(self, lhs: Any, rhs: Any) -> bool:
        return StructuralEqual.Equal(lhs, rhs, map_free_vars=False, skip_ndarray_content=True)


class StructuralHash:
    """Structural hash functor for Any values. Header: extra/structural_hash.h"""
    # Old include: tvm/ffi/reflection/structural_hash.h
    # New include: tvm/ffi/extra/structural_hash.h

    @staticmethod
    def Hash(value: Any, map_free_vars: bool = False,
             skip_ndarray_content: bool = False) -> uint64_t: ...
    # Interacts with: StructuralHashHandler (internal), TypeAttrColumn("__s_hash__")
    # Invariant: consistent with StructuralEqual — equal objects produce equal hashes

    def __call__(self, value: Any) -> uint64_t:
        return StructuralHash.Hash(value)


class reflection.AccessKind(IntEnum):
    """Discriminator for one step in an AccessPath. Header: reflection/access_path.h"""
    kObjectField      = 0
    kArrayItem        = 1   # was: kArrayIndex
    kMapItem          = 2   # was: kMapKey
    kArrayItemMissing = 3   # was: kArrayIndexMissing
    kMapItemMissing   = 4   # was: kMapKeyMissing


class reflection.AccessStep(ObjectRef):
    """One step along an object traversal path, used in StructuralEqual mismatch reporting."""
    @staticmethod
    def ObjectField(name: str) -> AccessStep: ...
    @staticmethod
    def ArrayItem(index: int64) -> AccessStep: ...          # was: ArrayIndex
    @staticmethod
    def ArrayItemMissing(index: int64) -> AccessStep: ...   # was: ArrayIndexMissing
    @staticmethod
    def MapItem(key: Any) -> AccessStep: ...                # was: MapKey
    @staticmethod
    def MapItemMissing(key: Any) -> AccessStep: ...         # was: MapKeyMissing
    # Interacts with: StructuralEqual.GetFirstMismatch (produces steps for first mismatch path)
```

## Impact
- API: **Breaking rename** — `AccessKind::kArrayIndex`/`kMapKey` variants and `AccessStep::ArrayIndex`/`MapKey` factory statics are renamed. Any C++ code using the old `reflection/structural_equal.h` or `reflection/structural_hash.h` include paths must update to `extra/`. Any code using `kArrayIndex`/`kMapKey` or `AccessStep::ArrayIndex()`/`MapKey()` must update to the new names. Severity: `medium` (3–10 call sites; these are internal helper types not typically used outside FFI core or tests).
- Behavioral: None — functionality is identical; only the location and naming of API surface changed.
- Flags/config: `access_path.cc` is now always compiled (moved out of `TVM_FFI_USE_EXTRA_CXX_API` guard), meaning AccessPath/AccessStep are always available, even when extra C++ APIs are disabled.
- Data formats/schemas: None.

## Usage Examples

**Before/after for AccessKind — consumers of AccessPath mismatch result:**
```cpp
// Before this commit:
auto diff = StructuralEqual::GetFirstMismatch(a, b);
if (diff && (*diff).get<0>()[0]->kind == reflection::AccessKind::kArrayIndex) { ... }
// Also: #include <tvm/ffi/reflection/structural_equal.h>

// After this commit:
auto diff = StructuralEqual::GetFirstMismatch(a, b);
if (diff && (*diff).get<0>()[0]->kind == reflection::AccessKind::kArrayItem) { ... }
// Also: #include <tvm/ffi/extra/structural_equal.h>
```
