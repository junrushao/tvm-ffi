# Isolate structural equal/hash into ffi/extra namespace, rename AccessStep factories
## TL;DR
- Moves `StructuralEqual` and `StructuralHash` from `tvm::ffi::reflection` namespace and `include/tvm/ffi/reflection/` directory to `tvm::ffi` namespace and `include/tvm/ffi/extra/` directory, formalizing the "extra API" concept as a distinct layer.
- Creates `include/tvm/ffi/extra/base.h` as the new home for `TVM_FFI_EXTRA_CXX_API` macro (previously in `c_api.h`), establishing the extra API directory.
- Renames `AccessStep` factory methods: `ArrayIndex` -> `ArrayItem`, `MapKey` -> `MapItem`, `ArrayIndexMissing` -> `ArrayItemMissing`, `MapKeyMissing` -> `MapItemMissing`; corresponding `AccessKind` enum values renamed to match.
- Promotes `access_path.cc` from conditional `TVM_FFI_USE_EXTRA_CXX_API` build to unconditional core build. Global function names shortened: `ffi.reflection.GetFirstStructuralMismatch` -> `ffi.GetFirstStructuralMismatch`, `ffi.reflection.StructuralHash` -> `ffi.StructuralHash`.

## Impact
- API: Breaking namespace change -- `StructuralEqual`/`StructuralHash` move from `tvm::ffi::reflection` to `tvm::ffi`. All C++ callers using the old fully-qualified names or `using namespace reflection` to reach these types must update includes and namespace prefixes. `AccessStep::ArrayIndex`/`MapKey` factories renamed; all call sites must update. Global function registry names shortened; any cross-language callers using the old string names will fail lookup.
- Behavioral: None -- equality/hash semantics unchanged.
- Flags/config: `access_path.cc` moved from conditional (`TVM_FFI_USE_EXTRA_CXX_API`) to unconditional core build in CMakeLists.txt.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`0008-reflection.md`): `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`, `FieldGetter`, `AccessStep`, `AccessPath`, `AccessPathPair` -- these remain in `tvm::ffi::reflection` and are now referenced via explicit `reflection::` qualification from structural equal/hash implementations.
- **C ABI visibility macros** (`0007-c-abi.md`): `TVM_FFI_DLL`, `TVM_FFI_DLL_EXPORT` -- used by the new `TVM_FFI_EXTRA_CXX_API` definition in `extra/base.h`.
- **Global function registry** (`0003-function-system.md`): `GlobalDef().def(...)` for registering `ffi.GetFirstStructuralMismatch` and `ffi.StructuralHash`.

Design elements this commit produces:
- **`ffi/extra` directory and base header**: New organizational layer (`include/tvm/ffi/extra/`) for non-core C++ APIs, with `extra/base.h` as the common header defining `TVM_FFI_EXTRA_CXX_API`. This establishes a convention: extra APIs live in `ffi/extra/`, depend on core but are not required for core functionality, and are gated behind `TVM_FFI_USE_EXTRA_CXX_API` CMake flag.

## Usage Examples

```cpp
// Before: accessing StructuralEqual from reflection namespace
#include <tvm/ffi/reflection/structural_equal.h>
using namespace tvm::ffi::reflection;
bool eq = StructuralEqual()(a, b);
auto diff = StructuralEqual::GetFirstMismatch(a, b);
// AccessStep used kArrayIndex:
auto step = AccessStep::ArrayIndex(0);

// After: StructuralEqual in ffi namespace, include from extra/
#include <tvm/ffi/extra/structural_equal.h>
using namespace tvm::ffi;
bool eq = StructuralEqual()(a, b);
auto diff = StructuralEqual::GetFirstMismatch(a, b);
// AccessStep factory renamed:
auto step = reflection::AccessStep::ArrayItem(0);
```
