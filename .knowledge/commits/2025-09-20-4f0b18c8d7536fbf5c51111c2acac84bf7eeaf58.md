# Migrate doc build from Makefile+requirements.txt to uv dependency-groups

## TL;DR
- Removes `docs/Makefile` and `docs/requirements.txt`, replacing the Makefile-based Sphinx build with `uv run --group docs` commands.
- Adds a PEP 735 `[dependency-groups] docs` section to `pyproject.toml` with the same 21 Sphinx/doc dependencies previously in `requirements.txt`.
- Rewrites `docs/README.md` with structured sections (interactive build, one-off build, C++ docs, cleanup) using the new uv workflow.

N/A -- infrastructure.

## Impact
- API: none
- Behavioral: none (doc content unchanged, only the build invocation changes)
- Flags/config: `BUILD_CPP_DOCS=1` environment variable remains; invocation changes from `make livehtml` to `uv run --group docs sphinx-autobuild ...`

## Usage Examples
N/A -- infrastructure. The new workflow is documented in `docs/README.md`:

```bash
# Interactive build (auto-reload)
uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated

# One-off build
uv run --group docs sphinx-build -M html docs docs/_build

# With C++ docs
BUILD_CPP_DOCS=1 uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated
```
