# Migrate docs build from Makefile+requirements.txt to uv dependency-groups
## TL;DR
- Deletes `docs/Makefile` and `docs/requirements.txt`, replacing them with a `[dependency-groups] docs` section in `pyproject.toml`.
- Rewrites `docs/README.md` with uv-based commands (`uv run --group docs sphinx-autobuild ...`) instead of the old `pip install -r requirements.txt && make livehtml` workflow.
- No functional changes to the documentation content or Sphinx configuration itself.

## Key Exports
N/A -- infrastructure only. No new classes, functions, or public API surfaces introduced.

## Impact
- API: none
- Behavioral: none -- docs content and Sphinx config unchanged
- Flags/config: `uv run --group docs` replaces `pip install -r docs/requirements.txt && make livehtml`. The `BUILD_CPP_DOCS=1` env var is preserved but invoked via uv now.
- Data formats/schemas: none

Design elements this commit consumes:

- Existing `pyproject.toml` structure from [0013-ffi-packaging-and-distribution](../design-records/0013-ffi-packaging-and-distribution.md)

Design elements this commit produces: none

## Usage Examples
The new one-liner for interactive docs build (from `docs/README.md`):
```bash
# Interactive build with auto-reload (from repo root)
uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated

# One-off build
uv run --group docs sphinx-build -M html docs docs/_build

# With C++ API reference
BUILD_CPP_DOCS=1 uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated
```
