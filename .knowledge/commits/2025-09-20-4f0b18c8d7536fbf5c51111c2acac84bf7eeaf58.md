# Migrate doc build workflow from pip+Makefile to uv dependency-groups

## TL;DR

- Deleted `docs/Makefile` and `docs/requirements.txt`; replaced with a `[dependency-groups] docs` section in `pyproject.toml` that lists all Sphinx dependencies.
- All doc build commands now use `uv run --group docs sphinx-autobuild|sphinx-build`; no separate `pip install -r requirements.txt` or `make` step is needed.
- `docs/README.md` rewritten to document the new one-liner workflows (interactive build, one-off build, C++ docs with `BUILD_CPP_DOCS=1`, and cleanup).

## Key Exports

N/A — infrastructure

## Impact

- API: none
- Behavioral: Doc build entry-point changes from `make livehtml` (requires `pip install -r requirements.txt` + `pip install ..`) to `uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated`. Makefile targets (`livehtml`, `clean`, etc.) are gone.
- Flags/config: `BUILD_CPP_DOCS=1` env-var still applies (same as before) but is now passed directly to the `uv run` commands rather than through `make`.
- Data formats/schemas: `pyproject.toml` gains a `[dependency-groups]` table (PEP 735 / uv extension). `docs/requirements.txt` is deleted.

## Usage Examples

```bash
# Interactive doc build (auto-reload at http://127.0.0.1:8000)
uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated

# One-off HTML build
uv run --group docs sphinx-build -M html docs docs/_build

# C++ API reference (requires Doxygen installed)
BUILD_CPP_DOCS=1 uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated

# Cleanup
rm -rf docs/_build/ docs/reference/python/generated docs/reference/cpp/generated
```
