# Migrate doc-build workflow from Makefile+requirements.txt to uv dependency groups
## TL;DR
- Deletes `docs/Makefile` and `docs/requirements.txt`, replacing them with a `[dependency-groups] docs = [...]` section in `pyproject.toml`.
- Rewrites `docs/README.md` to document the new `uv run --group docs` commands for interactive, one-off, and C++-inclusive doc builds.
- Aligns doc tooling with the project-wide `uv`-based workflow already used for Python development and testing.

## Key Exports
None

## Impact
- API: none
- Behavioral: none -- documentation content is unchanged; only the build invocation changes.
- Flags/config: The doc dependency list moves from `docs/requirements.txt` to `pyproject.toml` under `[dependency-groups] docs`. The env var `BUILD_CPP_DOCS=1` is preserved for C++ doc generation.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **uv-based project workflow** -- the project already uses `uv` for editable installs and test runs (`uv pip install -e .`, `uv run pytest`). This commit extends the same pattern to documentation builds.
- **Sphinx documentation infrastructure** (`.knowledge/designs/0015-docs-site.md` recommended in prior ledger) -- the Sphinx `conf.py`, toctree, and extension set are unchanged; only the entry point shifts from `make` to `uv run`.

Design elements this commit produces:
- **`[dependency-groups] docs` in `pyproject.toml`** -- a new PEP 735 dependency group that declares all Sphinx-related packages in one place, replacing the standalone `docs/requirements.txt`.

## Usage Examples
Interactive doc build with live reload (new workflow):
```bash
uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated
```

One-off HTML build:
```bash
uv run --group docs sphinx-build -M html docs docs/_build
```

With C++ API reference:
```bash
BUILD_CPP_DOCS=1 uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated
```
