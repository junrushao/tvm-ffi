# Migrate doc build from Makefile+requirements.txt to uv dependency groups
## TL;DR
- Deleted `docs/Makefile` and `docs/requirements.txt`, replacing them with a `[dependency-groups] docs` section in `pyproject.toml`.
- Rewrote `docs/README.md` with uv-based build commands (`uv run --group docs sphinx-autobuild ...` / `sphinx-build ...`).
- Doc building is now a one-liner using uv, consistent with the project's existing uv-based Python workflow.

## Key Exports
N/A -- infrastructure change only.

## Impact
- API: none
- Behavioral: Doc build invocation changes from `pip install -r requirements.txt && make livehtml` to `uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated`.
- Flags/config: `BUILD_CPP_DOCS=1` environment variable is preserved for optional C++ doc generation.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: None -- no FFI design elements are involved.

Design elements this commit produces: None -- purely build infrastructure.

## Usage Examples
Doc build one-liners (from `docs/README.md`):

```bash
# Interactive build with live reload
uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated

# One-off build
uv run --group docs sphinx-build -M html docs docs/_build

# With C++ API reference
BUILD_CPP_DOCS=1 uv run --group docs sphinx-autobuild docs docs/_build/html --ignore docs/reference/cpp/generated
```
