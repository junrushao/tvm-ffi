# Migrate doc building from Makefile+requirements.txt to uv dependency groups
## TL;DR
- Deletes `docs/Makefile` and `docs/requirements.txt`, replacing them with a `[dependency-groups] docs` section in `pyproject.toml`.
- Rewrites `docs/README.md` to document the new `uv run --group docs sphinx-autobuild ...` and `uv run --group docs sphinx-build ...` workflows.
- Aligns doc building with the project's existing uv-based Python workflow, making it a one-liner.
