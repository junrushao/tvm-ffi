# Fix JSON parser UTF-8 control character check
## TL;DR
- Casts *cur_ to unsigned char before comparing against space (0x20). On signed-char platforms, UTF-8 bytes >= 0x80 were misinterpreted as negative, causing non-ASCII strings to be rejected. Adds RawUTF8Bytes regression test.
