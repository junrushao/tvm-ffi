# Fix RPATH for tvm_ffi_testing in wheel packaging
## TL;DR
- Set `INSTALL_RPATH` on `tvm_ffi_testing` target (`@loader_path` on macOS, `$ORIGIN` on Linux) so the testing library can locate `libtvm_ffi.so` at runtime when installed via a wheel.
- Fixed `tvm_ffi_cython` RPATH guard from `LINUX` to `UNIX AND NOT APPLE` for broader Unix compatibility.
