# Fix tvm_ffi_testing RPATH and portable Linux detection in wheel packaging
## TL;DR
- Add `INSTALL_RPATH` to the `tvm_ffi_testing` shared library target so it can find `libtvm_ffi.so` at relative path when installed from a wheel.
- Fix platform detection for `tvm_ffi_cython` RPATH: replace `LINUX` (CMake 3.25+) with `UNIX AND NOT APPLE` (portable to CMake 3.18+, the project minimum).

- Behavioral: `tvm_ffi_testing.so` now locates `libtvm_ffi.so` via relative RPATH in installed wheels (previously failed at load time). Cython extension RPATH now correctly applies on all Unix platforms, not just those with CMake >= 3.25.
