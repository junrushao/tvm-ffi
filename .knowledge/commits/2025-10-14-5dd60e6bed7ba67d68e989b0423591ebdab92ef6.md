# Fix tvm_ffi_testing RPATH and broaden Unix RPATH detection for wheel packaging
## TL;DR
- Adds `INSTALL_RPATH` to `tvm_ffi_testing` so the testing shared library can locate `libtvm_ffi.so` via relative path (`@loader_path` on macOS, `$ORIGIN` on Linux/Unix) when installed in a wheel.
- Fixes `tvm_ffi_cython` RPATH condition from `LINUX` to `UNIX AND NOT APPLE`, covering BSD and other non-Linux Unix platforms.
