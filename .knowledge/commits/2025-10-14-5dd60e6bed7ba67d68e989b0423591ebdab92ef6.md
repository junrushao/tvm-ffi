# Fix INSTALL_RPATH for tvm_ffi_testing and correct UNIX guard for tvm_ffi_cython in CMakeLists.txt

## TL;DR
- Adds `INSTALL_RPATH` to the `tvm_ffi_testing` CMake target so that the test binary can locate `libtvm_ffi.so` via a relative path (`@loader_path` on macOS, `$ORIGIN` on Linux) after wheel installation.
- Fixes the `elseif (LINUX)` guard for `tvm_ffi_cython`'s RPATH to `elseif (UNIX AND NOT APPLE)` — `LINUX` is not a reliable CMake variable, whereas `UNIX AND NOT APPLE` correctly targets Linux and other non-Apple UNIX platforms.

- Behavioral: `tvm_ffi_testing` executable can now find `libtvm_ffi.so` when installed via wheel (e.g. `pip install`), fixing a runtime linker failure at test time on installed wheels.
- Flags/config: `INSTALL_RPATH` property added to `tvm_ffi_testing`; `elseif (LINUX)` corrected to `elseif (UNIX AND NOT APPLE)` for `tvm_ffi_cython`.
