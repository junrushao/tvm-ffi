# Add cmake>=3.18 to pyproject.toml build-system requires
## TL;DR
- Adds `cmake>=3.18` to the `[build-system].requires` list in `pyproject.toml`, so CMake is automatically fetched from PyPI during `pip install` / wheel builds.
- Eliminates the need for users to manually install CMake before building the package.
