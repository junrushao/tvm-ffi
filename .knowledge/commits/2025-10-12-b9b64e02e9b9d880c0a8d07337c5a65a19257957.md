# Add cmake>=3.18 as explicit PEP 517 build dependency
## TL;DR
- Adds `"cmake>=3.18"` to the `[build-system] requires` list in `pyproject.toml`, making CMake a declared PEP 517 build dependency alongside `scikit-build-core` and `cython`.
- Eliminates the need for users to pre-install CMake before `pip install tvm_ffi`; pip/uv will fetch it automatically from PyPI.
