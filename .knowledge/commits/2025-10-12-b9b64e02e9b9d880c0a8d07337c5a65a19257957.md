# Add cmake>=3.18 as a PEP 517 build dependency in pyproject.toml
## TL;DR
- Adds `"cmake>=3.18"` to `[build-system].requires` in `pyproject.toml`, so CMake is auto-installed during `pip install` / `pip wheel` without users needing to install it manually.
