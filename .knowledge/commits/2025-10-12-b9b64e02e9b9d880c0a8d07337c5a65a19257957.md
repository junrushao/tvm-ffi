# Add CMake as an explicit PEP 517 build dependency in pyproject.toml
## TL;DR
- Adds `cmake>=3.18` to the `[build-system].requires` list in `pyproject.toml`, so that CMake is automatically installed by the PEP 517 build frontend (pip/build/uv) rather than requiring users to install it manually.
- This removes the need to mention CMake as a prerequisite in tutorials and setup guides.

None

## Impact
- API: none
- ABI: none
- Behavioral: Build frontends (pip, build, uv) now automatically fetch and install CMake >= 3.18 when building from source if it is not already available. Previously, users had to ensure CMake was installed system-wide before running `pip install`.
