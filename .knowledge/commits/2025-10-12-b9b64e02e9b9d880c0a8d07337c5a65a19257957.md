# Add cmake>=3.18 as an explicit PyPI build-system dependency in pyproject.toml

## TL;DR
- Adds `cmake>=3.18` to `[build-system] requires` in `pyproject.toml` so that CMake is automatically installed by pip during editable/wheel builds without requiring a separate manual installation step.
- Removes the need to document CMake installation in tutorials, since pip's build-isolation now handles it.
