# Clean up libbacktrace build output and add target triple auto-detection
## TL;DR
- Suppresses verbose libbacktrace build output by redirecting to log files.
- Replaces the invalid `--host={MACHINE_NAME}` configure flag with a proper target triple auto-detection module (`cmake/Utils/DetectTargetTriple.cmake`).
- Adds 303-line CMake utility for detecting host target triple from compiler output.

## Impact
- API: None.
- Flags/config: New CMake module `DetectTargetTriple.cmake`. Cleaner build output.
