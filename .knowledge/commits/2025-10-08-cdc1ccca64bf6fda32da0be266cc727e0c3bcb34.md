# chore: Clean up libbacktrace-related outputs (#92)

## TL;DR
- Redirect libbacktrace ExternalProject configure/build/install output to log files (LOG_CONFIGURE, LOG_BUILD, LOG_INSTALL ON), only surfacing on failure.
- Replace the broken `--host=${MACHINE_NAME}` (undefined variable) with a new `detect_target_triple()` CMake function that properly auto-detects the target triple.
- Add `cmake/Utils/DetectTargetTriple.cmake` with a 5-tier detection strategy covering CMake compiler target, compiler query, platform-specific construction (Emscripten, Android, iOS, MSVC, MinGW), Debian multiarch, and OS-based fallback.
