# Silence libbacktrace build noise and introduce detect_target_triple() CMake helper

## TL;DR
- `ExternalProject_Add` for libbacktrace now sets `LOG_CONFIGURE ON`, `LOG_BUILD ON`, `LOG_INSTALL ON`, `LOG_OUTPUT_ON_FAILURE ON`, routing verbose configure/build/install stdout to log files; output is surfaced only on failure.
- The stale `--host=${MACHINE_NAME}` flag (which was an unset CMake variable, silently expanding to `--host=`) is replaced by `detect_target_triple(TVM_FFI_MACHINE_NAME)` which correctly determines the target triple.
- New `cmake/Utils/DetectTargetTriple.cmake` adds a standalone `detect_target_triple(out_var)` function with a five-level fallback chain usable by any future CMake consumer.
