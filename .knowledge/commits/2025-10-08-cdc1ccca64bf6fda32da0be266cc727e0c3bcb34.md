# Clean up libbacktrace build output and fix broken --host flag with target triple auto-detection

## TL;DR
- Redirects libbacktrace `ExternalProject_Add` configure/build/install output to log files, only showing output on failure, eliminating noisy build spam.
- Fixes the broken `--host=${MACHINE_NAME}` flag (undefined CMake variable, always expanded to empty string) by replacing it with a new `detect_target_triple()` CMake function that auto-detects the target triple.
- Adds `cmake/Utils/DetectTargetTriple.cmake` with a 5-level fallback strategy covering Linux, macOS, Windows (MSVC/MinGW), Android, iOS, Emscripten, and FreeBSD.

## Key Exports

**Functions (CMake)**:
- `detect_target_triple(out_var)` -- Determines the target machine triple and stores it in `out_var`. Fallback order: (1) `CMAKE_<lang>_COMPILER_TARGET`, (2) compiler `-dumpmachine` / `--print-target-triple`, (3) platform-specific construction (Emscripten, Android, iOS, MSVC, MinGW), (4) `CMAKE_LIBRARY_ARCHITECTURE` (Debian multiarch), (5) OS-based synthesis from `CMAKE_SYSTEM_PROCESSOR` and `CMAKE_SYSTEM_NAME`.

## Impact
- API: none
- ABI: none
- Behavioral: libbacktrace's `./configure` now receives a valid `--host=<triple>` argument instead of an empty string; build output is suppressed unless an error occurs.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Error handling configuration** (`.knowledge/designs/error-handling.md`): `TVM_FFI_USE_LIBBACKTRACE` option gates the libbacktrace build

Design elements this commit produces:
- **Target triple auto-detection**: Reusable CMake function `detect_target_triple()` for cross-platform host detection, included unconditionally in the top-level `CMakeLists.txt` so it is available to any downstream consumer

## Usage Examples
Called within `cmake/Utils/AddLibbacktrace.cmake` to supply the `--host` flag to libbacktrace's autoconf configure script:
```cmake
include(${CMAKE_SOURCE_DIR}/cmake/Utils/DetectTargetTriple.cmake)
# ...
detect_target_triple(TVM_FFI_MACHINE_NAME)
message(STATUS "Detected target triple: ${TVM_FFI_MACHINE_NAME}")
# Result used as: "--host=${TVM_FFI_MACHINE_NAME}" in ExternalProject_Add
```
