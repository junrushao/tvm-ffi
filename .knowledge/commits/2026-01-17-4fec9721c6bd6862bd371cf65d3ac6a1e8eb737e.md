# Support older PyTorch versions in Cython dtype handling
## TL;DR
- Updates `dtype.pxi` to handle older PyTorch versions (1.10.2, 1.14.0a0, 2.0) that lack newer dtype attributes like `torch.float8_e4m3fn`.
- Uses `hasattr()` guards before accessing version-specific torch dtype mappings.
