# Support older PyTorch versions by guarding dtype attributes with hasattr checks
## TL;DR
- Refactors `TORCH_DTYPE_TO_DL_DATA_TYPE` initialization in `python/tvm_ffi/cython/dtype.pxi` to guard newer dtype attributes (`uint16`, `uint32`, `uint64`, `float8_*`, `float4_*`) behind `hasattr(torch, attr_name)` checks.
- Previously, directly referencing `torch.uint16` etc. at import time caused `AttributeError` on PyTorch < 2.0. Now `import tvm_ffi` succeeds on PyTorch versions as old as 1.10.2.
