# Enable wheel building on every main commit while keeping publish manual-only
## TL;DR
- Added `push: branches: [main]` trigger to the `publish_wheel.yml` workflow so wheel builds run on every commit to main, not just on manual dispatch.
- Updated `ref:` in checkout steps to dynamically select `inputs.branch` (manual) or `github.ref` (push), ensuring both trigger types resolve the correct commit.
- Publish-to-PyPI step remains gated to `workflow_dispatch` only, so automatic pushes build but do not publish.
