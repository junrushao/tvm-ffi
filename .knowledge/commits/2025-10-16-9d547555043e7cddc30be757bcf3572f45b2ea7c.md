# Test wheel building on every main commit without publishing
## TL;DR
- Adds `push: branches: [main]` trigger to `publish_wheel.yml` so wheel builds run on every commit to `main`, catching build regressions early.
- Keeps the actual PyPI publish step gated on `workflow_dispatch` only, so automatic pushes build but do not publish.
- Fixes the `ref` parameter to use the triggering commit ref for push events (previously only used `inputs.ref` which is only set for manual runs).
