# Enable automatic wheel building on every push to main
## TL;DR
- Added `push: branches: [main]` trigger to `publish_wheel.yml` so wheel builds run on every commit to `main`, not only on manual dispatch.
- Fixed checkout `ref` to use a ternary (`inputs.branch` for manual runs, `github.ref` otherwise) in both build jobs, ensuring correct branch resolution regardless of trigger type.
- Publish step remains gated behind `if: github.event_name == 'workflow_dispatch'`, so automatic builds produce artifacts but never publish to PyPI.
