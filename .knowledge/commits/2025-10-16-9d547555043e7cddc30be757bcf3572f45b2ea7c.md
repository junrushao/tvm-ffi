# Enable wheel build CI on every main commit, guard publish to manual-only
## TL;DR
- Add `push` trigger on `main` to `publish_wheel.yml` so wheel builds run on every commit to main, not only on manual dispatch.
- Fix the `ref` parameter in both build and test checkout steps to use `github.ref` for push-triggered runs and `inputs.branch` for manual runs.
- Guard the PyPI publish job with `if: github.event_name == 'workflow_dispatch'` so automatic builds never publish.
