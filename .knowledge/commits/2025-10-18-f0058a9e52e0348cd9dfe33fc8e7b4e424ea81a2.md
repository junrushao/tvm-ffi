# Add C ABI version query API (TVMFFIGetVersion) and version macros
## TL;DR
- Adds `TVMFFIVersion` struct and `TVMFFIGetVersion()` function to `include/tvm/ffi/c_api.h` for runtime ABI version detection.
- Adds compile-time version macros `TVM_FFI_VERSION_MAJOR/MINOR/PATCH` (initially 0.1.0).
- Documents RFC-stage versioning scheme in README: `0.X.Y` where X = ABI-breaking, Y = other.

## Key Exports

**Macros (`include/tvm/ffi/c_api.h`):**

| Macro | Value |
|-------|-------|
| `TVM_FFI_VERSION_MAJOR` | 0 |
| `TVM_FFI_VERSION_MINOR` | 1 |
| `TVM_FFI_VERSION_PATCH` | 0 |

**Types (`include/tvm/ffi/c_api.h`):**

```c
typedef struct {
  uint32_t major;
  uint32_t minor;
  uint32_t patch;
} TVMFFIVersion;
```

**Functions (`include/tvm/ffi/c_api.h`, implemented in `src/ffi/object.cc`):**

```c
// Always stable across all versions of the C ABI.
TVM_FFI_DLL void TVMFFIGetVersion(TVMFFIVersion* out_version);
```

## Impact
- API: New C ABI function `TVMFFIGetVersion` and struct `TVMFFIVersion` added. Purely additive, no breakage.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **C ABI layer** (`0001-c-abi-layer.md`): Extends the stable C ABI surface in `c_api.h`.

Design elements this commit produces:
- **Version query protocol**: `TVMFFIGetVersion` enables runtime ABI version detection from any language binding. The function itself is guaranteed stable — a fixed entry point for compatibility negotiation.
- **RFC-stage versioning convention**: `0.X.Y` where X bumps = ABI-breaking changes.

## Usage Examples
From `tests/cpp/test_base.cc`:
```c
TVMFFIVersion version;
TVMFFIGetVersion(&version);
// version.major == TVM_FFI_VERSION_MAJOR (0)
// version.minor == TVM_FFI_VERSION_MINOR (1)
// version.patch == TVM_FFI_VERSION_PATCH (0)
```
