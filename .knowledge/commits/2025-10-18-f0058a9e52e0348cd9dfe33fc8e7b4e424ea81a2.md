# Add version query API with compile-time macros and runtime getter
## TL;DR
- Adds compile-time version macros (`TVM_FFI_VERSION_MAJOR/MINOR/PATCH`) and a runtime `TVMFFIGetVersion` C API function to `c_api.h`, enabling libraries to query the linked FFI version.
- Introduces `TVMFFIVersion` struct (3x `uint32_t`) as the version return type.
- Documents RFC-stage versioning policy (`0.X.Y`) in README with planned transition to semantic versioning.

## Usage Examples

**Context**: Querying the linked FFI library version at runtime from C code.
```c
#include <tvm/ffi/c_api.h>
#include <stdio.h>

// Runtime version query
TVMFFIVersion version;
TVMFFIGetVersion(&version);
printf("TVM FFI version: %u.%u.%u\n", version.major, version.minor, version.patch);

// Compile-time version check
#if TVM_FFI_VERSION_MAJOR == 0
  // RFC stage: 0.X.Y versioning
#endif

// Runtime vs compile-time mismatch detection
if (version.major != TVM_FFI_VERSION_MAJOR ||
    version.minor != TVM_FFI_VERSION_MINOR) {
  fprintf(stderr, "Warning: header/library version mismatch\n");
}
```
