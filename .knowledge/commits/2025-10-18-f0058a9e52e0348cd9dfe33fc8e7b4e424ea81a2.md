# Add TVMFFIGetVersion C ABI function and compile-time version macros to c_api.h

## TL;DR
- Adds three compile-time macros: `TVM_FFI_VERSION_MAJOR=0`, `TVM_FFI_VERSION_MINOR=1`, `TVM_FFI_VERSION_PATCH=0` to `include/tvm/ffi/c_api.h`.
- Adds `TVMFFIVersion` struct (`{uint32_t major, minor, patch}`) and `TVMFFIGetVersion(TVMFFIVersion*)` exported C ABI function.
- `src/ffi/object.cc` implements `TVMFFIGetVersion` filling the struct from the compile-time macros.
- `tests/cpp/test_base.cc` (new file) verifies the runtime values match the macros.
- README updated with versioning policy: `0.X.Y` during RFC stage, then semantic versioning.

## Usage Examples

```c
// C usage: check library version at load time
#include <tvm/ffi/c_api.h>

TVMFFIVersion version;
TVMFFIGetVersion(&version);
assert(version.major == TVM_FFI_VERSION_MAJOR);
assert(version.minor == TVM_FFI_VERSION_MINOR);
```
