# Add version query API (TVMFFIGetVersion) to the C ABI
## TL;DR
- Introduces `TVMFFIGetVersion` C ABI function and `TVMFFIVersion` struct, plus compile-time version macros (`TVM_FFI_VERSION_MAJOR/MINOR/PATCH`), enabling libraries to query the linked libtvm_ffi version at runtime.
- Adds a GoogleTest (`tests/cpp/test_base.cc`) verifying the runtime version matches the compile-time macros.
- Adds a "Status and Release Versioning" section to README.md documenting the RFC-stage `0.X.Y` versioning scheme.

## Key Exports

**Macros**:
- `TVM_FFI_VERSION_MAJOR` -- expands to `0`. Compile-time major version.
- `TVM_FFI_VERSION_MINOR` -- expands to `1`. Compile-time minor version.
- `TVM_FFI_VERSION_PATCH` -- expands to `0`. Compile-time patch version.

**Types/Classes**:
- `TVMFFIVersion` -- C struct with three `uint32_t` fields: `major`, `minor`, `patch`.

**Functions**:
- `TVM_FFI_DLL void TVMFFIGetVersion(TVMFFIVersion* out_version)` -- Fills `out_version` with the runtime library version. Declared as always stable across all C ABI versions.

## Impact
- API: New additive API (`TVMFFIGetVersion`, `TVMFFIVersion`). No existing callers affected.
- ABI: Additive only -- new struct and function appended; no existing struct layouts or signatures changed. Not ABI-breaking.
- Behavioral: None. No existing semantics changed.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- C ABI design (`.knowledge/designs/c-abi.md`): the new function follows established patterns (`TVM_FFI_DLL` export, placed in `c_api.h`, implemented in `src/ffi/object.cc`).
- `TVM_FFI_DLL` preprocessor macro for cross-platform symbol export.

Design elements this commit produces:
- **Version query API**: A new section in the C ABI for version introspection. `TVMFFIGetVersion` is explicitly documented as "always stable across all versions of the C ABI," making it the bootstrap entry point for future ABI negotiation.
- **Versioning scheme**: README documents the `0.X.Y` RFC-stage scheme (X = ABI-breaking, Y = other changes) and the intent to move to SemVer post-RFC.

## Usage Examples

Querying the TVM FFI version at runtime (C/C++):
```c
#include <tvm/ffi/c_api.h>

TVMFFIVersion version;
TVMFFIGetVersion(&version);
printf("TVM FFI v%u.%u.%u\n", version.major, version.minor, version.patch);

// Compile-time check against header version:
assert(version.major == TVM_FFI_VERSION_MAJOR);
assert(version.minor == TVM_FFI_VERSION_MINOR);
assert(version.patch == TVM_FFI_VERSION_PATCH);
```
