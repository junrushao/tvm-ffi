# Add version query API to the stable C ABI

## TL;DR
- Adds `TVMFFIVersion` struct and `TVMFFIGetVersion` C ABI function, enabling libraries to query the linked `libtvm_ffi` version at runtime.
- Defines compile-time macros `TVM_FFI_VERSION_MAJOR` / `MINOR` / `PATCH` (initial value 0.1.0).
- Documents the RFC-stage versioning scheme in README: `0.X.Y` where `X` bumps indicate ABI-breaking changes.

## Impact
- API: Additive only -- new struct `TVMFFIVersion` and function `TVMFFIGetVersion` in `c_api.h`. No existing callers affected.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- C ABI stable function convention (`TVM_FFI_DLL`, `extern "C"`) from `.knowledge/designs/0001-c-abi.md`
- Section-comment organization pattern in `c_api.h` (adds new "Section: Version API")

Design elements this commit produces:
- **Version query protocol**: compile-time macros + runtime `TVMFFIGetVersion` enabling version mismatch detection between headers and linked library.
- **Versioning scheme**: RFC-stage `0.X.Y` convention where `X` = ABI-breaking, `Y` = other changes. Planned transition to semver post-RFC.

## Usage Examples

**Context**: A language binding or plugin verifies it is linked against a compatible `libtvm_ffi`.

```c
// Compile-time vs runtime version check
TVMFFIVersion version;
TVMFFIGetVersion(&version);
if (version.major != TVM_FFI_VERSION_MAJOR ||
    version.minor != TVM_FFI_VERSION_MINOR) {
    // Header/library mismatch -- abort or warn
    fprintf(stderr, "Version mismatch: header %d.%d.%d vs lib %u.%u.%u\n",
            TVM_FFI_VERSION_MAJOR, TVM_FFI_VERSION_MINOR, TVM_FFI_VERSION_PATCH,
            version.major, version.minor, version.patch);
}
```
