## Usage Examples
The `tests/cpp/test_example.cc` file is itself a comprehensive usage catalog. Key patterns:

```cpp
// Object definition + type erasure round-trip
MyIntPair pair(100, 200);
ffi::Any any = pair;
MyIntPair pair2 = any.cast<MyIntPair>();

// Function creation (typed lambda)
ffi::Function fadd1 = ffi::Function::FromTyped([](int a) -> int { return a + 1; });
int b = fadd1(1).cast<int>();

// Global function registration via reflection
refl::GlobalDef().def("xyz.add1", [](int a) -> int { return a + 1; });
ffi::Function f = ffi::Function::GetGlobalRequired("xyz.add1");

// Reflection-based object registration (from testing.cc)
refl::ObjectDef<TestIntPairObj>()
    .def_ro("a", &TestIntPairObj::a)
    .def_ro("b", &TestIntPairObj::b)
    .def_static("__create__", [](int64_t a, int64_t b) -> TestIntPair { ... });
```
