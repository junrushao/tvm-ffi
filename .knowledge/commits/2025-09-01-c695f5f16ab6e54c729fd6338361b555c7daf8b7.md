## Usage Examples

C++ guide example (from `docs/guides/cpp_guide.md` / `tests/cpp/test_example.cc`):

```cpp
// Any/AnyView usage
ffi::Any int_value = 42;
ffi::AnyView view = int_value;
int extracted = view.cast<int>();                   // strict, throws on mismatch
std::optional<int> maybe = view.as<int>();          // non-coercing optional
std::optional<int> coerced = view.try_cast<int>();  // coercing optional

// Function creation
ffi::Function fadd1 = ffi::Function::FromTyped([](const int a) -> int { return a + 1; });
int b = fadd1(1).cast<int>();  // b == 2

// Object + reflection registration (TestIntPair example)
// C++: TVM_FFI_STATIC_INIT_BLOCK({ ObjectDef<TestIntPairObj>().def_ro("a", ...).def_ro("b", ...) })
// Python: obj = tvm_ffi.get_global_func("testing.TestIntPair.__create__")(3, 4)
//         obj.a  # => 3
```

Extension package usage (from `docs/guides/packaging.md`):

```python
# my_ffi_extension/base.py — load shared library
_LIB = tvm_ffi.load_module("my_ffi_extension.so")

# my_ffi_extension/_ffi_api.py — map C++ globals into Python namespace
tvm_ffi._init_api("my_ffi_extension", __name__)

# user code
import my_ffi_extension
my_ffi_extension.add_one(x, y)
```
