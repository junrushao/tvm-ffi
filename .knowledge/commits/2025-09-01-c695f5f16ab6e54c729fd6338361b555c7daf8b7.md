# Initial Sphinx docs scaffolding with example renames and test_example.cc
## TL;DR
- Adds the entire `docs/` directory: Sphinx config (`conf.py`, `Makefile`, `index.rst`, `requirements.txt`), concept doc (`abi_overview.md`), getting-started guides (`install.md`, `quick_start.md`), and usage guides (`cpp_guide.md`, `python_guide.md`, `packaging.md`).
- Renames the packaging example from `tvm_ffi_extension` to `my_ffi_extension` across CMake, pyproject.toml, Python source, and C++ namespace.
- Adds `tests/cpp/test_example.cc` (289 lines of GoogleTest examples covering Any, Function, NDArray, String, Array, Tuple, Map, Optional, Variant, and Object) and a `TestIntPair` reflection-registered test object in `src/ffi/extra/testing.cc`.
- Moves `examples/quick_start/get_started/` one level up to `examples/quick_start/`.

## Key Exports

**Types/Classes** (C++, in `src/ffi/extra/testing.cc`):
- `TestIntPairObj : Object` -- fields: `int64_t a`, `int64_t b`. Type key: `"testing.TestIntPair"`. Reflection-registered with read-only fields `a`, `b` and static `__create__(int64_t, int64_t) -> TestIntPair`.
- `TestIntPair : ObjectRef` -- ref wrapper for `TestIntPairObj`. Constructor: `TestIntPair(int64_t a, int64_t b)`.

**Types/Classes** (C++, in `tests/cpp/test_example.cc`, test-only):
- `MyIntPairObj : Object` -- same pattern as TestIntPairObj but with type key `"example.MyIntPair"`. Not reflection-registered.
- `MyIntPair : ObjectRef` -- ref wrapper.

**Documentation structure** (new):
- `docs/index.rst` -- Sphinx toctree root: Get Started (install, quick_start), Guides (packaging, cpp_guide, python_guide), Concepts (abi_overview).
- `docs/conf.py` -- Sphinx config using `sphinx_book_theme`, MyST, nbsphinx, autodoc, mermaid, intersphinx.
- `docs/concepts/abi_overview.md` -- comprehensive ABI design doc covering TVMFFIAny, TVMFFIObject, AnyView/Any, Function calling convention, Error handling, String/Bytes.

## Usage Examples

TestIntPair object creation and reflection (from `src/ffi/extra/testing.cc`):
```cpp
// C++ side: object is reflection-registered
// Python side (via reflection):
//   pair = tvm_ffi.testing.TestIntPair(a=1, b=2)
//   assert pair.a == 1
//   assert pair.b == 2

// C++ direct usage:
TestIntPair pair(100, 200);
assert(pair->a == 100);
assert(pair->b == 200);
```

GoogleTest examples demonstrating core FFI types (from `tests/cpp/test_example.cc`):
```cpp
// Any/AnyView
ffi::Any int_value = 42;
ffi::AnyView view = int_value;
int extracted = view.cast<int>();  // 42

// Function from typed lambda
ffi::Function fadd1 = ffi::Function::FromTyped([](int a) -> int { return a + 1; });
int b = fadd1(1).cast<int>();  // 2

// Global function registry
ffi::reflection::GlobalDef().def("xyz.add1", [](int a) -> int { return a + 1; });
ffi::Function f = ffi::Function::GetGlobalRequired("xyz.add1");
```
