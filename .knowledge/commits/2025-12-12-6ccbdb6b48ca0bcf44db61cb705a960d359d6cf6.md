# Break CPython reference cycle in error-handling path to enable prompt GC of frame locals

## TL;DR
- `TracebackManager.append_traceback` was binding the synthetic `frame` as a local variable, which got captured in the CPython `f_back` chain and formed a reference cycle with the traceback object. Fixed by delegating `TracebackType` construction to a nested helper so `frame` is never a named local in `append_traceback`.
- `_with_append_backtrace` left `py_error` and `tb` in its frame's locals after returning; since `py_error.__traceback__` chains through those frames back to `_with_append_backtrace` itself (via `f_back`), a cycle formed keeping all frame locals (including GPU tensors) alive until the cyclic GC ran. Fixed with `try/finally: del py_error, tb`.
- Added `test_error_no_cyclic_reference` which disables `gc`, triggers a C++ `KeyError`, and asserts via `weakref` that objects in the calling frame are immediately freed.

class TracebackManager:
    """Manages synthetic CPython frames for C++ backtrace injection into Python tracebacks."""

    def append_traceback(
        self,
        tb: types.TracebackType | None,
        filename: str,
        lineno: int,
        func: str,
    ) -> types.TracebackType:
        # Old (buggy): bound `frame` as local -> frame escaped into f_back chain
        #   frame = self._create_frame(filename, lineno, func)
        #   return types.TracebackType(tb, frame, frame.f_lasti, lineno)
        #
        # New (fixed): frame is an argument to a nested call, not a named local here
        def create(
            tb: types.TracebackType | None, frame: types.FrameType, lineno: int
        ) -> types.TracebackType:
            return types.TracebackType(tb, frame, frame.f_lasti, lineno)
        return create(tb, self._create_frame(filename, lineno, func), lineno)
        # Invariant: no reference to `frame` remains in append_traceback's locals after return
        # Interacts with: _with_append_backtrace (caller), _create_frame (creates synthetic frame)


def _with_append_backtrace(py_error: BaseException, backtrace: str) -> BaseException:
    """Append C++ backtrace frames to a Python exception's traceback. Cycle-free."""
    tb = py_error.__traceback__
    try:
        for filename, lineno, func in _parse_backtrace(backtrace):
            tb = _TRACEBACK_MANAGER.append_traceback(tb, filename, lineno, func)
        return py_error.with_traceback(tb)
    finally:
        del py_error, tb
        # Invariant: py_error and tb NOT in locals when frame is destroyed -> no cycle
        # Invariant: finally executes after the return expression is evaluated, not before
        # Interacts with: Python C++ safe_call boundary (caller), TracebackManager.append_traceback
        # Extension: any additional locals added here must also be del'd in finally

## Impact
- API: None — `_with_append_backtrace` and `TracebackManager.append_traceback` are internal; signatures unchanged.
- Behavioral: GPU tensors and other frame locals created in callers of FFI functions that raise C++ errors are now freed immediately (refcount GC) rather than requiring a cyclic GC pass. Observable in memory-constrained training loops.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- Python-side error protocol: `_with_append_backtrace`, `TracebackManager`, `_parse_backtrace`, `_TRACEBACK_MANAGER` in `python/tvm_ffi/error.py`; sits in the error propagation pipeline described in [0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md)

Design elements this commit produces:
- **Cycle-free exception augmentation invariant**: `_with_append_backtrace` must not retain `py_error` or `tb` (or any reference to a `TracebackType` or `BaseException`) in its frame locals at return time. This invariant is now enforced via `del` in a `finally` block. Not previously documented.
- **Nested-function frame isolation pattern**: `TracebackManager.append_traceback` uses a nested function to prevent synthetic `FrameType` objects from escaping as named locals — a pattern applicable to any code that creates CPython frame objects.

## Usage Examples

**Before (cycle forms)**:
```python
# _with_append_backtrace frame holds py_error and tb in locals when it returns.
# py_error.__traceback__ -> tb (TracebackType) -> tb_frame (synthetic frame)
# synthetic frame f_back -> _with_append_backtrace frame (which holds py_error)
# => cycle: _with_append_backtrace.locals -> py_error -> tb -> frame -> f_back -> _with_append_backtrace.locals
# GPU tensors in outer frames stay alive until cyclic GC runs.
```

**After (cycle-free)**:
```python
# _with_append_backtrace uses try/finally: del py_error, tb
# When the function returns, neither py_error nor tb are in its locals.
# CPython refcount GC can immediately collect the exception + traceback chain.

# Test pattern (test_error_no_cyclic_reference):
gc.disable()
def trigger():
    obj = SampleObject()
    tvm_ffi.Map({})["nonexistent_key"]  # raises C++ KeyError, goes through _with_append_backtrace
    return weakref.ref(obj)

wref = trigger()
assert wref() is None  # obj freed immediately, not held by cycle
gc.enable()
```
