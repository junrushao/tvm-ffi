# Remove reference cycle in error handling for faster GC of tensors
## TL;DR
- Fixes reference cycles in `python/tvm_ffi/error.py` that were keeping intermediate tensors alive unnecessarily. Uses `try...finally...del` to break the cycle between `frame`, `py_error`, and `tb` variables.
- Critical for training workloads where tensor memory needs prompt deallocation via reference counting (avoiding cyclic GC).
- Adds test coverage verifying no reference cycles remain after error handling.
