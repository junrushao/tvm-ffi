# Break reference cycles in error handling to enable immediate tensor GC
## TL;DR
- Eliminates reference cycles in `_with_append_backtrace()` and `TracebackManager.append_traceback()` that prevented CPython's reference-counting GC from immediately freeing tensors in error-handling call chains.
- `_with_append_backtrace()` now uses `try...finally: del py_error, tb` to explicitly break the cycle between the exception, its traceback, and the stack frames.
- `append_traceback()` uses a nested `create()` function to avoid binding the frame object as a local variable, preventing the frame-traceback cycle.

## Key Exports

**Modified method** (`TracebackManager.append_traceback`):
```python
def append_traceback(self, tb: TracebackType | None, filename: str, lineno: int, func: str) -> TracebackType:
    # Now uses nested create() function to avoid holding frame in locals
    def create(tb, frame, lineno) -> TracebackType:
        return types.TracebackType(tb, frame, frame.f_lasti, lineno)
    return create(tb, self._create_frame(filename, lineno, func), lineno)
```

**Modified function** (`_with_append_backtrace`):
```python
def _with_append_backtrace(py_error: BaseException, backtrace: str) -> BaseException:
    tb = py_error.__traceback__
    try:
        for filename, lineno, func in _parse_backtrace(backtrace):
            tb = _TRACEBACK_MANAGER.append_traceback(tb, filename, lineno, func)
        return py_error.with_traceback(tb)
    finally:
        del py_error, tb  # Break cycle: exception <-> traceback <-> frame
```

## Impact
- API: none (internal functions, signatures unchanged)
- Behavioral: Objects in the caller's frame (e.g., tensors) are freed immediately by CPython refcounting when their scope exits, rather than waiting for the cyclic GC collector. This reduces GPU memory pressure during training.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Test from the commit verifying no cycle:
```python
import gc, weakref
import tvm_ffi

gc.disable()
class Probe: ...

def trigger_cpp_error():
    try:
        tvm_ffi.Map(dict())["nonexistent"]
    except KeyError:
        pass

def may_create_cycle() -> weakref.ReferenceType:
    obj = Probe()
    trigger_cpp_error()
    return weakref.ref(obj)

wref = may_create_cycle()
assert wref() is None  # obj freed immediately, no cycle
gc.enable()
```
