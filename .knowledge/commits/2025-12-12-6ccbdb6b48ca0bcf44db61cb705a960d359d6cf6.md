# Remove reference cycles in Python error traceback reconstruction for faster GC

## TL;DR
- `TracebackManager.append_traceback` no longer stores the synthesized frame as a local variable; a nested `create()` function keeps the frame as a temporary, preventing CPython's frame locals from closing a reference cycle through `f_back`.
- `_with_append_backtrace` wraps its body in `try...finally: del py_error, tb` to eagerly clear the locals that form the other half of the cycle (exception -> traceback -> frame -> `f_back` -> caller frame -> locals -> exception).
- Together, these changes ensure tensors and other objects held by caller frames are freed immediately by CPython's deterministic refcounting rather than waiting for the cyclic GC collector.

## Impact
- API: None -- internal implementation only; no signature or behavioral change to callers.
- Behavioral: Objects (especially GPU tensors) held by caller frames are freed deterministically by CPython refcounting instead of being deferred to the cyclic GC collector. This reduces peak memory usage during training loops that encounter caught exceptions (e.g., `Map.get` with missing keys).
- Flags/config: None.
- Data formats/schemas: None.

Design elements this commit produces:
- **Reference-cycle-free traceback reconstruction pattern**: two techniques for breaking frame-local reference cycles in Python error handling:
  1. Nested function to avoid binding temporary objects to outer frame locals
  2. `try...finally: del` to eagerly clear exception/traceback locals

## Usage Examples

**Before** (creates reference cycle, delays GC):
```python
# In TracebackManager.append_traceback (old):
def append_traceback(self, tb, filename, lineno, func):
    frame = self._create_frame(filename, lineno, func)  # frame stored as local
    return types.TracebackType(tb, frame, frame.f_lasti, lineno)
    # BUG: frame.f_back -> append_traceback's own frame -> locals dict -> frame (cycle)

# In _with_append_backtrace (old):
def _with_append_backtrace(py_error, backtrace):
    tb = py_error.__traceback__
    for filename, lineno, func in _parse_backtrace(backtrace):
        tb = _TRACEBACK_MANAGER.append_traceback(tb, filename, lineno, func)
    return py_error.with_traceback(tb)
    # BUG: py_error and tb remain in frame locals, closing cycle through traceback chain
```

**After** (no reference cycle, immediate GC):
```python
# In TracebackManager.append_traceback (new):
def append_traceback(self, tb, filename, lineno, func):
    def create(tb, frame, lineno):
        return types.TracebackType(tb, frame, frame.f_lasti, lineno)
    return create(tb, self._create_frame(filename, lineno, func), lineno)
    # frame is a parameter of create(), not a local of append_traceback

# In _with_append_backtrace (new):
def _with_append_backtrace(py_error, backtrace):
    tb = py_error.__traceback__
    try:
        for filename, lineno, func in _parse_backtrace(backtrace):
            tb = _TRACEBACK_MANAGER.append_traceback(tb, filename, lineno, func)
        return py_error.with_traceback(tb)
    finally:
        del py_error, tb  # break cycle before frame is finalized
```
