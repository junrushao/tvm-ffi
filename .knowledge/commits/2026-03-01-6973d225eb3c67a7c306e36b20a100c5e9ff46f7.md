# Wire __init__ from C++ reflection in register_object and stubgen

## TL;DR
- Wires `__init__` from C++ reflection metadata in both `register_object` (runtime) and `tvm-ffi-stubgen` (static stubs), so registered classes with `refl::init()` work out of the box without requiring `@c_class`.
- Adds `InitFieldInfo` / `ObjectInfo.gen_init()` in `stub/utils.py` for generating typed `__init__` stubs from reflection metadata.
- `_install_init` in `registry.py` auto-wires `__init__` -> `__ffi_init__` for any class whose C++ `ObjectDef` registered `refl::init()`.

## Key Exports

**`stub/utils.py`:**
- `InitFieldInfo` -- per-field init metadata (name, type, kw_only, has_default)
- `ObjectInfo.gen_init()` -- generates `__init__` stub code from reflection

**`registry.py`:**
- `_install_init(cls, enabled=True)` -- wires `__init__` -> `__ffi_init__` at registration time

## Impact
- API: `register_object`-decorated classes now auto-get `__init__` if C++ reflection has `refl::init()`. No change for classes without reflection init.
- Behavioral: Stubgen now emits typed `__init__` stubs for reflected classes.
- Flags/config: none
- Data formats/schemas: none
