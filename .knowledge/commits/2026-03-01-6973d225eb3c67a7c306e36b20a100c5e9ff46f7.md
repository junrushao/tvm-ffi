# Wire __init__ from C++ reflection in register_object and stubgen

## TL;DR
- `register_object` now calls `_install_init(cls, enabled=True)` after `_add_class_attrs`, so all registered classes with `refl::init()` get a proper `__init__` without needing `@c_class`.
- `stub/utils.py` gains `InitFieldInfo` and `ObjectInfo.gen_init()` for generating typed `__init__` stubs from reflection metadata (parent chain traversal, c_init/c_kw_only/c_has_default flags).
- `_install_init` simplified: the `enabled=False` path now only raises a generic TypeError guard; the detailed "no __ffi_init__" error is removed.

## Impact
- API: `register_object` now auto-installs `__init__` for all reflected types (additive).
- Behavioral: Testing classes renamed from `TestCxxAutoInit*` to `TestAutoInit*` (test fixture rename). `_install_init` no longer warns about missing `refl::init()`.
- Flags/config: None.
- Data formats/schemas: None.
