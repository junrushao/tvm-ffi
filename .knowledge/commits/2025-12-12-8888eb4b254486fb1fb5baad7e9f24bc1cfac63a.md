# Add strided view APIs for Tensor, TensorView, and FromNDAllocStrided
## TL;DR
- Adds `Tensor::as_strided(shape, strides, element_offset)` and `TensorView::as_strided(shape, strides, element_offset)` for creating strided views with optional element offset.
- Adds `Tensor::FromNDAllocStrided(alloc, shape, strides, dtype, device)` for creating strided tensors via custom allocators.
- Adds C ABI function `TVMFFITensorCreateUnsafeView` that creates a view tensor sharing source data with custom metadata.

## Key Exports

**C API** (new, `include/tvm/ffi/c_api.h`):
```c
TVM_FFI_DLL int TVMFFITensorCreateUnsafeView(
    TVMFFIObjectHandle source,    // source tensor whose data is shared
    const DLTensor* prototype,    // metadata (shape, strides, dtype, device, byte_offset)
    TVMFFIObjectHandle* out       // output Tensor handle
);
```

**C++ methods** (new, `include/tvm/ffi/container/tensor.h`):

```cpp
// Tensor (owning ref) -- creates a new Tensor object that holds a ref to source
Tensor Tensor::as_strided(
    ShapeView shape, ShapeView strides,
    std::optional<int64_t> element_offset = std::nullopt) const;

// TensorView (non-owning) -- creates a lightweight view (caller must keep shape/strides alive)
TensorView TensorView::as_strided(
    ShapeView shape, ShapeView strides,
    std::optional<int64_t> element_offset = std::nullopt) const;

// Static factory: allocate strided tensor via custom allocator
template <typename TNDAlloc, typename... ExtraArgs>
static Tensor Tensor::FromNDAllocStrided(
    TNDAlloc alloc, ShapeView shape, ShapeView strides,
    DLDataType dtype, DLDevice device, ExtraArgs&&... extra_args);
```

**Behavioral note**: For direct-address devices (CPU), `element_offset` is folded into `data` pointer directly and `byte_offset` stays 0. For non-direct-address devices, `byte_offset` is incremented.

## Impact
- API: New C ABI function `TVMFFITensorCreateUnsafeView`. New C++ methods on `Tensor` and `TensorView`. No breaking changes.
- Behavioral: none (new APIs only)
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Tensor/TensorObj** (`.knowledge/designs/0008-containers.md`) -- `TensorObj`, `TensorObjFromNDAlloc`, `TensorView`, `make_inplace_array_object`
- **C ABI layer** (`.knowledge/designs/0001-c-abi-layer.md`) -- `TVM_FFI_SAFE_CALL_BEGIN`/`END`, DLTensor struct
- **`IsDirectAddressDevice`** -- determines whether byte_offset can be folded into data pointer

Design elements this commit produces:
- **Strided view creation pattern** -- `as_strided` on both `Tensor` (owns ref to source, copies shape/strides into new TensorObj) and `TensorView` (borrows shape/strides, caller manages lifetime). The `Tensor` version is safe; the `TensorView` version requires the caller to keep shape/strides arrays alive.
- **`TVMFFITensorCreateUnsafeView`** -- C ABI entry point for creating a view that shares source data. Uses a `ViewNDAlloc` that captures an `ObjectPtr` to the source tensor to keep it alive.
- **`FromNDAllocStrided`** -- overload that accepts explicit strides alongside shape. Uses a new `TensorObjFromNDAlloc` constructor that takes a `DLTensor` prototype.

## Usage Examples

Creating a column-major strided view from a row-major tensor:
```cpp
#include <tvm/ffi/container/tensor.h>
using namespace tvm::ffi;

Tensor tensor = Tensor::FromNDAlloc(CPUNDAlloc(), {2, 3}, {kDLFloat, 32, 1}, {kDLCPU, 0});
// tensor is row-major: shape=[2,3], strides=[3,1]

// Create a transposed view: shape=[3,2], strides=[1,3]
Tensor transposed = tensor.as_strided({3, 2}, {1, 3});

// Create a view with element offset (skip first element)
Tensor offset_view = tensor.as_strided({2, 2}, {3, 1}, /*element_offset=*/1);
```
