# Add strided view APIs to Tensor and TensorView, plus TVMFFITensorCreateUnsafeView C ABI entry

## TL;DR
- Adds `Tensor::as_strided(shape, strides, element_offset)` and `TensorView::as_strided(...)` that return a new view sharing the source tensor's data buffer, with custom shape/strides/offset.
- Adds `Tensor::FromNDAllocStrided(alloc, shape, strides, dtype, device)` to allocate a strided tensor directly via an NDAllocator.
- Adds `TVMFFITensorCreateUnsafeView` to `c_api.h` + `tensor.cc` as the C ABI entry point for creating a view; `Tensor::as_strided` calls it internally, keeping the source tensor alive via `ViewNDAlloc`.

## Impact
- API: Additive — three new public symbols (`TVMFFITensorCreateUnsafeView`, `Tensor::as_strided`, `Tensor::FromNDAllocStrided`, `TensorView::as_strided`). No existing signatures changed.
- Behavioral: Minor — `TensorView::dim()`, `sizes()`, `is_contiguous()` had `inline` removed (no semantic change).
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- `Tensor` / `TensorObj` / `TensorObjFromNDAlloc` — extends the NDAlloc factory pattern with a prototype-taking constructor (`0007-containers`)
- `TensorView` — adds `as_strided` view creation method (`0007-containers`)
- `ShapeView` — used as shape and strides parameters throughout (`0007-containers`)
- `make_inplace_array_object<T, int64_t>(ndim*2, ...)` — tail-allocation pattern for shape+strides (`0007-containers`)
- `IsDirectAddressDevice` — used to decide whether to fold `byte_offset` into data pointer (`0007-containers`)
- `GetDataSize(size_t nelems, DLDataType)` — converts element_offset to byte_offset (`0007-containers`)
- `TVMFFISafeCall` / `TVM_FFI_SAFE_CALL_BEGIN/END` — C ABI error propagation (`0001-c-abi`)
- `ObjectUnsafe::ObjectPtrFromUnowned` / `MoveObjectRefToTVMFFIObjectPtr` — raw ObjectPtr manipulation (`0002-object-system`)

Design elements this commit produces:
- `TVMFFITensorCreateUnsafeView` — new C ABI entry point for creating a shared-memory view of a Tensor. Caller must ensure prototype data pointer is within source tensor's buffer. Exposes `ViewNDAlloc` pattern (source-retaining allocator whose `FreeData` is a no-op).
- `Tensor::as_strided` — C++ convenience wrapper around `TVMFFITensorCreateUnsafeView`; folds `element_offset` into `byte_offset` / data ptr depending on device type.
- `Tensor::FromNDAllocStrided` — factory for strides-aware NDAlloc tensors (column-major etc.).
- `TensorView::as_strided` — lightweight non-owning strided view (no heap, no ref-count).
- `TensorObjFromNDAlloc` prototype constructor — internal constructor that accepts a pre-built `DLTensor` prototype and deep-copies shape/strides into tail allocation.

## Usage Examples

**Creating an owning strided view of a CPU Tensor:**
```cpp
// Source: tests/cpp/test_tensor.cc — TEST(Tensor, AsStrided)
Tensor tensor = Tensor::FromNDAlloc(CPUNDAlloc(), Shape({2, 3}), float32, cpu);
// fill data[0..5] = {0,1,2,3,4,5}

Shape new_shape = {3, 2};
Shape new_strides = {1, 3};
Tensor strided_view = tensor.as_strided(new_shape, new_strides);
// strided_view shares tensor's data buffer; data_ptr() == tensor.data_ptr()
// byte_offset() == 0 (CPU is direct-address; offset folded into ptr)

// With element offset (skips first element):
Tensor offset_view = tensor.as_strided({2, 2}, {3, 1}, /*element_offset=*/1);
// offset_view.data_ptr() == tensor.data_ptr() + 4  (1 float32 element = 4 bytes)
```

**Creating a non-owning TensorView strided view:**
```cpp
// Source: tests/cpp/test_tensor.cc — TEST(Tensor, TensorViewAsStrided)
TensorView tv = tensor;
Shape s = {3, 2}, st = {1, 3};
TensorView strided = tv.as_strided(s, st);
// CAUTION: s and st must outlive `strided`
```

**Allocating a column-major (strided) tensor directly:**
```cpp
// Source: tests/cpp/test_tensor.cc — Tensor::Basic test (EmptyStrided helper)
Tensor col_major = Tensor::FromNDAllocStrided(
    CPUNDAlloc(), /*shape=*/{2, 3}, /*strides=*/{1, 2}, float32, cpu);
```
