# Add strided view and strided allocation APIs for Tensor and TensorView
## TL;DR
- Adds `Tensor::as_strided` and `TensorView::as_strided` methods to create strided views of existing tensors, with optional element offset. On direct-address devices (CPU, CUDA), the byte offset is folded into the data pointer.
- Adds `Tensor::FromNDAllocStrided` static factory to allocate a new tensor with explicit strides (e.g., column-major layout).
- Adds `TVMFFITensorCreateUnsafeView` C ABI function that creates a view sharing source tensor data with metadata copied from a prototype `DLTensor`.

## Impact
- API: Additive. Three new public methods (`Tensor::as_strided`, `TensorView::as_strided`, `Tensor::FromNDAllocStrided`) and one new C ABI function (`TVMFFITensorCreateUnsafeView`). No existing signatures changed.
- Behavioral: Minor const-correctness fix on `TensorView::dim()` (was non-const, now const). Removal of `inline` keyword on `TensorView::dim()`, `sizes()`, `is_contiguous()` (no behavioral change -- class members are implicitly inline).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `IsDirectAddressDevice` (0007-containers.md) -- used in both `Tensor::as_strided` and `TensorView::as_strided` to decide whether byte offset is folded into data pointer
- `GetDataSize(size_t, DLDataType)` (0007-containers.md) -- converts element offset to byte offset
- `make_inplace_array_object<T, int64_t>` (0002-object-system.md, ADR-0012) -- allocates tensor + tail int64 arrays in one allocation
- `TensorObjFromNDAlloc<TNDAlloc>` (0007-containers.md) -- extended with a new prototype-based constructor
- `ShapeView` (0007-containers.md) -- parameter type for shape/strides throughout

Design elements this commit produces:
- `TVMFFITensorCreateUnsafeView` -- new C ABI entry point for unsafe view creation
- `Tensor::as_strided` -- owning strided view factory on Tensor
- `TensorView::as_strided` -- non-owning strided view factory on TensorView
- `Tensor::FromNDAllocStrided` -- allocator-based strided tensor factory
- `TensorObjFromNDAlloc(alloc, prototype, extra_args...)` -- new constructor overload for strided allocation

## Usage Examples

**Creating a column-major tensor with `FromNDAllocStrided`:**
```cpp
// Allocate a 2x3 column-major tensor (strides {1, 2})
Tensor nd = Tensor::FromNDAllocStrided(
    CPUNDAlloc(), {2, 3}, {1, 2},
    DLDataType({kDLFloat, 32, 1}), DLDevice({kDLCPU, 0}));
// nd.shape() == {2, 3}, nd.strides() == {1, 2}
```

**Creating a strided view with element offset (`Tensor::as_strided`):**
```cpp
// Base tensor: shape [2, 3], row-major, data = [0, 1, 2, 3, 4, 5]
Tensor base = Empty({2, 3}, DLDataType({kDLFloat, 32, 1}), DLDevice({kDLCPU, 0}));
// Transpose-like view: shape [3, 2], strides [1, 3]
Tensor view = base.as_strided({3, 2}, {1, 3});
// view.data_ptr() == base.data_ptr(), view.byte_offset() == 0

// With element offset: skip 1 element (4 bytes for float32)
Tensor offset_view = base.as_strided({2, 2}, {3, 1}, /*element_offset=*/1);
// offset_view.data_ptr() == base.data_ptr() + 4 (CPU folds byte_offset into pointer)
```

**Non-owning `TensorView::as_strided` (caution: lifetime management):**
```cpp
TensorView tv = tensor;
Shape new_shape = {3, 2};     // must outlive strided_view
Shape new_strides = {1, 3};   // must outlive strided_view
TensorView strided_view = tv.as_strided(new_shape, new_strides);
```
