# Add strided view API for Tensor and TensorView

## TL;DR
- Adds `Tensor::as_strided()` and `TensorView::as_strided()` methods for creating non-contiguous views with custom shape, strides, and element offset.
- Adds `Tensor::FromNDAllocStrided()` static factory for allocating tensors with explicit strides (e.g., column-major layout).
- Adds `TVMFFITensorCreateUnsafeView` C ABI function that creates a view tensor sharing the source tensor's data, with metadata copied from a prototype DLTensor.

## Impact
- API: New public C ABI function `TVMFFITensorCreateUnsafeView` in `c_api.h`. New public C++ methods `Tensor::as_strided`, `TensorView::as_strided`, `Tensor::FromNDAllocStrided`.
- Behavioral: Minor cleanup -- removed redundant `inline` keyword from `TensorView::dim()`, `TensorView::sizes()`, `TensorView::is_contiguous()` (no semantic change).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:

- `TensorObjFromNDAlloc<TNDAlloc>` -- the templated tensor allocation pattern with inplace trailing int64 arrays
- `make_inplace_array_object` -- allocates object + trailing typed array in single allocation
- `IsDirectAddressDevice` -- determines whether byte_offset can be folded into data pointer
- `GetDataSize(num_elements, dtype)` -- computes byte size from element count and dtype
- `ShapeView` -- non-owning shape/stride view type
- `TVMFFIObject`/`ObjectPtr` -- ref-counted object system for retaining source tensor lifetime in view
- `TVM_FFI_SAFE_CALL_BEGIN/END` -- C ABI error-handling wrapper

Design elements this commit produces:
- `TVMFFITensorCreateUnsafeView` -- new C ABI entry for creating view tensors (public, in `c_api.h`)
- `Tensor::as_strided(shape, strides, element_offset)` -- owning strided view factory

- `Tensor::FromNDAllocStrided(alloc, shape, strides, dtype, device, ...)` -- strided tensor allocation factory
- `TensorObjFromNDAlloc` prototype-based constructor overload -- internal extension point for strided allocation
- `ViewNDAlloc` allocator pattern -- internal pattern for creating view tensors that retain the source

## Usage Examples

**Creating a strided view of an existing Tensor (owning)**:
```cpp
// Allocate a row-major [2,3] tensor: data = [0,1,2,3,4,5]
Tensor tensor = Tensor::FromNDAlloc(CPUNDAlloc(), {2, 3}, {kDLFloat, 32, 1}, {kDLCPU, 0});
float* data = reinterpret_cast<float*>(tensor.data_ptr());
for (int i = 0; i < 6; ++i) data[i] = static_cast<float>(i);

// Create a transposed view [3,2] with column-major strides {1,3}
Tensor view = tensor.as_strided({3, 2}, {1, 3});
// view shares tensor's data; view[0,0]=0, view[1,0]=1, view[0,1]=3

// Create a view with element offset (skip first element)
Tensor offset_view = tensor.as_strided({2, 2}, {3, 1}, /*element_offset=*/1);
// offset_view.data_ptr() == data + 1 (for CPU, byte_offset folded into pointer)
```

**Allocating a strided tensor directly**:
```cpp
// Column-major [2,3] tensor with strides {1,2}
Tensor col_major = Tensor::FromNDAllocStrided(
    CPUNDAlloc(), {2, 3}, {1, 2}, {kDLFloat, 32, 1}, {kDLCPU, 0});
```

**Non-owning TensorView as_strided (for kernel signatures)**:
```cpp
TensorView tv = tensor;
Shape new_shape = {3, 2};    // must outlive strided_tv
Shape new_strides = {1, 3};  // must outlive strided_tv
TensorView strided_tv = tv.as_strided(new_shape, new_strides);
```
