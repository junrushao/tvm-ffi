# Add API to create strided tensor views
## TL;DR
- Adds `Tensor::CreateView` and `Tensor::CreateStridedView` C++ APIs in `include/tvm/ffi/container/tensor.h` for creating strided tensor views with custom shape, strides, dtype, and byte offset.
- Adds new C API function `TVMFFITensorCreateView` in `c_api.h`.
- Adds implementation in `src/ffi/tensor.cc` (28 new lines).
- Comprehensive tests in `tests/cpp/test_tensor.cc` (169 new lines).
- Updates kernel library guide with strided view documentation.

## Impact
- API: New C++ `Tensor::CreateView`/`CreateStridedView` methods and C API `TVMFFITensorCreateView`
- Flags/config: None
