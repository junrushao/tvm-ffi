# Add inline C++ tests for torch DLPackExchangeAPI protocol and fix hardcoded __dlpack_version__

## TL;DR
- Adds `tests/python/test_dlpack_exchange_api.py` — a pytest module that exercises all five function pointers in `DLPackExchangeAPI` (`managed_tensor_allocator`, `managed_tensor_from_py_object_no_sync`, `managed_tensor_to_py_object_no_sync`, `dltensor_from_py_object_no_sync`, `current_work_stream`) via `torch.utils.cpp_extension.load_inline` to avoid GIL release issues from `THPVariable_Wrap`.
- Adds version assertion on the `DLPackExchangeAPI.header.version` fields (`major == DLPACK_MAJOR_VERSION`, `minor == DLPACK_MINOR_VERSION`), pinning the round-trip protocol contract.
- Fixes `__dlpack_version__` in `tensor.pxi`: was hardcoded `(1, 1)`, now derived from the actual header constants `(DLPACK_MAJOR_VERSION, DLPACK_MINOR_VERSION)`.

## Key Exports

None — this commit adds tests and a one-line bugfix; no new API surface is produced.

## Impact
- API: none
- Behavioral: `__dlpack_version__` in `tensor.pxi` is now driven by `DLPACK_MAJOR_VERSION`/`DLPACK_MINOR_VERSION` from `dlpack.h` rather than hardcoded `(1, 1)`. Downstream `__dlpack__` negotiation in `tensor.pxi` will reflect the actual vendored DLPack version.
- Flags/config: none
- Data formats/schemas: none

- `__dlpack_version__` module-level tuple in `tensor.pxi` (0007-containers via 0013-python-package): governs `max_version` negotiation in `__dlpack__`/`__dlpack_capsule__` protocol.

## Usage Examples

The test shows the complete validation pattern for `DLPackExchangeAPI`:

```python
# tests/python/test_dlpack_exchange_api.py

import tvm_ffi  # loads _optional_torch_c_dlpack which sets torch.Tensor.__c_dlpack_exchange_api__
import torch
from torch.utils import cpp_extension
from tvm_ffi import libinfo

api_ptr = torch.Tensor.__c_dlpack_exchange_api__  # int (C pointer)
tensor = torch.arange(24, dtype=torch.float32).reshape(2, 3, 4)

# Inline C++ test exercises managed_tensor_from_py_object_no_sync:
#   DLManagedTensorVersioned* t = nullptr;
#   api->managed_tensor_from_py_object_no_sync(py_obj, &t);
#   assert t->version.major == DLPACK_MAJOR_VERSION;
#   assert t->dl_tensor.ndim == 3;

mod = cpp_extension.load_inline(
    name="dlpack_test",
    cpp_sources=[source],          # see diff for full C++ test body
    functions=["test_dlpack_api"],
    extra_include_paths=libinfo.include_paths(),  # provides dlpack/dlpack.h
)
mod.test_dlpack_api(tensor, api_ptr, torch.cuda.is_available())
```

Note: `load_inline` is used instead of ctypes function pointers because `THPVariable_Wrap` requires the GIL to be held and must execute in the same C extension as the pybind11 runtime — a pattern incompatible with ctypes-level calls that may drop GIL.
