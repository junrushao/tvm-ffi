# Rename examples/packaging to examples/python_packaging and replace inline code with literalinclude directives
## TL;DR
- Renames `examples/packaging/` to `examples/python_packaging/` for clarity, updating CI workflow paths accordingly.
- Replaces inline code blocks in `docs/packaging/python_packaging.rst` with `literalinclude` directives that reference the actual example source files, adding marker comments (`[tvm_ffi_abi.begin]`/`[tvm_ffi_abi.end]` etc.) to the C++, CMake, and TOML sources.
- Strips the ~150-line epilog from the `tvm-ffi-stubgen` CLI help text, replacing it with a link to the published documentation (`DOC_URL` constant).

| Before | After |
|--------|-------|
| `examples/packaging/` | `examples/python_packaging/` |
| Inline C++/CMake/TOML blocks in RST | `literalinclude` directives with marker-based extraction |
| 150-line CLI epilog in `cli.py` | 3-line description + `DOC_URL` link |

## Key Exports
None -- chore/docs commit with no new public API surface.

## Impact
- API: None.
- Behavioral: None. The example extension functionality is unchanged; the C++ code was rewritten to be simpler (removed `TensorView` `AddOne`, removed `IntPair` ref wrapper class, simplified to scalar `AddOne`/`AddTwo`/`RaiseError` + reflection-only `IntPairObj`) but this is example code, not library API.
- Flags/config: CI workflow steps renamed from `example/packaging` to `example/python_packaging`.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- Packaging pattern ([0013-packaging.md](../designs/0013-packaging.md)): renames the example directory and updates all references.

- `tvm_ffi.stub.consts` module: extended with `DOC_URL` constant.

Design elements this commit produces:
- **Literalinclude marker convention**: C++, CMake, and TOML example files now use paired marker comments (e.g., `// [tvm_ffi_abi.begin]` / `// [tvm_ffi_abi.end]`) that Sphinx `literalinclude` extracts. This convention ensures docs stay in sync with compilable source.
- **`DOC_URL` constant** in `python/tvm_ffi/stub/consts.py`: canonical URL for the Python packaging documentation, referenced by the stubgen CLI help text.
