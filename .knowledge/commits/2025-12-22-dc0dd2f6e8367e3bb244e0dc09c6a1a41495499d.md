# Rename examples/packaging to examples/python_packaging and migrate docs to literalinclude

## TL;DR
- Renames `examples/packaging/` to `examples/python_packaging/` across the repo (example sources, CI workflow, docs).
- Replaces inline code blocks in `docs/packaging/python_packaging.rst` with Sphinx `literalinclude` directives pointing to the actual example files, adding region markers (`[tvm_ffi_abi.begin]`/`[tvm_ffi_abi.end]`, etc.) to `extension.cc`, `CMakeLists.txt`, and `pyproject.toml`.
