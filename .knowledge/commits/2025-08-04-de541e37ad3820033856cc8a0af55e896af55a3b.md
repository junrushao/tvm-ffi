# Add lightweight JSON parser/writer to extra/ subsystem

## TL;DR
- Adds `tvm::ffi::json::Parse` and `tvm::ffi::json::Stringify` to `include/tvm/ffi/extra/json.h`, living in the opt-in `extra/` subsystem compiled only when `TVM_FFI_USE_EXTRA_CXX_API=ON`.
- The implementation reuses the existing `Any`/`ffi::Map<Any,Any>`/`ffi::Array<Any>` container system directly — no separate JSON value type is introduced. `json::Value` is a typedef for `Any`, `json::Object` for `Map<Any,Any>`, and `json::Array` for `Array<Any>`.
- Both functions are registered as global FFI functions (`ffi.json.Parse`, `ffi.json.Stringify`) via `TVM_FFI_STATIC_INIT_BLOCK`, making them accessible cross-language through the global function registry.

## Impact
- API: New `TVM_FFI_EXTRA_CXX_API` functions `json::Parse` / `json::Stringify` in `include/tvm/ffi/extra/json.h`. Additive only; no existing signatures changed. Callers must link against the extra CXX library.
- Behavioral: None to existing code — only adds new symbols guarded by `TVM_FFI_USE_EXTRA_CXX_API`.
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API=ON` in CMake required to compile the new `.cc` files.
- Data formats/schemas: Introduces two global function names (`ffi.json.Parse`, `ffi.json.Stringify`) in the global function registry; these become cross-language callable once the extra library is linked.

## Design Elements

Design elements this commit consumes:
- **Any / AnyView** (0003-any-anyview): `json::Value = Any`; parser populates `Any` via assignment; writer reads `TypeIndex` via `AnyUnsafe::CopyFromAnyViewAfterCheck`. The non-coercing `cast<T>()` / `as<T>()` API is used in tests.
- **ffi::Map / ffi::Array / ffi::String** (0007-containers): `json::Object = Map<Any,Any>`, `json::Array = Array<Any>`. Both containers' range constructors (from iterator pairs) are used by the parser to build final objects from the temp stack in a single allocation.
- **Global function registry** (0004-function-system): Both `Parse` and `Stringify` registered via `reflection::GlobalDef().def(name, fn)` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- **Error system** (0005-error-system): `TVM_FFI_THROW(ValueError)` used in `Stringify` for unsupported types and mistyped object keys; `TVM_FFI_ICHECK` used in parser.
- **extra/ subsystem** (0009-structural-eq-hash): Follows the same `TVM_FFI_EXTRA_CXX_API`-gated pattern established by `structural_equal.cc` / `structural_hash.cc`; added to the same CMake block.

Design elements this commit produces:
- **`tvm::ffi::json` namespace**: New JSON sub-namespace in the `extra/` component providing a zero-dependency, FFI-native JSON codec. The type alias design (Value=Any, Object=Map<Any,Any>, Array=Array<Any>) is a new structural convention: JSON tokens map 1:1 onto existing FFI types with no boxing overhead.
- **Dual-mode error API pattern**: `Parse` accepts an optional `String* error_msg` out-parameter; when non-null, errors are surfaced without throwing (error_msg set, returns null Any). This is a new API convention in the extra/ subsystem (structural-equal has no equivalent non-throwing path).
- **Temp-stack parsing optimization**: `JSONParser` accumulates elements in `array_temp_stack_` / `object_temp_stack_` vectors, then constructs `Array`/`Map` from iterator ranges to avoid incremental container mutations. Reusable across nested structures in a single parse call.
- **Float round-trip invariant**: Integer-valued doubles are always serialized with `.0` suffix so that re-parsing restores `double` (not `int64`) type.

## Usage Examples

**Parse JSON and navigate the result (C++):**
```cpp
#include <tvm/ffi/extra/json.h>
using namespace tvm::ffi;

// Parse a JSON object
auto val = json::Parse(R"({"key": 42, "arr": [1, 2.5, "x"]})");
auto obj = val.cast<json::Object>();   // Map<Any,Any>
auto n   = obj.at(String("key")).cast<int64_t>();  // 42

// Non-throwing path for user-facing input validation
String err;
auto bad = json::Parse("not-json", &err);  // returns nullptr, err is set
```

**Stringify a nested value (C++):**
```cpp
json::Object kv = json::Object({{String("x"), json::Value(1)}});
String compact = json::Stringify(kv);           // {"x":1}
String pretty  = json::Stringify(kv, 2);        // {\n  "x": 1\n}
```

**Cross-language via global registry (Python, once extra lib linked):**
```python
import tvm_ffi
parse     = tvm_ffi.get_global_func("ffi.json.Parse")
stringify = tvm_ffi.get_global_func("ffi.json.Stringify")
val = parse('{"a": 1}')
out = stringify(val, 2)
```
