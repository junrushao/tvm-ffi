# Add kw_only support to @c_class and field() for keyword-only __init__ parameters

## TL;DR
- `c_class(kw_only=True)` makes all fields keyword-only in the generated `__init__`.
- `field(kw_only=True|False)` overrides the class-level `kw_only` per field (field > `KW_ONLY` sentinel > class).
- `KW_ONLY` sentinel (backport from Python 3.10's `dataclasses.KW_ONLY`) marks all subsequent annotated fields as keyword-only when used as a type annotation.
- `method_init()` updated to split args into four buckets: `pos_no_defaults`, `pos_with_defaults`, `kw_no_defaults`, `kw_with_defaults`; inserts `*` separator in signature when any kw-only args exist.
- Adds `tvm_ffi.testing` module with a test C++ FFI class (`TestObject`) plus tests.

## Key Exports

```python
# python/tvm_ffi/dataclasses/field.py
KW_ONLY: object  # Sentinel — annotate a field with KW_ONLY to mark subsequent fields as keyword-only
# Backport: uses dataclasses.KW_ONLY on Python 3.10+, custom sentinel on 3.9

class Field:
    """Dataclass field descriptor."""
    name: str | None
    default_factory: Callable | MISSING_TYPE
    init: bool
    repr: bool
    kw_only: bool | MISSING_TYPE  # NEW — MISSING means "inherit from class-level or KW_ONLY sentinel"

def field(
    default=MISSING,
    default_factory=MISSING,
    init: bool = True,
    repr: bool = True,
    kw_only: bool | MISSING_TYPE = MISSING,  # NEW
) -> _FieldValue: ...
# Interacts with: c_class(), method_init(), fill_dataclass_field()

# python/tvm_ffi/dataclasses/c_class.py
@dataclass_transform(field_specifiers=(field,), kw_only_default=False)
def c_class(
    type_key: str,
    init: bool = True,
    kw_only: bool = False,  # NEW
    repr: bool = True,
) -> Callable[[Type[T]], Type[T]]: ...
# Interacts with: _inspect_c_class_fields(), fill_dataclass_field(), method_init()

# _inspect_c_class_fields returns tuple[list[TypeField], int | None]
# Second element = index of first KW_ONLY-sentinel field (None if no sentinel)
```

## Impact
- API: `c_class()` gains `kw_only: bool = False` parameter; `field()` gains `kw_only: bool | MISSING = MISSING` (all backward-compatible).
- Behavioral: `method_init()` now generates `*` separator in `__init__` signature when kw-only fields exist; signature matches Python standard `dataclasses` behavior.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
from tvm_ffi.dataclasses import c_class, field, KW_ONLY

# Class-level kw_only
@c_class("my.Config", kw_only=True)
class Config:
    host: str
    port: int = field(default=8080)

cfg = Config(host="localhost", port=9090)  # OK
# Config("localhost")  # TypeError: positional not allowed

# Per-field kw_only override
@c_class("my.Node")
class Node:
    name: str           # positional
    _: KW_ONLY          # all fields after this become kw_only
    debug: bool = field(default=False)  # keyword-only

n = Node("root", debug=True)
```
