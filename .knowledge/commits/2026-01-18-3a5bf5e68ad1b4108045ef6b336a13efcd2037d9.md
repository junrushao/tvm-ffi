# Add kw_only support for dataclass init generation in @c_class
## TL;DR
- Adds `kw_only` parameter to `c_class()` decorator and `field()` function, mirroring Python's `dataclasses.KW_ONLY` semantics.
- Adds `KW_ONLY` sentinel class for marking subsequent fields as keyword-only via annotation.
- Updates `method_init()` to generate proper keyword-only signatures with `*` separator.
- Adds C++ test class `TestCxxKwOnly` and comprehensive Python tests.

- Behavioral: generated `__init__` now supports keyword-only parameters
- Flags/config: none

## Usage Examples

```python
@c_class("testing.TestCxxKwOnly", kw_only=True)
class MyClass:
    x: int
    y: int
    z: int
    w: int = 100

obj = MyClass(x=1, y=2, z=3)        # OK: keyword-only
obj = MyClass(x=1, y=2, z=3, w=4)   # OK
# MyClass(1, 2, 3)                   # TypeError: positional not allowed
```
