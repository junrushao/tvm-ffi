# Add kw_only support for dataclass init generation
## TL;DR
- Adds `kw_only` parameter support in `@c_class` / `field()` for dataclass-style init generation, mirroring Python's `dataclasses.field(kw_only=True)`.
- Extends `_utils.py` and `c_class.py` to handle keyword-only fields in `__init__` generation.
- Adds C++ testing object with default fields and Python tests.
