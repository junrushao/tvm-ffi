# Introduce ShapeView, minimize TensorObj exposure, and inline shape/strides storage
## TL;DR
- Introduces `ShapeView` as a lightweight, non-owning view over shape data (`const int64_t*` + `size`), reducing managed `Shape` allocations. `Tensor::shape()` and `Tensor::strides()` now return `ShapeView` instead of `Shape`.
- Removes `shape_data_`, `strides_data_`, and `cached_dl_managed_tensor_versioned_` from `TensorObj`, minimizing its ABI surface. Shape and strides are now stored inline after the object via `make_inplace_array_object`.
- `TensorObjFromNDAlloc` and `TensorObjFromDLPack` allocate extra `int64_t` elements at the tail for shape/strides data, filled in-place during construction.
- Adds `Tensor::data_ptr()`, `Tensor::ndim()`, `Tensor::numel()` convenience methods.
- `ToDLPackVersioned` simplified: no longer caches `DLManagedTensorVersioned*`; creates a fresh one each call (like `ToDLPack`). Deleter templatized.
- Bumps version to `0.1.0b10`.

## Impact
- API: `Tensor::shape()` and `Tensor::strides()` return `ShapeView` instead of `Shape` (breaking for C++ callers that stored the return value as `Shape`). New `ShapeView` class. `TensorObj` loses protected fields.
- Flags/config: None
- Data formats/schemas: None

## Design Elements

- **Inplace array allocation** ([`.knowledge/designs/0003-object-system.md`](../designs/0003-object-system.md)): `make_inplace_array_object` used to store shape/strides at tail.

Design elements this commit produces:
- **ShapeView non-owning view**: A lightweight alternative to `Shape` for passing shape data without heap allocation. Implicit conversion between `Shape` and `ShapeView` in both directions.
- **Inline shape/strides storage for Tensor**: Shape and strides are stored contiguously after the `TensorObj` header, eliminating separate `Shape` heap allocations and the `Optional<Shape>` fields.
