# Introduce ShapeView non-owning class and minimize TensorObj ABI exposure

## TL;DR
- Introduces `ShapeView`, a lightweight non-owning view class wrapping `TVMFFIShapeCell {data, size}`, providing `operator[]`, `at()`, `begin()`/`end()`, `Product()`, `front()`/`back()`, `empty()`.
- Refactors `Shape` methods to use `ShapeView` where possible: `StridesFromShape(ShapeView)`, implicit conversion `operator ShapeView()`.
- Adds `FillStridesFromShape(ShapeView shape, int64_t* out_strides)` utility.
- Moves bounds-checking from `operator[]` to `at()` for `Shape` (matches STL convention).
- Reduces TensorObj exposure by removing destructor definition from header.

## Key Exports

**Classes**:
- `ShapeView` -- non-owning shape view
  - Constructors: `ShapeView()`, `ShapeView(const int64_t* data, size_t size)`, `ShapeView(initializer_list<int64_t>)`
  - Methods: `data()`, `size()`, `operator[]`, `at(idx)`, `begin()`, `end()`, `empty()`, `front()`, `back()`, `Product()`

**Functions**:
- `FillStridesFromShape(ShapeView shape, int64_t* out_strides) -> void` -- fill strides array from shape
- `MakeStridesFromShape(ShapeView shape) -> ObjectPtr<ShapeObj>` -- signature changed from `(const int64_t* data, int64_t ndim)`

**Conversions**:
- `Shape::operator ShapeView() const` -- implicit conversion
- `Shape(ShapeView other)` -- constructor from ShapeView

## Impact
- API: `Shape::StridesFromShape` now takes `ShapeView` instead of `(const int64_t*, int64_t)`. `Shape::operator[]` no longer bounds-checks (use `at()` for checked access).
- ABI: none
- Behavioral: `operator[]` is now unchecked for `Shape` (matches `ShapeView` and STL vector behavior). `at()` retains bounds checking.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:

Design elements this commit produces:
- **ShapeView non-owning pattern**: lightweight view into shape data without heap allocation, following the same pattern as `AnyView` for `Any`.

## Usage Examples
```cpp
// ShapeView usage
Shape s({3, 4, 5});
ShapeView view = s;            // implicit conversion
int64_t prod = view.Product(); // 60
int64_t elem = view[1];       // 4 (unchecked)
int64_t safe = view.at(1);    // 4 (checked)

// FillStridesFromShape
int64_t strides[3];
FillStridesFromShape(view, strides); // strides = {20, 5, 1}
```
