# Introduce ShapeView and minimize TensorObj ABI exposure via inplace storage
## TL;DR
- Introduces `ShapeView`, a lightweight non-owning view over shape data, replacing `Shape` (heap-allocated `ObjectRef`) in most Tensor internal APIs to reduce memory allocation.
- Removes three protected fields from `TensorObj` (`shape_data_`, `strides_data_`, `cached_dl_managed_tensor_versioned_`), eliminating the lazy-caching pattern and atomic caching of DLManagedTensorVersioned; shape and stride data are now stored inplace in trailing allocation of the TensorObj subclass objects.
- Adds convenience methods `Tensor::data_ptr()`, `Tensor::ndim()`, `Tensor::numel()` and unifies the DLPack deleter into a single template `DLManagedTensorDeleter<T>`.

## Impact
- API: **Breaking** -- `Tensor::shape()` and `Tensor::strides()` now return `ShapeView` instead of `Shape`. Callers that store the result as `Shape` still compile (implicit conversion), but callers relying on `ObjectRef` semantics (e.g., `shape().same_as()`) will break. The test removes two `EXPECT_EQ(nd2.shape(), shape)` assertions that relied on `Shape` equality.
- API: `Shape::StridesFromShape` parameter changed from `(const int64_t*, int64_t)` to `(ShapeView)`.
- API: `Tensor::FromNDAlloc` parameter changed from `ffi::Shape` to `ffi::ShapeView`.
- Behavioral: `TensorObj::ToDLPackVersioned()` no longer caches the result atomically; each call allocates a fresh `DLManagedTensorVersioned`. This trades a small allocation per export for eliminating atomic operations and the `~TensorObj` destructor overhead.
- Behavioral: Shape and stride int64_t arrays are now stored inplace (trailing allocation) in `TensorObjFromNDAlloc` and `TensorObjFromDLPack`, rather than as separate `Optional<Shape>` heap objects. This improves cache locality and reduces per-tensor allocation count.
- Flags/config: Version bump `0.1.0b9` -> `0.1.0b10`.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (`make_object`, `make_inplace_array_object`, `ObjectRef`, `ObjectPtr`) -- `make_inplace_array_object` is now used for `TensorObjFromNDAlloc` and `TensorObjFromDLPack` (when strides are null), not just for `ShapeObj`.
- **DLPack interop** -- `DLManagedTensor`, `DLManagedTensorVersioned`, `DLTensor` struct layout.
- **TVMFFIShapeCell** (C ABI struct) -- reused as the backing store for `ShapeView`.
- **Inplace array allocation** (`make_inplace_array_object<T, Elem>`) -- now central to Tensor construction, allocating trailing `int64_t` arrays for shape+strides.

Design elements this commit produces:
- **ShapeView** -- new lightweight non-owning view type for shape data. Designed to replace `Shape` (heap ObjectRef) in performance-sensitive paths. Mirrors `Shape`'s read API (`operator[]`, `at`, `Product`, iterators) without ref-counting. Implicit conversions to/from `Shape` enable gradual migration.
- **Inplace shape/strides in Tensor** -- new memory layout pattern where `TensorObjFromNDAlloc` and `TensorObjFromDLPack` store shape and stride data in trailing allocation after the object struct, using `make_inplace_array_object`. Eliminates separate `Optional<Shape>` fields and their heap allocations.
- **Unified DLPack deleter template** -- `DLManagedTensorDeleter<T>` replaces the separate `DLManagedTensorDeleter` and `EmbeddedDLManagedTensorVersionedDeleter` with a single template that works for both `DLManagedTensor` and `DLManagedTensorVersioned`.

## Usage Examples

**ShapeView construction and use (from test_shape.cc)**:
```cpp
// From managed Shape (implicit conversion)
Shape shape = Shape({1, 2, 3});
ShapeView shape_view = shape;  // zero-copy, borrows data
assert(shape_view.size() == 3);
assert(shape_view[0] == 1);
assert(shape_view.Product() == 6);

// From raw data pointer
std::vector<int64_t> data = {4, 5, 6};
ShapeView view(data.data(), data.size());

// From initializer list (borrows list's backing storage)
ShapeView init_view = {7, 8, 9};
```

**Tensor creation with ShapeView (from test_tensor.cc)**:
```cpp
// ShapeView accepts initializer_list directly, no Shape allocation needed
Tensor nd = Empty({1, 2, 3}, DLDataType({kDLFloat, 32, 1}), DLDevice({kDLCPU, 0}));
assert(nd.numel() == 6);
assert(nd.ndim() == 3);
assert(nd.data_ptr() == nd->data);
```
