# Introduce ShapeView non-owning class and minimize TensorObj ABI exposure
## TL;DR
- Introduces `ShapeView`, a lightweight non-owning view over shape data (pointer+size), analogous to `std::span<int64_t>`.
- Removes `shape_data_`, `strides_data_`, and `cached_dl_managed_tensor_versioned_` fields from `TensorObj`, replacing them with inplace-allocated shape/strides after the object header.
- `Tensor::shape()` and `Tensor::strides()` now return `ShapeView` instead of `Shape`. New helpers: `data_ptr()`, `ndim()`, `numel()`.

## Impact
- API: `Tensor.shape()` and `Tensor.strides()` return `ShapeView` instead of `Shape` (C++ API change). New `data_ptr()`, `ndim()`, `numel()` accessors. `Tensor::FromNDAlloc` takes `ShapeView` instead of `Shape`.
- Behavioral: `TensorObj` no longer caches `DLManagedTensorVersioned`; `ToDLPackVersioned()` allocates a new one each call. Shape and strides are stored inplace after the object body.
- Flags/config: None
- Data formats/schemas: `TensorObj` internal layout changed (removed `shape_data_`, `strides_data_`, `cached_dl_managed_tensor_versioned_`; shape/strides now inplace).
