# Add regression test for register_object __init__ wiring

## TL;DR
- Adds `test_register_object_wires_init` in `tests/python/test_object.py` covering two cases: (1) correct field values after `__init__` construction, (2) `chandle == 0` after bare `__new__` (confirming init is the only creation path).
- Prevents regression of the NULL-handle segfault where `CObject.tp_new` + `object.__init__` silently ignored extra positional args before `_install_init` was wired in commit 6973d225.
