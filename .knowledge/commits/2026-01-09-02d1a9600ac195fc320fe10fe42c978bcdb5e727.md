# Add starts_with and ends_with methods to String
## TL;DR
- Adds `starts_with` and `ends_with` methods to `tvm::ffi::String` with overloads for `String`, `std::string_view`, `const char*`, and `(const char*, size_t)` variants
- Implementation uses `std::memcmp` for efficient prefix/suffix comparison
- Includes comprehensive C++ tests

## Key Exports
```python
class String:
    def starts_with(self, prefix: str) -> bool: ...
    # Invariant: returns False if prefix longer than self
    def ends_with(self, suffix: str) -> bool: ...
    # Invariant: returns False if suffix longer than self
```

## Impact
- API: additive — new methods on `String`
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cpp
tvm::ffi::String s("hello world");
assert(s.starts_with("hello"));
assert(s.ends_with("world"));
assert(!s.starts_with("world"));
```
