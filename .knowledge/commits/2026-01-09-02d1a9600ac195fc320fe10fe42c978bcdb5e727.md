# Add starts_with and ends_with methods to String

## TL;DR

- Adds `starts_with(prefix)` to `String` with four overloads: `String`, `std::string_view`, `const char*`, `const char* + size_t`.
- Adds `ends_with(suffix)` to `String` with the same four overloads.
- Both methods use `std::memcmp` for prefix/suffix comparison; the `count > size()` guard prevents reading out of bounds.

## Key Exports

```python
class String:
    """Immutable UTF-8 string (existing); new prefix/suffix query methods added."""

    def starts_with(self, prefix: "String | str_view | const_char_ptr", count: int = ...) -> bool: ...
    # Overload 1: starts_with(const String& prefix) -> delegates to (data(), size())
    # Overload 2: starts_with(std::string_view prefix) -> delegates to (data(), size())
    # Overload 3: starts_with(const char* prefix) -> delegates to (prefix, strlen(prefix))
    # Overload 4: starts_with(const char* prefix, size_t count) -> memcmp(data(), prefix, count)
    # Invariant: count > size() returns false immediately (no OOB access)
    # Invariant: empty prefix ("") always returns true (memcmp of 0 bytes is trivially equal)
    # Interacts with: BytesBaseCell.data()/size() (raw buffer access)

    def ends_with(self, suffix: "String | str_view | const_char_ptr", count: int = ...) -> bool: ...
    # Overload 1: ends_with(const String& suffix) -> delegates to (data(), size())
    # Overload 2: ends_with(std::string_view suffix) -> delegates to (data(), size())
    # Overload 3: ends_with(const char* suffix) -> delegates to (suffix, strlen(suffix))
    # Overload 4: ends_with(const char* suffix, size_t count) -> memcmp(data() + size() - count, suffix, count)
    # Invariant: count > size() returns false immediately
    # Invariant: empty suffix ("") always returns true
    # Interacts with: BytesBaseCell.data()/size() (raw buffer access)
```

## Usage Examples

C++ test from `tests/cpp/test_string.cc` (same commit):

```cpp
String s{"hello world"};

// starts_with: const char* overload
EXPECT_TRUE(s.starts_with("hello"));
EXPECT_FALSE(s.starts_with("world"));

// starts_with: String overload
EXPECT_TRUE(s.starts_with(String{"hello"}));

// ends_with: std::string_view overload
EXPECT_TRUE(s.ends_with(std::string_view{"world"}));

// Edge case: empty prefix/suffix always matches
EXPECT_TRUE(s.starts_with(""));
EXPECT_TRUE(s.ends_with(""));

// Guard: prefix longer than string returns false
EXPECT_FALSE(s.starts_with("hello world extra"));
```
