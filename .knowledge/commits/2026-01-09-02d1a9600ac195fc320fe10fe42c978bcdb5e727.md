# Add starts_with and ends_with methods to ffi::String
## TL;DR
- Adds `starts_with` and `ends_with` methods to `ffi::String` in `include/tvm/ffi/string.h`, each with 4 overloads accepting `const String&`, `std::string_view`, `const char*`, and `(const char*, size_t)`.
- Core implementation uses `std::memcmp` against `data()` pointer with length-boundary check.
- Comprehensive tests in `tests/cpp/test_string.cc` covering normal, empty, single-char, and prefix-longer-than-string cases.

## Key Exports

**Methods** added to `ffi::String` (in `include/tvm/ffi/string.h`):

| Method | Signature | Notes |
|--------|-----------|-------|
| `starts_with` | `bool starts_with(const String& prefix) const` | Delegates to `(const char*, size_t)` overload |
| `starts_with` | `bool starts_with(std::string_view prefix) const` | Delegates to `(const char*, size_t)` overload |
| `starts_with` | `bool starts_with(const char* prefix) const` | Uses `strlen` then delegates |
| `starts_with` | `bool starts_with(const char* prefix, size_t count) const` | Core: returns `false` if `count > size()`, else `memcmp` |
| `ends_with` | `bool ends_with(const String& suffix) const` | Delegates to `(const char*, size_t)` overload |
| `ends_with` | `bool ends_with(std::string_view suffix) const` | Delegates to `(const char*, size_t)` overload |
| `ends_with` | `bool ends_with(const char* suffix) const` | Uses `strlen` then delegates |
| `ends_with` | `bool ends_with(const char* suffix, size_t count) const` | Core: returns `false` if `count > size()`, else `memcmp` at `data() + size() - count` |
