# Add starts_with and ends_with methods to the String class

## TL;DR
- Adds `starts_with(prefix)` and `ends_with(suffix)` to `tvm::ffi::String`, each with three overloads: `String`, `std::string_view`, and `const char*` (plus a `(const char*, size_t)` primitive that all delegate to).
- Both methods use `std::memcmp` and respect string boundaries; no null-terminator assumption.
- 46 lines of new tests in `tests/cpp/test_string.cc`.

## Key Exports

```python
class String:
    """Immutable ref-counted string. Lives in include/tvm/ffi/string.h."""

    def starts_with(self, prefix: String | str_view | char_ptr) -> bool:
        """True if string starts with prefix. Uses memcmp, O(len(prefix)).
        # Invariant: returns false immediately if len(prefix) > len(self)
        # Interacts with: String::data(), String::size()
        """

    def ends_with(self, suffix: String | str_view | char_ptr) -> bool:
        """True if string ends with suffix. Uses memcmp, O(len(suffix)).
        # Invariant: returns false immediately if len(suffix) > len(self)
        # Interacts with: String::data(), String::size()
        """
```

## Usage Examples

```cpp
#include <tvm/ffi/string.h>
using tvm::ffi::String;

String s = "tvm_ffi_my_function";
assert(s.starts_with("tvm_ffi_"));       // true
assert(s.ends_with("_function"));        // true
assert(!s.starts_with("mlc_"));          // false

// Works with std::string_view too
std::string_view prefix = "tvm";
assert(s.starts_with(prefix));
```
