# Robustify pyproject setup, make numpy/torch optional imports, and harden cibuildwheel CI

## TL;DR

- **Packaging / CI**: `pyproject.toml` updated to build cp39–cp312 abi3 wheels via `cibuildwheel`; RPATH set in `CMakeLists.txt` so `tvm_ffi_cython.so` finds `libtvm_ffi_shared.so` at `@loader_path/lib` (macOS) or `$ORIGIN/lib` (Linux).
- **Optional imports**: `numpy` import in `dtype.py` moved into a `try/except ImportError` block so the module loads without numpy installed; `torch.utils.cpp_extension` import in `function.pxi` deferred inside `try` to avoid top-level import failure.
- **Test robustification**: `test_error_from_nested_pyfunc` in `test_error.py` converts the whole debug-symbol–dependent assertion block to a soft `pytest.xfail` on `Exception` instead of using `@pytest.mark.xfail` at the function level.

## Key Exports

None — no new public API surface introduced. All changes are to build configuration, optional-dependency handling, and test resilience.

## Impact

- API: none
- Behavioral: `dtype.NUMPY_DTYPE_TO_STR` is now an empty dict when numpy is absent at import time; values are populated lazily on first successful `import numpy`. Previously, the module would raise `ImportError` at load time if numpy was missing.
- Flags/config: `cibuildwheel` config now targets cp39–cp312 (was skipping all of these), enables `test-extras = ["test"]` with `pytest {package}/tests/python -vvs`, and adds `setuptools` to the `torch` optional-dependency group.
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- `dtype` class (`python/tvm_ffi/dtype.py`) — `NUMPY_DTYPE_TO_STR` class-level dict used for numpy→TVM dtype string conversion. No design record; internal Python layer detail.
- `load_torch_get_current_cuda_stream` (`python/tvm_ffi/cython/function.pxi`) — deferred torch CUDA stream accessor. Relates to packaging concern only.

Design elements this commit produces: none — existing elements are adjusted, not newly introduced.

## Usage Examples

**Before (dtype.py — fails if numpy not installed):**
```python
# module-level, always executed
import numpy as np
class dtype(str):
    NUMPY_DTYPE_TO_STR = {np.dtype(np.bool_): "bool", ...}
```

**After (dtype.py — numpy optional):**
```python
class dtype(str):
    NUMPY_DTYPE_TO_STR = {}   # empty by default

try:
    import numpy as np
    dtype.NUMPY_DTYPE_TO_STR[np.dtype(np.bool_)] = "bool"
    # ... remaining entries populated here
except ImportError:
    pass
```

**Before (test_error.py — whole test xfails on 32-bit/Windows):**
```python
@pytest.mark.xfail("32bit" in platform.architecture() or platform.system() == "Windows",
                   reason="May fail if debug symbols are missing")
def test_error_from_nested_pyfunc():
    ...
    assert traceback.count("TestApply") == 1   # hard assertion
```

**After (test_error.py — soft xfail inside the test body):**
```python
def test_error_from_nested_pyfunc():
    ...
    try:
        assert traceback.count("TestApply") == 1
        ...
    except Exception as e:
        pytest.xfail("May fail if debug symbols are missing")
```
