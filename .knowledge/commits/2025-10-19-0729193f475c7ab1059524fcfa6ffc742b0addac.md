# Auto-generate __init__ from __ffi_init__ or raise explicit error
## TL;DR
- When `register_object` is called and the class lacks `__init__`, automatically generates one that: (a) delegates to `__ffi_init__` if available, or (b) raises an explicit error saying `__init__` is not defined.
- Prevents silent creation of objects with `chandle=None` that would segfault on field access.

## Impact
- API: Behavioral change: attempting to construct an object without a defined init now raises an informative error instead of silently producing a broken object.
- Flags/config: None.
- Data formats/schemas: None.
