# Refactor torch-c-dlpack-ext CI: merge build_libs+build_wheels into single job, extract build script
## TL;DR
- Consolidates the two-job (`build_libs` -> `build_wheels`) GitHub Actions workflow into a single `build_wheels` job that builds libs and wheels inside one Docker container.
- Extracts per-torch-version build logic from inline YAML steps into a reusable shell script `addons/torch_c_dlpack_ext/build_aot_wheels.sh`.
- Adds `cp314` to the Python version matrix and removes `torch` from `pyproject.toml` build-requires (build-time dependency no longer needed since builds happen in isolated venvs).
- Re-enables the `workflow_dispatch` guard on the publish job (was previously commented out).
