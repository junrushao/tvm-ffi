# Consolidate torch-c-dlpack-ext CI into single job with reusable build script
## TL;DR
- Merged two separate GitHub Actions jobs (`build_libs` + `build_wheels`) into a single `build_wheels` job, eliminating artifact upload/download between stages.
- Extracted per-torch-version build logic from inline YAML steps into a reusable `build_aot_wheels.sh` shell script with version-availability and CUDA-URL lookup functions.
- Added Python 3.14 (`cp314`) to the CI matrix and re-enabled the `workflow_dispatch` gate on the publish job.

## Key Exports
N/A -- infrastructure.

## Impact
- API: none
- Behavioral: CI wheel build pipeline now runs in a single job instead of two, reducing total build time by avoiding artifact serialization. The `torch` dependency is no longer required at `pyproject.toml` build-system level (only at runtime).
- Flags/config: `cp314` added to Python version matrix.
- Data formats/schemas: none
