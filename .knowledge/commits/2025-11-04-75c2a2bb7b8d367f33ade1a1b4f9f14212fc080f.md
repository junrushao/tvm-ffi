# Refactor torch-c-dlpack-ext CI into single-job pipeline with shared build script
## TL;DR
- Collapses the two-job GitHub Actions workflow (`build_libs` + `build_wheels`) into a single `build_wheels` job, eliminating the artifact-download hop between jobs.
- Extracts per-torch-version build logic from inline workflow steps into a reusable shell script `addons/torch_c_dlpack_ext/build_aot_wheels.sh`.
- Adds Python 3.14 (`cp314`) to the build matrix and removes `torch` from `pyproject.toml` build-system requires. Re-enables the publish guard (`if: github.event_name == 'workflow_dispatch'`).

## Key Exports
N/A -- infrastructure.

## Impact
- API: none
- Behavioral: The torch-c-dlpack-ext wheel build pipeline now runs as a single Docker-based job instead of two jobs with artifact passing. Build logic is centralized in `build_aot_wheels.sh`, making local reproduction easier.
- Flags/config: `torch` removed from `build-system.requires` in `addons/torch_c_dlpack_ext/pyproject.toml`. Torch is still installed inside per-version venvs by the build script; it is no longer needed at `python -m build -w` time since only pre-built `.so` files are packaged.
- Data formats/schemas: none
