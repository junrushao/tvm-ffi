# Introduce setuptools_scm for automated version management
## TL;DR
- Adopts `setuptools_scm` for Python package versioning, deriving version from git tags automatically.
- Adds a version consistency linter (`check_version.py`) that validates C++ and Rust version strings against the `setuptools_scm`-derived version, run per commit.
- Updates CI workflows, pre-commit hooks, and build configuration.

## Impact
- API: Python `__version__` now derived from git tags via `setuptools_scm`.
- Flags/config: New `[tool.setuptools_scm]` config in `pyproject.toml`. CI and pre-commit updated.
