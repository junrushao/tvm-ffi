# Introduce `setuptools_scm` for better versioning

## TL;DR
- Replaces the manual `version = "0.1.0"` in `pyproject.toml` and hardcoded `__version__ = "0.1.0"` in `__init__.py` with `setuptools_scm`-derived versioning. The Python package version is now fully controlled by git tags via `setuptools_scm`, with a generated `_version.py` file.
- Rewrites `tests/lint/check_version.py` from a simple pyproject-vs-init sync checker into a multi-language version consistency linter that uses `setuptools_scm` to derive the canonical version, then validates C++ macros (`TVM_FFI_VERSION_{MAJOR,MINOR,PATCH}`) and Rust `Cargo.toml` versions against it.
- Bumps C++ version macro `TVM_FFI_VERSION_PATCH` from `0` to `1` (now `0.1.1`), and updates all CI workflows to use `actions/checkout@v5` with `fetch-depth: 0` + `fetch-tags: true` (required for `setuptools_scm` to derive version from git history).

## Key Exports

**`pyproject.toml` changes**:
- `project.version` replaced with `dynamic = ["version"]`
- `[tool.setuptools_scm]`: `version_file = "python/tvm_ffi/_version.py"`, `write_to = "python/tvm_ffi/_version.py"`
- `[tool.scikit-build] metadata.version.provider = "scikit_build_core.metadata.setuptools_scm"`
- Build requires: `setuptools-scm` added, `cmake>=3.18` and `ninja` removed from build-system requires

**`python/tvm_ffi/__init__.py` versioning**:
```python
try:
    from ._version import __version__, __version_tuple__
except ImportError:
    __version__ = "0.0.0.dev0"
    __version_tuple__ = (0, 0, 0, "dev0", "7d34eb8ab.d20250913")
```
- `__version_tuple__` added to `__all__`

**`tests/lint/check_version.py`** (rewritten):
- `_version_info() -> dict[str, Any]`: Uses `setuptools_scm.get_version()` + `packaging.version.Version` to extract structured version info.
- `_check_cpp(version_info) -> list[str]`: Scans `include/tvm/ffi/c_api.h` for `TVM_FFI_VERSION_{MAJOR,MINOR,PATCH}` macros and validates against the canonical version.
- `_check_rust(version_info) -> list[str]`: Reads Rust `Cargo.toml` files for `tvm-ffi`, `tvm-ffi-macros`, `tvm-ffi-sys` and validates version compatibility.
- `_map_pep440_pre_to_semver(pre) -> str | None`: Maps PEP 440 pre-release tags to semver equivalents.
- CLI: `python tests/lint/check_version.py [--cpp] [--rust]`

**C++ version bump**: `TVM_FFI_VERSION_PATCH` `0` -> `1` in `include/tvm/ffi/c_api.h`

## Impact
- API: `__version_tuple__` added to `tvm_ffi.__all__`. `__version__` source changed from hardcoded string to auto-generated `_version.py`.
- Behavioral: Version string is now derived from git tags at build time. Development installs without tags get `0.0.0.dev0` fallback.
- Flags/config: CI workflows now require `fetch-depth: 0` and `fetch-tags: true` for `setuptools_scm` to work. Pre-commit hook renamed `check-version` -> `check-version-consistency` and requires `setuptools-scm`, `packaging`, `tomli` as additional dependencies.
- Data formats/schemas: `_version.py` is auto-generated and gitignored.

## Design Elements
Design elements this commit consumes:
- **Python package build system** (`pyproject.toml`, `scikit-build-core`): Modified to delegate version to `setuptools_scm`. See `.knowledge/designs/0014-python-package.md`.
- **C ABI version macros** (`c_api.h`): `TVM_FFI_VERSION_{MAJOR,MINOR,PATCH}` consumed and validated by the linter. See `.knowledge/designs/0001-c-abi-layer.md`.
- **CI pipeline** (`.github/workflows/`): All checkout steps updated. See `.knowledge/designs/0016-ci-and-lint-pipeline.md`.

Design elements this commit produces:
- **`setuptools_scm`-based version derivation**: Canonical version is derived from git tags rather than hardcoded in `pyproject.toml`. This eliminates manual version sync between pyproject.toml, `__init__.py`, and C++ headers.
- **Multi-language version consistency linter** (`check_version.py`): Validates C++ macros and Rust `Cargo.toml` against the `setuptools_scm`-derived version. Extensible via `--cpp`/`--rust` flags.

## Usage Examples

```bash
# Check C++ version consistency
python tests/lint/check_version.py --cpp
# Output:
# Project version: 0.1.1.dev9+g43f0820f6.d20251021
#   major: 0, minor: 1, micro: 1 ...

# Check both C++ and Rust
python tests/lint/check_version.py --cpp --rust

# In Python:
import tvm_ffi
print(tvm_ffi.__version__)        # "0.1.1.dev9+g43f0820f6.d20251021"
print(tvm_ffi.__version_tuple__)  # (0, 1, 1, "dev9", "g43f0820f6.d20251021")
```
