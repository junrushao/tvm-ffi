# Introduce setuptools_scm for dynamic version management from git tags

## TL;DR
- `pyproject.toml` switches from `version = "0.1.0"` (static) to `dynamic = ["version"]` via `scikit_build_core.metadata.setuptools_scm`.
- `check_version.py` updated to use `setuptools_scm` for version discovery and accepts a `--cpp` flag to validate C++ header versions against the SCM-derived version.
- CI workflows (`ci_test.yml`, `publish_wheel.yml`) updated to pass version information; `.gitignore` updated to exclude `_version.py`.
