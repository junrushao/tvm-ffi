# Add Function::InvokeExternC for direct SafeCall invocation without FunctionObj construction
## TL;DR
- Adds `Function::InvokeExternC`, a static template method that directly invokes an `extern "C"` function following the `TVMFFISafeCallType` convention without allocating a `FunctionObj` on the heap.
- This complements `Function::FromExternC` (which wraps the symbol into a `Function` object) with a zero-allocation call path for performance-sensitive scenarios.
- Includes a test exercising the new method against the existing `__tvm_ffi_testing_add1` exported symbol.

## Key Exports

```python
class Function(ObjectRef):
    # ... existing methods ...

    @staticmethod
    def InvokeExternC(handle: void_ptr, safe_call: TVMFFISafeCallType, *args: Args) -> Any:
        """Directly invoke an extern 'C' SafeCall function without constructing a FunctionObj.

        Packs args into AnyView[], calls safe_call directly, checks error code, returns result.
        """
        # Interacts with: PackedArgs.Fill (arg packing), TVM_FFI_CHECK_SAFE_CALL (error propagation)
        # Interacts with: TVMFFISafeCallType signature: (void*, const TVMFFIAny*, int32, TVMFFIAny*) -> int
        # Invariant: safe_call must follow SafeCall convention (return 0 on success, set TLS error on failure)
        # Invariant: handle is typically nullptr for exported symbols; non-nullptr for closure-based callbacks
        # Extension: can wrap any __tvm_ffi_* exported symbol into a typed inline function
        ...
```

## Impact
- API: Additive-only. New static method `Function::InvokeExternC` on the `Function` class. No existing callers affected.
- Behavioral: None -- no changes to existing functions.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **SafeCall convention** (`TVMFFISafeCallType`): The `(void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result) -> int` C ABI signature. See [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md).
- **PackedArgs::Fill**: Variadic template that converts C++ args into `AnyView[]`. Used identically to `Function::operator()`.
- **TVM_FFI_CHECK_SAFE_CALL**: Macro that checks the return code from a safe_call and throws any TLS-propagated error. See [0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md).
- **TVM_FFI_DLL_EXPORT_TYPED_FUNC**: Macro that exports a typed C++ function as an `extern "C"` symbol with `__tvm_ffi_` prefix. See [0004-ffi-function-system](../design-records/0004-ffi-function-system.md).

Design elements this commit produces:
- **Function::InvokeExternC**: A new static template method providing a zero-allocation call path for `extern "C"` SafeCall functions. Complements `FromExternC` (which allocates a `FunctionObj`) with a direct invocation that packs args on the stack, calls `safe_call` directly, and checks errors. See [0004-ffi-function-system](../design-records/0004-ffi-function-system.md).

## Usage Examples
Wrapping an exported extern "C" symbol into a typed inline function without heap allocation:

```cpp
// Given an exported symbol (e.g., from TVM_FFI_DLL_EXPORT_TYPED_FUNC):
extern "C" int __tvm_ffi_add(
  void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
);

// Direct invocation -- no FunctionObj allocated:
inline int add(int a, int b) {
  return tvm::ffi::Function::InvokeExternC(nullptr, __tvm_ffi_add, a, b).cast<int>();
}

// Compare with FromExternC (allocates a FunctionObj on the heap):
Function fadd = Function::FromExternC(nullptr, __tvm_ffi_add, nullptr);
int result = fadd(1, 2).cast<int>();
```
