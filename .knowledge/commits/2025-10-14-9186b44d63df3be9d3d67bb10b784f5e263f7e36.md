# Introduce Function::InvokeExternC for direct safe-call symbol invocation
## TL;DR
- Adds `Function::InvokeExternC(safe_call_addr, args...)` static method that invokes an exported safe-call symbol directly without constructing an `ffi::Function` object, reducing overhead for JIT/AOT-compiled functions.

## Impact
- API: New `Function::InvokeExternC` static template method.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Function system** (`.knowledge/designs/0004-function-system.md`): Safe-call convention `(void*, const TVMFFIAny*, int32_t, TVMFFIAny*) -> int`.

Design elements this commit produces:
- **`InvokeExternC` direct invocation path**: A zero-overhead path for calling safe-call symbols without Function object construction.
