# Introduce Function::InvokeExternC for direct extern C symbol invocation
## TL;DR
- Adds `Function::InvokeExternC(handle, safe_call, args...)`, a static template method on `Function` that directly invokes an `extern "C"` symbol following the TVM FFI SafeCall convention, without constructing a `Function` object.
- This enables lightweight, zero-allocation invocation of already-exported C symbols by packing arguments inline and calling the function pointer directly through the SafeCall protocol.
- Includes a test (`Func.InvokeExternC`) that exercises the new method via the existing `__tvm_ffi_testing_add1` export.

## Key Exports

```python
# Function::InvokeExternC (NEW static template method on Function):
#   template <typename... Args>
#   static Any InvokeExternC(void* handle, TVMFFISafeCallType safe_call, Args&&... args)
#     1. Stack-allocates AnyView[max(sizeof...(Args), 1)]
#     2. Fills via PackedArgs::Fill(args_pack, forward<Args>(args)...)
#     3. Calls safe_call(handle, reinterpret_cast<TVMFFIAny*>(args_pack), N, &result)
#     4. Checks return code via TVM_FFI_CHECK_SAFE_CALL
#     5. Returns result as Any
#   Interacts with: PackedArgs::Fill, TVM_FFI_CHECK_SAFE_CALL, TVMFFISafeCallType
#   Invariant: handle is typically nullptr for exported symbols
#   Key difference from Function::operator(): no FunctionObj allocation or ref counting
```

## Impact
- API: Adds one new public static method `Function::InvokeExternC`.
- Behavioral: Provides a fast path to invoke extern C symbols without constructing a `Function` / `FunctionObj`. The calling convention is identical to `Function::operator()` (packs args into `AnyView[]`, calls through SafeCall, checks return code), but skips the object allocation step.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **TVMFFISafeCallType** ([0001-c-abi.md](../designs/0001-c-abi.md)): The `safe_call` function pointer type used as the invocation target.
- **PackedArgs::Fill** ([0004-function-system.md](../designs/0004-function-system.md)): Argument packing into `AnyView[]`.
- **TVM_FFI_CHECK_SAFE_CALL** ([0004-function-system.md](../designs/0004-function-system.md)): Error checking macro for SafeCall return codes.
- **TVM_FFI_DLL_EXPORT_TYPED_FUNC** ([0004-function-system.md](../designs/0004-function-system.md)): The macro that generates the `__tvm_ffi_*` extern C symbol used in the test.

Design elements this commit produces:
- **Function::InvokeExternC**: A zero-allocation shortcut for invoking extern C function pointers that follow the SafeCall convention. Complements `Function::FromExternC` (which constructs a `Function` object wrapping the pointer) by providing a direct invocation path when no persistent Function handle is needed.

## Usage Examples
**Direct invocation of an exported C symbol (no Function object):**
```cpp
// Given an extern "C" symbol following SafeCall convention:
extern "C" int __tvm_ffi_add(
  void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
);

// Call it directly -- no Function object construction needed
inline int add(int a, int b) {
  return tvm::ffi::Function::InvokeExternC(nullptr, __tvm_ffi_add, a, b).cast<int>();
}
```

**Comparison with FromExternC (existing pattern):**
```cpp
// FromExternC: allocates a FunctionObj, returns Function handle
Function fadd1 = Function::FromExternC(nullptr, __tvm_ffi_testing_add1, nullptr);
fadd1(1).cast<int>();  // invoke through Function::operator()

// InvokeExternC: no allocation, direct call
Function::InvokeExternC(nullptr, __tvm_ffi_testing_add1, 1).cast<int>();
```
