# Add Function::InvokeExternC for zero-allocation direct C-ABI calls
## TL;DR
- Introduces `Function::InvokeExternC`, a static template method that directly calls a `TVMFFISafeCallType` function pointer without constructing a heap-allocated `Function` object.
- Provides a lightweight alternative to the `Function::FromExternC` + `operator()` two-step pattern, useful for creating typed inline wrappers around `__tvm_ffi_*` exported symbols.
- Adds a corresponding test (`Func.InvokeExternC`) reusing the existing `__tvm_ffi_testing_add1` symbol.

## Key Exports

```python
class Function(ObjectRef):
    # ... existing methods ...

    @staticmethod
    def InvokeExternC(handle: void_ptr, safe_call: TVMFFISafeCallType, *args: Args) -> Any:
        """Directly invoke a C-ABI safe_call function pointer without creating a Function object.

        Packs args via PackedArgs::Fill, calls safe_call directly, returns Any result.
        Zero heap allocation -- all work done on the stack.
        """
        # 1. Allocate AnyView[max(N,1)] on stack
        # 2. PackedArgs::Fill(arr, args...)
        # 3. safe_call(handle, arr, N, &result)
        # 4. TVM_FFI_CHECK_SAFE_CALL for error propagation
        # Interacts with: PackedArgs::Fill, TVM_FFI_CHECK_SAFE_CALL, TVMFFISafeCallType
        # Interacts with: FromExternC (same safe_call convention, but allocates FunctionObj)
        # Invariant: safe_call must match TVMFFISafeCallType signature
        # Invariant: handle is typically nullptr for __tvm_ffi_* exported symbols
        # maturity: active
```

## Impact
- API: New public static method `Function::InvokeExternC` added. No existing APIs changed or broken. Callers who previously used `FromExternC` + call for one-shot invocations can switch to `InvokeExternC` for lower overhead.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

### Creating a typed inline wrapper around an exported symbol
**Context**: Avoiding `Function` object allocation when you only need to call an already-exported C symbol.
```cpp
// Given an exported C symbol (produced by TVM_FFI_DLL_EXPORT_TYPED_FUNC):
// extern "C" int __tvm_ffi_add(void*, const TVMFFIAny*, int32_t, TVMFFIAny*);

// Lightweight typed wrapper -- no heap allocation
inline int add(int a, int b) {
  return tvm::ffi::Function::InvokeExternC(nullptr, __tvm_ffi_add, a, b).cast<int>();
}

// Compare with the FromExternC approach (allocates FunctionObj on heap):
// Function fadd = Function::FromExternC(nullptr, __tvm_ffi_add, nullptr);
// int result = fadd(a, b).cast<int>();
```
