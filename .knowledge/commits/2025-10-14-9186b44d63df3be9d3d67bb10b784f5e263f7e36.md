# Add Function::InvokeExternC for direct extern C symbol invocation without FunctionObj allocation
## TL;DR
- Adds `Function::InvokeExternC(handle, safe_call, args...)`, a static template method that directly calls an extern "C" function matching `TVMFFISafeCallType` without constructing a `FunctionObj` wrapper.
- This is a lightweight alternative to the existing `FromExternC` + `operator()` path, eliminating one heap allocation and ref-counting overhead for fire-and-forget calls to known symbols.
- Includes a C++ GoogleTest exercising the new method against `__tvm_ffi_testing_add1`.

## Key Exports

**Functions**:
```cpp
// Static method on tvm::ffi::Function (include/tvm/ffi/function.h)
template <typename... Args>
static Any Function::InvokeExternC(void* handle, TVMFFISafeCallType safe_call, Args&&... args);
```
- `handle`: Opaque pointer passed as the first argument to `safe_call`. For exported symbols this is typically `nullptr`.
- `safe_call`: A C function pointer matching `TVMFFISafeCallType` signature: `int(void*, const TVMFFIAny*, int32_t, TVMFFIAny*)`.
- `args...`: Variadic typed arguments, packed into `AnyView` array via `PackedArgs::Fill`.
- Returns: `Any` containing the result. Throws via `TVM_FFI_CHECK_SAFE_CALL` on non-zero return code.

## Impact
- API: Adds one new public static method to `Function`. No existing API is changed or removed.
- ABI: None. Header-only template addition; no changes to `TVMFFISafeCallType`, `FunctionObj` layout, or C ABI symbols.
- Behavioral: None. Existing call paths (`operator()`, `FromExternC`) are unaffected.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- Packed calling convention (`TVMFFISafeCallType`) and `PackedArgs::Fill` argument packing -- see `.knowledge/designs/function-system.md`
- `TVM_FFI_CHECK_SAFE_CALL` macro for error translation from C return codes to C++ exceptions
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro for producing `__tvm_ffi_*` symbol exports -- see `.knowledge/designs/0013-module-system.md`

Design elements this commit produces:
- The `InvokeExternC` static call pattern: a zero-allocation shortcut for invoking a known `TVMFFISafeCallType` function pointer with typed arguments

## Usage Examples

Wrapping an already-exported extern "C" symbol as a typed inline function (from the Doxygen comment and test):

```cpp
// Given an exported symbol produced by TVM_FFI_DLL_EXPORT_TYPED_FUNC:
//   extern "C" int __tvm_ffi_add(void*, const TVMFFIAny*, int32_t, TVMFFIAny*);

// Before (allocates FunctionObj):
Function fadd = Function::FromExternC(nullptr, __tvm_ffi_add, nullptr);
int result = fadd(1, 2).cast<int>();

// After (direct call, no allocation):
int result = Function::InvokeExternC(nullptr, __tvm_ffi_add, 1, 2).cast<int>();
```

The method body mirrors `Function::operator()` but replaces the `FunctionObj::CallPacked` dispatch with a direct `safe_call(handle, ...)` invocation, removing the object dereference, `cpp_call` vs `safe_call` branching, and ref-count overhead.
