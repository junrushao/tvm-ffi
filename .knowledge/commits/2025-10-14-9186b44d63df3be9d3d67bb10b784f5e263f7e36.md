# Introduce Function::InvokeExternC for direct SafeCall symbol invocation without Function object

## TL;DR
- Adds `Function::InvokeExternC(handle, safe_call, args...)` static method that directly invokes an `extern "C"` function following the `TVMFFISafeCallType` convention, bypassing `ffi::Function` object construction.
- Enables lightweight typed wrappers around exported C symbols with minimal overhead.

## Key Exports

**Static method: `Function::InvokeExternC`** (`include/tvm/ffi/function.h`):
```cpp
template <typename... Args>
static Any InvokeExternC(void* handle, TVMFFISafeCallType safe_call, Args&&... args);
```
- Packs arguments into `AnyView[]` via `PackedArgs::Fill`.
- Invokes `safe_call(handle, args_pack, num_args, &result)` directly.
- Checks return code via `TVM_FFI_CHECK_SAFE_CALL`.
- Returns `Any` (the caller typically `.cast<T>()` to extract the typed result).
- `handle` is typically `nullptr` for exported symbols.

## Impact
- API: New public static method on `Function`. Additive, non-breaking.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

From the test and docstring in this commit:
```cpp
// Given an exported extern "C" symbol:
extern "C" int __tvm_ffi_testing_add1(
    void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result);

// Direct invocation without Function object:
int result = Function::InvokeExternC(nullptr, __tvm_ffi_testing_add1, 1).cast<int>();
// result == 2
```
