# Add Function::InvokeExternC static method to call SafeCall-convention symbols without constructing a Function object

## TL;DR

- Adds `Function::InvokeExternC(handle, safe_call, args...)` — a static template method that invokes a `TVMFFISafeCallType` symbol directly on stack with zero heap allocation, bypassing `FunctionObj` construction.
- Complements the existing `Function::FromExternC` path: use `FromExternC` when the symbol needs to be stored or passed around as a `Function` object; use `InvokeExternC` for a one-shot call where no `Function` wrapper is needed.
- Returns `tvm::ffi::Any` with full error propagation via `TVM_FFI_CHECK_SAFE_CALL`.

## Key Exports

```python
class Function:
    @staticmethod
    def InvokeExternC(handle: void*, safe_call: TVMFFISafeCallType, *args: Args) -> Any:
        """Invoke an extern C SafeCall-convention symbol without constructing a Function object.

        Packs args into a stack-allocated AnyView array via PackedArgs::Fill,
        calls safe_call directly, and returns the result as Any.
        """
        # Interacts with: PackedArgs::Fill (arg packing into AnyView[]),
        #                 TVM_FFI_CHECK_SAFE_CALL (maps -1 return to C++ exception via TLS error slot),
        #                 TVMFFISafeCallType (C ABI safe_call signature),
        #                 AnyView / Any (argument/return value containers)
        # Invariant: safe_call must conform to TVMFFISafeCallType convention;
        #            handle is nullptr for symbols exported with __tvm_ffi_ prefix
        # Extension: covers single-invocation use case; for repeated calls or passing as
        #            a value, prefer Function::FromExternC which produces a Function object

# TVMFFISafeCallType (C ABI, from c_api.h — consumed, not changed):
#   typedef int (*TVMFFISafeCallType)(void* handle, const TVMFFIAny* args,
#                                    int32_t num_args, TVMFFIAny* result);
#   Convention: returns 0 on success, -1 on error (error in TLS slot)
```

## Impact

- API: Additive. New static method `Function::InvokeExternC<Args...>` in `include/tvm/ffi/function.h`. No existing signatures changed.
- Behavioral: None — existing `FromExternC` and `operator()` paths unchanged.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- `TVMFFISafeCallType` (0001-c-abi) — the C ABI function pointer type that `InvokeExternC` requires for its `safe_call` parameter.
- `PackedArgs::Fill` (0004-function-system) — packs variadic typed args into `AnyView[]` for the packed calling convention.
- `TVM_FFI_CHECK_SAFE_CALL` (0004-function-system) — maps the C integer return code to a C++ exception via the TLS error slot.
- `AnyView` / `Any` (0003-any-anyview) — argument array element type and return value type.

Design elements this commit produces:
- `Function::InvokeExternC` — a new static factory-free invocation path on the `Function` class (0004-function-system). Zero-allocation alternative to `FromExternC` for single-shot calls.

## Usage Examples

Example: wrap an exported symbol as a typed C++ function without heap allocation.

```cpp
// An extern "C" function following TVMFFISafeCallType
extern "C" int __tvm_ffi_testing_add1(
    void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
);

// Typed C++ wrapper — no FunctionObj allocation
inline int add1(int x) {
    return tvm::ffi::Function::InvokeExternC(nullptr, __tvm_ffi_testing_add1, x).cast<int>();
}

// Test from tests/cpp/test_function.cc
int invoke_testing_add1(int x) {
    return Function::InvokeExternC(nullptr, __tvm_ffi_testing_add1, x).cast<int>();
}
TEST(Func, InvokeExternC) { EXPECT_EQ(invoke_testing_add1(1), 2); }
```

Contrast with `FromExternC` (allocates a `FunctionObj`):
```cpp
// Use when you need to store or pass the callable as a Function value
Function f = Function::FromExternC(nullptr, __tvm_ffi_testing_add1, nullptr);
int result = f(1).cast<int>();
```
