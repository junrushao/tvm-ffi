# Add begin_index to TypeAttrColumn for sparse attribute storage
## TL;DR
- Adds `begin_index` field to `TVMFFITypeAttrColumn` C ABI struct for sparse attribute storage
- Allows type attribute columns to skip indices below `begin_index`, reducing memory for attributes used only by high-index types

## Key Exports
```python
class TVMFFITypeAttrColumn:
    data: *TVMFFIAny    # attribute values indexed by type_index
    size: int64          # number of entries
    begin_index: int64   # first valid type_index (entries below are skipped)
    # Invariant: valid range is [begin_index, begin_index + size)
```

## Impact
- API: extends `TVMFFITypeAttrColumn` struct
- Behavioral: none for existing code
- Flags/config: none
- Data formats/schemas: `TVMFFITypeAttrColumn` gains `begin_index` field
