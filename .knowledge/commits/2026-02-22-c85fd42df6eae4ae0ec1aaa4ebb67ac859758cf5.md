# Add begin_index to TVMFFITypeAttrColumn to enable sparse, range-bounded type attribute storage

## TL;DR
- Adds `begin_index: int32_t` field to `TVMFFITypeAttrColumn` (C ABI struct) alongside changing `size` from `size_t` to `int32_t`, enabling column arrays to start at an arbitrary type index rather than always from 0.
- All consumers (C++ `AnyHash`/`AnyEqual`, Cython `_lookup_type_attr`, Rust `TVMFFITypeAttrColumn`) are updated to compute `offset = type_index - begin_index` before accessing `data[offset]`, guarding against both under-range and over-range accesses.
- `begin_index` is hardcoded to 0 in the current implementation (noted as a TODO for 1.0) to keep the ABI forward-compatible while laying groundwork for space/locality-optimized sparse column storage.

## Impact
- API: `TVMFFITypeAttrColumn` struct gains `begin_index: int32_t`; `size` changes from `size_t` to `int32_t`. Any C/Rust code that directly accesses `column->size` or embeds the struct by value must recompile. Python Cython binding updated in the same commit — no Python API change.
- Behavioral: `AnyHash` and `AnyEqual` in `any.h` now correctly handle columns that begin at non-zero indices; however, since `begin_index` is always 0 in this release, no behavioral change for existing registrations. Prevents potential out-of-bounds read if a future column has `begin_index > 0`.
- Flags/config: None.
- Data formats/schemas: `TVMFFITypeAttrColumn` is a C ABI wire struct. The field addition and `size_t`→`int32_t` narrowing is an ABI break for any binary that passes this struct across a library boundary without recompiling. The commit message notes this is intentional and safe because current accessors are restricted to `extra/cc`.

## Usage Examples

Before (accessing a TypeAttrColumn without begin_index):
```cpp
// OLD: assumed column starts at index 0
if (custom_hash_column != nullptr &&
    static_cast<size_t>(src.data_.type_index) < custom_hash_column->size) {
  const TVMFFIAny& entry = custom_hash_column->data[src.data_.type_index];
  // ...
}
```

After (accounting for begin_index):
```cpp
// NEW: offset-based lookup
if (custom_hash_column != nullptr) {
  int32_t offset = src.data_.type_index - custom_hash_column->begin_index;
  if (offset >= 0 && offset < custom_hash_column->size) {
    const TVMFFIAny& entry = custom_hash_column->data[offset];
    // ...
  }
}
```

Test demonstrating `begin_index` invariants (tests/cpp/test_reflection.cc):
```cpp
TEST(Reflection, TypeAttrColumnBeginIndex) {
  TVMFFIByteArray attr_name = {"test.size", ...};
  const TVMFFITypeAttrColumn* column = TVMFFIGetTypeAttrColumn(&attr_name);
  ASSERT_NE(column, nullptr);
  EXPECT_GE(column->begin_index, 0);
  EXPECT_GT(column->size, 0);
  // Existing entries still accessible
  reflection::TypeAttrColumn size_attr("test.size");
  EXPECT_EQ(size_attr[TIntObj::RuntimeTypeIndex()].cast<int>(), sizeof(TIntObj));
}
```
