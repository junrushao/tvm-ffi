# Add begin_index to TypeAttrColumn for field layout
## TL;DR
- Adds `begin_index` field to `TVMFFITypeAttrColumn` in the C ABI to indicate where a type's own fields start (after parent fields).
- Updates `TVMFFIFieldInfo` with `field_byte_offset_in_parent` rename to clarify layout semantics.
- Wires the new field through Cython, Rust, and C++ reflection.

## Key Exports

```python
# C ABI struct update:
# TVMFFITypeAttrColumn.begin_index: int32_t
#   Invariant: fields[0..begin_index) belong to parent, fields[begin_index..) belong to this type
# Interacts with: object field accessor, Python Cython object.pxi
```

## Impact
- API: New `begin_index` field in `TVMFFITypeAttrColumn`.
- Behavioral: Enables correct field iteration for inherited types.
- Flags/config: None
- Data formats/schemas: C ABI struct layout change (additive).
