# Add begin_index to TVMFFITypeAttrColumn for sparse type index range support

## TL;DR
- `TVMFFITypeAttrColumn` gains `begin_index: int32_t` field alongside `size: int32_t` (was `size_t`). Data is now accessed as `data[type_index - begin_index]`.
- All `AnyHash`/`AnyEqual` lookups updated to use offset-based access.
- `begin_index` is 0 for now (TODO for 1.0: set to first registered index for sparse columns).

## Key Exports

```python
# C ABI struct: include/tvm/ffi/c_api.h
class TVMFFITypeAttrColumn:
    data: Ptr[TVMFFIAny]     # indexed by (type_index - begin_index)
    size: int32_t            # was size_t — now int32
    begin_index: int32_t     # NEW: starting type index; currently always 0
    # Invariant: valid range = [begin_index, begin_index + size)
    # Access: data[type_index - begin_index] iff begin_index <= type_index < begin_index + size
    # Interacts with: AnyHash, AnyEqual, StructuralHash, StructuralEqual, TypeTable

# C++ column lookup pattern (any.h, accessor.h):
# offset = type_index - column->begin_index
# if offset >= 0 && offset < column->size: use column->data[offset]
```

## Impact
- API: `TVMFFITypeAttrColumn.size` changed from `size_t` to `int32_t`. New `begin_index: int32_t` field added. **ABI break** if any external code accesses `TVMFFITypeAttrColumn` by offset. Rust bindings updated (`c_api.rs`). Python Cython bindings updated (`base.pxi`, `object.pxi`).
- Behavioral: Functionally identical (begin_index = 0 always for now). Prepares for sparse storage in v1.0.
- Flags/config: `TODO(1.0)` comment in `object.cc` marks planned migration.
- Data formats/schemas: none

## Usage Examples

```cpp
// Column access pattern after this change:
const TVMFFITypeAttrColumn* col = GetTypeAttrColumn("__any_hash__");
if (col != nullptr) {
    int32_t offset = type_index - col->begin_index;
    if (offset >= 0 && offset < col->size) {
        const TVMFFIAny& fn = col->data[offset];
        // use fn
    }
}
```
