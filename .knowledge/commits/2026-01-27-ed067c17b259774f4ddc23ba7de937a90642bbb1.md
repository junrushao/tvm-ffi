# Add compile-time `#embed` support check to cpp_embed example CMake
## TL;DR
- Adds a `CheckCXXSymbolExists` guard for `__cpp_pp_embed` in the `cpp_embed` example's CMakeLists.txt, so the build fails early with a clear message if the compiler lacks C++23 `#embed` support.
- The check is placed after `set(CMAKE_CXX_STANDARD 26)` because compilers like GCC only define the feature-test macro when the standard is active.
