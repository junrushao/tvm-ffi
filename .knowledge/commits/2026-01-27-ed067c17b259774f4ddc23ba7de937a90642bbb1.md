# Add early CMake #embed feature detection in cubin launcher cpp_embed example

## TL;DR
- Adds `CheckCXXSymbolExists(__cpp_pp_embed)` check in `examples/cubin_launcher/embedded_cubin/cpp_embed/CMakeLists.txt` after `set(CMAKE_CXX_STANDARD 26)`.
- CMake now emits `FATAL_ERROR` immediately if compiler lacks `#embed` support (GCC 15+, Clang 19+ required) rather than failing later during compilation.
