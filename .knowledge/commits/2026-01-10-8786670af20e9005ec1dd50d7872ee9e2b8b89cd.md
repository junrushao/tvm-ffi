# Add Function.__init__ to convert Python callables to tvm_ffi.Function
## TL;DR
- Adds `tvm_ffi.Function.__init__` to enable direct construction of `Function` from Python callables.
- Updates `base_details.h` to support the constructor pattern from C++ side.
- Note: This commit was reverted in 91fcaa8 (#406).

## Impact
- API: adds `Function.__init__` constructor (later reverted)
- Behavioral: enables `tvm_ffi.Function(python_callable)` pattern
- Flags/config: none
