# Add tvm_ffi.Function.__init__ to allow constructing Function from a Python callable

## TL;DR
- Adds `Function.__init__(self, func: Callable)` to the Cython `Function` class in `python/tvm_ffi/cython/function.pxi`, allowing `tvm_ffi.Function(my_python_fn)` to work.
- If `func` is already a `Function`, its handle is IncRef'd and reused; otherwise `_convert_to_ffi_func_handle` wraps the Python callable.
- Minor doc comment fixes in `include/tvm/ffi/base_details.h` (Doxygen `\endcond` placement, `TVM_FFI_STATIC_INIT_BLOCK` doc).
- Adds stub update for `python/tvm_ffi/core.pyi` and 9 lines of test.

## Key Exports

```python
class Function(Object):
    """Packed callable object. Cython class in python/tvm_ffi/cython/function.pxi."""

        # Invariant: func must be callable (raises TypeError otherwise)
        # If func is already a Function, ref-count is incremented (no double-wrap)

        #                  TVMFFIObjectIncRef (C ABI ref-count)
```

## Impact
- API: additive — `Function.__init__` is new; existing callers unaffected.
- Behavioral: `tvm_ffi.Function(some_fn)` now works; previously failed with "Function() takes no arguments".
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
import tvm_ffi

def add(a: int, b: int) -> int:
    return a + b

func = tvm_ffi.Function(add)
assert isinstance(func, tvm_ffi.Function)
assert func(1, 2) == 3

# Wrapping an existing Function is a no-op (handle reuse)
func2 = tvm_ffi.Function(func)
assert func2(1, 2) == 3
```
