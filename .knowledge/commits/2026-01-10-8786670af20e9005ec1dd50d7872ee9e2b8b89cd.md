# Add tvm_ffi.Function.__init__ to construct Function from Python callable
## TL;DR
- Adds `Function.__init__(self, func: Callable[..., Any])` in Cython (`python/tvm_ffi/cython/function.pxi`), enabling direct construction of `tvm_ffi.Function` from a Python callable or another `Function` instance.
- If `func` is already a `Function`, increments refcount and reuses the handle; otherwise calls `_convert_to_ffi_func_handle` to wrap the Python callable.
- Updates `core.pyi` type stub and adds Doxygen comment improvements to `base_details.h` (unrelated cleanup bundled in).

## Key Exports

**Method** added to `tvm_ffi.Function` (Cython class in `function.pxi`):

```python
def __init__(self, func: Callable[..., Any]) -> None:
    """Initialize a Function from a Python callable."""
```

- Raises `TypeError` if `func` is not callable.
- If `func` is `Function`, copies the handle with `TVMFFIObjectIncRef`.
- Otherwise wraps via `_convert_to_ffi_func_handle`.

## Impact
- API: new constructor on `tvm_ffi.Function`; purely additive
- Behavioral: none (existing code paths unaffected)
- Flags/config: none
- Data formats/schemas: none

- **Python FFI call dispatch** (`.knowledge/designs/0015-python-ffi-call-dispatch.md`) — `_convert_to_ffi_func_handle` for wrapping Python callables into FFI function objects.

Design elements this commit produces:
- Extends `tvm_ffi.Function` with an explicit constructor, providing a first-class API for wrapping Python callables (previously only possible via implicit conversion in `register_global_func` or argument passing).

## Usage Examples
```python
import tvm_ffi

def add(a: int, b: int) -> int:
    return a + b

func = tvm_ffi.Function(add)
assert isinstance(func, tvm_ffi.Function)
assert func(1, 2) == 3
```
