# Remove static inline object registration in favor of ObjectDef
## TL;DR
- Removes the automatic static-inline type registration triggered by `TVM_FFI_DECLARE_OBJECT_INFO` macros, which caused per-DLL overhead even for unused classes.
- Object types now require explicit registration via `reflection::ObjectDef<T>` for dynamic casting to work. Built-in types are pre-registered in `object.cc`.
- Reduces binary size and initialization overhead for shared libraries.

## Impact
- API: Objects not registered via `ObjectDef` will not support dynamic casting. This is an intentional trade-off.
- Flags/config: None.
- Data formats/schemas: None.
