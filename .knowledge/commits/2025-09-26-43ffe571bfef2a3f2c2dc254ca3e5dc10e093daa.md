# Only attach docstring to fields/methods when explicitly defined
## TL;DR
- Reverts auto-generated default docstrings for fields and methods that conflicted with Sphinx doc generation.
- `TypeField.as_property()` and `TypeMethod.as_callable()` now only set `__doc__` when `self.doc` is truthy.
- Adds explicit doc strings to `TestIntPairObj` fields `a` and `b` in `testing.cc` to exercise the fix.

## Key Exports

```python
class TypeField:
    """Reflection field descriptor."""
    def as_property(self, cls: type) -> property:
        # Changed: only sets ret.__doc__, fget.__doc__, fset.__doc__ when self.doc is truthy
        # Invariant: if self.doc is None/empty, property.__doc__ remains None
        ...

class TypeMethod:
    """Reflection method descriptor."""
    def as_callable(self, cls: type) -> Callable:
        # Changed: only sets func.__doc__ when self.doc is truthy
        ...
```

## Impact
- API: None
- Behavioral: Properties/methods without explicit doc now have `__doc__ = None` instead of auto-generated text.
- Flags/config: None
