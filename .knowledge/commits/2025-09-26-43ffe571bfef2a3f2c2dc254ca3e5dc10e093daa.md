# Only attach docstring to fields/methods when explicitly defined

## TL;DR
- Fixes `TypeField.as_property` and `TypeMethod.as_callable` to only set `__doc__` when the C++ reflection metadata provides a non-empty docstring, instead of generating a default docstring.
- Previously (from PR #49), auto-generated fallback docstrings like `"Property name of class Foo"` were always set even when no doc was defined in C++.

## Key Exports
None (behavioral fix to existing methods)

## Impact
- API: none
- ABI: none
- Behavioral: Fields/methods without C++ docstrings now have `None` as `__doc__` instead of auto-generated placeholder text.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```python
# Fields with explicit C++ doc
assert type(obj).a.__doc__ == "Field `a`"  # from def_ro("a", ..., "Field `a`")
# Fields without doc: __doc__ is None
assert type(obj).some_field.fget.__doc__ is None
```
