# Only attach docstrings to reflected fields/methods when explicitly defined
## TL;DR
- Reverts commit `98cb8af`'s behavior of generating fallback docstrings for reflected fields and methods when no C++ docstring is registered. Now `__doc__` is `None` when not explicitly set, fixing conflicts with upstream Sphinx documentation generation.
- Adds explicit docstrings (`"Field \`a\`"`, `"Field \`b\`"`) to `TestIntPairObj` fields in `testing.cc` for test coverage.

## Impact
- API: `TypeField.as_property()` and `TypeMethod.as_callable()` no longer generate default docstrings. Fields/methods without C++-registered docs will have `__doc__ = None`.
