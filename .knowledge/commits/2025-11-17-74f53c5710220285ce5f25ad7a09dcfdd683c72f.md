# Remove --no-as-needed linker flag from Linux torch C DLPack JIT build
## TL;DR
- Removes `-Wl,--no-as-needed` from the default Linux linker flags in `_build_optional_torch_c_dlpack.py`.
- The flag was unnecessary for the extension build; removing it simplifies the linker invocation.
- macOS path unchanged (already did not use this flag).

## Key Exports
None

## Impact
- API: none
- Behavioral: none -- `--no-as-needed` tells the linker to keep all specified shared libraries even if no symbols are referenced; removing it allows the linker to drop unused libraries, which is the default behavior. For this extension (which explicitly links only needed libraries), the flag had no practical effect.
- Flags/config: none
- Data formats/schemas: none
