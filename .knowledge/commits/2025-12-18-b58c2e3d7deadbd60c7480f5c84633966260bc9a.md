# Add --init-* flags to tvm-ffi-stubgen for bootstrapping new FFI packages
## TL;DR
- Adds `--init-pypkg`, `--init-lib`, `--init-prefix` CLI flags that generate `_ffi_api.py` and `__init__.py` from scratch for new FFI extension packages, enabling single-command package bootstrapping.
- Introduces four new stub block kinds (`import-section`, `import-object`, `export`, plus `@` syntax in `global/`), a new `lib_state.py` module for runtime metadata queries, and the `ImportItem`/`InitConfig` dataclasses.
- Refactors the pipeline from 5 stages to 6 (adds Stage 2 for init-mode generation between ty-map collection and existing stub processing), relocates `testing` utilities from `examples/packaging/` to `python/tvm_ffi/testing/`, and deletes `analysis.py`.

## Impact
- API: New CLI flags (`--init-pypkg`, `--init-lib`, `--init-prefix`, `--imports`). `--dlls` changed from nargs to semicolon-separated. `global/` blocks now support `@import_from` suffix. Block kind `"import"` renamed to `"import-section"`.
- Behavioral: The tool can now generate entire `_ffi_api.py` and `__init__.py` files from scratch. Existing block processing is now Stage 3 (was Stage 2). `__all__` ordering changed to isort-style (UPPER, CamelCase, lower).
- Flags/config: Three new required-together flags: `--init-pypkg`, `--init-lib`, `--init-prefix`. New optional `--imports` flag.
- Data formats/schemas: New marker directives `import-object` and `export/<submodule>`. `global/` blocks extended with `@<import_from>` syntax.

## Design Elements
Design elements this commit consumes:
- **Global function registry** ([0004-ffi-function-system](../design-records/0004-ffi-function-system.md)): `collect_global_funcs()` queries `list_global_func_names()` and `get_global_func_metadata()`.
- **Reflection system** ([0007-ffi-reflection](../design-records/0007-ffi-reflection.md)): `object_info_from_type_key()` queries `_lookup_or_register_type_info_from_type_key()` for field/method metadata.
- **Python type system** ([0015-ffi-python-type-system](../design-records/0015-ffi-python-type-system.md)): `TypeSchema`, `TypeInfo` consumed for schema parsing and type info construction.
- **Module system** ([0011-ffi-module-system](../design-records/0011-ffi-module-system.md)): `load_lib_module` imported in generated `_ffi_api.py` for library loading.
- **Packaging pattern** ([0013-ffi-packaging-and-distribution](../design-records/0013-ffi-packaging-and-distribution.md)): The `my_ffi_extension` example is the canonical consumer.

Design elements this commit produces:
- **Init-mode generation pipeline**: New Stage 2 (`_stage_2()`) that generates `_ffi_api.py` and `__init__.py` files from runtime metadata, including topologically sorted object class definitions with inheritance-aware parent imports.
- **`ImportItem` dataclass**: Type-safe import tracking replacing the ad-hoc `ty_used: set[str]` approach, with MOD_MAP rewriting at construction.
- **`InitConfig` dataclass**: Encapsulates `--init-*` flag triad for package bootstrapping configuration.
- **`lib_state.py` module**: Centralized, cached runtime metadata queries (replaces `analysis.py`), with `toposort_objects()` for inheritance-ordered class emission.
- **New marker directives**: `import-object` for explicit custom imports, `export/<submodule>` for `__all__` re-export boilerplate, `@<import_from>` syntax on `global/` blocks.
- **`tvm_ffi.testing` subpackage**: Relocated from `examples/packaging/python/my_ffi_extension/` to canonical location under `python/tvm_ffi/testing/`.

## Usage Examples

Single-command package bootstrapping from CLI:
```bash
tvm-ffi-stubgen examples/packaging/python \
  --dlls examples/packaging/build/libmy_ffi_extension.dylib \
  --init-pypkg  my-ffi-extension \
  --init-lib    my_ffi_extension \
  --init-prefix "my_ffi_extension."
```

Generated `_ffi_api.py` (abbreviated):
```python
# tvm-ffi-stubgen(import-object): tvm_ffi.libinfo.load_lib_module;False;_FFI_LOAD_LIB
LIB = _FFI_LOAD_LIB("my-ffi-extension", "my_ffi_extension")
# tvm-ffi-stubgen(begin): global/my_ffi_extension
# fmt: off
_FFI_INIT_FUNC("my_ffi_extension", __name__)
if TYPE_CHECKING:
    def raise_error(_0: str, /) -> None: ...
# fmt: on
# tvm-ffi-stubgen(end)
# tvm-ffi-stubgen(import-object): tvm_ffi.register_object;False;_FFI_REG_OBJ
@_FFI_REG_OBJ("my_ffi_extension.IntPair")
class IntPair(_ffi_Object):
    # tvm-ffi-stubgen(begin): object/my_ffi_extension.IntPair
    ...
    # tvm-ffi-stubgen(end)
```

Generated `__init__.py`:
```python
# tvm-ffi-stubgen(begin): export/_ffi_api
from ._ffi_api import *  # noqa: F403
from ._ffi_api import __all__ as _ffi_api__all__
if "__all__" not in globals():
    __all__ = []
__all__.extend(_ffi_api__all__)
# tvm-ffi-stubgen(end)
```
