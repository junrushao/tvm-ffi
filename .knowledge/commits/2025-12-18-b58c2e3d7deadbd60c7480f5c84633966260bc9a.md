# Add package-level stub generation with --init-* flags to stubgen
## TL;DR
- Extends `tvm-ffi-stubgen` with whole-package generation capability via `--init-*` flags.
- Generates `__init__.py` files with proper imports, `__all__` exports, and type stubs for entire Python packages.
- Major refactoring of the stubgen pipeline to support recursive package traversal.

## Key Exports

**CLI Flags:**
- `--init-imports` -- Generate import statements in `__init__.py`.
- `--init-all` -- Generate `__all__` lists in `__init__.py`.
- Package-level generation mode for processing entire directory trees.

## Impact
- API: New stubgen CLI flags for package generation.
- ABI: none
- Behavioral: stubgen can now process entire packages, not just individual files.
- Flags/config: New `--init-*` CLI flags.
- Data formats/schemas: none
