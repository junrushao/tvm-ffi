# Add CONTRIBUTING.md, fix repository URLs, and bump version to 0.1.0b1
## TL;DR
- Adds a new `CONTRIBUTING.md` with installation instructions, contribution workflow, stability philosophy, and release versioning policy (RFC stage, `0.X.Y` scheme).
- Fixes stale GitHub URLs throughout: `apache/tvm/blob/main/ffi/` -> `apache/tvm-ffi/blob/main/` in `docs/concepts/abi_overview.md` and `pyproject.toml` project URLs.
- Bumps Python package version from `0.1.0b0` to `0.1.0b1`.

## Design Elements
Design elements this commit consumes:
- **C ABI stability philosophy** (`.knowledge/designs/c-abi.md`) -- the `CONTRIBUTING.md` explicitly codifies that C ABI stability is the top priority and that changes should first consider building on top of existing mechanisms.
- **Release versioning convention** -- establishes the `0.X.Y` scheme where `X` bumps signal ABI-breaking changes and `Y` bumps signal non-breaking changes during the RFC stage.

Design elements this commit produces:
- **Contribution workflow** -- `CONTRIBUTING.md` defines the fork-branch-PR-review workflow, editable install instructions (`pip install --no-build-isolation -e . -v`), and RFC discussion process for significant changes.
- **Repository URL migration** -- canonicalizes the repository URL from `github.com/apache/tvm/ffi` (subdirectory of tvm monorepo) to `github.com/apache/tvm-ffi` (standalone repository), reflecting the project's extraction into its own repo.
