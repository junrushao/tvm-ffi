# Fix cibuildwheel test-extras → test-groups after test deps moved to dependency-group

## TL;DR
- PR #441 moved `test` from `optional-dependencies` to `dependency-groups` in `pyproject.toml`, breaking wheel smoke-testing.
- `cibuildwheel` uses `test-groups` (not `test-extras`) to install dependency-groups; this commit fixes the key name.
- One-line change in `[tool.cibuildwheel]`: `test-extras = ["test"]` → `test-groups = ["test"]`.
