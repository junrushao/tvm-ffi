# Fix cibuildwheel wheel test configuration broken by test dep group migration
## TL;DR
- One-line fix in `pyproject.toml`: changes `test-extras = ["test"]` to `test-groups = ["test"]` in `[tool.cibuildwheel]` config.
- Corrects the breakage introduced by PR #441 (e08dd68), which moved `test` from `[project.optional-dependencies]` to `[dependency-groups]`. `cibuildwheel` uses `test-extras` for optional deps and `test-groups` for dependency groups.
