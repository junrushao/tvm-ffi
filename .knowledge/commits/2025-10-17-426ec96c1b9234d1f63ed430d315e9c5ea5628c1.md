## Usage Examples
The commit itself adds a usage example. Cross-layer trace from the new IntPair example:

```cpp
// C++ (examples/packaging/src/extension.cc) -- define and register
class IntPairObj : public tvm::ffi::Object {
 public:
  int64_t a, b;
  IntPairObj(int64_t a, int64_t b) : a(a), b(b) {}
  int64_t GetFirst() const { return this->a; }
  TVM_FFI_DECLARE_OBJECT_INFO_FINAL("my_ffi_extension.IntPair", IntPairObj, tvm::ffi::Object);
};
// Registration in TVM_FFI_STATIC_INIT_BLOCK:
// refl::ObjectDef<IntPairObj>().def(refl::init<int64_t,int64_t>())
//   .def_static("static_get_second", ...).def("get_first", ...).def_ro("a",...).def_ro("b",...)
```

```python
# Python (examples/packaging/run_example.py) -- consume
pair = my_ffi_extension.IntPair(1, 2)
print(pair.get_first())  # -> 1
print(my_ffi_extension.IntPair.static_get_second(pair))  # -> 2
```
