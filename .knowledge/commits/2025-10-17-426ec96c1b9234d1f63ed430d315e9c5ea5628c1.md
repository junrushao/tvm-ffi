# Rename and expand packaging guide to Python Binding and Packaging, add IntPair example
## TL;DR
- Renamed `docs/guides/packaging.md` to `docs/guides/python_packaging.md` and substantially rewrote it as "Python Binding and Packaging", adding sections on pybind11/nanobind-style usage, design philosophy, mixing with existing solutions, and wheel auditing.

## Usage Examples
The rewritten guide itself serves as the usage example. The key new end-to-end trace (C++ definition to Python usage) for the `IntPair` object is:

**C++ side** (`examples/packaging/src/extension.cc`):
```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  refl::ObjectDef<IntPairObj>()
      .def(refl::init<int64_t, int64_t>())
      .def_static("static_get_second", [](IntPair pair) -> int64_t { return pair->b; })
      .def("get_first", &IntPairObj::GetFirst)
      .def_ro("a", &IntPairObj::a)
      .def_ro("b", &IntPairObj::b);
}
```

**Python side** (`examples/packaging/python/my_ffi_extension/__init__.py`):
```python
@tvm_ffi.register_object("my_ffi_extension.IntPair")
class IntPair(tvm_ffi.Object):
    def __init__(self, a: int, b: int) -> None:
        self.__ffi_init__(a, b)

pair = IntPair(1, 2)
pair.get_first()                      # -> 1
IntPair.static_get_second(pair)       # -> 2
```
