# Add TVM_FFI_CHECK macro for typed error checking

## TL;DR
- Adds `TVM_FFI_CHECK(ErrorKind, cond)` macro that throws a specific error kind (e.g. `ValueError`, `IndexError`) when condition fails, complementing the existing `TVM_FFI_ICHECK` (which always throws `InternalError`).
- Includes tests for `ValueError`, `IndexError`, and passing conditions.

## Key Exports

**Macros**:
- `TVM_FFI_CHECK(ErrorKind, cond)` -- if `!(cond)`, throws `TVM_FFI_THROW(ErrorKind) << "Check failed: (" #cond ") is false: "`. Supports stream-style message appending.

## Impact
- API: New macro `TVM_FFI_CHECK` in `include/tvm/ffi/error.h`.
- ABI: none
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Error handling** (`.knowledge/designs/error-handling.md`): `TVM_FFI_THROW`, `TVM_FFI_ICHECK`, error kind system

Design elements this commit produces:
- **TVM_FFI_CHECK macro**: user-facing typed check macro, completing the error checking API alongside `TVM_FFI_ICHECK`.

## Usage Examples
```cpp
TVM_FFI_CHECK(ValueError, value >= 0) << "Value must be non-negative, got " << value;
TVM_FFI_CHECK(IndexError, idx < size) << "Index out of bounds";
```
