# Add TVM_FFI_CHECK macro for user-specified error kind with condition stringification
## TL;DR
- Adds `TVM_FFI_CHECK(ErrorKind, cond)` macro that throws a specified error kind (e.g., `ValueError`, `IndexError`) with the condition string, complementing the existing `TVM_FFI_ICHECK` which always throws `InternalError`.
- Adds tests for `ValueError`, `IndexError`, and passing conditions.

## Impact
- API: New `TVM_FFI_CHECK` macro in `error.h`.
- Flags/config: None
- Data formats/schemas: None

Design elements this commit produces:
