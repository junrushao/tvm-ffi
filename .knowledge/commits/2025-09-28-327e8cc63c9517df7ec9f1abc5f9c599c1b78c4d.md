# Add TVM_FFI_CHECK macro for condition checks with user-specified error kinds
## TL;DR
- Introduces `TVM_FFI_CHECK(ErrorKind, cond)` macro in `error.h`, generalizing `TVM_FFI_ICHECK(x)` to allow callers to specify any error kind (e.g., `ValueError`, `IndexError`) rather than being hardcoded to `InternalError`.
- Adds three GoogleTest cases (`ValueError`, `IndexError`, `PassingCondition`) exercising the new macro.

## Key Exports

**Macros**:
```cpp
#define TVM_FFI_CHECK(ErrorKind, cond) \
  if (!(cond)) TVM_FFI_THROW(ErrorKind) << "Check failed: (" #cond << ") is false: "
```
- `ErrorKind`: unquoted identifier (e.g., `ValueError`, `IndexError`, `InternalError`) -- stringified by `TVM_FFI_THROW`.
- `cond`: boolean expression to check; if false, throws `Error` with the specified kind.
- Returns a stream (`std::ostringstream&`) so callers can append context via `<< ...`.

Relationship to existing macros:
| Macro | Error kind | Condition style |
|-------|-----------|----------------|
| `TVM_FFI_ICHECK(x)` | Always `InternalError` | Single boolean |
| `TVM_FFI_ICHECK_LT(x,y)` etc. | Always `InternalError` | Binary comparison |
| **`TVM_FFI_CHECK(ErrorKind, cond)`** | **User-specified** | **Single boolean** |

## Impact
- API: Purely additive. New public macro in `include/tvm/ffi/error.h`. No existing callers affected.
- Behavioral: None -- no changes to existing functions or macros.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **`TVM_FFI_THROW(ErrorKind)`** macro ([0006-error-handling.md](../designs/0006-error-handling.md)) -- the new macro delegates to `TVM_FFI_THROW` for the actual error construction and throw.
- **Error kind string convention** ([0006-error-handling.md](../designs/0006-error-handling.md)) -- error kinds are unquoted identifiers stringified by the macro, matching Python exception names (e.g., `ValueError`, `IndexError`).
- **`ErrorBuilder` stream pattern** ([0006-error-handling.md](../designs/0006-error-handling.md)) -- the macro returns an `ostringstream&` for appending context, consistent with `TVM_FFI_ICHECK` and `TVM_FFI_THROW`.

Design elements this commit produces:
- **`TVM_FFI_CHECK(ErrorKind, cond)` macro** -- a new member of the check macro family that fills the gap between `TVM_FFI_THROW` (manual throw, no condition) and `TVM_FFI_ICHECK` (condition check, but locked to `InternalError`). Enables idiomatic one-liner validation with appropriate error kinds for user-facing errors.

## Usage Examples
**Context**: Validate a function argument and throw a specific error kind if invalid.
```cpp
#include <tvm/ffi/error.h>

void SetDimension(int64_t dim) {
  TVM_FFI_CHECK(ValueError, dim > 0)
      << "dimension must be positive, got " << dim;
  // ... proceed with valid dim
}

void GetElement(int index, int size) {
  TVM_FFI_CHECK(IndexError, index >= 0 && index < size)
      << "Index " << index << " out of bounds for array of size " << size;
  // ... proceed with valid index
}

// Passing conditions are no-ops:
TVM_FFI_CHECK(ValueError, true);  // does nothing
```
