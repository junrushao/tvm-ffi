# Add TVM_FFI_CHECK macro with configurable error kind
## TL;DR
- Introduces `TVM_FFI_CHECK(ErrorKind, cond)` macro that throws a specified error kind on check failure, complementing the existing `TVM_FFI_ICHECK` which always throws `InternalError`.
- Adds tests for `ValueError`, `IndexError`, and passing conditions.

## Key Exports

```python
# C++ macro (pseudocode)
def TVM_FFI_CHECK(ErrorKind, cond):
    """Check condition, throw ErrorKind on failure."""
    # if not cond: TVM_FFI_THROW(ErrorKind) << "Check failed: (cond) is false: "
    # Interacts with: TVM_FFI_THROW, ErrorBuilder
    # Extension: use for user-facing checks where InternalError is too generic
    ...
```

## Impact
- API: New public macro `TVM_FFI_CHECK(ErrorKind, cond)`.
- Behavioral: None (additive only)
- Flags/config: None
- Data formats/schemas: None

## Usage Examples
```cpp
int value = -5;
TVM_FFI_CHECK(ValueError, value >= 0) << "Value must be non-negative, got " << value;
// Throws ValueError with message including the condition text
```
