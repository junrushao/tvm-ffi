# Add TVM_FFI_CHECK macro for condition checks that throw user-specified error kinds

## TL;DR

- Adds `TVM_FFI_CHECK(ErrorKind, cond)` macro to `include/tvm/ffi/error.h` as a complement to `TVM_FFI_ICHECK`, allowing callers to throw any registered error kind (e.g. `ValueError`, `IndexError`) rather than being locked into `InternalError`.
- Adds three GoogleTest cases (`ValueError`, `IndexError`, `PassingCondition`) to `tests/cpp/test_error.cc` covering the new macro's message format, error kind, and no-throw path.

## Key Exports

```python
# Macro: TVM_FFI_CHECK(ErrorKind, cond)
# Expands to:
#   if (!(cond)) TVM_FFI_THROW(ErrorKind) << "Check failed: (" #cond ") is false: "
# ErrorKind: any unquoted error type name registered with the error system
#             (e.g. ValueError, IndexError, RuntimeError, TypeError)
# cond: any boolean expression
# Interacts with: TVM_FFI_THROW (which wraps ErrorBuilder + TVMFFIBacktrace)
# Invariant: message stream after << appends context to the "Check failed" prefix
# Extension: ErrorKind is a literal token, not a string — add new kinds by defining
#            new Error subclasses or registering them via the error system
#
# Contrast with TVM_FFI_ICHECK(x):
#   always throws InternalError — for programmer-assertion failures
# TVM_FFI_CHECK(ErrorKind, cond):
#   throws caller-specified kind — for user-facing validation (ValueError, IndexError, etc.)
```

## Impact

- API: Additive only. `TVM_FFI_CHECK` is a new macro; no existing macro is changed.
- Behavioral: None to existing code.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

Validate user input in C++ with a specific error kind:

```cpp
// Validate non-negative value — throws ValueError with structured message
int value = -5;
TVM_FFI_CHECK(ValueError, value >= 0) << "Value must be non-negative, got " << value;

// Validate array index — throws IndexError
int index = 10, array_size = 5;
TVM_FFI_CHECK(IndexError, index < array_size)
    << "Index " << index << " out of bounds for array of size " << array_size;

// Error message format (via error.what()):
//   "... line N: Check failed: (value >= 0) is false: Value must be non-negative, got -5"
```
