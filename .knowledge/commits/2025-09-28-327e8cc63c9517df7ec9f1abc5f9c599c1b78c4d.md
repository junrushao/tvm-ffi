# Add TVM_FFI_CHECK macro for user-facing condition checks with configurable error kind
## TL;DR
- Adds `TVM_FFI_CHECK(ErrorKind, cond)` macro to `error.h`, generalizing `TVM_FFI_ICHECK` to allow caller-specified error kinds (e.g., `ValueError`, `IndexError`) instead of hard-coding `InternalError`.
- Includes three GoogleTest cases: `ValueError` check, `IndexError` check, and passing-condition no-throw verification.

## Key Exports

```python
# Macro expansion (pseudocode for TVM_FFI_CHECK(ErrorKind, cond)):
# if (!(cond)) TVM_FFI_THROW(ErrorKind) << "Check failed: (" #cond ") is false: "
# Returns an ostringstream for appending user-specified messages via <<
# Interacts with: TVM_FFI_THROW, ErrorBuilder stream pattern
# Invariant: ErrorKind must be a valid identifier (e.g., ValueError, IndexError, TypeError)
# Extension: Use any error kind string — no registration needed
```

## Impact
- API: Additive — new public macro `TVM_FFI_CHECK` in `include/tvm/ffi/error.h`. No existing callers affected.
- Behavioral: None — no changes to existing functions.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_THROW(ErrorKind)` macro and `ErrorBuilder` stream pattern ([0005-error-system.md](../designs/0005-error-system.md))
- Error kind string convention (free-form strings, no registration)

Design elements this commit produces:
- `TVM_FFI_CHECK(ErrorKind, cond)` macro — a user-facing check macro that fills the gap between `TVM_FFI_THROW` (manual if-throw) and `TVM_FFI_ICHECK` (internal-only, always `InternalError`). Enables concise one-line validation with correct error categorization.

## Usage Examples
**Context**: Using `TVM_FFI_CHECK` for user-facing validation with specific error kinds. From `tests/cpp/test_error.cc`:

```cpp
// Validate a value with ValueError
int value = -5;
TVM_FFI_CHECK(ValueError, value >= 0) << "Value must be non-negative, got " << value;

// Validate an index with IndexError
int index = 10, array_size = 5;
TVM_FFI_CHECK(IndexError, index < array_size)
    << "Index " << index << " out of bounds for array of size " << array_size;

// Passing conditions are silent (no-throw)
TVM_FFI_CHECK(ValueError, true);  // OK
TVM_FFI_CHECK(IndexError, 5 < 10);  // OK
```
