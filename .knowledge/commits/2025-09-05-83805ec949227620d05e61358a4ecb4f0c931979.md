# Add load_inline for compiling and loading C++/CUDA FFI modules from inline source

## TL;DR
- Introduces `tvm_ffi.cpp.load_inline()`, a Python function that compiles inline C++/CUDA source code into a shared library and loads it as a `Module` via the existing module system.
- Adds a cross-platform `FileLock` utility (`tvm_ffi.utils.lockfile`) for coordinating concurrent builds in the shared cache directory.
- New subpackages `tvm_ffi.cpp` and `tvm_ffi.utils` created as organizational homes for these utilities.

## Impact
- API: New public function `tvm_ffi.cpp.load_inline` and class `tvm_ffi.utils.FileLock`. No changes to existing APIs.
- Behavioral: none -- purely additive
- Flags/config: `TVM_FFI_CACHE_DIR` env var controls build cache location (default `~/.cache/tvm-ffi`). `TVM_FFI_CUDA_ARCH_LIST` env var overrides auto-detected CUDA architecture. `MAX_JOBS` env var limits ninja parallelism. `CXX` env var overrides C++ compiler.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Module system (0011)**: Uses `load_module()` to load the compiled `.so` and return a `Module`. Uses `Module` as return type.
- **Function system (0003)**: Uses `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro via `_decorate_with_tvm_ffi()` to export C++ functions as FFI-callable symbols.
- **C ABI env (0007/0011)**: Example code uses `TVMFFIEnvGetCurrentStream` for CUDA stream passthrough.
- **Python bindings (0012)**: Imports from `tvm_ffi.module` and `tvm_ffi.libinfo` for module loading and include path discovery.

Design elements this commit produces:
- **`tvm_ffi.cpp` subpackage**: New Python package for C++ compilation utilities. Currently contains only `load_inline`.
- **`tvm_ffi.utils` subpackage**: New Python package for general utilities. Currently contains only `FileLock`.
- **Inline module compilation pipeline**: Source hashing -> ninja build generation -> cached compilation -> `load_module()`. This is a new workflow pattern in the codebase.

## Usage Examples

Compile and call a C++ function from Python (from `tests/python/test_load_inline.py`):
```python
import numpy
import tvm_ffi.cpp
from tvm_ffi.module import Module

mod: Module = tvm_ffi.cpp.load_inline(
    name="hello",
    cpp_source=r"""
        void AddOne(DLTensor* x, DLTensor* y) {
          for (int i = 0; i < x->shape[0]; ++i) {
            static_cast<float*>(y->data)[i] = static_cast<float*>(x->data)[i] + 1;
          }
        }
    """,
    cpp_functions={"add_one_cpu": "AddOne"},
)

x = numpy.array([1, 2, 3, 4, 5], dtype=numpy.float32)
y = numpy.empty_like(x)
mod.add_one_cpu(x, y)  # Calls the compiled C++ function via FFI
numpy.testing.assert_equal(x + 1, y)
```
