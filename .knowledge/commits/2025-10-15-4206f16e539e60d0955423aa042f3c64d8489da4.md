# Use heap-allocated singleton for TypeTable to prevent deallocation order issues
## TL;DR
- Changed `TypeTable::Global()` from a static local variable (`static TypeTable inst`) to a heap-allocated pointer (`static TypeTable* inst = new TypeTable()`), intentionally leaking the singleton to ensure it outlives all objects during program shutdown.
- Prevents use-after-destroy when modules being unloaded still need type info from the global TypeTable.
