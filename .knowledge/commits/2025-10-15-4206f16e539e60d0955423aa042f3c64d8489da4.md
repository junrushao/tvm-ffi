# Use heap-allocated leaky singleton for TypeTable to prevent static destruction order issues
## TL;DR
- Changed `TypeTable::Global()` from a function-local static object to a heap-allocated leaky singleton (`new TypeTable()`).
- Prevents use-after-free when other static destructors access the type table during program shutdown.

## Key Exports
None

## Impact
- API: none -- `TypeTable::Global()` still returns `TypeTable*` with the same interface
- Behavioral: none during normal execution; fixes potential crash during program shutdown when static destruction order causes the type table to be freed before its last consumer
- Flags/config: none
- Data formats/schemas: none
