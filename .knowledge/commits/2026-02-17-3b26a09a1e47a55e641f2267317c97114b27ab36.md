# Document field_static_type_index semantics and add comprehensive serialization tests
## TL;DR
- Adds comprehensive documentation to `TVMFFIFieldInfo::field_static_type_index` in `c_api.h` explaining compile-time vs runtime type semantics and serializer usage.
- Adds 364 lines of C++ serialization tests and 515 lines of Python serialization tests.
- Restores `TypeToFieldStaticTypeIndex` / `TypeToRuntimeTypeIndex` template usage in type_traits.h.

## Key Exports

**Documentation** (improved `TVMFFIFieldInfo::field_static_type_index` docs):
- Clarifies this is a compile-time hint, not runtime type. `kTVMFFIAny` for `Any` fields regardless of actual content. Used by serializer to inline POD values (None, Bool, Int, Float, DataType).

## Impact
- API: Documentation-only change to `TVMFFIFieldInfo::field_static_type_index`. No behavioral change.
- Behavioral: none (tests only add coverage)
