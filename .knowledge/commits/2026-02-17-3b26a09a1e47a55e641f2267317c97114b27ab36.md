# Document field_static_type_index and add serialization tests
## TL;DR
- Adds comprehensive documentation to `field_static_type_index` in `TVMFFIFieldInfo` explaining compile-time static type semantics.
- Restores `TypeToFieldStaticTypeIndex` and `TypeToRuntimeTypeIndex` templates in `type_traits.h`.
- Restores POD field inlining in serialization/deserialization.
- Adds 40 C++ and 58 Python serialization tests.

## Key Exports

```python
# TVMFFIFieldInfo.field_static_type_index semantics:
# -1: unknown/composite type (route through node graph)
# >=0: POD type index (None=0, Bool, Int, Float, DataType) for inline serialization
# Interacts with: serializer POD inlining, TypeTraits specializations
```

## Impact
- API: `field_static_type_index` field in `TVMFFIFieldInfo` now properly documented and populated.
- Behavioral: Serializer can now inline POD values, improving serialization efficiency.
- Flags/config: None
- Data formats/schemas: Serialized format now inlines POD field values.
