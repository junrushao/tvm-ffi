# Add always-inline hints to Python call-manager helpers and adjust default stack size
## TL;DR
- Adds `TVM_FFI_INLINE` (`[[gnu::always_inline]]` / `[[msvc::forceinline]]`) attribute to all hot-path functions in `tvm_ffi_python_helpers.h`: `TVMFFIPyArgSetter::operator()`, `FuncCall`, `ConstructorCall`, `SetField`, `SetArgument`, and all free-standing `TVMFFIPy*` entry points.
- Changes default temp stack from `32 * 2 * sizeof(TVMFFIAny)` to `4096 / sizeof(TVMFFIAny)` (page-aligned 4K).
