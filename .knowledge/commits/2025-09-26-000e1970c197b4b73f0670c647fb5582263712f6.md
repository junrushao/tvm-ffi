# Add TVM_FFI_INLINE macro to Python helper dispatch functions and fix temp_stack_ sizing

## TL;DR
- Introduces `TVM_FFI_INLINE` macro (`[[gnu::always_inline]]` / `[[msvc::forceinline]]`) locally in `tvm_ffi_python_helpers.h` and applies it to all 9 hot-path helper functions to guarantee inlining regardless of optimization level.
- Fixes `TVMFFIPyCallManager::temp_stack_` initialization: `kDefaultStackSize` was a dimensionless slot count of 32 (resized to 64 slots via `* 2`); now it is 4096 bytes (page-aligned), yielding 256 slots via `/ sizeof(TVMFFIAny)`.
- Both changes target `tvm_ffi_python_helpers.h` only — no Python, Cython `.pyx`, or C ABI changes.

## Key Exports

```python
# macro: TVM_FFI_INLINE
# Defined in python/tvm_ffi/cython/tvm_ffi_python_helpers.h
# Protected by #ifndef so base_details.h definition wins when the full header chain is included.
# Old: not defined locally (functions marked plain `inline`)
# New:
#   #ifndef TVM_FFI_INLINE
#   #if defined(_MSC_VER)
#     define TVM_FFI_INLINE [[msvc::forceinline]] inline
#   #else
#     define TVM_FFI_INLINE [[gnu::always_inline]] inline
#   #endif
#   #endif
# Interacts with: base_details.h (defines same macro without #ifndef guard; that definition
#                 takes precedence when tvm/ffi headers are included before this file)
# Invariant: same definition as base_details.h — attribute selection is compiler-conditional

class TVMFFIPyCallManager:
    # kDefaultStackSize: size_t — CHANGED
    #   Old: kDefaultStackSize = 32; temp_stack_.resize(kDefaultStackSize * 2)  → 64 TVMFFIAny slots
    #   New: kDefaultStackSize = 4096 (bytes, page-aligned); temp_stack_.resize(kDefaultStackSize / sizeof(TVMFFIAny)) → 256 TVMFFIAny slots
    # Invariant: temp_stack_ holds at least 256 TVMFFIAny entries (sizeof(TVMFFIAny)==16)
    # Invariant: CallStack allocates num_args*2 slots (packed_args + temp obj arrays);
    #            256 slots ÷ 2 = up to 128 args before heap spill (was 32 args)
    # Interacts with: CallStack inline-stack fast path; heap fallback triggered when stack_top_ + num_args*2 > temp_stack_.size()

# Functions now marked TVM_FFI_INLINE (previously plain `inline`):
# TVMFFIPyArgSetter::operator()    — innermost dispatch per arg
# TVMFFIPyCallManager::FuncCall    — outer call entry point (many register params)
# TVMFFIPyCallManager::ConstructorCall
# TVMFFIPyCallManager::SetField
# TVMFFIPyCallManager::SetArgument
# TVMFFIPyFuncCall                 — free function called from Cython function.pxi
# TVMFFIPyConstructorCall
# TVMFFIPyCallFieldSetter
# TVMFFIPyPyObjectToFFIAny
# TVMFFIPyPushTempFFIObject
# TVMFFIPyPushTempPyObject
```

## Impact
- API: None — no public C ABI or Python API changes.
- Behavioral: `temp_stack_` grows from 64 to 256 `TVMFFIAny` slots at `TVMFFIPyCallManager` construction; calls with >32 args no longer unconditionally spill to heap.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `TVMFFIPyCallManager` / `TVMFFIPyCallContext` / `TVMFFIPyArgSetter` (`.knowledge/design-records/0016-py-ffi-call-dispatch.md`) — the entire helper dispatch layer being annotated.
- `TVMFFIAny` (`.knowledge/design-records/0001-c-abi.md`) — `sizeof(TVMFFIAny) == 16` is load-bearing for the new stack size calculation.

Design elements this commit produces:
- `TVM_FFI_INLINE` macro — new local definition in `tvm_ffi_python_helpers.h`, mirrors `base_details.h` definition with `#ifndef` guard. Not yet documented in `.knowledge/design-records/0016-py-ffi-call-dispatch.md`.
- `temp_stack_` sizing invariant — `kDefaultStackSize` is now 4096 bytes (256 slots) instead of 64 slots; the sizing formula `kDefaultStackSize / sizeof(TVMFFIAny)` is now explicit and correct.

## Usage Examples

No new APIs introduced. The change is a correctness/performance annotation on existing functions.

Before (internal constant, old behavior):
```cpp
// kDefaultStackSize = 32
// temp_stack_.resize(32 * 2);  → 64 TVMFFIAny slots → heap spill for calls with >32 args
```

After (new behavior):
```cpp
// kDefaultStackSize = 4096  (bytes, page-aligned)
// temp_stack_.resize(4096 / sizeof(TVMFFIAny));  → 256 TVMFFIAny slots → heap spill for calls with >128 args
```
