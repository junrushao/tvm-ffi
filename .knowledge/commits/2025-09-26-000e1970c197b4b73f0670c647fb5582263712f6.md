# Add TVM_FFI_INLINE hints to Python helper hot-path functions

## TL;DR
- Adds `TVM_FFI_INLINE` (`[[gnu::always_inline]]` / `[[msvc::forceinline]]`) attribute to hot-path functions in `tvm_ffi_python_helpers.h`: `TVMFFIPyArgSetter::operator()`, `FuncCall`, `ConstructorCall`, `SetField`.
- Changes default stack size from 32 elements to 4096 bytes (page-aligned) for better memory allocation patterns.
