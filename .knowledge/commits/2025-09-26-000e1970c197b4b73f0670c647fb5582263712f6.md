# Add always_inline hints to Cython Python helper functions for reliable register passing
## TL;DR
- Defines `TVM_FFI_INLINE` macro (platform-aware `[[gnu::always_inline]]` / `[[msvc::forceinline]]`) and applies it to all hot-path functions in `tvm_ffi_python_helpers.h` -- the C++ helpers called by Cython for Python-to-FFI argument packing and function dispatch.
- Changes `TVMFFIPyCallManager` default stack size from 64 `TVMFFIAny` elements (arbitrary) to 256 elements (4096 bytes / `sizeof(TVMFFIAny)`), making it page-aligned.

## Key Exports

```python
# New macro (C preprocessor, shown as pseudocode):
# TVM_FFI_INLINE = [[gnu::always_inline]] inline   (GCC/Clang)
# TVM_FFI_INLINE = [[msvc::forceinline]] inline     (MSVC)
# Guarded by #ifndef TVM_FFI_INLINE, so a centralized definition takes precedence.
# Interacts with: all TVMFFIPy* free functions and TVMFFIPyCallManager methods

# Functions receiving TVM_FFI_INLINE (replacing plain `inline`):
# TVMFFIPyCallManager::FuncCall(...)
# TVMFFIPyCallManager::ConstructorCall(...)
# TVMFFIPyCallManager::SetField(...)
# TVMFFIPyCallManager::SetArgument(...)   [private]
# TVMFFIPyArgSetter::operator()(...)
# TVMFFIPyFuncCall(...)
# TVMFFIPyConstructorCall(...)
# TVMFFIPyCallFieldSetter(...)
# TVMFFIPyPyObjectToFFIAny(...)
# TVMFFIPyGetDispatchMapSize()
# TVMFFIPyPushTempFFIObject(...)
# TVMFFIPyPushTempPyObject(...)
# Invariant: these are multi-parameter functions on the hot path;
#   without forced inlining, register-passing ABI may spill to stack

# Stack size change (internal to TVMFFIPyCallManager constructor):
# Old: kDefaultStackSize = 32;  temp_stack_.resize(32 * 2) -> 64 elements
# New: kDefaultStackSize = 4096; temp_stack_.resize(4096 / sizeof(TVMFFIAny)) -> 256 elements
# Invariant: page-aligned (4K) to avoid crossing page boundaries in typical call depths
```

## Impact
- API: none
- Behavioral: stack capacity increased from 64 to 256 `TVMFFIAny` elements, reducing heap fallback in deeply-nested or many-argument calls
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVMFFIPyCallManager` dispatcher architecture ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md)) -- all inline hints applied to its methods and the free-function wrappers that delegate to it.
- `TVMFFIAny` 16-byte value layout ([0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md)) -- used to compute page-aligned element count (`4096 / sizeof(TVMFFIAny)`).

Design elements this commit produces:
- `TVM_FFI_INLINE` macro (local definition in `tvm_ffi_python_helpers.h`, guarded by `#ifndef` for future centralization) -- not yet a design element, but a candidate if adopted in other headers.
