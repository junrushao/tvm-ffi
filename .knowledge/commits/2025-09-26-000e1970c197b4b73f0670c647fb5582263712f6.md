# Add TVM_FFI_INLINE (always_inline) hint to Cython Python helper functions and adjust temp_stack_ sizing
## TL;DR
- Defines `TVM_FFI_INLINE` macro locally in `tvm_ffi_python_helpers.h` (MSVC `[[msvc::forceinline]]` / GCC-Clang `[[gnu::always_inline]]`) and applies it to 10 helper functions on the Cython-to-C++ call path.
- Changes `kDefaultStackSize` from 32 (element count) to 4096 (bytes), and divides by `sizeof(TVMFFIAny)` when resizing `temp_stack_`, making the allocation page-aligned (4 KiB).

## Key Exports

```python
# Macro (C preprocessor, pseudocode):
# TVM_FFI_INLINE = [[gnu::always_inline]] inline   (GCC/Clang)
#                = [[msvc::forceinline]] inline     (MSVC)
# Interacts with: every inlined helper below
# Invariant: guarded by #ifndef TVM_FFI_INLINE to avoid redefinition if main headers define it

# --- Functions annotated with TVM_FFI_INLINE (were plain `inline`) ---

# TVMFFIPyArgSetter.operator()  (member)
# TVMFFIPyCallManager.FuncCall  (member)
# TVMFFIPyCallManager.ConstructorCall  (member)
# TVMFFIPyCallManager.SetField  (member)
# TVMFFIPyCallManager.SetArgument  (private member)
# TVMFFIPyFuncCall  (free function)
# TVMFFIPyConstructorCall  (free function)
# TVMFFIPyCallFieldSetter  (free function)
# TVMFFIPyPyObjectToFFIAny  (free function)
# TVMFFIPyGetDispatchMapSize  (free function)
# TVMFFIPyPushTempFFIObject  (free function)
# TVMFFIPyPushTempPyObject  (free function)
# Interacts with: Cython core module (.pyx) which calls these free functions on every FFI invocation
# Invariant: all functions have multiple parameters — inlining avoids register-passing ABI overhead

# --- Constant change ---
# kDefaultStackSize: 32 -> 4096  (bytes, was element count)
# temp_stack_.resize(kDefaultStackSize / sizeof(TVMFFIAny))  (was: kDefaultStackSize * 2)
# Interacts with: TVMFFIPyCallManager::CallStack (uses temp_stack_ for argument marshalling)
# Invariant: 4096 bytes is page-aligned, improving allocation behavior
```

None -- no new public API surface.

## Impact
- API: none -- no signature changes, no new symbols
- Behavioral: potential performance improvement on the Python FFI call path by ensuring the compiler inlines helper functions even at lower optimization levels (O1/O2). The `temp_stack_` default allocation changes from `32 * 2 = 64` TVMFFIAny elements to `4096 / 16 = 256` TVMFFIAny elements (assuming 16-byte TVMFFIAny), which is a 4x increase in pre-allocated argument capacity.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVMFFIPyCallManager` and its call dispatch architecture (0012-python-bindings): the inlining targets are all part of the Cython setter dispatch hot path.
- `TVMFFIAny` layout (0001-any-anyview-value-system, 0007-c-abi): `sizeof(TVMFFIAny)` used to compute `temp_stack_` element count from byte budget.

Design elements this commit produces:
- `TVM_FFI_INLINE` macro definition local to `tvm_ffi_python_helpers.h` -- a parallel definition to avoid pulling in non-C headers. Not a new design element per se, but a deliberate redundancy to keep the helpers header self-contained.
