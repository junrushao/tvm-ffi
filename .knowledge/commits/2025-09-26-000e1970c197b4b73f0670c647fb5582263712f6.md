# Add TVM_FFI_INLINE to Cython Python helper functions and adjust temp stack to 4K page-aligned

## TL;DR
- Replaces `inline` with `TVM_FFI_INLINE` (compiler-forced inlining via `[[gnu::always_inline]]` / `[[msvc::forceinline]]`) on 10 functions in `tvm_ffi_python_helpers.h` to guarantee inlining of the FFI call-path hot functions even below O3.
- Redefines `TVM_FFI_INLINE` locally in the header (guarded by `#ifndef`) to avoid pulling in non-C headers (`base_details.h`) from the Cython extension build.
- Changes `TVMFFIPyCallManager` default temp stack from 64 `TVMFFIAny` slots (32 * 2) to `4096 / sizeof(TVMFFIAny)` slots, making the allocation page-aligned (4K).

## Impact
- API: None -- no signature changes, no new symbols.
- Behavioral: Temp stack default size changes from 64 to ~128 `TVMFFIAny` slots (4096 / 32 bytes per `TVMFFIAny`), meaning fewer heap fallbacks for functions with many arguments. The forced inlining ensures register-passing correctness for functions with many pointer parameters on calling conventions with limited register slots.
- Flags/config: None.
- Data formats/schemas: None.
