# Fix torch DLPack addon to not bail out when torch is absent and handle ABI mismatch AttributeError

## TL;DR
- `build_backend.py`: guard `import torch` with `contextlib.suppress(ModuleNotFoundError)` so wheel builds in torch-free environments no longer fail.
- `_optional_torch_c_dlpack.py`: catch `AttributeError` from `ctypes.CDLL` when `torch_c_dlpack_ext` and torch have different ABI, allowing the JIT fallback path to proceed.
- Both changes restore the two-tier loading invariant: any failure in Tier 1 (AOT probe) must silently fall through to Tier 2 (JIT).

## Key Exports

None — no new public API surface. Both changes are defensive `try/except` and conditional guards inside existing functions.

## Impact
- API: none
- Behavioral: `load_torch_c_dlpack_extension()` now silently continues to JIT path on `AttributeError` (previously would propagate as uncaught exception). `build_backend.build_wheel()` no longer raises `ModuleNotFoundError` when torch is absent — it returns early instead.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **0022-torch-dlpack-addon** — two-tier loading strategy (`load_torch_c_dlpack_extension`, `build_backend.build_wheel`). This commit tightens the Tier 1 failure handling and the build guard.
- **0016-py-ffi-call-dispatch** — DLPackExchangeAPI attribute registration; ABI mismatch between `torch_c_dlpack_ext` and the installed torch is the root cause this commit defends against.

Design elements this commit produces: none.

## Usage Examples

**Bugfix — before/after:**

Before (build_backend.py):
```python
# build_wheel() would raise ModuleNotFoundError if torch not installed
if not _is_lib_prebuilt():
    import torch  # raises ModuleNotFoundError in torch-free CI
    if hasattr(torch.Tensor, "__dlpack_c_exchange_api__") or ...:
        ...
```

After (build_backend.py):
```python
# torch import is optional; build skipped if torch not available
torch = None
with suppress(ModuleNotFoundError):
    import torch

if torch is not None and not _is_lib_prebuilt():
    if hasattr(torch.Tensor, "__dlpack_c_exchange_api__") or ...:
        ...
```

Before (_optional_torch_c_dlpack.py):
```python
try:
    lib = ctypes.CDLL(get_lib_path())
    ...
except ImportError:
    pass
# AttributeError from ABI mismatch propagated uncaught → aborts load
```

After (_optional_torch_c_dlpack.py):
```python
try:
    lib = ctypes.CDLL(get_lib_path())
    ...
except ImportError:
    pass
except AttributeError:
    # torch_c_dlpack_ext and torch have different ABI;
    # ctypes.CDLL raises AttributeError — fall through to JIT
    pass
```
