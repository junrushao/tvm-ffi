# Fix build and load failures when torch is absent or has ABI mismatch with torch_c_dlpack_ext
## TL;DR
- `addons/torch_c_dlpack_ext/build_backend.py`: wrap `import torch` in `suppress(ModuleNotFoundError)` so wheel builds succeed in torch-free environments; guard the compilation block with `if torch is not None`.
- `python/tvm_ffi/_optional_torch_c_dlpack.py`: catch `AttributeError` during `ctypes.CDLL` loading when the pre-built `torch_c_dlpack_ext` and the installed torch have ABI symbol mismatches (e.g., in NGC containers), and fall through to JIT compilation.

None

## Impact
- API: none
- Behavioral: `load_torch_c_dlpack_extension()` no longer crashes with `AttributeError` when `torch_c_dlpack_ext` symbols don't match the installed torch; falls back to JIT build. Wheel builds no longer abort when torch is not installed.
