1. **CMake integration** (from `cpp_tooling.rst`):
```cmake
find_package(tvm_ffi CONFIG REQUIRED)

install(TARGETS my-shared-lib DESTINATION .)

```

2. **Setting tvm_ffi_ROOT** (from `cpp_tooling.rst`):
```bash
cmake -S . -B build -Dtvm_ffi_ROOT="$(tvm-ffi-config --cmakedir)"
```

3. **clangd config** (from `cpp_tooling.rst`):
```yaml
CompileFlags:
  CompilationDatabase: build-vscode/
  Remove:
    - -forward-unknown-to-host-compiler
    - --generate-code*
    - -Xcompiler*
```
