# Temporarily skip load_inline tests on non-Linux and add ninja dependency

## TL;DR
- Marks four `test_load_inline_cpp*` tests with `@pytest.mark.xfail` on non-Linux platforms (reason: "need to support non-linux").
- Adds `ninja` as a dependency to the `torch`, `cpp`, and `test` optional dependency groups in `pyproject.toml`.

None

## Impact
- API: None
- Behavioral: None -- tests still run on non-Linux but are now expected to fail rather than causing CI failures.
- Flags/config: `pyproject.toml` optional dependency groups `torch`, `cpp`, and `test` now include `ninja`. A new `cpp` group is introduced: `cpp = ["ninja"]`.
