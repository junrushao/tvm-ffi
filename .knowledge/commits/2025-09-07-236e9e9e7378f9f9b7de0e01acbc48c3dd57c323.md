# Skip load_inline tests on non-Linux platforms and add ninja dependency
## TL;DR
- Mark four `test_load_inline_cpp*` tests with `@pytest.mark.xfail` on non-Linux platforms, deferring cross-platform `load_inline` support to a future PR.
- Add `ninja` to the `torch`, `test`, and new `cpp` optional dependency groups in `pyproject.toml`.

None

## Impact
- API: none
- Behavioral: `test_load_inline_cpp`, `test_load_inline_cpp_with_docstrings`, `test_load_inline_cpp_multiple_sources`, `test_load_inline_cpp_build_dir` now produce `xfail` instead of hard failures on macOS/Windows.
- Flags/config: New optional dependency group `cpp = ["ninja"]` in `pyproject.toml`. `ninja` added to `torch` and `test` groups.
- Data formats/schemas: none

- **Python packaging** (see [0013-packaging.md](../designs/0013-packaging.md)): Optional dependency groups in `pyproject.toml`.
