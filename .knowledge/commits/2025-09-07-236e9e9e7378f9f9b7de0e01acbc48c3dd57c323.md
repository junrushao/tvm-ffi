# Temporarily skip load_inline tests on non-Linux platforms and add ninja dependency

## TL;DR

- Marks all four `test_load_inline_cpp*` tests with `@pytest.mark.xfail(not sys.platform.startswith("linux"), reason="need to support non-linux")` so they are expected-to-fail on macOS/Windows without breaking CI.
- Adds `ninja` to the `torch`, `cpp`, and `test` optional dependency groups in `pyproject.toml`; `cpp` is a new group introduced here for use without torch.
- Temporary measure — commit message notes the intent to revisit and improve multi-platform support later.
