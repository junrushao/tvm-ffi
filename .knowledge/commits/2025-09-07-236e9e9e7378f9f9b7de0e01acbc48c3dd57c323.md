# Skip load_inline tests on non-Linux and add ninja to optional deps
## TL;DR
- Mark four `test_load_inline_*` tests with `@pytest.mark.xfail` on non-Linux platforms (macOS, Windows) until `tvm_ffi.cpp.load_inline` is ported.
- Add `ninja` build tool to the `torch`, `cpp`, and `test` optional dependency groups in `pyproject.toml`.
