# Consolidate mypy config into pyproject.toml and add PEP 561 py.typed marker
## TL;DR
- Replaced four per-path mypy pre-commit hooks with a single project-wide hook, moving all configuration into `pyproject.toml` `[tool.mypy]` with namespace packages, explicit package bases, and test/example overrides.
- Bumped mypy from v1.17.0 to v1.18.2 and pinned `typing-extensions>=4.5` as a hard runtime dependency (was unversioned).
- Added `python/tvm_ffi/py.typed` PEP 561 marker file, bundled in both wheels and sdists, so downstream consumers get inline type information automatically.

## Key Exports
N/A -- infrastructure.

## Impact
- API: none
- Behavioral: `mypy` can now be run argument-free from the repo root; previously required per-path invocations. The `dataclass_transform` import in `c_class.py` is simplified (no try/except fallback) since `typing-extensions>=4.5` is guaranteed.
- Flags/config: `[tool.mypy]` in `pyproject.toml` gains `python_version`, `show_error_codes`, `mypy_path`, `files`, `namespace_packages`, `explicit_package_bases`, `exclude`, and an `[[overrides]]` section for optional deps (`torch`, `my_ffi_extension`).
- Data formats/schemas: none
