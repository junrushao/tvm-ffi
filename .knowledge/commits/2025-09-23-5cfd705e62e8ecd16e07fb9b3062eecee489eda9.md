# Revamp mypy config into pyproject.toml, consolidate pre-commit hooks, add PEP 561 py.typed marker

## TL;DR
- Consolidates 4 per-path mypy pre-commit hooks into a single project-wide hook (`pass_filenames: false`, config in `pyproject.toml`), bumps mypy from v1.17.0 to v1.18.2.
- Centralizes all mypy settings in `pyproject.toml` (`[tool.mypy]`): `python_version = "3.9"`, `mypy_path`, `files`, `namespace_packages`, `explicit_package_bases`, plus `[[tool.mypy.overrides]]` for optional deps.
- Adds PEP 561 `py.typed` marker file and bundles it in wheels/sdists, enabling downstream type checkers (mypy, pyright) to treat `tvm_ffi` as a typed package.

## Key Exports

**`py.typed` marker file** (`python/tvm_ffi/py.typed`): Empty PEP 561 marker that signals to type checkers that `tvm_ffi` ships inline type information.

**`[tool.mypy]` config** (`pyproject.toml`):
```toml
[tool.mypy]
python_version = "3.9"
show_error_codes = true
mypy_path = ["python", "examples", "tests/python"]
files = ["python/tvm_ffi", "examples", "tests/python"]
namespace_packages = true
explicit_package_bases = true
allow_redefinition = true
exclude = '(?x)(^\.venv/|^build/|^dist/|^\.mypy_cache/)'

[[tool.mypy.overrides]]
module = ["torch", "torch.*", "my_ffi_extension", "my_ffi_extension.*"]
ignore_missing_imports = true
```

## Impact
- API: None. No public Python or C++ APIs changed.
- Behavioral: `dataclass_transform` import in `c_class.py` now unconditionally uses `typing_extensions` (no fallback to `typing`). This works because `typing-extensions>=4.5` is now a pinned runtime dependency.
- Flags/config: `typing-extensions>=4.5` minimum version added to `pyproject.toml` `dependencies`. The previous declaration was `typing-extensions` (unpinned). Developers can now run bare `mypy` at the repo root instead of relying on per-path pre-commit hooks.
- Data formats/schemas: `py.typed` added to `sdist.include` list in `pyproject.toml`, affecting sdist contents.

## Usage Examples

After this commit, developers run mypy with no arguments:
```bash

# After: bare mypy reads [tool.mypy] from pyproject.toml

```
