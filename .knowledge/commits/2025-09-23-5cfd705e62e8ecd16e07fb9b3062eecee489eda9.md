# Centralize mypy config in pyproject.toml and add PEP 561 py.typed marker
## TL;DR
- Consolidate four per-path mypy pre-commit hooks into a single project-wide hook, upgrading mypy from v1.17.0 to v1.18.2 and moving all settings into `[tool.mypy]` in `pyproject.toml`.
- Add `python/tvm_ffi/py.typed` marker file for PEP 561, bundled in both wheels and sdists, enabling downstream type checkers to recognize `tvm_ffi` as a typed package.
- Pin `typing-extensions>=4.5` as a hard runtime dependency, removing the try/except import fallback for `dataclass_transform` in `c_class.py`.

## Impact
- API: none
- Behavioral: `mypy` can now be invoked argument-free from the repo root; downstream consumers of `tvm_ffi` wheels will see the `py.typed` marker and get type-checking support via PEP 561.

Overrides for `torch`, `my_ffi_extension` set `ignore_missing_imports = true`.
