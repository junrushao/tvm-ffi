# Consolidate mypy configuration into pyproject.toml, add py.typed PEP 561 marker, and fix double-except import in c_class.py

## TL;DR
- Merges four per-directory mypy pre-commit hooks into one project-wide hook (bumped to v1.18.2 with `pass_filenames: false`); moves all mypy settings (`python_version`, `files`, `mypy_path`, `exclude`, `namespace_packages`) into `[tool.mypy]` in `pyproject.toml`.
- Adds `python/tvm_ffi/py.typed` (an empty PEP 561 marker file), bundles it in both wheel and sdist via `pyproject.toml` sdist include rules; allows downstream type-checkers to discover that `tvm_ffi` is a typed package.
- Fixes a pre-existing double-`except ImportError` bug in `c_class.py`: replaces unreachable `try/except` fallback chain for `dataclass_transform` with a direct unconditional import from `typing_extensions` (which is already a hard runtime dependency pinned to `>=4.5` since commit `b5dd851f`).

## Impact
- API: none — no public Python or C API changed.
- Behavioral: mypy now runs project-wide with a single invocation (`mypy` with no args); previously required separate invocations per directory.
- Flags/config: `typing-extensions` dependency version pinned from unbounded to `>=4.5` (this happened in prior commit `b5dd851f`; reflected here via direct import). `pyproject.toml` sdist now includes `py.typed`.
- Data formats/schemas: none.
