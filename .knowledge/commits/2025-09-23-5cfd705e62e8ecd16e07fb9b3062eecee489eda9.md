# Revamp mypy config, add PEP 561 py.typed marker, and pin typing-extensions runtime dependency
## TL;DR
- Consolidates four per-path mypy pre-commit hooks into a single project-wide hook (v1.18.2) that reads all settings from `pyproject.toml`, enabling vanilla `mypy` invocation with no extra arguments.
- Adds `python/tvm_ffi/py.typed` marker file (PEP 561) and bundles it in sdists and wheels, so downstream consumers get inline type checking from `tvm_ffi`.
- Adds `typing-extensions>=4.5` as a runtime dependency (previously zero), eliminating the `try/except ImportError` fallback for `dataclass_transform` in `c_class.py`.

## Key Exports
**Files:**
- `python/tvm_ffi/py.typed` -- PEP 561 marker file (empty). Signals to type checkers that `tvm_ffi` ships inline types.

**Configuration (pyproject.toml `[tool.mypy]`):**
- `python_version = "3.9"` -- target version
- `mypy_path = ["python", "examples", "tests/python"]` -- module search paths
- `files = ["python/tvm_ffi", "examples", "tests/python"]` -- check targets
- `namespace_packages = true`, `explicit_package_bases = true` -- namespace support
- `[[tool.mypy.overrides]]` for `torch`, `my_ffi_extension` -- ignore missing imports

## Impact
- API: none
- ABI: none
- Behavioral: none (type-checking infrastructure only)
- Flags/config: `typing-extensions>=4.5` is now a runtime dependency of `apache-tvm-ffi`. This is a packaging change: the package previously had zero runtime Python dependencies. The `dataclass_transform` import in `c_class.py` is now unconditional -- if `typing-extensions` is somehow missing, import will fail rather than silently degrading.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Python packaging architecture** (`.knowledge/designs/0015-python-packaging.md`): modifies `pyproject.toml` sdist include list and runtime dependencies.
- **Reflection-based class decoration / `c_class.py`** (`.knowledge/designs/0014-python-bindings.md`): simplifies the `dataclass_transform` import by relying on `typing-extensions` as a guaranteed dependency.
- **Pre-commit lint configuration**: restructures the mypy hooks in `.pre-commit-config.yaml`.

Design elements this commit produces:
- **PEP 561 typing marker**: `py.typed` in the `tvm_ffi` package root. This enables downstream type checkers (mypy, pyright, Pylance) to treat `tvm_ffi` as a typed package and check against its inline annotations and `.pyi` stubs.
- **Centralized mypy configuration**: all mypy settings in `[tool.mypy]` section of `pyproject.toml`, replacing per-path hook arguments.

## Usage Examples
After this commit, developers run mypy with no arguments from the repo root:
```bash
mypy
```
This checks `python/tvm_ffi`, `examples`, and `tests/python` using settings from `pyproject.toml`.

Downstream consumers who `pip install apache-tvm-ffi` will automatically get PEP 561 typing support:
```python
# mypy / pyright will resolve tvm_ffi types because py.typed is present
import tvm_ffi
obj: tvm_ffi.Object = tvm_ffi.get_global_func("foo")()  # type-checked
```
