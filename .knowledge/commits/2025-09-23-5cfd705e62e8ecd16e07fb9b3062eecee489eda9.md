# Consolidate mypy config into pyproject.toml and add PEP 561 py.typed marker

## TL;DR
- Replaced four per-path mypy pre-commit hooks (python/, examples/inline_module, examples/packaging, examples/quick_start) with a single project-wide hook using settings centralized in `pyproject.toml`, pinned to mypy v1.18.2.
- Added `py.typed` PEP 561 marker file to `python/tvm_ffi/` and included it in both wheel and sdist builds, enabling downstream consumers to use `tvm_ffi` type stubs natively.
- Simplified `dataclass_transform` import in `c_class.py` from a try/except chain to a direct `from typing_extensions import dataclass_transform`, enabled by raising the `typing-extensions` floor to `>=4.5`.

## Key Exports
N/A -- infrastructure change. No new public API surface introduced.

## Impact
- API: None
- Behavioral: `mypy` can now be run argument-free from repo root for full-project type checking. Downstream packages that `import tvm_ffi` will see it as a PEP 561 typed package if their mypy/pyright respects `py.typed`.
- Flags/config: `[tool.mypy]` in `pyproject.toml` now specifies `python_version = "3.9"`, `mypy_path`, `files`, `namespace_packages = true`, `explicit_package_bases = true`, and overrides for optional deps (torch, my_ffi_extension).
- Data formats/schemas: `typing-extensions` dependency floor raised from unversioned to `>=4.5` in `pyproject.toml` `[project.dependencies]`.

## Design Elements
Design elements this commit consumes:
- **Packaging (0013-packaging)**: sdist include list in `pyproject.toml` -- adds `/python/tvm_ffi/py.typed` entry.

Design elements this commit produces:
