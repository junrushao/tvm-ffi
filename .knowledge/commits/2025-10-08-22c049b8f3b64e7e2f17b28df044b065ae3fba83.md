# Expose get_raw_stream API for retrieving current device stream
## TL;DR
- Adds `_env_get_current_stream` Cython wrapper around `TVMFFIEnvGetStream` C API.
- Exposes `tvm_ffi.stream.get_raw_stream(device)` Python function that returns the current FFI stream handle as an integer.

## Impact
- API: New public function `get_raw_stream(device: Device) -> int` in `tvm_ffi.stream`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Stream exchange protocol** (`.knowledge/ADRs/0030-generic-stream-exchange-protocol.md`): `TVMFFIEnvGetStream` C API for retrieving the thread-local stream.
- **Python bindings** (`.knowledge/designs/0014-python-bindings.md`): Cython `base.pxi` for low-level C API wrappers.

Design elements this commit produces:
- **`get_raw_stream` Python API**: Completes the stream get/set pair in Python (set was already available via `use_raw_stream`).
