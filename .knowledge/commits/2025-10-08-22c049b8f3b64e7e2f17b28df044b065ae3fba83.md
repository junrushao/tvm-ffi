# Expose get_raw_stream to query the current FFI environment stream for a device
## TL;DR
- Adds `tvm_ffi.get_raw_stream(device)` as a new public Python API to query the current FFI stream for a given device.
- Binds the existing C API `TVMFFIEnvGetStream` to Python via a new Cython function `_env_get_current_stream`.
- Updates `test_raw_stream` to verify `get_raw_stream` returns the correct stream at each nesting level of `use_raw_stream` contexts.

## Usage Examples
Query the current stream inside a `use_raw_stream` context:

```python
import tvm_ffi

device = tvm_ffi.device("cuda:0")
stream_handle = 123456789

with tvm_ffi.use_raw_stream(device, stream_handle):
    # Query the active stream for this device
    current = tvm_ffi.get_raw_stream(device)
    assert current == stream_handle
```

Cross-layer trace: Python `get_raw_stream` -> Cython `_env_get_current_stream` -> C API `TVMFFIEnvGetStream` -> thread-local `EnvContext` lookup.
