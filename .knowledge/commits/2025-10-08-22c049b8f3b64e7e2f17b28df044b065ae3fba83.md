# Expose get_raw_stream to query the current FFI environment stream for a device
## TL;DR
- Adds `get_raw_stream(device) -> int` to `tvm_ffi.stream` (and re-exports from `tvm_ffi`), enabling callers to query the current FFI environment stream for a given device without entering/exiting a context manager.
- Implements Cython binding `_env_get_current_stream` in `base.pxi` wrapping `TVMFFIEnvGetStream`, plus a corresponding type stub in `core.pyi`.
- Extends `test_raw_stream` with assertions verifying `get_raw_stream` returns the expected stream at each nesting level.

## Key Exports

**Functions**:
- `tvm_ffi.get_raw_stream(device: Device) -> int` -- Returns the current FFI environment stream handle for the given device. Delegates to `core._env_get_current_stream(device.dlpack_device_type(), device.index)`.
- `tvm_ffi.core._env_get_current_stream(device_type: int, device_id: int) -> int` -- Cython binding that calls `TVMFFIEnvGetStream(device_type, device_id)` and casts the `void*` result to `uint64_t`.

## Impact
- API: Additive only. New public function `tvm_ffi.get_raw_stream` added to `__init__.py` re-exports. No existing APIs changed.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **C ABI `TVMFFIEnvGetStream`** (`include/tvm/ffi/extra/c_env_api.h`): The C function that retrieves the per-thread, per-device stream handle. Already declared in `base.pxi`'s `cdef extern` block; this commit adds a Python-callable wrapper. See [0001-c-abi-layer.md](../designs/0001-c-abi-layer.md), [ADR 0013-env-api-naming-convention.md](../ADRs/0013-env-api-naming-convention.md).
- **`StreamContext` / `use_raw_stream` pattern** (`python/tvm_ffi/stream.py`): The existing stream context management design that `get_raw_stream` complements. See [0014-python-package.md](../designs/0014-python-package.md).
- **Cython `_env_set_current_stream` binding pattern** (`python/tvm_ffi/cython/base.pxi`): The new `_env_get_current_stream` mirrors the existing `_env_set_current_stream` in structure -- same parameter types, same `void* -> uint64_t` cast convention.
- **`__init__.py` re-export convention** (`python/tvm_ffi/__init__.py`): Public API surface management via explicit imports from submodules.

Design elements this commit produces:
- **`get_raw_stream` API**: A new public function completing the stream get/set pair. Previously only `use_raw_stream` (set via context manager) existed; now callers can also query the current stream without creating a context manager.

## Usage Examples
```python
import tvm_ffi

device = tvm_ffi.device("cuda:0")

# Query stream inside a use_raw_stream context
with tvm_ffi.use_raw_stream(device, my_stream_handle):
    current = tvm_ffi.get_raw_stream(device)
    assert current == my_stream_handle

    # Nested: inner stream overrides
    with tvm_ffi.use_raw_stream(device, another_handle):
        assert tvm_ffi.get_raw_stream(device) == another_handle

    # Outer stream restored
    assert tvm_ffi.get_raw_stream(device) == my_stream_handle
```
