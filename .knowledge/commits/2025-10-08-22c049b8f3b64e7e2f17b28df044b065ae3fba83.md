# Expose get_raw_stream Python API over TVMFFIEnvGetStream

## TL;DR
- Adds `get_raw_stream(device) -> int` to `python/tvm_ffi/stream.py` and exports it from `tvm_ffi.__init__`.
- Bridges the pre-existing C ABI `TVMFFIEnvGetStream` through a new Cython entry point `_env_get_current_stream` in `base.pxi`.
- Adds a matching stub entry `_env_get_current_stream` in `core.pyi` and extends `test_stream.py` with three assertions verifying RAII nesting round-trips.

## Impact
- API: `tvm_ffi.get_raw_stream(device)` is a new public symbol. No existing signatures changed. `tvm_ffi._env_get_current_stream` is a new semi-private Cython-level function.
- Behavioral: none — pre-existing C ABI `TVMFFIEnvGetStream` already existed; this commit only surfaces it to Python callers.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**Cross-layer: Python reads back the stream set via `use_raw_stream`.**
Taken from `tests/python/test_stream.py`:

```python
import tvm_ffi

device = tvm_ffi.device("cpu")   # or "cuda:0" on a GPU machine
stream_1 = 123456789
stream_2 = 987654321

with tvm_ffi.use_raw_stream(device, stream_1):
    assert tvm_ffi.get_raw_stream(device) == stream_1  # outer stream active

    with tvm_ffi.use_raw_stream(device, stream_2):
        assert tvm_ffi.get_raw_stream(device) == stream_2  # inner stream active

    assert tvm_ffi.get_raw_stream(device) == stream_1  # outer restored after inner exit
```
