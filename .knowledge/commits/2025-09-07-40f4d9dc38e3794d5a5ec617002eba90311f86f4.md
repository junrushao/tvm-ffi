# Cleanup tvm_ffi Python API: rename public symbols and align Device with torch conventions
## TL;DR
- Renames core public API functions (`register_func` -> `register_global_func`, `_init_api` -> `init_ffi_api`) and internal modules (`tensor.py` -> `_tensor.py`, `convert.py` -> `_convert.py`, `dtype.py` -> `_dtype.py`) for consistency.
- Refactors `Device` to align with `torch.device` conventions: `device_id` -> `index`, `device_type` -> `type` property (string) + `dlpack_device_type()` method (int); extracts device type constants into a new `DLDeviceType(IntEnum)` class; removes per-device convenience functions (`cpu()`, `cuda()`, etc.) from `tvm_ffi` root.
- Removes `String`, `Bytes`, `DataTypeCode`, `ObjectGeneric`, `ModulePropertyMask` from `tvm_ffi.__init__` public exports; renames `ObjectGeneric` -> `ObjectConvertible`; makes internal lookup dicts private (prefix `_`).

## Impact
- API: Breaking -- `register_func`, `_init_api`, `Device.device_id`, `Device.device_type`, `ObjectGeneric` are renamed. Convenience functions `cpu()`, `cuda()`, etc. are removed from `tvm_ffi` root. `String`, `Bytes`, `DataTypeCode`, `ModulePropertyMask` removed from `tvm_ffi.__init__` exports. All callers referencing old names must update.
- Behavioral: `Device.__init__` now accepts `index` keyword instead of `device_id`; string device specs with suffix annotations (e.g., `"cuda -arch=sm_80"`) are now stripped at the `Device.__init__` level (moved from `device()` function).
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Registering and calling a global function (from `tests/python/test_examples.py`):
```python
import tvm_ffi

@tvm_ffi.register_global_func("example.echo")
def echo(x):
    return x

f = tvm_ffi.get_global_func("example.echo")
assert f(1) == 1
```

Device usage with new API (from `tests/python/test_device.py`):
```python
import tvm_ffi

dev = tvm_ffi.device("cuda:3")
assert dev.dlpack_device_type() == tvm_ffi.DLDeviceType.kDLCUDA
assert dev.index == 3
assert dev.type == "cuda"
```

FFI API initialization (new name, from `examples/packaging/python/`):
```python
# _ffi_api.py
import tvm_ffi
tvm_ffi.init_ffi_api("my_ffi_extension", __name__)
```
