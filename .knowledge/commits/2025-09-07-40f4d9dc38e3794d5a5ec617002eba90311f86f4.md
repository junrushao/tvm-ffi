# Rename and clean up tvm_ffi Python public API for consistency with Python array/torch conventions

## TL;DR
- Renames core Python API functions (`register_func` -> `register_global_func`, `_init_api` -> `init_ffi_api`) and Device properties (`device_id` -> `index`, `device_type` -> `type`/`dlpack_device_type()`) for consistency with torch and Python array API conventions.
- Extracts `DLDeviceType` IntEnum from `Device` class constants; removes convenience device constructors (`cpu()`, `cuda()`, `rocm()`, etc.) from `tvm_ffi` namespace.
- Renames internal modules (`convert.py` -> `_convert.py`, `dtype.py` -> `_dtype.py`, `tensor.py` -> `_tensor.py`), removes `String`, `Bytes`, `DataTypeCode`, `ObjectGeneric`, `ModulePropertyMask` from top-level `__all__`, and adds Python API reference docs.

## Impact
- API: Breaking -- `register_func`, `_init_api`, `Device.device_id`, `Device.device_type` all renamed. Convenience functions (`cpu()`, `cuda()`, etc.) removed. `String`, `Bytes`, `DataTypeCode`, `ModulePropertyMask` no longer in top-level `tvm_ffi` namespace. All callers must update.
- Behavioral: `Device.type` now returns a string name (e.g. "cuda") instead of the integer code that `device_type` returned. Integer access moved to `dlpack_device_type()` method.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
import tvm_ffi

# Register a global function (new name)
@tvm_ffi.register_global_func("mytest.echo")
def echo(x):
    return x

f = tvm_ffi.get_global_func("mytest.echo")
assert f(1) == 1

# Device usage (new property names)
dev = tvm_ffi.device("cuda:0")
assert dev.type == "cuda"              # was: dev.device_type (returned int)
assert dev.index == 0                  # was: dev.device_id
assert dev.dlpack_device_type() == tvm_ffi.DLDeviceType.kDLCUDA  # new method

# Init FFI API in extension module (new name)
# _ffi_api.py:
tvm_ffi.init_ffi_api("my_extension", __name__)  # was: tvm_ffi._init_api(...)
```
