# Rename Python public API symbols for consistency with PyTorch and Python array API conventions

## TL;DR
- Renames core Python public API symbols (`register_func` → `register_global_func`, `_init_api` → `init_ffi_api`, `ObjectGeneric` → `ObjectConvertible`, `device_id` → `index`, `device_type` property → `dlpack_device_type()` method + `type` string property) and restructures internal modules (`tensor.py` → `_tensor.py`, `convert.py` → `_convert.py`, `dtype.py` → `_dtype.py`).
- Extracts `DLDeviceType` as a standalone `IntEnum` from `Device` class; removes convenience device constructors (`cpu()`, `cuda()`, etc.) from the `tvm_ffi` root namespace.
- Adds/expands docstrings with usage examples throughout `registry.py`, `container.py`, `module.py`; adds `tests/python/test_examples.py` to exercise docstring examples.

## Impact
- API: **Breaking** — all callers of `register_func`, `_init_api`, `device.device_id`, `device.device_type`, `ObjectGeneric`, `Device.kDLCPU` etc., `to_dlpack()` must update. The device convenience constructors (`tvm_ffi.cpu()` etc.) and `ModulePropertyMask`, `DataTypeCode`, `String`, `Bytes`, `is_view` are no longer exported from the root namespace (may still be accessible via submodules).
- Behavioral: `device(dev_type, dev_id=0)` signature changes to `device(device_type, index=None)` — positional callers unaffected, keyword-arg callers using `dev_id=` break.
- Flags/config: None.
- Data formats/schemas: `Device.__repr__` now emits `device(type='cuda', index=0)` (was `device(type='cuda', device_id=0)` implicitly).

- **0004-function-system** — global function registry (C++ side unchanged; Python-facing names updated)
- **0007-containers** — `Device`, `Tensor`, `Shape` Python wrappers; `DLDevice` DLPack struct layout

Design elements this commit produces:

- **`_tensor.py` module** — replaces `tensor.py`; exports `Device`, `DLDeviceType`, `Tensor`, `Shape`, `from_dlpack`, `device`

## Usage Examples

```python
import tvm_ffi

# register_global_func (was register_func)
@tvm_ffi.register_global_func("mytest.echo")
def echo(x):
    return x

f = tvm_ffi.get_global_func("mytest.echo")
assert f(1) == 1

# init_ffi_api (was _init_api); typical _ffi_api.py pattern:
tvm_ffi.init_ffi_api("mypackage", __name__)
# → auto-populates current module with all "mypackage.*" global functions

# DLDeviceType and Device API
dev = tvm_ffi.device("cuda:0")
assert dev.index == 0                                       # was: dev.device_id
assert dev.type == "cuda"                                   # new property (string)
assert dev.dlpack_device_type() == tvm_ffi.DLDeviceType.kDLCUDA  # was: dev.device_type == Device.kDLCUDA
```
