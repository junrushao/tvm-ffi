# Cleanup tvm_ffi Python API: rename public symbols for torch/array API consistency, extract DLDeviceType enum, remove convenience device shortcuts

## TL;DR
- Renames public Python API functions (`register_func` -> `register_global_func`, `_init_api` -> `init_ffi_api`, `ObjectGeneric` -> `ObjectConvertible`) and Device properties (`device_id` -> `index`, `device_type` -> `type`/`dlpack_device_type()`) to align with `torch.device` conventions.
- Extracts `DLDeviceType` as a standalone `IntEnum` (previously inline constants on `Device`), adds `Device.type` and `Device.index` properties, makes `Device.__init__` parameter `index` optional (default `None` instead of `0`).
- Removes convenience device constructors (`cpu()`, `cuda()`, `rocm()`, etc.) and several re-exports from `__init__.py` (`String`, `Bytes`, `DataTypeCode`, `ModulePropertyMask`), moves `tensor.py` -> `_tensor.py`, `convert.py` -> `_convert.py`, `dtype.py` -> `_dtype.py`.

```python
    kDLCPU = 1; kDLCUDA = 2; kDLCUDAHost = 3; kDLOpenCL = 4

    kDLROCMHost = 11; kDLExtDev = 12; kDLCUDAManaged = 13
    kDLOneAPI = 14; kDLWebGPU = 15; kDLHexagon = 16
```

**`Device`** (updated properties):
```python
class Device:
    @property
    def type(self) -> str: ...         # e.g., "cuda"
    @property
    def index(self) -> int: ...        # e.g., 0
    def dlpack_device_type(self) -> int: ...  # e.g., 2 (kDLCUDA)
```

**`register_global_func`** (renamed from `register_func`):
```python
def register_global_func(func_name: str, f=None, override=False) -> Function: ...
```

**`init_ffi_api`** (renamed from `_init_api`):
```python
def init_ffi_api(namespace: str, target_module_name=None) -> None: ...
```

**`ObjectConvertible`** (renamed from `ObjectGeneric`):
```python
class ObjectConvertible:
    def asobject(self) -> Object: ...
```

**`device`** (updated signature):
```python
def device(device_type: str | int, index: int | None = None) -> Device: ...
```

## Impact
- API: **Breaking** -- All callers using `register_func`, `_init_api`, `ObjectGeneric`, `Device.device_id`, `Device.device_type`, `Tensor.to_dlpack`, `Tensor.is_view`, or convenience device constructors (`cpu()`, `cuda()`, etc.) must update. `String`/`Bytes`/`DataTypeCode`/`ModulePropertyMask` removed from top-level `tvm_ffi` namespace.
- Behavioral: `device()` parameter `index` now defaults to `None` (resolved to 0 internally) instead of `0`. String parsing for device names now strips suffix annotations (`device_type_or_name.split(" ")[0]`) inside `Device.__init__` rather than in `device()`.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Device** (`0014-python-package.md`): Restructured to align with `torch.device` property naming (`type`, `index`, `dlpack_device_type()`).
- **Global function registry** (`0004-function-system.md`, `0014-python-package.md`): Registry API renamed for clarity (`register_func` -> `register_global_func`, `_init_api` -> `init_ffi_api`).
- **Python conversion protocol** (`0014-python-package.md`): `ObjectGeneric` -> `ObjectConvertible` in `_convert.py` and `function.pxi`.
- **Module system** (`0013-module-system.md`): `ModulePropertyMask` demoted from top-level export but still available at `tvm_ffi.module.ModulePropertyMask`.

Design elements this commit produces:
- **`DLDeviceType` IntEnum**: New standalone enum extracted from Device class constants. Maps 1:1 to DLPack `DLDeviceType` C enum. Used by tests and callers to reference device types symbolically without depending on the Device class.
- **Torch-aligned Device API**: `Device.type` (str), `Device.index` (int), `Device.dlpack_device_type()` (int) -- matches `torch.device` naming pattern.
- **Python API reference docs**: New Sphinx `autodoc` index at `docs/reference/python/index.rst` covering Object, Function, Module, Tensor, and Container APIs.

## Usage Examples

### Device API (before/after)
```python
# BEFORE
dev = tvm_ffi.device("cuda", 0)
assert dev.device_type == tvm_ffi.Device.kDLCUDA
assert dev.device_id == 0

# AFTER
dev = tvm_ffi.device("cuda", 0)
assert dev.dlpack_device_type() == tvm_ffi.DLDeviceType.kDLCUDA
assert dev.index == 0
assert dev.type == "cuda"
```

### Global function registration (before/after)
```python
# BEFORE
@tvm_ffi.register_func("mytest.echo")
def echo(x): return x

# AFTER
@tvm_ffi.register_global_func("mytest.echo")
def echo(x): return x
```

### FFI API initialization (before/after)
```python
# BEFORE (_ffi_api.py)
tvm_ffi._init_api("my_module", __name__)

# AFTER (_ffi_api.py)
tvm_ffi.init_ffi_api("my_module", __name__)
```
