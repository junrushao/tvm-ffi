# Cleanup tvm_ffi Python API: rename public functions, align Device with torch conventions
## TL;DR
- Renames public API symbols for consistency: `register_func` -> `register_global_func`, `_init_api` -> `init_ffi_api`, `ObjectGeneric` -> `ObjectConvertible`.
- Renames Device properties to align with torch.device conventions: `device_id` -> `index`, `device_type` (property) -> `type` (str) / `dlpack_device_type()` (int method). Extracts device type enum constants into a new `DLDeviceType(IntEnum)` class.
- Removes convenience device constructors (`cpu()`, `cuda()`, etc.) and several symbols from the public `__all__` (`String`, `Bytes`, `DataTypeCode`, `ModulePropertyMask`). Renames internal modules `convert.py` -> `_convert.py`, `dtype.py` -> `_dtype.py`, `tensor.py` -> `_tensor.py`.
- Adds Python API reference docs (`docs/reference/python/index.rst`) and enriches docstrings across Array, Map, Module, registry functions.

### Rename mapping

| Old name | New name | Location |
|----------|----------|----------|
| `tvm_ffi.register_func` | `tvm_ffi.register_global_func` | `registry.py`, `__init__.py` |
| `tvm_ffi._init_api` | `tvm_ffi.init_ffi_api` | `registry.py`, `__init__.py` |
| `ObjectGeneric` | `ObjectConvertible` | `object.pxi`, `_convert.py`, `function.pxi` |
| `Device.device_id` (property) | `Device.index` (property) | `device.pxi` |
| `Device.device_type` (property, int) | `Device.type` (property, str) + `Device.dlpack_device_type()` (method, int) | `device.pxi` |
| `Device.__init__(device_type_or_name, device_id)` | `Device.__init__(device_type, index)` | `device.pxi` |
| `Device.DEVICE_TYPE_TO_NAME` | `Device._DEVICE_TYPE_TO_NAME` | `device.pxi` |
| `Device.DEVICE_NAME_TO_TYPE` | `Device._DEVICE_NAME_TO_TYPE` | `device.pxi` |
| `dtype.NUMPY_DTYPE_TO_STR` | `dtype._NUMPY_DTYPE_TO_STR` | `_dtype.py` |

### Symbols removed from `tvm_ffi.__all__`

| Symbol | Status |
|--------|--------|
| `String`, `Bytes` | Still accessible via `tvm_ffi.core.String`, `tvm_ffi.core.Bytes` |
| `DataTypeCode` | Still accessible via `tvm_ffi._dtype.DataTypeCode` |
| `ModulePropertyMask` | Still in `module.py` but no longer re-exported at package level |
| `cpu()`, `cuda()`, `rocm()`, `opencl()`, `metal()`, `vpi()`, `vulkan()`, `ext_dev()`, `hexagon()`, `webgpu()` | Removed entirely; use `tvm_ffi.device("cuda", 0)` instead |

## Key Exports

**Classes**:
- `DLDeviceType(IntEnum)` -- new enum class extracted from Device, with constants `kDLCPU=1`, `kDLCUDA=2`, ..., `kDLHexagon=16`. Replaces `Device.kDLCPU`, etc.
- `ObjectConvertible` -- renamed from `ObjectGeneric`. Abstract base class with `asobject()` method for types convertible to FFI objects.

**Functions**:
- `register_global_func(func_name, f=None, override=False)` -- renamed from `register_func`. Same semantics.
- `init_ffi_api(namespace, target_module_name=None)` -- renamed from `_init_api`. Same semantics. No longer underscore-prefixed since it is part of the public API.

**Properties (Device)**:
- `Device.type -> str` -- new property returning the string device type name (e.g. `"cuda"`).
- `Device.index -> int` -- renamed from `device_id`. Returns `cdevice.device_id`.
- `Device.dlpack_device_type() -> int` -- new method returning the integer DLPack device type code. Replaces the old `device_type` property.

**Removed**:
- `Tensor.is_view` property removed.
- `Tensor.to_dlpack()` made private as `_to_dlpack()`.

## Impact
- API: Breaking for Python callers. `register_func`, `_init_api`, `ObjectGeneric`, `Device.device_id`, `Device.device_type`, convenience device constructors (`cpu()`, `cuda()`, etc.), `String`/`Bytes` at top-level, `Tensor.to_dlpack()`, `Tensor.is_view` are all renamed or removed. Every downstream project calling these symbols must update.
- ABI: None. All changes are Python-layer only; the C ABI and Cython extension type memory layouts are unchanged.
- Behavioral: `Device.__init__` now strips suffix annotations from string device types (splits on space before parsing). The `device()` function parameter `dev_id` renamed to `index` (keyword callers must update). `Device("cuda")` previously required explicit `device_id=0` for keyword usage; now `index=None` defaults to 0 inside the constructor.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Python binding layer** (`.knowledge/designs/0014-python-bindings.md`) -- `register_object`, `Object`, `PyNativeObject` pattern, `_init_api` namespace population, `ObjectGeneric`, `convert`, `Array`, `Map`, `Module`, value marshaling in `make_arg`/`make_ret`.
- **Module system** (`.knowledge/designs/0013-module-system.md`) -- `Module` class, `ModulePropertyMask`.
- **C ABI** (`.knowledge/designs/c-abi.md`) -- `DLDevice` struct, `TVMFFIDLDeviceFromIntPair`.

Design elements this commit produces:
- **`DLDeviceType` enum** -- new first-class `IntEnum` extracted from `Device`, providing named constants for DLPack device types. Used by tests and callers instead of `Device.kDLCPU` etc.
- **Torch-aligned Device API** -- `Device.type` (str), `Device.index` (int), `Device.dlpack_device_type()` (int) follow the `torch.device` property naming convention.
- **Public API naming convention** -- renames underscore-prefixed or abbreviated public functions (`_init_api`, `register_func`) to explicit names (`init_ffi_api`, `register_global_func`), establishing the convention that public tvm_ffi APIs should have clear, non-abbreviated names.
- **Internal module underscore convention** -- `_convert.py`, `_dtype.py`, `_tensor.py` are underscore-prefixed to signal they are internal implementation modules, not direct public imports.
- **Python API reference docs** -- `docs/reference/python/index.rst` added to Sphinx toctree, providing `autosummary` API docs for all key public classes and functions.

## Usage Examples

### Registering a global function (new API)
```python
import tvm_ffi

@tvm_ffi.register_global_func("mytest.echo")
def echo(x):
    return x

f = tvm_ffi.get_global_func("mytest.echo")
assert f(1) == 1
```

### Using the new Device API
```python
import tvm_ffi

dev = tvm_ffi.device("cuda:0")
assert dev.type == "cuda"                                # new .type property (str)
assert dev.index == 0                                     # renamed from device_id
assert dev.dlpack_device_type() == tvm_ffi.DLDeviceType.kDLCUDA  # new method + enum
```

### Initializing FFI API in a module (new API)
```python
# _ffi_api.py
from . import registry
registry.init_ffi_api("my_package", __name__)  # was: tvm_ffi._init_api(...)
```
