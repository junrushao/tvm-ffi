# Relocate CMake config to standard share/cmake/ path for automatic find_package discovery
## TL;DR
- Moved CMake config install location from `<prefix>/cmake/` to `<prefix>/share/cmake/tvm_ffi/`, matching CMake's standard `<prefix>/<name>*/share/cmake/<name>*/` search pattern.
- Eliminates the `execute_process(... tvm_ffi.config --cmakedir)` step in downstream CMakeLists.txt -- `find_package(tvm_ffi CONFIG REQUIRED)` now works automatically after `find_package(Python)` adds `sys.prefix` to search paths.
- Added `editable.rebuild = false` to pyproject.toml to avoid unnecessary rebuilds during editable installs.

## Impact
- API: none -- `tvm_ffi.config --cmakedir` still works, just returns updated path
- Behavioral: `find_package(tvm_ffi CONFIG REQUIRED)` now auto-discovers without manually setting `tvm_ffi_ROOT` (when `find_package(Python)` has been called first)
- Flags/config: `editable.rebuild = false` added to pyproject.toml, preventing scikit-build-core from recompiling on editable re-install
- Data formats/schemas: none

## Usage Examples

**Before (old pattern requiring manual path resolution):**
```cmake
find_package(Python COMPONENTS Interpreter REQUIRED)
execute_process(
  COMMAND "${Python_EXECUTABLE}" -m tvm_ffi.config --cmakedir
  OUTPUT_STRIP_TRAILING_WHITESPACE OUTPUT_VARIABLE tvm_ffi_ROOT)
find_package(tvm_ffi CONFIG REQUIRED)
```

**After (automatic discovery via standard CMake paths):**
```cmake
find_package(Python COMPONENTS Interpreter REQUIRED)
# tvm_ffi found automatically -- CMake adds sys.prefix to search paths
find_package(tvm_ffi CONFIG REQUIRED)
```
