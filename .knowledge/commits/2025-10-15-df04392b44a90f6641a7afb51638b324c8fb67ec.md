# Relocate CMake config to standard search path for automatic find_package discovery

## TL;DR
- Moves the CMake config install destination from `cmake/` to `share/cmake/tvm_ffi/`, matching CMake's standard `<prefix>/share/cmake/<name>*/` search pattern so `find_package(tvm_ffi CONFIG REQUIRED)` works automatically without manually setting `tvm_ffi_ROOT`.
- Removes the `execute_process(COMMAND python -m tvm_ffi.config --cmakedir ...)` boilerplate from all example CMakeLists.txt files and from the packaging documentation, since CMake now discovers the config files automatically via `sys.prefix` (added to search paths by `find_package(Python)`).
- Adds `editable.rebuild = false` and `editable.verbose = true` to `pyproject.toml` to avoid unnecessary rebuilds during editable installs.

## Key Exports

**Modified: CMake install destinations (`CMakeLists.txt`)**:
- `cmake/Utils/` install destination changed from `cmake/Utils` to `share/cmake/tvm_ffi/Utils`.
- `cmake/tvm_ffi-config.cmake` install destination changed from `cmake` to `share/cmake/tvm_ffi`.

**Modified: `python/tvm_ffi/libinfo.py` -- `find_cmake_path()`**:
- First candidate changed from `<package_dir>/cmake` to `<package_dir>/share/cmake/tvm_ffi` (standard install path).
- Second candidate remains `../../cmake` (development mode, source tree).

**Modified: `pyproject.toml` -- scikit-build-core editable install config**:
- Added `editable.rebuild = false` -- prevents automatic rebuilds on editable install.
- Added `editable.verbose = true` -- enables verbose output for editable installs.

**Modified: Example CMakeLists.txt files (simplified)**:
- `examples/packaging/CMakeLists.txt`: Removed 5-line `execute_process` block that called `tvm_ffi.config --cmakedir`. Now uses bare `find_package(tvm_ffi CONFIG REQUIRED)`.
- `examples/quick_start/CMakeLists.txt`: Same simplification -- removed 6-line `execute_process` block.

**Modified: Documentation**:
- `docs/guides/packaging.md`: Removed `execute_process` boilerplate from downstream CMake example.
- `examples/packaging/README.md`: Added `cd examples/packaging` instruction.
- `examples/quick_start/README.md`: Added `cd examples/quick_start` instruction.

## Impact
- API: None. No Python or C++ API changes.
- ABI: None. No object layout or C ABI changes.
- Behavioral:
  - **CMake install path change**: Config files move from `<prefix>/cmake/` to `<prefix>/share/cmake/tvm_ffi/`. Downstream projects that hardcode the old path to find the config file will not find it. However, the recommended pattern (`find_package(tvm_ffi CONFIG)`) now works automatically without any manual path configuration, which is strictly better.
  - **`find_cmake_path()` update**: First search candidate changed from `<package_dir>/cmake` to `<package_dir>/share/cmake/tvm_ffi`. Code that calls `tvm_ffi.libinfo.find_cmake_path()` or `tvm-ffi-config --cmakedir` will now return the new path.
  - **Editable install**: `editable.rebuild = false` prevents scikit-build-core from triggering a full CMake rebuild on every editable install invocation, significantly speeding up development workflows where only pure Python changes are made.
- Flags/config: `editable.rebuild` and `editable.verbose` added to `[tool.scikit-build]` in pyproject.toml.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Python packaging architecture** (`.knowledge/designs/0015-python-packaging.md`): The CMake install rules, `libinfo.py` search paths, and `tvm_ffi-config.cmake` discovery pattern are all part of the packaging design. This commit updates the install layout within that framework.
- **CMake standard search path convention**: CMake's `find_package()` searches `<prefix>/share/cmake/<name>*/` by default. This commit aligns the install location with that convention, following the same approach as pybind11.

Design elements this commit produces:
- **Automatic CMake config discovery**: By installing to the standard CMake search path, downstream projects no longer need the `execute_process(python -m tvm_ffi.config --cmakedir)` workaround. `find_package(Python)` adds `sys.prefix` to CMake's search paths, and the config file at `share/cmake/tvm_ffi/tvm_ffi-config.cmake` is found automatically. This is the new canonical pattern for downstream C++ projects.

## Usage Examples

### Before: Manual cmake discovery (no longer needed)
```cmake
find_package(Python COMPONENTS Interpreter REQUIRED)
# This boilerplate is no longer required:
execute_process(
  COMMAND "${Python_EXECUTABLE}" -m tvm_ffi.config --cmakedir
  OUTPUT_STRIP_TRAILING_WHITESPACE OUTPUT_VARIABLE tvm_ffi_ROOT)
find_package(tvm_ffi CONFIG REQUIRED)
```

### After: Automatic cmake discovery
```cmake
find_package(Python COMPONENTS Interpreter REQUIRED)
# find_package(Python) adds sys.prefix to search paths,
# and tvm_ffi config is at share/cmake/tvm_ffi/ under sys.prefix
find_package(tvm_ffi CONFIG REQUIRED)

add_library(my_ext SHARED my_ext.cc)
target_link_libraries(my_ext PRIVATE tvm_ffi_shared)
```
