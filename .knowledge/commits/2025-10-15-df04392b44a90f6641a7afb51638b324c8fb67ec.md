# Relocate CMake config to share/cmake/tvm_ffi/ for automatic find_package discovery
## TL;DR
- Moved CMake config files from `cmake/` to `share/cmake/tvm_ffi/` to match CMake's standard `<prefix>/share/cmake/<name>*/` search pattern, enabling `find_package(tvm_ffi CONFIG REQUIRED)` without manually setting `tvm_ffi_ROOT`.
- Removed `execute_process(... -m tvm_ffi.config --cmakedir ...)` calls from example and doc CMakeLists.
- Updated `find_cmake_path()` in `libinfo.py` to check the new standard install path first.
- Added `editable.rebuild = false` to `pyproject.toml` to avoid rebuilding in editable install mode.
