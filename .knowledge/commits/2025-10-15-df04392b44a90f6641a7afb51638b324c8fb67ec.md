# Enable automatic CMake config discovery via standard install paths
## TL;DR
- Relocates CMake config files to `share/cmake/tvm_ffi/` matching CMake's standard search pattern, enabling `find_package(tvm_ffi CONFIG REQUIRED)` without manually setting `tvm_ffi_ROOT`.
- Simplifies example and packaging CMakeLists.txt files.
