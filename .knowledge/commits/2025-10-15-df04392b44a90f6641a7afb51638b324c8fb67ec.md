# [CMake] Enable automatic cmake config discovery (#124)
## TL;DR
- Relocated CMake config files from `cmake/` to `share/cmake/tvm_ffi/` in the install layout, matching CMake's standard search pattern `<prefix>/<name>*/share/cmake/<name>*/`.
- This enables `find_package(tvm_ffi CONFIG REQUIRED)` to work automatically without manually setting `tvm_ffi_ROOT`, because `find_package(Python)` adds `sys.prefix` to CMake search paths.
- Updated `find_cmake_path()` in `libinfo.py` to look for the standard install path first (`share/cmake/tvm_ffi/`), with the development-mode path (`../../cmake`) as fallback.
- Simplified example CMakeLists.txt files by removing the `execute_process` + `tvm_ffi.config --cmakedir` boilerplate that was previously required to locate the config.
- Added `editable.rebuild = false` and `editable.verbose = true` to `pyproject.toml` to avoid rebuilding during editable installs.

## Impact
- API: none -- no public Python/C++ API changes
- Behavioral: `find_package(tvm_ffi CONFIG REQUIRED)` now works without setting `tvm_ffi_ROOT` when the Python environment is discoverable by CMake. The `tvm-ffi-config --cmakedir` CLI still works but is no longer required for basic usage.
- Flags/config: Added `editable.rebuild = false` and `editable.verbose = true` under `[tool.scikit-build]` in `pyproject.toml`, preventing automatic rebuilds during editable installs.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Packaging** (`0013-packaging.md`): The `find_cmake_path()` function in `libinfo.py`, the `tvm_ffi-config.cmake` config module, and the downstream `find_package(tvm_ffi)` pattern
- **Module system** (`0011-module-system.md`): The `cmake/Utils/Library.cmake` and `cmake/Utils/EmbedCubin.cmake` utilities included by the config module

Design elements this commit produces:
- **Standard CMake install path**: Config files now installed to `share/cmake/tvm_ffi/`, enabling CMake's automatic config-mode search without explicit `tvm_ffi_ROOT`. This aligns with pybind11's convention.

## Usage Examples
Downstream CMake projects can now use a simpler pattern:

```cmake
# Before this commit (required manual config discovery):
find_package(Python COMPONENTS Interpreter REQUIRED)
execute_process(
  COMMAND "${Python_EXECUTABLE}" -m tvm_ffi.config --cmakedir
  OUTPUT_STRIP_TRAILING_WHITESPACE OUTPUT_VARIABLE tvm_ffi_ROOT
)
find_package(tvm_ffi CONFIG REQUIRED)

# After this commit (automatic discovery):
find_package(Python COMPONENTS Interpreter REQUIRED)
find_package(tvm_ffi CONFIG REQUIRED)
```
