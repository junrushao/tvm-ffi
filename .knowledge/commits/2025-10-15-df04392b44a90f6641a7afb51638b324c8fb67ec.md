# Relocate CMake config to standard search path for automatic find_package discovery
## TL;DR
- Move CMake config files from `cmake/` to `share/cmake/tvm_ffi/` to match CMake's standard `<prefix>/<name>*/share/cmake/<name>*/` search pattern, enabling `find_package(tvm_ffi CONFIG REQUIRED)` without manually setting `tvm_ffi_ROOT`.
- Update `find_cmake_path()` in `libinfo.py` to check the new standard install path first, falling back to development-mode `../../cmake`.
- Simplify example and doc CMakeLists.txt files by removing `execute_process(...tvm_ffi.config --cmakedir...)` boilerplate; add `editable.rebuild = false` to `pyproject.toml` to avoid unnecessary rebuilds during editable installs.

## Impact
- API: none -- `find_cmake_path()` returns the same kind of path, just from a different location. `tvm_ffi.config --cmakedir` still works.
- Behavioral: downstream CMake consumers no longer need `execute_process(...tvm_ffi.config --cmakedir...)` before `find_package(tvm_ffi)`. The config is now auto-discoverable via CMake's standard search.
- Flags/config: `editable.rebuild = false` in `pyproject.toml` disables automatic C++ rebuild during `pip install -e .`, improving developer iteration speed for pure-Python changes.
- Data formats/schemas: none

## Usage Examples
Downstream CMake consumer (after this change):
```cmake
# Before: required manual path resolution
find_package(Python COMPONENTS Interpreter REQUIRED)
execute_process(
  COMMAND "${Python_EXECUTABLE}" -m tvm_ffi.config --cmakedir
  OUTPUT_STRIP_TRAILING_WHITESPACE OUTPUT_VARIABLE tvm_ffi_ROOT)
find_package(tvm_ffi CONFIG REQUIRED)

# After: automatic discovery (CMake finds via sys.prefix/share/cmake/tvm_ffi/)
find_package(Python COMPONENTS Interpreter REQUIRED)
find_package(tvm_ffi CONFIG REQUIRED)
```
