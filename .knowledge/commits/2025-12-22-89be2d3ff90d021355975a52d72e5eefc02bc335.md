# Documentation tweaks: rename ABI heading, add global func retrieval note, split example init blocks

## TL;DR
- Renamed the ABI concepts page heading from "ABI Specification" to "ABI Overview" (`docs/concepts/abi_overview.md`).
- Added an `.. note::` block to `docs/packaging/python_packaging.rst` showing how to retrieve global functions via `tvm_ffi.get_global_func` in Python, `TVMFFIFunctionGetGlobal` in C, and `tvm::ffi::Function::GetGlobal` in C++, with a Python usage example.
- Restructured `examples/python_packaging/src/extension.cc` to give `AddOne` its own `TVM_FFI_STATIC_INIT_BLOCK`, separate from `RaiseError`, aligning the `[global_function.begin/end]` doc-snippet markers with just the `AddOne` registration.

## Key Exports
None -- documentation and example restructuring only; no new public API surface.

## Impact
- API: none
- Behavioral: none -- the `AddOne` and `RaiseError` functions are registered identically; only the grouping of their `TVM_FFI_STATIC_INIT_BLOCK` calls changed.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Global function registration** (`refl::GlobalDef().def(...)` via `TVM_FFI_STATIC_INIT_BLOCK`) -- documented in [0008-reflection.md](../designs/0008-reflection.md) and [0004-function-system.md](../designs/0004-function-system.md). The example now shows each function in its own init block, reinforcing the convention that init blocks can be split per-function for clarity.
- **`tvm_ffi.get_global_func`** -- the Python-side retrieval API documented in [0012-python-bindings.md](../designs/0012-python-bindings.md). The new RST note adds cross-language equivalents (`TVMFFIFunctionGetGlobal` in C, `tvm::ffi::Function::GetGlobal` in C++).
- **Doc-snippet markers** (`[global_function.begin/end]`) -- convention in example code for extracting code blocks into documentation.

Design elements this commit produces:
- None -- purely documentary.

## Usage Examples
The new note added to `python_packaging.rst` demonstrates global function retrieval:

```python
import tvm_ffi

func = tvm_ffi.get_global_func("my_ffi_extension.add_one")
func(3)  # -> 4
```
