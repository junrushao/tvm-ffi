# Add comprehensive RecursiveHash Python test suite
## TL;DR
- Exposes `RecursiveHash` to the Python FFI API (`_ffi_api.py` stub + `__all__`).
- Adds two new testing dataclasses (`TestHash` with `Hash(false)` field exclusion, `TestCustomHash` with custom `__ffi_hash__` hook) to `tvm_ffi.testing`.
- Adds comprehensive `test_dataclass_hash.py` (971 lines) covering the full `RecursiveHash` contract from Python end-to-end.

## Impact
- **API**: One new internal `_ffi_api` symbol (`RecursiveHash`). Delegates to the C++ `ffi.RecursiveHash` global function already registered. No public API changes -- consumed by `@c_class`'s `unsafe_hash` dunder (introduced in follow-up commit `e5f3af7`).
- **Testing infrastructure**: `tvm_ffi.testing` gains `TestHash` (exercises `Hash(false)` field exclusion on `hash_ignored`) and `TestCustomHash` (exercises `__ffi_hash__` custom hook, hashes only `key`).
- **Flags/config**: None.
- **Data formats/schemas**: None.

## Design Elements

Design elements this commit **consumes**:

- **Dataclass Operations** ([`.knowledge/designs/0027-dataclass-operations.md`](../designs/0027-dataclass-operations.md)): The C++ `RecursiveHash` function from `src/ffi/extra/dataclass.cc`. This commit creates the Python-side typed stub.
- **Reflection System** ([`.knowledge/designs/0006-reflection.md`](../designs/0006-reflection.md)): Test fixtures use `Hash(false)` field flag and `__ffi_hash__` custom hook.

Design elements this commit **produces**:

- **Python-accessible recursive hash**: The `_ffi_api.RecursiveHash` binding enables Python code to invoke C++ recursive structural hashing. Consumed by `@c_class`'s `unsafe_hash=True` dunder in follow-up commit `e5f3af7`.

## Test Coverage

Tests in `test_dataclass_hash.py` covering:
- Primitives (int, float, bool, str, bytes, None, DataType, Device)
- NaN handling (all NaN payloads hash equal), signed zero (+0.0 and -0.0 hash identically)
- Containers (Array, List, Shape, Map, Dict -- equal/different/empty/nested)
- Reflected objects (TestIntPair, inherited fields, container fields)
- Field exclusion (Hash(false) via TestHash, Compare(false) implies hash-off)
- Custom hooks (__ffi_hash__ via TestCustomHash and TestCustomCompare)
- Cycle detection (self-referential List/Dict)
- Consistency law (RecursiveEq(a,b) implies RecursiveHash(a)==RecursiveHash(b))
- Aliasing invariants, recursion depth (127 and 1000 levels), DAG scaling (linear not exponential)
- Guard (__ffi_eq__ without __ffi_hash__ raises ValueError)
