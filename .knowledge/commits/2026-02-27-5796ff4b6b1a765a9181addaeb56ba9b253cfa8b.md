# Add comprehensive RecursiveHash Python test suite and expose RecursiveHash to Python FFI

## TL;DR
- Exposes the pre-existing C++ `RecursiveHash` global function to Python via `_ffi_api.py` stub and `__all__`.
- Adds two pre-existing C++ test fixtures (`TestHash`, `TestCustomHash`) to the Python `tvm_ffi.testing` module.
- Adds `tests/python/test_dataclass_hash.py` (971 LOC): comprehensive coverage of the `RecursiveHash` contract — primitives, containers, reflected objects, field exclusion, custom hooks, cycle/DAG scaling, aliasing invariants, and the `RecursiveEq ⟹ RecursiveHash` consistency law.

## Design Elements
Design elements this commit consumes:
- `RecursiveHash` C++ global function (`ffi.RecursiveHash`) — registered in `src/ffi/extra/dataclass.cc`; declared in `include/tvm/ffi/extra/dataclass.h`. Iterative (heap-stack) DFS hasher. Consistent with `RecursiveEq`. See `.knowledge/design-records/0009-structural-eq-hash.md`.
- `Hash(false)` field flag — excludes a field from hashing. Exercised via `TestHash.hash_ignored`. See `.knowledge/design-records/0006-reflection.md`.
- `Compare(false)` field flag — implies hash-off. Exercised via `TestCompare`. See `.knowledge/design-records/0006-reflection.md`.
- `__ffi_hash__` TypeAttr — custom hash hook registered via `TypeAttrDef<T>`. Exercised via `TestCustomHash`. See `.knowledge/design-records/0009-structural-eq-hash.md`.
- `TestHash` / `TestCustomHash` C++ objects — already registered in `src/ffi/testing/testing.cc` before this commit; now Python-accessible.
- `tvm_ffi.testing` module Python facade — `.knowledge/design-records/0013-python-package.md`.
- `ObjectGraphDFS` iterative DFS for cycle/DAG hashing — cycles survive gracefully (hash succeeds); shared DAGs hash in linear time.

## Usage Examples

The test file itself is the canonical usage reference. Key examples from `tests/python/test_dataclass_hash.py`:

```python
from tvm_ffi._ffi_api import RecursiveEq, RecursiveHash
import tvm_ffi
from tvm_ffi.testing import TestHash, TestCustomHash, TestEqWithoutHash

# Basic primitive hashing
assert RecursiveHash(42) == RecursiveHash(42)
assert RecursiveHash(math.nan) == RecursiveHash(math.nan)  # all NaN equal
assert RecursiveHash(-0.0) == RecursiveHash(0.0)           # signed-zero canonical

# Hash(false) field exclusion
a = TestHash(1, "x", 100)
b = TestHash(1, "x", 999)   # hash_ignored differs
assert RecursiveHash(a) == RecursiveHash(b)  # excluded field ignored

# Custom __ffi_hash__ hook
a = TestCustomHash(42, "alpha")
b = TestCustomHash(42, "beta")   # label differs but not hashed
assert RecursiveHash(a) == RecursiveHash(b)

# Guard: __ffi_eq__ without __ffi_hash__ must raise
obj = TestEqWithoutHash(1, "hello")
with pytest.raises(ValueError, match="__ffi_eq__ or __ffi_compare__ but not __ffi_hash__"):
    RecursiveHash(obj)

# Consistency law: RecursiveEq(a, b) => RecursiveHash(a) == RecursiveHash(b)
assert RecursiveEq(a, b)
assert RecursiveHash(a) == RecursiveHash(b)

# DAG scaling: linear, not exponential
d18 = _make_shared_binary_dag(18)
d19 = _make_shared_binary_dag(19)
# t19 <= t18 * 1.6 expected
```
