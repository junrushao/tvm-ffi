# Fix Map.get() performance by adding sentinel-based MapGetItemOrMissing FFI function

## TL;DR
- Adds `MapGetItemOrMissing` C++ FFI function that returns a singleton sentinel object on missing keys instead of throwing an exception, avoiding the expensive try/except overhead in Python `Map.get()`.
- Adds `MapGetMissingObject` FFI function exposing the singleton sentinel `ObjectRef` to Python as `MISSING`.
- Rewrites `Map.get()` and `ItemsView.__contains__()` in Python to use the sentinel pattern instead of catching `KeyError`.

## Impact
- API: Two new FFI functions (`ffi.MapGetItemOrMissing`, `ffi.MapGetMissingObject`) added to the global registry. Additive only.
- Behavioral: `Map.get()` no longer raises and catches `KeyError` internally. Performance improvement for missing-key lookups by avoiding Python exception creation overhead (fixes #326).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Map / MapObj** (`0006-ffi-containers`): Uses `MapObj.at()` for key lookup and `tvm::ffi::Error` as the miss signal in C++.
- **Global function registration** (`0004-ffi-function-system`): Registers two new global functions via `refl::GlobalDef().def(...)` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- **Object identity comparison**: Uses `Object.same_as()` for sentinel comparison in Python (avoiding `__eq__` overhead).

Design elements this commit produces:
- **Sentinel-based map lookup pattern**: Introduces a "missing sentinel" convention where a singleton `ObjectRef` serves as a return-value sentinel for "key not found," avoiding exception-based control flow. This is a new protocol not previously documented.

## Usage Examples

**Context**: Before/after showing the performance fix for `Map.get()`.

```python
# BEFORE (slow — exception on every miss):
# class Map:
#     def get(self, key, default=None):
#         try:
#             return self[key]          # calls MapGetItem -> throws KeyError on miss
#         except KeyError:              # Python exception creation is expensive
#             return default

# AFTER (fast — sentinel comparison):
from tvm_ffi.container import MISSING
from tvm_ffi import _ffi_api

m = Map({"a": 1, "b": 2})
ret = _ffi_api.MapGetItemOrMissing(m, "c")  # returns MISSING singleton (no exception)
if MISSING.same_as(ret):                      # identity check, O(1)
    result = None  # default
else:
    result = ret
```
