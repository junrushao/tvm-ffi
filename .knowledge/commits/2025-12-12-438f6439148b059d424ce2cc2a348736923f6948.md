# Optimize Map.get() to avoid exception-based control flow via MapGetItemOrMissing
## TL;DR
- Replaces `Map.get(key, default)` implementation from try/except `KeyError` to a sentinel-based approach using `MapGetItemOrMissing`, eliminating expensive exception creation on cache misses.
- Introduces a C++ singleton `GetMissingObject()` as a sentinel, exposed via `ffi.MapGetMissingObject`.
- Also optimizes `ItemsView.__contains__` to use `Map.get(key, MISSING)` instead of try/except.

## Key Exports

**Registered FFI functions** (new):
- `ffi.MapGetItemOrMissing(MapObj*, Any key) -> Any` -- returns value if key exists, otherwise returns the singleton missing object
- `ffi.MapGetMissingObject() -> ObjectRef` -- returns the singleton sentinel object

**Python module-level constant** (new, `python/tvm_ffi/container.py`):
```python
MISSING = _ffi_api.MapGetMissingObject()  # singleton sentinel
```

**Changed Python method** (`Map.get`):
```python
def get(self, key, default=None):
    ret = _ffi_api.MapGetItemOrMissing(self, key)
    if MISSING.same_as(ret):
        return default
    return ret
```

## Impact
- API: Two new internal FFI functions (`MapGetItemOrMissing`, `MapGetMissingObject`). `Map.get` public API unchanged.
- Behavioral: `Map.get()` no longer creates `KeyError` exceptions on cache misses, significantly reducing overhead in hot paths (fixes #326). The reference cycle issue from #327 is also mitigated since no exception is created.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Containers** (`.knowledge/designs/0008-containers.md`) -- `MapObj`, `Map` Python wrapper
- **Reference-cycle-free error handling** (commit 6ccbdb6) -- this change further reduces error path overhead by avoiding exception creation entirely

Design elements this commit produces:
- **Sentinel-based lookup pattern** -- `GetMissingObject()` singleton + `MapGetItemOrMissing` as the recommended fast-path for "get or default" operations on Map. Uses `same_as` (identity comparison) to check for the sentinel.

## Usage Examples

The optimization is transparent to users:
```python
import tvm_ffi

m = tvm_ffi.Map({"a": 1, "b": 2})
# Fast path: no KeyError exception created on miss
val = m.get("c", 0)  # returns 0, no exception overhead
```
