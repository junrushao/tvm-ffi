# Load library in config mode on Windows to fix DLL search path

## TL;DR
- On Windows (`sys.platform.startswith("win32")`), `libinfo.load_lib_ctypes` is called even in config mode to ensure the DLL search path is set correctly.
- Fixes cases where Cython extensions fail to load on Windows when `_is_config_mode()` skips all imports.
