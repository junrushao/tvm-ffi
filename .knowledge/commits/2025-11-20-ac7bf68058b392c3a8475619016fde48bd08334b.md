# Add reflection metadata and documentation export for DLL-exported FFI functions
## TL;DR
- Introduces compile-time flag `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` (default 0) that, when set to 1, causes `TVM_FFI_DLL_EXPORT_TYPED_FUNC` to emit a companion `__tvm_ffi__metadata_<name>` symbol containing the function's type schema as JSON.
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro for exporting documentation strings alongside functions, emitting `__tvm_ffi__doc_<name>` symbols.
- Exposes metadata and doc queries through C++ `ModuleObj::GetFunctionMetadata/GetFunctionDoc` and Python `Module.get_function_metadata/get_function_doc`.

## Key Exports

**Macros:**

- `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` -- Compile-time flag (0 or 1). When 1, enables metadata/doc symbol generation. Default: 0.
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)` -- (modified) Now exports `__tvm_ffi_<ExportName>` always. When `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`, also exports `__tvm_ffi__metadata_<ExportName>` returning JSON `{"type_schema":"..."}`.
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(ExportName, DocString)` -- (new) Exports `__tvm_ffi__doc_<ExportName>` returning the docstring. Only active when `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`. No-op otherwise.
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC_IMPL_(ExportName, Function)` -- (internal) Factored-out C ABI wrapper generation, used by the public macros. Not for direct use.

**Constants:**

- `tvm::ffi::symbol::tvm_ffi_doc_prefix` = `"__tvm_ffi__doc_"` -- Symbol prefix for documentation getters (`include/tvm/ffi/extra/module.h`).

**C++ Methods (virtual overrides in `LibraryModuleObj`):**

- `LibraryModuleObj::GetFunctionMetadata(const String& name) -> Optional<String>` -- Resolves `__tvm_ffi__metadata_<name>` symbol in loaded library, invokes it via `Function::InvokeExternC`, returns JSON string.
- `LibraryModuleObj::GetFunctionDoc(const String& name) -> Optional<String>` -- Resolves `__tvm_ffi__doc_<name>` symbol in loaded library, invokes it, returns docstring.

**Python Methods (on `Module`):**

- `Module.get_function_metadata(name: str, query_imports: bool = False) -> dict[str, Any] | None` -- Returns parsed JSON dict with `type_schema` key, or None.
- `Module.get_function_doc(name: str, query_imports: bool = False) -> str | None` -- Returns docstring or None.

**Python Helpers:**

- `tvm_ffi.cpp.extension._escape_cpp_string_literal(s: str) -> str` -- Escapes `\`, `"`, `\n`, `\r`, `\t` for embedding in C++ string literals.
- `tvm_ffi.cpp.extension._CPP_ESCAPE_TABLE` -- Translation table used by the escape function.

## Impact
- API: New public Python methods `Module.get_function_metadata()` and `Module.get_function_doc()`. New C++ macros `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` and `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA`. No breaking changes -- metadata is opt-in (flag defaults to 0), and the existing `TVM_FFI_DLL_EXPORT_TYPED_FUNC` behavior is unchanged when the flag is not set.
- Behavioral: When `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`, the export macro now generates additional symbols. Existing binaries compiled without the flag are unaffected.
- Flags/config: `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` preprocessor flag. Can be set via `-D` compiler flag or `#define` before including `function.h`.
- Data formats/schemas: Metadata symbol returns JSON string `{"type_schema":"<escaped-json>"}` where `type_schema` is the output of `FuncInfo::TypeSchema()`.

## Design Elements
Design elements this commit consumes:
- **Function system** (`0004-function-system.md`): `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro, `Function::InvokeExternC`, `FunctionInfo<F>::TypeSchema()`, `details::unpack_call`, `TVM_FFI_SAFE_CALL_BEGIN/END`.
- **Module system** (`0013-module-system.md`): `ModuleObj` virtual interface (`GetFunction`, `GetFunctionMetadata`, `GetFunctionDoc`), `LibraryModuleObj`, `Library::GetSymbol`, `tvm_ffi_metadata_prefix` symbol constant.
- **Reflection system** (`0009-reflection.md`): `reflection::GlobalDef` for registering test functions, `FuncInfo::TypeSchema()` for type introspection.
- **Type traits** (`0005-type-traits.md`): `TypeTraits<String>::MoveToAny` for returning string results through the C ABI.
- **JSON** (`0012-json-and-serialization.md`): `json::Parse` used in tests to validate metadata JSON, `EscapeString` used in macro to escape type schema.
- **Python package** (`0014-python-package.md`): `_decorate_with_tvm_ffi` for generating export wrappers, `build_inline`/`load_inline` for building C++ extensions.

Design elements this commit produces:
- **Metadata export protocol**: A convention where `TVM_FFI_DLL_EXPORT_TYPED_FUNC` (with `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`) emits companion symbol `__tvm_ffi__metadata_<name>` alongside `__tvm_ffi_<name>`. The metadata symbol has the same `TVMFFISafeCallType` signature and returns a JSON string.
- **Documentation export protocol**: `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` emits `__tvm_ffi__doc_<name>` symbol returning a docstring via the same calling convention.
- **`tvm_ffi_doc_prefix`** symbol constant complements the existing `tvm_ffi_metadata_prefix`.

## Usage Examples

**C++ -- export function with metadata and documentation:**
```cpp
#define TVM_FFI_DLL_EXPORT_INCLUDE_METADATA 1
#include <tvm/ffi/function.h>

int Add(int a, int b) { return a + b; }

TVM_FFI_DLL_EXPORT_TYPED_FUNC(add, Add);
TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(add, R"(Add two integers.)");
```

**Python -- query metadata and doc from loaded module:**
```python
import tvm_ffi
from tvm_ffi.core import TypeSchema

mod = tvm_ffi.load_module("mylib.so")
metadata = mod.get_function_metadata("add")
# metadata == {"type_schema": '{"type":"ffi.Function","args":[{"type":"int"},{"type":"int"},{"type":"int"}]}'}
schema = TypeSchema.from_json_str(metadata["type_schema"])
print(schema)  # Callable[[int, int], int]

doc = mod.get_function_doc("add")
print(doc)  # "Add two integers."
```

**Python -- `load_inline` with metadata and docstrings:**
```python
mod = tvm_ffi.cpp.load_inline(
    name="example",
    cpp_sources='int square(int x) { return x * x; }',
    functions={"square": "Return x squared."},
    extra_cflags=["-DTVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1"],
)
assert mod.get_function_metadata("square") is not None
assert mod.get_function_doc("square") == "Return x squared."
```
