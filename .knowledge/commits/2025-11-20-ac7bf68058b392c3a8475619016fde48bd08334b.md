# Embed type-schema metadata and docstrings for FFI-exported functions via new macros

## TL;DR
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(ExportName, DocString)` macro to `function.h` for exporting C-string docstrings as `__tvm_ffi__doc_<ExportName>` symbols.
- When `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`, `TVM_FFI_DLL_EXPORT_TYPED_FUNC` now also exports a `__tvm_ffi__metadata_<ExportName>` symbol returning `{"type_schema": "..."}` JSON.
- Adds Python `Module.get_function_metadata(name)` and `Module.get_function_doc(name)` methods; adds `tvm_ffi_doc_prefix` constant to C++ module symbol namespace.

## Key Exports

```python
# include/tvm/ffi/function.h

# Compile-time toggle (default: 0 = off)
TVM_FFI_DLL_EXPORT_INCLUDE_METADATA: int = 0  # set to 1 to enable metadata export

# Macro: TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)
# When TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=0 (default):
#   exports: __tvm_ffi_<ExportName>(void*, TVMFFIAny*, int32_t, TVMFFIAny*) -> int
# When TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1:
#   exports: __tvm_ffi_<ExportName>  (same as before)
#   exports: __tvm_ffi__metadata_<ExportName>  -> JSON string {"type_schema": "..."}
#   Interacts with: FuncInfo::TypeSchema(), EscapeString(), TypeTraits<String>::MoveToAny()

# Macro: TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(ExportName, DocString)
# When TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1:
#   exports: __tvm_ffi__doc_<ExportName>(void*, TVMFFIAny*, int32_t, TVMFFIAny*) -> String
# When TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=0: no-op
# Invariant: must pair with a corresponding TVM_FFI_DLL_EXPORT_TYPED_FUNC call

# include/tvm/ffi/extra/module.h - new symbol prefix constant
tvm_ffi_doc_prefix: str = "__tvm_ffi__doc_"
# Interacts with: tvm_ffi_metadata_prefix ("__tvm_ffi__metadata_")

# python/tvm_ffi/module.py

class Module:
    def get_function_metadata(
        self, name: str, query_imports: bool = False
    ) -> dict[str, Any] | None:
        """Returns parsed JSON metadata dict, e.g. {"type_schema": "Callable[...]"}, or None."""
        # Interacts with: _ffi_api.ModuleGetFunctionMetadata, json.loads()

    def get_function_doc(
        self, name: str, query_imports: bool = False
    ) -> str | None:
        """Returns docstring for name, or None if not exported."""
        # Interacts with: _ffi_api.ModuleGetFunctionDoc
```

## Impact
- API: New Python methods `Module.get_function_metadata()` and `Module.get_function_doc()` added (additive). New C++ macros additive. No breaking changes.
- Behavioral: `TVM_FFI_DLL_EXPORT_TYPED_FUNC` behavior unchanged when `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=0` (the default); additional symbols only emitted when flag is 1.
- Flags/config: `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` preprocessor define (default 0). Users building kernel libraries enable this to expose type schemas to consumers.
- Data formats/schemas: Metadata JSON schema: `{"type_schema": "<TypeSchema JSON string>"}`.

## Design Elements
Design elements this commit consumes:
- `0004-function-system`: `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro — extended with conditional metadata emission.
- `0011-module-system`: `ModuleObj::GetFunctionDoc`/`GetFunctionMetadata` virtual methods; `tvm_ffi_metadata_prefix` constant; `Library::GetSymbolWithSymbolPrefix`.
- `0019-type-schema`: `FuncInfo::TypeSchema()` produces the type_schema JSON for the metadata payload.

Design elements this commit produces:
- **`TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro**: new convention for embedding docstrings in kernel library `.so` files, keyed by `__tvm_ffi__doc_<name>` symbol.
- **`TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` compile flag**: new opt-in build-time mechanism for metadata embedding.
- **`Module.get_function_metadata()` / `Module.get_function_doc()`**: new Python API surface for querying per-function schema and docs from a loaded `Module`.

## Usage Examples

```cpp
// C++ kernel library (e.g., add_one_cpu.cc)
#define TVM_FFI_DLL_EXPORT_INCLUDE_METADATA 1
#include <tvm/ffi/function.h>

int AddOne(int x) { return x + 1; }

TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, AddOne);
TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(
    add_one,
    R"(Add one to the integer.

Parameters
----------
x : int
Returns
-------
result : int)");
```

```python
# Python consumer
import tvm_ffi

mod = tvm_ffi.load_module("add_one_cpu.so")
metadata = mod.get_function_metadata("add_one")
# -> {"type_schema": '{"origin": "Callable", "args": [...]}'}
doc = mod.get_function_doc("add_one")
# -> "Add one to the integer.\n..."
```
