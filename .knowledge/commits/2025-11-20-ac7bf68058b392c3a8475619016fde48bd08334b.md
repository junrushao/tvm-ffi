# Embed metadata for FFI exported functions via DLL export macros
## TL;DR
- Adds reflection metadata support for functions exported via `TVM_FFI_DLL_EXPORT_TYPED_FUNC`, including function signatures and documentation strings.
- When `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`, each exported function also exports a `__tvm_ffi__metadata_<ExportName>` symbol containing type signature and optional docstring.
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro variant that includes documentation.
- Updates Python `module.py` to read and expose function metadata.

## Key Exports

**Macros (C++):**
- `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` -- Build flag (0/1) controlling whether metadata symbols are emitted alongside exported functions.
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)` -- Now optionally exports metadata symbol when `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`.
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(ExportName, Function, DocStr)` -- New variant that includes a documentation string in the exported metadata.

**Metadata Symbol Format:**
- `__tvm_ffi__metadata_<ExportName>` -- Exported C function that returns a JSON/structured string containing the function's type signature and optional docstring.

**Python:**
- `Module` class in `module.py` updated to parse and expose function metadata from loaded shared libraries.

## Impact
- API: New `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro. Metadata accessible from Python via module introspection.
- ABI: New optional `__tvm_ffi__metadata_*` symbols (additive, opt-in via build flag).
- Behavioral: none (metadata export is opt-in)
- Flags/config: `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=0|1` controls metadata emission.
- Data formats/schemas: Metadata string format for function type signatures.

## Design Elements
Design elements this commit consumes:
- DLL export macro pattern (`TVM_FFI_DLL_EXPORT_TYPED_FUNC`)
- Module system (`load_module`)
- `FunctionInfo<F>` template machinery

Design elements this commit produces:
- **Function metadata export pattern** -- Optional metadata symbols alongside exported functions, enabling runtime reflection of function signatures and documentation.
- `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` build flag.

## Usage Examples
```cpp
// Export with metadata and documentation
#define TVM_FFI_DLL_EXPORT_INCLUDE_METADATA 1
TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(MyAdd,
    [](int a, int b) -> int { return a + b; },
    "Add two integers.");

// Python side:
mod = tvm_ffi.load_module("libmy.so")
f = mod["MyAdd"]
print(f.metadata)  # Includes type signature and docstring
```
