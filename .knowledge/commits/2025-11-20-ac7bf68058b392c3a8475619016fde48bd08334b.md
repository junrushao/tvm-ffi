# Embed reflection metadata for FFI exported functions
## TL;DR
- Extends `TVM_FFI_DLL_EXPORT_TYPED_FUNC` to export a companion `__tvm_ffi__metadata_<name>` symbol containing JSON type schema for each exported function.
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro that also exports a `__tvm_ffi__doc_<name>` documentation symbol.
- Adds C++ Module API (`GetFunctionMetadata`, `GetFunctionDoc`) and Python API (`mod.get_function_metadata()`, `mod.get_function_doc()`).
- Enables compile-time signature validation for compiler frameworks (JAX/XLA, MLIR) without invoking the function.

## Impact
- API: New macros, new Module methods (C++ and Python), new exported symbols per function
- Flags/config: None
- Data formats/schemas: New JSON metadata format `{"type_schema": "..."}`
