# Embed metadata and docstrings for FFI DLL-exported functions via opt-in macros

## TL;DR
- Adds opt-in metadata embedding for DLL-exported functions: when `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` is defined to 1, `TVM_FFI_DLL_EXPORT_TYPED_FUNC` now exports both `__tvm_ffi_<name>` and `__tvm_ffi__metadata_<name>` symbols. A new `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro exports `__tvm_ffi__doc_<name>` for docstrings.
- Implements `LibraryModuleObj::GetFunctionMetadata` and `LibraryModuleObj::GetFunctionDoc` overrides to look up these symbols from loaded libraries, completing the metadata retrieval path from C++ to Python.
- Adds Python `Module.get_function_metadata()` and `Module.get_function_doc()` methods, and wires `_decorate_with_tvm_ffi` in `extension.py` to emit `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` when docstrings are provided.
- Refactors testing.cc to extract schema test functions from inline lambdas into named functions in `schema_test_impl` namespace, enabling them to be used as DLL export targets.

## Impact
- API: Additive. New `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro, new `symbol::tvm_ffi_doc_prefix` constant, new Python methods `Module.get_function_metadata()` and `Module.get_function_doc()`. The existing `TVM_FFI_DLL_EXPORT_TYPED_FUNC` behavior is unchanged when `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` is 0 (the default).
- Behavioral: When `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`, `TVM_FFI_DLL_EXPORT_TYPED_FUNC` now emits an additional metadata symbol per exported function. Libraries compiled with the flag produce more symbols.
- Flags/config: New compile-time flag `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` (default 0). Must be `#define`d before `#include <tvm/ffi/function.h>` or passed as `-D` flag.
- Data formats/schemas: Metadata symbol returns JSON `{"type_schema": "<json-encoded-signature>"}`. Doc symbol returns raw string. Both follow the SafeCallType calling convention.

## Usage Examples

**End-to-end: C++ export with metadata and docstring, Python retrieval**

C++ side (`my_lib.cc`):
```cpp
#define TVM_FFI_DLL_EXPORT_INCLUDE_METADATA 1
#include <tvm/ffi/function.h>

int Add(int a, int b) { return a + b; }

TVM_FFI_DLL_EXPORT_TYPED_FUNC(add, Add);
TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(add, "Add two integers.");
```

Python side:
```python
import tvm_ffi
from tvm_ffi.core import TypeSchema

mod = tvm_ffi.load_module("my_lib.so")
result = mod.add(1, 2)  # 3

# Query type schema
metadata = mod.get_function_metadata("add")
# {"type_schema": "{\"type\":\"ffi.Function\",\"args\":[...]}"}
schema = TypeSchema.from_json_str(metadata["type_schema"])
print(schema)  # Callable[[int, int], int]

# Query docstring
doc = mod.get_function_doc("add")  # "Add two integers."
```

**Inline build with metadata and docstrings (Python)**:
```python
mod = tvm_ffi.cpp.load_inline(
    name="example",
    cpp_sources='int square(int x) { return x * x; }',
    functions={"square": "Return x squared."},
    extra_cflags=["-DTVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1"],
)
assert mod.square(5) == 25
assert mod.get_function_doc("square") == "Return x squared."
```
