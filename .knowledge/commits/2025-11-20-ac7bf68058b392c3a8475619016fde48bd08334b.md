# Embed metadata and documentation for DLL-exported FFI functions
## TL;DR
- Adds `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` compile-time flag and `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro, enabling DLL-exported functions to carry type schema metadata and documentation as additional exported symbols.
- Implements `LibraryModuleObj::GetFunctionMetadata` and `GetFunctionDoc` to look up `__tvm_ffi__metadata_<name>` and `__tvm_ffi__doc_<name>` symbols from loaded shared libraries.
- Adds Python-side `Module.get_function_metadata()` and `Module.get_function_doc()` methods; updates `_decorate_with_tvm_ffi` to emit doc export macros when docstrings are provided.

## Impact
- API: Additive -- new Python methods `Module.get_function_metadata()` and `Module.get_function_doc()`. New C++ macro `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC`. No existing APIs changed.
- Behavioral: `TVM_FFI_DLL_EXPORT_TYPED_FUNC` now conditionally exports a metadata symbol alongside the function symbol when `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1`. Default behavior (flag=0) is unchanged.
- Flags/config: New compile-time flag `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` (default 0). Users must `#define TVM_FFI_DLL_EXPORT_INCLUDE_METADATA 1` before including `function.h` or pass `-DTVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1` via `extra_cflags` to enable metadata export.
- Data formats/schemas: Metadata is a JSON string `{"type_schema": "<schema_json>"}` where `type_schema` is the existing `FunctionInfo::TypeSchema()` output. Doc is a raw string.

## Usage Examples

**C++ side: Export a function with metadata and documentation**
```cpp
#define TVM_FFI_DLL_EXPORT_INCLUDE_METADATA 1
#include <tvm/ffi/function.h>

int64_t Add(int64_t a, int64_t b) { return a + b; }

TVM_FFI_DLL_EXPORT_TYPED_FUNC(add, Add);
TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(add, R"(Add two integers.)");
```

**Python side: Query metadata and docs from loaded module**
```python
import tvm_ffi
from tvm_ffi.core import TypeSchema

mod = tvm_ffi.load_module("add.so")
metadata = mod.get_function_metadata("add")
# metadata == {"type_schema": '{"type":"ffi.Function","args":[...]}'}
schema = TypeSchema.from_json_str(metadata["type_schema"])
print(schema)  # Callable[[int, int], int]

doc = mod.get_function_doc("add")
print(doc)  # "Add two integers."
```

**Python inline build with metadata enabled**
```python
mod = tvm_ffi.cpp.load_inline(
    name="my_lib",
    cpp_sources='int square(int x) { return x * x; }',
    functions={"square": "Compute the square of x."},
    extra_cflags=["-DTVM_FFI_DLL_EXPORT_INCLUDE_METADATA=1"],
)
assert mod.get_function_metadata("square") is not None
assert mod.get_function_doc("square") == "Compute the square of x."
```
