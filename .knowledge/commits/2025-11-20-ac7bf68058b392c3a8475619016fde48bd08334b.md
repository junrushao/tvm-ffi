# Embed metadata for FFI exported functions via TVM_FFI_DLL_EXPORT_TYPED_FUNC
## TL;DR
- Extends `TVM_FFI_DLL_EXPORT_TYPED_FUNC` to optionally export a companion `__tvm_ffi__metadata_<name>` symbol containing JSON type schema, gated by `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA`.
- Adds new `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC` macro for exporting documentation strings as `__tvm_ffi__doc_<name>` symbols.
- Adds `Module::GetFunctionMetadata(name)` and `Module::GetFunctionDoc(name)` C++ and Python APIs for querying metadata/docs from loaded modules.

## Key Exports

```python
# Macro (C preprocessor): TVM_FFI_DLL_EXPORT_INCLUDE_METADATA
# When set to 1, TVM_FFI_DLL_EXPORT_TYPED_FUNC additionally exports:
#   __tvm_ffi__metadata_<ExportName> -> returns JSON string: {"type_schema": "..."}
# Interacts with: FunctionInfo<T>::TypeSchema(), EscapeString
# Invariant: metadata symbol has same C-ABI signature as the function symbol

# Macro: TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(ExportName, DocString)
# Exports: __tvm_ffi__doc_<ExportName> -> returns String(DocString)
# Interacts with: TVM_FFI_DLL_EXPORT_TYPED_FUNC (associated by name)
# Invariant: only exported when TVM_FFI_DLL_EXPORT_INCLUDE_METADATA == 1

class Module:
    def get_function_metadata(self, name: str) -> Optional[str]: ...
    # Interacts with: LibraryModuleObj, __tvm_ffi__metadata_<name> symbol lookup
    # Invariant: returns None if no metadata symbol found

    def get_function_doc(self, name: str) -> Optional[str]: ...
    # Interacts with: LibraryModuleObj, __tvm_ffi__doc_<name> symbol lookup
    # Invariant: returns None if no doc symbol found
```

## Impact
- API: new macros `TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC`, flag `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA`; new methods `Module.get_function_metadata()`, `Module.get_function_doc()`
- Behavioral: existing `TVM_FFI_DLL_EXPORT_TYPED_FUNC` unchanged when flag is 0 (default)
- Flags/config: `TVM_FFI_DLL_EXPORT_INCLUDE_METADATA` (compile-time, default 0)
- Data formats/schemas: metadata JSON format `{"type_schema": "<escaped JSON>"}`

## Design Elements
Design elements this commit consumes:
- Function system (0003-function-system): `TVM_FFI_DLL_EXPORT_TYPED_FUNC`, `FunctionInfo<T>::TypeSchema()`.
- Module system (0011-module-system): `LibraryModuleObj`, symbol lookup.
- Reflection (0008-reflection): `TypeSchema` JSON format.

Design elements this commit produces:
- Metadata export convention: `__tvm_ffi__metadata_<name>` and `__tvm_ffi__doc_<name>` symbol naming convention.
- `Module.get_function_metadata()` / `Module.get_function_doc()` API surface.

## Usage Examples
```cpp
// C++ — export function with metadata and docs
#define TVM_FFI_DLL_EXPORT_INCLUDE_METADATA 1
int Add(int a, int b) { return a + b; }
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add, Add);
TVM_FFI_DLL_EXPORT_TYPED_FUNC_DOC(add, "Add two integers.");

// Python — query metadata from loaded module
mod = tvm_ffi.module.load_module("libkernel.so")
metadata = mod.get_function_metadata("add")
# Returns: '{"type_schema": "{\"type\":\"ffi.Function\",\"args\":[...]}"}'
doc = mod.get_function_doc("add")
# Returns: "Add two integers."
```
