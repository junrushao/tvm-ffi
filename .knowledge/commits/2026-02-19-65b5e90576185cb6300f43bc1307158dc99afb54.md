# Add AMD HIP/ROCm backend support to the tvm_ffi.cpp extension build system

## TL;DR

- Adds a `backend: str | None` parameter to all four public `tvm_ffi.cpp` entry points (`build_inline`, `load_inline`, `build`, `load`); accepted values are `"cuda"`, `"hip"`, or `None` (auto-detect).
- Introduces `_detect_gpu_backend()` (cached auto-detection via `TVM_FFI_GPU_BACKEND` env or ROCm home probe) and three HIP-specific helpers: `_find_rocm_home()`, `_get_rocm_target()`, and `_resolve_gpu_backend()`.
- Replaces the internal boolean `with_cuda` flag in `_generate_ninja_build` and `_build_impl` with a `backend: str | None` parameter, routing `hipcc` compilation through the `compile_cuda` Ninja rule when `backend == "hip"`.

## Impact

- API: `backend: str | None = None` added to `build_inline`, `load_inline`, `build`, `load` — additive, backward-compatible; existing callers unaffected.
- Behavioral: when `cuda_sources`/`cuda_files` are provided and `backend` is not set, `_detect_gpu_backend()` auto-selects HIP on ROCm machines; previously CUDA was always assumed.
- Flags/config: two new env variables: `TVM_FFI_GPU_BACKEND` (override backend choice: `"cuda"` or `"hip"`) and `TVM_FFI_ROCM_ARCH_LIST` (space-separated arch list, e.g. `"gfx90a gfx942"`).
- Data formats/schemas: Ninja build file gains a `hipcc`-backed `compile_cuda` rule when `backend == "hip"`; HIP compile command omits `--generate-dependencies-with-compile` (hipcc doesn't support it).

## Usage Examples

**Context**: Compiling a HIP kernel inline and running on an AMD GPU.

```python
import torch
from tvm_ffi import Module
import tvm_ffi.cpp

hip_source = '''
#include <hip/hip_runtime.h>

__global__ void add_one_kernel(const float* x, float* y, int64_t n) {
    int64_t i = (int64_t)blockIdx.x * blockDim.x + threadIdx.x;
    if (i < n) y[i] = x[i] + 1.0f;
}

void add_one_hip(tvm::ffi::TensorView x, tvm::ffi::TensorView y) {
    int64_t n = x.size(0);
    constexpr int threads = 256;
    hipLaunchKernelGGL(add_one_kernel, dim3((n + threads - 1) / threads),
                       dim3(threads), 0, 0,
                       (const float*)x.data_ptr(), (float*)y.data_ptr(), n);
}
'''

mod: Module = tvm_ffi.cpp.load_inline(
    name="hello",
    cuda_sources=hip_source,   # HIP source goes in cuda_sources
    functions="add_one_hip",
    backend="hip",             # explicit; or omit for auto-detect on ROCm machine
)

x = torch.tensor([1, 2, 3, 4, 5], dtype=torch.float32, device="cuda")
y = torch.empty_like(x)
mod.add_one_hip(x, y)
torch.testing.assert_close(x + 1, y)
```

**Cross-layer trace**: `cuda_sources=hip_source, backend="hip"` → `_resolve_gpu_backend("hip")` returns `"hip"` → `_build_impl` writes `cuda.cu` → `_generate_ninja_build(backend="hip")` emits `nvcc = <rocm_home>/bin/hipcc` + HIP cflags + `--offload-arch=gfxNNNN` → `ninja` compiles via `hipcc -fPIC -D__HIP_PLATFORM_AMD__=1 -fno-gpu-rdc ...` → shared library loaded by `load_module`.
