# Support AMD HIP backend for C++ extension compilation
## TL;DR
- Extends `tvm_ffi.cpp.extension` to support AMD HIP/ROCm as a GPU backend alongside CUDA.
- Adds auto-detection of ROCm installation and GPU architecture via `rocm_agent_enumerator`/`rocminfo`.
- Introduces `TVM_FFI_GPU_BACKEND` env var override and `backend` parameter to `_generate_ninja_build`.

def _get_rocm_target() -> list[str]: ...
    # Interacts with: TVM_FFI_ROCM_ARCH_LIST env var, rocm_agent_enumerator, rocminfo

## Impact
- API: `load_inline` and `load_cpp` now accept `backend` parameter ("cuda"/"hip"/None for auto-detect).
- Behavioral: HIP compilation uses `hipcc` instead of `nvcc`, links `-lamdhip64`.
- Flags/config: New env vars `TVM_FFI_GPU_BACKEND`, `TVM_FFI_ROCM_ARCH_LIST`, `ROCM_HOME`/`ROCM_PATH`.
- Data formats/schemas: None
