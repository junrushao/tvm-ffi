# Add AMD HIP support to cpp extension (load_inline)
## TL;DR
- Extends `tvm_ffi.cpp.extension` to support AMD HIP compilation alongside NVIDIA CUDA, detecting HIP via `hipcc` and ROCm environment variables.
- Adds HIP-specific compilation flags, architecture detection (`rocm_agent_enumerator`), and GPU target mapping for AMD GPUs.
- Single file change: `python/tvm_ffi/cpp/extension.py` (155 lines added, 18 removed).

## Key Exports

**Python** (modified in `extension.py`):
- `load_inline(name, cuda_sources=..., functions=...)` now supports HIP sources when the system has ROCm/HIP installed (auto-detected). Uses `hipcc` compiler with appropriate flags.

## Impact
- API: `load_inline` now works on AMD ROCm systems. The `cuda_sources` parameter name is reused for HIP source code.
- Behavioral: Auto-detects HIP vs CUDA based on available toolchains.
- Flags/config: Checks `ROCM_HOME`, `HIP_PATH` environment variables for HIP detection.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Module system** (`.knowledge/designs/0013-module-system.md`): `load_inline` uses the module loading infrastructure.
- **Cubin launcher** (`.knowledge/designs/0021-cubin-launcher.md`): GPU target detection and compilation.

Design elements this commit produces:
- **HIP compilation path**: AMD HIP support in `load_inline`, including architecture detection and `hipcc` invocation.

## Usage Examples

```python
import tvm_ffi.cpp

mod = tvm_ffi.cpp.load_inline(
    name="hello",
    cuda_sources='''
#include <hip/hip_runtime.h>
__global__ void add_one_kernel(const float* x, float* y, int64_t n) {
    int64_t i = blockIdx.x * blockDim.x + threadIdx.x;
    if (i < n) y[i] = x[i] + 1.0f;
}
void add_one_hip(tvm::ffi::TensorView x, tvm::ffi::TensorView y) { /* ... */ }
''',
    functions="add_one_hip",
)
```
