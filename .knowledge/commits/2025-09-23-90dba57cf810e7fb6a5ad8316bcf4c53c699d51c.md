# Fix Array slicing to return list[T] instead of Array[T], restoring original TVM behavior
## TL;DR
- Reverts a behavioral regression introduced in PR #37 (`df58a05`) where `Array.__getitem__` with a slice returned `Array[T]` instead of `list[T]`.
- Removes the `list`-to-`Array` wrapping in `Array.__getitem__` so that `getitem_helper`'s native `list` return is passed through directly.
- Adds a test assertion confirming slices produce `list` instances.

## Key Exports
**Functions (changed signature/behavior)**:
- `Array.__getitem__(self, idx: slice) -> list[T]` -- previously returned `Array[T]`, now returns `list[T]`. The `@overload` type annotations are updated to match.

## Impact
- API: Callers that relied on `Array[start:stop]` returning an `Array` (only possible since PR #37) will now receive a `list`. This restores the original TVM stack behavior.
- ABI: none
- Behavioral: `Array.__getitem__` with a `slice` argument now returns `list[T]` instead of `Array[T]`. The `isinstance(a[0:2], list)` assertion now holds.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Python container wrappers** (`.knowledge/designs/containers.md`, "Python Container Wrappers" section) -- `Array.__getitem__` delegates to `getitem_helper` which returns a `list` for slices.
- **`getitem_helper`** (`.knowledge/designs/0014-python-bindings.md`, "Container Wrappers" section) -- shared indexing helper that builds a `list` from individual element lookups.

Design elements this commit produces:
- None (restores prior behavior, no new design elements).

## Usage Examples
**Before (PR #37 regression)**:
```python
a = tvm_ffi.convert([1, 2, 3])
s = a[0:2]
type(s)  # Array -- incorrect, broke downstream tests
```

**After (this fix)**:
```python
a = tvm_ffi.convert([1, 2, 3])
s = a[0:2]
assert isinstance(s, list)  # True -- restored original behavior
assert s == [1, 2]
```
