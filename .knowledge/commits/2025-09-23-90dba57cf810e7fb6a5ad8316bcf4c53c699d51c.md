# Fix Array slicing to return list[T] instead of Array[T], restoring original TVM behavior

## TL;DR
- Reverts Array slice return type from `Array[T]` to `list[T]`, fixing a behavioral regression introduced by PR #37.
- Removes the post-slice wrapping logic (`type(self)(result)`) in `Array.__getitem__`, letting `getitem_helper`'s native `list` return pass through directly.
- Adds a test assertion confirming the slice result is a `list`.

## Key Exports
**Type signature change** in `Array.__getitem__`:

| Overload | Before (PR #37) | After (this fix) |
|----------|-----------------|-------------------|
| `__getitem__(idx: slice)` | `-> Array[T]` | `-> list[T]` |
| `__getitem__(idx: SupportsIndex \| slice)` | `-> T \| Array[T]` | `-> T \| list[T]` |

## Impact
- API: Return type of `Array.__getitem__(slice)` changes from `Array[T]` back to `list[T]`. Callers that relied on the PR #37 behavior (receiving an `Array` from a slice) will now receive a `list`. This restores compatibility with the original TVM stack.
- Behavioral: `getitem_helper` already returned `list` for slices; PR #37 added a re-wrapping step (`type(self)(result)`) that is now removed, so the `list` passes through unchanged.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **`Array` Python wrapper** ([0008-containers.md](../designs/0008-containers.md)) -- the `__getitem__` method and its slice handling.
- **`getitem_helper` utility** (`python/tvm_ffi/container.py:41`) -- shared pythonic `__getitem__` implementation that returns `T` for integer indices and `list[T]` for slices.
- **`_ffi_api.ArrayGetItem`** -- C++ FFI function for element access, called per-element by `getitem_helper`.

Design elements this commit produces:
- None. This is a behavioral restoration, not a new design element.

## Usage Examples
**Before (PR #37 regression):**
```python
a = tvm_ffi.Array([1, 2, 3])
s = a[0:2]
# s was Array([1, 2]) -- broke callers expecting list
type(s)  # <class 'tvm_ffi.container.Array'>
```

**After (this fix):**
```python
a = tvm_ffi.Array([1, 2, 3])
s = a[0:2]
# s is [1, 2] -- plain list, matching original TVM behavior
type(s)  # <class 'list'>
assert isinstance(s, list)
```
