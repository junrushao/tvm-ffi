# Revert Array slicing to return list instead of Array
## TL;DR
- Reverts `Array.__getitem__` slice behavior to return `list[T]` instead of `Array[T]`, restoring backward compatibility with the existing TVM stack (broken by PR #37).

## Impact
- API: `Array[start:stop]` returns `list[T]` again (was `Array[T]` briefly).
- Flags/config: none
- Data formats/schemas: none
