# Improve register_object type hint so the decorator preserves the original class type

## TL;DR
- Introduces `_T = TypeVar("_T", bound=type)` in `registry.py` and updates `register_object` signature to `(type_key: str) -> Callable[[_T], _T]`, ensuring the decorator's return type matches the input class type for mypy/pyright.

## Key Exports

```python
# python/tvm_ffi/registry.py
_T = TypeVar("_T", bound=type)

def register_object(type_key: str) -> Callable[[_T], _T]:
    """Register an FFI object class under type_key.
    # Before: return type was Callable[[type], type] — treated as value, not type
    # After: return type is Callable[[_T], _T] — preserves original class type
    """
    ...
```

## Impact
- API: Type signature change for `register_object`; no runtime change.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: `register_object` decorator (0013-python-package)
Design elements this commit produces: none (type annotation improvement only)

## Usage Examples
```python
# Before: type checker reported MyClass as a value, not a type
# After: type checker correctly infers MyClass as type
@register_object("my.Class")
class MyClass(ObjectRef):  # MyClass: type[MyClass] ✓
    pass
```
