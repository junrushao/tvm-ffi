# Improve type hint of register_object to preserve decorated class type
## TL;DR
- Adds `_T` type variable to `register_object` so the decorator preserves the original type of the decorated class
- Fixes type lint errors where decorated objects were treated as generic values instead of typed classes

## Key Exports
```python
_T = TypeVar("_T")

@overload
def register_object(type_key: str) -> Callable[[_T], _T]: ...
@overload
def register_object(type_key: type[_T]) -> type[_T]: ...
```

- API: Type hints improved; runtime behavior unchanged
