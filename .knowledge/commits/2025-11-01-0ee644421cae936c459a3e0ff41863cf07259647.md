# Improve register_object type hint to preserve decorated class type identity
## TL;DR
- Introduces `_T = TypeVar("_T", bound=type)` in `python/tvm_ffi/registry.py` so that `@register_object` preserves the exact type of the decorated class instead of widening it to `type`.
- Changes the public signature from `register_object(type_key: str | type | None = None) -> Callable[[type], type] | type` to `register_object(type_key: str | None = None) -> Callable[[_T], _T]`.
- No runtime behavioral change; purely a static-analysis / IDE ergonomics improvement.

## Key Exports
None

## Impact
- API: none at runtime. The static type signature narrows the `type_key` parameter from `str | type | None` to `str | None`, but the runtime isinstance chain still handles a bare `type` argument.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none
