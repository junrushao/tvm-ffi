# Introduce opaque ptr protocol for passing C struct pointers through Python FFI
## TL;DR
- Adds `__tvm_ffi_opaque_ptr__` duck-type protocol: any Python class implementing this dunder method can pass opaque C pointers through FFI as `kTVMFFIOpaquePtr` values.
- New Cython setter `TVMFFIPyArgSetterFFIOpaquePtrCompatible_` converts the integer returned by `__tvm_ffi_opaque_ptr__()` to a `void*` in the FFI any value.
- Version bump 0.1.0b19 -> 0.1.0b20.

## Key Exports
```python
# --- __tvm_ffi_opaque_ptr__ Protocol (42e0612) ---
# Duck-type protocol method on any Python class to pass opaque C struct pointers through FFI:
#   def __tvm_ffi_opaque_ptr__(self) -> int:
#       """Return an integer representing the opaque C pointer value."""
# Setter: TVMFFIPyArgSetterFFIOpaquePtrCompatible_
# Uses kTVMFFIOpaquePtr type index and v_ptr field (same as ctypes.c_void_p path)
# Dispatch position: after ctypes.c_void_p, before callable
# Interacts with: TVMFFIPyArgSetterFactory_ dispatch chain (0012)
# Interacts with: kTVMFFIOpaquePtr type index (0001, 0007)
# Extension: DSL can wrap opaque C structs in Python objects and pass them to internal functions
```

## Impact
- API: New Python protocol `__tvm_ffi_opaque_ptr__` -- any class implementing it becomes passable to FFI functions as an opaque pointer. Non-breaking addition.
- Behavioral: Objects with `__tvm_ffi_opaque_ptr__` are now intercepted before the `callable` check in setter dispatch. If a callable class also implements `__tvm_ffi_opaque_ptr__`, it will be treated as an opaque pointer rather than a callable.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
**Context**: Wrapping an opaque C struct handle in a Python class and passing it through FFI.
```python
import tvm_ffi

class CUDAContext:
    """Wrapper for an opaque CUDA context handle."""
    def __init__(self, handle: int) -> None:
        self._handle = handle

    def __tvm_ffi_opaque_ptr__(self) -> int:
        return self._handle

# Pass the opaque pointer through an FFI function
fecho = tvm_ffi.get_global_func("testing.echo")
ctx = CUDAContext(0xDEADBEEF)
result = fecho(ctx)  # result is ctypes.c_void_p with value 0xDEADBEEF
```
