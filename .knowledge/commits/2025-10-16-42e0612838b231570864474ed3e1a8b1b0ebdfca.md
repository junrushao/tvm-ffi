# Introduce opaque pointer protocol for DSL pass-through of C structs
## TL;DR
- Adds opaque pointer protocol support in Cython arg setter: Python objects implementing `__tvm_ffi_opaque_ptr__()` can return a raw `ctypes.c_void_p` that is passed through to FFI functions as `void*`.
- Enables DSL compilers to pass opaque C structs through the FFI without wrapping them in Object.

## Impact
- API: New `__tvm_ffi_opaque_ptr__` protocol recognized by FFI call dispatch. Version bump to 0.1.0b20.
- Flags/config: None.
