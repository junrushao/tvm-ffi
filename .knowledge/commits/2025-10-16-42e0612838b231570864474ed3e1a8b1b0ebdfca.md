# Introduce __tvm_ffi_opaque_ptr__ protocol for passing opaque C pointers through FFI
## TL;DR
- Adds a new Python duck-typing protocol `__tvm_ffi_opaque_ptr__()` that allows arbitrary Python objects to be passed as opaque `void*` pointers through the FFI packed calling convention.
- Implements `TVMFFIPyArgSetterFFIOpaquePtrCompatible_` in Cython that calls `arg.__tvm_ffi_opaque_ptr__()` to extract the pointer, then packs it as `kTVMFFIOpaquePtr`.
- The protocol is detected via `hasattr(arg_class, "__tvm_ffi_opaque_ptr__")` in `TVMFFIPyArgSetterFactory_`, positioned after `ctypes.c_void_p` and before `callable` checks.

## Key Exports

**Protocols**:
- `__tvm_ffi_opaque_ptr__` protocol: Any Python class implementing `def __tvm_ffi_opaque_ptr__(self) -> int` can be passed as an FFI argument. The return value is interpreted as a `void*` pointer and packed with `type_index = kTVMFFIOpaquePtr`.

**Functions (Cython internal)**:
- `TVMFFIPyArgSetterFFIOpaquePtrCompatible_(handle, ctx, py_arg, out) -> int` — Cython arg setter that extracts `__tvm_ffi_opaque_ptr__()` from the Python object and packs it as `kTVMFFIOpaquePtr`.

## Impact
- API: New duck-typing protocol `__tvm_ffi_opaque_ptr__` for Python objects
- Behavioral: Objects implementing the protocol are now passable as FFI arguments (previously would fall through to callable or fail)
- Flags/config: Version bump 0.1.0b19 -> 0.1.0b20
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **`TVMFFIPyArgSetterFactory_` dispatch chain** — the Cython arg setter factory that maps Python types to packing functions. The new protocol check is inserted between `ctypes.c_void_p` and `callable` checks. See [0015-python-ffi-call-dispatch.md](../.knowledge/designs/0015-python-ffi-call-dispatch.md).
- **`kTVMFFIOpaquePtr` type index** — existing C ABI type code for opaque void pointers. See [0002-any-value-system.md](../.knowledge/designs/0002-any-value-system.md).

Design elements this commit produces:
- **`__tvm_ffi_opaque_ptr__` protocol** — a new duck-typing protocol for passing opaque C struct pointers through the FFI. Enables DSLs to wrap arbitrary C pointers in Python objects and pass them transparently to C++ functions.

## Usage Examples
Passing an opaque pointer through the FFI (from the test):
```python
class MyObject:
    def __init__(self, value):
        self.value = value

    def __tvm_ffi_opaque_ptr__(self):
        return self.value  # an integer representing a void* address

fecho = tvm_ffi.get_global_func("testing.echo")
x = MyObject(10)
y = fecho(x)           # passes as kTVMFFIOpaquePtr
assert isinstance(y, ctypes.c_void_p)
assert y.value == 10
```
