# Add __tvm_ffi_opaque_ptr__ protocol to Python FFI call dispatch for passing opaque C pointers

## TL;DR
- Introduces `__tvm_ffi_opaque_ptr__` protocol: any Python object implementing this dunder method can be passed to FFI functions as `kTVMFFIOpaquePtr` (raw void pointer, type index 4).
- Adds `TVMFFIPyArgSetterFFIOpaquePtrCompatible_` setter in Cython `function.pxi` and registers it in `TVMFFIPyArgSetterFactory_` before the `callable` fallback.
- Version bump `0.1.0b19` → `0.1.0b20`.

## Impact
- API: New duck-typed protocol `__tvm_ffi_opaque_ptr__`. Any class adding this method will automatically be marshalled as `kTVMFFIOpaquePtr` when passed to an FFI `Function`. No existing callers are affected.
- Behavioral: `kTVMFFIOpaquePtr` (type index 4) round-trips back to Python as `ctypes.c_void_p`. Integer pointer value is preserved.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Passing an opaque C struct pointer from a DSL object through an FFI function:

```python
import ctypes
import tvm_ffi

class MyOpaqueStruct:
    def __init__(self, ptr_value: int) -> None:
        self._ptr = ptr_value

    def __tvm_ffi_opaque_ptr__(self) -> int:
        return self._ptr  # raw integer pointer value

fecho = tvm_ffi.get_global_func("testing.echo")
obj = MyOpaqueStruct(0x10)
result = fecho(obj)
# result is ctypes.c_void_p with result.value == 0x10
assert isinstance(result, ctypes.c_void_p)
assert result.value == 0x10
```
