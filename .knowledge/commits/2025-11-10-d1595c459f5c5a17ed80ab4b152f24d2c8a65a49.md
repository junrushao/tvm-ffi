# Add Windows CI workflow and build script for torch-c-dlpack-ext wheels
## TL;DR
- Adds new GitHub Actions workflow `.github/workflows/torch_c_dlpack_windows.yml` for building torch-c-dlpack-ext wheels on Windows (x86_64, Python 3.9-3.14).
- Adds `addons/torch_c_dlpack_ext/build_aot_wheels.bat` -- the Windows equivalent of `build_aot_wheels.sh`, building libs for torch 2.4-2.9 with CUDA support.
- Fixes ninja build to handle spaces in Windows include paths (quoting) and limits colon escaping (`$:`) to Windows only.
- Adds CUDA linker flags (`torch_cuda.lib`/`c10_cuda.lib` on Windows, `-ltorch_cuda`/`-lc10_cuda` on Unix) when `--build-with-cuda` is set.
- Renames Linux CI job from `build_wheels` to `build_wheels_linux` and updates artifact naming to include `linux-`/`windows-` prefix.

## Key Exports
**New files**:
- `.github/workflows/torch_c_dlpack_windows.yml` -- Windows CI workflow for torch-c-dlpack-ext
- `addons/torch_c_dlpack_ext/build_aot_wheels.bat` -- Windows batch script for AOT wheel building

## Impact
- API: none
- Behavioral: torch-c-dlpack-ext wheels are now built for Windows in CI
- Flags/config: CUDA linker flags now explicitly added when `--build-with-cuda` is set (previously implicit)
- Data formats/schemas: none
