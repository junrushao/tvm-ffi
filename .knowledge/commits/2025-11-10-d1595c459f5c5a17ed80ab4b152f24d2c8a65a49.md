# Add Windows CI workflow and build script for torch_c_dlpack_ext wheels
## TL;DR
- Adds a new GitHub Actions workflow (`.github/workflows/torch_c_dlpack_windows.yml`) and Windows batch build script (`addons/torch_c_dlpack_ext/build_aot_wheels.bat`) for building torch_c_dlpack_ext wheels on Windows.
- Renames existing Linux workflow job from `build_wheels` to `build_wheels_linux` and prefixes artifact names with `linux-` to disambiguate from Windows artifacts.
- Fixes Windows-specific bugs in `_build_optional_torch_c_dlpack.py`: include path quoting for spaces, platform-conditional colon escaping, and CUDA library linking (`torch_cuda.lib`, `c10_cuda.lib`).
