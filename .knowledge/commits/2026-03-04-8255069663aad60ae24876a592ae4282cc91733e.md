# Fix 3 deny-level clippy lints in Rust bindings

## TL;DR
- `data_as_slice_mut(&self) -> &mut [T]` changed to `data_as_slice_mut(&mut self)` to prevent aliased mutable references (soundness fix for `clippy::mut_from_ref`).
- `with_stream(handle: *mut c_void)` and `from_extern_c(handle, safe_call, deleter)` now marked `unsafe fn` because callers must uphold pointer validity invariants the function cannot verify.
- `.gitignore` updated (minor).

## Key Exports

```rust
// rust/tvm-ffi/src/collections/tensor.rs
// OLD: pub fn data_as_slice_mut(&self) -> &mut [T]
// NEW:
pub fn data_as_slice_mut(&mut self) -> &mut [T]  // &mut self enforces borrow exclusivity
// Invariant: dtype, device, contiguity validated before from_raw_parts_mut

// rust/tvm-ffi/src/device.rs
// OLD: pub fn with_stream(handle: TVMFFIStreamHandle) -> ...
// NEW:
pub unsafe fn with_stream(handle: TVMFFIStreamHandle) -> ...
// Invariant: caller must ensure handle is a valid CUDA stream

// rust/tvm-ffi/src/function.rs
// OLD: pub fn from_extern_c(handle: *mut c_void, safe_call: ..., deleter: ...) -> ...
// NEW:
pub unsafe fn from_extern_c(handle: *mut c_void, safe_call: ..., deleter: ...) -> ...
// Invariant: caller must ensure handle is valid and safe_call/deleter are compatible
```

## Impact
- API: Breaking change for Rust callers of `data_as_slice_mut` (now requires `&mut` reference), `with_stream` (now requires `unsafe` block), and `from_extern_c` (now requires `unsafe` block).
- Behavioral: None — the underlying C calls are unchanged; only Rust type/safety annotations corrected.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Before (unsound, allowed aliased mutable borrows):
```rust
let tensor = get_tensor();
let slice1 = tensor.data_as_slice_mut::<f32>();  // &self → &mut [f32]
let slice2 = tensor.data_as_slice_mut::<f32>();  // second borrow OK → aliased mut!
```

After (sound):
```rust
let mut tensor = get_tensor();
let slice = tensor.data_as_slice_mut::<f32>();  // &mut self → exclusive borrow

// with_stream now requires unsafe
unsafe { stream_ctx.with_stream(cuda_stream_ptr); }
```
