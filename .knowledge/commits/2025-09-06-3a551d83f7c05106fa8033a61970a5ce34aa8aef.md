# Rename NDArray to Tensor across all layers (C ABI, C++, Cython, Python)
## TL;DR
- Renames `NDArray`/`NDArrayObj` to `Tensor`/`TensorObj` across C ABI, C++ headers, Cython bindings, and Python to align with `torch.Tensor` and `DLTensor` naming conventions.
- All C ABI symbols renamed: `kTVMFFINDArray` -> `kTVMFFITensor`, `TVMFFINDArray{From,To}DLPack{,Versioned}` -> `TVMFFITensor{From,To}DLPack{,Versioned}`, `TVMFFINDArrayGetDLTensorPtr` -> `TVMFFITensorGetDLTensorPtr`.
- Secondary: simplified `Module.__call__` to use reflection-based `self.main()` instead of cached `entry_func`; added `TVM_FFI_BUILD_DOCS` env guard around torch import in Cython.

## Impact
- API: ABI-breaking rename of 6 C ABI functions and 1 enum constant. All downstream callers using `NDArray`/`kTVMFFINDArray` must update. `StructuralEqual::Equal`/`StructuralHash::Hash` keyword argument `skip_ndarray_content` renamed to `skip_tensor_content`.
- Behavioral: `Module.__call__` now calls `self.main()` via reflection instead of cached `self._entry` property. Functionally equivalent but removes internal caching.
- Flags/config: New `TVM_FFI_BUILD_DOCS` env var gates torch import in Cython to avoid import errors during doc builds.
- Data formats/schemas: Type key string changed from `"ffi.NDArray"` to `"ffi.Tensor"` — affects serialized objects.

Design elements this commit produces/mutates:
- **Mutated**: `NDArray`/`NDArrayObj` -> `Tensor`/`TensorObj` throughout all layers. No structural or behavioral change to the type itself.
- **Mutated**: C ABI function names and enum constant (pure rename, same signatures and semantics).
- **Mutated**: `skip_ndarray_content` -> `skip_tensor_content` parameter name in StructuralEqual/Hash APIs.
- **Mutated (minor)**: `Module.__call__` simplified — no longer caches `entry_func`, directly calls `self.main()`.

## Usage Examples

Before/after for the rename:

```python
# BEFORE
import tvm_ffi
x = tvm_ffi.from_dlpack(np_data)
assert isinstance(x, tvm_ffi.NDArray)

# AFTER
import tvm_ffi
x = tvm_ffi.from_dlpack(np_data)
assert isinstance(x, tvm_ffi.Tensor)
```

```cpp
// BEFORE
#include <tvm/ffi/container/ndarray.h>
ffi::NDArray nd = ffi::NDArray::FromNDAlloc(alloc, shape, dtype, device);

// AFTER
#include <tvm/ffi/container/tensor.h>
ffi::Tensor tensor = ffi::Tensor::FromNDAlloc(alloc, shape, dtype, device);
```
