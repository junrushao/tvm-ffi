# Rename NDArray to Tensor across C ABI, C++ headers, Cython bindings, and Python API

## TL;DR
- Renames all `NDArray`/`NDArrayObj` symbols to `Tensor`/`TensorObj` across the entire codebase (C ABI, C++ headers, Cython bindings, Python module, tests, docs).
- Motivation: align with `torch.Tensor` and `DLTensor` naming conventions now dominant in ML ecosystem.
- Secondary: simplifies `Module.__call__` by removing `entry_func` property and `_entry` cache, delegating to `self.main()`. Also gates `import torch` behind `TVM_FFI_BUILD_DOCS` env var to avoid import failures during doc builds.

## Impact
- API: **ABI-breaking** -- all C ABI symbol names containing `NDArray` are renamed to `Tensor`. All downstream code calling `TVMFFINDArray*` functions must update. The `kTVMFFINDArray` enum constant is renamed to `kTVMFFITensor` (value 70 unchanged). The type key string changes from `"ffi.NDArray"` to `"ffi.Tensor"`, breaking serialized type keys. Python public export changes from `tvm_ffi.NDArray` to `tvm_ffi.Tensor`. The `StructuralEqual::Equal` and `StructuralHash::Hash` parameter `skip_ndarray_content` is renamed to `skip_tensor_content`, breaking keyword-argument callers.
- Behavioral: `Module.__call__` now delegates to `self.main()` instead of caching `self._entry`; `entry_func` property removed. Torch import guarded by `TVM_FFI_BUILD_DOCS` env var.
- Flags/config: New `TVM_FFI_BUILD_DOCS` env var gates `import torch` in Cython bindings.
- Data formats/schemas: Type key `"ffi.NDArray"` -> `"ffi.Tensor"` affects JSON serialization graph format.

## Design Elements
Design elements this commit consumes:
- **Object system** (0002): `TensorObj` inherits from `Object`, uses `TVM_FFI_DECLARE_STATIC_OBJECT_INFO`.
- **C ABI** (0007): Renames all `TVMFFINDArray*` symbols; type index value 70 preserved.
- **Containers** (0006): `Tensor` is a container type backed by DLPack layout.
- **Type traits** (0005): `TypeTraits<DLTensor*>` references `kTVMFFITensor` for permissive cast.
- **Structural eq/hash** (0009): Parameter rename `skip_ndarray_content` -> `skip_tensor_content`.

Design elements this commit produces:
- None new. This is purely a rename of existing design elements.

## Usage Examples

Before (old API):
```python
import tvm_ffi
arr = tvm_ffi.from_dlpack(torch_tensor)
assert isinstance(arr, tvm_ffi.NDArray)
```

After (new API):
```python
import tvm_ffi
arr = tvm_ffi.from_dlpack(torch_tensor)
assert isinstance(arr, tvm_ffi.Tensor)
```

C++ before/after:
```cpp
// Before
#include <tvm/ffi/container/ndarray.h>
NDArray arr = NDArray::FromDLPack(managed_tensor);

// After
#include <tvm/ffi/container/tensor.h>
Tensor arr = Tensor::FromDLPack(managed_tensor);
```
