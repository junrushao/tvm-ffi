# Rename NDArray to Tensor across C ABI, C++, Python, and Cython

## TL;DR

- `NDArray` is renamed to `Tensor` everywhere: C ABI enum constant, C ABI function names, C++ class names, static type key string, Python public class, Cython extension type, and all file names.
- The ABI enum value at index 70 is unchanged; only the symbolic name changes (`kTVMFFINDArray` → `kTVMFFITensor`).
- Secondary: `Module.entry_func` property + `Module.__new__` are removed; `Module.__call__` now delegates directly to `self.main()` instead of caching via `_entry`.

## Key Exports

```python
# C ABI (include/tvm/ffi/c_api.h)
# Enum value is UNCHANGED at 70; only symbolic name changes:
#   kTVMFFINDArray = 70  →  kTVMFFITensor = 70
# Interacts with: TVMFFIAny.type_index, TypeTraits<Tensor>, function.pxi make_args/make_ret

# C ABI DLPack bridge (renamed, signature unchanged):
def TVMFFITensorFromDLPack(from_: DLManagedTensor*, require_alignment: int32,
                           require_contiguous: int32, out: TVMFFIObjectHandle*) -> int: ...
def TVMFFITensorToDLPack(from_: TVMFFIObjectHandle, out: DLManagedTensor**) -> int: ...
def TVMFFITensorFromDLPackVersioned(from_: DLManagedTensorVersioned*, ...) -> int: ...
def TVMFFITensorToDLPackVersioned(from_: TVMFFIObjectHandle, ...) -> int: ...

# C ABI inline accessor (renamed):
def TVMFFITensorGetDLTensorPtr(obj: TVMFFIObjectHandle) -> DLTensor*: ...
# Invariant: obj must have type_index == kTVMFFITensor;
#            DLTensor is located at byte offset sizeof(TVMFFIObject)==24 from obj ptr

# C++ (include/tvm/ffi/container/tensor.h)
class TensorObj(Object, DLTensor):
    """Ref-counted tensor wrapping a DLTensor inline at offset 24."""
    # Invariant: layout = {TVMFFIObject (24 bytes), DLTensor, ...}; same ABI as before
    # Interacts with: Tensor (ObjectRef), TypeTraits<Tensor>, StructuralEqual, StructuralHash
    _type_key: str = "ffi.Tensor"  # was "ffi.NDArray"

class Tensor(ObjectRef):
    """ObjectRef wrapping TensorObj."""
    @staticmethod
    def FromNDAlloc(alloc: TNDAlloc, shape: Shape, dtype: DLDataType, device: DLDevice) -> Tensor: ...
    @staticmethod
    def FromDLPack(from_: DLManagedTensor*, require_alignment: int = 1,
                   require_contiguous: bool = False) -> Tensor: ...
    @staticmethod
    def FromDLPackVersioned(from_: DLManagedTensorVersioned*, ...) -> Tensor: ...
    def ToDLPack(self) -> DLManagedTensor*: ...
    def ToDLPackVersioned(self) -> DLManagedTensorVersioned*: ...
    # Interacts with: TypeTraits<Tensor> (type index), kTVMFFITensor (ABI tag)
    # Extension: subclass TensorObjFromNDAlloc / TensorObjFromDLPack for custom backing

# Static type key (include/tvm/ffi/object.h, struct StaticTypeKey):
#   kTVMFFITensor = "ffi.Tensor"   # was kTVMFFINDArray = "ffi.NDArray"

# Python / Cython (python/tvm_ffi/cython/tensor.pxi)
cdef class Tensor(Object):
    """N-dimensional array compatible with DLPack."""
    cdef DLTensor* cdltensor
    # Interacts with: make_args (Cython), make_ret (Cython), from_dlpack, TypeIndex kTVMFFITensor

# Module cleanup (python/tvm_ffi/module.py):
class Module(Object):
    entry_name: str = "main"  # class-level constant; __new__/_entry/_entry_func removed
    def __call__(self, *args): return self.main(*args)  # was: self.entry_func(*args)
    # Interacts with: Module.get_function, ffi.Module type key

# StructuralEqual parameter rename (include/tvm/ffi/extra/structural_equal.h):
# skip_ndarray_content → skip_tensor_content
```

## Impact

- API: **Breaking at C ABI level** — `TVMFFINDArrayFromDLPack`, `TVMFFINDArrayToDLPack`, `TVMFFINDArrayFromDLPackVersioned`, `TVMFFINDArrayToDLPackVersioned`, and `TVMFFINDArrayGetDLTensorPtr` are removed and replaced with `TVMFFITensor*` equivalents. Any caller compiled against the old header must be recompiled. ABI enum value 70 is preserved so binary layout is stable.
- API: **Breaking at C++ level** — `NDArrayObj`, `NDArray`, `StaticTypeKey::kTVMFFINDArray` removed; `TensorObj`, `Tensor`, `StaticTypeKey::kTVMFFITensor` replace them.
- API: **Breaking at Python level** — `tvm_ffi.NDArray` removed; `tvm_ffi.Tensor` is the new public name. Any caller importing `NDArray` must update.
- API: `StructuralEqual::Equal()` and `GetFirstMismatch()` keyword arg `skip_ndarray_content` renamed to `skip_tensor_content` — breaks C++ keyword callers.
- API: `Module.entry_func` property removed; `Module.__call__` now calls `self.main()` directly via attribute lookup rather than a cached `_entry` reference.
- Behavioral: None — no semantic change; all logic is identical under the new names.
- Flags/config: None.
- Data formats/schemas: Serialized type key changes from `"ffi.NDArray"` to `"ffi.Tensor"`. Any persisted JSON/binary object graphs using `"ffi.NDArray"` will fail deserialization unless migrated.
- Version bump: `pyproject.toml` version `0.1.0a7` → `0.1.0a8`.

## Design Elements

Design elements this commit consumes:
- `0001-c-abi`: Uses `kTVMFFINDArray=70` enum slot (preserved at same index); consumes `TVMFFIObject` inline layout invariant (DLTensor at offset 24).
- `0002-object-system`: `TensorObj`/`Tensor` continue the `FooObj`/`Foo` pattern; `TVM_FFI_DECLARE_STATIC_OBJECT_INFO` + `TVM_FFI_DEFINE_OBJECT_REF_METHODS` macros unchanged.
- `0007-containers`: NDArray was one of the eight container types; this commit renames that slot to Tensor.
- `0008-type-traits`: `TypeTraits<Tensor>` (was `TypeTraits<NDArray>`) lookup via `kTVMFFITensor`; `TryCastFromAnyView` branch for `kTVMFFITensor` still redirects to DLTensor pointer.
- `0013-python-package`: Cython fragment `ndarray.pxi` → `tensor.pxi`; `core.pyx` `include` updated.

Design elements this commit produces:
- `Tensor` / `TensorObj` — replacement for the `NDArray`/`NDArrayObj` design element in `0007-containers` and `0001-c-abi`. Same physical ABI; only names change.
- `"ffi.Tensor"` static type key — replaces `"ffi.NDArray"` in all type registries.
- `kTVMFFITensor` — C ABI enum name replacing `kTVMFFINDArray` (same value 70).

## Usage Examples

C++ → Python cross-layer round-trip (from `tests/cpp/test_tensor.cc` and `tests/python/test_tensor.py`):

```cpp
// C++ allocation and DLPack export:
Tensor t = Tensor::FromNDAlloc(CPUNDAlloc(), Shape({2, 3}),
                                DLDataType{kDLFloat, 32, 1},
                                DLDevice{kDLCPU, 0});
DLManagedTensor* dlpack = t.ToDLPack();
```

```python
# Python import via DLPack:
import tvm_ffi
t = tvm_ffi.from_dlpack(dlpack_capsule)
assert isinstance(t, tvm_ffi.Tensor)  # was NDArray
```

Module `__call__` cleanup (before/after):

```python
# Before:
module()  # → self._entry(*args) (cached) or self.entry_func(*args) → get_function("main")

# After:
module()  # → self.main(*args)  (no cache; uses attribute lookup each call)
```
