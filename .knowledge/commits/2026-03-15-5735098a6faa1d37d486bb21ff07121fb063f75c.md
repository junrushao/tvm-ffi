# Auto-register __ffi_* dunder methods in @py_class as TypeMethod
## TL;DR
- Extends `@py_class` to automatically detect `__ffi_*` dunder methods (like `__ffi_repr__`, `__ffi_compare__`, `__ffi_hash__`) and register them as `TypeMethod` entries in the reflection system.
- Adds Cython support in `type_info.pxi` for calling registered TypeMethods from Python.
- Adds tests for custom dunder methods on py_class types.

## Key Exports

```python
# py_class now auto-registers __ffi_* dunders:
# class MyObj:
#     def __ffi_repr__(self) -> str: ...  # registered as TypeMethod "ffi_repr"
#     def __ffi_compare__(self, other) -> bool: ...
#     def __ffi_hash__(self) -> int: ...
# Interacts with: TypeMethod registration, type_info.pxi dispatch
# Extension: add new __ffi_* dunders for custom behavior
```

## Impact
- API: `@py_class` classes with `__ffi_*` methods automatically participate in repr/compare/hash frameworks.
- Behavioral: Custom Python dunders now accessible from C++ via TypeMethod dispatch.
- Flags/config: None
- Data formats/schemas: None
