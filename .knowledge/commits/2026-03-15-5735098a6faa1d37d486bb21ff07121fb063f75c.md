# Auto-register __ffi_* dunder methods in @py_class as TypeMethod

## TL;DR
- `@py_class` now scans class dict for recognized FFI dunder methods and registers them as `TypeMethod` via `TVMFFITypeRegisterMethod`/`TVMFFITypeRegisterAttr`.
- `_FFI_RECOGNIZED_METHODS` allowlist gates which dunders are collected: `__ffi_repr__`, `__ffi_hash__`, `__ffi_eq__`, `__ffi_compare__`, `__s_equal__`, `__s_hash__`, `__data_to_json__`, `__data_from_json__`.
- `_register_py_methods` always called for every `@py_class` type to ensure system-generated methods (`__ffi_init__`, `__ffi_shallow_copy__`) are read back.

## Impact
- API: Additive. `@py_class` types can now define `__ffi_repr__`, `__ffi_hash__`, `__ffi_eq__`, `__ffi_compare__`, `__s_equal__`, `__s_hash__`, `__data_to_json__`, `__data_from_json__` and have them callable from C++.
- Behavioral: Python-defined FFI types now participate in repr, structural eq/hash, and JSON serialization via C++ dispatch.
- Flags/config: none
- Data formats/schemas: none

```python
@py_class(eq=True, structure="tree")
class MyNode(Object):
    type_key = "mymod.MyNode"
    value: int

    def __ffi_repr__(self) -> str:
        return f"MyNode({self.value})"

    def __s_equal__(self, other: "MyNode") -> bool:
        return self.value == other.value

    def __data_to_json__(self) -> dict:
        return {"value": self.value}
```
