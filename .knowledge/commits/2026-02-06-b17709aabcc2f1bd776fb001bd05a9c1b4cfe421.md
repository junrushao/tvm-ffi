# Major rewrite of Kernel Library Guide with complete CUDA Scale example and new examples/

## TL;DR
- Rewrites `docs/guides/kernel_library_guide.rst` from a reference-style API listing into a task-oriented guide structured around the four-step CUDA kernel pattern: validate → device guard → stream → dtype dispatch → launch.
- Adds three new runnable example files under `examples/kernel_library/`: `scale_kernel.cu` (complete CUDA Scale kernel), `tvm_ffi_utils.h` (reusable validation macros and helpers), and `load_scale.py` (Python caller using PyTorch).
- Fixes `include/tvm/ffi/base_details.h` to expose `TVM_FFI_STATIC_INIT_BLOCK` correctly under `TVM_FFI_DOXYGEN_MODE`, enabling accurate Doxygen documentation of the macro.

## Usage Examples

Complete CUDA kernel following the canonical TVM-FFI four-step pattern (from `examples/kernel_library/scale_kernel.cu`):

```cpp
// tvm_ffi_utils.h — reusable helpers
#define CHECK_CUDA(x) TVM_FFI_CHECK((x).device().device_type == kDLCUDA, ValueError) << ...
#define CHECK_CONTIGUOUS(x) TVM_FFI_CHECK((x).IsContiguous(), ValueError) << ...
#define CHECK_INPUT(x)  do { CHECK_CUDA(x); CHECK_CONTIGUOUS(x); } while(0)
inline cudaStream_t get_cuda_stream(DLDevice d) {
    return static_cast<cudaStream_t>(TVMFFIEnvGetStream(d.device_type, d.device_id));
}

// scale_kernel.cu — full kernel
void Scale(TensorView output, TensorView input, double factor) {
    CHECK_INPUT(input); CHECK_INPUT(output);   // 1. validate
    ffi::CUDADeviceGuard guard(input.device().device_id);  // 2. device guard
    cudaStream_t stream = get_cuda_stream(input.device()); // 3. stream
    int64_t n = input.numel();
    // 4. dtype dispatch + launch
    if (input.dtype() == dl_float32)
        ScaleKernel<<<(n+255)/256, 256, 0, stream>>>(
            (float*)output.data_ptr(), (float*)input.data_ptr(), (float)factor, n);
    else TVM_FFI_THROW(TypeError) << "Unsupported dtype: " << input.dtype();
}
TVM_FFI_DLL_EXPORT_TYPED_FUNC(scale, Scale);

// load_scale.py
mod = tvm_ffi.load_module("build/scale_kernel.so")
x = torch.randn(1024, device="cuda"); y = torch.empty_like(x)
mod.scale(y, x, 2.0)  # PyTorch tensors auto-converted to TensorView
```
