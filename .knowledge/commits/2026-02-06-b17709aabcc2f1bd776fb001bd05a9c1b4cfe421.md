# Rewrite kernel library guide with structured tutorial and new example files
## TL;DR
- Rewrote `docs/guides/kernel_library_guide.rst` from a reference-style doc into a task-oriented tutorial with sections: Anatomy of a Kernel Function, Export and Load, Tensor Handling, and Further Reading.
- Added three new example files (`scale_kernel.cu`, `tvm_ffi_utils.h`, `load_scale.py`) under `examples/kernel_library/` that are included by the guide via `literalinclude`.
- Fixed Doxygen rendering of `TVM_FFI_STATIC_INIT_BLOCK` in `base_details.h` by moving `\cond`/`\endcond` markers and adding a `TVM_FFI_DOXYGEN_MODE` branch. Cleaned up Doxygen exclude lists in `docs/conf.py`.

None -- documentation and example files only. The `tvm_ffi_utils.h` example header defines convenience macros/helpers (`CHECK_CUDA`, `CHECK_CONTIGUOUS`, `CHECK_INPUT`, `CHECK_DIM`, `CHECK_DEVICE`, `get_cuda_stream`, `alloc_tensor`, dtype constants) but these are example code, not library API.

## Usage Examples
The commit itself introduces the canonical example for the kernel library guide. The end-to-end trace (C++ kernel -> Python load) is:

```cpp
// scale_kernel.cu: define, validate, launch, export
void Scale(TensorView output, TensorView input, double factor) {
  CHECK_INPUT(input); CHECK_INPUT(output);
  ffi::CUDADeviceGuard guard(input.device().device_id);
  cudaStream_t stream = get_cuda_stream(input.device());
  // ... dtype dispatch and kernel launch ...
}
TVM_FFI_DLL_EXPORT_TYPED_FUNC(scale, Scale);
```

```python
# load_scale.py: load and call
import torch, tvm_ffi
mod = tvm_ffi.load_module("build/scale_kernel.so")
x = torch.randn(1024, device="cuda", dtype=torch.float32)
y = torch.empty_like(x)
mod.scale(y, x, 2.0)
```
