# Introduce `tvm_ffi::reflection::init<>` as a standardized constructor helper for `ObjectDef::def_static`

## TL;DR
- Adds `tvm_ffi::reflection::init<T, Args...>` in `include/tvm/ffi/reflection/registry.h`: a template function that constructs an `Object` (or `ObjectRef`) subtype via `make_object<>` and returns an `ObjectRef`, replacing ad-hoc lambdas previously used for `def_static("__init__", ...)`.
- Renames the reflected constructor method from `"__create__"` to `"__ffi_init__"` (in `testing.cc` and tests), establishing `__ffi_init__` as the canonical name for the reflection-exposed constructor static method.
- Adds `TestIntPair` Python class in `testing.py` that uses `__init_handle_by_constructor__(TestIntPair.__ffi_init__, ...)` to demonstrate the full cross-layer construction flow, and adds corresponding Python test coverage.

## Key Exports

```python
# In namespace tvm::ffi::reflection (include/tvm/ffi/reflection/registry.h)

def init(T: type, *args: Args) -> ObjectRef:
    """Construct an Object subtype and return as ObjectRef.

    If T is a subclass of Object, calls make_object<T>(args...) directly.
    If T is an ObjectRef subclass, calls make_object<T::ContainerType>(args...) instead.
    Returns the object wrapped in ObjectRef.

    Invariant: T must be constructible with Args...; constructor must be accessible.
    Interacts with: ffi::make_object<>, ObjectRef, ObjectDef<Class>::def_static
    Extension: pass as a function pointer to def_static("__ffi_init__", refl::init<MyObj, ArgT...>)
    """
    # Usage:
    #   refl::ObjectDef<MyObj>().def_static("__ffi_init__", refl::init<MyObj, int64_t, int32_t>);
    # The resulting static method is accessible from Python as MyPyClass.__ffi_init__
    ...


# object.h: two macros gain [[maybe_unused]] on _type_is_nullable to suppress
# "unused variable" warnings when _type_is_nullable is not referenced by callers.
# TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE: _type_is_nullable = true
# TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE: _type_is_nullable = false
# No behavioral change — annotation only.


# Python: TestIntPair in testing.py (cross-layer usage example)
class TestIntPair(Object):
    """Test Int Pair registered at 'testing.TestIntPair'."""
    # __ffi_init__ is injected by _add_class_attrs() via TypeMethod(is_static=True)
    # Interacts with: _add_class_attrs (registry.py), TypeMethod.is_static -> staticmethod
    # Interacts with: __init_handle_by_constructor__ (object.pxi)

    def __init__(self, a: int, b: int) -> None:
        self.__init_handle_by_constructor__(TestIntPair.__ffi_init__, a, b)
        # Invariant: __ffi_init__ must be registered as def_static("__ffi_init__", refl::init<...>)
        # Interacts with: Object.__init_handle_by_constructor__ (object.pxi line ~117)
```

## Impact
- API: `__create__` static method name on `TestIntPairObj` is replaced by `__ffi_init__`. Any caller resolving `refl::GetMethod("testing.TestIntPair", "__create__")` will fail after this commit — renamed to `"__ffi_init__"`.
- Behavioral: None beyond the rename; construction semantics are identical.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `ObjectDef<Class>::def_static` — used to register `refl::init<>` as a static method named `"__ffi_init__"` (see `0006-reflection.md`)
- `make_object<T>` — used internally by `refl::init<>` (see `0002-object-system.md`)
- `TypeMethod.is_static` / `_add_class_attrs` — Python side automatically exposes static methods via `staticmethod()` (see `0013-python-package.md`)
- `Object.__init_handle_by_constructor__` — Python constructor bridge (see `0013-python-package.md`)

Design elements this commit produces:
- `tvm_ffi::reflection::init<T, Args...>` — new template factory function in `registry.h` under the `reflection` namespace; see Key Exports above.
- Convention `"__ffi_init__"` as the canonical name for a type's reflected constructor static method, replacing the ad-hoc `"__create__"` name used previously.

## Usage Examples

**Cross-layer construction via `refl::init<>` (C++ → Python):**

```cpp
// C++ registration (src/ffi/extra/testing.cc):
TVM_FFI_STATIC_INIT_BLOCK() {
  refl::ObjectDef<TestIntPairObj>()
      .def_ro("a", &TestIntPairObj::a)
      .def_ro("b", &TestIntPairObj::b)
      .def_static("__ffi_init__", refl::init<TestIntPairObj, int64_t, int64_t>);
}

// C++ test invocation (tests/cpp/test_reflection.cc):
Function int_init = reflection::GetMethod("test.TestObjA", "__ffi_init__");
Any obj_a = int_init(1, 2);
assert(obj_a.as<TestObjA>()->x == 1);
```

```python
# Python registration (python/tvm_ffi/testing.py):
@register_object("testing.TestIntPair")
class TestIntPair(Object):
    def __init__(self, a: int, b: int) -> None:
        self.__init_handle_by_constructor__(TestIntPair.__ffi_init__, a, b)

# Python test (tests/python/test_object.py):
obj0 = tvm_ffi.testing.TestIntPair(1, 2)
assert obj0.a == 1
assert obj0.b == 2
```

**Using `refl::init<>` with an ObjectRef subtype (derived class):**

```cpp
// Template selects ContainerType (TestObjADerived) when T is an ObjectRef subclass:
refl::ObjectDef<TestObjADerived>()
    .def_static("__ffi_init__", refl::init<TestObjRefADerived, int64_t, int64_t, int64_t>);
// refl::init<TestObjRefADerived, ...> → make_object<TestObjADerived>(...) via ContainerType
```
