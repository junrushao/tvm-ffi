# Improve Sphinx autodoc: filter native-type inherited members and add cross-reference links for inherited methods

## TL;DR
- `docs/conf.py`: replaced `_never_skip_selected_dunders` with `_filter_inherited_members` (hides built-in method wrappers and members from native Python types) and added `_link_inherited_members` (appends a `:meth:` cross-reference for members defined in a parent class).
- `python/tvm_ffi/__init__.py`: added `_update_module()` to normalize `__module__` attributes of exported symbols to `"tvm_ffi"` for cleaner autodoc output.
- `pyproject.toml`: removed pinned versions from Sphinx-related doc dependencies.
