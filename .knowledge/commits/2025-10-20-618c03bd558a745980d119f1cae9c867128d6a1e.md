# doc: Handle builtin and inheritance (#177)
## TL;DR
- Filter out noisy inherited members from Python builtin types (str, tuple, list, etc.) in Sphinx autodoc output
- Replace inherited method docstrings with cross-reference links to the defining base class
- Set `__module__ = "tvm_ffi"` on all public exports so Sphinx renders canonical module paths
- Unpin doc dependency versions in pyproject.toml
