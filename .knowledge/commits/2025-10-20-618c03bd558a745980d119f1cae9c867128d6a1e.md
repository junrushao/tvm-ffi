# Improve Sphinx autodoc: skip builtin-inherited members and link inherited methods to defining class
## TL;DR
- Skip member methods inherited from Python builtin types (e.g. `str.capitalize` on `dtype`) in autodoc output by filtering on `__objclass__` and `_py_native_classes` tuple.
- For non-builtin inherited methods (e.g. `Tensor.same_as` from `Object`), replace docstrings with a cross-reference link to the defining base class.
- Unpin doc dependency versions in `pyproject.toml` and patch `__module__` on all `tvm_ffi.__all__` exports so Sphinx resolves qualified names correctly.
