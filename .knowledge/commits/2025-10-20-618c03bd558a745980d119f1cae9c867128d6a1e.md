# Handle builtin and inheritance in docs

## TL;DR
- Sphinx autodoc now skips member methods inherited from Python builtin types (`str`, `int`, `tuple`, etc.) to reduce documentation noise for classes like `dtype` (subclass of `str`).
- Inherited methods from non-builtin TVM FFI base classes are auto-linked to the defining base class (e.g., `Tensor.same_as` shows "Defined in Object").
- Unpins several Sphinx-related dependency versions in `pyproject.toml` and patches `__module__` on re-exported symbols so Sphinx renders them under `tvm_ffi`.

## Key Exports

**Sphinx hooks** (in `docs/conf.py`):
- `_filter_inherited_members(app, what, name, obj, skip, options)`: Replaces `_never_skip_selected_dunders`. Hides members from `_py_native_classes` and built-in methods.
- `_link_inherited_members(app, what, name, obj, options, lines)`: New `autodoc-process-docstring` hook. Replaces docstrings of inherited methods with a cross-reference to the defining base class.
- `_defining_class(cls, attr_name) -> type | None`: MRO walker to find the class that first defines an attribute.
- `_import_cls(cls_name) -> type | None`: Utility to import a class by fully qualified name.
- `_py_native_classes: tuple[type, ...]`: Tuple of 14 Python builtin types whose inherited members are hidden.

**Python init** (`python/tvm_ffi/__init__.py`):
- `_update_module()`: Patches `__module__` to `"tvm_ffi"` on all `__all__` exports whose module doesn't already start with `tvm_ffi`.

## Impact
- API: None (documentation-only behavioral change).
- Behavioral: `__ffi_init__` added to `_autodoc_always_show` set, ensuring it renders in docs.
- Flags/config: Unpinned versions for `sphinx-reredirects`, `sphinx-tabs`, `sphinx-toolbox`, `sphinxcontrib-napoleon`, `sphinxcontrib_httpdomain`, `setuptools`, `urllib3` in `pyproject.toml` docs group.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Sphinx autodoc hooks** (`docs/conf.py`): `autodoc-skip-member` and `autodoc-process-docstring` events.
- **`__all__` export list** (`python/tvm_ffi/__init__.py`): Used by `_update_module()` to patch `__module__`.

Design elements this commit produces:
- **`_py_native_classes` filter set**: A reusable tuple of Python builtin types for autodoc filtering.
- **`_filter_inherited_members` / `_link_inherited_members`**: Paired hooks that together implement clean inheritance documentation.
