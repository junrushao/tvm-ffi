# Expose Tensor.strides property in Python/Cython and bump DLPack to v1.2

## TL;DR
- Adds `Tensor.strides` property to the Cython `Tensor` class, returning a `tuple[int, ...]` of element strides from the underlying `DLTensor`.
- When `DLTensor.strides` is NULL (DLPack convention for contiguous layout), computes row-major strides from the shape via `_make_strides_from_shape()`.
- Bumps DLPack submodule to v1.2 and package version from `0.1.0b15` to `0.1.0b16`.

## Impact
- API: New `Tensor.strides` property accessible from Python. No breaking changes.
- Behavioral: None -- purely additive.
- Flags/config: None.
- Data formats/schemas: DLPack submodule updated from v1.1 to v1.2 (`1117366` -> `93c8f2a`).

## Usage Examples

Accessing tensor strides from Python after DLPack import:
```python
import numpy as np
import tvm_ffi

# Create a contiguous tensor via DLPack
data = np.ones((10, 8, 4, 2), dtype="int16")
x = tvm_ffi.from_dlpack(data)

# Access strides (element strides, not byte strides)
assert x.shape == (10, 8, 4, 2)
assert x.strides == (64, 8, 2, 1)  # row-major contiguous strides
assert x.dtype == tvm_ffi.dtype("int16")
```
