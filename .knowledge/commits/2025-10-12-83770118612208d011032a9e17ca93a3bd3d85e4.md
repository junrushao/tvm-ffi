# Expose Tensor.strides property in Python Cython bindings and bump DLPack to v1.2
## TL;DR
- Adds a `strides` property to the Cython `Tensor` class, reading `DLTensor.strides` directly or computing row-major strides from shape when the pointer is NULL.
- Adds a Cython helper `_make_strides_from_shape()` that computes row-major strides in reverse order.
- Bumps DLPack submodule from v1.1 to v1.2 and package version from `0.1.0b15` to `0.1.0b16`.

## Impact
- API: Adds `Tensor.strides` property to the Python `tvm_ffi.Tensor` class (new, non-breaking). Also adds corresponding type stub in `core.pyi`.
- Behavioral: None -- existing APIs unchanged.
- Flags/config: None.
- Data formats/schemas: DLPack submodule bumped from v1.1 to v1.2 (compatible upgrade).

## Design Elements
Design elements this commit consumes:
- `TensorObj` / `Tensor` container design ([0006-ffi-containers](../design-records/0006-ffi-containers.md)) -- the C++ `Tensor::strides()` accessor already exists and returns `ShapeView`; this commit mirrors it in Python.
- Python Cython Tensor binding ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md)) -- extends the existing `Tensor` Cython class which already has `shape`, `dtype`, `device` properties.
- DLTensor layout invariant: `DLTensor.strides` may be NULL for compact (row-major) tensors; when non-NULL, it has `ndim` elements.

Design elements this commit produces: None -- purely additive consumer of existing design.

## Usage Examples
From the test added in this commit (`tests/python/test_tensor.py`):
```python
import numpy as np
import tvm_ffi

data = np.arange(10 * 8 * 4 * 2, dtype="int16").reshape(10, 8, 4, 2)
x = tvm_ffi.from_dlpack(data)
assert x.shape == (10, 8, 4, 2)
assert x.strides == (64, 8, 2, 1)  # row-major strides in element count
```
