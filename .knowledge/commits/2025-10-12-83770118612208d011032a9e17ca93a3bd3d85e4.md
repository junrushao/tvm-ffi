# Expose Tensor.strides property in Cython and bump DLPack to v1.2

## TL;DR
- Adds `Tensor.strides` property to the Cython `Tensor` class, reading from `DLTensor.strides` or computing row-major strides when `strides == NULL`.
- Bumps DLPack submodule to v1.2 (`93c8f2a`) and package version to `0.1.0b16`.

## Key Exports

**Property: `Tensor.strides -> tuple[int, ...]`** (Cython `tensor.pxi`):
- Returns tensor strides as a tuple of integers.
- If `DLTensor.strides` is `NULL` (compact row-major), computes strides from shape via `_make_strides_from_shape`.

**Helper: `_make_strides_from_shape(shape: tuple) -> tuple[int, ...]`** (Cython `tensor.pxi`):
- Computes row-major (C-contiguous) strides from a shape tuple by iterating in reverse and accumulating products.

## Impact
- API: New read-only property `Tensor.strides` -- additive, non-breaking.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: DLPack submodule bumped to v1.2.

## Usage Examples

From the test added in this commit (`tests/python/test_tensor.py`):
```python
import numpy as np
import tvm_ffi

data = np.zeros((10, 8, 4, 2), dtype="int16")
x = tvm_ffi.from_dlpack(data)
assert x.strides == (64, 8, 2, 1)  # row-major strides
```
