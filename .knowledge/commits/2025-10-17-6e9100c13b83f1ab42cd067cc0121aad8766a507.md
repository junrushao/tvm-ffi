# Add forward declaration of Tensor class to fix MSVC compilation
## TL;DR
- Adds `class Tensor;` forward declaration in `include/tvm/ffi/container/tensor.h` before helper functions that precede the full class definition.
- Fixes MSVC compilation failure where the compiler requires forward declarations for classes referenced before their definition in the same translation unit.
