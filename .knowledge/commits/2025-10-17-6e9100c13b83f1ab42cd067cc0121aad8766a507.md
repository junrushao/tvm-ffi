# Add forward declaration of Tensor class to fix MSVC compilation error
## TL;DR
- Adds `class Tensor;` forward declaration at the top of `include/tvm/ffi/container/tensor.h` (line 41), before `TensorObj` which uses `friend class Tensor;`.
- MSVC requires the forward declaration to resolve the friend class reference; GCC and Clang do not.
- No functional or behavioral change.
