# Add forward declaration of Tensor class to fix MSVC compilation
## TL;DR
- Adds `class Tensor;` forward declaration in `include/tvm/ffi/container/tensor.h` before the `IsDeviceDirectAddress` function, resolving MSVC compilation errors caused by the class being used before its definition within the same translation unit.

## Key Exports
None — no new API; this is a compilation fix.

## Impact
- API: none
- Behavioral: none (fixes build failure on MSVC)
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **`Tensor` class** (`include/tvm/ffi/container/tensor.h`) — the forward declaration is needed because MSVC requires explicit forward declarations when a class is referenced (e.g., as a friend or parameter type) before its full definition appears later in the same header. See [0008-containers.md](../.knowledge/designs/0008-containers.md).
