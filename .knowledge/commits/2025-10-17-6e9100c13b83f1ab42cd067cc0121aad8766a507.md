# Add forward declaration of Tensor class in tensor.h for MSVC compatibility
## TL;DR
- Adds `class Tensor;` forward declaration in `include/tvm/ffi/container/tensor.h` before free function definitions.
- Fixes MSVC compilation error caused by stricter name lookup requiring the `Tensor` type to be declared before use in function signatures/return types later in the header.
