# Update load_inline to support exporting functions from cuda_sources when no cpp_sources given

## TL;DR
- `load_inline` previously always decorated `cpp_source` with `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macros and decorated `cuda_source` with empty functions. Now, when `cpp_sources` is empty, the export decorators are applied to `cuda_source` instead.
- The `test_load_inline_cuda` test is updated to remove the forward-declaration workaround in `cpp_sources`, confirming functions can be exported directly from CUDA sources.

## Key Exports

```python
def load_inline(
    name: str,
    cpp_sources: Sequence[str] | str = (),
    cuda_sources: Sequence[str] | str = (),
    functions: Mapping[str, str] | Sequence[str] | str = (),
    ...
) -> Module:
    # Behavior change:
    # if with_cpp (len(cpp_sources) > 0):
    #   cpp_source = _decorate_with_tvm_ffi(cpp_source, functions)
    #   cuda_source = _decorate_with_tvm_ffi(cuda_source, {})
    # else:
    #   cpp_source = _decorate_with_tvm_ffi(cpp_source, {})   # empty decoration
    #   cuda_source = _decorate_with_tvm_ffi(cuda_source, functions)
    # Invariant: functions must be declared in cpp_sources (if given) or
    #            defined in cuda_sources (if cpp_sources absent).
    # Interacts with: _decorate_with_tvm_ffi, TVM_FFI_DLL_EXPORT_TYPED_FUNC, Module.
```

## Impact
- API: `load_inline` interface unchanged in signature; behavioral change to how `functions` parameter targets sources.
- Behavioral: CUDA-only JIT compilation no longer requires a C++ forward-declaration stub.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

Before (required cpp_sources forward declaration):
```python
tvm_ffi.cpp.load_inline(
    name="hello",
    cpp_sources="void add_one_cuda(DLTensor* x, DLTensor* y);",  # workaround
    cuda_sources="__global__ void ... { ... }",
    functions=["add_one_cuda"],
)
```

After (no cpp_sources needed for CUDA-only):
```python
tvm_ffi.cpp.load_inline(
    name="hello",
    cuda_sources="""
        __global__ void AddOneKernel(float* x, float* y, int n) { ... }
        void add_one_cuda(DLTensor* x, DLTensor* y) { ... }
    """,
    functions=["add_one_cuda"],
)
```
