# Centralize object creation with __ffi_new__ fallback and add Python Field descriptor

## TL;DR
- New `CreateEmptyObject` and `HasCreator` inline helpers in `function.h`: unify scattered creator-null checks; fast path uses `metadata->creator`, fallback calls `__ffi_new__` type attr (for Python-defined types).
- New `python/tvm_ffi/dataclasses/field.py` — `Field` descriptor class for Python-defined FFI type fields (default, default_factory, init, repr, hash, compare, kw_only, doc).
- Cython `base.pxi` gains ~31 new extern C ABI declarations (`TVMFFITypeGetOrAllocIndex`, `TVMFFITypeRegisterField/Metadata/Attr`, `TVMFFIErrorSetRaisedFromCStr`, `TVMFFISEqHashKind` enum, new flag bits, `error.cause_chain`/`extra_context` fields) to prepare for pure-Python type registration.
- `TypeSchema.to_json()` added; `TypeMetadata.structural_eq_hash_kind` added to object.cc metadata init.

## Impact
- API: `CreateEmptyObject`/`HasCreator` are new C++ header-only helpers. `Field` descriptor is new Python API. `TypeSchema.to_json()` is new. `TVMFFITypeMetadata.total_size` changes from `int64_t` to `int32_t` (BREAKING C ABI), `structural_eq_hash_kind` member appended.
- Behavioral: Reflection creation (ObjectCreator, MakeInit, serialization) now succeeds for Python-registered types providing `__ffi_new__`. Previously threw "does not support reflection creation."
- Flags/config: `__ffi_new__` TypeAttr name is the extension point for Python types.
- Data formats/schemas: `TVMFFITypeMetadata` struct layout changed.

## Usage Examples

```python
# Field descriptor usage (preparatory for @py_class):
from tvm_ffi.dataclasses import Field
from tvm_ffi.core import TypeSchema

name_field = Field(
    name="name",
    ty=TypeSchema.from_annotation(str),
    default=MISSING,
    init=True,
    repr=True,
    hash=True,
    compare=True,
    kw_only=False,
)
```

```cpp
// C++ usage of CreateEmptyObject (replaces scattered creator-null checks):
const TVMFFITypeInfo* type_info = TVMFFIGetTypeInfo(type_index);
ObjectPtr<Object> obj = CreateEmptyObject(type_info);
// Works for C++ types (creator) and Python types (__ffi_new__ attr)
```
