# Centralize object creation with __ffi_new__ fallback and add Python Field descriptor

## TL;DR
- `CreateEmptyObject` and `HasCreator` utilities centralize scattered creator-or-error patterns; when native C++ `metadata->creator` is NULL, falls back to `__ffi_new__` TypeAttr, enabling reflection-based creation for Python-defined types.
- 5 call-sites unified: `ObjectCreator`, `MakeInit`, `MakeObjectFromPackedArgs`, `ObjectGraphDeserializer`.
- Python `Field` descriptor class in `tvm_ffi.dataclasses` for declaring fields with defaults and repr/hash/compare/init/kw_only control.
- **BREAKING C ABI**: `TVMFFITypeMetadata.total_size` changes from `int64_t` to `int32_t`; new `structural_eq_hash_kind` member appended.

## Impact
- API: `CreateEmptyObject`/`HasCreator` added. `Field` descriptor class added. **BREAKING**: `TVMFFITypeMetadata.total_size` type changed.
- Behavioral: Python-defined types can now be created via reflection (`__ffi_new__` fallback).
- Flags/config: None.
- Data formats/schemas: `TVMFFITypeMetadata` layout changed.
