# Run isort/black/ruff lint fixes across Python codebase for new CI compliance
## TL;DR
- Mechanically reformatted all Python files (import sorting via isort, whitespace via black, lint fixes via ruff) to comply with newly configured CI linters.
- Added `[tool.ruff]` configuration to `pyproject.toml` scoping ruff to `python/` and `tests/`, with per-file ignores for `__init__.py` (F401) and `tests/` (E741).
- Updated `tests/scripts/task_lint.sh` to run `isort --check`, `ruff check`, and reordered `black` invocation.

## Key Exports
**Config (pyproject.toml `[tool.ruff]` section):**
- `include = ["python/**/*.py", "tests/**/*.py"]` — scopes ruff to Python source and test files only.
- `"__init__.py" = ["F401"]` — suppresses unused-import warnings in package init files.
- `"tests/*" = ["E741"]` — suppresses ambiguous-variable-name warnings in tests.
- `max-args = 10` — pylint max function arguments.

**Lint script (`tests/scripts/task_lint.sh`):**
- Added `isort --check --diff .` step.
- Added `ruff check --diff .` step.
- Changed `black . --check --diff` to `black --check --diff .` (argument order).

## Impact

- Behavioral: one test function renamed from `test_device` to `test_device_dlpack_device_type` in `tests/python/test_device.py` to resolve pytest duplicate name collision; removed dead `tvm.testing.main()` call from `test_dtype.py`; removed unused `subprocess` import from `python/tvm_ffi/base.py`; removed unused variables (`y`, `z`, `dev`, `ext`) flagged by ruff.
