# Run lint to comply with the new CI

## TL;DR
- Applies automated formatting fixes across 33 Python files to satisfy the linters introduced in the preceding CI commit (`ef6d57b`): `isort` (import sorting), `black` (code formatting), and `ruff` (lint checks).
- Adds `[tool.ruff]` configuration to `pyproject.toml` (scoped to `python/**/*.py` and `tests/**/*.py`, with `F401` ignored in `__init__.py`, `E741` ignored in tests, and `max-args = 10`).
- Updates `tests/scripts/task_lint.sh` to run `isort --check`, `black --check`, and `ruff check` as CI lint steps.
- Fixes several `ruff` lint violations: removes unused imports (`pytest` in `test_access_path.py`, `platform` in `test_error.py`, `subprocess` in `base.py`), removes unused local variables (`dev` in `test_device.py`, `ext` in `check_asf_header.py`, `y`/`z` in `test_function.py`), replaces `==` with `is` for `None` comparison in `test_function.py`, removes a stale `if __name__ == "__main__": tvm.testing.main()` block from `test_dtype.py`, replaces an f-string with no placeholders with a plain string in `check_asf_header.py`, and renames a duplicate `test_device` function to `test_device_dlpack_device_type` in `test_device.py`.
- Changes `test_load_inline.py` build directory from `"./build_add_one"` to `"./build/build_add_one"`.
- Reformats multiline `__all__` in `_tensor.py` to a single-line list and removes trailing comma from `config.py` argparse description.

## Key Exports

**Configuration (`pyproject.toml`):**
- `[tool.ruff]` -- New ruff configuration section: `include = ["python/**/*.py", "tests/**/*.py"]`.
- `[tool.ruff.lint.per-file-ignores]` -- `__init__.py` ignores `F401` (unused imports); `tests/*` ignores `E741` (ambiguous variable names).
- `[tool.ruff.lint.pylint]` -- `max-args = 10`.

**CI (`tests/scripts/task_lint.sh`):**
- Adds `isort --check --diff .` step.
- Adds `ruff check --diff .` step.
- Reorders `black` invocation to `black --check --diff .` (arguments swapped).

**Test rename:**
- `test_device.py`: second `def test_device(...)` renamed to `def test_device_dlpack_device_type(...)` to eliminate duplicate test name.

## Impact
- API: None. All changes are formatting, import ordering, lint config, and test naming.
- ABI: None.
- Behavioral: (1) The duplicate `test_device` function is renamed, so pytest now discovers both tests instead of the second silently shadowing the first. (2) `test_load_inline.py` uses `./build/build_add_one` instead of `./build_add_one` as its build directory, moving the build artifact under the `build/` prefix. (3) Unused `import subprocess` removed from `base.py`; unused `import pytest` removed from `test_access_path.py`; unused `import platform` removed from `test_error.py`.
- Flags/config: New `[tool.ruff]` section in `pyproject.toml` governs ruff lint behavior for the project.
- Data formats/schemas: None.
