# Add back missing C++ tests for TVMFFIHandleInitOnce/DeinitOnce

## TL;DR
- Adds `tests/cpp/test_init_once.cc` (313 LOC) with GoogleTest coverage for `TVMFFIHandleInitOnce` and `TVMFFIHandleDeinitOnce` C ABI functions.
- Tests cover single-threaded idempotency (init/deinit called multiple times), error paths (init returning non-zero, init returning null handle, deinit returning non-zero), and multithreaded races (4 threads competing on init; 4 threads competing on deinit).

## Usage Examples
The tests demonstrate the expected calling contract for `TVMFFIHandleInitOnce`/`TVMFFIHandleDeinitOnce`:

```cpp
// Single-threaded lifecycle
void* handle = nullptr;
// First call initializes; subsequent calls with different init_func are no-ops.
int ret = TVMFFIHandleInitOnce(&handle, InitSuccess);  // ret==0, handle!=nullptr
ret = TVMFFIHandleInitOnce(&handle, InitShouldNotBeCalled);  // ret==0, handle unchanged

// Deinit sets handle back to nullptr
ret = TVMFFIHandleDeinitOnce(&handle, DeinitSuccess);  // ret==0, handle==nullptr
ret = TVMFFIHandleDeinitOnce(&handle, DeinitShouldNotBeCalled);  // ret==0, no-op

// Error path: init_func injects TLS error and returns -1
void* handle2 = nullptr;
ret = TVMFFIHandleInitOnce(&handle2, InitWithError);  // ret!=0, handle2==nullptr

// Even on deinit error, handle is set to nullptr
ret = TVMFFIHandleInitOnce(&handle4, InitForDeinitError);
ret = TVMFFIHandleDeinitOnce(&handle4, DeinitWithError);  // ret!=0, handle4==nullptr

// Multithreaded: 4 threads racing on init — init_func called exactly once
// (verified via atomic counter inside InitWithCounter)
EXPECT_EQ(init_count.load(), 1);
```
