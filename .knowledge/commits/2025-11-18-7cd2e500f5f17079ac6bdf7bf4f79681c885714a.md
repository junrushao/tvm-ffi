# Hide symbols by default for torch_c_dlpack_ext extension build
## TL;DR
- Adds `-fvisibility=hidden` to the default compiler flags for the torch C DLPack extension build on Linux-like platforms, preventing symbol conflicts when the shared library is loaded alongside other DSOs.
- Bumps `torch_c_dlpack_ext` package version from 0.1.2 to 0.1.3.

## Key Exports
None

## Impact
- API: none
- Behavioral: none -- the compiled extension's public interface is unchanged; only ELF symbol visibility metadata changes in the output `.so`.
- Flags/config: The default `cflags` list in `_build_optional_torch_c_dlpack.py` gains `-fvisibility=hidden`, affecting both JIT and AOT builds on Linux/macOS.
- Data formats/schemas: none
