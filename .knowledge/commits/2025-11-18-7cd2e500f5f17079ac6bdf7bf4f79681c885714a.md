# Hide symbols by default for torch_c_dlpack extension build
## TL;DR
- Added `-fvisibility=hidden` to default compiler flags in the torch C DLPack extension build script to prevent symbol conflicts.
- Bumped `torch_c_dlpack_ext` version from 0.1.2 to 0.1.3.
