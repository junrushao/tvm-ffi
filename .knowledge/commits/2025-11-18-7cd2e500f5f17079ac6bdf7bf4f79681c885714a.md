# Hide symbols by default for extension build via `-fvisibility=hidden`

## TL;DR
- Adds `-fvisibility=hidden` to `default_cflags` in `_run_build_on_linux_like()`, ensuring that the JIT-built torch-c-dlpack shared library only exports symbols explicitly marked `TVM_FFI_DLL_EXPORT`.
- Bumps `torch_c_dlpack_ext` addon version from `0.1.2` to `0.1.3`.

## Key Exports
None

## Impact
- API: none (only affects symbol visibility in compiled `.so`)
- Behavioral: torch-c-dlpack JIT `.so` on Linux/macOS now hides internal symbols by default. Prevents symbol clashes when multiple shared libraries are loaded in the same process.
- Flags/config: `default_cflags` now: `["-std=c++17", "-fPIC", "-O3", "-fvisibility=hidden"]`.
- Data formats/schemas: none
