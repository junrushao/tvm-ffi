# Hide symbols by default in torch-c-dlpack extension build; bump to 0.1.3
## TL;DR
- Adds `-fvisibility=hidden` to the default compiler flags in `_run_build_on_linux_like`, ensuring only explicitly exported symbols are visible in the built `.so`. This reduces symbol table pollution and avoids conflicts with other shared libraries.
- Bumps `torch_c_dlpack_ext` package version from `0.1.2` to `0.1.3`.
