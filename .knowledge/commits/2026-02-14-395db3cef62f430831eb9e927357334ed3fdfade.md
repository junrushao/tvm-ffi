# Add Ampere GPU name-to-compute-capability fallback in _get_cuda_target
## TL;DR
- Adds fallback GPU name-to-compute-capability mapping for NVIDIA Ampere GPUs (A10, A30, A40, A100, etc.) when `nvidia-smi` `compute_cap` query is unavailable on older drivers.
- Queries GPU name via `nvidia-smi --query-gpu=name` and maps known Ampere names to their SM versions.
