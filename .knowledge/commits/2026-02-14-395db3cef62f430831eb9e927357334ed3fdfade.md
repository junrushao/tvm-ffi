# Add GPU name fallback for CUDA compute capability detection on Ampere GPUs
## TL;DR
- When `nvidia-smi --query-gpu=compute_cap` fails (common on older Ampere drivers), falls back to querying GPU name and mapping known Ampere GPUs to their compute capabilities
- Maps `A100 -> 8.0`, `A10 -> 8.6` via `ampere_arch_map` dict
- Raises `RuntimeError` with actionable message if detection fails completely, instead of silently falling back to `compute_70`
