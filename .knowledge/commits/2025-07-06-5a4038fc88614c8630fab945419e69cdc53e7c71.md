# Replace Arg2Str with multi-overload for_each supporting constexpr index
## TL;DR
- Extends `details::for_each_dispatcher::run` to support three callable forms via `if constexpr` overload dispatch: `F(std::integral_constant<size_t, I>, Arg)` (constexpr index), `F(size_t, Arg)` (runtime index, backward-compatible), and `F(Arg)` (no index). Adds `always_false<T>` helper for dependent `static_assert` in the fallback branch.
- Removes the `Arg2Str` helper struct from `function_details.h` and rewrites `FuncFunctorImpl::Sig()` to use the new `for_each` with the constexpr-index overload, eliminating a single-purpose template in favor of the general-purpose utility.

## Impact
- API: **None** externally. The public `for_each` signature is unchanged (`for_each(f, args...)`). Existing callers using `F(size_t, Arg)` form (e.g., `PackedArgsSetter` in `function.h:306`) continue to work via the second `if constexpr` branch. The removed `Arg2Str` was internal to `details` namespace and only used by `FuncFunctorImpl::Sig()`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit **consumes**:
- **Function system -- signature reflection** ([`.knowledge/designs/0004-function-system.md`](../designs/0004-function-system.md)): `FuncFunctorImpl::Sig()` produces the human-readable function signature string used in error messages when unpacking fails. This commit rewrites its implementation without changing the output format.
- **C++ template metaprogramming utilities** (`include/tvm/ffi/base_details.h`): The `for_each` variadic pack iteration utility, introduced in the root commit and simplified to fold expressions in the prior commit `84cfbeb`, serves as the foundation for this enhancement.

Design elements this commit **produces**:
- **Multi-overload `for_each` dispatcher** (`include/tvm/ffi/base_details.h:138-158`): A strictly more powerful version of the prior `for_each`. The key design decision is the overload priority order checked via `if constexpr` + `std::conjunction_v<std::is_invocable<...>>`:
  1. `F(std::integral_constant<size_t, I>, Arg)` -- highest priority, enables `if constexpr (i() == ...)` branching on compile-time index values inside the callback.
  2. `F(size_t, Arg)` -- runtime index, backward compatible with all existing callers.
  3. `F(Arg)` -- no index, for callbacks that do not need the position.
  4. Fallback: `static_assert(always_false<F>, ...)` with a dependent false to produce a clear error message.

  This pattern is reusable wherever variadic pack iteration with per-element constexpr branching is needed (e.g., tuple-like visitors, heterogeneous container operations).

- **`always_false<T>` dependent-false helper** (`include/tvm/ffi/base_details.h:140-141`): A standard C++ idiom (`template <typename> inline constexpr bool always_false = false`) that makes `static_assert(false)` valid in `if constexpr` branches by introducing type dependency. Without this, `static_assert(false)` triggers unconditionally even in dead `if constexpr` branches.
