# [FFI] Replace `Arg2Str` with a more powerful `for_each` (#18117)

## TL;DR
- Enhances the existing `details::for_each` utility in `base_details.h` to support three callable signatures: `F(std::integral_constant<size_t, I>, Arg)` (constexpr index), `F(size_t, Arg)` (runtime index), and `F(Arg)` (no index). Uses `if constexpr` with `std::conjunction_v<std::is_invocable<...>>` to dispatch to the appropriate overload.
- Removes the `Arg2Str` template struct from `function_details.h` and replaces its sole call site (`FuncFunctorImpl::Sig()`) with a `for_each` call using the new constexpr-index signature, which allows `if constexpr (i() != 0)` to conditionally emit comma separators.
- Adds `details::always_false<T>` variable template for dependent-name `static_assert` in the `else` branch of `for_each_dispatcher::run`.

## Key Exports

### Removed: `details::Arg2Str<ArgType>` (`include/tvm/ffi/function_details.h`)
Template struct with `Apply<i>(ostream&)` and `Run(ostream&, index_sequence<I...>)` static methods. Used only by `FuncFunctorImpl::Sig()` to format function argument type signatures. Replaced entirely by `details::for_each`.

### Modified: `details::for_each_dispatcher::run` (`include/tvm/ffi/base_details.h`)
**Before:** Only supported `F(size_t, Arg)` signature -- `(f(I, std::forward<Args>(args)), ...)`.

**After:** Dispatches via `if constexpr` / `std::is_invocable` to three overloads, checked in priority order:
1. `F(std::integral_constant<size_t, I>, Arg)` -- index is a constexpr value, enabling `if constexpr` on the index inside the callable.
2. `F(size_t, Arg)` -- runtime index (original behavior).
3. `F(Arg)` -- no index at all.
4. `static_assert(always_false<F>, ...)` -- compile error if none match.

### New: `details::always_false<T>` (`include/tvm/ffi/base_details.h`)
```cpp
template <typename>
inline constexpr bool always_false = false;
```
Dependent-name false constant for use in `static_assert` inside `if constexpr` else branches, preventing premature assertion failure during template instantiation.

### Modified: `FuncFunctorImpl::Sig()` (`include/tvm/ffi/function_details.h`)
**Before:** Used `Arg2Str<std::tuple<Args...>>::Run(ss, IdxSeq{})` with a C-array pack expansion trick.

**After:** Uses `for_each` with a lambda taking `auto i` (deduced as `std::integral_constant<size_t, I>`) and `const auto& v`, calling `i()` to retrieve the constexpr index for `if constexpr` comma logic. The argument pack is `Type2Str<Args>::v()...`.

## Impact
- API: No public API change. `Arg2Str` and `for_each_dispatcher` are internal detail utilities in the `tvm::ffi::details` namespace, not part of the public API.
- ABI: No change. These are header-only template utilities that affect compile-time code generation only.
- Behavioral: The output of `FuncFunctorImpl::Sig()` (used in error messages for typed function signature mismatch) is identical before and after this change.
- The new `for_each` overload resolution enables future callers to use `std::integral_constant` indices for compile-time branching, which was not previously possible.

## Design Elements
Design elements this commit consumes:
- `details::for_each` / `for_each_dispatcher` -- pre-existing fold-expression-based iteration utility over variadic argument packs.
- `details::Type2Str<T>::v()` -- pre-existing static method returning a string representation of type `T`.
- `std::is_invocable` / `std::conjunction_v` (C++17 `<type_traits>`) -- SFINAE-free compile-time invocability check.
- `std::integral_constant<size_t, I>` -- compile-time constant wrapper enabling `if constexpr` on index values.

Design elements this commit produces:
- **Enhanced `for_each` dispatch protocol** -- The `details::for_each` utility now supports three callable signatures with automatic dispatch. This establishes a convention where callables receiving `std::integral_constant<size_t, I>` can perform compile-time branching on the iteration index.
- **`always_false<T>` idiom** -- Reusable dependent-false for `static_assert` in discarded `if constexpr` branches.

## Usage Examples

### Using for_each with constexpr index (new capability)
```cpp
// The constexpr index allows if constexpr branching on position
details::for_each(
    [&os](auto i, const auto& v) {
      if constexpr (i() != 0) {  // i is std::integral_constant<size_t, I>
        os << ", ";
      }
      os << i() << ": " << v;
    },
    Type2Str<Args>::v()...);
```

### Using for_each with runtime index (existing)
```cpp
details::for_each(
    [](size_t idx, auto&& arg) { /* ... */ },
    arg1, arg2, arg3);
```

### Using for_each without index (new capability)
```cpp
details::for_each(
    [](auto&& arg) { /* process each arg */ },
    arg1, arg2, arg3);
```
