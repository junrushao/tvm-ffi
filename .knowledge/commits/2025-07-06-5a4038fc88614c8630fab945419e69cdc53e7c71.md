# Replace Arg2Str with a more powerful for_each dispatcher supporting three invocation styles
## TL;DR
- Removes the `Arg2Str` helper struct (template-based index expansion for formatting function signatures) from `function_details.h`.
- Enhances `details::for_each` in `base_details.h` with SFINAE-based overload resolution supporting three callback styles: `F(integral_constant<size_t, I>, Arg)`, `F(size_t, Arg)`, and `F(Arg)`.
- Rewrites `FuncFunctorImpl::Sig()` to use the enhanced `for_each` with a lambda, replacing the old `Arg2Str` machinery.

## Key Exports

```python
# --- details::for_each (enhanced) ---
# Three callback styles are accepted, tested via std::conjunction + std::is_invocable:

def for_each(f: Callable, *args: Any) -> None:
    """Invoke f on each arg, dispatching by f's accepted signature."""
    # Style 1 (preferred): f(std::integral_constant<size_t, I>, arg)
    #   -> index available as constexpr, usable in `if constexpr` and template args
    # Style 2: f(size_t_index, arg)
    #   -> index as runtime value
    # Style 3: f(arg)
    #   -> no index
    # Invariant: exactly one style must match; static_assert fires otherwise
    # Interacts with: for_each_dispatcher::run (SFINAE dispatch), always_false<T>
    # Extension: add new callback styles by adding elif branches in for_each_dispatcher::run

# --- always_false<T> (new) ---
always_false: bool  # Template<typename T>, always false
    # Workaround for dependent-name static_assert in if-constexpr chains
    # Invariant: must be false for all T; used only in static_assert fallback branches

# --- FuncFunctorImpl::Sig() (rewritten) ---
# Old: used Arg2Str<std::tuple<Args...>>::Run(ss, IdxSeq{}) with TExpander trick
# New: uses for_each with lambda capturing ostringstream
#   for_each(lambda(auto i, auto& v) { if constexpr (i() != 0) ss << ", "; ss << i() << ": " << v; },
#            Type2Str<Args>::v()...)
# Interacts with: Type2Str<T>::v(), for_each, FuncFunctorImpl::Sig
```

## Impact
- API: None -- `Arg2Str` and `for_each` are both in `details::` namespace (internal). No public API changed.
- Behavioral: None -- `FuncFunctorImpl::Sig()` produces identical output strings.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- `details::for_each` (existing utility in `base_details.h`) -- now enhanced with SFINAE dispatch
- `details::Type2Str<T>` -- used by the rewritten `Sig()` to format argument types
- `FuncFunctorImpl` -- the internal struct powering `Function::FromUnpacked` signature introspection (see `0003-function-system.md`)

Design elements this commit produces:
- `details::for_each` enhanced dispatch: three callback styles via `std::conjunction_v<std::is_invocable<...>>` chain. The `integral_constant` style is the key addition -- it makes the iteration index available as a constexpr, enabling `if constexpr` branching inside the callback.
- `details::always_false<T>`: dependent-name `false` for `static_assert` in `if constexpr` else-branches (standard C++ workaround).

Design elements this commit removes:
- `details::Arg2Str<ArgType>`: replaced entirely by `for_each` + lambda.

## Usage Examples

Before (old `Arg2Str` pattern):
```cpp
// Arg2Str required a separate struct with Apply<i> and Run methods,
// plus the C++11 TExpander trick for pack expansion:
template <typename ArgType>
struct Arg2Str {
  template <size_t i>
  static void Apply(std::ostream& os) { /* ... */ }
  template <size_t... I>
  static void Run(std::ostream& os, std::index_sequence<I...>) {
    using TExpander = int[];
    (void)TExpander{0, (Apply<I>(os), 0)...};
  }
};
// Called as: Arg2Str<std::tuple<Args...>>::Run(ss, IdxSeq{});
```

After (new `for_each` pattern):
```cpp
// Inline lambda with constexpr index -- no helper struct needed:
for_each(
    [&ss](auto i, const auto& v) {
      if constexpr (i() != 0) {  // i is integral_constant, i() is constexpr
        ss << ", ";
      }
      ss << i() << ": " << v;
    },
    Type2Str<Args>::v()...);
```
