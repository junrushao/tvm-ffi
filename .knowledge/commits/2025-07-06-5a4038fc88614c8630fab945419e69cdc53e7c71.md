# Replace Arg2Str with enhanced for_each supporting constexpr index
## TL;DR
- Removed `Arg2Str` helper struct from `function_details.h` and replaced its usage in `FuncFunctorImpl::Sig()` with the existing `details::for_each` utility.
- Enhanced `for_each_dispatcher::run` in `base_details.h` to support three callable signatures via `if constexpr` + `std::is_invocable` dispatch: `F(std::integral_constant<size_t, I>, Arg)`, `F(size_t, Arg)`, and `F(Arg)`.
- Added `details::always_false<T>` variable template for dependent-name `static_assert` in the fallback branch.

## Key Exports

```python
# Enhanced for_each_dispatcher (in tvm::ffi::details)
# Previously only supported F(size_t, Arg). Now supports three signatures:

def for_each(f: Callable, *args: T) -> None:
    """Iterate over variadic args, calling f for each with optional index."""
    # Dispatch priority (checked via std::is_invocable at compile time):
    # 1. F(std::integral_constant<size_t, I>, Arg) -- constexpr index
    # 2. F(size_t, Arg) -- runtime index (backward compatible)
    # 3. F(Arg) -- no index
    # 4. static_assert failure via always_false<F>
    # Interacts with: PackedArgs::Fill (function.h:283), FuncFunctorImpl::Sig()
    # Invariant: exactly one of the three overloads must match for all args
    # Extension: add new callable signatures by inserting additional if-constexpr branches

# always_false<T> -- dependent-name false for static_assert in if-constexpr branches
always_false: bool = False  # template<typename> inline constexpr bool
    # Interacts with: for_each_dispatcher (compile-time error reporting)
    # Invariant: always evaluates to false; exists solely to make static_assert dependent
```

## Impact
- API: none -- `Arg2Str` was internal to `details` namespace; `for_each` public interface unchanged but gains new overload support
- Behavioral: `FuncFunctorImpl::Sig()` now uses `for_each` with `std::integral_constant` index, producing identical output format (`"0: type, 1: type, ..."`)
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `details::for_each` / `details::for_each_dispatcher` -- internal variadic argument iteration utility in `include/tvm/ffi/base_details.h`, used by `PackedArgs::Fill` and now by `FuncFunctorImpl::Sig()`. Previously documented in `commits/2025-07-05-84cfbeb12bc5ef6d9eb434095949c205433c9e35.md`.
- `Type2Str<T>::v()` -- compile-time type name strings used by `Sig()` for error messages.
- `FuncFunctorImpl::Sig()` -- generates human-readable function signature strings for error messages in `function_details.h`.

Design elements this commit produces:
- **`for_each` constexpr-index overload**: The `std::integral_constant<size_t, I>` callable form enables compile-time branching on index inside the callback. This is a new capability: callers can use `if constexpr (i() == 0)` to specialize behavior for the first argument without runtime branching. Used immediately by `FuncFunctorImpl::Sig()` to conditionally emit commas.
- **`details::always_false<T>`**: A utility variable template for dependent `static_assert` in `if constexpr` chains. Without this, `static_assert(false, ...)` triggers unconditionally even in dead branches. Standard C++17 pattern.

## Usage Examples

Before (using `Arg2Str`):
```cpp
// Old: Arg2Str required a separate struct with Apply<i>/Run methods
// and manual TExpander trick for fold
Arg2Str<std::tuple<Args...>>::Run(ss, std::make_index_sequence<sizeof...(Args)>{});
```

After (using enhanced `for_each`):
```cpp
// New: for_each with constexpr index -- cleaner, reuses existing utility
for_each(
    [&ss](auto i, const auto& v) {
      if constexpr (i() != 0) {  // i is std::integral_constant<size_t, I>
        ss << ", ";
      }
      ss << i() << ": " << v;
    },
    Type2Str<Args>::v()...);
```
