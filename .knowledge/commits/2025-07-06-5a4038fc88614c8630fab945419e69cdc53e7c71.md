# Replace Arg2Str with multi-mode for_each supporting constexpr indices
## TL;DR
- Enhanced `details::for_each` to support three calling conventions: `F(size_t, Arg)`, `F(Arg)`, and `F(std::integral_constant<size_t, I>, Arg)` (constexpr index).
- Removed `details::Arg2Str` helper struct from `function_details.h`; replaced its only usage in `FuncFunctorImpl::Sig()` with a `for_each` lambda that uses constexpr index for compile-time branching.
- Added `details::always_false<T>` helper for dependent `static_assert` in the `for_each` fallback branch.

## Key Exports

```python
# --- Enhanced utility in base_details.h (namespace tvm::ffi::details) ---

# Dependent-false for static_assert in unevaluated contexts
# always_false: bool  (template variable, always false for any T)

def for_each(f: Callable, *args: Args) -> None:
    """Iterate over a variadic argument pack, calling f on each element.
    Three overload modes, selected via SFINAE at compile time:
      1. f(std::integral_constant<size_t, I>, arg)  -- constexpr index (preferred)
      2. f(size_t_index, arg)                       -- runtime index
      3. f(arg)                                     -- no index
    """
    # Interacts with: FuncFunctorImpl::Sig() (signature generation),
    #                 Function::operator() via PackedArgsSetter (arg packing)
    # Invariant: exactly one of the three overloads must match; static_assert fires otherwise
    # Extension: callers needing compile-time index dispatch (e.g., if constexpr on index)
    #            should use mode 1 with std::integral_constant

# --- Removed ---
# Arg2Str<ArgType> -- replaced by for_each with constexpr-index lambda in FuncFunctorImpl::Sig()
```

## Impact
- API: none -- `for_each` and `Arg2Str` are internal (`details` namespace), not public API
- Behavioral: `FuncFunctorImpl::Sig()` produces identical output; the generation method changed from `Arg2Str`'s C-style expander to a fold-expression `for_each` lambda
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `FuncFunctorImpl::Sig()` (function signature string generation, part of [0004-ffi-function-system](../design-records/0004-ffi-function-system.md))
- `Type2Str<T>::v()` (type-to-string trait, used to render argument types)

Design elements this commit produces:
- `details::for_each` gains a new constexpr-index calling convention (`std::integral_constant<size_t, I>`) -- enables `if constexpr` branching on index inside the callback, which was not possible with the previous runtime `size_t` parameter
- `details::always_false<T>` utility for dependent static_assert

## Usage Examples
Before (removed `Arg2Str` pattern):
```cpp
// Old: dedicated struct with Apply<I>/Run pattern
template <typename ArgType>
struct Arg2Str {
  template <size_t i>
  static void Apply(std::ostream& os) {
    using Arg = std::tuple_element_t<i, ArgType>;
    if constexpr (i != 0) os << ", ";
    os << i << ": " << Type2Str<Arg>::v();
  }
  template <size_t... I>
  static void Run(std::ostream& os, std::index_sequence<I...>) {
    (void)(int[]){0, (Apply<I>(os), 0)...};
  }
};
```

After (using enhanced `for_each` with constexpr index):
```cpp
// New: inline lambda with compile-time index via std::integral_constant
for_each(
    [&ss](auto i, const auto& v) {
      if constexpr (i() != 0) {  // i is std::integral_constant, i() is constexpr
        ss << ", ";
      }
      ss << i() << ": " << v;
    },
    Type2Str<Args>::v()...);
```
