# Enhance for_each with multi-signature dispatch and remove Arg2Str

## TL;DR
- Upgrades `details::for_each` to accept three callback signatures: `F(std::integral_constant<size_t, I>, Arg)` (constexpr index), `F(size_t, Arg)` (runtime index), and `F(Arg)` (no index), selected via `if constexpr` + `std::conjunction_v<std::is_invocable<...>>`.
- Removes the `Arg2Str` helper struct from `function_details.h`, replacing its usage in `FuncFunctorImpl::Sig()` with a lambda-based call to the enhanced `for_each`.
- Adds the `always_false<T>` variable template to enable `static_assert` in dependent `else` branches.

## Key Exports

**Variable template** (new):
```cpp
// base_details.h
template <typename>
inline constexpr bool always_false = false;
```
Enables `static_assert(always_false<T>, ...)` in dependent `if constexpr` chains without premature evaluation.

**Function** (mutated — new overload resolution):
```cpp
// base_details.h — for_each_dispatcher::run
template <typename F, typename... Args, size_t... I>
static void run(std::index_sequence<I...>, const F& f, Args&&... args);
```
Now dispatches through three `if constexpr` branches based on `F`'s invocability:
1. `F(std::integral_constant<size_t, I>, Arg)` — constexpr index, enables `if constexpr (i() == 0)` in the callback
2. `F(size_t, Arg)` — runtime index (original behavior)
3. `F(Arg)` — no index

**Struct removed**: `Arg2Str<ArgType>` (was in `function_details.h`).

## Impact
- API: Internal-only change. `Arg2Str` was a private detail in `namespace details`. `for_each` is also internal but gains new callable-signature flexibility. Existing callers using `F(size_t, Arg)` (e.g., `PackedArgsSetter`) continue to work unchanged.
- Behavioral: `FuncFunctorImpl::Sig()` produces the same output — the format `"0: type, 1: type, ..."` is preserved via the new lambda.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **`for_each` utility** (`base_details.h`): The existing fold-expression-based iterator introduced in parent commit `84cfbeb`.
- **`Type2Str<T>::v()`** (`any.h`): Used in the new `Sig()` lambda to produce human-readable type names.
- **`FuncFunctorImpl::Sig()`** (`function_details.h`): Function signature reflection used by error messages in `unpack_call` — see [0004-function-system.md](../designs/0004-function-system.md).
- **C++17 fold expressions and `std::conjunction_v`/`std::is_invocable`**: Standard library traits for SFINAE-free overload selection within `if constexpr`.

Design elements this commit produces:
- **Multi-signature `for_each`**: A general-purpose compile-time iteration utility that auto-selects the most informative callback signature. The constexpr-index variant (`std::integral_constant`) is the key new capability — it enables callers to branch on index at compile time (e.g., skipping a separator for index 0).
- **`always_false<T>`**: A reusable dependent-false for `static_assert` in `if constexpr` else branches.

## Usage Examples

### Using enhanced for_each with constexpr index (from this commit's Sig() rewrite)
**Context**: Building a comma-separated type signature string at compile time, skipping the separator for the first element.
```cpp
// From FuncFunctorImpl::Sig() in function_details.h
for_each(
    [&ss](auto i, const auto& v) {
      if constexpr (i() != 0) {  // i is std::integral_constant<size_t, I>
        ss << ", ";
      }
      ss << i() << ": " << v;
    },
    Type2Str<Args>::v()...);
```

### Existing consumer: PackedArgsSetter uses F(size_t, Arg) variant
**Context**: `PackedArgs::Fill` passes arguments into an `AnyView[]` using the runtime-index variant.
```cpp
// function.h — unchanged, still works after this commit
details::for_each(details::PackedArgsSetter(data), std::forward<Args>(args)...);
// PackedArgsSetter::operator()(size_t i, T&& value) matches variant 2
```
