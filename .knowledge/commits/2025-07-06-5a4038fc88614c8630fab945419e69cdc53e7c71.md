# Extend `for_each` with constexpr-index and no-index dispatch modes, replace `Arg2Str` with it

## TL;DR
- `for_each` in `base_details.h` gains two new callable modes: `F(std::integral_constant<size_t,I>, Arg)` (constexpr index usable in `if constexpr`) and `F(Arg)` (no index). The existing `F(size_t, Arg)` mode is preserved.
- `Arg2Str<ArgType>` struct in `function_details.h` is deleted; `FuncFunctorImpl::Sig()` is rewritten to use `for_each` with a lambda leveraging the new constexpr-index mode.
- A `always_false<T>` helper is added to produce a cleaner `static_assert` when none of the three dispatch modes match.

## Key Exports

    # Invariant: all args must be invocable with f under at least one of the three modes;
    #            otherwise a compile-time static_assert fires.
    # Extension: callable mode detection is purely compile-time; adding a new mode requires
    #            adding another if constexpr branch in for_each_dispatcher::run.

# Removed: details::Arg2Str<ArgType>
# Was: struct with Apply<i>(os) and Run(os, index_sequence) for printing typed argument lists.

# FuncFunctorImpl::Sig() — updated usage (pseudocode)
def Sig() -> str:
    ss = ""

## Impact
- API: `details::Arg2Str<T>` removed — internal template, not part of public API; no external callers expected.
- Behavioral: `FuncFunctorImpl::Sig()` output is unchanged; the same formatted argument string is produced.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Before (using `Arg2Str`):
```cpp
// Old: Arg2Str<std::tuple<Args...>>::Run(ss, std::make_index_sequence<sizeof...(Args)>{})
// This required a two-level template struct with Apply<i> and Run methods.
```

After (using `for_each` with constexpr-index lambda):
```cpp
for_each(
    [&ss](auto i, const auto& v) {
      if constexpr (i() != 0) {  // i is integral_constant; i() is usable in if constexpr
        ss << ", ";
      }
      ss << i() << ": " << v;
    },
    Type2Str<Args>::v()...);  // expand all arg types as values, then iterate
```

The key pattern: pass `std::integral_constant<size_t, I>{}` (mode 3) so that `i()` (calling `operator()` on `integral_constant`) is a constexpr expression, enabling `if constexpr (i() != 0)` to compile away the separator for index 0 without a runtime branch.
