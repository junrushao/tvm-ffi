# Refactor Python FFI call path from monolithic make_args to C++-dispatched per-type setters for performance

## TL;DR
- Replaces the monolithic `make_args` + `FuncCall`/`FuncCall3` Cython functions with a C++-driven `TVMFFIPyCallManager` that caches `PyTypeObject* -> TVMFFIPyArgSetter` in a thread-local dispatch map, eliminating repeated isinstance chains on hot paths.
- Introduces `tvm_ffi_python_helpers.h`, a new C++ header compiled into the Cython extension, containing the `TVMFFIPyCallManager` class (call stack management, argument dispatch, GIL release, stream context), per-type POD setters, and temp-object lifecycle helpers.
- Adds `__dlpack_c_exporter__` protocol for zero-Python-overhead C-level DLPack export, and caches `DLManagedTensorVersioned` in `TensorObj` via atomic CAS to avoid per-call allocation.

    """Per-call state tracking device/stream and temporary object lifetimes."""
    packed_args: Ptr[TVMFFIAny]       # workspace for packed arguments

    # Invariant: temp arrays are sized to num_args, each setter pushes at most 1 temp

    """Argument setter: function pointer + optional DLPack C exporter."""

    dlpack_c_exporter: DLPackPyObjectCExporter  # optional, for __dlpack_c_exporter__ protocol
    # Interacts with: TVMFFIPyCallManager.SetArgument (dispatch lookup), TVMFFIPyArgSetterFactory_ (Cython factory)
    # Extension: new per-type setters registered by adding branches to TVMFFIPyArgSetterFactory_

    # Interacts with: TVMFFIPyFuncCall (top-level entry), TVMFFIFunctionCall (C ABI)
    # Invariant: dispatch_map_ is thread-local, no locking needed
    # Invariant: CallStack uses RAII -- temps are cleaned up even on exception

    class CallStack(TVMFFIPyCallContext):
        """RAII call stack: allocates packed_args + temp arrays from thread-local stack or heap."""
        # Invariant: heap fallback only when stack_top_ + requested > temp_stack_.size()
        # Interacts with: TVMFFIAny layout (must be >= 2*sizeof(void*) for temp reuse)

    def Call(self, setter_factory, func_handle, py_arg_tuple, result, c_api_ret_code) -> int: ...
        # 1. Allocate CallStack  2. SetArgument per arg  3. Set stream  4. Release GIL
        # 5. TVMFFIFunctionCall  6. Restore stream  7. CallStack destructor cleans temps
        # Interacts with: TVMFFIEnvSetCurrentStream (stream context), Py_BEGIN_ALLOW_THREADS

    def SetField(self, setter_factory, field_setter, field_ptr, py_arg, c_api_ret_code) -> int: ...

        # Used by tvm_ffi_callback to convert Python return values
        # Interacts with: TVMFFIAnyViewToOwnedAny (takes ownership)

    def SetArgument(self, setter_factory, ctx, py_arg, out) -> int: ...
        # Core dispatch: lookup Py_TYPE(py_arg) in dispatch_map_
        # Cache miss: call setter_factory, store result
        # Interacts with: dispatch_map_ (unordered_map<PyTypeObject*, TVMFFIPyArgSetter>)

# Top-level C-linkage entry points (called from Cython)
def TVMFFIPyFuncCall(setter_factory, func_handle, py_arg_tuple, result, c_api_ret_code) -> int: ...
def TVMFFIPyCallFieldSetter(setter_factory, field_setter, field_ptr, py_arg, c_api_ret_code) -> int: ...
def TVMFFIPyPyObjectToFFIAny(setter_factory, py_arg, out, c_api_ret_code) -> int: ...
def TVMFFIPyPushTempFFIObject(ctx: TVMFFIPyCallContext, arg: TVMFFIObjectHandle) -> None: ...
    # Invariant: at most one push per setter invocation
def TVMFFIPyPushTempPyObject(ctx: TVMFFIPyCallContext, arg: PyObject) -> None: ...
    # Calls Py_IncRef on push; CallStack destructor calls Py_DecRef

# New function pointer type for zero-Python-overhead DLPack export
DLPackPyObjectCExporter = Callable[[Ptr[void], Ptr[Ptr[DLManagedTensorVersioned]], Ptr[Ptr[void]]], int]
    # Interacts with: TVMFFIPyArgSetterDLPackCExporter_ (Cython setter), __dlpack_c_exporter__ attribute
    # Extension: any Python class can expose __dlpack_c_exporter__ as int (function pointer)

# === Cython per-type setters (function.pxi) ===
# Replaces make_args isinstance chain. Each setter handles one type:

def TVMFFIPyArgSetterFactory_(value: PyObject, out: TVMFFIPyArgSetter) -> int: ...
    # Type dispatch (order matters):
    # None -> SetterNone_ | Tensor -> SetterTensor_ | Object -> SetterObject_
    # ObjectRValueRef -> SetterObjectRValueRef_
    # __dlpack_c_exporter__ -> SetterDLPackCExporter_ | torch.Tensor -> SetterTorch_/SetterDLPackCExporter_
    # __dlpack__ -> SetterDLPack_ | bool -> SetterBool_ | int -> SetterInt_ | float -> SetterFloat_
    # dtype -> SetterDType_ | Device -> SetterDevice_ | str -> SetterStr_
    # bytes -> SetterBytes_ | c_void_p -> SetterCtypesVoidPtr_
    # callable -> SetterCallable_ | Exception -> SetterException_ | (fallback) -> SetterFallback_
    # Interacts with: TVMFFIPyCallManager.SetArgument (caches result by PyTypeObject*)
    # Invariant: same dispatch order semantics as old make_args (bool before int, dtype before str)

# === TensorObj atomic DLPack cache (tensor.h) ===

class TensorObj:
    # New field:
    cached_dl_managed_tensor_versioned_: Atomic[Ptr[DLManagedTensorVersioned]]  # mutable
    # Invariant: initialized to nullptr; set once via CAS (memory_order_release)
    # Invariant: destructor loads with acquire and deletes if non-null

    def ToDLPackVersioned(self) -> DLManagedTensorVersioned: ...
        # OLD: allocate new DLManagedTensorVersioned every call, deleter frees it
        # NEW: atomic CAS to cache; subsequent calls return cached + IncRef
        # Interacts with: EmbeddedDLManagedTensorVersionedDeleter (only DecRef, no delete)
        # Invariant: thread-safe via compare_exchange_strong (release/acquire)

    # Renamed: DLManagedTensorVersionedDeleter -> EmbeddedDLManagedTensorVersionedDeleter
    #   OLD: DecRef + delete tensor
    #   NEW: DecRef only (tensor lifetime managed by TensorObj destructor)

## Impact
- API: `make_args` and `FuncCall`/`FuncCall3` removed from Cython -- purely internal, no public Python API change. New `__dlpack_c_exporter__` protocol is a new extension point for third-party tensor libraries.
- Behavioral: Function call overhead reduced by caching type dispatch. `ToDLPackVersioned` now returns a cached struct (same pointer on repeated calls for same TensorObj). `testing.nop` changed from echoing arg[0] to truly no-op.
- Flags/config: `CMakeLists.txt` adds `target_include_directories` for the new `tvm_ffi_python_helpers.h` header.
- Data formats/schemas: `DLManagedTensorVersioned` Cython declaration fixed: `dl_tensor` field changed from `DLManagedTensor` to `DLTensor` (bug fix in the Cython extern declaration).

- **TensorObj::cached_dl_managed_tensor_versioned_** -- Atomic cached DLManagedTensorVersioned avoiding per-call allocation.
- **TVMFFIPyPushTempFFIObject / TVMFFIPyPushTempPyObject** -- RAII temp-object lifecycle helpers replacing the old `temp_args` list.

## Usage Examples

### New dispatch-based function calling (internal path)
**Context**: Shows how the old `make_args`+`FuncCall` path is replaced by the new `TVMFFIPyFuncCall` entry point. From `function.pxi` `Function.__call__`:

```python
# OLD path (removed):
#   temp_args = []
#   make_args(args, &packed_args[0], temp_args, &ctx_dev_type, &ctx_dev_id, &ctx_stream)
#   with nogil: TVMFFIFunctionCall(chandle, &packed_args[0], nargs, result)

# NEW path:
#   TVMFFIPyFuncCall(
#       TVMFFIPyArgSetterFactory_,  # Cython factory: maps PyTypeObject -> setter
#       self.chandle,               # function handle
#       <PyObject*>args,            # Python tuple of arguments
#       &result,                    # output
#       &c_api_ret_code             # C API return code
#   )
# Internally: TVMFFIPyCallManager caches dispatch per PyTypeObject,
# allocates from thread-local stack, releases GIL around TVMFFIFunctionCall.
```

### __dlpack_c_exporter__ protocol
**Context**: A Python tensor wrapper that exposes a C-level DLPack exporter for zero-overhead conversion. From `tensor.pxi`:

```python
# Define a C-level exporter function (Cython)
cdef int my_exporter(void* obj, DLManagedTensorVersioned** out, TVMFFIStreamHandle* env_stream) except -1:
    wrapper = <MyWrapper>(<PyObject*>obj)
    if env_stream != NULL:
        env_stream[0] = get_current_stream(wrapper.device)
    return TVMFFITensorToDLPackVersioned(wrapper.chandle, out)

# Expose as class attribute (integer function pointer)
class MyWrapper:
    __dlpack_c_exporter__ = get_exporter_intptr()  # int(cdef function pointer)
    # When passed to an FFI function, the setter factory detects __dlpack_c_exporter__
    # and calls the C function directly, bypassing Python __dlpack__ protocol
```
