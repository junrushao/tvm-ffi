# Refactor Python FFI call mechanism with C++ type-cached dispatcher for performance
## TL;DR
- Replaces the monolithic Cython `make_args()` / `FuncCall` / `FuncCall3` functions with a C++ type-dispatched calling system (`TVMFFIPyCallManager`) that caches `PyTypeObject* -> TVMFFIPyArgSetter` mappings in a thread-local hash map, eliminating repeated `isinstance()` checks on hot paths.
- Introduces individual Cython `TVMFFIPyArgSetterXXX_` functions registered by type, and a new `__dlpack_c_exporter__` protocol for zero-Python-overhead tensor conversion via C function pointers.
- Adds an atomic-cached `DLManagedTensorVersioned*` field in `TensorObj` so `ToDLPackVersioned()` avoids repeated heap allocation.

**Cython setter functions** (`function.pxi`):
- `TVMFFIPyArgSetterTensor_`, `TVMFFIPyArgSetterObject_`, `TVMFFIPyArgSetterDLPackCExporter_`, `TVMFFIPyArgSetterTorch_`, `TVMFFIPyArgSetterDLPack_`, `TVMFFIPyArgSetterDType_`, `TVMFFIPyArgSetterDevice_`, `TVMFFIPyArgSetterStr_`, `TVMFFIPyArgSetterBytes_`, `TVMFFIPyArgSetterCtypesVoidPtr_`, `TVMFFIPyArgSetterObjectRValueRef_`, `TVMFFIPyArgSetterCallable_`, `TVMFFIPyArgSetterException_`, `TVMFFIPyArgSetterFallback_`
- `TVMFFIPyArgSetterFactory_` -- the factory that maps Python objects to their setter

**Protocol `__dlpack_c_exporter__`** (Python-side, integer attribute):
- Objects exposing this attribute provide a C function pointer (as integer) conforming to `DLPackPyObjectCExporter` signature.
- Enables bypassing Python `__dlpack__` protocol for zero-overhead tensor conversion.
- Demonstrated in `DLTensorTestWrapper.__dlpack_c_exporter__`.

**`TensorObj` changes** (`tensor.h`):
- New field: `mutable std::atomic<DLManagedTensorVersioned*> cached_dl_managed_tensor_versioned_ = nullptr`
- `ToDLPackVersioned()` now returns a cached instance via atomic CAS (thread-safe, lock-free)
- Renamed: `DLManagedTensorVersionedDeleter` -> `EmbeddedDLManagedTensorVersionedDeleter` (no longer deletes the struct, only DecRefs the object)
- New destructor: `~TensorObj()` deletes the cached `DLManagedTensorVersioned*`

**Cython helpers** (`tensor.pxi`):
- `_from_dlpack_intptr(void* dlpack)` -- convert raw DLPack pointer
- `_from_dlpack_universal(ext_tensor, req_align, req_contiguous, out)` -- extracted from `from_dlpack()`

## Impact
- API: Internal only. No public Python API signatures changed. The `__dlpack_c_exporter__` protocol is new but optional.
- Behavioral: FFI function call overhead is reduced by caching type dispatch. The `make_args` isinstance-chain is replaced by O(1) hash-map lookup after first call per type. `ToDLPackVersioned` no longer allocates on repeated calls.
- Flags/config: CMake adds `target_include_directories(tvm_ffi_cython PRIVATE .../python/tvm_ffi/cython)` for the new header.
- Data formats/schemas: `testing.nop` now returns nothing (was echoing first arg). Benchmark-only impact.

Design elements this commit consumes:
- **C ABI function calling** ([0001-c-abi-layer.md](../designs/0001-c-abi-layer.md)): `TVMFFIFunctionCall`, `TVMFFIAny`, `TVMFFIFieldSetter`, error return codes (-1, -2, 0)

- **DLPack protocol**: `DLManagedTensor`, `DLManagedTensorVersioned`, `__dlpack__`
- **`__tvm_ffi_env_stream__` protocol**: Stream capture for non-CPU tensors

Design elements this commit produces:
- **Type-cached FFI dispatch system** (`TVMFFIPyCallManager` + `TVMFFIPyArgSetter`): Thread-local `PyTypeObject* -> setter` cache replacing linear isinstance chain. New architectural pattern for Python FFI performance.
- **`__dlpack_c_exporter__` protocol**: C-level tensor export bypass for DLPack, enabling zero-Python-overhead conversion.
- **Atomic-cached DLPack versioned export** (`TensorObj::cached_dl_managed_tensor_versioned_`): Lock-free caching of DLManagedTensorVersioned for repeated export.
- **RAII call stack** (`TVMFFIPyCallManager::CallStack`): Stack-based workspace with automatic temp object cleanup (both FFI and Python refs).

## Usage Examples

**C++ type-cached dispatch (end-to-end Cython -> C++ -> C ABI):**
```python
# Python call: func(tensor, 42, "hello")
# 1. Cython Function.__call__ invokes:
#    TVMFFIPyFuncCall(TVMFFIPyArgSetterFactory_, self.chandle, args, &result, &ret)
# 2. C++ TVMFFIPyCallManager::Call iterates args:
#    For each arg, looks up Py_TYPE(arg) in dispatch_map_
#    First call: cache miss -> calls TVMFFIPyArgSetterFactory_(arg, &setter)
#    Subsequent calls with same type: cache hit -> O(1)
# 3. Each setter converts PyObject* to TVMFFIAny (e.g., TVMFFIPyArgSetterInt_ for int)
# 4. GIL released, TVMFFIFunctionCall invoked, GIL reacquired
# 5. CallStack destructor cleans up temp objects via DecRef/Py_DecRef
```

**`__dlpack_c_exporter__` protocol usage:**
```python
class MyTensorWrapper:
    # Expose a C function pointer for zero-overhead DLPack export
    __dlpack_c_exporter__ = my_c_exporter_func_as_intptr()

    def __dlpack__(self, *, stream=None):
        # Fallback Python path (not used when c_exporter is available)
        ...

# When passed to an FFI function:
# TVMFFIPyArgSetterFactory_ detects __dlpack_c_exporter__, creates
# TVMFFIPyArgSetterDLPackCExporter_ with the C function pointer.
# Conversion happens entirely in C, no Python __dlpack__ call needed.
```
