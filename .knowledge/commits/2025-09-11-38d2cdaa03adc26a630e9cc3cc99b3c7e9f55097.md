# Refactor Python FFI call mechanism: replace monolithic make_args with C++ type-dispatched setter architecture

## TL;DR
- Replaces the monolithic Cython `make_args()` / `FuncCall()` / `FuncCall3()` functions with a C++ `TVMFFIPyCallManager` that caches per-type argument setter dispatch in a thread-local `unordered_map<PyTypeObject*, TVMFFIPyArgSetter>`, amortizing type-checking overhead across repeated FFI calls.
- Adds `tvm_ffi_python_helpers.h` — a new C++ header compiled into the Cython module — containing the call manager, RAII call stack, and predefined POD setters (int, float, bool, None).
- Introduces `__dlpack_c_exporter__` protocol: a C-level function pointer on Python objects enabling zero-Python-overhead DLPack tensor export (bypasses `__dlpack__` Python method dispatch).
- Caches `DLManagedTensorVersioned` on `TensorObj` via an atomic field, avoiding repeated allocation on `ToDLPackVersioned()`.

## Impact
- API: None — `Function.__call__`, `FieldSetter.__call__`, and callback return path remain behaviorally identical. New `__dlpack_c_exporter__` protocol is opt-in.
- Behavioral: `testing.nop` now returns nothing (was echo of first arg). `ToDLPackVersioned()` now returns a cached object (same pointer on repeated calls) instead of allocating fresh each time; the deleter only dec-refs the TensorObj without `delete`ing the struct.
- Flags/config: `CMakeLists.txt` adds `target_include_directories` for the new `tvm_ffi_python_helpers.h` header.
- Data formats/schemas: None.

- **0002 Object system**: `Object`, `ObjectRef` lifecycle (IncRef/DecRef), `TVMFFIObjectGetTypeIndex`.
- **0003 Function system**: `TVMFFIFunctionCall` C ABI for invoking packed functions.
- **0006 Containers**: `TensorObj`, `DLManagedTensor`, `DLManagedTensorVersioned`, `from_dlpack`.
- **0007 C ABI**: `TVMFFIAnyViewToOwnedAny`, `TVMFFITensorFromDLPack`, `TVMFFITensorFromDLPackVersioned`, `TVMFFIEnvSetCurrentStream`.
- **0012 Python bindings**: Cython `Object`, `Tensor`, `Function`, `FieldSetter`, `ByteArrayArg`, `DataType`, `Device`, `PyNativeObject`, `ObjectConvertible`, callback mechanism.

Design elements this commit produces:
- **TVMFFIPyCallManager + setter dispatch architecture**: New internal design element replacing `make_args`. Thread-local type cache with pluggable setter factory.
- **DLPackPyObjectCExporter / `__dlpack_c_exporter__` protocol**: New C-level extension point for zero-overhead DLPack tensor export, bypassing Python `__dlpack__` method dispatch.
- **TensorObj::cached_dl_managed_tensor_versioned_**: Atomic cached DLPack versioned export with lock-free CAS initialization.

## Usage Examples

**DLPack C-export protocol** (from test wrapper in `tensor.pxi`):
```python
# C-level: define a C function matching DLPackPyObjectCExporter signature
cdef int my_exporter(void* obj, DLManagedTensorVersioned** out,
                     TVMFFIStreamHandle* env_stream) except -1:
    wrapper = <MyWrapper>(<PyObject*>obj)
    if env_stream != NULL:
        env_stream[0] = get_current_stream(wrapper.device)
    return TVMFFITensorToDLPackVersioned(wrapper.tensor.chandle, out)

# Python-level: attach as class attribute (integer pointer)
class MyWrapper:
    __dlpack_c_exporter__ = my_exporter_as_intptr()  # long long of func ptr

# When passed to an FFI call, the setter factory detects __dlpack_c_exporter__
# and routes through TVMFFIPyArgSetterDLPackCExporter_ (C-speed path)
nop = tvm_ffi.get_global_func("testing.nop")
nop(MyWrapper(tensor))  # uses C exporter, no Python __dlpack__ call
```

**Before/after calling convention** (internal refactor):
```python
# BEFORE: monolithic make_args + FuncCall
#   make_args(args, &packed_args[0], temp_args, &ctx_dev_type, ...)
#   TVMFFIFunctionCall(chandle, &packed_args[0], nargs, result)

# AFTER: C++ dispatched call
#   TVMFFIPyFuncCall(TVMFFIPyArgSetterFactory_, chandle, <PyObject*>args, &result, &c_api_ret_code)
#   Internally: CallManager looks up setter per PyTypeObject*, caches it, invokes setter
```
