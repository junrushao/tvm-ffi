# Refactor Python FFI call mechanism with C++ type-dispatched arg setters for performance

## TL;DR
- Replaces the monolithic `make_args`/`FuncCall`/`FuncCall3` Cython arg-packing functions with a C++ `TVMFFIPyCallManager` dispatcher that caches per-`PyTypeObject*` setter functions in a thread-local `unordered_map`, avoiding repeated `isinstance` chains on every FFI call.
- Introduces `tvm_ffi_python_helpers.h` -- a new C++ header compiled into the Cython module -- containing `TVMFFIPyCallManager` (RAII call stack, GIL release, stream management), `TVMFFIPyArgSetter` (function-pointer struct), `TVMFFIPyCallContext` (per-call state), and free-standing POD setters for int/float/bool/None.
- Adds `DLManagedTensorVersioned` caching to `TensorObj::ToDLPackVersioned()` via a `mutable std::atomic<DLManagedTensorVersioned*>` field with CAS-based lazy init, eliminating repeated allocations for repeated DLPack exports.

## Impact
- API: New `__dlpack_c_exporter__` protocol for zero-Python-overhead DLPack tensor export. `DLTensorTestWrapper` demonstrates usage. The `testing.nop` function now returns nothing (was echoing first arg).
- Behavioral: FFI call arg packing is now type-dispatched via cached function pointers instead of sequential `isinstance` checks. First call per type pays a one-time factory lookup; subsequent calls hit the cache. GIL release now happens inside `TVMFFIPyCallManager::Call` (C++ side) rather than inline in Cython.
- Flags/config: none
- Data formats/schemas: `TensorObj` gains a new `cached_dl_managed_tensor_versioned_` field (does not affect serialization -- protected field, not reflection-registered).

## Design Elements
Design elements this commit consumes:
- FFI C ABI (`TVMFFIFunctionCall`, `TVMFFIAnyViewToOwnedAny`, `TVMFFIEnvSetCurrentStream`, `TVMFFITensorFromDLPack`, `TVMFFITensorFromDLPackVersioned`, `TVMFFITensorToDLPackVersioned`) -- see [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md)
- Object system (`TVMFFIObjectDecRef`, `TVMFFIObjectIncRef`, `TVMFFIObjectGetTypeIndex`) -- see [0003-ffi-object-system](../design-records/0003-ffi-object-system.md)
- Function system (`TVMFFIFunctionCall` packed calling convention) -- see [0004-ffi-function-system](../design-records/0004-ffi-function-system.md)
- Reflection field setters (`TVMFFIFieldSetter`) -- see [0007-ffi-reflection](../design-records/0007-ffi-reflection.md)
- Python FFI package structure (`core.pyx` composed from `.pxi` includes) -- see [0012-ffi-python-package](../design-records/0012-ffi-python-package.md)

Design elements this commit produces:
- **`TVMFFIPyCallManager`**: Thread-local C++ dispatcher with per-`PyTypeObject*` cached setter dispatch, RAII call stack with temp-object lifetime management. This replaces the old `make_args`/`FuncCall` pattern as the central Python->C arg conversion mechanism.
- **`TVMFFIPyArgSetter` protocol**: Function-pointer struct + factory pattern enabling extensible type-dispatched arg conversion. Each Python type maps to exactly one setter function.
- **`DLPackPyObjectCExporter` protocol**: C-level function pointer for exporting Python objects to `DLManagedTensorVersioned` without going through Python's `__dlpack__` protocol. Exposed via `__dlpack_c_exporter__` attribute.
- **`TensorObj::cached_dl_managed_tensor_versioned_`**: Atomic-cached DLPack versioned struct with CAS-based lazy init and destructor cleanup.

## Usage Examples

**C++ type-dispatched FFI call (how Function.__call__ now works internally):**
```python
# Before (old make_args / FuncCall pattern):
#   make_args() iterates args with isinstance chain for EVERY call
#   FuncCall3/FuncCall allocates stack/heap, manages stream inline

# After (new TVMFFIPyCallManager pattern):
#   1. TVMFFIPyArgSetterFactory_ checks isinstance ONCE per type, caches setter
#   2. TVMFFIPyCallManager::Call() uses cached setter on subsequent calls
#   3. CallStack RAII manages temp objects and packed_args memory

f = tvm_ffi.get_global_func("testing.echo")
x = tvm_ffi.Tensor.from_numpy(np.zeros(10))
# First call: Factory_ classifies Tensor -> TVMFFIPyArgSetterTensor_, caches it
# Subsequent calls: dispatch_map_[PyTypeObject* for Tensor] -> cached setter
result = f(x)
```

**DLPack C exporter protocol (new zero-overhead path):**
```python
# Objects with __dlpack_c_exporter__ bypass Python __dlpack__ protocol entirely
class MyTensorWrapper:
    __dlpack_c_exporter__ = get_c_exporter_intptr()  # int(function pointer)
    # The C function signature: int(void* py_obj, DLManagedTensorVersioned** out, void** env_stream)

wrapper = MyTensorWrapper(some_tensor)
f(wrapper)  # setter detects __dlpack_c_exporter__, calls C function directly
```
