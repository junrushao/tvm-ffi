# Add sphinx-design as documentation build dependency
## TL;DR
- Adds `sphinx-design` to the Sphinx extensions list in `docs/conf.py` and to the `[docs]` dependency group in `pyproject.toml`.
- Updates `docs/.rstcheck.cfg` to ignore sphinx-design directives (`tab-set`, `collapse`, `tabs`), the `c:macro` role, and `cpp`/`python` code blocks in rstcheck validation.
