# Add sphinx-design as a Sphinx extension dependency for the documentation build
## TL;DR
- Adds `sphinx-design` to the `[docs]` extras in `pyproject.toml` so it is installed with the doc build dependencies.
- Registers `sphinx_design` in `docs/conf.py`'s `extensions` list so Sphinx loads it.
- Extends `docs/.rstcheck.cfg` to ignore `sphinx-design`-specific directives (`tab-set`, `collapse`, `tabs`), role (`c:macro`), and code-block languages (`cpp`, `python`) that rstcheck cannot validate.
