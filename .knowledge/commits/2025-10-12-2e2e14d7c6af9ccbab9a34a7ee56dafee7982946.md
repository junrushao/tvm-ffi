# Add sphinx-design as a Sphinx documentation dependency
## TL;DR
- Adds `sphinx-design` to the `[docs]` optional dependency group in `pyproject.toml` and enables it as a Sphinx extension in `docs/conf.py`.
- Updates `docs/.rstcheck.cfg` to ignore new sphinx-design directives (`tab-set`, `collapse`, `tabs`), the `c:macro` role, and `cpp`/`python` code block languages.
