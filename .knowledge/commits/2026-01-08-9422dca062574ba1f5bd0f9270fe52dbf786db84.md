# Reorganize Tensor doc to lead with Common Usage section
## TL;DR
- Restructured `docs/concepts/tensor.rst`: moved the former "Tensor APIs" section (at the end) into a new "Common Usage" section placed before "Tensor Classes," giving readers API guidance earlier.
- Split monolithic API section into four topical subsections: Kernel Signatures, PyTorch Interop, C++ Allocation, C++ Stream Handling.
- Minor editorial fixes: title casing ("What Tensor Is Not"), added `#include` to kernel example, expanded PyTorch round-trip example to show `torch.from_dlpack` re-export.
