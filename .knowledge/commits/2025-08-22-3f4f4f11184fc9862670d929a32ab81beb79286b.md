# Fix strict-aliasing violation in fastmath-safe JSON float helpers by replacing reinterpret_cast with union type-punning
## TL;DR
- The `FastMathSafe*` helpers introduced in `1a271f0` used `reinterpret_cast` to convert between `double` and `uint64_t` for IEEE 754 bit manipulation. GCC with `-ffast-math -Werror=strict-aliasing` rejects this as a strict-aliasing violation, producing a compile error.
- This commit replaces all 5 `reinterpret_cast` type-punning sites with union-based type-punning (`union { double from; uint64_t to; }`), which is universally accepted by GCC/Clang/MSVC without strict-aliasing warnings.
- Affected functions: `FastMathSafePosInf`, `FastMathSafeNegInf`, `FastMathSafeNaN` (parser) and `FastMathSafeIsNaN`, `FastMathSafeIsInf` (writer).

## Key Exports
None -- all changes are to private static helper functions internal to `json_parser.cc` and `json_writer.cc`. No public API changes.

## Impact
- API: None
- Behavioral: None -- the bit patterns and logic are identical; only the type-punning mechanism changes.
- Flags/config: Fixes compilation under `-ffast-math` with `-Werror=strict-aliasing` (GCC). Previously this combination produced a hard compile error.
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Fastmath-safe float special-value pattern** ([0012-json-and-serialization.md](../designs/0012-json-and-serialization.md)): The commit modifies the implementation of the `#ifdef __FAST_MATH__` code paths introduced in `1a271f0`, preserving the same IEEE 754 bit constants and detection logic.
- **Extra API isolation** ([ADR-0010](../ADRs/0010-extra-api-isolation.md)): Both files are in `src/ffi/extra/`.

Design elements this commit produces:
- **Union-based type-punning idiom for IEEE 754 bit manipulation**: Establishes the `union { TypeA from; TypeB to; } u; u.from = x; return u.to;` pattern as the preferred way to do `double <-> uint64_t` bit reinterpretation under `__FAST_MATH__`. This supersedes the `reinterpret_cast` approach from `1a271f0`.

## Usage Examples
Before (strict-aliasing violation under `-ffast-math`):
```cpp
// Parser: reinterpret_cast triggers -Werror=strict-aliasing
static double FastMathSafePosInf() {
    const uint64_t inf_bits = 0x7FF0000000000000ULL;
    return *reinterpret_cast<const double*>(&inf_bits);  // UB: strict-aliasing
}

// Writer: same issue in reverse direction
static bool FastMathSafeIsNaN(double x) {
    uint64_t bits = *reinterpret_cast<const uint64_t*>(&x);  // UB: strict-aliasing
    // ...
}
```

After (union-based type-punning, no strict-aliasing violation):
```cpp
// Parser: union write-one-read-other pattern
static double FastMathSafePosInf() {
    union { uint64_t from; double to; } u;
    u.from = 0x7FF0000000000000ULL;  // write "from", read "to"
    return u.to;
}

// Writer: same pattern, reversed direction
static bool FastMathSafeIsNaN(double x) {
    union { double from; uint64_t to; } u;
    u.from = x;  // write "from", read "to"
    uint64_t bits = u.to;
    // ...
}
```
