# Rewrite ABI overview doc from Markdown to RST with extracted C example code
## TL;DR
- Rewrites `docs/concepts/abi_overview.md` (Markdown) as `docs/concepts/abi_overview.rst` (RST), adding Sphinx cross-references, `literalinclude` directives, and `seealso`/`dropdown` blocks.
- Adds `examples/abi_overview/example_code.c` (292 lines) containing self-contained C functions for every ABI concept (Any, Object, Tensor, Function, Error), referenced via `literalinclude` from the new RST.
- Refactors four concept docs (`any.rst`, `func_module.rst`, `object_and_class.rst`, `tensor.rst`) by removing inline C code examples and replacing them with cross-references to the centralized `abi_overview.rst`.
- Adds `[TAG.begin]`/`[TAG.end]` comment markers to `c_api.h` for Sphinx `literalinclude` extraction. Bumps version patch 8 to 9.
