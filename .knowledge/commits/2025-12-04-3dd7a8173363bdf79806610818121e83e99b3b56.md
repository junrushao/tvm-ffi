# Introduce __tvm_ffi_value__ generic value protocol and refactor CallStack into standalone TVMFFIPyCallStack/TVMFFIPyCallContext

## TL;DR
- Adds the `__tvm_ffi_value__` protocol: any Python class implementing this dunder method can participate in FFI argument dispatch by returning an FFI-compatible proxy value. The protocol supports recursive/nested dispatch.
- Refactors `TVMFFIPyCallManager::CallStack` (nested class) into two standalone types: `TVMFFIPyCallStack` (thread-local memory arena) and `TVMFFIPyCallContext` (RAII per-call context), decoupling memory ownership from call-manager internals.
- Adds `extra_temp_py_objects_stack` to handle temporary Python objects that exceed the one-temp-per-argument budget, needed by the value protocol's recursive dispatch.

## Impact
- API: New `__tvm_ffi_value__` dunder protocol. Any Python class implementing `__tvm_ffi_value__() -> Any` is now auto-dispatched through FFI argument conversion. Additive -- no existing protocols broken.
- Behavioral: `TVMFFIPyCallContext` is no longer a plain struct but an RAII class with constructor/destructor. `SetArgument` is now a public method of `TVMFFIPyCallManager` (was private, called only by internal methods).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Cached type dispatch** ([ADR 0011](../ADRs/0011-cached-type-dispatch-ffi-call.md)): The `__tvm_ffi_value__` setter is registered in `TVMFFIPyArgSetterFactory_` using the same `PyTypeObject*`-cached dispatch mechanism.
- **TVMFFIPyCallManager** ([0012-python-bindings](../designs/0012-python-bindings.md)): `SetArgument` and `FuncCall`/`ConstructorCall` are the dispatch backbone consumed by the new protocol.
- **Existing dunder protocols** (`__tvm_ffi_object__`, `__tvm_ffi_int__`, `__tvm_ffi_float__`): The new `__tvm_ffi_value__` follows the same extensibility pattern.

Design elements this commit produces:
- **`__tvm_ffi_value__` protocol**: A new generic value protocol for FFI argument conversion. Unlike `__tvm_ffi_object__`/`__tvm_ffi_int__`/`__tvm_ffi_float__` which convert to a specific FFI type, `__tvm_ffi_value__` returns an arbitrary Python value that is re-dispatched through the full setter pipeline. Supports recursive nesting.
- **`TVMFFIPyCallStack`**: Standalone thread-local memory arena extracted from `TVMFFIPyCallManager`. Owns `args_stack` and `extra_temp_py_objects_stack`.
- **Refactored `TVMFFIPyCallContext`**: Promoted from nested `CallStack` to standalone RAII class. Now takes a `TVMFFIPyCallStack*` parameter and manages `extra_temp_py_objects_stack` cleanup.
- **`TVMFFIPySetArgumentGenericDispatcher`**: New C-linkage entry point that allows re-dispatching a value through the argument setter pipeline mid-call.
- **`TVMFFIPyPushExtraTempPyObject`**: New C-linkage helper for overflow temporary object tracking.

## Usage Examples

Using `__tvm_ffi_value__` to make a custom class FFI-passable (from `test_function.py`):

```python
import tvm_ffi

class ValueProtocol:
    def __init__(self, value):
        self.value = value

    def __tvm_ffi_value__(self):
        return self.value

fecho = tvm_ffi.get_global_func("testing.echo")
# Scalar passthrough
assert fecho(ValueProtocol(10)) == 10
# Container passthrough (list -> Array)
assert tuple(fecho(ValueProtocol([1, 2, 3]))) == (1, 2, 3)
# Recursive nesting -- each layer unwraps via __tvm_ffi_value__
assert fecho(ValueProtocol(ValueProtocol(ValueProtocol(10)))) == 10
```

Combining with tensor interop (from `test_tensor.py`):

```python
class MyCustom:
    def __init__(self, a, b):
        self.a = a  # a tensor-like object
        self.b = b  # an int

    def __tvm_ffi_value__(self):
        return (self.a, self.b)  # tuple -> FFI Array dispatch

z = fecho(MyCustom(a=my_tensor, b=2))
assert z[0].__chandle__() == my_tensor.__chandle__()
assert z[1] == 2
```
