# Introduce generic value protocol for Python-to-FFI conversion
## TL;DR
- Introduces `__tvm_ffi_as_object__` protocol allowing Python objects to define custom conversion to FFI Object types.
- Refactors the Python-to-FFI value conversion pipeline to be more extensible.

## Key Exports

**Protocols (Python):**
- `__tvm_ffi_as_object__` -- Protocol for custom Python object conversion to FFI objects.

## Impact
- API: New `__tvm_ffi_as_object__` protocol for extensible type conversion.
- ABI: none
- Behavioral: Python objects implementing the protocol are automatically converted in FFI calls.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit produces:
