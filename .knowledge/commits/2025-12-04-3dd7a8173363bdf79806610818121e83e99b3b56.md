# Add __tvm_ffi_value__ protocol for generic Python-to-FFI value conversion, and refactor TVMFFIPyCallContext into a standalone RAII class with extra temp object stack

## TL;DR

- Introduces the `__tvm_ffi_value__` protocol: any Python class implementing this dunder method can declare how it converts to a TVM-FFI-compatible value, enabling transparent FFI argument passing for wrapper types like `NamedTuple` containers or custom domain objects.
- Extracts `TVMFFIPyCallManager::CallStack` (inner class) into a standalone `TVMFFIPyCallStack` (thread-local stack) and promotes `TVMFFIPyCallContext` from a plain `struct` to a fully RAII `class` that owns its own allocation/release lifecycle.
- Adds `extra_temp_py_objects_stack` to `TVMFFIPyCallStack` and the helper `TVMFFIPyPushExtraTempPyObject` to handle temporaries produced by value protocol conversion that may exceed the one-temp-per-argument budget.

## Impact

- API: Additive — new `__tvm_ffi_value__` dunder protocol for user-defined classes. No existing callers affected.
- Behavioral: `TVMFFIPyCallContext` is now a RAII class; its destructor also drains `extra_temp_py_objects_stack`, preventing refcount leaks from value-protocol temporaries that exceed the one-per-arg budget. Old `CallStack` inner class removed from `TVMFFIPyCallManager`.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

End-to-end trace: Python class with `__tvm_ffi_value__` → FFI call dispatch.

```python
# Python side (tests/python/test_function.py)
import tvm_ffi

class ValueProtocol:
    def __init__(self, value):
        self.value = value

    def __tvm_ffi_value__(self):
        return self.value  # can be int, list, another ValueProtocol, etc.

fecho = tvm_ffi.get_global_func("testing.echo")
assert fecho(ValueProtocol(10)) == 10
assert tuple(fecho(ValueProtocol([1, 2, 3]))) == (1, 2, 3)

# Nested value protocol — recursive dispatch unwraps automatically
nested = ValueProtocol(ValueProtocol(ValueProtocol(10)))
assert fecho(nested) == 10

# With NamedTuple fields containing Tensors (tests/python/test_tensor.py)
class MyCustom:
    def __init__(self, a, b):
        self.a = a
        self.b = b

    def __tvm_ffi_value__(self):
        return (self.a, self.b)  # tuple is FFI-compatible, dispatches each element

z = fecho(MyCustom(a=some_tensor, b=2))
assert z[0].__chandle__() == some_tensor.__chandle__()
assert z[1] == 2
```

C++ → Cython dispatch path for `__tvm_ffi_value__`:
```
TVMFFIPyArgSetterFactory_ detects hasattr(type(arg), "__tvm_ffi_value__")
  → caches TVMFFIPyArgSetterFFIValueProtocol_ setter for this PyType
  → on call: invoke arg.__tvm_ffi_value__()
  → push result to extra_temp_py_objects_stack (TVMFFIPyPushExtraTempPyObject)
  → call TVMFFIPySetArgumentGenericDispatcher to recursively dispatch result
  → result lifetime managed by extra_temp_py_objects_stack until frame destructor runs
```
