# Introduce __tvm_ffi_value__ generic value protocol and refactor call stack into RAII TVMFFIPyCallContext

## TL;DR
- Adds `__tvm_ffi_value__` protocol: any Python class implementing this dunder method can declare how it converts to an FFI-compatible value, with recursive dispatch and nested support.
- Refactors `TVMFFIPyCallManager::CallStack` (inner class) into a standalone `TVMFFIPyCallContext` (RAII class) and extracts reusable memory into `TVMFFIPyCallStack`, adding an `extra_temp_py_objects_stack` for protocols that produce more than one temporary per argument.
- Updates benchmark to use `NamedTuple` instead of `TestFFITensor` wrapper and adds `NamedTuple` + `__tvm_ffi_value__` tests.

## Impact
- API: Additive -- new `__tvm_ffi_value__` protocol allows any Python class to participate in FFI arg dispatch. No existing APIs removed.
- Behavioral: `TVMFFIPyCallContext` destructor now also cleans up `extra_temp_py_objects_stack` entries, broadening the per-call lifetime management scope.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVMFFIPyCallManager` dispatcher and cached per-type setter pattern ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md))
- `TVMFFIPyArgSetterFactory_` dispatch chain with priority ordering ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md))
- `TVMFFIPyCallContext` per-call context with temp object lifetime management ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md))
- DLPack exchange API protocol (`__c_dlpack_exchange_api__`) ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md))

Design elements this commit produces:
- **`__tvm_ffi_value__` protocol**: new dunder protocol for generic value conversion. Follows the same pattern as `__tvm_ffi_int__`, `__tvm_ffi_float__`, etc. but is fully generic -- the return value is recursively dispatched through the full setter factory.
- **`TVMFFIPyCallStack`**: new standalone class extracting reusable thread-local memory (args_stack, extra_temp_py_objects_stack) from `TVMFFIPyCallManager`.
- **`TVMFFIPyCallContext` promotion**: refactored from `TVMFFIPyCallManager::CallStack` inner class to standalone RAII class, now directly holding a `TVMFFIPyCallStack*` pointer.
- **`extra_temp_py_objects_stack`**: new overflow storage for protocols that produce more than one temporary Python object per argument (currently only `__tvm_ffi_value__`).
- **`TVMFFIPySetArgumentGenericDispatcher`**: new C++ helper enabling re-entrant setter dispatch from within a setter (needed for recursive value protocol).
- **`TVMFFIPyPushExtraTempPyObject`**: new C++ helper for pushing overflow temp objects.

## Usage Examples

### Using `__tvm_ffi_value__` protocol
**Context**: Pass an arbitrary Python class to an FFI function by implementing `__tvm_ffi_value__()`.
```python
import tvm_ffi

class MyCustom:
    def __init__(self, a, b):
        self.a = a
        self.b = b

    def __tvm_ffi_value__(self):
        """Return an FFI-compatible representation."""
        return (self.a, self.b)

fecho = tvm_ffi.get_global_func("testing.echo")

# Direct usage -- converted to tuple on the FFI side
result = fecho(MyCustom(a=1, b=2))
assert tuple(result) == (1, 2)

# Nested -- recursive dispatch resolves inner ValueProtocol objects too
class Wrapper:
    def __init__(self, val):
        self.val = val
    def __tvm_ffi_value__(self):
        return self.val

assert fecho(Wrapper(Wrapper(Wrapper(10)))) == 10
```

### Combining with tensor protocols
**Context**: `__tvm_ffi_value__` composes with other FFI protocols like `__tvm_ffi_object__`.
```python
class MyTensorPair:
    def __init__(self, a: tvm_ffi.Tensor, b: int):
        self.a = a
        self.b = b

    def __tvm_ffi_value__(self):
        return (self.a, self.b)

result = fecho(MyTensorPair(a=some_tensor, b=2))
# result[0] is a Tensor, result[1] is 2
```
