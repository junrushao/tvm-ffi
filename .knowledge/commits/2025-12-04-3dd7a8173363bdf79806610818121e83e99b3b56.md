# Introduce generic __tvm_ffi_value__ protocol for custom value conversion
## TL;DR
- Adds a generic `__tvm_ffi_value__` protocol in `cython/tvm_ffi_python_helpers.h` that allows arbitrary Python classes to declare how they convert to TVM FFI-compatible values.
- Refactors/consolidates classes in python helpers (+141/-87 lines in `tvm_ffi_python_helpers.h`).
- Adds support in Cython `base.pxi` and `function.pxi`.
- Tests for function, stream, and tensor conversions.

## Impact
- API: New opt-in protocol `__tvm_ffi_value__` for custom Python objects
