# Introduce __tvm_ffi_value__ protocol and refactor call stack into standalone TVMFFIPyCallStack/TVMFFIPyCallContext classes
## TL;DR
- Introduces a new `__tvm_ffi_value__` Python protocol: classes implementing this method can declare how they convert to FFI-compatible values. The returned value is recursively dispatched through the generic argument setter, supporting nested conversions.
- Refactors the Cython call stack management: extracts `TVMFFIPyCallManager::CallStack` into standalone `TVMFFIPyCallStack` (thread-local storage) and `TVMFFIPyCallContext` (RAII guard) classes, with a new `extra_temp_py_objects_stack` for value protocol temporaries that exceed the one-temp-per-argument budget.
- Adds `TVMFFIPySetArgumentGenericDispatcher` and `TVMFFIPyPushExtraTempPyObject` helper functions.

### Concern 1: `__tvm_ffi_value__` protocol
New Python duck-type protocol for converting arbitrary Python objects to FFI values. Detected via `hasattr(arg_class, "__tvm_ffi_value__")` in the Cython argument setter factory. The setter calls `arg.__tvm_ffi_value__()`, pushes the result to `extra_temp_py_objects_stack` for lifetime management, then recursively dispatches through `TVMFFIPySetArgumentGenericDispatcher`.

### Concern 2: Call stack refactoring
`TVMFFIPyCallManager::CallStack` (nested class inheriting `TVMFFIPyCallContext`) is replaced by two standalone classes:
- `TVMFFIPyCallStack`: owns the `args_stack` vector and `extra_temp_py_objects_stack`, with a default 4KB page-aligned allocation.
- `TVMFFIPyCallContext`: RAII guard that borrows from `TVMFFIPyCallStack`, managing allocation/deallocation and temp cleanup including the new `extra_temp_py_objects_stack`.

## Key Exports

**Classes**:
- `TVMFFIPyCallStack` -- Thread-local call stack storage.
  - Fields: `args_stack: vector<TVMFFIAny>`, `args_stack_top: int64_t`, `extra_temp_py_objects_stack: vector<PyObject*>`
- `TVMFFIPyCallContext` -- RAII call context (constructor allocates from stack or heap, destructor cleans up temps).
  - Fields: `packed_args`, `device_type`, `device_id`, `stream`, `c_dlpack_exchange_api`, `call_stack`, `temp_ffi_objects`, `temp_py_objects`, `num_temp_ffi_objects`, `num_temp_py_objects`

**Functions**:
- `TVMFFIPySetArgumentGenericDispatcher(setter_factory, ctx, py_arg, out) -> int` -- Dispatches a Python object through the generic setter, enabling recursive value protocol resolution.
- `TVMFFIPyPushExtraTempPyObject(ctx, arg) -> void` -- Pushes extra temporary Python objects to the call stack's overflow vector (for value protocol results that exceed one-temp-per-argument).

**Cython setter**:
- `TVMFFIPyArgSetterFFIValueProtocol_` -- Setter for classes with `__tvm_ffi_value__()` method. Registered in the setter factory dispatch chain after `__tvm_ffi_float__` and before `Exception`.

**Protocol**:
- `__tvm_ffi_value__(self) -> Any` -- Python duck-type protocol. Classes implementing this method are automatically recognized by the FFI argument setter. The returned value undergoes full recursive dispatch (can return another `__tvm_ffi_value__` object, a list, an int, etc.).

## Impact
- API: Additive. New `__tvm_ffi_value__` protocol for Python classes.
- Behavioral: `TVMFFIPyCallContext` is no longer a nested class of `TVMFFIPyCallManager`. Internal refactor, not user-visible.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Python FFI call dispatch** ([0015-python-ffi-call-dispatch.md](../designs/0015-python-ffi-call-dispatch.md)): Extends the dispatch chain with a new `__tvm_ffi_value__` protocol setter. Uses `TVMFFIPyArgSetterFactory_` for recursive dispatch.
- **DLPack exchange API** ([0017-dlpack-interop.md](../designs/0017-dlpack-interop.md)): `c_dlpack_exchange_api` field moved from being looked up per-call to being a field on `TVMFFIPyCallContext`.

Design elements this commit produces:
- **`__tvm_ffi_value__` protocol**: New Python protocol for generic value conversion, analogous to existing `__tvm_ffi_int__` and `__tvm_ffi_float__` protocols but more general -- the returned value is recursively dispatched rather than directly stored.
- **Standalone `TVMFFIPyCallStack`/`TVMFFIPyCallContext`**: Decoupled from `TVMFFIPyCallManager`, making the call stack accessible from helper functions that need to push extra temporaries.

## Usage Examples
```python
class MyPoint:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __tvm_ffi_value__(self):
        return [self.x, self.y]  # converts to Array when passed to FFI

fecho = tvm_ffi.get_global_func("testing.echo")
result = fecho(MyPoint(1, 2))  # passes [1, 2] to FFI
```
