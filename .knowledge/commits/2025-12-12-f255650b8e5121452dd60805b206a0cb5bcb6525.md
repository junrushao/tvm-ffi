# Add load_lib_module for downstream library loading via importlib.metadata
## TL;DR
- Introduces `tvm_ffi.libinfo.load_lib_module(package, target_name, keep_module_alive=True) -> Module` which combines `_find_library_by_basename` (importlib.metadata discovery) with `load_module` (FFI module loading).
- Simplifies downstream extension library loading from ~25 lines of manual platform-specific path searching to a 1-liner.
- Updates the packaging example (`examples/packaging/`) to use the new API, reducing `base.py` to 2 lines. Removes CMake `set_target_properties(... PREFIX "")` since `_find_library_by_basename` handles `lib` prefixes natively.

## Key Exports

**Function** (new, `python/tvm_ffi/libinfo.py`):
```python
def load_lib_module(package: str, target_name: str, keep_module_alive: bool = True) -> Module:
    """Load a shared library as a TVM FFI Module via importlib.metadata discovery.

    Combines _find_library_by_basename (importlib.metadata RECORD lookup + fallback)
    with load_module (DSO -> Module). Handles Windows DLL directory registration.
    """
```

## Impact
- API: New public function `tvm_ffi.libinfo.load_lib_module`. No breaking changes.
- Behavioral: Downstream extension packages no longer need custom platform-specific DSO discovery code. The `lib` prefix on shared libraries is handled transparently (CMake no longer needs `set_target_properties(... PREFIX "")`).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **`_find_library_by_basename`** (introduced in 6887892) -- importlib.metadata RECORD-based library discovery
- **`load_module`** with `keep_module_alive` (introduced in 8dcaec1) -- module loading with lifetime management
- **Downstream packaging pattern** (`.knowledge/designs/0014-python-package.md`) -- canonical `base.py` pattern

Design elements this commit produces:
- **`load_lib_module` API** -- the recommended one-liner for downstream packages to load their DSOs as TVM FFI Modules. Completes the load_lib_ctypes/load_lib_module pair: ctypes for low-level C library loading, module for FFI module loading.
