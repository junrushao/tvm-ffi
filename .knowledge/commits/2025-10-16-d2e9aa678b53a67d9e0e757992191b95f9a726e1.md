# Switch wheel distribution to manylinux2014 and add Python 3.8 import/typing compatibility
## TL;DR
- Configure cibuildwheel to produce manylinux2014 wheels (x86_64 and aarch64) instead of manylinux2_28, broadening glibc compatibility for older Linux systems.
- Add Python 3.8 compatibility branches for `collections.abc` imports (PEP 585), `typing.Type` vs `type[]` annotations, and `get_type_hints(include_extras=)` usage.
- Guard `torch.float8_e8m0fnu` dtype test behind `hasattr` check for older torch versions.
