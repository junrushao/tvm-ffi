# chore(build): Switch to manylinux2014 wheels and add Python 3.8 compatibility
## TL;DR
- Switch cibuildwheel manylinux images from default (manylinux2_28) to manylinux2014 for broader glibc compatibility on older Linux systems.
- Add Python 3.8 compatibility throughout the Python package: conditional imports for `collections.abc` vs `typing` generics, `typing.Type[X]` instead of `type[X]` (PEP 585), and version-guarded `get_type_hints` call.
- Guard optional `torch.float8_e8m0fnu` dtype behind `hasattr` check and lower CI test matrix Python versions.
