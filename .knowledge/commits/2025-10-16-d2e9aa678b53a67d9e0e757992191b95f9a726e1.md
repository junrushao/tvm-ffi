# Switch to manylinux2014 wheels and add Python 3.8 backward-compatibility shims
## TL;DR
- Configures cibuildwheel to produce `manylinux2014` wheels (x86_64 and aarch64) instead of the default `manylinux2_28`, targeting systems with older glibc.
- Adds Python 3.8 compatibility shims in `container.py`, `_utils.py`, and `c_class.py`: conditional imports from `typing` instead of `collections.abc` for generics, `typing.Type` instead of `type[]` (PEP 585), and `get_type_hints` without `include_extras` on Python < 3.9.
- Lowers CI test matrix Python versions (3.10 -> 3.8 on aarch64, 3.12 -> 3.9 on Windows) and guards `torch.float8_e8m0fnu` usage for older torch versions.
