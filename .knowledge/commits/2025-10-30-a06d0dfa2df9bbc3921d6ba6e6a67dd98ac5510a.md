# Fix torch C DLPack extension build by removing unnecessary Python lib linking on Linux
## TL;DR
- Removes `-L<python-lib-dir> -lpython3` linker flags on Linux when building the torch C DLPack extension, fixing a CI failure.
- Restructures platform-conditional linking: Windows links `python3.lib` with corrected `LIBPATH`, macOS links `-lpython<version>`, Linux links neither.
- Fixes Windows `python_libdir_list` fallback to use `sys.base_exec_prefix / "libs"` instead of `sysconfig.get_path("include")`.
