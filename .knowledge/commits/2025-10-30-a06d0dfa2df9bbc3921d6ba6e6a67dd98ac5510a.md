# Fix Linux build of torch C DLPack extension by removing unnecessary Python library linkage

## TL;DR
- Removes `-L<python-lib-dir> -lpython3` from linker flags on Linux when building the torch C DLPack extension, fixing a CI build failure where the Python shared library was not available or not needed.
- Restricts Python shared library linking to macOS only (where `libtorch_python` requires it) and Windows only (where `.lib` linking is needed), using a new `IS_DARWIN` platform constant.
- Also fixes Windows: replaces incorrect `sysconfig.get_path("include")` with `sys.base_exec_prefix / "libs"` for Python library directory lookup, and removes explicit `python3.lib` from ldflags (the `/LIBPATH` alone suffices).

## Impact
- API: none
- ABI: none
- Behavioral: On Linux, the JIT-compiled torch C DLPack extension no longer links against `libpython`. This fixes build failures where the Python shared library was either not available or caused linker errors. On macOS and Windows, Python library linking is preserved because `libtorch_python` (required on these platforms) depends on Python symbols.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- PyTorch integration module JIT compilation and its per-platform linker flag assembly (`.knowledge/designs/0018-dlpack-fast-path.md`, "PyTorch Integration Module" section)

Design elements this commit produces:
- **Platform-specific Python library linking policy**: Establishes that the torch C DLPack extension's linker flags must be platform-differentiated: Linux does not link `libpython` (no `libtorch_python` needed), macOS links `libpython` (required by `libtorch_python`), and Windows links via `/LIBPATH` only (without explicit `python3.lib`). This three-way split replaces the previous two-way Windows-vs-else split.

## Usage Examples
**Before (broken on Linux):** The `else` branch applied to both Linux and macOS, unconditionally adding `-L<python-libdir> -lpython3`:
```python
# Old code: else branch = all non-Windows platforms
else:
    python_libdir = sysconfig.get_config_var("LIBDIR")
    if python_libdir:
        ldflags.append(f"-L{python_libdir}")
        py_version = f"python{sysconfig.get_python_version()}"
        ldflags.append(f"-l{py_version}")
```

**After (fixed):** Python library linking is restricted to macOS via `IS_DARWIN`:
```python
# New code: only macOS needs libpython (for libtorch_python)
if IS_DARWIN:
    python_libdir = sysconfig.get_config_var("LIBDIR")
    if python_libdir:
        py_version = f"python{sysconfig.get_python_version()}"
        ldflags.append(f"-L{python_libdir}")
        ldflags.append(f"-l{py_version}")
```
