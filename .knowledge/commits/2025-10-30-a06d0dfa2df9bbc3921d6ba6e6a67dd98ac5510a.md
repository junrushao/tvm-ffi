# Fix torch C DLPack build by removing Python library linking on Linux
## TL;DR
- Fixes the torch C DLPack addon build on Linux by removing `-L<python-lib-dir> -lpython3` from linker flags. Linux does not need `libtorch_python`, so Python shared library linking is unnecessary.
- Restricts Python library linking to macOS (`IS_DARWIN`) and Windows (`IS_WINDOWS`), where `libtorch_python` (which depends on pybind11 symbols from Python) is required.
- Fixes Windows Python library path resolution to use `sys.base_exec_prefix / "libs"` instead of `sysconfig.get_path("include")`.
