# Re-enable Python 3.8 wheel builds on macOS arm64
## TL;DR
- Removes the `cp38-macosx_*` skip rule in `pyproject.toml` so cibuildwheel again produces Python 3.8 wheels on macOS.
- Adds a special-case step in the wheel-publishing workflow: on macOS arm64, uses `actions/setup-python@v5` to install a native arm64 Python 3.8 instead of the x86_64 build that `astral-sh/setup-uv` provides.
- Pins `astral-sh/setup-uv` to a specific commit hash (`b75a909f`) across both the wheel and sdist jobs for reproducibility.
