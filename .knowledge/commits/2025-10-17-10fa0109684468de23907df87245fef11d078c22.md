# Re-enable Python 3.8 wheel builds on macOS ARM64
## TL;DR
- Removed `cp38-macosx_*` from cibuildwheel skip list, re-enabling Python 3.8 macOS wheels.
- Added special CI handling for macOS ARM64 + Python 3.8: uses `actions/setup-python` instead of `astral-sh/setup-uv` because the latter provides an x86_64 Python 3.8 binary on ARM64 Macs.
- Pinned `astral-sh/setup-uv` to a specific commit SHA (`b75a909`) in both wheel and sdist build jobs.
