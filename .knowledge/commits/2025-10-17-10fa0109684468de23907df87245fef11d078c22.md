# Re-enable Python 3.8 wheel on macOS arm64 by using actions/setup-python for arm64-native CPython
## TL;DR
- Removes `cp38-macosx_*` from the cibuildwheel `skip` list in `pyproject.toml`, re-enabling Python 3.8 macOS wheels.
- Adds a conditional `actions/setup-python@v5` step in the publish workflow for macOS ARM64 + Python 3.8, because `astral-sh/setup-uv` provides an x86_64 Python 3.8 build instead of arm64.
- Pins `astral-sh/setup-uv` to a specific commit hash (`b75a909f`) instead of the floating `@v4` tag for reproducibility.

## Key Exports
N/A -- infrastructure change only.

## Impact
- API: none
- Behavioral: Python 3.8 macOS arm64 wheels are now built and published again. Previously skipped due to the `cp38-macosx_*` entry in the cibuildwheel skip list.
- Flags/config: `pyproject.toml` `[tool.cibuildwheel]` `skip` field changed from `["*musllinux*", "cp38-macosx_*"]` to `["*musllinux*"]`.
- Data formats/schemas: none
