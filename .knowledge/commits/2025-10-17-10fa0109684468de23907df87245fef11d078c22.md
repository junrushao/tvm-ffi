# Re-enable Python 3.8 wheel builds on macOS arm64 with special setup-python handling
## TL;DR
- Removes the `cp38-macosx_*` skip rule from `pyproject.toml`, re-enabling Python 3.8 wheel builds on macOS.
- Adds a conditional `actions/setup-python@v5` step to install a native arm64 Python 3.8 on macOS, working around the fact that `astral-sh/setup-uv` only provides an x86_64 Python 3.8 on Apple Silicon runners.
- Pins `astral-sh/setup-uv` to a specific commit hash (`b75a909f`) in both the `build_wheels` and `build_sdist` jobs for reproducibility.

## Impact
- API: none
- ABI: none
- Behavioral: Python 3.8 macOS arm64 wheels are now built and published, where previously they were skipped. This extends platform support for Python 3.8 users on Apple Silicon.
- Flags/config: `pyproject.toml` `[tool.cibuildwheel].skip` changes from `["*musllinux*", "cp38-macosx_*"]` to `["*musllinux*"]`. The `publish_wheel.yml` workflow gains a conditional `actions/setup-python@v5` step for macOS arm64 and conditionalizes the `astral-sh/setup-uv` step to skip on macOS arm64.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Python packaging wheel build pipeline via cibuildwheel (`.knowledge/designs/0015-python-packaging.md`)
- CI workflow structure for multi-platform wheel builds (`.github/workflows/publish_wheel.yml`)
- The `cp38-macosx_*` skip rule introduced in commit 8831e88 (`.knowledge/commits/2025-10-16-8831e880e93621017ded57ce8639d76ecc5ab82e.md`)

Design elements this commit produces:
- **macOS arm64 Python 3.8 cross-build workaround**: On Apple Silicon GitHub Actions runners, `astral-sh/setup-uv` provides an x86_64 Python 3.8 binary (not arm64), which causes cibuildwheel to produce x86_64 wheels instead of arm64 ones. The fix uses `actions/setup-python@v5` (which provides a native arm64 build) as a pre-step, and conditionally skips `setup-uv` on macOS arm64. This is documented inline via comments referencing the cibuildwheel FAQ: https://cibuildwheel.pypa.io/en/stable/faq/#macos-building-cpython-38-wheels-on-arm64
- **Pinned action versions**: `astral-sh/setup-uv` is pinned to commit `b75a909f75acd358c2196fb9a5f1299a9a8868a4` (v6.7.0) in both jobs, replacing the floating `@v4` tag for reproducible CI builds.
