# Clarify Function ABI: add cpp_call field and remove ImportedFunctionObjImpl
## TL;DR
- Adds `void* cpp_call` field to `TVMFFIFunctionCell` (C ABI), providing a dual-path calling convention: `safe_call` for C ABI boundary crossings, `cpp_call` for zero-overhead C++ calls.
- Removes `FunctionObj::call` member (was `FCall` type) in favor of using `TVMFFIFunctionCell::cpp_call` directly.
- Removes `RedirectCallToSafeCall<T>` CRTP base class and `ImportedFunctionObjImpl`. Adds `ExternCFunctionObjNullHandleImpl` for raw function pointers.
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC` signature updated: `args` parameter now `const TVMFFIAny*` (was non-const).

## Key Exports

class TVMFFIFunctionCell:
    """C ABI function cell."""
    safe_call: TVMFFISafeCallType  # C-ABI exception-catching call

    # Invariant: cpp_call is NULL for functions not originally created in C++

## Impact
- API: `TVMFFIFunctionCell` gains `cpp_call` field (C ABI change). `Function::ImportFromExternDLL` removed. `TVM_FFI_DLL_EXPORT_TYPED_FUNC` args now `const TVMFFIAny*`.
- Behavioral: `CallPacked` uses branchless conditional to select cpp_call vs safe_call fallback.
- Flags/config: None
- Data formats/schemas: `TVMFFIFunctionCell` C struct layout changed (new field added).

## Design Elements
Design elements this commit consumes:

Design elements this commit produces:
- `TVMFFIFunctionCell.cpp_call` field -- optional zero-overhead C++ call path stored as `void*` to avoid C++ dependency in C header.
- `ExternCFunctionObjNullHandleImpl` -- lightweight FunctionObj for raw C function pointers without closure.

## Usage Examples
```cpp
int testing_add1(int x) { return x + 1; }
TVM_FFI_DLL_EXPORT_TYPED_FUNC(testing_add1, testing_add1);

// Usage: wrap raw C-ABI function

assert(fadd1(1).cast<int>() == 2);
```
