# Unify Function dual-call pointers into TVMFFIFunctionCell and remove DLL import indirection
## TL;DR
- Moves the C++ fast-call pointer from `FunctionObj::call` into `TVMFFIFunctionCell::cpp_call` (a `void*`), making both call paths visible at the C ABI level and eliminating the C++-only `FCall call` member.
- Removes `ImportedFunctionObjImpl`, `Function::ImportFromExternDLL`, and the `RedirectCallToSafeCall<Derived>` CRTP base -- cross-DLL functions now always dispatch through `safe_call` without a wrapper object.
- Adds `ExternCFunctionObjNullHandleImpl` for lightweight raw C function pointers (no closure) and fixes `TVM_FFI_DLL_EXPORT_TYPED_FUNC` to use `const TVMFFIAny*` for args.

## Key Exports

**Struct (C ABI)**:
```c
typedef struct {
  TVMFFISafeCallType safe_call;  // existing
  void* cpp_call;                // NEW: C++ call pointer, NULL for non-C++ functions
} TVMFFIFunctionCell;
```

**Class (mutated)** -- `FunctionObj`:
```cpp
class FunctionObj : public Object, public TVMFFIFunctionCell {
public:
  typedef void (*FCall)(const FunctionObj*, const AnyView*, int32_t, Any*);
  using TVMFFIFunctionCell::cpp_call;   // NEW: replaces `FCall call;`
  using TVMFFIFunctionCell::safe_call;
  void CallPacked(const AnyView* args, int32_t num_args, Any* result) const;
  // CallPacked now: cpp_call ? reinterpret_cast<FCall>(cpp_call)(...) : CppCallDedirectToSafeCall(...)
private:
  static void CppCallDedirectToSafeCall(const FunctionObj*, const AnyView*, int32_t, Any*);
  // Protected SafeCall() REMOVED from base class
};
```

**Class (new)** -- `ExternCFunctionObjNullHandleImpl`:
```cpp
class ExternCFunctionObjNullHandleImpl : public FunctionObj {
public:
  explicit ExternCFunctionObjNullHandleImpl(TVMFFISafeCallType safe_call);
  // Sets this->safe_call = safe_call; this->cpp_call = nullptr;
};
```

**Class (mutated)** -- `FunctionObjImpl<TCallable>`:
- Constructor now sets `this->cpp_call = reinterpret_cast<void*>(CppCall)` instead of `this->call = Call`.
- `SafeCall` moved here from `FunctionObj` base; dispatches through `self->cpp_call`.

**Class (mutated)** -- `ExternCFunctionObjImpl`:
- No longer inherits `RedirectCallToSafeCall<>`.
- Sets `this->cpp_call = nullptr`.
- Destructor now guards `if (deleter_) deleter_(self_)`.

**Removed**:
- `RedirectCallToSafeCall<Derived>` template (CRTP base)
- `ImportedFunctionObjImpl` class
- `Function::ImportFromExternDLL` static method
- `FunctionObj::SafeCall` protected static method
- `FunctionObj::call` data member

**Macro (mutated)** -- `TVM_FFI_DLL_EXPORT_TYPED_FUNC`:
- `args` parameter type changed from `TVMFFIAny*` to `const TVMFFIAny*` (matches `TVMFFISafeCallType` signature).

**Function (mutated)** -- `Function::FromExternC`:
- Now dispatches to `ExternCFunctionObjNullHandleImpl` when `self == nullptr && deleter == nullptr`.

## Impact
- API: Breaking -- `FunctionObj::call` member removed (replaced by `cpp_call` via `TVMFFIFunctionCell`); `Function::ImportFromExternDLL` removed; `ImportedFunctionObjImpl` removed. Any code referencing these symbols must be updated.
- Behavioral: `CallPacked` now uses a branchless conditional (`cpp_call ? ... : CppCallDedirectToSafeCall`) instead of always calling through `call`. For extern-C functions, the `safe_call` path is used directly without an intermediate wrapper object.
- Flags/config: none
- Data formats/schemas: `TVMFFIFunctionCell` ABI struct gains a new `void* cpp_call` field (8 bytes). This changes the C ABI layout for function objects.

## Design Elements
Design elements this commit consumes:
- **TVMFFIFunctionCell** ([0001-c-abi-layer.md](../designs/0001-c-abi-layer.md)): Extended with `cpp_call` field
- **TVMFFISafeCallType** ([0001-c-abi-layer.md](../designs/0001-c-abi-layer.md)): Unchanged calling convention
- **FunctionObj dual-call architecture** ([0004-function-system.md](../designs/0004-function-system.md)): Restructured from `call`+`safe_call` to `cpp_call`+`safe_call`
- **TVM_FFI_SAFE_CALL_BEGIN/END** ([0004-function-system.md](../designs/0004-function-system.md)): Used in `FunctionObjImpl::SafeCall`
- **Module symbol loading** ([0013-module-system.md](../designs/0013-module-system.md)): `TVM_FFI_DLL_EXPORT_TYPED_FUNC` updated for const-correctness

Design elements this commit produces:
- **`TVMFFIFunctionCell::cpp_call`**: New void* field exposing the C++ fast-call pointer at the C ABI level (was previously C++-only as `FunctionObj::call`)
- **`ExternCFunctionObjNullHandleImpl`**: Lightweight FunctionObj for raw C function pointers with no closure
- **Branchless CallPacked dispatch**: Conditional expression selecting `cpp_call` or `CppCallDedirectToSafeCall` fallback
- **Invariant change**: The "dual-pointer invariant" changes from "both `call` and `safe_call` must be set" to "`safe_call` must always be set; `cpp_call` may be NULL (for non-C++ functions), in which case `CallPacked` falls back through `safe_call`"

## Usage Examples
**Creating a Function from an exported C symbol (new null-handle path)**:
```cpp
// Define and export a typed C++ function
int testing_add1(int x) { return x + 1; }
TVM_FFI_DLL_EXPORT_TYPED_FUNC(testing_add1, testing_add1);

// Wrap the exported C symbol -- self=nullptr, deleter=nullptr triggers ExternCFunctionObjNullHandleImpl
Function fadd1 = Function::FromExternC(nullptr, __tvm_ffi_testing_add1, nullptr);
EXPECT_EQ(fadd1(1).cast<int>(), 2);
```
