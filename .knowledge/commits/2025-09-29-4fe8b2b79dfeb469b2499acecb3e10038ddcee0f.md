# Clarify Function ABI: add cpp_call pointer to TVMFFIFunctionCell, remove ImportedFunctionObjImpl and RedirectCallToSafeCall
## TL;DR
- Adds `void* cpp_call` field to `TVMFFIFunctionCell` in `c_api.h`. This is a C++-style call pointer (throws exceptions instead of error codes) that can be used within the same DLL to bypass the safe-call overhead. Set to `nullptr` for C-origin functions.
- Removes `FunctionObj::call` C++ member (previously `FCall call`). `CallPacked` now dispatches via `cpp_call` (if non-null) or falls back to `CppCallDedirectToSafeCall` which wraps `safe_call`.
- Removes `RedirectCallToSafeCall<Derived>` CRTP helper and `ImportedFunctionObjImpl`. Cross-DLL function import (`ImportFromExternDLL`) is removed entirely.
- Adds `ExternCFunctionObjNullHandleImpl` for the common case of raw C function pointers without closure (`self == nullptr && deleter == nullptr`).
- Fixes `TVM_FFI_DLL_EXPORT_TYPED_FUNC` signature: `args` parameter becomes `const TVMFFIAny*`.
- Bumps version to `0.1.0b12`.

## Impact
- API: ABI-breaking. `TVMFFIFunctionCell` gains `cpp_call` field. `Function::ImportFromExternDLL` removed. `FunctionObj::call` removed. `TVM_FFI_DLL_EXPORT_TYPED_FUNC` signature changed.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Function system** ([`.knowledge/designs/0004-function-system.md`](../designs/0004-function-system.md)): Restructures the core `FunctionObj` dispatch mechanism.
- **C ABI** ([`.knowledge/designs/0001-c-abi.md`](../designs/0001-c-abi.md)): Extends `TVMFFIFunctionCell` with `cpp_call`.

Design elements this commit produces:
- **Dual-dispatch function ABI**: `TVMFFIFunctionCell` now has two call paths: `safe_call` (C-compatible, error codes) and `cpp_call` (C++ exceptions, same-DLL only). `CallPacked` uses branchless select: `cpp_call ? cpp_call : CppCallDedirectToSafeCall`.
- **Removed cross-DLL import**: `ImportedFunctionObjImpl` and `ImportFromExternDLL` are gone. All C-origin functions now route through `safe_call` with `cpp_call = nullptr`.
