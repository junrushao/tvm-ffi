# Unify FunctionObj dual entry points by moving cpp_call into C-level TVMFFIFunctionCell

## TL;DR
- The `FunctionObj::call` C++ field is replaced by `TVMFFIFunctionCell::cpp_call` (`void*`), moving the C++ fast-path entry point into the C ABI struct so it is visible/settable from any language.
- `ImportedFunctionObjImpl` and the `RedirectCallToSafeCall` CRTP helper are removed. Cross-DLL import is no longer a separate concern; `cpp_call = nullptr` naturally forces the safe-call path.
- `ExternCFunctionObjNullHandleImpl` is added to optimize the common case of raw C function pointers (no closure handle, no deleter).
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro signature gains `const` on the `args` parameter, matching `TVMFFISafeCallType`.

## Key Exports

```python
# --- C ABI layer (c_api.h) ---

class TVMFFIFunctionCell:
    """C-level function cell accessible from any language binding."""
    safe_call: TVMFFISafeCallType  # C ABI entry: (handle, args, num_args, result) -> int
    cpp_call: void_ptr             # NEW: C++ fast-path entry (same sig as FCall but void*); NULL for non-C++ functions
    # Invariant: cpp_call is NULL for functions not originally created in C++
    # Invariant: when non-NULL, cpp_call has signature void(const FunctionObj*, const AnyView*, int32, Any*)
    # Interacts with: FunctionObj.CallPacked (reads cpp_call), FunctionObjImpl (sets cpp_call)

# --- C++ layer (function.h) ---

class FunctionObj(Object, TVMFFIFunctionCell):
    """Backing object for type-erased functions."""
    # OLD: call: FCall  -- REMOVED
    # NEW: uses TVMFFIFunctionCell::cpp_call (via using declaration)
    # Interacts with: Function (ref wrapper), global registry

    # OLD: SafeCall was protected static, wrapping self->call
    # NEW: SafeCall moved into FunctionObjImpl (each subclass provides its own)

    def CallPacked(self, args: AnyView_array, num_args: int32, result: Any) -> None:
        # NEW: branchless select between cpp_call and CppCallDedirectToSafeCall
        call_ptr = reinterpret_cast[FCall](self.cpp_call) if self.cpp_call else CppCallDedirectToSafeCall
        call_ptr(self, args, num_args, result)
        # Invariant: if cpp_call is NULL, falls back to safe_call via CppCallDedirectToSafeCall
        # Interacts with: CppCallDedirectToSafeCall (private), TVM_FFI_CHECK_SAFE_CALL

class FunctionObjImpl(Generic[TCallable], FunctionObj):
    """Wraps a C++ callable into FunctionObj."""
    # OLD: call = Call, safe_call = FunctionObj::SafeCall
    # NEW: cpp_call = CppCall, safe_call = SafeCall (SafeCall moved here from FunctionObj)
    # Interacts with: Function.FromPacked, Function.FromTyped

class ExternCFunctionObjNullHandleImpl(FunctionObj):
    """NEW: Optimized wrapper for raw C function pointers with no closure handle."""
    # cpp_call = nullptr (always uses safe_call path)
    # No self_, no deleter_ overhead
    # Interacts with: Function.FromExternC (when self==nullptr && deleter==nullptr)

class ExternCFunctionObjImpl(FunctionObj):
    """Wraps a C-style callback with closure handle and deleter."""
    # OLD: inherited RedirectCallToSafeCall CRTP helper
    # NEW: standalone SafeCall, cpp_call = nullptr
    # Interacts with: Function.FromExternC

# REMOVED: ImportedFunctionObjImpl -- cross-DLL import no longer needed as separate class
# REMOVED: RedirectCallToSafeCall<Derived> -- CRTP helper replaced by direct cpp_call=nullptr pattern
# REMOVED: Function::ImportFromExternDLL -- method removed entirely

class Function(ObjectRef):
    @staticmethod
    def FromExternC(self_handle: void_ptr, safe_call: TVMFFISafeCallType,
                    deleter: Callable) -> Function:
        # NEW: dispatches to ExternCFunctionObjNullHandleImpl when self==nullptr && deleter==nullptr
        # Otherwise uses ExternCFunctionObjImpl as before
        ...

# Macro change:
# TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)
# OLD: int __tvm_ffi_##ExportName(void* self, TVMFFIAny* args, int32_t num_args, TVMFFIAny* result)
# NEW: int __tvm_ffi_##ExportName(void* self, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result)
#                                               ^^^^^
# Interacts with: Module system (symbol lookup via __tvm_ffi_ prefix)
```

## Impact
- API: `Function::ImportFromExternDLL` is removed. Callers that used this to safely import functions across DLL boundaries must use `Function::FromExternC` instead (which now handles the null-handle case natively). The `TVM_FFI_DLL_EXPORT_TYPED_FUNC` generated symbol signature adds `const` to `args`, which is ABI-compatible (callers already pass const data).
- Behavioral: `CallPacked` now uses a conditional (branchless select) instead of a direct function pointer dereference. Functions with `cpp_call = nullptr` (C-origin functions) go through `CppCallDedirectToSafeCall` which calls `safe_call` and checks the return code via `TVM_FFI_CHECK_SAFE_CALL`.
- Flags/config: none
- Data formats/schemas: `TVMFFIFunctionCell` grows by one pointer (`cpp_call`), changing the in-memory layout of all `FunctionObj` instances.

Design elements this commit produces/mutates:
- **Mutates** `TVMFFIFunctionCell`: adds `cpp_call` field (was `safe_call` only)
- **Mutates** `FunctionObj`: replaces `call` field with `using TVMFFIFunctionCell::cpp_call`; `CallPacked` now uses branchless select; `SafeCall` moved from `FunctionObj` (protected) into `FunctionObjImpl` (private)
- **Produces** `ExternCFunctionObjNullHandleImpl`: new lightweight subclass for null-handle C callbacks
- **Removes** `ImportedFunctionObjImpl`: cross-DLL import wrapper
- **Removes** `RedirectCallToSafeCall<Derived>`: CRTP helper for redirecting `call` to `safe_call`
- **Removes** `Function::ImportFromExternDLL`: static method
- **Mutates** `TVM_FFI_DLL_EXPORT_TYPED_FUNC`: adds `const` to args parameter

## Usage Examples
Creating a `Function` from a raw C function pointer (new null-handle path), from the test added in this commit:
```cpp
// Define a simple typed function
int testing_add1(int x) { return x + 1; }

// Export as C symbol via the macro (note: args is now const)
TVM_FFI_DLL_EXPORT_TYPED_FUNC(testing_add1, testing_add1);

// Create Function from the exported C symbol — no closure handle, no deleter
Function fadd1 = Function::FromExternC(nullptr, __tvm_ffi_testing_add1, nullptr);
// This creates ExternCFunctionObjNullHandleImpl (cpp_call = nullptr)
// CallPacked will route through safe_call via CppCallDedirectToSafeCall
int result = fadd1(1).cast<int>();  // result == 2
```
