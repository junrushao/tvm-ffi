# Clarify Function ABI by adding cpp_call pointer to TVMFFIFunctionCell

## TL;DR
- Adds `void* cpp_call` field to `TVMFFIFunctionCell` (C ABI struct), storing an optional direct C++ call pointer alongside the mandatory `safe_call` for cross-FFI-boundary calls.
- Removes `FunctionObj::call` member and `RedirectCallToSafeCall` CRTP base. `CallPacked` now branches: if `cpp_call` is set, cast and call directly; otherwise redirect through `safe_call` via `CppCallDedirectToSafeCall`.
- Removes `ImportedFunctionObjImpl` (was a thin `safe_call` redirector). Adds `ExternCFunctionObjNullHandleImpl` for raw C callbacks where handle and deleter are null.
- `FunctionObjImpl` sets `cpp_call` to its `CppCall` static method and `safe_call` to a wrapper that catches C++ exceptions.

## Key Exports

**Struct change** (`TVMFFIFunctionCell`):
```c
typedef struct {
  TVMFFISafeCallType safe_call;  // mandatory, exception-safe C call
  void* cpp_call;                 // optional, direct C++ call (NULL for non-C++ functions)
} TVMFFIFunctionCell;
```

**Classes removed**:
- `RedirectCallToSafeCall<Derived>` -- CRTP base eliminated
- `ImportedFunctionObjImpl` -- removed, functionality subsumed by `ExternCFunctionObjNullHandleImpl`

**Classes added**:
- `ExternCFunctionObjNullHandleImpl` -- for raw C function pointers with null handle/deleter, sets `cpp_call = nullptr`

**Methods changed**:
- `FunctionObj::CallPacked` -- now uses conditional: `cpp_call ? (FCall)cpp_call : CppCallDedirectToSafeCall`

## Impact
- API: `FunctionObj::call` member removed. Code accessing `func->call` must use `func->CallPacked()` instead.
- ABI: **Breaking**. `TVMFFIFunctionCell` gains `cpp_call` field. `FunctionObj` layout changes.
- Behavioral: Functions created in C++ have a direct call fast-path via `cpp_call`; functions from external C callbacks go through `safe_call` with exception translation.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Function system** (`.knowledge/designs/function-system.md`): `FunctionObj`, `TVMFFIFunctionCell`, packed calling convention
- **C ABI** (`.knowledge/designs/c-abi.md`): `TVMFFISafeCallType`

Design elements this commit produces:
- **Dual-path function call**: `cpp_call` for direct C++ invocation without exception translation overhead, `safe_call` for cross-FFI-boundary calls. This separates the C++ fast path from the C ABI safe path.

## Usage Examples
```cpp
// C++ functions get direct cpp_call:
FunctionObj* func = ...;  // created via FunctionObjImpl
func->CallPacked(args, nargs, &rv);  // uses cpp_call directly

// External C functions go through safe_call:
auto func = make_object<ExternCFunctionObjNullHandleImpl>(my_c_callback);
func->CallPacked(args, nargs, &rv);  // redirects to safe_call
```
