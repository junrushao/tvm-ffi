# Refactor FunctionObj dual-call-pointer layout: replace FCall call field with cpp_call void* in TVMFFIFunctionCell, remove ImportedFunctionObjImpl and ImportFromExternDLL

## TL;DR
- `TVMFFIFunctionCell` gains a new `cpp_call: void*` field (NULL for non-C++ functions); `FunctionObj::call` (typed `FCall` pointer) is removed and its role absorbed into the ABI struct, narrowing the C++/C boundary.
- `CallPacked` now dispatches branchlessly: if `cpp_call != nullptr` cast and call it directly, else fall through to `CppCallDedirectToSafeCall` (which invokes `safe_call`); `ImportedFunctionObjImpl` and `Function::ImportFromExternDLL` are deleted as a consequence.
- `ExternCFunctionObjNullHandleImpl` is introduced for the null-handle path; `TVM_FFI_DLL_EXPORT_TYPED_FUNC` symbol signature gains `const` on `args`; version bumped to 0.1.0b12.

## Key Exports

```python
# --- C ABI (c_api.h) ---

# TVMFFIFunctionCell — MUTATED: cpp_call added
class TVMFFIFunctionCell:
    safe_call: TVMFFISafeCallType   # C ABI boundary: catches exceptions → int return
    cpp_call: void*                 # NEW: ptr to CppCall (typed FCall). NULL for non-C++ functions.
    # Invariant: cpp_call must be NULL for functions not originally created in C++.
    # Invariant: caller must share the same C++ exception ABI when calling cpp_call directly.
    # Interacts with: FunctionObj.CallPacked (dispatches on cpp_call != NULL)

# --- C++ (function.h) ---

class FunctionObj(Object, TVMFFIFunctionCell):
    """Object container backing ffi::Function.
    Layout: TVMFFIObject header | TVMFFIFunctionCell {safe_call, cpp_call} | callable storage
    OLD: also had a separate `call: FCall` field directly in FunctionObj.
    NEW: cpp_call lives in TVMFFIFunctionCell (part of C ABI struct).
    """
    # REMOVED: call: FCall  (was C++-only dispatch field)
    using cpp_call  # from TVMFFIFunctionCell (void*)
    using safe_call  # from TVMFFIFunctionCell

    FCall = Callable[[FunctionObj*, AnyView*, int32_t, Any*], None]

    def CallPacked(self, args: AnyView*, num_args: int32_t, result: Any*) -> None:
        # Branchless conditional expression (no branch, select):
        call_ptr: FCall = (reinterpret_cast[FCall](self.cpp_call)
                           if self.cpp_call else CppCallDedirectToSafeCall)
        call_ptr(self, args, num_args, result)
        # Interacts with: CppCallDedirectToSafeCall (fallback), FunctionObjImpl.CppCall (hot path)

    @staticmethod
    def CppCallDedirectToSafeCall(func: FunctionObj*, args: AnyView*, num_args: int32_t, rv: Any*) -> None:
        # Fallback when cpp_call is NULL: redirect to safe_call, then check error code.
        TVM_FFI_CHECK_SAFE_CALL(func.safe_call(func, args, num_args, rv))
        # Interacts with: TVM_FFI_CHECK_SAFE_CALL macro, ErrorObj TLS slot


class FunctionObjImpl(Generic[TCallable], FunctionObj):
    """Most common case: wraps a C++ callable (lambda, functor)."""
    callable_: TCallable

    def __init__(self, callable: TCallable):
        self.safe_call = SafeCall
        self.cpp_call = reinterpret_cast[void*](CppCall)  # was: self.call = Call

    @staticmethod
    def CppCall(func: FunctionObj*, args: AnyView*, num_args: int32_t, result: Any*) -> None:
        # was: Call(...)
        cast[FunctionObjImpl](func).callable_(args, num_args, result)

    @staticmethod
    def SafeCall(handle: void*, args: TVMFFIAny*, num_args: int32_t, result: TVMFFIAny*) -> int:
        # NOW calls cpp_call via cast (was: called self.call directly)
        TVM_FFI_SAFE_CALL_BEGIN()
        TVM_FFI_ICHECK_LT(result.type_index, kTVMFFIStaticObjectBegin)
        self = cast[FunctionObj*](handle)
        reinterpret_cast[FCall](self.cpp_call)(self, args, num_args, result)
        TVM_FFI_SAFE_CALL_END()


class ExternCFunctionObjNullHandleImpl(FunctionObj):
    """NEW: Specialization for raw C function pointer with null handle and null deleter."""
    def __init__(self, safe_call: TVMFFISafeCallType):
        self.safe_call = safe_call
        self.cpp_call = nullptr
    # Interacts with: Function.FromExternC (dispatches here when self==nullptr, deleter==nullptr)


class ExternCFunctionObjImpl(FunctionObj):
    """Wraps a C-style callback (from TVMFFIFunctionCreate / FromExternC).
    SIMPLIFIED: no longer inherits RedirectCallToSafeCall CRTP mixin.
    Deleter guards: if deleter_ is not null, calls it on destruction.
    """
    self_: void*
    safe_call_: TVMFFISafeCallType
    deleter_: Callable[[void*], None]

    def __init__(self, self_: void*, safe_call: TVMFFISafeCallType, deleter: Callable):
        self.safe_call = SafeCall
        self.cpp_call = nullptr  # external C function — no C++ call path

    def __del__(self):
        if self.deleter_: self.deleter_(self.self_)  # guard added (was unconditional)

    @staticmethod
    def SafeCall(handle: void*, args: TVMFFIAny*, num_args: int32_t, rv: TVMFFIAny*) -> int:
        self = reinterpret_cast[ExternCFunctionObjImpl*](handle)
        return self.safe_call_(self.self_, args, num_args, rv)


# REMOVED: class RedirectCallToSafeCall(Generic[Derived])  — CRTP helper base
# REMOVED: class ImportedFunctionObjImpl  — wrapped cross-DLL FunctionObj via safe_call
# REMOVED: Function.ImportFromExternDLL(other: Function) -> Function


class Function(ObjectRef):
    @staticmethod
    def FromExternC(self: void*, safe_call: TVMFFISafeCallType,
                    deleter: Callable[[void*], None]) -> Function:
        # NEW dispatch: if self==nullptr and deleter==nullptr → ExternCFunctionObjNullHandleImpl
        #               otherwise → ExternCFunctionObjImpl (unchanged behaviour)
        # Interacts with: ExternCFunctionObjNullHandleImpl, ExternCFunctionObjImpl


# TVM_FFI_DLL_EXPORT_TYPED_FUNC — SIGNATURE FIX
# Old: int __tvm_ffi_##ExportName(void* self, TVMFFIAny* args, ...)
# New: int __tvm_ffi_##ExportName(void* self, const TVMFFIAny* args, ...)
#      — adds const to args pointer, matches TVMFFISafeCallType convention
```

## Impact
- API: `Function::ImportFromExternDLL` removed. Any caller relying on it must migrate to `FromExternC(nullptr, safe_call, nullptr)` or pass the function directly (cross-DLL safety is now handled by `CppCallDedirectToSafeCall` fallback). `FunctionObj::call` removed from C++ public interface; callers that set `this->call` directly must use `this->cpp_call = reinterpret_cast<void*>(fn)` instead.
- Behavioral: `CallPacked` now uses a conditional expression (branchless select) instead of unconditional call through `call` pointer. When `cpp_call == nullptr`, execution goes through `safe_call` + error-code check, which is slightly slower but semantically equivalent. For `FunctionObjImpl` (the common case), `cpp_call` is always set, so there is no hot-path regression.
- Flags/config: none
- Data formats/schemas: `TVMFFIFunctionCell` ABI struct gains `cpp_call: void*` field — this is a binary ABI change. Any pre-compiled binary loading a `TVMFFIFunctionCell` must be rebuilt. Version bumped 0.1.0b11 → 0.1.0b12.

## Usage Examples

**Context**: Using `TVM_FFI_DLL_EXPORT_TYPED_FUNC` and `Function::FromExternC` with a null handle (new path added in this commit).

```cpp
// Define a typed function and export it with the C ABI macro:
int testing_add1(int x) { return x + 1; }
TVM_FFI_DLL_EXPORT_TYPED_FUNC(testing_add1, testing_add1);
// Generates: extern "C" int __tvm_ffi_testing_add1(void*, const TVMFFIAny*, int32_t, TVMFFIAny*)

// Create a Function from the exported symbol using null handle (new ExternCFunctionObjNullHandleImpl path):
Function fadd1 = Function::FromExternC(nullptr, __tvm_ffi_testing_add1, nullptr);
// Internal: dispatches to ExternCFunctionObjNullHandleImpl (cpp_call = nullptr)
//           CallPacked → CppCallDedirectToSafeCall → safe_call = __tvm_ffi_testing_add1

int result = fadd1(1).cast<int>();   // == 2
```

**Before/After for cross-DLL function wrapping (removed API)**:
```cpp
// BEFORE (removed in this commit):
Function imported = Function::ImportFromExternDLL(other_func);
// detected same-DLL and returned as-is, or wrapped in ImportedFunctionObjImpl

// AFTER: no wrapping needed; cpp_call=nullptr functions always redirect through safe_call.
// Cross-DLL calls: just pass the Function directly. The fallback path handles it.
Function imported = other_func;   // or Function::FromExternC(handle, safe_call, deleter)
```
