# Skip expensive imports in tvm_ffi.__init__ when running tvm-ffi-config CLI

## TL;DR
- Adds `_is_config_mode()` to `__init__.py` that detects `tvm-ffi-config` CLI entry or `python -m tvm_ffi.config` invocation via `sys.argv`/`sys.orig_argv`.
- Wraps all heavy imports under `if TYPE_CHECKING or not _is_config_mode()`, allowing the config CLI to start without loading the native library.

## Impact
- API: none
- Behavioral: `tvm-ffi-config` CLI no longer triggers native library loading, reducing startup time and avoiding DLL issues on non-GPU systems.
