# Skip imports in config mode to reduce CLI startup overhead
## TL;DR
- Refactors `tvm_ffi/__init__.py` to skip heavy Cython/C library imports when running as `tvm-ffi-config` CLI, reducing startup overhead.
- Adds `_is_config_mode()` detection checking `sys.argv` and `sys.orig_argv`.
- Guards all heavy imports behind `if TYPE_CHECKING or not _is_config_mode()`.
