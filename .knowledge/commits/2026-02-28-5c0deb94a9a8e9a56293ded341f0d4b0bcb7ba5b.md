# Skip imports in config mode to reduce dependency and startup time

## TL;DR
- Detects config mode in `tvm_ffi/__init__.py` and skips heavy imports (Cython extension, containers, etc.), reducing startup time and dependency requirements when only `tvm_ffi.config` is needed.

None (internal optimization)

## Impact
- API: none
- Behavioral: `tvm_ffi` module loads faster when used in config-only mode.
