# Skip all heavy tvm_ffi imports when invoked as the tvm-ffi-config CLI entry point

## TL;DR
- Adds `_is_config_mode()` detection function that checks `sys.argv[0]` and `sys.orig_argv` for `tvm-ffi-config` / `-m tvm_ffi.config` invocation patterns.
- Wraps all eager `tvm_ffi/__init__.py` imports in `if TYPE_CHECKING or not _is_config_mode()` guard so the entire FFI stack (libinfo, Cython, containers, etc.) is skipped in config CLI mode.
- `TYPE_CHECKING` branch ensures static type checkers and IDEs still see all symbols.

## Key Exports

```python
# python/tvm_ffi/__init__.py

def _is_config_mode() -> bool:
    """Detect if tvm_ffi is being loaded as part of tvm-ffi-config CLI.
    # Interacts with: sys.argv, sys.orig_argv (Python 3.10+)
    # Invariant: returns True if argv[0] ends with 'tvm-ffi-config' OR orig_argv contains '-m tvm_ffi.config'
    # Invariant: falls back gracefully when sys.orig_argv is absent (Python < 3.10)
    """
    ...

# Guard pattern applied to all package-level imports:
if TYPE_CHECKING or not _is_config_mode():
    from . import libinfo
    LIB = libinfo.load_lib_ctypes("apache-tvm-ffi", "tvm_ffi", "RTLD_GLOBAL")
    # ... all remaining imports ...
```

## Impact
- API: No public API changes; `tvm_ffi` symbols remain the same in normal import mode.
- Behavioral: In config mode, `import tvm_ffi` will NOT load `libtvm_ffi`, NOT import Cython/ctypes bindings, NOT initialize the FFI. Accessing any `tvm_ffi` symbol (other than `__version__`) in config mode will raise `NameError`. This is an intentional design decision.
- Flags/config: `tvm-ffi-config` CLI entry point and `-m tvm_ffi.config` module invocation are the triggers.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `0013-python-package`: modifies the four-stage import protocol in `__init__.py`; `LIB = libinfo.load_lib_ctypes(...)` is now conditional.

Design elements this commit produces:
- Config-mode import guard pattern: `if TYPE_CHECKING or not _is_config_mode()` in `__init__.py` — new convention for lazy-import gating in CLI entry points.
- `_is_config_mode()`: internal detection helper with `sys.orig_argv` fallback for Python < 3.10.

## Usage Examples

Before (all imports always run):
```python
# tvm_ffi/__init__.py — always loads libtvm_ffi, Cython, etc.
from . import libinfo
LIB = libinfo.load_lib_ctypes("apache-tvm-ffi", "tvm_ffi", "RTLD_GLOBAL")
```

After (config mode skips all heavy imports):
```python
# tvm_ffi/__init__.py
if TYPE_CHECKING or not _is_config_mode():
    from . import libinfo
    LIB = libinfo.load_lib_ctypes("apache-tvm-ffi", "tvm_ffi", "RTLD_GLOBAL")
    from .core import Object, Function
    # ... all other imports ...
```
