# Bump torch_c_dlpack_ext to 0.1.2 with -O3 build optimization
## TL;DR
- Version bump of `torch_c_dlpack_ext` addon from 0.1.1 to 0.1.2.
- Ninja build default compiler flags changed from `-O2` to `-O3` on non-Windows platforms, aligning with the AOT build optimization level.
- `CurrentWorkStream` method reordered within `TorchDLPackExchangeAPI` struct (no semantic change).
