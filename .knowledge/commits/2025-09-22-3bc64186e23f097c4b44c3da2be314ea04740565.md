# Enable Doxygen build checks in CI and fix Doxygen warnings in C++ headers
## TL;DR
- Enables `BUILD_CPP_DOCS=1` and installs Doxygen in the CI doc-build job so C++ API docs are validated on every PR.
- Fixes Doxygen warnings in `c_api.h`, `map.h`, `tensor.h`, `access_path.h`, and `registry.h` (missing/extra `\return` tags, unmatched `\endcond`, deleted template specialization).
- Updates `docs/conf.py` to add `TVM_FFI_DOXYGEN_MODE` predefined macro, `WARN_AS_ERROR`, and `cpp_id_attributes`/`c_id_attributes` lists so Sphinx/Breathe/Exhale correctly parse TVM FFI macros.

N/A -- infrastructure

## Impact
- API: none -- all header changes are doc-comment-only or `#ifdef TVM_FFI_DOXYGEN_MODE` guards that compile away.
- Behavioral: none
- Flags/config: New `TVM_FFI_DOXYGEN_MODE` preprocessor macro defined only during Doxygen parsing; guards anonymous unions in `TVMFFIObject` and `TVMFFIAny` so Doxygen can parse them. `BUILD_CPP_DOCS=1` environment variable now set in CI.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- C ABI structs `TVMFFIObject`, `TVMFFIAny` (0007-c-abi) -- union members now have individual `\brief` doc comments and are wrapped in `#if !defined(TVM_FFI_DOXYGEN_MODE)` guards.
- `MapObj` deleted `make_object<>()` specialization (0006-containers) -- wrapped in `\cond Doxygen_Suppress` to hide from Doxygen.
- Reflection `AccessStep` constructor and `AttachFieldFlag` constructor (0008-reflection) -- removed erroneous `\return` Doxygen tags.

Design elements this commit produces: none -- purely doc/CI infrastructure.
