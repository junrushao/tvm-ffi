# Enable Doxygen build checks in CI and fix doc-generation warnings across C++ headers
## TL;DR
- Turns on `BUILD_CPP_DOCS=1` in the CI doc-build step (with `doxygen` apt install), so Doxygen warnings are caught before merge.
- Configures Doxygen `WARN_AS_ERROR` and Sphinx `cpp_id_attributes`/`c_id_attributes` in `docs/conf.py` to suppress false positives from TVM FFI macros.
- Introduces `TVM_FFI_DOXYGEN_MODE` preprocessor guard in `c_api.h` to hide anonymous unions from Doxygen, and fixes several Doxygen comment errors across headers (`\return` on constructors, stray `\endcond`, missing `\endcode`).

## Key Exports
**Macros**:
- `TVM_FFI_DOXYGEN_MODE` — new preprocessor symbol. Never defined at compile time; only defined via Doxygen's `PREDEFINED` list. Guards anonymous unions in `TVMFFIObject` and `TVMFFIAny` so Doxygen sees plain fields instead of unparseable anonymous union syntax.

**Config surfaces**:
- `docs/conf.py::cpp_id_attributes` — new list: `["TVM_FFI_DLL", "TVM_FFI_DLL_EXPORT", "TVM_FFI_INLINE", "TVM_FFI_EXTRA_CXX_API", "TVM_FFI_WEAK"]`. Tells Sphinx's C++ domain to treat these tokens as attributes (not types), preventing parse failures on decorated declarations.
- `docs/conf.py::c_id_attributes` — new list: `["TVM_FFI_DLL", "TVM_FFI_DLL_EXPORT", "TVM_FFI_WEAK"]`. Same purpose for Sphinx's C domain.
- `exhaleDoxygenStdin` additions: `TVM_FFI_DLL_EXPORT=`, `TVM_FFI_WEAK=`, `TVM_FFI_DOXYGEN_MODE` added to `PREDEFINED`; `WARNINGS=YES` and `WARN_AS_ERROR=FAIL_ON_WARNINGS_PRINT` added.

## Impact
- API: None — no runtime API changes.
- Behavioral: None — all changes are doc-build-only; `TVM_FFI_DOXYGEN_MODE` is never defined during actual compilation.
- Flags/config: `BUILD_CPP_DOCS=1` is now set in CI `ci_test.yml` doc-build step. Doxygen warnings are now fatal in the doc pipeline.
- Data formats/schemas: None.

Design elements this commit produces:
- **`TVM_FFI_DOXYGEN_MODE` guard pattern** — a convention for hiding C constructs that Doxygen cannot parse (anonymous unions) behind `#if !defined(TVM_FFI_DOXYGEN_MODE)`. Any future C header additions with anonymous unions or other Doxygen-incompatible syntax should use this guard.
- **`cpp_id_attributes`/`c_id_attributes` Sphinx config** — the canonical list of TVM FFI macros that Sphinx must treat as declaration attributes. Must be updated when new DLL-export or linkage macros are added.
