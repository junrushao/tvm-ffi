# Enable Doxygen build checks in CI and fix Doxygen warnings in C++ headers
## TL;DR
- CI now installs Doxygen and runs `BUILD_CPP_DOCS=1` during the doc build step, catching C++ doc errors before merge.
- `docs/conf.py` updated: new `TVM_FFI_DOXYGEN_MODE` predefined macro, `WARN_AS_ERROR` enabled, `cpp_id_attributes`/`c_id_attributes` lists added for Sphinx C/C++ domain.
- C++ headers (`c_api.h`, `map.h`, `tensor.h`, `access_path.h`, `registry.h`) patched to suppress Doxygen-unparseable anonymous unions via `#if !defined(TVM_FFI_DOXYGEN_MODE)` guards and fix stray/missing doc comment tags.

- Behavioral: none -- all C++ changes are `#ifdef`-guarded for Doxygen only; runtime code is identical.
- Flags/config: `BUILD_CPP_DOCS=1` environment variable now set in CI doc job; `TVM_FFI_DOXYGEN_MODE` macro added to Doxygen `PREDEFINED` list.
