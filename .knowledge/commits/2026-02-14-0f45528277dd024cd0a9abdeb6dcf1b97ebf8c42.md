# Suppress GCC -Warray-bounds false positive in String::Concat
## TL;DR
- Adds `__attribute__((noinline))` to `String::Concat` to prevent GCC from emitting false `-Warray-bounds` warnings when the function is inlined into downstream callers. Single line addition in `string.h`.
