# Add -Warray-bounds suppression to GCC diagnostic block in String::Concat

## TL;DR
- GCC emits a false-positive `-Warray-bounds` on `std::memcpy(dest_data + lhs_size, rhs, rhs_size)` inside `String::Concat` when the function is inlined across call sites where the compiler cannot statically see the small-string guard.
- Adds `#pragma GCC diagnostic ignored "-Warray-bounds"` to the existing `#if (__GNUC__) && !(__clang__)` suppression block (which already suppressed `-Wstringop-overflow` and `-Wrestrict` for the same reason).
- No API, ABI, or behavioral change; the fix is diagnostic-only and scoped to GCC (Clang already excluded).
