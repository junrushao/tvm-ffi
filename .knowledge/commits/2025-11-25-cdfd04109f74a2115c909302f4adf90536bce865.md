# Add CUDA `DeviceGuard` and `base.h` with `TVM_FFI_CHECK_CUDA_ERROR` macro

## TL;DR
- Adds `include/tvm/ffi/extra/cuda/base.h`: shared CUDA base utilities header defining `TVM_FFI_CHECK_CUDA_ERROR` macro that throws `RuntimeError` on CUDA API failures.
- Adds `include/tvm/ffi/extra/cuda/device_guard.h`: `CUDADeviceGuard` RAII struct for safe CUDA device switching across function calls.
- Minor cleanup in `cubin_launcher.h`: moves `TVM_FFI_CHECK_CUDA_ERROR` definition to `base.h` and includes it there (companion to `d49effdb2239`).

## Key Exports

```python
# include/tvm/ffi/extra/cuda/base.h

# Macro: TVM_FFI_CHECK_CUDA_ERROR(stmt)
# Checks CUDA runtime API return value; throws RuntimeError on failure
# Usage: TVM_FFI_CHECK_CUDA_ERROR(cudaMalloc(&ptr, size));
# Interacts with: TVM_FFI_THROW(RuntimeError), cudaGetErrorName, cudaGetErrorString

# include/tvm/ffi/extra/cuda/device_guard.h

class CUDADeviceGuard:
    """RAII guard: switches to target CUDA device on construction, restores on destruction."""
    # Invariant: only switches device if target != original (avoids no-op cudaSetDevice calls)
    # Invariant: destructor is noexcept(false) — CUDA errors in restore propagate as exceptions

    def __init__(self, device_index: int) -> None:
        """Saves current device via cudaGetDevice; switches to device_index."""
        # Interacts with: TVM_FFI_CHECK_CUDA_ERROR, cudaGetDevice, cudaSetDevice

    def __del__(self) -> None:
        """Restores original device if it differs from target_device_index_."""
```

## Usage Examples

```cpp
#include <tvm/ffi/extra/cuda/device_guard.h>

void kernel(ffi::TensorView x) {
    ffi::CUDADeviceGuard guard(x.device().device_id);
    // all CUDA API calls here execute on x's device
    // original device restored when guard goes out of scope
}
```
