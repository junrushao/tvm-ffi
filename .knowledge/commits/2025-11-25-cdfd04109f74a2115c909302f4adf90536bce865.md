# Add CUDA DeviceGuard for automatic device context management
## TL;DR
- Adds `include/tvm/ffi/extra/cuda/device_guard.h` with `DeviceGuard` RAII class (similar to `c10::cuda::CUDAGuard`).
- Adds `include/tvm/ffi/extra/cuda/base.h` with common CUDA error-checking macros and `cuDeviceGet`/`cuCtxSetCurrent` wrappers.
- Refactors `cubin_launcher.h` to use the shared `base.h` instead of inline CUDA utilities.

## Key Exports

```python
class DeviceGuard:
    """RAII guard that sets CUDA device context and restores on destruction."""
    def __init__(self, device_id: int): ...
    # Interacts with: cuDeviceGet, cuDevicePrimaryCtxRetain, cuCtxSetCurrent
    # Invariant: restores previous CUDA context on destruction
    # Extension: similar pattern to c10::cuda::CUDAGuard

# Error-checking macros in base.h:
# TVM_FFI_CHECK_CUDA_DRIVER_ERROR(result) — asserts CUresult == CUDA_SUCCESS
# TVM_FFI_CHECK_CUDA_RUNTIME_ERROR(result) — asserts cudaError_t == cudaSuccess
# Interacts with: TVM_FFI_THROW (0004-error-propagation)
```

## Impact
- API: new headers `tvm/ffi/extra/cuda/device_guard.h` and `tvm/ffi/extra/cuda/base.h` (additive)
- Behavioral: provides RAII device context management for multi-GPU kernel dispatch
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cpp
#include <tvm/ffi/extra/cuda/device_guard.h>

void LaunchOnDevice(int device_id, tvm::ffi::TensorView x) {
  tvm::ffi::DeviceGuard guard(device_id);
  // All CUDA operations here run on device_id
  // Original context restored when guard goes out of scope
}
```
