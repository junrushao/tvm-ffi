# Add CUDA DeviceGuard utility header
## TL;DR
- Adds `include/tvm/ffi/extra/cuda/device_guard.h` providing RAII-style `DeviceGuard` for setting and restoring CUDA device context.
- Extracts common CUDA utilities into `include/tvm/ffi/extra/cuda/base.h`.
- Refactors `cubin_launcher.h` to use shared `base.h` utilities.

## Key Exports

**C++ Classes:**
- `DeviceGuard` -- RAII class that sets CUDA device on construction and restores the previous device on destruction. Similar to `c10::cuda::CUDAGuard` in PyTorch.
- `base.h` utilities -- `CUDA_CALL` macro, `GetDeviceCount()`, `GetCurrentDevice()` functions.

## Impact
- API: New `DeviceGuard` class and CUDA base utilities.
- ABI: none (header-only)
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cpp
#include <tvm/ffi/extra/cuda/device_guard.h>
{
  tvm::ffi::extra::DeviceGuard guard(device_id);
  // ... CUDA operations on device_id ...
}  // device restored automatically
```
