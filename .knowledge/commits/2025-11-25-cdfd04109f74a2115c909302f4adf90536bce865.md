# Add CUDADeviceGuard and extract CUDA base utilities header
## TL;DR
- Adds `CUDADeviceGuard` RAII struct in `include/tvm/ffi/extra/cuda/device_guard.h` -- saves/restores the current CUDA device on construction/destruction, analogous to PyTorch's `c10::cuda::CUDAGuard`.
- Extracts `TVM_FFI_CHECK_CUDA_ERROR` macro from `cubin_launcher.h` into a new shared header `include/tvm/ffi/extra/cuda/base.h`.
- Fixes header guard naming in `cubin_launcher.h` (`TVM_FFI_EXTRA_CUBIN_LAUNCHER_H_` -> `TVM_FFI_EXTRA_CUDA_CUBIN_LAUNCHER_H_`).

## Key Exports

**Types/Classes (C++, `tvm::ffi`)**:

| Type | Key Members | Notes |
|------|-------------|-------|
| `CUDADeviceGuard` | `CUDADeviceGuard(int device_index)` | RAII struct. Constructor calls `cudaGetDevice` + `cudaSetDevice`. Destructor restores original device. Default-constructor deleted. Non-copyable by convention (no explicit delete, but RAII semantics). Destructor is `noexcept(false)` (can throw via `TVM_FFI_CHECK_CUDA_ERROR`). |

**Macros (moved)**:

| Macro | Change |
|-------|--------|
| `TVM_FFI_CHECK_CUDA_ERROR` | Relocated from `cubin_launcher.h` to `base.h`. No signature change. |

## Impact
- API: New public header `extra/cuda/device_guard.h`. New shared header `extra/cuda/base.h`. `cubin_launcher.h` now includes `base.h` instead of defining `TVM_FFI_CHECK_CUDA_ERROR` inline.
- Behavioral: None. `cubin_launcher.h` users see no change since `base.h` is included transitively.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

- **Error handling** ([0006-error-handling.md](../designs/0006-error-handling.md)): `TVM_FFI_THROW(RuntimeError)` used in both `TVM_FFI_CHECK_CUDA_ERROR` and `CUDADeviceGuard`.
- **Extra API isolation** ([ADR 0010](../ADRs/0010-extra-api-isolation.md)): All new headers under `include/tvm/ffi/extra/cuda/`.
- **CUBIN launcher** (from d49effd): Refactored to include `base.h`.

Design elements this commit produces:
- **CUDA base header** (new): Shared `extra/cuda/base.h` providing `TVM_FFI_CHECK_CUDA_ERROR` for all CUDA utility headers.
- **CUDADeviceGuard** (new): RAII device-switching guard for multi-GPU kernels.

## Usage Examples

```cpp
#include <tvm/ffi/extra/cuda/device_guard.h>

void kernel(tvm::ffi::TensorView x) {
  tvm::ffi::CUDADeviceGuard guard(x.device().device_id);
  // CUDA operations now target x's device
  // Original device is restored when guard goes out of scope
}
```
