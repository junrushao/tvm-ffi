# Add CUDA DeviceGuard RAII struct and extract shared CUDA base header
## TL;DR
- Adds `CUDADeviceGuard`, a RAII struct that saves/restores the active CUDA device index on construction/destruction, modeled after PyTorch's `c10::cuda::CUDAGuard`.
- Extracts the `TVM_FFI_CHECK_CUDA_ERROR` macro from `cubin_launcher.h` into a new shared header `tvm/ffi/extra/cuda/base.h` so both `device_guard.h` and `cubin_launcher.h` can use it without duplication.
- Fixes `cubin_launcher.h` header guard from `TVM_FFI_EXTRA_CUBIN_LAUNCHER_H_` to `TVM_FFI_EXTRA_CUDA_CUBIN_LAUNCHER_H_` to match the file path convention.

## Key Exports

```python
# -- include/tvm/ffi/extra/cuda/base.h --

# Macro: TVM_FFI_CHECK_CUDA_ERROR(stmt)
# Checks cudaError_t return value; throws RuntimeError with error name + description on failure.
# Interacts with: TVM_FFI_THROW(RuntimeError) from tvm/ffi/error.h
# Interacts with: cudaGetErrorName(), cudaGetErrorString() from CUDA runtime
# Extension: Use in any CUDA runtime API call site to get uniform error reporting.

# -- include/tvm/ffi/extra/cuda/device_guard.h --

class CUDADeviceGuard:
    """RAII guard that switches the active CUDA device and restores the original on destruction."""
    # Invariant: original_device_index_ is captured via cudaGetDevice at construction time.
    # Invariant: cudaSetDevice is only called if target differs from original (no-op optimization).
    # Invariant: destructor is noexcept(false) -- TVM_FFI_CHECK_CUDA_ERROR may throw on restore failure.
    # Interacts with: TVM_FFI_CHECK_CUDA_ERROR (from base.h)
    # Interacts with: cudaGetDevice, cudaSetDevice (CUDA runtime)
    # Extension: Instantiate at function scope before any CUDA kernel launch on a specific device.

    def __init__(self, device_index: int) -> None: ...
    # deleted default constructor -- device_index is required
```

## Impact
- API: Adds two new public headers (`base.h`, `device_guard.h`) under `include/tvm/ffi/extra/cuda/`. No existing API signatures changed.
- Behavioral: `TVM_FFI_CHECK_CUDA_ERROR` is now defined in `base.h` instead of `cubin_launcher.h`. Downstream code that included `cubin_launcher.h` solely for the macro will still compile (it includes `base.h`). Code that forward-declared or copy-pasted the macro should migrate.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Error system** (`TVM_FFI_THROW`): Used by `TVM_FFI_CHECK_CUDA_ERROR` to throw `RuntimeError`. See `.knowledge/designs/0005-error-system.md`.
- **CUDA extra header convention** (`include/tvm/ffi/extra/cuda/`): Pre-existing directory structure for optional CUDA utilities.

Design elements this commit produces:
- **CUDADeviceGuard**: New RAII device-switching primitive for multi-GPU scenarios. No existing knowledge doc.
- **`base.h` shared CUDA utilities header**: Establishes a pattern for shared CUDA macros/utilities separate from specific launcher or guard headers.

## Usage Examples
From the Doxygen example in the header:

```cpp
#include <tvm/ffi/extra/cuda/device_guard.h>

void kernel(ffi::TensorView x) {
  // Guard switches to the device that owns tensor x;
  // original device is restored when guard goes out of scope.
  ffi::CUDADeviceGuard guard(x.device().device_id);
  // ... launch CUDA kernels on x.device() ...
}
```
