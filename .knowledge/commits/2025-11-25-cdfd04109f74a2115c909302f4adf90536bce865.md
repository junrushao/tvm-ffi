# Add CUDA DeviceGuard RAII struct and extract shared CUDA error-check macro to base.h

## TL;DR
- Adds `CUDADeviceGuard`, an RAII struct that saves/restores the current CUDA device index around a scope (analogous to PyTorch's `c10::cuda::CUDAGuard`).
- Extracts the `TVM_FFI_CHECK_CUDA_ERROR` macro from `cubin_launcher.h` into a new shared header `tvm/ffi/extra/cuda/base.h` so it can be reused by `device_guard.h` and future CUDA utilities.
- Fixes the header guard in `cubin_launcher.h` from `TVM_FFI_EXTRA_CUBIN_LAUNCHER_H_` to `TVM_FFI_EXTRA_CUDA_CUBIN_LAUNCHER_H_` to match the actual file path.

## Key Exports

```python
# --- tvm/ffi/extra/cuda/base.h ---

# Macro expansion (pseudocode for TVM_FFI_CHECK_CUDA_ERROR):
# if cuda_call() != cudaSuccess:
#     raise RuntimeError(f"CUDA Runtime Error: {name} ({code}): {description}")
# Interacts with: cudaGetErrorName, cudaGetErrorString, TVM_FFI_THROW(RuntimeError)
# Extension: use for any CUDA runtime API call that returns cudaError_t

# --- tvm/ffi/extra/cuda/device_guard.h ---

class CUDADeviceGuard:
    """RAII guard that sets the CUDA device on construction and restores original on destruction."""
    # Invariant: original_device_index_ is always the device index at construction time
    # Invariant: only calls cudaSetDevice if target differs from current (avoids redundant API calls)
    # Interacts with: cudaGetDevice, cudaSetDevice, TVM_FFI_CHECK_CUDA_ERROR
    # Extension: analogous to c10::cuda::CUDAGuard in PyTorch

    def __init__(self, device_index: int) -> None: ...
    # Note: default constructor deleted -- device_index is required
    # Note: destructor is noexcept(false) -- CUDA errors on restore will throw
```

## Impact
- API: Additive only -- new public headers `cuda/base.h` and `cuda/device_guard.h`. Existing `cubin_launcher.h` users are unaffected since `TVM_FFI_CHECK_CUDA_ERROR` is still available via transitive include of `base.h`.
- Behavioral: None -- no change to existing behavior.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Error protocol** (0005): uses `TVM_FFI_THROW(RuntimeError)` for CUDA error reporting.
- **CUDA cubin launcher** (existing `cubin_launcher.h`): the `TVM_FFI_CHECK_CUDA_ERROR` macro originated here and is now shared via `base.h`.

Design elements this commit produces:
- **`CUDADeviceGuard`** (new RAII struct in `tvm/ffi/extra/cuda/device_guard.h`): scoped CUDA device switching with automatic restore.
- **`TVM_FFI_CHECK_CUDA_ERROR`** (extracted to `tvm/ffi/extra/cuda/base.h`): shared CUDA runtime error-checking macro, now reusable across all CUDA extra headers.
- **CUDA extras layering convention**: establishes `base.h` as the shared foundation for `tvm/ffi/extra/cuda/` headers, with higher-level utilities (`cubin_launcher.h`, `device_guard.h`) building on it.

## Usage Examples

From the inline doc in the header -- using `CUDADeviceGuard` with a tensor's device:

```cpp
#include <tvm/ffi/extra/cuda/device_guard.h>

void kernel(ffi::TensorView x) {
  ffi::CUDADeviceGuard guard(x.device().device_id);
  // All CUDA operations here run on x's device
  // ...
}  // Original device automatically restored
```
