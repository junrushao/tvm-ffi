# Add Array __contains__ support via ffi.ArrayContains
## TL;DR
- Adds `ffi.ArrayContains` global function (C++) performing linear search with `AnyEqual` on `ArrayObj`.
- Implements `Array.__contains__` in Python, enabling `value in array` syntax.
- Adds C++ and Python tests.

## Key Exports

**`ffi.ArrayContains`** (global function, `src/ffi/container.cc`):
```cpp
// (const ArrayObj*, const Any&) -> bool
// Uses AnyEqual for element comparison, std::any_of for iteration
```

**`Array.__contains__(self, value) -> bool`** (`python/tvm_ffi/container.py`):
```python
def __contains__(self, value: object) -> bool: ...
```

## Impact
- API: `Array` now supports Python `in` operator. New global function `ffi.ArrayContains`.
- Behavioral: None for existing code.
