# Add array __contains__ support
## TL;DR
- Adds `ffi.ArrayContains` global function that checks membership using `AnyEqual`.
- Wires it to Python `Array.__contains__` for `in` operator support.

## Key Exports

**Global Functions:**
- `ffi.ArrayContains(array, value) -> bool` -- Check if value exists in array.

**Python API:**
- `Array.__contains__(value)` -- Enables `value in array` syntax.

## Impact
- API: New `ArrayContains` global function.
- ABI: none
- Behavioral: Array now supports `in` operator in Python.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Array container
- AnyEqual comparison

Design elements this commit produces: none

## Usage Examples
```python
arr = tvm_ffi.Array([1, 2, 3])
assert 2 in arr
assert 10 not in arr
```
