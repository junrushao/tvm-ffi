# Add `ffi.ArrayContains` FFI function and Python `Array.__contains__` for `in` operator support

## TL;DR
- Registers a new `ffi.ArrayContains` C++ FFI function that performs linear search over `ArrayObj` using `AnyEqual` for element comparison.
- Adds `Array.__contains__` in Python, enabling native `value in array` syntax.
- Includes C++ (GoogleTest) and Python (pytest parametrized) tests covering int/string arrays and empty arrays.

## Usage Examples

**Python `in` operator on Array** (from `tests/python/test_container.py`):
```python
import tvm_ffi

arr = tvm_ffi.convert([1, 2, 3, 4, 5])
assert 3 in arr        # True
assert 10 not in arr   # True

str_arr = tvm_ffi.convert(["hello", "world"])
assert "hello" in str_arr  # True
assert "foo" not in str_arr  # True

empty = tvm_ffi.convert([])
assert 1 not in empty  # True
```

**C++ via packed function** (from `tests/cpp/test_array.cc`):
```cpp
Function f = Function::GetGlobalRequired("ffi.ArrayContains");
Array<int> arr = {1, 2, 3, 4, 5};
EXPECT_TRUE(f(arr, 3).cast<bool>());
EXPECT_FALSE(f(arr, 10).cast<bool>());

Array<String> str_arr = {String("hello"), String("world")};
EXPECT_TRUE(f(str_arr, String("hello")).cast<bool>());
```
