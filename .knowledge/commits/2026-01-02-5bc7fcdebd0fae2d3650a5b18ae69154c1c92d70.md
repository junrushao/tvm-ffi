# Add `__contains__` support to Array via `ffi.ArrayContains` FFI function
## TL;DR
- Adds `ffi.ArrayContains` C++ FFI function that checks element membership using `AnyEqual` and `std::any_of`.
- Implements `Array.__contains__` in Python, delegating to the C++ FFI function, enabling `value in array` syntax.
- Adds C++ and Python tests covering int arrays, string arrays, and empty arrays.

## Usage Examples
**Context**: Using the Python `in` operator on TVM FFI Arrays, tested in both C++ and Python.

```python
import tvm_ffi

# Create an array and test membership
arr = tvm_ffi.convert([1, 2, 3, 4, 5])
assert 3 in arr        # True -- delegates to ffi.ArrayContains
assert 10 not in arr   # True

# Works with string arrays
str_arr = tvm_ffi.convert(["hello", "world"])
assert "hello" in str_arr  # True
assert "foo" not in str_arr  # True

# Empty array always returns False
empty = tvm_ffi.convert([])
assert 1 not in empty  # True
```

```cpp
// C++ usage via global function registry
Function f = Function::GetGlobalRequired("ffi.ArrayContains");
Array<int> arr = {1, 2, 3, 4, 5};
bool found = f(arr, 3).cast<bool>();  // true
```
