# Unify EnvErrorAlreadySet to use error.kind instead of separate exception type
## TL;DR
- Removes the C++ `EnvErrorAlreadySet` exception class, replacing it with `Error("EnvErrorAlreadySet", "", "")` factory function.
- Removes error code `-2` from the ABI; all errors now use code `-1` with TLS error propagation.
- Updates Python bindings to check `error.kind == "EnvErrorAlreadySet"` instead of catching a separate exception or checking return code `-2`.
- Retains backward-compatible handling of `-2` return code with TODO to remove later.

## Impact
- API: removes `EnvErrorAlreadySet` C++ exception class; removes error code `-2` from ABI documentation
- Behavioral: EnvErrorAlreadySet now propagated as a regular Error with kind="EnvErrorAlreadySet" through TLS
- Flags/config: none
- Data formats/schemas: `TVMFFIErrorCell` error code `-2` deprecated (backward compat retained)
