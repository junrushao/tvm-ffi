# Add ROCm backend support for PyTorch tensor conversion
## TL;DR
- Adds ROCm/HIP backend support to torch c dlpack extension and tensor conversion
- Updates `build_backend.py` to detect ROCm and set `USE_ROCM` flag
- Updates `_optional_torch_c_dlpack.py` to handle ROCm device detection
- Adds ROCm tensor conversion tests
