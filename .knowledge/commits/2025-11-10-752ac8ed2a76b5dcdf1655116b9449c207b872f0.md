# Add ROCm backend support to torch tensor conversion in the C DLPack addon

## TL;DR
- Adds `BUILD_WITH_ROCM` conditional compilation path in `_build_optional_torch_c_dlpack.py` and `addons/torch_c_dlpack_ext/build_backend.py`.
- Updates `_optional_torch_c_dlpack.py` to detect ROCm availability and pass the flag.
- Adds test for ROCm tensor conversion in `tests/python/test_optional_torch_c_dlpack.py` and `test_tensor.py`.

## Key Exports

```python
# python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py
# New: build_with_rocm: bool argument / detection logic
# Interacts with: torch.version.hip, torch.cuda.is_available fallback
```

## Impact
- API: none
- Behavioral: `libtorch_c_dlpack_addon` now compiled with `BUILD_WITH_ROCM` on ROCm platforms, enabling tensor conversion on AMD GPUs.
- Flags/config: `BUILD_WITH_ROCM` compiler define; auto-detected from `torch.version.hip`.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: `_build_optional_torch_c_dlpack` build utility (0016-py-ffi-call-dispatch)
Design elements this commit produces: none (existing subsystem extension)

## Usage Examples

```python
# On ROCm system with torch installed with ROCm support:
import tvm_ffi
import torch
t = torch.tensor([1.0]).to("cuda")  # ROCm GPU
tvm_tensor = tvm_ffi.convert(t)  # now works on ROCm
```
