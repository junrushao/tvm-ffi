# Add ROCm backend support for torch tensor DLPack conversion
## TL;DR
- Adds `--build-with-rocm` flag to the torch-c-dlpack JIT build and AOT build scripts, enabling ROCm/HIP-backed tensor conversion alongside the existing CUDA path.
- Detects ROCm via `torch.version.hip` (distinct from `torch.version.cuda`) to choose the correct device name (`"rocm"`) and include paths (`c10/hip/HIPStream.h`).
- Adds mutual exclusion: `--build-with-cuda` and `--build-with-rocm` cannot be used simultaneously.
- Adds ROCm-specific `COMMON_HIP_FLAGS` from `torch.utils.cpp_extension` to compiler flags.
- Adds test `test_tensor_from_pytorch_rocm` verifying that PyTorch "cuda" device maps to TVM FFI `"rocm"` device type.

## Key Exports
**CLI argument** (new):
- `--build-with-rocm` on `_build_optional_torch_c_dlpack.py` -- enables ROCm/HIP compilation

**C preprocessor define** (new):
- `BUILD_WITH_ROCM` -- guards `#include <c10/hip/HIPStream.h>` in the generated C++ source

## Impact
- API: none (no public Python/C++ API change)
- Behavioral: torch-c-dlpack extension now builds and loads on ROCm systems; ROCm tensors can be converted via DLPack
- Flags/config: new `--build-with-rocm` CLI flag; device detection logic changed from `torch.cuda.is_available()` to `torch.version.cuda`/`torch.version.hip` checks
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Torch C DLPack JIT/AOT build pipeline per `.knowledge/designs/0017-dlpack-interop.md`
- DLPack exchange API and stream handling per `.knowledge/designs/0017-dlpack-interop.md`

Design elements this commit produces:
- ROCm device detection pattern: `torch.version.hip is not None` for ROCm, `torch.version.cuda is not None` for CUDA (replacing `torch.cuda.is_available()` which returns `True` on ROCm systems)

## Usage Examples
```bash
# Build with ROCm support
python -m tvm_ffi.utils._build_optional_torch_c_dlpack --build-with-rocm

# In Python, ROCm tensors are automatically detected
import torch, tvm_ffi
x = torch.randn(128, device="cuda")  # PyTorch "cuda" on ROCm
y = tvm_ffi.from_dlpack(x)
assert y.device.type == "rocm"
```
