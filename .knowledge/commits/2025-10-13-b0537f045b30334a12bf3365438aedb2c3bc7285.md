# Add CUDA stream protocol support via __cuda_stream__ in Cython arg setter

## TL;DR
- Adds support for NVIDIA's `__cuda_stream__` protocol: objects implementing `__cuda_stream__() -> (str, int)` are auto-converted to opaque pointers (`kTVMFFIOpaquePtr`) when passed to FFI functions.
- New `TVMFFIPyArgSetterCUDAStream_` setter in the arg-setter factory, dispatched after DLPack exchange API but before torch and `__dlpack__` fallbacks.
- Minor fix: `__dlpack__` attribute check changed from instance to class-level (`hasattr(arg_class, "__dlpack__")`).

## Key Exports

**Protocol: `__cuda_stream__`**:
- Any class with `__cuda_stream__(self) -> tuple[str, int]` is recognized by the type-cached arg setter factory.
- The second element of the returned tuple is treated as a `void*` pointer value.
- Checked on `type(arg)` (class-level).

**Cython function: `TVMFFIPyArgSetterCUDAStream_`** (`function.pxi`):
- Calls `arg.__cuda_stream__()`, extracts the integer pointer from index 1, and sets `out` to `kTVMFFIOpaquePtr`.

## Impact
- API: New Python protocol `__cuda_stream__`. Additive, non-breaking.
- Behavioral: `__dlpack__` attribute check changed from `hasattr(arg, ...)` to `hasattr(arg_class, ...)` -- consistent with other protocol checks but could change dispatch for objects with instance-level `__dlpack__` attributes.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

From `tests/python/test_device.py`:
```python
class MyDummyStream:
    def __init__(self, stream: int) -> None:
        self.stream = stream

    def __cuda_stream__(self) -> tuple[str, int]:
        return ("cuda", self.stream)

stream = MyDummyStream(1)
echo = tvm_ffi.get_global_func("testing.echo")
y = echo(stream)  # dispatched as kTVMFFIOpaquePtr
assert isinstance(y, ctypes.c_void_p)
assert y.value == 1
```
