# Add CUDA stream protocol support to Cython argument setter dispatch
## TL;DR
- Adds `TVMFFIPyArgSetterCUDAStream_` Cython setter that converts objects implementing `__cuda_stream__()` into `kTVMFFIOpaquePtr` (void*) for FFI transport.
- Inserts the `__cuda_stream__` check in `TVMFFIPyArgSetterFactory_` dispatch chain after DLPack exchange and before torch/DLPack fallbacks.
- Fixes `__dlpack__` detection to use `arg_class` (class-level check) instead of `arg` (instance-level), consistent with all other dunder-method checks in the factory.

## Impact
- API: New implicit conversion -- objects with `__cuda_stream__()` are now auto-converted to `void*` when passed as FFI arguments. No explicit API change needed.
- Behavioral: The `__dlpack__` check now uses `arg_class` instead of `arg`, which avoids triggering `__getattr__` on instances and is more efficient/consistent. This could change behavior for objects that define `__dlpack__` as an instance attribute (not a class method), but this is an edge case fix.
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces:

- Bugfix: `__dlpack__` dispatch now uses class-level `hasattr` (`arg_class`) instead of instance-level (`arg`), consistent with `__c_dlpack_exchange_api__` and `__cuda_stream__` checks.

## Usage Examples
**Context**: Passing a CUDA stream object through FFI using the `__cuda_stream__` protocol.
```python
import ctypes
import tvm_ffi

class MyCUDAStream:
    """Any class implementing __cuda_stream__() is auto-detected by FFI."""
    def __init__(self, stream_handle: int) -> None:
        self.handle = stream_handle

    def __cuda_stream__(self) -> tuple[str, int]:
        return ("cuda", self.handle)

# The stream is automatically converted to void* when passed to FFI functions
stream = MyCUDAStream(42)
echo = tvm_ffi.get_global_func("testing.echo")
result = echo(stream)
assert isinstance(result, ctypes.c_void_p)
assert result.value == 42
```
