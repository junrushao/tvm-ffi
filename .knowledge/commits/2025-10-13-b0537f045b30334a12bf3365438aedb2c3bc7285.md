# Add __cuda_stream__ protocol support to Cython arg setter dispatch

## TL;DR
- Adds a new Cython arg setter `TVMFFIPyArgSetterCUDAStream_` that converts objects implementing NVIDIA's `__cuda_stream__` protocol into `kTVMFFIOpaquePtr` values for the C ABI.
- Registers the setter in `TVMFFIPyArgSetterFactory_` dispatch chain, placed after `__c_dlpack_exchange_api__` and before `torch.Tensor` / `__dlpack__` checks.
- Incidental fix: changes `hasattr(arg, "__dlpack__")` to `hasattr(arg_class, "__dlpack__")` for consistency with other class-level attribute checks in the factory.

## Impact
- API: Additive -- objects implementing `__cuda_stream__` (e.g., `cuda.core.experimental.Stream`) can now be passed directly to TVM FFI functions. They are received as opaque `void*` pointers on the C++ side.
- Behavioral: The `__dlpack__` dispatch now checks on `arg_class` (the type) instead of `arg` (the instance), consistent with `__cuda_stream__`, `__c_dlpack_exchange_api__`, and `__tvm_ffi_tensor__` checks. This avoids triggering `__getattr__` on instances.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **TVMFFIPyArgSetterFactory_ dispatch chain** ([0012-python-bindings.md](../designs/0012-python-bindings.md)) -- adds a new branch for `__cuda_stream__`.
- **kTVMFFIOpaquePtr type index** ([0003-any-system.md](../designs/0003-any-system.md)) -- the output type for stream handles passed through ABI as `void*`.
- **TVMFFIPyArgSetter pattern** ([0012-python-bindings.md](../designs/0012-python-bindings.md)) -- follows the established per-type setter pattern with `(handle, ctx, py_arg, out)` signature.

Design elements this commit produces:
- **`__cuda_stream__` protocol integration** -- establishes that TVM FFI recognizes NVIDIA's CUDA stream protocol for automatic stream handle passing. This is distinct from the existing `__tvm_ffi_env_stream__` protocol (which sets the TLS stream context) -- `__cuda_stream__` simply passes the stream pointer as an opaque argument value.

## Usage Examples

From the test in this commit -- passing a `__cuda_stream__`-implementing object through the FFI:

```python
import ctypes
import tvm_ffi

class MyDummyStream:
    def __init__(self, stream: int) -> None:
        self.stream = stream

    def __cuda_stream__(self) -> tuple[str, int]:
        return ("cuda", self.stream)

stream = MyDummyStream(1)
echo = tvm_ffi.get_global_func("testing.echo")
y = echo(stream)
assert isinstance(y, ctypes.c_void_p)
assert y.value == 1
```
