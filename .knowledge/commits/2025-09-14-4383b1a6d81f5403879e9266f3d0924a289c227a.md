# Fix load_inline on Windows by running ninja build in MSVC developer prompt
## TL;DR
- Adds `_run_command_in_dev_prompt()` to `load_inline.py` that locates Visual Studio via `vswhere.exe`, finds `VsDevCmd.bat`, and runs build commands within the MSVC developer environment so that `cl.exe` and `link.exe` are available.
- Removes all `@pytest.mark.xfail(sys.platform.startswith("win"))` markers from `test_load_inline.py`, enabling Windows inline compilation tests.
