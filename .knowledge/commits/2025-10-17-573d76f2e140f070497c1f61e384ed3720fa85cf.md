# Add aten-style API aliases (dim, sizes, is_contiguous) and negative indexing to Tensor and TensorView

## TL;DR
- `Tensor` and `TensorView` gain three aten-style alias methods: `dim()` → `ndim()`, `sizes()` → `shape()`, `is_contiguous()` → `IsContiguous()`.
- `size(idx)` and `stride(idx)` parameter type changed from `size_t` to `int64_t`; both now support negative indexing (e.g., `size(-1)` = last dimension).
- Tests updated to verify negative indexing for `size` and `stride`.

## Key Exports

```python
class Tensor:
    """Ref-counted DLPack tensor."""
    # Existing methods (unchanged contract, new aliases added):
    def ndim(self) -> int: ...
    def shape(self) -> ShapeView: ...
    def IsContiguous(self) -> bool: ...

    # Changed signatures (size_t -> int64_t, adds negative indexing):
    def size(self, idx: int) -> int:
        # old: size(size_t idx) — unsigned, no negative indexing
        # new: size(int64_t idx) — signed; idx<0 wraps: shape[ndim+idx]
        # Invariant: idx in [-ndim, ndim-1]
        ...
    def stride(self, idx: int) -> int:
        # old: stride(size_t idx) — unsigned
        # new: stride(int64_t idx) — signed; wraps for negative idx
        ...

    # NEW aten-style aliases:
    def dim(self) -> int: ...          # -> ndim()
    def sizes(self) -> ShapeView: ...  # -> shape()
    def is_contiguous(self) -> bool: ...  # -> IsContiguous()
    # Interacts with: torch aten API consumers, DSL code expecting torch-like tensor API

class TensorView:
    """Non-owning DLTensor view, mirrors Tensor API."""
    # Same changes as Tensor: size/stride now int64_t, negative indexing supported
    # Same aten aliases: dim(), sizes(), is_contiguous()
```

## Impact
- API: `size(size_t)` / `stride(size_t)` signature changed to `size(int64_t)` / `stride(int64_t)` — callers passing unsigned values are unaffected (implicit conversion); callers passing signed values with negative intent now work correctly.
- Behavioral: Negative index access is now valid; previously would have wrapped around as a large unsigned value (UB territory). New aliases add three new method names.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```cpp
// C++: negative index access (new)
Tensor t = ...;  // shape [2, 3, 4]
assert(t.size(-1) == 4);   // last dim
assert(t.stride(-1) == 1); // last stride

// aten-style aliases (new)
assert(t.dim() == t.ndim());
assert(t.sizes()[0] == t.shape()[0]);
assert(t.is_contiguous() == t.IsContiguous());
```
