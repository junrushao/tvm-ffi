# Add aten-style API aliases (dim, sizes, is_contiguous) and negative indexing to Tensor/TensorView

## TL;DR
- Adds PyTorch aten-style convenience aliases to both `Tensor` and `TensorView`: `dim()` -> `ndim()`, `sizes()` -> `shape()`, `is_contiguous()` -> `IsContiguous()`.
- Changes `size(idx)` and `stride(idx)` parameter type from `size_t` to `int64_t` on both `Tensor` and `TensorView`, enabling negative indexing (e.g., `size(-1)` returns the last dimension).
- Adds tests for negative indexing on `size()` and `stride()`.

## Key Exports

```python
# --- On Tensor (ObjectRef) ---

class Tensor(ObjectRef):
    # CHANGED: size/stride parameter type from size_t to int64_t, now supports negative indexing
    # Old: def size(self, idx: size_t) -> int64: ...
    def size(self, idx: int64) -> int64: ...
        # Invariant: idx in range [-ndim, ndim). Negative idx wraps: shape[ndim + idx]
        # Interacts with: TensorObj.shape, TensorObj.ndim

    # Old: def stride(self, idx: size_t) -> int64: ...
    def stride(self, idx: int64) -> int64: ...
        # Invariant: idx in range [-ndim, ndim). Negative idx wraps: strides[ndim + idx]
        # Interacts with: TensorObj.strides, TensorObj.ndim

    # NEW: aten-style aliases
    def dim(self) -> int32: ...
        # Redirects to: ndim()
        # Interacts with: Tensor::ndim()

    def sizes(self) -> ShapeView: ...
        # Redirects to: shape()
        # Interacts with: Tensor::shape()

    def is_contiguous(self) -> bool: ...
        # Redirects to: IsContiguous()
        # Interacts with: Tensor::IsContiguous(), tvm::ffi::IsContiguous()

# --- On TensorView (non-owning) ---

class TensorView:
    # CHANGED: same negative indexing support as Tensor
    def size(self, idx: int64) -> int64: ...
    def stride(self, idx: int64) -> int64: ...

    # NEW: same aten-style aliases as Tensor
    def dim(self) -> int32: ...
    def sizes(self) -> ShapeView: ...
    def is_contiguous(self) -> bool: ...
```

## Impact
- API: Additive -- three new alias methods on each of `Tensor` and `TensorView`. Signature change for `size()`/`stride()` from `size_t` to `int64_t` is source-compatible for existing callers passing non-negative values.
- Behavioral: `size()` and `stride()` now accept negative indices (wrap-around). No bounds checking is performed; out-of-range negative indices produce undefined behavior (array underflow).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `Tensor::ndim()`, `Tensor::shape()`, `Tensor::IsContiguous()` -- existing accessors used as delegation targets for the new aliases. See [0007-containers.md](../designs/0007-containers.md).
- `TensorView` API mirror convention -- the new aliases are added to both `Tensor` and `TensorView` in parallel, maintaining the invariant that `TensorView` mirrors `Tensor`'s public API.
- PyTorch `at::Tensor` API naming conventions (`dim()`, `sizes()`, `is_contiguous()`) -- the motivation for the aliases.

Design elements this commit produces:
- **Aten-style alias convention**: `Tensor`/`TensorView` now provide both TVM-native names (`ndim`, `shape`, `IsContiguous`) and PyTorch aten-style names (`dim`, `sizes`, `is_contiguous`). This is a naming convention that may be extended to other methods in the future.
- **Negative indexing for dimension access**: `size(idx)` and `stride(idx)` now support Python-style negative indexing on both `Tensor` and `TensorView`.

## Usage Examples

**Context**: Using the new aten-style aliases and negative indexing in C++ kernel code.

```cpp
// Aten-style aliases -- use whichever naming convention your codebase follows
Tensor t = Tensor::Empty(Shape({2, 3, 4}), DLDataType{kDLFloat, 32, 1}, DLDevice{kDLCPU, 0});

int32_t ndims = t.dim();         // == t.ndim() == 3
ShapeView sh = t.sizes();        // == t.shape() == {2, 3, 4}
bool contig = t.is_contiguous(); // == t.IsContiguous() == true

// Negative indexing -- last dimension
int64_t last_size = t.size(-1);     // == t.size(2) == 4
int64_t last_stride = t.stride(-1); // == t.stride(2) == 1

// Same API works on TensorView
TensorView view = t;
int64_t first = view.size(-3);      // == view.size(0) == 2
```
