# Add aten-style API aliases (dim, sizes, is_contiguous) to Tensor/TensorView and support negative indexing in size/stride

## TL;DR
- Adds PyTorch aten-style alias methods to both `Tensor` and `TensorView`: `dim()` -> `ndim()`, `sizes()` -> `shape()`, `is_contiguous()` -> `IsContiguous()`.
- Changes `size(idx)` and `stride(idx)` parameter type from `size_t` to `int64_t` on both `Tensor` and `TensorView`, enabling negative indexing (e.g., `size(-1)` returns the last dimension).
- Adds tests for negative indexing and stride access in `test_tensor.cc`.

## Impact
- API: Additive -- new alias methods (`dim`, `sizes`, `is_contiguous`) on `Tensor` and `TensorView`. Signature change on `size()` and `stride()` from `size_t` to `int64_t` is source-compatible (implicit conversion) but enables negative indices.
- Behavioral: `size(idx)` and `stride(idx)` now accept negative indices, resolving them as `ndim + idx`. Previously, negative values passed as `size_t` would wrap to large positive values causing out-of-bounds access.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `Tensor` and `TensorView` accessor API pattern from [0006-ffi-containers](../design-records/0006-ffi-containers.md) -- `ndim()`, `shape()`, `IsContiguous()` are the canonical names; this commit adds aliases.
- `ShapeView` return type convention from [0006-ffi-containers](../design-records/0006-ffi-containers.md) -- `sizes()` alias returns `ShapeView`, consistent with `shape()`.

Design elements this commit produces:
- **Aten-style API alias convention**: Establishes a pattern of providing PyTorch-compatible method names as thin redirects on `Tensor`/`TensorView`. The canonical TVM names (`ndim`, `shape`, `IsContiguous`) remain the primary API; the aliases (`dim`, `sizes`, `is_contiguous`) exist for interop convenience.
- **Negative index support for `size()`/`stride()`**: Changes the parameter type from `size_t` to `int64_t` and adds `idx >= 0 ? idx : (ndim + idx)` normalization, matching PyTorch semantics.

## Usage Examples

**Context**: Using aten-style aliases and negative indexing on a Tensor (from test in this commit).
```cpp
// Create a 3D tensor with shape {1, 2, 3}
Tensor tensor = Tensor::FromNDAlloc(alloc, {1, 2, 3}, dtype, device);

// Aten-style aliases
int32_t d = tensor.dim();           // same as tensor.ndim() -> 3
ShapeView s = tensor.sizes();       // same as tensor.shape() -> {1, 2, 3}
bool contig = tensor.is_contiguous(); // same as tensor.IsContiguous()

// Negative indexing (new behavior)
EXPECT_EQ(tensor.size(-1), 3);     // last dimension
EXPECT_EQ(tensor.size(-2), 2);     // second-to-last
EXPECT_EQ(tensor.size(-3), 1);     // first dimension
EXPECT_EQ(tensor.stride(-1), 1);   // stride of last dimension
EXPECT_EQ(tensor.stride(-2), 3);   // stride of second-to-last
EXPECT_EQ(tensor.stride(-3), 6);   // stride of first dimension
```
