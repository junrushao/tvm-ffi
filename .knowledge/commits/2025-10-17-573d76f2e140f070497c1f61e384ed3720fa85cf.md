# Add torch-compatible API aliases to Tensor/TensorView
## TL;DR
- Adds method aliases on Tensor and TensorView matching PyTorch's ATen tensor API: `dim()` -> `ndim()`, `sizes()` -> `shape()`, `is_contiguous()` -> `IsContiguous()`.
- Makes it easier to write code compatible with both TVM FFI tensors and PyTorch tensors.

## Impact
- API: New convenience aliases `dim()`, `sizes()`, `is_contiguous()` on Tensor and TensorView.
