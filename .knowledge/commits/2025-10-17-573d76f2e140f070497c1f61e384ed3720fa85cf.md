# API Alias Redirect for torch aten tensor (#167)
## TL;DR
- Adds ATen-style alias methods to `Tensor` and `TensorView`: `dim()` -> `ndim()`, `sizes()` -> `shape()`, `is_contiguous()` -> `IsContiguous()`
- Changes `size()`/`stride()` parameter from `size_t` to `int64_t` on both `Tensor` and `TensorView` to support negative indexing (Python-style wrap-from-end)
- Adds tests for negative index access on `size()` and `stride()`

## Key Exports
```python
# --- Tensor (ObjectRef) ---
class Tensor:
    # Existing methods with signature change:
    # Old: size(idx: size_t) -> int64_t
    # New: size(idx: int64_t) -> int64_t  # negative idx wraps from end
    def size(self, idx: int) -> int: ...
    # Old: stride(idx: size_t) -> int64_t
    # New: stride(idx: int64_t) -> int64_t  # negative idx wraps from end
    def stride(self, idx: int) -> int: ...

    # New ATen-style aliases:
    def dim(self) -> int: ...           # Redirects to: ndim()
    def sizes(self) -> ShapeView: ...   # Redirects to: shape()
    def is_contiguous(self) -> bool: ...  # Redirects to: IsContiguous()
    # Interacts with: PyTorch at::Tensor API naming convention

# --- TensorView (non-owning view) ---
class TensorView:
    # Same signature changes and aliases as Tensor above
    def size(self, idx: int) -> int: ...    # negative idx support
    def stride(self, idx: int) -> int: ...  # negative idx support
    def dim(self) -> int: ...
    def sizes(self) -> ShapeView: ...
    def is_contiguous(self) -> bool: ...
    # Invariant: aliases kept in sync with Tensor class
```

## Impact
- API: `size()` and `stride()` parameter type changed from `size_t` to `int64_t` — callers passing `size_t` values will still work, but negative values are now valid. New alias methods added.
- Behavioral: Negative index values on `size()`/`stride()` now wrap from the end of dimensions instead of being (unsafely) cast to a large positive index.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
Using ATen-style aliases in C++ kernel code that works with both TVM and PyTorch conventions:

```cpp
#include <tvm/ffi/container/tensor.h>
using namespace tvm::ffi;

void process(Tensor tensor) {
  // ATen-style API (familiar to PyTorch users)
  int32_t d = tensor.dim();         // same as tensor.ndim()
  ShapeView s = tensor.sizes();     // same as tensor.shape()
  bool contig = tensor.is_contiguous();  // same as tensor.IsContiguous()

  // Negative indexing (Python-style)
  int64_t last_dim = tensor.size(-1);     // last dimension size
  int64_t last_stride = tensor.stride(-1); // last dimension stride
}
```
