# Add PyTorch aten-style API aliases and negative indexing for Tensor/TensorView

## TL;DR
- Adds three convenience method aliases on both `Tensor` and `TensorView`: `dim()` -> `ndim()`, `sizes()` -> `shape()`, `is_contiguous()` -> `IsContiguous()`, matching PyTorch's `at::Tensor` API surface.
- Changes `size(idx)` and `stride(idx)` parameter type from `size_t` to `int64_t` on both `Tensor` and `TensorView`, enabling negative indexing (e.g., `size(-1)` returns the last dimension's size).
- Adds tests for negative indexing of `size` and `stride`.

## Key Exports

**Methods on `Tensor` (new aliases)**:
- `int32_t Tensor::dim()` -- returns `ndim()` (aten-style alias)
- `ShapeView Tensor::sizes() const` -- returns `shape()` (aten-style alias)
- `bool Tensor::is_contiguous() const` -- returns `IsContiguous()` (aten-style alias)

**Methods on `TensorView` (new aliases)**:
- `int32_t TensorView::dim()` -- returns `ndim()` (aten-style alias)
- `ShapeView TensorView::sizes() const` -- returns `shape()` (aten-style alias)
- `bool TensorView::is_contiguous() const` -- returns `IsContiguous()` (aten-style alias)

**Signature changes on `Tensor`**:
- `int64_t Tensor::size(int64_t idx) const` -- was `size(size_t idx)`. Now supports negative indexing.
- `int64_t Tensor::stride(int64_t idx) const` -- was `stride(size_t idx)`. Now supports negative indexing.

**Signature changes on `TensorView`**:
- `int64_t TensorView::size(int64_t idx) const` -- was `size(size_t idx)`. Now supports negative indexing.
- `int64_t TensorView::stride(int64_t idx) const` -- was `stride(size_t idx)`. Now supports negative indexing.

## Impact
- API: Additive -- three new method aliases per class. The `size`/`stride` parameter type change from `size_t` to `int64_t` is source-compatible for all positive indices; callers using unsigned types will see implicit narrowing warnings only if compiling with strict warnings.
- ABI: None -- all methods are inline in the header; no vtable or symbol table changes.
- Behavioral: `size(idx)` and `stride(idx)` now accept negative indices, computing `ptr->ndim + idx` when `idx < 0`. No bounds checking is performed for out-of-range negative indices (same as the existing positive-index path).
- Flags/config: None
- Data formats/schemas: None

## Usage Examples

**Using aten-style aliases in C++ kernel code:**
```cpp
#include <tvm/ffi/container/tensor.h>

void process(tvm::ffi::TensorView x) {
  // aten-style API -- familiar to PyTorch C++ users
  int32_t d = x.dim();           // same as x.ndim()
  auto s = x.sizes();            // same as x.shape()
  bool c = x.is_contiguous();    // same as x.IsContiguous()

  // Negative indexing for size/stride
  int64_t last_dim = x.size(-1);       // last dimension size
  int64_t last_stride = x.stride(-1);  // last dimension stride
}
```
