# Add ATen-style tensor API aliases and negative-index support for size/stride
## TL;DR
- Adds ATen-style aliases `dim()`, `sizes()`, `is_contiguous()` to both `Tensor` and `TensorView`, redirecting to `ndim()`, `shape()`, `IsContiguous()` respectively.
- Changes `size()` and `stride()` parameter type from `size_t` to `int64_t` on both `Tensor` and `TensorView`, enabling negative indexing (Python-style: `-1` = last dimension).
- Adds tests for negative-index `size()` and `stride()` in `tests/cpp/test_tensor.cc`.

## Key Exports

**Methods mutated on `Tensor` (in `include/tvm/ffi/container/tensor.h`):**

| Method | Old signature | New signature |
|--------|--------------|---------------|
| `size` | `int64_t size(size_t idx) const` | `int64_t size(int64_t idx) const` |
| `stride` | `int64_t stride(size_t idx) const` | `int64_t stride(int64_t idx) const` |

**Methods mutated on `TensorView`** — same signature changes as `Tensor`.

**New aliases on both `Tensor` and `TensorView`:**

| Alias | Redirects to | Signature |
|-------|-------------|-----------|
| `dim()` | `ndim()` | `int32_t dim()` |
| `sizes()` | `shape()` | `ShapeView sizes() const` |
| `is_contiguous()` | `IsContiguous()` | `bool is_contiguous() const` |

## Impact
- API: `size()` and `stride()` parameter type changed from `size_t` to `int64_t` — callers passing `size_t` may get signed/unsigned warnings. No ABI break on 64-bit.
- Behavioral: `size(idx)` and `stride(idx)` now accept negative indices; no bounds checking added.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Containers / Tensor** (`0008-containers.md`): `Tensor`, `TensorView`, `TensorObj`, `ShapeView`, `IsContiguous()`
- **DLPack interop** (`0017-dlpack-interop.md`): `DLTensor` struct underlying `TensorView`

Design elements this commit produces:
- **ATen alias convention**: `dim()`/`sizes()`/`is_contiguous()` pattern on `Tensor` and `TensorView` — pure redirections to existing methods, establishing PyTorch ATen naming compatibility.
- **Negative indexing for tensor dimensions**: `size(-1)` and `stride(-1)` now work like Python negative indexing.

## Usage Examples
```cpp
// Negative indexing (new)
ffi::Tensor t = ffi::Tensor::Empty({2, 3, 4}, DLDataType{kDLFloat, 32, 1}, DLDevice{kDLCPU, 0});
t.size(-1);   // -> 4  (last dimension)
t.stride(-2); // -> 4  (second-to-last stride)

// ATen-style aliases (new)
t.dim();            // same as t.ndim() -> 3
t.sizes();          // same as t.shape()
t.is_contiguous();  // same as t.IsContiguous()
```
