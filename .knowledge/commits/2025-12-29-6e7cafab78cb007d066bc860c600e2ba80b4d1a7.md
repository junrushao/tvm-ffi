# Add ASF release process documentation for TVM-FFI
## TL;DR
- Adds `docs/dev/release_process.rst` documenting the full Apache TVM-FFI release workflow: tarball creation, GPG signing, ASF SVN staging, PyPI wheel publishing, version bumping, and docs deployment.

## Design Elements
Design elements this commit consumes:
- **C ABI version constants** (`TVM_FFI_VERSION_PATCH` in `include/tvm/ffi/c_api.h`): the version-bump script in the release doc reads and increments this macro. See `.knowledge/designs/0001-c-abi.md`.
- **Python packaging** (scikit-build-core wheel build, PyPI publishing via `publish_wheel.yml` GitHub Action): the release doc references this workflow. See `.knowledge/designs/0013-packaging.md`.

Design elements this commit produces:
- **Release workflow documentation** (`docs/dev/release_process.rst`): a new 3-step process (create RC -> conclude vote and retag -> upload final artifacts) with shell scripts for tarball, SVN upload, tag manipulation, and version bump. This is the first formalized release process doc in the repo.
