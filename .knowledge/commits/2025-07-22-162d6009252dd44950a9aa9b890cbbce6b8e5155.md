# Introduce TypeAttr column system and rename TypeExtraInfo to TypeMetadata
## TL;DR
- Adds a new **TypeAttr** column-oriented storage system that allows registering arbitrary per-type attributes (functions or constants) keyed by name, looked up by type index at runtime. This provides an extensible mechanism beyond the fixed `TVMFFITypeMetadata` struct.
- Renames `TVMFFITypeExtraInfo` to `TVMFFITypeMetadata` and `TVMFFITypeRegisterExtraInfo` to `TVMFFITypeRegisterMetadata` throughout the C ABI, C++ implementation, and consumers (structural equal/hash).
- Introduces C++ builder class `TypeAttrDef<Class>` for registering type attributes, and `TypeAttrColumn` accessor class for reading them.

Rename mapping:
| Before | After |
|--------|-------|
| `TVMFFITypeExtraInfo` | `TVMFFITypeMetadata` |
| `TVMFFITypeRegisterExtraInfo` | `TVMFFITypeRegisterMetadata` |
| `TVMFFITypeInfo::extra_info` | `TVMFFITypeInfo::metadata` |
| `TypeTable::Entry::extra_info_data` | `TypeTable::Entry::metadata_data` |
| `TypeTable::RegisterTypeExtraInfo` | `TypeTable::RegisterTypeMetadata` |

## Impact
- API: **Breaking rename** -- `TVMFFITypeExtraInfo` renamed to `TVMFFITypeMetadata`, `TVMFFITypeRegisterExtraInfo` renamed to `TVMFFITypeRegisterMetadata`, `TVMFFITypeInfo::extra_info` renamed to `TVMFFITypeInfo::metadata`. Any downstream code directly using these C ABI symbols must update. New symbols `TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`, `TVMFFITypeAttrColumn` are additive.
- Behavioral: Structural equal/hash now reads from `metadata` field instead of `extra_info` -- no semantic change.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Object system** (`0002-object-system.md`): `TypeAttrDef<Class>` requires `Class` to inherit from `Object` (`std::enable_if_t<std::is_base_of_v<Object, Class>>`).
- **Reflection system** (`0008-reflection.md`): `TypeAttrDef` reuses `ReflectionDefBase::GetMethod` for wrapping member functions into `ffi::Function` handles.
- **C ABI type table** (`0001-c-abi.md`): The new column storage lives inside `TypeTable` alongside existing type registration infrastructure. Uses `TVMFFIGetTypeInfo`, `Map<String, int64_t>` for name-to-column-index mapping.
- **Any/AnyView system** (`0003-any-system.md`): `TypeAttrColumn::operator[]` returns `AnyView`; values stored as `Any` in the column vector.

Design elements this commit produces:
- **TypeAttr column system** (new): A column-oriented per-type attribute store. Decouples extensible type metadata from the fixed `TVMFFITypeMetadata` struct. Columns are named, lazily created, and indexed by type_index.
- **TypeAttrDef builder** (new): Builder pattern for registering function-valued and constant-valued type attributes, paralleling `ObjectDef` for fields/methods.
- **TVMFFITypeMetadata** (renamed): Clearer name for the fixed per-type metadata struct (formerly `TVMFFITypeExtraInfo`).

## Usage Examples

Registering and accessing type attributes (from test code in this commit):

```cpp
// Registration side (in type's RegisterReflection):
namespace refl = tvm::ffi::reflection;
refl::TypeAttrDef<TIntObj>()
    .def("test.GetValue", &TIntObj::GetValue)   // function attr
    .attr("test.size", sizeof(TIntObj));          // constant attr

// Access side:
refl::TypeAttrColumn size_attr("test.size");
int size = size_attr[TIntObj::_type_index].cast<int>();
// Returns sizeof(TIntObj)
```
