# Introduce TypeAttr column storage and rename TypeExtraInfo to TypeMetadata in reflection
## TL;DR
- Renames `TVMFFITypeExtraInfo` to `TVMFFITypeMetadata` and `extra_info` field to `metadata` throughout the C ABI, reflection registry, and structural eq/hash.
- Introduces a new `TypeAttr` column-oriented storage system: `TVMFFITypeAttrColumn` C struct, `TVMFFITypeRegisterAttr`/`TVMFFIGetTypeAttrColumn` C API functions, and C++ wrappers `TypeAttrDef<T>` (registration builder) and `TypeAttrColumn` (lookup accessor).
- The TypeAttr system enables per-type attribute registration (functions or constants) indexed by type_index, stored as column arrays for cache-friendly lookup.

| Old name | New name |
|---|---|
| `TVMFFITypeExtraInfo` | `TVMFFITypeMetadata` |
| `TVMFFITypeInfo::extra_info` | `TVMFFITypeInfo::metadata` |
| `TVMFFITypeRegisterExtraInfo` | `TVMFFITypeRegisterMetadata` |
| `TypeTable::RegisterTypeExtraInfo` | `TypeTable::RegisterTypeMetadata` |
| `TypeTable::Entry::extra_info_data` | `TypeTable::Entry::metadata_data` |

## Impact
- API: `TVMFFITypeRegisterExtraInfo` renamed to `TVMFFITypeRegisterMetadata`; `TVMFFITypeInfo.extra_info` renamed to `.metadata`. All C/C++ callers of the old names must update. Two new C API functions added: `TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`.
- Behavioral: none — structural equality/hashing behavior unchanged (just field name swaps in the access path).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (0002): `TypeTable` stores type metadata; `Object::_type_index` used for column lookup.
- **C ABI** (0007): `TVMFFITypeInfo` struct extended with renamed `metadata` field. `TVMFFIByteArray` used for attr name passing.
- **Reflection** (0008): `ReflectionDefBase::GetMethod` reused to wrap functions in `TypeAttrDef::def`.
- **Any/AnyView** (0001): `AnyView::CopyToTVMFFIAny` used to store attribute values; `AnyView::CopyFromTVMFFIAny` used on retrieval.

Design elements this commit produces:
- **TypeAttr column system**: A new column-oriented storage mechanism within `TypeTable` for per-type named attributes. Columns are lazily created on first registration and stored as `vector<Any>` indexed by `type_index`. This is an extension point for the reflection system (0008) — any subsystem can register and query per-type metadata without modifying `TVMFFITypeMetadata`.
- **TypeAttrDef builder**: C++ fluent builder analogous to `ObjectDef`, used at static init time to register type attributes.
- **TypeAttrColumn accessor**: C++ class for reading column values by type_index.

## Usage Examples
Registering type attributes and looking them up (from `tests/cpp/testing_object.h` and `tests/cpp/test_reflection_accessor.cc`):
```cpp
// Registration (at static init time, alongside ObjectDef):
refl::TypeAttrDef<TIntObj>()
    .def("test.GetValue", &TIntObj::GetValue)    // function attribute
    .attr("test.size", sizeof(TIntObj));          // constant attribute

// Lookup:
refl::TypeAttrColumn size_attr("test.size");
int size = size_attr[TIntObj::_type_index].cast<int>();  // == sizeof(TIntObj)
```
