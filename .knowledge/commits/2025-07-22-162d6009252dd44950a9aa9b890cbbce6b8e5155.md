# Introduce TypeAttr in reflection and rename TypeExtraInfo to TypeMetadata
## TL;DR
- Renames `TVMFFITypeExtraInfo` to `TVMFFITypeMetadata` and `TVMFFITypeInfo::extra_info` to `TVMFFITypeInfo::metadata` across the C ABI and C++ layers.
- Introduces a new **TypeAttr** system: per-type key-value attributes stored in column-oriented arrays, registered via `TypeAttrDef<Class>` and queried via `TypeAttrColumn`.
- Adds two new C API functions (`TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`) and a new C ABI struct (`TVMFFITypeAttrColumn`).

## Key Exports

**Types/Classes**:

- `TVMFFITypeMetadata` (C struct, renamed from `TVMFFITypeExtraInfo`):
  ```c
  typedef struct {
      TVMFFIByteArray doc;
      TVMFFIObjectCreator creator;
      int64_t total_size;
      TVMFFISEqHashKind structural_eq_hash_kind;
  } TVMFFITypeMetadata;
  ```

- `TVMFFITypeAttrColumn` (C struct, new):
  ```c
  typedef struct {
      const TVMFFIAny* data;  // column array indexed by type_index
      size_t size;
  } TVMFFITypeAttrColumn;
  ```

- `TypeAttrDef<Class>` (C++ class template, new, `reflection/registry.h`):
  ```cpp
  template <typename Class>
  class TypeAttrDef : public ReflectionDefBase {
      template <typename Func>
      TypeAttrDef& def(const char* name, Func&& func);   // register function-valued attr
      template <typename T>
      TypeAttrDef& attr(const char* name, T value);       // register constant-valued attr
  };
  ```

- `TypeAttrColumn` (C++ class, new, `reflection/accessor.h`):
  ```cpp
  class TypeAttrColumn {
      explicit TypeAttrColumn(std::string_view attr_name);
      AnyView operator[](int32_t type_index) const;       // O(1) lookup, returns null AnyView if unset
  };
  ```

**Functions**:

- `TVMFFITypeRegisterMetadata(int32_t type_index, const TVMFFITypeMetadata* metadata) -> int` (renamed from `TVMFFITypeRegisterExtraInfo`)
- `TVMFFITypeRegisterAttr(int32_t type_index, const TVMFFIByteArray* attr_name, const TVMFFIAny* attr_value) -> int` (new)
- `TVMFFIGetTypeAttrColumn(const TVMFFIByteArray* attr_name) -> const TVMFFITypeAttrColumn*` (new, returns NULL if not registered)
- `EnsureTypeAttrColumn(std::string_view name) -> void` (new C++ inline helper, registers an empty column placeholder)

**Renames**:

| Old name | New name |
|----------|----------|
| `TVMFFITypeExtraInfo` | `TVMFFITypeMetadata` |
| `TVMFFITypeInfo::extra_info` | `TVMFFITypeInfo::metadata` |
| `TVMFFITypeRegisterExtraInfo` | `TVMFFITypeRegisterMetadata` |
| `TypeTable::RegisterTypeExtraInfo` | `TypeTable::RegisterTypeMetadata` |
| `Entry::extra_info_data` | `Entry::metadata_data` |

## Impact
- API: Breaking. `TVMFFITypeRegisterExtraInfo` renamed to `TVMFFITypeRegisterMetadata`. All callers of `TVMFFITypeInfo::extra_info` must use `->metadata`. Two new C API functions added.
- ABI: Breaking. `TVMFFITypeExtraInfo` renamed to `TVMFFITypeMetadata`. `TVMFFITypeInfo` field `extra_info` renamed to `metadata`. New `TVMFFITypeAttrColumn` struct.
- Behavioral: None to existing functionality. New TypeAttr registration does not affect existing type registration or field/method reflection.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Object system** (`.knowledge/designs/object-system.md`): `Object::_type_index`, `Object::RuntimeTypeIndex()` for type index resolution in `TypeAttrDef` and `TypeAttrColumn`.
- **Reflection system** (`.knowledge/designs/reflection.md`): `ObjectDef<Class>`, `ReflectionDefBase`, `ReflectionDefBase::GetMethod`, `TVM_FFI_CHECK_SAFE_CALL`, the `TypeTable` singleton and its `Entry` structure.
- **C ABI** (`.knowledge/designs/c-abi.md`): `TVMFFIAny`, `TVMFFIByteArray`, `TVMFFISEqHashKind`, `TVMFFITypeInfo` struct layout.
- **Any/AnyView** (`.knowledge/designs/any-system.md`): `AnyView::CopyToTVMFFIAny()`, `AnyView::CopyFromTVMFFIAny()` for converting between C++ values and C ABI `TVMFFIAny`.

Design elements this commit produces:
- **TypeAttr system** (new, no design doc yet): A column-oriented attribute store keyed by `(attr_name, type_index)`. Registered via `TypeAttrDef<Class>` at static init, queried via `TypeAttrColumn` at runtime. Stored in `TypeTable` as `Map<String, int64_t>` (name-to-column-index) + `vector<unique_ptr<TypeAttrColumnData>>`.
- **TVMFFITypeMetadata** (rename of `TVMFFITypeExtraInfo`): Improved naming for the per-type metadata struct.

## Usage Examples

### Registering type attributes via TypeAttrDef
**Context**: Extending a type with custom attributes alongside `ObjectDef` registration.
```cpp
// In TVM_FFI_STATIC_INIT_BLOCK, after ObjectDef<MyObj>():
namespace refl = tvm::ffi::reflection;
refl::TypeAttrDef<TIntObj>()
    .def("test.GetValue", &TIntObj::GetValue)     // function-valued attribute
    .attr("test.size", sizeof(TIntObj));           // constant-valued attribute
```

### Querying type attributes via TypeAttrColumn
**Context**: Runtime lookup of a registered attribute by type index.
```cpp
reflection::TypeAttrColumn size_attr("test.size");
int size = size_attr[TIntObj::_type_index].cast<int>();  // returns sizeof(TIntObj)
// Unregistered type indices return null AnyView:
AnyView v = size_attr[some_other_type_index];  // v is null if not set
```

### Ensuring a column exists before querying
**Context**: Pre-creating a column so that `TypeAttrColumn` lookup does not throw.
```cpp
reflection::EnsureTypeAttrColumn("my.custom_attr");
// Later, after types have registered:
reflection::TypeAttrColumn col("my.custom_attr");
```
