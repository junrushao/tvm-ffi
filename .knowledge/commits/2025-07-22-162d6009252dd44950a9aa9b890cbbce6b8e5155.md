# Introduce TypeAttr column-array registry and rename TVMFFITypeExtraInfo to TVMFFITypeMetadata

## TL;DR
- Renames `TVMFFITypeExtraInfo` → `TVMFFITypeMetadata` and `TVMFFITypeRegisterExtraInfo` → `TVMFFITypeRegisterMetadata` for clarity; updates all callers in registry, object table, and structural eq/hash.
- Introduces a new `TypeAttr` subsystem: a column-array store keyed by attribute name, indexed by type index. Each attribute is a sparse `TVMFFIAny[]` vector over all registered types. Exposed via `TVMFFITypeRegisterAttr` / `TVMFFIGetTypeAttrColumn` at the C ABI level.
- Adds `TypeAttrDef<Class>` (C++ builder) and `TypeAttrColumn` (C++ accessor) in the reflection layer, with a helper `EnsureTypeAttrColumn` for pre-allocating columns without a value.

### Rename mapping

| Old name | New name |
|----------|----------|
| `TVMFFITypeExtraInfo` | `TVMFFITypeMetadata` |
| `TVMFFITypeInfo::extra_info` | `TVMFFITypeInfo::metadata` |
| `TVMFFITypeRegisterExtraInfo` | `TVMFFITypeRegisterMetadata` |
| `TypeTable::RegisterTypeExtraInfo` | `TypeTable::RegisterTypeMetadata` |
| `Entry::extra_info_data` | `Entry::metadata_data` |

## Impact
- API: **Breaking rename** — `TVMFFITypeRegisterExtraInfo` removed; callers must switch to `TVMFFITypeRegisterMetadata`. `TVMFFITypeInfo::extra_info` field renamed to `metadata`. Any direct callers of the C ABI or C++ `ObjectDef` internals need to be updated. Additive: two new C ABI functions (`TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`) and two new C++ types (`TypeAttrDef`, `TypeAttrColumn`).
- Behavioral: None for existing behavior — rename is mechanical; `TVMFFITypeMetadata` has the same layout as `TVMFFITypeExtraInfo`. New `TypeAttr` store adds parallel per-type attribute lookup that didn't exist before.
- Flags/config: None.
- Data formats/schemas: `TVMFFITypeInfo` struct gains renamed field (`extra_info` → `metadata`); ABI-incompatible change for any pre-compiled binaries that read `TVMFFITypeInfo` by field name.

## Design Elements
Design elements this commit consumes:
- **0001-c-abi** — `TVMFFITypeInfo`, `TVMFFIAny`, `TVMFFIByteArray`, `TVMFFIObjectCreator`, `kTVMFFINone` sentinel; the existing `TVMFFITypeRegisterExtraInfo` C ABI function (now renamed)
- **0002-object-system** — `Object` base type, type index registration
- **0004-function-system** — `Function`/`FunctionObj` used as the value type for function-valued type attributes in `TypeAttrDef::def`
- **0006-reflection** — `ObjectDef<T>`, `ReflectionDefBase`, `FieldSetter`/`FieldGetter` pattern; structural eq/hash lookup via `TVMFFITypeInfo`

Design elements this commit produces:
- **`TVMFFITypeAttrColumn`** — new C ABI struct for the per-type attribute column store
- **`TVMFFITypeRegisterAttr` / `TVMFFIGetTypeAttrColumn`** — two new C ABI entry points extending the reflection C ABI surface
- **`TypeAttrDef<Class>`** — new C++ builder pattern for registering per-type attributes
- **`TypeAttrColumn`** — new C++ accessor wrapping a `TVMFFITypeAttrColumn*`
- **`EnsureTypeAttrColumn`** — utility for pre-allocating a column slot before any type registers a value
- **`TVMFFITypeMetadata`** — rename of `TVMFFITypeExtraInfo`; same layout, better name

## Usage Examples

**Registering type attributes (C++) — from `testing_object.h`:**

```cpp
// In the static initializer block for TIntObj:
refl::TypeAttrDef<TIntObj>()
    .def("test.GetValue", &TIntObj::GetValue)  // function-valued attr
    .attr("test.size", sizeof(TIntObj));        // constant-valued attr
```

**Reading a type attribute column (C++) — from `test_reflection_accessor.cc`:**

```cpp
// Look up column by name; throws RuntimeError if column doesn't exist
reflection::TypeAttrColumn size_attr("test.size");

// Index by type_index to get value for TIntObj
AnyView val = size_attr[TIntObj::_type_index];
int size = val.cast<int>();  // == sizeof(TIntObj)
```

**Ensuring a column exists before any type registers into it (C++):**

```cpp
// Called early (e.g., library init) to pre-allocate a column slot
reflection::EnsureTypeAttrColumn("my_lib.custom_attr");
// Later, TypeAttrDef<SomeObj>().attr("my_lib.custom_attr", some_value);
```
