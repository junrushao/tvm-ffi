# Introduce TypeAttr column-based type attributes and rename TypeExtraInfo to TypeMetadata
## TL;DR
- Renames `TVMFFITypeExtraInfo` to `TVMFFITypeMetadata` and `extra_info` to `metadata` throughout the C ABI, C++ implementation, and reflection system for clarity.
- Introduces a new `TypeAttr` system: column-oriented per-type-index attribute storage (`TVMFFITypeAttrColumn`) with C API registration (`TVMFFITypeRegisterAttr`) and lookup (`TVMFFIGetTypeAttrColumn`), plus C++ builder `TypeAttrDef<Class>` and accessor `TypeAttrColumn`.
- The TypeAttr system is orthogonal to reflection metadata -- it stores arbitrary named attributes (functions, constants) indexed by type, enabling extensible per-type dispatch without modifying the core type info struct.

**Rename mapping:**

| Old name | New name |
|----------|----------|
| `TVMFFITypeExtraInfo` | `TVMFFITypeMetadata` |
| `TVMFFITypeInfo::extra_info` | `TVMFFITypeInfo::metadata` |
| `TVMFFITypeRegisterExtraInfo` | `TVMFFITypeRegisterMetadata` |
| `TypeTable::RegisterTypeExtraInfo` | `TypeTable::RegisterTypeMetadata` |
| `TypeTable::Entry::extra_info_data` | `TypeTable::Entry::metadata_data` |

## Key Exports

**Structs:**

`TVMFFITypeMetadata` (renamed from `TVMFFITypeExtraInfo`) -- no field changes, only name:
```c
typedef struct {
  TVMFFIByteArray doc;
  TVMFFIObjectCreator creator;
  int64_t total_size;
  TVMFFISEqHashKind structural_eq_hash_kind;
} TVMFFITypeMetadata;
```

`TVMFFITypeAttrColumn` -- **new** column storage for per-type attributes:
```c
typedef struct {
  const TVMFFIAny* data;  // array indexed by type_index
  size_t size;            // length of the data array
} TVMFFITypeAttrColumn;
```

**C API functions:**

| Function | Status | Signature |
|----------|--------|-----------|
| `TVMFFITypeRegisterMetadata` | renamed from `TVMFFITypeRegisterExtraInfo` | `(int32_t type_index, const TVMFFITypeMetadata*) -> int` |
| `TVMFFITypeRegisterAttr` | **new** | `(int32_t type_index, const TVMFFIByteArray* attr_name, const TVMFFIAny* attr_value) -> int` |
| `TVMFFIGetTypeAttrColumn` | **new** | `(const TVMFFIByteArray* attr_name) -> const TVMFFITypeAttrColumn*` |

**C++ classes:**

`TypeAttrDef<Class>` -- **new** builder for registering per-type attributes (in `reflection/registry.h`):
```cpp
template <typename Class, typename = std::enable_if_t<std::is_base_of_v<Object, Class>>>
class TypeAttrDef : public ReflectionDefBase {
public:
  template <typename... ExtraArgs>
  explicit TypeAttrDef(ExtraArgs&&... extra_args);

  template <typename Func>
  TypeAttrDef& def(const char* name, Func&& func);  // register function-valued attr

  template <typename T>
  TypeAttrDef& attr(const char* name, T value);       // register constant-valued attr
};
```

`TypeAttrColumn` -- **new** accessor for reading type attributes (in `reflection/accessor.h`):
```cpp
class TypeAttrColumn {
public:
  explicit TypeAttrColumn(std::string_view attr_name);  // throws if column not found
  AnyView operator[](int32_t type_index) const;         // returns null AnyView if out of range
};
```

`EnsureTypeAttrColumn(std::string_view name)` -- **new** free function to pre-create a column without registering any value.

## Impact
- API: **Breaking C ABI change**. `TVMFFITypeExtraInfo` renamed to `TVMFFITypeMetadata`; `TVMFFITypeInfo::extra_info` renamed to `TVMFFITypeInfo::metadata`; `TVMFFITypeRegisterExtraInfo` renamed to `TVMFFITypeRegisterMetadata`. All downstream bindings (Cython, Rust) that reference these symbols must be updated. Two new C API functions added.
- Behavioral: No semantic change to existing functionality. The rename is purely cosmetic. The new TypeAttr system is additive.
- Flags/config: none
- Data formats/schemas: `TVMFFITypeAttrColumn` is a new runtime data structure; column data grows dynamically as types register attributes.

## Design Elements
Design elements this commit consumes:
- **Object system** (`0003-object-system.md`) -- `TypeAttrDef` requires `std::is_base_of_v<Object, Class>`, uses `Class::RuntimeTypeIndex()` and `Class::_type_key`
- **Reflection system** (`0009-reflection.md`) -- `TypeAttrDef` extends `ReflectionDefBase`, reuses `GetMethod<Class>()` for wrapping member functions
- **C ABI type info table** (`0001-c-abi-layer.md`) -- `TVMFFITypeInfo::metadata` (renamed field), `TVMFFIGetTypeInfo()`, type index dispatch
- **Any/AnyView value system** (`0002-any-value-system.md`) -- `TVMFFIAny` for column storage, `AnyView::CopyFromTVMFFIAny`/`CopyToTVMFFIAny` for value conversion

Design elements this commit produces:
- **TypeAttr column system** -- new extensible per-type attribute storage. Column-oriented layout (one `vector<Any>` per attribute name, indexed by `type_index`). Registered via `TVMFFITypeRegisterAttr`, looked up via `TVMFFIGetTypeAttrColumn`. Enables attaching arbitrary named attributes (functions, constants) to types without modifying `TVMFFITypeInfo`.
- **TypeAttrDef builder** -- nanobind-style registration API for type attributes, parallel to `ObjectDef` for fields/methods.
- **TVMFFITypeMetadata** (renamed) -- clarifies the semantic distinction between "metadata" (creator, size, doc, eq/hash kind -- fixed schema) and "attr" (extensible named values).

## Usage Examples

**Registering type attributes with TypeAttrDef:**
```cpp
#include <tvm/ffi/reflection/registry.h>
namespace refl = tvm::ffi::reflection;

// After ObjectDef registration:
refl::TypeAttrDef<TIntObj>()
    .def("test.GetValue", &TIntObj::GetValue)   // function attr
    .attr("test.size", sizeof(TIntObj));          // constant attr
```

**Reading type attributes with TypeAttrColumn:**
```cpp
#include <tvm/ffi/reflection/accessor.h>
namespace refl = tvm::ffi::reflection;

refl::TypeAttrColumn size_attr("test.size");
int size = size_attr[TIntObj::_type_index].cast<int>();  // sizeof(TIntObj)
```
