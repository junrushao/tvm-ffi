# Introduce TypeAttr column system and rename TypeExtraInfo to TypeMetadata

## TL;DR
- Renames `TVMFFITypeExtraInfo` to `TVMFFITypeMetadata` and `TVMFFITypeRegisterExtraInfo` to `TVMFFITypeRegisterMetadata` across C API, C++ headers, and implementation.
- Introduces a new **TypeAttr** column-array system for attaching arbitrary per-type attributes (functions or constants) keyed by string name, looked up by type index at runtime.
- Adds `TypeAttrDef<T>` builder class (analogous to `ObjectDef<T>`) with `.def()` (function attr) and `.attr()` (constant attr) methods, plus `TypeAttrColumn` accessor and C API (`TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`).

### Rename Mapping

| Before | After |
|--------|-------|
| `TVMFFITypeExtraInfo` | `TVMFFITypeMetadata` |
| `TVMFFITypeRegisterExtraInfo` | `TVMFFITypeRegisterMetadata` |
| `TVMFFITypeInfo::extra_info` | `TVMFFITypeInfo::metadata` |
| `TypeTable::RegisterTypeExtraInfo` | `TypeTable::RegisterTypeMetadata` |
| `TypeTable::Entry::extra_info_data` | `TypeTable::Entry::metadata_data` |

## Impact
- API: `TVMFFITypeExtraInfo` renamed to `TVMFFITypeMetadata`; `TVMFFITypeRegisterExtraInfo` renamed to `TVMFFITypeRegisterMetadata`. All callers of the old names must update. Three new C API functions added (`TVMFFITypeRegisterAttr`, `TVMFFIGetTypeAttrColumn`, `TVMFFITypeAttrColumn` struct).
- Behavioral: TypeAttr columns dynamically grow as new types register attributes. Column lookup returns NULL for unknown attr names (not an error at C level).
- Flags/config: none
- Data formats/schemas: `TVMFFITypeInfo` field `extra_info` renamed to `metadata`.

## Design Elements
Design elements this commit consumes:
- `TVMFFITypeInfo` type table ([0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md)) -- metadata pointer field, type_index for column indexing
- `ObjectDef<T>` reflection builder ([0007-ffi-reflection](../design-records/0007-ffi-reflection.md)) -- `TypeAttrDef` follows the same builder pattern
- `ReflectionDefBase::GetMethod` ([0007-ffi-reflection](../design-records/0007-ffi-reflection.md)) -- reused to wrap functions as bound methods in `TypeAttrDef::def()`
- `AnyView`/`Any` value system ([0002-ffi-any-value-system](../design-records/0002-ffi-any-value-system.md)) -- column storage uses `Any` array, accessor returns `AnyView`

Design elements this commit produces:
- **`TVMFFITypeAttrColumn`** (C struct): column-array storage for per-type attributes indexed by `type_index`. New C ABI surface.
- **`TypeAttrDef<T>`** (C++ builder): registration builder for type attributes, supporting function (`.def()`) and constant (`.attr()`) entries.
- **`TypeAttrColumn`** (C++ accessor): read-side wrapper for looking up attribute values by type index.
- **`EnsureTypeAttrColumn`** (C++ helper): ensures a column exists before any type registers into it.
- **Rename**: `TVMFFITypeExtraInfo` -> `TVMFFITypeMetadata` with corresponding API renames.

## Usage Examples

Registration (C++ side, from test fixture `testing_object.h`):
```cpp
// In a TVM_FFI_STATIC_INIT_BLOCK, after ObjectDef registration:
refl::TypeAttrDef<TIntObj>()
    .def("test.GetValue", &TIntObj::GetValue)      // function attr
    .attr("test.size", sizeof(TIntObj));            // constant attr
```

Lookup (C++ side, from `test_reflection_accessor.cc`):
```cpp
// Read back a constant attr by name, indexed by type_index
reflection::TypeAttrColumn size_attr("test.size");
int size = size_attr[TIntObj::_type_index].cast<int>();  // == sizeof(TIntObj)
```
