# [CI] setup asf yaml to protect main

## TL;DR
- Changes the GitHub branch protection target in `.asf.yaml` from `dev` to `main`, so that the `main` branch (instead of `dev`) requires at least one approving pull request review before merging.

## Key Exports
None. This commit changes no public API, ABI, or runtime behavior. It only affects the ASF-managed GitHub repository configuration.

## Impact
- API: No change.
- ABI: No change.
- Behavioral: The `main` branch now has branch protection enabled (requiring 1 approving review for PRs). The `dev` branch is no longer protected by this configuration. This reflects the project's transition to using `main` as the primary integration branch.
- Flags/config: No build flags or runtime configuration changed.
- Data formats/schemas: No change.

## Design Elements
Design elements this commit consumes:
- **ASF `.asf.yaml` infrastructure** -- Apache Software Foundation's GitHub integration reads `.asf.yaml` from the default branch to configure repository settings including branch protection rules, merge button options, and notification routing.

Design elements this commit produces:
- None. This is a configuration change, not a design change.
