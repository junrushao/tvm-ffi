# Fix two UBSan-detected undefined behaviors in object.h and string.h

## TL;DR
- Replace null-pointer arithmetic in `ObjectUnsafe::GetObjectOffsetToSubclass` with `__builtin_offsetof`, eliminating UB flagged by `-fsanitize=undefined`.
- Guard `std::memcpy` calls in `Bytes::InitData` and `String::InitData` with `size > 0` check to avoid passing null source pointer with zero size (UB per C++ standard).

## Key Exports

No new public API introduced. The changes are internal implementation fixes preserving existing interfaces.

```python
# ObjectUnsafe::GetObjectOffsetToSubclass<Class>() -> int64
# Implementation changed, interface unchanged.
# Old: reinterpret_cast on nullptr->header_ (UB)
# New: __builtin_offsetof(Class, header_) - __builtin_offsetof(Object, header_)
# Invariant: Class must have a header_ member inherited from Object.
# Interacts with: TVM_FFI_DEFINE_OBJECT_REF_METHODS macros, ObjectPtr casting

# Bytes::InitData(data: const char*, size: size_t) -> None
# String::InitData(data: const char*, size: size_t) -> None
# Now guarded: memcpy only called when size > 0
# Invariant: data may be null only when size == 0
# Interacts with: TVMFFIByteArray construction, String(const char*) constructors
```

## Impact
- API: None -- no signature changes.
- Behavioral: None -- only affects edge case where null data pointer with size 0 was passed; result is identical (empty string/bytes).
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `ObjectUnsafe` internal helper struct ([0003-ffi-object-system](../design-records/0003-ffi-object-system.md)) -- `GetObjectOffsetToSubclass` used for computing offset from base `Object` to subclass header, relied upon by object casting infrastructure.
- `String`/`Bytes` containers ([0006-ffi-containers](../design-records/0006-ffi-containers.md)) -- `InitData` is the internal data-copy path for constructing string/bytes from raw pointers.

Design elements this commit produces: None -- no new design elements. Restores correctness invariants without changing contracts.

## Usage Examples

Before/after pattern for the two UB fixes:

```cpp
// Fix 1: GetObjectOffsetToSubclass
// BEFORE (UB: null pointer member access)
return (reinterpret_cast<int64_t>(&(static_cast<Class*>(nullptr)->header_)) -
        reinterpret_cast<int64_t>(&(static_cast<Object*>(nullptr)->header_)));
// AFTER (defined behavior: compiler intrinsic)
return static_cast<int64_t>(__builtin_offsetof(Class, header_)) -
       static_cast<int64_t>(__builtin_offsetof(Object, header_));

// Fix 2: memcpy null guard
// BEFORE (UB: memcpy with null src when size==0)
std::memcpy(dest_data, data, size);
// AFTER (guarded)
if (size > 0) {
  std::memcpy(dest_data, data, size);
}
```

Reproduction case (from commit message):
```cpp
TVMFFIByteArray null_bytes{nullptr, 0};
tvm::ffi::String str_from_null(null_bytes);  // was UB, now safe
```
