# Fix two undefined behavior sanitizer issues
## TL;DR
- Guards `std::memcpy` in `String` and `Bytes` constructors with `if (size > 0)` to avoid passing a null source pointer with size 0, which is UB per the C standard.
- Replaces null-pointer-based member offset computation in `ObjectUnsafe::GetObjectOffsetToSubclass` with `__builtin_offsetof`, wrapped in `#pragma GCC diagnostic ignored "-Winvalid-offsetof"` to suppress warnings about using `offsetof` on non-standard-layout types.

## Impact
- API: None (no public interface changes).
- Safety: Eliminates two undefined behavior issues caught by `-fsanitize=undefined`.
