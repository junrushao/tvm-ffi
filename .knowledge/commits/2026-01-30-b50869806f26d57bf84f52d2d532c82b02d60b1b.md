# Fix two undefined behavior issues caught by UBSan
## TL;DR
- Guards `std::memcpy` in `String::InitData` and `Bytes::InitData` with size > 0 check to prevent passing null source pointer.
- Replaces null pointer arithmetic in `ObjectUnsafe::GetObjectOffsetToSubclass` with standard `__builtin_offsetof`, eliminating UBSan-flagged null pointer member access.

## Key Exports

```python
# Fix 1: String/Bytes InitData
# Before: std::memcpy(dest, data, 0) with data=nullptr -> UB
# After:  if (size > 0) std::memcpy(dest, data, size)
# Invariant: memcpy never called with null source

# Fix 2: GetObjectOffsetToSubclass
# Before: reinterpret_cast(static_cast<Class*>(nullptr)->header_) -> UB (null deref)
# After:  __builtin_offsetof(Class, header_) - __builtin_offsetof(Object, header_)
# Invariant: no null pointer arithmetic
# Interacts with: Object system header layout, all ObjectRef subclasses
```
