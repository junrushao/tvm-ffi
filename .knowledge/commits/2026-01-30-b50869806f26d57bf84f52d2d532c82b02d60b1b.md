# Fix two UBSan issues: null memcpy in String/Bytes and null pointer arithmetic in object offset
## TL;DR
- Guards `std::memcpy` in `String::InitData` and `Bytes::InitData` with `size > 0` check to avoid passing null source pointer with size 0 (UB per C++ standard).
- Replaces null pointer arithmetic in `ObjectUnsafe::GetObjectOffsetToSubclass` with `__builtin_offsetof` to avoid UBSan-flagged undefined behavior.

## Key Exports

**Functions (modified)**:
- `ObjectUnsafe::GetObjectOffsetToSubclass<Class>() -> int64_t` -- now uses `__builtin_offsetof(Class, header_) - __builtin_offsetof(Object, header_)` instead of null pointer dereference arithmetic. Suppresses `-Winvalid-offsetof` via `#pragma GCC diagnostic` for non-standard-layout types.
- `String::InitData(const char* data, size_t size)` -- guards memcpy with `size > 0`
- `Bytes::InitData(const char* data, size_t size)` -- guards memcpy with `size > 0`

## Impact
- API: none (no signature changes)
- Behavioral: Eliminates undefined behavior that UBSan detects: (1) `memcpy(dest, nullptr, 0)` in empty string/bytes construction, (2) null pointer member access for offset computation.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (`.knowledge/designs/0003-object-system.md`): `ObjectUnsafe::GetObjectOffsetToSubclass` computes the byte offset between a derived class's `header_` field and the `Object` base class's `header_` field, used for type hierarchy navigation.
- **Small string optimization / String** (`.knowledge/designs/0011-small-string-optimization.md`): `String::InitData` and `Bytes::InitData` handle the zero-length edge case.

Design elements this commit produces:
- None (bugfix only).

## Usage Examples

Before (UB on empty string construction):
```cpp
TVMFFIByteArray null_bytes{nullptr, 0};
tvm::ffi::String str(null_bytes);  // UBSan error: memcpy with null src
```

After (safe):
```cpp
TVMFFIByteArray null_bytes{nullptr, 0};
tvm::ffi::String str(null_bytes);  // OK: size==0 skips memcpy
```

Before (UB in offset computation):
```cpp
// Internally used null pointer arithmetic:
reinterpret_cast<int64_t>(&(static_cast<Class*>(nullptr)->header_))
// UBSan: member access within null pointer
```

After (well-defined offsetof):
```cpp
static_cast<int64_t>(__builtin_offsetof(Class, header_))
```
