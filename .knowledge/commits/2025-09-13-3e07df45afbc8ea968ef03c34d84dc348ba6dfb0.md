# Bump version to beta and configure GitHub merge buttons

## TL;DR
- Bumps the Python package version from `0.1.0a13` (alpha) to `0.1.0b0` (beta) in `pyproject.toml`.
- Adds `enabled_merge_buttons` section to `.asf.yaml` to enforce squash-only merges on the GitHub repository (squash enabled with DEFAULT commit message; merge and rebase buttons disabled).
