# Add cmake-format and cmake-lint pre-commit hooks and reformat all CMake files

## TL;DR
- Adds `cmake-format` (v0.6.13) and `cmake-lint` pre-commit hooks via the `cheshirekow/cmake-format-precommit` repo.
- Introduces `.cmake-format.json` configuration (100-col, 2-space indent, unix line endings, dangling parens, lint rules).
- Reformats all 10 CMake files to comply: whitespace, indentation alignment, comment wrapping, variable naming conventions, and function/macro doc-comments.
