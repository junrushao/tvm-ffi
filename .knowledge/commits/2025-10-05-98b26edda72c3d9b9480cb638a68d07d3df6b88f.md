# Add cmake-format and cmake-lint pre-commit hooks, reformat all CMake files
## TL;DR
- Adds `cmake-format` (v0.6.13) and `cmake-lint` hooks to `.pre-commit-config.yaml`.
- Adds `.cmake-format.json` configuration (100-col, 2-space indent, dangling parens, unix line endings, naming conventions for macros/functions/variables).
- Reformats all 9 CMake files to comply with the new formatter/linter, including variable renames (`tvm_ffi_objs_sources` -> `_tvm_ffi_objs_sources`) and macro rename (`tvm_ffi_add_googletest` -> `TVM_FFI_ADD_GTEST`) to satisfy cmake-lint naming conventions.

## Key Exports
N/A -- infrastructure. Notable convention changes:

| Before | After | Reason |
|--------|-------|--------|
| `tvm_ffi_add_googletest(target)` | `TVM_FFI_ADD_GTEST(target)` | cmake-lint: macros must match `[0-9A-Z_]+` |
| `Python_add_library(...)` | `python_add_library(...)` | cmake-lint: functions must match `[0-9a-z_]+` |
| `tvm_ffi_objs_sources` | `_tvm_ffi_objs_sources` | cmake-lint: local vars must match `[a-z][a-z0-9_]+` (prefixed with `_` for private) |
| `tvm_ffi_extra_objs_sources` | `_tvm_ffi_extra_objs_sources` | Same as above |
| `core_cpp`, `core_pyx`, `cython_sources` | `_core_cpp`, `_core_pyx`, `_cython_sources` | Same as above |
| `_libbacktrace_source`, `_cmake_c_compiler` | `libbacktrace_source`, `cmake_c_compiler` | cmake-lint: remove leading underscore for function-local vars |
| `endif()`, `else()` | `endif ()`, `else ()` | cmake-format: `separate_ctrl_name_with_space: true` |

## Impact
