# Add cmake-format and cmake-lint pre-commit hooks; reformat all CMake files
## TL;DR
- Adds `cmake-format` (v0.6.13) and `cmake-lint` as new pre-commit hooks, enforcing consistent CMake code style across the project.
- Introduces `.cmake-format.json` configuration (100-col line width, 2-space indent, dangling parens, unix line endings, lint rules for naming conventions).
- Reformats all 10 CMake files to comply and renames several internal CMake variables/macros to satisfy cmake-lint naming conventions.
