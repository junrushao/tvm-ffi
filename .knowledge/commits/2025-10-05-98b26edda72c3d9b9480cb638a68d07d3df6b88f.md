# Add cmake-format and cmake-lint pre-commit hooks; reformat all CMake files
## TL;DR
- Adds `cmake-format` (v0.6.13) and `cmake-lint` pre-commit hooks via `cheshirekow/cmake-format-precommit`.
- Introduces `.cmake-format.json` configuration (100-col, 2-space indent, dangling parens, canonical command case).
- Reformats all 10 CMake files to comply with the new style, including the root `CMakeLists.txt`, all `cmake/Utils/*.cmake` modules, `cmake/tvm_ffi-config.cmake`, and example/test `CMakeLists.txt` files.
- Renames macro `tvm_ffi_add_googletest` to `TVM_FFI_ADD_GTEST` (CMake macro uppercase convention) and several local variables (e.g., `core_cpp` -> `_core_cpp`, `tvm_ffi_objs_sources` -> `_tvm_ffi_objs_sources`).

## Key Exports
N/A -- infrastructure. The only behavioral naming change is the macro rename:

# After:

## Design Elements
Design elements this commit consumes:
- Pre-commit hook infrastructure (`.pre-commit-config.yaml`) -- extended with two new hooks.
- CMake build system conventions across `CMakeLists.txt` and `cmake/Utils/*.cmake`.

Design elements this commit produces:
- **CMake formatting convention**: codified in `.cmake-format.json`. Key rules: 100-col line width, 2-space indent, dangling parens with prefix alignment, canonical command casing, Unix line endings. All CMake files must pass `cmake-format --check` and `cmake-lint` via pre-commit.
- **CMake macro naming convention**: macros use UPPERCASE (`TVM_FFI_ADD_GTEST`); functions use lowercase (`tvm_ffi_add_prefix_map`). This was implicit before; the rename makes it explicit.
- **CMake local variable naming**: local variables in functions now drop the leading underscore in some cases (`_libbacktrace_source` -> `libbacktrace_source`) while build-scoped variables gain one (`tvm_ffi_objs_sources` -> `_tvm_ffi_objs_sources`). Convention: underscore-prefixed for file-scoped private variables, unprefixed for function-local.
