# Remove DLPack stride normalization workaround from torch C DLPack extension
## TL;DR
- Removed stride normalization logic in `toDLPackImpl` that created an `as_strided` view for 1-D single-element tensors with non-unit stride (PyTorch gh-83069 workaround).
- The original `src` tensor is now used directly without any intermediate view, simplifying the code path.

## Key Exports
None

## Impact
- API: none
- Behavioral: 1-D single-element torch tensors with stride != 1 now preserve their original stride in DLPack export instead of being normalized to stride `{1}`. This aligns with upstream PyTorch behavior after the gh-83069 fix landed.
- Flags/config: none
- Data formats/schemas: none
