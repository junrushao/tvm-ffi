# Remove all DLPack stride normalization from toDLPackImpl, passing source tensor through unchanged
## TL;DR
- Completely removes the stride normalization workaround in `toDLPackImpl<T>` that was introduced in `53ffe5e` (restricted to 1D tensors) and originated from PyTorch gh-83069.
- The `view` local variable, the `need_normalize_strides` check, and the `as_strided` call are all deleted. `src` is used directly for all tensor properties (handle, data_ptr, sizes, strides).
- Net effect: DLPack export now preserves the source tensor's strides exactly as-is for all tensor shapes, including 1D single-element tensors.

## Key Exports
None. No new types, functions, macros, or constants are introduced. The public API surface (`TorchDLPackFromPyObject`, `TorchDLPackToPyObject`, `TorchDLPackTensorAllocator`) is unchanged.

## Impact
- API: None -- the three exported C function pointers retain the same signatures and registration mechanism.
- Behavioral: `toDLPackImpl<T>` no longer normalizes strides for any tensor. Previously, 1D tensors with `shape=[1]` and `stride(0) != 1` had their strides forced to `[1]` via `as_strided`. After this commit, such tensors retain their original stride values in the exported DLPack struct. This changes the `DLTensor.strides` field visible to downstream consumers for this edge case.
- Flags/config: None.
- Data formats/schemas: The `DLManagedTensorVersioned.dl_tensor.strides` value may differ for 1D single-element tensors with non-unit strides (previously `[1]`, now the original stride value).

## Design Elements
Design elements this commit consumes:
- **DLPack fast-path exchange protocol** ([0017-dlpack-interop.md](../designs/0017-dlpack-interop.md)): `toDLPackImpl<T>` is the core conversion function called by `TorchDLPackFromPyObject`, which backs `torch.Tensor.__c_dlpack_from_pyobject__`.
- **Type-cached dispatch** ([0015-python-ffi-call-dispatch.md](../designs/0015-python-ffi-call-dispatch.md)): The speed-converter path invokes the exported function pointers.

Design elements this commit produces:
- None. This is a simplification of an existing implementation -- no new design elements are introduced.

Design elements this commit mutates:
- **Stride invariant in `toDLPackImpl`**: The previous invariant ("1D tensors with shape=[1] and non-unit stride get stride normalization") is removed. The new invariant is simpler: "all tensors pass through with their original strides unchanged."

## Usage Examples
None -- no new API surface. The behavioral change is transparent to callers of `TorchDLPackFromPyObject`.
