# Remove stride normalization workaround in toDLPackImpl for 1D size-1 tensors

## TL;DR

- Deletes the special-case stride normalization inside `toDLPackImpl` that silently created a new view with stride `{1}` for 1D tensors of shape `[1]` when the actual stride was not 1 (originally a workaround for PyTorch issue gh-83069).
- After removal, `toDLPackImpl` passes `src` directly for all fields (`handle`, `data_ptr`, `sizes`, `strides`) with no intermediate `view`.
- Ensures DLPack tensors exported from PyTorch always expose the tensor's actual strides, eliminating silent data hiding for strided 1D scalars.

## Key Exports

```python
# python/tvm_ffi/_optional_torch_c_dlpack.py (C++ source embedded as a string literal)
# Template function inside the embedded C++ extension source — not a Python API.

# BEFORE (removed):
# template <class T>
# T* toDLPackImpl(const Tensor& src) {
#   auto view = src;
#   bool need_normalize_strides = (src.dim() == 1 && src.size(0) == 1 && src.stride(0) != 1);
#   if (need_normalize_strides) {
#       view = src.as_strided(src.sizes(), {1}, src.storage_offset());  # gh-83069 workaround
#   }
#   atDLMTensor->handle = view;
#   atDLMTensor->tensor.dl_tensor.data    = view.data_ptr();
#   atDLMTensor->tensor.dl_tensor.shape   = const_cast<int64_t*>(view.sizes().data());
#   atDLMTensor->tensor.dl_tensor.strides = const_cast<int64_t*>(view.strides().data());
# }

# AFTER (current):
# template <class T>
# T* toDLPackImpl(const Tensor& src) {
#   atDLMTensor->handle = src;
#   atDLMTensor->tensor.dl_tensor.data    = src.data_ptr();
#   atDLMTensor->tensor.dl_tensor.shape   = const_cast<int64_t*>(src.sizes().data());
#   atDLMTensor->tensor.dl_tensor.strides = const_cast<int64_t*>(src.strides().data());
#   # Invariant: strides are always the tensor's actual strides — never normalized
#   # Interacts with: ATenDLMTensor<T>.handle (keeps src alive via ATen ref-counting)
# }
```

## Impact

- API: None — `toDLPackImpl` is an internal C++ template; `load_torch_c_dlpack_extension()` public Python API is unchanged.
- Behavioral: For a 1D PyTorch tensor with shape `[1]` and stride `!= 1` (e.g., a slice producing a non-contiguous scalar-like view), the exported `DLManagedTensorVersioned.dl_tensor.strides[0]` now reflects the actual stride instead of being silently normalized to 1. Consumers that previously received stride `1` will now see the real stride.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- `_optional_torch_c_dlpack.py` / `load_torch_c_dlpack_extension()` — fast C DLPack path registered on `torch.Tensor`'s `PyTypeObject*`. See `.knowledge/design-records/0016-py-ffi-call-dispatch.md` § "Optional Torch C Extension".
- `TVMFFIPyArgSetter.c_dlpack_from_pyobject` (`DLPackFromPyObject`) — the function pointer slot that calls into `toDLPackImpl` when a `torch.Tensor` argument is dispatched. See `.knowledge/design-records/0016-py-ffi-call-dispatch.md`.
- `ATenDLMTensor<T>` — ATen wrapper struct whose `handle` field keeps the source tensor alive via an ATen `Tensor` copy.

Design elements this commit produces:
- None — this commit only removes code from an existing function; no new design elements introduced.

## Usage Examples

Before/after for affected scenario (1D size-1 non-contiguous tensor):

```python
import torch
import tvm_ffi

tvm_ffi._optional_torch_c_dlpack.load_torch_c_dlpack_extension()

# Create a 1D tensor with non-unit stride (e.g., every other element)
base = torch.tensor([10.0, 20.0, 30.0])
t = base[::2]  # shape=[2], stride=[2]
t1 = t[:1]     # shape=[1], stride=[2]  (this was the affected case)

# BEFORE: toDLPackImpl would normalize stride to [1] for t1 → silent data mismatch
# AFTER:  toDLPackImpl exposes actual stride [2] → downstream consumers see truth
fn = tvm_ffi.get_global_func("some.kernel")
fn(t1)  # strides[0] == 2 now, not 1
```
