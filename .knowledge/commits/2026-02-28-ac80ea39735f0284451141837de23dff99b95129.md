# Add CMake namespace aliases for source dependency builds

## TL;DR
- Creates CMake ALIAS targets `tvm_ffi::header`, `tvm_ffi::shared`, `tvm_ffi::static` pointing to in-tree build targets.
- Ensures namespace-qualified target names work in both source dependency and installed-package builds.
