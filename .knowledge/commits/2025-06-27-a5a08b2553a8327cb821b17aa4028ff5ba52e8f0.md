# Harden reflection registration, allow int32 type_index in MakeObjectFromPackedArgs, and zero DLDataType padding in TVMFFIAny.

## TL;DR
- **dtype.h**: Zero the full `TVMFFIAny.v_uint64` before writing `v_dtype`, clearing padding bits so `DLDataType` equality comparisons on the 8-byte word are always reliable.
- **object.cc / `RegisterTypeExtraInfo`**: Add a guard that throws `RuntimeError` when `extra_info` is already set, preventing silent double-registration of reflection metadata. Simultaneously, pre-register the `Object` base type in `TypeTable` init so it has a valid `TVMFFITypeExtraInfo` from the start.
- **object.cc / `MakeObjectFromPackedArgs`**: Accept either an `int32_t` type_index or a `String` type_key as the first argument (enabling callers to skip the name→index lookup), move the arg-count parity check after type resolution, and replace `type_key` captures in error messages with `TypeIndexToTypeKey(type_index)` to unify the error path.

## Impact
- API: `MakeObjectFromPackedArgs` now accepts `int32_t` as `args[0]` — additive overload that does not break existing string-based callers.
- Behavioral: Double-calling `ObjectDef<T>()` for the same type now raises `RuntimeError` at startup instead of silently overwriting. Error messages in `MakeObjectFromPackedArgs` are now consistent regardless of whether the caller passed a string or int.
- Flags/config: none
- Data formats/schemas: `DLDataType` equality semantics tightened: padding bytes in `TVMFFIAny` are now zeroed, so bit-level comparison of `v_uint64` is safe.

## Usage Examples

**DLDataType equality (bugfix illustration)**:
```cpp
// Before: Two DLDataType values with same code/bits/lanes but different garbage padding
//   could compare unequal via v_uint64. After: padding is zeroed first.
TVMFFIAny a, b;
TypeTraits<DLDataType>::CopyToAnyView(dtype, &a);  // a.v_uint64 is clean
TypeTraits<DLDataType>::MoveToAny(dtype, &b);       // b.v_uint64 is clean
assert(a.v_uint64 == b.v_uint64);  // safe after the fix
```

**MakeObjectFromPackedArgs with type_index**:
```python
# Python pseudocode: calling via type_index (int32) instead of string key
# Previously only string key was accepted:
#   tvm.ffi.make_object("my.Foo", "field1", value1)
# Now also valid (skips name→index lookup):
#   tvm.ffi.make_object(type_index, "field1", value1)
```

**Double-registration guard**:
```cpp
// Before: second ObjectDef<T>() call silently overwrote extra_info.
```
