# CI: test multiple Python versions and migrate to uv for package installation
## TL;DR
- Expand CI test matrix to cover Python 3.9, 3.10, 3.12, and 3.13 across four OS/arch combinations (previously only 3.13).
- Replace `actions/setup-python` + `pip install` with `astral-sh/setup-uv` (pinned v6.7.0) + `uv pip install --reinstall -e ".[test]"`.
- Reorder workflow steps so `actions/checkout` precedes Python setup, and add section comments for readability.
