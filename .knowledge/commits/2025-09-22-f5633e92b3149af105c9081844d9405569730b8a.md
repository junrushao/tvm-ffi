# Expand CI Python version matrix to cover 3.9, 3.10, 3.12, and 3.13 across all platforms
## TL;DR
- Assigns a distinct Python version to each CI matrix runner: ubuntu-latest→3.13, ubuntu-24.04-arm→3.9, windows-latest→3.12, macos-14→3.10.
- Switches Python setup from `actions/setup-python` to `astral-sh/setup-uv` (pinned to `b75a909f75acd358c2196fb9a5f1299a9a8868a4`) with `activate-environment: true`, and Python install from `pip install` to `uv pip install --reinstall --verbose -e ".[test]"`.
- Moves `actions/checkout` before Python setup and reorders the `Print current commit` step to immediately after checkout, placing C++ test steps ahead of the Python setup block.
