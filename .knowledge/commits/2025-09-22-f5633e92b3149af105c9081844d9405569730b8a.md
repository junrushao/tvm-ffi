# Test various Python versions in GitHub Action CI
## TL;DR
- Extends the CI test matrix to cover four different Python versions instead of testing only against Python 3.13: ubuntu-latest gets 3.13, ubuntu-24.04-arm gets 3.9, windows-latest gets 3.12, and macos-14 gets 3.10.
- Replaces `actions/setup-python@v6` with `astral-sh/setup-uv@v6.7.0` (pinned by SHA) for Python setup, using `activate-environment: true` so `uv` manages the virtualenv.
- Switches the Python package install command from `python -m pip install --upgrade pip && pip install -v ".[test]"` to `uv pip install --reinstall --verbose -e ".[test]"`, aligning CI with the project's `uv`-based workflow.
- Reorders workflow steps so `actions/checkout` runs before Python setup, and adds section comments (`# Detect CPU count`, `# Run C++ tests`, `# Run Python tests`) for readability.

## Key Exports
None. This commit modifies only the GitHub Actions workflow file (`.github/workflows/ci_test.yml`). No source code, public APIs, or build artifacts are changed.

## Impact
- API: None.
- ABI: None.
- Behavioral: CI now validates the project against Python 3.9, 3.10, 3.12, and 3.13, catching version-specific issues (e.g., `from __future__ import annotations` behavior, `typing` compatibility, syntax differences). Previously, only 3.13 was tested, leaving older versions untested.
- Flags/config: The CI matrix gains a `python_version` parameter per OS entry. The Python setup action changes from `actions/setup-python` to `astral-sh/setup-uv`, and the install command switches from pip to uv.
- Data formats/schemas: None.
