# Add per-platform Python version matrix and switch CI to uv

## TL;DR
- Adds `python_version` to the CI test matrix so each platform tests a different Python version: ubuntu-latest/3.13, ubuntu-24.04-arm/3.9, windows-latest/3.12, macos-14/3.10.
- Replaces `actions/setup-python@v6` + `pip install` with `astral-sh/setup-uv@v6.7.0` (pinned SHA) + `uv pip install --reinstall`, aligning CI with the repo's `uv`-based workflow.
- Reorders workflow steps so `actions/checkout` runs before Python setup, and adds section comments for readability.
