# Diversify Python version coverage in CI test matrix
## TL;DR
- Each CI platform now tests a distinct Python version (ubuntu=3.13, ubuntu-arm=3.9, windows=3.12, macos=3.10) instead of all using 3.13.
- Python setup switched from `actions/setup-python` + pip to `astral-sh/setup-uv` with `uv pip install`.
- Workflow step ordering cleaned up: checkout before Python setup, added section comments.
