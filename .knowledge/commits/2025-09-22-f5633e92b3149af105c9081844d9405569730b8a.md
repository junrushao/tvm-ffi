# Add per-platform Python version matrix and migrate CI from pip to uv
## TL;DR
- CI test matrix now specifies a distinct Python version per OS/arch target instead of using a single global Python 3.13: ubuntu-latest=3.13, ubuntu-24.04-arm=3.9, windows-latest=3.12, macos-14=3.10.
- Python setup switches from `actions/setup-python@v6` to `astral-sh/setup-uv@v6.7.0` with `activate-environment: true`, and package installation migrates from `pip install -v ".[test]"` to `uv pip install --reinstall --verbose -e ".[test]"`.
- CI step ordering is cleaned up: checkout comes first, then git log, then env detection, then C++ tests, then Python setup and tests.

## Impact
- API: none
- Behavioral: CI now tests against Python 3.9, 3.10, 3.12, and 3.13 across 4 platforms, catching version-specific regressions that were previously invisible. The `uv` tool replaces `pip` for CI package installation.
- Flags/config: `matrix.python_version` is a new matrix variable in `.github/workflows/ci_test.yml`. `astral-sh/setup-uv` replaces `actions/setup-python`.
