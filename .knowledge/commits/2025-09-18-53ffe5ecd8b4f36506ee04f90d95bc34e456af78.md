# Restrict stride normalization in toDLPackImpl to 1D single-element tensors only

## TL;DR

- Fixes over-broad stride normalization in the PyTorch C extension (`_optional_torch_c_dlpack.py`) that incorrectly modified strides on multi-dimensional tensors with size-1 dims.
- Before the fix, any dimension where `size == 1 && stride != expected_stride` triggered normalization; now only `ndim == 1 && size(0) == 1 && stride(0) != 1` does.
- Addresses PyTorch issue [#163274](https://github.com/pytorch/pytorch/issues/163274).

## Key Exports

```python
# python/tvm_ffi/_optional_torch_c_dlpack.py — toDLPackImpl (C++ embedded in py file)

# BEFORE (buggy):
# bool need_normalize_strides = false
# for i in range(ndim - 1, -1, -1):
#     if stride(i) != expected_stride and size(i) == 1:
#         need_normalize_strides = True; break
#     expected_stride *= size(i)
# if need_normalize_strides:
#     strides = src.strides().vec()
#     for i in range(ndim):
#         if shape[i] < 2: strides[i] = 1
#     view = src.as_strided(shape, strides, src.storage_offset())

# AFTER (fixed):
# bool need_normalize_strides = (ndim == 1) and (size(0) == 1) and (stride(0) != 1)
# if need_normalize_strides:
#     view = src.as_strided(shape, {1}, src.storage_offset())

# Invariant (restored): stride normalization is only attempted for
#   1D single-element tensors (ndim==1, size[0]==1) with a non-unit stride.
#   Multi-dimensional tensors are exported as-is; callers must pass
#   contiguous or explicitly-strided tensors.
# Interacts with: at::Tensor.as_strided, DLManagedTensorVersioned.dl_tensor.strides,
#   TVMFFIPyArgSetter.c_dlpack_from_pyobject (which calls toDLPackImpl)
```

## Impact

- API: None — no public Python or C ABI surface changed.
- Behavioral: `toDLPackImpl` no longer normalizes strides on multi-dimensional tensors that happen to have a size-1 dimension with non-contiguous stride. Those tensors are now exported with their actual strides unchanged. This is the correct behavior per the DLPack contract (strides must match the actual memory layout).
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

**Before/after pattern showing the bug and the fix:**

```cpp
// 2D tensor with a size-1 first dim and non-contiguous stride (e.g., a view):
// shape = [1, 512], strides = [1024, 1]
//
// BEFORE (buggy): loop detects dim 0 has size==1 and stride(0)=1024 != expected_stride=512
//   → need_normalize_strides = true
//   → strides normalized to [1, 1]    ← WRONG: corrupts second-dim stride
//   → view = src.as_strided([1, 512], [1, 1], offset)
//   → DLPack tensor reports strides [1, 1] but memory layout is [1024, 1]
//
// AFTER (fixed): ndim==2, so condition (ndim==1) is false
//   → need_normalize_strides = false
//   → strides remain [1024, 1]        ← CORRECT: matches actual memory layout
//   → DLPack tensor reports strides [1024, 1]

// Only case that still normalizes (ndim==1, size[0]==1, stride[0]!=1):
// shape = [1], strides = [42]
//   → need_normalize_strides = true (stride is irrelevant for a single element)
//   → view = src.as_strided([1], {1}, offset)   ← safe: single element, stride irrelevant
```
