# Restrict stride normalization in toDLPackImpl to 1D shape-[1] tensors only

## TL;DR
- The `toDLPackImpl` C++ template (embedded in `_optional_torch_c_dlpack.py`) previously iterated all dimensions to normalize strides of any size-1 axis before DLPack export; this was incorrect for multi-dimensional tensors and could produce semantically wrong DLPack representations.
- Fix: `need_normalize_strides` is now `true` only when `ndim == 1 && size(0) == 1 && stride(0) != 1`, restricting correction to the scalar-wrapped 1D case.
- The stride array passed to `as_strided` is simplified from a full per-dimension vector to the single-element `{1}`.

## Key Exports

```python
# C++ template function embedded in _optional_torch_c_dlpack.py (inline C++ string)
# template <class T>
def toDLPackImpl(src: Tensor) -> T:
    """Convert ATen Tensor to DLPack-managed tensor struct (DLManagedTensor or DLManagedTensorVersioned)."""
    # OLD invariant (violated): normalize strides for *any* dimension where size==1 but stride!=expected
    # NEW invariant: normalize strides ONLY for ndim==1 && size(0)==1 && stride(0)!=1
    # Interacts with: as_strided() (ATen), ATenDLMTensor<T>, fillVersion<T>
    # Invariant: after normalization, dl_tensor.strides must accurately represent memory layout
    # Invariant: multi-dimensional tensors are passed through unchanged (no stride mutation)
    need_normalize_strides: bool  # = src.ndim() == 1 and src.size(0) == 1 and src.stride(0) != 1
    ...
```

## Impact
- API: None — function signature unchanged.
- Behavioral: Stride normalization no longer fires for N-D tensors with size-1 axes other than the exact 1D shape-`[1]` case. Tensors that previously had their strides silently mutated during DLPack export will now export with their original strides.
- Flags/config: None.
- Data formats/schemas: DLPack `dl_tensor.strides` field is now correct for multi-dimensional tensors; previously it could contain incorrect normalized strides for axes with `size==1`.

## Usage Examples

**Before (incorrect — could normalize strides of multi-dimensional tensors):**
```python
# A 2D tensor shape=[2,1], strides=[5,5]:
# Old code: need_normalize_strides=True, then strides[1] set to 1 -> strides=[5,1]
# This changes semantics for the 2D tensor in the DLPack view.
t = torch.empty_strided((2, 1), (5, 5))
dlpack = torch.utils.dlpack.to_dlpack(t)  # via toDLPackImpl -> wrong strides exported
```

**After (correct — only 1D shape-[1] case is normalized):**
```python
# Same 2D tensor: need_normalize_strides=False -> strides=[5,5] exported as-is (correct)
# Only this case triggers normalization:
t = torch.empty_strided((1,), (5,))  # ndim=1, size(0)=1, stride(0)!=1
dlpack = torch.utils.dlpack.to_dlpack(t)  # stride normalized to 1 (safe for 1D scalar-like)
```
