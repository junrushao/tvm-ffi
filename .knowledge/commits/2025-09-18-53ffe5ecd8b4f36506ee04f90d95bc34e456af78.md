# Restrict stride normalization to 1D tensors on DLPack export
## TL;DR
- Restricts the stride normalization logic in `toDLPackImpl` (within `_optional_torch_c_dlpack.py`) to only apply to 1D tensors with `size(0)==1` and `stride(0)!=1`, fixing a bug where multi-dimensional tensors with unit-sized dimensions had their strides incorrectly rewritten.
- Addresses upstream PyTorch issue pytorch/pytorch#163274.

## Impact
- API: none (internal behavior fix)
- Flags/config: none
- Data formats/schemas: The exported `DLManagedTensorVersioned` now preserves the original strides for multi-dimensional tensors with size-1 dimensions, only normalizing the single degenerate case of a 1D scalar-like tensor.

## Design Elements
Design elements this commit consumes:
- **DLPack Exchange Acceleration** (`.knowledge/designs/0020-dlpack-exchange-acceleration.md`): The `toDLPackImpl` function is part of the JIT-compiled C++ extension that implements C-level DLPack export from PyTorch tensors.
