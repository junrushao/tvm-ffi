# Fix Map.get to throw KeyError instead of IndexError for missing keys
## TL;DR
- Changes `DenseMapObj::At` to throw `KeyError` instead of `IndexError` when a key is not found, aligning with Python `Mapping` protocol and ensuring `Map.get(key)` returns `None` for absent keys instead of raising.

## Impact
- API: `Map.__getitem__` now raises `KeyError` (was `IndexError`). `Map.get` now works correctly (previously the `IndexError` was not caught by the `Mapping.get` default implementation which catches `KeyError`).
- Flags/config: none
- Data formats/schemas: none
