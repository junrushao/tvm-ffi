# Add CUBIN launcher utility: header-only C++ CUDA kernel loader, Python NVRTC/embed tooling, and CMake integration
## TL;DR
- Introduces `include/tvm/ffi/extra/cuda/cubin_launcher.h`, a header-only C++ utility for loading CUBIN modules from memory and launching CUDA kernels via the CUDA Runtime API, with multi-GPU and dynamic shared memory support.
- Adds Python-side tooling: `tvm_ffi.cpp.nvrtc.nvrtc_compile()` for NVRTC compilation to CUBIN, and `tvm_ffi.utils.embed_cubin` CLI utility for merging CUBIN data into object files via `ld`/`objcopy`.
- Extends `build_inline`/`load_inline` with an `embed_cubin` parameter, enabling end-to-end Python-driven CUBIN compilation and embedding into JIT-compiled shared libraries.
- Adds CMake utilities (`tvm_ffi_generate_cubin`, `tvm_ffi_embed_cubin`) for static build workflows.

## Impact
- API: Additive. `build_inline`/`load_inline`/`build` gain optional `embed_cubin` parameter. New `tvm_ffi.cpp.nvrtc` module. New `tvm_ffi.utils.embed_cubin` CLI utility. CMake config now exports `EmbedCubin.cmake`.
- Behavioral: None -- all existing APIs unchanged when `embed_cubin` is not passed.
- Flags/config: None.
- Data formats/schemas: Introduces `__tvm_ffi__cubin_<name>` / `__tvm_ffi__cubin_<name>_end` symbol naming convention for embedded CUBIN data in object files.

## Design Elements
Design elements this commit consumes:
- **0014-ffi-load-inline**: Extends `build_inline`/`load_inline`/`_build_impl`/`_generate_ninja_build`/`_hash_sources` with `embed_cubin` parameter. Uses existing Ninja build driver, content-hash cache, and `FileLock` infrastructure.
- **0011-ffi-module-system**: Uses `load_module()` to load the compiled shared library containing embedded CUBIN.
- **0005-ffi-error-protocol**: Uses `TVM_FFI_THROW(RuntimeError)` for CUDA error reporting.
- **0013-ffi-packaging-and-distribution**: Uses `TVM_FFI_DLL_EXPORT_TYPED_FUNC` for exporting host-side wrapper functions. CMake `find_package(tvm_ffi)` now provides `tvm_ffi_embed_cubin` utility.
- **0006-ffi-containers**: `TensorView` used in kernel wrapper signatures (recommended approach for CUDA kernel host wrappers).

Design elements this commit produces:
- **CUBIN launcher C++ API**: `CubinModule`, `CubinKernel`, `dim3` classes; `TVM_FFI_EMBED_CUBIN` / `TVM_FFI_EMBED_CUBIN_GET_KERNEL` / `TVM_FFI_CHECK_CUDA_ERROR` macros. Header-only, not compiled into `libtvm_ffi.so`.
- **Symbol naming convention**: `__tvm_ffi__cubin_<name>` / `__tvm_ffi__cubin_<name>_end` for embedded CUBIN data, created by `ld -r -b binary` + `objcopy --redefine-sym`.
- **NVRTC compilation utility**: `tvm_ffi.cpp.nvrtc.nvrtc_compile()` for runtime CUDA-to-CUBIN compilation.
- **CUBIN embedding utility**: `tvm_ffi.utils.embed_cubin` (Python function + CLI) for merging CUBIN data into object files.
- **CMake CUBIN utilities**: `tvm_ffi_generate_cubin` and `tvm_ffi_embed_cubin` functions for static build workflows.
- **Ninja build pipeline extension**: `merge_objects` and `embed_cubin` ninja rules for multi-step CUBIN embedding during JIT builds.

## Usage Examples

**End-to-end: compile CUDA kernel, embed CUBIN, launch from Python via load_inline**
```python
import torch
from tvm_ffi import cpp
from tvm_ffi.cpp import nvrtc

# 1. Compile CUDA kernel to CUBIN at runtime
cuda_source = 'extern "C" __global__ void add_one(float* x, float* y, int n) { ... }'
cubin_bytes = nvrtc.nvrtc_compile(cuda_source)

# 2. Write C++ wrapper using TVM_FFI_EMBED_CUBIN macros
cpp_wrapper = """
#include <tvm/ffi/extra/cuda/cubin_launcher.h>
TVM_FFI_EMBED_CUBIN(my_cubin);

void AddOne(tvm::ffi::TensorView x, tvm::ffi::TensorView y) {
  static auto kernel = TVM_FFI_EMBED_CUBIN_GET_KERNEL(my_cubin, "add_one");
  int64_t n = x.size(0);
  void* x_ptr = x.data_ptr(); void* y_ptr = y.data_ptr();
  void* args[] = {&x_ptr, &y_ptr, &n};
  kernel.Launch(args, tvm::ffi::dim3((n+255)/256), tvm::ffi::dim3(256), stream);
}
"""

# 3. JIT compile with embedded CUBIN
mod = cpp.load_inline("my_mod", cuda_sources=cpp_wrapper,
                       embed_cubin={"my_cubin": cubin_bytes})

# 4. Call
x = torch.arange(1024, dtype=torch.float32, device="cuda")
y = torch.empty_like(x)
mod.add_one(x, y)
```

**CMake static build workflow (from `cmake/Utils/EmbedCubin.cmake`)**
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
find_package(CUDAToolkit REQUIRED)

tvm_ffi_generate_cubin(OUTPUT ${CMAKE_CURRENT_BINARY_DIR}/kernel.cubin
                        SOURCE src/kernel.cu  ARCH native)
tvm_ffi_embed_cubin(OUTPUT ${CMAKE_CURRENT_BINARY_DIR}/lib_with_cubin.o
                     SOURCE src/lib.cc  CUBIN ${CMAKE_CURRENT_BINARY_DIR}/kernel.cubin
                     NAME my_kernels)

add_library(mylib SHARED ${CMAKE_CURRENT_BINARY_DIR}/lib_with_cubin.o)
target_link_libraries(mylib PRIVATE tvm_ffi_header CUDA::cudart)
```
