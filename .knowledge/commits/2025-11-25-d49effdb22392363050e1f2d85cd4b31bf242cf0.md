# Add CUBIN launcher header-only utility with Python/CMake embedding support

## TL;DR
- Adds `include/tvm/ffi/extra/cuda/cubin_launcher.h`, a header-only C++ utility wrapping CUDA Runtime API to load CUBIN modules from memory and launch kernels, with multi-GPU support and shared memory configuration.
- Adds `TVM_FFI_EMBED_CUBIN` / `TVM_FFI_EMBED_CUBIN_GET_KERNEL` macros for compile-time CUBIN embedding via symbol injection (`__tvm_ffi__cubin_<name>` / `__tvm_ffi__cubin_<name>_end`).
- Adds three embedding pipelines: CMake utility (`tvm_ffi_embed_cubin`), Python CLI utility (`tvm_ffi.utils.embed_cubin`), and `load_inline(..., embed_cubin=...)` parameter for seamless Python-driven JIT embedding.
- Adds `tvm_ffi.cpp.nvrtc` module for NVRTC-based CUDA source to CUBIN compilation.

## Impact
- API: Additive only. `build_inline` and `load_inline` gain a new optional `embed_cubin` parameter (backward-compatible).
- Behavioral: `_generate_ninja_build` now uses a 3-step object merge pipeline when `embed_cubin` is provided (merge -> embed -> link) instead of direct object-to-shared-lib linking. `_hash_sources` refactored to recursive `_hash` function supporting `bytes` type.
- Flags/config: None.
- Data formats/schemas: Introduces `__tvm_ffi__cubin_<name>` / `__tvm_ffi__cubin_<name>_end` symbol naming convention for embedded CUBIN data (extends the `__tvm_ffi__` internal symbol namespace from [ADR 0010](../ADRs/0010-ffi-symbol-prefix-convention.md)).

## Usage Examples

**End-to-end: NVRTC compile + load_inline with embedded CUBIN (Python -> C++ -> CUDA)**

```python
from tvm_ffi import cpp
from tvm_ffi.cpp import nvrtc

# 1. Compile CUDA kernel to CUBIN at runtime
cuda_source = 'extern "C" __global__ void add_one(float* x, float* y, int n) { ... }'
cubin_bytes = nvrtc.nvrtc_compile(cuda_source, name="kernel.cu")

# 2. Write C++ wrapper using TVM_FFI_EMBED_CUBIN macros
cpp_wrapper = """
#include <tvm/ffi/extra/cuda/cubin_launcher.h>
TVM_FFI_EMBED_CUBIN(my_cubin);
void AddOne(tvm::ffi::TensorView x, tvm::ffi::TensorView y) {
  static auto kernel = TVM_FFI_EMBED_CUBIN_GET_KERNEL(my_cubin, "add_one");
  int64_t n = x.size(0);
  void* x_ptr = x.data_ptr(); void* y_ptr = y.data_ptr();
  void* args[] = {&x_ptr, &y_ptr, &n};
  kernel.Launch(args, tvm::ffi::dim3((n + 255) / 256), tvm::ffi::dim3(256), stream);
}
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, AddOne);
"""

# 3. Build + load with embedded CUBIN
mod = cpp.load_inline("my_module", cuda_sources=cpp_wrapper,
                       embed_cubin={"my_cubin": cubin_bytes})
mod.add_one(x_cuda, y_cuda)
```

**C++ direct usage (without embedding)**

```cpp
#include <tvm/ffi/extra/cuda/cubin_launcher.h>
tvm::ffi::CubinModule module(cubin_bytes);
tvm::ffi::CubinKernel kernel = module["my_kernel"];
void* args[] = {&data_ptr, &n};
cudaError_t result = kernel.Launch(args, tvm::ffi::dim3(32), tvm::ffi::dim3(256), stream);
TVM_FFI_CHECK_CUDA_ERROR(result);
```
