# Add cubin launcher utility header, NVRTC Python helper, CMake embedding utilities, and examples

## TL;DR
- Adds `include/tvm/ffi/extra/cuda/cubin_launcher.h` (622 lines): a self-contained C++ header for loading CUDA CUBIN modules and launching kernels using CUDA Driver API, supporting multi-GPU via primary contexts and embedded CUBIN via `TVM_FFI_EMBED_CUBIN` macro.
- Adds `python/tvm_ffi/cpp/nvrtc.py`: Python wrapper for NVRTC to compile CUDA source to CUBIN bytes at runtime.
- Adds `cmake/Utils/EmbedCubin.cmake`: `tvm_ffi_generate_cubin` + `tvm_ffi_embed_cubin` CMake functions for compile-time CUBIN embedding; `python/tvm_ffi/utils/embed_cubin.py` provides the Python CLI equivalent.
- Includes full example set (`examples/cubin_launcher/`) and Sphinx doc page (`docs/guides/cubin_launcher.rst`).

## Impact
- API: New header-only `cubin_launcher.h` (additive). New Python modules `nvrtc.py`, `embed_cubin.py` (additive). New CMake utilities (additive). No existing APIs changed.
- Behavioral: none for existing code
- Flags/config: `CUDA version > 13.0` required for cubin_launcher tests (CUDA 13+ Driver API features assumed). CI skip guard added.
- Data formats/schemas: Embedded CUBIN symbols follow `__tvm_ffi__cubin_<name>` / `__tvm_ffi__cubin_<name>_end` naming convention.

## Design Elements
Design elements this commit consumes:
- `0012-env-api`: `TVMFFIEnvGetStream` used in `launch_kernel` for default CUDA stream.
- `0005-error-system`: `TVM_FFI_THROW(RuntimeError)` used in `TVM_FFI_CHECK_CUDA_ERROR`.
- `0011-module-system`: CUBIN loading pattern mirrors the `.so` module loading pattern; `__tvm_ffi__` symbol prefix convention extended to CUBIN data symbols.
- `0015-load-inline`: `nvrtc_compile` complements `load_inline`; `_hash_sources` in `extension.py` extended to handle `bytes` and `Mapping[str, bytes]` for CUBIN embedding.
- `0021-build-packaging`: `tvm_ffi_embed_cubin` CMake function registered in `cmake/tvm_ffi-config.cmake`.

Design elements this commit produces:
- **`CubinModule` / `TVM_FFI_EMBED_CUBIN`**: New pattern for compile-time CUBIN embedding with lazy multi-device loading. Key invariant: module is loaded once per device, shared across calls.
- **`nvrtc_compile()`**: New Python entry point for NVRTC-based runtime CUDA compilation returning `bytes`.
- **`tvm_ffi_generate_cubin` / `tvm_ffi_embed_cubin`** CMake functions: standard build pipeline for CUBIN embedding.
- **`TVM_FFI_CHECK_CUDA_ERROR` macro**: re-exported in `cubin_launcher.h` (note: also defined in `base.h` added by companion commit cdfd04109f74).

## Usage Examples

```cpp
// C++ kernel library with embedded CUBIN
#include <tvm/ffi/extra/cuda/cubin_launcher.h>

// Embed CUBIN from objcopy symbols (created by tvm_ffi_embed_cubin CMake function)
TVM_FFI_EMBED_CUBIN(my_kernels);  // declares static CubinModule instance

TVM_FFI_DLL_EXPORT_TYPED_FUNC(launch_add_one, [](ffi::TensorView x, ffi::TensorView out) {
    int device_id = x.device().device_id;
    CUfunction kernel = my_kernels_module.get_kernel(device_id, "add_one_kernel");
    launch_kernel(kernel, dim3(256), dim3(32), x, out);
});
```

```python
# Python: compile and load CUBIN at runtime
from tvm_ffi.cpp.nvrtc import nvrtc_compile
from tvm_ffi.cpp.extension import load_inline

cubin_bytes = nvrtc_compile(cuda_source, arch="sm_80")
mod = load_inline(..., embed_cubin={"my_kernels": cubin_bytes})
```
