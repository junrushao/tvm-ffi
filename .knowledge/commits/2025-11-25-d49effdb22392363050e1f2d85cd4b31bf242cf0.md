# Add cubin launcher utility header and NVRTC/embed tooling
## TL;DR
- Introduces `include/tvm/ffi/extra/cuda/cubin_launcher.h`, a header-only utility for loading and launching CUDA cubin kernels from byte buffers or files using CUDA Runtime API.
- Adds `python/tvm_ffi/cpp/nvrtc.py` for NVRTC-based runtime kernel compilation from Python.
- Adds `python/tvm_ffi/utils/embed_cubin.py` and `cmake/Utils/EmbedCubin.cmake` for embedding cubin into shared libraries at build time.
- Includes comprehensive examples (dynamic cubin, embedded cubin, NVRTC, Triton cubin) and documentation.

## Key Exports

**C++ Classes (cubin_launcher.h):**
- `CubinModule` -- Loads cubin from byte buffer or file, manages CUDA modules. Key methods: `LaunchKernel(name, grid, block, shared_mem, stream, args...)`.
- `CubinLauncher` -- Wraps a specific kernel in a cubin module with launch parameters.

**Python Modules:**
- `tvm_ffi.cpp.nvrtc` -- NVRTC wrapper for runtime CUDA kernel compilation.
- `tvm_ffi.utils.embed_cubin` -- Utility for embedding cubin data into C++ source files.

**CMake Modules:**
- `cmake/Utils/EmbedCubin.cmake` -- CMake function for embedding cubin files into shared libraries.

## Impact
- API: New `CubinModule`/`CubinLauncher` C++ classes. New `nvrtc` and `embed_cubin` Python modules.
- ABI: none (header-only utility, not compiled into main lib)
- Behavioral: none
- Flags/config: none
- Data formats/schemas: Cubin binary format loading.

## Design Elements
Design elements this commit consumes:
- Module system (`load_module`, `TVM_FFI_DLL_EXPORT_TYPED_FUNC`)
- Extension build infrastructure (`cpp/extension.py`)

Design elements this commit produces:
- **CubinModule/CubinLauncher pattern** -- Header-only CUDA kernel loading and launching utility.
- **Cubin embedding workflow** -- CMake + Python tooling for embedding compiled CUDA kernels into shared libraries.
- **NVRTC integration** -- Python wrapper for runtime CUDA compilation.

## Usage Examples
```cpp
#include <tvm/ffi/extra/cuda/cubin_launcher.h>
// Load and launch a kernel
tvm::ffi::extra::CubinModule mod(cubin_data, cubin_size);
mod.LaunchKernel("my_kernel", {grid_x, grid_y, grid_z},
                 {block_x, block_y, block_z}, shared_mem, stream,
                 arg0, arg1);
```
