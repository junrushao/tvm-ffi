# Add CUBIN launcher utility header and Python NVRTC/embed support
## TL;DR
- Adds `include/tvm/ffi/extra/cuda/cubin_launcher.h` (622 lines): a header-only CUDA Runtime API utility for loading CUBIN from memory/file and launching kernels with `CubinModule`/`CubinKernel` abstractions.
- Adds CMake utility `cmake/Utils/EmbedCubin.cmake` for embedding CUBIN as C arrays in shared libraries.
- Adds Python utilities: `python/tvm_ffi/cpp/nvrtc.py` for NVRTC compilation, `python/tvm_ffi/utils/embed_cubin.py` for CUBIN embedding.
- Extends `extension.py` with `embed_cubin` parameter for `load_inline`/`build_inline`.
- Comprehensive documentation (`docs/guides/cubin_launcher.rst`), examples (`examples/cubin_launcher/`), and tests.
- Benchmark shows 2.41x faster kernel launch vs Triton (2.034 vs 4.911 us/call).

## Impact
- API: New C++ header `cubin_launcher.h`, new Python APIs `nvrtc.nvrtc_compile()`, `embed_cubin` parameter, new macros `TVM_FFI_EMBED_CUBIN`, `TVM_FFI_EMBED_CUBIN_GET_KERNEL`
- Flags/config: New CMake function `EmbedCubin`
- Data formats/schemas: None
