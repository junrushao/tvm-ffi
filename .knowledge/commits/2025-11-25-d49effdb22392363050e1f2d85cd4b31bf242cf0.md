# Add cubin launcher utility header and Python NVRTC/embed_cubin support
## TL;DR
- Adds `include/tvm/ffi/extra/cuda/cubin_launcher.h` — a header-only CUDA Driver API utility for loading cubin from bytes/file and launching kernels.
- Adds `python/tvm_ffi/cpp/nvrtc.py` — Python wrapper for NVRTC compilation of CUDA source to cubin.
- Adds `python/tvm_ffi/utils/embed_cubin.py` — utilities for embedding cubin data into C++ sources.
- Extends `load_inline()` with `embed_cubin` parameter to embed compiled cubin blobs into JIT-compiled modules.
- Adds CMake `EmbedCubin.cmake` module for static cubin embedding in CMake-based builds.
- Adds comprehensive documentation, examples, and benchmarks.

## Impact
- API: new header `tvm/ffi/extra/cuda/cubin_launcher.h`, new Python modules `tvm_ffi.cpp.nvrtc` and `tvm_ffi.utils.embed_cubin`, extended `load_inline()` API
- Behavioral: enables cubin-based kernel launching with 2.4x lower launch overhead vs Triton (per benchmark)
- Flags/config: none
- Data formats/schemas: embedded cubin format (C array of bytes)

## Usage Examples
```python
import torch
from tvm_ffi.cpp import nvrtc, load_inline

cuda_source = 'extern "C" __global__ void add_one(float* x, float* y, int n) { ... }'
cubin = nvrtc.nvrtc_compile(cuda_source)

cpp_wrapper = '''
#include <tvm/ffi/extra/cuda/cubin_launcher.h>
TVM_FFI_EMBED_CUBIN(my_cubin);
void AddOne(tvm::ffi::TensorView x, tvm::ffi::TensorView y) {
  static auto kernel = TVM_FFI_EMBED_CUBIN_GET_KERNEL(my_cubin, "add_one");
  // ... launch kernel ...
}
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, AddOne);
'''
mod = load_inline("my_mod", cuda_sources=cpp_wrapper, embed_cubin={"my_cubin": cubin})
x = torch.randn(1024, device="cuda")
y = torch.empty_like(x)
mod.add_one(x, y)
```
