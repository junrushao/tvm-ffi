# Complete support of CHECK macros with all error kinds
## TL;DR
- Completes the CHECK macro family with `TVM_FFI_CHECK_*` variants for all standard error kinds
- Adds `TVM_FFI_ICHECK_*` internal check variants
- Includes comparison checks (EQ, NE, LT, GT, LE, GE) and simple boolean checks

## Key Exports
```python
# TVM_FFI_CHECK(cond, ErrorKind) << "message"  -- user-facing check
# TVM_FFI_CHECK_EQ(a, b, ErrorKind) << "message"  -- equality check
# TVM_FFI_CHECK_NE, TVM_FFI_CHECK_LT, TVM_FFI_CHECK_GT, TVM_FFI_CHECK_LE, TVM_FFI_CHECK_GE
# TVM_FFI_ICHECK(cond) << "message"  -- internal check (InternalError)
# TVM_FFI_ICHECK_EQ, TVM_FFI_ICHECK_NE, etc.
```

## Impact
- API: adds CHECK macro variants
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: Error propagation (0004)
Design elements this commit produces: Complete CHECK/ICHECK macro family
## Usage Examples
```cpp
TVM_FFI_CHECK(x > 0, ValueError) << "x must be positive, got " << x;
TVM_FFI_CHECK_EQ(a, b, TypeError) << "types must match";
TVM_FFI_ICHECK(ptr != nullptr) << "null pointer";
```
