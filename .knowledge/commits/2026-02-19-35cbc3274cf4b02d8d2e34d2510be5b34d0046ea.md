# Complete CHECK macro family with error-kind parameter and DCHECK variants

## TL;DR
- Generalizes `TVM_FFI_ICHECK*` macros into `TVM_FFI_CHECK*(x, y, ErrorKind)` macros that accept an arbitrary error kind (e.g., `ValueError`, `InternalError`), with the `ICHECK` variants now defined as thin wrappers passing `InternalError`.
- Introduces `TVM_FFI_DCHECK*` debug-check macros that are compiled out in release builds (`NDEBUG` defined), mirroring the full `ICHECK` family.
- Adds `TVM_FFI_CHECK_NOTNULL(x, ErrorKind)` for null-pointer checks with custom error kinds.

## Key Exports

**Macros (error.h):**

| Macro | Signature | Description |
|-------|-----------|-------------|
| `TVM_FFI_CHECK(cond, ErrorKind)` | condition + error kind | General condition check |
| `TVM_FFI_CHECK_LT(x, y, ErrorKind)` | binary comparison | `x < y` with formatted message |
| `TVM_FFI_CHECK_GT(x, y, ErrorKind)` | binary comparison | `x > y` |
| `TVM_FFI_CHECK_LE(x, y, ErrorKind)` | binary comparison | `x <= y` |
| `TVM_FFI_CHECK_GE(x, y, ErrorKind)` | binary comparison | `x >= y` |
| `TVM_FFI_CHECK_EQ(x, y, ErrorKind)` | binary comparison | `x == y` |
| `TVM_FFI_CHECK_NE(x, y, ErrorKind)` | binary comparison | `x != y` |
| `TVM_FFI_CHECK_NOTNULL(x, ErrorKind)` | pointer + error kind | Asserts non-null, returns `x` |
| `TVM_FFI_ICHECK(x)` | condition only | Shorthand for `CHECK(x, InternalError)` |
| `TVM_FFI_ICHECK_{LT,GT,LE,GE,EQ,NE}(x, y)` | binary | Shorthand for `CHECK_*(x, y, InternalError)` |
| `TVM_FFI_ICHECK_NOTNULL(x)` | pointer only | Shorthand for `CHECK_NOTNULL(x, InternalError)` |
| `TVM_FFI_DCHECK(x)` | condition only | Debug-only, compiled out under `NDEBUG` |
| `TVM_FFI_DCHECK_{LT,GT,LE,GE,EQ,NE}(x, y)` | binary | Debug-only comparison checks |
| `TVM_FFI_DCHECK_NOTNULL(x)` | pointer only | Debug-only null check (returns `x`) |

**Internal macro:**
- `TVM_FFI_CHECK_BINARY_OP(name, op, x, y, ErrorKind)` -- replaces former `TVM_FFI_ICHECK_BINARY_OP`

**DCHECK behavior under NDEBUG:**
- All `DCHECK` macros expand to `while (false) ICHECK(...)` which is dead code.
- Exception: `TVM_FFI_DCHECK_NOTNULL(x)` expands to just `(x)` (no check, still returns the pointer).

## Impact
- API: New `TVM_FFI_CHECK_*` and `TVM_FFI_DCHECK_*` macro families in `error.h`. Existing `TVM_FFI_ICHECK_*` macros unchanged in behavior (still produce `InternalError`), but are now implemented as wrappers around the new `CHECK_*` macros.
- Behavioral: none -- `ICHECK` behavior is identical. `DCHECK` is new functionality.
- Flags/config: `NDEBUG` controls whether `DCHECK` macros are active or compiled out.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Error handling system (`TVM_FFI_THROW`, error kinds) -- [design 0006](../designs/0006-error-handling.md)
- `LogCheck*` helper functions in `details` namespace

Design elements this commit produces:
- **Parameterized CHECK macro family** -- `TVM_FFI_CHECK_*(x, y, ErrorKind)` pattern enabling domain-specific error kinds for assertions (e.g., `TVM_FFI_CHECK_GE(idx, 0, IndexError)`)
- **Debug-only DCHECK family** -- `TVM_FFI_DCHECK_*` for performance-sensitive invariant checks that should not run in release builds

## Usage Examples
```cpp
// Custom error kind check
TVM_FFI_CHECK(idx >= 0, IndexError) << "Negative index";
TVM_FFI_CHECK_LT(idx, size, IndexError) << "Index out of bounds";

// Internal error check (unchanged API)
TVM_FFI_ICHECK_EQ(a, b) << "Values must match";

// Debug-only check (compiled out in release)
TVM_FFI_DCHECK_NOTNULL(ptr);
TVM_FFI_DCHECK_GE(size, 0) << "size invariant";
```
