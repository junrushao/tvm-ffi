# Complete support of CHECK macros with error kind parameter and DCHECK variants
## TL;DR
- Generalizes `TVM_FFI_ICHECK_*` macros into `TVM_FFI_CHECK_*(x, y, ErrorKind)` that accept an arbitrary error kind.
- Redefines `TVM_FFI_ICHECK_*` as wrappers around `TVM_FFI_CHECK_*(..., InternalError)`.
- Adds `TVM_FFI_DCHECK_*` debug-only variants that compile to no-ops under `NDEBUG`.

## Key Exports

```python
# C++ macro family (pseudocode):
# TVM_FFI_CHECK(cond, ErrorKind)  -- general condition check
# TVM_FFI_CHECK_EQ(x, y, ErrorKind)  -- equality check with custom error
# TVM_FFI_CHECK_LT/GT/LE/GE/NE(x, y, ErrorKind)  -- comparison checks
# TVM_FFI_CHECK_NOTNULL(x, ErrorKind)  -- null pointer check
# TVM_FFI_ICHECK_*(...)  -- InternalError variants (unchanged API)
# TVM_FFI_DCHECK_*(...)  -- debug-only, stripped in release builds
# Interacts with: TVM_FFI_THROW, Error system
# Invariant: DCHECK macros are no-ops when NDEBUG is defined
```

## Impact
- API: New `TVM_FFI_CHECK_*(..., ErrorKind)` and `TVM_FFI_DCHECK_*` macro families. Existing `TVM_FFI_ICHECK_*` unchanged.
- Behavioral: None for existing code.
- Flags/config: `NDEBUG` controls DCHECK behavior.
- Data formats/schemas: None

## Usage Examples
```cpp
TVM_FFI_CHECK_EQ(a, b, ValueError);  // throws ValueError if a \!= b
TVM_FFI_DCHECK_LT(idx, size);  // no-op in release builds
```
