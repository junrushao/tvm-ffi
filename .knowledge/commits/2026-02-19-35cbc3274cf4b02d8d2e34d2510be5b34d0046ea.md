# Add generalized TVM_FFI_CHECK_* and TVM_FFI_DCHECK_* macro families with configurable error kind

## TL;DR
- Introduces `TVM_FFI_CHECK_BINARY_OP(name, op, x, y, ErrorKind)` as a generalized binary-op assertion base that accepts any error kind, replacing the hardcoded-`InternalError` `TVM_FFI_ICHECK_BINARY_OP`.
- Adds `TVM_FFI_CHECK_*(x, y, ErrorKind)` family (EQ, NE, LT, GT, LE, GE, NOTNULL) for user-facing validation with caller-chosen error kind; refactors `TVM_FFI_ICHECK_*` to delegate to these with `InternalError`.
- Adds `TVM_FFI_DCHECK_*` family: active (delegates to ICHECK) in debug builds, no-ops (`while (false)`) in release (`NDEBUG` defined).

## Key Exports

```python
# TVM_FFI_CHECK_BINARY_OP(name, op, x, y, ErrorKind)
# Generalized binary assertion — the new canonical base macro.
# Replaces TVM_FFI_ICHECK_BINARY_OP (removed).
# Expands to:
#   if (auto err = ::tvm::ffi::details::LogCheck##name(x, y))
#       TVM_FFI_THROW(ErrorKind) << "Check failed: " #x " " #op " " #y << *err << ": "
# Interacts with: details::LogCheck{_EQ,_NE,_LT,_GT,_LE,_GE} helpers (return unique_ptr<string>)
# Interacts with: TVM_FFI_THROW (underlying throw mechanism)
# Invariant: evaluated left-to-right; ErrorKind is an unquoted token (macro-expanded to string by #ErrorKind)

# TVM_FFI_CHECK_EQ(x, y, ErrorKind)   → TVM_FFI_CHECK_BINARY_OP(_EQ, ==, x, y, ErrorKind)
# TVM_FFI_CHECK_NE(x, y, ErrorKind)   → TVM_FFI_CHECK_BINARY_OP(_NE, !=, x, y, ErrorKind)
# TVM_FFI_CHECK_LT(x, y, ErrorKind)   → TVM_FFI_CHECK_BINARY_OP(_LT, <,  x, y, ErrorKind)
# TVM_FFI_CHECK_GT(x, y, ErrorKind)   → TVM_FFI_CHECK_BINARY_OP(_GT, >,  x, y, ErrorKind)
# TVM_FFI_CHECK_LE(x, y, ErrorKind)   → TVM_FFI_CHECK_BINARY_OP(_LE, <=, x, y, ErrorKind)
# TVM_FFI_CHECK_GE(x, y, ErrorKind)   → TVM_FFI_CHECK_BINARY_OP(_GE, >=, x, y, ErrorKind)
# TVM_FFI_CHECK_NOTNULL(x, ErrorKind) → ((x) == nullptr ? TVM_FFI_THROW(ErrorKind) << "Check not null: " #x, (x) : (x))
# Invariant: NOTNULL returns (x) on success (expression, not statement)
# Extension: pass any error kind token (ValueError, IndexError, TypeError, etc.) — no code changes needed

# TVM_FFI_ICHECK(x)         → TVM_FFI_CHECK(x, InternalError)          [backward-compat alias]
# TVM_FFI_ICHECK_EQ(x, y)   → TVM_FFI_CHECK_EQ(x, y, InternalError)    [backward-compat alias]
# TVM_FFI_ICHECK_NE(x, y)   → TVM_FFI_CHECK_NE(x, y, InternalError)    [backward-compat alias]
# TVM_FFI_ICHECK_LT(x, y)   → TVM_FFI_CHECK_LT(x, y, InternalError)    [backward-compat alias]
# TVM_FFI_ICHECK_GT(x, y)   → TVM_FFI_CHECK_GT(x, y, InternalError)    [backward-compat alias]
# TVM_FFI_ICHECK_LE(x, y)   → TVM_FFI_CHECK_LE(x, y, InternalError)    [backward-compat alias]
# TVM_FFI_ICHECK_GE(x, y)   → TVM_FFI_CHECK_GE(x, y, InternalError)    [backward-compat alias]
# TVM_FFI_ICHECK_NOTNULL(x) → TVM_FFI_CHECK_NOTNULL(x, InternalError)  [backward-compat alias]

# TVM_FFI_DCHECK_* family — debug-only assertions
# When NDEBUG is NOT defined (debug build):
#   TVM_FFI_DCHECK(x)        → TVM_FFI_ICHECK(x)
#   TVM_FFI_DCHECK_EQ(x, y)  → TVM_FFI_ICHECK_EQ(x, y)
#   ... (all 8 variants delegate to ICHECK equivalents)
# When NDEBUG IS defined (release build):
#   TVM_FFI_DCHECK(x)         → while (false) TVM_FFI_ICHECK(x)      [dead code, zero overhead]
#   TVM_FFI_DCHECK_EQ(x, y)   → while (false) TVM_FFI_ICHECK_EQ(x, y)
#   ... (all binary op variants: while(false) wrapper)
#   TVM_FFI_DCHECK_NOTNULL(x) → (x)   [special: returns x directly, no while(false)]
# Invariant: DCHECK_NOTNULL in release just evaluates (x) — still evaluates the expression
# Interacts with: NDEBUG compile flag (standard C/C++ release flag)
# Extension: use DCHECK_* instead of ICHECK_* for performance-critical paths that are safe to skip in release
```

## Impact
- API: Adds `TVM_FFI_CHECK_BINARY_OP`, `TVM_FFI_CHECK_{EQ,NE,LT,GT,LE,GE,NOTNULL}`, `TVM_FFI_DCHECK{_EQ,_NE,_LT,_GT,_LE,_GE,_NOTNULL,}` to `include/tvm/ffi/error.h`. All existing `TVM_FFI_ICHECK_*` callers continue to work without changes.
- Behavioral: `TVM_FFI_ICHECK_BINARY_OP` is removed as a user-visible macro (it was a private implementation detail); callers using it directly must switch to `TVM_FFI_CHECK_BINARY_OP` with `InternalError`.
- Flags/config: `NDEBUG` now controls whether `TVM_FFI_DCHECK_*` assertions are live or dead; no new CMake/build flags.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_THROW(ErrorKind)` (0005-error-system) — underlying throw mechanism used by all expanded macros.
- `details::LogCheck{_EQ,_NE,_LT,_GT,_LE,_GE}` template helpers (0005-error-system) — return `unique_ptr<string>` with `"(x vs. y)"` diff message; unchanged.
- `TVM_FFI_CHECK(cond, ErrorKind)` (0005-error-system) — reused as the base for `TVM_FFI_ICHECK` delegation.

Design elements this commit produces:
- `TVM_FFI_CHECK_BINARY_OP(name, op, x, y, ErrorKind)` — generalized binary assertion base macro with configurable error kind.
- `TVM_FFI_CHECK_{EQ,NE,LT,GT,LE,GE,NOTNULL}` family — user-facing binary assertions with caller-specified error kind.
- `TVM_FFI_DCHECK_*` family — debug-only assertion variants, no-ops in NDEBUG builds.
- Refactored `TVM_FFI_ICHECK_*` delegation chain — ICHECK macros now delegate to CHECK macros (rather than having independent implementations).

## Usage Examples

**User-facing validation with specific error kind (C++):**
```cpp
// Before this commit: binary op assertions were only available with InternalError
// After: any error kind can be specified

// Range check that raises IndexError (not InternalError):
TVM_FFI_CHECK_LT(index, size, IndexError) << "Index out of bounds";

// Type assertion raises TypeError:
TVM_FFI_CHECK_EQ(actual_dtype, expected_dtype, TypeError)
    << "dtype mismatch in op " << op_name;

// Null-check that raises ValueError, returning the pointer on success:
auto* ptr = TVM_FFI_CHECK_NOTNULL(maybe_null_ptr, ValueError);
```

**Debug-only assertions (stripped in release):**
```cpp
// These are zero-overhead in NDEBUG builds:
TVM_FFI_DCHECK_EQ(lhs_shape[0], rhs_shape[0]);  // throws InternalError in debug only
TVM_FFI_DCHECK(invariant_holds);                 // no-op in release
```
