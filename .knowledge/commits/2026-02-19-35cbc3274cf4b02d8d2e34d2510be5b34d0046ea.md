# Complete CHECK macro family: add ErrorKind-parameterized variants and DCHECK suite

## TL;DR
- Refactors `TVM_FFI_ICHECK_BINARY_OP` into `TVM_FFI_CHECK_BINARY_OP(name, op, x, y, ErrorKind)` so any error kind can be used with comparison checks.
- Adds `TVM_FFI_CHECK_{LT,GT,LE,GE,EQ,NE,NOTNULL}(x, y, ErrorKind)` family, with `TVM_FFI_ICHECK_*` aliases hardcoded to `InternalError`.
- Adds `TVM_FFI_DCHECK_*` family stripped in release builds (`#ifndef NDEBUG`), forwarding to the corresponding `ICHECK_*` macros.

```python
# TVM_FFI_CHECK_NE(x, y, ErrorKind)
# TVM_FFI_CHECK_NOTNULL(x, ErrorKind)   -- was TVM_FFI_ICHECK_NOTNULL (InternalError hardcoded)

# InternalError aliases (now thin wrappers, same behavior as before):
# TVM_FFI_ICHECK(x)             = TVM_FFI_CHECK(x, InternalError)
# TVM_FFI_ICHECK_{LT,GT,...}(x,y) = TVM_FFI_CHECK_{LT,...}(x, y, InternalError)
# TVM_FFI_ICHECK_NOTNULL(x)    = TVM_FFI_CHECK_NOTNULL(x, InternalError)

# Debug variants (NEW, stripped when NDEBUG is defined):
# TVM_FFI_DCHECK(x)             -> TVM_FFI_ICHECK(x) if DEBUG, noop if NDEBUG
# TVM_FFI_DCHECK_{LT,GT,LE,GE,EQ,NE}(x,y)  -- forwarding pattern
# TVM_FFI_DCHECK_NOTNULL(x)    -> (x) if NDEBUG (returns value, no check)
# Invariant: DCHECK_NOTNULL is the only DCHECK that evaluates `x` in release.
```

## Impact
- API: `TVM_FFI_ICHECK_BINARY_OP` removed and replaced by `TVM_FFI_CHECK_BINARY_OP`. Any code directly invoking `TVM_FFI_ICHECK_BINARY_OP` (not via `TVM_FFI_ICHECK_EQ` etc.) would break — but this is an internal implementation macro unlikely to be used directly.
- Behavioral: `TVM_FFI_ICHECK_*` macros now delegate to `TVM_FFI_CHECK_*` — identical behavior. DCHECK variants are functionally new.
- Flags/config: `NDEBUG` preprocessor flag now gates DCHECK behavior.
- Data formats/schemas: none

## Usage Examples

```cpp
// Before: only InternalError possible with binary checks
TVM_FFI_ICHECK_EQ(x, y) << "mismatch";

// After: any error kind
TVM_FFI_CHECK_EQ(x, expected, ValueError) << "bad input value";

// Debug-only check (stripped in release):
TVM_FFI_DCHECK_GE(index, 0) << "negative index";
TVM_FFI_DCHECK_NOTNULL(ptr);  // no-op in NDEBUG, evaluates ptr in both modes
```
