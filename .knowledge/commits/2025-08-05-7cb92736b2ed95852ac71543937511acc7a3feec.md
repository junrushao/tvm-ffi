# Add reflection-based ObjectCreator and Shape serialization support
## TL;DR
- Introduces `reflection::ObjectCreator`, a new class that creates objects from `Map<String, Any>` field maps using reflection metadata (complementary to the existing packed-args `MakeObjectFromPackedArgs`).
- Adds Shape serialization/deserialization support to `ObjectGraphSerializer`/`ObjectGraphDeserializer`, encoding shapes as `{"type": "ffi.Shape", "data": [dim0, ...]}`.
- Relaxes `CreateObjectData` return type from `json::Object` to `json::Value`, enabling custom `__data_to_json__` serializers to return non-object JSON values.

Note: The commit message describes phasing out `TVM_REGISTER_NODE` and `TVM_REGISTER_OBJECT`, but the actual diff does not enact that removal -- those are aspirational goals for follow-up work.

## Impact
- API: New public header `include/tvm/ffi/reflection/creator.h` with `ObjectCreator` class. Internal `CreateObjectData` return type widened from `json::Object` to `json::Value`.
- Behavioral: Shape objects can now be round-tripped through JSON serialization. Custom `__data_to_json__` serializers can return any JSON value type (previously forced to `json::Object`).
- Flags/config: None.
- Data formats/schemas: Shape JSON format added: `{"type": "ffi.Shape", "data": [1, 2, 3]}`. This is additive -- no existing formats changed.

- **Serialization**: `TypeAttrColumn("__data_to_json__")` dispatch for custom serializers.

Design elements this commit produces:
- **`reflection::ObjectCreator`**: New public class for map-based reflection object creation. Distinct from `MakeObjectFromPackedArgs` (positional packed args) -- `ObjectCreator` uses a `Map<String, Any>` providing named fields.
- **Shape serialization protocol**: New ser/deser cases in the JSON graph serializer for `TypeIndex::kTVMFFIShape`.
- **Relaxed custom serializer contract**: `__data_to_json__` attribute functions may now return any `json::Value`, not just `json::Object`.

## Usage Examples

**Context**: Creating an object from a field map using `ObjectCreator`, and round-tripping a Shape through JSON serialization.

```cpp
// ObjectCreator: construct an object from named fields
namespace refl = tvm::ffi::reflection;
refl::ObjectCreator creator("test.Int");
Any obj = creator(Map<String, Any>({{"value", 1}}));
// obj is now a TInt with value == 1

// Shape serialization round-trip
Shape shape({1, 2, 3});
json::Value json = ToJSONGraph(shape);
// json == {"root_index": 0, "nodes": [{"type": "ffi.Shape", "data": [1, 2, 3]}]}
Shape restored = FromJSONGraph(json).cast<Shape>();
// StructuralEqual()(shape, restored) == true
```
