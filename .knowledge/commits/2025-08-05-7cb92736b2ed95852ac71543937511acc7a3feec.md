# Add ObjectCreator for reflection-based construction from field map; add Shape serialization support

## TL;DR
- Introduces `reflection::ObjectCreator` (`include/tvm/ffi/reflection/creator.h`): a reflection-driven factory that constructs any registered `Object` subtype from a `Map<String, Any>` of field name→value pairs, using `TVMFFITypeMetadata.creator` + field setters from the reflection registry.
- Extends the JSON serializer/deserializer (`src/ffi/extra/serialization.cc`) with a dedicated `ffi.Shape` encode/decode path; relaxes `CreateObjectData`'s return type from `json::Object` to `json::Value` so custom `__data_to_json__` handlers can return non-object JSON.
- Renames `tests/cpp/test_reflection_accessor.cc` → `tests/cpp/test_reflection.cc`; adds `TIntObj() = default` default constructor (required by `ObjectCreator`) to `testing_object.h`.

## Impact
- API: `reflection::ObjectCreator` is a new public class in `include/tvm/ffi/reflection/creator.h`. No existing public API is changed or removed.
- Behavioral: Shape values now round-trip through `ToJSONGraph`/`FromJSONGraph`. Previously, a `ffi.Shape` fell through to the generic object path (which may have failed or produced incorrect output).
- Flags/config: none
- Data formats/schemas: JSON graph node format gains a new type `"ffi.Shape"` with `"data": [int64_t, ...]`. Existing nodes are unaffected. Custom `__data_to_json__` handlers can now return non-object JSON (previously the return was cast to `json::Object`, which would throw for non-object returns).

## Design Elements
Design elements this commit consumes:
- `0006-reflection`: `ForEachFieldInfo`, `TVMFFIFieldInfo` (offset/setter/flags/default_value), `TVMFFITypeMetadata.creator`, `kTVMFFIFieldFlagBitMaskHasDefault` — `ObjectCreator` is a new consumer of the full field-iteration and creator registration path.
- `0006-reflection`: `TypeAttrColumn("__data_to_json__")` — serialization reads this column per type_index to dispatch custom JSON serialization.
- `0007-containers`: `ffi::Shape` (type index `kTVMFFIShape`, type key `"ffi.Shape"`) — new serialization case; `ffi::Shape(Array<int64_t>)` constructor used in deserialize path.
- `0002-object-system`: `ObjectUnsafe::ObjectPtrFromOwned` — wraps raw `TVMFFIObjectHandle` from `creator()` into a managed `ObjectPtr<Object>`.
- `0009-structural-eq-hash`: `StructuralEqual` — used in serialization tests to compare round-tripped values.

Design elements this commit produces:
- **`reflection::ObjectCreator`** (new) — a reflection-driven named-field constructor not previously in the reflection subsystem. Extends the construction capability alongside the existing positional `MakeObjectFromPackedArgs` (registered global). Both rely on `TVMFFITypeMetadata.creator`; `ObjectCreator` uses named fields while `MakeObjectFromPackedArgs` uses positional packed args.

## Usage Examples

**`ObjectCreator` construction from named fields** (from `tests/cpp/test_reflection.cc`):

```cpp
namespace refl = tvm::ffi::reflection;

// Create an ObjectCreator for type "test.Int" (which has a default constructor)
refl::ObjectCreator creator("test.Int");

// Construct a TInt by providing the "value" field by name
Any result = creator(Map<String, Any>({{"value", 1}}));
TInt obj = result.cast<TInt>();
assert(obj->value == 1);
```

**Shape serialization round-trip** (from `tests/cpp/extra/test_serialization.cc`):

```cpp
Shape shape({1, 2, 3});

// Serialize to JSON graph
json::Object serialized = ToJSONGraph(shape);
// → {"root_index": 0,
//    "nodes": [{"type": "ffi.Shape", "data": [1, 2, 3]}]}

// Deserialize back
Any restored = FromJSONGraph(serialized);
assert(StructuralEqual()(restored, shape));  // true
```
