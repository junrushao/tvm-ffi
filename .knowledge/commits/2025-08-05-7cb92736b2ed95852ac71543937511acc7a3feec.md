# Add ObjectCreator helper and extend serialization with Shape support and relaxed CreateObjectData return type

## TL;DR
- Introduces `reflection::ObjectCreator` — a reflection-based helper class that constructs any reflected `Object` type from a `Map<String, Any>` of field values, including required-field and unknown-field validation.
- Extends the JSON serialization layer to natively handle `ffi::Shape` (serialized as `{"type": "ffi.Shape", "data": [int64, ...]}`) and relaxes `CreateObjectData` return type from `json::Object` to `json::Value` to allow custom `__data_to_json__` functions to return non-object values.
- Renames `tests/cpp/test_reflection_accessor.cc` to `tests/cpp/test_reflection.cc` and consolidates accessor, method, and creator tests there; adds a `TIntObj()` default constructor to enable creation via reflection.

## Key Exports

```python
class ObjectCreator:
    """Reflection-based constructor: creates any Object type from a field map."""
    # Lives in: include/tvm/ffi/reflection/creator.h
    # Invariant: type must have reflection registered (TVMFFITypeMetadata.creator != nullptr)
    # Interacts with: TVMFFIGetTypeInfo, ForEachFieldInfo, ForEachFieldInfoWithEarlyStop,
    #                 TVMFFIFieldInfo.setter, ObjectDef<T> (registration), ObjectUnsafe

    def __init__(self, type_key: str) -> None:
        """Look up type by key; throws RuntimeError if no reflection or no creator."""

    def __init__(self, type_info: TVMFFITypeInfo_ptr) -> None:
        """Direct init from type_info pointer."""

    def __call__(self, fields: Map[String, Any]) -> Any:
        """
        Create object, set required fields from map, apply defaults for optional fields.
        Throws TypeError for missing required fields or unknown field names.
        Invariant: all fields without kTVMFFIFieldFlagBitMaskHasDefault must be present in `fields`.
        """

# Serialization changes (src/ffi/extra/serialization.cc):

# ObjectGraphSerializer.CreateObjectData return type relaxed:
# old: json::Object CreateObjectData(const Any& value)
# new: json::Value  CreateObjectData(const Any& value)
# Reason: custom __data_to_json__ may return non-object JSON (e.g., arrays).

# Shape serialization: encode Shape as {"type": "ffi.Shape", "data": [i64, ...]}
#   Interacts with: TypeIndex::kTVMFFIShape, ffi::Shape, StaticTypeKey::kTVMFFIShape
#   Serialize: Shape -> Array<int64_t> -> json::Array
#   Deserialize: json::Array -> Array<int64_t> -> ffi::Shape

# TIntObj gets a default constructor to satisfy TVMFFITypeMetadata.creator requirement:
# old: TIntObj(int64_t value) : value(value) {}
# new: TIntObj() = default;  (prepended)
#      TIntObj(int64_t value) : value(value) {}
```

## Impact
- API: `reflection::ObjectCreator` is a new public class in `include/tvm/ffi/reflection/creator.h`. No existing APIs removed or changed in signature.
- Behavioral: `CreateObjectData` now returns `json::Value` instead of `json::Object`; callers that relied on the concrete `json::Object` return would need to be updated (internal only — this is a non-public method). Custom `__data_to_json__` functions may now return any JSON value type.
- Flags/config: none.
- Data formats/schemas: `ffi::Shape` is now natively serializable in the JSON graph format. Previously, `Shape` values would have fallen through to the default object path (or errored); now they produce `{"type": "ffi.Shape", "data": [...]}` nodes.

Design elements this commit consumes:
- **Reflection system** (`0008-reflection.md`) — uses `TVMFFIGetTypeInfo`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`, `TVMFFIFieldInfo` (offset, setter, flags, default_value), `TVMFFITypeMetadata.creator`.
- **C ABI** (`0007-c-abi.md`) — uses `TVMFFITypeInfo`, `TVMFFIFieldInfo`, `TVMFFIObjectHandle`, `kTVMFFIFieldFlagBitMaskHasDefault`.
- **Object system** (`0002-object-system.md`) — uses `ObjectUnsafe::ObjectPtrFromOwned`, `ObjectPtr<Object>`, `ObjectRef`.
- **Containers** (`0006-containers.md`) — uses `Map<String, Any>`, `Array<int64_t>`, `ffi::Shape` (deserialized via `Array<int64_t>` constructor).
- **Any/AnyView** (`0001-any-anyview-value-system.md`) — uses `AnyUnsafe::CopyFromAnyViewAfterCheck<ffi::Shape>`, `TypeIndex::kTVMFFIShape`.
- **Serialization** (extra) — `CreateObjectData`/`DecodeObjectData` already used reflection creator directly via raw C API; now `ObjectCreator` encapsulates the same pattern for general use.

Design elements this commit produces:
- `reflection::ObjectCreator` — new public API in `include/tvm/ffi/reflection/creator.h`. Encapsulates the pattern of creating an object from a map of fields using the reflection system. Extends the reflection system's construction support (complement to `MakeObjectFromPackedArgs` but operating on a `Map<String, Any>` instead of packed args).

## Usage Examples

**ObjectCreator — creating an object by type key and field map (from `tests/cpp/test_reflection.cc`):**
```cpp
// Assuming TIntObj is registered with ObjectDef<TIntObj>().def_ro("value", ...)
// and TIntObj has a default constructor.
namespace refl = tvm::ffi::reflection;
refl::ObjectCreator creator("test.Int");
Any result = creator(Map<String, Any>({{"value", 1}}));
EXPECT_EQ(result.cast<TInt>()->value, 1);
```

**Shape round-trip through JSON graph (from `tests/cpp/extra/test_serialization.cc`):**
```cpp
Shape shape({1, 2, 3});
json::Object expected = json::Object{
    {"root_index", 0},
    {"nodes", json::Array{json::Object{{"type", "ffi.Shape"}, {"data", json::Array{1, 2, 3}}}}}};
EXPECT_TRUE(StructuralEqual()(ToJSONGraph(shape), expected));
EXPECT_TRUE(StructuralEqual()(FromJSONGraph(expected), shape));
```
