# Migrate Save/Load JSON to the new reflection: add ObjectCreator and Shape serialization

## TL;DR
- Introduces `reflection::ObjectCreator` (`include/tvm/ffi/reflection/creator.h`), a new utility class that creates objects from a type key and a `Map<String, Any>` of field values, using the reflection metadata (`TVMFFITypeInfo::metadata->creator` and field info) to instantiate and populate objects generically.
- Adds `Shape` serialization/deserialization support to `ObjectGraphSerializer`/`ObjectGraphDeserializer` in `src/ffi/extra/serialization.cc`. Shapes are serialized as `{"type": "ffi.Shape", "data": [dim0, dim1, ...]}` using an `Array<int64_t>`.
- Relaxes the return type of `CreateObjectData` from `json::Object` to `json::Value`, allowing custom `__data_to_json__` callbacks to return any JSON value type (not just objects). This fixes a cast failure when a custom serializer returns a non-object JSON value.
- Renames `tests/cpp/test_reflection_accessor.cc` to `tests/cpp/test_reflection.cc` and adds a `Reflection::ObjectCreator` test case that constructs a `TInt` object from a field map.
- Adds `TIntObj() = default` to the test object so that `TIntObj` becomes default-constructible, enabling reflection-based creation via `ObjectCreator`.

## Key Exports

### New Header: `include/tvm/ffi/reflection/creator.h`

**`reflection::ObjectCreator`** -- A class that wraps `TVMFFITypeInfo` to create objects from reflection metadata and a field map.

```cpp
class ObjectCreator {
 public:
  explicit ObjectCreator(std::string_view type_key);
  explicit ObjectCreator(const TVMFFITypeInfo* type_info);
  Any operator()(const Map<String, Any>& fields) const;
};
```

- Constructor validates that the type has reflection metadata registered and that `metadata->creator` is non-null. Throws `RuntimeError` if either check fails.
- `operator()` creates a new object instance via `metadata->creator`, then iterates through all field info (via `ForEachFieldInfo`) and populates each field:
  - If the field name is present in `fields`, sets the field value via `field_info->setter`.
  - If the field has a default value (`kTVMFFIFieldFlagBitMaskHasDefault`), sets the default.
  - Otherwise, throws `TypeError` for the missing required field.
- After setting fields, validates that no extra (unknown) fields were passed in `fields`. Throws `TypeError` if a field name in the input map does not match any registered field.
- Returns the created object as `Any`.

### Serialization Changes (`src/ffi/extra/serialization.cc`)

**Shape serialization/deserialization:**
- `ObjectGraphSerializer::GetOrCreateNodeIndex` now handles `TypeIndex::kTVMFFIShape`: serializes `Shape` as `{"type": "ffi.Shape", "data": [dim0, dim1, ...]}` where data is an `Array<int64_t>` of the shape dimensions.
- `ObjectGraphDeserializer::DecodeNode` now handles `TypeIndex::kTVMFFIShape`: deserializes from `Array<int64_t>` back to `ffi::Shape`.

**`CreateObjectData` return type change:**
- Return type changed from `json::Object` to `json::Value`. This allows custom `__data_to_json__` callbacks to return any JSON-compatible value (not just `json::Object`). The previous code forced a `.cast<json::Object>()` on the callback result, which would fail for types that serialize their data as a non-object JSON value.

## Impact
- **ABI**: None. No C ABI changes; `creator.h` is a C++ header-only utility.
- **API**: New public class `reflection::ObjectCreator` in `tvm/ffi/reflection/creator.h`. The `CreateObjectData` return type relaxation is an internal change (private method in an unnamed class).
- **Behavioral**: `Shape` values can now round-trip through `ToJSONGraph`/`FromJSONGraph`. Custom `__data_to_json__` callbacks that return non-`json::Object` values no longer cause a cast failure during serialization.
- **Flags/config**: None.
- **Data formats/schemas**: The JSON graph format gains a new node type `"ffi.Shape"` with `"data"` as an array of integers.

## Design Elements

Design elements this commit consumes:
- **`TVMFFITypeInfo::metadata->creator`** (`TVMFFIObjectCreator` callback) -- The C ABI's per-type creator callback, registered via `ObjectDef` for default-constructible types. Used by `ObjectCreator` to instantiate empty objects.
- **`ForEachFieldInfo` / `ForEachFieldInfoWithEarlyStop`** (`include/tvm/ffi/reflection/accessor.h`) -- Iterates over all fields (including inherited parent fields) for a given `TVMFFITypeInfo`. Used by `ObjectCreator` to populate fields and validate extra field names.
- **`TVMFFIFieldInfo::setter`** -- Per-field setter callback in the reflection metadata. Used by `ObjectCreator` to set field values by address offset.
- **`kTVMFFIFieldFlagBitMaskHasDefault`** -- Flag indicating a field has a default value. Used by `ObjectCreator` to fall back to defaults for missing fields.
- **`ObjectGraphSerializer` / `ObjectGraphDeserializer`** (from parent commit 8eaefe0) -- The JSON graph serialization framework that this commit extends with `Shape` support.
- **`reflection::TypeAttrColumn("__data_to_json__")` / `("__data_from_json__")`** -- Per-type custom serialization hooks registered via `TypeAttrDef`. Used to dispatch to custom JSON conversion for types that need non-default serialization.
- **`details::ObjectUnsafe::ObjectPtrFromOwned`** -- Wraps a raw `TVMFFIObject*` handle into a ref-counted `ObjectPtr<Object>`. Used by `ObjectCreator` after calling the creator callback.
- **`ffi::Shape`** (`include/tvm/ffi/container/shape.h`) -- The shape container with `data` (pointer to `int64_t` dimensions) and `size` fields. Serialized as an integer array.

Design elements this commit produces:
- **`reflection::ObjectCreator`** -- A high-level utility for creating objects from a type key and a field map via reflection. Validates required fields, applies defaults, and detects extra fields. This is the building block for generic object deserialization from structured data (used internally by the JSON graph deserializer's `DecodeObjectData` method, which contains similar logic).
- **Shape JSON graph serialization format** -- Shapes are serialized as `{"type": "ffi.Shape", "data": [int, ...]}` in the JSON graph, consistent with the existing Array/Map patterns.
- **Relaxed `__data_to_json__` return type** -- Custom serialization callbacks can now return any `json::Value`, not just `json::Object`. This enables types to serialize their data as arrays, scalars, or strings.

## Usage Examples

### Creating an object via ObjectCreator
```cpp
#include <tvm/ffi/reflection/creator.h>

namespace refl = tvm::ffi::reflection;

// Create an object of type "test.Int" with field "value" = 42
refl::ObjectCreator creator("test.Int");
Any result = creator(Map<String, Any>({{"value", 42}}));
// result is a TInt with value 42
```

### Shape round-trip through JSON graph
```cpp
#include <tvm/ffi/container/shape.h>
#include <tvm/ffi/extra/serialization.h>

Shape shape({1, 2, 3});
json::Value json = ToJSONGraph(shape);
// json == {"root_index": 0, "nodes": [{"type": "ffi.Shape", "data": [1, 2, 3]}]}

Shape restored = FromJSONGraph(json).cast<Shape>();
// restored == Shape({1, 2, 3})
```

### Custom __data_to_json__ returning a non-object value
```cpp
// Now valid: a custom serializer can return a json::Array or json::Value directly
refl::TypeAttrDef<MyTypeObj>()
    .def("__data_to_json__",
         [](const MyTypeObj* self) -> json::Array {
           return json::Array{self->x, self->y};
         });
```
