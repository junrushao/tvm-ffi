# Add reflection-based ObjectCreator, Shape serialization, and relax CreateObjectData return type
## TL;DR
- Introduces `reflection::ObjectCreator`, a new helper class in `reflection/creator.h` that creates objects from a type key and a `Map<String, Any>` of field name/value pairs, using the reflection registry's field metadata and setters.
- Adds `Shape` serialization/deserialization support to `ObjectGraphSerializer`/`ObjectGraphDeserializer` as a new built-in case in the JSON graph format (type `"ffi.Shape"`, data as `Array<int64_t>`).
- Relaxes `CreateObjectData` return type from `json::Object` to `json::Value`, allowing custom `__data_to_json__` type attributes to return any JSON value (not just objects).

## Key Exports

**Classes**:
```cpp
// include/tvm/ffi/reflection/creator.h
namespace tvm::ffi::reflection {
class ObjectCreator {
public:
  explicit ObjectCreator(std::string_view type_key);
  explicit ObjectCreator(const TVMFFITypeInfo* type_info);
  Any operator()(const Map<String, Any>& fields) const;
private:
  const TVMFFITypeInfo* type_info_;
};
}
```
- Constructor validates that the type has reflection metadata and a creator function; throws `RuntimeError` otherwise.
- `operator()` iterates `ForEachFieldInfo` on the type's hierarchy, sets each field from the `fields` map (using `field_info->setter`), applies defaults for missing fields with `kTVMFFIFieldFlagBitMaskHasDefault`, throws `TypeError` for missing required fields or extra unknown fields.

**Signature changes**:
```cpp
// src/ffi/extra/serialization.cc (internal, not public header)
// Before: json::Object CreateObjectData(const Any& value)
// After:  json::Value  CreateObjectData(const Any& value)
```

**File rename**: `tests/cpp/test_reflection_accessor.cc` -> `tests/cpp/test_reflection.cc`

## Impact
- API: New public header `include/tvm/ffi/reflection/creator.h` with `ObjectCreator` class. No existing API removed.
- Behavioral: `CreateObjectData` now returns `json::Value` instead of `json::Object`, enabling custom `__data_to_json__` handlers to return non-object JSON. The default reflection-based path still returns `json::Object`.
- Flags/config: None.
- Data formats/schemas: `Shape` values now serialize as `{"type": "ffi.Shape", "data": [dim0, dim1, ...]}` in JSON graph format. Previously `Shape` would fall through to the default object serializer (or fail).

## Design Elements
Design elements this commit consumes:
- **Reflection field traversal** (`ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`) from `reflection/accessor.h` -- used by `ObjectCreator` to iterate over fields in parent-to-child order. See `.knowledge/designs/0009-reflection.md`.
- **TVMFFITypeInfo / TVMFFITypeMetadata** -- `ObjectCreator` reads `type_info->metadata->creator` to default-construct the object, and field info for setters/flags/defaults. See `.knowledge/designs/0009-reflection.md`.
- **TypeAttrColumn** (`__data_to_json__`, `__data_from_json__`) -- serialization checks for custom per-type serializers before falling back to reflection-based field iteration.
- **Shape container** (`ffi::Shape`, `TypeIndex::kTVMFFIShape`, `StaticTypeKey::kTVMFFIShape`) from `container/shape.h`. See `.knowledge/designs/0008-containers.md`.
- **Object creation pattern** (`TVMFFIObjectCreator`, `ObjectUnsafe::ObjectPtrFromOwned`) -- both `ObjectCreator` and `DecodeObjectData` use this to create raw objects and wrap them in `ObjectPtr`.

Design elements this commit produces:
- **`reflection::ObjectCreator`** -- a reusable, type-safe helper for reflection-based object construction from field maps. Serves as a building block for deserialization and cross-language construction.
- **Shape serialization protocol** -- `Shape` is now a first-class citizen in the JSON graph format, alongside Array, Map, String, etc.
- **Relaxed `CreateObjectData` contract** -- custom `__data_to_json__` handlers may now return any `json::Value`, not just `json::Object`.

## Usage Examples

**ObjectCreator -- construct an object from a field map:**
```cpp
#include <tvm/ffi/reflection/creator.h>
namespace refl = tvm::ffi::reflection;

// Given a registered type "test.Int" with field "value" (int64_t):
refl::ObjectCreator creator("test.Int");
Any obj = creator(Map<String, Any>({{"value", 1}}));
// obj is a TInt with value == 1
```

**Shape serialization round-trip:**
```cpp
Shape shape({1, 2, 3});
json::Value json = ToJSONGraph(shape);
// json == {"root_index": 0, "nodes": [{"type": "ffi.Shape", "data": [1, 2, 3]}]}
Any restored = FromJSONGraph(json);
// restored is Shape({1, 2, 3})
```
