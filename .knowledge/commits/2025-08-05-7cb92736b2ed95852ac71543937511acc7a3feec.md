# Add reflection-based ObjectCreator, Shape serialization, and relax CreateObjectData return type
## TL;DR
- Introduces `reflection::ObjectCreator` class (`reflection/creator.h`) that creates objects from a type key and a `Map<String, Any>` of field values, using the reflection system's `TVMFFITypeMetadata::creator` and `ForEachFieldInfo`.
- Adds `Shape` serialization/deserialization support in the JSON graph codec (`serialization.cc`), encoding shapes as `{"type": "ffi.Shape", "data": [dims...]}`.
- Relaxes `CreateObjectData` return type from `json::Object` to `json::Value` to allow `__data_to_json__` custom serializers to return any JSON value type.
- Renames `test_reflection_accessor.cc` to `test_reflection.cc` (broader scope) and adds `TIntObj() = default` constructor to enable `ObjectCreator` tests.

## Impact
- API: `ObjectCreator` is a new public C++ API in `tvm::ffi::reflection`. No existing API signatures removed.
- Behavioral: `CreateObjectData` now returns `json::Value` instead of `json::Object`, which is a loosening -- existing callers returning `json::Object` still work (upcast).
- Flags/config: none
- Data formats/schemas: `Shape` objects now have a defined JSON graph encoding (`{"type": "ffi.Shape", "data": [...]}`). Previously, `Shape` was not handled as a built-in type in the serialization codec and would have fallen through to the generic object path.

## Design Elements
Design elements this commit consumes:
- `TVMFFITypeMetadata.creator` (from [0007-ffi-reflection](../design-records/0007-ffi-reflection.md)) -- used by `ObjectCreator` to instantiate objects.
- `ForEachFieldInfo` / `ForEachFieldInfoWithEarlyStop` (from [0007-ffi-reflection](../design-records/0007-ffi-reflection.md)) -- used to iterate fields for setting values and checking unknown fields.
- `TVMFFIFieldInfo.setter` / `TVMFFIFieldInfo.flags` / `TVMFFIFieldInfo.default_value` (from [0007-ffi-reflection](../design-records/0007-ffi-reflection.md)) -- used to set fields and apply defaults.
- `Shape` container (from [0006-ffi-containers](../design-records/0006-ffi-containers.md)) -- serialized/deserialized.
- `TypeAttrColumn("__data_to_json__")` (from [0007-ffi-reflection](../design-records/0007-ffi-reflection.md)) -- used for custom object data serialization dispatch.
- `ObjectPtr`, `details::ObjectUnsafe::ObjectPtrFromOwned` (from [0003-ffi-object-system](../design-records/0003-ffi-object-system.md)) -- used in `ObjectCreator` to wrap the raw handle.

Design elements this commit produces:
- `reflection::ObjectCreator` -- new class providing map-based object construction from reflection metadata. Extends the reflection subsystem ([0007-ffi-reflection](../design-records/0007-ffi-reflection.md)) with a higher-level creation API complementing the lower-level `MakeObjectFromPackedArgs`.
- Shape serialization codec entries in `ObjectGraphSerializer` and `ObjectGraphDeserializer` -- extends the JSON graph serialization format with built-in Shape support.

## Usage Examples
From the test (`tests/cpp/test_reflection.cc`):
```cpp
// Create an object using ObjectCreator with field map
namespace refl = tvm::ffi::reflection;
refl::ObjectCreator creator("test.Int");
TInt obj = creator(Map<String, Any>({{"value", 1}})).cast<TInt>();
assert(obj->value == 1);
```

Shape round-trip serialization (from `tests/cpp/extra/test_serialization.cc`):
```cpp
Shape shape({1, 2, 3});
json::Object serialized = ToJSONGraph(shape);
// serialized == {"root_index": 0, "nodes": [{"type": "ffi.Shape", "data": [1, 2, 3]}]}
Shape restored = FromJSONGraph(serialized).cast<Shape>();
assert(StructuralEqual()(shape, restored));
```
