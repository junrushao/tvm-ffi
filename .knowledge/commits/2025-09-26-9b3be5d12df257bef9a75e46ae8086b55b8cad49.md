# Add test verifying __doc__ is None for reflection fields without explicit docstrings
## TL;DR
- Adds `test_attribute_no_doc` to `tests/python/test_object.py`, verifying that `TypeField.as_property()` produces `__doc__ = None` for fields registered without an explicit docstring (the behavior fixed in PR #60, commit 43ffe57).
- Only the `v_i64` field on `TestObjectBase` has an explicit docstring (`"i64 field"`); `v_f64` and `v_str` do not, so their `__doc__` must be `None`.
