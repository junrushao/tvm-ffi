# Add test asserting that field __doc__ is None when not explicitly set

## TL;DR
- Adds `test_attribute_no_doc()` to `tests/python/test_object.py` as a follow-up to the fix in PR #60.
- Asserts that `TestObjectBase.v_f64.__doc__` and `TestObjectBase.v_str.__doc__` are `None` when no docstring is supplied to the C++ field registration.
- Asserts that `TestObjectBase.v_i64.__doc__` equals `"i64 field"` when a docstring is explicitly set.

- `TypeField.__doc__` optional docstring convention established in design record `0006-reflection` and `0013-python-package`: a `None` value signals that the C++ `def_field` call omitted a docstring string.

## Usage Examples

# From tests/python/test_object.py — verifying optional docstring behavior
def test_attribute_no_doc() -> None:
    from tvm_ffi.testing import TestObjectBase

    # Field with explicit doc => non-None
    assert TestObjectBase.v_i64.__doc__ == "i64 field"
    # Fields without explicit doc => None (not a generated default string)
    assert TestObjectBase.v_f64.__doc__ is None
    assert TestObjectBase.v_str.__doc__ is None
