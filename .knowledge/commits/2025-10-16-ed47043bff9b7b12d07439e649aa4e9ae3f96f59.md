# Add CMake-based endian detection and musl libc support in endian.h
## TL;DR
- CMake now detects endianness via `CMAKE_CXX_BYTE_ORDER` and defines `TVM_FFI_CMAKE_LITTLE_ENDIAN` as a compile definition on the `tvm_ffi_header` INTERFACE target.
- `endian.h` checks `TVM_FFI_CMAKE_LITTLE_ENDIAN` first, falling back to the existing preprocessor platform detection chain only if not set.
- Adds `__MUSL__` to the preprocessor detection path for musl-based Linux distributions.

## Impact
- API: none
- Behavioral: none -- endianness detection logic is unchanged for all previously-supported platforms. CMake-driven detection provides a new, higher-priority path that is more reliable on unusual platforms.
- Flags/config: new compile definition `TVM_FFI_CMAKE_LITTLE_ENDIAN` (0 or 1) set by CMake when `CMAKE_CXX_BYTE_ORDER` is available. Falls back gracefully if CMake cannot determine endianness.
- Data formats/schemas: none
