# Add toScalarTypeForDLPackv1 for full f4 DLPack conversion and fix Float4_e2m1fn_x2 dtype encoding

## TL;DR

- **Bugfix**: `getDLDataTypeForDLPackv1` was missing `dtype.lanes = 2; dtype.bits = 4;` for `Float4_e2m1fn_x2`, producing a malformed `DLDataType` when exporting f4 tensors to DLPack.
- **Feature**: New `toScalarTypeForDLPackv1` function added to `_optional_torch_c_dlpack.py`, replacing the call to ATen's `toScalarType` in `fromDLPackImpl`. The new function handles all DLPack type codes including `kDLFloat4_e2m1fn` (with its `lanes=2` special case), Float8 variants, Bool, Complex, BFloat16, UInt, Int, and Float.
- **Chore**: `tvm_ffi_python_helpers.h` install in `CMakeLists.txt` moved inside `TVM_FFI_BUILD_PYTHON_MODULE` guard (was unconditionally installed alongside library headers); version bumped to `0.1.0b4`.

## Impact

- API: None for external Python users; `toScalarTypeForDLPackv1` is C++ inside the compiled extension.
- Behavioral: Importing a DLPack tensor with `kDLFloat4_e2m1fn` dtype (4-bit float, lanes=2) now correctly round-trips through `fromDLPackImpl`. Previously, `getDLDataTypeForDLPackv1` emitted an ill-formed `DLDataType` (lanes and bits unset), and importing back via ATen's `toScalarType` would fail or produce `Undefined`.
- Flags/config: `tvm_ffi_python_helpers.h` is now only installed when `TVM_FFI_BUILD_PYTHON_MODULE=ON`; pure C++ library consumers without Python build will no longer receive it.
- Data formats/schemas: None.

## Usage Examples

**Bugfix: before/after for Float4_e2m1fn_x2 DLPack round-trip**

```cpp
// BEFORE (parent commit): Float4_e2m1fn_x2 export emits malformed DLDataType
DLDataType getDLDataTypeForDLPackv1(const Tensor& t) {
    // case ScalarType::Float4_e2m1fn_x2:
    //   dtype.code = DLDataTypeCode::kDLFloat4_e2m1fn;
    //   (lanes and bits NOT set — bug)
    //   break;
}
// Import side calls ATen's toScalarType() which doesn't know kDLFloat4_e2m1fn:
//   → returns ScalarType::Undefined or throws

// AFTER (this commit): correct DLDataType produced
DLDataType getDLDataTypeForDLPackv1(const Tensor& t) {
    case ScalarType::Float4_e2m1fn_x2:
        dtype.code = DLDataTypeCode::kDLFloat4_e2m1fn;
        dtype.lanes = 2;   // required: Float4 packs 2 values per element
        dtype.bits = 4;    // required: 4-bit float
        break;
}
// Import side now calls toScalarTypeForDLPackv1() which handles kDLFloat4_e2m1fn:
//   dtype.code==kDLFloat4_e2m1fn, bits==4, lanes==2 → ScalarType::Float4_e2m1fn_x2
```
