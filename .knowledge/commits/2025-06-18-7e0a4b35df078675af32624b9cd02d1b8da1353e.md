# Stabilize container ABI by decoupling data pointer from inplace allocation and fixing DenseMapObj slot arithmetic

## TL;DR
- `ArrayObj` and `MapObj` now carry an explicit `data_` (`void*`) field and a `data_deleter_` function pointer, decoupling the element storage pointer from `InplaceArrayBase::AddressOf(0)`. This makes containers safe when data is reallocated by a different shared library (cross-DLL malloc/free compatibility).
- `DenseMapObj` off-by-one in `slots_` semantics is fixed (`slots_` is now the actual count, not count-1); ring-probing corrected from `& slots_` (power-of-2 bitmask) to `% slots_` (correct modular wrap).
- Internal dispatch macros renamed `TVM_DISPATCH_MAP` → `TVM_FFI_DISPATCH_MAP` and `TVM_DISPATCH_MAP_CONST` → `TVM_FFI_DISPATCH_MAP_CONST` for consistent namespace prefix.

## Impact
- API: `ArrayObj::at()` return type changed from `const Any` (by value) to `const Any&` (by reference). Internal callers only — `ArrayObj` is not directly exposed through the public C ABI. `Array<T>` public API unchanged.
- Behavioral: `DenseMapObj` probing correctness fix changes which slot a key lands in after hash collision; existing serialized maps are ABI-compatible (type_index unchanged), but hash positions differ. `slots_` off-by-one fix means one more usable slot per power-of-2 table.
- Flags/config: none
- Data formats/schemas: `ArrayObj` and `MapObj` in-memory layout changed — `data_` and `data_deleter_` fields inserted. Binary-incompatible with pre-commit object snapshots (not a concern: objects are not serialized to disk by this layer).

## Usage Examples

**Cross-DLL safe array construction** (illustrates why `data_` and `data_deleter_` matter):
```cpp
// Normal inplace allocation (data_ → AddressOf(0), data_deleter_ = nullptr)
ObjectPtr<ArrayObj> arr = ArrayObj::Empty(8);
arr->EmplaceInit(arr->size_++, Any(42));

// Future: external buffer (data_deleter_ set to custom free fn)
// Caller allocates block with their own allocator:
//   arr->data_ = my_alloc(n * sizeof(Any));
//   arr->data_deleter_ = my_free;
// Destructor will call my_free(arr->data_) — safe across DLL boundaries.
```

**DenseMapObj probing fix** (before/after):
```cpp
// BEFORE (buggy — & slots_ is bitmask, only safe when slots_ is power-of-2 minus 1):
index = (index + offset) & (self->slots_);   // slots_=7 for 8-slot table → mask 0b111
// AFTER (correct — % wraps into [0, slots_)):
index = (index + offset) % self->slots_;     // slots_=8 for 8-slot table
```

**Tuple delegates to ArrayObj::Empty** (post-commit):
```cpp
// Before: open-coded inplace allocation in Tuple::MakeDefaultTupleNode
// After: delegates to ArrayObj::Empty which sets data_ correctly
ObjectPtr<ArrayObj> p = ArrayObj::Empty(sizeof...(Types));
```
