# Fix ctypes.c_void_p nullptr handling in Cython bindings
## TL;DR
- Fixes a corner case where `ctypes.c_void_p(value=0).value` returns `None` instead of `0`, causing nullptr mishandling in the Cython layer.
- Adds a test verifying that void pointer round-trip through FFI works correctly for nullptr.
