# Add tests for FileLock utility and fix re-entrant acquire behavior
## TL;DR
- Add comprehensive tests for `FileLock` in `tests/python/utils/test_filelock.py` covering basic acquire/release, context manager, re-entrant acquire, exception safety, and 16-process concurrent access.
- Fix `FileLock.acquire()` to return `False` if the lock is already held by the same instance (guards against double-acquire).
- Fix `FileLock.blocking_acquire()` to raise `RuntimeError` if the lock is already held by the same instance.
- Improve docstrings to Google/NumPy style with `Returns`, `Raises` sections.

## Key Exports
**Types** (mutated):
- `FileLock` (`python/tvm_ffi/utils/lockfile.py`):
  - `acquire() -> bool` — now returns `False` immediately if `_file_descriptor is not None` (already held). Previously would attempt OS-level lock again.
  - `blocking_acquire(timeout: float | None = None, poll_interval: float = 0.1) -> bool` — now raises `RuntimeError("Lock is already held by this instance.")` if `_file_descriptor is not None`. Previously would spin indefinitely or until timeout.

## Impact
- API: Behavioral change to `acquire()` (now returns `False` on re-entrant call instead of attempting OS lock) and `blocking_acquire()` (now raises `RuntimeError` on re-entrant call instead of spinning).
- Behavioral: Prevents same-instance double-locking which could cause deadlock or undefined behavior on some platforms.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **FileLock utility** (`tvm_ffi.utils.lockfile.FileLock`) — cross-platform advisory file locking used for coordinating concurrent JIT compilation (e.g., torch C DLPack extension build).

Design elements this commit mutates:
- **FileLock re-entrant acquire contract** — new invariant: a `FileLock` instance that already holds the lock (`_file_descriptor is not None`) will refuse to acquire again (`acquire` returns `False`, `blocking_acquire` raises `RuntimeError`).

## Usage Examples
```python
from tvm_ffi.utils.lockfile import FileLock

lock = FileLock("/tmp/my.lock")
assert lock.acquire() is True   # first acquire succeeds
assert lock.acquire() is False  # same-instance re-acquire returns False
lock.release()

# Context manager with exception safety
with FileLock("/tmp/my.lock"):
    # critical section
    pass  # lock released even on exception
```
