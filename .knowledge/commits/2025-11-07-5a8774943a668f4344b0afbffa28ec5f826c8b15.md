# Improve torch fallback and dtype convert behavior; fix tvm_ffi.convert to always return dtype

## TL;DR
- Fixes `tvm_ffi.convert(dtype_obj)` to always return `tvm_ffi.dtype` even when the input is already a dtype-compatible object.
- Improves torch fallback dispatch in `cython/function.pxi` for the case where the addon is absent.
- Refactors `cython/dtype.pxi` dtype conversion for correctness.
- Adds 7 lines to `addons/torch_c_dlpack_ext/README.md`; updates `docs/index.rst`.
