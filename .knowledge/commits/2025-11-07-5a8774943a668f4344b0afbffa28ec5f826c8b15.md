# Fix dtype conversion to return proper tvm_ffi.dtype and fix torch fallback device detection
## TL;DR
- Fixed `tvm_ffi.convert()` and Cython dtype conversion helpers to return proper `tvm_ffi.dtype` (str subclass) instead of raw `DataType`, by factoring out `make_dtype_from_dl_data_type()` and fixing `_create_cdtype_from_tuple` constructor call.
- Fixed torch fallback device detection bug: `ctx.device_type != -1` (never triggers) changed to `ctx.device_type == -1` (triggers on first CUDA tensor), restoring stream synchronization for torch fallback path.
- Extended `convert()` to recognize protocol objects (`__dlpack_data_type__`, `__tvm_ffi_object__`, `__cuda_stream__`, `__tvm_ffi_opaque_ptr__`, `__dlpack_device__`, `ctypes.c_void_p`) instead of wrapping them as opaque objects.

## Impact
- API: `core._create_dtype_from_tuple` renamed to `core._create_cdtype_from_tuple` (semi-internal, `_` prefixed). External code calling the old name will break.
- Behavioral: `tvm_ffi.convert()` now returns `tvm_ffi.dtype` (not raw `DataType`) for torch/numpy dtype inputs. `convert()` now recognizes protocol objects instead of wrapping as opaque. Torch fallback path now correctly captures CUDA device/stream info.
- Flags/config: Env var `TVM_FFI_SKIP_c_dlpack_from_pyobject` renamed to `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API`.
- Data formats/schemas: none

## Usage Examples
Before/after for the dtype conversion bug:

```python
import tvm_ffi
import torch

# BEFORE (broken): convert(torch.float32) returned raw DataType, not tvm_ffi.dtype
dtype_val = tvm_ffi.convert(torch.float32)
assert isinstance(dtype_val, tvm_ffi.dtype)  # FAILED

# AFTER (fixed): properly returns tvm_ffi.dtype (str subclass with _tvm_ffi_dtype)
dtype_val = tvm_ffi.convert(torch.float32)
assert isinstance(dtype_val, tvm_ffi.dtype)  # PASSES
```

Before/after for `convert()` with protocol objects:

```python
# BEFORE: objects with __dlpack_data_type__ were wrapped as OpaquePyObject
x = DLPackDataTypeProtocol((dtype.type_code, dtype.bits, dtype.lanes))
tvm_ffi.convert(x)  # -> OpaquePyObject (wrong)

# AFTER: properly converts to tvm_ffi.dtype
tvm_ffi.convert(x)  # -> tvm_ffi.dtype("float32") (correct)
```
