# Extend autodlpack benchmark to measure CUDA stream context overhead

## TL;DR
- Adds `stream=True` mode to `tvm_ffi_nop_autodlpack_from_torch` that runs the autodlpack benchmark inside a non-default `torch.cuda.Stream` context.
- Introduces `load_torch_get_current_cuda_stream()` which JIT-compiles a C++ CUDA extension via `torch.utils.cpp_extension.load_inline` to query the current CUDA stream with lower Python overhead than `torch.cuda.current_stream()`.
- Extends `main()` with two new benchmark groups: autodlpack under non-default stream, and `torch.cuda.current_stream` latency (Python vs. cpp-extension).
