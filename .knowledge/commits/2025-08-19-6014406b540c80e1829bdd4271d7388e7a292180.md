# Add CUDA stream context and stream query benchmarks to DLPack benchmark script

## TL;DR
- Extends `scripts/benchmark_dlpack.py` with CUDA stream-aware AutoDLPack benchmarking: adds a `stream=True` mode to `tvm_ffi_nop_autodlpack_from_torch()` that runs the NOP benchmark inside a non-default `torch.cuda.Stream()` context.
- Adds `load_torch_get_current_cuda_stream()`, a JIT-compiled C++ extension via `torch.utils.cpp_extension.load_inline` that queries the current CUDA stream through `at::cuda::getCurrentCUDAStream()`, plus a pure-Python counterpart `torch_get_cuda_stream_native()`. Benchmarks both for default and non-default streams.
- **Diff-message discrepancy**: The commit message describes updating the "autodlpack path to automatically update the env stream to be consistent with torch stream context," but the actual diff only modifies the benchmark script. The core stream-synchronization implementation is not present in this diff (likely in the upstream PR #18217).
