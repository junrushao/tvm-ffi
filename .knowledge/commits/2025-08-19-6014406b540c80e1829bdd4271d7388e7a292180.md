# Add stream-aware autodlpack benchmarks and CUDA stream query microbenchmarks
## TL;DR
- Extends `benchmark_dlpack.py` with a `stream=True` mode for `tvm_ffi_nop_autodlpack_from_torch` to benchmark autodlpack under non-default CUDA streams.
- Adds `load_torch_get_current_cuda_stream()` which JIT-compiles a C++ extension via `torch.utils.cpp_extension.load_inline` for fast CUDA stream querying, compared against the pure-Python `torch.cuda.current_stream` path.
- Adds `bench_torch_get_current_stream` benchmarks for both default and non-default stream contexts.

## Design Elements
Design elements this commit consumes:
- **autodlpack conversion** (`tvm_ffi.get_global_func("testing.nop")` + passing `torch.Tensor` directly): the benchmark exercises the automatic DLPack conversion path where torch tensors are passed to TVM FFI functions without explicit `from_dlpack`.
- **`torch.cuda.stream` context manager**: the benchmark tests whether autodlpack correctly propagates stream context when running under a non-default CUDA stream.
- **`torch.utils.cpp_extension.load_inline`**: used to JIT-compile a C++ function that calls `at::cuda::getCurrentCUDAStream` for low-overhead stream ID retrieval.
