# Extend benchmark_dlpack.py to measure autodlpack overhead under CUDA stream context

## TL;DR

- Adds a `stream=True` path to `tvm_ffi_nop_autodlpack_from_torch` that wraps the benchmark inside `torch.cuda.stream(torch.cuda.Stream())` to measure autodlpack overhead under a non-default CUDA stream.
- Introduces `load_torch_get_current_cuda_stream()` which JIT-compiles a C++ extension via `torch.utils.cpp_extension.load_inline` to query `at::cuda::getCurrentCUDAStream()` with minimal Python overhead; benchmarks it against the pure-Python `torch.cuda.current_stream().cuda_stream`.
- Adds `bench_torch_get_current_stream` utility and exercises both default and non-default stream scenarios in `main()`.

## Usage Examples

Running the updated benchmark on a CUDA device:

```python
# Default stream scenario (existing)
tvm_ffi_nop_autodlpack_from_torch(10000, "cuda")

# Non-default stream scenario (new)
tvm_ffi_nop_autodlpack_from_torch(10000, "cuda", stream=True)

# Benchmarking get_current_stream overhead (new)
native_fn = load_torch_get_current_cuda_stream()  # JIT-compiles on first call
bench_torch_get_current_stream(10000, "cpp-extension", native_fn)
bench_torch_get_current_stream(10000, "python", torch_get_cuda_stream_native)

# Non-default stream version
with torch.cuda.stream(torch.cuda.Stream()):
    bench_torch_get_current_stream(10000, "cpp-extension", load_torch_get_current_cuda_stream())
    bench_torch_get_current_stream(10000, "python", torch_get_cuda_stream_native)
```
