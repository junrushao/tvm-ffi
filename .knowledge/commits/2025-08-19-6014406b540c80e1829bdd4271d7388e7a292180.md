# Add CUDA stream-aware benchmarks and torch cpp_extension stream query to DLPack benchmark script
## TL;DR
- Extends `scripts/benchmark_dlpack.py` with CUDA stream-aware AutoDLPack benchmarks: runs `nop` inside a non-default `torch.cuda.Stream` context to measure stream-synchronization overhead.
- Adds `load_torch_get_current_cuda_stream()`, which JIT-compiles a C++ extension via `torch.utils.cpp_extension.load_inline` that calls `at::cuda::getCurrentCUDAStream` directly, bypassing Python overhead for stream queries.
- Adds `bench_torch_get_current_stream` to compare the C++ extension stream query against the native Python `torch.cuda.current_stream().cuda_stream` path, for both default and non-default streams.
