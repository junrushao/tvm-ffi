# Add CUDA stream-aware benchmarks for autodlpack and torch stream query overhead
## TL;DR
- Extends `scripts/benchmark_dlpack.py` with stream-context benchmarks for the autodlpack path (`tvm_ffi_nop_autodlpack_from_torch` now accepts `stream=True`).
- Adds `load_torch_get_current_cuda_stream()` using `torch.utils.cpp_extension.load_inline` to JIT-compile a fast C++ CUDA stream query, benchmarking it against the pure-Python `torch.cuda.current_stream` path.
- New `main()` sections measure autodlpack overhead inside a non-default CUDA stream and compare stream-query latency (cpp-extension vs Python) for both default and non-default streams.

**Diff-message discrepancy**: The commit message claims a functional change ("updates the autodlpack path to automatically update the env stream"), but the actual diff only modifies `scripts/benchmark_dlpack.py`. The production-side change likely resides in a different commit within PR #18217.
