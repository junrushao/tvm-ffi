# Rename TVMFFISafeCallType first parameter from `self` to `handle`
## TL;DR
- Renames the first parameter of `TVMFFISafeCallType` from `self` to `handle` in both the typedef and its Doxygen comment.
- Purely documentary/semantic change — no binary ABI impact (C function pointer typedefs do not encode parameter names).
- Stabilizes naming in preparation for bringing module support to the FFI layer.

| Old name | New name | Location |
|----------|----------|----------|
| `self` | `handle` | `TVMFFISafeCallType` first parameter (`include/tvm/ffi/c_api.h`) |
| `\param self` | `\param handle` | Doxygen comment for `TVMFFISafeCallType` |

## Key Exports

```python
# Signature change (parameter rename only, no ABI break):
# Old: TVMFFISafeCallType(self: void_ptr, args: TVMFFIAny_array, num_args: int32, result: TVMFFIAny_ptr) -> int
# New:
def TVMFFISafeCallType(
    handle: void_ptr,          # was: self  -- Function object handle
    args: TVMFFIAny_array,     # Input arguments
    num_args: int32,           # Argument count
    result: TVMFFIAny_ptr      # Output
) -> int:
    """Return 0=success, -1=error in TLS, -2=frontend error."""
    # Interacts with: TVMFFIErrorSetRaised (on -1), TVMFFIFunctionCall (caller)
    # Invariant: catches ALL exceptions at boundary, never leaks C++ exceptions across ABI
    ...
```
