# Rename TVMFFISafeCallType parameter from `self` to `handle`
## TL;DR
- Renames the first parameter of `TVMFFISafeCallType` from `self` to `handle` in both the Doxygen comment and the C typedef declaration.
- Aligns naming with the broader "library module" design direction mentioned in the commit message; the parameter name `handle` is more accurate since it represents an opaque function handle, not a `self`/`this` pointer.
- No ABI or behavioral change -- parameter names in C function pointer typedefs are purely documentary.

| Before | After | Location |
|--------|-------|----------|
| `void* self` | `void* handle` | `TVMFFISafeCallType` typedef, `include/tvm/ffi/c_api.h:281` |
| `\param self The function handle` | `\param handle The function handle` | Doxygen comment, `include/tvm/ffi/c_api.h:254` |

**Diff-message discrepancy**: The commit message mentions "Update symbol name for library module" which implies broader scope than the actual diff (only the `TVMFFISafeCallType` parameter rename). The diff is limited to `c_api.h`.
