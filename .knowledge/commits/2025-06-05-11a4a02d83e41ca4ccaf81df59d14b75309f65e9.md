# Rename TVMFFISafeCallType first parameter from `self` to `handle` in c_api.h
## TL;DR
- Renames the first parameter of the `TVMFFISafeCallType` typedef from `self` to `handle` in `include/tvm/ffi/c_api.h`, along with the corresponding Doxygen `\param` comment.
- Motivation: align parameter naming with "library module" terminology to stabilize the name before moving the module concept into the FFI layer.

| Before | After | File |
|--------|-------|------|
| `void* self` (param name in `TVMFFISafeCallType`) | `void* handle` | `include/tvm/ffi/c_api.h` |
| `\param self The function handle` (Doxygen) | `\param handle The function handle` | `include/tvm/ffi/c_api.h` |
