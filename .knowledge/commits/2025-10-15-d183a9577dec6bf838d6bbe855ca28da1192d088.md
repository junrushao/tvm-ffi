# Switch libtvm_ffi_testing from Python load_module to explicit CMake link dependency for deterministic unload ordering
## TL;DR
- Removed the Python-level `load_module(libinfo.find_library_by_basename("tvm_ffi_testing"))` call from `testing.py`, replacing it with a direct CMake `target_link_libraries(tvm_ffi_cython PRIVATE tvm_ffi_testing)` linkage.
- Added `TVMFFITestingDummyTarget()` as a C ABI symbol in `libtvm_ffi_testing` and declared+called it from Cython (`base.pxi` / `tvm_ffi_python_helpers.h`) to force the linker to include the testing library.
- This guarantees that the Cython extension (`core.abi3.so`) is always unloaded before `libtvm_ffi_testing` by the OS dynamic linker, preventing use-after-free of testing globals during Python shutdown.

## Key Exports
N/A -- infrastructure. The only new symbol is a dummy linkage target:

```python
# C ABI symbol (libtvm_ffi_testing, testing.cc):
def TVMFFITestingDummyTarget() -> int: ...
    # Returns 0. Sole purpose: force linker to include libtvm_ffi_testing
    # as a hard dependency of tvm_ffi_cython (core.abi3.so).
    # Interacts with: tvm_ffi_cython (Cython extension) -- called at module init
    # Invariant: must be extern "C" TVM_FFI_DLL_EXPORT to be visible across DLL boundary
```

## Impact
- API: none -- `tvm_ffi.testing` module's public API is unchanged.
- Behavioral: DLL unload order is now deterministic: Cython extension unloads before libtvm_ffi_testing. Previously, Python's `load_module` held a Module reference to libtvm_ffi_testing, and unload order depended on Python garbage collection timing.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Module system** ([0011-module-system.md](../designs/0011-module-system.md)) -- the `load_module` / `DSOLibrary` mechanism that was previously used to load `libtvm_ffi_testing` at Python import time is replaced by native linking. The `load_module` call and `_LIBTVM_FFI_TESTING` module handle are removed.
- **Python bindings / Cython extension** ([0012-python-bindings.md](../designs/0012-python-bindings.md)) -- `base.pxi` (Cython extern declarations) and `tvm_ffi_python_helpers.h` (C++ helper header compiled into the Cython extension) are extended with the dummy target declaration/call.
- **C ABI / TVM_FFI_DLL_EXPORT** ([0001-c-abi.md](../designs/0001-c-abi.md)) -- the `TVMFFITestingDummyTarget` uses the standard `extern "C" TVM_FFI_DLL_EXPORT` pattern for cross-DLL symbol visibility.

Design elements this commit produces:
- None significant -- `TVMFFITestingDummyTarget` is a trivial linkage anchor, not a design element.
