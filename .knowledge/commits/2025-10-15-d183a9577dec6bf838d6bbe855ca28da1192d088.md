# Explicitly link libtvm_ffi_testing from Cython for correct unloading order
## TL;DR
- Changed `libtvm_ffi_testing` from runtime `load_module` loading (in `testing.py`) to compile-time CMake linking against `tvm_ffi_cython`, ensuring Cython always unloads before the testing library.
- Removed the `load_module(find_library_by_basename("tvm_ffi_testing"))` call from `testing.py`.
- Added `TVMFFITestingDummyTarget()` call in `base.pxi` module init to force the linker to include the testing library.
