# Add CAny owned-value wrapper and refactor TypeSchema.convert to return CAny

## TL;DR
- **BREAKING**: `TypeSchema.convert()` now returns `CAny` (owned `TVMFFIAny` wrapper) instead of plain Python objects; callers must use `.to_py()`.
- `CAny` is a new cdef class in `object.pxi` that owns a `TVMFFIAny` struct with proper ref-counting.
- `TypeSchema.from_annotation()` static method builds schemas from Python type annotations; `try_check_value()`/`try_convert()` removed in favor of raising variants.

## Key Exports

```python
class CAny:
    """Owned TVMFFIAny value wrapper with ref-counting."""
    # Interacts with: TVMFFIAny struct, TVMFFIIncRef/DecRef
    def to_py(self) -> Any: ...     # Convert to Python object
    # Invariant: DecRef called on dealloc

class TypeSchema:
    @staticmethod
    def from_annotation(annotation: type) -> TypeSchema: ...
        # Supports: primitives, Optional, Union, list/tuple/dict, CObject subclasses,
        # parameterized containers, DataType, Device, ctypes.c_void_p, __dlpack__ types
        # Interacts with: _TYPE_INDEX_TO_ORIGIN, _annotation_cobject helper
    def convert(self, value: Any) -> CAny: ...  # BREAKING: returns CAny, not Any
    def check_value(self, value: Any) -> CAny: ...
```

## Impact
- API: **Breaking** — `TypeSchema.convert()` returns `CAny`; `try_check_value`/`try_convert` removed.
- Behavioral: CObject origins use canonical short names via `_TYPE_INDEX_TO_ORIGIN`.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

```python
from tvm_ffi.core import TypeSchema
schema = TypeSchema.from_annotation(int)
cany = schema.convert(42)   # returns CAny
value = cany.to_py()        # returns 42
```
