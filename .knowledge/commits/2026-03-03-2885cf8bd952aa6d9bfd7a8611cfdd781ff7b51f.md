# Add CAny owned-value wrapper and refactor TypeSchema.convert

## TL;DR
- **BREAKING**: `TypeSchema.convert()` now returns `CAny` (owned `TVMFFIAny`) instead of a plain Python object; callers use `.to_py()` to recover the Python value. `try_check_value()` and `try_convert()` removed.
- New `CAny` cdef class owns a `TVMFFIAny` struct: init packs via `TVMFFIPyPyObjectToFFIAny` + `TVMFFIAnyViewToOwnedAny`; dealloc decrefs object handles; `to_py()` converts back to Python.
- New `TypeSchema.from_annotation(annotation)` builds a `TypeSchema` from Python type annotations (bare types, generics, `Optional`, `Union`, `Callable`, CObject subclasses, STL equivalents).

## Impact
- API: Breaking — `TypeSchema.convert()` return type changed from `object` to `CAny`. `try_convert()` and `try_check_value()` removed. New `TypeSchema.from_annotation()` added.
- Behavioral: Callers of `convert()` must call `.to_py()` to get Python values. Unregistered CObject subclasses now raise `TypeError` in `from_annotation()` instead of silently falling back.
- Flags/config: none
- Data formats/schemas: `_ORIGIN_TO_TYPE_INDEX` / `_TYPE_INDEX_TO_ORIGIN` tables extended.

## Usage Examples

```python
from tvm_ffi.core import TypeSchema

schema = TypeSchema.from_annotation(list[int])
result: CAny = schema.convert([1, 2, 3])
py_val = result.to_py()  # → Array([1, 2, 3]) or List([1, 2, 3])

# from_annotation covers generics
opt_schema = TypeSchema.from_annotation(Optional[str])
int_schema  = TypeSchema.from_annotation(int)
callable_schema = TypeSchema.from_annotation(Callable[[int, str], bool])
```
