# Add CAny owned-value wrapper and refactor TypeSchema.convert to return CAny
## TL;DR
- Introduces `CAny` as a Cython owned-value wrapper (mirrors C++ `Any`) for safe lifetime management of converted values.
- Refactors `TypeSchema.convert` to return `CAny` instead of raw pointers, preventing dangling-pointer bugs.
- Significantly expands test coverage in `test_type_check.py`.

## Key Exports

```python
class CAny:
    """Cython owned-value wrapper mirroring C++ Any."""
    # Invariant: owns the underlying TVMFFIAny value, destructs on dealloc
    # Interacts with: TypeSchema.convert, field setters
    # Extension: conversion from any Python value via TypeSchema
```

## Impact
- API: `CAny` added to `tvm_ffi` namespace. `TypeSchema.convert` returns `CAny`.
- Behavioral: Eliminates dangling-pointer risks in type conversion pipeline.
