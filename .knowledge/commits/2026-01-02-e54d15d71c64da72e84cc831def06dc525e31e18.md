# Add bounds checking for Tensor/TensorView size() and stride() to prevent out-of-bounds memory access

## TL;DR
- Adds runtime bounds checking to `Tensor::size(idx)`, `Tensor::stride(idx)`, `TensorView::size(idx)`, and `TensorView::stride(idx)` after negative-index adjustment, throwing `IndexError` on out-of-range indices.
- Fixes undefined behavior (array underflow) introduced in 573d76f when negative indices wrapped to still-negative values.
- Adds C++ GoogleTest cases for both `Tensor` and `TensorView` out-of-bounds scenarios; minor Python test type annotation cleanup.

## Key Exports

No new exports. Four existing methods gain bounds checking:

```python
class Tensor(ObjectRef):
    def size(self, idx: int64) -> int64: ...
        # CHANGED: now throws IndexError when adjusted_idx < 0 or adjusted_idx >= ndim
        # Old: no bounds check -- undefined behavior on out-of-range
        # New: adjusted_idx = idx if idx >= 0 else ndim + idx; check 0 <= adjusted_idx < ndim
        # Interacts with: TensorObj.shape, TensorObj.ndim, TVM_FFI_THROW(IndexError)

    def stride(self, idx: int64) -> int64: ...
        # CHANGED: same bounds checking as size()
        # Interacts with: TensorObj.strides, TensorObj.ndim, TVM_FFI_THROW(IndexError)

class TensorView:
    def size(self, idx: int64) -> int64: ...
        # CHANGED: same bounds checking pattern as Tensor::size()
        # Interacts with: tensor_.shape, tensor_.ndim, TVM_FFI_THROW(IndexError)

    def stride(self, idx: int64) -> int64: ...
        # CHANGED: same bounds checking pattern as Tensor::stride()
        # Interacts with: tensor_.strides, tensor_.ndim, TVM_FFI_THROW(IndexError)
```

## Impact
- API: none -- method signatures unchanged
- Behavioral: `size()` and `stride()` on both `Tensor` and `TensorView` now throw `IndexError` for out-of-range indices (previously undefined behavior). Indices in `[-ndim, ndim)` are unaffected.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**Before** (573d76f -- undefined behavior on out-of-range negative index):
```cpp
Tensor t = Empty({2, 3, 4}, DLDataType{kDLFloat, 32, 1}, DLDevice{kDLCPU, 0});
int64_t val = t.size(-4);  // adjusted_idx = 3 + (-4) = -1 -> reads shape[-1] (UB: array underflow)
int64_t s = t.stride(3);   // reads strides[3] (UB: out-of-bounds read)
```

**After** (e54d15d -- throws IndexError):
```cpp
Tensor t = Empty({2, 3, 4}, DLDataType{kDLFloat, 32, 1}, DLDevice{kDLCPU, 0});
// Both now throw IndexError with descriptive message:
EXPECT_THROW({ t.size(-4); }, tvm::ffi::Error);   // "Index -4 out of bounds for tensor with 3 dimensions"
EXPECT_THROW({ t.stride(3); }, tvm::ffi::Error);   // "Index 3 out of bounds for tensor with 3 dimensions"

// Valid indices still work:
int64_t last = t.size(-1);   // == 4 (adjusted_idx = 2)
int64_t first = t.stride(0); // == 12
```
