# Add bounds checking for Tensor/TensorView size() and stride() methods
## TL;DR
- Adds bounds checking to `Tensor::size(idx)`, `Tensor::stride(idx)`, `TensorView::size(idx)`, and `TensorView::stride(idx)` -- previously, out-of-range indices caused undefined behavior (buffer overread).
- Throws `IndexError` with a descriptive message when the adjusted index is out of range.
- Adds C++ and Python tests for out-of-bounds cases.

**Invariant violated before fix**: `size(idx)` and `stride(idx)` assumed the caller provided a valid index, leading to out-of-bounds memory access on invalid input.

**Invariant restored**: All four methods now validate `0 <= adjusted_idx < ndim` after negative index adjustment, throwing `IndexError` on violation.

## Key Exports

**`Tensor::size(int64_t idx)` / `Tensor::stride(int64_t idx)`** -- updated contract:
```cpp
// Throws IndexError if adjusted index is out of [0, ndim)
int64_t size(int64_t idx) const;
int64_t stride(int64_t idx) const;
```

**`TensorView::size(int64_t idx)` / `TensorView::stride(int64_t idx)`** -- same bounds checking added.

## Impact
- API: None (additive bounds check; callers with valid indices see no change)
- Behavioral: Invalid indices now throw `IndexError` instead of UB
- Flags/config: None
- Data formats/schemas: None

## Usage Examples

**Before (UB):**
```cpp
Tensor t = Empty({2, 3}, ...);
t.size(5);  // undefined behavior -- reads past shape array
```

**After (safe):**
```cpp
Tensor t = Empty({2, 3}, ...);
t.size(5);  // throws IndexError: "Index 5 out of bounds for tensor with 2 dimensions"
```
