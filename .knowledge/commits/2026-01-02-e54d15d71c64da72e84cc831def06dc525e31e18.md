# fix: Add bounds checking for size() and stride() methods on Tensor and TensorView

## TL;DR
- `Tensor::size(idx)` and `Tensor::stride(idx)` now throw `IndexError` for out-of-bounds `idx` (both positive and negative) instead of silently accessing invalid memory
- Same fix applied to `TensorView::size(idx)` and `TensorView::stride(idx)`
- Added 14 new C++ test cases and updated Python tests

## Impact
- API: Behavioral change — previously silent OOB access now throws `IndexError`; callers relying on silent UB are broken (but were already wrong)
- Behavioral: Out-of-bounds `size()`/`stride()` now raises `IndexError` in both C++ and Python
- Flags/config: none
- Data formats/schemas: none
