# Add ty type-checker as pre-commit hook, migrate optional deps to dependency-groups, and add ty: ignore suppressions

## TL;DR
- Adds `ty@0.0.15` (Astral Python type checker) as a pre-commit hook with `--error-on-warning`; pins `ty==0.0.15` in `[dependency-groups].dev`; removes `yamllint`/`taplo-format` from before `clang-format` and relocates them after.
- Migrates `[project.optional-dependencies].test` and `.torch` to `[dependency-groups].test`/`.torch` (PEP 735); updates CI install commands from `-e ".[test]"` to `--group test -e .`.
- Adds `# ty: ignore[invalid-assignment]` comments to all `torch = None` fallback patterns in test/example files; adds `ml_dtypes < 0.4.0` version guard in `test_dtype.py`.
