# Place ErrorKind second in TVM_FFI_CHECK macro

## TL;DR
- Swaps the parameter order of `TVM_FFI_CHECK` from `TVM_FFI_CHECK(ErrorKind, cond)` to `TVM_FFI_CHECK(cond, ErrorKind)`, placing the condition first and the error kind second.
- Updates all call sites in `tests/cpp/test_error.cc` to match the new parameter order.

## Key Exports

```python
# --- include/tvm/ffi/error.h ---

# Before:
# TVM_FFI_CHECK(ErrorKind, cond) -> if (!(cond)) TVM_FFI_THROW(ErrorKind) << ...
# After:
# TVM_FFI_CHECK(cond, ErrorKind) -> if (!(cond)) TVM_FFI_THROW(ErrorKind) << ...
# Invariant: cond is the first parameter, ErrorKind is the second
# Invariant: mirrors TVM_FFI_ICHECK(x) parameter style where condition comes first
```

## Impact
- API: Breaking change to the `TVM_FFI_CHECK` macro signature. All existing call sites must swap the argument order.
- Behavioral: No runtime behavior change; only the macro parameter order is swapped.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

```cpp
// Before this commit:

// After this commit:

```
