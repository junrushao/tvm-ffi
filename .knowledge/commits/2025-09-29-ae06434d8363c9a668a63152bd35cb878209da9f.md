# Swap TVM_FFI_CHECK argument order to place condition first
## TL;DR
- Changes `TVM_FFI_CHECK(ErrorKind, cond)` to `TVM_FFI_CHECK(cond, ErrorKind)` for consistency with `TVM_FFI_ICHECK(cond)` convention where the condition comes first.
- Updates all tests accordingly.

## Key Exports

```python
# C++ macro (pseudocode)
# Old: TVM_FFI_CHECK(ErrorKind, cond)
# New: TVM_FFI_CHECK(cond, ErrorKind)
def TVM_FFI_CHECK(cond, ErrorKind):
    """Check condition, throw ErrorKind on failure. Condition-first convention."""
    ...
```

## Impact
- API: Breaking change to `TVM_FFI_CHECK` macro argument order (introduced in same release cycle, `327e8cc`).
- Behavioral: None
- Flags/config: None
- Data formats/schemas: None

// Before: TVM_FFI_CHECK(ValueError, value >= 0)
// After:  TVM_FFI_CHECK(value >= 0, ValueError)
