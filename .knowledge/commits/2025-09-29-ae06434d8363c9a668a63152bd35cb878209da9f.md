# Swap TVM_FFI_CHECK parameter order to place condition before ErrorKind
## TL;DR
- Changes `TVM_FFI_CHECK(ErrorKind, cond)` to `TVM_FFI_CHECK(cond, ErrorKind)`, placing the condition first and the error kind second.
- Updates all existing call sites in `tests/cpp/test_error.cc` to match the new parameter order.
- Aligns with the convention where the checked condition comes first (consistent with `assert(cond)` and `TVM_FFI_ICHECK(cond)` patterns).

## Key Exports
**Macros**:

| Macro | Old signature | New signature |
|-------|--------------|---------------|
| `TVM_FFI_CHECK` | `TVM_FFI_CHECK(ErrorKind, cond)` | `TVM_FFI_CHECK(cond, ErrorKind)` |

Expansion (unchanged semantics):
```cpp
#define TVM_FFI_CHECK(cond, ErrorKind) \
  if (!(cond)) TVM_FFI_THROW(ErrorKind) << "Check failed: (" #cond << ") is false: "
```

## Impact
- API: **Breaking** -- all callers of `TVM_FFI_CHECK` must swap argument order. Blast radius is minimal since the macro was introduced in the immediately preceding commit (#69, 327e8cc).
- Behavioral: None -- the runtime semantics are identical.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Error handling macros** ([0006-error-handling.md](../designs/0006-error-handling.md)): `TVM_FFI_THROW(ErrorKind)` stream-style error creation.
- **TVM_FFI_ICHECK**: The existing condition-first check macro pattern that this change aligns with.

Design elements this commit produces:
- **TVM_FFI_CHECK(cond, ErrorKind)** (mutated): Parameter order swapped to condition-first, matching the `TVM_FFI_ICHECK(cond)` convention and standard `assert(cond)` idiom. This is a public C++ macro in `include/tvm/ffi/error.h`.

## Usage Examples
**Before** (commit #69):
```cpp
TVM_FFI_CHECK(ValueError, value >= 0) << "Value must be non-negative, got " << value;
```

**After** (this commit):
```cpp
TVM_FFI_CHECK(value >= 0, ValueError) << "Value must be non-negative, got " << value;
```
