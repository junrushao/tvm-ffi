## Usage Examples
The guide documents these end-to-end patterns from `examples/python_packaging/`:

**C symbol export and retrieval:**
```python
# C++ side: TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_two, ...)
# Python side:
mod = tvm_ffi.load_module("path/to/library.so")
result = mod.add_two(40)  # -> 42
```

**Global function registration:**
```python
@tvm_ffi.register_global_func("my_ffi_extension.add_one")
def add_one(x: int) -> int:
    return x + 1

add_one = tvm_ffi.get_global_func("my_ffi_extension.add_one")
result = add_one(3)  # -> 4
```

**Object class instantiation from Python (after C++ registration via ObjectDef):**
```python
pair = my_ffi_extension.IntPair(1, 2)
print(pair.sum())  # -> 3
```
