# Fix Windows build: explicit Python module linking and ARM64 InterlockedAdd64 fallback

## TL;DR

- Explicitly link `tvm_ffi_cython` to `Python::SABIModule` and `Python::Module` in CMakeLists.txt to fix Windows Cython build failures.
- Add preprocessor fallback defining `_InlineInterlockedAdd64` as `InterlockedAdd64` on ARM64 Windows when the intrinsic is unavailable.
- Bump CI ARM test matrix minimum Python from 3.9 to 3.10.

## Impact

- API: none
- Behavioral: none — fixes build failures on Windows (especially ARM64), no runtime behavior change
- Flags/config: CI matrix drops Python 3.9 from the `ubuntu-24.04-arm` test entry (bumped to 3.10)
- Data formats/schemas: none
