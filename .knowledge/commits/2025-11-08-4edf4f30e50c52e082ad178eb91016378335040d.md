# Expose TypeAttr column lookup to Python via _lookup_type_attr
## TL;DR
- Adds `_lookup_type_attr(type_index, attr_key)` Python function that queries the C type attribute table (`TVMFFIGetTypeAttrColumn`) and returns the attribute value for a given type index.
- Exposes `TVMFFITypeAttrColumn` struct and `TVMFFIGetTypeAttrColumn` C API function in the Cython `base.pxi` declarations.
- Moves the "more complex objects" comment divider in `c_api.h` to after `kTVMFFIOpaquePyObject`, reorders some `ReserveBuiltinTypeIndex` calls in `TypeTable` constructor (cosmetic).
- Adds explicit zero-initialization of `type_attr_columns_` and `type_attr_name_to_column_index_` in `TypeTable` constructor.

## Key Exports
**Python function** (exposed via `core.pyi`):
- `_lookup_type_attr(type_index: int, attr_key: str) -> Any` -- returns the type attribute value for the given type index and attribute key, or `None` if not found

**C API consumed** (already existed, now bound in Cython):
- `TVMFFIGetTypeAttrColumn(const TVMFFIByteArray* attr_name) -> const TVMFFITypeAttrColumn*` -- returns a column of type attributes keyed by attribute name
- `TVMFFITypeAttrColumn` struct: `{ const TVMFFIAny* data; size_t size; }`

## Impact
- API: new internal Python function `_lookup_type_attr`; no public API change
- Behavioral: none (no type attributes are defined yet; the function returns `None` for all lookups)
- Flags/config: none
- Data formats/schemas: the `kTVMFFIStaticObjectEnd` boundary in `c_api.h` is effectively unchanged (same types, comment moved)

## Design Elements
Design elements this commit consumes:
- Type attribute system (`TVMFFITypeAttrColumn`, `TVMFFIGetTypeAttrColumn`) -- part of the C ABI layer per `.knowledge/designs/0001-c-abi-layer.md`
- `TypeTable` singleton in `src/ffi/object.cc` per `.knowledge/designs/0003-object-system.md`

Design elements this commit produces:
- Python-side type attribute lookup (`_lookup_type_attr`) -- an extension point anticipated for `__repr__`, `__metadata__`, and other per-type attributes used by stubgen and dataclass machinery

## Usage Examples
```python
from tvm_ffi.core import _lookup_type_attr

# Currently returns None for all lookups (no type attrs defined yet)
result = _lookup_type_attr(64, "__metadata__")
assert result is None

# Future: when type attrs are registered in C++, this will return the value
# result = _lookup_type_attr(type_index, "__repr__")
```
