# Expose TypeAttr via _lookup_type_attr in Cython bindings
## TL;DR
- Adds a new C API function `TVMFFIGetTypeAttr` and Cython binding `_lookup_type_attr` to query type attributes from Python.
- Updates `c_api.h` with the new function signature and `object.cc` with the implementation.
- Anticipates future use cases like `__repr__` and `__metadata__` type attributes.

## Key Exports

**C API Functions:**
- `TVMFFIGetTypeAttr(type_index, attr_name, out) -> int` -- Look up a type attribute by name for a given type index.

**Python Functions:**
- `_lookup_type_attr(type_index, attr_name)` -- Cython wrapper that calls `TVMFFIGetTypeAttr`.

## Impact
- API: New `TVMFFIGetTypeAttr` C API function; new `_lookup_type_attr` Python function.
- ABI: New C API symbol added (non-breaking, additive).
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none
