# Expose type attribute lookup to Python via `_lookup_type_attr` Cython function
## TL;DR
- Adds `_lookup_type_attr(type_index, attr_key)` Cython function that wraps the existing `TVMFFIGetTypeAttrColumn` C API, enabling Python code to query per-type attribute columns by type index and attribute name.
- Relocates the "more complex objects" comment divider in `c_api.h` to after `kTVMFFIOpaquePyObject`, and explicitly initializes `TypeTable` member fields in the constructor initializer list.
- Reorders `ReserveBuiltinTypeIndex` calls in `TypeTable` constructor to match the enum value order (Bool=2 before Float=3, etc.).

## Impact
- API: Adds `_lookup_type_attr` to the Cython-level `tvm_ffi.core` module (internal API, prefixed with `_`). No public API change.
- Behavioral: none -- purely additive, no existing function behavior changes.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVMFFITypeAttrColumn` struct and `TVMFFIGetTypeAttrColumn` C API function ([0001-c-abi.md](../designs/0001-c-abi.md), [0008-reflection.md](../designs/0008-reflection.md)) -- the C-level column-oriented type attribute store, introduced in 162d600. This commit creates the first Python-visible read path.
- `ByteArrayArg` / `c_str` Cython helpers ([0012-python-bindings.md](../designs/0012-python-bindings.md)) -- for converting Python `str` to `TVMFFIByteArray` for C API calls.
- `make_ret` Cython function ([0012-python-bindings.md](../designs/0012-python-bindings.md)) -- for converting the raw `TVMFFIAny` result back to a Python object.

Design elements this commit produces:
- `_lookup_type_attr` Cython function -- first Python accessor for per-type attribute columns. Enables Python-side code (stubgen, dataclass decorators, `__repr__` dispatch) to query C++-registered type attributes without going through a global function call.
