# Expose TypeAttr column lookup to Python via `_lookup_type_attr` Cython function

## TL;DR
- Adds `_lookup_type_attr(type_index, attr_key)` Cython function that wraps the existing C API `TVMFFIGetTypeAttrColumn`, making per-type attribute columns accessible from Python.
- Reorders the `TVMFFITypeIndex` enum comment block in `c_api.h` and `ReserveBuiltinTypeIndex` calls in `object.cc` to align with numeric order (cosmetic, no functional change).
- Adds a basic test verifying `_lookup_type_attr` returns `None` for nonexistent attributes.

## Impact
- API: Adds new Python-visible function `tvm_ffi.core._lookup_type_attr`. No existing API changed.
- Behavioral: None -- purely additive.
- Flags/config: None.
- Data formats/schemas: None. The `TVMFFITypeIndex` enum comment block moved (cosmetic) but no enum values changed.

## Design Elements
Design elements this commit consumes:
- **TypeAttrColumn / TVMFFITypeAttrColumn** (C-level column array indexed by type_index): the existing per-type attribute storage. See [0007-ffi-reflection](../design-records/0007-ffi-reflection.md).
- **TVMFFIGetTypeAttrColumn** (C API function): retrieves a column by attribute name string. See [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md).
- **Cython `ByteArrayArg` + `make_ret`**: standard Cython helpers for converting Python strings to `TVMFFIByteArray` and C `TVMFFIAny` back to Python objects. See [0012-ffi-python-package](../design-records/0012-ffi-python-package.md).
- **ReserveBuiltinTypeIndex call ordering**: reordered to match numeric enum order (cosmetic). See [0003-ffi-object-system](../design-records/0003-ffi-object-system.md).

Design elements this commit produces:
- None -- this commit exposes existing C-level functionality to Python without introducing new design abstractions.

## Usage Examples
Looking up a type attribute from Python (from the test in this commit):

```python
from tvm_ffi.core import _lookup_type_attr

# Returns None when no attribute is registered for the given type and key
result = _lookup_type_attr(64, "__metadata__")
assert result is None

# Once C++ code registers an attribute via TypeAttrDef<T>().attr("__repr__", fn),
# it becomes accessible:
# repr_fn = _lookup_type_attr(some_type_index, "__repr__")
```
