# Expose TypeAttr lookup in Python via _lookup_type_attr() Cython function

## TL;DR
- Adds `_lookup_type_attr(type_index: int, attr_key: str) -> Any` in `python/tvm_ffi/cython/object.pxi`, backed by the existing C ABI `TVMFFIGetTypeAttrColumn`.
- Adds corresponding `TVMFFIGetTypeAttrColumn` C ABI declaration/adjustment in `include/tvm/ffi/c_api.h` and implementation in `src/ffi/object.cc`.
- Adds stub entry in `python/tvm_ffi/core.pyi`.

## Key Exports

```python
# python/tvm_ffi/cython/object.pxi
def _lookup_type_attr(type_index: int, attr_key: str) -> Any:
    """Look up a per-type attribute value from the C++ TypeAttr registry.
    Returns None if the attribute is not set for this type_index.
    # Interacts with: TVMFFIGetTypeAttrColumn C ABI, TypeAttrDef<T>.def(attr_key, value)
    # Invariant: returns None if column is NULL or type_index out of range
    # Use case: stubgen, dataclass __repr__, __metadata__ per-type annotations
    """
    ...

# C ABI (include/tvm/ffi/c_api.h)
def TVMFFIGetTypeAttrColumn(attr_key: ByteArray) -> TVMFFITypeAttrColumn*:
    """Return pointer to the dense column vector for this attribute key.
    Returns NULL if no such attribute has been registered.
    # Interacts with: TypeAttrDef<T>.def(), TypeTable column storage
    """
    ...
```

## Impact
- API: New Python function `_lookup_type_attr(type_index, attr_key)` (internal, prefixed with `_`).
- Behavioral: Python code can now query per-type attributes registered on the C++ side.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes: `TypeAttrDef<T>` registration (0006-reflection), `TypeTable` column storage (0001-c-abi)
Design elements this commit produces:
- `_lookup_type_attr` Python bridge for TypeAttr (0006-reflection, 0013-python-package)

## Usage Examples

```python
from tvm_ffi.cython.object import _lookup_type_attr
from tvm_ffi import TypeInfo

type_index = TypeInfo.lookup("my.Class").type_index
attr = _lookup_type_attr(type_index, "__repr__")
# Returns None if no __repr__ TypeAttr registered; otherwise returns the value
```
