# Expose TypeAttr via _lookup_type_attr API in Cython
## TL;DR
- Adds `_lookup_type_attr` to Cython's `object.pxi` for querying type attributes from the C++ type registry on the Python side.
- Renames C API constants for type attribute columns in `c_api.h` (3 line changes).
- Anticipates future use cases like `__repr__`, `__metadata__` for stubgen and dataclass integration.
