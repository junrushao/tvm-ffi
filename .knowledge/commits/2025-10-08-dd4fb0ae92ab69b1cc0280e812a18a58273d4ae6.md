# Add TypeSchema.repr(ty_map) for flexible type name overrides
## TL;DR
- Adds `TypeSchema.repr(ty_map=None)` method allowing callers to override type name rendering (e.g., `list` -> `Sequence`, `dict` -> `Mapping`) for stub generation.
- Refactors `__repr__` to delegate to `repr(ty_map=None)`.
- Auto-fills empty `list` args as `list[Any]` and empty `dict` args as `dict[Any, Any]` in `__post_init__`.
- Large stub file update in `core.pyi` (458 additions).

## Impact
- API: New `TypeSchema.repr(ty_map)` method. `TypeSchema` is no longer `frozen` (mutable in `__post_init__`).
- Flags/config: None.
- Data formats/schemas: None.
