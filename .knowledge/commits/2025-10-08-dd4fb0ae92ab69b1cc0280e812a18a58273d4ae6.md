# Add TypeSchema.repr(ty_map) for customizable type-string rendering

## TL;DR
- Adds `TypeSchema.repr(ty_map=None)` — a new method that renders a `TypeSchema` as a Python typing string with an optional mapping function applied to origin names (e.g. `"list" -> "Sequence"`, `"dict" -> "Mapping"`).
- `__repr__` now delegates to `repr(ty_map=None)`, centralising all formatting logic in one place.
- `TypeSchema` is made non-frozen (`frozen=True` removed), and unparameterised `list`/`dict` origins are normalised in `__post_init__` to `list[Any]`/`dict[Any, Any]`.

## Key Exports

```python
@dataclasses.dataclass(repr=False)   # NOTE: no longer frozen=True
class TypeSchema:
    """Type schema that describes a TVM FFI type."""
    origin: str
    args: tuple[TypeSchema, ...] = ()
    # Invariant: after __post_init__:
    #   origin=="list" and args==()  is impossible — normalised to (TypeSchema("Any"),)
    #   origin=="dict" and args==()  is impossible — normalised to (TypeSchema("Any"), TypeSchema("Any"))

    def __repr__(self) -> str: ...
    # Delegates to self.repr(ty_map=None)

    def repr(self, ty_map: Callable[[str], str] | None = None) -> str:
        """Render schema as Python typing string, optionally remapping origin names.

        Parameters
        ----------
        ty_map : Callable[[str], str], optional
            Applied to each origin name before formatting. Useful to emit
            abstract type names (e.g. Sequence, Mapping) instead of concrete
            Python builtins.

        Returns str in formats:
          - Union:    "T1 | T2"
          - Optional: "T | None"
          - Callable: "Callable[[arg1, arg2], ret]"   (args[0]=ret, args[1:]=params)
          - Generic:  "origin[arg1, arg2]"
          - Atom:     "origin"
        """
    # Interacts with: TypeField.metadata["type_schema"], TypeMethod.metadata["type_schema"]
    # Interacts with: get_global_func_metadata() — consumers call repr() to display schema
    # Extension: pass ty_map to remap any origin string globally (recursive, applied at every node)

    @staticmethod
    def from_json_obj(obj: dict[str, Any]) -> TypeSchema: ...
    @staticmethod
    def from_json_str(s: str) -> TypeSchema: ...
```

## Impact
- API: `TypeSchema.repr(ty_map=None)` is a new public method; `__repr__` output is unchanged (same string as before for all well-formed schemas). Callers that relied on `frozen=True` for immutability now need to be aware the object is mutable (though mutation is only done in `__post_init__`).
- Behavioral: `TypeSchema("list")` and `TypeSchema("dict")` now materialise default `args` in `__post_init__`. Before this commit `TypeSchema("list").args == ()` was possible; after, it is always `(TypeSchema("Any"),)`.
- Flags/config: none
- Data formats/schemas: C++ test side adds two new schema testing functions `"testing.schema_id_arr"` (accepts raw `const ArrayObj*`) and `"testing.schema_id_map"` (accepts raw `const MapObj*`) to cover unparameterised array/map schemas in JSON round-trips.

## Usage Examples

End-to-end: C++ registers a typed function → Python retrieves metadata → `TypeSchema.repr(ty_map)` customises the string.

```python
from tvm_ffi.core import TypeSchema
from tvm_ffi._ffi_api import get_global_func_metadata
import json

# --- Default repr (no mapping) ---
meta = get_global_func_metadata("testing.schema_id_arr_int")
schema = TypeSchema.from_json_str(meta["type_schema"])
assert str(schema) == "Callable[[list[int]], list[int]]"

# --- Custom mapping: stdlib abstract types ---
def _abstract(ty: str) -> str:
    return {"list": "Sequence", "dict": "Mapping"}.get(ty, ty)

assert schema.repr(_abstract) == "Callable[[Sequence[int]], Sequence[int]]"

# --- Unparameterised array (new test case) ---
schema2 = TypeSchema.from_json_str(
    get_global_func_metadata("testing.schema_id_arr")["type_schema"]
)
assert str(schema2) == "Callable[[list[Any]], list[Any]]"
# Before this commit, schema2.args[0].args would have been () not (TypeSchema("Any"),)
```
