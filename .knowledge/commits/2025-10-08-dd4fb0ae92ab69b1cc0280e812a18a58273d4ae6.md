# Add TypeSchema.repr(ty_map) for customizable type name rendering
## TL;DR
- Adds `TypeSchema.repr(ty_map)` method that accepts an optional callable to override origin type names during string rendering (e.g., `list` to `Sequence`, `dict` to `Mapping`).
- Normalizes unparameterized `list` and `dict` schemas to default `Any` type args in `__post_init__`, so `list` renders as `list[Any]` and `dict` renders as `dict[Any, Any]`.
- Removes `frozen=True` from `TypeSchema` dataclass to allow `__post_init__` to mutate `self.args`.

## Impact
- API: New public method `TypeSchema.repr(ty_map)`. Existing `__repr__` / `str()` behavior is preserved (delegates to `repr(ty_map=None)`).
- Behavioral: `TypeSchema("list")` now normalizes to `TypeSchema("list", (TypeSchema("Any"),))` in `__post_init__`. Similarly `TypeSchema("dict")` normalizes to 2 `Any` args. This changes equality behavior for schemas created with empty args. The `frozen=True` constraint is removed.
- Flags/config: none
- Data formats/schemas: C++ schema JSON is unchanged. Two new test functions (`testing.schema_id_arr`, `testing.schema_id_map`) emit schemas without type args (`{"type":"ffi.Array"}`, `{"type":"ffi.Map"}`), validating that the Python side correctly defaults to `Any`.

- `_TYPE_SCHEMA_ORIGIN_CONVERTER` mapping (`type_info.pxi`) -- converts C-level type names (`ffi.Array` -> `list`, `ffi.Map` -> `dict`).

Design elements this commit produces:
- `TypeSchema.repr(ty_map)` method -- new public API for customizable schema rendering.
- Unparameterized-container normalization invariant -- `list` and `dict` schemas always carry explicit `Any` type args after construction.

## Usage Examples
From `tests/python/test_metadata.py`, demonstrating `ty_map` to remap `list`/`dict` to `Sequence`/`Mapping`:

```python
from tvm_ffi.core import TypeSchema

def _replace_list_dict(ty: str) -> str:
    return {"list": "Sequence", "dict": "Mapping"}.get(ty, ty)

schema = TypeSchema.from_json_str(
    '{"type":"ffi.Function","args":[{"type":"ffi.Map","args":[{"type":"ffi.String"},{"type":"int"}]},{"type":"ffi.Map","args":[{"type":"ffi.String"},{"type":"int"}]}]}'
)
assert str(schema) == "Callable[[dict[str, int]], dict[str, int]]"
assert schema.repr(_replace_list_dict) == "Callable[[Mapping[str, int]], Mapping[str, int]]"
```
