# Fix ffi.cpp.load_inline on Windows by adding MSVC compiler/linker flags, ninja rule adaptation, path escaping, and DLL extension handling
## TL;DR
- Adds MSVC-specific compiler flags (`/MD`, `/EHsc`, 8 warning suppressions), linker flags (`/LIBPATH:` + import lib for `tvm_ffi.dll`), and ninja build rules (`/showIncludes` + `deps = msvc`, `/link /out:`) to `_generate_ninja_build`.
- Escapes colons in Windows paths (`C:\...` -> `C$:\...`) for ninja syntax, uses `.dll` extension instead of hardcoded `.so`, and decodes subprocess output with `"oem"` encoding on Windows.
- Enables 4 previously-xfailed test functions on `win32` platform.

## Key Exports
None — no new public API. Internal changes to `_generate_ninja_build` and `_build_ninja` helper functions.

## Impact
- API: none — `load_inline` public signature unchanged
- Behavioral: `load_inline` now produces working DLLs on Windows; previously failed at compile, link, or load stages
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Module system** (`0011-module-system.md`): `load_module()` is called with the built DLL path; extension changed from `.so` to `.dll` on Windows
- **Python bindings** (`0012-python-bindings.md`): `find_libtvm_ffi()` from `tvm_ffi.libinfo` is newly consumed to locate the TVM FFI shared library for Windows linking
- **Ninja build generation**: internal `_generate_ninja_build` function (no design record)

Design elements this commit produces:
- None — purely fixes existing functionality for a new platform

## Usage Examples
Before (Windows): `load_inline` fails because:
1. Missing MSVC flags cause compilation errors
2. No `/LIBPATH:` for `tvm_ffi.dll` causes link failure
3. Hardcoded `.so` extension causes file-not-found at load time
4. Unescaped `C:\` paths break ninja syntax

After (Windows): `load_inline` works end-to-end:
```python
import tvm_ffi.cpp

mod = tvm_ffi.cpp.load_inline(
    name="hello",
    cpp_sources="""
    TVM_FFI_REGISTER_GLOBAL("hello").set_body_typed([](int x) -> int { return x + 1; });
    """,
)
f = mod["hello"]
assert f(41) == 42
```
