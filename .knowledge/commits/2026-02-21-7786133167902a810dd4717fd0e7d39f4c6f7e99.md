# Use distinct container type origins in type schema and stub generation

## TL;DR
- Changes `TypeSchema` origin mapping to preserve container identity: `ffi.Array` -> `Array`, `ffi.List` -> `List`, `ffi.Map` -> `Map`, `ffi.Dict` -> `Dict` (previously all collapsed to `list`/`dict`).
- Stub generation now emits `Sequence` for Array, `MutableSequence` for List, `Mapping` for Map, `MutableMapping` for Dict -- matching the Python ABCs each container implements.
- Adds `docs/concepts/containers.rst` documenting all container types, mutability semantics, and thread safety.

## Key Exports

**Type schema origin mapping (`type_info.pxi`):**

| C++ type key | Old origin | New origin |
|-------------|-----------|-----------|
| `ffi.Array` | `list` | `Array` |
| `ffi.List` | `list` | `List` |
| `ffi.Map` | `dict` | `Map` |
| `ffi.Dict` | `dict` | `Dict` |

**Stub type mapping (`stub/consts.py` `TY_MAP_DEFAULTS`):**

| Schema origin | Python annotation |
|--------------|-------------------|
| `Array` | `collections.abc.Sequence` |
| `List` | `collections.abc.MutableSequence` |
| `Map` | `collections.abc.Mapping` |
| `Dict` | `collections.abc.MutableMapping` |

**`TypeSchema` validation** (`type_info.pxi`):
- `origin in ("list", "Array", "List")` -- 0 or 1 type arg
- `origin in ("dict", "Map", "Dict")` -- 0 or 2 type args
- Backward compat: raw `list`/`dict` origins still accepted

## Impact
- API: Generated stub annotations change from `Sequence`/`Mapping` (for all) to distinct `Sequence`/`MutableSequence`/`Mapping`/`MutableMapping` based on container mutability.
- Behavioral: `TypeSchema.repr()` now returns `Array[int]` instead of `list[int]`, `Map[str, int]` instead of `dict[str, int]`.
- Flags/config: `D105` (undocumented-magic-method) added to global ruff ignore in `pyproject.toml`.
- Data formats/schemas: TypeSchema JSON `"type"` field values unchanged (still `"ffi.Array"` etc.), but parsed origins change.

## Usage Examples
```python
# TypeSchema now preserves container identity
s = TypeSchema.from_json_str('{"type":"ffi.Map","args":[{"type":"str"},{"type":"int"}]}')
assert s.repr() == "Map[str, int]"

s = TypeSchema.from_json_str('{"type":"ffi.Array","args":[{"type":"int"}]}')
assert s.repr() == "Array[int]"

# Stub generation maps to correct Python ABCs
# Generated stub for a function taking Array[int]:
#   def foo(arr: Sequence[int]) -> None: ...
# Generated stub for a function taking Dict[str, int]:
#   def bar(d: MutableMapping[str, int]) -> None: ...
```
