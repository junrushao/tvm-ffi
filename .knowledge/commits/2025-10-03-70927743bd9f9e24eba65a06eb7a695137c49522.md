# Fix memory leak in Cython tensor DLPack return path by releasing original chandle
## TL;DR
- Fixed a reference count leak in `make_tensor_from_chandle` where the original `chandle` was not released after successful DLPack-to-PyObject conversion, causing GPU memory to grow unboundedly when tensors were allocated in C++ and returned to Python.
- Added error-path cleanup: if `c_dlpack_to_pyobject` throws, the DLManagedTensor deleter is called before falling through to the default chandle path.
- Added a CUDA regression test (`test_cuda_memory_alloc_noleak`) that verifies memory does not grow when repeatedly calling a C++ function that allocates and returns a tensor.

## Key Exports
None

## Impact
- API: None
- Behavioral: Tensors allocated in C++ and returned to Python via the DLPack auto-import path no longer leak one ref count per return. This affects any code using `load_inline` or `load_module` with CUDA tensor returns when torch DLPack auto-import is active.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **DLPack exchange protocol** (0006-ffi-containers): `TVMFFITensorToDLPackVersioned` creates a `DLManagedTensorVersioned` that holds its own reference to the underlying tensor object.
- **`c_dlpack_to_pyobject` return-path auto-import** (0012-ffi-python-package): When active, tensors returned from FFI calls are automatically wrapped as framework tensors (e.g., `torch.Tensor`) via DLPack.
- **`TVMFFIObjectDecRef` C ABI** (0001-ffi-c-abi): Used to release the original chandle reference after ownership is transferred.
- **`load_inline`** (0014-ffi-load-inline): Used in the regression test to compile a C++ function that allocates and returns a tensor.

Design elements this commit produces: None

## Usage Examples
Before (leaking):
```cython
# make_tensor_from_chandle — DLPack success path
c_dlpack_to_pyobject(dlpack, &py_obj)
tensor = <Tensor>(<PyObject*>py_obj)
Py_DECREF(tensor)
return tensor  # BUG: chandle ref count never released — leaked
```

After (fixed):
```cython
# make_tensor_from_chandle — DLPack success path
c_dlpack_to_pyobject(dlpack, &py_obj)
tensor = <Tensor>(<PyObject*>py_obj)
Py_DECREF(tensor)
# DLManagedTensor holds its own ref; release the original chandle
TVMFFIObjectDecRef(chandle)
return tensor

# Error path: clean up the DLManagedTensor before falling through
except Exception:
    dlpack.deleter(dlpack)
    pass
```
