## Design Elements
Design elements this commit consumes:
- **Function system** (0003): The new docs section describes the pattern of registering compiler runtime state via `TVM_FFI_STATIC_INIT_BLOCK` + `reflection::GlobalDef` and retrieving it with `GetGlobalRequired` / `TVMFFIGetGlobalFunction`.
- **Module system** (0011): The docs recommend packaging compiler runtimes as shared libraries loaded before kernels.
- **C ABI** (0007): The docs reference `TVMFFIGetGlobalFunction` and `TVMFFIEnvGetStream` as the C-level access points.
