## Design Elements
Design elements this commit consumes:
- **Global function registration** (`0004-ffi-function-system`): the doc describes registering runtime state accessors via `TVM_FFI_STATIC_INIT_BLOCK` + `refl.GlobalDef().def(...)`, and retrieving them via `GetGlobalRequired()` / `TVMFFIGetGlobalFunction()`.
- **Module system** (`0011-ffi-module-system`): references shared library packaging and the `__tvm_ffi_` symbol convention.
- **Packaging and distribution** (`0013-ffi-packaging-and-distribution`): recommends distributing compiler runtime as a shared library inside a Python/C++ package.
- **C env API** (`0011-ffi-module-system`): references `TVMFFIEnvGetStream` as an example of common state managed by TVM FFI itself.

## Usage Examples
The commit itself provides an inline usage example in the documentation (singleton + `TVM_FFI_STATIC_INIT_BLOCK` pattern):

```cpp
class GlobalState {
    // ... compiler-specific state variables
public:
    static GlobalState* Global() {
        static auto* inst = new GlobalState();
        return inst;
    }
};

TVM_FFI_STATIC_INIT_BLOCK() {
    using refl = tvm::ffi::reflection;
    refl.GlobalDef().def("mylang.get_global_state",
                         []() -> void* { return GlobalState::Global(); });
}

// In a kernel: retrieve the state
auto f = GetGlobalRequired("mylang.get_global_state");
void* state = f();
```
