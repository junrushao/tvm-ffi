## Usage Examples
The new documentation section in `docs/guides/compiler_integration.md` provides this canonical usage pattern for compiler runtime state:

```c++
class GlobalState {
  // ... state variables ...
 public:
  static GlobalState* Global() {
    static auto* inst = new GlobalState();
    return inst;
  }
};

TVM_FFI_STATIC_INIT_BLOCK() {
  using refl = tvm::ffi::reflection;
  refl.GlobalDef().def("mylang.get_global_state",
    []() -> void* { return GlobalState::Global(); });
}

// Retrieval in C++ kernel:
// GetGlobalRequired("mylang.get_global_state")
// Retrieval via C ABI:
// TVMFFIGetGlobalFunction("mylang.get_global_state", ...)
```
