# Add GitHub Actions workflow to build and publish torch_c_dlpack_ext wheels to PyPI
## TL;DR
- Adds `.github/workflows/torch_c_dlpack.yml`, a manual-dispatch workflow that builds `torch_c_dlpack_ext` shared libraries for PyTorch 2.4 through 2.9 across x86_64/aarch64 and Python 3.9--3.13, then packages and publishes them to PyPI.
- The workflow uses manylinux_2_28 containers with CUDA 13.0 to produce CPU and CUDA variants of the extension for each torch version.
- Builds are audited with `auditwheel` (excluding torch/c10 libs) and uploaded via trusted-publisher OIDC attestation.
