# Add GitHub Actions workflow for torch-c-dlpack-ext PyPI release
## TL;DR
- Add `.github/workflows/torch_c_dlpack.yml` — a `workflow_dispatch`-triggered GitHub Actions workflow that builds torch C DLPack extension shared libraries for multiple torch versions (2.4–2.7), Python versions (cp39–cp313), and architectures (x86_64, aarch64), then packages and publishes wheels to PyPI.
- Builds use manylinux_2_28 containers with CUDA 13.0 toolkit; produces both CPU and CUDA variants.
- Workflow has three jobs: `build_libs` (compile `.so` per torch version/arch), `build_wheels` (assemble into pip wheels), `publish` (upload to PyPI via trusted publisher).
