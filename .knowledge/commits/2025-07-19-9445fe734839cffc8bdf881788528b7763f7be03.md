# Add reflection-based structural equality and hashing with AccessPath diagnostics
## TL;DR
- Introduces `StructuralEqual` and `StructuralHash` classes that compare/hash `Any` values by walking reflection-registered fields, supporting tree nodes, DAG nodes, free variables, and unique instances.
- Adds `TVMFFISEqHashKind` enum and per-field flags (`SEqHashIgnore`, `SEqHashDef`) to `c_api.h`, extending the reflection metadata with structural comparison semantics.
- Introduces `AccessPath`/`AccessStep` for diagnostic error reporting -- on mismatch, `GetFirstMismatch` returns the exact field/index/key path to the first differing element.

# --- C ABI enums (c_api.h) ---

class TVMFFISEqHashKind(IntEnum):
    """Per-type structural comparison strategy."""
    kTVMFFISEqHashKindUnsupported = 0      # Fallback to pointer equality
    kTVMFFISEqHashKindTreeNode = 1         # Compare fields recursively
    kTVMFFISEqHashKindFreeVar = 2          # Variable binding: can be mapped to another var in def region
    kTVMFFISEqHashKindDAGNode = 3          # Like tree but tracks seen nodes for DAG dedup
    kTVMFFISEqHashKindConstTreeNode = 4    # Tree node guaranteed free-var-free; pointer == is fast accept
    kTVMFFISEqHashKindUniqueInstance = 5   # Singleton; pointer equality only
    # Interacts with: TVMFFITypeExtraInfo.structural_eq_hash_kind, Object._type_s_eq_hash_kind
    # Invariant: kTVMFFISEqHashKindUnsupported falls back to pointer comparison in both equal and hash
    # Extension: new comparison kinds can be added by extending this enum and handler switch

# New field flag bits (extend existing TVMFFIFieldFlagBitMask):
# kTVMFFIFieldFlagBitMaskSEqHashIgnore = 1 << 3   # Field excluded from structural eq/hash
# kTVMFFIFieldFlagBitMaskSEqHashDef    = 1 << 4   # Field enters def region (enables free var mapping)

class StructuralEqual:
    """Reflection-driven recursive structural equality."""

    @staticmethod
    def Equal(lhs: Any, rhs: Any, map_free_vars: bool = False,
              skip_ndarray_content: bool = False) -> bool: ...
        # Interacts with: TVMFFITypeExtraInfo.structural_eq_hash_kind, ForEachFieldInfo, FieldGetter
        # Invariant: type_index mismatch -> false immediately (no cross-type equality)
        # Invariant: POD types compared by v_int64 bitwise equality

    def __call__(self, lhs: Any, rhs: Any) -> bool:

        # Invariant: consistent with StructuralEqual (equal objects -> same hash)

    def __call__(self, value: Any) -> uint64:

## Impact
- API: `TVMFFITypeExtraInfo.total_size` narrowed from `int64` to `int32`, and `structural_eq_hash_kind` field added. Callers reading `TVMFFITypeExtraInfo` must account for the new layout. `Bytes::memncmp` moved from private to public in `string.h`.
- Behavioral: Objects without `extra_info` or with `kTVMFFISEqHashKindUnsupported` fall back to pointer equality (same as before). No behavioral change for existing types that do not opt in.
- Flags/config: Two new field flag bits (`1<<3`, `1<<4`) added to `TVMFFIFieldFlagBitMask`. Existing flag values unchanged.
- Data formats/schemas: `TVMFFITypeExtraInfo` struct layout changed (binary-incompatible with prior versions).

## Design Elements
Design elements this commit consumes:
- **Reflection field iteration** (`ForEachFieldInfo`, `FieldGetter`) from `0007-ffi-reflection` -- drives the recursive field-by-field comparison/hashing.
- **Object type system** (`TVMFFITypeInfo`, `TVMFFIGetTypeInfo`, `type_index`) from `0003-ffi-object-system` -- used to dispatch comparison strategy per type.
- **Container type indices** (`kTVMFFIArray`, `kTVMFFIMap`, `kTVMFFIShape`, `kTVMFFINDArray`) from `0001-ffi-c-abi` / `0006-ffi-containers` -- switch dispatch for built-in container comparison.
- **AnyUnsafe internals** (`TVMFFIAnyPtrFromAny`, `MoveFromAnyAfterCheck`, `CopyFromAnyViewAfterCheck`) from `0002-ffi-any-value-system` -- low-level type-erased value access.
- **StableHashCombine / StableHashBytes** utility functions.

Design elements this commit produces:
- **TVMFFISEqHashKind enum** -- per-type structural comparison strategy (5 modes + unsupported).
- **SEqHash field flags** (`kTVMFFIFieldFlagBitMaskSEqHashIgnore`, `kTVMFFIFieldFlagBitMaskSEqHashDef`) -- per-field metadata for comparison control.
- **Object._type_s_eq_hash_kind** convention -- static constexpr on Object subclasses to declare comparison mode.
- **AccessPath / AccessStep** -- diagnostic path objects for pinpointing structural mismatches.
- **StructuralEqual / StructuralHash** -- the comparison/hashing engine classes.
- **AttachFieldFlag trait** -- builder trait for attaching field flags during reflection registration.
- **TVM_FFI_EXTRA_CXX_API macro** -- visibility annotation for extra C++ APIs in .cc files.

## Usage Examples

Declaring a type with structural equality support and using field flags:
```cpp
// Define a function-like object with free variable bindings
class TFuncObj : public Object {
 public:
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;
  // ...
  static void RegisterReflection() {
    namespace refl = tvm::ffi::reflection;
    refl::ObjectDef<TFuncObj>()
        .def_ro("params", &TFuncObj::params, refl::AttachFieldFlag::SEqHashDef())  // def region
        .def_ro("body", &TFuncObj::body)
        .def_ro("comment", &TFuncObj::comment, refl::AttachFieldFlag::SEqHashIgnore());  // ignored
  }
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
  // ...
};

// Compare two functions -- free vars are mapped positionally
TVar x("x"), y("y");
TFunc fa({x}, {TInt(1), x}, "comment a");
TFunc fb({y}, {TInt(1), y}, "comment b");
refl::StructuralEqual()(fa, fb);  // true: comment ignored, x<->y mapped

// Get diagnostic path on mismatch
TFunc fc({x}, {TInt(1), TInt(2)}, "c");
auto mismatch = refl::StructuralEqual::GetFirstMismatch(fa, fc);
// mismatch->get<0>() == [ObjectField("body"), ArrayIndex(1)]
```
