# Add reflection-driven structural equality and hashing for FFI objects
## TL;DR
- Introduces `StructuralEqual` and `StructuralHash` classes that recursively compare/hash FFI objects using reflection metadata (field info), eliminating per-type handwritten equality/hash implementations.
- Adds `TVMFFISEqHashKind` enum to the C ABI, encoding five comparison semantics per type: Unsupported, TreeNode, FreeVar, DAGNode, ConstTreeNode, UniqueInstance. Each object type declares its kind via `_type_s_eq_hash_kind`.
- Introduces `AccessPath`/`AccessStep` for structured error reporting -- `GetFirstMismatch` returns the exact path (field, array index, map key) to the first differing element.
- Extends `TVMFFIFieldFlagBitMask` with `SEqHashIgnore` (skip field during comparison) and `SEqHashDef` (field enters a definition region where free variables can be mapped).

## Impact
- API: `TVMFFITypeExtraInfo.total_size` narrowed from `int64_t` to `int32_t` (potential breaking for out-of-tree code reading this field). New `structural_eq_hash_kind` field added to `TVMFFITypeExtraInfo`. Two new field flag bits. `Bytes::memncmp` moved from private to public.
- Behavioral: Objects with `_type_s_eq_hash_kind != Unsupported` and registered reflection can now be structurally compared/hashed via the new APIs. Objects without reflection fall back to pointer equality.
- Flags/config: Two new field flag bits (`SEqHashIgnore`, `SEqHashDef`) and per-type `_type_s_eq_hash_kind` control comparison behavior.
- Data formats/schemas: `TVMFFITypeExtraInfo` struct layout changed (breaking C ABI change if consumed by external code).

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`.knowledge/designs/0008-reflection.md`): Uses `ForEachFieldInfo`, `FieldGetter`, `TVMFFIFieldInfo` to iterate and read object fields generically.
- **Object system** (`.knowledge/designs/0002-object-system.md`): Extends `Object` base with `_type_s_eq_hash_kind`. Uses `ObjectRef`, `ObjectPtrHash`, `ObjectPtrEqual` for identity maps.
- **C ABI type table** (`.knowledge/designs/0001-c-abi.md`): Extends `TVMFFITypeExtraInfo` and `TVMFFIFieldFlagBitMask` enums.
- **Any/AnyView system** (`.knowledge/designs/0003-any-system.md`): All comparisons operate on `Any` values, using `AnyUnsafe` internals for efficient type dispatch.
- **Containers** (`.knowledge/designs/0007-containers.md`): Specialized comparison for `Array`, `Map`, `Shape`, `NDArray`.

Design elements this commit produces:
- **Structural equality/hash subsystem**: `StructuralEqual`, `StructuralHash`, `StructEqualHandler`, `StructuralHashHandler` -- reflection-driven recursive comparison and hashing.
- **SEqHash kind taxonomy**: `TVMFFISEqHashKind` enum defining five comparison semantics (TreeNode, FreeVar, DAGNode, ConstTreeNode, UniqueInstance).
- **Access path error reporting**: `AccessStep`, `AccessPath`, `AccessPathPair` for pinpointing structural mismatches.
- **Field-level comparison control**: `AttachFieldFlag::SEqHashDef()` / `SEqHashIgnore()` traits and corresponding flag bits.
- **TVM_FFI_EXTRA_CXX_API macro**: Convention for marking non-core C++ APIs with reduced compile-time overhead.

## Usage Examples
**Context**: Defining objects with structural equality semantics and comparing them.

```cpp
// 1. Declare type with SEqHash kind
class MyExprObj : public Object {
 public:
  int64_t value;
  String name;
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
  static constexpr const char* _type_key = "my.Expr";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyExprObj, Object);
};

// 2. Register reflection with field flags
refl::ObjectDef<MyExprObj>()
    .def_ro("value", &MyExprObj::value)
    .def_ro("name", &MyExprObj::name, refl::AttachFieldFlag::SEqHashIgnore());
    // "name" field is skipped during structural comparison

// 3. Compare
ObjectRef a = make_my_expr(42, "foo");
ObjectRef b = make_my_expr(42, "bar");
bool eq = refl::StructuralEqual::Equal(a, b);  // true (name ignored)
uint64_t h = refl::StructuralHash::Hash(a);     // stable hash

// 4. Diagnose mismatch with access path
ObjectRef c = make_my_expr(99, "baz");
auto mismatch = refl::StructuralEqual::GetFirstMismatch(a, c);
// mismatch->get<0>() = [AccessStep::ObjectField("value")]
```

**Context**: Free variable mapping in function-like structures.

```cpp
// TVar has _type_s_eq_hash_kind = FreeVar
// TFunc has _type_s_eq_hash_kind = TreeNode, params field tagged SEqHashDef
TVar x("x"), y("y");
TFunc fa({x}, {TInt(1), x}, "comment a");
TFunc fb({y}, {TInt(1), y}, "comment b");
// Structurally equal: x maps to y in the def region, comment is ignored
assert(refl::StructuralEqual()(fa, fb));
assert(refl::StructuralHash()(fa) == refl::StructuralHash()(fb));
```
