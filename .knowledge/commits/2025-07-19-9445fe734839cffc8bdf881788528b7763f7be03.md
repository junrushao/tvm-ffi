# Add reflection-based structural equality and hash with AccessPath diagnostics
## TL;DR
- Introduces `StructuralEqual` and `StructuralHash` classes in `tvm::ffi::reflection` that recursively compare/hash `Any` values using the reflection field registry, supporting tree, DAG, free-variable, and constant-tree node semantics.
- Adds `AccessPath`/`AccessStep` for structured mismatch diagnostics: `GetFirstMismatch` returns the exact field/index/key path where two values diverge.
- Extends the C ABI with `TVMFFISEqHashKind` enum, new `TVMFFIFieldFlagBitMask` bits (`SEqHashIgnore`, `SEqHashDef`), `TVM_FFI_EXTRA_CXX_API` macro, and adds `structural_eq_hash_kind` field to `TVMFFITypeExtraInfo` (breaking: `total_size` narrowed from `int64_t` to `int32_t`).

## Key Exports

**Enums (C ABI)**:
- `TVMFFISEqHashKind` -- `{Unsupported=0, TreeNode=1, FreeVar=2, DAGNode=3, ConstTreeNode=4, UniqueInstance=5}`. Per-type structural comparison semantics.
- `kTVMFFIFieldFlagBitMaskSEqHashIgnore = 1 << 3` -- Field flag: skip this field during structural eq/hash.
- `kTVMFFIFieldFlagBitMaskSEqHashDef = 1 << 4` -- Field flag: entering a definition region where free vars can be mapped.

**Structs (C ABI change)**:
- `TVMFFITypeExtraInfo.total_size` narrowed from `int64_t` to `int32_t`.
- `TVMFFITypeExtraInfo.structural_eq_hash_kind` (`TVMFFISEqHashKind`) -- new field.

**Macros**:
- `TVM_FFI_EXTRA_CXX_API` -- Marks non-core C++ APIs implemented in `.cc` files. Defaults to `TVM_FFI_DLL`. Used for extra features that depend on but are not required by core functionality.

**Classes (C++)**:
- `StructuralEqual` (`reflection/structural_equal.h`):
  - `static bool Equal(const Any& lhs, const Any& rhs, bool map_free_vars=false, bool skip_ndarray_content=false)`
  - `static Optional<AccessPathPair> GetFirstMismatch(const Any& lhs, const Any& rhs, bool map_free_vars=false, bool skip_ndarray_content=false)`
  - `bool operator()(const Any& lhs, const Any& rhs) const` -- convenience, calls `Equal(lhs, rhs, false, true)`
- `StructuralHash` (`reflection/structural_hash.h`):
  - `static uint64_t Hash(const Any& value, bool map_free_vars=false, bool skip_ndarray_content=false)`
  - `uint64_t operator()(const Any& value) const` -- convenience, calls `Hash(value)`
- `AccessStepObj` (`reflection/access_path.h`) -- Object subclass with `{kind: AccessKind, key: Any}`.
- `AccessStep` -- ObjectRef wrapper with static factories: `ObjectField(String)`, `ArrayIndex(int64_t)`, `ArrayIndexMissing(int64_t)`, `MapKey(Any)`, `MapKeyMissing(Any)`.
- `AccessKind` -- `enum class : int32_t {kObjectField=0, kArrayIndex=1, kMapKey=2, kArrayIndexMissing=3, kMapKeyMissing=4}`.
- Type aliases: `AccessPath = Array<AccessStep>`, `AccessPathPair = Tuple<AccessPath, AccessPath>`.

**FieldInfoTrait (C++)**:
- `AttachFieldFlag` (`reflection/registry.h`) -- `FieldInfoTrait` subclass that OR-s a bitmask flag onto `TVMFFIFieldInfo::flags`. Static helpers: `SEqHashDef()`, `SEqHashIgnore()`.

**Object metadata field**:
- `Object::_type_s_eq_hash_kind = kTVMFFISEqHashKindUnsupported` -- new static constexpr on `Object` base class. Subclasses override to opt into structural comparison.

**Global functions (registered)**:
- `"ffi.reflection.GetFirstStructuralMismatch"` -> `StructuralEqual::GetFirstMismatch`
- `"ffi.reflection.StructuralHash"` -> `StructuralHash::Hash`

## Impact
- API: New public headers `reflection/structural_equal.h`, `reflection/structural_hash.h`, `reflection/access_path.h`. New `AttachFieldFlag` trait class in `registry.h`. `Bytes::memncmp` moved from `private` to `public` in `string.h`.
- ABI: **Breaking**. `TVMFFITypeExtraInfo.total_size` changed from `int64_t` to `int32_t`. New `TVMFFISEqHashKind structural_eq_hash_kind` field appended. Two new `TVMFFIFieldFlagBitMask` constants added (bits 3, 4). This changes the layout of `TVMFFITypeExtraInfo`.
- Behavioral: `ObjectDef::RegisterExtraInfo` now reads `Class::_type_s_eq_hash_kind` and writes it to `TVMFFITypeExtraInfo`. `ReflectionDefBase::FieldSetter<Any>` now uses direct assignment instead of `cast<Any>()` (correctness fix for `Any`-typed fields).
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **Reflection field registry** (`.knowledge/designs/reflection.md`) -- `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`, `FieldGetter`, `TVMFFIFieldInfo`, `TVMFFITypeExtraInfo` for traversing object fields during comparison/hashing.
- **Object system** (`.knowledge/designs/object-system.md`) -- `Object`, `ObjectRef`, `_type_key`, `_type_index`, type hierarchy metadata, `same_as()` for pointer equality.
- **Container types** (`.knowledge/designs/containers.md`) -- `Array`, `Map`, `Shape`, `NDArray`, `String`/`Bytes` (including `Bytes::memncmp`), `Tuple`, `Optional`. Each container type has dedicated comparison/hash logic.
- **Any system** (`.knowledge/designs/any-system.md`) -- `Any`, `AnyView`, `AnyUnsafe` internals for type-erased value access.
- **C ABI** (`.knowledge/designs/c-abi.md`) -- `TVMFFIFieldFlagBitMask`, `TVMFFITypeExtraInfo`, `TVM_FFI_DLL`, `TypeIndex` constants.
- **FieldInfoTrait protocol** (`.knowledge/designs/reflection.md`) -- Extended with `AttachFieldFlag` as a new trait subclass.

Design elements this commit produces:
- **Structural equality/hash protocol** -- A new reflection-driven protocol where types opt in via `_type_s_eq_hash_kind` and field-level flags (`SEqHashIgnore`, `SEqHashDef`). The comparison respects tree vs. DAG vs. free-variable semantics. This is a core design element that downstream compilers (e.g., TVM Relax) will rely on for IR comparison.
- **AccessPath diagnostics** -- `AccessStep`/`AccessPath`/`AccessPathPair` provide structured first-mismatch reporting, replacing opaque boolean equality results with traceable field-by-field paths.
- **TVM_FFI_EXTRA_CXX_API category** -- A new API visibility category for non-core C++ features that are ABI-stable within a single ABI family (Itanium or MSVC) but not across them. Distinguished from `TVM_FFI_DLL` (core) by intent, not by current expansion.
- **TVMFFISEqHashKind enum** -- Five-valued semantic classification for structural comparison behavior, stored per-type in `TVMFFITypeExtraInfo`.
- **AttachFieldFlag trait** -- Extends the `FieldInfoTrait` protocol with arbitrary bitmask flag attachment, generalizing beyond `DefaultValue`.

## Usage Examples

**Structural equality with mismatch diagnostics (C++, from test):**
```cpp
namespace refl = tvm::ffi::reflection;

// Compare arrays
Array<int> a = {1, 2, 3};
Array<int> b = {1, 2, 3};
assert(refl::StructuralEqual()(a, b));
assert(refl::StructuralHash()(a) == refl::StructuralHash()(b));

// Get first mismatch path
Array<int> c = {1, 3};
auto diff = refl::StructuralEqual::GetFirstMismatch(a, c);
// diff->get<0>() == [ArrayIndex(1)], diff->get<1>() == [ArrayIndex(1)]
```

**Defining a type with structural eq/hash semantics and field flags:**
```cpp
class TFuncObj : public Object {
 public:
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;

  static void RegisterReflection() {
    namespace refl = tvm::ffi::reflection;
    refl::ObjectDef<TFuncObj>()
        .def_ro("params", &TFuncObj::params, refl::AttachFieldFlag::SEqHashDef())
        .def_ro("body", &TFuncObj::body)
        .def_ro("comment", &TFuncObj::comment, refl::AttachFieldFlag::SEqHashIgnore());
  }

  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
  // ...
};
```

**Free variable mapping:**
```cpp
TVar a("a"), b("b");
// Without map_free_vars: different pointers => not equal
assert(!refl::StructuralEqual::Equal(a, b));
// With map_free_vars: free vars are mapped positionally
assert(refl::StructuralEqual::Equal(a, b, /*map_free_vars=*/true));
```
