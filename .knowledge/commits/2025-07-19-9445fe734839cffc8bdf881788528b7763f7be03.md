# Add reflection-based structural equality and hash with AccessPath error reporting
## TL;DR
- Introduces `StructuralEqual` and `StructuralHash` classes that recursively compare/hash `Any` values using the reflection field registry, supporting tree nodes, DAG nodes, free variables, and container types (Array, Map, Shape, NDArray).
- Adds `AccessPath` / `AccessStep` types for precise mismatch reporting -- `GetFirstMismatch` returns the exact field/index/key path where two values diverge.
- Extends the C ABI with `TVMFFISEqHashKind` enum (6 variants) and two new field flag bits (`SEqHashIgnore`, `SEqHashDef`), plus a `structural_eq_hash_kind` field on `TVMFFITypeExtraInfo`.

## Key Exports

```python
# --- C ABI additions (c_api.h) ---

class TVMFFISEqHashKind(IntEnum):
    """Per-type metadata controlling structural comparison strategy."""
    Unsupported = 0       # Pointer equality only (default for Object)
    TreeNode = 1          # Recursive field comparison, no dedup
    FreeVar = 2           # Variable that can be mapped across lhs/rhs
    DAGNode = 3           # Like TreeNode but with pointer-identity dedup
    ConstTreeNode = 4     # TreeNode with pointer-equality fast path
    UniqueInstance = 5    # Singleton; always pointer equality
    # Interacts with: TVMFFITypeExtraInfo.structural_eq_hash_kind
    # Extension: add new kinds here for new comparison semantics

# New field flag bits in TVMFFIFieldFlagBitMask:
kTVMFFIFieldFlagBitMaskSEqHashIgnore = 1 << 3  # Skip this field during eq/hash
kTVMFFIFieldFlagBitMaskSEqHashDef    = 1 << 4  # Field enters a def region (enables free var mapping)
# Interacts with: TVMFFIFieldInfo.flags, StructEqualHandler, StructuralHashHandler

# TVMFFITypeExtraInfo change:
#   total_size: int64 -> int32  (ABI breaking type change)
#   structural_eq_hash_kind: TVMFFISEqHashKind  (new field)

# --- C++ public headers ---

# Object base class gains default SEqHash kind:
# Object._type_s_eq_hash_kind = kTVMFFISEqHashKindUnsupported
# Subclasses override: static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = ...;
# Interacts with: ObjectDef.RegisterExtraInfo() reads _type_s_eq_hash_kind

# New macro: TVM_FFI_EXTRA_CXX_API
# Marks non-core C++ APIs implemented in .cc files to reduce compile-time overhead.
# Interacts with: TVM_FFI_DLL, structural_equal.h, structural_hash.h

class AccessStep:
    """Single step in a path through nested objects/containers."""
    kind: AccessKind       # ObjectField, ArrayIndex, MapKey, ArrayIndexMissing, MapKeyMissing
    key: Any               # str for field, int for array, Any for map
    # Interacts with: AccessPath (Array[AccessStep]), mismatch reporting
    # Extension: add new AccessKind variants for new container types

    @staticmethod
    def ObjectField(name: str) -> AccessStep: ...
    @staticmethod
    def ArrayIndex(index: int) -> AccessStep: ...
    @staticmethod
    def MapKey(key: Any) -> AccessStep: ...
    @staticmethod
    def ArrayIndexMissing(index: int) -> AccessStep: ...
    @staticmethod
    def MapKeyMissing(key: Any) -> AccessStep: ...

AccessPath = Array[AccessStep]
AccessPathPair = Tuple[AccessPath, AccessPath]

class StructuralEqual:
    """Reflection-driven deep structural equality."""
    @staticmethod
    def Equal(lhs: Any, rhs: Any, map_free_vars: bool = False,
              skip_ndarray_content: bool = False) -> bool: ...
    # Invariant: lhs and rhs must be same type_index for object comparison
    # Interacts with: TVMFFITypeInfo.extra_info.structural_eq_hash_kind,
    #   ForEachFieldInfo, FieldGetter, container comparators

    @staticmethod
    def GetFirstMismatch(lhs: Any, rhs: Any, map_free_vars: bool = False,
                         skip_ndarray_content: bool = False) -> Optional[AccessPathPair]: ...
    # Returns None if equal, otherwise (lhs_path, rhs_path) to first divergence point
    # Interacts with: AccessStep (builds reverse path, then reverses)

    def __call__(self, lhs: Any, rhs: Any) -> bool: ...
    # Shorthand: Equal(lhs, rhs, map_free_vars=False, skip_ndarray_content=True)

class StructuralHash:
    """Reflection-driven deep structural hash."""
    @staticmethod
    def Hash(value: Any, map_free_vars: bool = False,
             skip_ndarray_content: bool = False) -> int: ...
    # Invariant: consistent with StructuralEqual (equal objects -> same hash)
    # Interacts with: StableHashCombine, StableHashBytes, ForEachFieldInfo, FieldGetter

    def __call__(self, value: Any) -> int: ...
    # Shorthand: Hash(value)

# --- Reflection builder additions (registry.h) ---

class AttachFieldFlag:
    """Trait to attach SEqHash field flags during reflection registration."""
    @staticmethod
    def SEqHashDef() -> AttachFieldFlag: ...
    # Interacts with: ObjectDef.def_ro/def_rw (passed as variadic trait arg)

    @staticmethod
    def SEqHashIgnore() -> AttachFieldFlag: ...

# FieldSetter bugfix: Any fields now assigned directly (not via cast<Any>)

# --- Registered global functions ---
# "ffi.reflection.GetFirstStructuralMismatch" -> StructuralEqual.GetFirstMismatch
# "ffi.reflection.StructuralHash" -> StructuralHash.Hash
```

## Impact
- API: C ABI change -- `TVMFFITypeExtraInfo.total_size` narrowed from `int64_t` to `int32_t` and new `structural_eq_hash_kind` field added. All out-of-tree code that constructs `TVMFFITypeExtraInfo` must be updated.
- Behavioral: `Bytes::memncmp` moved from private to public in `Bytes` class (was only accessible to `AnyEqual` friend).
- Flags/config: New `TVM_FFI_EXTRA_CXX_API` macro defaults to `TVM_FFI_DLL` but can be overridden.
- Data formats/schemas: New field flag bits (bits 3-4) added to `TVMFFIFieldFlagBitMask`.

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`0008`): `ForEachFieldInfo`, `FieldGetter`, `ObjectDef`, `TVMFFIFieldInfo`, `TVMFFITypeExtraInfo` -- used extensively to iterate and read object fields during comparison and hashing.
- **Object system** (`0002`): `Object`, `ObjectRef`, `ObjectPtrHash`, `ObjectPtrEqual`, `make_object`, `same_as`, `type_index()`, `GetTypeKeyHash()`.
- **C ABI** (`0007`): `TVMFFIAny`, `TVMFFITypeInfo`, `TVMFFIGetTypeInfo`, `TypeIndex` constants, `TVMFFIFieldFlagBitMask`.
- **Containers** (`0006`): `Array`, `Map`, `Shape`, `NDArray`, `String`, `Bytes`, `Tuple`, `Optional` -- specialized comparison/hash paths for each.
- **Any/AnyView** (`0001`): `AnyUnsafe` internals (`TVMFFIAnyPtrFromAny`, `CopyFromAnyViewAfterCheck`, `MoveFromAnyAfterCheck`) for type-index dispatch.

Design elements this commit produces:
- **StructuralEqual/StructuralHash protocol**: New subsystem within `ffi/reflection` for deep comparison and hashing based on reflected fields. Driven by per-type `TVMFFISEqHashKind` metadata.
- **AccessPath mismatch reporting**: `AccessStep` + `AccessPath` types enabling structured error paths from root to first divergence point.
- **TVMFFISEqHashKind enum**: C ABI enum encoding how each Object type participates in structural equality (tree, DAG, free var, etc.).
- **SEqHash field flags**: `kTVMFFIFieldFlagBitMaskSEqHashIgnore` and `kTVMFFIFieldFlagBitMaskSEqHashDef` control per-field behavior during structural comparison.
- **AttachFieldFlag trait**: Builder-pattern trait for attaching SEqHash flags during `ObjectDef` field registration.
- **TVM_FFI_EXTRA_CXX_API macro**: Visibility attribute for non-core C++ APIs.

## Usage Examples

**Defining a type with structural equality support and comparing instances:**
```cpp
// 1. Define object with _type_s_eq_hash_kind
class MyNodeObj : public Object {
 public:
  String name;
  int64_t value;
  static constexpr const char* _type_key = "my.Node";
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyNodeObj, Object);
};

// 2. Register reflection with SEqHash flags
refl::ObjectDef<MyNodeObj>()
    .def_ro("name", &MyNodeObj::name)
    .def_ro("value", &MyNodeObj::value, refl::AttachFieldFlag::SEqHashIgnore());

// 3. Compare and hash
Any a = MyNode("hello", 1);
Any b = MyNode("hello", 2);
refl::StructuralEqual::Equal(a, b);  // true (value field ignored)
refl::StructuralHash::Hash(a) == refl::StructuralHash::Hash(b);  // true

// 4. Get mismatch path for debugging
auto mismatch = refl::StructuralEqual::GetFirstMismatch(a, c);
// Returns AccessPathPair with ObjectField("name") if names differ
```

**Free variable mapping (alpha-equivalence):**
```cpp
// TVar has _type_s_eq_hash_kind = kTVMFFISEqHashKindFreeVar
// TFunc.params field has SEqHashDef flag (def region)
TVar x("x"), y("y");
TFunc fa({x}, {TInt(1), x}, "a");
TFunc fb({y}, {TInt(1), y}, "b");
refl::StructuralEqual()(fa, fb);  // true: x maps to y in the def region
```
