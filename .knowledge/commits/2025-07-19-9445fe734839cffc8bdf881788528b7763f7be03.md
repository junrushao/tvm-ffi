# Add reflection-based structural equality and hash with AccessPath diagnostics
## TL;DR
- Introduces `StructuralEqual` and `StructuralHash` classes that recursively compare/hash `Any` values using the reflection system's field metadata, supporting tree nodes, DAG nodes, free variables, and pointer-equal singletons.
- Adds `TVMFFISEqHashKind` enum (6 variants) and two new field flag bits (`SEqHashIgnore`, `SEqHashDef`) to the C ABI, along with `_type_s_eq_hash_kind` on `Object` for per-type opt-in.
- Introduces `AccessPath` / `AccessStep` types for structured mismatch diagnostics (`GetFirstMismatch` returns the path to the first differing leaf).

## Key Exports

**Enum `TVMFFISEqHashKind`** (C ABI, `c_api.h`):
```c
enum TVMFFISEqHashKind : int32_t {
  kTVMFFISEqHashKindUnsupported    = 0,  // no structural eq/hash; pointer compare
  kTVMFFISEqHashKindTreeNode       = 1,  // compare by content, tree semantics
  kTVMFFISEqHashKindFreeVar        = 2,  // mappable free variable
  kTVMFFISEqHashKindDAGNode        = 3,  // compare by content, DAG identity
  kTVMFFISEqHashKindConstTreeNode  = 4,  // tree node; pointer eq is sufficient if same
  kTVMFFISEqHashKindUniqueInstance  = 5,  // singleton; always pointer eq
};
```

**New field flag bits** (`TVMFFIFieldFlagBitMask`, `c_api.h`):
```c
kTVMFFIFieldFlagBitMaskSEqHashIgnore = 1 << 3,  // skip field during structural eq/hash
kTVMFFIFieldFlagBitMaskSEqHashDef    = 1 << 4,  // field enters "def region" (enables free var mapping)
```

**`TVMFFITypeExtraInfo` struct change** (`c_api.h`):
- `total_size` narrowed from `int64_t` to `int32_t`
- New field: `TVMFFISEqHashKind structural_eq_hash_kind`

**`Object::_type_s_eq_hash_kind`** (`object.h`):
```cpp
static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindUnsupported;
// Subclasses override to opt in: kTVMFFISEqHashKindTreeNode, kTVMFFISEqHashKindFreeVar, etc.
```

**`TVM_FFI_EXTRA_CXX_API`** macro (`c_api.h`):
- Marks non-core C++ APIs implemented in `.cc` files to reduce compile-time overhead. Defaults to `TVM_FFI_DLL`. Used on `StructuralEqual::Equal`, `StructuralEqual::GetFirstMismatch`, `StructuralHash::Hash`.

**Class `StructuralEqual`** (`reflection/structural_equal.h`):
```cpp
class StructuralEqual {
  static bool Equal(const Any& lhs, const Any& rhs,
                    bool map_free_vars = false, bool skip_ndarray_content = false);
  static Optional<AccessPathPair> GetFirstMismatch(
      const Any& lhs, const Any& rhs,
      bool map_free_vars = false, bool skip_ndarray_content = false);
  bool operator()(const Any& lhs, const Any& rhs) const;  // Equal(lhs, rhs, false, true)
};
```

**Class `StructuralHash`** (`reflection/structural_hash.h`):
```cpp
class StructuralHash {
  static uint64_t Hash(const Any& value,
                       bool map_free_vars = false, bool skip_ndarray_content = false);
  uint64_t operator()(const Any& value) const;  // Hash(value)
};
```

**Class `AccessStepObj` / `AccessStep`** (`reflection/access_path.h`):
```cpp
enum class AccessKind : int32_t {
  kObjectField = 0, kArrayIndex = 1, kMapKey = 2,
  kArrayIndexMissing = 3, kMapKeyMissing = 4,
};
class AccessStepObj : public Object {
  AccessKind kind;
  Any key;
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindConstTreeNode;
};
using AccessPath = Array<AccessStep>;
using AccessPathPair = Tuple<AccessPath, AccessPath>;
```

**Class `AttachFieldFlag`** (`reflection/registry.h`):
```cpp
class AttachFieldFlag : public FieldInfoTrait {
  explicit AttachFieldFlag(int32_t flag);
  static AttachFieldFlag SEqHashDef();     // kTVMFFIFieldFlagBitMaskSEqHashDef
  static AttachFieldFlag SEqHashIgnore();  // kTVMFFIFieldFlagBitMaskSEqHashIgnore
  void Apply(TVMFFIFieldInfo* info) const; // info->flags |= flag_
};
```

**Global functions registered**:
- `"ffi.reflection.GetFirstStructuralMismatch"` -> `StructuralEqual::GetFirstMismatch`
- `"ffi.reflection.StructuralHash"` -> `StructuralHash::Hash`

**`ReflectionDefBase::FieldSetter<T>` fix** (`registry.h`):
- Added `if constexpr (std::is_same_v<T, Any>)` branch to avoid double-casting when the field type is `Any`.

## Impact
- API: `TVMFFITypeExtraInfo.total_size` narrowed from `int64_t` to `int32_t` (ABI-breaking for C callers). New `structural_eq_hash_kind` field added. Two new flag bits in `TVMFFIFieldFlagBitMask`. New `TVMFFISEqHashKind` enum. `Bytes::memncmp` moved from private to public.
- Behavioral: Object types default to `kTVMFFISEqHashKindUnsupported` (pointer equality). Types must explicitly set `_type_s_eq_hash_kind` to opt into content comparison.
- Flags/config: `kTVMFFIFieldFlagBitMaskSEqHashIgnore` (bit 3) and `kTVMFFIFieldFlagBitMaskSEqHashDef` (bit 4) are new optional metadata bits.
- Data formats/schemas: `TVMFFITypeExtraInfo` layout changed (field type change + new field).

## Usage Examples

**Opting a type into structural equality/hash and annotating fields:**
```cpp
class TFuncObj : public Object {
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;

  static void RegisterReflection() {
    namespace refl = tvm::ffi::reflection;
    refl::ObjectDef<TFuncObj>()
        .def_ro("params", &TFuncObj::params, refl::AttachFieldFlag::SEqHashDef())   // def region
        .def_ro("body", &TFuncObj::body)
        .def_ro("comment", &TFuncObj::comment, refl::AttachFieldFlag::SEqHashIgnore()); // ignored
  }
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
  // ...
};
```

**Comparing values and getting mismatch diagnostics:**
```cpp
namespace refl = tvm::ffi::reflection;

Array<int> a = {1, 2, 3};
Array<int> b = {1, 2, 3};
bool eq = refl::StructuralEqual()(a, b);        // true
uint64_t h = refl::StructuralHash()(a);          // same as hash of b

Array<int> c = {1, 3};
auto mismatch = refl::StructuralEqual::GetFirstMismatch(a, c);
// mismatch->get<0>() == [AccessStep::ArrayIndex(1)]
// mismatch->get<1>() == [AccessStep::ArrayIndex(1)]
```

**Free variable mapping:**
```cpp
TVar x("x"), y("y");
refl::StructuralEqual::Equal(x, y, /*map_free_vars=*/true);   // true (x mapped to y)
refl::StructuralEqual::Equal(x, y);                            // false (pointer inequality)
refl::StructuralHash::Hash(x, /*map_free_vars=*/true);         // same as Hash(y, true)
```
