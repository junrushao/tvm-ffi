# Add Python-level stream context managers for FFI environment stream exchange
## TL;DR
- Introduces `StreamContext`, `use_raw_stream()`, and `use_torch_stream()` as public Python APIs for managing the TVM FFI per-thread/per-device stream context.
- Adds a Cython-level `_env_set_current_stream()` function that wraps the existing C API `TVMFFIEnvSetStream`, returning the previous stream handle for save/restore semantics.
- The torch integration supports `torch.cuda.Stream`, `torch.cuda.CUDAGraph`, and implicit current-stream capture, with proper nesting via `__enter__`/`__exit__` on both the torch and FFI sides.

## Key Exports

**Classes**:

| Name | Key Fields | Key Methods | Notes |
|------|-----------|-------------|-------|
| `StreamContext` | `device_type: int`, `device_id: int`, `stream: int\|c_void_p`, `prev_stream: int` | `__enter__()`, `__exit__(*args)` | Context manager; calls `core._env_set_current_stream` on enter (caching prev), restores on exit |
| `TorchStreamContext` | `torch_context: Optional[Any]`, `ffi_context: StreamContext` | `__enter__()`, `__exit__(*args)` | Wraps a torch stream/graph context; enters torch context first, then creates `StreamContext` from `torch.cuda.current_stream()` |

**Functions**:

| Name | Signature | Notes |
|------|-----------|-------|
| `use_raw_stream` | `(device: Device, stream: int\|c_void_p) -> StreamContext` | Validates stream type, returns `StreamContext` |
| `use_torch_stream` | `(context: Optional[Any] = None) -> TorchStreamContext` | Accepts `torch.cuda.stream(s)` or `torch.cuda.graph(g)` context; `None` uses current stream. Falls back to `ImportError` if torch unavailable. |
| `core._env_set_current_stream` | `(device_type: int, device_id: int, stream: uint64) -> uint64` | Cython wrapper for `TVMFFIEnvSetStream`. Returns previous stream handle as uint64. |

## Impact
- API: Adds `StreamContext`, `use_raw_stream`, `use_torch_stream` to `tvm_ffi` top-level namespace. No existing APIs changed.
- Behavioral: none -- new feature only
- Flags/config: none

## Design Elements
Design elements this commit consumes:
- **`TVMFFIEnvSetStream` / `TVMFFIEnvGetStream` C API** (`include/tvm/ffi/extra/c_env_api.h`): The Cython `_env_set_current_stream` calls `TVMFFIEnvSetStream` with the `opt_out_original_stream` parameter to atomically swap and return the previous stream. See [ADR 0013 env-api-naming-convention](../ADRs/0013-env-api-naming-convention.md).
- **`EnvContext` thread-local stream table** (`src/ffi/extra/env_context.cc`): The C++ implementation uses a nested `vector<vector<TVMFFIStreamHandle>>` indexed by `(device_type, device_id)` for per-thread stream tracking.
- **`Device` and `device()`** (`python/tvm_ffi/_tensor.py`): `StreamContext.__init__` calls `device.dlpack_device_type()` and `device.index` to extract the DLDevice fields. See [design 0014-python-package](../designs/0014-python-package.md).
- **`tvm_ffi.cpp.load_inline`** (`python/tvm_ffi/cpp/`): Used in tests to JIT-compile a C++ module that calls `TVMFFIEnvGetStream` for verification. See [design 0014-python-package](../designs/0014-python-package.md).

Design elements this commit produces:
- **Python stream context protocol** (`python/tvm_ffi/stream.py`): A save/restore context manager pattern for FFI environment streams. This complements the lower-level `__tvm_ffi_env_stream__` protocol (which is per-argument automatic exchange) with explicit user-controlled stream context scoping.
- **Cython `_env_set_current_stream`** (`python/tvm_ffi/cython/base.pxi`): Exposes `TVMFFIEnvSetStream` to Python, bridging the gap between the C API and the Python `StreamContext` class.

## Usage Examples

**Raw stream context (nested)**:
```python
import tvm_ffi

device = tvm_ffi.device("cuda:0")
stream_1 = 123456789  # raw CUDA stream handle
stream_2 = 987654321

with tvm_ffi.use_raw_stream(device, stream_1):
    # FFI env stream is now stream_1
    with tvm_ffi.use_raw_stream(device, stream_2):
        # FFI env stream is now stream_2
        pass
    # FFI env stream is restored to stream_1
# FFI env stream is restored to original (NULL/0)
```

**Torch stream context (from test)**:
```python
import torch
import tvm_ffi

stream = torch.cuda.Stream()
with tvm_ffi.use_torch_stream(torch.cuda.stream(stream)):
    # Both torch current stream and FFI env stream are set to `stream`
    pass

# Implicit current stream capture:
with torch.cuda.stream(stream):
    with tvm_ffi.use_torch_stream():
        # FFI env stream set to torch's current stream
        pass
```
