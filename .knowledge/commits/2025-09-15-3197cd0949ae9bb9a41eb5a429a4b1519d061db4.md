# Add Python stream context managers bridging C env stream API to torch/raw CUDA streams
## TL;DR
- Adds `StreamContext`, `use_raw_stream()`, and `use_torch_stream()` to `tvm_ffi` for setting/restoring the per-thread device stream via Python context managers.
- Exposes Cython wrapper `_env_set_current_stream()` around `TVMFFIEnvSetStream` C ABI.
- Includes tests verifying nested stream contexts, torch stream integration, torch current-stream inference, and CUDA graph contexts.

Design elements this commit consumes:

Design elements this commit produces:
- **`StreamContext`** (Python class): context manager for setting/restoring per-thread device stream via C ABI. This is the Python-layer counterpart to the C++ thread-local `StreamContext` in `src/ffi/env/stream.cc`.
- **`use_torch_stream()`**: high-level factory that integrates torch stream/graph contexts with FFI stream management.
- **`use_raw_stream()`**: low-level factory for direct stream handle usage.
- **`_env_set_current_stream()`**: Cython bridge function exposing `TVMFFIEnvSetStream` to Python.

## Usage Examples

Setting a raw stream handle with nesting:
```python
import tvm_ffi

device = tvm_ffi.device("cuda:0")
with tvm_ffi.use_raw_stream(device, stream_handle_1):
    # FFI env stream is now stream_handle_1
    with tvm_ffi.use_raw_stream(device, stream_handle_2):
        # FFI env stream is now stream_handle_2
        pass
    # restored to stream_handle_1
# restored to original
```

Using torch stream context:
```python
import torch
import tvm_ffi

stream = torch.cuda.Stream()
with tvm_ffi.use_torch_stream(torch.cuda.stream(stream)):
    # Both torch current_stream and FFI env stream are synced
    pass
```

Using torch's current stream implicitly:
```python
stream = torch.cuda.Stream()
with torch.cuda.stream(stream):
    with tvm_ffi.use_torch_stream():
        # FFI env stream matches torch's current stream
        pass
```
