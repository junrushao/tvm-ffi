# Add Python stream context wrappers (StreamContext, use_raw_stream, use_torch_stream)
## TL;DR
- Introduces `python/tvm_ffi/stream.py` with Python-level `StreamContext` (context manager wrapping `TVMFFIEnvSetStream`), `use_raw_stream` (device + handle), and `use_torch_stream` (optional torch stream/graph context).
- Adds Cython `_env_set_current_stream` helper in `base.pxi` to bridge Python into the C-ABI `TVMFFIEnvSetStream` call, returning the previous stream handle as `uint64_t`.
- Exports `StreamContext`, `use_raw_stream`, `use_torch_stream` from `tvm_ffi.__init__` and adds Sphinx doc entries.

## Impact
- API: Three new public symbols added to `tvm_ffi` namespace: `StreamContext`, `use_raw_stream`, `use_torch_stream`. No existing APIs changed.
- Behavioral: none -- purely additive.
- Flags/config: none.

## Design Elements
Design elements this commit consumes:
- **C++ StreamContext / TVMFFIEnvSetStream** (0011-module-system): The Python `StreamContext` wraps `TVMFFIEnvSetStream` via the new Cython `_env_set_current_stream` helper. The C++ thread-local stream table provides the underlying storage.
- **Device** (0012-python-bindings): `device.dlpack_device_type()` and `device.index` extract the device coordinates passed to the C ABI.
- **Cython core module** (0012-python-bindings): `from . import core` accesses the compiled Cython module that exposes `_env_set_current_stream`.

Design elements this commit produces:
- **Python StreamContext** (`python/tvm_ffi/stream.py`): Context manager for save/restore stream semantics. This is a new Python-layer wrapper over the existing C++ `StreamContext` thread-local.
- **use_torch_stream / use_raw_stream** (`python/tvm_ffi/stream.py`): High-level factory functions for stream context creation, with torch integration gated by try/except ImportError.

## Usage Examples

Setting a raw stream handle for CUDA device 0:
```python
import tvm_ffi

device = tvm_ffi.device("cuda:0")
stream_handle = 123456789  # raw cudaStream_t as int
with tvm_ffi.use_raw_stream(device, stream_handle):
    # All FFI calls inside here see this stream via TVMFFIEnvGetCurrentStream
    pass
# Stream automatically restored to previous value
```

Using with a torch CUDA stream:
```python
import torch
import tvm_ffi

stream = torch.cuda.Stream()
with tvm_ffi.use_torch_stream(torch.cuda.stream(stream)):
    # Both torch and FFI see the same stream
    pass
```

Using with the current torch stream (no argument):
```python
with torch.cuda.stream(my_stream):
    with tvm_ffi.use_torch_stream():
        # Captures torch.cuda.current_stream() automatically
        pass
```
