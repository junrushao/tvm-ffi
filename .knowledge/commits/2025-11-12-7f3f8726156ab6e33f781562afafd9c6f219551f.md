# Leverage DLPackExchangeAPI in from_dlpack, fix memory leak and missing returns
## TL;DR
- Adds `_from_dlpack_exchange_api()` as the highest-priority path in `_from_dlpack_universal()`, so `from_dlpack()` uses the zero-overhead `__c_dlpack_exchange_api__` protocol when available, before falling back to `__dlpack__` or PyCapsule.
- Fixes a `DLManagedTensorVersioned` memory leak on error path: both `function.pxi` and `tensor.pxi` now call `temp_managed_tensor.deleter()` when `TVMFFITensorFromDLPackVersioned` fails.
- Adds missing `return` statements in all branches of `_from_dlpack_universal()`.
- Removes dead code (`_from_dlpack_intptr`), renames local variable `api` -> `exchange_api` for clarity.

# 1. __c_dlpack_exchange_api__  (NEW — fastest, zero-overhead C-level exchange)

# 3. PyCapsule                  (existing — raw capsule fallback)
```

## Impact
- API: None -- `from_dlpack()` public signature is unchanged.
- Behavioral: `from_dlpack()` now prefers `__c_dlpack_exchange_api__` when present on the input object's class, which is faster than `__dlpack__`. Falls back gracefully on `BufferError`. Error paths no longer leak `DLManagedTensorVersioned`. All code paths in `_from_dlpack_universal` now correctly return instead of falling through.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **DLPackExchangeAPI struct** (`__c_dlpack_exchange_api__` protocol, see [0012-ffi-python-package](../design-records/0012-ffi-python-package.md)): the new `_from_dlpack_exchange_api` helper calls `exchange_api.managed_tensor_from_py_object_no_sync` to obtain a `DLManagedTensorVersioned*` directly.
- **TVMFFITensorFromDLPackVersioned** (C ABI, see [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md)): converts `DLManagedTensorVersioned` to `ffi.Tensor`.
- **`_from_dlpack_universal` dispatch chain** (Cython internal, tensor.pxi): the entry point for `from_dlpack()` that tries multiple protocols in priority order.

Design elements this commit produces: None -- purely additive internal helper and bug fixes.

## Usage Examples

import torch

# If torch.Tensor (or any class) provides __c_dlpack_exchange_api__,
# from_dlpack now uses the fast C-level exchange path automatically.

ffi_tensor = tvm_ffi.from_dlpack(t)
# Internally: _from_dlpack_exchange_api() called instead of __dlpack__()

# If exchange API is unavailable, falls back to __dlpack__ as before.
```
