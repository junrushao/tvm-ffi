# Leverage DLPack exchange API when possible for tensor conversion
## TL;DR
- Updates `from_dlpack` in Cython to prefer the DLPack exchange API (`__dlpack__`/`__dlpack_device__`) when available, falling back to legacy paths.
- Improves tensor conversion efficiency by avoiding unnecessary intermediate copies.
