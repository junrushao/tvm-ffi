# Prefer DLPackExchangeAPI in from_dlpack universal path for zero-Python-overhead tensor import
## TL;DR
- Adds `_from_dlpack_exchange_api()` Cython function that converts external tensors to TVM FFI tensors via `DLPackExchangeAPI.managed_tensor_from_py_object_no_sync`, bypassing Python's `__dlpack__` protocol entirely.
- Wires this as the first-priority path in `_from_dlpack_universal()`: if `__c_dlpack_exchange_api__` attribute exists on the input tensor, it is tried before `__dlpack__` or PyCapsule fallbacks.
- Fixes a memory leak in `TVMFFIPyArgSetterDLPackExchangeAPI_`: when `TVMFFITensorFromDLPackVersioned` fails, the managed tensor's deleter is now called to reclaim it. Same pattern applied in the new `_from_dlpack_exchange_api`.
- Removes unused `_from_dlpack_intptr()` helper.
- Adds missing `return` statements to all branches in `_from_dlpack_universal()`, ensuring the function's `except -1` contract is honored.

## Key Exports
**Function** (Cython, internal):
```cython
cdef inline int _from_dlpack_exchange_api(
    object ext_tensor, DLPackExchangeAPI* exchange_api,
    int require_alignment, int require_contiguous,
    TVMFFIObjectHandle* out
) except -1
```

## Impact
- API: None (internal Cython function, not exposed to Python users)
- Behavioral: `tvm_ffi.Tensor.from_dlpack()` and any code path using `_from_dlpack_universal` now prefers the exchange API when available, achieving zero-Python-overhead conversion. Falls back to `__dlpack__` on `BufferError`.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **DLPackExchangeAPI struct** ([0017-dlpack-interop.md](../designs/0017-dlpack-interop.md)): Uses `managed_tensor_from_py_object_no_sync` function pointer for the conversion.
- **`TVMFFITensorFromDLPackVersioned` C API** ([0001-c-abi-layer.md](../designs/0001-c-abi-layer.md)): Used to convert `DLManagedTensorVersioned*` to a TVM FFI tensor handle.

Design elements this commit produces:
- **Exchange-API-first dispatch order in `_from_dlpack_universal`**: New priority: (1) `__c_dlpack_exchange_api__` -> (2) `__dlpack__` -> (3) PyCapsule. This establishes the convention that the exchange API is always preferred when available.

## Usage Examples
**Before**: `from_dlpack` always went through Python `__dlpack__()` protocol, even when exchange API was registered on torch.Tensor.

**After**: `from_dlpack` automatically uses the C-level exchange API when `__c_dlpack_exchange_api__` is present:
```python
import tvm_ffi
import torch

t = torch.randn(3, 4)
# Internally: _from_dlpack_universal detects __c_dlpack_exchange_api__,
# calls exchange_api->managed_tensor_from_py_object_no_sync (C fn ptr),
# skips __dlpack__() Python method entirely
result = tvm_ffi.Tensor.from_dlpack(t)
```
