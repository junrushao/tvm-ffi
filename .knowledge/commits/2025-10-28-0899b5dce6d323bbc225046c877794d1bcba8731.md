# Add clang-tidy CI job on mainline pushes
## TL;DR
- Adds new GitHub Actions workflow `.github/workflows/ci_mainline_only.yml` that runs clang-tidy on every push to `main` and on `workflow_dispatch`.
- The workflow has two jobs: `prepare` (reuses `detect-skip-ci` action) and `clang-tidy` (runs `tests/lint/clang_tidy_precommit.py` via `uv run` with pinned `clang-tidy==21.1.1`).
- Intended to catch C++ lint regressions before they accumulate on mainline.
