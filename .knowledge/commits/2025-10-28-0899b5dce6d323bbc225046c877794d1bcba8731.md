# Add clang-tidy to mainline-only CI workflow
## TL;DR
- Introduces a new GitHub Actions workflow (`ci_mainline_only.yml`) that runs clang-tidy on every push to the `main` branch.
- Uses the existing `tests/lint/clang_tidy_precommit.py` script with `clang-tidy==21.1.1` via `uv run --no-project`.
- Adds a `prepare` job with the reusable `detect-skip-ci` action before the `clang-tidy` job.
