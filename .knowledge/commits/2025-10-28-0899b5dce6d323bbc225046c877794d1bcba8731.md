# Add clang-tidy CI job to mainline-only workflow for per-commit static analysis
## TL;DR
- Adds a new GitHub Actions workflow `.github/workflows/ci_mainline_only.yml` that runs clang-tidy on every push to `main` (and on manual dispatch).
- The workflow invokes `tests/lint/clang_tidy_precommit.py` with `clang-tidy==21.1.1` against `./src/`, `./include/`, and `./tests/`.
