# Upgrade Web Runtime to new FFI: ABI-safe dtype-to-string and configurable log-before-throw

## TL;DR
- Changed `TVMFFIDataTypeToString` C ABI signature from pass-by-value `DLDataType` to pass-by-pointer `const DLDataType*` to avoid struct-passing ABI compatibility issues (especially on Web/Emscripten).
- Added compile-time flag `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` (default 0) that, when set to 1, makes every `TVM_FFI_THROW` log to stderr before throwing -- useful for environments where exception tracebacks are unreliable.

## Key Exports

**Functions (changed)**:
```c
// BEFORE: DLDataType passed by value
TVM_FFI_DLL int TVMFFIDataTypeToString(DLDataType dtype, TVMFFIObjectHandle* out);

// AFTER: DLDataType passed by pointer (ABI-safe)
TVM_FFI_DLL int TVMFFIDataTypeToString(const DLDataType* dtype, TVMFFIObjectHandle* out);
```

**Macros (new)**:
```c
// Compile-time toggle: when 1, all TVM_FFI_THROW calls log to stderr before throwing.
// Default: 0 (no logging). Override by defining before including error.h.
#ifndef TVM_FFI_ALWAYS_LOG_BEFORE_THROW
#define TVM_FFI_ALWAYS_LOG_BEFORE_THROW 0
#endif
```

**Macros (changed)**:
```c
// BEFORE: hardcoded `false` for log_before_throw
#define TVM_FFI_THROW(ErrorKind) \
  ::tvm::ffi::details::ErrorBuilder(#ErrorKind, TVM_FFI_TRACEBACK_HERE, false).stream()

// AFTER: uses the configurable flag
#define TVM_FFI_THROW(ErrorKind) \
  ::tvm::ffi::details::ErrorBuilder(#ErrorKind, TVM_FFI_TRACEBACK_HERE, \
                                    TVM_FFI_ALWAYS_LOG_BEFORE_THROW).stream()
```

## Impact
- API: **Breaking** -- `TVMFFIDataTypeToString` signature changed. All callers must pass `&dtype` instead of `dtype`. The C++ inline wrapper `DLDataTypeToString` in `dtype.h` is updated accordingly. Any external C callers or language bindings calling this symbol directly must update.
- Behavioral: When `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` is defined to 1, all `TVM_FFI_THROW` invocations additionally log to stderr. This changes runtime behavior for debug builds/platforms that set this flag.
- Flags/config: New compile-time flag `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` (defaults to 0, no behavioral change unless explicitly set).
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- **C ABI function export convention** (`c_api.h`) -- `TVMFFIDataTypeToString` is an exported `TVM_FFI_DLL` function following the int-return error convention. See [0001-c-abi-layer.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0001-c-abi-layer.md).
- **ErrorBuilder stream mechanism** (`error.h`) -- `TVM_FFI_THROW` delegates to `ErrorBuilder(kind, traceback, log_before_throw)`. See [0006-error-handling.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0006-error-handling.md).
- **TVM_FFI_SAFE_CALL_BEGIN/END** -- used in `dtype.cc` to wrap the implementation.
- **TVM_FFI_CHECK_SAFE_CALL** -- used in `dtype.h` inline wrapper to convert error codes to exceptions.

Design elements this commit produces:
- **`TVM_FFI_ALWAYS_LOG_BEFORE_THROW` compile flag** -- new configurable macro that controls logging behavior of `TVM_FFI_THROW`. Follows the same `#ifndef`-guarded defaulting pattern as `TVM_FFI_USE_LIBBACKTRACE` and `TVM_FFI_BACKTRACE_ON_SEGFAULT`.

## Usage Examples

**Calling `TVMFFIDataTypeToString` from C after this commit:**
```c
DLDataType dtype;
dtype.code = kDLFloat;
dtype.bits = 32;
dtype.lanes = 1;

TVMFFIObjectHandle out = NULL;
// Pass pointer, not value:
int ret = TVMFFIDataTypeToString(&dtype, &out);
if (ret == 0) {
    const TVMFFIByteArray* str = TVMFFIObjectGetByteArrayPtr(out);
    // str->data = "float32", str->size = 7
    TVMFFIObjectFree(out);
}
```

**Enabling log-before-throw for Web/Emscripten builds:**
```c
// In build config or before including error.h:
#define TVM_FFI_ALWAYS_LOG_BEFORE_THROW 1
#include <tvm/ffi/error.h>
// Now every TVM_FFI_THROW(X) << "msg" will also log "X: msg" to stderr
```
