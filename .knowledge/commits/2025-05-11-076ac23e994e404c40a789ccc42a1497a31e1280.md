# Change TVMFFIDataTypeToString to pass DLDataType by pointer and add TVM_FFI_ALWAYS_LOG_BEFORE_THROW flag
## TL;DR
- **ABI signature change**: `TVMFFIDataTypeToString(DLDataType dtype, ...)` changed to `TVMFFIDataTypeToString(const DLDataType* dtype, ...)` to avoid pass-by-value ABI incompatibilities across platforms (notably WASM/Emscripten where struct-by-value ABI differs).
- **Debug logging flag**: New compile-time macro `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` (default 0) replaces the hardcoded `false` in `TVM_FFI_THROW`, allowing all errors to be logged to stderr before being thrown -- useful for debugging in environments where exceptions are swallowed.
- Secondary concern: The commit message references a broader "Web Runtime upgrade" but the diff here is limited to these two core FFI adjustments.

## Key Exports

```python
# === Changed C ABI function (c_api.h) ===

# OLD: def TVMFFIDataTypeToString(dtype: DLDataType, out: Ref[TVMFFIObjectHandle]) -> int: ...
# NEW:
def TVMFFIDataTypeToString(dtype: Ptr[DLDataType], out: Ref[TVMFFIObjectHandle]) -> int: ...
    # Converts a DLDataType to its string representation.
    # Invariant: dtype pointer must be valid (non-null) for duration of call
    # Invariant: out receives a String object that caller must free via TVMFFIObjectFree
    # Interacts with: DLDataTypeToString_ (internal), TVMFFIObjectFree (caller responsibility)
    # Breaking: pass-by-value -> pass-by-pointer. All callers must update.

# === New compile-time flag (error.h) ===

TVM_FFI_ALWAYS_LOG_BEFORE_THROW: int = 0  # compile-time macro, default 0
    # When set to 1, TVM_FFI_THROW logs every error to stderr before throwing.
    # Useful for WASM/web environments where exceptions may be swallowed.
    # Interacts with: ErrorBuilder.log_before_throw_ field
    # Extension: define to 1 in build flags for debug/web builds

# Macro expansion change (pseudocode for TVM_FFI_THROW(ErrorKind)):
# OLD: ErrorBuilder("ErrorKind", traceback, false).stream()
# NEW: ErrorBuilder("ErrorKind", traceback, TVM_FFI_ALWAYS_LOG_BEFORE_THROW).stream()
```

## Impact
- API: **Breaking C ABI change** to `TVMFFIDataTypeToString` -- parameter changed from `DLDataType` (by value) to `const DLDataType*` (by pointer). All callers across all language bindings must update. The C++ inline wrapper `DLDataTypeToString()` in `dtype.h` is updated to pass `&dtype`.
- Behavioral: When `TVM_FFI_ALWAYS_LOG_BEFORE_THROW=1`, every `TVM_FFI_THROW` invocation will log the error to stderr before throwing. Default behavior (0) is unchanged.
- Flags/config: New `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` compile-time macro. Defined with `#ifndef` guard so it can be overridden via `-D` compiler flags.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **C ABI function table** ([0001-c-abi.md](../designs/0001-c-abi.md)): Modifies `TVMFFIDataTypeToString` signature.
- **Error system / ErrorBuilder** ([0005-error-system.md](../designs/0005-error-system.md)): Uses `ErrorBuilder.log_before_throw_` field, now controlled by compile-time macro instead of hardcoded `false`.
- **TVM_FFI_SAFE_CALL pattern**: Both `TVMFFIDataTypeFromString` and `TVMFFIDataTypeToString` use `TVM_FFI_SAFE_CALL_BEGIN/END`.

Design elements this commit produces:
- **TVM_FFI_ALWAYS_LOG_BEFORE_THROW macro**: New compile-time configuration point for error diagnostics. Not yet documented in knowledge base.

## Usage Examples

Before (old signature):
```cpp
// C caller -- old way (by value)
DLDataType dtype = {kDLFloat, 32, 1};
TVMFFIObjectHandle out;
TVMFFIDataTypeToString(dtype, &out);  // pass struct by value
```

After (new signature):
```cpp
// C caller -- new way (by pointer)
DLDataType dtype = {kDLFloat, 32, 1};
TVMFFIObjectHandle out;
TVMFFIDataTypeToString(&dtype, &out);  // pass pointer -- ABI-safe across WASM

// C++ wrapper (dtype.h) handles this transparently:
// String s = DLDataTypeToString(dtype);  // internally calls TVMFFIDataTypeToString(&dtype, &out)
```

Enabling debug logging:
```cpp
// In build flags or before including error.h:
#define TVM_FFI_ALWAYS_LOG_BEFORE_THROW 1
// Now every TVM_FFI_THROW() will log to stderr before throwing
```
