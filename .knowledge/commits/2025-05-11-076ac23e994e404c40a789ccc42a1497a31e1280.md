# Upgrade Web Runtime to new FFI: ABI-safe DLDataType pass-by-pointer and configurable log-before-throw

## TL;DR
- Changed `TVMFFIDataTypeToString` C API signature from pass-by-value (`DLDataType dtype`) to pass-by-pointer (`const DLDataType* dtype`) to avoid ABI compatibility issues when crossing shared library boundaries (e.g., Emscripten/web runtime).
- Added `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` compile-time flag (default 0) and wired it into `TVM_FFI_THROW`, replacing the hardcoded `false` for `log_before_throw`. This allows web/embedded builds to always log errors to stderr before throwing, useful in environments where exceptions may not propagate cleanly.

```python
    """Convert DLDataType to its string representation.
    Input dtype is a pointer to avoid ABI issues with struct pass-by-value."""

    # Invariant: caller owns the returned String object (must free via TVMFFIObjectFree)
    # Invariant: dtype pointer must be valid for the duration of the call
    ...

# --- Compile-time configuration flag ---
# TVM_FFI_ALWAYS_LOG_BEFORE_THROW: int (default 0)
# When set to 1 (via -DTVM_FFI_ALWAYS_LOG_BEFORE_THROW=1), TVM_FFI_THROW
# will always log errors to stderr before throwing.
# Interacts with: ErrorBuilder.log_before_throw_, TVM_FFI_THROW macro
# Extension: define before including error.h, or pass as compiler flag

# --- Updated macro expansion ---

#   ErrorBuilder("ErrorKind", TVM_FFI_TRACEBACK_HERE, TVM_FFI_ALWAYS_LOG_BEFORE_THROW).stream()
# (Previously hardcoded `false` instead of TVM_FFI_ALWAYS_LOG_BEFORE_THROW)
```

## Impact
- API: **Breaking** -- `TVMFFIDataTypeToString` signature changed from pass-by-value to pass-by-pointer. All direct C-level callers must update to pass `&dtype` instead of `dtype`. The C++ wrapper `DLDataTypeToString()` in `dtype.h` is already updated.
- Behavioral: `TVM_FFI_THROW` now respects `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` at compile time. Builds that define this flag to 1 will see error messages logged to stderr on every throw, not just on `TVM_FFI_LOG_AND_THROW`.
- Flags/config: New compile-time flag `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` (default 0, backward compatible).
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- C ABI calling convention and safe-call pattern (`0001-ffi-c-abi`): `TVMFFIDataTypeToString` is one of the C API functions following the `TVM_FFI_SAFE_CALL_BEGIN/END` pattern.
- Error protocol (`0005-ffi-error-protocol`): `TVM_FFI_THROW` macro and `ErrorBuilder` pattern.

Design elements this commit produces:
- **Mutates** `TVMFFIDataTypeToString` signature in the C ABI surface (`0001-ffi-c-abi`): struct pass-by-value to pass-by-pointer for ABI safety across compilation units.
- **Produces** `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` compile-time flag (`0005-ffi-error-protocol`): configurable log-before-throw behavior for `TVM_FFI_THROW`.

## Usage Examples

Before (old signature):
```cpp
DLDataType dtype = {kDLFloat, 32, 1};
TVMFFIObjectHandle out;
// Old: pass DLDataType by value
TVM_FFI_CHECK_SAFE_CALL(TVMFFIDataTypeToString(dtype, &out));
```

After (new signature):
```cpp
DLDataType dtype = {kDLFloat, 32, 1};
TVMFFIObjectHandle out;
// New: pass DLDataType by pointer for ABI safety
TVM_FFI_CHECK_SAFE_CALL(TVMFFIDataTypeToString(&dtype, &out));
```

Enabling always-log-before-throw (compile flag):
```bash
# Pass as compiler flag for web/embedded builds
cmake ... -DCMAKE_CXX_FLAGS="-DTVM_FFI_ALWAYS_LOG_BEFORE_THROW=1"
```
