# Change TVMFFIDataTypeToString to pass-by-pointer and add configurable log-before-throw for Web/Wasm ABI compatibility
## TL;DR
- Change `TVMFFIDataTypeToString` C API signature from `DLDataType` pass-by-value to `const DLDataType*` pass-by-pointer, fixing ABI compatibility issues on WebAssembly/Emscripten where struct-by-value across function boundaries is unreliable.
- Add `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` compile-time flag (default 0) that, when enabled, makes `TVM_FFI_THROW` log errors to stderr before throwing -- useful for Wasm debugging where exceptions may be swallowed.
- Update `DLDataTypeToString` C++ wrapper and `dtype.cc` implementation to match the new pointer-based signature.

```python
# New:
def TVMFFIDataTypeToString(dtype: const_DLDataType_ptr, out: TVMFFIObjectHandle_ptr) -> int:
    """Convert DLDataType to string representation."""
    # Interacts with: DLDataTypeToString_ (internal impl), String object system
    # Invariant: dtype must be a non-null pointer to a valid DLDataType
    # Changed from pass-by-value to pass-by-pointer for Wasm ABI compatibility

# --- New compile-time flag ---
# TVM_FFI_ALWAYS_LOG_BEFORE_THROW (default: 0)
# When set to 1, TVM_FFI_THROW logs to stderr before throwing.
# Interacts with: ErrorBuilder.log_before_throw_ parameter
# Extension: Set via compiler flag -DTVM_FFI_ALWAYS_LOG_BEFORE_THROW=1

# --- Updated macro expansion ---
# TVM_FFI_THROW(ErrorKind)
#   expands to:
#     ErrorBuilder("ErrorKind", TVM_FFI_TRACEBACK_HERE, TVM_FFI_ALWAYS_LOG_BEFORE_THROW).stream()
#   (Previously: third arg was hardcoded `false`)
```

## Impact
- API: Breaking change to `TVMFFIDataTypeToString` C ABI signature -- all callers (language bindings, Wasm runtime) must pass a pointer instead of a value. C++ callers updated in-tree (`dtype.h` wrapper passes `&dtype`).
- Behavioral: When `TVM_FFI_ALWAYS_LOG_BEFORE_THROW=1`, all `TVM_FFI_THROW` sites will log to stderr before throwing, which changes observable behavior (stderr output). Default (0) preserves existing behavior.
- Flags/config: New `TVM_FFI_ALWAYS_LOG_BEFORE_THROW` preprocessor flag.
- Data formats/schemas: None.

Before (old signature):

```cpp
// C API caller
DLDataType dtype = {kDLFloat, 32, 1};

TVMFFIDataTypeToString(dtype, &out);  // pass by value

// C++ wrapper
inline String DLDataTypeToString(DLDataType dtype) {
  TVMFFIObjectHandle out;
  TVM_FFI_CHECK_SAFE_CALL(TVMFFIDataTypeToString(dtype, &out));
  // ...
}
```

After (new signature):
```cpp
// C API caller
DLDataType dtype = {kDLFloat, 32, 1};

TVMFFIDataTypeToString(&dtype, &out);  // pass by pointer

// C++ wrapper
inline String DLDataTypeToString(DLDataType dtype) {
  TVMFFIObjectHandle out;
  TVM_FFI_CHECK_SAFE_CALL(TVMFFIDataTypeToString(&dtype, &out));  // &dtype
  // ...
}
```
