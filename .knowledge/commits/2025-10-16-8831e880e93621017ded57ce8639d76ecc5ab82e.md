# Move macOS cp38 skip from workflow env var to pyproject.toml cibuildwheel config
## TL;DR
- Removed the `CIBW_SKIP: "cp38-macosx_*"` environment variable from `.github/workflows/publish_wheel.yml`.
- Added `"cp38-macosx_*"` to the `skip` list in `[tool.cibuildwheel]` within `pyproject.toml`, co-located with the existing `*musllinux*` skip.
- Net effect: same build behavior (macOS cp38 wheels are still skipped), but the skip rule now lives in the canonical cibuildwheel config file instead of a workflow-level override.
