# Fix ROCm stream mismatch in DLPackExchangeAPI by using HIPStreamMasqueradingAsCUDA and forcing addon override on ROCm.

## TL;DR
- On ROCm, `CurrentWorkStream` in `TorchDLPackExchangeAPI` was calling `at::cuda::getCurrentCUDAStream` instead of `c10::hip::getCurrentHIPStreamMasqueradingAsCUDA`, causing stream identity mismatches that triggered HIP graph empty-capture warnings in callers like SGLang.
- The `_optional_torch_c_dlpack.py` loader now skips its early-return on ROCm even when `__dlpack_c_exchange_api__` is already set by native PyTorch, ensuring the fixed `tvm-ffi` addon's callback is active.
- A new GPU test (`test_current_work_stream_gpu.py`) verifies that both `kDLCUDA` and `kDLROCM` device types return a stream pointer matching the active `torch.cuda.Stream`.

## Impact
- API: None — no public API signature changes.

- Flags/config: None new; existing `torch.version.hip` runtime check drives the ROCm path.
- Data formats/schemas: None.

## Usage Examples

**Before (broken on ROCm):** Stream mismatch — PyTorch native API used `at::cuda::getCurrentCUDAStream` for both CUDA and ROCm:

```python
# HIP graph capture would see wrong stream:
# kDLROCM/kDLCUDA -> at::cuda::getCurrentCUDAStream(device_id)  # wrong on ROCm

# Also: if PyTorch already had __dlpack_c_exchange_api__, tvm-ffi would silently skip
# loading its own (corrected) addon, leaving the broken callback active.
```

**After (correct on ROCm):**

```python
# python -m pytest -q tests/python/test_current_work_stream_gpu.py
import torch, tvm_ffi
device_id = torch.cuda.current_device()
stream = torch.cuda.Stream(device=device_id)
with torch.cuda.stream(stream):
    # test verifies: api.current_work_stream(kDLCUDA, 0) == stream.cuda_stream
    # on ROCm: also verifies kDLROCM returns same stream pointer
    pass
```

Cross-layer trace: C++ `CurrentWorkStream` (using `c10::hip::getCurrentHIPStreamMasqueradingAsCUDA`) → `DLPackExchangeAPI.current_work_stream` function pointer → Python test calls via `ctypes` inline extension → verifies `stream_ptr == torch.cuda.Stream.cuda_stream`.
