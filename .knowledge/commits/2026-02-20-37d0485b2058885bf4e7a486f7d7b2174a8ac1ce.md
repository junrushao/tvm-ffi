# Fix DLPack current_work_stream for ROCm and force addon override for Torch exchange API
## TL;DR
- Fixes `current_work_stream` to use `getCurrentHIPStreamMasqueradingAsCUDA` for ROCm devices instead of the CUDA codepath.
- Forces loading of the torch C DLPack extension on ROCm even when `__dlpack_c_exchange_api__` is already set, to ensure the corrected stream implementation is used.
- Adds GPU-based integration test for stream consistency.
