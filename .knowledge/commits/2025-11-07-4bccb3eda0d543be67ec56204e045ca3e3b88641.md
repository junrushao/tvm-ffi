# Change Error::what() to return message-only; add FullMessage() for kind+traceback
## TL;DR
- `Error::what()` now returns only `obj->message.data` (the bare message string) instead of the full formatted string with traceback and error kind. This conforms to the `std::exception::what()` convention that the function must be `noexcept` and should not allocate.
- New `Error::FullMessage() -> std::string` method returns the full formatted message (traceback + kind + message), replacing the old `what()` behavior.
- Removes `thread_local std::string what_data` from `what()`, eliminating a TLS dependency in the header. This improves compatibility with LLVM JIT scenarios.
- `ErrorBuilder` destructor now calls `FullMessage()` instead of `what()` for logging before throw.

## Key Exports
**Methods on `Error`** (class in `include/tvm/ffi/error.h`):
- `const char* what() const noexcept(true) override` -- **contract changed**: now returns `obj->message.data` only (no kind, no traceback)
- `std::string FullMessage() const` -- **new**: returns `"Traceback (most recent call last):\n" + traceback + kind + ": " + message + "\n"`

## Impact
- API: **breaking** for C++ callers that relied on `Error::what()` to contain the full traceback and error kind. They must switch to `Error::FullMessage()`.
- Behavioral: `what()` no longer allocates or uses TLS; `FullMessage()` allocates a `std::string` on each call
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Error/ErrorObj pattern per `.knowledge/designs/0006-error-handling.md`
- `TVM_FFI_THROW` macro (uses `ErrorBuilder` whose destructor is updated)

Design elements this commit mutates:
- `Error::what()` contract: from "full message with traceback" to "message-only". This is a semantic change to a core design element.
- Removal of `thread_local` storage from `Error::what()` -- changes the threading/allocation contract of the error system.

## Usage Examples
Before:
```cpp
try { ... } catch (const Error& e) {
  // e.what() returned full traceback + kind + message
  std::cerr << e.what();
}
```

After:
```cpp
try { ... } catch (const Error& e) {
  std::cerr << e.FullMessage();  // full traceback + kind + message
  // e.what() now returns message only (e.g., "test0")
  EXPECT_EQ(e.what(), "test0");
}
```
