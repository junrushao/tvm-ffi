# Make Error::what() conform to std::exception by returning message only
## TL;DR
- Changes `Error::what()` to return only the message string (no trace/kind), conforming to the `std::exception` contract that `what()` should not throw.
- Adds `Error::FullMessage()` for getting the complete message with trace and kind.
- Removes TLS from the header side, making compiled C++ objects more friendly to LLVM JIT.

## Impact
- API: `Error::what()` now returns message only; use `Error::FullMessage()` for full output
