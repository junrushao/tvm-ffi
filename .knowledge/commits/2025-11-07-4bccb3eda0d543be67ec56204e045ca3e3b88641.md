# Make Error::what() return only message, add FullMessage() for complete error info
## TL;DR
- Changes `Error::what()` to return only the error message (conforming to `std::exception::what()` which should not throw).
- Adds `Error::FullMessage()` to get the full error string including kind, message, and traceback.
- Updates `ErrorBuilder` to use `FullMessage()` for logging before throw.

## Key Exports

**Methods (Error class):**
- `Error::FullMessage() const -> std::string` -- Returns full error with traceback, kind, and message.
- `Error::what() const noexcept -> const char*` -- Now returns only `message.data` (was previously full message with traceback).

## Impact
- API: `Error::what()` now returns only the message string, not the full traceback. Callers relying on `what()` for full error info must switch to `FullMessage()`.
- ABI: none (no struct layout change)
- Behavioral: `what()` no longer allocates `thread_local` storage; returns direct pointer to message data.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Error/ErrorObj pattern (`.knowledge/designs/error-handling.md`)

Design elements this commit produces:
- `Error::FullMessage()` -- New accessor for complete error string including traceback.

## Usage Examples
```cpp
try {
  // ... code that throws
} catch (const tvm::ffi::Error& e) {
  // Before: e.what() returned full message with traceback
  // After: e.what() returns only the message
  std::cerr << e.FullMessage();  // For full traceback + kind + message
}
```
