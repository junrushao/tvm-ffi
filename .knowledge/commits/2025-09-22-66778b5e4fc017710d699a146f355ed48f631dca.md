# Enable Sphinx doc build checks in CI with stub-based Doxygen fallback
## TL;DR
- Adds a `doc` CI job that runs `sphinx-build -W --keep-going` on every commit, catching documentation warnings early.
- Introduces a stub mechanism in `docs/conf.py` to supply placeholder RST files (e.g., `reference/cpp/generated/index.rst`) when Doxygen/Exhale has not been run, preventing spurious toctree-missing-file errors.
- Fixes several Napoleon-style docstring warnings in `python/tvm_ffi/_tensor.py` and `python/tvm_ffi/module.py`.

## Key Exports
**Functions** (Sphinx config, not public API):
- `docs/conf.py::_prepare_stub_files()` -- copies stub RST files from `docs/_stubs/` into expected locations if they do not already exist.
- `docs/conf.py::_apply_config_overrides(app, config)` -- propagates the `build_exhale` flag into the Sphinx config at `config-inited` time.
- `docs/conf.py::setup(app: sphinx.application.Sphinx)` -- standard Sphinx extension entry point; calls `_prepare_stub_files`, registers `build_exhale` config value, and connects `_apply_config_overrides`.

**Configuration values**:
- `build_exhale` (Sphinx config value, boolean) -- controls whether the C++ API toctree (generated by Exhale/Doxygen) is included. Exposed via `ifconfig:: build_exhale` in `docs/reference/cpp/index.rst`.

## Design Elements
Design elements this commit consumes:
- **CI pipeline structure** (`ci_test.yml`): the existing `lint` and `prepare` jobs are used as `needs` dependencies for the new `doc` job, following the same pattern as the `test` job.
- **`uv` dependency groups** (`.knowledge/designs/0015-python-packaging.md`): the `docs` dependency group in `pyproject.toml` is extended with `setuptools<81`.
- **Napoleon docstring conventions** (Python code style from `CLAUDE.md`): the fixes in `_tensor.py` and `module.py` align docstrings with Google/NumPy style that Napoleon expects.

Design elements this commit produces:
- **Sphinx stub fallback pattern**: a `_stubs/` directory holding placeholder RST files that `conf.py::_prepare_stub_files()` copies into place when the real generated files are absent. This decouples CI doc builds from Doxygen/Exhale availability.
- **Conditional toctree via `ifconfig`**: the C++ API toctree in `docs/reference/cpp/index.rst` is now gated behind `build_exhale`, so Sphinx does not attempt to resolve `generated/index` when Exhale output is missing.
