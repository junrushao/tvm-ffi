# Add Sphinx doc build CI job with warning-as-error and fix docstring formatting

## TL;DR
- Adds a `doc` CI job that runs `sphinx-build -W --keep-going` on every commit, catching doc-build warnings as errors.
- Introduces a stub RST file and conditional `ifconfig` guard so Sphinx does not fail when Doxygen-generated C++ API pages are absent.
- Fixes NumPy-style docstring formatting in `Shape` and `Module` classes to satisfy Sphinx's stricter parsing.
