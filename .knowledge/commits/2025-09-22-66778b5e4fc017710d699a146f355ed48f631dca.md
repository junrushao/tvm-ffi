# Enable Sphinx doc build checks in CI with stub fallback for C++ API docs
## TL;DR
- Adds a new `doc` CI job that builds Python docs via `sphinx-build -W --keep-going` on every commit, catching doc warnings early.
- Introduces a stub mechanism in `docs/conf.py` so Sphinx does not fail when Doxygen-generated C++ API docs are absent; the C++ toctree is conditionally included via `ifconfig`.
- Fixes several Sphinx/Napoleon docstring formatting warnings in `python/tvm_ffi/_tensor.py` and `python/tvm_ffi/module.py`.

## Key Exports
N/A -- infrastructure.

## Impact
- API: none
- Behavioral: CI now fails on any Sphinx documentation warning (`-W` flag), enforcing doc quality.
- Flags/config: `build_exhale` is now a registered Sphinx config value, exposed via `ifconfig` directive to conditionally include C++ API toctree.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Sphinx documentation build system (`docs/conf.py`, RST sources)
- CI workflow matrix (`ci_test.yml` -- `lint`, `prepare`, `test` stages)
- `docs` dependency group in `pyproject.toml`
- Exhale/Breathe conditional C++ doc generation (`build_exhale` variable, already present in `conf.py`)

Design elements this commit produces:
- **CI `doc` job**: A new parallel CI stage that builds docs with warnings-as-errors, gating merges on doc correctness.
- **Stub fallback mechanism**: `_prepare_stub_files()` in `conf.py` copies stub RST files from `docs/_stubs/` to generated output paths when Doxygen output is absent, preventing broken toctree references.
- **`ifconfig` conditional toctree**: The C++ API full index toctree is now wrapped in `.. ifconfig:: build_exhale`, so it only appears when C++ docs are actually generated.
