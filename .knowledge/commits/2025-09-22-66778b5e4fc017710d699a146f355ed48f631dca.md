# Add Sphinx doc build stage to CI and fix Python docstrings
## TL;DR
- Adds a new `doc` CI job (parallel to `lint`) that builds Sphinx HTML docs with `-W --keep-going` to catch warnings as errors.
- Introduces `_prepare_stub_files()` in `docs/conf.py` to copy C++ API stub `.rst` into place when Doxygen/Exhale output is absent, guarding the toctree via `ifconfig:: build_exhale`.
- Normalizes docstrings in `Shape` and `Module` to NumPy style (formatting-only, no semantic change).

## Key Exports
N/A — infrastructure

## Impact
- API: none
- Behavioral: Sphinx build now fails CI on any warning (`-W`). The `build_exhale` config value controls whether the C++ API `generated/index` toctree is included.
- Flags/config: `build_exhale` Sphinx config value added; set from `docs/conf.py` runtime logic; defaults to `False` when Exhale is not run.
- Data formats/schemas: `docs/_stubs/cpp_index.rst` added as fallback stub for `reference/cpp/generated/index.rst`.

## Design Elements
Design elements this commit consumes:
- CI pipeline (`ci_test.yml`) — adds new parallel `doc` job after `lint`/`prepare`
- Sphinx documentation system (`docs/conf.py`, `docs/` layout)

Design elements this commit produces:
- `_prepare_stub_files()` mechanism: copies `docs/_stubs/cpp_index.rst` → `docs/reference/cpp/generated/index.rst` if not present; prevents missing-file Sphinx warnings in CI where Doxygen/Exhale is not run.
- `build_exhale` Sphinx config value: runtime boolean controlling whether C++ API toctree is included via `ifconfig`.
- `setup(app)` Sphinx hook in `docs/conf.py`: calls `_prepare_stub_files()` and registers `build_exhale` config value.
