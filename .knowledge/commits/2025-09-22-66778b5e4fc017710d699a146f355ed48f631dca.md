# Add Sphinx doc build CI job with stub fallback for missing Doxygen output
## TL;DR
- Adds a `doc` CI job (parallel to `lint`) that builds Sphinx HTML docs with `-W --keep-going` to catch warnings as errors.
- Introduces a stub mechanism in `docs/conf.py` that copies placeholder RST files into `generated/` paths when Doxygen C++ API output is absent, preventing toctree warnings.
- Fixes minor NumPy-style docstring formatting in `Shape` and `Module` classes and pins `setuptools<81` in the docs dependency group.
