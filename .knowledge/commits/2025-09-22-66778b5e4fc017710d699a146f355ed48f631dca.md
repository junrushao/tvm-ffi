# Add Sphinx doc build CI job with warning-as-error and stub-based C++ index fallback
## TL;DR
- Adds a `doc` CI job to `ci_test.yml` that runs `sphinx-build -W --keep-going` on every commit, catching documentation warnings as errors.
- Introduces a stub-file mechanism in `docs/conf.py` (`_prepare_stub_files`) that copies placeholder RST files into `reference/cpp/generated/` when Doxygen/Exhale output is absent, preventing missing-toctree Sphinx errors.
- Conditionalizes the C++ API toctree inclusion via Sphinx `ifconfig` directive gated on `build_exhale`, so the generated index is only referenced when Exhale actually ran.
- Fixes numpydoc-style docstring formatting in `_tensor.py` and `module.py` to pass `sphinx-build -W`.

## Design Elements
Design elements this commit consumes:
- **CI pipeline structure** ([0016-ci-and-lint-pipeline.md](../designs/0016-ci-and-lint-pipeline.md)): The `doc` job follows the established pattern of `needs: [lint, prepare]`, parallel to the `test` job.
- **Sphinx doc build** (documented in `docs/conf.py` and `docs/dev/doc.md`): The `sphinx-build` command and `--group docs` dependency group were established in prior doc-infrastructure commits.
- **`build_exhale` / `BUILD_CPP_DOCS` env var**: Pre-existing mechanism that gates Doxygen+Exhale C++ doc generation; this commit hooks into it via `ifconfig`.

Design elements this commit produces:
- **Stub-file fallback pattern**: A mechanism where `docs/_stubs/` contains placeholder RST files that are copied into expected toctree targets during `conf.py` setup, preventing Sphinx warnings when optional doc generators (Exhale) haven't run. This is a new convention for handling optional doc build stages.
- **`doc` CI job**: A new CI stage that validates documentation builds with warnings-as-errors on every commit, catching broken cross-references, bad docstring syntax, and missing toctree targets early.

## Usage Examples

**Running the doc build locally (same as CI)**:
```bash
# Build docs with warnings as errors (mirrors the CI doc job)
uv run --group docs sphinx-build -W --keep-going -b html docs docs/_build/html
```

**Adding a new stub file** (extending the pattern):
```python
# In docs/conf.py, add to _STUBS dict:
_STUBS = {
    "_stubs/cpp_index.rst": "reference/cpp/generated/index.rst",
    "_stubs/new_stub.rst": "path/to/expected/generated/file.rst",  # new
}
# Then create docs/_stubs/new_stub.rst with placeholder content.
```
