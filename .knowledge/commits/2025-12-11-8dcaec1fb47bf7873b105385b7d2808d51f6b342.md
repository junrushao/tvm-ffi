# Add keep_module_alive parameter to load_module for lifetime management
## TL;DR
- Adds `keep_module_alive` parameter to `load_module()` to control whether loaded module handles are kept alive for the process lifetime.
- Helps prevent use-after-free when module functions are called after module objects are garbage collected.

## Key Exports

**Python Functions:**
- `load_module(path, keep_module_alive=True)` -- Updated signature with lifetime control parameter.

## Impact
- API: New `keep_module_alive` parameter on `load_module`.
- ABI: none
- Behavioral: Modules can now be explicitly kept alive to prevent premature unloading.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Module system (`load_module`)

Design elements this commit produces:
- Module lifetime management via `keep_module_alive` pattern.

## Usage Examples
```python
mod = tvm_ffi.load_module("libkernel.so", keep_module_alive=True)
```
