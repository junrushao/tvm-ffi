# Add keep_module_alive flag to load_module to prevent premature unloading
## TL;DR
- Adds `keep_module_alive: bool = True` parameter to `load_module`, `cpp.load_inline`, and `cpp.load`, which registers loaded modules in a C++-side `ModuleGlobals` registry to prevent Python GC from unloading them.
- Adds private APIs `ModuleGlobalsAdd`/`ModuleGlobalsRemove` for managing the registry.
- Fixes issues (#264, #322) where modules were prematurely unloaded.

## Impact
- API: New `keep_module_alive` parameter (default `True`) on `load_module`, `cpp.load_inline`, `cpp.load`
- Flags/config: None
- Data formats/schemas: None
