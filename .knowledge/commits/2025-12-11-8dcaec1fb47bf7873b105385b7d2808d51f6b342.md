# Add keep_module_alive flag to load_module/load_inline/load, backed by a new ModuleGlobals singleton in C++, to prevent module-unload-before-object-deletion hazard

## TL;DR
- Adds `keep_module_alive: bool = True` parameter to `load_module`, `cpp.load_inline`, and `cpp.load`. When `True` (the default), the loaded `Module` is inserted into a new `ModuleGlobals` C++ singleton, preventing `dlclose` until `libtvm_ffi.so` itself unloads.
- Introduces `ModuleGlobals` (`src/ffi/extra/module.cc`): a thread-safe `std::mutex`-protected singleton holding a `Map<Module, int>` set; exposed via two new globals `tvm_ffi._ffi_api.ModuleGlobalsAdd` / `ModuleGlobalsRemove`.
- Eliminates the manual workarounds in tests (`run_check()` sub-function, `gc.collect(); del mod`) that were needed to prevent use-after-free from premature module unload (ref issues #264, #322).

## Impact
- API: `load_module`, `cpp.load_inline`, `cpp.load` gain `keep_module_alive: bool = True` — existing callers are unaffected (default `True`). Callers that manage module lifetime manually (e.g. short-lived test fixtures) should pass `keep_module_alive=False`.
- Behavioral: Modules loaded with the default `keep_module_alive=True` are now retained indefinitely in `ModuleGlobals` until the process exits (or explicit `ModuleGlobalsRemove`). This closes the use-after-free hazard documented in commit `a97b7c60` without requiring call-site workarounds.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

**Feature: default keep_module_alive=True eliminates manual lifetime management (cross-layer: C++ singleton ← Python call)**

```python
# BEFORE (commit a97b7c60 workaround — required manual scoping + gc):
import gc, tvm_ffi

mod = tvm_ffi.cpp.load_inline("stl_test", cpp_sources="...", functions=["f"])
def run_check(mod):
    assert mod.f(1) == 2  # all temp objects destroyed when sub-function returns
run_check(mod)
gc.collect()   # force Python GC to destroy Objects before module unload
del mod        # allow dlclose

# AFTER (this commit — no workarounds needed):
import tvm_ffi

mod = tvm_ffi.cpp.load_inline("stl_test", cpp_sources="...", functions=["f"])
assert mod.f(1) == 2  # safe: mod is pinned in ModuleGlobals until process exit
# no gc.collect() or del needed
```

**Feature: opt-out for short-lived modules (keep_module_alive=False)**

```python
mod = tvm_ffi.load_module("ephemeral_kernel.so", keep_module_alive=False)
# mod will unload when last Python reference is dropped — caller must ensure
# all objects created from mod are destroyed first
```

**C++ → Python trace**:
`ModuleGlobals::Add(mod)` stores ref-counted `Module` in `modules_` → ref-count on underlying `ModuleObj` incremented → `dlclose` blocked until `modules_.erase(mod)` or process exit.
