# Publish both manylinux2014 and manylinux_2_28 wheels for broader Linux coverage
## TL;DR
- Expands the CI build matrix to produce both manylinux2014 and manylinux_2_28 Linux wheels (x86_64 + aarch64), doubling Linux wheel coverage.
- Moves manylinux image selection from `pyproject.toml` (`[tool.cibuildwheel]`) to the GitHub Actions workflow matrix, using `CIBW_MANYLINUX_*_IMAGE` env vars.
- manylinux2014 wheels are only built on manual `workflow_dispatch` runs; manylinux_2_28 wheels build on every push to main.

## Key Exports
None -- this commit changes only CI configuration and build metadata.
