# Publish both manylinux2014 and manylinux_2_28 wheels for broader distro coverage
## TL;DR
- Expands the CI wheel-build matrix from 4 to 6 entries, adding separate `manylinux2014` and `manylinux_2_28` variants for each Linux arch (x86_64 and aarch64).
- Gates `manylinux2014` builds behind `workflow_dispatch` (manual releases only); automated push builds produce only `manylinux_2_28`.
- Moves manylinux image selection from static `pyproject.toml` config to per-matrix `CIBW_MANYLINUX_*_IMAGE` environment variables in the workflow.
