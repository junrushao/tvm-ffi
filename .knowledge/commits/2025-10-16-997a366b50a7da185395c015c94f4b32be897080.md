# Add manylinux_2_28 wheel builds alongside manylinux2014 for broader glibc coverage
## TL;DR
- Expand CI wheel matrix to build both `manylinux2014` and `manylinux_2_28` images for Linux x86_64 and aarch64, doubling Linux wheel variants.
- Move manylinux image selection from static `pyproject.toml` config to per-matrix-entry `CIBW_MANYLINUX_*_IMAGE` env vars in the GitHub Actions workflow.
- Gate `manylinux2014` builds to manual `workflow_dispatch` only, keeping tagged releases lean with only `manylinux_2_28`.

## Key Exports
N/A -- infrastructure.

## Impact
- API: none
- Behavioral: Tagged releases now produce `manylinux_2_28` wheels (glibc >= 2.28) instead of `manylinux2014` (glibc >= 2.17). Manual workflow dispatch produces both variants.
- Flags/config: `manylinux-x86_64-image` and `manylinux-aarch64-image` removed from `pyproject.toml`; image selection moved to workflow matrix variable `linux_image` and `CIBW_MANYLINUX_X86_64_IMAGE` / `CIBW_MANYLINUX_AARCH64_IMAGE` env vars.
- Data formats/schemas: none
