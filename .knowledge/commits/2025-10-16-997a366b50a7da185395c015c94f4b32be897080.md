# Publish both manylinux2014 and manylinux_2_28 wheels for broader compatibility
## TL;DR
- Expand the `publish_wheel.yml` CI matrix to build both `manylinux2014` and `manylinux_2_28` wheels for x86_64 and aarch64, maximizing glibc compatibility coverage.
- Move manylinux image selection from global `pyproject.toml` cibuildwheel config to per-matrix-entry `CIBW_MANYLINUX_*_IMAGE` env vars in the workflow, enabling per-variant control.
- Gate `manylinux2014` builds to `workflow_dispatch`-only runs, so automatic CI builds only produce `manylinux_2_28` wheels.

## Key Exports
N/A -- infrastructure

## Impact
- API: none
- Behavioral: Wheel build matrix doubles Linux entries (2 images x 2 arches = 4 Linux jobs, up from 2). Automatic pushes build `manylinux_2_28` only; manual dispatches also build `manylinux2014`. Windows and macOS are unaffected (`linux_image: ""`).
- Flags/config: Removed `manylinux-x86_64-image` and `manylinux-aarch64-image` from `[tool.cibuildwheel]` in `pyproject.toml`. Added `CIBW_MANYLINUX_X86_64_IMAGE` and `CIBW_MANYLINUX_AARCH64_IMAGE` env vars per matrix entry. Added `matrix.linux_image` dimension and conditional `if` on job level.
- Data formats/schemas: none
