# Remove unused OBJECT_INDEX dict from Cython object registration

## TL;DR

- Removes the `OBJECT_INDEX` Cython `dict` (mapping `cls -> type_index`) from `object.pxi`.
- Removes the single write to `OBJECT_INDEX` in `_register_object_by_index`.
- Dead code: the dict was never read anywhere; only `OBJECT_TYPE` (the reverse list) is consulted for object construction.
