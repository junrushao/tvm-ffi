# Remove unused OBJECT_INDEX dict from Cython object registration
## TL;DR
- Removed the `OBJECT_INDEX` module-level `cdef dict` from `python/tvm_ffi/cython/object.pxi` and its sole write site in `_register_object_by_index`.
- `OBJECT_INDEX` mapped Python object classes back to their type indices but was never read anywhere in the codebase.
- No behavioral or API change; the forward mapping `OBJECT_TYPE` (index -> class) remains and is the only lookup direction used.
