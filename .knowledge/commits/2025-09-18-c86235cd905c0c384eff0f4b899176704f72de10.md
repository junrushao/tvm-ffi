# Remove unused OBJECT_INDEX dict from Cython object registration
## TL;DR
- Removed the `OBJECT_INDEX` cdef dict and its population in `_register_object_by_index` from `python/tvm_ffi/cython/object.pxi`.
- `OBJECT_INDEX` mapped Python class objects to their type index but had zero consumers anywhere in the codebase.
- `OBJECT_TYPE` (index-to-class lookup) remains and is the only active registration data structure.
