# Remove unused OBJECT_INDEX dict from Cython object registration
## TL;DR
- Removed the `OBJECT_INDEX` cdef dict and its population in `_register_object_by_index` from `python/tvm_ffi/cython/object.pxi`.
- `OBJECT_INDEX` mapped Python class -> type index but had zero consumers anywhere in the codebase. Only the reverse mapping (`OBJECT_TYPE`: type index -> class) is used by `make_ret`.
