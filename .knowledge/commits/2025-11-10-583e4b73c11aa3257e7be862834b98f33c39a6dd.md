# Support all C++ argument qualifications in exported functions
## TL;DR
- Extends `FuncFunctorImpl` in `function_details.h` to support all C++ argument type qualifications: `T`, `const T`, `T&`, `const T&`, `T&&`, `const T&&`
- Uses `std::decay_t` and `std::remove_cv_t` to normalize argument types before TypeTraits dispatch
- Fixes issue where const-ref or rvalue-ref arguments in exported functions caused compilation failures

## Key Exports
```python
# C++ function_details.h (pseudocode)
# FuncFunctorImpl now handles all cv-ref qualified args:
# Before: only T and const T& worked reliably
# After: T, const T, T&, const T&, T&&, const T&& all dispatched correctly
# Interacts with: TypeTraits<T> (design-record 0005), Function::FromTyped (design-record 0003)
```
