# Support T, const T, const T&, and T&& as C++ exported function argument types

## TL;DR
- Adds `ArgTypeSupported<T>` constraint in `function_details.h` that restricts valid argument ref-qualifiers to: value `T`, const-value `const T`, const-lvalue-ref `const T&`, and rvalue-ref `T&&`.
- Makes `ArgValueWithContext` a class template parameterized on `Type`; non-template conversion operator replaces the previous template operator. This fixes compilation errors with classes like `std::optional<T>` that have template constructors.
- `unpack_call` updated to pass `ArgValueWithContext<std::tuple_element_t<Is, PackedArgs>>` instead of the old non-template form.

## Key Exports

```python
# C++ pseudocode — include/tvm/ffi/function_details.h

# New constraint (compile-time predicate)
ArgTypeSupported<T> = (not is_reference<T>)
    or (is_const<remove_ref<T>> and is_lvalue_ref<T>)   # const T&
    or (not is_const<remove_ref<T>> and is_rvalue_ref<T>)  # T&&
# Note: T& (non-const lvalue ref) and const T&& are NOT supported

class ArgValueWithContext_T:  # now template<typename Type>
    """Type-deduced argument value with error context.
    # Before: class ArgValueWithContext with template operator Type()
    # After: class ArgValueWithContext<Type> with operator TypeWithoutCR()
    # Interacts with: unpack_call (passes ArgValueWithContext<tuple_element<I, ArgType>>)
    # Invariant: Type must satisfy ArgTypeSupported<Type>
    """
    def convert(self) -> TypeWithoutCR: ...
```

## Impact
- API: C++ callers using `FromTyped` or `TVM_FFI_REGISTER_GLOBAL` with `T&` (mutable lvalue ref) args will now get a compile error — only the four supported qualifiers are valid.
- Behavioral: `std::optional<T>` parameters now work correctly (previously could silently fail).
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```cpp
// Now supported:
Function::FromTyped([](int x) { ... });         // T
Function::FromTyped([](const int x) { ... });   // const T
Function::FromTyped([](const int& x) { ... });  // const T&
Function::FromTyped([](String&& s) { ... });     // T&&

// NOT supported (compile error):
Function::FromTyped([](int& x) { ... });  // T& (non-const lvalue ref)
```
