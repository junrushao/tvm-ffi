# Fix torch-c-dlpack-ext f8e8m0 support to require torch >= 2.7
## TL;DR
- Updates the version guard for `kDLFloat8E8M0` support in torch-c-dlpack extension from torch >= 2.8 to torch >= 2.7 (the actual version that introduced f8e8m0).
- Adds a comment to `c_api.h` clarifying `kDLFloat8E8M0` availability.
