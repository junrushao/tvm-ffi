# Fix precise version guard for `Float8_e8m0fnu` in torch-c-dlpack extension

## TL;DR
- Corrects `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` to `#if (TORCH_VERSION_MAJOR > 2) || (TORCH_VERSION_MAJOR == 2 && TORCH_VERSION_MINOR >= 7)` for `Float8_e8m0fnu` — the e8m0 dtype was introduced in PyTorch 2.7, not 2.8.
- Splits the old version guard so `Float4_e2m1fn_x2` (Float4) remains gated at `>= 2.8`.
- Bumps `TVM_FFI_VERSION_PATCH` from 3 to 4 in `c_api.h`.

## Impact
- **Invariant violated before the fix**: `Float8_e8m0fnu` DLPack conversion was compiled out for PyTorch 2.7.x, silently omitting dtype support.
- **Invariant restored**: `Float8_e8m0fnu` is now compiled in for torch >= 2.7; `Float4_e2m1fn_x2` remains torch >= 2.8.
