# Fix torch version check for Float8_e8m0fnu to require 2.7 instead of 2.8
## TL;DR
- Corrects the torch version guard for `Float8_e8m0fnu` dtype from `>= 2.8` to `>= 2.7` in the torch-c-dlpack extension, enabling f8e8m0 support on PyTorch 2.7.
- Fixes a latent bug in the version comparison macro: `MAJOR >= 2 && MINOR >= N` is incorrect for `MAJOR > 2` (where `MINOR` could be 0); replaced with `(MAJOR > 2) || (MAJOR == 2 && MINOR >= N)`.
- Splits the previously combined `#if` guard for `Float8_e8m0fnu` and `Float4_e2m1fn_x2` into separate guards (2.7 and 2.8 respectively).
- Bumps `TVM_FFI_VERSION_PATCH` from 3 to 4.

## Key Exports

**Constants:**

- `TVM_FFI_VERSION_PATCH` = `4` (was `3`) in `include/tvm/ffi/c_api.h`

## Impact
- API: none (no public API signature changes)
- Behavioral: `Float8_e8m0fnu` DLPack round-trip now works on PyTorch 2.7+. Previously required 2.8+ due to the incorrect guard. The `Float4_e2m1fn_x2` guard remains at 2.8+.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **DLPack interop** (`0017-dlpack-interop.md`): torch version guards for sub-byte dtype conversion in `_build_optional_torch_c_dlpack.py`, specifically the `getDLDataTypeForDLPackv1` and `toScalarTypeForDLPackv1` functions.
- **C ABI layer** (`0001-c-abi-layer.md`): `TVM_FFI_VERSION_PATCH` version constant.

Design elements this commit produces: none (corrects existing guards, no new design elements)

## Usage Examples
**Before (broken on torch 2.7):**
```cpp
// Guard excluded Float8_e8m0fnu on torch 2.7 even though it was available
#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8
    case ScalarType::Float8_e8m0fnu: ...
    case ScalarType::Float4_e2m1fn_x2: ...
#endif
```

**After (correct):**
```cpp
// Float8_e8m0fnu available since torch 2.7
#if (TORCH_VERSION_MAJOR > 2) || (TORCH_VERSION_MAJOR == 2 && TORCH_VERSION_MINOR >= 7)
    case ScalarType::Float8_e8m0fnu: ...
#endif
// Float4_e2m1fn_x2 available since torch 2.8
#if (TORCH_VERSION_MAJOR > 2) || (TORCH_VERSION_MAJOR == 2 && TORCH_VERSION_MINOR >= 8)
    case ScalarType::Float4_e2m1fn_x2: ...
#endif
```
