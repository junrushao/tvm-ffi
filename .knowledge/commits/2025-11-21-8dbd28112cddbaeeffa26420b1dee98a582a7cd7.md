# Fix torch version guard for Float8_e8m0fnu to require >= 2.7 instead of >= 2.8

## TL;DR
- Corrects the `#if` preprocessor guard for `Float8_e8m0fnu` DLPack type conversion from `TORCH_VERSION_MINOR >= 8` to `TORCH_VERSION_MINOR >= 7`, since PyTorch added `ScalarType::Float8_e8m0fnu` in torch 2.7 (not 2.8).
- Splits the combined `#if` block so `Float8_e8m0fnu` (torch >= 2.7) and `Float4_e2m1fn_x2` (torch >= 2.8) have independent version guards. Both conversion directions (`getDLDataTypeForDLPackv1` and `toScalarTypeForDLPackv1`) are fixed symmetrically.
- Fixes the version comparison to also handle `TORCH_VERSION_MAJOR > 2` (e.g., torch 3.x), replacing the incorrect `TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` pattern which would fail for `MAJOR=3, MINOR=0`.
- Bumps `TVM_FFI_VERSION_PATCH` from 3 to 4 in `c_api.h`.
