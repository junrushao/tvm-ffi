# Rename DLPack C exchange API attribute from __c_dlpack_exchange_api__ to __dlpack_c_exchange_api__ with backward-compat shim

## TL;DR

- Renames the DLPack C exchange API class attribute and env-var skip flag across all layers (Cython C++ helper, Python, addons, tests) to use `__dlpack_c_exchange_api__` as the canonical name, matching anticipated future DLPack spec naming.
- Backward compatibility is preserved: a new `_check_and_update_dlpack_c_exchange_api()` helper reads the old `__c_dlpack_exchange_api__` name and, if found, copies its value to `__dlpack_c_exchange_api__`, so older addon wheels still work.
- `DLTensorTestWrapper` now sets `__dlpack_c_exchange_api__` directly as a `PyCapsule("dlpack_exchange_api")` at class definition time (via `pycapsule.PyCapsule_New`), replacing the prior indirect integer-pointer path.

## Rename Mapping

| Old name | New name | Files affected |
|---|---|---|
| `__c_dlpack_exchange_api__` (Python class attribute) | `__dlpack_c_exchange_api__` | `_optional_torch_c_dlpack.py`, `cython/tensor.pxi`, `cython/function.pxi`, `core.pyi`, `torch_c_dlpack_ext/core.py`, tests |
| `c_dlpack_exchange_api` (C++ struct field name) | `dlpack_c_exchange_api` | `tvm_ffi_python_helpers.h`, `cython/base.pxi` |
| `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` (env var) | `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API` | `cython/function.pxi` |

## Impact

- API: **Breaking** for external code that reads `tensor_cls.__c_dlpack_exchange_api__` directly. The `_check_and_update_dlpack_c_exchange_api` shim bridges the gap for the addon flow, but any third-party code that reads the old attribute name from `torch.Tensor` directly will no longer find it after an upgrade to this version (unless the addon also sets the old name).
- Behavioral: None — the same `DLPackExchangeAPI*` pointer is passed through; only the Python-visible attribute name changes.
- Flags/config: `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` → `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API`. Users relying on the env var to disable the C exchange API path must update their environment.
- Data formats/schemas: none.

## Usage Examples

**Before/after backward-compat pattern:**

```python
# BEFORE (commit < 539364726ea5):
# load_torch_c_dlpack_extension checked and set:
if hasattr(torch.Tensor, "__c_dlpack_exchange_api__"):
    return None
setattr(torch.Tensor, "__c_dlpack_exchange_api__", capsule)

# AFTER: the shim handles both old and new names transparently:
if _check_and_update_dlpack_c_exchange_api(torch.Tensor):
    # __dlpack_c_exchange_api__ now set (from native or upgraded from legacy)
    return None
# Only if neither attribute found: fall through to JIT build
setattr(torch.Tensor, "__dlpack_c_exchange_api__", capsule)
```

**DLTensorTestWrapper class attribute (before/after):**

```python
# BEFORE: integer pointer stored; consumed lazily on first call
_dltensor_test_wrapper_exchange_api_ptr()  # returns <long long> address
DLTensorTestWrapper.__c_dlpack_exchange_api__ = _dltensor_test_wrapper_exchange_api_ptr()

# AFTER: PyCapsule created eagerly at class definition; no intermediate int
DLTensorTestWrapper.__dlpack_c_exchange_api__ = pycapsule.PyCapsule_New(
    _dltensor_test_wrapper_get_exchange_api(),
    b"dlpack_exchange_api",
    NULL,
)
```
