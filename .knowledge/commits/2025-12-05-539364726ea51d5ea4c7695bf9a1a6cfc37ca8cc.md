# Rename __c_dlpack_exchange_api__ to __dlpack_c_exchange_api__ for forward-compatible DLPack naming

## TL;DR
- Renames the DLPack exchange API class attribute from `__c_dlpack_exchange_api__` to `__dlpack_c_exchange_api__` across all Python/Cython layers and the C++ helper header, anticipating a future DLPack naming convention change.
- Renames the internal struct field `c_dlpack_exchange_api` to `dlpack_c_exchange_api` in `TVMFFIPyCallContext`, `TVMFFIPyArgSetter`, and `TVMFFIPyCallManager`.
- Adds backward compatibility: `_check_and_update_dlpack_c_exchange_api()` detects the legacy `__c_dlpack_exchange_api__` attribute and auto-upgrades it to the new name (wrapping int-to-PyCapsule if needed).
- Renames env var `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` to `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API`.

### Rename Mapping

| Old Name | New Name | Location |
|----------|----------|----------|
| `__c_dlpack_exchange_api__` | `__dlpack_c_exchange_api__` | Python class attribute protocol |
| `c_dlpack_exchange_api` | `dlpack_c_exchange_api` | `TVMFFIPyCallContext` struct field |
| `c_dlpack_exchange_api` | `dlpack_c_exchange_api` | `TVMFFIPyArgSetter` struct field |
| `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` | `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API` | Environment variable |
| `_dltensor_test_wrapper_exchange_api_ptr()` | (removed) | `tensor.pxi` helper function |

## Impact
- API: `__c_dlpack_exchange_api__` class attribute is now legacy; `__dlpack_c_exchange_api__` is the canonical name. Backward compat shim in `_check_and_update_dlpack_c_exchange_api()` auto-upgrades legacy attributes.
- Behavioral: `DLTensorTestWrapper.__dlpack_c_exchange_api__` is now a PyCapsule (was int returned by helper function). The `_dltensor_test_wrapper_get_exchange_api()` return type changed from `const DLPackExchangeAPI*` to `DLPackExchangeAPI*` to allow direct PyCapsule construction.
- Flags/config: `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` env var renamed to `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API`. Old name no longer recognized.
- Data formats/schemas: none
