# Rename __c_dlpack_exchange_api__ to __dlpack_c_exchange_api__ with backward compatibility
## TL;DR
- Renames the DLPack exchange API attribute from `__c_dlpack_exchange_api__` to `__dlpack_c_exchange_api__` across the full stack (Cython, Python, C++ helpers, tests, addons) in anticipation of future DLPack naming convention changes.
- Maintains backward compatibility: `_check_and_update_dlpack_c_exchange_api()` detects the old attribute name and auto-creates the new one.
- The PyCapsule wrapping is now the canonical representation (replaces raw integer pointers).
- Environment variable renamed: `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` -> `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API`.

| Old name | New name |
|----------|----------|
| `__c_dlpack_exchange_api__` | `__dlpack_c_exchange_api__` |
| `c_dlpack_exchange_api` (field) | `dlpack_c_exchange_api` (field) |
| `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` | `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API` |

## Key Exports

**Functions**:
- `_check_and_update_dlpack_c_exchange_api(tensor_cls) -> bool` -- New helper in `_optional_torch_c_dlpack.py` that checks for both old and new attribute names, auto-upgrades integer pointers to PyCapsules, and sets the new attribute.
- `_create_dlpack_exchange_api_capsule(ptr_as_int) -> PyCapsule` -- New helper in `torch_c_dlpack_ext/core.py` (duplicated in `_optional_torch_c_dlpack.py`) for wrapping raw integer pointers in PyCapsules with name `"dlpack_exchange_api"`.

## Impact
- API: `__c_dlpack_exchange_api__` is still recognized via backward compatibility path but `__dlpack_c_exchange_api__` is the canonical name going forward.
- Behavioral: The torch addon now sets both `__c_dlpack_exchange_api__` (legacy int) and `__dlpack_c_exchange_api__` (PyCapsule) on `torch.Tensor`.
- Flags/config: Environment variable renamed from `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` to `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API`.
- Data formats/schemas: None.
