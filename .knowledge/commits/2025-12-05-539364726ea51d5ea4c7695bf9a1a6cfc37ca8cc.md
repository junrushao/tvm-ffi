# Rename __c_dlpack_exchange_api__ to __dlpack_c_exchange_api__ with backward compatibility

## TL;DR
- Renames the DLPack exchange API attribute from `__c_dlpack_exchange_api__` to `__dlpack_c_exchange_api__` across all Python/Cython layers and the C++ helper header, aligning with a future DLPack naming convention change.
- Adds backward compatibility: `_check_and_update_dlpack_c_exchange_api()` detects the old `__c_dlpack_exchange_api__` attribute (int or PyCapsule) and auto-upgrades it to `__dlpack_c_exchange_api__`.
- The torch addon now sets **both** `__c_dlpack_exchange_api__` (legacy) and `__dlpack_c_exchange_api__` (new, PyCapsule) on `torch.Tensor`, while `DLTensorTestWrapper` uses only the new name with PyCapsule transport directly.
- Environment variable renamed: `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` -> `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API`.

### Rename Mapping

| Old name | New name | Location |
|----------|----------|----------|
| `__c_dlpack_exchange_api__` | `__dlpack_c_exchange_api__` | Python dunder attribute on tensor classes |
| `c_dlpack_exchange_api` | `dlpack_c_exchange_api` | C++ field: `TVMFFIPyCallContext`, `TVMFFIPyArgSetter` (`tvm_ffi_python_helpers.h`) |
| `c_dlpack_exchange_api` | `dlpack_c_exchange_api` | Cython struct fields: `TVMFFIPyCallContext`, `TVMFFIPyArgSetter` (`base.pxi`) |
| `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` | `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API` | Environment variable (`function.pxi`) |

## Impact
- API: `__c_dlpack_exchange_api__` is still accepted (legacy) but `__dlpack_c_exchange_api__` is now the canonical attribute name. Any code checking `hasattr(cls, "__c_dlpack_exchange_api__")` as the primary check will still work because the compatibility shim and the torch addon set both attributes. However, code that *only* sets `__c_dlpack_exchange_api__` on a custom tensor class will still be detected by the backward-compatibility handler.
- Behavioral: `DLTensorTestWrapper.__dlpack_c_exchange_api__` is now a PyCapsule (was an int returned by `_dltensor_test_wrapper_exchange_api_ptr()`). The removed helper function `_dltensor_test_wrapper_exchange_api_ptr()` is no longer exported. Test code now only checks for PyCapsule type, not int.
- Flags/config: `TVM_FFI_SKIP_C_DLPACK_EXCHANGE_API` renamed to `TVM_FFI_SKIP_DLPACK_C_EXCHANGE_API`. Old env var name no longer recognized.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **DLPackExchangeAPI struct** ([ADR-0015](../ADRs/0015-dlpack-exchange-api-struct.md)): The unified C struct for zero-Python-overhead tensor exchange. This commit renames the Python-facing attribute that points to it.
- **PyCapsule transport** (7f3bb77): The PyCapsule wrapping mechanism added previously is now the only transport for the new `__dlpack_c_exchange_api__` attribute. Legacy int transport is handled only in the backward-compat shim.
- **DLPack fast-path in arg setter** ([0012-python-bindings](../designs/0012-python-bindings.md)): `TVMFFIPyArgSetterFactory_` and `TVMFFIPyCallContext` carry the renamed field through the call dispatch path.

Design elements this commit produces:
- **`_check_and_update_dlpack_c_exchange_api()`**: New compatibility shim function that centralizes detection and migration from old to new attribute name. Replaces two separate `hasattr` + migration code paths in `load_torch_c_dlpack_extension()`.
- **Dual-attribute convention**: The torch addon now sets both old and new attribute names on `torch.Tensor`, establishing a forward+backward compatibility pattern.

## Usage Examples

**Before (old attribute name):**
```python
# Custom tensor class exposing DLPack exchange API (old convention)
class MyTensor:
    __c_dlpack_exchange_api__ = get_exchange_api_ptr()  # int or PyCapsule

# Check in consumer code
if hasattr(torch.Tensor, "__c_dlpack_exchange_api__"):
    ...
```

**After (new attribute name with backward compat):**
```python
# Custom tensor class exposing DLPack exchange API (new convention)
class MyTensor:
    __dlpack_c_exchange_api__ = PyCapsule(...)  # always PyCapsule now

# The loader auto-detects either attribute name:
from tvm_ffi._optional_torch_c_dlpack import _check_and_update_dlpack_c_exchange_api
if _check_and_update_dlpack_c_exchange_api(torch.Tensor):
    # __dlpack_c_exchange_api__ is guaranteed set (PyCapsule)
    pass
```
