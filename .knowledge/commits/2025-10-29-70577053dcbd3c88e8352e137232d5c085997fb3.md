# Refactor torch C DLPack build script: rename, version-tagged library names, separate build/output dirs
## TL;DR
- Renames `_build_optional_c_dlpack.py` to `_build_optional_torch_c_dlpack.py` and restructures its CLI: replaces `--build_dir` with `--build-dir` (temp dir by default), `--output-dir`, `--libname`, and `--build-with-cuda`.
- Library names now include torch version and device tag: `libtorch_c_dlpack_addon_torch{major}{minor}-{cpu|cuda}.so`, enabling multiple torch versions to coexist in the cache.
- Moves module-level imports (`tvm_ffi.cpp.load_inline`, `tvm_ffi.utils.lockfile`, `tvm_ffi.libinfo`) inside functions to break cyclic dependency, replacing the `TVM_FFI_DISABLE_TORCH_C_DLPACK` env var workaround at module scope.
- Separates build directory (temp, disposable) from output directory (cache, persistent), with file locking on the output path.

## Key Exports

**Renames**:
| Old | New |
|-----|-----|
| `python/tvm_ffi/utils/_build_optional_c_dlpack.py` | `python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py` |
| CLI `--build_dir` | CLI `--build-dir` (optional, defaults to temp dir) |
| CLI `--build_with_cuda` | CLI `--build-with-cuda` |

**New CLI args**:
- `--output-dir` -- directory for the final `.so`/`.dll` (default: `$TVM_FFI_CACHE_DIR` or `~/.cache/tvm-ffi/`)
- `--libname` -- override library filename; default `"auto"` generates version-tagged name

**Library naming convention**: `libtorch_c_dlpack_addon_torch{major}{minor}-{cpu|cuda}.{so|dll}`

## Impact
- API: build script renamed and CLI args changed (underscores to hyphens, new `--output-dir` and `--libname` args).
- Behavioral: library file now version-tagged, enabling multiple torch versions in the same cache directory without collisions.
- Flags/config: none (env vars unchanged)
- Data formats/schemas: none
