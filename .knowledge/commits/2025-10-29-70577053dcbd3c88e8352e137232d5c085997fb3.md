# Lint torch C DLPack build utility: rename, move top-level defs into main(), version-tagged lib names
## TL;DR
- Renames `_build_optional_c_dlpack.py` to `_build_optional_torch_c_dlpack.py` for naming consistency.
- Moves `argparse` setup, `tvm_ffi` imports, and environment variable side-effects from module top-level into `main()`, avoiding cyclic imports and lint issues.
- Introduces version-tagged library names (`libtorch_c_dlpack_addon_torch{major}{minor}-{cpu|cuda}.so`) and separates `--build-dir` (temp build artifacts) from `--output-dir` (final library location).

| Old name | New name |
|---|---|
| `python/tvm_ffi/utils/_build_optional_c_dlpack.py` | `python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py` |
| CLI `--build_dir` | CLI `--build-dir` (temp) + `--output-dir` (final) |
| CLI `--build_with_cuda` | CLI `--build-with-cuda` |
| Library name `libtorch_c_dlpack_addon.so` | `libtorch_c_dlpack_addon_torch{major}{minor}-{cpu|cuda}.so` |

## Key Exports
No new public API surface. Internal build script CLI changes only.

```python
# Build script CLI (python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py):
# OLD: python _build_optional_c_dlpack.py --build_dir DIR --build_with_cuda
# NEW: python _build_optional_torch_c_dlpack.py --build-dir DIR --output-dir DIR --libname NAME --build-with-cuda

# Library naming convention (new):
# libtorch_c_dlpack_addon_torch{major}{minor}-{cpu|cuda}.{so|dll}
# e.g. libtorch_c_dlpack_addon_torch26-cuda.so

# Import restructuring:
# OLD: top-level `from tvm_ffi.cpp.load_inline import build_ninja` (cyclic risk)
# NEW: lazy import inside main() and _generate_ninja_build()
```

## Impact
- API: none -- internal build utility only, not a public API
- Behavioral: library files now include torch version and device in their name, so different torch versions can coexist in the same cache directory; build artifacts go to a temp dir, only the final .so is placed in output-dir
- Flags/config: `--build_dir` renamed to `--build-dir`; new `--output-dir` and `--libname` args; `--build_with_cuda` renamed to `--build-with-cuda`
- Data formats/schemas: none
