# Refactor torch C DLPack build script: rename, separate output dir, version-specific library naming
## TL;DR
- Renames `_build_optional_c_dlpack.py` to `_build_optional_torch_c_dlpack.py` and moves top-level imports (`tvm_ffi.cpp.load_inline`, `tvm_ffi.libinfo`, `tvm_ffi.utils.lockfile`) inside `main()` to avoid cyclic imports at module scope.
- Separates the build directory from the output directory: builds now happen in a `tempfile.mkdtemp` temp dir, and the final `.so`/`.dll` is placed in `--output-dir` (default: `~/.cache/tvm-ffi`).
- Introduces version-and-device-specific library naming (`libtorch_c_dlpack_addon_torch{major}{minor}-{cpu|cuda}.so`) so multiple PyTorch versions can coexist in the same cache directory.

Rename mapping:

| Before | After |
|--------|-------|
| `python/tvm_ffi/utils/_build_optional_c_dlpack.py` | `python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py` |
| CLI: `--build_dir` | CLI: `--build-dir` (optional, defaults to tempdir) |
| CLI: `--build_with_cuda` | CLI: `--build-with-cuda` |
| (new) | CLI: `--output-dir` (where final lib is placed) |
| (new) | CLI: `--libname` (explicit or `auto` for version-specific name) |
| Lib name: `libtorch_c_dlpack_addon.so` | Lib name: `libtorch_c_dlpack_addon_torch{M}{m}-{device}.so` |

## Key Exports
None -- this commit does not introduce new public API. It restructures the internal build utility and its CLI interface. The key behavioral changes are:

```python
# Build script CLI (python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py)
# Before: single --build_dir served as both build and output location
# After:  --build-dir (temp by default) + --output-dir (cache dir) + --libname

# Library naming convention change:
# Before: libtorch_c_dlpack_addon.{so|dll}
# After:  libtorch_c_dlpack_addon_torch{major}{minor}-{cpu|cuda}.{so|dll}
# Invariant: major/minor come from torch.__version__.split(".")[:2]
# Invariant: device is "cuda" if torch.cuda.is_available() (caller) or --build-with-cuda (script)

# Import restructuring (cyclic import avoidance):
# Before: top-level imports of tvm_ffi.cpp.load_inline, tvm_ffi.libinfo, tvm_ffi.utils.lockfile
# After:  deferred inside main() or inside _generate_ninja_build()
# Invariant: os.environ["TVM_FFI_DISABLE_TORCH_C_DLPACK"] = "1" set before tvm_ffi imports
```

## Impact
- API: Internal CLI interface changed (underscore args to hyphen args, new `--output-dir`/`--libname` flags). No public Python API change.
- Behavioral: Library artifacts are now version-specific, allowing multiple PyTorch versions to coexist in the same cache without overwriting each other. Build artifacts go to a temp dir and only the final `.so` is placed in the output dir.
- Flags/config: `TVM_FFI_CACHE_DIR` env var behavior unchanged (still defaults to `~/.cache/tvm-ffi`). The lock file is now placed next to the output lib (`libname.lock`) in `--output-dir` rather than as `build.lock` in the build dir.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Module system / `load_inline` pipeline** (`.knowledge/designs/0011-module-system.md`): The build script uses `tvm_ffi.cpp.load_inline.build_ninja` to drive the ninja build. The `_generate_ninja_build` function also imports `tvm_ffi.libinfo.find_dlpack_include_path`.
- **FileLock utility** (`tvm_ffi.utils.lockfile`): Used to serialize concurrent builds of the same output library.
- **Torch C DLPack JIT extension** (`python/tvm_ffi/_optional_torch_c_dlpack.py`): The caller that invokes this build script, referenced in `.knowledge/ADRs/0015-dlpack-exchange-api-struct.md`.

Design elements this commit produces:
- **Version-specific library naming convention**: `libtorch_c_dlpack_addon_torch{major}{minor}-{cpu|cuda}.{so|dll}` -- a new naming pattern that encodes PyTorch version and device capability into the library filename. This is an internal convention, not a public API.

## Usage Examples
Before (invoking build script):
```bash
# Old: single build dir, fixed library name
python _build_optional_c_dlpack.py --build_dir ~/.cache/tvm-ffi/torch_c_dlpack_addon
# Produces: ~/.cache/tvm-ffi/torch_c_dlpack_addon/libtorch_c_dlpack_addon.so
```

After (invoking build script):
```bash
# New: separate output dir, version-specific library name
python _build_optional_torch_c_dlpack.py \
    --output-dir ~/.cache/tvm-ffi \
    --libname libtorch_c_dlpack_addon_torch213-cuda.so \
    --build-with-cuda
# Produces: ~/.cache/tvm-ffi/libtorch_c_dlpack_addon_torch213-cuda.so
# Build artifacts in a temp dir (auto-cleaned)
```
