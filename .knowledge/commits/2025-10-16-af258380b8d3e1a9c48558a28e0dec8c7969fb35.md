# Split installation docs into PyPI quickstart and build-from-source guide

## TL;DR
- Deleted monolithic `docs/get_started/install.md`; moved PyPI install snippet to `docs/index.rst` homepage and rewrote build-from-source as `docs/guides/build_from_source.md`.
- Updated `docs/index.rst` toctree: removed `get_started/install.md`, added `guides/build_from_source.md`, added top-level "Installation" section with `pip install` one-liner.
- Made CMake install of `tvm_ffi_testing` and `tvm_ffi_static` conditional on target existence (`if(TARGET ...)` + `OPTIONAL`), preventing install failures when those targets are not built.
