# Split installation docs into homepage PyPI snippet and a new build-from-source guide
## TL;DR
- Deleted `docs/get_started/install.md` and replaced it with two parts: an inline PyPI install snippet on the docs homepage (`docs/index.rst`) and a fully rewritten `docs/guides/build_from_source.md` guide.
- The new build guide covers Python (scikit-build-core) and C++-only workflows, plus a troubleshooting section.
- CMake install rules for `tvm_ffi_testing` and `tvm_ffi_static` targets now use `OPTIONAL` to prevent failures when those targets are not built.
