# Split installation docs: PyPI on homepage, build-from-source moved to guides

## TL;DR
- Deletes `docs/get_started/install.md` and splits its content into two locations: a brief PyPI install snippet inlined into `docs/index.rst` (the homepage), and a new `docs/guides/build_from_source.md` with a fully rewritten source-build guide.
- The new build-from-source guide covers Python package building (via `pip install --reinstall -e .` with scikit-build-core), C++-only library building, and troubleshooting.
- Makes CMake `install()` rules for `tvm_ffi_testing` and `tvm_ffi_static` targets conditional and `OPTIONAL`, so `cmake --install` succeeds even when those targets are not built.

## Key Exports

**`docs/guides/build_from_source.md`** (98 lines) -- New guide covering:
- Prerequisites: Python 3.9+, C++17 compiler, CMake 3.18+, Ninja
- Python package build via `pip install --reinstall --verbose -e . --config-settings cmake.define.TVM_FFI_ATTACH_DEBUG_SYMBOLS=ON`
- C++-only build via `cmake . -B build_cpp && cmake --build && cmake --install --prefix ./dist`
- Troubleshooting section (rebuild after C++/Cython changes, submodules, library-not-found, generator/build-type)

**`docs/index.rst`** changes -- Adds an "Installation" section with `pip install apache-tvm-ffi` code block directly on the homepage. Removes `get_started/install.md` from the toctree. Adds `guides/build_from_source.md` to the guides toctree.

**`CMakeLists.txt`** changes -- Two install rules made conditional:
- `install(TARGETS tvm_ffi_testing ...)` now guarded by `if (TARGET tvm_ffi_testing)` with `OPTIONAL`
- `install(TARGETS tvm_ffi_static ...)` now has `OPTIONAL` added
