# Split installation docs into homepage PyPI snippet and guides/build_from_source.md; guard optional CMake install targets

## TL;DR

- Deleted `docs/get_started/install.md`; moved PyPI one-liner inline into `docs/index.rst` homepage; added `docs/guides/build_from_source.md` with expanded Python + C++-only build workflows and troubleshooting.
- Updated `docs/index.rst` toctree: removed `install.md` from "Get Started", added `build_from_source.md` to "Guides".
- `CMakeLists.txt`: wrapped `tvm_ffi_testing` and `tvm_ffi_static` install targets in `if(TARGET …)` guards with `OPTIONAL` flag to prevent install errors when those targets are not built.

N/A — docs restructuring and CMake build fix; no new API surface.
