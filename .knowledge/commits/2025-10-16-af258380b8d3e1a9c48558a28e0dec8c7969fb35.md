# Split installation docs into PyPI quickstart on homepage and rewritten build-from-source guide

## TL;DR
- Deletes `docs/get_started/install.md`, inlines `pip install apache-tvm-ffi` onto the Sphinx homepage (`docs/index.rst`), and adds a fully rewritten `docs/guides/build_from_source.md` covering Python editable install and C++-only build workflows.
- Makes CMake `install()` for `tvm_ffi_testing` and `tvm_ffi_static` targets conditional/optional so `cmake --install` no longer fails when those targets are not built.

## Key Exports

None -- documentation restructuring and CMake install guard; no new public API symbols.

## Impact
- API: none
- Behavioral: `cmake --install` no longer errors when `tvm_ffi_testing` target was not built (e.g., when `TVM_FFI_BUILD_TESTS` is OFF). Previously, the unconditional `install(TARGETS tvm_ffi_testing ...)` would fail. Same for `tvm_ffi_static` when `TVM_FFI_BUILD_PYTHON_MODULE` is ON.
- Flags/config: CMake `install(TARGETS tvm_ffi_testing ...)` is now wrapped in `if (TARGET tvm_ffi_testing)` and both install directives gain the `OPTIONAL` keyword.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Sphinx toctree structure for documentation site (homepage `index.rst`, `get_started/` section, `guides/` section)
- CMake install targets convention for `tvm_ffi_shared`, `tvm_ffi_static`, `tvm_ffi_testing` (`.knowledge/designs/0013-packaging.md`)
- `tvm-ffi-config` CLI tool referenced in new build guide

Design elements this commit produces:
- New documentation page `docs/guides/build_from_source.md` covering two workflows: Python editable install with scikit-build-core, and C++-only library build
- Inline installation snippet on Sphinx homepage replacing the separate installation page
