# Split installation docs into PyPI install (homepage) and build-from-source (guide)
## TL;DR
- Deletes `docs/get_started/install.md` and splits its content: PyPI install instructions go inline on `docs/index.rst` homepage; build-from-source becomes a new `docs/guides/build_from_source.md` guide.
- Makes CMake `install()` targets for `tvm_ffi_testing` and `tvm_ffi_static` conditional/optional, preventing install failures when those targets are not built.
