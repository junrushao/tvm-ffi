# Fix code style issues in reflection init helper from PR #127
## TL;DR
- Renames `INIT_METHOD_NAME` to `kInitMethodName` to follow Google C++ naming convention for static constexpr constants.
- Makes `init<Args...>` default constructor `constexpr noexcept = default` instead of empty body.
- Adds `[[maybe_unused]]` attribute to the `init_func` tag parameter in `ObjectDef::def()` to suppress unused-parameter warnings.
