# Clean up init struct: constexpr default ctor, Google naming, [[maybe_unused]]
## TL;DR
- Applies three cosmetic fixes to `reflection::init<Args...>` struct and `ObjectDef::def(init<Args...>)` in `registry.h`, following up on PR #127 (fc2630f) which introduced the struct.
- `init()` constructor changed from empty body `{}` to `constexpr init() noexcept = default`.
- `INIT_METHOD_NAME` renamed to `kInitMethodName` (Google C++ style for constants).
- `[[maybe_unused]]` attribute added to the `init_func` parameter in `ObjectDef::def(init<Args...>, Extra&&...)`.
