# Rename INIT_METHOD_NAME to kInitMethodName and apply minor C++ style fixes in reflection registry
## TL;DR
- Renames `ObjectDef::INIT_METHOD_NAME` to `ObjectDef::kInitMethodName` to follow Google C++ naming convention for `static constexpr` string constants.
- Changes `init()` default constructor to `constexpr init() noexcept = default;` for correctness and optimizability.
- Marks the `init_func` parameter in `ObjectDef::def(init<Args...>, ...)` as `[[maybe_unused]]` to suppress a compiler warning.
