# Replace load_inline CUDA stream getter with torch._C._cuda_getCurrentRawStream

## TL;DR
- Removes `load_torch_get_current_cuda_stream()` — a function that JIT-compiled a C++ inline extension via `torch.utils.cpp_extension.load_inline` to call `at::cuda::getCurrentCUDAStream()`.
- Replaces the entire lazy-init pattern (`torch_get_current_cuda_stream` module-level variable + deferred compilation) with a direct one-liner: `torch._C._cuda_getCurrentRawStream(device_id)`.
- Bumps package version from `0.1.0a6` to `0.1.0a7`.

## Key Exports

The **removed** lazy-init pattern (as it existed before this commit):

```python
# REMOVED: load_torch_get_current_cuda_stream() in function.pxi
# This function JIT-compiled a cpp_extension.load_inline module on first CUDA tensor call.
# Invariant (old): function pointer was None until first CUDA DLPack arg; compilation happened
#                  in-process via torch.utils.cpp_extension.load_inline, with fallback
#                  to torch.cuda.current_stream(device_id).cuda_stream if compilation failed.

# REMOVED module-level variable:
torch_get_current_cuda_stream = None  # was lazily populated on first CUDA tensor

# REMOVED inside make_args(), CUDA tensor branch:
# if torch_get_current_cuda_stream is None:
#     torch_get_current_cuda_stream = load_torch_get_current_cuda_stream()
# temp_ptr = torch_get_current_cuda_stream(temp_dltensor.device.device_id)
```

The **new** direct call (after this commit):

```python
# CURRENT: inside make_args() CUDA tensor branch in function.pxi
# This is an API that dynamo and other uses to get the raw stream from torch
temp_ptr = torch._C._cuda_getCurrentRawStream(temp_dltensor.device.device_id)
# Interacts with: torch.Tensor DLPack path in make_args()
# Interacts with: ctx_stream[0] = <TVMFFIStreamHandle>temp_ptr  (stream injection into packed call)
# Invariant: torch._C._cuda_getCurrentRawStream is a stable internal PyTorch C API,
#            also used by torch.compile/dynamo — less likely to break across PT releases.
# Invariant: no lazy init guard needed; call directly on every CUDA tensor arg.
```

## Impact
- API: None — internal Cython implementation change, no public API surface affected.
- Behavioral: Eliminates JIT compilation on first CUDA tensor arg. The stream pointer is now obtained via a direct Python C API call instead of a compiled C++ extension. The `fallback_get_current_cuda_stream` path (pure Python `torch.cuda.current_stream`) is also removed.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **Packed function calling convention / `make_args`** (`0004-function-system`, `0013-python-package`): the CUDA tensor branch in `make_args` that injects the current stream into the packed call context. This commit modifies _how_ the stream handle is obtained but leaves the injection protocol (`ctx_stream[0] = <TVMFFIStreamHandle>temp_ptr`) unchanged.
- **`torch_get_current_cuda_stream` lazy-init pattern** (`0012-env-api`, `0013-python-package`): the deferred initialization pattern introduced in commit `4523a83`. This commit **removes** the pattern entirely.

Design elements this commit produces:
- **Direct `torch._C._cuda_getCurrentRawStream` call convention** — replaces the lazy-compiled helper. No new abstraction is introduced; the stream getter is now a stateless direct call. This is a simpler invariant: no module-level mutable state, no conditional compilation path.

## Usage Examples

**Before** (lazy-compiled C++ extension approach):
```python
# module level: torch_get_current_cuda_stream = None
# Inside make_args(), CUDA branch:
if torch_get_current_cuda_stream is None:
    torch_get_current_cuda_stream = load_torch_get_current_cuda_stream()
    # load_torch_get_current_cuda_stream() calls cpp_extension.load_inline(...)
    # compiles C++ code that calls at::cuda::getCurrentCUDAStream(device_id)
temp_ptr = torch_get_current_cuda_stream(temp_dltensor.device.device_id)
ctx_stream[0] = <TVMFFIStreamHandle>temp_ptr
```

**After** (direct C API call):
```python
# Inside make_args(), CUDA branch:
# This is an API that dynamo and other uses to get the raw stream from torch
temp_ptr = torch._C._cuda_getCurrentRawStream(temp_dltensor.device.device_id)
ctx_stream[0] = <TVMFFIStreamHandle>temp_ptr
```
