# Update backtrace storage to append-friendly order (ABI change)
## TL;DR
- Renames `traceback` to `backtrace` throughout the C ABI, C++ API, Cython bindings, and Python layer. The stored order is now "most recent call first" (top of stack to bottom), making incremental append efficient during error propagation.
- Adds `TVMFFIBacktraceUpdateMode` enum (`kTVMFFIBacktraceUpdateModeReplace`, `kTVMFFIBacktraceUpdateModeAppend`) and changes `update_traceback` function pointer in `TVMFFIErrorCell` to `update_backtrace` with a new `update_mode` parameter.
- Changes `TVMFFIErrorCreate` return type from `TVMFFIObjectHandle` to `int` (error code) with an `out` parameter, aligning with the standard C API error handling pattern.
- Renames `traceback.cc`/`traceback.h` to `backtrace.cc`/`backtrace_utils.h`.
- Bumps version to `0.1.0b5`.

## Impact
- API: **ABI-breaking change.** `TVMFFIErrorCell.traceback` -> `backtrace`, `update_traceback` -> `update_backtrace` (with extra `update_mode` param), `TVMFFIErrorCreate` signature change. All consumers of the error ABI must update.
- Flags/config: none
- Data formats/schemas: Backtrace string ordering changed from "most recent call last" to "most recent call first". Display code must reverse lines for Python-style rendering.

## Design Elements
Design elements this commit consumes:
- **Error Handling** (`.knowledge/designs/0007-error-handling.md`): `ErrorObj`, `ErrorObjFromStd`, `TVMFFIErrorCell` ABI struct.
- **Traceback System** (`.knowledge/designs/0015-traceback-system.md`): Backtrace capture and propagation across FFI boundaries.
- **C ABI** (`.knowledge/designs/0001-c-abi.md`): `TVMFFIErrorCreate`, `TVMFFIGetStackBacktrace` C API functions.

Design elements this commit produces:
- **Append-friendly backtrace convention**: Backtrace stored as "most recent call first" enables O(1) append during error propagation up the call stack. Display code reverses for user-friendly rendering.
- **`TVMFFIBacktraceUpdateMode` enum**: New ABI enum controlling whether backtrace is replaced or appended. Enables incremental backtrace building.
- **Safer `TVMFFIErrorCreate`**: Returns error code instead of raw handle, with `out` parameter. Avoids panic on OOM during error creation.
