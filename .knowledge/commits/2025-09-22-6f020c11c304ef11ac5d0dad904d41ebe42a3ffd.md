# Rename traceback to backtrace, reverse storage order for append-friendly propagation, update TVMFFIErrorCreate to return int

## TL;DR
- Renames `traceback` to `backtrace` across the entire C ABI, C++ API, Python bindings, and internal source files. Adds `TVMFFIBacktraceUpdateMode` enum for replace/append semantics.
- Reverses the default backtrace storage order to most-recent-call-first, enabling efficient append during error propagation. `TracebackMostRecentCallLast()` reverses lines for display.
- Changes `TVMFFIErrorCreate` from returning a handle directly to returning `int` with an out-parameter, adding proper `std::bad_alloc` handling.
- Bumps version from `0.1.0b4` to `0.1.0b5`. Fixes quick_start example dependencies.

## Impact
- API: Breaking. All C, C++, and Python callers using `traceback` APIs must migrate to `backtrace`. `TVMFFIErrorCreate` callers must handle `int` return and use out-parameter. `update_traceback`/`update_backtrace` callers must supply `update_mode`.
- ABI: Breaking. `TVMFFIErrorCell` layout changes (`traceback` -> `backtrace`, `update_traceback` signature gains `int32_t update_mode`). `TVMFFITraceback` renamed to `TVMFFIBacktrace`. `TVMFFIErrorCreate` return type changes from `TVMFFIObjectHandle` to `int`. Version bumped `0.1.0b4` -> `0.1.0b5`.
- Behavioral: Backtrace storage order reversed to most-recent-call-first. `Error::what()` now calls `TracebackMostRecentCallLast()` to reverse for display. Python `_traceback_to_backtrace_str` reverses lines before storing. `_with_append_backtrace` no longer calls `reversed()` when reconstructing Python traceback (the storage order already matches the iteration direction needed). Test assertions for position ordering are flipped (`<` vs `>`).
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Error object system** (`.knowledge/designs/error-handling.md`): ErrorObj/Error/ErrorBuilder hierarchy, TLS propagation, `TVM_FFI_THROW` macro, Python traceback reconstruction.
- **C ABI error surface** (`.knowledge/designs/c-abi.md`): `TVMFFIErrorCell`, `TVMFFIErrorCreate`, `TVMFFITraceback` (now `TVMFFIBacktrace`), `TVMFFIErrorSetRaised`.
- **Python binding layer** (`.knowledge/designs/0014-python-bindings.md`): Cython Error class, `set_last_ffi_error`, `CHECK_CALL`.
- **Log-and-abort error boundary** (`TVM_FFI_LOG_EXCEPTION_CALL_BEGIN/END`): Still used by `TVMFFIErrorCreate` for the outer wrapper (but now the inner logic uses `try/catch` for `bad_alloc`).

Design elements this commit produces:
- **`TVMFFIBacktraceUpdateMode` enum**: New C ABI enum enabling append-friendly backtrace updates during error propagation. Constants: `kTVMFFIBacktraceUpdateModeReplace = 0`, `kTVMFFIBacktraceUpdateModeAppend = 1`.
- **Append-friendly backtrace storage convention**: Backtrace stored in most-recent-call-first order. This enables `O(1)` append as errors propagate up the stack. Display uses `TracebackMostRecentCallLast()` to reverse.
- **`Error::TracebackMostRecentCallLast()`**: New C++ method that reverses backtrace lines for Python-style display. Used by `Error::what()`.
- **Safe `TVMFFIErrorCreate` pattern**: Returns `int` (0 success, nonzero failure) with out-parameter. Catches `std::bad_alloc` instead of aborting, since error creation is on the error handling path and cannot safely use TLS error propagation.

## Usage Examples

**C++ -- Catching an error and displaying the traceback in Python order:**
```cpp
try {
    TVM_FFI_THROW(TypeError) << "example error";
} catch (const ffi::Error& e) {
    std::cout << e.kind() << std::endl;            // "TypeError"
    std::cout << e.backtrace() << std::endl;        // most-recent-call-first order
    std::cout << e.TracebackMostRecentCallLast();   // most-recent-call-last (Python style)
}
```

**C -- Creating an error with the new safe pattern:**
```c
TVMFFIObjectHandle error_obj;
int ret = TVMFFIErrorCreate(&kind, &message, &backtrace, &error_obj);
if (ret != 0) {
    // MemoryError -- cannot create error object
    // log and report MemoryError directly
}
```

**C++ -- Updating backtrace with append mode:**
```cpp
Error error("RuntimeError", "msg", "frame1\n");
TVMFFIByteArray extra = {"frame2\n", 7};
error.UpdateBacktrace(&extra, kTVMFFIBacktraceUpdateModeAppend);
// error.backtrace() == "frame1\nframe2\n"
```

**C++ -- TracebackMostRecentCallLast reversal:**
```cpp
Error error("TypeError", "here", "test0\ntest1\ntest2\n");
EXPECT_EQ(error.TracebackMostRecentCallLast(), "test2\ntest1\ntest0\n");
```
