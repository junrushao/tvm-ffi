# Rename traceback->backtrace, reverse storage order to most-recent-first, add append mode

## TL;DR
- Renames the "traceback" terminology to "backtrace" across the entire codebase (C ABI, C++ headers, Python/Cython bindings, docs, tests). The internal storage format is now **most-recent-call-first**, which enables efficient appending during error propagation. A new `TracebackMostRecentCallLast()` method reverses lines for Python-style display.
- Introduces `TVMFFIBacktraceUpdateMode` enum (`kTVMFFIBacktraceUpdateModeReplace=0`, `kTVMFFIBacktraceUpdateModeAppend=1`) and extends `update_backtrace` callback with an `update_mode` parameter.
- Changes `TVMFFIErrorCreate` from returning `TVMFFIObjectHandle` directly to returning `int` (0=success, nonzero=failure) with an output parameter, adding `MemoryError` safety.

## Key Exports

**Enum (new)**:
```c
enum TVMFFIBacktraceUpdateMode : int32_t {
  kTVMFFIBacktraceUpdateModeReplace = 0,
  kTVMFFIBacktraceUpdateModeAppend = 1,
};
```

**Struct field changes** (`TVMFFIErrorCell`):
```c
typedef struct {
  TVMFFIByteArray kind;
  TVMFFIByteArray message;
  TVMFFIByteArray backtrace;  // was: traceback; now stores most-recent-call-first
  void (*update_backtrace)(TVMFFIObjectHandle self, const TVMFFIByteArray* backtrace,
                           int32_t update_mode);  // was: update_traceback (2 params)
} TVMFFIErrorCell;
```

**C ABI function signature changes**:
```c
// Old: TVMFFIObjectHandle TVMFFIErrorCreate(kind, message, traceback);
// New:
int TVMFFIErrorCreate(const TVMFFIByteArray* kind, const TVMFFIByteArray* message,
                      const TVMFFIByteArray* backtrace, TVMFFIObjectHandle* out);

// Old: const TVMFFIByteArray* TVMFFITraceback(...);
// New:
const TVMFFIByteArray* TVMFFIBacktrace(const char* filename, int lineno,
                                       const char* func, int cross_ffi_boundary);
```

**C++ method (new)**:
```cpp
// Error class -- reverses backtrace lines for Python-style display
std::string Error::TracebackMostRecentCallLast() const;

// Error class -- gains update_mode parameter
void Error::UpdateBacktrace(const TVMFFIByteArray* backtrace_str, int32_t update_mode);
```

**Python functions (renamed)**:
- `_parse_backtrace(backtrace: str) -> list[tuple[str, int, str]]`
- `_with_append_backtrace(py_error: BaseException, backtrace: str) -> BaseException`
- `_traceback_to_backtrace_str(tb: TracebackType | None) -> str` -- now reverses line order before returning

## Impact
- API: **Breaking ABI change** across all layers. `TVMFFITraceback` renamed to `TVMFFIBacktrace`. `TVMFFIErrorCreate` signature changed (return type `int`, added `out` parameter). `TVMFFIErrorCell` field and callback renamed and extended. All language bindings (Python/Cython) updated in this commit. Rust bindings not updated in this commit.
- Behavioral: Backtrace strings are now stored in **most-recent-call-first** order (reversed from previous convention). The `_traceback_to_backtrace_str` Python function now reverses the line order before storage. `_with_append_backtrace` no longer calls `reversed()` on the parsed frames. The `what()` method now calls `TracebackMostRecentCallLast()` to reverse for display. The concatenation order in `set_last_ffi_error` changed from `c_traceback + py_traceback` to `py_backtrace + c_backtrace` (Python frames first, then C++ frames -- both stored most-recent-first). Test assertion order for nested traceback positions changed from `pos_cxx_raise > pos_lambda > pos_cxx_apply` to `pos_cxx_raise < pos_lambda < pos_cxx_apply` confirming the reversal.
- Flags/config: none
- Data formats/schemas: Version bumped from `0.1.0b4` to `0.1.0b5` in `pyproject.toml`.

Design elements this commit produces:
- **`TVMFFIBacktraceUpdateMode` enum** -- new C ABI enum controlling whether `update_backtrace` replaces or appends the backtrace content
- **Most-recent-call-first storage convention** -- new invariant: backtrace strings are stored with the most recent call at the beginning, enabling efficient append-based construction during error propagation
- **`Error::TracebackMostRecentCallLast()`** -- new C++ method that reverses backtrace line order for Python-style display (called by `what()`)
- **`TVMFFIErrorCreate` error-safe signature** -- now returns `int` with `std::bad_alloc` catch, instead of directly returning handle (which could not signal allocation failure)

## Usage Examples

**C++ -- accessing backtrace and display:**
```cpp
try {
  TVM_FFI_THROW(TypeError) << "test0";
} catch (const ffi::Error& e) {
  // Raw backtrace (most-recent-call-first)
  std::string bt = e.backtrace();
  // Python-style display (most-recent-call-last)
  std::cout << e.TracebackMostRecentCallLast() << std::endl;
}
```

**TracebackMostRecentCallLast reversal:**
```cpp
Error error("TypeError", "here", "test0\ntest1\ntest2\n");
// Returns: "test2\ntest1\ntest0\n"
error.TracebackMostRecentCallLast();
```

**Python -- backtrace concatenation during error propagation:**
```python
# In set_last_ffi_error (Cython):
# py_backtrace is reversed Python frames, c_backtrace is reversed C++ frames
# Concatenation: py_backtrace + c_backtrace (both most-recent-first)
ffi_error.update_backtrace(py_backtrace + c_backtrace)
```
