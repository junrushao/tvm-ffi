# Rename traceback to backtrace with append-friendly storage order and TVMFFIErrorCreate ABI fix
## TL;DR
- Renames all `traceback` identifiers to `backtrace` across C ABI, C++, Python/Cython, and tests. File renames: `traceback.cc` -> `backtrace.cc`, `traceback.h` -> `backtrace_utils.h`, `traceback_win.cc` -> `backtrace_win.cc`.
- Reverses the default backtrace storage order to "most recent call first" (enabling efficient append during error propagation). `TracebackMostRecentCallLast()` reverses lines for Python-style display.
- Changes `TVMFFIErrorCreate` from returning `TVMFFIObjectHandle` directly to returning `int` (0/nonzero) with an output parameter, handling `std::bad_alloc` gracefully. Adds `TVMFFIBacktraceUpdateMode` enum with `Replace`/`Append` modes. Bumps version to `0.1.0b5`.

## Impact
- API: **ABI-breaking**. `TVMFFITraceback` renamed to `TVMFFIBacktrace`. `TVMFFIErrorCreate` signature changed from returning `TVMFFIObjectHandle` to returning `int` with output parameter. `TVMFFIErrorCell.traceback` -> `.backtrace`, `update_traceback` -> `update_backtrace` with added `update_mode` parameter. Python `Error.traceback` property -> `Error.backtrace`. All downstream callers (Cython, Python) updated in this commit. Rust bindings not changed in this commit.
- Behavioral: Backtrace lines stored in reversed order (most recent call first). `Error.what()` now calls `TracebackMostRecentCallLast()` to reverse for display. Python `_traceback_to_backtrace_str` now reverses lines before storing. Python test assertions for ordering (`pos_cxx_raise < pos_lambda < pos_cxx_apply`) are reversed from previous (`>` to `<`).
- Flags/config: none
- Data formats/schemas: Version bumped from `0.1.0b4` to `0.1.0b5` in `pyproject.toml`.

## Design Elements
Design elements this commit consumes:
- Error propagation protocol (0004): ErrorObj/Error/ErrorBuilder pattern, TLS error propagation, `TVM_FFI_THROW` macro
- C ABI (0007): `TVMFFIErrorCell`, `TVMFFIErrorCreate`, `TVMFFITraceback`, safe-call boundary macros
- Python bindings (0012): Cython `Error` class, Python traceback synthesis (`TracebackManager`)

Design elements this commit produces:
- `TVMFFIBacktraceUpdateMode` enum (C ABI): new enum enabling replace vs. append semantics for backtrace updates
- `Error::TracebackMostRecentCallLast()` (C++): new method to reverse backtrace lines for Python-style display
- Backtrace storage convention: "most recent call first" invariant across all layers

## Usage Examples

C++ creating and displaying error with reversed backtrace:
```cpp
// Creating an error -- backtrace stored most-recent-call-first
Error error("TypeError", "here", "test0\ntest1\ntest2\n");
// Accessing raw backtrace (most recent call first)
assert(error.backtrace() == "test0\ntest1\ntest2\n");
// Getting Python-style display order (most recent call last)
assert(error.TracebackMostRecentCallLast() == "test2\ntest1\ntest0\n");
```

Python error with backtrace:
```python
ffi_error = tvm_ffi.core.Error("ValueError", "bad value", "frame0\nframe1\n")
# Property renamed from .traceback to .backtrace
assert ffi_error.backtrace.find("frame0") != -1
# update_backtrace replaces the backtrace
ffi_error.update_backtrace("new_frame\n")
```
