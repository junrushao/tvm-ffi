# Rename traceback to backtrace, reverse storage order for append-friendly error propagation, and harden TVMFFIErrorCreate
## TL;DR
- Renamed all `traceback` identifiers to `backtrace` across the C ABI, C++ API, Python bindings, and file names (`traceback.cc` -> `backtrace.cc`, `traceback.h` -> `backtrace_utils.h`).
- Changed backtrace storage order to **most-recent-call-first** (top-of-stack first) so appending frames during error propagation is O(1). Added `Error::TracebackMostRecentCallLast()` to reverse for Python-style display.
- Changed `TVMFFIErrorCreate` from returning `TVMFFIObjectHandle` to returning `int` with an out-parameter, catching `std::bad_alloc` to avoid recursive error creation. Added `TVMFFIBacktraceUpdateMode` enum for replace/append semantics. Version bump to `0.1.0b5`.

## Impact
- API: **ABI-breaking**. `TVMFFITraceback` renamed to `TVMFFIBacktrace`. `TVMFFIErrorCreate` signature changed (added out-param, changed return type). `TVMFFIErrorCell` field renamed (`traceback` -> `backtrace`), `update_backtrace` callback gains `update_mode` parameter. Python `Error.traceback` property renamed to `Error.backtrace`, `Error.update_traceback()` renamed to `Error.update_backtrace()`.
- Behavioral: Backtrace strings are now stored in reverse order (most-recent-call-first). `Error::what()` now calls `TracebackMostRecentCallLast()` to reverse for display, so user-visible output is unchanged. Python `_traceback_to_backtrace_str()` now reverses lines before returning. Backtrace concatenation in `set_last_ffi_error` changed order: `py_backtrace + c_backtrace` (was `c_traceback + py_traceback`).
- Flags/config: none
- Data formats/schemas: In-memory backtrace storage convention changed from most-recent-call-last to most-recent-call-first.

## Design Elements
Design elements this commit consumes:
- [0005-ffi-error-protocol](../../.knowledge/design-records/0005-ffi-error-protocol.md) — ErrorObj/Error class hierarchy, TLS error propagation, TVM_FFI_THROW macro
- [0001-ffi-c-abi](../../.knowledge/design-records/0001-ffi-c-abi.md) — TVMFFIErrorCell C struct layout, TVMFFIByteArray
- [0012-ffi-python-package](../../.knowledge/design-records/0012-ffi-python-package.md) — Python Error class, Cython bindings

Design elements this commit produces/mutates:
- **TVMFFIBacktraceUpdateMode** (new enum) — Controls replace vs append semantics for backtrace updates. Enables incremental backtrace construction during error propagation.
- **Backtrace storage order convention** (mutated) — Changed from most-recent-call-last to most-recent-call-first. This is the central design change: appending frames during error unwinding is now O(1) string append rather than requiring prepend or rebuild.
- **TVMFFIErrorCreate safety contract** (mutated) — Now returns error code instead of object handle, catching `std::bad_alloc` to avoid recursive error creation during OOM.
- **Error::TracebackMostRecentCallLast()** (new method) — Reverses backtrace lines for Python-style display. Decouples storage order from display order.

## Usage Examples

**C++ — Creating and inspecting errors with the new backtrace API:**
```cpp
// TracebackMostRecentCallLast reverses the stored order for display
Error error("TypeError", "here", "test0\ntest1\ntest2\n");
assert(error.TracebackMostRecentCallLast() == "test2\ntest1\ntest0\n");

// UpdateBacktrace with append mode (used during error propagation up the stack)
TVMFFIByteArray extra = {"extra_frame\n", 12};
error.UpdateBacktrace(&extra, kTVMFFIBacktraceUpdateModeAppend);
// backtrace is now: "test0\ntest1\ntest2\nextra_frame\n"
```

**Python — Error construction now handles allocation failure:**
```python
# Python side: Error.__init__ now checks return code
error = Error("ValueError", "msg", "backtrace_str")
# If allocation fails, raises MemoryError instead of returning corrupt handle

# Backtrace property renamed
assert error.backtrace.find("TestRaiseError") != -1  # was: error.traceback
```

**Python — Backtrace ordering in cross-language propagation:**
```python
# In set_last_ffi_error (error.pxi):
# Python traceback is reversed to most-recent-first before concatenation
py_backtrace = _TRACEBACK_TO_BACKTRACE_STR(error.__traceback__)  # reversed
c_backtrace = TVMFFIBacktrace(NULL, 0, NULL, 0)  # already most-recent-first
# Concatenated: py frames (recent first) + c frames (recent first)
ffi_error = Error(kind, message, py_backtrace + c_backtrace)
```
