# Extract torch C DLPack addon build into standalone script with AOT/JIT caching
## TL;DR
- Extracts the inline C++ source for `TorchDLPackExchangeAPI` from `_optional_torch_c_dlpack.py` into a new standalone build script `python/tvm_ffi/utils/_build_optional_c_dlpack.py` (780 lines), which can be used both as an AOT CLI tool and as a JIT builder invoked via subprocess.
- Replaces the `torch.utils.cpp_extension.load_inline` JIT workflow with a subprocess-based build that caches the resulting `.so`/`.dll` in `$TVM_FFI_CACHE_DIR/torch_c_dlpack_addon/` (default `~/.cache/tvm-ffi/`), loaded via `ctypes.CDLL` at import time.
- Adds `TVM_FFI_DISABLE_TORCH_C_DLPACK` env var to skip the torch DLPack addon loading at import time (used by the build script itself to avoid circular imports).
- Renames `_build_ninja` to `build_ninja` in `load_inline.py` to make it reusable by the new build script.

## Key Exports
**Functions (Python)**:
- `build_ninja(build_dir: str) -> None` -- renamed from `_build_ninja` in `python/tvm_ffi/cpp/load_inline.py`; now public for reuse.

**Scripts**:
- `python/tvm_ffi/utils/_build_optional_c_dlpack.py` -- standalone build script; CLI: `python _build_optional_c_dlpack.py --build_dir <dir> [--build_with_cuda]`.

**Environment variables**:
- `TVM_FFI_CACHE_DIR` -- override default cache directory (`~/.cache/tvm-ffi/`) for JIT-built shared libraries.
- `TVM_FFI_DISABLE_TORCH_C_DLPACK` -- set to `"1"` to skip torch C DLPack addon loading on import.

## Impact
- API: `_build_ninja` renamed to `build_ninja` in `load_inline.py` (was private, now public).
- Behavioral: torch DLPack addon is now loaded via `ctypes.CDLL` from a cached `.so`/`.dll` instead of via `torch.utils.cpp_extension.load_inline`. The build is done in a subprocess, making it safe for the build script to import `torch` without triggering recursive addon loading.
- Flags/config: new env vars `TVM_FFI_CACHE_DIR` and `TVM_FFI_DISABLE_TORCH_C_DLPACK`. `setuptools` added to test dependencies in `pyproject.toml`.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **DLPackExchangeAPI struct** ([ADR 0021](../ADRs/0021-dlpack-exchange-api-struct.md)) -- the C++ `TorchDLPackExchangeAPI` singleton implementing the DLPack exchange protocol for PyTorch tensors.
- **`load_inline` / `build_ninja` build pipeline** ([0014-python-package.md](../designs/0014-python-package.md)) -- the ninja-based C++ inline compilation system, now reused by the standalone build script.
- **`torch.Tensor.__c_dlpack_exchange_api__`** attribute -- set by `load_torch_c_dlpack_extension` to point to the `TorchDLPackExchangeAPI` singleton.

Design elements this commit produces:
- **AOT/JIT torch addon build pattern** -- a two-mode build script that can be invoked as CLI (AOT for packaging) or as a subprocess from the loader (JIT with caching). Uses file-system locking for parallel-safe builds.
- **`TVM_FFI_CACHE_DIR` convention** -- a new cache directory convention for JIT-built artifacts under `~/.cache/tvm-ffi/`.
- **`TVM_FFI_DISABLE_TORCH_C_DLPACK` guard** -- env-var guard to prevent circular import during build.

## Usage Examples
**AOT build** (for packaging):
```bash
python python/tvm_ffi/utils/_build_optional_c_dlpack.py --build_dir ./build_torch_addon --build_with_cuda
```

**JIT (automatic, on first import)**:
```python
import tvm_ffi  # triggers load_torch_c_dlpack_extension()
# If no cached .so exists, spawns subprocess to build it
# Result cached in ~/.cache/tvm-ffi/torch_c_dlpack_addon/
```
