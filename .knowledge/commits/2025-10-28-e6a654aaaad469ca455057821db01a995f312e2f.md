# Replace inline JIT torch C DLPack build with standalone AOT/JIT build script
## TL;DR
- Extracts the ~570-line inline C++ source from `_optional_torch_c_dlpack.py` into a standalone build script `python/tvm_ffi/utils/_build_optional_c_dlpack.py` that compiles a shared library (`libtorch_c_dlpack_addon.so`/`.dll`) via Ninja, loadable via `ctypes.CDLL`.
- The old `torch.utils.cpp_extension.load_inline` JIT approach is replaced by a two-tier strategy: (1) AOT build via `python _build_optional_c_dlpack.py --build_dir <dir>` for packaging, (2) JIT build via subprocess at import time with caching under `~/.cache/tvm-ffi/torch_c_dlpack_addon/`.
- Makes `_build_ninja` public as `build_ninja` in `load_inline.py`, adds `TVM_FFI_DISABLE_TORCH_C_DLPACK` env var to skip addon loading, adds Windows CI support for Python tests via VsDevCmd.bat.

## Impact
- API: `_build_ninja` renamed to `build_ninja` (public). Internal callers updated. External callers of `_build_ninja` (unlikely) would break.
- Behavioral: torch C DLPack addon is now loaded via `ctypes.CDLL` instead of `torch.utils.cpp_extension.load_inline`. Module-level auto-load is now gated by `TVM_FFI_DISABLE_TORCH_C_DLPACK` env var. The `_mod` keep-alive global is removed; loading is now deferred and conditional.
- Flags/config: New `TVM_FFI_DISABLE_TORCH_C_DLPACK` env var (default "0") to skip torch addon loading. `TVM_FFI_CACHE_DIR` env var now used for addon cache location.
- Data formats/schemas: none

## Usage Examples

**AOT build** (for packaging or CI):
```bash
python python/tvm_ffi/utils/_build_optional_c_dlpack.py \
    --build_dir ./build_addon --build_with_cuda
# Result: ./build_addon/libtorch_c_dlpack_addon.so
```

**JIT build at import** (automatic, cached):
```python
import tvm_ffi  # internally calls load_torch_c_dlpack_extension()
# First import: spawns subprocess to build, caches to ~/.cache/tvm-ffi/torch_c_dlpack_addon/
# Subsequent imports: loads cached .so via ctypes.CDLL
import torch
assert hasattr(torch.Tensor, "__c_dlpack_exchange_api__")
```

**Disable addon loading** (e.g., for testing):
```python
import os
os.environ["TVM_FFI_DISABLE_TORCH_C_DLPACK"] = "1"
import tvm_ffi  # skips torch addon entirely
```
