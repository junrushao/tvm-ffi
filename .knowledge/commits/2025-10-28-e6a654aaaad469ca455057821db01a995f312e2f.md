# Add build script for optional PyTorch C DLPack extension
## TL;DR
- Introduces `python/tvm_ffi/utils/_build_optional_c_dlpack.py` (780 lines): a standalone build script that compiles a shared library patching older PyTorch versions to support DLPack protocol.
- Rewrites `python/tvm_ffi/_optional_torch_c_dlpack.py` from 573 to 34 lines, delegating to the new build utility (supports both AOT and JIT build modes).
- Adds CI test coverage (`test_optional_torch_c_dlpack.py`) and Windows MSVC helper (`locate_vsdevcmd_bat.py`).

## Impact
- API: New public utility `_build_optional_c_dlpack.py` usable standalone (`python -m`) or as JIT builder
- Flags/config: `--build_dir`, `--build_with_cuda` CLI flags for AOT mode
