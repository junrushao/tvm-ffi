# Add build script and JIT loader for PyTorch C DLPack extension
## TL;DR
- Adds `_build_optional_c_dlpack.py` utility for AOT and JIT compilation of a shared library that patches older PyTorch versions to support DLPack v1 protocol
- Replaces inline C++ source in `_optional_torch_c_dlpack.py` with subprocess-based build invocation, moving ~550 lines of C++ out of Python
- Adds CI test coverage and VS dev command locator for Windows builds

## Impact
- API: New utility module; no changes to existing public API
- Behavioral: DLPack patching now uses external build process instead of inline C++ compilation via load_inline
