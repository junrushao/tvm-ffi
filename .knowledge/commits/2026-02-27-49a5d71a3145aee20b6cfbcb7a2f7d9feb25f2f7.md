# Enforce __slots__=() for Object subclasses via _ObjectSlotsMeta; split CObject/Object

## TL;DR
- Splits Cython `Object` into `CObject` (Cython extension type owning the low-level handle) and `Object` (Python class with `_ObjectSlotsMeta` metaclass that auto-injects `__slots__=()`).
- All `Object` subclasses now enforce `__slots__=()` by default; setting arbitrary instance attributes raises `AttributeError`. Classes needing `__dict__` must explicitly declare `__slots__ = ("__dict__",)`.
- `_ObjectSlotsMeta` extends `ABCMeta`, enabling `Object` subclasses to register as ABCs (e.g., `Sequence`, `MutableMapping`).
- Replaces module-global `_REPR_PRINT` cache with local import in `object_repr()`.

## Key Exports

**`CObject`** (Cython `cdef class`, `object.pxi`):
```python
cdef class CObject:
    """Cython base class owning the low-level FFI handle."""
    __slots__ = ()
    cdef void* chandle
    # Methods: __repr__, __eq__, __ne__, __hash__, same_as,
    #          __move_handle_from__, __init_handle_by_constructor__
```

**`Object`** (Python class, `object.pxi`):
```python
class Object(CObject, metaclass=_ObjectSlotsMeta):
    """Python base class for TVM FFI objects. Enforces __slots__=()."""
    __slots__ = ()
    # Delegates __init_handle_by_constructor__ to CObject
```

**`_ObjectSlotsMeta`** (metaclass, `object.pxi`):
```python
class _ObjectSlotsMeta(ABCMeta):
    def __new__(mcls, name, bases, ns, **kwargs):
        if "__slots__" not in ns:
            ns["__slots__"] = ()
        return super().__new__(mcls, name, bases, ns, **kwargs)
```

**`object_repr(obj: CObject) -> str`** -- replaces `__object_repr__`, uses local import of `ReprPrint`.

## Impact
- API: Breaking. All `Object` subclasses enforce `__slots__=()` by default. Code setting arbitrary instance attributes will raise `AttributeError`.
- API: `_ObjectSlotsMeta` no longer accepts `slots` keyword argument.
- Behavioral: `Module.__getattr__` stores looked-up functions via `setattr` into `__dict__` (requires `__slots__ = ("__dict__",)` on Module).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Object system (Python side) -- [design 0014](../designs/0014-python-package.md)
- `ABCMeta` for container ABC registration

Design elements this commit produces:
- **CObject/Object split** -- separates Cython handle ownership (`CObject`) from Python-level policy enforcement (`Object` + `_ObjectSlotsMeta`). All Python subclasses go through `_ObjectSlotsMeta`.
- **Auto-slots metaclass** -- `_ObjectSlotsMeta` auto-injects `__slots__=()` if not declared, preventing accidental `__dict__` creation on Object subclasses.

## Usage Examples
```python
# Default: no __dict__ allowed
@register_object("my.Type")
class MyType(Object):
    pass  # __slots__=() auto-injected

obj = MyType()
obj.foo = 1  # AttributeError!

# Opt-in to __dict__:
@register_object("my.CachedType")
class CachedType(Object):
    __slots__ = ("__dict__",)

obj = CachedType()
obj.foo = 1  # OK
```
