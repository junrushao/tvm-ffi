# Enforce __slots__=() for Object subclasses via _ObjectSlotsMeta
## TL;DR
- Introduces `_ObjectSlotsMeta` metaclass that enforces `__slots__ = ()` on all `Object` subclasses
- Prevents accidental instance dict creation on FFI object wrappers (memory optimization)
- Breaking change: Python Object subclasses can no longer have arbitrary instance attributes
- 260 insertions, 177 deletions across 15 files

## Key Exports
```python
class _ObjectSlotsMeta(type):
    """Metaclass enforcing __slots__=() on Object subclasses."""
    # Automatically injects __slots__ = () if not defined
    # Raises TypeError if subclass tries to define non-empty __slots__
    # Interacts with: Object base class, @register_object, @c_class
    # Invariant: all Object subclasses are slot-based (no __dict__)

class Object(metaclass=_ObjectSlotsMeta):
    __slots__ = ()
    # All subclasses inherit empty slots
```

## Impact
- API: breaking — Object subclasses can no longer have `__dict__`
- Behavioral: memory optimization for FFI object wrappers
- Flags/config: none
- Data formats/schemas: none
