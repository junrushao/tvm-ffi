# Enforce __slots__=() on Object hierarchy via _ObjectSlotsMeta; split CObject/Object

## TL;DR
- Renames Cython `Object` extension type to `CObject` and introduces pure-Python `Object(CObject, metaclass=_ObjectSlotsMeta)` that auto-injects `__slots__ = ()` into all subclasses.
- `kDLMAIA = 17` added to `DLDeviceType`; `kDLTrn` renumbered from 17 → 18 (ABI break for serialized device type values).
- `Module.__getattr__` simplified: functions cached via `setattr` into `__dict__` (declared via `__slots__ = ("__dict__",)`).

## Key Exports

```python
# python/tvm_ffi/cython/object.pxi

cdef class CObject:
    """Cython extension type; owns the C handle. Low-level only."""
    cdef void* chandle
    # Invariant: chandle == NULL means uninitialized / null handle

class _ObjectSlotsMeta(ABCMeta):
    """Metaclass that auto-injects __slots__=() into every Object subclass.
    # Invariant: __slots__ always present in namespace (injected if missing)
    # Extension: subclasses needing __dict__ declare __slots__ = ("__dict__",) explicitly
    """
    def __new__(mcls, name, bases, ns, **kwargs): ...

class Object(CObject, metaclass=_ObjectSlotsMeta):
    """Python base for all TVM FFI objects; enforces slots policy.
    # Interacts with: CObject (handle), _ObjectSlotsMeta (slots enforcement)
    """
    __slots__ = ()
```

## Impact
- API: **Breaking**. `Object` subclasses that set arbitrary instance attributes will raise `AttributeError`; must declare explicit `__slots__`. `_ObjectSlotsMeta` no longer accepts `slots` keyword argument. `kDLTrn` renumbered 17→18; `kDLMAIA=17` added (affects serialized device type values).
- Behavioral: `Module.__getattr__` now caches via `setattr`/`__dict__` rather than a private cache dict.
- Flags/config: none
- Data formats/schemas: `kDLTrn` renumbering affects any serialized/persisted `DLDeviceType` integer values.

## Usage Examples

```python
# Before: arbitrary instance attrs were allowed on Object subclasses
class MyObj(Object): pass
obj = MyObj()
obj.x = 1  # worked silently

# After: AttributeError unless __slots__ declared
class MyObj(Object): pass
obj = MyObj()
obj.x = 1  # AttributeError!

# Fix: declare __slots__ if instance attrs needed
class MyObj(Object):
    __slots__ = ("x",)
```
