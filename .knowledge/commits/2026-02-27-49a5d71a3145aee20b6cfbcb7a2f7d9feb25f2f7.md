# Enforce __slots__=() for Object subclasses via _ObjectSlotsMeta
## TL;DR
- Introduces `_ObjectSlotsMeta` metaclass that enforces `__slots__ = ()` on all `Object` subclasses, preventing accidental Python-side instance attributes that would shadow FFI field access.
- Removes `__slots__` boilerplate from container classes and other Object subclasses.
- Refactors Cython `object.pxi` to use the new metaclass, updating all Object subclass definitions.

## Key Exports

```python
class _ObjectSlotsMeta(ABCMeta):
    """Metaclass enforcing __slots__=() on Object subclasses."""
    # Invariant: every Object subclass has __slots__ = ()
    # Interacts with: CObject (Cython base), ABCMeta
    # Extension: override __new__ to inject __slots__ automatically

class Object(CObject, metaclass=_ObjectSlotsMeta):
    """Base class with enforced slots."""
    __slots__ = ()
```

## Impact
- API: All `Object` subclasses now implicitly have `__slots__ = ()`. Subclasses that defined `__dict__` will break.
- Behavioral: Prevents accidental attribute creation on FFI objects.
- Flags/config: None
- Data formats/schemas: None
