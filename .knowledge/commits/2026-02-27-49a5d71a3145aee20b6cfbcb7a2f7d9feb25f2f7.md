# Split Cython Object into CObject+Object with _ObjectSlotsMeta to enforce __slots__=() across the hierarchy

## TL;DR
- Cython `Object` extension type is renamed to `CObject`; a new Python-level `Object(CObject, metaclass=_ObjectSlotsMeta)` class enforces `__slots__=()` on every subclass unless the subclass explicitly opts into `__slots__ = ("__dict__",)`.
- `_ObjectSlotsMeta` (subclass of `ABCMeta`) injects `__slots__ = ()` at class creation time and overrides `isinstance`/`issubclass` checks to treat `CObject` instances as `Object` instances, preserving backward compatibility for `isinstance(x, Object)` calls.
- `DLDeviceType.kDLMAIA = 17` is added and `kDLTrn` is renumbered from 17 to 18; `Module.__getattr__` is simplified to use `setattr` via the explicit `__slots__ = ("__dict__",)` on `Module`; `_deepcopy_supported` drops `lru_cache` and calls `_ffi_api.DeepCopy` directly.

## Key Exports

```python
# python/tvm_ffi/cython/object.pxi

cdef class CObject:
    """Cython extension type; owns the void* chandle handle.
    Prefer subclassing Object in Python code.
    # Invariant: chandle == NULL only during __cinit__ or after _move()
    # Interacts with: Function, Tensor, Error, OpaquePyObject (all direct CObject subclasses at Cython level)
    # Extension: subclass in Cython (.pxi) when low-level handle access is required
    """
    cdef void* chandle

    def same_as(self, other: object) -> bool: ...          # pointer identity
    def __move_handle_from__(self, other: CObject) -> None: ...
    def __init_handle_by_constructor__(self, fconstructor: Any, *args: Any) -> None: ...
    def __hash__(self) -> int: ...                         # cast chandle to uint64
    def __repr__(self) -> str: ...                         # delegates to object_repr(self)


class _ObjectSlotsMeta(ABCMeta):
    """Metaclass that auto-injects __slots__=() into every Object subclass.
    # Invariant: if __slots__ absent from class dict, sets it to () before class creation
    # Invariant: __instancecheck__ returns True for any CObject instance (backward compat)
    # Invariant: __subclasscheck__ returns True for any CObject subclass (backward compat)
    # Interacts with: ABCMeta, CObject, Object, register_object
    # Extension: subclasses needing __dict__ declare __slots__ = ("__dict__",) explicitly
    """
    def __new__(mcls, name, bases, ns, **kwargs): ...
    def __instancecheck__(cls, instance: Any) -> bool: ...
    def __subclasscheck__(cls, subclass: type) -> bool: ...


class Object(CObject, metaclass=_ObjectSlotsMeta):
    """Public Python base for all TVM FFI objects.
    # Invariant: __slots__ == () unless a subclass explicitly declares otherwise
    # Interacts with: register_object (wires __init__ from __ffi_init__)
    # Interacts with: _ObjectSlotsMeta (auto-enforces slots on subclasses)
    # Extension: subclass Object + @register_object("type.Key") for custom FFI types
    """
    __slots__ = ()

    def __ffi_init__(self, *args: Any) -> None: ...        # delegated to C++ constructor
    def _move(self) -> ObjectRValueRef: ...
    def __init_handle_by_constructor__(self, fconstructor, *args) -> None: ...
    def __move_handle_from__(self, other: CObject) -> None: ...
    def same_as(self, other: object) -> bool: ...


def object_repr(obj: CObject) -> str:
    """Call ffi.ReprPrint(obj); fallback to TypeName(handle) on error.
    # Old name: __object_repr__  (module-global with _REPR_PRINT cache)
    # New: local import of _ffi_api.ReprPrint per call; no module-level cache
    # Interacts with: ffi.ReprPrint (C++ global), CObject.chandle
    # Invariant: never raises — repr must always succeed
    """


# Cython direct CObject subclasses (all now inherit CObject, not Object):
cdef class Function(CObject): ...
cdef class Tensor(CObject): ...
cdef class Error(CObject): ...
cdef class OpaquePyObject(CObject): ...

# Device enum addition (device.pxi)
class DLDeviceType(IntEnum):
    kDLMAIA = 17    # NEW — Microsoft MAIA (renumbers kDLTrn from 17 → 18)
    kDLTrn = 18     # Was 17 in prior commits

# Module (module.py) — opts into __dict__ for attribute caching
class Module(core.Object):
    __slots__ = ("__dict__",)  # NEW: explicit opt-in for getattr-based caching
    # __getattr__: now uses setattr(self, name, func) instead of self.__dict__[name]
```

## Impact
- API: **Breaking** — any `Object` subclass that previously relied on implicit `__dict__` (i.e., setting arbitrary instance attributes without declaring `__slots__`) will now raise `AttributeError`. Migration: add `__slots__ = ("__dict__",)` to the subclass.
- API: **Breaking** — `_ObjectSlotsMeta(name, bases, ns, slots=True)` keyword argument removed; the `slots` parameter no longer exists.
- API: **Breaking** — `DLDeviceType.kDLTrn` renumbered from 17 to 18; `kDLMAIA = 17` added. Any code serializing or comparing device type integer values for `kDLTrn` is broken.
- Behavioral: `isinstance(x, Object)` still returns `True` for `CObject` instances via `_ObjectSlotsMeta.__instancecheck__`. No functional change for existing callers using `isinstance`.
- Behavioral: `Array.__repr__`, `List.__repr__`, `Map.__repr__`, `Dict.__repr__` removed; repr now falls through to `CObject.__repr__` → `object_repr()` which calls `ffi.ReprPrint`. Output format may differ.
- Behavioral: `_deepcopy_supported` drops `lru_cache` on `_get_deep_copy_func`; now imports `_ffi_api.DeepCopy` per call. Functionally equivalent but avoids stale cache if registry changes.
- Behavioral: `AccessPath.__init__` no longer calls `super().__init__()` before raising (cleanup; no user-visible change).
- Flags/config: none
- Data formats/schemas: `DLDeviceType` integer mapping changed for `kDLTrn`; affects any serialized device specs.

## Usage Examples

Defining a custom registered Object subclass (slots enforced automatically):
```python
import tvm_ffi

@tvm_ffi.register_object("my.Foo")
class Foo(tvm_ffi.Object):
    # __slots__ = ()  ← injected automatically by _ObjectSlotsMeta
    pass

foo = tvm_ffi.testing.create_object("testing.TestObjectBase")
foo._bad_attr = "x"   # raises AttributeError — __dict__ not present
```

Opting into per-instance dict (e.g., for caching):
```python
@tvm_ffi.register_object("my.CachingObj")
class CachingObj(tvm_ffi.Object):
    __slots__ = ("__dict__",)  # explicit opt-in

obj = CachingObj(...)
obj._cached_val = 42   # allowed
```

Verifying backward-compatible isinstance:
```python
from tvm_ffi.core import CObject, Object

func = tvm_ffi.get_global_func("ffi.ReprPrint")
assert isinstance(func, CObject)   # True — Function inherits CObject
assert isinstance(func, Object)    # True — _ObjectSlotsMeta.__instancecheck__ covers CObject
```
