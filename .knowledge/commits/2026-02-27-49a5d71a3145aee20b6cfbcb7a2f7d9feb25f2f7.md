# Enforce __slots__=() for Object subclasses via _ObjectSlotsMeta
## TL;DR
- Introduces `_ObjectSlotsMeta` metaclass that enforces `__slots__ = ()` on all Python Object subclasses, preventing accidental instance dict creation.
- Major refactor of Cython object, function, and type info code to use slots consistently.
- Updates `registry.py` and `module.py` to comply with the slots enforcement.

## Impact
- API: Breaking change for Python Object subclasses that relied on instance dicts; all must now declare `__slots__`.
- Flags/config: None.
- Data formats/schemas: None.
