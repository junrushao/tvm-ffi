# Fix mypy type warnings on dataclasses.field() return type
## TL;DR
- Changes `field()` return type from `Field` to `_FieldValue` (TypeVar) with `cast()`, eliminating mypy "incompatible types in assignment" errors when using `field(default=...)` in `@c_class` declarations.
- Converts `Field` from a `@dataclass` to use `__slots__` for consistency.
