# Fix mypy type-checking warnings on `dataclasses.field(...)` in `c_class` definitions
## TL;DR
- The `field()` helper in `tvm_ffi.dataclasses` previously returned `Field` at the type level, causing mypy to flag assignments like `v_str: str = field(default_factory=...)` with "Incompatible types in assignment (expression has type 'Field', variable has type 'str')".
- Fixed by introducing a `TypeVar` (`_FieldValue`) and using `typing.cast` so `field()` returns `_FieldValue` to type checkers, matching the `dataclasses.field()` pattern.
- Added `typing-extensions` as a package dependency in `pyproject.toml`.

## Key Exports

```python
_FieldValue = TypeVar("_FieldValue")

def field(
    *,
    default: _FieldValue | _MISSING_TYPE = MISSING,
    default_factory: Callable[[], _FieldValue] | _MISSING_TYPE = MISSING,
) -> _FieldValue:
    """Declare a dataclass-style field on a c_class proxy.
    At runtime, returns a Field object. At type-checking level,
    returns _FieldValue (matching the annotated type)."""
    # Old signature: -> Field  (caused mypy incompatible-types warning)
    # New signature: -> _FieldValue  (via cast, matches dataclasses.field pattern)
    # Interacts with: c_class decorator (inspects returned Field at runtime)
    # Invariant: runtime return is still a Field; only the static type changes
    ...

class Field:
    """Descriptor placeholder for c_class fields."""
    __slots__ = ("default_factory", "name")

    def __init__(
        self,
        *,
        name: str | None = None,
        default_factory: Callable[[], _FieldValue] | _MISSING_TYPE = MISSING,
        # Old: default_factory: Callable[[], Any]  (no MISSING default)
    ) -> None: ...
    # Interacts with: c_class decorator, field() factory function
```

## Usage Examples
**Before** (mypy error):
```python
@c_class("testing.TestCxxClassDerivedDerived")
class _TestCxxClassDerivedDerived(_TestCxxClassDerived):
    v_str: str = field(default_factory=lambda: "default")  # type: ignore[assignment]
    #                                                        ^^^^^^^^^^^^^^^^^^^^^^^^
    # Required to suppress: "Incompatible types in assignment
    # (expression has type 'Field', variable has type 'str')"
```

**After** (clean):
```python
@c_class("testing.TestCxxClassDerivedDerived")
class _TestCxxClassDerivedDerived(_TestCxxClassDerived):
    v_str: str = field(default_factory=lambda: "default")  # No type: ignore needed
```
