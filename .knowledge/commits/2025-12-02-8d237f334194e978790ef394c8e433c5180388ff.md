# Downgrade JIT compilation log message from info to debug in torch-c-dlpack addon

## TL;DR
- Changes `logger.info(...)` to `logger.debug(...)` for the "JIT-compiling torch-c-dlpack-ext to cache..." message in `_optional_torch_c_dlpack.py`.
- Prevents this build-once log line from appearing every server startup after the cache is populated; the message is only printed when the library is actually absent and being built.
