# Downgrade JIT compilation log message from info to debug to reduce noise
## TL;DR
- Changes `logger.info(...)` to `logger.debug(...)` for the JIT-compiling torch-c-dlpack-ext message in `load_torch_c_dlpack_extension()`.
- Motivation: the info-level message was noisy during server startup.
