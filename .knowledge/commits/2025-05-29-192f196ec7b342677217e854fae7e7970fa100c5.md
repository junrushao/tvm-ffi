# Move PackedFunc macro/namespace aliases into tvm-ffi headers
## TL;DR
- Introduces `TVM_FFI_DLL_EXPORT` macro in `c_api.h` -- always-export counterpart to `TVM_FFI_DLL` (which is import on consumer side on MSVC).
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro in `function.h` -- exports a typed C++ function as an `extern "C"` symbol with the `TVMFFISafeCallType` signature, wrapped in `TVM_FFI_SAFE_CALL_BEGIN/END`.
- Adds `using tvm::ffi::Any; using tvm::ffi::AnyView;` in `any.h` to expose these types into the `tvm` namespace for convenience.

This is part of a migration from legacy `TVM_DLL_EXPORT_TYPED_FUNC` (defined in the downstream `packed_func.h`) to the self-contained `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro within `tvm-ffi`. The old macro name is kept downstream until bindings are updated.

## Key Exports

```python
# === c_api.h ===

# New macro: TVM_FFI_DLL_EXPORT
# Always marks a symbol as DLL export, unlike TVM_FFI_DLL which is
# dllimport when TVM_FFI_EXPORTS is not defined (consumer side on MSVC).
# Platform behavior:
#   Emscripten: EMSCRIPTEN_KEEPALIVE
#   MSVC:       __declspec(dllexport)  (always export, never import)
#   GCC/Clang:  __attribute__((visibility("default")))
# Interacts with: TVM_FFI_DLL_EXPORT_TYPED_FUNC (uses this for symbol visibility)
# Invariant: TVM_FFI_DLL_EXPORT is always dllexport; TVM_FFI_DLL may be dllimport

# === function.h ===

# Macro expansion (pseudocode for TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)):
# extern "C" {
#   TVM_FFI_DLL_EXPORT int ExportName(
#       void* self, TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
#   ) {
#       TVM_FFI_SAFE_CALL_BEGIN();
#       FuncInfo = FunctionInfo<decltype(Function)>
#       static name = "ExportName"
#       unpack_call<FuncInfo.RetType>(
#           index_sequence<FuncInfo.num_args>, &name, Function,
#           reinterpret_cast<AnyView*>(args), num_args,
#           reinterpret_cast<Any*>(result)
#       )
#       TVM_FFI_SAFE_CALL_END();
#   }
# }
# Interacts with: details::unpack_call, details::FunctionInfo, TVM_FFI_SAFE_CALL_BEGIN/END
# Interacts with: TVM_FFI_DLL_EXPORT (controls symbol visibility)
# Invariant: ExportName and Function must be different identifiers (name collision otherwise)
# Invariant: generated symbol has TVMFFISafeCallType signature
# Extension: downstream module authors use this to expose typed C++ functions as loadable symbols

# === any.h ===

# Namespace aliases added in tvm namespace (outside tvm::ffi):
#   using tvm::ffi::Any
#   using tvm::ffi::AnyView
# Interacts with: any downstream code that uses tvm::Any / tvm::AnyView directly
```

## Impact
- API: Additive only. New `TVM_FFI_DLL_EXPORT` macro and `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro. Namespace aliases for `Any`/`AnyView` into `tvm::`.
- Behavioral: None -- no existing function signatures or behaviors changed.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Safe-call boundary** (`TVM_FFI_SAFE_CALL_BEGIN/END`) -- the exported function wraps its body in the standard exception-catching boundary. See [0004-function-system.md](../designs/0004-function-system.md).
- **`details::unpack_call` / `details::FunctionInfo`** -- compile-time machinery that converts a typed callable into the packed AnyView args convention. See [0004-function-system.md](../designs/0004-function-system.md).
- **`TVM_FFI_DLL` visibility macro** -- the new `TVM_FFI_DLL_EXPORT` follows the same platform-conditional pattern. See [0001-c-abi.md](../designs/0001-c-abi.md).
- **`Any` / `AnyView`** types -- exposed into `tvm::` namespace for convenience. See [0003-any-system.md](../designs/0003-any-system.md).

Design elements this commit produces:
- **`TVM_FFI_DLL_EXPORT` macro** -- always-export visibility attribute, complementing the existing `TVM_FFI_DLL` which can be dllimport. This is a new C ABI-level primitive.
- **`TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro** -- the canonical way to export a typed C++ function as a `TVMFFISafeCallType`-compatible `extern "C"` symbol from a shared library. This is the tvm-ffi equivalent of the legacy `TVM_DLL_EXPORT_TYPED_FUNC`.
- **`tvm::Any` / `tvm::AnyView` namespace aliases** -- convenience aliases so downstream code can write `tvm::Any` instead of `tvm::ffi::Any`.

## Usage Examples

**Exporting a typed function from a shared library module:**

```cpp
#include <tvm/ffi/function.h>

int AddOne_(int x) {
    return x + 1;
}

// Generates: extern "C" TVM_FFI_DLL_EXPORT int AddOne(void*, TVMFFIAny*, int32_t, TVMFFIAny*)
TVM_FFI_DLL_EXPORT_TYPED_FUNC(AddOne, AddOne_);

// Also works with lambdas:
TVM_FFI_DLL_EXPORT_TYPED_FUNC(SubOne, [](int x) { return x - 1; });
```

The generated symbol can be loaded via `load_module("path.so")` and called through the standard `Function` interface. The symbol has `TVMFFISafeCallType` signature, so exceptions are caught at the boundary.
