# Cleanup PackedFunc redirections: add TVM_FFI_DLL_EXPORT_TYPED_FUNC macro and namespace aliases

## TL;DR
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro to `function.h`, enabling typed C++ functions to be exported as C-ABI-safe DLL symbols using the `safe_call` protocol.
- Introduces `TVM_FFI_DLL_EXPORT` macro in `c_api.h` as an always-export counterpart to the dual-mode `TVM_FFI_DLL` macro.
- Re-exports `tvm::ffi::Any` and `tvm::ffi::AnyView` into `namespace tvm` for ergonomic access.

## Key Exports

```python
# --- c_api.h: New visibility macro ---
# TVM_FFI_DLL_EXPORT: Always marks a function as a DLL export.
# Unlike TVM_FFI_DLL (which imports when TVM_FFI_EXPORTS is not defined),
# TVM_FFI_DLL_EXPORT always exports regardless of build context.
# Platform mapping:
#   Emscripten  -> EMSCRIPTEN_KEEPALIVE
#   MSVC        -> __declspec(dllexport)
#   GCC/Clang   -> __attribute__((visibility("default")))
# Interacts with: TVM_FFI_DLL_EXPORT_TYPED_FUNC (uses this for symbol export)

# --- function.h: New typed export macro ---
# TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)
#   Expands to:
#   extern "C" {
#     TVM_FFI_DLL_EXPORT int ExportName(
#         void* self, TVMFFIAny* args, int32_t num_args, TVMFFIAny* result) {
#       TVM_FFI_SAFE_CALL_BEGIN();
#       FunctionInfo<decltype(Function)> introspects Function's arg/return types
#       unpack_call<RetType>(index_seq, &name, Function, args, num_args, result)
#       TVM_FFI_SAFE_CALL_END();
#     }
#   }
# Interacts with: details::FunctionInfo, details::unpack_call, TVM_FFI_SAFE_CALL_BEGIN/END
# Invariant: ExportName and Function must be different identifiers
# Extension: use for any typed C++ function to be called from Python/Rust via DLL symbol

# --- any.h: Namespace aliases ---
# using tvm::ffi::Any;    -- now accessible as tvm::Any
# using tvm::ffi::AnyView; -- now accessible as tvm::AnyView
# Interacts with: all C++ code that references Any/AnyView
```

## Impact
- API: Additive only. `TVM_FFI_DLL_EXPORT_TYPED_FUNC` provides the FFI-namespaced replacement for the legacy `TVM_DLL_EXPORT_TYPED_FUNC` from the broader TVM codebase. The old macro is retained downstream for backward compatibility.
- Behavioral: None -- no existing behavior changed.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_SAFE_CALL_BEGIN` / `TVM_FFI_SAFE_CALL_END` macros (0004-error-propagation) -- used inside `TVM_FFI_DLL_EXPORT_TYPED_FUNC` to catch exceptions at the C ABI boundary.
- `details::FunctionInfo<T>` and `details::unpack_call<R>` (0003-function-system) -- used to introspect the typed function's signature and unpack AnyView args into typed C++ args.
- `TVM_FFI_DLL` visibility macro (0007-c-abi) -- pattern followed by the new `TVM_FFI_DLL_EXPORT`.

Design elements this commit produces:
- `TVM_FFI_DLL_EXPORT` macro (c_api.h) -- always-export visibility annotation, complements the dual-mode `TVM_FFI_DLL`.
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro (function.h) -- exports a typed C++ function as a C-linkage DLL symbol with safe_call wrapping.
- `tvm::Any` / `tvm::AnyView` using-declarations (any.h) -- convenience aliases from `tvm::ffi::Any` / `tvm::ffi::AnyView`.

## Usage Examples
From the macro's own Doxygen example in `function.h`:
```cpp
int AddOne_(int x) {
    return x + 1;
}

// Export as DLL symbol "AddOne" with safe_call wrapping
TVM_FFI_DLL_EXPORT_TYPED_FUNC(AddOne, AddOne_);

// Lambda export as DLL symbol "SubOne"
TVM_FFI_DLL_EXPORT_TYPED_FUNC(SubOne, [](int x) {
    return x - 1;
});

// Caller (e.g., Python via ctypes/Cython) invokes:
//   int AddOne(void* self, TVMFFIAny* args, int32_t num_args, TVMFFIAny* result)
```
