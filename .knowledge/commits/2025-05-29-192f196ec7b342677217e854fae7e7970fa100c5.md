# Introduce TVM_FFI_DLL_EXPORT and TVM_FFI_DLL_EXPORT_TYPED_FUNC; hoist Any/AnyView into tvm namespace

## TL;DR
- Adds `TVM_FFI_DLL_EXPORT` macro to `c_api.h` — an always-export visibility annotation (unlike `TVM_FFI_DLL`, which is dllimport on consumer side for MSVC).
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)` macro to `function.h` — wraps a typed C++ callable into a C-ABI `extern "C"` exported symbol matching `TVMFFISafeCallType` convention.
- Hoists `Any` and `AnyView` from `tvm::ffi` into the `tvm` namespace via `using` declarations in `any.h`.

## Key Exports

**Macros**:

- `TVM_FFI_DLL_EXPORT` (defined in `c_api.h`) — always marks a symbol as DLL-exported, regardless of whether `TVM_FFI_EXPORTS` is defined. On MSVC: `__declspec(dllexport)`. On Emscripten: `EMSCRIPTEN_KEEPALIVE`. On GCC/Clang: `__attribute__((visibility("default")))`. This differs from `TVM_FFI_DLL`, which resolves to `dllimport` on MSVC when `TVM_FFI_EXPORTS` is not defined.

- `TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)` (defined in `function.h`) — expands to:
  ```cpp
  extern "C" {
  TVM_FFI_DLL_EXPORT int ExportName(void* self, TVMFFIAny* args, int32_t num_args,
                                    TVMFFIAny* result) {
    TVM_FFI_SAFE_CALL_BEGIN();
    // ... unpack_call using FunctionInfo<decltype(Function)> ...
    TVM_FFI_SAFE_CALL_END();
  }
  }
  ```
  The exported function has `TVMFFISafeCallType`-compatible signature. Internally uses `details::FunctionInfo` to extract arity and return type, then `details::unpack_call` to convert from packed `AnyView[]` to typed arguments. This is the FFI-prefixed replacement for the legacy `TVM_DLL_EXPORT_TYPED_FUNC`.

**Namespace aliases** (in `any.h`):

- `tvm::Any` — alias for `tvm::ffi::Any`
- `tvm::AnyView` — alias for `tvm::ffi::AnyView`

## Impact
- API: New macro `TVM_FFI_DLL_EXPORT_TYPED_FUNC` is the canonical way to export typed functions from shared libraries. The old `TVM_DLL_EXPORT_TYPED_FUNC` (in downstream TVM, not in this repo) is scheduled for removal after downstream migration.
- Behavioral: None — all additions are new symbols; no existing behavior is changed.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **TVMFFISafeCallType calling convention** ([0001-c-abi-layer.md](../../.knowledge/designs/0001-c-abi-layer.md)) — the exported function's signature matches `int(void*, TVMFFIAny*, int32_t, TVMFFIAny*)`.
- **TVM_FFI_SAFE_CALL_BEGIN/END macros** ([0004-function-system.md](../../.knowledge/designs/0004-function-system.md)) — exception boundary used inside the exported function body.
- **details::unpack_call / FunctionInfo** ([0004-function-system.md](../../.knowledge/designs/0004-function-system.md)) — template machinery to convert packed AnyView args into typed C++ parameters.
- **TVM_FFI_DLL visibility macro** ([0001-c-abi-layer.md](../../.knowledge/designs/0001-c-abi-layer.md)) — existing platform-specific visibility annotation, extended by the new `TVM_FFI_DLL_EXPORT`.

Design elements this commit produces:
- **TVM_FFI_DLL_EXPORT macro** — a new visibility annotation for always-export semantics. Complements `TVM_FFI_DLL` (which is import-on-consumer for MSVC). This is a new design element in the C ABI layer.
- **TVM_FFI_DLL_EXPORT_TYPED_FUNC macro** — a new function export mechanism for shared libraries / module system. Bridges the gap between typed C++ functions and the C ABI `TVMFFISafeCallType` convention.
- **tvm::Any / tvm::AnyView namespace aliases** — convenience aliases that let code outside `tvm::ffi` use the shorter names without explicit `ffi::` qualification.

## Usage Examples

**Exporting a typed function from a shared library**:
```cpp
// my_module.cc — compiled into a .so/.dll

int AddOne_(int x) {
  return x + 1;
}

// Creates extern "C" symbol "AddOne" with TVMFFISafeCallType signature
TVM_FFI_DLL_EXPORT_TYPED_FUNC(AddOne, AddOne_);

// Lambda variant
TVM_FFI_DLL_EXPORT_TYPED_FUNC(SubOne, [](int x) {
  return x - 1;
});

// The exported symbol can be loaded via tvm::ffi::Module::LoadFromFile("my_module.so")
// and called as: mod->GetFunction("AddOne")(42)  // returns 43
```

**Using tvm::Any directly (after namespace hoist)**:
```cpp
#include <tvm/ffi/any.h>

tvm::Any val = 42;        // Previously required tvm::ffi::Any
tvm::AnyView view = val;  // Previously required tvm::ffi::AnyView
```
