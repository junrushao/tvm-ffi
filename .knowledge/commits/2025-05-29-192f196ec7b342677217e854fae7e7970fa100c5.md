# Add TVM_FFI_DLL_EXPORT_TYPED_FUNC macro and tvm-namespace Any/AnyView aliases as part of PackedFunc redirection cleanup

## TL;DR

- Introduces `TVM_FFI_DLL_EXPORT` macro in `c_api.h` — an always-export variant distinct from `TVM_FFI_DLL` (which is import/export conditional on `TVM_FFI_EXPORTS`).
- Introduces `TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)` macro in `function.h` — exports a typed C++ callable as a C ABI-compatible `safe_call` symbol, replacing the legacy `TVM_DLL_EXPORT_TYPED_FUNC` name.
- Adds `using tvm::ffi::Any` and `using tvm::ffi::AnyView` aliases in the `tvm` namespace (in `any.h`), reducing boilerplate for callers in the root namespace.

## Key Exports

```python
# c_api.h additions

# TVM_FFI_DLL_EXPORT: always marks the symbol as a DLL export (no import path).
# Contrast with TVM_FFI_DLL, which conditionally imports or exports based on TVM_FFI_EXPORTS.
# Platform variants:
#   Emscripten: EMSCRIPTEN_KEEPALIVE
#   MSVC:       __declspec(dllexport)
#   GCC/Clang:  __attribute__((visibility("default")))
# Invariant: always-export; never conditional on TVM_FFI_EXPORTS
# Interacts with: TVM_FFI_DLL_EXPORT_TYPED_FUNC (uses this to mark the extern "C" symbol)
TVM_FFI_DLL_EXPORT = platform_export_attribute


# function.h additions

# TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)
# Wraps a typed C++ callable (lambda, function pointer, etc.) into a C ABI-compatible
# safe_call symbol named ExportName. The symbol matches the TVMFFISafeCallType convention:
#   int ExportName(void* self, TVMFFIAny* args, int32_t num_args, TVMFFIAny* result)
# Macro expands to an extern "C" block so the symbol has no C++ name mangling.
# Invariant: ExportName and Function must be different identifiers (see note in docstring).
# Interacts with: TVM_FFI_DLL_EXPORT (marks the symbol), TVM_FFI_SAFE_CALL_BEGIN/END (error boundary),
#                 tvm::ffi::details::FunctionInfo (type introspection), unpack_call (arg dispatch),
#                 AnyView (args array), Any (result pointer)
# Replaces: legacy TVM_DLL_EXPORT_TYPED_FUNC (same semantics, new TVM FFI namespace prefix)
def TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName: symbol, Function: callable) -> extern_c_symbol:
    # Expands to:
    # extern "C" {
    #   TVM_FFI_DLL_EXPORT int ExportName(
    #       void* self, TVMFFIAny* args, int32_t num_args, TVMFFIAny* result) {
    #     TVM_FFI_SAFE_CALL_BEGIN();
    #     using FuncInfo = tvm::ffi::details::FunctionInfo<decltype(Function)>;
    #     static std::string name = #ExportName;
    #     tvm::ffi::details::unpack_call<FuncInfo::RetType>(
    #         std::make_index_sequence<FuncInfo::num_args>{}, &name, Function,
    #         reinterpret_cast<const AnyView*>(args), num_args,
    #         reinterpret_cast<Any*>(result));
    #     TVM_FFI_SAFE_CALL_END();
    #   }
    # }
    ...


# any.h additions — tvm-namespace aliases

# Convenience aliases exposed directly into the tvm:: namespace (no ambiguity).
# Enables callers in the tvm:: root namespace to write `tvm::Any` / `tvm::AnyView`
# instead of `tvm::ffi::Any` / `tvm::ffi::AnyView`.
# Interacts with: all callers migrating from legacy TVM that expected tvm::PackedArgs/RetValue
using Any = tvm::ffi::Any        # Interacts with: 0003-any-anyview (owning variant)
using AnyView = tvm::ffi::AnyView  # Interacts with: 0003-any-anyview (non-owning borrow)
```

## Impact

- API: `TVM_FFI_DLL_EXPORT_TYPED_FUNC` supersedes the legacy `TVM_DLL_EXPORT_TYPED_FUNC` name. The commit message explicitly states `TVM_DLL_EXPORT_TYPED_FUNC` will be removed once downstream bindings are updated. New callers must use the `TVM_FFI_` prefix.
- Behavioral: none — purely additive; safe_call semantics and ABI layout are unchanged.
- Flags/config: none.
- Data formats/schemas: none.

## Design Elements

Design elements this commit consumes:
- **0001-c-abi** (`c_api.h`): Adds `TVM_FFI_DLL_EXPORT` macro alongside the existing `TVM_FFI_DLL` conditional macro; both follow the same platform-variant pattern already in that file.
- **0004-function-system** (`function.h`): Uses `TVM_FFI_SAFE_CALL_BEGIN/END`, `FunctionInfo`, `unpack_call`, `AnyView`, and `Any` — the packed calling convention infrastructure — to implement `TVM_FFI_DLL_EXPORT_TYPED_FUNC`.
- **0003-any-anyview** (`any.h`): Aliases `tvm::ffi::Any` and `tvm::ffi::AnyView` into the `tvm` namespace.

Design elements this commit produces:
- **`TVM_FFI_DLL_EXPORT` macro** (`c_api.h`): New always-export DLL annotation. Part of the stable C ABI surface.
- **`TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro** (`function.h`): New module export pattern — the canonical way to expose a typed C++ function as a C ABI symbol loadable by `load_module`. Extends `0004-function-system`.
- **`tvm::Any` / `tvm::AnyView` namespace aliases** (`any.h`): Convenience shim for legacy TVM callers; extends `0003-any-anyview`.

## Usage Examples

C++ definition of an exported typed function (taken from the macro's inline docstring):

```cpp
// Define a typed C++ function
int AddOne_(int x) { return x + 1; }

// Export it as "AddOne" with C ABI linkage and safe_call wrapping
TVM_FFI_DLL_EXPORT_TYPED_FUNC(AddOne, AddOne_);

// Export a lambda as "SubOne"
TVM_FFI_DLL_EXPORT_TYPED_FUNC(SubOne, [](int x) { return x - 1; });

// Load from Python (cross-layer trace):
// import tvm.ffi as ffi
// mod = ffi.load_module("mylib.so")
// result = mod["AddOne"](41)  # => 42
```
