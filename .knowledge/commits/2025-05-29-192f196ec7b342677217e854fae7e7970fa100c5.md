# Cleanup PackedFunc redirections: add TVM_FFI_DLL_EXPORT_TYPED_FUNC macro and namespace using declarations
## TL;DR
- Adds `TVM_FFI_DLL_EXPORT` macro to `c_api.h` that always marks a function as DLL export (unlike `TVM_FFI_DLL` which switches between import/export based on `TVM_FFI_EXPORTS`).
- Adds `TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)` macro to `function.h` that exports a typed C++ function as an `extern "C"` symbol with `TVMFFISafeCallType` calling convention.
- Adds `using tvm::ffi::Any` and `using tvm::ffi::AnyView` in the `tvm::` namespace for ergonomic access.

## Key Exports

```python
# --- c_api.h: New DLL export macro ---
# TVM_FFI_DLL_EXPORT: Always marks a function as DLL export.
# Unlike TVM_FFI_DLL, which is dllimport when TVM_FFI_EXPORTS is not defined,
# TVM_FFI_DLL_EXPORT is always dllexport/__attribute__((visibility("default"))).
# Interacts with: TVM_FFI_DLL_EXPORT_TYPED_FUNC (uses this for the exported symbol)
# Invariant: platform-specific definition (EMSCRIPTEN_KEEPALIVE, __declspec(dllexport),
#            or __attribute__((visibility("default"))))

# --- function.h: Typed function DLL export macro ---
# Macro expansion: TVM_FFI_DLL_EXPORT_TYPED_FUNC(ExportName, Function)
# produces:
#   extern "C" {
#     TVM_FFI_DLL_EXPORT int ExportName(
#         void* self, TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
#     ) {
#         TVM_FFI_SAFE_CALL_BEGIN();
#         // Infer arg count and return type from Function's signature
#         unpack_call<RetType>(index_sequence<num_args>{}, &name, Function, args, num_args, result);
#         TVM_FFI_SAFE_CALL_END();
#     }
#   }
# Interacts with: TVM_FFI_DLL_EXPORT (visibility), TVM_FFI_SAFE_CALL_BEGIN/END (error boundary),
#                 details::FunctionInfo (type introspection), details::unpack_call (arg unpacking)
# Invariant: ExportName and Function must be different identifiers (else compilation error)
# Invariant: exported function conforms to TVMFFISafeCallType calling convention
# Extension: used to expose typed C++ functions as loadable module symbols

# --- any.h: Namespace using declarations ---
# using tvm::ffi::Any   -> accessible as tvm::Any
# using tvm::ffi::AnyView -> accessible as tvm::AnyView
# Interacts with: all C++ code in tvm:: namespace that uses Any/AnyView
```

## Impact
- API: Additive only. New `TVM_FFI_DLL_EXPORT` and `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macros. `Any`/`AnyView` now also available in `tvm::` namespace (previously only in `tvm::ffi::`)
- Behavioral: None -- no existing behavior changed
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- `TVMFFISafeCallType` calling convention ([0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md)) -- the exported function conforms to this signature
- `TVM_FFI_SAFE_CALL_BEGIN/END` error boundary macros ([0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md)) -- used inside the generated function body
- `details::unpack_call` and `FunctionInfo` ([0004-ffi-function-system](../design-records/0004-ffi-function-system.md)) -- compile-time arg unpacking and type introspection
- `TVM_FFI_DLL` visibility macro ([0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md)) -- pattern replicated for the new export-only variant

Design elements this commit produces:
- `TVM_FFI_DLL_EXPORT` macro -- always-export variant of `TVM_FFI_DLL`, needed for module symbol export where import semantics are never appropriate
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro -- high-level macro to export typed C++ functions as C ABI symbols, counterpart to `TVM_FFI_REGISTER_GLOBAL` but for DLL-exported symbols rather than the global registry
- `tvm::Any` / `tvm::AnyView` using declarations -- convenience aliases from root `tvm::` namespace

## Usage Examples
From the Doxygen comment in the macro definition (`include/tvm/ffi/function.h`):
```cpp
// Define a typed C++ function
int AddOne_(int x) {
  return x + 1;
}

// Export as "AddOne" symbol with SafeCallType calling convention
TVM_FFI_DLL_EXPORT_TYPED_FUNC(AddOne, AddOne_);

// Also works with lambdas
TVM_FFI_DLL_EXPORT_TYPED_FUNC(SubOne, [](int x) {
  return x - 1;
});

// NOTE: ExportName must differ from Function name
// TVM_FFI_DLL_EXPORT_TYPED_FUNC(AddOne_, AddOne_);  // ERROR: same name
// TVM_FFI_DLL_EXPORT_TYPED_FUNC(AddOne_, xyz::AddOne_);  // OK: different namespace
```
