# Bump version to 0.1.0a9 and xfail Windows inline-compilation tests
## TL;DR
- Bumps `apache-tvm-ffi` package version from `0.1.0a8` to `0.1.0a9` in `pyproject.toml`.
- Marks four `test_load_inline_cpp*` tests as `xfail` on Windows with `pytest.mark.xfail(sys.platform.startswith("win"), reason="needs to robustify windows support")`, so CI passes while Windows inline-compilation support is hardened.
