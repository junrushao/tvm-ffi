# Temporarily skip load_inline tests on Windows and bump version to 0.1.0a9

- Mark four `test_load_inline_cpp*` tests with `@pytest.mark.xfail` on Windows (`sys.platform.startswith("win")`), deferring full Windows `load_inline` robustness to a future PR.
