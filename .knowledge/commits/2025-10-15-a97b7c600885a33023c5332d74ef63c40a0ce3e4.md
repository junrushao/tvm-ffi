# Fix module/tensor destruction order in tests and document lifetime hazard
## TL;DR
- Fixed test cases (`test_load_inline.py`) where objects returned by a loaded module could be destroyed after the module was unloaded, causing invalid deleter calls. Solution: wrap test logic in a nested function so returned objects are freed before the module goes out of scope.
- Added documentation to `Module` class docstring describing the lifetime hazard: objects whose deleters reside in a loaded library must be destroyed before the module is unloaded.
