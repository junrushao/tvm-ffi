# Add minimal C example for compiler codegen with C ABI doc improvements
## TL;DR
- Adds a new `examples/quick_start/src/add_one_c.c` demonstrating pure-C FFI function authoring via the `__tvm_ffi_` symbol convention, with matching Python runner and CMake integration.
- Updates `docs/get_started/quick_start.md` and `docs/guides/compiler_integration.md` with corrected C ABI code (fixes `ReadDLTensorPtr` signature bug, replaces `static_cast`/`reinterpret_cast` with C casts, renames function to `add_one_c`).
- Modifies `c_api.h`: moves `DLPackTensorAllocator` typedef inside `extern "C"` block, adds forward declaration for `DLManagedTensorVersioned`, removes `v_char32` field from `TVMFFIAny` union.
- Adds `--cflags` option to `tvm-ffi-config` CLI (C flags without `-std=c++17`).

## Impact
- API: `v_char32` field removed from `TVMFFIAny` union — any code accessing this field will fail to compile. `DLPackTensorAllocator` moved inside `extern "C"` block, improving C compatibility.
- Behavioral: none — computation logic unchanged.
- Flags/config: new `tvm-ffi-config --cflags` flag for C (not C++) compilation.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- **C ABI (0007)**: `TVMFFIAny`, `TVMFFIObject`, `kTVMFFIDLTensorPtr`, `kTVMFFITensor`, `TVMFFIErrorSetRaisedFromCStr` — all used in the C example to demonstrate raw FFI function authoring.
- **Module system (0011)**: `__tvm_ffi_` symbol prefix convention — the C example uses `__tvm_ffi_add_one_c` to be discoverable by `load_module`.
- **Function system (0003)**: `TVMFFISafeCallType` signature convention — the C function follows the packed calling convention.
- **Error propagation (0004)**: `TVMFFIErrorSetRaisedFromCStr` for C-level error reporting.

Design elements this commit produces:
- **`tvm-ffi-config --cflags`**: new CLI flag exposing C-only include paths (no `-std=c++17`). Parallel to existing `--cxxflags`.

## Usage Examples

End-to-end: compile C source and call from Python:

```bash
# Compile C module using tvm-ffi-config
gcc -shared -fPIC `tvm-ffi-config --cflags`  \
    src/add_one_c.c -o build/add_one_c.so    \
    `tvm-ffi-config --ldflags` `tvm-ffi-config --libs`
```

```python
# Load and call from Python (examples/quick_start/run_example.py)
import tvm_ffi
import numpy

mod = tvm_ffi.load_module("build/add_one_c.so")
x = numpy.array([1, 2, 3, 4, 5], dtype=numpy.float32)
y = numpy.empty_like(x)
mod.add_one_c(x, y)  # calls __tvm_ffi_add_one_c via module symbol lookup
```
