# Add C example for low-level FFI ABI integration with c_api.h cleanups
## TL;DR
- Adds a complete C-only example (`add_one_c.c`) demonstrating raw `TVMFFISafeCallType` function implementation and `TVMFFIAny` argument extraction, with documentation in `quick_start.md` and `compiler_integration.md`.
- Cleans up `c_api.h`: moves `DLPackTensorAllocator` typedef inside `extern "C"` block for C compatibility, removes unused `v_char32` field from `TVMFFIAny` union, adds forward declaration for `DLManagedTensorVersioned`.
- Adds `--cflags` option to `tvm-ffi-config` CLI tool (C flags without `-std=c++17`), supporting pure-C compilation workflows.
- Bumps version from `0.1.0b1` to `0.1.0b2`.

## Impact
- API: `TVMFFIAny.v_char32` field removed from the union. Any C/C++ code referencing `v_char32` will fail to compile. No known internal callers.
- API: `DLPackTensorAllocator` moved inside `extern "C"` block -- now usable from C code, previously only accessible from C++.
- Behavioral: none -- new example code is additive.
- Flags/config: new `--cflags` option added to `tvm-ffi-config` CLI.
- Data formats/schemas: none.

## Usage Examples

**C ABI function compiled and loaded from Python:**
```c
// add_one_c.c -- compile with: gcc -shared -fPIC `tvm-ffi-config --cflags` src/add_one_c.c -o build/add_one_c.so `tvm-ffi-config --ldflags` `tvm-ffi-config --libs`
#include <tvm/ffi/c_api.h>
#include <tvm/ffi/extra/c_env_api.h>

int __tvm_ffi_add_one_c(
    void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
) {
    DLTensor *x, *y;
    if (ReadDLTensorPtr(&args[0], &x) == -1) return -1;
    if (ReadDLTensorPtr(&args[1], &y) == -1) return -1;
    for (int i = 0; i < x->shape[0]; ++i)
        ((float*)(y->data))[i] = ((float*)(x->data))[i] + 1;
    return 0;
}
```

```python
# Load and call from Python
import tvm_ffi, numpy
mod = tvm_ffi.load_module("build/add_one_c.so")
x = numpy.array([1, 2, 3, 4, 5], dtype=numpy.float32)
y = numpy.empty_like(x)
mod.add_one_c(x, y)  # y == [2, 3, 4, 5, 6]
```
