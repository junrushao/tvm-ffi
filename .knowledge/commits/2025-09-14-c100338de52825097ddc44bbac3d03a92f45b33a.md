# Add minimal runnable C example demonstrating compiler codegen ABI target, fix c_api.h typedef placement, and remove v_char32 from TVMFFIAny

## TL;DR
- Adds `examples/quick_start/src/add_one_c.c`: a fully runnable pure-C implementation of the packed calling convention that serves as a reference for compiler codegen targets. Shows `ReadDLTensorPtr` helper, `__tvm_ffi_add_one_c` entry point, error propagation via `TVMFFIErrorSetRaisedFromCStr`, and stream query via `TVMFFIEnvGetStream`.
- Fixes `c_api.h`: moves `DLPackTensorAllocator` typedef inside `extern "C"` block (it was outside), adds a forward declaration `typedef struct DLManagedTensorVersioned DLManagedTensorVersioned` guarded by a TODO, and removes the `v_char32[2]` field from the `TVMFFIAny` union.
- Adds `--cflags` flag to `tvm-ffi-config` CLI (`python/tvm_ffi/config.py`) for use by pure-C consumers that don't want `-std=c++17`.

## Impact
- API: `TVMFFIAny` union loses the `v_char32[2]` field — any C code that referenced `value.v_char32` will fail to compile. No known external callers exist (field was undocumented).
- Behavioral: `DLPackTensorAllocator` typedef moved inside `extern "C"` — fixes potential linkage issue for C consumers that included `c_api.h` before the extern "C" block was entered; the typedef is now callable from pure C without manual C++ guard.
- Flags/config: `tvm-ffi-config --cflags` is now a valid invocation (previously only `--cxxflags` existed).
- Data formats/schemas: `TVMFFIAny` wire format unchanged functionally (the removed union member was never populated by any C++ code visible in this commit).

## Usage Examples

End-to-end: C codegen target compiled and called from Python.

```bash
# Build step (pure C, no C++ compiler needed)
gcc -shared -fPIC $(tvm-ffi-config --cflags) \
    src/add_one_c.c -o build/add_one_c.so \
    $(tvm-ffi-config --ldflags) $(tvm-ffi-config --libs)
```

```python
# Python call site (run_example.py)
import tvm_ffi, numpy

mod = tvm_ffi.load_module("build/add_one_c.so")
x = numpy.array([1, 2, 3, 4, 5], dtype=numpy.float32)
y = numpy.empty_like(x)
mod.add_one_c(x, y)   # dispatches through Module -> __tvm_ffi_add_one_c symbol
```

```c
/* C kernel skeleton (add_one_c.c) */
int __tvm_ffi_add_one_c(
    void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
) {
    DLTensor *x, *y;
    if (ReadDLTensorPtr(&args[0], &x) == -1) return -1;
    if (ReadDLTensorPtr(&args[1], &y) == -1) return -1;
    for (int i = 0; i < x->shape[0]; ++i)
        ((float*)y->data)[i] = ((float*)x->data)[i] + 1;
    return 0;
}
```
