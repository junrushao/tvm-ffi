# Add minimal C example demonstrating low-level C ABI codegen pattern
## TL;DR
- Adds a pure C example (`examples/quick_start/src/add_one_c.c`) that demonstrates how to implement a TVM FFI compatible function using only the C ABI, serving as a reference for compiler codegen.
- Extends `tvm-ffi-config` with `--cflags` flag (C include paths without `-std=c++17`) and updates docs/README to show GCC compilation workflow.
- Fixes `c_api.h` for pure C compatibility: moves `DLPackTensorAllocator` inside `extern "C"` block, removes `v_char32` union member from `TVMFFIAny`, adds forward declaration for `DLManagedTensorVersioned`.

## Key Exports

**Functions (CLI)**:
- `tvm-ffi-config --cflags`: New flag in `python/tvm_ffi/config.py` that prints `-I<include> -I<dlpack_include>` without `-std=c++17`, enabling pure C compilation against TVM FFI headers.

**Struct changes (c_api.h)**:
- `TVMFFIAny.v_char32` union member: **Removed**. The `char32_t v_char32[2]` field for small UCS4 string/Unicode is deleted from the union.
- `DLPackTensorAllocator` typedef: **Moved** from before `extern "C"` block to inside it, ensuring C linkage. A forward declaration `typedef struct DLManagedTensorVersioned DLManagedTensorVersioned;` is added to resolve the incomplete type in pure C.

**Reference patterns (not formal API)**:
- `ReadDLTensorPtr(const TVMFFIAny* value, DLTensor** out) -> int`: Documented C pattern for extracting `DLTensor*` from `TVMFFIAny`, handling both `kTVMFFIDLTensorPtr` (raw pointer) and `kTVMFFITensor` (object with header offset).
- `__tvm_ffi_add_one_c`: Reference implementation of `TVMFFISafeCallType` signature in pure C.

## Impact
- API: `v_char32` removed from `TVMFFIAny` union — any C/C++ code accessing `value.v_char32` will fail to compile. `DLPackTensorAllocator` moved inside `extern "C"` which may affect C++ code that relied on it having C++ linkage (unlikely in practice).
- Behavioral: None — the existing code paths are unchanged.
- Flags/config: New `tvm-ffi-config --cflags` flag. Version bumped from `0.1.0b1` to `0.1.0b2`.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **C ABI layer** ([0001-c-abi-layer.md](../designs/0001-c-abi-layer.md)): Uses `TVMFFIAny`, `TVMFFIObject`, `kTVMFFIDLTensorPtr`, `kTVMFFITensor`, `TVMFFIErrorSetRaisedFromCStr`, and `TVMFFISafeCallType` calling convention.
- **Module system** ([0013-module-system.md](../designs/0013-module-system.md)): Uses `__tvm_ffi_<name>` symbol prefix convention for function export; loaded via `tvm_ffi.load_module()` in Python.
- **Env C API** ([ADR 0013](../ADRs/0013-env-api-naming-convention.md)): Uses `TVMFFIEnvGetStream` from `extra/c_env_api.h` for device stream context.
- **Python package tooling** ([0014-python-package.md](../designs/0014-python-package.md)): Extends `tvm-ffi-config` CLI with `--cflags`.

Design elements this commit produces:
- **C codegen reference pattern**: `ReadDLTensorPtr` + `__tvm_ffi_add_one_c` form a documented, runnable pattern for pure C implementations of FFI functions. This is not a formal API but a convention for compiler codegen targets.
- **`tvm-ffi-config --cflags`**: New tooling entry point for C (non-C++) compilation against TVM FFI.

## Usage Examples

**Pure C FFI function (from `examples/quick_start/src/add_one_c.c`)**:
```c
#include <tvm/ffi/c_api.h>
#include <tvm/ffi/extra/c_env_api.h>

int ReadDLTensorPtr(const TVMFFIAny* value, DLTensor** out) {
  if (value->type_index == kTVMFFIDLTensorPtr) {
    *out = (DLTensor*)(value->v_ptr);
    return 0;
  }
  if (value->type_index != kTVMFFITensor) {
    TVMFFIErrorSetRaisedFromCStr("ValueError", "Expects a Tensor input");
    return -1;
  }
  *out = (DLTensor*)((char*)(value->v_obj) + sizeof(TVMFFIObject));
  return 0;
}

int __tvm_ffi_add_one_c(
    void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result
) {
  DLTensor *x, *y;
  if (ReadDLTensorPtr(&args[0], &x) == -1) return -1;
  if (ReadDLTensorPtr(&args[1], &y) == -1) return -1;
  for (int i = 0; i < x->shape[0]; ++i)
    ((float*)(y->data))[i] = ((float*)(x->data))[i] + 1;
  return 0;
}
```

**Compilation via `tvm-ffi-config --cflags`:**
```bash
gcc -shared -fPIC `tvm-ffi-config --cflags`  \
    src/add_one_c.c -o build/add_one_c.so    \
    `tvm-ffi-config --ldflags` `tvm-ffi-config --libs`
```

**Loading from Python (`examples/quick_start/run_example.py`):**
```python
import tvm_ffi
mod = tvm_ffi.load_module("build/add_one_c.so")
mod.add_one_c(x, y)
```
