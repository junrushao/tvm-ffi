# Add C example demonstrating low-level C ABI usage for compiler codegen
## TL;DR
- Adds a new `examples/quick_start/src/add_one_c.c` showing how to write a raw C FFI function following the `__tvm_ffi_<name>` symbol convention with `TVMFFISafeCallType` signature and `TVMFFIAny`-based argument extraction.
- Updates `docs/get_started/quick_start.md` and `docs/guides/compiler_integration.md` with corrected, runnable C example code -- fixing a bug in the old `ReadDLTensorPtr` helper (was `DLTensor*` out-param instead of `DLTensor**`), replacing `static_cast`/`reinterpret_cast` with C casts, and reducing from 3 tensor args to 2.
- Minor housekeeping: bumps version to `0.1.0b2`, adds `--cflags` flag to `tvm-ffi-config` CLI, increases GoogleTest discovery timeout from 300s to 600s, moves `DLPackTensorAllocator` typedef inside `extern "C"` block in `c_api.h`, and removes the unused `v_char32` union member from `TVMFFIAny`.

## Key Exports

```python
# tvm-ffi-config CLI: new --cflags flag
# Produces: -I<include_dir> -I<dlpack_include_dir>  (no -std=c++17, unlike --cxxflags)
# Interacts with: libinfo.find_include_path(), libinfo.find_dlpack_include_path()
# Extension: enables plain C compilation of FFI-compatible shared libraries

# Example C FFI function (codegen reference pattern):
# int __tvm_ffi_add_one_c(void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result)
# Invariant: follows TVMFFISafeCallType signature
# Invariant: returns 0 for success, -1 for error (set via TVMFFIErrorSetRaisedFromCStr)
# Interacts with: Module::LoadFromFile -> DSOLibrary -> GetSymbolWithSymbolPrefix("add_one_c")
# Interacts with: TVMFFIEnvGetStream (stream context for GPU synchronization)

# Helper pattern for C codegen:
# int ReadDLTensorPtr(const TVMFFIAny* value, DLTensor** out)
# Invariant: handles both kTVMFFIDLTensorPtr (raw pointer) and kTVMFFITensor (Object+offset)
# Invariant: for kTVMFFITensor, DLTensor starts at (char*)(value->v_obj) + sizeof(TVMFFIObject)
# Interacts with: TVMFFIAny.type_index, TVMFFIObject layout (24-byte header)
```

## Impact
- API: Adds `--cflags` to `tvm-ffi-config` CLI (additive). Removes `v_char32` union member and `DLPackTensorAllocator` position change in `c_api.h` (see below).
- Behavioral: The `DLPackTensorAllocator` typedef was moved from before `extern "C"` to inside it. This fixes C compilation compatibility -- previously the typedef used C++ before the `extern "C"` block, now it is properly inside. The `v_char32` member removal shrinks the union's named alternatives but does not change `sizeof(TVMFFIAny)` (still 16 bytes, 8-byte value union). Also a forward declaration `typedef struct DLManagedTensorVersioned DLManagedTensorVersioned;` was added with a TODO note.
- Flags/config: New `--cflags` flag on `tvm-ffi-config` emits C-only include flags (no `-std=c++17`).
- Data formats/schemas: none

## Usage Examples

End-to-end: compile C source into loadable module, then call from Python.

```bash
# Compile with C compiler using tvm-ffi-config --cflags (new) instead of --cxxflags
gcc -shared -fPIC `tvm-ffi-config --cflags`  \
    src/add_one_c.c -o build/add_one_c.so    \
    `tvm-ffi-config --ldflags` `tvm-ffi-config --libs`
```

```python
# Python: load and call the C-compiled module
import tvm_ffi
import numpy

mod = tvm_ffi.load_module("build/add_one_c.so")
x = numpy.array([1, 2, 3, 4, 5], dtype=numpy.float32)
y = numpy.empty_like(x)
mod.add_one_c(x, y)  # calls __tvm_ffi_add_one_c via DSOLibrary symbol lookup
```
