# Add file-based build() and load() to tvm_ffi.cpp alongside existing inline variants
## TL;DR
- Adds `tvm_ffi.cpp.build()` and `tvm_ffi.cpp.load()` -- file-path-based counterparts to the existing `build_inline()`/`load_inline()` that accept paths to `.cc`/`.cu` source files instead of raw source strings.
- Renames `load_inline.py` to `extension.py`, reflecting the broadened scope of the module from inline-only to general C++ extension building.
- Extracts a shared `_build_impl()` backend that both `build_inline()` and `build()` delegate to, removing duplication of build logic.

## Impact
- API: Additive -- two new public functions `tvm_ffi.cpp.build` and `tvm_ffi.cpp.load` exported in `__init__.py`. The `__all__` list is now explicitly defined.
- Behavioral: None -- existing `build_inline` and `load_inline` behavior unchanged; they now delegate to `_build_impl` internally.
- Flags/config: None
- Data formats/schemas: None

Design elements this commit produces:
- `tvm_ffi.cpp.build()` / `tvm_ffi.cpp.load()` -- file-path-based compilation API. Key difference from inline variants: no automatic `_decorate_with_tvm_ffi` wrapping; users must include FFI headers and export macros manually in their source files.
- `_build_impl()` -- shared internal backend extracted from `build_inline()`, now reused by both code paths. The `need_lock` parameter controls whether a `FileLock` is acquired (inline path already holds one).
- Module rename: `load_inline.py` -> `extension.py` -- broadens the module's identity from inline-only to general C++ extension building.

## Usage Examples
**File-based build and load (from `tests/python/test_build.py`):**
```python
import pathlib
import numpy
import tvm_ffi.cpp
from tvm_ffi.module import Module

# Source file (test_build.cc) uses TVM_FFI_DLL_EXPORT_TYPED_FUNC manually
cpp_path = pathlib.Path(__file__).parent.resolve() / "test_build.cc"
output_lib_path = tvm_ffi.cpp.build(
    name="hello",
    cpp_files=[str(cpp_path)],
)
mod: Module = tvm_ffi.load_module(output_lib_path)

x = numpy.array([1, 2, 3, 4, 5], dtype=numpy.float32)
y = numpy.empty_like(x)
mod.add_one_cpu(x, y)
numpy.testing.assert_equal(x + 1, y)
```

**Key distinction from inline API:** The C++ source file must include its own headers and export macros:
```cpp
// test_build.cc -- user is responsible for includes and export macros
#include "test_build.h"
#include <tvm/ffi/container/tensor.h>
#include <tvm/ffi/function.h>
// ...
void add_one_cpu(tvm::ffi::TensorView x, tvm::ffi::TensorView y) { /* ... */ }
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one_cpu, add_one_cpu);
```
