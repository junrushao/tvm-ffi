# Add build() and build_and_load() for file-path-based C++ extension compilation
## TL;DR
- Renames `load_inline.py` to `extension.py`, expanding scope from inline strings to file-path-based compilation
- Adds `build()` (compile without loading) and `build_and_load()` (compile + load as Module) functions accepting file paths instead of raw source strings
- API mirrors `torch.utils.cpp_extension.load` conventions

## Usage Examples
```python
import tvm_ffi.cpp as cpp

# Build from file paths
lib_path = cpp.build("my_ext", cpp_sources=["my_ext.cc"])

# Build and load in one step
mod = cpp.build_and_load("my_ext", cpp_sources=["my_ext.cc", "helper.cc"])
f = mod["my_function"]
```
