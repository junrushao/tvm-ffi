# Add build/build_and_load functions for C++/CUDA extension files
## TL;DR
- Renames `load_inline.py` to `extension.py` and adds `build()` and `build_and_load()` functions that accept file paths (not raw strings), similar to `torch.utils.cpp_extension.load`.
- Adds test files (`test_build.cc`, `test_build.h`, `test_build.py`) exercising file-based compilation.
- Updates docs reference index to reflect the new module.
