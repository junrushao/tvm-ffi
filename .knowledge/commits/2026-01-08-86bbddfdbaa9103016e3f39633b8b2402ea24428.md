# Add overflow check for uint64_t/size_t in TypeTraits<Int>::CopyToAnyView
## TL;DR
- Adds an overflow check in `TypeTraits<Int>::CopyToAnyView` for unsigned 64-bit integers that exceed `int64_t::max`.
- Throws `OverflowError` when a `uint64_t` value cannot be safely represented as `int64_t`.
- Updates `StructuralHash` to use explicit `static_cast<int64_t>` for hash values to avoid triggering the new overflow check.

## Key Exports
None (behavioral change to existing type trait)

## Impact
- API: none
- ABI: none
- Behavioral: Large uint64_t values now throw OverflowError instead of silently truncating when converted to Any.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:

Design elements this commit produces:
- **uint64_t overflow guard** -- Prevents silent data loss when converting large unsigned integers to the signed int64_t representation used by Any.

## Usage Examples
```cpp
uint64_t big = uint64_t(INT64_MAX) + 1;
// This now throws OverflowError:
AnyView view = big; // throws!
```
