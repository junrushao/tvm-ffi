# Add uint64_t overflow check in TypeTraits<Int>::CopyToAnyView and fix structural hash uint64->int64 conversions

## TL;DR
- Adds a compile-time-gated runtime overflow check in `TypeTraits<Int>::CopyToAnyView`: when `Int` is unsigned and `sizeof(Int) >= sizeof(int64_t)`, values exceeding `INT64_MAX` throw `OverflowError` instead of silently wrapping.
- Fixes `StructuralHash` internals and FFI-exposed function to return `int64_t` (via explicit bitcast from `uint64_t`) so that hash values pass through `Any` without triggering the new overflow check.
- Changes the custom `__s_hash__` callback signature from `(AnyView, uint64_t, bool) -> uint64_t` to `(AnyView, int64_t, bool) -> int64_t`.

## Key Exports

```python
# --- Mutated: TypeTraits<Int>::CopyToAnyView (include/tvm/ffi/type_traits.h) ---
# OLD: unconditionally stores static_cast<int64_t>(src)
# NEW: for unsigned types >= 64 bits, checks overflow before storing
class TypeTraits_Int:
    """TypeTraits specialization for integral types (enabled via is_integral_v)."""

    @staticmethod
    def CopyToAnyView(src: Int, result: TVMFFIAny) -> None:
        # NEW: compile-time guard + runtime check
        if is_unsigned(Int) and sizeof(Int) >= sizeof(int64_t):
            if src > int64_max:
                raise OverflowError(f"Integer value {src} is too large to fit in int64_t.")
        result.type_index = kTVMFFIInt
        result.zero_padding = 0
        result.v_int64 = int64_t(src)
        # Interacts with: Any/AnyView implicit constructors (all integer -> Any paths)
        # Invariant: uint64_t values > INT64_MAX are rejected, not silently truncated
        # Extension: 128-bit integers explicitly not considered

# --- Mutated: ffi.StructuralHash FFI function (src/ffi/extra/structural_hash.cc) ---
# OLD: refl::GlobalDef().def("ffi.StructuralHash", StructuralHash::Hash)
#      StructuralHash::Hash returns uint64_t -> stored directly in Any -> could overflow
# NEW: wrapper FFIStructuralHash bitcasts uint64_t result to int64_t before returning via Any

def ffi_structural_hash(value: Any, map_free_vars: bool, skip_tensor_content: bool) -> int64_t:
    """FFI-exposed wrapper around StructuralHash::Hash. Returns int64_t (bitcast from uint64_t)."""
    result: uint64_t = StructuralHash.Hash(value, map_free_vars, skip_tensor_content)
    return static_cast_int64(result)
    # Interacts with: refl::GlobalDef (registered as "ffi.StructuralHash")
    # Interacts with: Any return value conversion (now safe, int64_t fits in kTVMFFIInt)
    # Invariant: hash bits are preserved via bitcast, not value-conversion

# --- Mutated: __s_hash__ callback signature ---
# OLD: (ObjectRef, uint64_t init_hash, TypedFunction<uint64_t(AnyView, uint64_t, bool)>) -> uint64_t
# NEW: (ObjectRef, int64_t init_hash, TypedFunction<int64_t(AnyView, int64_t, bool)>) -> int64_t
# All custom __s_hash__ implementations must use int64_t instead of uint64_t.
# The internal lambda in StructuralHashHandler also bitcasts StableHashCombine results.
```

## Impact
- API: **Breaking** for custom `__s_hash__` callback implementations. The signature changes from `uint64_t` parameters/return to `int64_t`. All downstream types registering custom `__s_hash__` via `TypeAttrDef` must update. The FFI function `ffi.StructuralHash` now returns `int64_t` instead of `uint64_t` (Python callers unaffected since Python `int` is arbitrary precision).
- Behavioral: `uint64_t` and `size_t` values exceeding `INT64_MAX` now throw `OverflowError` when stored in `Any`/`AnyView`, where they previously silently wrapped to negative `int64_t`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeTraits<T> protocol** ([0002-ffi-any-value-system.md](../../.knowledge/design-records/0002-ffi-any-value-system.md)): extends the `CopyToAnyView` method for the integral specialization.
- **StructuralHash** ([0009-ffi-structural-eq-hash.md](../../.knowledge/design-records/0009-ffi-structural-eq-hash.md)): modifies how hash values flow through `Any` at the FFI boundary.
- **Error protocol** ([0005-ffi-error-protocol.md](../../.knowledge/design-records/0005-ffi-error-protocol.md)): uses `TVM_FFI_THROW(OverflowError)` for the overflow check.
- **Reflection GlobalDef** ([0007-ffi-reflection.md](../../.knowledge/design-records/0007-ffi-reflection.md)): re-registers `ffi.StructuralHash` with a wrapper function.

Design elements this commit produces/mutates:
- **TypeTraits<Int>::CopyToAnyView contract** (mutated): adds a new precondition — unsigned 64-bit values must not exceed `INT64_MAX`. This tightens the contract from "any integral value is accepted" to "unsigned values in the int64_t-representable range are accepted."
- **`__s_hash__` callback signature** (mutated): changes from `uint64_t` to `int64_t` throughout. This is a breaking change to the TypeAttr protocol for custom structural hashing.
- **`ffi.StructuralHash` FFI function** (mutated): return type changes from `uint64_t` to `int64_t` (via explicit bitcast). Internal hash combining lambdas also bitcast.

## Usage Examples

**Before (overflow silently wraps):**
```cpp
uint64_t big = static_cast<uint64_t>(std::numeric_limits<int64_t>::max()) + 1;
AnyView view = big;  // Silently wraps: v_int64 becomes negative (INT64_MIN)
```

**After (overflow throws):**
```cpp
uint64_t big = static_cast<uint64_t>(std::numeric_limits<int64_t>::max()) + 1;
AnyView view = big;  // Throws OverflowError: "Integer value ... is too large to fit in int64_t"

// For hash values that legitimately span the full uint64_t range, use explicit bitcast:
uint64_t hash = StructuralHash::Hash(value, false, false);
int64_t safe_hash = static_cast<int64_t>(hash);  // Bitcast preserves bits
AnyView view2 = safe_hash;  // OK: int64_t always fits
```

**Custom `__s_hash__` signature change:**
```cpp
// OLD:
uint64_t SHash(uint64_t init_hash, TypedFunction<uint64_t(AnyView, uint64_t, bool)> hash) const;
// NEW:
int64_t SHash(int64_t init_hash, TypedFunction<int64_t(AnyView, int64_t, bool)> hash) const;
```
