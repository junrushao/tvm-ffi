# Add overflow check for uint64_t/size_t to int64_t conversion in TypeTraits and fix structural hash
## TL;DR
- Adds runtime overflow detection in `TypeTraits<Int>::CopyToAnyView` when converting unsigned 64-bit integers to `int64_t` -- throws `OverflowError` if value exceeds `INT64_MAX`.
- Updates `StructuralHash` to explicitly `static_cast<int64_t>()` hash values before passing through `Any`, preventing the new overflow check from triggering on hash values. The FFI-registered `ffi.StructuralHash` now wraps the result in `int64_t`.
- Updates custom `__s_hash__` callback signature from `uint64_t` to `int64_t` for FFI compatibility.

## Key Exports

**`TypeTraits<Int>::CopyToAnyView`** -- updated contract (`type_traits.h`):
```cpp
// For unsigned integers >= 64 bits (uint64_t, size_t):
// Throws OverflowError if src > INT64_MAX
// "Integer value X is too large to fit in int64_t."
```

**`ffi.StructuralHash`** -- changed signature:
```cpp
// Before: (const Any& value, bool map_free_vars, bool skip_tensor_content) -> uint64_t
// After:  (const Any& value, bool map_free_vars, bool skip_tensor_content) -> int64_t
// Internally still computes uint64_t, then static_cast to int64_t
```

**Custom `__s_hash__` callback** -- updated signature:
```cpp
// Before: uint64_t SHash(uint64_t init_hash, TypedFunction<uint64_t(AnyView, uint64_t, bool)>)
// After:  int64_t SHash(int64_t init_hash, TypedFunction<int64_t(AnyView, int64_t, bool)>)
```

## Impact
- API: `ffi.StructuralHash` return type changes from `uint64_t` to `int64_t`. Custom `__s_hash__` implementations must update signature.
- Behavioral: `uint64_t` values > `INT64_MAX` now throw `OverflowError` when stored in `Any`/`AnyView`. This is a runtime check, not a type system change.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:

Design elements this commit produces:
- **uint64_t overflow guard**: Runtime check preventing silent truncation of large unsigned integers in `Any`.

## Usage Examples

**Before (silent truncation):**
```cpp
uint64_t big = uint64_t(INT64_MAX) + 1;
AnyView v = big;  // silently stored as negative int64_t
```

**After (throws):**
```cpp
uint64_t big = uint64_t(INT64_MAX) + 1;
AnyView v = big;  // throws OverflowError: "Integer value ... is too large to fit in int64_t"
```
