# Add overflow check for uint64_t/size_t in TypeTraits CopyToAnyView
## TL;DR
- Adds overflow checking when converting `uint64_t`/`size_t` values to `AnyView` in `type_traits.h`, preventing silent truncation to `int64_t`.
- Adds C++ tests for the overflow check.

## Impact
- API: Tightened invariant: large unsigned values now throw instead of silently truncating.
- Flags/config: None.
- Data formats/schemas: None.
