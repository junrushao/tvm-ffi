# Remove Python-side field descriptor infrastructure from dataclasses
## TL;DR
- Removes `_utils.py` and `field.py` Python-side field descriptor infrastructure, relying entirely on C++ reflection for field metadata.
- Simplifies `c_class.py` to use C++ reflection directly.
- Removes associated Python tests that tested the removed infrastructure.

## Impact
- API: Breaking change for any code using `field()` descriptor from `tvm_ffi.dataclasses`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Reflection** (`.knowledge/designs/0006-reflection.md`): C++ reflection replaces Python field descriptors.

Design elements this commit produces:
- **Simplified dataclass decorator**: `@c_class` now relies solely on C++ reflection, removing redundant Python-side metadata.
