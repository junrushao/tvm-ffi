# Remove Python-side field descriptor infrastructure from c_class; simplify to register_object pass-through

## TL;DR
- Deletes `_utils.py` (210 LOC), `field.py` (169 LOC), and the complex `c_class.py` (190→36 LOC) that duplicated C++ reflection metadata in Python.
- `c_class` is now a thin `register_object(type_key)` wrapper; `field()`, `Field`, `KW_ONLY`, `MISSING` are removed from `tvm_ffi.dataclasses`.
- Fixes `_add_class_attrs` to always override `__c_ffi_init__` per type (like `__ffi_shallow_copy__`), preventing base-class constructor inheritance.

```python
def c_class(type_key: str, **kwargs: Any) -> Callable[[type], type]:
    """Thin pass-through to register_object(type_key).
    kwargs reserved for future use (init/kw_only no longer functional).
    """
    # Interacts with: register_object, _add_class_attrs

# python/tvm_ffi/registry.py — _add_class_attrs fix:
# BEFORE: __c_ffi_init__ set only if not hasattr(type_cls, name)
#         => derived class inherits base constructor (wrong field count)
# AFTER:  __c_ffi_init__ always overridden (same pattern as __ffi_shallow_copy__)
#         => each type gets its own constructor

# REMOVED exports from tvm_ffi.dataclasses:
# - field(default, init, kw_only)
# - Field
# - KW_ONLY
# - MISSING
# - c_class(type_key, init=True, kw_only=False)  (init/kw_only params removed)
```

## Impact
- API: **Breaking**. `field()`, `Field`, `KW_ONLY`, `MISSING` no longer exported. `c_class(init=..., kw_only=...)` parameters silently ignored (`**kwargs`). Classes must explicitly inherit from `Object`.
- Behavioral: `__init__` on `c_class`-decorated types now calls C++ FFI constructor directly (positional args). No more Python codegen'd init with keyword-only / default factory support.
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces:

- `_add_class_attrs` fix: `__c_ffi_init__` always overridden per type.

## Usage Examples

```python
# Before: Python-side field infrastructure
from tvm_ffi.dataclasses import c_class, field, KW_ONLY

@c_class("testing.MyClass", init=True, kw_only=True)
class MyClass(Object):
    x: int = field(default=0)
    y: str = KW_ONLY; z: float = field()

# After: direct FFI, positional args only
from tvm_ffi.dataclasses import c_class
from tvm_ffi import Object

@c_class("testing.MyClass")
class MyClass(Object):
    pass  # __init__ calls C++ constructor positionally via __c_ffi_init__

obj = MyClass(1, "hello", 3.14)  # positional args in C++ field order
```
