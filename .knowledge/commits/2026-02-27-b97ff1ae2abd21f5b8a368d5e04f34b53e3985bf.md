# Remove Python-side field descriptor infrastructure from dataclasses
## TL;DR
- Removes `_utils.py` (Python field descriptors, repr helpers) and `field.py` (Python `Field` class) from `tvm_ffi.dataclasses`, migrating to C++-driven field access via reflection.
- Simplifies `c_class.py` to rely on the reflection-based field accessor introduced by `begin_index`.
- Removes 151-line `test_dataclasses_c_class.py` in favor of existing reflection-based tests.

## Key Exports
None -- this is a removal/simplification.

## Impact
- API: Removes `tvm_ffi.dataclasses.Field` and `tvm_ffi.dataclasses._utils` Python modules. Breaking for any code that imported these directly.
- Behavioral: `c_class` now fully delegates to C++ reflection for field access.
- Flags/config: None
- Data formats/schemas: None
