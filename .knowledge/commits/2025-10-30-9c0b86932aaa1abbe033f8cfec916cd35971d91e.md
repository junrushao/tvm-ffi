# Add example coverage and polish docstrings across Python public API
## TL;DR
- Adds copy-pastable example code blocks to docstrings across 15+ Python files: `_convert.py`, `_dtype.py`, `_tensor.py`, `access_path.py`, `container.py`, `error.py`, `module.py`, `registry.py`, `serialization.py`, `stream.py`, `lockfile.py`, and several Cython `.pxi` files.
