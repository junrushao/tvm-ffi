# Add example coverage and polish docstrings across Python public API
## TL;DR
- Adds runnable `Examples` sections (with `import tvm_ffi`) to nearly every public Python API: `convert`, `dtype`, `Module`, `system_lib`, `load_module`, `register_object`, `get_global_func`, `remove_global_func`, `get_global_func_metadata`, `use_raw_stream`, `get_raw_stream`, `to_json_graph_str`, `from_json_graph_str`, `AccessPath`, `Shape`, `FileLock`, `register_error`, `Array`, `Map`.
- Fixes a typo in `use_raw_stream` error message (`"stram"` -> `"stream"`).
- Registers `testing.add_one` as a system lib symbol in C++ to support the new `system_lib()` docstring example; updates `docs/reference/python/index.rst` to list individual API entries rather than module-level stubs.

## Key Exports

None -- this commit does not introduce or change any public API signatures.

The only functional change is a one-character typo fix in `stream.py`:

```python
# Before (stream.py line ~188):
"use_raw_stream only accepts int or c_void_p as stram input, "
# After:
"use_raw_stream only accepts int or c_void_p as stream input, "
```

## Usage Examples
None -- the commit itself is entirely about adding usage examples to existing APIs. The most architecturally informative example added is the `system_lib()` cross-layer trace (`module.py`), which demonstrates:

1. C++ side: `TVMFFIEnvModRegisterSystemLibSymbol("__tvm_ffi_testing.add_one", ...)` registers a raw C function.
2. Python side: `tvm_ffi.system_lib("testing.")["add_one"]` retrieves and calls it.
