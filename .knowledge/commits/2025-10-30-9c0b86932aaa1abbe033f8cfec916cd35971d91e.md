# Add example code and polish docstrings across the Python public API
## TL;DR
- Adds copy-pastable `Examples` sections (using `.. code-block:: python`) to nearly every public Python docstring: `convert`, `dtype`, `Shape`, `device`, `Array`, `Map`, `Function`, `Object`, `Tensor`, `from_dlpack`, `register_error`, `register_object`, `get_global_func`, `remove_global_func`, `get_global_func_metadata`, `system_lib`, `load_module`, `use_raw_stream`, `get_raw_stream`, `to_json_graph_str`, `from_json_graph_str`, `AccessPath`, `FileLock`.
- Polishes wording throughout (capitalization of "Python"/"FFI", grammar fixes, restructured `See Also` / `Returns` sections for numpydoc compliance, fixes typo "stram" -> "stream").
- Registers `__tvm_ffi_testing.add_one` as a system lib symbol in C++ to support the new `system_lib` docstring example; updates Sphinx `index.rst` to list `get_raw_stream` and expand `serialization`/`access_path` entries.

## Key Exports
None -- this commit adds documentation only and does not change any public API signatures or behavior. The sole functional addition is registering the `__tvm_ffi_testing.add_one` system-lib symbol in `src/ffi/testing/testing.cc`, which is a test-only helper used to make the `system_lib` docstring example runnable.
