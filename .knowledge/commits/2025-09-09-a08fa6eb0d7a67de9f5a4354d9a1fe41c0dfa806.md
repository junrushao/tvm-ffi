# Rename and consolidate object declaration macros, absorbing _type_key and mutable pointer logic

## TL;DR
- Renames all object declaration macros to a consistent `TVM_FFI_DECLARE_OBJECT_INFO[_FINAL|_STATIC]` pattern, adding `TypeKey` as the first parameter so the macros define `_type_key` internally.
- Consolidates four ref macros into two (`NULLABLE` / `NOTNULLABLE`) by using `std::conditional_t<ObjectName::_type_mutable, ...>` to auto-derive pointer constness, eliminating the separate `MUTABLE` variants.
- Updates all call sites (headers, tests, docs, examples) to the new macro names and signatures.

### Rename Mapping

| Old Macro | New Macro | Signature Change |
|---|---|---|
| `TVM_FFI_DECLARE_BASE_OBJECT_INFO(TypeName, ParentType)` | `TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, ParentType)` | `TypeKey` param added; absorbs `_type_key` definition |
| `TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TypeName, ParentType)` | `TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, TypeName, ParentType)` | same |
| `TVM_FFI_DECLARE_STATIC_OBJECT_INFO(TypeName, ParentType)` | `TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, TypeName, ParentType)` | same |
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS(T, P, O)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(T, P, O)` | Adds `__PtrType` conditional + `_type_is_nullable = true` |
| `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, O)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(T, P, O)` | Adds `__PtrType` conditional |
| `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS(T, P, O)` | *(removed)* | Merged into `NULLABLE` via `_type_mutable` |
| `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, O)` | *(removed)* | Merged into `NOTNULLABLE` via `_type_mutable` |
| *(new)* | `TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, ParentType)` | Internal helper for types that define `_type_key` separately |

## Key Exports

```python
# --- Declaration macros (object.h) ---

# TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, ParentType)
# Expansion (pseudocode):
#   static constexpr const char* _type_key = TypeKey;  # NEW: absorbed into macro
#   TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, ParentType)
# Interacts with: TVMFFITypeGetOrAllocIndex (dynamic index allocation)
# Invariant: ParentType must not be final

# TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, TypeName, ParentType)
# Expansion:
#   _type_child_slots = 0
#   _type_final = True
#   TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, ParentType)
# Interacts with: IsInstance fast-path (exact match for final types)

# TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, TypeName, ParentType)
# Expansion:
#   static constexpr const char* _type_key = TypeKey;  # NEW: absorbed
#   RuntimeTypeIndex() -> TypeName._type_index  (static constant)
#   TVM_FFI_REGISTER_STATIC_TYPE_INFO(TypeName, ParentType)
# Interacts with: built-in types with pre-assigned TypeIndex (Array, Map, etc.)

# TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, ParentType)
# Internal: same as old TVM_FFI_DECLARE_BASE_OBJECT_INFO
# For types that must define _type_key outside the macro (e.g., custom child_slots)

# --- Ref wrapper macros (object.h) ---

# TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(TypeName, ParentType, ObjectName)
# Expansion:
#   __PtrType = ObjectName* if ObjectName._type_mutable else const ObjectName*
#   operator->() -> __PtrType    # NEW: auto-derives constness
#   get() -> __PtrType
#   _type_is_nullable = true     # NEW: explicit marker
#   ContainerType = ObjectName
# Interacts with: _type_mutable field on the ObjectName class
# Extension: replaces both old OBJECT_REF_METHODS and MUTABLE_OBJECT_REF_METHODS

# TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(TypeName, ParentType, ObjectName)
# Expansion: same __PtrType logic but no default ctor, _type_is_nullable = false
# Interacts with: _type_mutable, UnsafeInit
```

## Impact
- API: All six old macro names are removed. All downstream C++ code must update to the new names and add `TypeKey` as the first argument to declare macros. The separate `_type_key` line must be removed.
- Behavioral: Ref macros now auto-derive pointer constness from `ObjectName::_type_mutable` via `std::conditional_t`, so `Module` (which sets `_type_mutable = true`) now gets mutable `operator->()` from `NOTNULLABLE` instead of requiring a separate `MUTABLE_NOTNULLABLE` macro. `ModuleObj` gains explicit `_type_mutable = true` in this commit.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Object type system (`_type_key`, `_type_mutable`, `_type_final`, `_type_child_slots`) — see `.knowledge/design-records/0003-ffi-object-system.md`
- `TVMFFITypeGetOrAllocIndex` C API for type registration — see `.knowledge/design-records/0001-ffi-c-abi.md`

Design elements this commit produces:
- **Macro rename**: Six old macros replaced by five new macros with consistent `TVM_FFI_DECLARE_OBJECT_INFO*` / `TVM_FFI_DEFINE_OBJECT_REF_METHODS_*` naming convention — mutates `.knowledge/design-records/0008-ffi-object-macros.md`
- **TypeKey absorption**: Declaration macros now define `_type_key` internally, reducing boilerplate from 2 lines to 1
- **Mutable pointer auto-derivation**: `__PtrType = std::conditional_t<ObjectName::_type_mutable, ObjectName*, const ObjectName*>` eliminates the need for separate mutable ref macro variants
- **`_type_is_nullable` on NULLABLE macro**: Explicit `static constexpr bool _type_is_nullable = true` added to the nullable ref macro (previously only the non-nullable variant set this field)

## Usage Examples

Before (old pattern):
```cpp
class MyNodeObj : public Object {
 public:
  int64_t value;
  static constexpr const char* _type_key = "my.Node";       // separate line
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyNodeObj, Object);      // 2-arg macro
};
class MyNode : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(MyNode, ObjectRef, MyNodeObj);
};
```

After (new pattern):
```cpp
class MyNodeObj : public Object {
 public:
  int64_t value;
  TVM_FFI_DECLARE_OBJECT_INFO_FINAL("my.Node", MyNodeObj, Object);  // 3-arg, absorbs _type_key
};
class MyNode : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(MyNode, ObjectRef, MyNodeObj);
};
```
