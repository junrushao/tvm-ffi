# Streamline Object declare/define macros: rename for consistency and unify mutable variants
## TL;DR
- Renames all `TVM_FFI_DECLARE_*` and `TVM_FFI_DEFINE_*` object macros to a consistent `VERB_OBJECT_INFO_QUALIFIER` / `VERB_OBJECT_REF_METHODS_QUALIFIER` naming scheme, folding `_type_key` declaration into the declare macros.
- Eliminates four separate mutable/immutable ref method macro variants by auto-deriving pointer constness from `ObjectName::_type_mutable` via `std::conditional_t`.
- Updates all call sites (headers, tests, docs, examples) to the new macro names.

### Rename mapping

| Old Macro | New Macro |
|---|---|
| `TVM_FFI_DECLARE_STATIC_OBJECT_INFO(TypeName, Parent)` + `_type_key = ...` | `TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, TypeName, Parent)` |
| `TVM_FFI_DECLARE_BASE_OBJECT_INFO(TypeName, Parent)` + `_type_key = ...` | `TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, Parent)` |
| `TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TypeName, Parent)` + `_type_key = ...` | `TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, TypeName, Parent)` |
| N/A | `TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, Parent)` (new intermediate) |
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS(T, P, O)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(T, P, O)` |
| `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, O)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(T, P, O)` |
| `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS(T, P, O)` | **Removed** — absorbed into `_NULLABLE` |
| `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, O)` | **Removed** — absorbed into `_NOTNULLABLE` |

## Key Exports

```python
# === Object declaration macros (C++ macros as pseudocode) ===

# TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, TypeName, ParentType):
#   static constexpr const char* _type_key = TypeKey;   # <-- newly folded in
#   static int32_t RuntimeTypeIndex() { return TypeName::_type_index; }
#   TVM_FFI_REGISTER_STATIC_TYPE_INFO(TypeName, ParentType)
# Interacts with: static type index table, TypeIndex enum

# TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, ParentType):
#   (Same as old TVM_FFI_DECLARE_BASE_OBJECT_INFO — dynamic index allocation)
#   _type_depth, _GetOrAllocRuntimeTypeIndex, RuntimeTypeIndex, _type_index
# Interacts with: TypeContext for runtime type index allocation
# Extension: Use when _type_key is already defined (e.g., from a parent or special source)

# TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, ParentType):
#   static constexpr const char* _type_key = TypeKey;
#   + TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, ParentType)
# Interacts with: TypeContext, global type registry
# Extension: Use for non-final object types that can be subclassed

# TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, TypeName, ParentType):
#   _type_child_slots = 0, _type_final = true
#   + TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, ParentType)
# Invariant: No subclass can register via the object system (IsInstance returns base type only)

# === ObjectRef definition macros (C++ macros as pseudocode) ===

# TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(TypeName, ParentType, ObjectName):
#   TypeName() = default;
#   explicit TypeName(ObjectPtr<ObjectName> n);
#   explicit TypeName(UnsafeInit tag);
#   using __PtrType = conditional_t<ObjectName::_type_mutable, ObjectName*, const ObjectName*>;
#   __PtrType operator->() const;
#   __PtrType get() const;
#   static constexpr bool _type_is_nullable = true;
#   using ContainerType = ObjectName;
# Interacts with: _type_mutable flag on ObjectName to auto-derive const/mutable
# Invariant: ObjectName::_type_mutable must be defined (defaults to false in Object base)

# TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(TypeName, ParentType, ObjectName):
#   (Same as NULLABLE but without default constructor, _type_is_nullable = false)
#   using __PtrType = conditional_t<ObjectName::_type_mutable, ObjectName*, const ObjectName*>;
# Interacts with: _type_mutable flag on ObjectName
# Invariant: Instance must always hold a valid object pointer
```

## Impact
- API: All old macro names are removed. Every downstream C++ consumer using `TVM_FFI_DECLARE_FINAL_OBJECT_INFO`, `TVM_FFI_DECLARE_BASE_OBJECT_INFO`, `TVM_FFI_DECLARE_STATIC_OBJECT_INFO`, `TVM_FFI_DEFINE_OBJECT_REF_METHODS`, `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS`, `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS`, or `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS` must migrate to the new names. The declare macros now take `TypeKey` as the first argument.
- Behavioral: `ModuleObj` gains explicit `_type_mutable = true` field; previously mutability was encoded only in the ref macro choice (`TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS`). Now the flag is the single source of truth.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Object system macro infrastructure (`.knowledge/design-records/0002-object-system.md`) — all declare/define macros
- `_type_mutable` flag on Object (0002) — now used as the single source for const/mutable dispatch
- `std::conditional_t` (C++ stdlib) — used to derive pointer type from `_type_mutable`

Design elements this commit produces:
- Unified naming convention: `TVM_FFI_DECLARE_OBJECT_INFO[_STATIC|_FINAL]` and `TVM_FFI_DEFINE_OBJECT_REF_METHODS[_NULLABLE|_NOTNULLABLE]`
- Auto-const/mutable dispatch via `__PtrType = conditional_t<ObjectName::_type_mutable, ...>` — replaces the four-way mutable/immutable x nullable/notnullable macro matrix with a two-way nullable/notnullable choice

## Usage Examples

Before (old pattern — two separate statements):
```cpp
class MyObj : public Object {
  static constexpr const char* _type_key = "my.Obj";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyObj, Object);
};
class My : public ObjectRef {
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(My, ObjectRef, MyObj);
};
```

After (new pattern — single macro, type key as argument):
```cpp
class MyObj : public Object {
  TVM_FFI_DECLARE_OBJECT_INFO_FINAL("my.Obj", MyObj, Object);
};
class My : public ObjectRef {
  TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(My, ObjectRef, MyObj);
};
```

For mutable objects (before: separate `MUTABLE` macro; after: just set `_type_mutable`):
```cpp
class MutableObj : public Object {
  static constexpr bool _type_mutable = true;
  TVM_FFI_DECLARE_OBJECT_INFO_FINAL("my.MutableObj", MutableObj, Object);
};
class Mutable : public ObjectRef {
  // Automatically returns non-const pointer because _type_mutable = true
  TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(Mutable, ObjectRef, MutableObj);
};
```
