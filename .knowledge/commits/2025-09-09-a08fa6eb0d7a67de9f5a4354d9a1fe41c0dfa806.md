# Streamline object declaration macros: rename 7 macros, absorb _type_key into declare macros, unify mutable/immutable ref macros via std::conditional_t

## TL;DR
- Renames all object declaration and ref-definition macros to a consistent `TVM_FFI_DECLARE_OBJECT_INFO[_FINAL|_STATIC]` / `TVM_FFI_DEFINE_OBJECT_REF_METHODS[_NULLABLE|_NOTNULLABLE]` naming scheme, and absorbs the `_type_key` definition into the declare macros as a first parameter.
- Collapses the four ref-definition macros (`OBJECT_REF_METHODS`, `NOTNULLABLE_OBJECT_REF_METHODS`, `MUTABLE_OBJECT_REF_METHODS`, `MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS`) into two (`NULLABLE`, `NOTNULLABLE`) by using `std::conditional_t<ObjectName::_type_mutable, ObjectName*, const ObjectName*>` to auto-select the pointer constness.
- Moves `_type_mutable = true` from `Module` ref macro side into `ModuleObj` class definition, aligning with the new macro design where mutability is a property of the Obj class, not the Ref macro choice.

## Rename Mapping

| Old Macro | New Macro | Signature Change |
|---|---|---|
| `TVM_FFI_DECLARE_BASE_OBJECT_INFO(TypeName, Parent)` | `TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, Parent)` | Added `TypeKey` param; absorbs `_type_key` |
| `TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TypeName, Parent)` | `TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, TypeName, Parent)` | Added `TypeKey` param; absorbs `_type_key` |
| `TVM_FFI_DECLARE_STATIC_OBJECT_INFO(TypeName, Parent)` | `TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, TypeName, Parent)` | Added `TypeKey` param; absorbs `_type_key` |
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS(T, P, Obj)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(T, P, Obj)` | Adds `_type_is_nullable = true`, auto-selects const via `_type_mutable` |
| `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, Obj)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(T, P, Obj)` | Auto-selects const via `_type_mutable` |
| `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS(T, P, Obj)` | (removed -- use `_NULLABLE` with `_type_mutable = true` on Obj) | Eliminated |
| `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, Obj)` | (removed -- use `_NOTNULLABLE` with `_type_mutable = true` on Obj) | Eliminated |

Internal helper introduced: `TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, Parent)` -- used when `_type_key` is already set (e.g., by the caller or a base class). Both `DECLARE_OBJECT_INFO` and `DECLARE_OBJECT_INFO_FINAL` delegate to it after setting `_type_key`.

## Impact
- API: **Breaking** -- all 7 old macro names are removed. Every call site using `TVM_FFI_DECLARE_BASE_OBJECT_INFO`, `TVM_FFI_DECLARE_FINAL_OBJECT_INFO`, `TVM_FFI_DECLARE_STATIC_OBJECT_INFO`, `TVM_FFI_DEFINE_OBJECT_REF_METHODS`, `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS`, `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS`, or `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS` must be updated. Additionally, the separate `static constexpr const char* _type_key = "..."` line must be removed from each Obj class (now part of the declare macro).
- Behavioral: `operator->()` and `get()` on ref types now auto-select `const ObjectName*` or `ObjectName*` based on `ObjectName::_type_mutable` via `std::conditional_t`, instead of being determined by which macro variant was chosen. `_type_is_nullable = true` is now explicitly set in the nullable macro (previously implicit).
- Flags/config: `ModuleObj` gains explicit `static constexpr bool _type_mutable = true` in the class body (previously this was only expressed via the mutable ref macro choice).
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (`.knowledge/designs/0002-object-system.md`): The full FooObj+Foo pattern, `_type_key`, `_type_final`, `_type_child_slots`, `_type_mutable`, `_type_is_nullable`, `_type_depth` static members.
- **C ABI** (`.knowledge/designs/0001-c-abi.md`): `TVMFFIGetOrAllocTypeIndex` for dynamic type registration.
- **Module system** (`.knowledge/designs/0011-module-system.md`): `ModuleObj` as a static-indexed mutable object.

Design elements this commit produces:
- **Consolidated macro API**: Reduces 7 macros to 5 (plus 1 internal helper), with a consistent `DECLARE_OBJECT_INFO` / `DEFINE_OBJECT_REF_METHODS` naming scheme.
- **`_type_key`-in-macro convention**: `_type_key` is no longer a separate line in the class body; it is passed as the first argument to the declare macro. This eliminates a common source of inconsistency (forgetting to define `_type_key` or mismatching it with the macro).
- **`std::conditional_t`-based mutability**: Ref macros use `ObjectName::_type_mutable` to determine pointer constness at compile time, instead of requiring users to pick the correct macro variant.

## Usage Examples

Before (old macros):
```cpp
class MyNodeObj : public Object {
 public:
  int64_t value;
  static constexpr const char* _type_key = "my.Node";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyNodeObj, Object);
};
class MyNode : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(MyNode, ObjectRef, MyNodeObj);
};
```

After (new macros):
```cpp
class MyNodeObj : public Object {
 public:
  int64_t value;
  TVM_FFI_DECLARE_OBJECT_INFO_FINAL("my.Node", MyNodeObj, Object);
};
class MyNode : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(MyNode, ObjectRef, MyNodeObj);
};
```

Before (mutable + non-nullable, e.g. Module):
```cpp
class ModuleObj : public Object {
  static constexpr const char* _type_key = StaticTypeKey::kTVMFFIModule;
  TVM_FFI_DECLARE_STATIC_OBJECT_INFO(ModuleObj, Object);
};
class Module : public ObjectRef {
  TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS(Module, ObjectRef, ModuleObj);
};
```

After (mutability on Obj, single non-nullable ref macro):
```cpp
class ModuleObj : public Object {
  static constexpr bool _type_mutable = true;
  TVM_FFI_DECLARE_OBJECT_INFO_STATIC(StaticTypeKey::kTVMFFIModule, ModuleObj, Object);
};
class Module : public ObjectRef {
  TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(Module, ObjectRef, ModuleObj);
};
```
