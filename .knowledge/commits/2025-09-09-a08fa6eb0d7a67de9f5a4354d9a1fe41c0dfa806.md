# Streamline object declaration macros: absorb _type_key into macro, unify mutable/immutable ref methods
## TL;DR
- Renames all object declaration and ref-method macros to a consistent naming scheme and absorbs `_type_key` as a macro parameter instead of a separate `static constexpr` member.
- Eliminates 4 separate `TVM_FFI_DEFINE_*_OBJECT_REF_METHODS` variants (nullable, non-nullable, mutable, mutable+non-nullable) down to 2 (`NULLABLE` and `NOTNULLABLE`) that auto-derive const/non-const pointer from `_type_mutable`.
- Adds `_type_mutable = true` to `ModuleObj` as a class-level field (previously only expressed through the mutable ref macro choice).

### Rename mapping

| Old macro | New macro |
|-----------|-----------|
| `TVM_FFI_DECLARE_BASE_OBJECT_INFO(TypeName, Parent)` | `TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, Parent)` |
| `TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TypeName, Parent)` | `TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, TypeName, Parent)` |
| `TVM_FFI_DECLARE_STATIC_OBJECT_INFO(TypeName, Parent)` | `TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, TypeName, Parent)` |
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS(T, P, O)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(T, P, O)` |
| `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, O)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(T, P, O)` |
| `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS(T, P, O)` | *(removed -- use NULLABLE)* |
| `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, O)` | *(removed -- use NOTNULLABLE)* |

- A new internal macro `TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, Parent)` is introduced for cases where `_type_key` is already defined in the class (used by `STATIC` and `OBJECT_INFO` macros internally).

## Key Exports

**Macros (declaration side -- `object.h`):**

| Macro | Parameters | Expansion summary |
|-------|-----------|-------------------|
| `TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, TypeName, ParentType)` | type key string, class name, parent class | Defines `_type_key`, `RuntimeTypeIndex()`, registers static type info |
| `TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, ParentType)` | type key string, class name, parent class | Defines `_type_key`, delegates to `PREDEFINED_TYPE_KEY` for dynamic index alloc |
| `TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, TypeName, ParentType)` | type key string, class name, parent class | Sets `_type_child_slots=0`, `_type_final=true`, delegates to `OBJECT_INFO` |
| `TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(TypeName, ParentType)` | class name, parent class | Dynamic index alloc assuming `_type_key` already defined; internal use |

**Macros (ref side -- `object.h`):**

| Macro | Parameters | Behavior change |
|-------|-----------|----------------|
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(T, P, O)` | ref name, parent ref, obj class | Auto-derives `__PtrType` via `std::conditional_t<O::_type_mutable, O*, const O*>`; sets `_type_is_nullable = true` |
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(T, P, O)` | ref name, parent ref, obj class | Same `__PtrType` derivation; sets `_type_is_nullable = false`; no default ctor |

**Key behavioral change in ref macros:** Both `NULLABLE` and `NOTNULLABLE` now use `std::conditional_t<ObjectName::_type_mutable, ObjectName*, const ObjectName*>` to derive `__PtrType`. Previously, mutability was encoded by choosing a different macro (`MUTABLE_*` vs non-mutable); now it is derived from `ObjectName::_type_mutable` at compile time. This is the primary semantic improvement: mutable/immutable is a property of the object class, not of the ref macro call site.

**New class-level field on `ModuleObj`:**
```cpp
static constexpr const bool _type_mutable = true;  // previously implicit via macro choice
```

## Impact
- API: All downstream C++ code using old macro names must migrate. The old names are removed in this commit. 16 files updated.
- ABI: None. The macros expand to the same static metadata and type registration; no C ABI struct layout changes.
- Behavioral: `operator->()` and `get()` return type on ref classes is now computed from `_type_mutable` rather than hardcoded const/non-const per macro variant. For all existing types this is equivalent.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Object dual-class pattern** (`.knowledge/designs/object-system.md`) -- The `FooObj` + `Foo` pattern with declaration macros and ref-method macros.
- **`_type_mutable` flag** (`.knowledge/designs/object-system.md`) -- Introduced in 1a85688; this commit leverages it to unify the 4 ref-method macro variants into 2.
- **`_type_key` static field** (`.knowledge/designs/object-system.md`) -- Previously user-declared; now set by the declaration macro.

Design elements this commit produces:
- **Unified declaration macro convention** -- `TVM_FFI_DECLARE_OBJECT_INFO{,_FINAL,_STATIC}(TypeKey, TypeName, Parent)` absorbs `_type_key` as the first parameter, reducing per-class boilerplate from 2 lines to 1.
- **`std::conditional_t`-based `__PtrType` in ref macros** -- Mutability is derived from `ObjectName::_type_mutable`, eliminating the need for separate mutable/immutable macro variants.
- **Explicit `_type_mutable = true` on `ModuleObj`** -- Previously, `ModuleObj` signaled mutability only through the use of `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS`. Now it declares `_type_mutable = true` as a class-level `constexpr`, making the intent explicit and allowing the unified ref macro to derive the correct pointer type.

## Usage Examples

### Before (old macros)
```cpp
class MyObj : public Object {
 public:
  int64_t x;
  static constexpr bool _type_mutable = true;
  static constexpr const char* _type_key = "my.MyObj";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyObj, Object);
};

class My : public ObjectRef {
 public:
  TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS(My, ObjectRef, MyObj);
};
```

### After (new macros)
```cpp
class MyObj : public Object {
 public:
  int64_t x;
  static constexpr bool _type_mutable = true;
  TVM_FFI_DECLARE_OBJECT_INFO_FINAL("my.MyObj", MyObj, Object);
};

class My : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(My, ObjectRef, MyObj);
};
```
The ref macro auto-derives `MyObj*` (non-const) from `MyObj::_type_mutable == true`.
