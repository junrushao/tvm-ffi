# Streamline and rename object declaration macros for clarity and consistency

## TL;DR
- Renames all object declaration and definition macros to a consistent `TVM_FFI_DECLARE_OBJECT_INFO_*` / `TVM_FFI_DEFINE_OBJECT_REF_METHODS_*` naming scheme.
- Collapses four `DEFINE_*_OBJECT_REF_METHODS` macros into two (`_NULLABLE` / `_NOTNULLABLE`) that handle both mutable and immutable via `std::conditional_t<_type_mutable, …>`.
- Moves `_type_key` assignment into the `DECLARE` macros (previously callers had to set it separately).

| Old name | New name |
|---|---|
| `TVM_FFI_DECLARE_BASE_OBJECT_INFO(T, P)` | `TVM_FFI_DECLARE_OBJECT_INFO_PREDEFINED_TYPE_KEY(T, P)` |
| `TVM_FFI_DECLARE_FINAL_OBJECT_INFO(T, P)` | `TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, T, P)` |
| `TVM_FFI_DECLARE_STATIC_OBJECT_INFO(T, P)` | `TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, T, P)` |
| `TVM_FFI_DECLARE_BASE_OBJECT_INFO(T, P)` + manual `_type_key` | `TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, T, P)` |
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS(T, P, O)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(T, P, O)` |
| `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, O)` | `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(T, P, O)` |
| `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS(T, P, O)` | merged into `_NULLABLE` via `_type_mutable` conditional |
| `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS(T, P, O)` | merged into `_NOTNULLABLE` via `_type_mutable` conditional |

## Key Exports

```python
# Macro TVM_FFI_DECLARE_OBJECT_INFO(TypeKey, TypeName, ParentType)
# Sets _type_key = TypeKey; then invokes _PREDEFINED_TYPE_KEY variant.
# Invariant: ParentType must not be marked _type_final.

# Macro TVM_FFI_DECLARE_OBJECT_INFO_FINAL(TypeKey, TypeName, ParentType)
# Sets _type_child_slots=0, _type_final=true, then calls DECLARE_OBJECT_INFO.
# Invariant: no subclasses can participate in IsInstance fast-path.

# Macro TVM_FFI_DECLARE_OBJECT_INFO_STATIC(TypeKey, TypeName, ParentType)
# Sets _type_key; uses static _type_index (no dynamic allocation).

# Macro TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(TypeName, ParentType, ObjectName)
# Emits: default ctor, ObjectPtr<> ctor, UnsafeInit ctor, copy/move/assign,
# and operator->/get() typed via std::conditional_t<_type_mutable, T*, const T*>.
# Sets _type_is_nullable = true.
# Interacts with: UnsafeInit (0002-object-system), ObjectPtr<T>, _type_mutable flag.

# Macro TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(TypeName, ParentType, ObjectName)
# Same as NULLABLE but: no default ctor, _type_is_nullable = false.
# Interacts with: TypeTraits<T>::CheckAnyStrict (0008-type-traits).
```

## Impact
- API: Breaking rename — all call sites using old macro names must be updated. Affected: `include/`, `src/`, `tests/`, `docs/`.
- Behavioral: `operator->()` and `get()` on ObjectRef types now return mutable pointer for `_type_mutable=true` types without needing a separate macro.
- Flags/config: None.
- Data formats/schemas: None.

- `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` / `_NOTNULLABLE` — unified mutable/immutable accessor macros.

## Usage Examples

Before (old macro set):
```cpp
class FooObj : public Object {
  static constexpr const char* _type_key = "Foo";
  TVM_FFI_DECLARE_BASE_OBJECT_INFO(FooObj, Object);
};
class Foo : public ObjectRef {
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(Foo, ObjectRef, FooObj);
};
```

After (new macro set):
```cpp
class FooObj : public Object {
  TVM_FFI_DECLARE_OBJECT_INFO("Foo", FooObj, Object);
};
class Foo : public ObjectRef {
  TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(Foo, ObjectRef, FooObj);
};
```
