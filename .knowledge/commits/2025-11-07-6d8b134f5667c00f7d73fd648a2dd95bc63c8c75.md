# Support load-bearing compiler flags (DLPACK_EXTRA_CFLAGS/LDFLAGS) for cross-compilation

## TL;DR
- Adds `DLPACK_EXTRA_CFLAGS` and `DLPACK_EXTRA_LDFLAGS` env vars to `_build_optional_torch_c_dlpack.py`; these are prepended to the Ninja compile/link commands.
- Needed for cross-compilation scenarios (e.g., x64 clang building for riscv64 with `--target`/`--sysroot` flags).

## Key Exports

```python
# python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py
# New env vars (read in build_ninja()):
# DLPACK_EXTRA_CFLAGS: space-separated extra compiler flags (e.g. "--target=riscv64 --sysroot=/")
# DLPACK_EXTRA_LDFLAGS: space-separated extra linker flags

def build_ninja(build_dir: str) -> None:
    """Write build.ninja and invoke ninja.
    # New: reads DLPACK_EXTRA_CFLAGS and DLPACK_EXTRA_LDFLAGS from environment
    # Invariant: extra flags are prepended so they can override defaults
    # Interacts with: os.environ, _generate_ninja_build
    """
    ...
```

## Impact
- API: none (new env vars are opt-in)
- Behavioral: Cross-compilation now works when `DLPACK_EXTRA_CFLAGS`/`DLPACK_EXTRA_LDFLAGS` are set.
- Flags/config: `DLPACK_EXTRA_CFLAGS`, `DLPACK_EXTRA_LDFLAGS` env vars
- Data formats/schemas: none

Design elements this commit consumes: `_build_optional_torch_c_dlpack` build utility (0016-py-ffi-call-dispatch)

## Usage Examples

```bash
export DLPACK_EXTRA_CFLAGS="--target=riscv64-unknown-linux-gnu --sysroot=/"
export DLPACK_EXTRA_LDFLAGS="--target=riscv64-linux-gnu --sysroot=/ -L/prefix/lib"
import tvm_ffi  # now builds successfully for riscv64 target
```
