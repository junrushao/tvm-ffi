# Add TVM_FFI_JIT_EXTRA_CFLAGS/LDFLAGS env vars for cross-compilation in dlpack JIT build
## TL;DR
- Adds `parse_env_flags()` helper that reads an env var and parses it via `shlex.split` (with fallback to `.split()`).
- Hooks `TVM_FFI_JIT_EXTRA_CFLAGS` and `TVM_FFI_JIT_EXTRA_LDFLAGS` into the JIT build pipeline in `_build_optional_torch_c_dlpack.py`, appending user-supplied compiler/linker flags to `cflags`/`ldflags` before ninja invocation.
- Enables cross-compilation scenarios (e.g., x64 clang targeting riscv64 with `--sysroot`/`--target` flags).

## Key Exports
**Functions**:
- `parse_env_flags(env_var_name: str) -> list[str]` -- reads an environment variable and shell-splits its value into a list of flags

**Environment variables** (new convention):
- `TVM_FFI_JIT_EXTRA_CFLAGS` -- extra compiler flags appended to cflags during JIT torch-c-dlpack build
- `TVM_FFI_JIT_EXTRA_LDFLAGS` -- extra linker flags appended to ldflags during JIT torch-c-dlpack build

## Impact
- API: none (no public Python/C++ API change)
- Behavioral: JIT builds now pick up extra compiler/linker flags from environment, enabling cross-compilation
- Flags/config: two new environment variables `TVM_FFI_JIT_EXTRA_CFLAGS`, `TVM_FFI_JIT_EXTRA_LDFLAGS`
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Torch C DLPack JIT build pipeline (`python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py`) -- the ninja-based build that compiles the dlpack exchange addon at import time

Design elements this commit produces:
- Environment-variable-based flag injection pattern for JIT builds -- a precedent for adding more `TVM_FFI_JIT_*` env vars

## Usage Examples
```bash
export TVM_FFI_JIT_EXTRA_CFLAGS="--target=riscv64-unknown-linux-gnu --sysroot=/"
export TVM_FFI_JIT_EXTRA_LDFLAGS="--target=riscv64-linux-gnu --sysroot=/ -L/prefix/lib"
python -c "import tvm_ffi"  # JIT build now succeeds with cross-compilation flags
```
