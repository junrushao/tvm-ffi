# Add TVM_FFI_JIT_EXTRA_CFLAGS/LDFLAGS env vars for cross-compilation support in torch C DLPack JIT build
## TL;DR
- Adds `TVM_FFI_JIT_EXTRA_CFLAGS` and `TVM_FFI_JIT_EXTRA_LDFLAGS` environment variables to inject compiler/linker flags into the torch C DLPack extension JIT build.
- Adds `parse_env_flags()` helper that uses `shlex.split` for shell-aware flag parsing with a `str.split()` fallback.
- Fixes cross-compilation scenarios (e.g., x64 clang targeting riscv64 inside a foreign build root) where `--sysroot` and `--target` flags are mandatory.

## Impact
- API: Two new environment variables (`TVM_FFI_JIT_EXTRA_CFLAGS`, `TVM_FFI_JIT_EXTRA_LDFLAGS`) form a public configuration surface for the JIT build. No Python API signature changes.
- Behavioral: The torch C DLPack JIT build now respects user-provided compiler and linker flags, enabling cross-compilation and custom sysroot scenarios that previously failed.
- Flags/config: `TVM_FFI_JIT_EXTRA_CFLAGS` and `TVM_FFI_JIT_EXTRA_LDFLAGS` are new environment-variable-based configuration knobs.
- Data formats/schemas: none

## Usage Examples
Cross-compilation scenario (from commit message):
```bash
# Set up cross-compilation flags before importing tvm_ffi
export TVM_FFI_JIT_EXTRA_CFLAGS="--target=riscv64-unknown-linux-gnu --sysroot=/"
export TVM_FFI_JIT_EXTRA_LDFLAGS="--target=riscv64-linux-gnu --sysroot=/ -L/prefix/lib"

# Now the JIT build of the torch C DLPack extension will use these flags
python -c "import tvm_ffi"
```
