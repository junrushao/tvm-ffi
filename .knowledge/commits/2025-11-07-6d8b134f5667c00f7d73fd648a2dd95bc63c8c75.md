# Add DLPACK_EXTRA_CFLAGS/LDFLAGS support for cross-compilation
## TL;DR
- Adds environment variable support for `DLPACK_EXTRA_CFLAGS` and `DLPACK_EXTRA_LDFLAGS` in the torch c dlpack build script
- Enables cross-compilation scenarios (e.g., x64 clang targeting riscv64 with `--sysroot` and `--target`)
- Fixes broken flashinfer builds that depend on tvm-ffi in cross-compilation environments

## Key Exports
```python
# Environment variables (new)
# DLPACK_EXTRA_CFLAGS: extra compiler flags passed to dlpack build (e.g., "--target=riscv64-unknown-linux-gnu --sysroot=/")
# DLPACK_EXTRA_LDFLAGS: extra linker flags passed to dlpack build
# Interacts with: _build_optional_torch_c_dlpack.py build_ninja()
```

## Impact
- API: None (environment variable config)
- Behavioral: Cross-compilation now works for torch c dlpack extension
- Flags/config: New `DLPACK_EXTRA_CFLAGS`, `DLPACK_EXTRA_LDFLAGS` env vars
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- Torch C DLPack build utility (e6a654a)

Design elements this commit produces:
- `DLPACK_EXTRA_CFLAGS`/`DLPACK_EXTRA_LDFLAGS` environment variable protocol

## Usage Examples
```bash
export DLPACK_EXTRA_CFLAGS="--target=riscv64-unknown-linux-gnu --sysroot=/"
export DLPACK_EXTRA_LDFLAGS="--target=riscv64-linux-gnu --sysroot=/ -L/prefix/lib"
python -c "import tvm_ffi"  # now builds successfully in cross-compilation
```
