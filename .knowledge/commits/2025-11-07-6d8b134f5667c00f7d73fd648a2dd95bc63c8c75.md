# Add TVM_FFI_JIT_EXTRA_CFLAGS/LDFLAGS env vars for cross-compilation of DLPack JIT extension

## TL;DR
- Introduces two environment variables (`TVM_FFI_JIT_EXTRA_CFLAGS`, `TVM_FFI_JIT_EXTRA_LDFLAGS`) that inject user-supplied compiler/linker flags into the DLPack Torch C extension JIT build.
- Adds `parse_env_flags()` helper that parses env var values via `shlex.split` (with `str.split` fallback) for shell-correct flag tokenization.
- Fixes cross-compilation scenarios (e.g., x86_64 host clang targeting riscv64 sysroot) where `--sysroot` and `--target` flags are required but were not passed through to the ninja build.

## Impact
- API: Two new environment variables (`TVM_FFI_JIT_EXTRA_CFLAGS`, `TVM_FFI_JIT_EXTRA_LDFLAGS`) as public configuration surface for the JIT build. No Python API changes.
- Behavioral: Cross-compilation with load-bearing compiler flags (e.g., `--sysroot`, `--target`) now works for the DLPack Torch C extension JIT build. Previously, `import tvm_ffi` would fail in such environments.
- Flags/config: `TVM_FFI_JIT_EXTRA_CFLAGS` and `TVM_FFI_JIT_EXTRA_LDFLAGS` are new.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **DLPack Torch C extension JIT build pipeline** (`python/tvm_ffi/utils/_build_optional_torch_c_dlpack.py`): the `main()` -> `_generate_ninja_build()` -> `build_ninja()` flow that JIT-compiles inline C++ into a shared library at import time. See `.knowledge/designs/0011-module-system.md` and `.knowledge/ADRs/0015-dlpack-exchange-api-struct.md`.
- **Ninja-based JIT compilation** (`_generate_ninja_build`): the function that writes `build.ninja` with `cflags`/`ldflags` variables, documented in `.knowledge/designs/0011-module-system.md`.

Design elements this commit produces:
- **`parse_env_flags()` utility**: A reusable helper for shell-correct parsing of environment variable flag strings. Currently only used in `_build_optional_torch_c_dlpack.py` but pattern is general.
- **`TVM_FFI_JIT_EXTRA_CFLAGS` / `TVM_FFI_JIT_EXTRA_LDFLAGS` configuration knobs**: Environment-variable-driven flag injection into the JIT build pipeline.

## Usage Examples

Cross-compilation scenario (from commit message):
```bash
# Set up cross-compilation flags for riscv64 target using x86_64 host clang
export TVM_FFI_JIT_EXTRA_CFLAGS="--target=riscv64-unknown-linux-gnu --sysroot=/"
export TVM_FFI_JIT_EXTRA_LDFLAGS="--target=riscv64-linux-gnu --sysroot=/ -L/prefix/lib"

# Now import succeeds -- flags are injected into the ninja build
python -c "import tvm_ffi"
```
