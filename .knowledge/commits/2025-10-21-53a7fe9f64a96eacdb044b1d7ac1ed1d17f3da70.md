# Fix OSError crash in get_dll_directories when PATH contains inaccessible entries
## TL;DR
- Wraps `path.is_dir()` and `path.resolve()` in `get_dll_directories()` with a `try/except OSError` to silently skip inaccessible paths from environment variables like `PATH`, `LD_LIBRARY_PATH`, and `DYLD_LIBRARY_PATH`.
- Prevents a crash during library discovery when the system PATH contains directories the process lacks permission to access.

## Key Exports
None — no public API change. The function signature and return type of `get_dll_directories()` are unchanged.

## Impact
- API: none
- Behavioral: `get_dll_directories()` no longer raises `OSError` when encountering inaccessible directories; it silently skips them.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit produces: None

## Usage Examples
Before (crash scenario):
```python
# If /some/restricted/path is in PATH but not readable:
# get_dll_directories() -> raises OSError
```

After (resilient):
```python
# /some/restricted/path is silently skipped
dirs = get_dll_directories()
# dirs contains only accessible, resolvable directories
```
