# Robustify libinfo finding

## TL;DR
- Wraps `path.is_dir()` and `path.resolve()` in `get_dll_directories()` with a `try/except OSError` to handle inaccessible directories (e.g., permission-denied paths on `PATH`).
- Previously, an `OSError` from `Path.resolve()` on an inaccessible directory would crash the entire import of `tvm_ffi`.

## Key Exports
None (internal fix, no API change).

## Impact
- API: None.
- Behavioral: `get_dll_directories()` now silently skips directories that raise `OSError` during `is_dir()` or `resolve()`, instead of crashing. This makes `import tvm_ffi` more robust on systems with inaccessible paths in `PATH`/`LD_LIBRARY_PATH`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **`get_dll_directories()`** (`python/tvm_ffi/libinfo.py`): The DLL search path resolver used by `find_libtvm_ffi()` during package import. See `.knowledge/designs/0014-python-package.md`.

Design elements this commit produces: None (bug fix to existing function).

## Usage Examples

Before (crash):
```python
# If PATH contains /some/inaccessible/dir with restricted permissions:
import tvm_ffi  # -> OSError: [Errno 13] Permission denied: '/some/inaccessible/dir'
```

After (silent skip):
```python
import tvm_ffi  # works; inaccessible dirs silently skipped
```
