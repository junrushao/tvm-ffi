# Robustify libinfo DLL directory discovery to ignore OSError from inaccessible paths

## TL;DR
- `get_dll_directories()` in `python/tvm_ffi/libinfo.py` now wraps each `path.is_dir()` + `path.resolve()` call in a `try/except OSError` to silently skip paths the process lacks permission to access.

## Key Exports
None

## Impact
- API: none — internal function.
- Behavioral: Paths in `PATH` / `LD_LIBRARY_PATH` that raise `OSError` (e.g., permission denied during `resolve()`) are now silently skipped rather than raising an exception during library discovery.
- Flags/config: none
- Data formats/schemas: none
