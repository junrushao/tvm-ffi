# Robustify libinfo DLL path resolution against OSError on inaccessible directories
## TL;DR
- Wraps `path.is_dir()` and `path.resolve()` in `get_dll_directories()` with a `try/except OSError` to skip paths the process lacks permission to access.
- Prevents an unhandled `OSError` crash during library discovery when `PATH` or `LD_LIBRARY_PATH` contains inaccessible directories.

## Key Exports
None -- no new API surface; behavioral fix to an existing internal function.

## Impact
- API: None
- Behavioral: `get_dll_directories()` now silently skips directories that raise `OSError` during `is_dir()` or `resolve()`, instead of crashing. This affects library loading at import time.
- Flags/config: None
- Data formats/schemas: None

## Usage Examples
Before (crash on inaccessible path in `PATH`):
```python
# If PATH contains e.g. /some/nfs/mount the user can't access:
# OSError: [Errno 13] Permission denied: '/some/nfs/mount'
get_dll_directories()  # raises OSError
```

After (graceful skip):
```python
# Same environment, but inaccessible paths are silently skipped
get_dll_directories()  # returns list of accessible directories only
```
