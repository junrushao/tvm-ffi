# Introduce tvm_ffi_configure_target and tvm_ffi_install CMake functions for simplified downstream integration
## TL;DR
- Adds `tvm_ffi_configure_target()` CMake function: a single call that links headers/shared lib, applies prefix map, dsymutil, MSVC flags, and optionally runs `tvm-ffi-stubgen` as a post-build step.
- Adds `tvm_ffi_install()` CMake function: installs platform-specific debug artifacts (Apple dSYM bundles).
- Simplifies the packaging example from ~50 lines of manual CMake to 3 lines: `tvm_ffi_configure_target(... STUB_DIR ... STUB_INIT ON)`, `install(TARGETS ...)`, `tvm_ffi_install(...)`.

## Key Exports

**CMake functions** (in `cmake/Utils/Library.cmake`):

`tvm_ffi_configure_target(target [LINK_SHARED ON|OFF] [LINK_HEADER ON|OFF] [DEBUG_SYMBOL ON|OFF] [MSVC_FLAGS ON|OFF] [STUB_INIT ON|OFF] [STUB_DIR <dir>] [STUB_PKG <pkg>] [STUB_PREFIX <prefix>])`
- **Always-on**: calls `tvm_ffi_add_prefix_map(target, CMAKE_CURRENT_SOURCE_DIR)`.
- **LINK_HEADER** (default ON): `target_link_libraries(target PRIVATE tvm_ffi_header)`.
- **LINK_SHARED** (default ON): `target_link_libraries(target PRIVATE tvm_ffi_shared)`.
- **DEBUG_SYMBOL** (default ON): On Apple, calls `tvm_ffi_add_apple_dsymutil(target)`.
- **MSVC_FLAGS** (default ON): calls `tvm_ffi_add_msvc_flags(target)`.
- **STUB_DIR**: When set, adds post-build command running `python -m tvm_ffi.stub.cli <STUB_DIR> --dlls <target_file>`.
- **STUB_INIT** (default OFF): When ON (requires STUB_DIR), adds `--init-lib`, `--init-pypkg`, `--init-prefix` flags to stubgen. STUB_PKG defaults to `SKBUILD_PROJECT_NAME` or target name. STUB_PREFIX defaults to `"${STUB_PKG}."`.
- Validation: STUB_PKG/STUB_PREFIX require STUB_DIR. STUB_INIT=ON requires STUB_DIR.

`tvm_ffi_install(target [DESTINATION <dir>])`
- On Apple: installs `$<TARGET_FILE:target>.dSYM` bundle to DESTINATION (default `"."`), using `OPTIONAL`.
- On non-Apple: currently a no-op.

**Minor behavioral change** to `tvm_ffi_add_apple_dsymutil()`: removed guard on `TVM_FFI_USE_LIBBACKTRACE`; now runs unconditionally on Apple.

## Impact
- API: Two new public CMake functions. `tvm_ffi_add_apple_dsymutil` no longer requires `TVM_FFI_USE_LIBBACKTRACE`.
- Behavioral: Downstream CMake consumers using `find_package(tvm_ffi)` get `tvm_ffi_configure_target` and `tvm_ffi_install` available automatically.
- Flags/config: `TVM_FFI_EXT_FROM_SOURCE` and `TVM_FFI_EXT_SHIP_DEBUG_SYMBOLS` CMake options removed from the packaging example (they were example-specific, not library-level).
- Data formats/schemas: none

Design elements this commit produces:
- **`tvm_ffi_configure_target`**: A single-call integration point (analogous to `pybind11_add_module`/`nanobind_add_module`) that bundles linking, debug symbols, and stub generation for downstream targets.
- **`tvm_ffi_install`**: Platform-aware install helper for debug artifacts.
- **Post-build stubgen integration**: Automates `tvm-ffi-stubgen` as a CMake post-build step, removing the need for manual CLI invocation.

## Usage Examples

**Minimal downstream CMakeLists.txt** (from `examples/packaging/CMakeLists.txt`):
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
add_library(my_ffi_extension SHARED src/extension.cc)
tvm_ffi_configure_target(my_ffi_extension STUB_DIR "./python" STUB_INIT ON)
install(TARGETS my_ffi_extension DESTINATION .)
tvm_ffi_install(my_ffi_extension)
```
This replaces ~50 lines of manual `target_link_libraries`, `tvm_ffi_add_prefix_map`, `tvm_ffi_add_apple_dsymutil`, and install logic.
