# Introduce tvm_ffi_configure_target and tvm_ffi_install CMake functions
## TL;DR
- Adds `tvm_ffi_configure_target` and `tvm_ffi_install` CMake utility functions for easier integration of TVM FFI in downstream projects.
- Simplifies the CMake boilerplate needed to build TVM FFI extensions.

## Key Exports

**CMake Functions:**
- `tvm_ffi_configure_target(target)` -- Configure a CMake target to use TVM FFI headers and link settings.
- `tvm_ffi_install(target ...)` -- Install a TVM FFI extension target with proper RPATH and packaging.

## Usage Examples
```cmake
find_package(tvm_ffi REQUIRED)
add_library(my_extension SHARED src/my_ext.cc)
tvm_ffi_configure_target(my_extension)
tvm_ffi_install(my_extension)
```
