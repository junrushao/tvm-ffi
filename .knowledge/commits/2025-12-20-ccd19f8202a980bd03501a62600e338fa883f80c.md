# Introduce tvm_ffi_configure_target and tvm_ffi_install CMake convenience functions for downstream integration
## TL;DR
- Adds `tvm_ffi_configure_target()` CMake function that bundles link setup (header + shared lib), prefix map, Apple dSYM, MSVC flags, and post-build stub generation into a single call with ON/OFF keyword parameters.
- Adds `tvm_ffi_install()` CMake function that handles platform-specific install artifacts (Apple dSYM bundles) for a configured target.
- Simplifies the `examples/packaging/` CMakeLists.txt from ~50 lines of manual wiring to 3 lines using the new functions, and removes the now-unnecessary source-build option from the example.
- Minor: removes `TVM_FFI_USE_LIBBACKTRACE` guard from `tvm_ffi_add_apple_dsymutil` (dsymutil now always runs on Apple), and fixes library name in the packaging example from `"my-ffi-extension"` to `"my_ffi_extension"`.

## Key Exports

```python
# === tvm_ffi_configure_target (cmake/Utils/Library.cmake) ===
# CMake function: tvm_ffi_configure_target(target_name, ...)
# Analogous to pybind11_add_module / nanobind_add_module.
#
# Parameters (all keyword, ON/OFF-style unless noted):
#   LINK_SHARED:  Link tvm_ffi_shared (default: ON)
#   LINK_HEADER:  Link tvm_ffi_header (default: ON)
#   DEBUG_SYMBOL: Enable dsymutil on Apple (default: ON)
#   MSVC_FLAGS:   Apply MSVC-specific flags (default: ON)
#   STUB_DIR:     Directory for Python stub generation (triggers stub gen when set)
#   STUB_INIT:    Allow generating new stub directives (default: OFF)
#   STUB_PKG:     Package name for stub generator (default: SKBUILD_PROJECT_NAME or target)
#   STUB_PREFIX:  Module prefix for stub generator (default: "${STUB_PKG}.")
#
# Always-on behaviors:
#   - tvm_ffi_add_prefix_map(target, CMAKE_CURRENT_SOURCE_DIR)
#
# Interacts with: tvm_ffi_add_prefix_map, tvm_ffi_add_apple_dsymutil,
#   tvm_ffi_add_msvc_flags, tvm_ffi_header, tvm_ffi_shared targets,
#   Python3 Interpreter (for stub generation), tvm_ffi.stub.cli
# Invariant: target must already exist as a CMake target
# Extension: add new keyword params for future build hooks (e.g., sanitizers)

# === tvm_ffi_install (cmake/Utils/Library.cmake) ===
# CMake function: tvm_ffi_install(target_name, [DESTINATION <dir>])
# Installs platform-specific debug artifacts alongside the target.
#
# Parameters:
#   DESTINATION: Install dir relative to CMAKE_INSTALL_PREFIX (default: ".")
#
# Behavior:
#   - Apple: installs .dSYM bundle (OPTIONAL -- does not fail if absent)
#   - Non-Apple: currently no-op
#
# Interacts with: tvm_ffi_configure_target (pair them: configure generates, install ships)
# Invariant: target must already exist
# Extension: extend for PDB on Windows, DWARF split on Linux
```

## Impact
- API: Two new CMake public functions (`tvm_ffi_configure_target`, `tvm_ffi_install`) added to `cmake/Utils/Library.cmake`. Downstream projects using `find_package(tvm_ffi)` gain access to these via the auto-included `Utils/Library.cmake`.
- Behavioral: `tvm_ffi_add_apple_dsymutil` no longer requires `TVM_FFI_USE_LIBBACKTRACE` to be ON; dsymutil now runs unconditionally on Apple. This is a broadening change -- projects that previously did not get dSYMs because `TVM_FFI_USE_LIBBACKTRACE` was OFF will now get them.
- Flags/config: `TVM_FFI_EXT_FROM_SOURCE` and `TVM_FFI_EXT_SHIP_DEBUG_SYMBOLS` options removed from the packaging example (they were example-local, not part of the core CMake API). The example now only uses `find_package(tvm_ffi)` (pre-built path).
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **CMake utility functions** (`tvm_ffi_add_prefix_map`, `tvm_ffi_add_apple_dsymutil`, `tvm_ffi_add_msvc_flags`) from `cmake/Utils/Library.cmake` -- the new `tvm_ffi_configure_target` orchestrates these existing primitives.
- **CMake imported targets** (`tvm_ffi_header`, `tvm_ffi_shared`) from `cmake/tvm_ffi-config.cmake` -- linked via the new function's `LINK_HEADER`/`LINK_SHARED` flags.
- **Stub generation CLI** (`tvm_ffi.stub.cli`) -- invoked as a post-build custom command when `STUB_DIR` is set. See [0013-packaging.md](../designs/0013-packaging.md).
- **Extension packaging pattern** from [0013-packaging.md](../designs/0013-packaging.md) -- the example is rewritten to use the new convenience functions.

Design elements this commit produces:
- **`tvm_ffi_configure_target` CMake function** -- a high-level integration point that replaces manual `target_link_libraries` + `tvm_ffi_add_prefix_map` + `tvm_ffi_add_apple_dsymutil` + `tvm_ffi_add_msvc_flags` calls with a single call. Analogous to `pybind11_add_module` / `nanobind_add_module`.
- **`tvm_ffi_install` CMake function** -- platform-aware install helper for debug artifacts (Apple dSYM). Designed to pair with `tvm_ffi_configure_target`.

## Usage Examples

Before (manual wiring in downstream CMakeLists.txt):
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
add_library(my_ext SHARED src/extension.cc)
target_link_libraries(my_ext tvm_ffi_header)
target_link_libraries(my_ext tvm_ffi_shared)
tvm_ffi_add_prefix_map(my_ext ${CMAKE_CURRENT_SOURCE_DIR})
tvm_ffi_add_apple_dsymutil(my_ext)
# Manual stub generation, manual dSYM install...
install(TARGETS my_ext DESTINATION .)
install(DIRECTORY ${CMAKE_CURRENT_BINARY_DIR}/ DESTINATION . FILES_MATCHING PATTERN "*.dSYM")
```

After (using new convenience functions):
```cmake
find_package(tvm_ffi CONFIG REQUIRED)
add_library(my_ext SHARED src/extension.cc)
tvm_ffi_configure_target(my_ext STUB_DIR "./python" STUB_INIT ON)
install(TARGETS my_ext DESTINATION .)
tvm_ffi_install(my_ext)
```
