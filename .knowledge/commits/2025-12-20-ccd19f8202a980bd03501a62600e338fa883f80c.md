# CMake gains tvm_ffi_configure_target and tvm_ffi_install helpers
## TL;DR
- Introduces `tvm_ffi_configure_target` and `tvm_ffi_install` CMake functions in `cmake/Utils/Library.cmake` to simplify integrating downstream targets with TVM-FFI (analogous to `pybind11_add_module`/`nanobind_add_module`).
- Replaces manual boilerplate in `examples/packaging/CMakeLists.txt` with the new helper functions.

## Impact
- API: New public CMake API (`tvm_ffi_configure_target`, `tvm_ffi_install`). Downstream CMake consumers benefit.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Module export system** (`.knowledge/designs/0008-module-export-system.md`): The helper configures targets to export `__tvm_ffi_*` symbols correctly.
- **Packaging and build** (`.knowledge/designs/0016-packaging-and-build.md`): Extends the CMake integration layer.

Design elements this commit produces:
- **CMake helper functions**: `tvm_ffi_configure_target` sets compile definitions, visibility, and symbol prefix; `tvm_ffi_install` handles install rules. These are new extension points for downstream packages.
