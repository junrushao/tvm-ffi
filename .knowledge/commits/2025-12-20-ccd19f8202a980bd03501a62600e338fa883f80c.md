# Introduce tvm_ffi_configure_target and tvm_ffi_install CMake helpers for extension integration
## TL;DR
- Adds `tvm_ffi_configure_target()` CMake function that bundles header/shared linking, prefix map, debug symbols, MSVC flags, and stub generation into a single call with keyword ON/OFF toggles.
- Adds `tvm_ffi_install()` CMake function that handles platform-specific artifact installation (currently Apple dSYM bundles).
- Simplifies `examples/packaging/CMakeLists.txt` from ~50 lines to ~5 by replacing manual `target_link_libraries`, `tvm_ffi_add_prefix_map`, `tvm_ffi_add_apple_dsymutil`, and `install(DIRECTORY ... *.dSYM)` calls with the two new functions.
- Removes `TVM_FFI_USE_LIBBACKTRACE` guard from `tvm_ffi_add_apple_dsymutil` -- dsymutil now runs unconditionally on Apple platforms.
- Fixes library name typo in example: `"my-ffi-extension"` changed to `"my_ffi_extension"` (underscores, matching Python module name).

## Key Exports

```python
# --- cmake/Utils/Library.cmake ---

# tvm_ffi_configure_target: one-stop configuration for TVM-FFI extension targets.
# Analogous to pybind11_add_module / nanobind_add_module.
def tvm_ffi_configure_target(
    target: str,               # Existing CMake target (positional, required)
    LINK_SHARED: bool = True,  # Link tvm_ffi_shared into target
    LINK_HEADER: bool = True,  # Link tvm_ffi_header into target
    DEBUG_SYMBOL: bool = True, # Apple: run dsymutil post-build; non-Apple: no-op
    MSVC_FLAGS: bool = True,   # Apply MSVC-specific compile flags
    STUB_INIT: bool = False,   # Generate new stub directives (requires STUB_DIR)
    STUB_DIR: str = None,      # Directory for Python stub generation
    STUB_PKG: str = None,      # Package name for stubs (default: SKBUILD_PROJECT_NAME or target)
    STUB_PREFIX: str = None,   # Module prefix for stubs (default: "<STUB_PKG>.")
) -> None: ...
    # Interacts with: tvm_ffi_header, tvm_ffi_shared (link targets),
    #   tvm_ffi_add_prefix_map, tvm_ffi_add_apple_dsymutil, tvm_ffi_add_msvc_flags (internal),
    #   tvm_ffi.stub.cli (Python stub generator, invoked as post-build command)
    # Invariant: target must already exist (created via add_library).
    # Invariant: STUB_PKG/STUB_PREFIX require STUB_DIR to be set.
    # Invariant: STUB_PKG/STUB_PREFIX require STUB_INIT=ON.
    # Invariant: STUB_INIT=ON requires STUB_DIR to be set.
    # Extension: Add new keyword args for future platform-specific behaviors.

# tvm_ffi_install: install TVM-FFI artifacts for a configured target.
def tvm_ffi_install(
    target: str,               # Existing CMake target (positional, required)
    DESTINATION: str = ".",    # Install directory relative to CMAKE_INSTALL_PREFIX
) -> None: ...
    # Interacts with: CMake install(), Apple dSYM bundles
    # Invariant: target must already exist.
    # Extension: Add PDB/DWARF packaging for non-Apple platforms.
```

## Impact
- API: Two new public CMake functions (`tvm_ffi_configure_target`, `tvm_ffi_install`) in `cmake/Utils/Library.cmake`. Existing lower-level functions (`tvm_ffi_add_prefix_map`, `tvm_ffi_add_apple_dsymutil`, `tvm_ffi_add_msvc_flags`) remain available but are now wrapped by `tvm_ffi_configure_target`.
- Behavioral: `tvm_ffi_add_apple_dsymutil` no longer checks `TVM_FFI_USE_LIBBACKTRACE` -- dsymutil runs unconditionally on Apple. This is a behavioral change for projects that set `TVM_FFI_USE_LIBBACKTRACE=OFF` and previously relied on the guard to skip dsymutil.
- Flags/config: `TVM_FFI_EXT_FROM_SOURCE` and `TVM_FFI_EXT_SHIP_DEBUG_SYMBOLS` options removed from the packaging example. The from-source build mode is removed from the example CMakeLists.txt (only `find_package` mode remains).
- Data formats/schemas: none

Design elements this commit produces:
- `tvm_ffi_configure_target()` -- new high-level CMake function that bundles all TVM-FFI target configuration into a single call. Becomes the canonical way to set up extension targets.
- `tvm_ffi_install()` -- new CMake function for platform-aware installation of TVM-FFI artifacts (currently Apple dSYM bundles).

## Usage Examples
**Context**: Setting up a C++ extension that links TVM-FFI and generates Python stubs, replacing the previous multi-line manual configuration.

```cmake
# Before (manual configuration):
add_library(my_ffi_extension SHARED src/extension.cc)
target_link_libraries(my_ffi_extension tvm_ffi_header)
target_link_libraries(my_ffi_extension tvm_ffi_shared)
tvm_ffi_add_prefix_map(my_ffi_extension ${CMAKE_CURRENT_SOURCE_DIR})
tvm_ffi_add_apple_dsymutil(my_ffi_extension)
install(DIRECTORY ${CMAKE_CURRENT_BINARY_DIR}/ DESTINATION . FILES_MATCHING PATTERN "*.dSYM")
install(TARGETS my_ffi_extension DESTINATION .)

# After (using new helpers):
add_library(my_ffi_extension SHARED src/extension.cc)
tvm_ffi_configure_target(my_ffi_extension STUB_DIR "./python" STUB_INIT ON)
install(TARGETS my_ffi_extension DESTINATION .)
tvm_ffi_install(my_ffi_extension)
```
