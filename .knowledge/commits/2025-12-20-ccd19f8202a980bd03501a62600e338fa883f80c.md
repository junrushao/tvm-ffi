# Introduce tvm_ffi_configure_target and tvm_ffi_install CMake convenience functions

## TL;DR
- Adds `tvm_ffi_configure_target(target ...)` to `cmake/Utils/Library.cmake`: a single function that wires up `tvm_ffi_header`/`tvm_ffi_shared` linking, prefix-map, Apple dSYM generation, MSVC flags, and optional Python stub generation in one call (inspired by `pybind11_add_module` / `nanobind_add_module`).
- Adds `tvm_ffi_install(target [DESTINATION <dir>])` to install Apple dSYM bundles.
- Simplifies the packaging example `CMakeLists.txt` from ~50 lines of manual boilerplate to 3 lines; also fixes a 1-line bugfix in `_ffi_api.py` (`"my-ffi-extension"` → `"my_ffi_extension"`).

## Key Exports

```python
# cmake/Utils/Library.cmake

def tvm_ffi_configure_target(
    target: str,
    LINK_SHARED: bool = True,    # link tvm_ffi_shared; FATAL_ERROR if target missing
    LINK_HEADER: bool = True,    # link tvm_ffi_header; FATAL_ERROR if target missing
    DEBUG_SYMBOL: bool = True,   # Apple: calls tvm_ffi_add_apple_dsymutil(target); no-op elsewhere
    MSVC_FLAGS: bool = True,     # calls tvm_ffi_add_msvc_flags(target)
    STUB_DIR: str = "",          # if set, adds POST_BUILD stub-gen command; absolute or relative to CMAKE_CURRENT_SOURCE_DIR
    STUB_INIT: bool = False,     # if ON, also passes --init-lib/--init-pypkg/--init-prefix to stub CLI
    STUB_PKG: str = "",          # requires STUB_INIT=ON and STUB_DIR; default: SKBUILD_PROJECT_NAME or target
    STUB_PREFIX: str = "",       # requires STUB_INIT=ON; default: "${STUB_PKG}."
) -> None:
    """
    Configure an existing CMake target for TVM-FFI integration.
    Always-on: tvm_ffi_add_prefix_map(target, CMAKE_CURRENT_SOURCE_DIR)
    Interacts with: tvm_ffi_add_prefix_map, tvm_ffi_add_apple_dsymutil, tvm_ffi_add_msvc_flags,
                    tvm_ffi_header CMake target, tvm_ffi_shared CMake target,
                    tvm_ffi.stub.cli (Python -m tvm_ffi.stub.cli)
    Invariant: target must be an existing CMake target (FATAL_ERROR otherwise)
    Invariant: STUB_PKG/STUB_PREFIX require both STUB_DIR set and STUB_INIT=ON (FATAL_ERROR otherwise)
    Extension: add new optional behavior behind new ON/OFF keyword args following the same pattern
    """

def tvm_ffi_install(
    target: str,
    DESTINATION: str = ".",  # relative to CMAKE_INSTALL_PREFIX
) -> None:
    """
    Install TVM-FFI artifacts for a configured target.
    Apple: installs $<TARGET_FILE:target>.dSYM bundle (OPTIONAL — no failure if absent).
    Non-Apple: currently no-op.
    Interacts with: tvm_ffi_configure_target (must be called first for dSYM to exist)
    Invariant: Does NOT generate dSYMs — only installs them. Pair with tvm_ffi_configure_target(DEBUG_SYMBOL ON).
    """

# Behavioral change (existing function):
# tvm_ffi_add_apple_dsymutil(target):
#   OLD: if (APPLE AND TVM_FFI_USE_LIBBACKTRACE)
#   NEW: if (APPLE)
#   Impact: dSYM generation now runs on Apple regardless of TVM_FFI_USE_LIBBACKTRACE flag.
```

## Impact
- API: `tvm_ffi_configure_target` and `tvm_ffi_install` are new CMake functions exported in `Library.cmake`; downstream projects using `find_package(tvm_ffi CONFIG REQUIRED)` gain access immediately.
- Behavioral: `tvm_ffi_add_apple_dsymutil` no longer checks `TVM_FFI_USE_LIBBACKTRACE`; Apple builds always run `dsymutil` post-build. Projects that intentionally disabled libbacktrace on Apple while relying on no-dSYM will now get dSYM generation.
- Flags/config: `STUB_DIR`, `STUB_INIT`, `STUB_PKG`, `STUB_PREFIX` replace previously manual stub-gen POST_BUILD command wiring.
- Data formats/schemas: none.

## Usage Examples

**Context**: downstream packaging example using the new API (from `examples/packaging/CMakeLists.txt`).

```cmake
find_package(tvm_ffi CONFIG REQUIRED)
add_library(my_ffi_extension SHARED src/extension.cc)

# One-liner replaces ~40 lines of manual boilerplate:
# - links tvm_ffi_header + tvm_ffi_shared
# - applies prefix map + Apple dSYM + MSVC flags
# - adds POST_BUILD Python stub generation into ./python
tvm_ffi_configure_target(my_ffi_extension STUB_DIR "./python" STUB_INIT ON)

install(TARGETS my_ffi_extension DESTINATION .)
tvm_ffi_install(my_ffi_extension)  # installs dSYM bundle on Apple
```
