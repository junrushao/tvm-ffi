# Refactor Map ABI to use MSB tag in slots_ for SmallMap/DenseMap dispatch

## TL;DR
- Repurposes the most significant bit (bit 63) of `MapObj::slots_` as a layout tag: MSB set indicates `SmallMapObj`, MSB clear indicates `DenseMapObj`.
- Replaces the old dispatch heuristic (`slots_ <= SmallMapObj::kMaxSize`) with an explicit `IsSmallMap()` predicate, decoupling the small/dense boundary from the `kMaxSize` constant.
- Adds accessor methods `NumSlots()` on both `SmallMapObj` and `DenseMapObj` that mask off the tag bit, and private setters `SetSlotsAndSmallLayoutTag()`/`SetSlotsAndDenseLayoutTag()` that enforce correct tagging on construction.

## Key Exports

```python
class MapObj:
    """Base class for SmallMapObj and DenseMapObj."""
    slots_: uint64
    # Invariant (NEW): MSB (bit 63) is a layout tag. 1 = SmallMap, 0 = DenseMap.
    # Invariant: raw slot count is stored in bits [0..62].
    # Changed: slots_ no longer represents a pure slot count; callers MUST use
    #          NumSlots()/IsSmallMap() instead of reading slots_ directly.

    kSmallTagMask: ClassVar[uint64] = 1 << 63  # static constexpr
    # Interacts with: SmallMapObj.NumSlots(), DenseMapObj.NumSlots(),
    #                 SetSlotsAndSmallLayoutTag(), SetSlotsAndDenseLayoutTag()

    def IsSmallMap(self) -> bool: ...
    # Returns (slots_ & kSmallTagMask) != 0
    # Interacts with: TVM_FFI_DISPATCH_MAP macro, MapObj::CopyFrom,
    #                 MapObj::InsertMaybeReHash, DenseMapObj::InsertMaybeReHash
    # Extension: future changes to the small/dense boundary threshold only need
    #            to adjust tagging logic, not dispatch predicates.

class SmallMapObj(MapObj):
    def NumSlots(self) -> uint64: ...
    # Returns slots_ & ~kSmallTagMask (masks off tag bit)
    # Interacts with: InsertMaybeReHash growth logic, SmallMapObj::Empty

    # private:
    def SetSlotsAndSmallLayoutTag(self, n: uint64) -> None: ...
    # Sets slots_ = (n & ~kSmallTagMask) | kSmallTagMask
    # Invariant: always sets MSB, ensuring IsSmallMap() returns true

class DenseMapObj(MapObj):
    def NumSlots(self) -> uint64: ...
    # Returns slots_ directly (MSB is always clear for dense maps)
    # Interacts with: IsFull(), Reset(), probe index wrapping (% NumSlots()),
    #                 Empty(), CopyFrom()

    # private:
    def SetSlotsAndDenseLayoutTag(self, n: uint64) -> None: ...
    # Asserts (n & kSmallTagMask) == 0 then sets slots_ = n
    # Invariant: MSB must be clear; dense map slot counts fit in 63 bits

# Macro expansion (pseudocode for TVM_FFI_DISPATCH_MAP):
# Old: if base->slots_ <= SmallMapObj::kMaxSize: cast to SmallMapObj else DenseMapObj
# New: if base->IsSmallMap(): cast to SmallMapObj else DenseMapObj
```

## Impact
- API: None -- all changes are internal to `map.h`. `Map<K,V>` public interface unchanged.
- Behavioral: SmallMap/DenseMap dispatch no longer depends on comparing `slots_` to `kMaxSize`. Instead, an explicit MSB tag determines layout. This is a prerequisite for future changes to the small map boundary threshold without breaking dispatch logic.
- Flags/config: None.
- Data formats/schemas: `MapObj::slots_` ABI changed -- bit 63 is now reserved as layout tag. Any code that reads `slots_` directly (instead of through `NumSlots()`) will see incorrect values for `SmallMapObj` instances.

## Usage Examples
The refactoring is internal. The public `Map<K,V>` API is unchanged. Below shows how the dispatch mechanism changed internally:

```cpp
// Before: dispatch based on raw slots_ value
// if (base->slots_ <= SmallMapObj::kMaxSize) { /* SmallMapObj path */ }

// After: dispatch based on explicit MSB tag
if (base->IsSmallMap()) {
  SmallMapObj* sm = static_cast<SmallMapObj*>(base);
  uint64_t actual_slots = sm->NumSlots();  // masks off tag bit
  // ...
} else {
  DenseMapObj* dm = static_cast<DenseMapObj*>(base);
  uint64_t actual_slots = dm->NumSlots();  // identity for dense maps
  // ...
}

// Construction: tag is set automatically
// SmallMapObj::Empty() calls SetSlotsAndSmallLayoutTag(n)
// DenseMapObj::Empty() calls SetSlotsAndDenseLayoutTag(n_slots) with assertion
```
