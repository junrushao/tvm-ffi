# Refactor Map ABI to use MSB tag bit for SmallMap/DenseMap dispatch
## TL;DR
- Replaces the `slots_ <= SmallMapObj::kMaxSize` threshold check with an MSB tag bit (`kSmallTagMask = 1 << 63`) in the `slots_` field to distinguish SmallMap from DenseMap layout.
- Adds `MapObj::IsSmallMap()`, `SmallMapObj::NumSlots()`, `DenseMapObj::NumSlots()`, `SmallMapObj::SetSlotsAndSmallLayoutTag()`, and `DenseMapObj::SetSlotsAndDenseLayoutTag()` to encapsulate tag management.
- Updates `TVM_FFI_DISPATCH_MAP` / `TVM_FFI_DISPATCH_MAP_CONST` macros and `MapObj::InsertMaybeReHash` to use the new tag-based dispatch instead of raw `slots_` comparison.

## Key Exports

Internal ABI change to `MapObj` and its subclasses. No new public-facing `Map<K,V>` user API. The new methods are all on the internal `*Obj` classes.

```python
class MapObj(Object):
    """Base map object with MSB-tagged slots_ field."""
    data_: void_ptr
    size_: uint64
    slots_: uint64
    # Changed: MSB of slots_ is now a layout tag (1 = SmallMap, 0 = DenseMap)
    # The remaining 63 bits store the actual slot count.

    kSmallTagMask: ClassVar[uint64] = 1 << 63
    # Invariant: kSmallTagMask is set iff the object is a SmallMapObj
    # Invariant: DenseMap slot counts are always < 2^63 (MSB clear)

    def IsSmallMap(self) -> bool: ...
    # Returns (slots_ & kSmallTagMask) != 0
    # Interacts with: TVM_FFI_DISPATCH_MAP macro, MapObj::CopyFrom, MapObj::InsertMaybeReHash
    # Replaces: slots_ <= SmallMapObj::kMaxSize threshold check

class SmallMapObj(MapObj):
    """Small linear-scan map with MSB tag in slots_."""

    def NumSlots(self) -> uint64: ...
    # Returns slots_ & ~kSmallTagMask (masks off tag bit)
    # Invariant: result <= SmallMapObj::kMaxSize (currently 4)
    # Interacts with: InsertMaybeReHash (capacity check), Empty (initialization)

    def SetSlotsAndSmallLayoutTag(self, n: uint64) -> None: ...  # private
    # Sets slots_ = (n & ~kSmallTagMask) | kSmallTagMask
    # Invariant: always sets the MSB tag bit
    # Interacts with: SmallMapObj::Empty (sole caller)

class DenseMapObj(MapObj):
    """Open-addressing hash map with MSB clear in slots_."""

    def NumSlots(self) -> uint64: ...
    # Returns slots_ directly (MSB is guaranteed clear for DenseMap)
    # Invariant: MSB of slots_ is always 0 for DenseMapObj
    # Interacts with: IsFull, probing logic, Reset, CopyFrom

    def SetSlotsAndDenseLayoutTag(self, n: uint64) -> None: ...  # private
    # Asserts (n & kSmallTagMask) == 0, then sets slots_ = n
    # Invariant: fails if n has MSB set (caller error)
    # Interacts with: DenseMapObj::Empty, DenseMapObj::CopyFrom

# Macro dispatch (pseudocode for TVM_FFI_DISPATCH_MAP):
# OLD: if slots <= SmallMapObj::kMaxSize -> SmallMapObj path
# NEW: if base->IsSmallMap() -> SmallMapObj path
```

## Impact
- API: none -- no changes to the public `Map<K,V>` user interface
- Behavioral: SmallMap/DenseMap dispatch now uses a tag bit instead of slot-count threshold. Functionally equivalent for all current uses, but enables future changes to the SmallMap/DenseMap boundary (e.g., changing `kMaxSize` without breaking dispatch logic).
- Flags/config: none
- Data formats/schemas: ABI change to the in-memory representation of `MapObj::slots_` -- SmallMap objects now have MSB set in `slots_`. Any code that reads `slots_` directly (outside the provided accessors) will see different values.

Design elements this commit produces:
- **MSB tag dispatch pattern**: Using the MSB of `slots_` as a layout discriminator instead of a value-range threshold. This decouples the SmallMap/DenseMap boundary from slot-count arithmetic.
- **Accessor encapsulation**: `IsSmallMap()`, `NumSlots()`, `SetSlotsAndSmallLayoutTag()`, `SetSlotsAndDenseLayoutTag()` hide the tag bit from all consumers of slot counts.

## Usage Examples

Before/after showing the refactored dispatch pattern:

```cpp
// BEFORE: dispatch based on slot count threshold
// (inside TVM_FFI_DISPATCH_MAP macro)
uint64_t slots = base->slots_;
if (slots <= SmallMapObj::kMaxSize) {
  SmallMapObj* var = static_cast<SmallMapObj*>(base);
  // ... SmallMap path
} else {
  DenseMapObj* var = static_cast<DenseMapObj*>(base);
  // ... DenseMap path
}

// AFTER: dispatch based on MSB tag bit
if (base->IsSmallMap()) {
  SmallMapObj* var = static_cast<SmallMapObj*>(base);
  // ... SmallMap path
} else {
  DenseMapObj* var = static_cast<DenseMapObj*>(base);
  // ... DenseMap path
}

// BEFORE: raw slots_ used for capacity checks
if (map_node->size_ < map_node->slots_) { /* has space */ }

// AFTER: accessor masks off tag bit
if (map_node->size_ < map_node->NumSlots()) { /* has space */ }
```
