# Refactor Map ABI to use MSB tag bit for SmallMap/DenseMap dispatch
## TL;DR
- Replaces the `slots_ <= SmallMapObj::kMaxSize` size-based dispatch between `SmallMapObj` and `DenseMapObj` with an explicit MSB tag bit (`kSmallTagMask = 1 << 63`) in the `slots_` field, accessed via `MapObj::IsSmallMap()`.
- Introduces `NumSlots()` accessors on both `SmallMapObj` (masks off the tag) and `DenseMapObj` (identity), and corresponding private `SetSlotsAnd*LayoutTag()` setters that manage the tag bit transparently.
- Decouples the SmallMap/DenseMap boundary from the compile-time `kMaxSize` constant, enabling future flexibility in when the map transitions from small to dense layout.

## Key Exports

**Constants**:
```cpp
// MapObj (include/tvm/ffi/container/map.h)
static constexpr uint64_t kSmallTagMask = static_cast<uint64_t>(1) << 63;
// Bit 63 of slots_ is reserved as the layout discriminator tag.
// MSB set => SmallMapObj layout, MSB clear => DenseMapObj layout.
```

**Methods (MapObj)**:
```cpp
bool IsSmallMap() const;  // returns (slots_ & kSmallTagMask) != 0
```

**Methods (SmallMapObj)**:
```cpp
uint64_t NumSlots() const;  // returns slots_ & ~kSmallTagMask  (masks off tag)
// private:
void SetSlotsAndSmallLayoutTag(uint64_t n);  // slots_ = (n & ~kSmallTagMask) | kSmallTagMask
```

**Methods (DenseMapObj)**:
```cpp
uint64_t NumSlots() const;  // returns slots_  (MSB always clear; identity)
// private:
void SetSlotsAndDenseLayoutTag(uint64_t n);  // asserts MSB clear, then slots_ = n
```

**Macros (changed)**:
```cpp
// TVM_FFI_DISPATCH_MAP / TVM_FFI_DISPATCH_MAP_CONST
// Before: dispatched on `base->slots_ <= SmallMapObj::kMaxSize`
// After:  dispatched on `base->IsSmallMap()`
```

## Impact
- API: No public API changes for `Map<K,V>` users. The new methods are on the internal `MapObj`/`SmallMapObj`/`DenseMapObj` classes. `IsSmallMap()` and `NumSlots()` are public but these are internal implementation types.
- Behavioral: No behavioral change; the tag bit is set/cleared at construction time such that `IsSmallMap()` returns the same answer as the old size-based check. The `InsertMaybeReHash` logic is restructured but preserves identical semantics (small maps grow within small layout, then transition to dense at `kMaxSize`).
- Flags/config: none
- Data formats/schemas: The in-memory value of `slots_` for `SmallMapObj` instances changes (MSB is now set). This is an ABI-level change -- any code that reads `slots_` directly from a `SmallMapObj` (e.g., via memory inspection or serialization of the raw object) would see different values. However, the `NumSlots()` accessor returns the correct logical value.

## Design Elements
Design elements this commit consumes:
- **MapObj / SmallMapObj / DenseMapObj class hierarchy** (`.knowledge/designs/0008-containers.md`): The two-tier map layout with `SmallMapObj` for small maps and `DenseMapObj` for large maps with open-addressing hash table.
- **`slots_` field semantics** (`.knowledge/ADRs/0006-container-data-pointer.md`): Prior ADR changed `slots_` from bitmask (`n-1`) to actual count (`n`). This commit further evolves the field to carry a tag bit.
- **`TVM_FFI_DISPATCH_MAP` / `TVM_FFI_DISPATCH_MAP_CONST` macros**: Internal dispatch macros that select the correct concrete map type at runtime.

Design elements this commit produces:
- **MSB tag-based map layout discrimination**: A new invariant where bit 63 of `MapObj::slots_` encodes the layout kind (small vs dense). This replaces the implicit convention that `slots_ <= kMaxSize` means small map.
- **`NumSlots()` accessor pattern**: Both `SmallMapObj` and `DenseMapObj` expose `NumSlots()` as the canonical way to read the logical slot count, abstracting away the tag bit. All internal code migrated from raw `slots_` reads to `NumSlots()`.

## Usage Examples
The public `Map<K,V>` API is unchanged. The refactoring is entirely internal. The key pattern change is in how internal code determines the map layout:

**Before** (size-based dispatch):
```cpp
// TVM_FFI_DISPATCH_MAP macro
uint64_t slots = base->slots_;
if (slots <= SmallMapObj::kMaxSize) {
  // SmallMapObj path
} else {
  // DenseMapObj path
}

// InsertMaybeReHash
if (base->slots_ < kSmallMapMaxSize) {
  SmallMapObj::InsertMaybeReHash(...);
} else if (base->slots_ == kSmallMapMaxSize) {
  // boundary: check if full, then transition to dense
}
```

**After** (tag-based dispatch):
```cpp
// TVM_FFI_DISPATCH_MAP macro
if (base->IsSmallMap()) {
  // SmallMapObj path
} else {
  // DenseMapObj path
}

// InsertMaybeReHash -- uses IsSmallMap() + NumSlots()
if (base->IsSmallMap()) {
  SmallMapObj* sm = static_cast<SmallMapObj*>(base);
  if (sm->NumSlots() < SmallMapObj::kMaxSize) {
    SmallMapObj::InsertMaybeReHash(...);
  } else if (sm->NumSlots() == SmallMapObj::kMaxSize) {
    // boundary: check if full, then transition to dense
  }
}
```
