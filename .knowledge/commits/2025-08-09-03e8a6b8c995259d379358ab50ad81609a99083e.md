# Encode SmallMap layout type in MSB of MapObj::slots_ to decouple identity from capacity

## TL;DR
- Adds `kSmallTagMask = 1ULL << 63` to `MapObj`. `SmallMapObj` sets this bit in `slots_` on construction via `SetSlotsAndSmallLayoutTag(n)`. `DenseMapObj` asserts MSB is clear via `SetSlotsAndDenseLayoutTag(n)`.
- Introduces `IsSmallMap()` (reads MSB) and `NumSlots()` (masks off MSB) on each subtype, replacing all direct `slots_` comparisons against `SmallMapObj::kMaxSize` in dispatch and capacity logic.
- Dispatch macros `TVM_FFI_DISPATCH_MAP` / `TVM_FFI_DISPATCH_MAP_CONST` now branch on `base->IsSmallMap()` instead of `slots_ <= kMaxSize`, enabling future changes to the SmallMap capacity threshold without touching dispatch logic.

## Impact
- API: None — `Map<K,V>` public interface is unchanged; `TVM_FFI_DISPATCH_MAP` macro signature is unchanged.
- Behavioral: `InsertMaybeReHash` logic is restructured around `IsSmallMap()` + `NumSlots()` instead of raw `slots_` comparisons. Semantics are equivalent for current `kMaxSize` values; the refactor enables future threshold changes.
- Flags/config: None.
- Data formats/schemas: `MapObj::slots_` field ABI changes — MSB is now a layout tag. Any external code that read `slots_` directly to discriminate Small vs Dense layout (i.e., compared `slots_` against `SmallMapObj::kMaxSize`) is broken. The public C++ interface (`Map<K,V>`) is unaffected.

## Design Elements
Design elements this commit consumes:
- `MapObj` / `SmallMapObj` / `DenseMapObj` — the two-variant Map implementation (`.knowledge/design-records/0007-containers.md`)
- `TVM_FFI_DISPATCH_MAP` / `TVM_FFI_DISPATCH_MAP_CONST` — the dispatch macros used by all Map operations

Design elements this commit produces:
- `MapObj::kSmallTagMask` — new class constant encoding MSB as a layout tag in `slots_`
- `MapObj::IsSmallMap()` — new predicate replacing range-check dispatch
- `SmallMapObj::NumSlots()` / `SmallMapObj::SetSlotsAndSmallLayoutTag()` — MSB-masked slot accessor/setter
- `DenseMapObj::NumSlots()` / `DenseMapObj::SetSlotsAndDenseLayoutTag()` — identity accessor + assertion-guarded setter
- Updated `MapObj::slots_` invariant: MSB is a layout-type tag, not part of the slot count

## Usage Examples

Before/after pattern for InsertMaybeReHash capacity check:

```cpp
// BEFORE: raw slots_ compared directly to kMaxSize boundary
if (base->slots_ < kSmallMapMaxSize) {
    SmallMapObj::InsertMaybeReHash(std::move(kv), map);
} else if (base->slots_ == kSmallMapMaxSize) {
    if (base->size_ < base->slots_) { ... }
}

// AFTER: IsSmallMap() reads tag; NumSlots() masks off MSB
if (base->IsSmallMap()) {
    SmallMapObj* sm = static_cast<SmallMapObj*>(base);
    if (sm->NumSlots() < SmallMapObj::kMaxSize) {
        SmallMapObj::InsertMaybeReHash(std::move(kv), map);
    } else if (sm->NumSlots() == SmallMapObj::kMaxSize) {
        if (base->size_ < sm->NumSlots()) { ... }
    }
}
```
