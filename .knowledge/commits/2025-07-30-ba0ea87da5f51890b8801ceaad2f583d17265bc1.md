# Optimize string equality, comparison, and hashing for performance
## TL;DR
- Add `Bytes::memequal` using `std::memcmp` for O(1) short-circuit and SIMD-eligible equality checks; replace `memncmp(...) == 0` in `AnyEqual` and `String::operator==` overloads.
- Optimize `StableHashBytes` to use direct 8-byte aligned loads on little-endian platforms, falling back to byte-by-byte copy only for unaligned data.
- Rewrite `String::compare(const char*)` to avoid calling `strlen()` on the RHS, eliminating a redundant pass over the C-string.

## Impact
- API: New `Bytes::memequal` static method added. No signatures removed. `memncmp` moved from out-of-class to in-class definition (ABI-compatible since it was already inline/header-only).
- Behavioral: `operator==(String, String)`, `operator==(String, std::string)`, and `AnyEqual` now use `memequal` (calls `std::memcmp`) instead of byte-by-byte loop via `memncmp`. `String::compare(const char*)` no longer calls `strlen`. All semantically equivalent, but faster.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `AnyEqual` / `AnyHash` functors from `any.h` -- used in `Map<K,V>` and other hash-table lookups for `Any` keys. See [0003-any-system.md](../designs/0003-any-system.md).
- `BytesObjBase` layout (`data`, `size` fields) from the String/Bytes object model. See [0007-containers.md](../designs/0007-containers.md).
- `TVM_FFI_IO_NO_ENDIAN_SWAP` compile-time constant for platform-aware hashing.

Design elements this commit produces:
- `Bytes::memequal` -- new static method on the `Bytes` ref class, providing a dedicated equality fast-path distinct from the ordering-comparison `memncmp`.

## Usage Examples
Test from the same commit showing aligned vs unaligned hash consistency:

```cpp
// Verify StableHashBytes produces identical hashes for aligned and unaligned data
TEST(String, BytesHash) {
  std::vector<int64_t> data1(10);           // naturally 8-byte aligned
  std::vector<int64_t> data2(11);
  for (size_t i = 0; i < data1.size(); ++i) data1[i] = i;

  char* data1_ptr = reinterpret_cast<char*>(data1.data());
  char* data2_ptr = reinterpret_cast<char*>(data2.data()) + 1;  // force unaligned
  std::memcpy(data2_ptr, data1.data(), data1.size() * sizeof(int64_t));

  uint64_t hash1 = details::StableHashBytes(data1_ptr, data1.size() * sizeof(int64_t));
  uint64_t hash2 = details::StableHashBytes(data2_ptr, data1.size() * sizeof(int64_t));
  EXPECT_EQ(hash1, hash2);  // aligned and unaligned paths must agree
}
```
