# Improve string equality and hash efficiency: add memequal, align-aware StableHashBytes, and avoid strlen in String::compare

## TL;DR
- Adds `Bytes::memequal` — a dedicated equality predicate that short-circuits on size mismatch before calling `std::memcmp`, avoiding a full character scan when lengths differ; replaces `memncmp(...) == 0` in `AnyEqual` and `String operator==` overloads.
- Inlines `Bytes::memncmp` into the header (previously an out-of-line definition at the bottom of `string.h`) and rewrites `String::compare(const char*)` to avoid a `strlen` call, scanning the C-string and the `String` data simultaneously.
- Rewrites `StableHashBytes` to take an aligned fast path (`reinterpret_cast<const uint64_t*>` load) when pointer alignment is a multiple of 8, and an unaligned byte-copy path otherwise; adds a test verifying both paths produce identical hashes.

## Impact
- API: `Bytes::memequal` is a new public static method on `Bytes`; additive only. `Bytes::memncmp` is now inline in the header rather than out-of-line — no ABI impact for C++ callers (same symbol, now inlined away). All `operator==` overloads for `String` / `std::string` pairs now route through `memequal`.
- Behavioral: `String::compare(const char*)` no longer calls `strlen`; result is semantically identical but avoids a second pass over the C-string. `StableHashBytes` now produces the same hash for aligned and unaligned pointers to the same bytes (previously the aligned reinterpret-cast path was missing, though the function was only called on aligned data in practice).
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**Before/after: equality check in AnyEqual (C++):**
```cpp
// Before:
return Bytes::memncmp(lhs_str->data, rhs_str->data,
                      lhs_str->size, rhs_str->size) == 0;

// After:
return Bytes::memequal(lhs_str->data, rhs_str->data,
                       lhs_str->size, rhs_str->size);
// memequal returns false immediately if sizes differ — no character scan needed
```

**New aligned-vs-unaligned hash correctness test:**
```cpp
TEST(String, BytesHash) {
  std::vector<int64_t> data1(10);
  // data2_ptr is offset by 1 byte — intentionally unaligned
  char* data2_ptr = reinterpret_cast<char*>(data2.data()) + 1;
  std::memcpy(data2_ptr, data1.data(), data1.size() * sizeof(int64_t));
  uint64_t hash1 = details::StableHashBytes(data1_ptr, data1.size() * 8);
  uint64_t hash2 = details::StableHashBytes(data2_ptr, data1.size() * 8);
  EXPECT_EQ(hash1, hash2);  // must be equal despite different alignment
}
```
