# Optimize string equality, hashing, and comparison for performance
## TL;DR
- Adds `Bytes::memequal` using `std::memcmp` for O(1) size-mismatch rejection and hardware-optimized byte comparison, replacing byte-by-byte `memncmp` in equality paths.
- Optimizes `StableHashBytes` to use direct 8-byte aligned loads when data alignment permits, avoiding per-byte union copy.
- Rewrites `String::compare(const char*)` to avoid upfront `strlen` call, checking for null terminator inline during comparison.

## Key Exports

**Functions**:

| Name | Signature | Notes |
|------|-----------|-------|
| `Bytes::memequal` | `static bool memequal(const char* lhs, const char* rhs, size_t lhs_count, size_t rhs_count)` | New. Returns `lhs_count == rhs_count && (lhs == rhs \|\| std::memcmp(lhs, rhs, lhs_count) == 0)`. |
| `Bytes::memncmp` | `static int memncmp(const char* lhs, const char* rhs, size_t lhs_count, size_t rhs_count)` | Moved from out-of-class definition to inline in-class definition. No behavioral change. |
| `String::compare(const char*)` | `int compare(const char* other) const` | Rewritten to avoid `strlen(other)`. |
| `details::StableHashBytes` | `uint64_t StableHashBytes(const char* data, size_t size)` | Added alignment fast-path for 8-byte aligned data on little-endian. |

## Impact
- API: None. `Bytes::memequal` is new but all existing signatures unchanged.
- Behavioral: `operator==` for `String` vs `String`, `String` vs `std::string`, and `AnyEqual` for string keys now use `memequal` instead of `memncmp(...) == 0`. Semantically equivalent but faster.
- Flags/config: None.
- Data formats/schemas: None.

- **`Bytes::memequal`** — New static method on `Bytes` providing optimized equality-only comparison (avoids full lexicographic ordering when only equality is needed).

## Usage Examples

**`memequal` usage pattern** (from `operator==` in `string.h`):
```cpp
// Before: equality via ordering comparison
inline bool operator==(const String& lhs, const String& rhs) {
  return lhs.compare(rhs) == 0;  // full lexicographic compare
}

// After: dedicated equality check
inline bool operator==(const String& lhs, const String& rhs) {
  return Bytes::memequal(lhs.data(), rhs.data(), lhs.size(), rhs.size());
  // Fast path: size mismatch → false immediately
  // Fast path: same pointer → true immediately
  // Otherwise: std::memcmp (hardware-optimized)
}
```

**`StableHashBytes` aligned load** (from `base_details.h`):
```cpp
// Before: always byte-by-byte copy into union
for (; it + 8 <= end; it += 8) {
  u.a[0] = it[0]; u.a[1] = it[1]; /* ... */ u.a[7] = it[7];
  result = (result * kMultiplier + u.b) % kMod;
}

// After: direct 8-byte load when aligned
if (reinterpret_cast<uintptr_t>(it) % 8 == 0) {
  for (; it + 8 <= end; it += 8) {
    u.b = *reinterpret_cast<const uint64_t*>(it);  // single load
    result = (result * kMultiplier + u.b) % kMod;
  }
}
```
