# feat: Add find() and substr() methods to String class

## TL;DR
- `String::find(str, pos)` and `String::find(char*, pos)` / `String::find(char*, pos, count)`: search for first occurrence, returning `String::npos` if not found (delegates to `std::string_view::find`)
- `String::substr(pos, count)`: returns a new `String` with the substring `[pos, pos+count)`, throws `std::out_of_range` if `pos > size()`
- Static `String::npos = static_cast<size_t>(-1)` constant
- Added 37 C++ tests and 18 Python tests
