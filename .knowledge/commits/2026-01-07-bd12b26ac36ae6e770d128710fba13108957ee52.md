# Add find() and substr() methods to String
## TL;DR
- Adds `String::find()` (3 overloads: String, const char*, const char* + count) and `String::substr()` with bounds checking to `include/tvm/ffi/string.h`.
- Adds `String::npos` constant.
- Adds C++ and Python tests.

## Key Exports

**`String::npos`** -- `static constexpr size_t npos = static_cast<size_t>(-1)`

**`String::find()`** overloads:
```cpp
size_t find(const String& str, size_t pos = 0) const;
size_t find(const char* str, size_t pos = 0) const;
size_t find(const char* str, size_t pos, size_t count) const;
// Delegates to std::string_view::find
```

**`String::substr(size_t pos, size_t count) -> String`**:
```cpp
String substr(size_t pos = 0, size_t count = size_t(-1)) const;
// Throws std::out_of_range if pos > size()
```

## Impact
- API: New methods on `String`. Additive, no breaking changes.
- Behavioral: None

## Usage Examples
```cpp
String s("hello world");
assert(s.find("world") == 6);
assert(s.substr(6) == "world");
assert(s.find("xyz") == String::npos);
```
