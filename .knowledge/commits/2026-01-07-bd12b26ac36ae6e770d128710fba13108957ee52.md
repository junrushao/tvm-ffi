# Add find() and substr() methods to String class
## TL;DR
- Adds `find()` method (3 overloads) and `substr()` method to the C++ `String` class, delegating to `std::string_view` internally.
- Introduces `String::npos` sentinel constant for find-miss returns.
- Tests cover C++ (GoogleTest) and Python (pytest) layers, confirming cross-language availability.

        # Delegates to: find(str.data(), pos, str.size())

        # Delegates to: find(str, pos, strlen(str))

        # Invariant: returns npos if not found or pos > size()

## Impact
- API: Additive -- two new methods and one constant on String. No existing signatures changed.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `String` class and its `BytesBaseCell` backing (`.knowledge/designs/0007-containers.md`) -- uses `data()` and `size()` accessors to construct `std::string_view` for delegation.
- `std::string_view::find` -- the underlying search implementation.

Design elements this commit produces:
- `String::find()` -- substring search API on the FFI String type, enabling string manipulation without converting to `std::string`.
- `String::substr()` -- substring extraction with bounds checking, returning a new `String`.
- `String::npos` -- sentinel constant (`static constexpr size_t`) for find-miss returns.

## Usage Examples

C++ usage (from `tests/cpp/test_string.cc`):
```cpp
String s{"hello world"};
size_t pos = s.find("world");       // 6
size_t miss = s.find("notfound");   // String::npos
String sub = s.substr(6, 5);        // "world"
String tail = s.substr(6);          // "world" (to end)
// s.substr(12) throws std::out_of_range
```

Python cross-layer usage (from `tests/python/test_string.py`):
```python
s = tvm_ffi.core.String("hello world")
assert s.find("world") == 6
assert s.find("o", 5) == 7
assert s.find("notfound") == -1   # Python returns -1 (not npos)
assert s[6:11] == "world"          # Python slice syntax works via existing __getitem__
```
