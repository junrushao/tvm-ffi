# Add find() and substr() methods to String class
## TL;DR
- Add `String::find()` with three overloads (by `String`, by `const char*`, by `const char*` + count) for substring search, returning `npos` on miss.
- Add `String::substr()` for substring extraction with bounds checking (`std::out_of_range` if `pos > size()`).
- Add `String::npos` static constant mirroring `std::string::npos`.

## Key Exports

```python
class String:
    npos: ClassVar[int] = -1  # static constexpr size_t(-1)
    # Interacts with: find() (return value on miss)

    def find(self, str: "String", pos: int = 0) -> int: ...
        # Overload 1: search for String
        # Delegates to: find(str.data(), pos, str.size())

    def find(self, str: str, pos: int = 0) -> int: ...
        # Overload 2: search for const char*
        # Delegates to: find(str, pos, strlen(str))

    def find(self, str: str, pos: int, count: int) -> int: ...
        # Overload 3: search for const char* with explicit length
        # Implementation: std::string_view(data(), size()).find(std::string_view(str, count), pos)
        # Interacts with: BytesBaseCell.data(), BytesBaseCell.size() (for self access)
        # Invariant: returns npos if no match found
        # Extension: follows std::string::find semantics exactly

    def substr(self, pos: int = 0, count: int = npos) -> "String": ...
        # Invariant: pos <= size(), else raises std::out_of_range
        # Invariant: actual count is min(count, size() - pos)
        # Interacts with: String(const char*, size_t) constructor (creates new owning String)
        # Extension: follows std::string::substr semantics
```

## Impact
- API: Additive -- three new `find()` overloads, one `substr()` method, and one `npos` constant on `String`. No existing signatures changed.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
**C++ (from test_string.cc):**
```cpp
String s{"hello world"};
// Substring search
s.find("world");            // 6
s.find("o", 5);             // 7 (search starting at pos 5)
s.find("notfound");         // String::npos

// Substring extraction
s.substr(0, 5);             // "hello"
s.substr(6);                // "world"
// s.substr(12);            // throws std::out_of_range
```

**Python (from test_string.py) -- cross-layer:**
```python
s = tvm_ffi.core.String("hello world")
s.find("world")             # 6
s.find("o", 5)              # 7
s.find("notfound")          # -1 (Python convention, maps from C++ npos)

# Python slicing uses __getitem__ rather than substr
s[6:11]                     # "world"
s[:5]                       # "hello"
```
