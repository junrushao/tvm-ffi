# Add find and substr methods to String
## TL;DR
- Adds `String::find()` overloads (by String, const char*, and with count) using `std::string_view::find`.
- Adds `String::substr()` with bounds checking (throws `std::out_of_range`).
- Adds `String::npos` constant.
- Python-side `find()` and `substr()` are exposed through the existing String class interface.

## Key Exports

**C++ API:**
- `String::find(const String&, size_t pos)` -- Find substring.
- `String::find(const char*, size_t pos)` -- Find C-string.
- `String::find(const char*, size_t pos, size_t count)` -- Find with explicit length.
- `String::substr(size_t pos, size_t count)` -- Extract substring.
- `String::npos` -- Sentinel for "not found".
