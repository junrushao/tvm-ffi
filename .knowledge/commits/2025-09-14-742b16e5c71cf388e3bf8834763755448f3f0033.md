# Document tvm_ffi.cpp.load_inline and update examples to use tvm::ffi::Tensor instead of DLTensor*

## TL;DR

- Adds a complete `load_inline` docstring with typed parameter descriptions, a worked example, and Sphinx `automodule` reference page under `docs/reference/python/cpp/`.
- Adds `#include <tvm/ffi/container/tensor.h>` to the auto-injected preamble in `_decorate_with_tvm_ffi`, enabling `tvm::ffi::Tensor` in inline sources without an explicit include.
- Updates all examples and tests from the raw `DLTensor*` pointer API to the idiomatic `tvm::ffi::Tensor` wrapper type.

## Key Exports

```python
# python/tvm_ffi/cpp/load_inline.py

def _decorate_with_tvm_ffi(source: str, functions: Mapping[str, str]) -> str:
    """Inject TVM FFI export macros and a fixed set of include headers into user source.

    Auto-injected headers now include:
      #include <tvm/ffi/container/tensor.h>   # NEW — enables tvm::ffi::Tensor
      #include <tvm/ffi/dtype.h>
      #include <tvm/ffi/error.h>
      #include <tvm/ffi/extra/c_env_api.h>
      ... (other existing headers)
    """
    # Invariant: every symbol named in `functions` gets a TVM_FFI_DLL_EXPORT_TYPED_FUNC wrapper.
    # Interacts with: load_inline() (caller), tvm/ffi/container/tensor.h (new dependency)

def load_inline(
    name: str,
    cpp_sources: Sequence[str] | str | None = None,
    cuda_sources: Sequence[str] | str | None = None,
    functions: Mapping[str, str] | Sequence[str] | str = ...,
    extra_cflags: Sequence[str] | None = None,
    extra_cuda_cflags: Sequence[str] | None = None,
    extra_ldflags: Sequence[str] | None = None,
    extra_include_paths: Sequence[str] | None = None,
    build_directory: str | None = None,
) -> Module: ...
    # Interacts with: _decorate_with_tvm_ffi(), Module (tvm_ffi.Module), FileLock (cache dir)
    # Invariant: cache key is content-hash of sources + flags; recompile only on change
    # Extension: pass extra_include_paths for custom headers; set TVM_FFI_CACHE_DIR env var
    # Default cache: ~/.cache/tvm-ffi
    # Default cflags (Linux/macOS): ['-std=c++17', '-fPIC', '-O2']
    # Default cflags (Windows):     ['/std:c++17', '/O2']
    # Default ldflags (Linux/macOS): ['-shared']
    # Default ldflags (Windows):     ['/DLL']
```

## Impact

- API: No signature changes to `load_inline()`. The `functions` parameter docstring clarifies that a `Sequence[str]` (list of names) is accepted, distinct from `Mapping[str, str]` (names → docstrings).
- Behavioral: `_decorate_with_tvm_ffi` now injects `#include <tvm/ffi/container/tensor.h>` unconditionally. Any inline C++ using `tvm::ffi::Tensor` no longer needs a manual include. Prior to this, writing `tvm::ffi::Tensor` in `cpp_sources` without extra includes would produce a compile error.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

Cross-layer trace: Python embeds C++ source string → `load_inline` JIT-compiles → `Module` exposes named function → Python calls via attribute access.

```python
import torch
from tvm_ffi import Module
import tvm_ffi.cpp

cpp_source = '''
    void add_one_cpu(tvm::ffi::Tensor x, tvm::ffi::Tensor y) {
        TVM_FFI_ICHECK(x->ndim == 1) << "x must be a 1D tensor";
        DLDataType f32_dtype{kDLFloat, 32, 1};
        TVM_FFI_ICHECK(x->dtype == f32_dtype) << "x must be a float tensor";
        TVM_FFI_ICHECK(x->shape[0] == y->shape[0]) << "shape mismatch";
        for (int i = 0; i < x->shape[0]; ++i)
            static_cast<float*>(y->data)[i] = static_cast<float*>(x->data)[i] + 1;
    }
'''

mod: Module = tvm_ffi.cpp.load_inline(
    name='hello', cpp_sources=cpp_source, functions='add_one_cpu'
)

x = torch.tensor([1, 2, 3, 4, 5], dtype=torch.float32)
y = torch.empty_like(x)
mod.add_one_cpu(x, y)
torch.testing.assert_close(x + 1, y)
```

Before/after pattern for the API correction (all examples and tests):

```cpp
// Before (raw pointer — worked but bypassed tvm::ffi::Tensor convenience API):
void add_one_cpu(DLTensor* x, DLTensor* y) { ... }

// After (idiomatic tvm::ffi::Tensor — same underlying data, richer interface):
void add_one_cpu(tvm::ffi::Tensor x, tvm::ffi::Tensor y) { ... }
```
