# Add documentation, API reference, and usage examples for tvm_ffi.cpp.load_inline

## TL;DR
- Adds an "Inline Module" section to the Python guide (`docs/guides/python_guide.md`) with a full end-to-end example of `tvm_ffi.cpp.load_inline`.
- Adds Sphinx API reference pages for `tvm_ffi.cpp` (`docs/reference/python/cpp/index.rst`) and links them from the Python reference index.
- Rewrites the `load_inline()` docstring with RST-formatted parameters, corrected descriptions, and an embedded usage example. Adds `#include <tvm/ffi/container/tensor.h>` to auto-included headers.
- Migrates all examples and tests from raw `DLTensor*` to `tvm::ffi::Tensor` as the recommended C++ function signature convention.

## Key Exports
None -- no new public API surface. The one functional change is the addition of `#include <tvm/ffi/container/tensor.h>` to `_decorate_with_tvm_ffi()`, which means all inline-compiled modules now automatically include the Tensor header.

## Impact
- API: none (additive include only)
- Behavioral: Inline-compiled modules now always include `tvm/ffi/container/tensor.h`, enabling `tvm::ffi::Tensor` usage without manual includes. No breakage for existing `DLTensor*` users.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
The commit itself adds the canonical usage example (from `docs/guides/python_guide.md` and the `load_inline` docstring):

```python
import torch
from tvm_ffi import Module
import tvm_ffi.cpp

cpp_source = '''
     void add_one_cpu(tvm::ffi::Tensor x, tvm::ffi::Tensor y) {
       TVM_FFI_ICHECK(x->ndim == 1) << "x must be a 1D tensor";
       DLDataType f32_dtype{kDLFloat, 32, 1};
       TVM_FFI_ICHECK(x->dtype == f32_dtype) << "x must be a float tensor";
       for (int i = 0; i < x->shape[0]; ++i) {
         static_cast<float*>(y->data)[i] = static_cast<float*>(x->data)[i] + 1;
       }
     }
'''

mod: Module = tvm_ffi.cpp.load_inline(
    name='hello', cpp_sources=cpp_source, functions='add_one_cpu'
)

x = torch.tensor([1, 2, 3, 4, 5], dtype=torch.float32)
y = torch.empty_like(x)
mod.add_one_cpu(x, y)
torch.testing.assert_close(x + 1, y)
```

Note the migration from `DLTensor*` (old convention) to `tvm::ffi::Tensor` (new recommended convention). The `tensor.h` header is now auto-included by `_decorate_with_tvm_ffi`, so no manual `#include` is needed.
