# Add documentation for tvm_ffi.cpp.load_inline including guide, API reference, and docstring improvements

## TL;DR
- Adds an "Inline Module" section to `docs/guides/python_guide.md` with a complete end-to-end example of `tvm_ffi.cpp.load_inline` usage.
- Creates Sphinx API reference stubs for `tvm_ffi.cpp` module (`docs/reference/python/cpp/index.rst`) and links them from the Python reference index.
- Rewrites the `load_inline()` docstring in `python/tvm_ffi/cpp/load_inline.py` with RST-compatible formatting, adds an inline `Example` section, and includes `#include <tvm/ffi/container/tensor.h>` in the auto-included headers.
- Updates all inline C++ source strings in examples and tests from `DLTensor*` to `tvm::ffi::Tensor`, aligning with the typed-ref convention established in `6fa40b5`.

## Key Exports

None -- this commit produces no new design elements. The only functional code change is the addition of `#include <tvm/ffi/container/tensor.h>` to `_decorate_with_tvm_ffi()`, which ensures inline-compiled C++ code can use `tvm::ffi::Tensor` without explicit includes.

## Impact
- API: None -- no public API signatures changed.
- Behavioral: Inline-compiled modules now automatically include `<tvm/ffi/container/tensor.h>`, allowing `tvm::ffi::Tensor` in user source without manual `#include`. Previously only `<tvm/ffi/dtype.h>`, `<tvm/ffi/error.h>`, `<tvm/ffi/extra/c_env_api.h>`, and `<tvm/ffi/module.h>` were auto-included.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Module system / `load_inline`** ([0011-module-system.md](../designs/0011-module-system.md)) -- documents the existing `load_inline` pipeline and updates its docstring.
- **`tvm::ffi::Tensor` typed-ref convention** -- the `DLTensor*` -> `tvm::ffi::Tensor` update in examples/tests reflects the typed-ref migration tracked in `6fa40b5` and `3a551d8`.
- **`TVM_FFI_DLL_EXPORT_TYPED_FUNC`** -- the auto-decoration pipeline in `_decorate_with_tvm_ffi` that wraps user functions with FFI export macros.

Design elements this commit produces:
- None -- purely documentation and example alignment.

## Usage Examples
N/A -- docs-only commit. The guide section itself serves as the usage example. The key snippet added to the Python guide:

```python
import tvm_ffi.cpp

mod = tvm_ffi.cpp.load_inline(
    name='hello',
    cpp_sources='''
         void add_one_cpu(tvm::ffi::Tensor x, tvm::ffi::Tensor y) {
           TVM_FFI_ICHECK(x->ndim == 1) << "x must be a 1D tensor";
           // ...
         }
    ''',
    functions='add_one_cpu'
)
mod.add_one_cpu(x, y)
```
