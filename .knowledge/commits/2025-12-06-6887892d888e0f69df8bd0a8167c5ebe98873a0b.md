# Refactor library discovery to use importlib.metadata; remove base.py; add load_lib_ctypes public API

## TL;DR
- Replaces ad-hoc directory scanning (`get_dll_directories` + `find_library_by_basename`) with `importlib.metadata` RECORD-based library discovery as the primary lookup strategy, falling back to environment-variable and relative-path scanning.
- Removes `python/tvm_ffi/base.py` entirely; library loading moves into `libinfo.load_lib_ctypes()` called directly from `__init__.py`.
- Introduces `load_lib_ctypes(package, target_name, mode)` as a reusable public API for downstream packages to locate and load their co-packaged DSOs via the same `importlib.metadata` mechanism.

## Impact
- API: `find_library_by_basename`, `get_dll_directories`, `split_env_var` removed from public surface. `load_lib_ctypes` added. `tvm_ffi.LIB` exposed as public. `find_windows_implib` moved from `config.py` to `libinfo.py`. Callers of the removed functions must migrate.
- Behavioral: Library discovery now prioritizes `importlib.metadata` RECORD parsing over directory scanning. This is more reliable for pip-installed packages but requires the package to be properly installed (not just on `PYTHONPATH` with a bare directory). The fallback path still covers dev builds.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Python packaging (`0013-ffi-packaging-and-distribution`): the `apache-tvm-ffi` package name, wheel layout with `libtvm_ffi.so` in `tvm_ffi/lib/`, and the `tvm_ffi.config` CLI tool.
- `importlib.metadata` standard library module: `distribution()`, `PathDistribution._path`, `RECORD` file format.

Design elements this commit produces:
- `load_lib_ctypes(package, target_name, mode)`: new public API for DSO loading, intended for reuse by downstream packages that link with `tvm_ffi`.
- `_find_library_by_basename` with `importlib.metadata` primary lookup: replaces the old `get_dll_directories`-based scanning. This is the new canonical library discovery strategy.
- `_resolve_and_validate`: shared pattern for path resolution with error handling, used by all `find_*` functions (refactored from repeated inline logic).
- `tvm_ffi.LIB`: public module-level attribute exposing the loaded `ctypes.CDLL` handle.

Design elements this commit removes:
- `base.py` module: the entire intermediate layer between `__init__.py` and `libinfo.py` is gone.
- `find_library_by_basename` (public): replaced by private `_find_library_by_basename`.
- `get_dll_directories` (public): logic absorbed into `_find_library_by_basename` fallback.
- `split_env_var` (public): renamed to `_split_env_var` (private).

## Usage Examples
Loading a DSO for a downstream package that ships alongside tvm_ffi:
```python
import tvm_ffi.libinfo

# One-liner for any downstream package that co-ships a DSO
LIB = tvm_ffi.libinfo.load_lib_ctypes("apache-tvm-ffi", "tvm_ffi", "RTLD_LOCAL")

# Or for a downstream extension:
LIB = tvm_ffi.libinfo.load_lib_ctypes("my-extension-pkg", "my_extension", "RTLD_LOCAL")
```

The tvm_ffi package itself now uses this in `__init__.py`:
```python
from . import libinfo
LIB = libinfo.load_lib_ctypes("apache-tvm-ffi", "tvm_ffi", "RTLD_GLOBAL")
```
