# Switch DSO discovery to importlib.metadata and expose load_lib_ctypes for downstream packages

## TL;DR
- Replaces the old `base.py` + `_load_lib()` pattern with `libinfo.load_lib_ctypes(package, target_name, mode)` called directly in `__init__.py`; `base.py` is deleted entirely.
- Rewrites `_find_library_by_basename` to use `importlib.metadata` RECORD as the primary lookup path (reliable for wheel installs), with a fallback to `build/lib/` directories and `PATH`/`LD_LIBRARY_PATH`.
- Adds `load_lib_ctypes(package, target_name, mode) -> ctypes.CDLL` as a **public API** so downstream libraries can locate and load their own DSOs using the same mechanism.

## Impact
- API: `load_lib_ctypes(package, target_name, mode)` is a new public API. `find_library_by_basename(base: str)` (old single-arg form) is **removed**; the replacement is private `_find_library_by_basename(package, target_name)`. `find_windows_implib()` moved from `config.py` to `libinfo.py` — callers must import from `libinfo`. `LIB` is now a module-level name in `tvm_ffi.__init__` and in `__all__`. `base.py` is deleted.
- Behavioral: DSO lookup now prefers `importlib.metadata` RECORD over filesystem traversal — correct for wheel installs where the `.so` lives inside `site-packages/tvm_ffi/lib/` without `LD_LIBRARY_PATH` being set. The old fallback chain (env-var search) is retained as a secondary path for dev/CMake builds.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**Downstream library loading pattern (new recommended pattern):**
```python
# In downstream package's __init__.py or base.py:
import tvm_ffi

LIB = tvm_ffi.libinfo.load_lib_ctypes("my-package-name", "my_lib_target", "RTLD_LOCAL")
# Locates libmy_lib_target.so via importlib.metadata RECORD first,
# then falls back to build/lib/ and PATH env vars.
```

**tvm_ffi self-load (now in __init__.py):**
```python
from . import libinfo
LIB = libinfo.load_lib_ctypes("apache-tvm-ffi", "tvm_ffi", "RTLD_GLOBAL")
# RTLD_GLOBAL exposes symbols to subsequently dlopen'd Cython extensions
```

**importlib.metadata primary lookup (from _find_library_by_basename):**
