# Use importlib.metadata for DSO location; add load_lib_ctypes API
## TL;DR
- Rewrites `python/tvm_ffi/libinfo.py` (+222/-143 lines) to use `importlib.metadata` for locating shared libraries, fixing issues with non-standard installation layouts (e.g., wheels).
- Introduces `tvm_ffi.libinfo.load_lib_ctypes(package, target, mode)` API for downstream libraries to locate and load their DSOs.
- Removes `python/tvm_ffi/base.py` (56 lines of library loading logic moved to libinfo).
- Adds test file `tests/python/test_libinfo.py`.
