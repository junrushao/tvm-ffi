# Replace short stable C ABI guide with comprehensive RST tutorial and pure-C examples
## TL;DR
- Deletes the 81-line markdown guide `docs/guides/stable_c_abi.md` and replaces it with a 254-line RST tutorial `docs/get_started/stable_c_abi.rst`, promoting it from a supplementary guide to a top-level get-started page.
- Adds a complete `examples/stable_c_abi/` directory with pure-C callee (kernel) and caller (loader) examples, CMakeLists.txt, raw compile scripts, and a README.
- Refactors the quickstart C++ load example to use `[main.begin]/[aux.begin]` section markers (from `[example.begin]`) and hides auxiliary logics behind a dropdown directive.

## Design Elements
Design elements this commit consumes:
- [0001-any-anyview-value-system](.knowledge/design-records/0001-any-anyview-value-system.md): TVMFFIAny 128-bit tagged union layout (type_index + reserved + payload)
- [0007-c-abi](.knowledge/design-records/0007-c-abi.md): `tvm_ffi_c_abi` calling convention (handle, args, num_args, result), `__tvm_ffi_` symbol prefix, `TVMFFIFunctionCall`, `TVMFFIErrorSetRaisedFromCStr`, `TVMFFIFunctionGetGlobal`, `TVMFFIObjectDecRef`, `kTVMFFI*` type index constants
- [0011-module-system](.knowledge/design-records/0011-module-system.md): `ffi.Module.load_from_file.so` and `ffi.ModuleGetFunction` global functions used from C loader
- [0006-containers](.knowledge/design-records/0006-containers.md): DLTensor/Tensor handling, `kTVMFFITensor` -> DLTensor offset calculation (`v_c_str + sizeof(TVMFFIObject)`)

Design elements this commit produces:
- Canonical pure-C callee pattern: `examples/stable_c_abi/src/add_one_cpu.c` demonstrates `__tvm_ffi_add_one_cpu` symbol, TVMFFIAny input marshalling (handling both `kTVMFFIDLTensorPtr` and `kTVMFFITensor`), error reporting, and return convention
- Canonical pure-C caller pattern: `examples/stable_c_abi/src/load.c` demonstrates module loading, function lookup, invocation, and RAII-style cleanup via `TVMFFIObjectDecRef`, all in pure C
- DSL codegen guidance in RST: symbol naming (`__tvm_ffi_{func_name}`), type checking via `type_index`, error handling (return 0/non-zero + `TVMFFIErrorSetRaisedFromCStr`)
- Formalized TVMFFIAny layout description with external SVG figures (layout-any, layout-func)

## Usage Examples
Callee-side C kernel following stable ABI:
```c
#include <tvm/ffi/c_api.h>
TVM_FFI_DLL int __tvm_ffi_add_one_cpu(void* handle, const TVMFFIAny* args, int32_t num_args,
                                      TVMFFIAny* result) {
  DLTensor* x;
  if (args[0].type_index == kTVMFFIDLTensorPtr) x = (DLTensor*)(args[0].v_ptr);
  else if (args[0].type_index == kTVMFFITensor) x = (DLTensor*)(args[0].v_c_str + sizeof(TVMFFIObject));
  else { TVMFFIErrorSetRaisedFromCStr("ValueError", "Expects a Tensor input"); return -1; }
  // ... kernel logic ...
  return 0;
}
```

Caller-side C loader invoking kernel via stable ABI:
```c
// Load module and get function
TVMFFIAny call_args[2];
call_args[0] = (TVMFFIAny){.type_index = kTVMFFIRawStr, .v_c_str = "build/add_one_cpu.so"};
call_args[1] = (TVMFFIAny){.type_index = kTVMFFISmallStr, .v_int64 = 0};
TVMFFIFunctionCall(fn_load_module, call_args, 2, &mod);
// Invoke function with DLTensor args
call_args[0] = (TVMFFIAny){.type_index = kTVMFFIDLTensorPtr, .v_ptr = x};
call_args[1] = (TVMFFIAny){.type_index = kTVMFFIDLTensorPtr, .v_ptr = y};
TVMFFIFunctionCall(func.v_ptr, call_args, 2, &none);
```
