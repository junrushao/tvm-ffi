## Design Elements
Design elements this commit consumes:
- **TVMFFIAny layout** (128-bit tagged union) -- documented in [0001-c-abi-layer.md](../designs/0001-c-abi-layer.md) and [ADR 0001](../ADRs/0001-unified-any-value.md). The new RST doc explains the 32+32+64 bit partitioning with a figure.
- **TVMFFISafeCallType calling convention** (`int fn(void* handle, const TVMFFIAny* args, int N, TVMFFIAny* result)`) -- documented in [0001-c-abi-layer.md](../designs/0001-c-abi-layer.md). The callee example (`add_one_cpu.c`) and caller example (`load.c`) both follow this convention.
- **Module system** -- `ffi.Module.load_from_file.so` and `ffi.ModuleGetFunction` global functions, documented in [0013-module-system.md](../designs/0013-module-system.md). The `load.c` caller demonstrates looking up and calling these via pure C API (`TVMFFIFunctionGetGlobal`, `TVMFFIFunctionCall`).
- **`__tvm_ffi_` symbol prefix convention** -- user-exported functions use `__tvm_ffi_<name>` (single underscore separator). The callee defines `__tvm_ffi_add_one_cpu`.
- **DLPack tensor interop** (`DLTensor`) -- the examples marshal tensors via `kTVMFFIDLTensorPtr` and `kTVMFFITensor` type indices.
- **Error propagation** via `TVMFFIErrorSetRaisedFromCStr` / `TVMFFIErrorMoveFromRaised` / `TVMFFIErrorCell` -- the `load.c` Finalize function demonstrates error retrieval.
- **`tvm-ffi-config` CLI tool** -- the `raw_compile.sh` uses `tvm-ffi-config --cflags`, `--ldflags`, and `--libs` flags.

## Usage Examples
**C callee** -- minimal kernel following the stable C ABI (`examples/stable_c_abi/src/add_one_cpu.c`):
```c
TVM_FFI_DLL int __tvm_ffi_add_one_cpu(void* handle, const TVMFFIAny* args, int32_t num_args,
                                      TVMFFIAny* result) {
  DLTensor* x;
  if (args[0].type_index == kTVMFFIDLTensorPtr) x = (DLTensor*)(args[0].v_ptr);
  else if (args[0].type_index == kTVMFFITensor) x = (DLTensor*)(args[0].v_c_str + sizeof(TVMFFIObject));
  // ... extract y similarly, then:
  for (int64_t i = 0; i < x->shape[0]; ++i)
    ((float*)y->data)[i] = ((float*)x->data)[i] + 1.0f;
  return 0;
}
```

**C caller** -- loading and invoking the kernel via the C ABI (`examples/stable_c_abi/src/load.c`):
```c
// Step 1. Load module
call_args[0] = (TVMFFIAny){.type_index = kTVMFFIRawStr, .v_c_str = "build/add_one_cpu.so"};
TVMFFIFunctionCall(fn_load_module, call_args, 2, &mod);
// Step 2. Get function from module
call_args[0] = (TVMFFIAny){.type_index = mod.type_index, .v_obj = mod.v_obj};
call_args[1] = (TVMFFIAny){.type_index = kTVMFFIRawStr, .v_c_str = "add_one_cpu"};
TVMFFIFunctionCall(fn_get_function, call_args, 3, &func);
// Step 3. Call function
call_args[0] = (TVMFFIAny){.type_index = kTVMFFIDLTensorPtr, .v_ptr = x};
call_args[1] = (TVMFFIAny){.type_index = kTVMFFIDLTensorPtr, .v_ptr = y};
TVMFFIFunctionCall(func.v_ptr, call_args, 2, &none);
```
