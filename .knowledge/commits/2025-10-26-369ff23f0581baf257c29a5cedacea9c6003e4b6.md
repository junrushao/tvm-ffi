# Comprehensive Stable C ABI tutorial replacing the old brief guide
## TL;DR
- Replaces the brief `docs/guides/stable_c_abi.md` with a comprehensive RST tutorial at `docs/get_started/stable_c_abi.rst`, documenting the TVMFFIAny layout, tvm_ffi_c_abi calling convention, and stability/interoperability guarantees.
- Adds a new `examples/stable_c_abi/` directory with two complete C examples: a callee kernel (`add_one_cpu.c`) and a caller/loader (`load.c`), plus CMake and raw-compile build scripts.
- Refactors `examples/quickstart/load/load_cpp.cc` to split its literalinclude markers into `[main.begin]`/`[main.end]` and `[aux.begin]`/`[aux.end]` sections, and adds a `dropdown` directive for auxiliary logic in the quickstart doc.

```c
    void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result) {
  // Extract DLTensor from TVMFFIAny (kTVMFFIDLTensorPtr or kTVMFFITensor)
  // Compute y = x + 1
  // Return 0 (success)
}
```

**Caller -- C loader using TVMFFIFunctionGetGlobal + TVMFFIFunctionCall:**
```c
// File: examples/stable_c_abi/src/load.c
// 1. TVMFFIFunctionGetGlobal(&name, &fn) to get "ffi.Module.load_from_file.so"
// 2. TVMFFIFunctionCall(fn_load_module, args, 2, &mod) to load .so
// 3. TVMFFIFunctionCall(fn_get_function, args, 3, &func) to get "add_one_cpu"
// 4. TVMFFIFunctionCall(func.v_ptr, tensor_args, 2, &none) to invoke kernel
// 5. TVMFFIObjectDecRef for cleanup; TVMFFIErrorMoveFromRaised on failure
```
