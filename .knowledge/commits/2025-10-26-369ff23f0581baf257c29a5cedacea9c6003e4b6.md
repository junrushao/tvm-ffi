## Design Elements
Design elements this commit consumes:
- **C ABI layout** (`TVMFFIAny`, `TVMFFIObject`, `TVMFFISafeCallType`): The new RST tutorial documents the 128-bit `TVMFFIAny` tagged union layout and the `tvm_ffi_c_abi` calling convention. See [0001-ffi-c-abi.md](../design-records/0001-ffi-c-abi.md).
- **Module system** (`TVMFFIFunctionCall`, `TVMFFIFunctionGetGlobal`, `TVMFFIObjectDecRef`, `TVMFFIErrorMoveFromRaised`): The C caller example (`load.c`) demonstrates loading a shared library via `ffi.Module.load_from_file.so`, getting a function via `ffi.ModuleGetFunction`, and calling it through the C ABI. See [0011-ffi-module-system.md](../design-records/0011-ffi-module-system.md).
- **Error protocol** (`TVMFFIErrorSetRaisedFromCStr`, `TVMFFIErrorMoveFromRaised`, `TVMFFIErrorCell`): Both examples consume error handling. The callee sets errors via `TVMFFIErrorSetRaisedFromCStr`; the caller retrieves them via `TVMFFIErrorMoveFromRaised` and reads `TVMFFIErrorCell`. See [0005-ffi-error-protocol.md](../design-records/0005-ffi-error-protocol.md).
- **DLPack tensor interop** (`DLTensor`, `kTVMFFIDLTensorPtr`, `kTVMFFITensor`): Both examples marshal `DLTensor*` through `TVMFFIAny` with explicit type-index checks. See [0006-ffi-containers.md](../design-records/0006-ffi-containers.md).
- **Module symbol naming convention** (`__tvm_ffi_<name>` prefix): The callee example defines `__tvm_ffi_add_one_cpu` directly, showing the raw symbol convention that `TVM_FFI_DLL_EXPORT_TYPED_FUNC` automates in C++.

Design elements this commit produces: None -- purely documents existing elements.

## Usage Examples
The commit itself is primarily documentation and examples. The two key code artifacts serve as canonical C ABI usage references:

**C callee** -- Implementing a kernel function in pure C following the stable ABI (`examples/stable_c_abi/src/add_one_cpu.c`):
```c
TVM_FFI_DLL int __tvm_ffi_add_one_cpu(
    void* handle, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result) {
  // Extract DLTensor* from TVMFFIAny, checking type_index for kTVMFFIDLTensorPtr or kTVMFFITensor
  DLTensor* x; /* ... extract from args[0] ... */
  DLTensor* y; /* ... extract from args[1] ... */
  // Compute y = x + 1
  for (int64_t i = 0; i < x->shape[0]; ++i)
    ((float*)y->data)[i] = ((float*)x->data)[i] + 1.0f;
  return 0;  // success
}
```

**C caller** -- Loading a module and calling a function through the C ABI (`examples/stable_c_abi/src/load.c`):
```c
// Look up global functions
TVMFFIFunctionGetGlobal(&name_load_module, &fn_load_module);
TVMFFIFunctionGetGlobal(&name_get_function, &fn_get_function);
// Load module, get function, call it with DLTensor args
TVMFFIFunctionCall(fn_load_module, call_args, 2, &mod);
TVMFFIFunctionCall(fn_get_function, call_args, 3, &func);
TVMFFIFunctionCall(func.v_ptr, call_args, 2, &none);
// RAII cleanup: DecRef all owned objects
if (mod.type_index >= kTVMFFIObject) TVMFFIObjectDecRef(mod.v_obj);
```
