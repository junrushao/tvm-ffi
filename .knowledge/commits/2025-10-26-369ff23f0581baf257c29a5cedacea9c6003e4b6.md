# Add comprehensive Stable C ABI documentation and C examples
## TL;DR
- Replaces the brief `docs/guides/stable_c_abi.md` (81 lines) with a thorough RST guide `docs/get_started/stable_c_abi.rst` (254 lines), moved from "Guides" to "Get Started" section.
- Adds full C examples under `examples/stable_c_abi/`: a callee kernel (`add_one_cpu.c`), a caller loader (`load.c`), CMakeLists.txt, and shell build scripts.
- Restructures the existing C++ quickstart example (`load_cpp.cc`) to separate main logic from auxiliary logic with `[main.begin]`/`[aux.begin]` markers for better `literalinclude` usage.

## Impact
- API: None (documentation-only; no C/C++ API changes)
- Flags/config: New CMake `EXAMPLE_NAME` option for the stable_c_abi example (kernel/load)
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **C ABI** (`.knowledge/designs/0001-c-abi.md`): The new doc explains the `TVMFFIAny` 128-bit layout (type_index + reserved + payload), the `tvm_ffi_c_abi` calling convention, and the `__tvm_ffi_` symbol prefix convention.
- **Module export system** (`.knowledge/designs/0008-module-export-system.md`): The loader example uses `TVMFFIFunctionGetGlobal` to look up `"ffi.Module.load_from_file.so"` and `"ffi.ModuleGetFunction"`, then calls them via `TVMFFIFunctionCall`.
- **Function system** (`.knowledge/designs/0004-function-system.md`): The examples demonstrate the packed calling convention (`TVMFFIFunctionCall`) from pure C.
- **Error handling** (`.knowledge/designs/0007-error-handling.md`): Callee uses `TVMFFIErrorSetRaisedFromCStr`; caller uses `TVMFFIErrorMoveFromRaised` + `TVMFFIErrorCell` to extract error kind/message.
- **FFI symbol prefix** (`.knowledge/ADRs/0027-ffi-symbol-prefix.md`): The C callee defines `__tvm_ffi_add_one_cpu` following the convention.

Design elements this commit produces:
- No new design elements introduced. This is a documentation and example commit that codifies existing C ABI conventions.
