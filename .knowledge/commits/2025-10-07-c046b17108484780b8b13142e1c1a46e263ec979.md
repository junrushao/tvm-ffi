# Fix schema type display to use `dtype` instead of internal `DataType` class name

## TL;DR
- Adds `"DataType": "dtype"` mapping to `_TYPE_SCHEMA_ORIGIN_CONVERTER` in `type_info.pxi`, so that reflected type schemas display the public `dtype` alias instead of the internal `DataType` class name.
- Updates test expectations in `test_metadata.py` to match the corrected output.

## Key Exports
None -- no new public API. This commit fixes a mapping entry in an existing lookup table.

## Impact
- API: Schema string representations for `DataType`-typed fields and function parameters now render as `dtype` instead of `DataType`. Affects `TypeSchema.__repr__()` output, stub generation, and any downstream code that inspects schema strings.
- Behavioral: `TypeSchema.from_json_obj()` now converts the C++ type name `"DataType"` to `"dtype"` via the origin converter, aligning displayed type with `tvm_ffi.dtype` (the public Python entry point).
- Flags/config: none
- Data formats/schemas: The JSON type schema metadata from C++ is unchanged; only the Python-side rendering is affected.

## Design Elements
Design elements this commit consumes:
- `_TYPE_SCHEMA_ORIGIN_CONVERTER` dict in `python/tvm_ffi/cython/type_info.pxi` -- maps C++ type names from reflection JSON to Python-friendly display names. Used by `TypeSchema.from_json_obj()`. See [0009-reflection.md](../designs/0009-reflection.md) and [0014-python-package.md](../designs/0014-python-package.md).
- `TypeSchema` dataclass in `type_info.pxi` -- parses and renders type schema JSON for display.
- `tvm_ffi.dtype` -- the public Python-level type for data types, re-exported from `tvm_ffi.__init__`. See [0014-python-package.md](../designs/0014-python-package.md).

Design elements this commit produces: none

## Usage Examples
**Before** (incorrect):
```python
metadata = get_global_func_metadata("testing.schema_id_dtype")
schema = TypeSchema.from_json_str(metadata["type_schema"])
str(schema)  # "Callable[[DataType], DataType]"  -- exposes internal class name
```

**After** (corrected):
```python
metadata = get_global_func_metadata("testing.schema_id_dtype")
schema = TypeSchema.from_json_str(metadata["type_schema"])
str(schema)  # "Callable[[dtype], dtype]"  -- uses public tvm_ffi.dtype alias
```
