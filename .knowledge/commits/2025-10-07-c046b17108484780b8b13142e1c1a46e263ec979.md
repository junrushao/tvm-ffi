# Fix TypeSchema to display `dtype` instead of `DataType` in Python
## TL;DR
- Adds `"DataType": "dtype"` to the `_TYPE_SCHEMA_ORIGIN_CONVERTER` mapping so that Python schema repr shows `dtype` (the public Python name via `tvm_ffi.dtype`) instead of the internal C++ `DataType`.

## Impact
- API: Schema string representation change for `DataType` fields/args: now shows `dtype` in Python.
