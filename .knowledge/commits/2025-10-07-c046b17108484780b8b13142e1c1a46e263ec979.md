# Fix TypeSchema to render DataType as dtype in Python type annotations

## TL;DR
- Adds a `"DataType": "dtype"` entry to `_TYPE_SCHEMA_ORIGIN_CONVERTER` in `type_info.pxi`, so that the C++ `DataType` origin string maps to Python's `dtype` (the public `tvm_ffi.dtype` class) instead of `DataType` (the internal Cython `tvm_ffi.core.DataType` cdef class).
- Updates test expectations in `test_metadata.py` to expect `dtype` instead of `DataType` in type schema string representations.

## Key Exports
None -- no new public API surface. This is a display/annotation fix within the existing `_TYPE_SCHEMA_ORIGIN_CONVERTER` table.

## Impact
- API: Type schema string representations for functions and fields involving `DataType` now display as `dtype` (e.g., `Callable[[dtype], dtype]` instead of `Callable[[DataType], DataType]`). This affects `TypeSchema.__str__()` output, auto-generated stubs, and any tooling that consumes schema display strings.
- ABI: none
- Behavioral: The `TypeSchema` Python representation changes for any schema origin that was `"DataType"`. This is a correctness fix -- `tvm_ffi.dtype` is the public interface, not `tvm_ffi.core.DataType`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeSchema origin converter** (`python/tvm_ffi/cython/type_info.pxi`): The `_TYPE_SCHEMA_ORIGIN_CONVERTER` dictionary that maps C++ type names to Python type annotation strings for schema rendering.
- **`tvm_ffi.dtype` class** (`.knowledge/designs/0014-python-bindings.md`): The public Python dtype class (`str` subclass) that wraps `tvm_ffi.core.DataType` internally.

Design elements this commit produces:
- **dtype display convention**: Establishes that `dtype` (not `DataType`) is the canonical Python type annotation for data type parameters in schema strings.

## Usage Examples
None -- this is a trivial display fix. After this commit:

```python
from tvm_ffi import get_global_func_metadata
from tvm_ffi.core import TypeSchema

metadata = get_global_func_metadata("testing.schema_id_dtype")
schema = TypeSchema.from_json_str(metadata["type_schema"])
print(str(schema))  # "Callable[[dtype], dtype]" (was "Callable[[DataType], DataType]")
```
