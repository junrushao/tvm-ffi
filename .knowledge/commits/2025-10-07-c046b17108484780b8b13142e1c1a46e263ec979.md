# Fix type schema to display `dtype` instead of internal `DataType` for DLDataType fields

## TL;DR
- Adds `"DataType": "dtype"` to `_TYPE_SCHEMA_ORIGIN_CONVERTER` in the Cython type schema module, so that C++ `DataType` fields/params render as `dtype` (the public Python name) in type schema strings.
- Updates test expectations from `Callable[[DataType], DataType]` to `Callable[[dtype], dtype]` and from field type `"DataType"` to `"dtype"`.

## Key Exports

None -- no new API surface. This is a one-line mapping fix in an existing lookup table.

## Impact
- API: None -- no function signatures or class interfaces changed.
- Behavioral: Type schema string representations for `DataType`-typed fields and function parameters now show `dtype` instead of `DataType`. Affects `TypeSchema.__str__()` output and any tooling that consumes schema strings (e.g., stubgen, IDE tooltips).
- Flags/config: None.
- Data formats/schemas: The `type_schema` JSON metadata for any field or global function using `DataType` now resolves to `dtype` when rendered as a Python type string.

## Design Elements
Design elements this commit consumes:
- **`_TYPE_SCHEMA_ORIGIN_CONVERTER`** (`.knowledge/designs/0012-python-bindings.md`): The C++-to-Python type name mapping table in `python/tvm_ffi/cython/type_info.pxi`. The commit adds a missing entry.
- **TypeSchema** (`.knowledge/designs/0008-reflection.md`): The reflection-derived type schema system that converts C++ type strings into Python-readable type annotations. The converter table is consumed during `TypeSchema.from_json_str()` rendering.
- **`tvm_ffi.dtype`** (`.knowledge/designs/0012-python-bindings.md`): The public Python-side name for `DLDataType`, distinct from the internal `tvm_ffi.core.DataType` class.

Design elements this commit produces: None.

## Usage Examples

**Before (incorrect):**
```python
metadata = get_global_func_metadata("testing.schema_id_dtype")
schema = TypeSchema.from_json_str(metadata["type_schema"])
str(schema)  # "Callable[[DataType], DataType]"  <-- internal name leaked
```

**After (corrected):**
```python
metadata = get_global_func_metadata("testing.schema_id_dtype")
schema = TypeSchema.from_json_str(metadata["type_schema"])
str(schema)  # "Callable[[dtype], dtype]"  <-- public Python name
```
