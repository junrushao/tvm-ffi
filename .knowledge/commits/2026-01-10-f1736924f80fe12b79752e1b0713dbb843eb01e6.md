## Design Elements
Design elements this commit consumes:
- **Function system** (`0004-ffi-function-system`): Documents `FunctionObj`, `TVMFFIFunctionCell` (`safe_call` + `cpp_call`), `Function::FromTyped`, `TypedFunction`, global registry (`refl::GlobalDef`), `TVMFFISafeCallType` calling convention.
- **Error protocol** (`0005-ffi-error-protocol`): Documents `ErrorObj`, `TVMFFIErrorCell` (kind/message/backtrace/update_backtrace), TLS error propagation, return codes (0/-1/-2), `TVM_FFI_THROW`, `TVM_FFI_SAFE_CALL_BEGIN`/`END`, `TVMFFIErrorMoveFromRaised`, `TVMFFIErrorSetRaisedFromCStr`.
- **Module system** (`0011-ffi-module-system`): Documents `ModuleObj`/`Module`, shared library loading via `dlopen`/`LoadLibraryW`, `TVM_FFI_DLL_EXPORT_TYPED_FUNC`, system library via `TVMFFIEnvModRegisterSystemLibSymbol`, `tvm_ffi.load_module`, `tvm_ffi.system_lib`, `tvm_ffi.cpp.load`.
- **C ABI** (`0001-ffi-c-abi`): Documents `TVMFFISafeCallType` signature, `TVMFFIFunctionCall`, `TVMFFIFunctionGetGlobal`, `TVMFFIFunctionSetGlobal`.
- **Any value system** (`0002-ffi-any-value-system`): Cross-referenced via `object-conversion-with-any` anchor in `object_and_class.rst`.
