# Add Tensor and DLPack concept doc; editorial fixes to quickstart, stable C ABI, and packaging guides
## TL;DR
- Adds `docs/concepts/tensor.rst` (483 lines): a comprehensive tutorial on TVM-FFI tensor types (DLPack vs TVM-FFI), ownership semantics (view vs managed), Any/AnyView conversion paths, allocation APIs, and stream handling.
- Adds a `(object-storage-format)=` cross-reference target to `docs/concepts/abi_overview.md` so the tensor doc can link to the Object Storage Format section.
- Applies editorial/prose cleanup across `quickstart.rst`, `stable_c_abi.rst`, and `python_packaging.rst` (wording, punctuation, consistency); no semantic changes.

## Design Elements
Design elements this commit consumes:
- **Tensor / TensorObj / TensorView** ownership model -- the new doc formalizes the view vs managed distinction already present in C++ headers. Related: [0014-stream-and-env-context.md](../designs/0014-stream-and-env-context.md) (stream and env allocator for tensors).
- **Any/AnyView type-erased container** -- the doc explains how tensors are stored in `TVMFFIAny` with two type indices (`kTVMFFIDLTensorPtr` for views, `kTVMFFITensor` for objects). Related: [0003-any-system.md](../designs/0003-any-system.md).
- **Object system** (ref-counted `ObjectRef` pattern) -- `TensorObj`/`Tensor` follows the `FooObj`/`Foo` pattern. Related: [0002-object-system.md](../designs/0002-object-system.md).
- **DLPack exchange protocol** -- the doc references `DLTensor`, `DLManagedTensorVersioned`, `DLDataType`, `DLDevice`. Related: [ADR 0015-dlpack-exchange-api-struct.md](../ADRs/0015-dlpack-exchange-api-struct.md), [ADR 0012-inplace-tail-allocation-for-tensor-metadata.md](../ADRs/0012-inplace-tail-allocation-for-tensor-metadata.md).
- **C ABI stable layout** -- the doc references `TVMFFIAny`, `TVMFFIObject`, `TVMFFITypeIndex`. Related: [0001-c-abi.md](../designs/0001-c-abi.md).
- **Stream and env context** -- the doc covers `TVMFFIEnvGetStream`, `TVMFFIEnvTensorAlloc`, `Tensor::FromEnvAlloc`. Related: [0014-stream-and-env-context.md](../designs/0014-stream-and-env-context.md).

Design elements this commit produces:
- **Tensor concept documentation** -- first dedicated tutorial-style doc for tensor types, their memory layouts, ABI conversion paths, and allocation/stream APIs. This fills a gap: previously tensor knowledge was spread across C++ headers and the stream/env-context design doc.
