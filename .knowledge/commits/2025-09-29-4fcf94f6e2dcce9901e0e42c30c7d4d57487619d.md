# Add `build_inline` utility that compiles inline C++/CUDA without loading

## TL;DR
- Extracts the compilation logic from `load_inline` into a new `build_inline` function that returns the shared library path (`str`) instead of a loaded `Module`.
- `load_inline` is preserved as a thin wrapper: `load_module(build_inline(...))`.
- Adds test (`test_build_inline.py`), docs (python guide, API reference), and exports `build_inline` from `tvm_ffi.cpp`.

## Key Exports

## Impact
- API: Additive -- new public function `tvm_ffi.cpp.build_inline`. `load_inline` signature and return type unchanged.
- Behavioral: `load_inline` internal implementation now delegates to `build_inline` + `load_module`; external behavior identical.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Module system / `load_module`** ([`.knowledge/designs/0011-module-system.md`](../designs/0011-module-system.md)) -- `load_inline` now calls `load_module(build_inline(...))` to load the compiled library.
- **Inline compilation pipeline** (same design doc, "Inline Module Compilation" section) -- `build_inline` inherits all compilation internals: source hashing, ninja build generation, cache directory management.

Design elements this commit produces:
- **`build_inline` public API** -- a new entry point for compile-only workflows, enabling callers to inspect, redistribute, or separately load compiled shared libraries.
- **Build/load separation pattern** -- establishes the convention that compilation and loading are independently accessible steps in the inline module pipeline.

## Usage Examples

Compile inline C++ and load separately (from `test_build_inline.py`):

```python
import numpy
import tvm_ffi.cpp
from tvm_ffi.module import Module

# Step 1: compile only — returns path to .so
lib_path: str = tvm_ffi.cpp.build_inline(
    name="hello",
    cpp_sources=r"""
        void add_one_cpu(tvm::ffi::Tensor x, tvm::ffi::Tensor y) {
          for (int i = 0; i < x->shape[0]; ++i)
            static_cast<float*>(y->data)[i] = static_cast<float*>(x->data)[i] + 1;
        }
    """,
    functions=["add_one_cpu"],
)

# Step 2: load separately
mod: Module = tvm_ffi.load_module(lib_path)

x = numpy.array([1, 2, 3, 4, 5], dtype=numpy.float32)
y = numpy.empty_like(x)
mod.add_one_cpu(x, y)
numpy.testing.assert_equal(x + 1, y)
```
