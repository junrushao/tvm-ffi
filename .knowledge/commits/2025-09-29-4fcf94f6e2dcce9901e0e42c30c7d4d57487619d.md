# Add build_inline utility and refactor load_inline to use it
## TL;DR
- Extracts the compilation-only logic from `load_inline` into `build_inline`, which returns the path to the built shared library instead of a loaded `Module`.
- `load_inline` is refactored to call `build_inline` then `load_module`, enabling users to build without loading.
- Adds `test_build_inline.py` test and updates Sphinx docs (`python_guide.md`, `reference/python/index.rst`, `conf.py`).

## Impact
- API: New `tvm_ffi.cpp.build_inline()` function. `load_inline` is unchanged in signature.
- Flags/config: `autodoc_typehints = "description"` added to Sphinx `conf.py`.
- Data formats/schemas: None
