# Add build_inline utility to compile inline C++/CUDA without loading
## TL;DR
- Refactors `load_inline` to extract `build_inline` as a standalone function that compiles inline C++/CUDA source and returns the path to the built shared library.
- `load_inline` now delegates to `build_inline` + `load_module`.
- Adds `autodoc_typehints = 'description'` to Sphinx config and documents `build_inline` in API reference.
