# Add build_inline utility for compiling without loading

## TL;DR
- Refactors `load_inline` into `build_inline` (returns shared library path) + `load_inline` (calls `build_inline` then loads). This separates compilation from loading.
- Adds `autodoc_typehints = "description"` to Sphinx config.
- Documents `build_inline` in Python guide and API reference.

## Key Exports

**Functions**:
- `tvm_ffi.cpp.build_inline(name, *, cpp_sources, cuda_sources, functions, extra_cflags, extra_cuda_cflags, extra_ldflags, extra_include_paths, build_directory) -> str` -- compiles inline C++/CUDA source to shared library, returns path without loading.

## Impact
- API: New `build_inline` function. `load_inline` now delegates to `build_inline`.
- ABI: none
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Inline module compilation** (`.knowledge/designs/0017-inline-module-compilation.md`): `load_inline`

Design elements this commit produces:
- **build_inline separation**: decouples compilation from module loading, enabling use cases like pre-compilation or custom loading.

## Usage Examples
```python
import tvm_ffi
# Build without loading
lib_path = tvm_ffi.cpp.build_inline(
    name='hello',
    cpp_sources='void add_one(const int* in, int* out, int n) { ... }',
    functions='add_one'
)
# Load separately
mod = tvm_ffi.load_module(lib_path)
```
