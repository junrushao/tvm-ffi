# Add test for subclassing tvm_ffi.Function (Cython cdef class)
## TL;DR
- Adds `test_function_subclass` documenting the pattern for subclassing `tvm_ffi.Function` (a Cython `cdef` class) with a Python mixin, including workarounds for `__init__` and `__call__` inheritance.
- Demonstrates handle transfer via `__move_handle_from__` and FFI round-trip identity preservation via `__chandle__` equality.

## Key Exports
The commit produces no new public API. It documents consumption patterns for existing APIs:

```python
# Pattern: subclassing tvm_ffi.Function (Cython cdef class) with a Python mixin
class MyFunction(tvm_ffi.Function, JitFunction):
    def __init__(self, metadata: Any) -> None:
        # Invariant: super().__init__() CANNOT be used -- Function is a Cython extension type
        JitFunction.__init__(self, metadata)

    # Invariant: __call__ must be explicitly re-assigned when __init__ is overridden
    # on a Cython cdef subclass, otherwise the subclass may not be callable
    __call__ = tvm_ffi.Function.__call__

# Object.__move_handle_from__(other: Object) -> None
#   Transfers raw chandle pointer from other to self, sets other.chandle = NULL
#   Interacts with: Object.chandle (cdef attribute in object.pxi)
#   Invariant: after move, other is invalidated (chandle == NULL)

# Object.__chandle__() -> int
#   Returns raw C handle as Python int for identity comparison
#   Interacts with: Object.chandle (cdef attribute)
```

## Usage Examples
Subclassing `tvm_ffi.Function` to attach JIT metadata while preserving callability:

```python
class JitFunction:
    def __init__(self, metadata):
        self.metadata = metadata

class MyFunction(tvm_ffi.Function, JitFunction):
    def __init__(self, metadata):
        JitFunction.__init__(self, metadata)  # explicit -- super() broken for cdef
    __call__ = tvm_ffi.Function.__call__      # explicit -- cdef __call__ not auto-inherited

f = tvm_ffi.convert(lambda x: x)
f_sub = MyFunction(128)
f_sub.__move_handle_from__(f)  # transfer underlying FunctionObj handle
assert f_sub(2) == 2           # callable via explicit __call__
assert f_sub.metadata == 128   # mixin attribute preserved

# FFI round-trip preserves handle identity (not Python subclass type)
echo = tvm_ffi.get_global_func("testing.echo")
fechoed = echo(f_sub)
assert fechoed.__chandle__() == f_sub.__chandle__()
```
