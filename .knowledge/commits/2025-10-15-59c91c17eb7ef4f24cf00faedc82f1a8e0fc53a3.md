# Add test for subclassing tvm_ffi.Function with metadata mixin
## TL;DR
- Adds `test_function_subclass()` demonstrating how to subclass the Cython `tvm_ffi.Function` extension type with a Python mixin (`JitFunction`) that carries user metadata.
- Documents two Cython subclassing caveats: (1) must call mixin `__init__` directly instead of `super().__init__()`, (2) must explicitly reassign `__call__ = tvm_ffi.Function.__call__` to preserve callability.
- Validates handle transfer (`__move_handle_from__`), round-trip through FFI (`testing.echo`), and handle identity (`__chandle__`).

## Usage Examples
The test itself serves as the canonical usage example for `Function` subclassing:

```python
class JitFunction:
    def __init__(self, metadata):
        self.metadata = metadata

class MyFunction(tvm_ffi.Function, JitFunction):
    def __init__(self, metadata):
        # Cannot use super().__init__() -- Function is a Cython cdef class
        JitFunction.__init__(self, metadata)
    # Must explicitly reassign __call__ when overriding __init__
    __call__ = tvm_ffi.Function.__call__

f = tvm_ffi.convert(lambda x: x)
f_sub = MyFunction(128)
f_sub.__move_handle_from__(f)   # transfer handle
assert f_sub(2) == 2            # callable via reassigned __call__
assert f_sub.metadata == 128    # mixin metadata preserved
```
