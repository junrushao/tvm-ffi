# Add test for subclassing tvm_ffi.Function with metadata mixin
## TL;DR
- Adds `test_function_subclass()` demonstrating how to subclass `tvm_ffi.Function` (a Cython cdef class) with a Python mixin (`JitFunction`) to attach custom metadata.
- Documents the required workarounds: explicit `JitFunction.__init__` call (not `super()`), explicit `__call__ = tvm_ffi.Function.__call__` reassignment, and `__move_handle_from__` for handle transfer.
- Validates that a subclassed function remains callable, preserves metadata, and round-trips through the FFI (via `testing.echo`) retaining handle identity.

## Usage Examples
Subclassing `tvm_ffi.Function` with a metadata mixin (from the test):
```python
class JitFunction:
    def __init__(self, metadata):
        self.metadata = metadata

class MyFunction(tvm_ffi.Function, JitFunction):
    def __init__(self, metadata):
        # Cannot use super() — tvm_ffi.Function is a Cython cdef class without __init__
        JitFunction.__init__(self, metadata)
    # Cython cdef class __call__ not inherited automatically on subclass with __init__
    __call__ = tvm_ffi.Function.__call__

f = tvm_ffi.convert(lambda x: x)
f_sub = MyFunction(128)
f_sub.__move_handle_from__(f)  # transfer handle from existing function
assert f_sub(2) == 2           # callable
assert f_sub.metadata == 128   # metadata preserved
```
