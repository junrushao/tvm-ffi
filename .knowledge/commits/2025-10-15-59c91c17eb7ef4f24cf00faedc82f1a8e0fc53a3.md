# Add test for subclassing tvm_ffi.Function with metadata mixin and handle transfer

## TL;DR
- Adds `test_function_subclass` to `tests/python/test_function.py`, documenting the pattern for subclassing `tvm_ffi.Function` (a Cython `cdef class`) from Python.
- Demonstrates the required workarounds: explicit mixin `__init__`, explicit `__call__` re-assignment, and `__move_handle_from__` for handle ownership transfer.
- Validates that a subclassed `Function` instance passes through the FFI registry (`testing.echo`) with pointer identity preserved.

## Usage Examples
```python
# Subclassing tvm_ffi.Function (a Cython cdef class) to attach metadata.
#
# Cython cdef classes do not support standard Python MRO __init__ chaining,
# so the mixin must be initialized explicitly and special methods re-assigned.

import tvm_ffi
from typing import Any

class JitFunction:
    def __init__(self, metadata: Any) -> None:
        self.metadata = metadata

class MyFunction(tvm_ffi.Function, JitFunction):
    def __init__(self, metadata: Any) -> None:
        # tvm_ffi.Function is a Cython extension type — calling super().__init__()
        # is not valid. Initialize the pure-Python mixin explicitly.
        JitFunction.__init__(self, metadata)

    # When subclassing a Cython cdef class and overriding __init__,
    # special methods like __call__ may not be inherited automatically.
    # Explicitly re-bind to ensure the subclass remains callable.
    __call__ = tvm_ffi.Function.__call__  # type: ignore

# Construct a Function, then move its handle into the subclass instance.
f = tvm_ffi.convert(lambda x: x)
f_sub = MyFunction(128)
f_sub.__move_handle_from__(f)          # transfers chandle; f.chandle becomes NULL

assert isinstance(f_sub, MyFunction)
assert isinstance(f_sub, JitFunction)
assert f_sub.metadata == 128
assert f_sub(2) == 2                   # __call__ works via explicit re-assignment

# Function subclasses are transparent to the FFI registry.
echo = tvm_ffi.get_global_func("testing.echo")
fechoed = echo(f_sub)
assert fechoed.__chandle__() == f_sub.__chandle__()   # pointer identity preserved
assert fechoed(10) == 10
```
