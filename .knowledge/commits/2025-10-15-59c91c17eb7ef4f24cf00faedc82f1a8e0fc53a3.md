# Add test for subclassing tvm_ffi.Function with metadata mixin

## TL;DR
- Adds `test_function_subclass()` that validates subclassing the Cython `tvm_ffi.Function` cdef class with a Python mixin (`JitFunction`) carrying custom metadata.
- Documents three workarounds for Cython cdef class subclassing: explicit mixin init (no `super()`), explicit `__call__` assignment, and `__move_handle_from__` for handle transfer.
- Verifies FFI round-trip: a subclass instance passed through `testing.echo` returns as a plain `tvm_ffi.Function` sharing the same `__chandle__()`.

## Key Exports

```python
# No new exports. Test exercises existing APIs:

# Pattern: subclassing tvm_ffi.Function (Cython cdef class)
class MyFunction(tvm_ffi.Function, JitFunction):
    def __init__(self, metadata):
        JitFunction.__init__(self, metadata)  # explicit mixin init, not super()
    __call__ = tvm_ffi.Function.__call__       # explicit special method re-assignment

# Existing APIs exercised:
Object.__move_handle_from__(self, other: Object) -> None
    # Transfers chandle from other to self, nulls other's chandle
    # Interacts with: Cython Object.chandle (cdef void* field)

Object.__chandle__(self) -> int
    # Returns raw chandle as uint64
    # Interacts with: identity comparison after FFI round-trip
```

## Usage Examples
Subclassing `tvm_ffi.Function` to attach JIT metadata:
```python
class JitFunction:
    def __init__(self, metadata):
        self.metadata = metadata

class MyFunction(tvm_ffi.Function, JitFunction):
    def __init__(self, metadata):
        JitFunction.__init__(self, metadata)       # no super() for Cython cdef
    __call__ = tvm_ffi.Function.__call__            # re-export __call__

f = tvm_ffi.convert(lambda x: x)
f_sub = MyFunction(128)
f_sub.__move_handle_from__(f)                       # transfer handle
assert f_sub.metadata == 128
assert f_sub(2) == 2                                # callable works
```
