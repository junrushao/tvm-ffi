# Robustify kwargs wrapper: rename parameters, add keyword validation and exclude_arg_names
## TL;DR
- Renames all public parameters in `make_kwargs_wrapper` and `make_kwargs_wrapper_from_signature` for brevity and consistency (`args_names` -> `arg_names`, `kwargsonly_names` -> `kwonly_names`, `prototype_func` -> `prototype`, etc.)
- Adds `exclude_arg_names` parameter to `make_kwargs_wrapper_from_signature` to skip specified arguments when extracting from a signature
- Adds Python keyword validation (e.g., `if`, `class`) in `_validate_argument_names` to reject reserved keywords as parameter names

### Parameter Rename Mapping

| Old name | New name |
|---|---|
| `args_names` | `arg_names` |
| `args_defaults` | `arg_defaults` |
| `kwargsonly_names` | `kwonly_names` |
| `kwargsonly_defaults` | `kwonly_defaults` |
| `prototype_func` | `prototype` |

## Impact
- API: Breaking rename of all public parameters in `make_kwargs_wrapper` and `make_kwargs_wrapper_from_signature`. Any caller using keyword arguments with old names (`args_names=`, `kwargsonly_names=`, `prototype_func=`) will break. No external callers found in this codebase at commit time.
- Behavioral: New `ValueError` raised for Python keywords used as parameter names (previously allowed, would produce broken generated code)
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Python `keyword.iskeyword` stdlib for reserved word detection
- Python `inspect.Signature` / `inspect.Parameter` for parameter extraction
- `functools.update_wrapper` for metadata propagation
- `exec()`-based code generation pattern (same as Python `dataclasses` module)

Design elements this commit produces:
- `exclude_arg_names` parameter on `make_kwargs_wrapper_from_signature`: a general mechanism for filtering parameters when generating wrappers from signatures. Enables callers to skip "self" or internal parameters that should not appear in the generated wrapper.
- Python keyword validation in `_validate_argument_names`: hardens the code generation path against producing syntactically invalid Python code.

## Usage Examples
Using `exclude_arg_names` to skip parameters from a signature:

```python
import inspect
from tvm_ffi.utils.kwargs_wrapper import make_kwargs_wrapper_from_signature

def source(a, b, c=10, d=20):
    pass

target = lambda *args: sum(args)

# Skip 'c' from the signature -- wrapper gets (a, b, d=20)
wrapper = make_kwargs_wrapper_from_signature(
    target, inspect.signature(source), exclude_arg_names=["c"]
)
wrapper(1, 2)       # -> 23  (1 + 2 + 20)
wrapper(1, 2, d=5)  # -> 8   (1 + 2 + 5)

# Non-existent names in exclude_arg_names are silently ignored
wrapper = make_kwargs_wrapper_from_signature(
    target, inspect.signature(source), exclude_arg_names=["non_existent"]
)
wrapper(1, 2)  # -> 33  (1 + 2 + 10 + 20), same as no exclusion
```
