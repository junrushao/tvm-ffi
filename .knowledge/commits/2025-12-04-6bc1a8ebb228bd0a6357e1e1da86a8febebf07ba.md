# Robustify kwargs_wrapper: rename parameters, add keyword validation and exclude_arg_names support
## TL;DR
- Renames API parameters for consistency: `args_names` -> `arg_names`, `args_defaults` -> `arg_defaults`, `kwargsonly_names` -> `kwonly_names`, `kwargsonly_defaults` -> `kwonly_defaults`, `prototype_func` -> `prototype`.
- Adds `exclude_arg_names` parameter to `make_kwargs_wrapper_from_signature` allowing callers to skip specific parameters from the generated wrapper (e.g., `self`).
- Adds Python keyword validation (`keyword.iskeyword`) to reject parameter names that are Python reserved words (e.g., `class`, `return`).

| Old name | New name |
|----------|----------|
| `args_names` | `arg_names` |
| `args_defaults` | `arg_defaults` |
| `kwargsonly_names` | `kwonly_names` |
| `kwargsonly_defaults` | `kwonly_defaults` |
| `prototype_func` | `prototype` |
| `__i_args_defaults` | `__i_arg_defaults` |

## Key Exports

**Functions** (updated signatures):
- `make_kwargs_wrapper(target_func, arg_names, arg_defaults=(), kwonly_names=None, kwonly_defaults=None, prototype=None) -> Callable`
- `make_kwargs_wrapper_from_signature(target_func, signature, prototype=None, exclude_arg_names=None) -> Callable` -- New `exclude_arg_names: Iterable[str] | None` parameter.

## Impact
- API: **Breaking** for callers of `make_kwargs_wrapper` and `make_kwargs_wrapper_from_signature` using keyword arguments with old parameter names. Since the module was introduced one commit ago (3115b23), this is effectively still the initial API stabilization.
- Behavioral: Argument names that are Python keywords (e.g., `class`, `return`) are now rejected with a `ValueError`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **kwargs_wrapper codegen pattern** (introduced in 3115b23): Extends the pattern with keyword validation and argument exclusion.

Design elements this commit produces:
- **`exclude_arg_names` pattern**: Convention for skipping parameters (like `self`) when generating wrappers from signatures. Silently ignores names not in the signature.

## Usage Examples
```python
from tvm_ffi.utils.kwargs_wrapper import make_kwargs_wrapper_from_signature
import inspect

sig = inspect.Signature([
    inspect.Parameter("self", inspect.Parameter.POSITIONAL_OR_KEYWORD),
    inspect.Parameter("x", inspect.Parameter.POSITIONAL_OR_KEYWORD),
    inspect.Parameter("y", inspect.Parameter.POSITIONAL_OR_KEYWORD, default=10),
])
# Skip 'self' in generated wrapper
wrapped = make_kwargs_wrapper_from_signature(fn, sig, exclude_arg_names=["self"])
# wrapped(x, y=10) -- no 'self' parameter
```
