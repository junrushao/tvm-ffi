# Enable custom structural equality and hash via TypeAttr dispatch (kTVMFFISEqHashKindCustomTreeNode)

## TL;DR
- Adds `kTVMFFISEqHashKindCustomTreeNode = 6` to the `TVMFFISEqHashKind` C ABI enum, enabling types to opt out of the reflection-driven field traversal and supply their own `__s_equal__`/`__s_hash__` functions registered as `TypeAttr` entries.
- Both `StructEqualHandler` and `StructuralHashHandler` gain a new dispatch branch for the new kind: they look up the type's `__s_equal__`/`__s_hash__` column entry, lazily build a callback closure (capturing the handler's internal state), and invoke it.
- Also fixes a pre-existing bug in `object.cc`: when `TVMFFITypeRegisterAttr` is called for an already-existing column name, it now correctly reads back the existing `column_index` from the map (the `else` branch was missing).

## Impact
- API: `TVMFFISEqHashKind` enum gains `kTVMFFISEqHashKindCustomTreeNode = 6`. Downstream code doing exhaustive enum switches needs a new case.
- Behavioral: Existing kinds (0–5) are unaffected. `kTVMFFISEqHashKindFreeVar` equal-map recording is now done **after** the dispatch branch (previously it was inside the `else` branch of field traversal, which excluded the custom case — now it unconditionally runs post-dispatch for all non-custom kinds).
- Flags/config: New CMake option `TVM_FFI_USE_EXTRA_CXX_API` (default ON) guards the `structural_equal.cc`, `structural_hash.cc`, and `access_path.cc` sources. When OFF, those files are excluded from the shared library.
- Data formats/schemas: `TVMFFITypeAttrColumn` C struct is now relied upon at runtime for behavioral dispatch (not just metadata), raising the criticality of correct column registration order.

## Design Elements

Design elements this commit consumes:
- `TVMFFISEqHashKind` enum and structural eq/hash dispatch (`kTVMFFISEqHashKindFreeVar`, `kTVMFFISEqHashKindDAGNode`) — `0001-c-abi.md`, `0006-reflection.md`
- `TypeAttrDef` builder and `TypeAttrColumn` accessor (introduced in commit 2025-07-22) — currently only documented inline; no standalone design record.
- `ffi::Function::FromTyped` for constructing the callback closures — `0004-function-system.md`
- `TVM_FFI_ICHECK` / `TVM_FFI_STATIC_INIT_BLOCK` conventions — `0005-error-system.md`

Design elements this commit produces:
- **`kTVMFFISEqHashKindCustomTreeNode`**: New enum value in `TVMFFISEqHashKind` that activates the `TypeAttr`-based dispatch path. Sets the contract that `__s_equal__` and `__s_hash__` entries must exist in the type's TypeAttr column.
- **`__s_equal__` / `__s_hash__` TypeAttr protocol**: A convention that types declare by setting `_type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode` and registering both attributes via `TypeAttrDef`. The function signatures (with `cmp`/`hash` callbacks and `def_region` flag) are now part of the public C ABI documentation in `c_api.h`.
- **`def_region` callback semantics**: The concept that a boolean parameter in `cmp`/`hash` callbacks temporarily flips `map_free_vars_` in the handler to enable free-variable binding at the call site. This is a new invariant not present in prior dispatch paths.

## Usage Examples

**Registering custom structural equal/hash for a new object type:**

```cpp
// In testing_object.h (tests/cpp/testing_object.h):

class TCustomFuncObj : public Object {
 public:
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;   // intentionally excluded from structural comparison

  bool SEqual(const TCustomFuncObj* other,
              ffi::TypedFunction<bool(AnyView, AnyView, bool, AnyView)> cmp) const {
    if (!cmp(params, other->params, /*def_region=*/true, "params")) return false;
    if (!cmp(body, other->body, /*def_region=*/false, "body")) return false;
    return true;   // comment is ignored
  }

  uint64_t SHash(uint64_t type_key_hash,
                 ffi::TypedFunction<uint64_t(AnyView, bool)> hash) const {
    uint64_t h = type_key_hash;
    h = StableHashCombine(h, hash(params, /*def_region=*/true));
    h = StableHashCombine(h, hash(body, /*def_region=*/false));
    return h;
  }

  static void RegisterReflection() {
    refl::ObjectDef<TCustomFuncObj>()
        .def_ro("params", &TCustomFuncObj::params)
        .def_ro("body", &TCustomFuncObj::body)
        .def_ro("comment", &TCustomFuncObj::comment);
    // Register TypeAttr dispatch entries:
    refl::TypeAttrDef<TCustomFuncObj>()
        .def("__s_equal__", &TCustomFuncObj::SEqual)
        .def("__s_hash__", &TCustomFuncObj::SHash);
  }

  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode;
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TCustomFuncObj, Object);
};
// Result: refl::StructuralEqual()(fa, fb) returns true when params/body match
// structurally even if variable names differ; "comment" is ignored entirely.
```
