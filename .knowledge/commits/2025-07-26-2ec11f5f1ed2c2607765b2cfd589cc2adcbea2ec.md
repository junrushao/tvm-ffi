# Add kTVMFFISEqHashKindCustomTreeNode for user-defined structural equal/hash via TypeAttrColumn
## TL;DR
- Introduces `kTVMFFISEqHashKindCustomTreeNode = 6` to the `TVMFFISEqHashKind` C ABI enum, enabling object types to provide custom `__s_equal__` and `__s_hash__` implementations registered via `TypeAttrDef`.
- Refactors FreeVar/DAGNode post-processing in `structural_equal.cc` and `structural_hash.cc` to apply *after* field comparison (or custom function), rather than as a mutually exclusive branch, fixing a latent correctness issue where custom tree nodes could not coexist with free-var mapping.
- Fixes a bug in `TypeTable::RegisterTypeAttr` where a duplicate column name would create a new column instead of reusing the existing one.
- Adds `TVM_FFI_USE_EXTRA_CXX_API` CMake option (default ON) to make reflection source files (`access_path.cc`, `structural_equal.cc`, `structural_hash.cc`) optional in the shared library build.

## Key Exports

**Constants/Enums**:
```c
// include/tvm/ffi/c_api.h
kTVMFFISEqHashKindCustomTreeNode = 6
```
Objects with `_type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode` delegate structural equality and hashing to user-defined functions registered as `__s_equal__` and `__s_hash__` type attributes via `TypeAttrDef`.

**Custom `__s_equal__` function signature** (registered via `TypeAttrDef`):
```cpp
bool __s_equal__(
  ObjectRefType self,
  ObjectRefType other,
  ffi::TypedFunction<bool(AnyView lhs, AnyView rhs, bool def_region, AnyView field_name)> cmp
);
```

**Custom `__s_hash__` function signature** (registered via `TypeAttrDef`):
```cpp
uint64_t __s_hash__(
  ObjectRefType self,
  uint64_t type_key_hash,
  ffi::TypedFunction<uint64_t(AnyView val, bool def_region)> hash
);
```

**CMake option**:
```cmake
option(TVM_FFI_USE_EXTRA_CXX_API "Enable extra CXX API in shared lib" ON)
```
Controls whether `src/ffi/reflection/{access_path,structural_equal,structural_hash}.cc` are compiled into the shared library.

**`StructEqualHandler::s_equal_callback_`** (private member, lazily initialized):
```cpp
ffi::Function s_equal_callback_ = nullptr;
// Wraps CompareAny with def_region support and mismatch path recording
```

**`StructuralHashHandler::s_hash_callback_`** (private member, lazily initialized):
```cpp
ffi::Function s_hash_callback_ = nullptr;
// Wraps HashAny with def_region support (swaps map_free_vars_ when def_region=true)
```

## Impact
- API: New enum value `kTVMFFISEqHashKindCustomTreeNode = 6` added to `TVMFFISEqHashKind` in the public C ABI header `c_api.h`. Downstream types can now opt into custom structural comparison by setting `_type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode` and registering `__s_equal__`/`__s_hash__` type attributes.
- Behavioral: FreeVar equality mapping (`equal_map_lhs_`/`equal_map_rhs_`) and DAGNode graph counter are now applied *after* successful field comparison, not as an alternative to it. For `kTVMFFISEqHashKindFreeVar`, the handler now checks content equality of fields before deciding whether to map the free variable, enabling prechecking of type signatures as noted in the commit message. This is a semantic change to existing FreeVar comparison behavior.
- Flags/config: New CMake option `TVM_FFI_USE_EXTRA_CXX_API` (default ON). When OFF, reflection source files are excluded from the shared library build.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **TypeAttrColumn** (`reflection/accessor.h`): Used as `static` local to look up `__s_equal__`/`__s_hash__` functions by type index at runtime. See `0009-reflection.md` (TypeAttrColumn is not yet documented there).
- **TypeAttrDef** (`reflection/registry.h`): Used in test code (`TCustomFuncObj::RegisterReflection`) to register custom `__s_equal__` and `__s_hash__` functions. See `0009-reflection.md` (TypeAttrDef is not yet documented there).
- **EnsureTypeAttrColumn** (`reflection/registry.h`): Called at static init to guarantee the `__s_equal__`/`__s_hash__` columns exist even if no type has registered custom functions yet.
- **TVMFFISEqHashKind enum** (`c_api.h`): Extended with new value.
- **ForEachFieldInfo / ForEachFieldInfoWithEarlyStop** (`reflection/accessor.h`): Used for non-custom field traversal.
- **ffi::Function::FromTyped**: Used to create type-erased callback wrappers for the comparison/hash delegates.
- **AccessStep::ObjectField** (`reflection/access_path.h`): Used in custom equal handler to record mismatch paths.
- **details::StableHashCombine**: Used in custom hash handler to combine sub-hashes.

Design elements this commit produces:
- **`kTVMFFISEqHashKindCustomTreeNode`** (new enum value = 6): Opts a type into custom structural equal/hash dispatch.
- **Custom structural equal/hash protocol**: Convention that types with `_type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode` must register `__s_equal__` and `__s_hash__` type attributes with specific signatures. The `cmp` callback supports `def_region` flag for free-variable scoping.
- **`TVM_FFI_USE_EXTRA_CXX_API` CMake option**: Build-time toggle for optional C++ reflection APIs.
- **Refactored FreeVar/DAGNode post-processing**: FreeVar mapping and DAGNode counter application are now decoupled from field traversal, applied unconditionally after comparison succeeds.

## Usage Examples

**Defining a type with custom structural equal/hash** (from test):
```cpp
class TCustomFuncObj : public Object {
 public:
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;  // intentionally excluded from comparison

  bool SEqual(const TCustomFuncObj* other,
              TypedFunction<bool(AnyView, AnyView, bool, AnyView)> cmp) const {
    // def_region=true for params (enables free-var mapping)
    if (!cmp(params, other->params, true, "params")) return false;
    // def_region=false for body (regular comparison)
    if (!cmp(body, other->body, false, "body")) return false;
    return true;
  }

  uint64_t SHash(uint64_t type_key_hash,
                 TypedFunction<uint64_t(AnyView, bool)> hash) const {
    uint64_t h = type_key_hash;
    h = StableHashCombine(h, hash(params, true));   // def_region=true
    h = StableHashCombine(h, hash(body, false));     // def_region=false
    return h;
  }

  static void RegisterReflection() {
    refl::ObjectDef<TCustomFuncObj>()
        .def_ro("params", &TCustomFuncObj::params)
        .def_ro("body", &TCustomFuncObj::body)
        .def_ro("comment", &TCustomFuncObj::comment);
    refl::TypeAttrDef<TCustomFuncObj>()
        .def("__s_equal__", &TCustomFuncObj::SEqual)
        .def("__s_hash__", &TCustomFuncObj::SHash);
  }

  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind =
      kTVMFFISEqHashKindCustomTreeNode;
};
```
