# Enable custom structural equal/hash via TypeAttr dispatch
## TL;DR
- Adds `kTVMFFISEqHashKindCustomTreeNode` (value 6) to the `TVMFFISEqHashKind` C ABI enum, enabling types to provide custom `__s_equal__` and `__s_hash__` functions via `TypeAttrDef` instead of using the default field-walking dispatch.
- Refactors `StructEqualHandler` and `StructuralHashHandler` so that `FreeVar` post-processing (equality map recording, lexical counter hashing) runs *after* field/custom comparison, fixing a logic gap where FreeVar types could not also use custom comparisons.
- Introduces `TVM_FFI_USE_EXTRA_CXX_API` CMake option (default ON) to gate reflection source files (`access_path.cc`, `structural_equal.cc`, `structural_hash.cc`) into an optional compile group, and moves the structural equal/hash test into `tests/cpp/extra/`.
- Fixes a bug in `TypeTable` where registering a TypeAttr column that already existed silently created a duplicate instead of reusing the existing column index.

## Impact
- API: New enum value `kTVMFFISEqHashKindCustomTreeNode = 6` added to `TVMFFISEqHashKind` in `c_api.h`. Additive change; no existing values altered.
- Behavioral: FreeVar equality-map recording now runs after field/custom comparison succeeds (was interleaved before). FreeVar hash now computes content hash first, then applies free-var counter/pointer fallback. This is a semantic correction for types that are both FreeVar and have content fields.
- Flags/config: New CMake option `TVM_FFI_USE_EXTRA_CXX_API` (default ON) gates compilation of reflection source files.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TVMFFISEqHashKind enum** (0007-c-abi): extended with value 6
- **TypeAttrColumn / TypeAttrDef** (0008-reflection): used to register and look up `__s_equal__` and `__s_hash__` per-type custom functions
- **Object `_type_s_eq_hash_kind`** (0002-object-system): per-type static constexpr consulted by dispatch
- **ForEachFieldInfo / ForEachFieldInfoWithEarlyStop** (0008-reflection): existing field-walking mechanism, now skipped for CustomTreeNode types
- **ffi::Function::FromTyped** (0003-function-system): used to create the callback closures passed to custom equal/hash functions
- **AccessStep::ObjectField** (0008-reflection): used in mismatch path recording within the custom equal callback

Design elements this commit produces:
- **kTVMFFISEqHashKindCustomTreeNode** (value 6): new dispatch kind for types providing custom structural equal/hash
- **`__s_equal__` / `__s_hash__` TypeAttr protocol**: convention that custom equal/hash functions are registered as TypeAttr columns with these names, looked up via `TypeAttrColumn("__s_equal__")` / `TypeAttrColumn("__s_hash__")`
- **EnsureTypeAttrColumn**: called at static init to pre-create columns even when no types register custom functions (prevents null column lookup)
- **`TVM_FFI_USE_EXTRA_CXX_API` CMake option**: gates reflection sources into optional compile group

## Usage Examples
Defining a type with custom structural equal/hash (from `tests/cpp/testing_object.h`):
```cpp
class TCustomFuncObj : public Object {
 public:
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;
  // custom equal: compare params with def_region=true, body with def_region=false, ignore comment
  bool SEqual(const TCustomFuncObj* other,
              ffi::TypedFunction<bool(AnyView, AnyView, bool, AnyView)> cmp) const {
    return cmp(params, other->params, true, "params") &&
           cmp(body, other->body, false, "body");
  }
  // custom hash: hash params and body, skip comment
  uint64_t SHash(uint64_t type_key_hash, ffi::TypedFunction<uint64_t(AnyView, bool)> hash) const {
    uint64_t h = type_key_hash;
    h = details::StableHashCombine(h, hash(params, true));
    h = details::StableHashCombine(h, hash(body, false));
    return h;
  }
  static void RegisterReflection() {
    refl::ObjectDef<TCustomFuncObj>()
        .def_ro("params", &TCustomFuncObj::params)
        .def_ro("body", &TCustomFuncObj::body)
        .def_ro("comment", &TCustomFuncObj::comment);
    refl::TypeAttrDef<TCustomFuncObj>()
        .def("__s_equal__", &TCustomFuncObj::SEqual)
        .def("__s_hash__", &TCustomFuncObj::SHash);
  }
  static constexpr const char* _type_key = "test.CustomFunc";
  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode;
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TCustomFuncObj, Object);
};
```
