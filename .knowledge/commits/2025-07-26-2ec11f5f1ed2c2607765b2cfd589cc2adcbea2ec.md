# Enable custom structural equal/hash via TypeAttrColumn and kTVMFFISEqHashKindCustomTreeNode

## TL;DR
- Adds `kTVMFFISEqHashKindCustomTreeNode = 6` to the C ABI enum, allowing object types to provide custom `__s_equal__` and `__s_hash__` functions via `TypeAttrColumn` instead of relying on reflection-based field iteration.
- Refactors `StructEqualHandler` and `StructuralHashHandler` control flow to separate FreeVar/DAG-node post-processing from field comparison, enabling both reflection-based and custom dispatch paths.
- Fixes a bug in `TypeTable::RegisterTypeAttr` where re-registering an existing TypeAttr column silently used an uninitialized `column_index`, and makes reflection sources optional via `TVM_FFI_USE_EXTRA_CXX_API` CMake flag.

## Key Exports

```python
# --- C ABI enum extension (include/tvm/ffi/c_api.h) ---

class TVMFFISEqHashKind(IntEnum):
    # ... existing values 0-5 ...
    kTVMFFISEqHashKindCustomTreeNode = 6
    # Interacts with: StructEqualHandler.CompareObject, StructuralHashHandler.HashObject
    # Invariant: types using this kind MUST register __s_equal__ and __s_hash__ via TypeAttrDef
    # Extension: set _type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode on your Obj class

# --- Custom equal protocol (called via TypeAttrColumn["__s_equal__"]) ---

def __s_equal__(
    self: ObjectRef,
    other: ObjectRef,
    cmp: TypedFunction[[AnyView, AnyView, bool, AnyView], bool],  # (lhs, rhs, def_region, field_name) -> bool
) -> bool: ...
    # Interacts with: StructEqualHandler.CompareAny (via cmp callback)
    # Invariant: cmp must be called for every field that participates in equality
    # Invariant: set def_region=True for fields that define free variables (e.g., function params)
    # Invariant: field_name passed to cmp is used for mismatch path reporting

# --- Custom hash protocol (called via TypeAttrColumn["__s_hash__"]) ---

def __s_hash__(
    self: ObjectRef,
    type_key_hash: int,  # uint64_t seed from GetTypeKeyHash()
    hash: TypedFunction[[AnyView, bool], int],  # (value, def_region) -> uint64_t
) -> int: ...  # uint64_t
    # Interacts with: StructuralHashHandler.HashAny (via hash callback)
    # Invariant: must combine type_key_hash with field hashes using StableHashCombine
    # Invariant: set def_region=True for fields that define free variables

# --- Registration pattern (via TypeAttrDef) ---

# refl::TypeAttrDef<MyObj>()
#     .def("__s_equal__", &MyObj::SEqual)
#     .def("__s_hash__", &MyObj::SHash);
# Interacts with: TypeAttrColumn, TVMFFIRegisterTypeAttr, EnsureTypeAttrColumn

# --- Lazy callback initialization (internal, in StructEqualHandler / StructuralHashHandler) ---

class StructEqualHandler:
    s_equal_callback_: Function  # lazily initialized, wraps CompareAny with def_region support
    # Invariant: initialized on first use of kTVMFFISEqHashKindCustomTreeNode path
    # Interacts with: CompareAny, map_free_vars_, mismatch path recording

class StructuralHashHandler:
    s_hash_callback_: Function  # lazily initialized, wraps HashAny with def_region support
    # Invariant: initialized on first use of kTVMFFISEqHashKindCustomTreeNode path
    # Interacts with: HashAny, map_free_vars_
```

## Impact
- API: Adds `kTVMFFISEqHashKindCustomTreeNode = 6` to the public C ABI enum `TVMFFISEqHashKind`. Existing callers unaffected (additive).
- Behavioral: FreeVar comparison now runs custom content comparison first (if applicable), then checks identity/mapping. Previously, FreeVar short-circuited before any field comparison. TVar.name is now `SEqHashIgnore`, so variables compare by identity/mapping rather than name content.
- Flags/config: New CMake option `TVM_FFI_USE_EXTRA_CXX_API` (default ON) controls whether reflection sources are compiled into the shared library.
- Data formats/schemas: none

## Usage Examples

Defining a custom structural equal/hash type (from `tests/cpp/testing_object.h`):

```cpp
class TCustomFuncObj : public Object {
 public:
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;  // intentionally excluded from equal/hash

  bool SEqual(const TCustomFuncObj* other,
              ffi::TypedFunction<bool(AnyView, AnyView, bool, AnyView)> cmp) const {
    // def_region=true for params (binds free vars), false for body
    if (!cmp(params, other->params, true, "params")) return false;
    if (!cmp(body, other->body, false, "body")) return false;
    return true;  // comment field intentionally omitted
  }

  uint64_t SHash(uint64_t type_key_hash,
                 ffi::TypedFunction<uint64_t(AnyView, bool)> hash) const {
    uint64_t h = type_key_hash;
    h = details::StableHashCombine(h, hash(params, true));
    h = details::StableHashCombine(h, hash(body, false));
    return h;
  }

  static void RegisterReflection() {
    namespace refl = tvm::ffi::reflection;
    refl::ObjectDef<TCustomFuncObj>()
        .def_ro("params", &TCustomFuncObj::params)
        .def_ro("body", &TCustomFuncObj::body)
        .def_ro("comment", &TCustomFuncObj::comment);
    // Register custom s_equal/s_hash via TypeAttrDef
    refl::TypeAttrDef<TCustomFuncObj>()
        .def("__s_equal__", &TCustomFuncObj::SEqual)
        .def("__s_hash__", &TCustomFuncObj::SHash);
  }

  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindCustomTreeNode;
  // ...
};
```
