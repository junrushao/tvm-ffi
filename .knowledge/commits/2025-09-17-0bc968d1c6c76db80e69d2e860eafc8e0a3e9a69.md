# Enable comprehensive Ruff linting and migrate Python code to modern idioms
## TL;DR
- Configures a broad set of Ruff lint rules (`UP`, `PL`, `I`, `RUF`, `NPY`, `F`, `PTH`, `D`) in `pyproject.toml`, replacing the previous separate `black` and `isort` tool configs.
- Applies the resulting lint fixes across all Python sources: `os.path` to `pathlib.Path`, `typing.List`/`Sequence`/`Mapping` to `collections.abc` equivalents, docstring style normalization (trailing periods, blank lines before closing `"""`), sorted `__all__` lists, and `from __future__ import annotations`-style type hints.
- Deletes two legacy lint scripts (`tests/scripts/task_lint.sh`, `tests/lint/git-clang-format.sh`) that are superseded by the pre-commit/Ruff workflow.

## Key Exports
None -- this commit changes only tooling configuration and applies mechanical code style fixes. No new public API surfaces are introduced.

## Impact
- API: None
- ABI: None
- Behavioral: Negligible -- `np.float_` usage replaced with `np.float64` (functionally identical alias); a warning message string in `_optional_torch_c_dlpack.py` lost a whitespace before "EnvTensorAllocator" (cosmetic).
- Flags/config: `[tool.black]` and `[tool.isort]` sections removed from `pyproject.toml`; `[tool.ruff]` expanded with `select`, `ignore`, `fixable`, `per-file-ignores`, and `[tool.ruff.format]` sections.
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Python bindings layer** (`python/tvm_ffi/`): All Python modules receive style fixes but no behavioral changes. See `.knowledge/designs/0014-python-bindings.md`.
- **Module system** (`python/tvm_ffi/module.py`, `python/tvm_ffi/cpp/load_inline.py`): `os.path` calls migrated to `pathlib.Path` throughout the module-loading and inline-compilation code. See `.knowledge/designs/0013-module-system.md`.
- **Python packaging** (`pyproject.toml`): Lint tool configuration consolidated from black+isort+ruff to ruff-only. See `.knowledge/designs/0015-python-packaging.md`.

Design elements this commit produces:
- **Ruff rule set convention**: Establishes the canonical set of enabled Ruff rules (`UP`, `PL`, `I`, `RUF`, `NPY`, `F`, `PTH`, `D`) and per-file ignores (tests exempt from `D100`, `D101`, `D103`, `D107`, `D205`; `__init__.py` exempt from `F401`). This is a new tooling convention for the project.
- **pathlib-first convention**: All Python source now uses `pathlib.Path` instead of `os.path` for filesystem operations (enforced by `PTH` rule). This is a new structural convention.
