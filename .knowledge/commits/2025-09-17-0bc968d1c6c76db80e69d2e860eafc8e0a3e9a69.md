# Enable baseline Ruff rule coverage and apply mechanical lint fixes

## TL;DR
- Configures `pyproject.toml` with a comprehensive ruff rule set (UP, PL, I, RUF, NPY, F, PTH, D) replacing the previous black+isort toolchain.
- Applies mechanical fixes across all Python sources: Google-style docstrings (trailing periods, blank lines), `os.path` to `pathlib.Path` migration (PTH rules), sorted `__all__` lists, `typing.Sequence`/`Mapping` to `collections.abc` equivalents (UP rules), f-string upgrades, and `# noqa` annotations for intentional suppressions.
- Deletes two obsolete lint scripts (`tests/lint/git-clang-format.sh`, `tests/scripts/task_lint.sh`) whose responsibilities are now covered by pre-commit hooks.

- Behavioral: One minor change in `_dtype.py`: `np.float_` (deprecated alias) replaced with `np.float64` for the numpy dtype-to-string mapping. This is a forward-compatibility fix, not a behavioral change for any currently-supported numpy version.
- Flags/config: `pyproject.toml` now configures `ruff.lint.select`, `ruff.lint.ignore`, `ruff.format`, and `ruff.lint.per-file-ignores`. The `[tool.black]` and `[tool.isort]` sections are removed.
