# Enable Ruff rule coverage and apply auto-fixes across Python codebase
## TL;DR
- Enables Ruff rule sets UP (pyupgrade), PL (pylint), I (isort), RUF, NPY, F (pyflakes), PTH (pathlib), D (pydocstyle) in `pyproject.toml` and applies their auto-fixes across all Python source and test files.
- Removes deprecated `[tool.black]` and `[tool.isort]` config sections, consolidating formatting under `[tool.ruff.format]`.
- Deletes two obsolete shell scripts (`tests/lint/git-clang-format.sh`, `tests/scripts/task_lint.sh`) superseded by pre-commit hooks.

## Key Exports
None

## Impact
- API: none (all changes are style/lint; no public signatures altered)
- Behavioral: `IOError` catch replaced with `OSError` in `FileLock.acquire()` (aliases in Python 3, no behavioral difference); `np.float_` replaced with `np.float64` in dtype mapping (equivalent)
- Flags/config: `pyproject.toml` gains explicit `[tool.ruff.lint] select`, `[tool.ruff.format]`, per-file ignore rules for tests; loses `[tool.black]` and `[tool.isort]` sections
- Data formats/schemas: none
