# Enable comprehensive Ruff rule coverage and apply auto-fixes across Python codebase
## TL;DR
- Replaces `black` + `isort` configuration with a comprehensive `ruff` rule set (`UP`, `PL`, `I`, `RUF`, `NPY`, `F`, `PTH`, `D`) in `pyproject.toml`, establishing ruff as the single Python linter/formatter.
- Applies mechanical ruff auto-fixes across 41 files: docstring formatting (D rules), `os.path` to `pathlib.Path` migration (PTH rules), import sorting (I rules), `noqa` suppression annotations, and alphabetically sorted `__all__` exports.
- Deletes obsolete lint scripts (`tests/lint/git-clang-format.sh`, `tests/scripts/task_lint.sh`) that are superseded by the `pre-commit` framework.

## Impact
- API: none -- all changes are style/lint mechanical transformations with no public API alterations.
- Behavioral: none -- the `np.float_` alias was already mapped to `float64`; the change from `np.float_` to `np.float64` in `_dtype.py` is a no-op since both resolve to the same numpy dtype.
- Flags/config: Ruff configuration in `pyproject.toml` is expanded with `select`, `ignore`, `fixable`, `per-file-ignores`, and `format` sections. `[tool.black]` and `[tool.isort]` sections are removed.
- Data formats/schemas: none.
