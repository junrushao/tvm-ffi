# Fix lint errors and improve docs (cross-references, license header, CI config)

## TL;DR
- Converts plain-text references in `docs/guides/compiler_integration.md` to Sphinx cross-reference roles (`{c:macro}`, `{cpp:func}`, `{cpp:class}`), improving rendered documentation with hyperlinks to API definitions.
- Adds missing Apache 2.0 license header to `docs/reference/python/cpp/index.rst`.
- Updates `.asf.yaml`: changes branch protection from `dev` to commenting style and adjusts the comment about status checks.
- Adds `TEST_DISCOVERY_TIMEOUT 300` to `gtest_discover_tests` in `cmake/Utils/AddGoogleTest.cmake` to prevent test discovery timeouts in CI.
