# Refactor Cython byte-array-to-Python conversions to use dedicated helper functions
## TL;DR
- Replaces all inline `py_str(PyBytes_FromStringAndSize(x.data, x.size))` and bare `PyBytes_FromStringAndSize(x.data, x.size)` patterns across 5 Cython `.pxi` files with calls to `bytearray_to_str(&x)` and `bytearray_to_bytes(&x)`.
- Adds a new `bytearray_to_bytes` helper in `base.pxi` (the `bytearray_to_str` helper already existed).
- Pure code cleanup; no behavioral or API change.

## Key Exports
**Functions** (Cython `cdef inline`, not public API but shared across `.pxi` files):

| Symbol | Signature | Notes |
|--------|-----------|-------|
| `bytearray_to_str` | `(const TVMFFIByteArray* x) -> str` | Already existed before this commit |
| `bytearray_to_bytes` | `(const TVMFFIByteArray* x) -> bytes` | **New** -- wraps `PyBytes_FromStringAndSize(x.data, x.size)` |

## Design Elements
Design elements this commit consumes:
- **`TVMFFIByteArray` C struct** (`.knowledge/designs/c-abi.md`) -- the `{data, size}` pair that the Cython layer receives from C API functions like `TVMFFISmallBytesGetContentByteArray`, `TVMFFIBytesGetByteArrayPtr`, and `TVMFFIFieldInfo.name`/`.doc`.
- **`bytearray_to_str` helper** (`base.pxi`) -- the pre-existing single-call wrapper for `TVMFFIByteArray* -> str`. This commit extends the pattern to cover the `bytes` case and replaces all remaining raw call sites.
- **`py_str` helper** (`base.pxi`) -- accepts `const char*`, decodes UTF-8. After this commit, `py_str` is no longer used for `TVMFFIByteArray` conversions (it was being wrapped around `PyBytes_FromStringAndSize` output, an unnecessary double-hop).

Design elements this commit produces:
- **`bytearray_to_bytes` helper** (`base.pxi`) -- new `cdef inline` that consolidates the `TVMFFIByteArray* -> bytes` conversion in one place.

## Usage Examples
None -- this is a pure refactoring commit. The before/after is straightforward:

```cython
# Before (scattered across .pxi files):
py_str(PyBytes_FromStringAndSize(field.name.data, field.name.size))
PyBytes_FromStringAndSize(bytes.data, bytes.size)

# After:
bytearray_to_str(&field.name)
bytearray_to_bytes(&bytes)
```
