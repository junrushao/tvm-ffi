# Replace raw CPython byte-conversion calls with `bytearray_to_str`/`bytearray_to_bytes` helpers in Cython bindings
## TL;DR
- Adds a new `bytearray_to_bytes` Cython inline helper in `base.pxi`, the bytes-returning counterpart of the existing `bytearray_to_str`.
- Replaces all scattered `PyBytes_FromStringAndSize(x.data, x.size).decode("utf-8")` and `PyBytes_FromStringAndSize(x.data, x.size)` patterns across five `.pxi` files with calls to `bytearray_to_str`/`bytearray_to_bytes`.
- No behavioral change; pure code-quality refactor reducing duplication and improving readability.

## Key Exports

```python
# Internal Cython helpers (not public API), defined in base.pxi

def bytearray_to_str(x: "const TVMFFIByteArray*") -> str:
    """Convert a C TVMFFIByteArray to a Python str (UTF-8 decode)."""
    # Pre-existing, now promoted as canonical pattern
    # Interacts with: TVMFFIByteArray (C ABI), all Cython .pxi files that decode byte arrays
    # Invariant: x.data must contain valid UTF-8
    ...

def bytearray_to_bytes(x: "const TVMFFIByteArray*") -> bytes:
    """Convert a C TVMFFIByteArray to Python bytes (no decode)."""
    # NEW in this commit
    # Interacts with: TVMFFIByteArray (C ABI), make_ret_small_bytes(), _bytes_obj_get_py_bytes()
    ...
```

## Design Elements
Design elements this commit consumes:
- `TVMFFIByteArray` struct from C ABI ([0007-c-abi](../design-records/0007-c-abi.md)) — the source data structure for all conversions.
- `TVMFFISmallBytesGetContentByteArray` / `TVMFFIBytesGetByteArrayPtr` from C ABI ([0007-c-abi](../design-records/0007-c-abi.md)) — accessors used upstream of the helpers.
- `bytearray_to_str` from `base.pxi` ([0012-python-bindings](../design-records/0012-python-bindings.md)) — pre-existing helper now used consistently.

Design elements this commit produces:
- `bytearray_to_bytes` in `base.pxi` — new internal Cython helper for raw bytes conversion, completing the `bytearray_to_str`/`bytearray_to_bytes` pair.

## Usage Examples
Before/after pattern showing the refactored calling convention:

```python
# BEFORE (scattered raw CPython API calls):
name = py_str(PyBytes_FromStringAndSize(field.name.data, field.name.size))
doc = py_str(PyBytes_FromStringAndSize(field.doc.data, field.doc.size)) if field.doc.size != 0 else None
raw = PyBytes_FromStringAndSize(bytes.data, bytes.size)

# AFTER (unified helpers):
name = bytearray_to_str(&field.name)
doc = bytearray_to_str(&field.doc) if field.doc.size != 0 else None
raw = bytearray_to_bytes(&bytes)
```
