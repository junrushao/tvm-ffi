# Introduce bytearray_to_bytes helper and use bytearray_to_str/bytes consistently across all Cython .pxi files

## TL;DR
- Adds `bytearray_to_bytes(const TVMFFIByteArray* x) -> bytes` as a new Cython `cdef inline` helper in `base.pxi`, mirroring the existing `bytearray_to_str`.
- Replaces all occurrences of the raw pattern `py_str(PyBytes_FromStringAndSize(x.data, x.size))` with `bytearray_to_str(&x)` and `PyBytes_FromStringAndSize(x.data, x.size)` with `bytearray_to_bytes(&x)` across `dtype.pxi`, `function.pxi`, `object.pxi`, and `string.pxi`.
- No behavioral change; purely a readability and DRY refactor.

## Key Exports

```python
# cdef inline — Cython-only, not visible from Python

cdef inline bytes bytearray_to_bytes(const TVMFFIByteArray* x):
    """Convert a TVMFFIByteArray to a Python bytes object."""
    # Interacts with: PyBytes_FromStringAndSize (CPython C API)
    # Interacts with: bytearray_to_str — sibling helper that decodes to str
    # Invariant: x must be a valid, non-NULL pointer; caller manages lifetime
    ...
```

## Impact
- API: None — `bytearray_to_bytes` is a `cdef inline` Cython helper; it is not part of any public Python API.
- Behavioral: None — all call sites produce identical runtime results.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- `TVMFFIByteArray` C ABI struct (design record `0001-c-abi`) — the struct being wrapped in both helpers.
- `bytearray_to_str` Cython helper (design record `0013-python-package`) — existing helper this commit extends and standardizes.
- Cython fragment architecture in `python/tvm_ffi/cython/` (design record `0013-python-package`) — the `.pxi` include pattern.

Design elements this commit produces:
- `bytearray_to_bytes` Cython helper (internal) — new symmetric companion to `bytearray_to_str` for producing `bytes` (not `str`) from `TVMFFIByteArray*`.

## Usage Examples

Before (in `string.pxi`):
```cython
cdef inline bytes _bytes_obj_get_py_bytes(obj):
    cdef TVMFFIByteArray* bytes = TVMFFIBytesGetByteArrayPtr((<Object>obj).chandle)
    return PyBytes_FromStringAndSize(bytes.data, bytes.size)
```

After:
```cython
cdef inline bytes _bytes_obj_get_py_bytes(obj):
    cdef TVMFFIByteArray* bytes = TVMFFIBytesGetByteArrayPtr((<Object>obj).chandle)
    return bytearray_to_bytes(bytes)
```
