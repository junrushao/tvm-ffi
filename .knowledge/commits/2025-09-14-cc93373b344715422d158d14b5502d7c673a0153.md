# Prefer `bytearray_to_str|bytes` to raw Python API in Cython bindings

## TL;DR
- Introduces `bytearray_to_bytes(const TVMFFIByteArray* x)` in `base.pxi` as a companion to the existing `bytearray_to_str`. The new helper wraps `PyBytes_FromStringAndSize(x.data, x.size)` into a single call.
- Replaces all 9 inline `py_str(PyBytes_FromStringAndSize(bytes.data, bytes.size))` and `PyBytes_FromStringAndSize(bytes.data, bytes.size)` call sites across 4 Cython `.pxi` files with calls to `bytearray_to_str(&bytes)` or `bytearray_to_bytes(&bytes)`.
- No behavioral change. Pure mechanical refactor for consistency and readability.

## Key Exports

New Cython-internal helper (not part of public API):
```python
# base.pxi
cdef inline bytes bytearray_to_bytes(const TVMFFIByteArray* x):
    return PyBytes_FromStringAndSize(x.data, x.size)
```

The existing `bytearray_to_str` (also in `base.pxi`) was already present before this commit. This commit extends its usage to all remaining call sites.

## Impact
- API: none -- internal Cython helpers only.
- Behavioral: none -- identical runtime behavior, same CPython C API calls.
- Flags/config: none.
- Data formats/schemas: none.

## Design Elements

Design elements this commit consumes:
- **TVMFFIByteArray**: The C ABI struct (`{const char* data; int64_t size}`) used to pass byte buffers across the FFI boundary. All Cython code that reads string/bytes data from C objects receives it via this struct.
- **`bytearray_to_str`** (`base.pxi`): Pre-existing helper that converts `TVMFFIByteArray*` to Python `str` via `PyBytes_FromStringAndSize` + `.decode("utf-8")`.

Design elements this commit produces:
- **`bytearray_to_bytes`** (`base.pxi`): New companion helper that converts `TVMFFIByteArray*` to Python `bytes` without UTF-8 decoding. Completes the pair of byte-array conversion helpers.
- **Convention**: All Cython code that converts `TVMFFIByteArray` to Python `str` or `bytes` should use `bytearray_to_str` / `bytearray_to_bytes` instead of inline `PyBytes_FromStringAndSize` calls. This makes the conversion points easier to find and modify (e.g., if the encoding or buffer strategy changes).

## Usage Examples

**Before** (scattered inline calls):
```cython
# dtype.pxi
res = py_str(PyBytes_FromStringAndSize(bytes.data, bytes.size))

# function.pxi
name = py_str(PyBytes_FromStringAndSize(field.name.data, field.name.size))
doc = py_str(PyBytes_FromStringAndSize(field.doc.data, field.doc.size)) if field.doc.size != 0 else None

# string.pxi
return PyBytes_FromStringAndSize(bytes.data, bytes.size)
```

**After** (uniform helper calls):
```cython
# dtype.pxi
res = bytearray_to_str(&bytes)

# function.pxi
name = bytearray_to_str(&field.name)
doc = bytearray_to_str(&field.doc) if field.doc.size != 0 else None

# string.pxi
return bytearray_to_bytes(bytes)
```
