# Refactor Cython byte array conversions to use bytearray_to_str/bytes helpers
## TL;DR
- Introduces `bytearray_to_bytes()` helper in `base.pxi` alongside existing `bytearray_to_str()`, then replaces all raw `PyBytes_FromStringAndSize(x.data, x.size)` + `py_str()` call patterns across Cython files with the centralized helpers.
- Affected files: `dtype.pxi`, `function.pxi`, `object.pxi`, `string.pxi` -- all converge on the same two helpers for `TVMFFIByteArray*` to Python string/bytes conversion.

## Impact
- API: none (purely internal refactor, no behavioral change)
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit **consumes**:
- **Python bindings** (`.knowledge/designs/0014-python-bindings.md`): The Cython `.pxi` files form the core Python FFI dispatch layer; this refactor centralizes a common conversion pattern within that layer.
- **C ABI** (`.knowledge/designs/0001-c-abi.md`): `TVMFFIByteArray`, `TVMFFISmallBytesGetContentByteArray`, `TVMFFIBytesGetByteArrayPtr` are C ABI symbols consumed by these helpers.

Design elements this commit **produces**: none (internal code quality improvement)
