# Prefer bytearray_to_str|bytes helpers over raw PyBytes_FromStringAndSize in Cython
## TL;DR
- Introduces `bytearray_to_bytes()` Cython helper in `base.pxi` to complement the existing `bytearray_to_str()`.
- Replaces all 8 call sites of raw `PyBytes_FromStringAndSize(...).decode("utf-8")` and `py_str(PyBytes_FromStringAndSize(...))` with `bytearray_to_str()` across `dtype.pxi`, `function.pxi`, `object.pxi`, and `string.pxi`.
- Replaces 2 call sites of raw `PyBytes_FromStringAndSize(...)` (bytes, not str) with `bytearray_to_bytes()`.

## Key Exports

```python
# base.pxi -- internal Cython helpers (cdef inline, not public API)

def bytearray_to_str(x: TVMFFIByteArray_ptr) -> str:
    """Convert C byte array to Python str via UTF-8 decode."""
    # Interacts with: PyBytes_FromStringAndSize (CPython C API)
    # Invariant: x.data must be valid UTF-8
    ...

def bytearray_to_bytes(x: TVMFFIByteArray_ptr) -> bytes:  # NEW in this commit
    """Convert C byte array to Python bytes (no decode)."""
    # Interacts with: PyBytes_FromStringAndSize (CPython C API)
    ...
```

## Impact
- API: none -- internal Cython helpers only, no public Python API change
- Behavioral: none -- semantically identical to the inlined expressions they replace
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVMFFIByteArray` C struct (from [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md)) -- the `data`/`size` pair wrapped by both helpers
- `TVMFFISmallBytesGetContentByteArray` / `TVMFFIBytesGetByteArrayPtr` C ABI functions -- callers in `function.pxi`, `dtype.pxi`, `string.pxi`, `object.pxi` that produce `TVMFFIByteArray` values passed to the new helpers
- Cython `.pxi` include pattern (from [0012-ffi-python-package](../design-records/0012-ffi-python-package.md)) -- `base.pxi` defines helpers consumed by other `.pxi` files in the same compilation unit

Design elements this commit produces:
- None at the design level. `bytearray_to_bytes` is an internal Cython `cdef inline` function, not a cross-language interface.

## Usage Examples
Before (raw CPython API, repeated at each call site):
```python
# str conversion -- two equivalent patterns both appeared in the codebase
res = py_str(PyBytes_FromStringAndSize(bytes.data, bytes.size))
# or
name = py_str(PyBytes_FromStringAndSize(field.name.data, field.name.size))
```

After (centralized helpers):
```python
res = bytearray_to_str(&bytes)
name = bytearray_to_str(&field.name)
raw = bytearray_to_bytes(&bytes)  # for bytes (no UTF-8 decode)
```
