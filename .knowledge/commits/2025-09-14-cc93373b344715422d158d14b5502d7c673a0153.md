# Standardize Cython byte-array-to-Python conversions via named helpers
## TL;DR
- Introduces `bytearray_to_bytes()` Cython helper in `base.pxi`, parallel to the existing `bytearray_to_str()`, for converting `TVMFFIByteArray*` to Python `bytes`.
- Replaces all 9 occurrences of raw `py_str(PyBytes_FromStringAndSize(...))` and `PyBytes_FromStringAndSize(...)` patterns across `dtype.pxi`, `function.pxi`, `object.pxi`, and `string.pxi` with calls to `bytearray_to_str()` or `bytearray_to_bytes()`.
- No behavioral change; purely a readability and maintainability refactoring.

## Key Exports
**Functions** (Cython `cdef inline`, internal to the Cython extension):

| Function | Signature | Status |
|----------|-----------|--------|
| `bytearray_to_str` | `(const TVMFFIByteArray* x) -> str` | Existing, now used consistently |
| `bytearray_to_bytes` | `(const TVMFFIByteArray* x) -> bytes` | **New** |

Both are thin wrappers around `PyBytes_FromStringAndSize(x.data, x.size)`, with `bytearray_to_str` adding `.decode("utf-8")`.

## Impact
- API: none -- these are internal Cython helpers, not exposed to Python callers.
- Behavioral: none -- identical semantics to the replaced inline code.
- Flags/config: none.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- **`TVMFFIByteArray` struct** ([0001-c-abi-layer.md](../designs/0001-c-abi-layer.md)): The C ABI byte array representation used by `TVMFFISmallBytesGetContentByteArray`, `TVMFFIBytesGetByteArrayPtr`, and reflection field info (`field.name`, `field.doc`).
- **`bytearray_to_str` helper** ([0014-python-package.md](../designs/0014-python-package.md)): Existing Cython helper that was already defined but not used in all conversion sites.
- **Small string optimization** ([0011-small-string-optimization.md](../designs/0011-small-string-optimization.md)): `TVMFFISmallBytesGetContentByteArray` returns a `TVMFFIByteArray` from inline small strings; this commit ensures those are converted through the same helper as heap-allocated strings.
- **Reflection system** ([0009-reflection.md](../designs/0009-reflection.md)): Field and method info structs (`TVMFFIFieldInfo`, `TVMFFIMethodInfo`) have `name` and `doc` fields of type `TVMFFIByteArray` that are converted to Python strings in `_add_class_attrs_by_reflection`.

Design elements this commit produces:
- **`bytearray_to_bytes` Cython helper** (new, in `base.pxi`): Establishes the convention that all `TVMFFIByteArray*` -> Python conversions go through named helpers (`bytearray_to_str` for `str`, `bytearray_to_bytes` for `bytes`), rather than calling `PyBytes_FromStringAndSize` directly.

## Usage Examples
None -- this is a refactoring commit. The new `bytearray_to_bytes` helper is used identically to the code it replaced:

```cython
# Before (raw Python C API):
return PyBytes_FromStringAndSize(bytes.data, bytes.size)

# After (named helper):
return bytearray_to_bytes(&bytes)
```
