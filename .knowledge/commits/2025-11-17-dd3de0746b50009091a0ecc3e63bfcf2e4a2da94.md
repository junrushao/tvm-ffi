# Add test exercising Optional<TensorView> nullability through FFI
## TL;DR
- Registers a new test helper `testing.optional_tensor_view_has_value` in C++ that accepts `Optional<TensorView>` and returns whether it has a value.
- Adds a Python test `test_optional_tensor_view` that verifies `None` maps to empty optional and a numpy array maps to a present `TensorView`.

## Key Exports
None -- test-only commit. The registered function is a testing helper, not a production API.

## Design Elements
Design elements this commit consumes:
- **Optional\<T\> TypeTraits** ([0006-type-traits.md](../designs/0006-type-traits.md)): The `Optional<TensorView>` parameter exercises the `Optional` conversion path -- `kTVMFFINone` maps to empty optional, otherwise delegates to `TypeTraits<TensorView>::TryCastFromAnyView`.
- **TensorView TypeTraits** ([0006-type-traits.md](../designs/0006-type-traits.md)): Non-owning tensor view that accepts `kTVMFFIDLTensorPtr` or `kTVMFFITensor` via `TryCastFromAnyView`. The numpy array with `__dlpack__` is converted to a DLTensor on the Python side before reaching C++.
- **Global function registration** ([0004-function-system.md](../designs/0004-function-system.md)): `RegistryHelper::def("testing.optional_tensor_view_has_value", ...)` registers the lambda as a packed function.
- **Python FFI bridge** ([0012-python-bindings.md](../designs/0012-python-bindings.md)): `tvm_ffi.get_global_func()` retrieves the C++ function for Python-side invocation.

## Usage Examples
The test itself serves as a usage example for `Optional<TensorView>` cross-layer interaction:

```cpp
// C++ side: register a function accepting Optional<TensorView>
.def("testing.optional_tensor_view_has_value",
     [](Optional<TensorView> t) { return t.has_value(); })
```

```python
# Python side: None -> empty optional, numpy array -> present TensorView
f = tvm_ffi.get_global_func("testing.optional_tensor_view_has_value")
assert not f(None)              # kTVMFFINone -> Optional(nullopt)
assert f(np.zeros((128,)))      # dlpack -> TensorView -> Optional(TensorView)
```
