# Add test for Optional<TensorView> FFI argument passing
## TL;DR
- Registers a new testing helper `testing.optional_tensor_view_has_value` that accepts `Optional<TensorView>` and returns whether it holds a value.
- Adds a Python test `test_optional_tensor_view` verifying that `None` maps to an empty optional and a numpy array maps to a present `TensorView`.

None — test-only addition.

- Behavioral: none

## Design Elements
Design elements this commit consumes:
- `Optional<T>` container (`0006-ffi-containers`) — used as the parameter type for the test helper, verifying that `None` round-trips to an empty optional.
- `TensorView` non-owning tensor view (`0006-ffi-containers`) — used as the inner type of `Optional<TensorView>`, verifying that a numpy array with `__dlpack__` converts to a present `TensorView`.
- `refl::GlobalDef` + `TVM_FFI_STATIC_INIT_BLOCK` (`0004-ffi-function-system`) — used to register the test helper function `testing.optional_tensor_view_has_value`.
- Python `get_global_func` (`0012-ffi-python-package`) — used in the test to retrieve the registered C++ helper from the global function registry.

Design elements this commit produces: none.

## Usage Examples
Cross-layer test pattern: register a C++ function accepting `Optional<TensorView>`, then call from Python with `None` and a DLPack-capable array.

```python
# Python side (test)
optional_tensor_view_has_value = tvm_ffi.get_global_func(
    "testing.optional_tensor_view_has_value"
)
assert not optional_tensor_view_has_value(None)        # None -> empty Optional
x = np.zeros((128,), dtype="float32")
assert optional_tensor_view_has_value(x)               # ndarray -> TensorView
```

```cpp
// C++ side (registration in testing.cc)
.def("testing.optional_tensor_view_has_value",
     [](Optional<TensorView> t) { return t.has_value(); })
```
