# Split reflection.h into registry.h (metadata registration) and accessor.h (runtime access helpers)
## TL;DR
- Renames `tvm/ffi/reflection/reflection.h` to `tvm/ffi/reflection/registry.h`, retaining only the registration machinery (`ObjectDef`, `ReflectionDefBase`, field/method registration templates).
- Extracts all runtime accessor helpers (`FieldGetter`, `FieldSetter`, `GetFieldInfo`, `GetMethodInfo`, `GetMethod`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`) into a new `tvm/ffi/reflection/accessor.h`.
- Updates all seven internal `#include` sites to use the new paths; no behavioral changes.

### Rename Mapping

| Before | After | Contents |
|--------|-------|----------|
| `tvm/ffi/reflection/reflection.h` | `tvm/ffi/reflection/registry.h` | `ReflectionDefBase`, `ObjectDef`, field/method registration templates, `TVM_FFI_REFLECTION_DEF` macro |
| *(embedded in reflection.h)* | `tvm/ffi/reflection/accessor.h` | `GetFieldInfo`, `FieldGetter`, `FieldSetter`, `GetMethodInfo`, `GetMethod`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop` |

### Include Migration

|------|-------------|-------------|
| `src/ffi/container.cc` | `reflection/reflection.h` | `reflection/registry.h` |

| `src/ffi/ndarray.cc` | `reflection/reflection.h` | `reflection/registry.h` |

| `tests/cpp/test_reflection.cc` | `reflection/reflection.h` | `reflection/accessor.h` + `reflection/registry.h` |

## Impact
- API: Header path change from `tvm/ffi/reflection/reflection.h` to `tvm/ffi/reflection/registry.h` and `tvm/ffi/reflection/accessor.h`. Downstream code including the old path will fail to compile.
- Behavioral: None -- pure code movement.
- Flags/config: None.
- Data formats/schemas: None.
