# [FFI][REFACTOR] Modularize reflection (#18147)

## TL;DR
- Splits the monolithic `include/tvm/ffi/reflection/reflection.h` (571 lines) into two focused headers: `registry.h` (type/field/method registration builders) and `accessor.h` (runtime field/method lookup and access utilities).
- `reflection.h` is removed. All `#include` sites in `src/ffi/*.cc` and `tests/cpp/` are updated to include `registry.h` (for registration) or both `registry.h` and `accessor.h` (for tests that also perform runtime access).
- No API or ABI changes; all classes and functions retain their original names and signatures within `tvm::ffi::reflection`.

## Key Exports

No new public symbols. The existing API is redistributed across two headers:

### `include/tvm/ffi/reflection/registry.h` (renamed from `reflection.h`, trimmed)
Retains all **registration-time** constructs:
- `FieldInfoTrait`, `DefaultValue` -- traits for field metadata.
- `GetFieldByteOffsetToObject<Class, T>()` -- byte-offset computation.
- `ReflectionDefBase` -- CRTP base with `FieldGetter<T>`, `FieldSetter<T>`, `ObjectCreatorDefault<T>`, `ApplyFieldInfoTrait`, `ApplyMethodInfoTrait`, `ApplyExtraInfoTrait`, `GetMethod` overloads.
- `GlobalDef` -- builder for registering global functions (`def`, `def_packed`, `def_method`).
- `ObjectDef<Class>` -- builder for registering object type metadata (`def_ro`, `def_rw`, `def`, `def_static`).

### `include/tvm/ffi/reflection/accessor.h` (new file)
Contains all **runtime access** utilities that were previously at the bottom of `reflection.h`:
- `GetFieldInfo(type_key, field_name) -> const TVMFFIFieldInfo*` -- looks up a field descriptor by type key and name.
- `FieldGetter` -- callable wrapper that reads a field from an `Object*`/`ObjectPtr`/`ObjectRef` using a `TVMFFIFieldInfo*`.
- `FieldSetter` -- callable wrapper that writes a field on an `Object*`/`ObjectPtr`/`ObjectRef`.
- `GetMethodInfo(type_key, method_name) -> const TVMFFIMethodInfo*` -- looks up a method descriptor.
- `GetMethod(type_key, method_name) -> Function` -- retrieves a method as a `Function` object.
- `ForEachFieldInfo(type_info, callback)` -- iterates all fields (parent-to-child order, skipping root Object), invokes a `void` callback per field.
- `ForEachFieldInfoWithEarlyStop(type_info, callback) -> bool` -- same iteration but the callback returns `bool` for early termination.

## Impact
- API: None. All symbols remain in `tvm::ffi::reflection` with identical signatures.
- ABI: None. These are header-only inline functions and classes; no compiled symbols change.
- Behavioral: None. Pure code reorganization.
- Include graph: Code that only registers types (all `src/ffi/*.cc` files, `tests/cpp/testing_object.h`) now includes only `registry.h`, reducing transitive include weight. Code that also performs runtime field/method access (`tests/cpp/test_reflection.cc`) includes both `registry.h` and `accessor.h`.

## Design Elements
Design elements this commit consumes:
- `TVMFFIFieldInfo`, `TVMFFIMethodInfo`, `TVMFFITypeInfo` C ABI structs (`c_api.h`) -- used by both registry and accessor code.
- `TVMFFITypeKeyToIndex`, `TVMFFIGetTypeInfo` C API functions -- used by accessor lookups.
- `TVMFFITypeRegisterField`, `TVMFFITypeRegisterMethod`, `TVMFFITypeRegisterExtraInfo` C API functions -- used by registry builders.

Design elements this commit produces:
- **Registry/accessor separation pattern** -- Registration-time code (builders that run at static init) is decoupled from runtime-access code (field/method lookup at query time). This reduces compilation dependencies: `.cc` files that only define types no longer pull in the accessor utilities.
