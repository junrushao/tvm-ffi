# Split reflection.h into registry.h (registration) and accessor.h (runtime access)
## TL;DR
- Splits the monolithic `include/tvm/ffi/reflection/reflection.h` (571 lines) into two focused headers: `registry.h` (414 lines, registration builders) and `accessor.h` (198 lines, runtime field/method accessors).
- All 7 consumer `.cc`/`.h` files updated their `#include` from `reflection/reflection.h` to `reflection/registry.h`. Only the test file additionally includes `accessor.h`.
- No behavioral or API changes -- purely a file-level reorganization.

### Rename mapping

| Before | After | Content |
|--------|-------|---------|
| `reflection/reflection.h` (registration part) | `reflection/registry.h` | `ReflectionDefBase`, `ObjectDef<T>`, `GlobalDef`, `DefaultValue`, `FieldInfoTrait`, `GetFieldByteOffsetToObject` |
| `reflection/reflection.h` (accessor part) | `reflection/accessor.h` | `GetFieldInfo`, `FieldGetter`, `FieldSetter`, `GetMethodInfo`, `GetMethod`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop` |

### Include path updates

| File | Old include | New include(s) |
|------|-------------|-----------------|
| `src/ffi/container.cc` | `reflection/reflection.h` | `reflection/registry.h` |
| `src/ffi/function.cc` | `reflection/reflection.h` | `reflection/registry.h` |
| `src/ffi/ndarray.cc` | `reflection/reflection.h` | `reflection/registry.h` |
| `src/ffi/object.cc` | `reflection/reflection.h` | `reflection/registry.h` |
| `src/ffi/testing.cc` | `reflection/reflection.h` | `reflection/registry.h` |
| `tests/cpp/testing_object.h` | `reflection/reflection.h` | `reflection/registry.h` |
| `tests/cpp/test_reflection.cc` | `reflection/reflection.h` | `reflection/accessor.h` + `reflection/registry.h` |

## Key Exports

No new public API symbols. The existing symbols are relocated to new headers:

```python
# --- reflection/registry.h (registration-time) ---
# Contains: ReflectionDefBase, ObjectDef<T>, GlobalDef, DefaultValue,
#   FieldInfoTrait, GetFieldByteOffsetToObject
# Unchanged from prior reflection/reflection.h

# --- reflection/accessor.h (runtime access) ---
# Contains: GetFieldInfo, FieldGetter, FieldSetter, GetMethodInfo,
#   GetMethod, ForEachFieldInfo, ForEachFieldInfoWithEarlyStop
# Unchanged from prior reflection/reflection.h

# Design rationale: registration (registry.h) is used by .cc files that
# define objects; accessor (accessor.h) is used by code that reads fields
# at runtime. Most consumers only need registry.h.
```

## Impact
- API: Header path change -- callers of `#include <tvm/ffi/reflection/reflection.h>` must update to `registry.h` and/or `accessor.h`. The old header is deleted.
- Behavioral: None -- all symbols, types, and function bodies are unchanged.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Reflection system** ([.knowledge/designs/0008-reflection.md](../designs/0008-reflection.md)) -- all symbols from the existing reflection header

Design elements this commit produces:
- **Header split convention**: Registration-time APIs in `registry.h`, runtime-access APIs in `accessor.h`. This establishes a pattern for separating "define" from "use" concerns in the reflection subsystem.

## Usage Examples
Before (single include for all reflection needs):
```cpp
#include <tvm/ffi/reflection/reflection.h>  // old: everything in one header
```

After (targeted includes):
```cpp
// For files that register object fields/methods:
#include <tvm/ffi/reflection/registry.h>

// For files that access fields/methods at runtime:
#include <tvm/ffi/reflection/accessor.h>

// For files that do both (e.g., tests):
#include <tvm/ffi/reflection/accessor.h>
#include <tvm/ffi/reflection/registry.h>
```
