# Split reflection.h into registry.h (registration builders) and accessor.h (runtime accessors)
## TL;DR
- The monolithic `include/tvm/ffi/reflection/reflection.h` (571 lines) is split into two focused headers: `registry.h` (registration builders) and `accessor.h` (runtime accessor utilities).
- `registry.h` retains `ObjectDef<T>`, `GlobalDef`, `ReflectionDefBase`, `FieldInfoTrait`, `DefaultValue`, and `GetFieldByteOffsetToObject` — everything needed to *define* reflection metadata.
- `accessor.h` extracts `GetFieldInfo`, `FieldGetter`, `FieldSetter`, `GetMethodInfo`, `GetMethod`, `ForEachFieldInfo`, and `ForEachFieldInfoWithEarlyStop` — everything needed to *consume* reflection metadata at runtime.

**Rename mapping:**

| Before | After | Content |
|--------|-------|---------|
| `reflection/reflection.h` | `reflection/registry.h` | Registration builders (`ObjectDef`, `GlobalDef`, `ReflectionDefBase`, traits) |
| (same file, bottom half) | `reflection/accessor.h` | Runtime accessors (`FieldGetter`, `FieldSetter`, `GetFieldInfo`, `GetMethodInfo`, `GetMethod`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`) |

**Include migration in consumers:**

| File | Old include | New include |
|------|-------------|-------------|
| `src/ffi/container.cc` | `reflection/reflection.h` | `reflection/registry.h` |
| `src/ffi/function.cc` | `reflection/reflection.h` | `reflection/registry.h` |
| `src/ffi/ndarray.cc` | `reflection/reflection.h` | `reflection/registry.h` |

## Key Exports

**New header `reflection/accessor.h`** — runtime accessor utilities extracted verbatim from old `reflection.h`:

| Symbol | Kind | Signature |
|--------|------|-----------|
| `GetFieldInfo` | free function | `const TVMFFIFieldInfo* GetFieldInfo(string_view type_key, const char* field_name)` |
| `FieldGetter` | class | `FieldGetter(const TVMFFIFieldInfo*)` / `FieldGetter(string_view type_key, const char* field_name)` / `Any operator()(const Object*)` |
| `FieldSetter` | class | `FieldSetter(const TVMFFIFieldInfo*)` / `FieldSetter(string_view type_key, const char* field_name)` / `void operator()(const Object*, AnyView)` |
| `GetMethodInfo` | free function | `const TVMFFIMethodInfo* GetMethodInfo(string_view type_key, const char* method_name)` |
| `GetMethod` | free function | `Function GetMethod(string_view type_key, const char* method_name)` |
| `ForEachFieldInfo` | function template | `void ForEachFieldInfo(const TypeInfo*, Callback)` — iterates ancestors then self fields |
| `ForEachFieldInfoWithEarlyStop` | function template | `bool ForEachFieldInfoWithEarlyStop(const TypeInfo*, Callback)` — same with early termination |

**Renamed header `reflection/registry.h`** — no API changes, same content as old `reflection.h` minus the accessor section:

| Symbol | Kind | Notes |
|--------|------|-------|
| `FieldInfoTrait` | struct | Unchanged |
| `DefaultValue` | class | Unchanged |
| `GetFieldByteOffsetToObject` | function template | Unchanged |
| `ReflectionDefBase` | class | Unchanged — base with `FieldGetter<T>`, `FieldSetter<T>`, `ObjectCreatorDefault<T>`, trait applicators, `GetMethod` |
| `GlobalDef` | class | Unchanged — `def`, `def_packed`, `def_method` |
| `ObjectDef<Class>` | class template | Unchanged — `def_ro`, `def_rw`, `def`, `def_static` |

## Impact
- API: Header path change only. All consumers must update `#include <tvm/ffi/reflection/reflection.h>` to either `reflection/registry.h` (for registration) or `reflection/accessor.h` (for runtime access), or both. No functional API changes.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`0009-reflection.md`) — the entire reflection API is the subject of this refactor.
- **C ABI layer** (`0001-c-abi-layer.md`) — `TVMFFIFieldInfo`, `TVMFFIMethodInfo`, `TVMFFITypeInfo`, `TVMFFIGetTypeInfo`, `TVMFFITypeKeyToIndex` are used by accessor.h.
- **Object system** (`0003-object-system.md`) — `Object`, `ObjectRef`, `ObjectPtr` used as accessor targets.
- **Function system** (`0004-function-system.md`) — `Function::FromTyped`, `Function::FromPacked` used in `GlobalDef`/`ObjectDef` method registration.

Design elements this commit produces:
- **Header decomposition of reflection into registry vs accessor** — establishes a separation of concerns: code that *registers* reflection metadata (`registry.h`) vs code that *reads* it at runtime (`accessor.h`). This is a new structural convention.

## Usage Examples
No new API — this is a pure refactor. Existing usage patterns are unchanged:

```cpp
// Registration (now requires registry.h):
#include <tvm/ffi/reflection/registry.h>
reflection::ObjectDef<MyObj>()
    .def_ro("field", &MyObj::field);

// Runtime access (now requires accessor.h):
#include <tvm/ffi/reflection/accessor.h>
auto info = reflection::GetFieldInfo("my.Type", "field");
reflection::FieldGetter getter(info);
Any value = getter(obj_ptr);
```
