# Split reflection.h into registry.h (registration) and accessor.h (runtime access)
## TL;DR
- Splits monolithic `include/tvm/ffi/reflection/reflection.h` (571 lines) into two focused headers: `registry.h` (414 lines, registration-side types) and `accessor.h` (198 lines, runtime access helpers).
- All 7 dependent `.cc` and test files updated to include `registry.h` instead of `reflection.h`; `test_reflection.cc` now additionally includes `accessor.h` since it uses `FieldGetter`/`FieldSetter`.
- No API or behavioral changes -- pure file reorganization.

## Key Exports

The commit does not introduce new API surface. It redistributes existing symbols across two headers:

**`reflection/registry.h`** (registration-time types):
```python
# Moved from reflection/reflection.h -- no changes to signatures or behavior.
class FieldInfoTrait: ...
class DefaultValue(FieldInfoTrait): ...
def GetFieldByteOffsetToObject(field_ptr: MemberPointer[Class, T]) -> int64: ...
class ReflectionDefBase: ...
    # Interacts with: TVMFFIFieldInfo, TVMFFIMethodInfo, Function.FromTyped
class GlobalDef(ReflectionDefBase): ...
    # Interacts with: TVMFFIFunctionSetGlobalFromMethodInfo (C API)
class ObjectDef(ReflectionDefBase):  # template<Class>
    # Interacts with: TVMFFITypeRegisterField, TVMFFITypeRegisterMethod,
    #                 TVMFFITypeRegisterExtraInfo (C API)
    def def_ro(name, field_ptr, *extra) -> ObjectDef: ...
    def def_rw(name, field_ptr, *extra) -> ObjectDef: ...
    def def_(name, func, *extra) -> ObjectDef: ...
    def def_static(name, func, *extra) -> ObjectDef: ...
```

**`reflection/accessor.h`** (runtime access types):
```python
# Moved from reflection/reflection.h -- no changes to signatures or behavior.
def GetFieldInfo(type_key: str, field_name: str) -> TVMFFIFieldInfo: ...
    # Interacts with: TVMFFITypeKeyToIndex, TVMFFIGetTypeInfo
class FieldGetter:
    def __call__(self, obj: Object | ObjectPtr | ObjectRef) -> Any: ...
    # Interacts with: TVMFFIFieldInfo.getter, TVMFFIFieldInfo.offset
class FieldSetter:
    def __call__(self, obj: Object | ObjectPtr | ObjectRef, value: AnyView) -> None: ...
    # Interacts with: TVMFFIFieldInfo.setter, TVMFFIFieldInfo.offset
def GetMethodInfo(type_key: str, method_name: str) -> TVMFFIMethodInfo: ...
def GetMethod(type_key: str, method_name: str) -> Function: ...
def ForEachFieldInfo(type_info: TypeInfo, callback: Callable) -> None: ...
    # Invariant: iterates ancestors parent-to-child, skipping root Object
def ForEachFieldInfoWithEarlyStop(type_info: TypeInfo, callback: Callable) -> bool: ...
```

## Impact
- API: Header path change -- `#include <tvm/ffi/reflection/reflection.h>` no longer exists. Callers that only register fields/methods now include `registry.h`; callers that also access fields at runtime additionally include `accessor.h`.
- Behavioral: None -- all functions and classes are identical to the old monolithic header.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- Reflection system (`0008-reflection`) -- all types moved are part of this design record.
- C ABI (`0007-c-abi`) -- `TVMFFIFieldInfo`, `TVMFFIMethodInfo`, `TVMFFITypeKeyToIndex`, `TVMFFIGetTypeInfo` used by accessor helpers.
- Object system (`0002-object-system`) -- `Object`, `ObjectPtr`, `ObjectRef` used by `FieldGetter`/`FieldSetter`.
- Function system (`0003-function-system`) -- `Function` used by `GetMethod` and method registration.

Design elements this commit produces:
- None -- no new design elements. The split introduces a **separation of concerns** within the existing reflection module: registration (write-time) vs. access (read-time). This is an organizational improvement, not a new design element.

## Usage Examples
Before/after include pattern:

```cpp
// Before (single monolithic header):
#include <tvm/ffi/reflection/reflection.h>

// After -- registration only (most .cc files):
#include <tvm/ffi/reflection/registry.h>

// After -- registration + runtime access (test/accessor code):
#include <tvm/ffi/reflection/accessor.h>
#include <tvm/ffi/reflection/registry.h>
```
