# Split reflection.h into registry.h (registration) and accessor.h (runtime access utilities)

## TL;DR
- Renames `include/tvm/ffi/reflection/reflection.h` → `registry.h` (retains the registration side: `ReflectionDef`, `ObjectDef`, `GlobalDef`, `ReflectionDefBase`, `DefaultValue`, `FieldInfoTrait`).
- Extracts the runtime accessor utilities out of `reflection.h` into a new `include/tvm/ffi/reflection/accessor.h`: `FieldGetter`, `FieldSetter`, `GetFieldInfo`, `GetMethodInfo`, `GetMethod`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`.
- Updates all 7 include-site callees (5 `src/ffi/*.cc`, `tests/cpp/test_reflection.cc`, `tests/cpp/testing_object.h`) to use the correct split header; `test_reflection.cc` now includes both `accessor.h` and `registry.h`.

## Before/After Rename Mapping

| Old path | New path | Content |
|---|---|---|
| `include/tvm/ffi/reflection/reflection.h` | `include/tvm/ffi/reflection/registry.h` | Registration builders (`ReflectionDef`, `ObjectDef`, `GlobalDef`, etc.) |
| _(did not exist)_ | `include/tvm/ffi/reflection/accessor.h` | Runtime accessor utilities (`FieldGetter`, `FieldSetter`, `GetFieldInfo`, `GetMethodInfo`, `GetMethod`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`) |

## Key Exports

No new public API surface — this is a pure split/rename. Moved symbols are listed below for include-site migration.

```python
# accessor.h — moved here from reflection.h
class FieldGetter:
    """Callable wrapper: looks up field by (type_key, field_name) then reads it."""
    def __init__(self, field_info: TVMFFIFieldInfo*) -> None: ...
    def __init__(self, type_key: str, field_name: str) -> None: ...
    def __call__(self, obj: Object* | ObjectPtr[Object] | ObjectRef) -> Any: ...
    # Interacts with: GetFieldInfo (lookup), TVMFFIFieldInfo.getter (actual read)
    # Invariant: field_info pointer must remain valid for the FieldGetter's lifetime

class FieldSetter:
    """Callable wrapper: looks up field by (type_key, field_name) then writes it."""
    def __init__(self, field_info: TVMFFIFieldInfo*) -> None: ...
    def __init__(self, type_key: str, field_name: str) -> None: ...
    def __call__(self, obj: Object* | ObjectPtr[Object] | ObjectRef, value: AnyView) -> None: ...
    # Interacts with: GetFieldInfo (lookup), TVMFFIFieldInfo.setter (actual write)

def GetFieldInfo(type_key: str, field_name: str) -> TVMFFIFieldInfo*: ...
    # Interacts with: TVMFFITypeKeyToIndex, TVMFFIGetTypeInfo

def GetMethodInfo(type_key: str, method_name: str) -> TVMFFIMethodInfo*: ...
    # Interacts with: TVMFFITypeKeyToIndex, TVMFFIGetTypeInfo

def GetMethod(type_key: str, method_name: str) -> Function: ...
    # Interacts with: GetMethodInfo, AnyView.CopyFromTVMFFIAny

def ForEachFieldInfo(type_info: TypeInfo*, callback: Callable[[TVMFFIFieldInfo*], None]) -> None: ...
    # Traverses ancestors in parent-to-child order; skips root Object (index 0)
    # Interacts with: type_info.type_acenstors, type_info.type_depth

def ForEachFieldInfoWithEarlyStop(
    type_info: TypeInfo*,
    callback: Callable[[TVMFFIFieldInfo*], bool]
) -> bool: ...
    # Like ForEachFieldInfo but returns True if any callback returned True (early stop)

# registry.h — remains here (registration builders, unchanged)
# ReflectionDef, ObjectDef, GlobalDef, DefaultValue, FieldInfoTrait — same API as before
```

## Impact
- API: **Include path change** — all callers of `#include <tvm/ffi/reflection/reflection.h>` must migrate to:
  - `#include <tvm/ffi/reflection/registry.h>` for registration builders
  - `#include <tvm/ffi/reflection/accessor.h>` for `FieldGetter`, `FieldSetter`, `GetFieldInfo`, `GetMethodInfo`, `GetMethod`, `ForEachFieldInfo`, `ForEachFieldInfoWithEarlyStop`
  - (or include both if needed — `test_reflection.cc` is the canonical example)
- Behavioral: None — no logic changed.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

Using the accessor utilities from the new `accessor.h` (from `tests/cpp/test_reflection.cc`):

```cpp
#include <tvm/ffi/reflection/accessor.h>
#include <tvm/ffi/reflection/registry.h>

// Field getter by type key + field name
reflection::FieldGetter getter("test.Int", "value");
int val = getter(my_int_obj).cast<int>();

// Field setter by type key + field name
reflection::FieldSetter setter("test.Float", "value");
setter(my_float_obj, 20.0);

// Traverse all fields across the full inheritance chain
const TypeInfo* info = TVMFFIGetTypeInfo(MyObj::RuntimeTypeIndex());
reflection::ForEachFieldInfo(info, [](const TVMFFIFieldInfo* fi) {
    // fi->name, fi->offset, fi->getter, fi->setter
});

// Look up a method Function by name
Function add_fn = reflection::GetMethod("test.Int", "static_add");
```
