# Enable torch.dtype, numpy.dtype, and ml_dtypes as FFI input via lookup-table conversion

## TL;DR
- Adds three Cython-level lookup tables (`TORCH_DTYPE_TO_DTYPE`, `NUMPY_DTYPE_TO_DTYPE`, `MLDTYPES_DTYPE_TO_DTYPE`) mapping framework-native dtype objects to `DLDataType` structs, and two new Cython arg setters (`TVMFFIPyArgSetterDTypeFromTorch_`, `TVMFFIPyArgSetterDTypeFromNumpy_`) registered in `TVMFFIPyArgSetterFactory_`.
- Adds corresponding pure-Python conversion branches in `_convert.py` for the `convert()` slow path (`torch.dtype -> core._convert_torch_dtype_to_ffi_dtype`, `numpy.dtype -> core._convert_numpy_dtype_to_ffi_dtype`).
- Adds `kDLBool` case to the C++ `DLDataTypeCodeAsCStr` switch in `dtype.h` (previously missing, causing unhandled enum value for `torch.bool` mapping to type code 6).

## Impact
- API: Additive -- `torch.dtype` and `numpy.dtype` objects can now be passed directly as FFI function arguments and through `tvm_ffi.convert()`. No existing signatures changed.
- Behavioral: `convert()` dispatch chain extended with two new branches (after `__dlpack__`, before `Exception`). The setter factory dispatch chain extended with two new branches (after `callable`, before `Exception`).
- Flags/config: `TVM_FFI_BUILD_DOCS` env var now also gates torch/numpy/ml_dtypes imports in `dtype.pxi` (was already used in `function.pxi`).
- Data formats/schemas: none

## Usage Examples

Passing torch and numpy dtypes directly to FFI functions (from `tests/python/test_dtype.py`):

```python
import tvm_ffi
import torch
import numpy as np

fecho = tvm_ffi.get_global_func("testing.echo")

# torch.dtype -> FFI DataType (goes through TVMFFIPyArgSetterDTypeFromTorch_)
result = fecho(torch.float32)
assert result.type_code == 2 and result.bits == 32 and result.lanes == 1

# numpy.dtype -> FFI DataType (goes through TVMFFIPyArgSetterDTypeFromNumpy_)
result = fecho(np.dtype(np.int64))
assert result.type_code == 0 and result.bits == 64 and result.lanes == 1

# Also works through convert() path
converted = tvm_ffi.convert(torch.bfloat16)
assert converted.type_code == 4 and converted.bits == 16
```
