# Add FunctionInfo SFINAE specialization for ObjectRef member function pointers
## TL;DR
- Adds `FunctionInfo` template specializations for `ObjectRef`-derived class member function pointers, fixing downstream compilation errors when registering `ObjectRef` methods as global functions.
- Introduces SFINAE (`std::enable_if_t`) on the second template parameter to disambiguate `Object::MemFn` (pointer-to-self) vs `ObjectRef::MemFn` (value-of-self) dispatch.
- Validates with `TestIntPair::Sum()` registered both as a type method and global function, with correct schema extraction (`Callable[[testing.TestIntPair], int]`).

## Key Exports

```python
# FunctionInfo SFINAE specialization hierarchy (C++ template metaprogramming):
#
# Primary template (lambdas, functors with operator()):
#   FunctionInfo<T, void> : FunctionInfoHelper<decltype(&T::operator())>
#
# Free functions:
#   FunctionInfo<R(Args...), void> : FuncFunctorImpl<R, Args...>
#   FunctionInfo<R(*)(Args...), void> : FuncFunctorImpl<R, Args...>
#
# Object-derived class member functions (pointer semantics for self):
#   FunctionInfo<R(Class::*)(Args...), enable_if<is_base_of<Object, Class>>>
#       : FuncFunctorImpl<R, Class*, Args...>
#   FunctionInfo<R(Class::*)(Args...) const, enable_if<is_base_of<Object, Class>>>
#       : FuncFunctorImpl<R, const Class*, Args...>
#
# ObjectRef-derived class member functions (value semantics for self):  [NEW]
#   FunctionInfo<R(Class::*)(Args...), enable_if<is_base_of<ObjectRef, Class>>>
#       : FuncFunctorImpl<R, Class, Args...>
#   FunctionInfo<R(Class::*)(Args...) const, enable_if<is_base_of<ObjectRef, Class>>>
#       : FuncFunctorImpl<R, const Class, Args...>
#
# Invariant: ObjectRef is NOT derived from Object, so SFINAE cleanly partitions
#            the two specialization sets without ambiguity.
# Interacts with: Function::FromTyped, GlobalDef::def_method, ObjectDef::RegisterMethod
# Interacts with: TypeSchema generation (correct first-arg type in schema)

# GlobalDef::def_method usage with ObjectRef member function:
class GlobalDef:
    def def_method(name: str, func: ObjectRef.MemFn, *extra) -> GlobalDef:
        """Register an ObjectRef member function as a global function.
        Uses FunctionInfo to deduce schema, GetMethod to wrap with by-value self."""
        # Interacts with: FunctionInfo (schema), GetMethod (wrapping), RegisterFunc
        ...

# Testing example: TestIntPair::Sum registered two ways
# 1. As type method via ObjectDef::def("sum", &TestIntPair::Sum)
# 2. As global function via GlobalDef::def_method("testing.TestIntPairSum", &TestIntPair::Sum)
# Both produce correct schema: Callable[[testing.TestIntPair], int]
```

## Impact
- API: None (additive template specialization; no existing callers change behavior)
- Behavioral: Member functions of `ObjectRef`-derived classes can now be registered as global functions via `def_method` and as type methods via `def()` without compilation errors. Previously only `Object`-derived member functions were handled.
- Flags/config: None
- Data formats/schemas: Type schema for `ObjectRef` member functions now correctly reflects the `ObjectRef` type name (e.g., `testing.TestIntPair`) as the first argument, rather than failing to compile.

## Usage Examples

Before/after pattern showing what was broken and the fix:

```cpp
// BEFORE (compilation error): FunctionInfo had no specialization
// for ObjectRef-derived member function pointers.
class TestIntPair : public ObjectRef {
  int64_t Sum() const { return get()->a + get()->b; }
  // ...
};

// This would fail to compile because FunctionInfo<int64_t (TestIntPair::*)() const>
// had no matching specialization:
// refl::GlobalDef().def_method("testing.TestIntPairSum", &TestIntPair::Sum);

// AFTER: New SFINAE specialization handles ObjectRef member functions.
// FunctionInfo<int64_t (TestIntPair::*)() const, enable_if<is_base_of<ObjectRef, TestIntPair>>>
//   : FuncFunctorImpl<int64_t, const TestIntPair>
// First arg is TestIntPair by value (not pointer), matching ObjectRef handle semantics.

// Both registration paths now work:
TVM_FFI_STATIC_INIT_BLOCK() {
  refl::ObjectDef<TestIntPairObj>()
      .def("sum", &TestIntPair::Sum, "Method to compute sum of a and b");
  refl::GlobalDef()
      .def_method("testing.TestIntPairSum", &TestIntPair::Sum, "Get sum of the pair");
}
```

```python

metadata = get_global_func_metadata("testing.TestIntPairSum")

assert str(type_schema) == "Callable[[testing.TestIntPair], int]"
```
