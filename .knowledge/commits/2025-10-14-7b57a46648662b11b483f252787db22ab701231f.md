# Add FunctionInfo specialization for ObjectRef member functions to fix schema generation

## TL;DR
- Adds SFINAE-based `FunctionInfo<>` specializations for `ObjectRef`-derived member functions (non-const and const), so that registering an `ObjectRef::MemFn` as a global function compiles and generates the correct type schema.
- Previously only `Object`-derived pointer-to-member specializations existed; `ObjectRef` members (passed by value, not pointer) were not handled, causing downstream compilation errors.

## Key Exports

**Template specializations in `function_details.h`**:

| Specialization | Self type | Condition |
|----------------|-----------|-----------|
| `FunctionInfo<R (Class::*)(Args...), enable_if<is_base_of<Object, Class>>>` | `Class*` | Object-derived (existing, now SFINAE-guarded) |
| `FunctionInfo<R (Class::*)(Args...) const, enable_if<is_base_of<Object, Class>>>` | `const Class*` | Object-derived const (existing, now SFINAE-guarded) |
| `FunctionInfo<R (Class::*)(Args...), enable_if<is_base_of<ObjectRef, Class>>>` | `Class` (by value) | **New** -- ObjectRef-derived |
| `FunctionInfo<R (Class::*)(Args...) const, enable_if<is_base_of<ObjectRef, Class>>>` | `const Class` (by value) | **New** -- ObjectRef-derived const |

The key distinction: `Object`-derived members receive `Class*` (pointer to the data object), while `ObjectRef`-derived members receive `Class` by value (the ref wrapper itself).

## Impact
- API: none (template specialization, no public API surface change)
- Behavioral: `ObjectRef` member functions can now be registered with `def_method` / global function registration and produce correct type schemas.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

From the test and C++ code in this commit:
```cpp
// C++ side: register an ObjectRef member function
class TestIntPair : public ObjectRef {
  int64_t Sum() const { return get()->a + get()->b; }
};

// Registration via ObjectDef
refl::ObjectDef<TestIntPairObj>()
    .def("sum", &TestIntPair::Sum, "Method to compute sum of a and b");

// Also as a global function
GlobalDef()
    .def_method("testing.TestIntPairSum", &TestIntPair::Sum, "Get sum of the pair");
```
```python
# Python side: schema is correctly inferred
metadata = get_global_func_metadata("testing.TestIntPairSum")
schema = TypeSchema.from_json_str(metadata["type_schema"])
assert str(schema) == "Callable[[testing.TestIntPair], int]"
```
