# Add FunctionInfo specialization for ObjectRef member functions
## TL;DR
- Adds `FunctionInfo` specializations for `ObjectRef` member functions (both const and non-const), fixing compilation errors when registering ObjectRef member methods as global functions in downstream TVM.
- Uses `ObjectRef` (not `ObjectRef*`) as the first schema argument since ObjectRef is already a value-semantic handle.

## Impact
- API: Fixes downstream compilation. No new public API.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Function system** (`.knowledge/designs/0004-function-system.md`): `FunctionInfo` template specializations.
- **Object system** (`.knowledge/designs/0003-object-system.md`): `ObjectRef` as value-semantic handle.

Design elements this commit produces:
- **ObjectRef member function schema**: `FunctionInfo` for `R (ObjectRef::*)(Args...)` uses `ObjectRef` (not `ObjectRef*`) as the self parameter type in the schema.
