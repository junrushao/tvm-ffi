# Replace C-style cast with static_cast in String::substr default parameter

## TL;DR
- `String::substr` default parameter changed from `size_t(-1)` to `npos` to fix a clang-tidy `google-readability-casting` warning.
- `npos` is already defined as `static constexpr size_t npos = static_cast<size_t>(-1)` in the `String` class (line 615 of `string.h`), so runtime value is identical.
- No behavioral change; pure lint compliance fix.
