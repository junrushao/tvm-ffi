# Fix clang20 compilation error by qualifying nullptr_t as std::nullptr_t in String constructor delete
## TL;DR
- Replaces unqualified `nullptr_t` with `std::nullptr_t` in the deleted constructor declaration of `String` class in `include/tvm/ffi/string.h`.
- Fixes a compilation error under clang 20, which no longer implicitly resolves `nullptr_t` without the `std::` namespace qualifier.

## Key Exports
None -- no new API surface. Single-token fix to an existing deleted constructor declaration.

## Impact
- API: None -- the deleted constructor prevents construction of `String` from null pointers; this behavior is unchanged.
- Behavioral: None -- compile-time only fix.
- Flags/config: None.
- Data formats/schemas: None.
