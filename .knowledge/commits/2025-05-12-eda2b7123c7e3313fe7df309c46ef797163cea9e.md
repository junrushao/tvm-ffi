# Fix clang20 compilation error by qualifying nullptr_t with std:: in String
## TL;DR
- Changed `nullptr_t` to `std::nullptr_t` in the deleted constructor of `String` (`include/tvm/ffi/string.h`), fixing a compilation failure with clang 20.
- Clang 20 no longer allows unqualified `nullptr_t` in some contexts; the C++ standard requires `std::nullptr_t`.
