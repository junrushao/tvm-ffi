# Fix clang20 compilation error: qualify nullptr_t as std::nullptr_t in String
## TL;DR
- Replace unqualified `nullptr_t` with `std::nullptr_t` in the deleted `String` constructor to fix a compilation failure under clang20.
- clang20 enforces stricter unqualified name lookup; `nullptr_t` is only guaranteed in `namespace std`.
- No functional or behavioral change; the constructor remains deleted.
