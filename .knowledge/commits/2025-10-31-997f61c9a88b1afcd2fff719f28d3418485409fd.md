# Add CUDA C++ loading example, C++ packaging guide, and pre-commit setup docs

## TL;DR
- Adds `examples/quickstart/load/load_cuda.cc`, a standalone C++ example demonstrating CUDA tensor allocation via `CUDANDAlloc` and module loading via `ffi::Module::LoadFromFile`, along with a commented-out Example 4 block in `raw_compile.sh` showing how to compile and link it.
- Creates `docs/guides/cpp_packaging.md`, a new documentation page explaining glibc/ABI compatibility challenges and the manylinux approach for distributing C++ and CUDA kernel libraries that use tvm-ffi.

## Usage Examples
The `load_cuda.cc` example itself serves as the canonical usage example for CUDA C++ module loading. Key pattern:

```cpp
// Allocate CUDA tensors using the NDAlloc protocol
ffi::Tensor x = ffi::Tensor::FromNDAlloc(CUDANDAlloc(), {ARRAY_SIZE}, f32_dtype, cuda_device);
// Load a compiled kernel library and call a function
ffi::Module mod = ffi::Module::LoadFromFile("build/add_one_cuda.so");
ffi::Function add_one_cuda = mod->GetFunction("add_one_cuda").value();
add_one_cuda(x, y);
```

The commented-out compilation block in `raw_compile.sh` shows the link flags:
```bash
g++ -fvisibility=hidden -O3 load/load_cuda.cc \
    $(tvm-ffi-config --cxxflags) $(tvm-ffi-config --ldflags) $(tvm-ffi-config --libs) \
    -I/usr/local/cuda/include -L/usr/local/cuda/lib64 -lcudart \
    -o build/load_cuda
```
