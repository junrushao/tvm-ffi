## Usage Examples
The `load_cuda.cc` example demonstrates the canonical pattern for loading and calling a CUDA FFI function from C++:

```cpp
#include <tvm/ffi/container/tensor.h>
#include <tvm/ffi/extra/module.h>

namespace ffi = tvm::ffi;

void Run(ffi::TensorView x, ffi::TensorView y) {
  ffi::Module mod = ffi::Module::LoadFromFile("build/add_one_cuda.so");
  ffi::Function add_one_cuda = mod->GetFunction("add_one_cuda").value();
  add_one_cuda(x, y);
}

// Custom CUDA allocator using Tensor::FromNDAlloc:
ffi::Tensor Empty(ffi::Shape shape, DLDataType dtype, DLDevice device) {
  return ffi::Tensor::FromNDAlloc(CUDANDAlloc(), shape, dtype, device);
}
```

The commented-out `raw_compile.sh` section shows the compilation command:
```bash
g++ -fvisibility=hidden -O3 load/load_cuda.cc \
    $(tvm-ffi-config --cxxflags) $(tvm-ffi-config --ldflags) $(tvm-ffi-config --libs) \
    -I/usr/local/cuda/include -L/usr/local/cuda/lib64 -lcudart \
    -o build/load_cuda
```
