- **Tensor / TensorView** (`ffi::Tensor`, `ffi::TensorView`, `ffi::Tensor::FromNDAlloc`) — the example shows CUDA device tensor allocation via `FromNDAlloc` with a custom allocator struct, consuming the tensor API from `.knowledge/designs/0017-dlpack-interop.md`.

- **ABI distribution guidance** — the `cpp_packaging.md` guide codifies the manylinux-based distribution strategy for kernel libraries.

## Usage Examples
CUDA tensor loading via `ffi::Module` (from `examples/quickstart/load/load_cuda.cc`):
```cpp
namespace ffi = tvm::ffi;

void Run(ffi::TensorView x, ffi::TensorView y) {
  ffi::Module mod = ffi::Module::LoadFromFile("build/add_one_cuda.so");
  ffi::Function add_one_cuda = mod->GetFunction("add_one_cuda").value();
  add_one_cuda(x, y);
}

// Custom CUDA allocator for Tensor::FromNDAlloc
struct CUDANDAlloc {
  void AllocData(DLTensor* tensor) { cudaMalloc(&tensor->data, ffi::GetDataSize(*tensor)); }
  void FreeData(DLTensor* tensor) { cudaFree(tensor->data); tensor->data = nullptr; }
};
ffi::Tensor x = ffi::Tensor::FromNDAlloc(CUDANDAlloc(), {5}, f32_dtype, cuda_device);
```
