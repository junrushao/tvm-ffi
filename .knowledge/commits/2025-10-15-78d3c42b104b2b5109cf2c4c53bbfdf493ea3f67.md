# Upgrade Python dependencies, add dev group, enforce Ninja, pre-import torch on Windows
## TL;DR
- Adds torch back to Windows test dependencies (removes `sys_platform != 'win32'` constraint) and pins to `python_version < '3.14'`.
- Introduces a `dev` dependency-group in `pyproject.toml` with common developer tools (ruff, mypy, clang-format, ipdb, pre-commit, etc.).
- Enforces Ninja as the sole build generator (`ninja.make-fallback = false`) and adds `ninja` to `build-system.requires`.
- Pre-imports `torch` in `tvm_ffi/__init__.py` to work around a symbol conflict on Windows x64 + Python 3.12 + torch 2.9.0.

## Impact
- API: none
- Behavioral: `import tvm_ffi` now silently attempts `import torch` first on all platforms; no effect if torch is absent.
- Flags/config: `ninja.make-fallback = false` in `[tool.scikit-build]` means builds will fail without Ninja (mitigated by adding it to `build-system.requires`). New `[dependency-groups] dev` available via `uv sync --group dev`.
