# Upgrade Python dependencies: add dev group, enforce Ninja, fix torch/tvm_ffi import-order conflict on Windows

## TL;DR
- Adds a new `[dependency-groups] dev` group to `pyproject.toml` with all developer tools (ruff, mypy, clang-format, clang-tidy, ipdb, ipython, cython, cmake, etc.), replacing the old ad-hoc `test` group that mixed test and dev dependencies.
- Enforces Ninja as the build backend for `scikit-build-core` (`ninja.make-fallback = false`) and adds `ninja` to `[build-system] requires` so pip-installable builds always have Ninja available.
- Re-adds `torch` to Windows test dependencies and inserts a defensive `try: import torch` at the top of `tvm_ffi/__init__.py` to prevent a symbol-conflict crash (Windows × Python 3.12 × torch 2.9.0).

## Key Exports

None — no new public API surface introduced. The `__init__.py` change is a defensive import guard, not a new export.

## Impact
- API: none
- Behavioral: On import, `tvm_ffi` now proactively imports `torch` (if available) before loading `libtvm_ffi`. This avoids a DLL symbol conflict observed on Windows x64, Python 3.12, torch 2.9.0. Existing callers are unaffected; the `try/except ImportError` is a no-op when torch is absent.
- Flags/config: `[tool.scikit-build] ninja.version = ">=1.11"` and `ninja.make-fallback = false` — builds now hard-require Ninja (installable via PyPI as `ninja`). `[tool.uv.dependency-groups] docs = { requires-python = ">=3.13" }` constrains the docs group to Python 3.13+. The `test` dependency group drops the `sys_platform != 'win32'` guard on `torch` and pins to `python_version < '3.14'` only.
- Data formats/schemas: none

## Usage Examples

None — chore/dependency commit with no new API surface. The only usage-relevant change is the import guard:

```python
# tvm_ffi/__init__.py — new preamble (before loading base/libinfo)
# HACK: try importing torch first, to avoid a potential
# symbol conflict when both torch and tvm_ffi are imported.
# Reproduced on: Windows x64 / Python 3.12 / torch 2.9.0
try:
    import torch  # type: ignore
except ImportError:
    pass

# base always go first to load the libtvm_ffi
from . import base
from . import libinfo
```
