# Upgrade Python dependencies: add dev group, enforce Ninja, workaround torch/Windows symbol conflict

## TL;DR
- Adds a `dev` dependency-group in `pyproject.toml` for local development tooling (ruff, mypy, clang-format, clang-tidy, ipdb, ipython, pre-commit, pytest, numpy, ml_dtypes, cython, cmake, scikit-build-core, ninja).
- Re-adds `torch` to the `test` optional dependency for Windows (previously excluded via `sys_platform != 'win32'`), constrained only by `python_version < '3.14'`.
- Enforces Ninja as the sole CMake generator in scikit-build-core (`ninja.make-fallback = false`), and adds `ninja` to the `build-system.requires`.
- Inserts a `try: import torch` hack in `tvm_ffi/__init__.py` to pre-load torch before `tvm_ffi` loads its native library, working around a Windows x64 + Python 3.12 + torch 2.9.0 symbol conflict.
- Adds `[tool.uv.dependency-groups] docs = { requires-python = ">=3.13" }` to restrict docs group to Python 3.13+.

## Key Exports
None -- this commit changes build/packaging configuration and a load-order workaround, not public API.

## Impact
- API: None
- ABI: None
- Behavioral: On Windows x64 + Python 3.12 + torch 2.9.0, `import tvm_ffi` now pre-imports torch to avoid a native symbol conflict that previously caused crashes. This is a narrow workaround; on other platforms the `try/except ImportError` is a no-op.
- Flags/config: `ninja.make-fallback = false` in `[tool.scikit-build]` means builds will fail if Ninja is unavailable (but Ninja is now a build-system requirement so this should not occur in practice).
- Data formats/schemas: None

## Usage Examples

### Installing with the dev dependency group
**Context**: A developer setting up a local development environment can install all tools in one command.
```bash
uv pip install --group dev -e .
```

### Torch pre-import workaround
**Context**: The workaround is automatic -- users do not need to take any action. The relevant code in `python/tvm_ffi/__init__.py`:
```python
# HACK: try importing torch first, to avoid a potential
# symbol conflict when both torch and tvm_ffi are imported.
try:
    import torch  # type: ignore
except ImportError:
    pass
```
