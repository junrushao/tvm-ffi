# Upgrade Python dependencies, add dev group, enforce Ninja, workaround torch symbol conflict
## TL;DR
- Added `torch` back to Windows test dependencies (removed `sys_platform != 'win32'` constraint).
- Added new `[dependency-groups] dev` with development tools (ruff, mypy, clang-format, pre-commit, etc.).
- Enforced Ninja as build system (`ninja.make-fallback = false`) in scikit-build-core config.
- Added `ninja` to `build-system.requires`.
- Added a workaround in `__init__.py`: pre-import torch before loading tvm_ffi to avoid a symbol conflict on Windows x64 / Python 3.12 / torch 2.9.0.
