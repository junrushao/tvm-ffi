# Upgrade Python dependencies: re-enable torch on Windows, add dev group, enforce Ninja
## TL;DR
- Re-enables `torch` as a test dependency on Windows (previously excluded via `sys_platform != 'win32'`) and adds an early `import torch` workaround in `__init__.py` to avoid a symbol conflict on Windows x64 / Python 3.12 / torch 2.9.0.
- Introduces a `dev` dependency-group in `pyproject.toml` bundling all local development tools (ruff, mypy, clang-format/tidy, pre-commit, cython, cmake, etc.).
- Enforces Ninja as the sole build generator for scikit-build-core (`ninja.make-fallback = false`), adding `ninja` to `build-system.requires`.

## Impact
- API: none
- Behavioral: `import tvm_ffi` now eagerly tries `import torch` before loading `libtvm_ffi`, preventing a narrow symbol-conflict crash on Windows x64 + Python 3.12 + torch 2.9.0 in CI.
- Flags/config: `ninja.make-fallback = false` means builds will fail if Ninja cannot be found (but it is now declared as a build-system requirement so pip/uv will install it automatically).
