# Explicitly zero-initialize __padding field in TVMFFIObject during allocation
## TL;DR
- Adds `ffi_ptr->__padding = 0;` to both `ObjAllocatorBase::make_object` and `ObjAllocatorBase::make_inplace_array`, ensuring the `TVMFFIObject` header's unused `uint32_t __padding` field is deterministically zeroed on every object allocation.
- Eliminates a source of non-deterministic memory content in allocated objects, which could affect tools like sanitizers, serializers, or hash-based comparisons that read raw header bytes.

## Key Exports
None

## Impact
- API: None -- no signature or public interface changes.
- Behavioral: `TVMFFIObject.__padding` is now guaranteed to be 0 after allocation. Previously, this field was uninitialized (whatever the allocator returned), which is technically undefined behavior if read. The field sits between `type_index` (int32_t) and `deleter` (function pointer) in the 24-byte `TVMFFIObject` struct.
- Flags/config: None.
- Data formats/schemas: None.
