# Explicitly zero __padding field in object allocator for deterministic memory
## TL;DR
- Sets `ffi_ptr->__padding = 0` in both `make_object` and `make_inplace_array_object` allocation paths, ensuring deterministic memory for the unused padding field in the `TVMFFIObject` header.
