# Introduce List<T> as mutable sequence container with SeqBaseObj shared base
## TL;DR
- Introduces `List<T>`, a mutable sequence container alongside immutable `Array<T>`, with full C++, Python, and serialization support.
- Extracts `SeqBaseObj` as a shared base class for `ArrayObj` and `ListObj`, consolidating element storage, iteration, and access. Adds `TVMFFISeqCell` to the C ABI.
- Adds `kTVMFFIList = 75` type index, cycle detection in serialization/hash/equality for `List`, and `TypeTraits<std::vector<T>>` accepting both `kTVMFFIArray` and `kTVMFFIList`.

## Key Exports

**C ABI**:
```c
// c_api.h
kTVMFFIList = 75  // new type index

// TVMFFISeqCell -- new C ABI struct for sequence containers
struct TVMFFISeqCell {
    void* data;                      // pointer to first element
    int64_t size;                    // elements used
    int64_t capacity;                // elements allocated
    void (*data_deleter)(void*);     // optional deleter for data buffer
};
```

**C++ types**:

## Impact
- API: New type index `kTVMFFIList = 75`. New `TVMFFISeqCell` C ABI struct. New `SeqBaseObj` base class refactored from `ArrayObj`. `ArrayObj` now inherits from `SeqBaseObj` instead of directly from `Object`.
- Behavioral: `TypeTraits<std::vector<T>>::TryCastFromAnyView` now accepts both `kTVMFFIArray` and `kTVMFFIList`. Serialization, structural hash, and structural equal all handle `List` with cycle detection.
- Flags/config: none
- Data formats/schemas: JSON writer handles `List` (with cycle detection).

Design elements this commit produces:
- **SeqBaseObj**: New shared base class for `ArrayObj` and `ListObj`, consolidating sequence operations.
- **TVMFFISeqCell**: New C ABI struct defining the memory layout shared by Array and List.
- **List<T>**: Mutable sequence container (unlike COW Array). Direct mutation, no COW. Not thread-safe. Can form reference cycles.

## Usage Examples

```cpp
// C++ List creation and mutation
List<int> l = {1, 2, 3};
l.push_back(4);
l.Set(0, 10);
assert(l[0] == 10);
l.erase(1);  // remove element at index 1
l.reverse();

// Python
lst = tvm_ffi.List([1, 2, 3])
lst.append(4)
lst[0] = 10
del lst[1]
lst.reverse()
```
