# Introduce List as mutable sequence container
## TL;DR
- Adds `List<T>` mutable sequence container in `include/tvm/ffi/container/list.h` with a shared `SeqBase` extracted from Array.
- Extends C ABI with List type index and manipulation functions.
- Adds full Python bindings, serialization, structural equality/hash, and deep copy support for List.

## Impact
- API: New `List<T>` container type in C++, Python, and C ABI.
- Flags/config: None.
- Data formats/schemas: New type index for List in C ABI.
