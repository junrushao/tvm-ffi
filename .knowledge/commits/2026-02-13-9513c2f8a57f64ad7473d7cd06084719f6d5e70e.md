# Introduce List<T> as mutable sequence container with SeqBaseObj extraction
## TL;DR
- Adds `List<T>`, a mutable sequence container alongside immutable `Array<T>`, with full C++ and Python support
- Extracts `SeqBaseObj` as shared base class for `ArrayObj` and `ListObj`, consolidating type-erased sequence ops
- Adds `kTVMFFIList = 75` to `TypeIndex` enum and `TVMFFISeqCell` struct to `c_api.h`
- Implements cycle detection in serialization/JSON/structural-equal/hash for `List`

## Key Exports

```python
class ListObj(SeqBaseObj):
    """Mutable sequence container backed by a contiguous Any buffer."""
    # Invariant: size <= capacity; data_deleter != nullptr for heap buffer
    # Extension: new container types can inherit SeqBaseObj

class List(ObjectRef, Generic[T]):
    """Mutable typed list, analogous to Python list."""
    def __getitem__(self, i: int) -> T: ...
    def __setitem__(self, i: int, val: T) -> None: ...  # via Set()
    def push_back(self, item: T) -> None: ...
    def pop_back(self) -> None: ...
    def insert(self, pos: iterator, val: T) -> None: ...
    def erase(self, pos: iterator) -> None: ...
    def resize(self, n: int) -> None: ...
    def reserve(self, n: int) -> None: ...
    def clear(self) -> None: ...
    # Interacts with: Array<T> (shared SeqBaseObj base), serialization, structural equal/hash
    # Invariant: NOT thread-safe; reference cycles possible but not collected by refcount

class SeqBaseObj(Object):
    """Shared base for ArrayObj and ListObj with common iteration/access."""
    data: void_ptr
    size: int64
    capacity: int64
    data_deleter: FunctionPtr
    # Interacts with: ArrayObj, ListObj, Python iteration protocol

# C ABI addition:
# kTVMFFIList = 75  (new type index)
# TVMFFISeqCell { data, size, capacity, data_deleter }
```

## Impact
- API: new public type `List<T>` in C++ and `tvm_ffi.List` in Python; new `kTVMFFIList = 75` enum value in `c_api.h`
- Behavioral: `TypeTraits<std::vector<T>>` now accepts both `kTVMFFIArray` and `kTVMFFIList`
- Flags/config: none
- Data formats/schemas: JSON serialization extended with cycle detection for List

## Usage Examples
```python
import tvm_ffi

# Construction
lst = tvm_ffi.List([1, 2, 3])
lst.append(4)
lst[0] = 10
assert len(lst) == 4
assert lst[0] == 10

# Iteration
for item in lst:
    print(item)

# Pickle round-trip
import pickle
lst2 = pickle.loads(pickle.dumps(lst))
```
