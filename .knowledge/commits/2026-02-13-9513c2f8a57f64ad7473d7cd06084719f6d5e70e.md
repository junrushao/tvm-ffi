# Introduce List as Mutable Sequence container
## TL;DR
- Introduces `List<Any>` as a mutable sequence container (complement to immutable `Array<T>`)
- Extracts common sequence logic into `SeqBaseObj`/`SeqBase<T>` shared by both `Array` and `List`
- Adds `ListObj` with `kTVMFFIList` type index and `TVMFFISeqCell` C ABI struct
- Python `List` class wraps with `MutableSequence` interface; adds `list()` conversion function
- Integrates with JSON serialization, structural equality/hashing

## Key Exports
```python
class TVMFFISeqCell:
    """C ABI layout for sequence containers (shared by Array and List)."""
    data: *mut c_void
    size: int64
    capacity: int64
    data_deleter: Optional[Callable]

class SeqBaseObj(Object):
    """Base class for sequence containers (Array and List share this)."""
    # Inherits TVMFFISeqCell layout

class ListObj(SeqBaseObj):
    """Mutable sequence container storing Any values."""
    _type_index: ClassVar[int] = kTVMFFIList
    _type_key: ClassVar[str] = "ffi.List"
    # Interacts with: Array (shares SeqBase), JSON serialization, structural eq/hash

class List[T]:
    """Typed mutable list wrapping ListObj."""
    def __init__(self, *args) -> None: ...
    def append(self, item: T) -> None: ...
    def __setitem__(self, index: int, value: T) -> None: ...
    def __delitem__(self, index: int) -> None: ...
    def insert(self, index: int, value: T) -> None: ...
    def pop(self, index: int = -1) -> T: ...
    def clear(self) -> None: ...
    def extend(self, iterable: Iterable[T]) -> None: ...
    # Interacts with: SeqBase for iteration/indexing, Array for immutable snapshot
    # Extension: use List for mutable collections, Array for immutable
```

## Impact
- API: adds `List<Any>` C++ class and Python `List` class; refactors Array to share `SeqBase`
- Behavioral: none for existing code
- Flags/config: none
- Data formats/schemas: adds `kTVMFFIList` type index
