# Add List<T> mutable sequence container with SeqBaseObj shared base, extending the container library alongside the existing immutable Array<T>

## TL;DR

- Introduces `List<T>` (`kTVMFFIList = 75`), a mutable contiguous sequence container with full C++ and Python (`tvm_ffi.List`) support, including push/pop/insert/erase/resize/slice/pickle.
- Extracts `SeqBaseObj` and `TVMFFISeqCell` (C ABI struct: `data`, `size`, `capacity`, `data_deleter`) as the shared base for both `ArrayObj` and `ListObj`, eliminating duplicated sequence logic; `ArrayObj` re-inherits `InplaceArrayBase` (inplace CoW allocation) alongside `SeqBaseObj`.
- Adds cycle detection (via `unordered_set<const void*>`) to JSON writer, serializer, structural-equal, and structural-hash for `List`, which unlike `Array` can form reference cycles.

## Key Exports

```python
# C ABI (include/tvm/ffi/c_api.h)
kTVMFFIList = 75       # New static type index; follows kTVMFFIOpaquePyObject=74

struct TVMFFISeqCell:
    """Shared ABI layout for ArrayObj and ListObj.
    Registered between [TVMFFISeqCell.begin] / [TVMFFISeqCell.end] markers in c_api.h.
    """
    data: void*                  # pointer to Any[] buffer
    size: int64_t                # number of live elements
    capacity: int64_t            # allocated slots
    data_deleter: Callable[[void*], None] | None
    # Invariant: if data_deleter is None, buffer lives in-object (ArrayObj inplace)
    # Invariant: if data_deleter is set, buffer is heap-allocated (ListObj)

# C++ (include/tvm/ffi/container/seq_base.h)
class SeqBaseObj(Object, TVMFFISeqCell):
    """Transparent base (no type index) for ArrayObj and ListObj.
    Follows same pattern as BytesObjBase — invisible to FFI type system.
    Provides: size(), capacity(), empty(), at(), operator[], front(), back(),
              begin(), end(), clear(), SetItem(), pop_back(),
              erase(idx), erase(first, last), insert(idx, item),
              insert(idx, first, last), Reverse(), resize(n)
    # Interacts with: ArrayObj (CoW), ListObj (heap-buffered), TypeTraits<Array<T>>, TypeTraits<List<T>>
    # Invariant: TVMFFISeqCell::size tracks live elements; destructor calls Any::~Any() on each
    """

class ListObj(SeqBaseObj):
    """Heap-buffered mutable sequence. type_index = kTVMFFIList = 75.
    _type_final = True  (no subclassing).
    # Interacts with: List<T> (ref wrapper), TypeTraits<List<T>>, SeqTypeTraitsBase
    # Invariant: data_deleter = RawDataDeleter (always non-null after construction)
    # Invariant: capacity doubles on growth (kIncFactor=2, kInitSize=4)
    # Warning: reference cycles possible — not collected by ref-counting alone
    """
    @staticmethod
    def CreateRepeated(n: int64_t, val: Any) -> ObjectPtr[ListObj]: ...
    @staticmethod
    def Empty(n: int64_t = 4) -> ObjectPtr[ListObj]: ...  # heap-allocates buffer

class List(ObjectRef):
    """Mutable contiguous sequence. Not thread-safe — requires external sync for concurrent access.
    # Interacts with: ListObj, TypeTraits<List<T>>, SeqTypeTraitsBase, container.cc FFI functions
    # Invariant: mutations happen in-place on the shared ListObj (no CoW unlike Array)
    # Extension: TypeTraits<List<T>> accepts both kTVMFFIList (primary) and kTVMFFIArray (other)
                 so std::vector<T> can be cast from either Array or List
    """
    value_type: ClassVar[type]  # T
    def push_back(self, item: T) -> None: ...
    def emplace_back(self, *args) -> None: ...
    def insert(self, position: iterator, val: T) -> None: ...
    def pop_back(self) -> None: ...
    def erase(self, position: iterator) -> None: ...
    def erase(self, first: iterator, last: iterator) -> None: ...
    def resize(self, n: int64_t) -> None: ...
    def reserve(self, n: int64_t) -> None: ...
    def clear(self) -> None: ...
    def Set(self, i: int64_t, value: T) -> None: ...
    def Assign(self, first: IterType, last: IterType) -> None: ...
    def GetListObj(self) -> ListObj*: ...

# CRTP traits base for both Array<T> and List<T> (include/tvm/ffi/container/seq_base.h)
class SeqTypeTraitsBase(ObjectRefTypeTraitsBase[SeqRef]):
    """
    Required in Derived:
      kPrimaryTypeIndex: int32_t   — canonical type index (kTVMFFIArray or kTVMFFIList)
      kOtherTypeIndex:  int32_t   — accepted alternate type (kTVMFFIList or kTVMFFIArray)
      kTypeName:        const char*
    # Interacts with: TypeTraits<Array<T>>, TypeTraits<List<T>>, TryCastFromAnyView
    # Key behavior: TryCastFromAnyView accepts kOtherTypeIndex by element-wise copy conversion
    """
    @staticmethod
    def CheckAnyStrict(src: TVMFFIAny*) -> bool: ...
    @staticmethod
    def TryCastFromAnyView(src: TVMFFIAny*) -> Optional[SeqRef]: ...

# Python (python/tvm_ffi/container.py)
@register_object("ffi.List")
class List(core.Object, MutableSequence[T]):
    """Mutable list container. Registered as ffi.List.
    # Interacts with: _ffi_api.List, _ffi_api.ListGetItem/SetItem/Append/Insert/Pop/Erase/...
    # Extension: slice assignment dispatches to ffi.ListReplaceSlice (copies replacement first
                 when self-aliased to guard against in-place corruption)
    """
    def __init__(self, input_list: Iterable[T] = ()) -> None: ...
    def __getitem__(self, idx: SupportsIndex | slice) -> T | list[T]: ...
    def __setitem__(self, index: SupportsIndex | slice, value) -> None: ...
    def __delitem__(self, index: SupportsIndex | slice) -> None: ...
    def insert(self, index: int, value: T) -> None: ...
    def append(self, value: T) -> None: ...
    def pop(self, index: int = -1) -> T: ...
    def extend(self, values: Iterable[T]) -> None: ...  # delegates to slice assignment
    def reverse(self) -> None: ...
    def clear(self) -> None: ...
    def __contains__(self, value) -> bool: ...
    def __repr__(self) -> str: ...       # "[elem, ...]"
    def __add__(self, other) -> List[T]: ...
    def __radd__(self, other) -> List[T]: ...

# STL bridge update (include/tvm/ffi/extra/stl.h)
# TypeTraits<std::vector<T>>::CheckAnyFast now accepts both kTVMFFIArray and kTVMFFIList:
def CheckAnyFast(src: TVMFFIAny*) -> bool:
    return src.type_index in (kTVMFFIArray, kTVMFFIList)
# TryCastFromAnyView reads via SeqBaseObj pointer — works for both Array and List

# Global FFI functions registered in container.cc:
# ffi.List(*items) -> List<Any>
# ffi.ListGetItem(n, i) -> Any
# ffi.ListSetItem(n, i, value) -> None
# ffi.ListSize(n) -> int64_t
```

## Impact

- API: New public C++ types `SeqBaseObj`, `ListObj`, `List<T>` and Python class `tvm_ffi.List`. Additive — no existing public API removed.
- Behavioral: `std::vector<T>` type-traits now accept `kTVMFFIList` in addition to `kTVMFFIArray` for `CheckAnyFast` and `TryCastFromAnyView`. Any caller passing an `Array` to a `std::vector<T>` parameter is unaffected; a `List` now also works.
- Flags/config: none
- Data formats/schemas: Serialization (`ToJSONGraph`/`FromJSONGraph`) now handles `kTVMFFIList` round-trip with type key `"ffi.List"`. JSON writer (`Stringify`) emits List as a JSON array with cycle detection. Deserialization added corresponding decode branch. Serialized graph format gains a new `"type": "ffi.List"` node kind.

## Design Elements

Design elements this commit consumes:
- `Array<T>` / `ArrayObj` object+ref pattern — extended to share `SeqBaseObj` base (0007-containers)
- `Object` / `ObjectRef` three-layer pattern — `ListObj` / `List<T>` follows it (0002-object-system)
- `Any` / `AnyView` — elements stored as `Any[]`; `SeqBaseObj` destructor calls `Any::~Any()` (0003-any-anyview)
- `TypeTraits<T>` customization point — `TypeTraits<List<T>>` implements full protocol (0008-type-traits)
- `GlobalDef().def(name, fn)` — all 13 `ffi.List*` functions registered in container.cc (0006-reflection)
- `StructEqualHandler` / `StructuralHashHandler` — extended with `CompareList`/`HashList` dispatch (0009-structural-eq-hash)
- `ObjectGraphSerializer` / `JSONWriter` — extended with List case + cycle detection (0010-json-serialization)
- `TVMFFIByteArray.end` comment marker pattern — used to delimit `TVMFFISeqCell` in c_api.h (0001-c-abi)

Design elements this commit produces:
- `TVMFFISeqCell` — new C ABI struct shared by `ArrayObj` and `ListObj` (extends 0001-c-abi)
- `SeqBaseObj` — new internal C++ base with full sequence mutation logic (extends 0007-containers)
- `SeqTypeTraitsBase<Derived, SeqRef, T>` — CRTP base for both `TypeTraits<Array<T>>` and `TypeTraits<List<T>>` (extends 0008-type-traits)
- `ListObj` / `List<T>` — new heap-buffered mutable sequence container (extends 0007-containers)
- `tvm_ffi.List` — Python `MutableSequence[T]` with full slice/pop/extend protocol (extends 0007-containers)

## Usage Examples

**C++ — creating and mutating a List:**
```cpp
// From tests/cpp/test_list.cc
ffi::List<Any> lst;
lst.push_back(1);
lst.push_back(2);
lst.push_back(3);
lst.insert(lst.begin() + 1, 9);   // [1, 9, 2, 3]
lst.erase(lst.begin() + 2);       // [1, 9, 3]
lst.Set(0, 42);                    // [42, 9, 3]
assert(lst.size() == 3);
```

**Python — cross-layer round-trip (C++ via ffi.List* global functions → Python List class):**
```python
# From tests/python/test_container.py
import tvm_ffi
lst = tvm_ffi.List([1, 2, 3])
lst.append(4)          # [1, 2, 3, 4]
lst.insert(2, 9)       # [1, 2, 9, 3, 4]
val = lst.pop()        # val=4, lst=[1, 2, 9, 3]
lst[2:4] = [10, 11]   # slice-assign via ListReplaceSlice
del lst[0]             # delete via ListErase
assert 2 in lst        # __contains__ via ListContains
```

**Cycle detection in serialization:**
```python
# List self-referential cycles are caught at serialization time
lst = tvm_ffi.List([1])
# (conceptually) lst.append(lst)  → would raise ValueError("Cycle detected")
```
