# Introduce List<T> as a mutable sequence container alongside Array<T>
## TL;DR
- Adds `List<T>` / `ListObj` as a mutable sequence container (`kTVMFFIList = 75`) alongside the existing immutable `Array<T>`. Mutations are in-place; no copy-on-write.
- Extracts `SeqBaseObj` (backed by new C ABI struct `TVMFFISeqCell`) as the shared base for both `ArrayObj` and `ListObj`, consolidating iteration, element access, and capacity management.
- `TypeTraits<std::vector<T>>` now accepts both `kTVMFFIArray` and `kTVMFFIList`, enabling transparent C++ interop. Cycle detection added to serialization, structural equal/hash, and JSON writer for `List` (which can form reference cycles). Python `List` class added as `@register_object("ffi.List")` implementing `MutableSequence[T]`.

## Key Exports

```python
# C ABI: new TVMFFISeqCell struct (c_api.h) — shared by ArrayObj and ListObj
# struct TVMFFISeqCell { void* data; int64_t size; int64_t capacity; void (*data_deleter)(void*); }
# Invariant: when data_deleter is nullptr, data is inplace (ArrayObj); when non-null, heap-allocated (ListObj)

class ListObj:
    """Mutable sequence node; heap-allocated buffer with dynamic resizing."""
    # type_index: kTVMFFIList = 75
    # Inherits: SeqBaseObj (which inherits Object + TVMFFISeqCell)
    # Invariant: NOT thread-safe; external sync required for concurrent access
    # Warning: reference cycles are possible (List containing itself); NOT gc'd by refcount alone

class List:
    """Mutable ref wrapper for ListObj. Unlike Array, mutations are in-place (no COW)."""
    def __init__(self, iterable: Iterable[T] = ...) -> None: ...
    def __getitem__(self, idx: int | slice) -> T | list[T]: ...
    def __setitem__(self, idx: int | slice, val: T | Iterable[T]) -> None: ...
    def __delitem__(self, idx: int | slice) -> None: ...
    def __len__(self) -> int: ...
    def append(self, val: T) -> None: ...
    def insert(self, idx: int, val: T) -> None: ...
    def pop(self, idx: int = -1) -> T: ...
    def extend(self, iterable: Iterable[T]) -> None: ...
    def clear(self) -> None: ...
    def reverse(self) -> None: ...
    # Interacts with: _ffi_api.List (constructor), _ffi_api.ListGetItem, ListSetItem, ListReplaceSlice
    # Interacts with: StructuralEqual, StructuralHash, json::Stringify (all with cycle detection)
    # Interacts with: TypeTraits<std::vector<T>> (accepts both kTVMFFIArray and kTVMFFIList)
    # Extension: array type index kTVMFFIList = 75

class SeqBaseObj:
    """Abstract base for ArrayObj and ListObj; holds TVMFFISeqCell data."""
    def size(self) -> int: ...
    def at(self, i: int) -> Any: ...
    def front(self) -> Any: ...
    def back(self) -> Any: ...
    def begin(self) -> Iterator[Any]: ...
    def end(self) -> Iterator[Any]: ...
    def clear(self) -> None: ...
    # Interacts with: ArrayObj (refactored to inherit), ListObj (new)
    # Invariant: bounds-checked at() raises IndexError on out-of-range

# Python: @register_object("ffi.List") class in python/tvm_ffi/container.py
# Implements MutableSequence[T]; delegates all mutation to _ffi_api.List* functions

# STL bridge: TypeTraits<std::vector<T>>::CheckAnyFast now accepts kTVMFFIArray OR kTVMFFIList
# TryCastFromAnyView unified through SeqBaseObj interface
```

## Impact
- API: `kTVMFFIList = 75` added to `TVMFFITypeIndex` enum in `c_api.h`. `TVMFFISeqCell` struct added to `c_api.h`. Both are ABI-additive.
- Behavioral: `TypeTraits<std::vector<T>>` now accepts `List` objects in addition to `Array` — passing a Python `tvm_ffi.List` where `std::vector<T>` is expected now works.
- Flags/config: none
- Data formats/schemas: JSON serialization now handles `List` (including cycle detection); `ToJSONGraph`/`FromJSONGraph` round-trips `List`.

## Usage Examples

End-to-end: C++ definition → Python use

```cpp
// C++: create and mutate a List
ffi::List<int64_t> lst;
lst.Append(1); lst.Append(2); lst.Append(3);
lst.Set(0, 10);
lst.PopBack();
// lst = [10, 2]
```

```python
# Python: List behaves like a Python list
import tvm_ffi
lst = tvm_ffi.List([1, 2, 3])
lst.append(4)
lst[0] = 10
del lst[1]
assert list(lst) == [10, 3, 4]
```
