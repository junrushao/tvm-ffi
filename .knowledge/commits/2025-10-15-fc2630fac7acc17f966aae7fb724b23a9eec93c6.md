# Replace free-function `reflection::init<T, Args...>` with struct-based `reflection::init<Args...>` used via `ObjectDef::def()`

## TL;DR
- Introduces `reflection::init<Args...>` as a struct template and a new `ObjectDef::def(init<Args...>())` method, aligning constructor registration with nanobind/pybind style.
- Removes the old free function `reflection::init<T, Args...>` that required the Class type as an explicit template parameter.
- Migrates all existing call sites from `.def_static("__ffi_init__", refl::init<T, Args...>)` to `.def(refl::init<Args...>())`.

## Key Exports

```python
# --- NEW: Struct template for constructor registration ---
class init(Generic[*Args]):
    """Helper struct used with ObjectDef.def() to register a constructor.
    The object type is automatically deduced from the ObjectDef<Class> context,
    eliminating the need to repeat the Class type.
    # Interacts with: ObjectDef.def(), make_object<Class>
    # Invariant: Args must match a constructor of the Class type
    """
    def __init__(self) -> None: ...

    # Private: called by ObjectDef.def()
    @staticmethod
    def execute(*args: Args) -> ObjectRef:
        """Constructs the object via make_object<Class>(args...)."""
        ...

# --- NEW: ObjectDef.def() overload for init<Args...> ---
class ObjectDef(ReflectionDefBase, Generic[Class]):
    # ... existing methods ...

    def def_(self, init_func: init[*Args], *extra) -> ObjectDef:
        """Register a constructor method (__ffi_init__) for this object type.
        # Interacts with: RegisterMethod, init<Args...>::execute<Class>
        # Invariant: registers as static method named INIT_METHOD_NAME ("__ffi_init__")
        """
        ...

    INIT_METHOD_NAME: str = "__ffi_init__"  # NEW: class-level constant

# --- REMOVED: Old free function ---
# OLD: def init(T, *args: Args) -> ObjectRef  # required Class type as first template param
# NEW: ObjectDef.def(init<Args...>())          # Class deduced from ObjectDef context
```

## Impact
- API: **Breaking** for C++ callers using `refl::init<T, Args...>` as a free function -- all must migrate to `.def(refl::init<Args...>())`. The registered method name (`__ffi_init__`) is unchanged, so Python callers are unaffected.
- Behavioral: None -- the constructed objects are identical.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

**New constructor registration pattern (C++):**
```cpp
class MyObj : public Object {
 public:
  int64_t x;
  int32_t y;
  MyObj(int64_t x, int32_t y) : x(x), y(y) {}
  TVM_FFI_DECLARE_OBJECT_INFO("example.MyObj", MyObj, Object);
};

TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  // NEW: Class type deduced from ObjectDef<MyObj>
  refl::ObjectDef<MyObj>()
      .def(refl::init<int64_t, int32_t>())  // registers __ffi_init__
      .def_ro("x", &MyObj::x)
      .def_ro("y", &MyObj::y);
  // OLD (removed):
  // .def_static("__ffi_init__", refl::init<MyObj, int64_t, int32_t>)
}
```

**Python-side usage (unchanged):**
```python
@register_object("example.MyObj")
class MyObj(tvm_ffi.Object):
    def __init__(self, x, y):
        self.__ffi_init__(x, y)
```
