# Replace refl::init<T,Args...> free function with refl::init<Args...> struct + ObjectDef::def() overload for nanobind/pybind-aligned constructor registration

## TL;DR
- Adds `refl::init<Args...>` as a template struct and a new `ObjectDef::def(init<Args...>)` overload that internally calls `RegisterMethod("__ffi_init__", /*is_static=*/true, &init<Args...>::execute<Class>, extra...)`.
- Removes the old `refl::init<T, Args...>` free function (which required explicitly naming the class type and was passed to `def_static("__ffi_init__", ...)`).
- Updates all call sites in tests, testing infra, and docs to the new form; aligns with nanobind/pybind constructor registration idiom.

## Key Exports

```python
# NEW: refl::init<Args...> — struct replacing the old init<T,Args...> free function
# File: include/tvm/ffi/reflection/registry.h

template init(Generic[*Args]):
    """Helper tag type passed to ObjectDef.def() to register a __ffi_init__ constructor.
    Class type is deduced from the enclosing ObjectDef<Class> context — not a parameter.
    Invariant: Class must be constructible with Args...
    Interacts with: ObjectDef.def(init<Args...>), make_object<Class>(args...)
    Extension: add default or keyword args as Extra when calling .def(init<...>(), "docstring")
    """
    # Private: only ObjectDef<Class> may call execute
    @staticmethod
    def execute(*args: Args) -> ObjectRef:  # template<typename Class>
        return ObjectRef(make_object[Class](*args))


# NEW: ObjectDef.def(init<Args...>) overload
# (alongside existing def(name, func) and def_static(name, func))
class ObjectDef(Generic[Class]):
    def def_(self, init_func: init[*Args], *extra) -> ObjectDef[Class]:
        """Register an __ffi_init__ static method from an init<Args...> tag.
        Equivalent to: .def_static(INIT_METHOD_NAME, &init<Args...>::execute<Class>, extra...)
        INIT_METHOD_NAME = "__ffi_init__"   # static constexpr in ObjectDef
        Interacts with: RegisterMethod, TypeInfo.__ffi_init__, c_class decorator (0017)
        Invariant: Class must be constructible from Args...
        """
        # Internally: RegisterMethod("__ffi_init__", is_static=True, ...)
        return self


# REMOVED: old free function form (no longer available)
# def init(T: type, *args: Args) -> ObjectRef:  # was refl::init<T,Args...>
#     Usage was: .def_static("__ffi_init__", refl::init<MyClass, int64_t, int32_t>)
#     Removed in this commit. New form: .def(refl::init<int64_t, int32_t>())


# Old → New calling convention mapping:
# OLD: refl::ObjectDef<TestIntPairObj>()
#          .def_static("__ffi_init__", refl::init<TestIntPairObj, int64_t, int64_t>)
# NEW: refl::ObjectDef<TestIntPairObj>()
#          .def(refl::init<int64_t, int64_t>())
```

## Impact
- API: Breaking — `refl::init<T, Args...>` (free function template) removed. All call sites must switch to `refl::ObjectDef<Class>().def(refl::init<Args...>())`. Impacted callers: `src/ffi/testing/testing.cc`, `tests/cpp/test_reflection.cc`; any downstream projects using the old `def_static("__ffi_init__", refl::init<...>)` pattern.
- Behavioral: None — the registered method name (`__ffi_init__`) and ABI are unchanged; Python and downstream callers are unaffected at runtime.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- `ObjectDef<Class>` builder and `RegisterMethod` dispatch — see `.knowledge/design-records/0006-reflection.md`
- `TVM_FFI_STATIC_INIT_BLOCK` pattern — see `.knowledge/design-records/0006-reflection.md`
- `make_object<T>` allocation primitive — see `.knowledge/design-records/0002-object-system.md`
- `__ffi_init__` convention and `c_class` Python bridge — see `.knowledge/design-records/0017-c-class-dataclasses.md`

Design elements this commit produces:
- `refl::init<Args...>` struct (replaces `refl::init<T,Args...>` free function) — new template tag; `ObjectDef` deduces `Class` from its own template parameter, eliminating the redundant first template argument.
- `ObjectDef::def(init<Args...>, extra...)` overload — new API point on `ObjectDef`; the string name `"__ffi_init__"` is now an `ObjectDef`-private constant (`INIT_METHOD_NAME`).

## Usage Examples

C++ side — before/after refactor showing the constructor registration change:

```cpp
// BEFORE (removed):
refl::ObjectDef<TestIntPairObj>()
    .def_static("__ffi_init__", refl::init<TestIntPairObj, int64_t, int64_t>)
    .def_ro("a", &TestIntPairObj::a, "Field `a`")
    .def_ro("b", &TestIntPairObj::b, "Field `b`");

// AFTER (this commit):
refl::ObjectDef<TestIntPairObj>()
    .def(refl::init<int64_t, int64_t>())
    .def_ro("a", &TestIntPairObj::a, "Field `a`")
    .def_ro("b", &TestIntPairObj::b, "Field `b`");

// With optional docstring (unchanged functionality):
refl::ObjectDef<TestUnregisteredBaseObject>()
    .def(refl::init<int64_t>(), "Constructor of TestUnregisteredBaseObject")
    .def_ro("v1", &TestUnregisteredBaseObject::v1)
    .def("get_v1_plus_one", &TestUnregisteredBaseObject::GetV1PlusOne, "...");
```

Python side — unchanged; `self.__ffi_init__(a, b)` still works (per docs update):

```python
class TestIntPair(tvm_ffi.Object):
    def __init__(self, a, b):
        # __ffi_init__ still resolves to the registered static method
        self.__ffi_init__(a, b)
```
