# Refactor `reflection::init` from free function to struct-based `ObjectDef::def(init<Args...>())` API

## TL;DR
- Replaces the old free-function `reflection::init<T, Args...>` with a new `reflection::init<Args...>` struct whose class type is deduced from the `ObjectDef<T>` context.
- Adds `ObjectDef::def(init<Args...>, Extra&&...)` overload that internally calls `RegisterMethod(INIT_METHOD_NAME, ...)` with the static `execute<Class>` method.
- Migrates all registration sites from `.def_static("__ffi_init__", refl::init<ObjType, arg_types...>)` to `.def(refl::init<arg_types...>())`, eliminating redundant type specification and aligning with the nanobind/pybind `py::init<>()` idiom.

| Old API | New API |
|---------|---------|
| `.def_static("__ffi_init__", refl::init<MyObj, int64_t, int32_t>)` | `.def(refl::init<int64_t, int32_t>())` |

## Key Exports

```python
# --- New: reflection::init<Args...> struct (replaces free function) ---
class init(Generic[*Args]):
    """Tag type passed to ObjectDef.def() to register __ffi_init__ constructor.
    Class type is deduced from ObjectDef<T> context — user specifies only arg types."""
    # Interacts with: ObjectDef.def() overload, make_object<Class>()
    # Invariant: Class must have a constructor accepting Args...
    # Extension: supports variadic Extra args (docstring, metadata) via ObjectDef.def()

    @staticmethod
    def execute(*args: Args) -> ObjectRef:
        """Private. Wraps make_object<Class>(args...) -> ObjectRef."""
        ...

# --- New: ObjectDef.def(init<Args...>) overload ---
class ObjectDef(ReflectionDefBase, Generic[Class]):
    INIT_METHOD_NAME: str = "__ffi_init__"  # static constexpr

    def def(self, init_func: init[*Args], *extra) -> ObjectDef:
        """Register a constructor for this object type.
        Calls RegisterMethod(INIT_METHOD_NAME, is_static=True, init::execute<Class>, extra...)."""
        # Interacts with: RegisterMethod, init<Args...>::execute<Class>
        # Invariant: registers as static method named "__ffi_init__"
        # Extension: extra args support docstrings and metadata traits
        ...

# --- Removed: reflection::init<T, Args...> free function ---
# Old: def init(T, *args: Args) -> ObjectRef: ...
# Was: function template with explicit T parameter
# Replaced by: init<Args...> struct with T deduced from ObjectDef context
```

## Impact
- API: The old `reflection::init<T, Args...>` free function is removed. All callers must migrate to `.def(refl::init<arg_types...>())`. This is a **source-breaking** change for any downstream code using the old pattern.
- Behavioral: None -- the registered `__ffi_init__` method produces identical behavior at runtime.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `ObjectDef<T>` builder and `RegisterMethod` internal API ([0007-ffi-reflection](../design-records/0007-ffi-reflection.md))
- `make_object<T>()` for heap object allocation ([0003-ffi-object-system](../design-records/0003-ffi-object-system.md))
- `__ffi_init__` naming convention for constructor methods ([0016-ffi-python-dataclasses](../design-records/0016-ffi-python-dataclasses.md))

Design elements this commit produces:
- **`reflection::init<Args...>` struct**: New tag type replacing the old free function. The class type parameter is deduced from `ObjectDef<T>`, eliminating redundancy. Private `execute<Class>` static method is friended by `ObjectDef`.
- **`ObjectDef::def(init<Args...>, Extra&&...)` overload**: New method that dispatches to `RegisterMethod(INIT_METHOD_NAME, true, ...)`. The `INIT_METHOD_NAME` constant (`"__ffi_init__"`) is now a private static constexpr in `ObjectDef`.
- **Mutated contract**: `reflection::init` changes from a free function template `init<T, Args...>(args...) -> ObjectRef` to a struct template `init<Args...>` that is only usable via `ObjectDef::def()`. This is a breaking API change.

## Usage Examples
**C++ registration (new pattern)**:
```cpp
// Before (old API — now removed):
refl::ObjectDef<TestIntPairObj>()
    .def_ro("a", &TestIntPairObj::a)
    .def_ro("b", &TestIntPairObj::b)
    .def_static("__ffi_init__", refl::init<TestIntPairObj, int64_t, int64_t>);

// After (new API):
refl::ObjectDef<TestIntPairObj>()
    .def(refl::init<int64_t, int64_t>())     // class type deduced from ObjectDef<TestIntPairObj>
    .def_ro("a", &TestIntPairObj::a)
    .def_ro("b", &TestIntPairObj::b);

// With docstring:
refl::ObjectDef<MyObj>()
    .def(refl::init<int64_t>(), "Constructor of MyObj")
    .def_ro("v1", &MyObj::v1);
```

**Python side (unchanged)**:
```python
class TestIntPair(tvm_ffi.Object):
    a: int
    b: int
    def __init__(self, a, b):
        self.__ffi_init__(a, b)  # calls the registered __ffi_init__ static method
```
