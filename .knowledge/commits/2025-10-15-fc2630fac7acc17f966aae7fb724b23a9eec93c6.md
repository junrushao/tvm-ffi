# Replace def_static("__ffi_init__") with nanobind-style def(init<Args...>()) API
## TL;DR
- Transforms `reflection::init` from a free function template `init<T, Args...>(Args&&...)` into a class template `init<Args...>` used as a tag argument to `ObjectDef::def()`, fully aligning the constructor registration API with nanobind/pybind11 style.
- Replaces the verbose `def_static("__ffi_init__", refl::init<ObjType, arg_types...>)` pattern with the shorter `def(refl::init<arg_types...>())`, where the object type is automatically deduced from the enclosing `ObjectDef<Class>` context.
- Updates all call sites (testing code, C++ tests, and documentation) to the new API; removes the old free-function `init<T, Args...>`.

## Key Exports

**Class template**: `tvm::ffi::reflection::init<Args...>` (replaces the old free function `init<T, Args...>`)
```cpp
template <typename... Args>
struct init {
  init();
 private:
  template <typename Class>
  static inline ObjectRef execute(Args&&... args);
};
```
- Declared in `include/tvm/ffi/reflection/registry.h`.
- `Args` are the constructor parameter types only; the object type `Class` is deduced from the `ObjectDef<Class>` context.
- The `execute` static method is private, accessible only to `ObjectDef` via a `friend` declaration.

**Method**: `ObjectDef<Class>::def(init<Args...>, Extra&&...)` (new overload)
```cpp
template <typename... Args, typename... Extra>
ObjectDef& def(init<Args...> init_func, Extra&&... extra);
```
- Registers a static method named `__ffi_init__` (via the private constant `INIT_METHOD_NAME`) that constructs an instance of `Class` with the given argument types.
- The method name `__ffi_init__` is hardcoded as a `static constexpr const char*` member of `ObjectDef`.
- Supports optional `Extra` args (e.g., docstrings) forwarded to `RegisterMethod`.

**Removed**: `tvm::ffi::reflection::init<T, Args...>(Args&&...)` free function template (the v17 API from c01dadf).

## Impact
- API: Medium. All existing `def_static("__ffi_init__", refl::init<ObjType, arg_types...>)` call sites must migrate to `def(refl::init<arg_types...>())`. The old free-function signature is removed, so any downstream code using it will fail to compile. The registered method name (`__ffi_init__`) and the runtime behavior are unchanged.
- ABI: None. The registered method name is still `__ffi_init__`; Python-side calling convention is unchanged.
- Behavioral: None. The constructor delegation still uses `make_object<Class>(std::forward<Args>(args)...)` internally.
- Flags/config: The `tests/cpp/CMakeLists.txt` change removes `EXCLUDE_FROM_ALL` from the `tvm_ffi_tests` target, making it build by default (minor build config change).
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`.knowledge/designs/reflection.md`): The `ObjectDef<Class>` builder, `RegisterMethod`, `def_static`, and the `__ffi_init__` convention established by c01dadf.
- **Object system** (`.knowledge/designs/object-system.md`): `make_object<T>()` for object allocation, `ObjectRef` as the return wrapper.
- **c_class decorator** (`.knowledge/designs/0019-c-class-decorator.md`): Python-side consumption of `__ffi_init__` is unchanged; the decorator continues to work because the registered method name remains `__ffi_init__`.

Design elements this commit produces:
- **`init<Args...>` class template**: A tag-type that captures constructor argument types and defers the object type to the enclosing `ObjectDef<Class>`. This eliminates the redundant `ObjType` template parameter from the old free-function API.
- **`ObjectDef::def(init<Args...>)` overload**: A dedicated method for constructor registration that enforces the `__ffi_init__` naming convention at compile time, preventing typos in the method name string.
- **`INIT_METHOD_NAME` private constant**: Centralizes the `"__ffi_init__"` string as `ObjectDef::INIT_METHOD_NAME`, ensuring consistency.

## Usage Examples

**Before (old API, removed in this commit)**:
```cpp
refl::ObjectDef<TestCxxClassBase>()
    .def_static("__ffi_init__", refl::init<TestCxxClassBase, int64_t, int32_t>)
    .def_rw("v_i64", &TestCxxClassBase::v_i64)
    .def_rw("v_i32", &TestCxxClassBase::v_i32);
```

**After (new API)**:
```cpp
refl::ObjectDef<TestCxxClassBase>()
    .def(refl::init<int64_t, int32_t>())
    .def_rw("v_i64", &TestCxxClassBase::v_i64)
    .def_rw("v_i32", &TestCxxClassBase::v_i32);
```

**With docstring**:
```cpp
refl::ObjectDef<TestUnregisteredBaseObject>()
    .def(refl::init<int64_t>(), "Constructor of TestUnregisteredBaseObject")
    .def_ro("v1", &TestUnregisteredBaseObject::v1);
```

**Python side (unchanged)**:
```python
@c_class("testing.TestCxxClassBase")
class TestCxxClassBase:
    v_i64: int
    v_i32: int = 0

obj = TestCxxClassBase(v_i64=42)  # dispatches through __ffi_init__
```
