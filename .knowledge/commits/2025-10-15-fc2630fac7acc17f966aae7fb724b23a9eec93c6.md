# Replace free-function refl::init with ObjectDef::def(init<Args...>()) for constructor registration

## TL;DR
- Introduces `refl::init<Args...>` as a **tag struct** (not a free function) and a new `ObjectDef::def(init<Args...>(), ...)` overload that registers `__ffi_init__` as a static method, fully aligning the constructor registration API with nanobind/pybind style.
- Removes the old free-function `refl::init<T, Args...>(args...)` that required explicit object type and was used via `def_static("__ffi_init__", refl::init<T, ...>)`.
- Updates all call sites (testing, reflection tests, docs) from `def_static("__ffi_init__", refl::init<T, ...>)` to `.def(refl::init<...>())`.
- Minor doc fixes: indentation correction for `TVM_FFI_DECLARE_OBJECT_INFO_FINAL` in cpp_guide.md and python_guide.md.

## Key Exports

```python
class init(Generic[*Args]):
    """Tag type for registering a constructor on ObjectDef.
    Instantiated as init<int64_t, int32_t>() etc.
    The object type T is NOT a template parameter -- it is deduced from ObjectDef<T>."""
    # Invariant: Args must match an existing constructor of the target Class
    # Interacts with: ObjectDef.def() overload, ffi::make_object<Class>(args...)

    # Private:
    @staticmethod
    def execute(*args: Args) -> ObjectRef:  # templated on Class (friend of ObjectDef)
        """Constructs ObjectRef(make_object<Class>(args...))."""
        # Interacts with: ffi::make_object<Class>, ObjectRef constructor

# === New: ObjectDef.def(init<Args...>) overload ===

class ObjectDef(ReflectionDefBase, Generic[Class]):
    INIT_METHOD_NAME: ClassVar[str] = "__ffi_init__"  # private constexpr

    def def(self, init_func: init[*Args], *extra: Union[str, InfoTrait]) -> ObjectDef:
        """Register __ffi_init__ as a static method that constructs Class from Args.
        Equivalent to: self.def_static("__ffi_init__", init<Args...>::execute<Class>, *extra)"""
        # Interacts with: RegisterMethod(INIT_METHOD_NAME, is_static=True, ...)
        # Invariant: only one __ffi_init__ per type (last registration wins)
        # Extension: pass Metadata or docstring as extra args
        ...

# === Removed: free-function refl::init<T, Args...> ===
# Old signature: def init(T: type, *args: Args) -> ObjectRef
# Old usage: .def_static("__ffi_init__", refl::init<TestObjA, int64_t, int64_t>)
# New usage: .def(refl::init<int64_t, int64_t>())
```

## Impact
- API: **Breaking** for any external C++ code using the old `refl::init<T, Args...>` free function or `def_static("__ffi_init__", refl::init<T, ...>)` pattern. Must migrate to `.def(refl::init<Args...>())`. The type parameter `T` is no longer needed (deduced from `ObjectDef<T>`).
- Behavioral: None -- the resulting `__ffi_init__` static method is identical in behavior. The Python side continues to call `__ffi_init__` the same way.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **ObjectDef builder** ([.knowledge/designs/0008-reflection.md](../designs/0008-reflection.md)): Extends the builder with a new `def()` overload.
- **RegisterMethod** (internal to ObjectDef): Reused to register the init as a static method with the `INIT_METHOD_NAME` constant.
- **ffi::make_object\<T\>** ([.knowledge/designs/0002-object-system.md](../designs/0002-object-system.md)): Used inside `init<Args...>::execute<Class>`.
- **`__ffi_init__` naming convention** ([.knowledge/designs/0008-reflection.md](../designs/0008-reflection.md)): The standard static method name for FFI constructors, now encapsulated as `INIT_METHOD_NAME`.

Design elements this commit produces:
- **`refl::init<Args...>` tag struct**: New nanobind/pybind-aligned tag type that deduces the object type from the enclosing `ObjectDef<T>` context.
- **`ObjectDef::def(init<Args...>, Extra...)` overload**: New method on ObjectDef that registers `__ffi_init__` using the tag struct, hiding the method name and static flag.
- **`ObjectDef::INIT_METHOD_NAME` constant**: Private `static constexpr` holding `"__ffi_init__"`, centralizing the magic string.

## Usage Examples

**C++ constructor registration (new pattern)**:
```cpp
// Before (old free-function style):
refl::ObjectDef<TestIntPairObj>()
    .def_ro("a", &TestIntPairObj::a)
    .def_ro("b", &TestIntPairObj::b)
    .def_static("__ffi_init__", refl::init<TestIntPairObj, int64_t, int64_t>);

// After (new nanobind/pybind-aligned style):
refl::ObjectDef<TestIntPairObj>()
    .def(refl::init<int64_t, int64_t>())
    .def_ro("a", &TestIntPairObj::a)
    .def_ro("b", &TestIntPairObj::b);
```

**Python side (unchanged)**:
```python
class TestIntPair(tvm_ffi.Object):
    def __init__(self, a, b):
        self.__ffi_init__(a, b)
```
