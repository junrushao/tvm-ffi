# Add def(init<Args...>()) syntax for object initializers in reflection
## TL;DR
- Introduces `def(init<Args...>())` method on `ObjectDef<T>` for defining object constructors, replacing `def_static("__ffi_init__", ...)` convention.
- Aligns with nanobind/pybind11 API style for constructor registration.

## Impact
- API: New `init<Args...>` type and `ObjectDef<T>::def(init<...>())` overload. Old `def_static("__ffi_init__", ...)` still works but is superseded.
- Flags/config: None.
- Data formats/schemas: None.
