# Replace refl::init<T, Args...> free function with init<Args...> struct and ObjectDef::def(init<...>) method
## TL;DR
- Introduced `refl::init<Args...>` as a struct (not a free function). The object type `T` is automatically deduced from the `ObjectDef<Class>` context, eliminating redundant type specification.
- Added `ObjectDef::def(init<Args...>, Extra...)` method that registers `__ffi_init__` automatically, replacing the verbose `def_static("__ffi_init__", refl::init<T, Args...>)` pattern.
- Removed the old `template <typename T, typename... Args> ObjectRef init(Args&&...)` free function.
- Migrated all call sites in testing and test code to the new pattern.

## Key Exports

**`init<Args...>`** (struct template -- `include/tvm/ffi/reflection/registry.h`):

```cpp
template <typename... Args>
struct init {
  init();  // default constructor
private:
  template <typename Class>
  static inline ObjectRef execute(Args&&... args);  // calls make_object<Class>
};
```

The class type is deduced from `ObjectDef<Class>` context via a friend relationship.

**`ObjectDef<Class>::def(init<Args...>, Extra...)`** (method -- same header):

```cpp
template <typename... Args, typename... Extra>
ObjectDef& def(init<Args...> init_func, Extra&&... extra);
```

Registers `__ffi_init__` as a static method via `RegisterMethod(INIT_METHOD_NAME, true, ...)`.

**`ObjectDef::INIT_METHOD_NAME`** (constant): `"__ffi_init__"` -- centralizes the init method name string.

**Removed**: `template <typename T, typename... Args> ObjectRef init(Args&&...)` free function.

## Impact
- API: **Breaking** -- `refl::init<T, Args...>` free function removed. All C++ code using `def_static("__ffi_init__", refl::init<SomeClass, Args...>)` must migrate to `.def(refl::init<Args...>())`.
- Behavioral: none (same runtime semantics)
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Reflection system** ([0009-reflection.md](../designs/0009-reflection.md)): `ObjectDef<T>`, `RegisterMethod`, `ReflectionDefBase`
- **Object system** ([0003-object-system.md](../designs/0003-object-system.md)): `make_object<T>`, `ObjectRef`

Design elements this commit produces/mutates:
- **`init<Args...>` struct** -- replaces the `init<T, Args...>` free function. Aligns with nanobind/pybind `py::init<Args...>()` pattern where the class type is deduced from context.
- **`ObjectDef::def(init<...>)` method** -- dedicated constructor registration method, more idiomatic than `def_static` with a magic string.

## Usage Examples

```cpp
// Before (removed pattern):
refl::ObjectDef<TestCxxClassBase>()
    .def_static("__ffi_init__", refl::init<TestCxxClassBase, int64_t, int32_t>)
    .def_rw("v_i64", &TestCxxClassBase::v_i64);

// After (new pattern):
refl::ObjectDef<TestCxxClassBase>()
    .def(refl::init<int64_t, int32_t>())
    .def_rw("v_i64", &TestCxxClassBase::v_i64);
```
