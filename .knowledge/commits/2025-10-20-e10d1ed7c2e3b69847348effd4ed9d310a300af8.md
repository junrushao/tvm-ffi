# Migrate .pyi docstrings into Cython sources so Sphinx autodoc can discover them
## TL;DR
- Moved all class/method/function docstrings from `core.pyi` into the corresponding Cython `.pxi` source files, because Sphinx autodoc does not inspect `.pyi` files.
- Added Python type annotations to Cython function signatures across all `.pxi` files, with `annotation_typing=False` in `core.pyx` to prevent Cython from treating them as Cython type declarations.
- Updated Sphinx `docs/conf.py` to force-show selected dunder methods (`__dlpack__`, `__from_extern_c__`, etc.) and exposed `tvm_ffi.cpp` in `__init__.py`.

## Key Exports
The commit does not introduce new public APIs. It moves docstrings and adds type annotations to existing Cython-defined APIs. The `tvm_ffi.cpp` module is newly exported from `__init__.py`.

```python
# tvm_ffi/__init__.py — newly exported module
from . import cpp  # load_inline module now accessible as tvm_ffi.cpp

# Cython convention change: annotations now appear in .pxi sources
# Example from device.pxi:
class Device:
    def __init__(self, device_type: str | int, index: Optional[int] = None) -> None: ...
    # Docstrings now live here in Cython, not in .pyi

# core.pyi now contains only bare stubs:
class Device:
    def __init__(self, device_type: str | int, index: int | None = None) -> None: ...
    # No docstrings — Sphinx reads Cython source instead
```

## Impact
- API: `tvm_ffi.cpp` is now importable directly (was previously only accessible via `tvm_ffi.cpp.load_inline`). No signature changes.
- Behavioral: none — runtime behavior is identical.
- Flags/config: `# cython: annotation_typing=False` added to `core.pyx` to prevent Cython from interpreting Python-style annotations as Cython type constraints.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- [0012-python-bindings](../design-records/0012-python-bindings.md): Cython `.pxi` include file structure, `.pyi` stub conventions, `tvm_ffi.__init__` module layout.

Design elements this commit produces:
- **Docstring location convention**: Docstrings live in Cython `.pxi` source files (not `.pyi` stubs). `.pyi` files contain only bare type signatures with `...` bodies. This enables Sphinx autodoc to discover documentation from the compiled Cython extension.
- **Cython annotation_typing=False pattern**: `# cython: annotation_typing=False` directive in `core.pyx` allows Python-style type annotations (e.g., `str | int`, `-> None`) without Cython interpreting them as Cython-level type declarations.
- **Sphinx dunder-method inclusion**: `_autodoc_always_show` set in `docs/conf.py` ensures selected protocol dunders appear in generated API docs.
