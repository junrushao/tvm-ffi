# Migrate .pyi docstrings into Cython sources for Sphinx autodoc compatibility
## TL;DR
- Moves all docstrings from `python/tvm_ffi/core.pyi` into the corresponding Cython `.pxi` source files, because Sphinx autodoc does not read `.pyi` files when generating API reference documentation.
- Adds type annotations to Cython method signatures (e.g., `-> str`, `-> bool`, `-> int`) and `from typing import ...` imports across all `.pxi` files.
- Configures Sphinx (`docs/conf.py`) to avoid skipping selected dunder methods (`__dlpack__`, `__dlpack_device__`, etc.) and reorders the Python API reference listing.
- Adds `# cython: annotation_typing=False` to `core.pyx` so Cython treats annotation syntax as documentation rather than Cython type declarations.
- Exports the `tvm_ffi.cpp` submodule (adds `from . import cpp` and `"cpp"` to `__all__`).

## Key Exports

**Sphinx configuration**:
- `_never_skip_selected_dunders(app, what, name, obj, skip, options)` -- autodoc event handler in `docs/conf.py` that prevents Sphinx from hiding selected dunder methods.
- `_autodoc_always_show` -- set of dunder names that should always appear in generated docs: `__dlpack__`, `__dlpack_device__`, `__device_type_name__`, `__from_extern_c__`, `__from_mlir_packed_safe_call__`.

**Module re-export**:
- `tvm_ffi.cpp` is now importable from `tvm_ffi.__init__` (was previously not exported).

**Type annotations added to Cython signatures** (selected examples):
- `Device.__init__(self, device_type: str | int, index: Optional[int] = None) -> None`
- `DataType.type_code -> int`, `.bits -> int`, `.lanes -> int`, `.itemsize -> int`
- `Tensor.shape -> tuple[int, ...]`, `.strides -> tuple[int, ...]`, `.dtype -> Any`, `.device -> Device`
- `Function.__call__(self, *args: Any) -> Any`
- `Error.__init__(self, kind: str, message: str, backtrace: str)`
- `TypeSchema.repr(self, ty_map: Optional[Callable[[str], str]] = None) -> str`

These are documentation/IDE annotations, not behavioral changes; the Cython compiler with `annotation_typing=False` treats them as inert.

## Impact
- API: No behavioral API changes. `tvm_ffi.cpp` is newly exported from `__init__` but the module already existed.
- ABI: None. No C ABI or struct changes.
- Behavioral: None. The docstrings and type annotations are documentation-only. The `annotation_typing=False` directive ensures Cython does not interpret annotations as Cython type constraints.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- Cython `.pxi` include-file architecture for single-module compilation ([`.knowledge/designs/0014-python-bindings.md`](.knowledge/designs/0014-python-bindings.md), section "Cython Include Files (.pxi)")
- `core.pyi` hand-written type stub pattern ([`.knowledge/designs/0014-python-bindings.md`](.knowledge/designs/0014-python-bindings.md), section "Cython Type Stubs (since 785e8ca)")
- Sphinx autodoc configuration ([`docs/conf.py`])

Design elements this commit produces:
- **Cython-embedded docstrings pattern**: Docstrings now live directly in `.pxi` source files rather than in `core.pyi`, making them visible to Sphinx autodoc. The `.pyi` file retains only bare signatures (no docstrings) for IDE type-checking.
- **`annotation_typing=False` directive**: Cython's `core.pyx` uses this directive to allow Python-style type annotations (e.g., `-> str`) without Cython interpreting them as Cython type declarations. This enables annotations to serve as both IDE hints (via `.pyi`) and documentation (via Sphinx reading Cython sources).
- **autodoc dunder allowlist**: `_autodoc_always_show` set in `docs/conf.py` controls which `__dunder__` methods Sphinx will document despite its default skip behavior.

## Usage Examples
None -- this is a documentation migration commit. The functional API is unchanged.

The key pattern introduced is adding type annotations to Cython `cdef class` methods:

```python
# In a .pxi file (Cython include), with annotation_typing=False in the parent .pyx:
cdef class Device:
    def __init__(self, device_type: str | int, index: Optional[int] = None) -> None:
        """A device descriptor used by TVM FFI and DLPack.
        ...
        """
        # implementation unchanged
```
