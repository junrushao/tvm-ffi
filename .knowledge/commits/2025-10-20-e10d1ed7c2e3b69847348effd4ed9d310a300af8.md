# Migrate .pyi docstrings into Cython and expose tvm_ffi.cpp submodule

## TL;DR
- Docstrings from `core.pyi` moved into Cython source (`core.pyx`); stub file stripped to minimal type annotations; `# cython: annotation_typing=False` added to prevent Cython from interpreting type annotations as C types.
- New `tvm_ffi.cpp` submodule exposed in `__init__.py` and `__all__`.
- Sphinx `_filter_inherited_members` / `_link_inherited_members` hooks replaced the simpler `_never_skip_selected_dunders` hook; `__ffi_init__` added to `_autodoc_always_show`.

## Key Exports

```python
# In docs/conf.py

def _never_skip_selected_dunders(app, what, name, obj, skip, options):
    # OLD: only whitelisted dunder names

def _filter_inherited_members(app, what, name, obj, skip, options):
    # NEW: also hides built-in method wrappers and members from _py_native_classes
    # Interacts with: _autodoc_always_show, _py_native_classes
    ...

# In python/tvm_ffi/__init__.py
from . import cpp   # new submodule export
```

## Impact
- API: `tvm_ffi.cpp` is now importable as a top-level submodule.
- Behavioral: Sphinx autodoc behavior changed: built-in methods (e.g., `str.maketrans`) and members inherited from native Python types are now hidden in the docs.
- Flags/config: `# cython: annotation_typing=False` in `core.pyx` prevents Cython from treating Python type annotations as C types.
- Data formats/schemas: none
