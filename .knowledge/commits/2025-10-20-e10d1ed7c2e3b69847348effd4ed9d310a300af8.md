# Migrate .pyi docstrings into Cython source for Sphinx autodoc

## TL;DR
- Moves all class/method/function docstrings from `core.pyi` into the corresponding Cython `.pxi` files so Sphinx autodoc can discover them (autodoc does not inspect `.pyi` files).
- Adds inline Python type annotations to Cython function/method signatures and property return types across all `.pxi` files, making the Cython source the single source of truth for both documentation and type information.
- Strips `core.pyi` down to bare signatures (docstrings removed, ~480 lines deleted), adds `# cython: annotation_typing=False` to `core.pyx` so Cython treats the new annotations as documentation rather than Cython type declarations, and configures Sphinx to always render selected dunder methods (`__dlpack__`, `__dlpack_device__`, etc.).

## Key Exports
None. No new public API is introduced. The change is purely documentation and annotation migration.

## Impact
- API: None -- no runtime behavior change.
- Behavioral: None.
- Flags/config: `# cython: annotation_typing=False` added to `core.pyx`. This tells Cython to ignore Python-style type annotations in `.pxi` files rather than interpreting them as Cython type constraints. Without this, annotations like `-> str` could cause Cython compilation errors or behavioral changes.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Cython binding layer** (`python/tvm_ffi/cython/*.pxi`) -- all 8 `.pxi` files are updated with docstrings and annotations. See `.knowledge/designs/0014-python-package.md`.
- **Cython type stub convention** (`core.pyi`) -- the stub file is stripped of docstrings, shifting the documentation authority to Cython source. See `.knowledge/designs/0014-python-package.md` (invariant: "Cython type stub convention").
- **Sphinx autodoc** (`docs/conf.py`) -- `autodoc-skip-member` hook added to always show selected dunders.

Design elements this commit produces:
- **`annotation_typing=False` Cython directive convention**: Establishes the pattern of adding Python type annotations to Cython `.pxi` files for documentation purposes while preventing Cython from interpreting them as type constraints.
- **`_autodoc_always_show` set** in `docs/conf.py`: Controls which dunder methods are never skipped by Sphinx autodoc (`__dlpack__`, `__dlpack_device__`, `__device_type_name__`, `__from_extern_c__`, `__from_mlir_packed_safe_call__`).
- **`tvm_ffi.cpp` submodule export**: `from . import cpp` and `"cpp"` entry added to `__init__.py` and `__all__`.
