# Add Function.__from_mlir_packed_safe_call__ for MLIR JIT integration
## TL;DR
- Adds `Function.__from_mlir_packed_safe_call__(mlir_packed_symbol, *, keep_alive_object=None)` static method to create an FFI Function from an MLIR packed safe call function pointer.
- Introduces `TVMFFIPyMLIRPackedSafeCall` C++ adapter class in `tvm_ffi_python_helpers.h` that translates between the MLIR packed calling convention (`void(void**)`) and the FFI safe call convention (`int(void*, TVMFFIAny*, int32_t, TVMFFIAny*)`).
- Makes `keep_alive_object` keyword-only on the existing `__from_extern_c__` method (minor breaking API change).

## Key Exports

**Types/Classes**:
- `TVMFFIPyMLIRPackedSafeCall` (C++ class in `tvm_ffi_python_helpers.h`): Adapter that wraps an MLIR packed safe call function pointer. Holds a `void(*)(void**)` function pointer and an optional `PyObject*` kept alive via ref-counting. Static methods: `Invoke(void*, const TVMFFIAny*, int32_t, TVMFFIAny*) -> int`, `Deleter(void*)`.

**Functions**:
- `Function.__from_mlir_packed_safe_call__(mlir_packed_symbol: int, *, keep_alive_object: Any | None = None) -> Function` (Python static method): Creates an FFI Function from an MLIR packed safe call function pointer. The pointer must follow the MLIR packed convention: `void(void** packed_args)` where `packed_args` is `[&handle, &args, &num_args, &rv, &ret_code]`.
- `TVMFFIPyMLIRPackedSafeCallCreate(void(*)(void**), PyObject*) -> void*` (C helper): Allocates adapter object.
- `TVMFFIPyMLIRPackedSafeCallInvoke(void*, const TVMFFIAny*, int32_t, TVMFFIAny*) -> int` (C helper): Invokes the adapter.
- `TVMFFIPyMLIRPackedSafeCallDeleter(void*)` (C helper): Frees the adapter.
- `testing.get_mlir_add_one_c_symbol() -> int` (registered global function): Returns the address of a test MLIR packed function for testing.

**Signature change**:
- `Function.__from_extern_c__(c_symbol: int, *, keep_alive_object=None)`: `keep_alive_object` changed from positional to keyword-only (added `*` separator).

## Impact
- API: New static method `Function.__from_mlir_packed_safe_call__` added. The existing `__from_extern_c__` has `keep_alive_object` changed to keyword-only, which breaks callers passing it positionally.
- ABI: None. No changes to C ABI structs or existing calling conventions.
- Behavioral: None. Existing functions unchanged.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

Creating an FFI Function from an MLIR execution engine's JIT-compiled function:
```python
import tvm_ffi

# Suppose `execution_engine` is an MLIR ExecutionEngine that JIT-compiled a function
# and `symbol_addr` is the integer address of the MLIR packed function pointer.
symbol_addr = execution_engine.lookup("my_function")

# Create an FFI function, keeping the execution engine alive
f = tvm_ffi.Function.__from_mlir_packed_safe_call__(
    symbol_addr,
    keep_alive_object=execution_engine,
)

# Call the function through the standard FFI calling convention
result = f(1)  # Packs args as TVMFFIAny, invokes via MLIR packed convention
```

The MLIR packed convention adapter unpacks `void** packed_args` as:
```
packed_args[0] = &handle       (void*)
packed_args[1] = &args         (const TVMFFIAny*)
packed_args[2] = &num_args     (int32_t)
packed_args[3] = &rv           (TVMFFIAny*)
packed_args[4] = &ret_code     (int)
```
