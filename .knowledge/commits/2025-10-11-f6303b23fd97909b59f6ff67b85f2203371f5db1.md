# Add Function.__from_mlir_packed_safe_call__() factory and make keep_alive_object keyword-only in __from_extern_c__

## TL;DR
- Adds `Function.__from_mlir_packed_safe_call__(mlir_packed_symbol, *, keep_alive_object)` as a new Python factory method for wrapping MLIR execution-engine JIT functions into `tvm_ffi.Function` objects.
- Implements `TVMFFIPyMLIRPackedSafeCall` C++ helper class in `tvm_ffi_python_helpers.h` that bridges the MLIR `void(void**)` packed calling convention to the TVM FFI `safe_call` ABI.
- Makes the `keep_alive_object` parameter keyword-only in `__from_extern_c__` (minor breaking change for positional callers), and adds `_mlir_add_one_c_symbol` test fixture in `testing.cc`.

## Impact
- API: `__from_extern_c__` `keep_alive_object` is now keyword-only (`*` separator added). Any existing callers passing it positionally (e.g., `Function.__from_extern_c__(sym, engine)`) will get a `TypeError`. The test in `test_function.py` was updated to use `keep_alive_object=keep_alive`.
- Behavioral: New `Function.__from_mlir_packed_safe_call__()` factory wraps MLIR `void(void**)` packed functions as `tvm_ffi.Function` objects, enabling MLIR JIT interop without access to raw extern-C pointers.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **0004-function-system**: `TVMFFIFunctionCreate` (the three-slot constructor: `safe_call`, `invoke`, `deleter`) is used to register the MLIR adapter. `FunctionObj` calling convention is consumed unchanged.
- **0013-python-package**: Cython `function.pxi` pattern for static factory methods; `TVMFFIPyObjectDeleter` pattern from `base.pxi` for memory management.
- **0016-py-ffi-call-dispatch**: `TVMFFIAny` args/rv layout, `TVMFFIPyCallContext` (not directly used here, but the ABI it defines is what MLIR packed args must match).

Design elements this commit produces:
- **TVMFFIPyMLIRPackedSafeCall** — new adapter class in `tvm_ffi_python_helpers.h` that translates the MLIR `void(void**)` ABI to TVM FFI `safe_call`. Not yet in any design record; see Reflection.
- **`Function.__from_mlir_packed_safe_call__`** — new Python-layer factory method extending `Function`'s construction protocol. Extends 0004-function-system / 0013-python-package.

## Usage Examples

End-to-end trace (MLIR execution engine → Python `tvm_ffi.Function`):

```python
import ctypes
import tvm_ffi

# 1. MLIR execution engine exposes a packed-safe-call symbol address
#    (the symbol has C type: void(*)(void**))
mlir_sym_addr = engine.lookup_packed("my_kernel")  # returns int (pointer as integer)

# 2. Wrap into tvm_ffi.Function, keeping the engine alive
f = tvm_ffi.Function.__from_mlir_packed_safe_call__(
    mlir_sym_addr,
    keep_alive_object=engine,  # prevents engine GC while f is alive
)

# 3. Call as a normal packed function
result = f(arg0, arg1)

# 4. When f is deleted, TVMFFIPyMLIRPackedSafeCallDeleter runs,
#    which decrements engine's refcount.
```

Before/after for `__from_extern_c__` callers:

```python
# BEFORE (positional — now raises TypeError):
fadd = tvm_ffi.Function.__from_extern_c__(sym, engine)

# AFTER (keyword-only):
fadd = tvm_ffi.Function.__from_extern_c__(sym, keep_alive_object=engine)
```
