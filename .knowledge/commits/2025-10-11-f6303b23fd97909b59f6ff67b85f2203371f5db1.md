# Add Function.__from_mlir_packed_safe_call__ for MLIR execution engine JIT interop
## TL;DR
- Adds `Function.__from_mlir_packed_safe_call__` static method to construct an FFI `Function` from an MLIR packed safe call function pointer (`void(*)(void**)`), enabling DSLs that use the MLIR execution engine for JIT compilation to expose their generated functions as FFI `Function` objects.
- Introduces `TVMFFIPyMLIRPackedSafeCall` C++ helper class in `tvm_ffi_python_helpers.h` that adapts the MLIR packed calling convention to the FFI's `TVMFFISafeCallType` convention, managing lifetime of a `keep_alive_object` (typically the execution engine).
- **Minor breaking change**: `Function.__from_extern_c__` now takes `keep_alive_object` as keyword-only (added `*` separator).

## Key Exports

```python
# === New: MLIR packed safe call adapter (tvm_ffi_python_helpers.h) ===

class TVMFFIPyMLIRPackedSafeCall:
    """Adapts MLIR packed calling convention void(*)(void**) to FFI safe_call convention."""
    mlir_packed_safe_call_: Callable[[Ptr[Ptr[void]]], None]  # void(*)(void**)
    keep_alive_object_: Optional[PyObject]  # Py_IncRef'd; typically the MLIR execution engine

    def __init__(self, mlir_packed_safe_call: Callable, keep_alive_object: Optional[PyObject]) -> None:
        # Py_IncRef(keep_alive_object) if not NULL
        ...

    def __del__(self) -> None:
        # Py_DecRef(keep_alive_object) if not NULL
        ...

    @staticmethod
    def Invoke(func: void_ptr, args: Ptr[TVMFFIAny], num_args: int32, rv: Ptr[TVMFFIAny]) -> int:
        """Redirect: packs args into void*[] per MLIR convention, calls mlir_packed_safe_call_."""
        # void* handle = nullptr
        # void* mlir_args[] = {&handle, &args, &num_args, &rv, &ret_code}
        # (*self->mlir_packed_safe_call_)(mlir_args)
        # return ret_code
        # Interacts with: TVMFFIFunctionCreate (registered as the invoke callback)
        # Invariant: mlir_args layout is [handle, args_ptr, num_args_ptr, rv_ptr, ret_code_ptr]
        # Invariant: ret_code is set by the MLIR-generated function (0=success, nonzero=error)
        ...

    @staticmethod
    def Deleter(self: void_ptr) -> None:
        # delete self
        # Interacts with: TVMFFIFunctionCreate (registered as the deleter callback)
        ...

# C-linkage entry points called from Cython:
def TVMFFIPyMLIRPackedSafeCallCreate(mlir_packed_safe_call: Callable, keep_alive_object: PyObject) -> void_ptr: ...
def TVMFFIPyMLIRPackedSafeCallInvoke(self: void_ptr, args: Ptr[TVMFFIAny], num_args: int32, rv: Ptr[TVMFFIAny]) -> int: ...
def TVMFFIPyMLIRPackedSafeCallDeleter(self: void_ptr) -> None: ...

# === New: Python static method (function.pxi, core.pyi) ===

class Function(Object):
    @staticmethod
    def __from_mlir_packed_safe_call__(
        mlir_packed_symbol: int,
        *,
        keep_alive_object: object | None = None
    ) -> Function:
        """Construct a Function from an MLIR packed safe call function pointer.

        The MLIR execution engine generates functions with signature void(*)(void**).
        This method wraps them into FFI Function objects via TVMFFIPyMLIRPackedSafeCall.
        """
        # 1. TVMFFIPyMLIRPackedSafeCallCreate(mlir_packed_symbol, keep_alive_object)
        # 2. TVMFFIFunctionCreate(mlir_obj, Invoke, Deleter, &handle)
        # 3. On error: TVMFFIPyMLIRPackedSafeCallDeleter(mlir_obj) before raising
        # Interacts with: TVMFFIFunctionCreate (C ABI), TVMFFIPyMLIRPackedSafeCall
        # Interacts with: ExternCFunctionObjImpl (same TVMFFIFunctionCreate pattern)
        # Extension: if MLIR execution engine gains extern C support, this may be deprecated
        ...

    # CHANGED: keep_alive_object is now keyword-only
    @staticmethod
    def __from_extern_c__(
        c_symbol: int,
        *,                                    # NEW: keyword-only separator
        keep_alive_object: object | None = None
    ) -> Function: ...
        # Interacts with: TVMFFIFunctionCreate (C ABI)

# === New: test helper (testing.cc) ===
# testing.get_mlir_add_one_c_symbol() -> int
#   Returns function pointer to _mlir_add_one_c_symbol which wraps __add_one_c_symbol
#   using the MLIR packed convention: void(*)(void**)
```

## Impact
- API: `Function.__from_mlir_packed_safe_call__` added. `Function.__from_extern_c__` signature changed -- `keep_alive_object` is now keyword-only; callers passing it positionally will get `TypeError`.
- Behavioral: none for existing functions
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TVMFFIFunctionCreate C API** (`designs/0004-function-system.md`, `designs/0001-c-abi.md`) -- used to register the MLIR adapter as a Function with custom invoke/deleter callbacks
- **ExternCFunctionObjImpl pattern** (`designs/0004-function-system.md`) -- the `__from_mlir_packed_safe_call__` follows the same 3-callback pattern (self, invoke, deleter) as `__from_extern_c__`
- **Safe call convention** (`designs/0004-function-system.md`) -- the MLIR adapter translates between MLIR's `void(*)(void**)` and FFI's `int(*)(void*, const TVMFFIAny*, int32_t, TVMFFIAny*)` conventions

Design elements this commit produces:
- **TVMFFIPyMLIRPackedSafeCall** -- new C++ adapter class bridging MLIR packed calling convention to FFI safe_call. Lives in Python helper layer (`tvm_ffi_python_helpers.h`), deliberately not in the core C++ headers, since MLIR may eventually support direct extern C exports.
- **Function.__from_mlir_packed_safe_call__** -- new Python entry point for MLIR JIT interop
- **MLIR packed calling convention** -- the layout `void*[] = {&handle, &args, &num_args, &rv, &ret_code}` is the de facto contract for MLIR execution engine functions that wrap TVM FFI safe calls

## Usage Examples

Creating an FFI Function from an MLIR-generated function pointer (from test):

```python
import tvm_ffi

# Get function pointer from MLIR execution engine (simulated here via test helper)
mlir_symbol = tvm_ffi.get_global_func("testing.get_mlir_add_one_c_symbol")()

# Create FFI Function from MLIR packed safe call pointer
fadd_one = tvm_ffi.Function.__from_mlir_packed_safe_call__(mlir_symbol)
assert fadd_one(1) == 2

# With keep_alive_object to prevent execution engine GC:
engine = get_mlir_execution_engine()  # hypothetical
fadd_one = tvm_ffi.Function.__from_mlir_packed_safe_call__(
    mlir_symbol, keep_alive_object=engine
)
# engine's refcount is incremented; it stays alive as long as fadd_one exists
assert fadd_one(2) == 3
```

For comparison, the existing extern C path (now with keyword-only arg):

```python
# __from_extern_c__ now requires keyword-only keep_alive_object
c_symbol = tvm_ffi.get_global_func("testing.get_add_one_c_symbol")()
f = tvm_ffi.Function.__from_extern_c__(c_symbol, keep_alive_object=keep_alive)
# OLD (broken): tvm_ffi.Function.__from_extern_c__(c_symbol, keep_alive)  # TypeError
```
