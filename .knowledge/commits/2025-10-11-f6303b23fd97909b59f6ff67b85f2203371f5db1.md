# Enable FFI function creation from MLIR packed function pointers
## TL;DR
- Adds `Function.__from_mlir_packed_safe_call__(mlir_packed_symbol, *, keep_alive_object=None)` that wraps an MLIR packed function pointer (`void (*)(void**)`) into an FFI Function via a `TVMFFIPyMLIRPackedSafeCall` C++ adapter class.
- The adapter translates between MLIR's packed calling convention and the TVM FFI safe-call convention (`(void*, const TVMFFIAny*, int32_t, TVMFFIAny*) -> int`).
- Refines `__from_extern_c__` to use keyword-only `keep_alive_object` parameter.

## Impact
- API: New `Function.__from_mlir_packed_safe_call__` Python API. `__from_extern_c__` parameter `keep_alive_object` is now keyword-only.
- Flags/config: None.
- Data formats/schemas: None.

Design elements this commit produces:
- **MLIR packed safe-call adapter**: `TVMFFIPyMLIRPackedSafeCall` class in `tvm_ffi_python_helpers.h` that bridges MLIR's `void(*)(void**)` convention to TVM FFI safe-call convention, with proper ref-count management for the keep-alive object.
- **`Function.__from_mlir_packed_safe_call__`**: Python entry point for JIT engines using MLIR execution engine to expose compiled functions.
