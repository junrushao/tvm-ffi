# Add MLIR packed safe call adapter for creating ffi.Function from MLIR execution engine JIT output
## TL;DR
- Adds `Function.__from_mlir_packed_safe_call__` static method and backing C++ class `TVMFFIPyMLIRPackedSafeCall` that adapts the MLIR packed calling convention (`void(*)(void**)`) to the TVM FFI packed calling convention (`TVMFFISafeCallType`).
- Also makes `keep_alive_object` keyword-only in both `__from_extern_c__` and the new `__from_mlir_packed_safe_call__`, and improves their docstrings.
- Adds a C++ test helper `_mlir_add_one_c_symbol` and exposed global `"testing.get_mlir_add_one_c_symbol"` for end-to-end Python testing.

## Key Exports

**Classes:**

`TVMFFIPyMLIRPackedSafeCall` (C++, `tvm_ffi_python_helpers.h`) -- adapts MLIR packed convention to TVM FFI:
```cpp
class TVMFFIPyMLIRPackedSafeCall {
public:
  TVMFFIPyMLIRPackedSafeCall(void (*mlir_packed_safe_call)(void**), PyObject* keep_alive_object);
  ~TVMFFIPyMLIRPackedSafeCall();  // Py_DecRef(keep_alive_object_)
  static int Invoke(void* func, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* rv);
  static void Deleter(void* self);
private:
  void (*mlir_packed_safe_call_)(void**);
  PyObject* keep_alive_object_;
};
```

**C helper functions** (non-class, `tvm_ffi_python_helpers.h`):
```cpp
void* TVMFFIPyMLIRPackedSafeCallCreate(void (*mlir_packed_safe_call)(void**), PyObject* keep_alive_object);
int TVMFFIPyMLIRPackedSafeCallInvoke(void* self, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* rv);
void TVMFFIPyMLIRPackedSafeCallDeleter(void* self);
```

**Python static method** (Cython, `function.pxi`):
```python
@staticmethod
def __from_mlir_packed_safe_call__(
    mlir_packed_symbol: int, *, keep_alive_object: object = None
) -> Function
```

**Test helper** (C++, `testing.cc`):
```cpp
void _mlir_add_one_c_symbol(void** packed_args);
// Registered as "testing.get_mlir_add_one_c_symbol"
```

**Signature change** -- `keep_alive_object` made keyword-only:
```python
# Before:
Function.__from_extern_c__(c_symbol: int, keep_alive_object: Any | None = None) -> Function
# After:
Function.__from_extern_c__(c_symbol: int, *, keep_alive_object: Any | None = None) -> Function
```

## Impact
- API: `Function.__from_extern_c__` now requires `keep_alive_object` as a keyword argument (minor breaking change for positional callers). New `Function.__from_mlir_packed_safe_call__` static method added.
- Behavioral: None -- existing functions unchanged.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Function system** (`0004-function-system.md`): Uses `TVMFFIFunctionCreate(self, safe_call, deleter, &handle)` C API to create function objects from the adapter's invoke/deleter pair.
- **Python FFI call dispatch** (`0015-python-ffi-call-dispatch.md`): The new Cython method integrates with the existing `Function` class and `base.pxi` extern declarations.
- **C ABI layer** (`0001-c-abi-layer.md`): Uses `TVMFFIFunctionCreate` to bridge the MLIR adapter to the object system.
- **TVM_FFI_SAFE_CALL_BEGIN/END**: The test helper `__add_one_c_symbol` (called by the MLIR wrapper) uses these macros for error handling.

Design elements this commit produces:
- **MLIR packed safe call adapter**: A new calling-convention bridge pattern (`TVMFFIPyMLIRPackedSafeCall`) that translates between the MLIR execution engine's `void(*)(void**)` convention and TVM FFI's `TVMFFISafeCallType` convention. This is a new extension point for the function system.

## Usage Examples

### Creating an FFI Function from MLIR JIT output
**Context**: An MLIR execution engine JIT-compiles a function. The engine exposes a `void(*)(void**)` packed pointer. This adapter wraps it as a first-class `tvm_ffi.Function`.

```python
import tvm_ffi

# Obtain the MLIR packed function pointer (as int) from an execution engine
mlir_symbol = get_jit_symbol_address("my_kernel")  # returns int

# Wrap as ffi.Function, keeping the engine alive
func = tvm_ffi.Function.__from_mlir_packed_safe_call__(
    mlir_symbol, keep_alive_object=execution_engine
)

# Call like any other FFI function
result = func(42)
```

### MLIR packed calling convention layout
**Context**: The `Invoke` method unpacks the `void**` argument array expected by MLIR packed functions:
```cpp
// MLIR packed convention: void(*)(void** packed_args)
// packed_args layout:
//   [0] -> void* handle        (ignored/null for TVM FFI)
//   [1] -> const TVMFFIAny* args
//   [2] -> int32_t num_args
//   [3] -> TVMFFIAny* rv
//   [4] -> int* ret_code       (output: 0=success, nonzero=error)
```
