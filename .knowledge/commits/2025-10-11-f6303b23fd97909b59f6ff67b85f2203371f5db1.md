# Add Function.__from_mlir_packed_safe_call__ for MLIR JIT integration
## TL;DR
- Introduces `Function.__from_mlir_packed_safe_call__(mlir_packed_symbol, *, keep_alive_object=None)` as a new static method to create FFI Functions from MLIR execution engine packed function pointers.
- Adds `TVMFFIPyMLIRPackedSafeCall` C++ adapter class in the Cython helper layer to bridge MLIR's `void(void**)` packed calling convention to TVM FFI's `int(void*, const TVMFFIAny*, int32_t, TVMFFIAny*)` safe_call convention.
- Changes `__from_extern_c__`'s `keep_alive_object` parameter from positional to keyword-only.

## Impact
- API: New `Function.__from_mlir_packed_safe_call__` static method. Breaking: `__from_extern_c__`'s `keep_alive_object` is now keyword-only (callers passing it positionally will break).
- Behavioral: none (new functionality only)
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Creating an FFI Function from an MLIR JIT-compiled function pointer:
```python
import tvm_ffi

# Get MLIR packed function pointer (e.g., from MLIR execution engine)
# The function must follow MLIR packed calling convention: void(void**)
# where void** = {&handle, &args, &num_args, &rv, &ret_code}
mlir_symbol = execution_engine.lookup("my_function")

# Create FFI function, keeping execution engine alive
func = tvm_ffi.Function.__from_mlir_packed_safe_call__(
    mlir_symbol,
    keep_alive_object=execution_engine  # prevents GC of JIT env
)

# Call like any other FFI function
result = func(42)
```

End-to-end trace (C++ test symbol -> Python call):
```python
# C++ side: _mlir_add_one_c_symbol(void** packed_args) unpacks MLIR convention
# and delegates to __add_one_c_symbol (standard safe_call)

# Python side:
add_one_ptr = tvm_ffi.get_global_func("testing.get_mlir_add_one_c_symbol")()
fadd_one = tvm_ffi.Function.__from_mlir_packed_safe_call__(add_one_ptr)
assert fadd_one(1) == 2
```
