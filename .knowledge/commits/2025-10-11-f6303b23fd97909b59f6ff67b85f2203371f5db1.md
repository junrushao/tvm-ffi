# Add Function.__from_mlir_packed_safe_call__ for MLIR execution engine JIT interop
## TL;DR
- Adds `Function.__from_mlir_packed_safe_call__` static method to construct an FFI Function from an MLIR packed safe call function pointer, enabling DSLs that use MLIR execution engine for JIT compilation to create callable FFI functions.
- Introduces `TVMFFIPyMLIRPackedSafeCall` C++ helper class (in `tvm_ffi_python_helpers.h`) that adapts the MLIR packed calling convention (`void(void**)`) to the FFI safe call convention (`int(void*, const TVMFFIAny*, int32_t, TVMFFIAny*)`).
- Minor fix: `__from_extern_c__` `keep_alive_object` parameter changed from positional to keyword-only (`*,` separator added).

## Impact
- API: Additive -- new `Function.__from_mlir_packed_safe_call__` static method. Minor breaking: `__from_extern_c__` `keep_alive_object` is now keyword-only (callers passing it positionally will break).
- Behavioral: None to existing functions.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- [0004-ffi-function-system](../design-records/0004-ffi-function-system.md) -- `TVMFFIFunctionCreate` C ABI for constructing Function objects from (handle, invoke, deleter) triple.
- [0012-ffi-python-package](../design-records/0012-ffi-python-package.md) -- `Function` Cython class, `tvm_ffi_python_helpers.h` helper pattern, `Object.chandle` ownership protocol.
- [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md) -- `TVMFFISafeCallType` calling convention `int(void*, const TVMFFIAny*, int32_t, TVMFFIAny*)`.

Design elements this commit produces:
- **MLIR packed safe call construction pattern**: A fourth Function construction path (alongside `FromTyped`, `FromPacked`, `FromExternC`) that adapts MLIR's `void(void**)` packed calling convention. Implemented in the Python helper layer (not core C++ API) as the need may be temporary if MLIR execution engine gains native extern-C export.
- **`TVMFFIPyMLIRPackedSafeCall` adapter class**: C++ class in `tvm_ffi_python_helpers.h` that bridges calling conventions. Manages `keep_alive_object` lifetime via `Py_IncRef`/`Py_DecRef`.

## Usage Examples
Creating an FFI Function from an MLIR JIT-compiled function pointer (from test):
```python
import tvm_ffi

# Get an MLIR packed function pointer (e.g., from MLIR execution engine JIT)
mlir_symbol = tvm_ffi.get_global_func("testing.get_mlir_add_one_c_symbol")()

# Create FFI Function from MLIR packed safe call
fadd_one = tvm_ffi.Function.__from_mlir_packed_safe_call__(mlir_symbol)
assert fadd_one(1) == 2

# With keep_alive_object to prevent GC of the execution engine
execution_engine = ...  # e.g., MLIR ExecutionEngine instance
fadd_one = tvm_ffi.Function.__from_mlir_packed_safe_call__(
    mlir_symbol, keep_alive_object=execution_engine
)
# execution_engine ref count increased; will be released when fadd_one is GC'd
```
