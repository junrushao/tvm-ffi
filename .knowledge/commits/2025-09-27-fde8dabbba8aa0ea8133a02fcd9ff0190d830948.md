# Fix stream passing bug in DLPack C exporter (device_id -> device_type)
## TL;DR
- Fixes a typo bug in `TVMFFIPyArgSetterDLPackCExporter_`: the "already queried device" check was `ctx.device_id != -1` instead of `ctx.device_type != -1`, causing stream context to be lost when multiple DLPack arguments were passed.
- Adds CUDA regression test (`test_load_inline_cuda`) that verifies the stream passed to the C++ kernel matches the expected stream handle.
- Bumps version to `0.1.0b11`.
