# Fix Cython stream passing bug (device_id vs device_type check)
## TL;DR
- Fixes a typo in `function.pxi` where `ctx.device_id` was checked instead of `ctx.device_type` when determining if the device was already queried, breaking expected stream passing behavior.
- Adds a regression test in `test_load_inline.py` that passes `raw_stream` to verify stream identity matches.

## Key Exports

```python
# In function.pxi TVMFFIPyArgSetterDLPackCExporter_
# Before: if ctx.device_id != -1:  (wrong field)
# After:  if ctx.device_type != -1: (correct field)
# Interacts with: DLPack export path, TVMFFIEnvGetStream
# Invariant: ctx.device_type == -1 means device not yet queried
```
