# Remove ninja dependency for non-Windows JIT torch-c-dlpack builds
## TL;DR
- Removes the ninja build system dependency for JIT compilation of torch-c-dlpack on non-Windows platforms.
- Simplifies the build by using the default make backend on Linux/macOS.
