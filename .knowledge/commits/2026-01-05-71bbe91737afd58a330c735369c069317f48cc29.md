# Fix TVMFFIEnvSetDLPackManagedTensorAllocator to correctly return original allocator
## TL;DR
- Fixes a bug where `TVMFFIEnvSetDLPackManagedTensorAllocator` returned the newly-set allocator instead of the original one via `opt_out_original_allocator`.
- Moves the output write before the allocator update so the caller receives the previous allocator.
