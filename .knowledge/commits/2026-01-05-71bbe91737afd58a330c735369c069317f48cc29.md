# fix: TVMFFIEnvSetDLPackManagedTensorAllocator now correctly returns the original allocator before overwriting

## TL;DR
- `EnvContext::SetDLPackManagedTensorAllocator()` previously set `*opt_out_original_allocator = dlpack_allocator_` AFTER overwriting `dlpack_allocator_` — always returning the NEW allocator as "original"
- Fix: capture `*opt_out_original_allocator = GetDLPackManagedTensorAllocator()` BEFORE the write
- Added 8 new C++ tests for the correct round-trip behavior

## Key Exports

```python
# src/ffi/extra/env_context.cc
class EnvContext:
    def SetDLPackManagedTensorAllocator(
        self,
        allocator: DLPackManagedTensorAllocator,
        write_to_global_context: int,
        opt_out_original_allocator: DLPackManagedTensorAllocator* = None
    ) -> None:
        # Invariant (after fix): opt_out_original_allocator is written BEFORE
        #   dlpack_allocator_ is updated, so callers get the truly original value
        # Interacts with: TVMFFIEnvSetDLPackManagedTensorAllocator C ABI
        # Interacts with: GlobalTensorAllocator() singleton
```

## Impact
- API: `TVMFFIEnvSetDLPackManagedTensorAllocator` behavior correction — callers that save the returned original allocator to restore it later now get the correct previous value
- Behavioral: Fixes incorrect original allocator being returned (was returning the new one, not the old one)
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit produces:

## Usage Examples
```cpp
// Bug: before fix
DLPackManagedTensorAllocator original;
TVMFFIEnvSetDLPackManagedTensorAllocator(new_alloc, 0, &original);
// `original` was wrongly == new_alloc

// After fix: `original` == previous allocator (correct for swap/restore pattern)
DLPackManagedTensorAllocator original;
TVMFFIEnvSetDLPackManagedTensorAllocator(new_alloc, 0, &original);
TVMFFIEnvSetDLPackManagedTensorAllocator(original, 0, nullptr);  // restore
```
