# Fix TVMFFIEnvSetDLPackManagedTensorAllocator to return original allocator before overwrite
## TL;DR
- Fixes `SetDLPackManagedTensorAllocator` to capture the original allocator into `opt_out_original_allocator` **before** overwriting `dlpack_allocator_`. Previously, it wrote the new allocator back (reading after write), making the "get previous" output useless.
- Adds a test verifying the returned previous allocator matches the one obtained via `TVMFFIEnvGetDLPackManagedTensorAllocator()`.

**Invariant violated**: `opt_out_original_allocator` was set to the **new** allocator (read after write) instead of the **old** one.
**Invariant restored**: `opt_out_original_allocator` is now populated **before** `dlpack_allocator_` is updated.
