# Fix TVMFFIEnvSetDLPackManagedTensorAllocator to return the original allocator before overwrite
## TL;DR
- `EnvContext::SetDLPackManagedTensorAllocator` wrote the out-parameter *after* overwriting `dlpack_allocator_`, so callers received the new allocator instead of the original.
- Fix: read the original allocator via `GetDLPackManagedTensorAllocator()` into the out-parameter *before* mutating any state.
- Added a regression test (`TVMFFIEnvSetDLPackManagedTensorAllocator`) that asserts the returned previous allocator equals the one that was active before the call.

## Key Exports
None -- no new public API. Bugfix only.

## Impact
- API: None -- function signature unchanged.
- Behavioral: `TVMFFIEnvSetDLPackManagedTensorAllocator` now correctly returns the previous allocator via `opt_out_original_allocator`. Before this fix, callers relying on the out-parameter to save/restore the allocator (e.g., around a scoped override) would silently get the *new* allocator back, making restoration a no-op.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `EnvContext::SetDLPackManagedTensorAllocator` / `EnvContext::GetDLPackManagedTensorAllocator` -- thread-local + global-fallback allocator management ([0011-ffi-module-system](../design-records/0011-ffi-module-system.md))
- `TVMFFIEnvSetDLPackManagedTensorAllocator` C API -- public env API surface ([0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md), [0011-ffi-module-system](../design-records/0011-ffi-module-system.md))

Design elements this commit produces: None.

## Usage Examples
**Before (buggy):** The out-parameter returned the *new* allocator, not the original.
```cpp
// Bug: pre_allocator == NewAllocator (wrong!)
auto old = TVMFFIEnvGetDLPackManagedTensorAllocator();
DLPackManagedTensorAllocator pre;
TVMFFIEnvSetDLPackManagedTensorAllocator(NewAllocator, 0, &pre);
// pre != old  <-- violated contract
```

**After (fixed):** The out-parameter correctly returns the original allocator.
```cpp
// Fix: pre_allocator == old_allocator (correct)
auto old = TVMFFIEnvGetDLPackManagedTensorAllocator();
DLPackManagedTensorAllocator pre;
TVMFFIEnvSetDLPackManagedTensorAllocator(NewAllocator, 0, &pre);
EXPECT_EQ(old, pre);  // passes
TVMFFIEnvSetDLPackManagedTensorAllocator(old, 0, nullptr);  // restore
```
