# Fix TVMFFIEnvSetDLPackManagedTensorAllocator to return the original allocator before overwriting it

## TL;DR
- `EnvContext::SetDLPackManagedTensorAllocator` had an ordering bug: it wrote `dlpack_allocator_ = allocator` before reading the original value into `*opt_out_original_allocator`, so callers always received the new allocator instead of the previous one.
- The fix reorders operations: capture the original allocator via `GetDLPackManagedTensorAllocator()` first, then update the global and TLS fields.
- A new GoogleTest (`TVMFFIEnvSetDLPackManagedTensorAllocator`) validates that the returned previous allocator matches the value obtained from the getter before the set call.

## Key Exports

No new public API. The fix corrects the behavior of an existing C ABI function.

```python
# Corrected behavior of existing function:
def TVMFFIEnvSetDLPackManagedTensorAllocator(
    allocator: DLPackManagedTensorAllocator,
    write_to_global_context: int,
    opt_out_original_allocator: Ptr[DLPackManagedTensorAllocator]
) -> int: ...
    # Invariant (restored): *opt_out_original_allocator receives the allocator
    #   that was active BEFORE this call (TLS-first, then global fallback),
    #   NOT the newly-set allocator.
    # Interacts with: EnvContext::GetDLPackManagedTensorAllocator (read),
    #                 EnvContext::GlobalTensorAllocator (conditional write),
    #                 EnvContext::dlpack_allocator_ (TLS write)
```

## Impact
- API: None -- no signature change.
- Behavioral: Callers that relied on the `opt_out_original_allocator` output parameter (e.g., save/restore patterns around FFI calls) were silently getting the wrong allocator back. The allocator save/restore pattern used by `TVMFFIPyCallManager` and C++ test harnesses now works correctly.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

**Before (buggy)**:
```cpp
// Bug: opt_out_original_allocator received the NEW allocator, not the old one
auto old_allocator = TVMFFIEnvGetDLPackManagedTensorAllocator();
DLPackManagedTensorAllocator pre_allocator;
TVMFFIEnvSetDLPackManagedTensorAllocator(NewAllocator, 0, &pre_allocator);
// pre_allocator == NewAllocator  <-- WRONG, should equal old_allocator
```

**After (fixed)**:
```cpp
// Fix: opt_out_original_allocator now correctly receives the previous allocator
auto old_allocator = TVMFFIEnvGetDLPackManagedTensorAllocator();
DLPackManagedTensorAllocator pre_allocator;
TVMFFIEnvSetDLPackManagedTensorAllocator(NewAllocator, 0, &pre_allocator);
// pre_allocator == old_allocator  <-- CORRECT
TVMFFIEnvSetDLPackManagedTensorAllocator(pre_allocator, 0, nullptr);  // restore works
```
