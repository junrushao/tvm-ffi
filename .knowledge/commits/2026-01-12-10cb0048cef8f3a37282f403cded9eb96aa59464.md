# Isolate unified CUDA API to cubin launcher only, split TVM_FFI_CHECK_CUDA_ERROR
## TL;DR
- Renames `TVM_FFI_CHECK_CUDA_ERROR` in `unified_api.h` to `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` to scope it to cubin launcher usage only.
- Adds a new `TVM_FFI_CHECK_CUDA_ERROR` in `base.h` that specifically uses the CUDA runtime API (`cudaError_t`), not the unified driver/runtime API.
- Updates `device_guard.h` to include `base.h` instead of `unified_api.h`.
- Updates all examples and tests to use the new macro name.

## Key Exports

```python
# Macro: TVM_FFI_CHECK_CUDA_ERROR(stmt)
# Location: include/tvm/ffi/extra/cuda/base.h
# Uses cudaError_t (runtime API only)
# Interacts with: cudaGetErrorName, cudaGetErrorString
# Invariant: always uses CUDA runtime API, never driver API

# Macro: TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR(stmt)
# Location: include/tvm/ffi/extra/cuda/internal/unified_api.h
# Uses cuda_api::ResultType (may be driver or runtime depending on config)
# Interacts with: cuda_api::GetErrorString, unified API abstraction
# Invariant: only used within cubin launcher code paths
```

## Impact
- API: renames `TVM_FFI_CHECK_CUDA_ERROR` -> `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` in unified_api.h (breaking for users of the old macro from unified_api.h)
- Behavioral: `base.h` now provides a runtime-API-only `TVM_FFI_CHECK_CUDA_ERROR`
- Flags/config: none
- Data formats/schemas: none
