# Isolate unified CUDA API to cubin launcher; add runtime-only TVM_FFI_CHECK_CUDA_ERROR in base.h
## TL;DR
- Renames `TVM_FFI_CHECK_CUDA_ERROR` in `unified_api.h` to `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` to isolate the driver/runtime API switching macro to cubin launcher usage only.
- Introduces a new `TVM_FFI_CHECK_CUDA_ERROR` macro in `include/tvm/ffi/extra/cuda/base.h` that is purely CUDA runtime API-based (`cudaError_t` / `cudaGetErrorName`).
- Updates all call sites: cubin launcher examples, device_guard.h, tests, and docs to use the appropriate macro.

| Old name | New name | Location |
|----------|----------|----------|
| `TVM_FFI_CHECK_CUDA_ERROR` (unified) | `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` | `internal/unified_api.h` |
| (new) | `TVM_FFI_CHECK_CUDA_ERROR` (runtime only) | `extra/cuda/base.h` |

## Key Exports

**Macro** added in `include/tvm/ffi/extra/cuda/base.h`:
```cpp
#define TVM_FFI_CHECK_CUDA_ERROR(stmt)  // checks cudaError_t, throws RuntimeError
```

**Macro** renamed in `include/tvm/ffi/extra/cuda/internal/unified_api.h`:
```cpp
#define TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR(stmt)  // checks cuda_api::ResultType (driver or runtime)
```

## Impact
- API: macro rename `TVM_FFI_CHECK_CUDA_ERROR` (unified) to `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR`; new runtime-only `TVM_FFI_CHECK_CUDA_ERROR` in `base.h`
- Behavioral: none (same error checking logic)
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cpp
// Generic CUDA runtime error checking (base.h):
TVM_FFI_CHECK_CUDA_ERROR(cudaMemcpy(dst, src, size, cudaMemcpyDefault));

// Cubin launcher internal (unified_api.h):
TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR(cuda_api::LaunchKernel(...));
```
