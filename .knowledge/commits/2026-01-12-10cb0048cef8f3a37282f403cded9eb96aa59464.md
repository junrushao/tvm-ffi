# Isolate TVM_FFI_CHECK_CUDA_ERROR to cubin launcher; add runtime-only macro in base.h

## TL;DR
- `TVM_FFI_CHECK_CUDA_ERROR` in `internal/unified_api.h` renamed to `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` to signal it is cubin-launcher-specific (bridges driver/runtime API).
- A new `TVM_FFI_CHECK_CUDA_ERROR` macro is added to `base.h` using the CUDA **runtime** API only (`cudaError_t`), replacing the unified-API macro for general use.
- All call sites in `cubin_launcher.h` and `unified_api.h` updated to use the renamed cubin-launcher macro.

## Key Exports

```python
# In include/tvm/ffi/extra/cuda/base.h (CUDA Runtime API only)
# NEW macro — replaces old TVM_FFI_CHECK_CUDA_ERROR for general runtime use
# TVM_FFI_CHECK_CUDA_ERROR(stmt: cudaError_t) -> void
# Throws RuntimeError on failure using cudaGetErrorName/cudaGetErrorString
# Invariant: stmt must return cudaError_t (runtime API only, NOT driver API)
# Interacts with: TVM_FFI_THROW(RuntimeError), tvm/ffi/error.h, cuda_runtime.h

# In include/tvm/ffi/extra/cuda/internal/unified_api.h (Unified Driver/Runtime API)
# RENAMED from TVM_FFI_CHECK_CUDA_ERROR → TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR
# TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR(stmt: cuda_api::ResultType) -> void
# Throws RuntimeError; works with either driver (CUresult) or runtime (cudaError_t) API
# Invariant: only use inside cubin launcher code that may switch between APIs
# Interacts with: cuda_api::ResultType, cuda_api::kSuccess, cuda_api::GetErrorString
```

## Impact
- API: `TVM_FFI_CHECK_CUDA_ERROR` macro changes meaning — old callers in `cubin_launcher.h` are updated; callers outside cubin launcher that used the unified-API version must now use `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` explicitly.
- Behavioral: `base.h` now includes `<cuda_runtime.h>` and `<tvm/ffi/error.h>` directly; any translation unit including `base.h` gains these transitive includes.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Before (cubin launcher and unified_api.h used the same macro):
```cpp
// In internal/unified_api.h and cubin_launcher.h:
TVM_FFI_CHECK_CUDA_ERROR(cuda_api::LoadLibrary(&library_, bytes.data()));
// Macro was defined in unified_api.h — mixed driver/runtime semantics
```

After (two separate macros for two separate purposes):
```cpp
// General runtime error checking (base.h):
TVM_FFI_CHECK_CUDA_ERROR(cudaMalloc(&ptr, size));  // cudaError_t only

// Cubin launcher internal use (unified_api.h):
TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR(cuda_api::LoadLibrary(&library_, bytes.data()));
```
