# Split TVM_FFI_CHECK_CUDA_ERROR into runtime-only and cubin-launcher-specific variants
## TL;DR
- Renames `TVM_FFI_CHECK_CUDA_ERROR` in `internal/unified_api.h` to `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` to isolate the unified (Driver/Runtime) error-checking macro to cubin launcher code only.
- Adds a new `TVM_FFI_CHECK_CUDA_ERROR` in `base.h` that is exclusively for CUDA Runtime API (`cudaError_t`), making it safe for general-purpose use without pulling in the Driver API.
- Updates `device_guard.h` to include `base.h` instead of `internal/unified_api.h`, breaking its dependency on the unified API layer.

### Rename Mapping

| Old name | New name | Location |
|----------|----------|----------|
| `TVM_FFI_CHECK_CUDA_ERROR` (in `unified_api.h`) | `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` | `internal/unified_api.h` |
| (new) | `TVM_FFI_CHECK_CUDA_ERROR` | `base.h` — runtime-only variant |

## Key Exports

```python
# === base.h (NEW macro) ===
# Macro expansion (pseudocode for TVM_FFI_CHECK_CUDA_ERROR in base.h):
# err: cudaError_t = stmt
# if err != cudaSuccess:
#     raise RuntimeError(f"CUDA Runtime Error: {cudaGetErrorName(err)} ({err}): {cudaGetErrorString(err)}")
# Interacts with: cudaGetErrorName, cudaGetErrorString, TVM_FFI_THROW(RuntimeError)
# Invariant: ONLY works with cudaError_t (Runtime API). NOT for CUresult (Driver API).
# Note: error prefix is "CUDA Runtime Error:" (distinct from unified macro's "CUDA Error:")

# === unified_api.h (RENAMED macro) ===
# Macro expansion (pseudocode for TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR):
# err: cuda_api::ResultType = stmt   # may be CUresult OR cudaError_t
# if err != cuda_api::kSuccess:
#     cuda_api::GetErrorString(err, &name, &desc)
#     raise RuntimeError(f"CUDA Error: {name} ({err}): {desc}")
# Interacts with: cuda_api::ResultType, cuda_api::kSuccess, cuda_api::GetErrorString
# Invariant: uses unified types — works with EITHER Driver or Runtime API depending on compile-time selection
# Invariant: scope restricted to cubin launcher code paths only
```

## Impact
- API: Renamed macro `TVM_FFI_CHECK_CUDA_ERROR` -> `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` in cubin launcher context. External users of cubin launcher headers who used the old name must update. The new `TVM_FFI_CHECK_CUDA_ERROR` in `base.h` is a drop-in for runtime-only code.
- Behavioral: `device_guard.h` no longer pulls in `internal/unified_api.h` (and transitively `cuda.h` for Driver API). It now includes only `base.h` + `cuda_runtime.h`. This reduces compilation dependencies for users of `CUDADeviceGuard`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_THROW(RuntimeError)` — error protocol ([0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md))
- `cuda_api::` unified namespace types (`ResultType`, `kSuccess`, `GetErrorString`) — CUDA extras ([0019-ffi-cuda-extras](../design-records/0019-ffi-cuda-extras.md))
- `CubinModule`, `CubinKernel` — cubin launcher classes ([0019-ffi-cuda-extras](../design-records/0019-ffi-cuda-extras.md))
- `CUDADeviceGuard` — device guard ([0019-ffi-cuda-extras](../design-records/0019-ffi-cuda-extras.md))

Design elements this commit produces/mutates:
- **Mutates** `TVM_FFI_CHECK_CUDA_ERROR`: previously lived in `unified_api.h` and operated on `cuda_api::ResultType` (unified). Now split into two macros:
  - `TVM_FFI_CHECK_CUDA_ERROR` in `base.h` — runtime-only (`cudaError_t`)
  - `TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR` in `unified_api.h` — unified, cubin-launcher-scoped
- **Mutates** `device_guard.h` include graph: was `unified_api.h` -> now `base.h` (lighter dependency)
- **Mutates** CI cpp-changed-files detection: scoped to `src/` and `tests/` directories instead of globbing all `*.c`/`*.cc`/`*.cpp`/`*.cxx` across the entire repo (avoids triggering C++ CI on example file changes)

## Usage Examples

Before (unified macro used everywhere):
```cpp
// In cubin launcher code AND in device guard — same macro, same include
#include <tvm/ffi/extra/cuda/internal/unified_api.h>
cudaError_t result = kernel.Launch(args, grid, block, stream);
TVM_FFI_CHECK_CUDA_ERROR(result);  // operated on cuda_api::ResultType
```

After (two distinct macros):
```cpp
// In general CUDA code (device guard, user code) — runtime-only
#include <tvm/ffi/extra/cuda/base.h>
TVM_FFI_CHECK_CUDA_ERROR(cudaSetDevice(device_id));  // cudaError_t only

// In cubin launcher code — unified Driver/Runtime
#include <tvm/ffi/extra/cuda/cubin_launcher.h>
TVM_FFI_CHECK_CUBIN_LAUNCHER_CUDA_ERROR(kernel.Launch(args, grid, block, stream));
```
