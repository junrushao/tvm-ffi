# Make JSON parser and writer fastmath-safe by replacing std::isnan/isinf/numeric_limits with IEEE 754 bit-level fallbacks
## TL;DR
- Under `-ffast-math`, `std::isnan()`, `std::isinf()`, and `std::numeric_limits<double>::infinity()/quiet_NaN()` may be optimized away or return incorrect results. This commit adds bit-level IEEE 754 fallbacks guarded by `#ifdef __FAST_MATH__`.
- JSON parser (`json_parser.cc`): introduces `FastMathSafePosInf()`, `FastMathSafeNegInf()`, `FastMathSafeNaN()` to construct special float values via raw bit patterns.
- JSON writer (`json_writer.cc`): introduces `FastMathSafeIsNaN()`, `FastMathSafeIsInf()` to detect special float values via bit-level exponent/mantissa inspection.
- Tests updated to use the same bit-level detection helpers so assertions pass under fastmath.

## Key Exports
These are private static helpers (not public API), but they encode important invariants:

**Functions (json_parser.cc, private to JSONParserContext)**:
- `static double FastMathSafePosInf()` -- returns `+Inf` via bit pattern `0x7FF0000000000000ULL`
- `static double FastMathSafeNegInf()` -- returns `-Inf` via bit pattern `0xFFF0000000000000ULL`
- `static double FastMathSafeNaN()` -- returns quiet NaN via bit pattern `0x7FF8000000000000ULL`

**Functions (json_writer.cc, private to JSONWriter)**:
- `static bool FastMathSafeIsNaN(double x)` -- detects NaN by checking exponent==0x7FF && mantissa!=0
- `static bool FastMathSafeIsInf(double x)` -- detects Inf by checking exponent==0x7FF && mantissa==0

**Constants (IEEE 754 double bit layouts)**:
- Positive infinity: `0x7FF0000000000000ULL` (exponent all 1s, mantissa all 0s, sign=0)
- Negative infinity: `0xFFF0000000000000ULL` (exponent all 1s, mantissa all 0s, sign=1)
- Quiet NaN: `0x7FF8000000000000ULL` (exponent all 1s, mantissa MSB=1, sign=0)

## Impact
- API: None -- all changes are internal to `json_parser.cc` and `json_writer.cc`. No public header changes.
- Behavioral: JSON serialization/deserialization of `NaN`, `Infinity`, `-Infinity` now works correctly when TVM FFI is compiled with `-ffast-math` (GCC/Clang `__FAST_MATH__` macro). Previously, these special values could silently produce incorrect results.
- Flags/config: Sensitive to compiler flag `-ffast-math` (detected via `__FAST_MATH__` preprocessor macro). No new build flags introduced.
- Data formats/schemas: None -- JSON wire format for NaN/Infinity is unchanged (`NaN`, `Infinity`, `-Infinity` literals).

## Design Elements
Design elements this commit consumes:
- **Extra API isolation** ([ADR-0010](../ADRs/0010-extra-api-isolation.md)): `json_parser.cc` and `json_writer.cc` live under `src/ffi/extra/`, the non-core module boundary.
- **JSON value type** (`tvm::ffi::json::Value`): The JSON subsystem uses the FFI type-erased value containers; the parser produces `Any` values and the writer consumes `json::Value`.
- **IEEE 754 double-precision layout**: The commit relies on `sizeof(double) == sizeof(uint64_t)` (asserted via `static_assert`) and standard IEEE 754 bit layout for exponent (bits 52-62) and mantissa (bits 0-51).

Design elements this commit produces:
- **Fastmath-safe float special-value pattern**: A reusable pattern for constructing/detecting NaN and Inf values via raw bit manipulation, guarded by `#ifdef __FAST_MATH__`. This pattern may need to be applied elsewhere if other code paths use `std::isnan`/`std::isinf`/`std::numeric_limits` special values.

## Usage Examples
Before (broken under `-ffast-math`):
```cpp
// Parser: std::numeric_limits may return 0.0 or be optimized away under -ffast-math
*out = std::numeric_limits<double>::infinity();
*out = -std::numeric_limits<double>::infinity();
*out = std::numeric_limits<double>::quiet_NaN();

// Writer: std::isnan/std::isinf may always return false under -ffast-math
if (std::isnan(value)) { WriteLiteral("NaN", 3); }
if (std::isinf(value)) { /* write Infinity */ }
```

After (correct under all modes):
```cpp
// Parser: bit-level construction, falls back to std::numeric_limits when safe
*out = FastMathSafePosInf();   // 0x7FF0000000000000ULL under __FAST_MATH__
*out = FastMathSafeNegInf();   // 0xFFF0000000000000ULL under __FAST_MATH__
*out = FastMathSafeNaN();      // 0x7FF8000000000000ULL under __FAST_MATH__

// Writer: bit-level detection, falls back to std::isnan/isinf when safe
if (FastMathSafeIsNaN(value)) { WriteLiteral("NaN", 3); }
if (FastMathSafeIsInf(value)) { /* write Infinity */ }
```
