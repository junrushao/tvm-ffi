# Make JSON parser and writer produce correct NaN/Infinity values under -ffast-math

## TL;DR
- Replaces `std::numeric_limits<double>::infinity()` / `quiet_NaN()` in the JSON parser with bit-level construction helpers (`FastMathSafePosInf`, `FastMathSafeNegInf`, `FastMathSafeNaN`) that bypass `-ffast-math` optimizations.
- Replaces `std::isnan()` / `std::isinf()` in the JSON writer with bit-level detection helpers (`FastMathSafeIsNaN`, `FastMathSafeIsInf`) that inspect IEEE 754 exponent/mantissa fields directly.
- Updates tests to use the same bit-level detection helpers so assertions pass under `-ffast-math`.

## Impact
- API: none -- all changes are internal to JSON parser/writer implementation.
- Behavioral: JSON round-trip of `NaN`, `Infinity`, `-Infinity` now produces correct values when compiled with `-ffast-math`. Previously, parsing could yield garbage and writing could emit wrong literals.
- Flags/config: the `__FAST_MATH__` preprocessor macro (set by `-ffast-math` / `-Ofast`) now triggers alternative code paths.
- Data formats/schemas: none -- JSON wire format unchanged (`NaN`, `Infinity`, `-Infinity` literals).

## Design Elements
Design elements this commit consumes:
- **JSON serialization subsystem** (`src/ffi/extra/json_parser.cc`, `src/ffi/extra/json_writer.cc`) -- the FFI's internal JSON parser/writer, exposed as `tvm.ffi.json_loads` / `tvm.ffi.json_dumps` global functions.
- **IEEE 754 double-precision encoding** -- bit layout: sign (bit 63), exponent (bits 52-62, biased), mantissa (bits 0-51). NaN = exponent all-ones + non-zero mantissa; Inf = exponent all-ones + zero mantissa.

Design elements this commit produces:
- **FastMathSafe special-value helpers** -- a pattern of bit-level IEEE 754 construction/detection guarded by `#ifdef __FAST_MATH__`, with standard-library fallback in the `#else` branch. Duplicated across parser, writer, and test; not yet extracted to a shared header.

## Usage Examples

**Before (broken under -ffast-math):**
```cpp
// In json_parser.cc -- std::numeric_limits is unreliable under -ffast-math
*out = std::numeric_limits<double>::infinity();   // may return 0.0
*out = std::numeric_limits<double>::quiet_NaN();  // may return 0.0

// In json_writer.cc -- std::isnan/isinf always return false under -ffast-math
if (std::isnan(value)) { WriteLiteral("NaN", 3); }        // never taken
if (std::isinf(value)) { WriteLiteral("Infinity", 8); }   // never taken
```

**After (correct under -ffast-math):**
```cpp
// In json_parser.cc -- bit-level construction bypasses compiler optimizations
*out = FastMathSafePosInf();  // 0x7FF0000000000000 -> +inf
*out = FastMathSafeNaN();     // 0x7FF8000000000000 -> quiet NaN

// In json_writer.cc -- bit-level detection inspects IEEE 754 fields directly
if (FastMathSafeIsNaN(value)) { WriteLiteral("NaN", 3); }        // works
if (FastMathSafeIsInf(value)) { WriteLiteral("Infinity", 8); }   // works
```
