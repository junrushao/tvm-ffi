# Make JSON parser and writer fastmath-safe with IEEE 754 bit-level fallbacks
## TL;DR
- Under `-ffast-math`, `std::isnan`/`std::isinf` and `std::numeric_limits<double>::infinity()`/`quiet_NaN()` produce undefined or incorrect results; this commit replaces all uses in JSON parser/writer with bit-level IEEE 754 helpers.
- Adds six private static helper functions: `FastMathSafePosInf`, `FastMathSafeNegInf`, `FastMathSafeNaN` (parser), `FastMathSafeIsNaN`, `FastMathSafeIsInf` (writer and tests).
- Tests updated to use the same bit-level checks so assertions pass under fastmath builds.

## Impact
- API: none -- all changes are internal (private static methods and file-local helpers)
- Behavioral: JSON parser now correctly produces NaN/Inf `double` values and JSON writer correctly detects NaN/Inf when the library is compiled with `-ffast-math` (GCC/Clang `__FAST_MATH__` macro)
- Flags/config: none (the `#ifdef __FAST_MATH__` is a compiler-defined macro, not a TVM config)
- Data formats/schemas: none -- JSON wire format unchanged ("NaN", "Infinity", "-Infinity" literals)

## Usage Examples

Before (broken under `-ffast-math`):
```cpp
// Parser: std::numeric_limits<double>::infinity() may be optimized to 0 or undefined
*out = std::numeric_limits<double>::infinity();     // parsed "Infinity"
*out = -std::numeric_limits<double>::infinity();    // parsed "-Infinity"
*out = std::numeric_limits<double>::quiet_NaN();    // parsed "NaN"

// Writer: std::isnan/std::isinf always return false under -ffast-math
if (std::isnan(value)) { WriteLiteral("NaN", 3); }       // never taken
if (std::isinf(value)) { WriteLiteral("Infinity", 8); }  // never taken
```

After (fastmath-safe via IEEE 754 bit manipulation):
```cpp
// Parser: construct special values from their exact IEEE 754 bit patterns
*out = FastMathSafePosInf();   // reinterpret_cast from 0x7FF0000000000000
*out = FastMathSafeNegInf();   // reinterpret_cast from 0xFFF0000000000000
*out = FastMathSafeNaN();      // reinterpret_cast from 0x7FF8000000000000

// Writer: detect via bit extraction (exponent field == 0x7FF)
if (FastMathSafeIsNaN(value)) { WriteLiteral("NaN", 3); }
if (FastMathSafeIsInf(value)) { /* write Infinity */ }
```
