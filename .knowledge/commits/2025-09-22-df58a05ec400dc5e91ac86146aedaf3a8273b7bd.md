# Make Array[T] and Map[K, V] parameterizable with type variables
## TL;DR
- Makes `Array` generic as `Array[T]` (inheriting `Sequence[T]`) and `Map` generic as `Map[K, V]` (inheriting `Mapping[K, V]`), enabling proper type parameterization for static type checkers.
- Refactors `getitem_helper` with TypeVar `T` return type, adds `@overload` for `__getitem__` on `Array` (returning `T` for index, `Array[T]` for slice).
- Updates `KeysView`, `ValuesView`, `ItemsView` to be generic over `K`/`V`.
- Fixes `__getitem__` index handling to use `operator.index()` for `SupportsIndex` compliance, and `slice.indices()` for proper slice normalization.

## Impact
- API: `Array` and `Map` are now generic types (`Array[T]`, `Map[K, V]`). This is backwards-compatible for runtime but changes the type signature for static analysis.
- Flags/config: none
- Data formats/schemas: none
