# Remove Function::Registry class and TVM_FFI_REGISTER_GLOBAL macro in favor of GlobalDef
## TL;DR
- Deletes the `Function::Registry` class (with `set_body_typed`, `set_body_packed`, `set_body_method`) and the `TVM_FFI_REGISTER_GLOBAL` macro from `include/tvm/ffi/function.h`.
- This is a pure deletion (0 additions, 144 deletions) completing the migration to `reflection::GlobalDef` (introduced in `b333288` / PR #18111).
- After this commit, zero uses of `TVM_FFI_REGISTER_GLOBAL` or `Function::Registry` remain in the codebase.

## Key Exports
Removed API surface (no longer available after this commit):

```python
# REMOVED: Function::Registry class
# Was: include/tvm/ffi/function.h
class Function.Registry:
    """Builder-pattern registry for global function registration."""
    name_: str  # private

    def set_body_packed(self, f: Callable) -> "Registry":
        """Register raw packed-signature callable."""
        # Interacts with: Function.FromPacked, Function.SetGlobal
    def set_body_typed(self, f: Callable) -> "Registry":
        """Register typed callable with auto-conversion."""
        # Interacts with: Function.FromTyped, Function.SetGlobal
    def set_body_method(self, f: MemberPointer) -> "Registry":
        """Register member function, binding first arg as self."""
        # Interacts with: Function.FromTyped, Function.SetGlobal

# REMOVED: TVM_FFI_REGISTER_GLOBAL macro
# Was: TVM_FFI_REGISTER_GLOBAL("name").set_body_typed(callable)
#   => static Function::Registry& = Function::Registry("name")
#   => .set_body_typed(callable)
#   => Function::SetGlobal("name", Function::FromTyped(callable))

# REPLACEMENT: reflection::GlobalDef (in include/tvm/ffi/reflection/registry.h)
# reflection::GlobalDef().def("name", callable)
#   => Function::SetGlobal("name", Function::FromTyped(callable))
# Interacts with: ReflectionDefBase, Function.FromTyped, Function.SetGlobal
```

## Impact
- API: Breaking -- `Function::Registry` class and `TVM_FFI_REGISTER_GLOBAL` macro are removed. All callers must use `reflection::GlobalDef` instead.
- Behavioral: none -- the underlying registration mechanism (`Function::SetGlobal`) is unchanged; only the builder API was removed.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `Function::SetGlobal` (0003-function-system) -- the underlying C API call is unchanged; only the builder wrapper was removed.
- `Function::FromTyped` / `Function::FromPacked` (0003-function-system) -- still used by `GlobalDef`, just not via `Registry`.

Design elements this commit produces:
- None (pure removal). The replacement `GlobalDef` was introduced in `b333288`.

Design elements this commit mutates:
- **Global function registration convention**: The canonical way to register global functions changes from `TVM_FFI_REGISTER_GLOBAL("name").set_body_typed(f)` to `GlobalDef().def("name", f)`. This is a convention change, not a new design element -- the underlying `Function::SetGlobal` call path is identical.

## Usage Examples
Before (removed):
```cpp
TVM_FFI_REGISTER_GLOBAL("mymath.Add")
.set_body_typed([](int a, int b) -> int {
  return a + b;
});
```

After (replacement pattern via GlobalDef):
```cpp
TVM_FFI_GLOBAL_DEF("mymath")
.def("Add", [](int a, int b) -> int {
  return a + b;
});
```
