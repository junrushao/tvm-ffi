# Remove Function::Registry class and TVM_FFI_REGISTER_GLOBAL macro, completing migration to GlobalDef
## TL;DR
- Deletes the `Function::Registry` class (builder with `set_body_packed`, `set_body_typed`, `set_body_method`) and the `TVM_FFI_REGISTER_GLOBAL` macro from `include/tvm/ffi/function.h`.
- Also deletes the helper macro `TVM_FFI_FUNC_REG_VAR_DEF`.
- This is a cleanup commit: all call sites were already migrated to `refl::GlobalDef` in prior commits. Zero additions, 144 deletions, single file.

## Key Exports

**Removed macros**:
| Name | Was | Status |
|------|-----|--------|
| `TVM_FFI_REGISTER_GLOBAL(name)` | Expanded to `static inline Function::Registry& __TVMFFIFuncRegN = Function::Registry(name)` | **Deleted** |
| `TVM_FFI_FUNC_REG_VAR_DEF` | Helper for the above, generating the variable declaration | **Deleted** |

**Removed class**:
| Name | Was | Status |
|------|-----|--------|
| `Function::Registry` | Builder class with `set_body_packed(f)`, `set_body_typed(f)`, `set_body_method(f)` methods, using `Function::SetGlobal` internally | **Deleted** |

**Replacement** (pre-existing, not introduced by this commit):
`refl::GlobalDef` in `include/tvm/ffi/reflection/registry.h`, with equivalent methods `def(name, func)`, `def_packed(name, func)`, `def_method(name, func)`.

**Note**: The forward declaration `class Registry;` at line 538 of `function.h` remains as an orphan after this commit.

## Impact
- API: **Breaking** for any external C++ code still using `TVM_FFI_REGISTER_GLOBAL` or `Function::Registry`. All internal call sites were already migrated. External users must switch to `refl::GlobalDef().def(...)` / `refl::GlobalDef().def_packed(...)` / `refl::GlobalDef().def_method(...)`.
- Behavioral: None. The `GlobalDef` replacement calls the same `Function::SetGlobal` / `Function::FromTyped` / `Function::FromPacked` under the hood.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `Function::SetGlobal` (indirectly -- the removed `Registry::Register` method called it; `GlobalDef::RegisterFunc` calls it too) (`.knowledge/designs/0004-function-system.md`)
- `Function::FromTyped`, `Function::FromPacked` (the removed methods delegated to these; `GlobalDef` methods delegate to the same) (`.knowledge/designs/0004-function-system.md`)

Design elements this commit produces:
- None new. This commit only removes deprecated elements.

Design elements this commit **removes**:
- `Function::Registry` class -- builder API for global function registration (`.knowledge/designs/0004-function-system.md`, lines 163-176)
- `TVM_FFI_REGISTER_GLOBAL` macro -- convenience macro for `Function::Registry` construction (`.knowledge/designs/0004-function-system.md`, lines 207-212)
- `TVM_FFI_FUNC_REG_VAR_DEF` macro -- helper for variable declaration

## Usage Examples

**Before** (no longer valid after this commit):
```cpp
TVM_FFI_REGISTER_GLOBAL("testing.add")
.set_body_typed([](int a, int b) -> int { return a + b; });
```

**After** (the replacement pattern, already in use):
```cpp
refl::GlobalDef()
.def("testing.add", [](int a, int b) -> int { return a + b; });
```

For method registration:
```cpp
// Before:
TVM_FFI_REGISTER_GLOBAL("MyObj_DoWork")
.set_body_method(&MyObj::DoWork);

// After:
refl::GlobalDef()
.def_method("MyObj_DoWork", &MyObj::DoWork);
```
