# Remove Function::Registry class and TVM_FFI_REGISTER_GLOBAL macro, completing migration to GlobalDef
## TL;DR
- Deletes the `Function::Registry` inner class (135 lines) and the `TVM_FFI_REGISTER_GLOBAL` / `TVM_FFI_FUNC_REG_VAR_DEF` macros from `include/tvm/ffi/function.h`.
- This completes the migration from the macro-based global function registration pattern to the reflection-integrated `refl::GlobalDef` mechanism in `reflection/registry.h`.
- Pure deletion commit -- no new code added. All call sites were already migrated in prior commits.

## Impact
- API: **Breaking** -- removes `Function::Registry`, `TVM_FFI_REGISTER_GLOBAL`, and `TVM_FFI_FUNC_REG_VAR_DEF` from the public C++ header. Any downstream code still using `TVM_FFI_REGISTER_GLOBAL` will fail to compile. Replacement: `refl::GlobalDef().def("name", func)`.
- Behavioral: None -- `GlobalDef` already called `Function::SetGlobal` under the hood, so runtime behavior is identical.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- `Function::FromTyped` / `Function::FromPacked` / `Function::SetGlobal` -- still used internally by `GlobalDef`. See [0004-ffi-function-system.md](../design-records/0004-ffi-function-system.md).
- `ReflectionDefBase` -- parent class of `GlobalDef`, provides `GetMethod` template. See [0007-ffi-reflection.md](../design-records/0007-ffi-reflection.md).

Design elements this commit produces/mutates:
- **Mutates** the function registration design: `Function::Registry` class and `TVM_FFI_REGISTER_GLOBAL` macro are removed. `GlobalDef` (from reflection subsystem) is now the sole mechanism for global function registration.
- **Key difference**: `GlobalDef.RegisterFunc` stores `TVMFFIMethodInfo` (name, doc, schema) in the type info registry in addition to calling `Function::SetGlobal`. The old `Function::Registry` only called `Function::SetGlobal`. This means all globally registered functions now have reflection metadata.

## Usage Examples

Before (removed):
```cpp
// Old pattern -- no longer compiles after this commit
TVM_FFI_REGISTER_GLOBAL("MyAdd")
.set_body_typed([](int a, int b) -> int {
  return a + b;
});
```

After (replacement, already in use throughout codebase):
```cpp
// New pattern using GlobalDef
#include <tvm/ffi/reflection/registry.h>

namespace { using namespace tvm::ffi;
refl::GlobalDef()
  .def("MyAdd", [](int a, int b) -> int { return a + b; })
  .def_packed("MyPackedFunc", [](PackedArgs args, Any* ret) { ... })
  .def_method("MyMethod", &MyClass::DoThing);
}
```
