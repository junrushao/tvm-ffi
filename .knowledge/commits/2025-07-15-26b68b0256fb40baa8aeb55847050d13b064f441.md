# Phase out TVM_FFI_REGISTER_GLOBAL in favor of GlobalDef

## TL;DR
- Removes the `TVM_FFI_REGISTER_GLOBAL` macro and its backing `Function::Registry` class from `function.h`. These are replaced by `reflection::GlobalDef` (defined in `reflection/registry.h`), which registers global functions with richer metadata (type schema, docstrings, and custom `InfoTrait` annotations) through the `TVMFFIFunctionSetGlobalFromMethodInfo` C API.
- This is a pure deletion: 144 lines removed from `include/tvm/ffi/function.h`, no new code added.

## Key Exports

```python
# === Removed from function.h ===

# DELETED: Function::Registry class
# Previously: builder class with set_body_packed, set_body_typed, set_body_method
# Replacement: reflection::GlobalDef (in reflection/registry.h)

# DELETED: TVM_FFI_REGISTER_GLOBAL(name) macro
# Previously: created a Function::Registry at static init, chained with .set_body_typed(...)
# Replacement: reflection::GlobalDef().def("name", callable)

# DELETED: TVM_FFI_FUNC_REG_VAR_DEF helper macro
# Previously: generated the static variable declaration for TVM_FFI_REGISTER_GLOBAL
# Replacement: none needed (GlobalDef is used directly)
```

## Impact
- API: `TVM_FFI_REGISTER_GLOBAL` macro and `Function::Registry` class are removed from the public header `function.h`. All call sites must migrate to `reflection::GlobalDef().def(...)`, `GlobalDef().def_packed(...)`, or `GlobalDef().def_method(...)`.
- Behavioral: No behavioral change. `GlobalDef` uses `TVMFFIFunctionSetGlobalFromMethodInfo` which registers in the same global function registry (ultimately calling `TVMFFIFunctionSetGlobal`) but additionally records type schema metadata.
- Flags/config: No changes.
- Data formats/schemas: No changes. The global function registry ABI is unchanged.

## Design Elements

Design elements this commit consumes:
- `reflection::GlobalDef` class (already existed in `reflection/registry.h`) as the replacement mechanism
- `TVMFFIFunctionSetGlobalFromMethodInfo` C API for registering functions with metadata
- `Function::FromTyped`, `Function::FromPacked` for wrapping callables (unchanged, used by GlobalDef internally)

Design elements this commit produces:
- **GlobalDef as the sole global function registration mechanism**: The old `TVM_FFI_REGISTER_GLOBAL` macro and `Function::Registry` class are removed. All global function registration now goes through `reflection::GlobalDef`, which provides richer metadata (type schema, docstrings, custom annotations via `InfoTrait` subclasses) compared to the bare `Function::SetGlobal` used by the old `Registry`.

## Usage Examples

**Before this commit (old pattern, now removed):**
```cpp
TVM_FFI_REGISTER_GLOBAL("my.add")
.set_body_typed([](int a, int b) -> int {
    return a + b;
});
```

**After this commit (new pattern):**
```cpp
namespace refl = tvm::ffi::reflection;
refl::GlobalDef().def("my.add", [](int a, int b) -> int {
    return a + b;
});
```

**GlobalDef with packed calling convention:**
```cpp
refl::GlobalDef().def_packed("ffi.Shape", [](ffi::PackedArgs args, Any* ret) {
    // ... construct shape from packed args
});
```

**GlobalDef with method exposure:**
```cpp
refl::GlobalDef().def_method("my.Class.method", &MyClass::DoThing);
```
