# Phase out TVM_FFI_REGISTER_GLOBAL macro and Function::Registry class in favor of GlobalDef

## TL;DR
- Removes the `Function::Registry` class (135 lines) and the `TVM_FFI_REGISTER_GLOBAL` macro (plus its helper `TVM_FFI_FUNC_REG_VAR_DEF`) from `include/tvm/ffi/function.h`.
- This completes the migration started in b333288 ("[FFI] Introduce GlobalDef for function registration"): `reflection::GlobalDef` is now the sole mechanism for registering global functions.
- Pure deletion commit -- no new code is added. All internal call sites were already migrated to `GlobalDef` in the predecessor commit.

## Key Exports

**Removed classes:**
- `Function::Registry` -- Builder class that was instantiated by the `TVM_FFI_REGISTER_GLOBAL` macro. Provided `set_body_packed(f)`, `set_body_typed(f)`, and `set_body_method(&T::Method)` methods. All functionality is now covered by `reflection::GlobalDef::def_packed()`, `reflection::GlobalDef::def()`, and `reflection::GlobalDef::def_method()` respectively.

**Removed macros:**
- `TVM_FFI_REGISTER_GLOBAL(OpName)` -- Macro that declared a static `Function::Registry` and returned a reference to it, enabling chained `.set_body_*` calls. Replaced by `reflection::GlobalDef().def(...)` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- `TVM_FFI_FUNC_REG_VAR_DEF` -- Internal helper macro for `TVM_FFI_REGISTER_GLOBAL` that defined the static variable with `__COUNTER__` suffix.

**No new exports.** This is a removal-only commit.

## Impact
- API: `TVM_FFI_REGISTER_GLOBAL` and `Function::Registry` are no longer available. Any external code using these must migrate to `reflection::GlobalDef`. The equivalent pattern is:
  ```cpp
  // Old:
  TVM_FFI_REGISTER_GLOBAL("my.Add").set_body_typed([](int a, int b) { return a + b; });

  // New:
  TVM_FFI_STATIC_INIT_BLOCK({
    tvm::ffi::reflection::GlobalDef().def("my.Add", [](int a, int b) { return a + b; });
  });
  ```
- ABI: No change. The removed code was entirely C++ header-level; no C ABI symbols are affected.
- Behavioral: No runtime behavior change. `GlobalDef` registers functions through the same underlying `TVMFFIFunctionSetGlobalFromMethodInfo` / `Function::SetGlobal` path.
- Flags/config: None.

## Design Elements
Design elements this commit consumes:
- **`reflection::GlobalDef`** (introduced in b333288) -- The replacement mechanism that provides `def()`, `def_packed()`, and `def_method()` with identical functionality.
- **`TVM_FFI_STATIC_INIT_BLOCK`** -- The static initialization macro that provides the block scope for `GlobalDef` registrations.

Design elements this commit produces:
- None. This commit only removes deprecated code.

Design elements this commit retires:
- **`Function::Registry`** -- The builder class for `TVM_FFI_REGISTER_GLOBAL`. Its `set_body_typed`, `set_body_packed`, and `set_body_method` methods are replaced by `GlobalDef::def`, `GlobalDef::def_packed`, and `GlobalDef::def_method`.
- **`TVM_FFI_REGISTER_GLOBAL` macro** -- The macro-based global function registration pattern. Replaced by `reflection::GlobalDef` used inside `TVM_FFI_STATIC_INIT_BLOCK`.
- **`TVM_FFI_FUNC_REG_VAR_DEF` macro** -- Internal helper for the removed registration macro.

## Usage Examples
No new usage patterns. See the GlobalDef introduction commit (b333288) for the replacement pattern:

```cpp
#include <tvm/ffi/reflection/reflection.h>

TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("my.Add", [](int a, int b) -> int { return a + b; })
      .def("my.Sub", [](int a, int b) -> int { return a - b; });
});
```
