# Remove Function::Registry class and TVM_FFI_REGISTER_GLOBAL macro, completing migration to GlobalDef

## TL;DR
- Deletes `Function::Registry` (the chained builder returned by `TVM_FFI_REGISTER_GLOBAL`) and the `TVM_FFI_REGISTER_GLOBAL` / `TVM_FFI_FUNC_REG_VAR_DEF` macros from `include/tvm/ffi/function.h` (144 lines removed, 0 added).
- The replacement mechanism — `reflection::GlobalDef().def(...)` inside `TVM_FFI_STATIC_INIT_BLOCK(...)` — was introduced in a prior commit (`b333288`) and is already in use across `src/ffi/` and `tests/`.
- This is the final cleanup step: after this commit `TVM_FFI_REGISTER_GLOBAL` has no definition anywhere in the repo.

## Rename / Removal Mapping

| Removed symbol | Replacement | Location |
|---|---|---|
| `TVM_FFI_REGISTER_GLOBAL(name)` macro | `TVM_FFI_STATIC_INIT_BLOCK({ refl::GlobalDef().def(name, fn); })` | `include/tvm/ffi/reflection/registry.h` + `include/tvm/ffi/base_details.h` |
| `TVM_FFI_FUNC_REG_VAR_DEF` macro | `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` (already existed) | `include/tvm/ffi/base_details.h` |
| `Function::Registry` class | `reflection::GlobalDef` class | `include/tvm/ffi/reflection/registry.h` |
| `.set_body_typed(fn)` | `.def(name, fn)` | `GlobalDef::def<Func>()` |
| `.set_body_packed(fn)` | `.def_packed(name, fn)` | `GlobalDef::def_packed<Func>()` |
| `.set_body_method(&Class::method)` | `.def_method(name, &Class::method)` | `GlobalDef::def_method<Func>()` |

class GlobalDef(ReflectionDefBase):
    """Chained builder for global function registration, aligned with ObjectDef style."""

    def def_(self, name: str, func: Callable, *extra) -> GlobalDef:
        """Register a typed callable via Function::FromTyped."""
        # Interacts with: Function::FromTyped, TVMFFIFunctionSetGlobalFromMethodInfo

    def def_packed(self, name: str, func: Callable, *extra) -> GlobalDef:
        """Register a packed callable (manual AnyView* handling) via Function::FromPacked."""
        # Interacts with: Function::FromPacked, TVMFFIFunctionSetGlobalFromMethodInfo

    def def_method(self, name: str, func: MethodPtr, *extra) -> GlobalDef:
        """Expose a class method pointer as a global (inserts self as first arg)."""
        # Interacts with: ReflectionDefBase::GetMethod_, TVMFFIFunctionSetGlobalFromMethodInfo

# REPLACEMENT invocation idiom (from include/tvm/ffi/base_details.h):
# TVM_FFI_STATIC_INIT_BLOCK({ refl::GlobalDef().def("name", fn); })
# Expands to:
#   static inline int __TVMFFIStaticInitReg<N> = ([]() { refl::GlobalDef().def(...); return 0; })()
# Invariant: runs before main(); same lifetime guarantee as TVM_FFI_REGISTER_GLOBAL
# Interacts with: GlobalDef::RegisterFunc → TVMFFIFunctionSetGlobalFromMethodInfo (C ABI)

## Impact
- API: **Breaking for C++ callers** — any code using `TVM_FFI_REGISTER_GLOBAL(...).set_body_typed/packed/method(...)` will fail to compile after this commit. Migration is mechanical (see mapping table above).
- Behavioral: None — the underlying `Function::SetGlobal` path and global registry are unchanged; `GlobalDef::RegisterFunc` calls `TVMFFIFunctionSetGlobalFromMethodInfo` which ultimately routes through the same `GlobalFunctionTable`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `0004-function-system` — uses `Function::FromTyped`, `Function::FromPacked`, `Function::SetGlobal` internally within `GlobalDef`; the packed calling convention and global registry are unchanged.
- `0001-c-abi` — `TVMFFIFunctionSetGlobalFromMethodInfo` is the new C ABI call used by `GlobalDef::RegisterFunc`.

Design elements this commit produces:
- Removes `Function::Registry` and `TVM_FFI_REGISTER_GLOBAL` as design elements from the function system. The canonical registration idiom is now `TVM_FFI_STATIC_INIT_BLOCK` + `GlobalDef`.
- Consolidates the registration pattern under `include/tvm/ffi/reflection/registry.h` (not `function.h`).

## Usage Examples

**Before** (deleted):
```cpp
// include/tvm/ffi/function.h — now removed
TVM_FFI_REGISTER_GLOBAL("my.add")
.set_body_typed([](int a, int b) -> int { return a + b; });

TVM_FFI_REGISTER_GLOBAL("Example_DoThing")
.set_body_method(&Example::DoThing);
```

**After** (replacement pattern, from `src/ffi/function.cc` and `tests/cpp/testing_object.h`):
```cpp
// src/ffi/function.cc
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("ffi.FunctionRemoveGlobal",
           [](const tvm::ffi::String& name) -> bool {
             return tvm::ffi::GlobalFunctionTable::Global()->Remove(name);
           })
      .def("ffi.String", [](tvm::ffi::String val) -> tvm::ffi::String { return val; });
});

// tests/cpp/testing_object.h
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def_method("testing.Int_GetValue", &TIntObj::GetValue);
});
```
