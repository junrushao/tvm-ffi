# Add reflection-based serialization to/from JSON object graph with base64 encoding

## TL;DR
- Introduces `ToJSONGraph` and `FromJSONGraph` functions that serialize/deserialize arbitrary `ffi::Any` values into a JSON object graph format, preserving type information, object sharing (DAG structure), and multi-reference deduplication.
- Adds `Base64Encode`/`Base64Decode` utility functions for encoding `Bytes` content in the JSON graph.
- Leverages the existing reflection system (`ForEachFieldInfo`, `FieldGetter`/`FieldSetter`, `TVMFFITypeMetadata::creator`) for automatic field-by-field serialization of registered object types, with custom `__data_to_json__`/`__data_from_json__` TypeAttr callbacks for per-type overrides.
- Registers two new TypeAttr columns (`__data_to_json__`, `__data_from_json__`) and two global functions (`ffi.ToJSONGraph`, `ffi.FromJSONGraph`).

## Key Exports

### Functions (`include/tvm/ffi/extra/serialization.h`)

- `TVM_FFI_EXTRA_CXX_API json::Value ToJSONGraph(const Any& value, const Any& metadata = Any(nullptr))` -- Serialize any FFI value to a JSON object graph. The result has the structure `{"root_index": <int>, "nodes": [<node>...], "metadata": <object>}`. Each node is `{"type": "<type_key>", "data": <type_data>}`. Primitive-typed object fields are inlined; non-primitive fields use node index references. Shared objects are deduplicated via `Map<Any, int64_t>`.
- `TVM_FFI_EXTRA_CXX_API Any FromJSONGraph(const json::Value& value)` -- Deserialize a JSON object graph back to an `ffi::Any` value. Supports lazy node decoding and arbitrary node ordering. Requires `TVMFFITypeMetadata::creator` for object types (default-constructible types).

### Functions (`include/tvm/ffi/extra/base64.h`)

- `inline String Base64Encode(TVMFFIByteArray bytes)` -- Encode a byte array to a base64 string.
- `inline String Base64Encode(const Bytes& data)` -- Convenience overload.
- `inline Bytes Base64Decode(TVMFFIByteArray bytes)` -- Decode a base64 string to a `Bytes` object.
- `inline Bytes Base64Decode(const String& data)` -- Convenience overload.

### TypeAttr Columns (`src/ffi/extra/serialization.cc`)

- `__data_to_json__` -- Per-type custom serialization callback: `(const TObj*) -> json::Object`. When present, called instead of reflection-based field walking.
- `__data_from_json__` -- Per-type custom deserialization callback: `(json::Value) -> Any`. When present, called instead of reflection-based field setting.

### Global Functions

- `ffi.ToJSONGraph` -- Global function wrapping `ToJSONGraph`.
- `ffi.FromJSONGraph` -- Global function wrapping `FromJSONGraph`.

## Impact
- API: Two new public C++ functions (`ToJSONGraph`, `FromJSONGraph`) and two new global functions. No existing API is changed.
- ABI: None -- all additions are in the `extra/` optional API layer.
- Behavioral: `TFuncObj::comment` field type changed from `String` to `Optional<String>` in test helpers; `TVarObj` and `TFuncObj` gain default constructors. These are test-only types.
- Flags/config: Gated by existing `TVM_FFI_USE_EXTRA_CXX_API` CMake flag.
- Data formats/schemas: Introduces the JSON object graph schema: `{"root_index": int, "nodes": [{"type": str, "data": ...}], "metadata": any}`.

## Design Elements

Design elements this commit consumes:
- **Reflection field iteration** (`ForEachFieldInfo`, `FieldGetter`, `FieldSetter`): Used to walk object fields during serialization and deserialization. See `.knowledge/designs/reflection.md`.
- **TypeAttr system** (`TypeAttrColumn`, `TypeAttrDef`, `EnsureTypeAttrColumn`): Used for custom `__data_to_json__`/`__data_from_json__` per-type callbacks, following the same pattern as `__s_equal__`/`__s_hash__`. See `.knowledge/designs/reflection.md` (TypeAttr System section).
- **TVMFFITypeMetadata::creator**: Used by `FromJSONGraph` to create empty object instances before setting fields. See `.knowledge/designs/reflection.md`.
- **TypeIndex switch dispatch**: Serializer and deserializer switch on `value.type_index()` to handle each built-in type (None, Bool, Int, Float, DataType, Device, Str, Bytes, Array, Map, and Object types >= `kTVMFFIStaticObjectBegin`). See `.knowledge/designs/any-system.md` and `.knowledge/designs/type-traits.md`.
- **json::Value/json::Object/json::Array**: The JSON DOM types from `extra/json.h` used for both the output format and the custom callback interface.
- **`field_static_type_index`**: Used during object field serialization to determine whether a field value is stored inline (primitives: Bool, Int, Float, DataType) or as a node reference (non-primitives). See `TVMFFIFieldInfo` in `.knowledge/designs/reflection.md`.
- **`Map<Any, int64_t>`**: Used as the node deduplication map (`node_index_map_`) during serialization. Relies on `AnyHash`/`AnyEqual` for identity-based lookup. See `.knowledge/designs/containers.md`.

Design elements this commit produces:
- **JSON object graph schema**: A new serialization format `{"root_index": int, "nodes": [...], "metadata": ...}` that preserves type information and object sharing. Each node is `{"type": "<type_key>", "data": <...>}`.
- **`__data_to_json__`/`__data_from_json__` TypeAttr protocol**: A new per-type hook for custom serialization, analogous to `__s_equal__`/`__s_hash__` for structural comparison. Presence-based dispatch: if the TypeAttr column entry is non-null, the custom function is used; otherwise, reflection-based field walking is the default.
- **Base64 encoding/decoding utilities**: `Base64Encode`/`Base64Decode` inline functions for `Bytes` serialization.
- **`ObjectGraphSerializer`/`ObjectGraphDeserializer` internal classes**: Encapsulate the serialize/deserialize logic. `ObjectGraphSerializer` does DAG-aware node deduplication via `Map<Any, int64_t>`. `ObjectGraphDeserializer` supports lazy node decoding and arbitrary node ordering.

## Usage Examples

### Serializing and deserializing a simple value
**Context**: Round-tripping an FFI value through JSON.
```cpp
#include <tvm/ffi/extra/serialization.h>

// Serialize
json::Value encoded = ToJSONGraph(String("hello"));
// encoded: {"root_index": 0, "nodes": [{"type": "ffi.String", "data": "hello"}]}

// Deserialize
Any decoded = FromJSONGraph(encoded);
// decoded is String("hello")
```

### Custom serialization for a type
**Context**: Registering `__data_to_json__`/`__data_from_json__` for a type that needs non-standard JSON representation.
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::TypeAttrDef<TIntObj>()
      .def("__data_to_json__",
           [](const TIntObj* self) -> Map<String, Any> {
             return Map<String, Any>{{"value", self->value}};
           })
      .def("__data_from_json__", [](Map<String, Any> json_obj) -> TInt {
        return TInt(json_obj["value"].cast<int64_t>());
      });
});
```

### Serializing an object graph with shared references
**Context**: Demonstrating deduplication of shared objects.
```cpp
TVar x = TVar("x");
TFunc f({x}, {x, x}, String("comment"));
json::Value encoded = ToJSONGraph(f);
// The string "x" and TVar(x) each appear once in the nodes array;
// the body array references the same TVar node index twice.
```
