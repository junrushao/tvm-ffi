# Add reflection-based JSON object graph serialization/deserialization
## TL;DR
- Introduces `ToJSONGraph` and `FromJSONGraph` for serializing/deserializing arbitrary `Any` values (including full object graphs with shared references) to/from a JSON node-indexed format.
- Adds `Base64Encode`/`Base64Decode` utilities for `Bytes` serialization within the JSON graph.
- Supports custom per-type serialization via `__data_to_json__`/`__data_from_json__` TypeAttr columns, with automatic reflection-based fallback for all reflected types.

## Impact
- API: Two new public C++ functions (`ToJSONGraph`, `FromJSONGraph`), two global FFI functions (`ffi.ToJSONGraph`, `ffi.FromJSONGraph`), base64 utilities. Purely additive.
- Behavioral: none -- no existing functions changed
- Flags/config: none
- Data formats/schemas: Introduces JSON object graph format: `{"root_index": int, "nodes": [{"type": str, "data": ...}], "metadata": ...}`. Primitive fields are stored inline; object/container fields stored as node indices. Bytes are base64-encoded.

## Design Elements
Design elements this commit consumes:
- **Any/AnyView value system** (0001): `Any` is the input/output type; type_index dispatch for serialization of all value kinds
- **Object system** (0002): Object pointers, `ObjectRef`, `ObjectPtr`, default constructors for deserialization
- **Containers** (0006): `Array<Any>`, `Map<Any,Any>`, `String`, `Bytes` -- serialized as array-of-indices and key-value-index pairs
- **Reflection** (0008): `ForEachFieldInfo`, `FieldGetter`, `TVMFFIFieldInfo.setter`, `TVMFFITypeInfo.metadata.creator` -- the core mechanism for walking object fields without compile-time knowledge
- **TypeAttr columns** (0008): `TypeAttrColumn("__data_to_json__"/"__data_from_json__")` for custom serialization hooks; `EnsureTypeAttrColumn` to register column names
- **JSON utilities** (`include/tvm/ffi/extra/json.h`): `json::Value`, `json::Object`, `json::Array` for the output format
- **C ABI** (0007): `TVMFFIFieldInfo.field_static_type_index` used to distinguish inline-storable primitive fields from reference fields; `TVMFFITypeInfo.metadata` for type metadata and creator

Design elements this commit produces:
- **JSON object graph format**: A node-indexed graph representation where shared object references are deduplicated. Each node is `{"type": key, "data": type_data}`. Root is identified by `root_index`.
- **`__data_to_json__` / `__data_from_json__` TypeAttr protocol**: Per-type custom serialization hooks registered via `TypeAttrDef`. When present, bypasses automatic reflection-based field walking.
- **Base64 encode/decode** (`include/tvm/ffi/extra/base64.h`): Header-only utilities for encoding `Bytes`/`TVMFFIByteArray` to/from base64 strings.

## Usage Examples
Serializing and deserializing a reflected object (from `test_serialization.cc`):
```cpp
// Define a variable object with reflection
TVar x = TVar("x");
// Serialize to JSON graph
json::Value serialized = ToJSONGraph(x);
// Result: {"root_index": 1, "nodes": [
//   {"type": "ffi.String", "data": "x"},
//   {"type": "test.Var", "data": {"name": 0}}  // 0 = index into nodes
// ]}

// Deserialize back
Any deserialized = FromJSONGraph(serialized);
// deserialized is structurally equal to x

// Custom serialization via __data_to_json__ / __data_from_json__:
refl::TypeAttrDef<TIntObj>()
    .def("__data_to_json__",
         [](const TIntObj* self) -> Map<String, Any> {
           return Map<String, Any>{{"value", self->value}};
         })
    .def("__data_from_json__", [](Map<String, Any> json_obj) -> TInt {
      return TInt(json_obj["value"].cast<int64_t>());
    });
```
