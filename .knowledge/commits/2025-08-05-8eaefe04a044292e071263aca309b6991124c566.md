# Add reflection-based ToJSONGraph/FromJSONGraph serialization to the extra/ subsystem

## TL;DR
- Adds `ToJSONGraph`/`FromJSONGraph` (C++ and global `"ffi.ToJSONGraph"`/`"ffi.FromJSONGraph"`) that serialize any `ffi::Any` value to/from a JSON node-array graph, preserving shared object identity (DAG structure) and type information via the string type key.
- Adds `include/tvm/ffi/extra/base64.h` with inline `Base64Encode`/`Base64Decode` helpers for `Bytes` fields, enabling safe JSON embedding of arbitrary binary data.
- Introduces the `__data_to_json__` / `__data_from_json__` `TypeAttrColumn` protocol as a custom serialization escape hatch, and requires a zero-argument default constructor (`TVMFFITypeMetadata.creator`) on every object type that participates in deserialization.

## Key Exports

## Impact
- API: New public symbols `ToJSONGraph`/`FromJSONGraph` exported from `libtvm_ffi_extra` (`TVM_FFI_EXTRA_CXX_API`). New global functions `"ffi.ToJSONGraph"` and `"ffi.FromJSONGraph"` registered in the global function table. New `base64.h` header (header-only, no ABI change). New `TypeAttrColumn` names `"__data_to_json__"`/`"__data_from_json__"` pre-created at static init time.
- Behavioral: None to existing APIs. `TFuncObj::comment` field type changed from `String` to `Optional<String>` in the test fixture (`testing_object.h`) — breaking change to test helpers only, not a public API.
- Flags/config: `src/ffi/extra/serialization.cc` added to `CMakeLists.txt` under `TVM_FFI_USE_EXTRA_CXX_API` guard.
- Data formats/schemas: New JSON wire format defined: `{"root_index": <int>, "nodes": [{"type": "<type_key>", "data": ...}], "metadata": ...}`. Primitive fields inlined; object/container fields stored as node indices. `Bytes` fields stored as base64. `DLDataType` stored as human-readable string (e.g., `"float32"`). `DLDevice` stored as `[device_type, device_id]` int array.

- **serialization API**: `ToJSONGraph`/`FromJSONGraph` pair with the JSON-graph wire format

## Usage Examples

**Serialize and round-trip a complex object graph:**
```cpp
#include <tvm/ffi/extra/serialization.h>

// Given a TFunc node with shared sub-objects:
TVar x = TVar("x");
TFunc fa = TFunc({x}, {x, x}, String("comment"));

// Serialize — shared 'x' appears once in nodes[], referenced by index twice
json::Value serialized = ToJSONGraph(fa);
// serialized["root_index"] == 5
// serialized["nodes"][1] == {"type": "test.Var", "data": {"name": 0}}  (x)
// serialized["nodes"][5]["data"]["params"] == index_of(array[x])
// serialized["nodes"][5]["data"]["body"]   == index_of(array[x, x])

// Round-trip
Any recovered = FromJSONGraph(serialized);
EXPECT_TRUE(StructuralEqual()(FromJSONGraph(serialized), fa));
```

**Register custom JSON serialization for a type:**
```cpp
// In testing_object.h, TIntObj overrides default field-walk with explicit data shape:
refl::TypeAttrDef<TIntObj>()
    .def("__data_to_json__",
         [](const TIntObj* self) -> Map<String, Any> {
             return Map<String, Any>{{"value", self->value}};
         })
    .def("__data_from_json__", [](Map<String, Any> json_obj) -> TInt {
        return TInt(json_obj["value"].cast<int64_t>());
    });
// Without these, serializer falls back to ForEachFieldInfo field walk.
```

**Attach metadata to a serialized graph:**
```cpp
json::Object metadata{{"version", "1.0"}, {"target", "cuda"}};
json::Value result = ToJSONGraph(my_module, metadata);
// result["metadata"] == {"version": "1.0", "target": "cuda"}
// metadata is ignored by FromJSONGraph (caller reads it manually)
```
