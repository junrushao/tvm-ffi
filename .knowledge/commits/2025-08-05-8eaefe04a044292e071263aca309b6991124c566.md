# Add reflection-based JSON object graph serialization (ToJSONGraph/FromJSONGraph) and Base64 utilities
## TL;DR
- Introduces `ToJSONGraph` / `FromJSONGraph`: a reflection-driven serialization round-trip that converts any `ffi::Any` value to/from a JSON object graph with node deduplication and type preservation.
- Adds `Base64Encode` / `Base64Decode` utilities for binary (`Bytes`) data within the serialized JSON.
- Establishes `__data_to_json__` / `__data_from_json__` TypeAttrColumn protocol for per-type custom JSON serialization, with the test `TIntObj` serving as the reference implementation.

## Impact
- API: New public C++ API in `tvm::ffi` namespace (`ToJSONGraph`, `FromJSONGraph`, `Base64Encode`, `Base64Decode`). New global functions `ffi.ToJSONGraph` and `ffi.FromJSONGraph` registered in the packed function registry. No existing APIs changed.
- Behavioral: None -- purely additive.
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` CMake flag must be enabled (was already guarding other `extra/` sources).
- Data formats/schemas: New JSON object graph format with structure `{"root_index": int, "nodes": [...], "metadata": ...}`. Each node has `{"type": "<type_key>", "data": <payload>}`. Primitive fields inlined; object/container fields stored as node indices.

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`ForEachFieldInfo`, `FieldGetter`, `FieldSetter`, `TVMFFIFieldInfo`, `TVMFFITypeInfo.metadata`, `TVMFFITypeMetadata.creator`) -- the serializer iterates reflected fields to serialize/deserialize objects generically. See `.knowledge/designs/0008-reflection.md`.
- **TypeAttrColumn / TypeAttrDef** -- used for `__data_to_json__` / `__data_from_json__` custom dispatch, same pattern as `__s_equal__`/`__s_hash__` in structural equality. See `.knowledge/designs/0008-reflection.md`.
- **Container types** (`Array<T>`, `Map<K,V>`, `String`, `Bytes`) -- serialized/deserialized as first-class node types. See `.knowledge/designs/0007-containers.md`.
- **Any/AnyView type erasure** -- `node_index_map_` uses `Map<Any, int64_t>` for identity-based deduplication via `Any` equality. See `.knowledge/designs/0003-any-system.md`.
- **json::Value / json::Object / json::Array** -- the JSON DOM used as the serialization target format (`include/tvm/ffi/extra/json.h`).
- **StructuralEqual** -- tests use `StructuralEqual()` to verify round-trip correctness. See `.knowledge/designs/0009-structural-equal-hash.md`.
- **Object default constructor** -- deserializer requires `TVMFFITypeMetadata.creator` (default constructor) for object types. Test objects `TVarObj` and `TFuncObj` gain explicit default constructors for this purpose.

Design elements this commit produces:
- **JSON object graph serialization protocol** -- a graph-based serialization format that preserves object identity (deduplication via node indices), type keys, and supports all FFI primitive types + containers + reflected objects.
- **`__data_to_json__` / `__data_from_json__` TypeAttrColumn protocol** -- per-type custom serialization hooks, analogous to `__s_equal__`/`__s_hash__` for structural equality.
- **Base64 encode/decode utilities** -- header-only implementation in `include/tvm/ffi/extra/base64.h`.

## Usage Examples

Serializing and deserializing a reflected object (from `test_serialization.cc`):
```cpp
// A reflected variable type with field "name"
TVar x = TVar("x");

// Serialize to JSON graph
json::Value graph = ToJSONGraph(x);
// Result: {"root_index": 1, "nodes": [
//   {"type": "ffi.String", "data": "x"},
//   {"type": "test.Var", "data": {"name": 0}}   // 0 = index into nodes
// ]}

// Deserialize back
Any restored = FromJSONGraph(graph);
EXPECT_TRUE(StructuralEqual::Equal(restored, x, /*map_free_vars=*/true));

// Custom per-type serialization (TIntObj registers __data_to_json__/__data_from_json__):
TInt value = TInt(42);
json::Value int_graph = ToJSONGraph(value);
// Result: {"root_index": 0, "nodes": [
//   {"type": "test.Int", "data": {"value": 42}}  // custom format
// ]}

// Attach metadata
json::Value with_meta = ToJSONGraph(true, json::Object{{"version", "1.0"}});
// Result: {"root_index": 0, "nodes": [...], "metadata": {"version": "1.0"}}
```
