# Add reflection-based JSON graph serialization and base64 utilities
## TL;DR
- Introduces `ToJSONGraph`/`FromJSONGraph` for reflection-driven serialization of `Any` values into a JSON object graph with node deduplication and shared reference preservation.
- Adds `Base64Encode`/`Base64Decode` inline utilities for `Bytes`/`TVMFFIByteArray`.
- Establishes `__data_to_json__`/`__data_from_json__` TypeAttr columns for per-type custom JSON serialization, following the same pattern as `__s_equal__`/`__s_hash__`.
- Testing objects updated: `TFuncObj.comment` changed to `Optional<String>`, `TVarObj`/`TFuncObj` gain default constructors for deserialization support.

## Impact
- API: New public functions `ToJSONGraph`, `FromJSONGraph`, `Base64Encode`, `Base64Decode` in `tvm::ffi` namespace. New global functions `ffi.ToJSONGraph`, `ffi.FromJSONGraph`.
- Behavioral: Testing object `TFuncObj.comment` changed from `String` to `Optional<String>` -- callers must wrap string arguments in `String()` or pass `std::nullopt`. `TVarObj`/`TFuncObj` gain default constructors (previously only parameterized).
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` CMake flag gates compilation of `serialization.cc`.
- Data formats/schemas: Defines the JSON object graph format with `root_index`/`nodes`/`metadata` structure.

## Design Elements
Design elements this commit consumes:
- **Reflection field iteration** (`ForEachFieldInfo`, `FieldGetter`, `FieldSetter`) -- walks registered fields for serialization/deserialization. See [0007-ffi-reflection.md](../design-records/0007-ffi-reflection.md).
- **TypeAttr column system** (`TypeAttrDef`, `TypeAttrColumn`, `EnsureTypeAttrColumn`) -- custom per-type dispatch for `__data_to_json__`/`__data_from_json__`. See [0007-ffi-reflection.md](../design-records/0007-ffi-reflection.md).
- **TVMFFITypeMetadata.creator** -- default-constructs objects during deserialization. See [0007-ffi-reflection.md](../design-records/0007-ffi-reflection.md).
- **TVMFFIFieldInfo.field_static_type_index** -- determines whether a field is inlined (primitive) or stored as a node reference (object/container). See [0007-ffi-reflection.md](../design-records/0007-ffi-reflection.md).
- **Global function registration** (`refl::GlobalDef`) -- registers `ffi.ToJSONGraph` and `ffi.FromJSONGraph`. See [0004-ffi-function-system.md](../design-records/0004-ffi-function-system.md).
- **Containers** (`Array`, `Map`, `String`, `Bytes`) -- serialized/deserialized as first-class node types. See [0006-ffi-containers.md](../design-records/0006-ffi-containers.md).
- **JSON utilities** (`json::Value`, `json::Object`, `json::Array`) -- output/input format.
- **StructuralEqual** -- used in tests to verify round-trip correctness. See [0009-ffi-structural-eq-hash.md](../design-records/0009-ffi-structural-eq-hash.md).

Design elements this commit produces:
- **JSON object graph format** -- `{"root_index": int, "nodes": [...], "metadata": ...}` with per-node `{"type": "<key>", "data": <data>}` structure. Primitive fields inlined, non-primitive stored as node index references.
- **`__data_to_json__` / `__data_from_json__` TypeAttr columns** -- per-type custom serialization hooks, following the same TypeAttrColumn pattern as `__s_equal__`/`__s_hash__`.
- **`ObjectGraphSerializer` / `ObjectGraphDeserializer`** internal classes -- implement the graph walk with `Map<Any, int64_t>` node deduplication (serializer) and lazy `decoded_nodes_` array (deserializer).
- **Base64 encode/decode utilities** -- standalone inline functions in `base64.h`.

## Usage Examples
**Round-trip serialization of a reflected object (from test_serialization.cc)**:
```cpp
// Define a test variable and function
TVar x = TVar("x");
TFunc fa = TFunc({x}, {x, x}, String("comment a"));

// Serialize to JSON graph
json::Value serialized = ToJSONGraph(fa);
// Result:
// {"root_index": 5, "nodes": [
//   {"type": "ffi.String", "data": "x"},
//   {"type": "test.Var", "data": {"name": 0}},       // "name" -> node index 0
//   {"type": "ffi.Array", "data": [1]},               // [var x]
//   {"type": "ffi.Array", "data": [1, 1]},            // [var x, var x] -- shared ref
//   {"type": "ffi.String", "data": "comment a"},
//   {"type": "test.Func", "data": {"params": 2, "body": 3, "comment": 4}}
// ]}

// Deserialize back
Any deserialized = FromJSONGraph(serialized);
StructuralEqual()(deserialized, fa);  // true
```

**Custom per-type JSON serialization (from testing_object.h)**:
```cpp
// Register custom __data_to_json__ / __data_from_json__ for TIntObj
refl::TypeAttrDef<TIntObj>()
    .def("__data_to_json__",
         [](const TIntObj* self) -> Map<String, Any> {
           return Map<String, Any>{{"value", self->value}};
         })
    .def("__data_from_json__", [](Map<String, Any> json_obj) -> TInt {
      return TInt(json_obj["value"].cast<int64_t>());
    });

// Usage: TInt(42) serializes as {"type": "test.Int", "data": {"value": 42}}
```
