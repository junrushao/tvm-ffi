# Add reflection-based JSONGraph serialization and base64 utilities
## TL;DR
- Introduces `ToJSONGraph` / `FromJSONGraph` for serializing arbitrary `ffi::Any` values into a JSON object-graph format that preserves type information, shared references, and supports round-tripping.
- Adds `Base64Encode` / `Base64Decode` inline utilities for encoding `Bytes` and `TVMFFIByteArray` to/from base64 strings.
- Extends the `TypeAttrColumn` mechanism with `__data_to_json__` / `__data_from_json__` columns for custom per-type serialization hooks.

## Key Exports

**Functions**:
- `tvm::ffi::ToJSONGraph(const Any& value, const Any& metadata = Any(nullptr)) -> json::Value` -- Serializes any `ffi::Any` value into a JSON object graph. Registered globally as `"ffi.ToJSONGraph"`.
- `tvm::ffi::FromJSONGraph(const json::Value& value) -> Any` -- Deserializes a JSON object graph back to an `ffi::Any` value. Registered globally as `"ffi.FromJSONGraph"`.
- `tvm::ffi::Base64Encode(TVMFFIByteArray bytes) -> String` -- Encodes a byte array to base64.
- `tvm::ffi::Base64Encode(const Bytes& data) -> String` -- Overload for `Bytes`.
- `tvm::ffi::Base64Decode(TVMFFIByteArray bytes) -> Bytes` -- Decodes a base64 string to `Bytes`.
- `tvm::ffi::Base64Decode(const String& data) -> Bytes` -- Overload for `String`.

**TypeAttr Columns** (created via `EnsureTypeAttrColumn`):
- `"__data_to_json__"` -- Per-type custom serializer: `Function(const Object*) -> json::Object`.
- `"__data_from_json__"` -- Per-type custom deserializer: `Function(json::Value) -> Any`.

**JSON Object Graph Format**:
```json
{
  "root_index": <int>,
  "nodes": [{"type": "<type_key>", "data": <type_data>}, ...],
  "metadata": <object>  // optional
}
```

**Type-to-node encoding**:

| Type key | `data` encoding |
|----------|----------------|
| `None` | (absent) |
| `bool` | JSON boolean |
| `int` | JSON integer |
| `float` | JSON float |
| `DataType` | string (e.g. `"int32"`, `"float64"`) |
| `Device` | `[device_type, device_id]` array |
| `ffi.String` | JSON string |
| `ffi.Bytes` | base64-encoded string |
| `ffi.Array` | array of node indices |
| `ffi.Map` | flat array of alternating key/value node indices |
| (Object) | JSON object with field names as keys; primitive fields inline, object fields as node indices |

## Impact
- API: New public functions `ToJSONGraph`, `FromJSONGraph`, `Base64Encode`, `Base64Decode`. New global functions `"ffi.ToJSONGraph"`, `"ffi.FromJSONGraph"`.
- Behavioral: none -- all new functionality.
- Flags/config: Gated by `TVM_FFI_USE_EXTRA_CXX_API` CMake option (serialization.cc added to extra sources).
- Data formats/schemas: Introduces the JSONGraph format as described above.

- **Base64 utilities** (`Base64Encode`, `Base64Decode`) -- new inline utilities in `extra/base64.h`.

## Usage Examples

### Serializing and deserializing an object graph
**Context**: Round-tripping a composite object through JSONGraph.
```cpp
#include <tvm/ffi/extra/serialization.h>
using namespace tvm::ffi;

// Serialize
Array<Any> arr;
arr.push_back(42);
arr.push_back(String("hello"));
json::Value graph = ToJSONGraph(arr);

// Deserialize
Any restored = FromJSONGraph(graph);
Array<Any> restored_arr = restored.cast<Array<Any>>();
// restored_arr[0] == 42, restored_arr[1] == "hello"
```

### Custom per-type JSON serialization
**Context**: Registering `__data_to_json__` and `__data_from_json__` for a type that needs non-reflection-based serialization.
```cpp
refl::TypeAttrDef<TIntObj>()
    .def("__data_to_json__",
         [](const TIntObj* self) -> Map<String, Any> {
           return Map<String, Any>{{"value", self->value}};
         })
    .def("__data_from_json__", [](Map<String, Any> json_obj) -> TInt {
      return TInt(json_obj["value"].cast<int64_t>());
    });
```

### Base64 encoding/decoding
```cpp
#include <tvm/ffi/extra/base64.h>
using namespace tvm::ffi;

String encoded = Base64Encode(Bytes("abcd"));  // "YWJjZA=="
Bytes decoded = Base64Decode(encoded);          // "abcd"
```
