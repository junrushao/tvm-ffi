# Generalize reflection field registration to support inherited fields and add generic enum TypeTraits
## TL;DR
- `ObjectDef::def_ro`/`def_rw`/`RegisterField` now accept member pointers to base class fields (`T BaseClass::*` instead of `T Class::*`), enabling registration of inherited fields with a `static_assert(is_base_of_v<BaseClass, Class>)` safety check.
- Adds a generic `TypeTraits<IntEnum>` partial specialization for all `enum class` types with integral underlying types, eliminating the need for per-enum manual specializations.
- Test added for enum round-trip through `AnyView`.

Note: The commit message mentions "Transition VisitAttrs to new reflection mechanism in tir/ir_builder/meta_schedule" but the diff only contains the FFI-level enablers (no tir/ir_builder/meta_schedule files). The upstream TVM changes are likely in a separate repo.

## Key Exports

```python
# === Change 1: Reflection field registration generalized to inherited fields ===

class ObjectDef(Generic[Class]):
    """Builder for registering reflection fields on an object type."""

    # OLD: def_ro(name: str, field_ptr: MemberPtr[Class, T]) -> ObjectDef
    # NEW: def_ro(name: str, field_ptr: MemberPtr[BaseClass, T]) -> ObjectDef
    def def_ro(self, name: str, field_ptr: "MemberPtr[BaseClass, T]") -> "ObjectDef[Class]": ...
        # Invariant: BaseClass must be a base class of Class (static_assert enforced)
        # Interacts with: RegisterField, TypeToFieldStaticTypeIndex<T>

    # OLD: def_rw(name: str, field_ptr: MemberPtr[Class, T]) -> ObjectDef
    # NEW: def_rw(name: str, field_ptr: MemberPtr[BaseClass, T]) -> ObjectDef
    def def_rw(self, name: str, field_ptr: "MemberPtr[BaseClass, T]") -> "ObjectDef[Class]": ...
        # Invariant: BaseClass must be a base class of Class (static_assert enforced)
        # Invariant: Class._type_mutable must be True
        # Interacts with: RegisterField

    def RegisterField(self, name: str, field_ptr: "MemberPtr[BaseClass, T]", writable: bool) -> None: ...
        # Invariant: static_assert(is_base_of_v<BaseClass, Class>)
        # Extension: enables registering parent class fields without re-declaring them


# === Change 2: Generic enum TypeTraits ===

class TypeTraits(Generic[IntEnum]):
    """Automatic TypeTraits for any enum class with integral underlying type."""
    # Enabled when: is_enum_v<IntEnum> AND is_integral_v<underlying_type_t<IntEnum>>
    field_static_type_index: int = TypeIndex.kTVMFFIInt

    @staticmethod
    def CopyToAnyView(src: IntEnum, result: "Ptr[TVMFFIAny]") -> None: ...
        # result.type_index = kTVMFFIInt; result.v_int64 = int(src)

    @staticmethod
    def MoveToAny(src: IntEnum, result: "Ptr[TVMFFIAny]") -> None: ...
        # Same as CopyToAnyView (POD type)

    @staticmethod
    def CheckAnyStrict(src: "Ptr[TVMFFIAny]") -> bool: ...
        # Returns src.type_index == kTVMFFIInt
        # Invariant: strict -- only matches kTVMFFIInt, not kTVMFFIBool

    @staticmethod
    def CopyFromAnyViewAfterCheck(src: "Ptr[TVMFFIAny]") -> IntEnum: ...
        # Returns IntEnum(src.v_int64)

    @staticmethod
    def MoveFromAnyAfterCheck(src: "Ptr[TVMFFIAny]") -> IntEnum: ...
        # Same as CopyFromAnyViewAfterCheck (POD type)

    @staticmethod
    def TryCastFromAnyView(src: "Ptr[TVMFFIAny]") -> "Optional[IntEnum]": ...
        # Accepts kTVMFFIInt OR kTVMFFIBool (implicit widening from bool)
        # Returns IntEnum(src.v_int64)
        # Interacts with: AnyView.cast<IntEnum>(), Any.cast<IntEnum>()

    @staticmethod
    def TypeStr() -> str: ...
        # Returns "int" (same as integer types)
```

## Impact
- API: Additive -- `def_ro`/`def_rw` now accept a wider set of member pointers (base class fields). Existing code using direct-class member pointers remains valid.
- Behavioral: Enum class types now automatically participate in FFI without manual `TypeTraits` specialization. Any existing manual enum specializations would conflict with the new partial specialization (SFINAE overlap).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeTraits protocol** ([0006-type-traits.md](../designs/0006-type-traits.md)): The enum specialization follows the established `TypeTraitsBase` protocol pattern, implementing `CheckAnyStrict`, `CopyToAnyView`, `MoveToAny`, `CopyFromAnyViewAfterCheck`, `MoveFromAnyAfterCheck`, `TryCastFromAnyView`, `TypeStr`.
- **Reflection field registration** ([0008-reflection.md](../designs/0008-reflection.md)): `ObjectDef::RegisterField` computes byte offsets and registers getter/setter; this commit generalizes the member pointer parameter.
- **Any/AnyView value containers** ([0003-any-system.md](../designs/0003-any-system.md)): Enum values stored as `kTVMFFIInt` in the 16-byte `TVMFFIAny` representation.

Design elements this commit produces:
- **Generic enum TypeTraits**: A new SFINAE-based partial specialization matching all `enum class` types with integral underlying types. This is a new extension pattern for the TypeTraits system -- instead of per-type manual specialization, a blanket specialization covers a category of types.
- **Inherited field reflection**: The ability to register parent-class fields in a child class's reflection definition is a new capability of the reflection system.

## Usage Examples

**Enum round-trip through AnyView** (from test):
```cpp
enum class ENum : int { A = 1, B = 2 };

// Enum -> AnyView (automatic via generic TypeTraits)
AnyView view = ENum::A;
assert(view.CopyToTVMFFIAny().type_index == TypeIndex::kTVMFFIInt);
assert(view.CopyToTVMFFIAny().v_int64 == 1);

// AnyView -> Enum (cast uses TryCastFromAnyView)
ENum v = view.cast<ENum>();
assert(v == ENum::A);
```

**Registering inherited fields** (enabled pattern):
```cpp
class BaseObj : public Object {
 public:
  int64_t base_field;
  // ...
};

class DerivedObj : public BaseObj {
 public:
  String extra;
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(DerivedObj, BaseObj);
};

// Before this commit: &BaseObj::base_field would fail template deduction
// After this commit: works, with static_assert ensuring BaseObj is base of DerivedObj
TVM_FFI_REFLECTION_DEF(DerivedObj)
    .def_ro("base_field", &BaseObj::base_field)    // inherited field
    .def_ro("extra", &DerivedObj::extra);           // own field
```
