# Generalize reflection field registration to accept base-class member pointers; add automatic TypeTraits for enum types

## TL;DR
- `ObjectDef::def_ro`, `def_rw`, and `RegisterField` now accept member pointers to base classes (`T BaseClass::*`) instead of requiring `T Class::*`, with a `static_assert` ensuring `BaseClass` is indeed a base of `Class`. This unblocks registering inherited fields in the reflection system.
- A new SFINAE-based `TypeTraits` partial specialization for `enum class` types with integral underlying types is added, so enums automatically convert to/from `Any`/`AnyView` as `kTVMFFIInt` without requiring per-enum manual specializations.
- A test (`TEST(Any, Enum)`) validates the enum round-trip through `AnyView`.

## Key Exports

**Template signature changes** in `ObjectDef` (reflection.h):

```cpp
// Before (old):
template <typename T, typename... Extra>
ObjectDef& def_ro(const char* name, T Class::*field_ptr, Extra&&... extra);

template <typename T, typename... Extra>
ObjectDef& def_rw(const char* name, T Class::*field_ptr, Extra&&... extra);

template <typename T, typename... ExtraArgs>
void RegisterField(const char* name, T Class::*field_ptr, bool writable, ExtraArgs&&... extra_args);

// After (new):
template <typename T, typename BaseClass, typename... Extra>
ObjectDef& def_ro(const char* name, T BaseClass::*field_ptr, Extra&&... extra);

template <typename T, typename BaseClass, typename... Extra>
ObjectDef& def_rw(const char* name, T BaseClass::*field_ptr, Extra&&... extra);

template <typename T, typename BaseClass, typename... ExtraArgs>
void RegisterField(const char* name, T BaseClass::*field_ptr, bool writable, ExtraArgs&&... extra_args);
// Added: static_assert(std::is_base_of_v<BaseClass, Class>)
```

**New TypeTraits specialization** (type_traits.h):

```cpp
template <typename IntEnum>
struct TypeTraits<IntEnum, std::enable_if_t<std::is_enum_v<IntEnum> &&
                                            std::is_integral_v<std::underlying_type_t<IntEnum>>>>
    : public TypeTraitsBase {
  static constexpr int32_t field_static_type_index = TypeIndex::kTVMFFIInt;
  // Full 7-method protocol: stores as kTVMFFIInt, casts via static_cast<int64_t>
  // TryCastFromAnyView accepts kTVMFFIInt or kTVMFFIBool
};
```

## Impact
- API: `def_ro`/`def_rw` template parameter list gains `BaseClass` — source-compatible (template deduction handles it), but changes the mangled symbol. Any code passing `T Class::*` still compiles since `BaseClass` deduces to `Class`. Code passing `T ParentClass::*` (inherited fields) now compiles where it previously failed.
- Behavioral: Enum class types that previously caused a compile error when used with `Any`/`AnyView` now silently work as integers. No runtime behavior change for non-enum types.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeTraits protocol** ([0005-type-traits.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0005-type-traits.md)) — the new enum specialization implements all 7 required methods following the existing pattern for integral types.
- **Reflection ObjectDef builder** ([0009-reflection.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0009-reflection.md)) — the base-class member pointer generalization is a refinement of the existing `RegisterField` mechanism.
- **TypeTraitsBase** — the enum specialization inherits from `TypeTraitsBase`, following the same pattern as `int`/`bool`/`float` POD specializations.

Design elements this commit produces:
- **Automatic enum TypeTraits** — a new SFINAE partial specialization that removes the need for per-enum manual `TypeTraits` specializations. Any `enum class` with an integral underlying type is now automatically supported.
- **Base-class field registration invariant** — `RegisterField` now enforces `static_assert(std::is_base_of_v<BaseClass, Class>)`, formalizing that inherited fields can be registered on derived types while preventing unrelated class member pointers.

## Usage Examples

**Enum round-trip through AnyView** (from `tests/cpp/test_any.cc`):
```cpp
enum class ENum : int { A = 1, B = 2 };

// Implicit conversion to AnyView
AnyView view = ENum::A;
assert(view.CopyToTVMFFIAny().type_index == TypeIndex::kTVMFFIInt);
assert(view.CopyToTVMFFIAny().v_int64 == 1);

// Extraction
ENum v = view.cast<ENum>();
assert(v == ENum::A);

// Optional extraction from empty
AnyView empty;
Optional<ENum> opt = empty.as<ENum>();
assert(!opt.has_value());
```

**Registering inherited fields** (motivating example, not in diff):
```cpp
class BaseObj : public Object {
 public:
  int64_t base_field;
  // ...
};

class DerivedObj : public BaseObj {
 public:
  int64_t derived_field;
  // ...
};

// Before this commit: would fail to compile (T BaseObj::* doesn't match T Class::*)
// After this commit: works, with static_assert ensuring BaseObj is base of DerivedObj
TVM_FFI_REFLECTION_DEF(DerivedObj)
  .def_ro("base_field", &BaseObj::base_field)      // inherited field, now OK
  .def_ro("derived_field", &DerivedObj::derived_field);
```
