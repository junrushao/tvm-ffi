# Add TypeTraits specialization for integral enum types and generalize ObjectDef::def_ro/def_rw to accept base-class member pointers

## TL;DR
- Adds a `TypeTraits<IntEnum>` partial specialization for any `enum class` with an integral underlying type, mapping enums to/from `kTVMFFIInt` in `AnyView`/`Any`.
- Generalizes `ObjectDef::def_ro` and `ObjectDef::def_rw` (and their internal `RegisterField`) to accept `T BaseClass::*` member pointers (not just `T Class::*`), with a `static_assert` requiring `BaseClass` to be a base of `Class`.
- Adds a `TEST(Any, Enum)` GoogleTest exercising round-trip and `as<ENum>` on an unset `AnyView`.

> **Diff-message alignment note**: The commit message says "Transition VisitAttrs to new reflection mechanism in tir/ir_builder/meta_schedule" — those components are not present in this diff. The actual diff is limited to `include/tvm/ffi/` headers and `tests/cpp/test_any.cc`. Analysis is scoped to the actual diff only.

## Key Exports

```python
# TypeTraits partial specialization for integral enum types
# Precondition: std::is_enum_v<IntEnum> && std::is_integral_v<std::underlying_type_t<IntEnum>>
class TypeTraits[IntEnum]:  # new specialization
    """Maps enum-class values to kTVMFFIInt in Any/AnyView. POD — no heap allocation."""
    field_static_type_index: int32_t = TypeIndex.kTVMFFIInt

    @staticmethod
    def CopyToAnyView(src: IntEnum, result: TVMFFIAny*) -> None:
        result.type_index = TypeIndex.kTVMFFIInt
        result.v_int64 = int(src)  # static_cast<int64_t>

    @staticmethod
    def MoveToAny(src: IntEnum, result: TVMFFIAny*) -> None:
        CopyToAnyView(src, result)  # POD: move == copy

    @staticmethod
    def CheckAnyStrict(src: TVMFFIAny*) -> bool:
        return src.type_index == TypeIndex.kTVMFFIInt
        # NOTE: strict only — does NOT accept kTVMFFIBool

    @staticmethod
    def CopyFromAnyViewAfterCheck(src: TVMFFIAny*) -> IntEnum:
        return IntEnum(src.v_int64)

    @staticmethod
    def MoveFromAnyAfterCheck(src: TVMFFIAny*) -> IntEnum:
        return CopyFromAnyViewAfterCheck(src)  # POD

    @staticmethod
    def TryCastFromAnyView(src: TVMFFIAny*) -> Optional[IntEnum]:
        if src.type_index in (kTVMFFIInt, kTVMFFIBool):
            return IntEnum(src.v_int64)
        return None
        # Interacts with: TypeTraits[int] (same wire type, same coercion path)

    @staticmethod
    def TypeStr() -> str: return StaticTypeKey.kTVMFFIInt


# ObjectDef::def_ro / def_rw signature generalization (old → new)
class ObjectDef[Class]:
    # Old signature (only accepted T Class::*):
    #   def def_ro(self, name: str, field_ptr: T Class::*, *extra) -> ObjectDef: ...
    # New signature (accepts inherited member pointers from any base):
    def def_ro(self, name: str, field_ptr: T BaseClass::*, *extra) -> ObjectDef:
        """Register a read-only field. BaseClass must be a base class of Class."""
        RegisterField(name, field_ptr, writable=False, *extra)
        return self
        # Invariant: static_assert(std::is_base_of_v<BaseClass, Class>)

    def def_rw(self, name: str, field_ptr: T BaseClass::*, *extra) -> ObjectDef:
        """Register a read-write field. Requires Class._type_mutable == true."""
        # Old: T Class::* only. New: T BaseClass::*
        RegisterField(name, field_ptr, writable=True, *extra)
        return self
        # Invariant: static_assert(std::is_base_of_v<BaseClass, Class>)

    def RegisterField(self, name: str, field_ptr: T BaseClass::*, writable: bool, *extra) -> None:
        # static_assert(std::is_base_of_v<BaseClass, Class>)   ← NEW guard
        info = TVMFFIFieldInfo(name=..., field_static_type_index=TypeToFieldStaticTypeIndex[T].value)
        # ...byte offset computed, getter/setter wired...
        TVMFFITypeRegisterExtraInfo(type_index_, &info)
        # Interacts with: TypeToFieldStaticTypeIndex[T], TVMFFIRegisterTypeField
```

## Impact
- API: `def_ro`/`def_rw`/`RegisterField` template parameters widened from `T Class::*` to `T BaseClass::*`. Callers passing `Class::*` member pointers continue to compile unchanged (BaseClass deduces to Class). Callers with inherited field pointers now compile that previously wouldn't.
- Behavioral: Enum values now round-trip through `Any`/`AnyView` as `kTVMFFIInt`; previously they would fail to compile or be silently lost. `TryCastFromAnyView` accepts both `kTVMFFIInt` and `kTVMFFIBool` for enum coercion.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**Enum round-trip through AnyView (from added test):**
```cpp
enum class ENum : int { A = 1, B = 2 };

// Store enum in AnyView
AnyView view1 = ENum::A;
assert(view1.CopyToTVMFFIAny().type_index == TypeIndex::kTVMFFIInt);
assert(view1.CopyToTVMFFIAny().v_int64 == 1);

// Cast back
ENum v1 = view1.cast<ENum>();
assert(v1 == ENum::A);

// Optional cast on empty view returns nullopt
AnyView view0;
Optional<ENum> opt = view0.as<ENum>();
assert(!opt.has_value());
```

**Registering an inherited field via def_ro (now valid):**
```cpp
// Base class holds the field
class BaseObj : public Object {
 public:
  int shared_field;
};

// Derived class — want to expose inherited field
class DerivedObj : public BaseObj { ... };

// Previously only T DerivedObj::* was accepted;
// now T BaseObj::* compiles with static_assert guard:
ObjectDef<DerivedObj>(RuntimeTypeIndex())
    .def_ro("shared_field", &BaseObj::shared_field);
// static_assert(std::is_base_of_v<BaseObj, DerivedObj>) passes
```
