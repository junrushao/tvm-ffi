# Fix error propagation when recovering DLPack tensor allocator after FFI calls with tensor arguments
## TL;DR
- Fixes a bug in `TVMFFIPyCallManager` (`tvm_ffi_python_helpers.h`) where the return code from `TVMFFIEnvSetDLPackManagedTensorAllocator` was incorrectly assigned to `c_api_ret_code[0]`, overwriting the actual function call error. Now checks the recovery call independently and raises `RuntimeError` on failure.
- Fixes `EnvContext::SetDLPackManagedTensorAllocator` in `env_context.cc` to return only the cached local allocator (`dlpack_allocator_`), not the result of `GetDLPackManagedTensorAllocator()` which might return the global allocator.
- Adds regression test in `tests/python/test_tensor.py`.
