# Fix error propagation when tensor arguments trigger DLPack allocator recovery

## TL;DR
- Fixes a bug where `TVMFFIEnvSetDLPackManagedTensorAllocator` restore call's error code was silently overwritten by the original function call's error code in `TVMFFIPyCallManager`.
- Fixes `EnvContext::SetDLPackManagedTensorAllocator` to return only the locally cached allocator (`dlpack_allocator_`) as the "original" value rather than calling `GetDLPackManagedTensorAllocator()` (which reads the global context).
- Adds a regression test in `test_tensor.py`.

## Key Exports

None — this is a bugfix restoring existing invariants, no new API introduced.

## Impact
- API: none — no public signatures changed (patch version reverted from 9 to 8, suggesting the bug was introduced in a recent patch).
- Behavioral: Error propagation in `TVMFFIPyCallManager` is now correct: if restore of the DLPack allocator fails, a `RuntimeError` is raised immediately; if the original call failed but restore succeeded, the original error is returned.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `0016-py-ffi-call-dispatch`: `TVMFFIPyCallManager` / `TVMFFIPyCallContext` with `dlpack_c_exchange_api` — the RAII call manager that owns DLPack allocator setup/teardown.
- `0012-env-api`: `TVMFFIEnvSetDLPackManagedTensorAllocator` — C ABI entry for setting tensor allocator; invariant "check `ret_code` before accessing `dl_tensor`".

Design elements this commit produces: None — bugfix only.

## Usage Examples

Before (bug): if `TVMFFIEnvSetDLPackManagedTensorAllocator` restore call failed, its error code was lost:
```python
# c_api_ret_code[0] was overwritten by restore call's return value,
# losing the original function call error
c_api_ret_code[0] = TVMFFIEnvSetDLPackManagedTensorAllocator(prev, 0, nullptr)
```

After (fix): restore error is propagated separately, original function error is preserved:
```python
# Restore error → immediate PyErr_SetString + return -1
if TVMFFIEnvSetDLPackManagedTensorAllocator(prev, 0, nullptr) != 0:
    PyErr_SetString(PyExc_RuntimeError, "Failed to recover DLPack managed tensor allocator")
    return -1
# Then check original call error
if c_api_ret_code[0] != 0:
    return 0
```

Also fixes `EnvContext::SetDLPackManagedTensorAllocator`:
```cpp
// Before: read potentially-stale global
*opt_out_original_allocator = GetDLPackManagedTensorAllocator();
// After: return local cache only
*opt_out_original_allocator = dlpack_allocator_;
```
