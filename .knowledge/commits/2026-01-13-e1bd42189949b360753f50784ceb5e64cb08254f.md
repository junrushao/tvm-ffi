# Fix error propagation when DLPack tensor allocator recovery fails
## TL;DR
- Fixes a bug where `TVMFFIEnvSetDLPackManagedTensorAllocator` return code was incorrectly overwriting the original function call error code in the Python helpers.
- Changes `EnvContext::SetDLPackManagedTensorAllocator` to return only the cached local allocator, ignoring the global allocator, preventing incorrect state.
- Adds regression test `test_tensor_auto_dlpack_with_error` for error propagation with torch tensor arguments.

## Key Exports

```python
# Fix in tvm_ffi_python_helpers.h TVMFFIPyCallManager:
# Before: c_api_ret_code[0] = TVMFFIEnvSetDLPackManagedTensorAllocator(...)
#   -> overwrites original error code
# After: separate error check, only PyErr_SetString on allocator failure
# Invariant: original c_api_ret_code preserved through allocator recovery
```
