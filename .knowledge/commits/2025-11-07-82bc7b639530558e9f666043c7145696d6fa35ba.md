# Fix missing static registration for kTVMFFIDLTensorPtr type index in TypeTable

## TL;DR
- Adds `ReserveBuiltinTypeIndex(StaticTypeKey::kTVMFFIDLTensorPtr, TypeIndex::kTVMFFIDLTensorPtr)` to `TypeTable::InitBuiltins()` in `src/ffi/object.cc`.
- Without this, `DLTensor*` type index `7` was not registered in the global type table, causing silent failures when `DLTensor*` values were passed to typed functions.
- Adds 16 test lines to `tests/cpp/test_function.cc`.

## Key Exports

```python
# C pseudocode — src/ffi/object.cc TypeTable::InitBuiltins()
# Before: kTVMFFIDLTensorPtr (index 7) was NOT in the builtin registration list
# After: added ReserveBuiltinTypeIndex(kTVMFFIDLTensorPtr, kTVMFFIDLTensorPtr)
# Invariant: all static type indices in kTVMFFITypeIndex enum MUST be registered here
# Interacts with: TypeTraits<DLTensor*>, TensorView (kTVMFFIDLTensorPtr=7)
```

## Impact
- API: none
- Behavioral: Fixes crash/mismatch when passing `DLTensor*`/`TensorView` to C++ typed packed functions.
- Flags/config: none
- Data formats/schemas: none
