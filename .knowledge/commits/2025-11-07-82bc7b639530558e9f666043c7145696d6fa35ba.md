# Fix missing static type registration for DLTensor* in TypeTable initialization
## TL;DR
- Added the missing `ReserveBuiltinTypeIndex` call for `kTVMFFIDLTensorPtr` in `TypeTable` constructor, restoring the invariant that all POD type indices are registered at startup.
- Added a test confirming that passing `DLTensor*` to a typed function produces a correctly-named `TypeError` message (e.g., "Expected `int` but got `DLTensor*`").

## Key Exports
None -- this commit fixes a registration gap in existing infrastructure, no new API surface.

## Impact
- API: none
- Behavioral: Type name resolution for `DLTensor*` (type index 7) now works correctly in error messages produced by typed function dispatch. Before this fix, passing a `DLTensor*` to a mismatched typed function could produce garbled or missing type names in the `TypeError` message.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeTable builtin registration** (`src/ffi/object.cc`): The `TypeTable` constructor registers all POD type indices via `ReserveBuiltinTypeIndex`, mapping `StaticTypeKey` strings to `TypeIndex` enum values. See [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md) for the `TVMFFITypeIndex` enum layout (POD range [0,64)).
- **StaticTypeKey / TypeIndex enums** (`include/tvm/ffi/c_api.h`, `include/tvm/ffi/object.h`): `kTVMFFIDLTensorPtr = 7` was already defined in both enums but lacked its runtime registration call. See [0002-ffi-any-value-system](../design-records/0002-ffi-any-value-system.md) for how `TypeTraits<DLTensor*>` uses this index.
- **Function::FromTyped error path** (`include/tvm/ffi/function.h`): Typed function dispatch uses type index to look up type names when generating mismatch errors. See [0004-ffi-function-system](../design-records/0004-ffi-function-system.md).

Design elements this commit produces: none

## Usage Examples
**Before fix (broken):** Passing `DLTensor*` to a typed function that expects `int` would produce a TypeError, but the error message could not resolve the type name `"DLTensor*"` from type index 7, since the index was never registered in the type table.

**After fix (correct):**
```cpp
Function fadd1 = Function::FromTyped([](int x) -> int { return x + 1; }, "fadd1");
DLTensor dltensor;
// Correctly throws TypeError with message:
// "Mismatched type on argument #0 when calling: `(0: int) -> int`.
//  Expected `int` but got `DLTensor*`"
fadd1(&dltensor);
```
