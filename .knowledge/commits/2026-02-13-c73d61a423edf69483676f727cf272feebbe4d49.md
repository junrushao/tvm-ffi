# Add __copy__, __deepcopy__, and __replace__ support for FFI objects
## TL;DR
- Introduces `ffi.DeepCopy` C++ entrypoint for memoized, graph-preserving deep copy of FFI objects (handles shared references, cycles, containers).
- Auto-registers `__ffi_shallow_copy__` method on copy-constructible reflected types via `ObjectDef`, enabling shallow copy without manual boilerplate.
- Python-side installs `__copy__`, `__deepcopy__`, and `__replace__` on registered object types; non-copyable types get clear `TypeError`.

## Key Exports

**C++ API**:
```cpp
// deep_copy.h
TVM_FFI_EXTRA_CXX_API Any DeepCopy(const Any& value);
```

**Reflection constants**:
```cpp
// reflection/registry.h
namespace type_attr {
    inline constexpr const char* kInit = "__ffi_init__";
    inline constexpr const char* kShallowCopy = "__ffi_shallow_copy__";
}
```

**ObjectDef auto-registration**:
- `ObjectDef` constructor now calls `AutoRegisterCopy()` which registers `__ffi_shallow_copy__` as both an instance method and a type attribute for `std::is_copy_constructible_v<Class>` types.

**Python methods** (installed via `registry.py`):
- `__copy__(self)` -- shallow copy via `__ffi_shallow_copy__`
- `__deepcopy__(self, memo)` -- deep copy via `ffi.DeepCopy`
- `__replace__(self, **kwargs)` -- dataclass-style replace (shallow copy + field overrides)

## Impact
- API: New `ffi.DeepCopy` global function. New `__ffi_shallow_copy__` type attribute automatically registered for copy-constructible reflected types. New `type_attr` namespace with `kInit` and `kShallowCopy` constants.
- Behavioral: All copy-constructible reflected objects now support Python `copy.copy()` and `copy.deepcopy()` out of the box. Deep copy preserves shared references and handles cycles.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Reflection** (`.knowledge/designs/0009-reflection.md`): `ObjectDef` constructor extended with `AutoRegisterCopy`.
- **Containers** (`.knowledge/designs/0008-containers.md`): `DeepCopy` recursively handles Array, List, Map.

Design elements this commit produces:

- **type_attr namespace**: Well-known attribute name constants for reflection system (`kInit`, `kShallowCopy`).

## Usage Examples

```python
import copy
from tvm_ffi import dataclasses

@dataclasses.c_class("test.Point")
class Point:
    x: int
    y: int

p = Point(x=1, y=2)
p_shallow = copy.copy(p)        # shallow copy via __ffi_shallow_copy__
p_deep = copy.deepcopy(p)       # deep copy via ffi.DeepCopy
p_replaced = p.__replace__(x=3) # returns Point(x=3, y=2)
```
