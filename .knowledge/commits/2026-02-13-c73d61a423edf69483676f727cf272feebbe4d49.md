# Add reflection-based __copy__, __deepcopy__, and __replace__ for FFI objects
## TL;DR
- Adds `ffi::DeepCopy(Any)` C++ API and global function `ffi.DeepCopy`: memoized graph copy that preserves shared references and cycles, recursively copies `Array`/`Map`/`List`, treats `String`/`Bytes` as immutable terminals.
- `ObjectDef::AutoRegisterCopy()` auto-registers `__ffi_shallow_copy__` as an instance method and type attribute for all C++ reflected types that are copy-constructible.
- Python: `_setup_copy_methods()` installs `__copy__`/`__deepcopy__`/`__replace__` on FFI classes (via `register_object` and `@c_class`) based on whether `__ffi_shallow_copy__` is registered. Non-copyable types get `TypeError`-raising stubs.

## Impact
- API: `ffi::DeepCopy` added to `include/tvm/ffi/extra/deep_copy.h`. `type_attr::kShallowCopy` / `kInit` constants in `reflection/registry.h`. Both are additive.
- Behavioral: All reflected C++ types that are copy-constructible now automatically expose `__copy__`/`__deepcopy__`/`__replace__` on their Python proxy classes. Types that are not copy-constructible raise `TypeError` on copy attempts.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
import copy
import tvm_ffi

# Shallow copy via copy.copy (uses __ffi_shallow_copy__)
x = MyFFIObject(value=1)
y = copy.copy(x)       # creates new C++ object via copy constructor

# Deep copy via copy.deepcopy (uses ffi.DeepCopy, preserves shared refs)
arr = tvm_ffi.Array([x, x])
arr2 = copy.deepcopy(arr)
assert arr2[0] is arr2[1]   # shared reference preserved

# Dataclass-style replace
z = x.__replace__(value=2)  # shallow copy with field override
assert z.value == 2 and x.value == 1

# Non-copyable type raises TypeError
try:
    copy.copy(non_copyable_obj)
except TypeError:
    pass  # expected
```
