# Add __copy__, __deepcopy__, and __replace__ for FFI objects
## TL;DR
- Introduces `include/tvm/ffi/extra/deep_copy.h` and `src/ffi/extra/deep_copy.cc` implementing deep copy for FFI objects via reflection.
- Adds `__copy__`, `__deepcopy__`, and `__replace__` Python dunder methods for FFI objects through `registry.py`.
- Removes previous Python-side `__repr__` generation in favor of C++ reflection-based approach.

## Impact
- API: FFI objects now support Python `copy.copy()`, `copy.deepcopy()`, and `copy.replace()`.
