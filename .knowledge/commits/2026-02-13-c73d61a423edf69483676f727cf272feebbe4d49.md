# Add __copy__, __deepcopy__, and __replace__ for FFI objects
## TL;DR
- Adds `deep_copy.h`/`deep_copy.cc` implementing reflection-driven deep copy for FFI objects
- Python objects get `__copy__` (shallow, ref-counted), `__deepcopy__` (deep, creates new objects), and `__replace__` (Python 3.13+ copy.replace() protocol)
- `__replace__` creates a shallow copy with specified field overrides via reflection
- Integrates with `@c_class` decorator: `copy` and `replace` params control which protocols are generated

## Key Exports
```python
# C++ deep copy:
def deep_copy(obj: ObjectRef) -> ObjectRef: ...
    # Interacts with: Reflection (field enumeration), Object system (make_object)
    # Invariant: creates entirely new object graph; no shared refs with original

# Python protocols auto-generated on @c_class types:
class SomeCClass:
    def __copy__(self) -> "SomeCClass": ...          # shallow (IncRef)
    def __deepcopy__(self, memo: dict) -> "SomeCClass": ...  # deep via ffi.deep_copy
    def __replace__(self, **kwargs) -> "SomeCClass": ...     # shallow copy + field overrides
    # Interacts with: copy module, Python 3.13 copy.replace()
```

## Impact
- API: adds `deep_copy` C++ function; Python FFI objects gain copy/deepcopy/replace protocols
- Behavioral: none for existing code
- Flags/config: `copy` and `replace` params on `@c_class`
- Data formats/schemas: none

## Usage Examples
```python
import copy
from tvm_ffi.dataclasses import c_class, field

@c_class("test.Point")
class Point:
    x: int = field()
    y: int = field()

p = Point(x=1, y=2)
p2 = copy.copy(p)      # shallow copy
p3 = copy.deepcopy(p)  # deep copy
p4 = copy.replace(p, x=10)  # replace with overrides (Python 3.13+)
```
