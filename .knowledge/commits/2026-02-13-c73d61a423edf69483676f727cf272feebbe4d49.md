# Add __copy__, __deepcopy__, __replace__ and reflection-based DeepCopy for FFI objects
## TL;DR
- Adds `ffi.DeepCopy` C++ entrypoint that does memoized graph copy preserving shared references and cycles
- Auto-registers `__ffi_shallow_copy__` for copy-constructible types via `ObjectDef` reflection
- Wires `__copy__`, `__deepcopy__`, `__replace__` on Python FFI objects; clear `TypeError` for non-copyable types
- Container roots (`Array`, `Map`) support `deepcopy` without requiring `__ffi_shallow_copy__`

class SomeObj:
    def __ffi_shallow_copy__(self) -> SomeObj: ...
    # Registered via ObjectDef::AutoRegisterCopy() if C++ type is copy-constructible

    def __copy__(self) -> SomeObj: ...       # calls __ffi_shallow_copy__
    def __deepcopy__(self, memo=None): ...   # calls ffi.DeepCopy
    def __replace__(self, **kwargs): ...     # copy + setattr

# Well-known type attribute names:
# type_attr::kInit = "__ffi_init__"

## Impact
- API: new `ffi.DeepCopy` global function; new `__copy__`/`__deepcopy__`/`__replace__` on all reflected objects
- Behavioral: copy-constructible C++ types automatically get Python copy support
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```python
import copy
from tvm_ffi import testing

obj = testing.TestObj(x=1, y="hello")
shallow = copy.copy(obj)       # calls __ffi_shallow_copy__
deep = copy.deepcopy(obj)      # calls ffi.DeepCopy
replaced = obj.__replace__(x=2)  # copy + setattr
```
