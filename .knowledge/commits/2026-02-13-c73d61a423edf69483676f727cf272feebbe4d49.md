# Add reflection-based __copy__, __deepcopy__, and __replace__ for FFI objects

## TL;DR

- Adds `ffi::DeepCopy(Any)` C++ entry-point (`src/ffi/extra/deep_copy.cc`) implementing memoized, cycle-safe graph deep-copy for FFI objects using reflection field iteration, preserving shared references.
- Extends `ObjectDef<T>` to auto-register `__ffi_shallow_copy__` as a type method and type attribute for all copy-constructible reflected types; introduces `type_attr::kInit` and `type_attr::kShallowCopy` well-known name constants.
- Wires Python class registration to install `__copy__`, `__deepcopy__`, and `__replace__` on every registered FFI type; non-copy-constructible types raise `TypeError` at call time.

## Key Exports

```python
# C++ public API — include/tvm/ffi/extra/deep_copy.h
def DeepCopy(value: Any) -> Any: ...
# Interacts with: ObjectDeepCopier (internal), reflection::TypeAttrColumn[kShallowCopy],
#                 TVMFFIGetTypeInfo, reflection::ForEachFieldInfo, FieldGetter/FieldSetter
# Invariant: primitives, Str, Bytes, Shape returned as-is (immutable).
#            Array, Map rebuilt element-by-element.
#            ObjectRef types must have __ffi_shallow_copy__ registered or raise RuntimeError.
# Registered as global function: registry["ffi.DeepCopy"] = PackedFunc(DeepCopy)

# C++ internal — src/ffi/extra/deep_copy.cc
class ObjectDeepCopier:
    """Memoized graph copier. Iterative queue drains field resolution."""
    column: TypeAttrColumn   # kShallowCopy column; indexed by type_index
    copy_map: dict           # original Object* -> copied Any
    resolve_queue: list      # Objects awaiting field resolution

    def Run(self, value: Any) -> Any: ...
    # Invariant: cyclic List is safe (registered before children resolved);
    #            Array/Map cycles impossible (immutable).

# C++ reflection extension — include/tvm/ffi/reflection/registry.h
namespace type_attr:
    kInit: str = "__ffi_init__"          # was ObjectDef<T>::kInitMethodName
    kShallowCopy: str = "__ffi_shallow_copy__"

class ObjectDef:
    # NEW: called in constructor for all copy-constructible Class types
    def AutoRegisterCopy(self) -> None: ...
    # Interacts with: RegisterMethod(kShallowCopy), TVMFFITypeRegisterAttr,
    #                 reflection::TypeAttrColumn (via DeepCopy static column)

# Python API — python/tvm_ffi/registry.py
def _setup_copy_methods(type_cls: type, has_shallow_copy: bool, *, is_container: bool = False) -> None: ...
# Interacts with: _copy_supported, _deepcopy_supported, _replace_supported,
#                 _copy_unsupported, _deepcopy_unsupported, _replace_unsupported
# Called from: _add_class_attrs (for register_object types) and c_class decorator

@functools.lru_cache(maxsize=1)
def _get_deep_copy_func() -> Function: ...
# Returns: get_global_func("ffi.DeepCopy"); cached to avoid repeated registry lookup

# Testing fixtures — src/ffi/testing/testing.cc
class TestDeepCopyEdgesObj(Object):
    v_any: Any
    v_obj: ObjectRef
    # _type_mutable = True; both fields are rw

class TestNonCopyable(Object):
    value: int64_t
    # copy constructor = delete; registered with ObjectDef (no AutoRegisterCopy)
```

## Impact

- API: New `ffi.DeepCopy` global function callable from Python and C++. New `__ffi_shallow_copy__` method auto-attached to every copy-constructible reflected object type. Python `__copy__`, `__deepcopy__`, `__replace__` installed on all FFI-registered types.
- Behavioral: `TestObjectDerived.v_map` and `v_array` changed from `def_ro` to `def_rw` in `src/ffi/testing/testing.cc` (side effect to support field resolution in deep copy tests). `ObjectDef<T>::kInitMethodName` constant moved into `type_attr::kInit` namespace alias.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- **0006-reflection** — `ObjectDef<T>`, `TypeAttrColumn`, `ForEachFieldInfo`, `FieldGetter`/`FieldSetter`, `TVMFFITypeRegisterAttr`; used by `AutoRegisterCopy` and `ObjectDeepCopier`
- **0004-function-system** — `Function`, `GlobalDef().def(...)` to register `ffi.DeepCopy`; `get_global_func` in Python
- **0003-any-anyview** — `Any` as the universal container traversed by deep copier
- **0002-object-system** — `Object*` identity tracking in `copy_map_`; `make_object<Class>(*self)` for shallow copy
- **0007-containers** — `Array`, `List`, `Map` deep-copy paths in `ObjectDeepCopier`; `ffi.Array`/`ffi.Map` get `__deepcopy__` via `is_container=True` path
- **0013-python-package** — `_add_class_attrs` and `register_object` extended to call `_setup_copy_methods`
- **0017-c-class-dataclasses** — `c_class` decorator updated to call `_setup_copy_methods`

Design elements this commit produces:
- **Deep copy subsystem** (`include/tvm/ffi/extra/deep_copy.h`, `src/ffi/extra/deep_copy.cc`): memoized graph copy with cycle safety; new `extra/` module pattern
- **`type_attr::kShallowCopy` protocol**: any copy-constructible `ObjectDef<T>` auto-registers a `__ffi_shallow_copy__` type attribute; downstream consumers (e.g. `DeepCopy`, Python `__copy__`) discover copyability via this attribute
- **`type_attr` well-known name constants** (`type_attr::kInit`, `type_attr::kShallowCopy`): centralizes magic string literals that previously lived in `ObjectDef` as private constants
- **Python copy protocol bridge** (`_setup_copy_methods`): reusable helper that installs `__copy__`/`__deepcopy__`/`__replace__` for both `register_object` and `c_class` paths, with a clean `TypeError` for non-copyable types

## Usage Examples

**Cross-layer trace — C++ definition to Python call:**

```python
# 1. C++ side (automatic on ObjectDef<T> construction for copy-constructible types):
#    refl::ObjectDef<TestIntPair>()  →  AutoRegisterCopy()
#    → __ffi_shallow_copy__ method + type attr registered

# 2. Python shallow copy (copy.copy):
import copy, tvm_ffi.testing
pair = tvm_ffi.testing.TestIntPair(1, 2)
pair_copy = copy.copy(pair)        # calls pair.__copy__() → __ffi_shallow_copy__()
assert not pair.same_as(pair_copy) # distinct object
assert pair_copy.a == 1

# 3. Python deep copy (copy.deepcopy):
inner = tvm_ffi.testing.TestIntPair(7, 8)
arr = tvm_ffi.convert([inner, inner])   # two slots share same object
obj = tvm_ffi.testing.create_object("testing.TestObjectDerived", v_i64=1,
                                     v_map=tvm_ffi.convert({}), v_array=arr)
obj_deep = copy.deepcopy(obj)
# shared references preserved in the copy
assert obj_deep.v_array[0].same_as(obj_deep.v_array[1])
assert not obj.v_array[0].same_as(obj_deep.v_array[0])

# 4. __replace__ (dataclass-style field replacement):
new_pair = pair.__replace__(a=99)
assert new_pair.a == 99

# 5. Non-copyable type raises TypeError:
nc = tvm_ffi.testing.TestNonCopyable(42)
copy.copy(nc)   # raises TypeError: "does not support copy"
```
