# Make CUDA an optional dependency for torch C DLPack extension and env tensor allocator test

## TL;DR
- Wraps CUDA-specific C++ includes and code paths in `_optional_torch_c_dlpack.py` behind `#ifdef BUILD_WITH_CUDA`, set only when `torch.cuda.is_available()`.
- Converts the env tensor allocator test from a CUDA-only test to a CPU-only test, removing the CUDA kernel and running the same allocation logic on CPU.
- Renames the inline extension from `to_dlpack` to `c_dlpack`.

## Key Exports

None -- no new public API. Changes are internal to the torch C DLPack JIT extension and its test.

## Impact
- API: none
- Behavioral: `load_torch_c_dlpack_extension()` now compiles successfully on CPU-only systems (previously failed on missing `c10/cuda/CUDAStream.h`). CUDA stream capture in `TorchDLPackFromPyObject` is a no-op on CPU-only builds.
- Flags/config: new `-DBUILD_WITH_CUDA` flag passed to `cpp_extension.load_inline` only when `torch.cuda.is_available()`.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Torch C DLPack extension** (`python/tvm_ffi/_optional_torch_c_dlpack.py`): JIT-compiled C++ extension providing fast DLPack conversion for torch tensors, loaded via `torch.utils.cpp_extension.load_inline`. Sets `__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, and `__c_dlpack_tensor_allocator__` on `torch.Tensor`. See [0012-ffi-python-package](../design-records/0012-ffi-python-package.md).
- **`load_inline`** (`python/tvm_ffi/cpp/`): JIT compilation of C++ source into a `Module`. See [0014-ffi-load-inline](../design-records/0014-ffi-load-inline.md).
- **`Tensor::FromDLPackAlloc` / `TVMFFIEnvGetTensorAllocator`**: Environment tensor allocator protocol for library functions to allocate output tensors via the caller's allocator (e.g., `torch.empty`). See [0006-ffi-containers](../design-records/0006-ffi-containers.md).

Design elements this commit produces: none

## Usage Examples

Before/after pattern for the conditional CUDA compilation in `_optional_torch_c_dlpack.py`:

```python
# BEFORE: always included CUDA headers and paths (fails on CPU-only systems)
mod = cpp_extension.load_inline(
    name="to_dlpack",
    cpp_sources=cpp_source,  # unconditionally #include <c10/cuda/CUDAStream.h>
    extra_cflags=["-O3"],
    extra_include_paths=libinfo.include_paths() + cpp_extension.include_paths("cuda"),
)

# AFTER: CUDA paths and flags only when available
include_paths = libinfo.include_paths()
extra_cflags = ["-O3"]
if torch.cuda.is_available():
    include_paths += cpp_extension.include_paths("cuda")
    extra_cflags += ["-DBUILD_WITH_CUDA"]
mod = cpp_extension.load_inline(
    name="c_dlpack",
    cpp_sources=cpp_source,  # c10/cuda/CUDAStream.h guarded by #ifdef BUILD_WITH_CUDA
    extra_cflags=extra_cflags,
    extra_include_paths=include_paths,
)
```
