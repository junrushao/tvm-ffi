# Make torch C DLPack extension optionally depend on CUDA

## TL;DR
- Guards CUDA-specific C++ includes and runtime calls in `_optional_torch_c_dlpack.py` behind `#ifdef BUILD_WITH_CUDA` / `torch.cuda.is_available()` so the torch C DLPack extension compiles and loads on CPU-only systems.
- Renames the inline extension module from `to_dlpack` to `c_dlpack`.
- Converts the `test_load_inline_cuda_with_env_tensor_allocator` test from a CUDA-only test to a CPU-only test (`test_load_inline_with_env_tensor_allocator`), removing the CUDA kernel in favor of a CPU loop.

## Impact
- API: none — the Python-facing `load_torch_c_dlpack_extension()` signature is unchanged.
- Behavioral: on CPU-only systems, the extension now compiles successfully instead of failing on missing `c10/cuda/CUDAStream.h`. CUDA stream capture in `TorchDLPackFromPyObject` is skipped when built without CUDA.
- Flags/config: new compile-time flag `BUILD_WITH_CUDA` controls CUDA code paths in the inline C++ source.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- `load_inline` compilation pipeline (0013) — uses `cpp_extension.load_inline` with conditional include paths and cflags.
- Torch C DLPack extension pattern (0012) — the `_optional_torch_c_dlpack.py` module that bridges torch tensors and DLPack.

Design elements this commit produces:
- Conditional CUDA compilation guard (`BUILD_WITH_CUDA`) in the torch C DLPack inline source — a new compile-time switch that partitions the extension into CPU-only and CUDA-capable builds.

## Usage Examples

Before (always requires CUDA):
```python
# Would fail on CPU-only systems with missing c10/cuda/CUDAStream.h
mod = cpp_extension.load_inline(
    name="to_dlpack",
    cpp_sources=cpp_source,
    extra_cflags=["-O3"],
    extra_include_paths=libinfo.include_paths() + cpp_extension.include_paths("cuda"),
)
```

After (CUDA optional):
```python
include_paths = libinfo.include_paths()
extra_cflags = ["-O3"]
if torch.cuda.is_available():
    include_paths += cpp_extension.include_paths("cuda")
    extra_cflags += ["-DBUILD_WITH_CUDA"]

mod = cpp_extension.load_inline(
    name="c_dlpack",
    cpp_sources=cpp_source,
    extra_cflags=extra_cflags,
    extra_include_paths=include_paths,
)
```
