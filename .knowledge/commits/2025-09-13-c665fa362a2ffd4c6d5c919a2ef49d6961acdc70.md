# Make torch DLPack extension optionally depend on CUDA
## TL;DR
- Guards CUDA-specific includes (`c10/cuda/CUDAStream.h`) and CUDA stream logic in the torch C DLPack inline extension behind `#ifdef BUILD_WITH_CUDA`, and conditionally passes `-DBUILD_WITH_CUDA` and CUDA include paths only when `torch.cuda.is_available()`.
- Converts the `test_load_inline_cuda_with_env_tensor_allocator` test from a CUDA-only test to a CPU-only test (`test_load_inline_with_env_tensor_allocator`), replacing the CUDA kernel with a CPU loop so the tensor-allocator path can be tested without a GPU.

## Impact
- API: none (runtime behavior unchanged when CUDA is available; now also works without CUDA)
- Flags/config: The inline-compiled torch extension module name changed from `to_dlpack` to `c_dlpack`.
- Data formats/schemas: none

## Design Elements

- **Inline module compilation** (`.knowledge/designs/0017-inline-module-compilation.md`): Uses `cpp_extension.load_inline` to JIT-compile the DLPack bridge; the commit modifies which include paths and compiler flags are passed.
