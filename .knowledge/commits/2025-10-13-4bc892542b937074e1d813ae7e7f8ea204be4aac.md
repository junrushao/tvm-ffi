# Introduce __tvm_ffi_tensor__ protocol for fast tensor fetch from wrapper objects
## TL;DR
- Adds a new `__tvm_ffi_tensor__` dunder protocol: any Python class implementing `__tvm_ffi_tensor__() -> tvm_ffi.Tensor` can be passed directly to FFI calls as a Tensor argument, bypassing DLPack exchange entirely.
- Implements `TVMFFIPyArgSetterFFITensorCompatible_` in Cython with ref-count-aware lifetime management: detects temporary tensors via `Py_REFCNT == 1` and bumps the C-level ref count to keep them alive through the call.
- Inserts the new setter in the dispatch chain after `ObjectRValueRef` but before `DLPackExchangeAPI`, giving it priority over DLPack-based paths for implementing classes.

## Key Exports

```python
# --- __tvm_ffi_tensor__ Protocol (duck-typed dunder) ---
# Any Python class can implement this to be treated as an ffi.Tensor in FFI calls:
class TensorCompatible(Protocol):
    def __tvm_ffi_tensor__(self) -> tvm_ffi.Tensor:
        """Return the underlying ffi.Tensor for fast FFI argument passing."""
        ...
    # Interacts with: TVMFFIPyArgSetterFFITensorCompatible_ (Cython setter)
    # Interacts with: TVMFFIPyArgSetterFactory_ dispatch chain (checked on class, not instance)
    # Invariant: must return an ffi.Tensor instance (not a DLPack tensor or numpy array)
    # Extension: implement on any wrapper class that holds an ffi.Tensor as a member

# --- Cython Setter (internal) ---
# TVMFFIPyArgSetterFFITensorCompatible_(handle, ctx, py_arg, out):
#   1. Calls arg.__tvm_ffi_tensor__() to get the Tensor
#   2. Reads Py_REFCNT(tensor) immediately after binding
#   3. Sets out.type_index = kTVMFFITensor, out.v_ptr = tensor.chandle
#   4. If ref_count == 1 (tensor is temporary):
#        TVMFFIObjectIncRef(chandle)        -- prevent premature C-level free
#        TVMFFIPyPushTempFFIObject(ctx, chandle)  -- ensure cleanup after call
#   Interacts with: TVMFFIPyCallManager dispatch cache, TVMFFIPyPushTempFFIObject
#   Invariant: ref_count == 1 means the Tensor was created as a temporary by __tvm_ffi_tensor__
#              and would be freed when the Cython local goes out of scope

# --- TVMFFIPyArgSetterFactory_ dispatch order update ---
# Previous: ... > ObjectRValueRef > DLPackExchangeAPI > torch > DLPack > ...
# New:      ... > ObjectRValueRef > __tvm_ffi_tensor__ > DLPackExchangeAPI > torch > DLPack > ...
# Note: `arg_class = type(arg)` extraction moved earlier (before the new check),
#        shared with the subsequent DLPackExchangeAPI hasattr check.
```

## Impact
- API: New duck-typed protocol `__tvm_ffi_tensor__`. Any class implementing it gains zero-copy FFI tensor passing. No existing callers are affected.
- Behavioral: Objects implementing `__tvm_ffi_tensor__` are now dispatched through the new setter instead of falling through to DLPack or other paths. This is faster because it avoids DLPack capsule creation/exchange overhead.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
A wrapper class holding an `ffi.Tensor` member can be passed directly to FFI calls:
```python
import tvm_ffi
import numpy as np

class MyTensor:
    def __init__(self, tensor: tvm_ffi.Tensor) -> None:
        self._tensor = tensor

    def __tvm_ffi_tensor__(self) -> tvm_ffi.Tensor:
        return self._tensor

# Create wrapper and pass directly to FFI
data = np.zeros((10, 8), dtype="int32")
x = tvm_ffi.from_dlpack(data)
wrapper = MyTensor(x)

fecho = tvm_ffi.get_global_func("testing.echo")
result = fecho(wrapper)  # passes x's underlying tensor, no DLPack exchange
assert result.__chandle__() == x.__chandle__()
```
