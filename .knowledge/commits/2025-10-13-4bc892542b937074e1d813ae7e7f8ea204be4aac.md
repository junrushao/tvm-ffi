# Introduce __tvm_ffi_tensor__ protocol for fast tensor extraction from wrapper objects

## TL;DR
- Adds `__tvm_ffi_tensor__` protocol: any Python object implementing `__tvm_ffi_tensor__() -> tvm_ffi.Tensor` can be passed directly to FFI functions as a Tensor argument.
- New `TVMFFIPyArgSetterFFITensorCompatible_` setter in the arg-setter factory dispatches before the DLPack exchange API path, extracting the inner `Tensor` and managing reference counting for temporary objects.

## Key Exports

**Protocol: `__tvm_ffi_tensor__`**:
- Any class with `__tvm_ffi_tensor__(self) -> tvm_ffi.Tensor` is recognized by the type-cached arg setter factory.
- Checked on `type(arg)` (class-level), not instance-level.
- Priority: dispatched before `__c_dlpack_exchange_api__` in the factory chain.

**Cython function: `TVMFFIPyArgSetterFFITensorCompatible_`** (`function.pxi`):
- Signature: `(TVMFFIPyArgSetter*, TVMFFIPyCallContext*, PyObject*, TVMFFIAny*) -> int`
- Calls `arg.__tvm_ffi_tensor__()` to get the inner `Tensor`.
- If `Py_REFCNT(tensor) == 1` (temporary), increments the C handle refcount and pushes it to the context's temp object list to keep it alive.

## Impact
- API: New Python protocol `__tvm_ffi_tensor__`. Additive, non-breaking.
- Behavioral: Objects with `__tvm_ffi_tensor__` are now auto-detected and fast-pathed before DLPack. The `arg_class = type(arg)` extraction was hoisted above the DLPack check (minor reordering in factory).
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

From `tests/python/test_tensor.py`:
```python
class MyTensor:
    def __init__(self, tensor: tvm_ffi.Tensor) -> None:
        self._tensor = tensor

    def __tvm_ffi_tensor__(self) -> tvm_ffi.Tensor:
        return self._tensor

data = np.zeros((10, 8, 4, 2), dtype="int32")
x = tvm_ffi.from_dlpack(data)
y = MyTensor(x)
fecho = tvm_ffi.get_global_func("testing.echo")
z = fecho(y)  # auto-dispatched via __tvm_ffi_tensor__ protocol
assert z.__chandle__() == x.__chandle__()
```
