# Introduce __tvm_ffi_tensor__ protocol for fast tensor member extraction in Cython arg dispatch
## TL;DR
- Adds a new `__tvm_ffi_tensor__` dunder protocol that allows arbitrary Python objects wrapping an `ffi.Tensor` member to be passed directly to FFI function calls without DLPack round-tripping.
- Implements a new Cython arg setter (`TVMFFIPyArgSetterFFITensorCompatible_`) that extracts the inner `Tensor` via the protocol method and handles temporary tensor lifetime via ref-count inspection.
- The new protocol is checked in the factory dispatch chain after `ObjectRValueRef` and before the DLPack C exchange API checks, giving it higher priority than DLPack-based tensor conversion paths.

## Key Exports

**Protocols**:
- `__tvm_ffi_tensor__() -> tvm_ffi.Tensor` -- Python dunder protocol. Any class defining this method on the class (not instance) can be passed as a tensor argument to FFI functions. The method must return an `ffi.Tensor` instance. Checked via `hasattr(type(arg), "__tvm_ffi_tensor__")` in the setter factory.

**Cython functions (internal)**:
- `TVMFFIPyArgSetterFFITensorCompatible_(handle, ctx, py_arg, out) -> int` -- Cython `cdef` setter function. Calls `arg.__tvm_ffi_tensor__()`, reads the `chandle` from the returned `Tensor`, sets `out.type_index = kTVMFFITensor` and `out.v_ptr = chandle`. If `Py_REFCNT(tensor) == 1` (the returned tensor is temporary), increments the object ref count and pushes it to the call context's temp object list to keep it alive through the call.

## Impact
- API: New protocol `__tvm_ffi_tensor__` enables any Python class wrapping a `Tensor` to participate in FFI calls without implementing DLPack. No existing APIs are changed.
- ABI: None.
- Behavioral: The setter factory dispatch order is modified: `type(arg)` is now extracted into `arg_class` before the `__tvm_ffi_tensor__` check, and this variable is reused for the subsequent `__c_dlpack_exchange_api__` check (previously `type(arg)` was called again there). This is a minor code-sharing change with no behavioral effect.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

**Wrapping an ffi.Tensor in a custom class and passing to FFI calls:**
```python
import tvm_ffi
import numpy as np

class MyTensor:
    def __init__(self, tensor: tvm_ffi.Tensor) -> None:
        self._tensor = tensor

    def __tvm_ffi_tensor__(self) -> tvm_ffi.Tensor:
        return self._tensor

data = np.zeros((10, 8, 4, 2), dtype="int32")
x = tvm_ffi.from_dlpack(data)
y = MyTensor(x)
fecho = tvm_ffi.get_global_func("testing.echo")
z = fecho(y)  # y is auto-converted via __tvm_ffi_tensor__ protocol
assert z.__chandle__() == x.__chandle__()  # same underlying tensor
```
