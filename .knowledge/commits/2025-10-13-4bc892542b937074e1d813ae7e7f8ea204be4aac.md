# Introduce __tvm_ffi_tensor__ protocol for fast tensor member access in Cython arg dispatch

## TL;DR
- Adds a new `__tvm_ffi_tensor__()` dunder protocol allowing Python classes that hold an `ffi.Tensor` as a member to be passed directly to FFI calls without manual unwrapping.
- Implements `TVMFFIPyArgSetterFFITensorCompatible_` in `function.pxi` with ref-count-aware keep-alive logic for temporary tensors.
- Inserts the new setter into `TVMFFIPyArgSetterFactory_` after `ObjectRValueRef` and before `__c_dlpack_exchange_api__`, giving it priority over DLPack-based conversion paths.

## Key Exports

```python
# === New dunder protocol (Python convention) ===

class TVMFFITensorCompatible(Protocol):
    """Any Python class implementing this protocol can be passed directly
    to FFI calls as a Tensor argument."""
    def __tvm_ffi_tensor__(self) -> "tvm_ffi.Tensor": ...
    # Interacts with: TVMFFIPyArgSetterFFITensorCompatible_ (dispatched via TVMFFIPyArgSetterFactory_)
    # Invariant: must return a valid tvm_ffi.Tensor (not None, not a DLPack capsule)
    # Extension: any wrapper class holding ffi.Tensor as a member can implement this

# === New Cython arg setter (function.pxi) ===

def TVMFFIPyArgSetterFFITensorCompatible_(
    handle: TVMFFIPyArgSetter,
    ctx: TVMFFIPyCallContext,
    py_arg: PyObject,
    out: Ptr[TVMFFIAny],
) -> int: ...
    # 1. Call arg.__tvm_ffi_tensor__() to get the Tensor
    # 2. Read Py_REFCNT(tensor) BEFORE extracting chandle
    # 3. Set out.type_index = kTVMFFITensor, out.v_ptr = tensor.chandle
    # 4. If ref_count == 1 (tensor is temporary): IncRef + PushTempFFIObject to keep alive
    # Interacts with: TVMFFIPyPushTempFFIObject (temp lifetime management)
    # Interacts with: TVMFFIObjectIncRef (prevents premature free of temporary tensor)
    # Invariant: ref_count == 1 check detects when __tvm_ffi_tensor__ returns a freshly
    #   constructed or sole-reference tensor that would be freed on scope exit
```

## Impact
- API: New protocol `__tvm_ffi_tensor__` -- any class implementing this dunder method can be passed as an FFI Tensor argument. No existing callers broken.
- Behavioral: none -- additive only, inserted before DLPack paths so existing dispatch order is preserved for existing types.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TVMFFIPyArgSetterFactory_ dispatch chain** (0012-python-bindings.md) -- new branch inserted at position after `ObjectRValueRef` and before `__c_dlpack_exchange_api__`
- **TVMFFIPyCallContext temp object management** (0012-python-bindings.md) -- uses `TVMFFIPyPushTempFFIObject` for keep-alive
- **TVMFFIPyArgSetter function pointer pattern** (0012-python-bindings.md) -- follows same `cdef int Setter_(handle, ctx, py_arg, out) except -1` signature
- **Py_REFCNT** (CPython C API) -- imported in `base.pxi` for ref-count inspection

Design elements this commit produces:
- **`__tvm_ffi_tensor__` protocol** -- a new dunder convention for classes wrapping `ffi.Tensor` as a member, enabling zero-DLPack-overhead tensor argument passing
- **`TVMFFIPyArgSetterFFITensorCompatible_`** -- the Cython setter implementing the protocol dispatch

## Usage Examples

From `tests/python/test_tensor.py::test_tvm_ffi_tensor_compatible`:

```python
import numpy as np
import tvm_ffi

class MyTensor:
    def __init__(self, tensor: tvm_ffi.Tensor) -> None:
        self._tensor = tensor

    def __tvm_ffi_tensor__(self) -> tvm_ffi.Tensor:
        return self._tensor

data = np.zeros((10, 8, 4, 2), dtype="int32")
x = tvm_ffi.from_dlpack(data)
y = MyTensor(x)
fecho = tvm_ffi.get_global_func("testing.echo")
z = fecho(y)  # y is auto-converted via __tvm_ffi_tensor__ protocol
assert z.__chandle__() == x.__chandle__()
```
