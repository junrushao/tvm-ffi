# Introduce __tvm_ffi_tensor__ protocol for zero-copy Tensor wrapper pass-through

## TL;DR
- Adds the `__tvm_ffi_tensor__()` dunder protocol: any Python class that implements this method can be passed directly as an FFI argument wherever `ffi.Tensor` is expected.
- Registers `TVMFFIPyArgSetterFFITensorCompatible_` in `TVMFFIPyArgSetterFactory_`, checked before DLPack, enabling zero-copy dispatch for wrapper classes that hold a `ffi.Tensor` as a member.
- Handles temporary tensor lifetime: if the returned `Tensor`'s refcount is 1 (caller holds the only reference), `IncRef` + push to the call context temp stack to prevent premature deallocation.

## Key Exports

```python
# Protocol (duck-typed, not a formal ABC):
class __tvm_ffi_tensor__Protocol:
    """Any Python class that wraps a ffi.Tensor and wishes to be passed
    directly to FFI call sites without DLPack round-trip."""

    def __tvm_ffi_tensor__(self) -> tvm_ffi.Tensor:
        """Return the underlying ffi.Tensor.
        # Invariant: returned Tensor must be a valid ffi.Tensor (chandle != NULL).
        # Interacts with: TVMFFIPyArgSetterFFITensorCompatible_, TVMFFIPyArgSetterFactory_
        """
        ...


# Cython setter registered for this protocol (pseudocode):
def TVMFFIPyArgSetterFFITensorCompatible_(handle, ctx, py_arg, out):
    """Setter function stored in TVMFFIPyArgSetter.func for __tvm_ffi_tensor__ implementors.
    # Invariant: py_arg.__tvm_ffi_tensor__() must return a live ffi.Tensor.
    # Interacts with: TVMFFIPyCallContext temp stack, TVMFFIObjectIncRef, Py_REFCNT
    # Extension: protocol is detected at class level (hasattr check), cached in dispatch table.
    """
    tensor: Tensor = py_arg.__tvm_ffi_tensor__()
    ref_count = Py_REFCNT(tensor)
    temp_chandle = tensor.chandle
    out.type_index = kTVMFFITensor
    out.v_ptr = temp_chandle
    if ref_count == 1:
        # tensor is temporary — IncRef and push to temp stack to keep alive
        TVMFFIObjectIncRef(temp_chandle)
        TVMFFIPyPushTempFFIObject(ctx, temp_chandle)


# Registration point in TVMFFIPyArgSetterFactory_ (dispatch priority):
# 1. isinstance(arg, Tensor/TensorView)         → TVMFFIPyArgSetterTensor_
# 2. isinstance(arg, ObjectRValueRef)            → TVMFFIPyArgSetterObjectRValueRef_
# 3. hasattr(type(arg), "__tvm_ffi_tensor__")    → TVMFFIPyArgSetterFFITensorCompatible_  [NEW]
# 4. hasattr(type(arg), "__c_dlpack_exchange_api__") → TVMFFIPyArgSetterDLPackExchangeAPI_
# 5. hasattr(type(arg), "__dlpack__")            → TVMFFIPyArgSetterDLPack_
# ...
```

## Impact
- API: New protocol `__tvm_ffi_tensor__()`. Any class implementing it becomes FFI-callable as a `Tensor` argument without code changes at call sites.
- Behavioral: Dispatch priority is above DLPack; classes implementing both `__tvm_ffi_tensor__` and `__dlpack__` will use the FFI-native path. No change to existing dispatch for classes that do not implement the new protocol.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

End-to-end: define a wrapper class, pass it to an FFI function expecting `Tensor`.

```python
import numpy as np
import tvm_ffi

class MyTensor:
    def __init__(self, tensor: tvm_ffi.Tensor) -> None:
        self._tensor = tensor

    def __tvm_ffi_tensor__(self) -> tvm_ffi.Tensor:
        return self._tensor

data = np.zeros((10, 8, 4, 2), dtype="int32")
x = tvm_ffi.from_dlpack(data)
y = MyTensor(x)

fecho = tvm_ffi.get_global_func("testing.echo")
z = fecho(y)                          # dispatched via __tvm_ffi_tensor__
assert z.__chandle__() == x.__chandle__()
```
