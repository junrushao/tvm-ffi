# Introduce __tvm_ffi_tensor__ protocol for fast tensor fetch in calls
## TL;DR
- Adds `__tvm_ffi_tensor__()` protocol: if a Python object defines this method, the FFI call dispatch will call it to get the underlying `ffi.Tensor`, enabling fast tensor argument passing for wrapper types.
- Adds benchmark script for DLPack performance comparison.

## Impact
- API: New protocol method `__tvm_ffi_tensor__()` recognized by FFI call dispatch.
