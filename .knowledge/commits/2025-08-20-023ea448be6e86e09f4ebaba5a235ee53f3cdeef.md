# Relocate env/module C APIs from core to extra and rename module-scoped symbols
## TL;DR
- Reorganizes `c_api.h` by moving user-facing C API declarations earlier in the file (before type reflection) and removing env/module APIs from core header.
- Moves `TVMFFIEnvCheckSignals`, `TVMFFIEnvRegisterCAPI` declarations from `c_api.h` to `extra/c_env_api.h`, with `EnvCAPIRegistry` implementation relocated from `src/ffi/function.cc` to new `src/ffi/extra/env_c_api.cc`.
- Renames three module-scoped C API symbols to include `Mod` prefix for clarity.

| Old Name | New Name | File |
|---|---|---|
| `TVMFFIEnvLookupFromImports` | `TVMFFIEnvModLookupFromImports` | `extra/c_env_api.h` |
| `TVMFFIEnvRegisterContextSymbol` | `TVMFFIEnvModRegisterContextSymbol` | `extra/c_env_api.h` |
| `TVMFFIEnvRegisterSystemLibSymbol` | `TVMFFIEnvModRegisterSystemLibSymbol` | `extra/c_env_api.h` |
| `TVMFFIEnvRegisterCAPI(const TVMFFIByteArray*, void*)` | `TVMFFIEnvRegisterCAPI(const char*, void*)` | Moved from `c_api.h` to `extra/c_env_api.h` (signature change) |
| `src/ffi/testing.cc` | `src/ffi/extra/testing.cc` | Build: moved from core to extra |

## Impact
- API: Breaking rename of three C API symbols (`TVMFFIEnvLookupFromImports` -> `TVMFFIEnvModLookupFromImports`, etc.) and signature change for `TVMFFIEnvRegisterCAPI` (`TVMFFIByteArray*` -> `const char*`). Callers using the old names or old signature must update. Callers including only `c_api.h` for `TVMFFIEnvCheckSignals`/`TVMFFIEnvRegisterCAPI` must now also include `extra/c_env_api.h`.
- Behavioral: None -- implementations are identical, only relocated.
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` CMake flag now gates compilation of `env_c_api.cc` and `testing.cc` (previously in core build).
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- C ABI layer (`c_api.h`) -- reorganizes section ordering of existing declarations (design record `0007-c-abi`)
- Module system (`extra/c_env_api.h`) -- renames module-scoped C symbols
- Error propagation -- `EnvCAPIRegistry` and signal checking mechanism (design record `0004-error-propagation`)

Design elements this commit produces:
- Naming convention: `TVMFFIEnvMod*` prefix for module-scoped environment C API symbols, distinguishing them from general environment APIs (`TVMFFIEnv*`)
- Build boundary: `EnvCAPIRegistry` and testing utilities now require `TVM_FFI_USE_EXTRA_CXX_API` to compile

## Usage Examples
Before/after for callers of renamed symbols:
```c
// BEFORE
#include <tvm/ffi/c_api.h>
TVMFFIEnvLookupFromImports(ctx, "func_name", &out);
TVMFFIEnvRegisterContextSymbol("sym", ptr);
TVMFFIEnvRegisterSystemLibSymbol("sym", ptr);
TVMFFIByteArray name = {"PyErr_CheckSignals", 18};
TVMFFIEnvRegisterCAPI(&name, fptr);

// AFTER
#include <tvm/ffi/extra/c_env_api.h>
TVMFFIEnvModLookupFromImports(ctx, "func_name", &out);
TVMFFIEnvModRegisterContextSymbol("sym", ptr);
TVMFFIEnvModRegisterSystemLibSymbol("sym", ptr);
TVMFFIEnvRegisterCAPI("PyErr_CheckSignals", fptr);  // simplified signature
```
