# Reorganize C API: move env/module APIs to extra, rename module-scoped symbols
## TL;DR
- Regroups `c_api.h` declarations: moves core APIs (object, function, error, DLPack, dtype) earlier in the file, before type reflection, removing a late "User APIs" section that mixed concerns.
- Moves `EnvCAPIRegistry` class and `TVMFFIEnvCheckSignals`/`TVMFFIEnvRegisterCAPI` implementations from `src/ffi/function.cc` to new `src/ffi/extra/env_c_api.cc`, and their declarations from `c_api.h` to `extra/c_env_api.h`.
- Renames three module-scoped C API functions to include `Mod` prefix: `TVMFFIEnvLookupFromImports` -> `TVMFFIEnvModLookupFromImports`, `TVMFFIEnvRegisterContextSymbol` -> `TVMFFIEnvModRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol` -> `TVMFFIEnvModRegisterSystemLibSymbol`.
- Changes `TVMFFIEnvRegisterCAPI` parameter from `const TVMFFIByteArray* name` to `const char* name`.

| Old Name | New Name |
|---|---|
| `TVMFFIEnvLookupFromImports` | `TVMFFIEnvModLookupFromImports` |
| `TVMFFIEnvRegisterContextSymbol` | `TVMFFIEnvModRegisterContextSymbol` |
| `TVMFFIEnvRegisterSystemLibSymbol` | `TVMFFIEnvModRegisterSystemLibSymbol` |

## Impact
- API: **Breaking** -- three C API functions renamed (`TVMFFIEnvLookupFromImports` -> `TVMFFIEnvModLookupFromImports`, `TVMFFIEnvRegisterContextSymbol` -> `TVMFFIEnvModRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol` -> `TVMFFIEnvModRegisterSystemLibSymbol`). `TVMFFIEnvRegisterCAPI` signature changed from `TVMFFIByteArray*` to `const char*`. `TVMFFIEnvCheckSignals` and `TVMFFIEnvRegisterCAPI` removed from `c_api.h` (now only in `extra/c_env_api.h`). Callers including only `c_api.h` will get compile errors for these symbols.
- Behavioral: None -- all implementations are code-moved with identical logic.
- Flags/config: `testing.cc` moved from core to extra; only built when `TVM_FFI_USE_EXTRA_CXX_API=ON`.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- C ABI surface (`c_api.h`) -- [0001-ffi-c-abi](../design-records/0001-ffi-c-abi.md): regroups existing declarations into logical sections (object, function, error, DLPack, dtype, type reflection).
- Error protocol -- [0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md): `TVMFFIEnvCheckSignals` moved but not changed.
- Module system (`extra/c_env_api.h`): consumes `ModuleObj::InternalUnsafe` for import lookup.

Design elements this commit produces:
- **Core/extra API boundary convention**: establishes the pattern that environment-specific APIs (`Env*`) belong in `extra/c_env_api.h`, not `c_api.h`. Core `c_api.h` now only contains APIs needed by all embedders; `extra/` holds host-environment and module APIs.
- **`Mod` naming convention for module-scoped env APIs**: `TVMFFIEnvMod*` prefix distinguishes module-context operations from general environment operations (`TVMFFIEnv*`).
- **`EnvCAPIRegistry` as standalone compilation unit**: previously embedded in `function.cc`, now in its own file under `extra/`, making the env API independently linkable.
