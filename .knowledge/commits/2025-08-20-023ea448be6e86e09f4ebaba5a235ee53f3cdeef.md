# Relocate env C APIs from core to extra and rename module-scoped env functions

## TL;DR
- Moved `EnvCAPIRegistry` class and its two C API functions (`TVMFFIEnvCheckSignals`, `TVMFFIEnvRegisterCAPI`) from core `src/ffi/function.cc` to `src/ffi/extra/env_c_api.cc`, making them part of the optional "extra" build target.
- Renamed three module-scoped C API functions with a `Mod` infix to clarify they operate on module contexts, not the global environment: `TVMFFIEnvLookupFromImports` -> `TVMFFIEnvModLookupFromImports`, `TVMFFIEnvRegisterContextSymbol` -> `TVMFFIEnvModRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol` -> `TVMFFIEnvModRegisterSystemLibSymbol`.
- Reordered `c_api.h` sections: moved basic object, function-calling, error, DLPack, and dtype APIs to appear immediately after struct definitions (before type reflection), and removed them from the later "User APIs" section.

| Old Name | New Name | Location Change |
|---|---|---|
| `TVMFFIEnvLookupFromImports` | `TVMFFIEnvModLookupFromImports` | stayed in `c_env_api.h` |
| `TVMFFIEnvRegisterContextSymbol` | `TVMFFIEnvModRegisterContextSymbol` | stayed in `c_env_api.h` |
| `TVMFFIEnvRegisterSystemLibSymbol` | `TVMFFIEnvModRegisterSystemLibSymbol` | stayed in `c_env_api.h` |
| `TVMFFIEnvCheckSignals` | (unchanged) | `c_api.h` -> `c_env_api.h` |
| `TVMFFIEnvRegisterCAPI` | (unchanged, signature changed) | `c_api.h` -> `c_env_api.h` |
| `EnvCAPIRegistry` class | (unchanged) | `function.cc` -> `extra/env_c_api.cc` |
| `src/ffi/testing.cc` | `src/ffi/extra/testing.cc` | file rename |

## Impact
- API: Breaking rename of 3 C API symbols (`TVMFFIEnvLookupFromImports`, `TVMFFIEnvRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol`). Callers using these symbols by name (e.g., `__tvm_ffi_EnvLookupFromImports` in compiled modules) must update. Signature change for `TVMFFIEnvRegisterCAPI` (from `TVMFFIByteArray*` to `const char*`).
- Behavioral: None -- all implementations are identical before/after.
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` cmake flag now controls compilation of `env_c_api.cc` and `testing.cc` (previously they were always compiled).
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- C ABI function table pattern ([.knowledge/designs/0001-c-abi.md](../designs/0001-c-abi.md)) -- all renamed functions follow the `TVM_FFI_DLL` convention
- Module system (extra/module.cc, extra/library_module.cc) -- the `TVMFFIEnvMod*` functions support module import resolution and symbol registration
- Error/signal handling pattern ([.knowledge/designs/0005-error-system.md](../designs/0005-error-system.md)) -- `TVMFFIEnvCheckSignals` pattern
- `TVM_FFI_SAFE_CALL_BEGIN`/`TVM_FFI_SAFE_CALL_END` macro pair for C ABI boundary

Design elements this commit produces:
- **API layering convention**: The commit establishes a clearer separation between "core" C API (always available, in `c_api.h`) and "extra" C API (requires `TVM_FFI_USE_EXTRA_CXX_API`, in `c_env_api.h`). Environment/Python-specific APIs and module-scoped APIs live in `extra/`.
- **Naming convention for module-scoped env APIs**: The `TVMFFIEnvMod` prefix distinguishes module-context operations (module imports, context symbols, system lib symbols) from global environment operations (`TVMFFIEnvCheckSignals`, `TVMFFIEnvRegisterCAPI`).
- **c_api.h section ordering**: Sections now follow dependency order -- struct definitions -> basic object API -> function calling -> error handling -> DLPack -> dtype -> type reflection -> registration -> backend noexcept.

## Usage Examples

Before/after for callers of renamed functions:

```c
// BEFORE
TVMFFIEnvLookupFromImports(lib_ctx, "my_func", &out);
TVMFFIEnvRegisterContextSymbol("my_sym", ptr);
TVMFFIEnvRegisterSystemLibSymbol("my_sym", ptr);

// AFTER
TVMFFIEnvModLookupFromImports(lib_ctx, "my_func", &out);
TVMFFIEnvModRegisterContextSymbol("my_sym", ptr);
TVMFFIEnvModRegisterSystemLibSymbol("my_sym", ptr);
```

Before/after for `TVMFFIEnvRegisterCAPI` signature change:

```c
// BEFORE (accepted TVMFFIByteArray*)
TVMFFIByteArray name = {"PyErr_CheckSignals", 18};
TVMFFIEnvRegisterCAPI(&name, (void*)PyErr_CheckSignals);

// AFTER (accepts const char* directly)
TVMFFIEnvRegisterCAPI("PyErr_CheckSignals", (void*)PyErr_CheckSignals);
```
