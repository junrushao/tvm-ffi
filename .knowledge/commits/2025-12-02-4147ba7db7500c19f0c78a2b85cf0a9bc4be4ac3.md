# Fix from_dlpack universal fallback to use _get_dlpack_exchange_api() instead of raw integer cast after PyCapsule upgrade

## TL;DR
- `_from_dlpack_universal` was casting `ext_tensor.__c_dlpack_exchange_api__` directly as a raw integer (`<DLPackExchangeAPI*><long long>(...)`), bypassing `_get_dlpack_exchange_api()`, which broke after commit `7f3bb771` changed the canonical form to `PyCapsule("dlpack_exchange_api")`.
- Fix: declare `cdef const DLPackExchangeAPI* exchange_api = NULL` and call `_get_dlpack_exchange_api(ext_tensor.__c_dlpack_exchange_api__, &exchange_api)` before forwarding to `_from_dlpack_exchange_api`.
- Also fixes `_from_dlpack_exchange_api` signature from `DLPackExchangeAPI*` to `const DLPackExchangeAPI*` for const-correctness. Adds a regression test `test_from_dlpack_torch`.

## Key Exports

```python
# ─── python/tvm_ffi/cython/tensor.pxi ──────────────────────────────────────

# BEFORE (broken after 7f3bb771 PyCapsule upgrade):
cdef inline int _from_dlpack_universal(object ext_tensor, ...):
    if hasattr(ext_tensor, "__c_dlpack_exchange_api__"):
        return _from_dlpack_exchange_api(
            ext_tensor,
            <DLPackExchangeAPI*><long long>(ext_tensor.__c_dlpack_exchange_api__),  # WRONG: assumes int form
            ...
        )

# AFTER (correct):
cdef inline int _from_dlpack_universal(object ext_tensor, ...):
    cdef const DLPackExchangeAPI* exchange_api = NULL
    if hasattr(ext_tensor, "__c_dlpack_exchange_api__"):
        _get_dlpack_exchange_api(ext_tensor.__c_dlpack_exchange_api__, &exchange_api)  # handles int OR PyCapsule
        return _from_dlpack_exchange_api(ext_tensor, exchange_api, ...)

# Signature fix (const-correctness):
# BEFORE: cdef inline int _from_dlpack_exchange_api(object ext_tensor, DLPackExchangeAPI* exchange_api, ...)
# AFTER:  cdef inline int _from_dlpack_exchange_api(object ext_tensor, const DLPackExchangeAPI* exchange_api, ...)
# Invariant: exchange_api pointer comes from _get_dlpack_exchange_api which validates int or PyCapsule form
# Interacts with: _get_dlpack_exchange_api (commit 7f3bb771), DLPackExchangeAPI (commit 22a78943)
```

## Impact
- API: none — internal Cython call path only
- Behavioral: `tvm_ffi.from_dlpack(torch_tensor)` now works correctly when PyTorch registers `__c_dlpack_exchange_api__` as a `PyCapsule` (as done by the torch DLPack addon after commit `7f3bb771`). Previously raised `ValueError("Expect a dlpack_exchange_api field")` or performed an unsafe reinterpret cast.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Before/after showing incorrect vs corrected usage:

```python
# After commit 7f3bb771: torch DLPack addon sets the attribute as PyCapsule
# torch.Tensor.__c_dlpack_exchange_api__ = PyCapsule("dlpack_exchange_api")

import tvm_ffi
import torch

t = torch.arange(24, dtype=torch.float32).reshape(2, 3, 4)

# BEFORE this fix: from_dlpack raises ValueError or crashes
# (raw integer cast fails for PyCapsule form)
# tvm_ffi.from_dlpack(t)  # ERROR

# AFTER this fix: works correctly via PyCapsule path
result = tvm_ffi.from_dlpack(t)
assert result.shape == t.shape        # (2, 3, 4)
assert result.dtype == tvm_ffi.float32
```
