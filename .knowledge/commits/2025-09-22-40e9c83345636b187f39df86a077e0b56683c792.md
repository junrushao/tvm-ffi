# Enable mypy type checking across Python codebase and tests
## TL;DR
- Adds mypy as a pre-commit hook for `python/`, `tests/`, and `examples/` directories, with `allow_redefinition` and `ignore_missing_imports` in `pyproject.toml`.
- Modernizes type annotations throughout: `from __future__ import annotations`, `X | None` over `Optional[X]`, `@overload` for `get_global_func`, and explicit field annotations on `testing.*` classes.
- Creates `_ffi_api.pyi` stub file to describe dynamically-registered FFI functions, and refactors `Field` from `@dataclass` to manual `__init__`/`__slots__` for mypy compatibility.
