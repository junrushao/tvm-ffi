# Enable mypy type checking across Python codebase
## TL;DR
- Adds mypy pre-commit hook and `pyproject.toml` configuration, enabling static type checking for `python/`, `tests/`, and `examples/`.
- Adds `_ffi_api.pyi` stub file for the dynamic FFI API module.
- Applies extensive type annotation fixes across the Python codebase: explicit casts, `Optional` annotations, return types, and variable type hints to satisfy mypy strict mode.
- Updates many modules (`registry.py`, `_convert.py`, `_tensor.py`, `load_inline.py`, `dataclasses/`, `error.py`, `testing.py`, etc.) with type-correct signatures.
