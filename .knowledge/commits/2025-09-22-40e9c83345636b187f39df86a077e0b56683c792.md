# Enable mypy type checking across Python codebase with type annotation fixes

## TL;DR
- Adds mypy as a pre-commit hook (v1.17.0) for `python/`, `tests/`, and `examples/` directories, with `ignore_missing_imports` and `allow_redefinition` in `pyproject.toml`.
- Fixes ~200 type annotation issues: replaces `Optional[X]` with `X | None` (post-PEP-604), adds `from __future__ import annotations` to files that lacked it, adds `# type: ignore` comments for dynamic FFI attributes, and improves type narrowing for conditional imports.
- Refactors `register_object`, `load_inline`, `Field`, and `_add_class_attrs` for type-correctness without changing runtime behavior; adds `@overload` signatures for `get_global_func`.

## Impact
- API: `get_global_func` now has `@overload` signatures enabling callers to get non-Optional return when `allow_missing=False`. `register_object` return type narrowed from `Any` to `Callable[[type], type] | type`. `Field` is no longer a dataclass (internal detail, no public API break since `field()` factory is the documented entry point).
- Behavioral: None. All changes are type-annotation-only or internal refactoring that preserves runtime semantics. The `_find_cuda_home` change to raise `RuntimeError` instead of returning empty string on Windows is the only behavioral change (previously returned `""` when no CUDA found, now raises).
- Flags/config: New `[tool.mypy]` section in `pyproject.toml` with `allow_redefinition = true` and `ignore_missing_imports = true`. Four mypy hooks added to `.pre-commit-config.yaml` targeting `python/`, `tests/`, `examples/inline_module`, `examples/packaging`, and `examples/quick_start`. All exclude `_ffi_api.py` files.
- Data formats/schemas: None.

## Usage Examples

The `@overload` pattern for `get_global_func`:

```python
# When allow_missing=False (default), mypy knows result is non-None:
f: tvm_ffi.Function = tvm_ffi.get_global_func("testing.echo")
f(1, 2, 3)

# When allow_missing=True, mypy knows result may be None:
f_or_none: tvm_ffi.Function | None = tvm_ffi.get_global_func("maybe.exists", allow_missing=True)
if f_or_none is not None:
    f_or_none(1, 2, 3)
```

The mypy-safe conditional import pattern for optional dependencies:

```python
from types import ModuleType

torch: ModuleType | None = None
try:
    import torch  # type: ignore[no-redef]
except ImportError:
    pass
```
