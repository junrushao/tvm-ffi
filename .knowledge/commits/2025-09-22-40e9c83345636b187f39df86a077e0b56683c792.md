# Enable mypy static type checking across python/, tests/, and examples/

## TL;DR
- Adds mypy pre-commit hooks (4 hooks covering `python/`, `tests/`, and three `examples/` subdirs) and `[tool.mypy]` config in `pyproject.toml`.
- Refactors Python source across 25+ files to satisfy mypy: adds `from __future__ import annotations`, replaces `Optional[T]` with `T | None`, adds `# type: ignore[...]` suppressions for Cython-backed dynamic methods, and tightens local variable types.
- Adds `python/tvm_ffi/_ffi_api.pyi` stub file so mypy can type-check callers of the auto-populated FFI namespace without seeing the actual generated module.

## Key Exports

```python
# python/tvm_ffi/_ffi_api.pyi — NEW stub file for the generated FFI namespace
# Allows mypy to resolve calls like `_ffi_api.Shape(...)` without importing the real module.
# All functions typed as (*args: Any) -> Any — structural, not semantic.
# Interacts with: registry.init_ffi_api(), all modules that do `from . import _ffi_api`
# Invariant: _ffi_api.py is excluded from mypy via `exclude: ^.*/_ffi_api\.py$`; only .pyi is checked.

# registry.py — get_global_func now has @overload stubs for Literal[True/False]
@overload
def get_global_func(name: str, allow_missing: Literal[True]) -> Function | None: ...
@overload
def get_global_func(name: str, allow_missing: Literal[False] = False) -> Function: ...
def get_global_func(name: str, allow_missing: bool = False) -> Function | None: ...
# Old: def get_global_func(name: str, allow_missing: bool = False) -> Optional[Function]
# Interacts with: core._get_global_func(), callers that branch on None

# register_object — return type narrowed for mypy correctness
# Old: -> Any
# New: -> Callable[[type], type] | type
def register_object(type_key: str | type | None = None) -> Callable[[type], type] | type: ...
# Internal: _register() split into _decorator_with_name / _decorator_default to avoid closure capture issues

# load_inline — cpp_sources/cuda_sources now accept Sequence[str] (previously only str | None)
# Internal variable renaming to avoid shadowing list vs input param (cpp_source_list etc.)
# functions param narrowed to Mapping[str, str] | Sequence[str] | str | None
def load_inline(
    name: str,
    *,
    cpp_sources: Sequence[str] | str | None = None,
    cuda_sources: Sequence[str] | str | None = None,
    functions: Mapping[str, str] | Sequence[str] | str | None = None,
    extra_cflags: Sequence[str] | None = None,
    extra_cuda_cflags: Sequence[str] | None = None,
    extra_ldflags: Sequence[str] | None = None,
    extra_include_paths: Sequence[str] | None = None,
    build_directory: str | None = None,
) -> Module: ...
# Interacts with: _decorate_with_tvm_ffi, FileLock, load_module

# dataclasses/field.py — Field class no longer uses @dataclass decorator
class Field:
    __slots__ = ("default_factory", "name")
    def __init__(self, *, name: str | None = None, default_factory: Callable[[], Any]) -> None: ...
    # Old: @dataclass(kw_only=True) class Field — caused mypy incompatibility with __slots__

# dataclasses/_utils.py — method_init inner loop: list[TypeField] (was list[TypeInfo])
fields: list[TypeField] = []
cur_type_info: TypeInfo | None = type_info
# while loop now checks `while cur_type_info is not None:` instead of `while True: ... if None: break`

# core.pyi — new entries for completeness
def _convert_torch_dtype_to_ffi_dtype(torch_dtype: Any) -> DataType: ...
def _convert_numpy_dtype_to_ffi_dtype(numpy_dtype: Any) -> DataType: ...
_CLASS_TENSOR: type[Tensor] = Tensor
def _set_class_tensor(cls: type[Tensor]) -> None: ...
def _env_set_current_stream(device_type: int, device_id: int, stream: int | c_void_p) -> int | c_void_p: ...

# testing.py — explicit field annotations added to test object classes for mypy
class TestObjectBase(Object):
    v_i64: int
    v_f64: float
    v_str: str

class TestIntPair(Object):
    a: int
    b: int

class TestObjectDerived(TestObjectBase):
    v_map: Map
    v_array: Array
```

## Impact
- API: None — all public-facing function signatures are behaviorally unchanged; the `load_inline` signature change expands accepted types (additive).
- Behavioral: `_find_cuda_home()` in `load_inline.py` now raises `RuntimeError` instead of returning `""` when no CUDA installation is found on Windows; callers that tested for empty-string return will no longer work (but no known callers).
- Flags/config: `[tool.mypy] allow_redefinition = true, ignore_missing_imports = true` added to `pyproject.toml`. Four mypy pre-commit hooks added covering `python/`, `tests/`, `examples/inline_module`, `examples/packaging`, `examples/quick_start`.
- Data formats/schemas: None.

## Usage Examples

`_ffi_api.pyi` stub — how callers interact with mypy-excluded generated module:
```python
# python/tvm_ffi/_ffi_api.pyi — written once, referenced by mypy
# callers like access_path.py do:
from . import _ffi_api
shape = _ffi_api.Shape(1, 2, 3)  # mypy resolves via .pyi → (*args: Any) -> Any
```

`get_global_func` overload narrowing:
```python
# Before: mypy could not narrow the None branch
fn = get_global_func("ffi.Foo")              # -> Function (non-None)
fn2 = get_global_func("ffi.Bar", allow_missing=True)  # -> Function | None
# After: @overload with Literal[True/False] enables mypy to infer correct return type
```

`Field` class without `@dataclass`:
```python
# Before: @dataclass(kw_only=True) caused mypy to reject __slots__ + default_factory combo
# After: explicit __init__ with __slots__ = ("default_factory", "name")
f = field(default_factory=lambda: "hello")  # type: Field
```
