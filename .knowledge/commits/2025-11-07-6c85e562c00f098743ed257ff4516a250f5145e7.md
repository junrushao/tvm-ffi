# Add fallback arg setter for cuda-python driver CUstream without __cuda_stream__ protocol
## TL;DR
- Adds `TVMFFIPyArgSetterCUDADriverStreamFallback_` in Cython to handle `cuda.bindings.driver.CUstream` objects that lack the `__cuda_stream__` protocol by casting via `int(arg)` to an opaque pointer.
- Renames the existing stream setter from `TVMFFIPyArgSetterCUDAStream_` to `TVMFFIPyArgSetterCUDAStreamProtocol_` for clarity.
- Adds conditional import of `cuda.bindings.driver` in the Cython function dispatch layer.
- Fixes return type annotation of `patch_torch_cuda_stream_protocol` and the inner `__torch_cuda_stream__` function.

## Key Exports
**Cython internal functions** (not public API, but key dispatch extension points):
- `TVMFFIPyArgSetterCUDAStreamProtocol_(handle, ctx, py_arg, out) -> int` -- renamed from `TVMFFIPyArgSetterCUDAStream_`, handles objects with `__cuda_stream__` protocol
- `TVMFFIPyArgSetterCUDADriverStreamFallback_(handle, ctx, py_arg, out) -> int` -- new fallback for `cuda_driver.CUstream`, casts `int(arg)` to `kTVMFFIOpaquePtr`

## Impact
- API: none (no public API change)
- Behavioral: `cuda.bindings.driver.CUstream` objects can now be passed as FFI arguments without requiring `__cuda_stream__` protocol support
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Cython arg setter dispatch factory (`TVMFFIPyArgSetterFactory_`) per `.knowledge/designs/0015-python-ffi-call-dispatch.md` -- the factory dispatches to per-type setter functions based on type checks
- `kTVMFFIOpaquePtr` type index from the Any value system per `.knowledge/designs/0002-any-value-system.md`
- CUDA stream protocol convention (`__cuda_stream__`)

Design elements this commit produces:
- New dispatch path in `TVMFFIPyArgSetterFactory_`: `cuda_driver.CUstream` isinstance check as a fallback after `__cuda_stream__` protocol check. Marked as temporary (`TODO: remove once cuda-python supports __cuda_stream__`).

## Usage Examples
```python
from cuda.bindings import driver as cuda_driver
import tvm_ffi

echo = tvm_ffi.get_global_func("testing.echo")
stream = cuda_driver.CUstream(0)
result = echo(stream)  # Now works without __cuda_stream__ protocol
```
