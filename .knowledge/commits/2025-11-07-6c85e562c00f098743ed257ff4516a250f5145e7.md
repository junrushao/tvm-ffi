# Add cuda-python driver CUstream fallback in FFI arg dispatch

## TL;DR
- Adds `TVMFFIPyArgSetterCUDADriverStreamFallback_` in `function.pxi` to handle `cuda.bindings.driver.CUstream` objects that lack the `__cuda_stream__` protocol, converting them to `kTVMFFIOpaquePtr` via `int(arg)`.
- Renames existing `TVMFFIPyArgSetterCUDAStream_` to `TVMFFIPyArgSetterCUDAStreamProtocol_` to clarify it handles the protocol-based path.
- Fixes type annotations in `_optional_torch_c_dlpack.py`: `patch_torch_cuda_stream_protocol` return `None` (was `Any`), `__torch_cuda_stream__` returns `tuple[int, int]` (was `tuple[int, torch.cuda.Stream]`).

## Impact
- API: None — internal Cython `cdef` functions, not exposed to Python API.
- Behavioral: `cuda_driver.CUstream` objects can now be passed directly to FFI functions without requiring `__cuda_stream__` protocol support. They are converted to opaque void pointers.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **TVMFFIPyArgSetterFactory_ dispatch chain** (`.knowledge/designs/0012-python-bindings.md`): Adds a new branch in the per-type dispatch factory.
- **`kTVMFFIOpaquePtr` type tag** (`.knowledge/designs/0003-any-system.md`): Both the protocol and fallback setters convert stream handles to this type.
- **`__cuda_stream__` protocol** (`.knowledge/designs/0014-stream-and-env-context.md`): The rename clarifies the existing setter handles the protocol path; the new setter is the fallback when protocol is absent.

Design elements this commit produces:
- **`TVMFFIPyArgSetterCUDADriverStreamFallback_`**: New temporary dispatch path for cuda-python streams. Marked with TODO for removal.
- **Rename: `TVMFFIPyArgSetterCUDAStream_` -> `TVMFFIPyArgSetterCUDAStreamProtocol_`**: Clarifies naming to distinguish protocol-based path from fallback.

## Usage Examples
From `tests/python/test_stream.py` (added in this commit):

```python
from cuda.bindings import driver as cuda_driver
import tvm_ffi

echo = tvm_ffi.get_global_func("testing.echo")
stream = cuda_driver.CUstream(0)
y = echo(stream)           # passes through TVMFFIPyArgSetterCUDADriverStreamFallback_
assert y is not None

z = echo(cuda_driver.CUstream(1))
assert isinstance(z, ctypes.c_void_p)
assert z.value == 1         # round-trips as opaque pointer
```
