# Enable compatibility with cuda-python driver stream objects
## TL;DR
- Adds compatibility mode for `cuda.cuda.CUstream` objects from cuda-python driver API, which do not yet support `__cuda_stream__` protocol
- Treats `CUstream` arguments as `void_p` for stream passing
- Adds test coverage for cuda-python driver stream handling

## Key Exports
```python
# In Cython function.pxi: new dispatch path for cuda-python driver streams
# When obj is a cuda.cuda.CUstream, extract its int handle as void_p
# Interacts with: TVMFFIPyArgSetter dispatch, __cuda_stream__ protocol (design-record 0012)
```

- Behavioral: cuda-python driver CUstream objects now accepted where stream handles are expected
