# Enable compact mode for cuda-python driver stream in DLPack exchange
## TL;DR
- Adds compact mode for `cuda.cuda.CUstream` arguments, treating them as raw void pointers for DLPack stream exchange.
- Updates `function.pxi` to handle `cuda_driver.CUstream` that does not yet support the CUDA stream protocol.
- Adds tests for stream-based tensor copy operations.

## Key Exports

**Functions (Cython):**
- Updated `_make_tvm_args_func` in `function.pxi` to detect `cuda.cuda.CUstream` and convert to `c_void_p`.

## Impact
- API: none (internal Cython path)
- ABI: none
- Behavioral: `cuda.cuda.CUstream` objects can now be passed through FFI as void pointers for DLPack stream exchange.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Cython function argument conversion pipeline (`function.pxi`)
- cuda-python driver stream API

Design elements this commit produces:
- Compact stream handling pattern for cuda-python driver streams lacking protocol support.

## Usage Examples
```python
import cuda.cuda as drv
err, stream = drv.cuStreamCreate(0)
tvm_ffi.nd.copy(src_tensor, dst_tensor, stream)
```
