# Add cuda-python driver CUstream fallback arg setter for streams lacking __cuda_stream__ protocol
## TL;DR
- Adds `TVMFFIPyArgSetterCUDADriverStreamFallback_` Cython setter that converts `cuda.bindings.driver.CUstream` objects to opaque `void*` by calling `int(arg)`, bypassing the `__cuda_stream__` protocol that cuda-python does not yet implement.
- Renames `TVMFFIPyArgSetterCUDAStream_` to `TVMFFIPyArgSetterCUDAStreamProtocol_` to distinguish protocol-based dispatch from the new fallback path.
- Fixes type annotations in `_optional_torch_c_dlpack.py`: `patch_torch_cuda_stream_protocol` return type `Any` -> `None`, and `__torch_cuda_stream__` return type `tuple[int, torch.cuda.Stream]` -> `tuple[int, int]`.

## Impact
- API: none -- internal Cython setter dispatch, no public Python API change
- Behavioral: `cuda.bindings.driver.CUstream` objects can now be passed directly to FFI function calls as opaque pointers, where previously they would fall through to an incorrect setter or error
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Arg setter dispatch factory** (`TVMFFIPyArgSetterFactory_` in `function.pxi`) -- the prioritized isinstance/hasattr dispatch chain that classifies Python arg types and caches setter function pointers per `PyTypeObject*`. See [0012-ffi-python-package.md](../design-records/0012-ffi-python-package.md).
- **`__cuda_stream__` protocol** -- protocol-based stream dispatch introduced in b0537f04. This commit adds a parallel fallback path for types that lack the protocol.
- **`kTVMFFIOpaquePtr` type index** -- both the protocol setter and the new fallback pack the stream pointer as `kTVMFFIOpaquePtr` in `TVMFFIAny.v_ptr`.

Design elements this commit produces:
- None -- the new setter is a compatibility shim within the existing dispatch pattern, not a new protocol or design element.

## Usage Examples
**Context**: Passing a `cuda.bindings.driver.CUstream` directly to an FFI function call. From `tests/python/test_stream.py`:
```python
from cuda.bindings import driver as cuda_driver
import tvm_ffi

echo = tvm_ffi.get_global_func("testing.echo")
stream = cuda_driver.CUstream(0)
y = echo(stream)       # dispatched via TVMFFIPyArgSetterCUDADriverStreamFallback_
assert y is not None

z = echo(cuda_driver.CUstream(1))
assert isinstance(z, ctypes.c_void_p)
assert z.value == 1     # round-trips as opaque pointer
```
