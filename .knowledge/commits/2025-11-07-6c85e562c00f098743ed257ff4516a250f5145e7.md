# Enable compat mode for cuda-python driver CUstream by treating it as void* opaque handle

## TL;DR
- `cuda_python` driver streams (`cuda.bindings.driver.CUstream`) don't yet implement the `__cuda_stream__` protocol; this commit adds a compat path that extracts the raw `void*` handle via `ctypes.c_void_p`.
- Adds test coverage in `tests/python/test_stream.py`.

## Key Exports

```python
# python/tvm_ffi/cython/function.pxi — compat mode addition
def TVMFFIPyArgSetterStream_(handle, ctx, py_arg, out) -> int:
    """Setter for stream arguments.
    # Before: only accepted __cuda_stream__ protocol
    # After: if no __cuda_stream__, tries ctypes.c_void_p extraction as compat for
    #   cuda.bindings.driver.CUstream which stores raw handle
    # Interacts with: TVMFFIEnvSetStream, ctypes.c_void_p null handling (see e6a85e9)
    # Invariant: ctypes.c_void_p(0).value is None → must check is None before casting
    """
    ...
```

## Impact
- API: none
- Behavioral: `cuda.bindings.driver.CUstream` objects can now be passed directly as stream arguments to TVM FFI functions.
- Flags/config: none
- Data formats/schemas: none
