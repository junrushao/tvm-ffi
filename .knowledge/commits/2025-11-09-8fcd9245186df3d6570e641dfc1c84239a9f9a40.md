# Introduce ffi.GetRegisteredTypeKeys() global function to enumerate all registered type keys

## TL;DR
- Adds `ffi.GetRegisteredTypeKeys()` registered global function returning `Array<String>` of all type keys currently in `TypeTable`.
- Exposed in Python as `tvm_ffi.registry.get_registered_type_keys()`.
- Primary use case: library stub generation querying C++-registered types.

## Key Exports

```python
# src/ffi/object.cc — registered global function
def GetRegisteredTypeKeys() -> Array[str]:
    """Return all type keys registered in the global TypeTable.
    # Registered as: refl::GlobalDef().def_method("ffi.GetRegisteredTypeKeys", ...)
    # Interacts with: TypeTable::Global(), TypeTable type_table_ vector
    # Invariant: includes all static builtins and dynamically registered types
    """
    ...

# python/tvm_ffi/registry.py
def get_registered_type_keys() -> list[str]:
    """Python wrapper for ffi.GetRegisteredTypeKeys().
    # Interacts with: tvm_ffi._ffi_api, global function registry
    """
    ...
```

## Impact
- API: New Python function `tvm_ffi.registry.get_registered_type_keys()`.
- Behavioral: none for existing code.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
from tvm_ffi.registry import get_registered_type_keys

keys = get_registered_type_keys()
# e.g.: ["object.Object", "runtime.Module", "ffi.String", ...]
for key in keys:
    print(key)
```

In stubgen:
```python
# enumerate all C++ types to generate stubs
type_keys = get_registered_type_keys()
for key in type_keys:
    info = TypeInfo.lookup(key)
    # generate stubs for info.fields and info.methods
```
