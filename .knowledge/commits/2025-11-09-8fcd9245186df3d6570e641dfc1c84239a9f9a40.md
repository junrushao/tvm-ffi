# Introduce get_registered_type_keys() for querying C++ registered types
## TL;DR
- Adds `tvm_ffi.registry.get_registered_type_keys()` Python API that returns all registered type keys from C++
- Adds C++ implementation `_GetRegisteredTypeKeys` as a global function
- Useful for library stub generation where Python needs to discover C++-registered objects
