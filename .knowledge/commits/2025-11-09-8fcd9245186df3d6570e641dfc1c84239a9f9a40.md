# Introduce get_registered_type_keys() for querying all registered C++ types
## TL;DR
- Adds `TypeTable::GetRegisteredTypeKeys()` C++ method that returns all registered type keys as `Array<String>`.
- Exposes it as `ffi.GetRegisteredTypeKeys` global function.
- Adds Python wrapper `tvm_ffi.registry.get_registered_type_keys()`.
- Useful for stub generation where registered types need to be queried dynamically.

## Key Exports

**C++ Methods:**
- `TypeTable::GetRegisteredTypeKeys() const -> Array<String>` -- Returns all registered type keys from the global type table.

**Global Functions:**
- `ffi.GetRegisteredTypeKeys() -> Array<String>` -- Registered global function wrapping `TypeTable::GetRegisteredTypeKeys()`.

**Python Functions:**
- `tvm_ffi.registry.get_registered_type_keys() -> list[str]` -- Python wrapper returning registered type keys.

## Usage Examples
```python
import tvm_ffi
keys = tvm_ffi.registry.get_registered_type_keys()
# Returns ["tvm.ffi.Object", "tvm.ffi.String", "tvm.ffi.Function", ...]
```
