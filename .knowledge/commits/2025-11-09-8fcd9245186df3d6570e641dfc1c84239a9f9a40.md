# Add ffi.GetRegisteredTypeKeys global function and Python wrapper for querying all registered type keys
## TL;DR
- Adds `TypeTable::GetRegisteredTypeKeys()` C++ method that iterates the global type table and returns all registered type keys as `Array<String>`.
- Registers the method as global function `ffi.GetRegisteredTypeKeys` via `GlobalDef.def_method`.
- Exposes it in Python as `tvm_ffi.registry.get_registered_type_keys()`, intended for library stub generation that needs to query C++-registered object types.
- Minor fix: `get_global_func_metadata` now handles `None` return with `or "{}"` fallback.

## Impact
- API: New public Python API `tvm_ffi.registry.get_registered_type_keys()` and C++ `TypeTable::GetRegisteredTypeKeys()`. Additive only.
- Behavioral: `get_global_func_metadata` now returns `{}` instead of raising on `None` metadata return. This is a minor robustness fix.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeTable** ([0002-object-system.md](../designs/0002-object-system.md)): Iterates `type_table_` entries to collect type keys. Uses `TypeTable::Global()` singleton.
- **GlobalDef.def_method** ([0008-reflection.md](../designs/0008-reflection.md)): Registers the new function in the global function table with full metadata.
- **get_global_func** ([0012-python-bindings.md](../designs/0012-python-bindings.md)): Python-side lookup of the registered global function by name.
- **Array\<String\>** ([0007-containers.md](../designs/0007-containers.md)): Return type from C++, auto-converted to Python `Sequence[str]`.

Design elements this commit produces:
- **ffi.GetRegisteredTypeKeys**: New global function exposing type table introspection. Intended consumer: stub generation tooling (`tvm-ffi-stubgen`).
- **get_registered_type_keys()**: Python API in `tvm_ffi.registry`, added to `__all__`.

## Usage Examples

**End-to-end: querying registered type keys from Python**
```python
import tvm_ffi

# Get all registered type keys
keys = tvm_ffi.registry.get_registered_type_keys()

# Includes primitive types
assert "int" in keys
assert "float" in keys
assert "None" in keys

# Includes object types with ffi.* prefix
assert "ffi.Object" in keys
assert "ffi.String" in keys

# All object types use namespace prefixes
for key in keys:
    if key not in {"None", "int", "bool", "float", "void*", "DataType",
                   "Device", "DLTensor*", "const char*",
                   "TVMFFIByteArray*", "ObjectRValueRef"}:
        assert "." in key  # namespace-prefixed
```
