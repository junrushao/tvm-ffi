# Add get_registered_type_keys() API to query all registered type keys from TypeTable
## TL;DR
- Adds C++ `TypeTable::GetRegisteredTypeKeys()` method that iterates the type table and returns all non-null type key strings as `Array<String>`.
- Registers it as global FFI function `ffi.GetRegisteredTypeKeys` via `refl::GlobalDef`.
- Exposes as Python `tvm_ffi.registry.get_registered_type_keys() -> Sequence[str]`.
- Minor fix: `get_global_func_metadata` now handles `None` return from `ffi.GetGlobalFuncMetadata` by defaulting to `"{}"`.

## Impact
- API: Additive only -- new public function `get_registered_type_keys()` added to `tvm_ffi.registry` and exported in `__all__`.
- Behavioral: `get_global_func_metadata()` now returns `{}` instead of raising when `ffi.GetGlobalFuncMetadata` returns `None` (defensive fix via `or "{}"`).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeTable singleton** (`0003-ffi-object-system`): reads `type_table_` entries to enumerate registered types.
- **Global function registration** (`0004-ffi-function-system`): uses `refl::GlobalDef().def_method()` in `TVM_FFI_STATIC_INIT_BLOCK` to register the new C++ method.
- **Python FFI bridge** (`0012-ffi-python-package`): `get_global_func("ffi.GetRegisteredTypeKeys")` to call C++ from Python.

Design elements this commit produces:
- **`ffi.GetRegisteredTypeKeys` global function**: new FFI-registered function exposing the TypeTable's type key inventory. Useful for stub generation and introspection.
- **`tvm_ffi.registry.get_registered_type_keys()`**: Python public API wrapper.

## Usage Examples
From the test added in this commit (`tests/python/test_object.py`):

```python
import tvm_ffi

# Query all registered type keys
keys = tvm_ffi.registry.get_registered_type_keys()

# Returns a sequence of strings; includes both POD type keys
# and object type keys (prefixed with "ffi." or package namespace)
assert "ffi.Object" in set(keys)
assert "ffi.String" in set(keys)
assert "int" in set(keys)
```
