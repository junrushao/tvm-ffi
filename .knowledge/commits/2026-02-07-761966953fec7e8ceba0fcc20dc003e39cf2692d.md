# Switch Python type checker from mypy to ty (Astral)
## TL;DR
- Replaces `mypy` with Astral's `ty` type checker in pre-commit config, `pyproject.toml`, CI workflow, and dev dependencies.
- Migrates `[tool.mypy]` configuration to `[tool.ty.environment]`, `[tool.ty.src]`, and `[tool.ty.analysis]` sections in `pyproject.toml`.
- Updates type annotations across ~30 Python files to satisfy `ty`'s stricter checking (mostly `# type: ignore` comment adjustments and minor annotation fixes).
