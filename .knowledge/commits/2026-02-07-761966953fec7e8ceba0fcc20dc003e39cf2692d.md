# Replace mypy with ty for Python type checking in CI and pre-commit

- Replaces `mypy` with Astral's `ty` type checker in `pyproject.toml` dev deps, `.pre-commit-config.yaml`, `.github/workflows/ci_test.yml`, and `CONTRIBUTING.md`.
