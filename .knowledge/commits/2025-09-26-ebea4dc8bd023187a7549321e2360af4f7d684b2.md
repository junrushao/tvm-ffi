# Expose package version via __version__ and add pre-commit version sync check
## TL;DR
- Adds `__version__ = "0.1.0b9"` to `tvm_ffi/__init__.py` and exports it in `__all__`.
- Adds `tests/lint/check_version.py` pre-commit hook that verifies `pyproject.toml` version matches `__init__.py` version, auto-fixing mismatches.
- Bumps version to `0.1.0b9`.
