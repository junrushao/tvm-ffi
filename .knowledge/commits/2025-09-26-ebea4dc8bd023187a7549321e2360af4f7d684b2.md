# Expose package version via __version__ and add pre-commit version sync check
## TL;DR
- Bumps package version from `0.1.0b8` to `0.1.0b9` in `pyproject.toml` and exposes `__version__` in `python/tvm_ffi/__init__.py`.
- Adds a new `check-version` pre-commit hook (`tests/lint/check_version.py`) that validates `pyproject.toml` and `__init__.py` versions stay in sync, auto-fixing `__init__.py` if they diverge.

## Key Exports
N/A — infrastructure. The only new public symbol is `tvm_ffi.__version__` (a plain string constant).

## Impact
- API: `tvm_ffi.__version__` is now available for programmatic version queries (additive).
- Behavioral: none — no functional code changes.
- Flags/config: new `check-version` pre-commit hook runs automatically; requires `tomli` dependency in the hook environment.
- Data formats/schemas: none.
