# Expose __version__ in Python package with pre-commit sync check
## TL;DR
- Adds `__version__` to `tvm_ffi/__init__.py`, sourced from `pyproject.toml` (currently `0.1.0b9`).
- Adds `check_version.py` pre-commit hook that verifies `pyproject.toml` version matches `__init__.py.__version__` and auto-fixes on mismatch.
- Version bumped from `0.1.0b8` to `0.1.0b9`.

## Key Exports

```python
# tvm_ffi/__init__.py
__version__: str = "0.1.0b9"
# Interacts with: pyproject.toml [project].version (source of truth)
# Invariant: must match pyproject.toml version; enforced by check_version pre-commit hook
```

## Impact
- API: New public `tvm_ffi.__version__` attribute.
- Behavioral: None
- Flags/config: New pre-commit hook `check-version` added to `.pre-commit-config.yaml`.
- Data formats/schemas: None
