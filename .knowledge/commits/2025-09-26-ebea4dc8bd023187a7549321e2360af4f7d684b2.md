# Expose package version via tvm_ffi.__version__ and add version lint check

## TL;DR
- Adds `tvm_ffi.__version__` attribute sourced from `importlib.metadata.version("apache-tvm-ffi")`.
- Adds `tests/lint/check_version.py` pre-commit hook that validates `pyproject.toml` and `__init__.py` versions are consistent.
- Adds `check-version` pre-commit hook configuration.

## Key Exports

**Attributes**:
