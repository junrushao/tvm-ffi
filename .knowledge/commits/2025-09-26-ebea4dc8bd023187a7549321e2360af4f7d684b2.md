# Expose package version via __version__ and enforce pyproject.toml/init sync with pre-commit hook

## TL;DR
- Bumps version from `0.1.0b8` to `0.1.0b9` in `pyproject.toml` and adds matching `__version__ = "0.1.0b9"` to `tvm_ffi/__init__.py`, exporting it via `__all__`.
- Adds `tests/lint/check_version.py`: a lint script that reads both version sources, reports mismatch, and auto-corrects `__init__.py` to match `pyproject.toml`.
- Registers a `check-version` pre-commit hook (local, `additional_dependencies: [tomli]`) so the two sources are always in sync before commits.

## Key Exports
N/A — infrastructure. Minor public API addition: `tvm_ffi.__version__` (str) is now a stable exported attribute.

```python
# tvm_ffi/__init__.py
__version__: str  # = "0.1.0b9"; pyproject.toml is source of truth
# Invariant: __version__ must equal pyproject.toml [project].version at all times
# Enforced by: check-version pre-commit hook (auto-corrects __init__.py on mismatch)
```

## Impact
- API: `tvm_ffi.__version__` is now accessible and exported. Callers can do `import tvm_ffi; tvm_ffi.__version__` or `from tvm_ffi import __version__`.
- Behavioral: none — no runtime logic changed.
- Flags/config: new pre-commit hook `check-version` added to `.pre-commit-config.yaml`; requires `tomli` as an additional dependency.
- Data formats/schemas: none.
