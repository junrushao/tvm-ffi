# Expose __version__ in tvm_ffi and add pre-commit version sync check
## TL;DR
- Bumps package version from `0.1.0b8` to `0.1.0b9` in `pyproject.toml`.
- Exposes `__version__` as a public attribute in `tvm_ffi.__init__` (added to `__all__`).
- Adds a `check-version` pre-commit hook (`tests/lint/check_version.py`) that enforces `pyproject.toml` as the single source of truth for version, auto-fixing `__init__.py` on drift.

## Key Exports

**Python attribute**:
- `tvm_ffi.__version__: str` -- package version string (currently `"0.1.0b9"`), manually synced from `pyproject.toml`.

**Lint script** (`tests/lint/check_version.py`):
```python
def read_pyproject_version(pyproject_path: Path) -> Optional[str]: ...

def update_init_version(init_path: Path, new_version: str) -> bool: ...
def main() -> int:  # returns 0 if versions match, 1 if mismatch (after auto-fix)
```

- Hook ID: `check-version`
- Entry: `python tests/lint/check_version.py`
- Additional dependency: `tomli`
- `pass_filenames: false`
