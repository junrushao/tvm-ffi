# Replace GCC/MSVC `__attribute__` macros with C++ standard `[[attributes]]`

## TL;DR
- Replaces compiler-specific `__attribute__((always_inline))`, `__forceinline`, `__attribute__((noinline))`, `__declspec(noinline)`, and `__attribute__((unused))` with C++17 standard attributes `[[gnu::always_inline]]`, `[[msvc::forceinline]]`, `[[gnu::noinline]]`, `[[msvc::noinline]]`, and `[[maybe_unused]]`.
- Reorders `TVM_FFI_INLINE` and `TVM_FFI_ATTRIBUTE_UNUSED` to appear before `static` in all ~88 call sites, fixing the attribute placement to conform to C++ standard attribute syntax (attributes must precede the declaration specifiers they modify).
- Unifies `TVM_FFI_ATTRIBUTE_UNUSED` from a platform-guarded `#if defined(__GNUC__)` block into a single `[[maybe_unused]]` definition that works on all compilers.

Rename mapping (macro definitions in `base_details.h`):

| Macro | Before | After |
|-------|--------|-------|
| `TVM_FFI_INLINE` (MSVC) | `__forceinline` | `[[msvc::forceinline]] inline` |
| `TVM_FFI_INLINE` (GCC/Clang) | `inline __attribute__((always_inline))` | `[[gnu::always_inline]] inline` |
| `TVM_FFI_NO_INLINE` (MSVC) | `__declspec(noinline)` | `[[msvc::noinline]]` |
| `TVM_FFI_NO_INLINE` (GCC/Clang) | `__attribute__((noinline))` | `[[gnu::noinline]]` |
| `TVM_FFI_ATTRIBUTE_UNUSED` | `__attribute__((unused))` (GCC only) / empty (MSVC) | `[[maybe_unused]]` |

Ordering change (across all 16 files):

| Before | After |
|--------|-------|
| `static TVM_FFI_INLINE void Foo(...)` | `TVM_FFI_INLINE static void Foo(...)` |
| `static inline TVM_FFI_ATTRIBUTE_UNUSED int __var` | `TVM_FFI_ATTRIBUTE_UNUSED static inline int __var` |

## Key Exports

None -- this commit changes macro definitions and their placement, but does not alter any public API signatures, add new symbols, or change any runtime behavior.

## Impact
- API: none -- all macros expand to compiler hints only; the emitted symbol signatures are unchanged.
- Behavioral: none -- `always_inline` / `noinline` / `unused` are optimizer hints, not semantic changes.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **TypeTraits protocol** (`0002-ffi-any-value-system`): Every `TypeTraits<T>` specialization method (`CopyToAnyView`, `MoveToAny`, `CheckAnyStrict`, `TryCastFromAnyView`, `TypeStr`, etc.) used `static TVM_FFI_INLINE` and is reordered to `TVM_FFI_INLINE static`.
- **ObjectUnsafe / AnyUnsafe** (`0002`, `0003`): Internal helper structs with `static TVM_FFI_INLINE` methods are similarly reordered.
- **ReflectionDefBase** (`0007-ffi-reflection`): Template methods `ApplyFieldInfoTrait`, `ApplyMethodInfoTrait`, `GetMethod` are reordered.
- **TVM_FFI_FUNC_REG_VAR_DEF** / **TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF**: Static registration macros using `TVM_FFI_ATTRIBUTE_UNUSED` are reordered.

Design elements this commit produces: none -- this is a pure refactor of compiler attribute syntax.

## Usage Examples

Before/after pattern showing the macro definition change:

```cpp
// Before (base_details.h):
#if defined(_MSC_VER)
#define TVM_FFI_INLINE __forceinline
#else
#define TVM_FFI_INLINE inline __attribute__((always_inline))
#endif

// After (base_details.h):
#if defined(_MSC_VER)
#define TVM_FFI_INLINE [[msvc::forceinline]] inline
#else
#define TVM_FFI_INLINE [[gnu::always_inline]] inline
#endif

// Before (any call site):
static TVM_FFI_INLINE void CopyToAnyView(const int& src, TVMFFIAny* result) { ... }

// After (any call site):
TVM_FFI_INLINE static void CopyToAnyView(const int& src, TVMFFIAny* result) { ... }
```
