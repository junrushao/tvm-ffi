# Replace compiler-specific __attribute__/__declspec with C++ standard attributes

## TL;DR
- Replaces GCC `__attribute__((always_inline))`, `__attribute__((noinline))`, `__attribute__((unused))` and MSVC `__forceinline`, `__declspec(noinline)` with C++17 standard attributes `[[gnu::always_inline]]`, `[[gnu::noinline]]`, `[[msvc::forceinline]]`, `[[msvc::noinline]]`, and `[[maybe_unused]]`.
- Reorders `static TVM_FFI_INLINE` to `TVM_FFI_INLINE static` across all headers so the attribute appears before the declaration specifiers, which is the correct placement for C++ standard attributes.
- Simplifies `TVM_FFI_ATTRIBUTE_UNUSED` from a platform-conditional macro (GCC-only) to a universal `[[maybe_unused]]` definition.

### Rename Mapping

| Before | After | Notes |
|--------|-------|-------|
| `inline __attribute__((always_inline))` | `[[gnu::always_inline]] inline` | GCC/Clang `TVM_FFI_INLINE` |
| `__forceinline` | `[[msvc::forceinline]] inline` | MSVC `TVM_FFI_INLINE` |
| `__attribute__((noinline))` | `[[gnu::noinline]]` | GCC/Clang `TVM_FFI_NO_INLINE` |
| `__declspec(noinline)` | `[[msvc::noinline]]` | MSVC `TVM_FFI_NO_INLINE` |
| `__attribute__((unused))` (GCC-only) | `[[maybe_unused]]` | `TVM_FFI_ATTRIBUTE_UNUSED`, now universal |
| `static TVM_FFI_INLINE T method(...)` | `TVM_FFI_INLINE static T method(...)` | Attribute placement fix, 88 call sites |
| `static inline TVM_FFI_ATTRIBUTE_UNUSED` | `TVM_FFI_ATTRIBUTE_UNUSED static inline` | Macro var defs in `base_details.h`, `function.h` |

## Key Exports

```python
# Macro definitions (base_details.h) — before → after:
#
# TVM_FFI_INLINE:
#   GCC/Clang: inline __attribute__((always_inline))  →  [[gnu::always_inline]] inline
#   MSVC:      __forceinline                           →  [[msvc::forceinline]] inline
#   # Invariant: must appear BEFORE `static` in member function declarations
#   # Interacts with: every TypeTraits<T> static method, AnyUnsafe, ObjectUnsafe, PackedArgs
#
# TVM_FFI_NO_INLINE:
#   GCC/Clang: __attribute__((noinline))  →  [[gnu::noinline]]
#   MSVC:      __declspec(noinline)       →  [[msvc::noinline]]
#   # Interacts with: error-path functions, logging helpers
#
# TVM_FFI_ATTRIBUTE_UNUSED:
#   Before: #if defined(__GNUC__) → __attribute__((unused)) / else → empty
#   After:  [[maybe_unused]]  (universal, no platform conditional)
#   # Interacts with: TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF, TVM_FFI_FUNC_REG_VAR_DEF
```

## Impact
- API: None — all changes are internal macro definitions and declaration reordering with identical semantics.
- Behavioral: None — the inlining, noinlining, and unused-suppression behavior is semantically identical.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **TypeTraits protocol** (`0006-type-traits.md`): All TypeTraits<T> static methods (CheckAnyStrict, CopyFromAnyViewAfterCheck, MoveFromAnyAfterCheck, GetMismatchTypeInfo, TypeStr, etc.) use `TVM_FFI_INLINE`. The attribute placement is corrected in all specializations across `type_traits.h`, `array.h`, `map.h`, `shape.h`, `tuple.h`, `variant.h`, `dtype.h`, `function.h`.
- **Object system** (`0002-object-system.md`): `ObjectUnsafe` and `AnyUnsafe` helper structs use `TVM_FFI_INLINE` on all their static methods. Attribute placement corrected in `object.h` and `any.h`.
- **Function system** (`0004-function-system.md`): `PackedArgs::Fill`, `TypedFunction` TypeTraits, and `TVM_FFI_FUNC_REG_VAR_DEF` macro updated.
- **Reflection system** (`0008-reflection.md`): `ObjectDef` visitor methods in `reflection.h` updated.
- **String** (`string.h`): TypeTraits<String> and TypeTraits<std::string> static methods updated.

Design elements this commit produces:
- **Convention: C++ standard attribute placement** — establishes the convention that `TVM_FFI_INLINE` (and by extension any attribute macro expanding to `[[...]]`) must precede `static` in declarations: `TVM_FFI_INLINE static T method(...)`.

## Usage Examples

Before/after pattern showing the old vs new calling convention:

```cpp
// BEFORE: compiler-specific attribute after static
static TVM_FFI_INLINE bool CheckAnyStrict(const TVMFFIAny* src) { ... }
// expanded to: static inline __attribute__((always_inline)) bool CheckAnyStrict(...)

// AFTER: C++ standard attribute before static
TVM_FFI_INLINE static bool CheckAnyStrict(const TVMFFIAny* src) { ... }
// expanded to: [[gnu::always_inline]] inline static bool CheckAnyStrict(...)
```

```cpp
// BEFORE: platform-conditional unused macro
#if defined(__GNUC__)
#define TVM_FFI_ATTRIBUTE_UNUSED __attribute__((unused))
#else
#define TVM_FFI_ATTRIBUTE_UNUSED
#endif
static inline TVM_FFI_ATTRIBUTE_UNUSED int __##TVMFFIStaticInitReg

// AFTER: universal C++17 attribute
#define TVM_FFI_ATTRIBUTE_UNUSED [[maybe_unused]]
TVM_FFI_ATTRIBUTE_UNUSED static inline int __##TVMFFIStaticInitReg
```
