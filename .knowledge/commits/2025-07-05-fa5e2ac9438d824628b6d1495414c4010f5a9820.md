# Replace GCC/MSVC __attribute__ with C++ standard attributes in FFI headers
## TL;DR
- Replaces compiler-specific `__attribute__((always_inline))`, `__forceinline`, `__attribute__((noinline))`, `__declspec(noinline)`, and `__attribute__((unused))` with C++ standard attributes (`[[gnu::always_inline]]`, `[[msvc::forceinline]]`, `[[gnu::noinline]]`, `[[msvc::noinline]]`, `[[maybe_unused]]`) in the three core macros: `TVM_FFI_INLINE`, `TVM_FFI_NO_INLINE`, `TVM_FFI_ATTRIBUTE_UNUSED`.
- Fixes attribute placement: moves `TVM_FFI_INLINE` and `TVM_FFI_ATTRIBUTE_UNUSED` before `static` to comply with C++ standard attribute ordering rules (attributes must precede the declaration specifiers they modify).
- Unifies `TVM_FFI_ATTRIBUTE_UNUSED` from a GCC-only `#ifdef` block to a single portable `[[maybe_unused]]` definition.

### Before/After Mapping

| Macro | Before (GCC/Clang) | Before (MSVC) | After (GCC/Clang) | After (MSVC) |
|-------|---------------------|---------------|-------------------|--------------|
| `TVM_FFI_INLINE` | `inline __attribute__((always_inline))` | `__forceinline` | `[[gnu::always_inline]] inline` | `[[msvc::forceinline]] inline` |
| `TVM_FFI_NO_INLINE` | `__attribute__((noinline))` | `__declspec(noinline)` | `[[gnu::noinline]]` | `[[msvc::noinline]]` |
| `TVM_FFI_ATTRIBUTE_UNUSED` | `__attribute__((unused))` (GCC only, empty otherwise) | _(empty)_ | `[[maybe_unused]]` | `[[maybe_unused]]` |

### Attribute Ordering Change

All 88 call sites across 14 header files change from:
```cpp
// Before: attribute after static
static TVM_FFI_INLINE ReturnType FuncName(...) { ... }
// After: attribute before static (C++ standard compliance)
TVM_FFI_INLINE static ReturnType FuncName(...) { ... }
```

Similarly for `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF`:
```cpp
// Before
static inline TVM_FFI_ATTRIBUTE_UNUSED int __##TVMFFIStaticInitReg
// After
TVM_FFI_ATTRIBUTE_UNUSED static inline int __##TVMFFIStaticInitReg
```
