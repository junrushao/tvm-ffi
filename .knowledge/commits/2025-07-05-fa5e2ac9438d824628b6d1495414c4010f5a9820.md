# Replace GCC/MSVC-specific __attribute__ macros with C++17 standard [[...]] attributes
## TL;DR
- Redefines `TVM_FFI_INLINE`, `TVM_FFI_NO_INLINE`, and `TVM_FFI_ATTRIBUTE_UNUSED` macros in `base_details.h` to use C++17 standard attributes (`[[gnu::always_inline]]`, `[[gnu::noinline]]`, `[[maybe_unused]]`) instead of compiler-specific `__attribute__`/`__declspec` syntax.
- Reorders `static TVM_FFI_INLINE` to `TVM_FFI_INLINE static` across all 16 files (88 call sites) because standard attributes must precede declaration specifiers.
- `TVM_FFI_ATTRIBUTE_UNUSED` is now unconditionally `[[maybe_unused]]`, removing the GCC-only `#ifdef` and the empty fallback for non-GCC compilers.

### Before/after mapping table

| Symbol | Before (GCC/Clang) | After (GCC/Clang) |
|---|---|---|
| `TVM_FFI_INLINE` | `inline __attribute__((always_inline))` | `[[gnu::always_inline]] inline` |
| `TVM_FFI_NO_INLINE` | `__attribute__((noinline))` | `[[gnu::noinline]]` |
| `TVM_FFI_ATTRIBUTE_UNUSED` | `__attribute__((unused))` (GCC-only, empty elsewhere) | `[[maybe_unused]]` (all compilers) |

| Symbol | Before (MSVC) | After (MSVC) |
|---|---|---|
| `TVM_FFI_INLINE` | `__forceinline` | `[[msvc::forceinline]] inline` |
| `TVM_FFI_NO_INLINE` | `__declspec(noinline)` | `[[msvc::noinline]]` |

| Call-site pattern | Before | After |
|---|---|---|
| Static inline methods | `static TVM_FFI_INLINE T Foo(...)` | `TVM_FFI_INLINE static T Foo(...)` |
| Static init block var | `static inline TVM_FFI_ATTRIBUTE_UNUSED int ...` | `TVM_FFI_ATTRIBUTE_UNUSED static inline int ...` |
| Func reg var | `static inline TVM_FFI_ATTRIBUTE_UNUSED ...` | `TVM_FFI_ATTRIBUTE_UNUSED static inline ...` |

## Key Exports

**Macros** (redefined, not new):

| Macro | Expansion (GCC/Clang) | Expansion (MSVC) |
|---|---|---|
| `TVM_FFI_INLINE` | `[[gnu::always_inline]] inline` | `[[msvc::forceinline]] inline` |
| `TVM_FFI_NO_INLINE` | `[[gnu::noinline]]` | `[[msvc::noinline]]` |
| `TVM_FFI_ATTRIBUTE_UNUSED` | `[[maybe_unused]]` | `[[maybe_unused]]` |

Key semantic change for `TVM_FFI_ATTRIBUTE_UNUSED`: previously expanded to nothing on non-GCC compilers; now expands to `[[maybe_unused]]` universally. This means MSVC/other compilers will now correctly suppress unused-variable warnings for `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` and `TVM_FFI_FUNC_REG_VAR_DEF` declarations.

## Impact
- API: None -- macro names are unchanged; this is an internal definition change.
- Behavioral: `TVM_FFI_ATTRIBUTE_UNUSED` now suppresses unused-variable warnings on MSVC (previously it was a no-op there). `TVM_FFI_INLINE` now includes explicit `inline` on MSVC (previously `__forceinline` implied it).
- Flags/config: None.
- Data formats/schemas: None.
