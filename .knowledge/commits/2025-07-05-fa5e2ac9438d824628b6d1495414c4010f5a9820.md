# Replace GCC/MSVC __attribute__ and __declspec syntax with ISO C++17 standard attributes

## TL;DR
- Macro definitions for `TVM_FFI_INLINE`, `TVM_FFI_NO_INLINE`, and `TVM_FFI_ATTRIBUTE_UNUSED` in `base_details.h` now expand to ISO C++17 `[[...]]` attribute syntax instead of compiler-specific `__attribute__((...))` / `__declspec(...)` forms.
- All call sites of `TVM_FFI_INLINE` across 15 headers were mechanically updated: `static TVM_FFI_INLINE` → `TVM_FFI_INLINE static` (required because `[[gnu::always_inline]]` must precede the specifier it annotates, unlike `__attribute__` which can follow `static`).
- No behavioral or ABI change; identical inlining semantics with improved compiler portability and standards conformance.

| Old expansion | New expansion |
|---|---|
| `inline __attribute__((always_inline))` | `[[gnu::always_inline]] inline` |
| `__forceinline` | `[[msvc::forceinline]] inline` |
| `__attribute__((noinline))` | `[[gnu::noinline]]` |
| `__declspec(noinline)` | `[[msvc::noinline]]` |
| `__attribute__((unused))` (GCC-guarded) | `[[maybe_unused]]` (unconditional, ISO) |

## Key Exports

```python
# base_details.h — macro definitions (before → after)
# Old (GCC/Clang):
#   TVM_FFI_INLINE = inline __attribute__((always_inline))
# Old (MSVC):
#   TVM_FFI_INLINE = __forceinline
# New (GCC/Clang):
#   TVM_FFI_INLINE = [[gnu::always_inline]] inline
# New (MSVC):
#   TVM_FFI_INLINE = [[msvc::forceinline]] inline
# Invariant: placement before `static` is now required at all call sites

# Old (GCC/Clang):
#   TVM_FFI_NO_INLINE = __attribute__((noinline))
# Old (MSVC):
#   TVM_FFI_NO_INLINE = __declspec(noinline)
# New (GCC/Clang):
#   TVM_FFI_NO_INLINE = [[gnu::noinline]]
# New (MSVC):
#   TVM_FFI_NO_INLINE = [[msvc::noinline]]

# Old (conditional on __GNUC__):
#   TVM_FFI_ATTRIBUTE_UNUSED = __attribute__((unused))
# New (unconditional ISO C++17):
#   TVM_FFI_ATTRIBUTE_UNUSED = [[maybe_unused]]

# Call-site pattern change across all TypeTraits<T> specializations
# Old: static TVM_FFI_INLINE void CopyToAnyView(...) {...}
# New: TVM_FFI_INLINE static void CopyToAnyView(...) {...}
# Interacts with: TypeTraits<T> in 0008-type-traits
```

## Impact
- API: none — macro names unchanged; call sites updated mechanically
- Behavioral: none — identical inlining hints to the compiler
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_INLINE`, `TVM_FFI_NO_INLINE`, `TVM_FFI_ATTRIBUTE_UNUSED` macros (defined in `include/tvm/ffi/base_details.h`; used pervasively across all FFI headers)
- `TypeTraits<T>` static-methods protocol (`0008-type-traits`) — every `TypeTraits` specialization in `type_traits.h`, `string.h`, `container/array.h`, `container/map.h`, `container/shape.h`, `container/tuple.h`, `container/variant.h`, `any.h`, `dtype.h`, `function.h`, `function_details.h`, `object.h`, `reflection/reflection.h`, `rvalue_ref.h` had call sites updated

Design elements this commit produces: None — no new design elements introduced.

## Usage Examples

Before/after showing corrected declaration ordering:

```cpp
// Before (in TypeTraits<std::nullptr_t>):
static TVM_FFI_INLINE void CopyToAnyView(const std::nullptr_t&, TVMFFIAny* result) { ... }

// After:
TVM_FFI_INLINE static void CopyToAnyView(const std::nullptr_t&, TVMFFIAny* result) { ... }

// Before (in base_details.h, GCC path):
#define TVM_FFI_ATTRIBUTE_UNUSED __attribute__((unused))  // conditional on __GNUC__

// After:
#define TVM_FFI_ATTRIBUTE_UNUSED [[maybe_unused]]         // unconditional ISO C++17
```

## Reflection

### Design docs / ADRs to write or update
None — the macro contract (`TVM_FFI_INLINE` forces inlining; `TVM_FFI_NO_INLINE` prevents inlining) is unchanged. The `base_details.h` macro convention is documented implicitly via the macros themselves; no separate design doc is warranted.

### Stale knowledge references
None — knowledge base references to `__attribute__` (`0001-c-abi.md`: `TVM_FFI_DLL` visibility attribute; prior commit ledgers for `TVM_FFI_WEAK`) are for different macros not touched by this commit.
