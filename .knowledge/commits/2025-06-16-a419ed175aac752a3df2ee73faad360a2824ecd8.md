# Upgrade reflection registry with full ABI metadata: ObjectDef<T>, TVMFFITypeExtraInfo, type_schema, and Map-based storage

## TL;DR
- `ReflectionDef` renamed to `ObjectDef<Class>` (template class that auto-derives `type_index` and `type_key` from the Class parameter); the `TVM_FFI_REFLECTION_DEF` macro is removed and replaced by the general-purpose `TVM_FFI_STATIC_INIT_BLOCK`.
- `TVMFFIFieldInfo` gains `type_schema`, `size`, `alignment`, and renames `byte_offset` → `offset`; `TVMFFIMethodInfo` gains `type_schema`; new `TVMFFITypeExtraInfo` struct (with `doc`, `creator`, `total_size`) enables reflection-based object construction.
- Internal registry storage migrated from `std::unordered_map` to `Map<String, …>` (TVM FFI's own container); global function entries now carry full `TVMFFIMethodInfo` metadata via `GlobalFunctionTable::Entry`.

## Impact
- API: **Breaking** — `TVMFFIFieldFlagBitMask*` enum constants renamed to `kTVMFFIFieldFlagBitMask*`; `TVMFFIFieldInfo.byte_offset` renamed to `offset`; `TVMFFIErrorSetRaisedByCStr` renamed to `TVMFFIErrorSetRaisedFromCStr`; `TVMFFITypeGetMethod` removed and replaced by `TVMFFITypeRegisterExtraInfo`; `TVMFFITypeInfo.fields/methods` changed from mutable to const pointers. All callers updating to these renamed symbols are updated in this commit.
- Behavioral: `ReflectionDef` → `ObjectDef<Class>` changes registration call site: no longer requires passing `type_index`/`type_key` manually; template parameter provides them. `TVM_FFI_REFLECTION_DEF` macro eliminated entirely.
- Flags/config: `TVM_FFI_BUILD_REGISTRY` CMake option removed (was OFF-by-default placeholder).
- Data formats/schemas: `TVMFFIFieldInfo` struct gains `type_schema`, `size`, `alignment` fields (ABI-breaking); existing binaries reading `TVMFFIFieldInfo` at a fixed offset will misread fields.

## Usage Examples

**Registering reflection fields/methods with the new API:**
```cpp
// NEW pattern (replaces TVM_FFI_REFLECTION_DEF):
TVM_FFI_STATIC_INIT_BLOCK({
    namespace refl = tvm::ffi::reflection;

    refl::ObjectDef<TFloatObj>()
        .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
        .def("sub", [](const TFloatObj* self, double other) -> double {
            return self->value - other;
        })
        .def("add", &TFloatObj::Add, "add method");

    refl::ObjectDef<TIntObj>()
        .def_ro("value", &TIntObj::value)
        .def_static("static_add", &TInt::StaticAdd, "static add method");
});

// OLD pattern (removed):
// TVM_FFI_REFLECTION_DEF(TFloatObj)
//     .def_rw("value", &TFloatObj::value, ...)
//     .def("add", &TFloatObj::Add, "add method");
```

**Checking field flags with renamed constants:**
```cpp
// NEW:
if (info->flags & kTVMFFIFieldFlagBitMaskHasDefault) { ... }
if (info->flags & kTVMFFIFieldFlagBitMaskWritable)   { ... }
// OLD (removed):
// if (info->flags & TVMFFIFieldFlagBitMaskHasDefault) { ... }
```

**Registering type extra info (new API):**
```cpp
TVMFFITypeExtraInfo extra;
extra.doc = TVMFFIByteArray{"My type doc", 11};
extra.creator = [](TVMFFIObjectHandle* result) -> int {
    auto obj = tvm::ffi::make_object<MyObj>();
    *result = tvm::ffi::details::ObjectUnsafe::MoveObjectRefToTVMFFIObjectPtr(std::move(obj));
    return 0;
};
extra.total_size = sizeof(MyObj);
TVMFFITypeRegisterExtraInfo(MyObj::_GetOrAllocRuntimeTypeIndex(), &extra);
```
