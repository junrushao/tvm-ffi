# Refactor FFI registry structs for complete reflection metadata

## TL;DR
- Enriches `TVMFFIFieldInfo` with `size`, `alignment`, `offset` (replaces `byte_offset`), and `type_schema` JSON string; enriches `TVMFFIMethodInfo` with `type_schema`.
- Introduces `TVMFFITypeExtraInfo` struct with `creator` callback, `total_size`, and `doc` for reflection-based object construction.
- Renames `ReflectionDef` to `ObjectDef<Class>` (templatized, auto-derives type index/key); removes `TVM_FFI_REFLECTION_DEF` macro in favor of `TVM_FFI_STATIC_INIT_BLOCK`.
- Replaces `std::unordered_map` with `Map<String, ...>` in both `TypeTable` and `GlobalFunctionTable`; renames `TVMFFIErrorSetRaisedByCStr` to `TVMFFIErrorSetRaisedFromCStr`.
- Adds `TVMFFIFunctionSetGlobalFromMethodInfo` C API for registering global functions with rich metadata, and `TVMFFITypeRegisterExtraInfo` for registering creator/size info.

Renames in this commit:

| Before | After |
|--------|-------|
| `ReflectionDef` | `ObjectDef<Class>` |
| `TVM_FFI_REFLECTION_DEF(TypeName)` | `TVM_FFI_STATIC_INIT_BLOCK({ ObjectDef<TypeName>()... })` |
| `TVMFFIFieldInfo.byte_offset` | `TVMFFIFieldInfo.offset` |
| `TVMFFIFieldFlagBitMaskWritable` | `kTVMFFIFieldFlagBitMaskWritable` |
| `TVMFFIFieldFlagBitMaskHasDefault` | `kTVMFFIFieldFlagBitMaskHasDefault` |
| `TVMFFIFieldFlagBitMaskIsStaticMethod` | `kTVMFFIFieldFlagBitMaskIsStaticMethod` |
| `TVMFFIErrorSetRaisedByCStr` | `TVMFFIErrorSetRaisedFromCStr` |
| `TVMFFITypeGetMethod` | removed (replaced by `TVMFFITypeRegisterExtraInfo`) |
| `ffi::refl` namespace alias | removed |

## Impact
- API: **Breaking** -- `TVMFFIFieldInfo.byte_offset` renamed to `offset`; `TVMFFIFieldInfo` gains `size`, `alignment`, `type_schema` fields; `TVMFFIMethodInfo` gains `type_schema`; enum constants gain `k` prefix; `TVMFFIErrorSetRaisedByCStr` renamed to `TVMFFIErrorSetRaisedFromCStr`; `TVMFFITypeGetMethod` removed, replaced by `TVMFFITypeRegisterExtraInfo`. `TVMFFITypeInfo` field ordering changed and `extra_info` added. `fields`/`methods` pointers become const-qualified. All downstream code referencing old names or old `TVMFFIFieldInfo` layout must update.
- Behavioral: `GlobalFunctionTable` now uses `Map<String, Any>` (insertion-ordered, ref-counted) instead of `std::unordered_map<String, Function*>`. Function entries now store full metadata (doc, type_schema). `TypeTable` uses `Map<String, int64_t>` instead of `std::unordered_map<std::string, int32_t>`.
- Flags/config: `TVM_FFI_BUILD_REGISTRY` CMake option removed (registry is now always built).
- Data formats/schemas: `TVMFFIFieldInfo` and `TVMFFIMethodInfo` now carry `type_schema` (JSON string) for future serialization/reflection tooling.

## Design Elements
Design elements this commit consumes:
- **Object system** (`.knowledge/designs/0002-object-system.md`) -- `GlobalFunctionTable::Entry` extends `Object` for ref-counted storage in `Map`
- **Container system** (`.knowledge/designs/0007-containers.md`) -- Uses `Map<String, Any>` and `Map<String, int64_t>` to replace `std::unordered_map`
- **C ABI** (`.knowledge/designs/0001-c-abi.md`) -- Extends `TVMFFIFieldInfo`, `TVMFFIMethodInfo`, `TVMFFITypeInfo` structs
- **Reflection system** (`.knowledge/designs/0008-reflection.md`) -- Refactors `ReflectionDef` into `ObjectDef<Class>`

Design elements this commit produces:
- **`TVMFFITypeExtraInfo`** -- New struct for reflection-based object construction (creator callback, total_size)
- **`TVMFFIObjectCreator`** -- New function pointer typedef for creating empty object instances
- **`TVM_FFI_STATIC_INIT_BLOCK`** -- General-purpose static initialization macro replacing reflection-specific macros
- **`TVMFFIFunctionSetGlobalFromMethodInfo`** -- New C API for metadata-rich global function registration
- **`TVMFFITypeRegisterExtraInfo`** -- New C API for registering type creator/size info
- **`ObjectDef<Class>`** -- Templatized replacement for `ReflectionDef`, auto-deriving type info from the class
- **`GlobalFunctionTable::Entry`** -- Internal class that stores global function metadata as an Object subclass

## Usage Examples

Before (old API):
```cpp
// Old: ReflectionDef with explicit macro
TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
    .def("add", &TFloatObj::Add, "add method");
```

After (new API):
```cpp
// New: ObjectDef<T> inside TVM_FFI_STATIC_INIT_BLOCK
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::ObjectDef<TFloatObj>()
      .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
      .def("add", &TFloatObj::Add, "add method");
});
```
