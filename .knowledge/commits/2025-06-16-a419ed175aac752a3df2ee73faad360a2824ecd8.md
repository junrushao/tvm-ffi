# Refactor type registry to carry complete ABI metadata for reflection
## TL;DR
- Extends `TVMFFIFieldInfo` with `size`, `alignment`, `offset` (replacing `byte_offset`), and `type_schema` JSON string; similarly extends `TVMFFIMethodInfo` with `type_schema`.
- Introduces `TVMFFITypeExtraInfo` struct (with `creator`, `total_size`, `doc`) and `TVMFFIObjectCreator` typedef for reflection-based object creation.
- Renames `ReflectionDef` to `ObjectDef<Class>` (class-templated), replaces `TVM_FFI_REFLECTION_DEF` macro with `TVM_FFI_STATIC_INIT_BLOCK`, and migrates internal registries from `std::unordered_map` to `Map<String, ...>`.

## Impact
- API: **Breaking C ABI change**. `TVMFFIFieldInfo.byte_offset` renamed to `offset` with new `size`/`alignment`/`type_schema` fields. `TVMFFITypeInfo` gains `extra_info` pointer, reorders `type_key_hash`. Enum constants gain `k` prefix. `TVMFFIErrorSetRaisedByCStr` renamed. `TVMFFITypeGetMethod` removed and replaced by `TVMFFITypeRegisterExtraInfo`. All downstream language bindings (Cython, Rust) that read these structs must be updated.
- Behavioral: `GlobalFunctionTable` now stores `Entry` objects (with full `TVMFFIMethodInfo` metadata) in a `Map<String, Any>` instead of raw `Function*` in `std::unordered_map`. `TVMFFIFunctionSetGlobalFromMethodInfo` enables registering functions with metadata. `TypeTable` similarly migrates from `std::unordered_map<std::string, int32_t>` to `Map<String, int64_t>`.
- Flags/config: `TVM_FFI_BUILD_REGISTRY` CMake option removed (registry is now unconditional).
- Data formats/schemas: `TVMFFIFieldInfo` and `TVMFFIMethodInfo` gain `type_schema` (JSON string) for future schema-aware code generation.

## Design Elements
Design elements this commit consumes:
- **Object system** (`0003-object-system.md`): `Object`, `ObjectRef`, `make_object<T>`, `ObjectPtr` -- used to create `GlobalFunctionTable::Entry`.
- **Containers** (`0008-containers.md`): `Map<K,V>` replaces `std::unordered_map` in `TypeTable` and `GlobalFunctionTable`, leveraging insertion-order preservation (ADR `0003-insertion-order-map.md`).
- **Function system** (`0004-function-system.md`): `Function`, `Function::FromTyped` used for method wrapping.
- **C ABI layer** (`0001-c-abi-layer.md`): `TVMFFIFieldInfo`, `TVMFFIMethodInfo`, `TVMFFITypeInfo`, `TVM_FFI_SAFE_CALL_BEGIN/END`.
- **Error handling** (`0006-error-handling.md`): `TVM_FFI_THROW`.

Design elements this commit produces:
- **`TVMFFITypeExtraInfo`**: New C ABI struct enabling reflection-based object creation via `TVMFFIObjectCreator` function pointer, with optional `total_size` for fixed-size types.
- **`TVMFFIFunctionSetGlobalFromMethodInfo`**: New C API for registering global functions with full method metadata (doc, type_schema, flags).
- **`TVMFFITypeRegisterExtraInfo`**: New C API for registering type extra info (creator, total_size, doc).
- **`ObjectDef<Class>`**: Replaces `ReflectionDef` with a class-templated builder that deduces `Class` from the template argument, simplifying field/method registration (no explicit `Class` template param at call sites).
- **`TVM_FFI_STATIC_INIT_BLOCK`**: General-purpose static init macro (not reflection-specific), replacing `TVM_FFI_REFLECTION_DEF`.
- **Rich `TVMFFIFieldInfo`**: Fields now carry `size`, `alignment`, `offset`, `type_schema` -- enough metadata for language bindings to do layout-aware operations.
- **`GlobalFunctionTable::Entry`**: Internal class that stores function metadata alongside the function object, enabling metadata queries on registered globals.

## Usage Examples

**Registering reflection with new API** (from `tests/cpp/test_reflection.cc`):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;

  refl::ObjectDef<TFloatObj>()
      .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
      .def("sub", [](const TFloatObj* self, double other) -> double { return self->value - other; })
      .def("add", &TFloatObj::Add, "add method");

  refl::ObjectDef<TIntObj>()
      .def_ro("value", &TIntObj::value)
      .def_static("static_add", &TInt::StaticAdd, "static add method");
});
```

**Registering a global function with method info** (new C API):
```c
TVMFFIMethodInfo info;
info.name = (TVMFFIByteArray){"my_func", 7};
info.doc = (TVMFFIByteArray){"Does something", 14};
info.type_schema = (TVMFFIByteArray){"{}", 2};
info.flags = kTVMFFIFieldFlagBitMaskIsStaticMethod;
info.method = /* TVMFFIAny holding a Function */;
TVMFFIFunctionSetGlobalFromMethodInfo(&info, /*override=*/0);
```
