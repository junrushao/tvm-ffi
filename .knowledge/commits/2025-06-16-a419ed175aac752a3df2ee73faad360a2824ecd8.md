# Refactor FFI registry to carry complete per-field/method metadata and remove std::unordered_map

## TL;DR
- Extends `TVMFFIFieldInfo` and `TVMFFIMethodInfo` with `type_schema`, `size`, and `alignment` fields to enable future runtime reflection and serialization. Adds a new `TVMFFITypeExtraInfo` struct with `creator`, `doc`, and `total_size` for reflection-based object construction.
- Renames `ReflectionDef` to `ObjectDef<Class>` (class-template), removes `TVM_FFI_REFLECTION_DEF` macro in favor of `TVM_FFI_STATIC_INIT_BLOCK`, and renames `TVMFFIErrorSetRaisedByCStr` to `TVMFFIErrorSetRaisedFromCStr`.
- Replaces `std::unordered_map` in both `GlobalFunctionTable` and `TypeTable` with TVM's own `Map<String, ...>` / `Dict` containers, and introduces `GlobalFunctionTable::Entry` (an Object holding `TVMFFIMethodInfo`) for richer global function metadata.

## Impact
- API: Breaking changes to C ABI — `TVMFFIFieldInfo.byte_offset` renamed to `offset`, `size`/`alignment`/`type_schema` fields added. `TVMFFIMethodInfo` gains `type_schema`. Enum constants gain `k` prefix. `TVMFFIErrorSetRaisedByCStr` renamed. `TVMFFITypeGetMethod` removed, replaced by `TVMFFITypeRegisterExtraInfo`. `TVMFFIFunctionSetGlobalFromMethodInfo` added. All callers of these C API symbols must update.
- Behavioral: `GlobalFunctionTable` now stores `Entry` objects (with full metadata) instead of raw `Function*` pointers. The internal storage switches from `std::unordered_map` to `Map<String, Any>`.
- Flags/config: `TVM_FFI_BUILD_REGISTRY` CMake option removed (registry is now always built).
- Data formats/schemas: `type_schema` field added to both field and method info — enables future JSON-based type description for reflection/serialization.

## Design Elements
Design elements this commit consumes:
- Object system (`0003-ffi-object-system`): `GlobalFunctionTable::Entry` inherits `Object` to participate in ref counting.
- Container system (`0006-ffi-containers`): `Map<String, Any>` and `Map<String, int64_t>` replace `std::unordered_map` in both registries.
- Function system (`0004-ffi-function-system`): `Function`, `make_object`, global registry patterns.
- C ABI (`0001-ffi-c-abi`): `TVMFFIByteArray`, `TVMFFIAny`, safe call convention.

Design elements this commit produces or mutates:
- **Mutates** `TVMFFIFieldInfo` (0007, 0001): adds `type_schema`, `size`, `alignment`; renames `byte_offset` to `offset`.
- **Mutates** `TVMFFIMethodInfo` (0007, 0001): adds `type_schema`.
- **Mutates** `TVMFFITypeInfo` (0001): adds `extra_info` pointer; makes `fields`/`methods` const.
- **Produces** `TVMFFITypeExtraInfo`: new struct for creator/doc/total_size.
- **Produces** `TVMFFIObjectCreator`: new callback type for reflection-based construction.
- **Produces** `TVMFFIFunctionSetGlobalFromMethodInfo`: new C API for metadata-rich function registration.
- **Produces** `TVMFFITypeRegisterExtraInfo`: new C API for registering type extra info.
- **Produces** `TVM_FFI_STATIC_INIT_BLOCK`: general-purpose static-init macro replacing `TVM_FFI_REFLECTION_DEF`.
- **Mutates** `ReflectionDef` -> `ObjectDef<Class>`: renamed, templatized on class; no longer needs explicit type_index/type_key.
- **Removes** `TVM_FFI_REFLECTION_DEF` macro, `namespace refl` alias, `TVMFFITypeGetMethod` API.
- **Renames** `TVMFFIErrorSetRaisedByCStr` -> `TVMFFIErrorSetRaisedFromCStr`.
- **Renames** enum constants to add `k` prefix (`kTVMFFIFieldFlagBitMaskWritable`, etc.).

## Usage Examples
New reflection registration pattern (from `tests/cpp/test_reflection.cc`):
```cpp
// Old pattern (removed):
//   TVM_FFI_REFLECTION_DEF(TFloatObj)
//       .def_rw("value", &TFloatObj::value);

// New pattern:
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::ObjectDef<TFloatObj>()
      .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
      .def("sub", [](const TFloatObj* self, double other) -> double { return self->value - other; })
      .def("add", &TFloatObj::Add, "add method");

  refl::ObjectDef<TIntObj>()
      .def_ro("value", &TIntObj::value)
      .def_static("static_add", &TInt::StaticAdd, "static add method");
});
```
