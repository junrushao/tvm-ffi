# Enrich registry metadata: complete field/method info, ObjectDef builder, type extra info, and global function metadata

## TL;DR
- Extends `TVMFFIFieldInfo` with `size`, `alignment`, `offset` (renamed from `byte_offset`), `doc`, and `type_schema` fields; adds `type_schema` and `doc` to `TVMFFIMethodInfo`. Introduces `TVMFFITypeExtraInfo` with a `creator` callback and `total_size` for reflection-based object construction.
- Replaces `ReflectionDef` with template class `ObjectDef<Class>`, removing the explicit type-index/type-key constructor parameters and the `TVM_FFI_REFLECTION_DEF` macro. Introduces `TVM_FFI_STATIC_INIT_BLOCK` as the universal static-init registration macro.
- Replaces `std::unordered_map` with `Map<String, ...>` in both `GlobalFunctionTable` and `TypeTable`, removes the `TVM_FFI_BUILD_REGISTRY` CMake option, and renames `TVMFFIErrorSetRaisedByCStr` to `TVMFFIErrorSetRaisedFromCStr`.

## Key Exports

**New C ABI type:**
- `TVMFFIObjectCreator = int (*)(TVMFFIObjectHandle* result)` -- Callback to create a new empty instance of a type for reflection-based construction.

**New C ABI struct:**
- `TVMFFITypeExtraInfo { TVMFFIByteArray doc; TVMFFIObjectCreator creator; int64_t total_size; }` -- Optional per-type metadata enabling reflection-based instantiation.

**Changed C ABI struct -- `TVMFFIFieldInfo`:**
- Added: `TVMFFIByteArray type_schema` (JSON type schema string)
- Renamed: `byte_offset` to `offset`
- Added: `int64_t size`, `int64_t alignment`
- Removed: implicit `readonly` field (replaced by `flags` bitmask, which already existed)

**Changed C ABI struct -- `TVMFFIMethodInfo`:**
- Added: `TVMFFIByteArray type_schema` (JSON type schema string)

**Changed C ABI struct -- `TVMFFITypeInfo`:**
- Moved `type_key_hash` after `type_acenstors` (field reordering)
- Changed `fields` from `TVMFFIFieldInfo*` to `const TVMFFIFieldInfo*`
- Changed `methods` from `TVMFFIMethodInfo*` to `const TVMFFIMethodInfo*`
- Added: `const TVMFFITypeExtraInfo* extra_info`

**Renamed C ABI enum constants:**
- `TVMFFIFieldFlagBitMaskWritable` to `kTVMFFIFieldFlagBitMaskWritable`
- `TVMFFIFieldFlagBitMaskHasDefault` to `kTVMFFIFieldFlagBitMaskHasDefault`
- `TVMFFIFieldFlagBitMaskIsStaticMethod` to `kTVMFFIFieldFlagBitMaskIsStaticMethod`

**New C API functions:**
- `TVMFFIFunctionSetGlobalFromMethodInfo(const TVMFFIMethodInfo* method_info, int override) -> int` -- Register a global function with full method metadata.
- `TVMFFITypeRegisterExtraInfo(int32_t type_index, const TVMFFITypeExtraInfo* extra_info) -> int` -- Register type creator/size metadata for reflection.

**Removed C API functions:**
- `TVMFFITypeGetMethod(int32_t type_index) -> const TVMFFITypeInfo*` -- Replaced by accessing `TVMFFITypeInfo::methods` via `TVMFFIGetTypeInfo`.

**Renamed C API function:**
- `TVMFFIErrorSetRaisedByCStr` to `TVMFFIErrorSetRaisedFromCStr`

**New C++ macro:**
- `TVM_FFI_STATIC_INIT_BLOCK(Body)` -- Executes `Body` once at static initialization via a `static inline` variable initialized by an immediately-invoked lambda. Uses `__COUNTER__` for unique naming.

**Changed C++ class -- `ObjectDef<Class>` (was `ReflectionDef`):**
- Now a class template parameterized on the object class, eliminating the need to pass `type_index` and `type_key` explicitly.
- Constructor: `ObjectDef()` -- deduces type index and type key from `Class::_GetOrAllocRuntimeTypeIndex()` and `Class::_type_key`.
- Methods: `def_ro`, `def_rw`, `def`, `def_static` -- same signatures but `Class` template parameter is no longer explicit on each method.

**Removed C++ macro:**
- `TVM_FFI_REFLECTION_DEF(TypeName)` -- Replaced by `TVM_FFI_STATIC_INIT_BLOCK({ ObjectDef<TypeName>()...; })`.

**Removed C++ namespace alias:**
- `namespace tvm::ffi::refl` (was alias for `tvm::ffi::reflection`) -- Removed from the header.

**Removed CMake option:**
- `TVM_FFI_BUILD_REGISTRY` -- Dynamic registry support is now unconditional.

## Impact
- API: Breaking. `ReflectionDef` renamed to `ObjectDef<T>`. `TVM_FFI_REFLECTION_DEF` macro removed. `TVMFFITypeGetMethod` removed. Enum constants gain `k` prefix. Callers using `byte_offset` must use `offset`. The `refl::` namespace alias is gone. All downstream code registering reflection must migrate to `TVM_FFI_STATIC_INIT_BLOCK` + `ObjectDef<T>`.
- ABI: Breaking. `TVMFFIFieldInfo` layout changed (fields added and renamed, different sizes). `TVMFFIMethodInfo` layout changed (new `type_schema` field). `TVMFFITypeInfo` layout changed (field reordered, new `extra_info` pointer, `fields`/`methods` now const-qualified). `TVMFFIErrorSetRaisedByCStr` symbol renamed.
- Behavioral: `GlobalFunctionTable` now stores entries as `Object` subclasses in a `Map<String, Any>` instead of raw `Function*` in `std::unordered_map`. This means global function entries now carry metadata (doc, type_schema, flags) beyond just the function object. `TypeTable` also migrates from `std::unordered_map<std::string, int32_t>` to `Map<String, int64_t>`.
- Flags/config: `TVM_FFI_BUILD_REGISTRY` CMake option removed. Registry is always built.
- Data formats/schemas: `type_schema` fields (JSON strings) added to field and method info, laying groundwork for schema-driven codegen/validation.

## Design Elements
Design elements this commit consumes:
- **Object system** (`.knowledge/designs/object-system.md`) -- `Object`, `make_object`, `ObjectRef` used to create `GlobalFunctionTable::Entry` as a proper Object subclass.
- **Containers** (`.knowledge/designs/containers.md`) -- `Map<String, Any>` and `Map<String, int64_t>` replace `std::unordered_map` in both `GlobalFunctionTable` and `TypeTable`.
- **Function system** (`.knowledge/designs/function-system.md`) -- `Function::FromTyped` used to register methods in `ObjectDef::GetMethod`.
- **C ABI contract** (`.knowledge/designs/c-abi.md`) -- `TVMFFIFieldInfo`, `TVMFFIMethodInfo`, `TVMFFITypeInfo` structs extended.
- **Reflection system** (`.knowledge/designs/reflection.md`) -- `ReflectionDef` class replaced by `ObjectDef<T>`.

Design elements this commit produces:
- **`TVMFFITypeExtraInfo`** -- New C ABI struct enabling reflection-based object instantiation via `TVMFFIObjectCreator` and `total_size`. Registered per type via `TVMFFITypeRegisterExtraInfo`.
- **`ObjectDef<Class>`** -- Type-safe replacement for `ReflectionDef`. The class template parameter eliminates the error-prone explicit type-index passing pattern.
- **`TVM_FFI_STATIC_INIT_BLOCK`** -- General-purpose static initialization macro that replaces the reflection-specific `TVM_FFI_REFLECTION_DEF` macro. Can be reused for any registration that needs to happen at static init time.
- **`GlobalFunctionTable::Entry`** -- Internal `Object` subclass that wraps `TVMFFIMethodInfo`, storing metadata (name, doc, type_schema, flags) alongside the function. Replaces the previous `Function*` raw pointer storage.
- **`TVMFFIFunctionSetGlobalFromMethodInfo`** -- New C API for metadata-rich function registration.
- **`type_schema` field** -- JSON schema strings on `TVMFFIFieldInfo` and `TVMFFIMethodInfo` for future type-driven code generation or validation.

## Usage Examples

### Defining reflection with ObjectDef (replaces TVM_FFI_REFLECTION_DEF)
```cpp
#include <tvm/ffi/reflection/reflection.h>

TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::ObjectDef<MyNodeObj>()
      .def_rw("value", &MyNodeObj::value, "value field", refl::DefaultValue(0))
      .def_ro("name", &MyNodeObj::name)
      .def("compute", &MyNodeObj::Compute, "compute method")
      .def_static("create", &MyNode::Create);
});
```

### Before/after migration
```cpp
// BEFORE (removed):
TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0));

// AFTER:
TVM_FFI_STATIC_INIT_BLOCK({
  tvm::ffi::reflection::ObjectDef<TFloatObj>()
      .def_rw("value", &TFloatObj::value, "float value field",
              tvm::ffi::reflection::DefaultValue(10.0));
});
```
