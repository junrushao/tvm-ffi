# Enrich FFI type registry metadata and remove unordered_map dependency
## TL;DR
- Replaces `std::unordered_map` with TVM's own `Map<String, ...>` in both `GlobalFunctionTable` and `TypeTable`, removing STL dependency from the registry internals.
- Enriches `TVMFFIFieldInfo` with `size`, `alignment`, `type_schema` fields and introduces `TVMFFITypeExtraInfo` struct (with `creator`, `total_size`, `doc`) for future reflection-based object construction.
- Renames `ReflectionDef` to `ObjectDef<Class>` (templatized), replaces `TVM_FFI_REFLECTION_DEF` macro with `TVM_FFI_STATIC_INIT_BLOCK`, and renames `TVMFFIErrorSetRaisedByCStr` to `TVMFFIErrorSetRaisedFromCStr`.

### Rename mapping

| Old | New |
|-----|-----|
| `ReflectionDef` | `ObjectDef<Class>` |
| `TVM_FFI_REFLECTION_DEF(TypeName)` | `TVM_FFI_STATIC_INIT_BLOCK({ refl::ObjectDef<TypeName>()... })` |
| `TVMFFIFieldFlagBitMaskWritable` | `kTVMFFIFieldFlagBitMaskWritable` |
| `TVMFFIFieldFlagBitMaskHasDefault` | `kTVMFFIFieldFlagBitMaskHasDefault` |
| `TVMFFIFieldFlagBitMaskIsStaticMethod` | `kTVMFFIFieldFlagBitMaskIsStaticMethod` |
| `TVMFFIErrorSetRaisedByCStr` | `TVMFFIErrorSetRaisedFromCStr` |
| `TVMFFITypeGetMethod` | `TVMFFITypeRegisterExtraInfo` (replaced) |
| `TVMFFIFieldInfo.byte_offset` | `TVMFFIFieldInfo.offset` |
| `namespace ffi::refl` alias | removed |
| `TVM_FFI_BUILD_REGISTRY` CMake option | removed |

## Impact
- API: Breaking rename of 3 C ABI enum constants (k-prefix), `TVMFFIErrorSetRaisedByCStr` -> `TVMFFIErrorSetRaisedFromCStr`, `TVMFFIFieldInfo.byte_offset` -> `TVMFFIFieldInfo.offset`, `TVMFFITypeGetMethod` removed and replaced by `TVMFFITypeRegisterExtraInfo`. All downstream C/C++ callers using old names must update.
- Behavioral: `GlobalFunctionTable` now stores full method metadata (doc, type_schema, flags) alongside the function. `TypeTable` uses TVM `Map` instead of `std::unordered_map`, changing iteration order guarantees (Map preserves insertion order).
- Flags/config: `TVM_FFI_BUILD_REGISTRY` CMake option removed (registry is now always built).
- Data formats/schemas: `TVMFFIFieldInfo` struct layout changed (new fields `type_schema`, `size`, `alignment`; `byte_offset` renamed to `offset`). `TVMFFITypeInfo` struct layout changed (`type_key_hash` moved after `type_acenstors`; new `extra_info` pointer; `fields`/`methods` now `const`).

## Design Elements
Design elements this commit consumes:
- **Object system** (0002): `Object`, `ObjectRef`, `make_object<T>()` used to wrap global function entries
- **Containers** (0006): `Map<String, Any>`, `Map<String, int64>`, `String`, `Array<String>` now used for registry storage
- **Function system** (0003): `Function::FromTyped`, `TVM_FFI_REGISTER_GLOBAL` pattern unchanged
- **C ABI** (0007): Builds on existing `TVMFFITypeInfo`, `TVMFFIFieldInfo`, `TVMFFIMethodInfo` structs

Design elements this commit produces:
- **`TVMFFITypeExtraInfo` struct**: New C ABI type enabling reflection-based object construction via `creator` callback
- **`TVMFFIObjectCreator` callback type**: New function pointer type for runtime object instantiation
- **`ObjectDef<Class>` template**: Replaces `ReflectionDef` with a type-safe templatized builder that infers type_index and type_key from the Class template parameter
- **`TVM_FFI_STATIC_INIT_BLOCK` macro**: General-purpose static initialization block replacing the reflection-specific `TVM_FFI_REFLECTION_DEF` macro
- **`TVMFFIFunctionSetGlobalFromMethodInfo`**: New C API enabling metadata-rich global function registration
- **`TVMFFITypeRegisterExtraInfo`**: New C API for registering type extra info (replaces `TVMFFITypeGetMethod`)
- **`GlobalFunctionTable::Entry`**: Internal class that co-inherits `Object` and `TVMFFIMethodInfo`, storing full metadata alongside the function

## Usage Examples

Before (old reflection API):
```cpp
// Old: macro-based, type_index/type_key passed explicitly
TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
    .def("add", &TFloatObj::Add, "add method");
```

After (new reflection API):
```cpp
// New: templatized builder inside a general init block
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::ObjectDef<TFloatObj>()
      .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
      .def("add", &TFloatObj::Add, "add method");
});
```
