# Fix Windows compatibility: CMake modernization, Tuple SFINAE decay, and non-ASCII comment cleanup
## TL;DR
- Replace `FetchContent_Populate` + manual `add_subdirectory` with `FetchContent_MakeAvailable` in GoogleTest CMake (modern CMake idiom, fixes Windows fetch issues).
- Change `std::remove_cv_t` to `std::decay_t` in `Tuple` variadic constructor SFINAE guard to fix MSVC template deduction failures.
- Replace non-ASCII en-dash characters (`–`) with ASCII hyphens (`-`) in `json_parser.cc` UTF-16 surrogate pair comments (avoids encoding issues on Windows).
- Remove hardcoded `MSVC_RUNTIME_LIBRARY` from test `CMakeLists.txt` and unify runtime output directory to `lib/`.
