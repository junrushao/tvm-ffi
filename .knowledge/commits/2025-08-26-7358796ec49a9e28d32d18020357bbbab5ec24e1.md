# Windows compatibility fixups: CMake modernization, MSVC SFINAE fix, and ASCII encoding cleanup
## TL;DR
- Replace `FetchContent_Populate` + `add_subdirectory` with `FetchContent_MakeAvailable` (modern CMake idiom, better Windows support).
- Change `std::remove_cv_t` to `std::decay_t` in `Tuple` variadic constructor SFINAE guard to fix MSVC template deduction.
- Replace non-ASCII en-dash characters (`\u2013`) with ASCII hyphens in `json_parser.cc` comments for source encoding portability.
- Clean up test CMakeLists: remove hardcoded `MSVC_RUNTIME_LIBRARY`, unify output directory to `lib/`.
