## Design Elements
Design elements this commit consumes:
- **Function system** (0003): `TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, ...)` exports a typed C++ function as a C-ABI-safe DLL symbol; `TVM_FFI_STATIC_INIT_BLOCK` performs static-init registration.

- **Reflection** (0008): `reflection::GlobalDef().def("tvm_ffi_extension.raise_error", RaiseError)` registers a function into the global table at static init time.
- **C ABI** (0007): `DLTensor*` used directly as a function parameter, demonstrating zero-copy tensor interop.
- **Containers** (0006): `ffi::String` as a typed parameter for `RaiseError`.

## Usage Examples
The new `examples/packaging/` files themselves serve as usage examples. The C++ extension demonstrates two function-export patterns side by side:

```cpp
// Pattern 1: Direct C-symbol export via macro
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, tvm_ffi_extension::AddOne);

// Pattern 2: Reflection-based global registration
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("tvm_ffi_extension.raise_error", RaiseError);
});
```

The Python runner calls the extension:
```python
import tvm_ffi_extension
tvm_ffi_extension.add_one(x, y)           # calls DLL-exported symbol
tvm_ffi_extension.raise_error("message")  # calls reflection-registered func
```
