## Usage Examples
The new `extension.cc` itself serves as a usage example demonstrating two function export patterns side by side:

```cpp
// Pattern 1: C symbol export (for Module::LoadFromFile)
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, tvm_ffi_extension::AddOne);

// Pattern 2: Global function registration (for get_global_func)
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("tvm_ffi_extension.raise_error", RaiseError);
});
```

The Python runner shows cross-language invocation via a hypothetical `tvm_ffi_extension` package:

```python
import tvm_ffi_extension
tvm_ffi_extension.add_one(x, y)           # calls DLL-exported symbol
tvm_ffi_extension.raise_error("message")  # calls globally registered function
```
