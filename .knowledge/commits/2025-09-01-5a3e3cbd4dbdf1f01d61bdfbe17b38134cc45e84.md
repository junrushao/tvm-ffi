## Usage Examples

**End-to-end packaging example: C++ definition → Python call**

Define and register functions in C++ (`examples/packaging/src/extension.cc`):
```cpp
// 1. Direct C-linkage typed export (no global registry needed):
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, tvm_ffi_extension::AddOne);

// 2. Global registry registration (findable via tvm_ffi.get_global_func):
TVM_FFI_STATIC_INIT_BLOCK({
    refl::GlobalDef().def("tvm_ffi_extension.raise_error", RaiseError);
});
```

Call from Python (`examples/packaging/run_example.py`):
```python
import tvm_ffi_extension

# call direct-export symbol
tvm_ffi_extension.add_one(x, y)

# call function registered in global table
tvm_ffi_extension.raise_error("This is an error")
```

This trace shows that `TVM_FFI_DLL_EXPORT_TYPED_FUNC` exposes `add_one` as a Python-callable attribute on the extension module, while `GlobalDef().def(...)` registers `raise_error` into the global function table accessible via `tvm_ffi.get_global_func(name)`.
