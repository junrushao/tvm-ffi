## Usage Examples
The new `examples/packaging/` files demonstrate two patterns for exporting functions from a `tvm_ffi`-based C++ extension:

**Pattern 1: C-symbol export (for `load_module`)**
```cpp
// extension.cc -- export via C symbol
void AddOne(DLTensor* x, DLTensor* y) { /* ... */ }
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, tvm_ffi_extension::AddOne);
```

**Pattern 2: Global function registry (for `get_global_func`)**
```cpp
// extension.cc -- register via reflection
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("tvm_ffi_extension.raise_error", RaiseError);
});
```

**Python caller:**
```python
import tvm_ffi_extension
tvm_ffi_extension.add_one(x_tensor, y_tensor)
tvm_ffi_extension.raise_error("message")
```
