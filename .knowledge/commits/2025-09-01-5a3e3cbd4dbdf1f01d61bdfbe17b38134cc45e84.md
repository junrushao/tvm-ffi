## Design Elements
Design elements this commit consumes:
- `refl::GlobalDef` + `TVM_FFI_STATIC_INIT_BLOCK` pattern (see [0004-ffi-function-system](../design-records/0004-ffi-function-system.md)) — used in `extension.cc` to register `tvm_ffi_extension.raise_error` into the global function table.
- `TVM_FFI_DLL_EXPORT_TYPED_FUNC` macro — used to export `add_one` as a C symbol following tvm-ffi ABI.
- `TVM_FFI_THROW(RuntimeError)` / `TVM_FFI_ICHECK` (see [0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md)) — used in `extension.cc` for argument validation and error propagation across the language boundary.

## Usage Examples

End-to-end trace showing how to author a `tvm-ffi` extension library and call it from Python:

**C++ (`examples/packaging/src/extension.cc`)**:
```cpp
// Register raise_error into the global function table via reflection
TVM_FFI_STATIC_INIT_BLOCK({
    refl::GlobalDef().def("tvm_ffi_extension.raise_error", RaiseError);
});

// Export add_one as a direct ABI-stable C symbol
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, tvm_ffi_extension::AddOne);
```

**Python (`examples/packaging/run_example.py`)**:
```python
import tvm_ffi_extension

# Call via C symbol export
x = torch.tensor([1, 2, 3], dtype=torch.float32)
y = torch.empty_like(x)
tvm_ffi_extension.add_one(x, y)

# Call via global function table registration
tvm_ffi_extension.raise_error("This is an error")
```
