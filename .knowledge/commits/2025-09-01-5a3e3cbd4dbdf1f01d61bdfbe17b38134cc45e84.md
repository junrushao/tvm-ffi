The `extension.cc` file demonstrates two registration patterns side by side:

```python
# Pattern 1: C symbol export (for runtime-loaded modules)
# TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, AddOne)
# Produces: extern "C" void* __tvm_ffi_add_one  (symbol loadable by Module::LoadFromFile)
# Interacts with: Module system (0011-module-system), DSOLibrary.GetSymbol

# Pattern 2: Reflection-based global registration (for statically linked code)
# TVM_FFI_STATIC_INIT_BLOCK({
#     refl::GlobalDef().def("tvm_ffi_extension.raise_error", RaiseError);
# })
# Produces: global function table entry accessible via get_global_func("tvm_ffi_extension.raise_error")
# Interacts with: Reflection system (0008-reflection), GlobalDef
```

## Design Elements
Design elements this commit consumes:
- **Module system** (`TVM_FFI_DLL_EXPORT_TYPED_FUNC`) -- used in `extension.cc` to export `add_one` as a C-ABI symbol. See `.knowledge/designs/0011-module-system.md`.
- **Reflection / GlobalDef** (`TVM_FFI_STATIC_INIT_BLOCK`, `refl::GlobalDef().def(...)`) -- used in `extension.cc` to register `raise_error` as a global function at static init time. See `.knowledge/designs/0008-reflection.md`.
- **Error system** (`TVM_FFI_THROW`, `TVM_FFI_ICHECK`) -- used in `extension.cc` for error propagation across the FFI boundary. See `.knowledge/designs/0005-error-system.md`.
- **DLTensor convention** -- `AddOne` takes raw `DLTensor*` arguments, demonstrating the tensor interop pattern with torch.

## Usage Examples
The packaging example itself serves as a usage example. The C++ side (`extension.cc`) shows how to write an FFI extension library, and the Python side (`run_example.py`) shows how to consume it:

```python
# run_example.py -- consuming the extension from Python
import torch
import tvm_ffi_extension

x = torch.tensor([1, 2, 3, 4, 5], dtype=torch.float32)
y = torch.empty_like(x)
tvm_ffi_extension.add_one(x, y)  # calls C-ABI exported __tvm_ffi_add_one
print(y)  # tensor([2., 3., 4., 5., 6.])

tvm_ffi_extension.raise_error("msg")  # calls reflection-registered global func
```
