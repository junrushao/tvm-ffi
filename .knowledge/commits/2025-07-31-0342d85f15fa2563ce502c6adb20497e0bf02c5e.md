# Fix SmallMapObj::CreateFromRange to deduplicate keys on construction
## TL;DR
- `MapObj::CreateFromRange` for the SmallMap path blindly copied all input pairs without deduplication, causing `Map.size()` to overcount when duplicate keys were present.
- Fix: for SmallMap inputs with `cap >= 2`, use `SmallMapObj::Empty(cap)` + per-element `InsertMaybeReHash` (which checks for existing keys) instead of the raw `CreateFromRange` bulk copy.
- `cap < 2` remains a fast path since 0 or 1 elements cannot contain duplicates.

## Key Exports

No new public API surface. The fix is internal to `MapObj::CreateFromRange` in `include/tvm/ffi/container/map.h`.

```python
# No new exports. Internal behavioral fix to:
# MapObj::CreateFromRange(first, last) -> ObjectPtr<Object>
#   Invariant (restored): output map.size() == number of distinct keys in [first, last)
#   Invariant (restored): last-write-wins for duplicate keys (consistent with DenseMapObj path)
#   Interacts with: SmallMapObj::InsertMaybeReHash (handles key dedup + value overwrite)
#   Interacts with: SmallMapObj::CreateFromRange (still used only for cap < 2 fast path)
```

## Impact
- API: none -- no public signature changes
- Behavioral: `Map` constructed from ranges with duplicate keys now correctly deduplicates (last-write-wins), matching `DenseMapObj` behavior and `std::map`/Python `dict` semantics
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `SmallMapObj` and `DenseMapObj` dual-strategy map storage ([0007-containers](../designs/0007-containers.md))

Design elements this commit produces:

## Usage Examples

Before (broken): constructing a SmallMap from a range with duplicates stored all entries.

```cpp
// BEFORE: bug -- SmallMapObj::CreateFromRange stored all 3 pairs
std::vector<std::pair<String, int>> data = {{"a", 1}, {"a", 2}, {"a", 3}};
Map<String, int> map(data.begin(), data.end());
// map.size() == 3  (WRONG -- should be 1)
// map["a"] undefined behavior (multiple entries for same key)
```

After (fixed): `InsertMaybeReHash` deduplicates, last write wins.

```cpp
// AFTER: fix -- InsertMaybeReHash deduplicates, last value wins
std::vector<std::pair<String, int>> data = {{"a", 1}, {"a", 2}, {"a", 3}};
Map<String, int> map(data.begin(), data.end());
// map.size() == 1  (CORRECT)
// map["a"] == 3    (last-write-wins)
```
