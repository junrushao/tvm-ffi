# Introduce TVM FFI foundation: C ABI, type-erased Any/Object/Function, containers, and reflection

## TL;DR
- Root commit establishing the entire TVM FFI module: 59 files, 15328 LOC of C++ headers, implementation, CMake build, and GoogleTest tests.
- Implements a modern version of the Unified Packed and Object RFC: stable C ABI (`c_api.h`), type-erased values (`Any`/`AnyView`), ref-counted objects (`Object`/`ObjectRef`), packed functions (`Function`), trait-based type conversion (`TypeTraits<T>`), and containers (`Array`, `Map`, `String`, `Shape`, `NDArray`, `Tuple`, `Variant`, `Optional`).
- Provides object-based error handling, runtime type registration with ancestor tracking, field reflection, and DLPack interop.

### C++ Any Layer (`include/tvm/ffi/any.h`)

**Classes:**
- `AnyView` -- Non-owning 16-byte type-erased value view. Key methods: `as<T>() -> optional<T>`, `cast<T>() -> T`, `type_index() -> int32_t`, `GetTypeKey() -> string`. Implicit construction from any `T` with `TypeTraits<T>::convert_enabled`.
- `Any` -- Owning 16-byte type-erased value. Same API as `AnyView` plus ref-counting of objects. Zero-cost conversion to `AnyView`. `reset()` decrements object refcount. `same_as(Any|ObjectRef) -> bool`.
- `AnyHash`, `AnyEqual` -- String-aware hash/equality functors for `Any`.

**Invariant:** `sizeof(AnyView) == sizeof(Any) == sizeof(TVMFFIAny) == 16`. `Any::data_` can always be safely used as `AnyView`.

### C++ Object Layer (`include/tvm/ffi/object.h`)

**Classes:**
- `Object` -- Base of all ref-counted heap objects. Contains `TVMFFIObject header_`. Key methods: `IsInstance<T>() -> bool`, `type_index() -> int32_t`, `GetTypeKey() -> string`, `use_count() -> int32_t`, `unique() -> bool`. Declares `_type_key`, `_type_index`, `_type_final`, `_type_child_slots`, `_type_child_slots_can_overflow`, `_type_depth` static fields for subclasses.
- `ObjectPtr<T>` -- Intrusive smart pointer. Ref-counting via `IncRef`/`DecRef`. Value semantics (copy increments, move transfers).
- `ObjectRef` -- Base reference wrapper holding `ObjectPtr<Object> data_`. Key methods: `as<ObjectType>() -> const ObjectType*`, `as<ObjectRefType>() -> optional<ObjectRefType>`, `defined() -> bool`, `same_as()`, `get()`, `type_index()`.

**Macros:**
- `TVM_FFI_DECLARE_BASE_OBJECT_INFO(TypeName, ParentType)` -- For inheritable object types. Registers dynamic type index via `TVMFFIGetOrAllocTypeIndex`.
- `TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TypeName, ParentType)` -- For leaf types. Sets `_type_final=true`, `_type_child_slots=0`.
- `TVM_FFI_DECLARE_STATIC_OBJECT_INFO(TypeName, ParentType)` -- For types with fixed (compile-time) type index.
- `TVM_FFI_DEFINE_OBJECT_REF_METHODS(TypeName, ParentType, ObjectName)` -- Defines default ctor, `operator->`, `get()`, `ContainerType`.
- `TVM_FFI_DEFINE_NOTNULLABLE_OBJECT_REF_METHODS(...)` -- Same but sets `_type_is_nullable=false`.

**Type checking:** `details::IsObjectInstance<TargetType>(type_index)` -- fast-path range check using `_type_child_slots`, fallback to ancestor table lookup.

### C++ Function Layer (`include/tvm/ffi/function.h`)

**Classes:**
- `FunctionObj : Object, TVMFFIFunctionCell` -- Object backing `Function`. Has `FCall call` (C++ exception-propagating) and `TVMFFISafeCallType safe_call` (C-style catching). `CallPacked(args, num_args, result)`.
- `Function : ObjectRef` -- Type-erased callable. Key static methods:
  - `FromPacked(callable) -> Function` -- from `void(const AnyView*, int32_t, Any*)` or `void(PackedArgs, Any*)`.
  - `FromUnpacked(callable) -> Function` -- from ordinary C++ function/lambda (auto-unpack via `TypeTraits`).
  - `FromExternC(self, safe_call, deleter) -> Function` -- from C callback.
  - `ImportFromExternDLL(other) -> Function` -- import cross-DLL function.
  - `GetGlobal(name) -> optional<Function>`, `GetGlobalRequired(name) -> Function`.
  - `SetGlobal(name, func, override)`, `ListGlobalNames()`, `RemoveGlobal(name)`.
  - `operator()(Args...) -> Any` -- call with auto-packed arguments.
- `TypedFunction<R(Args...)>` -- Compile-time typed wrapper around `Function`. Automatic pack/unpack.
- `PackedArgs` -- View over `AnyView[]` with `Slice`, indexing, `Fill`.
- `Function::Registry` -- Builder for `TVM_FFI_REGISTER_GLOBAL`. Methods: `set_body_packed`, `set_body_typed`, `set_body_method`.

**Macros:**
- `TVM_FFI_REGISTER_GLOBAL(name)` -- Register a global function.
- `TVM_FFI_SAFE_CALL_BEGIN()` / `TVM_FFI_SAFE_CALL_END()` -- Exception-to-error-code wrapper.
- `TVM_FFI_CHECK_SAFE_CALL(func)` -- Error-code-to-exception unwrapper.

### C++ TypeTraits (`include/tvm/ffi/type_traits.h`)

**Protocol:** `TypeTraits<T>` specialization must provide:
- `CopyToAnyView(T, TVMFFIAny*)` -- T to non-owning view.
- `MoveToAny(T, TVMFFIAny*)` -- T to owned Any.
- `CheckAnyStorage(TVMFFIAny*) -> bool` -- strict storage check.
- `CopyFromAnyStorageAfterCheck / MoveFromAnyStorageAfterCheck` -- extract T after check passes.
- `TryConvertFromAnyView(TVMFFIAny*) -> optional<T>` -- convert with possible coercion.
- `TypeStr() -> string`, `GetMismatchTypeInfo(TVMFFIAny*) -> string`.

Built-in specializations: `nullptr_t`, `bool`, `StrictBool`, integral types, floating types, `void*`, `DLDevice`, `DLTensor*`, `ObjectRef` subclasses, `Optional<T>`, `const TObject*` (weak ptr), `TypedFunction<F>`.

**Helper bases:** `TypeTraitsBase`, `ObjectRefTypeTraitsBase<T>`, `FallbackOnlyTraitsBase<T, FallbackTypes...>`, `ObjectRefWithFallbackTraitsBase<T, FallbackTypes...>`.

### C++ Memory (`include/tvm/ffi/memory.h`)

- `make_object<T>(args...) -> ObjectPtr<T>` -- Allocate and construct an Object. Sets `ref_counter=1`, `type_index=T::RuntimeTypeIndex()`, `deleter`.
- `make_inplace_array_object<ArrayType, ElemType>(num_elems, args...) -> ObjectPtr<ArrayType>` -- Inplace array allocation.
- `SimpleObjAllocator` -- Default allocator using `new`/`delete` with `aligned_storage`.

### C++ Error Handling (`include/tvm/ffi/error.h`)

- `ErrorObj : Object, TVMFFIErrorCell` -- Error object with kind, message, traceback.
- `Error : ObjectRef, std::exception` -- Ref wrapper. `kind()`, `message()`, `traceback()`, `what()`, `UpdateTraceback()`.
- `EnvErrorAlreadySet` -- Sentinel exception for frontend-signaled errors.
- `TVM_FFI_THROW(ErrorKind) << "msg"` -- Stream-style error throw with auto-traceback.
- `TVM_FFI_ICHECK(x)`, `TVM_FFI_ICHECK_LT/GT/LE/GE/EQ/NE(x,y)` -- Internal assertion macros.

### C++ Containers

- `String : ObjectRef` (`string.h`) -- Immutable UTF-8 string wrapping `StringObj : BytesObjBase : Object, TVMFFIByteArray`. Auto-converts from `const char*`, `std::string`, `std::string_view`.
- `Bytes : ObjectRef` -- Raw byte container wrapping `BytesObj`.
- `Array<T>` (`container/array.h`) -- Immutable typed array. `ArrayObj` uses inplace allocation of `Any` elements.
- `Map<K,V>` (`container/map.h`) -- Insertion-order-preserving hash map. `MapObj` with `KVType = pair<Any, Any>`.
- `NDArray` (`container/ndarray.h`) -- Managed tensor with DLPack interop.
- `Shape` (`container/shape.h`) -- Immutable shape (`ShapeObj`).
- `Tuple<T...>` (`container/tuple.h`) -- Typed fixed-size tuple.
- `Variant<T...>` (`container/variant.h`) -- Tagged union of ObjectRef types.
- `Optional<T>` (`optional.h`) -- Nullable value (nullptr for ObjectRef, `std::optional` for POD).

### C++ Reflection (`include/tvm/ffi/reflection/reflection.h`)

- `ReflectionDef` -- Builder class. `def_readonly(name, &Class::field)`, `def_readwrite(name, &Class::field)`. Registers `TVMFFIFieldInfo` entries via `TVMFFIRegisterTypeField`.
- `ReflectionFieldGetter` -- Wraps a `TVMFFIFieldInfo*` for dynamic field access.
- `TVM_FFI_REFLECTION_DEF(TypeName)` -- Macro to define reflection for an object type.

## Impact
- API: Establishes the entire public API surface. No prior API exists.
- ABI: Defines the stable C ABI layout (`TVMFFIObject` 16-byte header, `TVMFFIAny` 16-byte value, `TVMFFISafeCallType` calling convention). Not backward compatible with any predecessor.
- Behavioral: Introduces object-based error handling (replacing string-based), insertion-order `Map`, `Any` supporting both POD and object types natively (e.g., `Array<int>` now works without boxing).
- Flags/config: `TVM_FFI_USE_LIBBACKTRACE=1`, `TVM_FFI_BACKTRACE_ON_SEGFAULT=1`, `TVM_FFI_DEBUG_WITH_ABI_CHANGE` (Map concurrent modification check).
- Data formats/schemas: DLPack v1 and v2 interop via `TVMFFINDArrayFromDLPack` / `ToDLPack` and versioned variants.

## Design Elements
Design elements this commit consumes:
- DLPack (`dlpack/dlpack.h` via 3rdparty submodule) -- `DLTensor`, `DLDataType`, `DLDevice`, `DLManagedTensor`, `DLManagedTensorVersioned`.
- C++ STL -- `std::optional`, `std::string_view`, `std::unordered_map`, `std::aligned_storage`.
- GoogleTest -- test framework for all `tests/cpp/` files.
- libbacktrace (3rdparty) -- stack trace generation.

Design elements this commit produces:
- **C ABI contract** -- The 16-byte `TVMFFIObject` header and 16-byte `TVMFFIAny` value layout that all language bindings must respect. Error propagation via TLS (`TVMFFIErrorSetRaised` / `TVMFFIErrorMoveFromRaised`).
- **Type index system** -- Static range `[0, 64)` for POD, `[64, 128)` for built-in objects, `[128, +inf)` for dynamic types. Ancestor-chain type checking with child-slot optimization.
- **Object pattern** -- `FooObj` (data class, inherits `Object`) + `Foo` (ref wrapper, inherits `ObjectRef`). `make_object<T>()` for allocation. Intrusive ref-counting.
- **Any/AnyView duality** -- `Any` owns (refcounts objects), `AnyView` borrows. Same 16-byte binary layout.
- **TypeTraits protocol** -- Trait-based conversion between C++ types and `Any`/`AnyView`. Enables automatic pack/unpack for function calls.
- **Packed function calling convention** -- `void(const AnyView* args, int32_t num_args, Any* rv)` as the universal C++ call signature; `TVMFFISafeCallType` as the C ABI equivalent.
- **Global function registry** -- String-keyed registry for cross-language function dispatch (`SetGlobal`/`GetGlobal`).
- **Reflection system** -- `TVMFFIFieldInfo`-based field/method introspection registered per type index.
- **Container suite** -- `Array`, `Map` (insertion-order), `String`, `Bytes`, `Shape`, `NDArray`, `Tuple`, `Variant`, `Optional`.

## Usage Examples

### Defining a custom object type
```cpp
// Object data class (the "Obj" part)
class MyNodeObj : public Object {
 public:
  int64_t value;
  String name;
  static constexpr const char* _type_key = "my.Node";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyNodeObj, Object);
};
// Reflection registration
TVM_FFI_REFLECTION_DEF(MyNodeObj)
    .def_readonly("value", &MyNodeObj::value)
    .def_readonly("name", &MyNodeObj::name);
// Reference wrapper (the "Ref" part)
class MyNode : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(MyNode, ObjectRef, MyNodeObj);
};
```

### Using Any/AnyView for type-erased values
```cpp
Any x = 42;                         // stores int
Any y = String("hello");            // stores String object
int val = x.cast<int>();            // 42
String s = y.cast<String>();        // "hello"
optional<double> d = x.as<double>(); // 42.0 (int-to-float coercion)
```

### Registering and calling global functions
```cpp
// Registration
TVM_FFI_REGISTER_GLOBAL("my.Add")
    .set_body_typed([](int a, int b) -> int { return a + b; });
// Lookup and call
Function f = Function::GetGlobalRequired("my.Add");
int result = f(3, 4).cast<int>();  // 7
```

### Creating a packed function from a lambda
```cpp
Function f = Function::FromUnpacked([](int a, int b) -> int { return a + b; });
int result = f(1, 2).cast<int>();  // 3

// Typed wrapper for compile-time checking
TypedFunction<int(int, int)> typed_add = [](int x, int y) { return x + y; };
int r = typed_add(3, 4);  // 7
```

### ADRs to write or update
- `.knowledge/ADRs/001-unified-any-and-object.md` -- Decision to unify packed function values and object references through a single 16-byte Any type with shared type_index layout between TVMFFIAny and TVMFFIObject. Rationale: eliminates separate PackedFunc argument types, enables `Array<int>` without boxing.
- `.knowledge/ADRs/002-tls-error-propagation.md` -- Decision to use TLS for error propagation in the C ABI (TVMFFIErrorSetRaised/MoveFromRaised) rather than passing error through return arguments. Rationale: simplifies codegen for chains of calls.
- `.knowledge/ADRs/003-type-index-ranges.md` -- Decision to partition type indices into static POD `[0,64)`, static object `[64,128)`, and dynamic `[128,+inf)` ranges with child-slot optimization for fast IsInstance checks.
- `.knowledge/ADRs/004-insertion-order-map.md` -- Decision to make Map preserve insertion order. Rationale: deterministic iteration important for serialization and debugging.
