# Introduce modernized FFI system with unified Any/Object/Function ABI

## TL;DR
- Introduces the complete TVM FFI foundation: a stable C ABI (`c_api.h`), C++17 type-erased value system (`Any`/`AnyView`), ref-counted object hierarchy (`Object`/`ObjectRef`/`ObjectPtr`), packed function calling convention (`Function`/`FunctionObj`), and object-based error handling (`Error`).
- Provides generic containers (`Array`, `Map`, `Shape`, `Tuple`, `Variant`, `NDArray`, `String`/`Bytes`) that store `Any` values, enabling `Array<int>` without boxing.
- Establishes the `TypeTraits<T>` protocol for compile-time-driven conversion between C++ types and the FFI's type-erased `Any` layer, plus a runtime reflection system for field access.

## Impact
- API: Entirely new public C ABI and C++ API. This is the foundational commit -- no prior API existed in this repository.
- Behavioral: The commit message notes this is an ABI-breaking upgrade from the legacy TVM FFI. Code compiled under the old ABI will not work under the new one. `LegacyTVMArgValueToFFIAny` translation functions are mentioned for compatibility.
- Flags/config: `TVM_FFI_BUILD_TESTS` CMake option added to enable GoogleTest suite. `TVM_FFI_USE_LIBBACKTRACE` and `TVM_FFI_BACKTRACE_ON_SEGFAULT` control traceback behavior.
- Data formats/schemas: Introduces `TVMFFIAny` as the universal 16-byte value wire format. `TVMFFIObject` is the 16-byte heap object header. These define the stable C ABI layout.

## Design Elements

Design elements this commit consumes:
- DLPack (`DLTensor`, `DLManagedTensor`, `DLManagedTensorVersioned`, `DLDataType`, `DLDevice`) from `3rdparty/dlpack`
- GoogleTest framework for C++ tests
- CMake build system conventions

Design elements this commit produces:
- **C ABI contract** (`c_api.h`): The stable binary interface -- TVMFFIAny layout, TVMFFIObject layout, TVMFFISafeCallType calling convention, global function registry, TLS error propagation, type registration
- **Object system** (`object.h`): Object/ObjectRef/ObjectPtr pattern, type hierarchy with child-slot optimization for O(1) IsInstance, TVM_FFI_DECLARE_*_OBJECT_INFO macros
- **Any/AnyView value erasure** (`any.h`): 16-byte tagged union with ownership semantics (Any owns, AnyView borrows), automatic RawStr-to-String promotion
- **TypeTraits protocol** (`type_traits.h`): Compile-time trait specialization governing how types convert to/from Any
- **Function system** (`function.h`): Packed calling convention (AnyView[] args), FromPacked/FromUnpacked construction, global function registry, safe-call exception boundary
- **Error system** (`error.h`): Object-based errors with kind/message/traceback, TLS propagation across safe-call boundaries, TVM_FFI_THROW macro
- **Reflection** (`reflection.h`): Runtime field accessor registration via ReflectionDef/TVM_FFI_REFLECTION_DEF
- **Container suite**: Array, Map (insertion-ordered), String/Bytes, Shape, Tuple, Variant, NDArray with DLPack interop
- **Memory allocation**: make_object with SimpleObjAllocator, pluggable allocator base via CRTP

## Usage Examples

**Defining a new Object type and using reflection:**

```cpp
// In header: define Obj (data) + Ref (handle)
class MyNodeObj : public Object {
 public:
  int64_t value;
  String name;
  static constexpr const char* _type_key = "my.Node";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyNodeObj, Object);
};
// Register fields for cross-language reflection
TVM_FFI_REFLECTION_DEF(MyNodeObj)
    .def_readonly("value", &MyNodeObj::value)
    .def_readwrite("name", &MyNodeObj::name);

class MyNode : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(MyNode, ObjectRef, MyNodeObj);
};
// Construct:  auto node = make_object<MyNodeObj>(); sets type_index + ref_counter
```

**Registering and calling a global function:**

```cpp
// C++ side: register a typed function into the global registry
TVM_FFI_REGISTER_GLOBAL("my.add").set_body_typed([](int a, int b) -> int {
  return a + b;
});

// C++ caller:
Function f = Function::GetGlobalRequired("my.add");
int result = f(1, 2).cast<int>();  // packs args as AnyView[], unpacks result
```

**Using Any for type-erased storage:**

```cpp
Any val = 42;                    // int stored inline (type_index=kTVMFFIInt)
Any str = String("hello");       // String object, ref-counted
int x = val.cast<int>();         // extract with type check
auto opt = val.as<double>();     // optional conversion (int->double succeeds)
Array<int> arr({1, 2, 3});      // Array<int> works without boxing
```
