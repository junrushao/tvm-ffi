# Introduce foundational FFI module with Any/Object/Function system and stable C ABI
## TL;DR
- Introduces the complete `tvm::ffi` module: a stable C ABI (`c_api.h`), type-erased value containers (`Any`/`AnyView`), ref-counted object system (`Object`/`ObjectRef`/`ObjectPtr`), packed function calling convention (`Function`/`TypedFunction`), object-based error handling (`Error`), and containers (`Array`, `Map`, `String`, `Shape`, `NDArray`, `Tuple`, `Variant`, `Optional`).
- Establishes the global function registry (`TVM_FFI_REGISTER_GLOBAL`), runtime type system with static/dynamic type indices, and a reflection subsystem (`TVM_FFI_REFLECTION_DEF`) for cross-language field access.
- Adds comprehensive C++ test suite (17 test files), CMake build system, and infrastructure (libbacktrace, dlpack submodule, sanitizer support).

## Key Exports

The ~15 most architecturally significant symbols. Plus ~40 additional container types, helper classes, and internal details.

```python
# === C ABI Layer (c_api.h) ===

class TVMFFITypeIndex(IntEnum):
    """Runtime type discriminator shared by Any and Object."""
    kTVMFFINone = 0      # null
    kTVMFFIInt = 1        # int64
    kTVMFFIBool = 2       # bool
    kTVMFFIFloat = 3      # float64
    kTVMFFIDataType = 5   # DLDataType
    kTVMFFIDevice = 6     # DLDevice
    kTVMFFIRawStr = 8     # const char* (AnyView only, never in Any)
    kTVMFFIStaticObjectBegin = 64
    kTVMFFIObject = 64
    kTVMFFIStr = 65
    kTVMFFIError = 67
    kTVMFFIFunction = 68
    kTVMFFIArray = 69
    kTVMFFIMap = 70
    kTVMFFIDynObjectBegin = 128  # dynamic types start here
    # Invariant: type_index < kTVMFFIStaticObjectBegin means POD on-stack value
    # Invariant: type_index >= kTVMFFIStaticObjectBegin means heap-allocated Object

class TVMFFIObject:
    """C-level object header. First field of every heap object."""
    type_index: int32
    ref_counter: int32       # atomic ref count
    deleter: Callable[[TVMFFIObject], None]
    # Invariant: 8-byte aligned via union with int64

class TVMFFIAny:
    """C-level type-erased value. 16 bytes: type_index + small_len + 8-byte union."""
    type_index: int32
    small_len: int32         # reserved for small-string optimization
    # union: v_int64 | v_float64 | v_ptr | v_c_str | v_obj | v_dtype | v_device | v_bytes
    # Invariant: caller must init type_index to kTVMFFINone before passing as out-param

# Key C API functions:
def TVMFFIFunctionCall(func: ObjectHandle, args: TVMFFIAny*, num_args: int32, result: TVMFFIAny*) -> int: ...
    # Interacts with: TVMFFISafeCallType, TVMFFIErrorMoveFromRaised (TLS error propagation)
    # Invariant: result->type_index must be < kTVMFFIStaticObjectBegin on entry

def TVMFFIFunctionSetGlobal(name: ByteArray*, f: ObjectHandle, override: int) -> int: ...
    # Interacts with: global function registry (thread-safe singleton)

def TVMFFIFunctionGetGlobal(name: ByteArray*, out: ObjectHandle*) -> int: ...
    # Interacts with: global function registry

def TVMFFIGetOrAllocTypeIndex(type_key: ByteArray*, static_idx: int32, ...) -> int32: ...
    # Interacts with: global type table (TVMFFITypeInfo registry)
    # Extension: pass static_idx=-1 for dynamic allocation

# Error propagation via TLS:
def TVMFFIErrorSetRaised(error: ObjectHandle) -> None: ...
def TVMFFIErrorMoveFromRaised(result: ObjectHandle*) -> None: ...
    # Invariant: errors are stored in thread-local storage, moved (not copied) on retrieval

# === C++ Object System (object.h) ===

class Object:
    """Base of all ref-counted heap objects."""
    _type_key: str = "object.Object"
    _type_index: int32 = kTVMFFIObject
    _type_depth: int = 0
    # Interacts with: ObjectPtr (ref counting), TVMFFIGetTypeInfo (runtime RTTI)
    # Extension: subclass with TVM_FFI_DECLARE_BASE_OBJECT_INFO or TVM_FFI_DECLARE_FINAL_OBJECT_INFO
    # Invariant: single inheritance only (type hierarchy is a tree, not DAG)

    def IsInstance(self, TargetType) -> bool: ...
        # Uses: type_index range check + fallback to type_acenstors table

class ObjectPtr[T]:
    """Intrusive ref-counted smart pointer."""
    # Interacts with: Object.IncRef/DecRef (atomic)
    # Invariant: data_ is either nullptr or points to a valid Object with ref_counter >= 1

class ObjectRef:
    """Non-owning handle wrapper around ObjectPtr[Object]."""
    # Interacts with: ObjectPtr, Object
    # Extension: use TVM_FFI_DEFINE_OBJECT_REF_METHODS(TypeName, ParentRef, ObjType)

# === Any/AnyView (any.h) ===

class AnyView:
    """Non-owning type-erased value view. 16 bytes, same layout as TVMFFIAny."""
    # Interacts with: TypeTraits<T> for implicit conversions
    # Invariant: does not own references; caller must keep sources alive
    def cast(self, T) -> T: ...

class Any(AnyView):
    """Owning type-erased value container. Manages ref counts for Object values."""
    # Interacts with: Object.IncRef/DecRef, TypeTraits<T>
    # Invariant: if type_index >= kTVMFFIStaticObjectBegin, v_obj is ref-counted

# === Function System (function.h) ===

class FunctionObj(Object, TVMFFIFunctionCell):
    """Backing object for type-erased functions."""
    safe_call: TVMFFISafeCallType   # C ABI entry point
    call: FCall                      # C++ entry point (may throw)
    # Interacts with: Function (ref wrapper), ExternCFunctionObjImpl, ImportedFunctionObjImpl
    # Invariant: safe_call catches all exceptions and returns error code

class Function(ObjectRef):
    """Type-erased callable with packed calling convention."""
    # Interacts with: FunctionObj, global registry, AnyView/Any
    # Extension: Function.FromUnpacked(lambda) auto-wraps typed callables

    @staticmethod
    def GetGlobal(name: str) -> Optional[Function]: ...
    @staticmethod
    def SetGlobal(name: str, func: Function, override: bool = False) -> None: ...
    @staticmethod
    def FromUnpacked(callable) -> Function: ...
    @staticmethod
    def FromPacked(callable) -> Function: ...
    @staticmethod
    def ImportFromExternDLL(other: Function) -> Function: ...
    def __call__(self, *args) -> Any: ...
        # Packs args into AnyView[], calls FunctionObj.CallPacked, returns Any

class TypedFunction[R, *Args]:
    """Compile-time type-checked wrapper around Function."""
    # Interacts with: Function (internal packed_)

# Macro expansion: TVM_FFI_REGISTER_GLOBAL("name")
# registry["name"] = Function::FromUnpacked(lambda)
# Interacts with: Function::Registry, Function::SetGlobal

# === Error Handling (error.h) ===

class Error(ObjectRef, std.exception):
    """Object-based error with kind/message/traceback."""
    kind: str
    message: str
    traceback: str
    # Interacts with: TLS error propagation (TVMFFIErrorSetRaised/MoveFromRaised)
    # Interacts with: TVM_FFI_SAFE_CALL_BEGIN/END (exception boundary)

# Macro: TVM_FFI_THROW(ErrorKind) << "message"
# Creates ErrorBuilder -> constructs Error -> throws
# Interacts with: TVMFFITraceback (captures stack trace)

# === Memory (memory.h) ===

def make_object(T, *args) -> ObjectPtr[T]: ...
    # Sets ref_counter=1, type_index=T.RuntimeTypeIndex(), deleter=type-specific
    # Interacts with: SimpleObjAllocator, TVMFFIObject header initialization

# === Reflection (reflection.h) ===

class ReflectionDef:
    """Builder for registering field accessors on object types."""
    def def_readonly(self, name: str, field_ptr) -> ReflectionDef: ...
    def def_readwrite(self, name: str, field_ptr) -> ReflectionDef: ...
    # Interacts with: TVMFFIRegisterTypeField, TVMFFIFieldInfo, TVMFFITypeInfo

# Macro: TVM_FFI_REFLECTION_DEF(TypeName).def_readonly("field", &TypeName::field)
# Registers field getter/setter into the global TVMFFITypeInfo table
```

## Impact
- API: Entirely new public C ABI (`c_api.h`) and C++ API (`tvm::ffi` namespace). Not backward compatible with prior TVM FFI -- legacy code requires `LegacyTVMArgValueToFFIAny` translation.
- Behavioral: `Any` can now store POD types (int, float) and Object types uniformly. Containers like `Array<int>` are now supported without boxing. `Map` preserves insertion order. Error handling upgraded to object-based with cross-language tracebacks.
- Flags/config: `TVM_FFI_USE_LIBBACKTRACE` (default 1), `TVM_FFI_BACKTRACE_ON_SEGFAULT` (default 1), `TVM_FFI_DLL` visibility macros.
- Data formats/schemas: New 16-byte `TVMFFIAny` layout replaces prior `TVMValue`+`type_code` pair. New `TVMFFIObject` header layout (type_index + ref_counter + deleter, 16 bytes aligned).

## Design Elements
Design elements this commit consumes:
- DLPack (`dlpack/dlpack.h`): `DLTensor`, `DLDataType`, `DLDevice`, `DLManagedTensor`, `DLManagedTensorVersioned` -- used as the tensor interchange format.

Design elements this commit produces:
- **C ABI contract** (`c_api.h`): The stable C function interface (`TVMFFIFunctionCall`, `TVMFFIFunctionSetGlobal`, etc.) that all language bindings target. Error propagation via TLS (`TVMFFIErrorSetRaised`/`TVMFFIErrorMoveFromRaised`). Return code convention: 0=success, -1=error in TLS, -2=frontend error.
- **Type-erased value system** (`any.h`): `AnyView` (non-owning, 16 bytes) and `Any` (owning, manages refcounts). Unified storage for POD and Object types via shared `TVMFFITypeIndex` discriminator.
- **Object system** (`object.h`, `memory.h`): `Object`/`ObjectRef`/`ObjectPtr` triple. Intrusive ref-counting. Runtime type hierarchy with static slots for fast `IsInstance` checks and fallback ancestor table. `make_object<T>()` factory.
- **Function system** (`function.h`): `FunctionObj`/`Function` with dual entry points (C `safe_call` + C++ `call`). `TypedFunction<R(Args...)>` for compile-time checking. Global function registry. `TVM_FFI_REGISTER_GLOBAL` macro. `FromUnpacked`/`FromPacked`/`ImportFromExternDLL` construction patterns.
- **Error protocol** (`error.h`): Object-based `Error` with kind/message/traceback. `TVM_FFI_THROW` macro. `TVM_FFI_SAFE_CALL_BEGIN`/`END` exception boundary. `EnvErrorAlreadySet` for frontend signal propagation.
- **Type traits system** (`type_traits.h`): Trait-based conversion between C++ types and `Any`/`AnyView`. Controls how user types interact with the FFI.
- **Container suite**: `Array<T>` (immutable), `Map<K,V>` (insertion-ordered, immutable), `String`, `Shape`, `NDArray`, `Tuple`, `Variant<T...>`, `Optional<T>`.
- **Reflection subsystem** (`reflection.h`): `ReflectionDef` builder, `TVMFFIFieldInfo`/`TVMFFIMethodInfo` structs, `TVM_FFI_REFLECTION_DEF` macro. Enables cross-language field access.
- **Object declaration macros**: `TVM_FFI_DECLARE_BASE_OBJECT_INFO`, `TVM_FFI_DECLARE_FINAL_OBJECT_INFO`, `TVM_FFI_DECLARE_STATIC_OBJECT_INFO`, `TVM_FFI_DEFINE_OBJECT_REF_METHODS`.

## Usage Examples

Registering a global function (from `function.h` doc comments):
```cpp
// C++ side: register a function
TVM_FFI_REGISTER_GLOBAL("MyAdd")
.set_body_typed([](int a, int b) -> int {
  return a + b;
});

// C++ side: call a registered function
Function f = Function::GetGlobalRequired("MyAdd");
int result = f(1, 2).cast<int>();  // result == 3
```

Defining a new object type (from `object.h` + `reflection.h`):
```cpp
// Data class
class MyNodeObj : public Object {
 public:
  String name;
  int value;
  static constexpr const char* _type_key = "test.MyNode";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyNodeObj, Object);
};
// Ref wrapper
class MyNode : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(MyNode, ObjectRef, MyNodeObj);
};
// Register reflection
TVM_FFI_REFLECTION_DEF(MyNodeObj)
  .def_readonly("name", &MyNodeObj::name)
  .def_readwrite("value", &MyNodeObj::value);
```

Using Any/AnyView (from tests):
```cpp
Any a = 42;              // stores int64
Any b = String("hello"); // stores ref-counted String object
int x = a.cast<int>();   // x == 42
String s = b.cast<String>(); // extracts String
```

Error handling:
```cpp
TVM_FFI_THROW(ValueError) << "expected positive, got " << x;
// Captures traceback, constructs Error object, throws
```
