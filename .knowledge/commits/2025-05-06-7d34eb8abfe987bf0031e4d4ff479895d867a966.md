# Introduce modernized FFI system with unified Any/Object/Function foundations
## TL;DR
- Root commit establishing the entire TVM FFI module: a stable C ABI (`c_api.h`), C++17 type-erased value system (`Any`/`AnyView`), ref-counted object system (`Object`/`ObjectRef`/`ObjectPtr`), packed function system (`Function`/`FunctionObj`), and container library (`Array`, `Map`, `String`, `Shape`, `Tuple`, `Variant`, `NDArray`).
- Implements a modern version of the Unified Packed and Object RFC, where `Any` can store both POD types (int, float, bool) and reference-counted objects in a single 16-byte tagged union, eliminating the need for boxed primitive types.
- Provides reflection (`ReflectionDef`), error handling (`Error`/`ErrorObj` with cross-language traceback), global function registry (`TVM_FFI_REGISTER_GLOBAL`), and type traits enabling automatic conversion between C++ types and the `Any` value system.

## Impact
- API: Entirely new C ABI and C++ API surface -- this is the foundational root commit. Not backward compatible with prior TVM FFI ABI. Legacy translation helpers (e.g. `LegacyTVMArgValueToFFIAny`) mentioned in commit message for migration.
- Behavioral: `Any` now holds POD values (int, float) and objects uniformly. `Array<int>` works without boxing. `Map` preserves insertion order. Error handling upgraded to object-based with cross-language traceback.
- Flags/config: `TVM_FFI_USE_LIBBACKTRACE` (default 1), `TVM_FFI_BACKTRACE_ON_SEGFAULT` (default 1), `TVM_FFI_DLL` visibility macro.
- Data formats/schemas: `TVMFFIAny` is the 16-byte wire format for all cross-language values. `TVMFFIObject` is the 16-byte heap object header. Both share the `type_index` prefix for layout compatibility.

## Design Elements
Design elements this commit consumes:
- DLPack (`dlpack.h`): DLTensor, DLManagedTensor, DLDataType, DLDevice used for tensor interop
- C++ STL patterns: `std::optional`, `std::shared_ptr`-like intrusive refcounting, CRTP, type traits, `std::aligned_storage`

Design elements this commit produces:
- **Any/AnyView value system**: 16-byte tagged union that stores POD values and ref-counted object pointers, forming the wire format for all FFI calls
- **Object/ObjectRef/ObjectPtr hierarchy**: Intrusive ref-counted objects with single-inheritance type hierarchy, runtime type checking via ancestor table, and compile-time child-slot optimization
- **Function/FunctionObj packed calling convention**: Dual-path (C safe_call + C++ call) function objects with automatic argument unpacking via TypeTraits
- **Global function registry**: String-keyed global table for cross-language function discovery (`TVM_FFI_REGISTER_GLOBAL`)
- **Type registration and reflection**: Runtime type table with `TVMFFIGetOrAllocTypeIndex`, field-level reflection via `ReflectionDef`/`TVMFFIFieldInfo` with getter/setter function pointers
- **Container library**: Array (immutable, inline Any elements), Map (insertion-ordered), String, Bytes, Shape, NDArray, Tuple, Variant, Optional
- **Error propagation protocol**: Object-based errors with kind/message/traceback, TLS-based propagation across C ABI boundaries, safe-call macros
- **TypeTraits protocol**: Compile-time specialization interface for converting C++ types to/from Any

## Usage Examples

Registering and calling a global function (C++ -> C++ cross-layer via registry):

```cpp
// Registration (typically at static init time)
TVM_FFI_REGISTER_GLOBAL("mymath.Add")
.set_body_typed([](int a, int b) -> int {
  return a + b;
});

// Lookup and call
Function f = Function::GetGlobalRequired("mymath.Add");
int result = f(3, 4).cast<int>();  // result == 7
```

Defining a custom object with reflection:

```cpp
class MyNodeObj : public Object {
 public:
  String name;
  int64_t value;
  static constexpr const char* _type_key = "test.MyNode";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyNodeObj, Object);
};

class MyNode : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(MyNode, ObjectRef, MyNodeObj);
};

// Register reflection fields
TVM_FFI_REFLECTION_DEF(MyNodeObj)
  .def_readwrite("name", &MyNodeObj::name)
  .def_readonly("value", &MyNodeObj::value);

// Create an instance
auto node = make_object<MyNodeObj>();
node->name = String("hello");
node->value = 42;
```

Using Any as a universal value container:

```cpp
Any val = 42;                       // stores int64 inline
Any str_val = String("hello");      // stores ref-counted String
int x = val.cast<int>();            // extracts int
String s = str_val.cast<String>();  // extracts String
Array<int> arr({1, 2, 3});          // Array<int> works directly, no boxing
```
