# Introduce and modernize the TVM FFI system with unified packed function and object model

## TL;DR
- Root commit introducing the entire TVM FFI module: a stable C ABI layer, C++17 type-erased value system (`Any`/`AnyView`), ref-counted object hierarchy (`Object`/`ObjectRef`), packed function calling convention (`Function`), and generic containers (`Array`, `Map`, `Shape`, `Tuple`, `Variant`, `NDArray`).
- Implements the "Unified Packed and Object RFC" -- `Any` can hold both POD types (int, float, bool) and object references, enabling `Array<int>` without boxing.
- Provides object-based error handling with cross-language traceback, insertion-order-preserving `Map`, runtime type reflection, and a CMake/GoogleTest build system with 17 test suites.

## Key Exports

### C ABI (`include/tvm/ffi/c_api.h`)

**Enum `TVMFFITypeIndex`**: discriminator for the type-erased value system.
- POD range `[0, 64)`: `kTVMFFINone=0`, `kTVMFFIInt=1`, `kTVMFFIBool=2`, `kTVMFFIFloat=3`, `kTVMFFIOpaquePtr=4`, `kTVMFFIDataType=5`, `kTVMFFIDevice=6`, `kTVMFFIDLTensorPtr=7`, `kTVMFFIRawStr=8`, `kTVMFFIByteArrayPtr=9`, `kTVMFFIObjectRValueRef=10`.
- Static object range `[64, 128)`: `kTVMFFIObject=64`, `kTVMFFIStr=65`, `kTVMFFIBytes=66`, `kTVMFFIError=67`, `kTVMFFIFunction=68`, `kTVMFFIArray=69`, `kTVMFFIMap=70`, `kTVMFFIShape=71`, `kTVMFFINDArray=72`, `kTVMFFIModule=73`.
- Dynamic range `[128, +inf)`: `kTVMFFIDynObjectBegin=128`.

**Struct `TVMFFIObject`**: 16-byte object header `{ int32_t type_index; int32_t ref_counter; void(*deleter)(TVMFFIObject*) }`.

**Struct `TVMFFIAny`**: 16-byte type-erased value `{ int32_t type_index; int32_t small_len; union { int64_t, double, void*, const char*, TVMFFIObject*, DLDataType, DLDevice, char[8] } }`.

**Type `TVMFFISafeCallType`**: `int (*)(void* self, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result)`. Return codes: 0=success, -1=error in TLS, -2=frontend error.

**Struct `TVMFFITypeInfo`**: runtime type info `{ int32_t type_index, type_depth; TVMFFIByteArray type_key; uint64_t type_key_hash; const int32_t* type_acenstors; int32_t num_fields, num_methods; TVMFFIFieldInfo* fields; TVMFFIMethodInfo* methods }`.

**Struct `TVMFFIFieldInfo`**: reflection field descriptor `{ TVMFFIByteArray name; int32_t field_static_type_index; int32_t readonly; int64_t byte_offset; TVMFFIFieldGetter getter; TVMFFIFieldSetter setter }`.

### C++ Core Types (`tvm::ffi`)

**`AnyView`** (non-owning type-erased view): `reset()`, `swap()`, `type_index()`, `as<T>() -> optional<T>`, `cast<T>() -> T`, `GetTypeKey()`.

**`Any`** (owning type-erased value): same API as `AnyView` plus ownership semantics (IncRef on copy, DecRef on destroy). `sizeof(Any) == sizeof(TVMFFIAny) == 16`. Convertible to/from `AnyView` at zero cost.

**`Object`** (ref-counted base): `IsInstance<T>()`, `type_index()`, `GetTypeKey()`, `use_count()`, `unique()`. Static fields: `_type_key`, `_type_index`, `_type_final`, `_type_child_slots`, `_type_depth`.

**`ObjectPtr<T>`** (intrusive smart pointer): `get()`, `reset()`, `use_count()`, `unique()`, `swap()`.

**`ObjectRef`** (handle wrapper): `defined()`, `get()`, `same_as()`, `as<ObjectType>()`, `as<ObjectRefType>()`, `type_index()`, `GetTypeKey()`.

**`Function`** (type-erased callable): `operator()(Args...) -> Any`, `CallPacked(args, num_args, result)`. Static: `FromPacked(callable)`, `FromUnpacked(callable)`, `FromExternC(self, safe_call, deleter)`, `ImportFromExternDLL(other)`, `GetGlobal(name)`, `GetGlobalRequired(name)`, `SetGlobal(name, func)`, `ListGlobalNames()`, `RemoveGlobal(name)`.

**`TypedFunction<R(Args...)>`**: compile-time typed wrapper around `Function`.

**`Function::Registry`**: builder for registering global functions via `set_body_typed(f)`, `set_body_packed(f)`, `set_body_method(&T::method)`.

**`Error`** (`ObjectRef` + `std::exception`): `kind()`, `message()`, `traceback()`, `what()`, `UpdateTraceback()`.

**`String`** (`ObjectRef`): `std::string_view`-compatible, backed by `StringObj : BytesObjBase : Object + TVMFFIByteArray`.

**`Bytes`** (`ObjectRef`): raw byte container, backed by `BytesObj : BytesObjBase`.

### Type Traits System (`TypeTraits<T>`)

Protocol methods every specialization must provide:
- `CopyToAnyView(const T&, TVMFFIAny*)` -- non-owning store
- `MoveToAny(T, TVMFFIAny*)` -- owning store
- `CheckAnyStorage(const TVMFFIAny*)` -- exact type match
- `CopyFromAnyStorageAfterCheck(const TVMFFIAny*)` -- extract without ownership transfer
- `MoveFromAnyStorageAfterCheck(TVMFFIAny*)` -- extract with ownership transfer
- `TryConvertFromAnyView(const TVMFFIAny*) -> optional<T>` -- with coercion
- `TypeStr() -> string`

Specializations provided for: `nullptr_t`, `bool`, `StrictBool`, all integral types, all floating-point types, `void*`, `DLDevice`, `DLTensor*`, `DLDataType`, `const char*`, `std::string`, `std::string_view`, all `ObjectRef` subtypes (via `ObjectRefTypeTraitsBase<T>`), `Optional<T>`, `TypedFunction<FType>`.

Helper bases: `TypeTraitsBase`, `ObjectRefTypeTraitsBase<T>`, `FallbackOnlyTraitsBase<T, FallbackTypes...>`, `ObjectRefWithFallbackTraitsBase<T, FallbackTypes...>`.

### Memory Allocation

- `make_object<T>(args...) -> ObjectPtr<T>` -- allocate via `SimpleObjAllocator`, sets `ref_counter=1`, `type_index`, and type-specific deleter.
- `make_inplace_array_object<ArrayType, ElemType>(num_elems, args...) -> ObjectPtr<ArrayType>` -- allocate array + trailing elements in a single allocation.

### Reflection (`tvm::ffi::details`)

- `ReflectionDef`: builder with `def_readonly(name, &Class::field)` and `def_readwrite(name, &Class::field)`. Registers `TVMFFIFieldInfo` via `TVMFFIRegisterTypeField`.
- `ReflectionFieldGetter`: callable wrapper `(const Object*) -> Any` using stored `TVMFFIFieldInfo*`.

### IsInstance Fast Path

`details::IsObjectInstance<TargetType>(type_index)` uses:
1. For final types: direct index equality.
2. For non-final with `_type_child_slots > 0`: range check `[target_index, target_index + child_slots + 1)`.
3. Fallback: ancestor table lookup at `type_info->type_acenstors[depth]`.

## Impact
- API: Entirely new stable C ABI -- all symbols prefixed `TVMFFI*`. Not backward compatible with prior TVM packed function ABI.
- Behavioral: `Any` unifies POD and object storage (previously separate `TVMValue`+`type_code`). `Map` now preserves insertion order. Error handling is object-based rather than string-based.
- Flags/config: `TVM_FFI_USE_LIBBACKTRACE`, `TVM_FFI_BACKTRACE_ON_SEGFAULT`, `TVM_FFI_DEBUG_WITH_ABI_CHANGE` compile-time flags.
- Data formats/schemas: `TVMFFIAny` is a 16-byte struct (4-byte type_index + 4-byte small_len + 8-byte union). `TVMFFIObject` is a 16-byte header (4+4+8). These are the foundational ABI types.

## Design Elements

Design elements this commit consumes:
- **DLPack** (`dlpack/dlpack.h`): `DLTensor`, `DLManagedTensor`, `DLManagedTensorVersioned`, `DLDataType`, `DLDevice`, `DLDeviceType`. Used as the tensor interchange format.

Design elements this commit produces:
- **C ABI layer** (`c_api.h`): stable C function exports, `TVMFFITypeIndex` enum, `TVMFFIObject`/`TVMFFIAny` struct layouts.
- **Any/AnyView value system** (`any.h`, `type_traits.h`): type-erased value containers with trait-based conversion protocol.
- **Object system** (`object.h`, `memory.h`): intrusive ref-counted objects with `ObjectPtr<T>`/`ObjectRef`, runtime type hierarchy with fast `IsInstance`, `make_object<T>`.
- **Function system** (`function.h`): `FunctionObj` with dual calling convention (`call` for C++, `safe_call` for C ABI), `Function::Registry`, `TVM_FFI_REGISTER_GLOBAL`.
- **Error system** (`error.h`): object-based errors with kind/message/traceback, TLS-based error propagation across C ABI boundary, `TVM_FFI_THROW`.
- **String/Bytes** (`string.h`): `StringObj`/`BytesObj` with inplace allocation optimization, `std::string_view`-compatible `String`.
- **Containers** (`container/*.h`): `Array<T>` (COW inplace array), `Map<K,V>` (insertion-order dense hashmap), `Shape`, `NDArray`, `Tuple`, `Variant<V...>`.
- **Reflection** (`reflection/reflection.h`): field registration via `ReflectionDef`, getter/setter accessors, `TVM_FFI_REFLECTION_DEF`.
- **TypeTraits protocol** (`type_traits.h`): extensible conversion protocol between C++ types and `Any`, with `ObjectRefTypeTraitsBase`, `FallbackOnlyTraitsBase`, `ObjectRefWithFallbackTraitsBase`.

## Usage Examples

### Defining and using an Object type

```cpp
// Define object (data class)
class TIntObj : public Object {
 public:
  int64_t value;
  TIntObj(int64_t value) : value(value) {}
  static constexpr const char* _type_key = "test.Int";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TIntObj, Object);
};

// Define ref wrapper
class TInt : public ObjectRef {
 public:
  TVM_FFI_DEFINE_OBJECT_REF_METHODS(TInt, ObjectRef, TIntObj);
};

// Allocate and use
ObjectPtr<TIntObj> ptr = make_object<TIntObj>(42);
TInt ref(ptr);
assert(ref->value == 42);
assert(ref->IsInstance<TIntObj>());
```

### Registering and calling a global function

```cpp
// Registration
TVM_FFI_REGISTER_GLOBAL("testing.add")
.set_body_typed([](int a, int b) -> int { return a + b; });

// Retrieval and call
Function f = Function::GetGlobalRequired("testing.add");
int result = f(1, 2).cast<int>();  // result == 3
```

### Using Any as a type-erased value

```cpp
Any val = 42;                       // stores int
assert(val.cast<int>() == 42);
val = String("hello");              // stores String object
assert(val.cast<String>() == "hello");
auto opt = val.as<int>();           // returns nullopt (type mismatch)
assert(!opt.has_value());
```

### Reflection field access

```cpp
TVM_FFI_REFLECTION_DEF(TIntObj)
  .def_readonly("value", &TIntObj::value);

// Access field by name at runtime
auto info = details::GetReflectionFieldInfo("test.Int", "value");
details::ReflectionFieldGetter getter(info);
Any result = getter(int_obj.get());
```
