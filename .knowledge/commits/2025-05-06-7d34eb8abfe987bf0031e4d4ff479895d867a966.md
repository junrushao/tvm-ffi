# Introduce TVM FFI — a clean, stable ABI with Any/AnyView, Object, Function, and container system

## TL;DR

- Introduces the entire `tvm/ffi` module from scratch: a modern, minimal C ABI (`c_api.h`) plus C++17 headers implementing `AnyView`/`Any` (type-erased values), `Object`/`ObjectRef` (ref-counted heap objects), `Function` (packed callable), and a container library (`Array`, `Map`, `String`, `Shape`, `NDArray`, `Tuple`, `Variant`).
- Implements a unified packed-function and object type system based on the [RFC #0097](https://github.com/apache/tvm-rfcs/blob/main/rfcs/0097-unify-packed-and-object.md); `Any` now holds both POD values (int, float) and object references, eliminating the need for boxed container elements.
- ABI is intentionally incompatible with the prior TVM packed-func ABI; includes a legacy translation helper `LegacyTVMArgValueToFFIAny` and explicit `kTVMFFIDynObjectBegin = 128` boundary for dynamic type allocation.

## Key Exports

```python
# ---- C ABI (c_api.h) ----
# Wire-stable structs shared by all language bindings

class TVMFFITypeIndex(IntEnum):
    kTVMFFINone = 0          # null / None
    kTVMFFIInt = 1
    kTVMFFIBool = 2
    kTVMFFIFloat = 3
    kTVMFFIOpaquePtr = 4
    kTVMFFIDataType = 5
    kTVMFFIDevice = 6
    kTVMFFIDLTensorPtr = 7
    kTVMFFIRawStr = 8        # AnyView only — not owning
    kTVMFFIByteArrayPtr = 9
    kTVMFFIObjectRValueRef = 10
    kTVMFFIStaticObjectBegin = 64   # kTVMFFIObject..kTVMFFIModule live here
    kTVMFFIObject = 64
    kTVMFFIStr = 65
    kTVMFFIBytes = 66
    kTVMFFIError = 67
    kTVMFFIFunction = 68
    kTVMFFIArray = 69
    kTVMFFIMap = 70
    kTVMFFIShape = 71
    kTVMFFINDArray = 72
    kTVMFFIModule = 73
    kTVMFFIDynObjectBegin = 128     # Invariant: runtime-allocated type indices start here

class TVMFFIObject:              # C struct
    type_index: int32_t          # shared prefix with TVMFFIAny
    ref_counter: int32_t
    deleter: Callable[[TVMFFIObject*], None]  # set by make_object<T>

class TVMFFIAny:                 # C struct — 16 bytes on all platforms
    type_index: int32_t
    small_len: int32_t           # reserved for compact small-string future opt
    # union (8 bytes): v_int64, v_float64, v_ptr, v_c_str, v_obj, v_dtype, v_device

# Invariant: Any::type_index is NEVER kTVMFFIRawStr; AnyView may be.
# Invariant: fields {type_index, v_int64} are always zeroed when None.

# C ABI exported functions (DLL boundary)
def TVMFFIObjectFree(obj: TVMFFIObjectHandle) -> int: ...
def TVMFFIFunctionCreate(self, safe_call, deleter, out) -> int: ...
def TVMFFIFunctionCall(func, args: TVMFFIAny*, num_args, result: TVMFFIAny*) -> int: ...
def TVMFFIFunctionSetGlobal(name: TVMFFIByteArray*, f: TVMFFIObjectHandle, override: int) -> int: ...
def TVMFFIFunctionGetGlobal(name: TVMFFIByteArray*, out: TVMFFIObjectHandle*) -> int: ...
def TVMFFIErrorMoveFromRaised(result: TVMFFIObjectHandle*) -> None: ...
def TVMFFIErrorSetRaised(error: TVMFFIObjectHandle) -> None: ...
def TVMFFIGetTypeInfo(type_index: int32_t) -> TVMFFITypeInfo*: ...
def TVMFFIRegisterTypeField(type_index: int32_t, info: TVMFFIFieldInfo*) -> int: ...
def TVMFFINDArrayFromDLPack(from_: DLManagedTensor*, ..., out) -> int: ...

# ---- C++ API ----

class AnyView:
    """Non-owning type-erased value. Backed by TVMFFIAny. Copy-trivial."""
    data_: TVMFFIAny             # protected

    def reset(self) -> None: ...
    def type_index(self) -> int32_t: ...
    def as(self, T) -> Optional[T]: ...   # TypeTraits<T>::TryConvertFromAnyView
    def cast(self, T) -> T: ...           # raises TypeError on mismatch
    def GetTypeKey(self) -> str: ...
    # Interacts with: TypeTraits<T> (conversion dispatch), Any (ownership promotion)
    # Invariant: type_index==kTVMFFIRawStr is allowed; v_int64==0 when None

class Any(AnyView):
    """Owning type-erased value. Promoted from AnyView via InplaceConvertAnyViewToAny."""
    # Interacts with: ObjectPtr<T> (IncRef/DecRef on assign), String/Bytes (auto-box RawStr)
    # Invariant: Any::type_index is NEVER kTVMFFIRawStr after construction
    # Invariant: kTVMFFIObjectRValueRef is consumed exactly once (move-from)

class Object:
    """Base for all ref-counted heap objects. Header == TVMFFIObject."""
    header_: TVMFFIObject

    def IsInstance(self, TargetType) -> bool: ...   # fast slot check + table fallback
    def type_index(self) -> int32_t: ...
    def use_count(self) -> int32_t: ...
    def GetTypeKey(self) -> str: ...

    # Static class-level constants subclasses MUST define:
    # _type_key: str, _type_index: int32_t, _type_final: bool
    # _type_child_slots: int, _type_child_slots_can_overflow: bool
    # Interacts with: ObjectPtr<T> (IncRef/DecRef), make_object<T>() (sets deleter+type_index)
    # Extension: subclass Object, declare TVM_FFI_DECLARE_BASE_OBJECT_INFO or
    #            TVM_FFI_DECLARE_STATIC_OBJECT_INFO, instantiate with make_object<T>()

# Macro expansions (pseudocode):
# TVM_FFI_DECLARE_BASE_OBJECT_INFO(FooObj, ParentObj)
#   → defines RuntimeTypeIndex(), _GetOrAllocRuntimeTypeIndex()
#     with child-slot fast-path check for IsInstance<FooObj>
#
# TVM_FFI_DECLARE_STATIC_OBJECT_INFO(FooObj, ParentObj)
#   → same but type index is compile-time constant (_type_index)

class ObjectRef:
    """RAII smart-pointer wrapper for Object subclasses."""
    data_: ObjectPtr[Object]

    # TVM_FFI_DEFINE_OBJECT_REF_METHODS(Foo, ParentRef, FooObj) generates:
    #   - default/nullptr constructors
    #   - operator->() returning FooObj*

class FunctionObj(Object):
    """Object container backing ffi::Function. Layout: TVMFFIObject + TVMFFIFunctionCell."""
    safe_call: TVMFFISafeCallType     # C ABI safe call (catches exceptions → return -1/-2)
    call: Callable[[FunctionObj*, AnyView*, int32_t, Any*], None]  # C++ style call
    # Interacts with: TVM_FFI_SAFE_CALL_BEGIN/END macros, EnvErrorAlreadySet

class Function(ObjectRef):
    """Type-erased callable. Wraps FunctionObj."""

    @staticmethod
    def FromPacked(callable: Callable[[AnyView*, int32_t, Any*], None]) -> Function: ...
    @staticmethod
    def FromPacked(callable: Callable[[PackedArgs, Any*], None]) -> Function: ...
    @staticmethod
    def FromUnpacked(typed_lambda: Callable[..., R]) -> Function: ...
    #   → auto-generates arity check + TypeTraits-based argument unpacking

    def __call__(self, *args) -> Any: ...
    # Interacts with: PackedArgs (arg buffer), Any (result), TypeTraits (unpack)
    # Invariant: result->type_index must be < kTVMFFIStaticObjectBegin on entry

    @staticmethod
    def Registry(name: str) -> FunctionRegistry: ...
    # Global registry — string-keyed, accessible cross-language via C ABI

# Macro expansion:
# TVM_FFI_REGISTER_GLOBAL("op.name")
# .set_body_typed(fn)
# → static variable = Function::Registry("op.name").set_body_typed(fn)
# Interacts with: TVMFFIFunctionSetGlobal (C ABI), global name registry

class TypedFunction(Generic[R, *Args]):
    """Statically typed wrapper over Function. Auto-unpacks args via TypeTraits."""
    packed_: Function

    def __call__(self, *args: Args) -> R: ...
    # Interacts with: Function (unpack dispatch), TypeTraits<T> (conversion)

class PackedArgs:
    """Read-only view over a contiguous AnyView array passed into a packed call."""
    data_: AnyView*
    size_: int32_t

    def __getitem__(self, i: int) -> AnyView: ...
    def Slice(self, begin: int, end: int = -1) -> PackedArgs: ...
    @staticmethod
    def Fill(data: AnyView*, *args) -> None: ...

class ErrorObj(Object):
    """Object-based error. Layout: TVMFFIObject + TVMFFIErrorCell."""
    kind: TVMFFIByteArray           # error kind string (e.g., "TypeError")
    message: TVMFFIByteArray
    traceback: TVMFFIByteArray
    update_traceback: Callable      # in-place traceback enrichment across language boundaries
    # Interacts with: TVMFFIErrorSetRaised/MoveFromRaised (TLS error slot),
    #                 TVM_FFI_SAFE_CALL_END (catch + serialize), EnvErrorAlreadySet

# Error throw macro:
# TVM_FFI_THROW(TypeError) << "message"
# → constructs Error("TypeError", stream.str(), traceback), throws

class ReflectionDef:
    """Builder for registering field accessors for an Object subtype."""
    type_index_: int32_t

    def def_readonly(self, name: str, field_ptr: T Class::*) -> ReflectionDef: ...
    def def_readwrite(self, name: str, field_ptr: T Class::*) -> ReflectionDef: ...
    # Interacts with: TVMFFIRegisterTypeField (C ABI), TVMFFIFieldInfo, TypeTraits getter/setter
    # Invariant: byte offset computed relative to Object header, not subclass start

class TypeTraits(Generic[T]):
    """Type conversion protocol for Any/AnyView. Specialized per type T."""
    convert_enabled: bool   # guards AnyView constructors/operator=
    storage_enabled: bool   # guards container element storage

    @staticmethod
    def CopyToAnyView(value: T, out: TVMFFIAny*) -> None: ...
    @staticmethod
    def TryConvertFromAnyView(data: TVMFFIAny*) -> Optional[T]: ...
    @staticmethod
    def GetMismatchTypeInfo(data: TVMFFIAny*) -> str: ...
    @staticmethod
    def TypeStr() -> str: ...
    # Extension: specialize TypeTraits<MyType> to make MyType usable in Any/Function args

# Container types (all ObjectRef subclasses):
# Array[T]       — immutable, O(1) indexed, T must have storage_enabled TypeTraits
# Map[K,V]       — insertion-ordered hash map
# String         — ObjectRef wrapping TVMFFIByteArray; kTVMFFIStr type index
# Bytes          — ObjectRef wrapping TVMFFIByteArray; kTVMFFIBytes type index
# Shape          — ObjectRef wrapping int64_t* span; kTVMFFIShape type index
# NDArray        — ObjectRef wrapping DLTensor; kTVMFFINDArray; DLPack interop
# Tuple          — fixed-size heterogeneous sequence of Any
# Variant[T...]  — compile-time union of object types

# plus 15 additional internal/detail types (ObjectPtr, FunctionObjImpl, etc.)
```

## Impact

- API: Entirely new API surface — no prior API existed in this repo. All downstream consumers must use the new conventions.
- Behavioral: `Any` can hold int/float/bool directly (no boxing). `Map` preserves insertion order. Error objects carry structured `{kind, message, traceback}` instead of plain strings. `kTVMFFIRawStr` cannot appear in owned `Any`, only in `AnyView`.
- Flags/config: CMake options `TVM_FFI_BUILD_REGISTRY` (dynamic type index allocation), `TVM_FFI_USE_LIBBACKTRACE`, `TVM_FFI_BACKTRACE_ON_SEGFAULT`.
- Data formats/schemas: Binary ABI defined by `TVMFFIObject` (12-byte header + pointer-sized deleter), `TVMFFIAny` (16 bytes), `TVMFFIByteArray` (pointer + size_t, platform-varying). Static type indices 64–127 are reserved; dynamic indices start at 128.

## Design Elements

Design elements this commit consumes:
- DLPack (via vendored `3rdparty/dlpack`) — used for `TVMFFIDLTensorPtr`, `NDArray` interop, `DLDataType`, `DLDevice`

Design elements this commit produces:
- **Any/AnyView type system** — `TVMFFIAny` C struct, `AnyView` (non-owning), `Any` (owning), `TypeTraits<T>` specialization protocol (`include/tvm/ffi/any.h`, `include/tvm/ffi/type_traits.h`)
- **Object system** — `TVMFFIObject` C struct, `Object` base class, `ObjectPtr<T>` smart pointer, `ObjectRef` RAII wrapper, `make_object<T>()`, `IsInstance<T>()` with fast slot + table fallback (`include/tvm/ffi/object.h`, `src/ffi/object.cc`)
- **Function system** — `FunctionObj`, `Function`, `TypedFunction<R(Args...)>`, `PackedArgs`, `TVM_FFI_REGISTER_GLOBAL` macro, global string-keyed registry (`include/tvm/ffi/function.h`, `src/ffi/function.cc`)
- **Error system** — `ErrorObj`, `Error` (C++ exception), `EnvErrorAlreadySet`, `TVM_FFI_THROW`, `TVM_FFI_SAFE_CALL_BEGIN/END`, TLS error slot (`include/tvm/ffi/error.h`, `src/ffi/error.cc`)
- **C ABI** — `TVMFFITypeIndex` enum, all `TVMFFIDll` exported functions, wire-stable `TVMFFIObject`/`TVMFFIAny`/`TVMFFIByteArray` structs (`include/tvm/ffi/c_api.h`)
- **Reflection** — `ReflectionDef` builder, `TVMFFIFieldInfo`, `TVMFFIRegisterTypeField` C API (`include/tvm/ffi/reflection/reflection.h`)
- **Container library** — `Array`, `Map`, `String`, `Bytes`, `Shape`, `NDArray`, `Tuple`, `Variant` (`include/tvm/ffi/container/`)
- **Traceback** — libbacktrace integration, signal handler on segfault, cross-language traceback enrichment via `ErrorObj::update_traceback` (`src/ffi/traceback.cc`)
- **Build system** — CMake targets `tvm_ffi_header` (interface), `tvm_ffi_objs` (object lib), `tvm_ffi` (shared), `tvm_ffi_static`; options for registry and backtrace

## Usage Examples

**Creating and calling a typed Function (C++):**
```cpp
// Register a globally accessible function
TVM_FFI_REGISTER_GLOBAL("my.add")
.set_body_typed([](int a, int b) -> int { return a + b; });

// Retrieve and call it
Function f = Function::GetGlobal("my.add").value();
Any result = f(3, 4);
int v = result.cast<int>();  // v == 7
```

**Low-level packed call (C++):**
```cpp
Function f = Function::FromPacked([](PackedArgs args, Any* rv) {
    int a = args[0].cast<int>();
    int b = args[1].cast<int>();
    *rv = a + b;
});
Any r = f(3, 4);
```

**Using AnyView and Any (C++):**
```cpp
AnyView view = 42;          // POD int, no alloc
Any owned = view;           // InplaceConvertAnyViewToAny: kRawStr -> String object
int v = view.cast<int>();   // TypeTraits<int>::TryConvertFromAnyView
```

**Cross-layer: C ABI call from a non-C++ binding (pseudocode):**
```c
TVMFFIAny args[2] = {{kTVMFFIInt,0,{.v_int64=3}}, {kTVMFFIInt,0,{.v_int64=4}}};
TVMFFIAny result = {kTVMFFINone, 0, {.v_int64=0}};  // must pre-zero result
TVMFFIObjectHandle func_handle;
TVMFFIFunctionGetGlobal(&name_bytes, &func_handle);
TVMFFIFunctionCall(func_handle, args, 2, &result);
// result.type_index == kTVMFFIInt, result.v_int64 == 7
TVMFFIObjectFree(func_handle);
```
