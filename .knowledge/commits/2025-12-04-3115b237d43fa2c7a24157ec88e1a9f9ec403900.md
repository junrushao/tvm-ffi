# Add kwargs wrapping utility via code generation for positional-only callables
## TL;DR
- Introduces `make_kwargs_wrapper` and `make_kwargs_wrapper_from_signature` in `tvm_ffi.utils.kwargs_wrapper`, which dynamically generate Python wrapper functions that add keyword-argument support to positional-only callables via `exec()`-based code generation.
- Uses a `MISSING` sentinel pattern and carefully scoped code generation (no untrusted input in generated code) to handle default values safely, directly embedding only `None` and `bool` literals.
- Includes comprehensive tests (321 LOC) and a benchmark script for measuring overhead.

## Design Elements
Design elements this commit consumes:
- Python `exec()`-based code generation pattern (same approach used by stdlib `dataclasses` and `pydantic`). Related: [0016-ffi-python-dataclasses](../design-records/0016-ffi-python-dataclasses.md) uses the same `exec()` code-gen pattern for `__init__` generation.
- `functools.update_wrapper` for metadata propagation.
- `inspect.Signature` / `inspect.Parameter` for signature introspection.

Design elements this commit produces:
- **`MISSING` sentinel protocol**: a module-level `object()` sentinel used to distinguish "argument not passed" from any real default value, enabling safe code generation without embedding arbitrary `repr()` in generated source.
- **`make_kwargs_wrapper` code generation pattern**: generates a wrapper function body as a string, executes it with a controlled `exec_globals` namespace containing only the target function, the MISSING sentinel, and a runtime_defaults dict. This isolates untrusted values from generated code text.
- **Safe default embedding rules**: `None` and `bool` (exact type, not subclass) are inlined directly into generated signatures; all other types use the MISSING sentinel indirection. This is a deliberate safety/performance tradeoff.

## Usage Examples
Wrapping a positional-only FFI function with keyword argument support:

```python
from tvm_ffi.utils.kwargs_wrapper import make_kwargs_wrapper

# Positional-only target (e.g., a PackedFunc from C++)
def target_func(*args):
    return sum(args)

# Create wrapper with named params and defaults (right-aligned)
wrapper = make_kwargs_wrapper(
    target_func,
    args_names=["x", "y", "z"],
    args_defaults=(10, 20),          # y=10, z=20
    kwargsonly_names=["debug"],
    kwargsonly_defaults={"debug": False},
)

wrapper(1)                   # -> target_func(1, 10, 20, False)
wrapper(1, y=5, debug=True)  # -> target_func(1, 5, 20, True)
```

Using `make_kwargs_wrapper_from_signature` with an existing prototype:

```python
import inspect
from tvm_ffi.utils.kwargs_wrapper import make_kwargs_wrapper_from_signature

def prototype(a: int, b: int, c: int = 10) -> int:
    """Add three numbers."""
    ...

sig = inspect.signature(prototype)
wrapper = make_kwargs_wrapper_from_signature(target_func, sig, prototype)
# wrapper has name="prototype", doc="Add three numbers.", accepts a, b, c=10
```
