# Add kwargs_wrapper utility for wrapping positional-only callables with keyword argument support via code generation
## TL;DR
- Introduces `python/tvm_ffi/utils/kwargs_wrapper.py` with `make_kwargs_wrapper` and `make_kwargs_wrapper_from_signature` — two factories that use `exec()`-generated code to wrap positional-only callables with full kwargs support at low overhead.
- Default values for `None`/`bool` are embedded directly in generated code; all other types use a `MISSING` sentinel passed through `exec_globals` to avoid `__repr__` hazards — the same pattern used by `dataclasses` and `pydantic`.
- Exports the module via `python/tvm_ffi/utils/__init__.py`; adds full pytest test suite and a standalone benchmark script.

    # Invariant: kwargsonly_defaults keys must be a subset of kwargsonly_names

    # Invariant: internal exec_globals keys use "__i_" prefix to prevent collision with user arg names

    # Invariant: signature must not contain VAR_POSITIONAL (*args) or VAR_KEYWORD (**kwargs)

## Usage Examples

Creating a wrapper for a positional-only callable (from `tests/python/utils/test_kwargs_wrapper.py`):

```python
from tvm_ffi.utils.kwargs_wrapper import make_kwargs_wrapper, make_kwargs_wrapper_from_signature
import inspect

def target(*args):
    return sum(args)

# Positional args with right-aligned defaults
wrapper = make_kwargs_wrapper(target, ["a", "b", "c"], args_defaults=(10,))
assert wrapper(1, 2) == 13        # c defaults to 10
assert wrapper(1, 2, c=5) == 8   # c overridden by keyword

# With keyword-only args
wrapper = make_kwargs_wrapper(
    target, ["a", "b"],
    kwargsonly_names=["c", "d"],
    kwargsonly_defaults={"c": 100, "d": 200},
)
assert wrapper(1, 2) == 303           # c=100, d=200
assert wrapper(1, 2, c=10, d=20) == 33

# From an inspect.Signature
sig = inspect.signature(lambda a, b, c=10: None)
wrapper2 = make_kwargs_wrapper_from_signature(target, sig)
assert wrapper2(1, 2) == 13
```
