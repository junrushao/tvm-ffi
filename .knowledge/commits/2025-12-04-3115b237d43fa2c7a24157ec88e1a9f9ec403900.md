# Add kwargs wrapping utility for positional-only functions via code generation
## TL;DR
- Introduces `tvm_ffi.utils.kwargs_wrapper` module with `make_kwargs_wrapper()` and `make_kwargs_wrapper_from_signature()` that wrap positional-only callables with keyword argument support via `exec()`-based code generation.
- Uses a `MISSING` sentinel for non-trivial defaults (only `None` and `bool` are embedded directly in generated code) to prevent untrusted `repr()` output from reaching `exec()`.
- Includes comprehensive validation of argument names, defaults alignment, and internal name conflicts, plus a benchmark script measuring wrapper overhead.

## Design Elements
Design elements this commit consumes:
- `exec()`-based code generation pattern -- same strategy used by `dataclasses` stdlib, `pydantic`, and the existing `method_init()` in `tvm_ffi/dataclasses/_utils.py` ([0015-python-dataclasses.md](../designs/0015-python-dataclasses.md))
- `functools.update_wrapper` for metadata preservation
- `inspect.Signature` / `inspect.Parameter` for signature introspection

Design elements this commit produces:
- **`MISSING` sentinel** -- identity-compared sentinel for distinguishing "not passed" from explicit `None`. Analogous to `dataclasses.MISSING` but scoped to kwargs_wrapper.
- **`make_kwargs_wrapper()`** -- generic utility for adding kwargs to positional-only callables. Likely intended for use by `c_class`/`py_class` `__init__` generation or for wrapping FFI packed functions with Python-friendly signatures.
- **Safe default embedding policy** -- only `None` and exact `bool` (not subclasses) are embedded as literals in generated code; all other defaults go through the `MISSING` sentinel to avoid `repr()` injection.
- **Reserved internal name convention** -- `__i_` prefix for generated code internals (`__i_target_func`, `__i_MISSING`, `__i_args_defaults`).

## Usage Examples

**Wrapping a positional-only function with keyword argument support:**
```python
from tvm_ffi.utils.kwargs_wrapper import make_kwargs_wrapper

def target(*args):
    return sum(args)

# Right-aligned defaults: c=10, d=20
wrapper = make_kwargs_wrapper(target, ["a", "b", "c", "d"], args_defaults=(10, 20))
wrapper(1, 2)          # -> 33  (a=1, b=2, c=10, d=20)
wrapper(1, 2, c=5)     # -> 28  (a=1, b=2, c=5, d=20)
```

**Using keyword-only arguments with required and optional params:**
```python
wrapper = make_kwargs_wrapper(
    target,
    ["a", "b"],
    kwargsonly_names=["c", "d"],
    kwargsonly_defaults={"d": 100},  # c is required, d defaults to 100
)
wrapper(1, 2, c=10)         # -> 113  (a=1, b=2, c=10, d=100)
wrapper(1, 2, c=10, d=20)   # -> 33
```

**From an `inspect.Signature` (e.g. mirroring another function's signature):**
```python
import inspect
from tvm_ffi.utils.kwargs_wrapper import make_kwargs_wrapper_from_signature

def source_func(a, b, c=10, *, d=20):
    """Documented function."""
    pass

sig = inspect.signature(source_func)
wrapper = make_kwargs_wrapper_from_signature(target, sig, prototype_func=source_func)
assert wrapper.__name__ == "source_func"
assert wrapper.__doc__ == "Documented function."
```
