# Add kwargs_wrapper utility for wrapping positional-only functions with keyword argument support via codegen
## TL;DR
- Introduces `tvm_ffi.utils.kwargs_wrapper` module with `make_kwargs_wrapper` and `make_kwargs_wrapper_from_signature` functions that dynamically generate Python wrapper functions via `exec`-based code generation.
- The generated wrappers add keyword argument support (including keyword-only args with defaults) to positional-only callables (like FFI packed functions), following the same safe codegen pattern used by `dataclasses` and `pydantic`.
- Uses a `MISSING` sentinel for non-trivial defaults to avoid embedding arbitrary `repr()` output in generated code; only `None` and `bool` defaults are inlined directly.

## Key Exports

**Module**: `tvm_ffi.utils.kwargs_wrapper`

**Functions**:
- `make_kwargs_wrapper(target_func, args_names, args_defaults=(), kwargsonly_names=None, kwargsonly_defaults=None, prototype_func=None) -> Callable` -- Creates a codegen'd wrapper around `target_func` with the specified positional and keyword-only parameter signature.
- `make_kwargs_wrapper_from_signature(target_func, signature: inspect.Signature, prototype_func=None) -> Callable` -- Convenience wrapper that extracts `args_names`, `args_defaults`, `kwargsonly_names`, `kwargsonly_defaults` from an `inspect.Signature` object and delegates to `make_kwargs_wrapper`.

**Constants**:
- `MISSING` -- Sentinel object used to distinguish "argument not passed" from "argument passed as None" in generated code.

**Internal helpers** (not exported but part of the codegen contract):
- `_validate_argument_names(names, arg_type)` -- Validates names are valid Python identifiers and unique.
- `_validate_wrapper_args(...)` -- Validates no overlaps between positional/keyword args, no conflicts with internal names (`__i_target_func`, `__i_MISSING`, `__i_args_defaults`).

## Design Elements
Design elements this commit consumes:
- **Python package utils** ([0014-python-package.md](../designs/0014-python-package.md)): Adds a new submodule under `tvm_ffi.utils`.

Design elements this commit produces:
- **kwargs_wrapper codegen pattern**: A safe code generation pattern for wrapping positional-only FFI functions with Python keyword argument support. Key design decisions:
  - Only `None` and `bool` (exact type, not subclass) default values are inlined in generated code text.
  - All other defaults use a `MISSING` sentinel and are passed through a runtime dictionary, avoiding untrusted `repr()` injection.
  - Argument names are validated as valid Python identifiers.
  - Internal names use `__i_` prefix to avoid collision with user argument names.
  - Supports both `args_defaults` (right-aligned, matching Python `__defaults__`) and `kwargsonly_defaults` (dict, matching Python `__kwdefaults__`).

## Usage Examples
```python
from tvm_ffi.utils.kwargs_wrapper import make_kwargs_wrapper

def positional_only_fn(a, b, c):
    return a + b + c

# Wrap with keyword argument support and defaults
wrapped = make_kwargs_wrapper(
    positional_only_fn,
    args_names=["a", "b", "c"],
    args_defaults=(10, 20),  # b=10, c=20
)
wrapped(1)           # => 31 (a=1, b=10, c=20)
wrapped(1, b=5)      # => 26 (a=1, b=5, c=20)
wrapped(1, 2, c=3)   # => 6
```
