# Revert generalized for_each, restore Arg2Str for function signature formatting
## TL;DR
- Reverts PR #18117 (commit ad328f5), which replaced `Arg2Str` with a more powerful `for_each` supporting three invocation styles (constexpr index, runtime index, argument-only).
- Restores the simpler `Arg2Str<ArgType>` struct in `function_details.h` for formatting function signatures, and simplifies `for_each_dispatcher::run` back to a single calling convention `F(size_t, Arg)`.
- Removes the `always_false<T>` helper and the `#include <type_traits>` from `base_details.h`.

## Key Exports

**Restored struct** `details::Arg2Str<ArgType>` (in `include/tvm/ffi/function_details.h`):
```cpp
template <typename ArgType>
struct Arg2Str {
  template <size_t i>
  static void Apply(std::ostream& os);   // formats "i: TypeStr" with leading comma if i!=0
  template <size_t... I>
  static void Run(std::ostream& os, std::index_sequence<I...>);  // expands Apply for each index
};
```

**Simplified** `details::for_each_dispatcher::run` (in `include/tvm/ffi/base_details.h`):
```cpp
// Before (reverted): SFINAE dispatch across 3 invocation styles
// After (restored): single calling convention only
static void run(std::index_sequence<I...>, const F& f, Args&&... args) {
  (f(I, std::forward<Args>(args)), ...);
}
```

**Removed** `details::always_false<T>` — dependent-name false variable template used in the reverted static_assert.

## Impact
- API: None. All changes are in `details` namespace (internal). No public header signature changes.
- Behavioral: `for_each` now only supports `F(size_t, Arg)` — code relying on `F(Arg)` or `F(integral_constant, Arg)` overloads will fail to compile.
- Flags/config: None.
- Data formats/schemas: None.
