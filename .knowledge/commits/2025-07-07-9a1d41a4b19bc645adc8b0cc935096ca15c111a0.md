# Revert flexible for_each overload, restore simpler Arg2Str for function signature stringification

## TL;DR
- Reverts PR #18117 (commit ad328f5) which replaced `Arg2Str` with a multi-dispatch `for_each` utility.
- Restores `Arg2Str<ArgType>` template in `function_details.h` for generating function signature strings.
- Simplifies `for_each_dispatcher::run` back to the single calling convention `f(index, arg)`, removing the three-way `std::is_invocable` dispatch and the `always_false` helper.

## Key Exports

```python
# Restored: Arg2Str template (C++ pseudocode as Python)
# Located in: include/tvm/ffi/function_details.h
class Arg2Str(Generic[ArgType]):
    """Formats function argument types as 'index: TypeName' strings for signature display."""
    @staticmethod
    def Apply(os: ostream, i: int) -> None: ...
    # Writes "i: TypeName" to the stream, with leading ", " if i != 0
    # Interacts with: Type2Str<Arg>::v() for type name resolution

    @staticmethod
    def Run(os: ostream, idx_seq: IndexSequence) -> None: ...
    # Expands Apply for all indices via C-array fold trick
    # Interacts with: FuncFunctorImpl.Sig()

# Simplified: for_each_dispatcher (C++ pseudocode as Python)
# Located in: include/tvm/ffi/base_details.h
class for_each_dispatcher:
    """Fold-expression iterator over variadic args with index."""
    @staticmethod
    def run(f: Callable[[int, T], None], *args: T) -> None: ...
    # Calls f(i, arg) for each (i, arg) pair
    # Invariant: f must accept (size_t, Arg) — no other overload supported
    # Interacts with: details::for_each() free function wrapper
```

## Impact
- API: None — restores prior public surface. The reverted `for_each` with multi-dispatch was internal-only.
- Behavioral: `for_each` now only supports `f(index, arg)` calling convention. Callers using `f(arg)` or `f(integral_constant, arg)` (introduced by the reverted PR) no longer work, but those callers were introduced in the same reverted PR.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `FuncFunctorImpl::Sig()` — function signature stringification in the FFI function system (related to `0004-ffi-function-system`).
- `Type2Str<T>::v()` — compile-time type-to-string mapping used by `Arg2Str`.
- `details::for_each` — variadic fold utility in `base_details.h`.

Design elements this commit produces:
- None new — restores the pre-#18117 state of `Arg2Str` and `for_each_dispatcher`.

## Usage Examples

Before (reverted PR #18117 — no longer valid):
```cpp
// for_each supported three calling conventions:
details::for_each(
    [&ss](auto i, const auto& v) {   // integral_constant index
      if constexpr (i() != 0) ss << ", ";
      ss << i() << ": " << v;
    },
    Type2Str<Args>::v()...);
```

After (restored by this revert):
```cpp
// Arg2Str handles signature formatting directly
Arg2Str<std::tuple<Args...>>::Run(ss, std::make_index_sequence<sizeof...(Args)>{});

// for_each only supports f(index, arg)
details::for_each([](size_t i, const auto& arg) { /* use i and arg */ }, args...);
```
