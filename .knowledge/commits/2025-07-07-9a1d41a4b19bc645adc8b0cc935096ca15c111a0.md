# Revert replacement of Arg2Str with multi-convention for_each in function signature generation

## TL;DR

- Reverts commit ad328f5719d3663cc06396f46b53cd815d86e744 (PR #18117) which replaced `Arg2Str` with a more powerful `for_each` capable of three calling conventions (index-free, `size_t` index, `std::integral_constant` index).
- Restores `Arg2Str<ArgType>` template struct in `function_details.h` for generating `FuncFunctorImpl::Sig()` strings.
- Simplifies `for_each_dispatcher::run` back to a single calling convention (`F(size_t, Arg)`), removing the three-branch `if constexpr` dispatch and the `always_false` sentinel.

## Key Exports

```python
# Restored in include/tvm/ffi/function_details.h
class Arg2Str:
    """Converts a tuple of typed Args to a comma-separated argument string '0: T0, 1: T1, ...'."""
    # ArgType: std::tuple<Args...>

    @staticmethod
    def Apply(os: ostream, i: size_t) -> None: ...
    # Invariant: i == 0 suppresses leading ", "
    # Uses: Type2Str<Arg>::v() to get each argument's string representation

    @staticmethod
    def Run(os: ostream, idx_seq: index_sequence) -> None: ...
    # Interacts with: FuncFunctorImpl::Sig() — the sole caller
    # Uses TExpander int[] fold trick (pre-C++17 fold expression workaround)

# Simplified in include/tvm/ffi/base_details.h
class for_each_dispatcher:
    """Calls f(i, arg) for each arg in Args... with a compile-time index."""

    @staticmethod
    def run(idx_seq: index_sequence, f: F, *args: Args) -> None: ...
    # Invariant: F must accept (size_t, Arg) — no other overloads supported after revert
    # Old (reverted): three-branch dispatch: F(integral_constant<size_t,I>, Arg),
    #                 F(size_t, Arg), or F(Arg) — selected via std::conjunction_v + if constexpr

# Removed by this revert:
# always_false<T>: inline constexpr bool always_false = false
# (was used as a dependent-name false for static_assert in the unreachable branch)
```

## Impact

- API: `for_each` callers are now constrained to the `F(size_t, Arg)` signature only; the `F(std::integral_constant, Arg)` and `F(Arg)` overloads no longer compile.
- Behavioral: `FuncFunctorImpl::Sig()` output is unchanged — same string format `"(0: T0, 1: T1) -> R"` is produced by `Arg2Str` as it was before.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- `for_each` / `for_each_dispatcher` in `include/tvm/ffi/base_details.h` — internal compile-time iteration utility
- `FuncFunctorImpl::Sig()` in `include/tvm/ffi/function_details.h` — part of 0004-function-system; produces human-readable function signature strings for diagnostics
- `Type2Str<T>` — consumed by both `Arg2Str` and the reverted `for_each`-based implementation

Design elements this commit produces (restores):
- `Arg2Str<ArgType>` struct in `include/tvm/ffi/function_details.h` — template helper for argument-list string generation; the revert re-establishes this as the sole mechanism for `FuncFunctorImpl::Sig()`

## Usage Examples

**Before (PR #18117 — now reverted):** `for_each` with `std::integral_constant` index used in `Sig()`:

```cpp
for_each(
    [&ss](auto i, const auto& v) {
      if constexpr (i() != 0) { ss << ", "; }
      ss << i() << ": " << v;
    },
    Type2Str<Args>::v()...);
```

**After (restored by this revert):** `Arg2Str` with explicit `TExpander` fold trick:

```cpp
using IdxSeq = std::make_index_sequence<sizeof...(Args)>;
Arg2Str<std::tuple<Args...>>::Run(ss, IdxSeq{});
```

The reverted implementation required `for_each_dispatcher` to support `F(std::integral_constant<size_t, I>, Arg)` so that `i()` could be used in `if constexpr`. The restored implementation avoids that requirement by using compile-time `if constexpr (i != 0)` directly inside a templated `Apply<i>`.
