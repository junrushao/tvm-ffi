# Revert multi-dispatch for_each, restore Arg2Str for function signature generation

## TL;DR
- Reverts commit `ad328f5` (PR #18117), which had replaced the `Arg2Str` template with a multi-dispatch `for_each` for generating function signature strings.
- Restores `Arg2Str<ArgType>` in `function_details.h` and simplifies `for_each_dispatcher::run` back to a single calling convention `F(size_t, Arg)`.
- Removes the `always_false<T>` helper and multi-overload detection logic (`std::conjunction_v`, `std::is_invocable`) from `for_each_dispatcher`.

## Impact
- API: Callers of `for_each` that used `F(std::integral_constant<size_t, I>, Arg)` or `F(Arg)` calling conventions would break. However, these were introduced in the same commit being reverted, so no stable callers exist.
- Behavioral: `FuncFunctorImpl::Sig()` produces identical output -- signature strings like `(0: int, 1: float) -> void` are unchanged.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `details::for_each` / `details::for_each_dispatcher` -- internal variadic iteration utility in `include/tvm/ffi/base_details.h`, used by `PackedArgs::Fill` for packed FFI call arguments. Documented in ledger `2025-07-05-84cfbeb12bc5ef6d9eb434095949c205433c9e35.md`.
- `Type2Str<T>::v()` -- type-to-string conversion, part of the TypeTraits system (see `.knowledge/designs/0006-type-traits.md`).
- `FuncFunctorImpl::Sig()` -- generates human-readable function signatures for error messages, part of the function system (see `.knowledge/designs/0004-function-system.md`).

Design elements this commit produces:
- Restores `Arg2Str<ArgType>` -- a template struct for generating typed argument list strings. This is an internal implementation detail of `FuncFunctorImpl::Sig()`, not a public API.
