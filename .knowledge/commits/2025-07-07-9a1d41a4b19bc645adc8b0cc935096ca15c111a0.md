# Revert enhanced `for_each` dispatcher, restore simpler `Arg2Str` for function signature rendering

## TL;DR
- Reverts PR #18117 which replaced the `Arg2Str` struct with a more powerful `for_each` dispatcher that supported three calling conventions (index+arg, arg-only, constexpr-index+arg).
- Restores the original `Arg2Str` template struct in `function_details.h` for rendering typed function signatures.
- Simplifies `for_each` in `base_details.h` back to the single-form `F(size_t, Arg)` calling convention, removing `always_false`, `<type_traits>` include, and SFINAE dispatch.

## Key Exports

```python
# Restored: Arg2Str — renders function argument types into "i: TypeName" format
# Lives in: include/tvm/ffi/function_details.h
class Arg2Str[ArgType]:  # ArgType is a std::tuple of argument types
    """Renders each argument's index and type name into an ostream."""
    # Interacts with: Type2Str<T>::v() for type name strings
    # Interacts with: FuncFunctorImpl.Sig() — sole caller
    @staticmethod
    def Apply[i](os: ostream) -> None: ...  # writes "i: TypeName"
    @staticmethod
    def Run(os: ostream, idx_seq: index_sequence) -> None: ...

# Simplified: for_each — fold expression over variadic args with index
# Lives in: include/tvm/ffi/base_details.h
def for_each(f: Callable[[int, T], None], *args: T) -> None: ...
    # Invariant: f must accept (size_t, Arg) — the two other forms
    #   (F(Arg) and F(integral_constant<size_t,I>, Arg)) are no longer supported
    # Interacts with: for_each_dispatcher::run (implementation detail)
```

## Impact
- API: Callers of `details::for_each` that relied on the `F(Arg)` (no index) or `F(integral_constant<size_t,I>, Arg)` (constexpr index) forms will fail to compile. Only `F(size_t, Arg)` is supported after this revert.
- Behavioral: Function signature rendering (`FuncFunctorImpl::Sig()`) returns identical output but uses `Arg2Str` with C-style pack expansion instead of `for_each` with fold expressions.
- Flags/config: none
- Data formats/schemas: none
