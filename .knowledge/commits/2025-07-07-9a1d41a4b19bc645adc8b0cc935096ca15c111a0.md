# Revert "[FFI] Replace `Arg2Str` with a more powerful `for_each`" (#18121)

## TL;DR
- Reverts commit ad328f5 (PR #18117), which had enhanced `for_each` in `base_details.h` with three overload modes (`std::integral_constant<size_t, I>`, `size_t`, or no index) and replaced the `Arg2Str` helper in `function_details.h` with a `for_each`-based implementation.
- Restores the simpler `for_each` that only supports `F(size_t, Arg)` and brings back the standalone `Arg2Str` struct for function signature string generation.

## Key Exports

### Restored: `Arg2Str<ArgType>` (`include/tvm/ffi/function_details.h`)
Template struct for generating human-readable function argument type strings. Uses `std::tuple_element_t` and a C-style array expander to iterate over argument types:
- `Apply<i>(os)` -- writes `"i: TypeName"` for argument at position `i`.
- `Run(os, index_sequence)` -- invokes `Apply` for each index.

### Simplified: `for_each_dispatcher::run` (`include/tvm/ffi/base_details.h`)
Reverts to the single-mode fold expression `(f(I, std::forward<Args>(args)), ...)`. The enhanced version with `std::conjunction_v`-based SFINAE dispatching and `always_false` helper is removed.

### Removed
- `always_false<T>` variable template (was in `base_details.h`).
- `#include <type_traits>` from `base_details.h` (no longer needed without `std::conjunction_v`/`std::is_invocable`).

## Impact
- API: Internal-only change (`details` namespace). No public API change.
- ABI: No change. These are header-only template utilities that affect only compile-time code generation.
- Behavioral: `for_each` now only accepts callables with signature `F(size_t, Arg)`. The two alternative invocation modes (`F(Arg)` and `F(std::integral_constant<size_t, I>, Arg)`) are no longer available. `FuncFunctorImpl::Sig()` uses `Arg2Str` again instead of `for_each` with a lambda.

## Design Elements
Design elements this commit consumes:
- `Type2Str<T>::v()` -- Returns the string representation of a C++ type, used by both `Arg2Str` and the reverted `for_each`-based approach.
- `TVM_FFI_INLINE` -- Force-inline attribute macro applied to `Arg2Str` methods.
- `std::tuple_element_t` -- Used by `Arg2Str` to extract argument types from a tuple.

Design elements this commit produces:
- None new. This restores the pre-#18117 design where `for_each` is a simple index+value iterator and `Arg2Str` is a dedicated helper for function signature rendering.

## Usage Examples
No usage change for external consumers. Internally, function signature generation in `FuncFunctorImpl::Sig()` reverts from:
```cpp
for_each(
    [&ss](auto i, const auto& v) {
      if constexpr (i() != 0) { ss << ", "; }
      ss << i() << ": " << v;
    },
    Type2Str<Args>::v()...);
```
back to:
```cpp
using IdxSeq = std::make_index_sequence<sizeof...(Args)>;
Arg2Str<std::tuple<Args...>>::Run(ss, IdxSeq{});
```
