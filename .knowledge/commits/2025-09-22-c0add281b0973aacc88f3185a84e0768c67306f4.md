# Fix device() to use late-bound module attribute lookup for class override
## TL;DR
- Fixed `device()` in `_tensor.py` to reference `core._CLASS_DEVICE` via module attribute lookup instead of an early-bound import, so `_set_class_device()` overrides take effect.
- Added tests for both Device and Tensor class override via `_set_class_device`/`_set_class_tensor`.
- Version bump to `0.1.0b6`.

## Key Exports
```python
# Bug: early-bound import captured _CLASS_DEVICE at import time.
# from .core import _CLASS_DEVICE   # OLD — stale after _set_class_device()
# from . import core                # NEW — late-bound lookup each call

def device(device_type: Union[str, int, DLDeviceType], index: Optional[int] = None) -> Device:
    """Construct a TVM FFI device with given device type and index."""
    # Interacts with: core._CLASS_DEVICE, core._set_class_device()
    # Invariant: must use core._CLASS_DEVICE (module attribute), not a local binding,
    #   so that runtime overrides via _set_class_device() are visible.
    return core._CLASS_DEVICE(device_type, index)
```

## Impact
- API: none — `device()` signature and public behavior unchanged
- Behavioral: `device()` now returns instances of the overridden Device subclass when `_set_class_device()` has been called; previously it always returned the original `Device` class regardless of override
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Python class override protocol** (`core._CLASS_DEVICE`, `core._CLASS_TENSOR`, `core._set_class_device`, `core._set_class_tensor`) — the mechanism by which downstream frameworks (e.g., TVM proper) can substitute custom Device/Tensor subclasses into the FFI layer. Documented partially in design record 0012 (Python Bindings).

Design elements this commit produces:
- None — this is a bugfix restoring intended behavior of an existing protocol.

## Usage Examples
Before/after pattern showing the bug and fix:

```python
# Before this fix: override was silently ignored by device()
class MyDevice(tvm_ffi.Device):
    pass

tvm_ffi.core._set_class_device(MyDevice)
d = tvm_ffi.device("cuda", 0)
assert isinstance(d, MyDevice)  # FAILED — d was plain Device

# After this fix: override is picked up correctly
tvm_ffi.core._set_class_device(MyDevice)
d = tvm_ffi.device("cuda", 0)
assert isinstance(d, MyDevice)  # PASSES
```
