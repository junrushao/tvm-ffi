# Fix stale _CLASS_DEVICE reference in device() factory by using module-level attribute access
## TL;DR
- Fixed `tvm_ffi.device()` ignoring `_set_class_device()` overrides because it captured `_CLASS_DEVICE` at import time rather than reading it at call time.
- Changed `_tensor.py` to access `core._CLASS_DEVICE` via the module reference so overrides are picked up dynamically.
- Added tests for both device and tensor class override patterns (`test_device_class_override`, `test_tensor_class_override`).
- Version bump from `0.1.0b5` to `0.1.0b6`.

## Key Exports
None -- no new public API. The fix changes internal wiring only.

## Impact
- API: none -- `tvm_ffi.device()` signature unchanged.
- Behavioral: `tvm_ffi.device()` now correctly returns instances of the overridden device class after `core._set_class_device(MyDevice)` is called. Previously, it always returned the original `Device` class.
- Flags/config: none.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- **`_CLASS_DEVICE` / `_set_class_device` override pattern** (Cython `device.pxi`): Module-level global `_CLASS_DEVICE` is initially set to `Device`, overridable via `_set_class_device(cls)`. Used by `device()` factory and by Cython return-value construction (`_make_device`). Same pattern exists for `_CLASS_TENSOR` / `_set_class_tensor` in `tensor.pxi`.
- **Python import semantics**: `from module import name` binds the name's *value* at import time into the importing module's namespace; subsequent mutations of the source module's attribute are not reflected. `import module` + `module.name` accesses the attribute at call time, reflecting mutations.

Design elements this commit produces:
- None -- no new design elements. The override pattern already existed; this commit fixes the wiring.

## Usage Examples
**Before (broken):**
```python
class MyDevice(tvm_ffi.Device):
    pass

tvm_ffi.core._set_class_device(MyDevice)
d = tvm_ffi.device("cuda", 0)
assert isinstance(d, MyDevice)  # FAILS -- d is still plain Device
```

**After (fixed):**
```python
class MyDevice(tvm_ffi.Device):
    pass

tvm_ffi.core._set_class_device(MyDevice)
d = tvm_ffi.device("cuda", 0)
assert isinstance(d, MyDevice)  # PASSES -- override picked up at call time
```
