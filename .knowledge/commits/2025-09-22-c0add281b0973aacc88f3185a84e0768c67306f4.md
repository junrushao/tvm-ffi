# Fix device() to respect _CLASS_DEVICE override by using module-level attribute lookup
## TL;DR
- Fixed `tvm_ffi.device()` ignoring `_set_class_device()` overrides because `_tensor.py` captured a stale import-time reference to `_CLASS_DEVICE`.
- Added tests for device class override (`test_device_class_override`) and tensor class override (`test_tensor_class_override`).
- Version bump 0.1.0b5 -> 0.1.0b6.

## Key Exports
None -- this is a bugfix restoring existing behavior, no new API surface.

## Impact
- API: none -- `tvm_ffi.device()` signature unchanged.
- Behavioral: `tvm_ffi.device()` now correctly returns instances of the overridden device class after `_set_class_device()` is called. Previously it always returned the base `Device` class.
- Flags/config: none.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- **`_CLASS_DEVICE` / `_set_class_device()` override protocol** (Cython `device.pxi`): module-level class variable that can be swapped to a user subclass, used by both the Cython layer (for FFI return value construction) and `_tensor.py:device()` (for Python-side construction). Documented in 0012-ffi-python-package design record scope.
- **`_CLASS_TENSOR` / `_set_class_tensor()` override protocol** (Cython `tensor.pxi`): analogous override mechanism for Tensor; tested here but not changed.

Design elements this commit produces: none.

## Usage Examples
**Before (broken)**: `from .core import _CLASS_DEVICE` captured a snapshot at import time. Overrides were invisible:
```python
# _tensor.py (before fix)
from .core import _CLASS_DEVICE  # binds to Device at import time

def device(device_type, index=None):
    return _CLASS_DEVICE(device_type, index)  # always Device, never MyDevice
```

**After (fixed)**: attribute lookup on `core` module at call time picks up override:
```python
# _tensor.py (after fix)
from . import core

def device(device_type, index=None):
    return core._CLASS_DEVICE(device_type, index)  # resolves at call time
```

**Test pattern for verifying override**:
```python
class MyDevice(tvm_ffi.Device):
    pass

old_device = tvm_ffi.core._CLASS_DEVICE
tvm_ffi.core._set_class_device(MyDevice)
device = tvm_ffi.device("cuda", 0)
assert isinstance(device, MyDevice)
tvm_ffi.core._set_class_device(old_device)  # restore
```
