# Keep a reference to the loaded torch C DLPack patch library to prevent premature GC

## TL;DR
- Stores the `ctypes.CDLL` handle returned by `load_torch_c_dlpack_extension()` into a module-level variable so Python's GC does not unload the shared library.

## Key Exports
None

## Impact
- API: none
- Behavioral: Fixes silent use-after-free crash when the loaded shared library was garbage-collected after `load_torch_c_dlpack_extension()` returned a local handle that was immediately discarded.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `_optional_torch_c_dlpack.load_torch_c_dlpack_extension()` — bugfix restores lifetime invariant

Design elements this commit produces: none

## Usage Examples
Before:
```python
# ctypes lib handle discarded — library unloaded after this call
load_torch_c_dlpack_extension()
```
After:
```python
_TORCH_C_DLPACK_LIB = load_torch_c_dlpack_extension()  # module-level reference keeps lib alive
```
