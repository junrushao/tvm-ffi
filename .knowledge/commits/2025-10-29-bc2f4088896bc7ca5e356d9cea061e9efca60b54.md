# Keep module-level reference to loaded torch C DLPack addon shared library
## TL;DR
- Fixes `load_torch_c_dlpack_extension()` to `return lib` (the `ctypes.CDLL` handle) and stores it in module-level `_LIB`, preventing the shared library from being garbage-collected while `__c_dlpack_exchange_api__` still references its function pointer.

None

## Impact
- API: none
- Behavioral: prevents use-after-free crash when the `ctypes.CDLL` object was garbage-collected but `torch.Tensor.__c_dlpack_exchange_api__` still held a dangling pointer.
- Flags/config: none
