# Add __dlpack_device__ protocol for Device arg dispatch in Cython
## TL;DR
- Adds `TVMFFIPyArgSetterDLPackDeviceProtocol_` Cython setter: any Python class with `__dlpack_device__()` (but without `__dlpack__`) is automatically converted to a `Device` when passed as an FFI argument.
- Registers the new setter in `TVMFFIPyArgSetterFactory_` dispatch chain, placed after `__dlpack_data_type__` and before `Exception`.
- Test covers the round-trip: Python object with `__dlpack_device__` -> FFI echo -> Device comparison.

- API: Additive -- classes implementing `__dlpack_device__()` are now passable as FFI Device arguments without manual conversion. No existing callers affected.

## Usage Examples
Round-trip a `__dlpack_device__` object through an FFI function call (from test):
```python
import tvm_ffi

device = tvm_ffi.device("cuda:1")

class DLPackDeviceProtocol:
    def __init__(self, device: tvm_ffi.Device) -> None:
        self.device = device

    def __dlpack_device__(self) -> tuple[int, int]:
        return (self.device.dlpack_device_type(), self.device.index)

fecho = tvm_ffi.get_global_func("testing.echo")
x = DLPackDeviceProtocol(device)
y = fecho(x)  # auto-converted to Device via __dlpack_device__ protocol
assert y == device
```
