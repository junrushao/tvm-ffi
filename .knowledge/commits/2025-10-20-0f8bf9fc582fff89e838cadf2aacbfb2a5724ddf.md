# Add __dlpack_device__ protocol for automatic Device conversion in FFI calls
## TL;DR
- Introduces `__dlpack_device__` duck-type protocol: any Python class with `__dlpack_device__()` (but not `__dlpack__`) is auto-converted to a Device when passed through FFI calls.
- New Cython setter `TVMFFIPyArgSetterDLPackDeviceProtocol_` calls `arg.__dlpack_device__()` and converts the `(device_type, device_id)` tuple to `TVMFFIAny` with `kTVMFFIDevice` type index.

## Key Exports
```python
# --- __dlpack_device__ Protocol (new, 0f8bf9f) ---
# Duck-type protocol on any Python class to make instances passable as Device through FFI:
#   def __dlpack_device__(self) -> tuple[int, int]:
#       """Return (device_type, device_id) pair following DLPack convention."""
# Interacts with: TVMFFIPyArgSetterFactory_ dispatch, TVMFFIDLDeviceFromIntPair (C ABI)
# Invariant: class must NOT have __dlpack__ (to avoid conflict with tensor types that
#   expose both __dlpack__ and __dlpack_device__); tensor types are handled by the
#   DLPack exchange path instead.

# Cython setter: TVMFFIPyArgSetterDLPackDeviceProtocol_
#   Calls arg.__dlpack_device__() -> (int, int)
#   Sets out.type_index = kTVMFFIDevice
#   Sets out.v_device = TVMFFIDLDeviceFromIntPair(device_type, device_id)

# Dispatch position in TVMFFIPyArgSetterFactory_:
#   ... > DLPackDataTypeProtocol (__dlpack_data_type__) > DLPackDeviceProtocol (__dlpack_device__) > Exception > ...
```

## Impact
- API: New duck-type protocol. Any class implementing `__dlpack_device__()` (without `__dlpack__`) can now be passed directly to FFI functions and will be received as a Device value.
- Behavioral: none for existing code -- existing Device objects and DLPack tensors are handled by earlier dispatch entries.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
**Context**: Passing a custom device-like object through FFI using the `__dlpack_device__` protocol.
```python
import tvm_ffi

class MyDevice:
    """Any class that implements __dlpack_device__ (but not __dlpack__)."""
    def __init__(self, device_type: int, device_id: int) -> None:
        self._type = device_type
        self._id = device_id

    def __dlpack_device__(self) -> tuple[int, int]:
        return (self._type, self._id)

fecho = tvm_ffi.get_global_func("testing.echo")
x = MyDevice(2, 1)  # CUDA device 1
y = fecho(x)  # auto-converted to tvm_ffi.Device
assert y == tvm_ffi.device("cuda:1")
```
