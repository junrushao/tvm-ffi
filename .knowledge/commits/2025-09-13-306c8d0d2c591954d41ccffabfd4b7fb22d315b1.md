# Setup ASF YAML for GitHub repo metadata and branch protection

## TL;DR
- Adds `.asf.yaml` to configure Apache Software Foundation infrastructure for the GitHub repository: sets repo description ("TVM FFI"), homepage (`https://tvm.apache.org/ffi`), labels (`ffi`, `gpu`, `machine-learning`), branch protection for `dev` (1 required approving review), and mailing list notifications (`commits@tvm.apache.org`, `discuss-archive@tvm.apache.org`).
- Adds a blank line in `.github/workflows/ci_test.yml` between the `lint` job's last step and the `test` job (whitespace-only change).
