# Encapsulate torch DLPack exchange functions as static members and fix Py_DECREF portability in tests

## TL;DR
- Move five free functions implementing the torch DLPack exchange API into `TorchDLPackExchangeAPI` as private static members, improving encapsulation.
- Replace `Py_DECREF` (a CPython macro) with `Py_DecRef` (stable C API function) in the test's inline C++ code, fixing `decltype(&Py_DECREF)` portability issues.
- Fix `CurrentWorkStream` to explicitly set `*out_stream = nullptr` for non-CUDA devices, avoiding uninitialized output.

## Key Exports
None -- no new public API surface. Internal reorganization only.

## Impact
- API: none
- ABI: none
- Behavioral: `CurrentWorkStream` now explicitly returns `nullptr` stream for CPU/non-CUDA devices instead of leaving the output uninitialized. This is a correctness fix for callers that check the stream pointer.
