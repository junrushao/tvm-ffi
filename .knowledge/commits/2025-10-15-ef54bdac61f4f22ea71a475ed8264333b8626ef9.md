# Fix Py_DECREF→Py_DecRef function-pointer bug and encapsulate TorchDLPackExchangeAPI callbacks as private static members

## TL;DR
- **Bug fix**: Replaces `&Py_DECREF` with `&Py_DecRef` in `std::unique_ptr` custom deleters in the test file. `Py_DECREF` is a C macro and cannot be used as a function pointer; `Py_DecRef` is the actual C function.
- **Refactor**: Moves the five standalone C-linkage functions (`TorchDLPackDLTensorFromPyObjectNoSync`, `TorchDLPackManagedTensorFromPyObjectNoSync`, etc.) into private static member functions of `TorchDLPackExchangeAPI`, eliminating namespace pollution and co-locating them with the struct they serve.
- **Behavioral fix**: `CurrentWorkStream` now explicitly sets `*out_stream = nullptr` for non-CUDA/ROCm devices before returning 0, preventing callers from reading an uninitialized pointer on CPU tensors.

## Key Exports

```python
class TorchDLPackExchangeAPI(DLPackExchangeAPI):
    """C++ singleton; populates all five DLPackExchangeAPI function pointers for torch.Tensor.
    Public interface unchanged. Internal callback functions are now private static members
    (no longer standalone free functions with external linkage).
    """
    # OLD (pre-ef54bdac): standalone free functions in anonymous namespace:
    #   TorchDLPackDLTensorFromPyObjectNoSync, TorchDLPackManagedTensorFromPyObjectNoSync,
    #   TorchDLPackManagedTensorToPyObjectNoSync, TorchDLPackManagedTensorAllocator,
    #   TorchDLPackCurrentWorkStream
    # NEW: private static member functions:
    #   DLTensorFromPyObjectNoSync, ManagedTensorFromPyObjectNoSync,
    #   ManagedTensorToPyObjectNoSync, ManagedTensorAllocator, CurrentWorkStream

    @staticmethod
    def Global() -> "const DLPackExchangeAPI*": ...
    # Invariant: returns a stable pointer to a static singleton; safe to store permanently

    # Private static member: CurrentWorkStream behavioral fix
    # OLD: returned 0 without initializing *out_stream for non-CUDA devices
    # NEW: sets *out_stream = nullptr for non-CUDA/ROCm devices before returning 0
    # Invariant: *out_stream is always written on success (return 0)
    # Interacts with: TVMFFIPyCallManager stream detection (reads *out_stream after call)
```

## Impact
- API: None — `TorchDLPackExchangeAPI::Global()` pointer type and struct layout are unchanged; callers unaffected.
- Behavioral: `CurrentWorkStream` now correctly writes `nullptr` to `*out_stream` for CPU and non-CUDA devices. Previously the output parameter was left uninitialized on the non-CUDA branch, risking a garbage stream pointer being injected into `TVMFFIEnvSetStream`.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

**Before/after pattern — Py_DECREF macro vs. Py_DecRef function:**

```cpp
// BEFORE (broken — Py_DECREF is a macro, not addressable as a function pointer):
std::unique_ptr<PyObject, decltype(&Py_DECREF)> py_obj(THPVariable_Wrap(tensor), &Py_DECREF);

// AFTER (correct — Py_DecRef is the actual C function):
std::unique_ptr<PyObject, decltype(&Py_DecRef)> py_obj(THPVariable_Wrap(tensor), &Py_DecRef);
```

**Before/after pattern — CurrentWorkStream CPU branch:**

```cpp
// BEFORE (undefined behavior — *out_stream not written on non-CUDA path):
static int TorchDLPackCurrentWorkStream(DLDeviceType device_type, int32_t device_id, void** out_stream) {
    try {
#ifdef BUILD_WITH_CUDA
        if (device_type == kDLCUDA || device_type == kDLROCM) {
            *out_stream = at::cuda::getCurrentCUDAStream(device_id).stream();
        }
#endif
        return 0;  // *out_stream uninitialized for CPU!
    } ...
}

// AFTER (correct — *out_stream always written):
static int CurrentWorkStream(DLDeviceType device_type, int32_t device_id, void** out_stream) {
    try {
#ifdef BUILD_WITH_CUDA
        if (device_type == kDLCUDA || device_type == kDLROCM) {
            *out_stream = at::cuda::getCurrentCUDAStream(device_id).stream();
            return 0;
        }
#endif
        *out_stream = nullptr;  // CPU and other devices: no stream
        return 0;
    } ...
}
```
