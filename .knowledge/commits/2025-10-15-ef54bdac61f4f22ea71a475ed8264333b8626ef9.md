# Refactor torch DLPack exchange functions into static members and fix Py_DECREF portability

## TL;DR
- Moves five free functions (`TorchDLPackDLTensorFromPyObjectNoSync`, `TorchDLPackManagedTensorFromPyObjectNoSync`, `TorchDLPackManagedTensorToPyObjectNoSync`, `TorchDLPackManagedTensorAllocator`, `TorchDLPackCurrentWorkStream`) into `TorchDLPackExchangeAPI` as private static members, improving encapsulation.
- Replaces `Py_DECREF` with `Py_DecRef` in test C++ code for portability (macro vs. stable C API function).
- Fixes a latent bug in `CurrentWorkStream` where `*out_stream` was left uninitialized for non-CUDA devices; now explicitly set to `nullptr`.

## Key Exports

```python
# No new public API -- purely internal reorganization of TorchDLPackExchangeAPI.
# The struct's public interface (Global(), constructor, DLPackExchangeAPI fields) is unchanged.

class TorchDLPackExchangeAPI(DLPackExchangeAPI):
    """Singleton providing torch <-> DLPack exchange. JIT-compiled inline C++."""

    # Previously these were file-scope free functions; now private static members:
    #   TorchDLPackDLTensorFromPyObjectNoSync     -> DLTensorFromPyObjectNoSync (private static)
    #   TorchDLPackManagedTensorFromPyObjectNoSync -> ManagedTensorFromPyObjectNoSync (private static)
    #   TorchDLPackManagedTensorToPyObjectNoSync   -> ManagedTensorToPyObjectNoSync (private static)
    #   TorchDLPackManagedTensorAllocator          -> ManagedTensorAllocator (private static)
    #   TorchDLPackCurrentWorkStream               -> CurrentWorkStream (private static)

    @staticmethod
    def Global() -> Ptr[DLPackExchangeAPI]: ...
    # Interacts with: TorchDLPackExchangeAPIPtr() (the only external entry point)
    # Invariant: singleton — constructed once, lives for process lifetime
```

## Impact
- API: None — the public entry point `TorchDLPackExchangeAPIPtr()` and the `DLPackExchangeAPI` struct layout are unchanged.
- Behavioral: `CurrentWorkStream` now explicitly initializes `*out_stream = nullptr` for non-CUDA devices (previously left uninitialized). Also returns 0 from inside the CUDA branch before falling through to the explicit nullptr assignment.
- Flags/config: None.
- Data formats/schemas: None.

```cpp
    // Bug: *out_stream never written for non-CUDA → uninitialized
    ...

struct TorchDLPackExchangeAPI : public DLPackExchangeAPI {

        ...
```

```cpp
struct TorchDLPackExchangeAPI : public DLPackExchangeAPI {

        dltensor_from_py_object_no_sync = DLTensorFromPyObjectNoSync;

        ...
    }
 private:
    static int DLTensorFromPyObjectNoSync(void* py_obj, DLTensor* out) { ... }

```

Test fix (`Py_DECREF` macro to `Py_DecRef` stable C API function):
```cpp
// Before:
```
