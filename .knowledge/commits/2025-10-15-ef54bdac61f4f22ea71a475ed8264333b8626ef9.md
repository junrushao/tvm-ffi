# Refactor TorchDLPack exchange functions into static members and fix Py_DECREF -> Py_DecRef
## TL;DR
- Moved five free functions (`TorchDLPackDLTensorFromPyObjectNoSync`, `TorchDLPackManagedTensorFromPyObjectNoSync`, `TorchDLPackManagedTensorToPyObjectNoSync`, `TorchDLPackManagedTensorAllocator`, `TorchDLPackCurrentWorkStream`) into the `TorchDLPackExchangeAPI` struct as private static member functions.
- Replaced `Py_DECREF` (macro) with `Py_DecRef` (function) in test C++ code embedded in `test_dlpack_exchange_api.py`, fixing potential compilation issues with `decltype` on macros.
- Added a behavioral fix to `CurrentWorkStream`: CPU/non-CUDA devices now explicitly return `nullptr` stream instead of leaving the output uninitialized.

## Key Exports

The public API surface (`DLPackExchangeAPI` struct and its `Global()` accessor) is unchanged. The refactoring is internal -- free functions became private static members with shorter names. The function pointer table in the constructor now references static members instead of free functions.

```python
# Rename mapping (free functions -> static members of TorchDLPackExchangeAPI):
# TorchDLPackDLTensorFromPyObjectNoSync       -> TorchDLPackExchangeAPI::DLTensorFromPyObjectNoSync
# TorchDLPackManagedTensorFromPyObjectNoSync   -> TorchDLPackExchangeAPI::ManagedTensorFromPyObjectNoSync
# TorchDLPackManagedTensorToPyObjectNoSync     -> TorchDLPackExchangeAPI::ManagedTensorToPyObjectNoSync
# TorchDLPackManagedTensorAllocator            -> TorchDLPackExchangeAPI::ManagedTensorAllocator
# TorchDLPackCurrentWorkStream                 -> TorchDLPackExchangeAPI::CurrentWorkStream

class TorchDLPackExchangeAPI(DLPackExchangeAPI):
    """Torch implementation of the unified DLPack exchange API."""
    # Interacts with: DLPackExchangeAPI (base struct), __c_dlpack_exchange_api__ protocol
    # Invariant: Global() returns a singleton; function pointers are stable for process lifetime

    @staticmethod
    def Global() -> const DLPackExchangeAPI*: ...

    # All below are private static, exposed only via function pointers in base struct:
    # DLTensorFromPyObjectNoSync(py_obj, out) -> int
    # ManagedTensorFromPyObjectNoSync(py_obj, out) -> int
    # ManagedTensorToPyObjectNoSync(src, py_obj_out) -> int
    # ManagedTensorAllocator(prototype, out, error_ctx, SetError) -> int
    # CurrentWorkStream(device_type, device_id, out_stream) -> int
    #   Invariant (new): returns nullptr for non-CUDA devices instead of leaving out_stream uninitialized
```

## Impact
- API: None -- the `DLPackExchangeAPI` function pointer interface and `Global()` accessor are unchanged; callers interact through the struct, not by name.
- Behavioral: `CurrentWorkStream` now explicitly sets `*out_stream = nullptr` for non-CUDA devices, fixing a potential uninitialized read.
- Flags/config: None
- Data formats/schemas: None
