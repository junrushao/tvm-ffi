# Expose Python API to construct Function from extern C symbol address

## TL;DR
- Adds `Function.__from_extern_c__(c_symbol, keep_alive_object=None)` static method to the Cython `Function` class, enabling Python code to construct an FFI `Function` from a raw C function pointer (as an integer) and an optional keep-alive object.
- Fixes a stale Cython declaration in `base.pxi`: the `TVMFFIObject.deleter` field signature is corrected from `void (*deleter)(TVMFFIObject* self)` to `void (*deleter)(void* self, int flags)`, matching the C header change made in commit 24125d0.
- Adds a C++ test helper `testing.get_add_one_c_symbol` that returns a raw `TVMFFISafeCallType` function pointer as `int64_t`, plus a Python test exercising the new API.

## Key Exports

**Methods**:
- `Function.__from_extern_c__(c_symbol: int, keep_alive_object: Any | None = None) -> Function` -- Static method on the Cython `Function` class. Accepts a `TVMFFISafeCallType`-compatible C function pointer as a Python int and an optional Python object to keep alive as the function's closure. Calls `TVMFFIFunctionCreate` under the hood. When `keep_alive_object` is provided, it is `Py_INCREF`'d and stored as the function's `self` pointer with `TVMFFIPyObjectDeleter` as the deleter.

**Functions (C++ testing)**:
- `testing.get_add_one_c_symbol() -> int` -- Returns the address of an internal `__add_one_c_symbol` function as `int64_t` for testing the `__from_extern_c__` API.

## Impact
- API: New public Python method `Function.__from_extern_c__`. No existing callers are affected. This enables JIT execution engines to expose compiled functions to Python without going through the global registry.
- ABI: None. Uses existing `TVMFFIFunctionCreate` C API.
- Behavioral: The Cython `TVMFFIObject.deleter` field declaration is corrected to match the actual C ABI (`void* self, int flags` instead of `TVMFFIObject* self`). This is a declaration-only fix; the runtime behavior was already correct because Cython does not generate code that calls the deleter directly through this struct field.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `TVMFFIFunctionCreate` C API for creating Function from extern C callback (`.knowledge/designs/function-system.md`, `.knowledge/designs/c-abi.md`)
- `TVMFFISafeCallType` calling convention: `int(void*, const TVMFFIAny*, int32_t, TVMFFIAny*)` (`.knowledge/designs/function-system.md`)
- `TVMFFIPyObjectDeleter` for preventing Python object GC while the FFI holds a reference (`.knowledge/designs/0014-python-bindings.md`)
- `TVM_FFI_SAFE_CALL_BEGIN/END` error boundary macros (`.knowledge/designs/function-system.md`)
- `ExternCFunctionObjImpl` / `ExternCFunctionObjNullHandleImpl` -- the C++ implementation classes that back `FromExternC`-created functions (`.knowledge/designs/function-system.md`)

Design elements this commit produces:
- Python-level `Function.__from_extern_c__` -- the Python equivalent of `Function::FromExternC` in C++ and `Function::from_extern_c` in Rust, completing cross-language parity for constructing Functions from raw C symbols.

## Usage Examples

### Constructing a Function from a JIT-compiled C symbol
**Context**: A JIT engine compiles a kernel and returns a C function pointer. Python wraps it as an FFI Function, keeping the engine alive.
```python
import tvm_ffi

# Suppose jit_engine.compile() returns a TVMFFISafeCallType-compatible address
c_symbol = jit_engine.compile("my_kernel")

# Wrap as FFI Function; jit_engine stays alive as long as the Function exists
func = tvm_ffi.Function.__from_extern_c__(c_symbol, keep_alive_object=jit_engine)
result = func(42)

# Without keep_alive_object (caller manages lifetime):
func_no_closure = tvm_ffi.Function.__from_extern_c__(c_symbol)
```

### Test pattern from the commit
**Context**: The test retrieves a C symbol address via a global function and wraps it.
```python
import sys
import tvm_ffi

add_one_c_symbol = tvm_ffi.get_global_func("testing.get_add_one_c_symbol")()
fadd_one = tvm_ffi.Function.__from_extern_c__(add_one_c_symbol)
assert fadd_one(1) == 2

# With keep_alive_object, ref count is incremented
keep_alive = [1, 2, 3]
base_ref_count = sys.getrefcount(keep_alive)
fadd_one = tvm_ffi.Function.__from_extern_c__(add_one_c_symbol, keep_alive)
assert sys.getrefcount(keep_alive) == base_ref_count + 1
fadd_one = None  # releases the Function, decrements keep_alive ref
assert sys.getrefcount(keep_alive) == base_ref_count
```
