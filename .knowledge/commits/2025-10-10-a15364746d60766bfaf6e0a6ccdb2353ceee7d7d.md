# Expose Python API to construct Function from raw C symbol address
## TL;DR
- Adds `Function.__from_extern_c__(c_symbol, keep_alive_object=None)` static method to the Cython `Function` class, enabling Python code to construct an FFI `Function` from a raw C function pointer (passed as an integer) and an optional keep-alive object.
- The primary use case is wrapping JIT-compiled function pointers (e.g., from an LLVM execution engine) into callable FFI `Function` objects from Python, keeping the execution engine alive as long as the function exists.
- Includes a Cython struct fix: updates `TVMFFIObject.deleter` signature in `base.pxi` from `void (*deleter)(TVMFFIObject* self)` to `void (*deleter)(void* self, int flags)` to match the actual C header.

## Key Exports

        The c_symbol must be a TVMFFISafeCallType function pointer cast to int.
        The function pointer must ignore its first argument (the function handle).

        # Interacts with: TVMFFIFunctionCreate (C API), ExternCFunctionObjImpl / ExternCFunctionObjNullHandleImpl
        # Interacts with: TVMFFIPyObjectDeleter (prevents keep_alive_object from being GC'd)
        # Invariant: if keep_alive_object is not None, it is Py_INCREF'd and stored as the closure;
        #   TVMFFIPyObjectDeleter calls Py_DECREF when the Function is destroyed
        # Invariant: if keep_alive_object is None, deleter=NULL -> ExternCFunctionObjNullHandleImpl
        # Invariant: on TVMFFIFunctionCreate failure with keep_alive_object, Py_DECREF is called to avoid leak
        # Extension: JIT engines pass their engine object as keep_alive_object to prevent premature deallocation

## Usage Examples

Constructing a Function from a JIT-compiled C symbol in Python (from test):

```python
import tvm_ffi

# Get a raw C function pointer (e.g., from JIT engine)
add_one_c_symbol = tvm_ffi.get_global_func("testing.get_add_one_c_symbol")()

# Construct Function with no keep-alive (simple case)
fadd_one = tvm_ffi.Function.__from_extern_c__(add_one_c_symbol)
assert fadd_one(1) == 2

# Construct Function with keep-alive (e.g., JIT engine object)
engine = SomeJITEngine()  # keeps compiled code alive
fadd_one = tvm_ffi.Function.__from_extern_c__(add_one_c_symbol, engine)
assert fadd_one(1) == 2
# engine ref count is incremented; dropping fadd_one decrements it
```
