# Guard kDLFloat4_e2m1fn DLPack cases behind PyTorch >= 2.8 version check
## TL;DR
- Added `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` / `#endif` guards around the `kDLFloat4_e2m1fn` switch cases in the embedded torch C DLPack source (`python/tvm_ffi/_optional_torch_c_dlpack.py`), preventing compilation errors on PyTorch < 2.8.
- Bumped package version from `0.1.0b6` to `0.1.0b7` in `pyproject.toml`.

- Behavioral: none -- the guarded code paths were already unreachable on older PyTorch versions (compilation would fail before runtime). This fix makes the code compile cleanly on PyTorch < 2.8.
