# Guard kDLFloat4_e2m1fn DLPack cases behind TORCH_VERSION >= 2.8 for earlier torch compat
## TL;DR
- Wraps `kDLFloat4_e2m1fn` switch cases in `_optional_torch_c_dlpack.py` (inline C++ source) with `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` to avoid compile errors on older PyTorch.
- Bumps package version from `0.1.0b6` to `0.1.0b7`.
