# Guard Float4_e2m1fn DLPack cases behind TORCH_VERSION >= 2.8 for backward compat
## TL;DR
- Wraps `kDLFloat4_e2m1fn` switch cases in `_optional_torch_c_dlpack.py` with `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` guards so that the inline C++ compiles against PyTorch < 2.8 which lacks `ScalarType::Float4_e2m1fn_x2`.
- Bumps package version from `0.1.0b6` to `0.1.0b7`.
