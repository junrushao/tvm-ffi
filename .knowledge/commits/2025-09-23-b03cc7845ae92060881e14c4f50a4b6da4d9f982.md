# Guard kDLFloat4_e2m1fn dtype case in toScalarTypeForDLPackv1 behind TORCH_VERSION_MAJOR>=2 && TORCH_VERSION_MINOR>=8

## TL;DR
- `_optional_torch_c_dlpack.py` embeds C++ source compiled via `torch.utils.cpp_extension`. The `toScalarTypeForDLPackv1` function introduced in commit `929effa` added a `kDLFloat4_e2m1fn` dtype case referencing `ScalarType::Float4_e2m1fn_x2`, which only exists in PyTorch >= 2.8. This commit wraps that block with `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8 / #endif` so the extension compiles on earlier torch versions.
- Version bumped `0.1.0b6` → `0.1.0b7` in `pyproject.toml`.

## Key Exports

None — this commit changes no public API surface. It only narrows the compiled C++ switch-case body to respect torch version compatibility.

## Impact
- API: none
- Behavioral: `toScalarTypeForDLPackv1` on torch < 2.8 will no longer attempt to match `kDLFloat4_e2m1fn` dtype; it falls through to the `default: TORCH_CHECK(false, ...)` path. On torch >= 2.8 behaviour is unchanged.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `0016-py-ffi-call-dispatch` — `_optional_torch_c_dlpack.py` inline C++ `toScalarTypeForDLPackv1`, introduced in commit `929effa`; the version-guard pattern was already noted as the `# Extension: add new DLDataTypeCode cases here; guard with TORCH_VERSION macros` annotation in that ledger.

Design elements this commit produces: none

## Usage Examples

**Bugfix: before/after for torch < 2.8 compilation**

```cpp
// BEFORE (commit 929effa): compiles only on torch >= 2.8
ScalarType toScalarTypeForDLPackv1(const DLDataType& dtype) {
  switch (dtype.code) {
    // ...kDLFloat8 cases...
    case DLDataTypeCode::kDLFloat4_e2m1fn:   // ← ScalarType::Float4_e2m1fn_x2 undefined on torch < 2.8
      switch (dtype.bits) {
        case 4:
          switch (dtype.lanes) {
            case 2: stype = ScalarType::Float4_e2m1fn_x2; break;
            // ...
          }
      }
      break;
    default: TORCH_CHECK(false, ...);
  }
}

// AFTER (this commit): compiles on any supported torch version
ScalarType toScalarTypeForDLPackv1(const DLDataType& dtype) {
  switch (dtype.code) {
    // ...kDLFloat8 cases...
#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8
    case DLDataTypeCode::kDLFloat4_e2m1fn:
      // ...same body...
      break;
#endif
    default: TORCH_CHECK(false, ...);
  }
}
```
