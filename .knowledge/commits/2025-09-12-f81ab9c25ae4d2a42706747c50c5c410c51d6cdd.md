# Add DLPack exporter/importer/allocator function pointers and GIL-release control to speed up cross-framework tensor exchange

## TL;DR
- Introduces three new C-level function-pointer protocols (`DLPackPyObjectExporter`, `DLPackPyObjectImporter`, `DLPackTensorAllocator`) enabling zero-copy, fast-path DLPack tensor exchange between TVM FFI and external frameworks (primarily PyTorch).
- Adds `Tensor::FromDLPackAlloc` (C++) and a thread-local `EnvContext` (replacing the narrower `StreamContext`) to manage both stream and tensor-allocator state per thread, with a global fallback.
- Adds per-function `release_gil` property on `Function` objects (default: release, env-overridable via `TVM_FFI_RELEASE_GIL_BY_DEFAULT`) and renames `SetCurrentStream`/`GetCurrentStream` to `SetStream`/`GetStream`.

Rename mapping:

| Before | After |
|---|---|
| `TVMFFIEnvSetCurrentStream` | `TVMFFIEnvSetStream` |
| `TVMFFIEnvGetCurrentStream` | `TVMFFIEnvGetStream` |
| `DLPackPyObjectCExporter` | `DLPackPyObjectExporter` |
| `__dlpack_c_exporter__` | `__c_dlpack_exporter__` |
| `dlpack_c_exporter` (field) | `c_dlpack_exporter` (field) |
| `StreamContext` (C++ class) | `EnvContext` (C++ class) |
| `stream_context.cc` | `env_context.cc` |
| `TVMFFIPyArgSetterTorch_` | `TVMFFIPyArgSetterTorchFallback_` |

## Key Exports

```python
# --- C ABI (include/tvm/ffi/c_api.h) ---

# NEW: C-style allocator callback for DLPack tensors
# Interacts with: Tensor::FromDLPackAlloc, TVMFFIEnvSetTensorAllocator/GetTensorAllocator
# Invariant: must call SetError on failure and return -1; must set *out to valid DLManagedTensorVersioned on success
# Extension: implement per-framework (e.g. TorchDLPackTensorAllocator)
def DLPackTensorAllocator(
    prototype: Ptr[DLTensor],
    out: Ptr[Ptr[DLManagedTensorVersioned]],
    error_ctx: Ptr[void],
    SetError: Callable[[Ptr[void], str, str], None]
) -> int: ...

# --- C ABI (include/tvm/ffi/extra/c_env_api.h) ---

# RENAMED: SetCurrentStream -> SetStream
def TVMFFIEnvSetStream(device_type: int32, device_id: int32,
                       stream: TVMFFIStreamHandle,
                       opt_out_original_stream: Ptr[TVMFFIStreamHandle]) -> int: ...
    # Interacts with: EnvContext::ThreadLocal()

# RENAMED: GetCurrentStream -> GetStream
def TVMFFIEnvGetStream(device_type: int32, device_id: int32) -> TVMFFIStreamHandle: ...
    # Interacts with: EnvContext::ThreadLocal()

# NEW: Set tensor allocator in TLS (and optionally global) context
def TVMFFIEnvSetTensorAllocator(
    allocator: DLPackTensorAllocator,
    write_to_global_context: int,
    opt_out_original_allocator: Ptr[DLPackTensorAllocator]
) -> int: ...
    # Interacts with: EnvContext::ThreadLocal(), EnvContext::GlobalTensorAllocator()
    # Invariant: TLS takes priority; global is fallback when TLS is nullptr

# NEW: Get tensor allocator (TLS first, then global fallback)
def TVMFFIEnvGetTensorAllocator() -> DLPackTensorAllocator: ...
    # Interacts with: EnvContext::ThreadLocal(), EnvContext::GlobalTensorAllocator()

# --- C++ (include/tvm/ffi/container/tensor.h) ---

class Tensor(ObjectRef):
    # NEW static factory
    @staticmethod
    def FromDLPackAlloc(
        allocator: DLPackTensorAllocator,
        shape: Shape, dtype: DLDataType, device: DLDevice
    ) -> Tensor: ...
        # Interacts with: DLPackTensorAllocator callback, TensorObjFromDLPack
        # Invariant: allocator must not be nullptr (raises RuntimeError)
        # Extension: pass TVMFFIEnvGetTensorAllocator() as allocator

# --- C++ internal (src/ffi/extra/env_context.cc) ---

class EnvContext:
    """Thread-local env context managing stream table AND tensor allocator."""
    # Replaces StreamContext; adds DLPack allocator management
    # Invariant: exactly one instance per thread via ThreadLocal()
    # GlobalTensorAllocator is a process-wide static fallback
    stream_table_: List[List[TVMFFIStreamHandle]]
    dlpack_allocator_: DLPackTensorAllocator  # TLS-level
    @staticmethod
    def ThreadLocal() -> Ptr[EnvContext]: ...
    @staticmethod
    def GlobalTensorAllocator() -> Ref[DLPackTensorAllocator]: ...  # process-wide

# --- Python helpers (tvm_ffi_python_helpers.h) ---

# NEW function-pointer typedefs for Python-level fast DLPack exchange
def DLPackPyObjectExporter(py_obj: Ptr[void], out: Ptr[Ptr[DLManagedTensorVersioned]],
                           env_stream: Ptr[Ptr[void]]) -> int: ...
    # Invariant: sets PyErr on failure

def DLPackPyObjectImporter(tensor: Ptr[DLManagedTensorVersioned],
                           py_obj_out: Ptr[Ptr[void]]) -> int: ...
    # Invariant: sets PyErr on failure; returned PyObject has +1 refcount

# --- Python (cython/function.pxi) ---

class Function(Object):  # now cdef class
    release_gil: bool  # default: True (env TVM_FFI_RELEASE_GIL_BY_DEFAULT)
    # Interacts with: TVMFFIPyCallManager.Call (controls Py_BEGIN/END_ALLOW_THREADS)
    # Extension: set func.release_gil = False for short-running functions
```

## Impact
- API: Two C ABI symbols renamed (`TVMFFIEnvSetCurrentStream` -> `TVMFFIEnvSetStream`, `TVMFFIEnvGetCurrentStream` -> `TVMFFIEnvGetStream`). Four new C ABI symbols added (`TVMFFIEnvSetTensorAllocator`, `TVMFFIEnvGetTensorAllocator`, `DLPackTensorAllocator` typedef). Python `__dlpack_c_exporter__` protocol renamed to `__c_dlpack_exporter__`; two new optional protocols `__c_dlpack_importer__`, `__c_dlpack_tensor_allocator__`. `Function` promoted from `class` to `cdef class` in Cython.
- Behavioral: When calling an FFI function with a torch.Tensor argument that has `__c_dlpack_importer__` set, returned `Tensor` values are auto-converted back to `torch.Tensor` (previously returned as `tvm_ffi.Tensor`). GIL is now released by default but controllable per-function. DLPack import/export in tensor.pxi no longer releases GIL around the fast C calls (removed `with nogil` blocks).
- Flags/config: `TVM_FFI_RELEASE_GIL_BY_DEFAULT` env var (default "1") controls default GIL behavior. `TVM_FFI_SKIP_C_DLPACK_EXPORTER` env var (default "0") disables the fast C DLPack path.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **C ABI function table** (`c_api.h`, `c_env_api.h`) -- extends with new typedefs and functions. See `.knowledge/designs/0001-c-abi.md`.
- **Tensor / DLPack exchange** (`container/tensor.h`) -- adds a new factory method leveraging the DLPack allocator callback. See `.knowledge/designs/0007-containers.md`.
- **Python Cython bindings call path** (`tvm_ffi_python_helpers.h`, `function.pxi`, `tensor.pxi`) -- extends `TVMFFIPyCallManager::Call` and `TVMFFIPyArgSetter` with importer/allocator/GIL fields. See `.knowledge/designs/0012-python-bindings.md`.
- **Thread-local env context** (`stream_context.cc` -> `env_context.cc`) -- replaces `StreamContext` with broader `EnvContext`.

Design elements this commit produces:
- **DLPackPyObjectExporter/Importer/TensorAllocator protocols**: Three C function-pointer typedefs forming a bidirectional fast-path DLPack protocol. Objects exposing `__c_dlpack_exporter__`, `__c_dlpack_importer__`, `__c_dlpack_tensor_allocator__` class attributes participate in the fast path.
- **EnvContext**: Unified thread-local context holding both stream table and tensor allocator (TLS + global fallback).
- **Tensor::FromDLPackAlloc**: C++ factory for creating tensors via an external allocator callback, enabling kernel libraries to allocate output tensors in the caller's framework.
- **Function.release_gil**: Per-function GIL control property, allowing short-running FFI calls to skip the GIL release/reacquire overhead.
- **_optional_torch_c_dlpack module**: JIT-compiled C++ extension setting `__c_dlpack_exporter__`, `__c_dlpack_importer__`, `__c_dlpack_tensor_allocator__` on `torch.Tensor` at import time.

## Usage Examples

End-to-end: C++ kernel allocates output via env allocator, Python caller gets torch.Tensor back:

```python
# Python side -- calling a C++ function that returns a Tensor
import tvm_ffi
import torch

mod = tvm_ffi.cpp.load_inline(name="hello", cuda_sources=r"""
    #include <tvm/ffi/container/tensor.h>
    namespace ffi = tvm::ffi;
    ffi::Tensor return_add_one(DLTensor* x) {
        ffi::Tensor y = ffi::Tensor::FromDLPackAlloc(
            TVMFFIEnvGetTensorAllocator(), ffi::Shape({x->shape[0]}),
            DLDataType{kDLFloat, 32, 1}, x->device);
        // ... launch kernel ...
        return y;
    }
""", functions=["return_add_one"])

x = torch.randn(128, device="cuda")
y = mod.return_add_one(x)   # y is a torch.Tensor, not tvm_ffi.Tensor
assert isinstance(y, torch.Tensor)
```

GIL control:

```python
func = tvm_ffi.get_global_func("my.short_func")
func.release_gil = False  # skip GIL release overhead for short calls
result = func(arg)
```
