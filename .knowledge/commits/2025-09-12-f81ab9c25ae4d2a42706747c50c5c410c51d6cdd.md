# Enhance DLPack exchange with DLPackTensorAllocator, DLPackFromPyObject, DLPackToPyObject, and GIL-release control

## TL;DR
- Introduces `DLPackTensorAllocator` C typedef in `c_api.h`: a function pointer for allocating a `DLManagedTensorVersioned` given a prototype, enabling environment-controlled tensor allocation.
- Adds `TVMFFIEnvSetTensorAllocator`/`TVMFFIEnvGetTensorAllocator` to `c_env_api.h`; renames `TVMFFIEnvGetCurrentStream` → `TVMFFIEnvGetStream` and reverts `TVMFFIEnvSetCurrentStream` → `TVMFFIEnvSetStream`.
- Adds `_optional_torch_c_dlpack.py` (403 LOC): lazily compiled PyTorch C extension that provides fast `DLPackFromPyObject`, `DLPackToPyObject`, `DLPackTensorAllocator` for `torch.Tensor` objects.
- Adds `release_gil` option to FFI function call path; adds `env_context.cc` to consolidate stream + allocator context.

## Impact
- API: ABI change — `TVMFFIEnvSetCurrentStream` → `TVMFFIEnvSetStream`, `TVMFFIEnvGetCurrentStream` → `TVMFFIEnvGetStream` (net reverting db987299f74a). New exports: `TVMFFIEnvSetTensorAllocator`, `TVMFFIEnvGetTensorAllocator`, `DLPackTensorAllocator`.
- Behavioral: When `torch.Tensor` is passed to a TVM FFI function and torch C extension is loaded, conversion uses fast C-path instead of Python-level `__dlpack__`. Return Tensor values may be automatically converted back to `torch.Tensor` via `DLPackToPyObject`.
- Flags/config: `func.release_gil = False` disables GIL release for short-running functions.
- Data formats/schemas: None.

## Usage Examples

```python
# Load the optional torch fast-path once at startup:
import tvm_ffi
tvm_ffi._optional_torch_c_dlpack.load_torch_c_dlpack_extension()

# After loading, torch.Tensor arguments use C-level DLPack export:
import torch
x = torch.randn(10, device="cuda")
result = my_ffi_func(x)  # Uses TorchDLPackFromPyObject (C), not __dlpack__ (Python)
# If function returns Tensor, DLPackToPyObject converts it back to torch.Tensor
```

```python
# Disable GIL release for a short-running FFI function:
nop = tvm_ffi.get_global_func("ffi.testing.nop")
nop.release_gil = False
nop(x, y)  # GIL not released
```
