# Add AWS Trainium (kDLTrn=17) device type to DLDeviceType enum and Device name mappings
## TL;DR
- Adds `kDLTrn = 17` to the `DLDeviceType` IntEnum in both the Cython source (`device.pxi`) and the type stub (`core.pyi`).
- Adds bidirectional `"trn"` name mappings in `Device._DEVICE_TYPE_TO_NAME` and `Device._DEVICE_NAME_TO_TYPE`.

## Key Exports

```python
class DLDeviceType(IntEnum):
    # ... existing members ...
    kDLTrn = 17   # AWS Trainium accelerator
    # Interacts with: Device._DEVICE_TYPE_TO_NAME, Device._DEVICE_NAME_TO_TYPE
```

## Impact
- API: Additive only — new enum value `kDLTrn=17` and string alias `"trn"` enable `tvm_ffi.device("trn", 0)`.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `DLDeviceType` enum and `Device` class name-mapping protocol (see `0012-ffi-python-package` in design index).

Design elements this commit produces: None — purely additive enum extension.

## Usage Examples

```python
import tvm_ffi

# Create a Trainium device
dev = tvm_ffi.device("trn", 0)
assert dev.device_type == 17
```
