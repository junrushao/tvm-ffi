# Add Trainium (trn) device type to Python DLDeviceType enum and Device mappings
## TL;DR
- Adds `kDLTrn = 17` to the `DLDeviceType` IntEnum in `device.pxi` and `core.pyi`.
- Adds bidirectional `"trn"` string mapping in `Device._DEVICE_TYPE_TO_NAME` and `Device._DEVICE_NAME_TO_TYPE`.
- **Value mismatch**: The Python enum assigns `kDLTrn = 17`, but the Cython extern declaration in `base.pxi` has `kDLMAIA = 17` and `kDLTrn = 18`. This commit skips `kDLMAIA` and uses the wrong integer value for `kDLTrn`.

## Key Exports
**Constants/Enums**:
| Name | Value | Location |
|------|-------|----------|
| `DLDeviceType.kDLTrn` | `17` (should be `18` per `base.pxi`) | `device.pxi`, `core.pyi` |

**String mappings** (added to `Device`):
| Enum member | String name |
|-------------|-------------|
| `kDLTrn` | `"trn"` |

## Impact
- API: Callers can now use `tvm_ffi.device("trn:0")` or `Device("trn", 0)` to create a Trainium device. However, the integer value `17` will be passed to the C ABI where it corresponds to `kDLMAIA`, not `kDLTrn`.
- Behavioral: The `DLDeviceType.kDLTrn` Python enum value (17) disagrees with the C extern value (18). Any cross-language round-trip or DLPack interop using the integer device type will misidentify Trainium devices as MAIA devices.
- Flags/config: none
- Data formats/schemas: DLPack `DLDevice.device_type` integer interpretation differs between Python and C layers after this change.

## Design Elements
Design elements this commit consumes:
- `DLDeviceType` IntEnum pattern (see `.knowledge/designs/0014-python-package.md` line 142): adds a new member following existing convention.
- `Device._DEVICE_TYPE_TO_NAME` / `_DEVICE_NAME_TO_TYPE` bidirectional mapping pattern (see `device.pxi` lines 79-114).
- `core.pyi` stub for `DLDeviceType` (keeps type stubs in sync with Cython).

Design elements this commit produces:
- New device type `kDLTrn` / `"trn"` -- enables `Device("trn", N)` construction and `str(dev)` -> `"trn:N"` display.

## Usage Examples
```python
import tvm_ffi

# Create a Trainium device
dev = tvm_ffi.device("trn:0")
assert dev.type == "trn"
assert dev.index == 0

# From enum
from tvm_ffi.core import DLDeviceType
assert DLDeviceType.kDLTrn == 17  # NOTE: should be 18 per DLPack spec
```
