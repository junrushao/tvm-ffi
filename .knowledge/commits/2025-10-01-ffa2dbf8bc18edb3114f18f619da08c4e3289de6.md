# Add kDLTrn = 17 (AWS Trainium) to DLDeviceType enum with 'trn' string alias

## TL;DR
- Adds `kDLTrn = 17` to `DLDeviceType` IntEnum in both `cython/device.pxi` and the `core.pyi` stub.
- Registers `"trn"` as the bidirectional string alias in `Device._DEVICE_TYPE_TO_NAME` and `Device._DEVICE_NAME_TO_TYPE`.

## Key Exports

```python
class DLDeviceType(IntEnum):
    # ... existing entries kDLCPU=1 .. kDLHexagon=16 ...
    kDLTrn = 17   # AWS Trainium; added in this commit
    # Invariant: values must match DLDeviceType C enum from DLPack spec
    # Interacts with: Device.__init__() string-to-type resolution, Device._DEVICE_TYPE_TO_NAME, Device._DEVICE_NAME_TO_TYPE
```

## Impact
- API: New enum value `DLDeviceType.kDLTrn = 17` exposed at `tvm_ffi.DLDeviceType.kDLTrn`; `Device("trn", idx)` now resolves correctly.
- Behavioral: none — additive only, no existing code path changes.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

- `DLDeviceType` IntEnum + `Device` bidirectional name maps — defined in `python/tvm_ffi/cython/device.pxi`; see [0013-python-package](../design-records/0013-python-package.md)

Design elements this commit produces:
