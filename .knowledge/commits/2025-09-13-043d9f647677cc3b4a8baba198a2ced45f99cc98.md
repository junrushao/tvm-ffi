# Add formal C ABI for String/Bytes construction and improve nested container + stream handling

## TL;DR
- Introduces `TVMFFIStringFromByteArray` and `TVMFFIBytesFromByteArray` in `c_api.h` (with implementation in `object.cc`) as formal C ABI for String/Bytes creation from raw byte data.
- Fixes bug in temp object recycling (temp object lifetime during nested container argument conversion).
- Optimizes recursive argument conversion (tuple/dict with Tensor contents) by moving more logic into C++, ensuring stream context propagates correctly through nested containers.

## Key Exports

```python
# c_api.h — new formal String/Bytes construction APIs

def TVMFFIStringFromByteArray(input: TVMFFIByteArray*, out: TVMFFIAny*) -> int:
    # Reinterprets byte array as UTF-8 string; writes SmallStr (kTVMFFISmallStr=11)
    # or Str object (kTVMFFIStr=65) into out.
    # Invariant: out.type_index must be set to kTVMFFINone before call.
    # Interacts with: TypeTraits<String>::MoveToAny, TVMFFIAny small-string inline storage.

def TVMFFIBytesFromByteArray(input: TVMFFIByteArray*, out: TVMFFIAny*) -> int:
    # Reinterprets byte array as Bytes; writes SmallBytes (kTVMFFISmallBytes=12)
    # or Bytes object (kTVMFFIBytes=66) into out.
    # Invariant: out.type_index must be set to kTVMFFINone before call.
    # Interacts with: TypeTraits<Bytes>::MoveToAny.
```

## Impact
- API: Two new DLL-exported C functions (`TVMFFIStringFromByteArray`, `TVMFFIBytesFromByteArray`) added to stable C ABI.
- Behavioral: Nested containers (list/tuple of Tensor) now correctly propagate device stream into call context; temp object bug fixed so temporaries from inner containers are properly released.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

```c
// C usage:
TVMFFIByteArray input = {data, len};
TVMFFIAny out;
out.type_index = kTVMFFINone;
TVMFFIStringFromByteArray(&input, &out);
// out now holds a String value (SmallStr or heap Str)
```
