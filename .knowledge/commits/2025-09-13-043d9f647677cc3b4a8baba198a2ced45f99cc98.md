# Introduce formal C API for String/Bytes creation and move nested container conversion into C++/Cython

## TL;DR
- Adds two new C API functions (`TVMFFIStringFromByteArray`, `TVMFFIBytesFromByteArray`) that create owned `String`/`Bytes` objects from `TVMFFIByteArray`, replacing the previous approach of passing raw `const char*` pointers (`kTVMFFIRawStr`) or `TVMFFIByteArray*` views from the Cython layer.
- Restructures the Cython argument setter factory to handle `tuple`, `list`, `dict`, and `ObjectConvertible` natively with dedicated setters that recursively call `ffi.Array`/`ffi.Map` constructors via a new `ConstructorCall` path, eliminating the Python-side `_FUNC_CONVERT_TO_OBJECT` callback.
- Introduces `TVMFFIPyConstructorCall` — a constructor-specific call path that propagates torch stream/device/allocator context from nested conversions to the parent call context, fixing stream handling for nested containers containing torch tensors.

## Impact
- API: Two new C ABI functions (`TVMFFIStringFromByteArray`, `TVMFFIBytesFromByteArray`) added to the public C ABI surface. Purely additive.
- Behavioral: (1) Strings are no longer passed as `kTVMFFIRawStr` raw pointers from Python; they are now proper `String`/`SmallStr` objects created via the C API. This changes the type_index seen by C++ callee from `kTVMFFIRawStr` to `kTVMFFIStr`/`kTVMFFISmallStr`. (2) `tuple`/`list`/`dict` arguments are now recursively converted to `Array`/`Map` in Cython before the function call, with stream/device context propagated upward. Previously, conversion used a Python callback `_FUNC_CONVERT_TO_OBJECT`. (3) Temp object recycling bug fixed: uses `TVMFFIObjectDecRef` instead of directly calling deleter.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**String/Bytes passing through FFI (from new test):**
```python
import tvm_ffi

fecho = tvm_ffi.get_global_func("testing.echo")
# Small string (SSO path, <=7 bytes -> SmallStr)
assert fecho("hello") == "hello"
# Large string (heap path -> Str object)
x = "hello" * 100
y = fecho(x)
assert y == x
assert y.__tvm_ffi_object__ is not None  # backed by heap object
# Small bytes
assert fecho(b"hello") == b"hello"
# Large bytes
x = b"hello" * 100
y = fecho(x)
assert y == x
```

**Nested container passing with correct ref counting:**
```python
fecho = tvm_ffi.get_global_func("testing.echo")
use_count = tvm_ffi.get_global_func("testing.object_use_count")
obj = tvm_ffi.convert((1, 2, 3))
assert use_count(obj) == 1
# list/dict are recursively converted to Array/Map in Cython
y = fecho([obj, {"a": 1, "b": obj}])
assert use_count(obj) == 3  # referenced by original + array element + map value
assert use_count(y[1]) == 2  # inner map referenced by y and y[1]
```

**Nested container with torch tensors (preserves stream context):**
