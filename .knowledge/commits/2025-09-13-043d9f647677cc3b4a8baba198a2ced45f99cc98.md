# Introduce formal C ABI string/bytes creation, move nested container conversion to C++, fix temp object recycling

## TL;DR
- Adds two new C ABI functions (`TVMFFIStringFromByteArray`, `TVMFFIBytesFromByteArray`) that construct String/Bytes objects directly from byte arrays, replacing the old approach of passing raw `const char*` (`kTVMFFIRawStr`) or `TVMFFIByteArray*` pointers through the Cython setter layer.
- Moves nested container conversion (list/tuple -> Array, dict -> Map) from the Python `_convert.py` fallback into dedicated Cython setters that call constructor functions recursively, propagating torch CUDA stream/device context through a new `TVMFFIPyConstructorCall` path.
- Fixes a bug where temp FFI objects were recycled by calling the deleter directly instead of going through `TVMFFIObjectDecRef`, which skipped ref-count checks.

## Impact
- API: Two new C ABI symbols (`TVMFFIStringFromByteArray`, `TVMFFIBytesFromByteArray`) added to `c_api.h`. Additive, no breaking changes to existing symbols.
- Behavioral: (1) Strings/bytes are now constructed as proper String/Bytes objects at the setter level instead of being passed as `kTVMFFIRawStr`/`kTVMFFIByteArrayPtr`; callee sees the same types but construction happens earlier. (2) Nested containers (list, tuple, dict) are now converted to Array/Map during argument packing rather than via the Python-level `_FUNC_CONVERT_TO_OBJECT` callback, which means torch CUDA stream context is properly propagated through nested conversions. (3) Temp FFI object recycling uses `TVMFFIObjectDecRef` instead of direct deleter call, fixing potential double-free or use-after-free when ref count > 1.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

### String/bytes passing now constructs proper objects at setter level
```python
import tvm_ffi

fecho = tvm_ffi.get_global_func("testing.echo")
# Small string: SSO path (kTVMFFISmallStr)
assert fecho("hello") == "hello"

# Large string: heap-allocated String object
x = "hello" * 100
y = fecho(x)  # TVMFFIStringFromByteArray creates String, pushed as temp FFI object
assert y == x
assert y.__tvm_ffi_object__ is not None  # backed by ffi::String
```

### Nested containers with torch stream propagation
```python
import tvm_ffi

fecho = tvm_ffi.get_global_func("testing.echo")
use_count = tvm_ffi.get_global_func("testing.object_use_count")
obj = tvm_ffi.convert((1, 2, 3))

# Nested conversion: list/dict are recursively converted via ConstructorCall
# CUDA stream context from torch tensors inside nested containers is propagated
y = fecho([obj, {"a": 1, "b": obj}])
assert use_count(y) == 1
assert use_count(obj) == 3   # referenced by original + inside list + inside dict
assert use_count(y[1]) == 2  # the Map is referenced by y and by y[1]
```
