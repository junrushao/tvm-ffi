# Relax default alignment and contiguous requirements in DLPack import
## TL;DR
- Changes `from_dlpack()` defaults from `require_alignment=8, require_contiguous=True` to `require_alignment=0, require_contiguous=False`, making DLPack tensor import succeed in more settings without manual opt-out.
- Renames parameters from `required_alignment`/`required_contiguous` to `require_alignment`/`require_contiguous` (keyword-argument breaking change).
- Extracts `IsDirectAddressDevice()` as a reusable C++ utility and adds `Tensor::IsAligned()` method so callers can check alignment themselves after import.

## Key Exports

    # Interacts with: IsDirectAddressDevice

class Tensor(ObjectRef):
    # New method (was already wrapping IsContiguous, now also wraps IsAligned):
    def IsAligned(self, alignment: int) -> bool: ...
        # Interacts with: tvm.ffi.IsAligned (free function)

# --- Python (python/tvm_ffi/cython/tensor.pxi) ---

# New signature:

    ext_tensor: object,
    *,

    require_contiguous: bool = False,  # was: required_contiguous=True

    # Invariant: ext_tensor must be a PyCapsule or implement __dlpack__()
    # Extension: callers needing strict checks can pass require_alignment=8, require_contiguous=True

## Impact
- API: **Breaking** for Python callers using `from_dlpack(..., required_alignment=N, required_contiguous=True)` as keyword args -- parameter names changed from `required_*` to `require_*`. Callers passing only positional args or using defaults are unaffected by the rename but will get relaxed behavior.
- Behavioral: Tensors imported via `from_dlpack()` and the auto-conversion path (`convert()`, `make_args`) no longer raise on non-contiguous or unaligned data by default. This makes the FFI more permissive -- callers who relied on the old defaults to reject bad tensors must now check explicitly via `Tensor.IsAligned()` / `Tensor.IsContiguous()`.
- Flags/config: Removes the `__dlpack_auto_import_required_alignment__` module-level constant (was 8). Auto-import in `_convert.py` and `function.pxi` no longer passes any alignment/contiguous requirement.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Tensor / NDArray container** (0006-containers): `Tensor` class, `DLTensor` layout, `IsContiguous` / `IsAligned` free functions.
- **Python bindings DLPack bridge** (0012-python-bindings): Cython `from_dlpack`, `_from_dlpack`, `_from_dlpack_versioned` functions and the `__dlpack__` protocol dispatch.
- **DLPack capsule protocol**: `_c_str_dltensor` / `_c_str_dltensor_versioned` PyCapsule names.
- **Auto-conversion path**: `_convert.py:convert()` and `function.pxi:make_args()` call `from_dlpack` for `__dlpack__`-capable objects and torch tensors.

Design elements this commit produces:
- **`IsDirectAddressDevice()`**: New reusable C++ predicate factored out of `IsAligned`. Classifies devices into direct-address (pointer = real address) vs. indirect-buffer categories.
- **`Tensor::IsAligned()` method**: New convenience method on the `Tensor` ref class, wrapping the free function `tvm::ffi::IsAligned`.
- **Relaxed default import policy**: `from_dlpack` now defaults to no alignment/contiguity checking, shifting responsibility to callers.

## Usage Examples

Before (old API -- would reject non-contiguous tensors):
```python
# Old: from_dlpack enforced alignment=8 and contiguous by default
t = tvm_ffi.from_dlpack(torch_tensor)  # raises if non-contiguous

# Old: explicit keyword args
t = tvm_ffi.from_dlpack(x, required_alignment=16, required_contiguous=True)
```

After (new API -- permissive by default, caller checks explicitly):
```python
# New: from_dlpack accepts any tensor layout by default
t = tvm_ffi.from_dlpack(torch_tensor)  # always succeeds

# New: if strict checks are needed, pass them explicitly
t = tvm_ffi.from_dlpack(x, require_alignment=16, require_contiguous=True)

# New: or check after import using the new Tensor method
t = tvm_ffi.from_dlpack(x)
assert t.IsContiguous()
assert t.IsAligned(8)
```

C++ usage of new utility:
```cpp
#include <tvm/ffi/container/tensor.h>
// Check device type before making alignment assumptions
if (tvm::ffi::IsDirectAddressDevice(tensor.device)) {
  // pointer arithmetic reflects real memory layout
}
// Or use the Tensor method directly
Tensor t = ...;
TVM_FFI_ICHECK(t.IsAligned(64)) << "Need 64-byte alignment for vectorized access";
```
