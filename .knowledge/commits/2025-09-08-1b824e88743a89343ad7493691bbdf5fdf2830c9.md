# Relax Python DLPack import defaults to match C++ (no alignment/contiguity checks) and extract IsDirectAddressDevice utility

## TL;DR
- Changes Python `from_dlpack()` defaults from `required_alignment=8, required_contiguous=True` to `require_alignment=0, require_contiguous=False`, aligning with the C++ `Tensor::FromDLPack()` defaults that were already relaxed.
- Extracts `IsDirectAddressDevice(DLDevice&)` as a public free function in C++ (was inline logic inside `IsAligned`) and adds `Tensor::IsAligned(size_t)` convenience method.
- Removes the Python module-level `__dlpack_auto_import_required_alignment__` constant and all call sites that forwarded it; auto-import now uses the relaxed defaults.

## Key Exports

**Functions (C++, new)**:
```cpp
// include/tvm/ffi/container/tensor.h
inline bool IsDirectAddressDevice(const DLDevice& device);
// Returns true for devices where data pointer address implies alignment
// (device_type <= kDLCUDAHost, kDLCUDAManaged, kDLROCM, kDLROCMHost)
```

**Methods (C++, new)**:
```cpp
// Tensor class, include/tvm/ffi/container/tensor.h
bool Tensor::IsAligned(size_t alignment) const;
// Convenience wrapper: delegates to ffi::IsAligned(*get(), alignment)
```

**Functions (Python, mutated)**:
```python
# python/tvm_ffi/cython/tensor.pxi
def from_dlpack(ext_tensor, *, require_alignment=0, require_contiguous=False) -> Tensor
# Previously: from_dlpack(ext_tensor, *, required_alignment=8, required_contiguous=True)
# Parameter rename: required_alignment -> require_alignment, required_contiguous -> require_contiguous
```

**Constants (Python, removed)**:
- `__dlpack_auto_import_required_alignment__ = 8` in `tensor.pxi` -- deleted entirely.

## Impact
- API: **Breaking Python keyword-argument change**. `required_alignment` renamed to `require_alignment`, `required_contiguous` renamed to `require_contiguous`. Any caller using `from_dlpack(..., required_alignment=N)` or `from_dlpack(..., required_contiguous=True)` as keyword arguments will get a `TypeError`. The default behavior changes from strict (8-byte alignment + contiguity check) to permissive (no checks).
- Behavioral: DLPack imports via Python auto-conversion (`convert()`, Cython `make_args`) no longer reject unaligned or non-contiguous tensors. Users who need these checks must pass explicit `require_alignment=N` and `require_contiguous=True`.
- Flags/config: `__dlpack_auto_import_required_alignment__` module constant removed; no replacement.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **DLPack import protocol** (`from_dlpack`, `Tensor::FromDLPack`) -- the existing C++ defaults already used `require_alignment=0, require_contiguous=false`; this commit aligns Python to match. See [0008-containers.md](../designs/0008-containers.md), NDArray section.
- **`IsAligned` / `IsContiguous` free functions** (`tensor.h`) -- existing utilities for checking DLTensor alignment and contiguity.
- **Auto-DLPack conversion path** (`_convert.py`, `function.pxi`) -- the implicit DLPack conversion triggered when passing `__dlpack__`-supporting objects to FFI calls.

Design elements this commit produces:
- **`IsDirectAddressDevice(DLDevice&)`** -- new public utility extracted from `IsAligned`. Determines whether a device uses direct memory addressing (where pointer arithmetic implies alignment) versus indirect buffer addressing. Useful for any downstream code that needs device-aware alignment reasoning.
- **`Tensor::IsAligned(size_t)`** -- new convenience method exposing alignment checking at the `Tensor` ref-wrapper level (previously only available as a free function on raw `DLTensor`).

## Usage Examples

**C++ -- checking alignment and device type after import**:
```cpp
#include <tvm/ffi/container/tensor.h>
using namespace tvm::ffi;

// Check if a device uses direct addressing
DLDevice dev{kDLCUDA, 0};
bool direct = IsDirectAddressDevice(dev);  // true

// Import tensor and check alignment
Tensor t = Tensor::FromDLPack(managed_tensor);  // no alignment/contiguity check by default
if (!t.IsAligned(64)) {
  // handle misaligned tensor for vectorized kernels
}
```

**Python -- before vs after for auto-import callers**:
```python
# Before (strict by default, could throw on unaligned/non-contiguous):
#   from_dlpack(torch_tensor, required_alignment=8, required_contiguous=True)

# After (permissive by default):
from tvm_ffi import from_dlpack
t = from_dlpack(torch_tensor)  # always succeeds, no alignment/contiguity check

# Explicit strict import when needed:
t = from_dlpack(torch_tensor, require_alignment=8, require_contiguous=True)
```
