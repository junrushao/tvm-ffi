# Remove BUILD_WITH_INSTALL_RPATH from Cython RPATH config for scikit-build-core packaging
## TL;DR
- Removes `BUILD_WITH_INSTALL_RPATH ON` from the `tvm_ffi_cython` target RPATH properties on both macOS and Linux, simplifying each to a single-line `INSTALL_RPATH` setting.
- Part of the scikit-build-core packaging flow fixes (follow-up to PR #18239).

None

## Impact
- API: none
- Behavioral: RPATH is now applied at install time (CMake default) rather than at build time; this is the correct behavior for scikit-build-core which controls the install step.
