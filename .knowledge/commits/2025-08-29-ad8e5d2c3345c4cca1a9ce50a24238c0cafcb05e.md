# Remove BUILD_WITH_INSTALL_RPATH from Cython target in CMakeLists.txt
## TL;DR
- Removed `BUILD_WITH_INSTALL_RPATH ON` from `tvm_ffi_cython` target properties on both macOS and Linux, keeping only the `INSTALL_RPATH` setting.
- Follows up on PR #18239 to fix packaging issues encountered when using scikit-build-core.
