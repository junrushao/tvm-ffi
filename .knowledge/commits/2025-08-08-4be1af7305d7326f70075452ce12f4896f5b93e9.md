# Remove Downcast from FFI, keeping cast.h as a minimal GetRef/GetObjectPtr utility

## TL;DR
- Removes all four `Downcast` overloads (`BaseRef`, `const Any&`, `Any&&`, `const std::optional<Any>&`) from `include/tvm/ffi/cast.h` and the `using ffi::Downcast;` namespace alias. The functionality was redundant with `Any::cast<T>()` and is moved to a `node` module outside the FFI crate.
- Adds `using ffi::GetObjectPtr;` to the `tvm` namespace (previously not aliased).
- Relaxes `GetRef` from `TVM_FFI_INLINE` (force-inline) to plain `inline`.
- Removes unused includes (`<tvm/ffi/dtype.h>`, `<tvm/ffi/error.h>`, `<utility>`) from `cast.h`.
- Updates the test in `test_string.cc` to use `r.cast<String>()` instead of `Downcast<String>(r)`.

## Key Exports

**Functions removed from `tvm::ffi` (and `tvm` namespace)**:
- `Downcast<SubRef>(BaseRef ref)` -- typed downcast for ObjectRef subclasses with IsInstance check
- `Downcast<T>(const Any& ref)` -- delegates to `ref.cast<T>()`
- `Downcast<T>(Any&& ref)` -- delegates to `std::move(ref).cast<T>()`
- `Downcast<OptionalType>(const std::optional<Any>& ref)` -- optional-aware downcast

**Functions modified**:
- `GetRef<RefType>(const ObjectType* ptr)` -- changed from `TVM_FFI_INLINE` to `inline`

**Namespace aliases changed in `cast.h`**:
- Removed: `using ffi::Downcast;`
- Added: `using ffi::GetObjectPtr;` (now accessible as `tvm::GetObjectPtr`)

## Impact
- API: `tvm::Downcast` and `tvm::ffi::Downcast` no longer exist in the FFI headers. All call sites must migrate to `Any::cast<T>()` (for `Any`-based downcasts) or the `Downcast` in the external `node` module (for `ObjectRef`-based downcasts). The `Downcast<String>(Any)` overloads were thin wrappers around `Any::cast` anyway.
- ABI: None. No C ABI symbols changed; these were header-only templates.
- Behavioral: None. The replacement `Any::cast<T>()` has the same runtime semantics (type check + throw TypeError on mismatch).
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Any::cast<T>()** (`.knowledge/designs/any-system.md`) -- the conversion-enabled access method that subsumes all `Downcast` overloads for `Any` arguments.
- **Namespace aliasing convention** -- the `using ffi::X;` pattern in `namespace tvm` established in 16e9f0a.
- **GetRef / GetObjectPtr** (`.knowledge/designs/object-system.md`) -- retained utilities for constructing refs from raw object pointers.

Design elements this commit produces:
- **FFI minimality principle** -- explicitly scopes `cast.h` to only `GetRef` and `GetObjectPtr` as "extra casting helpers", removing backward-compatibility API (`Downcast`) that duplicated `Any::cast`. The commit message articulates this as "ffi part contains minimal set of implementations."

## Usage Examples

### Before (using Downcast)
```cpp
#include <tvm/ffi/cast.h>
Any r = some_string;
String s = Downcast<String>(r);           // delegates to r.cast<String>()
String s2 = tvm::Downcast<String>(r);     // same via namespace alias
```

### After (using Any::cast directly)
```cpp
#include <tvm/ffi/any.h>
Any r = some_string;
String s = r.cast<String>();              // direct, no wrapper
```
