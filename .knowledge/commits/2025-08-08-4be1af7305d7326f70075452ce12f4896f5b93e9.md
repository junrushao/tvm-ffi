# Remove Downcast from tvm::ffi, directing callers to Any.cast<T>() instead

## TL;DR
- Removes all four `Downcast` overloads from `include/tvm/ffi/cast.h` and the `using ffi::Downcast` re-export in the `tvm` namespace; canonical downcasting is now `Any.cast<T>()` from `any.h`.
- Drops unused `#include <tvm/ffi/dtype.h>` and `#include <tvm/ffi/error.h>` from `cast.h` (they were only needed by Downcast's error-throwing path).
- Updates `test_string.cc`: `Downcast<String>(r)` → `r.cast<String>()`, demonstrating the migration pattern.

## Key Exports

```python
# REMOVED from include/tvm/ffi/cast.h (was tvm::ffi::Downcast / tvm::Downcast):

# Overload 1 — ObjectRef-to-ObjectRef downcast
# def Downcast(ref: BaseRef) -> SubRef:  ...
#   Checked isinstance, raised TypeError on mismatch or nullptr-to-non-nullable.
#   Interacts with: Object.IsInstance(), ObjectPtr, Optional, is_optional_type_v

# Overload 2 — Any-to-T downcast (copy)
# def Downcast(ref: const Any&) -> T:  ...
#   Was: ref.cast<T>()
#   Interacts with: Any.cast<T>() in any.h (0001)

# Overload 3 — Any-to-T downcast (move)
# def Downcast(ref: Any&&) -> T:  ...
#   Was: std::move(ref).cast<T>()
#   Interacts with: Any.cast<T>() in any.h (0001)

# Overload 4 — optional<Any> to OptionalType
# def Downcast(ref: const std::optional[Any]&) -> OptionalType:  ...
#   Was: ref.has_value() ? (*ref).cast<OptionalType>() : OptionalType(nullopt)
#   Interacts with: Any.cast<T>() in any.h (0001)

# REMAINING in include/tvm/ffi/cast.h:

def GetRef(ptr: ObjectType*) -> RefType: ...
    # Invariant: RefType::ContainerType must be base of ObjectType (static_assert)
    # Interacts with: ObjectUnsafe::ObjectPtrFromUnowned (object.h, 0002)

def GetObjectPtr(ptr: ObjectType*) -> ObjectPtr[BaseType]: ...
    # Invariant: BaseType must be base of ObjectType (static_assert)
    # Interacts with: ObjectUnsafe::ObjectPtrFromUnowned (object.h, 0002)

# tvm namespace re-exports (after this commit):
# using ffi::GetObjectPtr   ← newly added re-export
# using ffi::GetRef         ← unchanged
# (using ffi::Downcast REMOVED)
```

## Impact
- API: **Breaking** — `tvm::Downcast<T>` and `tvm::ffi::Downcast<T>` are gone. All callers must migrate to `Any.cast<T>()` (for Any values) or `ObjectRef.as<T>()` / direct `GetRef` usage. The commit message notes `Downcast` is re-provided in the `tvm::node` layer for backward compat.
- Behavioral: None for callers that migrate; `Any.cast<T>()` has identical semantics for the Any-to-T overloads. The ObjectRef-to-ObjectRef overload's null-handling logic may differ slightly if `node` layer re-implements it.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **0001-any-anyview-value-system** (`Any.cast<T>()`) — the three-tier conversion model is the direct replacement for `Downcast`; this commit forces all downcast traffic through the canonical path.
- **0002-object-system** (`ObjectRef`, `ObjectPtr`, `IsInstance`) — `GetRef`/`GetObjectPtr` remain in `cast.h` and still use `ObjectUnsafe` internals.

Design elements this commit produces:
- None — removes a shim rather than adding a new design element.

## Usage Examples

Before/after migration pattern (from `tests/cpp/test_string.cc`):

```cpp
// BEFORE
#include <tvm/ffi/cast.h>
Any r = s;
String s2 = Downcast<String>(r);   // tvm::Downcast delegated to r.cast<String>()

// AFTER
// No cast.h include needed for this use case
Any r = s;
String s2 = r.cast<String>();      // Direct Any.cast<T>() — canonical path
```
