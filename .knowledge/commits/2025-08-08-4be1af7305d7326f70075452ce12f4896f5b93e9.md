# Move Downcast out of ffi/cast.h, consolidate on Any::cast

## TL;DR
- Removes all 4 `Downcast` overloads from `include/tvm/ffi/cast.h` and the `using ffi::Downcast` namespace re-export, moving them out of the FFI layer (to `node/` in the wider TVM repo) to keep the FFI minimal.
- `Downcast` was redundant with `Any::cast<T>()` — callers should use `.cast<T>()` instead.
- Adds the previously missing `using ffi::GetObjectPtr` namespace re-export to `tvm::`.

## Key Exports

After this commit, `cast.h` retains only two helpers plus the new re-export:

```python
# include/tvm/ffi/cast.h — remaining public API

def GetRef(ptr: ObjectType) -> RefType:
    """Wrap a raw Object pointer into its corresponding ObjectRef.
    # Invariant: ObjectType must be a base of RefType::ContainerType
    # Interacts with: ObjectRef (all ref wrappers), details::ObjectUnsafe
    """
    ...

def GetObjectPtr(ptr: ObjectType) -> ObjectPtr[BaseType]:
    """Get ObjectPtr from a raw object pointer (non-owning).
    # Invariant: ObjectType must be a base of BaseType
    # Interacts with: details::ObjectUnsafe::ObjectPtrFromUnowned
    """
    ...

# Namespace re-exports into tvm:: (cast.h)
# tvm::GetRef       = tvm::ffi::GetRef
# tvm::GetObjectPtr = tvm::ffi::GetObjectPtr   # NEW in this commit

# REMOVED:
# tvm::Downcast (4 overloads) — use Any::cast<T>() or move to tvm/node/ layer
```

## Impact
- API: Removes `tvm::Downcast` from the FFI public API. Callers must migrate to `Any::cast<T>()` or use the `Downcast` from `tvm/node/` (outside this repo). Adds `tvm::GetObjectPtr` re-export.
- Behavioral: `GetRef` changes from `TVM_FFI_INLINE` to plain `inline` — no semantic difference but may affect compiler inlining decisions at boundary.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Any::cast<T>()** — the primary type-safe extraction method on `Any`/`AnyView`, which `Downcast` was duplicating. See [0003-any-system.md](../designs/0003-any-system.md).
- **ObjectRef / ObjectPtr** — the ref-counted wrapper pattern. `GetRef` and `GetObjectPtr` convert raw pointers to these wrappers. See [0002-object-system.md](../designs/0002-object-system.md).
- **details::ObjectUnsafe** — internal unsafe operations for constructing ObjectPtr without incrementing refcount.

Design elements this commit produces:
- **`tvm::GetObjectPtr` re-export** — newly exposed at `tvm::` namespace level (was previously only at `tvm::ffi::GetObjectPtr`).

## Usage Examples

Before (using removed `Downcast`):
```cpp
#include <tvm/ffi/cast.h>
String s{"hello"};
Any r = s;
String s2 = Downcast<String>(r);  // calls Downcast<T>(const Any&)
```

After (using `Any::cast<T>()`):
```cpp
#include <tvm/ffi/any.h>
String s{"hello"};
Any r = s;
String s2 = r.cast<String>();  // direct, no Downcast needed
```
