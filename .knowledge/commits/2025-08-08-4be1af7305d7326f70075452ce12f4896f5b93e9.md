# Remove Downcast from FFI cast.h to minimize core FFI surface
## TL;DR
- Removes all four `Downcast` template overloads from `include/tvm/ffi/cast.h` and the `using ffi::Downcast` namespace alias from `tvm`. The functionality is moved out of FFI to the parent TVM `node/` layer for backward compatibility.
- Replaces the one in-tree test usage (`Downcast<String>(r)` in `test_string.cc`) with the canonical `r.cast<String>()` method, demonstrating that `Any::cast<T>()` is the preferred FFI-level API.
- Cleans up `cast.h`: removes now-unused includes (`dtype.h`, `error.h`, `<utility>`), changes `GetRef` from `TVM_FFI_INLINE` to plain `inline`, adds `using ffi::GetObjectPtr` to the `tvm` namespace, and updates the file docstring from "Value casting support" to "Extra value casting helpers".

## Impact
- API: Breaking for any downstream C++ code calling `tvm::Downcast` or `tvm::ffi::Downcast` via the FFI header. Callers must either (a) use `Any::cast<T>()` / `Any::try_cast<T>()` directly, or (b) include the relocated header in the parent TVM repo (`tvm/node/` layer). Within the FFI repo itself, only one test needed updating.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Any/AnyView type erasure system** ([`.knowledge/designs/0002-any-system.md`](../designs/0002-any-system.md)): The `Downcast<T>(const Any&)` and `Downcast<T>(Any&&)` overloads were thin wrappers around `Any::cast<T>()`. The removal confirms `cast<T>()` as the single canonical lenient-conversion API at the FFI level (see ADR [`.knowledge/ADRs/0008-as-strict-cast-lenient.md`](../ADRs/0008-as-strict-cast-lenient.md)).
- **Object system** ([`.knowledge/designs/0003-object-system.md`](../designs/0003-object-system.md)): The `Downcast<SubRef>(BaseRef)` overload performed a runtime `IsInstance` check and then moved the `ObjectPtr`. This is the object-system type-checking machinery, which remains available via `ObjectRef::as<T>()` and `Any::cast<T>()`.
- **`GetRef` / `GetObjectPtr` utilities** (remain in `cast.h`): These raw-pointer-to-ref-wrapper helpers are retained as core FFI utilities. `GetObjectPtr` is newly exposed to `tvm::` namespace via `using ffi::GetObjectPtr`.

Design elements this commit produces:
- **Minimal FFI surface principle**: This commit explicitly enforces the design principle that the FFI layer should contain the "minimal set of implementations." `Downcast` was a convenience wrapper with duplicated functionality (`Any::cast<T>()`), so it is pushed to a higher layer (`node/`). This is consistent with the extra-tier pattern ([`.knowledge/designs/0011-extra-api-tier.md`](../designs/0011-extra-api-tier.md)) where non-core C++ APIs are separated from core FFI.
- **`cast.h` scope reduction**: After this commit, `cast.h` contains only `GetRef` and `GetObjectPtr` -- two low-level utilities for converting raw `Object*` pointers to ref-counted wrappers. The file's role is now precisely scoped.
