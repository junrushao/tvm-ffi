# Remove Downcast from FFI cast.h, consolidating on Any::cast<T>()
## TL;DR
- Removes all four `Downcast` template overloads from `include/tvm/ffi/cast.h` and the `using ffi::Downcast` namespace alias, shrinking the FFI API surface.
- The `Downcast` overloads for `Any`/`Any&&`/`std::optional<Any>` were pure wrappers around `Any::cast<T>()` and therefore redundant. The `ObjectRef`-to-`ObjectRef` overload is relocated outside FFI (to `node/`).
- Adds the previously missing `using ffi::GetObjectPtr` alias to `tvm` namespace. Changes `GetRef` linkage from `TVM_FFI_INLINE` to `inline`.

## Key Exports

**Removed from `tvm::ffi` (and `tvm::` namespace)**:

| Template | Signature | Replacement |
|----------|-----------|-------------|
| `Downcast<SubRef, BaseRef>` | `SubRef Downcast(BaseRef ref)` | Relocated outside FFI (to `node/`) |
| `Downcast<T>` | `T Downcast(const Any& ref)` | `ref.cast<T>()` |
| `Downcast<T>` | `T Downcast(Any&& ref)` | `std::move(ref).cast<T>()` |
| `Downcast<OptionalType>` | `OptionalType Downcast(const std::optional<Any>& ref)` | `(*ref).cast<OptionalType>()` |

**Added to `tvm::` namespace**:
- `using ffi::GetObjectPtr` -- was previously absent from the namespace alias block.

**Changed**:
- `GetRef<RefType, ObjectType>`: linkage changed from `TVM_FFI_INLINE` to plain `inline`.

**Removed includes from `cast.h`**:
- `<tvm/ffi/dtype.h>`, `<tvm/ffi/error.h>`, `<utility>` -- no longer needed after removing `Downcast`.

## Impact
- API: **Breaking** -- any code calling `tvm::Downcast` or `tvm::ffi::Downcast` via `cast.h` will fail to compile. Callers must switch to `Any::cast<T>()` for value conversions, or include the relocated header (outside FFI) for `ObjectRef`-to-`ObjectRef` downcasts.
- Behavioral: None -- `Downcast`'s Any overloads were exact delegation to `Any::cast<T>()`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Any value system** ([0002-any-value-system.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0002-any-value-system.md)) -- `Any::cast<T>()` is the canonical replacement for the removed `Downcast<T>(Any)` overloads, as established by [ADR 0005-as-vs-cast-semantic-split](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/ADRs/0005-as-vs-cast-semantic-split.md).
- **Object system** ([0003-object-system.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0003-object-system.md)) -- `ObjectRef`, `ObjectPtr`, `Object` remain used by `GetRef`/`GetObjectPtr`.

Design elements this commit produces:
- **Slimmed `cast.h` contract**: After this commit, `tvm/ffi/cast.h` contains only two utilities: `GetRef<RefType>(const ObjectType* ptr)` and `GetObjectPtr<BaseType>(ObjectType* ptr)`. Both convert raw object pointers to ref-counted wrappers. All type-coercing conversion logic is consolidated in `Any::cast<T>()`.

## Usage Examples

Migration pattern (from the test change in `tests/cpp/test_string.cc`):

```cpp
// Before: Downcast convenience wrapper
#include <tvm/ffi/cast.h>
Any r = String("hello");
String s = Downcast<String>(r);

// After: use Any::cast<T>() directly
#include <tvm/ffi/any.h>
Any r = String("hello");
String s = r.cast<String>();
```
