# Remove Downcast from FFI cast.h, consolidate type casting to Any.cast

## TL;DR
- Removes the entire `Downcast` template family (4 overloads) from `include/tvm/ffi/cast.h` and the `using ffi::Downcast` namespace re-export; callers should use `Any::cast<T>()` instead.
- Strips `cast.h` dependencies on `<tvm/ffi/dtype.h>`, `<tvm/ffi/error.h>`, and `<utility>`, leaving only `GetRef` and `GetObjectPtr` as the file's API surface.
- Changes `GetRef` linkage from `TVM_FFI_INLINE` (forced always-inline) to plain `inline`.

## Key Exports

After this commit, `cast.h` exports exactly two helpers (unchanged semantics, reduced header weight):

```python
# tvm/ffi/cast.h — remaining public API

def GetRef(ptr: ObjectType) -> RefType:
    """Wrap a raw object pointer into a ref-counted reference type.
    Invariant: ptr must be non-null unless RefType is Optional or nullable.
    Interacts with: ObjectUnsafe.ObjectPtrFromUnowned, ObjectPtr<T>
    """
    ...

def GetObjectPtr(ptr: ObjectType) -> ObjectPtr[BaseType]:
    """Get an ObjectPtr from a raw pointer (non-owning bump).
    Invariant: BaseType must be a base of ObjectType.
    Interacts with: ObjectUnsafe.ObjectPtrFromUnowned
    """
    ...

# REMOVED from ffi (moved to node/):
# def Downcast(ref: BaseRef) -> SubRef: ...         # ObjectRef overload
# def Downcast(ref: Any) -> T: ...                  # Any overload (delegated to Any.cast<T>)
# def Downcast(ref: Any&&) -> T: ...                # Any rvalue overload
# def Downcast(ref: Optional[Any]) -> OptionalType: ...  # Optional overload
```

## Impact
- API: `tvm::Downcast` and `tvm::ffi::Downcast` are no longer available from `#include <tvm/ffi/cast.h>`. Callers in the wider TVM codebase must either include the new node-level header or migrate to `Any::cast<T>()`.
- Behavioral: None — `Downcast` for `Any` arguments was already a thin wrapper around `Any::cast<T>()`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Any::cast<T>()** (`0002-ffi-any-value-system`): The test change (`test_string.cc`) replaces `Downcast<String>(r)` with `r.cast<String>()`, confirming `Any::cast` is the canonical casting API.
- **ObjectUnsafe::ObjectPtrFromUnowned** (`0003-ffi-object-system`): Used internally by `GetRef` and `GetObjectPtr`.

Design elements this commit produces/mutates:
- **cast.h scope reduction**: `cast.h` is now strictly a utility header for raw-pointer-to-ref wrapping (`GetRef`, `GetObjectPtr`). The `Downcast` family is removed from FFI scope, and the description changes from "Value casting support" to "Extra value casting helpers". This narrows the FFI layer's responsibility.
- **GetRef linkage change**: `TVM_FFI_INLINE` (forced always-inline) replaced with plain `inline`, relaxing the inlining hint. This is a minor ABI-surface change for header-only code.
- **Namespace re-exports**: `using ffi::Downcast` removed; `using ffi::GetObjectPtr` added (was previously missing).

## Usage Examples

Before (pre-commit):
```cpp
#include <tvm/ffi/cast.h>
Any r = some_string;
String s = Downcast<String>(r);  // used ffi::Downcast
```

After (post-commit):
```cpp
#include <tvm/ffi/any.h>
Any r = some_string;
String s = r.cast<String>();     // use Any::cast directly
```
