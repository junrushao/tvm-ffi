# Remove Downcast() overloads from ffi/cast.h; callers should use Any::cast<T>() directly

## TL;DR
- Removes all four `Downcast` overloads (ObjectRef, Any const&, Any&&, optional<Any>) from `include/tvm/ffi/cast.h` because they duplicated functionality already in `Any::cast<T>()`.
- The `using ffi::Downcast` re-export in `namespace tvm` is also removed; `using ffi::GetObjectPtr` and `using ffi::GetRef` are retained.
- The file's doc comment is updated from "Value casting support" to "Extra value casting helpers", signalling reduced scope.
- One test updated: `Downcast<String>(r)` → `r.cast<String>()`.

## Key Exports

```python
# cast.h AFTER this commit — reduced to two helpers only

def GetRef(ptr: ObjectType*) -> RefType: ...
# Invariant: RefType::ContainerType must be base of ObjectType (static_assert).
# Interacts with: ObjectUnsafe::ObjectPtrFromUnowned, Optional, ObjectRef
# Unchanged by this commit.

def GetObjectPtr(ptr: ObjectType*) -> ObjectPtr[BaseType]: ...
# Invariant: BaseType must be base of ObjectType (static_assert).
# Interacts with: ObjectUnsafe::ObjectPtrFromUnowned
# Unchanged by this commit; but this commit adds `using ffi::GetObjectPtr` to namespace tvm.

# REMOVED (four overloads):
# def Downcast(ref: BaseRef) -> SubRef: ...    # ObjectRef overload
# def Downcast(ref: Any) -> T: ...             # const Any& overload → was Any::cast<T>()
# def Downcast(ref: Any) -> T: ...             # Any&& overload → was std::move(ref).cast<T>()
# def Downcast(ref: optional[Any]) -> OptionalType: ...  # optional overload
# using ffi::Downcast was removed from tvm namespace
# using ffi::GetObjectPtr was ADDED to tvm namespace
```

## Impact
- API: **Breaking removal** — `tvm::Downcast` and `ffi::Downcast` are no longer available after this commit. All callers in the TVM codebase (outside `ffi/`) that used `Downcast<T>(any_value)` must migrate to `any_value.cast<T>()`. The ObjectRef overload (`Downcast<SubRef>(base_ref)`) is documented as moved to `include/tvm/node/` for backward compat.
- Behavioral: None — `Downcast(any)` delegated to `any.cast<T>()` anyway; semantics are identical.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **0003-any-anyview** (`include/tvm/ffi/any.h`) — `Any::cast<T>()` / `Any::cast<T>() &&` are the coercing cast methods that replace `Downcast`. The strict/coercing split (commit 37a2e7c5 in the design index) is the underlying reason `Downcast` on `Any` was redundant.
- **0002-object-system** (`include/tvm/ffi/object.h`) — `ObjectRef`, `ObjectPtr`, `ObjectUnsafe::ObjectPtrFromObjectRef` were used by the removed ObjectRef `Downcast` overload.

Design elements this commit produces:
- Trimmed scope of `cast.h`: file is now solely "extra helpers" (`GetRef`, `GetObjectPtr`); `Downcast` is no longer part of `ffi::` namespace. This is a **mutation** of the cast subsystem's contract — callers must use `Any::cast<T>()` for type-erased casts and the node-level `Downcast` (moved outside `ffi/`) for ObjectRef upcasts.

## Usage Examples

Before/after showing the corrected usage pattern:

```cpp
// BEFORE (removed):
#include <tvm/ffi/cast.h>
Any r = some_string;
String s2 = Downcast<String>(r);  // delegated to r.cast<String>() internally

// AFTER (correct):
#include <tvm/ffi/any.h>
Any r = some_string;
String s2 = r.cast<String>();     // direct — no cast.h needed for Any casts

// GetRef / GetObjectPtr (unchanged, still in cast.h):
#include <tvm/ffi/cast.h>
MyNodeObj* raw = ...;
MyNode ref = GetRef<MyNode>(raw);   // wraps raw ptr in ObjectRef with ref-count bump
```
