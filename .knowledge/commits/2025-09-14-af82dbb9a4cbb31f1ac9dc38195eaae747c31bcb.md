# Fix __name__ always set on reflection-generated method wrappers, regardless of whether a doc string is present

## TL;DR

- In `_add_class_attrs_by_reflection` (`function.pxi`), `method_pyfunc.__name__ = name` was incorrectly nested inside `if doc is not None:`, so methods without doc strings never got their `__name__` attribute set.
- The fix unindents the assignment one level so it executes unconditionally for every reflected method.
- Methods with no doc string now correctly report their name (e.g., in tracebacks, `repr`, `help()`).

## Key Exports

```python
# Bugfix — no new API surface. Existing function contract is restored:

def _add_class_attrs_by_reflection(type_index: int, cls: type) -> type:
    """Attach reflected fields and methods to a Python class.

    For each method slot:
      - Wraps with staticmethod or _member_method_wrapper
      - Sets .__doc__ if the C++ reflection provides a doc string
      - Sets .__name__ = name  ← unconditionally (this was the bug: was inside if doc is not None)
      - Skips if cls already has an attribute with that name
    # Invariant: every method attached by this function must have __name__ set
    # Interacts with: TVMFFITypeMetadata.methods[], _member_method_wrapper, setattr(cls, name, ...)
    """
    ...
```

## Impact

- API: none — `_add_class_attrs_by_reflection` is an internal helper, not public API.
- Behavioral: methods registered via C++ reflection that lack a doc string now correctly expose `__name__`. Before the fix, such methods would show as `<lambda>` or the wrapper's internal name in tracebacks and introspection.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**Before (broken):** method with no doc string gets `__name__` from wrapper, not from reflection.

```python
# C++ registers method "compute" with no doc string
# After _add_class_attrs_by_reflection:
cls.compute.__name__  # was: "<lambda>" or "_member_method_wrapper.<locals>.wrapper"
```

**After (fixed):** `__name__` is always set regardless of doc presence.

```python
# C++ registers method "compute" with no doc string
# After _add_class_attrs_by_reflection:
cls.compute.__name__  # now: "compute"
```
