# Fix reflected method `__name__` always being set regardless of docstring presence

## TL;DR
- Fixed an indentation bug in `_add_class_attrs_by_reflection` where `method_pyfunc.__name__ = name` was incorrectly nested inside `if doc is not None:`, causing reflected methods without docstrings to have incorrect `__name__` attributes.
- The one-line de-indent ensures every reflected method gets its correct name, regardless of whether it has a docstring.

## Key Exports

None -- no new API surface. Existing behavior of `_add_class_attrs_by_reflection` is corrected.

## Impact
- API: none -- no signature changes.
- Behavioral: Reflected methods without docstrings now correctly report their `__name__`. Previously, methods registered via `ObjectDef<T>.def_()` or `def_static()` without a docstring would retain the wrapper function's default name instead of the C++ method name. This affects `repr()`, `help()`, debugging tools, and any code inspecting `method.__name__`.
- Flags/config: none.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- **Reflection method attachment** (`_add_class_attrs_by_reflection` in `function.pxi`): The Cython function that iterates over `TVMFFIMethodInfo` entries from the C++ type table and attaches them as Python class attributes. See [0012-python-bindings.md](../designs/0012-python-bindings.md) and [0008-reflection.md](../designs/0008-reflection.md).
- **Method flags** (`kTVMFFIFieldFlagBitMaskIsStaticMethod`): Determines whether a reflected method is wrapped via `staticmethod()` or `_member_method_wrapper()`.

Design elements this commit produces:
- None -- purely corrective.

## Usage Examples

Before (buggy): reflected methods without docstrings had wrong `__name__`:
```python
# C++ side: registers method without docstring
# refl::ObjectDef<MyObj>().def_("compute", &MyObj::Compute)
#
# Python side:
obj = MyObj()
print(obj.compute.__name__)  # BUG: prints wrapper name, not "compute"
```

After (fixed): `__name__` is always set correctly:
```python
# Same C++ registration
obj = MyObj()
print(obj.compute.__name__)  # FIXED: prints "compute"
```
