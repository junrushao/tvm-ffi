# Initial bringup of experimental Rust bindings for the TVM FFI ABI
## TL;DR
- Introduces a complete Rust crate workspace (`rust/`) with three crates: `tvm-ffi-sys` (raw C ABI), `tvm-ffi-macros` (proc macros), and `tvm-ffi` (safe ergonomic API).
- Mirrors the C++/Python FFI surface in Rust: `Any`/`AnyView`, `ObjectArc<T>`/`ObjectRef`, `Function`, `String`, `Bytes`, `Shape`, `Tensor`, `Error`, `Module`, plus `DLDataType`/`DLDevice` support.
- Adds CI job for Rust tests (`cargo test` in the `rust/` directory, after Python package install).

### Crate: `tvm-ffi-macros` (proc macros)

**Derive Macros**:
- `#[derive(Object)]` -- Generates `unsafe impl ObjectCore for T` with `TYPE_KEY`, `type_index()`, `object_header_mut()`. Requires `#[type_key = "..."]` attribute; accepts optional `#[type_index(...)]`.
- `#[derive(ObjectRef)]` -- Generates `unsafe impl ObjectRefCore for T` + `unsafe impl AnyCompatible for T` + `impl_try_from_any!` + `impl_arg_into_ref!` + `impl_into_arg_holder_default!`. Expects first field `data: ObjectArc<ContainerType>`.

### Crate: `tvm-ffi` (safe ergonomic API)

**Traits**:
- `AnyCompatible` -- unsafe trait: `copy_to_any_view`, `move_to_any`, `check_any_strict`, `copy_from_any_view_after_check`, `move_from_any_after_check`, `try_cast_from_any_view`, `type_str`. Implemented for: `bool`, `i8-i64`, `u8-u64`, `isize`, `usize`, `f32`, `f64`, `()`, `*mut c_void`, `String`, `Bytes`, `ObjectRef`, `DLDataType`, `DLDevice`, `Option<T: AnyCompatible>`.
- `ObjectCore` -- unsafe trait: `TYPE_KEY`, `type_index() -> i32`, `object_header_mut(&mut Self) -> &mut TVMFFIObject`
- `ObjectCoreWithExtraItems` -- unsafe trait: `ExtraItem`, `extra_items_count`, `extra_items`, `extra_items_mut`
- `ObjectRefCore` -- unsafe trait: `ContainerType`, `data`, `into_data`, `from_data`
- `AsPackedCallable<I, O>` -- trait for converting typed Rust functions to packed calling convention. Implemented for `Fn(T0, ..., TN) -> Result<Out>` up to 8 args.
- `TupleAsPackedArgs` -- trait: `LEN`, `fill_any_view`. Implemented for tuples up to 8 elements.
- `IntoArgHolder` -- trait for converting arg types to canonical holding types (e.g., `&str` -> `String`).
- `IntoArgHolderTuple` -- trait to apply `IntoArgHolder` across a tuple.
- `ArgIntoRef` -- trait to turn argument type to reference type.
- `NDAllocator` -- unsafe trait: `MIN_ALIGN`, `alloc_data`, `free_data`. For custom tensor memory allocation.
- `DLDataTypeExt` -- trait: `to_string() -> String`, `try_from_str(&str) -> Result<DLDataType>`.
- `AsDLDataType` -- trait: `DL_DATA_TYPE: DLDataType`. Implemented for `i8-i64`, `u8-u64`, `f32`, `f64`.
- `DLTensorExt` -- trait: `numel() -> usize`, `item_size() -> usize`.

**Types/Structs**:
- `Any` -- owning type-erased value. Methods: `new()`, `type_index()`, `try_as<T>()`, `debug_strong_count()`, `as_data_ptr()`, `into_raw_ffi_any()`, `from_raw_ffi_any()`. Implements `Clone` (IncRef), `Drop` (DecRef), `Default`, `From<T: AnyCompatible>`, `From<AnyView>`.
- `AnyView<'a>` -- non-owning type-erased view. Methods: `new()`, `type_index()`, `try_as<T>()`, `debug_strong_count()`. Implements `Copy`, `Clone`, `Default`, `From<&'a T: AnyCompatible>`, `From<&'a Any>`.
- `TryFromTemp<T>` -- helper to work around orphan rule for `TryFrom<AnyView/Any>`.
- `ObjectArc<T: ObjectCore>` -- intrusive refcounted smart pointer (like C++ `ObjectPtr<T>`). Methods: `new(data)`, `new_with_extra_items(data)`, `from_raw(*const T)`, `into_raw(Self) -> *const T`, `as_raw(&Self) -> *const T`, `as_raw_mut(&Self) -> *mut T`, `strong_count(&Self)`, `weak_count(&Self)`. Implements `Deref`, `DerefMut`, `Drop` (DecRef), `Clone` (IncRef), `Send + Sync`.
- `Object` -- base object `{header: TVMFFIObject}`.
- `ObjectRef` -- base ref wrapper `{data: ObjectArc<Object>}`.
- `Function` -- `{data: ObjectArc<FunctionObj>}`. Methods: `call_packed(&[AnyView]) -> Result<Any>`, `call_tuple(TupleType) -> Result<Any>`, `call_tuple_with_len<LEN>(TupleType) -> Result<Any>`, `get_global(name) -> Result<Function>`, `register_global(name, func) -> Result<()>`, `from_packed(Fn(&[AnyView]) -> Result<Any>) -> Self`, `from_typed<F, I, O>(func) -> Self`, `from_extern_c(handle, safe_call, deleter) -> Self`.
- `Error` -- `{data: ObjectArc<ErrorObj>}`. Methods: `new(kind, message, traceback)`, `from_raised()`, `set_raised(&Self)`, `kind()`, `message()`, `backtrace()`, `traceback_most_recent_call_last()`, `with_appended_backtrace(Self, &str) -> Self`. Implements `Display`, `Debug`, `std::error::Error`.
- `ErrorKind<'a>(&'a str)` -- error kind wrapper. Constants: `VALUE_ERROR`, `TYPE_ERROR`, `RUNTIME_ERROR`, `ATTRIBUTE_ERROR`, `KEY_ERROR`, `INDEX_ERROR`.
- `Result<T, E = Error>` -- alias for `std::result::Result`.
- `String` -- ABI-stable string with SSO (small string: inline up to 7 bytes; large: heap via `StringObj`). Methods: `new()`, `len()`, `as_bytes()`, `as_str()`. Implements `Deref<Target=str>`, `Clone` (IncRef), `Drop` (DecRef), `PartialEq`, `Eq`, `PartialOrd`, `Ord`, `Hash`, `Display`, `Debug`, `From<T: AsRef<str>>`, `Default`.
- `Bytes` -- ABI-stable bytes with SSO. Methods: `new()`, `len()`, `as_slice()`. Implements `Deref<Target=[u8]>`, `Clone`, `Drop`, `PartialEq`, `Eq`, `PartialOrd`, `Ord`, `Hash`, `Display`, `Debug`, `From<T: AsRef<[u8]>>`, `Default`.
- `Shape` -- `{data: ObjectArc<ShapeObj>}`. Methods: `new()`, `as_slice()`, `fill_strides_from_shape()`. Implements `Deref<Target=[i64]>`, `PartialEq`, `Eq`, `PartialOrd`, `Ord`, `From<T: AsRef<[i64]>>`.
- `Tensor` -- `{data: ObjectArc<TensorObj>}`. Methods: `data_ptr()`, `data_ptr_mut()`, `is_contiguous()`, `data_as_slice<T>()`, `data_as_slice_mut<T>()`, `shape()`, `ndim()`, `numel()`, `strides()`, `dtype()`, `device()`, `from_nd_alloc(alloc, shape, dtype, device)`, `from_slice<T>(slice, shape)`.
- `CPUNDAlloc` -- CPU-based `NDAllocator` implementation (64-byte aligned).
- `Module` -- `{data: ObjectArc<ModuleObj>}`. Methods: `load_from_file(file_name) -> Result<Module>`, `get_function(name) -> Result<Function>`.

**Macros**:
- `check_safe_call!(expr)` -- wraps FFI call return code check, returns `Result<(), Error>`.
- `bail!(error_kind, fmt, args...)` -- creates Error with file/line context and returns `Err`.
- `ensure!(cond, error_kind, fmt, args...)` -- conditional `bail!`.
- `attach_context!(expr)` -- appends file/line backtrace to error results.
- `function_name!()` -- returns the enclosing function name.
- `tvm_ffi_dll_export_typed_func!(name, func)` -- exports a typed Rust function as `__tvm_ffi_<name>` C symbol following the TVM FFI ABI.
- `into_typed_fn!(f, Fn(T0, ...) -> Result<R>)` -- converts a `Function` into a typed closure (0-8 args).
- `impl_try_from_any!(types...)` -- generates `TryFrom<AnyView>` and `TryFrom<Any>` for listed types.
- `impl_try_from_any_for_parametric!(Generic<T>)` -- same for generic types like `Option<T>`.
- `impl_into_arg_holder_default!(types...)` -- generates `IntoArgHolder` for listed types.
- `impl_arg_into_ref!(types...)` -- generates `ArgIntoRef` for listed types.

## Impact
- API: Introduces a new first-class language binding (Rust). No changes to C++, Python, or C ABI.
- ABI: None. The Rust crate consumes the existing C ABI via hand-written `#[repr(C)]` struct declarations (no bindgen). All C struct layouts are manually mirrored.
- Behavioral: None. The Rust crate is a consumer of the existing `libtvm_ffi` shared library; no changes to existing behavior.
- Flags/config: New Cargo workspace at `rust/` with `tvm-ffi-config` build dependency for finding `libtvm_ffi`.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- C ABI: `TVMFFIObject`, `TVMFFIAny`, `TVMFFIAnyDataUnion`, `TVMFFITypeIndex`, `TVMFFIByteArray`, `TVMFFIFunctionCell`, `TVMFFIErrorCell`, `TVMFFIShapeCell`, `TVMFFITypeInfo`, `TVMFFIFieldInfo`, `TVMFFIMethodInfo`, `TVMFFITypeMetadata`, `TVMFFITypeAttrColumn` (`.knowledge/designs/c-abi.md`)
- Any/AnyView system: type-erased value containers with 16-byte layout, small string optimization (`.knowledge/designs/any-system.md`)
- Object system: intrusive ref-counting, dual-class pattern (Obj + Ref), type index hierarchy, `ffi.*` namespace (`.knowledge/designs/object-system.md`)
- Combined ref count: packed strong+weak in a single `uint64_t`, two-phase deletion with deleter flags (`.knowledge/ADRs/018-combined-ref-count.md`)
- Function system: packed calling convention `(args, num_args, result)`, global registry, typed function wrapping (`.knowledge/designs/function-system.md`)
- Error handling: TLS-based error propagation with `TVMFFIErrorSetRaised`/`TVMFFIErrorMoveFromRaised` (`.knowledge/designs/error-handling.md`)
- Containers: String/Bytes with SSO, Shape, Tensor (`.knowledge/designs/containers.md`, `.knowledge/designs/0011-small-string-optimization.md`)
- Module system: dynamic library loading via `ffi.ModuleLoadFromFile` (`.knowledge/designs/0013-module-system.md`)
- Type traits: `TypeTraits<T>` protocol with strict/cast semantics (`.knowledge/designs/type-traits.md`)
- DLPack: DLTensor, DLDataType, DLDevice structs (`.knowledge/designs/0018-dlpack-fast-path.md`)
- FFI symbol prefix: `__tvm_ffi_` prefix convention (`.knowledge/ADRs/016-ffi-symbol-prefix.md`)

Design elements this commit produces:
- Rust binding architecture: three-crate workspace (`tvm-ffi-sys` / `tvm-ffi-macros` / `tvm-ffi`) with hand-written C ABI instead of bindgen
- Rust `AnyCompatible` trait: Rust equivalent of C++ `TypeTraits<T>` protocol
- Rust `ObjectCore` / `ObjectRefCore` traits + `#[derive(Object)]` / `#[derive(ObjectRef)]` proc macros: Rust equivalent of C++ dual-class pattern
- Rust `ObjectArc<T>`: Rust equivalent of C++ `ObjectPtr<T>` with native Rust ref-counting via the C ABI atomics
- Rust `AsPackedCallable` trait + `from_typed` / `from_packed` / `from_extern_c` constructors: Rust equivalent of C++ `TypedPackedFunc`
- Rust `into_typed_fn!` macro: Rust equivalent of creating typed function wrappers
- Rust `tvm_ffi_dll_export_typed_func!` macro: for exporting Rust functions as `__tvm_ffi_*` C symbols
- Rust `NDAllocator` trait + `CPUNDAlloc`: pluggable tensor memory allocation
- Build system: `tvm-ffi-config` based discovery of `libtvm_ffi`

## Usage Examples

### Defining and calling a typed function (Rust-only)
```rust
use tvm_ffi::*;

let add = Function::from_typed(|x: i32, y: i32| -> Result<i32> { Ok(x + y) });
let typed_add = into_typed_fn!(add, Fn(i32, i32) -> Result<i32>);
assert_eq!(typed_add(1, 2).unwrap(), 3);
```

### Exporting a Rust function as a C-ABI symbol
```rust
use tvm_ffi::*;

fn my_add(x: i32, y: i32) -> Result<i32> { Ok(x + y) }
tvm_ffi_dll_export_typed_func!(my_add, my_add);
// Generates: pub unsafe extern "C" fn __tvm_ffi_my_add(...) -> i32

let f = Function::from_extern_c(std::ptr::null_mut(), __tvm_ffi_my_add, None);
let typed = into_typed_fn!(f, Fn(i32, i32) -> Result<i32>);
assert_eq!(typed(3, 4).unwrap(), 7);
```

### Loading a shared library and calling a function from Rust
```rust
use tvm_ffi::{Module, Tensor, Result};

let lib = Module::load_from_file("path/to/add_one_cpu.so").unwrap();
let add_one = lib.get_function("add_one_cpu").unwrap();
let typed_add_one = tvm_ffi::into_typed_fn!(add_one, Fn(&Tensor, &Tensor) -> Result<()>);
let x = Tensor::from_slice(&[0.0f32, 1.0, 2.0, 3.0], &[4]).unwrap();
let y = Tensor::from_slice(&[0.0f32; 4], &[4]).unwrap();
typed_add_one(&x, &y).unwrap();
```

### Defining a custom object type
```rust
use tvm_ffi::derive::{Object, ObjectRef};
use tvm_ffi::object::{Object, ObjectArc};
use tvm_ffi_sys::TVMFFITypeIndex;

#[repr(C)]
#[derive(Object)]
#[type_key = "ffi.Function"]
#[type_index(TVMFFITypeIndex::kTVMFFIFunction)]
pub struct FunctionObj {
    object: Object,
    // ... fields
}

#[derive(Clone, ObjectRef)]
pub struct Function {
    data: ObjectArc<FunctionObj>,
}
```

### Creating a Tensor from a slice
```rust
use tvm_ffi::Tensor;

let data: &[f32] = &[1.0, 2.0, 3.0, 4.0];
let tensor = Tensor::from_slice(data, &[2, 2]).unwrap();
assert_eq!(tensor.ndim(), 2);
assert_eq!(tensor.numel(), 4);
let slice = tensor.data_as_slice::<f32>().unwrap();
assert_eq!(slice, &[1.0, 2.0, 3.0, 4.0]);
```
