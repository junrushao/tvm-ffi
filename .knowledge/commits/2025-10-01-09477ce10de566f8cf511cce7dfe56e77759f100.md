# Initial bringup of Rust language binding layer for TVM FFI

## TL;DR

- Introduces a three-crate Rust workspace (`rust/`): `tvm-ffi-sys` (hand-written C ABI bindings), `tvm-ffi` (ergonomic Rust API), and `tvm-ffi-macros` (proc-macro derive helpers).
- Mirrors every core abstraction from C++/Python — `Any`/`AnyView`, `ObjectArc`/`ObjectRef`, `Function`, `Error`, `Module`, `String`/`Bytes`, `Tensor`, `Shape` — as idiomatic Rust types sharing the same `TVMFFIObject` ref-count protocol.
- Adds `cargo test` to CI (runs after the Python pip package install, so the shared library is available at link time).

## Key Exports

```python
# ── tvm-ffi-sys  ──────────────────────────────────────────────
# Hand-written Rust mirror of the C ABI structs/enums/functions.
# No bindgen — manually authored to control AtomicU64 semantics.
class TVMFFITypeIndex(IntEnum):
    kTVMFFINone = 0; kTVMFFIInt = 1; kTVMFFIBool = 2; kTVMFFIFloat = 3
    kTVMFFIStaticObjectBegin = 64  # objects with ref-count
    kTVMFFIStr = 65; kTVMFFIBytes = 66; kTVMFFIError = 67
    kTVMFFIFunction = 68; kTVMFFIShape = 69; kTVMFFITensor = 70
    kTVMFFIArray = 71; kTVMFFIMap = 72; kTVMFFIModule = 73
    # Invariant: type_index >= kTVMFFIStaticObjectBegin means ref-counted object

class TVMFFIObject:
    combined_ref_count: AtomicU64  # lower 32 = strong, upper 32 = weak
    type_index: i32
    __padding: u32  # always 0
    deleter: Optional[Callable[[*mut c_void, i32], None]]
    # Interacts with: ObjectArc.inc_ref/dec_ref, TVMFFIObjectDeleterFlagBitMask

# ── tvm-ffi (core abstractions) ──────────────────────────────

class AnyView:
    """Non-owning, Copy type-erased value; lifetime-bound to source."""
    # repr(C) with inner TVMFFIAny; PhantomData lifetime
    def try_as(self, T: type) -> Optional[T]: ...
    # Invariant: must not outlive the value it borrows
    # Interacts with: AnyCompatible, Function.call_packed

class Any:
    """Owned type-erased value; drops ref-count on Drop."""
    def try_as(self, T: type) -> Optional[T]: ...
    def type_index(self) -> i32: ...
    # Drop: calls dec_ref if type_index >= kTVMFFIStaticObjectBegin
    # Interacts with: AnyCompatible, TryFromTemp, Function return values

trait AnyCompatible:
    """Customization point for Any ↔ T conversion. Unsafe trait."""
    def copy_to_any_view(src: Self, data: *mut TVMFFIAny): ...
    def move_to_any(src: Self, data: *mut TVMFFIAny): ...
    def check_any_strict(data: *TVMFFIAny) -> bool: ...
    def copy_from_any_view_after_check(data: *TVMFFIAny) -> Self: ...
    def move_from_any_after_check(data: *mut TVMFFIAny) -> Self: ...
    def try_cast_from_any_view(data: *TVMFFIAny) -> Result[Self, ()]: ...
    # Interacts with: TryFromTemp, ArgTryFromAnyView, impl_try_from_any! macro
    # Extension: impl AnyCompatible for new types to pass them through Any

class ObjectArc(T: ObjectCore):
    """Arc-like shared ownership wrapper; layout guarantees ptr is NonNull<T>."""
    ptr: NonNull[T]
    # inc_ref / dec_ref implemented natively in Rust (object::unsafe_ module)
    # matching C++ combined_ref_count protocol exactly
    # Interacts with: ObjectCore, unsafe_::inc_ref/dec_ref/object_deleter_for_new

trait ObjectCore:
    """Unsafe trait marking a #[repr(C)] struct as a TVM FFI object node."""
    TYPE_KEY: str  # string type key
    def type_index() -> i32: ...   # static or lazy-initialized via TVMFFITypeKeyToIndex
    def object_header_mut(this: *mut Self) -> *mut TVMFFIObject: ...
    # Invariant: first field of every ObjectCore struct must be parent ObjectCore type
    # (chain bottoms out at Object which wraps TVMFFIObject directly)
    # Extension: implement via #[derive(Object)] + #[type_key = "..."] attributes

class ObjectRef:
    """Base ObjectRef; wraps ObjectArc<Object>."""
    data: ObjectArc[Object]
    # #[derive(ObjectRef)] generates ObjectRefCore impl + AnyCompatible impl

class Function:
    """Type-erased callable; wraps FunctionObj with TVMFFIFunctionCell."""
    data: ObjectArc[FunctionObj]

    def call_packed(self, args: List[AnyView]) -> Result[Any]: ...
    def call_tuple(self, args: Tuple) -> Result[Any]: ...
    def call_tuple_with_len(self, LEN: const, args: Tuple) -> Result[Any]: ...
    # small-vector opt: stack buffer of 4 AnyView slots before heap spill
    def from_packed(f: Fn([AnyView]) -> Result[Any]) -> Function: ...
    def from_typed(f: Fn(T0, ...) -> Result[Out]) -> Function: ...
    # from_typed supports 0-8 typed args via impl_as_packed_callable! macro
    def get_global(name: str) -> Result[Function]: ...
    def register_global(name: str, func: Function) -> Result[()]: ...
    # Interacts with: global function registry (TVMFFIFunctionGetGlobal/SetGlobal)
    # Interacts with: AnyCompatible (arg/result conversion), Error (TLS error slot)

class Error:
    """Rust Error type backed by C++ ErrorObj via TLS error slot."""
    data: ObjectArc[ErrorObj]
    def new(kind: ErrorKind, message: str, traceback: str) -> Error: ...
    def from_raised() -> Error: ...   # reads TLS error slot after -1 return code
    def set_raised(error: Error): ... # writes TLS error slot before returning -1
    # Interacts with: TVMFFIErrorCreate/SetRaised/MoveFromRaised C ABI
    # Mirrors 0005-error-system protocol

class ErrorKind:
    """Newtype wrapping &'static str for error kind names."""
    # Predefined: VALUE_ERROR, TYPE_ERROR, RUNTIME_ERROR, ATTRIBUTE_ERROR, KEY_ERROR, INDEX_ERROR
    # Interacts with: bail!, ensure!, check_safe_call! macros

class Module:
    """Dynamic library wrapper; type index kTVMFFIModule=73."""
    data: ObjectArc[ModuleObj]
    def load_from_file(file_name: str) -> Result[Module]: ...
    def get_function(name: str) -> Result[Function]: ...
    # Uses LazyLock<Function> for "ffi.ModuleLoadFromFile" / "ffi.ModuleGetFunction"
    # Interacts with: global function registry, 0011-module-system

# ── tvm-ffi-macros (proc-macro derives) ──────────────────────

# #[derive(Object)] — applied to FooObj structs
# Generates: unsafe impl ObjectCore for FooObj
#   - const TYPE_KEY = #[type_key = "..."] literal
#   - type_index(): static (from #[type_index(Enum::Variant)]) or lazy via TVMFFITypeKeyToIndex
#   - object_header_mut: delegates to first field's object_header_mut (transitive chain)

# #[derive(ObjectRef)] — applied to Foo structs with `data: ObjectArc<FooObj>`
# Generates: unsafe impl ObjectRefCore for Foo
#   + AnyCompatible impl (for is-a subtype checks via is_a_of / check_any_strict)
#   + TryFrom<AnyView>/TryFrom<Any> via impl_try_from_any! indirection

# into_typed_fn!(func, Fn(&T0, T1) -> Result<Out>) macro
# Returns a closure that accepts typed args, converts via IntoArgHolder, calls call_packed
# Interacts with: Function.call_tuple_with_len, IntoArgHolder, TupleAsPackedArgs

# ── Macro utilities ───────────────────────────────────────────
# check_safe_call!(expr) — checks ret_code==0, else Error::from_raised()
# bail!(kind, msg, ...) — return Err(Error::new(kind, msg, file/line context))
# ensure!(cond, kind, msg) — bail! if cond is false
# impl_try_from_any!(T, ...) — generates TryFrom<AnyView>/TryFrom<Any> for primitive types
```

## Impact

- API: New crate surface only; no changes to existing C++/Python APIs.
- Behavioral: None to existing layers. Rust layer shares the live C ABI binary (`libtvm_ffi_shared.so`) loaded via `tvm-ffi-config --libdir`.
- Flags/config: `CARGO_FEATURE_EXAMPLE` feature flag gates example lib generation in `tvm-ffi/build.rs`.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **0001-c-abi** — `TVMFFIObject` 24-byte layout, `combined_ref_count` lower/upper 32-bit split, `TVMFFIFunctionCell.safe_call`, `TVMFFIAny`, all `TVMFFITypeIndex` constants, `TVMFFIByteArray`, deleter flag bitmask protocol. `tvm-ffi-sys/src/c_api.rs` replicates these manually without bindgen.
- **0002-object-system** — `combined_ref_count` protocol (`kCombinedRefCountBothOne`, `kCombinedRefCountStrongOne`, `kCombinedRefCountWeakOne`), two-phase decrement (`kStrong` then `kWeak` deleter flags). Rust `object::unsafe_` module reimplements `TVMFFIObjectIncRef`/`TVMFFIObjectDecRef` natively.
- **0003-any-anyview** — `TVMFFIAny` 16-byte layout; strict vs coercing distinction preserved as `try_as()` (strict) vs `TryFrom` (coercing via `try_cast_from_any_view`).
- **0004-function-system** — packed call convention `(handle, *args, num_args, *result) -> i32`; `TVMFFIFunctionGetGlobal`/`TVMFFIFunctionSetGlobal` for registry access.
- **0005-error-system** — TLS error slot via `TVMFFIErrorSetRaised`/`TVMFFIErrorMoveFromRaised`; `-1` return code protocol.
- **0011-module-system** — `"ffi.ModuleLoadFromFile"` / `"ffi.ModuleGetFunction"` global function names.
- **0012-env-api** — `TVMFFIEnvSetStream`/`TVMFFIEnvGetStream` for device stream context (`rust/tvm-ffi/src/device.rs`).

Design elements this commit produces:
- **Rust binding layer** (new): three-crate workspace `rust/`; `tvm-ffi-sys` as the unsafe sys crate; `tvm-ffi` as the safe ergonomic API; `tvm-ffi-macros` as proc-macro derives. See Reflection for recommended design record.
- **`AnyCompatible` trait** (new, Rust-specific): the Rust equivalent of C++ `TypeTraits<T>` customization point. Key difference: Rust uses a single unsafe trait instead of a template struct; split between strict `check_any_strict` and coercing `try_cast_from_any_view` maps to C++ `CheckAnyStrict`/`TryCastFromAnyView`.
- **`ObjectArc<T>` + `ObjectCore`/`ObjectRefCore` traits** (new, Rust-specific): mirrors C++ `ObjectPtr<T>`/`ObjectRef` pattern but uses Rust Arc-compatible RAII instead of custom smart pointer macros.
- **`#[derive(Object)]` / `#[derive(ObjectRef)]` proc macros** (new): Rust analog of `TVM_FFI_DECLARE_OBJECT_INFO` + `TVM_FFI_DEFINE_OBJECT_REF_METHODS`.
- **`into_typed_fn!(func, Fn(...) -> Result<T>)` macro** (new): typed wrapper factory; no C++/Python equivalent.

## Usage Examples

Registering and calling a typed function from Rust:

```rust
use tvm_ffi::{Function, Result, Any, AnyView};

// Create from a typed closure (0-8 args supported)
let add = Function::from_typed(|x: i32, y: i32| -> Result<i32> { Ok(x + y) });

// Call via packed convention
let result = add.call_tuple((1, 2)).unwrap();
let sum: i32 = result.try_into().unwrap();

// Register in global registry (accessible from C++ / Python)
Function::register_global("my.add", add).unwrap();

// Retrieve and call via typed wrapper
let f = Function::get_global("my.add").unwrap();
let typed_add = into_typed_fn!(f, Fn(&i32, i32) -> Result<i32>);
assert_eq!(typed_add(&1, 2).unwrap(), 3);
```

Defining a new Object type (parallel to C++ `TVM_FFI_DECLARE_OBJECT_INFO`):

```rust
use tvm_ffi::{Object, ObjectArc, ObjectCore, TVMFFIObject};
use tvm_ffi::derive::{Object as DeriveObject, ObjectRef};

#[repr(C)]
#[derive(DeriveObject)]
#[type_key = "my.Foo"]   // dynamic type index via TVMFFITypeKeyToIndex
pub struct FooObj {
    object: Object,      // must be first field
    pub value: i64,
}

#[derive(ObjectRef, Clone)]
pub struct Foo {
    data: ObjectArc<FooObj>,
}

let arc = ObjectArc::new(FooObj { object: Object::new(), value: 42 });
let any = tvm_ffi::Any::from(Foo { data: arc });
let back: Foo = any.try_into().unwrap();
```

Loading a shared library and calling an exported kernel:

```rust
use tvm_ffi::{Module, Tensor, Result};

let lib = Module::load_from_file("add_one_cpu.so").unwrap();
let add_one = lib.get_function("add_one_cpu").unwrap();
let typed = into_typed_fn!(add_one, Fn(&Tensor, &Tensor) -> Result<()>);
let x = Tensor::from_slice(&[0.0f32, 1.0, 2.0, 3.0], &[4]).unwrap();
let y = Tensor::from_slice(&[0.0f32; 4], &[4]).unwrap();
typed(&x, &y).unwrap();
```
