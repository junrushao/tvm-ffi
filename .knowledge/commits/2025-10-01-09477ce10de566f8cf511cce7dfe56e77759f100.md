# Initial bringup of Rust support as an experimental third first-class language for the FFI layer

## TL;DR
- Introduces the `rust/` workspace with three crates: `tvm-ffi-sys` (unsafe C-ABI bindings), `tvm-ffi` (ergonomic Rust API), and `tvm-ffi-macros` (proc-macros for object and ref derive).
- Rust mirrors the C++/Python object system: `Object`/`ObjectArc<T>` for ref-counting, `AnyView<'a>`/`Any` for type-erased values, `Function` for packed callables — all interoperating with the same C ABI.
- Adds a load-library example and CI integration; marked `[experimental]`, secondary to C++/Python support.

    def object_header_mut(this) -> TVMFFIObject: ...

    data: ObjectArc[T]

    def set_global(name: str, f: Function): ...

def typed_func(callback: Fn([AnyView]) -> Result[Any]) -> Function:

class RustString:  # ObjectRef wrapping BytesBaseCell-compatible storage
    """FFI String type; extra_items pattern for inline char storage."""

# #[derive(Object)] generates ObjectCore impl:
#   - TYPE_KEY from #[type_key = "ffi.Foo"]
#   - type_index() from #[type_index(TVMFFITypeIndex::kTVMFFI...)] (static) or lazy TVMFFITypeKeyToIndex
#   - object_header_mut via first field named `object`

# tvm_func!(name, args...) — wraps global function call with arg packing

## Impact
- API: New `rust/` workspace. No changes to C++/Python API surface.
- Behavioral: Rust can now call into and expose functions via the existing C ABI; load-library example demonstrates cross-language function lookup.
- Flags/config: `rust/Cargo.toml` workspace; `.github/workflows/ci_test.yml` adds Rust test step.
- Data formats/schemas: None — Rust bindings consume the existing C ABI structs without modification.

## Design Elements
Design elements this commit consumes:
- `AnyView`/`Any` 16-byte tagged union protocol (0001-any-anyview-value-system) — Rust `AnyView<'a>`/`Any` are `#[repr(C)]` wrappers over `TVMFFIAny`.
- Object system ref-counting (0002-object-system) — `ObjectArc<T>` mirrors `ObjectPtr<T>`; `ObjectCore` trait mirrors `ObjectCore` CRTP; `Drop` calls `TVMFFIObjectDecRef`.
- Function packed callable convention (0003-function-system) — `CallbackFunctionObjImpl<F>` provides `safe_call` C callback; `Function::call` uses `TVMFFISafeCallType`.
- TypeTraits protocol (0005-type-traits-protocol) — `AnyCompatible` trait mirrors `TypeTraits<T>` interface; same three-tier conversion pattern.
- C ABI (0007-c-abi) — `tvm-ffi-sys` provides raw bindings to all `TVMFFIAny`, `TVMFFIObject`, `TVMFFIFunction*`, `TVMFFIError*` symbols.
- Module system (0011-module-system) — `tvm-ffi/src/extra/module.rs` wraps `TVMFFIModLoad`/`TVMFFIModGetFunction`.

Design elements this commit produces:
- **Rust FFI layer** — new subsystem with `AnyView<'a>`, `Any`, `ObjectArc<T>`, `ObjectCore` trait, `ObjectRef` newtype pattern, `Function`, `Error`, `Tensor`, `ShapeView`, `String` (see Key Exports).
- **`AnyCompatible` trait** — Rust mirror of `TypeTraits<T>` providing compile-time any-value conversion protocol.
- **`#[derive(Object)]`/`#[derive(ObjectRef)]` proc-macros** — code-generation for Rust object boilerplate (parallel to C++ `TVM_FFI_DECLARE_OBJECT_INFO`/`TVM_FFI_DEFINE_OBJECT_REF_METHODS`).
- **`check_safe_call!`/`tvm_func!`/`register_global_func!`** — declarative macros for FFI call pattern.

## Usage Examples

Loading a library and calling a function from Rust:
```rust
// rust/tvm-ffi/examples/load_library.rs (from commit)
use tvm_ffi::extra::module::Module;
use tvm_ffi::function::Function;

let module = Module::load("path/to/lib.so").unwrap();
let func: Function = module.get_function("my_func").unwrap();
let result = func.call(&[]).unwrap();
```

Registering a Rust closure as a global FFI function:
```rust
use tvm_ffi::macros::register_global_func;
register_global_func!("my_rust_func", |args| {
    let x: i64 = args[0].try_as().unwrap();
    Ok(Any::from(&(x + 1)))
});
```

Defining a new Object type:
```rust
#[repr(C)]
#[derive(Object)]
#[type_key = "my.MyObj"]
pub struct MyObj {
    object: Object,
    value: i64,
}

#[derive(Clone, ObjectRef)]
pub struct MyRef {
    data: ObjectArc<MyObj>,
}
```
