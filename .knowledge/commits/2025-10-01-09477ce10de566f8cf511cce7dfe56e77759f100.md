# Initial bringup of experimental Rust FFI bindings (3-crate workspace)
## TL;DR
- Introduces the full Rust binding layer as a 3-crate workspace (`tvm-ffi-sys`, `tvm-ffi-macros`, `tvm-ffi`) under `rust/`, providing ergonomic Rust APIs for the TVM FFI C ABI.
- Maps the C++ object/ref pattern (`FooObj`/`Foo`) to Rust via `ObjectCore`/`ObjectRefCore` traits and `#[derive(Object)]`/`#[derive(ObjectRef)]` proc macros, with native atomic refcounting implemented in pure Rust.
- Supports both consuming FFI libraries (loading `.so` modules, calling global functions) and producing them (exporting Rust functions via `tvm_ffi_dll_export_typed_func!`).

## Key Exports

### Crate: `tvm-ffi-sys`
Low-level C ABI bindings. Manually written (not bindgen), providing:

| Type/Constant | Description |
|---|---|
| `TVMFFITypeIndex` (enum, `#[repr(i32)]`) | All ABI type indices (`kTVMFFINone`..`kTVMFFIOpaquePyObject`) |
| `TVMFFIAny` (`#[repr(C)]`, 16 bytes) | Type-erased value slot: `{type_index: i32, small_str_len: u32, data_union}` |
| `TVMFFIObject` (`#[repr(C)]`, 24 bytes) | Object header: `{combined_ref_count: AtomicU64, type_index: i32, __padding: u32, deleter: Option<fn>}` |
| `TVMFFIFunctionCell` | Function call cell: `{safe_call: TVMFFISafeCallType, cxx_call: *mut c_void}` |
| `TVMFFIErrorCell` | Error storage cell |
| `TVMFFIByteArray` | `{data: *const u8, size: usize}` |
| `TVMFFIObjectDeleterFlagBitMask` | Strong/Weak/Both deleter flags |
| `COMBINED_REF_COUNT_*` constants | Bit layout: lower 32 bits = strong count, upper 32 bits = weak count |
| `DLDataType`, `DLDevice`, `DLTensor` | DLPack type re-exports |
| C API functions | `TVMFFIFunctionGetGlobal`, `TVMFFIFunctionSetGlobal`, `TVMFFIFunctionCreate`, `TVMFFIErrorCreate`, `TVMFFIErrorSetRaised`, `TVMFFIErrorMoveFromRaised`, `TVMFFIAnyViewToOwnedAny`, `TVMFFITypeKeyToIndex`, `TVMFFIGetTypeInfo`, etc. |

### Crate: `tvm-ffi-macros` (proc-macro)
Two derive macros:

| Macro | Input | Generated code |
|---|---|---|
| `#[derive(Object)]` | Struct with `#[type_key = "..."]`, optional `#[type_index(...)]`, first field = parent `ObjectCore` | `unsafe impl ObjectCore for T { TYPE_KEY, type_index(), object_header_mut() }` |
| `#[derive(ObjectRef)]` | Struct with `data: ObjectArc<T>` as first field | `unsafe impl ObjectRefCore`, `unsafe impl AnyCompatible`, `impl_try_from_any!`, `impl_arg_into_ref!`, `impl_into_arg_holder_default!` |

### Crate: `tvm-ffi` (main API)

**Traits:**

| Trait | Key methods | Purpose |
|---|---|---|
| `unsafe trait AnyCompatible` | `copy_to_any_view`, `move_to_any`, `check_any_strict`, `copy_from_any_view_after_check`, `move_from_any_after_check`, `try_cast_from_any_view`, `type_str` | Rust equivalent of C++ `TypeTraits<T>` -- enables a type to round-trip through `Any`/`AnyView` |
| `unsafe trait ObjectCore` | `TYPE_KEY: &str`, `type_index() -> i32`, `object_header_mut(&mut Self) -> &mut TVMFFIObject` | Object data class protocol |
| `unsafe trait ObjectCoreWithExtraItems` | `ExtraItem` type, `extra_items_count`, `extra_items`, `extra_items_mut` | Trailing-data objects (String, Bytes) |
| `unsafe trait ObjectRefCore` | `ContainerType`, `data()`, `into_data()`, `from_data()` | Reference wrapper protocol |
| `trait AsPackedCallable<I, O>` | `call_packed(&self, &[AnyView]) -> Result<Any>` | Typed-to-packed adapter for up to 8 args |
| `trait TupleAsPackedArgs` | `LEN: usize`, `fill_any_view()` | Tuple-to-AnyView conversion for call sites |

**Types:**

| Type | Key API |
|---|---|
| `Any` (`#[repr(C)]`, owns `TVMFFIAny`) | `new()`, `type_index()`, `try_as::<T>()`, `From<T: AnyCompatible>`, `Clone` (inc_ref), `Drop` (dec_ref) |
| `AnyView<'a>` (`#[repr(C)]`, borrows `TVMFFIAny`) | `new()`, `type_index()`, `try_as::<T>()`, `From<&'a T>`, `From<&'a Any>` |
| `ObjectArc<T: ObjectCore>` | `new(T)`, `new_with_extra_items(T)`, `from_raw(*const T)`, `into_raw() -> *const T`, `strong_count()`, `weak_count()`, `Deref<Target=T>`, `Clone` (inc_ref), `Drop` (dec_ref) |
| `Object` | Base object. `ObjectCore::TYPE_KEY = "ffi.Object"`, index = `kTVMFFIStaticObjectBegin` |
| `ObjectRef` | Base reference. `data: ObjectArc<Object>` |
| `Function` | `call_packed(&[AnyView]) -> Result<Any>`, `call_tuple(tuple)`, `call_tuple_with_len::<LEN>(tuple)`, `get_global(name)`, `register_global(name, func)`, `from_packed(Fn(&[AnyView]) -> Result<Any>)`, `from_typed(Fn)`, `from_extern_c(handle, safe_call, deleter)` |
| `Error` | `new(kind, message, traceback)`, `from_raised()`, `set_raised()`, `kind()`, `message()`, `backtrace()`, `with_appended_backtrace()`. Implements `std::error::Error`. |
| `ErrorKind<'a>` | Named error categories: `VALUE_ERROR`, `TYPE_ERROR`, `RUNTIME_ERROR`, `ATTRIBUTE_ERROR`, `KEY_ERROR`, `INDEX_ERROR` |
| `String` (`#[repr(C)]`, inline `TVMFFIAny`) | Small-string optimized (<=7 bytes inline). `as_str()`, `as_bytes()`, `len()`, `From<T: AsRef<str>>`, `Deref<Target=str>` |
| `Bytes` (`#[repr(C)]`, inline `TVMFFIAny`) | Same SSO pattern for byte slices. `as_slice()`, `len()`, `From<T: AsRef<[u8]>>`, `Deref<Target=[u8]>` |
| `Tensor` | `from_slice(data, shape)`, `data_ptr()`, `data_as_slice::<T>()`, `data_as_slice_mut::<T>()`, via `CPUNDAlloc` allocator |
| `Shape` | Immutable shape container with trailing `i64` data |
| `Module` | `load_from_file(path)`, `get_function(name)` -- backed by global functions `ffi.ModuleLoadFromFile`, `ffi.ModuleGetFunction` |
| `DLDataTypeExt` (trait) | Extension methods on `DLDataType`: constructors (`int8()`, `float32()`, etc.), `bits()`, `lanes()`, `type_code()` |

**Macros:**

| Macro | Purpose |
|---|---|
| `check_safe_call!(expr)` | Wraps C API call, converts nonzero return to `Err(Error::from_raised())` |
| `bail!(kind, fmt, args...)` | Return `Err(Error::new(...))` with file/line traceback |
| `ensure!(cond, kind, fmt, args...)` | Conditional bail |
| `attach_context!(result)` | Append file/line to existing error traceback |
| `function_name!()` | Get enclosing function name via `std::any::type_name` trick |
| `tvm_ffi_dll_export_typed_func!(name, func)` | Export a typed Rust fn as `extern "C" __tvm_ffi_<name>` following FFI ABI |
| `into_typed_fn!(func, Fn(T0, T1, ...) -> Result<R>)` | Wrap a `Function` into a typed closure (0-8 args) |
| `impl_try_from_any!(types...)` | Generate `TryFrom<AnyView>` and `TryFrom<Any>` for listed types |
| `impl_any_compatible_for_int!(types...)` | Generate `AnyCompatible` impl for integer types |
| `impl_any_compatible_for_float!(types...)` | Generate `AnyCompatible` impl for float types |

## Design Elements
Design elements this commit consumes:
- **C ABI Layer** (`.knowledge/designs/0001-c-abi-layer.md`): `TVMFFIAny`, `TVMFFIObject`, `TVMFFIFunctionCell`, all C API functions, TLS error propagation, type index enum.
- **Any/AnyView Value System** (`.knowledge/designs/0002-any-value-system.md`): The 7-method `TypeTraits<T>` protocol is directly mapped to the `AnyCompatible` trait with identical semantics (`check_any_strict` = strict match, `try_cast_from_any_view` = widening cast).
- **Object System** (`.knowledge/designs/0003-object-system.md`): `Object`/`ObjectRef` pattern, `make_object` -> `ObjectArc::new`, intrusive refcounting with strong/weak split, deleter flags.
- **Function System** (`.knowledge/designs/0004-function-system.md`): Packed calling convention, `safe_call` path, `FunctionObj` layout, global function registry.
- **Type Traits** (`.knowledge/designs/0005-type-traits.md`): The `as` (strict) vs `cast` (widening) semantic split is preserved in Rust (`try_as` vs `TryFrom`).
- **Error Handling** (`.knowledge/designs/0006-error-handling.md`): Error kind taxonomy, TLS raise/move pattern, backtrace append.
- **Small String Optimization** (`.knowledge/designs/0011-small-string-optimization.md`): String/Bytes SSO with 7-byte inline threshold, type_index dispatch between small and heap variants.
- **Module System** (`.knowledge/designs/0013-module-system.md`): `Module::load_from_file`, `__tvm_ffi_<name>` symbol convention for DLL exports.

Design elements this commit produces:
- **Rust binding architecture**: 3-crate workspace split (`tvm-ffi-sys` for raw C, `tvm-ffi-macros` for proc-macros, `tvm-ffi` for ergonomic API). This is a new pattern not documented in existing design docs.
- **`AnyCompatible` trait**: Rust equivalent of C++ `TypeTraits<T>`, with 7 unsafe methods mapping 1:1 to the C++ specialization requirements.
- **`ObjectCore`/`ObjectRefCore`/`ObjectCoreWithExtraItems` trait hierarchy**: Rust's trait system replaces C++ macros (`TVM_FFI_DECLARE_OBJECT_INFO`) and virtual functions.
- **`#[derive(Object)]`/`#[derive(ObjectRef)]` proc macros**: Automatic boilerplate generation equivalent to C++ macros.
- **Native Rust refcounting in `object::unsafe_`**: `inc_ref`/`dec_ref` reimplemented in Rust with identical atomic ordering to C++ (`Relaxed` for inc, `Relaxed` fetch_sub + `Acquire` fence before delete). Not a C API call -- native for efficiency.
- **`CallbackFunctionObjImpl<F>` pattern**: Tail-allocation trick to embed arbitrary Rust closure after `FunctionObj` header, then cast `ObjectArc<CallbackFunctionObjImpl<F>>` to `ObjectArc<FunctionObj>`.
- **`into_typed_fn!` macro**: Typed function wrapper with small-vector optimization for args (stack-alloc up to 4, heap beyond).
- **`tvm_ffi_dll_export_typed_func!` macro**: DLL export symbol generation following `__tvm_ffi_<name>` convention.

## Usage Examples

### Creating and calling a typed function from Rust
```rust
use tvm_ffi::*;

// Define a typed function
let add = Function::from_typed(|x: i32, y: i32| -> Result<i32> { Ok(x + y) });

// Call via packed convention
let result = add.call_packed(&[AnyView::from(&1), AnyView::from(&2)]).unwrap();
assert_eq!(i32::try_from(result).unwrap(), 3);

// Or via typed wrapper
let typed_add = into_typed_fn!(add, Fn(&i32, i32) -> Result<i32>);
assert_eq!(typed_add(&1, 2).unwrap(), 3);
```

### Exporting a Rust function for DLL loading
```rust
use tvm_ffi::*;

fn add_one_tensor(x: Tensor, y: Tensor) -> Result<()> {
    let x_data = x.data_as_slice::<f32>()?;
    let y_data = y.data_as_slice_mut::<f32>()?;
    for i in 0..x_data.len() { y_data[i] = x_data[i] + 1.0; }
    Ok(())
}
tvm_ffi_dll_export_typed_func!(add_one_tensor, add_one_tensor);
// Generates: pub unsafe extern "C" fn __tvm_ffi_add_one_tensor(...)
```

### Loading and using an FFI module from Rust
```rust
use tvm_ffi::{Module, Result, Tensor};

let lib = Module::load_from_file("add_one_cpu.so").unwrap();
let add_one = lib.get_function("add_one_cpu").unwrap();
let typed_add_one = tvm_ffi::into_typed_fn!(add_one, Fn(&Tensor, &Tensor) -> Result<()>);
let x = Tensor::from_slice(&[1.0f32, 2.0, 3.0], &[3]).unwrap();
let y = Tensor::from_slice(&[0.0f32; 3], &[3]).unwrap();
typed_add_one(&x, &y).unwrap();
```

### ADRs to write or update
- `.knowledge/ADRs/0019-manual-c-abi-in-rust.md` -- Decision to manually write C ABI bindings in Rust rather than using `bindgen`, for precise control over atomic semantics and `#[repr(C)]` layout.
- `.knowledge/ADRs/0020-native-rust-refcounting.md` -- Decision to reimplement `inc_ref`/`dec_ref` in pure Rust rather than calling through C API, for performance (avoids FFI call overhead per refcount op).
