# Initial bringup of Rust FFI bindings as experimental third language layer

## TL;DR
- Adds a Rust workspace (`tvm-ffi`, `tvm-ffi-sys`, `tvm-ffi-macros`) that provides close-to-metal, ABI-compatible bindings to the TVM FFI C ABI — enabling Rust code to both expose libraries as FFI ABI and to load FFI-compatible shared libraries.
- Introduces the `AnyCompatible` trait as the Rust mirror of `TypeTraits<T>`, plus `ObjectCore`/`ObjectRefCore` unsafe traits with `ObjectArc<T>` (Arc-like wrapper) as the ref-counted smart pointer for heap objects.
- Provides `#[derive(Object)]` / `#[derive(ObjectRef)]` proc-macros (`tvm-ffi-macros`) and a set of ergonomic helper macros (`into_typed_fn!`, `tvm_ffi_dll_export_typed_func!`, `bail!`, `check_safe_call!`) that cover the packed-call/global-registry/module-loading round-trip.

## Key Exports

```python
# --- tvm-ffi-sys: raw C ABI bindings (hand-written, not bindgen) ---
# Mirrors c_api.h structs exactly; manually written to control AtomicU64 access

class TVMFFITypeIndex(IntEnum):
    # POD range [0,12), static objects [64,+...)
    kTVMFFINone = 0; kTVMFFIInt = 1; kTVMFFIBool = 2; kTVMFFIFloat = 3
    kTVMFFISmallStr = 11; kTVMFFISmallBytes = 12
    kTVMFFIStaticObjectBegin = 64
    kTVMFFIStr = 65; kTVMFFIBytes = 66; kTVMFFIError = 67
    kTVMFFIFunction = 68; kTVMFFIShape = 69; kTVMFFITensor = 70
    kTVMFFIModule = 73

class TVMFFIObject:           # 24-byte C header; repr(C)
    combined_ref_count: AtomicU64   # lower 32 = strong, upper 32 = weak
    type_index: i32
    __padding: u32
    deleter: Optional[extern "C" fn(*mut c_void, i32)]

# --- tvm-ffi: safe ergonomic layer ---

class AnyView:
    """Non-owning 16-byte view of a TVMFFIAny, lifetime-parameterized."""
    # Interacts with: AnyCompatible (conversion), Function::call_packed
    # Invariant: data.type_index determines active union field; must not outlive owner
    def try_as(self) -> Optional[T]: ...    # strict type check only, no cast

class Any:
    """Owning ref-counted TVMFFIAny value."""
    # Interacts with: AnyCompatible, ObjectArc (inc/dec_ref via unsafe_)
    # Invariant: Clone manually calls inc_ref; Drop calls dec_ref when type_index >= kTVMFFIStaticObjectBegin
    def try_as(self) -> Optional[T]: ...
    @staticmethod
    def from_raw_ffi_any(data: TVMFFIAny) -> Any: ...  # unsafe
    @staticmethod
    def into_raw_ffi_any(this: Any) -> TVMFFIAny: ...  # unsafe, transfers ownership

class AnyCompatible:
    """Trait: enables a Rust type to interconvert with TVMFFIAny."""
    # Mirrors C++ TypeTraits<T>: check_any_strict / copy / move / try_cast
    # Interacts with: AnyView::try_as, impl_try_from_any! macro, ObjectRef derive macro
    # Extension: unsafe impl AnyCompatible for MyType { ... }
    def copy_to_any_view(src: Self, data: *mut TVMFFIAny): ...   # unsafe
    def move_to_any(src: Self, data: *mut TVMFFIAny): ...        # unsafe, consumes src
    def check_any_strict(data: *TVMFFIAny) -> bool: ...          # unsafe
    def copy_from_any_view_after_check(data: *TVMFFIAny) -> Self: ...  # unsafe
    def move_from_any_after_check(data: *mut TVMFFIAny) -> Self: ...   # unsafe
    def try_cast_from_any_view(data: *TVMFFIAny) -> Result[Self, ()]: ... # unsafe

class ObjectCore:
    """Unsafe trait: marks a #[repr(C)] struct as an FFI object (first field = TVMFFIObject)."""
    TYPE_KEY: str
    # Interacts with: ObjectArc, #[derive(Object)] macro, AnyCompatible impl on ObjectRef
    # Invariant: first field must physically be (or chain to) TVMFFIObject for ABI compat
    def type_index() -> i32: ...          # static; uses LazyLock for dynamic types
    def object_header_mut(this: *mut Self) -> *mut TVMFFIObject: ...  # unsafe

class ObjectCoreWithExtraItems(ObjectCore):
    """Unsafe trait: declares trailing extra items after the object header (used for String/Shape/Tensor)."""
    ExtraItem: Type
    def extra_items_count(this: *Self) -> usize: ...

class ObjectArc:
    """Arc-like smart pointer for FFI objects; repr(C), compatible with TVMFFIObjectHandle."""
    # Interacts with: ObjectCore, unsafe_::inc_ref/dec_ref, ObjectRefCore, Any
    # Invariant: ptr is always non-null and allocated via std::alloc::alloc
    # Extension: use ObjectArc::new_with_extra_items for trailing-data objects
    def new(data: T) -> ObjectArc[T]: ...
    def new_with_extra_items(data: T) -> ObjectArc[T]: ...   # for ObjectCoreWithExtraItems
    def from_raw(ptr: *const T) -> ObjectArc[T]: ...         # unsafe, takes ownership
    def into_raw(this: ObjectArc[T]) -> *const T: ...        # unsafe, releases ownership
    def strong_count(this: *ObjectArc[T]) -> usize: ...

class ObjectRefCore:
    """Unsafe trait: marks a struct as an ObjectRef with a `data: ObjectArc<ContainerType>` field."""
    ContainerType: ObjectCore
    # Interacts with: AnyCompatible (impl generated by #[derive(ObjectRef)])
    def data(this: *Self) -> *ObjectArc[ContainerType]: ...
    def into_data(this: Self) -> ObjectArc[ContainerType]: ...
    def from_data(data: ObjectArc[ContainerType]) -> Self: ...

# proc-macro expansions (tvm-ffi-macros):
# #[derive(Object)] on FooObj generates:
#   unsafe impl ObjectCore for FooObj { TYPE_KEY, type_index(), object_header_mut() }
#   type_index uses LazyLock calling TVMFFITypeKeyToIndex for dynamic types,
#   or a const for #[type_index(TVMFFITypeIndex::kTVMFFIXxx)] static types.
#
# #[derive(ObjectRef)] on FooRef generates:
#   unsafe impl ObjectRefCore for FooRef { ... }
#   unsafe impl AnyCompatible for FooRef { ... }  (full inc_ref/dec_ref on copy_from)
#   impl_try_from_any!(FooRef); impl_arg_into_ref!(FooRef); impl_into_arg_holder_default!(FooRef);

class Function:
    """ABI-stable owned function; wraps FunctionObj (safe_call + cxx_call)."""
    # Interacts with: AnyView/Any for args/result, global registry, Module::get_function
    # Invariant: safe_call C ABI: fn(handle, *TVMFFIAny, num_args, *mut TVMFFIAny) -> i32
    def call_packed(self, packed_args: [AnyView]) -> Result[Any]: ...
    def call_tuple(self, tuple_args: T) -> Result[Any]: ...        # dynamic dispatch on LEN
    def call_tuple_with_len(self, tuple_args: T) -> Result[Any]: ... # const LEN, stack-allocated args
    @staticmethod
    def get_global(name: str) -> Result[Function]: ...
    @staticmethod
    def register_global(name: str, func: Function) -> Result[()]: ...
    @staticmethod
    def from_packed(func: Fn([AnyView]) -> Result[Any]) -> Function: ...
    @staticmethod
    def from_typed(func: F) -> Function: ...    # F: AsPackedCallable<I, O>
    @staticmethod
    def from_extern_c(handle, safe_call, deleter) -> Function: ...

class Error:
    """ABI-stable Error ref wrapping ErrorObj (kind + message + backtrace strings)."""
    # Interacts with: TVMFFIErrorCreate/MoveFromRaised/SetRaised, check_safe_call! macro
    # Invariant: backtrace stored most-recent-call-first (matches C++ convention)
    def new(kind: ErrorKind, message: str, traceback: str) -> Error: ...
    @staticmethod
    def from_raised() -> Error: ...         # moves TLS raised error
    @staticmethod
    def set_raised(error: *Error): ...      # stores into TLS
    def with_appended_backtrace(this: Error, backtrace: str) -> Error: ...

class Module:
    """ABI-stable Module ref for dynamic library loading."""
    # Interacts with: Function::get_global("ffi.ModuleLoadFromFile"), Function::get_global("ffi.ModuleGetFunction")
    # Extension: companion to C++ ModuleObj; loaded via shared library symbol __tvm_ffi_<name>
    @staticmethod
    def load_from_file(file_name: str) -> Result[Module]: ...
    def get_function(self, name: str) -> Result[Function]: ...

# Key macros:
# tvm_ffi_dll_export_typed_func!(name, func)
#   => pub unsafe extern "C" fn __tvm_ffi_<name>(_handle, args, num_args, result) -> i32
#   Interacts with: Module::get_function symbol lookup, C++ TVM_FFI_DLL_EXPORT_TYPED_FUNC pattern

# into_typed_fn!(func, Fn(T0, T1) -> Result<O>)
#   => closure that calls func.call_tuple_with_len::<N, _>(...)?.try_into()?
#   Supports 0-8 arguments via macro pattern matching

# check_safe_call!(expr) => if expr != 0 { Err(Error::from_raised()) } else { Ok(()) }
# bail!(kind, fmt, args...) => return Err(Error::new(kind, &format!(...), &context))
```

## Impact
- API: None to existing C++/Python layers — purely additive new `rust/` subtree.
- Behavioral: Adds CI job for Rust tests (`.github/workflows/ci_test.yml` +6 lines). Rust crates link against `libtvm_ffi` discovered via `tvm-ffi-config --libdir`.
- Flags/config: `tvm-ffi-config` CLI tool (installed by Python package) is now a hard build dependency for Rust crates.
- Data formats/schemas: `tvm-ffi-sys/src/c_api.rs` hand-writes all C ABI structs (not bindgen); `tvm-ffi-sys/src/dlpack.rs` hand-writes DLPack structs. These must stay in sync with `include/tvm/ffi/c_api.h` manually.

## Design Elements

Design elements this commit consumes:
- [0001-ffi-c-abi] — `tvm-ffi-sys/src/c_api.rs` is a hand-written Rust mirror of `TVMFFIAny`, `TVMFFIObject`, `TVMFFIFunctionCell`, `TVMFFIErrorCell`, `TVMFFITypeIndex` enum, and all ABI entry points (`TVMFFIFunctionCreate`, `TVMFFIErrorCreate`, etc.).
- [0002-ffi-any-value-system] — `AnyView`/`Any` + `AnyCompatible` trait directly mirrors `AnyView`/`Any` + `TypeTraits<T>` semantics including the strict/cast split.
- [0003-ffi-object-system] — `ObjectArc` replicates `ObjectPtr<T>` ref-counting logic (atomic inc/dec, two-phase decrement with weak refs, `COMBINED_REF_COUNT_*` constants).
- [0004-ffi-function-system] — `Function` wraps `FunctionObj`/`TVMFFIFunctionCell`; `CallbackFunctionObjImpl<F>` fills `safe_call` with a Rust closure.
- [0005-ffi-error-protocol] — `Error` wraps `ErrorObj`; uses `TVMFFIErrorSetRaised`/`TVMFFIErrorMoveFromRaised` for TLS propagation.
- [0011-ffi-module-system] — `Module::load_from_file` / `Module::get_function` call the `ffi.ModuleLoadFromFile` / `ffi.ModuleGetFunction` global functions exactly as Python does.
- [0013-ffi-packaging-and-distribution] — `tvm_ffi_dll_export_typed_func!` mirrors `TVM_FFI_DLL_EXPORT_TYPED_FUNC` for Rust-side symbol export; `tvm-ffi-config` mirrors `_load_lib` discovery.

Design elements this commit produces:
- **Rust FFI bindings layer** (`rust/`): `AnyCompatible` trait, `ObjectCore`/`ObjectRefCore`/`ObjectCoreWithExtraItems` unsafe traits, `ObjectArc<T>` smart pointer, `#[derive(Object)]`/`#[derive(ObjectRef)]` proc-macros, `into_typed_fn!`/`tvm_ffi_dll_export_typed_func!` macros. No design record exists yet.
- **`tvm-ffi-sys` C ABI mirror**: Hand-written Rust structs for all `TVMFFIAny`, `TVMFFIObject`, `TVMFFIFunctionCell`, `TVMFFIErrorCell`, `TVMFFIByteArray`, plus DLPack types. No design record exists yet.

## Usage Examples

End-to-end: exposing a Rust function as FFI and loading it in Rust

```rust
// --- Exposing Rust as FFI (library side) ---
use tvm_ffi::*;
fn add_one_cpu(x: &Tensor, y: &Tensor) -> Result<()> { /* ... */ Ok(()) }
tvm_ffi_dll_export_typed_func!(add_one_cpu, add_one_cpu);
// Produces symbol: pub unsafe extern "C" fn __tvm_ffi_add_one_cpu(...)

// --- Loading and calling from Rust (consumer side) ---
let lib = Module::load_from_file("/path/to/add_one_cpu.so").unwrap();
let func = lib.get_function("add_one_cpu").unwrap();
let typed = into_typed_fn!(func, Fn(&Tensor, &Tensor) -> Result<()>);
let x = Tensor::from_slice(&[1.0f32, 2.0, 3.0], &[3]).unwrap();
let y = Tensor::from_slice(&[0.0f32; 3], &[3]).unwrap();
typed(&x, &y).unwrap();
```

Defining a custom object type:

```rust
use tvm_ffi::*;
#[repr(C)]
#[derive(Object)]                   // generates ObjectCore impl
#[type_key = "my.MyObj"]
struct MyObj { object: Object, value: i64 }

#[derive(Clone, ObjectRef)]         // generates ObjectRefCore + AnyCompatible impls
struct MyRef { data: ObjectArc<MyObj> }

let arc = ObjectArc::new(MyObj { object: Object::new(), value: 42 });
let any = Any::from(MyRef { data: arc });
let back: MyRef = any.try_as().unwrap();
```
