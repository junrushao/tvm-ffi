# Initial bringup of experimental Rust bindings for TVM FFI
## TL;DR
- Introduces a three-crate Rust workspace (`tvm-ffi-sys`, `tvm-ffi-macros`, `tvm-ffi`) providing idiomatic Rust bindings over the C ABI, including the object system, Any/AnyView, Function, Error, String/Bytes, Tensor, Shape, Module, and DType/Device.
- Implements native Rust ref-counting (`ObjectArc<T>`) that directly manipulates the `TVMFFIObject.combined_ref_count` atomic, matching the C++ single-atomic fast-path delete protocol (including two-phase strong/weak deletion).
- Adds proc-macro derives (`#[derive(Object)]`, `#[derive(ObjectRef)]`) that auto-generate `ObjectCore`, `ObjectRefCore`, and `AnyCompatible` trait implementations, mirroring the C++ `TVM_FFI_DECLARE_OBJECT_INFO` / `TVM_FFI_DEFINE_OBJECT_REF_METHODS` macro pattern.

## Key Exports

```python
# === Crate: tvm-ffi-sys (raw C ABI bindings) ===
# Manually written #[repr(C)] structs mirroring c_api.h and c_env_api.h

class TVMFFITypeIndex(IntEnum):
    """Rust enum mirroring C type index values."""
    kTVMFFINone = 0; kTVMFFIInt = 1; kTVMFFIBool = 2; kTVMFFIFloat = 3
    kTVMFFIOpaquePtr = 4; kTVMFFIDataType = 5; kTVMFFIDevice = 6
    kTVMFFISmallStr = 11; kTVMFFISmallBytes = 12
    kTVMFFIStaticObjectBegin = 64; kTVMFFIStr = 65; kTVMFFIBytes = 66
    kTVMFFIError = 67; kTVMFFIFunction = 68; kTVMFFIShape = 69
    kTVMFFITensor = 70; kTVMFFIArray = 71; kTVMFFIMap = 72
    kTVMFFIModule = 73; kTVMFFIOpaquePyObject = 74
    # Interacts with: all Rust AnyCompatible impls, check_any_strict(), C++ TVMFFITypeIndex

class TVMFFIObject:
    """Rust #[repr(C)] mirror of C TVMFFIObject (24 bytes)."""
    combined_ref_count: AtomicU64  # strong=low32, weak=high32
    type_index: i32
    __padding: u32
    deleter: Option[extern "C" fn(*mut c_void, i32)]
    # Invariant: layout identical to C TVMFFIObject (verified by #[repr(C)])
    # Interacts with: ObjectArc (Rust), inc_ref/dec_ref (Rust native)

class TVMFFIAny:
    """Rust #[repr(C)] mirror of C TVMFFIAny (16 bytes)."""
    type_index: i32
    small_str_len: u32
    data_union: TVMFFIAnyDataUnion  # union: v_int64, v_float64, v_ptr, v_obj, v_bytes[8], ...
    # Invariant: layout identical to C TVMFFIAny (verified by #[repr(C)])

# extern "C" function declarations (linked at build time via tvm-ffi-config):
# TVMFFIFunctionGetGlobal, TVMFFIFunctionSetGlobal, TVMFFIFunctionCreate,
# TVMFFIFunctionCall, TVMFFIErrorMoveFromRaised, TVMFFIErrorSetRaised,
# TVMFFIErrorCreate, TVMFFIAnyViewToOwnedAny, TVMFFITensor{From,To}DLPack{,Versioned},
# TVMFFIString/BytesFromByteArray, TVMFFIGetTypeInfo, TVMFFITypeKeyToIndex,
# TVMFFIEnvSetStream, TVMFFIEnvGetStream, TVMFFIEnvSetTensorAllocator,
# TVMFFIEnvModLookupFromImports, etc.
# Interacts with: C++ libtvm_ffi.so (dynamic linking via build.rs -> tvm-ffi-config --libdir)

# === Crate: tvm-ffi-macros (proc macros) ===

# derive(Object): generates ObjectCore impl from struct with first field as base object
# Attributes: #[type_key = "..."], #[type_index(TypeIndex::kXxx)] (optional)
# Interacts with: ObjectCore trait, TVMFFIObject header access

# derive(ObjectRef): generates ObjectRefCore + AnyCompatible impls from struct with data: ObjectArc<T>
# Interacts with: ObjectRefCore trait, AnyCompatible trait, impl_try_from_any! macro

# === Crate: tvm-ffi (high-level Rust API) ===

class ObjectArc[T: ObjectCore]:
    """Arc-like ref-counted smart pointer wrapping FFI objects. Rust-native inc_ref/dec_ref."""
    ptr: NonNull[T]
    def new(data: T) -> ObjectArc[T]: ...
    def new_with_extra_items(data: T) -> ObjectArc[T]: ...  # for tail-allocated objects (String, Bytes)
    def from_raw(ptr: *const T) -> ObjectArc[T]: ...
    def into_raw(this: Self) -> *const T: ...
    def strong_count(this: &Self) -> usize: ...
    def weak_count(this: &Self) -> usize: ...
    # Invariant: Drop calls dec_ref; Clone calls inc_ref
    # Invariant: new() writes TVMFFIObject header with combined_ref_count = BOTH_ONE
    # Interacts with: unsafe_::inc_ref/dec_ref (native Rust atomic ops matching C++ protocol)
    # Extension: new_with_extra_items for tail-allocated objects (StringObj, BytesObj, ShapeObj)

class unsafe_:
    """Native Rust ref-counting operations (no C API call overhead)."""
    def inc_ref(handle: *mut TVMFFIObject) -> None: ...  # fetch_add(1, Relaxed)
    def dec_ref(handle: *mut TVMFFIObject) -> None: ...
        # Invariant: mirrors C++ DecRef exactly:
        #   fast path: old == BOTH_ONE -> deleter(BothMask)
        #   slow path: strong==1, weak>0 -> deleter(Strong), then sub weak, if weak==0 deleter(Weak)
    def object_deleter_for_new[T](*mut c_void, i32) -> None: ...          # drop_in_place + dealloc
    def object_deleter_for_new_with_extra_items[T,U](*mut c_void, i32): ...  # handles tail alloc

trait ObjectCore:
    """Unsafe trait marking a type as an FFI object (has TVMFFIObject header)."""
    TYPE_KEY: str                                      # e.g. "ffi.Function"
    def type_index() -> i32: ...                       # static or lazily resolved via TVMFFITypeKeyToIndex
    def object_header_mut(this: &mut Self) -> &mut TVMFFIObject: ...
    # Interacts with: derive(Object) macro, ObjectArc, TVMFFIObject header

trait ObjectCoreWithExtraItems(ObjectCore):
    """For objects with tail-allocated inline data (String, Bytes, Shape)."""
    ExtraItem: type
    def extra_items_count(this: &Self) -> usize: ...
    def extra_items(this: &Self) -> &[ExtraItem]: ...
    # Interacts with: ObjectArc::new_with_extra_items, object_deleter_for_new_with_extra_items

trait ObjectRefCore:
    """Maps ObjectRef wrapper <-> ObjectArc<ContainerType>."""
    ContainerType: ObjectCore
    def data(this: &Self) -> &ObjectArc[ContainerType]: ...
    def into_data(this: Self) -> ObjectArc[ContainerType]: ...
    def from_data(data: ObjectArc[ContainerType]) -> Self: ...
    # Interacts with: derive(ObjectRef) macro, AnyCompatible

trait AnyCompatible:
    """Protocol for types convertible to/from TVMFFIAny (Rust analog of C++ TypeTraits<T>)."""
    def copy_to_any_view(src: &Self, data: &mut TVMFFIAny): ...
    def move_to_any(src: Self, data: &mut TVMFFIAny): ...
    def check_any_strict(data: &TVMFFIAny) -> bool: ...
    def copy_from_any_view_after_check(data: &TVMFFIAny) -> Self: ...
    def move_from_any_after_check(data: &mut TVMFFIAny) -> Self: ...
    def try_cast_from_any_view(data: &TVMFFIAny) -> Result[Self, ()]: ...
    # Interacts with: Any, AnyView, Function argument marshaling
    # Extension: implement for new types to make them passable through FFI

class AnyView:
    """Non-owning type-erased value (wraps TVMFFIAny, lifetime-bounded)."""
    def try_as[T: AnyCompatible](&self) -> Option[T]: ...
    # Invariant: Copy+Clone, no ref-count management

class Any:
    """Owning type-erased value (wraps TVMFFIAny, manages ref counts on Drop/Clone)."""
    def try_as[T: AnyCompatible](&self) -> Option[T]: ...
    # Invariant: Drop dec_refs if type_index >= kTVMFFIStaticObjectBegin
    # Invariant: Clone inc_refs if type_index >= kTVMFFIStaticObjectBegin
    # Interacts with: Function return values, global registry

class Function:
    """Owned FFI function handle (ObjectArc<FunctionObj>)."""
    def call_packed(&self, args: &[AnyView]) -> Result[Any]: ...
    def call_tuple[T: TupleAsPackedArgs](&self, args: T) -> Result[Any]: ...
    def call_tuple_with_len[const LEN, T](&self, args: T) -> Result[Any]: ...
    def get_global(name: &str) -> Result[Function]: ...
    def register_global(name: &str, func: Function) -> Result[()]: ...
    def from_packed(func: Fn(&[AnyView]) -> Result[Any]) -> Function: ...
    def from_typed[F, I, O](func: F) -> Function: ...
    def from_extern_c(handle, safe_call, deleter) -> Function: ...
    # Interacts with: TVMFFIFunctionGetGlobal, TVMFFIFunctionSetGlobal, TVMFFIFunctionCreate
    # Interacts with: CallbackFunctionObjImpl (wraps Rust closures as FunctionObj)

class Error:
    """Owned FFI error (ObjectArc<ErrorObj>). Implements std::error::Error."""
    def new(kind: ErrorKind, message: &str, traceback: &str) -> Error: ...
    def from_raised() -> Error: ...   # TVMFFIErrorMoveFromRaised
    def set_raised(error: &Error): ...  # TVMFFIErrorSetRaised
    def kind(&self) -> ErrorKind: ...
    def message(&self) -> &str: ...
    def backtrace(&self) -> &str: ...
    def with_appended_backtrace(this: Self, bt: &str) -> Self: ...
    # Interacts with: TVMFFIErrorCell, TLS error protocol, check_safe_call! macro

class String:
    """ABI-stable string (SSO for <=7 bytes, heap StringObj otherwise). Wraps TVMFFIAny directly."""
    def as_str(&self) -> &str: ...
    def as_bytes(&self) -> &[u8]: ...
    # Invariant: type_index is kTVMFFISmallStr or kTVMFFIStr
    # Invariant: Clone/Drop manage ref counts for heap strings
    # Interacts with: StringObj (ObjectCoreWithExtraItems), AnyCompatible

class Bytes:
    """ABI-stable byte sequence (SSO for <=7 bytes, heap BytesObj otherwise)."""
    # Same SSO/heap pattern as String

class Tensor:
    """Wraps DLTensor-backed NDArray via TVMFFITensor* C API."""
    def from_slice[T](data: &[T], shape: &[i64]) -> Result[Tensor]: ...
    def data_as_slice[T](&self) -> Result[&[T]]: ...
    # Interacts with: TVMFFITensorFromDLPack, TVMFFITensorToDLPack, NDAllocator

class Shape:
    """Immutable shape descriptor (ObjectCoreWithExtraItems with i64 tail data)."""
    def from_slice(data: &[i64]) -> Shape: ...
    def as_slice(&self) -> &[i64]: ...

class Module:
    """Runtime module for loading shared libraries."""
    def load_from_file(file_name: &str) -> Result[Module]: ...
    def get_function(&self, name: &str) -> Result[Function]: ...
    # Interacts with: ffi.ModuleLoadFromFile, ffi.ModuleGetFunction (global functions)

# Macros:
# tvm_ffi_dll_export_typed_func!(name, func)
#   Expands to: extern "C" fn __tvm_ffi_{name}(handle, args, num_args, result) -> i32
#   Interacts with: __tvm_ffi_ symbol prefix convention, module system
# into_typed_fn!(func, Fn(T0, T1, ...) -> Result<R>)
#   Wraps a Function into a typed Rust closure (0-8 args)
# check_safe_call!(expr), bail!(kind, fmt, ...), ensure!(cond, kind, fmt, ...)
#   Error handling macros with file/line traceback
# Interacts with: Error::from_raised(), Error::set_raised()

def current_stream(device: &DLDevice) -> TVMFFIStreamHandle: ...
def with_stream[T](device, stream, f: FnOnce() -> Result[T]) -> Result[T]: ...
    # Interacts with: TVMFFIEnvSetStream, TVMFFIEnvGetStream
```

## Design Elements
Design elements this commit consumes:
- **C ABI** (`c_api.h`): All extern "C" function declarations. See `.knowledge/designs/0001-c-abi.md`.
- **Object system**: TVMFFIObject 24-byte header, combined ref count protocol, two-phase deletion. See `.knowledge/designs/0002-object-system.md`.
- **Any system**: TVMFFIAny 16-byte tagged union, type index discrimination, SSO for strings. See `.knowledge/designs/0003-any-system.md`.
- **Function system**: TVMFFIFunctionCell (safe_call + cxx_call), packed calling convention, global function registry. See `.knowledge/designs/0004-function-system.md`.
- **Error system**: TVMFFIErrorCell, TLS error propagation, backtrace append protocol. See `.knowledge/designs/0005-error-system.md`.
- **Module system**: `__tvm_ffi_` symbol prefix convention for DLL exports. See `.knowledge/designs/0011-module-system.md`.
- **Containers**: Shape (tail-allocated i64), Tensor (DLTensor wrapper), String/Bytes (SSO + tail-allocated). See `.knowledge/designs/0007-containers.md`.

Design elements this commit produces:
- **Rust crate architecture**: Three-crate workspace (`tvm-ffi-sys` for raw C bindings, `tvm-ffi-macros` for proc macros, `tvm-ffi` for high-level API). No design doc exists.
- **`ObjectCore` / `ObjectRefCore` / `AnyCompatible` trait protocol**: Rust equivalent of C++ `TypeTraits<T>` + `TVM_FFI_DECLARE_OBJECT_INFO`. No design doc exists.
- **Native Rust ref-counting**: `ObjectArc<T>` + `unsafe_::inc_ref/dec_ref` that operate on TVMFFIObject atomics directly (no C API call). No design doc exists.
- **`tvm_ffi_dll_export_typed_func!` macro**: Rust equivalent of `__tvm_ffi_` symbol export pattern. No design doc exists.
- **`into_typed_fn!` macro**: Converts untyped `Function` into typed Rust closure. No design doc exists.

## Usage Examples

**Exporting a Rust function as an FFI-compatible DLL symbol:**
```rust
use tvm_ffi::*;

fn add_one(x: i32) -> Result<i32> { Ok(x + 1) }

tvm_ffi_dll_export_typed_func!(add_one, add_one);
// Generates: extern "C" fn __tvm_ffi_add_one(handle, args, num_args, result) -> i32
```

**Loading a shared library and calling a function from Rust:**
```rust
use tvm_ffi::{Module, Result, Tensor};

let lib = Module::load_from_file("add_one_cpu.so").unwrap();
let add_one_cpu = lib.get_function("add_one_cpu").unwrap();
let typed_add_one = into_typed_fn!(add_one_cpu, Fn(&Tensor, &Tensor) -> Result<()>);

let x = Tensor::from_slice(&[0.0f32, 1.0, 2.0, 3.0], &[4]).unwrap();
let y = Tensor::from_slice(&[0.0f32; 4], &[4]).unwrap();
typed_add_one(&x, &y).unwrap();
```

**Registering and calling global functions from Rust:**
```rust
use tvm_ffi::{Function, Result};

let func = Function::from_typed(|x: i32, y: i32| -> Result<i32> { Ok(x + y) });
Function::register_global("test.rust_add", func).unwrap();

let retrieved = Function::get_global("test.rust_add").unwrap();
let result: i32 = retrieved.call_tuple_with_len::<2, _>((10, 20))?.try_into()?;
assert_eq!(result, 30);
```
