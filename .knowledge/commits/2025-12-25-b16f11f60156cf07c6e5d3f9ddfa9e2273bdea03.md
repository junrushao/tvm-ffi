# Refactor cubin launcher with unified CUDA Driver/Runtime API abstraction and new embedding paths
## TL;DR
- Introduces `cuda_api` namespace (`internal/unified_api.h`) providing a compile-time switchable abstraction over CUDA Driver and Runtime APIs, controlled by `TVM_FFI_CUBIN_LAUNCHER_USE_DRIVER_API` (auto-detected based on `CUDART_VERSION >= 12080`).
- Adds `TVM_FFI_EMBED_CUBIN_FROM_BYTES(name, imageBytes)` macro for loading CUBINs from byte arrays (C++23 `#embed` or `bin2c`), alongside the existing `TVM_FFI_EMBED_CUBIN` linker-based approach.
- Replaces all direct `cuda*` API calls in `CubinModule`/`CubinKernel` with `cuda_api::` wrappers; moves `dim3` to `base.h`, `TVM_FFI_CHECK_CUDA_ERROR` to `unified_api.h`; replaces old CMake functions (`tvm_ffi_generate_cubin`/`tvm_ffi_embed_cubin`) with `add_tvm_ffi_cubin`/`add_tvm_ffi_fatbin`/`tvm_ffi_embed_bin_into`.

## Key Exports

**Consumed design elements:**

**Produced design elements:**

**`cuda_api` namespace** (`extra/cuda/internal/unified_api.h`):
```cpp
namespace tvm::ffi::cuda_api {
  // Type aliases (Driver API or Runtime API depending on flag)
  using StreamHandle;   // CUstream or cudaStream_t
  using DeviceHandle;   // CUdevice or int
  using LibraryHandle;  // CUlibrary or cudaLibrary_t
  using KernelHandle;   // CUkernel or cudaKernel_t
  using ResultType;     // CUresult or cudaError_t
  constexpr ResultType kSuccess;

  // Wrapper functions
  ResultType LoadLibrary(LibraryHandle*, const void*);
  ResultType UnloadLibrary(LibraryHandle);
  ResultType GetKernel(KernelHandle*, LibraryHandle, const char*);
  DeviceHandle GetDeviceHandle(int device_id);
  ResultType LaunchKernel(KernelHandle, void**, dim3, dim3, StreamHandle, uint32_t);
  ResultType GetKernelSharedMem(KernelHandle, int&, DeviceHandle);
  ResultType SetKernelMaxDynamicSharedMem(KernelHandle, int, DeviceHandle);
  ResultType GetDeviceCount(int*);
  ResultType GetDeviceAttribute(int*, DeviceAttrType, DeviceHandle);
}
```

**`TVM_FFI_CUBIN_LAUNCHER_USE_DRIVER_API`** (compile flag):
- Auto-selects: `0` (Runtime API) when `CUDART_VERSION >= 12080`, `1` (Driver API) otherwise.
- User-overridable before including `unified_api.h`.
- `static_assert` if Runtime API requested but CUDA < 12.8.

**`TVM_FFI_EMBED_CUBIN_FROM_BYTES(name, imageBytes)`** macro:
- Creates singleton `EmbedCubinModule_<name>` wrapping `CubinModule{imageBytes}`.
- Paired with existing `TVM_FFI_EMBED_CUBIN_GET_KERNEL(name, kernel_name)`.

**`CubinModule(const unsigned char* code)`** -- new constructor overload for byte arrays.

**`dim3` struct** -- moved from `cubin_launcher.h` to `base.h`.

**CMake functions** (new):
- `add_tvm_ffi_cubin(OUTPUT, SOURCE, ...)` -- compile CUDA to CUBIN
- `add_tvm_ffi_fatbin(OUTPUT, SOURCE, ...)` -- compile CUDA to FATBIN
- `tvm_ffi_embed_bin_into(TARGET, BIN, NAME, ...)` -- embed binary into target via `PRE_LINK`

**CMake functions** (removed):
- `tvm_ffi_generate_cubin` -- replaced by `add_tvm_ffi_cubin`
- `tvm_ffi_embed_cubin` -- replaced by `tvm_ffi_embed_bin_into`

## Impact
- API: `CubinModule::GetHandle()` returns `cuda_api::LibraryHandle` (not `cudaLibrary_t`). `CubinKernel::Launch()` takes `cuda_api::StreamHandle`/`cuda_api::ResultType` (not raw CUDA types). `TVM_FFI_CHECK_CUDA_ERROR` now lives in `unified_api.h` and works with both APIs. `dim3` moved to `base.h`. `base.h` no longer includes `<cuda_runtime.h>`.
- Behavioral: Existing users of `CubinModule`/`CubinKernel` must include `unified_api.h` transitively (via `cubin_launcher.h`). Driver API used on CUDA < 12.8 by default.
- Flags/config: `TVM_FFI_CUBIN_LAUNCHER_USE_DRIVER_API` controls API selection.
- Data formats/schemas: None.

## Usage Examples

**Loading CUBIN from byte array (C++23 `#embed`):**
```cpp
#include <tvm/ffi/extra/cuda/cubin_launcher.h>

// Using C++23 #embed
constexpr unsigned char kernel_image[] = {
  #embed "kernel.cubin"
};
TVM_FFI_EMBED_CUBIN_FROM_BYTES(my_kernels, kernel_image);

void RunKernel() {
  static auto kernel = TVM_FFI_EMBED_CUBIN_GET_KERNEL(my_kernels, "my_kernel");
  void* args[] = { &input, &output };
  TVM_FFI_CHECK_CUDA_ERROR(kernel.Launch(args, tvm::ffi::dim3(grid), tvm::ffi::dim3(block), stream));
}
```
