# Refactor CUBIN launcher with unified CUDA Driver/Runtime API abstraction and declarative CMake utilities
## TL;DR
- Introduces `include/tvm/ffi/extra/cuda/internal/unified_api.h`, a unified abstraction layer over CUDA Driver and Runtime APIs, allowing compile-time selection via `TVM_FFI_CUBIN_LAUNCHER_USE_DRIVER_API` (defaults to Runtime for CUDA >= 12.8, Driver otherwise).
- Replaces imperative CMake functions (`tvm_ffi_generate_cubin`, `tvm_ffi_embed_cubin`) with declarative, target-based CMake functions (`add_tvm_ffi_cubin`, `add_tvm_ffi_fatbin`, `tvm_ffi_embed_bin_into`) that integrate with CMake's native CUDA support and dependency graph.
- Adds `TVM_FFI_EMBED_CUBIN_FROM_BYTES` macro for loading CUBIN/FATBIN from byte arrays (enabling C++23 `#embed` and `bin2c` workflows), and adds `CubinModule(const unsigned char*)` constructor overload.

## Impact
- API: `CubinModule` and `CubinKernel` public API types changed from `cudaLibrary_t`/`cudaKernel_t`/`cudaError_t`/`cudaStream_t` to `cuda_api::LibraryHandle`/`KernelHandle`/`ResultType`/`StreamHandle`. Callers using raw CUDA types for return values or stream parameters need to switch to `cuda_api::` aliases. New `CubinModule(const unsigned char*)` constructor enables byte-array loading.
- Behavioral: `TVM_FFI_CHECK_CUDA_ERROR` now works with both Driver and Runtime API error codes depending on compile-time configuration. `base.h` no longer provides `TVM_FFI_CHECK_CUDA_ERROR` -- it is now in `unified_api.h` (included transitively via `cubin_launcher.h`).
- Flags/config: New compile-time flag `TVM_FFI_CUBIN_LAUNCHER_USE_DRIVER_API` (0 or 1). New CMake variable `CMAKE_CUDA_RUNTIME_LIBRARY` auto-defaulted to `Shared`. Old CMake functions `tvm_ffi_generate_cubin` and `tvm_ffi_embed_cubin` removed.
- Data formats/schemas: None.

## Usage Examples

**Byte-array CUBIN loading with C++23 `#embed`:**
```cpp
#include <tvm/ffi/extra/cuda/cubin_launcher.h>

// Embed FATBIN data from file at compile time
constexpr unsigned char image[]{ #embed "kernel_fatbin.fatbin" };
TVM_FFI_EMBED_CUBIN_FROM_BYTES(my_kernels, image);

void MyFunc(tvm::ffi::TensorView x, tvm::ffi::TensorView y) {
    static auto kernel = TVM_FFI_EMBED_CUBIN_GET_KERNEL(my_kernels, "add_one_cuda");
    int64_t n = x.size(0);
    void* xp = x.data_ptr(), *yp = y.data_ptr();
    void* args[] = {&xp, &yp, &n};
    tvm::ffi::cuda_api::StreamHandle stream = /* ... */;
    TVM_FFI_CHECK_CUDA_ERROR(
        kernel.Launch(args, tvm::ffi::dim3((n+255)/256), tvm::ffi::dim3(256), stream));
}
```

**Declarative CMake embedding (replaces old imperative approach):**
```cmake
# Compile CUDA to FATBIN
add_tvm_ffi_fatbin(kernel_fatbin CUDA src/kernel.cu)
# Build shared library
add_library(lib_embedded SHARED src/lib_embedded.cc)
# Embed FATBIN into shared library
tvm_ffi_embed_bin_into(lib_embedded SYMBOL env BIN "$<TARGET_OBJECTS:kernel_fatbin>")
```
