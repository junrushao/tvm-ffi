# Refactor cubin launcher
## TL;DR
- Major refactoring of the CUDA cubin/fatbin embedding infrastructure.
- Replaces `tvm_ffi_generate_cubin`/`tvm_ffi_embed_cubin` with simpler `add_tvm_ffi_cubin`/`add_tvm_ffi_fatbin` CMake functions using native CUDA support.
- Adds new `ObjectCopyUtil.cmake` helper for post-build object file copying.
- Adds three new example variants for embedded cubin (cpp_embed, embed_with_tvm_ffi, include_bin2c).
- Introduces unified CUDA API wrapper header for driver/runtime API compatibility.

## Key Exports

**CMake Functions:**
- `add_tvm_ffi_cubin(<target> CUDA <source>)` -- Create cubin object library.
- `add_tvm_ffi_fatbin(<target> CUDA <source>)` -- Create fatbin object library.
- `tvm_ffi_embed_binary(<target> SOURCE <cc> BINARY <cubin/fatbin> NAME <sym>)` -- Embed binary into C++ object.

**C++ Header:**
- `tvm/ffi/extra/cuda/internal/unified_api.h` -- Unified CUDA driver/runtime API abstraction.

## Impact
- API: New CMake embedding functions, new unified CUDA API header.
- ABI: none
- Behavioral: Simpler cubin build workflow leveraging native CMake CUDA support.
- Flags/config: `CMAKE_CUDA_RUNTIME_LIBRARY` defaults to Shared.
- Data formats/schemas: none
