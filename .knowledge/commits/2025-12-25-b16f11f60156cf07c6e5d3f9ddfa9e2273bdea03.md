# feat: Refactor cubin launcher to support both CUDA Runtime API (>=12.8) and Driver API via unified_api.h abstraction

## TL;DR
- Introduces `include/tvm/ffi/extra/cuda/internal/unified_api.h` (206 lines): compile-time API selector between CUDA Runtime API (CUDA >= 12.8) and CUDA Driver API via `TVM_FFI_CUBIN_LAUNCHER_USE_DRIVER_API` flag
- Removes hand-rolled `tvm::ffi::dim3` struct from `cubin_launcher.h`; uses CUDA-provided types directly via the unified API layer
- Adds `TVM_FFI_EMBED_CUBIN_FROM_BYTES(name, imageBytes)` macro for embedding CUBIN from byte arrays (e.g. `#embed`/bin2c); reorganizes `examples/cubin_launcher/embedded_cubin/` into three sub-examples: `cpp_embed`, `embed_with_tvm_ffi`, `include_bin2c`
- Refactors `cmake/Utils/EmbedCubin.cmake` (net +93/-176 effective) and adds `cmake/Utils/ObjectCopyUtil.cmake` for binary file embedding utilities

## Impact
- API: `tvm::ffi::dim3` removed from `cubin_launcher.h`; callers must use CUDA-native `dim3` or `cuda_api::` types
- Behavioral: On CUDA < 12.8, Driver API path is used; on CUDA >= 12.8, Runtime API is used by default (can override with `TVM_FFI_CUBIN_LAUNCHER_USE_DRIVER_API`)
- Flags/config: New compile-time macro `TVM_FFI_CUBIN_LAUNCHER_USE_DRIVER_API`
- Data formats/schemas: none
