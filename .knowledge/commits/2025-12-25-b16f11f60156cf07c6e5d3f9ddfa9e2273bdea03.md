# Refactor cubin launcher with unified CUDA API and multiple embedding strategies
## TL;DR
- Refactors cubin launcher CMake utilities (`EmbedCubin.cmake`) and adds `ObjectCopyUtil.cmake`.
- Introduces `include/tvm/ffi/extra/cuda/internal/unified_api.h` for unified CUDA driver/runtime API.
- Expands examples with three embedding strategies: `cpp_embed`, `embed_with_tvm_ffi`, and `include_bin2c`.

## Impact
- API: New internal header `unified_api.h`; refactored `cubin_launcher.h` public API.
- Flags/config: None.
- Data formats/schemas: None.
