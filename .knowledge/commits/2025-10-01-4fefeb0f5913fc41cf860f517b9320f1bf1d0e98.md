# Allow null strides for zero-ndim tensors in Tensor and TensorView
## TL;DR
- Relaxes the strides-not-null invariant in `Tensor::strides()`, `TensorView::strides()`, and three `FromDLPack` variants to accept null strides when `ndim == 0` (scalar tensors).
- Before this fix, scalar tensors imported from DLPack with null strides would trigger an internal check failure or take the wrong construction path.

## Key Exports

```python
class Tensor(ObjectRef):
    def strides(self) -> ShapeView: ...
        # Invariant (updated): strides pointer may be null when ndim == 0;
        #   check is `strides != nullptr || ndim == 0`
        # Interacts with: ShapeView (returns empty view when ndim == 0 and strides is null)

    @staticmethod
    def FromNDAlloc(...) -> "Tensor": ...
        # Invariant (updated): treats ndim == 0 with null strides as "strides present"
        #   (uses TensorObjFromDLPack without extra_strides_at_tail)

    @staticmethod
    def FromDLPack(tensor: DLManagedTensor, ...) -> "Tensor": ...
        # Invariant (updated): same null-strides-with-ndim-0 treatment

    @staticmethod
    def FromDLPackVersioned(tensor: DLManagedTensorVersioned, ...) -> "Tensor": ...
        # Invariant (updated): same null-strides-with-ndim-0 treatment

class TensorView:
    def strides(self) -> ShapeView: ...
        # Invariant (updated): mirrors Tensor.strides() relaxation
```

## Impact
- API: none (no signature changes)
- Behavioral: `Tensor::strides()` and `TensorView::strides()` no longer crash on zero-ndim tensors with null strides. `FromDLPack`/`FromDLPackVersioned`/`FromNDAlloc` now correctly take the "strides present" path for zero-ndim tensors, avoiding unnecessary inplace-array allocation of a zero-length strides array.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
Before (crashes on scalar tensor from DLPack with null strides):
```cpp
DLManagedTensor* scalar_dlpack = get_scalar_tensor();
// scalar_dlpack->dl_tensor.ndim == 0, strides == nullptr
Tensor t = Tensor::FromDLPack(scalar_dlpack);
ShapeView s = t.strides();  // CRASH: TVM_FFI_ICHECK(strides != nullptr) fails
```

After (correctly returns empty ShapeView):
```cpp
DLManagedTensor* scalar_dlpack = get_scalar_tensor();
Tensor t = Tensor::FromDLPack(scalar_dlpack);
ShapeView s = t.strides();  // OK: returns ShapeView(nullptr, 0) — empty view
assert(s.size() == 0);
```
