# Fix strides null-check in Tensor and TensorView to allow null strides for zero-ndim tensors

## TL;DR
- Five identical `strides != nullptr` guards in `tensor.h` are changed to `strides != nullptr || ndim == 0`, fixing a crash when processing zero-dimensional tensors whose strides pointer is null.
- Affected sites: `Tensor::strides()`, `Tensor::FromDLPackVersioned` (two call sites), `Tensor::FromDLPack`, and `TensorView::strides()`.

## Key Exports

```python
# include/tvm/ffi/container/tensor.h — changed invariant (before → after)

class Tensor:
    def strides(self) -> ShapeView:
        # Before: TVM_FFI_ICHECK(strides != nullptr)
        # After:  TVM_FFI_ICHECK(strides != nullptr || ndim == 0)
        # Invariant (restored): strides may be null iff ndim == 0

    @staticmethod
    def FromDLPackVersioned(tensor: DLManagedTensorVersioned*) -> Tensor:
        # Before: if tensor.strides != nullptr → use strides path
        # After:  if tensor.strides != nullptr || tensor.ndim == 0 → use strides path
        # Behavioral change: zerodim tensors now correctly routed to strides-aware constructor

    @staticmethod
    def FromDLPack(tensor: DLManagedTensor*) -> Tensor:
        # Same fix as FromDLPackVersioned

class TensorView:
    def strides(self) -> ShapeView:
        # Before: TVM_FFI_ICHECK(strides != nullptr)
        # After:  TVM_FFI_ICHECK(strides != nullptr || ndim == 0)
```

## Impact
- API: None — no signature changes. Behavioral fix only.
- Behavioral: Zero-dimensional tensors with null strides no longer trigger assertion failures in `strides()` or `FromDLPack*` routing. The `FromDLPack*` functions now correctly select the strides-present constructor for ndim==0 tensors, matching DLPack convention where null strides on a scalar tensor is valid.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

```cpp
// Before (crash):
DLManagedTensorVersioned vtensor = make_zero_dim_tensor();  // ndim=0, strides=nullptr
auto t = ffi::Tensor::FromDLPackVersioned(&vtensor);  // ← assert fired: strides != nullptr

// After (correct):
auto t = ffi::Tensor::FromDLPackVersioned(&vtensor);  // ← succeeds; routes to strides path
auto sv = t.strides();  // returns empty ShapeView(nullptr, 0) — safe since ndim==0
```
