# Revert 'feat: Add tvm_ffi.Function.__init__' due to downstream breakage

## TL;DR
- Reverts commit 8786670af20e ("feat: Add `tvm_ffi.Function.__init__`").
- The feature broke a downstream use case where `tvm_ffi.Function()` was called as a no-arg constructor (a "wrong" usage that nevertheless existed in downstream code).
- Removes `Function.__init__` from `function.pxi`, stub from `core.pyi`, and tests from `test_function.py`.

## Key Exports

None — revert removes previously added API.

## Impact
- API: **removes** `Function.__init__(func)` Python constructor added in 8786670. `tvm_ffi.Function(some_fn)` no longer works.
- Behavioral: `Function.__cinit__` remains (low-level Cython init); `Function(callable)` constructor removed.
- Flags/config: none
- Data formats/schemas: none
