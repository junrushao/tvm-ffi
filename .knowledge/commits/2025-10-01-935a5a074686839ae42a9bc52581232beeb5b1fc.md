# Rename type_schema to metadata in field/method info, add GetFunctionDoc to ModuleObj
## TL;DR
- Renames `type_schema` field to `metadata` in both `TVMFFIFieldInfo` and `TVMFFIMethodInfo` C structs, reflecting the broader intent of storing structured JSON metadata (not just type schemas).
- Adds `ModuleObj::GetFunctionDoc(name)` virtual method and `GetFunctionDoc(name, query_imports)` method, separating unstructured docstrings from structured metadata. Registers `ffi.ModuleGetFunctionDoc` global function.
- Updates all consumers: `registry.h` (`GlobalDef`, `ObjectDef`), `function.cc` (`GlobalFunctionTable::Entry`), `object.cc` (`TypeTable`), and `base.pxi` Cython declarations.

## Impact
- API: ABI-breaking. `TVMFFIFieldInfo.type_schema` and `TVMFFIMethodInfo.type_schema` renamed to `metadata`. `ModuleObj` gains `GetFunctionDoc` virtual method. New `ffi.ModuleGetFunctionDoc` global function.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Reflection system** ([`.knowledge/designs/0006-reflection.md`](../designs/0006-reflection.md)): `TVMFFIFieldInfo` and `TVMFFIMethodInfo` structs.
- **Module system** ([`.knowledge/designs/0008-module-export-system.md`](../designs/0008-module-export-system.md)): `ModuleObj` virtual interface.
- **Function system** ([`.knowledge/designs/0004-function-system.md`](../designs/0004-function-system.md)): `GlobalFunctionTable::Entry` stores method metadata.

Design elements this commit produces:
- **Doc/metadata separation for functions**: Docstrings (unstructured, potentially large) are now separate from metadata (structured JSON). This enables efficient metadata queries without loading full docstrings.
- **`ModuleObj::GetFunctionDoc`**: New virtual method enabling modules to expose per-function documentation.
