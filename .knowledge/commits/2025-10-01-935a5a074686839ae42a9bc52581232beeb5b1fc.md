# Rename type_schema to metadata in C ABI reflection structs and add ModuleObj::GetFunctionDoc virtual extension

## TL;DR
- Renames `type_schema` → `metadata` in `TVMFFIFieldInfo` and `TVMFFIMethodInfo` C ABI structs, aligning with the design principle that docstrings are unstructured/large while metadata is focused structured JSON. The rename propagates through C header, C++ impl (`function.cc`, `object.cc`), reflection builder (`registry.h`), and Cython bindings (`base.pxi`).
- Adds `ModuleObj::GetFunctionDoc(name)` virtual extension (default: `std::nullopt`) and its public non-virtual traversal variant `GetFunctionDoc(name, query_imports)` in `ModuleObj`, registered as global `ffi.ModuleGetFunctionDoc`.
- The commit message confirms `ModuleObj` C++ ABI is broken for direct C++ callers, but Python users are unaffected (they access functions via packed registry, not struct fields directly).

### Rename mapping table
| Old name | New name | Location |
|---|---|---|
| `TVMFFIFieldInfo::type_schema` | `TVMFFIFieldInfo::metadata` | `include/tvm/ffi/c_api.h` |
| `TVMFFIMethodInfo::type_schema` | `TVMFFIMethodInfo::metadata` | `include/tvm/ffi/c_api.h` |
| `GlobalFunctionTable::Entry::type_schema_data` | `GlobalFunctionTable::Entry::metadata_data` | `src/ffi/function.cc` |

    def GetFunctionDoc(self, name: String, query_imports: bool) -> Optional[String]:
        """Check self first; if query_imports, walk imports_ chain in insertion order."""
        # Interacts with: ModuleObj.imports_ (import chain traversal), ffi.ModuleGetFunctionDoc

    # Previously existing (unchanged):
    def GetFunctionMetadata(self, name: String) -> Optional[String]: ...

## Impact
- API: `TVMFFIFieldInfo::type_schema` and `TVMFFIMethodInfo::type_schema` renamed to `metadata` — any C/C++ code reading these struct fields by name must be updated. This is a C ABI break at the C++ struct-field level; binary-level break only if the field layout changed (it did not — same offset and type, just the field name).
- Behavioral: `GetFunctionDoc` is additive; no existing behavior changed. Default returns `nullopt` (backward compatible for all existing `ModuleObj` subclasses).
- Flags/config: none.
- Data formats/schemas: `metadata` JSON field semantics now formally separated from docstring prose (`doc`).

## Design Elements
Design elements this commit consumes:
- `0001-c-abi` — `TVMFFIFieldInfo`, `TVMFFIMethodInfo` structs (mutated: rename field)
- `0004-function-system` — `GlobalFunctionTable::Entry` (mutated: rename internal field `type_schema_data` → `metadata_data`); `GlobalDef`/`ObjectDef` in `registry.h` (mutated: init site now writes `info.metadata`)
- `0006-reflection` — `GlobalDef`, `ObjectDef` field/method registration builders (mutated: `info.type_schema` → `info.metadata`)
- `0011-module-system` — `ModuleObj` virtual interface (mutated: new virtual + public traversal method added); import chain traversal pattern (consumed by new `GetFunctionDoc`)

Design elements this commit produces:
- **`ModuleObj::GetFunctionDoc`** — new virtual extension point for unstructured docstrings, analogous to `GetFunctionMetadata` for structured JSON. Extends `0011-module-system`.
- **`ffi.ModuleGetFunctionDoc`** global function — Python-accessible entry for cross-layer doc retrieval.
- **`metadata` field convention** — establishes the semantic split: `doc` = unstructured prose, `metadata` = focused structured JSON. This replaces the prior `type_schema` field name, which conflated schema with general metadata.

## Usage Examples

Cross-layer trace: override `GetFunctionDoc` in C++, access from Python.

```cpp
// C++: override virtual in a concrete ModuleObj subclass
class MyModuleObj : public ModuleObj {
  Optional<String> GetFunctionDoc(const String& name) override {
    if (name == "my_kernel")
      return String("Computes element-wise add. Args: (a: Tensor, b: Tensor) -> Tensor");
    return std::nullopt;
  }
  // GetFunctionMetadata still separate — returns JSON for typed schema
  Optional<String> GetFunctionMetadata(const String& name) override {
    if (name == "my_kernel")
      return String("{\"num_args\": 2, \"dtype\": \"float32\"}");
    return std::nullopt;
  }
};
```

```python
# Python: access via global function registry
get_doc = tvm_ffi.get_global_func("ffi.ModuleGetFunctionDoc")
doc = get_doc(my_module, "my_kernel", True)  # query_imports=True walks import chain
# doc -> str or None
```
