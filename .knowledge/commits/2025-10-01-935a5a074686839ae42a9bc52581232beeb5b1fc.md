# Stabilize doc and metadata ABI for functions and modules
## TL;DR
- Renames `type_schema` field to `metadata` in both `TVMFFIFieldInfo` and `TVMFFIMethodInfo` C ABI structs, clarifying that it stores structured JSON metadata rather than type schema.
- Adds `GetFunctionDoc` virtual method to `ModuleObj` alongside existing `GetFunctionMetadata`, separating unstructured docstrings from structured metadata.
- Registers `ffi.ModuleGetFunctionDoc` packed function for cross-language access.

## Key Exports

```python
class TVMFFIFieldInfo:
    name: TVMFFIByteArray
    doc: TVMFFIByteArray       # Unstructured docstring
    metadata: TVMFFIByteArray  # Structured JSON metadata (was: type_schema)
    # Interacts with: ObjectDef.def_field, TypeTable field registration

class TVMFFIMethodInfo:
    name: TVMFFIByteArray
    doc: TVMFFIByteArray       # Unstructured docstring
    metadata: TVMFFIByteArray  # Structured JSON metadata (was: type_schema)
    # Interacts with: ObjectDef.def_method, GlobalDef, TypeTable method registration

class ModuleObj:
    def GetFunctionDoc(self, name: str) -> Optional[str]:
        """Get function docstring. Default returns None."""
        # Interacts with: GetFunctionMetadata (separate concern)
        ...
    def GetFunctionDoc(self, name: str, query_imports: bool) -> Optional[str]:
        """Query doc with optional import traversal."""
        ...
```

## Impact
- API: `TVMFFIFieldInfo.type_schema` renamed to `metadata`. `TVMFFIMethodInfo.type_schema` renamed to `metadata`. New `ModuleObj::GetFunctionDoc` virtual method. `ModuleObj` C++ ABI changed (new virtual method).
- Behavioral: None -- rename only for existing fields; new doc method defaults to `None`.
- Flags/config: None
- Data formats/schemas: C ABI struct field rename (`type_schema` -> `metadata`).
