# Add Array concatenation via `+` operator and broaden constructor to accept Iterable

## TL;DR
- Adds `__add__` and `__radd__` dunder methods to `tvm_ffi.Array`, enabling `array1 + array2` concatenation that returns a new `Array`.
- Broadens `Array.__init__` parameter type from `Sequence[T]` to `Iterable[T]`, enabling construction from any iterable (including `itertools.chain` used internally by concatenation).
- Both `__add__` and `__radd__` accept any `Iterable[T]`, so `Array + list`, `list + Array`, `Array + tuple`, etc. all work.

## Impact
- API: Additive only. `Array.__init__` type annotation broadened from `Sequence[T]` to `Iterable[T]` -- all existing callers passing sequences still work. Two new dunder methods added.
- Behavioral: `Array` objects can now be concatenated with `+`. Previously this raised `TypeError`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Container suite** (`.knowledge/designs/0007-containers.md`): `Array` class, its immutability invariant, and the `_ffi_api.Array` constructor FFI function.
- **Python bindings** (`.knowledge/designs/0012-python-bindings.md`): `register_object`, `__init_handle_by_constructor__` pattern for constructing FFI objects from Python.

Design elements this commit produces:
- **Array concatenation protocol**: `__add__`/`__radd__` on `Array`, following Python sequence concatenation convention. Implementation materializes a new Array from chained iterators rather than using a C++ concatenation function.
- **Iterable constructor widening**: `Array.__init__` now accepts any `Iterable[T]`, not just `Sequence[T]`. This is a prerequisite for `itertools.chain`-based concatenation but also independently useful.

## Usage Examples

Concatenating Array with Array, list, or tuple (from tests):

```python
import tvm_ffi

a = tvm_ffi.Array([1, 2, 3])
b = tvm_ffi.Array([4, 5, 6])

# Array + Array
c = a + b
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# Array + list
c = a + [4, 5, 6]
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# list + Array (uses __radd__)
c = [1, 2, 3] + b
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# Array + tuple
c = a + (4, 5, 6)
assert tuple(c) == (1, 2, 3, 4, 5, 6)
```
