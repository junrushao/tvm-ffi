# Add `__add__`/`__radd__` to Python `Array` for concatenation via `+` operator
## TL;DR
- Adds `__add__` and `__radd__` dunder methods to `tvm_ffi.Array`, enabling `array1 + array2` concatenation with other `Array` instances, lists, or tuples.
- Widens `Array.__init__` parameter type from `Sequence[T]` to `Iterable[T]` to support `itertools.chain` used internally by concatenation.
- Adds comprehensive parametrized tests covering Array+Array, Array+list, list+Array, empty arrays, and Array+tuple combinations.

## Impact
- API: Additive -- new `__add__`/`__radd__` methods on `Array`. `__init__` parameter type widened from `Sequence[T]` to `Iterable[T]` (backward-compatible since all sequences are iterables).
- Behavioral: `Array` now participates in `+` operator dispatch. `list + Array` works via `__radd__` since `list.__add__` returns `NotImplemented` for non-list types.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
From the test suite (`tests/python/test_container.py`):
```python
import tvm_ffi

# Array + Array
a = tvm_ffi.Array([1, 2, 3])
b = tvm_ffi.Array([4, 5, 6])
c = a + b
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# Array + list
c = a + [4, 5, 6]
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# list + Array (uses __radd__)
c = [1, 2, 3] + b
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# Array + tuple
c = a + (4, 5, 6)
assert tuple(c) == (1, 2, 3, 4, 5, 6)
```
