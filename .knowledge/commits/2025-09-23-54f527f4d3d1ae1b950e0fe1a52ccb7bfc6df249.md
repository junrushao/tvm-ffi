# Add Array concatenation via + operator and widen constructor to Iterable in Python
## TL;DR
- Adds `__add__` and `__radd__` dunder methods to `tvm_ffi.Array`, enabling `array1 + array2` concatenation that returns a new `Array`.
- Widens the `Array.__init__` parameter type from `Sequence[T]` to `Iterable[T]`, enabling construction from any iterable (including `itertools.chain`).
- Comprehensive parametrized tests cover Array+Array, Array+list, list+Array, Array+tuple, tuple+Array, and empty-array edge cases.

## Impact
- API: Additive -- new `__add__`/`__radd__` methods on `Array`; constructor signature widened from `Sequence[T]` to `Iterable[T]` (backward-compatible).
- Behavioral: `Array + Array` and `Array + list` now work instead of raising `TypeError`. `list + Array` triggers `__radd__` since `list.__add__` returns `NotImplemented` for non-list operands.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Array Python wrapper** (0006-containers, 0012-python-bindings): The `Array` class registered as `ffi.Array`, backed by `ArrayObj` with inplace array storage. Constructor delegates to `_ffi_api.Array` via `__init_handle_by_constructor__`.
- **`type(self)` subclass preservation pattern**: Uses `type(self)(...)` instead of `Array(...)` to ensure that subclasses of Array (if any) return instances of the subclass.

Design elements this commit produces:
- **Array concatenation protocol**: `__add__`/`__radd__` dunder pair that enables `+` operator on Array, using `itertools.chain` for lazy element iteration followed by Array construction. This is a standard Python sequence enrichment, not a new architectural pattern.

## Usage Examples
Array concatenation with various operand types (from the test suite):
```python
import tvm_ffi

# Array + Array
a = tvm_ffi.Array([1, 2, 3])
b = tvm_ffi.Array([4, 5, 6])
c = a + b
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# Array + list
c = a + [4, 5, 6]
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# list + Array (triggers __radd__)
c = [1, 2, 3] + b
assert type(c) is type(b)  # returns Array, not list
assert tuple(c) == (1, 2, 3, 4, 5, 6)

# Array + tuple
c = a + (4, 5, 6)
assert tuple(c) == (1, 2, 3, 4, 5, 6)
```
