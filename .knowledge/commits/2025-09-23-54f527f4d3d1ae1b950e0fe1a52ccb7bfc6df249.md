# Support Array concatenation with + operator in Python
## TL;DR
- Adds `__add__` and `__radd__` methods to `Array` class using `itertools.chain`, enabling `Array + Array` and `list + Array` concatenation.
- Changes `Array.__init__` parameter from `Sequence[T]` to `Iterable[T]` to accept iterators (including `chain` objects).

## Impact
- API: New `Array.__add__` and `Array.__radd__` methods. `Array` constructor now accepts any `Iterable[T]`.
- Flags/config: none
- Data formats/schemas: none
