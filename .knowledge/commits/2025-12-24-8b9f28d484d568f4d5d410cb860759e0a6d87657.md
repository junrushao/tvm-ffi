# Fix missing pthread and dl link dependencies for tvm_ffi shared/static libraries

## TL;DR
- Added `find_package(Threads REQUIRED)` and linked `Threads::Threads` to both `tvm_ffi_shared` (PRIVATE) and `tvm_ffi_static` (INTERFACE), fixing `std::mutex` usage in `src/ffi/backtrace.cc`.
- Conditionally linked `${CMAKE_DL_LIBS}` (i.e., `-ldl`) when `TVM_FFI_USE_EXTRA_CXX_API` is enabled, fixing `dlsym`/`dlopen` usage in `src/ffi/extra/library_module_dynamic_lib.cc`.

## Key Exports

None -- no new public API. This commit only fixes CMake link dependencies.

## Impact
- API: none
- Behavioral: Fixes linker errors on platforms where pthread and dl are not implicitly linked (e.g., some Linux toolchains). Resolves GitHub issue #344.
- Flags/config: none (uses existing `TVM_FFI_USE_EXTRA_CXX_API` CMake option to guard dl linking)
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **CMake build system** (0013-ffi-packaging-and-distribution): The `tvm_ffi_shared` and `tvm_ffi_static` targets defined in the root `CMakeLists.txt`, created by `tvm_ffi_add_target_from_obj`.
- **`TVM_FFI_USE_EXTRA_CXX_API` option** (0013-ffi-packaging-and-distribution): Guards the extra C++ API sources including `library_module_dynamic_lib.cc` which uses `dlsym`/`dlopen`.

Design elements this commit produces: none

## Usage Examples

**Before (broken)**: On Linux toolchains that don't implicitly link pthread/dl, building `tvm_ffi_shared` succeeds at compile time but fails at link time with undefined references to `pthread_mutex_lock` or `dlsym`.

**After (fixed)**: CMake's `find_package(Threads REQUIRED)` discovers the platform-appropriate threading library, and `CMAKE_DL_LIBS` provides the portable dl library name. Both are linked correctly:
```cmake
# Threading (always needed -- backtrace.cc uses std::mutex)
target_link_libraries(tvm_ffi_shared PRIVATE Threads::Threads)
target_link_libraries(tvm_ffi_static INTERFACE Threads::Threads)

# Dynamic loading (only when extra CXX API is enabled)
if (TVM_FFI_USE_EXTRA_CXX_API AND CMAKE_DL_LIBS)
  target_link_libraries(tvm_ffi_shared PRIVATE ${CMAKE_DL_LIBS})
  target_link_libraries(tvm_ffi_static INTERFACE ${CMAKE_DL_LIBS})
endif ()
```
