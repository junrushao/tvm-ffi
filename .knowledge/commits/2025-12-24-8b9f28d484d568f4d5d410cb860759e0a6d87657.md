# Link dl and pthread dependencies for tvm_ffi
## TL;DR
- Links `Threads::Threads` (pthread) and `${CMAKE_DL_LIBS}` (dl) to tvm_ffi shared and static targets.
- Fixes missing link dependencies when using extra C++ API features (module loading requires dlopen).
