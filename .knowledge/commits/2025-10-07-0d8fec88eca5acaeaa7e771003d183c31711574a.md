# Introduce clang-tidy configuration and apply bulk modernization, performance, and correctness fixes
## TL;DR
- Adds `.clang-tidy` configuration file enabling `modernize-*`, `bugprone-*`, `performance-*`, `portability-*`, `google-*`, and `clang-analyzer-*` check families (with targeted exclusions) and a `tests/lint/clang_tidy_precommit.py` runner script.
- Applies ~600 lines of clang-tidy-suggested fixes across all C++ headers and sources: `noexcept` on move constructors/assignments, `std::move` for pass-by-value parameters, `using` instead of `typedef`, `_v`/`_t` trait suffixes, `static_cast` for narrowing conversions, `R"()"` raw strings, range-based `for` loops, and NOLINT annotations where suppression is appropriate.
- Includes several correctness fixes: `ObjectRef` move constructor/assignment explicitly nulls the source pointer, `MoveTVMFFIAnyToAny` now takes `TVMFFIAny*` instead of `TVMFFIAny&&` to avoid dangling-reference UB, `JSONParser` stores its input `String` to prevent use-after-free, `Object()` default constructor zero-initializes all header fields, and `InplaceArrayBase`/`ObjAllocatorBase` restrict default constructors to CRTP friends.

## Key Exports

**Configuration files**:
- `.clang-tidy` -- Project-wide clang-tidy configuration. Enables `clang-diagnostic-*`, `clang-analyzer-*`, `modernize-*`, `bugprone-*`, `performance-*`, `portability-*`, `google-*` with `WarningsAsErrors: '*'`. Key exclusions: `-modernize-use-trailing-return-type`, `-modernize-concat-nested-namespaces`, `-modernize-use-auto`, `-modernize-use-nodiscard`, `-modernize-return-braced-init-list`, `-modernize-avoid-c-arrays`, `-bugprone-easily-swappable-parameters`, `-google-build-using-namespace`, `-performance-enum-size`, `-clang-analyzer-unix.Malloc`, `-performance-avoid-endl`. Header filter: `(include/tvm/ffi|src/ffi)/.*\.h$`.

**Scripts**:
- `tests/lint/clang_tidy_precommit.py` -- 162-line Python script that runs clang-tidy on specified source directories using a CMake compilation database. Supports `--build-dir`, `--jobs`, `--fix` flags. Generates the `compile_commands.json` via CMake if not present.

**Signature changes**:
- `AnyUnsafe::MoveTVMFFIAnyToAny(TVMFFIAny&&)` changed to `AnyUnsafe::MoveTVMFFIAnyToAny(TVMFFIAny*)` -- takes pointer instead of rvalue reference to avoid dangling reference.
- `ObjectRef(ObjectRef&&)` -- changed from `= default` to explicit implementation that nulls source `data_` pointer. Same for `ObjectRef::operator=(ObjectRef&&)`.
- `ModuleObj::InspectSource(const String& format = "")` -- default argument removed from virtual declaration; becomes `InspectSource(const String& format)`.
- `GetDataSize(int64_t numel, DLDataType)` -- first parameter changed from `int64_t` to `size_t`.
- `Tensor::FromDLPackAlloc` -- `ffi::Shape` parameter changed to `ffi::ShapeView`.
- `FunctionObj::FCall` -- changed from `typedef` to `using` alias (no semantic change).
- `FObjectDeleter` -- changed from `typedef` to `using` alias (no semantic change).
- `FGetFuncSignature` -- changed from `typedef` to `using` alias (no semantic change).
- `TVM_FFI_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN` macro -- move constructor and move assignment now include `noexcept`.
- `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` / `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE` macros -- `ObjectPtr<ObjectName> n` constructor now uses `std::move(n)`.
- `TVM_FFI_ICHECK_BINARY_OP` macro -- internal variable renamed from `__tvm__log__err` to `__tvm_ffi_log_err`.

**Access control changes**:
- `InplaceArrayBase` -- default constructor made private, friended to `ArrayType` (CRTP child).
- `ObjAllocatorBase` -- default constructor made private, friended to `Derived` (CRTP child).
- `Object()` default constructor -- now zero-initializes `type_index`, `__padding`, and `__ensure_align` fields (previously only zeroed `combined_ref_count` and `deleter`).

## Impact
- API: `MoveTVMFFIAnyToAny` signature changed from rvalue-ref to pointer. `ModuleObj::InspectSource` loses its default argument for the virtual method (callers passing no argument must now pass `""`). `GetDataSize` first parameter widened from `int64_t` to `size_t`. `Tensor::FromDLPackAlloc` takes `ShapeView` instead of `Shape`. `InplaceArrayBase` and `ObjAllocatorBase` default constructors are now private.
- ABI: None. All changes are source-level. The C ABI layer (`c_api.h`) is wrapped in `NOLINTBEGIN/END` and unchanged semantically.
- Behavioral: `ObjectRef` move operations now explicitly null the source pointer (was implementation-defined with `= default`). `Object()` zero-initializes more header fields. `JSONParser` no longer risks use-after-free of its input string.
- Flags/config: New `.clang-tidy` configuration file. New `tests/lint/clang_tidy_precommit.py` script. clang-tidy not yet added to CI.
