# Introduce clang-tidy and apply codebase-wide C++ quality fixes
## TL;DR
- Adds `.clang-tidy` configuration (modernize, bugprone, performance, google, clang-analyzer checks with WarningsAsErrors) and a parallel `clang_tidy_precommit.py` runner script.
- Applies clang-tidy-suggested fixes across 60+ files: `noexcept` on move ops, `std::move` for pass-by-value params, modern type traits (`_v`/`_t` suffixes), `using` instead of `typedef`, `static_cast` for narrowing conversions, range-based for loops, raw string literals for JSON, and explicit NOLINT annotations for intentional patterns.
- Fixes several subtle correctness issues: `MoveTVMFFIAnyToAny` dangling-reference (now takes pointer), JSON parser dangling-reference (stores `String` in `storage_` member), dead code removal in `StableHashBytes`, `unsigned char` casts in base64/JSON for sign-extension safety.

## Key Exports
None (no new public API surface; all changes are internal quality improvements)

## Impact
- API: `MoveTVMFFIAnyToAny` signature changed from `TVMFFIAny&&` to `TVMFFIAny*`; `Tensor::FromDLPackAlloc` parameter changed from `ffi::Shape` to `ffi::ShapeView`; `ModuleObj::InspectSource` removed default argument for `format` parameter; `GetDataSize` first parameter changed from `int64_t` to `size_t`; `Module(ObjectPtr<ModuleObj>)` constructor now takes `const ObjectPtr<ModuleObj>&`; `AccessPath::FromSteps` now takes `const Array<AccessStep>&`.
- Behavioral: `ObjectRef` move constructor/assignment now explicitly null out the source `data_` pointer (was `= default` before, now manual). `BytesBaseCell::operator=(&&)` marked `noexcept`. `Metadata` constructor lost `explicit` qualifier. `reflection::_MetadataType` reserved-identifier NOLINT added.
- Flags/config: New `.clang-tidy` file controls which checks are active. `WarningsAsErrors: '*'` means all enabled checks are treated as errors.
- Data formats/schemas: none
