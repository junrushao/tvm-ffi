# Apply clang-tidy fixes across codebase and add .clang-tidy config
## TL;DR
- Introduces `.clang-tidy` configuration and `tests/lint/clang_tidy_precommit.py` runner script.
- Applies a wide set of clang-tidy-suggested fixes across all C++ headers and sources: style modernizations (`_v`/`_t` suffixes, `using` over `typedef`, range-for), performance (`std::move`), and correctness (`noexcept`, explicit casts, dangling pointer fixes).
- Touches nearly every C++ file in the project but is a non-functional refactor.

## Impact
- API: No functional API changes. Some internal function signatures gain `noexcept`.
- Flags/config: New `.clang-tidy` config file. New lint script `tests/lint/clang_tidy_precommit.py`.
- Data formats/schemas: None.
