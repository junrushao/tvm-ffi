# Introduce clang-tidy and apply codebase-wide C++ modernization and correctness fixes
## TL;DR
- Adds `.clang-tidy` configuration and `tests/lint/clang_tidy_precommit.py` runner script enabling clang-tidy as a lint tool (not yet in CI).
- Applies ~340 net LOC of clang-tidy-suggested fixes across 63 files: `noexcept` on move constructors/assignments, `std::move` for sink parameters, `std::is_base_of_v`/`std::is_same_v` modernization, `using` over `typedef`, raw string literals (`R"(...)"`), explicit casts to silence narrowing warnings, and range-based for loops.
- Fixes a dangling-pointer bug in `JSONParser` where `String` storage was moved-from before the parser context used it, and a missed `SyncMethodInfo` in `GlobalFunctionTable::Entry` that left the `method` field unset for manually-constructed entries.

## Impact
- API: `AnyUnsafe::MoveTVMFFIAnyToAny` signature changed from rvalue-ref to pointer. Internal-only API, but any direct callers (e.g., `Variant` `MoveFromAnyAfterCheck`) updated in same commit.
- Behavioral: `JSONParser` no longer has a dangling pointer when parsing; `GlobalFunctionTable::Entry` now correctly populates the `method` field for all construction paths; `Object` constructor now zero-initializes `type_index`, `__padding`, and `__ensure_align` (was only zeroing `combined_ref_count` and `deleter`). `Tensor::FromDLPackAlloc` now takes `ShapeView` instead of `Shape` (relaxes parameter type).
- Flags/config: New `.clang-tidy` config file controls which checks are active. `WarningsAsErrors: '*'` means all enabled warnings are errors.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Any/AnyView** (`any.h`) — adds `noexcept` to move ops, fixes `MoveTVMFFIAnyToAny` dangling move.
- **Object/ObjectRef** (`object.h`) — adds `noexcept` moves, modernizes `std::is_base_of_v`, fixes init.
- **Function/TypedFunction** (`function.h`) — adds `std::move` for captured lambdas, modernizes type traits.
- **Error/ErrorBuilder** (`error.h`) — adds `std::move` for string params, fixes narrowing cast.
- **Map/DenseMapObj** (`map.h`) — removes redundant `uint8_t()` casts, macro parenthesization.
- **Array** (`array.h`) — range-based for in TypeTraits, explicit `int64_t` casts for index.
- **String/Bytes** (`string.h`) — raw string literals, `noexcept` moves, `std::move` in ctors.
- **Optional** (`optional.h`) — NOLINT regions for implicit constructors, `noexcept` moves.
- **Reflection** (`access_path.h`, `registry.h`) — `std::move` for sink params throughout.
- **Module system** (`library_module.cc`) — `const&` for ObjectPtr params, `std::move` for register.
- **Serialization** (`serialization.cc`) — `const&` parameters, explicit `int64_t` casts.
- **Structural equal/hash** (`structural_equal.cc`, `structural_hash.cc`) — range-based for, explicit casts.
- **JSON parser** (`json_parser.cc`) — explicit `static_cast<char>` for UTF-8 encoding, storage ownership fix.
- **Type traits** (`type_traits.h`) — raw string literals for all `TypeSchema()` methods.

Design elements this commit produces:
- **clang-tidy configuration** (`.clang-tidy`) — new lint tool configuration defining C++ code quality standards.
- **clang-tidy runner** (`tests/lint/clang_tidy_precommit.py`) — new lint script for running clang-tidy with CMake integration.

## Usage Examples
Running clang-tidy manually (from commit message):
```bash
uv run --with "clang-tidy==21.1.1" \
  python tests/lint/clang_tidy_precommit.py \
    --build-dir=build-pre-commit \
    --jobs=16 \
    ./src/ ./include ./tests
```

The `--fix` flag auto-applies fixes:
```bash
python tests/lint/clang_tidy_precommit.py \
    --build-dir=build-pre-commit \
    --fix \
    ./src/ ./include
```
