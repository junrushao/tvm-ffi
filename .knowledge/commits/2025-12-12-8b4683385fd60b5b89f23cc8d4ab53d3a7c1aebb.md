# Bump pre-commit hook versions and enable ruff docstring code formatter

## TL;DR

- Updates all pre-commit hook versions (pre-commit-hooks v5→v6, yamllint v1.35→v1.37, ruff v0.12→v0.14, clang-format v20→v21, cython-lint v0.16→v0.18, shellcheck v0.10→v0.11, markdownlint-cli2 v0.14→v0.20, rstcheck v6.2.4→v6.2.5, mypy v1.18→v1.19).
- Enables `docstring-code-format = true` and sets `docstring-code-line-length = 80` in `pyproject.toml` under `[tool.ruff.format]`.
- Applies the resulting docstring code reformatting across `python/tvm_ffi/` (blank lines added around code blocks, long lines wrapped, quote style normalized to double).
