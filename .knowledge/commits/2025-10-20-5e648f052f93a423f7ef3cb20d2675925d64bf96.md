# Add __dlpack_data_type__ protocol for dtype exchange via DLDataType tuple
## TL;DR
- Introduces the `__dlpack_data_type__` duck-type protocol: any Python object whose class implements `__dlpack_data_type__() -> tuple[int,int,int]` can now be passed as a dtype argument through FFI calls.
- Adds `dtype.from_dlpack_data_type(tuple[int,int,int])` static factory method for constructing a `tvm_ffi.dtype` from a DLPack data type tuple.
- Renames internal slot `__tvm_ffi_dtype__` to `_tvm_ffi_dtype` across `_dtype.py`, `dtype.pxi`, and `function.pxi`.

## Key Exports

```python

class dtype(str):
    _tvm_ffi_dtype: core.DataType  # Renamed from __tvm_ffi_dtype__ (was dunder, now private)

    @staticmethod
    def from_dlpack_data_type(dltype_data_type: tuple[int, int, int]) -> dtype:
        """Create a dtype from a DLPack data type tuple (type_code, bits, lanes)."""
        # Interacts with: core._create_dtype_from_tuple, core.DataType
        # Extension: enables round-tripping dtype from any __dlpack_data_type__ provider

# --- __dlpack_data_type__ Protocol (Cython, python/tvm_ffi/cython/function.pxi) ---
# Duck-type protocol method on any Python class to make instances passable as dtype:
#   def __dlpack_data_type__(self) -> tuple[int, int, int]:
#       """Return (type_code, bits, lanes) DLDataType tuple."""
# Setter: TVMFFIPyArgSetterDLPackDataTypeProtocol_
# Detection: class-level hasattr(arg_class, "__dlpack_data_type__")
# Dispatch order: checked after numpy.dtype, torch.dtype, and callable; before Exception
# Invariant: the returned tuple must contain exactly 3 integers matching DLDataType struct fields
```

## Impact
- API: New public `dtype.from_dlpack_data_type()` static method; new `__dlpack_data_type__` protocol for automatic dtype coercion in FFI calls.
- Behavioral: Objects implementing `__dlpack_data_type__` are now automatically converted to `DLDataType` when passed as arguments to FFI functions. Previously, such objects would fall through to the opaque object fallback path.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Passing an object with `__dlpack_data_type__` through FFI:
```python
import tvm_ffi

class MyDType:
    def __init__(self, type_code: int, bits: int, lanes: int) -> None:
        self._dltype = (type_code, bits, lanes)

    def __dlpack_data_type__(self) -> tuple[int, int, int]:
        return self._dltype

# The object is automatically converted to DLDataType when passed to FFI
fecho = tvm_ffi.get_global_func("testing.echo")
x = MyDType(2, 32, 1)  # float32
y = fecho(x)  # returns tvm_ffi.dtype("float32")
assert y == tvm_ffi.dtype("float32")

# Direct factory construction from DLPack tuple
dt = tvm_ffi.dtype.from_dlpack_data_type((0, 8, 1))  # int8
assert dt.type_code == 0 and dt.bits == 8 and dt.lanes == 1
```
