# Introduce __dlpack_data_type__ protocol for dtype exchange
## TL;DR
- Adds `__dlpack_data_type__` protocol support: Python objects implementing this method can return a `(type_code, bits)` tuple that is converted to `DLDataType` for FFI calls.
- Enables dtype exchange from external frameworks without explicit conversion.

## Impact
- API: New `__dlpack_data_type__` protocol recognized in Cython arg setter and `tvm_ffi.dtype()` conversion.
