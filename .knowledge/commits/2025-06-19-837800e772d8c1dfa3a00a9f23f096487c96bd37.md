# Change type_acenstors from int32_t[] to TVMFFITypeInfo*[] for faster parent reflection and optimize if-constexpr branches

## TL;DR
- Changes `TVMFFITypeInfo.type_acenstors` from `const int32_t*` (array of type indices) to `const struct TVMFFITypeInfo**` (array of pointers to ancestor TypeInfo structs), eliminating an extra `TVMFFIGetTypeInfo()` lookup when traversing parent types during reflection and `IsInstance` fallback.
- Restructures `IsObjectInstance<T>` to use fully chained `if constexpr / else if constexpr / else` blocks, enabling the compiler to eliminate dead branches earlier during template instantiation.
- Adds `ForEachFieldInfo` traversal utility and `String(TVMFFIByteArray)` constructor.

## Key Exports

**Struct change — `TVMFFITypeInfo`** (C ABI, `c_api.h`):
```c
// BEFORE: const int32_t* type_acenstors;
// AFTER:
typedef struct TVMFFITypeInfo {
  // ...
  const struct TVMFFITypeInfo** type_acenstors;  // ancestor[depth] = pointer to TypeInfo at that depth
  // ...
} TVMFFITypeInfo;
```
The struct also gains a forward-declared tag name `TVMFFITypeInfo` to enable the self-referential pointer.

**Function template — `ForEachFieldInfo`** (`reflection/reflection.h`):
```cpp
template <typename Callback>
void ForEachFieldInfo(const TypeInfo* type_info, Callback callback);
// callback signature: void(const TVMFFIFieldInfo*)
// Traverses ancestors[1..type_depth-1] fields, then own fields, in parent-to-child order.
```

**Constructor — `String(TVMFFIByteArray)`** (`string.h`):
```cpp
explicit String(TVMFFIByteArray other);  // constructs from C ABI byte array
```

**Refactored — `IsObjectInstance<TargetType>`** (`object.h`):
- `_type_child_slots_can_overflow` check changed from runtime `if (!...)` to `if constexpr (TargetType::_type_child_slots_can_overflow)` with explicit else.
- Ancestor lookup changed: `type_info->type_acenstors[depth] == target_type_index` becomes `type_info->type_acenstors[depth]->type_index == target_type_index`.

## Impact
- API: **Breaking C ABI change** — `TVMFFITypeInfo.type_acenstors` field type changes from `const int32_t*` to `const struct TVMFFITypeInfo**`. All code that reads ancestor entries must dereference through the pointer to get `->type_index`. Affected callers: `IsObjectInstance`, `MakeObjectFromPackedArgs`, `TypeTable::DumpTypeTableStats`, test assertions in `test_object.cc`.
- Behavioral: `IsObjectInstance` fallback path (tier 3 ancestor lookup) now avoids a `TVMFFIGetTypeInfo()` call, directly dereferencing the stored pointer instead. `MakeObjectFromPackedArgs` similarly avoids lookup when iterating parent fields.
- Flags/config: None.
- Data formats/schemas: The in-memory layout of `TVMFFITypeInfo` changes (pointer width instead of int32_t per ancestor entry). This is an ABI break for any code that reads `type_acenstors` directly.

Design elements this commit produces:
- **Pointer-based ancestor array**: `type_acenstors` now stores `TVMFFITypeInfo*` pointers, enabling O(1) direct access to ancestor metadata (fields, methods, type_key) without an extra `TVMFFIGetTypeInfo()` indirection.
- **`ForEachFieldInfo` traversal**: New utility for iterating all fields (inherited + own) of a reflected type, using the pointer-based ancestor array. This is the canonical way to enumerate all fields for serialization, object construction, or binding generation.
- **Fully chained `if constexpr` in `IsObjectInstance`**: Ensures the compiler can prune unreachable branches at template instantiation time, rather than relying on dead-code elimination after lowering.

## Usage Examples

**`ForEachFieldInfo` — collecting all fields (inherited + own) of a derived type:**
```cpp
// Given: TestObjA has fields x, y; TestObjADerived : TestObjA adds field z
const TypeInfo* info = TVMFFIGetTypeInfo(TestObjADerived::RuntimeTypeIndex());
Map<String, int> field_name_to_offset;
reflection::ForEachFieldInfo(info, [&](const TVMFFIFieldInfo* field_info) {
  field_name_to_offset.Set(String(field_info->name), field_info->offset);
});
// field_name_to_offset contains: {"x": 16, "y": 24, "z": 32}
// (offsets relative to Object*, sizeof(TVMFFIObject) == 16)
```

**Ancestor lookup change — before/after:**
```cpp
// BEFORE (int32_t index, then lookup):
const TypeInfo* type_info = TVMFFIGetTypeInfo(object_type_index);
return type_info->type_acenstors[TargetType::_type_depth] == target_type_index;

// AFTER (direct pointer dereference):
const TypeInfo* type_info = TVMFFIGetTypeInfo(object_type_index);
return type_info->type_acenstors[TargetType::_type_depth]->type_index == target_type_index;
```
