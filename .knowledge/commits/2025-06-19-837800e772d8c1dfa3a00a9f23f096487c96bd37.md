# Change type_acenstors from int32_t[] to TVMFFITypeInfo*[] for direct parent reflection lookup
## TL;DR
- Changes `TVMFFITypeInfo::type_acenstors` from `const int32_t*` (array of type indices) to `const struct TVMFFITypeInfo**` (array of pointers to parent TypeInfo structs), enabling O(1) access to parent type metadata without `TVMFFIGetTypeInfo` lookup.
- Adds `reflection::ForEachFieldInfo(type_info, callback)` -- a new utility that walks the ancestor chain and invokes a callback for every registered field (parent fields first, child fields last).
- Restructures `if constexpr` branches in `IsObjectInstance` to use explicit `else` clauses, eliminating dead-code warnings and enabling earlier template elimination.

## Key Exports

**Struct change (C ABI)**:
```c
// Before:
typedef struct { ...; const int32_t* type_acenstors; ... } TVMFFITypeInfo;
// After:
typedef struct TVMFFITypeInfo { ...; const struct TVMFFITypeInfo** type_acenstors; ... } TVMFFITypeInfo;
```
The struct is now a named type (`struct TVMFFITypeInfo`) rather than anonymous, required for the self-referential pointer.

**Functions**:
```cpp
// include/tvm/ffi/reflection/reflection.h
template <typename Callback>
inline void ForEachFieldInfo(const TypeInfo* type_info, Callback callback);
// callback signature: void(const TVMFFIFieldInfo*)
// Walks ancestors[1..depth-1] then self, invoking callback for each registered field.
```

**Constructors**:
```cpp
// include/tvm/ffi/string.h
explicit String(TVMFFIByteArray other);
// Constructs a String from a C ABI byte array via MakeInplaceBytes.
```

## Impact
- API: `ForEachFieldInfo` is a new public API for reflection consumers. No existing public API signatures change.
- ABI: **Breaking**. `TVMFFITypeInfo::type_acenstors` changes from `const int32_t*` to `const struct TVMFFITypeInfo**`. Any code reading this field across the ABI boundary must be updated. The struct also gains a tag name (`TVMFFITypeInfo`).
- Behavioral: `IsObjectInstance` ancestor-table fallback now reads `type_info->type_acenstors[depth]->type_index` instead of `type_info->type_acenstors[depth]` directly. Same semantic result, different memory indirection.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Type index hierarchy and IsInstance dispatch** (`.knowledge/designs/object-system.md`, "Type Index Hierarchy" section) -- the three-tier check (final, child-slot range, ancestor table) is preserved but the ancestor table path now dereferences a pointer-to-TypeInfo instead of reading a raw index.
- **TypeTable registration** (`.knowledge/designs/object-system.md`, "Type Registration" section) -- ancestor chain construction in `TypeTable::GetOrAllocTypeIndex` is updated to store `TVMFFITypeInfo*` pointers instead of `int32_t` indices.
- **TVMFFIFieldInfo reflection** (`.knowledge/designs/reflection.md`) -- `ForEachFieldInfo` uses the field arrays from parent TypeInfo entries.
- **TVMFFITypeInfo C ABI struct** (`.knowledge/designs/c-abi.md`) -- field type changed.

Design elements this commit produces:
- **Direct ancestor TypeInfo pointers** -- `type_acenstors` now provides O(1) access to a parent's full TypeInfo (fields, methods, type_key, etc.) without requiring a `TVMFFIGetTypeInfo(index)` lookup. This eliminates one indirection per ancestor during reflection walks.
- **`ForEachFieldInfo` utility** -- new reflection primitive that iterates all fields in inheritance order (parent-to-child). Enables object construction from packed args (`MakeObjectFromPackedArgs`) and generic field visitors to handle inherited fields without manually walking the ancestor chain.
- **`String(TVMFFIByteArray)` constructor** -- convenience constructor for creating `String` objects from the C ABI byte array type; used in the new `ForEachFieldInfo` test where field names (which are `TVMFFIByteArray`) are converted to `String` keys for a `Map`.

## Usage Examples
Using `ForEachFieldInfo` to collect all fields (including inherited) for a derived type:

```cpp
#include <tvm/ffi/reflection/reflection.h>
#include <tvm/ffi/container/map.h>
#include <tvm/ffi/string.h>

// Given a derived type with inherited fields:
const TypeInfo* info = TVMFFIGetTypeInfo(MyDerivedObj::RuntimeTypeIndex());
Map<String, int> field_name_to_offset;
reflection::ForEachFieldInfo(info, [&](const TVMFFIFieldInfo* field_info) {
  field_name_to_offset.Set(String(field_info->name), field_info->offset);
});
// field_name_to_offset now contains fields from all ancestors + self
```
