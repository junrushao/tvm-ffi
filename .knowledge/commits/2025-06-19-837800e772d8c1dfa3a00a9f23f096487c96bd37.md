# Change type_acenstors from int32 array to TypeInfo pointer array for faster parent reflection

## TL;DR
- **Core change**: `TVMFFITypeInfo.type_acenstors` changed from `const int32_t*` (array of type indices) to `const struct TVMFFITypeInfo**` (array of pointers to parent TypeInfo structs). This eliminates redundant `TVMFFIGetTypeInfo()` lookups when traversing ancestors.
- **New utility**: Added `ForEachFieldInfo()` template function in `reflection.h` that iterates all fields of a type including inherited fields from ancestors, using the new pointer-based ancestor array for direct access.
- **Compilation speedup**: Restructured `if constexpr` branches in `IsObjectInstance` and `Tuple::TryConvertElements` to use explicit `else` clauses, enabling earlier branch elimination during compilation.

## Impact
- API: `TVMFFITypeInfo.type_acenstors` type changed from `const int32_t*` to `const struct TVMFFITypeInfo**`. All code reading `type_acenstors[i]` to get a type index must now dereference `type_acenstors[i]->type_index`. The struct is also now named `TVMFFITypeInfo` (was anonymous typedef).
- Behavioral: `IsObjectInstance` ancestor fallback now compares `type_info->type_acenstors[depth]->type_index == target_type_index` instead of `type_info->type_acenstors[depth] == target_type_index`. Semantically equivalent but avoids a `TVMFFIGetTypeInfo` call in `MakeObjectFromPackedArgs`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object type hierarchy / IsInstance** ([0002-object-system.md](../designs/0002-object-system.md)): The `IsObjectInstance<T>` function is restructured but preserves all check ordering and semantics.
- **Child-slot optimization** ([ADR 0003](../ADRs/0003-child-slot-type-checking.md)): The overflow fallback path now dereferences `type_acenstors[depth]->type_index` instead of using the index directly.
- **Reflection field iteration** ([0008-reflection.md](../designs/0008-reflection.md)): `MakeObjectFromPackedArgs` in `object.cc` previously iterated ancestors via `TVMFFIGetTypeInfo(type_acenstors[i])`. Now uses `type_acenstors[i]` directly.
- **TVMFFITypeInfo C ABI struct** ([0001-c-abi.md](../designs/0001-c-abi.md)): The `type_acenstors` field type is mutated.

Design elements this commit produces:
- **`ForEachFieldInfo` utility**: New template function in `reflection.h` that encapsulates the ancestor-walking + field-visiting pattern. Eliminates duplicated logic between `MakeObjectFromPackedArgs` and any future field enumeration needs.
- **Named `TVMFFITypeInfo` struct**: The struct is now named (was anonymous typedef), enabling the self-referential pointer type `const struct TVMFFITypeInfo**`.

## Usage Examples

**ForEachFieldInfo** -- iterating all fields of a derived type including inherited fields:
```cpp
// Given a type TestObjADerived that inherits TestObjA (which has fields x, y),
// and TestObjADerived adds field z:
const TypeInfo* info = TVMFFIGetTypeInfo(TestObjADerived::RuntimeTypeIndex());
Map<String, int> field_name_to_offset;
reflection::ForEachFieldInfo(info, [&](const TVMFFIFieldInfo* field_info) {
    field_name_to_offset.Set(String(field_info->name), field_info->offset);
});
// field_name_to_offset contains: {"x": 16, "y": 24, "z": 32}
// (offsets relative to Object header = sizeof(TVMFFIObject))
```
