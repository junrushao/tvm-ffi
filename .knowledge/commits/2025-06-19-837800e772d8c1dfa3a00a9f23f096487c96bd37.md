# Change type_acenstors from int32 indices to TypeInfo pointers for faster parent reflection

## TL;DR
- `TVMFFITypeInfo.type_acenstors` changes from `const int32_t*` (ancestor type indices) to `const TVMFFITypeInfo**` (direct pointers to ancestor TypeInfo structs), eliminating `TVMFFIGetTypeInfo()` lookups in `IsObjectInstance` fallback and parent field iteration.
- Adds `ForEachFieldInfo(type_info, callback)` utility in `reflection.h` that iterates all fields (including inherited parent fields) in parent-to-child order using the new pointer-based ancestor table.
- Restructures `if constexpr` branches in `IsObjectInstance` and `Tuple::TryConvertElements` to use explicit `else` clauses, helping compilers eliminate dead branches earlier.

def IsObjectInstance(TargetType, object_type_index: int32) -> bool:
    """Two-tier runtime type check. Fallback now dereferences TypeInfo pointer instead of index lookup."""
    if TargetType is Object:
        return True
    elif TargetType._type_final:
        return object_type_index == TargetType.RuntimeTypeIndex()
    else:
        target_idx = TargetType.RuntimeTypeIndex()
        # Fast range check (unchanged logic)
        if TargetType._type_child_slots != 0:
            end = target_idx + TargetType._type_child_slots + 1
            if target_idx <= object_type_index < end:
                return True
        else:
            if object_type_index == target_idx:
                return True

                return False

                    and type_info.type_acenstors[TargetType._type_depth].type_index == target_idx)

## Impact
- API: **Breaking ABI change** to `TVMFFITypeInfo.type_acenstors` field type (`const int32_t*` -> `const struct TVMFFITypeInfo**`). All code that reads `type_acenstors` entries must now dereference the pointer to get `->type_index` instead of using the value directly. The struct also gains a tag name `TVMFFITypeInfo` (was anonymous) to support self-referential pointer.
- Behavioral: `IsObjectInstance` fallback path is faster (one fewer `TVMFFIGetTypeInfo()` call per ancestor check). Parent field iteration in `MakeObjectFromPackedArgs` also avoids the lookup. The `!_type_child_slots_can_overflow` path now returns `false` directly via `else` rather than falling through.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

**ForEachFieldInfo**: Collecting all fields (including inherited) for a derived type.
```cpp
// Given: TestObjA with fields x, y and TestObjADerived (extends TestObjA) with field z
const TypeInfo* info = TVMFFIGetTypeInfo(TestObjADerived::RuntimeTypeIndex());
Map<String, int> field_name_to_offset;
reflection::ForEachFieldInfo(info, [&](const TVMFFIFieldInfo* field_info) {
    field_name_to_offset.Set(String(field_info->name), field_info->offset);
});
// Result: {"x": 16, "y": 24, "z": 32} (offsets from TVMFFIObject header)
```

**IsObjectInstance fallback change** (before/after):
```cpp
// Before: ancestor table stored int32_t indices, required TVMFFIGetTypeInfo lookup
type_info->type_acenstors[TargetType::_type_depth] == target_type_index

// After: ancestor table stores TypeInfo pointers, direct dereference
type_info->type_acenstors[TargetType::_type_depth]->type_index == target_type_index
```
