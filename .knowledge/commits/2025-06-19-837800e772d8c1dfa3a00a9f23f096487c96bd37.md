# Upgrade TVMFFITypeInfo.type_acenstors from int32_t array to TypeInfo* array to enable O(1) parent field traversal

## TL;DR
- Changes `TVMFFITypeInfo.type_acenstors` from `const int32_t*` (type index array) to `const struct TVMFFITypeInfo**` (pointer array), eliminating a global table lookup for each ancestor step during reflection and type checking.
- Adds `ForEachFieldInfo(const TypeInfo*, Callback)` in `reflection.h` that traverses all ancestor fields in parent-to-child order using the new pointer array.
- Refactors `IsObjectInstance<T>` in `object.h` to use a chained `if constexpr / else if constexpr / else` structure so the compiler can eliminate unreachable branches early, and ports the slow-path ancestor check to use direct pointer dereference instead of `TVMFFIGetTypeInfo`.

## Impact
- API: **Breaking C ABI change** — `TVMFFITypeInfo.type_acenstors` field type changes from `const int32_t*` to `const struct TVMFFITypeInfo**`. Any code that reads `type_acenstors[i]` as a bare integer (e.g., Python ctypes bindings, Rust bindings via tvm-ffi-sys) must be updated to read `type_acenstors[i]->type_index` instead.
- Behavioral: `IsObjectInstance<T>` slow path no longer calls `TVMFFIGetTypeInfo()` — it directly indexes the pointer stored in `type_acenstors`; functionally equivalent but avoids a hash/table lookup.
- Flags/config: none
- Data formats/schemas: `TVMFFITypeInfo` binary layout changes — `type_acenstors` is now a pointer-to-pointer rather than pointer-to-int32. Serialized type tables (if any) would need updating.

## Usage Examples

**Using `ForEachFieldInfo` to collect all fields of a derived type (C++ test):**

```cpp
// TestObjADerived extends TestObjA (fields: x, y, z)
const TypeInfo* info = TVMFFIGetTypeInfo(TestObjADerived::RuntimeTypeIndex());
Map<String, int> field_name_to_offset;
reflection::ForEachFieldInfo(info, [&](const TVMFFIFieldInfo* field_info) {
    field_name_to_offset.Set(String(field_info->name), field_info->offset);
});
// Result: {"x": sizeof(TVMFFIObject), "y": sizeof(TVMFFIObject)+8, "z": sizeof(TVMFFIObject)+16}
```

**Before/after for ancestor access:**

```cpp
// BEFORE: indirect lookup through global table
const TypeInfo* type_info = TVMFFIGetTypeInfo(object_type_index);
return type_info->type_depth > depth &&
       type_info->type_acenstors[depth] == target_type_index;  // int32_t comparison

// AFTER: direct pointer dereference, no lookup
const TypeInfo* type_info = TVMFFIGetTypeInfo(object_type_index);
return type_info->type_depth > depth &&
       type_info->type_acenstors[depth]->type_index == target_type_index;  // pointer->int
```
