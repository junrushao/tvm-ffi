# Change type_acenstors from int32 array to TypeInfo pointer array for faster parent reflection
## TL;DR
- Changes `TVMFFITypeInfo.type_acenstors` from `const int32_t*` (array of type indices) to `const struct TVMFFITypeInfo**` (array of pointers to TypeInfo structs), eliminating an indirection through `TVMFFIGetTypeInfo()` when walking ancestors.
- Adds `reflection::ForEachFieldInfo()` utility that iterates all fields of a type including inherited parent fields, using the new pointer-based ancestor array for direct traversal.
- Restructures `IsObjectInstance` to use explicit `if/else if/else` chains with `if constexpr`, improving compile-time branch elimination.

## Impact
- API: `TVMFFITypeInfo.type_acenstors` type changed from `const int32_t*` to `const struct TVMFFITypeInfo**` -- all code directly reading this field must dereference the pointer and access `->type_index` instead of using the value directly. Tests updated in this commit. External C code accessing the struct must adapt.
- Behavioral: `IsObjectInstance` Path 7 (ancestor table fallback) now compares `type_acenstors[depth]->type_index` instead of `type_acenstors[depth]`. Semantically identical, but avoids the `TVMFFIGetTypeInfo()` call during parent field iteration in `MakeObjectFromPackedArgs`. The `if constexpr` restructuring may improve compile times for template-heavy code.
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces:

- **Pointer-based ancestor array**: The `type_acenstors` field now stores `TVMFFITypeInfo**` instead of `int32_t*`, enabling direct traversal of the type hierarchy without global table lookups.

## Usage Examples
**ForEachFieldInfo**: Iterating all fields (including inherited) of a derived type.
```cpp
// Given: TestObjA has fields {x, y}, TestObjADerived : TestObjA has field {z}
const TypeInfo* info = TVMFFIGetTypeInfo(TestObjADerived::RuntimeTypeIndex());
Map<String, int> field_name_to_offset;
reflection::ForEachFieldInfo(info, [&](const TVMFFIFieldInfo* field_info) {
  field_name_to_offset.Set(String(field_info->name), field_info->offset);
});
// field_name_to_offset contains: {"x": 16, "y": 24, "z": 32}
```

**Pointer-based ancestor access** (updated pattern):
```cpp
// OLD: type_info->type_acenstors[depth] == some_type_index
// NEW: type_info->type_acenstors[depth]->type_index == some_type_index
// NEW: can also directly access ancestor's fields/methods:
//      type_info->type_acenstors[depth]->fields[i]
```
