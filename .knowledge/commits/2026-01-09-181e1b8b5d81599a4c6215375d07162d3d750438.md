# Add clang-tidy job to PR CI pipeline
## TL;DR
- Adds a `clang-tidy` job to `.github/workflows/ci_test.yml` so clang-tidy runs on PRs (not just mainline), preventing post-merge failures.
- The job is conditional on `cpp_changed == 'true'`, detected by diffing C/C++ file extensions against the PR base branch.
- Uses `uv run --no-project --with "clang-tidy==21.1.1"` to invoke `tests/lint/clang_tidy_precommit.py`.
