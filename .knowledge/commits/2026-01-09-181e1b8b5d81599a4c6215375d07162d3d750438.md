# Add clang-tidy job to PR CI to catch issues before merge

## TL;DR
- PR CI previously lacked clang-tidy; it only ran on main branch merges, causing post-merge failures.
- Adds a `clang-tidy` job to `.github/workflows/ci_test.yml` that detects changed C++ files and runs clang-tidy on them only when `cpp_changed == 'true'`.
- New `prepare` job outputs: `cpp_changed` and `cpp_files` (space-separated list of changed `.c`/`.cc`/`.cpp`/`.cxx` files diffed against `origin/<base_ref>`).
