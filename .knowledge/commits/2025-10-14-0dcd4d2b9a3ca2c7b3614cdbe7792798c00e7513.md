# Migrate Tensor and TensorView from operator->() to explicit accessor methods, adding size/stride/byte_offset/device per-index accessors

## TL;DR

- Replaces `operator->()` on both `Tensor` and `TensorView` with explicit typed methods (`data_ptr()`, `ndim()`, `dtype()`, `device()`, `shape()`, `strides()`); `operator->()` that returned `DLTensor*` is fully removed from `TensorView` and is replaced with `GetDLTensorPtr()` for escape-hatch access on `Tensor`.
- Adds `size(idx)`, `stride(idx)`, `byte_offset()`, and `numel()` per-index accessors on both `Tensor` and `TensorView`, plus free functions `GetDataSize(Tensor)` / `GetDataSize(TensorView)`.
- Replaces `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` macro expansion in `Tensor` with manual inline definition (explicit ctors + `get()` + `_type_is_nullable` constexpr).

## Impact

- API: **Breaking for external C++ callers** that used `operator->()` on `TensorView` (e.g., `view->data`, `view->ndim`, `view->shape[i]`). All call sites in the repo are updated. External downstream code must migrate: `view->ndim` → `view.ndim()`, `view->data` → `view.data_ptr()`, `view->shape[i]` → `view.size(i)`, `view->device` → `view.device()`.
- API: **Breaking for `Tensor` operator->()** usage: `tensor->data` → `tensor.data_ptr()`, `tensor->ndim` → `tensor.ndim()`, `tensor->device` → `tensor.device()`, `tensor->shape[i]` → `tensor.size(i)`.
- Behavioral: None — purely API surface change; all accessors return identical values.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

Before/after pattern for the operator->() migration (TensorView in kernel code):

```cpp
// BEFORE (operator->() on TensorView)
void MyKernel(tvm::ffi::TensorView x, tvm::ffi::TensorView y) {
    TVM_FFI_ICHECK(x->ndim == 1);
    TVM_FFI_ICHECK(x->dtype == f32_dtype);
    int64_t n = x->shape[0];
    for (int i = 0; i < x->shape[0]; ++i) {
        static_cast<float*>(y->data)[i] = static_cast<float*>(x->data)[i] + 1;
    }
}

// AFTER (method-based API)
void MyKernel(tvm::ffi::TensorView x, tvm::ffi::TensorView y) {
    TVM_FFI_ICHECK(x.ndim() == 1);
    TVM_FFI_ICHECK(x.dtype() == f32_dtype);
    int64_t n = x.size(0);  // replaces x->shape[0]
    for (int i = 0; i < x.size(0); ++i) {
        static_cast<float*>(y.data_ptr())[i] = static_cast<float*>(x.data_ptr())[i] + 1;
    }
}
```

Before/after for structural equal/hash (uses free function form):

```cpp
// BEFORE (direct struct access + function form)
size_t data_size = GetDataSize(*(lhs.operator->()));
std::memcmp(lhs->data, rhs->data, data_size);

// AFTER (method-based)
size_t data_size = GetDataSize(lhs);  // GetDataSize(Tensor) overload
std::memcmp(lhs.data_ptr(), rhs.data_ptr(), data_size);
```
