# Replace Tensor/TensorView operator->() with explicit method-based API
## TL;DR
- Removed `operator->()` from both `Tensor` and `TensorView`, replacing all raw `DLTensor*` field access with named methods: `data_ptr()`, `device()`, `ndim()`, `dtype()`, `size(idx)`, `stride(idx)`, `byte_offset()`, `numel()`.
- Added `Tensor::GetDLTensorPtr()` as the explicit escape hatch for code that needs the raw `DLTensor*`.
- Added free-function overloads `GetDataSize(const Tensor&)` and `GetDataSize(const TensorView&)`.
- Replaced `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` in `Tensor` with manual constructors, `_type_is_nullable`, `ContainerType`, and protected `get()`.

## Key Exports

**Tensor** (class, modified -- `include/tvm/ffi/container/tensor.h`):

| Method | Signature | Notes |
|--------|-----------|-------|
| `data_ptr()` | `void* data_ptr() const` | Replaces `(*this)->data` |
| `device()` | `DLDevice device() const` | Replaces `(*this)->device` |
| `ndim()` | `int32_t ndim() const` | Replaces `(*this)->ndim` |
| `dtype()` | `DLDataType dtype() const` | Replaces `(*this)->dtype` |
| `size(idx)` | `int64_t size(size_t idx) const` | New -- per-dimension shape access |
| `stride(idx)` | `int64_t stride(size_t idx) const` | New -- per-dimension stride access |
| `byte_offset()` | `uint64_t byte_offset() const` | New |
| `GetDLTensorPtr()` | `const DLTensor* GetDLTensorPtr() const` | Explicit escape hatch replacing `operator->()` |

**TensorView** (class, modified -- same header):

Same method surface as Tensor (`data_ptr`, `device`, `ndim`, `dtype`, `size`, `stride`, `byte_offset`, `numel`). `operator->()` removed.

**Free functions** (added):
- `size_t GetDataSize(const Tensor& tensor)` -- delegates to `GetDataSize(numel, dtype)`
- `size_t GetDataSize(const TensorView& tensor)` -- same

## Impact
- API: **Breaking** -- `operator->()` removed from both `Tensor` and `TensorView`. All C++ code using `tensor->data`, `tensor->ndim`, `tensor->shape[i]`, `tensor->device`, `tensor->dtype`, `tensor->strides`, `tensor->byte_offset` must migrate to method calls.
- Behavioral: none (pure API reshaping, same semantics)
- Flags/config: none
- Data formats/schemas: none

- **Type traits** ([0005-type-traits.md](../designs/0005-type-traits.md)): `TypeTraits<TensorView>` updated to use friend access to `tensor_` instead of `operator->()`

Design elements this commit produces/mutates:
- **Tensor method-based API**: Replaces the `operator->()` convention with explicit accessors, establishing the pattern that `ObjectRef` subclasses wrapping C structs should expose named methods rather than raw pointer dereference.
- **GetDLTensorPtr() escape hatch**: Explicit method for code needing raw DLTensor*, replacing implicit `operator->()`.

## Usage Examples

```cpp
// Before (removed pattern):
Tensor t = Tensor::FromDLPack(dlpack);
float* data = reinterpret_cast<float*>(t->data);
int ndim = t->ndim;
DLDevice dev = t->device;

// After (new pattern):
Tensor t = Tensor::FromDLPack(dlpack);
float* data = reinterpret_cast<float*>(t.data_ptr());
int ndim = t.ndim();
DLDevice dev = t.device();
int64_t dim0 = t.size(0);       // new per-dimension accessor
const DLTensor* raw = t.GetDLTensorPtr();  // explicit escape hatch
```
