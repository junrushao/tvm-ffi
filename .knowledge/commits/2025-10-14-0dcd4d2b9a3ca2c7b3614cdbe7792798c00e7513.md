# Replace operator->() on Tensor/TensorView with named method accessors
## TL;DR
- Removes public `operator->()` from `Tensor` (replaces inherited `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` with explicit constructors and a private `get()` method) and from `TensorView`, replacing raw `DLTensor*` field access with named methods: `data_ptr()`, `device()`, `ndim()`, `dtype()`, `size(idx)`, `stride(idx)`, `byte_offset()`, `numel()`.
- Adds `GetDLTensorPtr()` as the explicit escape hatch for callers that need the raw `const DLTensor*`.
- Mechanically updates all 17 files across docs, examples, tests, and implementation to use the new method-based API.

### Rename Mapping

| Old pattern | New pattern | Notes |
|---|---|---|
| `tensor->data` | `tensor.data_ptr()` | Applies to both Tensor and TensorView |
| `tensor->ndim` | `tensor.ndim()` | |
| `tensor->dtype` | `tensor.dtype()` | |
| `tensor->device` | `tensor.device()` | New accessor (previously no method equivalent) |
| `tensor->shape[i]` | `tensor.size(i)` | New indexed accessor |
| `tensor->strides[i]` | `tensor.stride(i)` | New indexed accessor |
| `tensor->byte_offset` | `tensor.byte_offset()` | New accessor |
| `*(tensor.operator->())` / `*(tensor->)` | `*tensor.GetDLTensorPtr()` | Explicit DLTensor* escape hatch on Tensor only |
| `GetDataSize(*(tensor.operator->()))` | `GetDataSize(tensor)` | New free-function overloads |
| `TensorView::operator->()` | (removed) | Use named methods instead |
| `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE(Tensor, ...)` | Explicit constructors + `_type_is_nullable` + `ContainerType` | Tensor class internals |

## Impact
- API: **Breaking** -- `operator->()` is removed from both `Tensor` and `TensorView`. All callers using `tensor->field` must migrate to `tensor.method()`. `GetDLTensorPtr()` provides escape hatch.
- Behavioral: None -- all accessors delegate to the same underlying DLTensor fields.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Object system** (`0002-object-system.md`): Replaces `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` macro expansion with explicit equivalent (constructors, `_type_is_nullable`, `ContainerType` alias, private `get()`).
- **Tensor / TensorView** (`0007-containers.md`): Extends the method-based accessor API established in prior commits (8ca0719, 1ec6236).
- **Structural equal/hash** (`0009-structural-equal-hash.md`): Updated callers in `structural_equal.cc` and `structural_hash.cc`.
- **TypeTraits** (`0006-type-traits.md`): `TypeTraits<TensorView>::CopyToAnyView` updated to use `&(src.tensor_)` instead of `src.operator->()`.

Design elements this commit produces:
- **Tensor method-only API convention**: Establishes that `Tensor` and `TensorView` expose data exclusively through named methods, not raw pointer dereferencing. This is a convention change affecting all downstream C++ code.
- **`size(idx)` / `stride(idx)` indexed accessors**: New per-dimension query pattern, replacing `->shape[idx]` / `->strides[idx]`.
- **`GetDLTensorPtr()`**: Explicit escape hatch for raw DLTensor* access, replacing implicit `operator->()`.
- **`GetDataSize` overloads for Tensor/TensorView**: Convenience free functions avoiding manual dereference.

## Usage Examples

**Before (old pattern -- no longer compiles):**
```cpp
void process(ffi::TensorView x) {
  int n = x->shape[0];                         // ERROR: operator->() removed
  float* data = static_cast<float*>(x->data);  // ERROR
  DLDevice dev = x->device;                    // ERROR
}
```

**After (new pattern):**
```cpp
void process(ffi::TensorView x) {
  int n = x.size(0);                               // indexed dimension access
  float* data = static_cast<float*>(x.data_ptr());  // named accessor
  DLDevice dev = x.device();                        // named accessor
}
```

**Escape hatch (when raw DLTensor* is needed):**
```cpp
ffi::Tensor t = ...;
const DLTensor* dl = t.GetDLTensorPtr();  // explicit, only on Tensor (not TensorView)
```
