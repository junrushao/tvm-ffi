# Migrate Tensor/TensorView from operator-> to method-based API
## TL;DR
- Replaces `operator->()` access pattern on Tensor/TensorView with explicit methods (`data_ptr()`, `ndim()`, `dtype()`, `device()`, `shape()`, `strides()`, `byte_offset()`, `numel()`), making the API less error-prone.
- Adds 123 lines of new methods to `tensor.h`, updates all examples, docs, and tests to use method-based access.

## Impact
- API: `operator->()` still exists but method-based access is now the recommended pattern. All examples and docs updated.
- Flags/config: None.
- Data formats/schemas: None.
