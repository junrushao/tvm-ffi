# Replace operator->() on Tensor/TensorView with explicit accessor methods
## TL;DR
- Removes `operator->()` from both `Tensor` and `TensorView`, replacing raw `DLTensor*` field access (e.g. `x->ndim`, `x->data`, `x->shape[0]`) with explicit method calls (`x.ndim()`, `x.data_ptr()`, `x.size(0)`).
- Adds new accessor methods to both classes: `device()`, `size(idx)`, `stride(idx)`, `byte_offset()`, and `GetDLTensorPtr()` on `Tensor`.
- Migrates all call sites across examples, docs, tests, and internal implementation (`structural_equal.cc`, `structural_hash.cc`) to the new method-based API.

## Impact
- API: Breaking -- `Tensor::operator->()` and `TensorView::operator->()` are removed. All callers using `tensor->field` syntax must migrate to `tensor.method()` calls. This affects any C++ code using `Tensor` or `TensorView` directly.
- Behavioral: None -- all accessor methods delegate to the same underlying `DLTensor` fields with identical semantics.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `TensorObj` / `DLTensor` layout ([0006-ffi-containers](../design-records/0006-ffi-containers.md)) -- all new accessors delegate to `DLTensor` fields
- `ObjectRef` pattern ([0003-ffi-object-system](../design-records/0003-ffi-object-system.md)) -- `Tensor` extends `ObjectRef` with manual constructor definitions
- `ShapeView` ([0006-ffi-containers](../design-records/0006-ffi-containers.md)) -- `shape()` / `strides()` return types unchanged
- `StructuralEqual` / `StructuralHash` ([0009-ffi-structural-eq-hash](../design-records/0009-ffi-structural-eq-hash.md)) -- `CompareTensor` / `HashTensor` migrated to method-based access
- `TypeTraits<TensorView>` ([0006-ffi-containers](../design-records/0006-ffi-containers.md)) -- `CopyToAnyView` changed to use friend access to `tensor_` field

Design elements this commit produces:
- **New `Tensor` accessor methods**: `device()`, `size(idx)`, `stride(idx)`, `byte_offset()`, `GetDLTensorPtr()` -- establish method-based API as the canonical way to access `DLTensor` fields through `Tensor`
- **New `TensorView` accessor methods**: `device()`, `size(idx)`, `stride(idx)`, `byte_offset()` -- mirror `Tensor` API for consistent cross-type usage
- **`GetDataSize(Tensor)` / `GetDataSize(TensorView)` overloads** -- convenience free functions replacing `GetDataSize(*(tensor.operator->()))`
- **Manual `Tensor` ref construction** -- replaces `TVM_FFI_DEFINE_OBJECT_REF_METHODS_NULLABLE` with explicit constructors, `_type_is_nullable`, and protected `get()`. This is a divergence from the standard macro pattern.

## Usage Examples
Before (old `operator->()` style):
```cpp
void AddOne(ffi::TensorView x, ffi::TensorView y) {
  TVM_FFI_ICHECK(x->ndim == 1) << "x must be a 1D tensor";
  TVM_FFI_ICHECK(x->shape[0] == y->shape[0]) << "same shape";
  for (int i = 0; i < x->shape[0]; ++i) {
    static_cast<float*>(y->data)[i] = static_cast<float*>(x->data)[i] + 1;
  }
}
```

After (new method-based style):
```cpp
void AddOne(ffi::TensorView x, ffi::TensorView y) {
  TVM_FFI_ICHECK(x.ndim() == 1) << "x must be a 1D tensor";
  TVM_FFI_ICHECK(x.size(0) == y.size(0)) << "same shape";
  for (int i = 0; i < x.size(0); ++i) {
    static_cast<float*>(y.data_ptr())[i] = static_cast<float*>(x.data_ptr())[i] + 1;
  }
}
```

For `Tensor` data access and DLPack:
```cpp
ffi::Tensor nd = Empty({2, 3}, DLDataType{kDLFloat, 32, 1}, DLDevice{kDLCPU, 0});
// Old: reinterpret_cast<float*>(nd->data)[i] = ...
// New:
reinterpret_cast<float*>(nd.data_ptr())[i] = static_cast<float>(i);

// Old: nd->device.device_type
// New:
DLDevice dev = nd.device();

// Old: *(tensor.operator->()) for raw DLTensor
// New:
const DLTensor* raw = nd.GetDLTensorPtr();
size_t data_size = GetDataSize(nd);  // new overload
```
