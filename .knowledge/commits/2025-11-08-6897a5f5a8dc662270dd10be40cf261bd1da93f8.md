# Fix TypeInfo parent propagation by enforcing inheritance-order registration in Cython
## TL;DR
- Moves all `_register_object_by_index` calls out of individual `.pxi` files and into `core.pyx`, placing them in strict inheritance order (base before derived) so that `TypeInfo.parent_type_info` is always properly propagated.
- Adds `TYPE_CLS_TO_INFO` dict and new `_type_cls_to_type_info(type_cls)` function for reverse lookup from Python class to `TypeInfo`.
- Removes `_set_class_object` from `core.pyi` (replaced by the centralized registration flow).
- Adds comprehensive parametrized tests verifying `type_key`, `type_cls`, and `parent_type_info` for all built-in and test classes.

## Key Exports
**Python function** (new, exposed via `core.pyi`):
- `_type_cls_to_type_info(type_cls: type) -> TypeInfo | None` -- reverse lookup from a Python class to its `TypeInfo`

**Removed from `core.pyi`**:
- `_set_class_object(cls: type) -> None` -- no longer exported (still exists internally)

## Impact
- API: `_set_class_object` removed from `core.pyi`; `_type_cls_to_type_info` added
- Behavioral: `TypeInfo.parent_type_info` is now reliably populated for all Cython-defined classes (Error, String, Bytes, Tensor, Function, etc.). Previously some had `None` parents due to registration ordering.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Object system type registration per `.knowledge/designs/0003-object-system.md`
- `TypeInfo` metadata structure per `.knowledge/designs/0009-reflection.md`

Design elements this commit mutates:
- Registration ordering invariant: **all `_register_object_by_index` calls must happen in inheritance order** (base class before derived class). This is now enforced by centralizing them in `core.pyx`.
- Added `TYPE_CLS_TO_INFO` reverse mapping dict alongside existing `TYPE_INDEX_TO_CLS` and `TYPE_KEY_TO_INFO`

## Usage Examples
```python
from tvm_ffi.core import _type_cls_to_type_info
import tvm_ffi

info = _type_cls_to_type_info(tvm_ffi.Tensor)
assert info is not None
assert info.type_key == "ffi.Tensor"
assert info.parent_type_info.type_cls is tvm_ffi.Object
```
