# Fix TypeInfo parent propagation for Cython-defined classes
## TL;DR
- Fixes `parent_type_info` propagation for several Cython classes (Device, Error, Function, String, Tensor) that were not properly registering their parent type info due to registration ordering issues.
- Centralizes type registration logic in `core.pyx` initialization to ensure correct ordering.
- Adds comprehensive tests verifying `parent_type_info` is set for all built-in Cython classes.
