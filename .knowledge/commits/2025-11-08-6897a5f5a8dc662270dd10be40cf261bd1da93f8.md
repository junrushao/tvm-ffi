# Fix TypeInfo parent propagation ordering in Cython class registration
## TL;DR
- Fixes `parent_type_info` not being properly propagated for Cython classes by reordering `include` directives and inserting `_register_object_by_index()` calls in inheritance order in `core.pyx`
- Removes per-class registration from individual `.pxi` files, centralizing in `core.pyx`
- Adds `TYPE_CLS_TO_INFO` dict and `_type_cls_to_type_info()` for reverse lookup
- Adds comprehensive test coverage for type hierarchy propagation
