# Fix Cython use-after-free in _type_info_create_from_type_key by extending ByteArrayArg lifetime

## TL;DR
- Fixes a use-after-free (read-after-free) memory corruption in `_type_info_create_from_type_key` detected by AddressSanitizer.
- The root cause: a temporary `ByteArrayArg` object was destroyed before `TVMFFITypeKeyToIndex` finished reading from its pointer.
- Fix: bind the `ByteArrayArg` to a named `cdef` variable so its lifetime extends to the function scope.

## Key Exports
None -- no public API surface changes.

## Impact
- API: None
- Behavioral: Eliminates a use-after-free that could cause crashes or data corruption during type registration in Cython bindings. The bug manifested non-deterministically depending on allocator behavior.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **ByteArrayArg** (`python/tvm_ffi/cython/base.pxi:337`): Cython wrapper that holds a Python `bytes` object and exposes a `TVMFFIByteArray*` pointer. The `py_data` field keeps the bytes alive; destruction releases the reference, invalidating the pointer.
- **TVMFFITypeKeyToIndex** C API (`include/tvm/ffi/c_api.h`): Takes a `TVMFFIByteArray*` and reads from its `.data` pointer. Documented in [0001-c-abi-layer.md](../designs/0001-c-abi-layer.md).
- **Cython temporary lifetime semantics**: Cython may destruct temporaries before the enclosing expression completes evaluation, unlike C++ which guarantees temporaries live until the end of the full-expression.

Design elements this commit produces:
- None (no new design elements; this is a bugfix enforcing an existing contract).

## Usage Examples
**Before** (buggy pattern -- temporary destroyed before C call completes):
```cython
# WRONG: ByteArrayArg temporary may be freed before TVMFFITypeKeyToIndex reads from it
if TVMFFITypeKeyToIndex(ByteArrayArg(c_str(type_key)).cptr(), &type_index) != 0:
    raise ValueError(...)
```

**After** (correct pattern -- named variable extends lifetime):
```cython
# CORRECT: type_key_arg lives until function scope ends
cdef ByteArrayArg type_key_arg = ByteArrayArg(c_str(type_key))
if TVMFFITypeKeyToIndex(type_key_arg.cptr(), &type_index) != 0:
    raise ValueError(...)
```
