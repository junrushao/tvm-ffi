# Fix Cython memory corruption (use-after-free) in _type_info_create_from_type_key
## TL;DR
- Fixes a use-after-free bug in `_type_info_create_from_type_key` where a temporary `ByteArrayArg` was destroyed before `TVMFFITypeKeyToIndex` finished reading its pointer. The fix assigns the temporary to a named `cdef` variable to extend its lifetime past the C API call.
