# Fix clang-tidy warnings in test_c_env_api.cc: replace C-style casts, add vector reserve, modernize lock_guard

## TL;DR
- Replaces all C-style pointer casts with `static_cast<T*>` in `tests/cpp/extra/test_c_env_api.cc` to satisfy `cppcoreguidelines-pro-type-cstyle-cast`.
- Adds `threads.reserve(num_threads)` before `push_back` loops in two multithreaded test cases to satisfy `performance-reserve-before-push-back`.
- Replaces `std::lock_guard<std::mutex>` with `std::scoped_lock<std::mutex>` in two barrier synchronization blocks to satisfy `modernize-use-std-scoped-lock`.

## Usage Examples
Before/after pattern for the three clang-tidy fixes:

```cpp
// BEFORE: C-style cast (cppcoreguidelines-pro-type-cstyle-cast)
delete (int*)h;
EXPECT_EQ(*(int*)handle, 42);
auto* counter = (ThreadSafeCounter*)h;

// AFTER: static_cast
delete static_cast<int*>(h);
EXPECT_EQ(*static_cast<int*>(handle), 42);
auto* counter = static_cast<ThreadSafeCounter*>(h);

// BEFORE: no reserve (performance-reserve-before-push-back warning)
std::vector<std::thread> threads;
// ... push_back calls follow

// AFTER: reserve first
std::vector<std::thread> threads;
threads.reserve(num_threads);

// BEFORE: lock_guard (modernize-use-std-scoped-lock)
std::lock_guard<std::mutex> lock(mtx);

// AFTER: scoped_lock (deadlock-safer, C++17)
std::scoped_lock<std::mutex> lock(mtx);
```
