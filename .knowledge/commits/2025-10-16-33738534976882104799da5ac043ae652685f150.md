# Skip DLPack JIT extension loading when torch natively provides __c_dlpack_exchange_api__
## TL;DR
- Adds an early-return guard to `load_torch_c_dlpack_extension()` that checks if `torch.Tensor` already has the `__c_dlpack_exchange_api__` attribute before attempting the slow JIT compilation path.
- If the attribute exists (newer PyTorch versions that natively provide it), the function returns `None` immediately, skipping the inline C++ JIT build entirely.
- Also handles `ImportError` for environments where torch is not installed, returning `None` early.
