# Skip loading DLPack torch extension if __c_dlpack_exchange_api__ already exists
## TL;DR
- Adds an early-return guard to `load_torch_c_dlpack_extension()` that checks whether `torch.Tensor.__c_dlpack_exchange_api__` is already set (e.g., by a newer PyTorch version that natively supports this protocol), skipping the entire JIT-compiled C++ extension load if so.
- Also surfaces the `ImportError` (torch not installed) check earlier, before reaching the JIT compilation block.

## Key Exports
None (no public API change; internal behavioral guard only).

## Impact
- API: none
- Behavioral: When PyTorch already exposes `__c_dlpack_exchange_api__` on `torch.Tensor`, the JIT compilation of the C++ DLPack extension is skipped entirely. This avoids a slow first-time JIT compile on newer PyTorch versions where the protocol is natively available.
- Flags/config: none
- Data formats/schemas: none
