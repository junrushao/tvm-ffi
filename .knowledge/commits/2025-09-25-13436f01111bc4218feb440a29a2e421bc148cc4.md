# Reorder TVMFFIObject header fields to put ref counters first and shrink strong_ref_count from u64 to u32

## TL;DR
- **Field reorder**: `TVMFFIObject` layout changes from `{type_index(i32), weak_ref_count(u32), strong_ref_count(u64)}` to `{strong_ref_count(u32), weak_ref_count(u32), type_index(i32), __padding(u32)}` — ref counters move to offset 0.
- **Type shrink**: `strong_ref_count` narrows from `uint64_t` → `uint32_t`; together with `weak_ref_count` they now fit in a single 64-bit word at offset 0, paving the way for a future single-`u64` atomic that avoids reading weak counter during deletion (mirrors torch `intrusive_ptr`).
- **Dropped invariant**: `TVMFFIObject.type_index` is no longer at offset 0, so it no longer shares a prefix with `TVMFFIAny.type_index`; the ABI test that checked this (`test_c_ffi_abi.cc`) is deleted.

## Impact
- API: None — C++ API (`Object`, `ObjectPtr`, `WeakObjectPtr`) is unchanged. No new public symbols.
- Behavioral: None at the C++ call level — ref-counting semantics are identical.
- Flags/config: None.
- Data formats/schemas: **ABI-breaking** — any pre-compiled binary that accesses `TVMFFIObject` fields by offset (e.g., old `.so` files, old Cython extensions, old Rust bindings compiled against the prior `c_api.h`) will silently read wrong values. All consumers of `c_api.h` must recompile. The Cython `base.pxi` was updated in this same commit.

## Usage Examples

Before/after showing the layout change (from deleted test and new header):

```c
// BEFORE (pre-commit): type_index at offset 0, shared with TVMFFIAny
typedef struct {
  int32_t type_index;          // offset 0 — same offset as TVMFFIAny.type_index
  uint32_t weak_ref_count;     // offset 4
  uint64_t strong_ref_count;   // offset 8
  // + deleter at offset 16
} TVMFFIObject;
// TEST: reinterpret_cast<TVMFFIAny*>(&obj)->type_index == obj.type_index  ← PASSED

// AFTER (this commit): ref counters at offset 0, type_index moved to offset 8
typedef struct {
  uint32_t strong_ref_count;   // offset 0 (was at offset 8 as u64)
  uint32_t weak_ref_count;     // offset 4
  int32_t type_index;          // offset 8 (was at offset 0)
  uint32_t __padding;          // offset 12 (new, for alignment)
  // + deleter at offset 16
} TVMFFIObject;
// Note: TVMFFIAny.type_index is still at ITS offset 0.
// They no longer share prefix — accessing TVMFFIAny via TVMFFIObject* (or vice versa)
// for type_index is now INCORRECT.

// Future optimization enabled by packing both counters in first 8 bytes:
// atomic<uint64_t> packed = (uint64_t)strong_ref_count | ((uint64_t)weak_ref_count << 32);
// Single 64-bit CAS can update both atomically, skipping weak counter read during deletion.
```
