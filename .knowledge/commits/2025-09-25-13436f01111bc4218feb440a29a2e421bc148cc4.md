# Reorder TVMFFIObject header: strong/weak ref counts first (u32), aligning with torch intrusive_ptr ABI

## TL;DR
- Reorders `TVMFFIObject` header to place `strong_ref_count` and `weak_ref_count` (both `uint32`) first, before `type_index` and a new `__padding` field. This aligns the ABI layout with PyTorch's `intrusive_ptr` pattern.
- Narrows `strong_ref_count` from `uint64` to `uint32`, packing both counters into the first 8 bytes. This opens the door for a future single-`uint64`-atomic optimization that combines both counters to avoid an extra atomic read of the weak counter during deletion.
- Removes the old `test_c_ffi_abi.cc` test that asserted `TVMFFIAny` and `TVMFFIObject` share the same `type_index` first-field alignment. `type_index` is no longer the first field in `TVMFFIObject`.

## Key Exports

```python
class TVMFFIObject:
    """C-level heap object header. 24 bytes, 8-byte aligned."""
    # --- NEW layout (fields reordered, strong narrowed) ---
    strong_ref_count: uint32   # WAS: uint64, now packed into first u64 with weak_ref_count
    weak_ref_count: uint32     # Position unchanged relative to strong, but both now come first
    type_index: int32          # MOVED: was first field, now third
    __padding: uint32          # NEW: padding to maintain 8-byte alignment before deleter union
    deleter: Callable[[void_ptr, int], None]  # Unchanged
    # Invariant: 24 bytes total, 8-byte aligned (union ensures alignment)
    # Invariant: strong_ref_count + weak_ref_count pack into first u64 for future atomic optimization
    # Invariant: type_index is NO LONGER at the same offset as TVMFFIAny.type_index
    # Interacts with: Object.IncRef/DecRef/TryPromoteWeakPtr (all updated for u32 atomics)
    # Interacts with: Cython base.pxi (struct definition mirrors this layout)
    # Extension: future single-u64 atomic combining strong+weak, avoiding extra weak read during deletion
```

## Impact
- API: ABI-breaking change to `TVMFFIObject` struct layout. All consumers that read fields by offset are affected. The `type_index` field is no longer at offset 0 in `TVMFFIObject` (now at offset 8). `strong_ref_count` narrows from 64-bit to 32-bit, limiting max ref count to ~4 billion.
- Behavioral: `Object::use_count()`, `IncRef()`, `DecRef()`, `TryPromoteWeakPtr()` all change from 64-bit atomics (`_InterlockedIncrement64`/`_InterlockedCompareExchange64`) to 32-bit atomics (`_InterlockedIncrement`/`_InterlockedCompareExchange`) on MSVC. On GCC/Clang, `__atomic_*` intrinsics operate on `uint32_t` instead of `uint64_t`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVMFFIObject` header layout ([0001-ffi-c-abi.md](../design-records/0001-ffi-c-abi.md)) -- restructured field order and types
- `Object` ref-counting atomics ([0003-ffi-object-system.md](../design-records/0003-ffi-object-system.md)) -- narrowed from u64 to u32

Design elements this commit produces:
- **Mutated**: `TVMFFIObject` header layout -- new field order: `strong_ref_count(u32) + weak_ref_count(u32) + type_index(i32) + __padding(u32) + deleter(8)`, replacing `type_index(i32) + weak_ref_count(u32) + strong_ref_count(u64) + deleter(8)`
- **Mutated**: `TVMFFIObject`/`TVMFFIAny` type_index alignment -- `TVMFFIObject.type_index` and `TVMFFIAny.type_index` no longer share the same offset (Object at +8, Any at +0). The old test asserting `reinterpret_cast<TVMFFIAny*>(&object)->type_index == object.type_index` is removed.

## Usage Examples
Before/after pattern for the header layout change:

```c
// BEFORE: type_index first, strong_ref_count was uint64
typedef struct TVMFFIObject {
  int32_t type_index;
  uint32_t weak_ref_count;
  uint64_t strong_ref_count;    // 8 bytes
  union { void (*deleter)(...); int64_t __ensure_align; };
} TVMFFIObject;

// AFTER: ref counts first, strong narrowed to uint32
typedef struct TVMFFIObject {
  uint32_t strong_ref_count;    // 4 bytes (was 8)
  uint32_t weak_ref_count;
  int32_t type_index;           // moved to offset +8
  uint32_t __padding;           // new, ensures alignment
  union { void (*deleter)(...); int64_t __ensure_align; };
} TVMFFIObject;
// Total: still 24 bytes, still 8-byte aligned
```

MSVC atomic change (applies to IncRef, DecRef, TryPromoteWeakPtr, use_count):
```cpp
// BEFORE: 64-bit MSVC intrinsics
_InterlockedIncrement64(reinterpret_cast<volatile __int64*>(&header_.strong_ref_count));
// AFTER: 32-bit MSVC intrinsics
_InterlockedIncrement(reinterpret_cast<volatile long*>(&header_.strong_ref_count));
```
