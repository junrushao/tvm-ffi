# Enhance reflection system with nanobind/pybind-style API: method registration, field flags, docstrings, and namespace restructuring

## TL;DR
- Refactors the reflection API to follow nanobind/pybind naming conventions (`def_ro`, `def_rw`, `def`, `def_static`), replacing the prior `def_readonly`/`def_readwrite` interface, and moves everything from `tvm::ffi::details` to `tvm::ffi::reflection` (alias `refl`).
- Adds method registration support (`def`/`def_static`) and enriches `TVMFFIFieldInfo`/`TVMFFIMethodInfo` with docstrings, bitmask flags, and default values — completing the previously-stubbed method reflection extension point.
- Renames three C ABI functions (`TVMFFIRegisterTypeField` -> `TVMFFITypeRegisterField`, `TVMFFIGetOrAllocTypeIndex` -> `TVMFFITypeGetOrAllocIndex`) and adds two new ones (`TVMFFITypeRegisterMethod`, `TVMFFITypeGetMethod`), plus introduces `Object::_type_mutable` for controlling mutable raw-pointer casts from `Any`/`AnyView`.

### Rename Mapping

| Old Name | New Name |
|----------|----------|
| `tvm::ffi::details` (namespace) | `tvm::ffi::reflection` (+ alias `tvm::ffi::refl`) |
| `details::ReflectionDef` | `reflection::ReflectionDef` |
| `details::ReflectionFieldGetter` | `reflection::FieldGetter` |
| `details::GetReflectionFieldInfo` | `reflection::GetFieldInfo` |
| `ReflectionDef::def_readonly` | `ReflectionDef::def_ro` |
| `ReflectionDef::def_readwrite` | `ReflectionDef::def_rw` |
| `TVMFFIRegisterTypeField` | `TVMFFITypeRegisterField` |
| `TVMFFIGetOrAllocTypeIndex` | `TVMFFITypeGetOrAllocIndex` |
| `TVMFFIFieldInfo::readonly` (int32_t) | `TVMFFIFieldInfo::flags` (int64_t bitmask) |
| `TVMFFIMethodInfo::method` (TVMFFIObjectHandle) | `TVMFFIMethodInfo::method` (TVMFFIAny) |
| `TypeTraits<const TObject*>` | `TypeTraits<TObject*>` (with `_type_mutable` guard) |

**Enum `TVMFFIFieldFlagBitMask`** (C/C++ dual definition):
```c
enum TVMFFIFieldFlagBitMask : int32_t {
  TVMFFIFieldFlagBitMaskWritable     = 1 << 0,  // field is writable
  TVMFFIFieldFlagBitMaskHasDefault   = 1 << 1,  // field has a default value
  TVMFFIFieldFlagBitMaskIsStaticMethod = 1 << 2, // method is static (reused for TVMFFIMethodInfo)
};
```

**Class `reflection::ReflectionDef`** — enhanced builder:
```cpp
class ReflectionDef {
public:
  explicit ReflectionDef(int32_t type_index, const char* type_key);  // NOW takes type_key

  template<typename Class, typename T, typename... Extra>
  ReflectionDef& def_ro(const char* name, T Class::*field_ptr, Extra&&... extra);

  template<typename Class, typename T, typename... Extra>
  ReflectionDef& def_rw(const char* name, T Class::*field_ptr, Extra&&... extra);

  template<typename Func, typename... Extra>
  ReflectionDef& def(const char* name, Func&& func, Extra&&... extra);       // instance method

  template<typename Func, typename... Extra>
  ReflectionDef& def_static(const char* name, Func&& func, Extra&&... extra); // static method
};
```
The `Extra...` parameter pack accepts: string literals (for docstrings) and `FieldInfoTrait` subclasses like `DefaultValue`.

**Class `reflection::FieldInfoTrait`** — base trait for field info customization.

class DefaultValue : public FieldInfoTrait {
public:

**Object property** `_type_mutable` (new):
```cpp
class Object {
  static constexpr bool _type_mutable = false;  // default: non-mutable
};
```
When `true`, enables `TypeTraits<TObject*>::CopyFromAnyViewAfterCheck` to return a non-const pointer. Guarded by `static_assert`.

**Removed from `TypeTraits`**: `field_static_type_index` removed from `TypeTraits<char[N]>` and `TypeTraits<const char*>` — now defaults to `kTVMFFIAny` via `TypeTraitsBase`.

## Impact
- API: **Breaking** — C ABI functions renamed (`TVMFFIRegisterTypeField` -> `TVMFFITypeRegisterField`, `TVMFFIGetOrAllocTypeIndex` -> `TVMFFITypeGetOrAllocIndex`). `TVMFFIFieldInfo` struct layout changed (fields reordered, `readonly` removed, new fields added). `TVMFFIMethodInfo::method` changed from `TVMFFIObjectHandle` to `TVMFFIAny`. C++ namespace changed from `details` to `reflection`. All callers of the old C API functions, the old reflection namespace, or the old `TVMFFIFieldInfo` layout must update.
- Behavioral: `TypeTraits<const TObject*>` changed to `TypeTraits<TObject*>`, requiring `_type_mutable = true` on object types that want non-const raw-pointer extraction from `Any`/`AnyView`. Perfect forwarding (`std::forward<Args>(params)...`) added to method wrappers in `Function::Registry`.
- Flags/config: `TVMFFIFieldInfo.readonly` (bool-like int32_t) replaced with `TVMFFIFieldInfo.flags` (int64_t bitmask with `TVMFFIFieldFlagBitMask` values). Semantics inverted: old `readonly=true` means new `flags & Writable == 0`.
- Data formats/schemas: `TVMFFIFieldInfo` memory layout changed — any serialized or binary-compatible consumers of this struct must be updated.

## Usage Examples

### Registering fields and methods with the new API
**Context**: Defining a reflectable type with read-only/read-write fields, default values, docstrings, instance and static methods.
```cpp
// Object definition
class TFloatObj : public TNumberObj {
 public:
  double value;
  TFloatObj(double value) : value(value) {}
  double Add(double other) const { return value + other; }
  static constexpr const char* _type_key = "test.Float";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TFloatObj, TNumberObj);
};

// Reflection registration (nanobind-style)
TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
    .def("sub", [](const TFloatObj* self, double other) -> double { return self->value - other; })
    .def("add", &TFloatObj::Add, "add method");

// Runtime field access
reflection::FieldGetter getter("test.Float", "value");
Any val = getter(some_float_obj);  // returns the double value

reflection::FieldSetter setter("test.Float", "value");
setter(some_float_obj, 20.0);  // sets the value

// Runtime method call
Function float_add = reflection::GetMethod("test.Float", "add");
double result = float_add(some_float_obj, 2.0).cast<double>();

// Field info inspection
const TVMFFIFieldInfo* info = reflection::GetFieldInfo("test.Float", "value");
bool writable = info->flags & TVMFFIFieldFlagBitMaskWritable;       // true
bool has_default = info->flags & TVMFFIFieldFlagBitMaskHasDefault;  // true (10.0)
```
