# Refactor reflection subsystem to nanobind/pybind-style API with methods, defaults, docstrings, and bitmask flags

## TL;DR
- Renames the `details` namespace to `reflection` (alias `refl`) and shortens field registration methods (`def_readonly` -> `def_ro`, `def_readwrite` -> `def_rw`) to align with nanobind/pybind11 style.
- Extends `TVMFFIFieldInfo` with docstring, bitmask flags (`TVMFFIFieldFlagBitMask`), and default value storage; replaces the `readonly` int32 with a `flags` bitmask. Adds `TVMFFIFieldFlagBitMaskIsStaticMethod` for methods.
- Adds full method registration support: `ReflectionDef::def()` for instance methods, `def_static()` for static methods, backed by new C APIs `TVMFFITypeRegisterMethod` and `TVMFFITypeGetMethod`. Introduces `FieldSetter`, `GetMethodInfo`, `GetMethod` helpers.
- Introduces `Object::_type_mutable` flag that gates `const`-removal casts from `Any`/`AnyView` to raw `TObject*` pointers.

### Rename Mapping

| Before | After |
|--------|-------|
| `tvm::ffi::details` namespace | `tvm::ffi::reflection` (alias `tvm::ffi::refl`) |
| `ReflectionDef::def_readonly()` | `ReflectionDef::def_ro()` |
| `ReflectionDef::def_readwrite()` | `ReflectionDef::def_rw()` |
| `details::GetReflectionFieldInfo()` | `reflection::GetFieldInfo()` |
| `details::ReflectionFieldGetter` | `reflection::FieldGetter` |
| `TVMFFIFieldInfo::readonly` (int32) | `TVMFFIFieldInfo::flags` (int64 bitmask) |
| `TVMFFIRegisterTypeField()` | `TVMFFITypeRegisterField()` |
| `TVMFFIGetOrAllocTypeIndex()` | `TVMFFITypeGetOrAllocIndex()` |
| `TVMFFIMethodInfo::method` (ObjectHandle) | `TVMFFIMethodInfo::method` (TVMFFIAny) |

# --- C ABI additions/changes (c_api.h) ---

class TVMFFIFieldFlagBitMask(IntEnum):
    """Bitmask flags for field/method metadata."""
    Writable = 1 << 0          # Field is read-write
    HasDefault = 1 << 1        # Field has a default value
    IsStaticMethod = 1 << 2    # Method is static (no self)
    # Interacts with: TVMFFIFieldInfo.flags, TVMFFIMethodInfo.flags

class TVMFFIFieldInfo:
    """C-level field descriptor. CHANGED: added doc, flags, default_value; removed readonly."""
    name: TVMFFIByteArray
    doc: TVMFFIByteArray                   # NEW: docstring
    flags: int64                           # NEW: bitmask (replaces old readonly: int32)
    byte_offset: int64
    getter: TVMFFIFieldGetter
    setter: TVMFFIFieldSetter
    default_value: TVMFFIAny               # NEW: valid when flags & HasDefault
    field_static_type_index: int32
    # Invariant: setter is always set (even for readonly fields) for serialization
    # Invariant: default_value is nullptr when HasDefault not set

class TVMFFIMethodInfo:
    """C-level method descriptor. CHANGED: added doc, flags; method is now TVMFFIAny."""
    name: TVMFFIByteArray
    doc: TVMFFIByteArray                   # NEW
    flags: int64                           # NEW: bitmask (IsStaticMethod)
    method: TVMFFIAny                      # CHANGED: was TVMFFIObjectHandle
    # Invariant: first arg to instance methods is always self

# Renamed: TVMFFIRegisterTypeField -> TVMFFITypeRegisterField
def TVMFFITypeRegisterField(type_index: int32, info: TVMFFIFieldInfo) -> int: ...
    # Interacts with: TVMFFITypeInfo.fields[], TypeTable::RegisterTypeField

# NEW
def TVMFFITypeRegisterMethod(type_index: int32, info: TVMFFIMethodInfo) -> int: ...
    # Interacts with: TVMFFITypeInfo.methods[], TypeTable::RegisterTypeMethod

# NEW
def TVMFFITypeGetMethod(type_index: int32) -> TVMFFITypeInfo: ...

# Renamed: TVMFFIGetOrAllocTypeIndex -> TVMFFITypeGetOrAllocIndex
def TVMFFITypeGetOrAllocIndex(type_key: ByteArray, static_idx: int32, ...) -> int32: ...

# --- C++ reflection API (reflection/reflection.h) ---

class DefaultValue(FieldInfoTrait):
    """Trait to attach a default value to a field registration."""
    def __init__(self, value: Any): ...
    def Apply(self, info: TVMFFIFieldInfo) -> None:
        info.default_value = value
        info.flags |= HasDefault
    # Interacts with: ReflectionDef.RegisterField via variadic Extra... args

class ReflectionDef:
    """Builder for registering fields and methods. CHANGED: added type_key_, method support."""
    type_index_: int32
    type_key_: str              # NEW: used to name methods "TypeKey.method_name"

    def def_ro(self, name: str, field_ptr, *extra) -> ReflectionDef: ...
        # Interacts with: TVMFFITypeRegisterField, FieldInfoTrait.Apply
    def def_rw(self, name: str, field_ptr, *extra) -> ReflectionDef: ...
    def def_(self, name: str, func, *extra) -> ReflectionDef: ...       # NEW: instance method
        # Interacts with: TVMFFITypeRegisterMethod, Function.FromTyped
    def def_static(self, name: str, func, *extra) -> ReflectionDef: ... # NEW: static method

class FieldGetter:
    """Renamed from ReflectionFieldGetter. Added convenience ctor from type_key + field_name."""
    def __init__(self, type_key: str, field_name: str): ...
    def __init__(self, field_info: TVMFFIFieldInfo): ...
    def __call__(self, obj: Object) -> Any: ...

class FieldSetter:
    """NEW: symmetric to FieldGetter for write access."""
    def __init__(self, type_key: str, field_name: str): ...
    def __init__(self, field_info: TVMFFIFieldInfo): ...
    def __call__(self, obj: Object, value: AnyView) -> None: ...
    # Invariant: caller must ensure field is writable (flags & Writable)

def GetFieldInfo(type_key: str, field_name: str) -> TVMFFIFieldInfo: ...
    # Renamed from GetReflectionFieldInfo

def GetMethodInfo(type_key: str, method_name: str) -> TVMFFIMethodInfo: ...  # NEW

def GetMethod(type_key: str, method_name: str) -> Function: ...              # NEW
    # Interacts with: AnyView.CopyFromTVMFFIAny to extract Function from stored TVMFFIAny

# --- Object system addition (object.h) ---
# Object._type_mutable: bool = False  # NEW: gates mutable pointer casts from Any
# Invariant: when _type_mutable is False, TypeTraits<TObject*>::CopyFromAnyViewAfterCheck
#   triggers static_assert. Only types with _type_mutable=True allow non-const raw ptr extraction.
# Interacts with: TypeTraits<TObject*> in type_traits.h

## Impact
- API: **Breaking** -- C ABI functions renamed (`TVMFFIRegisterTypeField` -> `TVMFFITypeRegisterField`, `TVMFFIGetOrAllocTypeIndex` -> `TVMFFITypeGetOrAllocIndex`). `TVMFFIFieldInfo` struct layout changed (new fields, `readonly` removed, replaced by `flags`). `TVMFFIMethodInfo::method` changed from `TVMFFIObjectHandle` to `TVMFFIAny`. C++ namespace changed from `details` to `reflection`. All callers of old API names must update.
- Behavioral: `TypeTraits<const TObject*>` is now `TypeTraits<TObject*>` and requires `_type_mutable = true` for non-const extraction from Any. Previously, `const TObject*` could be extracted freely.
- Flags/config: New `Object::_type_mutable` static constexpr (default `false`) controls mutable raw pointer extraction.
- Data formats/schemas: `TVMFFIFieldInfo` binary layout changed -- any code reading/writing this struct across DLL boundaries must be recompiled.

## Design Elements
Design elements this commit consumes:
- Object system (`0003`): byte-offset computation from Object header, `_GetOrAllocRuntimeTypeIndex`
- C ABI (`0001`): `TVMFFITypeInfo`, `TVMFFIAny`, safe-call macros
- Function system (`0004`): `Function::FromTyped` for wrapping method pointers
- Object macros (`0008`): `TVM_FFI_DECLARE_FINAL_OBJECT_INFO` macro updated to use renamed `TVMFFITypeGetOrAllocIndex`
- TypeTraits (`0002`): `TypeTraitsBase` now has default `field_static_type_index = kTVMFFIAny`; `char[N]` and `const char*` no longer override it

Design elements this commit produces:
- `TVMFFIFieldFlagBitMask` enum with `Writable`, `HasDefault`, `IsStaticMethod` -- bitmask flags that replace the old `readonly` bool
- Method registration API: `ReflectionDef::def()`, `def_static()`, `TVMFFITypeRegisterMethod`, `GetMethodInfo`, `GetMethod`
- Field default values: `reflection::DefaultValue` trait, `TVMFFIFieldInfo::default_value`
- Field/method docstrings: `TVMFFIFieldInfo::doc`, `TVMFFIMethodInfo::doc`
- `reflection::FieldSetter` wrapper class (symmetric to `FieldGetter`)
- `Object::_type_mutable` flag gating non-const raw pointer extraction
- Namespace alias `tvm::ffi::refl = tvm::ffi::reflection`
- `TypeTraitsBase::field_static_type_index` default (moved from per-type overrides to base)

## Usage Examples

Registering fields with defaults, docstrings, and methods (from `tests/cpp/test_reflection.cc`):
```cpp
// Define type with field and method reflection
TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
    .def("sub", [](const TFloatObj* self, double other) -> double { return self->value - other; })
    .def("add", &TFloatObj::Add, "add method");

TVM_FFI_REFLECTION_DEF(TIntObj)
    .def_ro("value", &TIntObj::value)
    .def_static("static_add", &TInt::StaticAdd, "static add method");

// Access fields
reflection::FieldGetter getter("test.Float", "value");
Any val = getter(my_float_obj);  // reads via byte-offset

reflection::FieldSetter setter("test.Float", "value");
setter(my_float_obj, 20.0);     // writes via byte-offset

// Call methods
Function float_add = reflection::GetMethod("test.Float", "add");
double result = float_add(TFloat(1), 2.0).cast<double>();  // 3.0

Function static_add = reflection::GetMethod("test.Int", "static_add");
TInt sum = static_add(TInt(1), TInt(2)).cast<TInt>();       // value=3
```
