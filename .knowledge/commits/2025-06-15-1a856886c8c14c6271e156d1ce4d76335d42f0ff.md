# Enhance reflection system with method registration, nanobind-style API, and C ABI namespace rationalization

## TL;DR
- Renames `ReflectionDef` builder methods from `def_readonly`/`def_readwrite` to `def_ro`/`def_rw` (nanobind/pybind style) and adds `def`/`def_static` for method registration; moves the class from `namespace details` to `namespace reflection` (aliased as `namespace refl`).
- Expands `TVMFFIFieldInfo` C struct with `doc` (docstring), `flags` bitmask (`Writable`, `HasDefault`, `IsStaticMethod`), and `default_value` (`TVMFFIAny`); renames `readonly` field → `flags`; adds new `TVMFFIMethodInfo` struct fields `doc` and `flags`.
- Renames three C ABI functions: `TVMFFIRegisterTypeField` → `TVMFFITypeRegisterField`, adds `TVMFFITypeRegisterMethod`, and `TVMFFIGetOrAllocTypeIndex` → `TVMFFITypeGetOrAllocIndex`; adds `FieldSetter` and `GetMethod` / `GetMethodInfo` C++ helpers.

## Impact
- API: **Breaking** — three C ABI function renames (`TVMFFIRegisterTypeField` → `TVMFFITypeRegisterField`, `TVMFFIGetOrAllocTypeIndex` → `TVMFFITypeGetOrAllocIndex`); `TVMFFIFieldInfo` struct layout changed (fields reordered, `readonly` removed, `flags`/`doc`/`default_value` added); `TVMFFIMethodInfo.method` type changed from `TVMFFIObjectHandle` to `TVMFFIAny`. Any C, Python, or Rust caller using the old struct field positions or old function names is broken.
- Behavioral: `def_ro`/`def_rw` replace `def_readonly`/`def_readwrite` — existing `TVM_FFI_REFLECTION_DEF` call sites in tests are updated; Python bindings calling the old C ABI names will fail at link time until updated.
- Flags/config: `Object::_type_mutable = false` is now a required constexpr for all Object subclasses; cast of non-const `TObject*` from `Any`/`AnyView` triggers `static_assert` unless `_type_mutable = true` is set.
- Data formats/schemas: `TVMFFIFieldInfo` binary layout changed — any serialized format that embeds the struct directly (e.g., mmap-based) must be regenerated.

## Usage Examples

**Register fields and methods on a C++ Object type (new API):**
```cpp
// Define the type:
class TFloatObj : public Object {
 public:
  double value;
  double Add(double other) const { return value + other; }
  static constexpr const char* _type_key = "test.Float";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TFloatObj, Object);
};

// Register at static init time (new API):
TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
    .def("sub", [](const TFloatObj* self, double other) -> double { return self->value - other; })
    .def("add", &TFloatObj::Add, "add method");

// Register a static method:
TVM_FFI_REFLECTION_DEF(TIntObj)
    .def_ro("value", &TIntObj::value)
    .def_static("static_add", &TInt::StaticAdd, "static add method");
```

**Read/write a field and call a method at runtime (new C++ helpers):**
```cpp
// Field access:
reflection::FieldGetter getter("test.Float", "value");
Any val = getter(TFloat(10.0));  // → 10.0

reflection::FieldSetter setter("test.Float", "value");
setter(obj_ref, 20.0);  // mutates field in-place

// Method call:
Function float_add = reflection::GetMethod("test.Float", "add");
double result = float_add(TFloat(1.0), 2.0).cast<double>();  // → 3.0

Function static_add = reflection::GetMethod("test.Int", "static_add");
TInt sum = static_add(TInt(1), TInt(2)).cast<TInt>();
```

**Mutable pointer guard:**
```cpp
// This will compile-error unless TPrimExprObj declares _type_mutable = true:
TVM_FFI_REFLECTION_DEF(TPrimExprObj)
    .def("sub", [](TPrimExprObj* self, double other) -> double { ... });
// In TPrimExprObj definition:
// static constexpr bool _type_mutable = true;
```
