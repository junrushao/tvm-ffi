# Refactor reflection to nanobind/pybind-style API with method registration, field defaults, and docstrings

## TL;DR
- Renames the reflection namespace from `details::` to `reflection::` (alias `refl::`) and adopts shorter pybind-style method names (`def_ro`, `def_rw`, `def`, `def_static`).
- Extends `TVMFFIFieldInfo` and `TVMFFIMethodInfo` with docstrings, bitmask flags (`TVMFFIFieldFlagBitMask`), and per-field default values; renames C API functions to `TVMFFIType*` prefix.
- Adds method registration (`TVMFFITypeRegisterMethod`) and helper accessors (`reflection::FieldSetter`, `reflection::GetMethod`), and introduces `Object::_type_mutable` to gate non-const raw pointer casts from Any.

## Key Exports

# --- C ABI layer (c_api.h) ---

class TVMFFIFieldFlagBitMask(IntEnum):
    """Bitmask flags for field/method metadata."""
    Writable = 1 << 0        # Field is writable
    HasDefault = 1 << 1      # Field has a default value
    IsStaticMethod = 1 << 2  # Method is static (no self param)

class TVMFFIFieldInfo:
    """Per-field reflection metadata (C struct)."""
    name: TVMFFIByteArray
    doc: TVMFFIByteArray                          # NEW: docstring
    flags: int64                                   # NEW: bitmask (replaces readonly: int32)
    byte_offset: int64
    getter: TVMFFIFieldGetter
    setter: TVMFFIFieldSetter
    default_value: TVMFFIAny                       # NEW: stored default (valid when HasDefault set)
    field_static_type_index: int32
    # Interacts with: TVMFFITypeRegisterField, reflection::ReflectionDef
    # Invariant: setter is always registered even for readonly fields (for serialization)

class TVMFFIMethodInfo:
    """Per-method reflection metadata (C struct)."""
    name: TVMFFIByteArray
    doc: TVMFFIByteArray                           # NEW
    flags: int64                                    # NEW: bitmask
    method: TVMFFIAny                              # CHANGED: was TVMFFIObjectHandle, now AnyView-stored Function
    # Interacts with: TVMFFITypeRegisterMethod, reflection::ReflectionDef.def/def_static

# Renamed C API functions:
# OLD: TVMFFIRegisterTypeField  -> NEW: TVMFFITypeRegisterField
# OLD: TVMFFIGetOrAllocTypeIndex -> NEW: TVMFFITypeGetOrAllocIndex

def TVMFFITypeRegisterMethod(type_index: int32, info: TVMFFIMethodInfo_ptr) -> int: ...  # NEW
def TVMFFITypeGetOrAllocIndex(type_key: TVMFFIByteArray_ptr, static_type_index: int32,
                              type_depth: int32, num_child_slots: int32,
                              child_slots_can_overflow: int32,
                              parent_type_index: int32) -> int32: ...

# --- C++ reflection layer (reflection/reflection.h) ---
# Namespace: tvm::ffi::reflection (alias tvm::ffi::refl)
# OLD namespace: tvm::ffi::details

class DefaultValue(FieldInfoTrait):
    """Trait to set a default value on a field."""
    def __init__(self, value: Any): ...
    def Apply(self, info: TVMFFIFieldInfo_ptr) -> None: ...
    # Interacts with: ReflectionDef.def_ro/def_rw via variadic extra args

class ReflectionDef:
    """Fluent builder for registering field/method accessors."""
    type_index_: int32
    type_key_: str                      # NEW: stored for method naming

    def __init__(self, type_index: int32, type_key: str) -> None: ...
    # CHANGED: was (type_index) only

    # OLD: def_readonly -> NEW: def_ro
    def def_ro(self, name: str, field_ptr: MemberPointer[Class, T], *extra) -> ReflectionDef: ...
    # OLD: def_readwrite -> NEW: def_rw
    def def_rw(self, name: str, field_ptr: MemberPointer[Class, T], *extra) -> ReflectionDef: ...

    # NEW methods:
    def def_(self, name: str, func: Callable, *extra) -> ReflectionDef: ...
        # Registers an instance method (self is first arg)
        # Interacts with: TVMFFITypeRegisterMethod, Function.FromTyped
    def def_static(self, name: str, func: Callable, *extra) -> ReflectionDef: ...
        # Registers a static method (no self)
        # Interacts with: TVMFFITypeRegisterMethod, TVMFFIFieldFlagBitMask.IsStaticMethod

# OLD: details::GetReflectionFieldInfo -> NEW:
def GetFieldInfo(type_key: str, field_name: str) -> TVMFFIFieldInfo_ptr: ...
# NEW:
def GetMethodInfo(type_key: str, method_name: str) -> TVMFFIMethodInfo_ptr: ...
def GetMethod(type_key: str, method_name: str) -> Function: ...

# OLD: details::ReflectionFieldGetter -> NEW:
class FieldGetter:
    """Resolved field getter for repeated access."""
    def __init__(self, field_info: TVMFFIFieldInfo_ptr): ...
    def __init__(self, type_key: str, field_name: str): ...   # NEW convenience ctor
    def __call__(self, obj: Object_ptr) -> Any: ...

# NEW:
class FieldSetter:
    """Resolved field setter for repeated access."""
    def __init__(self, field_info: TVMFFIFieldInfo_ptr): ...
    def __init__(self, type_key: str, field_name: str): ...
    def __call__(self, obj: Object_ptr, value: AnyView) -> None: ...
    # Interacts with: TVMFFIFieldInfo.setter, byte_offset

# --- Object system (object.h) ---
class Object:
    _type_mutable: ClassVar[bool] = False   # NEW: gates non-const raw ptr cast from Any
    # Invariant: TypeTraits<TObject*> static_asserts _type_mutable == True for non-const T

# --- Type traits (type_traits.h) ---
class TypeTraitsBase:
    field_static_type_index: ClassVar[int32] = TypeIndex.kTVMFFIAny  # MOVED here from individual specializations

## Impact
- API: Breaking rename of 3 C API functions (`TVMFFIRegisterTypeField` -> `TVMFFITypeRegisterField`, `TVMFFIGetOrAllocTypeIndex` -> `TVMFFITypeGetOrAllocIndex`); reflection method renames (`def_readonly` -> `def_ro`, `def_readwrite` -> `def_rw`); `TVMFFIFieldInfo.readonly` field replaced by `flags` bitmask; `TVMFFIMethodInfo.method` type changed from `TVMFFIObjectHandle` to `TVMFFIAny`; namespace change from `details::` to `reflection::`.
- Behavioral: `TypeTraits<const TObject*>` replaced by `TypeTraits<TObject*>` with `_type_mutable` gate; non-const raw ptr extraction from Any now requires opt-in.
- Flags/config: New `Object::_type_mutable` class-level flag (default false).
- Data formats/schemas: `TVMFFIFieldInfo` struct layout changed (added `doc`, `flags`, `default_value` fields; removed `readonly`; field ordering changed).

## Usage Examples

Registering fields with defaults, docstrings, and methods (from test_reflection.cc):
```cpp
// Define reflection with the new pybind-style API
TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
    .def("sub", [](const TFloatObj* self, double other) -> double { return self->value - other; })
    .def("add", &TFloatObj::Add, "add method");

TVM_FFI_REFLECTION_DEF(TIntObj)
    .def_ro("value", &TIntObj::value)
    .def_static("static_add", &TInt::StaticAdd, "static add method");

// Access field metadata at runtime
const TVMFFIFieldInfo* info = reflection::GetFieldInfo("test.Float", "value");
assert(info->flags & TVMFFIFieldFlagBitMaskHasDefault);
assert(info->default_value.v_float64 == 10.0);

// Call methods by name
Function float_add = reflection::GetMethod("test.Float", "add");
double result = float_add(TFloat(1), 2.0).cast<double>();  // 3.0

Function static_int_add = reflection::GetMethod("test.Int", "static_add");
TInt sum = static_int_add(TInt(1), TInt(2)).cast<TInt>();   // value=3
```
