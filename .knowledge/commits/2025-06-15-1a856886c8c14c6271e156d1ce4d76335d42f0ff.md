# Enhance reflection system with nanobind/pybind-style API: methods, defaults, docstrings, and field flag bitmask

## TL;DR
- Rewrites the `ReflectionDef` builder to support nanobind/pybind-style API: `def_ro`, `def_rw`, `def`, `def_static` with variadic `Extra...` args for docstrings and default values.
- Extends `TVMFFIFieldInfo` and `TVMFFIMethodInfo` C ABI structs with `flags` bitmask, `doc`, and `default_value` fields; replaces the `readonly` boolean with `TVMFFIFieldFlagBitMask` enum; changes `TVMFFIMethodInfo::method` from `TVMFFIObjectHandle` to `TVMFFIAny`.
- Renames C API functions (`TVMFFIRegisterTypeField` -> `TVMFFITypeRegisterField`, `TVMFFIGetOrAllocTypeIndex` -> `TVMFFITypeGetOrAllocIndex`), moves reflection from `details` namespace to `reflection` (alias `refl`), renames helper classes (`ReflectionFieldGetter` -> `FieldGetter`), and adds new `FieldSetter`, `GetMethodInfo`, `GetMethod` helpers.
- Introduces `Object::_type_mutable` flag controlling whether non-const `TObject*` can be extracted from `Any`/`AnyView`, with a compile-time `static_assert` guard.

```cpp
class ReflectionDef {
  ReflectionDef(int32_t type_index, const char* type_key);  // NEW: takes type_key

  template <typename Class, typename T, typename... Extra>
  ReflectionDef& def_ro(const char* name, T Class::*field_ptr, Extra&&... extra);

  template <typename Class, typename T, typename... Extra>
  ReflectionDef& def_rw(const char* name, T Class::*field_ptr, Extra&&... extra);

  template <typename Func, typename... Extra>
  ReflectionDef& def(const char* name, Func&& func, Extra&&... extra);

  template <typename Func, typename... Extra>
  ReflectionDef& def_static(const char* name, Func&& func, Extra&&... extra);

```

### FieldInfoTrait Protocol (`include/tvm/ffi/reflection/reflection.h`)

```cpp
struct FieldInfoTrait {};

class DefaultValue : public FieldInfoTrait {
  explicit DefaultValue(Any value);
  void Apply(TVMFFIFieldInfo* info) const;  // sets default_value + flags
};
```

Extra args to `def_ro`/`def_rw` matching `FieldInfoTrait` call `Apply(info)`; `const char*` extra args set `info->doc`.

### TypeTraits Changes (`include/tvm/ffi/type_traits.h`)

- `TypeTraitsBase` gains `static constexpr int32_t field_static_type_index = TypeIndex::kTVMFFIAny` (moved from per-specialization).
- `TypeTraits<const char*>` and `TypeTraits<char[N]>` lose their `field_static_type_index = kTVMFFIRawStr` overrides (now inherit `kTVMFFIAny` from base).
- `TypeTraits<const TObject*>` generalized to `TypeTraits<TObject*>` -- supports both const and non-const pointers; non-const path requires `TObject::_type_mutable == true` via `static_assert`.

## Impact
- API: Breaking. `def_readonly` -> `def_ro`, `def_readwrite` -> `def_rw`, `ReflectionFieldGetter` -> `reflection::FieldGetter`, `GetReflectionFieldInfo` -> `reflection::GetFieldInfo`. All call sites using reflection API must update.
- ABI: Breaking. `TVMFFIFieldInfo` struct layout changed (field order, added fields, removed `readonly`). `TVMFFIMethodInfo::method` type changed from `TVMFFIObjectHandle` to `TVMFFIAny`. C API function names renamed.
- Behavioral: `TypeTraits<TObject*>` now supports non-const object pointer extraction gated by `_type_mutable`; `Function::Registry::set_body_method` adds `std::forward` for args (correctness fix for move-only parameters).
- Flags/config: New `Object::_type_mutable` static constexpr field; defaults to `false`.
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- **Object system** (`.knowledge/designs/object-system.md`): dual-class pattern `FooObj`/`Foo`, `_GetOrAllocRuntimeTypeIndex()`, `_type_key`, `_type_final`. Adds new `_type_mutable` metadata field.
- **TypeTraits protocol** (`.knowledge/designs/type-traits.md`): `TypeTraitsBase`, `CopyToAnyView`, `MoveToAny`, `TryCastFromAnyView`. Modifies `field_static_type_index` default location.
- **Function system** (`.knowledge/designs/function-system.md`): `Function::FromTyped` used to wrap methods and lambdas for method reflection registration.
- **Any/AnyView** (`.knowledge/designs/any-system.md`): `AnyView::CopyFromTVMFFIAny`, `AnyView::CopyToTVMFFIAny` used for default values and method storage in the C ABI structs.
- **C ABI** (`.knowledge/designs/c-abi.md`): `TVMFFIFieldInfo`, `TVMFFIMethodInfo`, `TVMFFITypeInfo`, `TVMFFIByteArray` -- all modified or extended.

Design elements this commit produces:
- **`TVMFFIFieldFlagBitMask` enum**: Bitmask replacing boolean `readonly`. Extensible pattern for future field metadata flags.
- **`FieldInfoTrait` protocol**: Extension point for passing metadata to `def_ro`/`def_rw`. `DefaultValue` is the first concrete trait. String args (`const char*`) are handled via `if constexpr` in `ApplyFieldInfoTrait`.
- **Method reflection**: First functional implementation. `def`/`def_static` register instance and static methods via `TVMFFITypeRegisterMethod`. Methods are stored as `TVMFFIAny` (wrapping `Function`) in `TVMFFIMethodInfo`.
- **`_type_mutable` object flag**: Opt-in mechanism allowing non-const raw pointer extraction from `Any`/`AnyView`. Enforced at compile time via `static_assert`.
- **`reflection` namespace**: Moves reflection public API from `details` (internal) to `reflection` (public), signaling API stability intent.

## Usage Examples

### Defining fields with defaults and docstrings
```cpp
#include <tvm/ffi/reflection/reflection.h>
using namespace tvm::ffi;

TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value, "float value field", refl::DefaultValue(10.0))
    .def("sub", [](const TFloatObj* self, double other) -> double { return self->value - other; })
    .def("add", &TFloatObj::Add, "add method");

TVM_FFI_REFLECTION_DEF(TIntObj)
    .def_ro("value", &TIntObj::value)
    .def_static("static_add", &TInt::StaticAdd, "static add method");
```

### Querying field metadata at runtime
```cpp
const TVMFFIFieldInfo* info = reflection::GetFieldInfo("test.Float", "value");
// info->flags & TVMFFIFieldFlagBitMaskHasDefault  == true
// info->flags & TVMFFIFieldFlagBitMaskWritable     == true
// info->doc => "float value field"
// AnyView::CopyFromTVMFFIAny(info->default_value).cast<double>() == 10.0
```

### Calling a reflected method
```cpp
Function float_add = reflection::GetMethod("test.Float", "add");
double result = float_add(TFloat(1.0), 2.0).cast<double>();  // == 3.0

Function static_int_add = reflection::GetMethod("test.Int", "static_add");
TInt sum = static_int_add(TInt(1), TInt(2)).cast<TInt>();    // sum->value == 3
```

### Mutable object pointer extraction
```cpp
// In class definition:
class TPrimExprObj : public Object {
  static constexpr bool _type_mutable = true;
  // ...
};

// Now non-const pointer extraction works:
TPrimExprObj* ptr = any_view.cast<TPrimExprObj*>();  // OK
// Without _type_mutable = true, this would be a static_assert failure.
```
