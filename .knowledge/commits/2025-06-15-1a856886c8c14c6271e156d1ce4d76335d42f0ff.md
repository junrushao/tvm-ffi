# Refactor reflection system to nanobind/pybind-style API with method registration, default values, and bitmask flags

## TL;DR
- Restructures `ReflectionDef` to use nanobind/pybind-style API: `def_readonly`/`def_readwrite` become `def_ro`/`def_rw`, adds `def()` for instance methods and `def_static()` for static methods, and supports variadic extra arguments (docstrings, `DefaultValue`).
- Renames C API functions (`TVMFFIRegisterTypeField` -> `TVMFFITypeRegisterField`, `TVMFFIGetOrAllocTypeIndex` -> `TVMFFITypeGetOrAllocIndex`) and adds `TVMFFITypeRegisterMethod`.
- Moves reflection helpers from `tvm::ffi::details` to `tvm::ffi::reflection` (alias `tvm::ffi::refl`), replaces `readonly` int32 field with `flags` bitmask (`TVMFFIFieldFlagBitMask`), and adds `doc`, `default_value`, and `flags` to both `TVMFFIFieldInfo` and `TVMFFIMethodInfo`.

### Rename mapping

| Old name | New name |
|---|---|
| `tvm::ffi::details` (namespace) | `tvm::ffi::reflection` (with alias `tvm::ffi::refl`) |
| `ReflectionDef::def_readonly()` | `ReflectionDef::def_ro()` |
| `ReflectionDef::def_readwrite()` | `ReflectionDef::def_rw()` |
| `details::ReflectionFieldGetter` | `reflection::FieldGetter` |
| `details::GetReflectionFieldInfo()` | `reflection::GetFieldInfo()` |
| `TVMFFIRegisterTypeField()` | `TVMFFITypeRegisterField()` |
| `TVMFFIGetOrAllocTypeIndex()` | `TVMFFITypeGetOrAllocIndex()` |
| `TVMFFIFieldInfo::readonly` (int32) | `TVMFFIFieldInfo::flags` (int64 bitmask) |
| `TVMFFIMethodInfo::method` (ObjectHandle) | `TVMFFIMethodInfo::method` (TVMFFIAny) |

class TVMFFIFieldFlagBitMask(IntEnum):
    """Bitmask flags for field and method info."""
    Writable = 1 << 0          # Field is writable (replaces old `readonly` flag)
    HasDefault = 1 << 1        # Field has a default value
    IsStaticMethod = 1 << 2    # Method is static (no self argument)
    # Invariant: flags=0 means readonly, no default, instance method
    # Extension: new bits can be added without breaking ABI (int64 storage)

    type_index_: int32

        """Register a read-only field with optional docstring and default."""
        # Interacts with: TVMFFITypeRegisterField

    def def_rw(self, name: str, field_ptr: MemberPtr[Class, T],

## Impact
- API: **Breaking** -- C API function renames (`TVMFFIRegisterTypeField` -> `TVMFFITypeRegisterField`, `TVMFFIGetOrAllocTypeIndex` -> `TVMFFITypeGetOrAllocIndex`); `TVMFFIFieldInfo` struct layout reordered with new fields; `TVMFFIMethodInfo::method` type changed from `ObjectHandle` to `TVMFFIAny`; C++ `def_readonly`/`def_readwrite` renamed to `def_ro`/`def_rw`; namespace moved from `details` to `reflection`
- Behavioral: `TypeTraits<const TObject*>` replaced by `TypeTraits<TObject*>` which enforces `_type_mutable` via `static_assert` for non-const object pointer casts from Any/AnyView. Existing code using `const TObject*` in AnyView casts may need to switch to mutable pointers with `_type_mutable = true`.
- Flags/config: New `_type_mutable` static constexpr on Object (default `false`). Must be set to `true` on object types that need mutable pointer extraction from Any/AnyView.
- Data formats/schemas: `TVMFFIFieldInfo` struct layout changed (field order, new members). Binary compatibility broken.

## Usage Examples

### Registering fields with defaults and docstrings, plus methods
**Context**: C++ object type with the new nanobind-style reflection API.

```cpp
// C++ side: define type and register with new API
TVM_FFI_REFLECTION_DEF(TFloatObj)
    .def_rw("value", &TFloatObj::value,
            "float value field",                    // docstring (const char*)
            refl::DefaultValue(10.0))               // default value
    .def("sub", [](const TFloatObj* self, double other) -> double {
      return self->value - other;
    })
    .def("add", &TFloatObj::Add, "add method");     // member function pointer

TVM_FFI_REFLECTION_DEF(TIntObj)
    .def_ro("value", &TIntObj::value)               // read-only, no extras
    .def_static("static_add", &TInt::StaticAdd,     // static method
                "static add method");
```

### Querying method and field metadata at runtime
```cpp
using namespace tvm::ffi::reflection;

// Field info query with defaults and flags
const TVMFFIFieldInfo* info = GetFieldInfo("test.Float", "value");
assert(info->flags & TVMFFIFieldFlagBitMaskWritable);
assert(info->flags & TVMFFIFieldFlagBitMaskHasDefault);
// info->default_value holds 10.0

// Method dispatch
Function float_add = GetMethod("test.Float", "add");
double result = float_add(TFloat(1.0), 2.0).cast<double>();  // returns 3.0

// Static method dispatch
Function static_add = GetMethod("test.Int", "static_add");
TInt sum = static_add(TInt(1), TInt(2)).cast<TInt>();  // sum->value == 3
```
