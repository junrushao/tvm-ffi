# Extract stubgen docs into standalone page with expanded directive reference
## TL;DR
- Moved the stub generation section from `docs/packaging/python_packaging.rst` into a new standalone page `docs/packaging/stubgen.rst` with significantly expanded content (400 lines vs. original ~100 lines).
