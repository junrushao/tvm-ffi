# Fix IterAdapter to conform to LegacyInputIterator requirements
## TL;DR
- Fixes `IterAdapter` in `container_details.h` so the dereferenced iterator returns the correct `reference_type`, conforming to the C++ LegacyInputIterator named requirement.
- Prevents undefined behavior when used with STL algorithms like `std::make_move_iterator`.
