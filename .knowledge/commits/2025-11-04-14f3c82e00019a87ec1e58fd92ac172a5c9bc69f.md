# Fix IterAdapter to conform to InputIterator requirements
## TL;DR
- Fixes `IterAdapter` and `ReverseIterAdapter` to conform to C++ InputIterator requirements: `reference` type now matches dereference return type
- Changes `pointer` to `const T*` and `reference` to `const T` (was non-const references to converted values)
- `operator*` return type changed from `const value_type` to `reference`

## Key Exports
```python
# C++ IterAdapter (pseudocode)
class IterAdapter:
    # Before: reference = Converter::ResultType&  (dangling reference to temporary)
    # After:  reference = const Converter::ResultType  (value return, safe)
    # Invariant: dereference return type must match reference_type per cppreference
```

## Impact
- API: None (internal iterator types)
- Behavioral: Fixes undefined behavior when used with `std::make_move_iterator` and other STL components
- Flags/config: None
- Data formats/schemas: None

## Usage Examples
```cpp
// Before (UB): std::make_move_iterator with IterAdapter could reference dangling temps
// After (safe): proper value-type return from dereference
auto it = std::make_move_iterator(array.begin());
auto val = *it;  // now well-defined
```
