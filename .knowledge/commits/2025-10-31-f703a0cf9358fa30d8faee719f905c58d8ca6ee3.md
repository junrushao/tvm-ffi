# Add ahead-of-time (AOT) wheel distribution infrastructure for PyTorch DLPack extension

## TL;DR
- Introduces `addons/torch_c_dlpack_ext/` — a standalone pip package providing pre-built `libtorch_c_dlpack_addon` wheels for specific (python-version, pytorch-version) combinations.
- The package exposes `get_lib_path()` so `tvm_ffi._optional_torch_c_dlpack` can prefer the pre-built library over JIT compilation.
- `python/tvm_ffi/_optional_torch_c_dlpack.py` gains a probe for the installed `torch_c_dlpack_ext` package before falling back to JIT.

## Impact
- API: New optional package `torch_c_dlpack_ext` installable from PyPI; `tvm_ffi` checks for it at import time.
- Behavioral: When `torch_c_dlpack_ext` is installed, skips JIT compilation entirely — faster startup.
- Flags/config: `TVM_FFI_DISABLE_TORCH_C_DLPACK=1` still respected.
- Data formats/schemas: none

- `BuildBackend` — PEP 517 custom build backend for torch C DLPack wheels

## Usage Examples

```python
# After installing torch_c_dlpack_ext wheel:

```

```bash

```
