# Add ahead-of-time build option for PyTorch DLPack extension as a distributable addon package
## TL;DR
- Introduces `addons/torch_c_dlpack_ext/`, a standalone Python package with a custom PEP 517 build backend that can precompile the torch DLPack C extension into a wheel (eliminating JIT compilation at import time).
- Adds an early-return import path in `_optional_torch_c_dlpack.py`: `import torch_c_dlpack_ext` is tried before falling back to JIT compilation.
- Backward compatible: default behavior unchanged, the prebuilt package is opt-in only.

## Impact
- API: none -- additive only; new `torch_c_dlpack_ext` package can be installed independently
- Behavioral: when the prebuilt package is installed, `tvm_ffi` skips JIT compilation of the DLPack extension on first import (faster cold start)
- Flags/config: none (existing `TVM_FFI_DISABLE_TORCH_C_DLPACK` env var still respected)
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `__c_dlpack_exchange_api__` protocol (0012-ffi-python-package) -- the addon sets this class attribute on `torch.Tensor` using a prebuilt native library
- `TorchDLPackExchangeAPIPtr` C symbol -- called via ctypes to obtain the exchange API pointer
- `tvm_ffi.utils._build_optional_torch_c_dlpack` build script -- invoked by the build backend when no prebuilt library is available

Design elements this commit produces:
- None -- this is a packaging/distribution change that repackages existing functionality into a standalone wheel.

## Usage Examples

```python
# Install the prebuilt addon package (eliminates JIT compilation):
# pip install torch_c_dlpack_ext

# Automatic loading via tvm_ffi (new import path):
import tvm_ffi  # triggers load_torch_c_dlpack_extension()
# -> tries: import torch_c_dlpack_ext  (prebuilt, fast)
# -> falls back to JIT compile if not installed (unchanged behavior)

# Direct use:
from torch_c_dlpack_ext.core import load_torch_c_dlpack_extension
load_torch_c_dlpack_extension()
# torch.Tensor now has __c_dlpack_exchange_api__ attribute set
```
