# Add ahead-of-time build infrastructure for PyTorch DLPack extension
## TL;DR
- Adds `addons/torch_c_dlpack_ext/` as a standalone Python package with `pyproject.toml` and scikit-build backend (`build_backend.py`) for AOT compilation of the torch C DLPack extension.
- Adds `torch_c_dlpack_ext/core.py` with logic to locate and load prebuilt shared libraries matching the current Python/PyTorch version.
- Updates `python/tvm_ffi/_optional_torch_c_dlpack.py` to prefer prebuilt libraries from the addon before falling back to JIT build.
