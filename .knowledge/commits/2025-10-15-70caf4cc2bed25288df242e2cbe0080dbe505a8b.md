# Fix Cython exception annotations on DLPack function pointer typedefs
## TL;DR
- Change four DLPack callback function pointer typedefs in `base.pxi` from `noexcept` to `except -1`, enabling proper Python exception propagation when these callbacks return -1.
- Apply `except -1` to `TorchDLPackToPyObjectFallback_` in `function.pxi`, removing the now-redundant manual try/except wrapper.
- Fix `make_tensor_from_chandle` in `tensor.pxi`: change variable type from `cdef Tensor tensor` to `cdef object tensor` and cast from `<Tensor>` to `<object>`, since DLPack conversion can return non-Tensor Python objects (e.g., torch tensors).

## Key Exports
None (internal Cython fix, no public API changes)

## Impact
- API: none
- Behavioral: DLPack callback errors that previously were silently swallowed (due to `noexcept` suppressing exception checks) now correctly propagate as Python exceptions. `TorchDLPackToPyObjectFallback_` exceptions are no longer caught and converted to silent -1 returns. `make_tensor_from_chandle` no longer raises `TypeError` when receiving a non-Tensor object from DLPack conversion.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
**Before/after: Cython exception annotation on DLPack callback typedefs**
```cython
# BEFORE (incorrect): noexcept suppresses Python exception checking
ctypedef int (*DLPackManagedTensorFromPyObjectNoSync)(
    void* py_object,
    DLManagedTensorVersioned** out
) noexcept  # Cython won't check for exceptions on -1 return

# AFTER (correct): except -1 enables automatic exception propagation
ctypedef int (*DLPackManagedTensorFromPyObjectNoSync)(
    void* py_object,
    DLManagedTensorVersioned** out
) except -1  # Cython checks for Python exception when return == -1
```

**Before/after: TorchDLPackToPyObjectFallback_ error handling**
```cython
# BEFORE: manual try/except needed because noexcept hides errors
cdef int TorchDLPackToPyObjectFallback_(...) noexcept:
    try:
        tensor = make_tensor_from_chandle(temp_chandle)
        torch_tensor = torch.from_dlpack(tensor)
        ...
        return 0
    except Exception:
        return -1

# AFTER: except -1 lets Cython propagate exceptions automatically
cdef int TorchDLPackToPyObjectFallback_(...) except -1:
    tensor = make_tensor_from_chandle(temp_chandle)
    torch_tensor = torch.from_dlpack(tensor)
    ...
    return 0
```
