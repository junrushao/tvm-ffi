# Reorganize Python API reference docs and clean up __all__ exports
## TL;DR
- Restructured `docs/reference/python/index.rst`: added TOC, new "Global Registry" and "Misc" sections, promoted previously-unlisted APIs (`DLDeviceType`, `device`, `dtype`, `get_global_func_metadata`, `remove_global_func`, `serialization`, `access_path`, `ObjectConvertible`).
- Enabled Sphinx `autosummary_generate` and added `autosummary_filename_map` to disambiguate `tvm_ffi.device` (function) from `tvm_ffi.Device` (class).
- Cleaned up `python/tvm_ffi/__init__.py` `__all__`: removed duplicate entries (`Device`, `Object`), added missing stream-related exports (`StreamContext`, `get_raw_stream`, `use_raw_stream`, `use_torch_stream`).
