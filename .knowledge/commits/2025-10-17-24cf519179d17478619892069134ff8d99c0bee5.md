# Reorganize Python API docs and fix __all__ exports
## TL;DR
- Reorganizes `docs/reference/python/index.rst` into clearer sections: Object, Tensor, Function, Module, Containers, Global Registry, Stream Context, Inline Loading, and Misc. Adds previously undocumented APIs (`DLDeviceType`, `device`, `dtype`, `get_global_func_metadata`, `remove_global_func`, `serialization`, `access_path`, `ObjectConvertible`).
- Fixes `__all__` in `python/tvm_ffi/__init__.py`: removes duplicate entries (`Device`, `Object`), adds missing exports (`StreamContext`, `get_raw_stream`, `use_raw_stream`, `use_torch_stream`).
- Enables `autosummary_generate` in Sphinx config with filename mapping to avoid clashes between `tvm_ffi.device` (function) and `tvm_ffi.Device` (class).
