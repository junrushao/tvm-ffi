# Reorganize Python API reference docs and clean up __all__ exports
## TL;DR
- Reorganized `docs/reference/python/index.rst` into a cleaner hierarchy: Object (with Tensor/Function/Module/Containers subsections), Global Registry, Stream Context, Inline Loading, and Misc.
- Added previously-undocumented APIs to the reference page: `get_global_func_metadata`, `remove_global_func`, `serialization`, `access_path`, `ObjectConvertible`, `DLDeviceType`, `device`, `dtype`, `from_dlpack`.
- Fixed `python/tvm_ffi/__init__.py` `__all__`: removed duplicate `Device`/`Object` entries, added missing `StreamContext`, `get_raw_stream`, `use_raw_stream`, `use_torch_stream`.

## Impact
- API: `__all__` now includes `StreamContext`, `get_raw_stream`, `use_raw_stream`, `use_torch_stream` -- these were importable before but not listed in `__all__`, so tools relying on `__all__` (tab-completion, `from tvm_ffi import *`) now expose them.
- Behavioral: none
- Flags/config: `autosummary_generate = True` added to Sphinx config; `autosummary_filename_map` added to resolve `tvm_ffi.device` (function) vs `tvm_ffi.Device` (class) stub filename collision.
