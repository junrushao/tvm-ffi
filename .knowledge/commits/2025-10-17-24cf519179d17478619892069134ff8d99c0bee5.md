# Reorganize Python API reference docs and fix __all__ exports

## TL;DR
- Reorganized `docs/reference/python/index.rst` into a clearer hierarchy: Object > Tensor/Function/Module/Containers (subsections), plus new top-level sections for Global Registry, Misc, and a renamed "Inline Loading" section.
- Added previously undocumented APIs to the Sphinx autosummary (`DLDeviceType`, `device`, `dtype`, `get_global_func_metadata`, `remove_global_func`, `serialization`, `access_path`, `ObjectConvertible`).
- Fixed `python/tvm_ffi/__init__.py` `__all__`: removed duplicate entries (`Device`, `Object`), added missing exports (`StreamContext`, `get_raw_stream`, `use_raw_stream`, `use_torch_stream`).

## Key Exports

N/A -- documentation artifacts. No new code APIs produced.

## Impact
- API: `__all__` now correctly exports `StreamContext`, `get_raw_stream`, `use_raw_stream`, `use_torch_stream`. Previously these were importable but not listed in `__all__`, so `from tvm_ffi import *` would miss them. Duplicate `Device` and `Object` entries removed (no behavioral change).
- Behavioral: None -- no logic changes.
- Flags/config: `autosummary_generate = True` enabled in Sphinx conf, and `autosummary_filename_map` added to disambiguate `tvm_ffi.device` (function) from `tvm_ffi.Device` (class) in generated stub filenames.
- Data formats/schemas: None.
