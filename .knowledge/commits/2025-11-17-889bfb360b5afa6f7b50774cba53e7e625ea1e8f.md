# Use perfect forwarding for template types in FunctionObjImpl
## TL;DR
- Refactors `FunctionObjImpl<TCallable>` to use separate lvalue/rvalue constructors instead of copy-and-move, enabling perfect forwarding for callable types.
- Adds `static_assert` ensuring `TCallable` is not const or reference type.
- Uses `std::forward` in `Function::FromPacked` and related factory methods.

## Key Exports

**Classes (C++):**
- `FunctionObjImpl<TCallable>` -- Now has two constructors: `FunctionObjImpl(TCallable&&)` for rvalue and `FunctionObjImpl(const TCallable&)` for lvalue. `TStorage` typedef removed; uses `TCallable` directly for `callable_` member.

## Impact
- API: none (internal template change)
- ABI: none
- Behavioral: Avoids unnecessary copy/move construction when creating `Function` objects from callables.
- Flags/config: none
