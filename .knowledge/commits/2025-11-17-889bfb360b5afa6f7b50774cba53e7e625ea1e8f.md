# Use perfect forwarding for template types in function dispatch
## TL;DR
- Replaces copy-and-move patterns with perfect forwarding (`std::forward`) for template parameters in the function dispatch chain (`function.h`).
- Cheap-to-copy types (e.g., `Function`, `std::string`) retain copy-and-move; template types use forwarding references to avoid unnecessary copies during the dispatch chain.

## Key Exports

```python
# No new API. Internal change to forwarding semantics in:
# - unpack_call<> template: args now forwarded via universal references
# - FuncFunctorImpl: uses std::forward<Args> instead of copy
# Interacts with: Function::FromTyped, typed function wrapping, AnyView conversion
# Invariant: observable behavior unchanged; only eliminates redundant copies
```

## Impact
- API: none — no signature changes
- Behavioral: potential minor performance improvement by avoiding unnecessary copies in the function dispatch chain
- Flags/config: none
- Data formats/schemas: none
