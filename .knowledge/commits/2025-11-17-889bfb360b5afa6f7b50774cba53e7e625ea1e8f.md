# Use perfect forwarding for template callable types in function.h
## TL;DR
- Converts all callable-accepting templates in `Function`, `FunctionObjImpl`, and `TypedFunction` from copy-and-move to perfect forwarding (`T&&` + `std::forward<T>`), eliminating unnecessary copy/move constructions in the forwarding chain.
- Adds `static_assert` to `FunctionObjImpl` enforcing that `TCallable` is never a const or reference type, removing the `TStorage` alias.
- Adds SFINAE guards (`!is_same_v<decay_t<T>, Self>`) to `Function` constructor and `TypedFunction` constructors/assignment to prevent greedy template matches against copy/move operations.

## Impact
- API: None -- all changes are to template parameter passing conventions. No new/removed public symbols. Source-compatible for all callers.
- Behavioral: Lvalue callables are now copied (rather than copied then moved). Rvalue callables are now moved directly (rather than copied then moved). Net effect: fewer intermediate copy/move operations.
- Flags/config: None
- Data formats/schemas: None

## Usage Examples
Before (unnecessary copy):
```cpp
auto lambda = [state = heavy_object](...) { ... };
// Old: lambda copied into by-value parameter, then moved into storage = 1 copy + 1 move
Function f = Function::FromTyped(lambda);
```

After (perfect forwarding):
```cpp
auto lambda = [state = heavy_object](...) { ... };
// New (lvalue): lambda copied directly into storage = 1 copy
Function f = Function::FromTyped(lambda);
// New (rvalue): lambda moved directly into storage = 1 move
Function g = Function::FromTyped(std::move(lambda));
```
