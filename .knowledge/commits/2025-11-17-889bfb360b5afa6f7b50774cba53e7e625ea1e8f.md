# Use perfect forwarding in `FunctionObjImpl` and `Function` factory methods

## TL;DR
- `FunctionObjImpl<TCallable>` now takes `TCallable&&` (rvalue) or `const TCallable&` (lvalue) in separate constructors, and removes the `TStorage = remove_cv_t<remove_reference_t<TCallable>>` alias (now enforced via `static_assert` instead).
- `Function::FromPacked`, `Function::FromTyped`, and `Function(TCallable&&)` constructor all gain `std::forward<TCallable>` to avoid copying movable callables.
- `Function(TCallable&&)` gains an `enable_if` guard to prevent it from shadowing the copy constructor when `TCallable` decays to `Function`.

## Key Exports

```python
# include/tvm/ffi/function.h

class FunctionObjImpl(TCallable):  # TCallable must not be cv-qualified or reference
    """
    Heap object backing a packed function.
    Invariant: TCallable is always stored by value (never reference or pointer).
    """
    # static_assert: TCallable == remove_cv_t<remove_reference_t<TCallable>>
    def __init__(self, callable: TCallable) -> None: ...  # rvalue overload
    def __init__(self, callable: TCallable) -> None: ...  # const lvalue overload
    # Interacts with: FunctionObj.safe_call, FunctionObj.cpp_call

class Function(ObjectRef):
    def __init__(self, packed_call: TCallable) -> None: ...
    # enable_if: decay_t<TCallable> != Function  (prevents shadowing copy ctor)
    # Interacts with: FromPacked(std::forward<TCallable>(...))

    @staticmethod
    def FromPacked(packed_call: TCallable) -> Function: ...
    # CHANGED: parameter is now TCallable&& (was TCallable by value)
    # Captures callable via std::forward in lambda

    @staticmethod
    def FromTyped(callable: TCallable) -> Function: ...
    # CHANGED: parameter is now TCallable&& (was TCallable by value)
    # Uses FunctionInfo<std::decay_t<TCallable>> (not TCallable directly)
    # Captures callable via std::forward; comment: "always captured by value to avoid dangling ref"

    @staticmethod
    def FromTyped(callable: TCallable, name: str) -> Function: ...
    # CHANGED: same perfect-forwarding pattern
```

## Impact
- API: Source-compatible — call sites do not need to change. ABI-compatible — `FunctionObjImpl` layout is unchanged (single `callable_` field, was `TStorage`, now `TCallable` — same type due to the new `static_assert`).
- Behavioral: Move-only callables (e.g., lambdas capturing `unique_ptr`) can now be wrapped in `Function` without a copy. Previously they would fail to compile or silently copy.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `0004-function-system`: `FunctionObjImpl`, `Function::FromPacked`, `Function::FromTyped` — the packed-function factory pattern.

Design elements this commit produces:
- **Perfect-forwarding contract for `Function` factories**: establishes that `FromPacked`, `FromTyped`, and the `Function(TCallable&&)` constructor forward callable arguments rather than copy. This is now an invariant callers can rely on for move-only types.

## Usage Examples

```cpp
// Before: move-only callable silently copied (or failed to compile)
auto fn = Function::FromTyped(std::move(my_unique_closure));

// After: correctly forwarded, no copy
auto fn = Function::FromTyped(std::move(my_unique_closure));  // same call, now works for move-only
```
