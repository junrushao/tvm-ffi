# Use perfect forwarding for template callable types in Function construction
## TL;DR
- Replaces copy-and-move parameter passing with perfect forwarding (`TCallable&&` + `std::forward`) across `FunctionObjImpl`, `Function::FromPacked`, `Function::FromTyped`, `Function::FromPackedInternal`, and `TypedFunction` constructors/assignment operators.
- Adds SFINAE guards (`!is_same_v<decay_t<TCallable>, Function>` / `!is_same_v<decay_t<FLambda>, TSelf>`) to prevent forwarding-reference constructors from hijacking copy/move operations.
- Adds `static_assert` on `FunctionObjImpl<TCallable>` enforcing TCallable is never a const or reference type; removes the now-redundant `TStorage` alias.

## Key Exports

```python
# --- FunctionObjImpl constructor contract change ---
# Old: FunctionObjImpl(TCallable callable)  -- by value, then move
# New: two overloads for optimal forwarding
class FunctionObjImpl(Generic[TCallable], FunctionObj):
    """Wraps a C++ callable into FunctionObj. TCallable must be a bare value type."""
    callable_: TCallable  # was TStorage (remove_cv_t<remove_reference_t<TCallable>>)
    # Invariant: static_assert(is_same_v<TCallable, remove_cv_t<remove_reference_t<TCallable>>>)
    # Interacts with: Function.FromPackedInternal (creates FunctionObjImpl via make_object)

    def __init__(self, callable: TCallable) -> None:
        # Overload 1: TCallable&& (rvalue) -> move into callable_
        # Overload 2: const TCallable& (lvalue) -> copy into callable_
        ...

# --- Function construction paths: value -> forwarding reference ---

# Old: Function(TCallable packed_call)  -- by value
# New: Function(TCallable&& packed_call, enable_if<!is_same_v<decay_t<TCallable>, Function>>)
class Function(ObjectRef):
    @staticmethod
    def FromPacked(callable: TCallable) -> Function:
        """Old: TCallable by value. New: TCallable&& with std::forward."""
        # Interacts with: FromPackedInternal (forwarded), lambda capture (forwarded)

    @staticmethod
    def FromTyped(callable: TCallable) -> Function:
        """Old: TCallable by value + std::move. New: TCallable&& with std::forward."""
        # Uses FunctionInfo<decay_t<TCallable>> (was FunctionInfo<TCallable>)
        # Interacts with: details::unpack_call, FunctionInfo

    @staticmethod
    def FromTyped(callable: TCallable, name: str) -> Function:
        """Named variant. Same forwarding change."""
        # Interacts with: details::unpack_call, FunctionInfo

    @staticmethod
    def FromPackedInternal(callable: TCallable) -> Function:
        """Old: TCallable by value. New: TCallable&& with forward + decay_t for ObjType."""
        # ObjType = FunctionObjImpl<decay_t<TCallable>>  (was FunctionObjImpl<TCallable>)
        # Interacts with: make_object, FunctionObjImpl

# --- TypedFunction forwarding changes ---
class TypedFunction(Generic[R, Args]):
    packed_: Function

    def __init__(self, packed: Function) -> None:
        # Now uses std::move(packed) instead of copy
        ...

    def __init__(self, typed_lambda: FLambda, name: str) -> None:
        """Old: FLambda by value. New: FLambda&& with forward."""
        # SFINAE: enable_if<is_convertible<FLambda, function<R(Args...)>>>
        # Interacts with: Function.FromTyped

    def __init__(self, typed_lambda: FLambda) -> None:
        """Old: const FLambda&. New: FLambda&& with forward."""
        # SFINAE: added !is_same_v<decay_t<FLambda>, TSelf> guard
        # Interacts with: Function.FromTyped

    def __assign__(self, typed_lambda: FLambda) -> TSelf:
        """Old: FLambda by value. New: FLambda&& with forward."""
        # SFINAE: added !is_same_v<decay_t<FLambda>, TSelf> guard
        # Interacts with: Function.FromTyped
```

## Impact
- API: None -- source-compatible. Forwarding references preserve existing call-site semantics (lvalues copy, rvalues move).
- Behavioral: Reduces unnecessary copy+move operations when constructing functions from rvalue callables. Lvalue callables now avoid a redundant move (forwarded as lvalue reference directly to `FunctionObjImpl` copy constructor).
- Flags/config: None
- Data formats/schemas: None

Design elements this commit produces/mutates:
- **`FunctionObjImpl<TCallable>` constructor**: Now dual-overload (rvalue/lvalue) instead of by-value. `TStorage` alias removed; `callable_` is `TCallable` directly. `static_assert` enforces TCallable is a bare value type.
- **`Function` template constructor**: Added SFINAE guard to prevent hijacking copy/move.
- **`Function::FromPacked/FromTyped/FromPackedInternal`**: Forwarding reference parameter with `std::decay_t<TCallable>` for type introspection.
- **`TypedFunction` constructors/assignment**: Forwarding reference with SFINAE self-type exclusion guard.

## Usage Examples
Before (copy-and-move pattern):
```cpp
// Callable copied into Function(TCallable), then moved into FunctionObjImpl
auto lambda = [](const AnyView* a, int32_t n, Any* r) { /*...*/ };
Function f(lambda);  // lambda copied into constructor param, then moved into callable_
```

After (perfect forwarding):
```cpp
// Lvalue: forwarded as lvalue ref, copied once into FunctionObjImpl
auto lambda = [](const AnyView* a, int32_t n, Any* r) { /*...*/ };
Function f(lambda);  // lambda copied once (no intermediate move)

// Rvalue: forwarded as rvalue ref, moved once into FunctionObjImpl
Function g([](const AnyView* a, int32_t n, Any* r) { /*...*/ });  // moved once (no copy)
```
