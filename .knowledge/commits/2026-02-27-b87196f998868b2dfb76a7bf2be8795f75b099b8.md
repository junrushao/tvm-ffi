# Expose RecursiveEq/Lt/Le/Gt/Ge to Python with comprehensive tests

## TL;DR
- `_ffi_api.py` gains typed stubs for `RecursiveEq`, `RecursiveLt`, `RecursiveLe`, `RecursiveGt`, `RecursiveGe` (plus `GetKwargsObject` and `MakeInit` from stub regeneration). These delegate to already-registered C++ globals in the runtime.
- `tvm_ffi.testing` gains three new `@register_object` test dataclasses: `TestCompare` (field with `Compare(false)` opt-out), `TestCustomCompare` (custom `__ffi_eq__`/`__ffi_compare__` hooks comparing only `key`), `TestEqWithoutHash` (eq hook without hash — exercises hash-guard fallback to reflection for ordering).
- `tests/python/test_dataclass_compare.py` (1272 lines, 101 test cases) provides end-to-end coverage of recursive structural comparison from Python across primitives, containers, reflected objects, cycles, and ordering laws.

## Usage Examples

End-to-end trace from Python using the new stubs:

```python
from tvm_ffi._ffi_api import RecursiveEq, RecursiveLt, RecursiveGe
from tvm_ffi.testing import TestCompare, TestCustomCompare, TestEqWithoutHash
import tvm_ffi

# Compare(false) opt-out — ignored_field does not affect ordering
a = TestCompare(key=1, name="x", ignored_field=99)
b = TestCompare(key=1, name="x", ignored_field=0)
assert RecursiveEq(a, b)   # True: ignored_field excluded from comparison

# Custom __ffi_eq__ hook: only key matters
c = TestCustomCompare(key=5, label="foo")
d = TestCustomCompare(key=5, label="bar")
assert RecursiveEq(c, d)   # True: labels differ but keys match

# Hash-guard path: eq without hash falls back to reflection for ordering
e = TestEqWithoutHash(key=3, label="p")
f = TestEqWithoutHash(key=4, label="q")
assert RecursiveLt(e, f)   # True: field reflection fallback on key=3 < key=4

# Container comparison
a_list = tvm_ffi.Array([1, 2, 3])
b_list = tvm_ffi.Array([1, 2, 4])
assert RecursiveLt(a_list, b_list)  # lexicographic: 3 < 4 at index 2

# Cycle detection (equality returns True via on-stack pair memoization)
lst = tvm_ffi.List([1, 2])
lst.append(lst)  # self-referential
assert RecursiveEq(lst, lst)  # same pointer — identity fast-path → True
```
