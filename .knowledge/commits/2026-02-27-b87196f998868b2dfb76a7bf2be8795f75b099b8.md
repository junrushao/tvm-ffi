# Expose recursive compare APIs to Python with comprehensive tests and testing dataclasses

## TL;DR
- Adds Python-side typed stubs for `RecursiveEq`, `RecursiveLt/Le/Gt/Ge`, `GetKwargsObject`, and `MakeInit` in `_ffi_api.py`.
- Introduces three new testing dataclasses: `TestCompare` (field-level `CompareOff`), `TestCustomCompare` (custom `__ffi_eq__`/`__ffi_compare__`), `TestEqWithoutHash` (equality without hash).
- Adds 1272-line `test_dataclass_compare.py` with 101 test cases covering primitives, containers, cycles, ordering laws, and custom hooks.

## Usage Examples

```python
from tvm_ffi import _ffi_api
# Structural equality
assert _ffi_api.RecursiveEq(obj_a, obj_b)
# Ordering
assert _ffi_api.RecursiveLt(smaller, larger)
# CompareOff field exclusion
a = tvm_ffi.testing.create_object("testing.TestCompare", key=1, name="x", ignored_field=100)

```
