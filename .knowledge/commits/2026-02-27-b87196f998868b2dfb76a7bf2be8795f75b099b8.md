# Expose RecursiveEq/Lt/Le/Gt/Ge to Python with comprehensive structural compare tests

## TL;DR
- Exposes C++ `RecursiveEq`, `RecursiveLt`, `RecursiveLe`, `RecursiveGt`, `RecursiveGe` to Python via `_ffi_api` typed stubs.
- Adds `TestCompare`, `TestCustomCompare`, `TestEqWithoutHash` testing dataclasses with custom hook coverage.
- 101 test cases covering primitives, containers, cycles, ordering laws, and inheritance.

## Key Exports

```python
# python/tvm_ffi/_ffi_api.py (stubs added)
def RecursiveEq(lhs: Any, rhs: Any) -> bool: ...
def RecursiveLt(lhs: Any, rhs: Any) -> bool: ...
def RecursiveLe(lhs: Any, rhs: Any) -> bool: ...
def RecursiveGt(lhs: Any, rhs: Any) -> bool: ...
def RecursiveGe(lhs: Any, rhs: Any) -> bool: ...
def GetKwargsObject() -> Object: ...
def MakeInit(type_key: str) -> Function: ...

# python/tvm_ffi/testing
class TestCompare(Object):
    """Two int fields; second has Compare(false) — excluded from compare."""
class TestCustomCompare(Object):
    """Custom __ffi_eq__/__ffi_compare__ hooks comparing only 'key' field."""
class TestEqWithoutHash(Object):
    """Equality-only hook; ordering falls back to reflection."""
# Interacts with: RecursiveEq/Lt, TVMFFIFieldFlagBitMaskCompareOff
```

## Impact
- API: Additive only. New `_ffi_api` stubs for Python callers.
- Behavioral: none (C++ functions pre-registered; Python surface only).
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
from tvm_ffi._ffi_api import RecursiveEq, RecursiveLt

a = tvm_ffi.testing.TestIntPair(1, 2)
b = tvm_ffi.testing.TestIntPair(1, 3)
assert RecursiveLt(a, b)  # 2 < 3 field-by-field
assert RecursiveEq(a, a)  # identity
```
