# Specialize Variant storage to ObjectRef when all type arguments are ObjectRef subtypes
## TL;DR
- When all `Variant<V...>` type arguments derive from `ObjectRef`, the backing storage is now `ObjectRef` (8 bytes) instead of `Any` (16 bytes), halving memory footprint and enabling native `ObjectPtrHash`/`ObjectPtrEqual`.
- Introduces `VariantBase<true>` (ObjectRef-backed) and `VariantBase<false>` (Any-backed) base classes selected at compile time via `all_object_ref_v<V...>`.
- Adds `AnyUnsafe::MoveFromAnyStorageAfterCheck<T>` template and hardens `TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY` macro with parenthesized arguments.

## Impact
- API: None -- public Variant<V...> API unchanged; new `same_as` method added but is additive.
- Behavioral: `Variant<ObjectRef-types...>` now has `sizeof(ObjectRef)` instead of `sizeof(Any)` (8 vs 16 bytes). It now inherits from `ObjectRef`, enabling use in contexts that require ObjectRef (hash maps, Any storage as object).
- Flags/config: None.
- Data formats/schemas: None.

- **Container details** (`0006-containers`): `storage_enabled_v`, `all_storage_enabled_v` -- existing traits used alongside new `all_object_ref_v`.

Design elements this commit produces:
- **`all_object_ref_v<V...>`** -- compile-time trait checking if all types derive from ObjectRef. Used by Variant template selection.
- **`VariantBase<bool>`** -- two-branch base class: `VariantBase<false>` (Any-backed, default) and `VariantBase<true>` (ObjectRef-backed, specialized). Provides unified internal API (`SetData`, `MoveToAny`, `ToAnyView`).
- **`AnyUnsafe::MoveFromAnyStorageAfterCheck<T>`** -- template helper that dispatches to `TypeTraits<T>::MoveFromAnyStorageAfterCheck` or identity-moves for `T=Any`.

## Usage Examples
**Context**: Using `Variant<TInt, Array<TInt>>` where all types are ObjectRef -- now ObjectRef-backed.
```cpp
// All-ObjectRef Variant is now sizeof(ObjectRef) and IS-A ObjectRef
Variant<TInt, Array<TInt>> v0 = TInt(1);
static_assert(std::is_base_of_v<ObjectRef, decltype(v0)>);  // True!
EXPECT_EQ(sizeof(v0), sizeof(ObjectRef));  // 8 bytes, not 16

// Round-trip through Any works transparently
Any any0 = v0;
auto v2 = any0.cast<Variant<TInt, Array<TInt>>>();
EXPECT_TRUE(v0.same_as(v2));

// Assignment between variant alternatives
v0 = Array<TInt>({TInt(2), TInt(3)});
EXPECT_EQ(v0.get<Array<TInt>>().size(), 2);
```

**Context**: POD-containing Variant still uses Any backing and supports `same_as`.
```cpp
// Mixed POD + ObjectRef Variant: Any-backed (not ObjectRef)
Variant<String, int> v0 = 1;
Variant<String, int> v1 = 1;
EXPECT_TRUE(v0.same_as(v1));   // value comparison for POD

String s = String("hello");
v0 = s; v1 = s;
EXPECT_TRUE(v0.same_as(v1));   // identity comparison for ObjectRef
v1 = String("hello");          // different object, same value
EXPECT_FALSE(v0.same_as(v1));  // same_as checks identity, not equality
```
