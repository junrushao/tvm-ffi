# Specialize Variant storage to ObjectRef when all template parameters are ObjectRef subclasses

## TL;DR

- Introduces `details::VariantBase<bool all_storage_object>` as a policy base for `Variant<T...>`. When all `T` are `ObjectRef` subclasses (`all_object_ref_v<T...> == true`), the specialization `VariantBase<true>` inherits from `ObjectRef` directly — reducing `sizeof(Variant)` to `sizeof(ObjectRef)` and eliminating the `Any` wrapper overhead.
- Adds the compile-time trait `details::all_object_ref_v<T...>` (fold over `std::is_base_of_v<ObjectRef, T>`) in `container_details.h` and a new `AnyUnsafe::MoveFromAnyStorageAfterCheck<T>` utility in `any.h`.
- `Variant` public API is unchanged; the backing storage difference is transparent to callers, confirmed by tests checking `std::is_base_of_v<ObjectRef, decltype(v)>` and `sizeof(v) == sizeof(ObjectRef)`.

## Key Exports

```python
# --- include/tvm/ffi/container/container_details.h ---

# New compile-time trait
all_object_ref_v: bool  # = (std::is_base_of_v<ObjectRef, T> && ...) for all T in pack
# Interacts with: VariantBase<all_object_ref_v<V...>> (storage policy selector)
# Invariant: evaluated at compile-time only; no runtime footprint

# --- include/tvm/ffi/container/variant.h (details namespace) ---

class VariantBase:
    """Policy base class for Variant. Parameterized on whether all types are ObjectRef.

    Primary template (all_storage_object=False): backed by Any.
    Specialization (all_storage_object=True): inherits from ObjectRef.
    """
    # Primary template (default storage — Any-backed):
    def same_as(self, other: VariantBase) -> bool: ...
    # protected:
    def SetData(self, other: Any) -> None: ...   # writes to data_ (Any)
    def MoveToAny(self) -> Any: ...              # moves data_ out
    def ToAnyView(self) -> AnyView: ...          # casts data_ to AnyView
    data_: Any  # internal storage

    # Specialization (all_storage_object=True — ObjectRef-backed):
    # Inherits from ObjectRef instead of holding Any
    # SetData takes ObjectPtr<Object> (not Any)
    # MoveToAny wraps the ObjectRef data_ into Any(ObjectRef(std::move(data_)))
    # ToAnyView manually builds TVMFFIAny from data_->type_index() + data_.v_obj
    #   (handles nullptr by emitting kTVMFFINone)
    # Invariant: sizeof(VariantBase<true>) == sizeof(ObjectRef)
    # Interacts with: AnyUnsafe::MoveFromAnyStorageAfterCheck (constructor from Any)


class Variant(Generic[*V]):
    """Compile-time type-union. Public API unchanged.

    Backing storage selects VariantBase<all_object_ref_v<V...>>.
    When all V are ObjectRef subclasses: Variant IS-A ObjectRef (direct base).
    When any V is not ObjectRef: Variant HAS-A Any.
    """
    # Invariant: all_object_ref_v<V...> determines both base class and sizeof
    # Invariant: sizeof(Variant<ObjectRefs...>) == sizeof(ObjectRef) (tested)
    # Invariant: TypeTraits<Variant<V...>>::CopyToAnyView / MoveToAny delegate to TParent
    # Extension: adding new ObjectRef subtype to V... preserves ObjectRef-backed storage
    # Interacts with: TypeTraits<Variant<V...>> (CopyToAnyView, MoveToAny)
    # Interacts with: ObjectPtrHash / ObjectPtrEqual via data_.get() (object identity)

    def get(self, T: type) -> T: ...          # const& overload: ToAnyView().cast<T>()
    def get_rvalue(self, T: type) -> T: ...   # && overload: MoveToAny().cast<T>()
    def as(self, T: type) -> Optional[T]: ... # ToAnyView().as<T>()
    def same_as(self, other: Variant) -> bool: ...  # delegates to VariantBase
    def GetTypeKey(self) -> str: ...          # ToAnyView().GetTypeKey()


# --- include/tvm/ffi/any.h (AnyUnsafe) ---

class AnyUnsafe:
    # New helper:
    @staticmethod
    def MoveFromAnyStorageAfterCheck(ref: Any, T: type) -> T:
        """Move T out of Any without extra copy. If T is Any, return std::move(ref).
        Otherwise delegates to TypeTraits<T>::MoveFromAnyStorageAfterCheck(&ref.data_).
        """
        # Invariant: caller guarantees type is correct (no further check)
        # Interacts with: TypeTraits<T>::MoveFromAnyStorageAfterCheck (for T != Any)
        # Used by: VariantBase<true>.__init__ (constructing from Any argument)
```

## Impact

- API: None — `Variant<T...>` public surface (construction, `get<T>()`, `as<T>()`, `same_as`, `GetTypeKey`) is unchanged.
- Behavioral: When all types in `Variant<T...>` are `ObjectRef` subclasses, `same_as()` now uses `ObjectRef`-identity semantics (pointer equality) instead of `Any::same_as` (which also does pointer equality for objects, so observable behavior is the same). The `PODSameAs` test confirms same-value POD integers are `same_as` each other.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **0007-containers / Variant** (`include/tvm/ffi/container/variant.h`): extends the existing Variant design with a two-storage-strategy dispatch. The public API contract is preserved.
- **0003-any-anyview / AnyView, Any** (`include/tvm/ffi/any.h`): `ToAnyView()` in `VariantBase<true>` manually constructs a `TVMFFIAny`, consuming the AnyView layout contract (type_index, v_obj, padding clearing via `TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY`). `AnyUnsafe::MoveFromAnyStorageAfterCheck` consumes `AnyUnsafe`.
- **0002-object-system / ObjectRef** (`include/tvm/ffi/object.h`): `VariantBase<true>` inherits from `ObjectRef`, consuming the `ObjectRef` layout and ref-counting contract.
- **0001-c-abi / TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY** (`include/tvm/ffi/base_details.h`): the macro is used inside `VariantBase<true>::ToAnyView()`. The macro fix (parenthesizing `result` to support pointer-expression arguments) is also in this commit.
- **0008-type-traits / TypeTraits** (`include/tvm/ffi/type_traits.h`): `TypeTraits<Variant<V...>>::CopyToAnyView` / `MoveToAny` delegate to the new `ToAnyView()` / `MoveToAny()` methods.

Design elements this commit produces:
- **`details::VariantBase<bool>`** — new internal policy base class with a primary template (Any-backed) and a full specialization (ObjectRef-backed). Resides in `include/tvm/ffi/container/variant.h`.
- **`details::all_object_ref_v<T...>`** — new compile-time trait in `include/tvm/ffi/container/container_details.h`. Selects the storage policy.
- **`AnyUnsafe::MoveFromAnyStorageAfterCheck<T>`** — new utility method in `include/tvm/ffi/any.h`. Enables move-out from `Any` storage without an extra copy.
- **`TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY` macro fix** — parenthesizes `result` so the macro is safe when passed a pointer expression (e.g., `&any_data` dereference inside the specialization). Resides in `include/tvm/ffi/base_details.h`.

## Usage Examples

**Context**: Using `Variant<TInt, Array<TInt>>` where all types are `ObjectRef` — the variant becomes an `ObjectRef` subclass with `sizeof == sizeof(ObjectRef)`.

```cpp
// From tests/cpp/test_variant.cc (TEST(Variant, AllObjectRef))
Variant<TInt, Array<TInt>> v0 = TInt(1);

// Compile-time verification: Variant IS-A ObjectRef
static_assert(std::is_base_of_v<ObjectRef, decltype(v0)>);
// Size check: no Any wrapper overhead
// EXPECT_EQ(sizeof(v0), sizeof(ObjectRef));   // tested in the commit

// Pass through Any transparently — TypeTraits still handles it
Any any0 = v0;
EXPECT_EQ(any0.cast<TInt>()->value, 1);

// Roundtrip back to Variant
auto v2 = any0.cast<Variant<TInt, Array<TInt>>>();
EXPECT_TRUE(v0.same_as(v2));  // pointer identity

// Assignment — works via SetData(ObjectPtr<Object>)
v0 = Array<TInt>({TInt(2), TInt(3)});
EXPECT_EQ(v0.get<Array<TInt>>().size(), 2);
```

**Context**: `same_as` behavior for POD-containing Variant (Any-backed path).

```cpp
// From tests/cpp/test_variant.cc (TEST(Variant, PODSameAs))
Variant<String, int> v0 = 1;
Variant<String, int> v1 = 1;
EXPECT_TRUE(v0.same_as(v1));   // same POD value → same_as true (Any::same_as)

String s = String("hello");
v0 = s; v1 = s;
EXPECT_TRUE(v0.same_as(v1));   // same object pointer → true
v1 = String("hello");           // different String object with same value
EXPECT_TRUE(!v0.same_as(v1));  // different pointers → false (identity, not equality)
```
