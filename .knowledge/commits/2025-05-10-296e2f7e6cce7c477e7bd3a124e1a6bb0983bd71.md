# Variant specialization: use ObjectRef storage when all types are ObjectRef
## TL;DR
- Introduces `VariantBase<true>` specialization so that `Variant<V...>` where every V is an `ObjectRef` subclass is backed by `ObjectRef` instead of `Any`, reducing `sizeof(Variant)` to `sizeof(ObjectRef)` (one pointer) and making `Variant` a proper `ObjectRef` subclass.
- The generic `VariantBase<false>` retains the original `Any`-backed storage for mixed POD/ObjectRef variants.
- Minor hardening: parenthesizes macro argument in `TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY` to prevent operator-precedence bugs.

## Impact
- API: `Variant<V...>` where all V derive from `ObjectRef` now IS-A `ObjectRef`. Code that previously stored `Variant` as a standalone value can now pass it anywhere an `ObjectRef` is accepted. `sizeof(Variant<ObjectRef types>)` shrinks from 16 bytes (Any) to 8 bytes (one pointer).
- Behavioral: `Variant::as()` and `Variant::get()` now go through `ToAnyView()` indirection rather than directly accessing `data_`. For the all-ObjectRef case, `ToAnyView()` reconstructs a `TVMFFIAny` from the `ObjectPtr`. For the generic case, it simply converts the internal `Any` to `AnyView`.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
From `tests/cpp/test_variant.cc`, the `AllObjectRef` test demonstrates the key behavioral change:

```cpp
// Variant<TInt, Array<TInt>> -- all types are ObjectRef, so sizeof == sizeof(ObjectRef)
Variant<TInt, Array<TInt>> v0 = TInt(1);
EXPECT_EQ(v0.get<TInt>()->value, 1);
static_assert(std::is_base_of_v<ObjectRef, decltype(v0)>);  // IS-A ObjectRef

// Round-trip through Any
Any any0 = v0;
EXPECT_EQ(any0.cast<TInt>()->value, 1);
auto v2 = any0.cast<Variant<TInt, Array<TInt>>>();
EXPECT_TRUE(v0.same_as(v2));

// Assignment to different variant member
v0 = Array<TInt>({TInt(2), TInt(3)});
EXPECT_EQ(v0.get<Array<TInt>>().size(), 2);

// Size guarantee
EXPECT_EQ(sizeof(v0), sizeof(ObjectRef));
```
