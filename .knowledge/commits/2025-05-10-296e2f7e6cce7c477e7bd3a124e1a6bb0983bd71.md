# Specialize Variant to inherit ObjectRef when all variant types are ObjectRef subtypes
## TL;DR
- Introduces a `VariantBase` class template with two specializations: `VariantBase<false>` (backed by `Any`, existing behavior) and `VariantBase<true>` (inherits from `ObjectRef`, new zero-overhead path).
- `Variant<V...>` now conditionally inherits from `ObjectRef` when all `V...` are `ObjectRef` subtypes, reducing storage from `sizeof(Any)` to `sizeof(ObjectRef)` (one pointer) and enabling direct use in `ObjectPtrHash`/`ObjectPtrEqual` and container APIs that expect `ObjectRef`.
- Adds `details::all_object_ref_v<T...>` compile-time trait and `AnyUnsafe::MoveFromAnyStorageAfterCheck<T>` helper; fixes macro parenthesization in `TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY`.

## Key Exports

**Trait (compile-time constant)**:

**Class template -- `details::VariantBase<bool>`**:
```cpp
// variant.h -- default (non-ObjectRef) path
template <bool all_storage_object = false>
class VariantBase {
public:
  bool same_as(const VariantBase&) const;
protected:
  explicit VariantBase(T other);
  void SetData(Any other_data);
  Any MoveToAny() &&;
  AnyView ToAnyView() const;
  Any data_;
};

// variant.h -- ObjectRef specialization
template <>
class VariantBase<true> : public ObjectRef {
protected:
  explicit VariantBase(const T& other);
  explicit VariantBase(T&& other);
  explicit VariantBase(ObjectPtr<Object> ptr);
  explicit VariantBase(Any other);
  void SetData(ObjectPtr<Object> other);
  Any MoveToAny() &&;
  AnyView ToAnyView() const;
  // Storage reuses ObjectRef::data_ (ObjectPtr<Object>)
};
```

```cpp
  // ... rest unchanged

```

**Helper function -- `AnyUnsafe::MoveFromAnyStorageAfterCheck<T>`**:
```cpp

```

**Macro fix -- `TVM_FFI_CLEAR_PTR_PADDING_IN_FFI_ANY`**: Wraps `result` in parentheses `(result)->` for safe macro expansion.

## Impact
- API: `Variant<V...>` where all `V...` are `ObjectRef` subtypes now **is-a** `ObjectRef`. This is a behavioral expansion -- callers that check `std::is_base_of_v<ObjectRef, Variant<A, B>>` will now get `true` when both A and B are ObjectRef subtypes. Existing code that only held `Variant` by value is unaffected.
- Behavioral: `sizeof(Variant<ObjectRefTypes...>)` shrinks from 16 bytes (`Any`) to 8 bytes (`ObjectPtr`). `GetObjectPtrForHashEqual` now accesses `this->data_.get()` (direct ObjectRef member) instead of reinterpreting `Any` storage.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (`ObjectRef`, `ObjectPtr<Object>`, `data_` member) -- [.knowledge/designs/0003-object-system.md] -- the `VariantBase<true>` specialization inherits from `ObjectRef` and delegates storage to its `data_` field.
- **Any/AnyView value system** -- [.knowledge/designs/0002-any-value-system.md] -- the `VariantBase<false>` path continues to use `Any data_` as before; the `<true>` path converts to/from `Any` on demand via `MoveToAny()`/`ToAnyView()`.
- **TypeTraits protocol** -- [.knowledge/designs/0005-type-traits.md] -- `TypeTraits<Variant<V...>>` updated to delegate through `ToAnyView()`/`MoveToAny()` instead of directly accessing `data_`.
- **`AnyUnsafe` internal helpers** -- `ObjectPtrFromAnyAfterCheck`, `MoveAnyToTVMFFIAny`, `MoveTVMFFIAnyToAny`.
- **`ObjectUnsafe::TVMFFIObjectPtrFromObjectPtr`** -- used in `ToAnyView()` of the ObjectRef specialization to get raw pointer for AnyView construction.

Design elements this commit produces:
- **`details::all_object_ref_v<T...>`** -- new compile-time trait checking if all parameter pack types inherit from `ObjectRef`. Used as the `VariantBase` template argument.
- **`details::VariantBase<bool>`** -- CRTP-like base class hierarchy enabling `Variant` to switch storage strategy at compile time.
- **`AnyUnsafe::MoveFromAnyStorageAfterCheck<T>`** -- new extraction helper that moves a value out of `Any` storage after the caller has verified type compatibility.

## Usage Examples
**Context**: Creating a Variant where all types are ObjectRef subtypes. The variant inherits from ObjectRef, enabling direct use in ObjectRef-expecting APIs.
```cpp
// All-ObjectRef Variant: backed by ObjectRef, sizeof == sizeof(ObjectRef)
Variant<TInt, Array<TInt>> v0 = TInt(1);
static_assert(std::is_base_of_v<ObjectRef, decltype(v0)>);
EXPECT_EQ(sizeof(v0), sizeof(ObjectRef));

// Round-trip through Any
Any any0 = v0;
auto v2 = any0.cast<Variant<TInt, Array<TInt>>>();
EXPECT_TRUE(v0.same_as(v2));

// Assignment switches active type
v0 = Array<TInt>({TInt(2), TInt(3)});
EXPECT_EQ(v0.get<Array<TInt>>().size(), 2);
```

**Context**: POD-containing Variant retains Any-backed behavior with `same_as` support.
```cpp
// Mixed Variant (POD + ObjectRef): backed by Any
Variant<String, int> v0 = 1;
Variant<String, int> v1 = 1;
EXPECT_TRUE(v0.same_as(v1));   // bitwise equality on Any storage

String s = String("hello");
v0 = s;
v1 = s;
EXPECT_TRUE(v0.same_as(v1));   // same ObjectRef pointer
v1 = String("hello");
EXPECT_FALSE(v0.same_as(v1));  // different objects
```
