# Fix use-after-free in STL test by scoping temp variables in a sub-function
## TL;DR
- Replaces the `gc.collect(); del mod` workaround from commit 4076ef5 with a cleaner pattern: moves all test assertions into a `run_check(mod)` sub-function so that temporary Python objects (which may hold deleters from the loaded library) are deallocated when the sub-function returns, before the module is unloaded.
- Changes `== None` to `is None` (style fix).
