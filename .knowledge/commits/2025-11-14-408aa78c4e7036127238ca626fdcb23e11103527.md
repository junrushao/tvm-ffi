# Add dtype literal constants (bool, int8..int64, float16..float64, bfloat16, float8 types) to tvm_ffi._dtype

## TL;DR
- Adds 22 module-level `dtype` constant instances to `python/tvm_ffi/_dtype.py` and re-exports them via `python/tvm_ffi/__init__.py`.
- Covers: `bool`, `int8..int64`, `uint8..uint64`, `float16`, `float32`, `float64`, `bfloat16`, float8 variants, `float4_e2m1fnx2`.
- Adds `__dlpack_data_type__` method to dtype for round-trip protocol; updates `_convert.py`.

## Key Exports

```python
# python/tvm_ffi/_dtype.py (new module-level constants)
bool = dtype("bool")         # {kDLBool, bits=8}
int8 = dtype("int8")
int16 = dtype("int16")
int32 = dtype("int32")
int64 = dtype("int64")
uint8 = dtype("uint8")
uint16 = dtype("uint16")
uint32 = dtype("uint32")
uint64 = dtype("uint64")
float16 = dtype("float16")
float32 = dtype("float32")
float64 = dtype("float64")
bfloat16 = dtype("bfloat16")
float8_e4m3fn = dtype("float8_e4m3fn")
float8_e4m3fnuz = dtype("float8_e4m3fnuz")
float8_e5m2 = dtype("float8_e5m2")
float8_e5m2fnuz = dtype("float8_e5m2fnuz")
float8_e8m0fnu = dtype("float8_e8m0fnu")
float4_e2m1fnx2 = dtype("float4_e2m1fnx2")
float4_e2m1fn_x2 = float4_e2m1fnx2  # alias for torch naming

# All exported via tvm_ffi.__init__
# Invariant: follows numpy 2.0 convention (bool not bool_)
# Interacts with: dtype.__init__, DLDataType round-trip
```

## Impact
- API: New module-level constants in `tvm_ffi._dtype` and `tvm_ffi` namespace.
- Behavioral: `tvm_ffi.bool` shadows Python built-in `bool` within the `tvm_ffi` namespace — callers must be aware.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

## Usage Examples

```python
import tvm_ffi

# Before:
t = tvm_ffi.Tensor(shape=[3], dtype=tvm_ffi.dtype("float32"), device=...)

# Also useful in type annotations:
```
