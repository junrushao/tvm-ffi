# Add dtype literal constants to tvm_ffi namespace
## TL;DR
- Adds predefined dtype literal constants (`float16`, `float32`, `float64`, `int8`, `int16`, `int32`, `int64`, `uint8`, `bool`, `bfloat16`, `float8_e4m3fn`, `float8_e5m2`) to the `tvm_ffi` namespace.
- Updates `_convert.py` to handle `DataType` objects in the convert path.

## Key Exports

**Python Constants:**
- `tvm_ffi.float16`, `tvm_ffi.float32`, `tvm_ffi.float64` -- Float dtype literals.
- `tvm_ffi.int8`, `tvm_ffi.int16`, `tvm_ffi.int32`, `tvm_ffi.int64` -- Integer dtype literals.
- `tvm_ffi.uint8` -- Unsigned integer dtype literal.
- `tvm_ffi.bool` -- Boolean dtype literal.
- `tvm_ffi.bfloat16`, `tvm_ffi.float8_e4m3fn`, `tvm_ffi.float8_e5m2` -- Special float dtype literals.

## Impact
- API: New dtype literal constants in `tvm_ffi` module namespace.
- ABI: none
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```python
import tvm_ffi
print(tvm_ffi.float32)   # float32
```
