# Add dtype literal constants (tvm_ffi.float32, tvm_ffi.int8, etc.) to the public API
## TL;DR
- Defines 20 pre-built `dtype` literal constants in `_dtype.py` (bool, int8-64, uint8-64, float16/32/64, bfloat16, float8 variants, float4_e2m1fnx2) plus one alias (`float4_e2m1fn_x2`), and re-exports them from `tvm_ffi.__init__`.
- Updates `convert()` to treat `dtype` instances as atomic pass-through values (no wrapping into containers).
- Adds `test_builtin_dtype_conversion` verifying all 19 exported literals against their DLPack `(type_code, bits, lanes)` triples.

## Impact
- API: additive — 20 new public attributes on `tvm_ffi` module; no existing signatures changed.
- Behavioral: `convert()` now returns `dtype` instances as-is instead of falling through to the callable branch (which would have wrapped them as `Function`).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `dtype` class (`python/tvm_ffi/_dtype.py`) — the `str` subclass wrapping `core.DataType` / `DLDataType`. See `.knowledge/designs/0012-python-bindings.md` (dtype exchange protocol).
- `convert()` pass-through pattern (`python/tvm_ffi/_convert.py`) — the isinstance-guard chain that recognizes atomic FFI types.
- `DataTypeCode` enum (`python/tvm_ffi/_dtype.py`) — DLPack type codes used internally by `dtype.__new__`.
- numpy 2.0 naming convention (comment: "align with choice of numpy 2.0, which moved away from bool_ to bool").

Design elements this commit produces:
- **dtype literal constants** — 20 pre-instantiated `dtype` objects as module-level attributes, providing a numpy/torch-like `tvm_ffi.float32` access pattern. This is a new convenience convention for the package's public API.

## Usage Examples
```python
import tvm_ffi

# Direct access to dtype literals (no string construction needed)
assert tvm_ffi.float32 == "float32"
assert tvm_ffi.float32.bits == 32
assert tvm_ffi.float32.type_code == 2  # FLOAT

# Use in Tensor construction or FFI calls
tensor = tvm_ffi.Tensor.empty([2, 3], dtype=tvm_ffi.float16)

# convert() now passes dtype through unchanged
result = tvm_ffi.convert(tvm_ffi.bfloat16)
assert result is tvm_ffi.bfloat16  # no wrapping

# float8 variants for ML quantization
assert tvm_ffi.float8_e4m3fn.bits == 8
assert tvm_ffi.float4_e2m1fnx2.lanes == 2  # packed 4-bit type
assert tvm_ffi.float4_e2m1fn_x2 == tvm_ffi.float4_e2m1fnx2  # torch alias
```
