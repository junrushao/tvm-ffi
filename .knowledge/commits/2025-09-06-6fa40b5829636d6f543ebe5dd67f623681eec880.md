# Add Tensor.strides() accessor and modernize example signatures to ffi::Tensor

## TL;DR
- Adds `Tensor::strides()` method that lazily wraps the underlying `DLTensor::strides` pointer into an `ffi::Shape`, mirroring the existing `Tensor::shape()` pattern.
- Renames internal field `TensorObj::stride_data_` to `TensorObj::strides_data_` for naming consistency with the new accessor.
- Updates example code (`packaging`, `quick_start`) to accept `ffi::Tensor` instead of raw `DLTensor*`, demonstrating the preferred typed-ref calling convention.

## Key Exports

```python
class Tensor(ObjectRef):
    """Managed tensor wrapping DLTensor with ref-counted lifetime."""

    def strides(self) -> Shape:
        """Lazily wrap DLTensor::strides into an ffi::Shape.
        On first call, constructs Shape from raw int64_t* pointer and caches in strides_data_.
        Subsequent calls return the cached Shape."""
        ...
    # Invariant: strides pointer must be non-null (asserted via TVM_FFI_ICHECK)
    # Invariant: cached strides_data_ is consistent with DLTensor::strides
    # Interacts with: TensorObj::strides_data_ (lazy cache), Shape (return type)
    # Interacts with: Tensor::shape() (identical lazy-cache pattern)
    # Extension: mirrors shape() -- future accessors (e.g. device()) can follow the same pattern

class TensorObj(Object, DLTensor):
    """Internal storage. Protected field renamed for consistency."""
    shape_data_: Optional[Shape]     # lazy cache for shape()
    strides_data_: Optional[Shape]   # renamed from stride_data_; lazy cache for strides()
    # Invariant: strides_data_ is populated either at construction (FromNDAlloc, FromDLPack)
    #            or lazily on first Tensor::strides() call
```

## Impact
- API: Additive -- new public method `Tensor::strides()`. No existing API removed.
- Behavioral: Examples now accept `ffi::Tensor` (ref-counted) instead of `DLTensor*` (raw pointer). This is a signature change in example code only, not in the core library.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Object/ObjectRef pattern** (`TensorObj`/`Tensor`) -- uses `get_mutable()` for lazy field initialization through const ref.
- **Shape container** (`ffi::Shape`) -- used as return type for `strides()`, wrapping raw `int64_t*` into a ref-counted immutable shape. See [0007-containers.md](../designs/0007-containers.md).
- **Optional<Shape>** -- used for lazy caching (`strides_data_`), where `nullopt` signals "not yet materialized."
- **DLTensor ABI** -- `strides` field is a raw `int64_t*` from DLPack; this commit wraps it.
- **TVM_FFI_DLL_EXPORT_TYPED_FUNC** -- examples use typed function export, now with `ffi::Tensor` parameters instead of `DLTensor*`. See [0013-packaging.md](../designs/0013-packaging.md).

Design elements this commit produces:
- **`Tensor::strides()` accessor** -- new public API on `Tensor` for accessing strides as `Shape`.

## Usage Examples

**Context**: Accessing strides of a tensor in C++ (from `tests/cpp/test_tensor.cc`).

```cpp
Tensor nd = Empty(Shape({1, 2, 3}), DLDataType({kDLFloat, 32, 1}), DLDevice({kDLCPU, 0}));
Shape strides = nd.strides();
// strides[0] == 6, strides[1] == 3, strides[2] == 1  (row-major C-contiguous)

// Strides survive Any round-trip:
Any any0 = nd;
Tensor nd2 = any0.as<Tensor>().value();
EXPECT_EQ(nd2.strides(), strides);
```

**Context**: Example functions now use `ffi::Tensor` instead of `DLTensor*`.

```cpp
// Before: void AddOne(DLTensor* x, DLTensor* y) { ... }
// After:
void AddOne(ffi::Tensor x, ffi::Tensor y) {
    TVM_FFI_ICHECK(x->ndim == 1) << "x must be a 1D tensor";
    // x-> still accesses DLTensor fields via ObjectRef operator->
}
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, AddOne);
```
