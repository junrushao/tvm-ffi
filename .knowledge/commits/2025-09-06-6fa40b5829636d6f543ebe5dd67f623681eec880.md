# Add Tensor::strides() accessor with lazy-cached Shape return
## TL;DR
- Adds `Tensor::strides()` method returning `Shape`, mirroring the existing `Tensor::shape()` lazy-caching pattern.
- Renames internal field `TensorObj::stride_data_` to `strides_data_` for naming consistency.
- Updates example code from raw `DLTensor*` parameters to `ffi::Tensor` ref-counted parameters.

## Key Exports

```python
class TensorObj(Object, DLTensor):
    """Managed tensor backing object."""
    shape_data_: Optional[Shape]   # cached shape (protected)
    strides_data_: Optional[Shape] # cached strides (protected, renamed from stride_data_)
    # Invariant: strides_data_ populated lazily on first Tensor::strides() call
    # Interacts with: DLTensor::strides (raw int64_t* from DLPack)

class Tensor(ObjectRef):
    """Managed Tensor (n-dimensional array)."""

    def shape(self) -> Shape: ...
        # Existing. Lazy-caches into shape_data_.

    def strides(self) -> Shape: ...
        # NEW. Returns strides as Shape, lazy-caches into strides_data_.
        # Invariant: TVM_FFI_ICHECK(obj->strides != nullptr) -- fails if DLTensor has null strides
        # Interacts with: Shape (return type), TensorObj::strides_data_ (cache)
        # Interacts with: TensorObjFromDLPack (synthesizes strides from shape when DLPack provides nullptr)
        # Extension: follows same lazy-cache pattern as shape()
```

## Usage Examples
Accessing tensor strides in C++ (from `tests/cpp/test_tensor.cc`):
```cpp
Tensor nd = Empty(Shape({1, 2, 3}), DLDataType({kDLFloat, 32, 1}), DLDevice({kDLCPU, 0}));
Shape strides = nd.strides();
// strides == {6, 3, 1} for a contiguous (1,2,3)-shaped tensor
EXPECT_EQ(strides[0], 6);
EXPECT_EQ(strides[1], 3);
EXPECT_EQ(strides[2], 1);
```

Migrating from raw `DLTensor*` to `ffi::Tensor` (from examples):
```cpp
// Before:
void AddOne(DLTensor* x, DLTensor* y) { /* x->ndim, x->data, etc. */ }
// After:
void AddOne(ffi::Tensor x, ffi::Tensor y) { /* same body -- ffi::Tensor inherits DLTensor */ }
```
