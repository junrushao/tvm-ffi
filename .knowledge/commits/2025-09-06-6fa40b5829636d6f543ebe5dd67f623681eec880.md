# Add Tensor::strides() accessor and fix private field name typo in TensorObj

## TL;DR
- Adds `Tensor::strides() const -> tvm::ffi::Shape` to the `Tensor` ref-wrapper — lazy wrapper around `DLTensor::strides` that materializes into a `Shape` on first call, guarded by `TVM_FFI_ICHECK(obj->strides != nullptr)`.
- Fixes a private field name typo in `TensorObj`: `stride_data_` → `strides_data_` (plural, matching `DLTensor::strides` and `shape_data_` symmetry).
- Updates three example files to use `ffi::Tensor` typed parameters instead of raw `DLTensor*`, completing the `NDArray → Tensor` rename rollout in examples.

## Key Exports

```python
class Tensor(ObjectRef):
    """Managed n-dimensional array; wraps DLTensor inline in TensorObj."""

    def shape(self) -> Shape: ...
    # Lazy-cached: wraps obj->shape[0..ndim-1] into Shape on first call.
    # Invariant: DLTensor::shape is always set (never nullptr for TensorObjFromNDAlloc/DLPack).

    def strides(self) -> Shape: ...
    # NEW (this commit). Lazy-cached: wraps obj->strides[0..ndim-1] into Shape on first call.
    # Invariant: DLTensor::strides MUST NOT be nullptr — caller receives TVM_FFI_ICHECK failure.
    # Note: TensorObjFromNDAlloc and TensorObjFromDLPack (when src strides==nullptr) always
    #       populate strides_data_ at construction; so strides() is safe after those factory paths.
    # Interacts with: TensorObj::strides_data_ (Optional<Shape>), DLTensor::strides (int64_t*)

    def dtype(self) -> DLDataType: ...
    def IsContiguous(self) -> bool: ...

    @staticmethod
    def FromNDAlloc(alloc: TNDAlloc, shape: Shape, dtype: DLDataType, device: DLDevice,
                    *extra_args) -> Tensor: ...
    # Invariant: strides_data_ is populated at construction (C-contiguous order).
    # Interacts with: MakeStridesFromShape helper, TensorObjFromNDAlloc

    @staticmethod
    def FromDLPack(tensor: DLManagedTensor*, require_alignment=0,
                   require_contiguous=False) -> Tensor: ...
    # Invariant: if src strides==nullptr, strides_data_ populated from shape at construction.
    # Extension: FromDLPackVersioned for DLPack ≥ 1.0 API.

class TensorObj(Object, DLTensor):
    """Private storage backing Tensor. Inherits DLTensor fields inline."""
    shape_data_: Optional[Shape]    # owning backup for DLTensor::shape pointer
    strides_data_: Optional[Shape]  # owning backup for DLTensor::strides pointer
    # (was stride_data_ before this commit — typo fix)
    # Invariant: when strides_data_.has_value(), DLTensor::strides == strides_data_.data()
```

## Impact
- API: **Additive**. `Tensor::strides()` is a new public method. No existing signatures changed.
- Behavioral: None for existing callers. For non-contiguous tensors imported via `FromDLPack` with explicit strides, `strides()` now provides an ergonomic typed accessor instead of requiring callers to dereference `DLTensor::strides` directly.
- Flags/config: None.
- Data formats/schemas: None. Private field rename (`stride_data_` → `strides_data_`) is not part of any serialized format.

## Usage Examples

C++ — accessing strides after creating a tensor (from `tests/cpp/test_tensor.cc`):

```cpp
// Create a 1×2×3 float32 CPU tensor (C-contiguous)
Tensor nd = Empty(Shape({1, 2, 3}), DLDataType({kDLFloat, 32, 1}), DLDevice({kDLCPU, 0}));
Shape shape = nd.shape();    // {1, 2, 3}
Shape strides = nd.strides(); // {6, 3, 1}  — C-contiguous row-major

// strides[0] = shape[1]*shape[2] = 6
// strides[1] = shape[2]           = 3
// strides[2] = 1
EXPECT_EQ(strides.size(), 3);
EXPECT_EQ(strides[0], 6);
EXPECT_EQ(strides[1], 3);
EXPECT_EQ(strides[2], 1);

// Round-trip through Any: strides preserved
Any any = nd;
Tensor nd2 = any.as<Tensor>().value();
EXPECT_EQ(nd2.strides(), strides);
```
