# Add Tensor::strides() accessor with lazy Shape caching
## TL;DR
- Adds `Tensor::strides()` method that returns strides as a `Shape` object, mirroring the existing `Tensor::shape()` pattern with lazy caching via `Optional<Shape> strides_data_`.
- Renames internal field `TensorObj::stride_data_` to `TensorObj::strides_data_` for naming consistency with the new accessor.
- Updates example code to use `ffi::Tensor` instead of raw `DLTensor*` in function signatures, demonstrating the preferred typed API.

## Key Exports

```python
class Tensor(ObjectRef):
    """DLPack-compatible managed tensor with ref-counted storage."""

    def strides(self) -> Shape:
        """Return strides as a Shape object. Lazily caches on first access.
        # Invariant: strides pointer must be non-null (checked via TVM_FFI_ICHECK)
        # Interacts with: TensorObj.strides_data_ (Optional<Shape> cache field)
        # Interacts with: Tensor.shape() (same lazy-cache pattern)
        # Extension: subclasses of Tensor inherit this method via ObjectRef dispatch
        """
        ...

    # Existing for reference (unchanged):
    # def shape(self) -> Shape: ...
    # def dtype(self) -> DLDataType: ...
    # def IsContiguous(self) -> bool: ...
```

## Impact
- API: Additive -- new `Tensor::strides()` method. No existing signatures changed. Example functions migrated from `DLTensor*` to `ffi::Tensor` (non-breaking for callers since `Tensor` auto-converts from `DLTensor*` via TypeTraits).
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (0002): `Tensor` extends `ObjectRef`, uses `get_mutable()` to access the underlying `TensorObj`.
- **Containers / Shape** (0006): `Shape` is used as the return type for strides, constructed from raw `int64_t*` + `ndim`.
- **Containers / Optional** (0006): `Optional<Shape>` used for lazy caching pattern.
- **Error propagation** (0004): `TVM_FFI_ICHECK` used to assert strides are non-null before access.

Design elements this commit produces:
- **`Tensor::strides()` accessor**: New public API method on `Tensor` (ObjectRef wrapper). Follows the same lazy-cache-into-`Optional<Shape>` pattern as `Tensor::shape()`. The strides pointer is checked non-null (unlike `shape()` which always exists).

## Usage Examples

From the test added in this commit (`tests/cpp/test_tensor.cc`):

```cpp
// Create a 3D tensor [1, 2, 3] with row-major (C-contiguous) layout
Tensor nd = Empty(Shape({1, 2, 3}), DLDataType({kDLFloat, 32, 1}), DLDevice({kDLCPU, 0}));
Shape strides = nd.strides();
// strides for shape [1,2,3] in C-contiguous order: [6, 3, 1]
EXPECT_EQ(strides.size(), 3);
EXPECT_EQ(strides[0], 6);
EXPECT_EQ(strides[1], 3);
EXPECT_EQ(strides[2], 1);
```

The examples also show the recommended typed API pattern for kernel library functions:

```cpp
// Preferred: use ffi::Tensor instead of raw DLTensor*
void AddOne(ffi::Tensor x, ffi::Tensor y) {
  TVM_FFI_ICHECK(x->ndim == 1) << "x must be a 1D tensor";
  // x->data, x->shape, x->strides etc. still accessible via DLTensor inheritance
}
```
