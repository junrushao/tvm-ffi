# Add Tensor::strides() accessor and rename stride_data_ to strides_data_

## TL;DR
- Adds `Tensor::strides()` public method to `Tensor` ref class, mirroring the existing `Tensor::shape()` pattern: lazily wraps the raw `DLTensor::strides` pointer into an `Optional<Shape>` cache (`strides_data_`).
- Renames the internal field `TensorObj::stride_data_` to `TensorObj::strides_data_` for consistency with the plural naming of `strides` in DLTensor.
- Updates example code (`extension.cc`, `add_one_cpu.cc`, `add_one_cuda.cu`) to use `ffi::Tensor` instead of raw `DLTensor*`, following the prior NDArray-to-Tensor rename.

## Key Exports

**Method** (new):
```cpp
// Tensor : public ObjectRef (in include/tvm/ffi/container/tensor.h)
tvm::ffi::Shape Tensor::strides() const;
```
Lazily constructs a `Shape` from `DLTensor::strides` and caches it in `TensorObj::strides_data_`. Asserts `strides != nullptr` via `TVM_FFI_ICHECK`.

**Field rename** (protected, internal):
| Old name | New name |
|---|---|
| `TensorObj::stride_data_` | `TensorObj::strides_data_` |

## Impact
- API: New public method `Tensor::strides()` available to all C++ callers. No breaking change -- purely additive.
- Behavioral: The `strides_data_` field rename is internal/protected and does not affect any public ABI or cross-language callers (the field is not exposed via C ABI or reflection).
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Object system** (`ObjectRef`, `get_mutable()`) -- `Tensor` extends `ObjectRef` and uses `get_mutable()` to lazily populate the cache. See [0003-object-system.md](../designs/0003-object-system.md).
- **Shape container** -- `strides()` returns `tvm::ffi::Shape`, the immutable int64 tuple type. See [0008-containers.md](../designs/0008-containers.md).
- **Tensor always-non-null strides invariant** -- `strides()` asserts `strides != nullptr`, relying on the invariant established in commit ca95b41 that all TVM FFI Tensors have non-null strides. See [0008-containers.md](../designs/0008-containers.md).
- **Lazy caching pattern** -- mirrors the existing `shape()` implementation: check `Optional<Shape>::has_value()`, construct from raw pointer if absent, return cached value.

Design elements this commit produces:
- **`Tensor::strides()` accessor** -- completes the Tensor ref class's accessor surface (`shape()`, `strides()`, `dtype()`, `IsContiguous()`), making strides accessible without reaching through `operator->` to the raw `DLTensor` fields.

## Usage Examples
**Context**: Accessing strides from a Tensor in C++ (from `tests/cpp/test_tensor.cc`).
```cpp
#include <tvm/ffi/container/tensor.h>
using namespace tvm::ffi;

Tensor nd = Empty(Shape({1, 2, 3}), DLDataType({kDLFloat, 32, 1}), DLDevice({kDLCPU, 0}));
Shape strides = nd.strides();
// strides == {6, 3, 1} (row-major contiguous)
assert(strides.size() == 3);
assert(strides[0] == 6);
assert(strides[1] == 3);
assert(strides[2] == 1);

// Strides survive round-trip through Any
Any any_nd = nd;
Tensor nd2 = any_nd.as<Tensor>().value();
assert(nd2.strides() == strides);
```
