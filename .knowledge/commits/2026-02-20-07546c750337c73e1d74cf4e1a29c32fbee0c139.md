# Add const qualifier to Array::operator[] return type
## TL;DR
- Adds `const` to the return type of `Array<T>::operator[]` to prevent accidental mutation of immutable array elements.

## Key Exports
None

## Impact
- API: `Array<T>::operator[]` now returns `const T` instead of `T`. Callers that relied on modifying the returned value will get a compile error.

- Flags/config: None
