# Temporary workaround: revert Array::operator[] return type to const T for flashinfer compat

## TL;DR
- Changes `Array<T>::operator[](int64_t) const` return type from `T` back to `const T` as a temporary workaround for a flashinfer implicit conversion dependency.
- Explicitly marked as a temporary fix to unblock the 0.1.19 release; intended to be re-landed once flashinfer patches are released.

## Key Exports

**Signature change:**
```cpp
// Before (0.1.19 change): T operator[](int64_t i) const;
// After (this workaround): const T operator[](int64_t i) const;
```

## Impact
- API: `Array<T>::operator[]` returns `const T` instead of `T`. This affects implicit conversion rules for downstream callers that rely on const-qualified return types.
- Behavioral: none (same value returned, only constness differs)
- Flags/config: none
- Data formats/schemas: none
