# Temp revert Array::operator[] to return const T for flashinfer compatibility

## TL;DR
- Single-line change: `Array<T>::operator[](int64_t) const` return type changed from `T` back to `const T`.
- Explicit temporary workaround for 0.1.19 release; flashinfer relies on implicit conversion behavior that requires `const T`.
- Intended to be reverted once flashinfer's fix lands in a release.

## Key Exports
None

## Impact
- API: `Array<T>::operator[]` return type `T` → `const T`. This is a minor behavioral difference: callers cannot implicitly convert `const T` via non-const reference paths.
- Behavioral: Restores prior implicit conversion behavior needed by flashinfer.

- Data formats/schemas: none
