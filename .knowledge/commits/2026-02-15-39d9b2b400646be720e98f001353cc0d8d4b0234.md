# Enable customizable AnyHash/AnyEqual via type attribute columns
## TL;DR
- Extends `AnyHash` and `AnyEqual` to look up `__any_hash__` and `__any_equal__` type attribute columns before falling back to pointer/int comparison
- Supports both function-pointer fast path (via `kTVMFFIOpaquePtr`) and `ffi.Function` slow path
- Moves `MoveFromSafeCallRaised`/`SetSafeCallRaised` from `function_details.h` to `error.h` for broader reuse
- Registers `__any_hash__`/`__any_equal__` columns at startup in `container.cc`

## Key Exports

```python
class AnyHash:
    """String-aware Any hash functor with customizable per-type dispatch."""
    def __call__(self, a: Any) -> int: ...
    # Interacts with: TVMFFITypeAttrColumn("__any_hash__"), type_attr registration
    # Extension: register __any_hash__ on any Object type for custom hashing

class AnyEqual:
    """String-aware Any equal functor with customizable per-type dispatch."""
    def __call__(self, lhs: Any, rhs: Any) -> bool: ...
    # Interacts with: TVMFFITypeAttrColumn("__any_equal__"), type_attr registration
    # Extension: register __any_equal__ on any Object type for custom equality

# Type attribute convention:
# attr("__any_hash__", reinterpret_cast<void*>(&MyType::CustomAnyHash))
# attr("__any_equal__", reinterpret_cast<void*>(&MyType::CustomAnyEqual))
# Supports: void* (fast path) or ffi.Function (generic path)
```

## Impact
- API: `AnyHash`/`AnyEqual` now dispatch to custom implementations when registered
- Behavioral: object types with `__any_hash__`/`__any_equal__` attrs use value-based comparison instead of pointer identity in `Dict`/`Map` key lookup
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cpp
// Register custom hash/equal for TIntObj
refl::TypeAttrDef<TIntObj>()
    .attr("__any_hash__", reinterpret_cast<void*>(&TInt::CustomAnyHash))
    .attr("__any_equal__", reinterpret_cast<void*>(&TInt::CustomAnyEqual));

// Now Dict<TInt, V> uses value-based hashing/equality
Dict<Any, Any> d;
d.Set(TInt(7), String("seven"));
assert(d.at(TInt(7)).cast<String>() == "seven");
```
