# Enable customized AnyHash/Equal in Object type attributes
## TL;DR
- Adds support for custom `AnyHash` and `AnyEqual` functors in `any.h`, enabling objects to define custom hashing and equality semantics.
- Extends `testing_object.h` with customized hash/equal examples.

## Impact
- API: New `AnyHash`/`AnyEqual` customization points in the Any system.
