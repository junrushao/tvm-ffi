# Enable per-type custom AnyHash/AnyEqual dispatch via __any_hash__/__any_equal__ type attributes
## TL;DR
- Extends `AnyHash::operator()` and `AnyEqual::operator()` to check per-type `TVMFFITypeAttrColumn` for `"__any_hash__"`/`"__any_equal__"` attributes before falling back to default pointer-identity comparison.
- Two dispatch modes: raw function pointer (`void*` stored as `kTVMFFIOpaquePtr`) for fast-path, or a `Function` object for flexibility.
- `EnsureTypeAttrColumn("__any_hash__")` / `("__any_equal__")` called at static init (container.cc) to pre-allocate the columns.
- Extracts `MoveFromSafeCallRaised()`/`SetSafeCallRaised()` to `error.h` as shared helpers (previously inline at use sites in `any.h`).

## Key Exports

```python
# C++: AnyHash dispatch (any.h)
# AnyHash::operator()(src: Any) -> uint64_t
#   1. Short strings: hash via type_index + content bytes
#   2. Static object types: check TVMFFITypeAttrColumn["__any_hash__"][type_index]
#      a. kTVMFFIOpaquePtr: call as int64_t (*)(const Any&) — zero-overhead fast path
#      b. kTVMFFIFunction: call via cpp_call or safe_call, returns int64 hash
#   3. Fallback: StableHashCombine(type_index, v_uint64)  [pointer identity]
# Interacts with: TVMFFIGetTypeAttrColumn, TypeAttrDef.attr("__any_hash__", ...)

# C++: AnyEqual dispatch (any.h)
# AnyEqual::operator()(lhs: Any, rhs: Any) -> bool
#   Same column lookup pattern as AnyHash, dispatches to custom equal if registered
#   Interacts with: TVMFFIGetTypeAttrColumn, TypeAttrDef.attr("__any_equal__", ...)

# C++ registration pattern (TypeAttrDef):
# refl::TypeAttrDef<MyObj>()
#     .attr("__any_hash__",  reinterpret_cast<void*>(&MyObj::CustomAnyHash))
#     .attr("__any_equal__", reinterpret_cast<void*>(&MyObj::CustomAnyEqual))
# Invariant: CustomAnyHash signature must be int64_t(*)(const Any&)
# Invariant: CustomAnyEqual signature must be bool(*)(const Any&, const Any&)
# Invariant: columns pre-allocated via EnsureTypeAttrColumn() before first use

# error.h: new helpers extracted from inline use in any.h
# MoveFromSafeCallRaised() -> Error: moves TLS raised error into Error object
# SetSafeCallRaised(error: Error) -> void: sets TLS raised error
```

## Impact
- API: `AnyHash`/`AnyEqual` behavior extended — additive for new types; existing types unchanged (column entry is `kTVMFFINone`, falls through to old behavior). `MoveFromSafeCallRaised` / `SetSafeCallRaised` newly public in `error.h`.
- Behavioral: Object types can now define value-semantic hash/equal for `Any` containers (e.g., `Map<TInt, V>`) without inheriting from `StructuralHash`/`StructuralEqual`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `AnyHash` / `AnyEqual` (0002-ffi-any-value-system) — extended with per-type dispatch
- `TypeAttrDef<T>` / `TVMFFITypeAttrColumn` (0007-ffi-reflection) — used to store and look up `__any_hash__`/`__any_equal__`
- `TVMFFIGetTypeAttrColumn` (0001-ffi-c-abi) — C ABI for column lookup

Design elements this commit produces:
- `"__any_hash__"` / `"__any_equal__"` type attribute column convention — two new well-known attribute names for per-type `AnyHash`/`AnyEqual` override
- `MoveFromSafeCallRaised()` / `SetSafeCallRaised()` extracted to `error.h` as public details helpers

## Usage Examples

```cpp
// Register custom hash/equal for TInt so it can be used as Map keys
static int64_t CustomAnyHash(const Any& src) {
    return static_cast<int64_t>(src.cast<TInt>()->value + 1024);
}
static bool CustomAnyEqual(const Any& lhs, const Any& rhs) {
    return lhs.cast<TInt>()->value == rhs.cast<TInt>()->value;
}

// In TIntObj::RegisterReflection():
refl::TypeAttrDef<TIntObj>()
    .attr("__any_hash__",  reinterpret_cast<void*>(&TInt::CustomAnyHash))
    .attr("__any_equal__", reinterpret_cast<void*>(&TInt::CustomAnyEqual));

// Now TInt can be used as Map key with value semantics:
Map<TInt, String> m;
m.Set(TInt(42), "hello");
TVM_FFI_ICHECK(m[TInt(42)] == "hello");  // equality uses CustomAnyEqual
```
