# Enable customized AnyHash/AnyEqual via type attribute columns for Object types
## TL;DR
- Extends `AnyHash` and `AnyEqual` to look up per-type custom hash/equal functions via type attribute columns (`__any_hash__`, `__any_equal__`).
- Custom functions can be either raw function pointers (`kTVMFFIOpaquePtr` for fast path) or `ffi.Function` objects (general path).
- Enables Object types to be usable as Map keys with custom equality/hash semantics.

## Key Exports

**Type attributes** (registered via `TVMFFITypeRegisterAttr`):
- `"__any_hash__"` -- Custom hash function for `AnyHash`, signature `(const Any&) -> int64_t` (pointer) or `Function(Any) -> int` (FFI function)
- `"__any_equal__"` -- Custom equal function for `AnyEqual`, signature `(const Any&, const Any&) -> bool` (pointer) or `Function(Any, Any) -> bool` (FFI function)

**New error utility** (`error.h`):
```cpp
// Internal check helpers (for use in any.h without function.h dependency)
TVM_FFI_ICHECK_NOTNULL(ptr)
TVM_FFI_ICHECK_EQ(a, b)
```

## Impact
- API: `AnyHash` and `AnyEqual` now have public/private access specifiers. New type attribute columns `__any_hash__` and `__any_equal__` are consumed at runtime.
- Behavioral: Object types with `type_index >= kTVMFFIStaticObjectBegin` can now participate in Map key equality/hashing via registered type attributes. Without registration, behavior is unchanged (pointer-based comparison).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Any/AnyView value system** (`.knowledge/designs/0002-any-value-system.md`): Extends `AnyHash`/`AnyEqual` with type-dispatched custom functions.
- **Containers / Map** (`.knowledge/designs/0008-containers.md`): Enables custom key types for Map.

Design elements this commit produces:
- **Custom AnyHash/AnyEqual protocol**: Type attribute columns `__any_hash__` and `__any_equal__` enable per-Object-type custom hash/equality, supporting both fast-path function pointers and general FFI functions.

## Usage Examples

```cpp
// Register custom hash/equal for a type
int64_t MyObjHash(const Any& a) { /* custom hash */ }
bool MyObjEqual(const Any& a, const Any& b) { /* custom equal */ }

TVMFFIByteArray hash_attr = {"__any_hash__", 13};
TVMFFIAny hash_val;
hash_val.type_index = TypeIndex::kTVMFFIOpaquePtr;
hash_val.v_ptr = (void*)&MyObjHash;
TVMFFITypeRegisterAttr(MyObj::_type_index, &hash_attr, &hash_val);
// Now MyObj instances can be used as Map keys
```
