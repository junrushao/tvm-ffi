# Enable customized AnyHash/Equal in Object type attributes
## TL;DR
- Extends `AnyHash` and `AnyEqual` functors to support custom per-type hash/equal functions via type attribute columns
- Custom functions registered as `__any_hash__` and `__any_equal__` type attributes
- Supports both function pointer (fast path) and Function object (general path)
- Adds `Error::HashForAny` and `Error::EqualForAny` static methods for Error-specific hash/equal

## Key Exports
```python
class AnyHash:
    """String-aware Any hash functor with custom type support."""
    def __call__(self, src: Any) -> uint64: ...
    # For objects: checks __any_hash__ type attribute column first
    # Falls back to raw pointer hash if no custom hash registered
    # Interacts with: TypeAttrDef, TVMFFIGetTypeAttrColumn

class AnyEqual:
    """String-aware Any equality functor with custom type support."""
    def __call__(self, a: Any, b: Any) -> bool: ...
    # For objects: checks __any_equal__ type attribute column first
    # Falls back to pointer equality if no custom equal registered
    # Interacts with: TypeAttrDef, TVMFFIGetTypeAttrColumn
```

## Impact
- API: `AnyHash`/`AnyEqual` now dispatch to custom functions via type attributes
- Behavioral: objects with `__any_hash__`/`__any_equal__` type attrs get custom hash/equality
- Flags/config: none
- Data formats/schemas: none
