# Make Threads linkage optional in CMake for cross-compilation support
## TL;DR
- Changes `find_package(Threads REQUIRED)` to `find_package(Threads)` (non-fatal) and guards `Threads::Threads` linkage behind `if (Threads_FOUND)`.
- Enables building `tvm_ffi` for cross-compilation targets where pthreads may not be available.
- Follow-up commit `3b4a5327` later adds an explicit `TVM_FFI_USE_THREADS` CMake option to formalize this control.

N/A -- infrastructure.

## Impact
- API: none
- Behavioral: none -- on platforms where Threads is found, behavior is identical to before. On cross-compilation platforms lacking pthreads, the build now succeeds instead of failing at CMake configure time.
- Flags/config: `find_package(Threads)` moved from top-level unconditional `REQUIRED` to conditional near link targets. No new user-facing CMake options in this commit.
- Data formats/schemas: none
