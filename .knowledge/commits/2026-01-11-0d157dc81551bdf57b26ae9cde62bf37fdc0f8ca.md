# Make Threads linkage optional for cross-compilation targets

## TL;DR
- Removes `find_package(Threads REQUIRED)` (which aborts CMake if threads not found) and replaces with `find_package(Threads)` (non-required) guarded by `if (Threads_FOUND)`.
- On cross-compilation targets where threads are unavailable, CMake now succeeds; downstream can provide alternatives via source bundling.
- Net change: 7 additions, 4 deletions in `CMakeLists.txt`.

## Key Exports

```python
# CMakeLists.txt — CMake option behavior change (no new option added)
# Before: find_package(Threads REQUIRED)  # aborts if not found
#         target_link_libraries(tvm_ffi_shared PRIVATE Threads::Threads)
#         target_link_libraries(tvm_ffi_static INTERFACE Threads::Threads)

# After:
# find_package(Threads)  # non-required
# if (Threads_FOUND):
#     target_link_libraries(tvm_ffi_shared PRIVATE Threads::Threads)
#     target_link_libraries(tvm_ffi_static INTERFACE Threads::Threads)
# Invariant: tvm_ffi_shared/static built without Threads linkage if not found
```

## Impact
- API: none
- Behavioral: CMake configure now succeeds on platforms without `Threads`; previously aborted. No change on platforms where threads are found.
- Flags/config: none (no new CMake option — that's added in subsequent commit 3b4a532).
- Data formats/schemas: none
