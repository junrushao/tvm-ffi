# Support C++ dtype_trait and Python-side mapping to C++ dtype
## TL;DR
- Adds `tvm/ffi/extra/dtype.h` with `dtype_trait<T>` template mapping C++ types to DLPack dtypes at compile time.
- Covers standard integer/float types, CUDA types (__half, __nv_bfloat16, fp8 variants), and HIP types.
- Adds Python `tvm_ffi.cpp.dtype` module exposing dtype mappings to Python.

## Key Exports

**C++ API:**
- `tvm_ffi::dtype_trait<T>::value` -- Compile-time `DLDataType` for C++ type T.
- Specializations for: bool, all integer types, float, double, __half, __nv_bfloat16, __nv_fp8_e4m3, __nv_fp8_e5m2, and HIP equivalents.

**Python API:**
- `tvm_ffi.cpp.dtype` module with dtype mappings.

## Impact
- API: New dtype_trait template and Python dtype module.
- ABI: none
- Behavioral: Enables compile-time C++-to-DLPack dtype mapping.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- DLPack type system

Design elements this commit produces:
- **dtype_trait** -- Compile-time C++ type to DLDataType mapping with CUDA/HIP support.

## Usage Examples
```cpp
constexpr DLDataType dt = tvm_ffi::dtype_trait<float>::value;
// dt.code == kDLFloat, dt.bits == 32, dt.lanes == 1
```
