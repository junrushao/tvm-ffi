# feat: Add dtype_trait<T> C++ template and Python-side dtype mapping in tvm_ffi.cpp.dtype

## TL;DR
- New `include/tvm/ffi/extra/dtype.h` (206 lines): `tvm_ffi::dtype_trait<T>` template mapping C++ primitive and hardware-specific types (CUDA `__half`, `__nv_bfloat16`, `__nv_fp8_*`, HIP types, etc.) to `DLDataType` values
- New `python/tvm_ffi/cpp/dtype.py` (104 lines) and `python/tvm_ffi/cpp/__init__.py` addition: Python-side `tvm_ffi.cpp.dtype` submodule providing `DType` class and dtype string/object utilities

## Key Exports

```python
# include/tvm/ffi/extra/dtype.h  (C++)

class dtype_trait(T):
    """Maps C++ type T to DLDataType at compile time."""
    value: DLDataType  # constexpr
    # Interacts with: DLDataType (dlpack), tensor creation APIs

# Specializations provided for:
# - All standard C++ integer types (signed/unsigned char, short, int, long, long long)
# - float, double
# - bool
# - CUDA: __half (fp16), __nv_bfloat16, __nv_fp8_e4m3, __nv_fp8_e5m2, __nv_fp8_e8m0, __nv_fp4_e2m1
# - HIP: __hip_bfloat16, __hip_fp8_e4m3, __hip_fp8_e4m3_fnuz, __hip_fp8_e5m2, __hip_fp8_e5m2_fnuz, __hip_fp4_e2m1

# Helper structs:
class details::dtypes::integer_trait(T):
    value: DLDataType  # {kDLInt/kDLUInt, sizeof(T)*8, 1}
class details::dtypes::float_trait(T):
    value: DLDataType  # {kDLFloat, sizeof(T)*8, 1}

# python/tvm_ffi/cpp/dtype.py

class DType:
    """Python wrapper around DLDataType."""
    # Interacts with: tvm_ffi.cpp submodule, tensor dtype fields
```

## Impact
- API: Additive — new header `<tvm/ffi/extra/dtype.h>` and Python module `tvm_ffi.cpp.dtype`
- Behavioral: none for existing code
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cpp
// C++: get DLDataType for a CUDA half type
#include <tvm/ffi/extra/dtype.h>
constexpr DLDataType fp16_dtype = tvm_ffi::dtype_trait<__half>::value;
// → {kDLFloat, 16, 1}

// Pass to tensor creation:
auto tensor = Tensor::FromEnvAlloc(alloc, shape, strides,
    tvm_ffi::dtype_trait<float>::value, device);
```
