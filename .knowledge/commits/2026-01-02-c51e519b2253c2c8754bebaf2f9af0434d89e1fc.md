# Add C++ dtype_trait mapping and Python to_cpp_dtype for CUDA/ROCm/CPU types
## TL;DR
- Introduces `tvm_ffi::dtype_trait<T>` (C++ header `extra/dtype.h`) mapping C++ scalar types (integers, floats, CUDA/HIP half/fp8/fp4 types) to `DLDataType` at compile time.
- Adds Python module `tvm_ffi.cpp.dtype` with `to_cpp_dtype(dtype_str)` that converts TVM/PyTorch dtype strings to the corresponding C++ type name, with auto-detection of CUDA/ROCm/CPU backend.

## Key Exports

**`tvm_ffi::dtype_trait<T>`** (`extra/dtype.h`):
```cpp
namespace tvm_ffi {
template <typename T> struct dtype_trait {};  // primary: empty
// Specializations for: signed/unsigned char/short/int/long/long long, float, double, bool
// CUDA: __half, __nv_bfloat16, __nv_fp8_e4m3, __nv_fp8_e5m2, __nv_fp8_e8m0, __nv_fp4_e2m1, __nv_fp4x2_e2m1
// HIP: __hip_bfloat16, hip_bfloat16, __hip_fp8_e4m3, __hip_fp8_e4m3_fnuz, __hip_fp8_e5m2, __hip_fp8_e5m2_fnuz, __hip_fp4_e2m1, __hip_fp4x2_e2m1
// Each has: static constexpr DLDataType value = { code, bits, lanes };
}
```
Note: Uses forward declarations for CUDA/HIP types (no `<cuda_fp16.h>` required).

**`tvm_ffi.cpp.dtype.to_cpp_dtype(dtype_str) -> str`** (`python/tvm_ffi/cpp/dtype.py`):
```python
def to_cpp_dtype(dtype_str: str | Any) -> str: ...
# Converts "float32" -> "float", "bfloat16" -> "__nv_bfloat16" (CUDA) or "__hip_bfloat16" (ROCm)
# Accepts torch.dtype objects (stripped of "torch." prefix)
# Backend auto-detected via torch.cuda.is_available() + torch.version.cuda/hip
```

**Python dtype maps**: `CPU_DTYPE_MAP`, `CUDA_DTYPE_MAP`, `ROCM_DTYPE_MAP` dictionaries.

## Impact
- API: New public header `tvm/ffi/extra/dtype.h` (header-only, no library dependency). New Python module `tvm_ffi.cpp.dtype`. Note: uses `tvm_ffi` namespace (not `tvm::ffi`).
- Behavioral: None (additive only).
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:

Design elements this commit produces:
- **C++ dtype trait system** (`tvm_ffi::dtype_trait<T>`): Compile-time mapping from C++ scalar types to DLPack data types, covering standard integers, floats, bool, and vendor-specific half/fp8/fp4 types.
- **Python dtype conversion utility** (`tvm_ffi.cpp.dtype`): Runtime mapping from dtype strings to C++ type name strings for code generation workflows.

## Usage Examples

**C++ usage:**
```cpp
#include <tvm/ffi/extra/dtype.h>
constexpr DLDataType dt = tvm_ffi::dtype_trait<float>::value;
// dt == {kDLFloat, 32, 1}
constexpr DLDataType dt_half = tvm_ffi::dtype_trait<__half>::value;
// dt_half == {kDLFloat, 16, 1}
```

**Python usage:**
```python
from tvm_ffi.cpp.dtype import to_cpp_dtype
to_cpp_dtype("float32")       # "float"
to_cpp_dtype("bfloat16")      # "__nv_bfloat16" (on CUDA) or "__hip_bfloat16" (on ROCm)
to_cpp_dtype(torch.float16)   # "__half"
```
