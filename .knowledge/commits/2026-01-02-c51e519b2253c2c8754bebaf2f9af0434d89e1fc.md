# Introduce C++ dtype_trait and Python-side dtype mapping
## TL;DR
- Adds `include/tvm/ffi/extra/dtype.h` with C++ `dtype_trait<T>` compile-time dtype mapping.
- Adds `python/tvm_ffi/cpp/dtype.py` for Python-side mapping from C++ types to TVM dtypes.

## Impact
- API: New public header `extra/dtype.h` and Python module `tvm_ffi.cpp.dtype`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Any system** (`.knowledge/designs/0002-any-system.md`): DType is a core type-erased value type.
- **Extra API tier** (`.knowledge/designs/0011-extra-api-tier.md`): `extra/dtype.h` lives in the extra tier.

Design elements this commit produces:
- **dtype_trait**: Compile-time C++ type-to-DLDataType mapping, enabling generic kernel code to derive dtypes from C++ types.
