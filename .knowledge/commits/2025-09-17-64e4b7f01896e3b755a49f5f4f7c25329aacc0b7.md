# Modernize pre-commit hooks: migrate task_lint.sh into native pre-commit hooks

## TL;DR
- Expands `.pre-commit-config.yaml` from basic pre-commit-hooks to a full suite: `check-asf-header`, `check-file-type`, `ruff-check`/`ruff-format`, `clang-format` (v20.1.8), `cython-lint`/`double-quote-cython-strings`, `shfmt`, `shellcheck`, plus `check-yaml`/`check-toml`.
- Replaces the CI `lint` job's manual `pip install black pylint ruff` + `task_lint.sh` invocation with a single `pre-commit/action@v3.0.1` step; removes `isort` and `black` as standalone tools (superseded by `ruff-format`).
- Makes `test` job depend on `lint` (was independent) and applies formatter-driven whitespace/style reformatting across ~35 Python, Cython, and shell source files.
