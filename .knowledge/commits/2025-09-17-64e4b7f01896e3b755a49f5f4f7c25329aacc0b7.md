# Modernize pre-commit hooks and migrate CI lint stage to pre-commit/action

## TL;DR
- Expands `.pre-commit-config.yaml` with ruff (check+format), clang-format, cython-lint, shfmt, shellcheck, check-yaml, check-toml, and local hooks for ASF header and file-type checks.
- Replaces the CI `lint` job's custom `task_lint.sh` invocation with the canonical `pre-commit/action@v3.0.1`, making the `test` stage depend on `lint`.
- Applies auto-formatter output across the codebase (ruff-format for Python, clang-format for C++ headers, cython-lint/shfmt for `.pxi`/`.sh` files); no semantic code changes.
