# Modernize pre-commit hooks, replace task_lint.sh with native pre-commit in CI
## TL;DR
- Replaces the manual `task_lint.sh`-based CI lint step with `pre-commit/action@v3.0.1`, and expands `.pre-commit-config.yaml` with ruff-check/ruff-format (replacing black+isort), clang-format (mirrors v20.1.8), cython-lint, shfmt, shellcheck, check-yaml/check-toml, and local hooks for ASF header and file type checks.
- Makes the `test` CI job depend on `lint` (in addition to `prepare`), ensuring lint passes before tests run. Removes the docs-only skip condition from the lint job so lint always runs.
- Applies resulting formatting fixes across ~40 files: `from __future__ import annotations` additions, ruff-format whitespace changes, shfmt tab-indentation in shell scripts, cython-lint fixes, and trailing whitespace cleanup.

## Impact
- API: none (formatting only)
- Flags/config: `.pre-commit-config.yaml` is now the authoritative lint configuration. CI no longer installs black/pylint/clang-format-15 manually.
- Data formats/schemas: none
