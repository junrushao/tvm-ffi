# Modernize pre-commit hooks and migrate CI lint stage from task_lint.sh to pre-commit/action

## TL;DR
- Expanded `.pre-commit-config.yaml` with ruff (check+format), clang-format, cython-lint, shfmt, shellcheck, and custom ASF header / filetype checks; replaced `task_lint.sh` invocation in CI with `pre-commit/action@v3.0.1`.
- Applied auto-formatting across all Python, Cython, C++ header, and shell files (ruff-format line wrapping, clang-format whitespace, shfmt tab indentation, cython-lint fixes).
- Made the `test` CI stage depend on `lint`, enforcing lint-before-test ordering; removed `bench_ffi_nop_from_dlpack` duplicate function and unused `eps` variable from benchmark script.

## Key Exports
N/A -- infrastructure. No new public API symbols introduced.

## Impact
- API: none
- Behavioral: CI `lint` job now uses `pre-commit/action` instead of a custom `task_lint.sh` script; `test` job depends on `lint` completing first. One minor Cython fix: `_get_global_func` had a misleading 3-space indentation on `return None` (corrected to 4-space).
- Flags/config: `.pre-commit-config.yaml` is the new single source of truth for all linting hooks; `task_lint.sh` still exists but is now redundant (its `isort`/`black` calls overlap with ruff-format).
- Data formats/schemas: none
