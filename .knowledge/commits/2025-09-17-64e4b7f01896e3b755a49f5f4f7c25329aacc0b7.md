# Modernize pre-commit hooks: replace task_lint.sh with native pre-commit hooks and auto-format codebase

## TL;DR
- Expands `.pre-commit-config.yaml` with ruff (check+format), clang-format, cython-lint, shfmt, shellcheck, check-yaml, check-toml, and two local hooks (`check-asf-header`, `check-file-type`), replacing the ad-hoc `task_lint.sh`-based CI lint job with the standard `pre-commit/action@v3.0.1` GitHub Action.
- Applies auto-formatting fixes across ~45 files (Python, Cython, C++ headers, shell scripts, docs, tests) to satisfy the newly-enforced ruff-format, shfmt, cython-lint, and clang-format hooks. Changes are whitespace/style-only with two minor functional removals: unused `from .base import _LIB` import in `examples/packaging/python/my_ffi_extension/_ffi_api.py`, unused `import ctypes` in `examples/quick_start/run_example.py`, unused `import sys` in `docs/conf.py`, a duplicate `bench_ffi_nop_from_dlpack` function in `tests/scripts/benchmark_dlpack.py`, and an unused variable `eps` in the same file.
- Makes the CI `test` stage depend on `lint` (previously only depended on `prepare`), ensuring tests only run after lint passes.

## Key Exports

**Pre-commit hooks (`.pre-commit-config.yaml`)**:
- `check-asf-header` -- local hook running `python tests/lint/check_asf_header.py --check`
- `check-file-type` -- local hook running `python tests/lint/check_file_type.py`
- `check-yaml`, `check-toml` -- standard YAML/TOML validation
- `ruff-check` (v0.12.3) -- Python lint with `--fix`, types: `[python, pyi, jupyter]`
- `ruff-format` (v0.12.3) -- Python formatting, types: `[python, pyi, jupyter]`
- `clang-format` (v20.1.8) -- C/C++ formatting
- `cython-lint` (v0.16.7) -- Cython lint with `--max-line-length=120`
- `double-quote-cython-strings` -- Cython string quoting
- `shfmt` (v3.12.0-2) -- Shell script formatting
- `shellcheck` (v0.10.0.1) -- Shell script lint

**CI (`ci_test.yml`)**:
- `lint` job simplified to `pre-commit/action@v3.0.1` (replaces manual python setup + `task_lint.sh`)
- `test` job now `needs: [lint, prepare]` (was `needs: [prepare]`)
- `lint` job no longer gated by `should_skip_ci_docs_only` (lint runs on docs-only changes too)

## Impact
- API: none
- ABI: none
- Behavioral: (1) CI lint job now runs pre-commit hooks instead of `task_lint.sh`, adding cython-lint, shfmt, shellcheck, YAML/TOML validation that were not previously enforced in CI. (2) `task_lint.sh` is retained but reformatted by shfmt (still callable locally). (3) CI `test` stage now depends on `lint` passing. (4) `lint` stage no longer skipped for docs-only PRs. (5) Removed duplicate `bench_ffi_nop_from_dlpack` function in `benchmark_dlpack.py`. (6) Removed unused `_LIB` import in example `_ffi_api.py`.
- Flags/config: `default_install_hook_types: [pre-commit]` added to `.pre-commit-config.yaml`
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **CI pipeline architecture** (commit `ef6d57b`): Builds on the initial GitHub Actions CI setup by replacing the `lint` job implementation while keeping the same workflow structure.
- **Lint orchestration via `task_lint.sh`** (commit `ef6d57b`, updated in `5304752`): The canonical lint sequence previously defined in `task_lint.sh` is superseded by pre-commit hooks. The script is retained but no longer called by CI.
- **Pre-commit baseline** (commit `ef6d57b`): The initial `.pre-commit-config.yaml` with standard hygiene hooks is extended with project-specific linters.

Design elements this commit produces:
- **Pre-commit as canonical lint entry point**: Pre-commit hooks replace `task_lint.sh` as the single source of truth for lint checks. `pre-commit run --all-files` is now the local equivalent of the CI lint job.
- **Lint-gates-test dependency**: CI `test` stage now depends on `lint`, establishing a sequential pipeline where lint failures block test execution.

## Usage Examples
```bash
# Run all lint checks locally (replaces task_lint.sh)
pre-commit run --all-files

# Run a single hook
pre-commit run ruff-check --all-files
pre-commit run clang-format --all-files
pre-commit run cython-lint --all-files

# Install hooks for automatic pre-commit checking
pre-commit install
```
