# Modernize pre-commit hooks, replacing task_lint.sh with native pre-commit integration
## TL;DR
- Introduces a comprehensive `.pre-commit-config.yaml` with hooks for ruff, clang-format, cython-lint, shfmt, shellcheck, check-yaml, check-toml, ASF header checks, and file-type checks.
- Replaces the monolithic `tests/scripts/task_lint.sh` CI step with `pre-commit/action@v3.0.1` in `.github/workflows/ci_test.yml`, and makes the `test` stage depend on `lint`.
- All other file changes are automated formatting fixes produced by the new linters (ruff-format line wrapping, shfmt tab indentation, trailing whitespace removal, unused import removal, cython-lint style fixes).
