# Modernize pre-commit hooks, replacing task_lint.sh with native pre-commit orchestration

## TL;DR
- Replaces the monolithic `tests/scripts/task_lint.sh` CI invocation with declarative `.pre-commit-config.yaml` hooks (ruff, clang-format, cython-lint, shfmt, shellcheck, ASF header, file-type checks).
- Removes redundant `isort` and `black` steps (subsumed by `ruff-format`), and applies autoformatting fixes across the entire codebase.
- Makes CI `test` stage depend on `lint`, ensuring tests only run after lint passes.

## Key Exports
N/A -- infrastructure.

## Impact
- API: none
- Behavioral: CI `test` job now depends on `lint` (previously both depended only on `prepare`). Lint failures now block test execution.
- Flags/config: `.pre-commit-config.yaml` is the new canonical lint configuration. `task_lint.sh` still exists but is no longer invoked by CI.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- CI pipeline structure (`.github/workflows/ci_test.yml`) -- existing `prepare` / `lint` / `test` job graph.
- Existing lint scripts (`tests/lint/check_asf_header.py`, `tests/lint/check_file_type.py`, `tests/lint/git-clang-format.sh`).

Design elements this commit produces:
- **Pre-commit as canonical lint orchestration**: All linters are now declared in `.pre-commit-config.yaml` and invoked via `pre-commit/action@v3.0.1` in CI, replacing the imperative `task_lint.sh` script.
- **Lint-gates-test invariant**: CI `test` stage now `needs: [lint, prepare]`, enforcing that lint must pass before tests run.
