# Lower minimum Python version from 3.9 to 3.8 with compatibility workarounds
## TL;DR
- Lowered `requires-python` from `>=3.9` to `>=3.8` in `pyproject.toml`, added `cp38-*` to cibuildwheel build list, and set ruff/mypy target to `py38`.
- Added `from __future__ import annotations` to 8 Python files that lacked it, enabling PEP 604 (`X | Y`) union syntax and PEP 563 stringified annotations on Python 3.8.
- Added a conditional import workaround in `container.py` that uses `collections.abc` ABCs on Python 3.8 (where `typing.Mapping` etc. are not subscriptable at runtime) and `typing` ABCs on 3.9+.
- Guarded `ScalarType::Int1..Char` cases in the Torch C DLPack extension with `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6` since those enums do not exist in older PyTorch.

## Key Exports
None -- no new public API. Configuration and compatibility changes only.

## Impact
- API: none
- Behavioral: `tvm_ffi` now installs on Python 3.8; cibuildwheel produces `cp38-*` wheels. The runtime version check in `base.py` now accepts Python >= 3.8.
- Flags/config: `requires-python` changed from `>=3.9` to `>=3.8`. ruff `target-version` changed from `py39` to `py38`. mypy `python_version` changed from `3.9` to `3.8`. cibuildwheel `build` list now includes `cp38-*` (skipped in tests).
- Data formats/schemas: none

Design elements this commit produces:
- **Python 3.8 container ABC workaround**: conditional import in `container.py` (lines 40-54) that imports from `collections.abc` by default and overrides with `typing` module on Python >= 3.9. This is a compatibility shim, not a new abstraction.
- **Strengthened `from __future__ import annotations` convention**: 8 files that previously relied on Python 3.9+ annotation runtime semantics now explicitly opt in. This makes the convention universal across all `.py` files.
- **Torch version guard pattern**: `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6` guard in inline C++ string within `_optional_torch_c_dlpack.py`. This is a pattern for guarding against absent PyTorch ScalarType enums.
