# Lower minimum Python version to 3.8 with future annotations and compat guards
## TL;DR
- Lowers `requires-python` from `>=3.9` to `>=3.8` in `pyproject.toml`, updating cibuildwheel, ruff, and mypy targets accordingly.
- Adds `from __future__ import annotations` to 8 Python files that were missing it, enabling PEP 604 union syntax (`X | Y`) and forward-reference return types on Python 3.8.
- Adds a runtime workaround in `container.py` to import generic `Mapping`/`Sequence`/`KeysView`/`ValuesView`/`ItemsView` from `typing` instead of `collections.abc` on Python <=3.8, and guards Torch scalar type cases behind a `TORCH_VERSION` check.

## Key Exports
None -- this commit produces no new public API surface. Changes are configuration and compatibility adjustments.

## Impact
- API: none -- no signature changes; `from __future__ import annotations` makes string-quoted return types (`-> "dtype"`) into bare names (`-> dtype`) but this is cosmetic.
- Behavioral: `container.py` conditionally imports from `typing` on Python 3.8 to avoid `TypeError` with `collections.abc` generic aliases. `_optional_torch_c_dlpack.py` guards `ScalarType.Int1`..`Char` behind `TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6`.
- Flags/config: `requires-python` changed from `>=3.9` to `>=3.8`. Ruff target `py39` -> `py38`. Mypy `python_version` `3.9` -> `3.8`. cibuildwheel adds `cp38-*` to build matrix. New ruff rule set `FA` (flake8-future-annotations) enabled. `.gitignore` adds `wheelhouse/`.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Python container types (`Array`, `Map`) from `container.py` -- the `collections.abc` generic aliases (`Mapping`, `Sequence`, `KeysView`, `ValuesView`, `ItemsView`) are not subscriptable on 3.8 at runtime, requiring fallback to `typing` equivalents. See [0006-ffi-containers](../design-records/0006-ffi-containers.md).
- Python packaging configuration from [0013-ffi-packaging-and-distribution](../design-records/0013-ffi-packaging-and-distribution.md) -- `pyproject.toml` build/test targets updated.
- Python `StreamContext` / `Module` from [0012-ffi-python-package](../design-records/0012-ffi-python-package.md) -- typing adjustments for `Union[int, c_void_p]` -> `int | c_void_p` via future annotations.

Design elements this commit produces: none
