# Lower minimum Python version from 3.9 to 3.8 with compatibility shims and `from __future__ import annotations` propagation

## TL;DR
- `pyproject.toml` lowers `requires-python` from `>=3.9` to `>=3.8`; cibuildwheel gains a `cp38-*` build target; ruff and mypy targets updated to `py38`/`3.8`.
- All Python source files missing `from __future__ import annotations` receive it, enabling PEP 563 deferred evaluation; forward-reference string literals (`"Type"`) are replaced with bare names; `Union[X, Y]` / `Optional[X]` are rewritten as `X | Y` / `X | None` (these are valid only with deferred annotations on 3.8).
- `container.py` adds a runtime guard for py3.8: on Python ≤ 3.8, `collections.abc` variants of `ItemsView`, `KeysView`, `ValuesView`, `Mapping`, `Sequence` are used (the `typing` re-exports on 3.8 are not subscriptable at runtime); `_optional_torch_c_dlpack.py` adds a `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6` guard around newer `ScalarType` variants (`Int1`–`Int4`, `Char`) absent in older Torch.

## Key Exports

None — this commit introduces no new public APIs. Changes are compatibility shims and packaging configuration.

```python
# pyproject.toml (before → after)
# requires-python = ">=3.9"  →  ">=3.8"
# [tool.ruff] target-version = "py39"  →  "py38"
# [tool.mypy] python_version = "3.9"  →  "3.8"
# [tool.cibuildwheel] build = ["cp39-*", ...]  →  ["cp38-*", "cp39-*", ...]

# container.py py3.8 workaround pattern:
# Invariant: On Python 3.8, typing.ItemsView/KeysView/ValuesView/Mapping/Sequence
#            are NOT subscriptable at runtime; use collections.abc variants instead.
if not (sys.version_info[0] == 3 and sys.version_info[1] <= 8):
    from typing import ItemsView as ItemsViewBase, KeysView as KeysViewBase, ...

# _optional_torch_c_dlpack.py (inline C++ guard):
# #if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 6
#   case ScalarType::Int1: ... case ScalarType::Int4: case ScalarType::Char:
# #endif
# Invariant: ScalarType::Int1-Int4 and Char require Torch >= 2.6.
```

## Impact
- API: None — public API surface is unchanged.
- Behavioral: The package now installs on CPython 3.8. Runtime type-annotation evaluation is deferred (PEP 563) in all modified files via `from __future__ import annotations`, which means `get_type_hints()` callers must pass `localns`/`globalns` appropriately.
- Flags/config: cibuildwheel `test-skip` list grows to include `cp38-*`, so the cp38 wheel is built but not self-tested in CI.
- Data formats/schemas: None.
