# Lower minimum Python version from 3.9 to 3.8
## TL;DR
- Lowers `requires-python` from `>=3.9` to `>=3.8` in `pyproject.toml`, along with matching changes to ruff target-version, mypy python_version, cibuildwheel build matrix, and the runtime version check in `base.py`.
- Adds `from __future__ import annotations` to 8 Python files that were missing it, enabling PEP 604 (`X | Y`) and forward-reference syntax on Python 3.8.
- Adds Python 3.8 compatibility workaround in `container.py` for `collections.abc` vs `typing` import paths for `Mapping`, `Sequence`, `KeysView`, `ValuesView`, `ItemsView`.
- Guards `ScalarType::Int1..Char` in the torch C DLPack extension with `TORCH_VERSION >= 2.6`, since these enum values don't exist in older PyTorch.

None — no new public API; this is a compatibility change.

## Impact
- API: none
- Behavioral: Package now installable on Python 3.8
- Flags/config: `requires-python` changed from `>=3.9` to `>=3.8`; cibuildwheel builds `cp38-*`; ruff/mypy target `py38`
- Data formats/schemas: none
