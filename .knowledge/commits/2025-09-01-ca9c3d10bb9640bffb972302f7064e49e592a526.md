# Introduce weak reference counting to the FFI ABI for future cycle-breaking support
## TL;DR
- Adds weak reference counting to `TVMFFIObject`, growing the header from 16 to 24 bytes: `uint32_t weak_ref_count` (new) + `uint64_t strong_ref_count` (widened from `int32_t ref_counter`).
- Introduces `WeakObjectPtr<T>` smart pointer with `lock()` (CAS-based promotion) and `expired()` semantics, mirroring `std::weak_ptr`.
- Changes the deleter signature from `void(*)(TVMFFIObject*)` to `void(*)(TVMFFIObject*, int flags)` with a bitmask (`kTVMFFIObjectDeleterFlagBitMaskStrong`, `kTVMFFIObjectDeleterFlagBitMaskWeak`, `kTVMFFIObjectDeleterFlagBitMaskBoth`) to separate destruction from memory deallocation.
- Renames `TVMFFIObjectFree` to `TVMFFIObjectDecRef` and adds `TVMFFIObjectIncRef`.

## Key Exports

**Enum `TVMFFIObjectDeleterFlagBitMask`** (C/C++ shared, `c_api.h`):
```c
enum TVMFFIObjectDeleterFlagBitMask : int32_t {
  kTVMFFIObjectDeleterFlagBitMaskStrong = 1 << 0,  // call destructor, don't free memory
  kTVMFFIObjectDeleterFlagBitMaskWeak   = 1 << 1,  // free memory block
  kTVMFFIObjectDeleterFlagBitMaskBoth   = 0x3,      // common case: destroy + free
};
```

**Struct `TVMFFIObject`** (changed, `c_api.h`):
```c
typedef struct TVMFFIObject {
  int32_t  type_index;        // unchanged
  uint32_t weak_ref_count;    // NEW (was upper half of ref_counter)
  uint64_t strong_ref_count;  // WIDENED from int32_t ref_counter
  union {
    void (*deleter)(struct TVMFFIObject* self, int flags);  // CHANGED: added flags param
    int64_t __ensure_align;
  };
} TVMFFIObject;  // 24 bytes (was 16)
```

**Class `WeakObjectPtr<T>`** (new, `object.h`):
```cpp
template <typename T>
class WeakObjectPtr {
public:
  WeakObjectPtr();
  WeakObjectPtr(std::nullptr_t);
  WeakObjectPtr(const ObjectPtr<T>&);       // from strong ptr
  WeakObjectPtr(const WeakObjectPtr<T>&);   // copy
  WeakObjectPtr(WeakObjectPtr<T>&&);        // move
  template<typename U> WeakObjectPtr(const WeakObjectPtr<U>&);  // upcast copy
  template<typename U> WeakObjectPtr(const ObjectPtr<U>&);      // upcast from strong
  ~WeakObjectPtr();                          // DecWeakRef

  ObjectPtr<T> lock() const;                 // CAS-based TryPromoteWeakPtr -> strong or nullptr
  void reset();
  void swap(WeakObjectPtr<T>&);
  int use_count() const;                     // strong ref count (0 if expired)
  bool expired() const;                      // data_==nullptr || use_count()==0

  WeakObjectPtr<T>& operator=(const WeakObjectPtr<T>&);
  WeakObjectPtr<T>& operator=(WeakObjectPtr<T>&&);
private:
  Object* data_ = nullptr;
};
```

**Functions (C API)**:
| Old name | New name | Signature |
|----------|----------|-----------|
| `TVMFFIObjectFree` | `TVMFFIObjectDecRef` | `(TVMFFIObjectHandle) -> int` |
| _(new)_ | `TVMFFIObjectIncRef` | `(TVMFFIObjectHandle) -> int` |

**Typedef** (changed, `memory.h`):
```cpp
typedef void (*FObjectDeleter)(TVMFFIObject* obj, int flags);  // was (TVMFFIObject* obj)
```

**Private methods on `Object`** (new/changed, `object.h`):
- `IncWeakRef()` -- atomic increment of `weak_ref_count`
- `DecWeakRef()` -- atomic decrement; calls `deleter(_, kTVMFFIObjectDeleterFlagBitMaskWeak)` when it reaches 0
- `TryPromoteWeakPtr() -> bool` -- CAS loop on `strong_ref_count`; returns true if promoted (count was >0)
- `DecRef()` -- rewritten: on strong reaching 0, checks if `weak_ref_count == 1` (common case) to call deleter once with `kTVMFFIObjectDeleterFlagBitMaskBoth`; otherwise splits into strong-delete then weak-decrement

## Impact
- API: **Breaking**. `TVMFFIObjectFree` renamed to `TVMFFIObjectDecRef`. All callers (Cython `base.pxi`, `object.pxi`, `dtype.pxi`) updated. Deleter signature changed from `(TVMFFIObject*)` to `(TVMFFIObject*, int)` -- any custom allocator or deleter must be updated.
- Behavioral: `TVMFFIObject` grows from 16 to 24 bytes. The `static_assert` in `type_traits.h` and `test_c_ffi_abi.cc` updated from `sizeof(TVMFFIObject) == 16` to `== 24`. Allocation now initializes `weak_ref_count = 1` alongside `strong_ref_count = 1`.
- Flags/config: New `TVMFFIObjectDeleterFlagBitMask` enum governs deleter behavior.
- Data formats/schemas: ABI version bumped (`0.1.0a5` -> `0.1.0a6`).

## Design Elements
Design elements this commit consumes:
- **Object refcounting** ([0003-object-system.md](../designs/0003-object-system.md)) -- `IncRef`/`DecRef` atomic operations, `ObjectPtr<T>` lifecycle.
- **TVMFFIObject header** ([0001-c-abi-layer.md](../designs/0001-c-abi-layer.md)) -- 16-byte struct layout (now 24-byte).
- **Memory allocation** ([0007-memory-allocation.md](../designs/0007-memory-allocation.md)) -- `SimpleObjAllocator::Handler<T>::Deleter_` and `ObjAllocatorBase::make_object`.
- **Cython C API bindings** -- `base.pxi` extern declarations, `object.pxi` `__dealloc__`, `dtype.pxi` DataType string conversion.

Design elements this commit produces:
- **Weak reference counting protocol**: A new two-counter system (strong u64 + weak u32) with bitmask-dispatched deleter, enabling future cycle-breaking patterns.
- **`WeakObjectPtr<T>`**: A weak smart pointer type with `lock()`/`expired()` semantics.
- **`TVMFFIObjectDeleterFlagBitMask`**: A C ABI enum controlling whether deleter should destroy the object, free memory, or both.
- **`TVMFFIObjectIncRef`/`TVMFFIObjectDecRef`**: Explicit inc/dec C API functions (replacing the asymmetric `TVMFFIObjectFree`).

## Usage Examples

**Creating and using a weak pointer (from test_object.cc)**:
```cpp
// Create a strong pointer
ObjectPtr<TIntObj> strong = make_object<TIntObj>(42);
// Create a weak pointer from it
WeakObjectPtr<TIntObj> weak(strong);

// Lock to get a strong reference (CAS-based promotion)
ObjectPtr<TIntObj> locked = weak.lock();
assert(locked != nullptr);
assert(locked->value == 42);
assert(strong.use_count() == 2);  // strong + locked

// After all strong refs die, weak becomes expired
strong.reset();
locked.reset();
assert(weak.expired());
assert(weak.lock() == nullptr);
```

**Deleter flag dispatch (from memory.h)**:
```cpp
// Inside SimpleObjAllocator::Handler<T>::Deleter_:
static void Deleter_(TVMFFIObject* objptr, int flags) {
  T* tptr = ObjectUnsafe::RawObjectPtrFromUnowned<T>(objptr);
  if (flags & kTVMFFIObjectDeleterFlagBitMaskStrong) {
    tptr->T::~T();  // destroy object, keep memory alive
  }
  if (flags & kTVMFFIObjectDeleterFlagBitMaskWeak) {
    delete reinterpret_cast<StorageType*>(tptr);  // free memory
  }
}
```
