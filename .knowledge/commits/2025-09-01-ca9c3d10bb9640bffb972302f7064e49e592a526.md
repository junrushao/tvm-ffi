# Introduce weak reference counting to FFI ABI with WeakObjectPtr and two-phase deletion
## TL;DR
- Adds weak reference counter (`weak_ref_count: uint32`) to the `TVMFFIObject` header, growing it from 16 bytes to 24 bytes, and changes `strong_ref_count` from `int32` to `uint64`.
- Introduces `WeakObjectPtr<T>` smart pointer with `lock()` (CAS-based promotion), `expired()`, copy/move semantics, and weak ref counting.
- Changes the deleter signature from `(TVMFFIObject*)` to `(TVMFFIObject*, int flags)` with a `TVMFFIObjectDeleterFlagBitMask` enum for two-phase deletion (destructor vs. memory free).
- Renames C API `TVMFFIObjectFree` to `TVMFFIObjectDecRef` and adds `TVMFFIObjectIncRef`.

## Impact
- API: **Breaking ABI change** -- `TVMFFIObject` grows from 16 to 24 bytes, affecting all code that uses `sizeof(TVMFFIObject)` for pointer arithmetic (NDArray DLTensor offset, field accessors). `TVMFFIObjectFree` renamed to `TVMFFIObjectDecRef`. Deleter function pointer signature changed (added `int flags` parameter).
- Behavioral: `DecRef` now implements two-phase deletion: destructor runs when strong count hits zero, memory freed when weak count also hits zero. Common path (no weak refs) optimized to single deleter call with `kBoth` flag.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
From `tests/cpp/test_object.cc` -- basic WeakObjectPtr lifecycle:
```cpp
// Create strong pointer, wrap in weak
ObjectPtr<TIntObj> strong = make_object<TIntObj>(42);
WeakObjectPtr<TIntObj> weak(strong);

// Lock while alive: succeeds
ObjectPtr<TIntObj> locked = weak.lock();
assert(locked != nullptr);
assert(locked->value == 42);
assert(strong.use_count() == 2);  // strong + locked

// Drop all strong refs: weak expires
strong.reset();
locked.reset();
assert(weak.expired());
assert(weak.lock() == nullptr);  // promotion fails
```
