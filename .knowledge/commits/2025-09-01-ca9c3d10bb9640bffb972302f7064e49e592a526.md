# Introduce weak reference counting to Object ABI with split strong/weak lifecycle
## TL;DR
- Adds weak reference counting to `TVMFFIObject` header: `ref_counter: int32` is replaced by `strong_ref_count: uint64` + `weak_ref_count: uint32`, growing the header from 16 to 24 bytes.
- Introduces `WeakObjectPtr<T>` smart pointer with `lock()` / `expired()` semantics (analogous to `std::weak_ptr`) and a CAS-based `TryPromoteWeakPtr` for thread-safe promotion.
- Splits the deleter signature from `void(*)(TVMFFIObject*)` to `void(*)(TVMFFIObject*, int flags)` with a `TVMFFIObjectDeleterFlagBitMask` enum to separate object destruction (strong=0) from memory deallocation (weak=0), enabling deferred memory freeing while weak refs remain alive.
- Renames C API symbol `TVMFFIObjectFree` to `TVMFFIObjectDecRef` and adds `TVMFFIObjectIncRef`.

## Key Exports

```python
# --- C ABI changes (c_api.h) ---

class TVMFFIObjectDeleterFlagBitMask(IntEnum):
    """Bitmask controlling deleter behavior on ref-count transitions."""
    kTVMFFIObjectDeleterFlagBitMaskStrong = 1 << 0  # Strong rc -> 0: call destructor, do NOT free memory
    kTVMFFIObjectDeleterFlagBitMaskWeak   = 1 << 1  # Weak rc -> 0: free memory block
    kTVMFFIObjectDeleterFlagBitMaskBoth   = 0x3     # Both -> 0 simultaneously (common case optimization)
    # Interacts with: FObjectDeleter signature, SimpleObjAllocator.Deleter_
    # Invariant: strong flag triggers ~T() destructor only; weak flag triggers memory deallocation only
    # Extension: new flags can be added in upper bits without breaking ABI

class TVMFFIObject:
    """C-level object header. CHANGED: 16 bytes -> 24 bytes."""
    type_index: int32              # Runtime type ID (unchanged)
    weak_ref_count: uint32         # NEW: weak reference counter (u32 to keep header at 24 bytes)
    strong_ref_count: uint64       # CHANGED: was ref_counter: int32, now uint64
    deleter: Callable[[TVMFFIObject, int], None]  # CHANGED: added flags parameter
    # Invariant: sizeof == 24, 8-byte aligned
    # Invariant: newly allocated objects start with strong_ref_count=1, weak_ref_count=1
    # Invariant: strong rc=0 triggers destructor (~T); weak rc=0 triggers memory free
    # Invariant: the implicit weak_ref_count=1 is decremented when strong rc reaches 0
    # Interacts with: Object.IncRef/DecRef, WeakObjectPtr.IncWeakRef/DecWeakRef

# Old signature: void (*deleter)(TVMFFIObject* self)
# New signature: void (*deleter)(TVMFFIObject* self, int flags)
FObjectDeleter = Callable[[TVMFFIObject, int], None]
    # Interacts with: TVMFFIObjectDeleterFlagBitMask, SimpleObjAllocator handlers

def TVMFFIObjectIncRef(obj: TVMFFIObjectHandle) -> int: ...
    # NEW: Increase strong reference count
    # Interacts with: Object.IncRef

def TVMFFIObjectDecRef(obj: TVMFFIObjectHandle) -> int: ...
    # RENAMED from TVMFFIObjectFree: Decrease strong reference count
    # Interacts with: Object.DecRef, two-phase deletion protocol

# --- C++ Object changes (object.h) ---

class WeakObjectPtr(Generic[T]):
    """Weak smart pointer for Object. Does not prevent destruction, only keeps memory alive."""
    data_: Object  # raw pointer, nullable

    def __init__(self, other: Union[ObjectPtr[T], WeakObjectPtr[T], None]): ...
        # Increments weak_ref_count (NOT strong_ref_count)
    def lock(self) -> Optional[ObjectPtr[T]]: ...
        # CAS-based promotion: atomically increments strong_ref_count only if > 0
        # Returns ObjectPtr if still alive, None if expired
        # Interacts with: Object.TryPromoteWeakPtr (CAS loop)
    def expired(self) -> bool: ...
        # True if data_ is None or strong_ref_count == 0
    def reset(self) -> None: ...
        # Decrements weak_ref_count, may trigger memory free
    def use_count(self) -> int: ...
        # Returns strong_ref_count (0 if expired)
    # Invariant: holding a WeakObjectPtr keeps memory block alive but object may be destructed
    # Invariant: lock() is the ONLY safe way to obtain a strong reference from a weak one
    # Extension: supports polymorphic construction (WeakObjectPtr<Base> from ObjectPtr<Derived>)
    # Interacts with: ObjectPtr<T> (bidirectional friend), Object.IncWeakRef/DecWeakRef
```

## Impact
- API: **Breaking** -- `TVMFFIObjectFree` renamed to `TVMFFIObjectDecRef`; `TVMFFIObjectIncRef` added. `FObjectDeleter` signature gains `int flags` parameter. All existing deleters must be updated. Cython bindings updated correspondingly.
- Behavioral: `TVMFFIObject` header grows from 16 to 24 bytes; `strong_ref_count` widens from `int32` to `uint64`. Memory deallocation is now deferred while weak references exist. `make_object<T>` initializes `weak_ref_count=1` as an implicit weak ref owned by the strong count.
- Flags/config: none
- Data formats/schemas: Object binary layout changes (header size 16->24), affects any code using `sizeof(TVMFFIObject)` for pointer arithmetic (e.g., NDArray DLTensor offset).

- **TVMFFIObject header layout** (`.knowledge/designs/0001-c-abi.md`): Extends the 16-byte header to 24 bytes with split counters.
- **Object.IncRef/DecRef protocol** (`.knowledge/designs/0002-object-system.md`): Extends with weak ref counting and two-phase deletion.
- **SimpleObjAllocator / FObjectDeleter** (`.knowledge/designs/0002-object-system.md`): Modified deleter signature and handler implementations.
- **Cython bindings** (`python/tvm_ffi/cython/`): Consumes C API symbol names for object lifecycle.

Design elements this commit produces:
- **TVMFFIObjectDeleterFlagBitMask** enum: New C ABI enum controlling two-phase deletion behavior.
- **WeakObjectPtr<T>**: New C++ smart pointer type with weak reference semantics.
- **TryPromoteWeakPtr**: CAS-based atomic promotion from weak to strong reference.
- **Two-phase deletion protocol**: Strong rc=0 triggers destructor; weak rc=0 triggers memory free. Optimized common case where both reach 0 simultaneously.
- **TVMFFIObjectIncRef / TVMFFIObjectDecRef**: Renamed and expanded C API for reference management.

## Usage Examples
Constructing and using a weak reference to break potential cycles (from `tests/cpp/test_object.cc`):

```cpp
// Create a strong reference
ObjectPtr<TIntObj> strong = make_object<TIntObj>(42);
// Create a weak reference (does NOT increment strong_ref_count)
WeakObjectPtr<TIntObj> weak(strong);

// Lock to get a strong reference (CAS-based, thread-safe)
if (ObjectPtr<TIntObj> locked = weak.lock()) {
    assert(locked->value == 42);
    assert(strong.use_count() == 2);  // strong + locked
}

// After strong refs die, weak is expired but memory is still valid
strong.reset();
assert(weak.expired());
assert(weak.lock() == nullptr);
// Memory freed when weak is destructed (DecWeakRef)
```
