# Add TypeSchema type converter with function-pointer dispatch

## TL;DR
- Adds `convert()`, `check_value()`, `try_convert()`, `try_check_value()` methods to `TypeSchema` for Python-side type checking matching C++ FFI marshal path.
- Architecture: `_TypeConverter` cdef class with C function pointer dispatch — each call is a single indirect C function call with zero Python overhead.
- 1032-line `type_check.pxi` with 20+ leaf/composite converter functions; 3399-line test suite; 241-line C++ header `tvm_ffi_type_converter.h`.

## Key Exports

```python
class TypeSchema:
    converter: _TypeConverter  # NEW cached_property — lazy-built C function pointer converter
    def convert(self, value: Any) -> Any: ...
        # Interacts with: _TypeConverter._dispatch_fn (C function pointer)
        # Invariant: accepts all 10 FFI marshal protocols
    def check_value(self, value: Any) -> Any: ...
        # Like convert but verifies type without coercion
    def try_convert(self, value: Any) -> tuple[bool, Any]: ...
    def try_check_value(self, value: Any) -> tuple[bool, Any]: ...

# _TypeConverter (cdef class, internal):
#   _dispatch_fn: C function pointer set once at build time
#   Supports: POD types, Object subtypes (ancestor-chain check), Optional, Union,
#   containers (Array, List, Map, Dict), Callable, Tuple, Any
#   Uses iterative __tvm_ffi_value__ unwrap (depth limit 64) to prevent C stack overflow

# _ORIGIN_TO_TYPE_INDEX: dict mapping origin strings to C ABI type indices
# _ORIGIN_TYPE_INDEX_STRUCTURAL = -2  # sentinel for Optional/Union
# _ORIGIN_TYPE_INDEX_UNKNOWN = -3     # sentinel for unresolved origins
```

## Impact
- API: `TypeSchema` gains 4 new methods (`convert`, `check_value`, `try_convert`, `try_check_value`).
- Behavioral: Python-side type checking now mirrors C++ FFI marshal path exactly.
- Flags/config: None.
- Data formats/schemas: Extended `_TYPE_SCHEMA_ORIGIN_CONVERTER` with STL types (`std::vector`, `std::optional`, etc.).

## Usage Examples

```python
from tvm_ffi.core import TypeSchema
schema = TypeSchema.from_json_str('{"origin": "int"}')
result = schema.convert(42)       # returns 42
result = schema.convert(3.14)     # converts float to int
ok, val = schema.try_convert("x") # ok=False, conversion failed
```
