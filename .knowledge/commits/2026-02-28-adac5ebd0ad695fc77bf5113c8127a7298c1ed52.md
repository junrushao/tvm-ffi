# Add cuLaunchKernelEx support for extended launch API (cluster dimensions)

## TL;DR
- Adds `CubinKernel::LaunchEx(void** args, const LaunchConfig& config)` method for launching CUDA kernels via the extended launch API (`cuLaunchKernelEx` / `cudaLaunchKernelExC`).
- Adds `cuda_api::LaunchKernelEx` and `cuda_api::ConstructLaunchConfig` unified API functions that abstract driver vs runtime API differences.
- Enables cluster dimension launch attributes (SM90+ / Hopper) via `LaunchConfig`.

## Key Exports

**`CubinKernel::LaunchEx`** (`cubin_launcher.h`):
```cpp
cuda_api::ResultType LaunchEx(void** args, const cuda_api::LaunchConfig& config);
```

**`cuda_api::LaunchKernelEx`** (`internal/unified_api.h`):
```cpp
inline ResultType LaunchKernelEx(KernelHandle kernel, void** args, const LaunchConfig& config);
// Driver API: cuLaunchKernelEx(&config, kernel, args, nullptr)
// Runtime API: cudaLaunchKernelExC(&config, kernel, args)
```

**`cuda_api::ConstructLaunchConfig`** (`internal/unified_api.h`):
```cpp
inline ResultType ConstructLaunchConfig(
    KernelHandle kernel, StreamHandle stream, uint32_t smem_size,
    dim3 grid, dim3 block, int cluster_dim,
    LaunchConfig& config, LaunchAttrType& attr);
// Populates config; if cluster_dim > 1, sets cluster dimension launch attribute
```

## Impact
- API: New public methods on `CubinKernel` and `cuda_api` namespace. Additive only.
- Behavioral: none for existing code paths
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```cpp

cuda_api::LaunchAttrType attr;
cuda_api::ConstructLaunchConfig(kernel.GetHandle(), stream, smem,
                                 grid, block, /*cluster_dim=*/4, config, attr);
kernel.LaunchEx(args, config);
```
