# Add cuLaunchKernelEx support for extended kernel launch
## TL;DR
- Adds `LaunchKernelEx`, `ConstructLaunchConfig` to the CUDA unified API for extended kernel launch features (e.g., SM90+ cluster dimensions).
- Adds `CubinKernel::LaunchEx` method.
- Adds Python test exercising LaunchEx via compiled C++ extension.

## Key Exports

```python
# C++ API additions:
# cuda_api::LaunchKernelEx(kernel, args, config) -> ResultType
# cuda_api::ConstructLaunchConfig(kernel, stream, smem, grid, block, cluster_dim, config, attr) -> ResultType
# CubinKernel::LaunchEx(args, config) -> ResultType
# Interacts with: cuLaunchKernelEx (driver API) / cudaLaunchKernelExC (runtime API)
# Extension: cluster_dim > 1 enables SM90+ cluster launch
```

## Impact
- API: New `LaunchEx` method on `CubinKernel`, new `LaunchKernelEx`/`ConstructLaunchConfig` free functions.
- Behavioral: Enables cluster-based kernel launches on SM90+ GPUs.
- Flags/config: None
- Data formats/schemas: None
