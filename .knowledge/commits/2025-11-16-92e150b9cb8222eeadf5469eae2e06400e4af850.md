# Add `__all__` generation to stubgen and refactor codegen helpers into dataclass-based utils

## TL;DR
- Adds a new `__all__` block kind to `tvm-ffi-stubgen` that auto-generates `__all__` export lists from registered global functions and object types.
- Refactors codegen internals: extracts `generate_func_signature` into `FuncInfo.gen()`, object-level logic into `ObjectInfo`, and type schemas into `NamedTypeSchema` -- all in `utils.py`. Removes `collect_ty_maps()` from `analysis.py` (inlined into `cli.py`).
- Adds comprehensive unit tests for stubgen core (`tests/python/test_stubgen.py`, 361 lines) enabling testing without CLI invocation.

## Impact
- API: `collect_global_funcs()` return type changed from `dict[str, list[str]]` to `dict[str, list[FuncInfo]]`. `generate_func_signature()` removed (replaced by `FuncInfo.gen()`). `collect_ty_maps()` removed (inlined). These are internal APIs within the `stub` subpackage.
- Behavioral: New `__all__` block kind enables proper Python module exporting for stubgen-managed files. The pipeline now has a Stage 2.4 that fills `__all__` blocks.
- Flags/config: none
- Data formats/schemas: New marker syntax `# tvm-ffi-stubgen(begin): __all__` / `# tvm-ffi-stubgen(end)` for `__all__` generation.

## Usage Examples

Using the `__all__` directive in a module file:
```python
# In python/tvm_ffi/_ffi_api.py:

__all__ = [
    # tvm-ffi-stubgen(begin): __all__
    # tvm-ffi-stubgen(end)
]

# After running `uv run tvm-ffi-stubgen python`, expands to:
__all__ = [
    # tvm-ffi-stubgen(begin): __all__
    "Array",
    "ArrayGetItem",
    "Map",
    "String",
    # ... (all registered global funcs and object types for this file)
    # tvm-ffi-stubgen(end)
]
```

Unit-testing codegen without CLI (new capability from this commit):
```python
from tvm_ffi.core import TypeSchema
from tvm_ffi.stub.codegen import generate_all
from tvm_ffi.stub.file_utils import CodeBlock
from tvm_ffi.stub.utils import Options

code = CodeBlock(kind="global", param="all", lineno_start=1, lineno_end=2,
                 lines=["    # tvm-ffi-stubgen(begin): ...", "# tvm-ffi-stubgen(end)"])
generate_all(code, names={"tvm_ffi.foo", "bar"}, opt=Options(indent=2))
# code.lines now contains sorted, deduplicated __all__ entries
```
