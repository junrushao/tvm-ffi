# Generate __all__ for proper exporting in stubgen
## TL;DR
- Extends stubgen to generate `__all__` export lists for Python modules, enabling proper symbol exporting.
- Adds new utility functions in `stub/utils.py` for `__all__` list management.
- Adds comprehensive tests for `__all__` generation behavior.
- This is the last component before introducing whole-package stub generation.

## Key Exports

**Python Functions (stub/utils.py):**
- `generate_all_list(symbols) -> str` -- Generates a formatted `__all__` assignment from a list of symbol names.

**Directives:**
- `__all__` generation directive in stubgen markers -- Automatically populates `__all__` with exported symbols.

## Impact
- API: Stubgen now generates `__all__` lists in processed Python files.
- ABI: none
- Behavioral: Python modules processed by stubgen now have proper `__all__` for `from module import *` support.
- Flags/config: none
- Data formats/schemas: Stubgen output now includes `__all__` blocks.
