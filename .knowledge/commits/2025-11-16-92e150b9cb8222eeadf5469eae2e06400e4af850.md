# Add __all__ directive to stubgen and refactor codegen into FuncInfo/ObjectInfo classes
## TL;DR
- Introduces new `__all__` directive for stubgen (`# tvm-ffi-stubgen(begin): __all__`) that auto-generates an `__all__` list containing all global functions and object types defined in the file.
- Refactors stub codegen into `FuncInfo` and `ObjectInfo` data classes (in `utils.py`) that encapsulate function/object metadata and generation logic, replacing the previous procedural `generate_func_signature` approach.
- Moves `collect_ty_maps` logic inline into `cli.py` (removing it from `analysis.py`); `collect_global_funcs` now returns `list[FuncInfo]` objects instead of raw string lists.
- Adds `FN_NAME_MAP` constant for renaming specific functions (e.g., `__ffi_init__` -> `__c_ffi_init__`).
- Adds `TypeSchema.__init__` stub to `core.pyi`.
- Re-adds `tests/python/test_stubgen.py` (361 lines) with unit tests for the core stubgen utilities.

## Key Exports
**Classes** (in `python/tvm_ffi/stub/utils.py`):
- `FuncInfo(schema: TypeSchema, name: str)` -- wraps a global function's metadata; `gen(fn_ty_map, indent) -> str` produces the stub line.
- `ObjectInfo(type_key: str, fields: list[FieldInfo], methods: list[FuncInfo])` -- wraps an object's metadata; `gen_fields(fn_ty_map, indent) -> list[str]`, `gen_methods(fn_ty_map, indent) -> list[str]`. Static factory `from_type_key(type_key) -> ObjectInfo`.
- `FieldInfo(name: str, schema: TypeSchema)` -- field metadata wrapper.

**New CodeBlock kind**: `"__all__"` -- generates sorted `__all__` list entries.

**New constant**: `FN_NAME_MAP = {"__ffi_init__": "__c_ffi_init__"}` in `consts.py`.

**New codegen function**: `generate_all(code, all_defined, opt) -> None` in `codegen.py`.

## Impact
- API: None externally (stubgen internals only).
- Behavioral: `_ffi_api.py` now exports an `__all__` with 35 function names, making `from tvm_ffi._ffi_api import *` well-defined.
- Flags/config: None new.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Staged stubgen pipeline** ([0020-stubgen.md](../designs/0020-stubgen.md)): Extends stage 2 with a new 2.4 sub-stage for `__all__` generation.
- **FFI reflection registry** ([0009-reflection.md](../designs/0009-reflection.md)): `FuncInfo` and `ObjectInfo` query `TypeSchema` and `_lookup_or_register_type_info_from_type_key`.

Design elements this commit produces:
- **FuncInfo/ObjectInfo abstraction**: Encapsulates per-function and per-object metadata + code generation. This is the new unit of stubgen codegen.
- **`__all__` directive**: Completes the set of stubgen directives needed for whole-package generation.

## Usage Examples
```python
# In a module file:
__all__ = [
    # tvm-ffi-stubgen(begin): __all__
    "Array",
    "ArrayGetItem",
    "Map",
    # ... (auto-generated, sorted)
    # tvm-ffi-stubgen(end)
]
```
