# Initial bringup of Sphinx/Doxygen C++ API docs with header Doxygen cleanup and minor ABI fixes

## TL;DR

- Adds Sphinx C++ reference docs infrastructure: Breathe/Exhale/Doxygen pipeline under `docs/reference/cpp/`, gated by `BUILD_CPP_DOCS=1` env var.
- Adds or upgrades Doxygen `/*!` doc-comments across all public headers (`any.h`, `function.h`, `object.h`, `c_api.h`, `memory.h`, `reflection/registry.h`, containers, etc.); internal helpers hidden with `/// \cond Doxygen_Suppress`.
- Three functional changes embedded in the "docs" commit: `FObjectDeleter` signature changed from `TVMFFIObject*` to `void*`; `TVMFFITypeInfo` made C++-compatible via `#ifdef __cplusplus struct`; `SimpleObjAllocator` moved to `details::` namespace.

## Concern 1 — Docs Infrastructure

New files: `docs/reference/cpp/index.rst` (hand-written key-class table + toctree to generated/), updated `docs/conf.py` (Breathe + Exhale extensions, conditional `build_exhale` flag, Doxygen stdin config), updated `docs/Makefile` (`clean` removes `reference/cpp/generated`, `livehtml` ignores generated dir), `docs/requirements.txt` adds `exhale`/`breathe`.

## Concern 2 — Header Doxygen and Minor ABI Changes

Systematic `/*` → `/*!` upgrades and comment corrections across all public headers. Three non-doc changes:

| Change | Old | New |
|--------|-----|-----|
| `FObjectDeleter` type | `void (*)(TVMFFIObject* obj, int flags)` | `void (*)(void* obj, int flags)` |
| `TVMFFITypeInfo` struct | C-only `typedef struct TVMFFITypeInfo { ... } TVMFFITypeInfo` | `#ifdef __cplusplus struct TVMFFITypeInfo { ... }; #else typedef struct ... #endif` |
| `SimpleObjAllocator` | `tvm::ffi::SimpleObjAllocator` (public) | `tvm::ffi::details::SimpleObjAllocator` (internal) |

The `TVMFFIObject` and `TVMFFIAny` named typedef-struct names are removed (now anonymous structs), eliminating a `typedef struct TVMFFIObject { ... } TVMFFIObject` forward-declaration conflict with the C++ struct idiom.

```python
# New: typedef void (*FObjectDeleter)(void* obj, int flags)
# Interacts with: TVMFFIObject.deleter field, SimpleObjAllocator::Deleter_
# Invariant: caller casts void* to TVMFFIObject* before use (static_cast required)

# TVMFFITypeInfo: C++-compatible struct (c_api.h)
# Old: typedef struct TVMFFITypeInfo { ... } TVMFFITypeInfo;
# New:
#   #ifdef __cplusplus
#   struct TVMFFITypeInfo { ... };   // forward-declarable in C++ without typedef
#   #else
#   typedef struct TVMFFITypeInfo { ... } TVMFFITypeInfo;
#   #endif
# Interacts with: TVMFFIGetTypeInfo(), IsInstance() slow path, 0006-reflection registry
# Invariant: layout is identical in both C and C++ — only declaration differs

# SimpleObjAllocator moved to details namespace (memory.h)
# Old: tvm::ffi::SimpleObjAllocator  (public)
# New: tvm::ffi::details::SimpleObjAllocator  (internal)
# make_object<T> / make_inplace_array<A,E> remain at tvm::ffi:: (unchanged API)
```

## Impact

- API: `tvm::ffi::SimpleObjAllocator` moved to `tvm::ffi::details::SimpleObjAllocator` — any external code that directly constructed `SimpleObjAllocator` must update its namespace. `make_object<T>` is unchanged.
- Behavioral: None for normal callers. Deleter `void*` change is ABI-visible: any compiled-in `FObjectDeleter` function pointer typed as `void(*)(TVMFFIObject*, int)` must be recompiled; the cast is now explicit inside `Deleter_` using `static_cast<TVMFFIObject*>`.
- Flags/config: New `BUILD_CPP_DOCS=1` environment variable gates Doxygen/Breathe/Exhale in the Sphinx build.
- Data formats/schemas: None.

## Usage Examples

Building C++ docs:
```bash
# Install Doxygen first, then:
BUILD_CPP_DOCS=1 make livehtml
# Generates docs/reference/cpp/generated/ from Doxygen XML
# Without env var: Breathe is loaded but exhale doesn't run (no generated/ dir)
```

Custom deleter pattern after `FObjectDeleter` change:
```cpp
// Old (before this commit):
static void MyDeleter_(TVMFFIObject* objptr, int flags) {
    MyObj* p = details::ObjectUnsafe::RawObjectPtrFromUnowned<MyObj>(objptr);
    // ...
}

// New (after this commit):
static void MyDeleter_(void* objptr, int flags) {
    MyObj* p = details::ObjectUnsafe::RawObjectPtrFromUnowned<MyObj>(
        static_cast<TVMFFIObject*>(objptr));
    // ...
}
```
