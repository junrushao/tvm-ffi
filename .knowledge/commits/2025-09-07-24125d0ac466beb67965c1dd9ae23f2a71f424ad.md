# Initial bringup of C++ API documentation via Doxygen/Breathe/Exhale

## TL;DR
- Sets up Sphinx-integrated C++ API docs using Doxygen + Breathe + Exhale, gated behind `BUILD_CPP_DOCS=1` env var.
- Adds Doxygen `/*! \brief ... */` comments to ~30 C++ header files covering `AnyView`, `Any`, `Object`, `Function`, `Array`, `Map`, `Shape`, `Tensor`, `Tuple`, `Variant`, `String`, `Bytes`, `Error`, `Optional`, reflection classes, and `c_api.h` structs.
- Makes two minor code-level changes: (1) moves `SimpleObjAllocator` into `details::` namespace, (2) changes `FObjectDeleter` / `TVMFFIObject::deleter` signature from `(TVMFFIObject*, int)` to `(void*, int)`.

## Key Exports
None -- this commit is primarily documentation. The two code changes are internal refactors:

```python
# Code change 1: SimpleObjAllocator moved to details:: namespace
# Old: tvm::ffi::SimpleObjAllocator
# New: tvm::ffi::details::SimpleObjAllocator
# Callers (make_object, make_inplace_array_object) updated to use details:: prefix.

# Code change 2: FObjectDeleter signature changed
# Old: typedef void (*FObjectDeleter)(TVMFFIObject* obj, int flags);
# New: typedef void (*FObjectDeleter)(void* obj, int flags);
# Deleter implementations now cast `static_cast<TVMFFIObject*>(objptr)` internally.
# Also: TVMFFIObject::deleter field changed: void (*deleter)(struct TVMFFIObject*, int) -> void (*deleter)(void*, int)

# Code change 3: TVMFFITypeInfo C++/C split
# In C++: `struct TVMFFITypeInfo { ... };` (no typedef)
# In C:   `typedef struct TVMFFITypeInfo { ... } TVMFFITypeInfo;`
# Allows Doxygen to parse the struct cleanly in C++ mode.
```

## Impact
- API: The `FObjectDeleter` signature change from `(TVMFFIObject*, int)` to `(void*, int)` is a C ABI change in `c_api.h`. Custom allocator implementations must update their deleter signatures. However, this is internal-only (no external consumers known).
- Behavioral: None -- all functional behavior is preserved.
- Flags/config: New `BUILD_CPP_DOCS=1` environment variable gates C++ doc generation in the Sphinx build.
- Data formats/schemas: None.

## Usage Examples
Build C++ docs:
```bash
BUILD_CPP_DOCS=1 make livehtml
```

The `docs/reference/cpp/index.rst` provides a navigable C++ API reference organized by:
1. Key Classes table (Function, Any, AnyView, Object, ObjectRef, Tensor, etc.)
2. Header Organization table (`tvm/ffi/`, `tvm/ffi/container/`, `tvm/ffi/reflection/`, `tvm/ffi/extra/`)
3. Auto-generated Full API Index via Exhale tree view
