# Initial bringup of C++ API docs via Doxygen/Breathe/Exhale

## TL;DR
- Adds C++ API reference docs to the Sphinx site using the Breathe + Exhale pipeline (Doxygen under the hood), gated behind `BUILD_CPP_DOCS=1`.
- Adds Doxygen-style doc comments (`/*! \brief ... */`) to nearly every public class, method, constructor, field, enum, and typedef across all `include/tvm/ffi/` headers (26 header files touched).
- Moves `SimpleObjAllocator` into `details` namespace, changes `FObjectDeleter` parameter from `TVMFFIObject*` to `void*`, and wraps internal implementation symbols with `/// \cond Doxygen_Suppress` to hide them from generated docs.

## Key Exports
None produced. This commit does not introduce new public API types or functions. It documents existing API surface and adjusts internal symbols for doc-generation compatibility.

**ABI-level changes in support of docs:**

- **`FObjectDeleter` typedef** (changed, `include/tvm/ffi/memory.h`):
  ```cpp
  // Before:
  typedef void (*FObjectDeleter)(TVMFFIObject* obj, int flags);
  // After:
  typedef void (*FObjectDeleter)(void* obj, int flags);
  ```

- **`TVMFFIObject::deleter` field** (changed, `include/tvm/ffi/c_api.h`):
  ```cpp
  // Before:
  void (*deleter)(struct TVMFFIObject* self, int flags);
  // After:
  void (*deleter)(void* self, int flags);
  ```

- **`TVMFFIObject` and `TVMFFIAny` struct tags** (changed, `include/tvm/ffi/c_api.h`):
  Removed named struct tags (`typedef struct TVMFFIObject { ... } TVMFFIObject` -> anonymous `typedef struct { ... } TVMFFIObject`).

- **`TVMFFITypeInfo`** (changed, `include/tvm/ffi/c_api.h`):
  Split into `#ifdef __cplusplus` branches: `struct TVMFFITypeInfo { ... };` in C++ vs `typedef struct TVMFFITypeInfo { ... } TVMFFITypeInfo;` in C.

- **`SimpleObjAllocator`** (moved, `include/tvm/ffi/memory.h`):
  Moved from `tvm::ffi` into `tvm::ffi::details` namespace. Public `make_object<T>` and `make_inplace_array_object<T, E>` now call `details::SimpleObjAllocator`.

## Impact
- API: `FObjectDeleter` parameter type changed from `TVMFFIObject*` to `void*`. Any custom allocator that defines a deleter function must update its signature. `SimpleObjAllocator` moved to `details::SimpleObjAllocator` (but public `make_object`/`make_inplace_array_object` remain unchanged).
- Behavioral: None. The deleter implementations add a `static_cast<TVMFFIObject*>(objptr)` inside, so runtime behavior is identical.
- Flags/config: New `BUILD_CPP_DOCS=1` environment variable gates C++ doc generation during Sphinx builds.
- Data formats/schemas: None.
