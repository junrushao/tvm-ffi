# Initial bringup of C++ API docs via Doxygen/Exhale/Breathe Sphinx integration

## TL;DR
- Adds Sphinx C++ docs infrastructure: `exhale`/`breathe` extensions, Doxygen integration gated by `BUILD_CPP_DOCS=1`, new `docs/reference/cpp/index.rst` with key class listing and header organization table.
- Adds Doxygen `/*! \brief ... */` comments to nearly all public constructors, operators, type aliases, and free functions across all `include/tvm/ffi/` headers. Wraps internal details with `/// \cond Doxygen_Suppress` to hide them from generated docs.
- Two incidental code changes: moves `SimpleObjAllocator`/`ObjAllocatorBase` into `details::` namespace; changes `FObjectDeleter` signature from `TVMFFIObject*` to `void*`.

## Key Exports

The commit does not introduce new public APIs. The two minor code-level changes are:

```python
# CHANGE 1: FObjectDeleter signature (include/tvm/ffi/memory.h)
# Old: typedef void (*FObjectDeleter)(TVMFFIObject* obj, int flags);
# New:
FObjectDeleter = Callable[[void_ptr, int], None]  # was (TVMFFIObject*, int)
# Interacts with: SimpleObjAllocator::Handler::Deleter_, all custom allocators
# Invariant: callee casts void* back to TVMFFIObject* (or concrete type) internally

# CHANGE 2: SimpleObjAllocator moved to details:: namespace (include/tvm/ffi/memory.h)
# Old: tvm::ffi::SimpleObjAllocator
# New: tvm::ffi::details::SimpleObjAllocator
# Interacts with: make_object<T>(), make_inplace_array_object<ArrayType, ElemType>()
# Note: public make_object<T>() API unchanged -- only internal allocator namespace moved

# CHANGE 3: TVMFFITypeInfo uses struct (C++) vs typedef struct (C) via #ifdef __cplusplus
# (include/tvm/ffi/c_api.h)
# Interacts with: TVMFFITypeGetOrAllocIndex, TVMFFIGetTypeInfo
```

## Impact
- API: Minor -- `FObjectDeleter` typedef changed from `TVMFFIObject*` to `void*`; `SimpleObjAllocator` moved to `details::` namespace. Both are internal symbols unlikely to be used by downstream code.
- Behavioral: none -- all changes are documentation or namespace reorganization
- Flags/config: `BUILD_CPP_DOCS=1` environment variable gates Doxygen/Exhale doc generation
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- All core FFI types (Any, AnyView, Object, ObjectRef, Function, Array, Map, String, Bytes, Shape, Tensor, Tuple, Variant, Error, Optional) -- adds Doxygen documentation
- Reflection system (ObjectDef, GlobalDef, TypeAttrDef, AccessPath, AccessStep, ObjectCreator) -- adds Doxygen documentation
- C ABI structs (TVMFFIAny, TVMFFIObject, TVMFFIByteArray, TVMFFIShapeCell, TVMFFITypeInfo) -- fixes doc comments and param names

Design elements this commit produces:
- Sphinx C++ docs infrastructure (`docs/conf.py` exhale/breathe config, `docs/reference/cpp/index.rst`)
- `docs/reference/cpp/index.rst` key classes listing -- canonical reference of the most important C++ types

## Usage Examples
Building the C++ docs:
```bash
# From docs/ directory
BUILD_CPP_DOCS=1 make livehtml
```
