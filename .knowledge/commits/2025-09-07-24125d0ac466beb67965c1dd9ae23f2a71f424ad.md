# Initial bringup of C++ API docs via Doxygen/Exhale/Breathe with Doxygen comment annotations across all public headers

## TL;DR
- Sets up the Sphinx C++ documentation pipeline using Doxygen, Exhale, and Breathe, gated behind `BUILD_CPP_DOCS=1` environment variable.
- Adds Doxygen `/*! \brief ... */` comments to all public C++ headers (constructors, operators, methods, fields, enums) and uses `/// \cond Doxygen_Suppress` to hide internal details from generated docs.
- Makes minor ABI refinements: `FObjectDeleter` parameter changed from `TVMFFIObject*` to `void*`, `SimpleObjAllocator`/`ObjAllocatorBase` moved into `details` namespace, and `TVMFFIObject`/`TVMFFIAny` converted to anonymous C structs.

## Key Exports

```python
# --- ABI change: FObjectDeleter signature ---
# Old: typedef void (*FObjectDeleter)(TVMFFIObject* obj, int flags)
# New: typedef void (*FObjectDeleter)(void* obj, int flags)
FObjectDeleter = Callable[[void_ptr, int], None]
# Invariant: callee must static_cast<TVMFFIObject*>(obj) internally
# Interacts with: SimpleObjAllocator.Handler<T>.Deleter_, c_api.h TVMFFIObject.deleter

# --- Namespace move: allocators hidden in details ---
# Old: tvm::ffi::SimpleObjAllocator, tvm::ffi::ObjAllocatorBase
# New: tvm::ffi::details::SimpleObjAllocator, tvm::ffi::details::ObjAllocatorBase
# Public wrappers unchanged:
def make_object(T, *args) -> ObjectPtr[T]: ...
    # Interacts with: details.SimpleObjAllocator
def make_inplace_array_object(ArrayType, ElemType, num_elems, *args) -> ObjectPtr[ArrayType]: ...
    # Interacts with: details.SimpleObjAllocator

# --- C ABI struct changes ---
# TVMFFIObject: changed from `typedef struct TVMFFIObject { ... } TVMFFIObject`
#               to `typedef struct { ... } TVMFFIObject` (anonymous struct tag)
# TVMFFIAny:    same anonymous struct change
# TVMFFITypeInfo: now uses `struct TVMFFITypeInfo { ... }` in C++ mode,
#                 `typedef struct TVMFFITypeInfo { ... } TVMFFITypeInfo` in C mode

# --- Docs infrastructure (new) ---
# docs/conf.py: exhale_args, breathe_projects, exhaleDoxygenStdin configuration
# docs/reference/cpp/index.rst: curated key classes table + full API index
# docs/requirements.txt: exhale, breathe added
```

## Impact
- API: **Minor breaking** -- `FObjectDeleter` parameter type changed from `TVMFFIObject*` to `void*`; custom deleter implementations need update. `SimpleObjAllocator` moved to `details::` namespace; direct users need qualification change.
- Behavioral: None -- all runtime behavior unchanged.
- Flags/config: `BUILD_CPP_DOCS=1` environment variable added to enable C++ doc generation.
- Data formats/schemas: None.
