# Remove deprecated _type_has_method_sequal_reduce/_shash_reduce flags from Object base class
## TL;DR
- Removes two `static constexpr bool` fields (`_type_has_method_sequal_reduce`, `_type_has_method_shash_reduce`) from `Object` in `include/tvm/ffi/object.h`, completing the migration from compile-time method-presence flags to the reflection-based `SEqual`/`SHash` mechanism.
- Removes two `std::cout` debug prints from `TCustomFuncObj::SEqual` in `tests/cpp/testing_object.h`.

## Key Exports
None

## Impact
- API: The removed `static constexpr bool` fields were compile-time defaults (`false`) on `Object`. Any downstream subclass that overrode `_type_has_method_sequal_reduce` or `_type_has_method_shash_reduce` would need to remove those overrides as well. Within TVM FFI itself, no callers remain.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none
