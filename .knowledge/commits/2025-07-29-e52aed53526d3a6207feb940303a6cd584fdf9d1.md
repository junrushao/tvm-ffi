# Remove legacy SEqualReduce/SHashReduce static markers from Object base class
## TL;DR
- Removes two dead `static constexpr bool` fields (`_type_has_method_sequal_reduce`, `_type_has_method_shash_reduce`) from the `Object` base class in `include/tvm/ffi/object.h`. These legacy markers are fully superseded by the new reflection-based structural equality/hash mechanism.
- Removes debug `std::cout` prints from `TCustomFuncObj::SEqual` in the test helper `tests/cpp/testing_object.h`.

## Key Exports
None -- purely subtractive. Two static constants removed from `Object`:

```python
# REMOVED from Object base class:
# _type_has_method_sequal_reduce: bool = False  # legacy marker, no longer used
# _type_has_method_shash_reduce: bool = False    # legacy marker, no longer used
# Superseded by: reflection::ObjectDef<T>.def_method("SEqual", ...) / .def_method("SHash", ...)
```

## Impact
- API: Minimal -- the removed constants were `false` defaults in the base class. Any subclass that overrode them was already migrated in prior commits (#18156, #18165, #18166).
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none
