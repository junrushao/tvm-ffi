# Remove vestigial SEqualReduce/SHashReduce boolean fields from Object base class
## TL;DR
- Removes two `static constexpr bool` fields (`_type_has_method_sequal_reduce`, `_type_has_method_shash_reduce`) from the `Object` base class, completing the phase-out of the old equality/hashing dispatch mechanism in favor of reflection-based `__s_equal__`/`__s_hash__` type attributes.
- Cleans up debug `std::cout` prints from `TCustomFuncObj::SEqual` in test helpers.

None

## Impact
- API: none -- the removed fields were internal compile-time constants (`static constexpr`) on the base `Object` class, not part of any public or cross-language API surface.
- Behavioral: none -- the old boolean flags were no longer consulted by any dispatch path; the reflection system (`TypeAttrDef::def("__s_equal__", ...)`) is the active mechanism.
- Flags/config: none
- Data formats/schemas: none
