# Remove legacy SEqualReduce/SHashReduce static flags from Object base class
## TL;DR
- Removes `_type_has_method_sequal_reduce` and `_type_has_method_shash_reduce` static constexpr booleans from the `Object` base class in `include/tvm/ffi/object.h`. These were plug-in hooks for the old structural equality/hash mechanism, now superseded by the reflection system (`ffi/reflection`).
- Removes two `std::cout` debug prints from `TCustomFuncObj::SEqual` in `tests/cpp/testing_object.h`.

## Key Exports
None -- removal-only commit with no new API surface.

## Impact
- API: Subtypes that override `_type_has_method_sequal_reduce` or `_type_has_method_shash_reduce` will fail to compile if they reference the base class defaults. This is intentional -- such subtypes should migrate to the reflection-based `SEqual`/`SHash` mechanism.
- Behavioral: None. The removed fields were static compile-time constants not affecting runtime behavior.
- Flags/config: None.
- Data formats/schemas: None.

- **FFI Reflection** (`0007-ffi-reflection`): the commit message references the reflection mechanism as the replacement for the old SEqualReduce/SHashReduce plug-in hooks.
