# Introduce mutable Dict container
## TL;DR
- Adds `Dict` as a mutable key-value container (counterpart to immutable `Map`), reusing `map_base.h` internals.
- Full Python bindings with `__setitem__`, `__delitem__`, `clear()`, `pop()`, `update()`, etc.
- Integrates Dict into serialization, deep copy, structural equal/hash, and repr systems.

## Key Exports

```python
class DictObj(Object):
    """Mutable dictionary container backed by DenseMapNode."""
    # Interacts with: map_base.h (DenseMapNode), serialization, structural equal/hash
    # Invariant: keys support AnyHash/AnyEqual protocol

class Dict(ObjectRef):
    def __init__(self, data: dict | None = None) -> None: ...
    def __setitem__(self, key: Any, value: Any) -> None: ...
    def __delitem__(self, key: Any) -> None: ...
    def __getitem__(self, key: Any) -> Any: ...
    def __len__(self) -> int: ...
    def __contains__(self, key: Any) -> bool: ...
    def clear(self) -> None: ...
    def pop(self, key: Any, default: Any = ...) -> Any: ...
    def update(self, other: dict) -> None: ...
    # Interacts with: ffi.DictCreate, ffi.DictSetItem, ffi.DictDelItem global funcs
```

## Impact
- API: New `Dict` type in `tvm_ffi` namespace with full mutable dict API.
- Behavioral: None for existing code.
- Flags/config: None
- Data formats/schemas: Dict is serializable/deserializable.

```python
import tvm_ffi
d = tvm_ffi.Dict({"a": 1, "b": 2})
d["c"] = 3
del d["a"]
assert len(d) == 2
```
