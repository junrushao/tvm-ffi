# Introduce mutable Dict container with shared-reference semantics, backed by MapBaseObj

## TL;DR
- Adds `Dict<K,V>` (`DictObj`, type index 76) as a mutable map alongside the existing copy-on-write `Map<K,V>`; all handles sharing the same `DictObj` see mutations immediately with no copy-on-write.
- Refactors `MapBaseObj::InsertMaybeReHash` signature (returns `ObjectPtr<Object>` instead of mutating via `ObjectPtr*`) and adds `InplaceSwitchTo` to enable `Dict::Set` to rehash in-place on the shared object without COW.
- Extends all extra subsystems (serialization, deep-copy, structural equal/hash) and the Python layer (`tvm_ffi.Dict`, registered as `"ffi.Dict"`) to handle `kTVMFFIDict = 76`.

## Impact
- API: `MapBaseObj::InsertMaybeReHash` signature changed from `(KVType&&, ObjectPtr<Object>*)` to `(KVType&&, const ObjectPtr<Object>&) -> ObjectPtr<Object>`. All callers (`Map::Set`, internal rehash loop) updated. This is an internal/friend API — no public C ABI change.
- Behavioral: `Map::Set` now handles the returned pointer rather than mutating via pointer-to-pointer; semantics unchanged for Map users. Dict::Set mutates the shared object in-place; no COW.
- Flags/config: none
- Data formats/schemas: `kTVMFFIDict = 76` added to `TVMTypeIndex` enum in `c_api.h`. Serialized JSON graphs now include `"type": "ffi.Dict"` nodes. Pickle round-trip supported via JSON serialization path.

## Design Elements
Design elements this commit consumes:
- `MapBaseObj` / `MapObj` (0007-containers) — reuses hash-map internals (`DenseMapBaseObj`, `SmallMapBaseObj`, iteration, `KVType`) as the shared base
- `ObjectRef` pattern (0002-object-system) — `DictObj`/`Dict<K,V>` follow `FooObj`/`Foo` convention
- `TypeTraits<T>` customization point (0008-type-traits) — `MapTypeTraitsBase` reused; `kOtherTypeIndex=kTVMFFIMap` enables cross-conversion
- `TVMTypeIndex` / `c_api.h` (0001-c-abi) — adds `kTVMFFIDict = 76`
- Extra subsystem dispatch switches (0009-structural-eq-hash, 0010-json-serialization) — extended with `kTVMFFIDict` case
- `MISSING` sentinel and `KeysView`/`ValuesView`/`ItemsView` (0007-containers, 0024-kwargs-wrapper) — reused with `iter_functor_getter` param
- `register_object("ffi.Dict")` (0013-python-package) — standard Python registration

Design elements this commit produces:
- **`Dict<K,V>` / `DictObj`** — new mutable container type (type index 76) with shared-mutation semantics; sibling to `Map<K,V>`.
- **`MapBaseObj::InplaceSwitchTo`** — new internal protocol for in-place storage transfer after rehash, enabling Dict to remain mutation-consistent across all aliases.
- **`InsertMaybeReHash` return-value contract** — changed from void/out-pointer to returning a new container or null; consumers must check the return.
- **`kTVMFFIDict = 76`** — new stable type index in the C ABI enum.
- **Cross-conversion between `Dict<K,V>` and `Map<K,V>`** — `kOtherTypeIndex` in `TypeTraits` allows passing a `Dict` where a `Map` is expected (and vice versa), with element-level type-check on mismatch.

## Usage Examples

Cross-layer trace — C++ definition to Python call:

```python
# C++ side (container.cc) registers:
#   "ffi.Dict"(*flat_kvs) -> Dict<Any,Any>
#   "ffi.DictSetItem"(d, k, v) -> void
#   "ffi.DictForwardIterFunctor"(n) -> Function

# Python usage:
import tvm_ffi

# Construction
d = tvm_ffi.Dict({"a": 1, "b": 2})
d["c"] = 3          # calls _ffi_api.DictSetItem → DictObj.Set → InsertMaybeReHash → InplaceSwitchTo
assert len(d) == 3

# Shared-reference semantics (no COW unlike Map)
d2 = d
d["d"] = 4
assert d2["d"] == 4   # d2 sees the mutation immediately

# Exception-free lookup
val = d.get("missing", 42)   # calls DictGetItemOrMissing → returns MISSING → default returned

# Cross-conversion: Dict accepted where Map expected
from tvm_ffi.testing import _ffi_api as testing
result = testing.schema_id_map_str_int(d)   # TypeTraits kOtherTypeIndex path
assert isinstance(result, tvm_ffi.Map)
```
