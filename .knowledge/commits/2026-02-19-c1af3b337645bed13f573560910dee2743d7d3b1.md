# Introduce mutable Dict container
## TL;DR
- Adds `include/tvm/ffi/container/dict.h` implementing `Dict` as a mutable key-value container (mutable counterpart to `Map`).
- Extends C ABI with Dict type index and operations.
- Full Python bindings, serialization, structural equality/hash, deep copy, and repr support.
- Comprehensive C++ and Python tests.

## Impact
- API: New `Dict` container type in C++, Python, and C ABI.
- Flags/config: None.
- Data formats/schemas: New type index for Dict in C ABI.
