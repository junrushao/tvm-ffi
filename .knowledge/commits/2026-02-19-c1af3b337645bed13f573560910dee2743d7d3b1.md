# Introduce mutable Dict container sharing MapBaseObj with immutable Map

## TL;DR
- Adds `Dict<K,V>` / `DictObj` as a mutable dictionary container (type index `kTVMFFIDict=76`, type key `"ffi.Dict"`), sharing the `MapBaseObj` base class with immutable `Map<K,V>`.
- Dict mutates in-place (no COW). All handles sharing the same `DictObj` see mutations immediately, analogous to `List<T>` vs `Array<T>`.
- Full Python binding as `MutableMapping[K,V]` with `__setitem__`, `__delitem__`, `pop`, `clear`, `update`, sentinel-based `get`.
- Refactors `InsertMaybeReHash` to return `ObjectPtr<Object>` (new container if rehash needed, nullptr otherwise) instead of mutating a pointer in-place, enabling Dict's `InplaceSwitchTo` pattern.
- Extracts `MapTypeTraitsBase` CRTP for shared type-traits logic between `Map` and `Dict`.

**`Dict<K,V>`** (mutable, shared-reference semantics):
```cpp
template <typename K, typename V> class Dict : public ObjectRef {
  Dict();                                    // creates empty dict
  V at(const K& key) const;
  V operator[](const K& key) const;
  size_t size() const;
  size_t count(const K& key) const;
  bool empty() const;
  void clear();                             // in-place clear
  void Set(const K& key, const V& value);   // in-place insert/update
  void erase(const K& key);                 // in-place erase
  std::optional<V> Get(const K& key) const; // returns nullopt if not found
  iterator begin() const;
  iterator end() const;
  iterator find(const K& key) const;
};
```

**`MapBaseObj::InplaceSwitchTo`** (new method):
```cpp
void MapBaseObj::InplaceSwitchTo(ObjectPtr<Object>&& other);
// Steals storage from `other` into `this`, resetting `other`.
// Used by Dict::Set when rehashing produces a new container.
```

**`InsertMaybeReHash` signature change** (breaking internal API):
```cpp
// Before: static void InsertMaybeReHash(KVType&&, ObjectPtr<Object>* map);
// After:  static ObjectPtr<Object> InsertMaybeReHash(KVType&&, const ObjectPtr<Object>& map);
// Returns new container if rehash needed, nullptr otherwise.
```

## Impact
- API: New `Dict<K,V>` / `DictObj` type added. `kTVMFFIDict=76` is a new type index.
- API: `InsertMaybeReHash` signature changed from `void` + `ObjectPtr<Object>*` to `ObjectPtr<Object>` return + `const ObjectPtr<Object>&`. All internal call sites in `map.h`, `map_base.h`, and `stl.h` updated.
- Behavioral: `TypeTraits<Map<K,V>>::TryCastFromAnyView` now also accepts `kTVMFFIDict` (and vice versa for Dict accepting Map). This enables cross-conversion between Map and Dict.
- Flags/config: none
- Data formats/schemas: Serialization (`extra/serialization.cc`), deep copy (`extra/deep_copy.cc`), repr print (`extra/repr_print.cc`), structural equal/hash updated to handle `kTVMFFIDict`.

## Design Elements
Design elements this commit consumes:
- `MapBaseObj` hierarchy (produced by 5a6b211) -- Dict inherits the same base as Map
- Object system (`Object`, `ObjectRef`, type index registration)
- Global function registry (`register_global_func` / `def`)
- Sentinel-based `get` pattern (`GetMissingObject` / `MISSING`) -- reused for Dict.get
- `TypeTraits` system for FFI type checking and cross-conversion
- Python `@register_object` decorator

Design elements this commit produces:
- **`DictObj` / `Dict<K,V>` container** -- mutable map with shared-reference semantics, type index 76
- **`MapBaseObj::InplaceSwitchTo`** -- method for stealing storage between map containers (enables Dict mutation without changing ObjectPtr identity)
- **`MapTypeTraitsBase` CRTP** -- shared type-traits logic for map-like containers, enabling Map<->Dict cross-conversion
- **`InsertMaybeReHash` return-value pattern** -- returns new container instead of mutating pointer, enabling callers to decide how to apply the result (COW swap for Map, InplaceSwitchTo for Dict)

## Usage Examples
```cpp
// C++ Dict creation and in-place mutation
Dict<String, int> d;
d.Set("a", 1);
d.Set("b", 2);
assert(d.size() == 2);
assert(d.at("a") == 1);

// Shared reference semantics -- no COW
Dict<String, int> d2 = d;  // shared
d2.Set("c", 3);            // mutation visible to both
assert(d.size() == 3);     // d also sees the new entry

// Optional get
auto val = d.Get("missing");  // returns std::nullopt

// Erase and clear
d.erase("a");
d.clear();
```

```python
# Python Dict usage
import tvm_ffi

d = tvm_ffi.Dict({"a": 1, "b": 2})
d["c"] = 3
assert len(d) == 3
assert d["a"] == 1

val = d.get("missing", -1)  # returns -1

del d["b"]
popped = d.pop("c")  # returns 3
d.clear()
```
