# Introduce mutable Dict container backed by MapBaseObj

## TL;DR
- Adds `DictObj`/`Dict<K,V>` as a mutable map variant sharing the same `MapBaseObj` base as `Map`, enabling in-place mutations visible to all handles.
- Adds `kTVMFFIDict = 76` to the C ABI type index enum and registers FFI globals (`ffi.Dict`, `ffi.DictSetItem`, etc.).
- Adds full Python `Dict` class implementing `MutableMapping[K,V]` with shared-reference semantics (no copy-on-write).

## Impact
- API: New `kTVMFFIDict = 76` type index inserted in `TVMFFITypeIndex` — additive, no renumbering of existing values. `InsertMaybeReHash` signature changed (returns `ObjectPtr<Object>` instead of void, takes `const ObjectPtr<Object>&` instead of pointer) — internal to `map_base.h`, no public caller impact.
- Behavioral: `Dict` mutations are shared-reference (no COW), contrasting with `Map`'s COW semantics. `KeysView`/`ValuesView`/`ItemsView` now accept an optional `iter_functor_getter` parameter to support both `Map` and `Dict`.
- Flags/config: none
- Data formats/schemas: `DictObj` gets serialization support (structural_equal, structural_hash, deep_copy, JSON serialization, repr_print).

## Usage Examples

```python
# Shared-reference semantics (no copy-on-write)
import tvm_ffi
d1 = tvm_ffi.Dict({"a": 1})
d2 = d1           # same underlying DictObj
d1["b"] = 2
assert d2["b"] == 2   # mutation visible through d2

# MutableMapping protocol
d = tvm_ffi.Dict({"x": 10, "y": 20})
del d["x"]
d.update({"z": 30})
assert set(d.keys()) == {"y", "z"}
```
