# Introduce mutable Dict container
## TL;DR
- Introduces `Dict` as a mutable dictionary container (complement to immutable `Map<K,V>`)
- `DictObj` with `kTVMFFIDict` type index, sharing Map's hash-table infrastructure
- Python `Dict` class implements `MutableMapping` interface
- Integrates with JSON serialization, structural equality/hashing, and ReprPrint
- Large commit: 35 files, 1691 insertions

## Key Exports
