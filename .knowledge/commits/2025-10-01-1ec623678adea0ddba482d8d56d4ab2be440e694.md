# Add ffi::TensorView as a non-owning DLTensor view for FFI function arguments

## TL;DR
- Adds `ffi::TensorView` to `include/tvm/ffi/container/tensor.h`: a non-owning view over a `DLTensor` that can be constructed from `Tensor&` or `DLTensor*` but cannot be promoted to an owning `Tensor`.
- Provides `TypeTraits<TensorView>` specialization so FFI functions can accept `TensorView` as an argument type, enabling callers to pass either `Tensor` or raw `DLTensor*` without ownership transfer.
- Updates docs, examples, and tests; bumps `pyproject.toml` version.

## Key Exports

```python
# include/tvm/ffi/container/tensor.h

class TensorView:
    """Non-owning view of a DLTensor. Stores a copy of DLTensor by value."""
    # Constructors:
    #   TensorView(const Tensor&)   — copies DLTensor from owning Tensor
    #   TensorView(const DLTensor*) — copies DLTensor from raw pointer
    #   TensorView(Tensor&&) = delete  — prevents accidental move from owned Tensor
    # Invariant: user must ensure underlying DLTensor (data, shape, strides) outlives TensorView
    def shape(self) -> ShapeView: ...
    def strides(self) -> ShapeView: ...  # Invariant: strides != nullptr
    def data_ptr(self) -> void_ptr: ...
    def ndim(self) -> int32: ...
    def numel(self) -> int64: ...
    def dtype(self) -> DLDataType: ...
    def IsContiguous(self) -> bool: ...
    def operator_arrow(self) -> const DLTensor*: ...  # operator->
    # Interacts with: TypeTraits<TensorView>, Tensor::operator->, ShapeView

class TypeTraits_TensorView:  # TypeTraits<TensorView> specialization
    storage_enabled = False  # cannot be stored in Any (no ownership)
    field_static_type_index = TypeIndex.kTVMFFIDLTensorPtr
    # CopyToAnyView: sets type_index=kTVMFFIDLTensorPtr, v_ptr=DLTensor*
    # CheckAnyStrict: type_index == kTVMFFIDLTensorPtr only
    # TryCastFromAnyView: accepts kTVMFFIDLTensorPtr OR kTVMFFITensor (implicit promotion)
    #   Interacts with: TVMFFITensorGetDLTensorPtr C API
    # MoveToAny / MoveFromAny: deliberately NOT defined (storage_enabled=false)
    # Interacts with: AnyView conversion pipeline, function arg dispatch
```

## Impact
- API: New class `ffi::TensorView` in `include/tvm/ffi/container/tensor.h`. Fully additive; no existing APIs changed.
- Behavioral: FFI functions with `TensorView` parameter now accept both `kTVMFFIDLTensorPtr` and `kTVMFFITensor` type indices via `TryCastFromAnyView`, enabling broad caller compatibility.
- Flags/config: Version bump in `pyproject.toml`.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `Tensor`/`TensorObj` (0006-containers) — `TensorView` copies `DLTensor` from `Tensor::operator->()`.
- `TypeTraits<T>` protocol (0005-type-traits-protocol) — `TypeTraits<TensorView>` implements `CopyToAnyView`, `CheckAnyStrict`, `TryCastFromAnyView` following the existing SFINAE specialization pattern.
- `ShapeView` (0006-containers) — `TensorView::shape()`/`strides()` return `ShapeView`.
- C ABI `TVMFFITensorGetDLTensorPtr` (0007-c-abi) — used in `TryCastFromAnyView` to extract `DLTensor*` from an owning `Tensor`.

Design elements this commit produces:
- **`ffi::TensorView`** — non-owning tensor view type with `TypeTraits` specialization. Recommended as the preferred argument type for kernel ops that do not need to retain tensor ownership. Extends the existing `Tensor`/`ShapeView` non-owning view pattern.

## Usage Examples

```cpp
// C++: kernel op accepting TensorView (from include/tvm/ffi/container/tensor.h pattern)
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one, [](ffi::TensorView x, ffi::TensorView y) -> void {
    // x, y can come from Tensor or DLTensor* callers — no ownership needed
    int64_t n = x.numel();
    const float* px = static_cast<const float*>(x.data_ptr());
    float* py = static_cast<float*>(y.data_ptr());
    for (int64_t i = 0; i < n; ++i) py[i] = px[i] + 1.0f;
});
```
