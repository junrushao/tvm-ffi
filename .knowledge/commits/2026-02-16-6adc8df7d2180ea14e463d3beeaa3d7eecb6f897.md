# Introduce StructuralKey wrapper with cached structural hash
## TL;DR
- Introduces `StructuralKey` / `StructuralKeyObj` as a wrapper class that stores a value alongside its cached structural hash, enabling efficient structural-equality-based lookups.
- Provides `std::hash<StructuralKey>` specialization and `operator==`/`operator!=` using `StructuralEqual::Equal`.
- Adds Python `StructuralKey` class with `__hash__`, `__eq__`, `key` property, and reflection-based registration. Registers `__any_hash__` and `__any_equal__` type attributes.
- Adds Python `structural_hash` and `structural_equal` utility functions.

## Key Exports

**C++ types**:
```cpp
// structural_key.h
class StructuralKeyObj : public Object {
    Any key;
    int64_t hash_i64{0};
    explicit StructuralKeyObj(Any key);
    TVM_FFI_DECLARE_OBJECT_INFO_FINAL("ffi.StructuralKey", StructuralKeyObj, Object);
};

class StructuralKey : public ObjectRef {
    explicit StructuralKey(Any key);
    bool operator==(const StructuralKey& other) const;  // hash check + StructuralEqual
    bool operator!=(const StructuralKey& other) const;
    TVM_FFI_DEFINE_OBJECT_REF_METHODS_NOTNULLABLE(StructuralKey, ObjectRef, StructuralKeyObj);
};

// std::hash specialization
namespace std { template<> struct hash<tvm::ffi::StructuralKey> { ... }; }
```

**Python** (`structural.py`):
```python
@register_object("ffi.StructuralKey")
class StructuralKey:
    key: Any
    def __hash__(self) -> int: ...
    def __eq__(self, other) -> bool: ...

def structural_hash(value: Any) -> int: ...

```

## Impact
- API: New public header `structural_key.h`. New Python module `tvm_ffi.structural`. New type key `"ffi.StructuralKey"`.
- Behavioral: StructuralKey registers `__any_hash__` and `__any_equal__` type attributes, so StructuralKey objects can be used as Map keys with structural semantics.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

## Usage Examples

```cpp
// C++
StructuralKey k1(Array<int>{1, 2, 3});
StructuralKey k2(Array<int>{1, 2, 3});
assert(k1 == k2);  // structural equality

std::unordered_map<StructuralKey, int> m;
m[k1] = 42;
assert(m[k2] == 42);
```

```python
# Python
from tvm_ffi import StructuralKey, structural_hash, structural_equal
k = StructuralKey([1, 2, 3])
d = {k: "value"}
```
