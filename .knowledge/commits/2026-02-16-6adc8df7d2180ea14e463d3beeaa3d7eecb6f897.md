# Introduce StructuralKey: a hash-cached wrapper enabling structural equality and hash as dict/map key semantics

## TL;DR
- Adds `StructuralKey` (`StructuralKeyObj` / `StructuralKey`) in `include/tvm/ffi/extra/structural_key.h`: wraps any `Any` value, pre-computes and caches its structural hash at construction time, and defines `operator==` / `std::hash<StructuralKey>` for use in `std::unordered_map` and `tvm::ffi::Map<Any, Any>`.
- Registers the type with reflection (`ObjectDef`, read-only `key` + `hash_i64` fields) and two `TypeAttrColumn` entries (`__any_hash__`, `__any_equal__`) so it participates in `Map<Any, Any>` key lookup using structural semantics.
- Exposes `StructuralKey`, `structural_equal`, `structural_hash`, and `get_first_structural_mismatch` as top-level `tvm_ffi` Python API; also registers global C++ function `ffi.StructuralEqual` (was missing before).

class StructuralKey(ObjectRef):
    """Ref wrapper for StructuralKeyObj. Usable as std::unordered_map key."""
    def __init__(self, key: Any) -> None:
        # Calls make_object<StructuralKeyObj>(key); hash computed at construction
        self.__init_handle_by_constructor__(_ffi_api.StructuralKey, key)

    def __hash__(self) -> int:
        return self.hash_i64 & 0xFFFFFFFFFFFFFFFF  # mask: int64_t→uint64_t for Python
    def __eq__(self, other: Any) -> bool:
        return isinstance(other, StructuralKey) and _ffi_api.StructuralKeyEqual(self, other)

## Impact
- API: Additive — new public `tvm_ffi.StructuralKey`, `tvm_ffi.structural_equal`, `tvm_ffi.structural_hash`, `tvm_ffi.get_first_structural_mismatch` exports; new global func `ffi.StructuralEqual` (callers using `_ffi_api.StructuralHash` already existed, `StructuralEqual` was not previously exported as a global func).
- Behavioral: `Map<Any, Any>` with `StructuralKey` keys now resolves keys by structural content rather than pointer identity.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

C++ `std::unordered_map` with structural key semantics:
```cpp
#include <tvm/ffi/extra/structural_key.h>
#include <tvm/ffi/container/array.h>
#include <unordered_map>

StructuralKey k1(Array<int>{1, 2, 3});
StructuralKey k2(Array<int>{1, 2, 3});  // structurally equal to k1
StructuralKey k3(Array<int>{1, 2, 4});

std::unordered_map<StructuralKey, int> map;
map[k1] = 10;
map[k2] = 20;  // overwrites k1 (same structural key)
map[k3] = 30;
assert(map.size() == 2);
assert(map.at(k1) == 20);
```

Python dict and `tvm_ffi.Map` with structural key semantics:
```python
import tvm_ffi

k0 = tvm_ffi.StructuralKey({"a": [1, 2], "b": [3]})
k1 = tvm_ffi.StructuralKey({"b": [3], "a": [1, 2]})  # structurally equal
k2 = tvm_ffi.StructuralKey({"a": [1, 2], "b": [4]})

# Python dict uses __hash__/__eq__
d = {k0: "val-a", k2: "val-b"}
assert d[k1] == "val-a"  # k1 matches k0 structurally

# tvm_ffi.Map uses __any_hash__/__any_equal__ TypeAttrColumn
m = tvm_ffi.Map({k0: 1, k1: 2})
assert len(m) == 1  # k0 and k1 hash to the same bucket
```
