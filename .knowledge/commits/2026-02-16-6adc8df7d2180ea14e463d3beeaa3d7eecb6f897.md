# Introduce StructuralKey wrapper with cached structural hash
## TL;DR
- Adds `StructuralKey` (C++ `StructuralKeyObj` + Python wrapper) that caches a structural hash alongside an arbitrary key value, enabling efficient structural-equality-based dict/map lookups.
- Exposes `structural_equal`, `structural_hash`, `get_first_structural_mismatch` as top-level Python APIs in new `tvm_ffi.structural` module.
- Registers `__any_hash__` / `__any_equal__` type attributes on `StructuralKeyObj` for native container integration.

## Key Exports

```python
class StructuralKeyObj:
    """Caches structural hash alongside a key value."""
    key: Any
    hash_i64: int  # Invariant: == StructuralHash::Hash(key)
    # Interacts with: StructuralEqual, StructuralHash, __any_hash__/__any_equal__ type attrs
    # Extension: used as map key with structural semantics

class StructuralKey(ObjectRef):
    """Python-side wrapper for StructuralKeyObj."""
    def __init__(self, key: Any) -> None: ...
    def __hash__(self) -> int: ...  # Returns hash_i64 masked to u64
    def __eq__(self, other: Any) -> bool: ...  # Delegates to StructuralEqual
    # Interacts with: ffi.StructuralKey (global func), ffi.StructuralKeyEqual

def structural_equal(lhs: Any, rhs: Any, map_free_vars: bool = False, skip_tensor_content: bool = False) -> bool: ...
    # Interacts with: ffi.StructuralEqual C++ global func

def structural_hash(value: Any, map_free_vars: bool = False, skip_tensor_content: bool = False) -> int: ...
    # Interacts with: ffi.StructuralHash C++ global func

def get_first_structural_mismatch(lhs: Any, rhs: Any, ...) -> tuple[AccessPath, AccessPath] | None: ...
    # Interacts with: ffi.GetFirstStructuralMismatch C++ global func
```

## Usage Examples
```python
import tvm_ffi

k0 = tvm_ffi.StructuralKey([1, 2, 3])
k1 = tvm_ffi.StructuralKey([1, 2, 3])
k2 = tvm_ffi.StructuralKey([1, 2, 4])

d = {k0: "value-a", k2: "value-b"}
assert d[k1] == "value-a"  # k1 matches k0 structurally

assert tvm_ffi.structural_equal([1, 2, 3], [1, 2, 3])
assert not tvm_ffi.structural_equal([1, 2, 3], [1, 2, 4])
h = tvm_ffi.structural_hash([1, 2, 3])
```
