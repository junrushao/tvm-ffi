# Introduce StructuralKey with cached structural hash
## TL;DR
- Adds `StructuralKeyObj`/`StructuralKey` object that wraps any value with its cached structural hash
- Provides Python `StructuralKey` class with `__eq__`/`__hash__` using structural equality/hash
- Enables using FFI objects as dictionary keys and set members with structural semantics

## Key Exports
```python
class StructuralKeyObj(Object):
    key: Any                  # The wrapped value
    hash_i64: int64           # Cached structural hash
    # Invariant: hash_i64 is computed at construction time via structural_hash

class StructuralKey(ObjectRef):
    def __init__(self, key: Any) -> None: ...
    def __eq__(self, other: "StructuralKey") -> bool: ...  # structural_equal
    def __hash__(self) -> int: ...                          # cached hash_i64
    # Interacts with: structural_equal, structural_hash, AnyHash/AnyEqual
```

- API: adds `StructuralKey` type
- Behavioral: none

## Usage Examples
```python
import tvm_ffi
key1 = tvm_ffi.StructuralKey(some_object)
key2 = tvm_ffi.StructuralKey(same_object_copy)
assert key1 == key2  # structural equality
d = {key1: "value"}  # usable as dict key
```
