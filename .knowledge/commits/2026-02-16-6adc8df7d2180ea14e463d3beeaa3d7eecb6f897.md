# Introduce StructuralKey wrapper that caches structural hash for use as dict/map key
## TL;DR
- Adds `StructuralKey` (C++ `StructuralKeyObj`/`StructuralKey` + Python `tvm_ffi.StructuralKey`) -- a hash-caching wrapper that enforces structural equality/hash semantics when used as a dictionary or `Map` key.
- Registers `__any_hash__`/`__any_equal__` TypeAttr overrides on `StructuralKeyObj` so the FFI container layer (`Map<Any, Any>`) automatically uses structural comparison.
- Adds `tvm_ffi.structural` module exposing `structural_equal`, `structural_hash`, `get_first_structural_mismatch` as top-level Python helpers, plus new FFI registrations `ffi.StructuralEqual` and `ffi.StructuralKey`.

## Impact
- API: Adds new public class `StructuralKey` and three top-level functions (`structural_equal`, `structural_hash`, `get_first_structural_mismatch`) to `tvm_ffi`. Also registers `ffi.StructuralEqual` as a new FFI global (previously only `ffi.StructuralHash` and `ffi.GetFirstStructuralMismatch` were registered).
- Behavioral: `Map<Any, Any>` now uses structural equality/hash when keys are `StructuralKey` instances, via `__any_hash__`/`__any_equal__` TypeAttr dispatch.
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces:
- **StructuralKey** -- A new Object type that wraps any value with a cached structural hash, enabling structural-equality-based dictionary key semantics across C++ (`std::unordered_map`) and Python (`dict`, `tvm_ffi.Map`).
- **`tvm_ffi.structural` module** -- New Python module consolidating structural comparison helpers previously accessible only via `_ffi_api`.
- **`ffi.StructuralEqual` FFI registration** -- The `StructuralEqual::Equal` function was previously not registered as a global FFI function; this commit exposes it.

## Usage Examples

C++ usage with `std::unordered_map`:
```cpp
#include <tvm/ffi/extra/structural_key.h>
#include <unordered_map>

StructuralKey k1(Array<int>{1, 2, 3});
StructuralKey k2(Array<int>{1, 2, 3});  // structurally equal to k1
std::unordered_map<StructuralKey, int> map;
map[k1] = 10;
map[k2] = 20;  // overwrites k1's entry
assert(map.size() == 1 && map.at(k1) == 20);
```

Python usage with `tvm_ffi.Map` and native dict:
```python
import tvm_ffi

k1 = tvm_ffi.StructuralKey({"a": [1, 2], "b": [3]})
k2 = tvm_ffi.StructuralKey({"b": [3], "a": [1, 2]})  # structurally equal
k3 = tvm_ffi.StructuralKey({"a": [1, 2], "b": [4]})

# Works with tvm_ffi.Map (via __any_hash__/__any_equal__)
m = tvm_ffi.Map({k1: 1, k2: 2, k3: 3})
assert len(m) == 2 and m[k1] == 2

# Works with Python dict (via __hash__/__eq__)
d = {k1: "a", k3: "b"}
assert d[k2] == "a"
```
