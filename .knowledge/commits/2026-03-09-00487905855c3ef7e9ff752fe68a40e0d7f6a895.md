# Fix setter error propagation, native parent layout, and setter leak
## TL;DR
- Fixes setter error propagation: type conversion errors now properly raised instead of silently swallowed.
- Fixes native parent field layout so inherited fields from C++ parent objects are correctly accessible.
- Fixes setter function reference leak in Cython.
- Adds 2480-line `test_py_class_from_fields.py` test suite for Python-defined FFI classes.
