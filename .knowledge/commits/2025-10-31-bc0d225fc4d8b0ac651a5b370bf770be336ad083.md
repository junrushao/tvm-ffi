# Add README documentation for the torch-c-dlpack-ext addon package
## TL;DR
- Adds a 26-line `addons/torch_c_dlpack_ext/README.md` describing the purpose of the `torch-c-dlpack-ext` package.
- Documents that it provides an AOT-compiled module for faster DLPack conversion, avoiding JIT compilation overhead in `tvm_ffi`.
- Notes the package will become unnecessary once PyTorch ships DLPack v1.2 support natively.
