# Add README documentation for torch-c-dlpack-ext addon package
## TL;DR
- Adds a README to `addons/torch_c_dlpack_ext/` describing the `torch-c-dlpack-ext` package: an AOT-compiled wheel that replaces the JIT compilation of the DLPack conversion module.
- Documents that this addon will become unnecessary once PyTorch ships DLPack v1.2 support natively, and that `tvm-ffi` JIT-compiles a fallback by default.
