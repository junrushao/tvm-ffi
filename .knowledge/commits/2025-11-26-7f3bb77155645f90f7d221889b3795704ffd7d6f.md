# Upgrade DLPack exchange API to pass by PyCapsule
## TL;DR
- Updates DLPack exchange API to support passing `DLManagedTensor` via PyCapsule (the standard DLPack v2 way) in addition to the legacy integer-based passing.
- Maintains backward compatibility with integer-based exchange.
- Updates both the Cython tensor path and torch-c-dlpack addon.

## Key Exports
None (internal protocol upgrade)

## Impact
- API: none (backward compatible)
- ABI: none
- Behavioral: DLPack exchange now uses PyCapsule when supported, with fallback to integer passing.
- Flags/config: none
- Data formats/schemas: DLPack exchange protocol updated to prefer PyCapsule format.
