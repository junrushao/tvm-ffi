# Upgrade DLPack exchange API to pass pointer via PyCapsule with int backward compatibility
## TL;DR
- The `__c_dlpack_exchange_api__` class attribute now supports `PyCapsule` (named `"dlpack_exchange_api"`) in addition to the legacy raw `int` pointer representation.
- Cython dispatch (`_get_dlpack_exchange_api`) accepts either type and extracts the `DLPackExchangeAPI*` pointer accordingly.
- The `tvm_ffi` Python loader eagerly upgrades legacy int pointers to PyCapsule at import time, while the `torch_c_dlpack_ext` addon still sets the attribute as int for backward compatibility with older tvm-ffi versions.

## Impact
- API: `__c_dlpack_exchange_api__` attribute type widens from `int` to `int | PyCapsule`. All existing callers that read this attribute as int continue to work because the Cython layer handles both types transparently.
- Behavioral: `load_torch_c_dlpack_extension()` in `_optional_torch_c_dlpack.py` now wraps the raw int pointer in a PyCapsule before setting the attribute, and retroactively upgrades an existing int attribute set by the `torch_c_dlpack_ext` addon.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **`DLPackExchangeAPI` struct and `__c_dlpack_exchange_api__` protocol** ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md)): the 5-function-pointer struct is unchanged; only the transport mechanism for the pointer is upgraded.
- **`TVMFFIPyArgSetterFactory_` dispatch** ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md)): the factory previously cast the attribute directly from int; now delegates to `_get_dlpack_exchange_api`.
- **`torch_c_dlpack_ext` addon** ([0012-ffi-python-package](../design-records/0012-ffi-python-package.md)): continues to set the attribute as int for backward compatibility with older tvm-ffi consumers.

Design elements this commit produces:
- **PyCapsule transport for `__c_dlpack_exchange_api__`**: mutates the protocol contract -- the attribute may now be either `int` or `PyCapsule(name="dlpack_exchange_api")`. Cython-side `_get_dlpack_exchange_api` is the single dispatch point.
- **Eager int-to-capsule upgrade**: `load_torch_c_dlpack_extension()` detects legacy int attribute and converts it in place, ensuring downstream consumers always see PyCapsule when loaded via tvm_ffi.

## Usage Examples

Before (int pointer, legacy):
```python
# torch_c_dlpack_ext sets attribute as raw int
setattr(torch.Tensor, "__c_dlpack_exchange_api__", func())  # int
```

After (PyCapsule, new path via tvm_ffi):
```python
from tvm_ffi._optional_torch_c_dlpack import _create_dlpack_exchange_api_capsule

# New loader wraps int -> PyCapsule
capsule = _create_dlpack_exchange_api_capsule(func())
setattr(torch.Tensor, "__c_dlpack_exchange_api__", capsule)

# Retroactive upgrade when addon already set int
if isinstance(torch.Tensor.__c_dlpack_exchange_api__, int):
    torch.Tensor.__c_dlpack_exchange_api__ = _create_dlpack_exchange_api_capsule(
        torch.Tensor.__c_dlpack_exchange_api__
    )
```
