# Upgrade DLPack exchange API to pass pointer by PyCapsule instead of int
## TL;DR
- Changes `__c_dlpack_exchange_api__` from raw `int` pointer to a `PyCapsule` (name `"dlpack_exchange_api"`), improving type safety and aligning with Python's C API conventions.
- Adds backward compatibility: both tvm-ffi (Cython `_get_dlpack_exchange_api`) and the addon (`_optional_torch_c_dlpack.py`) accept either `int` or `PyCapsule` and eagerly upgrade `int` to `PyCapsule`.
- Cython dispatch in `function.pxi` now calls `_get_dlpack_exchange_api()` instead of directly casting the int.

## Key Exports

**Functions (Python, new)**:

| Function | Signature | Module |
|----------|-----------|--------|
| `_create_dlpack_exchange_api_capsule` | `(ptr_as_int: int) -> PyCapsule` | `tvm_ffi._optional_torch_c_dlpack` |

**Functions (Cython, new)**:

| Function | Signature | File |
|----------|-----------|------|
| `_get_dlpack_exchange_api` | `(object dlpack_exchange_api_obj, const DLPackExchangeAPI** out_ptr) -> int` | `cython/tensor.pxi` |

Accepts either `int` (cast to pointer) or `PyCapsule` with name `"dlpack_exchange_api"` (extract via `PyCapsule_GetPointer`). Raises `ValueError` if neither.

## Impact
- API: `__c_dlpack_exchange_api__` attribute on tensor classes changes from `int` to `PyCapsule`. Backward compatible -- consumers that read an `int` value will still work because the upgrade happens eagerly on the tvm-ffi side.
- Behavioral: `load_torch_c_dlpack_extension()` now wraps the `int` pointer from the addon into a `PyCapsule` before setting it on `torch.Tensor`. If the addon already set it as an `int`, tvm-ffi upgrades it in-place.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **DLPack interop layer** ([0017-dlpack-interop.md](../designs/0017-dlpack-interop.md)): The `__c_dlpack_exchange_api__` attribute and the three-tier loading strategy.
- **DLPackExchangeAPI struct** ([ADR-0021](../ADRs/0021-dlpack-exchange-api-struct.md)): The struct whose pointer is being wrapped.
- **Type-cached dispatch** ([0015-python-ffi-call-dispatch.md](../designs/0015-python-ffi-call-dispatch.md)): `TVMFFIPyArgSetterFactory_` reads the attribute to set up the DLPack exchange setter.

Design elements this commit produces:
- **PyCapsule-based exchange API pointer** (mutator): Changes the transport mechanism for the `DLPackExchangeAPI*` pointer from raw integer to `PyCapsule` with name `"dlpack_exchange_api"`. This is a contract change to the exchange API attribute type.

## Usage Examples

```python
# Before (int-based, still accepted for backward compat):
setattr(torch.Tensor, "__c_dlpack_exchange_api__", int_ptr)

# After (PyCapsule-based, new default):
capsule = _create_dlpack_exchange_api_capsule(int_ptr)
setattr(torch.Tensor, "__c_dlpack_exchange_api__", capsule)
```
