# Add py_class decorator for Python-defined FFI dataclasses

## TL;DR
- New `@py_class` decorator in `python/tvm_ffi/dataclasses/py_class.py` (459 lines): creates Python-defined FFI types from class annotations without requiring C++ type definitions.
- Two-phase registration: Phase 1 allocates C-level type index; Phase 2 resolves type hints and registers fields. Deferred forward-reference resolution via `_PENDING_CLASSES`.
- `field()` helper with `default`, `default_factory`, `init`, `repr`, `hash`, `compare`, `kw_only`; `KW_ONLY` sentinel; `__post_init__` support.

## Key Exports

```python
# python/tvm_ffi/dataclasses/py_class.py
@dataclass_transform(eq_default=False, order_default=False)
def py_class(
    init: bool = True,
    repr: bool = True,
    eq: bool = False,
    order: bool = False,
    unsafe_hash: bool = False,
) -> Callable[[type], type]:
    """Register a Python-defined FFI type with dataclass-style field annotations.
    # Invariant: class must subclass Object (directly or indirectly).
    # Phase 1: allocate C type index + register with global registry.
    # Phase 2: resolve annotations → TypeSchema → Field objects; register fields.
    # Deferred: if forward reference not yet defined, retry after each successful Phase 2.
    # Interacts with: _install_dataclass_dunders, _add_class_attrs, ffi.MakeFFINew, ffi.MakeFieldSetter
    """

def field(
    default=MISSING,
    default_factory=MISSING,
    init: bool = True,
    repr: bool = True,
    hash: bool | None = None,  # tri-state: None = same as compare
    compare: bool = True,
    kw_only: bool = False,
) -> Field: ...
    # Interacts with: Field descriptor, py_class phase 2

KW_ONLY: ClassVar  # sentinel for positional→keyword-only boundary
# (re-exported from dataclasses.KW_ONLY on Python 3.10+)
```

## Impact
- API: New `@py_class`, `field()`, `KW_ONLY` exported from `tvm_ffi.dataclasses`.
- Behavioral: Pure-Python types can now participate in the FFI type system (serialization, deepcopy, repr, structural eq/hash) without C++ code.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
from tvm_ffi.dataclasses import py_class, field, KW_ONLY
from tvm_ffi import Object

@py_class(eq=True, unsafe_hash=True)
class Point(Object):
    type_key = "mymod.Point"
    x: float
    y: float = field(default=0.0)

p = Point(1.0, y=2.0)
assert p.x == 1.0
assert p == Point(1.0, 2.0)
```
