# Remove `using ffi::Tuple` re-export from `tvm` namespace
## TL;DR
- Removes the `using ffi::Tuple;` convenience alias from the `tvm` namespace in `include/tvm/ffi/container/tuple.h`.
- Callers using `tvm::Tuple` must switch to `tvm::ffi::Tuple`.
- Part of a broader "phase out ObjectPath in favor of AccessPath" effort (PR #18192), but the only change in tvm-ffi is this namespace cleanup. The commit message scope is broader than the actual diff.

## Key Exports
None -- this commit only removes an existing re-export. No new API surface.

## Impact
- API: Minor breaking change for C++ callers using `tvm::Tuple` -- must switch to `tvm::ffi::Tuple`. Other containers (`Array`, `Map`, `Variant`, `String`, `Bytes`, `Optional`) still retain their `using ffi::` re-exports.
- Behavioral: none
- Flags/config: none
- Data formats/schemas: none
