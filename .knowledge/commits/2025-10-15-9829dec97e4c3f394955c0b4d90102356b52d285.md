# Remove local DLPackTensorAllocator typedef and rename to DLPackManagedTensorAllocator from upstream dlpack.h
## TL;DR
- Removes the locally-defined `DLPackTensorAllocator` typedef and forward declaration of `DLManagedTensorVersioned` from `c_api.h`, since these are now provided by the upstream `dlpack.h` (as `DLPackManagedTensorAllocator`).
- Renames all internal references from `DLPackTensorAllocator` to `DLPackManagedTensorAllocator` across C++, Cython, and Rust.
- Removes unused `DLPackFromPyObject` and `DLPackToPyObject` typedefs from `tvm_ffi_python_helpers.h` and their Cython `ctypedef` declarations.

| Before | After |
|--------|-------|
| `DLPackTensorAllocator` (in `c_api.h`) | `DLPackManagedTensorAllocator` (from `dlpack.h`) |
| `DLPackFromPyObject` typedef (in `tvm_ffi_python_helpers.h`) | removed |
| `DLPackToPyObject` typedef (in `tvm_ffi_python_helpers.h`) | removed |
| `DLPackTensorAllocator` ctypedef (in `base.pxi`) | removed |
| `DLPackFromPyObject` ctypedef (in `base.pxi`) | removed |
| `DLPackToPyObject` ctypedef (in `base.pxi`) | removed |
| `EnvContext::GetDLPackTensorAllocator()` | `EnvContext::GetDLPackManagedTensorAllocator()` |
| `EnvContext::SetDLPackTensorAllocator()` | `EnvContext::SetDLPackManagedTensorAllocator()` |
| `rust DLPackTensorAllocator` type alias | `rust DLPackManagedTensorAllocator` type alias |
| `Tensor::FromDLPackAlloc(DLPackTensorAllocator, ...)` | `Tensor::FromDLPackAlloc(DLPackManagedTensorAllocator, ...)` |

## Key Exports
**Renames** (type alias, all layers):

| Old Name | New Name | Location |
|----------|----------|----------|
| `DLPackTensorAllocator` | `DLPackManagedTensorAllocator` | `dlpack.h` (upstream), `c_env_api.h`, `tensor.h`, `c_env_api.rs` |

**Removed** (no longer needed, now provided by upstream `dlpack.h` or unused):
- `DLPackTensorAllocator` typedef from `c_api.h`
- `DLManagedTensorVersioned` forward declaration from `c_api.h`
- `DLPackFromPyObject` typedef from `tvm_ffi_python_helpers.h`
- `DLPackToPyObject` typedef from `tvm_ffi_python_helpers.h`
- Corresponding Cython `ctypedef` declarations for all three from `base.pxi`

**Signatures updated** (parameter types changed from `DLPackTensorAllocator` to `DLPackManagedTensorAllocator`):
- `TVMFFIEnvSetTensorAllocator(DLPackManagedTensorAllocator, int, DLPackManagedTensorAllocator*) -> int`
- `TVMFFIEnvGetTensorAllocator() -> DLPackManagedTensorAllocator`
- `Tensor::FromDLPackAlloc(DLPackManagedTensorAllocator, ShapeView, DLDataType, DLDevice) -> Tensor`

**Rust type alias**: `pub type DLPackManagedTensorAllocator = unsafe extern "C" fn(...)` (renamed from `DLPackTensorAllocator`)

## Impact
- API: All code using `DLPackTensorAllocator` must switch to `DLPackManagedTensorAllocator`. Affects C/C++, Cython, and Rust callers.
- ABI: None. The C API function names (`TVMFFIEnvSetTensorAllocator`, `TVMFFIEnvGetTensorAllocator`) and their binary signatures are unchanged -- only the typedef name for the function pointer type changed.
- Behavioral: None. Pure rename/cleanup.
- Flags/config: None.
- Data formats/schemas: None.
