# Rename DLPackTensorAllocator to DLPackManagedTensorAllocator and remove obsolete DLPack typedefs

## TL;DR
- Renames `DLPackTensorAllocator` to `DLPackManagedTensorAllocator` across all layers (C ABI, C++ headers/impl, Python/Cython, Rust) to align with the latest DLPack naming conventions.
- Removes obsolete forward declaration of `DLManagedTensorVersioned` and the `DLPackTensorAllocator` typedef from `c_api.h`, plus removes superseded `DLPackFromPyObject`/`DLPackToPyObject` typedefs from Python/Cython helpers.
- Fixes an unused variable warning in Rust macro code (`m` -> `_m`).

| Old Name | New Name / Status |
|---|---|
| `DLPackTensorAllocator` (typedef in `c_api.h`) | **Removed** from `c_api.h`; now `DLPackManagedTensorAllocator` (defined in dlpack headers) |
| `DLPackTensorAllocator` (C++ usage) | `DLPackManagedTensorAllocator` |
| `DLPackTensorAllocator` (Rust type alias) | `DLPackManagedTensorAllocator` |
| `DLPackFromPyObject` (C typedef in helpers) | **Removed** (superseded by `DLPackExchangeAPI`) |
| `DLPackToPyObject` (C typedef in helpers) | **Removed** (superseded by `DLPackExchangeAPI`) |
| `DLPackFromPyObject` (Cython ctypedef) | **Removed** |
| `DLPackToPyObject` (Cython ctypedef) | **Removed** |
| `DLPackTensorAllocator` (Cython ctypedef) | **Removed** |
| `EnvContext::GetDLPackTensorAllocator()` | `EnvContext::GetDLPackManagedTensorAllocator()` |
| `EnvContext::SetDLPackTensorAllocator()` | `EnvContext::SetDLPackManagedTensorAllocator()` |
| `TestDLPackTensorAllocator` (test) | `TestDLPackManagedTensorAllocator` |
| `TestDLPackTensorAllocatorError` (test) | `TestDLPackManagedTensorAllocatorError` |

## Impact
- API: **Breaking rename** -- `DLPackTensorAllocator` no longer exists; all callers must use `DLPackManagedTensorAllocator`. Affects C/C++ code using the typedef, Rust code using the type alias, and any Cython code referencing the old ctypedefs.
- Behavioral: none (pure rename, no semantic change)
- Flags/config: none
- Data formats/schemas: none
