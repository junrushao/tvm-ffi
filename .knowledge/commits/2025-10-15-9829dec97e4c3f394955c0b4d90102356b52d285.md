# Rename DLPackTensorAllocator to DLPackManagedTensorAllocator and remove obsolete DLPack typedefs across all language layers

## TL;DR
- Renames `DLPackTensorAllocator` → `DLPackManagedTensorAllocator` in all layers (C++, Cython, Rust) following migration to the latest DLPack version.
- Removes now-obsolete typedefs `DLPackFromPyObject`, `DLPackToPyObject` from `tvm_ffi_python_helpers.h` and `base.pxi` (already superseded by `DLPackExchangeAPI` in commit 22a78943).
- Removes `DLManagedTensorVersioned` forward-decl and `DLPackTensorAllocator` typedef from `c_api.h` (the TODO-guarded workarounds are no longer needed since dlpack.h was updated).

| Old name | New name | Scope |
|---|---|---|
| `DLPackTensorAllocator` | `DLPackManagedTensorAllocator` | C++ public headers, Rust, Cython, internal |
| `DLPackFromPyObject` (typedef) | *(removed)* | `tvm_ffi_python_helpers.h`, `base.pxi` |
| `DLPackToPyObject` (typedef) | *(removed)* | `tvm_ffi_python_helpers.h`, `base.pxi` |
| `DLManagedTensorVersioned` forward-decl | *(removed)* | `c_api.h` (was guarded by TODO) |
| `EnvContext::GetDLPackTensorAllocator` | `EnvContext::GetDLPackManagedTensorAllocator` | internal `env_context.cc` |
| `EnvContext::SetDLPackTensorAllocator` | `EnvContext::SetDLPackManagedTensorAllocator` | internal `env_context.cc` |
| `TestDLPackTensorAllocator` (test fn) | `TestDLPackManagedTensorAllocator` | `tests/cpp/test_tensor.cc` |
| `TestDLPackTensorAllocatorError` (test fn) | `TestDLPackManagedTensorAllocatorError` | `tests/cpp/test_tensor.cc` |

## Impact
- API: **Breaking** — `DLPackTensorAllocator` renamed to `DLPackManagedTensorAllocator` in `c_api.h`, `c_env_api.h`, and Rust `c_env_api.rs`. Any external code using the old typedef by name must update. `DLPackFromPyObject`/`DLPackToPyObject` typedefs removed from `tvm_ffi_python_helpers.h` (internal header, callers already migrated to `DLPackExchangeAPI`).
- Behavioral: None — pure rename, no functional change.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- `DLPackManagedTensorAllocator` protocol (formerly `DLPackTensorAllocator`) — defined in `c_api.h`, used by `TVMFFIEnvSetTensorAllocator`/`TVMFFIEnvGetTensorAllocator` (see `.knowledge/design-records/0012-env-api.md`)
- `Tensor::FromDLPackAlloc` — factory accepting the allocator, part of `.knowledge/design-records/0007-containers.md`
- `DLPackExchangeAPI` struct — the superseding protocol for `DLPackFromPyObject`/`DLPackToPyObject` (`.knowledge/design-records/0016-py-ffi-call-dispatch.md`)

Design elements this commit produces:
- `DLPackManagedTensorAllocator` typedef — replaces `DLPackTensorAllocator` as the canonical name for the DLPack environment-controlled tensor allocator function pointer in the public C ABI.
