# Rename DLPackTensorAllocator to DLPackManagedTensorAllocator and remove stale DLPack forward declarations
## TL;DR
- Renamed `DLPackTensorAllocator` to `DLPackManagedTensorAllocator` across all layers (C API, C++ implementation, Cython, Rust).
- Removed stale forward declarations and typedefs from `c_api.h` and `tvm_ffi_python_helpers.h` that are now provided by the updated dlpack.h: `DLManagedTensorVersioned` forward decl, `DLPackFromPyObject`, `DLPackToPyObject`.
- Fixed a Rust clippy lint: unused variable `m` to `_m` in `rust/tvm-ffi-macros/src/utils.rs`.

| Old name | New name / Status |
|----------|-------------------|
| `DLPackTensorAllocator` (typedef in c_api.h) | **Removed** from c_api.h (now in dlpack.h as `DLPackManagedTensorAllocator`) |
| `DLPackTensorAllocator` (Rust type alias) | `DLPackManagedTensorAllocator` |
| `DLPackFromPyObject` (typedef in helpers.h) | **Removed** (in dlpack.h) |
| `DLPackToPyObject` (typedef in helpers.h) | **Removed** (in dlpack.h) |
| `DLManagedTensorVersioned` (forward decl in c_api.h) | **Removed** (in dlpack.h) |
| `EnvContext::GetDLPackTensorAllocator()` | `EnvContext::GetDLPackManagedTensorAllocator()` |
| `EnvContext::SetDLPackTensorAllocator()` | `EnvContext::SetDLPackManagedTensorAllocator()` |
| `Tensor::FromDLPackAlloc(DLPackTensorAllocator, ...)` | `Tensor::FromDLPackAlloc(DLPackManagedTensorAllocator, ...)` |

## Key Exports
None (rename only, no new API surface)

## Impact
- API: **Breaking** -- `DLPackTensorAllocator` typedef removed from `c_api.h`; replaced by `DLPackManagedTensorAllocator` (now from dlpack.h). C/C++ code using the old name must update.
- Behavioral: none
