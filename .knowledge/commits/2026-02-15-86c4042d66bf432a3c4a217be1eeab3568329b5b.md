# Rename ffi.MapGetMissingObject to ffi.GetInvalidObject and promote MISSING singleton to core
## TL;DR
- Removes global function `ffi.MapGetMissingObject` and adds `ffi.GetInvalidObject` with broader semantic scope (not Map-specific).
- Moves `MISSING` singleton initialization from `container.py` (`_ffi_api.MapGetMissingObject()` at module load) to `cython/core.pyx` (`_get_global_func("ffi.GetInvalidObject")()` after `Function` is registered), then re-exports from `core` into `container`.
- Adds `MISSING: Object` to `core.pyi` type stub.

## Key Exports

```python
# Renamed global function:
# "ffi.MapGetMissingObject" REMOVED → "ffi.GetInvalidObject" ADDED

# Python: MISSING singleton now lives in core, not container
# from tvm_ffi.core import MISSING  (initialized in core.pyx at C extension load)
# Interacts with: MapGetItemOrMissing (returns MISSING on key miss), Map.get()
# Invariant: identity singleton — always compare with `is MISSING`, never equality
```

## Impact
- API: Global function `ffi.MapGetMissingObject` removed; `ffi.GetInvalidObject` added. Any code calling `_ffi_api.MapGetMissingObject()` or relying on `container.MISSING` via that path must update to use `ffi.GetInvalidObject` or import `MISSING` from `core`.
- Behavioral: `MISSING` singleton now initialized at Cython core module load (not lazily from container.py). The singleton identity and `MapGetItemOrMissing` behavior are unchanged.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `Map.get()` / `MapGetItemOrMissing` / sentinel pattern (0006-ffi-containers) — the MISSING singleton is used by `Map.get()` to distinguish miss from None value.

Design elements this commit produces:
- Renames `ffi.MapGetMissingObject` → `ffi.GetInvalidObject` (global registry)
- Promotes `MISSING` from `container` to `core` module scope

## Usage Examples
Before:
```python
from tvm_ffi._ffi_api import MapGetMissingObject
MISSING = MapGetMissingObject()
result = some_map.get(key, default)  # MISSING used internally
```
After:
```python
from tvm_ffi.core import MISSING  # singleton initialized at core load
result = some_map.get(key, default)  # unchanged from user perspective
```
