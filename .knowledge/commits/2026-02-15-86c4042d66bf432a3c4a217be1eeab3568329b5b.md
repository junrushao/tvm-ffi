# Add ffi.GetInvalidObject global function replacing ffi.MapGetMissingObject
## TL;DR
- Renames `ffi.MapGetMissingObject` to `ffi.GetInvalidObject` (more general-purpose name for the singleton sentinel).
- Initializes Python `MISSING` constant in `core.pyx` via `_get_global_func` after `Function` is registered; re-exports from `container.py`.
- Adds `MISSING: Object` type stub in `core.pyi`.

## Key Exports

**Renamed global function**:
- `ffi.MapGetMissingObject` -> `ffi.GetInvalidObject` (returns the singleton sentinel `ObjectRef`)

**Python**:
- `MISSING: Object` -- singleton sentinel available in `tvm_ffi.core` and `tvm_ffi.container`

## Impact
- API: `ffi.MapGetMissingObject` removed, replaced by `ffi.GetInvalidObject`. Downstream callers using the old name must update.
- Behavioral: none (same singleton object)
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Containers / Map sentinel** (`.knowledge/designs/0008-containers.md`): `GetMissingObject()` sentinel for `Map.get`.

Design elements this commit produces:
- **`ffi.GetInvalidObject`**: General-purpose name for the singleton sentinel, usable beyond just Map.

## Usage Examples

```python
from tvm_ffi import MISSING
val = my_map.get("key")
if val is MISSING:
    print("key not found")
```
