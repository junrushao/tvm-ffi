# Add ffi.GetInvalidObject global function and initialize MISSING singleton in core.pyx
## TL;DR
- Renames `ffi.MapGetMissingObject` to `ffi.GetInvalidObject` as a general-purpose sentinel
- Initializes `MISSING` singleton in `core.pyx` via `_get_global_func("ffi.GetInvalidObject")()` at import time
- Re-exports `MISSING` from `container.py` via `from .core import MISSING`
- Adds `MISSING: Object` to `core.pyi` type stub

## Key Exports

```python
def GetInvalidObject() -> Object:
    """Return the global MISSING/invalid object singleton."""
    # Interacts with: Map.get() (uses MISSING as sentinel), container.py
    # Invariant: singleton identity -- same object across all imports

MISSING: Object  # module-level singleton in tvm_ffi.core
# Interacts with: Map.get(), Map.__contains__(), container MISSING checks
```

## Impact
- API: `ffi.MapGetMissingObject` removed, replaced by `ffi.GetInvalidObject` -- **breaking** for direct callers of the old name
- Behavioral: MISSING now initialized earlier (at Cython module load) instead of lazily
- Flags/config: none
- Data formats/schemas: none

from tvm_ffi.core import MISSING
