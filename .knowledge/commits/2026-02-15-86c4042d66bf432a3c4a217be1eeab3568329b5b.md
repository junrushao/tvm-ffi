# Rename ffi.MapGetMissingObject to ffi.GetInvalidObject and relocate MISSING init to core.pyx

## TL;DR
- Renames the C++ global function `ffi.MapGetMissingObject` → `ffi.GetInvalidObject`, decoupling the singleton sentinel from Map-specific naming so it can serve as a general invalid-object marker.
- Moves `MISSING` initialization from `container.py` (eager `_ffi_api.MapGetMissingObject()` at import) to `core.pyx` (Cython, after `Function` registration), ensuring the sentinel is available earlier in the import chain.
- Re-exports `MISSING` from `container.py` via `from .core import MISSING`, keeping backward-compatible access for existing callers.

## Key Exports

```python
# C++ global function registration (src/ffi/container.cc):
# REMOVED: "ffi.MapGetMissingObject" -> () -> ObjectRef
# ADDED:   "ffi.GetInvalidObject"    -> () -> ObjectRef
#   Returns the static GetMissingObject() singleton (same underlying C++ impl)
#   Interacts with: global reflection registry (GlobalDef), ObjectRef ref-counting
#   Invariant: always returns the same ObjectRef identity for process lifetime

# Python (python/tvm_ffi/cython/core.pyx):
MISSING: Object  # = _get_global_func("ffi.GetInvalidObject", False)()
# Initialized once after Function is registered in core.pyx
# Interacts with: _get_global_func (core bootstrap), ffi.GetInvalidObject global
# Invariant: MISSING.same_as(x) is the correct identity check, not ==

# Python (python/tvm_ffi/container.py):
from .core import MISSING  # re-export for backward compatibility
# Interacts with: Map.get(), MapGetItemOrMissing, kwargs_wrapper.MISSING (separate concept)
```

## Impact
- API: `_ffi_api.MapGetMissingObject` removed from `__all__` and stubs — direct callers of this internal function will break. `MISSING` Python attribute is unchanged (same object, same import path).
- Behavioral: `MISSING` is now initialized earlier (in `core.pyx` after `Function` registration) rather than lazily at `container.py` import. No semantic change to `Map.get()` behavior.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Cross-layer trace — C++ definition → Python usage:

```python
# C++ (src/ffi/container.cc) — registers the new global:
# .def("ffi.GetInvalidObject", []() -> ObjectRef { return GetMissingObject(); })

# Python (core.pyx) — initialization after Function is registered:
MISSING = _get_global_func("ffi.GetInvalidObject", False)()

# Python (container.py) — Map.get() integration (unchanged API):
m = tvm_ffi.Map({"a": 1})
assert m.get("b") is None          # MapGetItemOrMissing returns MISSING; converted to None
assert m.get("b", 42) == 42        # explicit default returned when key missing

# Test confirming singleton identity across import paths:
from tvm_ffi.container import MISSING as CONTAINER_MISSING
from tvm_ffi.core import MISSING
assert MISSING.same_as(CONTAINER_MISSING)   # same ObjectRef identity
```
