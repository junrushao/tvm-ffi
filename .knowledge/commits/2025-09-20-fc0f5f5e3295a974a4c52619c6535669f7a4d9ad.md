# Add Docker dev container and C++ CUDA quick-start example
## TL;DR
- Adds a GPU-capable Docker dev container (`tests/docker/Dockerfile`) based on `nvidia/cuda:12.6.3-devel-ubuntu22.04`, with full C++/Python/CUDA toolchain, and documents its use in `CONTRIBUTING.md`.
- Introduces `run_example_cuda.cc`, a C++ example that allocates CUDA tensors via a custom `CUDANDAlloc` adapter, loads the FFI CUDA module, and round-trips data through `add_one_cuda`.
- Modernizes the quick-start build: replaces deprecated `find_package(CUDA)` with `find_package(CUDAToolkit)`, prefers Ninja generator, adds `--parallel` builds, and auto-detects/runs the CUDA binary in `run_example.sh`.

## Usage Examples

**Loading and running a CUDA FFI module from C++** (from `run_example_cuda.cc`):
```cpp
namespace ffi = tvm::ffi;

// Custom allocator satisfying the NDAlloc concept
struct CUDANDAlloc {
  void AllocData(DLTensor* tensor) { cudaMalloc(&tensor->data, ffi::GetDataSize(*tensor)); }
  void FreeData(DLTensor* tensor)  { cudaFree(tensor->data); tensor->data = nullptr; }
};

// Create CUDA tensors, load module, call function
ffi::Tensor x = ffi::Tensor::FromNDAlloc(CUDANDAlloc(), {5}, {kDLFloat, 32, 1}, {kDLCUDA, 0});
cudaMemcpy(x->data, host_data, nbytes, cudaMemcpyHostToDevice);

ffi::Module mod = ffi::Module::LoadFromFile("build/add_one_cuda.so");
ffi::Function add_one = mod->GetFunction("add_one_cuda").value();
add_one(x, y);
```

**Building and running with the Docker dev container** (from `CONTRIBUTING.md`):
```bash
docker build -t tvm-ffi-dev -f tests/docker/Dockerfile tests/docker
docker run --rm -it --gpus all -v "$(pwd)":/workspace/tvm-ffi -w /workspace/tvm-ffi tvm-ffi-dev bash
# Inside container:
pip install -ve .
cd examples/quick_start && bash run_example.sh
```
