# Add Docker dev container and C++ CUDA quick-start example
## TL;DR
- Add `tests/docker/Dockerfile` based on `nvidia/cuda:12.6.3-devel-ubuntu22.04` with full C++/Python/CUDA toolchain for reproducible dev environments.
- Add `examples/quick_start/src/run_example_cuda.cc` demonstrating GPU tensor allocation, FFI function invocation, and device-host copy using `Tensor::FromNDAlloc` and `Module::LoadFromFile`.
- Modernize the quick-start CMake build: migrate from deprecated `find_package(CUDA)` to `find_package(CUDAToolkit)`, prefer Ninja generator, add `--parallel` to builds, and add `requirements.txt` for Python deps.

## Usage Examples

End-to-end C++ CUDA example pattern (from `run_example_cuda.cc`):

```cpp
// 1. Load a shared library that exports an FFI function
ffi::Module mod = ffi::Module::LoadFromFile("build/add_one_cuda.so");

// 2. Allocate CUDA tensors using a custom NDAlloc
ffi::Tensor x = ffi::Tensor::FromNDAlloc(CUDANDAlloc(), {5}, f32_dtype, cuda_device);

// 3. Copy host data to device, invoke FFI function, copy back
cudaMemcpy(x->data, host_x.data(), nbytes, cudaMemcpyHostToDevice);
ffi::Function add_one_cuda = mod->GetFunction("add_one_cuda").value();
add_one_cuda(x, y);
cudaMemcpy(host_y.data(), y->data, nbytes, cudaMemcpyDeviceToHost);
```

Docker workflow:
```bash
docker build -t tvm-ffi-dev -f tests/docker/Dockerfile tests/docker
docker run --rm -it --gpus all -v "$(pwd)":/workspace/tvm-ffi -w /workspace/tvm-ffi tvm-ffi-dev bash
# Inside container: pip install -ve . && cd examples/quick_start && bash run_example.sh
```
