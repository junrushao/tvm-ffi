# Add Docker dev container and C++ CUDA quick-start example
## TL;DR
- Adds a `tests/docker/Dockerfile` based on `nvidia/cuda:12.6.3-devel-ubuntu22.04` with the full build toolchain (CMake, Ninja, clang, Python 3) for GPU-enabled development.
- Introduces `examples/quick_start/src/run_example_cuda.cc`, a C++ example that allocates CUDA tensors via a custom `CUDANDAlloc`, loads the `add_one_cuda.so` module, and invokes the FFI function on-device.
- Modernizes the quick-start CMake from `find_package(CUDA)` to `find_package(CUDAToolkit)`, adds Ninja generator preference, and updates docs/README/scripts accordingly.

## Usage Examples

CUDA tensor allocation and FFI invocation (from `run_example_cuda.cc`):

```cpp
#include <cuda_runtime.h>
#include <tvm/ffi/container/tensor.h>
#include <tvm/ffi/extra/module.h>
namespace ffi = tvm::ffi;

// 1. Define a custom CUDA allocator satisfying the NDAlloc concept
struct CUDANDAlloc {
  void AllocData(DLTensor* tensor) {
    cudaMalloc(&tensor->data, ffi::GetDataSize(*tensor));
  }
  void FreeData(DLTensor* tensor) {
    if (tensor->data) cudaFree(tensor->data);
  }
};

// 2. Load module, create tensors, invoke function
ffi::Module mod = ffi::Module::LoadFromFile("build/add_one_cuda.so");
ffi::Tensor x = ffi::Tensor::FromNDAlloc(CUDANDAlloc(), {5}, f32, {kDLCUDA, 0});
ffi::Tensor y = ffi::Tensor::FromNDAlloc(CUDANDAlloc(), {5}, f32, {kDLCUDA, 0});
// copy host data to x...
ffi::Function add_one = mod->GetFunction("add_one_cuda").value();
add_one(x, y);
// copy y back to host and inspect
```
