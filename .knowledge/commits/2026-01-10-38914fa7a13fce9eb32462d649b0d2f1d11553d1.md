# Add Type2Str specializations for Any&& and AnyView&& to fix reflection Init
## TL;DR
- Adds `Type2Str<Any&&>` and `Type2Str<AnyView&&>` specializations in `any.h` to fix compile errors when using `refl::init<Any>()`.
- Adds forward declaration of `Any` in `type_traits.h`.
- Adds tests for `Reflection::InitWithAny` and `Reflection::InitWithAnyView`.

## Key Exports

```python
# Template specialization (pseudocode for what's added):
# Type2Str<Any&&>::v() -> "Any"
# Type2Str<AnyView&&>::v() -> "AnyView"
# Interacts with: reflection system's init<> template, TypeStr generation
```

## Impact
- API: none -- fixes compile-time issue, no runtime API change
- Behavioral: `refl::init<Any>()` and `refl::init<AnyView>()` now compile correctly
- Flags/config: none
- Data formats/schemas: none
