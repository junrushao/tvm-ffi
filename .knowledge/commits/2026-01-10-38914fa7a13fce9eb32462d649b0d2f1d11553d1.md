# Fix compilation failure when using refl::init<Any> by adding Type2Str specializations for rvalue references
## TL;DR
- Adds `Type2Str<Any&&>` and `Type2Str<AnyView&&>` template specializations in `include/tvm/ffi/any.h`, fixing a compile error when `refl::init<Any>()` is used in reflection-based constructors.
- Adds forward declaration of `class Any` in `include/tvm/ffi/type_traits.h` to support the specialization.
- Tests cover `refl::init<Any>` and `refl::init<AnyView>` with int, double, and String arguments.

## Key Exports

**Template specializations** added in `include/tvm/ffi/any.h`:

| Specialization | Returns |
|---------------|---------|
| `Type2Str<Any&&>::v()` | `"Any"` |
| `Type2Str<AnyView&&>::v()` | `"AnyView"` |

These complement the existing `Type2Str<Any>`, `Type2Str<const Any&>`, `Type2Str<AnyView>`, and `Type2Str<const AnyView&>` specializations.

## Impact
- API: none (compile-time fix only; no runtime API changes)
- Behavioral: `refl::init<Any>()` and `refl::init<AnyView>()` now compile. Previously the reflection system internally converted `Any` to `Any&&` via `std::forward`, but no `Type2Str` specialization existed for `Any&&`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Type traits / Type2Str** (`.knowledge/designs/0005-type-traits.md`) — the `Type2Str<T>` protocol for converting C++ types to human-readable names for reflection.
- **Reflection** (`.knowledge/designs/0009-reflection.md`) — `refl::init<Args...>()` constructor registration and `ObjectDef<T>` builder.

Design elements this commit produces:
- None (bugfix filling a gap in the existing `Type2Str` specialization set).

## Usage Examples
**Before** (bug): compile error when defining a constructor accepting `Any`.
```cpp
// This failed to compile - no Type2Str<Any&&>
refl::ObjectDef<MyObj>().def(refl::init<Any>());
```

**After** (fix): compiles and works correctly.
```cpp
refl::ObjectDef<TestObjWithAny>()
    .def(refl::init<Any>())
    .def_ro("value", &TestObjWithAny::value);

// Usage via reflection:
Function init = reflection::GetMethod("test.TestObjWithAny", "__ffi_init__");
Any obj = init(42);  // value.cast<int>() == 42
```
