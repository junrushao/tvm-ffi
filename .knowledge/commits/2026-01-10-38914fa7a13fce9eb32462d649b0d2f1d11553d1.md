# Fix missing Type2Str specializations for Any&& and AnyView&& in reflection init

## TL;DR
- `refl::init<Any>()` failed to compile because `init<Any>::execute<Class>` produces a function pointer `ObjectRef execute(Any&&)`, and `details::Type2Str<Any&&>` had no specialization.
- Added `Type2Str<Any&&>` and `Type2Str<AnyView&&>` specializations in `any.h`, both returning `"Any"` and `"AnyView"` respectively, completing the cv-ref coverage for these types.
- Added a forward declaration of `class Any` in `type_traits.h` to support include-order independence when `Type2Str<Any&&>` is needed early in the compilation.

## Key Exports

```python
# In namespace tvm::ffi::details (any.h)

# Before this commit:
# Type2Str<Any>        exists → "Any"
# Type2Str<const Any&> exists → "Any"
# Type2Str<Any&&>      MISSING → compile error via TypeTraitsNoCR<Any&&>::TypeStr()
# Type2Str<AnyView&&>  MISSING → compile error

# After this commit (additive specializations):
class Type2Str_Any_RValueRef:
    """Type2Str<Any&&> — maps rvalue-ref qualified Any to "Any" string."""
    @staticmethod
    def v() -> str: return "Any"
    # Interacts with: FuncFunctorImpl::Sig(), Arg2Str (function signature string generation)
    # Interacts with: TypedOverload mismatch error messages (reflection/overload.h:156)
    # Invariant: returns same string as Type2Str<Any> and Type2Str<const Any&>
    # Note: TypeSchema<Any&&> was already handled via TypeSchema = TypeSchemaImpl<remove_cvref_t<T>>

class Type2Str_AnyView_RValueRef:
    """Type2Str<AnyView&&> — maps rvalue-ref qualified AnyView to "AnyView" string."""
    @staticmethod
    def v() -> str: return "AnyView"
    # Interacts with: same as Type2Str<Any&&>

# Forward declaration in type_traits.h (include order safety):
# class Any;  — allows Type2Str<Any&&> to be referenced when type_traits.h
#              is included before any.h
```

## Impact
- API: None — additive specializations only; no changes to existing signatures.
- Behavioral: Enables `refl::ObjectDef<T>().def(refl::init<Any>())` and `refl::ObjectDef<T>().def(refl::init<AnyView>())` to compile and work at runtime.
- Flags/config: None.
- Data formats/schemas: None. The `TypeSchema<Any&&>` path already stripped the `&&` via `TypeSchemaImpl<remove_cvref_t<T>>`, so JSON schema output is unchanged.

## Design Elements
Design elements this commit consumes:
- `details::Type2Str<T>` template — the partial-specialization table in `any.h` that converts C++ types (including cv-ref variants) to human-readable strings for function signatures and error messages. Covered by [0002-ffi-any-value-system.md](../design-records/0002-ffi-any-value-system.md) and [0007-ffi-reflection.md](../design-records/0007-ffi-reflection.md).
- `reflection::init<Args...>` — constructor registration helper whose `execute<Class>` static method uses perfect forwarding (`Args&&...`), meaning `init<Any>` produces a function pointer `ObjectRef(Any&&)`. Covered by [0007-ffi-reflection.md](../design-records/0007-ffi-reflection.md).
- `FuncFunctorImpl<R, Args...>::Sig()` — calls `Type2Str<Arg>::v()` for each argument without stripping the reference qualifier, unlike `TypeSchema` which strips via `TypeSchemaImpl<remove_cvref_t<T>>`. Consumed from `include/tvm/ffi/function_details.h`.

Design elements this commit produces:
- None — this is a gap-fill in an existing specialization table.

## Usage Examples

**Before (compile error):**
```cpp
struct MyObj : public Object {
  Any value;
  explicit MyObj(Any v) : value(std::move(v)) {}
  TVM_FFI_DECLARE_OBJECT_INFO_FINAL("MyObj", MyObj, Object);
};

TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  // FAILS: no Type2Str<Any&&> -- compile error in FuncFunctorImpl::Sig()
  refl::ObjectDef<MyObj>().def(refl::init<Any>());
}
```

**After (compiles and works):**
```cpp
// Same definition now compiles.
// Runtime verification from the new test:
Function init = reflection::GetMethod("test.TestObjWithAny", "__ffi_init__");
Any obj = init(42);
EXPECT_EQ(obj.as<TestObjWithAny>()->value.cast<int>(), 42);  // passes
Any obj2 = init(3.14);
EXPECT_EQ(obj2.as<TestObjWithAny>()->value.cast<double>(), 3.14);  // passes
```
