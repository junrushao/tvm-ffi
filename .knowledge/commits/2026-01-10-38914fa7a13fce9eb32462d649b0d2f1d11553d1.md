# Add Type2Str specializations for Any&& and AnyView&& to fix reflection init with Any args

## TL;DR
- Using `refl::init<Any>()` to register a constructor that takes `Any` triggered a compile error: no `Type2Str<Any&&>` specialization existed.
- Adds `Type2Str<Any&&>` (→ `"Any"`) and `Type2Str<AnyView&&>` (→ `"AnyView"`) template specializations in `include/tvm/ffi/any.h`.
- Adds a forward declaration of `class Any` in `include/tvm/ffi/type_traits.h` to break a header circular dependency.
- 56 lines of new tests in `tests/cpp/test_reflection.cc` validating reflection init with `Any` and `AnyView` args.

## Key Exports

```python
# include/tvm/ffi/any.h — added template specializations
# Before: Type2Str<Any&&> missing → compile error when using refl::init<Any>()
# After:
# template<> struct Type2Str<Any&&> { static std::string v() { return "Any"; } }
# template<> struct Type2Str<AnyView&&> { static std::string v() { return "AnyView"; } }

# include/tvm/ffi/type_traits.h — forward declaration
# class Any;  (forward decl to allow Type2Str usage without full include)
```

## Impact
- API: additive — no existing callers broken. Enables previously-broken use case.
- Behavioral: `refl::init<Any>()` and `refl::init<AnyView>()` now compile correctly.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `0003-any-anyview` — adds `Type2Str<Any&&>` and `Type2Str<AnyView&&>` specializations to `any.h`.
- `0006-reflection` — `refl::init<Args...>` generates type string via `Type2Str` for each arg; `Any` was missing rvalue-ref specialization.
- `0008-type-traits` — `Type2Str<T>` lives alongside `TypeTraits<T>` in the type-traits subsystem; forward declaration added to `type_traits.h`.

Design elements this commit produces: None — restores existing invariant.

## Usage Examples

```cpp
// Before: compile error
// After: compiles and works
struct MyObj : Object { ... };
TVM_FFI_STATIC_INIT_BLOCK() {
  ObjectDef<MyObj>()
    .def(refl::init<Any>())  // Was: error — no Type2Str<Any&&>
    .def(refl::init<AnyView>());  // Was: error — no Type2Str<AnyView&&>
}
```
