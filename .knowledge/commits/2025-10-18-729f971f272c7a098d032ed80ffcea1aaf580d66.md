# Add Rust documentation guide, API reference index, and cargo doc integration into Sphinx

## TL;DR
- Adds a new Rust usage guide (`docs/guides/rust_guide.md`) covering installation, basic usage (modules, tensors, functions), and advanced topics (global functions, type-erased functions, error handling).
- Adds a Rust API reference landing page (`docs/reference/rust/index.rst`) that links to `cargo doc`-generated documentation for the three workspace crates.
- Integrates `cargo doc` generation into the Sphinx build system via a `BUILD_RUST_DOCS=1` environment variable and a new `_build_rust_docs()` function in `docs/conf.py`.
- Modifies `rust/tvm-ffi-sys/build.rs` to gracefully skip linking during `rustdoc` builds (detecting `RUSTDOC` or `CARGO_CFG_DOC` env vars), enabling `cargo doc` to succeed without `libtvm_ffi` installed.

## Key Exports
None (documentation-only commit; no new public API surface).

## Impact
- API: None
- ABI: None
- Behavioral: `rust/tvm-ffi-sys/build.rs` now returns early (skipping link directives) when `RUSTDOC` or `CARGO_CFG_DOC` environment variables are set, allowing `cargo doc` to build without `libtvm_ffi` installed. This does not affect normal `cargo build` or `cargo test`.
- Flags/config: New `BUILD_RUST_DOCS=1` environment variable controls Rust doc generation during Sphinx builds. New `build_rust_docs` Sphinx config value registered via `app.add_config_value`.
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- Rust three-crate workspace architecture (`.knowledge/designs/rust-bindings.md`): the guide and reference page describe the `tvm-ffi`, `tvm-ffi-sys`, and `tvm-ffi-macros` crate organization.
- `tvm-ffi-config` build tool dependency (`.knowledge/designs/rust-bindings.md`, "Build system" section): the guide instructs users to verify `tvm-ffi-config --libdir` and the `build.rs` changes add graceful fallback when the tool is absent.
- Module system and `load_from_file` API (`.knowledge/designs/rust-bindings.md`, Function/Module sections): the guide demonstrates `Module::load_from_file` and `Function::get_global`/`register_global`.
- `Function::from_packed` / `Function::from_typed` patterns (`.knowledge/designs/rust-bindings.md`): the guide covers both typed and packed function creation from Rust closures.
- Existing Sphinx doc build infrastructure with `BUILD_CPP_DOCS` pattern (`docs/conf.py`): the new `BUILD_RUST_DOCS` follows the same convention.

Design elements this commit produces:
- Rust documentation build pipeline: `_build_rust_docs()` in `docs/conf.py` runs `cargo doc --no-deps --workspace` with `RUSTDOCFLAGS=--cfg docsrs`, copies output to `docs/reference/rust/generated/`, and adds it to `html_extra_path` for static serving.
- Rustdoc-safe build.rs pattern: `build.rs` detects rustdoc builds and skips linking, enabling documentation generation without runtime library dependencies.

## Usage Examples

Building Rust docs alongside the Sphinx documentation site:
```bash
# One-off build with all docs
BUILD_CPP_DOCS=1 BUILD_RUST_DOCS=1 uv run --group docs sphinx-build -M html docs docs/_build

# Interactive auto-rebuild during development
BUILD_RUST_DOCS=1 uv run --group docs sphinx-autobuild docs docs/_build/html \
  --ignore docs/reference/rust/generated --watch rust
```

The `build.rs` graceful degradation for `cargo doc` builds:
```rust
// In rust/tvm-ffi-sys/build.rs:
// When RUSTDOC or CARGO_CFG_DOC is set, build.rs returns early
// without emitting link directives, so `cargo doc` succeeds
// even without libtvm_ffi installed.
let is_rustdoc = env::var("RUSTDOC").is_ok() || env::var("CARGO_CFG_DOC").is_ok();
// ... if tvm-ffi-config fails and is_rustdoc, return early
```
