# Add Rust API documentation, guide, and Sphinx build integration
## TL;DR
- Adds a new Rust usage guide (`docs/guides/rust_guide.md`) covering installation, basic usage (modules, tensors, functions), and advanced topics (global functions, typed closures, error handling).
- Adds Rust API reference page (`docs/reference/rust/index.rst`) with links to `cargo doc`-generated HTML for all three crates (`tvm-ffi`, `tvm-ffi-sys`, `tvm-ffi-macros`).
- Integrates Rust documentation into the Sphinx build pipeline via `BUILD_RUST_DOCS=1` env var, and hardens `tvm-ffi-sys/build.rs` to gracefully skip linking during `cargo doc` builds.
