# Add Rust documentation guide and integrate cargo-doc into Sphinx build
## TL;DR
- Adds a new Rust Guide (`docs/guides/rust_guide.md`) covering installation, basic usage (Module, Tensor, Function), advanced topics (global functions, type-erased closures, error handling), and the example runner.
- Integrates `cargo doc` into the Sphinx build pipeline via `BUILD_RUST_DOCS=1` environment variable, with incremental builds for `sphinx-autobuild` and clean rebuilds for CI.
- Makes `tvm-ffi-sys/build.rs` tolerant of missing `tvm-ffi-config` during `rustdoc` builds, enabling `cargo doc` without a full Python install.

## Key Exports
None -- this is a documentation-only commit. No new public API symbols are introduced.

## Impact
- API: none
- Behavioral: `cargo doc` now succeeds without `tvm-ffi-config` on PATH when `RUSTDOC` or `CARGO_CFG_DOC` env vars are set (rustdoc mode). Previously it would panic.
- Flags/config: new `BUILD_RUST_DOCS=1` env var for Sphinx builds; new `build_rust_docs` Sphinx config value; `html_extra_path` conditionally includes Rust generated docs.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Rust three-crate workspace** (`.knowledge/designs/0016-rust-bindings.md`): The Rust guide documents `tvm-ffi`, `tvm-ffi-sys`, and `tvm-ffi-macros` crates and their public API (`Module`, `Tensor`, `Function`, `Error`, `Any`, `AnyView`).
- **Module system** (`.knowledge/designs/0011-module-system.md`): The guide documents `Module::load_from_file` and `module.get_function` patterns.
- **Function system** (`.knowledge/designs/0004-function-system.md`): The guide documents `Function::get_global`, `Function::register_global`, `Function::from_packed`, `Function::from_typed`.
- **Build linkage** (`.knowledge/designs/0016-rust-bindings.md`, "Build linkage" invariant): `build.rs` is modified to make the `tvm-ffi-config` dependency soft during rustdoc builds.

Design elements this commit produces:
- **Sphinx Rust docs integration**: New `_build_rust_docs()` function in `docs/conf.py` that invokes `cargo doc --no-deps --workspace` and copies output to `docs/reference/rust/generated/`. This is a documentation-infrastructure pattern, not a design element.
