# Add Rust API docs, Rust guide, and Sphinx integration for cargo doc
## TL;DR
- New `docs/guides/rust_guide.md` tutorial covering installation, basic usage (Module, Tensor, Function), and advanced topics (global functions, typed closures, error handling).
- New `docs/reference/rust/index.rst` Rust API reference page listing the three crates (`tvm-ffi`, `tvm-ffi-sys`, `tvm-ffi-macros`) with links to `cargo doc`-generated HTML.
- Sphinx `conf.py` gains `BUILD_RUST_DOCS=1` env-gated integration: runs `cargo doc --no-deps --workspace`, copies output to `docs/reference/rust/generated/`, and serves it via `html_extra_path`.
- `rust/tvm-ffi-sys/build.rs` hardened to allow `cargo doc` without `tvm-ffi-config` installed — early-returns for rustdoc builds.

## Key Exports
None — documentation-only commit. No new public API symbols introduced.

## Impact
- API: none
- Behavioral: `cargo doc` for the Rust workspace now succeeds even when `tvm-ffi-config` is not installed (rustdoc builds only).
- Flags/config: new `BUILD_RUST_DOCS=1` env variable controls Sphinx Rust doc generation.
- Data formats/schemas: none

## Usage Examples
Build Rust docs alongside Sphinx:

```bash
# One-off build with Rust + C++ docs
BUILD_CPP_DOCS=1 BUILD_RUST_DOCS=1 uv run --group docs sphinx-build -M html docs docs/_build

# Interactive build with auto-rebuild on Rust source changes
BUILD_RUST_DOCS=1 uv run --group docs sphinx-autobuild docs docs/_build/html \
  --ignore docs/reference/rust/generated --watch rust
```
