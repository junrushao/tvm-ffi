# Add Rust usage guide, API reference page, and Sphinx integration for cargo doc
## TL;DR
- Adds `docs/guides/rust_guide.md` with comprehensive Rust usage guide: module loading, tensor creation, function calling, global functions, typed closures, error handling.
- Adds `docs/reference/rust/index.rst` and Sphinx integration (`BUILD_RUST_DOCS=1`) that runs `cargo doc` and copies output into the Sphinx build.
- Makes `tvm-ffi-sys/build.rs` gracefully skip linking during rustdoc builds by detecting `RUSTDOC`/`CARGO_CFG_DOC` environment variables.

## Key Exports
None — documentation infrastructure only. The `build.rs` change is a build-script behavior change, not a library API change.

**Build script behavior change (`rust/tvm-ffi-sys/build.rs`):**
- When `RUSTDOC` or `CARGO_CFG_DOC` env var is set, `tvm-ffi-config --libdir` failure is non-fatal and the build script returns early without linking.

## Impact
- API: none
- Behavioral: `tvm-ffi-sys` build script no longer panics during `cargo doc` when `tvm-ffi-config` is unavailable.
- Flags/config: new `BUILD_RUST_DOCS=1` environment variable for Sphinx doc builds.
- Data formats/schemas: none
