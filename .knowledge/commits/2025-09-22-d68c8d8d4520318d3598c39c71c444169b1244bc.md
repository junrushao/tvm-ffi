# Fix fallback for unregistered object types in FFI return path
## TL;DR
- Fixes `make_ret_object` in `object.pxi` to properly handle cases where `TYPE_INDEX_TO_INFO[tindex]` is `None` (unregistered type index), falling back gracefully to `Object` instead of crashing with `AttributeError`.
- Adds a C++ testing helper for obtaining an unregistered object type, with corresponding Python test coverage.
