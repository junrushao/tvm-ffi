# Skip Python 3.8 wheel builds on arm64 macOS in CI
## TL;DR
- Adds `CIBW_SKIP: "cp38-macosx_*"` to the `publish_wheel.yml` workflow to skip Python 3.8 on all macOS architectures.
- Rationale: arm64 macOS has no native Python 3.8 support, making those wheel builds pointless.

## Key Exports
None

## Impact
- API: none
- Behavioral: Python 3.8 macOS wheels are no longer produced by CI. Users on arm64 macOS with Python 3.8 (a near-impossible combination natively) lose prebuilt wheels.
- Flags/config: `CIBW_SKIP` env var added to the cibuildwheel matrix in `.github/workflows/publish_wheel.yml`.
- Data formats/schemas: none
