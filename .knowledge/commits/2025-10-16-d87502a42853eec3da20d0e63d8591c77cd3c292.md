# Skip Python 3.8 wheel builds on arm64 macOS in CI

## TL;DR
- Adds `CIBW_SKIP: "cp38-macosx_*"` to the `cibuildwheel` step in `publish_wheel.yml`, preventing Python 3.8 wheel builds on all macOS arm64 targets.
- Rationale: arm64 macOS has no native Python 3.8 support, so building those wheels is pointless.
