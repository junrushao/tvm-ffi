# Skip Python 3.8 wheel builds on arm64 macOS
## TL;DR
- Added `CIBW_SKIP: "cp38-macosx_*"` to the `publish_wheel.yml` workflow to exclude Python 3.8 from macOS wheel builds, since arm64 macOS has no native Python 3.8 support.

## Key Exports
None

## Impact
- API: none
- Behavioral: CI no longer attempts (and fails) to build Python 3.8 wheels on arm64 macOS
- Flags/config: `CIBW_SKIP` env var added to the `build_wheels` job in `.github/workflows/publish_wheel.yml`
- Data formats/schemas: none
