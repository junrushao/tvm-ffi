# Skip Python 3.8 wheel builds on arm64 macOS in CI
## TL;DR
- Adds `CIBW_SKIP: "cp38-macosx_*"` to the `publish_wheel.yml` GitHub Actions workflow to skip building Python 3.8 wheels on macOS.
- ARM64 macOS does not have native Python 3.8 support, making those wheel builds pointless.
