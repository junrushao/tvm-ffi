# Skip Python 3.8 wheel builds on arm64 macOS in CI
## TL;DR
- Adds `CIBW_SKIP: "cp38-macosx_*"` environment variable to the `publish_wheel.yml` GitHub Actions workflow to skip building Python 3.8 wheels on macOS.
- ARM64 (Apple Silicon) macOS has no native Python 3.8 support, so attempting to build cp38 wheels on `macos-14` (arm64) is pointless and would fail.
