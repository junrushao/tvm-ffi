# Guard ml_dtypes >= 0.5 types behind hasattr check to support ml_dtypes < 0.5
## TL;DR
- Fixes `AttributeError` at import time when `ml_dtypes < 0.5` is installed, by moving 8 dtype mappings that only exist in `ml_dtypes >= 0.5.0` behind a `hasattr(ml_dtypes, "int2")` guard.
- Mirrors the same `hasattr`-guard pattern already applied to `torch.float8_e8m0fnu` / `torch.float4_e2m1fn_x2` in commit `eb5492a`.
- The 8 universally-available types (`int4`, `uint4`, `bfloat16`, `float8_e4m3b11fnuz`, `float8_e4m3fn`, `float8_e4m3fnuz`, `float8_e5m2`, `float8_e5m2fnuz`) remain unconditional.

## Key Exports
None -- no new public API. Internal `MLDTYPES_DTYPE_TO_DTYPE` dict population is restructured but its public contract (used by `NUMPY_DTYPE_TO_DTYPE` spread and `_convert_numpy_dtype_to_ffi_dtype`) is unchanged.

## Impact
- API: none
- Behavioral: `import tvm_ffi` no longer raises `AttributeError` when `ml_dtypes == 0.4.x` is installed. The 8 newer dtype mappings are silently unavailable on older ml_dtypes versions.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Cython dtype mapping** (`python/tvm_ffi/cython/dtype.pxi`) -- `MLDTYPES_DTYPE_TO_DTYPE` dict that maps `numpy.dtype(ml_dtypes.X)` constants to `DLDataType` values, then spread into `NUMPY_DTYPE_TO_DTYPE`. See `.knowledge/designs/0012-python-bindings.md` "numpy/torch/ml_dtypes are optional" invariant.
- **hasattr version-guard pattern** -- established in `eb5492a` for torch dtypes, now applied identically to ml_dtypes. The sentinel attribute is `ml_dtypes.int2` (introduced in ml_dtypes 0.5.0).

Design elements this commit produces: none

## Usage Examples
Before (crashes on `ml_dtypes < 0.5`):
```python
# dtype.pxi -- all 16 entries in a single dict literal
MLDTYPES_DTYPE_TO_DTYPE = {
    numpy.dtype(ml_dtypes.int2): DLDataType(0, 2, 1),  # AttributeError: ml_dtypes < 0.5
    ...
}
```

After (works on `ml_dtypes >= 0.4`):
```python
# dtype.pxi -- base dict with 8 universally-available types
MLDTYPES_DTYPE_TO_DTYPE = {
    numpy.dtype(ml_dtypes.int4): DLDataType(0, 4, 1),
    ...  # 8 entries always present
}
if hasattr(ml_dtypes, "int2"):  # ml_dtypes >= 0.5.0
    MLDTYPES_DTYPE_TO_DTYPE[numpy.dtype(ml_dtypes.int2)] = DLDataType(0, 2, 1)
    ...  # 8 additional entries
```
