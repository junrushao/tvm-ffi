# Support ml_dtypes < 0.5 by conditionally registering newer dtype entries
## TL;DR
- Guards ml_dtypes entries that were introduced in v0.5.0 (int2, uint2, float8_e3m4, float8_e4m3, float8_e8m0fnu, float6_e2m3fn, float6_e3m2fn, float4_e2m1fn) behind `hasattr(ml_dtypes, "int2")` in `python/tvm_ffi/cython/dtype.pxi`.
- Fixes ImportError when using ml_dtypes 0.4.x which lacks those attributes.

## Impact
- API: None (backward-compatible fix; newer dtypes still registered when available)
- Flags/config: None
- Data formats/schemas: None
