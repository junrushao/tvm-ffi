# Add DefaultFactory to field reflection to support per-instance mutable defaults
## TL;DR
- Adds `reflection::DefaultFactory` trait (symmetric to `DefaultValue`) that stores a `() -> Any` callable invoked fresh each time a default is needed, preventing aliasing of mutable defaults (e.g., `Array`, `Map`).
- Renames `TVMFFIFieldInfo::default_value` → `default_value_or_factory` in `c_api.h`; adds flag `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5`.
- Extracts `SetFieldToDefault()` helper in `accessor.h` to consolidate default resolution across `creator.h`, `reflection_extra.cc`, and `serialization.cc`.

## Key Exports

# TVMFFIFieldInfo::default_value  →  default_value_or_factory

#     default_value_or_factory holds Function(() -> Any) — call to get fresh default
#   When not set:
#     default_value_or_factory holds static AnyView default (as before)

## Impact
- API: `TVMFFIFieldInfo::default_value` field renamed to `default_value_or_factory` in `c_api.h`. **This is a breaking ABI-level rename** for any code reading `TVMFFIFieldInfo` fields directly. All in-tree bindings (Rust `c_api.rs`, Cython `base.pxi`) updated in this commit.
- Behavioral: Fields registered with `DefaultFactory` now produce a fresh value per object instance, preventing aliasing bugs when mutable containers (Array, Map) are used as defaults.
- Flags/config: New flag bit `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5` in `TVMFFIFieldFlagBitMask`.
- Data formats/schemas: none

## Usage Examples

```cpp
// C++: register a field with a mutable default (Array) — safe, no aliasing
TVM_FFI_STATIC_INIT_BLOCK() {
    ObjectDef<MyObj>()
        .def_field("items", &MyObj::items,
                   DefaultFactory([]() -> Any { return Array<String>(); }));
}

// Compare: DefaultValue would share one Array across all instances (aliasing bug):
// .def_field("items", &MyObj::items, DefaultValue(Array<String>()))  // WRONG for mutable

// C++ consumer: check flag and call SetFieldToDefault
const TVMFFIFieldInfo* fi = ...;
if (fi->flags & kTVMFFIFieldFlagBitMaskHasDefault) {
    SetFieldToDefault(fi, field_addr);  // handles factory or static value uniformly
}
```
