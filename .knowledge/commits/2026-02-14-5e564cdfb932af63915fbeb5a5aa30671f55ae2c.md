# Add DefaultFactory support to field reflection for mutable defaults
## TL;DR
- Adds `DefaultFactory` trait to field reflection, storing a callable `() -> Any` that produces fresh default values per instance (avoiding aliasing of mutable defaults like Array/Map).
- Renames `TVMFFIFieldInfo::default_value` to `default_value_or_factory` and adds `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5` flag bit.
- Adds `SetFieldToDefault` helper in `accessor.h` that centralizes default resolution (direct value vs factory call) for the three consumption sites.

## Key Exports

**C ABI**:
```c
// c_api.h
kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5  // new flag bit

// TVMFFIFieldInfo field renamed:
TVMFFIAny default_value_or_factory;  // was: default_value
```

**C++ API**:
```cpp
// reflection/registry.h
class DefaultFactory : public InfoTrait {
    explicit DefaultFactory(Function factory);
    void Apply(TVMFFIFieldInfo* info) const;
};

// reflection/accessor.h
inline void SetFieldToDefault(const TVMFFIFieldInfo* field_info, void* field_addr);
```

## Impact
- API: Breaking rename `TVMFFIFieldInfo::default_value` -> `default_value_or_factory`. New flag bit `kTVMFFIFieldFlagBitMaskDefaultFromFactory`. Rust and Cython bindings updated.
- Behavioral: Mutable defaults in reflected fields now produce fresh values per instance when using `DefaultFactory`.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Reflection** (`.knowledge/designs/0009-reflection.md`): Extends `TVMFFIFieldInfo` with factory semantics.
- **C ABI layer** (`.knowledge/designs/0001-c-abi-layer.md`): Modifies `TVMFFIFieldInfo` struct and `TVMFFIFieldFlagBitMask` enum.

Design elements this commit produces:
- **DefaultFactory pattern**: Factory-based default values for reflected fields, preventing mutable default aliasing.
- **SetFieldToDefault helper**: Centralized default resolution (value vs factory).

## Usage Examples

```cpp
ObjectDef<MyObj>("test.MyObj")
    .def_field("items", &MyObj::items,
               DefaultFactory(Function::from_typed([]() -> Array<int> {
                   return Array<int>{};
               })));
```
