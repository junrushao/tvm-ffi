# Add DefaultFactory support to field reflection
## TL;DR
- Adds `DefaultFactory` trait to reflection field registration, allowing fields to have factory-based default values
- Extends `TVMFFIFieldInfo` with default factory support in C ABI
- Updates serialization to handle fields with default factories
- Adds accessor support for reading default factory metadata

## Key Exports
```python
class DefaultFactory(InfoTrait):
    """Registers a default value factory for a reflected field."""
    # Interacts with: ObjectDef<T>.def_field(), TVMFFIFieldInfo metadata
    # Used by: Python @c_class __init__ generation for default values

# Usage in C++ reflection:
# ObjectDef<T>().def_field("name", &T::field, DefaultFactory([]() { return default_val; }));
```

## Impact
- API: extends reflection field registration with default factory support
- Behavioral: none for existing code
- Flags/config: none
- Data formats/schemas: extends TVMFFIFieldInfo metadata
