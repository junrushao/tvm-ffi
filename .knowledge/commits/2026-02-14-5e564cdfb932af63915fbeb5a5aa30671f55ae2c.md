# Add DefaultFactory trait and SetFieldToDefault helper to prevent mutable-default aliasing in reflected Object fields.

## TL;DR
- `TVMFFIFieldInfo::default_value` renamed to `default_value_or_factory`; new flag `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5` lets the slot hold a `Function () -> Any` factory instead of a static value.
- New `reflection::DefaultFactory(fn)` trait (symmetric to `DefaultValue`) and `reflection::SetFieldToDefault` helper centralize factory dispatch so all three consumption sites (`creator.h`, `reflection_extra.cc`, `serialization.cc`) share one implementation.
- Without this fix every reflected object sharing an `Array` default received the same underlying container (aliasing bug); the factory produces a fresh value per construction.

## Key Exports

```python
# --- c_api.h ---
class TVMFFIFieldFlagBitMask(IntEnum):
    kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5
    # Invariant: only meaningful when kTVMFFIFieldFlagBitMaskHasDefault is also set.
    # When set: default_value_or_factory holds a Function (() -> Any).
    # When clear: default_value_or_factory holds a static AnyView.

class TVMFFIFieldInfo:
    """C ABI struct describing one reflected field."""
    # OLD: default_value: TVMFFIAny
    # NEW:
    default_value_or_factory: TVMFFIAny
    # Interacts with: SetFieldToDefault, ObjectCreator, ObjectGraphDeserializer

# --- include/tvm/ffi/reflection/registry.h ---
class DefaultFactory(InfoTrait):
    """Trait providing a factory callable for mutable field defaults.
    Pass as *extra to ObjectDef::def_ro / def_rw.
    """
    def __init__(self, factory: Function) -> None: ...
    # factory must be callable with no arguments, returning the default value.
    # Apply sets kTVMFFIFieldFlagBitMaskHasDefault | kTVMFFIFieldFlagBitMaskDefaultFromFactory.
    # Invariant: factory is called once per object construction, never shared.
    # Interacts with: TVMFFIFieldInfo.default_value_or_factory, SetFieldToDefault
    # Extension: pass any Function::FromTyped([]() -> T { return T{}; }) as factory

    def Apply(self, info: TVMFFIFieldInfo*) -> None:
        info.default_value_or_factory = AnyView(factory_).CopyToTVMFFIAny()
        info.flags |= kTVMFFIFieldFlagBitMaskHasDefault
        info.flags |= kTVMFFIFieldFlagBitMaskDefaultFromFactory

# --- include/tvm/ffi/reflection/accessor.h ---
def SetFieldToDefault(field_info: TVMFFIFieldInfo*, field_addr: void*) -> None:
    """Resolve and apply the default: call factory if DefaultFromFactory flag set,
    else pass static value directly to setter.
    Precondition: kTVMFFIFieldFlagBitMaskHasDefault must be set.
    """
    if field_info.flags & kTVMFFIFieldFlagBitMaskDefaultFromFactory:
        factory = AnyView.CopyFromTVMFFIAny(field_info.default_value_or_factory).cast[Function]()
        default_val = factory()   # () -> Any, fresh value per call
        field_info.setter(field_addr, &default_val)
    else:
        field_info.setter(field_addr, &field_info.default_value_or_factory)
    # Interacts with: TVMFFIFieldInfo.setter, Function (packed call)
    # Replaces: three identical inline patterns in creator.h, reflection_extra.cc, serialization.cc
```

## Impact
- API: **Breaking rename** — `TVMFFIFieldInfo::default_value` → `default_value_or_factory`. All out-of-tree code directly accessing the field (C, Cython, Rust) must update. The C ABI struct layout is unchanged (same field, same offset).
- Behavioral: Objects whose reflected fields use `DefaultFactory` now receive independent mutable containers per construction rather than a shared alias. `DefaultValue` behavior is unchanged.
- Flags/config: New enum value `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5` in `TVMFFIFieldFlagBitMask`.
- Data formats/schemas: None — `default_value_or_factory` is not serialized to JSON (only actual field values are); the factory itself is a transient C++ `Function` object.

## Design Elements
Design elements this commit consumes:
- `TVMFFIFieldInfo` + `kTVMFFIFieldFlagBitMask*` flags (0001-c-abi) — extends the flag enum and renames a struct field.
- `reflection::DefaultValue` trait + `ObjectDef::RegisterField` (0006-reflection) — `DefaultFactory` follows the same `InfoTrait::Apply` protocol.
- `reflection::ObjectCreator` and `MakeObjectFromPackedArgs` (0006-reflection, 0010-json-serialization) — three consumption sites updated to call `SetFieldToDefault`.
- `Function` + packed calling convention (0004-function-system) — factory stored as `Function (() -> Any)`.
- Rust `TVMFFIFieldInfo` binding (0018-rust-binding) — field rename propagated.
- Cython `base.pxi` (0013-python-package) — field rename + new flag propagated.

Design elements this commit produces:
- `reflection::DefaultFactory` trait — symmetric to `DefaultValue`; produces fresh values per object construction.
- `reflection::SetFieldToDefault` helper — consolidates factory-vs-static dispatch into one shared site in `accessor.h`.
- `kTVMFFIFieldFlagBitMaskDefaultFromFactory` — new C ABI flag bit at position 5.
- `TVMFFIFieldInfo::default_value_or_factory` — renamed slot (semantics extended; layout unchanged).

## Usage Examples

**Registering an Array field with a per-instance factory default (from `tests/cpp/test_reflection.cc`)**:
```cpp
struct TestObjWithFactory : public Object {
    Array<ObjectRef> items;
    int64_t count;
    explicit TestObjWithFactory(UnsafeInit) {}
    TVM_FFI_DECLARE_OBJECT_INFO_FINAL("test.TestObjWithFactory", TestObjWithFactory, Object);
};

TVM_FFI_STATIC_INIT_BLOCK() {
    namespace refl = tvm::ffi::reflection;
    refl::ObjectDef<TestObjWithFactory>()
        .def_ro("items", &TestObjWithFactory::items,
                refl::DefaultFactory(
                    Function::FromTyped([]() -> Array<ObjectRef> { return Array<ObjectRef>(); })))
        .def_ro("count", &TestObjWithFactory::count, refl::DefaultValue(int64_t{0}));
}

// Two objects without providing "items" → distinct, non-aliased arrays:
refl::ObjectCreator creator("test.TestObjWithFactory");
Any obj1 = creator(Map<String, Any>({{"count", int64_t(42)}}));
Any obj2 = creator(Map<String, Any>({{"count", int64_t(99)}}));
// obj1.as<TestObjWithFactory>()->items.get() != obj2.as<TestObjWithFactory>()->items.get()
```
