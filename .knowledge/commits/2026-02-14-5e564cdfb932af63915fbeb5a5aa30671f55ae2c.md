# Add DefaultFactory support to field reflection for mutable defaults
## TL;DR
- Renames `TVMFFIFieldInfo::default_value` to `default_value_or_factory` across C++, Python (Cython), and Rust
- Adds `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5` flag to distinguish factory callables from static values
- Introduces `reflection::DefaultFactory` trait and `reflection::SetFieldToDefault` helper
- All three default-consumption sites (creator.h, reflection_extra.cc, serialization.cc) now share one helper

## Impact
- API: `TVMFFIFieldInfo::default_value` renamed to `default_value_or_factory` -- **breaking ABI change** for anyone accessing this field directly
- Behavioral: mutable default fields (Array, Map) now get independent instances per object instead of shared aliased references
- Flags/config: new flag bit `kTVMFFIFieldFlagBitMaskDefaultFromFactory = 1 << 5`
- Data formats/schemas: none

## Usage Examples
```cpp
// C++ definition with factory default
refl::ObjectDef<MyObj>()
    .def_ro("items", &MyObj::items,
            refl::DefaultFactory(
                Function::FromTyped([]() -> Array<ObjectRef> { return Array<ObjectRef>(); })))
    .def_ro("count", &MyObj::count, refl::DefaultValue(int64_t(0)));

// Each MyObj created without explicit "items" gets a fresh empty Array
```
