# Add DefaultFactory support to field reflection
## TL;DR
- Extends field reflection with `DefaultFactory` support, allowing fields to have factory-constructed defaults.
- Adds new C ABI fields for `field_default_factory` in `TVMFFIFieldInfo`.
- Updates reflection accessor and registry to handle default factories.

## Impact
- API: New `default_factory` in field info C ABI; new `def_field` overload accepting factory.
- Flags/config: None.
- Data formats/schemas: Extended `TVMFFIFieldInfo` structure.
