# Set up initial CI with GitHub Actions workflows, lint scripts, and pre-commit hooks
## TL;DR
- Adds two GitHub Actions workflows: `ci_test.yml` (lint + C++/Python tests on 4 OS/arch targets) and `publish_wheel.yml` (cibuildwheel build + PyPI publish).
- Introduces reusable composite actions for CPU-count detection and skip-CI logic (`[bypass ci]`, docs-only changes).
- Adds lint infrastructure: ASF header checker, file-type checker, clang-format wrapper, `task_lint.sh` orchestrator, and `.pre-commit-config.yaml`.

## Key Exports
**Workflows**:
- `.github/workflows/ci_test.yml` -- triggers on push (main, dev), PR, and workflow_dispatch. Jobs: `prepare` (skip-ci detection) -> `lint` (task_lint.sh) + `test` (matrix: ubuntu-latest x86_64, ubuntu-24.04-arm aarch64, windows-latest AMD64, macos-14 arm64).
- `.github/workflows/publish_wheel.yml` -- triggers on workflow_dispatch with `branch` input. Jobs: `build_wheels` (cibuildwheel v3.1.4 on same 4-target matrix) -> `build_sdist` -> `upload_pypi` (trusted publisher, artifact attestation).

**Composite Actions**:
- `.github/actions/detect-env-vars/action.yml` -- outputs `cpu_count` (via `multiprocessing.cpu_count()`).
- `.github/actions/detect-skip-ci/action.yaml` -- inputs: `github_event_name`, `pr_base_ref`, `pr_head_sha`. Outputs: `should_skip_ci_commit` (true if message starts with `[bypass ci]`), `should_skip_ci_docs_only` (true if all changed files under `docs/` or `*.md`).

**Lint Scripts**:
- `tests/lint/check_asf_header.py` -- CLI with `--check`, `--fix`, `--dry-run`. Uses `git ls-files` to enumerate tracked files. `FMT_MAP` dict maps file extensions to ASF header templates (C-style, Python-style, Markdown-style, RST-style, Groovy-style, CMD-style).
- `tests/lint/check_file_type.py` -- `ALLOW_EXTENSION` set (~50 extensions), `ALLOW_FILE_NAME` set, `ALLOW_SPECIFIC_FILE` set. Uses `git ls-files`, exits non-zero if disallowed file types found.
- `tests/lint/git-clang-format.sh` -- wrapper around `git-clang-format-15` with `--rev` and `-i` flags. Falls back to `clang-format` if `clang-format-15` not found.
- `tests/scripts/task_lint.sh` -- orchestrator: runs `check_file_type.py`, `check_asf_header.py --check`, `black . --check --diff`, `git-clang-format.sh`.

**Config**:
- `.pre-commit-config.yaml` -- pre-commit-hooks v5.0.0 with: check-added-large-files, check-case-conflict, check-merge-conflict, check-symlinks, end-of-file-fixer, mixed-line-ending, requirements-txt-fixer, trailing-whitespace.

## Design Elements
Design elements this commit consumes:
- `0014-python-package` (design): The CI workflow installs the Python package via `pip install -v ".[test]"` and runs `pytest -vvs tests/python`, exercising the standalone Python packaging design.
- `0014-standalone-python-package` (ADR): The `publish_wheel.yml` workflow uses cibuildwheel to build platform wheels, directly implementing the standalone package distribution decision.

Design elements this commit produces:
- **CI workflow structure convention**: Two-phase CI (prepare -> lint | test), skip-ci via composite action, 4-target OS/arch matrix. Not yet documented in `.knowledge/`.
- **Lint pipeline convention**: `task_lint.sh` as the single-entry-point lint runner (file-type -> ASF header -> black -> clang-format). Not yet documented in `.knowledge/`.
- **Skip-CI protocol**: `[bypass ci]` prefix in commit message skips all CI; docs-only changes skip test jobs. Detected via composite action.
