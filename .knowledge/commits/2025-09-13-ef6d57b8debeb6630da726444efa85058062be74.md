# Set up initial CI pipeline with GitHub Actions workflows, lint scripts, and pre-commit hooks
## TL;DR
- Added `ci_test.yml` workflow: prepare (skip-ci detection) -> lint -> test (C++ and Python) across Linux x86_64/aarch64, macOS arm64, Windows AMD64.
- Added `publish_wheel.yml` workflow: builds wheels via cibuildwheel on all 4 platforms, builds sdist, publishes to PyPI with artifact attestation.
- Added lint tooling: `check_asf_header.py`, `check_file_type.py`, `git-clang-format.sh`, `task_lint.sh` orchestrator, and `.pre-commit-config.yaml` with standard hooks.
- Minor lint-compliance fixups: `isort: skip_file` directives, expanded `black` exclude in `pyproject.toml`, whitespace normalizations in docs.

## Design Elements
Design elements this commit consumes:
- CMake build system (`cmake . -B build_test -DTVM_FFI_BUILD_TESTS=ON`) -- used as-is in CI test steps
- Python package install via pip (`pip install -v ".[test]"`) -- consumed by CI test jobs
- pytest test runner (`pytest -vvs tests/python`) -- consumed by CI test jobs
- Apache 2.0 license convention -- enforced by new `check_asf_header.py`

Design elements this commit produces:
- **CI skip-detection protocol**: Two-output GitHub Action (`.github/actions/detect-skip-ci/`) that emits `should_skip_ci_commit` and `should_skip_ci_docs_only` booleans, consumed by downstream jobs via `needs.prepare.outputs.*`
- **Lint orchestration script**: `tests/scripts/task_lint.sh` chains file-type check -> ASF header check -> black -> clang-format
- **Pre-commit baseline**: `.pre-commit-config.yaml` with `pre-commit-hooks v5.0.0` (large file, case conflict, merge conflict, symlink, EOF fixer, mixed line ending, trailing whitespace)
- **Wheel publish pipeline**: `publish_wheel.yml` using `cibuildwheel v3.1.4` with artifact attestation and PyPI trusted publishing
