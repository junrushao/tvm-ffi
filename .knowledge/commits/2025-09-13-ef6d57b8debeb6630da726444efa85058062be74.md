# Setup initial CI with GitHub Actions, pre-commit hooks, and lint scripts
## TL;DR
- Adds GitHub Actions CI workflow (`ci_test.yml`) with prepare/lint/test jobs across Linux x86_64, Linux aarch64, Windows AMD64, and macOS arm64, including skip-CI detection for `[bypass ci]` commits and docs-only changes.
- Adds GitHub Actions wheel publishing workflow (`publish_wheel.yml`) using `cibuildwheel` for the same four platform targets, with PyPI upload via trusted publisher (OIDC) and build attestation.
- Adds `.pre-commit-config.yaml` with `pre-commit-hooks` (large file check, merge conflict check, trailing whitespace, end-of-file fixer, etc.).
- Adds lint scripts: `check_asf_header.py` (ASF license header enforcement), `check_file_type.py` (allowed file type whitelist), `git-clang-format.sh` (C++ format via clang-format-15), and `task_lint.sh` (orchestrator that runs all lint checks).
- Minor fixes: adds `# isort: skip_file` to `python/tvm_ffi/__init__.py` and `examples/packaging/python/my_ffi_extension/__init__.py` to prevent isort from reordering import-order-sensitive modules; expands `[tool.black]` exclude patterns in `pyproject.toml`; adds blank line after HTML comment block in `docs/concepts/abi_overview.md`; removes stray blank line in `docs/reference/python/index.rst`.

## Key Exports

**GitHub Actions Workflows**:
- `.github/workflows/ci_test.yml` -- CI workflow triggered on push to `main`/`dev`, pull requests, and manual dispatch. Jobs: `prepare` (skip-ci detection), `lint` (file type, ASF header, black, clang-format), `test` (C++ via cmake/ctest + Python via pytest on 4 platform targets).
- `.github/workflows/publish_wheel.yml` -- Wheel publishing workflow triggered on manual dispatch. Builds wheels via `cibuildwheel` on 4 platforms, builds sdist, and publishes to PyPI with attestation.

**GitHub Actions (Reusable Composite Actions)**:
- `.github/actions/detect-env-vars/action.yml` -- Detects environment variables (CPU count) for parallel builds.
- `.github/actions/detect-skip-ci/action.yaml` -- Detects `[bypass ci]` in commit messages and docs-only changes to skip CI.

**Lint Scripts**:
- `tests/lint/check_asf_header.py` -- Checks/fixes Apache Software Foundation license headers on all git-tracked files. Supports `--check`, `--fix`, and `--dry-run` modes. Maps file extensions to header styles (C-style, Python-style, Markdown-style, RST-style, Groovy-style, CMD-style).
- `tests/lint/check_file_type.py` -- Validates that all git-tracked files have allowed extensions or names. Also checks that ASF-headered files do not have extraneous copyright lines.
- `tests/lint/git-clang-format.sh` -- Runs `git-clang-format-15` on C/C++ files (extensions: `.h`, `.mm`, `.c`, `.cc`, `.cu`). Supports `--rev` for diffing against a specific revision, `-i` for in-place formatting.
- `tests/scripts/task_lint.sh` -- Orchestration script that runs `check_file_type.py`, `check_asf_header.py --check`, `black . --check --diff`, and `git-clang-format.sh` in sequence.

**Configuration Changes**:
- `.pre-commit-config.yaml` -- Pre-commit hooks config with `pre-commit-hooks` v5.0.0 (check-added-large-files, check-case-conflict, check-merge-conflict, check-symlinks, end-of-file-fixer, mixed-line-ending, requirements-txt-fixer, trailing-whitespace).
- `pyproject.toml` -- Expanded `[tool.black]` exclude to skip `.venv`, `build`, `docs`, `dist`, and `3rdparty` directories.

## Design Elements
Design elements this commit consumes:
- **Standalone repo identity** (established in `30f1e0af`): This commit builds on the initial repo scaffolding by adding CI, linting, and publishing infrastructure.
- **C++ build system**: The CI workflow reuses the existing cmake-based build (`cmake . -B build_test -DTVM_FFI_BUILD_TESTS=ON`) for C++ tests.
- **Python packaging** (`.knowledge/designs/0015-python-packaging.md`): The publish workflow uses `cibuildwheel` and `pip install -v ".[test]"` patterns consistent with the project's packaging design.

Design elements this commit produces:
- **CI pipeline architecture**: Two-workflow design with `ci_test.yml` (continuous) and `publish_wheel.yml` (manual release). The CI workflow uses a `prepare` job to detect skip conditions (commit message `[bypass ci]`, docs-only changes) that gate downstream `lint` and `test` jobs. Test matrix covers 4 OS/arch combinations: `ubuntu-latest` (x86_64), `ubuntu-24.04-arm` (aarch64), `windows-latest` (AMD64), `macos-14` (arm64).
- **Skip-CI detection**: The `detect-skip-ci` composite action implements two skip conditions: (1) commit message starts with `[bypass ci]`, (2) all changed files are under `docs/` or have `.md` extension. For pull requests, it diffs `origin/<base_ref>` against the PR head SHA; for pushes, it diffs `HEAD^` against `HEAD`.
- **Lint orchestration**: `task_lint.sh` defines the canonical lint sequence: file type check, ASF header check, black formatting check, clang-format check. This is the single entry point called by the CI lint job.
- **ASF header enforcement**: `check_asf_header.py` maps file extensions to header comment styles via `FMT_MAP` and supports both checking and auto-fixing. It uses `git ls-files` to enumerate tracked files and has a `SKIP_LIST` (initially empty) for exceptions.
- **File type allowlist**: `check_file_type.py` maintains `ALLOW_EXTENSION`, `ALLOW_FILE_NAME`, and `ALLOW_SPECIFIC_FILE` sets to prevent accidental check-in of binary or unsupported file types.
- **Wheel publishing pipeline**: Uses `cibuildwheel` v3.1.4 for cross-platform wheel builds, `build --sdist` for source distribution, `twine check` for metadata validation, and `gh-action-pypi-publish` with OIDC trusted publishing and build attestation via `attest-build-provenance`.
- **Pre-commit baseline**: Initial `.pre-commit-config.yaml` with standard hygiene hooks (trailing whitespace, merge conflict detection, large file prevention). This is the foundation that later commits extend with ruff, clang-format, cython-lint, and other project-specific hooks.

## Usage Examples

### Running lint locally
**Context**: The `task_lint.sh` script is the same entry point used by CI.
```bash
# Run all lint checks (same as CI)
tests/scripts/task_lint.sh

# Check ASF headers only
python tests/lint/check_asf_header.py --check

# Auto-fix missing ASF headers
python tests/lint/check_asf_header.py --fix

# Check C++ formatting against all files
tests/lint/git-clang-format.sh

# Check C++ formatting against a specific revision
tests/lint/git-clang-format.sh --rev HEAD~1

# In-place format C++ files
tests/lint/git-clang-format.sh -i
```

### Skip CI on a commit
**Context**: Prefix commit message with `[bypass ci]` to skip the entire CI pipeline.
```bash
git commit -m "[bypass ci] Update docs only"
```
