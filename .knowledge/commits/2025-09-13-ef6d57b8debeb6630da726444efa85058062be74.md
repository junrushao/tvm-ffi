# Setup initial CI with GitHub Actions, lint scripts, and publish workflow
## TL;DR
- Adds GitHub Actions CI pipeline (`ci_test.yml`) with prepare/lint/test jobs across Linux x86_64/aarch64, macOS arm64, and Windows AMD64, including skip-CI detection for `[bypass ci]` and docs-only changes.
- Adds wheel publishing workflow (`publish_wheel.yml`) using `cibuildwheel` with PyPI trusted publisher attestations and sdist build.
- Introduces pre-commit config, ASF header checker (`check_asf_header.py`), file type checker (`check_file_type.py`), and clang-format wrapper script; minor whitespace/isort fixes in docs and Python files.

## Impact
- API: none
- Flags/config: `pyproject.toml` black exclude patterns expanded. New `.pre-commit-config.yaml` with standard hooks (trailing whitespace, EOF fixer, large-file check, etc.).
- Data formats/schemas: none
- CI/CD: This is the genesis CI commit -- establishes the entire GitHub Actions infrastructure. All future PRs will be gated by these workflows.

## Design Elements
Design elements this commit **consumes**:
- **Packaging and build** (`.knowledge/designs/0016-packaging-and-build.md`): The publish workflow relies on the existing `pyproject.toml` build configuration and cibuildwheel support to produce platform-specific wheels.
- **C ABI** (`.knowledge/designs/0001-c-abi.md`): The CI test job runs C++ tests via CMake (`TVM_FFI_BUILD_TESTS=ON`) as part of the validation pipeline.

Design elements this commit **produces**:
- **CI pipeline structure**: A three-stage pipeline (prepare -> lint -> test) with conditional skip logic based on commit message (`[bypass ci]`) and docs-only change detection. The `detect-skip-ci` composite action uses git diff against the base branch to classify changes.
- **Lint infrastructure**: `check_asf_header.py` enforces Apache 2.0 license headers across all git-tracked files with format-specific header templates (C-style, Python-style, RST-style, etc.). `check_file_type.py` whitelists allowed file extensions to prevent binary checkins. `git-clang-format.sh` wraps `clang-format-15` for C++ formatting checks.
- **Wheel publish pipeline**: A workflow_dispatch-triggered pipeline that builds wheels via cibuildwheel on 4 platforms, builds sdist, then publishes to PyPI with attestation support.

## Reflection

  - `.knowledge/designs/0021-ci-cd-pipeline.md`: Should cover the three-stage pipeline structure, skip-CI detection logic, the matrix of OS/arch targets, and the relationship between lint/test/publish workflows. Future commits modifying CI (adding linters, changing matrix) would reference this.

* **ADRs to write**:
  - `.knowledge/ADRs/0038-ci-skip-detection.md`: Documents the decision to use `[bypass ci]` prefix (not `[skip ci]`) and docs-only detection via file path patterns (`docs/` prefix or `.md` extension). Alternative: GitHub's native `[skip ci]` -- the custom approach gives finer granularity (skip tests but keep lint for docs-only).

* **Design diagrams to draw**:
  - Mermaid flowchart showing: `push/PR -> prepare (skip detection) -> lint (parallel) / test (matrix) -> publish (manual dispatch only)` with conditional edges based on skip flags.
