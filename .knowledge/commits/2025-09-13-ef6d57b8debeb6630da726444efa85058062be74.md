# Setup initial CI with GitHub Actions, pre-commit, and lint scripts
## TL;DR
- Adds GitHub Actions workflows for CI testing (`ci_test.yml`) across Linux x86_64/aarch64, macOS arm64, and Windows AMD64, and wheel publishing (`publish_wheel.yml`) via cibuildwheel with PyPI trusted publishing.
- Introduces reusable composite actions: `detect-env-vars` (CPU count) and `detect-skip-ci` (`[bypass ci]` prefix and docs-only change detection).
- Adds lint infrastructure: `check_asf_header.py`, `check_file_type.py`, `git-clang-format.sh`, `task_lint.sh` orchestrator, and `.pre-commit-config.yaml` with standard hooks.
- Minor formatting fixes to existing files (`pyproject.toml` black exclude, `isort: skip_file` comments, doc whitespace) to pass the new linters.
