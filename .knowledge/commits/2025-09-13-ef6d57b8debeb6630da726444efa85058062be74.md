# Setup initial CI with GitHub Actions workflows, lint scripts, and pre-commit config
## TL;DR
- Added GitHub Actions CI workflow (`ci_test.yml`) with lint, C++ test, and Python test jobs across Linux x86_64/aarch64, macOS arm64, and Windows AMD64.
- Added wheel publishing workflow (`publish_wheel.yml`) using cibuildwheel with PyPI trusted publishing via OIDC.
- Added lint infrastructure: ASF header checker, file type checker, clang-format wrapper, pre-commit config, and a task_lint.sh orchestrator.

## Design Elements
Design elements this commit consumes:
- CI test matrix mirrors the platform support documented in the project (Linux x86_64 + aarch64, macOS arm64, Windows AMD64)
- Uses `cmake` + `ctest` build pattern from CLAUDE.md for C++ tests
- Uses `pip install ".[test]"` + `pytest` for Python tests

Design elements this commit produces:
- **CI pipeline structure**: `prepare` (skip-ci detection) -> `lint` + `test` (parallel). Skip-CI is driven by `[bypass ci]` commit message prefix or docs-only change detection.
- **Lint toolchain**: `task_lint.sh` orchestrates file type check, ASF header check, black formatting check, and clang-format check in sequence.
- **Pre-commit hooks**: standard hooks from `pre-commit/pre-commit-hooks` v5.0.0 (large files, case conflict, merge conflict, symlinks, EOF fixer, mixed line endings, trailing whitespace).
- **Wheel publishing pipeline**: workflow_dispatch triggered, builds via cibuildwheel v3.1.4, publishes to PyPI with OIDC attestation.
