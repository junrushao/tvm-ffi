# Fix Windows build by linking Python::SABIModule/Module explicitly and adding InterlockedAdd64 fallback for ARM64.

## TL;DR
- `CMakeLists.txt`: explicitly link `tvm_ffi_cython` to `Python::SABIModule` (all platforms) and `Python::Module` (non-Windows, inside the `>= 3.12` branch) so the Windows linker resolves Python symbols.
- `include/tvm/ffi/base_details.h`: on Windows ARM64 targets (`_M_ARM64`/`_ARM64_`/`_M_ARM64EC`), define `_InlineInterlockedAdd64` as `InterlockedAdd64` when the inline intrinsic variant is missing, fixing compilation of the ref-count fast path.
- `.github/workflows/ci_test.yml`: upgrade the aarch64 Linux CI Python version from 3.9 to 3.10.
