# Fix Windows build: link Python modules and fallback InterlockedAdd64
## TL;DR
- Explicitly linked `tvm_ffi_cython` to `Python::SABIModule` and `Python::Module` in CMake for correct Windows symbol resolution.
- Added `#define _InlineInterlockedAdd64 InterlockedAdd64` fallback for ARM64 Windows where `_InlineInterlockedAdd64` is not available.
- Bumped CI aarch64 Linux test from Python 3.9 to 3.10.
