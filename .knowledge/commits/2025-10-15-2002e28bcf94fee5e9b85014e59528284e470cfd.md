# Fix Windows build by linking Python targets and falling back to InterlockedAdd64 on ARM64
## TL;DR
- Explicitly link `tvm_ffi_cython` to `Python::SABIModule` (always) and `Python::Module` (non-Windows), fixing unresolved symbols on Windows.
- Add a preprocessor fallback from `_InlineInterlockedAdd64` to `InterlockedAdd64` for ARM64 Windows where the inline intrinsic is unavailable.
- Bump CI minimum Python from 3.9 to 3.10 on aarch64 Linux.
