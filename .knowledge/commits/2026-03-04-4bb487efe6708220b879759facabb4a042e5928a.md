# Extend TVMFFIFieldInfo setter to support FunctionObj dispatch (bit 11)

## TL;DR
- Adds `kTVMFFIFieldFlagBitSetterIsFunctionObj = 1 << 11` to `TVMFFIFieldFlags`. When set, `TVMFFIFieldInfo::setter` holds a `TVMFFIObjectHandle` (FunctionObj) instead of a raw function pointer.
- `setter` field type changed from `TVMFFIFieldSetter` to `void*`.
- New `CallFieldSetter` helper in `accessor.h` centralizes dispatch: casts to `TVMFFIFieldSetter` when flag off; calls `TVMFFIFunctionCall` when flag on.

## Impact
- API: **Breaking**. `TVMFFIFieldInfo::setter` type changed from `TVMFFIFieldSetter` to `void*`. All code accessing `setter` directly must be updated. Rust `c_api.rs` updated.
- Behavioral: Enables Python `@property`-style setters registered as `FunctionObj` to work through the reflection system.
- Flags/config: none
- Data formats/schemas: none
