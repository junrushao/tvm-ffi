# Extend TVMFFIFieldInfo setter to support FunctionObj dispatch

## TL;DR
- New `kTVMFFIFieldFlagBitSetterIsFunctionObj = 1 << 11` flag in `TVMFFIFieldFlags`; when set, `TVMFFIFieldInfo::setter` is a `TVMFFIObjectHandle` (FunctionObj) called with `(field_addr_as_OpaquePtr, value_as_AnyView)`.
- `TVMFFIFieldInfo::setter` type changed from `TVMFFIFieldSetter` (function pointer) to `void*` to accommodate both variants.
- New `CallFieldSetter` helper in `accessor.h` centralizes dispatch: checks flag, casts accordingly, and invokes.
- All call sites updated: C++ (`init.h`, `creator.h`, `serialization.cc`, `reflection_extra.cc`), Cython (`base.pxi`, `type_info.pxi`, `object.pxi`, `tvm_ffi_python_helpers.h`), Rust (`c_api.rs`).

```c
typedef enum {
    // ...existing flags...
    kTVMFFIFieldFlagBitMaskKwOnly = 1 << 10,
    kTVMFFIFieldFlagBitSetterIsFunctionObj = 1 << 11,  // NEW
} TVMFFIFieldFlags;

typedef struct {
    TVMFFIFieldGetter getter;
    // BREAKING: was TVMFFIFieldSetter (function pointer), now void*
    void* setter;  // cast to TVMFFIFieldSetter OR TVMFFIObjectHandle depending on flag
    // ...other fields...
} TVMFFIFieldInfo;
```

```cpp
// include/tvm/ffi/reflection/accessor.h

inline int CallFieldSetter(const TVMFFIFieldInfo* field_info, void* field_addr,
                           const TVMFFIAny* value) {
    // Interacts with: TVMFFIFunctionCall (C ABI), TVMFFIFieldSetter (function ptr)
    // Invariant: when kTVMFFIFieldFlagBitSetterIsFunctionObj is set, setter is a live FunctionObj
    // Invariant: FunctionObj called with 2 args: (field_addr as OpaquePtr, value as AnyView)
    if (!(field_info->flags & kTVMFFIFieldFlagBitSetterIsFunctionObj)) {
        auto setter = reinterpret_cast<TVMFFIFieldSetter>(field_info->setter);
        return setter(field_addr, value);
    } else {
        // Call FunctionObj(field_addr_as_OpaquePtr, value)
        TVMFFIAny args[2]; ...
        return TVMFFIFunctionCall(static_cast<TVMFFIObjectHandle>(field_info->setter), args, 2, &result);
    }
}
```

```rust
}
```

## Impact
- API: **BREAKING** (C ABI) — `TVMFFIFieldInfo::setter` is now `void*`. Code directly accessing `setter` as a function pointer must cast from `void*` or use `CallFieldSetter`.
- Behavioral: When `kTVMFFIFieldFlagBitSetterIsFunctionObj` is set, setting a field invokes a `FunctionObj` via `TVMFFIFunctionCall` — enables Python-callable field setters from C++.
- Flags/config: `kTVMFFIFieldFlagBitSetterIsFunctionObj = 1 << 11`
- Data formats/schemas: `TVMFFIFieldInfo` struct layout change (setter member type).

## Usage Examples

C++ registration with FunctionObj setter:
```cpp
// ObjectDef registration would set kTVMFFIFieldFlagBitSetterIsFunctionObj
// and store a FunctionObj handle in field_info->setter
// CallFieldSetter automatically dispatches:
CallFieldSetter(field_info, field_addr, &value);
// If flag off: calls setter(field_addr, &value) as function pointer
// If flag on: calls FunctionObj(OpaquePtr(field_addr), AnyView(value))
```
