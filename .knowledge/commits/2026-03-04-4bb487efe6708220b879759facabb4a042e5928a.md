# Extend TVMFFIFieldInfo setter to support FunctionObj dispatch
## TL;DR
- Extends `TVMFFIFieldInfo` with a `setter` field that can point to a `FunctionObj` for custom field setting logic (e.g., type-checked assignment).
- Updates C ABI, C++ reflection accessor, Cython bindings, and Rust bindings.

## Key Exports

```python
# C ABI addition:
# TVMFFIFieldInfo.setter: void*  # points to FunctionObj for custom setter dispatch
# Interacts with: reflection accessor, field write path
# Invariant: if setter is NULL, uses direct memory write; if non-NULL, calls FunctionObj
```

## Impact
- API: New `setter` field in `TVMFFIFieldInfo` C ABI struct.
- Behavioral: Enables type-checked field writes via function dispatch.
- Flags/config: None
- Data formats/schemas: C ABI struct layout change.
