# Extend TVMFFIFieldInfo setter to support FunctionObj dispatch

## TL;DR
- **BREAKING C ABI**: `TVMFFIFieldInfo.setter` changed from `TVMFFIFieldSetter` to `void*`; new flag bit `kTVMFFIFieldFlagBitSetterIsFunctionObj` (1 << 11) controls dispatch.
- `CallFieldSetter` helper centralizes dispatch: flag off = cast to `TVMFFIFieldSetter`; flag on = `TVMFFIFunctionCall` with `(field_addr, value)`.
- Updated across C++ reflection (`init.h`, `creator.h`), Cython bindings, and Rust FFI struct.

## Impact
- API: **Breaking C ABI** — `TVMFFIFieldInfo.setter` type changed to `void*`.
- Behavioral: Field setters can now be FunctionObj instances (enabling Python-defined setters).
