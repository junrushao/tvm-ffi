# Add C++17 structured bindings, ADL get(), and move semantics to Tuple
## TL;DR
- Enable C++17 structured bindings for `tvm::ffi::Tuple<Types...>` by specializing `std::tuple_size` and `std::tuple_element`, and adding free-function `get<I>()` overloads in the `tvm::ffi` namespace for ADL.
- Add rvalue-ref `get() &&` overload that moves the element out of the tuple when the ref count is 1, falling back to copy when shared.
- Add a CTAD (class template argument deduction) guide: `Tuple(UTypes&&...) -> Tuple<decay_t<UTypes>...>`.

## Key Exports
**Types** (mutated):
- `Tuple<Types...>` (`include/tvm/ffi/container/tuple.h`):
  - `template <size_t I> auto get() const&` — existing, signature narrowed from `get() const` to `get() const&`
  - `template <size_t I> auto get() &&` — **new**, moves element out if `this->unique()`, copies otherwise

**Free functions** (new, ADL-friendly):
- `template <size_t I, typename... Types> auto get(const Tuple<Types...>& t) -> tuple_element_t<I, tuple<Types...>>`
- `template <size_t I, typename... Types> auto get(Tuple<Types...>&& t) -> tuple_element_t<I, tuple<Types...>>`

**std specializations** (new):
- `std::tuple_size<tvm::ffi::Tuple<Types...>>` — yields `sizeof...(Types)`
- `std::tuple_element<I, tvm::ffi::Tuple<Types...>>` — yields `std::tuple_element_t<I, std::tuple<Types...>>`

**Deduction guide** (new):
- `Tuple(UTypes&&...) -> Tuple<std::remove_cv_t<std::remove_reference_t<UTypes>>...>`

## Impact
- API: Public header change. Existing code calling `get() const` continues to work (now binds to `get() const&`). New capabilities: structured bindings, ADL `get`, move-out semantics.
- Behavioral: `get() &&` on a uniquely-owned tuple will move elements out (uses `MutableBegin()` + `MoveFromAnyAfterCheck`), leaving the Any slot empty. When ref count > 1, falls back to copy.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Tuple container** — `Tuple<Types...>` extends `ObjectRef`, backed by `ArrayObj`. Documented in `.knowledge/designs/0008-containers.md`.
- **AnyUnsafe utilities** — `CopyFromAnyViewAfterCheck`, `MoveFromAnyAfterCheck` for type-erased element access.
- **ObjectRef uniqueness** (`this->unique()`) — ref-count check to decide move vs copy.

Design elements this commit produces:
- **Tuple structured binding protocol** — `std::tuple_size`/`std::tuple_element` specializations + ADL `get` enable `auto [a, b, c] = tuple;` syntax.
- **Tuple move-out semantics** — rvalue `get() &&` that transfers ownership when uniquely held, consistent with the container mutation convention (check `unique()` before mutating).

## Usage Examples
```cpp
using namespace tvm::ffi;

// CTAD + structured binding
auto t = Tuple{1, 2.0f, String{"hello"}};
auto [a, b, c] = t;  // a=1, b=2.0f, c="hello"

// Move semantics: element moved out when unique
auto p = Tuple{Array<int>{0}};
assert(p.use_count() == 1);
auto [arr] = std::move(p);  // arr gets sole ownership
assert(arr.use_count() == 1);

// ADL-friendly get
auto q = Tuple{42, String{"world"}};
using std::get;
auto val = get<0>(q);  // ADL finds tvm::ffi::get
```
