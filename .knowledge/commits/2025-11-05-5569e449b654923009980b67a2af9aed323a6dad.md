# Add C++17 structured binding, ADL get, deduction guide, and move-get to Tuple
## TL;DR
- Enables C++17 structured bindings on `Tuple<Types...>` via `std::tuple_size`/`std::tuple_element` specializations and ADL-friendly free `get<I>()` functions.
- Adds rvalue-ref `get() &&` overload that moves elements out when the tuple has unique ownership (refcount == 1), falling back to copy when shared.
- Adds a C++17 deduction guide so `Tuple{1, 2.0f, String{"hello"}}` deduces `Tuple<int, float, String>` automatically.

## Impact
- API: Additive. Existing `get() const` signature narrowed to `get() const&` (compatible change -- const lvalue callers bind identically). New rvalue `get() &&`, free `get<I>()`, deduction guide, and `std` specializations added.
- Behavioral: Move-get transfers element ownership when refcount == 1, avoiding a copy. Shared tuples still copy (safe fallback).
- Flags/config: none
- Data formats/schemas: none

- **Move-semantic `get() &&`**: ref-qualified overload with unique-ownership optimization. Establishes the pattern: check `unique()`, move if sole owner, copy otherwise.

## Usage Examples
**Context**: C++17 structured bindings and move semantics with `Tuple` (from `tests/cpp/test_tuple.cc`).
```cpp
// Deduction guide + structured binding (lvalue copy)
auto t = Tuple{1, 2.0f, String{"hello"}};
auto [a, b, c] = t;          // copies; t still valid
// a == 1, b == 2.0f, c == "hello"

// ADL-friendly get (const ref, copies element)
auto p = Tuple{Array<int>{0}};
const auto q = get<0>(p);     // copies; q.use_count() == 2

// Structured binding (rvalue, moves elements out)
auto p2 = Tuple{Array<int>{0}};
auto [arr] = std::move(p2);   // moves; arr.use_count() == 1

// Move-get with shared refcount (safe fallback to copy)
auto p3 = Tuple{Array<int>{0}};
auto shared = p3;              // p3.use_count() == 2
auto elem = get<0>(std::move(shared));  // copies (refcount > 1)
```
