# Add structured binding support and move semantics to ffi::Tuple via ADL-friendly get<I>()

## TL;DR
- `Tuple::get<I>()` gains two overloads: lvalue-ref (`const&`) returns by value copy; rvalue-ref (`&&`) moves the I-th element out if the ref-count is 1.
- Adds ADL-friendly free `get<I>(t)` in `tvm::ffi` namespace and `std::tuple_size`/`std::tuple_element` specializations so C++17 structured bindings (`auto [a, b] = t;`) work.
- 67 lines of new test coverage.

## Key Exports

```python
# C++ pseudocode — include/tvm/ffi/container/tuple.h
class Tuple:
    """Type-indexed tuple container backed by Array<Any>.
    # Interacts with: Any, AnyView, Array<Any>, std::tuple_element, std::tuple_size
    # Extension: add new element types via TypeTraits<T> specialization
    """
    def get_I_lvalue(self) -> ReturnType: ...
    # Invariant: returns copy — safe even if ref count > 1

    def get_I_rvalue(self) -> ReturnType: ...
    # Invariant: moves element only if unique() (ref count == 1); else copies

# ADL get — required for structured bindings
# Placed in tvm::ffi namespace for ADL lookup
# Usage: { using std::get; get<0>(t); }  or  auto [a, b] = t;
def get_tuple_I(t: Tuple[T0, T1, ...]) -> Ti: ...

# std specializations (in namespace std):
# std::tuple_size<Tuple<T...>>::value == sizeof...(T)
# std::tuple_element<I, Tuple<T...>>::type == T_I
```

## Impact
- API: Adds `Tuple::get<I>() &&` overload and ADL free `get<I>` — backward compatible additions.
- Behavioral: Rvalue `get<I>()` moves element when unique; this changes semantics for code moving Tuples.
- Flags/config: none
- Data formats/schemas: none
