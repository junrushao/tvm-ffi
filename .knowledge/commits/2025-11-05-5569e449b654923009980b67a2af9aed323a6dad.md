# Add structured binding support to Tuple via ADL-friendly get()
## TL;DR
- Adds move-qualified `get() &&` overload that moves out elements when the Tuple is unique (falls back to copy if shared)
- Adds ADL-friendly free functions `get<I>(tuple)` for both lvalue and rvalue references
- Specializes `std::tuple_size` and `std::tuple_element` to enable C++17 structured bindings for `Tuple<Types...>`

## Key Exports
```python
# C++ Tuple (pseudocode of new additions)
class Tuple(ObjectRef):  # Tuple<Types...>
    def get[I](self) -> T:  # const& overload (existing, unchanged)
        ...
    def get[I](self) -> T:  # && overload (NEW: move semantics when unique)
        # Invariant: if not self.unique(), falls back to copy
        ...

# ADL-friendly free functions (NEW)
def get[I](t: Tuple) -> T: ...  # const& version
def get[I](t: Tuple) -> T: ...  # && version

# std specializations enabling structured bindings:
# std::tuple_size<Tuple<T...>> = sizeof...(T)
# std::tuple_element<I, Tuple<T...>> = decltype(tuple.get<I>())
```

## Impact
- API: New `get() &&` overload + ADL free functions; backward compatible
- Behavioral: Enables `auto [a, b] = tuple;` structured bindings in C++17
- Flags/config: None
- Data formats/schemas: None
