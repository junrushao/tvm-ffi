# Add C++17 structured binding and ADL get() support to Tuple
## TL;DR
- Add `std::tuple_size` and `std::tuple_element` specializations for `tvm::ffi::Tuple<Types...>`, enabling C++17 structured bindings (`auto [a, b, c] = tuple;`).
- Add ADL-friendly free-function `get<I>(tuple)` overloads (const lvalue and rvalue) in `tvm::ffi` namespace, plus a rvalue-qualified `get() &&` member that moves elements out when the tuple is uniquely owned.
- Add a CTAD deduction guide: `Tuple(UTypes&&...) -> Tuple<decay_t<UTypes>...>`.

## Key Exports

**`Tuple::get<I>() &&` (member, rvalue-ref qualified)**:
Move-out accessor. When `this->unique()` is true, moves the I-th element via `AnyUnsafe::MoveFromAnyAfterCheck` on `MutableBegin()`. Falls back to the `const&` copy path when the tuple is shared.

**`tvm::ffi::get<I>(const Tuple<Types...>&)` (free function)**:
ADL-friendly const-lvalue get. Returns `std::tuple_element_t<I, std::tuple<Types...>>` by delegating to `t.template get<I>()`.

**`tvm::ffi::get<I>(Tuple<Types...>&&)` (free function)**:
ADL-friendly rvalue get. Returns same type, delegates to `std::move(t).template get<I>()` (invokes the new rvalue-qualified member).

**`std::tuple_size<tvm::ffi::Tuple<Types...>>`**:
Specialization inheriting `std::integral_constant<size_t, sizeof...(Types)>`.

**`std::tuple_element<I, tvm::ffi::Tuple<Types...>>`**:
Specialization with `using type = std::tuple_element_t<I, std::tuple<Types...>>`.

**Deduction guide**: `Tuple(UTypes&&...) -> Tuple<std::remove_cv_t<std::remove_reference_t<UTypes>>...>`.

## Impact
- API: New functionality only; existing `get<I>() const` is re-qualified as `get<I>() const&` (backward compatible since lvalue calls match both `const` and `const&`).
- ABI: None. No object layout changes; additions are header-only template code.
- Behavioral: `get<I>()` on a uniquely-owned rvalue tuple now moves the element instead of copying. This is an optimization, not a semantic break (the moved-from slot becomes undefined, but the tuple is consumed).
- Flags/config: None.
- Data formats/schemas: None.

Design elements this commit produces:

- ADL-friendly `get()` free functions enabling `using std::get; get<I>(t);` pattern
- Move-semantic `get() &&` for zero-copy element extraction from uniquely-owned tuples

## Usage Examples

Structured binding (lvalue copy):
```cpp
auto t = Tuple{1, 2.0f, String{"hello"}};  // CTAD
auto [a, b, c] = t;
// a == 1, b == 2.0f, c == "hello"
// t is still valid (elements were copied)
```

Structured binding (rvalue move):
```cpp
auto t = Tuple{Array<int>{0}};
auto [arr] = std::move(t);
// arr.use_count() == 1  (moved, not copied)
```

ADL-friendly get with move semantics:
```cpp
auto t = Tuple{Array<int>{0}};
// When t is uniquely owned, element is moved out:
Array<int> arr = get<0>(std::move(t));
// arr.use_count() == 1
```
