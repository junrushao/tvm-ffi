# Add structured binding support to tvm::ffi::Tuple
## TL;DR
- Extends `include/tvm/ffi/container/tuple.h` with `std::tuple_size`, `std::tuple_element`, and `get<>()` specializations so `tvm::ffi::Tuple` supports C++17 structured bindings (e.g., `auto [a, b] = tuple;`).
- Adds comprehensive test coverage in `tests/cpp/test_tuple.cc`.
