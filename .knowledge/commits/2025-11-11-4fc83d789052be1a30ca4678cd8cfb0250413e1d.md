# Enhanced CUDA availability check using torch.cuda.is_available()
## TL;DR
- Fixes CUDA detection by adding `torch.cuda.is_available()` check in addition to `torch.version.cuda`
- `torch.version.cuda` being set does not guarantee CUDA runtime is available in the environment
- Updates both the addon build backend and the JIT build path
- Bumps C ABI patch version
