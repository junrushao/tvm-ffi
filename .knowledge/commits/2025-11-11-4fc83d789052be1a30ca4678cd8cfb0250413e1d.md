# Fix CUDA availability check to use torch.cuda.is_available() before version sniffing
## TL;DR
- Fixes a bug where `torch.version.cuda` alone was used to detect CUDA support; this is insufficient because PyTorch can report a CUDA version string even when no GPU hardware/driver is available. Now `torch.cuda.is_available()` gates the GPU path.
- The same two-level check (`is_available()` then `version.cuda`/`version.hip`) is applied consistently in three places: the build backend, the runtime extension loader, and the test harness.
- Bumps `TVM_FFI_VERSION_PATCH` from 2 to 3.

## Key Exports
None — this commit does not introduce new public API. It corrects the internal CUDA detection logic.

## Impact
- API: none
- Behavioral: On systems where PyTorch is built with CUDA headers but no GPU/driver is present, the torch_c_dlpack extension now correctly falls back to CPU instead of attempting (and failing) a CUDA build. A new `ValueError` is raised if `torch.cuda.is_available()` is true but neither `torch.version.cuda` nor `torch.version.hip` is set.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **torch_c_dlpack extension loading** (`.knowledge/design-records/0012-ffi-python-package.md`): `load_torch_c_dlpack_extension()` JIT-compiles a native extension; this commit fixes its GPU detection guard.
- **TVM_FFI_VERSION_PATCH** (`.knowledge/design-records/0001-ffi-c-abi.md`): version bump from 2 to 3.

Design elements this commit produces:
- None — purely a bugfix consuming existing patterns.

## Usage Examples
Before (broken):
```python
# torch.version.cuda is not None even without a GPU present,
# causing the build to attempt --build-with-cuda and fail.
if torch.version.cuda is not None:
    device = "cuda"
elif torch.version.hip is not None:
    device = "rocm"
else:
    device = "cpu"
```

After (corrected):
```python
# Gate on actual GPU availability first, then determine variant.
if torch.cuda.is_available():
    if torch.version.cuda is not None:
        device = "cuda"
    elif torch.version.hip is not None:
        device = "rocm"
    else:
        raise ValueError("Cannot determine whether to build with CUDA or ROCm.")
else:
    device = "cpu"
```
