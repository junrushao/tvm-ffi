# Fix CUDA availability check to use torch.cuda.is_available() before checking version strings
## TL;DR
- The CUDA detection logic in three places (build backend, runtime loader, test) used `torch.version.cuda is not None` to decide whether to build/select CUDA or ROCm variants. This is wrong: `torch.version.cuda` is non-None even in CPU-only environments where CUDA libraries are not actually available.
- The fix gates the GPU-type check behind `torch.cuda.is_available()` first, falling back to `device="cpu"` (runtime) or no extra args (build/test) when no GPU environment is present.
- Version bump: `TVM_FFI_VERSION_PATCH` 2 -> 3.

## Key Exports
None (bugfix only -- no new public API surface).

## Impact
- API: None
- Behavioral: `load_torch_c_dlpack_extension()` now correctly selects `device="cpu"` on systems where PyTorch was built with CUDA headers but no GPU runtime is present. Previously it would attempt to load a CUDA-tagged addon `.so` that might not exist or fail at load time.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Three-tier torch DLPack loading** ([0017-dlpack-interop.md](../designs/0017-dlpack-interop.md)): The runtime loader in `_optional_torch_c_dlpack.py` determines the device tag (`cuda`/`rocm`/`cpu`) for the cached `.so` filename. This commit fixes the device-tag selection logic.
- **AOT addon build backend** ([0017-dlpack-interop.md](../designs/0017-dlpack-interop.md)): `build_backend.py` passes `--build-with-cuda`/`--build-with-rocm` based on the same detection. Fixed identically.

Design elements this commit produces:
- None (no new design elements).

## Usage Examples
**Before** (broken -- selects CUDA on CPU-only systems):
```python
# torch.version.cuda is not None even on CPU-only PyTorch installs
if torch.version.cuda is not None:
    device = "cuda"  # Wrong! No GPU runtime available
elif torch.version.hip is not None:
    device = "rocm"
else:
    device = "cpu"
```

**After** (correct -- gates on actual GPU availability):
```python
if torch.cuda.is_available():
    if torch.version.cuda is not None:
        device = "cuda"
    elif torch.version.hip is not None:
        device = "rocm"
    else:
        raise ValueError("Cannot determine whether to build with CUDA or ROCm.")
else:
    device = "cpu"
```
