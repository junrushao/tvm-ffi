# Introduce reflection::GlobalDef as new fluent API for global function registration
## TL;DR
- Adds `reflection::GlobalDef`, a fluent builder class for registering global functions, aligning global function registration with the existing reflection-style API (`ObjectDef`).
- Migrates all existing `TVM_FFI_REGISTER_GLOBAL` call sites in core FFI (`container.cc`, `function.cc`, `ndarray.cc`, `object.cc`, `testing.cc`) to use `GlobalDef` within `TVM_FFI_STATIC_INIT_BLOCK`.
- Enhances `ReflectionDefBase::GetMethod` to support both `ObjectRef` and `Object` subclasses via `if constexpr` branching, passing `ObjectRef` by value instead of by const pointer.

## Impact
- API: `GlobalDef` is a new public API in `tvm::ffi::reflection`. The old `TVM_FFI_REGISTER_GLOBAL` macro still exists and works (not removed), but core FFI code is migrated away from it. The `GetMethod` dispatch now correctly handles `ObjectRef` subclasses by-value, which changes how method pointers on `ObjectRef` types are wrapped.
- Behavioral: The error message format for `Function` type name changed from `object.Function` to `ffi.Function` (visible in test_function.cc assertion update). This is a type_key rename side-effect.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Function system** (0003): `Function::FromTyped`, `Function::FromPacked`, `Function::SetGlobal` via `TVMFFIFunctionSetGlobalFromMethodInfo` C API.
- **Reflection system** (0008): `ReflectionDefBase` base class, `TVMFFIMethodInfo` struct, `ApplyMethodInfoTrait`, `GetMethod` helpers.
- **C ABI** (0007): `TVMFFIMethodInfo`, `TVMFFIFunctionSetGlobalFromMethodInfo`, `TVMFFIByteArray`.
- **Type traits** (0005): `TypeTraits<T>` for argument conversion in `FromTyped`/`FromPacked`.
- **Object system** (0002): `ObjectRef`/`Object` base class distinction used in `GetMethod` `if constexpr` branching.

Design elements this commit produces:
- **`reflection::GlobalDef`**: New fluent builder for global function registration, analogous to `ObjectDef` for type reflection. Registers functions via `TVMFFIFunctionSetGlobalFromMethodInfo` with metadata (name, docstring, type schema).
- **`ObjectRef`-aware method wrapping**: `GetMethod` now dispatches differently for `ObjectRef` subclasses (pass by value) vs `Object` subclasses (pass by const pointer). This is an incremental extension of the existing reflection base.

## Usage Examples
Registering multiple global functions in a single static init block (from `container.cc`):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("ffi.ArrayGetItem",
           [](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); })
      .def("ffi.ArraySize",
           [](const ffi::ArrayObj* n) -> int64_t {
             return static_cast<int64_t>(n->size());
           })
      .def_packed("ffi.Array",
                  [](ffi::PackedArgs args, Any* ret) {
                    *ret = Array<Any>(args.data(), args.data() + args.size());
                  });
});
```

Registering a class method as a global function (from `test_reflection.cc`):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def_method("testing.Int_GetValue", &TIntObj::GetValue);
});
// Calling the method through global registry:
Function fget_value = Function::GetGlobalRequired("testing.Int_GetValue");
TInt a(12);
EXPECT_EQ(fget_value(a).cast<int>(), 12);
```
