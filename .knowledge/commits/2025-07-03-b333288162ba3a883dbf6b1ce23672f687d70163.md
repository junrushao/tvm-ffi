# Introduce reflection::GlobalDef as the new fluent API for global function registration

## TL;DR
- Adds `reflection::GlobalDef`, a new builder class for registering global functions using the reflection-style fluent API (`def`, `def_packed`, `def_method`), replacing per-function `TVM_FFI_REGISTER_GLOBAL(...).set_body_typed(...)` calls.
- Migrates all existing global function registrations in `src/ffi/` (container, function, ndarray, object, testing) from `TVM_FFI_REGISTER_GLOBAL` to `GlobalDef` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- Enhances `ReflectionDefBase::GetMethod` to dispatch by `ObjectRef` (pass-by-value) vs `Object` (pass-by-pointer) using `if constexpr`, adding a `static_assert` guard.

## Impact
- API: `GlobalDef` is a new public class in `tvm::ffi::reflection`. The old `TVM_FFI_REGISTER_GLOBAL` macro and `Function::Registry` class remain defined in `function.h` but are no longer used within `src/ffi/`. External users of `TVM_FFI_REGISTER_GLOBAL` are not broken.
- Behavioral: The test expectation string changed from `object.Function` to `ffi.Function`, reflecting a prior type-key rename. No behavioral changes to registered functions themselves.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Function system (`0004-ffi-function-system`): `Function::FromTyped`, `Function::FromPacked`, `TVMFFIFunctionSetGlobalFromMethodInfo` C API
- Reflection subsystem (`0007-ffi-reflection`): `ReflectionDefBase`, `TVMFFIMethodInfo`, `ApplyMethodInfoTrait`
- Object system (`0003-ffi-object-system`): `ObjectRef` vs `Object` base-class distinction for method dispatch
- Static initialization: `TVM_FFI_STATIC_INIT_BLOCK` macro for registration-time execution

Design elements this commit produces:
- **`reflection::GlobalDef`** — new fluent builder class for global function registration, parallel to `ObjectDef` for type reflection. Supersedes the `TVM_FFI_REGISTER_GLOBAL` + `Function::Registry` pattern within `src/ffi/`.
- **Enhanced `ReflectionDefBase::GetMethod`** — now uses `if constexpr` dispatch for `ObjectRef` (pass-by-value) vs `Object` (pass-by-pointer) methods, with a `static_assert` guard. Previously always passed `const Class*`.

## Usage Examples

Registering multiple global functions with `GlobalDef` inside a static init block:

```cpp
// Before (old pattern):
TVM_FFI_REGISTER_GLOBAL("ffi.ArrayGetItem")
    .set_body_typed([](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); });
TVM_FFI_REGISTER_GLOBAL("ffi.ArraySize")
    .set_body_typed([](const ffi::ArrayObj* n) -> int64_t { return n->size(); });

// After (new pattern):
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("ffi.ArrayGetItem",
           [](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); })
      .def("ffi.ArraySize",
           [](const ffi::ArrayObj* n) -> int64_t { return static_cast<int64_t>(n->size()); })
      .def_packed("ffi.Array",
                  [](ffi::PackedArgs args, Any* ret) {
                    *ret = Array<Any>(args.data(), args.data() + args.size());
                  })
      .def_method("testing.Int_GetValue", &TIntObj::GetValue);
});
```
