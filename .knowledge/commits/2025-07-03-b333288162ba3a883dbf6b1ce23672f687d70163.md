# Introduce reflection::GlobalDef as a fluent builder for global function registration

## TL;DR
- Adds `reflection::GlobalDef`, a new builder class for registering global functions using `.def()`, `.def_packed()`, and `.def_method()` chains, aligning global function registration with the existing reflection style (`ObjectDef`).
- Migrates all `TVM_FFI_REGISTER_GLOBAL` call sites in `src/ffi/` to use `GlobalDef` inside `TVM_FFI_STATIC_INIT_BLOCK`, demonstrating the intended transition pattern.
- Enhances `ReflectionDefBase::GetMethod` to handle both `ObjectRef`-derived and `Object`-derived classes, passing `ObjectRef` by value instead of by const pointer.

## Key Exports

**Class `reflection::GlobalDef`** (new, `include/tvm/ffi/reflection/reflection.h`):
```cpp
class GlobalDef : public ReflectionDefBase {
public:
  // Register a typed global function
  template <typename Func, typename... Extra>
  GlobalDef& def(const char* name, Func&& func, Extra&&... extra);

  // Register a packed-args global function
  template <typename Func, typename... Extra>
  GlobalDef& def_packed(const char* name, Func func, Extra&&... extra);

  // Register a class method as a global function (self is first arg)
  template <typename Func, typename... Extra>
  GlobalDef& def_method(const char* name, Func&& func, Extra&&... extra);

private:
  // Dispatches to ReflectionDefBase::GetMethod for member-function-pointers,
  // or Function::FromTyped for plain callables
  template <typename Func>
  static Function GetMethod_(std::string name, Func&& func);

  // Calls TVMFFIFunctionSetGlobalFromMethodInfo to register
  template <typename... Extra>
  void RegisterFunc(const char* name, Function func, Extra&&... extra);
};
```

**Changed: `ReflectionDefBase::GetMethod`** — now uses `if constexpr` to dispatch:
- If `Class` derives from `ObjectRef`: wraps as `[func](Class target, Args...) -> R` (pass by value).
- If `Class` derives from `Object`: wraps as `[func](const Class* target, Args...) -> R` (pass by pointer, original behavior).
- Adds `static_assert` requiring `Class` derives from `ObjectRef` or `Object`.

**Incidental: `FunctionObj::_type_key`** changed from `"object.Function"` to `"ffi.Function"` (evidenced by test expectation change in `test_function.cc`).

## Impact
- API: New `GlobalDef` class added. `TVM_FFI_REGISTER_GLOBAL` remains available but is no longer the preferred pattern in `src/ffi/`. No breaking changes to callers; both old and new registration APIs coexist.
- Behavioral: `GetMethod` now passes `ObjectRef`-derived classes by value instead of const pointer, which means methods on `ObjectRef` subclasses receive the ref handle directly (natural calling convention) rather than a raw pointer.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit **consumes**:
- **Function global registry** (`Function::SetGlobal`, `TVMFFIFunctionSetGlobalFromMethodInfo`) — GlobalDef's `RegisterFunc` ultimately calls the C API `TVMFFIFunctionSetGlobalFromMethodInfo`. See [0004-function-system.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0004-function-system.md).
- **Reflection builder pattern** (`ReflectionDefBase`, `ObjectDef`) — GlobalDef inherits from `ReflectionDefBase` and follows the same fluent builder pattern as `ObjectDef`. See [0009-reflection.md](/Users/junrus/Projects/tvm-ffi-knowledge/.knowledge/designs/0009-reflection.md).
- **`TVM_FFI_STATIC_INIT_BLOCK` macro** — used at all call sites to wrap `GlobalDef` chains in static initialization blocks.
- **`Function::FromTyped` / `Function::FromPacked`** — used by `def()` and `def_packed()` to create `Function` objects from callables.

Design elements this commit **produces**:
- **`reflection::GlobalDef`** — a new builder class for registering global functions in reflection style. This is a **new design element** that provides a unified, chainable API for function registration, replacing the `TVM_FFI_REGISTER_GLOBAL().set_body_typed()` pattern.
- **`ObjectRef` pass-by-value method dispatch** — `GetMethod` now has a branch for `ObjectRef`-derived classes that passes `self` by value, enabling natural ref-handle semantics.

## Usage Examples

**Registering global functions with GlobalDef** (from `src/ffi/container.cc`):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def_packed("ffi.Array",
                  [](ffi::PackedArgs args, Any* ret) {
                    *ret = Array<Any>(args.data(), args.data() + args.size());
                  })
      .def("ffi.ArrayGetItem",
           [](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); })
      .def("ffi.ArraySize",
           [](const ffi::ArrayObj* n) -> int64_t { return static_cast<int64_t>(n->size()); });
});
```

**Registering a method with def_method** (from `tests/cpp/test_reflection.cc`):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def_method("testing.Int_GetValue", &TIntObj::GetValue);
});
// Callable: fget_value(TInt(12)).cast<int>() == 12
```
