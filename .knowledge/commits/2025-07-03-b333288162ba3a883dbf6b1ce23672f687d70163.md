# Introduce reflection::GlobalDef as a chained builder for global function registration, aligning with the ObjectDef reflection style

## TL;DR
- Adds `reflection::GlobalDef` — a new chained builder class (analogous to `ObjectDef`) for registering global functions via `def`, `def_packed`, and `def_method` on a single expression chain inside `TVM_FFI_STATIC_INIT_BLOCK`.
- Migrates all uses of `TVM_FFI_REGISTER_GLOBAL(...).set_body_typed/packed` in `src/ffi/` (container, function, ndarray, object, testing) to the new `GlobalDef` style.
- Fixes `GetMethod` in `ReflectionDefBase` to dispatch correctly when the class is an `ObjectRef` (pass by value) versus an `Object` subclass (pass by pointer), resolving the `object.Function` → `ffi.Function` error-message discrepancy.

## Key Exports

    """Chained builder for registering global functions in the global function table."""

        """Register a typed callable (auto-unpacked via Function::FromTyped)."""
        # Invariant: `func` must be a typed callable or lambda; type unpacking
        #            uses the same TypeTraits machinery as ObjectDef.def.
        # Interacts with: TVMFFIFunctionSetGlobalFromMethodInfo (C ABI), GlobalFunctionTable
        ...

    def def_packed(self, name: str, func: PackedFunc, *extra) -> GlobalDef:
        """Register a packed callable (manual arg handling; no auto-unpacking)."""
        # Interacts with: Function::FromPacked, GlobalFunctionTable
        ...

    def def_method(self, name: str, func: MethodPointer, *extra) -> GlobalDef:
        """Expose a class method (member pointer) as a global function.
        First argument in the packed convention is the self/receiver.
        ObjectRef subclass: receiver passed by value.
        Object subclass: receiver passed as const pointer.
        """
        # Interacts with: ReflectionDefBase.GetMethod (ObjectRef vs Object dispatch)
        # Interacts with: TVMFFIFunctionSetGlobalFromMethodInfo
        ...

    def _register_func(self, name: str, func: Function, *extra) -> None:
        """Internal: populate TVMFFIMethodInfo and call TVMFFIFunctionSetGlobalFromMethodInfo."""
        # Invariant: name must be a static C string (lifetime >= module load)
        # Interacts with: TVMFFIMethodInfo, TVMFFIFunctionSetGlobalFromMethodInfo (C ABI)


# GetMethod fix in ReflectionDefBase — ObjectRef dispatch (pass by value):
# Old: always used const Class* pointer path
# New: if Class is ObjectRef, wrap as `[func](Class target, Args...) -> R { (target.*func)(...) }`
#      if Class is Object,    wrap as `[func](const Class* target, Args...) -> R { (target->*func)(...) }`

## Impact
- API: `TVM_FFI_REGISTER_GLOBAL` macro is unchanged and still public. `GlobalDef` is additive — both patterns coexist. Internal callers in `src/ffi/` now use `GlobalDef`.
- Behavioral: `GetMethod` now correctly dispatches for `ObjectRef`-derived class method pointers (receiver by value). Error messages for `Function`-returning typed callables now show `ffi.Function` instead of the incorrect `object.Function`.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

**Migrating from old `TVM_FFI_REGISTER_GLOBAL` to new `GlobalDef` style:**

```cpp
// Old style (still works, but no longer used in src/ffi/):
TVM_FFI_REGISTER_GLOBAL("ffi.ArrayGetItem")
    .set_body_typed([](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); });

// New style (from src/ffi/container.cc after this commit):
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("ffi.ArrayGetItem",
           [](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); })
      .def("ffi.ArraySize",
           [](const ffi::ArrayObj* n) -> int64_t { return static_cast<int64_t>(n->size()); });
});

// Exposing an Object class method pointer as a global function (from tests/cpp/test_reflection.cc):
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def_method("testing.Int_GetValue", &TIntObj::GetValue);
});
// Callable from Python as: get_global_func("testing.Int_GetValue")(my_int_obj)
```
