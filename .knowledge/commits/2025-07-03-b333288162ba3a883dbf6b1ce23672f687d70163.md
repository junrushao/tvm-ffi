# Introduce reflection::GlobalDef for global function registration
## TL;DR
- Adds `reflection::GlobalDef`, a new builder class for registering global functions using the reflection-style API (fluent `.def()`, `.def_packed()`, `.def_method()` chaining).
- Migrates all internal `TVM_FFI_REGISTER_GLOBAL` call sites in `src/ffi/` to use `GlobalDef` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- Enhances `ReflectionDefBase::GetMethod` to dispatch correctly on `ObjectRef`-derived classes (pass by value) vs `Object`-derived classes (pass by pointer).

## Key Exports
**Classes:**

```cpp
class GlobalDef : public ReflectionDefBase {
  // Typed function: auto-unpack arguments
  template <typename Func, typename... Extra>
  GlobalDef& def(const char* name, Func&& func, Extra&&... extra);

  // Packed function: void(PackedArgs, Any*)
  template <typename Func, typename... Extra>
  GlobalDef& def_packed(const char* name, Func func, Extra&&... extra);

  // Method pointer: prepends self as first arg, dispatches ObjectRef vs Object
  template <typename Func, typename... Extra>
  GlobalDef& def_method(const char* name, Func&& func, Extra&&... extra);
};
```

Each method returns `GlobalDef&` for fluent chaining. All three call `RegisterFunc` which builds a `TVMFFIMethodInfo` and calls `TVMFFIFunctionSetGlobalFromMethodInfo(&info, 0)`.

**Behavioral change to `ReflectionDefBase::GetMethod`:**

Previously, `GetMethod` always wrapped the first argument as `const Class*` (pointer). Now it uses `if constexpr` to branch:
- `ObjectRef`-derived: wraps as pass-by-value `Class target` (leverages ref-counting copy)
- `Object`-derived: wraps as `const Class* target` (raw pointer, existing behavior)

This enables `def_method` to work with methods defined on `ObjectRef` wrappers (e.g., `Foo::SomeMethod()`), not just on `Object` subclasses.

## Impact
- API: Adds `reflection::GlobalDef` as the recommended new way to register global functions. The old `TVM_FFI_REGISTER_GLOBAL` macro remains available but internal usage is migrated away.
- ABI: none -- the C ABI function `TVMFFIFunctionSetGlobalFromMethodInfo` already existed; `GlobalDef` is a pure C++ wrapper on top of it.
- Behavioral: `GetMethod` now dispatches ObjectRef by value instead of by pointer. This changes the FFI signature for methods on ObjectRef-derived classes (first arg becomes `Class` instead of `const Class*`). The test string `"ffi.Function"` replacing `"object.Function"` in test_function.cc reflects this.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Packed calling convention** (`function-system.md`) -- `GlobalDef::def_packed` wraps via `Function::FromPacked`, `def` wraps via `Function::FromTyped`.
- **Global function registry** (`function-system.md`) -- `RegisterFunc` calls `TVMFFIFunctionSetGlobalFromMethodInfo` which routes to `GlobalFunctionTable`.
- **Object/ObjectRef dual-class pattern** (`object-system.md`) -- `GetMethod` distinguishes `Object`-derived (pointer semantics) from `ObjectRef`-derived (value semantics).
- **TVMFFIMethodInfo** (`reflection.md`) -- reused as the carrier struct for global function registration metadata (name, doc, type_schema, function handle).
- **TVM_FFI_STATIC_INIT_BLOCK** -- static initialization macro used as the block scope for GlobalDef registrations (replaces per-function static `Registry` objects).

Design elements this commit produces:
- **`reflection::GlobalDef`** -- new builder class for global function registration, parallel to `reflection::ObjectDef` for type fields/methods. Provides a reflection-aligned alternative to `TVM_FFI_REGISTER_GLOBAL`.
- **ObjectRef-aware method dispatch in `GetMethod`** -- the `if constexpr` branching pattern that enables method pointers on both `ObjectRef` and `Object` subclasses.

## Usage Examples
Registering global functions with `GlobalDef` (from `src/ffi/container.cc`):

```cpp
#include <tvm/ffi/reflection/reflection.h>

TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def_packed("ffi.Array",
                  [](ffi::PackedArgs args, Any* ret) {
                    *ret = Array<Any>(args.data(), args.data() + args.size());
                  })
      .def("ffi.ArrayGetItem",
           [](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); })
      .def("ffi.ArraySize",
           [](const ffi::ArrayObj* n) -> int64_t { return static_cast<int64_t>(n->size()); });
});
```

Registering a method pointer with `def_method` (from `tests/cpp/test_reflection.cc`):

```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def_method("testing.Int_GetValue", &TIntObj::GetValue);
});
```
