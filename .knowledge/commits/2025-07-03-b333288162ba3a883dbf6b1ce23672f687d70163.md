# Introduce reflection::GlobalDef as the new global function registration API

## TL;DR
- Introduces `reflection::GlobalDef`, a new builder class for registering global functions, aligning function registration with the reflection-based `ObjectDef` style.
- Migrates all internal `TVM_FFI_REGISTER_GLOBAL` call sites (in `container.cc`, `function.cc`, `ndarray.cc`, `object.cc`, `testing.cc`) to use `GlobalDef` inside `TVM_FFI_STATIC_INIT_BLOCK`.
- Extends `ReflectionDefBase::GetMethod` to support `ObjectRef`-derived classes (pass by value) in addition to `Object`-derived classes (pass by pointer), enabling `def_method` on ref types.

## Impact
- API: Introduces `reflection::GlobalDef` as a new public API for global function registration. `TVM_FFI_REGISTER_GLOBAL` remains available but this commit begins transitioning away from it internally. No breaking changes -- both APIs coexist.
- Behavioral: `GetMethod` now accepts `ObjectRef`-derived classes by value instead of requiring pointer-to-Object. This changes how `def_method` wraps member functions on ref types -- the first argument is passed by value rather than as `const T*`. The test file change (`object.Function` -> `ffi.Function`) aligns a test expectation with a prior type_key rename (commit 0966c36), not a behavioral change in this commit.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Function.FromTyped / Function.FromPacked** ([0004-function-system.md](../designs/0004-function-system.md)): Used by `GlobalDef.def` and `GlobalDef.def_packed` to wrap callables into `Function` objects before registration.
- **TVMFFIFunctionSetGlobalFromMethodInfo** ([0004-function-system.md](../designs/0004-function-system.md)): The C API function that `GlobalDef.RegisterFunc` calls to register functions in the global table with method metadata.
- **TVM_FFI_STATIC_INIT_BLOCK** ([0004-function-system.md](../designs/0004-function-system.md)): Static initialization macro used to invoke `GlobalDef` at program startup.
- **ReflectionDefBase** ([0008-reflection.md](../designs/0008-reflection.md)): Parent class providing `GetMethod`, `ApplyMethodInfoTrait`, and the method-info pattern.
- **TVMFFIMethodInfo** ([0001-c-abi.md](../designs/0001-c-abi.md)): The C struct used to pass function metadata (name, doc, type_schema, flags, method handle) to the registration C API.

Design elements this commit produces:
- **reflection::GlobalDef**: New builder class for global function registration. Extends `ReflectionDefBase` to register free functions (not just object methods/fields). Provides `def`, `def_packed`, and `def_method` with chaining.
- **ObjectRef-aware GetMethod**: Extends `ReflectionDefBase::GetMethod` to support `ObjectRef`-derived classes, passing `self` by value rather than by pointer. Uses `if constexpr` with `std::is_base_of_v` to dispatch.

## Usage Examples

**Registering global functions with GlobalDef (C++):**
```cpp
// Inside a TVM_FFI_STATIC_INIT_BLOCK:
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      // typed function: signature inferred from lambda
      .def("ffi.ArrayGetItem",
           [](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); })
      // packed function: takes (PackedArgs, Any*) explicitly
      .def_packed("ffi.Array",
                  [](ffi::PackedArgs args, Any* ret) {
                    *ret = Array<Any>(args.data(), args.data() + args.size());
                  })
      // method: exposes a member function as a global, self becomes first arg
      .def_method("testing.Int_GetValue", &TIntObj::GetValue);
});
```

**Equivalent old-style registration (being replaced):**
```cpp
// Old: separate TVM_FFI_REGISTER_GLOBAL per function
TVM_FFI_REGISTER_GLOBAL("ffi.ArrayGetItem")
    .set_body_typed([](const ffi::ArrayObj* n, int64_t i) -> Any { return n->at(i); });
```
