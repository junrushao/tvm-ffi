# Add __repr__ generation support for @c_class dataclasses
## TL;DR
- Adds `repr` parameter to `c_class()` decorator (default `True`) and `field()` function (default `True`), auto-generating `__repr__` methods for C++ object proxies in `ClassName(field1=value1, ...)` format.
- Extracts `_get_all_fields()` helper from `method_init` for shared field-hierarchy traversal.
- Changes `_add_method` in `type_info_to_cls` to always override attrs (removing the `if name in attrs: return` guard), enabling generated `__repr__` to replace `Object.__repr__`.

## Impact
- API: Additive. `c_class()` gains `repr` parameter (default True). `field()` gains `repr` parameter (default True). Existing code unaffected.
- Behavioral: `@c_class`-decorated classes now get auto-generated `__repr__` by default. `_add_method` no longer skips methods already in `attrs` and no longer calls `setattr(cls, name, func)` — methods are added via `attrs` dict only, which is used when creating the new class via `type()`.
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces:
- `method_repr()` — new codegen function for `__repr__`, parallel to `method_init()`
- `_get_all_fields()` — extracted helper for field hierarchy traversal (was inline in `method_init`)
- `Field.repr` attribute — per-field repr inclusion control
- `c_class(repr=...)` parameter — class-level repr generation control
- Behavioral change to `_add_method`: always overrides attrs (needed so generated `__repr__` can replace inherited `Object.__repr__`)

## Usage Examples
**Auto-generated repr for a derived class** (from `tests/python/test_dataclasses_c_class.py`):
```python
from tvm_ffi.dataclasses import c_class, field

@c_class("testing.TestCxxClassDerived")
class _TestCxxClassDerived(TestCxxClassBase):
    v_f64: float
    v_f32: float = 8

obj = _TestCxxClassDerived(v_i64=123, v_i32=456, v_f64=4.0, v_f32=8.0)
repr(obj)
# => "_TestCxxClassDerived(v_i64=123, v_i32=456, v_f64=4.0, v_f32=8.0)"
```

**Excluding a field from repr** (pseudocode based on new `field(repr=False)` API):
```python
@c_class("my.Type")
class MyType:
    name: str
    _internal_id: int = field(repr=False)  # hidden from repr output

repr(MyType(name="foo", _internal_id=42))
# => "MyType(name='foo')"
```
