# Add __repr__ generation support for @c_class dataclasses
## TL;DR
- Adds `repr` parameter to `c_class()` decorator (default: True) and `field()` function (default: True).
- Implements `method_repr()` to generate `__repr__` methods in the format `ClassName(field1=value1, field2=value2, ...)`.
- Fields with `repr=False` are excluded from the representation.
- Refactors `_get_all_fields()` helper to be shared between `method_init()` and `method_repr()`.

## Impact
- API: additive -- new `repr` parameter on `c_class()` and `field()`
- Behavioral: `@c_class` decorated classes now have auto-generated `__repr__` by default
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
@c_class("testing.TestCxxClassDerived")
class MyClass:
    v_i64: int
    v_i32: int

obj = MyClass(v_i64=123, v_i32=456)
repr(obj)  # "MyClass(v_i64=123, v_i32=456, ...)"
```
