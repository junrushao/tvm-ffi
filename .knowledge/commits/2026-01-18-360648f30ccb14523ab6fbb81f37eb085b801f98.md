# Add __repr__ generation support for @c_class dataclasses
## TL;DR
- Adds `repr` parameter to `c_class(type_key, init=True, repr=True)` decorator and `field(repr=True)` function.
- Implements `method_repr()` code generator in `_utils.py` that produces `__repr__` methods showing `ClassName(field1=value1, ...)` with fields traversed from parent to child.
- Extracts `_get_all_fields(type_info)` helper for field collection, shared between `method_init` and `method_repr`.
- Changes `_add_method` to always override (allows generated `__repr__` to replace `Object.__repr__`).

## Key Exports

**Parameters** added to existing functions:
- `c_class(type_key, init=True, repr=True)` — new `repr: bool` parameter
- `field(..., repr=True)` — new `repr: bool` parameter on `Field`

**Function** added in `python/tvm_ffi/dataclasses/_utils.py`:
- `method_repr(type_cls: type, type_info: TypeInfo) -> Callable[..., str]` — generates `__repr__` via `exec` of f-string code
- `_get_all_fields(type_info: TypeInfo) -> list[TypeField]` — collects fields from parent to child

## Impact
- API: new optional parameters on `c_class()` and `field()`; purely additive
- Behavioral: `@c_class` now auto-generates `__repr__` by default (can be disabled with `repr=False`)
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
```python
@c_class("my_ext.Config", repr=True)
class Config(Object):
    name: str
    value: int = field(default=0)
    internal: Any = field(default=None, repr=False)

cfg = Config(name="test", value=42)
print(cfg)  # Config(name='test', value=42)
```
