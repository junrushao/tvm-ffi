# Add __repr__ generation support for @c_class dataclasses
## TL;DR
- Adds auto-generated `__repr__` method for `@c_class` decorated classes based on reflected fields
- Extracts `_get_all_fields()` helper to collect fields across type hierarchy (parent to child order)
- Supports `repr=True/False` per-field via `field()` to control which fields appear in repr output
- Changes `_add_method` to always override (including base class methods like `Object.__repr__`)

## Impact
- API: `@c_class` instances now have meaningful `__repr__` output instead of generic `Object.__repr__`
- Behavioral: `_add_method` now always overrides existing methods (including inherited ones)
- Flags/config: none
- Data formats/schemas: none
