# Switch wheel builds from push-on-main to nightly cron schedule
## TL;DR
- Replace `push` trigger on `main` with a daily cron schedule (`0 9 * * *`) in `publish_wheel.yml`.
- Remove the `if` condition that restricted `manylinux2014` builds to manual dispatch only, so all matrix entries now build on schedule.
- Publishing to PyPI remains manual-only via `workflow_dispatch`.

N/A -- infrastructure

## Impact
- API: none
- Behavioral: Wheel builds no longer run on every push to `main`; instead they run once daily at 9am UTC. All platform/image combinations now build on every scheduled run (previously `manylinux2014` was gated to manual dispatch). Publishing remains manual.
- Flags/config: Trigger in `.github/workflows/publish_wheel.yml` changed from `push.branches: [main]` to `schedule.cron: '0 9 * * *'`.
