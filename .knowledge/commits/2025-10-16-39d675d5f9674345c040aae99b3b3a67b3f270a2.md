# Switch wheel builds from per-commit to nightly schedule and remove manylinux2014 gating

## TL;DR
- Replaces the `push: branches: [main]` trigger on `publish_wheel.yml` with a `schedule: cron: '0 9 * * *'` (daily at 9am UTC), so wheels are built nightly instead of on every commit to main.
- Removes the `if:` condition that skipped `manylinux2014` on non-manual runs and the per-matrix `name:` line from the `build_wheels` job, so all matrix entries (including both manylinux2014 and manylinux_2_28) build unconditionally on every trigger.
- Publishing to PyPI remains gated on `workflow_dispatch` only (unchanged).

## Design Elements
Design elements this commit consumes:
- CI wheel publishing workflow structure (`.github/workflows/publish_wheel.yml`)
- Dual manylinux2014 + manylinux_2_28 matrix introduced in commit 997a366

Design elements this commit produces:
- **Nightly wheel-build cadence**: Replaces per-commit CI wheel builds with a daily 9am UTC cron schedule, reducing CI load while still catching packaging regressions within 24 hours.
- **Unconditional full-matrix builds**: All matrix entries (including manylinux2014) now build on every trigger (schedule or manual), eliminating the conditional `if:` gating that previously excluded manylinux2014 from push-triggered runs.
