# Rewrite TypeSchema converter to produce CAny via C++ __ffi_convert__ dispatch
## TL;DR
- Replaces Cython-side `type_check.pxi` (1068 lines removed) with new `type_converter.pxi` (806 lines) that dispatches type conversion to C++ `__ffi_convert__` reflection methods.
- Adds `ObjectDef::def_convert` in reflection headers for registering per-type converters.
- Renames `test_type_check.py` to `test_type_converter.py`.
