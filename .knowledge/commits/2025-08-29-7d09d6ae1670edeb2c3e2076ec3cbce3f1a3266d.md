# Revert cmake libbacktrace URL in favor of git submodule
## TL;DR
- Removed `GIT_REPOSITORY` and `GIT_TAG` directives from `AddLibbacktrace.cmake`, so cmake no longer fetches libbacktrace directly and instead relies on the vendored git submodule at `3rdparty/libbacktrace`.
- Updated the `3rdparty/libbacktrace` submodule pointer from fork commit `08f7c7e` to upstream HEAD `7939218`, which already incorporates the macOS patch previously carried in the fork.
