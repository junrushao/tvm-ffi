# Revert cmake libbacktrace URL in favor of git submodule for upstream source
## TL;DR
- Removes `GIT_REPOSITORY` and `GIT_TAG` directives from `cmake/Utils/AddLibbacktrace.cmake`, reverting the cmake-driven fetch introduced in PR #18246.
- Updates the `3rdparty/libbacktrace` submodule pointer from the tlc-pack fork (`08f7c7e`) to upstream HEAD (`7939218`), since upstream already incorporates the one macOS patch the fork carried.

## Key Exports
None

## Impact
- API: none
- Behavioral: libbacktrace is now sourced from the vendored submodule at `3rdparty/libbacktrace` rather than fetched via cmake's `ExternalProject_Add` GIT_REPOSITORY. The upstream commit `7939218` includes the macOS `macho.c` fix previously carried only in the tlc-pack fork.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `ExternalProject_Add(project_libbacktrace ...)` in `cmake/Utils/AddLibbacktrace.cmake` -- the cmake external project mechanism for building libbacktrace from a local source directory.
- `3rdparty/libbacktrace` git submodule -- vendored dependency pattern used across the project.
