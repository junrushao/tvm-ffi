# Revert cmake libbacktrace URL in favor of git submodule

## TL;DR
- Removed `GIT_REPOSITORY` and `GIT_TAG` from `cmake/Utils/AddLibbacktrace.cmake` so the build uses the vendored `3rdparty/libbacktrace` submodule instead of cloning at configure time.
- Updated `3rdparty/libbacktrace` submodule pointer from the TLC-pack fork (`08f7c7e`) to upstream HEAD (`7939218`), since the upstream already incorporates the one macOS patch the fork carried.
