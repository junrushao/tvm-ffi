# Revert CMake libbacktrace git-download in favor of git submodule
## TL;DR
- Removes `GIT_REPOSITORY` and `GIT_TAG` directives from `ExternalProject_Add` in `AddLibbacktrace.cmake`, reverting the CMake-driven download path added in b245f1f (#18246).
- Updates the `3rdparty/libbacktrace` submodule pointer from the tlc-pack fork (`08f7c7e`) to upstream HEAD (`7939218`), which already incorporates the macOS patch that the fork provided.
- Restores the convention that libbacktrace source is obtained exclusively via `git submodule`, not via CMake `ExternalProject` git-clone.

None

## Impact
- API: none
- ABI: none
- Behavioral: Builds that previously relied on CMake fetching libbacktrace at configure time will now require the git submodule to be initialized (`git submodule update --init --recursive`). The submodule now points to upstream rather than the tlc-pack fork.
- Flags/config: none
- Data formats/schemas: none
