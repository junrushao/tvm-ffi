# Patch torch.cuda.Stream with __cuda_stream__ protocol for older PyTorch versions
## TL;DR
- Adds `patch_torch_cuda_stream_protocol()` to `_optional_torch_c_dlpack.py` that monkey-patches `torch.cuda.Stream.__cuda_stream__` on older PyTorch versions lacking the method natively.
- The patched method returns `(0, self.cuda_stream)` following the CUDA stream protocol specification.
- Executes at module import time, immediately after the torch C DLPack extension is loaded.

## Key Exports
**Functions**:
- `patch_torch_cuda_stream_protocol() -> Any` (module-level, in `python/tvm_ffi/_optional_torch_c_dlpack.py`): Checks if `torch.cuda.Stream` has `__cuda_stream__` and, if not, patches it with a version-0 protocol implementation.

## Impact
- API: none -- no public API changes; this is an internal compatibility shim.
- ABI: none.
- Behavioral: Older PyTorch versions (pre-native `__cuda_stream__` support) will now expose the CUDA stream protocol on `torch.cuda.Stream`, enabling the FFI's stream-aware tensor exchange (introduced in parent commit b0537f0) to work with those versions.
- Flags/config: none.
- Data formats/schemas: none.

## Design Elements
Design elements this commit consumes:
- CUDA stream protocol specification (https://nvidia.github.io/cuda-python/cuda-core/latest/interoperability.html#cuda-stream-protocol), requiring `__cuda_stream__` to return `(version: int, stream_ptr)`.
- `.knowledge/designs/0018-dlpack-fast-path.md` -- the PyTorch integration module where this patch is appended. The fast-path protocol already sets stream context during argument packing; this ensures older torch exposes the stream handle needed by that mechanism.
- Parent commit b0537f0 (#109) which added CUDA stream protocol support to the Cython binding layer, creating the consumer that expects `__cuda_stream__` to exist on stream objects.

Design elements this commit produces:
- None new. This is a backward-compatibility shim for an existing protocol.

## Usage Examples
The patch is transparent. After importing `tvm_ffi`, even on older PyTorch:

```python
import tvm_ffi
import torch

# On older torch versions, __cuda_stream__ is now patched automatically
s = torch.cuda.Stream()
version, stream_ptr = s.__cuda_stream__()
assert version == 0
assert isinstance(stream_ptr, int)

# The FFI stream protocol from commit b0537f0 can now consume this:
f = tvm_ffi.get_global_func("some_cuda_kernel")
f(tensor)  # stream context is propagated correctly even on older torch
```
