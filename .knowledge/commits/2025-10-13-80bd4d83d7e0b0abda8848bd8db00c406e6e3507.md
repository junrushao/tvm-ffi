# Patch __cuda_stream__ protocol onto torch.cuda.Stream for older PyTorch versions

## TL;DR
- Adds `patch_torch_cuda_stream_protocol()` to `_optional_torch_c_dlpack.py` that monkey-patches `__cuda_stream__` onto `torch.cuda.Stream` if absent (older PyTorch versions).
- Enables the `__cuda_stream__` arg setter (introduced in commit b0537f0) to work with older PyTorch CUDA streams.

## Key Exports

**Function: `patch_torch_cuda_stream_protocol() -> None`** (`_optional_torch_c_dlpack.py`):
- If `torch.cuda.is_available()` and `torch.cuda.Stream` lacks `__cuda_stream__`, patches it with `lambda self: (0, self.cuda_stream)`.
- Called at module import time.

## Impact
- API: none (additive monkey-patch on third-party class)
- Behavioral: `torch.cuda.Stream` objects now pass through the `__cuda_stream__` FFI dispatch path on older PyTorch.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- **`__cuda_stream__` protocol** (introduced in b0537f0) -- this patch ensures the protocol is available on torch.cuda.Stream

Design elements this commit produces: none (compatibility shim only)
