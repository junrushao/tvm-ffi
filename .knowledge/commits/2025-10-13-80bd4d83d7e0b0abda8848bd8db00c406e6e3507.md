# Monkey-patch __cuda_stream__ onto torch.cuda.Stream for older torch versions
## TL;DR
- Adds `patch_torch_cuda_stream_protocol()` to `_optional_torch_c_dlpack.py`, which monkey-patches `__cuda_stream__` onto `torch.cuda.Stream` when the attribute is missing (older torch versions).
- The patched method returns `(0, self.cuda_stream)` matching the CUDA stream protocol expected by the Cython `TVMFFIPyArgSetterCUDAStream_` setter in `function.pxi`.
- Called at module import time alongside the existing `load_torch_c_dlpack_extension()`.

## Key Exports
None — trivial compatibility shim, no new public API surface.

## Impact
- API: none
- Behavioral: enables CUDA stream argument passing for older torch versions that lack the `__cuda_stream__` dunder
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **`__cuda_stream__` protocol** — the Cython arg setter (`TVMFFIPyArgSetterCUDAStream_` in `function.pxi:297,622`) checks for and calls `__cuda_stream__()` on stream objects. This commit ensures older torch versions expose that protocol.
- **`_optional_torch_c_dlpack` module-level init pattern** — the existing pattern of calling a setup function at import time (`_mod = load_torch_c_dlpack_extension()`) is followed for the new `patch_torch_cuda_stream_protocol()`.

Design elements this commit produces: none

None — the patch is auto-applied at import time. No user action required.
