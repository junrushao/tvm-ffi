# Patch torch.cuda.Stream with __cuda_stream__ protocol for older PyTorch versions
## TL;DR
- Adds `patch_torch_cuda_stream_protocol()` to monkey-patch `torch.cuda.Stream.__cuda_stream__` on older PyTorch versions that lack native support
- The patched method returns the version-0 tuple `(0, self.cuda_stream)` matching the CUDA Stream Exchange Protocol
- Called at module import time alongside the existing DLPack extension loading

## Key Exports
The patch is internal (no new public API surface). It enables the `__cuda_stream__` protocol consumed by the Cython `TVMFFIPyArgSetterCUDAStream_` setter (added in parent commit PR #109).

```python
# Internal function in python/tvm_ffi/_optional_torch_c_dlpack.py
def patch_torch_cuda_stream_protocol() -> Any:
    """Monkey-patch torch.cuda.Stream.__cuda_stream__ if missing."""
    # Idempotent: only patches if __cuda_stream__ not already present
    # Guards: ImportError (no torch), cuda not available
    # Protocol: returns (version: int, stream_ptr: int)
    ...

# Interacts with: TVMFFIPyArgSetterCUDAStream_ in function.pxi
#   which calls arg.__cuda_stream__() and extracts stream_ptr from tuple[1]
# Interacts with: __tvm_ffi_env_stream__ dunder protocol (stream exchange layer)
```

## Impact
- API: none -- internal compatibility shim, no new public API
- Behavioral: enables CUDA stream protocol for torch.cuda.Stream on older PyTorch versions (pre-2.4 or similar), where the `__cuda_stream__` dunder is not natively defined
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces:

## Usage Examples
The patch is transparent to users. After this change, passing a `torch.cuda.Stream` to an FFI function works on both old and new PyTorch:

```python
import torch
import tvm_ffi

# On older torch, __cuda_stream__ is now monkey-patched
stream = torch.cuda.Stream()
# FFI functions can now accept stream as argument
# (internally dispatched via TVMFFIPyArgSetterCUDAStream_)
some_ffi_func(stream)  # works on all supported torch versions
```
