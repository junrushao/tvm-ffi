# Polyfill __cuda_stream__ on torch.cuda.Stream for older PyTorch versions

## TL;DR

- Adds `patch_torch_cuda_stream_protocol()` to `_optional_torch_c_dlpack.py` to monkey-patch `torch.cuda.Stream.__cuda_stream__` on older PyTorch versions that lack it.
- Called at module import time (bottom of file), after `load_torch_c_dlpack_extension()`.
- Silently no-ops if torch is not installed, CUDA is unavailable, or the attribute already exists (idempotent).

## Key Exports

```python
def patch_torch_cuda_stream_protocol() -> None:
    """Polyfill __cuda_stream__ on torch.cuda.Stream for older PyTorch versions."""
    # Invariant: called at module import time (end of _optional_torch_c_dlpack.py)
    # Invariant: no-op if torch not installed, CUDA unavailable, or attribute already present
    # Invariant: idempotent — hasattr guard prevents double-patching
    # Interacts with: torch.cuda.Stream.__cuda_stream__ (CUDA stream protocol)
    # Interacts with: TorchStreamContext (0012-env-api) which consumes __cuda_stream__ at runtime

    # Patched method signature:
    def __cuda_stream__(self: torch.cuda.Stream) -> tuple[int, torch.cuda.Stream]:
        # Returns (protocol_version=0, raw_cuda_stream_int)
        # Invariant: protocol_version=0 per CUDA stream protocol spec
        return (0, self.cuda_stream)
```

## Impact

- API: none — no new public Python API; `patch_torch_cuda_stream_protocol` is module-private and called automatically.
- Behavioral: `TorchStreamContext` and any code consuming `__cuda_stream__` now works on older PyTorch builds that lack the attribute.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- `0012-env-api`: `TorchStreamContext` / torch stream integration — the `__cuda_stream__` protocol is the interface between PyTorch streams and TVM FFI stream context management.
- `0016-py-ffi-call-dispatch`: torch stream argument setters may rely on the `__cuda_stream__` protocol being present on stream objects.

Design elements this commit produces:
- None — this is a pure compatibility shim; no new design elements are introduced.

## Usage Examples

Before (older PyTorch without `__cuda_stream__`):
```python
# AttributeError at runtime when TorchStreamContext tries to use __cuda_stream__
stream = torch.cuda.Stream()
# stream.__cuda_stream__  # AttributeError: 'Stream' object has no attribute '__cuda_stream__'
```

After (with patch applied at import time):
```python
import tvm_ffi  # triggers patch_torch_cuda_stream_protocol() automatically
stream = torch.cuda.Stream()
# stream.__cuda_stream__() == (0, stream.cuda_stream)  # now available
```
