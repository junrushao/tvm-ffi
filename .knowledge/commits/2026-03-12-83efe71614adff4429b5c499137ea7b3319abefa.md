# Expand py_class test coverage and fix serialization for py_class types

## TL;DR
- 972 new test lines in `test_dataclass_py_class.py`: containers, optional containers, function fields, `Any` fields, `__post_init__` mutation, custom init, inheritance with defaults, type validation, container mutation, optional field cycles, multi-type interactions.
- Serialization fix: `serialization.cc` replaces `metadata==nullptr` check with `HasCreator()` — now correctly handles `py_class` types with `__ffi_new__` (previously would skip serialization for Python-defined types).
- Python 3.8 compat fix: annotations use `typing.List[int]`/`typing.Dict`/`typing.Optional` instead of PEP 585/604 syntax for runtime-evaluated `@py_class` annotations.
