# Expand py_class test coverage with tests ported from mlc-python; fix serialization for Python types

## TL;DR
- Ports 972 additional test lines to `test_dataclass_py_class.py` (from mlc-python), covering serialization, repr, copy, forward references, and inheritance for `py_class` types.
- Fixes `serialization.cc`: `ToJSONGraph` error check now uses `HasCreator(type_info)` instead of `metadata == nullptr`, enabling Python-defined types (`__ffi_new__`) to serialize correctly.
- Adds 62 new repr tests for `py_class` types.

## Key Exports

```python
# Bug fix in src/ffi/extra/serialization.cc:
# Before: TypeError if type_info->metadata == nullptr
# After: TypeError if !HasCreator(type_info) — allows __ffi_new__-based Python types
```

## Impact
- API: none
- Behavioral: `ToJSONGraph`/`FromJSONGraph` now works for `@py_class` types that have `__ffi_new__` but no C++ `metadata->creator`.
- Flags/config: none
