# Add TVM_FFI_USE_DL_LIBS CMake option to explicitly control dl linkage

## TL;DR
- Adds `option(TVM_FFI_USE_DL_LIBS "Link against dl libs in shared lib" ON)` to `CMakeLists.txt`.
- Guards the existing `if (TVM_FFI_USE_EXTRA_CXX_API AND CMAKE_DL_LIBS)` with an additional `AND TVM_FFI_USE_DL_LIBS` check.
- Net change: 5 additions, 1 deletion.

## Key Exports

```python
# CMakeLists.txt — new CMake option
# option(TVM_FFI_USE_DL_LIBS "Link against dl libs in shared lib" ON)
# Default: ON (same as prior behavior)
# Set OFF to skip dl linkage (e.g. -DTVM_FFI_USE_DL_LIBS=OFF for certain cross-compile targets)
# Invariant: dl linkage only when TVM_FFI_USE_EXTRA_CXX_API AND CMAKE_DL_LIBS AND TVM_FFI_USE_DL_LIBS
# Interacts with: TVM_FFI_USE_THREADS (sibling option)
#                  TVM_FFI_USE_EXTRA_CXX_API (existing gating condition)
```

## Impact
- API: none
- Behavioral: cross-compilation users can pass `-DTVM_FFI_USE_DL_LIBS=OFF` to skip dl linkage. Default ON is same as before.
- Flags/config: `TVM_FFI_USE_DL_LIBS` (new CMake option, default ON).
- Data formats/schemas: none

## Usage Examples

```cmake
# Cross-compile without dl:
cmake . -B build -DTVM_FFI_USE_DL_LIBS=OFF

# Normal build (default):
cmake . -B build  # TVM_FFI_USE_DL_LIBS=ON
```
