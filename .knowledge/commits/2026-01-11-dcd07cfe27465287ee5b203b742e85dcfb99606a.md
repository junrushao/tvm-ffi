# Add TVM_FFI_USE_DL_LIBS CMake option to allow explicitly disabling dl library linking

## TL;DR

- Introduces `TVM_FFI_USE_DL_LIBS` CMake option (default `ON`) that gates linking of `${CMAKE_DL_LIBS}` against the shared and static FFI libraries.
- The existing linking condition `TVM_FFI_USE_EXTRA_CXX_API AND CMAKE_DL_LIBS` is extended with `AND TVM_FFI_USE_DL_LIBS`, giving users explicit override control.
- Enables cross-compilation scenarios where the `dl` library is unavailable or must be excluded (e.g., bare-metal or embedded targets).

N/A — infrastructure

## Impact

- API: none
- Behavioral: When `TVM_FFI_USE_DL_LIBS=OFF`, `${CMAKE_DL_LIBS}` is no longer linked into `tvm_ffi_shared` or `tvm_ffi_static`, regardless of `TVM_FFI_USE_EXTRA_CXX_API` and `CMAKE_DL_LIBS` platform detection.
- Flags/config: New CMake option `TVM_FFI_USE_DL_LIBS` (BOOL, default `ON`).
- Data formats/schemas: none

## Usage Examples

```cmake
# Cross-compilation: explicitly disable dl linking when targeting a bare-metal platform
cmake -DTVM_FFI_USE_DL_LIBS=OFF \
      -DTVM_FFI_USE_EXTRA_CXX_API=ON \
      -DCMAKE_TOOLCHAIN_FILE=my_crosscompile.cmake \
      -B build_cross .
```
