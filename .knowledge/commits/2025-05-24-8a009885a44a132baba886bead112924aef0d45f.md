# Add TVM_FFI_WEAK macro and fix stale TVM_REGISTER_GLOBAL reference in comment
## TL;DR
- Adds `TVM_FFI_WEAK` macro to `c_api.h` for platform-portable weak linking (`__attribute__((weak))` on GCC/Clang, `__declspec(selectany)` on MSVC).
- Fixes a stale `TVM_REGISTER_GLOBAL` reference in a doc comment in `function.h`, replacing it with `TVM_FFI_REGISTER_GLOBAL`.
- **Diff-message misalignment**: The commit message describes a broad migration (`registry.h` removal, `c_runtime_api.h` replacement, `TVM_REGISTER_GLOBAL` rename), but the actual diff in this repo is limited to the two changes above. The broader migration was likely applied to the main TVM repo, not this standalone FFI repo.

## Key Exports

**Macros**:
| Macro | Definition | Purpose |
|-------|-----------|---------|
| `TVM_FFI_WEAK` | `__declspec(selectany)` (MSVC) or `__attribute__((weak))` (others) | Portable weak-linking attribute for symbols that may be overridden or multiply defined |
