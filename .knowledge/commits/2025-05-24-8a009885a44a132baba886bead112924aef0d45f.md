# Phase out legacy C API: add TVM_FFI_WEAK macro and fix doc comment to TVM_FFI_REGISTER_GLOBAL

## TL;DR
- Adds `TVM_FFI_WEAK` cross-platform weak-linking macro to `c_api.h` (MSVC `__declspec(selectany)` / GCC/Clang `__attribute__((weak))`).
- Fixes a stale doc comment in `function.h` that still referenced the legacy `TVM_REGISTER_GLOBAL` macro, updating it to `TVM_FFI_REGISTER_GLOBAL`.
- Part of a broader effort (PR #18010) to phase out legacy TVM runtime API in favor of the unified FFI surface. The bulk of the rename (`registry.h` -> `function.h`, `c_runtime_api.h` -> `base.h`) happened in the parent TVM repo; only the FFI-local changes land here.

## Key Exports

```python
# New macro in c_api.h (C preprocessor, shown as pseudocode):
# TVM_FFI_WEAK -- cross-platform weak linkage attribute
# On MSVC:  __declspec(selectany)
# On GCC/Clang: __attribute__((weak))
# maturity: planned (defined but not yet used by any symbol in this commit)
# Interacts with: future weak-linked C API symbols in c_api.h
# Extension: apply to C API function declarations that need to be overridable
#            by downstream shared libraries (e.g., plugin injection)
```

## Impact
- API: None -- `TVM_FFI_WEAK` is additive, not yet applied to any symbol. Doc comment fix is cosmetic.
- Behavioral: None
- Flags/config: None
- Data formats/schemas: None
