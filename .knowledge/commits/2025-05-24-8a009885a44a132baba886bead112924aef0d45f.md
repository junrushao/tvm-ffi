# Phase out legacy C API: add TVM_FFI_WEAK macro and fix stale TVM_REGISTER_GLOBAL reference

## TL;DR
- Adds the `TVM_FFI_WEAK` macro to `c_api.h` for cross-platform weak linking (`__attribute__((weak))` on GCC/Clang, `__declspec(selectany)` on MSVC).
- Fixes a stale `TVM_REGISTER_GLOBAL` reference in a doc comment in `function.h`, replacing it with the canonical `TVM_FFI_REGISTER_GLOBAL`.
- Part of a broader upstream effort (apache/tvm#18010) to phase out the legacy `tvm/runtime/` C API in favor of the unified `tvm/ffi/` C API surface.

## Key Exports

### New macro (`include/tvm/ffi/c_api.h`)

- `TVM_FFI_WEAK` -- Cross-platform weak-linking attribute. Defined as `__declspec(selectany)` on MSVC and `__attribute__((weak))` on all other compilers. Placed in `c_api.h` so it is available to any translation unit that includes the FFI C ABI header. This macro enables symbols to be defined in headers without causing multiple-definition linker errors, which is essential for optional runtime hooks and default stub implementations in the module/plugin loading system.

### Documentation fix (`include/tvm/ffi/function.h`)

- In the Doxygen comment for `Function::Registry::set_body_typed`, the example code snippet used the legacy macro name `TVM_REGISTER_GLOBAL("sub")`. This is corrected to `TVM_FFI_REGISTER_GLOBAL("sub")` to match the canonical macro defined in this codebase.

## Impact
- API: Adds `TVM_FFI_WEAK` as a new public preprocessor macro. No functions, classes, or signatures changed.
- ABI: No ABI change. The macro is a compile-time attribute directive only.
- Behavioral: None. The doc comment fix has no runtime effect.

## Design Elements
Design elements this commit consumes:
- The `TVM_FFI_DLL` visibility/export macro pattern already established in `c_api.h` -- the new `TVM_FFI_WEAK` follows the same `#ifdef _MSC_VER` / `#else` structure.
- The `TVM_FFI_REGISTER_GLOBAL` macro from `function.h` (replacing the legacy `TVM_REGISTER_GLOBAL`).

Design elements this commit produces:
- **`TVM_FFI_WEAK` macro** -- A portable weak-linking attribute that downstream code and the module system can use to provide default/overridable symbol definitions in headers. This is the FFI-native replacement for any legacy `TVM_WEAK` or ad-hoc `__attribute__((weak))` usage.
