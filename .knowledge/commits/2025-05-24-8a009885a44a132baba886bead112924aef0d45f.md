# Add TVM_FFI_WEAK macro and fix stale TVM_REGISTER_GLOBAL doc comment

- Fixes a stale doc comment in `function.h` that still referenced `TVM_REGISTER_GLOBAL` instead of `TVM_FFI_REGISTER_GLOBAL`.
