# Add TVM_FFI_WEAK macro to c_api.h and fix legacy macro name in function.h doc comment

## TL;DR

- Adds `TVM_FFI_WEAK` macro to `c_api.h` providing platform-portable weak linking (`__declspec(selectany)` on MSVC, `__attribute__((weak))` on GCC/Clang).
- Fixes a stale doc comment in `function.h` that referenced the legacy `TVM_REGISTER_GLOBAL` macro; updated to `TVM_FFI_REGISTER_GLOBAL`.
- **Diff-message alignment note**: The commit message describes a broad legacy C API phase-out (redirecting headers, removing `registry.h` scaffolding, renaming `TVM_REGISTER_GLOBAL` at call sites), but the actual diff is limited to these two small changes — this is likely a preparatory or partial commit in a larger series.

## Key Exports

```python
# New macro in include/tvm/ffi/c_api.h

# TVM_FFI_WEAK — platform-portable weak-symbol linkage attribute
# On MSVC:    __declspec(selectany)
# On GCC/Clang: __attribute__((weak))
# Usage: decorate variable/function definitions that may be multiply defined across TUs
# Interacts with: c_api.h DLL export infrastructure (TVM_FFI_DLL)
# Invariant: defined before any TVM_FFI_DLL usage to allow optional override points
TVM_FFI_WEAK = "__attribute__((weak))"  # or __declspec(selectany) on MSVC
```
