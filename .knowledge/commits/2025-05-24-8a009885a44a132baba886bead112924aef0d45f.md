# Phase out legacy C API: add TVM_FFI_WEAK macro and rename TVM_REGISTER_GLOBAL in docs

## TL;DR
- Adds the `TVM_FFI_WEAK` platform-portable weak-linking macro to `c_api.h` (`__attribute__((weak))` on GCC/Clang, `__declspec(selectany)` on MSVC).
- Fixes a stale `TVM_REGISTER_GLOBAL` reference in a doc comment inside `function.h`, renaming it to `TVM_FFI_REGISTER_GLOBAL`.
- Part of a broader effort (PR #18010) to phase out legacy C API (`c_runtime_api.h`, `registry.h`) in favor of the unified FFI C API. The commit message describes wider renames (`registry.h => function.h`, `c_runtime_api.h => base.h`), but this repo's diff only contains the two changes above.

## Key Exports

```python
# New preprocessor macro in c_api.h (C/C++ only, no Python equivalent)
# TVM_FFI_WEAK: platform-portable weak-linking attribute
# - MSVC: expands to __declspec(selectany)
# - GCC/Clang: expands to __attribute__((weak))
# maturity: planned (defined but no active callers in this commit)
# Interacts with: future weak symbol definitions for optional C API entry points
# Extension: use TVM_FFI_WEAK before global variable definitions that may be
#   overridden by a stronger definition in another translation unit
```
