# Phase out legacy C API by adding TVM_FFI_WEAK macro and fixing stale TVM_REGISTER_GLOBAL reference
## TL;DR
- Adds the `TVM_FFI_WEAK` macro to `c_api.h`, providing cross-platform weak-linking support (`__attribute__((weak))` on GCC/Clang, `__declspec(selectany)` on MSVC). This macro is part of the broader effort to consolidate FFI scaffolding and remove dependency on the legacy `tvm/runtime/` headers.
- Fixes a stale doc-comment in `function.h` that still referenced the legacy `TVM_REGISTER_GLOBAL` macro, updating it to the canonical `TVM_FFI_REGISTER_GLOBAL`.
- This commit is one piece of a larger TVM-wide refactor (PR #18010) that replaces `tvm/runtime/registry.h` with `tvm/ffi/function.h` across the entire TVM codebase. Only the FFI-core changes land here.

## Impact
- **API**: The `TVM_FFI_WEAK` macro is a new public C preprocessor symbol in `c_api.h`. It enables downstream code (kernel libraries, module loaders, addons) to define weak symbols that can be optionally overridden by the main TVM shared library without causing linker errors. No existing API is changed or removed.
- **Flags/config**: None.
- **Data formats/schemas**: None.

## Design Elements

Design elements this commit consumes:

- **C ABI layer** ([`.knowledge/designs/0001-c-abi.md`](../designs/0001-c-abi.md)): The `TVM_FFI_WEAK` macro is placed alongside existing visibility macros (`TVM_FFI_DLL`, `TVM_FFI_DLL_EXPORT`) in `c_api.h`, following the same platform-conditional `#ifdef` pattern. It extends the C ABI surface with a linking-control primitive.
- **Function system / registration macros** ([`.knowledge/designs/0004-function-system.md`](../designs/0004-function-system.md)): The doc-comment fix in `function.h` corrects the `TVM_REGISTER_GLOBAL` -> `TVM_FFI_REGISTER_GLOBAL` reference, aligning documentation with the actual macro defined in `TVM_FFI_REGISTER_GLOBAL` (line ~937 of `function.h`).

Design elements this commit produces:

- **`TVM_FFI_WEAK` macro** (new, in `include/tvm/ffi/c_api.h:30-35`): A cross-platform weak-linking attribute macro. On MSVC, expands to `__declspec(selectany)` (the closest MSVC equivalent to weak symbols). On GCC/Clang (including Emscripten), expands to `__attribute__((weak))`. This is an infrastructure primitive that enables optional symbol override patterns in shared-library architectures -- for example, a kernel library can define a default implementation of a function that the main TVM runtime overrides at link time.
