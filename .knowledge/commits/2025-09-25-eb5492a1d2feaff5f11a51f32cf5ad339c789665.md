# Guard torch 2.8+ dtype symbols behind version/hasattr checks
## TL;DR
- `Float8_e8m0fnu` was unconditionally referenced in both the C++ torch-DLPack addon and the Cython dtype mapping, causing `AttributeError` (Python) or compile failure (C++) on torch < 2.8.
- C++ addon (`_optional_torch_c_dlpack.py`): moved `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` guard to also cover `ScalarType::Float8_e8m0fnu` case and the `dtype.lanes == 1` assertion that only applies when `Float4_e2m1fn_x2` exists.
- Cython (`dtype.pxi`): replaced unconditional `torch.float8_e8m0fnu` dict literal with `hasattr` guard; added similarly guarded entry for `torch.float4_e2m1fn_x2`.

## Key Exports
None — this commit only fixes version guards on existing dtype mappings; no new public API surface.

## Impact
- API: None — no signature changes.
- Behavioral: Restores compatibility with torch <= 2.7. Previously, importing `tvm_ffi` or loading the torch DLPack addon would fail on these older torch versions.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **DLDataType code enum** (`DLDataTypeCode` from DLPack) — the numeric codes `kDLFloat8_e8m0fnu` (14) and `kDLFloat4_e2m1fn` (17) are used in both layers. See `0001-ffi-c-abi`.
- **TORCH_DTYPE_TO_DTYPE mapping** in `dtype.pxi` — the Python-side torch dtype to DLDataType lookup table. See `0012-ffi-python-package`.
- **`_optional_torch_c_dlpack.py` C++ inline source** — embedded C++ compiled by the torch DLPack addon for bidirectional DLPack v1 conversion. See `0012-ffi-python-package`.

Design elements this commit produces: None.

## Usage Examples
Before (fails on torch < 2.8):
```python
# dtype.pxi — unconditional access raises AttributeError
TORCH_DTYPE_TO_DTYPE = {
    ...
    torch.float8_e8m0fnu: DLDataType(14, 8, 1),  # AttributeError if torch < 2.8
}
```

After (guarded):
```python
TORCH_DTYPE_TO_DTYPE = { ... }  # only types present in all supported torch versions
if hasattr(torch, "float8_e8m0fnu"):
    TORCH_DTYPE_TO_DTYPE[torch.float8_e8m0fnu] = DLDataType(14, 8, 1)
if hasattr(torch, "float4_e2m1fn_x2"):
    TORCH_DTYPE_TO_DTYPE[torch.float4_e2m1fn_x2] = DLDataType(17, 4, 2)
```
