# Guard Float8_e8m0fnu and Float4_e2m1fn_x2 dtype mappings behind torch >= 2.8 version checks
## TL;DR
- Fixes compilation and runtime errors when using TVM FFI with PyTorch versions older than 2.8, where `ScalarType::Float8_e8m0fnu`, `ScalarType::Float4_e2m1fn_x2`, `torch.float8_e8m0fnu`, and `torch.float4_e2m1fn_x2` do not exist.
- In the JIT-compiled C++ source (`_optional_torch_c_dlpack.py`): moves the `Float8_e8m0fnu` case inside the existing `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` guard (previously only `Float4_e2m1fn_x2` was guarded). Also guards the `kDLFloat4_e2m1fn` lanes-check branch in `toScalarTypeForDLPackv1` and the `kDLFloat8_e8m0fnu` DLPack-to-ScalarType case behind the same version macro.
- In the Cython dtype mapping (`dtype.pxi`): replaces the unconditional `torch.float8_e8m0fnu` dict entry with a `hasattr(torch, "float8_e8m0fnu")` guard, and adds a similarly guarded entry for `torch.float4_e2m1fn_x2` (DLDataType code 17, 4 bits, 2 lanes).

## Key Exports
None (no new APIs). This modifies version guards in existing code.

Changed symbols:

| Symbol | Kind | Change |
|--------|------|--------|
| `getDLDataTypeForDLPackv1` | C++ function (JIT-compiled) | `Float8_e8m0fnu` case moved inside `TORCH_VERSION >= 2.8` guard |
| `toScalarTypeForDLPackv1` | C++ function (JIT-compiled) | `kDLFloat4_e2m1fn` lanes-check and `kDLFloat8_e8m0fnu` case moved inside `TORCH_VERSION >= 2.8` guard |
| `TORCH_DTYPE_TO_DTYPE` | Cython dict (`dtype.pxi`) | `float8_e8m0fnu` entry guarded by `hasattr`; `float4_e2m1fn_x2` entry added (also guarded) |

## Impact
- API: none
- ABI: none
- Behavioral: Enables TVM FFI to work with PyTorch < 2.8 without compilation errors in the JIT-compiled DLPack extension. On torch < 2.8, the `Float8_e8m0fnu` and `Float4_e2m1fn_x2` dtype codes are simply unavailable (attempting to convert a tensor with those dtypes would hit a default error path). On torch >= 2.8, behavior is unchanged. Additionally, the Cython `TORCH_DTYPE_TO_DTYPE` mapping now includes `float4_e2m1fn_x2` (previously missing entirely), enabling DLPack conversion for that dtype on torch >= 2.8.
- Flags/config: none
- Data formats/schemas: none
