# Guard Float8_e8m0fnu behind torch >= 2.8 version check alongside Float4_e2m1fn_x2
## TL;DR
- Moves the `#if TORCH_VERSION_MAJOR >= 2 && TORCH_VERSION_MINOR >= 8` guard in the inline C++ source (`_optional_torch_c_dlpack.py`) to also cover `Float8_e8m0fnu` (not just `Float4_e2m1fn_x2`), fixing JIT compilation failures on PyTorch < 2.8.
- Adds a second `#if`/`#endif` guard around the `kDLFloat4_e2m1fn` lane-check in `toScalarTypeForDLPackv1`, which references `kDLFloat4_e2m1fn` (also torch >= 2.8-only).
- In `dtype.pxi`, switches `torch.float8_e8m0fnu` and `torch.float4_e2m1fn_x2` from static dict entries to `hasattr`-guarded runtime additions, preventing `AttributeError` on older torch.
