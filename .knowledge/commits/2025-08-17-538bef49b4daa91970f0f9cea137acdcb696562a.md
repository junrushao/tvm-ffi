# Formalize ffi.Module as a first-class object with library loading and import tree support
## TL;DR
- Introduces `ModuleObj`/`Module` as the abstract base for dynamically-loadable FFI modules, with virtual methods for function lookup, serialization, source inspection, and import management.
- Adds two concrete backends: `DSOLibrary` (dynamic shared library via dlopen/LoadLibrary) and `SystemLibrary` (statically-registered symbol table), both wrapped by `LibraryModuleObj`.
- Provides three new C ABI entry points (`TVMFFIEnvLookupFromImports`, `TVMFFIEnvRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol`) and registers FFI global functions for module operations.
- Fixes macro hygiene in `object.h`: removes trailing semicolons from `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS` / `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS`, and corrects `TVM_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN` typo to `TVM_FFI_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN`.

## Impact
- API: Adds `ModuleObj`/`Module` to the public C++ API under `include/tvm/ffi/extra/module.h` and three new C ABI functions in `include/tvm/ffi/extra/c_env_api.h`. Adds `ffi.Module` type index to the static type table. Also adds `ffi.SmallStr` and `ffi.SmallBytes` type keys (reordering in `StaticTypeKey`).
- Behavioral: Fixes trailing-semicolon macro hygiene in `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS` and `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS`. Fixes `TVM_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN` typo to `TVM_FFI_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN` in the notnullable variant.
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` CMake option now also builds the four new module source files.
- Data formats/schemas: Defines the library binary format for `__tvm_ffi_library_bin`: `<nbytes:u64> <import_tree_CSR> <kind0:str> <val0:bytes> ...`, where `_lib` kind marks DSO module position.

## Design Elements
Design elements this commit consumes:
- Object system (0002): `ModuleObj` extends `Object`, `Module` extends `ObjectRef`. Uses `TVM_FFI_DECLARE_STATIC_OBJECT_INFO`, `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS`.
- Function system (0003): `GetFunction` returns `Optional<Function>`. `Function::GetGlobal` for loader lookup. `Function::FromPacked` wraps C-ABI symbols.
- Reflection (0008): `reflection::ObjectDef<ModuleObj>` registers `imports_` field. `reflection::GlobalDef` registers 12 global functions.
- Containers (0006): `Array<Any>` for imports, `Map<String, Function>` for import lookup cache, `Map<String, void*>` for system lib symbols.
- C ABI (0007): `TVMFFISafeCallType`, `TVM_FFI_SAFE_CALL_BEGIN/END`, `TVM_FFI_DLL` export.
- TypeTraits (0005): `TypeIndex::kTVMFFIModule` added to the static type index enum via `StaticTypeKey::kTVMFFIModule`.

Design elements this commit produces:
- **`ffi.Module` subsystem**: New abstract module interface (`ModuleObj`/`Module`) with import tree, function lookup, serialization, and property masks.
- **Library loading protocol**: `Library` abstract base + `DSOLibrary` (dlopen) + `SystemLibrary` (static registry) + `LibraryModuleObj` concrete module.
- **Library binary format**: CSR-encoded import tree with embedded serialized modules.
- **C ABI env functions**: `TVMFFIEnvLookupFromImports`, `TVMFFIEnvRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol`.
- **Context symbol registry**: `ContextSymbolRegistry` singleton for injecting symbols into library modules at load time.

## Usage Examples

Loading a shared library module and calling a function from it:
```cpp
// C++ usage: load a .so and call a function
#include <tvm/ffi/extra/module.h>

Module mod = Module::LoadFromFile("my_kernel.so");
// Resolve a function from the module (also searches imports)
Optional<Function> func = mod->GetFunction("my_kernel", /*query_imports=*/true);
Any result;
(*func)(input_tensor, &result);
```

Registering system library symbols for embedded deployment:
```c
// C usage: register symbols before loading system lib
TVMFFIEnvRegisterSystemLibSymbol("my_kernel", (void*)&my_kernel_impl);
// Then from C++/Python: ffi.SystemLib("") returns a Module wrapping the system library
```

Import tree usage with cyclic detection:
```cpp
Module parent = Module::LoadFromFile("parent.so");
Module child = Module::LoadFromFile("child.so");
parent->ImportModule(child);  // OK
// child->ImportModule(parent);  // throws RuntimeError: cyclic dependency
```
