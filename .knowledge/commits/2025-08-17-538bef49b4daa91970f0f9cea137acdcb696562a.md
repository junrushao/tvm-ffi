# Introduce ffi.Module: a stable dynamic module abstraction moved from runtime into core FFI

## TL;DR
- Formalizes `ffi::Module` (`ModuleObj` / `Module`) as a stable extra-API type at static type index 73, ported from `runtime::Module`, exposing `GetFunction`, `ImportModule`, and property-mask capabilities.
- Adds `Library` + `LibraryModuleObj` + system-library and DSO-library backends; registers `ffi.Module.load_from_file.so` and `ffi.SystemLib` as global functions.
- Exposes three new C-ABI symbols (`TVMFFIEnvLookupFromImports`, `TVMFFIEnvRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol`) and fixes two macro trailing-semicolon issues in `object.h`.

## Impact
- API: New public C++ types `ModuleObj`/`Module` in `tvm::ffi::` namespace under `include/tvm/ffi/extra/module.h` (guarded by `TVM_FFI_USE_EXTRA_CXX_API` build flag). Three new C-ABI exported symbols added to `c_env_api.h`.
- Behavioral: `Module::LoadFromFile` dispatches to `ffi.Module.load_from_file.<ext>` registry; `.dll`/`.dylib`/`.dso` extensions are normalized to `"so"` before dispatch. Import cycle detection is now enforced at `ImportModule` time (DFS, throws `RuntimeError`).
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` cmake flag now also compiles four additional `.cc` files.
- Data formats/schemas: The library binary blob format embedded in `.so` files is a CSR-structured import tree: `<nbytes:u64><indptr:vec<u64>><child_indices:vec<u64>>` followed by `<kind:str><bytes:str>` pairs. `"_lib"` kind is a placeholder for the DSO module itself.

## Design Elements
Design elements this commit consumes:
- **Object system** (0002-object-system): `ModuleObj` follows the `FooObj`/`Foo` pattern with `TVM_FFI_DECLARE_STATIC_OBJECT_INFO` and `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS`. Uses `make_object<T>()`.
- **C ABI** (0001-c-abi): Assigns `kTVMFFIModule = 73` to the static type index range. Adds three C-linkage `TVM_FFI_DLL` functions to `c_env_api.h`. Uses `TVMFFISafeCallType` calling convention via `TVM_FFI_SAFE_CALL_BEGIN/END`.
- **Function system** (0004-function-system): Uses `reflection::GlobalDef().def(...)` inside `TVM_FFI_STATIC_INIT_BLOCK` for all global registrations. Uses `Function::GetGlobal`, `Function::FromPacked`, `TypedFunction`.
- **Reflection** (0006-reflection): Uses `ObjectDef<ModuleObj>().def_ro("imports_", ...)` to expose the imports field. Uses `GlobalDef().def_method(...)` for module method globals.
- **Containers** (0007-containers): `imports_` is `Array<Any>`, `import_lookup_cache_` is `Map<String, ffi::Function>`.

Design elements this commit produces:
- **ffi.Module subsystem** (new): `ModuleObj`/`Module`, `Library` abstract interface, `LibraryModuleObj`, `DSOLibrary`, `SystemLibrary`, `SystemLibModuleRegistry`, `ContextSymbolRegistry`, `BufferInStream`, `ProcessLibraryBin`, `CreateLibraryModule`. Located in `include/tvm/ffi/extra/module.h` and `src/ffi/extra/`.

## Usage Examples

Loading a compiled `.so` and calling a function:
```cpp
// C++: load a compiled kernel library and invoke a function
Module mod = Module::LoadFromFile("kernel.so");
// "ffi.Module.load_from_file.so" handler is registered automatically

Optional<Function> fn = mod->GetFunction("__tvm_main__", /*query_imports=*/true);
if (fn) (*fn)(/* packed args */);

// Import another module for symbol resolution
Module helper = Module::LoadFromFile("helper.so");
mod->ImportModule(helper);  // cycle detection: throws if helper transitively imports mod
```

Using the system library (static linking / embedded code):
```cpp
// C-generated code calls at load time:
TVMFFIEnvRegisterSystemLibSymbol("my_kernel", reinterpret_cast<void*>(&my_kernel_impl));

// Host retrieves the module:
Module sys = get_global_func("ffi.SystemLib")();  // or with prefix: ("ffi.SystemLib")("prefix_")
Optional<Function> fn = sys->GetFunction("my_kernel");
```

Generated kernel code resolves host imports via C ABI:
```c
// Generated C code in kernel .so — no explicit link dep on tvm runtime:
TVMFFIEnvLookupFromImports(library_ctx, "host_helper_fn", &out_fn_handle);
// Resolved through the import chain + global registry at first call, then cached.
```
