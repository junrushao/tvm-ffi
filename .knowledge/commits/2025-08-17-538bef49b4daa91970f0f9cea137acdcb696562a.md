# Formalize ffi.Module: dynamic module loading, library wrapping, and import tree deserialization
## TL;DR
- Introduces `ModuleObj`/`Module` as a first-class FFI Object type (`type_index=73`, `type_key="ffi.Module"`) with virtual methods for function lookup, serialization, source inspection, and hierarchical module imports with cyclic dependency detection.
- Adds `Library` abstract interface, `LibraryModuleObj` (wraps DSO symbols as `ffi::Function`), `DSOLibrary` (dlopen/LoadLibrary), `SystemLibrary` (static symbol registry), and binary import-tree deserialization via `ProcessLibraryBin`.
- Introduces C env APIs (`TVMFFIEnvLookupFromImports`, `TVMFFIEnvRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol`) and context symbol initialization for loaded libraries.
- Fixes macro bugs in `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS` and `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS` (trailing semicolons, wrong macro name `TVM_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN`), and adds `kTVMFFIModule` to `StaticTypeKey`/`TypeIndex`.

## Impact
- API: New public header `include/tvm/ffi/extra/module.h` and C API `include/tvm/ffi/extra/c_env_api.h`. Adds `StaticTypeKey::kTVMFFIModule` and reorders `StaticTypeKey::kTVMFFISmallStr`/`kTVMFFISmallBytes` in `object.h`.
- Behavioral: Fixes trailing-semicolon bugs in `TVM_FFI_DEFINE_MUTABLE_OBJECT_REF_METHODS` and `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS` macros. Fixes `TVM_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN` typo to `TVM_FFI_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN` in the notnullable variant.
- Flags/config: `TVM_FFI_USE_EXTRA_CXX_API` CMake option now builds the four new module source files.
- Data formats/schemas: Defines binary library format (`ProcessLibraryBin`): `<nbytes:u64> <import_tree_indptr:vec<u64>> <child_indices:vec<u64>> <kind:str,bytes:bytes>...`

## Design Elements
Design elements this commit consumes:
- Object/ObjectRef pattern (`0003-ffi-object-system`): ModuleObj extends Object, Module extends ObjectRef
- Static object macros (`0008-ffi-object-macros`): uses `TVM_FFI_DECLARE_STATIC_OBJECT_INFO` with pre-assigned `kTVMFFIModule=73`
- Function system (`0004-ffi-function-system`): Module methods registered via `refl::GlobalDef` in `TVM_FFI_STATIC_INIT_BLOCK`; `Function::FromPacked` wraps library symbols
- Reflection (`0007-ffi-reflection`): `ObjectDef<ModuleObj>.def_ro("imports_", ...)` exposes imports to cross-language access
- Containers (`0006-ffi-containers`): `Array<Any>` for imports, `Map<String, Function>` for import cache, `Map<String, void*>` for symbol tables
- C ABI (`0001-ffi-c-abi`): `TVMFFISafeCallType` calling convention used by `LibraryModuleObj::GetFunction`; `TVM_FFI_SAFE_CALL_BEGIN/END` for C env API implementations

Design elements this commit produces:
- **ModuleObj/Module** (`ffi.Module`): First-class FFI module type with virtual interface for function lookup, serialization, import hierarchy, and source inspection
- **Library** (internal): Abstract symbol-lookup interface for shared libraries
- **LibraryModuleObj**: Concrete module wrapping a Library, bridging native symbols to packed Functions
- **DSOLibrary**: Dynamic shared library loader (dlopen/LoadLibraryW)
- **SystemLibrary/SystemLibSymbolRegistry**: Static symbol table for ahead-of-time compiled modules
- **ContextSymbolRegistry**: Global registry for context symbols initialized at library load time
- **ProcessLibraryBin protocol**: Binary deserialization of module import trees
- **C env API surface**: `TVMFFIEnvLookupFromImports`, `TVMFFIEnvRegisterContextSymbol`, `TVMFFIEnvRegisterSystemLibSymbol`
- **Module.ModulePropertyMask**: Bitmask enum for module capability declaration
- **Well-known symbols**: `__tvm_ffi_library_ctx`, `__tvm_ffi_library_bin`, `__tvm_ffi_main__`
- **Mutable ref macro fix**: `TVM_FFI_DEFINE_MUTABLE_NOTNULLABLE_OBJECT_REF_METHODS` now uses correct `TVM_FFI_DEFINE_DEFAULT_COPY_MOVE_AND_ASSIGN` and removes trailing semicolons

## Usage Examples

Loading a compiled DSO module and calling an exported function (C++ side):
```cpp
// Load a shared library module
Module mod = Module::LoadFromFile("my_model.so");
// Look up a function (including in imported sub-modules)
Optional<Function> f = mod->GetFunction("main", /*query_imports=*/true);
// Call the function
Any result = (*f)(input_tensor);

// Import sub-modules
Module sub = Module::LoadFromFile("sub_module.so");
mod->ImportModule(sub);  // cyclic dependency check runs automatically
```

Registering a custom module loader for a new file format:
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("ffi.Module.load_from_file.myformat",
    [](String library_path, String format) -> Module {
      auto lib = make_object<MyCustomLibrary>(library_path);
      return CreateLibraryModule(lib);
    });
});
```
