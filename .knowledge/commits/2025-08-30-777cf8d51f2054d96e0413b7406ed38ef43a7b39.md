# Reorder static type indices for C ABI complexity grouping and add module metadata API

## TL;DR
- Reorders `TVMFFITypeIndex` static enum values to group simple C-ABI types (Shape=69, NDArray=70) before complex C++-dependent types (Array=71, Map=72), preparing for ABI freeze.
- Adds `ModuleObj::GetFunctionMetadata` virtual method and `tvm_ffi_metadata_prefix` symbol convention for retrieving per-function metadata from dynamically loaded modules.
- Renames `override` -> `allow_override` parameter in `TVMFFIFunctionSetGlobal` / `TVMFFIFunctionSetGlobalFromMethodInfo` for clarity (source-level only, not ABI-breaking).

## Impact
- API: ABI-breaking change to `TVMFFITypeIndex` enum values — Shape (71->69), NDArray (72->70), Array (69->71), Map (70->72). All language bindings must update mirrored enum values. Cython updated in this commit; Rust bindings would also need updating.
- Behavioral: New `GetFunctionMetadata` virtual method on `ModuleObj` with default returning `nullopt` — existing subclasses unaffected unless they shadow the name.
- Flags/config: none
- Data formats/schemas: Any serialized type indices for Shape/NDArray/Array/Map are invalidated by the reordering. Version bumped to 0.1.0a3 to signal ABI break.

Design elements this commit produces:
- **Complexity grouping convention** in `TVMFFITypeIndex`: simple C-ABI-only objects (Shape, NDArray) are now grouped before complex C++-dependent objects (Array, Map). This establishes a sub-ordering principle within the static object range.
- **`ModuleObj::GetFunctionMetadata`** virtual method pair (single-module + import-traversing overloads)
- **`symbol::tvm_ffi_metadata_prefix`** (`"__tvm_ffi_metadata_"`) well-known DSO symbol prefix convention
- **`ffi.ModuleGetFunctionMetadata`** registered global function

## Usage Examples
Querying metadata from a loaded module (C++ level):
```cpp
#include <tvm/ffi/extra/module.h>

Module mod = Module::LoadFromFile("model.so");
// Query metadata for a specific function, searching imports
Optional<String> meta = mod->GetFunctionMetadata("forward", /*query_imports=*/true);
if (meta.defined()) {
  // meta.value() is a JSON string with function metadata
  LOG(INFO) << "Metadata: " << meta.value();
}
```
