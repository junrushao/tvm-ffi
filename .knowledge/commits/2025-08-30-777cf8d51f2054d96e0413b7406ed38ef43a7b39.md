# ABI: reorder static type indices to separate simple from complex objects, add GetFunctionMetadata to Module

## TL;DR
- `kTVMFFITypeIndex` enum values reordered in `c_api.h` and mirrored in Cython `base.pxi`: simple C-ABI objects (Shape=69, NDArray=70) now precede complex C++ objects (Array=71, Map=72), keeping Module=73; version bumped to 0.1.0a3.
- `TVMFFIFunctionSetGlobal`/`TVMFFIFunctionSetGlobalFromMethodInfo` parameter renamed from `override` to `allow_override` for clarity.
- `ModuleObj::GetFunctionMetadata` virtual method added (default: `std::nullopt`) with public non-virtual override supporting `query_imports`, registered as global `ffi.ModuleGetFunctionMetadata`; symbol constant `tvm_ffi_metadata_prefix = "__tvm_ffi_metadata_"` added.

## Impact
- API: **ABI-breaking** — `kTVMFFIArray`, `kTVMFFIMap`, `kTVMFFIShape`, `kTVMFFINDArray` all changed numeric values; all compiled consumers must be recompiled. Version bumped to `0.1.0a3`. Cython `base.pxi` updated in lock-step.
- API: `override` parameter renamed to `allow_override` in `TVMFFIFunctionSetGlobal` and `TVMFFIFunctionSetGlobalFromMethodInfo` — breaks any C or Cython callers using keyword arguments (rare but possible).
- Behavioral: New `GetFunctionMetadata` is additive; no existing behavior changed. Default implementation returns `nullopt` (backward compatible for all existing `ModuleObj` subclasses).
- Flags/config: `scripts/run_tests.sh` changed build type from `Release` to `RelWithDebugInfo`; added `rm -rf build/CMakeCache.txt` before cmake configure step (local script only, not CI-gating).
- Data formats/schemas: `tvm_ffi_metadata_prefix = "__tvm_ffi_metadata_"` establishes a naming convention for metadata symbols embedded in shared libraries (anticipates future DSO library metadata lookups).

## Design Elements
Design elements this commit consumes:
- `0001-c-abi`: `TVMFFITypeIndex` enum, `TVMFFIFunctionSetGlobal`, `TVMFFIFunctionSetGlobalFromMethodInfo`
- `0011-module-system`: `ModuleObj`/`Module`, `imports_` chain traversal pattern, `TVM_FFI_STATIC_INIT_BLOCK` registration idiom, `symbol::` namespace constants
- `0007-containers`: static type indices for Array, Map, Shape, NDArray

Design elements this commit produces:
- **Updated `kTVMFFITypeIndex` ordering** — simple (C-ABI layout) objects precede complex (C++ layout) objects in the static range [69–73]. Documented in `0001-c-abi`.
- **`ModuleObj::GetFunctionMetadata`** — new virtual extension point returning JSON metadata for a named function, with public import-chain traversal variant. Extends `0011-module-system`.
- **`symbol::tvm_ffi_metadata_prefix`** — naming convention `"__tvm_ffi_metadata_"` for future DSO metadata symbol discovery. Extends `0011-module-system`.
- **`ffi.ModuleGetFunctionMetadata`** global function — Python-accessible entry for cross-layer metadata retrieval.

## Usage Examples

Cross-layer trace for `GetFunctionMetadata`:

```cpp
// C++: subclass ModuleObj and override virtual method
class MyModuleObj : public ModuleObj {
  Optional<String> GetFunctionMetadata(const String& name) override {
    if (name == "my_kernel")
      return String("{\"num_args\": 3, \"dtype\": \"float32\"}");
    return std::nullopt;
  }
};
```

