# Reorder static object type indices for C ABI simplicity and add Module metadata API

## TL;DR
- Reorders the `TVMFFIStaticObjectKind` enum in `c_api.h` so simple C-ABI-safe objects (Shape, NDArray) precede more complex C++-dependent objects (Array, Map), as ABI preparation before freezing.
- Adds `ModuleObj::GetFunctionMetadata()` virtual method and `tvm_ffi_metadata_prefix` symbol constant for future per-function metadata retrieval from loaded modules.
- Renames `override` parameter to `allow_override` in `TVMFFIFunctionSetGlobal` and `TVMFFIFunctionSetGlobalFromMethodInfo` C API signatures.
- Bumps version from `0.1.0a2` to `0.1.0a3`.

## Impact
- API: **ABI-breaking** -- type index values for Array (69->71), Map (70->72), Shape (71->69), NDArray (72->70) changed. All bindings that hardcode these values must update. Parameter `override` renamed to `allow_override` in two C API signatures.
- Behavioral: None -- no semantic change to existing functions. `GetFunctionMetadata` returns `nullopt` by default.
- Flags/config: Build script changed to `RelWithDebugInfo` and now clears CMakeCache before builds.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **C ABI type index enum** (`0007-c-abi`) -- reorders static object range `[68, 73]`
- **Module virtual interface** (`0011-module-system`) -- extends `ModuleObj` with new virtual method
- **Import chain lookup pattern** (`0011-module-system`) -- `GetFunctionMetadata(name, query_imports)` follows the same recursive import-search pattern as `GetFunction`

Design elements this commit produces:
- **Simple/complex object ordering convention** -- establishes that within `TVMFFIStaticObjectKind`, objects with pure C-ABI layout (Shape, NDArray) are grouped before objects requiring C++ runtime (Array, Map). This ordering is a new convention that future additions to the enum should follow.
- **Module function metadata protocol** -- `GetFunctionMetadata` + `tvm_ffi_metadata_prefix` symbol convention for per-function metadata retrieval from loaded modules. Currently a stub (returns None), intended for future extension.

## Usage Examples

Querying function metadata from a loaded module (C++):
```cpp
#include <tvm/ffi/extra/module.h>
using namespace tvm::ffi;

Module mod = Module::LoadFromFile("my_kernel.so");
// Get metadata for a specific function, searching imports
Optional<String> meta = mod->GetFunctionMetadata("my_kernel", /*query_imports=*/true);
if (meta.defined()) {
    // meta.value() is a JSON string with function metadata
}
```
