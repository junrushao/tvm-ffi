# Fix Rust docs build by deferring copy to build-finished Sphinx event
## TL;DR
- Fixes Rust documentation integration: moves the `cargo doc` output copy from `_build_rust_docs()` (called at config time, before `app.outdir` exists) to a new `_copy_rust_docs_to_output()` handler connected to Sphinx's `build-finished` event.
- Removes the intermediate `_RUST_OUTPUT_DIR` constant and `html_extra_path` approach; copies directly to `app.outdir/reference/rust/generated/` after the build completes.
- Adds `from __future__ import annotations` to `docs/conf.py`.
