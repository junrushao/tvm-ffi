# Fix Rust docs build by copying output to correct Sphinx output directory
## TL;DR
- The Rust doc copy step in `docs/conf.py` was writing to a docs-source-relative path (`docs/reference/rust/generated/`) instead of the Sphinx HTML output directory (`app.outdir`), so generated Rust docs were missing from the final site.
- Replaced the inline `shutil.copytree` inside `_build_rust_docs()` with a new `_copy_rust_docs_to_output()` hook registered on Sphinx's `build-finished` event, which copies to `Path(app.outdir) / "reference" / "rust" / "generated"`.
- Removed the now-unused `_RUST_OUTPUT_DIR` module-level constant.
