# Fix Rust docs build to copy output after Sphinx build-finished event

## TL;DR
- Removed pre-build static `_RUST_OUTPUT_DIR` constant; Rust docs are now copied during the Sphinx `build-finished` event so the HTML output directory is known.
- Introduced `_copy_rust_docs_to_output(app, exception)` callback registered via `app.connect("build-finished", ...)`.
- Added `from __future__ import annotations` to `docs/conf.py`.

## Impact
- API: none — internal docs build pipeline only.
- Behavioral: Rust documentation is now copied to `<outdir>/reference/rust/generated/` after the Sphinx HTML build completes, rather than to a hardcoded relative path that didn't exist at build time.
