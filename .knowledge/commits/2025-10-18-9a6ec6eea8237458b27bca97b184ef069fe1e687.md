# Fix Rust docs build by copying to Sphinx output dir instead of source tree
## TL;DR
- Rust docs were being copied into the source tree (`docs/reference/rust/generated/`) instead of the Sphinx HTML output directory (`app.outdir`), so they never appeared in the built site.
- Introduced a new `_copy_rust_docs_to_output` Sphinx `build-finished` event handler that copies Rust docs to `app.outdir/reference/rust/generated/` after the build completes.
- Removed the now-unnecessary `_RUST_OUTPUT_DIR` constant and the inline copy logic from `_build_rust_docs()`.
