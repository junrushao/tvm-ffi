# Fix Rust docs build by copying to Sphinx output dir after build completes
## TL;DR
- Fixed Rust documentation build by moving the copy step from build-time (source tree) to a Sphinx `build-finished` event handler that copies to the correct output directory (`app.outdir`).
- Removed the intermediate `_RUST_OUTPUT_DIR` constant that pointed to a source-tree path.
- Added `from __future__ import annotations` to `docs/conf.py` for code convention compliance.
