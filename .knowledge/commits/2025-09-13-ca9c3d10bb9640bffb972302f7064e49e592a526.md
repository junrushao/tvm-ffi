# Introduce weak reference counter support to the FFI object ABI

## TL;DR
- Splits the single `ref_counter` in `TVMFFIObject` into `weak_ref_count` (uint32) + `strong_ref_count` (uint64), growing the header from 16 to 24 bytes; the design choice keeps weak as u32 to stay within the 24-byte boundary.
- Changes the `deleter` signature from `void(*)(obj)` to `void(*)(obj, int flags)` using `TVMFFIObjectDeleterFlagBitMask` so one allocator can handle destructor-only, free-only, or both in a single call.
- Introduces `WeakObjectPtr<T>` (parallel to `ObjectPtr<T>`) with `lock()` / `expired()` / `reset()` and renames `TVMFFIObjectFree` → `TVMFFIObjectDecRef` (new `TVMFFIObjectIncRef` added).

## Impact
- API: **Breaking ABI change** — `TVMFFIObject` layout changed from 16 to 24 bytes; any compiled code (binaries, Cython extensions, Rust bindings) against the old header is binary-incompatible. `TVMFFIObjectFree` removed from C ABI; `TVMFFIObjectDecRef` and `TVMFFIObjectIncRef` replace it. All callers of `TVMFFIObjectFree` must be updated (Cython `base.pxi`, `dtype.pxi`, `object.pxi` done in this commit).
- Behavioral: `DecRef` fast-path (gcc/clang): when `strong_ref_count` hits 0 and `weak_ref_count == 1`, calls deleter once with `kTVMFFIObjectDeleterFlagBitMaskBoth`. Slower path: when weak refs remain, calls deleter with `kStrong` first, then defers `kWeak` deletion. Destructor and memory free are now logically decoupled.
- Flags/config: `static_assert(sizeof(TVMFFIObject) == 24)` enforced in `type_traits.h` (NDArray layout check) and `test_c_ffi_abi.cc`.
- Data formats/schemas: `TVMFFIObject` header size is part of the stable C ABI; `kTVMFFINDArray` offsets derived from `sizeof(TVMFFIObject)` must be recomputed by any external code.

## Usage Examples

Constructing and locking a weak reference (from `tests/cpp/test_object.cc`):

```cpp
// Create a strong reference
ObjectPtr<TIntObj> strong_ptr = make_object<TIntObj>(42);
// Obtain a weak reference (does NOT keep object alive)
WeakObjectPtr<TIntObj> weak_ptr(strong_ptr);

// Try to promote back to strong while object is alive
ObjectPtr<TIntObj> locked = weak_ptr.lock();  // returns non-null
assert(locked->value == 42);
assert(strong_ptr.use_count() == 2);

// Drop all strong refs; weak ref remains, but object is destroyed
strong_ptr.reset();
locked.reset();
assert(weak_ptr.expired());
assert(weak_ptr.lock() == nullptr);  // memory still alive until weak_ptr destroyed
// Destructor called when strong_ref_count → 0; memory freed when weak_ref_count → 0
```

Custom deleter with flags (pattern from `SimpleObjAllocator`):

```cpp
static void Deleter_(TVMFFIObject* objptr, int flags) {
    T* tptr = ObjectUnsafe::RawObjectPtrFromUnowned<T>(objptr);
    if (flags & kTVMFFIObjectDeleterFlagBitMaskStrong) {
        tptr->T::~T();           // destructor: release owned resources
    }
    if (flags & kTVMFFIObjectDeleterFlagBitMaskWeak) {
        delete reinterpret_cast<StorageType*>(tptr);  // free raw memory
    }
}
```
