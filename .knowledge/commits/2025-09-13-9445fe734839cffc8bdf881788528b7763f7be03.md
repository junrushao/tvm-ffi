# Add structural equality and hash driven by reflection metadata

## TL;DR
- Introduces `StructuralEqual` and `StructuralHash` classes that recursively compare/hash any `Any` value by walking registered reflection fields, supporting tree, DAG, free-var, and const-tree node semantics.
- Adds `TVMFFISEqHashKind` enum and `structural_eq_hash_kind` to `TVMFFITypeExtraInfo` so each `Object` subtype declares its comparison mode once at registration; introduces field-level flags `kTVMFFIFieldFlagBitMaskSEqHashIgnore` / `kTVMFFIFieldFlagBitMaskSEqHashDef` to fine-tune per-field behaviour.
- Adds `AccessStep`/`AccessPath` types that record the mismatch location (field name, array index, map key) for rich error reporting via `StructuralEqual::GetFirstMismatch`.

## Key Exports

# ---- c_api.h additions ----

class TVMFFISEqHashKind(IntEnum):
    """Per-type comparison/hash strategy stored in TVMFFITypeExtraInfo."""
    kTVMFFISEqHashKindUnsupported   = 0  # pointer equality only (default for Object)
    kTVMFFISEqHashKindTreeNode      = 1  # recurse fields; ignore DAG sharing
    kTVMFFISEqHashKindFreeVar       = 2  # symbolic variable; map-or-pointer equality
    kTVMFFISEqHashKindDAGNode       = 3  # recurse fields; record mapping to detect sharing
    kTVMFFISEqHashKindConstTreeNode = 4  # tree node with no free-var children; pointer equality as fast path
    kTVMFFISEqHashKindUniqueInstance = 5 # singleton; always pointer equality
    # Invariant: stored in TVMFFITypeExtraInfo.structural_eq_hash_kind (new field)

class TVMFFITypeExtraInfo:          # CHANGED: total_size int64→int32, new field added
    total_size: int32_t             # changed from int64_t (ABI change in this commit)
    structural_eq_hash_kind: TVMFFISEqHashKind  # NEW
    creator: ...
    doc: TVMFFIByteArray

# NEW field flag bits (ORed into TVMFFIFieldInfo.flags):
# kTVMFFIFieldFlagBitMaskSEqHashIgnore = 1 << 3  — skip this field during s-eq/hash
# kTVMFFIFieldFlagBitMaskSEqHashDef    = 1 << 4  — this field enters free-var def region

# NEW macro/attribute:
#   TVM_FFI_EXTRA_CXX_API  — marks symbols implemented in .cc but exposed as DLL exports
#   (distinct from C ABI: input/output are Any/ObjectRef for ABI stability)

# ---- reflection/access_path.h ----

class AccessKind(IntEnum):
    kObjectField         = 0
    kArrayIndex          = 1
    kMapKey              = 2
    kArrayIndexMissing   = 3
    kMapKeyMissing       = 4

class AccessStepObj(Object):
    """One step in a path to a mismatching field/element."""
    kind: AccessKind
    key: Any   # str for ObjectField, int for ArrayIndex, Any for MapKey
    # Invariant: _type_s_eq_hash_kind = kTVMFFISEqHashKindConstTreeNode
    # (AccessStep itself is structurally comparable — used in test assertions)

AccessPath     = Array[AccessStep]
AccessPathPair = Tuple[AccessPath, AccessPath]  # (lhs_path, rhs_path)

# ---- reflection/structural_equal.h ----

class StructuralEqual:
    """Reflection-driven structural equality comparator."""
    @staticmethod
    def Equal(lhs: Any, rhs: Any,
              map_free_vars: bool = False,
              skip_ndarray_content: bool = False) -> bool: ...
    # Interacts with: TVMFFITypeInfo.extra_info.structural_eq_hash_kind (dispatch)
    # Interacts with: TVMFFIFieldInfo.flags (SEqHashIgnore / SEqHashDef)
    # Interacts with: StructEqualHandler.equal_map_lhs_ / equal_map_rhs_ (DAG+FreeVar)

    @staticmethod
    def GetFirstMismatch(lhs: Any, rhs: Any,
                         map_free_vars: bool = False,
                         skip_ndarray_content: bool = False
                         ) -> Optional[AccessPathPair]: ...
    # Returns None on equality, else (lhs_path, rhs_path) to first diverging element
    # Registered as global func: "ffi.reflection.GetFirstStructuralMismatch"

    def __call__(self, lhs: Any, rhs: Any) -> bool:
        return StructuralEqual.Equal(lhs, rhs, map_free_vars=False, skip_ndarray_content=True)
    # Extension: operator() defaults skip_ndarray_content=True (content ignored by default)

# ---- reflection/structural_hash.h ----

class StructuralHash:
    """Reflection-driven structural hash functor."""
    @staticmethod
    def Hash(value: Any,
             map_free_vars: bool = False,
             skip_ndarray_content: bool = False) -> int: ...  # uint64_t
    # Registered as global func: "ffi.reflection.StructuralHash"
    # Interacts with: StructuralHashHandler.hash_memo_ (memoisation for DAG/ConstTree)
    # Interacts with: StructuralHashHandler.free_var_counter_ (lexical order for FreeVar)

    def __call__(self, value: Any) -> int:
        return StructuralHash.Hash(value)

# ---- reflection/registry.h: AttachFieldFlag ----

class AttachFieldFlag(FieldInfoTrait):
    """Trait to OR a bit-mask flag into TVMFFIFieldInfo.flags at registration time."""
    @staticmethod
    def SEqHashDef()    -> AttachFieldFlag: ...   # sets kTVMFFIFieldFlagBitMaskSEqHashDef
    @staticmethod
    def SEqHashIgnore() -> AttachFieldFlag: ...   # sets kTVMFFIFieldFlagBitMaskSEqHashIgnore
    # Usage: ObjectDef<TFuncObj>().def_ro("params", &TFuncObj::params, AttachFieldFlag::SEqHashDef())

# Object base class (object.h): new static member on all Object subclasses:
# static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindUnsupported;
# Subclasses override to opt in: static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;

## Impact
- API: `TVMFFITypeExtraInfo.total_size` changed from `int64_t` to `int32_t` — binary ABI break for any code reading this struct by offset. `structural_eq_hash_kind` field is added after `total_size`.
- Behavioral: `ObjectDef<T>::RegisterExtraInfo` now writes `Class::_type_s_eq_hash_kind` into `TVMFFITypeExtraInfo`; all registered types without an explicit `_type_s_eq_hash_kind` override inherit `kTVMFFISEqHashKindUnsupported` from `Object`.
- Flags/config: Two new `TVMFFIFieldFlagBitMask` bits (bits 3 and 4) are defined; existing flags unaffected.
- Data formats/schemas: `Bytes::memncmp` moved from `private:` to `public:` (used by `StructEqualHandler::CompareAny` for string comparison). `FieldSetter` now has a branch for `T == Any` to avoid a `.cast<Any>()` round-trip.

## Usage Examples

**Defining a type that participates in structural eq/hash:**

```cpp
// In the object class header:
class TFuncObj : public Object {
 public:
  Array<TVar> params;
  Array<ObjectRef> body;
  String comment;

  static constexpr TVMFFISEqHashKind _type_s_eq_hash_kind = kTVMFFISEqHashKindTreeNode;
  static constexpr const char* _type_key = "test.Func";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TFuncObj, Object);

  static void RegisterReflection() {
    namespace refl = tvm::ffi::reflection;
    refl::ObjectDef<TFuncObj>()
        .def_ro("params", &TFuncObj::params, refl::AttachFieldFlag::SEqHashDef())
        // params are in "def region" — free vars inside are mapped here
        .def_ro("body", &TFuncObj::body)
        .def_ro("comment", &TFuncObj::comment, refl::AttachFieldFlag::SEqHashIgnore());
        // comment is ignored for structural comparison
  }
};

// Usage:
TVar x = TVar("x"), y = TVar("y");
TFunc fa = TFunc({x}, {TInt(1), x}, "comment a");
TFunc fb = TFunc({y}, {TInt(1), y}, "comment b");
assert(refl::StructuralEqual()(fa, fb));  // true — alpha-equivalent
assert(refl::StructuralHash()(fa) == refl::StructuralHash()(fb));
```

**Getting the first mismatch path:**

```cpp
Array<int> a = {1, 2, 3};
Array<int> d = {1, 2};
auto diff = refl::StructuralEqual::GetFirstMismatch(a, d);
// diff == Optional<AccessPathPair>({ [ArrayIndex(2)], [ArrayIndexMissing(2)] })
```
