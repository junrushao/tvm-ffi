# Add cause_chain and extra_context fields to Error for future cause chaining support
## TL;DR
- Appends two optional fields (`cause_chain`, `extra_context`) to `TVMFFIErrorCell`, enabling error cause chaining and opaque context attachment.
- Adds `TVMFFIErrorCreateWithCauseAndExtraContext` C API function for constructing errors with cause/context in a single call.
- Extends `Error` C++ ref class with a new constructor accepting `std::optional<Error>` and `std::optional<ObjectRef>`, plus accessor methods `cause_chain()` and `extra_context()`.

## Impact
- API: Additive -- two new fields appended to `TVMFFIErrorCell`, one new C API function, one new `Error` constructor overload, two new accessors. No changes to existing signatures.
- Behavioral: Existing error creation paths are unaffected; `ErrorObj()` default constructor initializes new fields to nullptr.
- Flags/config: none
- Data formats/schemas: `TVMFFIErrorCell` struct grows by 16 bytes (two pointer fields). Backward compatible since fields are appended at the end.

## Usage Examples
From `tests/cpp/test_error.cc`:
```cpp
// Construct an original error, then chain it as the cause of a new error
Error original_error("TypeError", "here", "test0");
Error cause_chain("ValueError", "cause", "test1", original_error, std::nullopt);

// Access the cause chain
auto opt_cause = cause_chain.cause_chain();
EXPECT_TRUE(opt_cause.has_value());
EXPECT_EQ(opt_cause->kind(), "TypeError");

// extra_context is not set
EXPECT_TRUE(!cause_chain.extra_context().has_value());
```
