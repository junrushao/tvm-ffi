# Extend Error ABI with cause_chain and extra_context fields for future error chaining
## TL;DR
- Adds `cause_chain` and `extra_context` fields to `TVMFFIErrorCell` in `c_api.h`, enabling future error chaining support.
- Adds `Error` constructor accepting `std::optional<Error> cause_chain` and `std::optional<ObjectRef> extra_context`.
- Adds C ABI function `TVMFFIErrorCreateWithCauseAndExtraContext`.
- Backward compatible: existing code ignores the new fields.
