# Extend Error ABI with cause_chain and extra_context fields for future error chaining
## TL;DR
- Extends `TVMFFIErrorCell` (C ABI struct in `c_api.h`) with two new optional fields: `cause_chain` and `extra_context`, both `TVMFFIObjectHandle`. Backward compatible (appended to end of struct).
- Adds `Error` constructor overload accepting `std::optional<Error> cause_chain` and `std::optional<ObjectRef> extra_context`, plus accessor methods `cause_chain()` and `extra_context()`.
- Adds C API function `TVMFFIErrorCreateWithCauseAndExtraContext` and `ErrorObj` constructor/destructor to manage lifetime of the new owned handles.

## Key Exports

**C ABI struct fields** added to `TVMFFIErrorCell` (in `include/tvm/ffi/c_api.h`):

| Field | Type | Notes |
|-------|------|-------|
| `cause_chain` | `TVMFFIObjectHandle` | Optional owned handle to a chained Error |
| `extra_context` | `TVMFFIObjectHandle` | Optional owned handle to arbitrary context object |

**C API function** (in `include/tvm/ffi/c_api.h`, impl in `src/ffi/error.cc`):

```c
int TVMFFIErrorCreateWithCauseAndExtraContext(
    const TVMFFIByteArray* kind, const TVMFFIByteArray* message,
    const TVMFFIByteArray* backtrace, TVMFFIObjectHandle cause_chain,
    TVMFFIObjectHandle extra_context, TVMFFIObjectHandle* out);
```

**C++ methods** added to `Error` (in `include/tvm/ffi/error.h`):

| Method | Signature | Notes |
|--------|-----------|-------|
| `Error(...)` | `Error(string kind, string message, string backtrace, optional<Error> cause_chain, optional<ObjectRef> extra_context)` | New constructor |
| `cause_chain()` | `std::optional<Error> cause_chain() const` | Returns chained cause error if present |
| `extra_context()` | `std::optional<ObjectRef> extra_context() const` | Returns extra context object if present |

**C++ lifecycle** added to `ErrorObj`:
- Default constructor initializes both new fields to `nullptr`.
- Destructor calls `DecRefObjectHandle` on non-null `cause_chain` and `extra_context`.

## Impact
- API: backward-compatible ABI extension (new fields appended to `TVMFFIErrorCell`); new C API function; new C++ constructor/accessors
- Behavioral: none for existing code (fields default to nullptr)
- Flags/config: none
- Data formats/schemas: `TVMFFIErrorCell` struct grows by 2 pointer-sized fields

## Usage Examples
```cpp
Error original("TypeError", "original message", "backtrace0");
Error chained("ValueError", "wrapping error", "backtrace1",
              /*cause_chain=*/original, /*extra_context=*/std::nullopt);

auto cause = chained.cause_chain();
assert(cause.has_value());
assert(cause->kind() == "TypeError");
assert(!chained.extra_context().has_value());
```
