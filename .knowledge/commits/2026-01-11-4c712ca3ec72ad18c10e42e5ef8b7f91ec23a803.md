# Add cause_chain and extra_context fields to ErrorObj for future error chaining
## TL;DR
- Adds `cause_chain` and `extra_context` fields to `TVMFFIErrorCell` C ABI struct, enabling future error cause chaining
- Adds `TVMFFIErrorCreateWithCauseAndExtraContext` C API function
- Extends `Error` C++ class with a new constructor accepting `std::optional<Error>` cause and `std::optional<ObjectRef>` extra context
- Adds `cause_chain()` and `extra_context()` accessor methods on `Error`

## Key Exports
```python
class ErrorObj(Object):
    # New fields (C ABI layout extension):
    cause_chain: Optional[Object]       # owned handle, nullable
    extra_context: Optional[ObjectRef]   # owned handle, nullable
    # Invariant: both handles are DecRef'd in ~ErrorObj()

class Error(ObjectRef):
    def __init__(self, kind: str, message: str, backtrace: str,
                 cause_chain: Optional["Error"] = None,
                 extra_context: Optional[ObjectRef] = None) -> None: ...
    def cause_chain(self) -> Optional["Error"]: ...
    # Interacts with: ErrorObj.cause_chain handle
    def extra_context(self) -> Optional[ObjectRef]: ...
    # Interacts with: ErrorObj.extra_context handle

# New C API:
# int TVMFFIErrorCreateWithCauseAndExtraContext(
#     kind, message, backtrace, cause_chain, extra_context, out) -> 0 on success
# Interacts with: TVMFFIErrorCreate, ErrorObj ownership protocol
```

## Impact
- API: extends `TVMFFIErrorCell` struct layout (ABI change — two new pointer fields at end)
- Behavioral: none — fields default to nullptr
- Flags/config: none
- Data formats/schemas: `TVMFFIErrorCell` struct gains two pointer fields

## Usage Examples
```cpp
Error inner("ValueError", "division by zero", "");
Error outer("RuntimeError", "computation failed", "",
            /*cause_chain=*/inner, /*extra_context=*/std::nullopt);
assert(outer.cause_chain().has_value());
assert(outer.cause_chain().value().kind() == "ValueError");
```
