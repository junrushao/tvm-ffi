# Replace three separate DLPack C function pointers with unified DLPackExchangeAPI struct

## TL;DR
- Introduces `DLPackExchangeAPI` struct (from DLPack proposal #175) that bundles five C function pointers (`managed_tensor_allocator`, `managed_tensor_from_py_object_no_sync`, `managed_tensor_to_py_object_no_sync`, `dltensor_from_py_object_no_sync`, `current_work_stream`) replacing the previous triple of separate pointers (`DLPackFromPyObject`, `DLPackToPyObject`, `DLPackTensorAllocator`).
- All `_from_pyobject` conversions are now "no-sync" — stream synchronization is explicit via `current_work_stream` instead of being baked into the import call; stream detection is moved to a separate step after conversion.
- The Python class attribute for tensor framework registration changes from three separate integer attributes (`__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, `__c_dlpack_tensor_allocator__`) to one struct pointer attribute checked on the **class** (`__c_dlpack_exchange_api__`).

## Impact
- API: Breaking change for third-party code that registers `__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, or `__c_dlpack_tensor_allocator__` on a custom tensor type. Must migrate to `__c_dlpack_exchange_api__` (a pointer to a `DLPackExchangeAPI` struct). The attribute is now read from the **class** (`type(arg)`), not the instance.
- Behavioral: Stream detection is now deferred: `managed_tensor_from_py_object_no_sync` does not query the stream; a separate call to `current_work_stream` follows only if the tensor is on a non-CPU device and `ctx.device_type == -1`. Previous behavior queried stream inside `DLPackFromPyObject` with an optional out-param.
- Flags/config: `TVM_FFI_SKIP_c_dlpack_from_pyobject` env variable guard is retained (now gates `__c_dlpack_exchange_api__` detection).
- Data formats/schemas: `DLPackExchangeAPI` struct layout is governed by the DLPack standard (proposal #175); `DLPackExchangeAPIHeader.version` must be set to `DLPACK_MAJOR/MINOR_VERSION` at construction.

## Design Elements
Design elements this commit consumes:
- `0016-py-ffi-call-dispatch` — `TVMFFIPyCallContext`, `TVMFFIPyArgSetter`, `TVMFFIPyArgSetterFactory_`, `TVMFFIPyFuncCall`, `_optional_torch_c_dlpack`
- `0012-env-api` — `TVMFFIEnvSetTensorAllocator` / `DLPackTensorAllocator` (allocator is now accessed via `DLPackExchangeAPI.managed_tensor_allocator`)
- `0007-containers` — `Tensor`, `DLManagedTensorVersioned`, `TVMFFITensorToDLPackVersioned`

Design elements this commit produces:
- `DLPackExchangeAPI` struct — a new versioned protocol struct for bundling all DLPack exchange operations. Replaces `DLPackFromPyObject` + `DLPackToPyObject` + `DLPackTensorAllocator` as the registration surface.
- `__c_dlpack_exchange_api__` class attribute convention — new protocol for tensor framework types. Checked on `type(arg)`, not instance.
- `current_work_stream` function pointer — extracted stream query capability, decoupled from tensor conversion.
- `dltensor_from_py_object_no_sync` function pointer — non-owning DLTensor view, new capability with no prior equivalent.

## Usage Examples

**Registering a custom tensor type with the new protocol (C++ + Python):**

```python
# Step 1: Define a C++ struct inheriting DLPackExchangeAPI (or initializing it directly)
# (C++, in the extension module):
#
# struct MyFrameworkExchangeAPI : public DLPackExchangeAPI {
#     MyFrameworkExchangeAPI() {
#         header.version.major = DLPACK_MAJOR_VERSION;
#         header.version.minor = DLPACK_MINOR_VERSION;
#         header.prev_api = nullptr;
#         managed_tensor_from_py_object_no_sync = MyFromPyObject;  // no stream side-effect
#         managed_tensor_to_py_object_no_sync   = MyToPyObject;
#         managed_tensor_allocator              = MyAllocator;
#         current_work_stream                   = MyGetStream;    // explicit stream query
#         dltensor_from_py_object_no_sync       = nullptr;       // optional
#     }
#     static const DLPackExchangeAPI* Global() {
#         static MyFrameworkExchangeAPI inst;
#         return &inst;
#     }
# };
# int64_t MyExchangeAPIPtr() { return (int64_t)MyFrameworkExchangeAPI::Global(); }

# Step 2: Register on Python class (once at startup)
setattr(MyTensor, "__c_dlpack_exchange_api__", mod.MyExchangeAPIPtr())

# Step 3: Use — TVMFFIPyArgSetterFactory detects the attribute on the class automatically
import tvm_ffi
fn = tvm_ffi.get_global_func("my.kernel")
fn(MyTensor(...))  # dispatches via MyFrameworkExchangeAPI, no Python-level __dlpack__
```

**Before/after for the stream query change:**

```python
# BEFORE (DLPackFromPyObject with env_stream* out-param):
# typedef int (*DLPackFromPyObject)(void* py_obj, DLManagedTensorVersioned** out, void** env_stream)
# — stream was queried inside the conversion call; caller passed &env_stream to receive it.

# AFTER (no-sync + explicit current_work_stream):
# api.managed_tensor_from_py_object_no_sync(arg, &temp_managed_tensor)  # pure conversion
# if not CPU and first device seen:
#     api.current_work_stream(dev_type, dev_id, &current_stream)          # explicit stream query
```
