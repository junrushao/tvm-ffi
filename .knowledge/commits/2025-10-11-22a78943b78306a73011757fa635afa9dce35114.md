# Introduce DLPackExchangeAPI struct to unify DLPack speed-exchange function pointers

## TL;DR
- Replaces three separate DLPack function pointers (`__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, `__c_dlpack_tensor_allocator__`) with a single `DLPackExchangeAPI` struct exposed via `__c_dlpack_exchange_api__`, per DLPack proposal #175.
- Adds `current_work_stream` function pointer to the exchange API for explicit stream querying, and a non-owning `DLTensor` conversion path (`dltensor_from_py_object_no_sync`) that avoids refcount overhead.
- All conversions are renamed to `_no_sync` variants, decoupling stream synchronization from tensor export/import.

## Key Exports

**Struct: `DLPackExchangeAPI`** (declared in `dlpack/dlpack.h`, Cython binding in `base.pxi`):
```c
typedef struct {
    DLPackExchangeAPIHeader header;              // {version, prev_api}
    DLPackManagedTensorAllocator managed_tensor_allocator;
    DLPackManagedTensorFromPyObjectNoSync managed_tensor_from_py_object_no_sync;
    DLPackManagedTensorToPyObjectNoSync managed_tensor_to_py_object_no_sync;
    DLPackDLTensorFromPyObjectNoSync dltensor_from_py_object_no_sync;
    DLPackCurrentWorkStream current_work_stream;
} DLPackExchangeAPI;
```

**Function pointer typedefs** (Cython `base.pxi`):
- `DLPackManagedTensorAllocator(DLTensor*, DLManagedTensorVersioned**, void*, SetError) -> int`
- `DLPackManagedTensorFromPyObjectNoSync(void* py_object, DLManagedTensorVersioned**) -> int`
- `DLPackManagedTensorToPyObjectNoSync(DLManagedTensorVersioned*, void** out) -> int`
- `DLPackDLTensorFromPyObjectNoSync(void* py_object, DLTensor* out) -> int`

## Impact
- API: **Breaking** -- `torch.Tensor.__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, `__c_dlpack_tensor_allocator__` are removed. Replaced by single `__c_dlpack_exchange_api__`. Any external framework addon using the old three-attribute protocol must migrate to populate a `DLPackExchangeAPI` struct instead.
- Behavioral: Stream synchronization is no longer embedded in the `from_pyobject` call. Callers now use the separate `current_work_stream` callback, queried by the Cython arg setter after tensor conversion.
- Flags/config: `TVM_FFI_SKIP_c_dlpack_from_pyobject` env var still works but the attribute it checks is now `__c_dlpack_exchange_api__` on the class (not instance).
- Data formats/schemas: DLPack submodule updated from `addbc8b` to `1117366` (incorporates `DLPackExchangeAPI` struct definition).

Design elements this commit produces:
- **`DLPackExchangeAPI` struct protocol** -- a unified struct bundling 5 function pointers for DLPack tensor exchange. This replaces the ad-hoc "attach N function pointers as class attributes" pattern with a single versioned struct pointer. The struct includes `header.prev_api` for future ABI evolution (linked-list of API versions).
- **Non-owning DLTensor path** (`dltensor_from_py_object_no_sync`) -- a new zero-copy, zero-refcount conversion from PyObject to `DLTensor*` that fills a caller-owned struct. Enables read-only tensor metadata inspection without ownership transfer.
- **`current_work_stream` callback** -- decouples stream querying from tensor export, allowing the Cython arg setter to query the stream independently after conversion.

## Usage Examples

**Implementing DLPackExchangeAPI for a custom framework** (pattern from the torch implementation):
```c++
// 1. Implement the individual function signatures
int MyFrameworkManagedTensorFromPyObjectNoSync(void* py_obj, DLManagedTensorVersioned** out) { ... }
int MyFrameworkManagedTensorToPyObjectNoSync(DLManagedTensorVersioned* src, void** py_obj_out) { ... }
int MyFrameworkCurrentWorkStream(DLDeviceType dev, int32_t id, void** out) { ... }

// 2. Bundle into a singleton struct
struct MyExchangeAPI : public DLPackExchangeAPI {
  MyExchangeAPI() {
    header.version = {DLPACK_MAJOR_VERSION, DLPACK_MINOR_VERSION};
    header.prev_api = nullptr;
    managed_tensor_from_py_object_no_sync = MyFrameworkManagedTensorFromPyObjectNoSync;
    managed_tensor_to_py_object_no_sync = MyFrameworkManagedTensorToPyObjectNoSync;
    current_work_stream = MyFrameworkCurrentWorkStream;
    // optional: managed_tensor_allocator, dltensor_from_py_object_no_sync
  }
  static const DLPackExchangeAPI* Global() { static MyExchangeAPI inst; return &inst; }
};

// 3. Expose pointer and register on the Python class
int64_t MyExchangeAPIPtr() { return reinterpret_cast<int64_t>(MyExchangeAPI::Global()); }
// Python: setattr(MyTensor, "__c_dlpack_exchange_api__", mod.MyExchangeAPIPtr())
```
