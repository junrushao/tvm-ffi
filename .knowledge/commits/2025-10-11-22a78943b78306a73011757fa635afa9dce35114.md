# Unify DLPack exchange into struct-based DLPackExchangeAPI with stream and non-owning tensor support
## TL;DR
- Replaces the three separate DLPack function-pointer dunder attributes (`__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, `__c_dlpack_tensor_allocator__`) with a single `DLPackExchangeAPI` struct exposed via `__c_dlpack_exchange_api__`.
- Adds `current_work_stream` and `dltensor_from_py_object_no_sync` function pointers to the new struct, enabling explicit stream querying and non-owning DLTensor conversion.
- All DLPack from/to conversions renamed to `*_no_sync` variants, separating stream synchronization from tensor exchange.

| Old (removed) | New (replacement) |
|---|---|
| `torch.Tensor.__c_dlpack_from_pyobject__` | `torch.Tensor.__c_dlpack_exchange_api__` |
| `torch.Tensor.__c_dlpack_to_pyobject__` | (bundled in `DLPackExchangeAPI.managed_tensor_to_py_object_no_sync`) |
| `torch.Tensor.__c_dlpack_tensor_allocator__` | (bundled in `DLPackExchangeAPI.managed_tensor_allocator`) |
| `DLPackFromPyObject` (typedef) | `DLPackManagedTensorFromPyObjectNoSync` (typedef in struct) |
| `DLPackToPyObject` (typedef) | `DLPackManagedTensorToPyObjectNoSync` (typedef in struct) |
| `TVMFFIPyArgSetter.c_dlpack_from_pyobject` | `TVMFFIPyArgSetter.c_dlpack_exchange_api` |
| `TVMFFIPyArgSetter.c_dlpack_to_pyobject` | (via struct) |
| `TVMFFIPyArgSetter.c_dlpack_tensor_allocator` | (via struct) |
| `TVMFFIPyCallContext.c_dlpack_to_pyobject` | `TVMFFIPyCallContext.c_dlpack_exchange_api` |
| `TVMFFIPyCallContext.c_dlpack_tensor_allocator` | (via struct) |
| `TorchDLPackFromPyObject` (C++ fn) | `TorchDLPackManagedTensorFromPyObjectNoSync` |
| `TorchDLPackToPyObject` (C++ fn) | `TorchDLPackManagedTensorToPyObjectNoSync` |
| `TorchDLPackTensorAllocator` (C++ fn) | `TorchDLPackManagedTensorAllocator` |
| N/A | `TorchDLPackCurrentWorkStream` (new) |
| N/A | `TorchDLPackDLTensorFromPyObjectNoSync` (new) |
| N/A | `toDLPackNonOwningImpl` (new) |

## Impact
- API: **Breaking** — Removes dunder attributes `__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, `__c_dlpack_tensor_allocator__` from `torch.Tensor`. Replaces with single `__c_dlpack_exchange_api__`. External code checking for or setting these attributes must update. `DLTensorTestWrapper.__c_dlpack_from_pyobject__` also replaced. The env var `TVM_FFI_SKIP_c_dlpack_from_pyobject` still works (factory check path unchanged).
- Behavioral: Stream querying is now decoupled from tensor conversion. Previously `TorchDLPackFromPyObject` accepted an `env_stream` out-param and combined conversion with stream capture. Now `current_work_stream` is called separately after conversion, only on first non-CPU device encounter. All conversions are `_no_sync` — the consumer must handle synchronization explicitly.
- Flags/config: None
- Data formats/schemas: Aligns with DLPack proposal #175. Updates `3rdparty/dlpack` submodule.

Design elements this commit consumes:

- Tensor DLPack conversion (`TVMFFITensorFromDLPackVersioned`, `TVMFFITensorToDLPackVersioned`) — `.knowledge/design-records/0006-containers.md`

Design elements this commit produces:
- **`DLPackExchangeAPI` struct** — New unified struct bundling 5 function pointers for DLPack exchange (allocator, from/to PyObject, non-owning DLTensor, stream query). Versioned via header with `prev_api` linked-list chain.
- **`__c_dlpack_exchange_api__` dunder protocol** — Single class-level attribute (checked on type, not instance) replacing 3 separate instance-level dunder attributes.
- **`current_work_stream` function pointer** — Explicit stream query decoupled from tensor conversion.
- **`dltensor_from_py_object_no_sync` function pointer** — Non-owning DLTensor conversion avoiding unnecessary reference counting.
- **`toDLPackNonOwningImpl`** (C++) — Fills a pre-allocated `DLTensor` with direct pointers to torch tensor storage.
- **`TorchDLPackExchangeAPI` singleton** — Concrete implementation for PyTorch, exposed via `TorchDLPackExchangeAPIPtr()`.
- **Torch fallback exchange API** (`GetTorchFallbackExchangeAPI()`) — Cython-level fallback with only `managed_tensor_to_py_object_no_sync` populated.

## Usage Examples

Implementing `DLPackExchangeAPI` for a custom tensor type:

```python
# C++ side (in a JIT-compiled extension or shared library):
# 1. Define the C-ABI functions
# int MyFromPyObjectNoSync(void* py_obj, DLManagedTensorVersioned** out) { ... }
# int MyToPyObjectNoSync(DLManagedTensorVersioned* src, void** py_obj_out) { ... }
# int MyCurrentWorkStream(int device_type, int32_t device_id, void** out_stream) { ... }
#
# 2. Create a static DLPackExchangeAPI instance
# struct MyExchangeAPI : public DLPackExchangeAPI {
#     MyExchangeAPI() {
#         header.version.major = DLPACK_MAJOR_VERSION;
#         header.version.minor = DLPACK_MINOR_VERSION;
#         header.prev_api = nullptr;
#         managed_tensor_from_py_object_no_sync = MyFromPyObjectNoSync;
#         managed_tensor_to_py_object_no_sync = MyToPyObjectNoSync;
#         current_work_stream = MyCurrentWorkStream;
#         managed_tensor_allocator = nullptr;  # optional
#         dltensor_from_py_object_no_sync = nullptr;  # optional
#     }
#     static const DLPackExchangeAPI* Global() { static MyExchangeAPI inst; return &inst; }
# };
#
# 3. Python side: set class attribute with integer pointer
# MyTensor.__c_dlpack_exchange_api__ = get_api_ptr()  # int64 pointer
#
# The Cython arg-setter factory detects __c_dlpack_exchange_api__ on the CLASS
# and routes through TVMFFIPyArgSetterDLPackExchangeAPI_ for fast conversion.
```
