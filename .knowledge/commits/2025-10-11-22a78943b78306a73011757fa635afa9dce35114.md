# Replace separate DLPack function-pointer dunders with unified DLPackExchangeAPI struct
## TL;DR
- Replaces three separate class-attribute function pointers (`__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, `__c_dlpack_tensor_allocator__`) with a single `__c_dlpack_exchange_api__` attribute pointing to a `DLPackExchangeAPI` struct, aligning with DLPack proposal #175.
- All conversions renamed to `_no_sync` variants; stream querying is moved out of the per-tensor export function into a dedicated `current_work_stream` function pointer on the struct.
- Adds a non-owning `DLTensor` conversion path (`dltensor_from_py_object_no_sync`) that avoids `DLManagedTensorVersioned` overhead and reference counting for read-only access.

## Impact
- API: **Breaking** -- `__c_dlpack_from_pyobject__`, `__c_dlpack_to_pyobject__`, `__c_dlpack_tensor_allocator__` class attributes replaced by `__c_dlpack_exchange_api__`. Any third-party framework implementing the old per-function-pointer protocol must migrate to the struct-based API.
- Behavioral: Stream querying is now separated from tensor export. The `_no_sync` naming makes explicit that callers must handle stream synchronization via `current_work_stream` rather than relying on the export function to capture it.
- Flags/config: `TVM_FFI_SKIP_c_dlpack_from_pyobject` env var still gates the fast-path detection (unchanged).
- Data formats/schemas: DLPack submodule updated; `DLPackExchangeAPI` struct added to dlpack.h.

## Usage Examples

### Framework implementing the exchange API (torch)
**Context**: The JIT-compiled torch addon now populates a single struct instead of three separate function pointers.

```python
# In _optional_torch_c_dlpack.py, the inline C++ source defines:
#   struct TorchDLPackExchangeAPI : public DLPackExchangeAPI { ... };
# After JIT compilation, a single pointer is set on the class:
setattr(torch.Tensor, "__c_dlpack_exchange_api__", mod.TorchDLPackExchangeAPIPtr())

# The Cython arg setter detects this on type(arg):
#   arg_class = type(arg)
#   if hasattr(arg_class, "__c_dlpack_exchange_api__"):
#       api = <const DLPackExchangeAPI*>arg_class.__c_dlpack_exchange_api__
#       api.managed_tensor_from_py_object_no_sync(arg, &out)  # convert tensor
#       api.current_work_stream(device_type, device_id, &stream)  # query stream
```
