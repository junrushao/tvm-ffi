# Refactor TVM_FFI_STATIC_INIT_BLOCK from lambda-body macro to function-style macro

## TL;DR
- Rewrites `TVM_FFI_STATIC_INIT_BLOCK` from a `(Body)` argument style (lambda-initialized static variable) to a `()` function-style macro (GCC/Clang: `__attribute__((constructor))`; MSVC fallback: static variable invoking a named function).
- Removes `TVM_FFI_ATTRIBUTE_UNUSED` macro and `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` helper macro from `base_details.h`.
- Updates all 18 call sites across `src/`, `tests/`, `docs/`, and `examples/` from `TVM_FFI_STATIC_INIT_BLOCK({ ... });` to `TVM_FFI_STATIC_INIT_BLOCK() { ... }`.

## Key Exports

**Macros:**

- `TVM_FFI_STATIC_INIT_BLOCK()` -- New signature (no arguments). On GCC/Clang, expands to `__attribute__((constructor)) static void __TVMFFIStaticInitFunc<N>()` where `<N>` is `__COUNTER__`. On other compilers, expands to a static function declaration + static variable that calls it at init time.

**Removed macros:**

- `TVM_FFI_ATTRIBUTE_UNUSED` -- Previously `[[maybe_unused]]`. Removed entirely; `[[maybe_unused]]` is now inlined directly in the non-GCC fallback branch of `TVM_FFI_STATIC_INIT_BLOCK`.
- `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` -- Previously the per-variable definition helper. Replaced by the new two-branch implementation.

## Impact
- API: Non-breaking for external consumers. The macro name is unchanged but the invocation syntax changes: `TVM_FFI_STATIC_INIT_BLOCK({ body });` becomes `TVM_FFI_STATIC_INIT_BLOCK() { body }`. Any downstream code using the old `(Body)` syntax will fail to compile.
- ABI: None. The generated symbols are internal static functions/variables; no exported symbol changes.
- Behavioral: On GCC/Clang, static init blocks now use `__attribute__((constructor))` instead of static-variable-with-lambda initialization. Constructor functions run before `main()` with well-defined ordering guarantees within a translation unit, and the compiler can emit better error diagnostics (function name in backtraces vs. anonymous lambda).
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **`TVM_FFI_STATIC_INIT_BLOCK`** (`.knowledge/designs/reflection.md`) -- The universal static initialization macro used throughout the codebase for reflection registration (`ObjectDef<T>`, `GlobalDef().def(...)`) and function table population.
- **`__COUNTER__` / `TVM_FFI_STR_CONCAT`** (`.knowledge/designs/c-abi.md`) -- Token-pasting helpers for unique symbol generation in macros.

Design elements this commit produces:
- **Function-style `TVM_FFI_STATIC_INIT_BLOCK()` with platform branching** -- A new two-implementation pattern: `__attribute__((constructor))` on GCC/Clang for true constructor functions, and a static-variable-invoking-function fallback on other compilers (MSVC). This replaces the single lambda-body-in-static-variable implementation.

Design elements this commit removes:
- **`TVM_FFI_ATTRIBUTE_UNUSED`** -- Macro removed from `base_details.h`. Was used only inside `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF`.
- **`TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF`** -- Internal helper macro removed.

## Usage Examples

Before (old syntax):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("my_func", MyFunc);
});
```

After (new syntax):
```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("my_func", MyFunc);
}
```

The new syntax reads like a regular function definition. The `()` expands to either a constructor-attributed function declaration (GCC/Clang) or a function + static-variable pair (other compilers), and the user-written `{ ... }` becomes the function body.
