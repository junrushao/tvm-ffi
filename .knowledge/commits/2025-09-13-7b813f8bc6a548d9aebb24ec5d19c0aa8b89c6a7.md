# Refactor TVM_FFI_STATIC_INIT_BLOCK from expression-body to function-body style

## TL;DR
- Changes `TVM_FFI_STATIC_INIT_BLOCK` macro from expression-body syntax `TVM_FFI_STATIC_INIT_BLOCK({...});` to function-body syntax `TVM_FFI_STATIC_INIT_BLOCK() {...}`, improving readability and error reporting (compiler diagnostics now point to the right line).
- On GCC/Clang, the new implementation uses `__attribute__((constructor))` for direct static initialization; on other compilers, falls back to a static variable + lambda trick similar to the old approach.
- Removes the `TVM_FFI_ATTRIBUTE_UNUSED` macro (inlined as `[[maybe_unused]]` in the non-GCC fallback path) and `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF`.

### Syntax mapping

| Before | After |
|---|---|
| `TVM_FFI_STATIC_INIT_BLOCK({ Body });` | `TVM_FFI_STATIC_INIT_BLOCK() { Body }` |
| `TVM_FFI_ATTRIBUTE_UNUSED` | removed (was `[[maybe_unused]]`) |
| `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` | removed (internal detail absorbed into new macro) |

## Key Exports

```python
# Macro expansion (pseudocode for TVM_FFI_STATIC_INIT_BLOCK()):
#
# On GCC/Clang (__GNUC__ defined):
#   __attribute__((constructor))
#   static void __TVMFFIStaticInitFunc<N>() { ... }
#   # Interacts with: dynamic linker (constructor attribute), __COUNTER__ for unique names
#   # Invariant: body runs once at load time, before main() or dlopen returns
#   # Extension: general-purpose static init, not reflection-specific
#
# On other compilers (MSVC, etc.):
#   static void __TVMFFIStaticInitFunc<N>();
#   [[maybe_unused]] static inline int __TVMFFIStaticInitReg<N> = []() {
#       __TVMFFIStaticInitFunc<N>();
#       return 0;
#   }();
#   static void __TVMFFIStaticInitFunc<N>() { ... }
#   # Same semantics, uses static-variable-init trick as fallback
```

## Impact
- API: Macro calling convention changes from `TVM_FFI_STATIC_INIT_BLOCK({Body})` to `TVM_FFI_STATIC_INIT_BLOCK() {Body}`. All downstream users of this macro must update call sites. `TVM_FFI_ATTRIBUTE_UNUSED` is removed.
- Behavioral: None -- runtime behavior is identical (static init at load time).
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Reflection / static init registration** (`.knowledge/designs/0008-reflection.md`) -- `TVM_FFI_STATIC_INIT_BLOCK` is the standard mechanism for calling `ObjectDef<T>` and `GlobalDef` at static init time.
- **`__COUNTER__` / `TVM_FFI_STR_CONCAT`** -- token-pasting utilities for generating unique symbol names.

Design elements this commit produces:
- **`TVM_FFI_STATIC_INIT_BLOCK()` (new calling convention)** -- the macro now takes no arguments; the body is a trailing brace-delimited block. This is a contract change (mutator) to an existing design element.
- **Platform-split implementation** -- GCC/Clang path uses `__attribute__((constructor))` (direct, no variable), non-GCC path uses the static-variable + lambda fallback. This is a new internal design detail.

Design elements removed:
- `TVM_FFI_ATTRIBUTE_UNUSED` macro -- was `[[maybe_unused]]`, now inlined directly where needed.
- `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` -- internal helper, absorbed into the non-GCC fallback path.

## Usage Examples

Before (old syntax):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("my_func", MyFunc);
});
```

After (new syntax):
```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("my_func", MyFunc);
}
```
