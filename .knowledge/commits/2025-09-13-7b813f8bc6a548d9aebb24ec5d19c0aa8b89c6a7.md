# Refactor TVM_FFI_STATIC_INIT_BLOCK from lambda-body macro to function-style macro

## TL;DR
- Changes `TVM_FFI_STATIC_INIT_BLOCK({...});` (body-as-macro-argument) to `TVM_FFI_STATIC_INIT_BLOCK() {...}` (function-style block), improving error reporting and debuggability.
- On GCC/Clang, now uses `__attribute__((constructor))` for a real constructor function. On other compilers, uses a named-function + variable-init trick.
- Removes `TVM_FFI_ATTRIBUTE_UNUSED` and `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` helper macros (no longer needed).

Before/after syntax at call sites:
| Before | After |
|---|---|
| `TVM_FFI_STATIC_INIT_BLOCK({ ... });` | `TVM_FFI_STATIC_INIT_BLOCK() { ... }` |

## Key Exports

```python
# Macro: TVM_FFI_STATIC_INIT_BLOCK() (C++ preprocessor macro)
# Purpose: Define a block executed at static initialization time.
# Interacts with: refl::GlobalDef, refl::ObjectDef<T> (used inside the block body)
# Interacts with: __COUNTER__ (generates unique symbol names per TU)
# Invariant: Each expansion produces a unique function name via __COUNTER__.
# Extension: Use this macro in any .cc file to register FFI functions/types at load time.

# GCC/Clang expansion (pseudocode):
# __attribute__((constructor)) static void __TVMFFIStaticInitFunc<N>() { <body> }

# MSVC/other expansion (pseudocode):
# static void __TVMFFIStaticInitFunc<N>();
# [[maybe_unused]] static inline int __TVMFFIStaticInitReg<N> = []() {
#     __TVMFFIStaticInitFunc<N>();
#     return 0;
# }();
# static void __TVMFFIStaticInitFunc<N>() { <body> }

# Removed macros:
# TVM_FFI_ATTRIBUTE_UNUSED  -- was [[maybe_unused]], only used by old STATIC_INIT_BLOCK
# TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF -- old variable-definition helper
```

## Impact
- API: The macro signature changed from `TVM_FFI_STATIC_INIT_BLOCK(Body)` to `TVM_FFI_STATIC_INIT_BLOCK()`. All downstream users must update call sites. This is a source-breaking change for any out-of-tree code using the old syntax.
- Behavioral: On GCC/Clang, static init blocks now execute as `__attribute__((constructor))` functions rather than as side effects of static variable initialization. This provides better stack traces and error reporting locality.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_STR_CONCAT` / `__COUNTER__` macro machinery (`include/tvm/ffi/base_details.h`) for unique symbol generation.
- `refl::GlobalDef` and `refl::ObjectDef<T>` builder APIs (see `0007-ffi-reflection`, `0004-ffi-function-system`) -- used inside every static init block body.

Design elements this commit produces:
- **Mutates** `TVM_FFI_STATIC_INIT_BLOCK`: changed from lambda-body-argument pattern to function-style block pattern, with compiler-specific implementation branches (GCC/Clang vs others).
- **Removes** `TVM_FFI_ATTRIBUTE_UNUSED` macro.
- **Removes** `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` macro.

## Usage Examples

Before (old syntax):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("my_func", MyFunc);
});
```

After (new syntax):
```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("my_func", MyFunc);
}
```
