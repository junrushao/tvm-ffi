# Refactor TVM_FFI_STATIC_INIT_BLOCK from lambda-body to function-definition style

## TL;DR
- Changes `TVM_FFI_STATIC_INIT_BLOCK` macro syntax from `TVM_FFI_STATIC_INIT_BLOCK({ body });` (lambda-body) to `TVM_FFI_STATIC_INIT_BLOCK() { body }` (function-definition style).
- On GCC/Clang, now uses `__attribute__((constructor))` for cleaner static init; on other compilers, falls back to a static-variable-invoking-function pattern.
- Removes the now-unused `TVM_FFI_ATTRIBUTE_UNUSED` macro and `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` internal helper.

## Key Exports

```python
# Macro: TVM_FFI_STATIC_INIT_BLOCK() (defined in include/tvm/ffi/base_details.h)
#
# OLD syntax:
#   TVM_FFI_STATIC_INIT_BLOCK({
#     RegisterStuff();
#   });
#
# NEW syntax:
#   TVM_FFI_STATIC_INIT_BLOCK() {
#     RegisterStuff();
#   }
#
# GCC/Clang path: expands to __attribute__((constructor)) static void __TVMFFIStaticInitFunc<N>()
# Non-GCC path: expands to a forward-declared static function + a [[maybe_unused]] static inline
#   int variable that calls it via a lambda IIFE.
#
# Interacts with: reflection::ObjectDef<T>, reflection::GlobalDef, all registration callsites
# Invariant: body executes exactly once at static init time before main()
# Extension: wrap any registration code in this macro; __COUNTER__ ensures unique symbol names

# REMOVED:
# TVM_FFI_ATTRIBUTE_UNUSED  (was [[maybe_unused]], inlined into non-GCC fallback)
# TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF  (internal helper, replaced by new two-path impl)
```

## Impact
- API: Breaking change to macro calling convention. All callsites using `TVM_FFI_STATIC_INIT_BLOCK({ ... });` must change to `TVM_FFI_STATIC_INIT_BLOCK() { ... }`. The 17 callsite files in this commit cover all in-tree usages.
- Behavioral: On GCC/Clang, static init now uses constructor attribute instead of static variable initialization. This can produce better error backtraces (named function instead of lambda) and avoids static initialization order fiasco edge cases on some platforms.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `reflection::ObjectDef<T>` and `reflection::GlobalDef` — all callsites wrap these builder calls (design record `0008-reflection`)
- `TVM_FFI_STR_CONCAT` / `__COUNTER__` — used to generate unique symbol names (design record `0007-c-abi`)

Design elements this commit produces:
- `TVM_FFI_STATIC_INIT_BLOCK()` — new function-definition-style macro replacing the lambda-body variant. Two-path implementation: `__attribute__((constructor))` on GCC/Clang, static-variable-trick on MSVC and others.

## Usage Examples

Before (old syntax):
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("my_func", MyFunc);
});
```

After (new syntax):
```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef().def("my_func", MyFunc);
}
```
