# Refactor TVM_FFI_STATIC_INIT_BLOCK from lambda-body style to function-definition style

## TL;DR
- Rewrites the `TVM_FFI_STATIC_INIT_BLOCK` macro from a lambda-body syntax (`TVM_FFI_STATIC_INIT_BLOCK({ ... });`) to a function-definition syntax (`TVM_FFI_STATIC_INIT_BLOCK() { ... }`), improving readability and error reporting.
- On GCC/Clang, the new macro emits an `__attribute__((constructor))` function; on other compilers (MSVC), it falls back to a static-variable-triggers-function pattern.
- Removes the `TVM_FFI_ATTRIBUTE_UNUSED` macro (previously `[[maybe_unused]]`) since the new implementation no longer needs it.
- Updates all 16 call sites across `src/`, `tests/`, `examples/`, and `docs/` to the new syntax.

## Key Exports

**Macros (mutated)**:

| Macro | Old Expansion | New Expansion (GCC/Clang) | New Expansion (MSVC/other) |
|-------|--------------|--------------------------|---------------------------|
| `TVM_FFI_STATIC_INIT_BLOCK()` | `[[maybe_unused]] static inline int __TVMFFIStaticInitReg<N> = []() { Body return 0; }()` | `__attribute__((constructor)) static void __TVMFFIStaticInitFunc<N>()` | `static void FnName(); [[maybe_unused]] static inline int RegVar = []() { FnName(); return 0; }(); static void FnName()` |

**Macros (removed)**:

| Macro | Was | Note |
|-------|-----|------|
| `TVM_FFI_ATTRIBUTE_UNUSED` | `[[maybe_unused]]` | No longer needed; `[[maybe_unused]]` is inlined where required in the MSVC fallback path |
| `TVM_FFI_STATIC_INIT_BLOCK_VAR_DEF` | `TVM_FFI_ATTRIBUTE_UNUSED static inline int __TVMFFIStaticInitReg` | Replaced by `TVM_FFI_STATIC_INIT_BLOCK_DEF_` helper |

**Macros (new internal helpers)**:

| Macro | Expansion | Visibility |
|-------|-----------|-----------|
| `TVM_FFI_STATIC_INIT_BLOCK_DEF_(FnName)` (GCC/Clang) | `__attribute__((constructor)) static void FnName()` | Internal |
| `TVM_FFI_STATIC_INIT_BLOCK_DEF_(FnName, RegVar)` (other) | Static fn + lambda-driven init var | Internal |

## Impact
- API: Syntactic breaking change -- all users of `TVM_FFI_STATIC_INIT_BLOCK` must update from `TVM_FFI_STATIC_INIT_BLOCK({ ... });` to `TVM_FFI_STATIC_INIT_BLOCK() { ... }`. Any downstream code using the old syntax will fail to compile. Users of `TVM_FFI_ATTRIBUTE_UNUSED` must switch to `[[maybe_unused]]` directly.
- Behavioral: On GCC/Clang, static init blocks now use `__attribute__((constructor))` instead of static variable initialization. This may change initialization ordering relative to static variables, though in practice the functions being called (reflection registration) are order-independent.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- **`TVM_FFI_STR_CONCAT` / `__COUNTER__`**: Used to generate unique function names, same pattern as before (`include/tvm/ffi/base_details.h`).
- **`reflection::GlobalDef` / `reflection::ObjectDef<T>`**: All call sites use the reflection builder API inside the init block. No change to the reflection API itself. See [designs/0009-reflection.md](../designs/0009-reflection.md).

Design elements this commit produces/mutates:
- **`TVM_FFI_STATIC_INIT_BLOCK` macro** (mutated): Contract changes from "pass a brace-enclosed body as a macro argument" to "call as a no-arg function-like macro followed by a brace-enclosed body." This is a breaking syntactic change to a core infrastructure macro used across the entire codebase.
- **Compiler-specific init strategy** (new internal detail): GCC/Clang path uses `__attribute__((constructor))` (true constructor functions), MSVC path uses the old static-variable-lambda pattern wrapped around a named function. This is a new compiler-specific bifurcation in the init mechanism.

## Usage Examples

**New syntax (after this commit):**
```cpp
// Register reflection fields and global functions at static init time
TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  refl::ObjectDef<TestIntPairObj>()
      .def_ro("a", &TestIntPairObj::a)
      .def_ro("b", &TestIntPairObj::b)
      .def_static("__create__",
                  [](int64_t a, int64_t b) -> TestIntPair { return TestIntPair(a, b); });
}
```

**Old syntax (before this commit) -- no longer compiles:**
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  namespace refl = tvm::ffi::reflection;
  refl::ObjectDef<TestIntPairObj>()
      .def_ro("a", &TestIntPairObj::a)
      .def_ro("b", &TestIntPairObj::b)
      .def_static("__create__",
                  [](int64_t a, int64_t b) -> TestIntPair { return TestIntPair(a, b); });
});
```
