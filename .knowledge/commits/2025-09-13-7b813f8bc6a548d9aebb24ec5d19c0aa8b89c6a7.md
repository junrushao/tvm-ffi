# Update TVM_FFI_STATIC_INIT_BLOCK to function-style syntax with __attribute__((constructor)) on GCC/Clang

## TL;DR
- Changes `TVM_FFI_STATIC_INIT_BLOCK(Body)` (body passed as macro argument) to `TVM_FFI_STATIC_INIT_BLOCK() { ... }` (block body follows the macro invocation as a function body).
- On GCC/Clang: uses `__attribute__((constructor))` for a real named static constructor function, improving debuggability and error location reporting.
- On MSVC: falls back to the lambda/variable trick with `[[maybe_unused]]`.
- Removes `TVM_FFI_ATTRIBUTE_UNUSED` macro (superseded by `[[maybe_unused]]` inline).

## Key Exports

```python
# Macro TVM_FFI_STATIC_INIT_BLOCK() — new function-style usage
# GCC/Clang path:
#   #define TVM_FFI_STATIC_INIT_BLOCK()
#       __attribute__((constructor)) static void __TVMFFIStaticInitFunc<N>()
# MSVC path:
#   #define TVM_FFI_STATIC_INIT_BLOCK()
#       static void __TVMFFIStaticInitFunc<N>();
#       [[maybe_unused]] static inline int __TVMFFIStaticInitReg<N> = [](){
#           __TVMFFIStaticInitFunc<N>(); return 0;
#       }();
#       static void __TVMFFIStaticInitFunc<N>()
#
# Invariant: The macro must be followed immediately by a { ... } block.
# Invariant: Each usage site gets a unique function name via __COUNTER__.
# Interacts with: global function registration (0004-function-system),
#                 TypeTable registration (0002-object-system), reflection (0006-reflection).
```

## Impact
- API: Source-level breaking change — old `TVM_FFI_STATIC_INIT_BLOCK(Body)` call sites must be rewritten as `TVM_FFI_STATIC_INIT_BLOCK() { Body }`. All `.cc` files in `src/ffi/` updated.
- Behavioral: On GCC/Clang, init functions are now proper named symbols (easier to see in debuggers and stack traces). On MSVC, no behavioral change.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

## Usage Examples

Before:
```cpp
TVM_FFI_STATIC_INIT_BLOCK({
  GlobalDef().def("my.func", MyFunc);
});
```

After:
```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  GlobalDef().def("my.func", MyFunc);
}
```
