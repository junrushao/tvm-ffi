# Add macOS arm64 wheel builds for torch_c_dlpack_ext addon
## TL;DR
- Adds a `build_wheels_macos` job to `torch_c_dlpack.yml` CI workflow, building `torch_c_dlpack_ext` wheels for macOS arm64 across Python 3.9-3.14.
- Makes `build_aot_wheels.sh` cross-platform (Linux/Darwin): uses `delocate-wheel` on macOS instead of `auditwheel`, skips CUDA builds on macOS, uses PyPI torch index (no `--index-url` override) on macOS.
- Fixes `build_backend.py` to use `.so` extension on macOS (not `.dylib`), matching the actual extension produced by `torch.utils.cpp_extension`.
