# Add macOS arm64 wheel builds for torch_c_dlpack_ext addon
## TL;DR
- Adds a `build_wheels_macos` CI job targeting macOS arm64 (macos-14) for Python cp39-cp314.
- Makes `build_aot_wheels.sh` cross-platform (Linux/Darwin) by OS-detecting torch install URLs, CUDA build steps, and wheel repair tools (`auditwheel` on Linux, `delocate` on macOS).
- Removes the Darwin-specific `.dylib` extension check from `build_backend.py`, unifying on `.so` for non-Windows prebuilt detection.

## Key Exports
N/A -- infrastructure only.

## Impact
- API: None
- Behavioral: macOS arm64 wheels are now built and uploaded to PyPI alongside Linux wheels. Torch 2.5 availability on macOS excludes cp313/cp314 (unlike Linux which excludes aarch64/cp314).
- Flags/config: None
- Data formats/schemas: Wheel platform tag on macOS is `macosx_11_0_arm64`.
