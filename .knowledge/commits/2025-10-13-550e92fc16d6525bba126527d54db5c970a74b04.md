# Add TVMFFIErrorSetRaisedFromCStrParts C API for composable error messages
## TL;DR
- Adds `TVMFFIErrorSetRaisedFromCStrParts(kind, parts, num_parts)` C API that concatenates multiple C string parts into a single error message, enabling DSL compilers to reuse common substrings across error messages.
- Version bump to 0.1.0b17.

## Impact
- API: New C API function `TVMFFIErrorSetRaisedFromCStrParts`. Documentation and examples updated.
- Flags/config: None.
- Data formats/schemas: None.
