# Add TVMFFIErrorSetRaisedFromCStrParts C API for concatenating reusable error message parts
## TL;DR
- Adds new C API function `TVMFFIErrorSetRaisedFromCStrParts(kind, message_parts, num_parts)` that constructs error messages by concatenating an array of C string parts, allowing DSL compilers to reuse common substrings (e.g., function signatures) across multiple error messages.
- Implements the concatenation in `SafeCallContext::SetRaisedByCstrParts` with a two-pass approach (measure total length, then append) and NULL-part skipping.
- Bumps version from 0.1.0b16 to 0.1.0b17. Updates docs, examples, and backtrace frame exclusion to reference the new API.

## Key Exports
**Functions**:
- `TVMFFIErrorSetRaisedFromCStrParts(const char* kind, const char** message_parts, int32_t num_parts) -> void` — Sets a raised error in TLS by concatenating `num_parts` C string pointers. NULL entries in `message_parts` are silently skipped. Backtrace is captured at the call site.

## Impact
- API: Additive-only. New C API function alongside existing `TVMFFIErrorSetRaisedFromCStr`. No existing callers are changed.
- ABI: None. No existing struct or enum changes. The new symbol is exported via `TVM_FFI_DLL`.
- Behavioral: None. Existing error paths are unchanged.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples
A DSL compiler can store error message fragments as global constants and compose them at runtime:

```c
// In compiler-generated code: reusable parts stored as globals
static const char* kFuncSig = "matmul(x: Tensor, y: Tensor)";

// Error for argument 1
const char* parts1[] = {"Argument 1 mismatch in `", kFuncSig, "`, dtype mismatch"};
TVMFFIErrorSetRaisedFromCStrParts("TypeError", parts1, 3);
return -1;

// Error for argument 2 (reuses kFuncSig)
const char* parts2[] = {"Argument 2 mismatch in `", kFuncSig, "`, shape[0] mismatch"};
TVMFFIErrorSetRaisedFromCStrParts("TypeError", parts2, 3);
return -1;
```

NULL parts are skipped, enabling optional message segments:

```c
const char* parts[] = {"Mismatched", NULL, " got Tensor"};
TVMFFIErrorSetRaisedFromCStrParts("TypeError", parts, 3);
// Error message: "Mismatched got Tensor"
```
