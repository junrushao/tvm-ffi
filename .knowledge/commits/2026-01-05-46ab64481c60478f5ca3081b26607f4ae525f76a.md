# feat: Add __bool__ support to Python Array and Map containers

## TL;DR
- `Array.__bool__()` returns `True` if non-empty (`len(self) > 0`)
- `Map.__bool__()` returns `True` if non-empty (`len(self) > 0`)
- Added 28 Python test cases

## Key Exports

```python
class Array:
    def __bool__(self) -> bool:
        """Return True if the array is non-empty."""
        # Interacts with: ArraySize via __len__

class Map:
    def __bool__(self) -> bool:
        """Return True if the map is non-empty."""
        # Interacts with: MapSize via __len__
```

## Impact
- API: Additive — `bool(array)` and `if array:` now work in Python; previously would raise `TypeError`
- Behavioral: `bool(Array([]))` → `False`; `bool(Array([1]))` → `True`
- Flags/config: none
- Data formats/schemas: none
