# Add __bool__ to Array and Map for correct Python truthiness

## TL;DR
- Implemented `__bool__` on `Array` and `Map` Python classes so empty containers are falsy (`bool(Array([])) == False`) and non-empty containers are truthy, matching Python's built-in `list`/`dict` behavior.
- Added parametrized pytest tests covering empty and non-empty cases for both container types.

## Key Exports

```python

    def __bool__(self) -> bool:
        """Return True if the array is non-empty."""
        # Implementation: len(self) > 0
        # Interacts with: Array.__len__() -> _ffi_api.ArraySize
        # Invariant: empty arrays are falsy, non-empty arrays are truthy
        ...

        # Implementation: len(self) > 0
        # Interacts with: Map.__len__() -> _ffi_api.MapSize
        # Invariant: empty maps are falsy, non-empty maps are truthy
        ...
```

## Impact
- API: Additive only -- new `__bool__` method on `Array` and `Map`. No existing signatures changed.
- Behavioral: `bool(Array([]))` now returns `False` (was `True`). `bool(Map({}))` now returns `False` (was `True`). Any code that relied on `bool(empty_container) == True` will change behavior. This is a semantic fix aligning with Python conventions.
- Flags/config: None
- Data formats/schemas: None

## Usage Examples

```python
import tvm_ffi

# Array truthiness
assert bool(tvm_ffi.Array([1, 2, 3])) is True
assert bool(tvm_ffi.Array([])) is False

# Map truthiness

assert bool(tvm_ffi.Map({})) is False
```
