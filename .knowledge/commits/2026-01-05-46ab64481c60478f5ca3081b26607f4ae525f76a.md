# Add __bool__ support for Python Array and Map containers
## TL;DR
- Implements `__bool__` on Python `Array` and `Map` classes, returning `len(self) > 0`. Previously `bool(Array([]))` returned `True` (falling through to default Object truthiness).

## Key Exports

**`Array.__bool__(self) -> bool`** and **`Map.__bool__(self) -> bool`** (`python/tvm_ffi/container.py`).

## Impact
- API: None (Python-only, additive)
- Behavioral: `bool(empty_array)` now returns `False` (was `True`); same for `Map`.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **Python containers** (`0014-python-package.md`): `Array`, `Map` classes

Design elements this commit produces: None (behavioral fix)

## Usage Examples
```python
arr = tvm_ffi.convert([])
assert not arr          # was True, now False
assert tvm_ffi.convert([1])  # True
```
