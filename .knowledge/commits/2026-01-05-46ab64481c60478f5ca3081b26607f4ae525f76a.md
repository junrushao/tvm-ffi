# Add __bool__ support for Array and Map containers
## TL;DR
- Implemented `__bool__` on Python `Array` and `Map` so empty containers are falsy, matching built-in `list`/`dict` semantics.
- Added parametrized pytest tests covering truthy/falsy behavior for both container types.

## Key Exports
None — trivial addition delegating to existing `__len__`.

## Impact
- API: none (additive only)
- Behavioral: `bool(Array([]))` and `bool(Map({}))` now return `False` instead of `True`; non-empty containers still return `True`
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `Array` and `Map` Python classes (`python/tvm_ffi/container.py`) and their `__len__` implementations — see [0006-ffi-containers](../design-records/0006-ffi-containers.md)

Design elements this commit produces: None

## Usage Examples
```python
from tvm_ffi import Array, Map

# Empty containers are now falsy
assert not Array([])
assert not Map({})

# Non-empty containers are truthy
assert Array([1, 2, 3])
assert Map({"a": 1})

# Works in conditional context
items = Array([])
if items:
    process(items)  # skipped for empty array
```
