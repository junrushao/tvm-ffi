# Add __bool__ support for Array and Map
## TL;DR
- Adds `__bool__` method to Python Array and Map classes, returning True for non-empty containers.

## Key Exports

**Python API:**
- `Array.__bool__()` -- Returns True if non-empty.
- `Map.__bool__()` -- Returns True if non-empty.

## Impact
- API: New Python dunder methods.
- ABI: none
- Behavioral: `bool(array)` and `bool(map)` now work correctly (empty = False, non-empty = True).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Array and Map containers

Design elements this commit produces: none

## Usage Examples
```python
arr = tvm_ffi.Array([1, 2])
assert bool(arr) is True
assert bool(tvm_ffi.Array([])) is False
```
