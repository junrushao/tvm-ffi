# Extract MapBaseObj hierarchy into map_base.h and remove InplaceArrayBase

## TL;DR
- Extracted the full map implementation (`MapBaseObj`, `DenseMapBaseObj`, `SmallMapBaseObj`) from `map.h` into a new `map_base.h` header, making `MapObj` a thin subclass of `MapBaseObj` with only a type index and friend declarations.
- Templatized `Empty`, `CreateFromRange`, `InsertMaybeReHash`, and `CopyFrom` on `<MapObjType>` so the base classes can mint objects with the correct runtime type index for any subclass, enabling future map variants.
- Removed `InplaceArrayBase` CRTP class from `container_details.h`; `ArrayObj` now computes its inplace data offset directly via `reinterpret_cast<char*>(p.get()) + sizeof(ArrayObj)`.

class MapBaseObj(Object):
    """FFI-transparent base for all map specializations. No type index of its own.
    Follows BytesObjBase pattern: transparent to FFI type system."""
    data_: void_ptr
    size_: uint64
    slots_: uint64  # MSB = layout tag (small vs dense)
    data_deleter_: Optional[Callable]
    # Invariant: sizeof(MapObj) == sizeof(MapBaseObj) (enforced by static_assert in subclasses)
    # Interacts with: SmallMapBaseObj, DenseMapBaseObj (via IsSmallMap dispatch)
    # Interacts with: TVM_FFI_DISPATCH_MAP / TVM_FFI_DISPATCH_MAP_CONST macros
    # Extension: subclass MapBaseObj to create new map variants with distinct type indices

    class iterator: ...
        # iterator.self is now const MapBaseObj* (was const MapObj*)
        # Interacts with: DenseMapBaseObj, SmallMapBaseObj (friend declarations)

    @staticmethod
    def Empty[MapObjType]() -> ObjectPtr[Object]: ...
        # Delegates to SmallMapBaseObj.Empty<MapObjType>()

    @staticmethod
    def CreateFromRange[MapObjType, IterType](first: IterType, last: IterType) -> ObjectPtr[Object]: ...
        # Routes to SmallMapBaseObj or DenseMapBaseObj based on capacity

    @staticmethod
    def InsertMaybeReHash[MapObjType](kv: KVType, map: ObjectPtr[Object]) -> None: ...
        # Dispatches small/dense, stamps header_.type_index = MapObjType::RuntimeTypeIndex()

    @staticmethod
    def CopyFrom[MapObjType](from_: MapBaseObj) -> ObjectPtr[Object]: ...
        # Dispatches small/dense copy

    def clear(self) -> None: ...  # NEW: dispatches to SmallMapBaseObj/DenseMapBaseObj.clear()
    # Interacts with: SmallMapBaseObj.clear(), DenseMapBaseObj.clear()

class DenseMapBaseObj(MapBaseObj):
    """Array-based hash map with Fibonacci hashing. Reorganized before SmallMapBaseObj."""
    # Invariant: header_.type_index is stamped to MapObjType::RuntimeTypeIndex() at creation
    # static_assert: sizeof(MapObjType) == sizeof(MapBaseObj)
    # static_assert: is_base_of_v<MapBaseObj, MapObjType>
    # Extension: subclass MapBaseObj, pass as template arg to Empty/CreateFromRange

    def clear(self) -> None: ...  # NEW: clears entries without releasing memory

class SmallMapBaseObj(MapBaseObj):
    """Small-capacity linear-scan map (<=4 entries). Uses inplace array storage."""
    # Invariant: data_ = reinterpret_cast<char*>(this) + sizeof(SmallMapBaseObj)
    #   (was: data_ = AddressOf(0) via InplaceArrayBase, now direct offset)
    # Extension: same MapObjType template pattern for type-index stamping

    def clear(self) -> None: ...  # NEW: destroys entries, resets size to 0

class MapObj(MapBaseObj):
    """Concrete map type with kTVMFFIMap type index. Thin subclass."""
    _type_index = kTVMFFIMap
    # Invariant: sizeof(MapObj) == sizeof(MapBaseObj) (no additional fields)
    # Interacts with: Map<K,V> ref wrapper (friend), stl.h TypeTraits (CreateFromRange<MapObj>)

## Impact
- API: `MapObj::Empty()` -> `MapObj::Empty<MapObj>()`, `MapObj::CreateFromRange(...)` -> `MapObj::CreateFromRange<MapObj>(...)`, `MapObj::InsertMaybeReHash(...)` -> `MapObj::InsertMaybeReHash<MapObj>(...)`, `MapObj::CopyFrom(...)` -> `MapObj::CopyFrom<MapObj>(...)`. All call sites in `map.h` and `stl.h` updated. Downstream code using `Map<K,V>` is unaffected (changes are internal to ref wrapper).
- Behavioral: `DenseMapBaseObj::clear()` and `SmallMapBaseObj::clear()` are new public methods (clear entries without deallocating). `DenseMapBaseObj::Reset()` now delegates to `clear()` + `ReleaseMemory()` instead of inline destruction.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `Object` system (`include/tvm/ffi/object.h`) -- `MapBaseObj` inherits from `Object`, uses `header_.type_index` stamping
- `make_inplace_array_object` (`include/tvm/ffi/memory.h`) -- used by `SmallMapBaseObj::Empty`
- `AnyHash`/`AnyEqual` (`include/tvm/ffi/any.h`) -- used throughout map lookup/insertion
- `BytesObjBase` pattern (referenced in `MapBaseObj` doc comment as precedent for FFI-transparent base)

Design elements this commit produces:
- `MapBaseObj` hierarchy (`map_base.h`) -- new reusable base for map variants with templatized factory methods
- `MapBaseObj::clear()` dispatch chain -- new public API for clearing map entries without deallocation
- `SmallMapBaseObj` / `DenseMapBaseObj` -- renamed and reorganized (DenseMapBaseObj before SmallMapBaseObj) for future refactors

Design elements this commit removes:
- `InplaceArrayBase<ArrayType, ElemType>` (`container_details.h`) -- CRTP base for arrays with inplace storage. Replaced by direct pointer arithmetic in `ArrayObj` and `SmallMapBaseObj`.

## Usage Examples

Before (old API, internal to Map<K,V>):
```cpp
// Creating a Map
Map<String, int> m;                               // calls MapObj::Empty()
m.Set("key", 42);                                 // calls MapObj::InsertMaybeReHash(kv, &data_)
Map<String, int> m2(init.begin(), init.end());     // calls MapObj::CreateFromRange(first, last)
```

After (new API, internal to Map<K,V>):
```cpp
// Same user-facing API, but internal calls now carry explicit MapObjType
Map<String, int> m;                               // calls MapObj::Empty<MapObj>()
m.Set("key", 42);                                 // calls MapObj::InsertMaybeReHash<MapObj>(kv, &data_)
Map<String, int> m2(init.begin(), init.end());     // calls MapObj::CreateFromRange<MapObj>(first, last)

// Future: a custom map variant
// class MyMapObj : public MapBaseObj { ... _type_index = kMyIndex ... };
// MapBaseObj::Empty<MyMapObj>();  // creates SmallMapBaseObj with MyMapObj's type index
```

STL bridge change (stl.h):
```cpp
// Before:
return MapObj::CreateFromRange(std::begin(src), std::end(src));
// After:
return MapObj::CreateFromRange<MapObj>(std::begin(src), std::end(src));
```
