# Cleanup and improve map array containers
## TL;DR
- Extracts Map's hash-table internals into a separate `map_base.h` header (~1444 lines) for reuse by Dict.
- Removes `container_details.h` (128 lines of dead/unused code).
- Simplifies `map.h` from 1332 lines down to ~11 lines of Map-specific logic plus includes.

## Key Exports

```python
# New internal header: include/tvm/ffi/container/map_base.h
# Contains: SmallMapNode, DenseMapNode (hash table implementation)
# Interacts with: Map, Dict (both consume the base implementation)
# Invariant: SmallMapNode used for <=4 entries, DenseMapNode for larger maps
```
