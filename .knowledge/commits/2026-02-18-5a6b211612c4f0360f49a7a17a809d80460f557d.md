# Extract MapBaseObj from MapObj and remove InplaceArrayBase from ArrayObj

## TL;DR
- Extracts all map implementation from `map.h` into a new `include/tvm/ffi/container/map_base.h`, introducing `MapBaseObj`, `DenseMapBaseObj`, and `SmallMapBaseObj` as FFI-transparent base classes; `MapObj` is now a thin concrete subclass of `MapBaseObj`.
- Removes `details::InplaceArrayBase<ArrayObj, TVMFFIAny>` from `ArrayObj`'s inheritance; the inplace data pointer is now computed with a direct `reinterpret_cast` instead of `AddressOf(0)`.
- Templatizes map factory methods (`Empty`, `CreateFromRange`, `InsertMaybeReHash`, `CopyFrom`) on `MapObjType` so future subclasses can reuse the allocation logic while stamping their own `type_index`.

## Key Exports

```python
# include/tvm/ffi/container/map_base.h (new file)

class MapBaseObj(Object):
    """FFI-transparent base holding all hash-map implementation; no type_index."""
    # Subclasses MUST satisfy: sizeof(SubClass) == sizeof(MapBaseObj)
    # Invariant: subclass sets type_index via MapObjType::RuntimeTypeIndex() in factory
    key_type = Any
    mapped_type = Any
    KVType = Pair[Any, Any]

    def size(self) -> int: ...
    def count(self, key: Any) -> int: ...
    def at(self, key: Any) -> Any: ...          # throws KeyError if missing
    def find(self, key: Any) -> iterator: ...
    def erase(self, position_or_key) -> None: ...
    def clear(self) -> None: ...

    # Templatized factory methods (MapObjType must be base_of MapBaseObj)
    @staticmethod
    def Empty() -> ObjectPtr[Object]: ...
    # Interacts with: DenseMapBaseObj.Empty / SmallMapBaseObj.Empty based on size
    @staticmethod
    def CreateFromRange(first: IterType, last: IterType) -> ObjectPtr[Object]: ...
    @staticmethod
    def InsertMaybeReHash(kv: KVType, map: ObjectPtr[Object]*) -> None: ...
    # Invariant: may replace *map with a DenseMapBaseObj if SmallMap is full
    @staticmethod
    def CopyFrom(from_: MapBaseObj*) -> ObjectPtr[Object]: ...

class DenseMapBaseObj(MapBaseObj):
    """Open-addressing hash table backing for large maps."""
    # Invariant: MSB of slots_ == 0 (IsSmallMap() returns False)
    # Extension: subclass MapBaseObj, set sizeof == sizeof(MapBaseObj),
    #            pass as MapObjType to factory methods

class SmallMapBaseObj(MapBaseObj):
    """Inplace array-backed map for ≤ kMaxSize entries."""
    # Invariant: MSB of slots_ == 1 (IsSmallMap() returns True)
    kMaxSize: int  # threshold for promotion to DenseMapBaseObj

class MapObj(MapBaseObj):
    """Concrete Map type registered in the FFI type system."""
    # type_index = TypeIndex::kTVMFFIMap
    # _type_final = True
    # Inherits all API from MapBaseObj; adds no new fields.
    # Interacts with: Map[K,V] (public ObjectRef wrapper)

# ArrayObj change (include/tvm/ffi/container/array.h)
class ArrayObj(SeqBaseObj):
    """Array object — no longer inherits InplaceArrayBase."""
    # Removed: InplaceArrayBase<ArrayObj, TVMFFIAny> base (CRTP)
    # Removed: AddressOf(0) call; replaced with:
    #   data = reinterpret_cast<char*>(p.get()) + sizeof(ArrayObj)
    # Invariant: TVMFFIAny must remain trivially destructible
    # Extension: inplace data layout is unchanged; only the CRTP helper is gone
```

## Impact
- API: `MapObj` is now a final subclass of `MapBaseObj` instead of `Object`. All `Map<K,V>` callers updated to pass `MapObj` as template argument to `CreateFromRange<MapObj>`, `Empty<MapObj>`, `InsertMaybeReHash<MapObj>`, `CopyFrom<MapObj>`. Direct users of `MapObj` as a base class will now use `MapBaseObj` instead.
- Behavioral: None — this is a pure structural refactor. Public `Map<K,V>` API is unchanged.
- Flags/config: None
- Data formats/schemas: None

## Design Elements

Design elements this commit consumes:
- `0007-containers`: `ArrayObj` (SeqBaseObj subclass), `MapObj` / `DenseMapObj` / `SmallMapObj` internals, `Map<K,V>` copy-on-write wrapper.
- `0002-object-system`: `Object` base, `ObjectPtr`, `make_object`, `make_inplace_array_object`.
- `details::InplaceArrayBase<ArrayType, ElemType>` (from `container_details.h`) — **removed** by this commit.

Design elements this commit produces:
- **`MapBaseObj`** — new FFI-transparent base class (no type index) extracted from `MapObj`. Holds all map implementation. Enables future `Map`-like subclasses by providing templatized factory methods that stamp the correct `type_index` via `MapObjType::RuntimeTypeIndex()`.
- **`DenseMapBaseObj`** / **`SmallMapBaseObj`** — renames of `DenseMapObj` / `SmallMapObj` to reflect their new role as internal implementation helpers under `MapBaseObj`.
- **`map_base.h`** — new public header aggregating the base hierarchy; `map.h` is now a thin consumer.
- Removal of **`details::InplaceArrayBase`** from `container_details.h` — CRTP helper eliminated; `ArrayObj` computes inplace data pointer directly.

## Usage Examples

To create a map subclass reusing the allocation machinery (future extension pattern):

```cpp
// Forward declare a future DictObj subclass that shares MapBaseObj layout
class DictObj : public MapBaseObj {
 public:
  static constexpr const int32_t _type_index = TypeIndex::kTVMFFIDict; // hypothetical
  static const constexpr bool _type_final = true;
  TVM_FFI_DECLARE_OBJECT_INFO_STATIC("ffi.Dict", DictObj, Object);
};

// Create an empty DictObj using the MapBaseObj factory machinery:
ObjectPtr<Object> empty = MapBaseObj::Empty<DictObj>();

// Insert with automatic small→dense promotion:
MapBaseObj::InsertMaybeReHash<DictObj>(MapBaseObj::KVType(k, v), &empty);
```

Before/after for ArrayObj data pointer (no behavioral change):

```cpp
// Before:
p->data = p->AddressOf(0);  // via InplaceArrayBase CRTP

// After:
p->data = reinterpret_cast<char*>(p.get()) + sizeof(ArrayObj);
```
