# Polish quickstart doc: literalinclude from examples, restructure directory, add loader scripts

## TL;DR
- Rewrites `docs/get_started/quickstart.rst` to use RST `literalinclude` directives pointing at real example files instead of inline code blocks, making docs testable and eliminating copy drift.
- Renames `examples/quick_start/` to `examples/quickstart/` with a cleaner `compile/` + `load/` subdirectory layout. Adds standalone loader scripts for NumPy, CuPy, PyTorch, and C++.
- Adds `run_all_cpu.sh`, `run_all_cuda.sh`, and `raw_compile.sh` runner scripts; configures `shfmt --indent=2`; adds `[tool.setuptools_scm]` to `pyproject.toml`.

Rename mapping:

| Old path | New path |
|----------|----------|
| `examples/quick_start/` | `examples/quickstart/` |
| `examples/quick_start/src/add_one_cpu.cc` | `examples/quickstart/compile/add_one_cpu.cc` |
| `examples/quick_start/src/add_one_cuda.cu` | `examples/quickstart/compile/add_one_cuda.cu` |
| `examples/quick_start/run_example.sh` | `examples/quickstart/run_all_cuda.sh` |
| `examples/quick_start/src/run_example.cc` (deleted) | `examples/quickstart/load/load_cpp.cc` (new, rewritten) |
| `examples/quick_start/run_example.py` (deleted) | Split into `load/load_numpy.py`, `load/load_cupy.py`, `load/load_pytorch.py` |
