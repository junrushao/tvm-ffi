# Polish quickstart doc to use literalinclude and restructure examples directory
## TL;DR
- Renames `examples/quick_start/` to `examples/quickstart/` and reorganizes into `compile/` and `load/` subdirectories, separating library-building examples from library-loading examples.
- Rewrites `docs/get_started/quickstart.rst` to use Sphinx `literalinclude` directives pointing to actual source files (with `[example.begin]`/`[example.end]` markers) instead of inline code blocks, ensuring doc snippets stay in sync with runnable code.
- Adds new standalone Python loading scripts (`load_numpy.py`, `load_pytorch.py`, `load_cupy.py`) and a C++ loader (`load_cpp.cc`), plus shell scripts (`raw_compile.sh`, `run_all_cpu.sh`, `run_all_cuda.sh`) and minor linting config adjustments.

| Old path | New path |
|----------|----------|
| `examples/quick_start/` | `examples/quickstart/` |
| `examples/quick_start/src/add_one_cpu.cc` | `examples/quickstart/compile/add_one_cpu.cc` |
| `examples/quick_start/src/add_one_cuda.cu` | `examples/quickstart/compile/add_one_cuda.cu` |
| `examples/quick_start/src/add_one_c.c` | (removed) |
| `examples/quick_start/src/run_example.cc` | (removed, replaced by `examples/quickstart/load/load_cpp.cc`) |
| `examples/quick_start/src/run_example_cuda.cc` | (removed) |
| `examples/quick_start/run_example.py` | (removed, replaced by per-framework `load/*.py`) |
| `examples/quick_start/run_example.sh` | `examples/quickstart/run_all_cuda.sh` |
