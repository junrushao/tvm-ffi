# Polish quickstart doc to use literalinclude and add runnable examples directory

## TL;DR
- Rewrites `docs/get_started/quickstart.rst` to use Sphinx `literalinclude` directives referencing actual source files instead of inline code blocks, ensuring docs stay in sync with runnable examples.
- Renames `examples/quick_start/` to `examples/quickstart/` and restructures it into `compile/` (source files to build) and `load/` (scripts that load and call the built libraries), adding standalone Python scripts for PyTorch, NumPy, CuPy and a C++ loader.
- Removes the old `run_example.py`, `run_example.cc`, `run_example_cuda.cc`, and `add_one_c.c` files. Adds `raw_compile.sh` with tagged regions, `run_all_cpu.sh`, and `run_all_cuda.sh` runner scripts. Minor cleanups: removes TODO comments from `.pre-commit-config.yaml`, adds `--indent=2` to shfmt, adds empty `[tool.setuptools_scm]` to `pyproject.toml`.

## Usage Examples
The commit itself is essentially a collection of usage examples. The canonical cross-layer trace is:

**Compile a C++ function and call it from Python (NumPy):**
```cpp
// examples/quickstart/compile/add_one_cpu.cc
#include <tvm/ffi/container/tensor.h>
#include <tvm/ffi/function.h>

namespace tvm_ffi_example_cpu {
void AddOne(tvm::ffi::TensorView x, tvm::ffi::TensorView y) {
  int64_t n = x.size(0);
  float* x_data = static_cast<float*>(x.data_ptr());
  float* y_data = static_cast<float*>(y.data_ptr());
  for (int64_t i = 0; i < n; ++i) {
    y_data[i] = x_data[i] + 1;
  }
}
TVM_FFI_DLL_EXPORT_TYPED_FUNC(add_one_cpu, tvm_ffi_example_cpu::AddOne);
}
```

```python
# examples/quickstart/load/load_numpy.py
import tvm_ffi
mod = tvm_ffi.load_module("build/add_one_cpu.so")

import numpy as np
x = np.array([1, 2, 3, 4, 5], dtype=np.float32)
y = np.empty_like(x)
mod.add_one_cpu(x, y)
print(y)
```
