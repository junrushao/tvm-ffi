# Restructure quickstart examples into examples/quickstart/ and use literalinclude in docs
## TL;DR
- Renames `examples/quick_start/` to `examples/quickstart/` with restructured layout: `compile/` (source), `load/` (per-framework Python/C++ loaders), `raw_compile.sh`, `run_all_cpu.sh`, `run_all_cuda.sh`.
- Converts `docs/get_started/quickstart.rst` from inline code blocks to Sphinx `.. literalinclude::` directives with `[example.begin]`/`[example.end]` markers, ensuring docs stay in sync with runnable examples.
- Minor config: `shfmt` gains `--indent=2`; `pyproject.toml` adds empty `[tool.setuptools_scm]` section.

| Old path | New path |
|---|---|
| `examples/quick_start/` | `examples/quickstart/` |
| `examples/quick_start/src/add_one_cpu.cc` | `examples/quickstart/compile/add_one_cpu.cc` |
| `examples/quick_start/src/add_one_cuda.cu` | `examples/quickstart/compile/add_one_cuda.cu` |
| `examples/quick_start/run_example.py` | (removed; split into `load/load_numpy.py`, `load/load_pytorch.py`, `load/load_cupy.py`) |
| `examples/quick_start/src/run_example.cc` | `examples/quickstart/load/load_cpp.cc` |
| `examples/quick_start/run_example.sh` | `examples/quickstart/run_all_cuda.sh` (+ new `run_all_cpu.sh`) |
