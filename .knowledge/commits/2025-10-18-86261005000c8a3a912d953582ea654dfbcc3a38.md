# Polish quickstart doc and restructure examples directory
## TL;DR
- Renames `examples/quick_start/` to `examples/quickstart/` and restructures into `compile/` (source to build) and `load/` (consumer scripts per framework) subdirectories.
- Replaces inline code blocks in `docs/get_started/quickstart.rst` with `.. literalinclude::` directives pointing to actual example files, using `[example.begin]`/`[example.end]` markers to keep documentation and code in sync.
- Simplifies example source code (removes verbose ICHECK guards from add_one_cpu.cc/add_one_cuda.cu), removes monolithic scripts (run_example.py, run_example.cc, run_example_cuda.cc, add_one_c.c), and adds per-framework loader scripts (load_numpy.py, load_pytorch.py, load_cupy.py, load_cpp.cc).
