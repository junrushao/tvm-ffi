# Add .pyi type stubs for Cython-compiled core module to enable IDE type checking
## TL;DR
- Introduces `python/tvm_ffi/core.pyi`, a hand-written type stub (227 lines) that declares the full public API surface of the Cython-compiled `tvm_ffi.core` extension module, enabling Pylance/mypy/pyright type checking and IDE autocomplete.
- Refactors `_tensor.py` imports to use direct symbol imports (`from .core import _CLASS_DEVICE, PyNativeObject, ...`) instead of qualified access (`core._CLASS_DEVICE`, `core.PyNativeObject`), which works better with the new `.pyi` stub.
- Registers `.pyi` extension in `check_asf_header.py` so that type stub files receive ASF license header checking.

## Key Exports
**Type stub file** `python/tvm_ffi/core.pyi` -- declares the following public symbols from the Cython `core` module:

**Classes:**
- `Object` -- base class for all FFI objects, with `__ctypes_handle__`, `__chandle__`, `same_as`, `_move`, pickle support
- `ObjectConvertible` -- abstract base with `asobject() -> Object`
- `ObjectRValueRef` -- RValue wrapper for move semantics
- `OpaquePyObject(Object)` -- opaque Python object container with `pyobject() -> Any`
- `PyNativeObject` -- base for Python-builtin + FFI hybrid objects, `__init_tvm_ffi_object_by_constructor__`
- `Error(Object)` -- FFI error with `kind`, `message`, `traceback` properties and `py_error()` method
- `DataType` -- DLDataType wrapper with `type_code`, `bits`, `lanes`, `itemsize` properties
- `DLDeviceType(IntEnum)` -- enum with kDLCPU through kDLHexagon (16 values)
- `Device` -- DLDevice wrapper with `type`, `index` properties and string parsing
- `Tensor(Object)` -- managed ndarray with `shape`, `dtype`, `device` properties and DLPack v2 support
- `DLTensorTestWrapper` -- test-only DLPack wrapper
- `Function(Object)` -- packed function with `release_gil` property and `__call__`
- `String(str, PyNativeObject)` -- FFI string with `__tvm_ffi_object__` slot
- `Bytes(bytes, PyNativeObject)` -- FFI bytes with `__tvm_ffi_object__` slot

**Module-level variables:**
- `ERROR_NAME_TO_TYPE: dict[str, type]`
- `ERROR_TYPE_TO_NAME: dict[type, str]`
- `_WITH_APPEND_TRACEBACK`, `_TRACEBACK_TO_STR` -- optional callbacks for traceback reconstruction
- `__dlpack_version__: tuple[int, int]`
- `_CLASS_DEVICE: type[Device]`

**Functions:**
- `_set_class_object(cls: type) -> None`
- `_register_object_by_index(index: int, cls: type) -> None`
- `_object_type_key_to_index(type_key: str) -> int | None`
- `_add_class_attrs_by_reflection(type_index: int, cls: type) -> type`
- `_convert_to_ffi_error(error: BaseException) -> Error`
- `_env_set_current_stream(device_type: int, device_id: int, stream: int) -> int`
- `_set_class_dtype(cls: type) -> None`
- `_create_dtype_from_tuple(cls: type[DataType], code: int, bits: int, lanes: int) -> DataType`
- `_set_class_device(cls: type) -> None`
- `_shape_obj_get_py_tuple(obj: Any) -> tuple[int, ...]`
- `from_dlpack(ext_tensor: Any, *, require_alignment: int = ..., require_contiguous: bool = ...) -> Tensor`
- `_dltensor_test_wrapper_c_dlpack_from_pyobject_as_intptr() -> int`
- `_register_global_func(name: str, pyfunc: Callable | Function, override: bool) -> Function`
- `_get_global_func(name: str, allow_missing: bool) -> Function | None`
- `_convert_to_ffi_func(pyfunc: Callable) -> Function`
- `_convert_to_opaque_object(pyobject: Any) -> OpaquePyObject`
- `_print_debug_info() -> None`

## Impact
- API: none -- the `.pyi` file is purely a type-checking artifact; no runtime behavior changes.
- ABI: none
- Behavioral: none -- `_tensor.py` import refactoring is semantically identical (direct symbol import vs. qualified access).
- Flags/config: Pylance users may need `"python.analysis.extraPaths": ["./build/"]` if Cython `core` module is not installed.
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Python binding layer** (`.knowledge/designs/0014-python-bindings.md`) -- the stub declares the same classes and functions documented in this design doc: `Object`, `Function`, `Error`, `PyNativeObject`, `Tensor`, `Device`, `DataType`, `String`, `Bytes`, reflection helpers, error/traceback hooks.
- **Object system** (`.knowledge/designs/object-system.md`) -- `PyNativeObject` pattern, `Object` base class, `ObjectRValueRef` move semantics.

- **ASF header enforcement** (`tests/lint/check_asf_header.py`, documented in `.knowledge/commits/2025-09-13-ef6d57b8.md`) -- `FMT_MAP` extension registry.

Design elements this commit produces:
- **Cython type stub convention** -- introduces the pattern of providing a hand-written `.pyi` stub alongside Cython `.pyx` modules for IDE support. This is the first `.pyi` file in the codebase and establishes the convention that Cython extension modules should have companion type stubs.

## Usage Examples
The `.pyi` stub is consumed implicitly by type checkers. No code imports it directly.

**IDE experience after this commit:**
```python
# In a user's editor, Pylance/pyright now provides autocomplete and type checking:
from tvm_ffi.core import Function, Object, Tensor

def my_func(f: Function, t: Tensor) -> None:
    result = f(t)        # type checker knows f is callable
    print(t.shape)       # autocomplete shows .shape, .dtype, .device
    print(t.device.type) # nested property chain is typed
```
