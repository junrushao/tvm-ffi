# Add .pyi typestubs for Cython-generated core module to enable IDE type checking
## TL;DR
- New `python/tvm_ffi/core.pyi` provides type annotations for the entire Cython-compiled `core` extension module (227 lines covering Object, Function, Tensor, Device, DataType, Error, String, Bytes, and module-level helpers).
- `_tensor.py` switches from `core.X` qualified attribute access to explicit named imports, improving type checker visibility.
- ASF header lint (`check_asf_header.py`) extended to cover `.pyi` files.

## Key Exports

```python
# python/tvm_ffi/core.pyi — typestub for the Cython extension module

# Module-level variables
ERROR_NAME_TO_TYPE: dict[str, type]
ERROR_TYPE_TO_NAME: dict[type, str]

class Object:
    """Base class of all TVM FFI objects."""
    def __chandle__(self) -> int: ...
    def __init_handle_by_constructor__(self, fconstructor: Function, *args: Any) -> None: ...
    def same_as(self, other: Any) -> bool: ...
    def _move(self) -> ObjectRValueRef: ...
    # Interacts with: Function (constructor init), ObjectRValueRef (move semantics)

class ObjectRValueRef:
    """RValue ref for move semantics."""
    obj: Object

class PyNativeObject:
    """Base for TVM objects that also subclass Python builtins (str, bytes, tuple)."""
    # Interacts with: String, Bytes, Shape — all subclass both a builtin and this
    # Extension: subclass with __from_tvm_ffi_object__ classmethod

class Function(Object):
    """Packed callable with tvm-ffi ABI."""
    release_gil: bool  # property, controls GIL release per-call
    def __call__(self, *args: Any) -> Any: ...
    # Interacts with: global registry (_register_global_func, _get_global_func)

class Tensor(Object):
    """Managed n-dimensional array with DLPack exchange."""
    shape: tuple[int, ...]
    dtype: Any
    device: Device
    def __dlpack__(self, *, stream: Any | None = None, ...) -> Any: ...
    # Interacts with: from_dlpack(), Device, DLPack protocol

class Device:
    """Device descriptor (type + index)."""
    def __init__(self, device_type: str | int, index: int | None = None) -> None: ...
    # Interacts with: DLDeviceType enum, _CLASS_DEVICE module var

class DataType:
    """DLDataType wrapper."""
    type_code: int  # property
    bits: int       # property
    lanes: int      # property

class Error(Object):
    """FFI error with kind/message/traceback."""
    kind: str       # property
    message: str    # property
    traceback: str  # property

class String(str, PyNativeObject):
    """FFI String that subclasses Python str."""
    __tvm_ffi_object__: Object | None

class Bytes(bytes, PyNativeObject):
    """FFI Bytes that subclasses Python bytes."""
    __tvm_ffi_object__: Object | None

# Registration helpers
def _register_global_func(name: str, pyfunc: Callable[..., Any] | Function, override: bool) -> Function: ...
def _get_global_func(name: str, allow_missing: bool) -> Function | None: ...
def _add_class_attrs_by_reflection(type_index: int, cls: type) -> type: ...
def from_dlpack(ext_tensor: Any, *, require_alignment: int = ..., require_contiguous: bool = ...) -> Tensor: ...
```

## Impact
- API: none — `.pyi` is purely a type annotation layer, no runtime behavior change
- Behavioral: none
- Flags/config: Pylance users may need `"python.analysis.extraPaths": ["./build/"]` for full resolution
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Object system (0002) — annotated as `Object` base class with ref-counting methods
- Function system (0003) — annotated as `Function` class with `release_gil` and packed `__call__`
- Error propagation (0004) — annotated as `Error` class with kind/message/traceback properties
- Containers (0006) — annotated `String`, `Bytes`, `Tensor` types
- Python bindings (0012) — the Cython extension module whose surface is being described

Design elements this commit produces:
- `.pyi` typestub convention for Cython-generated modules (new pattern: hand-maintained stub alongside `.pyx`/`.pxi` sources)

## Usage Examples

After this commit, IDEs (Pylance, mypy) can resolve types from the Cython module:

```python
from tvm_ffi.core import Object, Function, Tensor, Device

# IDE now provides autocomplete and type checking for:
obj: Object = some_ffi_call()
obj.same_as(other)       # resolved: (other: Any) -> bool
obj._move()              # resolved: () -> ObjectRValueRef

fn: Function = get_global_func("some.func")
fn.release_gil = True    # resolved: property setter
result = fn(1, "hello")  # resolved: (*args: Any) -> Any

t: Tensor = from_dlpack(np_array)
t.shape                  # resolved: tuple[int, ...]
t.device                 # resolved: Device
```
