# Simplify Triton cubin extraction by using kernel call return value directly
## TL;DR
- In `examples/cubin_launcher/example_triton_cubin.py` and `benchmark_overhead.py`, replaces the 6-line pattern of walking `kernel.device_caches` to find the compiled kernel with a single-line direct capture: `compiled_kernel = kernel[grid](args...)`.
- The Triton kernel launch call returns `CompiledKernel` directly, making cache traversal unnecessary.
