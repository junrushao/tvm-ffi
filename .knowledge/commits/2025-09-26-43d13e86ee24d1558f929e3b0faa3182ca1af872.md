# Pack strong/weak ref counts into single u64 combined_ref_count for single-atomic deletion fast path
## TL;DR
- Replaces separate `uint32_t strong_ref_count` + `uint32_t weak_ref_count` fields in `TVMFFIObject` with a single `uint64_t combined_ref_count` that packs strong (lower 32 bits) and weak (upper 32 bits).
- Rewrites all atomic ref-count operations (`IncRef`, `DecRef`, `IncWeakRef`, `DecWeakRef`, `TryPromoteWeakPtr`, `use_count`) to operate on the combined field, enabling a single-atomic fast path in `DecRef` that detects both-counts-reaching-zero without a separate weak-count read.
- Follows up commit 13436f0 which reordered `TVMFFIObject` to place ref counts first and narrowed strong to u32, enabling this packing. Version bumped to `0.1.0b8`.

## Key Exports

```python
# New constants in tvm::ffi::details namespace (object.h)
kCombinedRefCountWeakOne: uint64 = 1 << 32       # Add to combined_ref_count to increment weak count
kCombinedRefCountStrongOne: uint64 = 1            # Add to combined_ref_count to increment strong count
kCombinedRefCountBothOne: uint64 = (1 << 32) | 1  # Initial value: both counts = 1
kCombinedRefCountMaskUInt32: uint64 = (1 << 32) - 1  # Mask to extract strong count (lower 32 bits)
# Interacts with: Object.IncRef, Object.DecRef, Object.IncWeakRef, Object.DecWeakRef,
#                 Object.TryPromoteWeakPtr, Object.use_count, ObjAllocatorBase.make
# Invariant: strong_count = combined & kCombinedRefCountMaskUInt32
# Invariant: weak_count = (combined >> 32) & kCombinedRefCountMaskUInt32

class TVMFFIObject:
    """Updated 24-byte C ABI object header. Ref counts packed into single u64."""
    # Old: strong_ref_count: uint32, weak_ref_count: uint32
    # New:
    combined_ref_count: uint64  # Offset 0. Lower 32 = strong, upper 32 = weak.
    type_index: int32           # Offset 8.
    __padding: uint32           # Offset 12.
    deleter: Callable[[void_ptr, int], None]  # Offset 16.
    # Invariant: sizeof == 24 (unchanged)
    # Invariant: newly allocated objects start with combined_ref_count = kCombinedRefCountBothOne

class Object:
    """Updated ref-count operations using combined field."""
    def use_count(self) -> uint64: ...
        # Old return type: int32_t. New return type: uint64_t.
        # Returns: atomic_load(combined_ref_count) & kCombinedRefCountMaskUInt32
        # Interacts with: ObjectPtr.unique()

    def IncRef(self) -> None: ...
        # Old: atomic_add(strong_ref_count, 1)
        # New: atomic_add(combined_ref_count, 1)  # kCombinedRefCountStrongOne == 1
        # Invariant: caller already holds a strong reference

    def DecRef(self) -> None: ...
        # Old: atomic_sub(strong_ref_count, 1); if zero: read weak; dispatch
        # New: count_before = atomic_sub(combined_ref_count, kCombinedRefCountStrongOne)
        #   if count_before == kCombinedRefCountBothOne:
        #       -> fast path: both will be zero, call deleter(kBoth) -- ONE atomic op total
        #   elif (count_before & mask) == kCombinedRefCountStrongOne:
        #       -> strong reaches zero, weak still alive
        #       -> call deleter(kStrong), then atomic_sub(combined, kCombinedRefCountWeakOne)
        #       -> if that also reaches zero: call deleter(kWeak)
        # Interacts with: TVMFFIObjectDeleterFlagBitMask, ObjAllocatorBase.Deleter_

    def IncWeakRef(self) -> None: ...
        # Old: atomic_add(weak_ref_count, 1)
        # New: atomic_add(combined_ref_count, kCombinedRefCountWeakOne)

    def DecWeakRef(self) -> None: ...
        # Old: atomic_sub(weak_ref_count, 1); if zero: call deleter(kWeak)
        # New: atomic_sub(combined_ref_count, kCombinedRefCountWeakOne); if zero: call deleter(kWeak)

    def TryPromoteWeakPtr(self) -> bool: ...
        # Old: CAS loop on strong_ref_count (u32)
        # New: CAS loop on combined_ref_count (u64), checking lower 32 bits for > 0,
        #      incrementing by kCombinedRefCountStrongOne
        # Interacts with: WeakObjectPtr.lock()
```

## Impact
- API: ABI break. `TVMFFIObject.strong_ref_count` and `TVMFFIObject.weak_ref_count` fields replaced by `TVMFFIObject.combined_ref_count`. `Object::use_count()` return type widened from `int32_t` to `uint64_t`. Any code accessing struct fields by name or offset must update. Rust bindings not updated in this commit.
- Behavioral: `DecRef` now uses one fewer atomic operation in the common case (no weak refs). Previously: atomic_sub(strong) + atomic_load(weak) + conditional atomic_sub(weak). Now: atomic_sub(combined) + branch on pre-sub value. The fast path (both counts == 1, i.e. single owner, no weak refs) collapses to a single atomic + deleter call.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Before/after pattern showing the DecRef optimization:

```cpp
// BEFORE (13436f0): two separate atomics to detect common case
void DecRef() {
    if (__atomic_fetch_sub(&strong_ref_count, 1, RELEASE) == 1) {
        if (__atomic_load_n(&weak_ref_count, RELAXED) == 1) {
            // common case: both zero -- but required 2 atomic ops to detect
            __atomic_thread_fence(ACQUIRE);
            deleter(self, kBoth);
        } else {
            // slow path: weak refs still alive
            ...
        }
    }
}

// AFTER (43d13e8): single atomic detects common case
void DecRef() {
    uint64_t before = __atomic_fetch_sub(&combined_ref_count,
                                          kCombinedRefCountStrongOne, RELEASE);
    if (before == kCombinedRefCountBothOne) {
        // fast path: both strong=1, weak=1 -> both will be zero. ONE atomic op total.
        __atomic_thread_fence(ACQUIRE);
        deleter(self, kBoth);
    } else if ((before & kCombinedRefCountMaskUInt32) == kCombinedRefCountStrongOne) {
        // slow path: strong reaches zero, weak refs still alive
        ...
    }
}
```
