# Pack strong/weak ref counts into single uint64 combined_ref_count for single-atomic deletion fast path
## TL;DR
- Replaces `TVMFFIObject`'s two separate `uint32_t` fields (`strong_ref_count`, `weak_ref_count`) with a single `uint64_t combined_ref_count` that packs strong in the lower 32 bits and weak in the upper 32 bits.
- `DecRef` fast path now uses a single atomic subtract+compare instead of an atomic decrement followed by a separate atomic load of the weak counter, reducing atomic operations on the common deletion path.
- All ref counting operations (`IncRef`, `DecRef`, `IncWeakRef`, `DecWeakRef`, `TryPromoteWeakPtr`, `use_count`) updated across C++ (GCC/MSVC), Cython bindings, and ABI docs.

## Key Exports

```python
# --- TVMFFIObject header (C ABI, c_api.h) ---
# CHANGED: was { uint32_t strong_ref_count; uint32_t weak_ref_count; }
class TVMFFIObject:
    """C-level heap object header. First 24 bytes of every heap-allocated object."""
    combined_ref_count: uint64  # packed: strong in lower 32, weak in upper 32
    # strong_ref_count = combined_ref_count & 0xFFFFFFFF
    # weak_ref_count = (combined_ref_count >> 32) & 0xFFFFFFFF
    # Invariant: layout is 24 bytes total, 8-byte aligned (unchanged)
    # Invariant: equivalent to { uint32_t strong, uint32_t weak } on little-endian
    # Interacts with: Object.IncRef/DecRef/IncWeakRef/DecWeakRef, ObjAllocatorBase
    type_index: int32
    __padding: uint32
    deleter: Callable[[void_ptr, int], None]

# --- Constants (object.h, details namespace) ---
kCombinedRefCountWeakOne: uint64 = 1 << 32        # increment for one weak ref
kCombinedRefCountStrongOne: uint64 = 1             # increment for one strong ref
kCombinedRefCountBothOne: uint64 = (1 << 32) | 1   # initial value: one strong + one weak
kCombinedRefCountMaskUInt32: uint64 = 0xFFFFFFFF    # mask to extract strong count
# Interacts with: Object.DecRef (fast path comparison), ObjAllocatorBase (initialization)

# --- Object (object.h) ---
class Object:
    def use_count(self) -> uint64:  # CHANGED: was int32
        """Returns strong ref count only (lower 32 bits)."""
        return atomic_load_relaxed(self.header_.combined_ref_count) & kCombinedRefCountMaskUInt32
        # Interacts with: WeakObjectPtr.use_count, ObjectPtr.use_count

    def IncRef(self):  # private
        atomic_add_relaxed(self.header_.combined_ref_count, kCombinedRefCountStrongOne)
        # Note: +1 on uint64 only touches lower 32 bits (no carry into weak)

    def DecRef(self):  # private -- optimized two-phase deletion
        count_before = atomic_sub_release(self.header_.combined_ref_count, kCombinedRefCountStrongOne)
        if count_before == kCombinedRefCountBothOne:
            # FAST PATH: both counters were 1, single atomic tells us both are now 0
            # No separate weak counter read needed
            fence_acquire()
            self.header_.deleter(self.header_, kBoth)
        elif (count_before & kCombinedRefCountMaskUInt32) == kCombinedRefCountStrongOne:
            # Strong was 1 (now 0), but weak > 1: external weak refs exist
            fence_acquire()
            self.header_.deleter(self.header_, kStrong)
            # Decrement weak sentinel
            if atomic_sub_release(self.header_.combined_ref_count, kCombinedRefCountWeakOne) == kCombinedRefCountWeakOne:
                fence_acquire()
                self.header_.deleter(self.header_, kWeak)
        # Interacts with: ObjectPtr destructor, TVMFFIObjectDeleterFlagBitMask
        # Invariant: fast path avoids the second atomic entirely (was: decrement strong, then load weak)

    def TryPromoteWeakPtr(self) -> bool:  # private
        """CAS loop on combined_ref_count; checks strong portion via mask."""
        old = atomic_load_relaxed(self.header_.combined_ref_count)
        while (old & kCombinedRefCountMaskUInt32) != 0:
            new = old + kCombinedRefCountStrongOne
            if atomic_cmpxchg(self.header_.combined_ref_count, old, new):
                return True
        return False
        # Interacts with: WeakObjectPtr.lock()

    def IncWeakRef(self):  # private
        atomic_add_relaxed(self.header_.combined_ref_count, kCombinedRefCountWeakOne)

    def DecWeakRef(self):  # private
        if atomic_sub_release(self.header_.combined_ref_count, kCombinedRefCountWeakOne) == kCombinedRefCountWeakOne:
            fence_acquire()
            self.header_.deleter(self.header_, kWeak)
```

## Impact
- API: `Object::use_count()` return type changed from `int32_t` to `uint64_t`. Callers comparing against `int32_t` may need adjustment.
- Behavioral: `DecRef` fast path now avoids a separate atomic load of the weak counter. The common case (no external weak refs, `combined_ref_count == kCombinedRefCountBothOne` before decrement) completes with one fewer atomic operation.
- Flags/config: none
- Data formats/schemas: `TVMFFIObject` binary layout is ABI-compatible on little-endian (same first 8 bytes, just reinterpreted as `uint64_t`). The struct field names in the C header changed.

## Usage Examples
The combined ref count is an internal optimization; usage patterns for `ObjectPtr`, `WeakObjectPtr`, `make_object` are unchanged externally. The key behavioral difference is in `DecRef`:

```cpp
// Before (two atomics on fast path):
//   if (atomic_sub(strong_ref_count, 1) == 1) {
//     if (atomic_load(weak_ref_count) == 1) { deleter(kBoth); }
//     else { deleter(kStrong); atomic_sub(weak_ref_count, 1); ... }
//   }

// After (one atomic on fast path):
//   count_before = atomic_sub(combined_ref_count, 1);  // subtract from lower 32
//   if (count_before == kCombinedRefCountBothOne) { deleter(kBoth); }  // single compare
//   else if ((count_before & mask) == 1) { deleter(kStrong); ... }

// Initialization also simplified:
// Before: ffi_ptr->strong_ref_count = 1; ffi_ptr->weak_ref_count = 1;
// After:  ffi_ptr->combined_ref_count = kCombinedRefCountBothOne;
```
