# Pack strong and weak ref counters into single uint64_t combined_ref_count

## TL;DR
- Replaces `uint32_t strong_ref_count` + `uint32_t weak_ref_count` with `uint64_t combined_ref_count` in `TVMFFIObject`, packing both counters into one field (strong in lower 32 bits, weak in upper 32 bits).
- Enables single-atomic fast path in `DecRef`: when `combined_ref_count == kCombinedRefCountBothOne`, one atomic decrement handles both counters, avoiding a separate weak counter read.
- All reference counting operations (`IncRef`, `DecRef`, `IncWeakRef`, `DecWeakRef`, `TryPromoteWeakPtr`, `use_count`) updated to use 64-bit atomics on the combined field.

## Key Exports

**Struct layout change** (`TVMFFIObject`, 24 bytes):

| Offset | Before | After |
|--------|--------|-------|
| 0 | `uint32_t strong_ref_count` | `uint64_t combined_ref_count` |
| 4 | `uint32_t weak_ref_count` | (part of combined_ref_count) |
| 8 | `int32_t type_index` | `int32_t type_index` |
| 12 | `uint32_t __padding` | `uint32_t __padding` |

**Constants** (in `tvm::ffi::details`):
- `kCombinedRefCountWeakOne = 1ULL << 32` -- one weak reference increment
- `kCombinedRefCountStrongOne = 1` -- one strong reference increment
- `kCombinedRefCountBothOne = kCombinedRefCountWeakOne | kCombinedRefCountStrongOne`
- `kCombinedRefCountMaskUInt32 = (1ULL << 32) - 1` -- mask to extract strong count

**Methods changed**:
- `Object::use_count() -> uint64_t` (was `int32_t`) -- returns only strong count via mask

## Impact
- API: `use_count()` return type changed from `int32_t` to `uint64_t`.
- ABI: **Breaking**. `TVMFFIObject` first field changed from two `uint32_t` to one `uint64_t`. Cython `base.pxi` updated.
- Behavioral: `DecRef` fast path: when both strong and weak are 1, a single atomic decrement + compare triggers combined deletion (`kTVMFFIObjectDeleterFlagBitMaskBoth`), saving one atomic operation.
- Flags/config: none
- Data formats/schemas: none
