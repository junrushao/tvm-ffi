# Pack strong and weak ref counters into single u64 combined_ref_count atomic
## TL;DR
- Replaces separate `strong_ref_count` (u32) and `weak_ref_count` (u32) with a single `uint64_t combined_ref_count` field. Lower 32 bits = strong, upper 32 bits = weak.
- `DecRef` now reads both counters in a single atomic, enabling a fast path: if `count_before_sub == kCombinedRefCountBothOne`, both counters transition to zero simultaneously, and the deleter is called once with `kTVMFFIObjectDeleterFlagBitMaskBoth` -- eliminating the extra atomic read of weak count during the common case deletion.
- All atomic operations (`IncRef`, `DecRef`, `IncWeakRef`, `DecWeakRef`, `TryPromoteWeakPtr`, `use_count`) are rewritten to operate on the combined u64 field using offset constants (`kCombinedRefCountStrongOne = 1`, `kCombinedRefCountWeakOne = 1 << 32`).
- Bumps package version to `0.1.0b8`.

## Impact
- API: ABI-breaking change to `TVMFFIObject` -- `strong_ref_count`/`weak_ref_count` replaced by `combined_ref_count`. All compiled code must be recompiled.
- API: `Object::use_count()` return type changes from `int32_t` to `uint64_t`.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- **TVMFFIObject header layout** ([`.knowledge/designs/0003-object-system.md`](../designs/0003-object-system.md)): Builds on the previous reorder (commit `13436f0`) that placed ref counters at offset 0.
- **Two-phase destruction protocol** ([`.knowledge/designs/0003-object-system.md`](../designs/0003-object-system.md)): The three-way flag dispatch (`Strong`, `Weak`, `Both`) is preserved; the optimization is in *how* the strong decrement detects zero-weak.

Design elements this commit produces:
- **Combined ref-count single-atomic fast path**: The common case (no weak references) is now handled with exactly one atomic decrement + one branch, eliminating the second atomic load/sub on `weak_ref_count`. Constants: `kCombinedRefCountBothOne = (1ULL << 32) | 1`, `kCombinedRefCountStrongOne = 1`, `kCombinedRefCountWeakOne = 1ULL << 32`, `kCombinedRefCountMaskUInt32 = 0xFFFFFFFF`.
