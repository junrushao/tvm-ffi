# Collapse TVMFFIObject ref counters into a single uint64_t combined_ref_count for one-atomic deletion

## TL;DR

- `TVMFFIObject` header field layout changed: two `uint32_t` fields (`strong_ref_count`, `weak_ref_count`) replaced by one `uint64_t combined_ref_count`; strong occupies the lower 32 bits, weak the upper 32 bits.
- `DecRef()` fast path now requires only **one** atomic fetch-sub (on the full 64-bit word) to detect the common case where both counts drop to zero simultaneously, eliminating the separate weak-counter read.
- All callers updated across C++ (`object.h`, `memory.h`), C ABI (`c_api.h`), Cython (`base.pxi`), and documentation (`abi_overview.md`); version bumped to `0.1.0b8`.

## Key Exports

```python
# C ABI struct (24-byte header, layout unchanged)
class TVMFFIObject:
    combined_ref_count: uint64_t  # offset 0 — was: strong_ref_count(u32) | weak_ref_count(u32)
    # - strong_ref_count = combined_ref_count & 0xFFFFFFFF
    # - weak_ref_count   = (combined_ref_count >> 32) & 0xFFFFFFFF
    # Invariant: every new object starts with combined_ref_count = kCombinedRefCountBothOne (0x0000000100000001)
    # Interacts with: Object::IncRef, Object::DecRef, Object::IncWeakRef, Object::DecWeakRef,
    #                 Object::TryPromoteWeakPtr, ObjAllocatorBase::make, ObjAllocatorBase::make_array
    type_index: int32_t           # offset 8
    __padding: uint32_t           # offset 12
    deleter: Callable             # offset 16

# Constants in namespace tvm::ffi::details (also mirrored as Object private statics)
kCombinedRefCountWeakOne:   uint64_t = 1 << 32       # increment/decrement unit for weak counter
kCombinedRefCountStrongOne: uint64_t = 1              # increment/decrement unit for strong counter
kCombinedRefCountBothOne:   uint64_t = (1 << 32) | 1 # initial value after allocation
kCombinedRefCountMaskUInt32: uint64_t = (1 << 32) - 1 # mask to isolate strong count

class Object:
    # use_count() now returns uint64_t (was int32_t); caller must mask to get strong count
    def use_count(self) -> uint64_t:
        return AtomicLoadRelaxed(header_.combined_ref_count) & kCombinedRefCountMaskUInt32
    # Interacts with: ObjectPtr<T> (shared_ptr-like), WeakObjectPtr<T>

    # IncRef: single u64 atomic add of kCombinedRefCountStrongOne (== 1)
    def IncRef(self) -> None:
        AtomicFetchAdd(header_.combined_ref_count, kCombinedRefCountStrongOne, RELAXED)

    # DecRef: one atomic covers common path
    def DecRef(self) -> None:
        count_before = AtomicFetchSub(header_.combined_ref_count, kCombinedRefCountStrongOne, RELEASE)
        if count_before == kCombinedRefCountBothOne:
            # fast path: strong=1→0 and weak=1→0 simultaneously — call deleter(kBoth)
            header_.deleter(self, kTVMFFIObjectDeleterFlagBitMaskBoth)
        elif (count_before & kCombinedRefCountMaskUInt32) == kCombinedRefCountStrongOne:
            # strong=1→0, but weak>1 — call deleter(kStrong), then dec weak
            header_.deleter(self, kTVMFFIObjectDeleterFlagBitMaskStrong)
            if AtomicFetchSub(header_.combined_ref_count, kCombinedRefCountWeakOne, RELEASE) == kCombinedRefCountWeakOne:
                header_.deleter(self, kTVMFFIObjectDeleterFlagBitMaskWeak)
        # Invariant: if strong count was already 0 before this call, nothing happens (caller bug)

    # IncWeakRef / DecWeakRef: use kCombinedRefCountWeakOne as step (upper 32 bits)
    def IncWeakRef(self) -> None:
        AtomicFetchAdd(header_.combined_ref_count, kCombinedRefCountWeakOne, RELAXED)
    def DecWeakRef(self) -> None:
        if AtomicFetchSub(header_.combined_ref_count, kCombinedRefCountWeakOne, RELEASE) == kCombinedRefCountWeakOne:
            header_.deleter(self, kTVMFFIObjectDeleterFlagBitMaskWeak)

    # TryPromoteWeakPtr: CAS loop operates on combined_ref_count, masking lower 32 bits for check
    def TryPromoteWeakPtr(self) -> bool:
        old = AtomicLoad(header_.combined_ref_count, RELAXED)
        while (old & kCombinedRefCountMaskUInt32) != 0:
            if CAS(header_.combined_ref_count, old, old + kCombinedRefCountStrongOne, ACQ_REL):
                return True
        return False
        # Invariant: CAS on full u64 — concurrent weak count changes do not interfere with strong CAS

# Allocation — ObjAllocatorBase::make and make_array
def make_object(T, *args) -> ObjectPtr[T]:
    ptr = Handler.New(T, *args)
    ptr.header_.combined_ref_count = kCombinedRefCountBothOne  # was: strong=1; weak=1 separately
    ptr.header_.type_index = T.RuntimeTypeIndex()
    ptr.header_.deleter = Handler.Deleter()
    return ObjectPtr(ptr)
```

## Impact

- API: **ABI-breaking change** — `TVMFFIObject.strong_ref_count` and `TVMFFIObject.weak_ref_count` fields are gone; replaced by `combined_ref_count`. Any external code reading/writing these fields by name (in C, C++, or Cython) must be updated. The struct's total size and field offsets for `type_index` and `deleter` are **unchanged** (still 24 bytes).
- Behavioral: `Object::use_count()` return type changed from `int32_t` to `uint64_t`; callers comparing against signed values should be updated (practically no semantic change since the masked lower 32 bits are the strong count).
- Flags/config: none.
- Data formats/schemas: The in-memory object header layout changes at offset 0 (8 bytes were two `uint32_t`, now one `uint64_t`). Serialized object graphs are unaffected (headers are never serialized). Dynamic library ABI is broken for any consumer that directly accessed `strong_ref_count` or `weak_ref_count` by field.

## Usage Examples

Before/after for the common `DecRef` path (performance context):

```cpp
// BEFORE (two separate atomics in common case):
if (__atomic_fetch_sub(&header_.strong_ref_count, 1, __ATOMIC_RELEASE) == 1) {
    if (__atomic_load_n(&header_.weak_ref_count, __ATOMIC_RELAXED) == 1) {
        // common path: separate read of weak counter
        header_.deleter(&header_, kTVMFFIObjectDeleterFlagBitMaskBoth);
    }
}

// AFTER (single atomic covers common case):
uint64_t count_before = __atomic_fetch_sub(&header_.combined_ref_count,
                                           kCombinedRefCountStrongOne, __ATOMIC_RELEASE);
if (count_before == kCombinedRefCountBothOne) {
    // common path: both counts were 1 → no separate weak read needed
    __atomic_thread_fence(__ATOMIC_ACQUIRE);
    header_.deleter(&header_, kTVMFFIObjectDeleterFlagBitMaskBoth);
}
```

Object allocation initialization:
```cpp
// BEFORE:
ffi_ptr->strong_ref_count = 1;
ffi_ptr->weak_ref_count = 1;

// AFTER:
ffi_ptr->combined_ref_count = kCombinedRefCountBothOne;  // 0x0000000100000001
```
