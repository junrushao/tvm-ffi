# Add yamllint, markdownlint-cli2, and rstcheck linters to pre-commit
## TL;DR
- Adds three new pre-commit hooks: `yamllint` (v1.35.1), `markdownlint-cli2` (v0.14.0), and `rstcheck` (v6.2.4) with their corresponding config files.
- Cleans up existing documentation (`.md`, `.rst`) and YAML config files to pass the new linter rules: blank lines before lists, code fence language tags (`bash`/`text` instead of bare fences), consistent list indentation, and trailing whitespace in YAML.
- Adds `.cfg` to the allowed file extension list in `tests/lint/check_file_type.py` to accommodate `docs/.rstcheck.cfg`.
