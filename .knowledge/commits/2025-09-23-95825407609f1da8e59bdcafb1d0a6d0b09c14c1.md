# Add markdownlint, yamllint, and rstcheck linters to pre-commit

## TL;DR
- Adds three new pre-commit hooks: `yamllint`, `markdownlint-cli2`, and `rstcheck` with their configuration files (`.yamllint.yaml`, `.markdownlint-cli2.yaml`, `docs/.rstcheck.cfg`).
- Fixes existing Markdown and YAML files to comply with the new linters: removes extra blank lines, adds blank lines before lists and code blocks, fixes list indentation, and corrects fenced code block language annotations (e.g., bare ` ``` ` to ` ```text ` or ` ```bash `).
- Adds `.cfg` to the allowed file extensions in `tests/lint/check_file_type.py`.
