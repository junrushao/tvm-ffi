# Add yamllint, markdownlint-cli2, and rstcheck linters to pre-commit
## TL;DR
- Adds three new pre-commit hooks: `yamllint` (v1.35.1), `markdownlint-cli2` (v0.14.0), and `rstcheck` (v6.2.4) with their config files.
- Applies formatting fixes across 8 doc files and 3 config files to satisfy the new linters (blank-line spacing, code fence language tags, list indentation, trailing whitespace in YAML).
- Adds `.cfg` to the allowed file extensions in `tests/lint/check_file_type.py` to permit the new `docs/.rstcheck.cfg`.
