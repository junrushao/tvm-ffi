# Add markdownlint, yamllint, and rstcheck linters to pre-commit workflow
## TL;DR
- Adds three new pre-commit hooks: `yamllint` (v1.35.1), `markdownlint-cli2` (v0.14.0), and `rstcheck` (v6.2.4) with corresponding config files.
- Fixes existing markdown, YAML, and RST docs to comply with the new lint rules (blank lines around lists/fenced blocks, language tags on code fences, consistent indentation, removal of extraneous blank lines).
- Adds `.cfg` to the allowed file extension set in `check_file_type.py` to accommodate the new `docs/.rstcheck.cfg`.

## Impact
- API: none
- Behavioral: none
- Flags/config: Three new config files control the new linters:
  - `.yamllint.yaml` -- extends `default`, disables `document-start`, sets `line-length` max 120 (warning), allows common truthy values.
  - `.markdownlint-cli2.yaml` -- disables `MD013` (line length) rule.
  - `docs/.rstcheck.cfg` -- `report_level=warning`, ignores `automodule`/`autosummary`/`currentmodule`/`toctree`/`ifconfig` directives and `ref`/`cpp:class`/`cpp:func`/`py:func` roles.
