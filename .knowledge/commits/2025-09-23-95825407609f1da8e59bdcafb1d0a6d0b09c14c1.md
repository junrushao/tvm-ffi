# Add YAML, Markdown, and RST linters to pre-commit with initial doc cleanup

## TL;DR

- Introduces three new pre-commit hooks: `yamllint` (v1.35.1), `markdownlint-cli2` (v0.14.0), and `rstcheck` (v6.2.4 with Sphinx support).
- Adds config files for each new linter (`.yamllint.yaml`, `.markdownlint-cli2.yaml`, `docs/.rstcheck.cfg`).
- Cleans up existing docs (`docs/`, `examples/`) and config files (`.asf.yaml`, `.clang-format`) to satisfy the new lint rules; adds `cfg` to allowed file extensions in `check_file_type.py`.

- Behavioral: none — lint-only, no runtime behavior changed
- Flags/config: Three new lint config files added to repo root and `docs/`:

  - `docs/.rstcheck.cfg`: warning-level; ignores Sphinx directives (`automodule`, `autosummary`, `currentmodule`, `toctree`, `ifconfig`) and roles (`ref`, `cpp:class`, `cpp:func`, `py:func`)
