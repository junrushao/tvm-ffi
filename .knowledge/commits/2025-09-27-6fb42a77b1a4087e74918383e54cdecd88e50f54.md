# Replace new/delete with raw aligned alloc/free in object allocator
## TL;DR
- Replaces `new StorageType()` / `delete` with `AlignedAlloc<alignof(T)>(sizeof(T))` / `AlignedFree` in `SimpleObjAllocator`, eliminating the intermediate `StorageType` struct and `StorageType[]` array.
- For inplace arrays, allocation size is now `sizeof(ArrayType) + sizeof(ElemType) * num_elems` rounded up to alignment, instead of `num_storage_slots * sizeof(StorageType)`. This reduces over-allocation.
- Introduces `details::AlignedAlloc<align>` (uses `malloc` for standard alignment, `posix_memalign` otherwise, `_aligned_malloc` on MSVC) and `details::AlignedFree`.
