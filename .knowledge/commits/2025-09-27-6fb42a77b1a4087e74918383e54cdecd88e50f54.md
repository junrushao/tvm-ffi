# Replace new/delete with raw aligned alloc in SimpleObjAllocator
## TL;DR
- Introduces `details::AlignedAlloc<align>(size)` and `details::AlignedFree(data)` as platform-abstracted raw memory allocation primitives, replacing C++ `new`/`delete` in `SimpleObjAllocator`.
- Removes `StorageType` wrapper structs from both `Handler<T>` and `ArrayHandler<ArrayType, ElemType>`, eliminating the `std::aligned_storage` usage and rounding-to-`sizeof(StorageType)` waste in inplace array allocation.
- Inplace array allocation now computes exact `sizeof(ArrayType) + sizeof(ElemType) * num_elems`, rounded up to `alignof(ArrayType)` boundary, reducing total allocation size.

## Key Exports

```python
# namespace tvm::ffi::details

def AlignedAlloc(size: int) -> void_ptr:
    """Allocate aligned memory."""
    # Template parameter: align (must be power of 2, compile-time)
    # Platform dispatch:
    #   MSVC: _aligned_malloc(size, align)
    #   Non-MSVC, align <= alignof(max_align_t): std::malloc(size)
    #   Non-MSVC, align > alignof(max_align_t): posix_memalign(&ptr, align, size)
    # Invariant: align must be a power of 2 (static_assert enforced)
    # Invariant: throws std::bad_alloc on failure (never returns nullptr)
    # Interacts with: SimpleObjAllocator::Handler::New, SimpleObjAllocator::ArrayHandler::New
    ...

def AlignedFree(data: void_ptr) -> None:
    """Free aligned memory."""
    # Platform dispatch:
    #   MSVC: _aligned_free(data)
    #   Non-MSVC: std::free(data)
    # Interacts with: SimpleObjAllocator::Handler::Deleter_, SimpleObjAllocator::ArrayHandler::Deleter_
    ...

class SimpleObjAllocator:
    class Handler(Generic[T]):
        # REMOVED: StorageType = alignas(T) char[sizeof(T)]
        # NOW: allocates via AlignedAlloc<alignof(T)>(sizeof(T))

        def New(allocator, *args) -> T:
            data = AlignedAlloc[alignof(T)](sizeof(T))  # was: new StorageType()
            placement_new(data, T, *args)
            return reinterpret_cast[T](data)

        def Deleter_(objptr: void_ptr, flags: int):
            # kStrong: call T::~T()
            # kWeak: AlignedFree(tptr)  # was: delete reinterpret_cast<StorageType*>(tptr)
            ...

    class ArrayHandler(Generic[ArrayType, ElemType]):
        # REMOVED: StorageType = std::aligned_storage<sizeof(ArrayType), alignof(ArrayType)>
        # REMOVED: static_assert alignment constraint (moved into New method)
        # NOW: exact size calculation with alignment rounding

        def New(allocator, num_elems: int, *args) -> ArrayType:
            # Invariant: alignof(ArrayType) % alignof(ElemType) == 0
            # Invariant: sizeof(ArrayType) % alignof(ElemType) == 0
            size = sizeof(ArrayType) + sizeof(ElemType) * num_elems
            align = alignof(ArrayType)
            aligned_size = (size + (align - 1)) & ~(align - 1)
            # was: num_storage_slots = ceil(size / sizeof(StorageType)); new StorageType[num_storage_slots]
            data = AlignedAlloc[align](aligned_size)
            placement_new(data, ArrayType, *args)
            return reinterpret_cast[ArrayType](data)

        def Deleter_(objptr: void_ptr, flags: int):
            # kWeak: AlignedFree(tptr)  # was: delete[] reinterpret_cast<StorageType*>(tptr)
            ...
```

## Impact
- API: None -- `AlignedAlloc`/`AlignedFree` are internal to `details` namespace. Public `make_object<T>()` and `make_inplace_array_object<ArrayType, ElemType>()` signatures unchanged.
- Behavioral: Inplace array allocation size reduced. Previously rounded up to multiples of `sizeof(StorageType)` (which is `sizeof(ArrayType)`); now rounds up to multiples of `alignof(ArrayType)` only. For typical containers where `sizeof(ArrayType) >> alignof(ArrayType)`, this significantly reduces wasted trailing bytes.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- `SimpleObjAllocator` CRTP pattern with `Handler<T>` and `ArrayHandler<ArrayType, ElemType>` ([0003-ffi-object-system](../design-records/0003-ffi-object-system.md))
- `FObjectDeleter` two-phase deletion protocol with `kStrong`/`kWeak`/`kBoth` flags ([0003-ffi-object-system](../design-records/0003-ffi-object-system.md))
- `ObjectUnsafe::RawObjectPtrFromUnowned` for deleter-internal type recovery ([0003-ffi-object-system](../design-records/0003-ffi-object-system.md))

Design elements this commit produces:
- `details::AlignedAlloc<align>(size)` -- platform-portable aligned allocation primitive with compile-time alignment, `constexpr if` dispatch, and `std::bad_alloc` guarantee
- `details::AlignedFree(data)` -- matching deallocation primitive with MSVC/POSIX dispatch

Design elements this commit mutates:
- `SimpleObjAllocator::Handler<T>` -- removed `StorageType` wrapper, allocation now via `AlignedAlloc<alignof(T)>(sizeof(T))` + placement new, deallocation via `AlignedFree`
- `SimpleObjAllocator::ArrayHandler<ArrayType, ElemType>` -- removed `StorageType` and `std::aligned_storage`, moved `static_assert` into `New()`, allocation size calculation changed from `ceil(requested / sizeof(StorageType)) * sizeof(StorageType)` to `(size + align - 1) & ~(align - 1)`

## Usage Examples
Allocation behavior change for inplace arrays (e.g., `ArrayObj` with 3 int64 elements):

```cpp
// Before: StorageType = aligned_storage<sizeof(ArrayObj), alignof(ArrayObj)>
// Suppose sizeof(ArrayObj) = 48, alignof(ArrayObj) = 8
// requested_size = 3 * 8 + 48 = 72
// num_storage_slots = ceil(72 / 48) = 2
// allocated = 2 * 48 = 96 bytes (24 bytes wasted)

// After: AlignedAlloc
// size = 48 + 3 * 8 = 72
// aligned_size = (72 + 7) & ~7 = 72 (0 bytes wasted)
```
