# Replace StorageType new/delete with raw AlignedAlloc/AlignedFree in SimpleObjAllocator
## TL;DR
- Introduces `details::AlignedAlloc<align>(size)` and `details::AlignedFree(data)` as platform-aware aligned allocation helpers (MSVC `_aligned_malloc`/`_aligned_free` vs POSIX `malloc`/`posix_memalign`/`free`).
- Replaces `Handler<T>::StorageType` (aligned struct) + `new`/`delete` with `AlignedAlloc<alignof(T)>(sizeof(T))` + `AlignedFree`, eliminating the intermediate type entirely.
- Replaces `ArrayHandler::StorageType` slot-based allocation (rounding to `sizeof(ArrayType)` multiples) with direct byte-level allocation rounded to `alignof(ArrayType)`, reducing wasted memory for inplace arrays.

## Key Exports

**Function**: `details::AlignedAlloc<align>(size_t size) -> void*` (`include/tvm/ffi/memory.h`):
```cpp
template <size_t align>
TVM_FFI_INLINE void* AlignedAlloc(size_t size);
```
- `align` must be a power of 2 (compile-time enforced via `static_assert`).
- On non-MSVC: delegates to `std::malloc` when `align <= alignof(std::max_align_t)`, else `posix_memalign`.
- On MSVC: delegates to `_aligned_malloc`.
- Throws `std::bad_alloc` on failure.

**Function**: `details::AlignedFree(void* data) -> void` (`include/tvm/ffi/memory.h`):
```cpp
TVM_FFI_INLINE void AlignedFree(void* data);
```
- On non-MSVC: delegates to `std::free`. On MSVC: delegates to `_aligned_free`.

**Removed**: `SimpleObjAllocator::Handler<T>::StorageType` struct — `struct alignas(T) StorageType { char data[sizeof(T)]; }` is eliminated.

**Removed**: `SimpleObjAllocator::ArrayHandler<ArrayType, ElemType>::StorageType` alias — `std::aligned_storage<sizeof(ArrayType), alignof(ArrayType)>::type` is eliminated.

**Changed**: `ArrayHandler` alignment constraint `static_assert` moved from class scope to function scope (inside `New`), no semantic change.

**Changed**: `ArrayHandler::New` size computation:
```cpp
// Before: round up to sizeof(StorageType) multiples
size_t unit = sizeof(StorageType);
size_t requested_size = num_elems * sizeof(ElemType) + sizeof(ArrayType);
size_t num_storage_slots = (requested_size + unit - 1) / unit;
StorageType* data = new StorageType[num_storage_slots];

// After: round up to alignof(ArrayType) multiples
size_t size = sizeof(ArrayType) + sizeof(ElemType) * num_elems;
constexpr size_t align = alignof(ArrayType);
size_t aligned_size = (size + (align - 1)) & ~(align - 1);
void* data = AlignedAlloc<align>(aligned_size);
```

## Impact
- API: None externally. `AlignedAlloc`/`AlignedFree` are in `details` namespace (internal). `make_object` and `make_inplace_array_object` signatures unchanged.
- Behavioral: Inplace array allocations now use less memory. Previously rounded to `sizeof(ArrayType)` granularity (often 32-64+ bytes), now rounds to `alignof(ArrayType)` granularity (typically 8 bytes). For example, if `sizeof(ArrayType)=48` and you allocate 3 elements of 8 bytes each: before = `ceil(72/48)*48 = 96`; after = `ceil(72/8)*8 = 72`.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples
The public API (`make_object`, `make_inplace_array_object`) is unchanged, so usage is identical:
```cpp
// Object allocation (unchanged API, now uses AlignedAlloc internally)
ObjectPtr<TIntObj> ptr = make_object<TIntObj>(42);

// Inplace array allocation (unchanged API, now allocates tighter)
ObjectPtr<ArrayObj> arr = make_inplace_array_object<ArrayObj, Any>(10);
// Before: allocated ceil((sizeof(ArrayObj) + 10*sizeof(Any)) / sizeof(ArrayObj)) * sizeof(ArrayObj)
// After:  allocated ceil((sizeof(ArrayObj) + 10*sizeof(Any)) / alignof(ArrayObj)) * alignof(ArrayObj)
```
