# Replace StorageType wrapper with raw aligned allocation in SimpleObjAllocator

## TL;DR
- Introduces `details::AlignedAlloc<align>(size)` and `details::AlignedFree(void*)` as portable cross-platform helpers for aligned heap allocation (MSVC: `_aligned_malloc`/`_aligned_free`; POSIX: `malloc` when `align ≤ alignof(max_align_t)`, `posix_memalign` otherwise).
- Removes the `StorageType` wrapper structs from both `Handler` (scalar objects) and `ArrayHandler` (inline-array objects) inside `SimpleObjAllocator`, replacing `new StorageType()` / `new StorageType[n]` with direct `AlignedAlloc` calls.
- For `ArrayHandler`, the allocation size shrinks from `ceil(sizeof(ArrayType)+ElemSize*n, sizeof(ArrayType)) * sizeof(ArrayType)` (rounded up to whole `ArrayType` units) to `ceil(sizeof(ArrayType)+ElemSize*n, alignof(ArrayType))` (rounded up to array alignment only) — saving up to `sizeof(ArrayType) - alignof(ArrayType)` bytes per allocation in the common case.

## Key Exports

```python
# New internal helpers in tvm::ffi::details (include/tvm/ffi/memory.h)

def AlignedAlloc(align: size_t, size: size_t) -> void*:
    """Allocate `size` bytes with alignment `align` (must be power of 2).
    # Invariant: align must be a power of 2 (enforced by static_assert)
    # Invariant: throws std::bad_alloc on allocation failure (never returns nullptr)
    # Interacts with: SimpleObjAllocator::Handler::New, SimpleObjAllocator::ArrayHandler::New
    # Platform: MSVC uses _aligned_malloc; POSIX uses malloc (align<=max_align_t) or posix_memalign
    """
    ...

def AlignedFree(data: void*) -> None:
    """Free memory allocated by AlignedAlloc.
    # Invariant: must only be called on pointers from AlignedAlloc (not new/malloc)
    # Interacts with: SimpleObjAllocator::Handler::Deleter_, SimpleObjAllocator::ArrayHandler::Deleter_
    # Platform: MSVC uses _aligned_free; POSIX uses std::free
    """
    ...

# Changed: SimpleObjAllocator::Handler (scalar object allocation)
class SimpleObjAllocator_Handler(Generic[T]):
    """Allocator handler for plain Objects (non-array)."""

    @staticmethod
    def New(allocator, *args) -> T*:
        # Old: StorageType = struct alignas(T) { char data[sizeof(T)]; }
        #      data = new StorageType()
        # New:
        data = AlignedAlloc[alignof(T)](sizeof(T))
        new (data) T(*args)  # placement-new
        return reinterpret_cast[T*](data)
        # Interacts with: ObjAllocatorBase::make, Object header initialization in make_object<T>

    @staticmethod
    def Deleter_(objptr: void*, flags: int) -> None:
        tptr = ObjectUnsafe.RawObjectPtrFromUnowned[T](static_cast[TVMFFIObject*](objptr))
        if flags & kTVMFFIObjectDeleterFlagBitMaskStrong:
            tptr.T.__dtor__()
        if flags & kTVMFFIObjectDeleterFlagBitMaskWeak:
            # Old: delete reinterpret_cast<StorageType*>(tptr)
            # New:
            AlignedFree(static_cast[void*](tptr))
        # Interacts with: ObjectPtr<T>::DecRef (calls deleter via header_.deleter field)

# Changed: SimpleObjAllocator::ArrayHandler (inline-array object allocation)
class SimpleObjAllocator_ArrayHandler(Generic[ArrayType, ElemType]):
    """Allocator handler for InplaceArrayBase-derived Objects with inline element storage."""
    # Invariant: alignof(ArrayType) % alignof(ElemType) == 0
    # Invariant: sizeof(ArrayType) % alignof(ElemType) == 0
    # (enforced by static_assert — moved from class scope to New() body in this commit)

    @staticmethod
    def New(allocator, num_elems: size_t, *args) -> ArrayType*:
        # Old: StorageType = aligned_storage<sizeof(ArrayType), alignof(ArrayType)>
        #      unit = sizeof(StorageType)  # == sizeof(ArrayType)
        #      requested = num_elems * sizeof(ElemType) + sizeof(ArrayType)
        #      slots = ceil(requested, unit)
        #      data = new StorageType[slots]  # over-allocated by up to sizeof(ArrayType)-1 bytes
        # New (tighter allocation):
        size = sizeof(ArrayType) + sizeof(ElemType) * num_elems
        align = alignof(ArrayType)
        aligned_size = (size + (align - 1)) & ~(align - 1)  # round up to alignment, not ArrayType size
        data = AlignedAlloc[align](aligned_size)
        new (data) ArrayType(*args)
        return reinterpret_cast[ArrayType*](data)
        # Interacts with: InplaceArrayBase<ArrayType,ElemType> (element storage follows header)
        # Invariant: element region starts at data+sizeof(ArrayType), aligned by ElemType

    @staticmethod
    def Deleter_(objptr: void*, flags: int) -> None:
        tptr = ObjectUnsafe.RawObjectPtrFromUnowned[ArrayType](static_cast[TVMFFIObject*](objptr))
        if flags & kTVMFFIObjectDeleterFlagBitMaskStrong:
            tptr.ArrayType.__dtor__()
        if flags & kTVMFFIObjectDeleterFlagBitMaskWeak:
            # Old: p = reinterpret_cast<StorageType*>(tptr); delete[] p
            # New:
            AlignedFree(static_cast[void*](tptr))
```

## Impact
- API: None — `AlignedAlloc`/`AlignedFree` are in `tvm::ffi::details::` (internal namespace). `make_object<T>` and `make_inplace_array_object<T,E>` public signatures are unchanged.
- Behavioral: Objects and inline-array objects are now allocated with exact required sizes. For `ArrayHandler`, allocations are smaller by `O(sizeof(ArrayType))` worst-case per allocation. No change to object layout or ABI.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

Before/after for the `ArrayHandler` allocation — showing the size calculation change:

```cpp
// BEFORE (commit parent): over-allocation rounded to sizeof(ArrayType) units
using StorageType = typename std::aligned_storage<sizeof(ArrayType), alignof(ArrayType)>::type;
size_t unit = sizeof(StorageType);  // == sizeof(ArrayType), e.g. 48 bytes for ShapeObj
size_t requested_size = num_elems * sizeof(ElemType) + sizeof(ArrayType);
size_t num_slots = (requested_size + unit - 1) / unit;
StorageType* data = new StorageType[num_slots];  // e.g. 1 elem → 2 slots = 96 bytes

// AFTER (this commit): allocation rounded to alignof(ArrayType) only
size_t size = sizeof(ArrayType) + sizeof(ElemType) * num_elems;  // e.g. 48 + 8*1 = 56
constexpr size_t align = alignof(ArrayType);  // e.g. 8
size_t aligned_size = (size + (align - 1)) & ~(align - 1);  // e.g. 56 bytes (already aligned)
void* data = AlignedAlloc<align>(aligned_size);  // saves ~40 bytes vs before for 1-elem Shape
```
