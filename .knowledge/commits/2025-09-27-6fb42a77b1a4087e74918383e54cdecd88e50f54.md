# Replace StorageType-based allocation with raw aligned alloc in memory module
## TL;DR
- Introduces `AlignedAlloc<align>(size)` and `AlignedFree(data)` template helpers replacing `new StorageType` / `new StorageType[]` allocation patterns.
- `SimpleObjAllocator::Handler` now uses raw aligned allocation, removing the `StorageType` wrapper struct.
- `ArrayHandler` computes exact aligned size instead of rounding up to `StorageType` multiples, reducing wasted memory for inplace arrays.

## Impact
- API: None (internal allocator change)
- Behavioral: Allocation size for inplace arrays is now exact-aligned rather than rounded to StorageType multiples. Reduces memory waste.
- Flags/config: None
- Data formats/schemas: None
