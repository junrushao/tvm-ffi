# Replace new/delete with raw aligned alloc/free in SimpleObjAllocator

## TL;DR
- Replaces `new StorageType` / `delete StorageType` in `SimpleObjAllocator` with `AlignedAlloc<alignof(T)>(sizeof(T))` / `AlignedFree(ptr)`, using raw memory allocation with explicit alignment.
- Removes `StorageType` wrappers (`alignas(T) char data[sizeof(T)]`) that were used to satisfy alignment.
- Adds `details::AlignedAlloc<align>(size)` and `details::AlignedFree(data)` utility functions with platform-specific implementations (MSVC: `_aligned_malloc`/`_aligned_free`; POSIX: `malloc` for small alignment, `posix_memalign` for larger).
- `ArrayHandler` similarly updated: removes `std::aligned_storage`-based allocation, uses `AlignedAlloc` with correct size rounding.

## Key Exports

**Functions** (in `tvm::ffi::details`):
- `template <size_t align> void* AlignedAlloc(size_t size)` -- aligned memory allocation. `align` must be power of 2. Uses `malloc` when `align <= alignof(std::max_align_t)`, `posix_memalign` otherwise. MSVC uses `_aligned_malloc`.
- `void AlignedFree(void* data)` -- frees memory allocated by `AlignedAlloc`. MSVC uses `_aligned_free`, others use `std::free`.

## Impact
