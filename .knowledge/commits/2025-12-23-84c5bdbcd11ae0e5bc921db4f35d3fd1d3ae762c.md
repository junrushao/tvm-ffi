# Support dynamic-style overload for FFI object types
## TL;DR
- Introduces `include/tvm/ffi/reflection/overload.h` providing dynamic-dispatch overload resolution for FFI object methods based on argument types.
- Extends the reflection registry to support overloaded method definitions via the new overload infrastructure.
- Adds comprehensive C++ tests in `tests/cpp/test_overload.cc`.

## Impact
- API: New public header `overload.h` with overload resolution API for C++ consumers.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Function system** (`.knowledge/designs/0004-function-system.md`): Overloads are dispatched through the packed function calling convention.
- **Reflection** (`.knowledge/designs/0006-reflection.md`): Extends `ObjectDef<T>` with overloaded method support.

Design elements this commit produces:
- **Overload resolution**: New design element for type-based dynamic dispatch of FFI methods. Located in `include/tvm/ffi/reflection/overload.h`.
