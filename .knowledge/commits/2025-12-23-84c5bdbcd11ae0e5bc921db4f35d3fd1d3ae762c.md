# Add dynamic-style method overloading for FFI object type reflection
## TL;DR
- Introduces `OverloadObjectDef<T>`, a new reflection builder that extends `ObjectDef<T>` with method overloading support. Methods and constructors registered with the same name are dispatched at runtime based on argument count and type.
- Adds `Function::FromPackedInplace<TCallable>` to construct a `Function` while retaining a typed pointer to the internal callable, enabling the overload registry to attach new overloads after construction.
- Generalizes `FunctionObjImpl<TCallable>` constructor from dual overloads (rvalue/lvalue) to a single variadic template forwarding constructor, and exposes `GetCallable()` accessor.

## Impact
- API: Additive. New `OverloadObjectDef<T>` builder and `Function::FromPackedInplace` static method. Existing `ObjectDef<T>` unchanged.
- Behavioral: Methods registered via `OverloadObjectDef` dispatch dynamically by argument type. If no overload matches, a `TypeError` is thrown listing all candidates and their mismatch reasons.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `ObjectDef<T>` builder and its registration machinery (`0007-ffi-reflection`): `OverloadObjectDef` inherits privately from `ObjectDef` and reuses `RegisterExtraInfo`, `RegisterField`, field/method info builders, `type_index_`, `type_key_`.
- `FunctionObjImpl<TCallable>` and `Function` construction patterns (`0004-ffi-function-system`): extended with variadic constructor and `FromPackedInplace`.
- `ReflectionDefBase::GetMethod` and member-function wrapping logic (`0007-ffi-reflection`): refactored into `WrapFunction` + `GetMethod` composition.
- `FunctionInfo<T>` SFINAE dispatch (`0004-ffi-function-system`): used by `TypedOverload` for arg-count and type introspection.
- `AnyView::try_cast<T>` (`0002-ffi-any-value-system`): used for non-throwing type checks in overload dispatch.

Design elements this commit produces:
- **`OverloadObjectDef<T>`** -- new reflection builder enabling method overloading for FFI object types.
- **`OverloadedFunction<Callable>`** -- runtime overload dispatcher that wraps a primary callable plus a chain of `TypedOverload` entries.
- **`TypedOverload<Callable>`** -- single-callable dispatch entry with `try_cast`-based type matching and optional capture.
- **`OverloadBase`** -- abstract base with virtual `Register`/`GetTryCallPtr`/`GetMismatchMessage`.
- **`Function::FromPackedInplace<TCallable>`** -- in-place construction returning `(Function, TCallable*)` tuple.
- **`FunctionObjImpl::GetCallable()`** -- accessor exposing internal callable pointer.
- **`ReflectionDefBase::WrapFunction`** -- factored-out member-function wrapping (enables reuse by both `ObjectDef` and `OverloadObjectDef`).

## Usage Examples
Registering overloaded constructors, instance methods, and static methods (from test):
```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  refl::OverloadObjectDef<TestOverloadObj>()
      .def(refl::init<int32_t>())           // constructor overload 1
      .def(refl::init<float>())             // constructor overload 2
      .def("hold_same_type", &TestOverloadObj::Holds<int32_t>)
      .def("hold_same_type", &TestOverloadObj::Holds<float>)
      .def_static("add_one_static", &TestOverloadObj::AddOneInt)
      .def_static("add_one_static", &TestOverloadObj::AddOneFloat);
}

// Call overloaded constructor -- dispatches by arg type
Function init_method = reflection::GetMethod("test.TestOverloadObj", "__ffi_init__");
Any obj_int = init_method(10);     // selects init<int32_t>
Any obj_float = init_method(3.14f); // selects init<float>

// Call overloaded instance method
Function hold = reflection::GetMethod("test.TestOverloadObj", "hold_same_type");
Any res = hold(obj_int, 20);       // true: int obj + int arg
Any res2 = hold(obj_int, 3.14f);   // false: int obj + float arg
```
