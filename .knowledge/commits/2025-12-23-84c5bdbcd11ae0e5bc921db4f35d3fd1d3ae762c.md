# feat: Introduce dynamic-style overload for FFI object types via OverloadObjectDef and OverloadedFunction

## TL;DR
- Adds `include/tvm/ffi/reflection/overload.h` (501 lines) with `TypedOverload<Callable>`, `OverloadedFunction<Callable>`, and `OverloadObjectDef<Class>` — enabling Python-style function overloading within the FFI reflection system
- Adds `Function::FromPackedInplace<TCallable>(args...)` factory in `function.h` that returns `(Function, TCallable*)` for in-place construction of callables whose lifetime is managed by the `Function` object
- Adds `tests/cpp/test_overload.cc` with coverage for single and multi-overload dispatch

// Register a function with an overload for int vs. string argument
