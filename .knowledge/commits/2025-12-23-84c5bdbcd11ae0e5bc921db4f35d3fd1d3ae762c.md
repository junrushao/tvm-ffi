# Add dynamic-style method overloading for FFI object types via OverloadObjectDef
## TL;DR
- Introduces `OverloadObjectDef<Class>`, a new reflection registration builder that supports registering multiple overloads of the same method name (including `__ffi_init__` constructors) with type-based dispatch at call time.
- Adds `Function::FromPackedInplace<TCallable>(Args...)` to construct a `Function` whose callable is created in-place, returning both the `Function` and a pointer to the embedded callable for post-construction mutation (used to register additional overloads).
- Refactors `ReflectionDefBase::GetMethod` into a two-step `WrapFunction` + `GetMethod` pattern, separating member-pointer-to-lambda wrapping from `Function` construction, enabling reuse by the overload system.

## Key Exports

**`Function::FromPackedInplace<TCallable>(Args...) -> std::tuple<Function, TCallable*>`** (`function.h`):
```cpp
template <typename TCallable, typename... Args>
static auto FromPackedInplace(Args&&... args);
// static_assert: TCallable == decay_t<TCallable>
// static_assert: TCallable is invocable with (const AnyView*, int32_t, Any*)
// Returns (Function, pointer-to-embedded-callable)
```

**`FunctionObjImpl<TCallable>` constructor change** (`function.h`):
```cpp
// Before: two explicit constructors (rvalue + lvalue copy)
// After: single variadic forwarding constructor
template <typename... Args>
explicit FunctionObjImpl(Args&&... args) : callable_(std::forward<Args>(args)...) { ... }
// + copy/assignment deleted
// + GetCallable() -> TCallable* accessor added
```

**`details::OverloadBase`** (`reflection/overload.h`):
```cpp
struct OverloadBase {
  using FnPtr = bool (*)(OverloadBase*, const AnyView*, int32_t, Any*);
  explicit OverloadBase(int32_t num_args, std::optional<std::string> name);
  virtual void Register(std::unique_ptr<OverloadBase> overload) = 0;
  virtual FnPtr GetTryCallPtr() = 0;
  virtual void GetMismatchMessage(std::ostringstream& os, const AnyView* args, int32_t num_args) = 0;
  int32_t last_mismatch_index_;  // fast cache for error reporting
  const int32_t num_args_;
  const std::string name_;
};
```

**`details::TypedOverload<Callable>`** (`reflection/overload.h`):
```cpp
template <typename Callable>
struct TypedOverload : OverloadBase {
  bool TryCall(const AnyView* args, int32_t num_args, Any* rv);
  // Uses try_cast per argument; returns false on type mismatch
  FnPtr GetTryCallPtr() final;  // returns captureless lambda convertible to FnPtr
};
```

**`details::OverloadedFunction<Callable>`** (`reflection/overload.h`):
```cpp
template <typename Callable>
struct OverloadedFunction : TypedOverload<Callable> {
  void Register(std::unique_ptr<OverloadBase> overload) final;
  void operator()(const AnyView* args, int32_t num_args, Any* rv);
  // Fast path: no overloads -> direct unpack_call (zero extra overhead)
  // Slow path: try self, then iterate overloads by num_args then try_call
  // Failure: throws TypeError with all overload mismatch messages
};
```

**`reflection::OverloadObjectDef<Class>`** (`reflection/overload.h`):
```cpp
template <typename Class>
class OverloadObjectDef : private ObjectDef<Class> {
  OverloadObjectDef& def_ro(name, field_ptr, extra...);
  OverloadObjectDef& def_rw(name, field_ptr, extra...);
  OverloadObjectDef& def(name, func, extra...);        // overloadable
  OverloadObjectDef& def_static(name, func, extra...); // overloadable
  OverloadObjectDef& def(init<Args...>, extra...);     // overloadable constructor
};
// Internally tracks registered_fields_ map: name -> OverloadBase*
// First def() for a name creates OverloadedFunction via FromPackedInplace
// Subsequent def() calls Register() on the existing OverloadBase
```

**`ReflectionDefBase::WrapFunction`** (`registry.h`):
```cpp
// New: separates member-pointer wrapping from Function construction
template <typename Func>
static Func&& WrapFunction(Func&& func);  // passthrough for non-member
template <typename Class, typename R, typename... Args>
static auto WrapFunction(R (Class::*func)(Args...));       // -> lambda
static auto WrapFunction(R (Class::*func)(Args...) const); // -> lambda
```

## Impact
- API: New public header `tvm/ffi/reflection/overload.h`. `FunctionObjImpl` constructor signature changed from two explicit constructors to variadic forwarding (source-compatible for existing callers since `make_object` forwards args).
- Behavioral: `OverloadObjectDef` enables multiple methods with the same name dispatched by argument types at runtime. `OverloadedFunction` has zero overhead when no overloads are registered (fast path calls `unpack_call` directly).
- Flags/config: None.
- Data formats/schemas: None.

Design elements this commit produces:
- **`OverloadObjectDef<Class>`**: Overload-aware registration builder for FFI object types. Private-inherits `ObjectDef<Class>`, adds overload tracking via `registered_fields_` map.
- **`OverloadedFunction<Callable>`**: Runtime overload dispatch callable. Stored inside a `Function` via `FromPackedInplace`. Holds a vector of `(unique_ptr<OverloadBase>, FnPtr)` pairs for additional overloads.
- **`Function::FromPackedInplace<TCallable>(Args...)`**: Factory returning `(Function, TCallable*)` tuple, enabling post-construction mutation of the embedded callable (critical for the overload registration pattern).
- **`ReflectionDefBase::WrapFunction`**: Factored-out member-pointer-to-lambda conversion, reusable by both `ObjectDef::GetMethod` and `OverloadObjectDef::GetOverloadMethod`.

## Usage Examples

**Registering overloaded methods and constructors:**
```cpp
#include <tvm/ffi/reflection/overload.h>
namespace refl = tvm::ffi::reflection;

struct MyObj : public Object {
  explicit MyObj(int32_t x);
  explicit MyObj(float y);
  static int AddOne(int x);
  static float AddOne(float x);
  TVM_FFI_DECLARE_OBJECT_INFO("test.MyObj", MyObj, Object);
};

TVM_FFI_STATIC_INIT_BLOCK() {
  refl::OverloadObjectDef<MyObj>()
      .def(refl::init<int32_t>())        // constructor overload 1
      .def(refl::init<float>())          // constructor overload 2
      .def_static("add_one", &MyObj::AddOne(int))    // static overload 1
      .def_static("add_one", &MyObj::AddOne(float)); // static overload 2
}

// Calling from C++:
Function init = reflection::GetMethod("test.MyObj", "__ffi_init__");
Any obj_int = init(10);    // dispatches to MyObj(int32_t)
Any obj_flt = init(3.14f); // dispatches to MyObj(float)

Function add = reflection::GetMethod("test.MyObj", "add_one");
Any r1 = add(20);    // -> 21 (int overload)
Any r2 = add(1.0f);  // -> 2.0f (float overload)
```
