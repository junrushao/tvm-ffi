# Support dynamic-style overload for FFI object types
## TL;DR
- Adds a new `overload.h` header implementing dynamic-style function overloading for FFI object types via type-based dispatch.
- Introduces `OverloadObjectDef` builder that allows registering multiple typed overloads for the same function name.
- Adds `Function::FromPackedInplace` for in-place construction of callable objects within Function, avoiding extra allocations.
- Refactors `FunctionObjImpl` constructor to use variadic forwarding.

## Key Exports

**C++ API:**
- `tvm::ffi::details::OverloadBase` -- Base class for overload dispatch entries with try-call semantics.
- `tvm::ffi::details::TypedOverload<Callable>` -- Typed overload entry that matches argument types at runtime.
- `tvm::ffi::reflection::OverloadObjectDef<Class>` -- Builder for registering overloaded functions on reflected object types.
- `Function::FromPackedInplace<TCallable>(args...)` -- Static factory returning `tuple<Function, TCallable*>`.

## Impact
- API: New `OverloadObjectDef` builder and `FromPackedInplace` factory.
- ABI: none (additive only)
- Behavioral: Enables Python-style overloaded methods on C++ FFI objects.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Function packed calling convention
- Reflection ObjectDef builder

Design elements this commit produces:
- **Dynamic overload dispatch** -- Runtime type-based dispatch for FFI functions, with mismatch error reporting.
- **In-place Function construction** -- `FromPackedInplace` pattern for zero-copy callable embedding.

## Usage Examples
```cpp
reflection::OverloadObjectDef<MyClass>(type_key)
    .def_method("compute", [](MyClass* self, int x) { ... })
    .def_method("compute", [](MyClass* self, double x) { ... });
```
