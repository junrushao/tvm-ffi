# Distinguish strict `as()` from coercing `cast()`/`try_cast()` in Any/AnyView

## TL;DR
- `as<T>()` on `AnyView`/`Any` is changed from coercing (calling `TryConvertFromAnyView`) to strict-only (calling `CheckAnyStrict` + `CopyFromAnyViewAfterCheck`). It no longer performs type conversion (e.g., int->float returns `nullopt`).
- A new `try_cast<T>()` method is added to `AnyView`/`Any` that preserves the old coercing behavior (calls `TryCastFromAnyView`).
- Four `TypeTraits<T>` protocol methods are renamed: `CheckAnyStorage` -> `CheckAnyStrict`, `CopyFromAnyStorageAfterCheck` -> `CopyFromAnyViewAfterCheck`, `MoveFromAnyStorageAfterCheck` -> `MoveFromAnyAfterCheck`, `TryConvertFromAnyView` -> `TryCastFromAnyView`.

### Rename mapping

| Old name | New name |
|----------|----------|
| `TypeTraits<T>::CheckAnyStorage` | `TypeTraits<T>::CheckAnyStrict` |
| `TypeTraits<T>::CopyFromAnyStorageAfterCheck` | `TypeTraits<T>::CopyFromAnyViewAfterCheck` |
| `TypeTraits<T>::MoveFromAnyStorageAfterCheck` | `TypeTraits<T>::MoveFromAnyAfterCheck` |
| `TypeTraits<T>::TryConvertFromAnyView` | `TypeTraits<T>::TryCastFromAnyView` |
| `AnyUnsafe::CheckAnyStorage<T>` | `AnyUnsafe::CheckAnyStrict<T>` |
| `AnyUnsafe::CopyFromAnyStorageAfterCheck<T>` | `AnyUnsafe::CopyFromAnyViewAfterCheck<T>` |
| `AnyUnsafe::MoveFromAnyStorageAfterCheck<T>` | `AnyUnsafe::MoveFromAnyAfterCheck<T>` |
| `Tuple::CheckAnyStorageHelper` | `Tuple::CheckAnyStrictHelper` |

## Key Exports

**Methods on `AnyView`** (behavioral change + new method):
```cpp
// CHANGED: now strict-only (no coercion). Uses CheckAnyStrict + CopyFromAnyViewAfterCheck.
template <typename T> std::optional<T> AnyView::as() const;
// UNCHANGED shortcut: returns const T* or nullptr for Object types.
template <typename T> const T* AnyView::as() const;
// NEW: coercing conversion, calls TryCastFromAnyView.
template <typename T> std::optional<T> AnyView::try_cast() const;
// UNCHANGED: calls TryCastFromAnyView, throws on failure.
template <typename T> T AnyView::cast() const;
```

**Methods on `Any`** (behavioral change + new overloads):
```cpp
// CHANGED: now strict-only (no coercion). New rvalue-ref overload added.
template <typename T> std::optional<T> Any::as() const&;
template <typename T> std::optional<T> Any::as() &&;
template <typename T> const T* Any::as() const&;
// NEW: coercing conversion.
template <typename T> std::optional<T> Any::try_cast() const;
// UNCHANGED: coercing cast with exception on failure.
template <typename T> T Any::cast() const&;
template <typename T> T Any::cast() &&;
```

**TypeTraits protocol methods** (renamed, semantics unchanged):

| # | New Method | Old Method | Signature | Semantics |
|---|-----------|-----------|-----------|-----------|
| 3 | `CheckAnyStrict` | `CheckAnyStorage` | `(const TVMFFIAny*) -> bool` | Exact type match, no coercion |
| 4 | `CopyFromAnyViewAfterCheck` | `CopyFromAnyStorageAfterCheck` | `(const TVMFFIAny*) -> T` | Extract after strict check passed |
| 5 | `MoveFromAnyAfterCheck` | `MoveFromAnyStorageAfterCheck` | `(TVMFFIAny*) -> T` | Extract with ownership transfer |
| 6 | `TryCastFromAnyView` | `TryConvertFromAnyView` | `(const TVMFFIAny*) -> optional<T>` | Coercing conversion |

**New TypeTraits methods for `DLTensor*`**: `CheckAnyStrict` and `CopyFromAnyViewAfterCheck` added (previously missing, only had `TryConvertFromAnyView`).

## Impact
- API: **Breaking**. All `TypeTraits<T>` specializations (including user-defined ones) must rename the 4 protocol methods. All call sites using `any.as<T>()` that relied on coercion semantics must switch to `any.try_cast<T>()` or `any.cast<T>()`.
- Behavioral: `as<T>()` no longer performs type coercion. Code like `AnyView(1).as<double>()` now returns `nullopt` instead of `1.0`. This is the primary semantic change.
- Flags/config: none
- Data formats/schemas: none

## Design Elements

Design elements this commit consumes:
- **Any/AnyView value system** ([0002-any-value-system.md](../../.knowledge/designs/0002-any-value-system.md)): Core `as()`/`cast()` methods on `AnyView` and `Any`.
- **TypeTraits protocol** ([0005-type-traits.md](../../.knowledge/designs/0005-type-traits.md)): All 4 renamed protocol methods across every built-in specialization.
- **Container system** ([0008-containers.md](../../.knowledge/designs/0008-containers.md)): `Array<T>`, `Map<K,V>`, `Tuple<Types...>`, `Variant<V...>` all consume TypeTraits internally for element access and type checking.
- **ArgValueWithContext** (`function_details.h`): Changed from `as<T>()` to `try_cast<T>()` for packed function argument conversion.

Design elements this commit produces/mutates:
- **`as()` vs `cast()` vs `try_cast()` semantic distinction**: New three-level API:
  - `as<T>()` = strict check only, no type conversion
  - `try_cast<T>()` = try coercion, return `optional`
  - `cast<T>()` = try coercion, throw on failure
- **`Any::as() &&` rvalue overload**: New overload enabling move semantics for strict `as<T>()` on rvalue `Any`.
- **TypeTraits method naming**: Renamed 4 of 7 protocol methods for clarity (Storage->Strict/View/AfterCheck, Convert->Cast).

## Usage Examples

**Strict check vs coercing conversion (new semantics, from `test_any.cc`):**
```cpp
AnyView view0 = 1;  // stores as kTVMFFIInt

// as() is strict: int stored, but bool/double requested -> nullopt
auto v0 = view0.as<int64_t>();   // has_value() == true, value() == 1
auto v1 = view0.as<bool>();      // has_value() == false (strict: int != bool)
auto v2 = view0.as<double>();    // has_value() == false (strict: int != float)

// try_cast() coerces: int -> bool/double succeeds
auto v3 = view0.try_cast<bool>();    // has_value() == true, value() == 1
auto v4 = view0.try_cast<double>();  // has_value() == true, value() == 1.0
```

**Migrating call sites (before/after):**
```cpp
// BEFORE: as() did coercion
auto opt = any_val.as<DLDataType>();        // converted string "float32" to DLDataType

// AFTER: must use try_cast() for coercion
auto opt = any_val.try_cast<DLDataType>();  // converts string "float32" to DLDataType
// as() only works if the stored type is exactly kTVMFFIDataType
```
