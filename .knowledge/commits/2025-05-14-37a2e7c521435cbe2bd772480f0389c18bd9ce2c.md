# Distinguish strict `as` from conversion-allowing `cast`/`try_cast` in Any/AnyView and TypeTraits

## TL;DR
- `as<T>()` on `AnyView` and `Any` is now strict-only: it checks exact type match (`CheckAnyStrict`) and returns `std::nullopt` if the stored type does not match, with no implicit conversion.
- New `try_cast<T>()` method on both `AnyView` and `Any` performs conversion-allowing extraction (old `as` behavior), delegating to `TryCastFromAnyView`.
- `cast<T>()` remains the throwing variant but now calls `TryCastFromAnyView` (renamed from `TryConvertFromAnyView`).
- All `TypeTraits<T>` method names are renamed for consistency with the new semantics.

### Rename Mapping

| Old Name | New Name | Semantic Change |
|---|---|---|
| `CheckAnyStorage` | `CheckAnyStrict` | Name only -- same strict-match behavior |
| `CopyFromAnyStorageAfterCheck` | `CopyFromAnyViewAfterCheck` | Name only -- clarifies it works on view-level data |
| `MoveFromAnyStorageAfterCheck` | `MoveFromAnyAfterCheck` | Name only |
| `TryConvertFromAnyView` | `TryCastFromAnyView` | Name only -- still does conversion |
| `AnyView::as<T>()` | `AnyView::as<T>()` | **Behavioral**: now strict-only (no conversion) |
| *(new)* | `AnyView::try_cast<T>()` | New method: conversion-allowing `Optional<T>` extraction |
| *(new)* | `Any::try_cast<T>()` | New method: conversion-allowing `Optional<T>` extraction |
| *(new)* | `Any::as<T>() &&` | New rvalue overload: strict-only with move semantics |

## Key Exports

```python
# --- AnyView (non-owning, 16-byte) ---
class AnyView:
    def as(self, T: type) -> Optional[T]: ...
        # Strict check only: CheckAnyStrict + CopyFromAnyViewAfterCheck
        # Returns None if stored type != T (no implicit conversion)
        # Interacts with: TypeTraits<T>.CheckAnyStrict, TypeTraits<T>.CopyFromAnyViewAfterCheck
        # Invariant: as<float>() on int storage returns None (unlike old behavior)

    def as(self, T: ObjectType) -> Optional[Ptr[T]]: ...
        # Shortcut for object types: returns const T* or nullptr
        # Delegates to as<const T*>()

    def try_cast(self, T: type) -> Optional[T]: ...
        # Conversion-allowing: calls TryCastFromAnyView (may widen int->float, etc.)
        # Interacts with: TypeTraits<T>.TryCastFromAnyView
        # This is the old as<T>() behavior

    def cast(self, T: type) -> T: ...
        # Throws TypeError on failure
        # Interacts with: TypeTraits<T>.TryCastFromAnyView (renamed from TryConvertFromAnyView)

# --- Any (owning, 16-byte) ---
class Any:
    def as(self, T: type) -> Optional[T]: ...  # const& overload
        # Strict check only: CheckAnyStrict + CopyFromAnyViewAfterCheck
        # Invariant: no conversion, exact type match required

    def as(self, T: type) -> Optional[T]: ...  # && rvalue overload (NEW)
        # Strict check + MoveFromAnyAfterCheck (move semantics)
        # Interacts with: TypeTraits<T>.CheckAnyStrict, TypeTraits<T>.MoveFromAnyAfterCheck

    def as(self, T: ObjectType) -> Optional[Ptr[T]]: ...  # const& overload
        # Object pointer shortcut

    def try_cast(self, T: type) -> Optional[T]: ...  # NEW
        # Conversion-allowing extraction
        # Interacts with: TypeTraits<T>.TryCastFromAnyView

    def cast(self, T: type) -> T: ...  # const& overload
        # Throws on failure, calls TryCastFromAnyView

    def cast(self, T: type) -> T: ...  # && rvalue overload
        # Fast path: CheckAnyStrict + MoveFromAnyAfterCheck
        # Slow path fallback: TryCastFromAnyView

# --- TypeTraits<T> protocol (renamed methods) ---
class TypeTraits(Generic[T]):
    @staticmethod
    def CheckAnyStrict(src: Ptr[TVMFFIAny]) -> bool: ...
        # Was: CheckAnyStorage. Same semantics: strict type match.
        # Invariant: returns True iff src holds exactly this T's storage format

    @staticmethod
    def CopyFromAnyViewAfterCheck(src: Ptr[TVMFFIAny]) -> T: ...
        # Was: CopyFromAnyStorageAfterCheck. Clarifies it reads view-level data.
        # Precondition: CheckAnyStrict(src) == True

    @staticmethod
    def MoveFromAnyAfterCheck(src: Ptr[TVMFFIAny]) -> T: ...
        # Was: MoveFromAnyStorageAfterCheck.
        # Precondition: CheckAnyStrict(src) == True

    @staticmethod
    def TryCastFromAnyView(src: Ptr[TVMFFIAny]) -> Optional[T]: ...
        # Was: TryConvertFromAnyView. Same semantics: may do implicit conversion.
        # Invariant: CheckAnyStrict(src)==True implies TryCastFromAnyView(src).has_value()
```

## Impact
- API: **Breaking** -- `as<T>()` no longer performs implicit conversion. All call sites relying on `as<T>()` for widening conversions (e.g., `any.as<float>()` on an int) must switch to `try_cast<T>()`. Internal callers updated: `ArgValueWithContext`, `Array<T>`, `Map<K,V>`, `Tuple<Types...>`, `Variant<V...>`, `ffi.Shape` registration, `DLDataType` string conversion tests.
- Behavioral: `as<T>()` is now strict. Code that previously relied on `as<float>()` succeeding on int storage will now get `std::nullopt`.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Before/after pattern showing the semantic split:

```cpp
// === BEFORE this commit ===
AnyView v = 1;
auto f = v.as<double>();       // returned Optional(1.0) -- implicit int->double
auto i = v.as<int64_t>();      // returned Optional(1)

// === AFTER this commit ===
AnyView v = 1;
auto f_strict = v.as<double>();      // returns std::nullopt (strict: int != double)
auto f_cast = v.try_cast<double>();  // returns Optional(1.0) (conversion allowed)
auto i_strict = v.as<int64_t>();     // returns Optional(1) (strict: int == int)

// cast<T>() still does conversion (throws on failure):
double d = v.cast<double>();         // returns 1.0 (conversion allowed, throws on fail)

// New rvalue overload for Any:
Any a = 42;
auto moved = std::move(a).as<int64_t>();  // strict + move, a is now None
```
