# Distinguish `as` (strict reinterpret) from `cast`/`try_cast` (with type conversion) in the Any system
## TL;DR
- Splits the `as()` method into a strict-only check (no type conversion) and introduces `try_cast()` as the conversion-allowing counterpart alongside `cast()`.
- Renames 4 `TypeTraits<T>` protocol methods: `CheckAnyStorage` -> `CheckAnyStrict`, `CopyFromAnyStorageAfterCheck` -> `CopyFromAnyViewAfterCheck`, `MoveFromAnyStorageAfterCheck` -> `MoveFromAnyAfterCheck`, `TryConvertFromAnyView` -> `TryCastFromAnyView`.
- Updates all call sites across containers (`Array`, `Map`, `Tuple`, `Variant`), helper types (`Optional`, `RValueRef`, `TypedFunction`, `DLDataType`), and tests.

### Rename Mapping

| Old Name | New Name | Scope |
|----------|----------|-------|
| `TypeTraits<T>::CheckAnyStorage` | `TypeTraits<T>::CheckAnyStrict` | type_traits.h, all container TypeTraits |
| `TypeTraits<T>::CopyFromAnyStorageAfterCheck` | `TypeTraits<T>::CopyFromAnyViewAfterCheck` | type_traits.h, all container TypeTraits |
| `TypeTraits<T>::MoveFromAnyStorageAfterCheck` | `TypeTraits<T>::MoveFromAnyAfterCheck` | type_traits.h, all container TypeTraits |
| `TypeTraits<T>::TryConvertFromAnyView` | `TypeTraits<T>::TryCastFromAnyView` | type_traits.h, all container TypeTraits |
| `AnyUnsafe::CheckAnyStorage` | `AnyUnsafe::CheckAnyStrict` | any.h |
| `AnyUnsafe::CopyFromAnyStorageAfterCheck` | `AnyUnsafe::CopyFromAnyViewAfterCheck` | any.h |
| `AnyUnsafe::MoveFromAnyStorageAfterCheck` | `AnyUnsafe::MoveFromAnyAfterCheck` | any.h |
| `AnyView::as<T>()` (old: conversion-allowing) | `AnyView::try_cast<T>()` (conversion-allowing); `AnyView::as<T>()` (strict-only) | any.h |
| `Any::as<T>()` (old: conversion-allowing) | `Any::try_cast<T>()` (conversion-allowing); `Any::as<T>()` (strict-only) | any.h |

## Key Exports

```python
# --- AnyView (updated methods) ---
class AnyView:
    def as(self, T) -> Optional[T]:
        """Strict reinterpret: returns T only if the stored type matches exactly.
        Does NOT run type conversions (int -> float fails)."""
        if TypeTraits[T].CheckAnyStrict(self.data_):
            return TypeTraits[T].CopyFromAnyViewAfterCheck(self.data_)
        return None
        # Interacts with: TypeTraits<T>::CheckAnyStrict, TypeTraits<T>::CopyFromAnyViewAfterCheck
        # Invariant: as<float>() on int-valued Any returns nullopt

    # Overload: as<ObjectType>() -> const ObjectType*
    def as(self, T: ObjectType) -> Optional[T]:  # T must derive from Object
        """Shortcut: returns raw pointer or nullptr."""
        return self.as(Ptr[T]) or None

    def cast(self, T) -> T:
        """Cast with type conversion. Throws TypeError on failure."""
        opt = TypeTraits[T].TryCastFromAnyView(self.data_)
        if not opt: raise TypeError(...)
        return opt
        # Interacts with: TypeTraits<T>::TryCastFromAnyView

    def try_cast(self, T) -> Optional[T]:  # NEW
        """Cast with type conversion. Returns nullopt on failure."""
        return TypeTraits[T].TryCastFromAnyView(self.data_)
        # Interacts with: TypeTraits<T>::TryCastFromAnyView

# --- Any (updated methods) ---
class Any:
    def as(self, T) -> Optional[T]:   # const& qualified
        """Strict reinterpret (no conversion). Same semantics as AnyView.as()."""
        ...
        # Interacts with: TypeTraits<T>::CheckAnyStrict, CopyFromAnyViewAfterCheck

    def as(self, T) -> Optional[T]:   # && (rvalue) qualified -- NEW overload
        """Strict reinterpret with move semantics."""
        if TypeTraits[T].CheckAnyStrict(self.data_):
            return TypeTraits[T].MoveFromAnyAfterCheck(self.data_)
        return None
        # Interacts with: TypeTraits<T>::MoveFromAnyAfterCheck

    def try_cast(self, T) -> Optional[T]:  # NEW
        """Cast with type conversion. Returns nullopt on failure."""
        return TypeTraits[T].TryCastFromAnyView(self.data_)

# --- TypeTraits protocol (renamed methods) ---
class TypeTraits(Generic[T]):
    @staticmethod
    def CheckAnyStrict(src: TVMFFIAny) -> bool: ...
        # Was: CheckAnyStorage
        # Invariant: returns True only if src holds exactly type T (no implicit conversion)

    @staticmethod
    def CopyFromAnyViewAfterCheck(src: TVMFFIAny) -> T: ...
        # Was: CopyFromAnyStorageAfterCheck
        # Invariant: caller must have verified CheckAnyStrict first

    @staticmethod
    def MoveFromAnyAfterCheck(src: TVMFFIAny) -> T: ...
        # Was: MoveFromAnyStorageAfterCheck
        # Invariant: caller must have verified CheckAnyStrict first

    @staticmethod
    def TryCastFromAnyView(src: TVMFFIAny) -> Optional[T]: ...
        # Was: TryConvertFromAnyView
        # Allows implicit conversions (int -> float, String -> DLDataType, etc.)
```

## Impact
- API: All 4 TypeTraits protocol methods renamed. Any downstream `TypeTraits<T>` specialization using the old names will fail to compile. `as<T>()` call sites that relied on implicit conversion must migrate to `try_cast<T>()`.
- Behavioral: `as<T>()` is now strict -- `AnyView(1).as<double>()` returns `nullopt` instead of `1.0`. Only `try_cast<double>()` or `cast<double>()` performs the int-to-float conversion.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TypeTraits<T>` protocol (0002-ffi-any-value-system) -- renames 4 of 8 methods
- `Any`/`AnyView` type-erased value containers (0002-ffi-any-value-system) -- adds `try_cast()`, redefines `as()`
- Container `TypeTraits` specializations for `Array<T>`, `Map<K,V>`, `Tuple`, `Variant`, `Optional` (0006-ffi-containers) -- updated to new names

Design elements this commit produces:
- **`as()` vs `try_cast()` semantic split**: `as()` is now strict (no type conversion), `try_cast()` performs conversions. This is a new design invariant across the entire Any system.
- **Rvalue-qualified `Any::as()` overload**: enables zero-copy move extraction with strict type checking.

## Usage Examples
Before (old API -- `as()` performs conversions):
```cpp
AnyView view = 1;
auto v = view.as<double>();  // returned optional(1.0) via implicit int->float
```

After (new API -- `as()` is strict, `try_cast()` converts):
```cpp
AnyView view = 1;
auto v1 = view.as<int64_t>();    // optional(1) -- strict match succeeds
auto v2 = view.as<double>();     // nullopt -- strict, no conversion
auto v3 = view.try_cast<double>(); // optional(1.0) -- conversion applied
auto v4 = view.cast<double>();   // 1.0 -- conversion, throws on failure
```
