# Rename __tvm_ffi_tensor__ to __tvm_ffi_object__ and __tvm_ffi_object__ attribute to _tvm_ffi_cached_object
## TL;DR
- Renames the `PyNativeObject.__tvm_ffi_object__` internal attribute to `_tvm_ffi_cached_object`, because dunder convention is reserved for methods/protocols, not plain data attributes.
- Renames the `__tvm_ffi_tensor__` protocol method (introduced in 4bc8925) to `__tvm_ffi_object__`, generalizing it from tensor-only to any `Object` subclass. The setter now uses `TVMFFIObjectGetTypeIndex(chandle)` instead of hardcoding `kTVMFFITensor`.
- Bumps version from `0.1.0b17` to `0.1.0b18`.

| Before | After | Kind |
|--------|-------|------|
| `PyNativeObject.__tvm_ffi_object__` (attribute) | `PyNativeObject._tvm_ffi_cached_object` | Internal attribute rename |
| `__init_tvm_ffi_object_by_constructor__` (method) | `__init_cached_object_by_constructor__` | Internal method rename |
| `__tvm_ffi_tensor__` (protocol method) | `__tvm_ffi_object__` (protocol method) | Public protocol rename + generalization |
| `TVMFFIPyArgSetterFFITensorCompatible_` | `TVMFFIPyArgSetterFFIObjectCompatible_` | Internal Cython setter rename |
| `out.type_index = kTVMFFITensor` | `out.type_index = TVMFFIObjectGetTypeIndex(temp_chandle)` | Behavioral: dynamic type index |
| `cdef Tensor tensor = arg.__tvm_ffi_tensor__()` | `cdef Object obj = arg.__tvm_ffi_object__()` | Type widened from Tensor to Object |
| version `0.1.0b17` | version `0.1.0b18` | Version bump |

## Key Exports

**Protocols (renamed)**:
- `__tvm_ffi_object__() -> tvm_ffi.Object` -- Python dunder protocol (was `__tvm_ffi_tensor__() -> tvm_ffi.Tensor`). Any class defining this method can be passed as an argument to FFI function calls. The method must return an `ffi.Object` (or any subclass, including `Tensor`). Checked via `hasattr(arg_class, "__tvm_ffi_object__")` in the setter factory. The setter now reads the actual type index from the returned object handle, making it generic for all Object types.

**Renames (internal, not user-facing)**:
- `PyNativeObject._tvm_ffi_cached_object` -- attribute (was `PyNativeObject.__tvm_ffi_object__`). Stores the backing `Object` handle for `PyNativeObject` subclasses (`String`, `Bytes`, `Shape`).
- `PyNativeObject.__init_cached_object_by_constructor__` -- method (was `__init_tvm_ffi_object_by_constructor__`). Initializes `_tvm_ffi_cached_object` by calling an FFI constructor function.
- `TVMFFIPyArgSetterFFIObjectCompatible_` -- Cython setter (was `TVMFFIPyArgSetterFFITensorCompatible_`).

## Impact
- API: The `__tvm_ffi_tensor__` protocol is renamed to `__tvm_ffi_object__` and generalized from returning `Tensor` to returning any `Object`. Existing implementors of `__tvm_ffi_tensor__` must rename their method. The internal `__tvm_ffi_object__` attribute on `PyNativeObject` subclasses is renamed to `_tvm_ffi_cached_object`; this was not part of the public API but may affect code that directly accessed the attribute (e.g., `shape.__tvm_ffi_object__`).
- ABI: none
- Behavioral: `TVMFFIPyArgSetterFFIObjectCompatible_` now uses `TVMFFIObjectGetTypeIndex(temp_chandle)` to set the type index dynamically, instead of hardcoding `kTVMFFITensor`. This means the protocol now correctly propagates the actual type of any returned `Object`, not just `Tensor`. A new test (`test_object_protocol`) verifies this with a non-tensor `Object` (an `Array`).
- Flags/config: none
- Data formats/schemas: none

Design elements this commit produces:
- Generalized `__tvm_ffi_object__` protocol: the protocol now accepts any `Object` subclass (not just `Tensor`), enabling wrapper classes around arbitrary FFI objects (Arrays, Maps, custom objects) to be passed directly to FFI calls
- Cleaner naming convention: `_tvm_ffi_cached_object` (single-underscore private) for the internal cached handle, reserving dunder names for protocols/methods

## Usage Examples

**Wrapping an arbitrary FFI Object (not just Tensor) and passing to FFI calls (new capability):**
```python
import tvm_ffi

class CompactObject:
    def __init__(self, backend_obj):
        self.backend_obj = backend_obj

    def __tvm_ffi_object__(self):
        return self.backend_obj

x = tvm_ffi.convert([])  # creates an ffi.Array
wrapper = CompactObject(x)
echo = tvm_ffi.get_global_func("testing.echo")
y = echo(wrapper)  # auto-converted via __tvm_ffi_object__ protocol
assert y.__chandle__() == x.__chandle__()  # same underlying object
```

**Before/after for existing `__tvm_ffi_tensor__` implementors:**
```python
# BEFORE (0.1.0b17):
class MyTensor:
    def __init__(self, tensor):
        self._tensor = tensor
    def __tvm_ffi_tensor__(self):    # OLD protocol name
        return self._tensor

# AFTER (0.1.0b18):
class MyTensor:
    def __init__(self, tensor):
        self._tensor = tensor
    def __tvm_ffi_object__(self):    # NEW protocol name
        return self._tensor
```
