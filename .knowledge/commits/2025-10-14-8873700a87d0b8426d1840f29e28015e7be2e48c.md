# Rename __tvm_ffi_tensor__ to __tvm_ffi_object__ protocol and __tvm_ffi_object__ attribute to _tvm_ffi_cached_object

## TL;DR
- Generalizes the `__tvm_ffi_tensor__` duck-type protocol to `__tvm_ffi_object__`, allowing any `Object` subclass (not just `Tensor`) to be returned. The setter now reads `type_index` dynamically via `TVMFFIObjectGetTypeIndex` instead of hardcoding `kTVMFFITensor`.
- Renames the internal `PyNativeObject.__tvm_ffi_object__` cached-handle attribute to `_tvm_ffi_cached_object`, fixing the convention mismatch (dunder reserved for methods/protocols, not plain attributes).
- Version bump 0.1.0b17 -> 0.1.0b18. New test `test_object_protocol` validates the generalized protocol with a non-Tensor object.

### Rename Mapping

| Before | After | Scope |
|--------|-------|-------|
| `__tvm_ffi_tensor__` (protocol method) | `__tvm_ffi_object__` | User-facing duck-type protocol |
| `TVMFFIPyArgSetterFFITensorCompatible_` | `TVMFFIPyArgSetterFFIObjectCompatible_` | Cython setter function |
| `PyNativeObject.__tvm_ffi_object__` (attribute) | `PyNativeObject._tvm_ffi_cached_object` | Internal cached Object handle |
| `__init_tvm_ffi_object_by_constructor__` | `__init_cached_object_by_constructor__` | PyNativeObject constructor helper |
| `String.__slots__ = ["__tvm_ffi_object__"]` | `String.__slots__ = ["_tvm_ffi_cached_object"]` | String/Bytes/Shape slot names |

## Impact
- API: `__tvm_ffi_tensor__` protocol renamed to `__tvm_ffi_object__` -- existing implementors of the old protocol must rename their method. Pre-release, low external impact per commit message.
- Behavioral: `TVMFFIPyArgSetterFFIObjectCompatible_` now reads `type_index` dynamically via `TVMFFIObjectGetTypeIndex(chandle)` instead of hardcoding `kTVMFFITensor`. This enables the protocol to work with any `Object` subclass, not just `Tensor`.
- Flags/config: None.
- Data formats/schemas: None.

## Usage Examples

The new `test_object_protocol` demonstrates passing a non-Tensor wrapper through FFI:

```python
class CompactObject:
    def __init__(self, backend_obj):
        self.backend_obj = backend_obj

    def __tvm_ffi_object__(self):
        return self.backend_obj

x = tvm_ffi.convert([])           # returns an Array (Object subclass, not Tensor)
x_compact = CompactObject(x)
test_echo = tvm_ffi.get_global_func("testing.echo")
y = test_echo(x_compact)          # auto-converted via __tvm_ffi_object__ protocol
assert y.__chandle__() == x.__chandle__()  # same underlying object
```
