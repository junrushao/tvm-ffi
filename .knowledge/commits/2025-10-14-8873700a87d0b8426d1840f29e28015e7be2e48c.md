# Rename __tvm_ffi_tensor__ to __tvm_ffi_object__ and __tvm_ffi_object__ attribute to _tvm_ffi_cached_object

## TL;DR
- Renames `__tvm_ffi_tensor__` protocol to `__tvm_ffi_object__`, generalizing it from Tensor-only to any Object type.
- Renames internal `PyNativeObject.__tvm_ffi_object__` attribute to `_tvm_ffi_cached_object` to avoid dunder convention conflict.
- The setter now uses `TVMFFIObjectGetTypeIndex(temp_chandle)` instead of hardcoded `kTVMFFITensor`, enabling generic object dispatch.
- Version bump to `0.1.0b18`.

| Old name | New name |
|----------|----------|
| `__tvm_ffi_tensor__` (protocol method) | `__tvm_ffi_object__` |
| `TVMFFIPyArgSetterFFITensorCompatible_` | `TVMFFIPyArgSetterFFIObjectCompatible_` |
| `PyNativeObject.__tvm_ffi_object__` (cached attribute) | `PyNativeObject._tvm_ffi_cached_object` |

## Key Exports

**Protocol: `__tvm_ffi_object__`** (renamed from `__tvm_ffi_tensor__`):
- `__tvm_ffi_object__(self) -> tvm_ffi.Object` -- return the wrapped FFI object.
- Now works for any Object subclass, not just Tensor.
- Type index is dynamically queried via `TVMFFIObjectGetTypeIndex`.

## Impact
- API: **Breaking** for any code using `__tvm_ffi_tensor__` (not yet in a formal release per commit message).
- Behavioral: The setter now dynamically resolves the type index rather than hardcoding `kTVMFFITensor`.
- Flags/config: none
- Data formats/schemas: none

class MyObjectWrapper:
    def __init__(self, obj: tvm_ffi.Object) -> None:
        self._obj = obj

    def __tvm_ffi_object__(self) -> tvm_ffi.Object:
