# Generalize __tvm_ffi_tensor__ protocol to __tvm_ffi_object__ and rename internal caching attribute
## TL;DR
- Renames the duck-type protocol method `__tvm_ffi_tensor__` to `__tvm_ffi_object__`, generalizing it from Tensor-only to any FFI Object subclass.
- Renames the internal caching attribute `__tvm_ffi_object__` (on PyNativeObject subclasses) to `_tvm_ffi_cached_object`, reserving dunder for protocol methods.
- Bumps version to `0.1.0b18`.

### Rename Mapping

| Before | After | Kind |
|--------|-------|------|
| `__tvm_ffi_tensor__()` (protocol method) | `__tvm_ffi_object__()` (protocol method) | duck-type protocol |
| `__tvm_ffi_object__` (attribute on PyNativeObject) | `_tvm_ffi_cached_object` (attribute) | internal cache |
| `__init_tvm_ffi_object_by_constructor__` | `__init_cached_object_by_constructor__` | helper method |
| `TVMFFIPyArgSetterFFITensorCompatible_` | `TVMFFIPyArgSetterFFIObjectCompatible_` | Cython setter |

## Key Exports

```python
# --- Protocol: __tvm_ffi_object__ (generalized from __tvm_ffi_tensor__) ---
# Any Python class can implement this method to make instances passable through FFI.
# Previously restricted to returning Tensor; now returns any Object subclass.
# Interacts with: TVMFFIPyArgSetterFactory_ dispatch, TVMFFIPyArgSetterFFIObjectCompatible_
# Invariant: returned object must be an ffi.Object (or subclass)

class MyWrapper:
    def __tvm_ffi_object__(self) -> ffi.Object:  # active
        """Return the backing FFI object for argument passing."""
        return self._backend_obj

# --- Internal attribute: _tvm_ffi_cached_object (renamed from __tvm_ffi_object__) ---
# Used by PyNativeObject subclasses (String, Bytes, Shape) to cache the backing FFI object.
# Not a protocol — just an implementation detail, hence underscore-prefixed.
# Interacts with: PyNativeObject.__init_cached_object_by_constructor__

class PyNativeObject:
    def __init_cached_object_by_constructor__(self, fconstructor, *args):  # active
        # was: __init_tvm_ffi_object_by_constructor__
        ...

# --- Cython setter: TVMFFIPyArgSetterFFIObjectCompatible_ ---
# was: TVMFFIPyArgSetterFFITensorCompatible_
# Key change: uses TVMFFIObjectGetTypeIndex(chandle) instead of hardcoded kTVMFFITensor
# This enables the protocol to work with any Object type, not just Tensor.
# Interacts with: TVMFFIPyArgSetterFactory_ (dispatch on hasattr(__tvm_ffi_object__))
```

## Impact
- API: `__tvm_ffi_tensor__` protocol replaced by `__tvm_ffi_object__`. Any code implementing `__tvm_ffi_tensor__` must rename to `__tvm_ffi_object__`. The `__tvm_ffi_object__` attribute (cache) on PyNativeObject subclasses renamed to `_tvm_ffi_cached_object` — affects direct attribute access in tests/user code.
- Behavioral: The setter now reads the actual type index from the returned object via `TVMFFIObjectGetTypeIndex` instead of hardcoding `kTVMFFITensor`, enabling generic object pass-through (not just tensors).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Object system: `TVMFFIObjectGetTypeIndex` used by the new generic setter (`.knowledge/design-records/0002-object-system.md`)
- Setter dispatch: `TVMFFIPyArgSetterFactory_` dispatch chain (`.knowledge/design-records/0012-python-bindings.md`)

Design elements this commit produces:
- **Generalized `__tvm_ffi_object__` protocol**: Any Python class implementing `__tvm_ffi_object__() -> Object` can be passed through FFI calls. Supersedes the Tensor-only `__tvm_ffi_tensor__` protocol. Update in `.knowledge/design-records/0012-python-bindings.md`.
- **`_tvm_ffi_cached_object` naming convention**: Dunder reserved for protocol methods; internal caching attributes use single-underscore prefix. Update in `.knowledge/design-records/0012-python-bindings.md`.

## Usage Examples

**Context**: Custom wrapper class implementing the `__tvm_ffi_object__` protocol to pass any Object (not just Tensor) through FFI calls.
```python
import tvm_ffi

class CompactObject:
    """Wrapper that holds a backend FFI object and exposes it via protocol."""
    def __init__(self, backend_obj):
        self.backend_obj = backend_obj

    def __tvm_ffi_object__(self):
        return self.backend_obj

# Works with any Object type (Array, Map, custom objects, Tensor, etc.)
x = tvm_ffi.convert([1, 2, 3])  # Array object
wrapper = CompactObject(x)

echo = tvm_ffi.get_global_func("testing.echo")
y = echo(wrapper)  # passes through FFI via __tvm_ffi_object__ protocol
assert y.__chandle__() == x.__chandle__()
```
