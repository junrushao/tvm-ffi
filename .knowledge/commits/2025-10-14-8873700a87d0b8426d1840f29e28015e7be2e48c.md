# Rename cached-object attribute and generalize tensor protocol to object protocol

## TL;DR
- Renamed the internal attribute `PyNativeObject.__tvm_ffi_object__` to `_tvm_ffi_cached_object` (and corresponding constructor helper `__init_tvm_ffi_object_by_constructor__` to `__init_cached_object_by_constructor__`) because dunder convention should be reserved for methods, not attributes.
- Generalized the `__tvm_ffi_tensor__` protocol to `__tvm_ffi_object__` so any user-defined class can provide a backing `Object` (not just `Tensor`) for FFI argument passing.
- Added `test_object_protocol` test verifying the new `__tvm_ffi_object__` protocol works with generic `Object` instances.

### Rename Mapping

| Before | After | Kind |
|--------|-------|------|
| `PyNativeObject.__tvm_ffi_object__` (attribute) | `PyNativeObject._tvm_ffi_cached_object` | slot/attribute |
| `__init_tvm_ffi_object_by_constructor__` | `__init_cached_object_by_constructor__` | method |
| `__tvm_ffi_tensor__` (user protocol method) | `__tvm_ffi_object__` (user protocol method) | protocol |
| `TVMFFIPyArgSetterFFITensorCompatible_` | `TVMFFIPyArgSetterFFIObjectCompatible_` | Cython setter function |

```python
class PyNativeObject:
    """Mixin for Python classes that are simultaneously a Python builtin
    and have an FFI Object backing store."""
    _tvm_ffi_cached_object: Object | None  # was: __tvm_ffi_object__
    # Interacts with: String.__slots__, Bytes.__slots__, Shape slot
    # Invariant: None when constructed from Python side without FFI backing

    def __init_cached_object_by_constructor__(self, fconstructor: Function, *args: Any) -> None:
        # was: __init_tvm_ffi_object_by_constructor__
        # Interacts with: Shape.__new__(), which calls this to create FFI backing object
        ...

# User protocol: __tvm_ffi_object__() -> Object
# was: __tvm_ffi_tensor__() -> Tensor
# Any class implementing this protocol can be passed as an FFI argument.
# The setter reads the returned Object's type_index dynamically (was hardcoded kTVMFFITensor).
# Interacts with: TVMFFIPyArgSetterFFIObjectCompatible_ (Cython setter)
# Interacts with: TVMFFIPyArgSetterFactory_ (dispatches to this setter when hasattr(__tvm_ffi_object__))
# Extension: implement __tvm_ffi_object__() on any class to make it FFI-passable

# Cython setter (internal):
# TVMFFIPyArgSetterFFIObjectCompatible_(handle, ctx, py_arg, out)
#   was: TVMFFIPyArgSetterFFITensorCompatible_
#   Key change: out.type_index = TVMFFIObjectGetTypeIndex(obj.chandle)
#     was: out.type_index = kTVMFFITensor (hardcoded)
#   This generalization allows any Object subclass, not just Tensor.
```

## Impact
- API: `__tvm_ffi_tensor__` protocol renamed to `__tvm_ffi_object__`. Any user class implementing the old protocol must rename. The commit message notes this was not in a formal release, so impact is low.
- API: `PyNativeObject.__tvm_ffi_object__` attribute renamed to `_tvm_ffi_cached_object`. This is internal but technically accessible to downstream code referencing the slot directly.
- Behavioral: The `__tvm_ffi_object__` protocol now returns a generic `Object` and the setter dynamically reads `type_index` via `TVMFFIObjectGetTypeIndex` instead of hardcoding `kTVMFFITensor`. This broadens the protocol from Tensor-only to any Object subclass.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **PyNativeObject pattern** -- [0012-python-bindings.md](../designs/0012-python-bindings.md) -- dual-inheritance pattern for Python builtins with FFI backing
- **Cython setter dispatch** -- [0012-python-bindings.md](../designs/0012-python-bindings.md) -- `TVMFFIPyArgSetterFactory_` dispatch chain
- **Object handle and type_index** -- [0002-object-system.md](../designs/0002-object-system.md) -- `TVMFFIObjectGetTypeIndex` for runtime type resolution

Design elements this commit produces:
- **`__tvm_ffi_object__` protocol** (generalized from `__tvm_ffi_tensor__`) -- user-facing protocol for making arbitrary Python objects FFI-passable by returning a backing Object. This is a broader replacement of the tensor-specific protocol.
- **`_tvm_ffi_cached_object` attribute** (renamed from `__tvm_ffi_object__`) -- internal cached FFI Object on PyNativeObject subclasses. Now uses single-underscore to signal internal use.

## Usage Examples
The new `__tvm_ffi_object__` protocol for generic objects (from `test_object_protocol`):

```python
import tvm_ffi

class CompactObject:
    def __init__(self, backend_obj):
        self.backend_obj = backend_obj

    def __tvm_ffi_object__(self):
        """Return backing FFI Object -- works for any Object subclass, not just Tensor."""
        return self.backend_obj

x = tvm_ffi.convert([])
x_compact = CompactObject(x)
test_echo = tvm_ffi.get_global_func("testing.echo")
y = test_echo(x_compact)  # passes through FFI via __tvm_ffi_object__ protocol
assert y.__chandle__() == x.__chandle__()
```
