# Rename __tvm_ffi_tensor__ to __tvm_ffi_object__ and _tvm_ffi_cached_object
## TL;DR
- Renames `PyNativeObject.__tvm_ffi_object__` attribute to `_tvm_ffi_cached_object` (private, not a protocol).
- Renames `__tvm_ffi_tensor__()` protocol to `__tvm_ffi_object__()`, generalizing it for any FFI object type (not just tensors).
- Version bump to 0.1.0b18.

## Impact
- API: Protocol rename from `__tvm_ffi_tensor__` to `__tvm_ffi_object__`. Internal attribute rename. Not yet in a formal release.
- Flags/config: Version bump.
- Data formats/schemas: None.
