# Rename PyNativeObject protocols: __tvm_ffi_tensor__ → __tvm_ffi_object__ (generic Object protocol), __tvm_ffi_object__ attr → _tvm_ffi_cached_object

## TL;DR
- `PyNativeObject.__tvm_ffi_object__` (the *attribute* holding the cached FFI handle) is renamed to `_tvm_ffi_cached_object` to follow the convention that dunders are for methods, not data attributes.
- The user-facing *method* protocol `__tvm_ffi_tensor__` (used on wrapper classes to expose a `tvm_ffi.Tensor` to the FFI call dispatcher) is renamed `__tvm_ffi_object__` and generalized to accept any `ffi.Object` subclass — not just `Tensor`.
- Version bumped `0.1.0b17` → `0.1.0b18`.

| Old name | New name | Kind | Location |
|---|---|---|---|
| `__tvm_ffi_object__` (attribute) | `_tvm_ffi_cached_object` | data attribute on `PyNativeObject` | `object.pxi`, `string.pxi`, `_tensor.py`, `core.pyi` |
| `__init_tvm_ffi_object_by_constructor__` | `__init_cached_object_by_constructor__` | method on `PyNativeObject` | `object.pxi`, `core.pyi` |
| `__tvm_ffi_tensor__` (protocol method) | `__tvm_ffi_object__` (protocol method) | duck-typed method on user wrapper classes | `function.pxi` (dispatcher), `test_tensor.py`, `benchmark_dlpack.py` |
| `TVMFFIPyArgSetterFFITensorCompatible_` | `TVMFFIPyArgSetterFFIObjectCompatible_` | internal Cython setter function | `function.pxi` |

## Impact
- API: **Breaking for external code** that accessed `obj.__tvm_ffi_object__` directly on `String`, `Bytes`, or `Shape` instances (e.g., `y.__tvm_ffi_object__ is not None` in tests). All such call sites updated within this commit. Commit message notes the attribute "is hidden to user" and formal release has not yet been made for `__tvm_ffi_tensor__`.
- Behavioral: The `__tvm_ffi_object__` dispatch branch in `TVMFFIPyArgSetterFactory` now accepts **any** `ffi.Object` subclass (not only `Tensor`). The type index is read dynamically via `TVMFFIObjectGetTypeIndex(chandle)` instead of the former hardcoded `kTVMFFITensor`. This allows arbitrary FFI objects to be passed via the wrapper protocol.
- Flags/config: None
- Data formats/schemas: None

## Design Elements
Design elements this commit consumes:
- `PyNativeObject` + `_tvm_ffi_cached_object` slot — defined in `0013-python-package.md` (`object.pxi`)
- `TVMFFIPyArgSetterFactory` dispatch logic in `function.pxi` — defined in `0016-py-ffi-call-dispatch.md`
- `String`, `Bytes`, `Shape` built-in-subclassing pattern — defined in `0007-containers.md`, `0013-python-package.md`

Design elements this commit produces (mutates):
- **`PyNativeObject._tvm_ffi_cached_object` protocol** (renamed from `__tvm_ffi_object__`): data attribute for cached Object handle on Python built-in subclasses
- **`PyNativeObject.__init_cached_object_by_constructor__`** (renamed from `__init_tvm_ffi_object_by_constructor__`): constructor helper
- **`__tvm_ffi_object__` duck-typed method protocol** (renamed from `__tvm_ffi_tensor__`): user-facing protocol for wrapping any `ffi.Object` in a Python-native type, now generalized beyond `Tensor`

## Usage Examples

New generic object wrapper protocol (`__tvm_ffi_object__` accepting any Object):

```python
# test_object.py — test_object_protocol (added in this commit)
import tvm_ffi
from typing import Any

class CompactObject:
    """Any Python object wrapping a tvm_ffi.Object can now use __tvm_ffi_object__."""
    def __init__(self, backend_obj: Any) -> None:
        self.backend_obj = backend_obj

    def __tvm_ffi_object__(self) -> Any:
        return self.backend_obj

x = tvm_ffi.convert([])          # x is a tvm_ffi.Object (Array)
x_compact = CompactObject(x)
test_echo = tvm_ffi.get_global_func("testing.echo")
y = test_echo(x_compact)          # TVMFFIPyArgSetterFFIObjectCompatible_ dispatches
assert y.__chandle__() == x.__chandle__()
```

Before/after pattern for migration:

```python
# Before (Tensor-specific protocol):
class MyTensorWrapper:
    def __tvm_ffi_tensor__(self) -> tvm_ffi.Tensor:
        return self._tensor

# After (generic Object protocol):
class MyTensorWrapper:
    def __tvm_ffi_object__(self) -> tvm_ffi.Tensor:   # Tensor is a subclass of Object
        return self._tensor
```
