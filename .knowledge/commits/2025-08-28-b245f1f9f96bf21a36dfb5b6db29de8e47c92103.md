# Add git download fallback for libbacktrace ExternalProject
## TL;DR
- The `ExternalProject_Add` call for libbacktrace in `cmake/Utils/AddLibbacktrace.cmake` lacked `GIT_REPOSITORY` and `GIT_TAG` parameters, so CMake had no way to fetch the source when the `3rdparty/libbacktrace` submodule directory was empty.
- This commit adds both parameters, pinning to commit `793921876c981ce49759114d7bb89bb89b2d3a2d` on the upstream `ianlancetaylor/libbacktrace` repository.
