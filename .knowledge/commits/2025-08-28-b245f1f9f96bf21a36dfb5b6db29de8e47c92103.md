# Add missing git download path for libbacktrace in CMake ExternalProject
## TL;DR
- Adds `GIT_REPOSITORY` and `GIT_TAG` to the `ExternalProject_Add` call for libbacktrace, so CMake can auto-download the dependency when the `3rdparty/libbacktrace` submodule is not already populated.

None

## Impact
- API: none
- Behavioral: CMake builds that lack a pre-populated `3rdparty/libbacktrace` submodule will now auto-clone the correct libbacktrace commit instead of failing at configure time.
