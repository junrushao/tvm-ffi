# Add missing git download path for libbacktrace in CMake ExternalProject
## TL;DR
- Adds `GIT_REPOSITORY` and `GIT_TAG` directives to the `ExternalProject_Add(project_libbacktrace ...)` call in `cmake/Utils/AddLibbacktrace.cmake`.
- Without these, CMake's ExternalProject had no download step configured, relying solely on the vendored `3rdparty/libbacktrace` `SOURCE_DIR`. The added directives provide an explicit git-based download path as a fallback or initial fetch mechanism.
