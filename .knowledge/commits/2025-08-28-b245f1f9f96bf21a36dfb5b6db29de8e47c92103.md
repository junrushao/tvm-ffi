# Fix missing GIT_REPOSITORY/GIT_TAG in ExternalProject_Add for libbacktrace

## TL;DR
- `cmake/Utils/AddLibbacktrace.cmake` was missing `GIT_REPOSITORY` and `GIT_TAG` in the `ExternalProject_Add` call, causing the libbacktrace download step to fail silently or error out when the source directory was not already populated.
- Adds the canonical upstream URL (`https://github.com/ianlancetaylor/libbacktrace.git`) and a pinned commit tag (`793921876c981ce49759114d7bb89bb89b2d3a2d`).
