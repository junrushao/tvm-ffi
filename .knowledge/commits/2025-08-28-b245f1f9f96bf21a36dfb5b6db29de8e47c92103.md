# Add missing GIT_REPOSITORY and GIT_TAG to libbacktrace ExternalProject
## TL;DR
- Adds `GIT_REPOSITORY` and `GIT_TAG` fields to the `ExternalProject_Add(project_libbacktrace ...)` call in `cmake/Utils/AddLibbacktrace.cmake`, pinning the download source to a specific commit on `github.com/ianlancetaylor/libbacktrace`.
- Without these fields, CMake's `ExternalProject_Add` had no download step configured, causing the build to fail if the `3rdparty/libbacktrace` source directory was not already populated (e.g., missing git submodule init).

None

## Impact
- API: none
- Behavioral: Builds that rely on `ExternalProject_Add` to fetch libbacktrace now have a valid git download path as fallback. Previously, builds would fail if the vendored submodule was missing.
