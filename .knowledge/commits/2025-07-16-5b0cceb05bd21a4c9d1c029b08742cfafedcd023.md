# Improve duplicate global function registration error to log-and-throw with actionable message
## TL;DR
- Switches `GlobalFunctionTable::Update(const TVMFFIMethodInfo*, bool)` from `TVM_FFI_THROW` to `TVM_FFI_LOG_AND_THROW` for duplicate registration errors, ensuring the message is printed to stderr before the exception is thrown.
- Expands the error message to list possible causes (duplicate `GlobalDef().def` registrations) and a remediation step.
- Only the `TVMFFIMethodInfo*` overload (used during static initialization via `TVM_FFI_REGISTER_GLOBAL`) is changed; the `String`+`Function` overload retains `TVM_FFI_THROW`.

## Impact
- API: none
- Behavioral: Error message for duplicate global function registration is now more descriptive and is always logged to stderr before throwing, improving debuggability during static initialization when exceptions may not propagate cleanly.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_LOG_AND_THROW` macro (design record `0005-ffi-error-protocol`) -- forces `log_before_throw=true` in the `ErrorBuilder`, appropriate for startup-time errors that may not be caught.
- `GlobalFunctionTable` (design record `0004-ffi-function-system`) -- the global string-keyed registry where packed functions are registered and looked up.
- `TVM_FFI_REGISTER_GLOBAL` macro path (design record `0004-ffi-function-system`) -- static-init registration flows through the `Update(const TVMFFIMethodInfo*, bool)` overload.
