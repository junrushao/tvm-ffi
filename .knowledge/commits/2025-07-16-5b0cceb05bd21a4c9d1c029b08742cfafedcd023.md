# Switch duplicate global function registration error to log-and-throw with improved diagnostics
## TL;DR
- In `GlobalFunctionTable::Update(const TVMFFIMethodInfo*, bool)`, replaced `TVM_FFI_THROW` with `TVM_FFI_LOG_AND_THROW` so that duplicate function registration errors are logged to stderr before throwing.
- Improved the error message to describe the probable cause ("two GlobalDef().def registrations for the same function") and remediation ("remove the duplicate registration").
- Only the `TVMFFIMethodInfo*`-based overload (reflection/GlobalDef path) is changed; the `(String, Function, bool)` overload (used by `Function::SetGlobal`) retains the original `TVM_FFI_THROW`.

## Key Exports
None -- no new public API surface. The change is internal to `GlobalFunctionTable::Update` in `src/ffi/function.cc`.

## Impact
- API: None -- the same `RuntimeError` is thrown on duplicate registration.
- Behavioral: Duplicate registration errors via the `TVMFFIMethodInfo*` path now also log to stderr before throwing, making diagnosis easier when exceptions are swallowed or when debugging startup crashes.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- `TVM_FFI_LOG_AND_THROW(ErrorKind)` macro -- logs to stderr then throws, documented in [0006-error-handling.md](../../.knowledge/designs/0006-error-handling.md).
- `GlobalFunctionTable` -- internal class managing the global function registry, documented in [0004-function-system.md](../../.knowledge/designs/0004-function-system.md).
- `GlobalDef().def` reflection registration path -- the `TVMFFIMethodInfo*` overload of `Update` is the target for reflection-based function registration.

Design elements this commit produces:
- None.

## Usage Examples
**Before** (unclear error on duplicate registration):
```
RuntimeError: Global Function `my.func` is already registered
```

**After** (actionable diagnostic logged to stderr and included in thrown error):
```
RuntimeError: Global Function `my.func` is already registered, possible causes:
- Two GlobalDef().def registrations for the same function
Please remove the duplicate registration.
```
