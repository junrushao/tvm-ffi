# Switch duplicate GlobalDef registration error from TVM_FFI_THROW to TVM_FFI_LOG_AND_THROW for better diagnostics
## TL;DR
- Changes the `GlobalFunctionTable::Update(TVMFFIMethodInfo*, bool)` overload to use `TVM_FFI_LOG_AND_THROW` instead of `TVM_FFI_THROW` when a duplicate function registration is detected.
- Improves the error message to suggest the likely cause ("Two GlobalDef().def registrations for the same function") and a remediation ("Please remove the duplicate registration").
- Only the `TVMFFIMethodInfo*`-based overload is changed; the `(String, Function, bool)` overload still uses plain `TVM_FFI_THROW`.

## Key Exports
None. No new public API surface is introduced. The change modifies an internal error path within `GlobalFunctionTable` in `src/ffi/function.cc`.

## Impact
- API: none
- ABI: none
- Behavioral: The duplicate-registration error on the `TVMFFIMethodInfo*` path now logs to stderr before throwing, making it visible even if the exception is swallowed during shared-library loading. The error message is more descriptive.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **`TVM_FFI_LOG_AND_THROW` macro** (`include/tvm/ffi/error.h`): Stream-style error builder that logs to stderr before throwing. Already documented in `.knowledge/designs/error-handling.md` (line 106). Used here because duplicate registration typically occurs at static initialization / library load time, where thrown exceptions may be silently lost.
- **`GlobalFunctionTable` class** (`src/ffi/function.cc`): Internal registry for global functions. Documented in `.knowledge/designs/function-system.md` (lines 70-78). The `Update(TVMFFIMethodInfo*, bool)` overload is the entry point for `GlobalDef().def(...)` static registrations.

Design elements this commit produces:
- None. This is a diagnostic improvement to an existing error path, not a new design element.

## Usage Examples
None. This is an internal error-path improvement. Users do not call this code directly; it triggers when two `TVM_FFI_REGISTER_GLOBAL` or `GlobalDef().def` macros register the same function name in the same binary.
