# Improve duplicate global function registration error to log before throwing
## TL;DR
- In `GlobalFunctionTable::Update(const TVMFFIMethodInfo*, bool)`, replaced `TVM_FFI_THROW` with `TVM_FFI_LOG_AND_THROW` so the error is printed to stderr before being thrown. This helps diagnose static-init-time duplicate registration failures that may otherwise be silently swallowed.
- Improved the error message to include possible causes ("Two GlobalDef().def registrations for the same function") and a suggested fix.

## Key Exports
None -- no new API surface. The change is internal to `GlobalFunctionTable::Update`.

## Impact
- API: None
- Behavioral: Duplicate global function registration via `TVMFFIMethodInfo*` path now logs to stderr before throwing. Previously the error was thrown but could be lost during static initialization if no catch handler was in place.
- Flags/config: None
- Data formats/schemas: None
