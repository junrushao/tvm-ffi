# Upgrade duplicate global function registration error to log-and-throw with actionable message

## TL;DR

- In `GlobalFunctionTable::Update(TVMFFIMethodInfo*, bool)`, the `can_override=false` duplicate-registration guard was changed from `TVM_FFI_THROW` to `TVM_FFI_LOG_AND_THROW`.
- The error message is expanded to name the specific cause (`GlobalDef().def` duplicate) and prescribe a fix.
- Only the `TVMFFIMethodInfo*` overload is affected; the `String`+`Function` overload retains `TVM_FFI_THROW`.

## Key Exports

None — no new public API surface; change is purely to error message content and logging behavior.

## Impact

- API: None — no signature change; `can_override` protocol is unchanged.
- Behavioral: Duplicate `GlobalDef().def` registrations now emit a `stderr` log line before throwing, improving diagnosability during library startup when the exception may not be caught or may produce an opaque stack trace.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **Global function registry** (`GlobalFunctionTable::Update`) — `0003-function-system`: the `can_override` guard that rejects duplicate `TVMFFIMethodInfo` registrations.
- **Error macros** (`TVM_FFI_LOG_AND_THROW` vs `TVM_FFI_THROW`) — `0004-error-propagation`: `TVM_FFI_LOG_AND_THROW` is the startup-safe variant that writes to `stderr` before throwing; the doc comment in `error.h` (line 227) notes it is intended for startup-phase functions where the error cannot be caught.

Design elements this commit produces: None — no new design elements introduced.

## Usage Examples

Before (incorrect path that's now improved):
```cpp
// Before: silent throw with terse message
TVM_FFI_THROW(RuntimeError) << "Global Function `foo` is already registered";

// After: logs to stderr then throws with actionable guidance
TVM_FFI_LOG_AND_THROW(RuntimeError)
    << "Global Function `foo` is already registered, possible causes:\n"
    << "- Two GlobalDef().def registrations for the same function \n"
    << "Please remove the duplicate registration.";
```

## Reflection

### Design docs to write or update

- `0003-function-system`: Minor note opportunity — document that the `TVMFFIMethodInfo*` overload uses `TVM_FFI_LOG_AND_THROW` (startup-safe) while the `String`+`Function` overload uses `TVM_FFI_THROW`. This asymmetry is intentional but currently undocumented.
