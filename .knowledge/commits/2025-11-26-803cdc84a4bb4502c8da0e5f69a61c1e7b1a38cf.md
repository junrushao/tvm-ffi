# Add CUDADeviceGuard documentation to kernel library guide
## TL;DR
- Adds a new "Device Guard" section to `docs/guides/kernel_library_guide.rst` documenting the RAII `tvm::ffi::CUDADeviceGuard` class.
- Describes the save/set/restore pattern for CUDA device context, analogous to `c10::cuda::CUDAGuard`.
- Includes a C++ usage example showing guard construction from `TensorView.device().device_id`.

## Usage Examples
The commit adds this inline example to the kernel library guide:

```cpp
void func(ffi::TensorView input, ...) {
  // current device index is original device index
  ffi::CUDADeviceGuard device_guard(input.device().device_id);
  // current device index is input device index
}
// After func returns, device_guard restores the original device index.
```
