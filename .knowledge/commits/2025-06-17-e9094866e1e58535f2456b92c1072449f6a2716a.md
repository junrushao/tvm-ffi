# Introduce FFI reflection-based object creation and refactor ObjectDef into base/derived hierarchy
## TL;DR
- Adds `ReflectionDefBase` superclass extracted from `ObjectDef`, centralizing field getter/setter, method wrapper, and object creator templates for reuse.
- Introduces `TVMFFITypeExtraInfo` registration (object size, default creator, doc) via new `ObjectDef` constructor and `RegisterExtraInfo`.
- Adds `MakeObjectFromPackedArgs` global function (`ffi.MakeObjectFromPackedArgs`) enabling reflection-driven object construction from key-value packed arguments, traversing the ancestor chain to set inherited fields.
- Enforces `_type_mutable` static assert on `def_rw` -- only mutable types may have writable fields.
- Secondary: replaces deprecated `std::aligned_storage` with manual `alignas` struct in `SimpleObjAllocator`; adds `String::compare(TVMFFIByteArray)`.

## Impact
- API: New global function `ffi.MakeObjectFromPackedArgs` enables creating any reflected type from packed key-value args. `ObjectDef` constructor now accepts variadic extra args for `TVMFFITypeExtraInfo`.
- Behavioral: `def_rw` now enforces `_type_mutable` at compile time -- existing types using `def_rw` without `_type_mutable = true` will fail to compile.
- Flags/config: `_type_mutable` static constexpr becomes load-bearing for `def_rw` (previously unenforced).
- Data formats/schemas: `TVMFFITypeInfo` gains `extra_info` pointer (`TVMFFITypeExtraInfo*`) for object size, creator, and doc.

## Design Elements
Design elements this commit consumes:
- Object system (`0003`): `make_object<T>`, `ObjectPtr`, `ObjectUnsafe` helpers for creator implementation.
- Reflection subsystem (`0007`): `TVMFFIFieldInfo`, `TVMFFITypeInfo`, `GetFieldByteOffsetToObject`, `FieldGetter`/`FieldSetter` templates, `TVMFFITypeRegisterField`.
- Function system (`0004`): `Function::FromTyped` for method wrapping, `TVM_FFI_REGISTER_GLOBAL` for `MakeObjectFromPackedArgs`.
- C ABI (`0001`): `TVMFFIByteArray`, `TVMFFIAny`, `TVMFFISafeCallType` via `TVM_FFI_SAFE_CALL_BEGIN/END`.

Design elements this commit produces:
- `ReflectionDefBase` -- new base class extracting shared reflection utilities from `ObjectDef`, enabling future reuse by other builders.
- `TVMFFITypeExtraInfo` -- new per-type metadata struct (size, creator, doc) registered via `TVMFFITypeRegisterExtraInfo`.
- `MakeObjectFromPackedArgs` -- reflection-driven object factory traversing the ancestor chain to populate inherited fields.
- `_type_mutable` enforcement on `def_rw` -- compile-time guard preventing writable field registration on immutable types.

## Usage Examples

Registering a mutable type with extra info and creating it via packed args:
```cpp
// C++ side: define a mutable type with reflection
class TestObjectBase : public Object {
 public:
  int64_t v_i64;
  double v_f64;
  String v_str;
  static constexpr bool _type_mutable = true;
  static constexpr const char* _type_key = "testing.TestObjectBase";
  TVM_FFI_DECLARE_BASE_OBJECT_INFO(TestObjectBase, Object);
};

// Register with defaults and methods
refl::ObjectDef<TestObjectBase>()
    .def_rw("v_i64", &TestObjectBase::v_i64, refl::DefaultValue(10))
    .def_ro("v_f64", &TestObjectBase::v_f64, refl::DefaultValue(10.0))
    .def_rw("v_str", &TestObjectBase::v_str, refl::DefaultValue("hello"))
    .def("add_i64", &TestObjectBase::AddI64);

// Python side (via global function):
// obj = ffi.MakeObjectFromPackedArgs("testing.TestObjectBase", "v_i64", 42, "v_str", "world")
// obj.v_i64 == 42, obj.v_f64 == 10.0 (default), obj.v_str == "world"
```
