# Introduce FFI reflection support in Python via ObjectDef refactoring, ReflectionDefBase, object creator, and MakeObjectFromPackedArgs

## TL;DR
- Refactors `ObjectDef<T>` to inherit from a new `ReflectionDefBase` base class, hoisting `FieldGetter`, `FieldSetter`, `GetMethod`, `ApplyFieldInfoTrait`, and `ApplyMethodInfoTrait` into the base for reuse.
- Adds `TVMFFITypeExtraInfo` registration (object size, default creator, doc) via `ObjectDef` constructor and new `RegisterExtraInfo` method, enabling Python-side object construction.
- Introduces `MakeObjectFromPackedArgs` (registered as `"ffi.MakeObjectFromPackedArgs"`) to create objects by type key and set fields by name, traversing the ancestor chain.
- Adds `String::compare(const TVMFFIByteArray&)` overload and replaces deprecated `std::aligned_storage` with a manual aligned struct in `SimpleObjAllocator`.
- Enforces `_type_mutable` static_assert on `def_rw` to prevent writable field registration on immutable types.

## Key Exports

**Class: `ReflectionDefBase`** (new, `include/tvm/ffi/reflection/reflection.h`):
Base class extracted from `ObjectDef`, providing reusable static helpers:
```cpp
class ReflectionDefBase {
protected:
  template<typename T> static int FieldGetter(void* field, TVMFFIAny* result);
  template<typename T> static int FieldSetter(void* field, const TVMFFIAny* value);
  template<typename T> static int ObjectCreatorDefault(TVMFFIObjectHandle* result);
  template<typename T> static void ApplyFieldInfoTrait(TVMFFIFieldInfo* info, const T& value);
  template<typename T> static void ApplyMethodInfoTrait(TVMFFIMethodInfo* info, const T& value);
  template<typename T> static void ApplyExtraInfoTrait(TVMFFITypeExtraInfo* info, const T& value);
  template<typename Class, typename R, typename... Args>
  static Function GetMethod(std::string name, R (Class::*func)(Args...));
  template<typename Class, typename R, typename... Args>
  static Function GetMethod(std::string name, R (Class::*func)(Args...) const);
  template<typename Class, typename Func>
  static Function GetMethod(std::string name, Func&& func);
};
```

**Class: `ObjectDef<Class>`** (modified, now extends `ReflectionDefBase`):
```cpp
template<typename Class>
class ObjectDef : public ReflectionDefBase {
public:
  template<typename... ExtraArgs>
  explicit ObjectDef(ExtraArgs&&... extra_args);  // registers TVMFFITypeExtraInfo
  ObjectDef& def_ro(const char* name, T Class::*field_ptr, Extra&&... extra);
  ObjectDef& def_rw(const char* name, T Class::*field_ptr, Extra&&... extra);
    // NEW: static_assert(Class::_type_mutable) enforced
  ObjectDef& def(const char* name, Func&& func, Extra&&... extra);
  ObjectDef& def_static(const char* name, Func&& func, Extra&&... extra);
private:
  void RegisterExtraInfo(ExtraArgs&&... extra_args);  // NEW
};
```

**Function: `MakeObjectFromPackedArgs`** (new, `src/ffi/object.cc`):
```cpp
void MakeObjectFromPackedArgs(ffi::PackedArgs args, Any* ret);
// Registered as "ffi.MakeObjectFromPackedArgs"
// args[0]: String type_key
// args[1], args[2], ...: alternating field_name, field_value pairs
// Returns: ObjectRef with all fields set
```

**Method: `String::compare(const TVMFFIByteArray&)`** (new, `include/tvm/ffi/string.h`):
```cpp
int compare(const TVMFFIByteArray& other) const;
```

**Struct: `SimpleObjAllocator::Handler<T>::StorageType`** (changed, `include/tvm/ffi/memory.h`):
```cpp
// Before: using StorageType = std::aligned_storage<sizeof(T), alignof(T)>::type;
// After:
struct alignas(T) StorageType { char data[sizeof(T)]; };
```

## Impact
- API: New global function `"ffi.MakeObjectFromPackedArgs"` enables Python (and other languages) to construct any reflectable object by type key + keyword arguments. `ObjectDef` constructor now accepts variadic extra args for `TVMFFITypeExtraInfo`.
- Behavioral: `def_rw` now enforces `Class::_type_mutable == true` at compile time. Test objects `TFloatObj` and `TPrimExprObj` swap their ro/rw designations to match mutability constraints.
- Flags/config: None.
- Data formats/schemas: `TVMFFITypeExtraInfo` struct is newly populated for types using `ObjectDef` (size, creator function pointer, doc string).

Design elements this commit produces:
- **`ReflectionDefBase`**: New base class factoring out shared reflection helpers (getters, setters, method wrappers, trait applicators, object creator). Enables future alternative reflection builders beyond `ObjectDef`.
- **`TVMFFITypeExtraInfo` registration**: `ObjectDef` constructor now registers `TVMFFITypeExtraInfo` (total_size, creator, doc) for each type, enabling runtime object construction.
- **`ObjectCreatorDefault<T>`**: Default creator using `make_object<T>()` for default-constructible types.
- **`MakeObjectFromPackedArgs`**: Global packed function that creates objects from type key + field name/value pairs, walking the ancestor chain to set inherited fields.
- **`_type_mutable` enforcement on `def_rw`**: Compile-time invariant that only mutable types can register writable fields.

## Usage Examples

**Creating an object from Python via packed args (conceptual end-to-end):**
```cpp
// C++ registration (testing.cc):
class TestObjectBase : public Object {
 public:
  int64_t v_i64;
  double v_f64;
  String v_str;
  static constexpr bool _type_mutable = true;
  static constexpr const char* _type_key = "testing.TestObjectBase";
  TVM_FFI_DECLARE_BASE_OBJECT_INFO(TestObjectBase, Object);
};

refl::ObjectDef<TestObjectBase>()
    .def_rw("v_i64", &TestObjectBase::v_i64, refl::DefaultValue(10))
    .def_ro("v_f64", &TestObjectBase::v_f64, refl::DefaultValue(10.0))
    .def_rw("v_str", &TestObjectBase::v_str, refl::DefaultValue("hello"))
    .def("add_i64", &TestObjectBase::AddI64);

// Python side (conceptual):
# make_obj = get_global_func("ffi.MakeObjectFromPackedArgs")
# obj = make_obj("testing.TestObjectBase", "v_i64", 42, "v_str", "world")
# assert obj.v_i64 == 42
# assert obj.v_f64 == 10.0  # default
# assert obj.v_str == "world"
```

**Ancestor chain traversal in MakeObjectFromPackedArgs:**
```cpp
// For TestObjectDerived (extends TestObjectBase):
// 1. Skip ancestor[0] (always root Object)
// 2. Set fields from TestObjectBase (v_i64, v_f64, v_str)
// 3. Set fields from TestObjectDerived (v_map, v_array)
// Missing fields with defaults use the default; missing without default -> TypeError
```
