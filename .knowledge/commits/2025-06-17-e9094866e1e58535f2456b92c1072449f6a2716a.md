# Extend reflection system with extra-info registration, object creation from packed args, and mutability enforcement

## TL;DR
- Adds `ReflectionDefBase` as a base class for `ObjectDef`, extracting getter/setter/method helpers so they can be shared across reflection builders.
- Introduces `TVMFFITypeExtraInfo` registration in `ObjectDef` constructor (object size, default creator, doc), enabling generic object construction by type key.
- Adds `ffi.MakeObjectFromPackedArgs` global function: creates objects by type key and sets fields from keyword-style packed arguments, walking the ancestor chain.
- Enforces `_type_mutable` static assertion on `def_rw` -- only mutable types can have writable fields.
- Minor: `String::compare(TVMFFIByteArray)` overload, `std::aligned_storage` replacement, `TVM_FFI_INLINE` annotations.

## Impact
- API: New global function `ffi.MakeObjectFromPackedArgs` enables generic object construction from Python/Rust. `ObjectDef` constructor now auto-registers extra info.
- Behavioral: `def_rw` now enforces `_type_mutable` at compile time -- existing code using `def_rw` on immutable types will fail to compile. Test adjustments show `TFloatObj.value` changed from `def_rw` to `def_ro` and `TPrimExprObj.dtype` from `def_ro` to `def_rw` to match mutability.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (0002): `Object`, `ObjectPtr`, `make_object<T>`, `ObjectUnsafe` for pointer manipulation
- **Reflection** (0008): `TVMFFIFieldInfo` (getter/setter/offset), `TVMFFITypeInfo` (type hierarchy with `type_acenstors`, `type_depth`), `GetFieldByteOffsetToObject`
- **C ABI** (0007): `TVMFFITypeExtraInfo`, `TVMFFITypeRegisterExtraInfo`, `TVMFFITypeKeyToIndex`, `TVMFFIGetTypeInfo`
- **Function system** (0003): `Function::FromTyped` for method wrapping, `TVM_FFI_REGISTER_GLOBAL` for `ffi.MakeObjectFromPackedArgs`
- **Containers** (0006): `Map`, `Array`, `String` used in test objects

Design elements this commit produces:
- **`ReflectionDefBase`** (new): Extracted base class containing getter/setter templates and method-wrapping helpers. Enables future reflection builder variants.
- **`ObjectDef::RegisterExtraInfo`** (new): Registers `TVMFFITypeExtraInfo` (size, default creator, doc) during `ObjectDef` construction.
- **`MakeObjectFromPackedArgs`** (new): Generic object factory walking the type ancestor chain to populate fields from keyword arguments.
- **`String::compare(TVMFFIByteArray)`** (new): Enables direct string comparison with C ABI byte arrays without constructing `String` objects.
- **Mutability enforcement on `def_rw`** (new invariant): `static_assert(Class::_type_mutable)` prevents writable fields on immutable types.

## Usage Examples

Registering a reflected type with extra info and creating it from packed args (C++):
```cpp
// Define mutable object with reflected fields
class MyObj : public Object {
 public:
  int64_t x;
  String name;
  static constexpr bool _type_mutable = true;
  static constexpr const char* _type_key = "test.MyObj";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(MyObj, Object);
};

// Registration: constructor now auto-registers extra info (size + creator)
TVM_FFI_STATIC_INIT_BLOCK({
  reflection::ObjectDef<MyObj>()
      .def_rw("x", &MyObj::x, reflection::DefaultValue(0))
      .def_rw("name", &MyObj::name, reflection::DefaultValue("default"));
});

// Create from packed args (as Python would call it):
Function make = get_global_func("ffi.MakeObjectFromPackedArgs");
Any result = make("test.MyObj", "x", 42, "name", "hello");
```
