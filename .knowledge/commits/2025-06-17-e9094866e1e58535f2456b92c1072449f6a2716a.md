# Introduce ReflectionDefBase, type extra info registration, and packed-args object creation for Python reflection
## TL;DR
- Extracts shared reflection utilities (field getter/setter, method wrappers, trait applicators) from `ObjectDef` into a new `ReflectionDefBase` base class, enabling reuse by future reflection builders.
- Adds `RegisterExtraInfo` to `ObjectDef` constructor, which registers a `TVMFFITypeExtraInfo` (creator function, total_size, doc) for each reflected type, enabling runtime object creation via `TVMFFITypeExtraInfo.creator`.
- Introduces `ffi.MakeObjectFromPackedArgs`, a global function that creates objects from keyword-value pairs using the type table, traversing the ancestor chain to populate inherited fields -- the key primitive for Python-side reflection-based construction.
- Adds `static_assert(Class::_type_mutable)` guard on `def_rw` to enforce mutability at compile time.

## Impact
- API: New global function `ffi.MakeObjectFromPackedArgs` enables Python-side construction of C++ objects using reflection metadata. `ReflectionDefBase` becomes available for other reflection builders to inherit.
- Behavioral: `def_rw` now enforces `_type_mutable` at compile time -- existing code using `def_rw` on non-mutable types will fail to compile. Test updates show `TFloatObj.value` changed from `def_rw` to `def_ro` and `TPrimExprObj.dtype` changed from `def_ro` to `def_rw` to align with their actual mutability.
- Flags/config: none
- Data formats/schemas: `TVMFFITypeExtraInfo` (pre-existing C ABI struct) is now populated by `ObjectDef` constructor for all reflected types.

## Usage Examples

### Registering a reflected type with inheritance and creating it from packed args

**Context**: C++ type definition with inherited fields, registered via `ObjectDef`, then constructed from Python via `ffi.MakeObjectFromPackedArgs`.

```cpp
// C++ side: define base + derived with reflection
class TestObjectBase : public Object {
 public:
  int64_t v_i64;
  double v_f64;
  String v_str;
  int64_t AddI64(int64_t other) const { return v_i64 + other; }
  static constexpr bool _type_mutable = true;
  static constexpr const char* _type_key = "testing.TestObjectBase";
  TVM_FFI_DECLARE_BASE_OBJECT_INFO(TestObjectBase, Object);
};

class TestObjectDerived : public TestObjectBase {
 public:
  Map<Any, Any> v_map;
  Array<Any> v_array;
  static constexpr const char* _type_key = "testing.TestObjectDerived";
  TVM_FFI_DECLARE_FINAL_OBJECT_INFO(TestObjectDerived, TestObjectBase);
};

// Register fields (constructor auto-registers extra_info with creator)
refl::ObjectDef<TestObjectBase>()
    .def_rw("v_i64", &TestObjectBase::v_i64, refl::DefaultValue(10))
    .def_ro("v_f64", &TestObjectBase::v_f64, refl::DefaultValue(10.0))
    .def_rw("v_str", &TestObjectBase::v_str, refl::DefaultValue("hello"))
    .def("add_i64", &TestObjectBase::AddI64);

refl::ObjectDef<TestObjectDerived>()
    .def_ro("v_map", &TestObjectDerived::v_map)
    .def_ro("v_array", &TestObjectDerived::v_array);
```

```python
# Python side (conceptual):
make = get_global_func("ffi.MakeObjectFromPackedArgs")
obj = make("testing.TestObjectDerived", "v_i64", 42, "v_str", "world")
# Walks ancestor chain: sets TestObjectBase fields first, then TestObjectDerived fields
# v_i64=42, v_f64=10.0 (default), v_str="world", v_map=default, v_array=default
```
