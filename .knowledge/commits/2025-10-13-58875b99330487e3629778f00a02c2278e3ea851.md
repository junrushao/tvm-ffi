# Fix CMake include path to use CMAKE_CURRENT_LIST_DIR for subdir builds
## TL;DR
- Replace `CMAKE_SOURCE_DIR` with `CMAKE_CURRENT_LIST_DIR` in the `DetectTargetTriple.cmake` include directive, fixing builds where tvm-ffi is consumed as a CMake subdirectory (via `add_subdirectory`).
