# Fix CMake include path to use CMAKE_CURRENT_LIST_DIR for subdirectory builds
## TL;DR
- Changed `CMAKE_SOURCE_DIR` to `CMAKE_CURRENT_LIST_DIR` for the `DetectTargetTriple.cmake` include, fixing builds where TVM FFI is used as a CMake subdirectory.
- The other `include()` calls in the same file already used `CMAKE_CURRENT_LIST_DIR`; this was the sole inconsistent one.

- Behavioral: fixes CMake configuration failure when TVM FFI is added via `add_subdirectory()` from a parent project — `CMAKE_SOURCE_DIR` would resolve to the parent project root instead of the TVM FFI source tree.
