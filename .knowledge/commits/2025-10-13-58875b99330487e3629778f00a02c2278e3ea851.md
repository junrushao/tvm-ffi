# Fix CMake include path to use CMAKE_CURRENT_LIST_DIR for subdirectory builds
## TL;DR
- Replaced `CMAKE_SOURCE_DIR` with `CMAKE_CURRENT_LIST_DIR` in the top-level `CMakeLists.txt` for the `DetectTargetTriple.cmake` include, fixing builds where TVM FFI is consumed as a CMake subdirectory (via `add_subdirectory()`).
