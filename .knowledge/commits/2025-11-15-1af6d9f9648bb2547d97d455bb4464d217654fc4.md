# Refactor tvm-ffi-stubgen into staged pipeline with import directive
## TL;DR
- Rebuilds `tvm-ffi-stubgen` from monolithic `stubgen.py` into staged pipeline: `file_utils.py` (parsing), `consts.py` (constants), `codegen.py` (generation), `analysis.py` (import inference), `cli.py` (CLI), `utils.py` (helpers)
- Introduces `import` directive (`tvm-ffi-stubgen(begin): import` / `tvm-ffi-stubgen(end): import`) that auto-generates required imports for stubs
- CLI now supports `--dry-run`, `--verbose` mode and whole-tree scanning
- Adopts new directive syntax across public Python surface: `_ffi_api.py`, `access_path.py`, `module.py`, `testing.py`
- Removes old monolithic `stubgen.py` and its tests

## Impact
- API: New `import` directive for stub generation; old stubgen.py removed
- Behavioral: Stub generation is now staged, supports tree scanning and dry-run
- Flags/config: CLI gains `--dry-run` and `--verbose` flags
- Data formats/schemas: New `import` block format in generated stubs
