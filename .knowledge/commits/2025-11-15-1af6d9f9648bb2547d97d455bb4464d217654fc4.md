# Refactor stubgen into staged pipeline, introduce directive `import`
## TL;DR
- Refactors `tvm-ffi-stubgen` from a monolithic `stubgen.py` into a staged pipeline with separate modules: `file_utils.py` (parsing), `consts.py` (directives/format constants), `analysis.py` (analysis), `codegen.py` (code generation), `cli.py` (CLI), and `utils.py` (utilities).
- Introduces a new `import` directive for stubgen markers, allowing explicit import injection in generated stubs.
- Removes the old monolithic `stubgen.py` and associated tests, replacing with new modular structure.

## Key Exports

**Python Modules:**
- `tvm_ffi.stub.file_utils` -- File parsing utilities for stubgen markers.
- `tvm_ffi.stub.consts` -- Directive and format constants for stubgen.
- `tvm_ffi.stub.analysis` -- Analysis logic for extracting type information from the C++ reflection registry.
- `tvm_ffi.stub.codegen` -- Code generation for inline stubs.
- `tvm_ffi.stub.cli` -- CLI entry point for `tvm-ffi-stubgen`.
- `tvm_ffi.stub.utils` -- Shared utility functions.

**Directives:**
- `import` directive in stubgen markers -- Allows injecting import statements into generated stub blocks.

## Impact
- API: Stubgen now uses a modular pipeline; old monolithic API removed.
- ABI: none
- Behavioral: Stubgen output remains compatible; new `import` directive enables more flexible stub generation.
- Flags/config: none
- Data formats/schemas: Stubgen marker format extended with `import` directive.

## Design Elements
Design elements this commit consumes:
- Stubgen marker format (`tvm-ffi-stubgen(begin)` / `tvm-ffi-stubgen(end)`)
- C++ reflection registry for type/method/field extraction

Design elements this commit produces:
- **Staged stubgen pipeline** -- Modular architecture with distinct parsing, analysis, codegen, and CLI stages.
- **`import` directive** -- New marker directive for injecting imports in generated stubs.

## Usage Examples
```python
# In a .py file, use the import directive:
# tvm-ffi-stubgen(begin, import=typing)
# ... generated stubs will include 'import typing' ...
# tvm-ffi-stubgen(end)
```
