# Refactor tvm-ffi-stubgen into staged pipeline with new import directive
## TL;DR
- Splits monolithic `stub/stubgen.py` (528 lines) into five modules: `cli.py` (entry point), `consts.py` (constants/directives), `file_utils.py` (parsing/FileInfo/CodeBlock), `codegen.py` (stub generation), `analysis.py` (global func collection, ty-map collection), `utils.py` (Options dataclass).
- Introduces new `import` directive block (`# tvm-ffi-stubgen(begin): import` / `# tvm-ffi-stubgen(end)`) that auto-generates `from __future__ import annotations`, `TYPE_CHECKING` imports, and any types referenced by generated stubs.
- Changes stub output format: field annotations are now emitted as PEP 526 class-level attributes (outside `TYPE_CHECKING`) while method stubs remain guarded inside `if TYPE_CHECKING:`. Previously, both fields and methods were inside `TYPE_CHECKING`.
- Updates `_ffi_api.py`, `access_path.py`, `module.py`, and `testing.py` to use new `import` blocks and `ty-map` directive syntax.
- Removes `tests/python/test_stubgen.py` (182 lines).
- CLI entry point moves from `tvm_ffi.stub.stubgen:__main__` to `tvm_ffi.stub.cli:__main__`.
- Adds `--dry-run` and `--verbose` CLI flags.

## Key Exports
**Module structure** (`python/tvm_ffi/stub/`):

| Module | Responsibility |
|--------|---------------|
| `cli.py` | `__main__()` entry point, argparse, staged orchestration |
| `consts.py` | Marker strings (`STUB_BEGIN`, `STUB_END`, etc.), `TY_MAP_DEFAULTS`, `TY_TO_IMPORT`, `MOD_MAP` |
| `file_utils.py` | `FileInfo`, `CodeBlock` dataclasses, `collect_files()` |
| `codegen.py` | `generate_global_funcs()`, `generate_object()`, `generate_imports()` |
| `analysis.py` | `collect_global_funcs()`, `collect_ty_maps()` |
| `utils.py` | `Options` dataclass |

**New directive**: `# tvm-ffi-stubgen(begin): import` -- auto-generates import block with all types used by generated stubs.

**Key classes**:
- `CodeBlock(kind, param, lineno_start, lineno_end, lines)` -- `kind` is one of `"global"`, `"object"`, `"ty-map"`, `"import"`, `None`
- `FileInfo(path, code_blocks, original_lines)` -- parsed file with `update(show_diff, dry_run)` method
- `Options(dlls, indent, files, verbose, dry_run)` -- replaces old `Options` (adds `verbose`, `dry_run`; removes `suppress_print`)

## Impact
- API: CLI entry point moved (`tvm_ffi.stub.stubgen:__main__` -> `tvm_ffi.stub.cli:__main__`). Updated in `pyproject.toml`.
- Behavioral: Generated stubs now place field annotations outside `TYPE_CHECKING` (visible at runtime for dataclass-like reflection), while methods remain `TYPE_CHECKING`-only. Method signatures now use `self` instead of positional `_0`.
- Flags/config: New `--verbose` and `--dry-run` flags.
- Data formats/schemas: New `ty-map` directive syntax (standalone `# tvm-ffi-stubgen(ty-map): A -> B` line, not inside a begin/end block).

## Design Elements
Design elements this commit consumes:
- **Stub generation system** ([0020-stubgen.md](../designs/0020-stubgen.md)): Refactored from single-file to staged pipeline.
- **FFI reflection registry** ([0009-reflection.md](../designs/0009-reflection.md)): Used by `collect_global_funcs()` via `list_global_func_names()`.

Design elements this commit produces:
- **Staged stubgen pipeline**: Three-stage architecture: (1) parse files and collect ty-maps, (2) generate global/object stubs tracking type usage, (3) generate import blocks from collected type usage.
- **`import` directive**: New block type that auto-infers needed imports from the types used in generated stubs.
- **PEP 526 field annotations outside TYPE_CHECKING**: Fields are now runtime-visible annotations, enabling potential runtime introspection.

## Usage Examples
```python
# New import directive in source files:
# tvm-ffi-stubgen(begin): import
# fmt: off
# isort: off
from __future__ import annotations
from typing import Any, TYPE_CHECKING
if TYPE_CHECKING:
    from collections.abc import Sequence
    from tvm_ffi import Object
# isort: on
# fmt: on
# tvm-ffi-stubgen(end)

# ty-map directive (standalone, not in begin/end block):
# tvm-ffi-stubgen(ty-map): ffi.reflection.AccessStep -> ffi.access_path.AccessStep

# Object block now emits fields outside TYPE_CHECKING:
# tvm-ffi-stubgen(begin): object/ffi.reflection.AccessStep
# fmt: off
kind: int
key: Any
# fmt: on
# tvm-ffi-stubgen(end)
```
