# Refactor tvm-ffi-stubgen into staged pipeline with new import directive and modular architecture

## TL;DR
- Deletes monolithic `stub/stubgen.py` (528 lines); replaces with 5 new modules: `consts.py`, `file_utils.py`, `codegen.py`, `analysis.py`, `cli.py`, plus `utils.py`.
- Introduces new `import` directive (`tvm-ffi-stubgen(begin): import`) that auto-generates required import blocks from type maps.
- CLI (`cli.py`) now scans whole directory trees, honors `ty-map` directives, and supports `--dry-run`/`--verbose`.
- Adopts new directives across `_ffi_api.py`, `access_path.py`, `module.py`, `testing.py`.

## Impact
- API: `tvm-ffi-stubgen python` CLI unchanged. New `import` directive added (additive).
- Behavioral: Stubgen now scans entire directory trees (not just listed files); honors `skip-file` directive; generates `import` blocks automatically.
- Flags/config: `--dry-run`, `--verbose` flags added to CLI.
- Data formats/schemas: New `# tvm-ffi-stubgen(begin): import` directive format.
