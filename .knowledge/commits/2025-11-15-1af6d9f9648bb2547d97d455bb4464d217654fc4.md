# Refactor stubgen into staged pipeline with import directive support
## TL;DR
- Completely restructures `tvm-ffi-stubgen` from a monolithic `stubgen.py` (528 lines, deleted) into a staged pipeline with separate modules: `analysis.py`, `cli.py`, `codegen.py`, `consts.py`, `file_utils.py`, `utils.py`.
- Introduces new `import` directive that auto-generates `TYPE_CHECKING` import blocks needed by stubs.
- Adds `ty-map` directive support for mapping C++ types to Python type annotations.
- Adds `--dry-run` and `--verbose` CLI options; supports whole-tree scanning.

## Impact
- API: New stubgen directives (`import`, `ty-map`); CLI interface changes (`--dry-run`, `--verbose`)
- Flags/config: None
- Data formats/schemas: Stub file format extended with `import` blocks
