# Remove tvm:: namespace re-exports of ffi types to enforce tvm::ffi:: qualification
## TL;DR
- Removes all `using ffi::X` declarations from the `tvm::` namespace in 8 public FFI headers.
- After this commit, `Array`, `Map`, `String`, `Bytes`, `Variant`, `Optional`, `make_object`, `GetObjectPtr`, and `GetRef` must be accessed as `tvm::ffi::X` instead of `tvm::X`.
- Preparatory cleanup for isolating the FFI package from the broader TVM namespace.

### Namespace migration table

| Old (removed)         | New (required)             | Header                              |
|-----------------------|----------------------------|--------------------------------------|
| `tvm::Array`          | `tvm::ffi::Array`          | `include/tvm/ffi/container/array.h`  |
| `tvm::Map`            | `tvm::ffi::Map`            | `include/tvm/ffi/container/map.h`    |
| `tvm::Variant`        | `tvm::ffi::Variant`        | `include/tvm/ffi/container/variant.h`|
| `tvm::Optional`       | `tvm::ffi::Optional`       | `include/tvm/ffi/optional.h`         |
| `tvm::String`         | `tvm::ffi::String`         | `include/tvm/ffi/string.h`           |
| `tvm::Bytes`          | `tvm::ffi::Bytes`          | `include/tvm/ffi/string.h`           |
| `tvm::make_object`    | `tvm::ffi::make_object`    | `include/tvm/ffi/memory.h`           |
| `tvm::GetObjectPtr`   | `tvm::ffi::GetObjectPtr`   | `include/tvm/ffi/cast.h`             |
| `tvm::GetRef`         | `tvm::ffi::GetRef`         | `include/tvm/ffi/cast.h`             |

## Key Exports
None -- this commit only removes re-exports; no new symbols are introduced.

## Impact
- API: Breaking for downstream C++ code using `tvm::Array`, `tvm::Map`, `tvm::String`, `tvm::Bytes`, `tvm::Variant`, `tvm::Optional`, `tvm::make_object`, `tvm::GetObjectPtr`, or `tvm::GetRef`. All must migrate to `tvm::ffi::` prefix.
- Behavioral: None -- no runtime semantics changed.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- C++ namespace conventions for `tvm::ffi::` (documented across 0002-object-system, 0005-type-traits-protocol, 0006-containers)

Design elements this commit produces:
- None -- enforces existing `tvm::ffi::` namespace convention by removing legacy shortcuts.

## Usage Examples
Before (no longer compiles):
```cpp
#include <tvm/ffi/container/array.h>
tvm::Array<int> arr;                    // Error: no type 'Array' in namespace 'tvm'
auto obj = tvm::make_object<FooObj>();  // Error: no function 'make_object' in namespace 'tvm'
```

After:
```cpp
#include <tvm/ffi/container/array.h>
tvm::ffi::Array<int> arr;                    // OK
auto obj = tvm::ffi::make_object<FooObj>();  // OK
```
