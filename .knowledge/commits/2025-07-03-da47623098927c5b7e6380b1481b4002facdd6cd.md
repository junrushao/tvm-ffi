# Remove dead `_type_has_method_visit_attrs` flag from Object base class
## TL;DR
- Removes the `static constexpr bool _type_has_method_visit_attrs = true` declaration from the `Object` base class in `include/tvm/ffi/object.h`.
- This flag was a leftover from the legacy `VisitAttrs` mechanism, which has been fully replaced by the reflection system (`TVM_FFI_REFLECTION_DEF`, `TVMFFIFieldInfo`).
- No functional change: the removed constant had no remaining consumers in the codebase.

None

## Impact
- API: None -- the removed field was a compile-time constant in a base class, not part of any public API surface. Downstream code that referenced `Object::_type_has_method_visit_attrs` would fail to compile, but this symbol had no known consumers after the VisitAttrs phase-out.
- Behavioral: None
- Flags/config: None
- Data formats/schemas: None
