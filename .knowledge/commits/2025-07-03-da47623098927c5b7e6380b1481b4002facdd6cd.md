# Remove legacy _type_has_method_visit_attrs static field from Object base class
## TL;DR
- Removes the `_type_has_method_visit_attrs` static constexpr bool from the `Object` base class in `include/tvm/ffi/object.h`.
- This field was a vestige of the old TVM VisitAttrs visitor pattern, now fully replaced by the reflection system (0008-reflection).
- No functional change; the field was not referenced within the FFI layer.
