# Fix unused-parameter and extra-semicolon compiler warnings
## TL;DR
- Add `[[maybe_unused]]` to the `num_args` parameter in `TypedOverload::GetMismatchMessageAux` to silence unused-parameter warnings (the recursion terminates via compile-time `kNumArgs`, not the runtime argument).
- Remove trailing semicolons after all `TVM_FFI_DLL_EXPORT_TYPED_FUNC(...)` call sites across examples, src, and tests. The macro already expands to a complete declaration ending with `}`, so the trailing `;` produced a `-Wextra-semi` warning.
