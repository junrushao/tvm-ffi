# Fix error propagation order in TVMFFIEnvTensorAlloc
## TL;DR
- Reorders checks in `TVMFFIEnvTensorAlloc`: now checks return code *before* asserting `dlpack_tensor != nullptr`, allowing proper error message propagation from the allocator
- Replaces `TVM_FFI_ICHECK` (internal assert) with `TVM_FFI_CHECK(cond, RuntimeError)` for user-facing error
- Adds `AllocationError` to Python error registry

## Key Exports
```python
# Before: TVM_FFI_ICHECK(dlpack_tensor != nullptr) ran first, hiding allocator errors
# After:  if (ret != 0) return ret;  // propagates allocator's error first
#         TVM_FFI_CHECK(dlpack_tensor != nullptr, RuntimeError) << "..."
```

## Impact
- API: None
- Behavioral: Allocator errors now propagate correctly instead of being masked by null-pointer assertions
- Flags/config: None
- Data formats/schemas: None
