# Fix error propagation order in TVMFFIEnvTensorAlloc and standardize allocator error kind to MemoryError
## TL;DR
- Reorder checks in `TVMFFIEnvTensorAlloc`: check allocator return code before asserting non-null on the output tensor, so the allocator's error message propagates correctly instead of being masked by a generic internal check.
- Replace `TVM_FFI_ICHECK` (InternalError) with `TVM_FFI_CHECK(..., RuntimeError)` for the post-return-code null-pointer guard, providing a meaningful error message.
- Standardize the error kind for allocation failures from the ad-hoc `"TorchDLPackManagedTensorAllocator"` to `"MemoryError"` across both Torch DLPack and test allocators, and register `MemoryError` in the Python error registry.

## Key Exports
None — no new public API surface. The behavioral fix is internal to `TVMFFIEnvTensorAlloc`.

## Impact
- API: None — no signature changes.
- Behavioral: `TVMFFIEnvTensorAlloc` now correctly propagates the allocator's error (kind + message) to the caller when the allocator returns a non-zero code. Previously, `TVM_FFI_ICHECK(dlpack_tensor != nullptr)` ran before the return-code check, masking the allocator error with a generic `InternalError`.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Error protocol** ([0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md)): Uses `TVM_FFI_CHECK(cond, ErrorKind)` macro, `SetError` callback pattern in allocator API, and `register_error` Python-side registration.
- **Env tensor allocator** ([0011-ffi-module-system](../design-records/0011-ffi-module-system.md)): The `TVMFFIEnvTensorAlloc` function and `DLPackManagedTensorAllocator` callback with `SetError` convention.
- **Python error registry** ([0005-ffi-error-protocol](../design-records/0005-ffi-error-protocol.md)): `register_error("MemoryError", MemoryError)` maps the C++ error kind string to Python's built-in `MemoryError`.

Design elements this commit produces:
- None — purely restores an invariant that was previously violated.

## Usage Examples
**Before** (broken error propagation):
```cpp
// In TVMFFIEnvTensorAlloc, the old code:
int ret = (*dlpack_alloc)(prototype, &dlpack_tensor, nullptr, TVMFFIEnvTensorAllocSetError);
TVM_FFI_ICHECK(dlpack_tensor != nullptr);  // Fires BEFORE checking ret, masks allocator error
if (ret != 0) return ret;                  // Never reached when allocator returns null + error
```

**After** (correct propagation):
```cpp
// In TVMFFIEnvTensorAlloc, the fixed code:
int ret = (*dlpack_alloc)(prototype, &dlpack_tensor, nullptr, TVMFFIEnvTensorAllocSetError);
if (ret != 0) return ret;  // Propagate allocator's error first
TVM_FFI_CHECK(dlpack_tensor != nullptr, RuntimeError)
    << "TVMFFIEnvTensorAlloc: failed to allocate a tensor from the allocator";
```

The test verifies end-to-end error kind propagation:
```cpp
try {
  Tensor::FromEnvAlloc(TVMFFIEnvTensorAlloc, {1, 2, 3}, DLDataType({kDLFloat, 32, 1}),
                       DLDevice({kDLCPU, 0}));
} catch (const tvm::ffi::Error& e) {
  EXPECT_EQ(e.kind(), "MemoryError");           // Previously would have been "InternalError"
  EXPECT_EQ(e.message(), "TestDLPackManagedTensorAllocatorError");
  throw;
}
```
