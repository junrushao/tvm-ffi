# Change squash commit default from DEFAULT to PR_TITLE_AND_DESC in .asf.yaml
## TL;DR
- Changed `squash_commit_message` setting in `.asf.yaml` from `DEFAULT` to `PR_TITLE_AND_DESC`, so squash-merged PRs use the PR title and description as the commit message instead of the GitHub default.

## Key Exports
None

## Impact
- API: none
- Behavioral: Squash-merged PRs now produce commit messages containing the PR title and body text instead of the GitHub default (which concatenates individual commit messages).
- Flags/config: `.asf.yaml` `squash_commit_message` changed from `DEFAULT` to `PR_TITLE_AND_DESC`
