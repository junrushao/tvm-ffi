# Update squash commit default to PR_TITLE_AND_DESC in .asf.yaml
## TL;DR
- Changed the GitHub squash-merge commit message default from `DEFAULT` to `PR_TITLE_AND_DESC` in `.asf.yaml`, so merged PRs use the PR title and description as the commit message instead of the GitHub default.

None

## Impact
- API: none
- Behavioral: Squash-merged PRs now use `PR_TITLE_AND_DESC` as the commit message template instead of GitHub's `DEFAULT` format. This affects all future squash merges on the repository.
- Flags/config: `.asf.yaml` `github.merge_options.squash_commit_message` changed from `DEFAULT` to `PR_TITLE_AND_DESC`.
