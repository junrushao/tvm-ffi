# Change default squash-commit message format to PR_TITLE_AND_DESC in .asf.yaml

## TL;DR
- Updates `.asf.yaml` GitHub merge settings: `squash_commit_message` changed from `DEFAULT` to `PR_TITLE_AND_DESC`.
- Squash-merged PRs now preserve both the PR title and the PR description body in the resulting commit message, rather than using GitHub's default format.
