# Update squash commit default to PR title and description

## TL;DR
- Changes the `squash_commit_message` setting in `.asf.yaml` from `DEFAULT` to `PR_TITLE_AND_DESC`, so squash-merged PRs use the PR title and description as the commit message instead of the GitHub default.
