# Fix `tvm-ffi-config --sourcedir` by checking `src/` instead of `cmake/` in wheel installs
## TL;DR
- `find_source_path()` in `libinfo.py` checked for a `cmake/` subdirectory to locate the source root, but in wheel installs the CMake files live under `share/cmake/`, so the check always failed.
- Switches the condition to check for `src/` instead, which exists at the same relative path in both dev and wheel layouts.

## Key Exports
None -- no new API surface; one-line condition fix in an existing internal function.

## Impact
- API: none
- Behavioral: `tvm-ffi-config --sourcedir` now correctly returns the source path when invoked from a wheel-installed package (previously raised `RuntimeError`).
- Flags/config: `--sourcedir` flag of the `tvm-ffi-config` CLI now works in wheel installs.
- Data formats/schemas: none

## Usage Examples
Before (broken in wheel installs):
```python
# find_source_path() checked: (candidate_path / "cmake").is_dir()
# In wheels, cmake lives at <pkg>/share/cmake/tvm_ffi/, not <pkg>/cmake/
# -> condition always False -> RuntimeError("Cannot find home path.")
```

After (fixed):
```python
# find_source_path() checks: (candidate_path / "src").is_dir()
# <pkg>/src/ exists in both dev and wheel layouts
# -> correctly returns the source root path
```
