# Fix find_source_path() to use src/ instead of cmake/ for wheel layout compatibility

## TL;DR

- `find_source_path()` in `libinfo.py` was checking for a `cmake/` subdirectory to locate the source root, but in installed wheels the CMake files live at `share/cmake/`, not `cmake/`.
- Fix: switch the probe condition from `(p / "cmake").is_dir()` to `(p / "src").is_dir()`, which is present in both dev-tree and wheel layouts.
- Breakage was caught by CI: `tvm-ffi-config --sourcedir` returned a `RuntimeError` in wheel environments.

## Usage Examples

**Before (broken in wheel):**
```python
# find_source_path() checked for cmake/ subdirectory
# cond=lambda p: (p / "cmake").is_dir()
```

**After (fixed):**
```python

```
