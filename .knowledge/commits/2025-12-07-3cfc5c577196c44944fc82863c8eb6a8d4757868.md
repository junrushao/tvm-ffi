# Fix find_source_path() validation condition to check 'src' instead of 'cmake'
## TL;DR
- Fixes `tvm-ffi-config --sourcedir` failing in wheel installs by changing `find_source_path()` validation from `(p / "cmake").is_dir()` to `(p / "src").is_dir()`, since the cmake directory lives under `share/cmake` in wheels, not at the top level.

## Key Exports
None

## Impact
- API: none
- Behavioral: `find_source_path()` now correctly locates the source directory in wheel installs where `cmake/` is under `share/cmake/` rather than at the package root. The `src/` directory is a more reliable marker.
- Flags/config: none
- Data formats/schemas: none
