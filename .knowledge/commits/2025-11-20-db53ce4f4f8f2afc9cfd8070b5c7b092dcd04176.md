# Add kernel library guide documenting Tensor/TensorView, allocation strategies, and module system usage
## TL;DR
- Adds `docs/guides/kernel_library_guide.rst` (171 lines): a comprehensive guide for shipping kernel libraries with TVM FFI, covering `Tensor` vs `TensorView`, tensor attributes, allocation strategies (`FromEnvAlloc` vs `FromNDAlloc`), function export via `TVM_FFI_EXPORT_FUNC`, and module loading/calling.
- Adds Doxygen doc comment to `Tensor::FromNDAlloc` in `tensor.h` with example allocator structs for CPU (`malloc`/`free`), CUDA (`cudaMalloc`/`cudaFree`), and NVSHMEM (`nvshmem_malloc`/`nvshmem_free`).
- Registers the guide in `docs/index.rst` and `docs/conf.py`.
