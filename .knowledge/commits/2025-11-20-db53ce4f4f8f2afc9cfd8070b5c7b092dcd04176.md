# Add kernel library guide documenting Tensor, Stream, and function export workflows
## TL;DR
- Added `docs/guides/kernel_library_guide.rst` covering Tensor/TensorView usage, tensor allocation (FromEnvAlloc, FromNDAlloc, FromDLPack), stream context management, and function exporting via `TVM_FFI_DLL_EXPORT_TYPED_FUNC`.
- Added intersphinx mappings for `torch-cpp` and `dlpack` in `docs/conf.py`.
- Added Doxygen code examples for `Tensor::FromNDAlloc` in `include/tvm/ffi/container/tensor.h` (CPU, CUDA, NVSHMEM allocator patterns).
