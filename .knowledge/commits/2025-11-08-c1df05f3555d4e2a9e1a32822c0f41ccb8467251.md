# Introduce TVMFFIPyArgSetterIntegral_ and TVMFFIPyArgSetterReal_ for numbers.Integral/Real dispatch

## TL;DR
- Adds two new Cython setter functions: `TVMFFIPyArgSetterIntegral_` (for `numbers.Integral`) and `TVMFFIPyArgSetterReal_` (for `numbers.Real`) to `cython/function.pxi`.
- These handle numeric types that subclass Python's ABC numbers but are not exactly `int`/`float`, using Cython-level cast for correctness.
- Renames `TVMFFIPyArgSetterFFIObjectCompatible_` → `TVMFFIPyArgSetterFFIObjectProtocol_` for clarity.
- Adds 33 test lines.

## Key Exports

```python
# Cython (tvm_ffi/cython/function.pxi)
cdef int TVMFFIPyArgSetterIntegral_(handle, ctx, py_arg, out) except -1:
    """Setter for numbers.Integral subclasses (e.g. numpy.int64, custom int types).
    # Invariant: uses <long long>arg Cython cast — handles subclasses of int
    # Interacts with: TVMFFIPyCallManager setter cache, keyed on PyTypeObject*
    """
    out.type_index = kTVMFFIInt
    out.v_int64 = <long long>arg
    return 0

cdef int TVMFFIPyArgSetterReal_(handle, ctx, py_arg, out) except -1:
    """Setter for numbers.Real subclasses (e.g. numpy.float32, custom float types).
    # Invariant: uses <double>arg Cython cast
    """
    out.type_index = kTVMFFIFloat
    out.v_float64 = <double>arg
    return 0

# Also renamed:
# TVMFFIPyArgSetterFFIObjectCompatible_ → TVMFFIPyArgSetterFFIObjectProtocol_
```

## Impact
- API: none (internal Cython dispatch)
- Behavioral: `numbers.Integral` and `numbers.Real` subclasses (e.g., `numpy.int64`) now correctly convert to TVM FFI `int`/`float` types via dedicated setters.
- Flags/config: none
- Data formats/schemas: none
