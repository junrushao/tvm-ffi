# Add __tvm_ffi_int__/__tvm_ffi_float__ protocols and separate Integral/Real setter paths
## TL;DR
- Introduces two new Python dunder protocols (`__tvm_ffi_int__`, `__tvm_ffi_float__`) for custom classes to provide integer/float conversion when passed as FFI arguments.
- Splits `Integral`/`Real` handling into dedicated Cython setters (`TVMFFIPyArgSetterIntegral_`, `TVMFFIPyArgSetterReal_`) that use Cython-level casts instead of reusing the exact-`int`/`float` setters, handling subtypes like `np.int32` correctly.
- Renames `TVMFFIPyArgSetterFFIObjectCompatible_` to `TVMFFIPyArgSetterFFIObjectProtocol_` for naming consistency with other protocol-based setters.

# Dispatch priority: after __tvm_ffi_int__, before Exception.
# Interacts with: TVMFFIPyArgSetterFactory_ dispatch chain
# Extension: implement __tvm_ffi_float__(self) -> float on any Python class

# TVMFFIPyArgSetterIntegral_(handle, ctx, py_arg, out):
#     """Cython setter for numbers.Integral subclasses (e.g., np.int32)."""
#     out.type_index = kTVMFFIInt
#     out.v_int64 = <long long>arg  # Cython-level cast, not int(arg)

#     # Interacts with: numbers.Real ABC

# --- Rename for naming consistency ---
# TVMFFIPyArgSetterFFIObjectCompatible_ -> TVMFFIPyArgSetterFFIObjectProtocol_
# (internal rename only, no behavioral change)

## Impact
- API: Two new protocols (`__tvm_ffi_int__`, `__tvm_ffi_float__`) available for user classes. `convert()` also recognizes these protocols, returning the object as-is (passthrough to Cython dispatch).
- Behavioral: `numbers.Integral` subclasses (e.g., `np.int32`) now use Cython-level `<long long>` cast via `TVMFFIPyArgSetterIntegral_` instead of the exact-int setter `TVMFFIPyArgSetterInt_`. Same pattern for `numbers.Real` subclasses via `TVMFFIPyArgSetterReal_`. This is more conservative -- it lets Cython handle implicit numeric conversions rather than assuming the object is exactly `int`/`float`.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples
From the test (`tests/python/test_function.py`):
```python
import tvm_ffi
import numpy as np

fecho = tvm_ffi.get_global_func("testing.echo")

# Integral subclass (np.int32) now correctly handled
y = fecho(np.int32(1))
assert isinstance(y, int) and y == 1

# Custom class with __tvm_ffi_int__ protocol
class IntProtocol:
    def __init__(self, value: int) -> None:
        self.value = value
    def __tvm_ffi_int__(self) -> int:
        return self.value

y = fecho(IntProtocol(10))
assert isinstance(y, int) and y == 10

# Custom class with __tvm_ffi_float__ protocol
class FloatProtocol:
    def __init__(self, value: float) -> None:
        self.value = value
    def __tvm_ffi_float__(self) -> float:
        return self.value

y = fecho(FloatProtocol(10))
assert isinstance(y, float) and y == 10
```
