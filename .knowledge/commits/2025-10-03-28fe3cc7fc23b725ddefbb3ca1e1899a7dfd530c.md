# Add metadata and JSON-based type schemas for fields, methods, and global functions

## TL;DR
- Introduces a `reflection::Metadata` class for attaching arbitrary key-value pairs (int, bool, string) to fields, methods, and global functions during registration.
- Adds compile-time JSON type schema generation via `details::TypeSchema<T>` / `TypeSchemaImpl<T>`, with `TypeSchema()` methods on every `TypeTraits<T>` specialization and on `FuncFunctorImpl`.
- Exposes metadata to Python via `TypeField.metadata`, `TypeMethod.metadata`, `TypeSchema` dataclass, and `get_global_func_metadata()` function.

## Key Exports

**`details::TypeSchemaImpl<T>`** (C++, `base_details.h` forward-decl, `function_details.h` specializations):
```cpp
// Primary template: delegates to TypeTraits<U>::TypeSchema() after stripping const/ref
template <typename T> struct TypeSchemaImpl { static std::string v(); };
// Specializations for void, Any, AnyView
template <> struct TypeSchemaImpl<void> { static std::string v(); };   // {"type":"None"}
template <> struct TypeSchemaImpl<Any> { static std::string v(); };    // {"type":"Any"}
template <> struct TypeSchemaImpl<AnyView> { static std::string v(); }; // {"type":"Any"}
```

**`details::TypeSchema<T>`** (C++, `base_details.h`):
```cpp
template <typename T>
using TypeSchema = TypeSchemaImpl<std::remove_const_t<std::remove_reference_t<T>>>;
```

**`TypeTraits<T>::TypeSchema()`** -- new static method added to every built-in specialization:
Returns a JSON string like `{"type":"int"}`, `{"type":"ffi.Array","args":[{"type":"int"}]}`, etc. Added to: `nullptr_t`, `bool`, `StrictBool`, integers, floats, `void*`, `DLDevice`, `DLDataType`, `DLTensor*`, `const char*`, `std::string`, `String`, `Bytes`, `TVMFFIByteArray*`, `TensorView`, `Optional<T>`, `RValueRef<T>`, all `ObjectRef` subtypes, `Object*` subtypes, `Array<T>`, `Map<K,V>`, `Tuple<Ts...>`, `Variant<Vs...>`, `TypedFunction<FType>`.

**`FuncFunctorImpl<R, Args...>::TypeSchema()`** (C++, `function_details.h`):
```cpp
static std::string TypeSchema();
// Returns: {"type":"ffi.Function","args":[<return_schema>,<arg1_schema>,...]}
// First element in args is always the return type schema
```

**`FunctionInfo<T>` additions** (C++, `function_details.h`):
```cpp
// New specializations for pointer-to-member-function types:
template <typename Class, typename R, typename... Args>
struct FunctionInfo<R (Class::*)(Args...)> : FuncFunctorImpl<R, Args...> {};
template <typename Class, typename R, typename... Args>
struct FunctionInfo<R (Class::*)(Args...) const> : FuncFunctorImpl<R, Args...> {};
```

**`reflection::InfoTrait`** (C++, `registry.h`) -- renamed from `FieldInfoTrait`:
```cpp
struct InfoTrait {};  // Base class for both field and method info traits
```

**`reflection::Metadata`** (C++, `registry.h`):
```cpp
class Metadata : public InfoTrait {
public:
  explicit Metadata(std::initializer_list<std::pair<String, Any>> dict);
  void Apply(FieldInfoBuilder* info) const;
  void Apply(MethodInfoBuilder* info) const;
private:
  static std::string ToJSON(const _MetadataType& metadata); // serializes to JSON string
};
```

**`reflection::FieldInfoBuilder`** / **`MethodInfoBuilder`** (C++, `registry.h`):
```cpp
struct FieldInfoBuilder : public TVMFFIFieldInfo { _MetadataType metadata_; };
struct MethodInfoBuilder : public TVMFFIMethodInfo { _MetadataType metadata_; };
// _MetadataType = std::vector<std::pair<String, Any>>
```

**`EscapeString`** (C++, `string.h`):
```cpp
inline String EscapeString(const String& value);
// Returns a JSON-escaped, double-quoted string. Refactored from json_writer.cc.
```

**`TypedFunction<R(Args...)>::TypeSchema()`** (C++, `function.h`):
```cpp
static std::string TypeSchema(); // delegates to FuncFunctorImpl<R, Args...>::TypeSchema()
```

**`ffi.GetGlobalFuncMetadata`** (C++ global function, `function.cc`):
```cpp
// Registered as global func. Takes String name, returns String (JSON metadata).
// Throws RuntimeError if function not found.
```

**`TypeSchema`** (Python, `cython/type_info.pxi`):
```python
@dataclasses.dataclass(repr=False, frozen=True)
class TypeSchema:
    origin: str
    args: tuple[TypeSchema, ...] = ()
    @staticmethod
    def from_json_obj(obj: dict[str, Any]) -> TypeSchema
    @staticmethod
    def from_json_str(s: str) -> TypeSchema
    def __repr__(self) -> str  # e.g. "Callable[[int], int]", "list[int]", "int | str"
```

**`_TYPE_SCHEMA_ORIGIN_CONVERTER`** (Python, `cython/type_info.pxi`):
Maps C++ type keys to Python-idiomatic names (e.g., `ffi.Array` -> `list`, `ffi.Map` -> `dict`, `Variant` -> `Union`, `ffi.Function` -> `Callable`).

**`get_global_func_metadata(name: str) -> dict[str, Any]`** (Python, `registry.py`):
Calls `ffi.GetGlobalFuncMetadata`, parses returned JSON string.

**`TypeField.metadata`** / **`TypeMethod.metadata`** (Python, `cython/type_info.pxi` + `object.pxi`):
New `dict[str, Any]` field on both dataclasses, populated by parsing the `TVMFFIByteArray metadata` JSON from the C structs.

## Impact
- API: `FieldInfoTrait` renamed to `InfoTrait`; `DefaultValue` and `AttachFieldFlag` now inherit from `InfoTrait` instead of `FieldInfoTrait`. Internal signatures of `ApplyFieldInfoTrait`/`ApplyMethodInfoTrait`/`RegisterFunc`/`RegisterField`/`RegisterMethod` changed to use builder types. New public APIs: `Metadata`, `TypeSchema` (C++ and Python), `get_global_func_metadata`, `EscapeString`.
- Behavioral: All fields, methods, and global functions now automatically include a `type_schema` key in their metadata JSON. User-supplied metadata is merged alongside.
- Flags/config: None.
- Data formats/schemas: Introduces a JSON type schema format: `{"type":"<type_key>", "args":[...]}`. Function schemas encode return type as `args[0]`, followed by parameter schemas. Packed functions have no `args` key.

## Usage Examples

### C++ -- Registering a global function with metadata
```cpp
#include <tvm/ffi/reflection/registry.h>
namespace refl = tvm::ffi::reflection;

TVM_FFI_STATIC_INIT_BLOCK() {
  refl::GlobalDef()
      .def("my.add", [](int a, int b) -> int { return a + b; },
           refl::Metadata{{"description", "Adds two integers"}, {"version", 1}});
}
// The function's metadata JSON will be:
// {"type_schema":"{\"type\":\"ffi.Function\",\"args\":[{\"type\":\"int\"},{\"type\":\"int\"},{\"type\":\"int\"}]}",
//  "description":"Adds two integers","version":1}
```

### Python -- Retrieving function metadata and parsing type schema
```python
from tvm_ffi import get_global_func_metadata
from tvm_ffi.core import TypeSchema

metadata = get_global_func_metadata("testing.schema_id_int")
# metadata = {"type_schema": '{"type":"ffi.Function","args":[{"type":"int"},{"type":"int"}]}',
#              "bool_attr": True, "int_attr": 1, "str_attr": "hello"}

schema = TypeSchema.from_json_str(metadata["type_schema"])
print(schema)  # Callable[[int], int]
```

### Python -- Inspecting field/method metadata via TypeInfo
```python
from tvm_ffi.testing import _SchemaAllTypes
from tvm_ffi.core import TypeSchema

type_info = _SchemaAllTypes.__tvm_ffi_type_info__
for field in type_info.fields:
    schema = TypeSchema.from_json_str(field.metadata["type_schema"])
    print(f"{field.name}: {schema}")
    # v_bool: bool
    # v_arr_int: list[int]
    # v_variant: str | list[int] | dict[str, int]
```
