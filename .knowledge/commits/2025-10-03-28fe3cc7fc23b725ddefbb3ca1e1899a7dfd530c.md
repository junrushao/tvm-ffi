# Add metadata and JSON type schemas for fields, methods, and global functions
## TL;DR
- Introduces `TypeSchema<T>` static method on every `TypeTraits` specialization, generating a JSON string describing the type (e.g. `{"type":"int"}`, `{"type":"ffi.Function","args":[...]}`) for all primitive, container, and ObjectRef types.
- Adds `reflection::Metadata` class (key-value pairs of `String`->`Any`) that can be attached to fields, methods, and global functions via `InfoTrait` apply protocol. Serialized to JSON in the C metadata structs.
- Python side: new `TypeSchema` dataclass that parses JSON schema strings, new `metadata` field on `TypeField`/`TypeMethod`, new `get_global_func_metadata()` API.

## Impact
- API: New C++ types `Metadata`, `FieldInfoBuilder`, `MethodInfoBuilder` in `reflection/registry.h`. New `TypeSchema()` method on all `TypeTraits`. New Python `TypeSchema` class and `get_global_func_metadata()` function. `FieldInfoTrait` renamed to `InfoTrait`.
- Flags/config: None.
- Data formats/schemas: JSON type schema format is introduced: `{"type":"<key>", "args":[...]}` with recursive nesting for containers.

## Design Elements
Design elements this commit consumes:
- **Reflection system** (`.knowledge/designs/0006-reflection.md`): Extends `ObjectDef<T>` and `GlobalDef` registration with metadata and type schema generation. `FieldInfoTrait` base renamed to `InfoTrait` and broadened to apply to both fields and methods.
- **Function system** (`.knowledge/designs/0004-function-system.md`): `FunctionInfo<T>` extended with `TypeSchema()` that generates the JSON schema for typed function signatures. New `FunctionInfo` specializations for pointer-to-member functions.
- **Any/AnyView type system** (`.knowledge/designs/0002-any-system.md`): `TypeTraits<T>::TypeSchema()` added to every specialization (nullptr_t, bool, int, float, DLDevice, void*, DLTensor*, ObjectRef, Optional, enums).
- **Python bindings** (`.knowledge/designs/0014-python-bindings.md`): Cython `TypeField` and `TypeMethod` dataclasses extended with `metadata` dict.

Design elements this commit produces:
- **JSON type schema format**: A recursive JSON representation `{"type":"<key>", "args":[<sub-schemas>]}` for describing FFI types. Consumed by Python `TypeSchema.from_json_str()` for tooling, stub generation, and static analysis.
- **Metadata attachment protocol**: `Metadata` class with `Apply()` dispatched to `FieldInfoBuilder`/`MethodInfoBuilder`, serialized to JSON via `Metadata::ToJSON()`.
- **`get_global_func_metadata` Python API**: Retrieves metadata dict (including `type_schema`) for any registered global function by name.
- **`__tvm_ffi_type_info__` attribute**: Set on Python classes during `register_object`, exposing the full `TypeInfo` to introspection.
