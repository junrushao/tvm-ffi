# Add JSON-based type schema and user-supplied metadata for fields, methods, and global functions
## TL;DR
- Introduces a compile-time `TypeSchema<T>` trait on every `TypeTraits` specialization that generates a JSON schema string describing the type, and a `FunctionInfo<F>::TypeSchema()` that wraps function signatures into `{"type":"ffi.Function","args":[ret, arg0, arg1, ...]}`.
- Adds `Metadata` class (key-value pairs of `String -> int|bool|String`) as an `InfoTrait` that can be attached to fields, methods, and global functions during reflection registration, serialized to JSON and stored in the existing `TVMFFIFieldInfo::metadata` / `TVMFFIMethodInfo::metadata` byte arrays.
- Exposes metadata to Python: `TypeField.metadata`, `TypeMethod.metadata` dicts, a new `TypeSchema` Python class for parsing JSON schema strings, and `get_global_func_metadata(name)` for retrieving global function metadata.

## Key Exports

**Types/Classes (C++)**:

- `details::TypeSchemaImpl<T>` -- Template struct with `static std::string v()` returning a JSON type schema for `T`. Specialized for `void` (`{"type":"None"}`), `Any`/`AnyView` (`{"type":"Any"}`), and defaulting to `TypeTraits<T>::TypeSchema()`.
- `details::TypeSchema<T>` -- Alias for `TypeSchemaImpl<remove_const_t<remove_reference_t<T>>>`.
- `reflection::FieldInfoBuilder` -- Extends `TVMFFIFieldInfo` with a temporary `_MetadataType metadata_` vector used during registration before being serialized to JSON.
- `reflection::MethodInfoBuilder` -- Extends `TVMFFIMethodInfo` with a temporary `_MetadataType metadata_` vector.
- `reflection::Metadata` -- `InfoTrait` subclass; constructed from `initializer_list<pair<String, Any>>`; `Apply(FieldInfoBuilder*)` / `Apply(MethodInfoBuilder*)` appends key-value pairs to the builder's metadata vector. Static `ToJSON(_MetadataType&) -> string` serializes metadata to a JSON object string.
- `reflection::InfoTrait` -- Renamed from `FieldInfoTrait`; base class for traits that apply to both fields and methods.

**Functions (C++)**:

- `TypeTraits<T>::TypeSchema() -> string` -- New static method on every TypeTraits specialization, returns JSON type schema like `{"type":"int"}`, `{"type":"ffi.Array","args":[...]}`, etc.
- `FuncFunctorImpl<R, Args...>::TypeSchema() -> string` -- Returns a function-typed schema: `{"type":"ffi.Function","args":[<ret_schema>,<arg0_schema>,...]}`.
- `FunctionInfo<T>::TypeSchema() -> string` -- Dispatches to `FuncFunctorImpl`. New specializations for member function pointers (`R (Class::*)(Args...)` and `R (Class::*)(Args...) const`).
- `TypedFunction<R(Args...)>::TypeSchema() -> string` -- Static method delegating to `FuncFunctorImpl`.
- `EscapeString(String) -> String` -- New utility in `string.h` (moved from `json_writer.cc`), escapes a string per JSON spec (RFC 8259) with double-quote wrapping.

**Functions (Python)**:

- `get_global_func_metadata(name: str) -> dict[str, Any]` -- Calls `ffi.GetGlobalFuncMetadata` and JSON-parses the result. Exported from `tvm_ffi.__init__`.
- `ffi.GetGlobalFuncMetadata` -- New global function registered in `function.cc`; retrieves `metadata_data` from `GlobalFunctionTable::Entry`.

**Types/Classes (Python)**:

- `TypeSchema` -- Frozen dataclass in `type_info.pxi` with `origin: str` and `args: tuple[TypeSchema, ...]`. Methods: `from_json_str(s) -> TypeSchema`, `from_json_obj(dict) -> TypeSchema`, `__repr__` renders as Python-style type annotation (e.g., `Callable[[int], int]`, `list[str]`, `int | str | None`).
- `TypeField.metadata: dict[str, Any]` -- New field containing the parsed JSON metadata dictionary (includes `type_schema` key).
- `TypeMethod.metadata: dict[str, Any]` -- New field containing the parsed JSON metadata dictionary.

**Constants (Python)**:

- `_TYPE_SCHEMA_ORIGIN_CONVERTER` -- Dict mapping C++ type keys to Python-friendly origin names (e.g., `"ffi.Array" -> "list"`, `"Variant" -> "Union"`, `"ffi.String" -> "str"`).

**Renames (C++)**:

| Old Name | New Name |
|----------|----------|
| `FieldInfoTrait` | `InfoTrait` |

## Impact
- API: `FieldInfoTrait` renamed to `InfoTrait`. All existing `FieldInfoTrait` subclasses (`DefaultValue`, `AttachFieldFlag`) now derive from `InfoTrait`. Code that references `FieldInfoTrait` by name must be updated. `ApplyFieldInfoTrait` and `ApplyMethodInfoTrait` now take `FieldInfoBuilder*`/`MethodInfoBuilder*` instead of `TVMFFIFieldInfo*`/`TVMFFIMethodInfo*`, but these are internal to `ReflectionDefBase`.
- ABI: None. The `TVMFFIFieldInfo::metadata` and `TVMFFIMethodInfo::metadata` byte array fields already existed in the C ABI; this commit populates them with JSON content instead of leaving them empty.
- Behavioral: Every field, method, and global function registration now automatically includes a `type_schema` key in its metadata JSON. Global function metadata is retrievable at runtime via `ffi.GetGlobalFuncMetadata`.
- Flags/config: None.
- Data formats/schemas: The metadata JSON format is `{"type_schema": "<json>", ...}` where the type_schema value is a nested JSON object like `{"type":"int"}` or `{"type":"ffi.Function","args":[...]}`. User-supplied metadata keys (via `Metadata{...}`) are merged alongside `type_schema`.

## Usage Examples

### Attaching metadata to a global function (C++ -> Python)
```cpp
// C++ registration with Metadata
TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("my.Add", [](int a, int b) -> int { return a + b; },
           refl::Metadata{{"description", "Adds two integers"}, {"version", 1}});
}
```
```python
# Python retrieval
from tvm_ffi import get_global_func_metadata
from tvm_ffi.core import TypeSchema

metadata = get_global_func_metadata("my.Add")
# metadata == {"type_schema": '{"type":"ffi.Function","args":[{"type":"int"},{"type":"int"},{"type":"int"}]}',
#              "description": "Adds two integers", "version": 1}
schema = TypeSchema.from_json_str(metadata["type_schema"])
print(schema)  # Callable[[int, int], int]
```

### Inspecting field metadata from Python
```python
from tvm_ffi.core import TypeSchema

# Assuming a registered object with reflected fields
type_info = getattr(MyObj, "__tvm_ffi_type_info__")
for field in type_info.fields:
    schema = TypeSchema.from_json_str(field.metadata["type_schema"])
    print(f"{field.name}: {schema}")
    # e.g. "x: int", "name: str", "items: list[int]"
```
