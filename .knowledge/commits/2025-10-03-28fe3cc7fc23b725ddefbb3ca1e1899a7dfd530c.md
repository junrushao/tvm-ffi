# Add JSON type-schema generation and key-value metadata attachment to the reflection registry for fields, methods, and global functions

## TL;DR
- Introduces `details::TypeSchema<T>` (C++) — a compile-time trait that serializes any C++ type used in FFI signatures to a structured JSON string (e.g., `{"type":"ffi.Function","args":[{"type":"int"},{"type":"int"}]}`). Every `TypeTraits<T>` specialization gains a `TypeSchema()` static method.
- Adds `reflection::Metadata` class — a user-supplied key-value bag (`std::initializer_list<std::pair<String, Any>>`) that can be attached to fields, methods, and global functions at registration time. The `type_schema` key is automatically injected for all registrations.
- Extends Python `TypeField` and `TypeMethod` with a `metadata: dict[str, Any]` field; adds `TypeSchema` dataclass (Python) for structured schema parsing; adds `get_global_func_metadata(name)` public API.

## Impact
- API: Additive. `TypeField` and `TypeMethod` gain `metadata: dict[str, Any]` field — callers constructing these manually (unlikely, they are created by Cython) must supply it. `get_global_func_metadata` is new public API. `__tvm_ffi_type_info__` is now set on every `@register_object`-decorated class.
- Behavioral: `GlobalDef::def` / `GlobalDef::def_packed` / `GlobalDef::def_method` / `ObjectDef::RegisterField` / `ObjectDef::RegisterMethod` now always populate `TVMFFIFieldInfo/MethodInfo.metadata` with at least `{"type_schema": "..."}`. Previously `metadata` was always null/empty.
- Flags/config: None.
- Data formats/schemas: `TVMFFIFieldInfo.metadata` and `TVMFFIMethodInfo.metadata` fields (already in C ABI) now carry JSON payloads. The `metadata` field in `TVMFFIFieldInfo`/`TVMFFIMethodInfo` was structurally present before but always empty; now always non-empty after registration.
- Rename: `FieldInfoTrait` -> `InfoTrait` (C++ internal, not in C ABI). Callers using `FieldInfoTrait` as a base class for custom traits must rename.

## Usage Examples

**Cross-layer trace: C++ registration → Python schema inspection**

```python
# C++ (src/ffi/extra/testing.cc) — registers with type_schema auto-injected:
# TVM_FFI_STATIC_INIT_BLOCK() {
#   GlobalDef()
#     .def("testing.schema_id_int", [](int64_t x) -> int64_t { return x; },
#          Metadata{{"bool_attr", true}, {"int_attr", 1}, {"str_attr", "hello"}});
# }

# Python (tests/python/test_metadata.py):
from tvm_ffi import get_global_func_metadata
from tvm_ffi.core import TypeSchema

metadata = get_global_func_metadata("testing.schema_id_int")
# {"type_schema": "{\"type\":\"ffi.Function\",\"args\":[{\"type\":\"int\"},{\"type\":\"int\"}]}",
#  "bool_attr": True, "int_attr": 1, "str_attr": "hello"}

schema = TypeSchema.from_json_str(metadata["type_schema"])
print(repr(schema))  # "Callable[[int], int]"
```

**Field metadata inspection via `__tvm_ffi_type_info__`**

```python
from tvm_ffi.core import TypeSchema
from tvm_ffi.testing import _SchemaAllTypes  # @register_object class

type_info = _SchemaAllTypes.__tvm_ffi_type_info__
for field in type_info.fields:
    if field.name == "v_map_str_arr_int":
        schema = TypeSchema.from_json_str(field.metadata["type_schema"])
        print(repr(schema))  # "dict[str, list[int]]"
```

**User metadata on fields/methods (C++)**

```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  refl::ObjectDef<MyObj>()
      .def_rw("value", &MyObj::value,
              refl::Metadata{{"description", "The value"}, {"version", 1}});
  refl::GlobalDef()
      .def("my.func", my_func,
           refl::Metadata{{"description", "Adds two integers"}, {"version", 1}});
}
```
