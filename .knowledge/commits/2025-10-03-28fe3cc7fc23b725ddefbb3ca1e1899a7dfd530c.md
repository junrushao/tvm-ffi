# Add JSON-based type schemas and user-defined metadata for fields, methods, and global functions
## TL;DR
- Introduces `details::TypeSchema<T>` / `TypeSchemaImpl<T>` compile-time JSON schema generation for all FFI types, adding a `TypeSchema()` static method to every `TypeTraits<T>` specialization.
- Adds `reflection::Metadata` class for attaching user-defined key-value pairs (int/bool/string) to fields, methods, and global functions; renames `FieldInfoTrait` to `InfoTrait`; adds `FieldInfoBuilder`/`MethodInfoBuilder` wrapper structs.
- Exposes metadata in Python via `TypeField.metadata`, `TypeMethod.metadata`, `TypeSchema` dataclass, `get_global_func_metadata()`, and `ffi.GetGlobalFuncMetadata` global function.

## Impact
- API: Adds new public `TypeSchema` class and `get_global_func_metadata()` to Python. Extends `TypeField` and `TypeMethod` with `metadata` dict. Renames `FieldInfoTrait` to `InfoTrait` in C++ (breaking for direct subclasses, though the old name had no external users).
- Behavioral: All field/method/global registrations now automatically include `type_schema` in their metadata JSON. The `type_schema` key is always present.
- Flags/config: none
- Data formats/schemas: Introduces a JSON schema format for types: `{"type":"<name>","args":[...]}`. The schema for functions puts the return type at `args[0]`, followed by parameter types.

## Usage Examples

### C++: Registering a global function with metadata
```cpp
TVM_FFI_STATIC_INIT_BLOCK() {
  namespace refl = tvm::ffi::reflection;
  refl::GlobalDef()
      .def("my_add", my_add_func,
           refl::Metadata{{"description", "Adds two integers"}, {"version", 1}});
}
// Metadata JSON stored: {"type_schema":"...","description":"Adds two integers","version":1}
```

### C++: Registering fields/methods with metadata
```cpp
refl::ObjectDef<MyObj>()
    .def_rw("v_bool", &MyObj::v_bool, "bool field",
            refl::Metadata{{"custom_attr", true}})
    .def("my_method", &MyObj::Method, "method doc",
         refl::Metadata{{"deprecated", false}});
// type_schema is automatically added to metadata for both fields and methods
```

### Python: Inspecting type schemas
```python
from tvm_ffi import get_global_func_metadata
from tvm_ffi.core import TypeSchema

metadata = get_global_func_metadata("testing.schema_id_int")
# {"type_schema": '{"type":"ffi.Function","args":[{"type":"int"},{"type":"int"}]}',
#  "bool_attr": True, "int_attr": 1, "str_attr": "hello"}

schema = TypeSchema.from_json_str(metadata["type_schema"])
print(schema)  # Callable[[int], int]
```

### Python: Accessing field/method metadata
```python
type_info = getattr(MyClass, "__tvm_ffi_type_info__")
for field in type_info.fields:
    schema = TypeSchema.from_json_str(field.metadata["type_schema"])
    print(f"{field.name}: {schema}")  # e.g., "v_arr_int: list[int]"
```
