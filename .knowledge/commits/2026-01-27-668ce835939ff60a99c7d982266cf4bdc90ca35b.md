# Fix JSONDecodeError when get_global_func_metadata receives empty string
## TL;DR
- Adds empty string check in `get_global_func_metadata()` before calling `json.loads()`, returning an empty dict for functions without metadata.
- Fixes `JSONDecodeError` for Python-registered global functions that have no metadata.

None (bugfix to existing function)

- API: none
