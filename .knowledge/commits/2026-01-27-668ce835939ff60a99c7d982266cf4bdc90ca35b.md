# Fix JSONDecodeError in get_global_func_metadata for Python functions without metadata
## TL;DR
- Fixes `get_global_func_metadata()` in `python/tvm_ffi/registry.py` to return `{}` when the metadata string is empty, instead of passing it to `json.loads()` which raised `JSONDecodeError`.
- Adds regression test for Python-registered functions without metadata.
