# Enhance load_module to accept PathLike objects in addition to str

## TL;DR
- `load_module(path)` now accepts `str | os.PathLike` by calling `os.fspath(path)` before passing to `_ffi_api.ModuleLoadFromFile`.
- Docstring updated with a `pathlib.Path` example.

## Key Exports

```python
# python/tvm_ffi/module.py

def load_module(path: str | PathLike) -> Module:
    """Load module from file.

    Invariant: path is converted to str via os.fspath before C++ call.
    Interacts with: _ffi_api.ModuleLoadFromFile, os.fspath
    """
    path = fspath(path)   # NEW: PathLike support
    return _ffi_api.ModuleLoadFromFile(path)
```

## Impact
- API: `load_module` type signature widened from `str` to `str | PathLike`. Fully backward compatible.
- Behavioral: none — `os.fspath(str)` is a no-op.
- Flags/config: none
- Data formats/schemas: none
