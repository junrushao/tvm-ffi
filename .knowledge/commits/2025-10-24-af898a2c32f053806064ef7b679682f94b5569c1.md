# Enhance load_module to accept PathLike objects

## TL;DR
- Widens the `path` parameter of `load_module()` from `str` to `str | PathLike`, calling `os.fspath(path)` before forwarding to the C API.
- Enables `pathlib.Path` and other `os.PathLike` objects to be passed directly to `load_module()`.
- Closes issue #158.

## Key Exports

**Function signature change** (`python/tvm_ffi/module.py`):
```python
def load_module(path: str | PathLike) -> Module:
```
Previously: `def load_module(path: str) -> Module`.

## Impact
- API: `load_module()` now accepts `PathLike` objects (e.g., `pathlib.Path`). This is a backward-compatible widening of the parameter type.
- Behavioral: `os.fspath()` is called on the path argument before passing to `_ffi_api.ModuleLoadFromFile`. For `str` inputs, `fspath` is a no-op.
- Flags/config: None.
- Data formats/schemas: None.

## Design Elements
Design elements this commit consumes:
- **Module system** (`python/tvm_ffi/module.py`): The `load_module` function and `_ffi_api.ModuleLoadFromFile` C API call. See `.knowledge/designs/0013-module-system.md`.

Design elements this commit produces: None (enhances existing API surface).

## Usage Examples

```python
from pathlib import Path
import tvm_ffi

# String path (existing behavior)
mod = tvm_ffi.load_module("path/to/module.so")

# PathLike (new behavior)
mod = tvm_ffi.load_module(Path("path/to/module.so"))
```
