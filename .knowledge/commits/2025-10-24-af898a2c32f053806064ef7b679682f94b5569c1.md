# Widen load_module path parameter to accept PathLike objects in addition to str
## TL;DR
- `load_module(path)` now accepts `str | PathLike` instead of just `str`, using `os.fspath()` to convert before passing to the C++ backend.
- Type annotation and docstring updated; usage examples added showing `pathlib.Path` compatibility.
- Single-file Python change (12 additions, 4 deletions) with no C++ or Cython changes.

## Key Exports

```python
def load_module(path: str | PathLike) -> Module:
    """Load module from file.
    # Old signature: def load_module(path: str) -> Module
    # New signature: def load_module(path: str | PathLike) -> Module
    # Interacts with: os.fspath (converts PathLike -> str before FFI call)
    # Interacts with: _ffi_api.ModuleLoadFromFile (C++ Module::LoadFromFile, expects str)
    # Invariant: os.fspath() raises TypeError if path is neither str nor PathLike
    """
    ...
```

## Impact
- API: Signature of `load_module` widened from `str` to `str | PathLike`. Fully backward-compatible -- all existing `str` callers continue to work. New `pathlib.Path` callers are now supported.
- Behavioral: `os.fspath()` is called before `_ffi_api.ModuleLoadFromFile`, coercing `PathLike` to `str`. For `str` inputs, `fspath` is a no-op passthrough.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Module system / `load_module`** ([.knowledge/designs/0011-module-system.md](../designs/0011-module-system.md)): The `load_module` function delegates to `_ffi_api.ModuleLoadFromFile` (C++ `Module::LoadFromFile`), which dispatches by file extension to format-specific loaders. This commit does not change the dispatch logic.
- **Python bindings / `module.py`** ([.knowledge/designs/0012-python-bindings.md](../designs/0012-python-bindings.md)): `load_module` is part of the top-level `tvm_ffi` public API.

Design elements this commit produces:
- None (no new design elements; this is a type-widening of an existing API).

## Usage Examples
```python
from pathlib import Path
import tvm_ffi

# String path (unchanged)
mod = tvm_ffi.load_module("path/to/module.so")

# pathlib.Path (new)
mod = tvm_ffi.load_module(Path("path/to/module.so"))

# Any os.PathLike implementation
mod = tvm_ffi.load_module(some_pathlike_object)
```
