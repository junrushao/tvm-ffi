# Fix member function schema to include `self` (this) as first argument
## TL;DR
- Fixes `FunctionInfo` specializations for pointer-to-member functions to include `Class*` / `const Class*` as the first argument in the type schema, matching the actual packed calling convention where `self` is the first arg.
- Updates Python `TypeSchema` repr for `Callable` to correctly display member function schemas.

## Impact
- API: Schema output for member functions registered via `def_method` now correctly includes the self/class parameter. This is a behavioral fix for the metadata feature introduced in PR #36.
- Flags/config: None.
- Data formats/schemas: JSON type schemas for member functions now have the correct argument count.

## Design Elements
Design elements this commit consumes:
- **Function system** (`.knowledge/designs/0004-function-system.md`): `FunctionInfo<R (Class::*)(Args...)>` specializations in `function_details.h`.
- **Reflection system** (`.knowledge/designs/0006-reflection.md`): `def_method` registration path that uses `FunctionInfo::TypeSchema()`.

Design elements this commit produces:
- **Corrected member function schema invariant**: For pointer-to-member `R (Class::*)(Args...)`, the schema includes `Class*` as first arg followed by `Args...`, matching the packed ABI convention.
