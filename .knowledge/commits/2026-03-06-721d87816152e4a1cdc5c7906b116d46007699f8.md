# Remove broken __instancecheck__/__subclasscheck__ from _ObjectSlotsMeta

## TL;DR
- Removes `_ObjectSlotsMeta.__instancecheck__` and `__subclasscheck__` overrides that made `isinstance(any_cobject, any_ffi_class)` return `True` — causing cross-type false positives (e.g., `isinstance(Map(...), Array) == True`).
- Standard Python MRO now governs `isinstance`/`issubclass` for the Object hierarchy.
- Adds 30+ regression tests in `test_object.py`.

## Key Exports

```python
# What invariant was violated before the fix:
# _ObjectSlotsMeta.__instancecheck__ returned True for any CObject against any Object subclass
# isinstance(tvm_ffi.Map({}), tvm_ffi.Array) == True  # BUG
# isinstance(parent_obj, DerivedClass) == True  # BUG

# What invariant is restored after the fix:
# isinstance/issubclass respect actual type hierarchy (C++ type_index-based)
# isinstance(tvm_ffi.Map({}), tvm_ffi.Array) == False  # CORRECT
# isinstance(parent_obj, DerivedClass) == False  # CORRECT
# isinstance(derived_obj, ParentClass) == True  # CORRECT (via MRO)
```

## Impact
- API: **Breaking** for code relying on the old `__instancecheck__` override behavior (e.g., using `isinstance(obj, Array)` as a coarse "is an Object" check). All sibling FFI types now correctly reject each other.
- Behavioral: `isinstance`/`issubclass` now use standard Python MRO. Cross-type checks return `False`.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
# Before (broken):
m = tvm_ffi.Map({"a": 1})
assert isinstance(m, tvm_ffi.Array)  # was True, now False

# After (correct):
a = tvm_ffi.Array([1, 2])
assert isinstance(a, tvm_ffi.Object)   # True
assert not isinstance(a, tvm_ffi.Map)  # False
assert issubclass(tvm_ffi.Array, tvm_ffi.Object)  # True
assert not issubclass(tvm_ffi.Array, tvm_ffi.Map)  # False
```
