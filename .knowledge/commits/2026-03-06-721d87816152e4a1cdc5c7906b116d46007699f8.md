# Remove broken __instancecheck__/__subclasscheck__ from _ObjectSlotsMeta

## TL;DR
- Removes `__instancecheck__` and `__subclasscheck__` from `_ObjectSlotsMeta` which unconditionally returned `True` for any `CObject` instance/subclass, causing incorrect behavior (e.g., `isinstance(Map(...), Array)` returning `True`).
- Standard Python MRO-based checks work correctly since all C++ objects are constructed as proper `Object` subclasses.
- Adds 22 regression tests for correct isinstance/issubclass behavior.

## Key Exports

```python
# Removed from _ObjectSlotsMeta:
# def __instancecheck__(cls, instance) -> bool: ...  # REMOVED — was always True for CObject
# def __subclasscheck__(cls, subclass) -> bool: ...  # REMOVED — was always True for CObject subclasses
# Invariant: standard Python isinstance/issubclass now correctly respects type hierarchy
```

## Impact
- API: None — removing broken metaclass methods restores correct Python semantics.
- Behavioral: `isinstance(Map(...), Array)` now correctly returns `False`.
- Flags/config: None.
