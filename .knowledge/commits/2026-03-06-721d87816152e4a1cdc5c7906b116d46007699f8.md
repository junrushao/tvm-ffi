# Remove broken isinstance/issubclass overrides from _ObjectSlotsMeta

## TL;DR
- Deleted `__instancecheck__` and `__subclasscheck__` from `_ObjectSlotsMeta` that unconditionally returned `True` for any `CObject` instance or subclass, making `isinstance(Map(...), Array)` return `True`.
- Standard Python MRO-based checks are correct because all C++ FFI objects are constructed as proper `Object` subclasses — the overrides were wrong from the start.
- Added 22 regression tests covering containers, inheritance hierarchies, and cross-hierarchy isinstance/issubclass.

## Key Exports

```python
# python/tvm_ffi/cython/object.pxi

class _ObjectSlotsMeta(ABCMeta):
    """Metaclass for Object. Injects __slots__ = () for subclasses.
    # OLD: also overrode __instancecheck__ and __subclasscheck__
    #      → unconditionally returned True for any CObject pair
    # NEW: those overrides removed; standard MRO-based isinstance works correctly
    # Invariant: isinstance(Map(...), Array) now correctly returns False
    # Invariant: isinstance(Array(...), Object) correctly returns True
    """
    ...
```

## Impact
- API: None — `_ObjectSlotsMeta` is internal.
- Behavioral: Breaking (correctness fix): `isinstance(obj, SomeObjectSubclass)` now uses standard MRO. Previously, any `isinstance(CObject_instance, SomeObjectType)` returned `True` regardless of actual type.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Before (broken):
```python
from tvm_ffi import Array, Map
arr = Array([1, 2, 3])
m = Map({"a": 1})
isinstance(m, Array)  # → True (WRONG — any CObject matched any Object subtype)
```

After (correct):
```python
isinstance(m, Array)   # → False
isinstance(m, Map)     # → True
isinstance(arr, Array) # → True
```
