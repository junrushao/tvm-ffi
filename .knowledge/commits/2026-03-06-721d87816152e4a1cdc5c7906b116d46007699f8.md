# Remove broken __instancecheck__/__subclasscheck__ from _ObjectSlotsMeta
## TL;DR
- Removes `__instancecheck__` and `__subclasscheck__` overrides from `_ObjectSlotsMeta` that incorrectly returned `True` for any `CObject` against any `Object` subclass (e.g. `isinstance(Map(...), Array)` was `True`).
- Adds comprehensive regression tests for `isinstance`/`issubclass` correctness across containers and user-defined types.

## Key Exports
None

## Impact
- API: None (removes incorrect behavior).
- Behavioral: `isinstance(obj, SomeFFIType)` now correctly checks the actual type hierarchy instead of always returning `True` for any FFI object.
- Flags/config: None
- Data formats/schemas: None

## Usage Examples

# After (correct): isinstance(tvm_ffi.Map({"a": 1}), tvm_ffi.Array) == False
