# Remove broken __instancecheck__/__subclasscheck__ from _ObjectSlotsMeta

## TL;DR
- Removes `__instancecheck__` and `__subclasscheck__` from `_ObjectSlotsMeta` which unconditionally returned `True` for any `CObject` instance/subclass, causing `isinstance(Map(...), Array)` to return `True`.
- Standard Python MRO-based isinstance/issubclass checks work correctly since all C++ objects are constructed as proper Object subclasses.
- Adds 22 regression tests covering containers, inheritance, and cross-hierarchy isinstance/issubclass checks.

## Key Exports

**Removed methods from `_ObjectSlotsMeta`:**
- `__instancecheck__` -- was broken (always returned True for CObject)
- `__subclasscheck__` -- was broken (always returned True for CObject subclasses)

## Impact
- API: `isinstance`/`issubclass` checks on Object subclasses now use standard Python MRO (correct behavior).
- Behavioral: `isinstance(Map(...), Array)` now correctly returns `False`.
- Flags/config: none
- Data formats/schemas: none
