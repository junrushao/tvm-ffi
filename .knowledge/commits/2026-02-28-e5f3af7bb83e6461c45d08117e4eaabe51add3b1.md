# Reimplement @c_class with structural dunders (eq, hash, order, repr, init)

## TL;DR
- `@c_class` now accepts `init`, `repr`, `eq`, `order`, `unsafe_hash` parameters and installs corresponding structural dunders from C++ recursive operations.
- `@dataclass_transform` decoration enables IDE/type-checker support.
- All `tvm_ffi.testing` objects migrated from `@register_object` to `@c_class`.

## Key Exports

```python
# python/tvm_ffi/dataclasses/c_class.py
@dataclass_transform(eq_default=False, order_default=False)
def c_class(
    type_key: str,
    *,
    init: bool = True,          # auto __init__ from C++ reflection
    repr: bool = True,          # __repr__ via ReprPrint
    eq: bool = False,           # __eq__/__ne__ via RecursiveEq
    order: bool = False,        # __lt__/__le__/__gt__/__ge__ via RecursiveLt/Le/Gt/Ge
    unsafe_hash: bool = False,  # __hash__ via RecursiveHash (unsafe with mutable fields)
) -> Callable[[type], type]:
    # Delegates to register_object + _install_dataclass_dunders
    # Invariant: user-defined dunders in class body are never overwritten
    # Interacts with: _make_init, RecursiveEq, RecursiveHash, RecursiveLt, ReprPrint

# python/tvm_ffi/registry.py
def _install_dataclass_dunders(cls, type_info, init, repr, eq, order, unsafe_hash): ...
    # Called by c_class; installs dunders from C++ recursive ops
def _install_init(cls, type_info): ...
    # Synthesizes __init__ or installs guard; uses _make_init
def _is_comparable(lhs, rhs) -> bool: ...
    # isinstance guard for __eq__/__lt__: returns False for unrelated types
```

## Impact
- API: `@c_class` gains `init`, `repr`, `eq`, `order`, `unsafe_hash` keyword parameters. Old `@c_class("key")` continues to work with defaults `init=True`, `repr=True`, `eq=False`, `order=False`, `unsafe_hash=False`.
- Behavioral: With `eq=True`, `__eq__` delegates to `RecursiveEq` and returns `NotImplemented` for unrelated types (Python convention). `unsafe_hash=True` enables hash via `RecursiveHash`.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

```python
@c_class("my.Point", eq=True, unsafe_hash=True, order=True)
class Point(Object):
    x: float
    y: float

p1 = Point(1.0, 2.0)
p2 = Point(1.0, 2.0)
assert p1 == p2                     # RecursiveEq
assert hash(p1) == hash(p2)         # RecursiveHash
assert Point(0.0, 0.0) < p1         # RecursiveLt
assert p1 != Point(3.0, 4.0)        # NotImplemented for unrelated type returned
```
