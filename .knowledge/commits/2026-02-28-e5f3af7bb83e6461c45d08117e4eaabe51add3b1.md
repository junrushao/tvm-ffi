# Rewrite @c_class to combine FFI type registration with dataclass-style structural dunders

## TL;DR
- `@c_class` now accepts `init`, `repr`, `eq`, `order`, `unsafe_hash` keyword args and installs corresponding dunder methods using C++ recursive structural operations (`RecursiveEq`, `RecursiveHash`, `RecursiveLt/Le/Gt/Ge`).
- New internal function `_install_dataclass_dunders` in `registry.py` centralizes all dunder installation logic; `_install_init` is now called from there rather than from `_add_class_attrs`, enabling `@c_class` to control init installation independently.
- All testing fixtures migrated from `@register_object` to `@c_class`; `@dataclass_transform` annotation added for IDE support.

## Impact
- API: `@c_class` gains `init`, `repr`, `eq`, `order`, `unsafe_hash` keyword args. Old usage `@c_class("key")` unchanged — defaults maintain backward compat (`eq=False`, `order=False`, `unsafe_hash=False`). `@register_object` no longer installs `__init__` automatically (removed from `_add_class_attrs`); callers must use `@c_class` or call `_install_dataclass_dunders` explicitly.
- Behavioral: `_add_class_attrs` no longer calls `_install_init`; `__init__` installation is now opt-in via `@c_class(init=True)`. Objects registered with bare `@register_object` will NOT get auto-`__init__` unless separately wired.
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Basic `@c_class` with structural equality and hashing:

```python
from tvm_ffi.dataclasses import c_class
from tvm_ffi.core import Object

# C++ side registers "my.Point" via TVM_FFI_DECLARE_OBJECT_INFO
@c_class("my.Point", eq=True, unsafe_hash=True, order=True)
class Point(Object):
    x: float
    y: float

a = Point(x=1.0, y=2.0)
b = Point(x=1.0, y=2.0)
assert a == b           # RecursiveEq delegates to C++ structural comparison
assert hash(a) == hash(b)  # RecursiveHash
assert not (a < b)      # RecursiveLt
```

Custom `__init__` is preserved (not overwritten):
```python
@c_class("testing.TestCxxClassBase")
class _TestCxxClassBase(Object):
    v_i64: int
    v_i32: int

    def __init__(self, v_i64: int, v_i32: int) -> None:
        self.__ffi_init__(v_i64 + 1, v_i32 + 2)  # user-defined init kept

obj = _TestCxxClassBase(v_i64=10, v_i32=20)
assert obj.v_i64 == 11  # +1 from custom __init__
```
