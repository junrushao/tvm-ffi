# Optimize make_ret_object by adding direct type_index-to-class lookup list
## TL;DR
- Introduces `TYPE_INDEX_TO_CLS`, a parallel `cdef list` in `object.pxi` that maps `type_index` directly to the Python `type_cls`, eliminating the indirection through `TYPE_INDEX_TO_INFO[tindex].type_cls` on the critical return path (`make_ret_object`).
- Adds `_set_type_cls(type_index, type_cls)` for late-binding a Python class to an already-registered type index.
- Net effect: one fewer Python attribute access per FFI object return, targeting the hot path in `make_ret_object`.

## Impact
- API: Additive -- new `_set_type_cls` function exported in `core.pyi`. No existing API changed.
- Behavioral: `make_ret_object` is semantically identical but faster due to eliminated indirection.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object registration system** (`TYPE_INDEX_TO_INFO`, `_register_object_by_index`): the existing type-index-to-metadata mapping. Documented in [0012-python-bindings.md](../designs/0012-python-bindings.md).
- **PyNativeObject pattern**: `make_ret_object` still checks `issubclass(cls, PyNativeObject)` for dual-typed objects. Documented in [0012-python-bindings.md](../designs/0012-python-bindings.md).
- **make_ret dispatch**: the FFI return value conversion path. Documented in [0012-python-bindings.md](../designs/0012-python-bindings.md).

Design elements this commit produces:
- **TYPE_INDEX_TO_CLS list**: A new `cdef list` that mirrors `TYPE_INDEX_TO_INFO` but stores only the `type_cls` for O(1) indexed access without attribute indirection.
- **_set_type_cls function**: A new two-phase registration primitive enabling late class binding.

## Usage Examples
```python
# Two-phase registration pattern enabled by _set_type_cls:
# Phase 1: Register metadata without a Python class (type_cls=None in TypeInfo)
info = core._register_object_by_index(type_index, None)  # sets TYPE_INDEX_TO_INFO, TYPE_INDEX_TO_CLS[idx] = None

# Phase 2: Later, bind the actual Python class
core._set_type_cls(type_index, MyClass)  # sets TYPE_INDEX_TO_CLS[idx] = MyClass, type_info.type_cls = MyClass

# On FFI return, make_ret_object now does:
#   cls = TYPE_INDEX_TO_CLS[tindex]  # direct list index, no attribute access
# instead of:
#   type_info = TYPE_INDEX_TO_INFO[tindex]; cls = type_info.type_cls  # list index + attr access
```
