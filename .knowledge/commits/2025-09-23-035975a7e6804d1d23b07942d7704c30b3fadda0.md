# Optimize Cython make_ret_object by adding direct type_index-to-type_cls lookup
## TL;DR
- Introduces a new `TYPE_INDEX_TO_CLS` cdef list in `object.pxi` that maps `type_index` directly to the Python `type_cls`, eliminating the intermediate `TypeInfo` lookup on the critical object-return path.
- Adds `_set_type_cls(type_index, type_cls)` function for deferred class registration (register type_info first, set type_cls later).
- Adds corresponding stub in `core.pyi`.

## Key Exports

```python

cdef list TYPE_INDEX_TO_CLS  # Direct mapping: type_index -> Python type class
# Interacts with: TYPE_INDEX_TO_INFO (kept in sync), make_ret_object (consumer)
# Invariant: len(TYPE_INDEX_TO_CLS) == len(TYPE_INDEX_TO_INFO) at all times

# Before (old path):
#   TYPE_INDEX_TO_INFO[tindex] -> type_info -> type_info.type_cls -> cls

#   TYPE_INDEX_TO_CLS[tindex] -> cls
```

## Impact
- API: Additive only -- new `_set_type_cls` function exposed in `core.pyi`
- Behavioral: `make_ret_object` is faster due to one fewer Python attribute access per call; no semantic change
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Object type registration system (`_register_object_by_index`, `TypeInfo`, `TYPE_INDEX_TO_INFO`) from 0012-python-bindings
- `make_ret_object` return path from Cython layer (0012-python-bindings)
- `PyNativeObject.__from_tvm_ffi_object__` protocol (0012-python-bindings)

Design elements this commit produces:
- `TYPE_INDEX_TO_CLS`: parallel index array providing O(1) direct type_cls lookup without TypeInfo indirection
- `_set_type_cls`: deferred type class setter enabling two-phase registration (create TypeInfo first, bind Python class later)

## Usage Examples
The optimization is internal to the Cython layer and transparent to users. The new `_set_type_cls` function enables deferred registration:

```python
# Two-phase registration pattern:
# Phase 1: register type_info by index (type_cls=None initially)
info = core._register_object_by_index(type_index, None)
# ... later, once the Python class is defined ...
# Phase 2: bind the Python class to the type_index
core._set_type_cls(type_index, MyClass)
```
