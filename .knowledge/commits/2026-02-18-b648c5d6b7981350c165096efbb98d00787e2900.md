# Add DFS-based ffi.ReprPrint for unified object repr with cycle detection
## TL;DR
- Introduces `ffi.ReprPrint` C++ function that produces human-readable repr for any TVM FFI value using DFS with 3-state cycle detection (NotVisited/InProgress/Done).
- Adds `Repr(bool)` field trait and `kTVMFFIFieldFlagBitMaskReprOff = 1 << 6` flag to exclude fields from repr output.
- All Python `__repr__` methods now delegate to `ffi.ReprPrint`. Removes per-type custom `__repr__` implementations from dataclasses.

## Key Exports

**C ABI**:
```c
kTVMFFIFieldFlagBitMaskReprOff = 1 << 6  // new flag bit
```

**C++ API** (`reflection/registry.h`):
```cpp
class Repr : public InfoTrait {
    explicit Repr(bool show);  // Repr(false) excludes field from repr
    void Apply(TVMFFIFieldInfo* info) const;
};

namespace type_attr {
    inline constexpr const char* kRepr = "__ffi_repr__";
}
```

**Global function**:
- `ffi.ReprPrint(Any) -> String` -- DFS-based repr with cycle detection and DAG memoization.

**Repr format**:
| Type | Format |
|------|--------|
| int | `42` |
| String | `"hello"` |
| Array | `(1, 2, 3)` |
| List | `[1, 2, 3]` |
| Map | `{"key": "value"}` |
| Object | `TypeKey(field1=val1, field2=val2)` |
| Cycle | `...` |
| Tensor | `float32[3, 4]@cpu:0@0x1234` |

## Impact
- API: New `ffi.ReprPrint` global function. New `kTVMFFIFieldFlagBitMaskReprOff` flag. New `Repr` trait in `registry.h`. New `type_attr::kRepr` constant.
- Behavioral: Python `__repr__` for all FFI objects now uses unified C++ repr. Previous per-class `__repr__` from dataclasses removed. Addresses hidden by default (configurable via `TVM_FFI_REPR_WITH_ADDR=1` env var).
- Flags/config: `TVM_FFI_REPR_WITH_ADDR` environment variable controls address display in repr.
- Data formats/schemas: none

## Usage Examples

```cpp
// Exclude a field from repr
ObjectDef<MyObj>("test.MyObj")
    .def_field("x", &MyObj::x)
    .def_field("internal_cache", &MyObj::cache, Repr(false));
// repr: "test.MyObj(x=42)" -- cache excluded
```

```python
import tvm_ffi
obj = MyObj(x=1, y="hello")
repr(obj)  # "test.MyObj(x=1, y=\"hello\")"
```
