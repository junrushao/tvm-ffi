# Introduce C++-side ReprPrint with DFS cycle/DAG tracking; move all __repr__ from Python to C++.

## TL;DR
- New `src/ffi/extra/repr_print.cc` implements `ffi.ReprPrint(value)` — a single global function that produces human-readable repr for any TVM FFI value using DFS with 3-state cycle/DAG tracking (`NotVisited`/`InProgress`/`Done`).
- Adds `kTVMFFIFieldFlagBitMaskReprOff` (1<<6) to `c_api.h` and `Repr(false)` InfoTrait to `registry.h` so C++ field definitions can opt out of repr output; the type_attr key `__ffi_repr__` is registered per-type.
- Removes Python-side `method_repr()`, `field(repr=...)`, `c_class(repr=...)`, and `Field.repr` — repr generation is now entirely driven from C++ reflection; `Array`, `List`, `Map`, and `Object.__repr__` all delegate to `ffi.ReprPrint`.

## Impact
- API: `field()` loses `repr=` kwarg (breaking for callers passing `repr=False` — now must use C++ `Repr(false)` trait); `c_class()` loses `repr=` kwarg. `Field.__slots__` shrinks.
- Behavioral: `Array.__repr__`, `List.__repr__`, `Map.__repr__` now produce C++-style output — `Array` uses tuple format `(a, b)` instead of list format `[a, b]`; existing tests in `test_container.py` updated accordingly.
- Flags/config: New env var `TVM_FFI_REPR_WITH_ADDR=1` enables address display in repr output.
- Data formats/schemas: None.

Design elements this commit consumes:
- `0006-reflection`: Uses `TypeAttrColumn`, `type_attr::kRepr`, `ForEachFieldInfo`, `FieldGetter`, `TVMFFITypeRegisterAttr` to register and retrieve `__ffi_repr__` per-type attribute.

- `0007-containers`: Registers built-in `__ffi_repr__` for `Array`, `List`, `Map`, `String`, `Bytes`, `Tensor`, `Shape`.
- `0017-c-class-dataclasses`: Removes `method_repr()`, `field(repr=)`, `c_class(repr=)` — Python repr now fully driven by C++ ReprPrint.
- `0013-python-package`: Cython `__object_repr__` updated to call `ffi.ReprPrint` lazily.

Design elements this commit produces:
- **ReprPrint subsystem** (`src/ffi/extra/repr_print.cc`): DFS-based repr printer with cycle/DAG detection via 3-state tracking; custom `__ffi_repr__` type attribute protocol.
- **`Repr` InfoTrait** (`include/tvm/ffi/reflection/registry.h`): Per-field opt-out from repr, applied via `kTVMFFIFieldFlagBitMaskReprOff` (1<<6).
- **`kTVMFFIFieldFlagBitMaskReprOff`** (`include/tvm/ffi/c_api.h`): New ABI-stable field flag bit.

## Usage Examples

C++ side — defining a field excluded from repr, then calling ReprPrint:
```python
# C++ side (pseudocode for ObjectDef)
# ObjectDef<MyObj>()
#   .def_field("name", &MyObj::name)
#   .def_field("internal_handle", &MyObj::handle, Repr(false))  # excluded from repr

# Python side
from tvm_ffi._ffi_api import ReprPrint
obj = tvm_ffi.testing.create_object("testing.TestIntPair", a=10, b=20)
assert ReprPrint(obj) == "testing.TestIntPair(a=10, b=20)"

# Cycle handling
inner = tvm_ffi.testing.create_object("testing.TestIntPair", a=1, b=2)
arr = tvm_ffi.Array([inner, inner])
# DAG: same object appears twice → full form on each occurrence
assert ReprPrint(arr) == "(testing.TestIntPair(a=1, b=2), testing.TestIntPair(a=1, b=2))"

# Container repr format change
assert repr(tvm_ffi.Array([1, 2, 3])) == "(1, 2, 3)"   # was "[1, 2, 3]"
assert repr(tvm_ffi.List([1, 2, 3]))  == "[1, 2, 3]"
```
