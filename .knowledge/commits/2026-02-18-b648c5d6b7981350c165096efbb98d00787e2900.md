# Add DFS-based ffi.ReprPrint for unified object repr
## TL;DR
- Introduces `ffi.ReprPrint` — a DFS-based reflection-driven repr printer for FFI objects
- Replaces per-class `__repr__` generation in `@c_class` with unified `ReprPrint` system
- Registers `__repr_print__` type attribute for custom repr formatting per type
- Adds `TVMFFITypeAttrType` enum to C API for typed type attributes
- Handles circular references with `@<addr>` markers
- Python `repr()` on FFI objects now uses the unified system

## Impact
- API: adds `ffi.ReprPrint` global function; removes per-class `__repr__` codegen from `@c_class`
- Behavioral: `repr()` on FFI objects now uses unified DFS-based printer
- Flags/config: none
- Data formats/schemas: adds `TVMFFITypeAttrType` enum to C API
