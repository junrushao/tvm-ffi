# Add DFS-based ffi.ReprPrint for unified object repr
## TL;DR
- Adds `src/ffi/extra/repr_print.cc` implementing DFS-based recursive repr printing using reflection field info.
- Replaces Python-side `__repr__` generation with C++-side `ffi.ReprPrint`.
- Extends C ABI with repr-related fields in reflection registry.
- Extensive Python test suite in `tests/python/test_repr.py`.

## Impact
- API: New `ffi.ReprPrint` global function; `__repr__` on `@c_class` objects now uses C++ reflection.
- Flags/config: None.
- Data formats/schemas: New C ABI field for repr in type info.
