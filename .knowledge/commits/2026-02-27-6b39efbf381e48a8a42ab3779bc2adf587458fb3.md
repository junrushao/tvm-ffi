# Consolidate repr_print/deep_copy into dataclass.cc with recursive hash/compare APIs
## TL;DR
- Merges `repr_print.cc` and `deep_copy.cc` into a unified `src/ffi/extra/dataclass.cc` with recursive hash and compare APIs.
- Introduces `include/tvm/ffi/extra/dataclass.h` and `include/tvm/ffi/reflection/init.h` as new public headers.
- Extends C ABI with dataclass-related functions (recursive hash, compare, repr, deep copy).
- Significantly extends reflection registry with richer init/field metadata.

## Impact
- API: New dataclass C ABI functions; new `dataclass.h` and `init.h` public headers. Breaking: removes standalone `deep_copy.h`.
- Flags/config: None.
- Data formats/schemas: Extended C ABI for dataclass operations.
