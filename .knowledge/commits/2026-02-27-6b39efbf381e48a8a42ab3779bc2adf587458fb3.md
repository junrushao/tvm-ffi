# Consolidate repr_print/deep_copy into dataclass.cc; add RecursiveHash/Eq/Lt/Le APIs and auto-init

## TL;DR
- `deep_copy.cc` + `repr_print.cc` merged into `src/ffi/extra/dataclass.cc` backed by a shared `ObjectGraphDFS` CRTP engine (eliminating duplicated graph-walking code).
- New public C++ header `include/tvm/ffi/extra/dataclass.h` with `DeepCopy`, `ReprPrint`, `RecursiveHash`, `RecursiveEq`, `RecursiveLt`, `RecursiveLe`.
- New reflection traits: `refl::repr`, `refl::compare`, `refl::hash`, `refl::kw_only`, `refl::init(bool)`, `refl::default_`, `refl::default_factory`; 4 new field flag bitmask values.
- `ObjectDef` destructor auto-registers `__ffi_init__` when no explicit `refl::init<Args...>` was supplied.

## Impact
- API: **Breaking**. `refl::Repr` renamed to `refl::repr`. `include/tvm/ffi/extra/deep_copy.h` removed from public API (moved to `src/ffi/object_internal.h`). New field flag bits 7-10 (ABI extension to `TVMFFIFieldFlagBitMask`).
- Behavioral: `ObjectDef` now auto-registers `__ffi_init__` when no explicit `init<>` provided. `RecursiveHash`/`RecursiveEq` are new public comparators (separate from `StructuralHash`/`StructuralEqual`).
- Flags/config: none
- Data formats/schemas: field flag bitmask extended with bits 7-10.

## Usage Examples

```cpp
// New reflection traits
refl::ObjectDef<MyClass>()
    .def_rw("hidden", &MyClass::hidden,
            refl::init(false),       // exclude from __init__
            refl::compare(false),    // exclude from RecursiveEq/Lt
            refl::hash(false),       // exclude from RecursiveHash
            refl::default_value(42)) // default when not in init
    .def_rw("key_only", &MyClass::key,
            refl::kw_only(true));    // keyword-only in __init__

// New public API
int64_t h = ffi::RecursiveHash(obj);
bool eq  = ffi::RecursiveEq(obj1, obj2);
bool lt  = ffi::RecursiveLt(obj1, obj2);
```
