# Consolidate repr_print/deep_copy into dataclass.cc; add recursive hash/compare APIs and auto-init

## TL;DR
- Consolidates `deep_copy.cc` and `repr_print.cc` into `dataclass.cc` using a shared `ObjectGraphDFS` CRTP engine for iterative graph walking with cycle/DAG handling.
- Adds `RecursiveHash`, `RecursiveEq`, `RecursiveLt/Le/Gt/Ge` as new public C++ APIs in `dataclass.h` for reflection-based recursive comparison and hashing.
- Auto-generates `__ffi_init__` constructor from reflection metadata when no explicit `refl::init<Args...>` is supplied (`init.h`).
- Adds 4 new C ABI field flag bits: `CompareOff` (1<<7), `HashOff` (1<<8), `InitOff` (1<<9), `KwOnly` (1<<10).
- Adds lowercase reflection trait helpers: `repr`, `compare`, `hash`, `kw_only`, `init(bool)`, `default_`, `default_factory`.

```cpp
TVM_FFI_EXTRA_CXX_API bool RecursiveEq(const Any& lhs, const Any& rhs);
TVM_FFI_EXTRA_CXX_API bool RecursiveLt(const Any& lhs, const Any& rhs);
TVM_FFI_EXTRA_CXX_API bool RecursiveLe(const Any& lhs, const Any& rhs);
TVM_FFI_EXTRA_CXX_API bool RecursiveGt(const Any& lhs, const Any& rhs);
TVM_FFI_EXTRA_CXX_API bool RecursiveGe(const Any& lhs, const Any& rhs);
```

**New header: `include/tvm/ffi/reflection/init.h`:**
- `MakeInit` / `RegisterAutoInit` -- auto-generates packed `__ffi_init__` from reflection field metadata

**New C ABI field flag bits (`c_api.h`):**

| Flag | Value | Meaning |
|------|-------|---------|
| `kTVMFFIFieldFlagBitMaskCompareOff` | `1 << 7` | Exclude from recursive comparison |
| `kTVMFFIFieldFlagBitMaskHashOff` | `1 << 8` | Exclude from recursive hashing |
| `kTVMFFIFieldFlagBitMaskInitOff` | `1 << 9` | Exclude from auto-generated init |
| `kTVMFFIFieldFlagBitMaskKwOnly` | `1 << 10` | Keyword-only in auto-generated init |

**Renamed/removed:**
- `refl::Repr` -> `refl::repr` (lowercase convention)
- `include/tvm/ffi/extra/deep_copy.h` -> `src/ffi/object_internal.h` (internalized)
- `src/ffi/extra/repr_print.cc` -> deleted (merged into `dataclass.cc`)
- `src/ffi/extra/deep_copy.cc` -> deleted (merged into `dataclass.cc`)

## Impact
- API: Breaking. `refl::Repr` renamed to `refl::repr`. `deep_copy.h` removed from public headers.
- API: New `RecursiveHash`, `RecursiveEq`, `RecursiveLt/Le/Gt/Ge` public functions.
- API: New field flags in `TVMFFIFieldFlagBitMask` enum.
- Behavioral: `ObjectDef` destructor auto-registers `__ffi_init__` when none explicitly provided.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- Reflection system (`ObjectDef`, `def_field`, `def_method`) -- [design 0009](../designs/0009-reflection.md)
- Structural equal/hash system -- [design 0010](../designs/0010-structural-equal-hash.md)
- Object graph walking (cycle/DAG detection)

Design elements this commit produces:
- **`dataclass.h` unified API** -- single public header for all reflection-based dataclass operations (deep copy, repr, hash, compare)
- **`ObjectGraphDFS` CRTP engine** (internal, `dataclass.cc`) -- shared iterative graph-walking with cycle/DAG detection for all dataclass operations
- **Auto-init from reflection** (`init.h`) -- auto-generates packed constructor from field metadata, honoring `InitOff`, `KwOnly`, defaults
- **Per-field opt-out flags** -- `compare(false)`, `hash(false)`, `init(false)`, `kw_only` reflection traits controlling field participation

## Usage Examples
```cpp
// Recursive hash and comparison
Any a = make_object<MyDataclass>(1, "hello");
Any b = make_object<MyDataclass>(1, "hello");
assert(RecursiveEq(a, b));
assert(RecursiveHash(a) == RecursiveHash(b));
assert(!RecursiveLt(a, b));

// Per-field opt-out in ObjectDef
ObjectDef<MyObj>()
    .def_rw("cached", &MyObj::cached, compare(false), hash(false))
    .def_rw("internal", &MyObj::internal, init(false));
```
