# Add TVMFFIHandleInitOnce and TVMFFIHandleDeinitOnce for thread-safe DSL handle lifecycle in the stable C ABI

## TL;DR
- Adds two new `TVM_FFI_DLL` functions to `c_api.h`: `TVMFFIHandleInitOnce` (double-checked locking init) and `TVMFFIHandleDeinitOnce` (atomic swap-then-deinit), enabling DSLs without C++ static-init support to safely lazily initialize and teardown opaque handles.
- Implementation in new `src/ffi/init_once.cc` uses `__atomic_load_n`/`__atomic_store_n`/`__atomic_exchange_n` (with `_Interlocked*` MSVC equivalents) and a function-local `std::mutex` for the slow path.
- Purely additive to the stable ABI; no existing signatures changed.

## Key Exports

```python
# TVM_FFI_DLL int TVMFFIHandleInitOnce(void** handle_addr, int (*init_func)(void** result))
# Thread-safe double-checked locking initialization.
# Fast path: atomic acquire-load of *handle_addr; returns 0 immediately if non-null.
# Slow path: locks a static std::mutex, rechecks, calls init_func(&result), atomic release-stores result.
# Invariant: init_func MUST write a non-NULL pointer to *result and return 0 on success,
#            OR call TVMFFIErrorSetRaisedFromCStr and return non-zero on failure.
# Invariant: *handle_addr must initially be nullptr; subsequent calls are idempotent.
# Interacts with: TVMFFIErrorSetRaisedFromCStr (error propagation on init_func failure)

# TVM_FFI_DLL int TVMFFIHandleDeinitOnce(void** handle_addr, int (*deinit_func)(void* handle))
# Thread-safe atomic swap deinit.
# Atomically exchanges *handle_addr with nullptr (acq_rel); calls deinit_func only if old value was non-null.
# Invariant: deinit_func is responsible for freeing the resource; after return, *handle_addr == nullptr.
# Invariant: Multiple concurrent deinit calls are safe; deinit_func is called at most once.
# Interacts with: TVMFFIErrorSetRaisedFromCStr (if deinit_func sets an error and returns non-zero)
```

## Usage Examples

DSL static handle initialization pattern (C or non-C++ language embedding TVM FFI):

```c
// Define a static handle and its init/deinit callbacks
static void* g_my_module_handle = NULL;

static int MyModuleInit(void** result) {
    void* handle = /* ... create handle ... */;
    if (!handle) {
        TVMFFIErrorSetRaisedFromCStr("RuntimeError", "Failed to create module");
        return -1;
    }
    *result = handle;
    return 0;
}

static int MyModuleDeinit(void* handle) {
    /* ... destroy handle ... */
    return 0;
}

// Thread-safe lazy initialization:
int ret = TVMFFIHandleInitOnce(&g_my_module_handle, MyModuleInit);
if (ret != 0) { /* handle error */ }

// Thread-safe teardown (safe to call from any thread, idempotent):
ret = TVMFFIHandleDeinitOnce(&g_my_module_handle, MyModuleDeinit);
```

Multithreaded correctness (from `tests/cpp/extra/test_c_env_api.cc`): 4 concurrent threads all calling `TVMFFIHandleInitOnce` → `init_func` called exactly once; 4 concurrent threads all calling `TVMFFIHandleDeinitOnce` → `deinit_func` called exactly once.
