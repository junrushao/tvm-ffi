# Introduce TVMFFIHandleInitOnce for thread-safe static handle initialization
## TL;DR
- Adds `TVMFFIHandleInitOnce` and `TVMFFIHandleInitOnceWithArg` C API functions for thread-safe one-time initialization of static handles, without requiring C++ `std::call_once` support.
- Adds `src/ffi/init_once.cc` (94 lines) implementation.
- Extensive tests in `tests/cpp/extra/test_c_env_api.cc` (288 new lines) covering multi-threaded initialization.

## Impact
- API: Two new C API functions: `TVMFFIHandleInitOnce`, `TVMFFIHandleInitOnceWithArg`
