# Add thread-safe static handle init/deinit C API for DSL environments without C++ static init

## TL;DR
- Introduces two new C ABI functions `TVMFFIHandleInitOnce` and `TVMFFIHandleDeinitOnce` in `c_api.h` for thread-safe, idempotent initialization and deinitialization of static handles.
- Targets DSL environments (e.g., non-C++ languages) that lack `std::call_once` or static initialization support but need to lazily initialize FFI handles in a thread-safe manner.
- Implementation uses double-checked locking (acquire/release atomics + mutex fallback) with cross-platform support (GCC builtins on POSIX, Interlocked* on MSVC).

## Key Exports

```python
def TVMFFIHandleInitOnce(handle_addr: Ptr[void_ptr],
                          init_func: Callable[[Ptr[void_ptr]], int]) -> int: ...
    # Thread-safe, idempotent handle initialization.
    # Fast path: atomic acquire load of *handle_addr; returns 0 immediately if non-NULL.
    # Slow path: acquires static mutex, double-checks, calls init_func, stores result with release semantics.
    # Invariant: init_func MUST set *result to non-NULL on success (returns 0); violation raises RuntimeError.
    # Invariant: init_func errors: must call TVMFFIErrorSetRaisedFromCStr then return nonzero.
    # Invariant: exactly one init_func call per handle, even under concurrent access.
    # Invariant: *handle_addr remains NULL if init_func fails.
    # Interacts with: TVMFFIErrorSetRaisedFromCStr (error propagation on NULL result)
    # Extension: DSL code generators emit calls to this for lazy singleton initialization.

def TVMFFIHandleDeinitOnce(handle_addr: Ptr[void_ptr],
                            deinit_func: Callable[[void_ptr], int]) -> int: ...
    # Thread-safe, idempotent handle deinitialization.
    # Atomically exchanges *handle_addr with NULL (acq_rel semantics).
    # Calls deinit_func on old handle only if it was non-NULL.
    # Invariant: exactly one deinit_func call per handle, even under concurrent access.
    # Invariant: *handle_addr is NULL after return regardless of deinit_func success/failure.
    # Interacts with: paired with TVMFFIHandleInitOnce for full lifecycle management.
    # Extension: enables reinit after deinit (handle reset to NULL allows fresh InitOnce).

# Internal helpers (anonymous namespace, not exported):
# AtomicLoadHandleAcquire(void** src_addr) -> void*
#   MSVC: InterlockedCompareExchangePointerAcquire (Win8+) or InterlockedCompareExchangePointer
#   GCC/Clang: __atomic_load_n with __ATOMIC_ACQUIRE
# AtomicStoreHandleRelease(void** dst_addr, void* src)
#   MSVC: _InterlockedExchangePointer
#   GCC/Clang: __atomic_store_n with __ATOMIC_RELEASE
```

## Usage Examples

From the test (`tests/cpp/extra/test_c_env_api.cc`), basic lifecycle:

```c
// 1. Declare a static handle (initially NULL)
static void* my_handle = NULL;

// 2. Define an init function
int my_init(void** result) {
    *result = create_some_resource();
    return (*result != NULL) ? 0 : -1;
}

// 3. Thread-safe lazy initialization (idempotent -- safe to call from multiple threads)
int ret = TVMFFIHandleInitOnce(&my_handle, my_init);
// my_handle is now initialized; subsequent calls are fast-path no-ops.

// 4. Thread-safe cleanup (also idempotent)
ret = TVMFFIHandleDeinitOnce(&my_handle, my_deinit);
// my_handle is now NULL; deinit called exactly once.

// 5. Can re-initialize after deinit
ret = TVMFFIHandleInitOnce(&my_handle, my_other_init);
```
