# Add TVMFFIHandleInitOnce/DeinitOnce for thread-safe static handle lifecycle in C ABI

## TL;DR

- Introduces `TVMFFIHandleInitOnce` and `TVMFFIHandleDeinitOnce` in `c_api.h` for DSL runtimes lacking C++ static-initialization support (e.g., Rust, Go, Julia FFI).
- Implementation in `src/ffi/init_once.cc` uses a double-checked lock (atomic acquire-load fast path, `std::mutex` slow path) for init and an atomic exchange for deinit.
- Adds 289-line multithreaded GoogleTest suite covering idempotency, error propagation, and race-condition safety.

## Key Exports

```python
# src/ffi/init_once.cc / include/tvm/ffi/c_api.h

def TVMFFIHandleInitOnce(handle_addr: void**, init_func: Callable[[void**], int]) -> int:
    """Thread-safe, one-shot initialization of *handle_addr.

    Fast path: atomic acquire-load; if not nullptr, return 0 immediately.
    Slow path: acquires a static mutex, double-checks *handle_addr, calls init_func.
    # Invariant: init_func MUST store a non-NULL pointer in *result; returning 0 with *result=NULL is an error.
    # Invariant: if init_func returns nonzero, *handle_addr is left as nullptr.
    # Invariant: atomic store-release ensures visibility to future atomic load-acquires in other threads.
    # Interacts with: TVMFFIErrorSetRaisedFromCStr (error propagation on init_func failure or null return).
    # Interacts with: AtomicLoadHandleAcquire / AtomicStoreHandleRelease (internal, platform-abstracted).
    # Extension: DSL callers manage the handle lifetime; deinit via TVMFFIHandleDeinitOnce.
    """
    ...

def TVMFFIHandleDeinitOnce(handle_addr: void**, deinit_func: Callable[[void*], int]) -> int:
    """Thread-safe, one-shot deinitialization of *handle_addr.

    Atomically exchanges *handle_addr with nullptr; calls deinit_func only if old value was not nullptr.
    # Invariant: *handle_addr is set to nullptr before deinit_func is called (prevents double-free).
    # Invariant: if *handle_addr is already nullptr, deinit_func is not called and 0 is returned (idempotent).
    # Interacts with: TVMFFIHandleInitOnce (paired lifecycle).
    # Interacts with: _InterlockedExchangePointer (Windows) / __atomic_exchange_n (GCC/Clang).
    """
    ...

# Internal platform-abstraction helpers (anonymous namespace, not exported):
def AtomicLoadHandleAcquire(src_addr: void**) -> void*: ...
    # Uses __atomic_load_n(..., __ATOMIC_ACQUIRE) on GCC/Clang
    # Uses InterlockedCompareExchangePointerAcquire on Windows >= Win8 (_WIN32_WINNT >= 0x0602)

def AtomicStoreHandleRelease(dst_addr: void**, src: void*) -> None: ...
    # Uses __atomic_store_n(..., __ATOMIC_RELEASE) on GCC/Clang
    # Uses _InterlockedExchangePointer on Windows
```

## Impact

- API: Two new exported C ABI symbols in `c_api.h` under `TVM_FFI_DLL`. Purely additive — no existing signatures changed.
- Behavioral: None to existing functions. The static mutex inside `TVMFFIHandleInitOnce` is a per-translation-unit singleton; all callers of `TVMFFIHandleInitOnce` across all modules sharing `libtvm_ffi` share this one mutex. This means concurrent init of **different** handles is serialized through the same lock — a potential hotspot if many handles are initialized simultaneously at startup.
- Flags/config: `CMakeLists.txt` gains one source file entry: `src/ffi/init_once.cc`.
- Data formats/schemas: None.

## Design Elements

Design elements this commit consumes:
- **0001-c-abi**: Extends `c_api.h` with two new `TVM_FFI_DLL` symbols; follows the existing `int32_t` return-code convention (0 = success, nonzero = error).
- **0005-error-system**: Uses `TVMFFIErrorSetRaisedFromCStr("RuntimeError", ...)` in the implementation to set TLS error slots when init_func returns a null handle or nonzero error code.

Design elements this commit produces:
- **TVMFFIHandleInitOnce / TVMFFIHandleDeinitOnce** — new C ABI lifecycle primitive for DSL runtimes. Not yet linked from any design record. (See Reflection.)

## Usage Examples

**Typical DSL usage pattern (C-compatible caller)**:
```c
// Declare a static handle — initialized to NULL by C zero-init
static void* g_my_runtime = NULL;

static int create_my_runtime(void** result) {
    MyRuntime* rt = malloc(sizeof(MyRuntime));
    if (!rt) {
        TVMFFIErrorSetRaisedFromCStr("RuntimeError", "OOM");
        return -1;
    }
    *result = rt;
    return 0;
}

static int destroy_my_runtime(void* handle) {
    free(handle);
    return 0;
}

// --- init: called from any thread, safe to call concurrently ---
int ret = TVMFFIHandleInitOnce(&g_my_runtime, create_my_runtime);
if (ret != 0) { /* handle error via TVMFFIErrorGetRaised */ }
MyRuntime* rt = (MyRuntime*)g_my_runtime;

// --- deinit: called from any thread, safe to call concurrently ---
ret = TVMFFIHandleDeinitOnce(&g_my_runtime, destroy_my_runtime);
```

**Idempotency invariant (from test suite)**:
```cpp
void* handle = nullptr;
// First call: initializes
TVMFFIHandleInitOnce(&handle, InitSuccess);           // sets handle = new int(42)
void* original = handle;
// Second call with different init_func: no-op
TVMFFIHandleInitOnce(&handle, InitShouldNotBeCalled); // handle unchanged
assert(handle == original);

// First deinit: frees
TVMFFIHandleDeinitOnce(&handle, DeinitSuccess);       // handle = nullptr
// Second deinit: no-op
TVMFFIHandleDeinitOnce(&handle, DeinitShouldNotBeCalled); // DeinitShouldNotBeCalled never called
assert(handle == nullptr);
```
