# Introduce TVMFFIHandleInitOnce for thread-safe lazy initialization
## TL;DR
- Adds `TVMFFIHandleInitOnce` C API and corresponding C++ wrapper for thread-safe, once-only initialization of handles (functions, type indices, etc.).
- Useful for lazy initialization of global function handles without repeated lookup overhead.

## Key Exports

**C API Functions:**
- `TVMFFIHandleInitOnce(handle, init_func, ...) -> int` -- Thread-safe once-only initialization.

**C++ Utilities:**
- Wrapper classes/functions for `TVMFFIHandleInitOnce` usage pattern.

## Impact
- API: New `TVMFFIHandleInitOnce` C API function.
- ABI: New C API symbol (additive).
- Behavioral: none

## Usage Examples
```cpp
static TVMFFIObjectHandle cached_func = nullptr;
TVMFFIHandleInitOnce(&cached_func, []() {
  return TVMFFIFunctionGetGlobal("my.func", &cached_func);
});
```
