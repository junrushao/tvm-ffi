# Add opaque PyObject support for unrecognized Python types in FFI
## TL;DR
- Introduces `kTVMFFIOpaquePyObject` (type index 74) as a new static object type that wraps arbitrary Python objects as ref-counted FFI objects, enabling them to round-trip through C++ containers and callbacks without conversion.
- Adds C API function `TVMFFIObjectCreateOpaque` and the `TVMFFIOpaqueObjectCell` struct for creating and accessing opaque objects.
- Changes the Python `convert()` fallback from raising `TypeError` to wrapping the unknown object as an opaque PyObject, and updates `make_arg`/`make_ret` in Cython to handle the new type index.

## Key Exports

**Types/Classes**:

- `TVMFFIOpaqueObjectCell` (C struct in `c_api.h`):
  ```c
  typedef struct {
      void* handle;  // For Python: PyObject*
  } TVMFFIOpaqueObjectCell;
  ```

- `OpaqueObjectImpl` (C++ class in `src/ffi/object.cc`, internal):
  ```cpp
  class OpaqueObjectImpl : public Object, public TVMFFIOpaqueObjectCell {
  public:
      OpaqueObjectImpl(void* handle, void (*deleter)(void* handle));
      void SetTypeIndex(int32_t type_index);
      ~OpaqueObjectImpl();  // calls deleter(handle)
  };
  ```

- `OpaquePyObject` (Cython class in `object.pxi`):
  ```python
  cdef class OpaquePyObject(Object):
      def pyobject(self) -> object  # Extract underlying Python object
  ```

**Functions**:

- `TVMFFIObjectCreateOpaque(void* handle, int32_t type_index, void (*deleter)(void*), TVMFFIObjectHandle* out) -> int` (C API in `c_api.h`) -- Creates a ref-counted opaque object wrapping an external resource handle. Currently only `kTVMFFIOpaquePyObject` is supported.

- `TVMFFIOpaqueObjectGetCellPtr(TVMFFIObjectHandle obj) -> TVMFFIOpaqueObjectCell*` (inline in `c_api.h`) -- Returns pointer to the opaque cell following the object header.

- `_convert_to_opaque_object(object pyobject) -> OpaquePyObject` (Cython in `function.pxi`) -- Wraps a Python object via `Py_INCREF` + `TVMFFIObjectCreateOpaque`.

- `make_ret_opaque_object(TVMFFIAny result) -> object` (Cython in `object.pxi`) -- Unwraps an opaque return value back to the original Python object via `OpaquePyObject.pyobject()`.

**Constants/Enums**:

- `kTVMFFIOpaquePyObject = 74` -- New static type index for opaque Python objects. Placed immediately after `kTVMFFIModule = 73`, before `kTVMFFIStaticObjectEnd`.

**Renames**:

- `tvm_ffi_callback_deleter` -> `tvm_ffi_pyobject_deleter` (Cython in `function.pxi`) -- Generalized from function-specific deleter to shared PyObject deleter, now used by both `_convert_to_ffi_func` and `_convert_to_opaque_object`.

## Impact
- API: `convert()` no longer raises `TypeError` for unrecognized Python types; they are silently wrapped as opaque objects. Callers relying on `TypeError` to detect unsupported types will need updating. `make_arg` in Cython also wraps unknown types instead of raising `TypeError`.
- ABI: New static type index `kTVMFFIOpaquePyObject = 74` added before `kTVMFFIStaticObjectEnd`. New C API function `TVMFFIObjectCreateOpaque`. New inline accessor `TVMFFIOpaqueObjectGetCellPtr`. New C struct `TVMFFIOpaqueObjectCell`. All additive, but the type index enum change is ABI-breaking for consumers that hardcode `kTVMFFIStaticObjectEnd`.
- Behavioral: Python objects that previously caused `TypeError` in `convert()` or `make_arg` now silently round-trip through the FFI as opaque objects. When returned from C++, the original Python object identity is preserved (`y is x`).
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (`.knowledge/designs/object-system.md`): `OpaqueObjectImpl` inherits from `Object`, uses `make_object<T>`, `ObjectPtr<T>`, and `ObjectUnsafe` for handle manipulation. The type index is set post-construction via `SetTypeIndex` because `RuntimeTypeIndex()` is not available for a non-standard static type.
- **C ABI** (`.knowledge/designs/c-abi.md`): Follows the cell-after-header layout pattern (`TVMFFIOpaqueObjectCell` at `obj + sizeof(TVMFFIObject)`), matching `TVMFFIErrorCell`, `TVMFFIFunctionCell`, `TVMFFIShapeCell`.
- **Type index ranges** (`.knowledge/ADRs/003-type-index-ranges.md`): Allocates index 74 from the `[74, 128)` reserved static range.
- **Python bindings** (`.knowledge/designs/0014-python-bindings.md`): Extends `make_arg` and `make_ret` dispatch tables in function.pxi. Extends `convert()` fallback in convert.py.
- **Ref-counting / GIL discipline**: The deleter (`tvm_ffi_pyobject_deleter`) acquires the GIL via `with gil` to safely call `Py_DECREF`.

Design elements this commit produces:
- **Opaque PyObject pattern**: A new object kind that wraps arbitrary Python objects as FFI-managed ref-counted handles. The lifecycle is: `Py_INCREF` on creation -> stored in `TVMFFIOpaqueObjectCell.handle` -> `Py_DECREF` via deleter on destruction. Identity is preserved: the same `PyObject*` round-trips through C++ and back.
- **`TVMFFIObjectCreateOpaque` C API**: Extensible to other opaque object kinds beyond Python (the `type_index` parameter supports future opaque types, though only `kTVMFFIOpaquePyObject` is currently validated).
- **`OpaquePyObject` Cython class**: Python-side wrapper that exposes `.pyobject()` for extracting the underlying object. Subclasses `Object` for automatic ref-counting.

## Usage Examples

### Opaque PyObject round-trip through FFI function call
**Context**: Passing an arbitrary Python object through a C++ echo function and getting the same object back.
```python
import tvm_ffi

class MyObject:
    def __init__(self, value):
        self.value = value

fecho = tvm_ffi.get_global_func("testing.echo")
x = MyObject("hello")
y = fecho(x)          # x is wrapped as OpaquePyObject, passed to C++, returned
assert y is x          # identity preserved
assert y.value == "hello"
```

### Opaque PyObject in containers
**Context**: Storing arbitrary Python objects in FFI Array and Map containers.
```python
import tvm_ffi

class MyObject:
    def __init__(self, value):
        self.value = value

a = tvm_ffi.convert([MyObject("hello"), MyObject(1)])
assert isinstance(a, tvm_ffi.Array)
assert isinstance(a[0], MyObject)  # unwrapped back to original type
assert a[0].value == "hello"

m = tvm_ffi.convert({"key": MyObject(42)})
assert isinstance(m["key"], MyObject)
assert m["key"].value == 42
```

### Explicit OpaquePyObject conversion and extraction
**Context**: Directly converting and inspecting the opaque wrapper.
```python
import tvm_ffi

obj = MyObject("test")
wrapped = tvm_ffi.convert(obj)           # returns OpaquePyObject
assert isinstance(wrapped, tvm_ffi.core.OpaquePyObject)
assert wrapped.pyobject() is obj          # extract original
```
