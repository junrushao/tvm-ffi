# Add opaque PyObject support for type-erased Python objects in FFI
## TL;DR
- Adds `kTVMFFIOpaquePyObject` (type index 74) and `TVMFFIOpaqueObjectCell` to the C ABI, enabling FFI to carry arbitrary Python objects that have no native FFI representation.
- Implements `TVMFFIObjectCreateOpaque` C API function and `OpaqueObjectImpl` C++ class to create lifecycle-managed opaque objects with a custom deleter.
- Updates Python/Cython layer: `convert()` fallback now wraps unknown types as opaque objects instead of raising `TypeError`; return path unwraps them back to the original Python object via identity-preserving `PyObject*` round-trip.

## Impact
- API: Adds `kTVMFFIOpaquePyObject` (74) to the static type index enum; adds `TVMFFIOpaqueObjectCell` struct and `TVMFFIObjectCreateOpaque` function to c_api.h. Exposes `OpaquePyObject` class and `_convert_to_opaque_object` in Python.
- Behavioral: `tvm_ffi.convert()` no longer raises `TypeError` for unknown Python types -- it silently wraps them as opaque objects. This is a semantic change for callers that relied on the `TypeError` for validation.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- **Object system** (0002): `OpaqueObjectImpl` inherits from `Object`, uses `make_object`, `ObjectPtr`, `ObjectUnsafe::GetHeader` for type index mutation, `ObjectUnsafe::MoveObjectPtrToTVMFFIObjectPtr` for C ABI handoff.
- **C ABI** (0007): follows the cell pattern (`TVMFFIOpaqueObjectCell` placed after `TVMFFIObject` header, accessed via pointer arithmetic), mirrors `TVMFFIFunctionCell`/`TVMFFIErrorCell` layout.
- **Python bindings** (0012): extends Cython `make_ret` dispatch, `make_args` packing, and `convert()` fallback chain.

Design elements this commit produces:
- **Opaque PyObject protocol**: a new object kind (`kTVMFFIOpaquePyObject = 74`) that wraps arbitrary `PyObject*` handles with FFI-managed lifetime. The protocol guarantees identity-preserving round-trip (Python -> FFI -> Python returns the same object). This is the first "foreign object" kind in the type index enum.

## Usage Examples

Round-trip through FFI echo function (from `tests/python/test_function.py`):
```python
import tvm_ffi

class MyObject:
    def __init__(self, value):
        self.value = value

fecho = tvm_ffi.get_global_func("testing.echo")
x = MyObject("hello")
y = fecho(x)            # passes through C++ FFI as opaque object
assert y is x            # identity-preserving round-trip

# Also works in containers
arr = tvm_ffi.convert([MyObject("a"), MyObject(1)])
assert arr[0].value == "a"  # unwrapped back to MyObject
```

Direct conversion and introspection (from `tests/python/test_object.py`):
```python
obj = MyObject("hello")
wrapped = tvm_ffi.convert(obj)              # -> OpaquePyObject
assert isinstance(wrapped, tvm_ffi.core.OpaquePyObject)
unwrapped = wrapped.pyobject()
assert unwrapped is obj                      # identity preserved
```
