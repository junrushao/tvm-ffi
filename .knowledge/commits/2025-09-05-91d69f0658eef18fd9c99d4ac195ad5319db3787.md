# Add Opaque PyObject support for wrapping arbitrary Python objects as FFI-managed objects

## TL;DR
- Adds `kTVMFFIOpaquePyObject` (type index 74) and `TVMFFIObjectCreateOpaque` C API for wrapping arbitrary opaque handles (primarily Python objects) as ref-counted FFI objects.
- Python's `convert()` fallback now wraps unrecognized Python objects as `OpaquePyObject` instead of raising `TypeError`, enabling them to be stored in containers (`Array`, `Map`), passed through FFI function calls, and returned transparently.
- Cython adds `OpaquePyObject(Object)` class and `make_ret_opaque_object` to automatically unwrap opaque objects back to their original Python identity on return.

## Impact
- API: `convert()` no longer raises `TypeError` for unrecognized Python types -- instead wraps them as opaque objects. Callers previously catching `TypeError` from `convert()` will need to adapt.
- Behavioral: `make_args` in Cython now wraps unrecognized argument types as opaque objects instead of raising `TypeError`. FFI function returns with `type_index == kTVMFFIOpaquePyObject` are unwrapped to the original Python object identity (`obj is original`).
- Flags/config: none
- Data formats/schemas: New static type index `kTVMFFIOpaquePyObject = 74` added to `TVMFFITypeIndex` enum before `kTVMFFIStaticObjectEnd`.

Design elements this commit produces:
- **`kTVMFFIOpaquePyObject` (type index 74)**: New static type index for opaque Python objects. Extends the `TVMFFITypeIndex` enum.
- **`TVMFFIOpaqueObjectCell` struct**: New C-level cell layout for opaque objects (just a `void* handle`), following the existing cell pattern (`TVMFFIFunctionCell`, `TVMFFIErrorCell`, etc.).
- **`TVMFFIObjectCreateOpaque` C API**: Factory function for creating opaque objects. Currently restricted to `kTVMFFIOpaquePyObject` but designed for extension.
- **`TVMFFIOpaqueObjectGetCellPtr` inline accessor**: Follows the `sizeof(TVMFFIObject)` offset pattern established by other cell accessors.
- **`OpaqueObjectImpl` C++ class**: Internal implementation using multiple inheritance (`Object` + `TVMFFIOpaqueObjectCell`) to ensure cell layout compatibility.
- **`OpaquePyObject` Cython class**: Python-side wrapper with `.pyobject()` extraction method.
- **`_convert_to_opaque_object` Cython function**: Bridges Python object wrapping with C API creation.
- **Callback deleter rename**: `tvm_ffi_callback_deleter` -> `tvm_ffi_pyobject_deleter` (generalized, now shared by both Function callbacks and opaque objects).

## Usage Examples

**Wrapping arbitrary Python objects and passing through FFI (from test_function.py):**
```python
import tvm_ffi

class MyObject:
    def __init__(self, value):
        self.value = value

# Pass an arbitrary Python object through FFI echo function
fecho = tvm_ffi.get_global_func("testing.echo")
x = MyObject("hello")
y = fecho(x)                # x is wrapped as OpaquePyObject, echoed, then unwrapped
assert y is x               # identity preserved through FFI round-trip

# Store in FFI containers
a = tvm_ffi.convert([MyObject("hello"), MyObject(1)])
assert isinstance(a, tvm_ffi.Array)
assert isinstance(a[0], MyObject)       # unwrapped back to original type
assert a[0].value == "hello"
```

**Explicit OpaquePyObject lifecycle (from test_object.py):**
```python
import sys, tvm_ffi

obj = MyObject("hello")
assert sys.getrefcount(obj) == 2         # local + arg
converted = tvm_ffi.convert(obj)         # wraps as OpaquePyObject
assert sys.getrefcount(obj) == 3         # +1 from FFI
assert isinstance(converted, tvm_ffi.core.OpaquePyObject)
assert converted.pyobject() is obj       # identity preserved
converted = None                         # release FFI reference
assert sys.getrefcount(obj) == 2         # refcount restored
```
