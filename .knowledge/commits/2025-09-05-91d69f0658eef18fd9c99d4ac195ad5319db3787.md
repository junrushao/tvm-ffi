# Add OpaquePyObject type and cross-language lifecycle bridge for unrecognized Python objects
## TL;DR
- Introduces `kTVMFFIOpaquePyObject = 74` as a new static type index; any Python object not natively recognized by FFI is now wrapped into a ref-counted `OpaqueObjectImpl` instead of raising `TypeError`.
- Adds `TVMFFIObjectCreateOpaque` C ABI function and `TVMFFIOpaqueObjectCell` struct; the opaque object's `void* handle` stores a `PyObject*` whose lifecycle is tied to the FFI object via a user-supplied `deleter`.
- Python binding completes the round-trip: `_convert_to_opaque_object` wraps (`Py_INCREF` + `TVMFFIObjectCreateOpaque`); `make_ret_opaque_object` unwraps by calling `OpaquePyObject.pyobject()`, returning the original Python identity (`is` test passes).

class OpaqueObjectImpl(Object, TVMFFIOpaqueObjectCell):
    """Heap object wrapping an arbitrary external handle with a custom deleter."""
    handle: void*         # inherited from TVMFFIOpaqueObjectCell
    deleter_: Callable    # stored as function pointer

class OpaquePyObject(Object):
    """Thin Cython wrapper around a kTVMFFIOpaquePyObject handle."""
    def pyobject(self) -> object: ...
    # Retrieves original PyObject* via TVMFFIOpaqueObjectGetCellPtr(self.chandle).handle
    # Interacts with: TVMFFIOpaqueObjectGetCellPtr, Python reference counting

# Cython additions (python/tvm_ffi/cython/function.pxi)
def _convert_to_opaque_object(pyobject: object) -> OpaquePyObject: ...
# Py_INCREF(pyobject) then TVMFFIObjectCreateOpaque
# Interacts with: tvm_ffi_pyobject_deleter, OpaquePyObject

## Impact
- API: `TVMFFIObjectCreateOpaque` and `TVMFFIOpaqueObjectGetCellPtr` added to the stable C ABI in `c_api.h`. `kTVMFFIOpaquePyObject = 74` inserted before `kTVMFFIStaticObjectEnd` — callers that range-check against the old `kTVMFFIStaticObjectEnd` value (73+1=74) now need to use the symbolic constant rather than a hardcoded integer. Any language binding that exposes `make_args` and previously raised `TypeError` for unrecognized objects will now silently wrap them.
- Behavioral: `convert(value)` in Python no longer raises `TypeError` for arbitrary objects; it wraps them as `OpaquePyObject`. Round-tripping through any FFI call that uses `make_ret` transparently unwraps back to the original Python object (identity preserved). `fecho(x)` where `x` is an arbitrary Python object now returns `x` itself.
- Flags/config: none
- Data formats/schemas: none

## Design Elements
Design elements this commit consumes:
- `0001-c-abi` — extends the static type index enum, adds new `TVMFFIOpaqueObjectCell` ABI struct and `TVMFFIObjectCreateOpaque` DLL export; relies on inline `TVMFFIObject`-header-offset pattern used by `TVMFFIFunctionGetCellPtr`, `TVMFFIErrorGetCellPtr`, etc.
- `0002-object-system` — `OpaqueObjectImpl` inherits from `Object`; uses `make_object<T>`, `ObjectPtr<T>`, `ObjectUnsafe::GetHeader` for post-construction type_index override, `ObjectUnsafe::MoveObjectPtrToTVMFFIObjectPtr`; dual ref-count lifecycle (strong decrement triggers custom deleter)
- `0004-function-system` — reuses `tvm_ffi_pyobject_deleter` (renamed from `tvm_ffi_callback_deleter`) for both `Function` and `OpaquePyObject` creation; `make_args` now calls `_convert_to_opaque_object` instead of raising `TypeError`
- `0013-python-package` — extends Cython `base.pxi`, `function.pxi`, `object.pxi`; `convert.py` fallback path updated

Design elements this commit produces:
- **OpaquePyObject bridge protocol** — new cross-language lifecycle pattern: C ABI `TVMFFIObjectCreateOpaque` + `TVMFFIOpaqueObjectCell` + `kTVMFFIOpaquePyObject=74` + Cython `OpaquePyObject` + `_convert_to_opaque_object`/`make_ret_opaque_object`. This is the first non-C++ object type with static type index. No design record exists yet.
- **tvm_ffi_pyobject_deleter** — generalized deleter replacing the Function-only `tvm_ffi_callback_deleter`; shared by both packed-function wrapping and opaque-object wrapping paths.

## Usage Examples

End-to-end round-trip (Python → FFI → Python, from `tests/python/test_function.py`):

```python
class MyObject:
    def __init__(self, value):
        self.value = value

fecho = tvm_ffi.get_global_func("testing.echo")
x = MyObject("hello")
y = fecho(x)        # x is wrapped as kTVMFFIOpaquePyObject, then unwrapped on return
assert y is x       # identity preserved — not a copy

# Python callback also works transparently
def py_callback(z):
    assert z is x   # z unwrapped from OpaquePyObject before reaching Python
    return z

fcallback = tvm_ffi.convert(py_callback)
z = fcallback(x)
assert z is x
```

Container storage (from `tests/python/test_container.py`):

```python
a = tvm_ffi.convert([MyObject("hello"), MyObject(1)])
assert isinstance(a, tvm_ffi.Array)
assert isinstance(a[0], MyObject)   # unwrapped transparently on element access
```

Direct conversion and lifecycle (from `tests/python/test_object.py`):

```python
obj0 = MyObject("hello")
assert sys.getrefcount(obj0) == 2
obj0_converted = tvm_ffi.convert(obj0)    # Py_INCREF — refcount 3
assert isinstance(obj0_converted, tvm_ffi.core.OpaquePyObject)
obj0_cpy = obj0_converted.pyobject()      # another strong ref — refcount 4
obj0_converted = None                     # FFI object GC'd — Py_DECREF — refcount 3
obj0_cpy = None                           # refcount 2
```
