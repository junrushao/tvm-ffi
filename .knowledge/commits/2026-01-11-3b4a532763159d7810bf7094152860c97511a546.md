# Add TVM_FFI_USE_THREADS CMake option for explicit thread linkage control
## TL;DR
- Replaces the auto-detect `find_package(Threads)` with a new CMake option `TVM_FFI_USE_THREADS` (default ON). When OFF, threads linkage is skipped entirely, supporting cross-compilation targets without pthreads.
