# Add CMake option to explicitly disable threads linking
## TL;DR
- Adds `TVM_FFI_USE_THREADS` CMake option (default ON) to control whether `Threads::Threads` is linked.
- Changes `find_package(Threads)` from optional-with-silent-skip to `REQUIRED`-when-enabled, making build failures explicit.
- Supports cross-compilation platforms where pthreads is unavailable or undesirable.

## Impact
- API: none
- Behavioral: none
- Flags/config: New CMake option `TVM_FFI_USE_THREADS` (default `ON`). Setting `-DTVM_FFI_USE_THREADS=OFF` skips threads detection and linking entirely. When `ON`, `find_package(Threads REQUIRED)` now fails loudly if threads are not found (previously silently skipped).
