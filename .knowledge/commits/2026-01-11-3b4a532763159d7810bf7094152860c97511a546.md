# Add TVM_FFI_USE_THREADS CMake option to explicitly control thread linkage

## TL;DR
- Adds `option(TVM_FFI_USE_THREADS "Link against threads in shared lib" ON)` to `CMakeLists.txt`.
- Replaces the `if (Threads_FOUND)` guard (from 0d157dc) with `if (TVM_FFI_USE_THREADS)` — when enabled, `find_package(Threads REQUIRED)` is called (hard fail); when disabled, skipped entirely.
- Net change: 3 additions, 4 deletions.

## Key Exports

```python
# CMakeLists.txt — new CMake option
# option(TVM_FFI_USE_THREADS "Link against threads in shared lib" ON)
# Default: ON (same as prior behavior when Threads found)
# Set OFF to skip thread linkage entirely (e.g. -DTVM_FFI_USE_THREADS=OFF for embedded targets)
# Invariant: when ON, Threads REQUIRED — fails hard if not found
# Interacts with: TVM_FFI_USE_DL_LIBS (sibling option added in dcd07cf)
```

## Impact
- API: none
- Behavioral: cross-compilation users can now pass `-DTVM_FFI_USE_THREADS=OFF` to unconditionally skip thread linkage. Default ON is unchanged from 0d157dc behavior when threads are present.
- Flags/config: `TVM_FFI_USE_THREADS` (new CMake option, default ON).
- Data formats/schemas: none

## Usage Examples

```cmake
# Cross-compile without threads:
cmake . -B build -DTVM_FFI_USE_THREADS=OFF

# Normal build (default, same as before):
cmake . -B build  # TVM_FFI_USE_THREADS=ON
```
