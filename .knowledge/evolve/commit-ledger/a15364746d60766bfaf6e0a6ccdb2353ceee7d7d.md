# Expose Python API to construct Function from raw C function pointer
## TL;DR
- Adds `Function.__from_extern_c__(c_symbol, keep_alive_object)` static method in Cython, enabling Python code to construct a `Function` from a raw C function pointer (as integer) and an optional keep-alive object.
- Fixes the Cython `TVMFFIObject.deleter` signature to `void(*)(void*, int flags)`, aligning with the current C ABI (commit `24125d0`).
- Adds C++ test helper `testing.get_add_one_c_symbol` that returns a raw function pointer for testing the new API.

## Key Exports

```python
class Function(Object):
    @staticmethod
    def __from_extern_c__(c_symbol: int, keep_alive_object: Any | None = None) -> Function:
        """Construct a Function from a C symbol address and optional keep-alive object.

        c_symbol is cast to TVMFFISafeCallType (must match signature:
            int(void* self, const TVMFFIAny* args, int32_t num_args, TVMFFIAny* result)
        where the first argument (self/handle) is ignored.

        When keep_alive_object is None:
            TVMFFIFunctionCreate(NULL, safe_call, NULL, &handle)
        When keep_alive_object is provided:
            Py_INCREF(keep_alive_object)
            TVMFFIFunctionCreate(py_obj, safe_call, TVMFFIPyObjectDeleter, &handle)
            # On error: Py_DECREF(keep_alive_object) for cleanup
        """
        # Interacts with: TVMFFIFunctionCreate (C ABI, 0007)
        # Interacts with: Function::FromExternC (C++ counterpart, 0003)
        # Interacts with: TVMFFIPyObjectDeleter (Cython object deleter)
        # Invariant: c_symbol must be a valid function pointer cast to int
        # Invariant: keep_alive_object ref count incremented by 1 while Function is alive
        # Extension: useful for JIT execution engines that provide raw C symbols
```

## Impact
- API: New `Function.__from_extern_c__` static method added to the Python `Function` class. No existing APIs changed.
- Behavioral: The Cython `TVMFFIObject.deleter` signature is corrected to match the C ABI; this is a binding-level fix with no behavioral change (the previous signature was already incorrect/unused directly in Cython).
- Flags/config: none
- Data formats/schemas: none

## Usage Examples

Constructing a Function from a JIT-compiled C symbol:
```python
import tvm_ffi

# Get raw C function pointer from a JIT engine (here using test helper)
add_one_c_symbol = tvm_ffi.get_global_func("testing.get_add_one_c_symbol")()

# Construct Function without keep-alive
fadd_one = tvm_ffi.Function.__from_extern_c__(add_one_c_symbol)
assert fadd_one(1) == 2
assert fadd_one(2) == 3

# Construct Function with keep-alive (e.g., JIT engine that must stay alive)
engine = SomeJITEngine()
c_symbol = engine.get_symbol_address("my_kernel")
func = tvm_ffi.Function.__from_extern_c__(c_symbol, engine)
# engine's ref count is incremented; it stays alive as long as func exists
result = func(42)
```
