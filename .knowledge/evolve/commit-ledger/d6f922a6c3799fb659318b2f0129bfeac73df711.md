# Skill /commit-ledger - Self-Evolution
- **Procedure friction**: Bash tool was completely unavailable due to a system-level EPERM error on session-env directory creation. This prevented worktree setup, git show, and date capture. Recovery required detecting previously-written output files via file-search tools and validating their content without running any shell commands.
- **Template gap**: The skill procedure has no documented fallback path for when bash is entirely unavailable. A note about checking for existing OUTFILE before re-running could save effort in repeated invocations.
- **Wasted effort**: Significant upfront effort trying multiple bash invocations (with and without sandbox) before discovering the session-env EPERM issue was systemic. Earlier detection heuristics (e.g., checking for existing output files first) would reduce wasted steps.
- **Suggested skill change**: Add a Step 0.0 "idempotency check" — before any worktree/git operations, check whether $OUTFILE already exists and is non-empty. If so, log that it was previously processed and skip to writing LOGFILE/EVOLVEFILE unless re-analysis is explicitly requested.
