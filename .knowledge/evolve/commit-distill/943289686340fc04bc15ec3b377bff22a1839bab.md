- **Template mismatch**: None.
- **Upstream skill gap**: None -- ledger inputs were sufficient. All 33 ledgers had correct frontmatter for triage and comprehensive Key Exports for active commits.
- **Quality bar friction**: Requiring usage examples for pure-rename commits (a08fa6e, 4dee97f) felt borderline -- the "before/after" pattern in the ledger served as the example, but the design doc already had examples. Deferred to updating existing examples rather than adding new ones.
- **Procedure friction**: Phase 0 worktree isolation was difficult when the agent was spawned into a non-existent worktree directory. The guardrail checks caught the issue, but the recovery path (manually creating a git worktree) was not documented in the skill procedure.
- **Suggested skill change**: Add a recovery step in Phase 0.2: "If $REPO_WORKTREE does not exist as a real git worktree (no .git file), create one via `git worktree add` before proceeding."
